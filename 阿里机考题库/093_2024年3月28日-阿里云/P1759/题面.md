## 题目描述

塔子哥有一个长度为$n$的数组$a$，他定义$(x,y)$为一个"好数对”，当且仅当$x$和$y$不为倍数关系，换句话说$x\%y\ne 0$，同时$y\%x\ne 0$。
现在塔子哥想从数组$a$中选择一个求和最大的好数对$(a_i,a_j)$，他想知道这个最大和是多少，请你帮帮他吧。



## 输入描述

> 输入包含两行。
> 第一行一个正整数$n(2 \le n\le 10^5)$，表示数组 $a$的长度。
> 第二行$n$ 个正整数$a_i(1\le a_i \le 10^5)$，表示数组$a$的每个元素。



## 输出描述

> 输出包含一行一个正整数表示答案。
> 如果数组中不存在好数对，输出 0。





## 样例

**输入**

```
5
1 1 2 3 4
```

**输出**

```
7
```
