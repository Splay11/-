# 题目内容

小红有一个正整数$x$，他希望你找到一个满足$1≤y<x$的正整数$y$，使得:$ (x +y)×gcd(x,y)$ 的值尽可能大，请你帮他求出这个最大值吧。
$gcd(x,y) $表示$x$和$y$的最大公约数，例如:$gcd(4,6)=2$。

# 输入描述
每个测试文件均包含多组测试数据。第一行输入一个整数$T$($1≤T≤10^3$)代表数据组数，每组测试数据描述如下：

在一行上输入一个正整数$x$($2 ≤x≤10^9$)，表示小红询问的$x$。

# 输出描述

对于每组测试数据，输出包含一行一个正整数，表示$(x+y)×gcd(x,y)$的最大值。

## 样例1 

**输入** 

```
3 
3
6
5
```

**输出** 

```
5
27
9
```
