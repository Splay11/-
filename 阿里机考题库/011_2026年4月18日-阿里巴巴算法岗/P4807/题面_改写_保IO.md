# 指标采集与清零

# 题目内容

运维侧维护长度为 $n$ 的指标数组 $h_1,h_2,\ldots,h_n$，以及两个 $1 \sim n$ 的排列 $\sigma$ 与 $\tau$。

至多各执行一次下列操作（顺序任意，也可跳过其中一种；两种都不做则得分为 $0$）：

1. 选取 $t$（$1 \le t \le n$），得分 $=\sum_{i=1}^{t} h_{\sigma_i}$；
2. 选取 $u$（$1 \le u \le n$），依次将 $h_{\tau_1},h_{\tau_2},\ldots,h_{\tau_u}$ 置为 $0$。

输出可获得的**最大得分**。

# 输入描述

每个测试文件包含多组测试数据。

1. 第一行一个整数 $T$（$1 \le T \le 10^4$），表示组数。
2. 每组数据：
   - 第一行整数 $n$（$1 \le n \le 2 \times 10^5$）；
   - 第二行 $n$ 个整数 $h_1,\ldots,h_n$（$-10^9 \le h_i \le 10^9$）；
   - 第三行 $n$ 个整数 $\sigma_1,\ldots,\sigma_n$（$1 \sim n$ 的排列）；
   - 第四行 $n$ 个整数 $\tau_1,\ldots,\tau_n$（$1 \sim n$ 的排列）。
3. 单个测试文件中所有 $n$ 之和不超过 $2 \times 10^5$。

# 输出描述

每组数据输出一行一个整数，表示最大得分。

## 样例1

**输入**

```
3
3
3 -5 6
1 3 2
2 1 3
4
8 -12 5 1
1 2 3 4
2 4 1 3
1
-3
1
1
```

**输出**

```
9
14
0
```

**说明**

- 第一组：仅做操作 1 且 $t=2$，沿 $\sigma$ 取前缀 $3+6=9$ 即为最优。
- 第二组：先做操作 2 令 $u=1$ 将 $h_2$ 清零，再沿 $\sigma$ 取全长前缀，得 $8+0+5+1=14$。
- 第三组：唯一指标为负，最优为不做任何操作，得 $0$。
