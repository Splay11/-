## 解题思路

先把题意转化一下。

你需要选一个整数位置 $x$，要求它不能落在任何一个人的禁区 $[l_i, r_i]$ 中，也就是 $x$ 不能被这些区间的并集覆盖。同时要让你走的距离 $|x-p|$ 最小。

所以问题本质上就是：

给定若干个区间，求离 $p$ 最近的、**不在这些区间并集内** 的整数点。

### 核心思路

如果把所有禁区看成一个整体，那么真正起作用的是这些区间合并后的结果。

比如有区间：

$$
[1,3],[2,5],[7,8]
$$

它们合并后就是：

$$
[1,5],[7,8]
$$

因为在并集意义下，单独区间已经没有区别了。

接下来分情况讨论：

#### 情况一：$p$ 不在任何合并后的区间内

说明当前位置 $p$ 本身就可以选，答案就是：

$$
0
$$

#### 情况二：$p$ 落在某个合并后的区间 $[L,R]$ 内

因为整个区间里的点都不能选，所以最近的可选位置只能在这个区间外侧，且一定是：

* 左边最近点：$L-1$
* 右边最近点：$R+1$

对应距离分别为：

$$
p-(L-1)=p-L+1
$$

$$
(R+1)-p=R-p+1
$$

所以答案就是：

$$
\min(p-L+1,; R-p+1)
$$

### 实现方法

1. 读入所有区间。
2. 按左端点从小到大排序；若左端点相同，则按右端点从小到大排序。
3. 依次合并区间：

   * 若当前区间与上一个合并区间有交集或相邻，则扩展右端点；
   * 否则开始一个新的合并区间。
4. 在合并过程中判断 $p$ 是否落在当前合并区间中：

   * 如果不在任何合并区间中，输出 $0$；
   * 如果在某个合并区间 $[L,R]$ 中，输出 $\min(p-L+1,;R-p+1)$。

这里“相邻”也要合并，即当新区间左端点满足：

$$
l \le \text{当前右端点} + 1
$$

就可以并到一起。因为如果两个区间分别是 $[1,2]$ 和 $[3,4]$，它们虽然没有重叠，但整数点 $2$ 和 $3$ 紧挨着，中间没有可选整数点，合并后处理更自然。当然本题即使只按重叠合并也能做，但合并相邻区间写法更统一。



## 复杂度分析

设单组数据有 $n$ 个区间。

排序的时间复杂度为：

$$
O(n \log n)
$$

排序后线性扫描合并区间，时间复杂度为：

$$
O(n)
$$

所以单组总时间复杂度为：

$$
O(n \log n)
$$

空间复杂度主要来自存储区间：

$$
O(n)
$$

题目保证所有测试数据的 $n$ 之和不超过 $5 \times 10^5$，这个复杂度完全可以通过。



## 代码实现

### Python

```python
import sys


def solve_case(n, p, intervals):
    # 按区间左端点排序，左端点相同时按右端点排序
    intervals.sort()

    # 当前正在维护的合并区间左右端点
    cur_l, cur_r = intervals[0]

    for i in range(1, n):
        l, r = intervals[i]

        # 如果新区间与当前合并区间有交集或相邻，则继续合并
        if l <= cur_r + 1:
            if r > cur_r:
                cur_r = r
        else:
            # 当前合并区间已经结束，先判断 p 是否在其中
            if cur_l <= p <= cur_r:
                # 最近可选位置只能是 cur_l - 1 或 cur_r + 1
                return min(p - cur_l + 1, cur_r - p + 1)

            # 开始维护下一个合并区间
            cur_l, cur_r = l, r

    # 别忘了判断最后一个合并区间
    if cur_l <= p <= cur_r:
        return min(p - cur_l + 1, cur_r - p + 1)

    # p 不在任何禁区中，当前位置就可以选
    return 0


def main():
    input = sys.stdin.readline
    t = int(input().strip())
    ans = []

    for _ in range(t):
        n, p = map(int, input().split())
        intervals = []

        for _ in range(n):
            l, r = map(int, input().split())
            intervals.append((l, r))

        ans.append(str(solve_case(n, p, intervals)))

    print("\n".join(ans))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.StringTokenizer;
import java.util.Arrays;

public class Main {

    // 用于存储区间
    static class Interval implements Comparable<Interval> {
        int l;
        int r;

        Interval(int l, int r) {
            this.l = l;
            this.r = r;
        }

        @Override
        public int compareTo(Interval other) {
            if (this.l != other.l) {
                return this.l - other.l;
            }
            return this.r - other.r;
        }
    }

    // 处理单组测试数据
    static int solveCase(int n, int p, Interval[] intervals) {
        // 按左端点排序，左端点相同按右端点排序
        Arrays.sort(intervals);

        // 当前正在维护的合并区间
        int curL = intervals[0].l;
        int curR = intervals[0].r;

        for (int i = 1; i < n; i++) {
            int l = intervals[i].l;
            int r = intervals[i].r;

            // 如果新区间与当前合并区间有交集或相邻，则合并
            if (l <= curR + 1) {
                if (r > curR) {
                    curR = r;
                }
            } else {
                // 当前合并区间结束后，判断 p 是否落在其中
                if (curL <= p && p <= curR) {
                    return Math.min(p - curL + 1, curR - p + 1);
                }

                // 开始新的合并区间
                curL = l;
                curR = r;
            }
        }

        // 判断最后一个合并区间
        if (curL <= p && p <= curR) {
            return Math.min(p - curL + 1, curR - p + 1);
        }

        // p 不在任何禁区中
        return 0;
    }

    public static void main(String[] args) throws Exception {
        FastScanner fs = new FastScanner();
        StringBuilder sb = new StringBuilder();

        int T = fs.nextInt();

        while (T-- > 0) {
            int n = fs.nextInt();
            int p = fs.nextInt();

            Interval[] intervals = new Interval[n];
            for (int i = 0; i < n; i++) {
                int l = fs.nextInt();
                int r = fs.nextInt();
                intervals[i] = new Interval(l, r);
            }

            sb.append(solveCase(n, p, intervals)).append('\n');
        }

        System.out.print(sb.toString());
    }

    // 使用 BufferedReader + StringTokenizer 完成输入
    static class FastScanner {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st;

        String next() throws IOException {
            while (st == null || !st.hasMoreElements()) {
                st = new StringTokenizer(br.readLine());
            }
            return st.nextToken();
        }

        int nextInt() throws IOException {
            return Integer.parseInt(next());
        }
    }
}
```

```cpp
    int curL = intervals[0].first;
    int curR = intervals[0].second;

    for (int i = 1; i < n; i++) {

        if (l <= curR + 1) {
            if (r > curR) {
                curR = r;
            }
        } else {
            // 当前合并区间结束，判断 p 是否在其中
            if (curL <= p && p <= curR) {
                return min(p - curL + 1, curR - p + 1);
            }

            // 开始新的合并区间
            curL = l;
            curR = r;
        }
    }

    // 判断最后一个合并区间
    if (curL <= p && p <= curR) {

}
```
