## 解题思路

### 核心思路

题目中有两个人轮流拿食物：

* 笨蛋同学先手，并且每次都拿当前桌上美味度最高的食物；
* 天才同学后手，但会采用最优策略，使最终差值
  $$
  \text{diff} = \text{笨蛋总美味度} - \text{天才总美味度}
  $$
  尽量小。

由于笨蛋同学的策略已经固定，所以关键在于分析天才同学应该怎么拿。

先把所有食物按美味度从大到小排序，记为：

$$
b_1 \ge b_2 \ge b_3 \ge \cdots \ge b_n
$$

因为笨蛋同学每次都拿当前最大值，所以如果天才同学也总是拿当前最大值，那么整个过程就会变成：

* 笨蛋拿 $b_1$
* 天才拿 $b_2$
* 笨蛋拿 $b_3$
* 天才拿 $b_4$
* ……

也就是说，最终：

* 笨蛋拿到排序后奇数位置的数
* 天才拿到排序后偶数位置的数

下面证明为什么天才同学最优策略一定是“每次也拿当前最大值”。

### 为什么天才同学也应该每次拿当前最大值

假设某一轮笨蛋同学拿完之后，当前桌上最大值是 $y$，天才同学却没有拿它，而是拿了一个更小的值 $x$，其中 $x < y$。

那么下一轮笨蛋同学一定会把 $y$ 拿走，因为笨蛋总拿当前最大值。

此时如果把这两个数的归属交换：

* 让天才同学这一轮拿 $y$
* 原来后面会被拿走的 $x$，改成由对应的人去拿

由于 $y > x$，交换后：

* 天才同学拿到的总和更大了
* 笨蛋同学拿到的总和更小了或者不变

所以最终差值一定不会变大，反而会更小。

因此，天才同学如果想让差值尽量小，最优策略一定是：**每次也拿当前剩余食物中的最大值**。

### 实现方法

既然双方都会按当前最大值依次拿，那么只需要：

1. 将数组按从大到小排序；
2. 遍历排序后的数组：

   * 下标为偶数的位置（第 $1,3,5,\dots$ 个）加到笨蛋同学总和；
   * 下标为奇数的位置（第 $2,4,6,\dots$ 个）加到天才同学总和；
3. 输出两者差值即可。



## 复杂度分析

设每组数据有 $n$ 个食物。

排序的时间复杂度为：

$$
O(n \log n)
$$

遍历求和的时间复杂度为：

$$
O(n)
$$

所以单组数据总时间复杂度为：

$$
O(n \log n)
$$

空间复杂度主要是排序使用的空间：

* Python：通常为 $O(n)$
* Java / C++：取决于排序实现，通常可认为是 $O(\log n)$ 到 $O(n)$

整体可以写为：

$$
O(n)
$$

到

$$
O(n \log n)
$$


## 代码实现

### Python

```python
import sys


def solve_case(n, arr):
    # 将食物按美味度从大到小排序
    arr.sort(reverse=True)

    # bad_sum 表示笨蛋同学拿到的总美味度
    # good_sum 表示天才同学拿到的总美味度
    bad_sum = 0
    good_sum = 0

    # 排序后，笨蛋同学拿奇数次，也就是下标为 0, 2, 4... 的位置
    # 天才同学拿偶数次，也就是下标为 1, 3, 5... 的位置
    for i in range(n):
        if i % 2 == 0:
            bad_sum += arr[i]
        else:
            good_sum += arr[i]

    # 返回最终最小差值
    return bad_sum - good_sum


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    t = data[0]
    idx = 1
    ans = []

    for _ in range(t):
        n = data[idx]
        idx += 1

        arr = data[idx:idx + n]
        idx += n

        ans.append(str(solve_case(n, arr)))

    sys.stdout.write("\n".join(ans))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.Arrays;
import java.util.StringTokenizer;

public class Main {
    // 使用 StringTokenizer 进行输入读取
    static class Scanner {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st;

        String next() throws IOException {
            while (st == null || !st.hasMoreTokens()) {
                st = new StringTokenizer(br.readLine());
            }
            return st.nextToken();
        }

        int nextInt() throws IOException {
            return Integer.parseInt(next());
        }
    }

    static long solveCase(int n, int[] arr) {
        // 将食物按美味度从小到大排序
        Arrays.sort(arr);

        long badSum = 0;
        long goodSum = 0;

        // 因为当前最大值总是被优先拿走，
        // 所以从数组末尾开始模拟双方轮流取数即可
        // 最后一个数是最大的，先给笨蛋同学
        boolean badTurn = true;

        for (int i = n - 1; i >= 0; i--) {
            if (badTurn) {
                badSum += arr[i];
            } else {
                goodSum += arr[i];
            }
            badTurn = !badTurn;
        }

        // 返回最终最小差值
        return badSum - goodSum;
    }

    public static void main(String[] args) throws Exception {
        Scanner sc = new Scanner();
        StringBuilder sb = new StringBuilder();

        int t = sc.nextInt();

        while (t-- > 0) {
            int n = sc.nextInt();
            int[] arr = new int[n];

            for (int i = 0; i < n; i++) {
                arr[i] = sc.nextInt();
            }

            sb.append(solveCase(n, arr)).append('\n');
        }

        System.out.print(sb.toString());
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

long long solve_case(int n, vector<int>& arr) {
    // 将食物按美味度从大到小排序
    sort(arr.begin(), arr.end(), greater<int>());

    long long bad_sum = 0;
    long long good_sum = 0;

    // 排序后按顺序轮流取即可：
    // 下标 0, 2, 4... 归笨蛋同学
    // 下标 1, 3, 5... 归天才同学
    for (int i = 0; i < n; i++) {
        if (i % 2 == 0) {
            bad_sum += arr[i];
        } else {
            good_sum += arr[i];
        }
    }

    // 返回最终最小差值
    return bad_sum - good_sum;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    while (T--) {
        int n;
        cin >> n;

        vector<int> arr(n);
        for (int i = 0; i < n; i++) {
            cin >> arr[i];
        }

        cout << solve_case(n, arr) << '\n';
    }

    return 0;
}
```
