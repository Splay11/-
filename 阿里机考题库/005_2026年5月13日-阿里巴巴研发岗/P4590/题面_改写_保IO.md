# 比特递增

在数字电路设计中，需要将寄存器的初始值通过若干次比特翻转提升到目标值。

给定两个整数 $a$ 与 $b$，每次操作你可以选择一个非负整数 $i$，把当前数值加上 $2^i$。问从 $a$ 变到 $b$ 最少需要多少次操作。

# 输入描述

每个测试文件包含多组数据。

第一行一个整数 $T$ ($1 \le T \le 100000$)，表示数据组数。

接下来 $T$ 行，每行两个整数 $a, b$ ($-10^{18} \le a \le b \le 10^{18}$)。

# 输出描述

对每组数据输出一行一个整数，表示最少操作次数。

## 样例1

**输入**

```
4
0 9
3 7
-2 6
10 10
```

**输出**

```
2
1
1
0
```

**说明**
- 第一组：$0 + 2^0 + 2^3 = 9$，共 $2$ 次操作。
- 第二组：$3 + 2^2 = 7$，共 $1$ 次操作。
- 第三组：$(-2) + 2^3 = 6$，共 $1$ 次操作。
- 第四组：初始值已是目标值，$0$ 次操作。
