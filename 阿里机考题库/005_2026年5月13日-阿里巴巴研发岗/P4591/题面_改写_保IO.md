# 相邻不同串计数

在密码学场景中，需要统计一个满足相邻字符两两不同约束的密钥序列方案数。

给定一个长度为 $m$ 的模板串 $\textit{pat}$，其中包含小写字母和 `?`。你需要统计所有长度为 $m$、仅由小写字母构成的字符串 $t$ 的个数，满足：

1. 若 $\textit{pat}[i] \ne$ `?`，则 $t[i] = \textit{pat}[i]$。
2. 相邻字符不能相同，即 $t[i + 1] \ne t[i]$。

请你将答案对 $10^9+7$ 取模后输出。

# 输入描述

第一行一个整数 $T$ ($1 \le T \le 1000$)，表示数据组数。

对于每组数据：

第一行一个整数 $m$ ($1 \le m \le 10^5$)，表示模板串长度。

第二行一个长度为 $m$ 的字符串 $\textit{pat}$，只包含小写字母与 `?`。

保证所有数据的 $m$ 之和不超过 $500000$。

# 输出描述

对于每组数据输出一行一个整数，表示满足条件的字符串数对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
4
2
??
3
a?c
3
abc
2
aa
```

**输出**

```
650
24
1
0
```

**说明**
- 第一组：$\textit{pat}=$ `??`，第一位有 $26$ 种选择，第二位有 $25$ 种（不能同第一位），$26 \times 25 = 650$。
- 第二组：$\textit{pat}=$ `a?c`，`?` 不能是 `a`（前面限制）也不能是 `c`（后面限制），故只有 $24$ 种合法方案。
- 第三组：$\textit{pat}=$ `abc`，没有 `?`，已满足相邻不同，方案数为 $1$。
- 第四组：$\textit{pat}=$ `aa`，两个相邻固定字符相等，无合法方案。
