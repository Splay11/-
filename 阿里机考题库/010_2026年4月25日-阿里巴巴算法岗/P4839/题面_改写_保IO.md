# 设备标识逐段拼装

# 题目内容

内网运维侧需将空标识逐段拼成给定编码。

从空串出发，共进行 $L$ 次操作：每次在**当前串**的任意位置（下标 $0$ 至当前长度）插入一个小写字母。两种操作序列视为不同，当且仅当某一步的插入位置或插入字母不同。

求能得到目标编码串 $\textit{token}$ 的不同操作序列数，对 $10^9+7$ 取模。

# 输入描述

每个测试文件包含多组测试数据。

- 第一行：整数 $T$（$1 \le T \le 2 \times 10^5$），测试组数。
- 每组数据：
  - 第一行：整数 $L$（$1 \le L \le 5 \times 10^5$），目标编码长度；
  - 第二行：长度为 $L$ 的小写字母串 $\textit{token}$。

单个测试文件中，所有组的 $L$ 之和不超过 $2 \times 10^6$。

# 输出描述

每组数据输出一行一个整数，表示合法操作序列数对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
2
2
xy
3
xzx
```

**输出**

```
2
6
```

**说明**

- 第一组：$L=2$，两次插入共有 $2!=2$ 种不同序列。
- 第二组：$L=3$，共有 $3!=6$ 种不同序列。
