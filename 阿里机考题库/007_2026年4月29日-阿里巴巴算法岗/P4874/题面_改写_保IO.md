# 最早空闲时刻

## 题目内容

运维侧拿到 $n$ 个维护窗口，每个窗口是一个闭区间 $[s_i,e_i]$，表示该时段被占用。

请找出最小的非负整数时刻 $x$，使得 $x$ 不属于任何一个维护窗口，即不存在 $i$ 满足 $s_i \le x \le e_i$。

## 输入描述

第一行输入一个整数 $n\ (1 \le n \le 2 \times 10^5)$，表示维护窗口的数量。

此后 $n$ 行，每行输入两个整数 $s,e\ (0 \le s \le e \le 10^{18})$，表示一个闭区间 $[s,e]$。

## 输出描述

输出一个整数，表示最早的空闲时刻。

## 样例1

**输入**

```
3
0 2
4 6
8 10
```

**输出**

```
3
```

**说明**

- 窗口为 $[0,2]$、$[4,6]$、$[8,10]$，时刻 $0,1,2$ 均被占用，$3$ 是第一个空闲时刻。

## 样例2

**输入**

```
2
0 5
3 7
```

**输出**

```
8
```

**说明**

- 两个窗口覆盖了 $0$ 到 $7$ 的连续时段，$8$ 是第一个空闲时刻。
