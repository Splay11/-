# 题目内容


给定三个长度为 $n$ 的数组 $\{a_1, a_2, \dots, a_n\}$、$\{b_1, b_2, \dots, b_n\}$ 和 $\{c_1, c_2, \dots, c_n\}$。这里 $c_j$ 表示对数组 $b$ 的一个下标。
请你统计满足以下条件的有序对 $(i, j)$ 的数量：
- $1 \le i \le j \le n$；
- $a_i = b_{c_j}$。


# 输入描述


每个测试文件均包含多组测试数据。第一行输入一个整数 $T$（$1 \le T \le 2 \times 10^5$）代表数据组数；除此之外，保证单个测试文件的 $n$ 之和不超过 $2 \times 10^5$。
每组测试数据的输入格式如下：
- 第一行输入一个整数 $n$（$1 \le n \le 10^5$）；
- 第二行输入 $n$ 个整数 $a_1, a_2, \dots, a_n$（$1 \le a_i \le 10^9$）；
- 第三行输入 $n$ 个整数 $b_1, b_2, \dots, b_n$（$1 \le b_i \le 10^9$）；
- 第四行输入 $n$ 个整数 $c_1, c_2, \dots, c_n$（$1 \le c_j \le n$）。


# 输出描述


对于每一组测试数据，新起一行输出一个整数，表示满足条件的有序对数量。



## 样例1 



**输入** 



```
2
5
1 2 1 2 1
2 1 3 1 2
2 1 5 4 3
3
7 7 7
1 2 7
3 3 3
```



**输出** 



```
5
6
```
