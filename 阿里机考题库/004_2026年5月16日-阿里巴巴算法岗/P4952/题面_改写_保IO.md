# 相邻编组方案

# 题目内容

排班系统要把 $m$ 名员工分成若干小组，每人恰好属于一组，每组人数只能是 $1$ 或 $2$。

员工能力值序列 $h_1,h_2,\dots,h_m$ 已按非降序给出。

两人一组时，只能选下标相邻的 $(i-1,i)$，且 $h_i-h_{i-1}\le d$；单人组无额外限制。

求合法编组方案数，对 $10^9+7$ 取模。

# 输入描述

共有多组独立用例，需逐组求解。

- 首行给出整型 $q$（$1 \le q \le 10^5$），表示用例个数。
- 每组用例两行：
  - 第一行两个整型 $m,d$（$1 \le m \le 2\times 10^5$；$0 \le d \le 10^9$）。
  - 第二行 $m$ 个整型 $h_1,h_2,\dots,h_m$（$|h_i| \le 10^{18}$），保证 $h_1 \le h_2 \le \cdots \le h_m$。
- 全体用例的 $m$ 之和不超过 $2\times 10^5$。

# 输出描述

输出 $q$ 行，每行一个整数，为该组方案数对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
3
4 1
2 3 3 5
2 0
1 2
5 3
1 4 4 7 10
```

**输出**

```
3
1
8
```

**说明**

- 第一组：可配对的相邻对为 $(1,2)$、$(2,3)$，共 $3$ 种编组方式。
- 第二组：差值均大于 $0$，只能全单人，答案为 $1$。
- 第三组：相邻均可配对，方案数为 $8$。
