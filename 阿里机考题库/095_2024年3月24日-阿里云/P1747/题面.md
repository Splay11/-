### 问题描述

塔子哥的村庄将要举办一年一度的搭配大赛。在这项赛事中，参赛者需要从两个长度相等的数组中，分别挑选出相同长度的子数组进行搭配。如果两个子数组在相同位置上的元素完全不同，则认为这是一次成功的搭配。塔子哥作为赛事的主办方，需要计算出所有可能的成功搭配的数量。

### 输入格式

第一行包含一个正整数 $n$，表示数组的长度。

第二行包含 $n$ 个由空格分开的整数 $a_1, a_2, ..., a_n$，代表第一个数组。

第三行包含 $n$ 个由空格分开的整数 $b_1, b_2, ..., b_n$，代表第二个数组。

### 输出格式

输出一个整数，代表所有可能的成功搭配的数量。

### 样例输入

```
3
1 2 3
3 2 1
```

### 样例输出

```
2
```

### 样例说明

在这个例子中，数组 `1 2 3` 和 `3 2 1` 可以形成两个成功的搭配：

- 第一个成功的搭配是第一个数组的第一个元素 `1` 与第二个数组的第一个元素 `3` 组成的子数组对。
- 第二个成功的搭配是第一个数组的第三个元素 `3` 与第二个数组的第三个元素 `1` 组成的子数组对。

其他子数组对至少在一个位置上有相同的元素，因此不构成成功的搭配。

### 评测数据与规模

对于 $100\%$ 的评测数据，$1 \leq n \leq 10^5$，$0 \leq a_i, b_i \leq 10^9$。
