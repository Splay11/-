# 仓储标签消消乐

# 题目内容

仓储分拣线上一排货箱从左到右排开，第 $i$ 个货箱的品类编号为 $c_i$。

反复执行：若存在相邻两个货箱品类相同，可将其配对清除，剩余货箱自动左移拼接；直到相邻品类均不同为止。每清除一对计 $1$ 次。

开始前最多**补入** $1$ 个任意正整数品类的新货箱（可不补；可插在队首、任意相邻间隙或队尾）。

求最多能清除多少次。

# 输入描述

本题含多组测试数据。

1. 第一行一个整数 $T$（$1 \le T \le 200000$），表示组数。
2. 每组数据：
   - 第一行一个整数 $n$（$1 \le n \le 200000$），表示货箱数。
   - 第二行 $n$ 个整数 $c_1,c_2,\dots,c_n$（$1 \le c_i \le n$），表示各货箱品类。
3. 保证所有组别的 $n$ 之和不超过 $400000$。

# 输出描述

每组数据输出一行一个整数，表示最多清除次数。

## 样例1

**输入**

```
2
4
3 5 5 3
5
2 2 4 6 6
```

**输出**

```
2
3
```

**说明**

- 第一组：先清 $(5,5)$ 得 $(3,3)$，再清 $(3,3)$ 得空，共 $2$ 次；补入也无法超过 $2$。
- 第二组：原序列可清 $2$ 次，化简后剩 $[4]$；在 $4$ 旁补入 $4$ 可再清 $1$ 次，共 $3$ 次。
