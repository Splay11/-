## 解题思路

将相邻测点读数差分：

$\Delta_i = v_{i+1} - v_i$

内部测点 $i$ 是拐点，当且仅当左右差分异号或至少一侧为零，即 $\Delta_{i-1} \cdot \Delta_i \le 0$。

因此，长度至少为 $3$ 的连续测点段合规，等价于其差分区间内任意相邻两项乘积 $\le 0$。

在差分数组上找所有满足上述条件的连续段。设某段长度为 $s$，则其中长度为 $q$（$q \ge 2$）的子段对应原序列长度为 $q+1$ 的合规段，贡献 $q-1$ 个拐点。

该段总贡献为：

$\sum_{q=2}^{s} (s-q+1)(q-1) = \dfrac{s(s-1)(s+1)}{6}$

线性扫描差分，维护当前最长合规段长度 $s$，遇到断裂处结算即可。段长为 $1$ 或 $2$ 的测点段贡献为 $0$。

## 复杂度分析

每组数据一次遍历。

时间复杂度：$O(m)$

空间复杂度：$O(1)$（除读数数组外）

所有组别的 $m$ 之和不超过 $2 \times 10^5$。

## 代码实现

### Python

```python
MOD = 10**9 + 7


def segment_contribution(length):
    return length * (length - 1) * (length + 1) // 6


def count_turn_points(m, readings):
    if m < 3:
        return 0

    total = 0
    run_len = 1

    for i in range(1, m - 1):
        delta_left = readings[i] - readings[i - 1]
        delta_right = readings[i + 1] - readings[i]
        if delta_left * delta_right <= 0:
            run_len += 1
        else:
            total = (total + segment_contribution(run_len)) % MOD
            run_len = 1

    total = (total + segment_contribution(run_len)) % MOD
    return total


def main():
    t = int(input())
    out_lines = []
    for _ in range(t):
        m = int(input())
        readings = list(map(int, input().split()))
        out_lines.append(str(count_turn_points(m, readings)))
    print("\n".join(out_lines))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.*;

public class Main {
    static final long MOD = 1000000007L;

    static long segmentContribution(long len) {
        return len * (len - 1) * (len + 1) / 6;
    }

    static long countTurnPoints(int m, long[] readings) {
        if (m < 3) {
            return 0;
        }

        long total = 0;
        long runLen = 1;

        for (int i = 1; i < m - 1; i++) {
            long deltaLeft = readings[i] - readings[i - 1];
            long deltaRight = readings[i + 1] - readings[i];
            if (deltaLeft * deltaRight <= 0) {
                runLen++;
            } else {
                total = (total + segmentContribution(runLen)) % MOD;
                runLen = 1;
            }
        }

        total = (total + segmentContribution(runLen)) % MOD;
        return total;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();
        StringBuilder sb = new StringBuilder();

        while (T-- > 0) {
            int m = sc.nextInt();
            long[] readings = new long[m];

            for (int i = 0; i < m; i++) {
                readings[i] = sc.nextLong();
            }

            sb.append(countTurnPoints(m, readings)).append('\n');
        }

        System.out.print(sb.toString());
        sc.close();
    }
}
```
