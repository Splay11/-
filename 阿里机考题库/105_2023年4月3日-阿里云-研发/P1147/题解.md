## 解题思路

把原图中所有红色格子看成点，按上下左右四个方向连边。题目要求对每个位置 $(i,j)$，把它染成白色后，求剩余红色连通块个数。

核心结论如下：

* 如果原来这个位置就是白色，那么染成白色后图不变，答案就是原图红色连通块总数。
* 如果原来这个位置是红色，那么相当于删除这个红点，删除后红色连通块数会发生变化。

这其实就是一个二维网格图上的“删点后连通块个数”问题。
由于 $n,m \le 40$，总点数不超过 $1600$，可以直接对每个位置单独做一次搜索。

具体做法：

1. 定义函数，统计当前图中红色连通块个数。
2. 枚举每个位置 $(i,j)$：

   * 若原来是 $W$，答案直接等于原图的红色连通块数。
   * 若原来是 $R$，暂时把它视作白色，然后用 $DFS$ 或 $BFS$ 重新统计全图红色连通块个数，记为该位置答案。
3. 输出答案矩阵。

由于数据范围很小，这样做可以稳定通过。

这里使用的算法是：

* 网格图遍历
* 深度优先搜索 $DFS$

实现上只需要在搜索时跳过被“删除”的那个位置即可，不必真的修改原矩阵，代码会更简洁。

## 复杂度分析

设总格子数为 $N = n \times m$。

* 每次统计连通块需要一次整图遍历，时间复杂度为 $O(N)$。
* 一共要对 $N$ 个位置求答案，因此总时间复杂度为 $O(N^2)$。
* 由于 $n,m \le 40$，所以 $N \le 1600$，总操作量约为 $1600^2$，完全可行。

空间复杂度：

* 每次搜索需要一个访问数组，空间复杂度为 $O(N)$。

## 代码实现

### Python

```python
# 计算删去(block_x, block_y)这个位置后，红色连通块个数
def count_components(grid, n, m, block_x, block_y):
    visited = [[False] * m for _ in range(n)]
    dirs = [(-1, 0), (1, 0), (0, -1), (0, 1)]

    # 深度优先搜索
    def dfs(x, y):
        visited[x][y] = True
        for dx, dy in dirs:
            nx, ny = x + dx, y + dy
            if 0 <= nx < n and 0 <= ny < m:
                # 跳过被删除的位置
                if nx == block_x and ny == block_y:
                    continue
                if not visited[nx][ny] and grid[nx][ny] == 'R':
                    dfs(nx, ny)

    cnt = 0
    for i in range(n):
        for j in range(m):
            # 跳过被删除的位置
            if i == block_x and j == block_y:
                continue
            if grid[i][j] == 'R' and not visited[i][j]:
                cnt += 1
                dfs(i, j)
    return cnt


def solve(grid, n, m):
    ans = [[0] * m for _ in range(n)]

    # 原图的红色连通块个数
    base = count_components(grid, n, m, -1, -1)

    for i in range(n):
        for j in range(m):
            if grid[i][j] == 'W':
                # 原来就是白色，答案不变
                ans[i][j] = base
            else:
                # 原来是红色，删除后重新统计
                ans[i][j] = count_components(grid, n, m, i, j)
    return ans


def main():
    n, m = map(int, input().split())
    grid = []
    for _ in range(n):
        row = input().split()
        grid.append(row)

    ans = solve(grid, n, m)

    for i in range(n):
        print(*ans[i])


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.*;

public class Main {
    static int n, m;
    static char[][] grid;
    static boolean[][] vis;
    static int[] dx = {-1, 1, 0, 0};
    static int[] dy = {0, 0, -1, 1};

    // 深度优先搜索，统计一个红色连通块
    static void dfs(int x, int y, int blockX, int blockY) {
        vis[x][y] = true;
        for (int k = 0; k < 4; k++) {
            int nx = x + dx[k];
            int ny = y + dy[k];
            if (nx < 0 || nx >= n || ny < 0 || ny >= m) {
                continue;
            }
            // 跳过被删除的位置
            if (nx == blockX && ny == blockY) {
                continue;
            }
            if (!vis[nx][ny] && grid[nx][ny] == 'R') {
                dfs(nx, ny, blockX, blockY);
            }
        }
    }

    // 计算删去(blockX, blockY)后，红色连通块个数
    static int countComponents(int blockX, int blockY) {
        vis = new boolean[n][m];
        int cnt = 0;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                // 跳过被删除的位置
                if (i == blockX && j == blockY) {
                    continue;
                }
                if (grid[i][j] == 'R' && !vis[i][j]) {
                    cnt++;
                    dfs(i, j, blockX, blockY);
                }
            }
        }
        return cnt;
    }

    // 求答案矩阵
    static int[][] solve() {
        int[][] ans = new int[n][m];

        // 原图红色连通块个数
        int base = countComponents(-1, -1);

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (grid[i][j] == 'W') {
                    // 原来就是白色，答案不变
                    ans[i][j] = base;
                } else {
                    // 原来是红色，删除后重新统计
                    ans[i][j] = countComponents(i, j);
                }
            }
        }
        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        n = sc.nextInt();
        m = sc.nextInt();

        grid = new char[n][m];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                grid[i][j] = sc.next().charAt(0);
            }
        }

        int[][] ans = solve();

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                System.out.print(ans[i][j]);
                if (j + 1 < m) {
                    System.out.print(" ");
                }
            }
            System.out.println();
        }
    }
}
```
