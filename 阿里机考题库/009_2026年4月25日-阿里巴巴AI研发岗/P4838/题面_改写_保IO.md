# 指标段累计次序

# 题目内容

运维侧有一条非负整型负载序列 $load_1,\dots,load_{len}$。

对区间 $[L,R]$ 定义段累计分：

$$
score(L,R)=\sum_{i=L}^{R}\left(\sum_{t=L}^{i} load_t\right)
$$

即区间内每个位置的前缀和之和。

将全部 $\dfrac{len(len+1)}{2}$ 个区间的 $score$ 值从小到大排序（相同值按出现次数重复计入），求第 $rank$ 小的数值。

# 输入描述

每个测试文件包含多组测试数据。

1. 第一行一个整数 $tc$（$1 \le tc \le 10^5$），表示测试组数。
2. 每组数据两行：
   - 第一行两个整数 $len,\ rank$（$1 \le len \le 2 \times 10^5$，$1 \le rank \le \dfrac{len(len+1)}{2}$）；
   - 第二行 $len$ 个整数 $load_1,\dots,load_{len}$（$0 \le load_i \le 10^6$）。
3. 所有测试中 $len$ 之和不超过 $5 \times 10^5$。

# 输出描述

每组测试数据输出一行一个整数，为第 $rank$ 小的 $score(L,R)$。

## 样例1

**输入**

```
2
3 3
3 1 2
3 4
2 0 1
```

**输出**

```
3
2
```

**说明**

- 组 1：六个区间得分排序为 $1,2,3,4,7,13$，第 $3$ 小为 $3$。
- 组 2：六个区间得分排序为 $0,1,1,2,2,3$，第 $4$ 小为 $2$。
