# 指定逆序排列

# 题目内容

调度模块要给出长度为 $m$ 的排列 $p$（$1\sim m$ 各出现一次），使其逆序对个数恰好为 $t$。

所谓逆序对，是指一对下标 $(i,j)$ 满足 $i<j$ 且 $p_i>p_j$；统计的是全部这样的下标对的数量。

# 输入描述

共有多组独立用例，需逐组求解。

- 首行给出整型 $q$（$1 \le q \le 200000$），表示用例个数。
- 随后 $q$ 行，每行两个整型 $m,t$（$1 \le m \le 200000$；$0 \le t \le m(m-1)/2$）。
- 全体用例的 $m$ 之和不超过 $200000$。

# 输出描述

每组输出一行 $m$ 个整数，为任意一个合法排列。

## 样例1

**输入**

```
2
4 0
4 3
```

**输出**

```
1 2 3 4
4 1 2 3
```

**说明**

- 第一组：递增排列，逆序对为 $0$。
- 第二组：$4$ 与后面三个数各成一对，共 $3$ 个逆序对。
