# 传送与右移最短路

# 题目内容

链路侧有 $1\sim m$ 共 $m$ 个站点。在站点 $i$ 可做两种移动：

- 花费 $0$，经传送到达 $g_i$；
- 若 $i<m$，花费 $1$，向右走到 $i+1$。

从 $1$ 出发到达 $m$，求最小总花费。

# 输入描述

共有多组独立用例，需逐组求解。

- 首行给出整型 $q$（$1 \le q \le 100000$），表示用例个数。
- 每组格式如下：
  1. 第一行一个整型 $m$（$1 \le m \le 500000$）；
  2. 第二行 $m$ 个整型 $g_1,\dots,g_m$（$1 \le g_i \le m$）。
- 全体用例的 $m$ 之和不超过 $500000$。

# 输出描述

每组一行一个整数：最小总花费。

## 样例1

**输入**

```
2
3
2 3 3
3
1 1 3
```

**输出**

```
0
2
```

**说明**

- 第一组：一路传送 $1\to 2\to 3$，花费 $0$。
- 第二组：传送均回 $1$，需向右走两次，花费 $2$。
