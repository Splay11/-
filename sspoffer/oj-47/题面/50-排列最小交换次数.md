# 排列恢复升序的最小交换次数

## 题目描述

给定一个 $1$ 到 $n$ 的排列（即 $1, 2, \ldots, n$ 的一个打乱），求将其恢复为升序排列 $[1, 2, \ldots, n]$ 所需的最小交换次数。每次交换可以选择任意两个位置。

## 输入描述

第一行包含一个整数 $n$（$1 \le n \le 10^5$），表示排列长度。

第二行包含 $n$ 个整数，为 $1$ 到 $n$ 的一个排列。

## 输出描述

输出一个整数，表示最小交换次数。

## 样例 1

**输入**

```text
3
2 3 1
```

**输出**

```text
2
```

## 样例 2

**输入**

```text
4
1 2 3 4
```

**输出**

```text
0
```
