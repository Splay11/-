# 二分类交叉熵

## 题目描述

实现二分类任务的 Binary Cross Entropy Loss。

给定真实标签 $y \in \{0,1\}^N$ 和模型预测概率 $p \in (0,1)^N$，计算：

$$
\mathrm{BCE} = -\frac{1}{N}\sum_{i=1}^{N}\left(y_i \ln p_i + (1-y_i)\ln(1-p_i)\right)
$$

为避免数值溢出，需要对 $p$ 裁剪到 $[\varepsilon, 1-\varepsilon]$，其中 $\varepsilon = 10^{-7}$。

## 输入描述

第一行包含一个整数 $N$（$1 \le N \le 10^{4}$），表示样本数。

第二行包含 $N$ 个整数 $y_1, y_2, \ldots, y_N$（每个 $y_i \in \{0,1\}$），表示真实标签。

第三行包含 $N$ 个浮点数 $p_1, p_2, \ldots, p_N$（每个 $p_i \in [0,1]$），表示预测概率。

## 输出描述

输出一个浮点数，表示 BCE 损失，保留 $2$ 位小数。

## 样例 1

**输入**

```text
4
1 0 1 0
0.9 0.1 0.8 0.2
```

**输出**

```text
0.16
```

**样例解释**

$\mathrm{BCE} = -\frac{1}{4}(\ln 0.9 + \ln 0.9 + \ln 0.8 + \ln 0.8) \approx 0.164252$。

四个样本预测都接近真实标签，损失较小。

## 样例 2

**输入**

```text
2
1 0
0.0 1.0
```

**输出**

```text
16.12
```

**样例解释**

第一个样本 $y = 1, p = 0$ 经裁剪变为 $10^{-7}$，$-\ln(10^{-7}) \approx 16.118$。

第二个样本 $y = 0, p = 1$ 经裁剪变为 $1-10^{-7}$，$-\ln(10^{-7}) \approx 16.118$。

两个完全错误的样本，平均损失约 $16.118$。

## 提示

1. 概率裁剪必做：直接 $\ln(0)$ 会产生 $-\infty$，必须先 clip 到 $[\varepsilon, 1-\varepsilon]$。
2. 与多分类 CE 的区别：BCE 只针对单标签二分类（或独立多标签），多分类用 Softmax + Cross Entropy。
3. PyTorch 等价：`F.binary_cross_entropy(p, y, reduction='mean')`，其内部裁剪策略略有不同。
4. 训练时常用 logits 版：`F.binary_cross_entropy_with_logits` 数值更稳定（融合 sigmoid + log）。
