# RMS Normalization（均方根归一化）

## 题目描述

实现 RMS Normalization（均方根归一化）。

给定输入张量 $X$（$N \times d$）、可学习参数 $\gamma$（$d$）和数值稳定项 $\varepsilon$，计算：

$$
y = \gamma \cdot \frac{x}{\sqrt{\dfrac{1}{d}\sum_{j=1}^{d} x_j^2 + \varepsilon}}
$$

## 输入描述

第一行包含两个整数 $N, d$（$1 \le N \le 100$，$1 \le d \le 64$），表示样本数和特征维度。

接下来 $N$ 行，每行 $d$ 个浮点数，表示输入张量 $X$。

接下来一行，$d$ 个浮点数，表示缩放参数 $\gamma$。

最后一行，$1$ 个浮点数，表示 $\varepsilon$。

## 输出描述

输出 $N$ 行，每行 $d$ 个浮点数，表示归一化结果，保留 $2$ 位小数。

## 样例 1

**输入**

```text
2 3
1.0 2.0 3.0
3.0 4.0 0.0
1.0 1.0 1.0
1e-5
```

**输出**

```text
0.46 0.93 1.39
1.04 1.39 0.00
```

**样例解释**

样本 1（$x = [1, 2, 3]$）：$\mathrm{RMS} = \sqrt{(1+4+9)/3} = \sqrt{14/3} \approx 2.160$，输出 $y = 1.0 \cdot [1, 2, 3] / 2.160 \approx [0.463, 0.926, 1.389]$。

样本 2（$x = [3, 4, 0]$）：$\mathrm{RMS} = \sqrt{(9+16+0)/3} = \sqrt{25/3} \approx 2.887$，输出 $y = 1.0 \cdot [3, 4, 0] / 2.887 \approx [1.039, 1.386, 0]$。

## 样例 2

**输入**

```text
1 4
2.0 0.0 0.0 0.0
0.5 0.5 0.5 0.5
1e-6
```

**输出**

```text
1.00 0.00 0.00 0.00
```

**样例解释**

$\mathrm{RMS} = \sqrt{4/4} = 1$，$y = 0.5 \cdot [2, 0, 0, 0] / 1 = [1, 0, 0, 0]$。

## 提示

1. 与 LayerNorm 区别：RMSNorm 无中心化（不减均值），无 $\beta$ 参数，计算更高效。
2. LLaMA 标配：LLaMA、Mistral 等现代 LLM 均使用 RMSNorm 替代 LayerNorm。
3. 公式变体：部分实现 RMS 不除以 $d$，本题采用标准定义（除以 $d$）。
