# 对称二叉树

## 题目描述

给你一个二叉树的根节点 $root$，检查它是否轴对称。

## 输入描述

一行包含二叉树的序列化数组（节点数目在 $[0, 100]$ 范围内，节点值 $-100 \leq Node.val \leq 100$），节点值之间用空格隔开，空节点用 $null$ 表示。

## 输出描述

输出包含一行，若二叉树是轴对称的，输出 $true$；否则，输出 $false$。

## 样例 1

**输入**

```text
1 2 2 3 4 4 3
```

**输出**

```text
true
```

**样例解释**

该二叉树左右子树镜像对称。

## 样例 2

**输入**

```text
1 2 2 null 3 null 3
```

**输出**

```text
false
```

**样例解释**

该二叉树左右子树结构不对称。
