# 删除排序链表中的重复元素 II

## 题目描述

给定一个已排序的链表的头节点 $head$，删除所有含有重复数字的节点，只保留原始链表中没有重复出现的数字。返回已排序的结果链表。

## 输入描述

第一行输入一个整数 $n(0 \le n \le 300)$，表示链表长度

第二行输入 $n$ 个整数（已排序），表示链表节点值，$-100 \le val \le 100$

若 $n = 0$，无第二行输入

## 输出描述

输出去重后的链表节点值，空格分隔。若链表为空，输出空行。

## 样例 1

**输入**

```text
7
1 2 3 3 4 4 5
```

**输出**

```text
1 2 5
```

**样例解释**

$3$ 和 $4$ 出现了多次，被完全删除。

## 样例 2

**输入**

```text
5
1 1 1 2 3
```

**输出**

```text
2 3
```
