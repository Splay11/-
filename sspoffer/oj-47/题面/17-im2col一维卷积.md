# im2col 一维卷积

## 题目描述

使用 im2col（image to column）方法实现一维卷积。

im2col 的核心思想：将卷积运算转化为矩阵乘法——把输入信号中每个滑窗片段展开为矩阵的一行，再与卷积核做矩阵乘法，避免嵌套循环。

给定一维输入信号 $x$（长度 $L$），卷积核 $w$（长度 $K$），步长 $S$ 和填充 $P$：

1. 对 $x$ 两端各补 $P$ 个零，得到 $x'$（长度 $L' = L + 2P$）。
2. 构建 im2col 矩阵 $C$（大小 $O \times K$），其中 $O = \lfloor (L' - K) / S \rfloor + 1$，第 $i$ 行是 $x'[iS : iS + K]$。
3. 卷积结果 $y = C \cdot w$（矩阵乘向量，输出长度 $O$）。

输出 im2col 矩阵和卷积结果。

## 输入描述

第一行包含四个整数 $L, K, S, P$（$4 \le L \le 64$，$2 \le K \le 9$，$1 \le S \le 3$，$0 \le P \le K/2$）。

第二行包含 $L$ 个浮点数，表示输入信号 $x$。

第三行包含 $K$ 个浮点数，表示卷积核 $w$。

所有浮点数保留 $4$ 位小数。保证输出长度 $O \ge 1$。

## 输出描述

第一行两个整数 $O$ 和 $K$，表示 im2col 矩阵的行数和列数。

接下来 $O$ 行，每行 $K$ 个浮点数，表示 im2col 矩阵的每一行，保留 $4$ 位小数。

最后一行 $O$ 个浮点数，表示卷积结果 $y$，保留 $4$ 位小数。

## 样例 1

**输入**

```text
5 3 1 0
1.0000 2.0000 3.0000 4.0000 5.0000
0.5000 -0.5000 1.0000
```

**输出**

```text
3 3
1.0000 2.0000 3.0000
2.0000 3.0000 4.0000
3.0000 4.0000 5.0000
2.5000 3.5000 4.5000
```

**样例解释**

$L = 5, K = 3, S = 1, P = 0$，无填充，步长为 $1$，滑窗产生 $3$ 个片段。

第 $1$ 行取 $x'[0:3] = [1, 2, 3]$，与 $w = [0.5, -0.5, 1.0]$ 点积得 $1 \times 0.5 + 2 \times (-0.5) + 3 \times 1.0 = 2.5$。

## 样例 2

**输入**

```text
6 3 2 1
1.0000 3.0000 -1.0000 2.0000 4.0000 -2.0000
-1.0000 0.5000 1.0000
```

**输出**

```text
3 3
0.0000 1.0000 3.0000
3.0000 -1.0000 2.0000
2.0000 4.0000 -2.0000
3.5000 -1.5000 -2.0000
```

**样例解释**

$P = 1$，左右各补一个零，得到 $x' = [0, 1, 3, -1, 2, 4, -2, 0]$。$S = 2$，从位置 $0, 2, 4$ 取窗口。

第 $1$ 行取 $x'[0:3] = [0, 1, 3]$，点积得 $0 \times (-1) + 1 \times 0.5 + 3 \times 1.0 = 3.5$。

im2col 的后两行按这个取窗规则整理为 $x'[2:5]$、$x'[4:7]$。

## 提示

1. im2col 的意义：把卷积变成矩阵乘法后，可以直接调用高度优化的 BLAS 库（如 cuBLAS），比手写嵌套循环快很多。
2. 二维卷积推广：二维 im2col 同理，将 $K_h \times K_w$ 的窗口展成一行，原理完全相同。
3. 填充的作用：$P > 0$ 保留边缘信息，$P = K // 2$ 且 $S = 1$ 时输出长度等于输入长度（same 卷积）。
