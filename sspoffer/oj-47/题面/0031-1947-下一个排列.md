# 下一个排列

## 题目描述

整数数组的一个排列是其所有元素的线性顺序排列。

给定一个整数数组 $nums$，请计算其下一个排列：

下一个排列是指字典序更大的排列。

如果不存在下一个更大的排列，则将 $nums$ 重新排列为字典序最小的排列（即升序排列）。

必须原地修改，且只能使用常数级额外空间。

## 输入描述

第一行输入一个整数 $n(1\le n\le 100)$，表示数组的长度。

第二行输入 $n$ 个整数 $nums_i(0\le nums_i\le 100)$，表示数组元素，以空格分隔。

## 输出描述

输出一行，表示数组 $nums$ 的下一个排列，元素之间用空格分隔。

## 样例 1

**输入**

```text
3
1 2 3
```

**输出**

```text
1 3 2
```

**样例解释**

$[1,2,3]$ 的下一个排列是 $[1,3,2]$。

## 样例 2

**输入**

```text
3
3 2 1
```

**输出**

```text
1 2 3
```

**样例解释**

$[3,2,1]$ 是最大排列，下一个排列回到最小排列 $[1,2,3]$。

## 样例 3

**输入**

```text
3
1 1 5
```

**输出**

```text
1 5 1
```

**样例解释**

$[1,1,5]$ 的下一个排列是 $[1,5,1]$。
