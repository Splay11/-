# 长度最小的子数组

## 题目描述

给定一个含有 $n$ 个正整数的数组和一个正整数 $target$。找出该数组中满足其总和大于等于 $target$ 的长度最小的子数组 $[nums_l, nums_{l+1}, \ldots, nums_r]$，并返回其长度。如果不存在符合条件的子数组，返回 $0$。

## 输入描述

第一行输入两个整数 $n,target(1 \le n \le 10^5, 1 \le target \le 10^9)$，表示数组长度和目标值。

第二行输入 $n$ 个正整数 $nums[i](1 \le nums[i] \le 10^4)$。

## 输出描述

输出一个整数，表示满足条件的最短子数组长度，不存在则输出 $0$。

## 样例 1

**输入**

```text
6 7
2 3 1 2 4 3
```

**输出**

```text
2
```

**样例解释**

子数组 $[4,3]$ 是满足总和 $\ge 7$ 的最短子数组，长度为 $2$。

## 样例 2

**输入**

```text
3 11
1 1 1
```

**输出**

```text
0
```
