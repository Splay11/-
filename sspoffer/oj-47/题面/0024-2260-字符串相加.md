# 字符串相加

## 题目描述

给定两个字符串形式的非负整数 $num1$ 和 $num2$，计算它们的和并同样以字符串形式返回。不能使用任何内建的大整数库。

## 输入描述

第一行输入字符串 $num1(1 \le |num1| \le 10^4)$，仅包含数字，不含前导零（除了数字 $0$ 本身）

第二行输入字符串 $num2(1 \le |num2| \le 10^4)$，同上

## 输出描述

输出两数之和的字符串表示。

## 样例 1

**输入**

```text
11
123
```

**输出**

```text
134
```

## 样例 2

**输入**

```text
456
77
```

**输出**

```text
533
```
