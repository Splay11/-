# 三数之和

## 题目描述

给你一个整数数组 $nums$，判断是否存在三元组 $[nums[i],nums[j],nums[k]]$ 满足 $i \neq j$、$i \neq k$、$j \neq k$，同时还满足 $nums[i]+nums[j]+nums[k]=0$。请你输出所有和为 $0$ 且不重复的三元组。

注意：答案中不可以包含重复的三元组。

## 输入描述

第一行输入一个整数 $n(3\le n\le 3000)$，表示数组 $nums$ 的长度。

第二行输入 $n$ 个整数 $nums_i(-10^5\le nums_i\le 10^5)$，以空格分隔。

## 输出描述

输出所有满足条件的三元组，每行一个三元组，三元组内数字以空格分隔。输出顺序不限。

## 样例 1

**输入**

```text
6
-1 0 1 2 -1 -4
```

**输出**

```text
-1 -1 2
-1 0 1
```

**样例解释**

$nums[0]+nums[1]+nums[2]=(-1)+0+1=0$

$nums[0]+nums[3]+nums[4]=(-1)+2+(-1)=0$

不同的三元组是 $[-1,0,1]$ 和 $[-1,-1,2]$。

注意：输出的顺序和三元组内的顺序不重要。

## 样例 2

**输入**

```text
3
0 1 1
```

**输出**

```text

```

**样例解释**

唯一可能的三元组 $[0,1,1]$ 和不为 $0$，因此输出空。

## 样例 3

**输入**

```text
3
0 0 0
```

**输出**

```text
0 0 0
```

**样例解释**

唯一可能的三元组 $[0,0,0]$ 和为 $0$。
