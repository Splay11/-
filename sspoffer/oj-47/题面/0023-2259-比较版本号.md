# 比较版本号

## 题目描述

给你两个版本号字符串 $version1$ 和 $version2$，请你比较它们。版本号由一个或多个修订号组成，各修订号由 $.$ 连接。每个修订号由多位数字组成，可能包含前导零。比较修订号时，仅比较忽略前导零后的整数值。如果版本号没有指定某个下标处的修订号，则该修订号视为 $0$。

返回规则：$version1 > version2$ 返回 $1$，$version1 < version2$ 返回 $-1$，相等返回 $0$。

## 输入描述

第一行输入版本号字符串 $version1(1 \le |version1| \le 500)$

第二行输入版本号字符串 $version2(1 \le |version2| \le 500)$

版本号仅包含数字和 '.'

## 输出描述

输出 $1$、$-1$ 或 $0$。

## 样例 1

**输入**

```text
1.2
1.10
```

**输出**

```text
-1
```

**样例解释**

第二个修订号 $2 < 10$，所以 $version1 < version2$。

## 样例 2

**输入**

```text
1.01
1.001
```

**输出**

```text
0
```

**样例解释**

忽略前导零，$01 = 001 = 1$，两个版本号相等。
