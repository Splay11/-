# 二叉树的中序遍历

## 题目描述

给定一个二叉树的根节点 $root$，输出它的中序遍历。

## 输入描述

输入一行包含二叉树的序列化数组（树中节点数目在范围 $[0, 100]$ 内，节点值 $-100\le Node.val\le 100$），节点值之间用空格隔开，空节点用 $null$ 表示。

## 输出描述

输出一行，从 $root$ 开始中序遍历，数字之间以空格分隔。

## 样例 1

**输入**

```text
1 null 2 3
```

**输出**

```text
1 3 2
```

**样例解释**

根据输入构建的二叉树如下：

```text
    1
   / \
 null  2
       /
      3
```

中序遍历（左-根-右）顺序为：1 -> 3 -> 2。

## 样例 2

**输入**

```text
1
```

**输出**

```text
1
```

**样例解释**

仅有一个根节点，因此中序遍历结果就是该节点本身。
