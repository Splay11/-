# PPO 裁剪代理损失

## 题目描述

实现 PPO（Proximal Policy Optimization）的裁剪代理损失（clipped surrogate objective）。

PPO 用重要性采样复用旧策略采集的数据，但重要性比一旦偏离 $1$ 太远，估计的方差就会爆炸。PPO 的做法是把重要性比裁剪到 $[1-\epsilon, 1+\epsilon]$，再对裁剪前后取较保守的那一个，从而限制单次更新的步长。

给定 $n$ 条样本，每条样本有优势估计 $A_i$、当前策略的 log 概率 $\pi_i$、采样时旧策略的 log 概率 $\pi_i^{old}$。

重要性采样比：

$$
\rho_i = \exp(\pi_i - \pi_i^{old})
$$

裁剪代理损失：

$$
\mathcal{L}_{PPO} = -\frac{1}{n}\sum_{i=1}^{n}\min\big(\rho_i A_i,\ \mathrm{clip}(\rho_i, 1-\epsilon, 1+\epsilon)\,A_i\big)
$$

注意优势 $A_i$ 由外部的 critic 网络给出，本题直接作为输入，不需要自行估计。

## 输入描述

第一行输入一个整数 $n$（$1 \le n \le 1000$）和一个浮点数 $\epsilon$（$0.01 \le \epsilon \le 0.5$），分别表示样本数和裁剪范围。

接下来 $n$ 行，每行输入 $3$ 个浮点数 $A_i$、$\pi_i$、$\pi_i^{old}$，其中 $-10 \le A_i \le 10$，$-20 \le \pi_i, \pi_i^{old} \le 0$。

## 输出描述

输出 PPO 损失值，保留 $4$ 位小数。

## 样例 1

**输入**

```text
3 0.2
1.0000 -1.0000 -1.2000
-0.5000 -2.0000 -1.5000
2.0000 -0.8000 -0.8000
```

**输出**

```text
-0.9333
```

**样例解释**

重要性比 $\rho = [1.2214, 0.6065, 1.0000]$，裁剪区间为 $[0.8, 1.2]$。

第 $1$ 条：$\rho_1 = 1.2214$ 超出上界被裁到 $1.2$，$A_1 > 0$，取较小者得 $1.2$。

第 $2$ 条：$\rho_2 = 0.6065$ 低于下界被裁到 $0.8$，$A_2 < 0$，裁剪后为 $-0.4$，比未裁剪的 $-0.3033$ 更小，取 $-0.4$。

第 $3$ 条：$\rho_3 = 1$ 在区间内，裁剪不生效，得 $2$。

三项均值为 $(1.2 - 0.4 + 2)/3 = 0.9333$，取负号得损失 $-0.9333$。
