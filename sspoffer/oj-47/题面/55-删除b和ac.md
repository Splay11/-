# 删除字符 b 和连续的 ac

## 题目描述

给定一个只含小写字母的字符串，执行以下两步操作：

1. 移除字符串中所有字符 `b`。
2. 移除字符串中所有连续的 `"ac"`（`ac` 可能嵌套：移除一对 `ac` 后，新相邻的字符可能又形成 `ac`，需继续移除）。

输出最终处理后的字符串。

## 输入描述

一行字符串 $s$（$1 \le |s| \le 10^5$），只含小写字母。

## 输出描述

输出处理后的字符串。若结果为空，输出空行。

## 样例 1

**输入**

```text
js
```

**输出**

```text
js
```

## 样例 2

**输入**

```text
cpgaaiczahcrtbxambcbc
```

**输出**

```text
cpgaaiczahcrtxamcc
```
