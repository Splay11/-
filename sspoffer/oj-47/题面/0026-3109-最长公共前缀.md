# 最长公共前缀

## 题目描述

编写一个函数来查找字符串数组中的最长公共前缀。

如果不存在公共前缀，返回空字符串。

## 输入描述

第一行输入一个整数 $n(1 \le n \le 200)$，表示字符串的个数。

第二行输入 $n$ 个空格分隔的字符串，每个字符串长度 $len(1 \le len \le 200)$，仅由小写英文字母组成。

## 输出描述

输出最长公共前缀。若不存在公共前缀，输出空行。

## 样例 1

**输入**

```text
3
flower flow flight
```

**输出**

```text
fl
```

## 样例 2

**输入**

```text
3
dog racecar car
```

**输出**

```text
```

**样例解释**

输入不存在公共前缀。
