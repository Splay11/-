# 无重复字符的最长子串

## 题目描述

给定一个字符串 $s$，请你找出其中不含有重复字符的最长子串的长度。

## 输入描述

输入一行字符串 $s(0\le |s|\le 5\times 10^4)$，由英文字母、数字、符号和空格组成。

## 输出描述

输出一个整数，表示不含重复字符的最长子串长度。

## 样例 1

**输入**

```text
abcabcbb
```

**输出**

```text
3
```

**样例解释**

无重复字符的最长子串是 $abc$，长度为 $3$。

## 样例 2

**输入**

```text
bbbb
```

**输出**

```text
1
```

**样例解释**

无重复字符的最长子串是 $b$，长度为 $1$。

## 样例 3

**输入**

```text
pwwkew
```

**输出**

```text
3
```

**样例解释**

无重复字符的最长子串是 $wke$，长度为 $3$。注意答案必须是子串的长度，$pwke$ 是一个子序列，不是子串。
