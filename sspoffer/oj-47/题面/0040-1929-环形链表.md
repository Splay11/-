# 环形链表

## 题目描述

给定一个单链表，判断链表是否存在环。如果存在环，返回 $true$；否则返回 $false$。

## 输入描述

第一行输入一个整数 $n(0\le n\le 10^4)$，表示链表的节点数。

接下来 $n$ 行，每行三个整数 $addr$、$val$、$next\_addr$：

- $addr$：当前节点地址
- $val$：节点值 $(-10^5\le val\le 10^5)$
- $next\_addr$：下一个节点地址，$-1$ 表示链表结束

第一行的 $addr$ 为链表头。

## 输出描述

输出 $true$ 或 $false$，表示链表是否存在环。

## 样例 1

**输入**

```text
4
100 3 200
200 2 300
300 0 400
400 -4 200
```

**输出**

```text
true
```

**样例解释**
![](https://sspnote.oss-cn-hangzhou.aliyuncs.com/static/a5d216e0-b837-42b1-a6c7-b532dc1948f8/circularlinkedlist.png)

尾节点 $400$ 连接到节点 $200$ 形成环。

**输入**

```text

```

**输出**
