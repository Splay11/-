# 乘法和开方后的最小值

## 题目描述

给定一个正整数 $n$，你可以对 $n$ 执行以下两种操作任意多次：

1. 乘法操作：将 $n$ 乘以任意一个正整数。
2. 开方操作：若 $n$ 是完全平方数，将 $n$ 变为 $\sqrt{n}$。

请你求出经过任意次操作后 $n$ 能变成的最小值，以及达到该最小值所需的最少操作次数。

## 输入描述

输入一个正整数 $n$（$1 \le n \le 10^{12}$）。

## 输出描述

输出两个整数，用空格隔开。第一个整数为 $n$ 能变成的最小值，第二个整数为达到该最小值的最少操作次数。

## 样例 1

**输入**

```text
256
```

**输出**

```text
2 3
```

## 样例 2

**输入**

```text
72
```

**输出**

```text
6 3
```

## 样例 3

**输入**

```text
1
```

**输出**

```text
1 0
```
