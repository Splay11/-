# 二叉树的最近公共祖先

## 题目描述

给定一个二叉树，找到该树中两个指定节点的最近公共祖先。

定义：对于有根树 $T$ 的两个节点 $p$、$q$，最近公共祖先表示为一个节点 $x$，满足 $x$ 是 $p$、$q$ 的祖先且 $x$ 的深度尽可能大（一个节点也可以是它自己的祖先）。

## 输入描述

第一行包含二叉树的序列化数组（节点数目 $n$ 满足 $2 \le n \le 10^5$，节点值 $a_i$ 满足 $-10^9 \le a_i \le 10^9$ 且互不相同），节点值之间用空格隔开，空节点用 $null$ 表示。

第二行包含两个整数 $p$ 和 $q$（$p \neq q$，且 $p$、$q$ 均存在于树中），表示要查询的节点值。

## 输出描述

输出最近公共祖先节点的值。

## 样例 1

**输入**

```text
3 5 1 6 2 0 8 null null 7 4
5 1
```

**输出**

```text
3
```

**样例解释**

节点 $5$ 和节点 $1$ 的最近公共祖先是节点 $3$。

## 样例 2

**输入**

```text
3 5 1 6 2 0 8 null null 7 4
5 4
```

**输出**

```text
5
```

**样例解释**

节点 $5$ 和节点 $4$ 的最近公共祖先是节点 $5$（一个节点也可以是它自己的祖先）。

## 样例 3

**输入**

```text
1 2
1 2
```

**输出**

```text
1
```

**样例解释**

节点 $1$ 和节点 $2$ 的最近公共祖先是节点 $1$。
