# 调用示例

## 例 1：默认三级套题（最常用）

用户先建好三个目录（可空），再调用：

```text
/kexin-trusted-exam-set 在 @Problems/P8101 @Problems/P8102 @Problems/P8103 生成一套可信题目（入门/工作/专业各一）
```

期望映射：

| 目录 | 级别 | 难度 | 形态 / 选核 |
|------|------|------|-------------|
| P8101 | 入门级 | 2～3 | 单函数；周赛/小白月赛 A～B，**只取核心题意**后自有业务包装 |
| P8102 | 工作级 | 4～6 | 单函数；周赛 C～D / 月赛中档，**只取核心题意**后自有业务包装 |
| P8103 | 专业级 | 7～8 | **多函数业务项目**（不对号入座周赛/月赛） |

Agent 先检索近期牛客周赛/月赛定第1/2题核（禁止照搬原题），再按 `reference-scenes.md` **随机抽生活场景并改写**（第1/2题不要默认机器人/链路）；蓝图含第3题类名与方法表；**题面题解不写牛客出处**。

---

## 例 2：只要专业级三题

```text
/kexin-trusted-exam-set 专业级套题：@可信题库/P8104 @可信题库/P8105 @可信题库/P8106
```

第3题自动为多函数系统设计。前两题算法核按周赛 **D～E** / 月赛偏难档选取核心题意，用自有业务背景包装（交付物不写出处，禁止照搬原题）。

---

## 例 3：指定业务域与禁区

```text
/kexin-trusted-exam-set
目录：Problems/P8110 Problems/P8111 Problems/P8112
默认三级；业务偏零信任/安全；不要出纯网格 DFS；工作级希望带二分或堆
```
