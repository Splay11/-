# 套题业务场景池

出题前**必读**。题面背景不要默认写成巡检机器人、光纤链路、分片副本、心跳探针这类工业壳；日常生活与工程场景**同一池子抽样**。

---

## 抽样规则（写死）

1. 打开本文件。对套题里**每一题**，先从下面清单里 **随机抽 1 条**（三题尽量不同「分类」：球类 / 饮食 / 校园 / 出行生活 / 家务收纳 / 文娱……不要三题都是「运维」）。
2. **抽到后必须改写**：换物件名、换角色称谓、换一两句具体情节；禁止整句粘贴词条当题面。规则与数据仍由算法核决定，场景只负责外壳。
3. **第 1、2 题（单函数）**：默认优先抽 **日常生活**；用户点名「云 / 安全 / 运维」时再改抽工程条。
4. **第 3 题（多函数项目）**：可以抽生活向小系统（借书、订场、食堂窗口、快递柜），也可以抽工程组件（缓存、租约、资源池）。不要为了「像可信」三题全写成网关/链路。
5. 同一套已用过的分类，下一题避开；同一 Agent 连续多套时轮换，避免总是「机器人 + 链路 + 缓存」。
6. 仍禁止真实公司名、品牌名；避免「小苯 / 小红」人名主角，用「两位同学 / 值班师傅 / 教练」这类角色即可。
7. 场景句删掉后，形式化规则仍须完整。`0`/`1` 等 I/O 字符集不得因换场景而改掉。

蓝图里写一句：`场景：#编号 分类 → 改写要点`（内部即可）。
