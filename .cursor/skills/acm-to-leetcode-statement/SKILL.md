# ACM 题面 → 华为 OD LeetCode 样例风格

## 权威参考（题面结构）

**轻量转换以用户指定的华为 OD 已改题为准**，典型结构如下（交卷学号题为例）：

```markdown
# 题目内容
（原题意，尽量不动）

# 输入描述
- 条目说明各输入含义……
- 数据范围可写在条目后或段末

# 输出描述
- 条目说明输出含义……
- 必要时说明 `[...]` 输出形态

## 样例1

```
单行 stdin
```

```
单行 stdout
```

（可选说明）

## 样例2
……
```

**对照文件**：`2025年华为od/100分/P2977/题面.md`（转换完成后）。

**stdin 编码规则**仍与 `Problems/` 测例一致（逗号分隔、数组方括号无空格等），见下表；但 **不要在 `# 输入描述` 里写 `**输入**（stdin 一行）` 那种 Problems 专用段落**，也不要单独加 `## 输入输出格式` 节。

---

## 目标

**默认做三件事**：

1. **`# 题目内容`**：原文尽量不动。
2. **`# 输入描述` / `# 输出描述`**：用 **`-` 条目** 说明各字段/结果含义，语义覆盖原 ACM 输入输出；段末可写数据范围；表述须与样例单行编码 **字段一致**（先定样例格式，再写描述）。
3. **样例**：ACM 多行 → **单行** ` ``` ` 代码块（不用 `text` 语言标记）；输出 `[a,b]` 或 `[]` 等同款。

**默认不做**：函数接口、三语言签名、`## 输入输出格式（stdin / stdout）`、重写题意标题。

**排版**：章节之间最多保留**一个**空行；样例内 **输入/输出** 与代码块之间**不要**空行；避免连续多个空行。

---

## 样例格式规范

### 章节与编号

- 直接用 `## 样例1`、`## 样例2`（**「样例」与数字之间无空格**，与参考题一致）。
- **不要**使用 `## 样例` + `### 样例 1` 两级标题。

### 每个样例块

```markdown
## 样例1

**输入**
```
10,[1,5,3,2,6,7,8,9,10]
```
**输出**
```
[4]
```
**说明**

班级内共有 10 人……
```

- **输入** / **输出** / **说明** 加粗标签；代码块为无语言标记的 ` ``` `，块内**仅一行**。
- **输入**、**输出** 与紧随其后的代码块之间**不要空行**；**说明** 前保留一个空行。
- 原题有几组样例就改几组；**输出数值与原 ACM 完全一致**。

### stdin 单行编码（与 Problems 测例一致）

| 约定 | 说明 |
|------|------|
| 分隔 | 字段间 **英文逗号** |
| 整型数组 | `[a,b,c]`，元素逗号分隔、无空格 |
| 字符串 | **一律双引号包裹**，如 `"ekam a ekac"`、`"8F-3T-1G-2n",4`（见 `Problems/P5107`） |
| 字符串数组输出 | `["a","b"]`（见 `Problems/P14398`） |

**字符串题强制约定**：凡输入含字符串字段（含空格、标点），**样例与测例** stdin **必须**写成双引号形式；裸字符串（无引号）禁止作为默认格式。

**题面文案（给客户看）**：`# 输入描述` / `# 输出描述` 只写字段**语义与约束**，**不要**写「双引号包裹」「方括号数组」「stdin 一行」等评测编码说明；双引号/方括号仅出现在**样例**代码块中即可。

### 常见 ACM → 单行映射

| 原 ACM | 样例 stdin 示例 |
|--------|-----------------|
| 第一行 `2N` 交错 + 第二行两整数 | `n,cap,workers,[t1,t2,...],[d1,d2,...]` |
| 学生数 + 交卷学号列表 | `n,[id1,id2,...]` |
| 一行整句 / 空格分词字符串 | `"ekam a ekac"` |
| 字符串 + 整数 | `"sn",m` |
| 第一行 `n` + 第二行数组 + 其他参数 | `n,w,[scores...]` 等，按字段顺序 |

## 输入 / 输出描述写法

### 输入描述

- 每条 `-` 对应样例中的一个逻辑字段（或一组等长数组）。
- 写清排序、唯一性、值域等原 ACM 约束。
- **不要**嵌入格式模板行；**不要**写「双引号包裹」等编码提示；**不要**使用 Problems 的 `**输入**（stdin **一行**：……）` 句式。

示例（P2977）：

```markdown
# 输入描述

- 任务数量 $N$。
- 工作队列的最大长度。
- 执行者的数量。
- 长度为 $N$ 的提交时刻列表；……
- 长度为 $N$ 的执行时长列表；……

$N$ 不超过 $20$，……
```

### 输出描述

- 条目说明各输出量含义。
- 若为多值数组输出，写明 `[a, b, …]` 形态（参考「未交卷学号列表」→ `[1,4,8,10]` 的写法）。

---

## 轻量模式工作流

1. 保留 `# 题目内容`。
2. 根据原 ACM 样例确定 stdin 单行格式，改写全部 `## 样例k`。
3. 按样例字段重写 `# 输入描述`、`# 输出描述`（条目式，与样例一致）。
4. 自检：题意不变、样例数值不变、描述与样例字段对应、无函数接口节。
