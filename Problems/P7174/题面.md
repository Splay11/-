# 题目内容

银行通常可以通过银行卡号的前缀判断银行卡所属的银行。

现在给定 $n$ 条银行卡前缀匹配规则，第 $i$ 条规则包含一个数字字符串 $prefix_i$ 和对应的银行名称 $bank_i$。如果某张银行卡的卡号以 $prefix_i$ 开头，则说明该银行卡可能属于银行 $bank_i$。

一张银行卡可能同时匹配多个前缀。例如，卡号 $6222021234567890$ 可能同时匹配前缀 $62$ 和 $622202$。

如果一个银行卡号能够匹配多个规则，则选择长度最长的前缀所对应的银行。

现在给定 $m$ 个银行卡号，请判断每个银行卡号所属的银行。

如果某个银行卡号无法匹配任何前缀，则输出 $UNKNOWN$。

# 输入描述

第一行输入一个整数 $n$，表示银行卡前缀匹配规则的数量。

接下来 $n$ 行，每行输入两个字符串 $prefix_i$ 和 $bank_i$，分别表示银行卡号前缀和对应的银行名称。

随后输入一个整数 $m$，表示需要查询的银行卡号数量。

接下来 $m$ 行，每行输入一个字符串 $card_i$，表示一个银行卡号。

### 约束

$1 \le n \le 10^5$

$1 \le m \le 10^5$

$1 \le |prefix_i| \le 20$

$1 \le |card_i| \le 30$

$prefix_i$ 和 $card_i$ 均只由数字 $0$ 到 $9$ 组成。

所有 $prefix_i$ 互不相同。

$bank_i$ 仅由大小写英文字母组成，且长度不超过 $30$。

# 输出描述

对于每个银行卡号 $card_i$，输出一行其所属的银行名称。

如果该银行卡号能够匹配多个前缀，则输出其中最长前缀对应的银行名称。

如果无法匹配任何前缀，则输出 $UNKNOWN$。

## 样例1

**输入**

```text
4
62 BankA
6222 BankB
622202 BankC
955 BankD
5
6222021234567890
622233445566
621234567890
955880012345
123456789
```

**输出**

```text
BankC
BankB
BankA
BankD
UNKNOWN
```

**说明**

银行卡号 $6222021234567890$ 可以匹配前缀 $62$、$6222$ 和 $622202$。

其中 $622202$ 的长度最长，因此该银行卡属于 $BankC$。

银行卡号 $622233445566$ 可以匹配前缀 $62$ 和 $6222$，因此输出 $BankB$。

银行卡号 $621234567890$ 只能匹配前缀 $62$，因此输出 $BankA$。

银行卡号 $955880012345$ 可以匹配前缀 $955$，因此输出 $BankD$。

银行卡号 $123456789$ 无法匹配任何已知前缀，因此输出 $UNKNOWN$。

## 样例2

**输入**

```text
3
1 Alpha
12 Beta
123 Gamma
4
123456
129999
188888
999999
```

**输出**

```text
Gamma
Beta
Alpha
UNKNOWN
```

**说明**

对于银行卡号 $123456$，可以同时匹配前缀 $1$、$12$ 和 $123$，最长匹配前缀为 $123$，因此输出 $Gamma$。

对于银行卡号 $129999$，最长匹配前缀为 $12$，因此输出 $Beta$。

对于银行卡号 $188888$，只能匹配前缀 $1$，因此输出 $Alpha$。

银行卡号 $999999$ 无法匹配任何前缀，因此输出 $UNKNOWN$。
