# 多模态系统与后训练核对卷

上线前用本卷核对注意力实现、学习率调度、语音对齐、量化、智能体与视觉–语言桥接等基础点。单选题只选一项；多选题须选出全部正确项；判断题选是或否。

## 一、单选题

**1、展厅要把文物点云做成可交互的三维高斯场景。训练中途会做 densification。下列说法正确的是？**
{{ select(1) }}
- densification 用泊松重建替换高斯表示，训练中途切换几何后端
- densification 仅在导出 mesh 时执行一次，训练阶段冻结高斯个数
- 在梯度较大或高斯尺寸不匹配的区域做 clone / split,动态增加或分裂高斯,提升欠拟合区域的重建质量
- densification 只把所有高斯半径统一放大一倍，不增不减个数

**2、值班日志检索要把很长的 token 序列送进注意力层，显存已经打满。讨论 FlashAttention 的核心机制时，下列说法正确的是？**
{{ select(2) }}
- 通过在线 softmax 与分块(tiling)把 attention 显存从 O(N²) 降到 O(N),数值等价原实现
- 把注意力矩阵改成随机投影后不可逆压缩，显存下降但无法还原原分数
- 只在 CPU 上用稀疏掩码跳过计算，GPU kernel 保持不变
- 用固定窗口截断 key/value，超出窗口的位置直接丢弃且不可恢复

**3、巡检照片问答台要把摄像头画面和值班提问送进同一套语言模型。关于 LLaVA 系列视觉–语言对齐的典型做法，下列说法正确的是？**
{{ select(3) }}
- 把图像像素直接当词表 id 查 embedding，不再经过视觉编码器
- 用两层 MLP projector 把视觉 encoder 特征映射到 LLM 的 token embedding 空间,与文本 token 拼接后送入 LLM
- 用对比学习把整图压成一个标量分数，再与文本相似度相乘
- 训练时删掉文本 token，只让 LLM 读视觉特征

**4、货架俯拍要做商品检测。骨干从 ViT 换成 Swin Transformer。关于 Swin 相对 ViT 的关键差异，下列说法正确的是？**
{{ select(4) }}
- Swin 把整图展平后只做一层全局平均池化，不再计算任何注意力
- Swin 强制输入分辨率必须是 224，其他尺寸直接拒绝
- Swin 用 FFT 把空间混合换成频域点乘，与窗口无关
- Swin 用 window attention + shifted window,把复杂度从 O(N²) 降到 O(N),并保留跨窗口信息交换

**5、分拣机械臂要根据料箱画面给出抓取轨迹。策略头在确定性 MLP 和 Diffusion Policy 之间选型。下列说法正确的是？**
{{ select(5) }}
- 通过条件扩散过程建模多模态动作分布,可表示"多种同样合理"的动作,并输出稳定的动作 chunk
- 把动作空间离散成 4 个方向按键，用分类头一次输出
- 用卡尔曼滤波替代策略网络，不再学习视觉条件
- 推理时把扩散步数固定为 0，直接输出噪声本身作为动作

**6、厂区广播转写要在 CTC 和 RNN-T 之间选 ASR 头。关于二者的关键差异，下列说法正确的是？**
{{ select(6) }}
- CTC 强制输出长度必须严格等于声学帧数，禁止插入 blank
- RNN-T 不能做流式解码，必须等整句音频结束
- CTC 假设时间步之间条件独立,不显式建模输出序列的语言先验;RNN-T 通过 predictor 引入自回归语言建模,更擅长长文本
- 两者共用同一套对齐路径，只是优化器不同

**7、设备台账助手要边推理边查库存接口。关于 ReAct(Reason + Act) 范式的核心机制，下列说法正确的是？**
{{ select(7) }}
- 先把全部工具调用写成静态脚本一次性跑完，中间不看返回
- 交替生成 thought(推理链)与 action(工具调用),把中间观察 observation 拼回上下文,形成"想–做–看"循环
- 只用检索增强生成，禁止模型输出任何动作标记
- 要求每个 thought 对应一个可微损失，用反传更新工具参数

**8、点云分割大模型用大 batch 开训，计划采用 warmup + cosine 学习率调度。下列说法正确的是？**
{{ select(8) }}
- warmup 只用来初始化 BN 统计量，与学习率无关
- 建议把 warmup 设成总步数的 80%，否则一定发散
- cosine 阶段把学习率锁死为峰值不再变化
- warmup 阶段先线性升到峰值 lr,再按 cosine 衰减,可稳定大 batch 训练早期

**9、值班助手要压到端侧，权重量化在 AWQ 与 GPTQ 之间比较。关于 AWQ 相对 GPTQ 的改进，下列说法正确的是？**
{{ select(9) }}
- AWQ 必须先训练一份完整 Hessian，再按二阶曲率量化
- 保留少量对激活敏感的显著权重通道以更高精度,并按激活尺度做 per-channel 缩放,不需二阶信息
- AWQ 把所有权重统一量化到 INT2，不允许混合精度通道
- AWQ 只改激活量化，权重保持 FP16 不动

## 二、多选题

**10、客服话术模型要做后训练，方案里出现 SFT / DPO / RLHF / RLAIF。下列说法正确的是？**
{{ multiselect(10) }}
- SFT 使用人类演示做监督微调,是后训练第一步,决定基础能力
- RLAIF 用 AI 反馈替代人类标注,可显著降低标注成本
- DPO 不显式训 reward model,直接从成对偏好数据推导策略更新
- RLHF 需要先训 reward model,再用 PPO 类算法优化策略

**11、库房拍照问答要把视觉编码器接到 LLM。关于连接方式，下列说法正确的是？**
{{ multiselect(11) }}
- MLP Projector(LLaVA) 是当前最简单主流的做法,训练开销小
- 视觉桥接只能用单层线性层，多层 MLP 或交叉注意力都会立刻发散
- Cross-Attention(Flamingo) 把视觉特征当作 K/V,通过门控插入 LLM 的中间层
- Q-Former(BLIP-2) 用可学习 query 从冻结视觉编码器中提取 LLM 友好特征

**12、制度问答大模型要核对 RMSNorm / SwiGLU / RoPE 的用法。下列说法正确的是？**
{{ multiselect(12) }}
- SwiGLU = (Swish(xW1)) ⊙ (xW2),相比标准 FFN 在同参数量下效果更好
- RMSNorm 必须同时减去均值并除以标准差，不能省略均值项
- RoPE 通过对 Q/K 施加旋转矩阵,天然编码相对位置,支持外推
- RMSNorm 相比 LayerNorm 省略均值项,只做尺度归一化,推理更快

**13、工单助手要在 ReAct / Reflexion / Tree-of-Thoughts / LangGraph 等 Agent 范式里选型。下列说法正确的是？**
{{ multiselect(13) }}
- Reflexion 让模型对失败轨迹做语言化反思并写入 memory,下轮任务复用
- Tree-of-Thoughts 通过搜索多条推理分支并做剪枝,比线性 CoT 在复杂规划上更稳
- ReAct 让模型交替"思考–行动–观察",观察结果拼回上下文形成闭环
- Tree-of-Thoughts 禁止分支，只能沿单条链逐步改写同一段落

**14、驾驶舱回放要用世界模型/视频生成补全未拍摄片段。关于 Sora / Cosmos / Genie / Stable Video Diffusion / DriveDreamer 等工作，下列说法正确的是？**
{{ multiselect(14) }}
- Genie 类无动作监督世界模型,可从视频学隐动作空间做交互式生成
- NVIDIA Cosmos 面向物理 AI,提供开放世界模型底座,支持条件生成与仿真数据合成
- 世界模型一旦训练完成就必须冻结全部权重，条件生成会破坏已学到的动力学
- Sora 基于 Diffusion Transformer(DiT)架构,把时空 patch 作为统一 token

**15、会议室拾音要做前端处理与麦克风阵列。下列说法正确的是？**
{{ multiselect(15) }}
- 声学回声消除(AEC)通常估计参考信号到麦克风的传输通道并做减法
- 波束成形只能用单麦克风通过软件插值得到阵列，硬件阵列没有意义
- MVDR / GEV 是常见的自适应波束成形算法
- 波束成形(beamforming)通过阵列信号相位对齐提升目标方向 SNR

**16、厂区广播转写要在 Whisper / RNN-T / Conformer 等现代语音识别模型里选型。下列说法正确的是？**
{{ multiselect(16) }}
- Whisper 用大规模弱监督(网页字幕)训练,零样本多语种 ASR 能力强
- RNN–T 因引入 predictor 而适合流式识别,便于低延迟部署
- SeamlessM4T / Voxtral 支持语音–语音、语音–文本、文本–语音多任务统一建模
- Conformer = Convolution + Transformer,兼顾局部与全局建模,广泛用于工业级 ASR

**17、分拣台要用视觉–语言–动作模型做抓取。关于 OpenVLA / RT–2 / π0 / GR–1 / SmolVLA 等主流 VLA 工作，下列说法正确的是？**
{{ multiselect(17) }}
- OpenVLA 基于 LLaVA 类骨架,把动作 token 化后与视觉/语言一起自回归输出
- 所有 VLA 都必须丢掉视觉输入，只靠语言指令闭环
- RT–2 用 web VQA 数据与机器人数据共同训练,提升语义泛化
- π0 用 flow matching 输出连续动作 chunk,适合高频闭环控制

**18、制度助手要实现 Tool Use / Function Calling。下列说法正确的是？**
{{ multiselect(18) }}
- 工具 schema 写得越含糊，模型越能自由发挥，调用准确率反而更高
- OpenAI Function Calling 通过在 system prompt 中注入 JSON schema,让模型输出结构化函数名与参数
- Anthropic tool_use 采用 XML/JSON 混合标记,模型输出 tool_use 块由 runtime 拦截执行
- Tool 描述与参数 schema 越清晰,模型调用准确率越高;模糊 schema 是主要 bad case 来源之一
