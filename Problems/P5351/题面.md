## 一、单选题
**1、关于 FlashAttention 的核心机制,下列说法正确的是?**
{{ select(1) }}
- 只加速 forward,不能加速 backward
- 通过在线 softmax 与分块(tiling)把 attention 显存从 O(N²) 降到 O(N),数值等价原实现
- 通过近似低秩分解降低复杂度,数值上是一种近似 attention
- 仅在 A100 上有实现,消费级 GPU 不适用


**2、关于 warmup + cosine 学习率调度,下列说法正确的是?**
{{ select(2) }}
- warmup 是给 optimizer 二阶矩预热,与 batch size 无关
- cosine 阶段严格保证 loss 单调下降,若上升说明超参错误
- warmup 阶段先线性升到峰值 lr,再按 cosine 衰减,可稳定大 batch 训练早期
- warmup 步数越长收敛越快,建议至少设 total steps 的 30%


**3、关于 Swin Transformer 相对 ViT 的关键差异,下列说法正确的是?**
{{ select(3) }}
- Swin 不再需要位置编码,输入顺序无影响
- Swin 用 window attention + shifted window,把复杂度从 O(N²) 降到 O(N),并保留跨窗口信息交换
- Swin 仅在图像分类有效,不适合检测/分割
- Swin 完全放弃 self-attention,改用 depthwise 卷积


**4、关于 CTC 与 RNN-T 用于 ASR 的关键差异,下列说法正确的是?**
{{ select(4) }}
- CTC 输出必须与输入等长,不需 blank 符号
- CTC 与 RNN-T 数学等价,只是实现方式不同
- RNN-T 假设时间步之间条件独立,CTC 才做自回归
- CTC 假设时间步之间条件独立,不显式建模输出序列的语言先验;RNN-T 通过 predictor 引入自回归语言建模,更擅长长文本


**5、关于 AWQ(Activation-aware Weight Quantization) 相对 GPTQ 的改进,下列说法正确的是?**
{{ select(5) }}
- AWQ 与 GPTQ 等价,只是命名不同
- AWQ 需要构造 Hessian 二阶信息才能量化,复杂度高于 GPTQ
- AWQ 只支持 INT8,不支持 INT4
- 保留少量对激活敏感的显著权重通道以更高精度,并按激活尺度做 per-channel 缩放,不需二阶信息


**6、关于 3D Gaussian Splatting 训练中 densification 的作用,下列说法正确的是?**
{{ select(6) }}
- densification 用于删除多余高斯,与增删无关
- 在梯度较大或高斯尺寸不匹配的区域做 clone / split,动态增加或分裂高斯,提升欠拟合区域的重建质量
- densification 会破坏可微分光栅化,不能与梯度下降联用
- densification 只对静态场景生效,4DGS 中禁用


**7、关于 ReAct(Reason + Act) 范式的核心机制,下列说法正确的是?**
{{ select(7) }}
- 一次性生成完整思维链 + 全部动作,不与环境交互
- 交替生成 thought(推理链)与 action(工具调用),把中间观察 observation 拼回上下文,形成"想–做–看"循环
- ReAct 不使用任何外部工具,只在 prompt 内推理
- ReAct 要求所有动作可微,可通过梯度反传优化


**8、关于 LLaVA 系列视觉–语言对齐的典型做法,下列说法正确的是?**
{{ select (8) }}
- 用 GAN 判别器对齐视觉与文本分布
- 视觉与文本各自训一个独立 LLM,推理时 vote 融合
- LLaVA 训练时冻结 projector,微调整个 LLM
- 用两层 MLP projector 把视觉 encoder 特征映射到 LLM 的 token embedding 空间,与文本 token 拼接后送入 LLM


**9.关于 Diffusion Policy 相对确定性 MLP 策略头的优势,下列说法正确的是?**
{{ select(9) }}
- Diffusion Policy 只支持离散动作,不能输出连续控制
- Diffusion Policy 完全放弃视觉输入,只用触觉
- 通过条件扩散过程建模多模态动作分布,可表示"多种同样合理"的动作,并输出稳定的动作 chunk
- Diffusion Policy 推理只需一步,不需迭代 sampling

## 二、多选题

**10、关于视觉编码器与 LLM 的连接方式,下列说法正确的是?**
{{ select(10) }}
- MLP Projector(LLaVA) 是当前最简单主流的做法,训练开销小
- Cross-Attention(Flamingo) 把视觉特征当作 K/V,通过门控插入 LLM 的中间层
- Q-Former(BLIP-2) 用可学习 query 从冻结视觉编码器中提取 LLM 友好特征
- 所有视觉桥接结构都必须冻结 LLM,否则一定崩溃


**11、关于音频前端信号处理与麦克风阵列,下列说法正确的是?**
{{ select(11) }}
- 空间音频渲染只需要单声道输入,与 HRTF 无关
- 声学回声消除(AEC)通常估计参考信号到麦克风的传输通道并做减法
- MVDR / GEV 是常见的自适应波束成形算法
- 波束成形(beamforming)通过阵列信号相位对齐提升目标方向 SNR


**12、关于 LLM Tool Use / Function Calling 的实现,下列说法正确的是?**
{{ select(12) }}
- OpenAI Function Calling 通过在 system prompt 中注入 JSON schema,让模型输出结构化函数名与参数
- Function Calling 必须由模型端 fine-tune 才能启用,零样本 prompt 无法触发工具调用
- Anthropic tool_use 采用 XML/JSON 混合标记,模型输出 tool_use 块由 runtime 拦截执行
- Tool 描述与参数 schema 越清晰,模型调用准确率越高;模糊 schema 是主要 bad case 来源之一


**13、关于 ReAct / Reflexion / Tree-of-Thoughts / LangGraph 等 Agent 范式,下列说法正确的是?**
{{ select(13) }}
- Reflexion 让模型对失败轨迹做语言化反思并写入 memory,下轮任务复用
- Tree-of-Thoughts 通过搜索多条推理分支并做剪枝,比线性 CoT 在复杂规划上更稳
- LangGraph 是纯 prompt 模板库,不涉及 state / edge / node 抽象
- ReAct 让模型交替"思考–行动–观察",观察结果拼回上下文形成闭环


**14、关于现代语音识别模型,下列说法正确的是?**
{{ select(14) }}
- Whisper 用大规模弱监督(网页字幕)训练,零样本多语种 ASR 能力强
- RNN–T 因引入 predictor 而适合流式识别,便于低延迟部署
- SeamlessM4T / Voxtral 支持语音–语音、语音–文本、文本–语音多任务统一建模
- Conformer = Convolution + Transformer,兼顾局部与全局建模,广泛用于工业级 ASR


**15、关于 SFT / DPO / RLHF / RLAIF 后训练范式,下列说法正确的是?**
{{ select(15) }}
- SFT 使用人类演示做监督微调,是后训练第一步,决定基础能力
- RLAIF 用 AI 反馈替代人类标注,可显著降低标注成本
- DPO 不显式训 reward model,直接从成对偏好数据推导策略更新
- RLHF 需要先训 reward model,再用 PPO 类算法优化策略


**16、关于 RMSNorm / SwiGLU / RoPE 在现代大模型中的应用,下列说法正确的是?**
{{ select(16) }}
- RoPE 只能用于绝对位置编码,不支持相对位置
- SwiGLU = (Swish(xW1)) ⊙ (xW2),相比标准 FFN 在同参数量下效果更好
- RoPE 通过对 Q/K 施加旋转矩阵,天然编码相对位置,支持外推
- RMSNorm 相比 LayerNorm 省略均值项,只做尺度归一化,推理更快


**17、关于 OpenVLA / RT–2 / π0 / GR–1 / SmolVLA 等主流 VLA 工作,下列说法正确的是?**
{{ select(17) }}
- VLA 已在通用商业机器人上完全替代传统规控栈,不再需要专家模块
- OpenVLA 基于 LLaVA 类骨架,把动作 token 化后与视觉/语言一起自回归输出
- RT–2 用 web VQA 数据与机器人数据共同训练,提升语义泛化
- π0 用 flow matching 输出连续动作 chunk,适合高频闭环控制


**18、关于 Sora / Cosmos / Genie / Stable Video Diffusion / DriveDreamer 等世界模型/视频生成工作,下列说法正确的是?**
{{ select(18) }}
- Genie 类无动作监督世界模型,可从视频学隐动作空间做交互式生成
- Stable Video Diffusion 只支持静态图像,不能生成视频
- NVIDIA Cosmos 面向物理 AI,提供开放世界模型底座,支持条件生成与仿真数据合成
- Sora 基于 Diffusion Transformer(DiT)架构,把时空 patch 作为统一 token
