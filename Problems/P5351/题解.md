# 答案+解析

## 一、单选题

### 1
**答案：C**

densification 是在梯度大或尺度不匹配处做 clone / split，用来补欠拟合区域。换成泊松后端、训练期锁死个数、只统一放大半径，都不是这件事。

### 2
**答案：A**

FlashAttention 用在线 softmax 和分块，把注意力显存从 $O(N^2)$ 降到 $O(N)$，且与原实现数值等价。随机投影不可逆、只改 CPU 掩码、硬截断窗口，都不是该机制。

### 3
**答案：B**

LLaVA 用两层 MLP projector 把视觉特征映到 LLM 的 token 空间再与文本拼接。像素当词表 id、压成标量再乘相似度、训练时丢掉文本 token，都不是典型对齐做法。

### 4
**答案：D**

Swin 用 window attention 加 shifted window，复杂度降到 $O(N)$ 同时还能跨窗口换信息。全局平均池化、锁死 $224$、改成 FFT 点乘，都不是相对 ViT 的这一差异。

### 5
**答案：A**

Diffusion Policy 用条件扩散刻画多模态连续动作，并输出动作 chunk。四方向分类、卡尔曼替代策略、扩散步数设为 $0$ 直接当动作，都不是它的优势。

### 6
**答案：C**

CTC 假设各时间步条件独立、不显式带语言先验；RNN-T 用 predictor 做自回归，更适合长文本。CTC 仍需要 blank 且输入输出不必等长；RNN-T 可以流式；二者对齐也并不等价。

### 7
**答案：B**

ReAct 是 thought 与 action 交替，把 observation 拼回上下文。一次性跑完脚本、禁止动作标记、要求动作可微反传，都不是该范式。

### 8
**答案：D**

warmup 先线性升到峰值学习率，再 cosine 衰减，用来稳住大 batch 早期。它不是给 BN 预热；warmup 也不是越长越好；cosine 阶段学习率会下降而不是锁死。

### 9
**答案：B**

AWQ 按激活敏感度保留少量高精度通道，并做 per-channel 缩放，不依赖 Hessian。先造完整二阶信息、全体压到 INT2、只重量化激活而冻结权重，都不是相对 GPTQ 的改进。

## 二、多选题

### 10
**答案：A、B、C、D**

四项都对：SFT 用人类演示打底；RLAIF 用模型反馈降标注成本；DPO 不显式训奖励模型；RLHF 先训奖励模型再用 PPO 类算法。

### 11
**答案：A、C、D**

MLP Projector、Flamingo 式 cross-attention、BLIP-2 的 Q-Former 都是常见桥接。B 说多层 MLP 或交叉注意力一定会发散，不是事实；LLM 也不是必须冻结。

### 12
**答案：A、C、D**

SwiGLU、RoPE 旋转相对位置、RMSNorm 省略均值项都对。B 把 RMSNorm 说成必须减均值，说反了。

### 13
**答案：A、B、C**

Reflexion 写反思进 memory、ToT 多分支搜索剪枝、ReAct 思考–行动–观察闭环都对。D 禁止 ToT 分支，与 ToT 相反。LangGraph 也不是纯 prompt 模板库，本题未再采用该旧错项。

### 14
**答案：A、B、D**

Genie 可从无动作标签视频学隐动作；Cosmos 面向物理 AI 的世界模型底座；Sora 用 DiT 把时空 patch 当统一 token。C 说训完必须冻参、条件生成会破坏动力学，没有这回事。

### 15
**答案：A、C、D**

AEC 估通道再减法、MVDR/GEV 自适应波束成形、阵列相位对齐提升目标方向 SNR，都对。B 说单麦软件插值就能替代硬件阵列，是错的。

### 16
**答案：A、B、C、D**

Whisper 弱监督多语种零样本、RNN-T 适合流式、SeamlessM4T/Voxtral 多任务统一、Conformer 卷积加 Transformer，四项都对。

### 17
**答案：A、C、D**

OpenVLA 动作 token 化后自回归、RT-2 混 web VQA 与机器人数据、π0 用 flow matching 出连续动作块，都对。B 要求丢掉视觉只靠语言，不是这些 VLA 的设定；VLA 也尚未完全替代传统规控栈。

### 18
**答案：B、C、D**

把 JSON schema 注入 prompt、runtime 拦截 tool_use 块、schema 越清晰调用越准，都对。A 说 schema 越含糊准确率越高，说反了；工具调用也不必必须微调才能触发。

## 三、判断题

### 19
**答案：A（是）**

RNN-T 的 predictor 带来自回归语言建模，可以逐帧流式解码，适合端侧低延迟转写。

### 20
**答案：B（否）**

HRTF 描述的是空间声源到双耳的滤波，双耳渲染常常要基于它，并不是功放电路频响，也不能忽略。
