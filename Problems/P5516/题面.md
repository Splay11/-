# 题目内容

给定一个长度为 $n$ 的整数数组 $a$，请你找到最长的「山峰子序列」的长度。

山峰子序列定义：一个子序列 $b_1, b_2, \ldots, b_m$（$m \ge 3$），存在某个位置 $k$（$1 < k < m$），使得 $b_1 < b_2 < \cdots < b_k > b_{k+1} > \cdots > b_m$，即先严格递增再严格递减。

如果不存在满足条件的山峰子序列，输出 $0$。

# 输入描述

第一行输入一个整数 $n$（$3 \le n \le 5000$），表示数组长度。

第二行输入 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 10^9$）。

# 输出描述

输出一个整数，表示最长山峰子序列的长度。若不存在则输出 $0$。

## 样例 $1$

**输入**

```text
8
2 1 4 7 3 2 5 1
```

**输出**

```text
6
```

## 样例 $2$

**输入**

```text
5
1 2 3 4 5
```

**输出**

```text
0
```
