# P7127 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：第一行 `n x`，第二行 $n$ 个整数（原链表从头沿后继的值）。
输出：$n+1$ 个数，值为 $x$ 的新头接在原序列前面。

约束：$1 \le n \le 10^4$，$-10^9 \le a_i,x \le 10^9$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1 | 输出 $10\ 1\ 2\ 3\ 4$ | 把 $x$ 接到末尾，或漏掉原序列 |
| 2 | 样例 2 | 输出 $5\ 7\ 8\ 9$ | 只输出原序列 |
| 3 | 最小规模 $n=1$ | 输出 $100\ 5$，单节点自环后头插 | 单节点时 $prev/next$ 没接成环，插入后死循环或崩溃 |
| 4 | 全负数 | 输出 $-1\ -2\ -3\ -4$ | 按无符号输出 |
| 5 | $x$ 与原值相同 | 输出四个 $2$ | 去重或跳过相同值 |
| 6 | 值域两端 | 新头是 $-10^9$ | 32 位不够 |
| 7 | 逆序原链 | 新头 $0$ 后保持逆序 | 插入时把链表方向接反 |
| 8 | 小随机 $n=12$ | 链表遍历与直接拼接应对上 | 遍历多走或少走一圈 |
| 9 | 压满 $n=10^4$，值为 $0..n-1$ | 输出 $123$ 再接 $0$ 到 $9999$ | 建表 $O(n^2)$ 或遍历不终止 |
| 10 | 压满 $n=10^4$，随机含负数 | 新头为 $-10^9$ | 读入/输出超时或断环 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：真实双向循环链表头插遍历的结果，必须等于把 $x$ 直接拼在序列前面。
