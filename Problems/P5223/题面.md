# 题目内容


在一项单败淘汰制的比赛中，共有 $2^k$ 名选手参赛，选手编号依次为 $1$ 到 $2^k$。每位选手的实力与其编号相同，即编号为 $i$ 的选手的实力为 $i$（注意：较大的实力值表示更强的选手）。在任一场比赛中，如果编号为 $i$ 的选手与编号为 $j$ 的选手对阵，则编号为 $i$ 的选手获胜的概率 $P(i \text{胜 } j)=\frac{i}{i+j}$。

具体地对阵流程如下：
- 第一轮，参赛选手按初始排列顺序两两配对，依次为第 $1$ 名选手对阵第 $2$ 名选手，第 $3$ 名选手对阵第 $4$ 名选手，……，第 $2^k-1$ 名选手对阵第 $2^k$ 名选手。（注意，这里是位置在 $1$ 上的选手，不一定就是编号为 $1$ 的选手）
- 后续轮次，按上一轮胜者出现的先后顺序重新排成一行，再依次每两人配对（对第 $1$ 名选手对阵第 $2$ 名选手，第 $3$ 名选手对阵第 $4$ 名选手，……），胜者继续进入下一轮，直至决出冠军。

初始排列为一个长度为 $2^k$ 的排列，即每名选手恰好出现一次，且顺序决定其首轮配对关系。现在你希望通过调整初始排列顺序，求解一共有多少种不同的初始排列顺序，使得编号为 $1$ 的选手的夺冠概率达到最大。由于答案可能很大，请将答案对 $998244353$ 取模后输出。

【名词解释】

长度为 $n$ 的排列：由 $1,2,\dots,n$ 这 $n$ 个整数、按任意顺序组成的数组（每个整数均恰好出现一次）。例如，$\{2,3,1,5,4\}$ 是一个长度为 $5$ 的排列，而 $\{1,2,2\}$ 和 $\{1,3,4\}$ 都不是排列，因为前者存在重复元素，后者包含了超出范围的数。



# 输入描述

输入一行一个整数 $k$。（$1 \le k \le 12$）



# 输出描述


输出一行整数，表示答案对 $998244353$ 取模的结果。


## 样例1 



**输入** 



```
1
```



**输出** 



```
1
```



**说明**

$(k=1)$，一共 $2^1=2$ 选手，$\{1,2\}$ 和 $\{2,1\}$。只有 $1$ 和 $2$ 首轮碰到；$1$夺冠概率$\frac{1}{1+2}$，两种排列概率一样，但是注意：当$(k=1)$，答案$1$。


## 样例2



**输入** 



```
2
```



**输出** 



```
8
```
