# P5223 题解 —— 方案淘汰最优编排

## 题目理解

本题要求计算：在逐轮两两对比淘汰评审中（共 $2^m$ 个方案，实力=编号），求使得方案 $1$ 最终胜出概率达到**最大**的初始编排数。

**核心符号约定：**
- $m$：比赛轮数，$1 \le m \le 12$，方案总数 $N=2^m$
- 淘汰规则：编号 $i$ 与 $j$ 对比，$i$ 胜出的概率 $P(i\text{ 胜 }j)=\frac{i}{i+j}$
- 固定位置两两配对（$(1,2),(3,4),\dots$），胜者按原序排列后继续配对
- 初始编排为 $\{1,\dots,2^m\}$ 的一个排列

## 最优编排的结构

### 关键观察

1. **方案 1 希望面对尽可能弱的对手**。因为 $P(1\text{ 胜 }j)=\frac{1}{1+j}$ 随 $j$ 增大而单调递减，所以方案 1 在每一轮的对手越弱，胜率越高。

2. **高编号方案应当远离方案 1**。若两个高编号方案在远离方案 1 的半区中对碰，更强的会被淘汰，最终只有较弱者能与方案 1 对阵。

3. **自相似性**。在任一不包含方案 1 的子树中，该子树的最小编号方案若能最大化其出线概率，则方案 1 在后续轮次面对的对手预期强度最低。

### 贪心归纳

对大小为 $2^k$ 的子赛程（含方案集合 $S$，其中 $a=\min S$），最优编排满足：
- **第一步**：将 $S$ 按编号大小等分为两个子集，$a$ 所在的那一半取**最小的** $2^{k-1}$ 个编号，另一半取**最大的** $2^{k-1}$ 个编号。
- **第二步**：两半各自递归地按同一原则编排。

$a$ 所在的那一半称为"优惠半区"，另一个半区称为"对手半区"。

### 计数推导

设 $a(k)$ 为 $2^k$ 个方案时使最小编号胜出概率最大的编排数。

- **基准** $k=1$（$N=2$）：共有 $2! = 2$ 种排列，都给出相同的胜率 $\frac{1}{3}$。因此 $a(1)=2$。

- **递推** $k \ge 2$：
  - 根结点将 $2^k$ 个位置分成左右两个大小为 $2^{k-1}$ 的半区。
  - 方案 1 所在的半区可**位于左或右**（$2$ 种选择）。
  - 方案 1 的半区必须放 $\{1,2,\dots,2^{k-1}\}$，并按 $a(k-1)$ 种编排。
  - 对手半区放 $\{2^{k-1}+1,\dots,2^k\}$，其最小编号 $2^{k-1}+1$ 按 $a(k-1)$ 种编排最大化自身出线概率。

  因此递推式：
  $$
  a(k) = 2 \cdot a(k-1)^2, \qquad k \ge 2
  $$

- **通项公式**：由 $a(1)=2$ 反复代入得：
  $$
  a(k) = 2^{2^k - 1}
  $$

### 样例验算

| $m$ | $2^m$ | $a(m) = 2^{2^m-1}$ | |
|---|---|---|---|
| 1 | 2 | $2^1 = 2$ | — |
| 2 | 4 | $2^3 = 8$ | 样例 1 |
| 3 | 8 | $2^7 = 128$ | 样例 2 |
| 4 | 16 | $2^{15} = 32768$ | — |
| 5 | 32 | $2^{31} \bmod 998244353 = 150994942$ | — |

## 算法实现

由于 $m\le 12$ 即 $2^m\le 4096$，直接计算 $2^{2^m-1}\bmod 998244353$ 即可。

使用**快速幂（倍增法）**：
- 时间复杂度：$O(\log 2^m) = O(m)$，在本题约束下常数极小。
- 空间复杂度：$O(1)$。

### 参考代码（Python）

```python
MOD = 998244353

def solve(m: int) -> int:
    e = (1 << m) - 1    # 指数 = 2^m - 1
    return pow(2, e, MOD)
```

### 参考代码（C++）

```cpp
const long long MOD = 998244353;

long long fastPow(long long a, long long e, long long mod) {
    long long res = 1;
    a %= mod;
    while (e) {
        if (e & 1) res = res * a % mod;
        a = a * a % mod;
        e >>= 1;
    }
    return res;
}

long long solve(int m) {
    long long e = (1LL << m) - 1;
    return fastPow(2, e, MOD);
}
```

## 易错点提醒

1. **取模遗漏**：$m=5$ 时 $2^{31}\approx 2.1\times 10^9 > 998244353$，若不取模会输出错误值。
2. **指数溢出**：在 C++ 中若用 `int` 计算 `1<<m`（$m=12$ 时仍安全），但指数本身需传给 `long long` 类型的幂运算参数，否则可能在后续移位中截断。
3. **直接计算 $2^{2^m-1}$**：$m=12$ 时结果有 $10^{1233}$ 数量级，任何语言都会溢出，必须边乘边取模。
