# P7146 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：一行合法加减表达式，可含空格、括号、一元减号。
输出：表达式的值（有符号 $32$ 位整数范围内）。

约束：$1\le |s|\le 3\times 10^5$。加号不能作一元运算符；没有两个连续运算符。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1，含空格 | $2$ | 用 $cin$ 只读到 $1$ |
| 2 | 样例 2，首尾空格 | $3$ | 没有跳过空格把数字读坏 |
| 3 | 样例 3，多层括号 | $23$ | 括号层符号没压栈 |
| 4 | 一元减号作用在括号上 | $-5$ | 算成 $-2+3=1$ |
| 5 | 单个 $0$ | $0$ | 空结果 |
| 6 | 多位整数 | $27$ | 数字只读一位得到 $1+2-3$ |
| 7 | 嵌套减法 | $1-(2-(3-4))=-2$ | 从左到右无括号得到错误值 |
| 8 | 小随机加减、括号、一元减与空格 | 栈扫描与递归下降对拍 | 把加号当一元正号 |
| 9 | 压满约 $3\times 10^5$ 的 $1+1+\cdots$ | 线性扫，不能递归按加号深度 | 递归求值爆栈或 TLE |
| 10 | 压满约 $3\times 10^5$ 的 $(1)+(1)+\cdots$ | 大量括号进出栈 | 右括号没把内层乘回外层符号 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：栈扫描必须等于递归下降求值。
