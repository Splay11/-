# A 类内网 IP 筛选与排序

企业内网运维中，需要对分配的 $IP$ 地址段进行有效性校验：给定一个存储内网 $IP$ 地址列表，要求筛选出符合 $A$ 类内网网段（$10.0.0.0$-$10.255.255.255$）的 $IP$ 地址，并按「网段层级」（即 $IP$ 的第二、第三、第四分段数值）升序排序。

**A 类内网 IP 规则：**

1. $IP$ 格式为 $xxx.xxx.xxx.xxx$（$4$ 个分段，每个分段为 $0$-$255$ 的整数）；
2. 第一个分段必须是 $10$；
3. 每个分段不能以 $0$ 开头（除非分段本身是 $0$，如 $10.0.1.1$ 合法，$10.01.1.1$ 不合法）。

**补充说明：** 给定的每组 $IP$ 地址列表中最多有 $15$ 个 $IP$ 地址；输入 $IP$ 格式不保证合法。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def filterValidAClassIPs(self, ips: List[str]) -> List[str]` |
| Java | `public String[] filterValidAClassIPs(String[] ips)` |
| C++ | `vector<string> filterValidAClassIPs(vector<string>& ips)` |

**参数**

- `ips`：字符串数组，每个元素为一个待校验的 $IP$ 地址（长度 $\le 15$）。

**返回值**

筛选并排序后的合法 $A$ 类内网 $IP$ 字符串数组；若无合法 $IP$ 则返回空数组 `[]`。

**排序规则**

对合法 $IP$ 按 $(第二分段,\ 第三分段,\ 第四分段)$ 的数值三元组字典序升序排列；比较的是分段数值而非字符串。

## 输入输出格式（stdin / stdout）

**输入**（stdin 整行，JSON 风格字符串数组，元素用双引号、逗号无空格）：

```text
["10.2.3.4","192.168.1.1","10.0.1.1"]
```

**输出**（stdout 一行，同格式字符串数组）：

```text
["10.0.1.1","10.2.3.4"]
```

## 数据范围

- $0 \le |ips| \le 15$；
- 每个 $IP$ 字符串长度 $\le 20$。

## 样例

### 样例 1

**输入**

```text
["10.2.3.4","192.168.1.1","10.0.1.1","10.01.2.3","10.1.0.256","10.10.5.6","10.1.8.9"]
```

**输出**

```text
["10.0.1.1","10.1.8.9","10.2.3.4","10.10.5.6"]
```

**说明**

- `192.168.1.1` 首段非 $10$；`10.01.2.3` 含前导零；`10.1.0.256` 第四段超 $255$，均剔除；
- 剩余按 $(0,1,1)\to(1,8,9)\to(2,3,4)\to(10,5,6)$ 排序。

### 样例 2

**输入**

```text
["10.216.20.96","10.257.25.193","10.218.150.20","10.159.163.72","10.233.43.60","10.263.201.27","10.94.142.203","10.251.113.174","44.74.87.156","10.145.173.233","10.102.21.96","10.20.23.65","10.43.130.246.12","250.166.162.178","10.138.80.223"]
```

**输出**

```text
["10.20.23.65","10.94.142.203","10.102.21.96","10.138.80.223","10.145.173.233","10.159.163.72","10.216.20.96","10.218.150.20","10.233.43.60","10.251.113.174"]
```

**说明**

- `10.257.25.193`、`10.263.201.27` 分段超 $255$；`10.43.130.246.12` 分段数不为 $4$；`44.74.87.156`、`250.166.162.178` 首段非 $10$，均剔除。

### 样例 3

**输入**

```text
["10.45.50.76","10.72.48.0","137.8.136.55","10.72.99.206","10.46.51.77","10.0.166.206","10.46.51.79","10.2.111.132.253","10.45.50.77","10.46.50.77"]
```

**输出**

```text
["10.0.166.206","10.45.50.76","10.45.50.77","10.46.50.77","10.46.51.77","10.46.51.79","10.72.48.0","10.72.99.206"]
```

**说明**

- `137.8.136.55` 首段非 $10$；`10.2.111.132.253` 分段数不为 $4$；
- `10.0.166.206` 合法（第二分段为 $0$），按网段层级排在最前；
- 排序时 $10.72.48.0$ 的第四分段为 $0$，排在 $10.72.99.206$ 之前。
