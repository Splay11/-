# 题目内容

在工业界落地分类模型时，除了输出 $0/1$ 预测，越来越常见的做法是输出预测集（$Prediction Set$）：当模型不确定时允许 “拒识 / 保留意见”，以换取更可靠的覆盖率保证。这类方法在近两年很流行，统称 Conformal $Prediction$（共形预测）。本题要求你在仅使用 `numpy / pandas / scikit‑learn` 的前提下，实现 Split $Conformal$（分类版）的确定性预测集构造，并将预测集映射成整数标签输出。

**已知：**

- 校准集（$calibration set$）上每个样本的真实标签 $\text{cal\_y} \in \{0,1\}$；
- 模型对校准集输出的正类概率 $\text{cal\_p1}$；
- 模型对测试集输出的正类概率 $\text{test\_p1}$。

请按以下严格流程计算：

**1) 定义非一致性分数**

对校准集第 i 个样本：

- 若 $\text{cal\_y}[i] = 1：s_i = 1 - p_i$
- 若$\text{cal\_y}[i] = 0$：$s_i = p_i$

其中 $p_i = \text{cal\_p1}[i]$。

**2) 计算 Conformal 阈值 q**

本题固定显著性水平：$\alpha=0.2$（即目标覆盖率约 80%）。

令校准集大小为 n，将所有 \(s_i\) 升序排序得到 \(s_{(0)} \le \dots \le s_{(n-1)}\)。

使用如下固定索引规则取阈值：

$k = \lceil (n+1)\cdot(1-\alpha) \rceil -1$

$\lceil \cdot \rceil$ 表示**向上取整**。

若 $k \ge n$，则令 $k = n-1$（防越界）。

最后：\(q = s_{(k)}\)

**3) 对测试集构造预测集 \(\Gamma(x)\)**

对第 $t$ 个测试样本，概率 $p = \text{test\_p1}[t]$：

- 将类别 $1$ 纳入预测集当且仅当：$1-p \le q \iff p \ge 1-q$
- 将类别 $0$ 纳入预测集当且仅当：$p \le q$

因此预测集可能为：$\{0\}、$\{1\}$、$\{0,1\}$、或空集 \emptyset$。

**4) 将预测集映射为输出整数**

对每个测试样本，输出一个整数：

- $\Gamma(x) = \{0\}$ 输出 $0$
- $\Gamma(x) = \{1\}$输出 1
- $\Gamma(x)$ = $\{0,1\}$ 输出 \(-1\)（表示不确定，拒识 / 保留）
- $\Gamma(x) = \emptyset$ 输出 -2$（表示 “无任何类别通过阈值”，仍需如实输出）

# 输入描述

标准输入为单行 JSON，格式如下：

```
{
  "cal_y": [0, 1, 0, ...],
  "cal_p1": [0.12, 0.83, 0.05, ...],
  "test_p1": [0.20, 0.70, 0.95, ...]
}
```

- `cal_y` 与 `cal_p1` 长度相同，均为校准集数据，长度为n，\(2<n<20\)；
- `cal_p1`、`test_p1` 均为 \([0,1]\) 内浮点数；
- `test_p1` 长度为m，\(1<m<20\)；
- 不存在缺失值与额外空行

# 输出描述

标准输出仅一行：长度等于`len(test_p1)`的 JSON 整数数组，例如：

```
[0, -1, 1]
```
