# 检索召回置信集映射

## 解题思路

按 Split Conformal 分类流程：先在校准集上算非一致性分数并取阈值 $q$，再对测试概率构造预测集并映射整数。

1. **非一致性分数**：正类样本 $s=1-p$，负类样本 $s=p$。
2. **阈值 $q$**：$\alpha=0.2$，$k=\lceil(n+1)(1-\alpha)\rceil-1$，若 $k\ge n$ 则 $k=n-1$，$q=s_{(k)}$（升序后第 $k$ 个）。
3. **预测集**：类别 $0$ 当 $p\le q$；类别 $1$ 当 $p\ge 1-q$。
4. **映射**：仅 $\{0\}\to 0$，仅 $\{1\}\to 1$，$\{0,1\}\to -1$，$\emptyset\to -2$。

用 `numpy` 排序与向量化条件判断即可。

## 复杂度分析

- 时间复杂度：$O(n\log n + m)$。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
import json
import math
import sys

import numpy as np


def solve(cal_y, cal_p1, test_p1, alpha=0.2):
  cal_y = np.asarray(cal_y, dtype=int)
  cal_p1 = np.asarray(cal_p1, dtype=float)
  test_p1 = np.asarray(test_p1, dtype=float)

  # 正类 1-p，负类 p
  s = np.where(cal_y == 1, 1.0 - cal_p1, cal_p1)
  s_sorted = np.sort(s)
  n = len(cal_y)
  k = math.ceil((n + 1) * (1 - alpha)) - 1
  if k >= n:
    k = n - 1
  q = float(s_sorted[k])

  out = []
  for p in test_p1:
    in0 = p <= q
    in1 = p >= 1.0 - q
    if in0 and in1:
      out.append(-1)
    elif in0:
      out.append(0)
    elif in1:
      out.append(1)
    else:
      out.append(-2)
  return out


data = json.loads(sys.stdin.read())
result = solve(data["cal_y"], data["cal_p1"], data["test_p1"])
sys.stdout.write(json.dumps(result))
```
