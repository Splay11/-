# 检索召回置信集映射

# 题目内容

制度问答检索侧在上线前，需要对二分类召回结果做**置信集**输出：模型不确定时允许拒识，以换取更稳的覆盖率。本题在仅使用 `numpy / pandas / scikit-learn` 的前提下，实现 Split Conformal（分类版）的确定性预测集构造，并将预测集映射为整数标签。

**已知：**

- 校准集真实标签 $\text{cal\_y}\in\{0,1\}$；
- 校准集正类概率 $\text{cal\_p1}$；
- 测试集正类概率 $\text{test\_p1}$。

请按以下流程计算：

**1) 非一致性分数**

对校准集第 $i$ 个样本，$p_i=\text{cal\_p1}[i]$：

- 若 $\text{cal\_y}[i]=1$：$s_i=1-p_i$
- 若 $\text{cal\_y}[i]=0$：$s_i=p_i$

**2) 计算阈值 $q$**

固定显著性水平 $\alpha=0.2$（目标覆盖率约 $80\%$）。

令校准集大小为 $n$，将 $s_i$ 升序排序得 $s_{(0)}\le\cdots\le s_{(n-1)}$。

$$
k=\lceil (n+1)\cdot(1-\alpha)\rceil-1
$$

若 $k\ge n$，令 $k=n-1$。阈值 $q=s_{(k)}$。

**3) 构造预测集 $\Gamma(x)$**

对测试样本概率 $p=\text{test\_p1}[t]$：

- 类别 $1$ 纳入当且仅当 $p\ge 1-q$
- 类别 $0$ 纳入当且仅当 $p\le q$

**4) 映射为整数**

- $\Gamma=\{0\}$ → $0$
- $\Gamma=\{1\}$ → $1$
- $\Gamma=\{0,1\}$ → $-1$（不确定 / 拒识）
- $\Gamma=\emptyset$ → $-2$

# 输入描述

标准输入为单行 JSON：

```
{
  "cal_y": [0, 1, 0, ...],
  "cal_p1": [0.12, 0.83, 0.05, ...],
  "test_p1": [0.20, 0.70, 0.95, ...]
}
```

- `cal_y` 与 `cal_p1` 长度相同，校准集长度 $n$，$3\le n\le 19$；
- `cal_p1`、`test_p1` 均为 $[0,1]$ 内浮点数；
- `test_p1` 长度 $m$，$2\le m\le 19$。

# 输出描述

标准输出仅一行：长度等于 `len(test_p1)` 的 JSON 整数数组，例如 `[0, -1, 1]`。

## 样例1

**输入**

```
{"cal_y":[0,0,1,1,0,1,0,1],"cal_p1":[0.08,0.12,0.88,0.92,0.25,0.85,0.15,0.78],"test_p1":[0.0,1.0,0.5,0.18,0.82]}
```

**输出**

```
[0, 1, -2, 0, 1]
```

**说明**

校准集 $n=8$，$\alpha=0.2$，$k=\lceil 9\times 0.8\rceil-1=7$，排序后取 $q=0.25$。测试 $0.0\le q$ 得 $0$；$1.0\ge 0.75$ 得 $1$；$0.5$ 两端均不满足得 $-2$；$0.18\le q$ 得 $0$；$0.82\ge 0.75$ 得 $1$。
