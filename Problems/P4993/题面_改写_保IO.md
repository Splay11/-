# 等距峰点统计

# 题目内容

产线侧在一条流水线上部署了 $m$ 个温感测点，读数依次为整型序列 $h_1,h_2,\dots,h_m$。质检模块要标记一类特殊测点：对满足 $1 < p < m$ 的下标 $p$，取其左侧读数的最大值 $\max(h_1,h_2,\ldots,h_{p-1})$，若有多个位置同取到该最大值，则选用其中与 $p$ 距离最近的下标 $u$；再取其右侧读数的最大值 $\max(h_{p+1},h_{p+2},\ldots,h_m)$，同样在并列最大值中选用与 $p$ 最近的下标 $v$。若 $p-u=v-p$，则称下标 $p$ 为**等距峰点**。

请统计序列中等距峰点的个数。

# 输入描述

每个测试文件均包含多组测试数据。

- 第一行读入一个整型 $q$（$1 \le q \le 10000$），代表数据组数。
- 每组测试数据描述如下：
  1. 第一行读入一个整型 $m$（$3 \le m \le 200000$），表示序列长度。
  2. 第二行读入 $m$ 个整型 $h_1,h_2,\dots,h_m$（$1 \le h_i \le 1000000000$），表示序列读数。
- 保证单个测试文件的 $m$ 之和不超过 $200000$。

# 输出描述

对于每一组测试数据，新起一行，写出一个非负整数表示结果。

## 样例1

**输入**

```
2
3
5 1 5
5
3 1 4 1 5
```

**输出**

```
1
2
```

**说明**

第一组：$m=3$，只需检查 $p=2$。左侧最大值在下标 $1$，距离 $1$；右侧最大值在下标 $3$，距离 $1$。相等，答案为 $1$。

第二组：$m=5$，检查 $p=2,3,4$。

- $p=2$：左峰下标 $1$、距离 $1$；右峰下标 $5$、距离 $3$。不等。
- $p=3$：左峰下标 $1$、距离 $2$；右峰下标 $5$、距离 $2$。相等，计入。
- $p=4$：左峰下标 $3$、距离 $1$；右峰下标 $5$、距离 $1$。相等，计入。

故答案为 $2$。
