# 双侧峰值等距

# 题目内容

产线侧部署了一排长度为 $n$ 的温感测点，读数依次为 $h_1,h_2,\dots,h_n$。关注中间某个测点 $i$（满足 $1 < i < n$）时：取其左侧读数的最大值 $\max(h_1,h_2,\ldots,h_{i-1})$，若有多个位置同取到该最大值，则选用其中与 $i$ 距离最近的下标 $p$；再取其右侧读数的最大值 $\max(h_{i+1},h_{i+2},\ldots,h_n)$，同样在并列最大值中选用与 $i$ 最近的下标 $q$。若 $i-p=q-i$，则称下标 $i$ 为**等距测点**。

请统计整排测点中等距测点的个数。

# 输入描述

第一行读入一个整数 $n$（$3 \le n \le 200000$），表示测点个数。

第二行读入 $n$ 个整数 $h_1,h_2,\dots,h_n$（$1 \le h_i \le 1000000000$），表示各测点读数。

# 输出描述

写出一行一个非负整数，表示等距测点的个数。

## 样例1

**输入**

```
4
2 3 1 4
```

**输出**

```
1
```

**说明**

仅需检查 $i=2,3$。

- $i=2$：左侧最大值取自下标 $1$，距离 $1$；右侧最大值取自下标 $4$，距离 $2$。不相等。
- $i=3$：左侧最大值取自下标 $2$，距离 $1$；右侧最大值取自下标 $4$，距离 $1$。相等，计入。

故答案为 $1$。

## 样例2

**输入**

```
4
2 2 2 2
```

**输出**

```
2
```

**说明**

读数全相等时，左右侧最大值均取与 $i$ 最近的并列位置。

- $i=2$：左侧取下标 $1$，右侧取下标 $3$，距离均为 $1$。
- $i=3$：左侧取下标 $2$，右侧取下标 $4$，距离均为 $1$。

两处均为等距测点，答案为 $2$。

## 样例3

**输入**

```
5
5 3 4 3 5
```

**输出**

```
1
```

**说明**

- $i=2$：左峰下标 $1$、距离 $1$；右峰下标 $5$、距离 $3$。不等。
- $i=3$：左峰下标 $1$、距离 $2$；右峰下标 $5$、距离 $2$。相等，计入。
- $i=4$：左峰下标 $1$、距离 $3$；右峰下标 $5$、距离 $1$。不等。

故答案为 $1$。
