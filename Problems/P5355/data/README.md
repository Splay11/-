# P5355 测试数据说明

共 $10$ 组。第一行 $q$，随后 $q$ 个询问（$m$ 与高度数组）。求最少相邻合并次数，使序列单调不减。无 $\sum m$ 限制，$q$ 最大 $25$、$m$ 最大 $5000$，必须保留多询问。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 | 基本合并 | 输出 $m-1$ |
| 2 | 样例2 | 递减后缀 | 从左贪心接最短段 |
| 3 | 样例3 $m=1$ | 边界 | 输出 $1$ |
| 4 | 已不降 | 答案 $0$ | 仍去合并 |
| 5 | 递减 | 必须并成两段或一段 | 少合并 |
| 6 | $(4,1,6,6)$ 等 | 最优切分 | 左贪心得到 $2$ |
| 7 | 短数组随机 | 与 $O(m^2)$ 对拍 | DP 转移漏 $j=0$ |
| 8 | 中等随机 | 对拍 | 最后一段和取大了 |
| 9 | $q=25,m=5000$ 随机 | 满询问 | $O(qm^2)$ 的 Python |
| 10 | $q=25,m=5000$ 递减 | 最坏合并 | $O(qm^2)$ |

前 $8$ 组可对拍；后 $2$ 组压复杂度。
