# 潮位并段

# 题目内容

滨海观测站把一昼夜拆成连续的 $m$ 个时段，第 $i$ 个时段记下的潮位高度是 $h_i$。归档规程要求整段记录从早到晚单调不减，否则后面的比对程序会拒绝入库。

值班员可以把两个**相邻**时段合成一个新时段，新时段的高度等于原来两段高度之和，原先的两个时段从序列里消失。这样每操作一次，序列长度减 `1`。

请计算：最少要合并多少次，才能让高度序列满足对所有相邻位置都有 $h_i\le h_{i+1}$。保证一定能做到（必要时可以把全部时段合成一段）。

输入会给出 $q$ 个独立的观测日，请对每一天分别给出答案。

约束：
- `1` $\le$ $q$ $\le$ $25$
- `1` $\le$ $m$ $\le$ $5\times 10^3$
- `1` $\le$ $h_i$ $\le$ `1000000000`

# 输入描述

第一行一个整数 $q$（`1` $\le$ $q$ $\le$ $25$），表示随后有多少个观测日。

对每一天：
- 第一行一个整数 $m$（`1` $\le$ $m$ $\le$ $5\times 10^3$），表示时段个数。
- 第二行 $m$ 个整数 $h_1,h_2,\ldots,h_m$（`1` $\le$ $h_i$ $\le$ `1000000000`），表示各时段潮位高度。

# 输出描述

输出 $q$ 行，每行一个整数，即该观测日的最少合并次数。

## 样例1

**输入**

```
3
3
5 2 6
3
1 3 8
4
4 1 6 6
```

**输出**

```
1
0
1
```

**说明**

- 第一天：把 `2` 与 `6` 合并得到 $(5,8)$，已经不减，操作 `1` 次。
- 第二天：本身已不减，操作 `0` 次。
- 第三天：把 `4` 与 `1` 合并得到 $(5,6,6)$，操作 `1` 次。若先把 `1` 与后面的 `6` 合并，剩下 $(4,7,6)$ 还要再合并，次数更多。

## 样例2

**输入**

```
2
3
9 8 7
5
6 3 3 1 8
```

**输出**

```
1
2
```

**说明**

- 第一天：把 `8` 与 `7` 合并得到 $(9,15)$，操作 `1` 次。
- 第二天：把中间三段 `3,3,1` 合成 `7`，得到 $(6,7,8)$，操作 `2` 次。

## 样例3

**输入**

```
1
1
12
```

**输出**

```
0
```

**说明**

只有一个时段，已经不减，无需合并。
