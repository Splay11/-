# 题目内容

小明有一个长度为 $n$ 的正整数数组 $a$。每次操作他可以选择一对相邻元素，将它们合并为一个新元素，新元素的值为两者之和。

小明想让数组变为单调不减（即对于所有相邻元素满足 $a_i \le a_{i+1}$）。请你帮他求出最少需要多少次操作。




# 输入描述


第一行一个正整数 $T$，表示测试数据组数。

对于每组测试数据：

第一行一个正整数 $n$，表示数组长度。

第二行 $n$ 个正整数 $a_1,a_2,\dots,a_n$，表示数组元素。

$1 \le n\le 5000$，$1 \le a_i\le 10^9$，$1 \le T\le 25$


# 输出描述

对于每组测试数据，输出一行一个整数，表示最少操作次数。




## 样例1 



**输入** 



```
3
4
3 1 2 4
4
1 2 3 4
5
4 2 3 1 5
```



**输出** 



```
1
0
2
```



**说明**

第一组：将 $a_2$ 和 $a_3$ 合并得到 $([3,3,4])$，已单调不减，操作 $1$ 次。

第二组：数组已经单调不减，不需要操作。

第三组：将 $a_2$,$a_3$ 合并，再将 $a_4$,$a_5$ 合并，得到 $([4,5,6])$，操作 $2$ 次。
