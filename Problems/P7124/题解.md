# 长度最小的子数组

算法标签：滑动窗口、双指针

算法难度：$5 / 10$

## 解题思路

数组里全是正整数，要找总和 $\ge target$ 的**最短连续段**。没有就输出 $0$。

1. 用滑动窗口：右端点 $r$ 从左到右扫，把 $nums_r$ 加进窗口和 $s$。
2. 一旦 $s\ge target$，就尝试把左端点 $l$ 右移。因为元素为正，左移只会让 $s$ 变小，所以可以一直缩，直到窗口刚好还满足（或再也满足不了）。每次满足时用 $r-l+1$ 更新最短长度。
3. 正数保证窗口具有单调性：更长的段和一定更大，因此每个端点最多进出一次，总复杂度是 $O(n)$。
4. 若扫完最短长度仍是哨兵（例如 $n+1$），说明整段和都小于 $target$，答案为 $0$。
5. $n\le 10^5$，暴力枚举左右端点是 $O(n^2)$，过不了。常见假解：找到第一段满足的就停（不一定最短）；或者把「最长公共子序列」那套 DP 搬过来。

## 复杂度分析

- 时间复杂度：$O(n)$。左右指针都只向右移动，每个位置最多被加入和移出一次。
- 空间复杂度：$O(1)$。除开存放数组本身，只需要窗口和、左右指针和当前答案。

$n=10^5$ 时线性扫描足够。

## 代码实现

### Python

```python
def min_subarray_len(nums, target):
    # 找总和 >= target 的最短连续段；没有则返回 0
    n = len(nums)
    s = 0
    left = 0
    # 用 n+1 当「还没找到」的哨兵
    ans = n + 1
    for right in range(n):
        # 右端点纳入窗口
        s += nums[right]
        # 元素为正，可以一直收缩左端点
        while s >= target:
            length = right - left + 1
            if length < ans:
                ans = length
            s -= nums[left]
            left += 1
    if ans == n + 1:
        return 0
    return ans


def main():
    # 第一行：n 和 target
    n, target = map(int, input().split())
    # 第二行：n 个正整数
    nums = list(map(int, input().split()))
    print(min_subarray_len(nums, target))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.StringTokenizer;

public class Main {
    // 找总和 >= target 的最短连续段；没有则返回 0
    static int minSubarrayLen(int[] nums, long target) {
        int n = nums.length;
        long s = 0;
        int left = 0;
        // 用 n+1 当「还没找到」的哨兵
        int ans = n + 1;
        for (int right = 0; right < n; right++) {
            // 右端点纳入窗口
            s += nums[right];
            // 元素为正，可以一直收缩左端点
            while (s >= target) {
                int length = right - left + 1;
                if (length < ans) {
                    ans = length;
                }
                s -= nums[left];
                left++;
            }
        }
        if (ans == n + 1) {
            return 0;
        }
        return ans;
    }

    public static void main(String[] args) throws IOException {
        // n 最大 1e5，用 BufferedReader 读入
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        long target = Long.parseLong(st.nextToken());
        st = new StringTokenizer(br.readLine());
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = Integer.parseInt(st.nextToken());
        }
        System.out.println(minSubarrayLen(nums, target));
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 找总和 >= target 的最短连续段；没有则返回 0
int minSubarrayLen(const vector<int>& nums, long long target) {
    int n = (int)nums.size();
    long long s = 0;
    int left = 0;
    // 用 n+1 当「还没找到」的哨兵
    int ans = n + 1;
    for (int right = 0; right < n; right++) {
        // 右端点纳入窗口
        s += nums[right];
        // 元素为正，可以一直收缩左端点
        while (s >= target) {
            int length = right - left + 1;
            if (length < ans) {
                ans = length;
            }
            s -= nums[left];
            left++;
        }
    }
    if (ans == n + 1) {
        return 0;
    }
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long target;
    cin >> n >> target;
    vector<int> nums(n);
    for (int i = 0; i < n; i++) {
        cin >> nums[i];
    }
    cout << minSubarrayLen(nums, target) << '\n';
```
