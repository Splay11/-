# P7124 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：第一行 `n target`，第二行 $n$ 个正整数。
输出：最短连续子数组长度；不存在则 $0$。

约束：$1 \le n \le 10^5$，$1 \le target \le 10^9$，$1 \le nums_i \le 10^4$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1，$n=6,target=7$ | 最短是 $4,3$，答案 $2$ | 找到第一段 $2,3,1,2$ 就停，误输出 $4$ |
| 2 | 样例 2，单元素已经够 | 答案 $1$ | 忽略长度为 $1$ 的合法段 |
| 3 | 样例 3，整段和仍不够 | 答案 $0$ | 没有解时误输出 $n$ 或最短正长度 |
| 4 | 最小规模，刚好等于 $target$ | 答案 $1$ | 单点相等却输出 $0$ |
| 5 | 最小规模，单点不够 | 答案 $0$ | 没有解时输出 $1$ |
| 6 | 必须取整段，$sum=15$ | 答案 $5$ | 漏掉右端或提前收缩导致无解 |
| 7 | hack：中间一个 $10$ 就够 | 答案 $1$，不是前面一长串 | 取到第一段和 $\ge target$ 就不再缩短 |
| 8 | 小随机，$n=12$，值较小 | 暴力可对拍 | 收缩条件写成 $>$ 而不是 $\ge$ |
| 9 | 压满 $n=10^5$，全 $1$，$target=50000$ | 答案必须是 $50000$ | $O(n^2)$ 会超时；错误二分会偏 $1$ |
| 10 | 压满 $n=10^5$，中间连续 $5$ 个 $10^4$ | 答案必须是 $3$（三个 $10000$ 刚好 $30000$） | 只看前缀/后缀，或把整段 $10^5$ 当答案 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：

1. 滑动窗口与「前缀和 + 二分」答案一致；
2. 第 $1\sim 8$ 组再用 $O(n^2)$ 暴力交叉校验。
