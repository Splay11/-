# 题目内容

给定一个包含 $n$ 个正整数的数组 $nums$ 和一个正整数 $target$。

请找出数组中满足元素总和大于等于 $target$ 的长度最小的连续子数组，并输出该子数组的长度。

设该子数组的左右端点分别为 $l$ 和 $r$，则子数组为 $nums_l,nums_{l+1},\ldots,nums_r$。

如果不存在满足条件的子数组，输出 $0$。

# 输入描述

第一行输入两个整数 $n$ 和 $target$，分别表示数组 $nums$ 的长度和目标值。

第二行输入 $n$ 个正整数 $nums_i$，表示数组中的各个元素，相邻整数之间用空格分隔。

### 约束

$1 \le target \le 10^9$

$1 \le n \le 10^5$

$1 \le nums_i \le 10^4$

# 输出描述

输出一个整数，表示元素总和大于等于 $target$ 的最短连续子数组的长度。

如果不存在满足条件的子数组，则输出 $0$。

## 样例 $1$

**输入**

```text
6 7
2 3 1 2 4 3
```

**输出**

```text
2
```

**说明**

连续子数组 $4,3$ 的元素总和为 $7$，满足总和大于等于 $target$ 的条件，并且它是满足条件的最短连续子数组，因此答案为 $2$。

## 样例 $2$

**输入**

```text
3 4
1 4 4
```

**输出**

```text
1
```

**说明**

单个元素 $4$ 已经满足总和大于等于 $target$，因此最短连续子数组的长度为 $1$。

## 样例 $3$

**输入**

```text
8 11
1 1 1 1 1 1 1 1
```

**输出**

```text
0
```

**说明**

整个数组的元素总和为 $8$，小于 $target=11$，因此不存在满足条件的连续子数组，输出 $0$。
