# 展廊灯带后缀点亮

## 解题思路

按下第 $i$ 段会翻转后缀 $i\sim m$，且不能回头。走到 $i$ 时，左边已经决定完，若当前实际状态还是 `0`，就只能在这里按，否则这盏灯再也无法改成 `1`。

1. 用变量 $\textit{flip}$ 记录已经按过的次数的奇偶（也就是当前后缀被翻转了几次）。
2. 第 $i$ 段的实际状态是 $b_i\oplus\textit{flip}$。若为 `0`，必须操作一次，并把 $\textit{flip}$ 取反。
3. 这样得到的方案是唯一合法方案，因此也是最少次数。

## 复杂度分析

- 时间复杂度：$O(m)$。
- 空间复杂度：$O(m)$。

## 代码实现

### Python

```python
def solve(n, a):
  # 从左到右扫，flip 表示左边已按次数的奇偶
  ans = 0
  flip = 0
  for x in a:
    cur = x ^ flip
    if cur == 0:
      # 现在是灭的，必须按，否则无法再改
      ans += 1
      flip ^= 1
  return ans


n = int(input())
a = list(map(int, input().split()))
print(solve(n, a))
```

### Java

```java
import java.io.*;

public class Main {
  static int solve(int n, int[] a) {
    // 从左到右扫，flip 表示左边已按次数的奇偶
    int ans = 0, flip = 0;
    for (int i = 0; i < n; i++) {
      int cur = a[i] ^ flip;
      if (cur == 0) {
        // 现在是灭的，必须按，否则无法再改
        ans++;
        flip ^= 1;
      }
    }
    return ans;
  }

  public static void main(String[] args) throws IOException {
    BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    int n = Integer.parseInt(br.readLine().trim());
    String[] sp = br.readLine().trim().split("\\s+");
    int[] a = new int[n];
    for (int i = 0; i < n; i++) a[i] = Integer.parseInt(sp[i]);
    System.out.println(solve(n, a));
  }
}
```

#include <bits/stdc++.h>
using namespace std;

int solve(int n, const vector<int>& a) {
  // 从左到右扫，flip 表示左边已按次数的奇偶
  int ans = 0, flip = 0;
  for (int i = 0; i < n; i++) {
    int cur = a[i] ^ flip;
    if (cur == 0) {
      // 现在是灭的，必须按，否则无法再改
      ans++;
      flip ^= 1;
    }
  }
  return ans;
}

int main() {
  ios::sync_with_stdio(false);
  cin.tie(nullptr);
  int n;
  cin >> n;
  vector<int> a(n);
  for (int i = 0; i < n; i++) cin >> a[i];
  cout << solve(n, a) << "\n";
  return 0;
}
