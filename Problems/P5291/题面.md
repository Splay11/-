# 题目内容

多多是一名数据中心的运维人员，他需要巡检一排共 $n$ 个机柜，从左到右编号为 $1$ 到 $n$。每个机柜有一盏状态指示灯，亮记为 $1$，灭记为 $0$。

第 $i$ 个机柜旁有一个联动按钮。按下后，第 $i$ 个到第 $n$ 个机柜的指示灯状态都会翻转：$1$ 变为 $0$，$0$ 变为 $1$。

多多从第 $1$ 个机柜开始，依次向右巡检。到达第 $i$ 个机柜时，他可以选择是否按下该联动按钮。一旦离开某个机柜，就不能再回到它左侧的机柜。

请计算：巡检结束后，要使所有指示灯都处于亮（$1$）状态，最少需要按下多少次按钮。

# 输入描述

第一行一个整数 $n$，表示机柜数量。

第二行 $n$ 个整数 $a_1,a_2,\ldots,a_n$，其中 $a_i\in\{0,1\}$，表示第 $i$ 盏指示灯的初始状态。

# 输出描述

输出一个整数，表示使所有指示灯变为 $1$ 的最少操作次数。

## 样例1

**输入**

```
2
1 0
```

**输出**

```
1
```

**说明**

只需按下第 $2$ 个机柜旁的按钮：$1\ 0\to 1\ 1$。

# 数据范围

- $1\le n\le 100000$
- $a_i$ 只能为 $0$ 或 $1$
- 所有输入均为整数
