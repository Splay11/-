# P5291 测试数据说明

输入：第一行 $n$，第二行 $n$ 个 `0`/`1`。输出：最少后缀翻转次数。`.in` 无多余换行，`.out` 恰好一个换行。

| 组别 | 分值 | 规模/分布 | 目标 | 卡掉的错误解 |
|---:|---:|---|---|---|
| 1 | 样例 | 原题 `1 0` | 格式 | 按第 `1` 个导致全灭 |
| 2 | 边界 | $n=1$，已是 `1` | 答案 $0$ | 强制按一次 |
| 3 | 边界 | $n=1$，是 `0` | 答案 $1$ | 输出 $0$ |
| 4 | 样例 | `0 1 0` | 必须按三次 | 只数 `0` 的个数得 $2$ |
| 5 | 构造 | 全 `0` | 按最左一次 | 每个 `0` 都按 |
| 6 | 构造 | 全 `1` | 零次 | 无端操作 |
| 7 | hack | `1 0` 交替 | 奇偶翻转累计 | 只统计 `0` |
| 8 | 随机 | $n=12$，暴力对拍 | 正确性 | 实现笔误 |
| 9 | 压力 | $n=10^5$ 随机 | 复杂度 | $O(n^2)$ 真翻转 |
| 10 | 压力+hack | 半段 `0` + 交替 | 满约束 | 同上 |
