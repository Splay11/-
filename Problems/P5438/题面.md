# 题目内容

多多有 $n$ 个魔法水晶，从左到右编号为 $1,2,\dots,n$。每颗水晶都蕴含着一个初始能量值 $a_i$。

根据魔法书上的描述，只有当所有水晶的能量值从左到右严格递增，即满足：$a_1 < a_2 < \dots < a_n$ 时，传送阵才能开启。

多多每次可以选择一颗水晶，向其注入一点魔法能量使其能量值增加1，或者抽取一点魔法能量使其能量值减少1。

多多今天早上睡过头了，为了能尽快到达魔法学院，多多想要用最少的操作次数来开启传送阵。由于多多刚起床意识还不太清醒，所以他向你寻求帮助。请你告诉多多最少需要的操作次数。




# 输入描述


第一行包含一个整数 $n$ ($1 \le n \le 2000$)，表示魔法水晶的数量。

第二行包含 $n$ 个整数 $a_1,a_2,\dots,a_n$ ($|a_i| \le 10^9$)，表示每颗水晶的初始能量值。


# 输出描述


输出一个整数，表示最少需要的操作次数。


## 样例1 



**输入** 



```
5
1 1 1 1 1
```



**输出** 



```
6
```



**说明**

可以将魔法水晶的魔法值序列调整成-1 0 1 2 3，总共需要
$|(1-(-1))|+|(1-0)|+|(1-1)|+|(1-2)|+|(1-3)| = 2+1+0+1+2 = 6$ 次操作

## 样例2



**输入** 



```
4
1 2 3 4
```



**输出** 



```
0
```



**说明**

无需操作即可开启传送阵
