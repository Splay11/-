# 题目内容

多多的配送站收到若干配送任务，每个任务都有开始时刻和结束时刻。任务执行期间需要由一名配送员全程负责，同一名配送员不能同时执行两个任务。

一个任务结束后，配送员可以立即接手另一个任务；
如果两个任务的结束时刻和开始时刻相同，可以由同一名配送员接续完成。所有任务都必须按给定时刻执行，不能提前或推迟。

请计算，完成全部任务至少需要安排多少名配送员，以及安排这些配送员后，所有配送员同时执行任务的累计时长。如果这样的时段有多段，需要将它们的长度相加。



# 输入描述


第一行输入一个整数 $n$，表示任务数，满足 $1 \le n \le 200000$。

接下来 $n$ 行，每行输入两个整数 $s,e$，分别表示一个任务的开始时刻和结束时刻，满足 $0 \le s < e \le 10^9$。

任务按任意顺序给出。时间相同的任务仍是不同任务，需要分别安排配送员。



# 输出描述

输出两个整数，依次表示所需配送员的最少人数，以及所有配送员同时执行任务的累计时长。




## 样例1 



**输入** 



```
5
1 4
2 3
3 5
4 6
6 7
```



**输出** 



```
2 3
```



**说明**

至少需要两名配送员。从时刻二到时刻五，始终有两个任务同时进行，累计时长为三；中间发生的任务交接不会中断这段忙碌时间。
