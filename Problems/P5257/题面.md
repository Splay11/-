# 题目内容


为迎接大促，多多推出了一款挑战小游戏，完成挑战的用户有机会获取免单。

小游戏中包含 $n$ 个节点和 $m$ 条单向边。节点的编号为 $1$ 到 $n$。

游戏中的边按输入顺序依次给出。第 $i$ 条边是一条从节点 $u_i$ 指向节点 $v_i$ 的单向边，通过该边可以获得 $w_i$ 点积分。图中可能存在自环或重边。

游戏的挑战规则：选择一条由连续边组成的路径，路径包含的边数越多，可以获得的奖励就越高。为了成功完成挑战，选择的路径必须满足以下条件：
1. 边的顺序：路径所经过的边，在输入数据中出现的顺序必须严格递增（即不能选择出现在当前边之前的边作为后续路径）。
2. 积分递增：路径上后续边获得的积分必须严格大于前一条边获得的积分。

请计算，能够获得最高奖励的路径最多可以包含多少条边？


# 输入描述

第一行包含两个整数 $(n,m)$ $(1 \le n \le 100000, 1 \le m \le 100000)$，分别表示图中的节点数和边数。

接下来 $m$ 行，第 $i$ 行包含三个由空格分隔的整数 $a_i,b_i,w_i$ $(1 \le a_i,b_i \le n, 0 \le w_i \le 100000)$，表示一条从节点 $a_i$ 到节点 $b_i$ 且权值为 $w_i$ 的有向边。




# 输出描述


输出一个整数，表示能够获得最高奖励的路径最大边数。



## 样例1 



**输入** 



```
3 3
3 1 3
1 2 1
2 3 2
```



**输出** 



```
2
```



**说明**

最优答案是 $2$，节点 $1 \to 2 \to 3$，一共两条边。需要注意，不能 $1 \to 2 \to 3 \to 1$，因为边 $(3,1)$ 在输入中比另外两条边更早出现，因此不能在经过另外两条边中的任何一条之后再选择它。


## 样例2

**输入**

```
5 5
1 3 2
3 2 3
3 4 5
5 4 0
4 5 8
```

**输出**

```
3
```

**说明**

一条合法路径为 $1 \to 3 \to 4 \to 5$，依次使用输入中的第 $1$、$3$、$5$ 条边（下标递增，积分 $2<5<8$），共 $3$ 条边。
