# 题目内容

学校组织了一场 “找朋友” 活动，有 N 个 A 班的同学和 N 个 B 班的同学参加。每个同学都有一个兴趣值，A 班同学的兴趣值分别为 $A_1,A_2,\dots,A_N$，B 班同学的兴趣值分别为 $B_1,B_2,\dots,B_N$。

活动规则如下：需要将 A 班和 B 班的同学一一配对成朋友。当 A 班序号为 i 的同学与 B 班序号为 \(p_i\) 的同学配对时，他们的 “矛盾值” 定义为

$(A_i+B_{p_i})\bmod M$其中 M 是一个给定的常数。矛盾值越小，说明两个同学越适合成为朋友。

作为活动组织者，你希望使所有参与的同学都有唯一的朋友，并且通过合理安排配对方案，使得所有配对的矛盾值之和最小，即

$\sum_{i=1}^N\big((A_i+B_{p_i})\bmod M\big)$的值最小，其中 p 是 1 到 n 的一个排列。请计算这个最小值。

有 T 组测试数据，请分别求出每组数据的答案。

# 输入描述

第一行为一个正整数 T，代表测试数据组数。 每组测试数据包含三行：

- 第一行有两个正整数 N 和 M。

- 第二行有 N 个整数，分别表示 $A_1,A_2,\dots,A_N$。

- 第三行有 N 个整数，分别表示 $B_1,B_2,\dots,B_N$。

  

$1\le T\le 10^5$

$1\le N\le 10^5$

$1\le M\le 10^9$

$0\le A_i,B_i<M$

所有测试数据的 N 之和不超过 $3\times 10^5$

# 输出描述

对于每组测试数据，输出一个整数，表示可能的最小矛盾值



## 样例1 

**输入** 

```
2
3 5
1 2 3
2 3 4
4 10
0 1 2 3
5 6 7 8
```

**输出** 

```
0
12
```

**说明**

对于第一组数据：

- A 班同学兴趣值：$A=[1,2,3]$
- B 班同学兴趣值：$B=[2,3,4]$
- 矛盾值常数：$M=5$

一种最优配对方案是：

- A 班第 3 个同学（兴趣值 3）与 B 班第 1 个同学（兴趣值 2）配对，矛盾值为 $(3+2)\bmod 5=0$
- A 班第 2 个同学（兴趣值 2）与 B 班第 2 个同学（兴趣值 3）配对，矛盾值为 $(2+3)\bmod 5=0$
- A 班第 1 个同学（兴趣值 1）与 B 班第 3 个同学（兴趣值 4）配对，矛盾值为 $(1+4)\bmod 5=0$

总矛盾值为 \(0+0+0=0\)。
