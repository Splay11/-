# 货柜编号对位最小残差

# 题目内容

中转仓今晚要把左右两排货柜一一对位。值班员必须按编号残差算出总偏差，并写成最小可达成的对位方案，好写进调度单。

左右两排各有 $k$ 个货柜。左排编号是 $x_1,x_2,\dots,x_k$，右排编号是 $y_1,y_2,\dots,y_k$。对位必须是一一配对：存在 $1$ 到 $k$ 的排列 $p$，把左排第 $i$ 个柜与右排第 $p_i$ 个柜配在一起。

一对货柜的残差定义为 $(x_i+y_{p_i})\bmod q$，其中 $q$ 是给定的模数。总偏差是所有配对残差之和，也就是

$\sum_{i=1}^{k}\bigl((x_i+y_{p_i})\bmod q\bigr)$。

请计算所有对位方案里，总偏差的最小值。

货柜数满足 $1 \le k \le$ `300000`，模数满足 $1 \le q \le$ `1000000000`，且 $0 \le x_i,y_i < q$。

# 输入描述

第一行两个正整数 $k$、$q$（$1 \le k \le$ `300000`，$1 \le q \le$ `1000000000`），表示每排货柜数和模数。

第二行 $k$ 个整数 $x_1,x_2,\dots,x_k$（$0 \le x_i < q$），表示左排编号。

第三行 $k$ 个整数 $y_1,y_2,\dots,y_k$（$0 \le y_i < q$），表示右排编号。

# 输出描述

输出一个整数，即最小总偏差。

## 样例1

**输入**

```
3 5
4 0 1
1 4 2
```

**输出**

```
2
```

**说明**

一种最优对位是 $4$ 配 $1$、$1$ 配 $4$、$0$ 配 $2$。残差分别是 $(4+1)\bmod 5=0$、$(1+4)\bmod 5=0$、$(0+2)\bmod 5=2$，总和为 `2`。

## 样例2

**输入**

```
1 10
3
4
```

**输出**

```
7
```

**说明**

只有一对，$3+4=7$，小于模数 `10`，残差就是 `7`。

## 样例3

**输入**

```
4 7
1 2 3 6
1 1 4 5
```

**输出**

```
2
```

**说明**

把 $6$ 配 $1$、$3$ 配 $4$、$2$ 配 $5$、$1$ 配 $1$，残差分别是 $0$、$0$、$0$、$2$，总和为 `2`。
