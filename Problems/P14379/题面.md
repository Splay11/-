# 作文批改后的最长无重复子串

你是一名小学英语老师，正在批改学生的英语作文。学生在书写时可能出现多余空格：需要去掉首尾空格，并把连续多个空格压缩为一个空格（单词之间最多保留一个空格）。

在批改后的字符串上，求**最长**的、**不含重复字符**的连续子串长度。判断重复时**忽略大小写**（例如 `a` 与 `A` 视为同一字符）。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def lengthOfLongestSubstring(self, story: str) -> int` |
| Java | `public int lengthOfLongestSubstring(String story)` |
| C++ | `int lengthOfLongestSubstring(string story)` |

**语义**：对 `story` 先做上述空格规范化，再在结果串上用滑动窗口求最长无重复子串长度（大小写不敏感判重）。若规范化后为空串，返回 `0`。

## 数据范围

- $0 \le \texttt{story.length} \le 1000$
- `story` 仅包含 ASCII 字符（$0$–$127$）

## 样例

### 样例 1

**输入**（stdin 为带双引号的 Python 风格字符串字面量，整行一条）：

```text
"Hello World!"
```

**输出**

```text
7
```

**说明**：规范化后为 `Hello World!`；最长无重复子串为 `World!`，长度为 $7$。

### 样例 2

**输入**

```text
" hi, jIn"
```

**输出**

```text
5
```

**说明**：去掉首尾空格并压缩中间空格后为 `hi, jIn`；最长无重复子串为 `, jIn`（长度为 $5$）。

## 评测输入输出

- **输入**：一行，为合法 Python 字符串字面量（双引号包裹，支持 `\"`、`\n` 等转义），表示原始作文 `story`。
- **输出**：一行一个非负整数，为答案；行末换行。
