# 交换字符使不同字符数相等

给定两个仅由小写字母组成的字符串 `resA` 和 `resB`。你可以**恰好执行一次**操作：选择下标 `i` 和 `j`，交换 `resA[i]` 与 `resB[j]`。

问是否存在一种交换，使交换后两个字符串中**不同字符的数量相等**。

- 若存在，返回交换后 `resA` 与 `resB` 中不同字符的数量（二者相等）；若有多种合法交换，取该数量**最小**的一种。
- 若不存在任何合法交换，返回 `-1`。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def minDistinctAfterSwap(self, resA: str, resB: str) -> int` |
| Java | `public int minDistinctAfterSwap(String resA, String resB)` |
| C++ | `int minDistinctAfterSwap(string resA, string resB)` |

**参数**

- `resA`、`resB`：仅含小写英文字母的字符串，$1 \le |resA|,\ |resB| \le 10^5$。

**返回值**

- 合法交换后两串共有的不同字符个数（取所有合法方案中的最小值）；无法达成则返回 `-1`。

## 输入输出格式（stdin / stdout）

**输入**（stdin 单行）：两个双引号包裹的字符串，逗号分隔（逗号后无空格）。

```text
"ac","b"
```

**输出**（stdout 一行）：一个整数。

```text
-1
```

## 数据范围

- $1 \le |resA|,\ |resB| \le 10^5$；
- `resA`、`resB` 仅由小写英文字母组成。

## 样例

### 样例 1

**输入**

```text
"ac","b"
```

**输出**

```text
-1
```

**说明**

无论交换哪一组下标，交换后第一个字符串都有 $2$ 个不同字符，第二个字符串只有 $1$ 个，无法相等。

### 样例 2

**输入**

```text
"abcc","aab"
```

**输出**

```text
2
```

**说明**

交换 `resA` 下标 $1$ 的 `'b'` 与 `resB` 下标 $0$ 的 `'a'`，得到 `resA = "aacc"`、`resB = "abb"`，各有 $2$ 个不同字符；且不存在更小的合法结果。

### 样例 3

**输入**

```text
"abcde","fghij"
```

**输出**

```text
5
```

**说明**

两串字符集不相交，任意一次交换后两串仍各有 $5$ 个不同字符。
