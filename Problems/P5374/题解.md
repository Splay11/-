# 仓格挪件

## 解题思路

货物总数不变，一开始全在 `1` 号货位。

1. 若 $\sum a_i \ne s$，直接不可能。
2. 最少搬运次数是必须离开 `1` 号的件数 $mn=s-a_1$。$t<mn$ 则不可能。
3. 多出来的 $t-mn$ 步是浪费：两个货位只能来回，浪费必须是偶数；三个及以上货位可以绕一圈，浪费也可以是奇数。已经到位时无法只多走 `1` 步。没有货或只有一个货位时，任何浪费都走不了。

## 复杂度分析

设货位数为 $n$。

时间复杂度为 $O(n)$。

空间复杂度为 $O(n)$。

## 代码实现

### Python

```python
def can_reach(n, s, t, a):
    # 物体总数必须对上；最少搬运次数是离开 1 号货位的件数
    if sum(a) != s:
        return False
    mn = s - a[0]
    if t < mn:
        return False
    extra = t - mn
    # 刚好最少次数，无需浪费
    if extra == 0:
        return True
    # 没有货或只有一个货位时，多出来的步数走不了
    if s == 0 or n == 1:
        return False
    # 两个货位只能来回，浪费步数必须是偶数
    if extra % 2 == 0:
        return True
    # 奇数步浪费需要第三个货位绕一下；已经到位时无法只多走 1 步
    if n < 3 or t == 1:
        return False
    return True


def main():
    n, s, t = map(int, input().split())
    a = list(map(int, input().split()))
    if can_reach(n, s, t, a):
        print("Yes")
    else:
        print("No")


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    static boolean canReach(int n, long s, long t, long[] a) {
        // 物体总数必须对上；最少搬运次数是离开 1 号货位的件数
        long sum = 0;
        for (int i = 0; i < n; i++) {
            sum += a[i];
        }
        if (sum != s) {
            return false;
        }
        long mn = s - a[0];
        if (t < mn) {
            return false;
        }
        long extra = t - mn;
        // 刚好最少次数，无需浪费
        if (extra == 0) {
            return true;
        }
        // 没有货或只有一个货位时，多出来的步数走不了
        if (s == 0 || n == 1) {
            return false;
        }
        // 两个货位只能来回，浪费步数必须是偶数
        if (extra % 2 == 0) {
            return true;
        }
        // 奇数步浪费需要第三个货位绕一下；已经到位时无法只多走 1 步
        if (n < 3 || t == 1) {
            return false;
        }
        return true;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long s = sc.nextLong();
        long t = sc.nextLong();
        long[] a = new long[n];
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextLong();
        }
        if (canReach(n, s, t, a)) {
            System.out.println("Yes");
        } else {
            System.out.println("No");
        }
        sc.close();
    }
}
```
