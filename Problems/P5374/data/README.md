# P5374 测试数据说明

共 $10$ 组。单组，$n$ 个货位，初始 $s$ 件全在 `1` 号，恰好 $t$ 次搬运后是否能变成 $a$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 三货位均分 | `Yes` | 总数判断错 |
| 2 | 样例2 两货位多 `1` 步 | `No` | 忽略奇偶 |
| 3 | 样例3 已到位走来回 | `Yes` | 认为已到位只能 $t=0$ |
| 4 | $n=1,t=0$ | `Yes` | |
| 5 | $n=1,t=1$ | `No` | 允许原地空搬 |
| 6 | 已到位 $t=1$ | `No` | 用三货位奇数浪费套到 $k=1$ |
| 7 | $s=0,t=2$ | `No` | 空库乱走 |
| 8 | $n=4$ 刚好最少 | `Yes` | $t\ge mn$ 当成充分 |
| 9 | $n=10^5$ 最少次数 | `Yes` 压测 | $O(n^2)$ |
| 10 | $n=10^5$ 空库 $t=10^{18}$ | `No` | `int` 溢出比较 |

前 $8$ 组小；后 $2$ 组压测。
