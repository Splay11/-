# 邻项合并归序

## 解题思路

本题考查**贪心**与**从右向左**维护后缀信息，将「最少合并次数」转化为一次线性扫描。

1. 合并只会减少数组长度，且合并后的新元素一定比被合并的右侧元素更大。因此从右向左处理时，只需关心当前位置右侧已经整理好的「代表值」。
2. 设从右向左扫描时，右侧已整理块的代表值为 $suf$（初始为极大值）。若当前 $v_i \le suf$，说明 $v_i$ 可以直接接在右侧块前面，令 $suf \leftarrow v_i$。
3. 若 $v_i > suf$，则 $v_i$ 与右侧相邻元素必然违反非降，**必须**把 $v_i$ 合并进右侧块，合并次数 $+1$，且合并后右侧块的代表值变为 $suf + v_i$（用 $64$ 位整型存储）。
4. 每个位置最多触发一次合并，答案即为扫描过程中合并次数之和。多组询问按题面格式逐组计算即可。

常见假解：

- 从左向右遇到逆序就立刻合并：例如 $[4,2,3,1,5]$ 会多合并，正解为 $2$ 次而非 $3$ 次；
- 用 $32$ 位整数累加合并后的和，在 $v_i$ 接近 $10^9$、多次合并时溢出；
- 误以为答案与元素个数 $n$ 无关而漏读多组询问。

## 复杂度分析

- 时间复杂度：每组 $O(n)$，共 $O\!\left(\sum n\right)$，在 $n \le 4\times 10^3$、$q \le 20$ 下足够。
- 空间复杂度：$O(n)$ 读入数组，或 $O(1)$ 额外空间（若边读边处理）。

## 代码实现

### Python

```python
def min_merges(v: list[int]) -> int:
  # 从右向左贪心：维护右侧块的代表值 suf，当前项过大则必须合并
  suf = 10**18
  ans = 0
  for x in reversed(v):
    if x <= suf:
      suf = x
    else:
      ans += 1
      suf += x
  return ans


def main() -> None:
  q = int(input())
  for _ in range(q):
    n = int(input())
    v = list(map(int, input().split()))
    print(min_merges(v))


if __name__ == "__main__":
  main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
  // 从右向左贪心：维护右侧块的代表值 suf，当前项过大则必须合并。
  static long minMerges(long[] v) {
    long suf = Long.MAX_VALUE / 4;
    long ans = 0;
    for (int i = v.length - 1; i >= 0; i--) {
      if (v[i] <= suf) {
        suf = v[i];
      } else {
        ans++;
        suf += v[i]; // 合并后右侧块变大，需 64 位
      }
    }
    return ans;
  }

  public static void main(String[] args) throws Exception {
    BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    int q = Integer.parseInt(br.readLine().trim());
    StringBuilder out = new StringBuilder();
    while (q-- > 0) {
      int n = Integer.parseInt(br.readLine().trim());
      StringTokenizer st = new StringTokenizer(br.readLine());
      long[] v = new long[n];
      for (int i = 0; i < n; i++) {
        v[i] = Long.parseLong(st.nextToken());
      }
      out.append(minMerges(v)).append('\n');
    }
    System.out.print(out);
  }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

using int64 = long long;

// 从右向左贪心：维护右侧块的代表值 suf，当前项过大则必须合并。
int64 min_merges(const vector<int64>& v) {
  int64 suf = LLONG_MAX;
  int64 ans = 0;
  for (int i = (int)v.size() - 1; i >= 0; --i) {
    if (v[i] <= suf) {
      suf = v[i];
    } else {
      ++ans;
      suf += v[i]; // 合并后右侧块变大，需 64 位
    }
  }
  return ans;
}

int main() {
  ios::sync_with_stdio(false);
  cin.tie(nullptr);

  int q;
  cin >> q;
  while (q--) {
    int n;
    cin >> n;
    vector<int64> v(n);
    for (int i = 0; i < n; ++i) {
      cin >> v[i];
    }
    cout << min_merges(v) << '\n';
  }
  return 0;
}
```
