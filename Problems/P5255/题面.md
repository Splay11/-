# 多多的神奇通道

# 题目内容

多多在游乐园里发现了一条神奇通道。彩色小球会按一定顺序从入口滚入，通道内有一块临时存放区，小球最终从出口滚出。

通道可能处于两种工作模式之一：

1. 队列模式：存放区按队列规则工作，先进入存放区的小球会先被取出（先进先出）。
2. 栈模式：存放区按栈规则工作，后进入存放区的小球会先被取出（后进先出）。

两种模式下流程相同：小球按字符串 $S$ 的顺序从入口一个一个滚入存放区；任意时刻都可以把存放区当前可取出的那一个小球（队列为队首，栈为栈顶）送到出口，也可以先让更多小球进入存放区。最终全部小球都要从出口滚出，形成字符串 $T$。

给定入场序列 $S$ 和出场序列 $T$，请判断通道使用的是哪种模式。

# 输入描述

第一行一个由小写字母组成的字符串 $S$，表示小球进入顺序。

第二行一个由小写字母组成的字符串 $T$，表示小球离开顺序。

$1 \le |S| = |T| \le 100000$

$S$ 与 $T$ 长度相同，且所含字符种类与出现次数均相同。

# 输出描述

输出一行字符串：

- 如果只能是队列模式，输出 `queue`
- 如果只能是栈模式，输出 `stack`
- 如果两种模式都可能，输出 `both`
- 如果两种模式都不可能，输出 `neither`

## 样例1

**输入**

```
abc
abc
```

**输出**

```
both
```

**说明**

队列模式：先进先出，依次进入再依次取出，得到 `abc`。

栈模式：`a` 进入后立即取出，`b` 进入后立即取出，`c` 进入后立即取出，也能得到 `abc`。

## 样例2

**输入**

```
abc
cba
```

**输出**

```
stack
```

**说明**

队列模式：只能得到 `abc`。

栈模式：全部进入后再依次弹出，得到 `cba`。

## 样例3

**输入**

```
abc
acb
```

**输出**

```
stack
```

**说明**

队列模式：只能得到 `abc`。

栈模式：`a` 进入后取出；再让 `b`、`c` 进入；先取出 `c` 再取出 `b`，得到 `acb`。

## 样例4

**输入**

```
abc
cab
```

**输出**

```
neither
```

**说明**

队列模式：只能得到 `abc`。

栈模式：若第一个出场的是 `c`，则 `a`、`b`、`c` 必须都已入栈，此时栈顶为 `c`、其下为 `b`，无法接着取出 `a` 得到 `cab`。
