# 充电桩调度与失败计数

某新能源公司有 $N$ 个充电桩和 $M$ 辆电动车需要充电。每辆车有预计到达时间 $AT$、充电时长 $CT$、最大可等待时长 $WT$（从到达后到**开始充电**的等待时间不能超过该值，否则车辆离开，无法完成充电）。

按下列**固定调度规则**模拟后，输出**未能成功完成充电**的车辆数量。

## 调度规则

1. 每个充电桩同一时间只能服务一辆车；初始时刻所有充电桩均空闲。
2. 车辆必须在到达时间 $AT$ 或之后才能开始充电；一旦开始充电不可中断。
3. 等待时间 $=$ 开始充电时刻 $-$ 到达时刻 $AT$，须满足 $\le WT$，否则该车辆充电失败。
4. 车辆到达后：若有充电桩在到达时刻已空闲，则**立即**占用其中一台开始充电；否则进入等待队列。
5. 某充电桩在时刻 $T$ 释放后：按**到达先后（FCFS）**检查等待队列队首车辆；若队首在 $T$ 时刻仍满足等待约束则占用该桩，否则队首失败出队并继续检查下一位，直到成功分配或队列为空。
6. 同一时刻若既有充电桩释放又有车辆到达：**先处理所有释放事件，再处理所有到达事件**，随后尽可能分配空闲桩。

**目标**：统计充电失败的车辆数（含等待超时离开者）。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def countFailedCharging(self, n: int, cars: List[List[int]]) -> int` |
| Java | `public int countFailedCharging(int n, int[][] cars)` |
| C++ | `int countFailedCharging(int n, vector<vector<int>>& cars)` |

**参数**：

- `n`：充电桩数量 $N$；
- `cars`：长度 $M$ 的列表/数组，每个元素为 `[AT, CT, WT]`（到达时间、充电时长、最大可等待时长），**下标顺序即车辆编号 $1\ldots M$ 的到达优先级 tie-break**（同到达时刻按编号小的优先）。

**返回值**：充电失败的车辆数量。

## 数据范围

- $1 \le N \le 100$，$1 \le M \le 1000$；
- $1 \le AT \le 10000$，$1 \le CT \le 10000$，$0 \le WT \le 10000$；
- `len(cars) == M`（与输入中的 $M$ 一致）。

## 样例

### 样例 1

**输入**（stdin 一行，无多余空格）：

```text
3,5,[[10,1,0],[10,1,0],[10,1,0],[10,1,0],[10,1,0]]
```

**输出**

```text
2
```

**说明**：$3$ 个桩、$5$ 辆车同时到达且 $WT=0$，仅 $3$ 辆能在时刻 $10$ 立即开充；后 $2$ 辆无法立即开充且不能等待，失败。

### 样例 2

**输入**

```text
2,4,[[1,10,0],[2,2,1],[3,1,0],[4,1,0]]
```

**输出**

```text
1
```

**说明**：车辆 $3$ 在时刻 $3$ 到达时无空闲桩且 $WT=0$ 失败；车辆 $4$ 在时刻 $4$ 占用刚释放的桩，成功。

## 评测输入输出

- **输入**：一行，格式 `N,M,[[AT1,CT1,WT1],...,[ATM,CTM,WTM]]`（嵌套列表为 Python/JSON 风格方括号整数列表，逗号分隔，**无空格**）。
- **输出**：一行一个非负整数，表示失败车辆数；行末换行。
