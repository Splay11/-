# 题目内容


小红有一个长度为 $n$ 的整数数组 $a$ 和一个整数 $k$。她想让数组 $a$ 里的元素进行配对，配对的两个数 $x$、$y$ 需要满足 $(x + k) \times (y + k)$ 是偶数。数组 $a$ 的每个元素最多配对一次。

小红想要尽可能多的配对，你能帮帮她吗？


# 输入描述

第一行两个整数$n$和$k$。

第二行$n$个整数$a_i$。

$1 \le n, k, a_i \le 10^6$



# 输出描述


第一行先输出一个整数$m$，表示最大的配对数。

接下来$m$行，每行两个整数，表示配对的两个数。

答案可以按任意顺序输出。如果有多解，输出任意一解即可通过。


## 样例1 



**输入** 



```
7 5
1 5 4 4 3 6 3
```



**输出** 



```
3
6 3
4 3
4 5
```
