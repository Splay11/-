# P5387 测试数据说明

共 $10$ 组。单组：$m$ 个正整数与常数 $t$，最大配对使 $(x+t)(y+t)$ 为偶数。多解，`check.cc` 按输入验证方案。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 | `2` 档 | 把两个奇类配在一起 |
| 2 | 样例2 $m=1$ | `0` | 输出空行或假配对 |
| 3 | 样例3 全偶类 | `2` | |
| 4 | 两个奇类 | `0` | 相邻就配 |
| 5 | 全偶类奇数个 | $\lfloor m/2\rfloor$ | 漏掉余 $1$ |
| 6 | $t$ 奇、值全偶 | `0` | 奇偶判断反了 |
| 7 | 奇类远多于偶类 | 档数=偶类个数 | 输出 $\lfloor m/2\rfloor$ |
| 8 | 随机 $m=40$ | 对拍 | 输出下标而不是值 |
| 9 | $m=1000000$ 全奇类 | `0` 压测 I/O | $O(m^2)$ |
| 10 | $m=1000000$ 随机 | 压测 | 超时、溢出 |

前 $8$ 组小；后 $2$ 组压测。
