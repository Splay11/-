# 供电区最大不均衡度

某电力公司管理 $N$ 个变电站节点（编号 $0$ 至 $N-1$），节点间通过 $M$ 条输电线路连接，**直接/间接相连的节点属于同一供电区**。

对节点数不少于 $2$ 的供电区，定义其**不均衡度**为：

$$\text{不均衡度} = (\text{区内最大负载} - \text{区内最小负载}) \times \text{节点数}$$

请找出所有供电区中不均衡度的**最大值**并返回。若无有效供电区（$M=0$，或所有连通块节点数均 $<2$），返回 $-1$。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def maxZoneImbalance(self, loads: List[int], edges: List[List[int]]) -> int` |
| Java | `public int maxZoneImbalance(int[] loads, int[][] edges)` |
| C++ | `int maxZoneImbalance(vector<int>& loads, vector<vector<int>>& edges)` |

**参数**

- `loads`：长度为 $N$ 的数组，`loads[i]` 为节点 $i$ 的负载（MW），$0 \le loads[i] \le 10^4$；
- `edges`：长度为 $M$ 的边列表，`edges[j] = [u, v]` 表示节点 $u$ 与 $v$ 之间有线路，$0 \le u, v \le N-1$，$u \ne v$，无重复边。

**返回值**

所有有效供电区不均衡度的最大值；若无有效供电区，返回 $-1$。

## 输入输出格式（stdin / stdout）

**输入**（stdin 整行：先 `loads` 一维数组，逗号后为 `edges` 二维数组；方括号、元素逗号无空格，与样例一致）：

```text
[100,200,150,50,300],[[0,1],[1,2],[3,4]]
```

**输出**（stdout 一行整数）：

```text
500
```

## 数据范围

- $1 \le N \le 100$；
- $0 \le M \le N(N-1)/2$；
- $0 \le loads[i] \le 10^4$；
- $0 \le edges[j][0], edges[j][1] \le N-1$，$edges[j][0] \ne edges[j][1]$，无重复边。

## 样例

### 样例 1

**输入**

```text
[100,200,150,50,300],[[0,1],[1,2],[3,4]]
```

**输出**

```text
500
```

**说明**

- 供电区 A：节点 $0,1,2$，负载 $[100,200,150]$，不均衡度 $=(200-100)\times 3=300$；
- 供电区 B：节点 $3,4$，负载 $[50,300]$，不均衡度 $=(300-50)\times 2=500$；
- 取最大值 $500$。

### 样例 2

**输入**

```text
[80,90,80,90],[[0,1],[1,2],[2,3]]
```

**输出**

```text
40
```

**说明**

$4$ 个节点连成 $1$ 个供电区，不均衡度 $=(90-80)\times 4=40$。

### 样例 3

**输入**

```text
[100,200,300],[]
```

**输出**

```text
-1
```

**说明**

$M=0$，各节点独立，无有效供电区，输出 $-1$。
