# 题目内容

在大型数据通信网络中，网络管理员需要分析流量在网络设备之间的传输路径。给定一系列的网络链路配置，其中每条链路表示一个连接关系 $\text{links}[i] = [\text{\(\text{source}\)}, \text{\(\text{destination}\)}]$，表示数据包从源设备($\text{\(\text{source}\)}$)发送到目标设备($\text{\(\text{destination}\)}$)。

请对该流量链路进行重新规划排序。所有这些链路都属于一个从核心交换机 $\text{\(\text{Core-SW-01}\)}$ 开始的流量流，因此该路径必须从 $\text{\(\text{Core-SW-01}\)}$ 开始。如果存在多种有效的流量路径，请按设备名称的字典排序返回最小的路径组合。

例如，路径 $["\text{\(\text{Core-SW-01}\)}", "\text{SW-A-1}"]$ 与 $["\text{\(\text{Core-SW-01}\)}", "\text{SW-B-1}"]$ 相比就更小，排序更靠前。

假定所有链路至少存在一种合理的路径规划。且所有的链路必须都用一次且只能用一次。

## 业务背景
在网络运维和流量分析场景中，网络设备之间形成了一张复杂的拓扑图。当网络中出现异常流量或进行网络架构优化时，需要明确流量在设备之间的传输序列。本题模拟了根据预配置的链路信息，还原流量在网络中的实际传输路径的过程。

SW-A SW-B
Core-SW-01 SW-A
Router-X Router-Y
SW-B Router-X

## 样例1 



**输入** 



```
Core-SW-01Switch-B
Core-SW-01 Switch-A
Switch-A Switch-B
Switch-A Core-SW-01
Switch-B Switch-A
```



**输出** 



```
Core-SW-01 Switch-A Core-SW-01 Switch-B Switch-A Switch-B
```




**说明**

输入形成的网络拓扑图如下：

![](file://3y3RmKyUW1DNWtKuF9hxf.png)


另一种有效的路径是：["Core-SW-01", "Switch-B", "Switch-A", "Core-SW-01", "Switch-A", "Switch-B"]，但是它的字典序更大，更靠后。

提示：在有多条可选链路时，优先选择目标设备名称字典序较小的链路进行跳转。

## 约束条件
- $1 \le \text{links.length} \le 300$
- $\text{links}[i].\text{length} == 2$
- $\text{links}[i][0]$ 和 $\text{links}[i][1]$ 由大写字母、数字、短横线组成
- 设备名称长度在 $1$ 到 $20$ 个字符之间
- 所有链路至少构成一条从 $\text{\(\text{Core-SW-01}\)}$ 开始的有效路径
