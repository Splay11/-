# 最长异色连续灯带

## 解题思路

异色带就是相邻色号都不相同的连续段。从左扫到右，同色就断开重计即可。

1. 用 $cur$ 记当前这段异色带长度，$best$ 记历史最长。
2. 若 $w_i \neq w_{i-1}$，当前段可以延长一格；否则从这一格重新开始，长度为 $1$。
3. 单字符一定合法，所以答案至少是 $1$。

## 复杂度分析

- 时间复杂度：$O(|w|)$。
- 空间复杂度：$O(|w|)$。

## 代码实现

### Python

```python
def solve(w):
  # 扫一遍，相邻同色就断开，统计当前段长度
  best = 1
  cur = 1
  for i in range(1, len(w)):
    if w[i] != w[i - 1]:
      cur += 1
      if cur > best:
        best = cur
    else:
      cur = 1
  return best


w = input().strip()
print(solve(w))
```

### Java

```java
import java.util.Scanner;

public class Main {
  static int solve(String w) {
    // 扫一遍，相邻同色就断开，统计当前段长度
    int best = 1;
    int cur = 1;
    for (int i = 1; i < w.length(); i++) {
      if (w.charAt(i) != w.charAt(i - 1)) {
        cur++;
        if (cur > best) best = cur;
      } else {
        cur = 1;
      }
    }
    return best;
  }

  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    String w = sc.next();
    System.out.println(solve(w));
    sc.close();
  }
}
```

### C++

```cpp
#include <iostream>
#include <string>
using namespace std;

int solve(string w) {
  // 扫一遍，相邻同色就断开，统计当前段长度
  int best = 1, cur = 1;
  for (int i = 1; i < (int)w.size(); i++) {
    if (w[i] != w[i - 1]) {
      cur++;
      if (cur > best) best = cur;
    } else {
      cur = 1;
    }
  }
  return best;
}

int main() {
  string w;
  cin >> w;
  cout << solve(w) << "\n";
  return 0;
}
```
