# 最长异色连续灯带

# 题目内容

灯带车间今晚要量一段展台灯带的可用长度。值班员必须找出最长的一段连续色号，使得相邻两格颜色都不同，并把这个长度写入工艺单。

灯带用小写字母串 $w$ 表示，每个字母是一种色号。一段非空连续子串如果任意两个相邻字符都不同，就称为一段异色带。请输出 $w$ 中最长异色带的长度。

串长满足 $1 \le |w| <$ `100000`，且 $w$ 只含小写字母。

# 输入描述

一行一个字符串 $w$（$1 \le |w| <$ `100000`），只含小写英文字母。

# 输出描述

输出一个整数，即最长异色带的长度。

## 样例1

**输入**

```
xyzzyx
```

**输出**

```
3
```

**说明**

`xyz` 与 `zyx` 都是长度为 `3` 的异色带。中间 `zz` 相邻同色，不能整段算进去。

## 样例2

**输入**

```
bbba
```

**输出**

```
2
```

**说明**

前面连续的 `b` 只能各算长度 `1`，`ba` 相邻不同，最长为 `2`。

## 样例3

**输入**

```
abcab
```

**输出**

```
5
```

**说明**

整串相邻都不相同，最长就是 $|w|=5$。
