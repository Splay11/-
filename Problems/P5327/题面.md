# 题目内容

多多是个热爱探险的小伙，有一次在山洞中探险发现一个神秘密码宝箱和一块刻着一串字母的石板，石板背面写着：

这串字母是由小写英文字母组成的字符串`s`，如果它的一个子串中任意两个相邻的字符都不同，则称该子串为**神秘子串**，密码就是字符串`s`中最长的神秘子串的长度。

请帮多多解出密码！

**补充说明**：“子串” 指非空连续子串

# 输入描述

一行一串字符串$s$，长度满足 $1 \le \text{length}(s) < 10^5$，仅包含小写英文字母。

# 输出描述

一个整数，表示最长神秘子串的长度。

## 样例1 

**输入** 

```
abbccd
```

**输出** 

```
2
```

**说明**

神秘子串有 "$ab$"(长度 $2$)、"$bc$"(长度 $2$)、"$bcc$" 中 $cc$ 相邻相同不符合，最长长度为 $2$。





## 样例2 

**输入** 

```
aaaa
```

**输出** 

```
1
```

**说明**

任意两个相邻字符都相同，每个单字符是最长的神秘子串，长度为 $1$。





## 样例3

**输入** 

```
abac
```

**输出** 

```
4
```
