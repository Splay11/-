# P7123 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：第一行 `n m`，第二行 $n$ 个整数（$nums1$），第三行 $m$ 个整数（$nums2$）。
输出：一个整数，最长公共子数组长度。

约束：$1 \le n,m \le 1000$，$0 \le nums1_i,nums2_i \le 100$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1，$n=m=5$ | 公共段 $3,2,1$，答案 $3$ | 把子数组理解成子序列以外的别的东西 |
| 2 | 样例 2，两数组完全相同 | 答案等于数组长度 $5$ | 漏掉整段相等、答案偏小 |
| 3 | 最小规模 $1\times1$，元素不同 | 答案 $0$ | 没有公共元素时误输出 $1$ 或数组长度 |
| 4 | 最小规模 $1\times1$，元素相同 | 答案 $1$ | 单点相等却输出 $0$ |
| 5 | 完全没有公共元素 | 答案 $0$ | 用 $\min(n,m)$ 当答案 |
| 6 | hack：子序列更长、子数组很短 | 公共子数组最长为 $1$，子序列却是 $3$ | 按 LCS 子序列做会输出 $3$ |
| 7 | 公共后缀，$n\ne m$ | 公共段 $1,2,3$，答案 $3$ | 只处理等长数组、或只看前缀 |
| 8 | 小随机，$15\times12$，值域 $[0,100]$ | 暴力可对拍 | 转移写反、忘记取全局最大值 |
| 9 | 压满 $1000\times1000$，一边全 $0$，另一边中间连续 $500$ 个 $0$ | 答案必须是 $500$ | 只比较整段或只取两端公共前缀/后缀 |
| 10 | 压满 $1000\times1000$ 随机，值域 $[0,100]$ | 压测 $O(nm)$ 与读入 | $O(n^2m)$ 枚举起点再匹配会超时 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：

1. 标程 DP 与滚动数组 DP 答案一致；
2. 第 $1\sim 8$ 组再用 $O(nmL)$ 暴力匹配交叉校验；
3. 第 $6$ 组确认 LCS 子序列答案为 $3$，而正确子数组答案为 $1$。
