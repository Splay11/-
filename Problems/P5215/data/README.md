| 编号 | 类型 | 说明 | 卡掉的错误解 |
|---:|---|---|---|
| 1 | 样例 | 样例1：整段最优展示公式 | 无 |
| 2 | 样例 | 样例2：整段最优，切开更差 | 无 |

| 4 | 边界 | 边界：全部相等，极差为 0 | 未处理全相等 |
