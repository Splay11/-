**9、下列关于进程管理说法错误的是（）**
{{ select(9) }}

**13、事务 T1 在 `READ COMMITTED` 隔离级别下两次执行同一条普通查询。两次查询之间，事务 T2 更新了其中一行并提交了事务。T1 第二次查询读到新值，最能解释这一现象的是?**
{{ select(13) }}
- 每条语句通常基于执行时已提交的可见版本判断
- 普通查询根据事务第一次读取到的版本继续判断可见性
- `READ COMMITTED` 在事务开始时固定一个供所有语句复用的快照
- 并发更新期间，数据库通过串行化访问避免两次查询出现差异

**15、系统使用分页存储管理。某进程访问一个页面，该页面已经建立虚拟地址映射，但当前不在物理内存中，且对应的磁盘内容有效。处理缺页异常时，最关键的顺序是?**

**16、对话式大模型采用因果注意力和 KV Cache。第 40 个位置的输入被修改，而第 41 个位置及其后的原始 token 均未改变。为保证后续生成使用正确上下文，通常应如何处理?**
{{ select(16) }}
- 使第 40 个位置的 KV 缓存失效，并从第 41 个位置继续复算
- 沿用第 40 个位置之后的缓存，因为后续 token 文本没有变化
- 保留输入侧缓存，只从新的最终输出位置开始计算
- 使第 40 个位置及其后的相关 KV 缓存失效，并从修改位置重新计算

**17、团队只更换了生成模型的 BPE 分词器，检索器、向量索引和候选文档排序均不变；上下文窗口仍按新分词器的 token 数限制。哪个处理最必要?**
{{ select(17) }}
- 生成侧分词器发生变化，重新建立向量索引以保持召回结果一致
- 候选排序保持不变，打包时沿用旧分词器的 token 计数
- 用新分词器重新计算候选片段、提示模板和分隔符的 token 占用
- 按照旧分词器记录的 token 下标确定新输入的截断位置

**18、推测解码中，小模型先生成候选 token，大模型逐个验证。若某一步大模型拒绝了候选 token，正确的处理原则是?**
{{ select(18) }}
- 丢弃被拒绝位置之后的小模型候选，并按校正后的大模型分布采样替代 token
- 依据小模型的下一个候选替换当前位置，再继续执行验证
- 接受该候选并继续验证后续 token，以减少一次目标模型计算
- 从被拒绝的位置重新生成整段草稿，再交给大模型验证
