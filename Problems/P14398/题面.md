# 进制转换与数值排序

给定一个非负整数数组 $nums$ 和一个目标进制 $base$（$2 \le base \le 16$），请完成以下操作并返回最终结果：

1. **进制转换**：将数组中每个整数转换为 $base$ 进制的字符串（$10$–$15$ 用小写字母 `a`–`f` 表示，如 $10 \to$ `"a"`，$15 \to$ `"f"`）；
2. **自定义排序**：对转换后的字符串数组，按各字符串在 $base$ 进制下对应的**十进制数值**降序排列；
3. $0$ 转换为任意进制的结果均为 `"0"`；输入整数均为非负整数。数值相同时，相对顺序不限。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def sortConvertedNums(self, nums: List[int], base: int) -> List[str]` |
| Java | `public String[] sortConvertedNums(int[] nums, int base)` |
| C++ | `vector<string> sortConvertedNums(vector<int>& nums, int base)` |

**参数**

- `nums`：非负整数数组，$1 \le |nums| \le 100$，$0 \le nums[i] \le 10^6$；
- `base`：目标进制，$2 \le base \le 16$。

**返回值**

按题意排序后的 $base$ 进制字符串数组。

## 输入输出格式（stdin / stdout）

**输入**（stdin 整行：先整数数组，逗号后为目标进制；数组用方括号、元素逗号无空格）：

```text
[10,25,3,15,8],16
```

**输出**（stdout 一行，双引号包裹元素的字符串数组，元素间逗号无空格）：

```text
["19","f","a","8","3"]
```

## 数据范围

- $1 \le nums.length \le 100$；
- $0 \le nums[i] \le 10^6$；
- $2 \le base \le 16$。

## 样例

### 样例 1

**输入**

```text
[10,25,3,15,8],16
```

**输出**

```text
["19","f","a","8","3"]
```

**说明**

- 进制转换：$10 \to$ `"a"`、$25 \to$ `"19"`、$3 \to$ `"3"`、$15 \to$ `"f"`、$8 \to$ `"8"`；
- 对应十进制值：$10$、$25$、$3$、$15$、$8$；
- 按数值降序：$25$（`"19"`）$\to$ $15$（`"f"`）$\to$ $10$（`"a"`）$\to$ $8$（`"8"`）$\to$ $3$（`"3"`）。

### 样例 2

**输入**

```text
[16,256,0,16],2
```

**输出**

```text
["100000000","10000","10000","0"]
```

**说明**

- 进制转换：$16 \to$ `"10000"`、$256 \to$ `"100000000"`、$0 \to$ `"0"`；
- 对应十进制值：$256 > 16 = 16 > 0$；
- 两个 `"10000"` 数值相同，顺序不限。
