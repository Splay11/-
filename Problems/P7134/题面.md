# 题目内容

系统中存在 $n$ 个进程，这些进程形成一棵有根树。

给定两个长度均为 $n$ 的整数数组 $pid$ 和 $ppid$，其中 $pid_i$ 表示第 $i$ 个进程的 $ID$，$ppid_i$ 表示第 $i$ 个进程的父进程 $ID$。

每个进程最多只有一个父进程，但可以拥有多个子进程。恰好有一个进程满足 $ppid_i=0$，表示该进程没有父进程，是整棵树的根进程。

当一个进程被终止时，它的所有子进程以及更深层的后代进程也都会被终止。

现在给定一个整数 $kill$，表示需要终止的进程 $ID$。请找出所有最终会被终止的进程。

为了便于输出，请将所有被终止的进程 $ID$ 按照从小到大的顺序输出。

# 输入描述

第一行输入两个整数 $n$ 和 $kill$，分别表示进程数量以及需要终止的进程 $ID$。

第二行输入 $n$ 个整数 $pid_i$，表示各个进程的 $ID$。

第三行输入 $n$ 个整数 $ppid_i$，其中 $ppid_i$ 表示进程 $pid_i$ 的父进程 $ID$。

### 约束

$1 \le n \le 5 \times 10^4$

$1 \le pid_i \le 5 \times 10^4$

$0 \le ppid_i \le 5 \times 10^4$

$pid$ 中所有进程 $ID$ 互不相同。

恰好有一个进程的父进程 $ID$ 为 $0$。

$kill$ 一定是 $pid$ 中存在的进程 $ID$。 

# 输出描述

输出一行，包含所有最终会被终止的进程 $ID$，并按照从小到大的顺序排列，相邻两个整数之间用空格分隔。

## 样例1

**输入**

```text
4 5
1 3 10 5
3 0 5 3
```

**输出**

```text
5 10
```

**说明**

进程 $3$ 是根进程，它的子进程为进程 $1$ 和进程 $5$，进程 $5$ 的子进程为进程 $10$。

当进程 $5$ 被终止时，它的后代进程 $10$ 也会被终止。

因此最终被终止的进程为 $5$ 和 $10$。

## 样例2

**输入**

```text
1 1
1
0
```

**输出**

```text
1
```

**说明**

系统中只有进程 $1$，且该进程没有子进程。
