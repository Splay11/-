# 石室铭文回程

# 题目内容

探险队沿洞穴石室寻路，按进入顺序走过 $m$ 间石室；第 $i$ 间石室壁上有一条铭文链表 $C_i$（$i=1,2,\ldots,m$），节点为铭文编号。出洞时须把沿途铭文收成一条链表带回地面，收纳顺序为后进先出：先接最后一间的 $C_m$，再接 $C_{m-1}$，直到最先进入的 $C_1$；每一间内部铭文的先后不变。空石室没有铭文。请给出带回地面的那条链表。

# 输入描述

读入一行，表示这 $m$ 条链表，形态为 `[{x,y,...},{...},...]`。每条链表用花括号按节点顺序列出整型值，彼此以逗号分隔；空链表写成 `{}`。

$1 \le m \le 250000$，全部节点个数之和不超过 $250000$，节点值为 $1$ 到 $1000000000$ 的正整型。

请对这一行输入计算拼接结果。

# 输出描述

写出一行，即拼接后的链表，形态为 `{...}`；若没有任何节点，写出 `{}`。

## 示例 1

**输入**

```
[{4,5},{9},{1,1,2}]
```

**输出**

```
{1,1,2,9,4,5}
```

**说明**

三间石室的铭文依次为 $\{4,5\}$、$\{9\}$、$\{1,1,2\}$。出洞后进先出：先接 $\{1,1,2\}$，再接 $\{9\}$，再接 $\{4,5\}$。各条内部顺序不改。

## 示例 2

**输入**

```
[{8},{},{2,2}]
```

**输出**

```
{2,2,8}
```

**说明**

中间一间是空石室，回程时直接跳过，结果由 $\{2,2\}$ 再接 $\{8\}$ 得到。
