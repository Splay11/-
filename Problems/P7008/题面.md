# 题目内容

小红有多条链表，她想将这些链表合并成一条链表。合并的方式是按照原来链表顺序的逆序依次拼接这些链表（每条链表内部的相对顺序保持不变）。保证所有链表的长度之和不超过 $200000$。

# 输入描述

输入一行，为一个链表数组，表示若干条链表。

格式为：`[{a,b,c},{d,e},...]`，其中每条链表用花括号列出节点值，空链表记为 `{}`。

# 输出描述

输出一行，表示按逆序拼接后得到的那条链表，格式为 `{...}`；若结果为空，输出 `{}`。

## 示例 1

**输入**

```
[{1,2,3},{3,4},{6,7,8}]
```

**输出**

```
{6,7,8,3,4,1,2,3}
```

## 示例 2

**输入**

```
[{6},{},{5}]
```

**输出**

```
{5,6}
```
