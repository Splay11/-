# 题目内容


博主 AK机发布了一组共 $n$ 篇笔记，每篇笔记有一个初始热度值 $a_i$（正数表示受欢迎，负数表示反响不佳）。

运营团队允许 AK机执行一次推流加倍操作：选择一个连续笔记区间 $[l,r](1 \le l \le r \le n)$，将该区间内所有笔记的热度值变为原来的两倍。当然，AK机也可以选择不执行此操作。

操作结束后（或不操作），AK机想知道连续笔记的最大热度总和是多少，即选择一段连续笔记，使其热度值之和最大。

注意：所选子段不能为空，至少包含一篇笔记。


# 输入描述

第一行一个正整数 $T(1 \le T \le 20)$，表示测试数据组数。

对于每组测试数据：
第一行一个正整数 $n(1 \le n \le 200000)$，表示笔记数量。
第二行 $n$ 个整数 $a_1,a_2,\dots,a_n(|a_i| \le 10^9)$，表示每篇笔记的初始热度值。

保证所有测试数据的 $n$ 之和不超过 $2 \times 10^5$。



# 输出描述

对于每组测试数据，输出一行一个整数，表示最大连续热度总和。




## 样例1 



**输入** 



```
1
5
1 -2 3 -1 2
```



**输出** 



```
8
```



**说明**

选择 $[3,5]$（即 $a_3,a_4,a_5 = 3,-1,2$）加倍，笔记热度变为 $[1,-2,6,-2,4]$。最大连续热度总和为 $6 + (-2) + 4 = 8$。
