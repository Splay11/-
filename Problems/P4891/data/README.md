# 数据生成说明

题面未给出显式数值上界；本地包采用：

- 小数据组（$1$–$8$）：$n$ 不超过几十，时间坐标在较小范围内。
- 大数据组（$9$–$10$）：$n=2\times 10^5$，时间坐标至 $10^{12}$ 量级。

| 组别 | 类型 | 说明 |
|---:|---|---|
| 1 | 小数据 | 样例：与题面一致，验证输入格式与端点包含规则。 |
| 2 | 小数据 | 边界：$n=1$，答案为 $1$。 |
| 3 | 小数据 | 构造：链式无交区间，贪心应取满。 |
| 4 | 小数据 | 构造：完全相同区间，卡重复计数与去重误用。 |
| 5 | 小数据 | hack：大区间挡在前面，正解按结束时间取两个小区间。 |
| 6 | 小数据 | hack：长区间包裹多段短区间，检验排序关键字是否为结束时间。 |
| 7 | 小数据 | 边界：相邻区间在公共端点处重叠，最多取 $1$。 |
| 8 | 小数据 | 随机：小规模混合分布，便于与暴力对拍。 |
| 9 | 大数据 | 大数据：$n=2\times 10^5$，时间坐标到 $10^9$，压测排序与扫描。 |
| 10 | 大数据 | 大数据：共用极大右端点，卡排序与整型范围。 |

主要针对的错误解法：

- 按开始时间或区间长度贪心。
- 把「端点相接」当成不冲突（应用 `>` 而不是 `>=` 判断衔接）。
- 排序关键字错误（按左端点或区间长度）。
- 坐标与累加使用 32 位整型溢出。
