# 储能舱对称配重

# 题目内容

某场站有 $n$ 个储能舱，第 $i$ 舱当前电量记为 $c_i$。运维希望各舱电量呈左右对称，即最终序列为**回文**：对所有 $1\le i\le n$ 均有 $c_i=c_{n+1-i}$。

每次操作可选两个不同下标 $i,j$，将 $1$ 单位电量从 $i$ 舱转到 $j$ 舱：$c_i\leftarrow c_i-1$，$c_j\leftarrow c_j+1$。

求使序列变为回文的最少操作次数；若不可能，输出 $-1$。

# 输入描述

第一行一个整数 $q$（$1\le q\le 100000$），表示询问个数。

每组询问：
- 第一行一个整数 $n$（$1\le n\le 200000$）；
- 第二行 $n$ 个正整数 $c_1,c_2,\ldots,c_n$（$1\le c_i\le 1000000000$）。

保证单个文件中所有询问的 $n$ 之和不超过 $500000$。

# 输出描述

对每个询问输出一行一个整数：最少操作次数，无解则 $-1$。

## 样例1

**输入**

```
3
4
3 1 4 2
2
2 2
3
4 2 9
```

**输出**

```
2
0
3
```

**说明**

电量总量守恒。第 $1$ 个询问总和 $10$，对称对差 $|3-2|+|1-4|=4$，最少 $\lceil 4/2\rceil=2$ 次。

第 $2$ 个询问已是回文，答案 $0$。

第 $3$ 个询问只需两端相等，差 $|4-9|=5$，最少 $\lceil 5/2\rceil=3$ 次（例如得到 $[6,2,6]$）。
