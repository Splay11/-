# 储能舱对称配重

## 解题思路

操作在储能舱之间转移 $1$ 单位电量，总量守恒，目标是变成回文且次数最少。

1. **可行性**：偶数长度时，回文序列总和必为偶数；若 $n$ 为偶数且 $\sum c$ 为奇数，无解，输出 $-1$。奇数长度总有解。
2. **配对**：最终必须 $c_i'=c_{n+1-i}$。对每个对称对 $(i,n+1-i)$，两端差值 $|c_i-c_{n+1-i}|$ 需要通过转移抹平。
3. **代价**：每次操作使某个舱 $+1$、另一舱 $-1$，全局最少次数等于所有对称对差值和的一半（向上取整），即 $\left\lceil\dfrac{\sum |c_i-c_{n+1-i}|}{2}\right\rceil$。奇数差额可通过中间舱或其他配对消化。

## 复杂度分析

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(1)$（不计输入）。

## 代码实现

### Python

```python
def solve(c):
    n = len(c)
    s = sum(c)
    # 偶数长 + 奇数和：无法形成整数回文
    if n % 2 == 0 and s % 2 == 1:
        return -1
    diff = 0
    for i in range(n // 2):
        # 统计每个对称对的绝对差
        diff += abs(c[i] - c[n - 1 - i])
    # ceil(diff/2)
    return (diff + 1) // 2


q = int(input())
for _ in range(q):
    n = int(input())
    c = list(map(int, input().split()))
    print(solve(c))
```

### Java

```java
import java.util.*;

public class Main {
    static long solve(long[] c) {
        int n = c.length;
        long s = 0;
        for (long x : c) s += x;
        if (n % 2 == 0 && s % 2 == 1) return -1;
        long diff = 0;
        for (int i = 0; i < n / 2; i++)
            diff += Math.abs(c[i] - c[n - 1 - i]);
        return (diff + 1) / 2;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int q = sc.nextInt();
        while (q-- > 0) {
            int n = sc.nextInt();
            long[] c = new long[n];
            for (int i = 0; i < n; i++) c[i] = sc.nextLong();
            System.out.println(solve(c));
        }
        sc.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

long long solve(const vector<long long>& c) {
    int n = (int)c.size();
    long long s = 0;
    for (auto x : c) s += x;
    if (n % 2 == 0 && s % 2 == 1) return -1;
    long long diff = 0;
    for (int i = 0; i < n / 2; i++)
        diff += abs(c[i] - c[n - 1 - i]);
    return (diff + 1) / 2;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q;
    cin >> q;
    while (q--) {
        int n;
        cin >> n;
        vector<long long> c(n);
        for (int i = 0; i < n; i++) cin >> c[i];
        cout << solve(c) << '\n';
    }
    return 0;
}
```
