# 同类单据冷却排期

## 解题思路

把出现次数最多的类型当作骨架，用冷却长度把它们拉开，其余类型去填空档。

1. 统计每种大写字母的出现次数，记最大次数为 $\textit{mx}$，达到 $\textit{mx}$ 的种类数为 $\textit{kinds}$。
2. 先排 $\textit{mx}$ 个「最高频」单据，相邻两次之间至少空出 $G$ 个位置，形成 $\textit{mx}-1$ 段，每段长度为 $G+1$，最后再并排放下 $\textit{kinds}$ 个并列最高频类型。骨架长度为 $(\textit{mx}-1)\times(G+1)+\textit{kinds}$。
3. 若其它单据填不满这些空档，答案就是骨架长度；否则没有空转，答案等于总张数 $P$。
4. 因此最短时间为 $\max\bigl(P,(\textit{mx}-1)\times(G+1)+\textit{kinds}\bigr)$。

## 复杂度分析

- 时间复杂度：$O(P)$。
- 空间复杂度：$O(1)$（只开 `26` 个计数器）。

## 代码实现

### Python

```python
def solve(n, s, m):
  # 只会出现 A-Z，用长度为 26 的数组计数
  cnt = [0] * 26
  for ch in s:
    cnt[ord(ch) - 65] += 1
  # mx：出现最多的次数；kinds：有多少种都达到这个次数
  mx = max(cnt)
  kinds = 0
  for c in cnt:
    if c == mx:
      kinds += 1
  # 最高频类型先占位：每两个之间空出 m 格，最后一轮放下 kinds 个并列最高频
  frame = (mx - 1) * (m + 1) + kinds
  # 其它单据若能填满空档，总时间不能短于总张数
  if frame > n:
    return frame
  return n


n = int(input())
s = input().strip()
m = int(input())
print(solve(n, s, m))
```

### Java

```java
import java.io.*;

public class Main {
  static int solve(int n, String s, int m) {
    // 只会出现 A-Z，用长度为 26 的数组计数
    int[] cnt = new int[26];
    for (int i = 0; i < s.length(); i++) {
      cnt[s.charAt(i) - 'A']++;
    }
    // mx：出现最多的次数；kinds：有多少种都达到这个次数
    int mx = 0;
    for (int c : cnt) {
      mx = Math.max(mx, c);
    }
    int kinds = 0;
    for (int c : cnt) {
      if (c == mx) kinds++;
    }
    // 最高频类型先占位：每两个之间空出 m 格，最后一轮放下 kinds 个并列最高频
    int frame = (mx - 1) * (m + 1) + kinds;
    // 其它单据若能填满空档，总时间不能短于总张数
    return Math.max(n, frame);
  }

  public static void main(String[] args) throws IOException {
    BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    int n = Integer.parseInt(br.readLine().trim());
    String s = br.readLine().trim();
    int m = Integer.parseInt(br.readLine().trim());
    System.out.println(solve(n, s, m));
  }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int solve(int n, const string& s, int m) {
  // 只会出现 A-Z，用长度为 26 的数组计数
  int cnt[26] = {0};
  for (char ch : s) cnt[ch - 'A']++;
  // mx：出现最多的次数；kinds：有多少种都达到这个次数
  int mx = 0;
  for (int i = 0; i < 26; i++) mx = max(mx, cnt[i]);
  int kinds = 0;
  for (int i = 0; i < 26; i++) {
    if (cnt[i] == mx) kinds++;
  }
  // 最高频类型先占位：每两个之间空出 m 格，最后一轮放下 kinds 个并列最高频
  int frame = (mx - 1) * (m + 1) + kinds;
  // 其它单据若能填满空档，总时间不能短于总张数
  return max(n, frame);
}

int main() {
  ios::sync_with_stdio(false);
  cin.tie(nullptr);
  int n, m;
  string s;
  cin >> n >> s >> m;
  cout << solve(n, s, m) << "\n";
  return 0;
}
```
