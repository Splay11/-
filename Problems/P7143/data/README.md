# P7143 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：一行英文句子（字母与空格）。
输出：单词平均长度，固定两位小数。

约束：$1\le |s|\le 10^4$，至少 $1$ 个单词。

题面原稿样例 $1$ 误写输出 $4.00$，已按 $(1+4+6)/3=3.67$ 纠正。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1，$11/3$ | $3.67$，不能先四舍五入成整数 | 输出 $4.00$ 或 $3$ |
| 2 | 样例 2，$11/4$ | $2.75$ | 整数除法得到 $2$ |
| 3 | 单个字母单词 | $1.00$，必须两位小数 | 输出 $1$ 或 $1.0$ |
| 4 | 单个长单词 | $5.00$ | 漏掉末尾单词 |
| 5 | 多个连续空格 | $(1+2+3)/3=2.00$ | 把空串当成单词得到更小平均值 |
| 6 | 首尾空格 | 只有两个单词 $leading$、$trailing$ | 把首尾空格切成空单词 |
| 7 | 大量单字母 | 平均值 $1.00$ | 按字符总数含空格去除 |
| 8 | 小随机、多空格、大小写混合 | 扫描与 $split$ 对拍 | 只读第一个单词 |
| 9 | 压满约 $10^4$，很多短单词 | 线性扫一遍 | $O(n^2)$ 反复拼接 |
| 10 | 压满约 $10^4$，少数长单词 | 长度累加不能用 $int$ 溢出（本题不会，但格式仍要两位小数） | 只统计单词个数忘记累加长度 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：手写扫描必须等于 $split$ 后求平均。
