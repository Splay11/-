# 题目内容

给定一句英文，请计算其中所有单词的平均长度。

一个单词定义为由英文字母组成的连续字符串。句子中的单词之间用空格分隔。

平均单词长度定义为所有单词长度之和除以单词个数。

结果保留两位小数输出。

# 输入描述

输入一行字符串 $s$，表示一句英文。

### 约束

$1 \le |s| \le 10^4$

字符串 $s$ 由大小写英文字母和空格组成。

句子中至少包含 $1$ 个单词。

单词之间由一个或多个空格分隔。

# 输出描述

输出一个实数，表示这句话中所有单词的平均长度。

结果保留两位小数。

## 样例1

**输入**

```text
I love coding
```

**输出**

```text
3.67
```

**说明**

这句话共有 $3$ 个单词，长度分别为 $1$、$4$、$6$。

平均长度为

$ (1+4+6) / 3 = 11/3 \approx 3.67 $

因此输出 $3.67$。

## 样例2

**输入**

```text
this is a test
```

**输出**

```text
2.75
```

**说明**

这句话共有 $4$ 个单词，长度分别为 $4$、$2$、$1$、$4$。

平均长度为

$ (4+2+1+4) / 4 = 11/4 = 2.75 $
