# InfoNCE（对比学习）

## 解题思路

1. 本题实现对比学习中的 $\mathrm{InfoNCE}$ 损失：每个 anchor $a_i$ 的正样本是同下标的 $p_i$，其余 $p_j$ 作为负样本（batch 内对比，非双向 CLIP）。
2. 先对 $A$、$P$ 按行做 $L2$ 归一化，得到余弦相似度矩阵，再整体除以温度 $\tau$。
3. 对每一行做数值稳定的 $\log\mathrm{softmax}$（自然对数），取对角位置作为正样本对数概率，再对 $n$ 个样本取负平均。
4. 在 `Solution.infoNCE` 中用矩阵乘法一次算出全部相似度，并用减行最大值的方式保证数值稳定。

## 复杂度分析

- 时间复杂度：$O(n^2 d)$，主要来自 $n \times n$ 相似度矩阵。
- 空间复杂度：$O(n^2)$，用于存放相似度。

## 代码实现

### Python

```python
from typing import List
import numpy as np


class Solution:
    def infoNCE(self, A: List[List[float]], P: List[List[float]], tau: float) -> float:
        """计算 batch 内 anchor-positive 的 InfoNCE 损失（自然对数）。"""
        A = np.asarray(A, dtype=np.float64)
        P = np.asarray(P, dtype=np.float64)
        n = A.shape[0]
        # L2 归一化后做余弦相似度，再除以温度
        An = A / np.linalg.norm(A, axis=1, keepdims=True)
        Pn = P / np.linalg.norm(P, axis=1, keepdims=True)
        sim = (An @ Pn.T) / tau
        # 数值稳定的 log-softmax：对角为正样本
        row_max = sim.max(axis=1, keepdims=True)
        lse = row_max.ravel() + np.log(np.exp(sim - row_max).sum(axis=1))
        pos = sim[np.arange(n), np.arange(n)]
        loss = -float(np.mean(pos - lse))
        return loss
```
