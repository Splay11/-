# P7126 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：第一行 `n`，接下来 $n$ 行 `start end`。
输出：`YES` 或 `NO`。结束时刻等于下一场开始时刻不算冲突。

约束：$1 \le n \le 10^4$，$0 \le start_i < end_i \le 10^4$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1 | 有重叠，答案 NO | 没检查 $1\sim3$ 与 $2\sim6$ |
| 2 | 样例 2，首尾相接 | 答案 YES | 把结束时刻等于开始时刻判成冲突 |
| 3 | 样例 3，输入未排序 | 答案 YES | 按输入顺序只比相邻，未排序会误判 |
| 4 | 最小规模 $n=1$ | 答案 YES | 单场还判冲突 |
| 5 | 完全包含 | 答案 NO | 只判断起点落在开区间内、漏掉被包含的短区间 |
| 6 | 多场首尾相接 | 答案 YES | 连锁相接却输出 NO |
| 7 | 乱序且中间有重叠 | 排序后 $0\sim3,3\sim6,5\sim9$，答案 NO | 直接输出 YES |
| 8 | 小随机，若干段相接或留缝 | 暴力两两判断可对拍 | 比较写成 $\le$ 把相接当冲突 |
| 9 | 压满 $n=10^4$，每场 $[i,i+1)$，打乱顺序 | 全部相接，答案 YES | $O(n^2)$ 可能超时；不排序会乱 |
| 10 | 压满 $n=10^4$，其中一场 $[100,250)$ 覆盖一长串 | 答案 NO | 只看输入相邻两项，打乱后漏判 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：排序扫描与「按起点排序后维护上一结束时刻」一致；第 $1\sim 8$ 组再用两两暴力交叉校验。
