# 安全策略最优组合

在云服务中，有 $n$ 个安全策略，编号 $1$ 到 $n$。每个策略有一个重要度权重（正整数）。某些策略对之间互斥，不能同时启用。

现在需要为某个实例**恰好选择** $k$ **个策略**，要求：

1. 选中的策略之间没有互斥关系（即构成图上的独立集）；
2. 在满足条件 1 的所有大小为 $k$ 的策略组合中，使选中策略的权重之和最大；
3. 返回所有达到最大权重和的最优组合。

## 输出规则

- 每个组合内的策略编号按**升序**排列；
- 所有组合按**字典序**排列（将每个组合视为整数序列比较）；
- 若不存在大小为 $k$ 的合法独立集，返回空数组 `[]`。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def selectMaxWeightPolicies(self, n: int, k: int, weights: List[int], conflicts: List[List[int]]) -> List[List[int]]` |
| Java | `public List<List<Integer>> selectMaxWeightPolicies(int n, int k, int[] weights, int[][] conflicts)` |
| C++ | `vector<vector<int>> selectMaxWeightPolicies(int n, int k, vector<int>& weights, vector<vector<int>>& conflicts)` |

**参数**

- `n`：策略总数，$1 \le n \le 25$；
- `k`：需要选择的策略数量，$0 \le k \le n$；
- `weights`：长度为 $n$ 的数组，`weights[i]` 为策略 $i+1$ 的权重，$1 \le weights[i] \le 1000$；
- `conflicts`：互斥边列表，每条为 `[a, b]`（$1 \le a, b \le n$，$a \ne b$），表示策略 $a$ 与 $b$ 无向互斥，无重复边。

**返回值**

二维整数数组：每个内层数组为一个最优策略编号组合（升序）；外层数组按字典序排列。无合法解时返回 `[]`。

## 输入输出格式（stdin / stdout）

**输入**（stdin **一行**：`n`、英文逗号、`k`、英文逗号、一维权重数组、英文逗号、二维互斥数组；方括号内元素逗号分隔、无空格，与样例一致）：

```text
4,2,[5,1,3,4],[[1,2],[2,3]]
```

**输出**（stdout **一行**：二维整数数组，内层与外层均用方括号，元素逗号无空格）：

```text
[[1,4]]
```

## 数据范围

- $1 \le n \le 25$；
- $0 \le k \le n$；
- $1 \le weights[i] \le 1000$；
- $0 \le conflicts.length \le n(n-1)/2$。

## 样例

### 样例 1

**输入**

```text
4,2,[5,1,3,4],[[1,2],[2,3]]
```

**输出**

```text
[[1,4]]
```

**说明**

所有大小为 $2$ 的策略组合及互斥检查：

| 组合 | 是否互斥 | 权重和 |
| ---- | -------- | ------ |
| [1,2] | 是 (1-2 冲突) | 非法 |
| [1,3] | 否 | 5+3=8 |
| [1,4] | 否 | 5+4=9 |
| [2,3] | 是 (2-3 冲突) | 非法 |
| [2,4] | 否 | 1+4=5 |
| [3,4] | 否 | 3+4=7 |

权重和最大为 $9$，对应组合 $[1,4]$，故输出 `[[1,4]]`。

### 样例 2

**输入**

```text
5,3,[3,4,3,4,3],[[1,3],[2,4],[3,5]]
```

**输出**

```text
[[1,2,5],[1,4,5]]
```

**说明**

合法的大小为 $3$ 的组合仅 $[1,2,5]$ 与 $[1,4,5]$，权重和均为 $10$ 且为最大值；按字典序输出。

### 样例 3

**输入**

```text
3,2,[10,10,10],[[1,2],[1,3],[2,3]]
```

**输出**

```text
[]
```

**说明**

三张策略两两互斥，不存在大小为 $2$ 的独立集。
