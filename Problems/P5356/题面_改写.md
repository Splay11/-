# 系统结构与数据工程核对卷

上线前用本卷过一遍流水线冒险、UML、封装、索引变形、哈希冲突与过拟合等基础点。均为单选题，每题只选一项。

**1、巡检工单引擎要把“受理—分派—闭环”写成可复用流程。模板方法模式的典型特征是？**
{{ select(1) }}
- 运行时动态替换整个类层次，不再保留父类骨架
- 用观察者在每个步骤结束时广播事件，算法顺序由监听方决定
- 父类定义算法骨架，子类实现某些步骤
- 把各步骤拆成互不调用的独立工具函数，由调用方自行拼接

**2、访客登记要把证件号写成不可认的假号码再入库。数据脱敏技术中，将敏感信息替换为虚构数据的方法称为？**
{{ select(2) }}
- 替换
- 差分隐私加噪后仍保留可逆明文
- 哈希加盐后当作加密存储，必要时再解密还原
- 按行删除整张登记表以消除敏感字段

**3、指令流水线在相邻两条指令之间发生数据冒险。不能通过以下哪种方式解决？**
{{ select(3) }}
- 用编译器重排无关指令，拉开写后读的距离
- 增加指令长度
- 把尚未写回的结果经旁路送到后续指令
- 在相关指令之间插入空操作等待写回完成

**4、场馆订座大表要清掉过期订单。对大型表执行 DELETE 时，为避免一次性占用过多资源，最佳实践是？**
{{ select(4) }}
- 先把整库导出再执行 DROP DATABASE
- 把 DELETE 改成没有 WHERE 的全表字段重写
- 关掉事务日志，直接在磁盘上抹掉数据文件
- 在事务中使用分批删除

**5、货架模型里“仓间拥有若干货位”。在面向对象编程中，以下哪种特性描述了对象之间的拥有关系？**
{{ select(5) }}
- 抽象类必须声明为 final，禁止再派生子类
- 静态方法不能被任何对象调用
- 接口不能声明方法，只能存放常量
- 组合

**6、票务库原始查询为 `SELECT * FROM tickets WHERE fee_amt/100 > 5000`。优化后的等价写法是？**
{{ select(6) }}
- WHERE fee_amt > 5000*100
- WHERE fee_amt + 100 > 5000
- WHERE ABS(fee_amt) > 5000
- WHERE fee_amt/1000 > 5000

**7、网关把每个入站连接交给工作线程处理。以下关于进程与线程的说法中，哪一项是正确的？**
{{ select(7) }}
- 同一进程里的线程绝不能共享堆上的对象
- 进程切换时不必保存寄存器，因为线程会代为保存
- 每个进程和线程都有独立的程序计数器
- 用户态线程一旦崩溃，操作系统会自动重启整台机器

**8、要列出巡检平台对外提供的功能清单。最适合使用下列哪种 UML 图进行建模？**
{{ select(8) }}
- 部署图，只画内存条和网线的连接关系
- 用例图
- 状态图，只描述数据库事务隔离级别切换
- 构件图，用来画出神经网络每一层的张量形状

**9、图像质检模型已经在训练集上拟合过强。防止过拟合的方法不包括以下哪个？**
{{ select(9) }}
- 增加模型层数
- 在验证损失抬头时提前停止训练
- 增大训练样本的多样性与扰动
- 使用权重衰减限制参数幅度

**10、货号数组长度为 $k$，用基数排序。基数为 $r$，最大位数为 $p$，且每层分配和收集的时间复杂度为 $O(k+r)$。该算法的空间复杂度是？**
{{ select(10) }}
- $O(r!)$
- $O(k + r)$
- $O(p^{k})$
- $O(\log k)$

**11、场馆储值卡的点数必须受控增减。我们应该使用以下哪种设计？**
{{ select(11) }}
- 将点数属性声明为私有，并提供公共的deposit和withdraw方法来修改点数
- 把点数做成全局常量，所有卡实例共用同一个值
- 把点数做成公开字段，任意类都可以直接改写
- 只提供打印方法，不允许任何变更入口

**12、缓存服务用哈希表存字段。关于哈希表冲突处理，下述说法错误的是哪个？**
{{ select(12) }}
- 发生哈希冲突时，在哈希表中寻找下一个空闲位置来存储数据也是链地址法的一种
- 哈希表在装载因子合适时，平均查找可以接近常数时间
- 链地址法是为每个槽维护溢出链，与开放寻址不是同一类策略
- 开放寻址法把冲突记录探查到表内下一个空槽，不必为每个槽额外挂指针

**13、班组表 `crew` 中至少有 3 人。执行 `SELECT staff_nm, pay_amt, RANK() OVER (ORDER BY pay_amt DESC) FROM crew;` 前两名 `pay_amt` 相同且为全表最高，第三高严格低于前两名。薪资第三高的这名员工，结果里的排名值是？**
{{ select(13) }}
- 3
- 0
- 4
- 空字符串

**14、检索服务要按键值区间扫一批缓存项。以下哪种结构不支持范围查询？**
{{ select(14) }}
- 跳表按键有序，可以从某键扫到另一键
- Redis的哈希表结构
- B 树叶子有序，支持区间查找
- 有序平衡树可以按中序取出一段键

**15、把训练任务弹性调度到共享算力池。以下哪项不属于云计算的核心特点？**
{{ select(15) }}
- 资源不可共享
- 资源池化后多租户共用底层算力
- 用量可计量并按使用量结算
- 服务能力可按负载快速伸缩
