# 题目内容

实现数值稳定的交叉熵损失及其梯度计算。

给定 $N$ 个样本的 $K$ 分类 logits 和真实标签，计算：

1. 每个样本的交叉熵损失。
2. 平均损失。
3. 损失对 logits 的梯度。

损失公式：$\mathrm{CE}_i = -z_{i,y_i} + \log\sum_j e^{z_{ij}}$。

梯度公式：$\mathrm{grad} = \mathrm{softmax}(z) - \mathrm{one\_hot}(y)$。

# 输入描述

第一行包含两个整数 $N, K$（$1 \le N \le 100$，$2 \le K \le 10$），表示样本数和类别数。

接下来 $N$ 行，每行 $K$ 个浮点数，表示每个样本的 logits。

最后一行包含 $N$ 个整数 $y_1, y_2, \ldots, y_N$（$0 \le y_i < K$），表示每个样本的真实类别。

# 输出描述

输出三部分：

1. 第一行：$N$ 个浮点数，表示每个样本的交叉熵损失，保留 $2$ 位小数。
2. 第二行：$1$ 个浮点数，表示平均损失，保留 $2$ 位小数。
3. 接下来 $N$ 行：每行 $K$ 个浮点数，表示梯度矩阵，保留 $2$ 位小数。

## 样例 $1$

**输入**

```text
2 3
1.0 2.0 3.0
0.0 0.0 0.0
2 1
```

**输出**

```text
0.41 1.10
0.75
0.09 0.24 -0.33
0.33 -0.67 0.33
```

**说明**

样本 1（$\mathrm{logits} = [1, 2, 3]$，标签 $= 2$）：$\mathrm{Softmax} = [0.090, 0.245, 0.665]$，损失 $= -\log(0.665) = 0.408$，梯度 $= [0.090 - 0, 0.245 - 0, 0.665 - 1] = [0.090, 0.245, -0.335]$。

样本 2（$\mathrm{logits} = [0, 0, 0]$，标签 $= 1$）：$\mathrm{Softmax} = [0.333, 0.333, 0.333]$，损失 $= -\log(0.333) = 1.099$，梯度 $= [0.333 - 0, 0.333 - 1, 0.333 - 0]$。

