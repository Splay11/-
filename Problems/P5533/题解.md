# 交叉熵损失与梯度

## 解题思路

本题计算多分类交叉熵及其对 logits 的梯度，接口为 `Solution.crossEntropy(logits, labels)`。

1. 对每个样本用 log-sum-exp 稳定计算 $\mathrm{CE}_i=-z_{i,y_i}+\log\sum_j e^{z_{ij}}$。
2. 平均损失为各样本损失的均值。
3. 梯度 $\mathrm{grad}=\mathrm{softmax}(z)-\mathrm{one\_hot}(y)$，其中 softmax 同样基于减最大值的稳定实现。

## 复杂度分析

时间复杂度为 $O(NK)$。

空间复杂度为 $O(NK)$。

## 代码实现

### Python

```python
import math


class Solution:
    def crossEntropy(self, logits, labels):
        """数值稳定交叉熵：返回 per-sample 损失、平均损失、对 logits 的梯度。"""
        n = len(logits)
        k = len(logits[0])
        losses = []
        grads = []
        for i in range(n):
            z = logits[i]
            # log-sum-exp：先减最大值保证数值稳定
            m = max(z)
            exps = [math.exp(v - m) for v in z]
            s = sum(exps)
            # CE = -z_y + logsumexp(z)
            loss = -z[labels[i]] + m + math.log(s)
            losses.append(loss)
            sm = [e / s for e in exps]
            # grad = softmax - one_hot(y)
            g = list(sm)
            g[labels[i]] -= 1.0
            grads.append(g)
        avg = sum(losses) / n
        return losses, avg, grads
```
