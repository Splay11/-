# 题目内容

请你在仅使用 $numpy / pandas / scikit‑learn$ 的前提下，实现一个带固定随机过程的随机子空间 $Bagging$ 分类器，并对测试集输出预测结果。

给定训练集与测试集，类别标签为非负整数。
你需要训练若干个基分类器，每个基分类器都由下列部分组成：
- 一次 $bootstrap$ 采样
- 一次 随机特征子集采样
- 一个 最近质心分类器

## 训练规则
设训练集特征矩阵为 $X \in \mathbb{R}^{n\times d}$，标签为 $y$。

输入中给出：
- $n\_estimators =$ $T$
- $max\_features =$ $m$
- $seed$

你必须使用：$rg = np.random.RandomState(seed)$，并按如下顺序构造每个基分类器。

1. **Bootstrap 采样**
第 $t$ 个基分类器从训练集做一次有放回采样，样本数仍为 $n$：$i_1,i_2,\dots,i_n$
要求使用：$idx = rg.randint(0, n, size=n)$

2. **随机特征子集**
然后从 $d$ 个特征中无放回随机选出 $max\_features =$ $m$ 个特征，要求使用：$feat = rg.choice(d, size=m, replace=False)$，并将选出的特征下标按升序保存。

3. **最近质心分类器**
在该 $bootstrap$ 样本、该特征子集上，对每个类别 $c$ 计算质心：
$$
\mu_c=\frac{1}{N_c}\sum_{x_i\in c}x_i
$$
其中 $N_c$ 是该 $bootstrap$ 样本中类别 $c$ 的出现次数。

对测试样本 $x$，基分类器预测为：
$$
\hat y=\arg\min_{c}\|x^{(feat)}-\mu_c\|_2^2
$$
即使用平方欧氏距离最近的质心。
若多个类别距离完全相同，输出类别标签数值更小的那个。

本题必须严格遵守以下规则。

**规则1：缺失类别处理**
某个 $bootstrap$ 样本里，某个类别可能一次都没出现。
若类别 $c$ 在当前 $bootstrap$ 样本中缺失，则该类别质心不能删掉，而是改用：原始完整训练集上该类别在同一特征子集下的全局质心。

**规则2：投票规则**
所有基分类器都对测试样本预测一个类别。最终结果用多数投票：
$$
\hat y=\arg\max_{c}\text{vote}(c)
$$
若票数并列，输出类别标签数值更小的那个。



# 输入描述

标准输入为 $JSON$，格式如下：
```json
{
    "train": [[f11, f12, ..., y1],
              [f21, f22, ..., y2],
              ...],
    "test": [[g11, g12, ...],
             [g21, g22, ...],
             ...],
    "n_estimators": 5,
    "max_features": 1,
    "seed": 42
}
```

说明：
- $train$：二维列表 $((n,d+1))$，每行最后一列为类别标签
- $test$：二维列表 $((m,d))$，仅包含特征
- $n\_estimators$：基分类器个数
- $max\_features$：每个基分类器选取的特征数
- $seed$：固定随机种子
- 标签为非负整数
- 输入数据保证合法，且 $1 \le \text{max\_features} \le d$，$(1<n,m<20)$，$1\le d<10$




# 输出描述

输出仅为一个 $JSON$ 对象，格式如下：
```json
{
    "features": [[1], [0], [0]],
    "bootstraps": [[2,3,0,2], [3,0,0,2], [2,2,2,2]],
    "pred": [0,1,0]
}
```

你需要输出：
1. $features$：每个基分类器使用的特征下标列表
2. $bootstraps$：每个基分类器的 $bootstrap$ 下标列表
3. $pred$：测试集最终预测标签

要求：
- $features$ 中每个子数组为升序特征下标
- $bootstraps$ 中每个子数组长度等于训练样本数
- $pred$ 顺序与输入测试集一致
- 输出格式中的符号、空格、换行等参考示例的输出

### 补充说明
- 仅允许使用 $numpy / pandas / scikit‑learn$
- 距离使用平方欧氏距离
- 缺失类别时使用完整训练集上的全局质心
- 多数投票并列时取更小类别编号
