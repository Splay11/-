# 线性层

## 解题思路

本题实现全连接层前向：$Y = XW + b$。

1. 将输入 $X$（$N \times d_{in}$）、权重 $W$（$d_{in} \times d_{out}$）与偏置 $b$（$d_{out}$）转为矩阵。
2. 做矩阵乘法 $XW$，再把 $b$ 按行广播加到每个样本上。
3. 用 `numpy` 完成矩阵运算，结果按题面保留 $6$ 位小数输出。

## 复杂度分析

- 时间复杂度：$O(N \cdot d_{in} \cdot d_{out})$
- 空间复杂度：$O(N \cdot d_{out})$

## 代码实现

### Python

```python
import numpy as np


class Solution:
    def linear(self, X, W, b):
        # Y = X W + b，b 沿 batch 广播
        X = np.asarray(X, dtype=np.float64)
        W = np.asarray(W, dtype=np.float64)
        b = np.asarray(b, dtype=np.float64)
        return X @ W + b
```
