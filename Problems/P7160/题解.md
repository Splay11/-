# 存在重复元素

算法标签：哈希表、数组

算法难度：$2 / 10$

## 解题思路

判断数组里有没有某个数至少出现两次。$n$ 到 $10^5$，需要线性时间。

1. 用哈希集合记下已经见过的数。
2. 从左到右扫：当前数已在集合里就输出 $true$。
3. 扫完都没撞上，输出 $false$。
4. 常见假解：只检查相邻两项是否相等（没排序时会漏）；先排序再扫相邻，正确但多一次 $O(n\log n)$，不是必须；输出大写 $True$。

## 复杂度分析

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
def solve(nums):
    """用集合记下已经出现过的数。
    扫到某个数已经在集合里，说明至少出现两次，存在重复。
    全部扫完都没撞上，则互不相同。
    """
    seen = set()
    for x in nums:
        if x in seen:
            return True
        seen.add(x)
    return False


def main():
    # 第一行 n，第二行 n 个整数
    n = int(input())
    nums = list(map(int, input().split()))
    # 题面要求输出小写 true / false
    print("true" if solve(nums) else "false")


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.HashSet;
import java.util.StringTokenizer;

public class Main {
    // 用哈希表记录出现过的数，再次出现就是有重复
    static boolean solve(int[] nums) {
        HashSet<Integer> seen = new HashSet<Integer>();
        for (int i = 0; i < nums.length; i++) {
            if (seen.contains(nums[i])) {
                return true;
            }
            seen.add(nums[i]);
        }
        return false;
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());
        StringTokenizer st = new StringTokenizer(br.readLine());
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = Integer.parseInt(st.nextToken());
        }
        // 题面要求输出小写 true / false
        System.out.println(solve(nums) ? "true" : "false");
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <unordered_set>
using namespace std;

// 用哈希表记录出现过的数，再次出现就是有重复
bool solve(const vector<int>& nums) {
    unordered_set<int> seen;
    for (int i = 0; i < (int)nums.size(); i++) {
        if (seen.count(nums[i])) {
            return true;
        }
        seen.insert(nums[i]);
    }
    return false;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> nums(n);
    for (int i = 0; i < n; i++) {
        cin >> nums[i];
    }
    cout << (solve(nums) ? "true" : "false") << '\n';
    return 0;
}
```
