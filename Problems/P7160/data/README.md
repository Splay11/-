# P7160 测试数据说明

主造数脚本：题目根目录 `gen.py`。输出小写 true/false。
约束：$1\le n\le 10^5$，$-10^9\le nums_i\le 10^9$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1，末尾重复 | true | 只看相邻得到 false |
| 2 | 样例 2，全不同 | false | 输出 true |
| 3 | 样例 3，多处重复 | true | 去重后比长度 |
| 4 | n=1 | false | 输出 true |
| 5 | 负数重复 | true | 没处理负数 |
| 6 | 值域两端且不同 | false | 溢出当相同 |
| 7 | 重复不在相邻位置 | true | 只比较相邻 |
| 8 | 中等随机 | 与集合对拍 | O(n^2) 后面 TLE |
| 9 | 压满 n=10^5 全不同 | false | O(n^2) TLE |
| 10 | 压满 n=10^5 最后两数相同 | true | 只查前半段 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。
