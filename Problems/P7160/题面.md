# 题目内容

给定一个包含 $n$ 个整数的数组 $nums$。

如果数组中任意一个元素至少出现两次，则认为数组中存在重复元素。

如果数组中的所有元素都互不相同，则认为数组中不存在重复元素。

请判断数组 $nums$ 中是否存在重复元素。

# 输入描述

第一行输入一个整数 $n$，表示数组 $nums$ 的长度。

第二行输入 $n$ 个整数 $nums_i$，表示数组中的各个元素，相邻整数之间用空格分隔。

### 约束

$1 \le n \le 10^5$

$-10^9 \le nums_i \le 10^9$

# 输出描述

如果数组中存在至少出现两次的元素，输出 $true$。

如果数组中的所有元素都互不相同，输出 $false$。

## 样例1

**输入**

```text
4
1 2 3 1
```

**输出**

```text
true
```

**说明**

元素 $1$ 在数组中出现了 $2$ 次，因此数组中存在重复元素，输出 $true$。

## 样例2

**输入**

```text
4
1 2 3 4
```

**输出**

```text
false
```

**说明**

数组中的所有元素都只出现了 $1$ 次，彼此互不相同，因此输出 $false$。

## 样例3

**输入**

```text
10
1 1 1 3 3 4 3 2 4 2
```

**输出**

```text
true
```

**说明**

数组中存在多个重复出现的元素，因此输出 $true$。
