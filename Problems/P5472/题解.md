# 答案与解析

## 一、单选题

**1、答案：C**

快速选择平均线性时间即可找到中位数，复杂度为 $O(n)$。直接取下标、枚举排列、多重嵌套排序都不是该算法的平均界。

**2、答案：C**

UDP 提供无连接、端口寻址和校验和。可靠交付和流量控制是 TCP 的服务，UDP 不包括。

**3、答案：B**

非抢占 SJF：0 时刻只有 J1，跑完到 8；就绪里最短是 J3，再到 9；接着最短 J5 到 11；J4 与 J2 时长相同，按原题口径选 J4 再 J2。顺序为 J1→J3→J5→J4→J2。

**4、答案：C**

两个对象构造后静态 `cnt=2`。先 `dump(3)` 输出 $2+3=5$，再 `dump()` 输出 2，合在一起是 $52$。

**5、答案：D**

避免死锁（如银行家算法）动态检查安全状态，利用率和吞吐量较好。一次分光全部仪器、随机杀进程、忽略互斥，都会伤吞吐或直接出错。

**6、答案：B**

`substring(3,5)` 左闭右开，取下标 3、4，即 `DE`。

**7、答案：B**

`chmod` 改权限，`-R` 递归。`chgrp`、`umask`、`ls` 都不是改目录树权限的正确做法。

**8、答案：C**

`InputStream` 是字节输入流，用于读取二进制。写字符、序列化输出、按 UTF-16 编码，都不是它的职责。

**9、答案：C**

`joined` 由变量拼接得到，与常量池里的 `"ab"` 不是同一引用，`==` 为 `false`。

**10、答案：D**

`Leaf` 私有继承 `Mid` 后，沿继承链进来的数据成员与相关成员都落入私有侧，个数为 4。

**11、答案：D**

Linux 的 `select` 默认可监视的文件描述符数量有上限（1024）。它能盯 TCP/UDP，也支持超时，不必在内核线程里调用。

**12、答案：B**

右撇子树不是完全树，用一维数组会大量空位。邻接表、一般树、拉链哈希更常用链式结构，这里问的不宜项仍是右撇子树。

**13、答案：B**

双引号会展开变量，`echo "$JOBSLOT"` 才能打出环境变量值。单列名字、`unset`、只 `grep` 环境表，都不是正确输出方式。

**14、答案：C**

JDK8 之后静态变量在方法区（元空间）一侧。不是寄存器、线程栈或指令缓存。

**15、答案：D**

删掉所有 `pp` 后的长度差再除以 2，得到出现次数。只数 `p`、只看子串长度或原串长度，都得不到次数。

**16、答案：C**

等价路由按 metric 选，数值较小者优先。MAC 字典序、区域号、登录名都不是内核的依据。

**17、答案：B**

视图可更新的前提是与基表行一一对应。带 `UNION`、再套 `DISTINCT`、只加 `ORDER BY` 都不能保证可更新。

## 二、多选题

**18、答案：B、D**

Prim 从顶点扩张，并且是贪心。分治、先对边做并查集连通，都不是 Prim 的特征。

**19、答案：B、C、D**

`cnt` 初值 1。T1 加一、T2 减一。完整串行会得到 1；交错读写会得到 0 或 2。无法得到 3。

**20、答案：A、B、C、D**

SAT、01 背包、顶点覆盖、TSP 都可以在多项式时间验证解，都属于 NP。
