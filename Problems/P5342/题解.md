# 偏振脉冲核销

## 解题思路

每次操作删掉相邻的 `01` 或 `10`，等价于同时去掉一个 `0` 和一个 `1`。

1. 若串里既有 `0` 又有 `1`，两种字符的分界处一定出现相邻异对，所以一定还能继续删。
2. 于是操作会一直进行到只剩一种字符，或变成空串。剩下的字符个数是 $|c_0-c_1|$。
3. 能变成空串，当且仅当 $c_0=c_1$，也就是 `0` 的个数等于 `1` 的个数。
4. 对每条串数一遍两种字符即可，不必真的模拟删除。
5. 长度是奇数时两个计数不可能相等，可以直接判否，但数一遍已经足够。

## 复杂度分析

设所有字符串长度之和为 $L$。

时间复杂度为 $O(L)$，每条串扫一次。

空间复杂度为 $O(1)$ 额外空间（不计读入的字符串本身）。

## 代码实现

### Python

```python
def can_clear(s):
    # 每次核销都同时去掉一个 0 和一个 1
    # 只要两种字符都还在，串里一定存在相邻的 01 或 10
    # 所以能删空当且仅当 0 和 1 的个数相等
    return s.count("0") == s.count("1")


def count_clearable(strs):
    ans = 0
    for s in strs:
        if can_clear(s):
            ans += 1
    return ans


def main():
    m = int(input())
    strs = []
    for _ in range(m):
        strs.append(input().strip())
    print(count_clearable(strs))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Main {
    static boolean canClear(String s) {
        // 每次核销都同时去掉一个 0 和一个 1
        // 只要两种字符都还在，串里一定存在相邻的 01 或 10
        // 所以能删空当且仅当 0 和 1 的个数相等
        int c0 = 0, c1 = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '0') {
                c0++;
            } else {
                c1++;
            }
        }
        return c0 == c1;
    }

    static int countClearable(List<String> strs) {
        int ans = 0;
        for (int i = 0; i < strs.size(); i++) {
            if (canClear(strs.get(i))) {
                ans++;
            }
        }
        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        List<String> strs = new ArrayList<String>();
        for (int i = 0; i < m; i++) {
            strs.add(sc.next());
        }
        System.out.println(countClearable(strs));
        sc.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

bool can_clear(const string& s) {
    // 每次核销都同时去掉一个 0 和一个 1
    // 只要两种字符都还在，串里一定存在相邻的 01 或 10
    // 所以能删空当且仅当 0 和 1 的个数相等
    int c0 = 0, c1 = 0;
    for (size_t i = 0; i < s.size(); i++) {
        if (s[i] == '0') {
            c0++;
        } else {
            c1++;
        }
    }
    return c0 == c1;
}

int count_clearable(const vector<string>& strs) {
    int ans = 0;
    for (size_t i = 0; i < strs.size(); i++) {
        if (can_clear(strs[i])) {
            ans++;
        }
    }
    return ans;
}

int main() {
    // 总长度可能到 500000，关闭同步以免读入超时
    ios::sync_with_stdio(false);
    cin.tie(0);
    int m;
    cin >> m;
    vector<string> strs(m);
    for (int i = 0; i < m; i++) {
        cin >> strs[i];
    }
    cout << count_clearable(strs) << endl;
    return 0;
}
```
