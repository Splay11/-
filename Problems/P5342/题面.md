# 题目内容

给定若干仅由 $0$ 和 $1$ 构成的字符串。我们允许你对字符串重复进行如下操作：
- 从相邻位置中，选择一对不同字符（即 "$01$" 或 "$10$"），将其同时删除，剩余部分拼接在一起。

如果一个字符串通过若干次（也可以为 $0$ 次）上述操作后，能够变为空串，则称这个字符串为“可删去”。对于每组测试数据，请计算有多少个字符串是可删去的。




# 输入描述

输入一个整数 $n$，表示字符串数量 $(1 \le n \le 2 \times 10^5)$；

随后 $n$ 行，每行输入一个仅由 $0$ 和 $1$ 组成的字符串，其长度在 $[1,10^5]$ 内。

保证所有字符串长度的总和不超过 $5 \times 10^5$。



# 输出描述


在一行上输出一个整数，表示其中“可删去”的字符串数量。


## 样例1 



**输入** 



```
5
0
1
01
0011
010
```



**输出** 



```
2
```



**说明**

字符串 "$01$"：一次删除 "$01$"，变为空串，可删去；

字符串 "$0011$"：可依次删除中间的 "$01$"，再删除剩下的 "$01$"，可删去；

字符串 "$0$"、"$1$"、"$010$" 均无法全部删空（最后会剩下至少一个字符）。
