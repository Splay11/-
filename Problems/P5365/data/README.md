# P5365 测试数据说明

共 $10$ 组。第一行 $q$，随后每份调度单三行。输出 $q$ 个最多放行条数。所有 $m$ 之和 $\le 200000$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 | 去掉相向一对后剩 $3$ | 区间重叠就禁 |
| 2 | 样例2 同起点 | $t=0$ 算撞 | 忽略起点重合 |
| 3 | 样例3 单艇 | 答案 `1` | 输出 `0` |
| 4 | 四点同起点 | 答案 `1` | 按终点 LIS 多选 |
| 5 | 起点终点都递增 | 答案 $m$ | 乱判相撞 |
| 6 | 终点递减 | 答案 `1` | 输出 $m$ |
| 7 | $n=10$ 随机 | 与 $2^n$ 对拍 | 碰撞条件写反 |
| 8 | $q=5$ 小单 | 多询问 | 没清空 LIS |
| 9 | $m=2\times 10^5$ 递增 | 压测 | $O(m^2)$ TLE |
| 10 | $m=2\times 10^5$ 递减 | 压测答案 `1` | TLE |

前 $8$ 组小；后 $2$ 组压测。
