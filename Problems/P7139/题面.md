# 题目内容

给定一个由小写英文字母组成的字符串 $s$，请统计字符串 $s$ 中回文子串的数量。

回文字符串是指正着读和倒着读完全相同的字符串。

子字符串是字符串中由连续字符组成的一个序列。

需要注意的是，即使两个回文子串的内容相同，只要它们在原字符串中的位置不同，也需要分别计数。

# 输入描述

输入一行字符串 $s$，表示给定的字符串。

### 约束

$1 \le |s| \le 1000$

字符串 $s$ 仅由小写英文字母组成。

# 输出描述

输出一个整数，表示字符串 $s$ 中回文子串的数量。

## 样例1

**输入**

```text
abc
```

**输出**

```text
3
```

**说明**

字符串 $s$ 中共有 $3$ 个回文子串，分别为 $a$、$b$ 和 $c$。

因此答案为 $3$。

## 样例2

**输入**

```text
aaa
```

**输出**

```text
6
```

**说明**

长度为 $1$ 的回文子串共有 $3$ 个，分别对应字符串中的三个字符 $a$。

长度为 $2$ 的回文子串共有 $2$ 个，分别为第 $1$、第 $2$ 个字符组成的 $aa$，以及第 $2$、第 $3$ 个字符组成的 $aa$。

长度为 $3$ 的回文子串共有 $1$ 个，即 $aaa$。

因此回文子串总数为

$3+2+1=6$。
