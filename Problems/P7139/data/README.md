# P7139 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：一行小写字符串 $s$。
输出：回文子串个数（按出现位置计数）。

约束：$1\le |s|\le 1000$，$s$ 仅含小写英文字母。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1 | 三个单字符，答案 $3$ | 把 $abc$ 整串也算进去 |
| 2 | 样例 2 | 按位置计 $6$ 个，不去重 | 按内容去重只输出 $3$ |
| 3 | 单字符 | 答案 $1$ | 输出 $0$ |
| 4 | 偶数回文 $abba$、$bb$ | 单字符 $4$ 个加 $bb$、$abba$，共 $6$ | 漏掉偶数中心 |
| 5 | 奇数回文 $aba$ | 单字符 $3$ 个加 $aba$，共 $4$ | 漏掉跨中心的 $aba$ |
| 6 | 更长回文 | 中心扩张与 DP 对拍 | 只统计最长回文 |
| 7 | 小随机 $n=40$ | 扩张与区间 DP 对拍 | 子序列也当成子串 |
| 8 | 压满 $n=1000$，全是 $a$ | 全部子串都是回文，答案 $n(n+1)/2=500500$ | int 溢出或只数了 $n$ 个单字符 |
| 9 | 压满 $n=1000$，$ab$ 交替 | 几乎只有单字符和极少偶数回文 | 把 $aba$ 漏计或多重计 |
| 10 | 压满 $n=1000$ 随机小写字母 | 线性扩张 | $O(n^3)$ 暴力在本组可能勉强过，但扩张更稳 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：中心扩张必须等于区间 DP 的回文个数。
