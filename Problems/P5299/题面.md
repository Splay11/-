# 题目内容

给出一个只包含大写英文字母 $\text{\(\text{A}\)},\text{\(\text{B}\)},\text{\(\text{C}\)}$ 的字符串，每次可以选择该字符串的一个前缀，然后将其反转，请问至少反转几次，才能使字符串中的较小的字母都排在较大的字母之前，即字母 $\text{\(\text{A}\)}$ 都在字母 $\text{\(\text{B}\)},\text{\(\text{C}\)}$ 之前，字母 $\text{\(\text{B}\)}$ 都在字母 $\text{\(\text{C}\)}$ 之前。




# 输入描述

第一行给出两个正整数 $(N,Q)$，代表字符串的长度和字符串的个数

接下来 $Q$ 行每行给出一个一个长度为 $N$ 的字符串
$2 \le N \le 13,1 \le Q \le 100000$



# 输出描述


对于每个字符串在一行中输出一个整数代表最少的反转次数



## 样例1 



**输入** 



```
5 1
CCBAB
```



**输出** 



```
3
```



**说明**

$ABCBA -> BCBAA -> CBBAA -> AABBC$

## 样例2



**输入** 



```
5 1
CCBAB
```



**输出** 



```
2
```



**说明**

$CCBAB -> BABCC -> ABBCC$
