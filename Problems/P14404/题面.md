# 光伏电站发电量预测

某地面光伏电站按区域划分为多个子阵。每个子阵的发电能力由三元组 `[max_capacity, min_capacity, base_generation]` 描述（均为整数）：

- `max_capacity`：该子阵发电能力上限；
- `min_capacity`：该子阵发电能力下限；
- `base_generation`：该子阵基准发电量。

另有整型 `station_capacity` 表示电站总容量上限。系统需根据各子阵约束与基准值，预测每个子阵的最终发电量。

## 预测策略

1. 初始取各子阵的 `base_generation` 作为预测值；
2. 若**总预测发电量** $>$ `station_capacity`，按各子阵**可用缩减空间**比例分配缩减量后更新预测值；
3. 若**总预测发电量** $<$ **总下限**（各子阵 `min_capacity` 之和），按各子阵**可用放大空间**比例分配增加量后更新预测值；
4. 将每个子阵预测值**向上取整**为整数后输出。

### 缩减场景

当 $\sum base\_generation > station\_capacity$ 时：

- 子阵 $i$ 的可用缩减空间 $= base\_generation_i - min\_capacity_i$；
- 总缩减量 $= \sum base\_generation - station\_capacity$；
- 分配：$缩减量_i = 总缩减量 \times \dfrac{可用缩减空间_i}{\sum 可用缩减空间}$；
- 更新：$predicted_i = base\_generation_i - 缩减量_i$（取整前为实数）。

若所有子阵均已达下限（可用缩减空间之和为 $0$），但总基准和仍超过 `station_capacity`，则**无法调整**，返回全 $0$ 数组。

### 放大场景

当 $\sum base\_generation <$ $\sum min\_capacity$ 时：

- 子阵 $i$ 的可用放大空间 $= max\_capacity_i - base\_generation_i$；
- 总增加量 $= \sum min\_capacity - \sum base\_generation$；
- 分配：$增加量_i = 总增加量 \times \dfrac{可用放大空间_i}{\sum 可用放大空间}$；
- 更新：$predicted_i = base\_generation_i + 增加量_i$（取整前为实数）。

若所有子阵均已达上限（可用放大空间之和为 $0$），但总基准和仍低于总下限，则**无法调整**，返回全 $0$ 数组。

### 其它说明

- 若既不需要缩减也不需要放大，直接对基准值向上取整输出；
- 最终每个子阵预测值须满足 $min\_capacity \le predicted \le max\_capacity$（在可调整情形下由上述比例分配保证；不可调整时返回全 $0$）。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def predictGeneration(self, sub_arrays: List[List[int]], station_capacity: int) -> List[int]` |
| Java | `public int[] predictGeneration(int[][] sub_arrays, int station_capacity)` |
| C++ | `vector<int> predictGeneration(vector<vector<int>>& sub_arrays, int station_capacity)` |

**参数**

- `sub_arrays`：子阵列表，每个元素为长度 $3$ 的整数数组 `[max_capacity, min_capacity, base_generation]`；
- `station_capacity`：电站总容量上限。

**返回值**

长度与 `sub_arrays` 相同的一维整数数组，第 $i$ 个元素为子阵 $i$ 的预测发电量；无法调整时返回等长全 $0$ 数组。

## 输入输出格式（stdin / stdout）

**输入**（stdin **一行**：先子阵二维数组，逗号后为 `station_capacity`；方括号、元素逗号无空格，与样例一致）：

```text
[[1000,800,900],[1200,900,1100],[800,600,700]],2800
```

**输出**（stdout **一行**，方括号包裹的整数数组，元素逗号无空格）：

```text
[900,1100,700]
```

## 数据范围

- $1 \le |sub\_arrays| \le 1000$；
- 每个三元组满足 $1 \le min\_capacity \le base\_generation \le max\_capacity \le 10^9$；
- $1 \le station\_capacity \le 10^{12}$。

## 样例

### 样例 1

**输入**

```text
[[1000,800,900],[1200,900,1100],[800,600,700]],2800
```

**输出**

```text
[900,1100,700]
```

**说明**

基准总和 $2700$，介于总下限 $2300$ 与电站容量 $2800$ 之间，无需比例调整，向上取整即为基准值。

### 样例 2

**输入**

```text
[[1000,800,800],[1200,900,900],[800,600,600]],2600
```

**输出**

```text
[800,900,600]
```

**说明**

基准总和等于总下限 $2300$，无需放大；亦未超过电站容量 $2600$。

### 样例 3

**输入**

```text
[[1000,800,900],[1200,900,1100],[800,600,700]],2500
```

**输出**

```text
[850,1000,650]
```

**说明**

基准总和 $2700 > 2500$，总缩减 $200$；可用缩减空间分别为 $100,200,100$，按比例分配后向上取整。

### 样例 4

**输入**

```text
[[100,80,80],[100,80,80]],150
```

**输出**

```text
[0,0]
```

**说明**

各子阵基准均已等于下限，无缩减空间，但总基准 $160$ 仍超过电站容量 $150$，返回全 $0$。
