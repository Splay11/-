# 题目内容

给定正整数数组 $a$。两人轮流从当前序列两端各取一个数，先手最大化自己的得分之和，后手最小化先手得分。双方均按最优策略取数，求先手的最终得分。

## 输入描述

第一行一个整数 $n$。

第二行 $n$ 个正整数 $a_1,a_2,\ldots,a_n$。

## 输出描述

输出一个整数，表示先手的最终得分。

## 数据范围

- $1 \le n \le 200$
- $1 \le a_i \le 10^9$

## 样例1

输入：

```
4
3 9 1 2
```

输出：

```
11
```

说明：先手取右端 $2$ 后，无论后手取哪一端，先手都能再拿到 $9$，总分 $11$。若先手取左端 $3$，后手会取走 $9$，先手最多再得 $2$，总分 $5$。

## 样例2

输入：

```
1
5
```

输出：

```
5
```
