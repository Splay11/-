# 区间博弈

## 解题思路

为什么可以把后手的目标变成：最大化自己的得分？

设数组为 $arr$，所有数的和为 $sum(arr)$。两人得分加起来是一个固定值：

$$
score(先)+score(后)=sum(arr)
$$

所以 $score(先)=sum(arr)-score(后)$。后手想让先手得分最小，就是想让 $sum(arr)-score(后)$ 最小，也就是让 $score(后)$ 最大。通俗理解：先手拿得越少，后手就拿得越多。因此后手的目标可以等价为最大化自己的得分。双方都是「当前区间上的先手」，都在最大化自己的得分。

用记忆化 DFS。设 $dfs(L,R)$ 表示面对区间 $arr[L..R]$ 时，当前先手的最大得分。

1. 边界：$L=R$ 时只剩一个数，直接拿走，$dfs(L,L)=arr[L]$。
2. 转移：先算出区间和 $s$。选左边后，对手在剩余区间上得到 $dfs(L+1,R)$，自己得到 $s-dfs(L+1,R)$；选右边则自己得到 $s-dfs(L,R-1)$。取较大者：
   $$
   dfs(L,R)=\max\bigl(s-dfs(L+1,R),\ s-dfs(L,R-1)\bigr)
   $$
   这与「选 $arr[L]$ 再加剩余区间和、减去对手得分」是同一件事。
3. 用字典记下每个 $(L,R)$ 的结果，避免同一区间重复搜索。答案为 $dfs(0,n-1)$。

## 复杂度分析

区间状态有 $O(n^2)$ 个，每个状态里求一次区间和是 $O(n)$。

时间复杂度为 $O(n^3)$。

空间复杂度为 $O(n^2)$，用于字典和递归栈。

在 $n\le 200$ 时记忆化可以通过；不记忆化的普通递归是指数级，只能通过前面的小数据。

## 代码实现

### Python

```python
import sys

sys.setrecursionlimit(1000000)


def main():
    n = int(input())
    arr = list(map(int, input().split()))
    d = {}

    # dfs(L,R) 表示面对区间 [L,R] 时，当前先手的最大得分
    def dfs(L, R):
        if L == R:
            return arr[L]
        # 算过就直接用，避免重复递归
        if (L, R) in d:
            return d[(L, R)]
        s = 0
        for i in range(L, R + 1):
            s += arr[i]
        # 选左或选右，自己得分 = 区间和 - 对手在剩余区间的最大得分
        d[(L, R)] = max(s - dfs(L + 1, R), s - dfs(L, R - 1))
        return d[(L, R)]

    print(dfs(0, n - 1))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.HashMap;
import java.util.Scanner;

public class Main {
    static int[] arr;
    static HashMap<Long, Long> d = new HashMap<Long, Long>();

    static long key(int L, int R) {
        return ((long) L << 32) ^ R;
    }

    // dfs(L,R) 表示面对区间 [L,R] 时，当前先手的最大得分
    static long dfs(int L, int R) {
        if (L == R) {
            return arr[L];
        }
        // 算过就直接用，避免重复递归
        long k = key(L, R);
        if (d.containsKey(k)) {
            return d.get(k);
        }
        long s = 0;
        for (int i = L; i <= R; i++) {
            s += arr[i];
        }
        // 选左或选右，自己得分 = 区间和 - 对手在剩余区间的最大得分
        long ans = Math.max(s - dfs(L + 1, R), s - dfs(L, R - 1));
        d.put(k, ans);
        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }
        System.out.println(dfs(0, n - 1));
        sc.close();
    }
}
```

### C

```c
#include <stdio.h>

#define N 2005

int arr[N];
long long d[N][N];
int vis[N][N];

// dfs(L,R) 表示面对区间 [L,R] 时，当前先手的最大得分
long long dfs(int L, int R) {
    if (L == R) {
        return arr[L];
    }
    // 算过就直接用，避免重复递归
    if (vis[L][R]) {
        return d[L][R];
    }
    vis[L][R] = 1;
    long long s = 0;
    int i;
    for (i = L; i <= R; i++) {
        s += arr[i];
    }
    {
        long long a = s - dfs(L + 1, R);
        long long b = s - dfs(L, R - 1);
        // 选左或选右，自己得分 = 区间和 - 对手在剩余区间的最大得分
        d[L][R] = a > b ? a : b;
    }
    return d[L][R];
}

int main(void) {
    int n, i;
    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%d", &arr[i]);
    }
    printf("%lld\n", dfs(0, n - 1));
    return 0;
}
```
