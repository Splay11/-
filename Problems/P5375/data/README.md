# P5375 测试数据说明

共 $10$ 组。单组，$m$ 个货位，$q$ 次询问/修改。询问输出三进制拼接、`0`/`2` 互换再翻转后的十进制，模 $998244353$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 | 整段与前缀 | 忘记翻转 |
| 2 | 样例2 单点 `0` 再改成 `3` | `0` 写成一位 | 把 `0` 当成空串 |
| 3 | 样例3 $[2,3,7]$ | 答案 `102` | 只互换不翻转 |
| 4 | 全 `0` | 拼接后的 `2` | 丢掉位数 |
| 5 | $m=5$ 含修改 | 改后重算 | 线段树不 `push`/`pull` |
| 6 | 单点 $10^9$ | 19 位三进制 | `int` 溢出 |
| 7 | $m=8$ 混合操作 | 与暴力对拍 | 合并左右儿子顺序反了 |
| 8 | $m=10$ 只询问 | 卡从左往右拼 | 正向拼接 |
| 9 | $m=q=10^5$ 随机 | 压测 | $O(m)$ 每次询问 |
| 10 | $m=10^5$ 全 `0` 后改左端 | 前导 `0` 仍占位 | 去掉前导零 |

前 $8$ 组小；后 $2$ 组压测。
