# 登山路径（P4726）

## 题目描述

你在给定的数字地形图中寻找登山路径，数字代表当前位置的海拔高度，要求从最低海拔出发，不断攀登，最终到达最高山峰。你需要寻找所有满足条件的登山路径。地图已经保证最低海拔和最高山峰都只有一个。

## 路径条件

- **登山规则**：路径上的海拔必须严格递增。
- **移动限制**：可以向上下左右 $4$ 个方向移动。
- **路径限制**：路径必须从最低海拔开始，到最高海拔结束。
- **访问控制**：每个地点只能走一次。
- **高度差限制**：每一步的攀登高度差必须大于 $0$，小于等于给定参数 `maxDiff`（即下一步海拔 $h'$ 满足 $h < h' \le h + \text{maxDiff}$）。

评测采用 **LeetCode 核心代码模式**：你只需要实现 `Solution` 类中的方法，平台会负责读入数据并调用你的方法。**不要**编写 `main` 或标准输入输出逻辑。

## 方法签名

三种语言的类名均为 `Solution`，请实现：

- **C++**：`long long countHikingPaths(vector<vector<int>>& grid, int maxDiff);`
- **Java**：`public long countHikingPaths(int[][] grid, int maxDiff)`
- **Python**：`def countHikingPaths(self, grid: List[List[int]], maxDiff: int) -> int:`

### 参数说明

- `grid`：$n \times m$ 的二维整数数组，表示海拔图；$2 \le n, m \le 10$。
- `maxDiff`：单步允许的最大高度差（正整数），每一步必须满足 $0 < h_{\text{next}} - h_{\text{cur}} \le \text{maxDiff}$。

### 返回值

从唯一最低点走到唯一最高点的合法路径条数。路径计数可能超过 $2^{31}-1$，C++/Java 使用 `long long` / `long`；Python 返回 `int`（任意精度）。

## 输入格式（平台侧，选手无需编写）

一行文本，与题面示例同形：

```text
[[<第0行>],[<第1行>],...],<maxDiff>
```

- 前半段为二维数组的字面形式：最外层一对 `[]` 包裹若干行，每一行形如 `[a,b,...]`，行间用英文逗号分隔；整数可为多位数，可为负数（若题面数据出现）。
- 紧接着英文逗号 `,`（逗号前后可有若干空格），最后一项为整数 `maxDiff`。

## 输出格式

一行一个整数，表示路径总数，行末一个换行符。

## 样例 1

**输入**

```text
[[1,2],[3,5]],2
```

**输出**

```text
1
```

**说明**：最低点 $(0,0)$ 海拔 $1$，最高点 $(1,1)$ 海拔 $5$，单步最大高度差 $2$。唯一路径：$(0,0) \to (1,0) \to (1,1)$。

## 样例 2

**输入**

```text
[[4,3],[3,2]],1
```

**输出**

```text
2
```

**说明**：最低点 $(1,1)$，最高点 $(0,0)$，高度差上限 $1$。两条路径：$(1,1)\to(0,1)\to(0,0)$ 与 $(1,1)\to(1,0)\to(0,0)$。

## 样例 3

**输入**

```text
[[1,3],[3,4]],1
```

**输出**

```text
0
```

**说明**：从 $(0,0)$ 无法在不违反单步高度差的前提下到达最高点。

## 数据范围

- $2 \le n, m \le 10$。
- 网格中每个元素为整数（具体范围由测试数据给出；保证唯一最小值与唯一最大值各出现一次）。
