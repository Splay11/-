# 题目内容

流水线上依次摆放 $m$ 个工位，从左到右编号 $0,1,\dots,m-1$。工位 $p$ 的铭牌写着正整数 $seq_p$。一台巡检仪最初停在 $0$ 号工位。

每当仪器停在工位 $p$ 时，取出 $seq_p$ 的全部质因数。对其中每个质因数 $d$，只要不越界，就可以把仪器一次滑到工位 $p+d$ 或 $p-d$（须满足 $0 \le p-d$ 且 $p+d \le m-1$）。铭牌为 $1$ 时没有任何质因数，仪器无法再滑。

请判断能否经过若干次滑动，恰好停到最右侧工位 $m-1$。

质因数：能整除某正整数的质数。整数 $1$ 不被视作任何数的质因数。例如 $12$ 的质因数是 $2$ 与 $3$。

# 输入描述

第一行一个整数 $m\ (1 \le m \le 10^{4})$，表示工位个数。

第二行 $m$ 个正整数 $seq_0,seq_1,\dots,seq_{m-1}\ (1 \le seq_p \le 10^{3})$，依次为各工位铭牌。

保证序列非空。

# 输出描述

若巡检仪能够到达最右工位，输出 `1`；否则输出 `0`。

## 样例1

**输入**

```
4
4 1 1 9
```

**输出**

```
0
```

**说明**

- 起点铭牌为 `4`，质因数只有 `2`，只能滑到下标 `2`。
- 下标 `2` 的铭牌为 `1`，无法继续滑动，到不了下标 `3`。

## 样例2

**输入**

```
5
10 1 4 9 1
```

**输出**

```
1
```

**说明**

- `10` 的质因数为 `2` 与 `5`。从下标 `0` 沿 `2` 滑到下标 `2`（铭牌 `4`）。
- `4` 的质因数为 `2`。再沿 `2` 滑到下标 `4`，即最右工位。

## 样例3

**输入**

```
3
1 6 8
```

**输出**

```
0
```

**说明**

起点铭牌为 `1`，不存在可用的质因数，仪器无法离开下标 `0`，而最右工位是下标 `2`。
