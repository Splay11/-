## 题目内容

给定一个只包含正整数的非空数组 `nums` 长度为 `n`，初始时刻下标 `i` 在数组索引 `0` 处，下一时刻下标 `i` 可以移动到 `i+k` 或 `i-k` 下标处并且需要保证 `i+k <= n-1` 且 `i-k >= 0`。其中 `k` 为当前下标对应元素值的质因数，当 `k` 不存在时(元素值为 `1`)下标无法移动。判断是否可以根据以上规则将下标正好移至数组末尾。

质因数定义：如果一个质数是某个正整数的因数，那么这个质数就被称为该正整数的质因数，注意 `1` 不是任何一个数的质因数。

例如：`12` 的质因数为 `2` 和 `3`。

## 输入描述

输入为非空数组，以空格分隔如

```
1 2 3 4
```

其中数组长度 $<= 10^4$，数组元素 $<= 10^3$

## 输出描述

下标能够达到数组末尾返回 `true`

下标不能达到数组末尾返回 `false`

## 样例1

**输入** 

```
5 2 3 5 1 10 7
```

**输出** 

```
false
```

**说明**

无法以任何方式移动到数组末尾

## 样例2

**输入** 

```
12 2 4 1 1
```

**输出** 

```
true
```

**说明**

`12` 的质因数为 `3` 和 `2`

第一时刻下标可以移动到 `4`

`4` 的质因数为 `2`

下一时刻下标可以移动到数组末尾

## 样例3

**输入** 

```
1 1
```

**输出** 

```
false
```

**说明**

`1` 不是任何一个数的质因数因此下标无法移动
