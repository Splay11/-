# 最小极差之和

给定 $n$ 个整数，你需要将它们任意分成两组，且两组都不能为空。

对于一组数，它的**极差**定义为该组中的最大值减去最小值。

设两组分别为第 $1$ 组和第 $2$ 组，则它们的极差分别为：

- 第 $1$ 组极差 $=$ 第 $1$ 组最大值 $-$ 第 $1$ 组最小值
- 第 $2$ 组极差 $=$ 第 $2$ 组最大值 $-$ 第 $2$ 组最小值

你的目标是最小化这两个极差之和，即最小化：

$$(\text{max}_1-\text{min}_1)+(\text{max}_2-\text{min}_2)$$

请输出这个最小值。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def minimizeRangeSum(self, n: int, nums: List[int]) -> int` |
| Java | `public long minimizeRangeSum(int n, int[] nums)` |
| C++ | `long long minimizeRangeSum(int n, vector<int>& nums)` |

**参数**

- `n`：整数个数，$2 \le n \le 10^5$；
- `nums`：长度为 $n$ 的数组，`nums[i]` 为第 $i+1$ 个数，$1 \le nums[i] \le 10^9$。

**返回值**

两组极差之和的最小值（$64$ 位整数范围内）。

## 输入输出格式（stdin / stdout）

**输入**（stdin **一行**：`n`、英文逗号、一维数组；方括号内元素逗号分隔、无空格，与样例一致）：

```text
5,[10,1,5,3,8]
```

**输出**（stdout **一行**整数）：

```text
6
```

## 数据范围

- $2 \le n \le 10^5$；
- $1 \le nums[i] \le 10^9$；
- 输入保证 `n` 与 `nums.length` 一致。

## 样例

### 样例 1

**输入**

```text
5,[10,1,5,3,8]
```

**输出**

```text
6
```

**说明**

划分为 $[1,5,3]$ 和 $[10,8]$ 两组：

- 第 $1$ 组极差 $= 5-1 = 4$
- 第 $2$ 组极差 $= 10-8 = 2$
- 总和 $= 6$

### 样例 2

**输入**

```text
5,[1,1,9,1,9]
```

**输出**

```text
0
```

**说明**

分组为 $[1,1,1]$ 和 $[9,9]$，两组的极差均为 $0$，和也为 $0$。

### 样例 3

**输入**

```text
2,[1,2]
```

**输出**

```text
0
```

**说明**

只能分为两组，每组一个数。每组的最大值与最小值相同，极差为 $0$。
