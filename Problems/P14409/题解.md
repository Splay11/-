## 解题思路

本题将 $n$ 个数分成两个**非空**子集，最小化两组极差之和。关键观察：

1. **排序后枚举断点**：将 `nums` 升序得到 `a[0..n-1]`。可以证明存在最优解，使得两组在排序序列上分别对应两个**连续区间** `[0,i]` 与 `[i+1,n-1]`（或全局最小值与最大值同组、另一组单独取一个数，该情况会被下面第 2 点覆盖）。
2. **相邻切分**：若全局最小 `a[0]` 与最大 `a[n-1]` 分属两组，切分点 $i$（$0 \le i < n-1$）的代价为 $(a[i]-a[0]) + (a[n-1]-a[i+1])$。
3. **同组情形**：若 `a[0]` 与 `a[n-1]` 在同一组，另一组至少有一个数，代价至少为 $a[n-1]-a[0]$，取等即可。
4. **特判 $n=2$**：每组恰一个数，极差均为 $0$。

对所有切分点取最小，并与 $a[n-1]-a[0]$ 比较即可。

常见假解：$2^n$ 暴力分组（$n=10^5$ 会 TLE）、未排序直接枚举、允许空组、漏掉 $n=2$ 特判、32 位整型溢出。

## 复杂度分析

- 时间复杂度：$O(n \log n)$，排序 dominates，切分枚举 $O(n)$。
- 空间复杂度：$O(n)$，排序辅助数组。

## 代码实现

### Python

```python
from typing import List


class Solution:
    def minimizeRangeSum(self, n: int, nums: List[int]) -> int:
        a = sorted(nums)
        if n == 2:
            return 0
        # 全局 min 与 max 同组时的下界
        ans = a[-1] - a[0]
        for i in range(n - 1):
            # 左组 [0..i]，右组 [i+1..n-1]
            cost = (a[i] - a[0]) + (a[-1] - a[i + 1])
            if cost < ans:
                ans = cost
        return ans
```

### Java

```java
import java.util.Arrays;

public class Solution {
    public long minimizeRangeSum(int n, int[] nums) {
        int[] a = Arrays.copyOf(nums, n);
        Arrays.sort(a);
        if (n == 2) return 0;
        // 全局 min 与 max 同组时的下界
        long ans = (long) a[n - 1] - a[0];
        for (int i = 0; i < n - 1; i++) {
            // 左组 [0..i]，右组 [i+1..n-1]
            long cost = (long) (a[i] - a[0]) + (a[n - 1] - a[i + 1]);
            if (cost < ans) ans = cost;
        }
        return ans;
    }
}
```

#include <algorithm>
#include <vector>

using namespace std;

class Solution {
 public:
  long long minimizeRangeSum(int n, vector<int>& nums) {
    vector<int> a = nums;
    sort(a.begin(), a.end());
    if (n == 2) return 0;
    // 全局 min 与 max 同组时的下界
    long long ans = (long long)a[n - 1] - a[0];
    for (int i = 0; i < n - 1; i++) {
      // 左组 [0..i]，右组 [i+1..n-1]
      long long cost = (long long)(a[i] - a[0]) + (a[n - 1] - a[i + 1]);
      if (cost < ans) ans = cost;
    }
    return ans;
  }
};
