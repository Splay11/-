# P5247 测试数据说明

多询问：第一行 $q$，每个询问两行（$n$ 与 $n$ 个收益）。
约束：$1\le q\le 80$，$2\le n\le 30$ 且 $n$ 为偶数，$1\le v_i\le 10^9$。

| 编号 | 类型 | 说明 | 针对的错误解 |
|---:|---|---|---|
| 1 | 样例 | 样例1：n=2 与可均分的 n=4 | — |
| 2 | 样例 | 样例2：交替贪心非最优；n=6 差为 1 | — |
| 3 | 边界 | 边界：n=2 最小规模 | n=2 / 极值差 |
| 4 | 边界 | 边界：全相等，差必为 0 | 全相等仍输出非 0 |
| 5 | hack | hack：排序交替放入两班（1 2 3 6 会得到 4） | 排序交替贪心 |
| 6 | hack | hack：忽略「每班恰好 n/2 个」（1 1 1 3 无基数约束可得 0） | 无基数约束的划分 |
| 7 | 构造 | 构造：含 1e9 极值，检查大整数求和 | int 溢出 / 大值求和 |
| 8 | 随机 | 随机小数据：若干偶数 n<=12 | 随机噪声 |
| 9 | 压力 | 大数据：q=1，n=30 | n=30 折半枚举 |
| 10 | 压力 | 大数据：q=80，混入 n=30 与 1e9 | q=80 满询问 |
