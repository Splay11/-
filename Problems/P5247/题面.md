# 题目内容

现在有$ n $块蛋糕（$n $为偶数）。第$ i$ 块蛋糕的幸福度为$a_i$。为了公平，小红先把全部蛋糕分成两堆，每一堆都恰好有 $\frac{n}{2}$块；随后小蓝从这两堆中先选一堆。两个人都会做对自己最有利的选择。

请计算：在两人都足够聪明的前提下，最终两人拿到的总幸福度之和的最小差值是多少。

# 输入描述

每个测试文件均包含多组测试数据。 第一行输入一个整数 $T\ (1 \le T \le 100)$ 表示测试组数。 接下来对于每一组测试数据：

- 第一行输入一个整数 $n\ (1 \le n \le 30)$，保证 $n$ 为偶数，表示蛋糕数量。
- 第二行输入 $n$ 个整数 $a_1,a_2,\dots,a_n\ (1 \le a_i \le 10^9)$，表示每块蛋糕的幸福度。



# 输出描述

对于每一组测试数据，新起一行输出一个整数，表示两人总幸福度之和的最小差值。



## 样例1 

**输入** 

```
2
2
1 3
4
1 2 3 4
```

**输出** 

```
2
0
```
