# 独立区间计数

给定一个以二维数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [starti, endi]`（`starti` 和 `endi` 都是整数），这些区间之间可能存在重叠。

请统计**跟其他任何区间都不重叠**的区间数量。

两个区间 `[a, b]` 与 `[c, d]` **重叠**，当且仅当 `a <= d` 且 `c <= b`（端点相接也算重叠，例如 `[2,4]` 与 `[4,6]` 重叠）。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def countIsolatedIntervals(self, intervals: List[List[int]]) -> int` |
| Java | `public int countIsolatedIntervals(int[][] intervals)` |
| C++ | `int countIsolatedIntervals(vector<vector<int>>& intervals)` |

**参数**

- `intervals`：区间列表，`intervals[i] = [starti, endi]`，$0 \le starti \le endi \le 10^4$。

**返回值**

与其他所有区间都不重叠的区间个数。

## 输入输出格式（stdin / stdout）

**输入**（stdin **一行**：二维数组字面量；外层与内层方括号、元素逗号均无空格，与样例一致）：

```text
[[8,10],[1,4],[2,6],[15,18]]
```

**输出**（stdout **一行**整数）：

```text
2
```

## 数据范围

- $1 \le \text{intervals.length} \le 10^4$；
- $\text{intervals}[i].\text{length} = 2$；
- $0 \le starti \le endi \le 10^4$。

## 样例

### 样例 1

**输入**

```text
[[8,10],[1,4],[2,6],[15,18]]
```

**输出**

```text
2
```

**说明**

区间 `[8,10]` 和 `[15,18]` 与其他区间都不重叠。

### 样例 2

**输入**

```text
[[2,4],[4,6]]
```

**输出**

```text
0
```

**说明**

`[2,4]` 与 `[4,6]` 在端点 $4$ 处相接，视为重叠，不存在与其他区间都不重叠的区间，故返回 $0$。

### 样例 3

**输入**

```text
[[0,1]]
```

**输出**

```text
1
```

**说明**

只有一个区间时，自然与其他区间都不重叠。
