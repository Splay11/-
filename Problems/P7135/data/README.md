# P7135 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：第一行 `m n`；随后 $m$ 行 $grid1$，再 $m$ 行 $grid2$。
输出：$grid2$ 中子岛屿的个数。

约束：$1\le m,n\le 500$，矩阵元素为 $0$ 或 $1$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1 | 子岛屿个数为 $3$ | 按陆地格子数统计，或漏掉其中一座 |
| 2 | 样例 2 | 子岛屿个数为 $2$ | 把底部两个对角 $1$ 也算进去 |
| 3 | 单格两张都是陆地 | 答案 $1$ | 空岛或漏统计 |
| 4 | 单格 grid2 是陆地但 grid1 是水 | 答案 $0$ | 不看 grid1 直接输出 $1$ |
| 5 | 一座岛只有部分被覆盖 | 整座不算，答案 $0$ | 按格点覆盖率计算，输出 $2$ |
| 6 | 全是水 | 答案 $0$ | 输出 $1$ 把空图当一座岛 |
| 7 | 四座互不相邻的单格岛，全部被包含 | 答案 $4$ | 用八连通把它们合成一座 |
| 8 | 小随机 $8\times 8$ | DFS 与 BFS 对拍 | 染色串岛 |
| 9 | 压满 $500\times 500$，grid1 全陆地，grid2 蛇形一座岛 | 答案 $1$ | 递归 DFS 爆栈 |
| 10 | 压满 $500\times 500$ 随机 $0/1$ | 线性扫岛 | I/O 超时；或只扫了 grid2 没对照 grid1 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：栈 DFS 必须等于队列 BFS 的子岛屿个数。
