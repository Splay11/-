# 题目内容

多多的物流网络中有 $n$ 个仓库和 $m$ 条单向道路。每条道路都有一个正整数运输费用，以及一个标签，标签为 $A$、$B$、$C$ 之一。

车辆从仓库 $s$ 出发，沿道路行驶至仓库 $t$。将沿途道路的标签按顺序连接，得到这条路线的标签串。

给定一个非空禁用串 $P$。如果路线的标签串中不含连续子串 $P$，则称这条路线合规。

车辆可以重复经过仓库和道路，每次经过道路都需支付相应费用。请计算合规路线的最小总费用，以及达到这一费用的不同路线数。路线数对 $1000000007$ 取模。

道路按输入顺序编号。两条路线经过的道路编号序列不同，就视为不同路线；即使端点、费用和标签均相同，不同编号的道路也分别计数。

当 $s = t$ 时，允许不经过任何道路的空路线，其费用为0，标签串为空。




# 输入描述


第一行输入四个整数 $n,m,s,t$，以空格分隔，分别表示仓库数、道路数、起点编号和终点编号。其中：
$1 \le n \le 5000$；
$0 \le m \le 20000$；
$1 \le s,t \le n$。

第二行输入禁用字符串 $P$，满足 $1 \le |P| \le 50$，仅由 $A$、$B$、$C$ 组成。

接下来 $m$ 行，每行依次输入三个整数和一个字符 $u,v,w,ch$，以空格分隔，表示一条从仓库 $u$ 到仓库 $v$、费用为 $w$、标签为 $ch$ 的道路。其中 $1 \le u,v \le n$，$1 \le w \le 10^9$，$ch$ 为 $A$、$B$、$C$ 之一。

允许重边和自环。



# 输出描述

输出两个整数，以空格分隔，依次为最小总费用，以及最优路线数对 $1000000007$ 取模的结果。
如果不存在合规路线，输出 $-1\ \ 0$。

### 补充说明
对于 $20\%$ 的测试数据，仓库不超过 $10$，道路数不超过 $20$，禁用串长度不超过 $4$，且每条道路的起点编号都小于终点编号。

另外 $30\%$ 的测试数据中，禁用串只包含一个字符。

剩余 $50\%$ 的测试数据没有额外限制。




## 样例1 



**输入** 



```
4 5 1 4
AB
1 2 1 A
2 4 1 B
1 3 1 B
3 4 2 A
1 4 3 C
```



**输出** 



```
3 2
```



**说明**

路线 $1 \to 2 \to 4$ 虽然费用为 $2$，但标签串是禁用串 $AB$，不合规。

路线 $1 \to 3 \to 4$ 的标签串为 $BA$，直接从仓库 $1$ 到仓库 $4$ 的标签串为 $C$；二者均合规，费用都为 $3$。
