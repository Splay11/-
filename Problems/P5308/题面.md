# 题目内容

你正在开发一个机器人清洁系统。机器人在一个 $m \times n$ 的网格状房间中移动，需要从左上角 $(0, 0)$ 移动到右下角 $(m-1, n-1)$。每个格子有一定量的灰尘，用非负整数表示。机器人每次只能向右或向下移动一格。

机器人在移动过程中会吸收所在格子的灰尘，机器人的功率控制系统需要根据灰尘浓度自动调节清洁功率。当机器人从 $A$ 位置移动到 $B$ 位置时，由于灰尘浓度从 $C_A$ 变化为 $C_B$，控制系统需要消耗调节能量来调整功率输出。调节能量消耗为：$E = |C_B - C_A|$。例如，从灰尘值为 $3$ 的格子移动到灰尘值为 $5$ 的格子，需要消耗 $|5-3| = 2$ 单位能量。

请规划一条路径，使得整个移动过程中的总调节能耗最小。



# 输入描述


第一行表示整数 $m$,$n$ 表示网格大小

后面为 $m$ 行 $n$ 列的整数矩阵，表示各位置灰尘浓度

$1 \le m, n \le 200$

$0 \le grid[i][j] \le 10000$


# 输出描述

一个整数，表示最小总调节能耗




## 样例1 



**输入** 



```
1 5
1 2 3 4 5
```



**输出** 



```
4
```



**说明**

路径 $1-2-3-4-5$，调节能耗为$(1+1+1+1=4)$，该条路径总调节能耗为最低

## 样例2



**输入** 



```
3 3
1 3 1
2 5 4
6 8 1
```



**输出** 



```
8
```



**说明**


路径 $1-2-5-4-1$，调节能耗为 $(1+3+1+3=8)$，该条路径总调节能耗为最低
