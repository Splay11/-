# P7156 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：第一行 $n$，第二行 $n$ 个 $gas$，第三行 $n$ 个 $cost$。
输出：绕圈可行的唯一起点（从 $0$ 编号），否则 $-1$。

约束：$1\le n\le 10^5$，$0\le gas_i,cost_i\le 10^4$，有解时起点唯一。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1，$n=5$，起点 $3$ | $3$ | 从 $0$ 模拟或按 $1$ 编号输出 $4$ |
| 2 | 样例 2，总量不够 | $-1$ | 不判断总量仍返回某个下标 |
| 3 | $n=1$ 且油够 | $0$ | 输出 $-1$ |
| 4 | $n=1$ 且油不够 | $-1$ | 输出 $0$ |
| 5 | 唯一起点在 $0$ | $0$ | 总量够就随便输出非 $0$ |
| 6 | 净油最大的站不是起点 | 唯一合法起点 $0$ | 选 $gas-cost$ 最大的下标 |
| 7 | 小环形、起点不在两端 | 起点 $5$ | 取第一个 $gas\ge cost$ 的站 |
| 8 | 中等 $n=80$，构造唯一起点 | DP/贪心与枚举对拍 | 从每个起点模拟在后面大数据超时 |
| 9 | 压满 $n=10^5$，起点在最后一站 | $O(n)$ 贪心 | $O(n^2)$ 每个起点绕圈 TLE |
| 10 | 压满 $n=10^5$，总量不够 | $-1$ | 不判断总量返回 $0$ 或 $n$ |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：贪心结果必须与前缀最小值判定的合法起点集合一致；
$n\le 400$ 时再与逐起点模拟对拍。有解时集合大小必须为 $1$。
