# 雾幕聚光后的灯位亮度

# 题目内容

请算出直线舞台上每个灯位在雾幕和聚光同时生效后的最终亮度。

舞台上有 $t$ 个灯位，编号 $1 \sim t$，第 $i$ 个灯位的初始亮度是整数 $d_i$。有两类覆盖连续灯位的装置会一起生效：

- 雾幕：给定区间 $[l,r]$ 和上界 $u$，表示该区间内亮度不能超过 $u$。
- 聚光：给定区间 $[l,r]$ 和下界 $v$，表示该区间内亮度不能低于 $v$。

对每个位置 $i$，把覆盖它的所有聚光下界取最大值记为 $lo_i$（没有聚光则 $lo_i=0$）；把覆盖它的所有雾幕上界取最小值记为 $hi_i$（没有雾幕则 $hi_i=+\infty$）。最终亮度

$$
f_i=\min(\max(d_i,\ lo_i),\ hi_i)
$$

请输出 $f_1,f_2,\dots,f_t$。

# 输入描述

第一行一个整数 $e$（$1 \le e \le 10^5$），表示询问组数。

每组第一行三个整数 $t$、$g$、$s$（$1 \le t \le 2 \times 10^5$，$0 \le g,s \le 2 \times 10^5$），表示灯位数、雾幕数、聚光数。

第二行 $t$ 个整数 $d_1,d_2,\dots,d_t$（$0 \le d_i \le 10^9$），表示初始亮度。

接下来 $g$ 行，每行三个整数 $l$、$r$、$u$（$1 \le l \le r \le t$，$0 \le u \le 10^9$），表示一个雾幕。

接下来 $s$ 行，每行三个整数 $l$、$r$、$v$（$1 \le l \le r \le t$，$0 \le v \le 10^9$），表示一个聚光。

保证所有组的 $t$ 之和、$g$ 之和、$s$ 之和都不超过 $2 \times 10^5$。

# 输出描述

对每组输出一行 $t$ 个整数，即各灯位的最终亮度，相邻数之间用空格分隔。

## 样例1

**输入**

```
2
4 1 1
5 0 8 2
2 4 3
1 2 4
3 0 0
1 2 3
```

**输出**

```
5 3 3 2
1 2 3
```

**说明**

第一组：聚光下界 $lo=[4,4,0,0]$，雾幕上界 $hi=[+\infty,3,3,3]$。

- $f_1=\min(\max(5,4),+\infty)=5$
- $f_2=\min(\max(0,4),3)=3$
- $f_3=\min(\max(8,0),3)=3$
- $f_4=\min(\max(2,0),3)=2$

第二组没有装置，最终亮度就是初始亮度。
