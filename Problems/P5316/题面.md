# 题目内容

在一条直线舞台上依次编号 $1 \sim n$ 的灯位，每个灯位初始亮度为整数 $a_i$。有两类覆盖若干连续灯位的装置同时生效：
- 雾幕：给定区间 $([l,r])$ 及上界值 $p$，对区间内位置施加“亮度不超过 $p$”的限制；
- 聚光：给定区间 $([l,r])$ 及下界值 $q$，对区间内位置施加“亮度不低于 $q$”的限制。

对每个位置 $i$，将覆盖它的所有聚光下界取最大值记为 $L_i$（若无聚光覆盖则 $L_i=0$），将覆盖它的所有雾幕上界取最小值记为 $U_i$（若无雾幕覆盖则 $U_i=+\infty$）。所有装置同时生效，最终亮度 $b_i$ 的计算规则为
$$b_i = \min(\max(a_i,\ L_i),\ U_i).$$

请计算所有位置的最终亮度 $b_1,b_2,\dots,b_n$。



# 输入描述

每个测试文件包含多组测试数据。第一行输入一个整数 $T(1 \le T \le 10^5)$ 表示数据组数，每组测试数据描述如下：

第一行输入三个整数 $n,m_f,m_s\ (1 \le n \le 2 \times 10^5,\ 0 \le m_f,m_s \le 2 \times 10^5)$，分别表示灯位数量、雾幕数量与聚光数量。

第二行输入 $n$ 个整数 $a_1,a_2,\dots,a_n\ (0 \le a_i \le 10^9)$，表示初始亮度。

接下来 $m_f$ 行，每行输入三个整数 $l,r,p\ (1 \le l \le r \le n,\ 0 \le p \le 10^9)$，表示一个雾幕区间及其上界。

接下来 $m_s$ 行，每行输入三个整数 $l,r,q\ (1 \le l \le r \le n,\ 0 \le q \le 10^9)$，表示一个聚光区间及其下界。

保证所有测试数据的 $n$ 之和、$m_f$ 之和、$m_s$ 之和均不超过 $2 \times 10^5$。




# 输出描述


对于每组测试数据，输出一行包含 $n$ 个整数 $b_1,b_2,\dots,b_n$，表示各位置的最终亮度。不同测试数据的输出各占一行，顺序与输入一致。


## 样例1 



**输入** 



```
2
5 2 2
4 2 7 1 3
2 4 3
3 5 5
1 3 6
4 5 2
0 5 9 1
1 4 4
2 2 7
3 3 8
1 3 1
```



**输出** 



```
6 3 3 2 3
1 4 4 1
```



**说明**

样例第一组数据中，聚光下界为 $L = [6,6,6,2,2]$，雾幕上界为 $U = [+\infty,3,3,3,5]$。逐位计算：
$b_1 = \min(\max(4,6), +\infty) = 6$.
$b_2 = \min(\max(2,6), 3) = 3$.
$b_3 = \min(\max(7,6), 3) = 3$.
$b_4 = \min(\max(1,2), 3) = 2$.
$b_5 = \min(\max(3,2), 5) = 3$.
