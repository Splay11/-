# 题目内容

小明的农田是一块 $n$ 行 $m$ 列的网格。第 $i$ 行第 $j$ 列地块的土壤肥力为 $w_{i,j}$。

播种机单次作业可从任意格子出发，沿同一行或同一列直线行驶至另一格子，途经格子均被播种。

需选取一个**非空**连续矩形子区域。设该子区域：

- 土壤肥力总和为 $S$；
- 用播种机覆盖其中全部格子所需的最少作业次数为 $k$（可横播或纵播，取更优方案）。

满意度定义为：

$$
\text{满意度} = S \times k.
$$

矩形高 $H$、宽 $W$ 时，按行播种需 $H$ 次、按列播种需 $W$ 次，故 $k=\min(H,W)$。

求最大满意度。

# 输入描述

第一行两个正整数 $n,m$，表示农田行数与列数。

接下来 $n$ 行，每行 $m$ 个整数 $w_{i,j}$，表示土壤肥力。

# 输出描述

输出一个整数，表示最大满意度。

## 样例1

**输入**

```
3 4
-5 3 4 -1
-1 9 0 2
-2 -6 -5 -2
```

**输出**

```
34
```

**说明**

选取左上角 $(1,2)$、右下角 $(2,4)$ 的子矩形（下标从 $1$ 起）：

- 所含数值为 $3,4,-1,9,0,2$，总和 $S=17$；
- 高 $H=2$，宽 $W=3$，最少作业次数 $k=\min(2,3)=2$；
- 满意度 $17\times 2=34$。

# 数据范围

- $1\le n,m\le 400$
- $-1000\le w_{i,j}\le 1000$
- 所有输入均为整数
