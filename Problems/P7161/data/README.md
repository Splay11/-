# P7161 测试数据说明

主造数脚本：题目根目录 `gen.py`。
有公共字符时两行：个数、按字典序空格分隔的字符；否则只一行 $0$。
约束：$1\le n,|words_i|\le 100$，小写字母。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1，$e$ 一次 $l$ 两次 | 3 / e l l | 忽略次数只输出 e l |
| 2 | 样例 2 | 2 / c o | 没按字典序 |
| 3 | n=1，整串都是公共 | a b c | 输出 0 |
| 4 | 完全没有公共字母 | 只输出 0 | 仍打印空第二行 |
| 5 | 次数取最小，$a$ 两次 | a a | 按最长串次数输出 4 个 a |
| 6 | 单字母对不上 | 0 | 输出 z |
| 7 | 公共 a 一次 | a | 输出 a b |
| 8 | 中等随机 | 与 Counter 交对拍 | 只做集合交 |
| 9 | 压满 n=100，每串长度 100 | O(nL) 计数 | 指数枚举 |
| 10 | 压满全是 a | 100 个 a | 输出 1 个 a |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。
