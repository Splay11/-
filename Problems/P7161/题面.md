# 题目内容

给定一个包含 $n$ 个字符串的数组 $words$，请找出所有在 $words$ 的每个字符串中都出现的公共字符。

如果某个字符在每个字符串中都出现了多次，则该字符也需要按照能够共同出现的次数重复计入答案。

例如，如果字符 $l$ 在每个字符串中都至少出现 $2$ 次，那么答案中需要包含 $2$ 个字符 $l$。

请将所有公共字符按照字典序从小到大输出。

# 输入描述

第一行输入一个整数 $n$，表示字符串数组 $words$ 的长度。

接下来输入 $n$ 行，每行输入一个字符串 $words_i$，表示数组中的第 $i$ 个字符串。

### 约束

$1 \le n \le 100$

$1 \le |words_i| \le 100$

$words_i$ 仅由小写英文字母组成。

# 输出描述

第一行输出一个整数 $k$，表示所有公共字符的数量。

如果 $k>0$，第二行按照字典序从小到大输出这 $k$ 个公共字符，相邻字符之间用空格分隔。

如果不存在公共字符，即 $k=0$，则只输出一行 $0$。

## 样例1

**输入**

```text
3
bella
label
roller
```

**输出**

```text
3
e l l
```

**说明**

字符 $e$ 在所有字符串中都至少出现 $1$ 次。

字符 $l$ 在所有字符串中都至少出现 $2$ 次，因此需要在答案中出现 $2$ 次。

所以公共字符为 $e,l,l$，共有 $3$ 个。

## 样例2

**输入**

```text
3
cool
lock
cook
```

**输出**

```text
2
c o
```

**说明**

字符 $c$ 和字符 $o$ 都在所有字符串中出现。

其他字符无法同时出现在所有字符串中，因此公共字符共有 $2$ 个，分别为 $c$ 和 $o$。
