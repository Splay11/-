**1、Agent 需要调用两个工具：先查订单状态，再决定是否退款。更合理的链路是?**
{{ select(1) }}
- 两个工具共用无约束字符串参数并跳过状态字段
- 模型产出结构化计划，系统校验订单状态后退款
- 先执行退款工具，再让模型解释订单状态变化
- 状态查询失败时按用户催促先退款再补查订单

**2、长上下文推理的 KV Cache 随并发和序列长度快速占满显存。在不修改模型权重且要兼顾吞吐与时延时，应优先怎么做?**
{{ select(2) }}
- 结合上下文上限、并发数以及分页和淘汰策略控制占用
- 关闭缓存并在每个解码步重算全部历史 token 以降低延迟
- 无限延长组批等待时间，用更大 batch 摊薄缓存占用
- 为每个请求预留最大上下文长度的连续显存空间

**3、RAG 系统检索到了正确文档，但正确段落排名靠后，未进入注入上下文。更应优先优化什么?**
{{ select(3) }}
- 重排和上下文截取规则
- 弱化文档版本字段
- 把回答长度调到更短
- 让模型绕过检索自由回答

**4、并查集的 parent 关系为 1→2、2→3、3→4、4→4。对 1 执行带路径压缩的 find 后，parent 关系会怎样变化?**
{{ select(4) }}
- 4 的父节点被改成 1 以保持链式结构
- 1 和另一个未查询集合被合并到一起
- 1、2、3 被重新编号为新的集合编号
- 1、2、3 都更直接指向根节点 4 附近

**5、SFT 数据中若同一指令存在多个互相矛盾的目标回答，最直接的风险是?**
{{ select(5) }}
- 奖励模型分数会替代 SFT 标签成为主要训练信号
