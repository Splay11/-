# P5377 测试数据说明

共 `10` 组。输入：第一行 $n$ $b$，第二行 $n$ 个 $v_i$。
前 `8` 组小数据，后 `2` 组 $n=`100`$ 大数据。

| 组别 | 类型 | 规模/分布 | 目标 | 卡掉的错误解 |
|---:|---|---|---|---|
| 1 | 样例 | $n=`4`$ | 展示总消耗计算 | — |
| 2 | 样例 | $n=`1`$ 恰好用完 | 边界 | 下标天数写成 $n-i$ 少一天 |
| 3 | 样例 | 前缀申请太贵 | 应跳过第一人 | — |
| 4 | 边界 | 全部超库存 | 答案 $0$ | 输出 `-1` 或 `1` |
| 5 | 基础 | 库存充足 | 全选 | 提前 break |
| 6 | hack | 同样例3 | 按天序必须先接第一人 | 前缀贪心得 $0$ |
| 7 | hack | 日耗小、驻期长 | 按 $v_i$ 排序先拿长驻 | 人数少 `1` |
| 8 | 随机 | $n=`20`$ | 对拍 | 天数算成 $i$ 而非 $n-i$ |
| 9 | 压力 | $n=`100`,b=`1000000`$ 随机 | 满约束 | $O(2^n)$ |
| 10 | 构造 | 日耗全 `10000` | 大消耗 | 溢出 / 天数算错 |

生成器：`gen.py`，随机种子 `5377`。正解为按总消耗升序贪心，$O(n\log n)$。
