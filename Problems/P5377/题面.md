# 题目内容

AK机准备招待一些客人。一共有 $n$ 天，每天都会有一个客人提出拜访的邀请，如果AK机接受了这个邀请，那么这个人会前来拜访，持续到第 $n$ 天结束。

已知第 $i$ 个人将在第 $i$ 天来访，并且每天都会消耗 $a_i$ 食物。例如，如果 $n = 4, a = [2,5,3,1]$，那么如果AK机接受了第二个人的邀请，那么他将每天消耗 $5$ 食物并持续 $3$ 天，共消耗 $15$ 食物。

AK机总共的食物数量为 $m$。他可以回绝掉一些朋友的拜访邀请。AK机想知道，自己最多可以接受多少人的拜访？



# 输入描述

第一行输入两个正整数 $n, m(1 \le n \le 100,1 \le m \le 10^6)$，分别表示天数和食物总量。

第二行输入 $n$ 个正整数 $a_i(1 \le a_i \le 10^4)$，表示每个人每天的食物消耗量。



# 输出描述

输出一个整数表示答案。



## 样例1 



**输入** 



```
3 10
2 4 3
```



**输出** 



```
2
```



**说明**

AK机可以接受第一个朋友和第三个朋友的拜访，其中第一个朋友第一天、第二天和第三天分别消耗其 $2$ kg食物，第三个朋友将在第三天消耗其 $3$ kg的食物。

## 样例2



**输入** 



```
5 75
1 1 1 1 1
```



**输出** 



```
5
```
