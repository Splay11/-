# 驻场耗材

# 题目内容

实验中心对外开放 $n$ 个工作日。每天都会收到一份驻场申请：第 $i$ 个工作日提出申请的课题组，一旦获批，就从当天起一直用到第 $n$ 个工作日结束，不能中途清退。驻场期间该课题组每天消耗 $v_i$ 份试剂。仓库里试剂总量只有 $b$ 份，中心可以拒绝一部分申请。请计算最多能批准多少个课题组。

第 $i$ 个课题组若被批准，占用天数为 $n-i+`1`$，因此一共消耗 $v_i\cdot(n-i+`1`)$ 份试剂。所有获批课题组的消耗之和不能超过 $b$。

约束：
- `1` $\le$ $n$ $\le$ $10^2$
- `1` $\le$ $b$ $\le$ `1000000`
- `1` $\le$ $v_i$ $\le$ `10000`

# 输入描述

第一行两个正整数 $n$ 和 $b$（`1` $\le$ $n$ $\le$ $10^2$，`1` $\le$ $b$ $\le$ `1000000`），表示工作日数和试剂总量。

第二行 $n$ 个正整数 $v_1,v_2,\ldots,v_n$（`1` $\le$ $v_i$ $\le$ `10000`），表示各课题组每天的试剂消耗。

# 输出描述

输出一个非负整数，表示最多能批准的课题组个数。

## 样例1

**输入**

```
4 20
3 1 4 2
```

**输出**

```
3
```

**说明**

四个课题组的总消耗依次为 `12`、`3`、`8`、`2`。批准后三个（消耗 `2` $+$ `3` $+$ `8` $=$ `13`）不超过 `20`；再批准第一个会超出。

## 样例2

**输入**

```
1 5
5
```

**输出**

```
1
```

**说明**

只有一个工作日、一个申请，消耗恰好 `5`，可以批准。

## 样例3

**输入**

```
3 9
4 1 1
```

**输出**

```
2
```

**说明**

三个课题组总消耗依次为 `12`、`2`、`1`。第一个申请单独就超过库存；批准后两个消耗 `3`，共 `2` 个。
