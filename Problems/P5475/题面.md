# 题目内容


请你在仅使用numpy / pandas / scikit-learn的前提下，实现二分类评估指标ROC-AUC的计算，并对给定数据输出AUC值。

本题要求你用秩统计（Mann-Whitney U）等价形式计算AUC，并且必须正确处理分数并列（ties）：并列样本使用平均秩（average rank）。

你可以参考如下规则：
1) 平均秩（average rank）
将样本按$y\_score$升序排序，秩从$1$开始。
如果若干样本分数相同，占据排序中的第$l$…$r$名，则这些样本的秩都取：$rank = \frac{l + r}{2}$

2) 用秩和计算AUC
设正类个数$n\_pos$，负类个数$n\_neg$，正类样本的秩和为$R\_pos$，则：
$$U = R_{pos} - \frac{n_{pos}(n_{pos}+1)}{2},\quad AUC = \frac{U}{n_{pos}n_{neg}}$$



# 输入描述


标准输入为一行JSON：
```json
{
"\(y\_true\)": [0, 1, 0, 1, ...],
"\(y\_score\)": [0.12, 0.83, 0.40, 0.51, ...]
}
```
- $y\_true$：长度$n$，元素为$0/1$，$1<n<20$
- $y\_score$：长度$n$，浮点分数（越大越倾向正类），$1<n<20$
- 输入保证$y\_true$同时包含$0$和$1$（避免AUC无定义）


# 输出描述

标准输出仅一行：一个浮点数（JSON数字），表示AUC，严格保留$6$位小数：
`0.750000`
