# 新能源电站温度监测

新能源电站配备了多个温度传感器，用于监测关键设备的运行温度，需要定期分析温度数据：找出历史最高温度记录，并检测是否存在温度异常升高的危险时段。

**危险时段**定义为一段连续 $k$ 个时间点的温度**严格单调递增**，且该时段内温度升高总幅度 $\ge$ 阈值 $t$，这样的时段被标记为设备存在过热风险。

给定整数数组 `temperatures`，其中 `temperatures[i]` 表示第 $i$ 个时间点的温度记录，请完成以下任务：

1. 找出最高温度值及其**首次出现**的下标位置；
2. 统计所有「危险时段」的数量；
3. 找出温度升高幅度最大的「危险时段」的起始与结束位置（下标均含端点）。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def analyzeTemperatureData(self, temperatures: List[int], k: int, t: int) -> List[int]` |
| Java | `public int[] analyzeTemperatureData(int[] temperatures, int k, int t)` |
| C++ | `vector<int> analyzeTemperatureData(vector<int>& temperatures, int k, int t)` |

**参数**

- `temperatures`：温度记录序列，长度 $1 \le n \le 10000$，$-100 \le \texttt{temperatures}[i] \le 100$；
- `k`：危险时段所需的连续点数，$2 \le k \le n$；
- `t`：连续升高的温度差值阈值，$0 < t \le 100$。

**返回值**

长度为 $5$ 的整数数组（或等价列表）：

```text
[最高温度值, 最高温度首次出现下标, 危险时段数量, 最大危险时段起始位置, 最大危险时段结束位置]
```

**补充规则**

- 严格单调递增：$\texttt{temperatures}[i] < \texttt{temperatures}[i+1] < \cdots < \texttt{temperatures}[i+k-1]$；
- 危险时段的升高幅度为 $\texttt{temperatures}[i+k-1] - \texttt{temperatures}[i]$，须 $\ge t$；
- 若无危险时段，起始与结束位置均返回 $-1$；
- 若多个危险时段升高幅度相同且最大，取**起始位置最小**的那个；
- 下标从 $0$ 开始计数。

## 输入输出格式（stdin / stdout）

**输入**（stdin 单行）：数组长度 $n$、逗号、一维整型数组、逗号、$k$、逗号、$t$。数组使用方括号，元素逗号分隔（逗号后可有空格）。

```text
8,[20,25,30,28,35,40,42,25],3,10
```

**输出**（stdout 一行，方括号包裹的 $5$ 个整数，逗号无空格）：

```text
[42,6,2,3,5]
```

## 数据范围

- $1 \le n \le 10000$；
- $-100 \le \texttt{temperatures}[i] \le 100$；
- $2 \le k \le n$；
- $0 < t \le 100$。

## 样例

### 样例 1

**输入**

```text
8,[20,25,30,28,35,40,42,25],3,10
```

**输出**

```text
[42,6,2,3,5]
```

**说明**

最高温度 $42$，首次出现在下标 $6$。

危险时段检测（$k=3,\ t=10$）：

- 下标 $0\sim 2$：$20 \to 25 \to 30$，升高 $10$ 度 $(\ge 10)$ ✓ 危险时段 $1$；
- 下标 $3\sim 5$：$28 \to 35 \to 40$，升高 $12$ 度 $(\ge 10)$ ✓ 危险时段 $2$；
- 下标 $4\sim 6$：$35 \to 40 \to 42$，升高 $7$ 度 $(< 10)$ ✗。

危险时段共 $2$ 个；最大升高幅度为下标 $3\sim 5$（$12$ 度）。

### 样例 2

**输入**

```text
3,[10,15,20],3,30
```

**输出**

```text
[20,2,0,-1,-1]
```

**说明**

下标 $0\sim 2$：$10 \to 15 \to 20$，升高 $10$ 度 $(< 30)$，非危险时段；无危险时段时后两项为 $-1$。

### 样例 3

**输入**

```text
6,[1, 3, 6, 2, 4, 7],3,5
```

**输出**

```text
[7,5,2,0,2]
```

**说明**

- 下标 $0\sim 2$：$1 \to 3 \to 6$，升高 $5$ 度 ✓；
- 下标 $3\sim 5$：$2 \to 4 \to 7$，升高 $5$ 度 ✓；
- 两段升高幅度同为最大 $5$，取起始下标更小的 $0\sim 2$。
