# 双资源池隔离判定

多组任务依次给出资源总数与互斥资源对。互斥的两个资源不能放入同一个资源池。判断每组任务的全部资源能否**仅使用两个资源池**完成划分：可行输出 `1`，不可行输出 `0`。

等价模型：第 $i$ 组以 $1\ldots resourceCount[i]$ 为顶点、以 $conflicts[i]$ 为边建无向图，判定该图是否为**二分图**（不存在自环，不存在奇环）。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def canIsolateWithTwoPools(self, resourceCount: List[int], conflicts: List[List[List[int]]]) -> List[int]` |
| Java | `public int[] canIsolateWithTwoPools(int[] resourceCount, int[][][] conflicts)` |
| C++ | `vector<int> canIsolateWithTwoPools(vector<int>& resourceCount, vector<vector<vector<int>>>& conflicts)` |

**参数**

- `resourceCount`：长度 $k$ 的数组，`resourceCount[i]` 表示第 $i$ 组资源编号为 $1\ldots resourceCount[i]$；
- `conflicts`：长度与 `resourceCount` 相同；`conflicts[i]` 为若干互斥对，每对 `[u, v]`（或等价二元组）表示资源 $u$ 与 $v$ 不能同池，$1 \le u, v \le resourceCount[i]$。

**返回值**

长度为 $k$ 的整数数组/列表，第 $i$ 个元素为 `1`（可划分）或 `0`（不可划分）。

## 数据范围

- $1 \le resourceCount.length \le 100$；
- $1 \le resourceCount[i] \le 10^4$；
- $0 \le conflicts[i].length \le 2 \times 10^4$；
- 所有 `resourceCount[i]` 之和 $\le 10^5$；
- 所有 `conflicts[i].length` 之和 $\le 2 \times 10^5$；
- 测试数据保证 `conflicts.length == resourceCount.length`，且边端点均在对应组资源编号范围内。

## 样例

### 样例 1

**输入**（stdin 整行：先 `resourceCount` 列表，再逗号分隔各组 `conflicts` 列表；互斥对用圆括号、逗号无空格，与下式一致）：

```text
[4,3,5],[(1,2),(1,3),(2,4)],[(1,2),(2,3),(1,3)],[(1,2),(3,4)]
```

**输出**

```text
[1,0,1]
```

**说明**

- 第 1 组可划分，例如池 1：$\{1,4\}$，池 2：$\{2,3\}$；
- 第 2 组资源 $1,2,3$ 两两互斥（奇环），两池不够；
- 第 3 组可划分，例如池 1：$\{1,3,5\}$，池 2：$\{2,4\}$。

### 样例 2

**输入**

```text
[2,2,4],[(1,2)],[],[(1,2),(2,3),(3,4),(4,1)]
```

**输出**

```text
[1,1,1]
```

**说明**

第 2 组无互斥边；第 3 组为偶数环，可二分染色。

### 样例 3

**输入**

```text
[3,4],[(1,1)],[(1,2),(2,3),(3,1)]
```

**输出**

```text
[0,0]
```

**说明**

第 1 组存在自环 $(1,1)$；第 2 组为三角形奇环。
