# P5369 测试数据说明

共 $10$ 组。单组，$m$ 个可区分箱子，输出合法排列数模 $998244353$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 $m=3$ 递增 | 可下落 `1` | 当成 $\|差\|\le d$ |
| 2 | 样例2 一高一矮 | 答案 `1` | 输出 `2` |
| 3 | 样例3 三箱同高 | $3!$ | 同高当不可区分 |
| 4 | 两同高一高 | $3!=6$ | 同高当不可区分得 `3` |
| 5 | 间隔大于 $d$ | 只能升高，答案 `1` | 输出 $m!$ |
| 6 | 四箱同高 | $4!$ | 漏模或漏阶乘 |
| 7 | $m=7$ 随机 | 与暴力对拍 | 双指针 off-by-one |
| 8 | $m=8$ 小 $d$ | 卡双向差约束 | 只允许相邻高度差 $\le d$ |
| 9 | $m=2\times10^5$ 随机 | 压测 | $O(m^2)$ |
| 10 | $m=2\times10^5$ 全 `1` | $m!\bmod 998244353$ | `int` 溢出、未取模 |

前 $8$ 组小；后 $2$ 组压测。
