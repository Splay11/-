# 题目内容

给定一个长度为 $n$ 的整数数组 $a$ 和正整数 $k$，将数组 $a$ 重复拼接 $k$ 次得到新数组，求新数组的最大连续子数组和。

# 输入描述

第一行包含两个整数 $n, k$（$1 \le n \le 10^5$，$1 \le k \le 10^4$），表示数组长度和重复次数。

第二行包含 $n$ 个整数 $a_i$（$-10^9 \le a_i \le 10^9$）。

# 输出描述

输出一个整数，表示最大连续子数组和。

## 样例 $1$

**输入**

```text
3 1
1 -2 3
```

**输出**

```text
3
```

## 样例 $2$

**输入**

```text
4 3
1 2 -1 3
```

**输出**

```text
15
```
