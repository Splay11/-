# 数据生成说明

本题本地数据保证 $N$ 为正整数，十进制表示长度不超过 $4001$ 位。

| 组别 | 类型 | 目标 |
|---:|---|---|
| 1 | 小数据 | 样例测试：覆盖题面样例，答案为 2。 |
| 2 | 小数据 | 边界测试：最小正整数，答案为 0。 |
| 3 | 小数据 | 边界测试：刚好是 2 的 1 次幂。 |
| 4 | 小数据 | 边界测试：刚好小于 2 的 2 次幂，卡 k+1 判断。 |
| 5 | 小数据 | 构造测试：刚好小于 2 的 20 次幂，卡 off-by-one。 |
| 6 | 小数据 | 构造测试：刚好等于 2 的 20 次幂。 |
| 7 | 小数据 | 随机测试：中等规模非特殊大数。 |
| 8 | 小数据 | 构造测试：超过常规整数范围，卡 64 位溢出。 |
| 9 | 大数据 | 大数据：接近 2 的幂但差 1，卡浮点 log2 与边界。 |
| 10 | 大数据 | 大数据：4001 位十进制数，压测大整数读入。 |

主要针对的错误解法：

- 使用 `int` / `long long` 读入导致溢出。
- 使用浮点 `log2` 处理超大整数导致精度错误。
- 对 $N=2^t$ 或 $N=2^t-1$ 的边界判断错误。
