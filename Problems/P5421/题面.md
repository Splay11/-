# 题目内容

有一排无限长的连续木板。你有 $n$ 种颜色，第 $i$ 种颜色对应一个参数 $a_i$。上色规则为如果第 $k$ 块木板被涂成颜色 $i$，那么 $k-a_i$ 与 $k+a_i$ 的木板也必须被涂成颜色 $i$（反复应用这一规则）。

换句话说，木板按整数编号 $(\dots,-2,-1,0,1,2,\dots)$，无限延伸至正负两端。若第 $k\ (k\in \mathbb Z)$ 块木板被涂成颜色 $i$，第 $k-a_i$ 与 $k+a_i$ 也必须涂该色，依此规则反复推广。

为适配喷涂设备的节奏，你可以先选择一个正整数 $L$ 作为“整体节拍”。选定 $L$ 后，需要同时满足：
- 只能使用那些步长 $L$ 能整除 $a_i$ 的颜色（即 $a_i$ 是 $L$ 的整数倍）；
- 所使用的不同颜色的初始上色位置（即规则中的 $k$ 值）在模 $L$ 意义下必须是互不相同的。

每块木板至多涂一种颜色，允许有未上色的木板。请你使被使用的颜色种类数尽可能多，并输出能达到的最大值。




# 输入描述

每个测试文件均包含多组测试数据。第一行输入一个整数 $T\ (1 \le T \le 2 \times 10^5)$ 代表数据组数，每组测试数据描述如下：

第一行输入一个整数 $n\ (1 \le n \le 2 \times 10^5)$；

第二行输入 $n$ 个整数 $a_1,a_2,\dots,a_n\ (1 \le a_i \le 2 \times 10^5)$。

保证所有测试中 $n$ 的总和不超过 $3 \times 10^5$。




# 输出描述

对于每组测试数据，输出一个整数，表示可以使用的颜色种类的最大数量。



## 样例1 



**输入** 



```
2
5
1 2 3 4 6
4
2 2 3 3
```



**输出** 



```
2
2
```



**说明**

对于第一组测试数据，选择 $L=2$。此时，参数 $a_i$ 是 $2$ 倍数的颜色共有三种（参数分别为 $2,4,6$）。由于节拍为 $2$，最多只能使用 $2$ 种互不干扰的颜色，因此选用 $L=2$ 时最多能使用 $2$ 种颜色。尝试其他 $L$ 的选择，无法得到更优的答案，故最终答案为 $2$。
