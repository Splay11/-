# 根据字符出现频率排序

算法标签：哈希表、排序

算法难度：$4 / 10$

## 解题思路

按字符出现次数从高到低重排字符串。同一字符必须连在一起。次数相同的字符之间顺序任意。大小写视为不同字符。

1. 统计每个字符出现多少次。字符种类最多是大小写字母加数字，一共 $62$ 种。
2. 把出现过的字符按次数从高到低排序；次数相同按字符 ASCII 排，方便写出确定的一种合法答案。
3. 按这个顺序把每个字符连续重复输出对应次数。
4. 常见假解：次数相同的字符交叉摆放（例如 $cacaca$）；把 $A$ 和 $a$ 当成同一个字符；没按次数降序。

本题答案不唯一，评测用 special judge：长度相同、每种字符个数相同、相同字符连续、各段次数单调不增即可。

## 复杂度分析

- 时间复杂度：$O(|s|+C\log C)$，$C\le 62$。
- 空间复杂度：$O(|s|)$。

## 代码实现

### Python

```python
def solve(s):
    """统计每个字符出现次数。
    先按次数从高到低、次数相同再按字符本身排序，保证三语言输出一致。
    同一字符必须连在一起输出。
    """
    cnt = {}
    for ch in s:
        cnt[ch] = cnt.get(ch, 0) + 1
    items = list(cnt.items())
    items.sort(key=lambda x: (-x[1], x[0]))
    parts = []
    for ch, c in items:
        parts.append(ch * c)
    return "".join(parts)


def main():
    s = input().strip()
    print(solve(s))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.ArrayList;
import java.util.Collections;
import java.util.Comparator;

public class Main {
    static String solve(String s) {
        int[] cnt = new int[256];
        for (int i = 0; i < s.length(); i++) {
            cnt[s.charAt(i)]++;
        }
        ArrayList<int[]> items = new ArrayList<int[]>();
        for (int c = 0; c < 256; c++) {
            if (cnt[c] > 0) {
                items.add(new int[] {cnt[c], c});
            }
        }
        Collections.sort(items, new Comparator<int[]>() {
            public int compare(int[] a, int[] b) {
                if (a[0] != b[0]) {
                    return b[0] - a[0];
                }
                return a[1] - b[1];
            }
        });
        StringBuilder sb = new StringBuilder(s.length());
        for (int i = 0; i < items.size(); i++) {
            int times = items.get(i)[0];
            char ch = (char) items.get(i)[1];
            for (int k = 0; k < times; k++) {
                sb.append(ch);
            }
        }
        return sb.toString();
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String s = br.readLine();
        System.out.println(solve(s));
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
#include <utility>
using namespace std;

string solve(const string& s) {
    int cnt[256] = {0};
    for (int i = 0; i < (int)s.size(); i++) {
        cnt[(unsigned char)s[i]]++;
    }
    vector<pair<int, char> > items;
    for (int c = 0; c < 256; c++) {
        if (cnt[c] > 0) {
            items.push_back(make_pair(-cnt[c], (char)c));
        }
    }
    sort(items.begin(), items.end());
    string ans;
    ans.reserve(s.size());
    for (int i = 0; i < (int)items.size(); i++) {
        int times = -items[i].first;
        char ch = items[i].second;
        ans.append(times, ch);
    }
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    cout << solve(s) << '\n';
    return 0;
}
```
