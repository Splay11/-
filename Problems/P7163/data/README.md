# P7163 测试数据说明

主造数脚本：题目根目录 `gen.py`。多解，评测使用 `checker.cc`（testlib）。
约束：$1\le |s|\le 5\times 10^5$，大小写字母与数字。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1，$e$ 两次 | eert（也允许 eetr） | 交错输出 eret |
| 2 | 样例 2，次数相同 | aaaccc 或 cccaaa | cacaca 交错 |
| 3 | 样例 3，大小写不同 | bbAa | 把 A、a 合并 |
| 4 | 长度 1 | a | 输出空 |
| 5 | 单字符重复 | zzzzz | 输出 z |
| 6 | 字母数字各一次 | 按 ASCII 的一种合法序 | 打乱相同频率的块内部 |
| 7 | 多字母不同次数 | 频率降序连续块 | 没把相同字母连在一起 |
| 8 | 中等随机 | 自校验计数与连续性 | 按字典序而不是频率 |
| 9 | 较长串，a、b 次数相同 | SPJ 允许两种块顺序 | 交叉摆放 a、b |
| 10 | 压满 |s|=5e5，62 种字符 | O(|s|) | O(|s|^2) 排序 TLE |

`.in` 为整串且末尾无换行；`.out` 末尾恰好一个换行符。
