# P5343 测试数据说明

共 $10$ 组。第一行 $q$，随后 $q$ 行各一个 $p$。对每个 $p$ 输出 $\sum_{i=1}^{p-1}(i\oplus(i+1))$ 对 $1000000007$ 取模。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 | 小 $p$ 手算 | 漏边、异或写成加 |
| 2 | 样例2 | $p=16,4$ | 公式常数项 |
| 3 | 样例3 | $p=100$ | 取模时机 |
| 4 | $p=1$ | 空路为 $0$ | 输出 $-1$ 或模数 |
| 5 | $2$ 的幂 | $\mathrm{ctz}$ 边界 | 位移少一位 |
| 6 | $p=10^{18}$ | 必须 $O(\log p)$ | $O(p)$ 暴力 TLE |
| 7 | $p=1..20$ | 与暴力对拍 | 递推写错 |
| 8 | $p\le 10^6$ 随机 | 中等 | `int` 溢出 |
| 9 | $1000$ 组极值 | 反复 $1$ 与 $10^{18}$ | 预处理假设 $p$ 小 |
| 10 | $q=10^5$ | 压测读入 | TLE / 少输出行 |

前 $8$ 组小或可对拍；后 $2$ 组压测。
