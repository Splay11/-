# 题目内容

在数轴上有点 $1,2,3,\dots,n$。仅相邻点之间有无向边，边权为两个端点的按位异或值：边 $((i,i+1))$ 的权为 $i \oplus (i+1)$。求从 $1$ 出发到 $n$ 的路径权值和，对 $10^9+7$ 取模。等价地，答案为 $\sum_{i=1}^{n-1}\big(i \oplus (i+1)\big)$ 的值，对 $10^9+7$ 取模。

【名词解释】
符号 $\oplus$ 表示按位异或（bitwise XOR）。对任意非负整数 $(x,y)$，按二进制逐位定义：若某一位上 $x$ 与 $y$ 的该位不同（$0$ 与 $1$），则该位结果为 $1$；相同则为 $0$。等价表述：逐位对 $(x,y)$ 做不进位加法（每一位上
$0 \oplus 0 = 0,\ 0 \oplus 1 = 1,\ 1 \oplus 0 = 1,\ 1 \oplus 1 = 0$）。




# 输入描述

每个测试文件均包含多组测试数据。第一行输入一个整数 $T\ (1 \le T \le 2 \times 10^5)$ 代表数据组数，每组测试数据描述如下：

在一行上输入一个整数 $n\ (1 \le n \le 10^{18})$。



# 输出描述

输出 $T$ 行，每行一个整数，表示从 $1$ 到 $n$ 的路径权值和对 $10^9+7$ 取模的结果。
