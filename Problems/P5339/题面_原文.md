# 题目内容

在一个古老的王国里，有一张$ m × n$ 的方格地图，每个格子要么是城墙（$X$），要么是村庄（$O$）。

王国的法律规定：

- 如果一个村庄能够通过连续的村庄道路，最终通到地图边界（意味着能与外界贸易往来），它就属于自由村庄，不能被改变。
- 如果某一片村庄完全被城墙包围，并且无论怎样走都无法到达地图边界，那么这片村庄就被认定为封闭领地，后续会被王国改建为城墙（全部变成 $X$）。

你的任务是帮助王国的规划官检查整张地图`board`：找出所有无法通往边界的村庄区域，返回被改建为城墙的村庄的个数。

# 输入描述

二维列表的行和列，以及二维列表详情，其中包含墙（$X$）和村庄（$O$）

# 输出描述

返回被改建为城墙的村庄的个数，返回值为整数。



## 样例1 

**输入** 

```
1 1
x
```

**输出** 

```
0
```

**说明**

整张地图中，没有$O$，故不存在需要改造的村庄，返回$0$

## 样例2

**输入** 

```
4 4
xxxx
xoox
xxox
xoxx
```

**输出** 

```
3
```

**说明**

最后一行的 $O$ 连通到了边界，不能改变，中间两行的 $3$ 个 $O$ 无法与地图边界连通，需要改造为城墙。因此，整张地图里面需要改造的村庄数量为 $3$，故返回 $3$。
