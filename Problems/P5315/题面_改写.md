# 窗口严格高峰下标

# 题目内容

请找出整数序列里所有「窗口严格高峰」的位置，按下标从小到大输出。

给定长度为 $m$ 的整数序列 $v_1,v_2,\dots,v_m$，以及非负整数窗口半径 $w$。称位置 $i$ 是窗口严格高峰，当且仅当对所有满足 $1 \le j \le m$ 且 $1 \le |j-i| \le w$ 的下标 $j$，都有 $v_i > v_j$。也就是：$i$ 必须严格高于左右各至多 $w$ 格内的每一个数。

特别地，当 $w=0$ 时，每个位置都是窗口严格高峰。下标从 $1$ 开始编号。

# 输入描述

第一行一个整数 $q$（$1 \le q \le 10^5$），表示询问组数。

每组第一行两个整数 $m$、$w$（$1 \le m \le 2 \times 10^5$，$0 \le w \le 2 \times 10^5$）。

第二行 $m$ 个整数 $v_1,v_2,\dots,v_m$（$-10^9 \le v_i \le 10^9$）。

保证所有组的 $m$ 之和不超过 $2 \times 10^5$。

# 输出描述

对每组输出两行：

- 第一行一个整数 $k$，表示窗口严格高峰的个数。
- 第二行 $k$ 个严格递增的整数，即这些位置的下标；若 $k=0$，第二行输出空行。

## 样例1

**输入**

```
2
4 1
4 1 3 2
3 0
7 7 7
```

**输出**

```
2
1 3
3
1 2 3
```

**说明**

第一组窗口半径为 `1`。位置 `1` 的值 `4` 大于右边的 `1`；位置 `3` 的值 `3` 大于左边的 `1` 和右边的 `2`。位置 `2`、`4` 都不能严格高于邻居。

第二组 $w=0$，三个位置都是高峰。

## 样例2

**输入**

```
1
3 1
2 2 2
```

**输出**

```
0

```

**说明**

三个数相等，谁也不能严格高于窗口里的其他位置，所以没有高峰，第二行为空行。
