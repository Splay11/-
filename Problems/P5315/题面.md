# 题目内容


给定一个长度为 $n$ 的整数序列 $a_1,a_2,\dots,a_n$，以及一个非负整数窗口距离 $d$。定义位置 $i$ 是一个 $d$-极峰，当且仅当对所有满足 $1 \le j \le n$ 且 $1 \le |j-i| \le d$ 的位置 $j$，都有 $a_i > a_j$。请找出所有 $d$-极峰所在的位置索引，并按从小到大输出。特别地，当 $(d=0)$ 时，每个位置都是 $d$-极峰。



# 输入描述

每个测试文件包含多组测试数据。第一行输入一个整数 $T(1 \le T \le 10^5)$ 表示数据组数，每组测试数据描述如下：

第一行输入两个整数 $n,d\ (1 \le n \le 2 \times 10^5,\ 0 \le d \le 2 \times 10^5)$。

第二行输入 $n$ 个整数 $a_1,a_2,\dots,a_n\ (-10^9 \le a_i \le 10^9)$。

保证所有测试数据的 $n$ 之和不超过 $2 \times 10^5$。


# 输出描述

对于每组测试数据，输出两行：
- 第一行输出一个整数 $k$，表示 $d$-极峰的数量。
- 第二行输出 $k$ 个严格递增的整数，表示所有 $d$-极峰的位置索引；若 $(k=0)$，则该行输出为空行。




## 样例1 



**输入** 



```
2
8 2
1 3 3 2 5 4 4 6
5 0
2 2 1 3 3
```



**输出** 



```
2
5 8
5
1 2 3 4 5
```
