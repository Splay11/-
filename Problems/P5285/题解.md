# 双抽核验期望轮次

## 解题思路

一轮核验通过，当且仅当第一次抽到 $X$、第二次抽到 $Y$，两次独立。

1. 统计密级 $X$、$Y$ 的出现次数 $c_X$、$c_Y$。
2. 一轮成功概率 $p=\dfrac{c_X}{m}\cdot\dfrac{c_Y}{m}$。
3. 轮次服从几何分布，期望 $E=\dfrac{1}{p}=\dfrac{m^2}{c_X\cdot c_Y}$，保留一位小数。

## 复杂度分析

- 时间复杂度：$O(m)$。
- 空间复杂度：$O(1)$（不计读入）。

## 代码实现

### Python

```python
def solve(n, A, B, a):
  # 统计目标密级出现次数
  ca = sum(1 for x in a if x == A)
  cb = sum(1 for x in a if x == B)
  return n * n / (ca * cb)


n, A, B = map(int, input().split())
a = list(map(int, input().split()))
print("%.1f" % solve(n, A, B, a))
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
  public static void main(String[] args) throws IOException {
    Scanner sc = new Scanner(System.in);
    int n = sc.nextInt();
    long A = sc.nextLong(), B = sc.nextLong();
    long ca = 0, cb = 0;
    for (int i = 0; i < n; i++) {
      long x = sc.nextLong();
      if (x == A) ca++;
      if (x == B) cb++;
    }
    double ans = 1.0 * n * n / (ca * cb);
    System.out.printf("%.1f\n", ans);
  }
}
```
