# 题目内容

小红有一个 $n$ 面骰子。这个骰子每个面上都写有一个数字。小红每次抛骰子时，骰子会等概率落在某一面上。

在每一轮游戏中，小红将会抛两次骰子（这两次抛掷互相独立）。她认为当且仅当第一次掷出的数字为 $A$、第二次掷出的数字为 $B$ 时，她将会得到好运气。

小红将不断进行游戏，直到第一次得到好运气时停止。

请问期望进行多少轮，小红才能得到好运气？

# 输入描述

第一行三个整数 $n,A,B$，含义如题所示。

接下来一行 $n$ 个非负整数 $a_1,a_2,\ldots,a_n$，表示骰子上每个面上的数字。

# 输出描述

输出一个浮点数，表示期望进行的轮数，保留一位小数即可。

## 样例1

**输入**

```
2 1 2
1 2
```

**输出**

```
4.0
```

**说明**

第一次掷出 $1$ 的概率为 $\frac{1}{2}$，第二次掷出 $2$ 的概率为 $\frac{1}{2}$，一轮内得到好运气的概率为 $\frac{1}{4}$，期望轮数为 $4$。

## 样例2

**输入**

```
5 1 2
1 2 2 2 3
```

**输出**

```
8.3
```

# 数据范围

- $2\le n\le 10^5$
- $0\le A,B,a_i\le 10^9$，且 $A\neq B$
- 保证 $A$、$B$ 都在面上出现过
