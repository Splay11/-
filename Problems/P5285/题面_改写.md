# 双抽核验期望轮次

# 题目内容

档案室值班岗位每次核验要连抽两份档签。柜内共有 `m` 格，第 `j` 格档签上印着密级 $v_j$。抽签规则由值班手册给出：每一格被抽到的概率相同，两次抽取互相独立（抽完放回）。

只有「第一次抽到密级 $X$，并且第二次抽到密级 $Y$」才算核验通过。值班同学从第 `1` 轮开始，每轮按上述规则抽两次；未通过则立刻开始下一轮，直到某一轮首次通过为止。

设一轮通过的概率为 $p$。该过程是成功概率为 $p$ 的几何分布，期望轮次为
$$
E=\frac{1}{p}.
$$
其中
$$
p=\frac{c_X}{m}\times\frac{c_Y}{m},
$$
$c_X$ 为密级等于 $X$ 的格数，$c_Y$ 为密级等于 $Y$ 的格数。保证 $X\neq Y$，且两种密级都至少出现一次。

输出期望轮次，保留一位小数。

约束：$2\le m\le 100000$，$0\le X,Y,v_j\le 1000000000$，且 $X\neq Y$，柜中必有 $X$ 与 $Y$。

# 输入描述

第一行三个整数 `m`、`X`、`Y`，分别表示格数、第一次目标密级与第二次目标密级（`2` $\le$ `m` $\le$ `100000`，`0` $\le$ `X`,`Y` $\le$ `1000000000`，`X` $\neq$ `Y`）。

第二行 `m` 个非负整数 $v_1,v_2,\ldots,v_m$，表示各格密级（`0` $\le$ $v_j$ $\le$ `1000000000`）。

# 输出描述

输出一个浮点数，表示期望核验轮次，保留一位小数。

## 样例1

**输入**

```
3 8 5
8 5 5
```

**输出**

```
4.5
```

**说明**

密级 `8` 出现 `1` 格，密级 `5` 出现 `2` 格。一轮通过概率为 $\frac{1}{3}\times\frac{2}{3}=\frac{2}{9}$，期望为 $\frac{9}{2}=4.5$。

## 样例2

**输入**

```
4 0 1
0 0 1 1
```

**输出**

```
4.0
```

**说明**

$c_X=2$，$c_Y=2$，$p=\frac{1}{4}$，期望为 `4.0`。
