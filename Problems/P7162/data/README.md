# P7162 测试数据说明

主造数脚本：题目根目录 `gen.py`。元素互异且不含 $0$。
约束：$1\le n\le 10^5$，$-10^9\le nums_i\le 10^9$，$nums_i\\ne 0$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1，两对 | 2 | 数两次得到 4 |
| 2 | 样例 2，没有相反数 | 0 | 输出 n |
| 3 | 样例 3，三对 | 3 | 漏掉负数一侧 |
| 4 | n=1 | 0 | 输出 1 |
| 5 | 值域两端成对 | 1 | int 取负溢出 |
| 6 | 一对夹一个无关正数 | 1 | 把 4 也算进去 |
| 7 | 两对加一个落单 | 2 | 双计数得到 4 |
| 8 | 中等互异随机符号 | 对拍 | 排序去重后丢符号 |
| 9 | 压满全是正数 | 0 | O(n^2) TLE |
| 10 | 压满 5e4 对相反数 | 50000 | 双计数得到 100000 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。
