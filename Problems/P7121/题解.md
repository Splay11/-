# 找出数组中的第k大整数

## 解题思路

本题用到的是「排序 + 自定义比较规则」，难点不在排序本身，而在**怎么比较两个大整数**。

1. 题面规定每个字符串最长可达 $100$ 位，而 $64$ 位整数最多只能表示约 $19$ 位十进制数，所以**不能**把字符串转成 `int` / `long long` / `long` 再比较，否则会溢出。必须在字符串层面直接比较大小。
2. 利用题面给的「不含前导零」这一条件，可以设计出与数值大小完全等价的比较规则：
   - **长度不同**：长度更长的那个数一定更大。例如 `10` 比 `9` 大，虽然字典序上 `"9" > "10"`。
   - **长度相同**：此时两个数的位数一样，逐位比较也就是字典序比较，字典序大的数更大。例如同为两位时 `21 > 12`。
3. 按上面的规则把整个数组**从大到小**排序，则第 $k$ 大的整数就是排序后的第 $k$ 个元素，即下标 $k-1$。
4. 题面特别说明重复的数字要分别参与排名，所以**不需要去重**，直接按下标取即可。例如 `1,2,2` 从大到小是 `2,2,1`，第 $2$ 大是 `2`。

实现上，Python 可以直接把排序键取成 `(len(s), s)` 并倒序排；C++ 与 Java 则写一个自定义比较器，先比长度、长度相同再比字典序。

## 复杂度分析

时间复杂度为 $O(n \log n \cdot L)$：排序需要 $O(n \log n)$ 次比较，每次字符串比较最坏要扫完 $L \le 100$ 个字符，因此总代价是 $O(n \log n \cdot L)$。本题 $n \le 10^4$、$L \le 100$，完全可以接受。

空间复杂度为 $O(n)$：排序本身需要 $O(\log n)$ 的递归栈空间，另外 Python 的 `sorted` 会额外产生一个长度为 $n$ 的新列表；C++ 的 `sort` 与 Java 的 `Arrays.sort` 都在原数组上就地排序。

## 代码实现

### Python

```python
class Solution:
    def kthLargestNumber(self, nums, k):
        # 排序键取 (长度, 字符串本身)，并倒序排，等价于「先按数值从大到小排」：
        # reverse=True 时先按长度从大到小，长度相同的再按字典序从大到小
        ordered = sorted(nums, key=lambda s: (len(s), s), reverse=True)
        # 第 k 大对应排序后下标 k-1（重复元素各自占一个名次，无需去重）
        return ordered[k - 1]


def main():
    # 第一行：n（数组长度）和 k（排名）
    n, k = map(int, input().split())
    # 第二行：n 个表示非负整数的字符串
    nums = input().split()
    # 输出第 k 大的那个字符串
    print(Solution().kthLargestNumber(nums, k))


if __name__ == "__main__":
    main()```

### Java

```java
import java.util.Arrays;
import java.util.Scanner;

public class Main {
    static String kthLargestNumber(String[] nums, int k) {
        // 自定义比较器按「数值从大到小」排序
        Arrays.sort(nums, (a, b) -> {
            if (a.length() != b.length()) {
                // 长度不同：长的数更大，排在前面
                return b.length() - a.length();
            }
            // 长度相同且无前导零：字典序大的数更大，排在前面
            return b.compareTo(a);
        });
        // 第 k 大对应排序后下标 k-1（重复字符串各自占一个名次，不需要去重）
        return nums[k - 1];
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // 第一行：n（数组长度）和 k（排名）
        int n = sc.nextInt();
        int k = sc.nextInt();
        // 第二行：n 个表示非负整数的字符串
        String[] nums = new String[n];
        for (int i = 0; i < n; i++) {
            nums[i] = sc.next();
        }

        // 输出第 k 大的那个字符串
        System.out.println(kthLargestNumber(nums, k));
        sc.close();
    }
}```

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

string kthLargestNumber(vector<string>& nums, int k) {
    sort(nums.begin(), nums.end(), [](const string& a, const string& b) {
        if (a.size() != b.size()) {
            // 长度不同：长的数更大，排在前面
            return a.size() > b.size();
        }
        // 长度相同且无前导零：字典序大的数更大，排在前面
        return a > b;
    });
    // 第 k 大对应排序后下标 k-1（重复字符串各自占一个名次，不需要去重）
    return nums[k - 1];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // 第一行：n（数组长度）和 k（排名）
    int n, k;
    cin >> n >> k;
    // 第二行：n 个表示非负整数的字符串
    vector<string> nums(n);
    for (int i = 0; i < n; i++) {
        cin >> nums[i];
    }

    // 输出第 k 大的那个字符串
    cout << kthLargestNumber(nums, k) << "\n";
    return 0;
}```
