# 题目内容

给你一个长度为 $n$ 的字符串数组 $nums$ 和一个整数 $k$。数组 $nums$ 中的每个字符串都表示一个不含前导零的非负整数。

请找出 $nums$ 中表示第 $k$ 大整数的字符串。

在比较两个字符串所表示的整数大小时，应按照它们对应的数值进行比较，而不是按照字符串的字典序进行比较。

注意，重复的数字在统计排名时需要视为不同的元素。例如，如果 $nums$ 中的数字依次为 $1$、$2$、$2$，那么最大的整数是 $2$，第二大的整数也是 $2$，第三大的整数是 $1$。

# 输入描述

第一行输入两个整数 $n$ 和 $k$，分别表示字符串数组 $nums$ 的长度以及需要寻找的排名。

第二行输入 $n$ 个字符串 $nums_i$，每个字符串表示一个非负整数，相邻字符串之间用空格分隔。

### 约束

$1 \le k \le n \le 10^4$

$1 \le nums_i.length \le 100$

$nums_i$ 仅由数字 $0$ 到 $9$ 组成。

$nums_i$ 不包含任何前导零。

# 输出描述

输出一个字符串，表示数组 $nums$ 中第 $k$ 大的整数。

## 样例 $1$

**输入**

```text
4 4
3 6 7 10
```

**输出**

```text
3
```

**说明**

将所有数字按照从大到小的顺序排列后为：

$10,7,6,3$

其中第 $4$ 大的整数为 $3$。

## 样例 $2$

**输入**

```text
4 3
2 21 12 1
```

**输出**

```text
2
```

**说明**

将所有数字按照从大到小的顺序排列后为：

$21,12,2,1$

其中第 $3$ 大的整数为 $2$。

## 样例 $3$

**输入**

```text
2 2
0 0
```

**输出**

```text
0
```

**说明**

将所有数字按照从大到小的顺序排列后为：

$0,0$

重复的数字需要分别参与排名，因此第 $2$ 大的整数为 $0$。
