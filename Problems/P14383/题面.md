# 网关最小间隔放行方案计数

在微服务网关中，为防止同一用户短时间内请求过多，采用**最小请求间隔**限流：任意两个被放行的请求时间戳之差须 **$\ge$ `minInterval`** 秒（例如 `minInterval = 2` 时，$1$ 与 $3$ 可同时放行，$1$ 与 $2$ 不可）。

现有一批同一用户的请求，每个请求有一个整数时间戳（秒）。从这批请求中**任选子集放行**（可为空集），要求子集中任意两时间戳之差 $\ge$ `minInterval`。求**合法放行方案总数**。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def countValidPlans(self, timestamps: List[int], minInterval: int) -> int` |
| Java | `public int countValidPlans(int[] timestamps, int minInterval)` |
| C++ | `int countValidPlans(vector<int>& timestamps, int minInterval)` |

**语义**：`timestamps` 可能乱序、元素互不相同；统计满足间隔约束的子集个数（含空集）。

## 数据范围

- $1 \le \texttt{timestamps.length} \le 15$
- $0 \le \texttt{timestamp} \le 10^9$
- `minInterval` 为正整数

## 样例

### 样例 1

**输入**（stdin 一行：`[...]` 后紧跟逗号与 `minInterval`，无空格）：

```text
[1,2,4],2
```

**输出**

```text
6
```

**说明**：合法方案：$[]$、$[1]$、$[2]$、$[4]$、$[1,4]$、$[2,4]$。

### 样例 2

**输入**

```text
[10],5
```

**输出**

```text
2
```

（$[]$ 与 $[10]$）

## 评测输入输出

- **输入**：一行，格式为 `[t0,t1,...],minInterval`（整数列表为 Python/JSON 风格方括号列表，逗号后直接跟间隔整数）。
- **输出**：一行一个非负整数；行末换行。
