# P7153 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：一行数字字符串 $s$。
输出：解码方案数；不能完整解码则为 $0$。

约束：$1\le |s|\le 100$，答案在有符号 $32$ 位整数范围内。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1 | $2$ 种：$AB$ 或 $L$ | 漏掉两位编码 |
| 2 | 样例 2 | $3$ 种 | 把 $26$ 漏掉或把 $27$ 当成合法两位 |
| 3 | 样例 3，前导零 | $0$ | 把 $06$ 当成 $6$ |
| 4 | 单个 $0$ | $0$ | 当成 $A$ 得到 $1$ |
| 5 | $10$ 只能两位 | $1$ | 拆成 $1,0$ 得到 $0$ 或再加一种 |
| 6 | $27$ 不能当两位 | 只能 $2,7$，共 $1$ 种 | 当成 $B$ 和某非法字母仍加一 |
| 7 | 中间的 $0$ 必须跟前面组成 $10$ | $1$ 种：$10,1$ | 拆成 $1,01$ 或 $10,1$ 和 $1,0,1$ |
| 8 | 长度 $20$ 随机数字 | DP 与记忆化搜索对拍 | 不处理前导零 |
| 9 | 压满 $100$ 个 $3$ | 每位只能单独译，方案数 $1$ | 当成斐波那契得到巨大数 |
| 10 | 压满 $100$，含 $10$ 与一长串 $1$ | 方案数仍在 $32$ 位整数内 | 递归无记忆化 TLE |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：线性 DP 必须等于记忆化搜索，且答案 $\le 2^{31}-1$。
