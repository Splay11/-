# 回退审核检修

# 题目内容

结算台要把已入账交易的回退申请做成风险分级、人工流转和低风险自动过闸。台上已经有一套可运行的审核服务，但实现里被故意埋了多处业务、状态、安全和数据处理缺陷。检修员不必从零搭服务，而是在现有工程上完成：对照契约找出不符点、改 `project/` 源码、补测试，并做成低风险自动过闸（模型异常必须转人工）。所有与时间有关的计算必须使用固定业务时刻 `2026-08-20T10:00:00+08:00`，不得读取设备当前时间。

技术栈：Java `17`+ / Spring Boot / Maven，官方测试为 JUnit `5`。请不要更改本文件、`src/main/resources/refunds.json` 与 `src/test/` 下的官方公开测试。

### 2.2 业务逻辑说明

核心逻辑集中在 `RefundService`（静态纯函数）：

1. `toCny(amount, currency)`：金额换算，USD × `7.20` 转为人民币。
2. `riskTier(score)`：风险分映射为 `HIGH` / `MEDIUM` / `LOW` / `UNKNOWN`。
3. `dedupeRefunds(rows)`：按 `refundId` 去重，保留业务版本较新记录。
4. `sortRefunds(rows, field, order)`：按金额或时间排序，不得修改输入。
5. `isOverdue(row, now)`：SLA 超时判定。
6. `canTransition(from, to)` / `applyBatch(rows, currentPageIds, target, reason)`：状态机与批量处置。
7. `validReason(reason)`：审核理由校验。
8. `canReadRefund(actor, row)`：租户与用户双重隔离。
9. `summarize(rows)`：总览指标计算。
10. `autoReview(row, model)`：低风险自动过闸与降级。
11. `appendDecision(store, key, decision, now)`：审计幂等追加。

`RefundController` 提供 REST API（统一前缀 `/api`）：`GET /health`、`GET /api/refunds`、`GET /api/refunds/summary`、`GET /api/refunds/audit`、`GET /api/refunds/{id}`、`POST /api/refunds/{id}/transition`、`POST /api/refunds/batch`、`POST /api/refunds/auto-review`。

源码中存在多处刻意植入的缺陷；数量与位置不会公开。

#### 数据模型

**Refund**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| refundId | string | 唯一编号，可能有多个版本 |
| tenantId / userId | string | 租户与归属用户（双重隔离依据） |
| amount | number \| string | 原币金额，可能为数字字符串或非法字符串 |
| currency | string | 仅接受 `CNY` / `USD` |
| riskScore | number \| string \| null | 风险分，非法或空值映射为 `UNKNOWN` |
| status | string | `CREATED` / `REVIEWING` / `APPROVED` / `REJECTED` / `CANCELLED` |
| updatedAt / dueAt | string (ISO 8601) | 版本时间与 SLA 到期时间 |

**Decision**

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| key | string | 决策幂等键，同一 key 只产生一条审计 |
| decision | string | 决策结果 |
| at | string (ISO 8601) | 审计时间，使用固定业务时间 |

#### 业务规则

- 金额：`CNY` 保持不变，`USD` × `7.20` 转为人民币；仅接受这两种币种。金额须为非负有限数，数字字符串可按字段约定转换；`null`、空串、`NaN`、`Infinity`、负金额等非法值必须拒绝（响应字段返回 `null`），不能静默变成 `0`。
- 风险：`score >= 80` 为 `HIGH`，`50 <= score < 80` 为 `MEDIUM`，其余合法非负数为 `LOW`；空值、非法值和负数为 `UNKNOWN`。所有阈值均包含边界。
- 去重：按 `refundId` 去重，保留 `updatedAt` 较晚记录；同时间或都无有效时间时保留后出现记录。排序返回新数组，不得原地修改输入。
- 状态：`CREATED -> REVIEWING | CANCELLED`，`REVIEWING -> APPROVED | REJECTED`，三个终态不可再流转。SLA 仅统计非终态且 `dueAt < now` 的记录。
- 权限：管理员可读全部；普通用户仅可读取「同 tenant 且同 userId」的记录，任一条件不满足均拒绝。
- 批量处置：只遍历 `currentPageIds`，逐项校验流转和 trim 后不少于 `5` 字符的原因，返回 `{changed, skipped}`，不得修改非目标或终态记录。
- 幂等：同一决策 `key` 只能产生一条审计记录，并返回原稳定记录；审计时间使用传入 `now`（固定业务时间）。
- 自动过闸：人民币等值 <= `200` 且风险分 < `30` 才调用模型；模型仅明确返回 `APPROVED` 才通过，通过后状态直接置为 `APPROVED` 并追加审计（自动通道，不经手动流转白名单）。异常、超时、空值或非法结果一律 `{decision:'MANUAL'}`。
