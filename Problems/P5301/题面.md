# 题目内容

给定一个长度为 $n$ 的整数数组 $a$，需要进行两类操作，每次操作都在上一次操作的结果上进行：

- 操作一：$1$ $i$ $x$，将 $a_i$ 修改为 $x$。
- 操作二：$2$，表示查询当前所有元素两两差的绝对值之和
$$S(a)=\sum_{1\le i<j\le n}|a_i-a_j|$$



# 输入描述

每个测试文件均包含多组测试数据。第一行输入一个整数 $T (1 \le T \le 10^5)$ 代表数据组数，每组测试数据描述如下。

第一行输入两个整数 $n, m(1 \le n, m \le 2 \times 10^5)$。

第二行输入 $n$ 个整数 $a_1,a_2,\dots,a_n(|a_i| \le 10^9)$。

接下来 $m$ 行，每行一条操作：若为修改，输入 $1$ $i$ $x$，其中 $1 \le i \le n,|x| \le 10^9$；若为查询，输入 $2$。

保证所有测试中 $(n+m)$ 的总和不超过 $5 \times 10^5$。




# 输出描述


对于每组测试数据中的每次查询操作，输出一行一个整数，即当前 $(S(a))$。


## 样例1 



**输入** 



```
2
3 3
1 3 6
2
1 2 8
2
2 3
-4 4
2
1 1 4
2
```



**输出** 



```
10
14
8
0
```



**说明**


第一组数据的数组是 $(1,3,6)$，三对元素的差的绝对值分别是 $|1-3|=2,|1-6|=5,|3-6|=3$，首次查询答案为 $(2+5+3=10)$。随后把 $a_2$ 改成 $8$，数组变为 $(1,8,6)$，三对元素给出 $|1-8|=7,|1-6|=5,|8-6|=2$，第二次查询答案为 $(7+5+2=14)$。

第二组数据的数组是 $-(4,4)$，只有一对元素，$|-4-4|=8$，首次查询答案为 $8$。随后把 $a_1$ 改成 $4$，数组变为 $(4,4)$，唯一一对元素的差的绝对值为 $0$，第二次查询答案为 $0$。




## 样例2



**输入** 



```
1
4 3
2 2 2 2
2
1 3 10
2
```



**输出** 



```
0
24
```



**说明**


初始数组四个元素全部相等，六对元素的差的绝对值都是 $0$，首次查询答案为 $0$。把 $a_3$ 改成 $10$ 后数组变为 $(2,2,10,2)$，含下标 $3$ 的三对元素给出 $|2-10|=8$ 各一次，其余三对仍为 $0$，第二次查询答案为 $8 \times 3 = 24$。
