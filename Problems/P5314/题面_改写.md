# 刀盾分配最小承伤

# 题目内容

请合理分配随身的刀和盾，使连续若干轮怪物攻击下受到的总伤害尽可能小，并输出这个最小值。

一场冒险里会连续遭遇 $t$ 轮攻击，第 $i$ 轮伤害为 $d_i$。你带了 $s$ 把刀和 $b$ 面盾，每件道具都是一次性的，用过即消失。每一轮必须且只能选下面三种做法之一：

1. 用刀：消耗 $1$ 把刀，当场击杀，本轮伤害为 $0$。
2. 用盾：消耗 $1$ 面盾，抵挡 $h$ 点伤害，本轮实际伤害为 $\max(0,\ d_i-h)$。
3. 硬抗：不用道具，本轮伤害为 $d_i$。

同一轮不能同时用刀又用盾。

# 输入描述

第一行一个整数 $q$（$1 \le q \le 10^5$），表示询问组数。

每组先是一行四个整数 $t$、$s$、$b$、$h$（$1 \le t \le 2 \times 10^5$，$0 \le s,b \le t$，$1 \le h \le 10^9$），表示轮数、刀数、盾数和盾的抵挡值。

下一行 $t$ 个整数 $d_1,d_2,\dots,d_t$（$0 \le d_i \le 10^9$），表示各轮伤害。

保证所有组的 $t$ 之和不超过 $2 \times 10^5$。

# 输出描述

对每组输出一行一个整数，即最小总伤害。

## 样例1

**输入**

```
2
3 2 0 5
4 9 1
5 1 2 3
8 8 1 2 0
```

**输出**

```
1
6
```

**说明**

第一组有 `2` 把刀、没有盾。把刀用在伤害 `9` 和 `4` 的两轮，剩下 `1` 硬抗，总伤害 `1`。

第二组有 `1` 把刀、`2` 面盾、抵挡值 `3`。伤害从大到小是 `8,8,2,1,0`：刀消掉一个 `8`，两面盾分别挡另一个 `8` 和 `2`（实际伤害 `5` 和 `0`），剩下 `1` 和 `0` 硬抗，总伤害 $5+1=6$。
