# 题目内容

在一场冒险中，你遭遇了连续 $n$ 轮怪物攻击。第 $i$ 轮怪物造成的伤害为 $a_i$。你随身携带了 $m$ 把刀和 $k$ 面盾，且每件道具为消耗品（使用一次后即消失）。在每一轮中，你必须在以下三种策略中选择其一：
1. 使用刀：该轮消耗 $1$ 把刀，直接击杀怪物，该轮受到的伤害为 $0$。
2. 使用盾：该轮消耗 $1$ 面盾，抵挡怪物伤害 $p$ 点，该轮实际受到的伤害为 $\max(0,\ a_i - p)$。
3. 承受攻击：不使用任何道具，该轮受到的伤害为 $a_i$。

请合理分配刀与盾，使得 $n$ 轮攻击的总伤害之和最小。输出能够达到的最小总伤害值。




# 输入描述

每个测试文件包含多组测试数据。第一行输入一个整数 $T(1 \le T \le 10^5)$ 表示数据组数，每组测试数据描述如下：
第一行输入四个整数 $n,m,k,p\ (1 \le n \le 2 \times 10^5,\ 0 \le m,k \le n,\ 1 \le p \le 10^9)$。
第二行输入 $n$ 个整数 $a_1,a_2,\dots,a_n\ (0 \le a_i \le 10^9)$。
保证所有测试数据的 $n$ 之和不超过 $2 \times 10^5$。



# 输出描述

对于每组测试数据，输出一个整数，表示在最优策略下受到的最小总伤害。




## 样例1 



**输入** 



```
2
3 1 1 5
10 20 2
4 0 1 10
100 20 20 10
```



**输出** 



```
7
140
```
