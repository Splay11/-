# 题目内容

现在给你初始的 $n$ 个整数。你可以做下述操作若干次：
 
- 选择其中一个整数，加二或减二。
 
接下来给定 $q$ 次询问，每次询问一个整数 $x$，你需要将所有数字通过操作变到 $[x-1,\ x+1]$ 范围内。询问你最少需要操作的次数。

每次询问之间互不影响，换句话说每次询问前都会重新把数组置为初始状态。
 



# 输入描述

第一行两个整数 $n,q$，表示共有 $n$ 个数字，一共进行 $q$ 次询问。

接下来一行 $n$ 个整数，描述初始的n个整数组成的序列。

接下来一行 $q$ 个整数，描述每次询问的整数 $x$。

$1\le n,q\le100000$

所有初始数字和询问数字（记为$x$）均满足 $1\le x\le100000$



# 输出描述


一行q个整数，第i个整数表示第i次询问的答案。
 


## 样例1 



**输入** 



```
3 3
1 2 3
1 2 3
```



**输出** 



```
1 0 1
```






## 样例2



**输入** 



```
8 4
15 4 6 18 12 7 30 11
10 25 1 40
```



**输出** 



```
23 51 45 107
```
