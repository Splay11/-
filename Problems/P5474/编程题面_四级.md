# 时钟档位校准

# 题目内容

边缘推理集群里有 $m$ 台节点，第 $p$ 台当前的时钟偏移是 $v_p$。运维每次只能挑一台节点，把它的偏移加上 $2$ 或者减去 $2$。这类微调可以重复任意多次。

现在有 $k$ 项校准任务。第 $j$ 项给出目标档 $g_j$，要求把所有节点的偏移都收进闭区间 $[g_j-1,g_j+1]$。不同任务彼此独立：做完一项后偏移会恢复成一开始的 $v$，再处理下一项。

请对每项任务求出最少微调次数。

# 输入描述

首行一个正整数 $m$（$1\le m\le 10^{5}$），表示节点台数。

第二行 $m$ 个整数 $v_1,v_2,\dots,v_m$（$1\le v_p\le 10^{5}$），即各台当前偏移。

第三行一个正整数 $k$（$1\le k\le 10^{5}$），表示校准任务条数。

随后 $k$ 行，第 $j$ 行一个整数 $g_j$（$1\le g_j\le 10^{5}$），即该项任务的目标档。

# 输出描述

输出 $k$ 行，第 $j$ 行一个整数，表示第 $j$ 项任务的最少微调次数。

## 样例1

**输入**

```
4
5 8 6 11
3
6
9
7
```

**输出**

```
3
4
3
```

**说明**

- $g=6$ 时区间是 $[5,7]$：$8$ 调到 $6$ 用 $1$ 次，$11$ 调到 $7$ 用 $2$ 次，其余已在区间内，合计 $3$。
- $g=9$ 时区间是 $[8,10]$：$5$ 调到 $9$ 用 $2$ 次，$6$ 调到 $8$ 用 $1$ 次，$11$ 调到 $9$ 用 $1$ 次，合计 $4$。
- $g=7$ 时区间是 $[6,8]$：$5$ 调到 $7$ 用 $1$ 次，$11$ 调到 $7$ 用 $2$ 次，合计 $3$。

## 样例2

**输入**

```
5
3 3 10 1 20
2
3
15
```

**输出**

```
12
23
```

**说明**

- $g=3$ 时区间是 $[2,4]$：$10$ 收到 $4$ 要 $3$ 次，$1$ 收到 $3$ 要 $1$ 次，$20$ 收到 $4$ 要 $8$ 次，合计 $12$。
- $g=15$ 时区间是 $[14,16]$，五项分别要 $6$、$6$、$2$、$7$、$2$ 次，合计 $23$。
