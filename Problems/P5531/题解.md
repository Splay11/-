# 多项式回归

## 解题思路

本题用最小二乘法拟合多项式 $y = a_n x^n + \cdots + a_0$，接口为 `Solution.polynomialRegression(xs, ys, degree)`。

1. 构建设计矩阵 $A$，第 $i$ 行为 $[x_i^n, x_i^{n-1}, \ldots, 1]$。
2. 求解 $\min_c \|Ac - y\|^2$，可用 `numpy.linalg.lstsq`。
3. 返回系数从最高次 $a_n$ 到常数项 $a_0$。

## 复杂度分析

时间复杂度为 $O(N\cdot n^{2})$ 量级（取决于最小二乘实现），$n$ 为多项式阶数。

空间复杂度为 $O(N\cdot n)$。

## 代码实现

### Python

```python
import numpy as np


class Solution:
    def polynomialRegression(self, xs, ys, degree):
        """最小二乘多项式回归，返回从高次到常数项的系数。"""
        xs = np.asarray(xs, dtype=float)
        ys = np.asarray(ys, dtype=float)
        # 设计矩阵第 i 行为 [x^n, x^{n-1}, ..., 1]
        A = np.vander(xs, degree + 1, increasing=False)
        # 求解 min ||Ac - y||^2
        coef, _, _, _ = np.linalg.lstsq(A, ys, rcond=None)
        return coef.tolist()
```
