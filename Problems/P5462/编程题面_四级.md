# 数位积最小码

# 题目内容

出厂时要给设备打一个十进制编号 $z$。把 $z$ 写成十进制以后，把位数记成 $L$，把各位数字加起来记成 $s(z)$。

现在给出校验额度 $w$，要求 $L$ 与 $s(z)$ 的乘积恰好等于 $w$。请在闭区间 $[1,10000000000000000]$ 内挑出数值尽量小的合法编号；若一个都挑不到，就输出 $-1$。

位数怎么数：例如 $7$ 占 $1$ 位，$105$ 占 $3$ 位。
各位怎么加：例如 $105$ 是 $1+0+5=6$。

# 输入描述

第一行一个整数 $q$，表示询问次数。$(1\le q\le 50000)$

第二行 $q$ 个整数 $w$，即每组询问的校验额度。$(1\le w\le 2.5\times 10^{3})$

# 输出描述

一行输出 $q$ 个整数，相邻两项用空格隔开：依次给出每组询问的最小合法编号；不存在时该位置为 $-1$。

## 样例1

**输入**

```
5
1 10 11 27 16
```

**输出**

```
1 14 10000000000 108 17
```

**说明**

- $w=1$：一位数 $1$ 满足 $1\times 1=1$
- $w=10$：一位数各位最多加到 $9$，不够；两位数需要各位之和为 $5$，最小是 $14$
- $w=11$：$11$ 能整除的长度里，取 $11$ 位且各位之和为 $1$，最小是 $1$ 后面跟 $10$ 个 $0$
- $w=27$：三位且各位之和为 $9$，最小是 $108$
- $w=16$：两位且各位之和为 $8$，最小是 $17$

## 样例2

**输入**

```
3
8 29 17
```

**输出**

```
8 -1 10000000000000000
```

**说明**

- $w=8$：一位数 $8$ 即可
- $w=29$：约数只有 $1$ 和 $29$。一位数加不到 $29$；$29$ 位又超出闭区间上界，故为 $-1$
- $w=17$：只能取 $17$ 位且各位之和为 $1$，闭区间内恰好是 $10000000000000000$
