# 题目内容

给定一个正整数 $x$。我们用 $|a|$ 表示十进制下整数 $a$ 的数位长度，用 $\text{sum}(a)$ 表示 $a$ 的十进制数位和。

你的任务是在区间 $[1,10^{16}]$ 内，找到满足 $|a| \cdot \text{sum}(a) = x$ 的最小整数 $a$（数值最小）。如果不存在这样的 $a$，输出 $-1$。

数位长度的含义：例如 $|7| = 1$，$|105| = 3$。
数位和的含义：例如 $\text{sum}(105) = 1 + 0 + 5 = 6$。




# 输入描述

每个测试文件均包含多组测试数据。第一行输入一个整数 $T(1 \le T \le 5 \times 10^4)$。

接下来 $T$ 行，每行输入一个整数 $x(1 \le x \le 2500)$。




# 输出描述


对于每组测试数据，输出一个整数，为满足条件的最小 $a$；若不存在，输出 $-1$。



## 样例1 



**输入** 



```
4
9
20
23
18
```



**输出** 



```
9
19
-1
18
```



**说明**

对 $x = 9$，一位数 $9$ 满足 $1 \times 9 = 9$。

对 $x = 20$，一位数的数位和最多为 $9$，不行；两位数需要数位和为 $10$，最小的是 $19$。

对 $x = 23$，$23$ 是质数，只能是一位数且数位和为 $23$（不可能），或 $23$ 位数且数位和为 $1$（超出 $10^{16}$），所以输出 $-1$。

对 $x = 18$，一位数不行；两位数需要数位和为 $9$，最小的是 $18$。
