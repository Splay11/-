# 构建物三端就绪清单

## 解题思路

对每个构建物，检查其要求版本下是否三端（$android$、$ios$、$pc$）都至少有一条 $READY$。

1. 遍历日志，把所有 $status=READY$ 的三元组 $(artifact\_id,version,platform)$ 放入集合。
2. 按构建计划顺序枚举每个 $artifact\_id$，取其 $need\_ver$，检查三个平台是否都在集合中。
3. 缺任一平台则记入缺失列表；若一个都不缺，输出 $none$。

注意：$FAIL$ 不计入；$version\neq need\_ver$ 的记录忽略；计划外日志忽略。

## 复杂度分析

- 时间复杂度：$O(N+M)$。
- 空间复杂度：$O(M)$。

## 代码实现

### Python

```python
def solve(plans, logs):
    # plans: (artifact_id, channel, need_ver)
    # logs: (artifact_id, version, platform, status)
    ready = set()
    for rid, ver, plat, status in logs:
        if status == "READY":
            ready.add((rid, ver, plat))
    missing = []
    for rid, channel, need_ver in plans:
        ok = True
        for plat in ("android", "ios", "pc"):
            if (rid, need_ver, plat) not in ready:
                ok = False
                break
        if not ok:
            missing.append(rid)
    return missing if missing else ["none"]


N, M = map(int, input().split())
plans = []
for _ in range(N):
    rid, channel, need_ver = input().split()
    plans.append((rid, channel, need_ver))
logs = []
for _ in range(M):
    rid, ver, plat, status = input().split()
    logs.append((rid, ver, plat, status))
for line in solve(plans, logs):
    print(line)
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(st.nextToken());
        int M = Integer.parseInt(st.nextToken());
        List<String[]> plans = new ArrayList<>();
        for (int i = 0; i < N; i++) {
            st = new StringTokenizer(br.readLine());
            plans.add(new String[]{st.nextToken(), st.nextToken(), st.nextToken()});
        }
        Set<String> ready = new HashSet<>();
        for (int i = 0; i < M; i++) {
            st = new StringTokenizer(br.readLine());
            String rid = st.nextToken();
            String ver = st.nextToken();
            String plat = st.nextToken();
            String status = st.nextToken();
            if (status.equals("READY")) ready.add(rid + "\0" + ver + "\0" + plat);
        }
        List<String> missing = new ArrayList<>();
        for (String[] p : plans) {
            String rid = p[0], need = p[2];
            boolean ok = ready.contains(rid + "\0" + need + "\0android")
                    && ready.contains(rid + "\0" + need + "\0ios")
                    && ready.contains(rid + "\0" + need + "\0pc");
            if (!ok) missing.add(rid);
        }
        if (missing.isEmpty()) {
            System.out.println("none");
        } else {
            for (String x : missing) System.out.println(x);
        }
    }
}
```

### C++

```cpp
#include <iostream>
#include <set>
#include <string>
#include <tuple>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, M;
    cin >> N >> M;
    vector<tuple<string, string, string>> plans;
    for (int i = 0; i < N; i++) {
        string rid, channel, need;
        cin >> rid >> channel >> need;
        plans.emplace_back(rid, channel, need);
    }
    set<tuple<string, string, string>> ready;
    for (int i = 0; i < M; i++) {
        string rid, ver, plat, status;
        cin >> rid >> ver >> plat >> status;
        if (status == "READY") ready.emplace(rid, ver, plat);
    }
    vector<string> missing;
    for (size_t i = 0; i < plans.size(); i++) {
        string rid = get<0>(plans[i]);
        string need = get<2>(plans[i]);
        bool ok = ready.count({rid, need, "android"})
               && ready.count({rid, need, "ios"})
               && ready.count({rid, need, "pc"});
        if (!ok) missing.push_back(rid);
    }
    if (missing.empty()) {
        cout << "none\n";
    } else {
        for (auto& x : missing) cout << x << '\n';
    }
    return 0;
}
```
