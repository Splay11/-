# P14392 题解：AGENTS.md 子文件加载



## 1. 解题思路



将 `fileIds[i]` 与 `parentIds[i]` 连成森林（虚拟根 `0`），在父节点上建 **子节点邻接表**。从 `targetId` 出发做 **DFS 或 BFS**，收集目标及全部后代，最后 **排序** 输出。



- 建树：对每个下标 $i$，边 `parentIds[i] → fileIds[i]`；

- 遍历：栈/队列从 `targetId` 扩展，保证每个可达子文件只访问一次；

- 答案：遍历到的 ID 升序排列（含 `targetId` 自身）。



**常见假解**：



- 只收集 **直接子节点**，不递归后代：链 `1→2→3`、加载 `1` 会漏 `3`；

- 忘记把 **targetId** 放进答案；

- 未排序或按插入顺序输出。



## 2. 复杂度分析



- **时间复杂度**：$O(n)$ 建树 + $O(n)$ 遍历 + $O(k \log k)$ 排序（$k$ 为子树大小，$k \le n$），整体 $O(n \log n)$，在 $n \le 1000$ 下足够；

- **空间复杂度**：$O(n)$ 存邻接表与访问集合/栈。



## 3. 代码实现



### Python



```python

from collections import defaultdict

from typing import List





class Solution:

    def getLoadedFileIds(

        self, fileIds: List[int], parentIds: List[int], targetId: int

    ) -> List[int]:

        children = defaultdict(list)

        for fid, pid in zip(fileIds, parentIds):

            children[pid].append(fid)  # 父 -> 子 建表



        ans = []

        stack = [targetId]

        while stack:

            u = stack.pop()

            ans.append(u)

            for v in children[u]:  # 递归展开所有后代

                stack.append(v)

        ans.sort()

        return ans

```



### Java



```java

import java.util.ArrayList;

import java.util.Arrays;

import java.util.HashMap;



class Solution {

    public int[] getLoadedFileIds(int[] fileIds, int[] parentIds, int targetId) {

        HashMap<Integer, ArrayList<Integer>> children = new HashMap<>();

        for (int i = 0; i < fileIds.length; i++) {

            children.computeIfAbsent(parentIds[i], k -> new ArrayList<>()).add(fileIds[i]);

        }

        ArrayList<Integer> ans = new ArrayList<>();

        ArrayList<Integer> stack = new ArrayList<>();

        stack.add(targetId);

        while (!stack.isEmpty()) {

            int u = stack.remove(stack.size() - 1);

            ans.add(u);

            ArrayList<Integer> ch = children.get(u);

            if (ch != null) {

                for (int v : ch) stack.add(v);  // 深度优先收集子树

            }

        }

        int[] out = new int[ans.size()];

        for (int i = 0; i < ans.size(); i++) out[i] = ans.get(i);

        Arrays.sort(out);

        return out;

    }

}

```



### C++



```cpp

#include <algorithm>

#include <unordered_map>

#include <vector>



using namespace std;



class Solution {

 public:

  vector<int> getLoadedFileIds(vector<int>& fileIds, vector<int>& parentIds,

                               int targetId) {

    unordered_map<int, vector<int>> children;

    for (size_t i = 0; i < fileIds.size(); i++) {

      children[parentIds[i]].push_back(fileIds[i]);

    }

    vector<int> ans;

    vector<int> stack = {targetId};

    while (!stack.empty()) {

      int u = stack.back();

      stack.pop_back();

      ans.push_back(u);

      for (int v : children[u]) stack.push_back(v);

    }

    sort(ans.begin(), ans.end());

    return ans;

  }

};

```
