# AGENTS.md 子文件加载

编码 Agent 工具会在当前项目下生成 `AGENTS.md` 文件以记录上下文与规范；每个 md 文件有唯一 **文件 ID**，根文件 ID 为 `0`，其余文件除自身 ID 外还有一个 **父文件 ID**。

加载某个 md 文件时，需同时加载该文件及其 **全部子文件**（递归后代）。给定：

- 文件自身 ID 列表（保证不含 `0`）；
- 与之一一对应的父文件 ID 列表；
- 本次要加载的目标文件 ID（保证出现在自身 ID 列表中）。

请返回：目标文件 ID 与所有子文件 ID，按数值 **升序** 排列。

评测采用 **LeetCode 核心代码模式**：只需实现 `Solution` 中的方法，平台负责读入与调用。**不要** 编写 `main` 或自行处理 stdin/stdout。

## 函数接口

| 语言 | 签名 |
|------|------|
| Python | `def getLoadedFileIds(self, fileIds: List[int], parentIds: List[int], targetId: int) -> List[int]` |
| Java | `public int[] getLoadedFileIds(int[] fileIds, int[] parentIds, int targetId)` |
| C++ | `vector<int> getLoadedFileIds(vector<int>& fileIds, vector<int>& parentIds, int targetId)` |

### 参数

- `fileIds`：长度 $n$，各 md 文件的 ID；
- `parentIds`：长度 $n$，`parentIds[i]` 为 `fileIds[i]` 的父文件 ID（可为 `0` 表示挂在根下）；
- `targetId`：本次加载的文件 ID。

### 返回值

包含 `targetId` 及其所有后代文件 ID 的升序整数列表。

## 数据范围

- $1 \le n = \texttt{fileIds.length} = \texttt{parentIds.length} \le 1000$；
- `fileIds` 中元素互不相同，且均不为 $0$；
- `targetId` 出现在 `fileIds` 中。

## 输入格式（平台侧，选手无需编写）

stdin **一行**，三个字段用英文逗号分隔（与样例字符级一致；数组内逗号后不加空格）：

```text
[<fileIds>],[<parentIds>],<targetId>
```

前两项为整数数组；第三项为单个整数。

## 输出格式

一行：整数列表的 JSON 表示，行末换行。例如 `[2,4,5]`。

## 样例 1

**输入**

```text
[1,2,3,4,5,6,7],[0,1,1,2,2,3,0],2
```

**输出**

```text
[2,4,5]
```

**说明**

父子关系：

```text
0
├── 1
│   ├── 2
│   │   ├── 4
│   │   └── 5
│   └── 3
│       └── 6
└── 7
```

加载 ID `2` 时需带上子文件 `4`、`5`，故返回 `[2,4,5]`。

## 样例 2

**输入**

```text
[1,2,3],[0,1,1],3
```

**输出**

```text
[3]
```

**说明**：`3` 无子文件，仅返回自身。

## 样例 3

**输入**

```text
[1,2,3,4],[0,1,2,3],1
```

**输出**

```text
[1,2,3,4]
```

**说明**：`1` 为链式祖先，整棵子树均需加载。
