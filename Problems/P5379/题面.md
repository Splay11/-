# 题目内容

给定 $t$ 个正整数 $n$，请找出 $n$ 的最小奇数质因数。如果不存在这样的因数，则输出 $-1$。



# 输入描述


第一行输入一个整数 $t(1 \le t \le 100)$，表示测试用例数量。

接下来的 $t$ 行，每行输入一个整数 $n(2 \le n \le 10^{14})$。


# 输出描述

对于每个测试用例，在一行上输出一个整数，表示 $n$ 的最小奇数质因数；如果 $n$ 没有大于 $1$ 的奇数因数，则输出 $-1$。



## 样例1 



**输入** 



```
3
15
2
49
```



**输出** 



```
3
-1
7
```
