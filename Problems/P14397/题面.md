# 数字字母交替展开

给定一个仅含大写字母与数字的字符串 $S$。先将 $S$ 中所有数字按出现顺序提取为数字串 $D$，所有字母按出现顺序提取为字母串 $L$，再按下标 $0,1,2,\ldots$ 交替拼接：

- 先输出 $D[i]$；
- 再将 $L[i]$ 重复 $D[i]$ 所表示的整数次（$D[i]=0$ 时不输出字母）；
- 当 $D$ 与 $L$ 长度不等时，将较长一侧剩余字符直接拼接到末尾。

若 $S$ **只含字母**或**只含数字**，则直接输出原串 $S$。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def processString(self, s: str) -> str` |
| Java | `public String processString(String s)` |
| C++ | `string processString(string s)` |

**参数**

- `s`：仅含大写字母 `A`–`Z` 与数字 `0`–`9` 的字符串，$1 \le |s| \le 100$。

**返回值**

按题意处理后的字符串。

## 输入输出格式（stdin / stdout）

**输入**（stdin 一行，双引号包裹的字符串字面量，与样例一致）：

```text
"A1B2C3"
```

**输出**（stdout 一行，同格式双引号字符串）：

```text
"1A2BB3CCC"
```

## 数据范围

- $1 \le |S| \le 100$；
- $S$ 仅含大写字母与数字。

## 样例

### 样例 1

**输入**

```text
"A1B2C3"
```

**输出**

```text
"1A2BB3CCC"
```

**说明**

- 数字串 $D=123$，字母串 $L=ABC$；
- 交替：$1+A\times1$、$2+B\times2$、$3+C\times3$ $\Rightarrow$ `1A2BB3CCC`。

### 样例 2

**输入**

```text
"ABC0123"
```

**输出**

```text
"01B2CC3"
```

**说明**

- $D=0123$，$L=ABC$；
- $0$ 对应 $A$ 重复 $0$ 次不输出；$1+B$、$2+CC$；数字侧余下 `3` 直接拼接。

### 样例 3

**输入**

```text
"B"
```

**输出**

```text
"B"
```

**说明**

只含字母，直接输出原串。
