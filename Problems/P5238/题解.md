# 答案+解析

1、**答案：否**

解析：A100 Tensor Core 支持 FP16/BF16/TF32/INT8；硬件原生把 FP8 作为一等加速精度是从 H100 起。题干把 FP8 提前安到 A100 上，因此错误。

2、**答案：是**

解析：MASt3R 在 DUST3R 思路上增加 matching head，强化跨视图匹配，更适配大规模多视图重建。

3、**答案：否**

解析：Diffusion Policy 学习动作分布的 score/去噪过程，推理通常需要多步 denoise 才能得到动作 chunk，并非单步直接回归即可。

4、**答案：是**

解析：CoT 促使模型写出中间步骤，对算术、常识、多步推理类任务通常有帮助。

5、**答案：是**

解析：LAION 是大规模图文数据；DataComp、DFN 侧重数据筛选/过滤，均服务 CLIP 类预训练。

6、**答案：是**

解析：Deformable DETR 引入可变形注意力与多尺度特征，缓解原版 DETR 收敛慢的问题。

7、**答案：否**

解析：delay-and-sum 中孔径增大通常使主瓣变窄、空间分辨率提升；题干写成“主瓣变宽、分辨率下降”，与事实相反。

8、**答案：是**

解析：NVIDIA Cosmos 面向物理可信世界建模，可按文本/视频条件生成符合物理规律的仿真数据。

9、**答案：否**

解析：greedy 只保留单条路径，容易因 blank/重复折叠丢候选；prefix beam search 保留并合并等价路径，通常更稳，并非“必然丢字且更差”。
