# 题目内容

今天有 $n$ 位预约顾客，并把营业时间依次划分为编号 $1,2,\dots,n+1$的 $n+1$ 个接待时段。

第$ i$ 位顾客可以接受闭区间 $[l_i,r_i]$中任意一个整数编号的时段。每位顾客都必须恰好被安排在一个时段，同一个时段最多接待一位顾客。

店主想给自己留出一个完整的时段试做新品。对每个时段 x，请独立判断：**如果时段 x 完全不接待顾客，是否仍然可以把全部 n 位顾客安排到各自可以接受、且互不冲突的时段？**

请按时段编号从小到大输出判断结果。每个时段的判断彼此独立；判断不同的$ x$ 时，可以采用完全不同的顾客安排方案。



# 输入描述

第一行包含一个整数 n，表示预约顾客的数量。 接下来 $n$ 行，第 i 行包含两个整数 $l_i,r_i$，表示第 $i$ 位顾客可以接受的时段闭区间。

约束：

- $1 \le n \le 200000$
- $1 \le l_i \le r_i \le n+1$
- 本题只有一组测试数据。

# 输出描述

输出一个长度为 $n+1$的`01`字符串。第 $x$ 个字符为`1`，当且仅当存在一种合法安排，使全部顾客都得到接待且时段$x$ 不接待任何顾客；否则为`0`。



## 样例1 

**输入** 

```
2
1 3
2 2
```

**输出** 

```
101
```

**说明**

预留时段 $1 $时，可以把两位顾客分别安排在时段 3、2；预留时段 3 时，可以分别安排在时段 1、2。如果预留时段 2，第二位顾客将没有可以接受的时段。



## 样例2 

**输入** 

```
2
1 2
2 3
```

**输出** 

```
111
```



## 样例3

**输入** 

```
3
1 1
1 2
1 2
```

**输出** 

```
0000
```

**说明**

即使不预留时段，也无法把三位顾客安排到它们共同可以接受的两个时段中，因此无论预留哪个时段，都不存在合法安排。
