# 梯度下降求平方根

## 解题思路

1. 损失函数取 $L(x)=(x^2-a)^2$，其对 $x$ 的梯度为 $4x(x^2-a)$。
2. 从 $x_0$ 出发，按 $x\leftarrow x-\eta\cdot 4x(x^2-a)$ 迭代 $T$ 次。
3. 每次更新后若 $x<0$ 则取绝对值，并记录当前 $x$ 与 $L(x)$。
4. 在 `Solution.gradientDescentSqrt` 中完成上述循环并返回轨迹。

## 复杂度分析

- 时间复杂度：$O(T)$，迭代 $T$ 次。
- 空间复杂度：$O(T)$，存放每次迭代结果。

## 代码实现

### Python

```python
from typing import List


class Solution:
    def gradientDescentSqrt(self, a: float, x0: float, eta: float, T: int) -> List[List[float]]:
        """梯度下降求平方根，返回每次迭代后的 [x, L]。"""
        x = x0
        out = []
        for _ in range(T):
            # 梯度 4x(x^2 - a)，按题面更新
            grad = 4.0 * x * (x * x - a)
            x = x - eta * grad
            # 可取绝对值保证非负（题面提示）
            if x < 0:
                x = -x
            loss = (x * x - a) * (x * x - a)
            out.append([x, loss])
        return out
```
