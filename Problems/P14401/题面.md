# 最佳维护窗口

某数据中心记录了连续 $N$ 小时内每小时的服务器负载得分，记录在数组 `scores` 中；$0$ 表示该小时无效（服务器故障）。

需要选择连续 $W$ 小时的窗口作为最佳的维护窗口，满足如下规则：

1. 窗口内不能包含无效小时（得分为 $0$）；
2. 在满足条件的窗口中，选取负载得分总和**最小**的窗口；若存在多个总和相同的最小窗口，选取**起始小时最早**的；
3. 不存在满足条件的窗口时，输出 `[-1, 0]`。

下标从 $0$ 开始计数。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def findMaintenanceWindow(self, n: int, w: int, scores: List[int]) -> List[int]` |
| Java | `public int[] findMaintenanceWindow(int n, int w, int[] scores)` |
| C++ | `vector<int> findMaintenanceWindow(int n, int w, vector<int>& scores)` |

**参数**

- `n`：总小时数，$1 \le n \le 100000$，且与 `scores` 长度一致；
- `w`：窗口长度，$1 \le w \le \min(n, 10000)$；
- `scores`：长度为 $n$ 的负载得分数组，$0 \le \texttt{scores}[i] \le 1000$；$0$ 表示无效小时。

**返回值**

长度为 $2$ 的整数数组 `[起始下标, 最小负载总和]`；若无合法窗口，返回 `[-1, 0]`。

## 输入输出格式（stdin / stdout）

**输入**（stdin **一行**：总小时数 $n$、英文逗号、窗口长度 $w$、英文逗号、一维整型数组 `scores`；数组用方括号，元素逗号分隔、无空格）：

```text
9,2,[10,5,20,10,5,15,10,5,25]
```

**输出**（stdout **一行**，方括号包裹的两个整数，逗号无空格）：

```text
[0,15]
```

## 数据范围

- $1 \le n \le 100000$；
- $1 \le w \le \min(n, 10000)$；
- $0 \le \texttt{scores}[i] \le 1000$。

## 样例

### 样例 1

**输入**

```text
9,2,[10,5,20,10,5,15,10,5,25]
```

**输出**

```text
[0,15]
```

**说明**

$3$ 个长度为 $2$ 的合法窗口（下标 $[0,1]$、$[3,4]$、$[6,7]$）总得分都是 $15$，选取起始下标最早的 $0$，输出 `[0,15]`。

### 样例 2

**输入**

```text
5,3,[0,5,0,8,12]
```

**输出**

```text
[-1,0]
```

**说明**

任意连续 $3$ 小时窗口都包含得分为 $0$ 的无效小时，不存在合法窗口。

### 样例 3

**输入**

```text
12,4,[10,2,1,0,15,0,8,3,6,12,6,9]
```

**输出**

```text
[7,27]
```

**说明**

前若干位置无法形成不含 $0$ 的长度为 $4$ 的窗口。从下标 $6$ 起首个合法窗口和为 $29$；从下标 $7$ 开始的窗口和为 $27$ 最小，故输出 `[7,27]`。
