# 题目内容

Bingbong 想要构造一个长度为 $n$、仅由字符 $0$ 和 $1$ 构成的字符串 $s$，下标从 $1$ 开始。

现在给定 $m$ 个区间 $[l_i,r_i]$（条数保证是偶数），你需要保证字符串 $s$ 在该区间里 $0$ 和 $1$ 的数量相等。

Bingbong 还要忙着和哆啦 A 梦玩耍，请你帮帮他。

# 输入描述

第一行一个整数 $n$ 和一个偶数 $m$，表示字符串长度和区间个数。

接下来 $m$ 行，第 $i$ 行输入两个整数 $l_i$、$r_i$，表示给定的区间端点。

### 约束

$2 \le n \le 10^5$

$1 \le m \le 10^5$，且 $m$ 为偶数

$1 \le l_i < r_i \le n$

$r_i-l_i+1$ 为偶数

# 输出描述

输出任意一个符合条件的字符串 $s$，可以证明在题目的约束下始终存在一个满足题意的答案。

如果存在多个解决方案，您可以输出任意一个，系统会自动判定是否正确。注意，自测运行功能可能因此返回错误结果，请自行检查答案正确性。

## 样例1

**输入**

```
3 2
1 2
2 3
```

**输出**

```
010
```

**说明**

区间 $[1,2]$ 对应 $01$，各一个；$[2,3]$ 对应 $10$，也是各一个。
