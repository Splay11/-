# P5419 测例说明

输出任意合法 $01$ 串，使用 `check.cc`（testlib）按输入窗口判对，不要求与标程逐字符相同。

输入协议（四级）：第一行 $k$，第二行 $q$，随后 $q$ 行 $a,b$。

分层（每组 $10$ 分）：

- 1：四级样例。$k=6$，窗口 $[1,6]$、$[3,6]$。卡全 $0$、全 $1$，以及仍把 $k$、$q$ 读在同一行的旧 I/O。
- 2：最小串 $k=2$，同一约束出现两次。
- 3：相邻长度为 $2$ 的窗口再加整段 $[1,4]$。卡 $0011$ 循环。
- 4：$k$ 为奇数，约束不相交。
- 5：整段 $[1,8]$ 与嵌套/重叠窗口。
- 6：$k=20$ 随机 $10$ 个偶数窗口。
- 7：大量重复的 $[1,2]$，再加两端短窗口。
- 8：$k=500$，$q=200$ 随机，便于对拍。
- 9：$k=10^5$，$q=2$，只卡两端。压测构造与输出长度。
- 10：$k=10^5$，$q=10^5$ 满上限随机偶数窗口。

hack 点：全 $0$/全 $1$、$0011$ 分块、输出长度不是 $k$、出现非 $01$ 字符、按空格而不是逗号读端点。
