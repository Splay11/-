# 题目内容

Bingbong 打算拼出长度为 $k$ 的串 $t$，里面只能填字符 $0$ 与 $1$，位置编号从 $1$ 计起。

接着会给出 $q$ 段闭区间 $[a_i,b_i]$，条数 $q$ 一定是偶数。串 $t$ 落在每一段里的 $0$ 必须和 $1$ 一样多。

Bingbong 正忙着跟哆啦 A 梦一起玩，这件事先拜托你来完成。

# 输入描述

首行给出整数 $k$ 以及偶数 $q$（$2 \le k \le 10^5;\ 1 \le q \le 10^5$），分别是串长和区间条数。

随后 $q$ 行，第 $i$ 行两个整数 $a_i$、$b_i$（$1 \le a_i < b_i \le k$，且 $b_i-a_i+1$ 为偶数），即第 $i$ 段的左右端点。

# 输出描述

打印任意一条合法的串 $t$。在题设范围内一定能找到这样的串。

合法答案不止一条时，任选一条提交即可，评测程序会核验对错。自行试跑时可能对不上某份参考输出，需要自己判断是否满足区间条件。

## 样例1

**输入**

```
6 2
1 6
3 6
```

**输出**

```
010101
```

**说明**

取 $t=010101$。整段 $[1,6]$ 是三个 $0$、三个 $1$；$[3,6]$ 是 $0101$，各两个。
