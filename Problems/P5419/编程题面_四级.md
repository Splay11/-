# 灯带电平

# 题目内容

产线要把长度为 $k$ 的灯带 $t$ 烧成两种电平 $0$ 与 $1$，灯位从 $1$ 编号。

质检会下发 $q$ 段闭窗口 $[a_i,b_i]$，窗口条数 $q$ 一定是偶数。灯带 $t$ 在每一窗口内低电平与高电平的颗数必须相同。

值班员还要去对另外一组治具，这条灯带就交给你来排。

# 输入描述

第一行一个整数 $k$（$2 \le k \le 10^5$），表示灯带长度。

第二行一个偶数 $q$（$1 \le q \le 10^5$），表示窗口条数。

随后 $q$ 行，每行把左右端点写成 $a_i,b_i$（$1 \le a_i < b_i \le k$，且 $b_i-a_i+1$ 为偶数）。

# 输出描述

打印任意一条合法的灯带 $t$。在题设范围内一定能找到这样的串。

合法答案不止一条时，任选一条提交即可，评测程序会核验对错。自行试跑时可能对不上某份参考输出，需要自己判断是否满足窗口条件。

## 样例1

**输入**

```
6
2
1,6
3,6
```

**输出**

```
010101
```

**说明**

取 $t=010101$。整段 $[1,6]$ 是三个 $0$、三个 $1$；$[3,6]$ 是 $0101$，各两个。
