# 灯带电平

## 解题思路

窗口长度保证是偶数，所以每个 $[a_i,b_i]$ 里 $0$ 和 $1$ 数量相等是做得到的。题目还保证在给定约束下始终有解。

直接按窗口去填字符也可以，但没必要。观察：交错串 $010101\ldots$（灯位从 $1$ 开始，奇数位为 $0$，偶数位为 $1$）对**所有**偶数长度窗口都成立。

1. 在交错串里，奇数下标全是 $0$，偶数下标全是 $1$。
2. 任意长度为偶数的窗口 $[a,b]$ 里，奇数下标和偶数下标各占一半。
3. 因此该窗口里 $0$ 的个数等于 $1$ 的个数。
4. 所以只要输出 $0101\ldots$，所有 $q$ 个约束同时满足。$1010\ldots$ 同样合法。
5. 窗口本身不用参与构造，按四级协议读入后丢掉即可：第一行 $k$，第二行 $q$，随后 $q$ 行 $a_i,b_i$。

常见错法：输出全 $0$ 或全 $1$（任意长度至少为 $2$ 的窗口都会失败）；输出 $0011$ 循环（$[1,2]$ 是 $00$，不相等）；仍按旧协议把 $k$、$q$ 读在同一行。

## 复杂度分析

- 时间复杂度：$O(k+q)$，读入 $q$ 个窗口，再构造长度为 $k$ 的串。
- 空间复杂度：$O(k)$，存放答案字符串。

$k,q\le 10^5$，线性即可。

## 代码实现

### Python

```python
def build_balanced_01(k):
    # 灯位从 1 开始：奇数位放 0，偶数位放 1，得到 0101...
    # 任意偶数长度窗口里奇偶下标各一半，因此 0 和 1 一样多
    chars = []
    for i in range(1, k + 1):
        if i % 2 == 1:
            chars.append("0")
        else:
            chars.append("1")
    return "".join(chars)


def main():
    # 第一行灯带长度，第二行窗口条数
    k = int(input())
    q = int(input())
    # 窗口长度已保证为偶数，交错串对所有窗口都成立，读掉 a,b 即可
    for _ in range(q):
        input()
    print(build_balanced_01(k))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Main {
    // 灯位从 1 开始：奇数位放 0，偶数位放 1，得到 0101...
    static String buildBalanced01(int k) {
        StringBuilder sb = new StringBuilder(k);
        for (int i = 1; i <= k; i++) {
            if (i % 2 == 1) {
                sb.append('0');
            } else {
                sb.append('1');
            }
        }
        return sb.toString();
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        // 第一行灯带长度，第二行窗口条数
        int k = Integer.parseInt(br.readLine().trim());
        int q = Integer.parseInt(br.readLine().trim());
        // 窗口写成 a,b，交错串对所有窗口都成立，读掉即可
        for (int i = 0; i < q; i++) {
            br.readLine();
        }
        System.out.println(buildBalanced01(k));
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
using namespace std;

string buildBalanced01(int k) {
    // 灯位从 1 开始：奇数位放 0，偶数位放 1
    string t;
    t.resize(k);
    for (int i = 1; i <= k; i++) {
        t[i - 1] = (i % 2 == 1) ? '0' : '1';
    }
    return t;
}

int main() {
    ios::sync_with_stdio(false);

    // 第一行灯带长度，第二行窗口条数

        int a, b;

    }

}
```

```javascript
function buildBalanced01(k) {
    // 灯位从 1 开始：奇数位放 0，偶数位放 1
    const chars = [];
    for (let i = 1; i <= k; i++) {
        chars.push(i % 2 === 1 ? "0" : "1");

    return chars.join("");
}
```

### C

```c
#include <stdio.h>

#define MAXN 100005

char s[MAXN];

void build_balanced_01(int k) {
    int i;
    /* 灯位从 1 开始：奇数位放 0，偶数位放 1 */
    for (i = 1; i <= k; i++) {
        s[i - 1] = (i % 2 == 1) ? '0' : '1';
    }
    s[k] = '\0';
}

int main(void) {
    int k, q, i, a, b;
    /* 第一行灯带长度，第二行窗口条数 */
    scanf("%d", &k);
    scanf("%d", &q);
    /* 窗口写成 a,b，交错串对所有窗口都成立，读掉即可 */
    for (i = 0; i < q; i++) {
        scanf("%d,%d", &a, &b);
    }
    build_balanced_01(k);
    printf("%s\n", s);
    return 0;
}
```
