**2、货架俯拍要用卷积网络判断零件是否到位。下列关于卷积神经网络的说法，正确的是？**
{{ select(2) }}
- 卷积核越大，网络一定越不容易过拟合
- $卷积神经网络对图像进行分类，属于有监督学习方式$
- 池化层的作用是把全连接替换成循环神经网络

**3、点云分割大模型用数据并行训练。反向里梯度聚合通信占了 70%，且部分梯度通信可以和后续反向计算重叠。下列哪项优化最直接？**
{{ select(3) }}
- 按梯度就绪顺序发起通信，使梯度聚合与反向计算重叠
- 先把优化器换成随机猜参数，不再做反向传播
- 未看切分与拓扑就改成流水线并行，并关掉所有通信
- 把每张卡的 batch 扩到显存上限，使通信占比更高

**4、巡检照片要判“有裂缝 / 无裂缝”（二分类）。若输出层仅含一个神经元，激活函数通常使用？**
{{ select(4) }}
- 线性恒等映射，把输出限制在整数编号上
- 把所有通道做全局平均后再取 argmax
- logistic
- 用随机符号函数代替可导激活

**5、值班日志超长，要用能扛长序列的架构。下列哪种架构设计无法直接解决长序列建模问题？**
{{ select(5) }}

- 对远程 token 做分块稀疏连接，使复杂度低于二次

**7、巡检机器人按策略 $\pi$ 在厂区里走。以下是强化学习中状态价值函数 $V^\pi(s)$ 的定义的是？**
{{ select(7) }}
- $\mathrm{P}[S_{t+1}=s' \mid S_t=s]$
- $\max_a Q(s,a)$
- $\mathbb{E}_\pi[G_t \mid S_t = s]$
- $\sum_a \pi(a|s)$

**8、制度条款要做成词向量。以下关于词汇表征方法的表述正确的是？**
{{ select(8) }}
- 每个词只保留一个比特标记，因此 one-hot 一定比稠密向量更省显存
- word2vec 本质上是一种降维操作
- 词频统计不能得到任何向量，必须先训练生成式语言模型
- 字符级卷积会把词表膨胀成与句子长度无关的固定三维坐标
