# P5362 测试数据说明

共 $10$ 组。第一行 $m$，第二行长度 $2m$ 的 `01` 串（各 $m$ 个）。输出环上变成严格交错的最少相邻交换次数。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 `1100` | 中间交换一次 | 输出 $0$ |
| 2 | 样例2 跨首尾 | 必须用环边 | 当线性做 |
| 3 | 样例3 $m=1$ | 已交错 | 输出 $1$ |
| 4 | `(01)^m` | 答案 $0$ | 多种目标重复加 |
| 5 | `0^m 1^m` | 绕环更优 | 只匹配 $k\ge 0$ |
| 6 | `1^m 0^m` | 对称两团 | 只做一种交错 |
| 7 | $m=25$ 随机 | 与 $O(m^2)$ 对拍 | 偏移公式写错 |
| 8 | 局部打乱 | 中等答案 | 除以 `2` |
| 9 | $m=2\times 10^5$ 两团 | 压测 | $O(m^2)$ TLE |
| 10 | $m=2\times 10^5$ 随机 | 压测 | TLE / 溢出 |

前 $8$ 组小；后 $2$ 组压测。
