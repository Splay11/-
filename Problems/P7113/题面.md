# 题目内容

给定长度为 $n$ 的正整数数组 $a$。每次只能删除当前序列最左或最右的元素；若当前长度为 $\textit{len}$、被删元素值为 $x$，则此次代价为 $\textit{len}\times x$。求将数组全部删完的最小总代价。

## 输入描述

第一行一个整数 $n$。

第二行 $n$ 个正整数 $a_1,a_2,\ldots,a_n$。

## 输出描述

输出一个整数，表示最小总代价。

## 数据范围

- $1 \le n \le 1000$
- $1 \le a_i \le 10^9$

## 样例1

输入：

```
4
2 2 1 2
```

输出：

```
17
```

说明：一种最优顺序是先删右端 $2$（代价 $8$），再删右端 $1$（代价 $3$），再删一端的 $2$（代价 $4$），最后删剩下的 $2$（代价 $2$），总代价 $8+3+4+2=17$。
