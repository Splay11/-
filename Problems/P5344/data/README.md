# P5344 测试数据说明

共 $10$ 组。第一行 $c\ q\ w$，第二行 $c$ 个硬度。输出打完 $q$ 块的最少天数。已改为单组询问。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 | 周期中途击杀 | 功率按天 $+1$ |
| 2 | 样例2 | 长期只打一个槽位 | 漏掉空锤日 |
| 3 | 样例3 $c=1,w=0$ | 第一天打不了 | 输出 $1$ |
| 4 | $w$ 已盖过最大硬度 | 答案等于 $q$ | 仍去升功率 |
| 5 | $c=1$ 需升功率 | $\lfloor(D-1)/c\rfloor$ | 下标从 $0$ 算错 |
| 6 | 只有中间一天能打 | 位置贡献公式 | 把所有天都当能打 |
| 7 | 四天硬度全相同 | 与暴力对拍 | 功率按天 $+1$ 而不是每 $c$ 天 $+1$ |
| 8 | 短周期随机 | 对拍 | 取模天数 |
| 9 | $c=200000,q=10^6$ | 中等满周期 | $O(q)$ 模拟 |
| 10 | $c=200000,q=10^{12}$，硬度全 $10^{12}$ | 必须二分 | 按天模拟 TLE |

前 $8$ 组可暴力；后 $2$ 组压测。
