# 题目内容

有 $m$ 个怪物。第 $t$ 天（从 $1$ 开始计数）每个怪物的血量统一为 $a_{(t-1 \bmod n)+1}$，其中给定长度为 $n$ 的数组 $a$ 表示血量随天数的循环变化。

你是一名勇者。初始攻击力为 $k$，攻击力以 $n$ 天为一个阶段增长。在第 $1$ 天至第 $n$ 天，攻击力为 $k$；在第 $(n+1)$ 天至第 $2n$ 天，攻击力为 $(k+1)$；在第 $2(n+1)$ 天至第 $3n$ 天，攻击力为 $(k+2)$，以此类推。形式化地，在第 $D$ 天，攻击力为 $k+\lfloor(D-1)/n\rfloor$。每一天你可以选择一个怪物进行一次攻击：
- 若第 $D$ 天的攻击力不小于当日怪物血量，则你打败该怪物，剩余怪物数量减一；
- 否则攻击失败，无任何变化。第二天怪物血量按规则重新置为 $a_{(t-1 \bmod n)+1}$。

请计算打败全部 $m$ 个怪物所需的最少天数。



# 输入描述

输入包含多组测试数据。第一行输入一个整数 $T\ (1 \le T \le 10^3)$ 表示测试组数。每组测试数据描述如下：

第一行输入三个整数 $n,m,k\ (1 \le n \le 2 \times 10^5,\ 1 \le m \le 10^{12},\ 0 \le k \le 10^{12})$；

第二行输入 $n$ 个整数 $a_1,a_2,\dots,a_n\ (1 \le a_i \le 10^{12})$。

保证所有测试中 $n$ 的总和不超过 $2 \times 10^5$。



# 输出描述

对于每组测试数据，输出一行一个整数，表示最少所需天数。



## 样例1 



**输入** 



```
3
3 2 100
5 7 6
3 3 1
2 1 3
2 4 0
5 10
```



**输出** 



```
2
5
17
```



**说明**

样例一：$(n=3,m=2,k=100,a=[5,7,6])$。

第1天血量5，$k=100 \ge 5$，击败1只；第2天血量7，继续击败最后1只，共用2天。

样例二：$(n=3,m=3,k=1,a=[2,1,3])$。

第2天击败1只；第4天击败1只；第5天击败1只，共5天。

样例三：$(n=2,m=4,k=0,a=[5,10])$。

攻击力按天数每过2天+1，能击杀的天为第11、13、15、17天，共4只，最少17天。
