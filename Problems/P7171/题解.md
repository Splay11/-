# 1到n的最小公倍数

算法标签：数学、数论

算法难度：$3 / 10$

## 解题思路

求 $lcm(1,2,\ldots,n)$。$n\le 40$，答案保证在 $64$ 位有符号整数内。

1. 从 $1$ 开始累乘。每加入一个 $i$，更新 $ans=lcm(ans,i)$。
2. $lcm(a,b)=a/\gcd(a,b)\times b$。先除后乘，避免中间因子重复。
3. 等价于把 $1$ 到 $n$ 每个质因数的最高次幂乘起来，例如 $n=10$ 时是 $8\times 9\times 5\times 7=2520$。
4. 常见假解：直接把 $1$ 到 $n$ 连乘（那是阶乘，不是最小公倍数）；用 $32$ 位整数存 $n=40$ 的答案会溢出。

## 复杂度分析

- 时间复杂度：$O(n\log n)$。每步求一次 $\gcd$。
- 空间复杂度：$O(1)$。

## 代码实现

### Python

```python
def gcd(a, b):
    """辗转相除求最大公约数。"""
    while b:
        a, b = b, a % b
    return a


def solve(n):
    """从 1 累乘到 n，每步用 lcm(ans, i) = ans / gcd(ans, i) * i。"""
    ans = 1
    for i in range(1, n + 1):
        g = gcd(ans, i)
        ans = ans // g * i
    return ans


def main():
    n = int(input())
    print(solve(n))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class Main {
    static long gcd(long a, long b) {
        while (b != 0) {
            long t = a % b;
            a = b;
            b = t;
        }
        return a;
    }

    static long solve(int n) {
        long ans = 1;
        for (int i = 1; i <= n; i++) {
            long g = gcd(ans, i);
            ans = ans / g * i;
        }
        return ans;
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());
        System.out.println(solve(n));
    }
}
```
