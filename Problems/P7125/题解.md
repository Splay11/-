# 多数元素

算法标签：Boyer-Moore 投票、哈希表

算法难度：$3 / 10$

## 解题思路

多数元素出现次数严格大于 $\lfloor n/2 \rfloor$，题目还保证它一定存在，所以不必处理「没有多数」的情况。

1. 最直接的做法是用哈希表统计每个数出现几次，找出次数大于 $\lfloor n/2 \rfloor$ 的那个。$n\le 5\times 10^4$，这样做时间和空间都是 $O(n)$，可以通过。
2. 更省空间的做法是 Boyer-Moore 投票：维护当前候选人 $cand$ 和它的票数 $cnt$。遇到 $cand$ 就 $cnt+1$，遇到别的就 $cnt-1$；票数掉到 $0$ 时，把当前数立成新的候选人。
3. 不同的数会互相抵消。因为多数元素的出现次数过半，抵消完之后留下的候选人一定是它。题目保证存在，所以扫一遍即可，不用再验票。
4. 也可以排序后取下标 $\lfloor n/2 \rfloor$ 上的元素，复杂度 $O(n\log n)$。
5. 常见假解：直接输出第一个数（它不一定是多数）；只统计正数，漏掉负数多数元素。

## 复杂度分析

- 时间复杂度：$O(n)$。每个元素只看一次。
- 空间复杂度：$O(1)$。只保存候选人和票数。哈希表做法是 $O(n)$ 额外空间。

$n=5\times 10^4$ 时线性扫描足够。

## 代码实现

### Python

```python
def majority_element(nums):
    # Boyer-Moore 投票：抵消后剩下的就是多数元素
    cand = 0
    cnt = 0
    for x in nums:
        # 没有候选人时，把当前数立为候选人
        if cnt == 0:
            cand = x
            cnt = 1
        elif x == cand:
            # 碰到候选人，票数加一
            cnt += 1
        else:
            # 碰到其他数，互相抵消一票
            cnt -= 1
    # 题目保证多数元素存在，候选人就是答案
    return cand


def main():
    # 第一行：数组长度
    n = int(input())
    # 第二行：n 个整数
    nums = list(map(int, input().split()))
    print(majority_element(nums))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.StringTokenizer;

public class Main {
    // Boyer-Moore 投票：抵消后剩下的就是多数元素
    static int majorityElement(int[] nums) {
        int cand = 0;
        int cnt = 0;
        for (int x : nums) {
            // 没有候选人时，把当前数立为候选人
            if (cnt == 0) {
                cand = x;
                cnt = 1;
            } else if (x == cand) {
                // 碰到候选人，票数加一
                cnt++;
            } else {
                // 碰到其他数，互相抵消一票
                cnt--;
            }
        }
        // 题目保证多数元素存在，候选人就是答案
        return cand;
    }

    public static void main(String[] args) throws IOException {
        // n 最大 5e4，用 BufferedReader 读入
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());
        StringTokenizer st = new StringTokenizer(br.readLine());
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = Integer.parseInt(st.nextToken());
        }
        System.out.println(majorityElement(nums));
    }
}
```

        if (cnt == 0) {

        }

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
