# P7125 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：第一行 `n`，第二行 $n$ 个整数。
输出：多数元素（出现次数 $> \lfloor n/2 \rfloor$）。输入保证存在。

约束：$1 \le n \le 5\times 10^4$，$-10^9 \le nums_i \le 10^9$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1，$n=3$ | 答案 $3$，出现 $2$ 次 | 输出第一个数 $3$ 碰巧对，不足以覆盖后面的组 |
| 2 | 样例 2，$n=7$ | 答案 $2$，出现 $4$ 次 | 误把出现 $3$ 次的 $1$ 当成多数 |
| 3 | 最小规模 $n=1$ | 答案就是唯一那个数 | 空数组/下标越界 |
| 4 | 全部相同 | 答案 $5$ | 投票时票数加减写反 |
| 5 | 多数元素是负数 | 答案 $-3$ | 只统计正数，或用无符号类型 |
| 6 | 刚好过半：$3>\lfloor 5/2 \rfloor$ | 答案 $7$ | 写成 $\ge n/2$ 时本题仍对，但次数判断要严格大于 |
| 7 | 多数 $1$ 偏后，开头不是答案 | 答案 $1$ | 直接输出 $nums_0$ |
| 8 | 小随机，$n=11$，多数为 $42$ | 哈希计数可对拍 | 投票候选人更新条件写错 |
| 9 | 压满 $n=5\times 10^4$，多数为 $1$，刚过半 | 答案 $1$ | $O(n^2)$ 计数超时 |
| 10 | 压满 $n=5\times 10^4$，多数为 $-10^9$，其余为 $0$ 或 $10^9$ | 答案 $-10^9$ | 32 位不够存元素，或漏掉负数 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：哈希计数得到的众数必须与 Boyer-Moore 结果一致，且次数严格大于 $\lfloor n/2 \rfloor$。
