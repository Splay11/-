# P5274 测例说明

单组无向图，从 1 号 BFS。不可达点不输出。

| 组 | 规模 | 目标 | 卡掉的错误解 |
|---:|---|---|---|
| 1 | 改写样例1 | 同层按编号 | 按 BFS 入队序输出 |
| 2 | 改写样例2 | 只输出 1 | 把其他连通块也打出来 |
| 3 | 改写样例3 | 边序与编号序不同 | 不按编号打破平局 |
| 4 | n=1 | 仅 `1 0` | 空图漏点 |
| 5 | 自环重边 | 仍是无向最短路 | 建成有向图 |
| 6 | 链 | 距离等于编号差 | 0 下标 |
| 7 | 星形乱序边 | 同层排序 | 按边输入序 |
| 8 | 小随机+隔离块 | 不输出隔离点 | 距离写成 -1 仍输出 |
| 9 | n=1e5 长链 | 压测 | 递归 DFS 爆栈 |
| 10 | n=1e5 星形 | 同层 99999 个点排序 | 漏排序、TLE 输出 |
