# 题目内容

小华今年工作完成的非常好，部门公认的优秀员工，部门准备奖励一下小华。

小华可以从礼物清单里面选四个礼物，总价不能超过$10000$元。

每个礼物都有特定编号和价格，礼物编号不会重复，价格可能重复。

小华想挑选四个总价最接近上限的礼物，如果总价一样，就选择礼物编号按照升序排序后数值序小的那一组。




# 输入描述

第一行包含一个整数$N$，表示礼物个数。

后面的$N$行表示$N$个礼物，每行的两个数字$N_i$和$P_i$分别表示礼物的编号和价格。

如果没有满足要求的$4$个礼物，输出$0$。

数据范围:
- $1 \le N \le 2000$
- $1 \le N_i, P_i \le 10000$



# 输出描述

如果有满足要求的礼品，输出礼品编号，礼品编号之间以空格分割，礼品编号按照升序排序。如果没有满足要求的礼物输出$0$。




## 样例1 



**输入** 



```
6
1 100
3 10000
5 5000
8 3000
7 100
9 100
```



**输出** 



```
1 5 7 8
```



**说明**

$[1,5,8,7]$ $[1,5,8,9]$ $[5,8,7,9]$三组礼物价值之和全部是$8200$且最接近$10000$，优选按照ID数值排序后数值序小的礼物组合。

## 样例2



**输入** 



```
5
1 100
3 10000
5 5000
8 5000
9 9988
```



**输出** 



```
0
```



**说明**

这里面找不出4个礼物之和小于等于$10000$元，输出$0$。
