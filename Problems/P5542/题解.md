# Transformer FFN

## 解题思路

本题实现 Position-wise FFN：$\mathrm{FFN}(X)=\mathrm{ReLU}(XW_1+b_1)W_2+b_2$。

1. 第一层线性：$H = XW_1 + b_1$。
2. 逐元素 $\mathrm{ReLU}$：$H \leftarrow \max(0, H)$。
3. 第二层线性：$Y = HW_2 + b_2$。
4. 用 `numpy` 矩阵乘实现，输出保留 $2$ 位小数。

## 复杂度分析

- 时间复杂度：$O(N \cdot d_{model} \cdot d_{ff})$
- 空间复杂度：$O(N \cdot d_{ff} + N \cdot d_{model})$

## 代码实现

### Python

```python
import numpy as np


class Solution:
    def ffn(self, X, W1, b1, W2, b2):
        # FFN(X) = ReLU(X W1 + b1) W2 + b2
        X = np.asarray(X, dtype=np.float64)
        W1 = np.asarray(W1, dtype=np.float64)
        b1 = np.asarray(b1, dtype=np.float64)
        W2 = np.asarray(W2, dtype=np.float64)
        b2 = np.asarray(b2, dtype=np.float64)
        h = X @ W1 + b1
        h = np.maximum(h, 0.0)  # ReLU
        return h @ W2 + b2
```
