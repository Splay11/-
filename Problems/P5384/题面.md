# 题目内容

多多是一位魔法探险家，正在探索一片由 $n$ 个魔法节点组成的古老迷宫，节点编号为 $0$ 到 $n-1$。迷宫中存在两种通道：
- 普通道路：给定数组 edges，edges[i] = [u, v, w]，表示节点 $u$ 和 $v$ 之间有一条耗时为 $w$ 的双向普通道路，$(w>=0)$。
- 魔法传送门：给定数组 portals，portals[i] = [u, v]，表示节点 $u$ 和 $v$ 之间有一个双向传送门，使用传送门的耗时为 $0$。

多多从起点 start 出发，希望尽快到达终点 end。传送门的使用需要遵守以下规则：
1. 整条途中最多使用 $k$ 次传送门。
2. 不能连续使用两次传送门（两次传送门之间必须经过至少一条普通道路）。
3. 从起点出发时，可以直接使用传送门。

给定起点 start 和终点 end，返回从起点到终点的最短总时间。若 start 等于 end，输出 $0$。如果无法到达，返回 $-1$。



# 输入描述

第一行包含两个整数 $n$ 和 $m$，分别表示节点数量和普通道路数量。

接下来 $m$ 行，每行三个整数 $u(u、v)v(u、v)w$，表示一条普通道路。

下一行包含一个整数 $p$，表示传送门数量。

接下来 $p$ 行，每行两个整数 $u(u、v)v$，表示一个传送门。

下一行包含三个整数 $k$(u、v)start(u、v)end。

数据范围：
$1 \le n \le 10000$

$0 \le m \le 200000$

$0 \le p \le 10$

$0 \le k \le 10$

$0 \le w \le 10^9$

$0 \le start, end < n$

普通道路和传送门均可能有重边或自环

答案可能超过 int 范围，建议用 long 存储



# 输出描述


输出一个整数，表示从起点到终点的最短总时间。若 start 等于 end，输出 $0$。如果无法到达，返回 $-1$。



## 样例1 



**输入** 



```
4 3
0 1 10
1 2 10
2 3 10
2
0 2
2 3
2 0 3
```



**输出** 



```
10
```



**说明**

先通过传送门从 $0$ 到 $2$（耗时 $0$），再通过普通道路从 $2$ 到 $3$（耗时 $10$），总时间为 $10$。

不能从 $0$ 传送到 $2$ 后立刻再次传送到 $3$（违反规则2：不能连续使用传送门）。

## 样例2



**输入** 



```
3 2
0 1 5
1 2 5
0
2 0 2
```



**输出** 



```
10
```



**说明**

$(k=0)$ 表示不能使用任何传送门，只能走普通道路。
从 $0$ 经 $1$ 到 $2$，总时间为 $(5+5=10)$。


## 样例3



**输入** 



```
3 1
0 1 5
0
1 1 1
```



**输出** 



```
0
```



**说明**

start 等于 end（均为节点 $1$），无需移动，输出 $0$。
