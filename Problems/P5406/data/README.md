# P5406 测例说明

分层（每组 10 分）：

- 1：样例 1。免费边不在原最短路上，答案 $1$。卡「只在最短路上挑一条免费」。
- 2：样例 2。不连通，答案 $-1$。
- 3：$s=t$，答案 $0$。
- 4：免费一条捷径后路程变成 $0$。
- 5：只有一条边，免费后答案 $0$。
- 6：$n=30$。枚举每条边改权再 Dijkstra 可通过。
- 7：$n=800$。
- 8：$n=8000$ 的等权链。免费恰好一条，答案 $799800$。
- 9：$n=8000$ 随机，边权到 $10^6$，卡 `int` 溢出。
- 10：$n=8000$ 的链加一条可免费的大跨边，答案 $1$。

hack 点：裸最短路不用协议、只免费最短路上的边、漏掉通道反方向、用 `int` 累加。
