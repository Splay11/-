

**1、跳表中高层索引用于快速跳过一段有序结点。查找目标值时，较合理的过程是?**
{{ select(1) }}
- 从最底层头结点线性扫描到链表结尾
- 从最高层索引开始逐层向下并向右推进
- 先重建高层索引，再从底层头结点顺序扫描查找目标
- 每次随机选择一个结点作为根结点

**2、模型在公开基准上异常高分，但业务集表现一般，且训练语料可能包含基准答案。应优先排查什么?**
{{ select(2) }}
- 线上样本分布变化使模型在公开基准上的得分被低估
- 评测集污染使模型对公开基准的离线分数被高估
- 模型参数量不足使业务集得分必然高于公开基准
- 推理批次过小使基准答案随机进入模型生成结果

**3、一张图片可以同时包含“猫”和“狗”等多个标签。训练这类多标签分类模型时，更合适的输出与损失组合是?**
{{ select(3) }}
- 每个标签独立 sigmoid 输出，并配合二元交叉熵
- 使用聚类簇编号替代监督标签
- 对标签向量做一个 softmax 输出，并把概率最高的类别作为训练目标
- 把标签字符串作为卷积核权重

**4、二分类数据中正例很少。如果只用总体准确率选模型，哪项能力最容易被掩盖?**
{{ select(4) }}
- 训练损失在每个批次中都无法执行反向传播
- 模型对多数负例的整体识别能力可能明显不足
- 模型对少数正例的识别能力可能明显不足
- 预测概率无法用于排序，只能输出一个固定类别

**5、向量检索把问题和文档片段编码为 embedding 后，相似度分数用于完成哪一步?**
{{ select(5) }}
- 根据 token 数量接近程度筛选长度相似的文档片段

- 把查询向量转成类别编号，再按编号查找文档片段
- 召回与用户问题语义相近的候选文档片段

**6、Transformer 使用 LayerNorm 时，均值和方差通常沿哪个范围计算?**
{{ select(6) }}
- 在全部训练样本上预先计算一组固定均值和方差
- 在一个批次内按同一隐藏位置聚合不同样本的统计量
- 只对注意力权重矩阵的每一列做全局归一化处理
- 沿单个样本的隐藏维度计算归一化统计量

**7、企业模型要说明结论依据，但不能泄露隐藏推理、系统提示词或密钥。回答应包含什么?**

**11、大模型解码采用top-k采样时，候选token如何确定?**
{{ select(11) }}
- 始终选择概率最高的一个token，不进行随机采样
- 保留累计概率达到阈值p的最小候选集合后再采样
- 从概率最高的k个token中采样
- 从完整词表的全部token中按原始概率直接采样

**13、训练损失继续下降而验证损失开始上升时，早停策略要避免什么?**
{{ select(13) }}
- 验证损失上升后继续训练，使模型充分记住训练集样本
- 在验证性能恶化前停止训练，减少过拟合造成的泛化下降
- 删除验证集，只依据训练准确率选择最后一轮模型
- 从第一轮开始固定全部参数，使训练损失不再发生变化

**14、不固定分类阈值时，ROC-AUC重点衡量二分类模型的哪项能力?**
{{ select(14) }}
- 衡量预测概率与真实发生频率之间的校准一致性
- 在一个固定阈值下统计分类预测正确的样本比例
- 计算预测概率与二分类标签之间的平均平方误差
- 衡量模型把正样本排在负样本之前的排序能力

**15、B+树常用于数据库索引。相比把记录散布在内部结点，B+树叶子结点按键值有序链接的一个好处是?**
{{ select(15) }}
- 查询通常可以绕过叶子页读取，主要在内部结点完成定位和返回
- 范围扫描沿叶子链表顺序访问
- 哈希冲突会在根结点合并处理，减少叶子链表维护成本
- 插入操作不再需要维护键值顺序关系

**16、训练图像分类模型时，若亮度和对比度的小幅随机扰动不改变类别语义，原标签应怎样处理?**
{{ select(16) }}
- 把类别标签改成背景类

- 降低样本监督权重，把增强后的样本更多作为无标签数据参与训练
- 把标签替换为随机类别

**18、目标检测使用Smooth L1进行边界框回归，相比L2，它希望降低哪类样本对训练的影响?**

**19、真实类别为公交车的图片经常被模型预测成卡车。混淆矩阵中的这一现象说明什么?**
{{ select(19) }}
- 模型对外观相近的车辆类别存在较明显的识别混淆

- 公交车和卡车的预测概率都已经完成准确校准
- 训练集中公交车样本数量必然多于卡车样本数量
