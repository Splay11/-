# 灯架层深

# 题目内容

灯会搭建组要把一架花灯支成二叉树：每个实灯最多分出左、右两根杈。名册按层从左到右登记每盏灯的编号；某一杈空着时写成 `#`，空杈不再往下登记。整份名册用花括号包起来，项与项之间用逗号分隔，例如 `{8,4,6}` 表示顶灯为 `8`，左右子灯为 `4` 与 `6`。

层深定义为：从顶灯走到某一盏叶子灯，途中经过的实灯个数的最大值。请根据名册求出这架灯的层深。输入保证顶灯存在，名册是合法的层序登记。

约束：

- 名册中的项数（含 `#`）为 `1` 到 $10^4$
- 实灯编号为整数，绝对值不超过 $10^9$

# 输入描述

一行一个字符串，形如 `{a,b,#,c}`：花括号内是层序登记，实灯为整数，空杈为 `#`。

# 输出描述

输出一个整数，表示灯架的层深。

## 样例1

**输入**

```
{8,4,6}
```

**输出**

```
2
```

**说明**

顶灯 `8` 下左右各一盏，最深走 `2` 盏实灯。

## 样例2

**输入**

```
{2,#,8,#,9}
```

**输出**

```
3
```

**说明**

只有右链：`2` → `8` → `9`，层深为 `3`。

## 样例3

**输入**

```
{5}
```

**输出**

```
1
```

**说明**

只有顶灯一盏，层深为 `1`。
