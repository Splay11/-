# P5386 测试数据说明

共 $10$ 组。一行 `{...}` 层序名册，`#` 为空杈，输出二叉树层深（根到最远叶子的实灯个数）。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 `{8,4,6}` | 层深 `2` | 输出结点数 `3` |
| 2 | 样例2 右链 | 层深 `3` | 漏掉被 `#` 隔开的右子 |
| 3 | 样例3 单点 | `1` | 输出 `0` |
| 4 | 三结点完全树 | `2` | |
| 5 | 短左链 | 深度等于链长 | 用边数，少 `1` |
| 6 | 小随机 | 结构 | 把 `#` 当成一层 |
| 7 | `{10,#,11,12}` | 左空再分叉 | 下标错位建树 |
| 8 | 满 `4` 层 | `4` | 按序列长度当深度 |
| 9 | 右链 $5000$ 结点 | 压测 | 递归爆栈 |
| 10 | 完全树 $8191$ 结点 | 压测 I/O | $O(n^2)$ 用 `list.pop(0)` |

前 $8$ 组小；后 $2$ 组压测。项数均 $\le 10^4$。
