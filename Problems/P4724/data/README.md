主生成脚本：目录上级 `gen_data.py`（`SEED=472406897`，可复现）。

**平台单次 JSON 上传若遇 HTTP 413**：请使用题目目录内 **`P4724_testdata_all_pairs.zip`**（与 `data/` 内全部 `.in/.out` 一致）走 CodeFun2000 / Hydro 的**测试数据打包导入**入口完成原样同步；勿为通过接口而改弱本地数据。

## 组别与意图

| 编号 | 规模 | 特征与目标 |
|------|------|------------|
| 1 | 5 条路径 | 题面样例 1 |
| 2 | 5 条路径 | 题面样例 2 |
| 3 | 3 条路径 | 题面样例 3 |
| 4 | 3 条路径 | 目标不存在 → `[]`；`files`/`sizes` 等长 |
| 5 | 1 条路径 | 目标仅为文件、无子项 → `[]` |

| 8 | 800 条路径 | 中层：多文件聚于一级子目录 `c0`，深度贴题意上限 |
| 9 | **50000** | **极限**：每条路径总长 **128** 字节；`size` 大量为 **10^9** 与 0 混合；一级子项 `A`/`B` 两桶 |
| 10 | **100000** | **极限**：`n` 顶满；单条路径总长 **128**；`c0` 下 99900 条累加 vs `c1` 下 100 条 `10^9`（答案以 `.out` 为准） |

## 文件体积（约）

- `9.in` 约 7.2 MB；`10.in` 约 13.9 MB（单行 JSON 风格 stdin，用于压测读入与解析）。

## Hack 指向

- **6**：路径前缀未校验 `/` 边界。
- **8–10**：漏用 64 位累加、错判一级子项、或只扫最大单文件而非子树和。

## 换行约定

- `.in`：单行，行末**无**多余换行（最后一字节为数据字符，一般为 `]`）。
- `.out`：单行 JSON，末尾**有且仅有**一个 `\n`。
