# 一级子项最大占用空间

## 题目描述

员工 $A$ 的磁盘空间经常被耗尽，他需要找到占用空间最大的目录或文件，并据此决定如何清理以释放空间。

给定某一目录路径 `target`，以及文件系统中所有**文件**的完整路径列表 `files` 与对应的占用大小 `sizes`（与 `files` 一一对应），请你统计：**在 `target` 目录下的一级子项**（直接位于 `target` 下的文件，或直接位于 `target` 下的子目录）各自所占用的空间；并返回其中占用空间**最大**的一级子项的完整路径列表。

评测采用 **LeetCode 核心代码模式**：你只需要实现 `Solution` 类中的方法，平台会负责读入数据并调用你的方法。**不要**编写 `main` 或标准输入输出逻辑。

## 规则说明

1. **目录占用空间**：某个目录所占空间等于其**内部所有文件**的 `Size` 之和（递归计入子目录中的文件）；目录本身不单独占非零大小（可视为 $0$）。
2. **一级子项**：若 `target` 为 `/a`，则路径形如 `/a/x`（文件）或 `/a/b/...`（其中 `b` 为一级子目录名）中的 **`/a/x` 或 `/a/b`** 为一级子项；更深层的文件计入对应一级子目录的大小中。
3. **路径与数据范围**：目录深度不超过 $7$ 层；目录或文件名总长度不超过 $128$ 字节。`files` 中每条路径表示一个文件。
4. **并列最大**：若有多个一级子项占用空间同为最大值，需按路径字符串**字典序升序**全部输出。
5. **目标不存在**：若不存在任何 `files` 中的路径 `p` 满足 `p == target` 或 `p` 以 `target + '/'` 为前缀（即 `target` 未出现在该文件系统的前缀意义下），返回**空列表** `[]`。
6. **无一级子项**：若 `target` 存在（上一条成立），但没有任何文件位于 `target` 的子路径下（即无法形成一级子项），返回空列表 `[]`。

## 方法签名

三种语言的类名均为 `Solution`，请实现：

- **C++**：`vector<string> findMaxOccupiedPaths(string target, vector<string>& files, vector<int>& sizes);`
- **Java**：`public List<String> findMaxOccupiedPaths(String target, List<String> files, List<Integer> sizes)`
- **Python**：`def findMaxOccupiedPaths(self, target: str, files: List[str], sizes: List[int]) -> List[str]:`

### 参数说明

- `target`：要统计的目标目录绝对路径，以 `/` 开头，无尾随 `/`。
- `files`：文件系统中所有文件的绝对路径，与 `sizes` 等长。
- `sizes`：与 `files` 一一对应的非负整数文件大小。

### 返回值

占用空间最大的所有一级子项路径，按字典序升序排列；格式与下方样例输出一致（与 Python `json.dumps` 对字符串列表的默认序列化一致：`["/a", "/b"]`）。

## 输入格式（平台侧，选手无需编写）

一行文本，结构为：

```text
"<target>", ["<path1>", ...], [<size1>, ...]
```

- 第一项为双引号包裹的 `target` 字符串（路径内不含未转义的双引号）。
- 第二项为 JSON 风格字符串数组（文件路径列表）。
- 第三项为整数数组（与文件一一对应）。
- 项与项之间为英文逗号；解析时需考虑字符串内部的逗号（路径中不含英文逗号时与模板解析一致）。

## 输出格式

一行，为字符串列表的 JSON 表示，行末换行。例如：`["/dir1/dir2-1/file3-2"]` 或 `["/dir1/dir1", "/dir1/dir2"]`。

## 样例 1

**输入**

```text
"/dir1/dir2-1", ["/dir0/dir1-1/file1-1", "/dir1/dir1-1/file1-1", "/dir1/dir2-1/file3-1", "/dir1/dir2-1/file3-2", "/dir1/dir2-1/dir3-1/file4-1"], [8192, 81920, 2048, 8192, 1024]
```

**输出**

```text
["/dir1/dir2-1/file3-2"]
```

**解释**：`/dir1/dir2-1` 下有三个一级子项 `file3-1`、`file3-2`、`dir3-1`，占用分别为 $2048$、$8192$、$1024$；最大为 `file3-2`。

## 样例 2

**输入**

```text
"/dir1", ["/dir0/dir2-1/file3-1", "/dir1/dir2-1/file3-1", "/dir1/dir2-1/file3-2", "/dir1/dir2-2/file3-3", "/dir1/file2-3"], [10240, 4096, 8192, 10240, 8192]
```

**输出**

```text
["/dir1/dir2-1"]
```

**解释**：一级子项 `dir2-1`、`dir2-2`、`file2-3` 占用分别为 $12288$、$10240$、$8192$。

## 样例 3

**输入**

```text
"/dir1", ["/dir1/dir1/file1", "/dir1/dir1/file2", "/dir1/dir2/file3"], [1024, 2048, 3072]
```

**输出**

```text
["/dir1/dir1", "/dir1/dir2"]
```

**解释**：`dir1` 与 `dir2` 占用均为 $3072$，并列最大，字典序输出 `dir1` 在前。

## 数据范围

- 记 $n$ 为 `files` 的长度，则 $1 \le n \le 10^5$。
- 路径长度不超过 $128$；目录深度不超过 $7$。
- $0 \le sizes[i] \le 10^9$，建议使用 64 位整数累加。
