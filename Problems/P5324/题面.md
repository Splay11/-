# 题目内容

AK机点了一个外卖，已知外卖员从取餐处到达 AK机 宿舍楼计划经过 $n$ 个建筑，其中，第 $n$ 个建筑一定是 AK机 的宿舍楼。

通过地图显示，这 $n$ 个目标建筑距离 AK机 宿舍楼的距离依次为 $d_1,d_2,\dots,d_{n-2},d_{n-1},0$。

由于外卖员还有其它送餐需求，所以 $d$ 数组不一定是降序。

外卖员在第 $i(1 \le i \le n)$ 个建筑时拨打了 AK机 的电话，通知 AK机 可以下楼取餐，假设外卖员只会在到达某个建筑时拨打电话，在挂断电话之后才会上路，如果此时不在 AK机 的宿舍楼，那么，外卖员就会更改原定计划，将第 $(i+1)$ 个目的建筑更改为 AK机 的宿舍楼；即：外卖会在 $d_i$ 个单位距离后送达。

假设外卖员经过 $1$ 个单位距离恰好需要 $1$ 个单位时间，而 AK机 会在挂断电话的 $m$ 个单位时间后到达宿舍楼下，请问，AK机 还需要等待多久，外卖才会抵达。




# 输入描述

本题为多组测试数据，第一行输入一个正整数 $T(1 \le T \le 1000)$，代表测试数据的组数。

对于每组测试数据，第一行输入两个整数 $n,m(1 \le n \le 10^5,0 \le m \le 10^9)$，依次代表外卖员原计划经过的建筑数量，以及 AK机 在挂断电话后到达宿舍楼下的时间。

第二行依次输入 $n$ 个整数 $d_1,d_2,\dots,d_n$，对于前 $n-1$ 个建筑而言，$1 \le d_i \le 10^9$，而第 $n$ 个建筑一定是 AK机 宿舍楼，所以 $d_n = 0$。

题目保证，所有测试数据的 $n$ 之和不会超过 $2 \times 10^5$。




# 输出描述

对于每组测试数据，一行输出 $n$ 个整数，依次代表外卖员选择在第 $1,2,\dots,n$ 个建筑的时候拨打 AK机 的电话，AK机 下楼后需要等待的时长，特殊的，如果 AK机 在 到宿舍楼下前外卖就已抵达，则等待时长记为 $0$。




## 样例1 



**输入** 



```
2
3 0
9 6 0
3 6
6 9 0
```



**输出** 



```
9 6 0
0 3 0
```



**说明**

第一组测试数据，AK机 会在挂断电话的瞬间（不耗时）到达楼下，因此，等待的时长就是第 $i$ 个建筑到达 AK机 宿舍楼的时长，即：依次输出对应的 $d_i$ 即可。

第二组测试数据，AK机 会在挂断电话的 $6$ 个单位时间后到达寝室楼下，当 $(i=1)$ 时外卖到达宿舍楼下也恰好需要 $6$ 个单位时间，所以 AK机 不需要额外的等待时长；当 $(i=2)$ 时，外卖到达宿舍楼下需要 $9$ 个单位时间，所以 AK机 需要在楼下额外等待 $3$ 个单位时间；当 $(i=3)$ 时，外卖在抵达楼下后才打的电话，所以 AK机 不论 $m$ 为多少，到达楼下后都不需要任何等待时间，即可拿到外卖。
