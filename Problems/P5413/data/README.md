# P5413 测试数据说明

第一行是数组 $a$，第二行是 $t$。每个位置取左右最近严格更大元素，距离超过 $t$ 则该侧贡献为 $0$，总和对 $10^9+7$ 取模。

| 组别 | 规模/分布 | 生成逻辑 | 卡掉的错误解 |
|---|---|---|---|
| 1 | m=7，样例1 | 数组 [9,4,7,2,8,1,6]，t=4，最近更大与窗口边界都出现 | 在窗口里取最大值而不是第一个更大；相等也当成更大 |
| 2 | m=5，样例2 | t=2，下标 0 右侧真正的更大元素 12 距离为 3，不能计入；相邻 3 相等不算更大 | 忽略 t，直接用全局 NGE；把相等当成严格更大 |
| 3 | n=1，最小值 | 只有一座基站，左右都无邻居，答案为 0 | 越界访问；把 k 当成下标 |
| 4 | n=8，严格递减 | 每个位置左侧最近更大就是左邻，右侧没有更大 | 左右方向扫反；把距离写成下标本身 |
| 5 | n=8，严格递增 | 每个位置右侧最近更大就是右邻，左侧没有更大 | 左侧误用 <= 找到自己；右侧跳过紧邻去找更远的最大值 |
| 6 | n=10，全相等 | 严格大于不成立，所有贡献必须为 0 | 把 > 写成 >=，会把相邻相等当成干扰源 |
| 7 | n=15，k=1 | 只看左右紧邻；重复值不能作为严格更大 | k=1 时仍向远处搜索；相邻相等被计入 |
| 8 | n=20，k=2 | 下标 0 的第一个更大是 6 而不是更远的 10；若干位置的 NGE 落在 k 之外 | 窗口内取最大值；忽略 k 直接用 NGE |
| 9 | n=100000，严格递减，k=n | 每个位置向右扫描会走完整段，暴力 O(nk) 超时 | 每个位置向左右各扫 k 步的朴素解 |
| 10 | n=100000，值接近 1e9，k=n | 乘积达 1e14，总和超过 MOD，必须 64 位并取模 | 用 int 乘距离溢出；忘记对 1e9+7 取模 |
