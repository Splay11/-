# 题目内容

做 $5$G 组网方案时，要沿一条直线在若干点位架设基站。现在已知点位 $p$ 上的场强为 $a[p]$。对每一座基站，都要统计它被左右邻近基站干扰的程度。

对任意一座基站 $a[p]$，约定如下：

1. 左侧干扰区间：只在数组内部，自下标 $p-1$ 起朝更小下标走，至多探访 $t$ 座。
2. 右侧干扰区间：只在数组内部，自下标 $p+1$ 起朝更大下标走，至多探访 $t$ 座。
3. 左侧干扰指数：
    - 在该区间里找到最近、且场强严格高于 $a[p]$ 的那一座，记下标 $L$。
    - 找得到时，这一侧贡献为 $a[p] \times (p - L)$。
    - 找不到（窗口里没有更强的），这一侧贡献记 $0$（相当于令 $L = p$）。
4. 右侧干扰指数：
    - 在该区间里找到最近、且场强严格高于 $a[p]$ 的那一座，记下标 $R$。
    - 找得到时，这一侧贡献为 $a[p] \times (R - p)$。
    - 找不到，这一侧贡献记 $0$（相当于令 $R = p$）。
5. 总干扰指数：全部基站左、右两侧贡献加在一起。

请算出该总干扰指数并给出答案。

# 输入描述

第一行：数组 $a$，即全部基站的场强，例如 $9\ 4\ 7\ 2\ 8\ 1\ 6$

第二行：整数 $t$，一侧最多探访的座数，例如 $4$

### 约束

$1 \le m \le 10^5$，其中 $m$ 为 $a$ 的长度。

$1 \le a[p] \le 10^9$

$1 \le t \le m$

输入保证合法，不必再做校验。

# 输出描述

输出一个整数，表示总干扰指数。

结果需要对 $10^9+7$ 取模。

## 样例1

**输入**

```text
9 4 7 2 8 1 6
4
```

**输出**

```text
86
```

**说明**

1. 点位 $0$（场强 $9$）
    - 左：左侧没有基站 → 贡献 $=0$
    - 右：查看下标 $1$ 到 $4$（$4,7,2,8$）
        - $4 \le 9$ → 继续
        - $7 \le 9$ → 继续
        - $2 \le 9$ → 继续
        - $8 \le 9$ → 继续，窗口结束
        - 贡献 $=0$
    - 合计 $=0$
2. 点位 $1$（场强 $4$）
    - 左：查看下标 $0$（$9$）
        - $9>4$ → 间距 $=1-0=1$
        - 贡献 $=4\times 1=4$
    - 右：查看下标 $2$ 到 $5$（$7,2,8,1$）
        - $7>4$ → 间距 $=2-1=1$
        - 贡献 $=4\times 1=4$
    - 合计 $=4+4=8$
3. 点位 $2$（场强 $7$）
    - 左：查看下标 $1$ 到 $0$（$4,9$）
        - $4 \le 7$ → 继续
        - $9>7$ → 间距 $=2-0=2$
        - 贡献 $=7\times 2=14$
    - 右：查看下标 $3$ 到 $6$（$2,8,1,6$）
        - $2 \le 7$ → 继续
        - $8>7$ → 间距 $=4-2=2$
        - 贡献 $=7\times 2=14$
    - 合计 $=14+14=28$
4. 点位 $3$（场强 $2$）
    - 左：查看下标 $2$（$7$），$7>2$，间距 $1$，贡献 $2$
    - 右：查看下标 $4$（$8$），$8>2$，间距 $1$，贡献 $2$
    - 合计 $=4$
5. 点位 $4$（场强 $8$）
    - 左：查看下标 $3$ 到 $0$（$2,7,4,9$），前三个都不高于 $8$，下标 $0$ 的 $9>8$，间距 $4$，贡献 $32$
    - 右：查看下标 $5$ 到 $6$（$1,6$），都不高于 $8$，贡献 $0$
    - 合计 $=32$
6. 点位 $5$（场强 $1$）
    - 左：下标 $4$ 的 $8>1$，间距 $1$，贡献 $1$
    - 右：下标 $6$ 的 $6>1$，间距 $1$，贡献 $1$
    - 合计 $=2$
7. 点位 $6$（场强 $6$）
    - 左：下标 $5$ 的 $1$ 不高于 $6$，下标 $4$ 的 $8>6$，间距 $2$，贡献 $12$
    - 右：右侧没有基站 → 贡献 $=0$
    - 合计 $=12$

各点贡献汇总：
点位 $0$：$0$
点位 $1$：$8$
点位 $2$：$28$
点位 $3$：$4$
点位 $4$：$32$
点位 $5$：$2$
点位 $6$：$12$
加总 $=0+8+28+4+32+2+12=86$，再对 $10^9+7$ 取模仍是 $86$。

## 样例2

**输入**

```text
8 3 3 12 5
2
```

**输出**

```text
23
```

**说明**

1. 点位 $0$（场强 $8$）
    - 左：左侧没有基站 → 贡献 $=0$
    - 右：查看 $3,3$（至多 $2$ 座）
        - 均不高于 $8$ → 贡献 $=0$
        - 下标 $3$ 的 $12$ 虽然更大，间距已是 $3$，超出 $t=2$，不能用
    - 合计 $=0$
2. 点位 $1$（场强 $3$）
    - 左：查看 $8$，$8>3$，间距 $1$，贡献 $3$
    - 右：查看 $3,12$，相等不算，随后 $12>3$，间距 $2$，贡献 $6$
    - 合计 $=9$
3. 点位 $2$（场强 $3$）
    - 左：相邻 $3$ 相等不算，再往左 $8>3$，间距 $2$，贡献 $6$
    - 右：查看 $12,5$，$12>3$，间距 $1$，贡献 $3$
    - 合计 $=9$
4. 点位 $3$（场强 $12$）
    - 左：查看 $3,3$，都不高于 $12$ → 贡献 $=0$
    - 右：查看 $5$，不高于 $12$ → 贡献 $=0$
    - 合计 $=0$
5. 点位 $4$（场强 $5$）
    - 左：查看 $12,3$，$12>5$，间距 $1$，贡献 $5$
    - 右：右侧没有基站 → 贡献 $=0$
    - 合计 $=5$

加总 $0+9+9+0+5=23$，再对 $10^9+7$ 取模仍是 $23$。
