# 题目内容

在5G网络规划中，需要在一条直线上的若干位置部署基站。现给定每个位置 $i$ 的基站信号强度为 $\text{\(\text{power}\)}[i]$。针对每个基站，需要计算其受到的左右两相邻基站的干扰影响。

对于每个基站 $\text{\(\text{power}\)}[i]$，定义：
1. 左侧干扰区间：在数组范围内，从位置 $i-1$ 开始向左搜索（索引递减），最多搜索 $k$ 个基站。
2. 右侧干扰区间：在数组范围内，从位置 $i+1$ 开始向右搜索（索引递增），最多搜索 $k$ 个基站。
3. 左侧干扰指数：
    - 在左侧干扰区间内，寻找第一个（即最近一个）信号强度严格大于 $\text{\(\text{power}\)}[i]$ 的基站位置 $\text{left}_j$。
    - 若找到，则贡献值为 $\text{\(\text{power}\)}[i] \times (i - \text{left}_j)$。
    - 若未找到（即在搜索范围内无更强信号），则左侧贡献值为 $0$（即取 $\text{left}_j = i$）。
4. 右侧干扰指数：
    - 在右侧干扰区间内，寻找第一个（即最近一个）信号强度严格大于 $\text{\(\text{power}\)}[i]$ 的基站位置 $\text{right}_j$。
    - 若找到，则贡献值为 $\text{\(\text{power}\)}[i] \times (\text{right}_j - i)$。
    - 若未找到，则右侧贡献值为 $0$（即取 $\text{right}_j = i$）。
5. 总干扰指数：所有基站的 左侧干扰指数 + 右侧干扰指数 之和。

请计算并输出基站的总干扰指数。

# 输入描述

第一行: $\text{\(\text{power}\)}$ 所有基站的信号强度，如 $3\ 1\ 4\ 2\ 5$
第二行: $k$ 连续基站数量，如 $3$
- $\text{\(\text{power}\)}$ 长度范围: $1$-$10^5$
- $\text{\(\text{power}\)}$ 每个元素取值范围: $1 \le \text{\(\text{power}\)}[i] \le 10^9$
- $k$范围: $1 \le k \le$ 基站总数($\text{\(\text{power}\)}$长度)
> 注意: 题目保证输入合法，无需校验输入



# 输出描述


一个整数，基站的总干扰指数。
- 输出结果对 $10^9 + 7$ 取模



## 样例1 



**输入** 



```
7 2 5 3 9 4 6 1 8 3
5
```



**输出** 



```
7
```



**说明**

1. 基站0（强度7）
    - 左: 无基站 → 干扰=0
    - 右: 查看索引1到5 (2,5,3,9,4)
        - $2 \le7 \to$ 继续
        - $5 \le7 \to$ 继续
        - $3 \le7 \to$ 继续
        - $9>7 \to$ 距离=$4-0=4$
        - 干扰=$7 \times4=28$
    - 合计=$0+28=28$
2. 基站1（强度2）
    - 左: 查看索引0 (7)
        - $7>2 \to$ 距离=$1-0=1$
        - 干扰=$2 \times1=2$
    - 右: 查看索引2到6 (5,3,9,4,6)
        - $5>2 \to$ 距离=$2-1=1$
        - 干扰=$2 \times1=2$
    - 合计=$2+2=4$
3. 基站2（强度5）
    - 左: 查看索引1到0 (2,7)
        - $2 \le5 \to$ 继续
        - $7>5 \to$ 距离=$2-0=2$
        - 干扰=$5 \times2=10$
    - 右: 查看索引3到7 (3,9,4,6,1)
        - $3 \le5 \to$ 继续
        - $9>5 \to$ 距离=$4-2=2$
        - 干扰=$5 \times2=10$
    - 合计=$10+10=20$

结果汇总:
基站0:28
基站1:4
基站2:20
基站3:6
基站4:0
基站5:8
基站6:24
基站7:2
基站8:32
基站9:3
总和 = $28 + 4 + 20 + 6 + 0 + 8 + 24 + 2 + 32 + 3 = 127$ 然后对$10^9 + 7$取模 = $127$

## 样例2



**输入** 



```
3 1 4 2 5
3
```



**输出** 



```
20
```



**说明**

1. 基站0（强度3）
    - 左: 无基站 → 干扰=0
    - 右: 查看1,4,2 (最多3个)
        - $1 \le3 \to$ 继续
        - $4>3 \to$ 距离=$2$
        - 干扰=$3 \times2=6$
    - 合计=$0+6=6$
2. 基站1（强度1）
    - 左: 查看3
        - $3>1 \to$ 距离=$1$
        - 干扰=$1 \times1=1$
    - 右: 查看4,2,5 (最多3个)
        - $4>1 \to$ 距离=$1$
        - 干扰=$1 \times1=1$
    - 合计=$1+1=2$
3. 基站2（强度4）
    - 左: 查看1,3
        - 都$\le4 \to$ 干扰=0
    - 右: 查看2,5 (不足3个)
        - $2 \le4 \to$ 继续
        - $5>4 \to$ 距离=$2$
        - 干扰=$4 \times2=8$
    - 合计=$0+8=8$
4. 基站3（强度2）
    - 左: 查看4,1,3 (最多3个)
        - $4>2 \to$ 距离=$1$
        - 干扰=$2 \times1=2$
    - 右: 查看5
        - $5>2 \to$ 距离=$1$
        - 干扰=$2 \times1=2$
    - 合计=$(2+2=4$
5. 基站4（强度5）
    - 左: 查看2,4,1 (最多3个)
        - 都$\le5 \to$ 干扰=0
    - 右: 无基站 → 干扰=0
    - 合计=$0+0=0$

最终结果
$6$（基站0） + $2$（基站1） + $8$（基站2） + $4$（基站3） + $0$（基站4） = $20$ 然后对$10^9 + 7$取模 = $20$
