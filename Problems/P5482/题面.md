# 选花最大收益

# 题目内容

花店里摆着 $n$ 朵花。第 $i$ 朵花有一个类型 $t_i$ 和一个价值 $v_i$。

你必须恰好从中选出 $k$ 朵花做成一束。设这 $k$ 朵花的价值之和为 $S$，其中出现过的不同的类型个数为 $C$，则这束花的收益定义为

$S + C \times C$

请计算能得到的最大收益。

# 输入描述

第一行两个正整数 $n$ 和 $k$（$1\le k\le n\le 10^{5}$），表示花的数量和必须选中的朵数。

第二行 $n$ 个整数 $t_1,t_2,\dots,t_n$（$1\le t_i\le 10^{9}$），表示每朵花的类型。

第三行 $n$ 个整数 $v_1,v_2,\dots,v_n$（$1\le v_i\le 10^{9}$），表示每朵花的价值。

# 输出描述

输出一个整数，表示最大收益。

## 样例1

**输入**

```
3 2
1 1 2
5 3 4
```

**输出**

```
13
```

**说明**

- 选类型 $1$ 的价值 $5$ 与类型 $2$ 的价值 $4$：价值和 $9$，类型数 $2$，收益 $9+4=13$。
- 选两朵类型 $1$：价值和 $8$，类型数 $1$，收益 $9$。
- 选价值 $3$ 与 $4$：收益 $11$。

最大为 $13$。

## 样例2

**输入**

```
3 2
1 1 2
100 99 1
```

**输出**

```
200
```

**说明**

两朵类型 $1$ 的价值和为 $199$，类型数 $1$，收益 $200$。若改拿类型 $2$ 那朵价值 $1$ 的花，类型数变成 $2$，收益只有 $105$。种类更多不一定更优。
