# 题目内容

一堆有 $n$ 颗石子，两人轮流取，每次必须取走 $1\sim k$ 颗，取走最后一颗的人获胜。双方均以最优策略取子，判断先手获胜还是后手获胜。

## 输入描述

一行两个正整数 $n$ 和 $k$。

## 输出描述

若先手获胜，输出 `YES`；否则输出 `NO`。

## 数据范围

- $1 \le n,k \le 1000$

## 样例1

输入：

```
10 3
```

输出：

```
YES
```

说明：每次最多取 $3$ 颗。先手先取 $2$ 颗，剩下 $8$ 颗；此后无论后手取 $x$ 颗（$1\le x\le 3$），先手都取 $4-x$ 颗，总能取走最后一颗。

## 样例2

输入：

```
4 3
```

输出：

```
NO
```

说明：$4$ 是 $k+1=4$ 的倍数。先手无论取 $1\sim 3$ 颗，后手都能一次取完并获胜。
