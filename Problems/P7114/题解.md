# 取石子博弈

## 解题思路

这是经典的 Bash 博弈（一堆石子、每次取 $1\sim k$ 颗、取完者胜）。

1. 把石子按 $k+1$ 颗分成一轮。若当前剩余恰好是 $k+1$ 的倍数，先手无论取 $x$（$1\le x\le k$）颗，后手都可以取 $k+1-x$ 颗，把局面重新变成倍数。
2. 因此 $n\bmod (k+1)=0$ 时，先手一直面对倍数局面，最后一颗会被后手取走，后手胜。
3. 否则先手第一次取 $n\bmod (k+1)$ 颗，把剩余变成倍数，之后模仿后手，先手胜。
4. 常见假解是写成 $n\bmod k$，或把胜负写反。

## 复杂度分析

时间复杂度为 $O(1)$。

空间复杂度为 $O(1)$。

## 代码实现

### Python

```python
# Bash 博弈：n 能被 k+1 整除则后手胜，否则先手胜


def who_wins(n, k):
    # 每 k+1 颗构成一轮：先手若面对 k+1 的倍数，无论取 1~k 颗，
    # 后手都能取到刚好补成 k+1，把倍数局面丢回给先手
    if n % (k + 1) == 0:
        return "后手"
    return "先手"


def main():
    n, k = map(int, input().split())
    print(who_wins(n, k))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.nio.charset.StandardCharsets;
import java.util.Scanner;

public class Main {
    // Bash 博弈：n 能被 k+1 整除则后手胜，否则先手胜
    static String whoWins(long n, long k) {
        // 每 k+1 颗构成一轮：先手若面对 k+1 的倍数，无论取 1~k 颗，

        sc.close();
    }
}
```
