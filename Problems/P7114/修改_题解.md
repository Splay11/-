# 取石子博弈

## 解题思路

用博弈 DFS 判断必胜必败。设 $dfs(n)$ 表示：还剩 $n$ 颗石子、轮到当前玩家取时，这个人能否必胜（$True$ 赢，$False$ 输）。原问题就是求 $dfs(n)$：它为 $True$ 则输出 $YES$，否则输出 $NO$。双方都按最优策略走。

1. 先手赢，等价于能把后手送进一个必输局面。也就是 $dfs(n-1)$、$dfs(n-2)$、$\ldots$、$dfs(n-k)$ 里，只要有一个是 $False$（取走对应颗数后剩余不能为负），当前玩家就能赢。
2. 边界：$dfs(0)=False$，已经没有石子，当前玩家无法行动，算输。
3. 枚举取走 $i=1\sim \min(k,n)$ 颗，用 $ok$ 收集「是否存在一种取法让对方必输」：$ok = ok\ \mathrm{or}\ \mathrm{not}\ dfs(n-i)$。
4. 用字典 $d$ 记下每个 $n$ 算过的结果，避免同一局面重复搜索。

## 复杂度分析

加上记忆化后，每个剩余颗数最多算一次，时间复杂度为 $O(nk)$。

空间复杂度为 $O(n)$，用于字典和递归栈。

## 代码实现

### Python

```python
def main():
    n, k = map(int, input().split())
    d = {}

    # dfs(n)=True 表示还剩 n 颗时，当前玩家必胜
    def dfs(n):
        if n == 0:
            return False
        # 算过就直接用，避免重复递归
        if n in d:
            return d[n]
        ok = False
        # 枚举拿走 1~k 颗（不能超过剩下的）
        for i in range(1, min(k, n) + 1):
            # 只要有一种取法让对方必输，自己就赢
            ok = ok or (not dfs(n - i))
        d[n] = ok
        return ok

    print("YES" if dfs(n) else "NO")


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.HashMap;
import java.util.Scanner;

public class Main {
    static int k;
    static HashMap<Integer, Boolean> d = new HashMap<Integer, Boolean>();

    // dfs(n)=True 表示还剩 n 颗时，当前玩家必胜
    static boolean dfs(int n) {
        if (n == 0) {
            return false;
        }
        // 算过就直接用，避免重复递归
        if (d.containsKey(n)) {
            return d.get(n);
        }
        boolean ok = false;
        int up = Math.min(k, n);
        // 枚举拿走 1~k 颗（不能超过剩下的）
        for (int i = 1; i <= up; i++) {
            // 只要有一种取法让对方必输，自己就赢
            ok = ok || !dfs(n - i);
        }
        d.put(n, ok);
        return ok;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        k = sc.nextInt();
        System.out.println(dfs(n) ? "YES" : "NO");
        sc.close();
    }
}
```

```cpp
    return ok;
}
```

### C

```c
#include <stdio.h>

int k;

/* 这里不用字典，逻辑与上面相同：dfs(n)=1 表示当前玩家必胜 */
int dfs(int n) {
    int i, up, ok;
    if (n == 0) {
        return 0;
    }
    ok = 0;
    up = k < n ? k : n;
    /* 枚举拿走 1~k 颗（不能超过剩下的） */
    for (i = 1; i <= up; i++) {
        /* 只要有一种取法让对方必输，自己就赢；|| 短路后不再搜后面 */
        ok = ok || !dfs(n - i);
    }
    return ok;
}

int main(void) {
    int n;
    scanf("%d %d", &n, &k);
    printf("%s\n", dfs(n) ? "YES" : "NO");
    return 0;
}
```
