# 温感窗口平方和

## 解题思路

统计满足「窗口和 $=\ell^2$」的连续子段个数，其中 $\ell$ 为窗口长度。

关键观察：由 $|v_i|\le 100$ 可知任意长度为 $\ell$ 的子段和绝对值不超过 $100\ell$。若要等于 $\ell^2$，必须 $\ell^2\le 100\ell$，即 $\ell\le 100$。因此合法窗口长度至多为 $100$，不必枚举更长区间。

做法：对每个左端点 $L$，向右最多扫描 $100$ 个位置，维护前缀和并检查是否等于 $\ell^2$。多询问下 $\sum n\le 2\cdot 10^5$，总复杂度可接受。

## 复杂度分析

- 时间复杂度：$O(100\cdot\sum n)=O(\sum n)$。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
import sys


def solve(v):
    n = len(v)
    ans = 0
    # |v_i|<=100 且和=ell^2 ⇒ ell<=100，左端点确定后最多看 100 格
    for L in range(n):
        s = 0
        lim = n if n < L + 100 else L + 100
        for R in range(L, lim):
            s += v[R]
            ell = R - L + 1
            if s == ell * ell:
                ans += 1
    return ans


data = list(map(int, sys.stdin.buffer.read().split()))
it = iter(data)
q = next(it)
out = []
for _ in range(q):
    n = next(it)
    v = [next(it) for _ in range(n)]
    out.append(str(solve(v)))
sys.stdout.write("\n".join(out) + "\n")
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    static long solve(int[] v) {
        int n = v.length;
        long ans = 0;
        for (int L = 0; L < n; L++) {
            long s = 0;
            int lim = Math.min(n, L + 100);
            for (int R = L; R < lim; R++) {
                s += v[R];
                int ell = R - L + 1;
                if (s == 1L * ell * ell) ans++;
            }
        }
        return ans;
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int q = Integer.parseInt(br.readLine().trim());
        StringBuilder sb = new StringBuilder();
        while (q-- > 0) {
            int n = Integer.parseInt(br.readLine().trim());
            StringTokenizer st = new StringTokenizer(br.readLine());
            int[] v = new int[n];
            for (int i = 0; i < n; i++) v[i] = Integer.parseInt(st.nextToken());
            sb.append(solve(v)).append('\n');
        }
        System.out.print(sb);
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

long long solve(const vector<int>& v) {
    int n = (int)v.size();
    long long ans = 0;
    for (int L = 0; L < n; L++) {
        long long s = 0;
        int lim = min(n, L + 100);
        for (int R = L; R < lim; R++) {
            s += v[R];
            int ell = R - L + 1;
            if (s == 1LL * ell * ell) ans++;
        }
    }
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q;
    cin >> q;
    while (q--) {
        int n;
        cin >> n;
        vector<int> v(n);
        for (int i = 0; i < n; i++) cin >> v[i];
        cout << solve(v) << '\n';
    }
    return 0;
}
```
