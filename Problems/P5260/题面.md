# 题目内容

给定一个长度为 $n$ 的整数数组 $a$。定义任意非空子数组 $([l,r])$ 的长度为 $L = r-l+1$，其元素和为 $\sum_{i=l}^{r} a_i$。请统计满足 $\sum_{i=l}^{r} a_i = L^2$ 的子数组个数。

子数组为从原数组中，连续的选择一段元素（可以全选）得到的新数组。




# 输入描述

每个测试文件均包含多组测试数据。第一行输入一个整数 $T(1 \le T \le 10^5)$ 表示测试组数。每组测试数据描述如下：

第一行输入一个整数 $n(1 \le n \le 10^5)$。

第二行输入 $n$ 个整数 $a_1,a_2,\dots,a_n(|a_i| \le 100)$。

保证所有测试数据的 $n$ 之和不超过 $2 \times 10^5$。



# 输出描述


对于每组测试数据，输出一个整数，表示满足 $\sum_{i=l}^{r} a_i = L^2$ 的子数组个数。


## 样例1 



**输入** 



```
1
5
1 4 0 3 1
```



**输出** 



```
4
```



**说明**

长度为 $1$ 时要求元素等于 $1$，下标 $1$ 与下标 $5$ 的元素均为 $1$，贡献 $2$ 个。长度为 $2$ 时要求两元素之和为 $4$，子数组 $([2,3])$ 的和为 $4$、子数组 $([4,5])$ 的和为 $4$，再贡献 $2$ 个。长度 $(3,4,5)$ 分别要求和为 $(9,16,25)$，实际最大的一段和只有 $9$ 以下，均不满足。合计 $4$ 个。


## 样例2



**输入** 



```
2
3
-1 2 3
4
1 2 2 4
```



**输出** 



```
0
2
```



**说明**

第一组中，长度 $1$ 要求元素为 $1$，三个元素分别是 $-1,2,3$ 都不满足；长度 $2$ 要求和为 $4$，两段和分别是 $(1,5)$；长度 $3$ 要求和为 $9$，整段和只有 $4$。因此答案为 $0$。

第二组中，下标 $1$ 的元素为 $1$ 满足长度 $1$ 的要求；子数组 $([2,3])$ 的和为 $4$ 满足长度 $2$ 的要求。其余情况都不成立，因此答案为 $2$。
