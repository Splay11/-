# 题目内容


有一天，AK机想到了一个等式：
$x \oplus (x + 1) \oplus (x + 2) \cdots \oplus y = z$

其中 $\oplus$ 表示按位异或操作。

AK机想知道，对于一组 $x,z$，最小的能使等式成立且满足 $x \le y$ 的 $y$ 是多少。


# 输入描述



输入两个整数 $x,z$($0 \le x < 2^{20},0 \le z < 2^{20}$)。

# 输出描述

如果不存在对应的 $y$，直接输出 $-1$；否则，输出一个非负整数表示最小的能使等式成立的 $y$。




## 样例1 



**输入** 



```
1 4
```



**输出** 



```
4
```



**说明**

$1 \oplus 2 \oplus 3 \oplus 4 = 4$，而 $y = 1,2,3$ 时的异或结果分别为 $1,3,0$，都不等于 $4$，所以最小的 $y$ 为 $4$。
