# 异或区间右端

一句话总结：区间异或等于两端前缀异或的差，转化为找最小 $q\ge p$ 使 $0..q$ 的前缀异或等于目标值。

算法标签：位运算、前缀异或

算法难度：$4 / 10$

## 解题思路

要求 $p \oplus (p+1) \oplus \cdots \oplus q = w$ 且 $q$ 最小、$q\ge p$。直接从 $p$ 往后扫最多约 $10^6$ 步也能过，但用前缀异或可以 $O(1)$ 判定。

1. 记 $xor\_pref(n)=0\oplus 1\oplus \cdots \oplus n$，空前缀 $xor\_pref(-1)=0$。则区间异或就是 $xor\_pref(q)\oplus xor\_pref(p-1)$。
2. $0$ 到 $n$ 的连续异或每 $4$ 个数一循环：若 $n\bmod 4=0$ 结果是 $n$；等于 $1$ 结果是 $1$；等于 $2$ 结果是 $n+1$；等于 $3$ 结果是 $0$。
3. 令 $need=w\oplus xor\_pref(p-1)$，问题变成：最小的 $q\ge p$ 满足 $xor\_pref(q)=need$。
4. 前缀异或只能取到四类值：$0$、$1$、模 $4$ 余 $0$ 的数、模 $4$ 余 $3$ 的数。因此：
   - $need=0$：取 $q=0$（仅当 $p=0$）或最小的 $q\ge p$ 且 $q\bmod 4=3$；
   - $need=1$：取最小的 $q\ge p$ 且 $q\bmod 4=1$；
   - $need\bmod 4=0$ 且 $need\ne 0$：只能 $q=need$，再检查 $q\ge p$；
   - $need\bmod 4=3$：只能 $q=need-1$，再检查 $q\ge p$；
   - 其余情况无解，输出 $-1$。
5. 常见假解：认为一定存在、把 $y$ 上界误当成 $2^{20}-1$ 就提前停、模 $4$ 分类漏掉 $need=0$ 与 $need=1$ 的无穷多解、输出任意合法 $q$ 而不是最小。

## 复杂度分析

- 时间复杂度：$O(1)$。只做几次取模和异或。
- 空间复杂度：$O(1)$。

$p,w< 1048576$，即使改成从 $p$ 扫到 $p+4$ 或扫到 $need$ 也足够。评测时限 $3$ 秒、内存 $512$ MB。

## 代码实现

### Python

```python
def xor_pref(n):
    # 0 到 n 的连续异或。n<0 时为空区间，返回 0
    if n < 0:
        return 0
    # 连续整数异或每 4 个一循环：n, 1, n+1, 0
    r = n % 4
    if r == 0:
        return n
    if r == 1:
        return 1
    if r == 2:
        return n + 1
    return 0


def min_right(p, w):
    # 找最小 q>=p 使得 p⊕...⊕q = w；不存在返回 -1
    need = w ^ xor_pref(p - 1)
    # 前缀异或只能取到：0、1、模 4 余 0 的数、模 4 余 3 的数
    if need == 0:
        if p == 0:
            return 0
        return p + (3 - p % 4) % 4
    if need == 1:
        return p + (1 - p % 4) % 4
    if need % 4 == 0:
        return need if need >= p else -1
    if need % 4 == 3:
        q = need - 1
        return q if q >= p else -1
    return -1


def main():
    # 四级协议：第一行校验字 w，第二行左端点 p
    w = int(input())
    p = int(input())
    print(min_right(p, w))


if __name__ == "__main__":
    main()
```
