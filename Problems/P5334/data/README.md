# P5334 测试数据说明

题意：三角分层图上求从指定点出发的无向欧拉回路。多询问，所有 $h$ 之和 $\le 1000$。答案不唯一，`.out` 为标程给出的一条合法回路。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---:|---|---|---|
| 1 | 样例1：$h=2,s=3$ | 展示最小三角形 | 输出长度不是 $4$、不过起点 |
| 2 | 样例2：$h=3,s=4$ | 展示底层角点出发 | 漏画向下三角的边 |
| 3 | 样例3：两组 $h=2,4$ | 多询问格式 | 只处理第一组 |
| 4 | 三个 $h=2$，起点 $1,2,3$ | 最小图全部角点 | 固定从编号 $1$ 开始却不旋转到 $s$ |
| 5 | $h=5$ 顶/底左/底右/内部 | 边界起点 | $0$ 下标、最后一个点越界 |
| 6 | $h=3,4,6,7$ 构造 | 建图递推 | 编号公式写成 $r(r+1)/2$ |
| 7 | 随机小层数 | 暴力对拍 | 边重复走、漏边 |
| 8 | $44$ 组 $h=2$ + $h=6,8,9$ | hack 多询问与错误剖分 | 只建竖边、忽略 $k$、假三角 |
| 9 | $h=200,200,250,350$ | 中等压力 | $O(h^3)$ 或递归爆栈 |
| 10 | $h=1000$，起点为末台位 | 上限 | 邻接表不标删除导致 TLE/重边 |
