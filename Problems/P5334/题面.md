# 题目内容

小美有一个三角形图，这个图总共有 $n$ 层，第 $i$ 层有 $i$ 个节点，第 $i$ 层节点编号为 $i \times (i-1)/2+1,\ 2,\dots,\ i\times(i-1)/2+i$。

对于所有的 $2 \le i \le n$，第 $i$ 层中对于所有 $1 \le j < i$，节点 $i \times (i-1)/2+j$ 与节点 $i\times(i-1)/2+j+1$ 之间存在一条无向边，节点 $i \times (i-1)/2+j$ 与节点 $(i-1)\times(i-2)/2+j$ 之间存在一条无向边，节点 $i \times (i-1)/2+j+1$ 与节点 $(i-1)\times(i-2)/2+j$ 之间存在一条无向边。

小美想知道初始在节点 $m$ 如何移动才能将所有边恰好遍历一遍并返回节点 $m$。可以证明在题目限制内总存在解。



# 输入描述


每个测试文件均包含多组测试数据。第一行输入一个整数 $T(1 \le T \le 50)$ 代表数据组数；随后，每组测试数据：
- 在一行上输入两个整数 $n,m(2 \le n \le 1000;\ 1 \le m \le n\times(n+1)/2)$，分别表示层数以及TK初始所在的节点；

此外，保证单个测试文件的 $n$ 之和不超过 $1000$。



# 输出描述

对于每一组测试数据，新起一行，输出 $3\times n\times(n-1)/2+1$ 个整数，表示路径经过的节点；

如果存在多个解决方案，您可以输出任意一个，系统会自动判定是否正确。注意，自测运行功能可能因此返回错误结果，请自行检查答案正确性。



## 样例1 



**输入** 



```
2
2 1
3 6
```



**输出** 



```
1 2 3 1
6 3 1 2 4 5 3 2 5 6
```
