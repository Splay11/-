# 数据包多通道传输

在通信系统中，有一组数据包需要按顺序通过 $k$ 个通道传输。每个数据包 $i$ 的传输耗时为 $nums[i]$（单位：毫秒）。

## 传输规则

- 同一通道内的数据包必须按顺序连续传输：若数据包 $[i,\ i+1,\ \ldots,\ j]$ 分配给同一通道，则该通道的传输总延迟为 $nums[i] + nums[i+1] + \cdots + nums[j]$。
- 不同通道之间可以并行传输，系统整体延迟取决于**延迟最大的那个通道**。
- 数据包只能被拆分为**连续子段**（例如 $[1,2,3]$ 可拆为 $[1,2]$ 与 $[3]$，不可拆为 $[1,3]$ 与 $[2]$）。
- 必须划分为恰好 $k$ 个**非空**连续通道，覆盖全部数据包。

你的任务是：将 $nums$ 划分到 $k$ 个连续非空通道，使得系统总耗时（各通道延迟的最大值）最小。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def minimumLatency(self, nums: List[int], k: int) -> int` |
| Java | `public int minimumLatency(int[] nums, int k)` |
| C++ | `int minimumLatency(vector<int>& nums, int k)` |

**参数**

- `nums`：非负整数数组，$1 \le |nums| \le 1000$，每个元素 $0 \le nums[i] \le 10^6$；
- `k`：通道数量，$1 \le k \le |nums|$。

**返回值**

符合题意的最优传输策略下的总耗时（整数）。

## 输入输出格式（stdin / stdout）

**输入**（stdin **一行**：先 `nums` 整数数组，逗号后为 `k`；方括号内元素逗号后可有空格，与样例一致）：

```text
[7, 2, 5, 10, 8],2
```

**输出**（stdout **一行**整数）：

```text
18
```

## 数据范围

- $1 \le n = |nums| \le 1000$；
- $0 \le nums[i] \le 10^6$；
- $1 \le k \le n$。

## 样例

### 样例 1

**输入**

```text
[7, 2, 5, 10, 8],2
```

**输出**

```text
18
```

**说明**

划分为 $[7,2,5]$ 与 $[10,8]$，两通道延迟分别为 $14$ 与 $18$，系统总耗时 $18$ 最优。

### 样例 2

**输入**

```text
[1, 2, 3, 4, 5],2
```

**输出**

```text
9
```

**说明**

最优划分为 $[1,2,3]$ 与 $[4,5]$，系统总耗时 $9$。

### 样例 3

**输入**

```text
[1, 4, 4],3
```

**输出**

```text
4
```

**说明**

划分为 $[1]$、$[4]$、$[4]$，系统总耗时 $4$。
