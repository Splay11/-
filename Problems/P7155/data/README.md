# P7155 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：第一行 $n$ $target$，第二行 $n$ 个互不相同的正整数。
输出：有序方案数（可重复使用；顺序不同算不同）。

约束：$1\le n\le 200$，$1\le nums_i,target\le 1000$，答案在 $32$ 位有符号整数内。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1，顺序不同要分开计 | $7$ | 组合背包得到 $4$ |
| 2 | 样例 2，凑不出 | $0$ | 输出 $1$ |
| 3 | 单个数正好等于目标 | $1$ | 输出 $0$ |
| 4 | 重复使用同一个数 | $2+2$ 只有一种顺序，答案 $1$ | 当成不能重复得到 $0$ |
| 5 | $1+1+1$、$1+2$、$2+1$ | $3$ | 漏掉 $2,1$ |
| 6 | 两个不同数的两种顺序 | $3+4$ 与 $4+3$，答案 $2$ | 只计一种 |
| 7 | 所有数都比目标大 | $0$ | 输出负数 |
| 8 | 小随机、不含 $1$ | DP 与记忆化搜索对拍 | 0-1 背包每个数只用一次 |
| 9 | 压满 $n=200$，数值 $\ge 400$，$target=1000$ | 至多选两个数 | 含 $1$ 时斐波那契式爆 int |
| 10 | 压满 $n=200$，数值 $\ge 250$，$target=1000$ | $O(n\cdot target)$ | 指数枚举排列 TLE |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：完全背包 DP 必须等于记忆化搜索，且答案 $\le 2^{31}-1$。
