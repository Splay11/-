# 二分类 AUC

## 解题思路

本题要求根据真实标签与预测概率计算二分类 $\mathrm{AUC}$，对应 `Solution.binaryAUC(y, pred)`。

1. $\mathrm{AUC}$ 的含义：随机抽一个正样本和一个负样本，正样本预测概率大于负样本的概率；预测相等时计 $0.5$。
2. 将样本按标签拆成正、负两组预测概率。
3. 枚举所有正负样本对，累加「大于」与「相等」贡献，再除以正负样本数之积。
4. $n \le 10^{4}$ 时双重循环即可。

## 复杂度分析

时间复杂度为 $O(n_{+}\cdot n_{-})$，最坏 $O(n^{2})$。

空间复杂度为 $O(n)$。

## 代码实现

### Python

```python
class Solution:
    def binaryAUC(self, y, pred):
        """根据标签与预测概率计算二分类 AUC。"""
        pos = []
        neg = []
        # 按标签拆成正负样本的预测概率
        for yi, pi in zip(y, pred):
            if yi == 1:
                pos.append(pi)
            else:
                neg.append(pi)
        # AUC = 正样本分数大于负样本的概率；相等计 0.5
        total = len(pos) * len(neg)
        good = 0.0
        for p in pos:
            for q in neg:
                if p > q:
                    good += 1.0
                elif p == q:
                    good += 0.5
        return good / total
```
