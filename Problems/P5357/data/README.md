# P5357 测试数据说明

共 $10$ 组。一行封口串（可为空文件）。输出 `true` 或 `false`。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 `[()]{}` | 嵌套+并列 | 只认一种括号 |
| 2 | 样例2 `([)]` | 交叉非法 | 只数个数 |
| 3 | 空串 | 合法 | 空串输出 `false` |
| 4 | `()` | 最小正例 | 读写出错 |
| 5 | `{{[]}}` | 深嵌套 | 栈没用对 |
| 6 | `())` | 多余闭口 | 弹栈不判空 |
| 7 | 三个开圆口 | 未闭合 | 扫完不看栈 |
| 8 | 混合合法 | 多段并列 | 映射写错 |
| 9 | $5\times 10^4$ 层圆口 | 压测 | $O(n^2)$ / 递归爆栈 |
| 10 | $10^5$ 个开封口 | 计数相等不够 | 只比数量 |

前 $8$ 组小；后 $2$ 组压测。
