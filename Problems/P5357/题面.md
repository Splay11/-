

**16、给定一个字符串$s$，仅包含字符`(`、`)`、`[`、`]`、`{`、`}`中的若干种（可能为$0$个），判断该字符串是否为有效的括号表达式。**

有效括号表达式的定义：
括号必须成对匹配（如`()`、`[]`、`{}`是合法的）；
括号可以嵌套（如`([])`、`{{[]}}`是合法的）；
括号不能交叉（如`([)]`是非法的）；
空字符串（长度为$0$）视为合法。

样例输入：`()[]{}`
样例输出：`true`

```

2     import sys
3 
4 if __name__ == "__main__":
5     main()
```
