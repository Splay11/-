# 能量管理系统净能量查询

设计一个能量管理系统，用于管理多种能源的生产与消耗。系统按顺序接收若干条操作命令；每条**生产/消耗**命令对应一个版本号（第 $1$ 条为版本 $1$，依次递增）。最后一条命令为查询，返回指定版本范围内、指定时间段内的**净能量**（生产加权量减去消耗加权量）。

## 命令格式

输入为字符串数组 `commands`，长度不超过 $1000$，**最后一条**为查询命令，其余为生产或消耗记录。各字段以英文逗号 `,` 分隔；能量类型字段不做校验。

1. **生产记录**（可有多条）：以 `AddProductionRecord` 开头，共 $4$ 个参数  
   `AddProductionRecord,<能量类型>,<生产量>,<起始时间>,<终止时间>`  
   能量类型为 `wind` / `solar` / `grid` 之一（仅记录，不参与计算）。

2. **消耗记录**（可有多条）：以 `AddConsumptionRecord` 开头，共 $3$ 个参数  
   `AddConsumptionRecord,<消耗量>,<起始时间>,<终止时间>`

3. **查询命令**（仅一条，且为最后一条）：以 `QueryNetEnergy` 开头，共 $3$ 个参数  
   `QueryNetEnergy,<版本号>,<查询起始时间>,<查询终止时间>`  
   - 版本号：$32$ 位非负整数，表示只统计**版本号 $\le$ 该值**的生产/消耗记录；若为字符 `A`，表示统计**全部**生产/消耗记录（全量查询）。  
   - 查询时间段为**闭区间** $[\text{查询起始},\ \text{查询终止}]$（两端时间点均计入）。

所有时间戳为 Unix 秒级时间戳；生产量、消耗量均为 $32$ 位有符号整型。

## 加权规则

对每条纳入统计的生产/消耗记录，设其时段为 $[s,\ e]$（$e \ge s$），查询时段为 $[qs,\ qe]$：

- 若无时间交集，该条贡献为 $0$；
- 否则令交集为 $[\max(s, qs),\ \min(e, qe)]$，记录总时长 $T = e - s$，交集时长 $L = \min(e, qe) - \max(s, qs)$；
- 该条有效量为 $\text{amount} \times L / T$（生产计入加项，消耗计入减项）。

净能量 $=$ 所有生产有效量之和 $-$ 所有消耗有效量之和，结果**四舍五入**为 $32$ 位整数，取值范围 $[-2^{31},\ 2^{31}-1]$。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def queryNetEnergy(self, commands: List[str]) -> int` |
| Java | `public int queryNetEnergy(String[] commands)` |
| C++ | `int queryNetEnergy(vector<string>& commands)` |

**参数**

- `commands`：命令字符串数组，$1 \le |commands| \le 1000$；最后一条为 `QueryNetEnergy`，其余为 `AddProductionRecord` 或 `AddConsumptionRecord`。

**返回值**

查询得到的净能量（四舍五入后的 $32$ 位整数）。

## 输入输出格式（stdin / stdout）

**输入**（stdin **一行**：Python 列表字面量，元素为双引号字符串，与样例一致）：

```text
["AddProductionRecord,wind,500,1640000000,1640001000","AddConsumptionRecord,100,1640000000,1640000600","AddConsumptionRecord,200,1640000251,1640001251","QueryNetEnergy,3,1640000000,1640001000"]
```

**输出**（stdout **一行**整数）：

```text
250
```

## 数据范围

- $1 \le |commands| \le 1000$；
- 生产/消耗量、时间戳均在 $32$ 位有符号整型范围内；
- 输入保证合法（最后一条为查询，其余为添加记录）。

## 样例

### 样例 1

**输入**

```text
["AddProductionRecord,wind,500,1640000000,1640001000","AddConsumptionRecord,100,1640000000,1640000600","AddConsumptionRecord,200,1640000251,1640001251","QueryNetEnergy,3,1640000000,1640001000"]
```

**输出**

```text
250
```

**说明**

版本 $1$：生产 $500$，时段 $[1640000000, 1640001000]$，完全落在查询区间内，贡献 $500$。  
版本 $2$：消耗 $100$，完全落在查询区间内，贡献 $100$。  
版本 $3$：消耗 $200$，与查询区间部分重叠，有效量 $200 \times \dfrac{1640001000-1640000251}{1640001251-1640000251} = 149.8$。  
净能量 $500 - 100 - 149.8 = 250.2$，四舍五入为 $250$。

### 样例 2

**输入**

```text
["AddProductionRecord,wind,1000,1640000000,1640000500","QueryNetEnergy,1,1640001000,1640002000"]
```

**输出**

```text
0
```

**说明**

版本 $1$ 的生产时段与查询区间 $[1640001000, 1640002000]$ 无交集，净能量为 $0$。

### 样例 3

**输入**

```text
["AddProductionRecord,solar,300,1640000000,1640002000","AddConsumptionRecord,150,1640001000,1640003000","QueryNetEnergy,A,1640000000,1640002000"]
```

**输出**

```text
225
```

**说明**

全量查询（版本 `A`）。生产 $300$ 完全计入；消耗 $150$ 与查询区间重叠一半（时长 $2000$ 中重叠 $1000$），有效量 $75$。净能量 $300 - 75 = 225$。
