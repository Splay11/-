# 题目内容

夜间公共服务站的工作人员小月需要对当天的设备运转记录进行核验。每条记录包含一系列按模 $M$ 计的读数，表示设备在各个时间点的工作状态值。

小月的核验任务是观察这些读数的前向变化量：对于相邻的两个读数，第 $(i+1)$ 个相对于第 $i$ 个的变化量为 $(a_{(i+1)}-a_i)\bmod M$。如果一段连续的记录中，所有相邻读数的变化量都相同，小月就将其标记为一个“平稳变化段”。

请帮助小月找出最长的平稳变化段。如果存在多个长度并列的最长段，选取最靠左（起始位置最早）的那一段。



# 输入描述


第一行输入两个整数 $n$（$1 \le n \le 2 \times 10^5$）和 $M$（$2 \le M \le 10^9$）。

第二行输入 $n$ 个读数 $a_i$（$0 \le a_i < M$）。


# 输出描述



输出最长平稳变化段的长度、左端点位置（从 $1$ 开始计）以及该段的公共变化量。


## 样例1 



**输入** 



```
8 12
1 4 7 10 1 4 8 0
```



**输出** 



```
6 1 3
```
