# P5279 测例说明

单组。输出「长度 左端点 公共变化量」。

| 组 | 规模 | 目标 | 卡掉的错误解 |
|---:|---|---|---|
| 1 | 改写样例1 | 并列取左 | 取右边那段 |
| 2 | 单点 | 1 1 0 | 没处理 n=1 |
| 3 | 改写样例3 | 从段交界接着扫 | 跳过交界点 |
| 4 | 全相同 | d=0 整段 | 认为长度是差的个数 |
| 5 | 递减取模 | 负差 | C++ 负余数 |
| 6 | 两段等长 | 取左 | 用 >= 更新 |
| 7 | 绕模长段 | 差要 mod | 直接相减 |
| 8 | 小随机 | 一般 | 下标从 0 输出 |
| 9 | n=2e5 一整段 | 满约束 | 超时 |
| 10 | n=2e5 短段多 | 线性扫描 | O(n^2) |
