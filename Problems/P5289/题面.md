# 题目内容

文远组织了一批想来文远的应届生们来文远参观感受。 这次参观之旅共有n个地点，标号为1~n。其中广州科盛办公室标号为1，从广州科盛办公室出发。这次参观之旅结束后，无需回到广州科盛办公室。 现在想知道所需最短路程是多少？

# 输入描述

第一行包含一个整数 $n\ (1<=n<=10^5)$。

 接下来$n-1$行，每行包含三个整数 $x,y,w\ (1<= x,y <= n, 0<= w <= 10^9)$，表示参观之旅的$x$号点和$y$号点之间存在班车接送，路程为$w$。

 输入保证任意两个点都可以互相到达。

# 输出描述

包含一个整数，表示最短路程。



## 样例1 

**输入** 

```
3
1 2 3
2 3 4
```

**输出** 

```
7
```



## 样例2 

**输入** 

```
5
5 3 60
4 3 63
2 1 97
3 1 14
```

**输出** 

```
371
```



## 样例3 

**输入** 

```
13
8 2 58
2 1 49
13 10 41
11 9 67
6 4 18
7 1 79
3 2 58
9 7 92
10 6 62
4 3 5
12 4 87
5 3 66
```

**输出** 

```
1126
```
