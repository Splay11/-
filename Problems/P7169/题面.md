# 题目内容

给定一个非负整数 $n$，请计算所有严格小于 $n$ 的质数数量。

质数是指大于 $1$，并且除了 $1$ 和它本身之外不能被其他正整数整除的整数。

例如，小于 $10$ 的质数有 $2$、$3$、$5$ 和 $7$，因此共有 $4$ 个。

# 输入描述

输入一个非负整数 $n$。

### 约束

$0 \le n \le 5 \times 10^6$

# 输出描述

输出一个整数，表示所有严格小于 $n$ 的质数数量。

## 样例1

**输入**

```text
10
```

**输出**

```text
4
```

**说明**

小于 $10$ 的质数为 $2$、$3$、$5$ 和 $7$。

因此共有 $4$ 个质数。

## 样例2

**输入**

```text
0
```

**输出**

```text
0
```

**说明**

不存在小于 $0$ 的质数，因此输出 $0$。

## 样例3

**输入**

```text
1
```

**输出**

```text
0
```

**说明**

质数必须大于 $1$，因此不存在小于 $1$ 的质数，输出 $0$。
