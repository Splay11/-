# P7169 测试数据说明

主造数脚本：题目根目录 `gen.py`。约束 $0\le n\le 5\times 10^6$，统计严格小于 $n$ 的质数。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1，2 3 5 7 | 4 | 把 1 算进去 |
| 2 | 样例 2 | 0 | 输出负数 |
| 3 | 样例 3 | 0 | 把 1 当质数 |
| 4 | 没有小于 2 的质数 | 0 | 输出 1 |
| 5 | 只有 2 | 1 | 把 3 也算上 |
| 6 | 2 和 3 | 2 | 统计 <=n |
| 7 | 中等 | 25 | 试除后面 TLE |
| 8 | 质数本身，答案不含它 | 筛法 | 统计成 pi(n) 而不是 pi(n-1) 附近 |
| 9 | 压满 n=5e6 | 埃氏筛 | O(n sqrt n) TLE |
| 10 | 压满附近 | 筛法 | 数组开成 n+1 把 n 算进去 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。
