# 计数质数

算法标签：数学、筛法

算法难度：$4 / 10$

## 解题思路

求严格小于 $n$ 的质数个数。$n$ 最大 $5\times 10^6$，需要线性筛或埃氏筛，不能对每个数做试除。

1. $n\le 2$ 时答案是 $0$（没有小于 $2$ 的质数）。
2. 开长度为 $n$ 的布尔数组，下标 $0..n-1$ 表示小于 $n$ 的整数。先把 $0$、$1$ 标成合数。
3. 从 $2$ 扫到 $\sqrt{n}$，若 $i$ 还是质数，就把 $i^2,i^2+i,\ldots$ 标成合数。
4. 统计 $2$ 到 $n-1$ 里还是质数的个数。注意是小于 $n$，不要把 $n$ 自己算进去。
5. 常见假解：试除 $O(n\sqrt{n})$ 在 $n=5\times 10^6$ 超时；统计的是 $\le n$；把 $1$ 当质数。

## 复杂度分析

- 时间复杂度：$O(n\log\log n)$。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
def solve(n):
    """埃氏筛：标记所有小于 n 的合数，剩下的就是质数。
    题目要的是严格小于 n 的质数个数，所以筛到 n-1。
    """
    if n <= 2:
        return 0
    is_prime = [True] * n
    is_prime[0] = False
    is_prime[1] = False
    i = 2
    while i * i < n:
        if is_prime[i]:
            j = i * i
            while j < n:
                is_prime[j] = False
                j += i
        i += 1
    ans = 0
    for i in range(2, n):
        if is_prime[i]:
            ans += 1
    return ans


def main():
    n = int(input())
    print(solve(n))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class Main {
    static int solve(int n) {
        if (n <= 2) return 0;
        boolean[] isPrime = new boolean[n];
        for (int i = 2; i < n; i++) isPrime[i] = true;
        for (int i = 2; (long) i * i < n; i++) {
            if (isPrime[i]) {
                for (int j = i * i; j < n; j += i) isPrime[j] = false;
            }
        }
        int ans = 0;
        for (int i = 2; i < n; i++) if (isPrime[i]) ans++;
        return ans;
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());
        System.out.println(solve(n));
    }
}
```

```cpp
#include <iostream>
#include <vector>
using namespace std;

int solve(int n) {
    if (n <= 2) return 0;
    vector<char> is_prime(n, 1);
    is_prime[0] = is_prime[1] = 0;
    for (int i = 2; 1LL * i * i < n; i++) {
        if (is_prime[i]) {
            for (int j = i * i; j < n; j += i) is_prime[j] = 0;
        }
    }
    int ans = 0;
    for (int i = 2; i < n; i++) if (is_prime[i]) ans++;
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    cout << solve(n) << '\n';
    return 0;
}
```
