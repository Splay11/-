# P7137 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：第一行 `n k`；第二行 $n$ 个正整数 $a_i$。
输出：能切出至少 $k$ 段时，每段的最大整数长度。

约束：$1\le n\le 10^5$，$1\le k\le 10^9$，$1\le a_i\le 10^9$，$\sum a_i\ge k$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1（原题误写成 $k=11$ 已改正） | 最大长度 $3$ | 按 $k=11$ 会得到 $2$；或长度 $4$ 只切出 $7$ 段仍输出 $4$ |
| 2 | 样例 2 | 最大长度 $7$ | 长度 $8$ 只切出 $4$ 段仍输出 $8$ |
| 3 | 一根绳子切成 $100$ 段 | 答案 $1$ | 输出 $100$ |
| 4 | 只要求 $1$ 段 | 答案就是整根 $100$ | 输出 $1$ |
| 5 | $k$ 等于长度总和 | 只能切长度 $1$ | 输出 $0$ 或平均数 |
| 6 | 三根等长，要 $6$ 段 | $5//2=2$，三根共 $6$ 段，答案 $2$ | 平均一下输出 $2.5$ 取整成 $3$ |
| 7 | 原错误样例：$k=11$ | 长度 $3$ 只够 $10$ 段，答案应为 $2$ | 照着错样例输出 $3$ |
| 8 | 小随机 $n=12$ | 两种二分对拍 | 浮点除法四舍五入 |
| 9 | 压满 $n=10^5$，$a_i=10^9$，$k=10^9$ | 答案 $10^5$ | int 累加溢出；或 $L$ 用 double |
| 10 | 压满 $n=10^5$ 随机长度 | 线性检查 + 二分长度 | 每轮 $O(n)$ 写成 $O(n^2)$ 会 TLE |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：闭区间二分必须等于另一种上整二分。

题面样例 1 原文 $k=11$ 与输出 $3$ 矛盾，已改为 $k=10$；第 $7$ 组保留 $k=11$ 的正确结果 $2$。
