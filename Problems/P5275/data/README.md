# P5275 测例说明

单组，输出对调后的表。

| 组 | 规模 | 目标 | 卡掉的错误解 |
|---:|---|---|---|
| 1 | 改写样例1 | 3×2→2×3 | 原样输出 |
| 2 | 单格 | 不变 | 空行/多空格 |
| 3 | 单列 | 变成一行 | 仍按列输出 |
| 4 | 单行 | 变成一列 | 仍按行输出 |
| 5 | 极值正负 | 符号与 1e9 | int 溢出（若用短整型） |
| 6 | 3×3 单位阵 | 仍对称 | 下标写反 |
| 7 | 小随机 | 一般矩形 | 行列互换写错 |
| 8 | 重复值 | 形状仍对 | 只看数值漏形状 |
| 9 | 1000×1000 | 压测 I/O | 超时、行列搞反 |
| 10 | 1000×1 | 长列变长行 | 输出成 1000 行 |
