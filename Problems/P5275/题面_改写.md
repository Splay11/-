# 货架层列对调

# 题目内容

仓管员要把一面货架上的货号抄到另一张对照表上。货架一共有 $r$ 层、$c$ 列，第 $i$ 层从左到右第 $j$ 格的货号是 $v_{i,j}$。对照表的规则是：原来第 $i$ 层第 $j$ 格的货号，要写到新表的第 $j$ 行第 $i$ 列。也就是层和列对调，货号本身不变。

请按对照表的格式把全部货号打出来。

# 输入描述

第一行两个正整数 $r$ 和 $c$（$1\le r,c\le 10^3$），表示货架的层数和列数。

接下来 $r$ 行，每行 $c$ 个整数 $v_{i,1},v_{i,2},\ldots,v_{i,c}$（$|v_{i,j}|\le 10^9$），表示第 $i$ 层从左到右的货号。

# 输出描述

输出 $c$ 行，每行 $r$ 个整数，表示对调后的对照表；同一行相邻货号之间用空格隔开。

## 样例1

**输入**

```
3 2
7 8
9 0
1 4
```

**输出**

```
7 9 1
8 0 4
```

**说明**

原来第 `1` 列是 `7`、`9`、`1`，对调后成为新表第 `1` 行；原来第 `2` 列是 `8`、`0`、`4`，成为新表第 `2` 行。

## 样例2

**输入**

```
1 1
5
```

**输出**

```
5
```

**说明**

只有一格，对调后还是这一格。

## 样例3

**输入**

```
2 1
-3
6
```

**输出**

```
-3 6
```

**说明**

原来是一列两层，对调后变成一行两个数。

# 数据范围

- $1\le r,c\le 10^3$
- $|v_{i,j}|\le 10^9$
- 所有输入均为整数
