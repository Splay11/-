# 进制表达式求值与取反

给出一个由字母、数字和加减运算符组成的简单表达式，做如下处理：

1. 对字符串进行解析，获取 $8$ 进制（`0o` 或 `0O` 开头）、$10$ 进制、$16$ 进制（`0x` 或 `0X` 开头）整数和 `+`、`-` 运算符；
2. 对解析结果，按照表达式的顺序从左到右进行运算，得到 $10$ 进制整数结果；
3. 把运算的整数结果调整到 $-255$～$255$ 范围：若值大于 $255$ 则取 $255$，若值小于 $-255$ 则取 $-255$；
4. 对调整后的有符号整数做按位取反，再与 `0xFF` 相与，得到 $0$～$255$ 的无符号字节值；
5. 输出带双引号的字符串：`"0x"` 为前缀、数值部分为大写十六进制、**至少两位**（如 `"0x00"`、`"0xBB"`）；任意环节不合法则返回 `"NA"`。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def processExpression(self, inputStr: str) -> str` |
| Java | `public String processExpression(String inputStr)` |
| C++ | `string processExpression(string inputStr)` |

**语义**：按上节规则处理表达式字符串 `inputStr`，返回带双引号的结果串（如 `"0xBB"`）或 `"NA"`。

## 数据范围与合法性

- $0 \le \texttt{inputStr.length} \le 10000$；
- `inputStr` 仅由字母、数字、`+`、`-` 组成，**不允许空白**及其它字符；
- 解析出的每个整数的 $10$ 进制值须在 $0$～$999$；不支持表达式中出现负数字面（如 `-1+5` 为非法）；
- 进制前缀与数字字母大小写均可；$10$ 进制允许前导零（如 `023` 表示 $23$）；
- 非法情形（含但不限于）：非法字符、长度超限、表达式结构不合法、某整数超 $999$、含空格、含 `=` 等）一律返回 `"NA"`。

## 样例

### 样例 1

**输入**（stdin 为带双引号的 Python 字符串字面量，整行一条）：

```text
"023+0x21+0o13+1"
```

**输出**

```text
"0xBB"
```

**说明**：运算得 $68$，取反后与 `0xFF` 相得 `0xBB`。

### 样例 2

**输入**

```text
"0x0C-0o20+1"
```

**输出**

```text
"0x02"
```

### 样例 3

**输入**

```text
"-1+5"
```

**输出**

```text
"NA"
```

（不支持负数字面）

### 样例 4～8

与平台题面一致：`2324+12-23`→`"NA"`；`"123 + 12-13="`→`"NA"`；`"3A+0xEGW-0o89"`→`"NA"`；`"45-46"`→`"0x00"`；`"30+0xEc+0O12+9"`→`"0x00"`。

## 评测输入输出

- **输入**：一行，为合法 Python 双引号字符串字面量，表示 `inputStr`（支持 `\"` 等转义）。
- **输出**：一行，为 `processExpression` 的返回值（带双引号的 `"NA"` 或 `"0x.."`）；行末换行。
