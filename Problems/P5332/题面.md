# 题目内容

小明最近学会了一个新算法：滑动窗口。最近他遇到了下面的例题：

给定一个长度为 n 的序列 $a_1,a_2,\dots,a_n$，若对于所有 $1\le p\le n-L+1$，

$\Big(\sum_{i=p}^{p+L-1}a_i\Big)\bmod m$ 的值均为 0，则输出 YES，否则输出 NO。

小明已经写好了程序，现在你需要帮忙构造测试数据。已经生成长度为 n 的序列 $b_1,b_2,\dots,b_n$，你需要构造序列 $a_1,a_2,\dots,a_n$，使得小明的程序可以输出 YES，并且对所有 $1\le i\le n$，满足 $a_i\ge b_i$。

请回答，在所有合法构造中，

$\sum_{i=1}^n a_i-\sum_{i=1}^n b_i$的最小值是多少？输出该值作为答案。

注意：输入保证 $0\le b_i<m$，但你构造的 $a_i$ 不必满足该限制。

# 输入描述

第一行有三个正整数 $n,m$ 和 L，含义与题目描述中相同。 接下来一行，有 n 个整数，分别表示 $b_1,b_2,\dots,b_n$。

约束：

$1\le n,m\le 500,\quad 1\le L\le n,\quad 0\le b_i<m$

# 输出描述

输出一个整数，代表答案。



## 样例1 

**输入** 

```
5 5 3
3 2 1 2 4
```

**输出** 

```
5
```

**说明**

输入数据 $[3,2,1,2,4]$ 的总和为 12。一种可行的构造方案为 $[3,4,3,3,4]$，总和为 17，其差值为 5。可以证明，5 是所有合法构造中差值最小的。
