# 盘丝洞灵脉

天命人深入盘丝洞，洞内布满了蜘蛛精设下的迷阵。整座洞穴呈**二叉树结构**，每个结点是一间石室，石室中藏有灵气结晶（整数，可正可负，零值视为非负）。

天命人从**根石室**出发，寻找通往**叶子石室**的路径收集灵气。但盘丝洞有**毒瘴禁制**：路径上**不允许出现连续两个或以上灵气值为负**的石室。

**叶子石室**的定义：左右子结点均为空的结点。

请实现一个函数，在一遍遍历中同时计算以下三个指标：

1. 合法路径的最大灵气和
2. 是否存在合法路径和 $\ge$ 给定阈值
3. 合法路径的总数

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数（平台提供 `TreeNode` 定义：`val`、`left`、`right`）：

| 语言 | 签名 |
|------|------|
| Python | `def analyzeSpiritPaths(self, root: Optional[TreeNode], threshold: int) -> List[int]` |
| Java | `public int[] analyzeSpiritPaths(TreeNode root, int threshold)` |
| C++ | `vector<int> analyzeSpiritPaths(TreeNode* root, int threshold)` |

**参数**

- `root`：二叉树根结点；空树为 `null` / `None` / 空指针；
- `threshold`：路径和阈值，$-10^9 \le \text{threshold} \le 10^9$。

**返回值**

长度为 $3$ 的整数数组（或等价列表）$[\text{max\_val}, \text{has\_path\_ge}, \text{count}]$：

- $\text{max\_val}$：合法路径的最大灵气和；无合法路径返回 $-2147483648$；
- $\text{has\_path\_ge}$：存在合法路径和 $\ge \text{threshold}$ 返回 $1$，否则返回 $0$；
- $\text{count}$：合法路径的总数。

**补充规则**

- 路径为从根到叶子的结点序列（含根与叶子）；
- 结点值 $v < 0$ 视为负，$v \ge 0$ 视为非负（含 $0$）；
- 若路径上存在相邻两个结点均为负，则该路径非法；
- 空树（$n=0$）返回 $[-2147483648, 0, 0]$。

## 输入输出格式（stdin / stdout）

**输入**（stdin **一行**：层次遍历序列化的二叉树，花括号包裹、逗号分隔；`#` 表示空结点；逗号后接整数阈值；与样例形态一致）：

```text
{10,-5,20,#,8,-6,15},40
```

**输出**（stdout **一行**，方括号包裹的 $3$ 个整数，逗号无空格）：

```text
[45,1,3]
```

### 二叉树输入格式说明

二叉树采用层次遍历方式序列化表示：

- 按从上到下、从左到右的顺序依次列出每个结点的值；
- `#` 表示该位置为空结点（无子结点）；
- 空树用 `{}` 或 `{#}` 表示。

示例：`{10,-5,20,#,8,-6,15}` 表示：

```text
    10
   /  \
 -5    20
  \   /  \
   8 -6   15
```

解析规则：根结点为 $10$，左子 $-5$（其左子为空 `#`，右子为 $8$），右子 $20$（左子 $-6$，右子 $15$）。

## 数据范围

| 项目 | 范围 |
| ---- | ---- |
| 节点数 | $0 \le n \le 10^5$ |
| 节点值 | $-100 \le \text{val} \le 100$ |
| 树深度 | $\le 10^4$ |
| 阈值 | $-10^9 \le \text{threshold} \le 10^9$ |

空树说明：当 $n = 0$ 时返回 $[-2147483648, 0, 0]$。

## 样例

### 样例 1

**输入**

```text
{10,-5,20,#,8,-6,15},40
```

**输出**

```text
[45,1,3]
```

**说明**

从根到叶子共 $3$ 条路径：

- $10 \to -5 \to 8$，和 = $13$，负结点不连续，合法；
- $10 \to 20 \to -6$，和 = $24$，负结点不连续，合法；
- $10 \to 20 \to 15$，和 = $45$，无负结点，合法。

最大合法路径和 = $45$，存在路径和 $\ge 40$，合法路径数 = $3$。

### 样例 2

**输入**

```text
{-5,-3,#,#,-7},-100
```

**输出**

```text
[-2147483648,0,0]
```

**说明**

从根到叶子仅 $1$ 条路径：$-5 \to -3 \to -7$，和 = $-15$，但 $-5$ 与 $-3$ 为连续负结点，路径非法。

### 样例 3

**输入**

```text
{5,-3,#,#,8,-2,#,#,10},18
```

**输出**

```text
[18,1,1]
```

**说明**

从根到叶子仅 $1$ 条路径：$5 \to -3 \to 8 \to -2 \to 10$，和 = $18$，负结点 $-3$ 与 $-2$ 之间隔了正结点 $8$，不连续，路径合法。
