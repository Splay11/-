# 题目内容

给你两棵二叉树 $root$ 和 $subRoot$。检验 $root$ 中是否包含和 $subRoot$ 具有相同结构和节点值的子树。如果存在，返回 $true$；否则，返回 $false$。

# 输入描述

第一行输入一个整数 $n_1(1 \le n_1 \le 2000)$，表示 $root$ 的层序遍历长度

第二行输入 $n_1$ 个值，表示 $root$ 的层序遍历（$null$ 表示空节点，非空值范围 $(-10^4 \le val \le 10^4)$）

第三行输入一个整数 $n_2(1 \le n_2 \le 1000)$，表示 $subRoot$ 的层序遍历长度

第四行输入 $n_2$ 个值，表示 $subRoot$ 的层序遍历

# 输出描述

输出 $true$ 或 $false$。

## 样例 $1$

**输入**

```text
7
3 4 5 1 2 null null
3
4 1 2
```

**输出**

```text
true
```

**说明**

$subRoot = [4,1,2]$ 是 $root$ 的左子树，结构和值完全相同。

## 样例 $2$

**输入**

```text
9
3 4 5 1 2 null null null null
1
0
```

**输出**

```text
false
```
