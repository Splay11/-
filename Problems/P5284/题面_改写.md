# 产线物料保质领用

# 题目内容

产线侧按 $D$ 个工位班次发放物料，班次编号 $1$ 到 $D$。调度模块拿到三条等长整型序列 $p,x,y$。

第 $i$ 个班次依次做两件事：

1. 入库 $x_i$ 件同批次物料。该批次最后可用班次为
   $$
   L_i=p_i-1.
   $$
   在班次 $t$ 仍可用，当且仅当 $t\le L_i$。
2. 本班次领用需求为 $y_i$ 件，只能从**当前仍可用**的库存中取。库存不足时，缺额
   $$
   g_i=\max(0,y_i-s_i),
   $$
   其中 $s_i$ 为该班次实际领到的件数。

每次领用可任选库存中的可用批次。求一种领用次序，使缺额总和
$$
W=g_1+g_2+\cdots+g_D
$$
最小，输出 $W$。

# 输入描述

第一行一个整数 $D$，表示班次数。

第二行 $D$ 个整数 $p_1,p_2,\ldots,p_D$。

第三行 $D$ 个整数 $x_1,x_2,\ldots,x_D$。

第四行 $D$ 个整数 $y_1,y_2,\ldots,y_D$。

# 输出描述

输出一个整数，表示最小缺额总和 $W$。

## 样例1

**输入**

```
4
3 5 4 6
3 0 2 1
2 2 3 1
```

**输出**

```
2
```

**说明**

班次 $1$：入库 $3$ 件（最后可用班次 $2$），领用 $2$ 件，剩 $1$ 件。

班次 $2$：无入库；库存 $1$ 件仍可用，需求 $2$，缺额 $1$，库存清空。

班次 $3$：入库 $2$ 件（最后可用班次 $3$），领用 $2$ 件，库存清空。

班次 $4$：入库 $1$ 件（最后可用班次 $5$），领用 $1$ 件。

各班次缺额为 $0,1,1,0$，总和 $W=2$。

# 数据范围

- $1\le D\le 100000$
- $1\le p_i\le D+1$
- $0\le x_i,y_i\le 1000000000$
- 所有输入均为整数
