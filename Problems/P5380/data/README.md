# P5380 测试数据说明

共 $10$ 组。单组：长度为 $n$ 的合法 `(`/`)` 串，统计匹配对内部长度 $R-L-1$ 能被 $m$ 整除的个数。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 $n=2$ 单对 | 展示 `inner=0` 必计 | 认为 $0$ 不能整除 |
| 2 | 样例2 `(()())` | 近邻匹配 | 配到最左侧未匹配 `(` |
| 3 | 样例3 外层 $4,6$ 不整除 | 部分计数 | 只看最外层或只看最内层 |
| 4 | `()()()()`，$m=3$ | 全是 $inner=0$ | 用 $R-L$ 或 $R-L+1$ 当内部长度 |
| 5 | 全嵌套 $n=10$，$m=4$ | 内部长度全偶数 | 漏掉中间层 |
| 6 | $m=1$ 混合结构 | 答案必为 $n/2$ | 漏计任意一对 |
| 7 | $n=2,m=2$ | 最小规模且 $m$ 上界 | 边界取模 |
| 8 | $m=n$ 混合 | 只有相邻对计入 | 把 $n-2$ 误当成 $m$ 的倍数 |
| 9 | $n=200000$ 全嵌套 $m=2$ | 压测；内部全偶数 | $O(n^2)$、递归爆栈、$R-L$ 全为奇数 |
| 10 | $n=200000$ 随机 Dyck $m=7$ | 一般结构压测 | I/O 与复杂度 |

前 $8$ 组小；后 $2$ 组压测。
