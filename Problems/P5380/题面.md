# 题目内容


给定一个长度为 $n$ 的合法括号字符串 $s$，其中只包含左括号、右括号。每个右括号与它左侧最近的、尚未匹配的左括号配对。

设一对匹配括号的位置为 $l,r(1 \le l < r \le n)$。这对括号的内部长度定义为 $r-l-1$，即两个括号之间的字符数量。请计算内部长度能被 $k$ 整除的匹配对数量。特别地，$0$ 能被任意正整数整除。

【名词解释】
合法括号字符串满足：从左到右扫描任意前缀时，左括号数量不少于右括号数量；扫描完整字符串后，两种括号数量相等。


# 输入描述


第一行输入两个整数 $n$ 和 $k(2 \le n \le 2 \times 10^5;\ 1 \le k \le n)$，分别表示字符串长度、整除条件中的正整数。

第二行输入一个长度为 $n$ 的合法括号字符串 $s$。保证 $n$ 为偶数。



# 输出描述


输出一个整数，表示内部长度能被 $k$ 整除的匹配对数量。


## 样例1 



**输入** 



```
8 3
()(())
```



**输出** 



```
3
```



**说明**

内部长度为 $0$ 的三个匹配对满足条件；最外层匹配对的内部长度为 $4$，不满足条件。

## 样例2



**输入** 



```
4 2
(())
```



**输出** 



```
2
```



**说明**

两对匹配括号的内部长度分别为 $2$、$0$，均能被 $2$ 整除。
