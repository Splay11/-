# 题目内容

给定一棵有 $N$ 个节点的二叉树，根节点编号为 0，每个结点最多有 2 个子结点。每个节点都有一个权值 \(w[i]\)。

梅工程师会以深度优先搜索 (DFS) 的方式遍历这棵树。对于当前搜索到的节点 i，若其有两个子结点，设为 l 和 r，则先搜索 l 节点的概率为 $w[l]/(w[l]+w[r])$，反之亦然。

遍历完整棵树后，梅工程师的满意程度为 $S = \sum (N - \text{dfn}[i] + 1) * w[i]$，其中 $\text{dfn}[i]$表示节点 i 被搜索到的 DFS 序。

梅工程师现在有一个着色器，可以将树上最多一个节点的权值修改为 W，也可以不修改。请问，最后梅工程师观看树的最大期望满意程度是多少？

# 输入描述

第一行一个整数N，代表树的节点的数量，其中 $1 \le N \le 10^5$。

接下来一行 \(N-1\) 个整数，第 $i$ 个数代表结点 $i$ 的父节点的编号 $\text{fa}[i]$，其中 $\text{fa}[i] < i$，数据保证构成的树会是一棵二叉树。

接下来一行 N 个整数 $w[i]$，代表每个结点的权值，其中 $1 \le w[i] \le 1000$。

最后一行一个整数W，代表着色器修改后结点的权值，其中 $1 \le W \le 1000$。

# 输出描述

输出一个数，代表修改后最大的期望满意程度，结果与最终结果相对误差或者绝对误差小于\(10^{-4}\)视为正确。

## 样例1 

**输入** 

```
5
0 0 1 1
5 1 1 1 1
4
```

**输出** 

```
46.4000
```

**说明**

将结点$ 1$ 的权值替换为 4，可以使最终 

遍历顺序为 <0,2,1,3,4> 和 <0,2,1,4,3> 的概率都为 40%

 遍历顺序为 < 0,1,3,4,2> 和 <0,1,4,3,2> 的概率都为 10% $

因此期望 $E=(40\%*2)*(5*5+4*1+1*3+1*2+1*1)+(10\%*2)*(5*5+1*4+4*3+1*2+1*1) = 46.40$
