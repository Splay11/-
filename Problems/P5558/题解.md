# 双色条码最长保留

## 解题思路

留下的墨点必须仍按原顺序排成「浅色段 + 深色段 + 浅色段」，三段都允许为空。同一种颜色在自己那一段里全部留下不会更差，所以只要决定深色段覆盖原条码的哪一段下标。

1. 设条码为 $t$，长度为 $m$。选定切分点 $i,j$（$0 \le i \le j \le m$）：下标落在 $[0,i)$ 的位置只留 $a$，$[i,j)$ 只留 $b$，$[j,m)$ 只留 $a$。
2. 用前缀计数 $A(x)$、$B(x)$ 表示前 $x$ 颗里浅色、深色各有多少。这一对切分的长度是
   $A(i)+B(j)-B(i)+A(m)-A(j)$，也就是 $A(i)-B(i)$ 再加上只跟 $j$ 有关的部分。
3. 右端点 $j$ 从 $0$ 扫到 $m$，顺手维护 $i \le j$ 时 $A(i)-B(i)$ 的最大值。每个 $j$ 用这个最大值更新答案。$i=j$ 时深色段为空，全留浅色；整段都划进深色段时，两侧浅色可以为空。

## 复杂度分析

- 时间复杂度：$O(m)$。前缀和扫一遍，右端点再扫一遍。
- 空间复杂度：$O(m)$。保存两个前缀数组。

## 代码实现

### Python

```python
def longest_keep(t, m):
    # 前缀里浅色 a、深色 b 各有多少颗，下标覆盖 0 到 m
    cnt_a = [0] * (m + 1)
    cnt_b = [0] * (m + 1)
    for i in range(m):
        cnt_a[i + 1] = cnt_a[i]
        cnt_b[i + 1] = cnt_b[i]
        if t[i] == "a":
            cnt_a[i + 1] += 1
        else:
            cnt_b[i + 1] += 1
    total_a = cnt_a[m]
    # best_diff：左端点不超过当前右端点时，左段 a 个数减去左段 b 个数的最大值
    best_diff = -10**18
    ans = 0
    for j in range(m + 1):
        diff = cnt_a[j] - cnt_b[j]
        if diff > best_diff:
            best_diff = diff
        # 右端点定在 j：左段用最优切分，中段把区间里的 b 全部留下，右段把后面的 a 全部留下
        cur = best_diff + cnt_b[j] + (total_a - cnt_a[j])
        if cur > ans:
            ans = cur
    return ans


def main():
    # 第一行是墨点数，第二行是条码
    m = int(input())
    t = input().strip()
    print(longest_keep(t, m))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    static int longestKeep(String t, int m) {
        // 前缀里浅色 a、深色 b 各有多少颗
        int[] cntA = new int[m + 1];
        int[] cntB = new int[m + 1];
        for (int i = 0; i < m; i++) {
            cntA[i + 1] = cntA[i];
            cntB[i + 1] = cntB[i];
            if (t.charAt(i) == 'a') {
                cntA[i + 1] += 1;
            } else {
                cntB[i + 1] += 1;
            }
        }
        int totalA = cntA[m];
        // bestDiff：左端点不超过当前右端点时，左段 a 个数减左段 b 个数的最大值
        int bestDiff = Integer.MIN_VALUE;
        int ans = 0;
        for (int j = 0; j <= m; j++) {
            int diff = cntA[j] - cntB[j];
            if (diff > bestDiff) {
                bestDiff = diff;
            }
            // 右端点定在 j：中段留满 b，右段留满后面的 a
            int cur = bestDiff + cntB[j] + (totalA - cntA[j]);
            if (cur > ans) {
                ans = cur;
            }
        }
        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        // 第一行墨点数，第二行条码
        int m = sc.nextInt();
        String t = sc.next();
        System.out.println(longestKeep(t, m));
        sc.close();
    }
}
```
