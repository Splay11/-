# 题目内容

有一个只包含小写字母 $a$ 和 $b$ 的字符串。

我们认为一个字符串是“多多字符串”，当且仅当它可以被分成连续的三段，并且：

第一段只包含字母 $a$

第二段只包含字母 $b$

第三段只包含字母 $a$

注意(其中任何一段都可以为空)

简单来说，“多多字符串”的形态就是：前面全是 $a$，中间全是 $b$，后面又全是 $a$。

你通过删除原字符串中的一些字符（也可以一个都不删）来把它变成一个“多多字符串”，且不能改变剩余字符的先后顺序。请你看一下你可以从给定字符串得到的最长多多字符串有多长。

# 输入描述

第一行包含一个非空字符串，长度不超过 $5000$，且仅由小写字母 $a$ 和 $b$ 组成。






# 输出描述

输出一个整数，表示能得到的“多多字符串”的最大可能长度。




## 样例1 



**输入** 



```
abba
```



**输出** 



```
4
```

## 样例2



**输入** 



```
bab
```



**输出** 



```
2
```
