# P5294 测例说明

单组输入，与改写题面一致。`D`/`S`/`YES`/`NO` 字符集冻结。

| 组 | 规模 | 目标 | 卡掉的错误解 |
|---:|---|---|---|
| 1 | 改写样例1 | 和差联立已唯一 | 把和当差、漏判 k=0 |
| 2 | 改写样例2 | 自和奇数 | 不检查整除 |
| 3 | 改写样例3 | 差链一个自由度 | 当成已唯一或无解 |
| 4 | 自差恒真+孤立点 | 自由度=点数 | 把恒真当钉死 |
| 5 | S+D 整数解 | 已唯一 | 把 S 当 D 会得 k=1 |
| 6 | 三条和唯一确定 | k=0 | 只数连通块会得 k=1 |
| 7 | 差账矛盾 | NO | 不检查环一致性 |
| 8 | 小随机混和差 | 有解/无解混合 | 漏传播 fixed |
| 9 | n=1e5 无边 | k=n | 忘记孤立点 |
| 10 | n=m=1e5 差链+自和 | 钉死整链 | 递归 find 爆栈、int 溢出、超时 |
