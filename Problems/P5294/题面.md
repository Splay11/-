# 题目内容


多多在电商平台运营一张由 $n$ 个区域仓组成的调拨网络（编号 $1$ 到 $n$ ）。每个区域仓 $i$ 在某个时刻持有 $(c[i])$ 件某爆款商品， $(c[i])$ 为整数（可为负，表示欠货）。大促期间，各区域仓通过自动对账系统上报两两库存关系，系统记录了 $m$ 条对账单线索，每条是下列两种之一：

- 差账 $D$ $a$ $b$ $d$：区域仓 $a$ 与区域仓 $b$ 的库存差为 $d$，即 $c[a] - c[b] = d$（$d$ 可为负，代表调拨方向）。
- 合账 $S$ $a$ $b$ $s$：区域仓 $a$ 与区域仓 $b$ 的库存之和为 $s$，即 $c[a] + c[b] = s$。

对账系统需要完成两项任务：
1. 判断是否存在一组整数库存赋值 $(c[1..n])$ 同时满足全部 $m$ 条线索。
2. 若存在，系统希望用最少的“实地盘点”来确定全部库存：每实地盘点一个区域仓 $i$，就能准确得知 $(c[i])$ 的值。求最少需要盘点多少个区域仓，才能唯一确定所有 $n$ 个区域仓的库存。



# 输入描述


第一行一个整数 $T$，表示测试用例组数。
每组测试用例的格式如下：

第一行两个整数 $(n,m)$，表示区域仓数量和对账单线索数量。
接下来 $m$ 行，每行描述一条线索，格式为：
- $D$ $a$ $b$ $d$：表示 $c[a] - c[b] = d$
- $S$ $a$ $b$ $s$：表示 $c[a] + c[b] = s$


其中第一个字段为线索类型（大写字母 $D$ 或 $S$），随后两个整数为区域仓编号，最后一个整数为关系值。

$1 \le T$

$1 \le n \le 10^5$

$0 \le m \le 10^5$

$1 \le a,b \le n$

$|d|,|s| \le 10^9$

$\sum n \le 10^5,\ \sum m \le 10^5$


# 输出描述


对于每组测试用例，输出两行：

第一行：若存在满足全部线索的整数库存赋值，输出 $YES$；否则输出 $NO$。

第二行：若第一行为 $YES$，输出最少需要盘点的区域仓数量 $k$（$k \ge 0$，$(k=0)$ 表示无需盘点即可唯一确定全部库存）；若第一行为 $NO$，输出 $-1$。


## 样例1 



**输入** 



```
1
3 3
D 1 2 4
D 2 3 -1
D 1 3 3
```



**输出** 



```
YES
1
```



**说明**

三条差账自治: $c[1]−c[2]=4、c[2]−c[3]=(-1)、c[1]−c[3]=3$（第三条可由前两条推出）。

三个仓库的库存由一个自由变量决定（如已知 $c[3]$ 则 $c[2]=c[3](-1)、c[1]=c[3]+3）$。故最少盘点 $1$ 个仓库。


## 样例1 



**输入** 



```
1
2 2
S 1 2 10
D 1 2 7
```



**输出** 



```
NO
-1
```



**说明**


$c[1]+c[2]=10$ 与 $c[1]−c[2]=7$ 联立得 $2c[1]=17$，$c[1]=8.5$ 非整数，不存在整数赋值。
