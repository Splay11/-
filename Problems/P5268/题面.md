# 题目内容

牛牛是异世界的魔法师。一只怪物血量 $10^\wedge y$，牛牛学会四种魔法，每次操作选择一个可用魔法施放。问是否存在施法顺序，在某时刻让怪物血量 $(<1)$（击败怪物）。

## 魔法说明
1. **魔法一**（最多使用 $n$ 次，$n \le 10$）

有 $n$ 个增幅水晶，倍率分别为（$a_1$,$a_2$,...,$a_n$），每个只能用一次。

释放魔法一：选一个未使用水晶（$a_k$），下一次释放的魔法基础伤害 $\times\ a_k$。

魔法一本身无伤害；使用魔法一后，紧接着的下一次不能再放魔法一。

2. **魔法二**（最多使用 $m$ 次）

$m$ 个单体伤害法术，基础伤害（$b_1$...$b_m$），每个只能用一次。造成对应基础伤害。

3. **魔法三**（最多使用 $1$ 次）

记怪物当前血量为 $r$，造成基础伤害 $p/q * r$。

4. **魔法四**（最多使用 $1$ 次）

记怪物当前血量为 $r$，造成基础伤害 $r$ 开根号。

> 注意：魔法一的增幅只作用于紧随其后那一次魔法（可以是魔法二 / 三 / 四，不能是魔法一）。

伤害结算：怪物血量 = 当前血量 −（被增幅后的实际伤害）。

$\lfloor x \rfloor$ 是向下取整。

初始怪物血量 $z = 10^\wedge\{18\}$。




# 输入描述

多组测试数据。

第一行整数 $T$;($1 \le T \le 20$)。

每组数据：

第一行：三个整数 $n$,$m$,$p$,$q$,$y$

第二行：$n$ 个整数 $a_1$...$a_n$。

第三行：$m$ 个整数 $b_1,b_2\dots b_m$;($1 \le b_i \le 10^\wedge9$)。




# 输出描述

对于每组测试数据，输出一行：$Yes$ 或者 $No$，代表能否击败怪物。


## 题意关键点梳理（做题要点）
1. $m \le 17$，提示可以用状态压缩位掩码标记魔法二哪些已经用过；$n \le 10$ 标记水晶使用状态。

## 样例1 



**输入** 



```
4
1 1 1 2 9
100
500000000
0 2 1 1 6

999999 999999
1 0 99 100 3
10

0 0 1 1 2
```



**输出** 



```
Yes
Yes
No
Yes
```



**说明**

**样例1第1组：$(n=1,m=1,p=1,q=2,y=9)$，$(a=[100])$，$(b=[500000000])$**
初始血量 $10^9 = 1000000000$。
施法顺序：魔法一（水晶$100$）→魔法二（$500000000$）。
魔法二被放大 $100$ 倍，实际伤害 $500000000 \times 100 = 5\times10^{10}$。
怪物血量 $=10^9 - 5\times10^{10} < 1$，直接击杀。输出 `Yes`。

**样例1第2组：$(n=0,m=2,p=1,q=1,y=6)$，$a$为空，$(b=[999999,999999])$**
初始血量 $10^6 = 1000000$。
先放魔法二 $999999$，血量变为 $1$；再放第二个魔法二 $999999$，血量 $1-999999(<1)$，击杀。输出 `Yes`。

**样例1第3组：$(n=1,m=0,p=99,q=100,y=3)$，$(a=[10])$，$b$为空**
初始血量 $10^3=1000$。
可用魔法：魔法一、魔法三。
魔法一后面必须接魔法二/三/四，没有魔法二、四，只能接魔法三。
魔法三基础伤害：$\frac{99}{100} \times 1000 = 990$。就算放大$10$倍，伤害 $9900$。
血量：$1000 - 9900$，但是注意：魔法三伤害是$\lfloor r \cdot \frac{p}{q} \rfloor$。
第一轮：$((r=10)00)$，魔法三伤害 $\lfloor 1000 * 99/100 \rfloor =990$，放大十倍 $9900$；$1000-9900$，血量不会小于1吗？
> 这里关键规则：伤害不能超过当前血量，血量最低为0；本题魔法三伤害向下取整，$r$ 更新为 $r - \lfloor k\cdot r \cdot p/q\rfloor$。执行完魔法一+魔法三之后 $(r=10)$。没有剩余魔法，无法继续输出伤害，无法击杀。输出 `No`。

**样例1第4组：$(n=0,m=0,p=1,q=1,y=2)$，$a$空，$b$空**
初始血量 $10^2=100$。
使用魔法三，$(p/q=1)$。基础伤害 $1 \times 100 = 100$。怪物血量 $100-100=0(<1)$，直接击败。输出 `Yes`。

## 题意关键点梳理（做题要点）
1. $m \le 17$，提示可以用状态压缩位掩码标记魔法二哪些已经用过；$n \le 10$ 标记水晶使用状态。
2. 魔法一释放后下一次不能释放魔法一；魔法一的增益只作用紧接其后一次魔法。
3. 魔法三、魔法四最多各使用一次；魔法三伤害是向下取整；
4. 只要**任意时刻**怪物血量 $(<1)$，就判定成功，不需要把全部魔法打完。
5. $y$ 可以很大，初始血量可达 $10^{18}$，中间过程数值要用 $64$位整数。

---

> 补充说明：这道题核心搜索状态维度：
> - 水晶使用状态：$2^{n}$，$n\le10$，最多 $1024$
> - 魔法二使用状态：$2^{m}$，$m\le17$，最多 $131072$
> - 魔法三是否用过：$(0/1)$
> - 魔法四是否用过：$(0/1)$
> - 是否刚刚释放魔法一（下一个不能放魔法一）：$(0/1)$
> 总状态数可控，可以DFS/记忆化搜索。
