# 技能链压测过关

# 题目内容

助手技能编排侧要对目标负载做压测：初始负载为 $10^{e}$。可用四类技能，每次选一个仍可用的技能施放。问是否存在施法顺序，使某一时刻负载降到小于 $1$。

## 技能说明

1. **技能甲**（最多 $c$ 次，$c\le 10$）

有 $c$ 个增幅系数 $w_1,w_2,\ldots,w_c$，每个只能用一次。

施放技能甲：选一个未用系数 $w_k$，使**下一次**技能的固定伤害乘上 $w_k$。技能甲本身不造成削减；施放后紧接着的下一次不能再放技能甲。

2. **技能乙**（最多 $d$ 次）

$d$ 个固定削减值 $h_1,\ldots,h_d$，每个只能用一次。造成对应基础削减；若紧接在技能甲之后，则实际削减为 $h_j\cdot w$。

3. **技能丙**（最多 $1$ 次）

记当前负载为 $r$，造成基础削减 $\lfloor r\cdot \alpha/q\rfloor$（$\alpha,q$ 为给定正整数）。若紧接在技能甲之后，仅消耗该次增幅，削减仍按上述基础公式计算（不另乘系数）。

4. **技能丁**（最多 $1$ 次）

记当前负载为 $r$，造成基础削减 $\lfloor\sqrt{r}\rfloor$。若紧接在技能甲之后，仅消耗该次增幅，削减仍按开方公式计算。

负载更新：新负载 $=$ 当前负载 $-$ 实际削减。只要某一时刻负载 $<1$，即判定过关。

# 输入描述

第一行一个整数 $t$（$1\le t\le 20$），表示询问个数。

每个询问：
- 第一行五个整数 $c,d,\alpha,q,e$；
- 若 $c>0$，下一行 $c$ 个整数 $w_1,\ldots,w_c$；
- 若 $d>0$，下一行 $d$ 个整数 $h_1,\ldots,h_d$（$1\le h_i\le 10^9$）。

保证 $0\le c\le 10$，$0\le d\le 17$，$1\le \alpha,q$，$0\le e\le 18$，初始负载 $10^{e}$ 可用 $64$ 位整数表示。

# 输出描述

对每个询问输出一行 `Yes` 或 `No`，表示能否使负载小于 $1$。

## 样例1

**输入**

```
4
1 1 1 2 8
50
30000000
0 2 1 1 5
100000 100000
1 0 9 10 3
5
0 0 1 1 1
```

**输出**

```
Yes
Yes
No
Yes
```

**说明**

第 $1$ 个询问：初始负载 $10^8$。技能甲（系数 $50$）后接技能乙 $30000000$，实际削减 $1.5\times 10^9$，负载变为负，过关。

第 $2$ 个询问：先乙 $100000$ 使负载为 $0$，已小于 $1$（或再打第二下亦可）。

第 $3$ 个询问：仅有甲与丙。丙使负载从 $1000$ 变为 $100$；甲后接丁按开方削减无法打到小于 $1$。输出 `No`。

第 $4$ 个询问：初始 $10$，技能丙 $\alpha/q=1$，一刀清零，输出 `Yes`。
