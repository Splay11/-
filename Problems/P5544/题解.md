# im2col 一维卷积

## 解题思路

im2col 把一维卷积变成矩阵乘向量：

1. 对 $x$ 两端各补 $P$ 个 $0$，得到 $x'$。
2. 输出长度 $O=\lfloor(L'-K)/S\rfloor+1$，构建矩阵 $C$（$O\times K$），第 $i$ 行为 $x'[iS:iS+K]$。
3. $y=Cw$。
4. 先输出 $O$、$K$ 与 $C$，再输出 $y$，均保留 $4$ 位小数。

## 复杂度分析

- 时间复杂度：$O(O \cdot K)$
- 空间复杂度：$O(O \cdot K)$

## 代码实现

### Python

```python
import numpy as np


class Solution:
    def im2col_conv1d(self, x, w, S, P):
        # 返回 (im2col矩阵 O x K, 卷积结果 y)
        x = np.asarray(x, dtype=np.float64)
        w = np.asarray(w, dtype=np.float64)
        K = len(w)
        # 两端补零
        if P > 0:
            xp = np.pad(x, (P, P), mode="constant")
        else:
            xp = x
        L2 = len(xp)
        O = (L2 - K) // S + 1
        C = np.zeros((O, K), dtype=np.float64)
        for i in range(O):
            # 第 i 行取滑窗片段
            C[i] = xp[i * S : i * S + K]
        y = C @ w
        return C, y
```
