# 题目内容

多多果园的采摘季共有 $n$ 天，第 $i$ 天的净产量为 $a_i$ 吨（$a_i$ 可能为负，表示当天倒贴的运输与损耗成本）。

果园要开启一段连续的"连收模式"：选定一段连续的日子 $[l, r]$，且这段日子长度至少为 $L$（太短的连收没有规模效应，等于白干）。

报表上好看的是平均日产量。定义一段日子的平均日产量为
$$
\left\lfloor \frac{a_l + a_{l+1} + \dots + a_r}{r-l+1} \right\rfloor
$$
其中 $\lfloor \cdot \rfloor$ 表示向下取整（不大于它的最大整数，例如 $\lfloor -8/3 \rfloor = \lfloor -2.67 \rfloor = -3$）。

多多想在所有合法的方案中，让平均日产量最大。由于 $L \le n$，方案一定存在。请输出这个最大值。




# 输入描述


第一行一个整数 $T$，表示测试数据组数。

对于每组数据：

第一行两个整数 $n, L$，

第二行 $n$ 个整数 $a_1,a_2,\dots,a_n$。


# 输出描述


对于每组数据，输出一行一个整数，表示平均日产量的最大值。



## 样例1 



**输入** 



```
3
5 3
3 -4 5 2 -1
3 2
-5 -3 -8
4 4
7 -2 -3 7
```



**输出** 



```
2
-4
2
```



**说明**

第一组：$L$=3，最优区间为 [3, 5]，即 $\{5,2,-1\}$，总和6、长度3，平均值$\lfloor6/3\rfloor = 2$。其他如 $\{3,-4,5,2\}$ 平均$\lfloor6/4\rfloor = 1$，都不如它；

第二组：全为负数，最优区间为$\{-5,-3\}$，平均$\lfloor-8/2\rfloor = -4$。注意$\{-5,-3,-8\}$的平均是$\lfloor-16/3\rfloor = -6$，更差——即使全为负，也要选亏损最少的那段。
