# LoRA（Low-Rank Adaptation）

## 解题思路

1. 冻结预训练权重 $W$，用低秩分解 $A\in\mathbb{R}^{d_{in}\times r}$、$B\in\mathbb{R}^{r\times d_{out}}$ 表示增量。
2. 前向公式按题面：$y=xW+\alpha\cdot xAB$，其中 $\alpha$ 直接给定。
3. 在 `Solution.loraForward` 中用两次矩阵乘完成低秩路径，再与主路径相加。
4. 注意矩阵形状以题面为准：$W$ 为 $d_{in}\times d_{out}$，$A$ 为 $d_{in}\times r$，$B$ 为 $r\times d_{out}$。

## 复杂度分析

- 时间复杂度：$O(n d_{in} d_{out}+n d_{in} r+n r d_{out})$。
- 空间复杂度：$O(n d_{out})$，存放输出。

## 代码实现

### Python

```python
from typing import List
import numpy as np


class Solution:
    def loraForward(
        self,
        X: List[List[float]],
        W: List[List[float]],
        A: List[List[float]],
        B: List[List[float]],
        alpha: float,
    ) -> List[List[float]]:
        """LoRA 前向：y = xW + alpha * xAB。"""
        X = np.asarray(X, dtype=np.float64)
        W = np.asarray(W, dtype=np.float64)
        A = np.asarray(A, dtype=np.float64)
        B = np.asarray(B, dtype=np.float64)
        # 主路径 + 低秩增量
        Y = X @ W + alpha * (X @ A @ B)
        return Y.tolist()
```
