# 题目内容

给定一个长度为 $n$ 的权值数组 $\{a_1,a_2,\dots,a_n\}$。你需要构造一个长度为 $n$ 的整数数组 $\{b_1,b_2,\dots,b_n\}$，并基于 $a$ 与 $b$ 构造一张包含 $n$ 个节点的无向图（节点编号为 $1 \sim n$）。对于任意两两不同的节点 $(i,j)$（$1 \le i \le j \le n$）：
- 若 $b_i > b_j$，则在 $i$ 与 $j$ 之间连一条边，边长为 $a_j$；
- 若 $b_j > b_i$，则在 $i$ 与 $j$ 之间连一条边，边长为 $a_i$。

等价地，当且仅当 $b_i \neq b_j$ 时，$i$ 与 $j$ 之间恰好有一条边，其边长等于较小 $b$ 所在节点对应的 $a$ 值；当 $b_i = b_j$ 时不连边。

你需要保证该图是连通图。在满足连通性的前提下，使得所有边长之和尽可能大，并输出这一最大值。
可以证明一定有解。

【名词解释】
<u>连通图</u>：如果图中的任意两个顶点之间都存在路径相连，则称这个图是连通图。




# 输入描述


每个测试文件均包含多组测试数据。第一行输入一个整数 $T$（$1 \le T \le 10^4$）表示数据组数。每组测试数据描述如下：
- 第一行输入一个整数 $n$（$1 \le n \le 2 \times 10^5$）表示节点数量；
- 第二行输入 $n$ 个整数 $a_1,a_2,\dots,a_n$（$-n \le a_i \le n$）表示数组 $a$。

除此之外，保证单个测试文件的 $n$ 之和不超过 $2 \times 10^5$。


# 输出描述


对于每一组测试数据，新起一行，输出一个整数，表示在最优构造下所有边长之和的最大值。



## 样例1 



**输入** 



```
3
4
3 -1 2 0
3
-2 0 -1
5
1 2 3 4 5
```



**输出** 



```
4
-3
34
```



**说明**

**样例1第1组：$n=4,\ a=[3,-1,2,0]$**
最优构造 $b$ 数组例如：$(b=[1,2,3,4])$，全部 $b$ 值互不相等，任意两点之间都有边。
总边计算：
- $((1,2))$：$b_1<b_2$，边权 $a_1=3$
- $((1,3))$：$b_1<b_3$，边权 $a_1=3$
- $((1,4))$：$b_1<b_4$，边权 $a_1=3$
- $((2,3))$：$b_2<b_3$，边权 $a_2=-1$
- $((2,4))$：$b_2<b_4$，边权 $a_2=-1$
- $((3,4))$：$b_3<b_4$，边权 $a_3=2$
总和 $3+3+3-1-1+2 = 4$，图连通，达到最大和。

**样例1第2组：$n=3,\ a=[-2,0,-1]$**
最优构造全部 $b$ 互不相等。
全部边：$a_1+a_1+a_2 = -2 + (-2) + 0 = -3$。

**样例1第3组：$n=5,\ a=([1,2,3,4,5])$**
构造严格递增 $b$。
每个 $a_i$ 贡献次数：$a_1$ 贡献 $4$ 次，$a_2$ 贡献 $3$ 次，$a_3$ 贡献 $2$ 次，$a_4$ 贡献 $1$ 次，$a_5$ 贡献 $0$ 次。
$1\times4 + 2\times3 +3\times2 +4\times1 =4+6+6+4 = 34$。
