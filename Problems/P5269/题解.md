# 链路权重贡献最大化

## 解题思路

本题要求构造优先级数组 $r$，使按“较低优先级一侧的权重 $v$ 作为边权”连边后的图连通，且边权和最大。

1. 对每个实例 $i$，$v_i$ 的贡献次数等于「$r$ 严格大于 $r_i$ 的实例个数」。
2. 将 $v$ 从大到小排序。正数应尽量排在较低的 $r$ 上以获得更大倍数；非正数贡献非正，应共享最高 $r$，贡献为 $0$。
3. 若全部非正：不能所有 $r$ 相同（否则不连通），最优是取最大值单独作为较低 $r$，答案为 $\max(v)\cdot(n-1)$。
4. 若存在正数：正数赋互不相同的递增 $r$，非正数共享最高 $r$，答案为 $\sum v_{[i]}\cdot(n-1-i)$（仅对正数项求和）。
5. $n=1$ 时无边，答案为 $0$。

## 复杂度分析

- 时间复杂度：$O(n\log n)$（排序）。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
def solve(v):
    n = len(v)
    if n == 1:
        return 0
    # 从大到小排序，优先给大权重更大倍数
    v = sorted(v, reverse=True)
    # 全部非正：最大值单独当较低优先级 r
    if v[0] <= 0:
        return v[0] * (n - 1)
    ans = 0
    for i, x in enumerate(v):
        if x <= 0:
            break  # 后面共享最高 r，贡献 0
        # 排在第 i 位（0-index）时，有 n-1-i 个更高 r
        ans += x * (n - 1 - i)
    return ans


q = int(input())
for _ in range(q):
    n = int(input())
    v = list(map(int, input().split()))
    print(solve(v))
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    static long solve(int[] v) {
        int n = v.length;
        if (n == 1) return 0;
        Arrays.sort(v);  // 升序，再从大到小取
        if (v[n - 1] <= 0) return 1L * v[n - 1] * (n - 1);
        long ans = 0;
        for (int i = 0; i < n; i++) {
            int x = v[n - 1 - i];  // 第 i 大的权重
            if (x <= 0) break;
            ans += 1L * x * (n - 1 - i);
        }
        return ans;
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int q = Integer.parseInt(st.nextToken());
        StringBuilder sb = new StringBuilder();
        while (q-- > 0) {
            st = new StringTokenizer(br.readLine());
            int n = Integer.parseInt(st.nextToken());
            int[] v = new int[n];
            st = new StringTokenizer(br.readLine());
            for (int i = 0; i < n; i++) v[i] = Integer.parseInt(st.nextToken());
            sb.append(solve(v)).append('\n');
        }
        System.out.print(sb);
    }
}
```

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

long long solve(vector<int> v) {
    int n = (int)v.size();
    if (n == 1) return 0;
    sort(v.begin(), v.end(), greater<int>());
    // 全非正：最大值单独作为较低 r
    if (v[0] <= 0) return 1LL * v[0] * (n - 1);
    long long ans = 0;
    for (int i = 0; i < n; i++) {
        if (v[i] <= 0) break;
        ans += 1LL * v[i] * (n - 1 - i);
    }
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q;
    cin >> q;
    while (q--) {
        int n;
        cin >> n;
        vector<int> v(n);
        for (int i = 0; i < n; i++) cin >> v[i];
        cout << solve(v) << '\n';
    }
    return 0;
}
```
