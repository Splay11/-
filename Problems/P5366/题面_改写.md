# 样品超标对数几率

# 题目内容

实验室质检组要把一批已经人工复核过的样品仪器读数做成达标 / 超标判定器，再给当晚待检样品打标签。规程要求必须只用 `numpy` 手写对数几率模型，并且每一轮用**全部**训练样品算一次梯度再更新参数，不能换成现成分类库，也不能改成随机小批量。学习率、轮数、正则系数和数值截断都写在当班工艺卡上，必须原样执行。

每条训练记录是一组读数 $u_i$ 和一个标签 $t_i\in\{0,1\}$，其中 `0` 表示达标，`1` 表示超标。测试记录只有读数、没有标签。实现时在读数最左侧拼一列全 `1` 作为偏置，得到增广向量

$\bar{u}_i=[1,u_{i,1},u_{i,2},\ldots,u_{i,k}]$

权向量 $\theta$ 从全 `0` 开始。记 $s_i=\theta^\top\bar{u}_i$，再把 $s_i$ 截断到 $\bigl[-3\times 10^1,\,3\times 10^1\bigr]$（防止指数溢出）。通过率定义为

$q_i=\sigma(s_i)=\dfrac{1}{1+e^{-s_i}}$

其中 $\sigma$ 为 Sigmoid。每一轮用全部 $N$ 条训练样品做一次更新：

$\nabla=\dfrac{1}{N}\bigl(\bar{u}_1(q_1-t_1)+\bar{u}_2(q_2-t_2)+\cdots+\bar{u}_N(q_N-t_N)\bigr),\qquad \theta\leftarrow\theta-\eta\cdot\nabla$

固定口径：学习率 $\eta=`0.2`$；迭代轮数 $T=8\times 10^2$；L2 正则系数为 `0.0`。预测规则：若 $q\ge `0.5`$ 则判为 `1`，否则判为 `0`。本题不使用随机数，因此无需设置随机种子。为保证通过测试用例，仅允许使用 `numpy`。

约束：

- 训练条数 $N$ 满足 `1` $<$ $N$ $<$ $2\times 10^1$
- 测试条数 $Q$ 满足 `1` $<$ $Q$ $<$ $2\times 10^1$
- 读数维数 $k$ 满足 `0` $<$ $k$ $<$ `6`

# 输入描述

标准输入为一行 JSON，形如 `{"train": [[...features...,t],...],"test": [[...features...],...]}`。

- `train`：二维列表，共 $N$ 行。每行最后一列是标签 $t$（只取 `0` 或 `1`），其余列是读数；`1` $<$ $N$ $<$ $2\times 10^1$
- `test`：二维列表，共 $Q$ 行，只含读数，维数 $k$ 与训练一致；`1` $<$ $Q$ $<$ $2\times 10^1$，`0` $<$ $k$ $<$ `6`

# 输出描述

标准输出仅一行：一个 JSON 数组，长度为 $Q$，表示测试集预测标签（每个值是 `0` 或 `1`），顺序与 `test` 一致，例如 `[0,1,1]`。

## 样例1

**输入**

```text
{"train": [[2, 0], [3, 0], [8, 1], [9, 1]], "test": [[1], [2], [6], [9]]}
```

**输出**

```
[0, 0, 1, 1]
```

**说明**

- 训练集是一维读数：`2`、`3` 标为达标 `0`，`8`、`9` 标为超标 `1`
- 按固定口径训练 $8\times 10^2$ 轮后，$\theta\approx[-6.656,\,1.308]$，分界大约落在 `5.09` 附近
- 因此测试点 `1`、`2` 判为 `0`，测试点 `6`、`9` 判为 `1`

## 样例2

**输入**

```text
{"train": [[0, 1, 0], [1, 0, 0], [5, 1, 1], [6, 2, 1]], "test": [[0, 0], [6, 1], [3, 1]]}
```

**输出**

```
[0, 1, 1]
```

**说明**

- 训练集是二维读数。训练后 $\theta\approx[-5.175,\,1.979,\,0.033]$
- 三个测试点代入 $\theta^\top\bar{u}$ 分别得到约 $-5.175$、$6.729$、$0.794$
- 经 Sigmoid 后，第一个通过率小于 `0.5`，后两个大于 `0.5`，所以预测为 `0`、`1`、`1`

## 样例3

**输入**

```text
{"train": [[1, 0], [2, 0], [7, 1]], "test": [[1], [4], [8]]}
```

**输出**

```
[0, 0, 1]
```

**说明**

- 一维读数里较小的两条标达标，较大的一条标超标。训练后 $\theta\approx[-6.333,\,1.528]$，分界大约在 `4.14`
- 测试点 `4` 的通过率约为 `0.445`，尚未达到 `0.5`，因此判为 `0`；`1` 同样为 `0`，`8` 为 `1`
