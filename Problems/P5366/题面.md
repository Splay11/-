## 题目描述

请你在仅使用 numpy 的前提下，手写实现二分类 Logistic Regression，并用全批 Batch Gradient Descent（全批梯度下降）在训练集上训练，最后对测试集输出 0/1 预测。

训练口径固定如下：学习率 $lr=0.2$；迭代次数 $epochs=800$；L2 正则系数 $l2=0.0$；需要包含 bias 项，即对特征矩阵最左侧拼接一列全 1；sigmoid 输入 z 要做截断 $z=\text{clip}(z,-30,30)$（防止 exp 溢出）；预测规则为若 $p \ge 0.5$ 预测为 1，否则为 0。

训练目标：设训练集为 $(X,y)$，训练数据为 $(x_i,y_i),\ y_i \in \{0,1\}$，模型为

$p_i=\sigma(w^\top \bar{x}_i),\quad \bar{x}_i=[1,x_i]$

其中 w 为权重矩阵，\(\sigma\) 为 Sigmoid 函数。全批梯度下降更新为

$\nabla=\frac{1}{n}\bar{X}^\top(p-y),\quad w \leftarrow w-lr\cdot\nabla$

本题实现不需要随机数（权重初始化为全 0），因此无需设置随机种子。为保证通过测试用例，仅允许使用 numpy。

### 输入描述

标准输入为一行 JSON，形如 `{"train": [[...features...,y],...],"test": [[...features...],...]}`。

`train` 为 $n$ 行训练样本，每行最后一列是标签 $y(0/1)$，其余为特征值，$1<n<20$。 `test` 为$ m$ 行测试样本，仅包含特征，维度 d 与训练一致，$1<m<20,0<d<6$。

### 输出描述

标准输出仅一行：一个 JSON 数组，长度为 m，表示测试集预测标签，例如 `[0,1,1]`。

### 示例 1

输入

```text
{"train": [[0, 0], [1, 0], [4, 1], [5, 1]], "test": [[0], [1], [3], [5]]}
```

输出

```
[0, 0, 1, 1]
```

**说明**

训练集是一维特征，特征值 $0,1$ 标签为$ 0$，特征值 $4,5$ 标签为$ 1$。按固定口径训练 800 轮后权重为 $w \approx [-5.353,2.395]$，决策边界落在$ 2.24$ 附近，因此测试点$ 0,1$ 预测为 0，测试点 3,5 预测为 1。

### 示例 2

输入

```text
{"train": [[0, 0, 0], [1, 2, 0], [3, 1, 1], [4, 4, 1]], "test": [[0, 1], [4, 2], [3, 2]]}
```

输出

```
[0, 1, 1]
```

**说明**

训练集是二维特征，训练后权重为 $w \approx [-4.204,3.848,-1.638]$。三个测试点代入 $w^\top \bar{x}$分别得到 $-5.84,7.91,2.43$，经 $Sigmoid$ 后第一个概率小于 $0.5$、后两个大于 $0.5$，所以预测为 $0,1,1$。
