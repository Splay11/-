# 档位差异组合统计

在进行手机、平板、穿戴等设备的系统调优时，会为不同设备采集一组性能与能耗综合档位值；为了分析产品矩阵中是否存在稳定的档位梯度，工程师需要统计所有「档位差异恰好为指定值」的档位组合数量。

给定一个整数数组 `profiles`，其中 `profiles[i]` 表示第 $i$ 台终端设备的综合档位值；再给定一个非负整数 `diff`，表示目标档位差。

请你返回不同档位值组成的组合数量，使得两个档位值的绝对差等于 `diff`。

### 注意

1. 只按档位值去重，不按设备下标计数。  
   例如 `profiles = [1,1,3,3]`，`diff = 2` 时，只能计为一组 $(1, 3)$。
2. 当 `diff = 0` 时，只有某个档位值出现至少两次，才可以形成一组。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def countProfilePairs(self, profiles: List[int], diff: int) -> int` |
| Java | `public int countProfilePairs(int[] profiles, int diff)` |
| C++ | `int countProfilePairs(vector<int>& profiles, int diff)` |

**参数**

- `profiles`：整数数组，$1 \le |profiles| \le 10^5$，每个元素 $-2^{31} \le profiles[i] \le 2^{31}-1$；
- `diff`：目标档位差，$0 \le diff \le 2^{31}-1$。

**返回值**

满足条件的不同档位值组合数量（非负整数）。

## 输入输出格式（stdin / stdout）

**输入**（stdin **一行**：先 `profiles` 整数数组，逗号后为 `diff`；方括号内元素逗号后可有空格，与样例一致）：

```text
[1, 5, 3, 4, 2],2
```

**输出**（stdout **一行**整数）：

```text
3
```

## 数据范围

- $1 \le n = |profiles| \le 10^5$；
- $-2^{31} \le profiles[i] \le 2^{31}-1$；
- $0 \le diff \le 2^{31}-1$。

## 样例

### 样例 1

**输入**

```text
[1, 5, 3, 4, 2],2
```

**输出**

```text
3
```

**说明**

满足要求的不同档位组合为 $(1, 3)$、$(3, 5)$、$(2, 4)$，共 $3$ 组。

### 样例 2

**输入**

```text
[8, 8, 8, 10, 10, 12],0
```

**输出**

```text
2
```

**说明**

档位 $8$ 和档位 $10$ 都至少出现两次，可以分别形成一组差值为 $0$ 的组合；档位 $12$ 只出现一次，不能形成组合。

### 样例 3

**输入**

```text
[-5, -3, -1, 1],2
```

**输出**

```text
3
```

**说明**

满足要求的组合为 $(-5, -3)$、$(-3, -1)$、$(-1, 1)$。
