# P5382 测试数据说明

共 $10$ 组。每组文件内有 $q$ 条任务（$1\le q\le 10$），每条任务 $m$ 道彩门。沿当前方向贪心揭门，统计最少换向次数，不能揭完为 $-1$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 三任务 | `0 / 1 / -1` | 漏掉 `-1`、把 `[1,0]` 当成 `0` |
| 2 | 样例2 `[1,0,2]` | 换向 `2` 次 | 只扫一轮或认为最多换 `1` 次 |
| 3 | 样例3 右侧可链式揭开 | 换向 `1` 次 | 提前掉头导致多算 |
| 4 | $m=1$、全 $0$、阈值过大 | 边界 | 没有 $0$ 仍输出 `0` |
| 5 | 递增 / 递减 / 之字 / 死锁 | 结构 | 递减当成 `0`；`[0,2,2]` 误判可解 |
| 6 | $0$ 在中间或右侧，$w_i\ge m$ | 位置 | 默认必须从下标 `0` 开始揭；忽略 $w_i\ge m$ |
| 7 | 短之字 $m=1..7$ | 多次换向 | 换向后下标没踏回数组 |
| 8 | 随机小 $m\le 20$ | 对拍 | 漏任务、I/O 行数错 |
| 9 | $q=10,m=500$ 构造 | 压测 | $O(m^3)$ 或递归 |
| 10 | $q=10,m=500$ 混合 | 压测 | 同上 |

前 $8$ 组小；后 $2$ 组压测。
