# 彩门换向

## 解题思路

花车不能移动，彩门按当前牵引方向依次经过。初始从左到右。每次经过时，若当前绶带数不小于该门阈值且尚未揭开，就揭开并令绶带加 $1$。

1. 贪心：在当前方向上一直走到尽头，能揭就揭。提前掉头只会增加换向次数，不会减少。
2. 走到尽头后若已经全部揭开，答案就是已经换向的次数。
3. 若本趟一扇都没揭开，说明剩下彩门的阈值都大于当前绶带数，输出 `-1`。
4. 否则换向，从另一端再扫一趟，换向次数加 $1$。
5. 初始绶带为 $0$，因此若没有阈值为 $0$ 的门，第一趟必然毫无进展，答案为 `-1`。某扇门阈值不小于彩门总数时，绶带最多加到 $m-1$，同样永远揭不开。

模拟即可。$m \le 5\times 10^2$，每趟至少揭开一扇，趟数不超过 $m$，总复杂度可接受。

## 复杂度分析

设单条任务彩门数为 $m$，任务条数为 $q$。

时间复杂度为 $O(q m^2)$。

空间复杂度为 $O(m)$。

## 代码实现

### Python

```python
# 沿当前方向扫描，能揭就揭；整趟没有进展则失败，否则掉头继续


def min_turns(w):
    n = len(w)
    opened = [False] * n
    keys = 0
    done = 0
    ans = 0
    d = 1
    i = 0
    while done < n:
        gained = 0
        # 沿当前方向走到尽头，路过能揭的彩门就揭
        while 0 <= i < n:
            if (not opened[i]) and keys >= w[i]:
                opened[i] = True
                keys += 1
                done += 1
                gained += 1
            i += d
        if done == n:
            return ans
        # 这一趟一扇都没揭开，剩下的阈值永远够不着
        if gained == 0:
            return -1
        # 走到尽头后换向，从端点外再踏回数组
        d = -d
        i += d
        ans += 1
    return ans


def main():
    q = int(input())
    for _ in range(q):
        n = int(input())
        w = list(map(int, input().split()))
        print(min_turns(w))


if __name__ == "__main__":
    main()
```
