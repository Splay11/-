# 题目内容

给定三个字符串 $s_1, s_2, s_3$，求它们的最长公共子序列（LCS）长度，并输出字典序最小的一个 LCS 字符串。

# 输入描述

三行，每行一个仅由小写字母组成的字符串，每个字符串长度 $|s|$（$1 \le |s| \le 100$）。

# 输出描述

第一行输出 LCS 长度。

第二行输出字典序最小的 LCS 字符串（若长度为 $0$，则第二行输出空行）。

## 样例 $1$

**输入**

```text
bb
bdb
bcbb
```

**输出**

```text
2
bb
```

## 样例 $2$

**输入**

```text
bc
cbacd
bc
```

**输出**

```text
2
bc
```
