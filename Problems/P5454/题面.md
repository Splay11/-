

# 题目内容

在一张二维平面地图上分布着若干个雷达站点，每个雷达站的位置可以用整数坐标表示。

当以某一个雷达站作为中心进行探测时，如果该雷达站到另外两个不同雷达站的距离完全相同，则这三个雷达站形成一种特殊的等距探测关系。

给定平面上 $n$ 个互不相同的点 $\text{\(\text{points}\)}$，其中 $\text{\(\text{points}\)}[i] = [x_i, y_i]$，表示第 $i$ 个雷达站的坐标。

定义“等距探测三元组”为由点 $(i,j,k)$ 表示的有序三元组，满足点 $i$ 到点 $j$ 的距离等于点 $i$ 到点 $k$ 的距离，这里的距离为平面二维距离，统计并返回平面上所有等距探测三元组的数量。

需要注意三元组的顺序是有意义的：
若 $(i,j,k)$ 是一个等距探测三元组，则 $(i,k,j)$ 也应被视为另一个不同的等距探测三元组。



# 输入描述

输入第一行为点的个数 $N$。

接下来$N$行，每行包含两个整数 $x_i$ 和 $y_i$，表示一个雷达站在平面上的坐标。

点的输入顺序即为点的编号顺序。

$3 \le N \le 2000$
$-100000 \le x_i,y_i \le 100000$
所有点都互不相同



# 输出描述


请统计并返回平面上所有等距探测三元组的数量。


## 样例1 



**输入** 



```
3
0 0
1 0
2 0
```



**输出** 



```
2
```



**说明**

节点$(1,0)$到$(0,0)$、$(2,0)$点距离相同，三元组的顺序是有意义的，故返回$2$
