# 题目内容

给定一个长度为 $n$ 的整数数组 $a$，从中选取若干不相邻元素（即任意两个被选中元素的下标之差大于 $1$），使得所选元素之和最小。要求至少选取一个元素。

# 输入描述

第一行输入一个整数 $n$（$1 \le n \le 10^5$），表示数组长度。

第二行输入 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$-10^9 \le a_i \le 10^9$）。

# 输出描述

输出一个整数，表示不相邻子集的最小元素之和。

## 样例 $1$

**输入**

```text
5
3 -2 5 -1 -4
```

**输出**

```text
-6
```

## 样例 $2$

**输入**

```text
3
2 -5 3
```

**输出**

```text
-5
```
