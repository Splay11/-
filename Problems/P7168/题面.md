# 题目内容

在二维平面上给定两个边与坐标轴平行的矩形，请计算这两个矩形覆盖区域的总面积。

第一个矩形由左下角坐标 $(ax1,ay1)$ 和右上角坐标 $(ax2,ay2)$ 确定。

第二个矩形由左下角坐标 $(bx1,by1)$ 和右上角坐标 $(bx2,by2)$ 确定。

两个矩形可能发生重叠。计算总覆盖面积时，两个矩形的重叠部分只能计算一次。

# 输入描述

输入一行，共 $8$ 个整数 $ax1$、$ay1$、$ax2$、$ay2$、$bx1$、$by1$、$bx2$、$by2$。

其中 $(ax1,ay1)$ 和 $(ax2,ay2)$ 分别表示第一个矩形的左下角和右上角。

$(bx1,by1)$ 和 $(bx2,by2)$ 分别表示第二个矩形的左下角和右上角。

### 约束

$-10^4 \le ax1 \le ax2 \le 10^4$

$-10^4 \le ay1 \le ay2 \le 10^4$

$-10^4 \le bx1 \le bx2 \le 10^4$

$-10^4 \le by1 \le by2 \le 10^4$

# 输出描述

输出一个整数，表示两个矩形覆盖区域的总面积。

两个矩形发生重叠时，重叠部分的面积只计算一次。

## 样例1

**输入**

```text
-3 0 3 4 0 -1 9 2
```

**输出**

```text
45
```

**说明**

第一个矩形的面积为

$(3-(-3))\times(4-0)=24$

第二个矩形的面积为

$(9-0)\times(2-(-1))=27$

两个矩形的重叠区域横向范围为 $0$ 到 $3$，纵向范围为 $0$ 到 $2$，因此重叠面积为

$(3-0)\times(2-0)=6$

所以两个矩形覆盖的总面积为

$24+27-6=45$

## 样例2

**输入**

```text
-2 -2 2 2 -2 -2 2 2
```

**输出**

```text
16
```

**说明**

两个矩形完全重合。

单个矩形的面积为

$(2-(-2))\times(2-(-2))=16$

由于重叠区域不能重复计算，因此两个矩形覆盖的总面积为 $16$。
