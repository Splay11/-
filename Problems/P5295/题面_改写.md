**34、Hive 中音乐表 `music`、收藏表 `user_music`、关注表 `user_follow` 如下。**

`music`：

| id | name |
|----|------|
| 1 | 漠河舞厅 |
| 2 | 天外飞来物 |
| 3 | 金玉良缘 |
| 4 | 天下无双 |
| 5 | 一笑江湖 |

`user_music`：

| user_id | music_id |
|----|------|
| 1 | 1 |
| 2 | 1 |
| 3 | 2 |
| 4 | 3 |

`user_follow`：

| user_id | follow_id |
|----|------|
| 1 | 3 |
| 1 | 4 |
| 2 | 1 |

执行：

```sql
SELECT
    m.user_id AS user_id,
    concat_ws(',', collect_set(n.music_name))
FROM
(
    SELECT user_id, follow_id
    FROM user_follow
    WHERE user_id = 1
) m
LEFT JOIN
(
    SELECT
        t0.user_id AS user_id,
        t0.music_id AS music_id,
        t1.name AS music_name
    FROM user_music t0
    LEFT JOIN music t1
    ON t0.music_id = t1.id
) n
ON m.follow_id = n.user_id
GROUP BY m.user_id
```

输出应是？
{{ select(34) }}
- `1 天下无双,金玉良缘`
- `1 天外飞来物,金玉良缘`
- `1 天外飞来物,漠河舞厅`
- `1 天外飞来物,一笑江湖`
