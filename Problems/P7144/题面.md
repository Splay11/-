# 题目内容

给定一个由小写英文字母组成的字符串 $s$，请找出其中由连续元音字母组成的最长子串。

元音字母包括 $a$、$e$、$i$、$o$、$u$。

例如，在字符串 $abcaeioubc$ 中，子串 $aeiou$ 由连续的元音字母组成，其长度为 $5$。

如果存在多个长度相同的最长连续元音子串，输出最先出现的一个。

如果字符串中不存在元音字母，则输出 $-1$。

# 输入描述

输入一行字符串 $s$，表示给定的字符串。

### 约束

$1 \le |s| \le 10^5$

字符串 $s$ 仅由小写英文字母组成。

# 输出描述

输出一个字符串，表示 $s$ 中最长的连续元音字母子串。

如果存在多个长度相同的最长子串，输出最先出现的一个。

如果不存在元音字母，则输出 $-1$。

## 样例1

**输入**

```text
abcaeioubc
```

**输出**

```text
aeiou
```

**说明**

字符串中连续的元音字母子串包括 $a$ 和 $aeiou$。

其中 $aeiou$ 的长度为 $5$，是最长的连续元音字母子串，因此输出 $aeiou$。

## 样例2

**输入**

```text
beautiful
```

**输出**

```text
eau
```

**说明**

字符串中的连续元音字母子串包括 $eau$、$i$ 和 $u$。

其中 $eau$ 的长度为 $3$，最长，因此输出 $eau$。

## 样例3

**输入**

```text
bcdfg
```

**输出**

```text
-1
```

**说明**

字符串中不存在元音字母，因此输出 $-1$。
