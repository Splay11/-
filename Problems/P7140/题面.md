# 题目内容

给定一个字符串 $s$，请判断 $s$ 是否表示一个有效数字。

一个有效数字可以按照以下两种形式之一表示：

* 一个整数，后面可以跟一个可选的指数。
* 一个小数，后面可以跟一个可选的指数。

其中，一个整数由一个可选符号 $+$ 或 $-$，后面跟着一个或多个数字组成。

一个小数由一个可选符号 $+$ 或 $-$，后面满足以下三种形式之一：

* 一个或多个数字，后面跟一个小数点 $.$。
* 一个或多个数字，后面跟一个小数点 $.$，再跟一个或多个数字。
* 一个小数点 $.$，后面跟一个或多个数字。

指数由指数符号 $e$ 或 $E$ 开始，后面必须跟一个整数。

数字由一个或多个 $0$ 到 $9$ 之间的字符组成。

例如，以下字符串都是有效数字：

$"2"$、$"0089"$、$"-0.1"$、$"+3.14"$、$"4."$、$"-.9"$、$"2e10"$、$"-90E3"$、$"3e+7"$、$"+6e-1"$、$"53.5e93"$、$"-123.456e789"$。

而以下字符串不是有效数字：

$"abc"$、$"1a"$、$"1e"$、$"e3"$、$"99e2.5"$、$"--6"$、$"-+3"$、$"95a54e53"$。

# 输入描述

输入一行字符串 $s$，表示需要判断的字符串。

### 约束

$1 \le |s| \le 20$

字符串 $s$ 仅包含英文字母、数字 $0$ 到 $9$、加号 $+$、减号 $-$ 和小数点 $.$。

# 输出描述

如果字符串 $s$ 表示一个有效数字，输出 $true$。

否则输出 $false$。

## 样例1

**输入**

```text
0
```

**输出**

```text
true
```

**说明**

字符串 $"0"$ 是一个合法的整数，因此是有效数字。

## 样例2

**输入**

```text
e
```

**输出**

```text
false
```

**说明**

指数符号 $e$ 前后均没有合法的数字部分，因此 $"e"$ 不是有效数字。

## 样例3

**输入**

```text
.
```

**输出**

```text
false
```

**说明**

小数点 $.$ 的前后均不存在数字，不符合小数的定义，因此 $"."$ 不是有效数字。
