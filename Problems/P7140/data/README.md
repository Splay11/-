# P7140 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：一行字符串 $s$。
输出：$true$ 或 $false$（小写）。

约束：$1\le |s|\le 20$，$s$ 只含字母、数字、正负号和小数点。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1 | 整数 $0$ 合法 | 把前导零当非法 |
| 2 | 样例 2 | 单独 $e$ 非法 | 指数没有底数仍输出 true |
| 3 | 样例 3 | 单独小数点非法 | 把 $.$ 当成小数 |
| 4 | 数字加小数点 | 合法小数 | 要求小数点后必须有数字 |
| 5 | 符号加 $.9$ | 合法小数 | 要求小数点前必须有数字 |
| 6 | 整数带指数 | 合法 | 没处理指数 |
| 7 | 指数部分是小数 | 非法 | 指数里允许小数点 |
| 8 | 两个符号 | 非法 | 只看了有没有数字 |
| 9 | 较长合法串，小数加指数 | 合法 | E 和 e 只认一种 |
| 10 | 数字中间夹字母 | 非法 | 扫到 $e$ 就忽略前面的 $a$ |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：规则解析必须等于正则 `fullmatch`。
