# 色号喷涂最少次数

## 解题思路

喷涂色号必须字典序不降，所以较小色号一定先喷完。挪喷头不计次数，一次喷涂只能在当前空隙留下一段连续相同色号。

1. 喷色号 $x$ 时，所有更小的色号已经在灯带上，所有更大的色号还没出现。因此最终串里被更大字母隔开的两段 $x$，当时其实还连在一起，可以一次喷完。
2. 若两段 $x$ 中间已经夹着更小色号，喷头过不去这段已有格子，必须再启动一次。
3. 于是对每个色号 $x$，先丢掉 $w$ 里所有大于 $x$ 的字符，再统计剩下序列中 $x$ 的连续段数，把 `26` 个色号的段数加起来就是答案。
4. 每个色号扫一遍 $w$，总时间与长度成正比。

## 复杂度分析

- 时间复杂度：$O(26\cdot |w|)$。
- 空间复杂度：$O(|w|)$。

## 代码实现

### Python

```python
def solve(w):
  # 对每个色号，先丢掉比它大的格子，再数它自己的连续段
  # 更大色号后喷，不会隔开当前这一次喷涂
  ans = 0
  for c in range(26):
    ch = chr(ord("a") + c)
    in_run = False
    for x in w:
      if x > ch:
        continue
      if x == ch:
        if not in_run:
          ans += 1
          in_run = True
      else:
        # 碰到更小色号，当前段被已经喷好的格子隔开
        in_run = False
  return ans


w = input().strip()
print(solve(w))
```

### Java

```java
import java.util.Scanner;

public class Main {
  static int solve(String w) {
    // 对每个色号，先丢掉比它大的格子，再数它自己的连续段
    int ans = 0;
    int n = w.length();
    for (int c = 0; c < 26; c++) {
      char ch = (char) ('a' + c);
      boolean inRun = false;
      for (int i = 0; i < n; i++) {
        char x = w.charAt(i);
        if (x > ch) continue;
        if (x == ch) {
          if (!inRun) {
            ans++;
            inRun = true;
          }
        } else {
          // 碰到更小色号，当前段被已经喷好的格子隔开
          inRun = false;
        }
      }
    }
    return ans;
  }

  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    String w = sc.next();
    System.out.println(solve(w));
    sc.close();
  }
}
```

```c
#include <stdio.h>
#include <string.h>

int solve(char *w) {
  int ans = 0, c, i, n = (int)strlen(w);
  for (c = 0; c < 26; c++) {
    char ch = (char)('a' + c);
    int in_run = 0;
    for (i = 0; i < n; i++) {
      char x = w[i];
      if (x > ch) continue;
      if (x == ch) {
        if (!in_run) {
          ans++;
          in_run = 1;
        }
      } else {
        in_run = 0;
      }
    }
  }
  return ans;
}

int main(void) {
  static char w[100005];
  scanf("%s", w);
  printf("%d\n", solve(w));
```
