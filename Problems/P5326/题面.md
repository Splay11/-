# 题目内容

小美需要输入一串仅由小写字母组成的密码。
她可以进行两类操作：
- 按下一个小写字母键：选择某个字母 $x \in \{a,\dots,z\}$ 和一个正整数 $k$，在当前光标位置一次性插入 $k$ 个字母 $x$，记为 $1$ 次“按键”；
- 鼠标点击：将光标移动到当前文本中任意一个位置（包括两字符之间或首尾处），鼠标点击次数不计入答案。

同时，小美要求所有字母键的按下操作必须遵循字典序不降的规则。具体而言，若某次按下了字母 $x_1$ 键，那么下一次按下的任何字母 $x_2$ 键，都必须满足 $x_2 \ge x_1$（按字典序比较）。这意味着，一旦按下了例如 'c' 键，就再也不能按 'a' 或 'b' 键了。

给定目标字符串 $s$，请计算：在满足上述约束的前提下，得到 $s$ 所需的最少“按键次数”（只统计字母键的次数，鼠标不计）。



# 输入描述


输入一行仅由小写字母构成的字符串 $s(1 \le |s| \le 10^5)$，代表目标密码字符串。


# 输出描述

输出一个整数，表示构造出目标字符串所需要的最少按键次数。



## 样例1 



**输入** 



```
abac
```



**输出** 



```
3
```



**说明**

一种可行方案：
1. 按 $1$ 次 'a'，插入 $1$ 个 'a'；
2. 按 $1$ 次 'b'，插入 $1$ 个 'b'；
3. 移动光标到末尾，按 $1$ 次 'c'，插入 $1$ 个 'c'；
再移动光标到第 $1$ 个字符之后，插入 'a'。
总按键次数为 $3$。
> 注：因为按键必须字典序不降，在已经按过 'b'、'c' 之后不能再按 'a'，所以 'a' 必须在 'b' 之前一次性全部插入或者分批在更前面的阶段插入。

## 样例2



**输入** 



```
aaabbbccc
```



**输出** 



```
3
```



**说明**

依次按 $1$ 次 'a'（插入 $3$ 个a）、$1$ 次 'b'（插入 $3$ 个b）、$1$ 次 'c'（插入 $3$ 个c），总按键次数为 $3$。

## 样例2



**输入** 



```
cba
```



**输出** 



```
3
```



**说明**


按键顺序必须不降，不能先c再b再a，因此只能分别三次按键，再通过光标调整顺序，总按键次数为 $3$。
