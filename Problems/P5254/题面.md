# 多多凑单王

# 题目内容

拼多多正在举办「百亿补贴·神秘三件套」活动。参与活动需要从商城中选出价格分别为 $a$、$b$、$c$ 的三件商品，价格范围从 $1$ 到 $n$ 元，组成一个「盲盒套装」。

为防止恶意薅羊毛，系统设置了三条「风控规则」，套装必须同时满足才能下单：

1. 价格非降：$1 \le a \le b \le c \le n$。
2. 为增加趣味性，三件商品价格的二进制异或和必须为 $0$：
$$a \oplus b \oplus c = 0$$
3. 三角形原则：任意两件商品价格之和必须严格大于第三件。结合规则 1，即 $a+b>c$。

请统计有多少个三元组 $(a,b,c)$ 满足上述全部条件。

# 输入描述

输入一个整数 $n$。

$1 \le n \le 2500$

# 输出描述

输出满足条件的套装数量。

## 样例1

**输入**

```
6
```

**输出**

```
1
```

**说明**

商品价格可以是 $(3, 5, 6)$。

- 规则 1：$1 \le 3 \le 5 \le 6 \le 6$
- 规则 2：$3 \oplus 5 \oplus 6 = 0$（因为 $3 \oplus 5 = 6$）
- 规则 3：$3+5=8>6$

## 样例2

**输入**

```
10
```

**输出**

```
2
```

**说明**

满足全部风控规则的套装共有 $2$ 组。
