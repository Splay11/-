# 逻辑回归二分类

## 解题思路

本题按题面给定的批量梯度下降训练逻辑回归，并用训练好的模型预测测试集，接口为 `Solution.logisticRegression(...)`。

1. 初始化 $W=0$，$b=0$，不做特征归一化。
2. 每轮计算 $p=\mathrm{sigmoid}(XW+b)$ 与交叉熵损失。
3. 按 $W\leftarrow W-\alpha\cdot\frac{1}{n}X^{T}(p-y)$，$b\leftarrow b-\alpha\cdot\mathrm{mean}(p-y)$ 更新。
4. 当损失变化绝对值 $\le tol$ 或达到 $max\_iter$ 时停止。
5. 对测试样本输出类别（概率 $\ge 0.5$ 为 $1$）与概率。

## 复杂度分析

时间复杂度为 $O(max\_iter\cdot n\cdot d)$，本题 $d=3$。

空间复杂度为 $O(n\cdot d)$。

## 代码实现

### Python

```python
import math


class Solution:
    def logisticRegression(self, X, y, max_iter, alpha, tol, X_test):
        """按题面批量梯度下降训练逻辑回归，返回测试集 (类别, 概率)。"""
        n = len(X)
        d = len(X[0])
        W = [0.0] * d
        b = 0.0

        def sigmoid(z):
            # 数值稳定 sigmoid
            if z >= 0:
                return 1.0 / (1.0 + math.exp(-z))
            ez = math.exp(z)
            return ez / (1.0 + ez)

        prev_loss = None
        for _ in range(max_iter):
            # 前向：p = sigmoid(XW + b)
            p = []
            for i in range(n):
                z = b
                for j in range(d):
                    z += X[i][j] * W[j]
                p.append(sigmoid(z))
            # 交叉熵损失
            loss = 0.0
            for i in range(n):
                pi = min(max(p[i], 1e-15), 1.0 - 1e-15)
                loss -= y[i] * math.log(pi) + (1.0 - y[i]) * math.log(1.0 - pi)
            loss /= n
            if prev_loss is not None and abs(prev_loss - loss) <= tol:
                break
            prev_loss = loss
            # 梯度更新
            diff = [p[i] - y[i] for i in range(n)]
            for j in range(d):
                g = 0.0
                for i in range(n):
                    g += X[i][j] * diff[i]
                W[j] -= alpha * g / n
            b -= alpha * (sum(diff) / n)

        out = []
        for row in X_test:
            z = b
            for j in range(d):
                z += row[j] * W[j]
            prob = sigmoid(z)
            label = 1 if prob >= 0.5 else 0
            out.append((label, prob))
        return out
```
