# 数值稳定 Sigmoid

## 解题思路

1. 按定义计算 $\sigma(x)=\dfrac{1}{1+e^{-x}}$，导数为 $\sigma'(x)=\sigma(x)(1-\sigma(x))$。
2. 当 $x<0$ 时改用等价式 $\sigma(x)=\dfrac{e^{x}}{1+e^{x}}$，避免 $e^{-x}$ 过大溢出。
3. 在 `Solution.stableSigmoid` 中对每个输入分别求函数值与导数并返回。

## 复杂度分析

- 时间复杂度：$O(n)$，遍历全部输入一次。
- 空间复杂度：$O(n)$，存放输出。

## 代码实现

### Python

```python
from typing import List
import math


class Solution:
    def stableSigmoid(self, x: List[float]) -> List[List[float]]:
        """数值稳定 Sigmoid 及其导数，返回 [sigmoid, derivative]。"""
        sig, der = [], []
        for v in x:
            # x<0 时用 e^x/(1+e^x)，避免 exp(-x) 溢出
            if v < 0:
                e = math.exp(v)
                s = e / (1.0 + e)
            else:
                s = 1.0 / (1.0 + math.exp(-v))
            sig.append(s)
            # 导数 sigma * (1 - sigma)
            der.append(s * (1.0 - s))
        return [sig, der]
```
