# 题目内容


$Tk$ 有 $n$ 个六面骰子，掷出后得到点数序列 $\{a_1,a_2,\dots,a_n\}$，其中每个 $a_i \in \{1,2,3,4,5,6\}$；她统计到所有骰子点数之和为 $s$。

随后，他的猫悄悄偷走了这 $n$ 颗骰子中点数最大的 $d$ 颗，将剩余 $n-d$ 颗的点数之和记为 $r$。已知 $1 \le d < n$，且偷走的一定是最大点数的骰子（若存在多颗最大点数，猫任意偷走其中 $d$ 颗）。

现在你只知道整数 $(n,d,s,r)$，请还原出一组可能的原始掷骰子点数序列 ${a_1,a_2,\dots,a_n}$，使得：
- 每个 $a_i \in {1,2,3,4,5,6}$；
- 原序列和为 $s$；
- 丢弃点数最大的 $d$ 颗后，剩余和为 $r$。

若不存在满足条件的序列，则输出 $-1$。



# 输入描述


每个测试文件均包含多组测试数据。第一行输入一个整数 $T(1 \le T \le 10^4)$ 代表数据组数，每组测试数据描述如下：

在一行上输入四个整数 $(n,d,s,r)$（$2 \le n \le 2 \times 10^5$；$1 \le d < n$；$1 \le r < s \le 1.2 \times 10^6$）

除此之外，保证所有测试数据的 $\sum n \le 2 \times 10^5$。


# 输出描述

对于每组测试：

如果有解，输出一行 $n$ 个整数，代表任意一个合法骰子序列；

无解输出 $-1$。



## 样例1 



**输入** 



```
2
3 1 10 4
2 1 7 2
```



**输出** 



```
4 6 0
4 3
2 5
```



**说明**

$(n=3,d=1,(s=10),r=4)$，总总和$(s=10)$，拿走最大 $1$ 颗后剩下 $2$ 颗和为 $4$，被拿走那一颗是 $10-4=6$；剩余两颗总和 $4$，取值 $([1,3])$，完整序列 $1$ $3$ $6$。输出可以任意顺序。
