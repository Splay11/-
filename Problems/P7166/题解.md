# 回文数

算法标签：数学

算法难度：$2 / 10$

## 解题思路

判断 $32$ 位整数从左往右和从右往左是否一样。

1. 负数带负号，反着读负号会跑到末尾，一定不是回文。
2. 以 $0$ 结尾且本身不是 $0$ 的数（如 $10$），反过来会有前导 $0$，也不是回文。
3. 只翻转后半段数字：当翻转值已经不小于剩下的前半段时停止，避免把整个数翻过来溢出。
4. 偶数位要求两半相等；奇数位中间那一位可以丢掉再比。
5. $0$ 本身是回文。常见假解：把负数当回文；把 $10$ 判成 $true$；整段翻转导致溢出。

## 复杂度分析

- 时间复杂度：$O(\log |x|)$。
- 空间复杂度：$O(1)$。

## 代码实现

### Python

```python
def solve(x):
    """负数带符号，从右往左读符号会跑到末尾，一定不是回文。
    不以 0 结尾（除了 0 本身）。翻转后半段数字，和前半段比较。
    """
    if x < 0:
        return False
    if x != 0 and x % 10 == 0:
        return False
    rev = 0
    while x > rev:
        rev = rev * 10 + x % 10
        x //= 10
    return x == rev or x == rev // 10


def main():
    x = int(input())
    print("true" if solve(x) else "false")


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class Main {
    static boolean solve(int x) {
        if (x < 0) return false;
        if (x != 0 && x % 10 == 0) return false;
        int rev = 0;
        while (x > rev) {
            rev = rev * 10 + x % 10;
            x /= 10;
        }
        return x == rev || x == rev / 10;
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int x = Integer.parseInt(br.readLine().trim());
        System.out.println(solve(x) ? "true" : "false");
    }
}
```
