# P5456 测例说明

输入：首行 $p,e,a,b$，随后 $e$ 行 $x\ y\ c\ z$，再一行 $q$，若 $q>0$ 再一行同伴位置。输出一个整数（分钟）。`.in` 末尾无换行，`.out` 末尾恰好一个换行。

分层（每组 10 分）：

- 1：二级样例 1。只接一人更优，答案 $20$。
- 2：二级样例 2。必须绕路去接，答案 $40$。
- 3：$q=0$，只有驾车 $a\to b$。
- 4：同伴已在馆子，步行 $0$。
- 5：全接上车更优（步行太远）。
- 6：单向链。卡把 $z=0$ 当成双向。
- 7：两名同伴在同一路口。
- 8：最近邻贪心接人不是最优。
- 9：上限 $p=10^3,q=15$ 随机链。压测 Dijkstra + $2^{q}$。
- 10：上限链 + 全接/半接权衡。

hack 点：速度乘反、单向当双向、必须全接、最近邻贪心、$q=0$。
