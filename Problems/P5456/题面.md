# 题目内容

小红计划与$k$位朋友在城中的某餐厅聚餐。

小红、朋友和餐厅间的道路有的只允许单向通行（包含人和车），有的可双向通行。小红开车速度为$2$分钟/公里，朋友步行速度为$10$分钟/公里。

给定小红出发点、餐厅位置以及每位朋友的位置，小红可以选择：
1. 直接开车去餐厅
2. 途中绕路接上部分朋友一起前往餐厅
3. 不接的朋友会自行步行前往餐厅

每位朋友只能选择一种方式：要么被小红接上车，要么自己步行，不能中途改变。

请你设计一个算法，计算在最优策略下，所有人到达餐厅所需的最短时间（即最后一个人到达的时间）。



# 输入描述


第一行：四个整数$n, m, s, t$
- $n$: 城市路口总数 ($1 \le n \le 1000$)
- $m$: 道路总数 ($1 \le m \le 1000$)
- $s$: 小红出发点路口编号 ($1 \le s \le n$)
- $t$: 餐厅所在路口编号 ($1 \le t \le n$)

接下来$m$行：每行四个整数$u, v, w, d$，表示路口$u$和路口$v$之间有一条长度为$w$($1 \le w \le 100$)公里的道路，$d$表示路口$u$到路口$v$的道路为单向($d$为$0$)或双向($d$为$1$)道路。

第$m+2$行：一个整数$k$($0 \le k \le 15$)，表示朋友数量。

第$m+3$行：$k$个整数，表示每位朋友所在的路口编号。


# 输出描述

一个整数，表示所有人到达餐厅的最短时间（分钟）。



## 样例1 



**输入** 



```
6 7 1 6
1 2 2 1
1 3 3 1
2 4 1 0
3 4 1 0
3 5 2 0
4 6 3 1
5 6 2 1
3
2 3 5
```



**输出** 



```
22
```



**说明**

![](file://kJTxPOaGdBcM2pOikwy7N.png)




当前有$6$个路口和$7$条道路；

小红在路口$1$，餐厅在路口$6$，$3$位朋友分别在路口$2$、$3$、$5$；

小红开车通过路口$1$->$2$->$1$->$3$->$5$->$6$，接上所有朋友，到达餐厅总距离$11$公里，开车总耗时$22$分钟，时间最短。

## 样例2



**输入** 



```
6 7 1 6
1 2 2 1
1 3 3 1
2 4 2 0
3 4 1 0
3 5 2 0
4 6 3 1
5 6 2 1
3
2 4 5
```



**输出** 



```
20
```



**说明**

![](file://arTKXO6yLlmhGiNeHp2VS.png)




当前有$6$个路口和$7$条道路；

小红在路口$1$，餐厅在路口$6$，$3$位朋友分别在路口$2$、$4$、$5$；

小红开车通过路口$1$->$2$->$4$->$6$，接上朋友$1$和朋友$2$，到达餐厅总距离$7$公里，开车总耗时$14$分钟；朋友$3$自己步行前往餐厅距离$2$公里，耗时$20$分钟。
因此，时间最短为$20$分钟。

## 提示
1. 不考虑车辆承载上限
2. 每个道路和路口可重复通过
3. 用例不存在有人不可到达餐厅的情况
