# P5378 测试数据说明

共 $10$ 组。每组 $q$ 条询问，每条一个长度 $m$，统计长度为 $m$、无四连相同小写字母的串数，模 $1000000007$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 $m=1,3,5$ | 小长度 | $m=1$ 输出 $0$ |
| 2 | 样例2 $m=6,8$ | 取模后的中等值 | 未取模 |
| 3 | 样例3 $m=7$ | 取模后变小 | 认为答案随 $m$ 单调增 |
| 4 | $1..4$ | $m=4$ 应为 $26^4-26$ | 全程 $26^m$ |
| 5 | $9..12$ | 转移累计 | 只减 $26$ 种全同串 |
| 6 | $13,20,26,27$ | 更长 | 把三连也判非法 |
| 7 | $1..15$ 全覆盖 | 递推初值 | $f_2,f_3$ 初值写错 |
| 8 | 随机 $m\le 80$，$q=30$ | 对拍 | 询问行数错 |
| 9 | $q=200000$，扫遍 $1..200000$ | 压测预处理与 I/O | 每询问现场 $O(m)$ |
| 10 | $q=200000$，极值 $1/4/200000$+随机 | 压测 | `int` 乘 $25$ 溢出 |

前 $8$ 组小；后 $2$ 组压测。
