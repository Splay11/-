# 答案与解析

**1、答案：B**

Linux 下标准的 IO 多路复用是 `select`、`poll`、`epoll`。不存在 `eselect`。A、C、D 分别对应 poll、epoll、select 的真实机制。

**2、答案：C**

二叉排序树遇到更大的键就往右挂。序列严格递增，每个新货位号都比已有结点大，一直插在最右侧，得到右向单支树。完美树、堆序按层填满、只留左孩子的递减链都不是这条插入路径。

**3、答案：D**

三阶段流水线，读码枪与喷码机各一台。第一份工单采集+核算+喷码共 $2+3+4=9\mathrm{ms}$；瓶颈在喷码，之后每份再占 $4\mathrm{ms}$。总时间 $9+3\times 4=21\mathrm{ms}$。$9\mathrm{ms}$ 只完成第一份，$17\mathrm{ms}$ 只算到第三份，$13\mathrm{ms}$ 少计了后续喷码。

**4、答案：A**

mysqldump 导出 `CREATE TABLE`、`INSERT` 一类 SQL，恢复时重放语句，属于逻辑备份。停库打包数据文件、二进制日志回放、存储引擎页拷贝都不是 mysqldump 的做法。

**5、答案：C**

SQL Server 的 `like '[王,赵]%'` 表示首字为王或赵、后面任意长度。用 `=` 时通配符不生效；`group by` 加精确 `like '王'` 对不上复姓以外的姓名；取第 $2$ 个字符当姓，位置错了。
