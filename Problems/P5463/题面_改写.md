**5、变电站检修班组人事库中，表结构如下：①检修员表(工号,姓名,性别,出生日期,入职日期,班组编号) ②出勤表(工号,年份,月份,出勤量)。若完成操作：显示所有姓“王”和“赵”的检修员信息。以下操作可行的是：（）**
{{ select(5) }}
- select * from 检修员表 where 姓名 = '王%' or 姓名 = '赵%'

- select * from 检修员表 where 姓名 like '[王,赵]%'
- select * from 检修员表 where substring(姓名,2,1) in ('王','赵')
