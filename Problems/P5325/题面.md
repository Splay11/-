# 题目内容


你正在研究密码强度。

给你一个数字 $n$，让你构造一个长度为 $n$ 的字符串，要求只能含有小写字母并且构造出的字符串不能含有超过三个连续一样的字符，例如 aaaa、bbbb 等就不符合要求，而 aaabaaa 就符合要求。

现在给你这个 $n$，问你能构造出多少满足要求的字符串。由于答案可能很大，请将答案对 $10^9 + 7$ 取模后输出。



# 输入描述


每个测试文件均包含多组测试数据。第一行输入一个整数 $T(1 \le T \le 2 \times 10^5)$，代表数据组数，每组测试数据描述如下：

在一行上输入一个整数 $n(1 \le n \le 2 \times 10^5)$，表示字符串长度。



# 输出描述


对于每一组测试数据，新起一行输出一个整数，表示满足要求的字符串数量。


## 样例1 



**输入** 



```
2
2
4
```



**输出** 



```
676
456950
```



**说明**

对于第一组测试数据，$n$ 为 $2$ 的时候所有情况均满足要求，故答案为 $26 \times 26$。

对于第二组测试数据，$n$ 为 $4$ 的时候，总方案数为 $26^4$。不符合要求的字符串是那些含有 $4$ 个连续相同字符的子串。在长度为 $4$ 的字符串中，这只可能是 aaaa、bbbb、…、zzzz 这 $26$ 种情况。因此答案为 $26^4 - 26$。
