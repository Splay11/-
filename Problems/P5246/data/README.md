# P5246 测试数据说明

输入为紧凑单行 JSON（键 `records` / `min_cnt`），与改写题面样例同形。
约束：$1\le n\le 24$，每条记录互异整数且长度 $\le 4$，$\textit{min\_cnt}\ge 1$。

| 编号 | 类型 | 说明 | 针对的错误解 |
|---:|---|---|---|
| 1 | 样例 | 样例1：二元项集部分被阈值丢掉 | — |
| 2 | 样例 | 样例2：三元频繁项集存活 | — |
| 3 | 边界 | 边界：n=1、单项、min_cnt=1 | 漏掉 n=1 / 单项 |
| 4 | 边界 | 边界：min_cnt>n，结果为空；含空记录 | min_cnt 大于出现次数仍输出项集；空记录当非法 |
| 5 | hack | hack：子集计数而非整条记录相等（{1,2} 被 {1,2,3} 包含） | 用记录相等代替子集包含 |
| 6 | hack | hack：编号按数值字典序（2<10<11，不能当字符串比） | 把编号当字符串排序 |
| 7 | hack | hack：同支持的真子集也要输出（非极大/非闭项集） | 只输出极大项集或闭项集 |
| 8 | 随机 | 随机小数据：n=10，编号 1..8 | 随机噪声下计数/排序漂移 |
| 9 | 构造/压力 | 大数据：n=24，全集 6 个编号、每条 4 项，min_cnt=8 | 层数到 4、候选剪枝与计数 |
| 10 | 构造/压力 | 大数据：n=24 拉满，记录无序，min_cnt=1 | min_cnt=1 时项集多、记录无序 |
