# 抽检共现项集

## 解题思路

本题要求按 $Apriori$ 挖掘全部频繁项集，输出带支持计数的项集列表。算法核是「逐层生成候选 → 子集剪枝 → 扫描计数」。

1. 把每条记录看成集合。扫描全部记录，统计每个单项编号的出现次数，次数 $\ge \textit{min\_cnt}$ 的单项组成频繁 $1$-项集 $G_1$。
2. 对 $k\ge 2$，用 $G_{k-1}$ 两两连接生成 $k$-项候选：两项的前 $k-2$ 个元素相同，且第一项末元素小于第二项末元素。若候选的某个 $(k-1)$ 元子集不在 $G_{k-1}$ 中，则丢弃（$Apriori$ 性质：非频繁项集的超集必非频繁）。
3. 候选 $X$ 的支持计数为包含它的记录条数
   $$\mathrm{sup}(X)=\bigl|\{R\mid X\subseteq R\}\bigr|$$
   满足 $\mathrm{sup}(X)\ge \textit{min\_cnt}$ 的进入 $G_k$。$G_k$ 为空时停止。
4. 合并全部 $G_k$，按项集大小升序、同大小按编号字典序输出；每个项集内部编号升序，并附带支持计数。

常见假解：

- 把「子集」做成「与某条记录完全相等」，漏计被更长记录包含的项集；
- 只输出极大项集或闭项集，丢掉同支持的真子集；
- 按字符串比较编号（$10$ 会排到 $2$ 前面）；
- 把 $\textit{min\_cnt}$ 当成相对支持率。

本题数据规模很小（$n\le 24$，每条至多 $4$ 项），按上述过程实现即可。按题目要求仅提供 $Python3$。

## 复杂度分析

- 时间复杂度：项集宽度至多为 $4$，候选规模为常数级；每层对 $n$ 条记录扫描，总体 $O(n)$ 量级。
- 空间复杂度：$O(n)$，用于存放记录集合与当前层频繁项集。

## 代码实现

### Python

```python
import json
from itertools import combinations


def support_of(itemset, recs):
    # 支持计数：有多少条记录把该候选项集当成子集
    s = set(itemset)
    return sum(1 for r in recs if s <= r)


def frequent_itemsets(records, min_cnt):
    recs = [set(r) for r in records]
    cnt = {}
    for r in recs:
        for x in r:
            cnt[x] = cnt.get(x, 0) + 1
    # G1：频繁 1-项集
    G = sorted((x,) for x, c in cnt.items() if c >= min_cnt)
    U = []
    while G:
        G_set = set(G)
        k = len(G[0])
        for itemset in G:
            U.append([list(itemset), support_of(itemset, recs)])
        D = []
        # 连接：前 k-2 项相同且末项升序
        for i in range(len(G)):
            for j in range(i + 1, len(G)):
                a, b = G[i], G[j]
                if a[:-1] == b[:-1] and a[-1] < b[-1]:
                    cand = a + (b[-1],)
                    # 剪枝：任一 (k-1) 子集都必须频繁
                    ok = True
                    for sub in combinations(cand, k):
                        if sub not in G_set:
                            ok = False
                            break
                    if ok:
                        D.append(cand)
        G = []
        for cand in D:
            if support_of(cand, recs) >= min_cnt:
                G.append(cand)
        G.sort()
    # 先按大小，再按字典序
    U.sort(key=lambda x: (len(x[0]), x[0]))
    return U


def read_json():
    chunks = []
    while True:
        try:
            chunks.append(input())
        except EOFError:
            break
    return json.loads("\n".join(chunks))


def main():
    data = read_json()
    ans = frequent_itemsets(data["records"], data["min_cnt"])
    print(json.dumps(ans))


if __name__ == "__main__":
    main()
```
