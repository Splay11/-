## 题目内容

在云计算基础设施中，CI/CD 流水线由一系列任务组成，任务队列由一个数组表示，每个元素的值表示执行任务所需要的时间。

由于资源限制，你不能执行所有任务。规则如下：

1. 从任务队列头节点开始遍历
2. 对于每个任务，你可以选择执行或跳过
3. 如果执行任务，消耗对应的时间
4. 如果跳过任务，不消耗时间，但可以继续遍历后续任务
5. 关键的约束：连续跳过的任务数量不能超过 $maxSkip$ 个
6. 目标：在满足上述约束的前提下，恰好完成 $K$ 个任务，并使总执行时间最小

## 输入描述

- $head$: 任务节点数组，$node.val$ 表示任务的执行时间
- $k$: int - 需要完成的任务数量
- $maxSkip$: int - 最大连续跳过数量

参数约束：

- $0 <= head.length <= 1000$
- $1 <= node.val <= 10000$
- $0 <= k <= head.length$
- $0 <= maxSkip <= 1000$

## 输出描述

int - 最小总执行时间；无任务序列($head.length==0$)，输出0；如果无法完成至少 $K$ 个任务，返回-1

## 样例1

**输入** 

```
1 2 3 4 5
3
0
```

**输出** 

```
-1
```

**说明**
不允许跳过任务时，需要完成5个任务，无法实现执行3个任务，输出-1

## 样例2

**输入** 

```
3 1 4 2 5
3
2
```

**输出** 

```
6
```

**说明**
执行任务序列：3 → 1 → 跳过 4 → 2 → 停止

- 执行了3个任务 (3, 1, 2)
- 总时间 = 3 + 1 + 2 = 6
- 连续跳过最多1个任务 (≤ 2)

## 样例3

**输入** 

```
1 100 1 100 1
3
1
```

**输出** 

```
3
```

**说明**
执行任务序列：1 → 跳过 100 → 1 → 跳过 100 → 1

- 执行了3个任务 (第1、3、5个)
- 总时间 = 1 + 1 + 1 = 3
- 连续跳过最多1个任务 (≤ 1)

## 样例4

**输入** 

```
0
1
```

**输出** 

```
0
```

**说明**
无任务序列，输出0
