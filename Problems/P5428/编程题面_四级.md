# 题目内容

推理集群里排着一条待审作业链，一共 $m$ 项，从左到右编号 $1,2,\dots,m$。第 $p$ 项的预计耗时记为 $dur_p$。窗口算力有限，链上每一项并不都要接进来。

审阅从左端开始。对当前项只能接单或放掉：接单就把 $dur_p$ 累进总耗时；放掉则不加耗时，并继续看右侧。任意一段连续被放掉的项数不能大于 $g$。要在该限制下刚好接满 $t$ 项，并使累进的耗时之和尽量小。整条链都要审完：左端到第一单之前、相邻两单之间、以及最后一单到右端，每一段连续放掉的项数都受 $g$ 约束。

# 输入描述

第一行一个整数 $m$（$0\le m\le 1000$），表示链上的项数。

第二行两个整数 $t$ 与 $g$（$0\le t\le m$，$0\le g\le 1000$），依次为必须接满的项数、连续放掉的上限。

若 $m\ge 1$，第三行给出 $m$ 个整数 $dur_1,dur_2,\dots,dur_m$（$1\le dur_p\le 10000$），相邻两项用逗号分隔，表示各项预计耗时。若 $m=0$，没有第三行。

# 输出描述

输出一个整数：能够刚好接满 $t$ 项时的最小总耗时；链为空（$m=0$）时输出 $0$；无法在约束下接满 $t$ 项时输出 $-1$。

## 样例1

**输入**

```
4
2 0
8,8,8,8
```

**输出**

```
-1
```

**说明**

$g=0$ 时任何一项都不能放掉，要把长度为 $4$ 的整链全部接完才合法，无法刚好只接 $2$ 项。

## 样例2

**输入**

```
5
3 2
5,2,9,3,4
```

**输出**

```
9
```

**说明**

耗时序列为 $5,2,9,3,4$，要接满 $3$ 项，连续放掉上限为 $2$。

一种接法：放掉 $5$，接 $2$，放掉 $9$，再接 $3$ 与 $4$。各段连续放掉长度分别为 $1,1,0$，均不超过 $2$，总耗时 $2+3+4=9$。

其余合法接法的耗时都不低于 $9$，因此答案是 $9$。

## 样例3

**输入**

```
5
3 1
2,50,2,50,2
```

**输出**

```
6
```

**说明**

接第 $1$、$3$、$5$ 项，两处 $50$ 各自单独放掉一次，连续放掉长度均为 $1$，总耗时 $2+2+2=6$。把任何一项 $50$ 接进来都会让耗时变大，故最小值为 $6$。

## 样例4

**输入**

```
0
1 0
```

**输出**

```
0
```

**说明**

链上没有任何项，按约定直接输出 $0$。
