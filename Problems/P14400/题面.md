# 分段去重拼接

给定一个字符串 $s$，以及字符串子串的长度 $n$，要求：

1. 把 $s$ 按照 $n$ 的长度进行字符串子串拆分（最后一个子串长度可以小于 $n$）；
2. 每个子串不允许出现重复的字符；若出现重复，则**保留最后一次出现**，删除更早的重复字符。例如 `"aba"` 处理为 `"ba"`（第一个 `a` 被删，保留最后一个 `a`）；
3. 将所有处理后的子串按原顺序拼接，得到最终字符串。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def processChunks(self, s: str, n: int) -> str` |
| Java | `public String processChunks(String s, int n)` |
| C++ | `string processChunks(string s, int n)` |

**参数**

- `s`：非空字符串，仅含小写字母 `a`–`z`，$1 \le |s| \le 1000$；
- `n`：子串长度，$1 \le n \le 1000$。

**返回值**

按题意处理并拼接后的字符串。

## 输入输出格式（stdin / stdout）

**输入**（stdin **一行**，双引号包裹的字符串字面量、英文逗号、整数 $n$，与样例一致）：

```text
"abaabacbda",3
```

**输出**（stdout **一行**，双引号包裹的结果字符串）：

```text
"babacbda"
```

## 数据范围

- $1 \le |s| \le 1000$；
- $1 \le n \le 1000$；
- $s$ 仅含小写字母。

## 样例

### 样例 1

**输入**

```text
"abaabacbda",3
```

**输出**

```text
"babacbda"
```

**说明**

原始字符串分成 $4$ 个子串：`aba`、`aba`、`cbd`、`a`。

- `aba` → `ba`
- `aba` → `ba`
- `cbd` → `cbd`
- `a` → `a`

拼接：`ba` + `ba` + `cbd` + `a` = `babacbda`。

### 样例 2

**输入**

```text
"aaabbb",2
```

**输出**

```text
"aabb"
```

**说明**

分成 `aa`、`ab`、`bb`：

- `aa` → `a`
- `ab` → `ab`
- `bb` → `b`

拼接：`a` + `ab` + `b` = `aabb`。

### 样例 3

**输入**

```text
"a",1
```

**输出**

```text
"a"
```

### 样例 4

**输入**

```text
"a",1000
```

**输出**

```text
"a"
```

**说明**

仅 $1$ 个字符时，无论 $n$ 多大，结果均为原串。
