## 解题思路

本题是**固定长度分块 + 块内去重（保留最后出现）+ 拼接**，可按以下步骤处理：

1. **按 $n$ 分块**：从下标 $0$ 开始，每次取长度为 $n$ 的子串；最后一块长度 $\le n$。
2. **块内去重**：对当前块，记录每个字符**最后一次**出现的下标；从左到右扫描，仅保留下标等于「最后出现位置」的字符（等价于删去所有更早的重复）。
3. **拼接**：将各块处理结果按顺序连接即为答案。

**常见假解**：

- 保留**第一次**出现而非最后一次 → `"aba"` 会得到 `"ab"` 而非 `"ba"`；
- 对**整串**去重而非**逐块**去重 → 样例 2 `"aaabbb",2` 会错成 `"ab"`；
- 忘记最后一块可能短于 $n$ → 边界拼接错误；
- $n \ge |s|$ 时整块处理一次，仍须走块内规则（单字符块不变）。

## 复杂度分析

设 $m = |s| \le 1000$，块数为 $O(m/n)$，每块长度 $\le n$。

- 时间：$O(m)$，每个字符被扫描常数次；
- 空间：$O(n)$，块内哈希表规模不超过块长。

## 代码实现

### Python

```python
class Solution:
    def processChunks(self, s: str, n: int) -> str:
        def dedup(chunk: str) -> str:
            last = {}
            for i, c in enumerate(chunk):
                last[c] = i
            # 只保留各字符最后一次出现的位置
            return "".join(c for i, c in enumerate(chunk) if last[c] == i)

        parts = []
        for i in range(0, len(s), n):
            parts.append(dedup(s[i : i + n]))
        return "".join(parts)
```

### Java

```java
import java.util.HashMap;

public class Solution {
    public String processChunks(String s, int n) {
        StringBuilder res = new StringBuilder();
        for (int i = 0; i < s.length(); i += n) {
            int end = Math.min(i + n, s.length());
            String chunk = s.substring(i, end);
            HashMap<Character, Integer> last = new HashMap<>();
            for (int j = 0; j < chunk.length(); j++) last.put(chunk.charAt(j), j);
            // 块内仅输出「最后出现」的字符
            for (int j = 0; j < chunk.length(); j++)
                if (last.get(chunk.charAt(j)) == j) res.append(chunk.charAt(j));
        }
        return res.toString();
    }
}
```

### C++

```cpp
#include <string>
#include <unordered_map>

using namespace std;

class Solution {
 public:
  string processChunks(string s, int n) {
    string res;
    for (int i = 0; i < (int)s.size(); i += n) {
      string chunk = s.substr(i, n);
      unordered_map<char, int> last;
      for (int j = 0; j < (int)chunk.size(); j++) last[chunk[j]] = j;
      for (int j = 0; j < (int)chunk.size(); j++)
        if (last[chunk[j]] == j) res += chunk[j];
    }
    return res;
  }
};
```
