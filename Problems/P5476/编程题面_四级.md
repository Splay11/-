# 四因子乘积对

# 题目内容

边缘集群里排着 $m$ 个推理批次，第 $t$ 个批次带着指纹 $b_t$。调度会从中任取两个不同批次做成一组，把两个指纹相乘，若乘积的正因子恰好有 $4$ 个，就记这组为合法组。

同一对批次只算一次，顺序无关。请统计合法组的个数。

# 输入描述

一行给出正整数 $m$（$1\le m\le 100000$），随后同一行再给出 $m$ 个整数 $b_1,b_2,\dots,b_m$（$1\le b_t\le 1000000$），表示批次个数和各批次指纹。

# 输出描述

输出一个整数，即合法组的个数。

## 样例1

**输入**

```
5 6 2 3 9 1
```

**输出**

```
3
```

**说明**

- $1$ 与 $6$：乘积 $6=2\times 3$，四个正因子。
- $2$ 与 $3$：乘积 $6$，四个正因子。
- $3$ 与 $9$：乘积 $27=3^{3}$，四个正因子。

其余组合的乘积因子个数都不是 $4$。

## 样例2

**输入**

```
4 4 4 2 7
```

**输出**

```
3
```

**说明**

两个 $4$ 分别与 $2$ 配对，乘积都是 $8=2^{3}$；再加 $2$ 与 $7$ 的乘积 $14$。两个 $4$ 相乘得到 $16$，因子个数是 $5$，不计入。
