# 题目内容


小红拿到了一个数组 $a_1,a_2,\dots,a_n$，他定义其权值为满足如下条件的 $i,j$ 对数：
- $i < j$，且 $a_i \times a_j$ 有四个因子。

请你帮他求出这个数组的权值。



# 输入描述



第一行输入一个整数 $n\ (1 \le n \le 10^5)$。

第二行输入 $n$ 个整数 $a_1,a_2,\dots,a_n\ (1 \le a_i \le 10^6)$，代表数组的元素。



# 输出描述


输出一个整数，代表数组的权值。


## 样例1 



**输入** 



```
5
1 2 3 4 5
```



**输出** 



```
4
```



**说明**

符合条件的数对有 $\{2,3\},\{2,4\},\{2,5\},\{3,5\}$。
