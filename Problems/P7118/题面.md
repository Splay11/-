# 题目内容

给定一个有序的不含重复数字的数组，问有多少个数对，加起来恰好是 $k$。

## 输入描述

第一行两个整数 $n$ 和 $k$。

第二行 $n$ 个严格递增的整数 $nums_1,nums_2,\ldots,nums_n$。

## 输出描述

输出一个整数，表示和为 $k$ 的数对个数。

## 数据范围

- $1 \le n \le 10^5$
- $-10^9 \le nums_i,k \le 10^9$
- $nums$ 严格递增（因此不含重复数字）

## 样例1

输入：

```
5 6
-1 1 5 7 11
```

输出：

```
2
```

说明：数对为 $(-1,7)$ 和 $(1,5)$。

## 样例2

输入：

```
1 0
8
```

输出：

```
0
```
