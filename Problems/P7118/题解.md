# 两数之和II

## 解题思路

数组有序且不含重复数字，用双指针统计和恰好为 $k$ 的数对。

1. 左端点固定为 $i$ 时，要找的数是 $k-nums[i]$。
2. 单调性：从左往右枚举左端点 $i$，$nums[i]$ 增大，$k-nums[i]$ 减小（如果存在）。
3. 所以随着左端点向右移动，右端点应当向左寻找合法位置。
4. 实现上令 $left=0$，$right=n-1$。和等于 $k$ 则计数并两侧同时收缩；和偏小则 $left$ 右移；和偏大则 $right$ 左移。因为无重复，找到一对后不必再考虑这两个数。

## 复杂度分析

时间复杂度为 $O(n)$，左右指针总共移动 $O(n)$ 次。

空间复杂度为 $O(1)$。

## 代码实现

### Python

```python
# 截图中的双指针：和等于 k 则左右都移动，和偏小则左移，和偏大则右移


class Solution:
    def twoSum2(self, nums, k):
        left = 0
        right = len(nums) - 1
        count = 0
        # 数组有序且无重复，左右夹逼统计和为 k 的数对
        while left < right:
            current_sum = nums[left] + nums[right]
            if current_sum == k:
                # 找到一对，两侧都收一格；无重复所以不会再配同一对数
                count += 1
                left += 1
                right -= 1
            elif current_sum < k:
                # 当前和偏小，左端右移让 nums[left] 变大
                left += 1
            else:
                # 当前和偏大，右端左移让 nums[right] 变小
                right -= 1
        return count


def main():
    n, k = map(int, input().split())
    nums = list(map(int, input().split()))
    print(Solution().twoSum2(nums, k))


if __name__ == "__main__":
    main()
```
