# 统计指定月份的生日数

## 题目描述

公司想统计：在员工生日列表中，有多少人的生日落在给定的公历月份 `month` 里。

评测采用 **LeetCode 核心代码模式**：你只需要实现 `Solution` 类中的方法，平台会负责读入数据并调用你的方法。**不要**编写 `main` 或标准输入输出逻辑。

## 方法签名

你需要实现以下接口（三种语言名称与参数类型需与模板一致）：

- **C++**：`int countBirthdayGifts(int month, vector<string>& employees, vector<string>& birthdays);`
- **Java**：`public int countBirthdayGifts(int month, List<String> employees, List<String> birthdays)`
- **Python**：`def countBirthdayGifts(self, month, employees, birthdays)`

### 参数说明

- `month`：目标月份，范围为 $1 \sim 12$。
- `employees`：员工姓名字符串列表，与 `birthdays` **等长**（本题统计不依赖姓名，但需保持接口一致）。
- `birthdays`：与 `employees` 一一对应的生日字符串，格式为 **`M-D` 或 `MM-DD`**`（月-日），月、日均为非负整数书写，不含年份。

### 返回值

返回 `birthdays` 中，**月份部分**（`-` 左侧的整数）等于 `month` 的个数。

## 输入格式（平台侧，选手无需编写）

一行文本，结构为：

```text
month,["员工1",...],["生日1",...]
```

即：整数 `month`，然后是英文逗号分隔的两个 JSON 风格字符串数组；第二个数组中每一项为 `月-日` 形式。字符串中可能包含英文逗号（`,`），但不会破坏上述最外层结构（与评测模板解析方式一致）。

## 输出格式

一行一个整数，即方法返回值。

## 样例

**输入**

```text
2,["Alice","Bob"],["02-01","02-28"]
```

**输出**

```text
2
```

**解释**：两个生日的月份均为 $2$，故计数为 $2$。

## 数据范围

- $1 \le n \le 10^5$，$n$ 为员工数（即 `employees` / `birthdays` 长度）。
- `month` 在 $[1,12]$。
- 每个姓名为非空字符串；每个生日字符串合法且含恰好一个 `-`。
