# 统计指定月份的生日数 — 题解

## 1. 解题思路

- 本题考查**线性扫描**与**简单字符串解析**。
- 对每个 `birthdays[i]`，按字符 `-` 分割，取左侧子串转为整数得到生日月份；若等于给定的 `month`，则答案加一。
- 与 LeetCode 风格一致：在 `class Solution` 的成员方法中完成逻辑，**不**进行任何标准输入输出。

## 2. 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 为 `birthdays` 长度；每个字符串仅做常数次分割与比较。
- **空间复杂度**：$O(1)$ 额外空间（不计入参字符串本身）；若语言实现中分割产生临时数组，则为 $O(1)$ 次均摊。

## 3. 代码实现

### Python

```python
class Solution:
    def countBirthdayGifts(self, month, employees, birthdays):
        ans = 0  # 合法生日条数
        for s in birthdays:
            m = int(s.split("-")[0])  # 解析「月-日」中的月份
            if m == month:
                ans += 1
        return ans
```

### Java

```java
class Solution {
    public int countBirthdayGifts(int month, List<String> employees, List<String> birthdays) {
        int ans = 0; // 合法生日条数
        for (String s : birthdays) {
            int dash = s.indexOf('-'); // 分隔月与日
            int m = Integer.parseInt(s.substring(0, dash));
            if (m == month) {
                ans++;
            }
        }
        return ans;
    }
}
```

```cpp
    }
```

### C

```c
int countBirthdayGifts(int month, char** employees, int employeesSize,
                       char** birthdays, int birthdaysSize) {
    int ans = 0; // 合法生日条数
    for (int i = 0; i < birthdaysSize; i++) {
        int m = 0; // 解析「月-日」中的月份
        for (int j = 0; birthdays[i][j] != '-'; j++) {
            m = m * 10 + (birthdays[i][j] - '0');
        }
        if (m == month) {
            ans++;
        }
    }
    return ans;
}
```
