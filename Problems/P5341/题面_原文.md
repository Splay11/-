# 题目内容

作为智慧城市项目组的工程师，你负责优化城市间的数据网络连接。现在有 $n$ 个城市（编号 $0$ 到 $n-1$）和 $m $条现有的双向数据链路。每条链路连接两个城市，并有一个数据传输带宽（单位：$Gb/s$）。

由于预算有限，对每一种从城市$ 0$ 到城市 $n-1$ 的路径中，你只能选择一条路径并且升级该路径上的$ k $条现有链路。每条链路升级后，其传输带宽会变为原来的 $2 $倍，每一条链路只能升级$ 1$ 次。

你需要设计一个算法，计算在升级恰好 $k$ 次的情况下，从城市 $0$ 到城市 $n-1 $的最大瓶颈带宽。瓶颈带宽定义为路径上链路中传输带宽最小的那个值，例如 $0 $到 $1 $带宽为 $10Gb/s$，$1 $到 $2$ 带宽为 $20Gb/s$，则瓶颈带宽为 $10Gb/s$，你需要计算城市$ 0 $到城市$ n-1$ 所有路径中，在升级完成后，最大的瓶颈带宽。

注意：

- 如果无法从城市 $0$ 到达城市$ n-1$，则返回$ -1$
- 对每条 $0$ 到$ n-1$ 的路径中，你可以选择不升级，但如果需要升级，则必须恰好升级$ k$ 次链路，不能多也不能少，如果该条路径不满足升级条件，则无法升级
- 每条链路只能升级 $1$ 次

# 输入描述

第一行包含三个整数$ n$（城市数量）,$ m（数据链路数量）, $k$（升级$ k$ 条链路）$(2 \le n \le 100, 1 \le m \le 1000, 0 \le k \le \min(10, m)$

接下来$ m$ 行，每行包含三个整数$ u, v, w$，表示城市 $u$ 和城市 $v$ 之间有一条速度为 $w$ 的链路$(0 < w < 1000)$

# 输出描述

输出一个整数，表示最大瓶颈带宽。如果无法从城市 0 到达城市 n-1，则输出 -1



## 样例1 

**输入** 

```
4 3 2
0 1 10
0 2 20
1 2 15
```

**输出** 

```
-1
```

**说明**

没有一条路径可以到达 3，输出 -1



## 样例2 

**输入** 

```
5 6 2
0 1 10
0 2 20
1 2 5
1 3 30
2 4 15
3 4 25
```

**输出** 

```
30
```

**说明**

最佳方案是升级链路 $(0,2)$ 和$ (2,4)$，升级后路径 $0->2->4$ 的瓶颈速度为 $30$。

## 样例3

**输入** 

```
6 10 2
0 1 10
0 2 20
1 2 5
1 3 15
2 3 25
2 4 8
3 4 12
3 5 30
4 5 18
0 5 50
```

**输出** 

```
50
```

**说明**

该题目有多条路径，但由于需要升级 $2 $次，无法直接升级$ 0->5$ 路径，因此挑选路径$ 0->2->3->5$ 当中进行升级，但是升级完后该路径瓶颈带宽依旧小于$ 0->5$ 路径的$ 50$，因此输出$ 50$
