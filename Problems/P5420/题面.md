# 题目内容


给定长度为 $n$ 的序列 $a$，可进行至多 $k$ 次操作。每次操作选择某个起点 $i\ (1 \le i \le n-m+1)$，使区间 $[i,i+m-1]$ 内所有元素都加一。

请问经过至多 $k$ 次操作后，序列最小值的最大可能值是多少。



# 输入描述


第一行三个整数 $n,m,k\ (1 \le n \le 2 \times 10^5,\ 1 \le m \le n,\ 0 \le k \le 10^9)$；

第二行 $n$ 个整数 $a_1,a_2,\dots,a_n\ (|a_i| \le 10^9)$。



# 输出描述


输出一个整数，表示能达到的最大最小值。


## 样例1 



**输入** 



```
5 3 4
1 2 3 2 1
```



**输出** 



```
3
```
