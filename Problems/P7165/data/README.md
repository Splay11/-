# P7165 测试数据说明

主造数脚本：题目根目录 `gen.py`。四个 $1..9$，实数四则运算凑 $24$。
约束始终是 $4$ 张牌，后两组用较大数字覆盖搜索分支。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1，(8-4)*(7-1) | true | 整数除法或漏括号 |
| 2 | 样例 2 凑不出 | false | 输出 true |
| 3 | 全 1 | false | 输出 true |
| 4 | 经典 8/(3-8/3) | true | 整数除法得到 false |
| 5 | 8*(1+1+1) | true | 只用加法 |
| 6 | 5 5 5 5 | 对拍回溯 | 只做加减 |
| 7 | 全 9 | 对拍 | 爆搜漏排列 |
| 8 | 中等组合 | 对拍 | 除以 0 没跳过 |
| 9 | 接近上限的牌面 | 对拍 | 没枚举减法和除法方向 |
| 10 | 另一组常用牌 | 对拍 | 只检查一种括号 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。
