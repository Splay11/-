# 题目内容


某仓内作业系统记录了拣货波次和拣货任务。请使用 $MySQL$ $8.0$ 编写 $SQL$ 查询语句，统计 $2026$ 年 $10$ 月 $1$ 日存在拣货异常的波次。

表名：$picking\_waves$

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| wave_id | int | 波次 ID |
| warehouse | varchar($20$) | 仓库编码 |
| wave_date | date | 波次日期 |

表名：$picking\_tasks$

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| task_id | int | 拣货任务 ID |
| wave_id | int | 波次 ID |
| plan_qty | int | 计划拣货数量 |
| picked_qty | int | 实际拣货数量 |
| task_status | varchar($20$) | 任务状态，取值包括 DONE、PENDING、RUNNING |

拣货异常任务指未完成任务，或实际拣货数量少于计划拣货数量的任务。请输出存在至少 $1$ 个异常任务的波次。
输出字段固定为：$warehouse$、$wave\_id$、$task\_count$、$abnormal\_task\_count$、$shortage\_qty$。列名和列顺序必须与要求一致。

其中 $task\_count$ 表示该波次的任务总数；$abnormal\_task_count$ 表示异常任务数量；$shortage\_qty$ 表示该波次中所有少拣数量之和，未少拣的任务不计入少拣数量。

结果先按 $abnormal\_task\_count$ 降序排列；若相同，按 $shortage\_qty$ 降序排列；若仍相同，按 $warehouse$ 升序排列；若仍相同，按 $wave\_id$ 升序排列。





## 样例1 



**输入** 



```sql
CREATE TABLE picking_waves (
wave_id int,
warehouse varchar(20),
wave_date date
);

CREATE TABLE picking_tasks (
task_id int,
wave_id int,
plan_qty int,
picked_qty int,
task_status varchar(20)
);

INSERT INTO picking_waves VALUES
(101, 'BJ01', '2026-10-01'),
(102, 'BJ01', '2026-10-01'),
(103, 'SH01', '2026-10-01'),
(104, 'BJ01', '2026-09-30');

INSERT INTO picking_tasks VALUES
(1, 101, 10, 10, 'DONE'),
(2, 101, 8, 5, 'DONE'),
(3, 101, 6, 6, 'PENDING'),
(4, 102, 5, 5, 'DONE'),
(5, 102, 4, 4, 'DONE'),
(6, 103, 9, 4, 'PENDING'),
(7, 103, 7, 7, 'DONE');
```



**输出** 


| warehouse | wave_id | task_count | abnormal_task_count | shortage_qty |
| ---- | ---- | ---- | ---- | ---- |
| BJ01 | 101 | 3 | 2 | 3 |
| SH01 | 103 | 2 | 1 | 5 |




**说明**

$wave\_id=101$ 任务：

任务 $1$：$DONE，plan=10$ $picked=10$，正常；

任务 $2$：$DONE，plan8$ $picked5$，实际少于计划，异常，少拣 $8-5=3$；

任务 $3$：$PENDING$ 未完成，异常，无少拣数量；
总 $task\_count=3$，$abnormal\_task\_count=2$，$shortage\_qty=3$。

$wave\_id=103$ 任务：

任务 $6$：$PENDING$ 未完成，$plan9$ $picked4$，异常，少拣 $9-4=5$；

任务 $7$：$DONE$，$plan7$ $picked7$ 正常；
$task\_count=2$，$abnormal\_task\_count=1$，$shortage\_qty=5$。

$wave\_id=102$ 全部任务正常，不输出。
