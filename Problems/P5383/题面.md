# 题目内容


多多最近在逛一家盲盒店，店里正在进行一场促销活动。店里有 $n$ 个盲盒，每个盲盒都有一个固定的价值 $A_i$。

活动的规则是这样的：多多可以从中选取恰好两个盲盒。如果这两个盲盒的价值之和恰好是整数 $m$ 的倍数，那么多多就可以将这两个盲盒免费全部拿走。

多多想知道，在所有挑选两个盲盒的方案中，有多少种方案能够让他免费拿走盲盒？

注意：盲盒虽然价值可能相同，但它们被视为不同的独立个体。也就是说，如果第$i$个盲盒和第$j$个盲盒被选中，这与第$j$个和第$i$个被选中是同一种方案（即不考虑顺序），但下标不同代表不同的方案。


# 输入描述


第一行包含两个整数 $n$ 和 $m$，分别表示盲盒的数量和价值之和需要满足的模数。

第二行包含 $n$ 个整数 $A_1,A_2,\dots,A_n$，表示每个盲盒的价值。

数据范围
$2 \le n \le 10^5$
$1 \le m \le 10^5$
$0 \le A_i \le 10^9$（$A_i$为非负整数）


# 输出描述


输出一个整数，表示能够免费拿走两个盲盒的方案总数。


## 样例1 



**输入** 



```
6 3
1 2 3 4 6
```



**输出** 



```
3
```



**说明**

盲盒价值为$([1,2,3,4,6])$，$(m=3)$。下标从$1$开始，即$A_1=1$,$A_2=2$,$A_3=3$,$A_4=4$,$A_5=6$。
满足价值之和为$3$的倍数的组合有：
下标$((1,2))$：$A_1+A_2=1+2=3$，是$3$的倍数
下标$((2,4))$：$A_2+A_4=2+4=6$，是$3$的倍数
下标$((3,5))$：$A_3+A_5=3+6=9$，是$3$的倍数

## 样例2



**输入** 



```
4 2
2 2 2 2
```



**输出** 



```
6
```



**说明**

所有盲盒价值均为$2$，$(m=2)$。任意两个盲盒价值之和为$4$，均为$2$的倍数。从$4$个盲盒中任选$2$个的方案数为$C_4^2=6$种。
