# 题目内容

小红拿到了一个长度为 $n$ 的数组 $\{a_1, a_2, \dots, a_n\}$，她每次操作可以选择两个下标不同的元素 $a_i$ 和 $a_j$（即满足 $i \neq j$），若 $|a_i - a_j| \le 1$，则删除这两个元素中较大的那个（若两元素相等，则随机删除一个）。小红想知道，是否可能通过一系列操作，使得数组最后只剩一个元素。

# 输入描述

每个测试文件包含多组测试数据。

第一行包含一个整数 $T$（$1 \le T \le 10^3$），表示测试数据组数。

对于每组测试数据：

- 第一行包含一个整数 $n$（$2 \le n \le 10^3$），表示数组长度。
- 第二行包含 $n$ 个正整数 $a_1, a_2, \dots, a_n$（$1 \le a_i \le 200$），表示数组元素。

# 输出描述

对于每组测试数据，新起一行输出结果。如果可以通过一系列操作使数组只剩一个元素，输出 `YES`；否则输出 `NO`。

## 示例 1

**输入**

```
2
4
1 2 2 3
3
1 2 4
```

**输出**

```
YES
NO
```
