# 读数消融判定

# 题目内容

产线侧在工位上部署了测点，回传一条长度为 $n$ 的整型读数序列 $\{v_1,v_2,\dots,v_n\}$。质检模块每次可任选两个不同下标 $p,q$（$p\neq q$）：若 $|v_p-v_q|\le 1$，即两读数相等或恰相差 $1$，则抹去其中较大的那条；两读数相等时任抹其一。请判断能否经过若干次上述抹除，使序列最终只剩一条读数。

# 输入描述

第一行一个整型 $k$（$1 \le k \le 1000$），表示随后有 $k$ 条读数序列。

对其中每一条序列：

- 第一行一个整型 $n$（$2 \le n \le 1200$），表示该序列长度。
- 第二行 $n$ 个正整型 $v_1, v_2, \dots, v_n$（$1 \le v_i \le 250$），表示各测点读数。

请对每条序列逐一判定能否消融到只剩一条读数。

# 输出描述

共写出 $k$ 行。对每一条序列，若可以消融到只剩一条读数，写出 `YES`；否则写出 `NO`。

## 示例 1

**输入**

```
3
3
2 3 4
2
5 7
6
1 2 2 3 3 4
```

**输出**

```
YES
NO
YES
```

**说明**

第一条 $\{2,3,4\}$：选 $3$ 与 $4$ 抹去 $4$，再选 $2$ 与 $3$ 抹去 $3$，剩 $2$。

第二条 $\{5,7\}$：$|5-7|=2$，无法操作，不能消到一条。

第三条 $\{1,2,2,3,3,4\}$：可先抹去 $4$（与某个 $3$ 配对），再抹去两个 $3$（分别与 $2$ 配对），再抹去多余的 $2$（与 $1$ 配对），最后剩 $1$。

## 示例 2

**输入**

```
2
4
8 8 10 9
3
1 1 3
```

**输出**

```
YES
NO
```

**说明**

第一条：选 $10$ 与 $9$ 抹去 $10$，得到 $\{8,8,9\}$；再选 $9$ 与某个 $8$ 抹去 $9$，得到 $\{8,8\}$；再抹去其中一个 $8$，剩 $8$。

第二条：只能把两个 $1$ 配成一对并抹去其中一个，得到 $\{1,3\}$；此时 $|1-3|=2$，无法继续，最终剩两条。
