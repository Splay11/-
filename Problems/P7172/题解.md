# 补码转十进制

算法标签：位运算、数学

算法难度：$3 / 10$

## 解题思路

长度为 $n$ 的二进制补码，$bits_0$ 是最高位也是符号位。十进制值就是题面给出的公式：

$-bits_0\times 2^{n-1}+\sum_{i=1}^{n-1}bits_i\times 2^{n-1-i}$

1. 若最高位是 $1$，先减去 $2^{n-1}$；否则这一项是 $0$。
2. 从左到右剩下的位按普通二进制权值加进去。
3. $n=1$ 时：只有符号位，$0$ 表示 $0$，$1$ 表示 $-1$。
4. $n=8$ 且 $10000000$ 时，就是 $-128$。
5. 常见假解：把最高位也按正权加（无符号整数）；权值下标写反。

$n\le 31$，$2^{30}$ 仍在 $32$ 位有符号整数范围内。

## 复杂度分析

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
def solve(bits):
    """按题面公式：最高位是符号位，值为 -bits0 * 2^(n-1)，其余位按正权相加。"""
    n = len(bits)
    ans = 0
    if bits[0] == 1:
        ans -= 1 << (n - 1)
    for i in range(1, n):
        if bits[i] == 1:
            ans += 1 << (n - 1 - i)
    return ans


def main():
    n = int(input())
    bits = list(map(int, input().split()))
    print(solve(bits))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.StringTokenizer;

public class Main {
    static int solve(int[] bits) {
        int n = bits.length;
        int ans = 0;
        if (bits[0] == 1) ans -= (1 << (n - 1));
        for (int i = 1; i < n; i++) {
            if (bits[i] == 1) ans += (1 << (n - 1 - i));
        }
        return ans;
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());
        StringTokenizer st = new StringTokenizer(br.readLine());
        int[] bits = new int[n];
        for (int i = 0; i < n; i++) bits[i] = Integer.parseInt(st.nextToken());
        System.out.println(solve(bits));
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

int solve(const vector<int>& bits) {
    int n = (int)bits.size();
    int ans = 0;
    if (bits[0] == 1) ans -= (1 << (n - 1));
    for (int i = 1; i < n; i++) {
        if (bits[i] == 1) ans += (1 << (n - 1 - i));
    }
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> bits(n);
    for (int i = 0; i < n; i++) cin >> bits[i];
    cout << solve(bits) << '\n';
    return 0;
}
```
