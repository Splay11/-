**2、下面的 Python 函数被多次调用后，默认列表会保留此前加入的元素。最合适的改法是哪项？**

```
def add_item(item, items=[]):
    items.append(item)
    return items
```

{{ select(2) }}

- 在模块导入时调用一次垃圾回收，即可清空默认参数里的内容
- 把默认值改成 `None`，并在函数体内再创建新列表
- 只把形参改成别的名字，默认对象就会按每次调用重新分配
- 每次返回前把列表转成字符串再转回列表，即可切断与默认对象的关联



**3、一个交互线程和一个批处理线程同时处于可运行状态。系统希望交互线程响应更快，但又不能让批处理线程长期得不到执行。下列哪项调度调整最合适？**

- 只按线程创建时间排序，并一直运行最早创建者
- 采用带时间片和优先级老化的多级反馈队列



**4、若 `asyncio` 服务在协程中直接调用耗时的同步文件处理函数，期间其他请求也停止响应。最合适的调整是哪项？**

- 将阻塞的同步调用放到线程执行器中运行，并在协程里等待其结果

- 继续直接调用同步函数，只把入口函数声明为 `async`
- 成倍增加协程数量，让更多协程同时阻塞在同一个事件循环上

**6、下面的函数使用半开区间，在升序数组中返回第一个大于等于 `target` 的位置；若不存在则返回 `a.size()`：**

```
int lowerBound(const vector<int>& a, int target) {
    int left = 0, right = a.size();
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (a[mid] < target) /* 填空 */;
        else right = mid;
    }
    return left;
}
```

{{ select(6) }}

- left = mid
- right = mid - 1
- right = mid + 1
- left = mid + 1

**9、一个持续接收整数的数据流需要随时返回中位数，插入次数远多于查询次数，且不能在每次查询前重新排序。以下哪种数据结构组合更合适？**

**10、某 Python 程序需要对大量独立图像执行纯 CPU 计算。改用更多线程后，单进程吞吐几乎没有提升，CPU 也未充分利用多核。最合适的调整是哪项？**

- 使用多进程分配独立任务，并控制序列化与进程数量



**11、订单表需要记录订单、用户和商品明细。为避免同一订单重复保存用户姓名，也避免一个订单只能存一件商品，以下哪组建表语句更符合关系模型的规范化设计？**

**12、非递减有序数组（长度大于 1）可能包含重复值，下面的双指针代码用于判断是否存在两个不同位置的元素之和等于 `target`：**

```
int left = 0, right = a.size() - 1;
while (left < right) {
    long long sum = 1LL * a[left] + a[right];
    if (sum == target) return true;
    if (sum < target) ++left;
    else --right;
}
return false;
```

{{ select(12) }}

- 把循环条件改成 `left <= right` 后，仍能保证不会使用同一位置
- 存在重复值时必须先去重，否则一定会漏掉正确答案
- 使用 `left < right` 能避免同一位置被重复使用



**13、一个 Python 异步服务并发请求多个外部接口。高峰期部分接口超时，未完成任务不断累积，关闭服务时仍有大量协程悬挂。最合适的调整是哪项？**
{{ select(13) }}

- 移除所有超时，让每个协程无限等待外部接口最终返回
- 只增加事件循环中的任务数量，不限制下游连接和请求速率
- 为外部调用设置超时，并在请求结束时取消不再需要的任务
- 用信号量限制并发后吞掉取消异常，不再向外传播

**17、非递减有序数组（长度大于 1）可能包含重复值，下面的双指针代码用于判断是否存在两个不同位置的元素之和等于 `target`。关于该实现，以下哪些说法正确？（错选不得分，少选得 1/3 分）**

```
int left = 0, right = a.size() - 1;
while (left < right) {
    long long sum = 1LL * a[left] + a[right];
    if (sum == target) return true;
    if (sum < target) ++left;
    else --right;
}
return false;
```

{{ multiselect(17) }}

- 数组有序时，依据当前和的大小移动一侧指针是成立的
- 存在重复值时必须先去重，否则一定会漏掉正确答案

- 该算法要求数组严格递增，出现相等元素就会进入死循环
