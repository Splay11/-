# 题目内容

有 $m$ 个苹果要分给 $n$ 个人，每个人可以分到 $0$ 到 $m$ 个苹果，要求苹果总量恰好分完。请输出所有合法的分配方案，方案按字典序升序排列，最后一行输出方案总数。

# 输入描述

一行输入两个整数 $m, n$（$0 \le m \le 15$，$1 \le n \le 5$）。

# 输出描述

每行输出一个方案，包含 $n$ 个整数（空格分隔），表示每人分到的苹果数。所有方案按字典序升序输出。

最后一行输出一个整数，表示方案总数。

## 样例 $1$

**输入**

```text
0 2
```

**输出**

```text
0 0
1
```

## 样例 $2$

**输入**

```text
2 1
```

**输出**

```text
2
1
```
