# 题目内容

某小型多多分拣站有一条主传送带和一条缓冲道。今天有$n$个包裹按顺序到达主传送带，第$i$个到达的包裹的目的地编号为$a_i$。

已知$a$是$1 \sim n$的一个排列（即每个目的地编号恰好出现一次）。 包裹必须按目的地编号从小到大的顺序依次装车发出，即装车顺序必须恰好为 $1,2,\dots,n$。

分拣员对每个到达的包裹可以选择以下两种操作之一：

- **I (In)**：将该包裹推入缓冲道；
- **O (Out)**：将该包裹直接装车发出。

此外，在任意时刻（包括所有包裹到达之后），分拣员都可以从缓冲道取出最顶端包裹并装车发出。

请你判断是否存在一种操作方案，使得最终装车顺序恰好为$1,2,\dots,n$。若存在，输出对应的操作序列；若不存在，输出$\texttt{N}$。

可以证明：当存在合法方案时，操作序列唯一确定。



# 输入描述

第一行一个正整数 $n$，表示包裹数量。 第二行 $n $个正整数 $1,2,\dots,n$，表示包裹到达顺序，保证是 $1\sim n$ 的排列。

**数据范围**

- $1 \le T \le 12$
- $1 \le n \le 2\times 10^5$
- 单个测试文件中所有 $n$ 之和不超过 $1\times 10^6$
- 每组数据的 $a$ 均为 $1\sim n$的一个排列

# 输出描述

若存在合法方案，输出一行由`I`和`O`组成的字符串，表示唯一的合法操作序列；若不存在，输出一行一个字符`N`。

## 补充说明： 

操作序列含义：从左到右依次执行，`I`表示把下一个到达的包裹压入栈，`O`表示弹出栈顶包裹装车。序列恰好包含 n 个`I`和 n 个`O`。

## 样例1 

**输入** 

```
3
2 1 3
```

**输出** 

```
IIOOIO
```

**说明**

- `I`：包裹 2 到达，压栈，栈 = [2]
- `I`：包裹 1 到达，压栈，栈 = [2, 1]
- `O`：栈顶 1 = 当前应发 1，弹出装车，已发 =[1]，栈 = [2]
- `O`：栈顶 2 = 当前应发 2，弹出装车，已发 =[1,2]，栈 = []
- `I`：包裹 3 到达，压栈，栈 = [3]
- `O`：栈顶 3 = 当前应发 3，弹出装车，已发 =[1,2,3]，栈 = []
