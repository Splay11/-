## 1.单选题
**1、关于Transformer pre-LN与post-LN的差异,下列说法正确的是?**
{{ select(1) }}

- pre-LN模型必须用warmup,post-LN无需warmup
- pre-LN把LayerNorm放在残差分支之前,训练时数值更稳定,大模型广泛采用
- post-LN在深层堆叠时数值稳定性优于pre-LN,是当前大模型主流
- pre-LN与post-LN数学等价,可任意替换



**2、关于SigLIP相对CLIP的关键差异,下列说法正确的是?**
{{ select(2) }}

- SigLIP放弃图文对比学习,改用masked image modeling
- SigLIP与CLIP数学等价,只是学习率调度不同
- 把InfoNCE对比loss换成sigmoid二分类loss,免除batch内所有负样本的softmax归一化,支持更大batch
- SigLIP仅在中文场景可用,对英文不支持



**3、SigLIP仅在中文场景可用,对英文不支持?**
{{ select(3) }}

- 在$68$万小时网页字幕上做弱监督多任务训练,输入log-Mel频谱,零样本多语种ASR能力强
- Whisper只输出识别文本,不能翻译
- Whisper只在LibriSpeech上训练,不涉及网页数据
- Whisper属于CTC架构,不做自回归



**4、关于AdamW相对Adam的关键改进,下列说法正确的是?**
{{ select(4) }}

- AdamW只对分类任务生效,不适合序列模型
- AdamW把weight decay从梯度更新中解耦出来直接作用于参数,与Adam-L2不等价,在大模型训练更稳
- AdamW不再维护二阶矩,以降低显存开销
-  AdamW等价于Adam加L2正则,只是命名不同



**5、关于RAG(Retrieval Augmented Generation)与long-context in-context的对比,下列说法正确的是?**
{{ select(5) }}

- RAG通过检索小段相关证据拼入prompt,可显著降低推理成本;long-context直接把大知识拼入上下文,成本高且易受lost-in-the-middle影响
- long-context完全替代RAG,已成为业界主流,RAG已过时
- RAG与long-context数学等价,可任意替换
- RAG只支持文本检索,不能扩展到图像/表格



**6、关于Qwen-VL / InternVL类模型的dynamic resolution处理,下列说法正确的是?**
{{ select(6) }}

- 将所有输入统一缩放到$224$×$224$,不做动分辨率处理
- Qwen-VL与InternVL均不支持超高分辨率图像
- 按输入图像纵横比选择最接近的一组分块方案,把patch token数量与图像内容量匹配,支持任意分辨率细节保留
- 通过GAN生成对抗调整分辨率



**7、关于ACT(Action Chunking Transformer)一次预测未来$k$步动作chunk的动机,下列说法正确的是?**
{{ select(7) }}

- chunk只对分类动作有效,不能用于连续控制
- ACT输出必须严格单步,不能chunk
- 一次输出chunk可显著缓解逐步预测下的累积误差与非马尔科夫性,配合temporal ensemble提升平滑度
- chunk越长控制越精确,建议$k$ = $1$全逐步



**8、关于MQA(Multi-Query Attention) / GQA(Grouped-Query Attention) / MLA(Multi-head Latent Attention)对KV cache的作用,下列说法正确的是?**
{{ select(8) }}

- MQA / GQA / MLA数学等价,只是命名不同
- MQA让所有head共享同一组K/V,GQA分组共享,MLA通过低秩潜变量压缩K/V,三者均以降低KV cache显存为主要目标
- MLA是MQA的近似,精度显著低于MQA
- 三者只影响训练速度,与KV cache无关

**9、关于DINOv2特征与SAM特征在下游任务中的差异,下列说法正确的是?**
{{ select(9) }}

-  DINOv2特征只能做零样本聚类,不能作backbone
- SAM特征天生适合分类,DINOv2特征天生适合mask生成多个线程并发执行时不涉及同步问题，因为它们共享同一份内存
- DINOv2与SAM特征完全等价,可互换
- DINOv2语义可分性强,常作分类/检测/分割backbone;SAM特征对分割mask边界友好,适合可提示分割

## 2.多选题

**10、关于主流 LLM 推理与服务框架,下列说法正确的是?**
{{ select(10) }}

- vLLM 基于 PagedAttention 提供高吞吐 LLM 服务
- SGLang 通过结构化前端与 RadixAttention 复用前缀 KV cache,擅长复杂多轮/工具调用场景
- MLC-LLM / llama.cpp 提供跨端(手机/桌面)部署方案
- TensorRT-LLM 面向 NVIDIA GPU 深度优化,配合自定义算子获得极致吞吐



**11、关于多智能体系统(Multi-Agent)的常见范式,下列说法正确的是?**
{{ select(11) }}


- AutoGen 提供对话式多 Agent 编排,Agent 之间以消息传递协作
- CAMEL 用 role-playing 让两个 Agent 分别扮演用户与助手驱动任务
- CrewAI 以“角色 + 任务 + 流程”抽象组织多 Agent 协作
- 多 Agent 系统对复杂任务一定优于单 Agent,不存在通信成本



**12、关于 NeRF / 3DGS 类三维重建加速方案,下列说法正确的是?**

{{ select(12) }}
- NeRF 类方法必须完全废弃,3DGS 已在所有场景全面替代 NeRF
- Instant-NGP 用多分辨率哈希编码把训练从小时级压到分钟级
- TensoRF / Plenoxels 用张量分解或体素网格显式表征,免除 MLP 推理
- gsplat / Nerfstudio 提供高效可扩展的开源实现,常作研究/工程基线

**13、关于 LLM 模型压缩相关技术,下列说法正确的是?**
{{ select(13) }}

- SmoothQuant 通过在权重-激活间做等价缩放,把量化难度从激活转移到权重侧,便于 INT8 部署
- SqueezeLLM / GPTQ / AWQ 均属于 PTQ 类权重量化算法
- 4bit 量化后必然无法在推理时恢复精度,建议禁用
- bitsandbytes NF4 是常用 4bit 量化实现,配合 QLoRA 可低成本微调



**14、关于 LLM Agent 的 Memory 系统与向量检索,下列说法正确的是?**
{{ select(14) }}

- Episodic memory 记录时间戳与事件流,便于回放与失败反思
- short-term memory 通常保存在上下文窗口内,long-term memory 落到向量库或结构化存储
- Memory 与 RAG 冲突,同一系统只能启用其一
- 常见开源向量库有 FAISS / Chroma / Qdrant / Milvus / Weaviate



**15、关于视觉编码器的演进,下列说法正确的是?**
{{ select(15) }}

- DFN(Data Filtering Network) 类方法侧重预训练前的数据筛选与清洗
- CLIP ViT 是 VLM 中最常用的视觉 backbone 之一,依赖大规模图文对比学习
- 视觉 encoder 必须冻结,任何微调都会破坏对齐
- SigLIP 用 sigmoid loss 替代 softmax,支持大 batch 训练,已被多款 MLLM 采用



**16、关于策略优化 RL 算法在 VLA / RLHF 中的应用,下列说法正确的是?**
 {{ multiselect(16) }}

- DPO 直接从成对偏好数据推导闭式解,不显式训 reward model
- PPO 通过 clip 目标限制策略更新幅度,是 RLHF 主流优化器
- 强化学习必须显式建模 reward model,DPO / GRPO 都需先训 RM
- GRPO(Group Relative Policy Optimization) 通过组内相对优势估计,免除单独 critic



**17、关于 TTS(语音合成) 的主流方法,下列说法正确的是?**
 {{ multiselect(17) }}

- StyleTTS 结合参考风格向量做可控音色/语调合成
- TTS 与 ASR 数学等价,可互换
- VITS 是 end-to-end 变分自编码 + Flow 的 TTS,声码器与声学模型联合训练
- VALL-E / VoiceCraft 用 codec token + LLM-like 自回归做 zero-shot 声音克隆

**18、 关于多模态大模型的常见评测基准,下列说法正确的是?**
 {{ multiselect(18) }}

- MMMU 面向大学多学科多模态推理,评测 VLM 在复杂图文推理上的能力
- 一次模型迭代通过一项 benchmark 即代表泛化能力,无需组合评测
- MMBench / SEED-Bench 从感知、认知、推理多维度评测通用能力
- TextVQA / DocVQA 侧重文字与文档理解,考验 OCR + 推理联合能力

**19、关于Transformer位置编码的演进,下列说法正确的是?**
 {{ multiselect(19) }}

- RoPE通过对Q/K施加旋转矩阵,支持相对位置且可用NTK/YaRN扩展长度
- Sinusoidal位置编码是固定的三角函数,无需学习,可外推到未训练长度但外推能力有限
- ALiBi通过在attention分数上加线性偏置,长度外推能力强,不需显式位置向量
- Learnable位置编码在ViT中常用,但对未训练长度无法直接外推



**20、关于 BEV(Bird-Eye-View) 与 Occupancy 感知,下列说法正确的是?**
 {{ multiselect(20) }}

- BEV / Occupancy 已完全替代 2D 感知,后者已被淘汰
- CenterPoint / BEVDet 在 BEV 空间做检测,与图像 detector 相比可减少后处理
- BEVFormer 通过 spatial cross-attention 与 temporal self-attention 在 BEV 空间统一多视图特征
- Occupancy 用 3D 体素网格表示空间占据,能表达任意形状物体



**21、关于语音增强(SE)与去噪的常见方法,下列说法正确的是?**
 {{ multiselect(21) }}

- 深度语音增强要求必须有配对的干净-噪声数据,不能用自监督
- RNNoise 是轻量传统+DNN 混合的实时降噪,常用于会议场景
- DNSMOS 是 Microsoft 的无参考语音质量评估工具,常作 SE 训练/评测的 proxy 指标
- DEMUCS / SEMamba 用深度网络在时域或时频域端到端做语音-噪声分离
