# 题目内容

多多和小明进行赛马比赛，两人各有 $N$ 匹赛马。用一个 $N\times N$ 的矩阵 $M$ 表示这些赛马之间的比赛结果：
$(M[i][j]=1)$ 表示多多的第 $i$ 匹马可以战胜小明的第 $j$ 匹马，多多得 $1$ 分。

$M[i][j]=-1$ 表示多多的第 $i$ 匹马会输给小明的第 $j$ 匹马，多多扣 $1$ 分。

比赛共进行 $N$ 轮，每轮：

小明从自己剩余的马中选择一匹上场。

多多看到小明的选择后，从自己剩余的马中选择一匹上场。

双方该对马对决，多多获得对应分数，两匹马均退出比赛。

双方均采用最优策略：小明希望最小化多多的总得分，多多希望最大化自己的总得分。

求多多最终能获得的最大总得分。




# 输入描述


第一行为一个整数 $T$，表示共有 $T$ 个测试数据($1 \le T \le10$)

每个测试数据：

第一行一个整数 $N$ ($1\le N\le100$)，表示每人拥有的马的数量。

接下来 $N$ 行，每行 $N$ 个整数，第 $i$ 行第 $j$ 列的整数 $M[i][j] \in \{1,-1\}$，表示多多的第 $i$ 匹马对小明的第 $j$ 匹马的结果。



# 输出描述


每个测试用例，输出一个整数，表示在双方均采用最优策略的情况下，多多能获得的最大总得分。

## 补充说明
不同的马之间可能有相互克制关系，例如多多的马 $A$ 克制小明的马 $B$，小明的马 $B$ 克制多多的马 $C$，多多的马 $C$ 克制小明的马 $D$，小明的马 $D$ 克制多多的马 $A$。
$A\rightarrow B\rightarrow C\rightarrow D\rightarrow A$

也就是说，数据中可能会有环，没有绝对最快的马。


## 样例1 



**输入** 



```
2
1
1
2
1 1
-1 -1
```



**输出** 



```
1
0
```



**说明**

一共$2$组数据：

第一组一匹马，多多获胜，得$1$分。

第二组两匹马，多多的马1可以胜过其他马，马2谁也比不过，一胜一负，$0$分。
