# P5385 测试数据说明

共 $10$ 组。每组文件内有 $q$ 场（$1\le q\le 10$），每场 $m\times m$ 的 $\pm 1$ 对阵册。答案为 $2\cdot\mathrm{MM}-m$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 | `-1` 与全可配 `2` | 单艇败仍输出 `1` |
| 2 | 样例2 完美匹配 | `3` | 有环就判无解 |
| 3 | 样例3 匹配 $2$ | `1` | 直接输出匹配数 $2$ |
| 4 | $m=1$ 胜、全胜、全负、对角 | $\pm m$、对角得分 $2-m$ | 全负输出 `0` |
| 5 | 循环 / 上三角 / 稀疏 | 结构 | 按行和排序贪心 |
| 6 | 一列全 $1$、置换、极端 | 匹配上界 | 同一艘艇重复应战 |
| 7 | 循环 $m=1..7$ | 短增广路 | 只匹配对角 |
| 8 | 随机 $m\le 12$ | 对拍 | I/O 场次错位 |
| 9 | $q=10,m=100$ 构造+随机 | 压测 | $O(m^4)$ |
| 10 | $q=10,m=100$ 混合 | 压测 | 同上 |

前 $8$ 组小；后 $2$ 组压测。
