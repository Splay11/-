# 题目内容

给定一个进制 $B$、一个长度 $L$ 和一个序号$ K$，求第$ K$ 个长度为 $L$ 的$ B$ 进制回文数（不含前导零）的十进制值。

回文数定义：一个数正读和反读都相同。例如，在十进制中，$121、1331 $都是回文数。

注意：

- 回文数的长度指其 $B $进制表示的位数
- 首位不能为零（即不含前导零）
- 回文数按照从小到大的顺序编号，从$ 1 $开始

约束条件

- $2 \le B \le 16$
- $1 \le L \le 60$
- $1 \le K \le 9*10^8$
- 保证第 $K$ 个回文数存在
- 答案不超过 $10^{18}$

# 输入描述

输入一行，包含三个整数$ B、L、K$，用空格分隔。

# 输出描述

输出一个整数，表示第 K 个长度为 L 的 B 进制回文数的十进制值。



## 样例1 

**输入** 

```
3 4 5
```

**输出** 

```
68
```

**说明**

三进制下，长度为$ 4 $的回文数依次为 $1001 (28), 1111 (40), 1221 (52), 2002 (56), 2112 (68), 2222 (80)$，第 $5$ 个是 $2112$，对应的十进制值是 $68$

## 样例2

**输入** 

```
2 5 2
```

**输出** 

```
21
```

**说明**

二进制下，长度为$ 5$ 的回文数依次为 $10001 (17), 10101 (21), 11011 (27), 11111 (31)$，第 $2 $个是 $10101$，对应的十进制值是 $21$。

## 样例3

**输入** 

```
10 3 1
```

**输出** 

```
101
```

**说明**

二进制下，长度为$ 5$ 的回文数依次为 $10001 (17), 10101 (21), 11011 (27), 11111 (31)$，第 $2 $个是 $10101$，对应的十进制值是 $21$。
