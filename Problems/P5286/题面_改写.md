# 配平读数下线

# 题目内容

仓储调度台在出库前要对货位读数做配平检查。每个货位贴有一个正整数读数。规程写明：若仍处于「在册」状态的两个货位，读数之和恰好等于配平阈值，则视为配平冲突，出库流程会被拦截。起初全部货位都在册。值班员每次操作可将一个货位的在册状态翻转（在册变为不在册，或不在册变为在册）。求最少操作次数，使得不再存在配平冲突。

形式化地：给定 $m$ 个正整数 $v_1,v_2,\ldots,v_m$ 与配平阈值 $t$。初始时每个下标都在册。一次操作将某个下标的在册状态取反。出库扫描时，若存在下标 $p,q$（$p\neq q$）同时在册且

$$
v_p+v_q=t,
$$

则判定为冲突。求使冲突不再出现所需的最少操作次数。

# 输入描述

第一行两个正整数 $m$ 和 $t$，表示货位数与配平阈值。

第二行 $m$ 个正整数 $v_1,v_2,\ldots,v_m$，相邻两个数之间用一个空格隔开。

其中，$1\le m\le 100000$，$1\le t\le 1000000000$，$1\le v_i\le 1000000000$。

# 输出描述

输出一个非负整数，表示最少操作次数。

## 样例1

**输入**

```
1 8
6
```

**输出**

```
0
```

**说明**

只有一个货位在册，无法取出两个下标，不构成配平冲突，不必操作。

## 样例2

**输入**

```
6 12
4 8 5 7 4 1
```

**输出**

```
2
```

**说明**

- $4+8=12$：读数 $4$ 出现 `2` 次，$8$ 出现 `1` 次，关掉出现次数较少的一侧即可，需 `1` 次。
- $5+7=12$：两侧各出现 `1` 次，再关掉一侧，需 `1` 次。
- $1+11=12$：不存在读数 $11$，无需处理。

合计 `2` 次。例如将唯一的 $8$ 与唯一的 $7$ 下线后，剩余 $4,5,4,1$，任意两数之和都不是 $12$。

## 样例3

**输入**

```
4 14
7 7 7 3
```

**输出**

```
2
```

**说明**

$7+7=14$，同类读数出现 `3` 次，至多保留 `1` 个在册，必须下线 `2` 个。读数 $3$ 没有配平对象 $11$，可以全部保留。最少操作次数为 `2`。

# 数据范围

- $1\le m\le 100000$
- $1\le t\le 1000000000$
- $1\le v_i\le 1000000000$
- 所有输入均为整数
