# 题目内容

W 地区发现了一枚数字控制型炸弹，拆弹专家牛牛被指派去拆除这枚炸弹。牛牛注意到炸弹控制器上正好有 $n$ 个按钮，每个按钮上都写有一个自然数。每个按钮都有两种状态：触发和非触发，按下按钮可以改变其状态（即触发变为非触发，非触发变为触发）。最初，所有按钮都处于触发状态。

当且仅当在倒计时结束时炸弹上存在两个处于触发状态的按钮，并且它们上的数字总和恰好为 $k$ 时，炸弹才会爆炸。牛牛想知道，为了防止炸弹爆炸，他必须按下的最少按钮次数是多少。

# 输入描述

第一行输入两个正整数 $n$ 和 $k$。

第二行输入 $n$ 个自然数 $a_1,a_2,a_3,\ldots,a_n$，相邻两个数之间用一个空格隔开。

其中，$1\le n\le 10^5$，$1\le k\le 10^9$，$1\le a_i\le 10^9$。

# 输出描述

输出牛牛按下的最少按钮次数。

## 样例1

**输入**

```
1 1
2021
```

**输出**

```
0
```

**说明**

只有一个按钮处于触发状态，因此不必再按下按钮了。

## 样例2

**输入**

```
7 10
2 8 7 3 2 7 1
```

**输出**

```
2
```

**说明**

需要将 $8$ 和 $3$ 按下（使 $8$ 不能和 $2$ 组合，$3$ 不能和 $7$ 组合），使他们处于非触发状态，才有可能避免爆炸。

# 数据范围

- $1\le n\le 10^5$
- $1\le k\le 10^9$
- $1\le a_i\le 10^9$
- 所有输入均为整数
