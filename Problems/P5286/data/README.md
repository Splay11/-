# P5286 测试数据说明

输入：第一行 `n k`，第二行 `n` 个正整数。输出：最少按下/下线次数。末行规则：`.in` 无多余换行，`.out` 恰好一个换行。

| 组别 | 分值 | 规模/分布 | 目标 | 卡掉的错误解 |
|---:|---:|---|---|---|
| 1 | 样例 | $n=1$，原题样例 1 | 展示单点、答案为 $0$ | 误以为必须按一次 |
