# P7129 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：第一行 `n k`，第二行 $n$ 个整数。
输出：倒数第 $k$ 个节点的值。保证 $1 \le k \le n$。

题面未写 $n$、$a_i$ 上界。本套取 $1 \le n \le 10^4$，$-10^9 \le a_i \le 10^9$（与邻近链表题一致）。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1，$n=5,k=2$ | 倒数第 $2$ 个是 $4$ | 输出正数第 $2$ 个 $2$，或下标从 $0$ 数错成 $3$ |
| 2 | 倒数第 $1$ 个即尾节点 | 答案 $5$ | 快指针多走一步走到空，空指针 |
| 3 | 倒数第 $n$ 个即头节点 | 答案 $1$ | 快指针先走 $n$ 步后已是空，慢指针没动却取了错节点 |
| 4 | 最小规模 $n=k=1$ | 答案 $9$ | 空链表/越界 |
| 5 | 含负数，$k=2$ | 倒数第 $2$ 个是 $8$ | 只看绝对值 |
| 6 | $k=3$，落在中间 | 答案 $20$ | 快指针走 $k-1$ 步，答案偏成 $30$ |
| 7 | 有重复值 | 倒数第 $4$ 个是 $7$（从头数第 $2$ 个 $7$） | 按值去重 |
| 8 | 小随机 $n=15$ | 与下标 $n-k$ 对拍 | 快慢不同步 |
| 9 | 压满 $n=10^4$，$k=1$ 取尾 | 答案 $9999$ | 整表存成数组后倒着数写错边界 |
| 10 | 压满 $n=10^4$，$k=n/2$ | 取中间偏后那个节点 | 两遍扫描长度算错 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：双指针结果必须等于 $vals[n-k]$。
