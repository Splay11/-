# P7130 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：第一行 `n x`；$n>0$ 时第二行 $n$ 个整数；$n=0$ 时没有第二行。
输出：头插后从新头沿后继走一圈的节点值。

约束：$0 \le n \le 10^4$，$-10^9 \le a_i,x \le 10^9$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1 | 头插 $10$ 得到 $10\ 1\ 2\ 3\ 4$ | 接到末尾会得到 $1\ 2\ 3\ 4\ 10$ |
| 2 | 样例 2，单节点 | 得到 $7\ 5$，两节点成环 | 单节点没把头尾接成环 |
| 3 | 样例 3，空链表 $n=0$，无第二行 | 只输出 $8$ | 去读第二行导致 RE；或输出空行 |
| 4 | 头插 $0$，两节点 | 得到 $0\ 1\ 2$ | 把 $0$ 当成空表特殊处理 |
| 5 | 全负数 | 得到 $-1\ -3\ -2\ -1$ | 符号弄丢 |
| 6 | 新值与原节点重复 | 得到 $5\ 5\ 5\ 5$ | 去重后只留一个 $5$ |
| 7 | 值域边界 | 新头 $10^9$，后接极值 | int 溢出 |
| 8 | 小随机 $n=15$ | 链表头插与 $[x]+vals$ 对拍 | 遍历没停在 $n+1$ 步，死循环或少输出 |
| 9 | 压满 $n=10^4$，插入值域下界 | 新头接在序列最前 | 建表断环，或超时 |
| 10 | 压满 $n=10^4$，随机值 | 线性建表 + 头插 | Java 对 $n=0$ 多读一行在大数据上不易暴露，本组压 I/O |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：链表头插结果必须等于 $[x]+vals$。
