# 题目内容

有一个长度为 $n $的整数数组$ a$ 和一个整数 $k$。她想让数组$ a$ 里的元素进行配对，配对的两个数 $x,y$ 需要满足 $(x+k)\times(y+k)$是偶数。

数组$ a$ 的每个元素最多配对一次。

想要尽可能多的配对，你能帮帮她吗？

# 输入描述

第一行两个整数 $n,k(1 \le n \le 10^5,1 \le k \le 10^5)$。

第二行 $n $个整数 $a_1,a_2,\dots,a_n(1 \le a_i \le 10^5)$。

# 输出描述

第一行先输出一个整数 $m$，表示最大的配对数。

接下来$ m $行，每行两个整数，表示配对的两个数。

答案可以按任意顺序输出。如果有多解，输出任意一解即可通过。



## 样例1 

**输入** 

```
7 5
1 5 4 4 3 6 3
```

**输出** 

```
3
6 3
4 3
4 5
```

**说明**

$k=5$是奇数。$6+5=11$ 是奇数、$3+5=8$ 是偶数，乘积 $11\times 8=88$ 是偶数，所以 $(6,3)$ 可以配对；同理 $(4,3)$ 与 $(4,5)$ 也都合法。这三对用掉了 $6,4,4,3,3,5$ 共 $6$ 个元素，只剩下 $1$ 无法再配，因此最大配对数为 $3$。
