# 零件成盒

# 题目内容

装配线旁有 $m$ 个零件，第 $i$ 个零件的规格编号是 $v_i$。质检员还拿到一个调整参数 $d$。她要把零件两两装进盒子：一盒里的两个编号 $x,y$ 必须满足 $(x+d)\times(y+d)$ 是偶数。每个零件最多进一盒。

请帮她装进尽可能多的盒子，并给出一种装箱方案。

约束：
- `1` $\le$ $m$ $\le$ `100000`
- `1` $\le$ $d$ $\le$ `100000`
- `1` $\le$ $v_i$ $\le$ `100000`

# 输入描述

第一行两个整数 $m$、$d$（`1` $\le$ $m,d$ $\le$ `100000`），表示零件个数和调整参数。

第二行 $m$ 个整数 $v_1,v_2,\ldots,v_m$（`1` $\le$ $v_i$ $\le$ `100000`），表示各零件编号。

# 输出描述

第一行一个整数 $p$，表示最多能装多少盒。

随后 $p$ 行，每行两个整数，表示一盒里两个零件的编号。

配对顺序任意。若有多种最大方案，输出任意一种即可。

## 样例1

**输入**

```
6 4
1 2 3 5 7 8
```

**输出**

```
2
1 2
3 8
```

**说明**

$d=`4`$ 为偶数。$(1+4)\times(2+4)=`30`$ 是偶数，$(3+4)\times(8+4)=`84`$ 是偶数。四件奇数里剩下两件无法再和偶数配，最大为 `2` 盒。下面的输出也合法。

## 样例2

**输入**

```
4 2
1 3 5 7
```

**输出**

```
0
```

**说明**

$d$ 为偶数且零件全是奇数，$x+d$ 全是奇数，两两乘积仍为奇数，一盒都装不成。

## 样例3

**输入**

```
2 1
3 5
```

**输出**

```
1
3 5
```

**说明**

$d$ 为奇数，两个奇数配成一盒：$(3+1)\times(5+1)=`24`$ 是偶数。
