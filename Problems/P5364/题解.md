# 零件成盒

## 解题思路

$(x+d)\times(y+d)$ 是偶数，当且仅当 $x+d$ 与 $y+d$ 里至少有一个偶数，也就是 $x,y$ 里至少有一个和 $d$ 同奇偶。

1. 把与 $d$ 同奇偶的数放进 $same$，其余放进 $diff$。
2. $diff$ 里的两个数乘积对应两个奇数，不能配对；所以 $diff$ 只能和 $same$ 配。
3. 先把 $diff$ 尽量配给 $same$，剩下的 $same$ 再两两配对。若 $same$ 为空，一盒都装不成。
4. 最大盒数等于 $\min(|same|,\lfloor m/2\rfloor)$。方案不唯一，按上述顺序给出一种即可。

## 复杂度分析

时间复杂度为 $O(m)$。

空间复杂度为 $O(m)$。

## 代码实现

### Python

```python
def max_pairs(d, v):
    # (x+d)*(y+d) 为偶数 <=> 至少一个数与 d 同奇偶
    # 与 d 同奇偶的放 same，不同的放 diff；diff 只能和 same 配
    same = []
    diff = []
    for x in v:
        if x % 2 == d % 2:
            same.append(x)
        else:
            diff.append(x)
    pairs = []
    i = 0
    j = 0
    # 先把不同奇偶的配给 same
    while i < len(diff) and j < len(same):
        pairs.append((diff[i], same[j]))
        i += 1
        j += 1
    # 剩下的 same 两两配对
    while j + 1 < len(same):
        pairs.append((same[j], same[j + 1]))
        j += 2
    return pairs


def main():
    parts = input().split()
    m = int(parts[0])
    d = int(parts[1])
    v = list(map(int, input().split()))
    pairs = max_pairs(d, v)
    print(len(pairs))
    for x, y in pairs:
        print(x, y)


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int d = sc.nextInt();
        int[] v = new int[m];
        for (int i = 0; i < m; i++) {
            v[i] = sc.nextInt();
        }
        // 与 d 同奇偶的才能让 (x+d) 为偶数；diff 只能和 same 配
        List<Integer> same = new ArrayList<Integer>();
        List<Integer> diff = new ArrayList<Integer>();
        for (int i = 0; i < m; i++) {
            if (v[i] % 2 == d % 2) {
                same.add(v[i]);
            } else {
                diff.add(v[i]);
            }
        }
        List<int[]> pairs = new ArrayList<int[]>();
        int i = 0, j = 0;
        // 先把不同奇偶的配给 same
        while (i < diff.size() && j < same.size()) {
            pairs.add(new int[] {diff.get(i), same.get(j)});
            i++;
            j++;
        }
        // 剩下的 same 两两配对
        while (j + 1 < same.size()) {
            pairs.add(new int[] {same.get(j), same.get(j + 1)});
            j += 2;
        }
        System.out.println(pairs.size());
        for (int t = 0; t < pairs.size(); t++) {
            System.out.println(pairs.get(t)[0] + " " + pairs.get(t)[1]);
        }
        sc.close();
    }
}
```
