# 题目内容

给定一个由正数、负整数和 $0$ 组成的 $N \times M$ 矩阵，请找出元素总和最大的子矩阵。

一个子矩阵由矩阵中连续的若干行和连续的若干列组成。

设答案子矩阵左上角的位置为 $(r_1,c_1)$，右下角的位置为 $(r_2,c_2)$，其中行号和列号均从 $0$ 开始编号。

如果存在多个元素总和相同且最大的子矩阵，输出任意一个即可。

# 输入描述

第一行输入两个整数 $N$ 和 $M$，分别表示矩阵的行数和列数。

接下来 $N$ 行，每行输入 $M$ 个整数，其中第 $i$ 行第 $j$ 个整数表示矩阵中的元素 $matrix_{i,j}$。

### 约束

$1 \le N \le 200$

$1 \le M \le 200$

# 输出描述

输出四个整数 $r_1$、$c_1$、$r_2$、$c_2$，用空格分隔。

其中 $(r_1,c_1)$ 表示元素总和最大的子矩阵左上角位置，$(r_2,c_2)$ 表示该子矩阵右下角位置。

如果存在多个满足条件的子矩阵，输出任意一个即可。

## 样例 $1$

**输入**

```text
2 2
-1 0
0 -1
```

**输出**

```text
0 1 0 1
```

**说明**

位置 $(0,1)$ 的元素为 $0$。

选择左上角和右下角均为 $(0,1)$ 的子矩阵，其元素总和为 $0$，是所有子矩阵中的最大值，因此可以输出 $0\ 1\ 0\ 1$。
