# 最大子矩阵

## 解题思路

本题用到的是「枚举上下边界 + 一维 Kadane（最大子段和）」。

1. 最直接的想法是枚举所有子矩阵，但 $N, M \le 200$ 时子矩阵有 $O(N^2M^2)$ 个，约 $1.6 \times 10^9$ 个，会超时，需要降一维。
2. 关键观察：如果**固定上下边界** $r_1$ 与 $r_2$，那么任意一个「行区间为 $r_1 \sim r_2$」的子矩阵，其总和只取决于它取哪一段连续列。把第 $r_1$ 行到第 $r_2$ 行按列求和，得到一个长度为 $M$ 的一维数组 $col$，其中 $col[j]$ 是第 $j$ 列在这个行区间内的元素之和。于是原问题退化成一维问题：在 $col$ 中找一段连续区间，使其和最大。
3. 一维的「最大子段和」用 Kadane 算法可以在 $O(M)$ 内求出，同时在过程中记录这段区间的起点与终点，它们正好就是子矩阵的列边界 $c_1$ 与 $c_2$。
4. 因此只需枚举 $O(N^2)$ 个行区间，每个区间跑一次 $O(M)$ 的 Kadane，总复杂度 $O(N^2M)$。$N=M=200$ 时约为 $8 \times 10^6$，可以轻松通过。
5. 实现细节一（坐标记录）：Kadane 过程中用一个变量 $cStart$ 记住「当前累加区间的起点」；每当累加和刷新了历史最优，就把 $(r_1, cStart, r_2, j)$ 一起记下来，扫描结束时它就是要输出的四个坐标。
6. 实现细节二（子矩阵必须非空）：Kadane 的写法采用「若当前累加和 $\le 0$，就丢弃它并从当前列重新开始」。这样即使矩阵里全是负数，也会取到最大的那个**单个元素**，而不会出现「空子矩阵总和为 $0$」的非法答案。样例 1 正是这种情况：最优总和是 $0$，来自某个单独的 $0$ 元素，而不是什么都不选的空矩阵。
7. 实现细节三（并列任取）：只在累加和**严格大于**当前最优时才更新坐标，于是并列时保留先找到的那一个，满足题面「输出任意一个即可」。

## 复杂度分析

时间复杂度为 $O(N^2M)$：枚举上下边界共 $O(N^2)$ 对，每对内部先花 $O(M)$ 维护列和，再花 $O(M)$ 跑一次 Kadane，合计 $O(N^2M)$。取 $N=M=200$ 时约为 $8 \times 10^6$ 次基本操作。

空间复杂度为 $O(M)$：除输入矩阵本身外，只需要一个长度为 $M$ 的列和数组，以及常数个用于记录坐标与当前最优值的变量。

## 代码实现

### Python

```python
class Solution:
    def maxSubmatrix(self, matrix):
        n = len(matrix)
        m = len(matrix[0])
        # best 记录目前找到的最大总和；br1/bc1/br2/bc2 是它对应的四个坐标
        best = None
        br1 = bc1 = br2 = bc2 = 0

        # 枚举子矩阵的上下边界 r1、r2（共 O(n^2) 对）
        for r1 in range(n):
            # col[j] 表示第 j 列在第 r1 行到当前 r2 行之间的元素之和
            col = [0] * m
            for r2 in range(r1, n):
                row = matrix[r2]
                for j in range(m):
                    col[j] += row[j]

                # 行区间固定后，问题变成一维的「最大子段和」，用 Kadane 求列区间
                cur = 0          # 当前连续列的累加和
                c_start = 0      # 当前连续列的起点
                for j in range(m):
                    if cur <= 0:
                        # 前面的累加和不为正，留着只会拖累结果，从当前列重新开始
                        cur = col[j]
                        c_start = j
                    else:
                        cur += col[j]
                    # 比当前最优更大才更新，保证并列时取先找到的那一个
                    if best is None or cur > best:
                        best = cur
                        br1, bc1, br2, bc2 = r1, c_start, r2, j

        # 返回最优子矩阵的左上角与右下角坐标
        return [br1, bc1, br2, bc2]


def main():
    # 第一行：矩阵行数 N 和列数 M
    n, m = map(int, input().split())
    # 接下来 N 行，每行 M 个整数
    matrix = [list(map(int, input().split())) for _ in range(n)]
    # 输出四个整数：r1 c1 r2 c2
    print(*Solution().maxSubmatrix(matrix))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    // 返回 {r1, c1, r2, c2}，表示元素总和最大的子矩阵的左上角与右下角坐标
    static int[] maxSubmatrix(int[][] matrix) {
        int n = matrix.length;
        int m = matrix[0].length;

        // best 记录目前找到的最大总和；br1/bc1/br2/bc2 是它对应的四个坐标
        long best = 0;
        boolean has = false;
        int br1 = 0, bc1 = 0, br2 = 0, bc2 = 0;

        // 枚举子矩阵的上下边界 r1、r2（共 O(n^2) 对）
        for (int r1 = 0; r1 < n; r1++) {
            // col[j] 表示第 j 列在第 r1 行到当前 r2 行之间的元素之和
            long[] col = new long[m];
            for (int r2 = r1; r2 < n; r2++) {
                for (int j = 0; j < m; j++) {
                    col[j] += matrix[r2][j];
                }

                // 行区间固定后，问题变成一维的「最大子段和」，用 Kadane 求列区间
                long cur = 0;      // 当前连续列的累加和
                int cStart = 0;    // 当前连续列的起点
                for (int j = 0; j < m; j++) {
                    if (cur <= 0) {
                        // 前面的累加和不为正，留着只会拖累结果，从当前列重新开始
                        cur = col[j];
                        cStart = j;
                    } else {
                        cur += col[j];
                    }
                    // 比当前最优更大才更新，保证并列时取先找到的那一个
                    if (!has || cur > best) {
                        has = true;
                        best = cur;
                        br1 = r1; bc1 = cStart; br2 = r2; bc2 = j;
                    }
                }
            }
        }

        // 返回最优子矩阵的左上角与右下角坐标
        return new int[] {br1, bc1, br2, bc2};
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // 第一行：矩阵行数 N 和列数 M
        int n = sc.nextInt();
        int m = sc.nextInt();
        // 接下来 N 行，每行 M 个整数
        int[][] matrix = new int[n][m];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                matrix[i][j] = sc.nextInt();
            }
        }

        int[] ans = maxSubmatrix(matrix);
        // 输出四个整数：r1 c1 r2 c2
        System.out.println(ans[0] + " " + ans[1] + " " + ans[2] + " " + ans[3]);
        sc.close();
    }
}
```
