# 题目内容

多多是一名货车司机，这次他接到一个运输任务，需要在最短时间内把货物从城市$ 1$ 运送到城市$ N$。

已知这 $N$ 个城市之间有$ M $条双向道路，每条路可以用四个整数来描述：\(u_i,v_i,c_i,t_i\)，表示该道路连接城市 $u_i$ 和 $v_i$，货车通过这条路需要消耗 $c_i$ 单位的汽油，花费 $t_i$ 分钟。

多多的货车出发时油箱中有 $F$ 单位燃油（油箱容量为 $F$，油量不能超过 $F$）。在城市$ i$，可以加油，每加 $1$ 单位燃油需要花费 $p_i$ 分钟。

请你帮多多算一算，他从城市 $1$ 到城市 $N$ 需要的最短时间，如果无法到达输出 $-1$。



# 输入描述

第一行包含三个整数 \(N,M,F\)，分别代表城市的数量、双向道路的数量以及油箱的容量。

 第二行包含 $N$ 个整数 $p_1,p_2,\dots,p_N$，表示在各城市每加 $1$ 单位燃油需要花费的分钟数。 

接下来 $M$ 行，每行包含四个整数 $u_i,v_i,c_i,t_i$，描述每条双向道路。

$N\ M\ F$
$P_1\  P_2...P_N$
$u_1\ v_1\ C_1\ t_1$
$U_M\ U_M\ C_M\ t_M$

**约束**

- $2 \le N \le 1000$
- $1 \le M \le 10000$
- $1 \le F \le 100$
- $0 \le p_i \le 100$
- $1 \le c_i \le 100$
- $1 \le t_i \le 1000$
- $1 \le u_i,v_i \le N$

# 输出描述

一个整数，表示他从城市 $1 $到城市 $N $需要的最短时间，若无法到达输出 `-1`。



## 样例1 

**输入** 

```
3 3 3
2 3 5
1 2 1 10
1 3 1 100
2 3 3 1
```

**输出** 

```
14
```

**说明**

$1 \to 2$（耗油 $1$，$10$ 分钟）$\to$ 在 $2$ 加油 $1$ 单位（$3$ 分钟）$\to 2\to3$（耗油 $3$，$1$ 分钟），总计 $14$ 分钟。直接 $1\to3$ 需要 $100$ 分钟



## 样例2 

**输入** 

```
2 1 5
1 10
1 2 10 5
```

**输出** 

```
-1
```

**说明**

不可达
