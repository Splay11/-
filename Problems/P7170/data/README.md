# P7170 测试数据说明

主造数脚本：题目根目录 `gen.py`。翻转后超出 $[-2^{31},2^{31}-1]$ 输出 $0$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1 | 321 | 输出 3210 |
| 2 | 样例 2 负号保留 | -321 | 输出 321 |
| 3 | 样例 3 丢掉前导零 | 21 | 输出 021 |
| 4 | 样例 4 | 0 | 输出空 |
| 5 | 下界，翻转必溢出 | 0 | 取相反数溢出 |
| 6 | 上界，翻转溢出 | 0 | 用 64 位硬存 |
| 7 | 正数翻转溢出 | 0 | 不检查溢出 |
| 8 | 负数翻转仍在范围内 | 对拍 | 负号处理错 |
| 9 | 中间很多 0 | 3000000001 溢出故 0 | 丢掉 0 后位数判断错 |
| 10 | 翻转后贴上界 | 2147483641 | 误判溢出 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。
