# P7132 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：第一行 `n targetSum`；$n>0$ 时第二行 $n$ 个层序记号；$n=0$ 时没有第二行。
输出：第一行路径条数 $k$，随后 $k$ 行路径；没有路径时只输出 $0$。

约束：非空节点个数 $\le 5000$，$-1000\le Node.val,targetSum\le 1000$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1 | 两条路径 $5\ 4\ 11\ 2$ 与 $5\ 8\ 4\ 5$ | 先右后左会把顺序写反；漏掉 $5\ 8\ 4\ 5$ |
| 2 | 样例 2，两条叶子都不匹配 | 只输出 $0$ | 把 $1\ 2$ 或 $1\ 3$ 硬输出 |
| 3 | 样例 3，$targetSum=0$ 但路径和为 $3$ | 只输出 $0$ | 把根当成叶子，输出 $1$ 和 $1$ |
| 4 | 空树 $n=0$，无第二行 | 只输出 $0$ | 去读第二行导致 RE |
| 5 | 单节点且值等于目标 | 一条路径就是 $7$ | 单节点不当成叶子 |
| 6 | 含负数，目标为负 | 路径 $1\ -2\ -3$ | 当前和已超就剪枝，负数分支被砍掉 |
| 7 | 四条叶子路径和都是 $9$ | 按从左到右输出四条 $5\ 3\ 1$ / $5\ 3\ 1$ / $5\ 3\ 1$ / $5\ 3\ 1$ | 去重后只留一条 |
| 8 | 左偏小链，唯一路径命中 | 整条链 $10\ -3\ 2\ -1\ 5$ | 链上中途节点也当叶子输出前缀 |
| 9 | 压满完全树 $m=4095$，全部为 $1$，目标和 $0$ | 无路径 | 层序建树错位，或把非叶子当叶子扫出大量假路径 |
| 10 | 压满 $m=5000$ 随机值，目标和取最左路径和 | 至少包含最左根到叶 | 递归过深（本组是完全树，高约 $12$）；I/O 超时 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：标程 DFS 结果必须等于独立实现的根到叶路径过滤。
