# 直捣黄龙（最短安全路径统计）

## 题目描述

小王在玩一款叫做「直捣黄龙」的小游戏。敌军阵营是一个 $n \times n$ 的矩阵，**入口**在坐标 $(0, n/2)$，**敌军司令部**在 $(n-1, n/2)$。每个哨兵警戒以自身为中心的 **$3 \times 3$ 九宫格**（含自身，即切比雪夫距离 $\le 1$ 的格子），角色进入这些格子则行动失败。

角色每次只能向 **上、下、左、右** 四邻走一步（坐标 $(x,y)$ 中**恰好**有一个分量变化 $1$）。你需要统计：在**不进入任何哨兵九宫格**的前提下，从入口到司令部的 **最短路径** 有多少条，以及该最短路径上的 **格子数**（含起点与终点，与官方样例一致）。

评测采用 **LeetCode 核心代码模式**：只需实现 `Solution` 类中的方法，平台负责读入并调用。**不要**编写 `main` 或标准输入输出。

## 规则说明

1. $n$ 为大于 $1$ 的**奇数**，且 $n < 30$。坐标 $x$ 表示**行**，$y$ 表示**列**；$(0,0)$ 为矩阵**左下角**，$(n-1,n-1)$ 为**右上角**（与官方题面一致）。
2. 入口为 $(0, n/2)$，司令部为 $(n-1, n/2)$（整数除法下 $n/2$ 即 $\lfloor n/2 \rfloor$，因 $n$ 为奇数，恰为正中列）。
3. 对每个哨兵 $(gx, gy)$，所有满足 $\max(|x-gx|, |y-gy|) \le 1$ 且在矩阵内的格子 $(x,y)$ **不可走**。
4. 若不存在满足条件的从入口到司令部的路径，返回 **`[0, 0]`**（先条数，后长度）。

## 方法签名

三种语言类名均为 `Solution`，请实现：

- **C++**：`vector<int> countShortestPaths(int n, vector<vector<int>>& guards);`
- **Java**：`public List<Integer> countShortestPaths(int n, List<List<Integer>> guards)`
- **Python**：`def countShortestPaths(self, n: int, guards: List[List[int]]) -> List[int]:`

### 参数说明

- `n`：方阵边长，为奇数，$1 < n < 30$。
- `guards`：哨兵坐标列表，每个元素为长度 $2$ 的列表或等价结构，表示 $(x, y)$。可为空列表 `[]`。

### 返回值

长度为 $2$ 的整数列表：`[最短路径条数, 最短路径上的格子数]`。若不可达则为 `[0, 0]`。  
多条最短路时，条数为所有**边数最少**的路径数量；长度为该最短路对应的**顶点数**（边数 $+ 1$）。

## 输入格式（平台侧，选手无需编写）

一行文本，形如：

```text
<n>,<哨兵列表>
```

- `<n>` 为十进制整数。
- 逗号后为 Python 字面量风格的列表，元素为形如 `(x, y)` 的二元组或 `[x, y]` 的列表，例如：`[(1,1)]`、`[(2,1),(0,3)]`、`[]`。
- 允许在逗号两侧及括号内外有**任意数量空格**（解析以与样例同形为准）。

## 输出格式

一行，为两个整数的 JSON 数组，**逗号后无空格**，行末换行。例如：`[0,0]`、`[1,7]`、`[2,9]`。

## 样例 1

**输入**

```text
3,[(1,1)]
```

**输出**

```text
[0,0]
```

**解释**：哨兵在中心，九宫格覆盖全图，入口与终点均在警戒范围内，无可行最短路，返回 `[0, 0]`。

## 样例 2

**输入**

```text
5,[(2,1)]
```

**输出**

```text
[1,7]
```

**解释**：唯一一条最短路上的格子数为 $7$（官方说明中的路径含 $7$ 个坐标）。

## 样例 3

**输入**

```text
5,[(2,2)]
```

**输出**

```text
[2,9]
```

**解释**：两条不同的最短路径，每条含 $9$ 个格子。

## 数据范围

- $3 \le n < 30$，$n$ 为奇数。
- 哨兵个数 $0 \le m \le n^2$，坐标均在 $[0, n-1]$ 内；**同一格子可有多个哨兵**（九宫格取并集）。
- 最短路条数在评测数据范围内可用 **64 位有符号整数** 表示（标程 C++/Java 使用 `long long` / `long` 累加）。
