# 居民区工厂选址

# 题目内容

某地区有 $n$ 个居民区分布在二维平面上，第 $i$ 个居民区的坐标为 $(x_i, y_i)$，且该居民区有 $p_i$ 名居民。现在需要在该平面上选择一个点作为工厂的选址，使得所有居民到工厂的加权曼哈顿距离之和最小。

- **曼哈顿距离**：两点 $(a, b)$ 和 $(c, d)$ 之间的曼哈顿距离为 $|a - c| + |b - d|$；
- **加权曼哈顿距离**：对于第 $i$ 个居民区，其到工厂 $(X, Y)$ 的加权曼哈顿距离为 $p_i \times (|x_i - X| + |y_i - Y|)$。

请你计算出这个最小的加权曼哈顿距离之和。

解答要求：

- 时间限制：C/C++ $100$ms，其他语言：$200$ms
- 内存限制：C/C++ $256$MB，其他语言：$512$MB

# 输入描述

第一行包含一个整数 $n$（$1 \le n \le 10000$），表示居民区的数量。

接下来 $n$ 行，每行包含三个整数 $x_i, y_i, p_i$（$-10^9 \le x_i, y_i \le 10^9$，$1 \le p_i \le 10^6$），分别表示第 $i$ 个居民区的坐标和居民数量。

# 输出描述

输出最小的加权曼哈顿距离之和。

## 样例1

**输入**

```
3
1 2 3
4 5 2
7 8 1
```

**输出**

```
24
```

**说明**

把工厂建在 $(1, 2)$ 时：

- 到 $(1, 2)$ 的距离是 $0$，人数 $3$，贡献 $0 \times 3 = 0$
- 到 $(4, 5)$ 的距离是 $|4-1| + |5-2| = 6$，人数 $2$，贡献 $6 \times 2 = 12$
- 到 $(7, 8)$ 的距离是 $|7-1| + |8-2| = 12$，人数 $1$，贡献 $12 \times 1 = 12$
- 总距离之和为 $0 + 12 + 12 = 24$，这就是最小的加权曼哈顿距离之和，所以答案是 $24$

## 样例2

**输入**

```
3
0 0 1
2 0 1
1 2 1
```

**输出**

```
4
```

**说明**

把工厂建在 $(1, 0)$ 时：

- 到 $(0, 0)$ 的距离是 $1$，贡献 $1 \times 1 = 1$
- 到 $(2, 0)$ 的距离是 $1$，贡献 $1 \times 1 = 1$
- 到 $(1, 2)$ 的距离是 $2$，贡献 $2 \times 1 = 2$
- 总距离之和为 $1 + 1 + 2 = 4$，这就是最小的加权曼哈顿距离之和，所以答案是 $4$
