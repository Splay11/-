# P7157 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：第一行 $n$，随后 $n$ 行 $start$ $end$。
输出：最少删除区间数。端点相碰不算重叠。

约束：$1\le n\le 10^5$，$-5\times 10^4\le start<end\le 5\times 10^4$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1，删掉覆盖三段的长区间 | $1$ | 按左端点贪心可能多删 |
| 2 | 样例 2，三个完全相同 | $2$ | 相同区间只删 $1$ 个 |
| 3 | 样例 3，端点相碰 | $0$ | 把相碰当成重叠输出 $1$ |
| 4 | $n=1$ 负数端点 | $0$ | 输出 $1$ |
| 5 | 大区间包住两段相碰的短区间 | 删 $1$ 个 | 按左端点先留下大区间 |
| 6 | 长区间左端更靠前 | 删 $1$ 留三段短的 | 按左端点排序贪心 |
| 7 | 两段相碰再加一段分离 | $0$ | 负数没处理 |
| 8 | 中等随机 $n=60$ | 与 $O(n^2)$ DP 对拍 | 区间 DP TLE 在后面大数据 |
| 9 | 压满 $n=10^5$ 单位区间首尾相接 | $0$ | 相碰当重叠会删很多；$O(n^2)$ TLE |
| 10 | 压满 $n=10^5$ 完全相同 | $n-1$ | 只删 $1$ 个或输出 $0$ |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：$n\le 300$ 时贪心必须等于 $O(n^2)$ DP。
