## 解题思路

本题求**最长连续有效子数组**，规则可归纳为三类局部约束：

1. 子链必须以 `0` 开头；
2. `1` 的前一项必须是 `0`；`2` 的前两项必须是 `0,0`；
3. 相邻两个 `0` 之间至多一个非 `0` 元素（等价于不能出现 `0,1,1,0` 或 `0,1,2,0` 等「两连扩展/高级夹在两个基础之间」）。

**动态规划（三状态）**：扫描到下标 `i` 时，维护以 `i` 结尾的最长合法链长度：

- `dp0`：末尾为 `0`；
- `dp1`：末尾为 `1`（且前一项为 `0`）；
- `dp2`：末尾为 `2`（且前两项为 `0,0`）。

转移：

- 当前为 `0`：可新开长度为 `1`，或接在 `dp0/dp1/dp2` 后各 `+1`；
- 当前为 `1`：若 `type[i-1]==0` 且 `dp0>0`，则 `dp1=dp0+1`；
- 当前为 `2`：若 `type[i-1]==type[i-2]==0` 且 `dp0>0`，则 `dp2=dp0+1`。

答案为全程 `max(dp0,dp1,dp2)`；空数组返回 `0`。

**常见假解**：

- 忽略「首元素必须是 0」→ 样例 3 错；
- 把 `2` 当成只依赖前一个 `0`（允许 `0,2,0`）→ hack 组 8 错；
- 允许两个 `1` 夹在两个 `0` 之间 → hack 组 7 错。

## 复杂度分析

- 时间：$O(n)$，一次线性扫描，$n=\texttt{type.length}$；
- 空间：$O(1)$，仅常数个 DP 变量。

## 代码实现

### Python

```python
from typing import List


class Solution:
    def longestValidSkillChain(self, type: List[int]) -> int:
        n = len(type)
        if n == 0:
            return 0

        dp0 = dp1 = dp2 = 0
        ans = 0

        for i in range(n):
            nd0 = nd1 = nd2 = 0
            if type[i] == 0:
                nd0 = 1
                if i > 0:
                    # 基础类型可接在 0/1/2 之后，或单独作为新链起点
                    nd0 = max(nd0, dp0 + 1, dp1 + 1, dp2 + 1)
            elif type[i] == 1:
                # 扩展类型：直接前驱必须是基础类型
                if i > 0 and type[i - 1] == 0 and dp0 > 0:
                    nd1 = dp0 + 1
            elif type[i] == 2:
                # 高级类型：前驱与前前驱都必须是 0
                if i >= 2 and type[i - 1] == 0 and type[i - 2] == 0 and dp0 > 0:
                    nd2 = dp0 + 1

            dp0, dp1, dp2 = nd0, nd1, nd2
            ans = max(ans, dp0, dp1, dp2)

        return ans
```

### Java

```java
public class Solution {
    public int longestValidSkillChain(int[] type) {
        int n = type.length;
        if (n == 0) return 0;

        int dp0 = 0, dp1 = 0, dp2 = 0, ans = 0;
        for (int i = 0; i < n; i++) {
            int nd0 = 0, nd1 = 0, nd2 = 0;
            if (type[i] == 0) {
                nd0 = 1;
                if (i > 0) {
                    nd0 = Math.max(nd0, Math.max(dp0 + 1, Math.max(dp1 + 1, dp2 + 1)));
                }
            } else if (type[i] == 1) {
                if (i > 0 && type[i - 1] == 0 && dp0 > 0) {
                    nd1 = dp0 + 1;
                }
            } else if (type[i] == 2) {
                if (i >= 2 && type[i - 1] == 0 && type[i - 2] == 0 && dp0 > 0) {
                    nd2 = dp0 + 1;
                }
            }
            dp0 = nd0;
            dp1 = nd1;
            dp2 = nd2;
            ans = Math.max(ans, Math.max(dp0, Math.max(dp1, dp2)));
        }
        return ans;
    }
}
```
