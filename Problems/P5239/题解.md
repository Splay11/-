# 答案+解析

可采用「端侧优先、复杂任务上云」的协同架构：

- **时延（对应 $a$）**：用 **GQA/MLA** 压缩 KV Cache；权重侧优先 **AWQ INT4**（或 SmoothQuant/NF4 视激活敏感度选型）；解码侧上 **Speculative Decoding / Medusa**，目标把中端机首 token 从约 $750$–$800$ms 压向 $280$ms 量级。
- **检索（对应 $b$）**：视觉编码换 **SigLIP**（或经 DFN 过滤数据训出的更强对比编码器），时序用 **VideoMAE / 关键帧采样**（复杂语义再用 VideoLLaMA 类模型），索引用 **FAISS/Qdrant**；离线看 Recall@$k$、mAP，线上用点击率/采用率做 A/B。
- **个性化（对应 $c$）**：冷启动用 **few-shot in-context + 用户风格向量**（隐私友好、存储小）；样本足够后再上 **轻量 LoRA** 提稳定性，并在「隐私 / 存储 / 效果」三维做账号级开关。
- **路由（对应 $d$）**：规则示例——弱网/断网或隐私片段优先端侧；复杂多镜长视频且电量/算力充足可上云；超时或云失败回退端侧模板剪辑，并维护统一 Edit Plan 保证端云时间线一致；放量时按机型与网络分层灰度。
