# P5358 测试数据说明

共 $10$ 组。第一行 $h$、$w$，随后 $h$ 行每行 $w$ 个 `0`/`1`。输出最短格子数或 `-1`。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 | 绕开货架 | 斜走 |
| 2 | 样例2 对角空地 | `-1` | 八连通 |
| 3 | 样例3 $1\times 1$ | 答案 `1` | 输出 `0` |
| 4 | $2\times 2$ 全空 | 答案 `3` | 按边数输出 `2` |
| 5 | 起点为 `1` | `-1` | 没判起点 |
| 6 | 终点为 `1` | `-1` | 没判终点 |
| 7 | 仅斜向可通 | `-1` | 八方向 BFS |
| 8 | 蛇形走廊 | 唯一长路 | DFS 乱走 |
| 9 | $500\times 500$ 全空 | 压测，答案 $999$ | $O((hw)^2)$ |
| 10 | $500\times 500$ 随机墙 | 压测 | TLE |

前 $8$ 组小；后 $2$ 组压测。
