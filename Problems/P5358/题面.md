
## 题目内容
给定一个$m \times n$的二维迷宫，其中$0$表示通路，$1$表示墙壁。起点为左上角$((0,0))$，终点为右下角$(m-1, n-1)$。找出从起点到终点的最短路径长度，若无法到达则返回$-1$。

假设迷宫为：

```
3 3    // m行 n列
0 0 0  //迷宫的情况
1 1 0
0 0 0
```

最短路径为$5$

样例输入：

```
3 3
0 0 0
1 1 0
0 0 0
```

**样例输出：$5$**
