# 题目内容

仓库有$N$个货架。
第$i$个货架上有$A_i$件商品。
每天机器人都会从左到右经过所有货架。
机器人支持一种操作：
选择一个连续区间 $[l,r]$
一次性搬走这一段货架上的所有商品。
但是是由于机械臂限制：
一次操作只能搬走这一段中商品数量完全相同的货架。

例如：
$2\ 2\ 2$可以一次搬走。
$2\ 3\ 2$不能。
问最少需要多少次搬运运。



# 输入描述


第一行为一个整数$T$，表示共有$T$个测试数据($1<=T<=10$)
每个测试数据:

第一行: $N$

第二行: $A_1,\ A_2,\ ...,\ A_N$

约束: 货架数量: $N,\ 1 \le N \le 10^5$，第$i$个货架上的商品数量: $A_i,\ 1 \le A_i \le 10^5$



# 输出描述


每个测试用例的最少搬运次数


## 样例1 



**输入** 



```
1
8
2 2 3 3 3 1 1 2
```



**输出** 



```
4
```



**说明**

第1个用例

四段分别是

2 2
3 3 3
1 1
2

最终输出 4

## 样例2



**输入** 



```
2
5
1 2 3 4 5
6
1 1 2 2 2 3
```



**输出** 



```
5
3
```



**说明**

第1个用例

每个货架上的商品数量都不相同，1 次搬运只能搬走一个货架上的商品。最终需要 5 次搬运

第2个用例

商品数量相同的一起搬运， [1 1],[2 2 2],[3]。最终需要 3 次搬运
