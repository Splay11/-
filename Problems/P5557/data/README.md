# P5557 测例说明

输入与四级题面样例同形：第一行 $q$，随后 $q$ 行，每行先是 $m$ 再跟 $m$ 个零件个数。输出一行 $q$ 个答案，空格分隔。`.in` 末尾无换行，`.out` 末尾恰好一个换行。

分层：

- 1：四级样例 1。多段与整行同值。
- 2：四级样例 2。同值被隔开，段数是 $3$ 不是 $2$。
- 3：单工位、全不同、全相同、恰好两段。
- 4：零件个数取 $1$ 与 $100000$，以及交替序列。
- 5：小随机，值域很小，方便对拍。
- 6：严格递增、整段相同、变化落在最右或最左。
- 7：交替与成对重复。全局去重会得到 $2$，正解分别是 $200$ 与 $100$。
- 8：漏掉第一段会少 $1$；`3 3 1 1 3 3 3` 若允许中间清空后左右贴合，次数会变成 $2$，正解是 $3$。
- 9：$q=10$，每行 $m=100000$，严格交替。段数等于 $m$，去重只有 $2$。
- 10：$q=10$，每行 $m=100000$，周期为 $100000,100000,1$。正解每行 $66667$；若按贴合后再合并，会少很多。

生成答案预览：

- 1：$3\ 1$
- 2：$3$
- 3：$1\ 3\ 1\ 2$
- 4：$1\ 1\ 8$
- 8：$2\ 2\ 3$
- 9：每行 $100000$
- 10：每行 $66667$
