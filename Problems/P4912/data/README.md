# P4912 测试数据说明

题面约束：多组 $t$，$\sum n \le 4 \times 10^5$，$2 \le n \le 2 \times 10^5$，$1 \le m \le 10^9$，$a_i \in [1,m]$。本目录共 $10$ 组，编号 `1.in` … `10.out`。`.in` 文件**最后一行末尾无换行**；`.out` **末尾有且仅有一个** `\n`。

| 编号 | 设计意图 | 覆盖类型 |
|------|----------|----------|
| 1 | 题面样例原样 | 样例 / 格式 |
| 2 | $n=2,\ m=10^9$ 极大值域 | 边界 / 基础 |
| 3 | 长全相等序列 | 边界（大量 $0$ 间隔） |
| 4 | 小 $n$ 需形变抬高答案 | hack 假解「从不修改」 |
| 5 | 多组小 $n$ 随机 | 随机 / 暴力对拍 |
| 6 | 两簇近 + 中间大空洞 | 构造 / 桥接间隔 |
| 7 | 大步长近似等差 | 构造 / 与均匀上界相关 |
| 8 | 大量重复 + 单离群 | 构造 / 计数与排序稳定性 |
| 9 | 单组 $n=2 \times 10^5$ | 压力 / 复杂度 |
| 10 | 多组 $\sum n \approx 4 \times 10^5$ | 压力 / 多组总长度 |

生成脚本：`../gen.py`（固定种子 `491200`）。重跑后应用 `gen.py` 内自校验与（Windows 下）`std.cpp` 对比输出（已归一化 `\r\n`）。

**验题人可关注**：$m$ 与答案上界需 `int64`；判定 $G>0$ 时「坏间隔至多一处」与「宽缝 $\ge 2G$」的边界；全文件 $\sum n$ 与单组 $n$ 的混合压力。
