# 题目内容

在一条整数坐标轴上，部署了 n 个编号为 $1 $到 $n$ 的信标。第 j 个信标当前所在的坐标为 \(b_j\)，因此所有信标的位置可以表示为一个长度为 $n$ 的整数数组 $\{b_1,b_2,\dots,b_n\}$；为了衡量这些信标之间最大的 “盲区距离”，对于任意一个长度为$ n$ 的整数数组 $a$，定义函数：

$g(a)=\max_{i=\min(a_1,a_2,\dots,a_n)}^{\max(a_1,a_2,\dots,a_n)}\left(\min_{j=1}^n |i-a_j|\right),\ i\in \mathbb{Z}$

也就是说，只考虑从所有信标的最小坐标到最大坐标之间（含两端）的整数坐标 $i$。对于每个这样的坐标$ i$，计算它到最近信标的距离；而 $g(a)$ 就是这些距离中的最大值。

接下来会对信标坐标数组 b 进行 m 次修改；每次操作如下：

- 选择一个下标 $x$，将 $b_x$ 修改为$ y$。

每次修改后，请输出此时的 $g(b)$ 的值。

# 输入描述

第一行输入两个整数 $n,m\ (2 \le n,m \le 10^5)$，分别表示信标数量和操作次数；

 第二行输入$ n$ 个整数 $b_1,b_2,\dots,b_n\ (1 \le b_i \le 10^9)$，表示各个信标的初始坐标； 

接下来$ m$ 行，每行输入两个整数$(x,y\ (1 \le x \le n,\ 1 \le y \le 10^9)$，表示将编号为 x 的信标坐标修改为$ y$。

# 输出描述

输出$ m $行，每行输出一个整数，表示对应操作后的 $g(b)$ 的值。



## 样例1 

**输入** 

```
5 3
1 3 6 10 15
3 8
1 2
5 20
```

**输出** 

```
2
2
5
```
