# P5368 测试数据说明

共 $10$ 组。单组地图，$h\times w\le 200000$，输出任意一对最大曼哈顿过道。评测使用 `checker.cc`。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 $3\times 4$ | 基本机制 | 坐标从 $0$ 编号 |
| 2 | 样例2 单行 | 左右两端 | 只取最上与最下 |
| 3 | 样例3 反对角更远 | $r-c$ 才是最大 | 只取 $r+c$ 极值 |
| 4 | $4\times 1$ 单列 | 上下两端 | 只取最左与最右 |
| 5 | $2\times 2$ 全过道 | 对角线距离 $2$ | 输出同一格 |
| 6 | 内部一圈过道 | 框内最远 | 只看外圈四角（外圈是货架） |
| 7 | $6\times 8$ 随机 | 与暴力对拍 | 漏空地 |
| 8 | $12\times 12$ 偏少过道 | 构造稀疏 | 网格最短路当曼哈顿 |
| 9 | $1\times 200000$ 三过道 | 压测 I/O | 只配相邻过道 |
| 10 | $400\times 500$ 三角落 | 压测；$r-c$ 更大 | 只取 $r+c$ 或只取四角 |

前 $8$ 组小；后 $2$ 组压测。
