# 打靶凑总分的方案数

## 解题思路

1. 共打 $10$ 枪，每枪得分属于 $\{0,1,\ldots,10\}$，求总分恰好为 $S$ 的有序方案数（枪与枪可区分）。
2. 完全背包式计数 DP：令 $dp[s]$ 表示当前已打完若干枪后总分恰为 $s$ 的方案数，初始 $dp[0]=1$。
3. 枚举第 $1\ldots 10$ 枪，对每个旧状态 $s$ 与得分 $v\in[0,10]$，若 $s+v\le S$ 则累加到新的 $dp[s+v]$。
4. 答案为打完 $10$ 枪后的 $dp[S]$。方案数可达约 $10^9$，用 $64$ 位整数存储。

## 复杂度分析

- 时间复杂度：$O(10\cdot S\cdot 11)=O(S)$。
- 空间复杂度：$O(S)$。

## 代码实现

### Python

```python
# -*- coding: utf-8 -*-
"""P5515 打靶凑总分的方案数"""


def count_ways(S):
    # dp[s]：用若干次射击得到总分 s 的方案数
    dp = [0] * (S + 1)
    dp[0] = 1
    for _ in range(10):
        ndp = [0] * (S + 1)
        for s in range(S + 1):
            if dp[s] == 0:
                continue
            # 本枪得 0..10 分
            for v in range(11):
                if s + v <= S:
                    ndp[s + v] += dp[s]
        dp = ndp
    return dp[S]


def main():
    S = int(input())
    print(count_ways(S))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int S = Integer.parseInt(br.readLine().trim());
        // dp[s]：当前已打若干枪得到总分 s 的方案数
        long[] dp = new long[S + 1];
        dp[0] = 1;
        for (int shot = 0; shot < 10; shot++) {
            long[] ndp = new long[S + 1];
            for (int s = 0; s <= S; s++) {
                if (dp[s] == 0) continue;
                for (int v = 0; v <= 10; v++) {
                    if (s + v <= S) ndp[s + v] += dp[s];
                }
            }
            dp = ndp;
        }
        System.out.println(dp[S]);
    }
}
```

#include <bits/stdc++.h>

int main() {

    // dp[s]：当前已打若干枪得到总分 s 的方案数

    for (int shot = 0; shot < 10; shot++) {

        for (int s = 0; s <= S; s++) {

            }
        }
        dp.swap(ndp);
    }

}
