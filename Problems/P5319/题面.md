# 题目内容

笨蛋同学拿到一个长度为 $n$ 的 $01$ 字符串 $s = s_1 s_2 \dots s_n$。

她会从 $s$ 中选择一个下标集合
$1 \le p_1 < p_2 < \dots < p_m \le n$（$m$ 可以为 $0$），并按顺序拼接得到子序列字符串 $t = s_{p_1} s_{p_2} \dots s_{p_m}$。

如果 $t$ 不包含相邻的两个 $0$，也不包含相邻的两个 $1$，即
对任意 $1 \le i < |t|$ 都有 $t_i \neq t_{i+1}$，则称 $t$ 为一个“交替串”。

现在考虑所有能得到交替串的选择方案（不同下标集合视为不同方案）。把每个方案得到的字符串 $t$ 收集起来，得到一个字符串序列（允许出现相同的 $t$ 多次）。

将该序列按字典序从小到大排序后，求第 $k$ 个字符串是什么；如果不存在第 $k$ 个，输出 $-1$。
字典序比较规则：从左到右比较，第一处不同字符较小者字典序更小；若一个字符串是另一个的前缀，则较短者字典序更小。空串 "" 也参与排序。



# 输入描述


每个测试文件均包含多组测试数据，第一行输入一个整数 $T(1 \le T \le 2 \times 10^3)$ 表示数据组数，每组测试数据描述如下：
一行输入两个整数 $n,k \ (1 \le n \le 2 \times 10^3,\ 2 \le k \le 10^{15})$，不会出现答案为空。
一行输入一个长度为 $n$ 的 $01$ 字符串 $s$。
除此之外，保证单个测试文件中所有测试数据的 $n$ 之和不超过 $2 \times 10^3$。



# 输出描述


对于每组测试用例，输出一行字符串，代表排序后第 $k$ 个交替串；若不存在第 $k$ 项，输出 $-1$。


## 样例1 



**输入** 



```
1
2 3
01
```



**输出** 



```
1
```



**说明**

所有合法下标集合以及对应的 $t$：
- $(m=0)$：空串 ""
- $p_1=1$："0"
- $p_1=2$："1"
- $p_1=1,p_2=2$："01"
全部序列为：`["", "0", "1", "01"]`，字典序排序后，第 $1$ 项是空串，第 $2$ 项是 "0"，第 $3$ 项是 "1"，第 $4$ 项是 "01"。输入 $(k=3)$，因此输出 "1"。
