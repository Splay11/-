# 日志关键词统计与关联分析

给定日志字符串数组 `logs` 与关键词数组 `keywords`，完成：

1. **出现次数**：统计每个关键词在**全部日志**中出现的总次数（同一日志内多次出现分别计数）；
2. **经常关联**：若两个不同关键词在至少 $2$ 条**不同**日志中均至少出现一次，则记为一对关联组合；
3. **返回格式**：前 `keywords.length` 个整数为各关键词出现次数；其后每两个整数为一组关联组合的下标对 $(i, j)$，满足 $i < j$。多组组合按第一个下标升序，再按第二个下标升序排列。

## 匹配规则

1. **大小写不敏感**：`Error` 与 `error` 视为同一词；
2. **完整单词匹配**：关键词须与切分后的单词完全相同，不能是子串（如 `error` 不匹配 `errors`）；
3. **单词边界**：以空格或英文标点（`,` `.` `!` `?` `;` `:`）切分；字符串首尾亦视为边界；**不含**中文标点。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def analyzeLogKeywords(self, logs: List[str], keywords: List[str]) -> List[int]` |
| Java | `public int[] analyzeLogKeywords(String[] logs, String[] keywords)` |
| C++ | `vector<int> analyzeLogKeywords(vector<string>& logs, vector<string>& keywords)` |

**参数**

- `logs`：日志字符串数组，$1 \le |logs| \le 1000$，每条长度 $\le 1000$；
- `keywords`：关键词数组，$1 \le |keywords| \le 100$。

**返回值**

长度为「关键词个数 + $2 \times$ 关联组合个数」的整数数组，格式见上文。

## 输入输出格式（stdin / stdout）

**输入**（stdin：先 `logs` 字符串数组，逗号后为 `keywords` 字符串数组；两数组可在同一行，也可换行分隔；允许数组元素间有空格；双引号包裹字符串，与样例一致）：

```text
["Error in system", "warning: error detected", "No errors found"],["error", "warning"]
```

**输出**（stdout **一行**，方括号包裹的整数数组，元素逗号无空格）：

```text
[2,1]
```

## 数据范围

- $1 \le |logs| \le 1000$；
- $1 \le |keywords| \le 100$；
- 每条日志长度 $\le 1000$ 字符。

## 样例

### 样例 1

**输入**

```text
["Error in system", "warning: error detected", "No errors found"],["error", "warning"]
```

**输出**

```text
[2,1]
```

**说明**

`error` 出现 $2$ 次，`warning` 出现 $1$ 次；两词仅在第 $2$ 条日志中共现 $1$ 次，未达 $2$ 条，故无关联组合。

### 样例 2

**输入**

```text
["Error: system failure", "Warning: error in network", "System error detected again", "Network warning error found"],["error", "system", "warning", "network"]
```

**输出**

```text
[4,2,2,2,0,1,0,2,0,3,2,3]
```

**说明**

出现次数 $[4,2,2,2]$；关联组合 $(0,1)$、$(0,2)$、$(0,3)$、$(2,3)$ 均满足至少 $2$ 条日志共现。

### 样例 3

**输入**

```text
["Error in module A", "Module error B error", "Error module C error", "Module error D"],["error", "module"]
```

**输出**

```text
[6,4,0,1]
```

**说明**

`error` 共 $6$ 次，`module` 共 $4$ 次；两词在 $4$ 条日志中均出现，输出关联 $[0,1]$。

### 样例 4

**输入**

```text
["Test log one","Test log two","Test log three"],["test", "log", "one", "two", "three"]
```

**输出**

```text
[3,3,1,1,1,0,1]
```

**说明**

`test` 与 `log` 在 $3$ 条日志中均出现，构成唯一关联组合 $[0,1]$。
