# SN 地址重排

通信设备 $SN$ 一般包含字母与数字，并用 `-`（破折号）分组，例如 `8F-3T-1G-2n` 是一个有效的 $SN$ 地址。

现需将已有 $SN$ 按新规则重排：去掉原有分组破折号，提取全部字母与数字后转大写，再按每组恰好 $m$ 个字符（余数段放首组）重新用 `-` 连接。

## 重排规则

1. 从输入 $SN$ 中**按顺序**提取所有字母与数字（忽略 `-`）；若无任何字母或数字，返回空字符串 `""`。
2. 将小写字母转为大写。
3. 设有效字符总数为 $n$，分组长度参数为 $m$：
   - 若 $n \bmod m \neq 0$，**第一段**长度为 $n \bmod m$（小于 $m$），其余每段长度均为 $m$；
   - 若 $n \bmod m = 0$，每段长度均为 $m$。
4. 各段用 `-` 连接输出。
5. **异常场景**：$SN$ 中出现除字母、数字、`-` 以外的字符时，返回空字符串 `""`。

## 函数接口（LeetCode 核心代码模式）

实现类 `Solution` 的成员函数：

| 语言 | 签名 |
|------|------|
| Python | `def rearrangeSN(self, sn: str, m: int) -> str` |
| Java | `public String rearrangeSN(String sn, int m)` |
| C++ | `string rearrangeSN(string sn, int m)` |

**参数**

- `sn`：待重排的 $SN$ 字符串，长度 $< 10000$，可为空串；
- `m`：每组目标长度，$1 \le m \le 10$。

**返回值**

重排后的 $SN$ 字符串；异常或无有效字符时返回 `""`。

## 输入输出格式（stdin / stdout）

**输入**（stdin 单行，双引号包裹的 $SN$ 字符串 + 逗号 + 整数 $m$，逗号后无空格）：

```text
"8F-3T-1G-2n",4
```

**输出**（stdout 一行，双引号包裹的结果字符串）：

```text
"8F3T-1G2N"
```

## 数据范围

- $0 \le |sn| < 10000$；
- $1 \le m \le 10$。

## 样例

### 样例 1

**输入**

```text
"8F-3T-1G-2n",4
```

**输出**

```text
"8F3T-1G2N"
```

**说明**

有效字符 `8F3T1G2n` 共 $8$ 个，$8 \bmod 4 = 0$，分成 `8F3T` 与 `1G2N` 两段；原破折号删除后按新规则插入。

### 样例 2

**输入**

```text
"2-2g-5-g",2
```

**输出**

```text
"2-2G-5G"
```

**说明**

有效字符 `22g5g` 共 $5$ 个，$5 \bmod 2 = 1$，首段 $1$ 个字符 `2`，其余两段各 $2$ 个字符 `2G`、`5G`。

### 样例 3

**输入**

```text
"g",10
```

**输出**

```text
"G"
```

**说明**

仅 $1$ 个有效字符，首段长度 $1$，转大写后为 `G`。

### 样例 4

**输入**

```text
"2-2g-5-g",1
```

**输出**

```text
"2-2-G-5-G"
```

**说明**

$m=1$ 时每个字符单独成段。

### 样例 5

**输入**

```text
"",10
```

**输出**

```text
""
```

**说明**

输入为空字符串，无有效字符，返回空串。

### 样例 6

**输入**

```text
"---------",1
```

**输出**

```text
""
```

**说明**

仅有破折号、无字母或数字，返回空串。
