# 枚举暴力解法

这道题的正解是状压动态规划，但是我们用枚举机器子集的朴素解法也能在考试时拿到一定的分数。

每台机器提供若干条目，要从 $d$ 台里挑尽量少的几台，把业务点名的 $t$ 条全部覆盖；怎么挑都缺条目就输出 $0$。$d$ 不大时可以直接枚举「选哪些机器」。

1. 先给业务点名的 $t$ 条互异编号映射到比特 $0..t-1$，每台机器变成一个覆盖掩码。
2. 枚举 $0..2^{d}-1$ 的每一个子集，把选中机器的掩码做按位或，统计选了几台。
3. 能覆盖全集的子集里，留下台数最小的那个；一个都没有就输出 $0$。

子集共 $2^{d}$ 个。$d\le 8$ 的小数据可以过，但 $d$ 到 $30$ 时大约 $10^{9}$ 次运算，会超时，所以后面再用状压。

## 枚举解法

```python
def min_devices(specs, need):
    # 业务条目映射到比特，每台机器变成覆盖掩码
    bit = {}
    for i, x in enumerate(need):
        bit[x] = i
    t = len(need)
    covers = []
    for row in specs:
        mask = 0
        for x in row:
            if x in bit:
                mask |= 1 << bit[x]
        covers.append(mask)
    d = len(covers)
    full = (1 << t) - 1
    inf = t + 5
    best = inf
    # 枚举每一台选或不选
    for pick in range(1 << d):
        s = 0
        cnt = 0
        for i in range(d):
            if (pick >> i) & 1:
                s |= covers[i]
                cnt += 1
        if s == full and cnt < best:
            best = cnt
    return 0 if best >= inf else best


def main():
    d, w, t = map(int, input().split())
    specs = []
    for _ in range(d):
        specs.append(list(map(int, input().split())))
    need = list(map(int, input().split()))
    print(min_devices(specs, need))


if __name__ == "__main__":
    main()
```

```cpp
            }
        }
        covers.push_back(mask);

    int d = (int)covers.size();
    int full = (1 << t) - 1;
    int inf = t + 5;

    int lim = 1 << d;
    for (int pick = 0; pick < lim; pick++) {
        int s = 0;
        int cnt = 0;
        for (int i = 0; i < d; i++) {
            if ((pick >> i) & 1) {
                s |= covers[i];
                cnt++;
            }
        }
        if (s == full && cnt < best) {
            best = cnt;
        }

    return best >= inf ? 0 : best;
```

# 正确解法

## 题目分析

$d$ 到 $30$ 时不能再枚举机器子集，但业务条目只有 $t\le 20$ 条，可以对「已经覆盖了哪些业务条目」做状压。

1. 同样先把业务点名映射到比特 $0..t-1$，每台机器得到覆盖掩码 $c$。
2. 设 $dp[s]$ 为覆盖集合恰好等于 $s$ 时的最少台数。$dp[0]=0$，其余为正无穷。
3. 按机器做 $0$-$1$ 转移：倒序枚举旧集合 $s$，用 $dp[s]+1$ 更新 $dp[s\mid c]$，每台最多用一次。
4. 全集 $full=(1<<t)-1$。$dp[full]$ 仍是无穷则输出 $0$，否则就是最少台数。

## 复杂度分析

- 时间复杂度：$O(d\cdot 2^{t})$。每台机器扫一遍 $2^{t}$ 个集合。
- 空间复杂度：$O(2^{t})$。

$t\le 20$、$d\le 30$，约 $3\times 10^{7}$ 次运算，可以通过。

## 代码实现

### Python

```python
def min_devices(specs, need):
    # 只把业务点名的条目映射到比特 0..t-1
    bit = {}
    for i, x in enumerate(need):
        bit[x] = i
    t = len(need)
    covers = []
    for row in specs:
        mask = 0
        for x in row:
            if x in bit:
                mask |= 1 << bit[x]
        covers.append(mask)
    full = (1 << t) - 1
    inf = t + 5
    # dp[s]：覆盖集合恰好为 s 时的最少台数
    dp = [inf] * (1 << t)
    dp[0] = 0
    for c in covers:
        if c == 0:
            continue
        # 倒序枚举，保证每台最多用一次
        for s in range((1 << t) - 1, -1, -1):
            if dp[s] >= inf:
                continue
            ns = s | c
            v = dp[s] + 1
            if v < dp[ns]:
                dp[ns] = v
    ans = dp[full]
    return 0 if ans >= inf else ans


def main():
    d, w, t = map(int, input().split())
    specs = []
    for _ in range(d):
        specs.append(list(map(int, input().split())))
    need = list(map(int, input().split()))
    print(min_devices(specs, need))


if __name__ == "__main__":
    main()
```

```java
import java.util.HashMap;
import java.util.Map;
import java.util.Scanner;

public class Main {
    // 状压最短覆盖
    static int minDevices(int[][] specs, int[] need) {
        Map<Integer, Integer> bit = new HashMap<>();
        int t = need.length;
        // 只把业务点名的条目映射到比特 0..t-1
        for (int i = 0; i < t; i++) {
            bit.put(need[i], i);
        }
        int[] covers = new int[specs.length];
        for (int i = 0; i < specs.length; i++) {
            int mask = 0;
            for (int x : specs[i]) {
                Integer b = bit.get(x);
                if (b != null) {
                    mask |= 1 << b;
                }
            }
            covers[i] = mask;
        }
        int full = (1 << t) - 1;
        int inf = t + 5;
        // dp[s]：覆盖集合恰好为 s 时的最少台数
        int[] dp = new int[1 << t];
        for (int i = 0; i <= full; i++) {
            dp[i] = inf;
        }
        dp[0] = 0;
        for (int c : covers) {
            if (c == 0) {
                continue;
            }
            // 倒序枚举，保证每台最多用一次
            for (int s = full; s >= 0; s--) {
                if (dp[s] >= inf) {
                    continue;
                }
                int ns = s | c;
                int v = dp[s] + 1;
                if (v < dp[ns]) {
                    dp[ns] = v;
                }
            }
        }
        return dp[full] >= inf ? 0 : dp[full];
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int d = sc.nextInt();
        int w = sc.nextInt();
        int t = sc.nextInt();
        int[][] specs = new int[d][w];
        for (int i = 0; i < d; i++) {
            for (int j = 0; j < w; j++) {
                specs[i][j] = sc.nextInt();
            }
        }
        int[] need = new int[t];
        for (int i = 0; i < t; i++) {
            need[i] = sc.nextInt();
        }
        sc.close();
        System.out.println(minDevices(specs, need));
    }
}
```
