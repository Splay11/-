# 二分类交叉熵

## 解题思路

本题计算二分类交叉熵损失，接口为 `Solution.binaryCrossEntropy(y, p)`。

1. 公式 $\mathrm{BCE}=-\frac{1}{N}\sum_i\big(y_i\ln p_i+(1-y_i)\ln(1-p_i)\big)$。
2. 为避免 $\ln 0$，将 $p$ 裁剪到 $[\varepsilon,1-\varepsilon]$，其中 $\varepsilon=10^{-7}$。
3. 对所有样本累加后取平均并取负。

## 复杂度分析

时间复杂度为 $O(N)$。

空间复杂度为 $O(1)$。

## 代码实现

### Python

```python
import math


class Solution:
    def binaryCrossEntropy(self, y, p):
        """二分类 BCE，概率裁剪到 [eps, 1-eps]。"""
        eps = 1e-7
        n = len(y)
        s = 0.0
        for yi, pi in zip(y, p):
            # 裁剪避免 log(0)
            pi = min(max(pi, eps), 1.0 - eps)
            s += yi * math.log(pi) + (1.0 - yi) * math.log(1.0 - pi)
        return -s / n
```
