# P7147 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：第一行 $n$，第二行 $n$ 个非零整数。
输出：第一行剩余数量 $m$；$m>0$ 时第二行剩余序列；$m=0$ 时只有一行 $0$。

约束：$2\le n\le 10^4$，$-1000\le asteroids_i\le 1000$ 且不为 $0$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1 | $5$ 与 $10$ 同向保留 | 把 $10$ 也炸掉 |
| 2 | 样例 2，大小相等 | 全部爆炸，只输出 $0$ | 输出空行或 $8$ $-8$ |
| 3 | 样例 3，连锁碰撞 | 只剩 $10$ | 只撞一次得到 $10$ $-5$ |
| 4 | 样例 4，先清左边再处理右边 | $-6$ $2$ $4$ | 让 $-6$ 去撞右边的 $2$ |
| 5 | 背向飞走 | 两颗都留 | 误判为相向碰撞 |
| 6 | 全部向右 | 原序列 | 同向也互相抵消 |
| 7 | 全部向左 | 原序列 | 同向也互相抵消 |
| 8 | 小随机正负交错 | 栈模拟与相邻消除对拍 | 只比较符号不比绝对值 |
| 9 | 压满 $10^4$ 随机 | 线性栈 | $O(n^2)$ 每次从头扫描可能 TLE |
| 10 | 压满 $10^4$，右侧大质量向左清场 | 连锁弹栈 | 不循环碰撞导致大量右行残留 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：栈模拟必须等于反复消除相邻相向对。
