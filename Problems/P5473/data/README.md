# P5473 测例说明

输入三行：$m$，然后 $p\ q$，然后 $m$ 个 $w_i$。输出最少次数。`.in` 末尾无换行，`.out` 末尾恰好一个换行。

分层（每组 10 分）：

- 1：四级样例 1。三条主题，答案 $3$。
- 2：四级样例 2。单主题，答案 $3$。
- 3：全部积压相同。
- 4：$p=q+1$，差额极小。
- 5：一条积压特别大，其余很小。
- 6：答案贴近只靠顺带消费的上界。
- 7：随机小数据。
- 8：$m=200$，中等。
- 9：$m=10^5$ 随机压测。
- 10：$m=10^5$ 且 $w_i$ 接近上限，卡 `int` 溢出。

hack 点：每轮点当前积压最大、`int` 乘爆、二分下界忘记上取整。
