# 主题积压清零

# 题目内容

接入层挂着 $m$ 条消息主题。第 $i$ 条主题当前积压 $w_i$ 条待处理记录，必须把每条主题的积压都清到 $0$ 及以下，下游才允许继续接单。

调度器每一轮只能指定一条主题做主消费，这一轮的效果是：

1. 被指定的那条主题清掉 $p$ 条积压。
2. 其余主题各清掉 $q$ 条积压。保证 $p>q$。

请计算最少需要多少轮，才能让全部主题的积压都不高于 $0$。

# 输入描述

第一行一个整数 $m$，表示主题条数。$(1 \le m \le 100000)$

第二行两个整数 $p$ 和 $q$，依次为主消费量与顺带消费量。$(1 \le q < p \le 1000000000)$

第三行 $m$ 个整数 $w_i$，即各主题的初始积压。$(1 \le w_i \le 1000000000)$

# 输出描述

输出一个整数，表示最少轮次。

## 样例1

**输入**

```
3
10 3
15 8 4
```

**输出**

```
3
```

**说明**

- 一共 $3$ 轮：积压 $15$ 的主题做主消费 $2$ 轮，积压 $8$ 的做主消费 $1$ 轮。
- 每条主题先吃到 $3\times 3$ 的顺带消费，再按主消费多出来的 $7$ 乘上被点中的轮数。
- 三条分别清掉 $9+14$、$9+7$、$9$，都不小于各自积压，且主消费轮数之和恰好为 $3$。少于 $3$ 轮不够。

## 样例2

**输入**

```
1
5 1
12
```

**输出**

```
3
```

**说明**

只有一条主题时每轮都点它，需要 $\lceil 12/5\rceil=3$ 轮。
