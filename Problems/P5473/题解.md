# 主题积压清零

一句话总结：二分消费轮次，每轮先给所有主题扣掉顺带量 $q$，剩下的积压用主消费多出来的 $p-q$ 补，被点中轮数之和不能超过二分值。

算法标签：二分答案、贪心

算法难度：$5 / 10$

## 解题思路

每一轮相当于：所有主题积压减 $q$，被指定主消费的那条再多减 $p-q$。设一共做 $x$ 轮，第 $i$ 条主题做主消费 $t_i$ 轮，则 $t_1+\cdots+t_m=x$，且

$w_i - q\cdot x - (p-q)\cdot t_i \le 0$

1. $x$ 越大越容易清完，具有单调性，可以二分 $x$。
2. 下界：就算每轮都点积压最大的那条，也要 $\max\lceil w_i/p\rceil$ 轮。上界：完全不做主消费、只靠顺带消费，$\max\lceil w_i/q\rceil$ 轮一定够。
3. 判定：顺带消费已经贡献 $q\cdot x$。若 $w_i\le q\cdot x$，这条不必再做主消费；否则还要做主消费 $\lceil(w_i-q x)/(p-q)\rceil$ 轮。所有 $t_i$ 之和不超过 $x$ 即可。
4. $p,q,w_i,x$ 到 $10^9$，乘积必须用 $64$ 位。常见假解：每轮贪心点当前积压最大（局部最优不一定最少）、`int` 溢出、下界只取 $\max w_i/p$ 却忘了上取整。

## 复杂度分析

- 时间复杂度：$O(m\log X)$，$X\le 10^9$，每次判定扫一遍主题。
- 空间复杂度：$O(m)$。

$m\le 100000$，约 $3\times 10^6$ 次运算。评测时限 $3$ 秒、内存 $512$ MB。

## 代码实现

### Python

```python
def enough(times, heat, center, ambient):
    # times 轮是否够把所有积压清到不超过 0
    extra = center - ambient
    need = 0
    cooled = ambient * times
    for w in heat:
        rest = w - cooled
        if rest > 0:
            # 向上取整：还要做主消费多少轮
            need += (rest + extra - 1) // extra
            if need > times:
                return False
    return True


def min_starts(heat, center, ambient):
    lo = 0
    hi = 0
    for w in heat:
        need_center = (w + center - 1) // center
        if need_center > lo:
            lo = need_center
        need_amb = (w + ambient - 1) // ambient
        if need_amb > hi:
            hi = need_amb
    while lo < hi:
        mid = (lo + hi) // 2
        if enough(mid, heat, center, ambient):
            hi = mid
        else:
            lo = mid + 1
    return lo


def main():
    m = int(input())
    p, q = map(int, input().split())
    w = list(map(int, input().split()))
    print(min_starts(w, p, q))


if __name__ == "__main__":
    main()
```

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int m = in.nextInt();
        long p = in.nextLong();
        long q = in.nextLong();
        long[] w = new long[m];
        for (int i = 0; i < m; i++) {
            w[i] = in.nextLong();
        }
        in.close();
        System.out.println(minStarts(w, p, q));
    }

    static boolean enough(long times, long[] heat, long center, long ambient) {
        long extra = center - ambient;
        long need = 0;
        long cooled = ambient * times;
        for (int i = 0; i < heat.length; i++) {
            long rest = heat[i] - cooled;
            if (rest > 0) {
                need += (rest + extra - 1) / extra;
                if (need > times) {
                    return false;
                }
            }
        }
        return true;
    }

    static long minStarts(long[] heat, long center, long ambient) {
        long lo = 0;
        long hi = 0;
        for (int i = 0; i < heat.length; i++) {
            long w = heat[i];

                lo = needCenter;

                hi = needAmb;

            if (enough(mid, heat, center, ambient)) {
                hi = mid;

            }
        }
        return lo;
    }
}

#include <iostream>

bool enough(long long times, const vector<long long>& heat, long long center, long long ambient) {
    long long extra = center - ambient;
    long long need = 0;
    long long cooled = ambient * times;
    for (int i = 0; i < (int)heat.size(); i++) {
        long long rest = heat[i] - cooled;
        if (rest > 0) {
            need += (rest + extra - 1) / extra;
            if (need > times) {
                return false;
            }
        }
    }
    return true;
}

    for (int i = 0; i < (int)heat.size(); i++) {

        if (need_center > lo) {
