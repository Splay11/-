# 题目内容

多多正在为一场长距离赛跑进行训练。训练场由从左到右排列的 $n$ 段连续跑道组成，第 $i$ 段跑道的初始平整度为 $a_i$。平整度越高，运动员经过该路段时越不容易受到影响（$1 \le n \le 10^9$，$0 \le a_i \le 10^9$）。

为了改善训练条件，多多最多可以进行 $m$ 次修整操作。($0 \le m \le 10^9$)
每次修整操作可以选择一段连续的跑道区间 $[l, r]$。选择的区间需要满足：
$1 \le l \le r \le n$
$r - l + 1 \le k$
也就是说，一次操作最多能够修整连续的 $k$ 段跑道。($1 \le k \le 10^9$)

完成一次修整后，区间 $([l, r])$ 内每一段跑道的平整度都会增加 $1$。即对于所有满足 $l \le i \le r$ 的位置 $i$，执行：
$(a[i]) = (a[i]) + 1$

多多希望在修整完成后，整条跑道中平整度最低的路段也尽可能平整。
请你计算，在最多进行 $m$ 次修整操作后，所有路段平整度最小值的最大可能值。




# 输入描述


第一行输入三个整数 $((n,m),k)$，分别表示跑道段数、最多修整次数和单次操作最多覆盖的连续路段数量。

第二行输入 $n$ 个整数： $a_1,a_2,…,a_n$，其中， $a_i$ 表示第 $i$ 段跑道的初始平整度。



# 输出描述

输出一个整数，表示经过最多 $m$ 次修整操作后，所有跑道路段平整度的最小值所能达到的最大值。



## 样例1 



**输入** 



```
5 4 3
1 2 1 2 1
```



**输出** 



```
3
```
