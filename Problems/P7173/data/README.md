# P7173 测试数据说明

主造数脚本：题目根目录 `gen.py`。两个答案顺序任意；`checker.cc` 按输入统计两个落单数，选手输出顺序不限。
约束：$2\le n\le 3\times 10^4$，恰好两个数出现一次，其余出现两次。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1 | 3 5 | 输出 1 2 |
| 2 | 样例 2 两个落单 | -1 0 | 漏负数 |
| 3 | 样例 3 | 0 1 | 顺序必须 1 0 才会和样例展示不同，SPJ 都收 |
| 4 | 一对加两个落单 | -3 9 | 哈希表以外空间 |
| 5 | 下界和上界 | INT_MIN INT_MAX | 异或最低位取错 |
| 6 | 0 出现两次 | 1 2 | 把 0 当落单 |
| 7 | 含 INT_MIN 的中等数组 | 1000 和 INT_MIN | 符号位分组出错 |
| 8 | 多对重复 | 5 8 | 只异或一次拆不开 |
| 9 | 压满约 3e4 | O(n) 位运算 | 排序后数次数 TLE/空间 |
| 10 | 压满偶数长度 | O(1) 额外空间 | 哈希表 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。
