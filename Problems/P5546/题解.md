# Batch Normalization

## 解题思路

训练模式下的 BatchNorm 前向：

1. 对每个特征维 $j$，算 batch 均值 $\mu_j$ 与总体方差 $\sigma_j^2$（除以 $N$）。
2. 标准化 $\hat x_{i,j}=(x_{i,j}-\mu_j)/\sqrt{\sigma_j^2+\varepsilon}$。
3. 仿射变换 $y_{i,j}=\gamma_j\hat x_{i,j}+\beta_j$。
4. 依次输出 $\mu$、$\sigma^2$ 与 $Y$，均保留 $2$ 位小数。

## 复杂度分析

- 时间复杂度：$O(N \cdot d)$
- 空间复杂度：$O(N \cdot d)$

## 代码实现

### Python

```python
import numpy as np


class Solution:
    def batch_norm(self, X, gamma, beta, eps):
        # 训练模式：用当前 batch 的均值/方差（总体方差 1/N）
        X = np.asarray(X, dtype=np.float64)
        gamma = np.asarray(gamma, dtype=np.float64)
        beta = np.asarray(beta, dtype=np.float64)
        mu = X.mean(axis=0)
        var = X.var(axis=0)  # ddof=0，即 1/N
        xhat = (X - mu) / np.sqrt(var + eps)
        Y = gamma * xhat + beta
        return mu, var, Y
```
