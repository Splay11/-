# KL 散度

## 解题思路

1. 对每组离散分布按定义计算 $D_{KL}(P\parallel Q)=\sum_j P_j\log\dfrac{P_j}{Q_j}$（自然对数）。
2. 对 $m$ 组结果取平均得到最终答案。
3. 在 `Solution.averageKLDivergence` 中双重循环实现上述求和与平均。

## 复杂度分析

- 时间复杂度：$O(mn)$，遍历全部概率分量。
- 空间复杂度：$O(1)$，除输入外只用常数额外空间。

## 代码实现

### Python

```python
from typing import List
import math


class Solution:
    def averageKLDivergence(self, P: List[List[float]], Q: List[List[float]]) -> float:
        """计算 m 组 KL(P||Q) 的平均值。"""
        m = len(P)
        total = 0.0
        for i in range(m):
            # 对每个类别累加 P_j * ln(P_j / Q_j)
            kl = 0.0
            for pj, qj in zip(P[i], Q[i]):
                kl += pj * math.log(pj / qj)
            total += kl
        return total / m
```
