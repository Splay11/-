# 题目内容

给定一个长度为 $n$ 的整数数组 $a$。定义
$$
(f(k))=\sum_{i=0}^{n-1}\big((i \bmod k)\cdot a_i\big).
$$
请你依次输出 $k=1,2,\dots,n$ 时的 $(f(k))$ 值。由于答案可能很大，请将答案对 $(10^9+7)$ 取模后输出。




# 输入描述

每个测试文件包含多组测试数据。第一行输入一个整数 $T(1 \le T \le 10^5)$ 表示数据组数，每组测试数据描述如下：

第一行输入一个整数 $n\ (1 \le n \le 2 \times 10^5)$；

第二行输入 $n$ 个整数 $a_0,a_1,\dots,a_{n-1}\ (0 \le a_i \le 10^9)$。

保证所有测试中 $n$ 的总和不超过 $5 \times 10^5$。



# 输出描述


对于每组测试数据，输出一行包含 $n$ 个整数，第 $k$ 个数为 $(f(k))\%(10^9+7)$（对应 $k=1,2,\dots,n$）。



## 样例1 



**输入** 



```
2
5
1 2 3 4 5
6
1 1 4 5 1 4
```



**输出** 



```
0 6 13 20 40
0 10 18 28 28 48
```



**说明**

对于 $a = \{1,2,3,4,5\}$：
$f(1)=\sum(i \bmod 1)\cdot a_i = 0$；
$f(2) = (0\cdot1)+(1\cdot2)+(0\cdot3)+(1\cdot4)+(0\cdot5)=6$；
$f(3) = (0\cdot1)+(1\cdot2)+(2\cdot3)+(0\cdot4)+(1\cdot5)=13$；
$f(4) = (0\cdot1)+(1\cdot2)+(2\cdot3)+(3\cdot4)+(0\cdot5)=20$；
$f(5) = (0\cdot1)+(1\cdot2)+(2\cdot3)+(3\cdot4)+(4\cdot5)=40$；
