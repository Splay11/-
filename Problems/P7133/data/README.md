# P7133 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：第一行 `n qid`；随后 $n$ 行 `id importance m [subs...]`，$m=0$ 时没有下属。
输出：查询员工及其所有下属的重要度之和。

约束：$1\le n\le 2000$，$1\le id_i\le 2000$ 互异，$-100\le importance_i\le 100$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1 | 根 $1$ 加两名下属得 $11$ | 只加直属忘了加自己，得到 $6$ |
| 2 | 样例 2，查询叶子且重要度为负 | 答案 $-3$ | 把上级 $1$ 也加进来得到 $-1$ |
| 3 | 只有一人 | 答案就是自己的 $10$ | 去读不存在的下属 |
| 4 | 查询链底叶子 | 只有 $4$ | 把整条链 $1+2+4$ 都加上 |
| 5 | 查询链中间节点 | $6+7=13$ | 漏掉间接下属 $3$，只输出 $6$ |
| 6 | 两棵树的森林，查询其中一棵 | $8+2=10$，不含另一棵 | 把所有员工重要度加总 |
| 7 | 星形，根和叶子都是负数 | 根加 $5$ 个叶子 | 重要度当无符号数 |
| 8 | 短链查询根 | $1+\cdots+8=36$ | 只走一层 |
| 9 | 压满链 $n=2000$，查询根 | 正负交替求和 | 递归 DFS 在链上爆栈 |
| 10 | 压满 $n=2000$ 随机树，查询随机节点 | 只累加该节点子树 | I/O 按行读错，或 ID 不从 $1$ 连续时数组越界 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：栈 DFS 必须等于队列 BFS 的子树重要度之和。
