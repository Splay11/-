## 题目内容

作为出题官，您需要设计算法题目。系统提供了 N 个知识点模块，每个模块有一个唯一编号（从 1 到 N）和一个难度系数。

您需要将这些模块组织成一个题目，规则如下：

1. 模块选择：从 N 个模块中选择 K 个模块组成一道题目
2. 顺序排列：选中的 K 个模块按编号递增顺序排列
3. 冲突检测：相邻的两个模块不能存在"知识冲突"。如果两个模块的编号之差的绝对值小于等于 D，则认为它们存在冲突
4. 难度约束：选中的 K 个模块的难度系数总和必须在 $[minDifficulty, maxDifficulty]$ 范围内

请找出所有满足上述条件的题目设计方案。

## 输入描述

- 第一行：五个整数 $N, K, D, minDifficulty, maxDifficulty$
  - N：模块总数（$1 \le N \le 20$）
  - K：需要选择的模块数量（$1 \le K \le N$）
  - D：冲突阈值（$0 \le D \le N$）
  - minDifficulty：最小难度总和（$1 \le minDifficulty \le 1000$）
  - maxDifficulty：最大难度总和（$minDifficulty \le maxDifficulty \le 1000$）
- 第二行：N 个整数，表示每个模块的难度系数（$1 \le 难度系数 \le 100$）

## 输出描述

- 第一行：输出所有满足条件的方案数量
- 如果方案数量大于 0，按字典序输出最多前 3 个方案（每个方案一行，模块编号用空格分隔）

## 样例1

**输入** 

```
5 3 1 10 20
3 5 2 4 6
```

**输出** 

```
1
1 3 5
```

**说明**

- 模块编号：1, 2, 3, 4, 5
- 难度系数：3, 5, 2, 4, 6
- 需要选择 3 个模块，相邻模块编号差必须 > 1，难度总和在 $[10, 20]$ 范围内
- 所有可能的 3 模块组合共 10 个，但大多数存在冲突：
  - (1, 2, 3)：冲突，2-1=1≤1
  - (1, 3, 4)：冲突，4-3=1≤1
  - (1, 3, 5)：有效，3-1=2>1，5-3=2>1，难度和=3+2+6=11 ✓
  - (1, 4, 5)：冲突，5-4=1≤1
  - 其他组合类似，都存在相邻编号差≤1的情况
- 最终只有 1 个有效方案：(1, 3, 5)
