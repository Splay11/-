# P7142 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：一行 Unix 绝对路径 $path$。
输出：化简后的规范路径。

约束：$1\le |path|\le 3000$，仅含字母、数字、点、斜杠和下划线。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1 | 去掉末尾斜杠得到 $/home$ | 末尾仍留 $/home/$ |
| 2 | 样例 2 | 合并连续斜杠得到 $/home/foo$ | 中间留下空目录名 |
| 3 | 样例 3，$..$ 回到上一级 | $/home/user/Pictures$ | 没有弹出 $Documents$ |
| 4 | 样例 4，根目录再往上 | 仍是 $/$ | 弹出后变成空串 |
| 5 | 样例 5，$...$ 是普通目录名 | $/.../b/d$ | 把 $...$ 当成 $..$ 得到 $/b/d$ |
| 6 | 已经是根目录 | 答案 $/$ | 输出空串 |
| 7 | 经典组合：当前目录和两级返回 | $/c$ | 少弹一次得到 $/a/c$ |
| 8 | 小随机目录名、$.$、$..$ 与多余斜杠 | 栈模拟与 split 过滤对拍 | 把下划线目录名拆坏 |
| 9 | 压满约 $3000$，大量斜杠与点 | 线性扫一遍 | $O(n^2)$ 反复拼接字符串可能 TLE |
| 10 | 压满重复模式 $a/./../b$ | 最终只剩规范路径 | 栈弹出写错导致越界 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：手写扫描必须等于 $split('/')$ 后用栈过滤。
