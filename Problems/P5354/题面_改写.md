**4、语音转写大模型改成 MoE。路由机制的工作方式是？**
{{ select(4) }}

- 只训练一个专家，其余专家权重从该专家复制且不再更新

**5、工单摘要模型会写出原始工单里没有的原因。大模型产生“幻觉”的根本原因是？**

- 只要检索库无误，模型就绝不会写出未出现的事实
- 幻觉只发生在微调阶段，推理阶段已经消除
- 把解码改成逐词对照知识库后，训练目标就变成了事实验证

**6、零件货号串 `t` 由字母/数字组成，要删掉 `m` 个字符且保持相对顺序，使剩下的串字典序最小。应使用的贪心策略是？**

- 从前往后，删除第一个比后面字符大的字符

**15、调度服务用多线程读写同一份任务队列。下列关于进程管理说法错误的是？**
{{ select(15) }}
- 采用锁来访问线程共享资源时，如果加锁和解锁操作处在同一个线程中，则不会导致死锁
- 进程是资源分配的基本单位，线程是 CPU 调度的基本单位
- 同一进程内的多个线程共享地址空间，但各自有独立的栈
- 创建进程的开销通常大于创建线程

**16、制度问答要做流式续写。关于 LLM 推理优化中的 KV Cache，以下哪种理解是正确的？**
{{ select(16) }}
- KV Cache 会改写词表，使后续 token 不再对应原文字
- KV Cache 只缓存最终答案字符串，中间层不算
- KV Cache 必须在训练阶段写入检查点，否则推理无法启用
- KV Cache缓存已计算层Key/Value张量，避免自回归生成重复计算

**17、场馆雇员表名为 `STAFF`，部门列 `dept`，薪资列 `salary`。三行示例如下。要查找雇员数超过 2 个的部门的最高和最低薪水，下面 SQL 语句正确的是？**

|  |姓名|部门|薪资| |入职时间|
| ---- | ---- | ---- | ---- | ---- | ---- |
|6|周北|夜班组|3000|5|2010-10-05|
|7|吴西|夜班组|3100|7|2010-10-07|
|8|郑南|夜班组|3500|7|2010-10-06|

{{ select(17) }}
- SELECT dept, MAX(salary) FROM STAFF WHERE COUNT(*) > 2
- SELECT * FROM STAFF GROUP BY salary HAVING dept > 2
- SELECT dept ,MAX(salary) AS MAXIMUM ,MIN(salary) AS MINIMUM
FROM STAFF
GROUP BY dept
HAVING COUNT(*) > 2 ORDER BY dept
- SELECT MAX(dept), MIN(salary) FROM STAFF ORDER BY COUNT(*)

**18、库存助手要调查询接口。AI Agent 的工具调用环节中，最容易被忽视的工程风险是？**
{{ select(18) }}

**19、巡检日报按 token 逐个生成。关于 LLM 推理优化中的 KV Cache，以下哪种理解是正确的？**
{{ select(19) }}

- KV Cache 缓存的是优化器动量，用来加速反向传播
