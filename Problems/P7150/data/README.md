# P7150 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：一行小写字符串 $s$。
输出：反复删除相邻相同字符后的结果，可能为空。

约束：$1\le |s|\le 10^5$，仅小写字母。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1，连锁删除 | $ca$ | 只删一轮得到 $aaca$ |
| 2 | 样例 2 | $ay$ | 删 $xx$ 后不再删 $zz$ |
| 3 | 单个字符 | $a$ | 空串 |
| 4 | 一对相同 | 删空，输出空行 | 输出 $aa$ |
| 5 | 奇数个相同 | 只剩 $a$，不能整段删光 | 输出空串 |
| 6 | 互不相同 | 原串 | 误删 |
| 7 | 从内向外消成空 | 空串 | 只消 $bb$ 得到 $aa$ 就停 |
| 8 | 小随机 $a$–$c$ | 栈与下标栈对拍 | 只看相邻不连锁 |
| 9 | 压满 $10^5$ 随机小写 | 线性栈 | 每次 $erase$ 中间字符 $O(n^2)$ TLE |
| 10 | 压满 $10^5$，大量成对 $aa$ | 反复弹栈 | 奇数段处理错误 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：list 栈必须等于下标栈。
