# 题目内容


新学期开课在即，教研组需要赶制一批配套课件。教研组已经确定了 $n$ 个待制作的课件，编号从 $0$ 到 $n-1$。由于课件之间存在知识点上的递进关系，必须**严格按照编号顺序**制作；同时每个课件都要求当天交付，**不能拆到两天完成**。

整批课件需要在 $m$ 天内全部完成，这项工作主要由张老师承担，制作编号为 $i$ 的课件，他需要花费 time[$i$] **分钟**。

学校规定每位老师每天用于备课的时间有限，因此教研组希望排期尽量均衡——把**最忙的那一天**压到最短，避免出现某天严重超时、其余几天却很空闲的情况。

好在教研组还有资深的李老师可以支援。张老师每天最多可以向李老师求助 $k$ 次，把当天的至多 $k$ 个课件完全交给李老师制作，这些课件**不占用张老师的任何时间**。同时要求张老师和李老师**每天最多工作 $480$ 分钟**。

我们把这 $m$ 天中，张老师**单日制作耗时最长**的那一天的耗时记为 $T$（由李老师完成的课件不计入张老师的耗时，单位为分钟）。

请你帮教研组安排排期，求出 $T$ 的最小值。


# 输入描述


第一行包含三个整数$n$ $m$ $k$，分别表示课件总数、可用天数、张老师每天最多可以求助的次数。

第二行包含 $n$ 个整数 $time[0]$, $time[1]$,$ …$, $time[n-1]$，表示张老师制作各个课件所需的分钟数。



# 输出描述

输出一个整数，表示 $T$ 的最小值（单位：分钟）；如果没有合理排期，输出 $-1$。

## 补充说明
数据范围：
- $1 \le n \le 20000$
- $1 \le$ $time[i]$ $\le 480$
- $1 \le m \le 1000$
- $0 \le k \le 10$

## 样例1 



**输入** 



```
4 2 1
60 120 180 180
```



**输出** 



```
180
```



**说明**

每天最多求助 $1$ 次。第一天制作编号 $0$, $1$ 两个课件（$60$, $120$），把 $120$ 分钟的交给李老师，张老师当天耗时 $60$ 分钟；第二天制作编号 $2$, $3$ 两个课件（$180$, $180$），把其中一个交给李老师，张老师当天耗时 $180$ 分钟。

两天中最忙的一天耗时 $180$ 分钟，无法更小。


## 样例2



**输入** 



```
6 2 2
300 60 480 240 180 420
```



**输出** 



```
420
```



**说明**
每天最多求助 $2$ 次，但李老师自己每天也只有 $480$ 分钟。

第一天制作编号 $0$, $1$, $2$ 三个课件（$300$, $60$, $480$）。李老师最多能接 $480$ 分钟的活，所以只能接走 $480$ 分钟那一个（再接 $300$ 分钟的就变成 $780$ 分钟，超出李老师的上限），张老师当天耗时 $300 + 60 = 360$ 分钟。

第二天制作编号 $3$, $4$, $5$ 三个课件（$240$, $180$, $420$）。李老师同理只能接走 $420$ 分钟那一个，张老师当天耗时 $240 + 180 = 420$ 分钟。

两天中最忙的一天耗时 $420$ 分钟。


## 样例3



**输入** 



```
3 4 1
480 480 480
```



**输出** 



```
0
```



**说明**

可用天数比课件数还多。张老师每天只制作一个课件，并且每天都向李老师求助（每天李老师只做 $480$ 分钟，正好不超上限），三天内全部完成，张老师自己一分钟都没花，因此 $T = 0$。


## 样例4



**输入** 



```
3 1 0
480 1 1
```



**输出** 



```
-1
```



**说明**

只有 $1$ 天，且 $(k=0)$ 意味着张老师无法求助。三个课件共需 $480 + 1 + 1 = 482$ 分钟，超过张老师每天 $480$ 分钟的上限，无论怎么安排都完不成，输出 $-1$。
