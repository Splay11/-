# P5273 测例说明

单组输入，与改写题面一致。每天工时上限常数为 `480`。

| 组 | 规模 | 目标 | 卡掉的错误解 |
|---:|---|---|---|
| 1 | 改写样例1 | 交接后最忙日为 40 | 少算第二天也可交接 |
| 2 | 改写样例2 | T=0 | 认为 T 至少为 min(g_i) |
| 3 | 改写样例3 | 支援应拿 250+200 | 只拿最大的 k 个导致 450 或 -1 |
| 4 | 改写样例4 | 无解 | 忽略 480 上限 |
| 5 | 单卷 | 答案即该卷 | 空段 / 下标错误 |
| 6 | k=0 均分数组 | 分割最大和 | 不连续选取 |
| 7 | k=0 两天 | 每段 400 | 误把四卷塞进一天 |
| 8 | 小随机 | 混合有解 | 二分边界 |
| 9 | n=2e4, k=0, 全 1 | T=20 | 复杂度、忽略天数 |
| 10 | n=2e4, k=10, 值偏小 | 压测位集 | 递归/朴素背包超时 |
