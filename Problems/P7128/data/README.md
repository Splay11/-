# P7128 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin：第一行 `n k`；$n>0$ 时第二行 $n$ 个整数；$n=0$ 时没有第二行。
输出：右旋后的节点值；空链表为单独空行。

约束：$0 \le n \le 500$，$-100 \le a_i \le 100$，$0 \le k \le 2\times 10^9$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1 | 右旋 $2$ 得到 $4\ 5\ 1\ 2\ 3$ | 做成左旋会得到 $3\ 4\ 5\ 1\ 2$ |
| 2 | 样例 2，$k>n$ | $4\bmod 3=1$，得到 $2\ 0\ 1$ | 不对 $n$ 取模，或取模用错 |
| 3 | 空链表 $n=0$，无第二行 | 输出空行 | 去读第二行导致 RE；或输出 $0$ |
| 4 | 单节点，任意 $k$ | 仍是 $7$ | 取模除零 |
| 5 | $k=0$ 不旋转 | 原序列 | 仍然移动节点 |
| 6 | $k$ 是 $n$ 的倍数 | 回到原序列 $1\ 2\ 3$ | 没取模转了 $6$ 次但断链 |
| 7 | 右旋 $1$，含负数 | $-3\ -5\ -4$ | 符号弄丢 |
| 8 | 小随机 $n=11$ | 切片拼接与链表旋转对拍 | 新尾 $next$ 没置空导致多输出 |
| 9 | 压满 $n=500$，$k=2\times 10^9$ | $k\bmod n=0$，输出原序列 | 真的循环 $k$ 次会 TLE |
| 10 | 压满 $n=500$，$k=2\times 10^9-1$，余数非 $0$ | 先取模再旋 | int 溢出存 $k$，或左旋 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。

生成后自校验：链表旋转结果必须等于 $vals[-k:]+vals[:-k]$（先 $k\bmod n$）。
