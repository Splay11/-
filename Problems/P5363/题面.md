# 题目内容

给定一棵二叉树，求它的最大深度，即从根节点到最远叶子节点的路径上经过的节点个数。

二叉树按层序给出，`#` 表示空节点。例如 `{1,2,3,#,#,4}` 对应的二叉树形态如下：

```
    1
   / \
  2   3
     /
    4
```

这棵树的最大深度为 $3$，对应路径 $1 \rightarrow 3 \rightarrow 4$。空树的最大深度为$ 0$。

# 输入描述

一行一个字符串 $s$，表示二叉树的层序序列。序列被一对花括号包裹，元素之间用逗号分隔，`#` 表示空节点，序列末尾的空节点被省略，空树写作 `{}`。

二叉树的节点个数 $n(0 \le n \le 10^5)$，每个节点的权值 $val(1 \le val \le 10^9)$。

# 输出描述

输出一个整数，表示这棵二叉树的最大深度。



## 样例1 

**输入** 

```
{1,2,3,#,#,4}
```

**输出** 

```
3
```

**说明**

根节点 $1$ 的左孩子是 $2$、右孩子是$ 3$，节点$ 2 $的两个孩子都为空，节点$ 3$ 的左孩子是 $4$。最长的一条根到叶子的路径是 $1 \rightarrow 3 \rightarrow 4$，经过 $3 $个节点，故最大深度为 $3$。



## 样例2 

**输入** 

```
{}
```

**输出** 

```
0
```

**说明**

空树没有任何节点，最大深度为 $0$。
