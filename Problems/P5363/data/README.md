# P5363 测试数据说明

共 $10$ 组。一行层序串 `{...}`，`#` 为空，末尾空位省略。输出最大深度（节点个数）。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例1 `{5,#,8,6}` | 右斜深度 $3$ | 漏掉 `#` 后的节点 |
| 2 | 样例2 单点 | 答案 `1` | 输出 `0` |
| 3 | 样例3 `{}` | 答案 `0` | 空树当 `1` |
| 4 | `{7,2,4}` | 满两层 | 把边数当深度 |
| 5 | 换值的原形态 | 深度 $3$ | 解析逗号失败 |
| 6 | 左链 $20$ | 深度等于点数 | 只走右儿子 |
| 7 | 右链 $15$ | 对称 | 只走左儿子 |
| 8 | 随机 $80$ 点 | 对拍 | 层序下标错位 |
| 9 | 完全树 $10^5$ | 压测 $\lfloor\log_2 m\rfloor+1$ | TLE |
| 10 | 左链 $10^5$ | 压测、深度 $10^5$ | 递归爆栈 |

前 $8$ 组小；后 $2$ 组压测。
