# P7164 测试数据说明

主造数脚本：题目根目录 `gen.py`。输出小写 true/false。
约束：$1\le k\le n\le 10^5$，$-10^9\le nums_i\le 10^9$。

| 组别 | 规模/分布 | 目标 | 卡掉的错误解 |
|---|---|---|---|
| 1 | 样例 1 | true | 输出 false |
| 2 | 样例 2，$1$ 出现 3 次 | false | 只看 n%k |
| 3 | 样例 3 | true | 5 出现 6 次没拆两组 |
| 4 | n=k=1 | true | 输出 false |
| 5 | k=1 恒成立 | true | 要求值相同 |
| 6 | n 能被 k 整除但 1 出现 3 次 | false | 只判断 n%k==0 |
| 7 | k=n 且全相同 | true | k=n 时输出 false |
| 8 | k=n 但有两种值 | false | 只看长度 |
| 9 | 压满 n=10^5，每值 2000 次，$k=8$ | true | O(n^2) TLE |
| 10 | 压满几乎全是 1，多一个 2 | false | 忽略落单的 2 |

`.in` 最后一行后无换行符；`.out` 末尾恰好一个换行符。
