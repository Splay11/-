## LeetCode 35. 搜索插入位置

[在线刷题](https://codefun2000.com/p/P4023)

给定一个排序数组和一个目标值，在数组中找到目标值，并输出其索引。如果目标值不存在于数组中，输出它将会被按顺序插入的位置。

请必须使用时间复杂度为 $0(log\ n)$的算法。

**输入1** 

```
4 5
1 3 5 6
```

**输出1** 

```
2
```

**输入2** 

```
4 2
1 3 5 6
```

**输出2** 

```
1
```

**输入3** 

```
4 7
1 3 5 6
```

**输出3** 

```
4
```

- $1 <= nums.length <= 10^4$
- $-10^4 <= nums[i] <= 10^4$
- $nums$为 无重复元素 的 升序 排列数组
- $-10^4 <= target <= 10^4$

**思路**

1.如果目标值$T$存在于数组，则找到目标值的下标。

2.如果目标值$T$不存在于数组，则找到$\geq T$的第一个位置的下标。

**化简一下就是：找到数组中$\geq T$ 的第一个位置**

利用**前置知识2** 中所提到的通用分析方法：

1.将数组划分成:$<T$ 和 $\geq T$ 两个部分

2.二分，让$L$停在`Suf`的第一个位置，直接输出$L$即可。

**代码实现**

```python
class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1

        # 二分查找第一个大于等于 target 的位置
        while left <= right:
            mid = (left + right) // 2

            # nums[mid] 小于 target，说明答案一定在右边
            if nums[mid] < target:
                left = mid + 1

            # nums[mid] 大于等于 target，说明当前位置可能是答案，继续往左找
            else:
                right = mid - 1

        # left 最终停在第一个大于等于 target 的位置
        return left
```

## LeetCode 34. 在排序数组中查找元素的第一个和最后一个位置

[在线刷题](https://codefun2000.com/p/P4076)

给定一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

你必须设计并实现时间复杂度为 $O(\log n)$ 的算法解决此问题。

**输入** 

```
6
5 7 7 8 8 10
8
```

**输出** 

```

```

- $0 \leq n \leq 10^5$
- $-10^9 \leq nums[i] \leq 10^9$
- `nums` 是一个非递减数组
- $-10^9 \leq target \leq 10^9$

**思路**

本题 和 **前置知识2** 中的 **实战:【二分2】二分找下标问题** 没有本质区别，先搞懂那个题即可。

```python
class Solution:
    def find_first_position(self, nums: List[int], target: int) -> int:
        n = len(nums)
        left, right = 0, n - 1

        # 二分查找第一个大于等于 target 的位置
        while left <= right:
            mid = (left + right) // 2

            # nums[mid] 小于 target，说明答案一定在右边
            if nums[mid] < target:
                left = mid + 1

            # nums[mid] 大于等于 target，说明当前位置可能是第一个 target，继续往左找
            else:
                right = mid - 1

        # 如果 left 没有越界且 nums[left] 等于 target，说明找到了第一个位置
        return left if left < n and nums[left] == target else -1

    def find_last_position(self, nums: List[int], target: int) -> int:
        n = len(nums)
        left, right = 0, n - 1

        # 二分查找最后一个小于等于 target 的位置
        while left <= right:
            mid = (left + right) // 2

            # nums[mid] 小于等于 target，说明最后一个 target 可能在当前位置或右边
            if nums[mid] <= target:
                left = mid + 1

            # nums[mid] 大于 target，说明答案一定在左边
            else:
                right = mid - 1

        # 如果 right 没有越界且 nums[right] 等于 target，说明找到了最后一个位置
        return right if right >= 0 and nums[right] == target else -1

    def searchRange(self, nums: List[int], target: int) -> List[int]:
        # 分别找到 target 的第一个位置和最后一个位置
        first = self.find_first_position(nums, target)
        last = self.find_last_position(nums, target)
        return [first, last]
```

### 面试问答

**1. 本题的核心思路是什么？**

本题的核心思路是：利用二分查找，找到目标值第一次和最后一次出现的位置。

对于第一次出现的位置，如果当前位置的值小于目标值，就让左指针右移，否则让右指针左移。过程结束后，左指针指向的是整个数组大于等于目标值的第一个位置。直接检查$a[L]$即可。

对于最后一次出现的位置，如果当前位置的值小于等于目标值，就让左指针右移，否则让右指针左移。过程结束后，右指针指向的是整个数组小于等于目标值的最后一个位置。直接检查$a[R]$即可。

## LeetCode 74. 搜索二维矩阵

[在线刷题](https://codefun2000.com/p/P4024)

给你一个满足下述两条属性的 $m×n$整数矩阵：

- 每行中的整数从左到右按非严格递增顺序排列。
- 每行的第一个整数大于前一行的最后一个整数。

给你一个整数 $target$ ，如果 $target$ 在矩阵中，输出 $true$ ；否则，输出 $false$。

**输入** 

```
3 4
1 3 5 7
10 11 16 20
23 30 34 60
3
```

**输出** 

```
true
```

- $m == matrix.length$
- $n == matrix[i].length$
- $1 <= m, n <= 100$
- $-10^4 <= matrix[i][j], target <= 10^4$

**思路**

由于本矩阵逐行有序，则将其看成一个$1 \times n$ 的一维数组，在这个数组上二分即可。

注意矩阵和一维数组的下标映射关系:$arr[i] \rightarrow (\lfloor \frac{i}{m}\rfloor , i \% m)$ ， 其中$m$是列数。

#code-switcher
```python
def _value_at_flat_index(matrix: List[List[int]], index: int, m: int) -> int:
    # 将一维下标映射回二维矩阵下标
    return matrix[index // m][index % m]


class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        # 获取二维矩阵的行数和列数
        n = len(matrix)
        m = len(matrix[0])

        # 将二维矩阵看成长度为 n * m 的一维有序数组
        left, right = 0, n * m - 1

        # 在一维有序数组上进行二分查找
        while left <= right:
            mid = (left + right) // 2
            value = _value_at_flat_index(matrix, mid, m)

            # 找到目标值
            if value == target:
                return True

            # 当前值小于 target，说明答案在右半部分
            elif value < target:
                left = mid + 1

            # 当前值大于 target，说明答案在左半部分
            else:
                right = mid - 1

        return False
```

本题所给的数组如下所示👇

从上图我们不难发现，整个数组由两个连续递增区间构成。我们不妨给每个元素编号：属于第一个区间的编号为$0$，属于第二个区间的编号为$1$。

例如:$a=[4,5,6,7,0,1,2]$  , 编号数组$b=[0,0,0,0,1,1,1]$

**考虑一个问题：给定下标$i$ , 如何判断$a[i]$ 属于哪个区间？**


由于第一段中任意的数都**大于**第二段的最大值(也就是数组最后一个元素)都大，而第二段中的任意元素都**小于等于**第二段的最大值。

所以如果$a[i] > a[n]$  , 则$i \in 第一个区间$ , 反之$i \in 第二个区间$ 。

即：
$$
b_i =
\begin{cases}
1, & a[i] > a[n] \\
0, & a[i] \le a[n]
\end{cases}
$$

知道每个位置的编号如何计算之后，我们就能二分了👇

1.将数组$b$划分成:$<1$ 和 $\geq 1$ 两个部分

2.二分，让$L$停在`Suf`的第一个位置，直接输出$L$即可。

```python
def _rotated_segment(index: int, nums: List[int]) -> int:
    # 从 nums 数组映射到编号数组
    # 第一段元素都大于最后一个元素，编号为 0
    # 第二段元素都小于等于最后一个元素，编号为 1
    return 0 if nums[index] > nums[-1] else 1


class Solution:
    def findMin(self, nums: List[int]) -> int:
        left, right = 0, len(nums) - 1

        # 本质上是在一个先 0 后 1 的数组中找到第一个 1
        while left <= right:
            mid = (left + right) // 2
            value = _rotated_segment(mid, nums)

            # 当前在第一段，最小值一定在右边
            if value == 0:
                left = mid + 1

            # 当前在第二段，当前位置可能是最小值，继续往左找
            else:
                right = mid - 1

        # left 停在第二段的第一个位置，也就是最小值位置
        return nums[left]
```

```python
def _segment(value: int, nums: List[int]) -> int:
    # 判断 value 属于旋转数组的哪一段
    # 大于最后一个元素，说明在第一段；否则在第二段
    return 0 if value > nums[-1] else 1


class Solution:
    def search(self, nums: List[int], target: int) -> int:
        # 先判断 target 属于哪一段
        target_value = _segment(target, nums)

        left, right = 0, len(nums) - 1

        while left <= right:
            mid = (left + right) // 2

            # 判断 nums[mid] 属于哪一段
            mid_value = _segment(nums[mid], nums)

            # 如果 mid 和 target 在同一段，就按照普通有序数组二分
            if mid_value == target_value:
                if nums[mid] < target:
                    left = mid + 1
                elif nums[mid] > target:
                    right = mid - 1
                else:
                    return mid

            # 如果 mid 和 target 不在同一段，就根据两段的位置关系移动指针
            else:
                # mid 在第一段，target 在第二段，答案在右边
                if mid_value < target_value:
                    left = mid + 1

                # mid 在第二段，target 在第一段，答案在左边
                else:
                    right = mid - 1

        return -1
```

### 面试问答

**1. 本题的核心思路是什么？**

本题的核心思路是：利用二分查找，不断逼近target的真实位置。

具体的，二分时先判断$target$和$nums[mid]$在哪一段，如果同一段，则根据实际值的大小关系来确定左右指针的移动方向。如果不同段，则根据$mid$和$target$的位置关系来确定左右指针的移动方向。

时间复杂度：$O(log\ n)$ ，因为每次二分都将问题规模缩小一半。

空间复杂度：$O(1)$
