
## 哈希表（Hash Table）

哈希表是一种基于哈希函数（Hash Function）的数据结构，用于实现键值对的快速存储和查找。它的主要特点是：

**1.快速查找**：平均情况下，哈希表的查找、插入和删除操作的时间复杂度都是 O(1)。

**2.键值对存储**：哈希表存储的是键值对，每个键（Key）唯一对应一个值（Value）。

**3.哈希函数**：通过哈希函数将键映射到哈希表中的位置，从而实现快速存取。

## python/c++/java 中的哈希表的主要操作

**1.插入或更新元素：**

#code-switcher

   ```python
   my_dict = dict()
   my_dict[1] = 3  # 插入或更新键值对 1:3
   ```

```cpp
unordered_map<int, int> hash_map;
hash_map[1] = 3;  // 插入或更新键为 1 的值为 3
```

```java
import java.util.HashMap;

HashMap<Integer, Integer> hashMap = new HashMap<>();
hashMap.put(1, value);  // 插入或更新键为 1 的值为 3
```

#code-switcher

**2.查找元素（键存在）：**

#code-switcher

   ```python
   x = my_dict[1]  
   ```

```cpp
int x = hash_map[1];
```

```java
int x = hashMap.get(key);
```

#code-switcher

**3.查找元素（键不存在）：**

#code-switcher

   ```python
x = my_dict.get(2, 0) # 如果键不存在，返回 0
   ```

```cpp
int x = hash_map[2]; // 如果键不存在，会自动插入 key 并初始化值为 默认值（例如0）
```

```java
int x = hashMap.getOrDefault(2, 0); // 如果键不存在，返回 0
```

#code-switcher

**4.删除元素：**

#code-switcher

   ```python
del my_dict[1]
# 或
my_dict.pop(1, None)
   ```

```cpp

```

```java
hashMap.remove(1);
```

## 时间复杂度

| 操作 | 平均时间复杂度 |
| ---- | -------------- |
| 插入 | O(1)           |
| 查找 | O(1)           |
| 删除 | O(1)           |

## 示例代码

#code-switcher

```python
my_dict = {}

# 插入
my_dict[1] = 2
my_dict[2] = 3

# 查询（存在）
if 1 in my_dict:
    print("键1的值:", my_dict[1])

# 查询（不存在）
print("键3的值:", my_dict.get(3, 0))

# 计数示例
nums = [1, 2, 2, 3]
cnt = {}
for x in nums:
    cnt[x] = cnt.get(x, 0) + 1
print(cnt)

# 删除
del my_dict[2]

# 大小
print("大小:", len(my_dict))

```

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

int main() {
    unordered_map<int, int> mp;

    // 插入
    mp[1] = 2;
    mp[2] = 3;

    // 查询（存在）
    if (mp.find(1) != mp.end()) {
        cout << "键1的值: " << mp[1] << endl;
    }

    // 查询（不存在）
    cout << "键3的值: " << mp[3] << endl; // 会插入 (3,0)

    // 计数示例
    int nums[] = {1, 2, 2, 3};
    unordered_map<int, int> cnt;
    for (int x : nums) {
        cnt[x]++;
    }

    // 删除
    mp.erase(2);

    // 大小
    cout << "大小: " << mp.size() << endl;

    return 0;
}

```

```java
import java.util.HashMap;

public class Main {
    public static void main(String[] args) {
        HashMap<Integer, Integer> map = new HashMap<>();

        // 插入
        map.put(1, 2);
        map.put(2, 3);

        // 查询（存在）
        if (map.containsKey(1)) {
            System.out.println("键1的值: " + map.get(1));
        }

        // 查询（不存在）
        System.out.println("键3的值: " + map.getOrDefault(3, 0));

        // 计数示例
        int[] nums = {1, 2, 2, 3};
        HashMap<Integer, Integer> cnt = new HashMap<>();
        for (int x : nums) {
            cnt.put(x, cnt.getOrDefault(x, 0) + 1);
        }

        // 删除
        map.remove(2);

        // 大小
        System.out.println("大小: " + map.size());
    }
}

```
