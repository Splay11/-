## LeetCode 20. 有效的括号

[在线刷题](https://codefun2000.com/p/P4025)

给定一个只包括 '('，')'，'{'，'}'，'['，']' 的字符串 s，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

**输入** 

```
([])
```

**输出** 

```
true
```

- 1 <= s.length <= 10^4
- s 仅由括号 '()[]{}' 组成

**思路：栈**

我们先来观察一下，括号到底是怎么匹配的。

比如样例：

```
([])
```

从左往右看，先出现的是$'('$，后出现的是$'['$

但真正匹配的时候，却是$'['$和$']'$先匹配，最后才轮到$'('$和$')'$匹配

也就是说：

**最后出现的左括号，反而是最先被匹配掉**

这个特点恰好与**栈**的**后进先出**特点吻合

由此得到启发，我们可以用栈来解决这道题

我们现在用栈来模拟样例进行匹配的过程。

比如字符串：

```
s = "{()}[]"
```

以及字符串

```
s = "{}(][{"
```

**我们用一个动画来为大家演示模拟的过程：**
@[video](https://codefun2000.com/p/4068/file/%E6%9C%89%E6%95%88%E7%9A%84%E6%8B%AC%E5%8F%B7.mp4)
通过动画的模拟我们可以总结出这题做法：

遍历每个字符，对于当前字符：

- 如果它是左括号，那么直接入栈。
- 如果它是右括号，那么它应该匹配某一种固定的左括号。

对于本题来说：

- `')'` 应该匹配 `'('`
- `']'` 应该匹配 `'['`
- `'}'` 应该匹配 `'{'`

```python 
class Solution:
    def isValid(self, s: str) -> bool:
        # 创建栈，用来存放还没有匹配的左括号
        stack = []

        # 括号匹配字典：右括号 -> 对应的左括号

            ')': '(',
            ']': '[',
            '}': '{'
        }

        # 遍历字符串中的每个字符
        for char in s:
            # 如果是左括号，直接入栈
            if char in '([{':
                stack.append(char)

            # 如果是右括号，需要和栈顶左括号匹配
            elif char in ')]}':
                # 如果栈为空，说明没有左括号可以匹配
                # 如果栈顶元素不是对应的左括号，说明匹配失败
                if not stack or stack.pop() != brackets[char]:
                    return False

        # 最后栈为空，说明所有左括号都被正确匹配
        return len(stack) == 0
```

```cpp 
class Solution {
public:
    bool isValid(string s) {
        // 创建栈，用来存放还没有匹配的左括号
        vector<char> stack;

        // 括号匹配字典：右括号 -> 对应的左括号
        unordered_map<char, char> brackets = {
            {')', '('},
            {']', '['},
            {'}', '{'}
        };

        // 遍历字符串中的每个字符
        for (char ch : s) {
            // 如果是左括号，直接入栈
            if (ch == '(' || ch == '[' || ch == '{') {
                stack.push_back(ch);
            }

            // 如果是右括号，需要和栈顶左括号匹配
            else if (ch == ')' || ch == ']' || ch == '}') {
                // 如果栈为空，说明没有左括号可以匹配
                // 如果栈顶元素不是对应的左括号，说明匹配失败
                if (stack.empty() || stack.back() != brackets[ch]) {
                    return false;
                }

                // 匹配成功，弹出栈顶左括号
                stack.pop_back();
            }
        }

        // 最后栈为空，说明所有左括号都被正确匹配
        return stack.empty();
    }
};
```

```go 
func isValid(s string) bool {
	// 创建栈，用来存放还没有匹配的左括号
	stack := []byte{}

	// 遍历字符串中的每个字符
	for i := 0; i < len(s); i++ {
		ch := s[i]

		// 如果是左括号，直接入栈
		if ch == '(' || ch == '[' || ch == '{' {
			stack = append(stack, ch)
		} else {
			// 如果是右括号，需要和栈顶左括号匹配
			if len(stack) == 0 {
				return false
			}

			top := stack[len(stack)-1]

			// 判断括号是否匹配
			if (ch == ')' && top != '(') ||
				(ch == ']' && top != '[') ||
				(ch == '}' && top != '{') {
				return false
			}

			// 匹配成功，弹出栈顶左括号
			stack = stack[:len(stack)-1]
		}
	}

	// 最后栈为空，说明所有左括号都被正确匹配
```

```c 
bool isValid(char* s) {
    int n = strlen(s);

    // 创建栈，用来存放还没有匹配的左括号
    char* stack = (char*)malloc(sizeof(char) * (n + 1));
    int top = 0;

    // 遍历字符串中的每个字符
    for (int i = 0; i < n; i++) {
        char ch = s[i];

        // 如果是左括号，直接入栈
        if (ch == '(' || ch == '[' || ch == '{') {
            stack[top++] = ch;
        } else {
            // 如果是右括号，需要和栈顶左括号匹配
            if (top == 0) {
                free(stack);
                return false;
            }

            char left = stack[--top];

            // 判断括号是否匹配
            if ((ch == ')' && left != '(') ||
                (ch == ']' && left != '[') ||
                (ch == '}' && left != '{')) {
                free(stack);
                return false;
            }
        }
    }

    // 最后栈为空，说明所有左括号都被正确匹配
    bool ans = (top == 0);

    free(stack);
    return ans;
}
```

### 面试问答

**1. 本题的核心思路是什么？**

先观察括号匹配的规律，会发现**最后出现的左括号一定要最先被匹配掉**，这正好符合栈“后进先出”的特点，所以可以用栈来维护当前还没有匹配的左括号。遍历字符串时，遇到左括号就入栈，遇到右括号就拿它和栈顶元素进行匹配；如果栈为空或者类型不对应，说明当前括号无法合法闭合，直接返回 `false`。最后如果栈为空，说明所有括号都被正确匹配，字符串有效。

**时间复杂度是 `O(n)`**，因为我们只需要从左到右遍历一遍字符串，每个字符最多只会入栈或出栈一次，所以整体是线性的。

**空间复杂度是 `O(n)`**，最坏情况下如果字符串全部都是左括号，那么这些括号都会被压入栈中，此时栈的大小会达到 `n`。

## LeetCode 155. 最小栈

[在线刷题](https://codefun2000.com/p/P4026)

设计一个支持 $push$ ，$pop$ ，$top$操作，并能在常数时间内检索到最小元素的栈。

   实现 $MinStack$ 类:

   - $MinStack()$ 初始化堆栈对象。

   - $void push(int val)$ 将元素val推入堆栈。
   - $void pop()$ 删除堆栈顶部的元素。
   - $int top()$ 获取堆栈顶部的元素。
   - $int getMin()$ 获取堆栈中的最小元素。

**输入**

```
7
push -2
push 0
push -3
getMin
pop
top
getMin
```

**输出**

```
-3
0
-2
```

- $-2^{31} <= val <= 2^{31} - 1$
- $pop$、$top$ 和 $getMin$操作总是在非空栈上调用
- $push$, $pop$, $top$, $and\  getMin$最多被调用 $3 * 10^4$ 次

**思路：普通栈+最小栈**

这道题一眼看上去不难，因为普通栈本来就支持：

* `push`
* `pop`
* `top`

真正难的地方在于：

**题目要求我们在 `O(1)` 时间内得到当前栈里的最小值**

我们先来看一个例子，假设**入栈顺序**为：

```
[-2,3,1,-5,4,-7]
```

我们发现当`-2`入栈后，后面入栈的`3`和`1`显然不可能是最小值，因为他们至少比`-2`大，往后直到`-5`入栈，才能够更新最小值，也就是说 **仅对于getMin()** 这个操作而言，其实大部分元素可能都没必要入栈，因为这些元素根本不可能成为最小值。

还有一个问题：

**如果我们只用一个普通栈，那么每次调用 `getMin()` 时，可能都要把整个栈遍历一遍，才能找到最小值**

这样时间复杂度就是 `O(n)`，显然不符合题意。

上面两个问题启发我们：

**可以再开一个最小栈，专门用来维护最小值**

**我们先来看这个样例的动画演示：**

@[video](https://codefun2000.com/p/4068/file/%E6%9C%80%E5%B0%8F%E6%A0%88.mp4)

从这个动画中我们可以看出来最小栈`min_stack`的作用就是存储,更新和获取最小值，我们总结一下规律:

* 普通数据全部放在 `data_stack`
* 每当一个新元素 **小于等于** 当前最小值时，就把它也压入 `min_stack`
* 每当 `pop()` 删除的元素，恰好等于 `min_stack` 的栈顶时，说明当前最小值被删掉了，此时 `min_stack` 也要同步弹出
#code-switcher

```python 
class MinStack:
    def __init__(self):
        # 数据栈：存放所有入栈元素
        self.data_stack = []

        # 最小栈：维护当前栈中的最小值
        self.min_stack = []

    def push(self, val: int) -> None:
        # 将元素压入数据栈
        self.data_stack.append(val)

        # 如果最小栈为空，或者当前元素小于等于最小栈栈顶
        # 说明当前元素可能成为当前栈的最小值，需要同步压入最小栈
        if not self.min_stack or val <= self.min_stack[-1]:
            self.min_stack.append(val)

    def pop(self) -> None:
        # 弹出数据栈栈顶元素
        top_element = self.data_stack.pop()

        # 如果弹出的元素等于最小栈栈顶元素
        # 说明当前最小值被弹出了，最小栈也要同步弹出
        if top_element == self.min_stack[-1]:
            self.min_stack.pop()

    def top(self) -> int:
        # 返回数据栈栈顶元素
        return self.data_stack[-1]

    def getMin(self) -> int:
        # 返回最小栈栈顶元素，也就是当前栈中的最小值
        return self.min_stack[-1]
```

```java 
import java.util.*;

class MinStack {
    // 数据栈：存放所有入栈元素
    private List<Integer> dataStack;

    // 最小栈：维护当前栈中的最小值
    private List<Integer> minStack;

    public MinStack() {
        // 初始化数据栈和最小栈
        dataStack = new ArrayList<>();
        minStack = new ArrayList<>();
    }

    public void push(int val) {
        // 将元素压入数据栈
        dataStack.add(val);

        // 如果最小栈为空，或者当前元素小于等于最小栈栈顶元素，则压入最小栈
        if (minStack.isEmpty() || val <= minStack.get(minStack.size() - 1)) {
            minStack.add(val);
        }
    }

    public void pop() {
        // 弹出数据栈栈顶元素
        int topElement = dataStack.remove(dataStack.size() - 1);

        // 如果弹出的元素等于最小栈栈顶元素，则最小栈也同步弹出
        if (topElement == minStack.get(minStack.size() - 1)) {
            minStack.remove(minStack.size() - 1);
        }
    }

    public int top() {
        // 返回数据栈栈顶元素
        return dataStack.get(dataStack.size() - 1);
    }

    public int getMin() {
        // 返回当前栈中的最小元素
        return minStack.get(minStack.size() - 1);
    }
}

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // 读取操作次数
        int q = scanner.nextInt();

        // 创建最小栈对象
        MinStack stack = new MinStack();

        // 依次处理每个操作
        for (int i = 0; i < q; i++) {
            String op = scanner.next();

            if (op.equals("push")) {
                int val = scanner.nextInt();
                stack.push(val);
            } else if (op.equals("pop")) {
                stack.pop();
            } else if (op.equals("top")) {
                System.out.println(stack.top());
            } else if (op.equals("getMin")) {
                System.out.println(stack.getMin());
            }
        }

        scanner.close();
    }
}
```

```c 
    // 数据栈：存放所有入栈元素
    int* dataStack;

    // 最小栈：维护当前栈中的最小值
    int* minStack;

    // 数据栈当前元素个数
    int dataSize;

    // 最小栈当前元素个数
    int minSize;

    // 栈容量
    int capacity;

MinStack* minStackCreate() {
    // 初始化最小栈对象
    MinStack* obj = (MinStack*)malloc(sizeof(MinStack));

    // 题目最多调用 3 * 10^4 次，这里开 30010 足够
    obj->capacity = 30010;
    obj->dataSize = 0;
    obj->minSize = 0;

    obj->dataStack = (int*)malloc(sizeof(int) * obj->capacity);
    obj->minStack = (int*)malloc(sizeof(int) * obj->capacity);

    return obj;
}

void minStackPush(MinStack* obj, int val) {
    // 将元素压入数据栈
    obj->dataStack[obj->dataSize++] = val;

    // 如果最小栈为空，或者当前元素小于等于最小栈栈顶元素，则压入最小栈
    if (obj->minSize == 0 || val <= obj->minStack[obj->minSize - 1]) {
        obj->minStack[obj->minSize++] = val;
    }
}

void minStackPop(MinStack* obj) {
    // 弹出数据栈栈顶元素
    int topElement = obj->dataStack[obj->dataSize - 1];
    obj->dataSize--;

    // 如果弹出的元素等于最小栈栈顶元素，则最小栈也同步弹出
    if (topElement == obj->minStack[obj->minSize - 1]) {
        obj->minSize--;
    }
}

int minStackTop(MinStack* obj) {
    // 返回数据栈栈顶元素
    return obj->dataStack[obj->dataSize - 1];
}

int minStackGetMin(MinStack* obj) {
    // 返回当前栈中的最小元素
    return obj->minStack[obj->minSize - 1];
```

**注意：**

代码里有一个细节`if not self.min_stack or val <= self.min_stack[-1]:`，为什么这里要写“小于等于”而不是“小于”？

这是一个非常容易忽略的细节。

比如依次压入：

```
push(2)
push(2)
push(3)
```

如果我们只在“严格小于当前最小值”时才压入最小栈，那么最小栈里可能只存一个 `2`

之后如果弹出一个 `2`，你会误以为最小值已经没了，但其实栈里还有一个 `2`

所以这里必须写成：

```
val <= self.min_stack[-1]
```

也就是说：

**只要新元素小于等于当前最小值，都要压入最小栈**

这样才能正确处理重复最小值。

### 面试问答

**1. 本题的核心思路是什么？**

普通栈无法在 `O(1)` 时间获取最小值，因此我们额外使用一个辅助栈 `min_stack` 来同步维护当前最小值；当元素入栈时，如果它小于等于当前最小值，就同时压入 `min_stack`，当元素出栈时，如果它正好等于最小栈栈顶，则同步弹出，这样 `min_stack` 的栈顶始终就是当前栈中的最小值，从而保证 `getMin()` 操作可以在常数时间内完成。

**时间复杂度是 `O(1)`**，因为每个操作（`push`、`pop`、`top`、`getMin`）都只涉及常数次栈的入栈或出栈操作，不需要遍历。

**空间复杂度是 `O(n)`**，最坏情况下所有元素都会进入 `min_stack`（例如单调递减序列），因此需要额外的线性空间来存储辅助栈。

```go 
    stack := []byte{}

    // 遍历字符串中的每个字符
    for i := 0; i < len(s); i++ {
        c := s[i]
```

```c 
static void ensureCapacity(char** arr, int* capacity, int need) {
    // 如果当前容量不够，就不断扩容
    while (*capacity <= need) {
        *capacity *= 2;
        *arr = (char*)realloc(*arr, sizeof(char) * (*capacity));

char* decodeString(char* s) {
    int n = strlen(s);

    // 使用字符数组模拟栈
    int capacity = n + 10;
    char* stack = (char*)malloc(sizeof(char) * capacity);
    int top = 0;

    // 遍历字符串中的每个字符
    for (int i = 0; i < n; i++) {
        char c = s[i];

        // 遇到非右括号字符，直接入栈
        if (c != ']') {
            ensureCapacity(&stack, &capacity, top + 1);
            stack[top++] = c;
        } else {
            // 1. 取出括号中的字符串
            int strCap = 16;
            char* nowStr = (char*)malloc(sizeof(char) * strCap);
            int strLen = 0;

            while (top > 0 && stack[top - 1] != '[') {
                if (strLen + 1 >= strCap) {
                    strCap *= 2;
                    nowStr = (char*)realloc(nowStr, sizeof(char) * strCap);
                }
                nowStr[strLen++] = stack[--top];
            }

            // 弹出左括号
            top--;

            // 因为是从栈顶取出的，所以需要反转
            for (int l = 0, r = strLen - 1; l < r; l++, r--) {
                char temp = nowStr[l];
                nowStr[l] = nowStr[r];
                nowStr[r] = temp;
            }

            // 2. 取出左括号前面的数字
            int num = 0;
            int base = 1;
            while (top > 0 && isdigit(stack[top - 1])) {
                num += (stack[--top] - '0') * base;
                base *= 10;
            }

            // 3. 将解码后的字符串重新压入栈中
            int need = top + num * strLen + 1;
            ensureCapacity(&stack, &capacity, need);

            for (int k = 0; k < num; k++) {
                for (int j = 0; j < strLen; j++) {
                    stack[top++] = nowStr[j];
                }
            }

            free(nowStr);
        }
    }

    // 栈中剩余字符拼接成最终结果
    ensureCapacity(&stack, &capacity, top + 1);
    stack[top] = '\0';

    return stack;
}
```

## LeetCode 71. 简化路径
[在线刷题](https://codefun2000.com/p/P4818)

给你一个字符串 `path` ，表示指向某一文件或目录的 Unix 风格 **绝对路径**（以 `'/'` 开头），请你将其转化为 **更加简洁的规范路径**。

在 Unix 风格的文件系统中，规则如下：

- 一个点 `'.'` 表示当前目录本身。
- 此外，两个点 `'..'` 表示将目录切换到上一级（指向父目录）。
- 任意多个连续的斜杠（即，`'//'` 或 `'///'`）都被视为单个斜杠 `'/'`。
- 任何其他格式的点（例如，`'...'` 或 `'....'`）均被视为有效的文件/目录名称。

返回的 **简化路径** 必须遵循下述格式：

- 始终以斜杠 `'/'` 开头。
- 两个目录名之间必须只有一个斜杠 `'/'`。
- 最后一个目录名（如果存在）**不能**以 `'/'` 结尾。
- 此外，路径仅包含从根目录到目标文件或目录的路径上的目录（即，不含 `'.'` 或 `'..'`）。

返回简化后得到的 **规范路径**。

**输入** 

```
path = "/.../a//../b/c/../d/./"
```

**输出** 

```
"/.../b/d"
```

* $1 \le |path| \le 3000$
* $path$ 由英文字母、数字、$'.'$、$'/'$、$'\_'$ 组成
* $path$ 保证是一个合法的 Unix 风格绝对路径

**思路：栈**

我们按 `'/'` 分割后，会得到这些片段：

```
["", "...", "a", "", "..", "b", "c", "..", "d", ".", ""]
```

这些空串都可以直接忽略。去除空串得到：

```
[ "...", "a",  "..", "b", "c", "..", "d", "."]
```

**分析题目的规则**

`'.'` 表示当前目录本身，说明需要**保留前一个目录**，例如示例中的`["d", "."]`，简化为`["d"]`

`'..'` 表示将目录切换到上一级，说明需要**跳过前一个目录**，例如示例中的`["...", "a",  ".."]`，简化为`["..."]`

**为什么使用栈？**

因为这个过程天然就符合**栈“后进先出”**的特点。

每进入一个新目录，就相当于把这个目录压进栈里；而遇到 `".."` 时，表示返回上一级目录，实际上就是把**最近进入的那个目录**删掉。

而“最近进入的目录最先退出”，这正好就是栈的规则。

我们可以总结以下步骤：

1. 先将路径按`'/'`分割成不包含空串的字符串数组
2. 从左到右遍历
   - 遇到`'.'` ，直接跳过继续遍历，
   - 遇到`'..'`，弹出栈顶，
   - 其它情况，将字符串放入栈中。
3. 最后把栈中的目录重新拼起来。

```go
                stack = stack[:len(stack)-1]
            }
        } else {
            // 普通目录名入栈
            stack = append(stack, name)
        }
    }

    // 如果栈为空，说明结果是根目录
    if len(stack) == 0 {
        return "/"
    }

    // 拼接成规范路径
    return "/" + strings.Join(stack, "/")
}
```

```c
char* simplifyPath(char* path) {
    int n = strlen(path);

    // 用栈保存规范路径中的目录
    char** stack = (char**)malloc(sizeof(char*) * (n + 1));
    int top = 0;

    char* copy = (char*)malloc(sizeof(char) * (n + 1));
    strcpy(copy, path);

    // 按 '/' 分割路径
    char* token = strtok(copy, "/");

    // 依次处理每一段
    while (token != NULL) {
        if (strcmp(token, ".") == 0) {
            // 空串和 '.' 都直接忽略
        } else if (strcmp(token, "..") == 0) {
            // '..' 表示返回上一级目录
            if (top > 0) {
                free(stack[--top]);
            }
        } else {
            // 普通目录名入栈
            stack[top] = (char*)malloc(sizeof(char) * (strlen(token) + 1));
            strcpy(stack[top], token);
            top++;
        }

        token = strtok(NULL, "/");
    }

    // 如果栈为空，说明结果是根目录
    if (top == 0) {
        char* ans = (char*)malloc(sizeof(char) * 2);
        strcpy(ans, "/");

        free(stack);
        free(copy);

        return ans;
    }

    int totalLen = 1;
    for (int i = 0; i < top; i++) {
        totalLen += strlen(stack[i]) + 1;
    }

    char* ans = (char*)malloc(sizeof(char) * (totalLen + 1));
    ans[0] = '\0';

    // 拼接成规范路径
    for (int i = 0; i < top; i++) {
        strcat(ans, "/");
        strcat(ans, stack[i]);
    }

    for (int i = 0; i < top; i++) {
        free(stack[i]);
    }
    free(stack);
    free(copy);

    return ans;
}
```

### 面试问答

**1. 本题的核心思路是什么？**

先把路径按 `/` 切开，再用一个栈模拟走目录。遇到普通文件夹名就进去，也就是入栈；遇到 `".."` 就退回上一级，也就是弹栈；遇到 `"."` 或空串就直接跳过。最后把栈里的内容重新用 `/` 拼起来，就是规范路径。

**时间复杂度是 `O(n)`**，因为整个字符串只需要遍历一遍。

**空间复杂度是 `O(n)`**，因为栈最多存储整个路径。
