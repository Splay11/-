给定两个整数数组 `preorder` 和 `inorder`，其中 `preorder` 是这棵树的先序遍历，`inorder` 是同一棵树的中序遍历。请你把这棵二叉树构造出来，并返回根节点。

**输入**

```

```


**提示**

- `1 <= preorder.length <= 3000`
- `inorder.length == preorder.length`
- `-3000 <= preorder[i], inorder[i] <= 3000`
- `preorder` 和 `inorder` 中都没有重复元素
- `inorder` 中每个值都在 `preorder` 中出现
- `preorder` 保证是某棵树的先序序列
- `inorder` 保证是同一棵树的中序序列

# 方法一：递归划分区间（DFS + 哈希表）

构造二叉树的条件是：确定根+确定左子树和右子树。

而:

1. **先序遍历的第一个元素一定是当前子树的根**
2. **中序遍历里，根左边是左子树，根右边是右子树**

如下图所示👇

![img](https://codefun2000.com/p/4258/file/%E7%A4%BA%E6%84%8F%E5%9B%BE.svg?type=additional_file)

所以我们可以写一个递归函数 `dfs(preL, preR, inL, inR)`，表示：

- 当前要构建的子树，先序范围是 `[preL, preR]`
- 中序范围是 `[inL, inR]`

每次递归：

1. 取根:`rootVal = preorder[preL]`
2. 在中序`inorder`里找到`rootVal`的下标 `k`
3. 左子树大小 `leftSize = k - inL`
4. 递归构建左子树：
   - 先序：`[preL+1, preL+leftSize]`
   - 中序：`[inL, k-1]`
5. 递归构建右子树：
   - 先序：`[preL+leftSize+1, preR]`
   - 中序：`[k+1, inR]`

注意一点：如果每次都在中序数组里线性找 `k`，会退化成 `O(n^2)`。  
所以我们先用哈希表 `idx[val] = 在 inorder 中的位置`，这样找根位置就是 `O(1)`。

```python
class Solution:
    def buildTree(self, preorder, inorder):
        n = len(preorder)

        # 空数组无法构造二叉树
        if n == 0:
            return None

        # 记录中序遍历中每个值的位置，方便 O(1) 找到根节点下标
        idx = {}
        for i in range(n):
            idx[inorder[i]] = i

        # dfs(preL, preR, inL, inR):
        # 当前子树的先序区间是 [preL, preR]
        # 当前子树的中序区间是 [inL, inR]
        def dfs(preL, preR, inL, inR):
            # 区间为空，说明没有节点
            if preL > preR:
                return None

            # 先序遍历的第一个元素一定是当前子树的根节点
            root_val = preorder[preL]
            root = TreeNode(root_val)

            # 在中序遍历中找到根节点位置
            k = idx[root_val]

            # 根节点左边都是左子树，所以可以得到左子树节点个数
            left_size = k - inL

            # 递归构造左子树
            root.left = dfs(preL + 1, preL + left_size, inL, k - 1)

            # 递归构造右子树
            root.right = dfs(preL + left_size + 1, preR, k + 1, inR)

            return root

        return dfs(0, n - 1, 0, n - 1)
```

## 复杂度分析

- 时间复杂度：`O(n)`  
  每个节点只会被递归处理一次，哈希表定位根位置是 `O(1)`。
  
- 空间复杂度：`O(n)`  
  哈希表 `O(n)`，递归栈最坏 `O(n)`（一条链）

### 面试问答

**1. 本题核心思路**

递归。还原二叉树的先决条件是：确定根+确定左子树和右子树。考虑先序首元素是根，中序按根一刀切成左右子树，再递归构造左右区间。为了优化复杂度，不在中序里反复找根，用哈希表把“值 -> 下标”先预处理好。
