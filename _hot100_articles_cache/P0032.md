## LeetCode 739. 每日温度

[在线刷题](https://codefun2000.com/p/P4081)

给定一个整数数组 $temperatures$ ，表示每天的温度，返回一个数组 $answer$ ，其中 $answer[i] $是指对于第 $i$ 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 $0$ 来代替

**输入** 

```
73 74 75 71 69 72 76 73
```

**输出** 

```
1 1 4 2 1 1 0 0
```

- $1 <= temperatures.length <= 10^5$
- $30 <= temperatures[i] <= 100$

**思路**

一个朴素的思想是：双重循环枚举，从后往前枚举每个元素$a_i$，然后每次往后寻找第一个大于它的元素的下标。如以下动画所示👇
@[video](https://codefun2000.com/p/4068/file/%E6%AF%8F%E6%97%A5%E6%B8%A9%E5%BA%A6%E6%9A%B4%E5%8A%9B.mp4)


**从后往前**枚举$i$的过程中，我们可以动态的维护一个栈，用于弹出那些无用的元素，减少重复计算。



so，哪些元素是没用的？我们看个例子：

![](/file/2/Zk10ZzigtegfWBj6_rxqm.png)



对于上图的例子而言，假设已经枚举到8了，已处理部分中的$5,6$ 均比$8$ 要小 。

仔细想想，这个问题要我们 **对每个元素求 (右边离他最近的) (比它大) 的元素的下标。**

而对于**未处理部分**，$8$  比$5,6$  离它们更近，而且它又更大。这意味着$5,6$ 这两个元素在后续过程中不会产生任何影响了。

换句话说，**新出现的这个$8$ , 像一座更高的山，把$5,6$ 给拦住了，使得未处理部分的元素不可能找得到$5,6$了。**

![](/file/2/SaBsp15NmavoLtG8NhrGG.png)



所以可以这么说：**每次新增一个元素$a_i$，所有右侧比$a_i$ 小的元素都可以被删除。**

此时$5,6$被弹出栈，$8$ 被压入栈中。

接着我们看下一个位置的计算👇

![](/file/2/cRLoRWi7oc6cf5XXY9FMS.png)



考虑 $a_5 = 4$  ，  栈顶元素$a_6 = 8$的下标$6$是它的答案。   

**此时$4$ 要不要压入栈中呢？**  从图上的例子看好像是不需要的，因为左侧未处理部分都比他大啊？但是**如果把7改成3，4必须保留了。**

![](/file/2/wsIqgMZwh8vgNz143xill.png)

#warning-box
**发现**:这个例子告诉我们，每个元素一定要被压入栈中。因为你无法确定左侧是否存在比当前元素更小的元素
#warning-box

**所以我们大概能想到一个栈的做法：**

从右往左枚举每一个位置，维护一个栈记录下标。每次新增一个元素的时候，不停的将栈顶元素弹出，直到栈为空(此时答案为$0$)或者找到一个比它大的元素（此时答案为栈顶元素）。最后将元素下标推入栈内。



接着我们看一段动画来进一步理解这个做法👇
@[video](https://codefun2000.com/p/4068/file/%E6%AF%8F%E6%97%A5%E6%B8%A9%E5%BA%A6.mp4)


**思考1：为什么这个算法叫单调栈？**

因为这个栈从栈顶到栈底，元素是单调的。在本问题中这个栈是单调递增的。 

为什么会是单调的？ 假设当前栈是单调递增的，每个新的元素在插入栈的时候，会将所有比它小的元素弹出，遇到大的才停止(你可以这么理解，每一个新的元素出现，所有栈里的**逆序对会被清空**)。这个算法保证了栈的单调性。

**思考2：为什么单调栈能找到最近的元素？**

**因为算法保证了每一个新增的元素必须被插入栈中，无论它多小，都必须保留。此时就保证了栈里每个元素是尽量"新"的** 。 如动画里的两个相邻的5，如果有相同大小的元素，我们只保留最新的那一个。

**思考3：该算法时间复杂度是多少？**

$O(n)$ ， 因为每个元素最多进栈一次，出栈一次。也就是不会有重复进出的情况。总共有$n$个元素，则计算次数为$2n$次。

```python
class Solution:
    def dailyTemperatures(self, temperatures: list) -> list:
        n = len(temperatures)
        answer = [0] * n  # 初始化答案数组
        stack = []  # 存储温度下标

        # 遍历温度数组
        for i in range(n - 1, -1, -1):
            # 弹出栈顶元素，直到找到一个比当前温度更高的温度
            while stack and temperatures[i] >= temperatures[stack[-1]]:
                stack.pop()

            # 如果栈不为空，计算等待天数
            if stack:
                answer[i] = stack[-1] - i

            # 将当前温度的下标压入栈中
            stack.append(i)

        return answer
```

```cpp
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        int n = temperatures.size();
        vector<int> answer(n, 0); // 初始化答案数组
        vector<int> stack; // 存储温度下标

        // 遍历温度数组
        for (int i = n - 1; i >= 0; i--) {
            // 弹出栈顶元素，直到找到一个比当前温度更高的温度
            while (!stack.empty() && temperatures[i] >= temperatures[stack.back()]) {
                stack.pop_back();

            if (!stack.empty()) {
                answer[i] = stack.back() - i;
            }

            // 将当前温度的下标压入栈中
            stack.push_back(i);
        }

        return answer;
    }
};
```

## LeetCode 456. 132 模式

[在线刷题](https://codefun2000.com/p/P4817)

> 本题不属于Hot 100 题单，但是来源于[华为高频手撕题Top20](https://codefun2000.com/codenote/hot100/P0023) !

给你一个整数数组 `nums` ，数组中共有 `n` 个整数。132 模式的子序列由三个整数 `nums[i]`、`nums[j]` 和 `nums[k]` 组成，并满足：`i < j < k` 和 `nums[i] < nums[k] < nums[j]` 。

如果 `nums` 中存在 132 模式的子序列 ，返回 `true` ；否则，返回 `false` 。

**输入**
```
1 2 3 4
```
**输出**
```
false
```
**说明**
```
132 模式的子序列需要满足：`i < j < k` 和 `nums[i] < nums[k] < nums[j]` 。
```

**思路:枚举2 + 贪心 + 单调栈**

"132"模式中，`2`是三个数里最靠右的，考虑从左往右枚举`2`，回头看前缀区域去找`13` :

先不考虑`1`的限制，当我们枚举到某个`2`的时候，考虑左侧有若干个`3` ，如下图所示👇

![](/file/2/XZV48YjNnxEDrT-Z4qN5K.png)


此时我们应该选哪个`3`才**最有可能**满足132条件？  

这里有些同学可能会想不明白，觉得我们选最大的那个`3`才行，但其实不然。

我们先选图中最大的那个`3`试试看👇

![](/file/2/eRF3yaQj7idN3vVlLJii2.png)


说明：选定`32`后我们发现，`1`要从`3`的左侧选的。又因为`1`是三个数里的最小值，所以贪心的思考，一定是去选`3`左侧最小的元素（即前缀最小值）。因为选出来的`1`越小，越容易满足`132`模式。

所以对于这些`3`，一定是选最靠右的位置。只有这样才能让`1`的选择范围尽可能大👇

![](/file/2/YHADS22oAB4aE2p9dDn6c.png)

#warning-box 

**补充说明**: 有些同学可能有疑问，我选靠右侧的`3` ， 这样`3`有可能变小了呀。

**但是其实这个地方的瓶颈不在`3`而是`2`**。因为我们不管选哪个`3`，都比当前的`2`要大。所以选最靠右的`3`，是为了找到一个数去比`2`更小，跟`3`多大是不搭嘎的。

#warning-box 


所以如何得到`2`左侧第一个比`2`大的`3`？单调栈即可。 找到之后，再考虑`3`之前的前缀最小值`min` , 如果`min < 2`，则满足132条件。

到这里做法就很显然了：

1.先预处理一遍前缀最小值，用于后续方便选出`1`。

2.从左到右枚举`2`,同时维护一个单调栈，对于每个`2`，贪心的考虑左侧第一个比`2`大的`3`。如果`3`对应位置的前缀最小值`min` < `2`，则满足132条件。

整个算法结束，如果没有满足132条件的`2`，则返回`false`。

```python id="v5ex1p"
class Solution:
    def find132pattern(self, nums: List[int]) -> bool:
        # 单调栈，维护可能作为 nums[j] 的元素
        stack = []

        # third 表示当前找到的 nums[k]
        # 也就是 132 模式中的 “2”
        third = float("-inf")

        # 从右往左枚举 nums[i]
        for i in range(len(nums) - 1, -1, -1):
            # 如果 nums[i] < third，说明找到了 nums[i] < nums[k] < nums[j]
            if nums[i] < third:
                return True

            # 如果当前 nums[i] 比栈顶大
            # 那么栈顶可以作为 nums[k]，当前 nums[i] 可以作为 nums[j]
            while stack and nums[i] > stack[-1]:
                third = stack.pop()

            # 当前元素入栈，作为后续可能的 nums[j]
            stack.append(nums[i])

        return False
```

```cpp id="z1tkv9"
public:
    bool find132pattern(vector<int>& nums) {
```

## LeetCode 84. 柱状图中最大的矩形

[在线刷题](https://codefun2000.com/p/P4082)

给定 $n$ 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为$ 1 $。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

**输入** 

```
2 1 5 6 2 3
```

**输出** 

```
10
```

- $1 <= heights.length <=10^5$
- $0 <= heights[i] <= 10^4$

**思路**

**1.枚举 + 两遍单调栈**

一个比较直接的思路是：直接枚举每个柱子$i$，考虑以$h[i]$为高度的最大面积。

高度确定了，位置也确定了，怎么计算以$h[i]$为高度的最大宽度呢？

很简单，往左找第一个比它矮的柱子的位置，再往右找第一个比它矮的柱子的位置。因为只有比它矮的位置会把这个高度**截断**👇

![](/file/2/6hVuq97_qqSBsQsTGpwAs.png)


在上一题中，我们学习了如何用单调栈寻找单边第一个比它大/小的元素位置。而在本题中，我们就只需要跑正反两遍单调栈就能得到计算面积所需要的面积了！

可以，这段后面可以这样接：

**用这种思路，我们可以预处理两个数组：**

* `left[i]`：表示 `i` 左边第一个严格小于 `heights[i]` 的位置
* `right[i]`：表示 `i` 右边第一个严格小于 `heights[i]` 的位置

那么以 `heights[i]` 作为矩形高度时，它能向左右扩展的最大区间就是：

```text
(left[i], right[i])
```

注意左右两边是开区间，所以宽度是：

```text
right[i] - left[i] - 1
```

因此当前柱子能形成的最大矩形面积就是：

```text
heights[i] * (right[i] - left[i] - 1)
```

最后枚举所有柱子取最大值即可。

你说得对，这题必须保证：

* `left[i]`：左边第一个 **严格小于** `heights[i]` 的位置
* `right[i]`：右边第一个 **严格小于** `heights[i]` 的位置
* 所以单调栈弹栈条件必须是：

```text
heights[stackTop] >= heights[i]
```

对于样例：

```text
9 6 8 5 2 3 10
```

高度 `5` 的位置可以覆盖 `[9,6,8,5]`，宽度是 `4`，面积是 `5 * 4 = 20`。

```python id="ko7w8t"
from typing import List

class Solution:
    def largestRectangleArea(self, h: List[int]) -> int:
        n = len(h)

        # left[i]表示h[i]左边第一个比它小的元素的下标，right[i]表示h[i]右边第一个比它小的元素的下标
        left = [0] * n
        right = [0] * n
        stack = []

        # 正序遍历，求出每个元素左边第一个比它小的元素的下标
        for i in range(n):
            while stack and h[stack[-1]] >= h[i]:
                stack.pop()

            left[i] = stack[-1] if stack else -1
            stack.append(i)

        stack.clear()

        # 逆序遍历，求出每个元素右边第一个比它小的元素的下标
        for i in range(n - 1, -1, -1):
            while stack and h[stack[-1]] >= h[i]:
                stack.pop()

            right[i] = stack[-1] if stack else n
            stack.append(i)

        # 遍历每个元素，计算以它为高度的矩形的面积，并更新最大面积
        ans = 0
        for i in range(n):
            ans = max(ans, (right[i] - left[i] - 1) * h[i])

        return ans
```

**2.巧妙的优化成一遍单调栈**

在上面那个做法中，正序遍历时我们得到的是每个元素**它左侧这"半扇"的宽度**，如何在这个过程中直接算出**右侧“半扇”的宽度呢**？

思路：考虑每次插入$h[i]$的时候，大家仔细想想，**那些要弹被出来的元素$k$ , 满足条件$h[k] > h[i]$ ， 那么此时这些$k$ 的右边比它小的第一个位置都是$i$**

**如下图给的这种情况👇**

![](/file/2/k1vmyU-uF3Mv8N_iwz8hw.png)


说明：假设这个数组已经扫到第四个元素，此时栈中的$5,9$ 都需要被弹出，此时4就是它们右侧的"限制"。此时左侧和右侧的位置都被求出，自然的就能确定<以这些被弹出的柱子为高度>的最大面积了。

**就比如上述例子的9，它的宽度是这样被确定的👇**

![](/file/2/wCzunctv73_5VQsJ4RkW0.png)


**运行到最后，需要把栈里未弹出的元素再统一计算一遍**。运行完还在栈里的元素，是那些<它的右侧没有比它更低的柱子>的位置，它们的右侧没有宽度限制，一直顶到右边界，如图中例子$3[1],5[6],6[7]$ 是运行完之后会留在单调栈里的元素,它们的右边界没有限制👇。

![](/file/2/DFt2xK-w17F6rx7fv5lGV.png)


所以总结一下这个算法的思想：对于每一个柱子，左侧的宽度通过单调栈的顺序结构得出，右侧的宽度通过 <之后某个比它小的元素>让它弹出的时刻计算出来。

**所以这个思路和第一个思路不同的地方在于**：第一个思路是提前算出左右宽度，接着对于每个柱子直接计算答案，而本思路进一步发现了<元素被弹出>的时刻其实右宽度就能被确定了。

```python id="x0wv0t"
from typing import List

class Solution:
    def largestRectangleArea(self, h: List[int]) -> int:
        n = len(h)
        stack = []
        ans = 0

        for i in range(n):
            while stack and h[stack[-1]] >= h[i]:
                index = stack.pop()

                # <栈顶元素> 的高度是 h[stack[-1]]
                height = h[index]

                # <栈顶元素> 的右“半扇”的宽度是当前元素与栈顶元素的距离
                right_width = i - index - 1

                # <栈顶元素> 的左“半扇”的宽度是栈顶元素到再前一个元素的距离
                # 如果栈中没有再前一个元素了，那么左“半扇”的宽度就是栈顶元素到最左边的距离
                left_width = index - (stack[-1] if stack else -1)

                # <栈顶元素> 的矩形面积是高度乘以宽度
                area = height * (left_width + right_width)
                ans = max(ans, area)

            stack.append(i)

        # 处理剩余的元素
        while stack:
            index = stack.pop()
            height = h[index]
            right_width = n - index - 1
            left_width = index - (stack[-1] if stack else -1)
            area = height * (left_width + right_width)
            ans = max(ans, area)

        return ans
```

### 面试问答

1. **本题的核心思路是什么？（朴素版）**

对于一个柱子$i$，考虑以$h[i]$为高度的最大宽度 受限于 左侧和右侧第一个高度比它小的位置。那么可以正反跑一遍单调栈来分别求出左侧/右侧比它小的位置`left/right`。之后枚举所有柱子，以这个柱子的高度所能形成的最大面积就是$(right[i] - left[i] - 1) * h[i]$ 。 所有柱子能形成的最大面积中的最大值就是本题的结果。

时间复杂度为：$O(n)$ ， 因为一遍单调栈的每个元素最多进栈一次，出栈一次。也就是不会有重复进出的情况。总共有$n$个元素，则计算次数为$2n$次。 两遍单调栈计算$4n$次。

空间复杂度：$O(n)$ , 开销来自栈数组。
