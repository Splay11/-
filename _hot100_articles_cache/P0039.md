## 二叉树

二叉树本质是一个无环[图](https://codefun2000.com/codenote/hot100/P0034) 。

它形如一个树形结构，其中每个节点**最多只有两个孩子节点**，通常称为左孩子和右孩子。

例如这就是一棵二叉树:

```
    A
   / \
  B   C
 / \
D   E
```

这不是一棵二叉树,因为它有环

```
    A
   / \
  B   C
 / \ /
D   E
```

这也不是一棵二叉树,因为`B`节点有三个儿子

``` 
    A
   / \
  B   C
 /|\ 
D E F
```

## **完全二叉树**

在二叉树的基础上，满足下面这个条件：

除了最后一层外，**其余每一层的节点数都达到最大值**；
 最后一层的节点都**连续集中在最左边**。

换句话说：

1.前面几层必须是满的

2.最后一层可以不满

3.但最后一层缺的节点只能出现在右边，不能左边空了右边还有节点
例如这是完全二叉树：

```
      1
     / \
    2   3
   / \  /
  4  5 6
```

最后一层是从左往右连续排的，所以它是完全二叉树。

这也是一个完全二叉树：

```
      1
     / \
    2   3
   / \  / \
  4  5 6   7
```

这种最后一层没有缺失的完全二叉树也叫做满二叉树，它的节点个数是$2^{层数 - 1}$ 。

这个不是完全二叉树：

```
      1
     / \
    2   3
   / \   \
  4  5    6
```

因为最后一层没有“左对齐”，左边缺了位置。

这更不是完全二叉树：

```
      1
     /
    2 
   / \   
  4   5
```

因为它第二层都没满。

### 完全二叉树的存储和访问

完全二叉树有一个非常重要的性质：可以用**数组来存储**，并且**通过下标直接访问节点关系**

我们把节点按层序遍历（从上到下、从左到右）依次放入数组：

例如这棵完全二叉树：

```
      1
     / \
    2   3
   / \  /
  4  5 6
```
对应数组为：
```
index: 0 1 2 3 4 5
value: 1 2 3 4 5 6
```
**下标关系**

假设当前节点下标为 `i`：

左孩子：`2 * i + 1`

右孩子：`2 * i + 2`

父节点：`(i - 1) // 2`

如果将数组的下标放在节点里，不难发现每一个位置和它们的儿子节点都满足上述关系👇
