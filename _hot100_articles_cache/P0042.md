## LeetCode 121. 买卖股票的最佳时机

[在线刷题](https://codefun2000.com/p/P4029)

给定一个数组 $prices$，它的第 $i$ 个元素 $prices[i]$ 表示一支给定股票第 $i$ 天的价格。

你只能选择某一天买入这只股票，并选择在未来的某一个不同的日子卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 $0$ 。

**输入** 

```
6
7 1 5 3 6 4
```

**输出** 

```
5
```

- $1 <= prices.length <= 10^5$
- $0 <= prices[i] <= 10^4$

**思路**

枚举每一天去卖出股票。假设在第$i$天卖，那么一定是在前缀区域$[1,i - 1]$ 去找一个$j$使得 $prices[j]$  最小， 这样答案

$$ans = price[i] - price[j]$$  

才能最大。

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        # 维护前缀区域中的最低价格
        minPrice = prices[0]
        # 记录当前能够获得的最大利润
        ans = 0

        # 枚举每一天作为卖出日
        for price in prices:
            # 如果今天卖出，利润 = 今天价格 - 前面最低买入价格
            ans = max(ans, price - minPrice)
            # 更新到目前为止的最低价格
            minPrice = min(minPrice, price)

        return ans
```

## LeetCode 55. 跳跃游戏

[在线刷题](https://codefun2000.com/p/P4030)

给你一个非负整数数组 $nums$ ，你最初位于数组的第一个下标 。数组中的每个元素代表你在该位置可以跳跃的最大长度。

判断你是否能够到达最后一个下标，如果可以，返回 $true$ ；否则，返回 $false$ 。

**输入** 

```
2 3 1 1 4
```

**输出** 

```
true
```

- $1 <= nums.length <= 10^4$
- $0 <= nums[i] <= 10^5$

**思路**

维护一个当前能到达的最大右边界$right$，一开始$right = 1$ 。 从左往右循环，每次考虑$i + nums[i]$ 是否能将右边界$right$ 往右推进，即$right = max(right,i + nums[i])$ 。 当循环过程中$i > right$ 则循环终止。

class Solution:
    def canJump(self, nums: List[int]) -> bool:
        right = 0  # 当前可以跳跃到的最远下标
        n = len(nums)

        for i in range(n):
            # 如果当前位置不可达，则返回 False
            if i > right:
                return False

            # 更新最远可以到达的下标
            right = max(right, i + nums[i])

            # 如果可以到达最后一个下标，直接返回 True
            if right >= n - 1:
                return True

        return False

## LeetCode 45. 跳跃游戏Ⅱ

[在线刷题](https://codefun2000.com/p/P4084)

给定一个长度为 $n$的 $0$ 索引整数数组 $nums$。初始位置为 $nums[0]$。

每个元素 $nums[i]$ 表示从索引 $i$ 向后跳转的最大长度。换句话说，如果你在 $nums[i]$ 处，你可以跳转到任意 $nums[i + j]$ 处:

- $0 <= j <= nums[i]$ 
- $i + j < n$

返回到达 $nums[n - 1]$的最小跳跃次数。生成的测试用例可以到达 $nums[n - 1]$。

**输入** 

```
2 3 1 1 4
```

**输出** 

```
2
```

- $1 <= nums.length <= 10^4$
- $0 <= nums[i] <= 1000$
- 题目保证可以到达 $nums[n-1]$

**思路:贪心+双指针优化**

和上题的区别在于：需要求出最小的跳跃次数。

一个**暴力贪心**的思路是：

每次在当前跳跃能到达的所有范围$[i,end]$中，找一个能到达的最远距离的下标，将这个下标当作下一次跳跃的目的地，如此往复计算即可。

这里举个实际的例子大家就明白了

```python id="a7j2ks"
class Solution:
    def jump(self, nums: List[int]) -> int:
        n = len(nums)
        if n <= 1:
            return 0

        ans = 0
        end = 0
        idx = 0

        while end < n - 1:
            # 当前能到的范围
            end = min(idx + nums[idx], n - 1)

            right = -1 # 记录这个可行范围里的最远距离
            mx_idx = -1 # 记录这个可行范围里的最远距离所对应的下标，也就是下一次跳跃的目的地

            # 枚举这个区间里的最远距离并找到这个下标
            for i in range(idx, end + 1):
                if right < i + nums[i]:
                    right = i + nums[i]
                    mx_idx = i

            # 跳到对应下标，进行下下一轮
            idx = mx_idx
            ans += 1

        return ans
```

上述复杂度不够优秀，因为每次枚举时跳跃可行范围$[i,end]$ 区间有重叠，导致重复计算。其实这些重叠的区间的$right$我们已经算出来过了，但是每次计算新的跳跃的时候$right$还是得从$-1$开始👇

![](/file/2/fN9iP2h22FqB4lLq8rYX3.png)



**双指针优化**：为了不进行重复计算，可以将$right$变成一个单调往右移动的指针。每次枚举到`end + 1`之后，跳跃数+1 ，此时$idx$不回再到$max\_id$的位置，而是继续向右扫描，如此往复。

```python
class Solution:
    def jump(self, nums: List[int]) -> int:
        n = len(nums)
        if n <= 1:
            return 0

        ans = 0
        # end 代表本次跳跃的右边界
        end = 0
        # right 代表当前能够达到的右边界
        right = 0

        for i in range(n - 1):
            # 更新右边界
            right = max(right, i + nums[i])

            # 当枚举的位置超过本次跳跃的右边界，则 将end 更新到当前能够达到的右边界
            if i == end:
                ans += 1
                end = right

        return ans
```

        right = Math.max(right, i + nums[i]);

        // 当枚举的位置超过本次跳跃的右边界，则 将end 更新到当前能够达到的右边界
        if (i === end) {
            ans++;
            end = right;
        }
    }

    return ans;
}

int jump(int* nums, int numsSize) {
    int n = numsSize;
    if (n <= 1) {
        return 0;
    }

    int ans = 0;
    // end 代表本次跳跃的右边界
    int end = 0;

    int right = 0;

            right = i + nums[i];

        if (i == end) {
            ans++;
            end = right;
        }
    }

}

## LeetCode 763. 划分字母区间

[在线刷题](https://codefun2000.com/p/P4088)

给你一个字符串 $s$ 。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。例如，字符串 "$ababcc$" 能够被分为 `["abab", "cc"]`，但类似 `["aba", "bcc"]` 或 `["ab", "ab", "cc"]` 的划分是非法的。

注意，划分结果需要满足：将所有划分结果按顺序连接，得到的字符串仍然是 $s$ 。

返回一个表示每个字符串片段的长度的列表。

**输入** 

```
ababcbacadefegdehijhklij
```

**输出** 

```
9 7 8
```

- $1 <= s.length <= 500$
- $s$仅由小写英文字母组成

**思路：贪心+双指针**

**重要性质**：当片段包含某个字符$x$ 时，需要至少包含到$x$**在字符串中最后出现的位置**

考虑从左往右计算第一个片段，$right$来表示这个片段至少要到达的位置。类似**跳跃游戏Ⅱ**的，根据每个遍历到的字符的最后一个位置来更新$right$，直到$i == right$ 的时候，一个新的片段才能结束。

int* partitionLabels(char* s, int* returnSize) {

    int last[26];
    int n = strlen(s);

    for (int i = 0; i < 26; i++) {
        last[i] = 0;
    }

### 面试问答

**1. 本题的思路是什么？**

贪心+双指针。先用哈希表计算出每一个字母的最后出现的位置，也就是代码中的$last$。然后从左往右枚举每一个位置$i$，再用指针$right$来表示当前片段至少要到达的位置 ， 不停的用$last[s[i]]$ 来更新$right$。直到$i == right$ 时就找到了一个新的片段。

时间复杂度:$O(n)$ , 所有指针单方向移动。
