## LeetCode 62. 不同路径

[在线刷题](https://codefun2000.com/p/P4033)

一个机器人位于一个 $m × n$网格的左上角 （起始点在下图中标记为 “$Start$” ）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 “$Finish$” ）。

问总共有多少条不同的路径？

![image-20260408111041914](https://codefun2000.com/p/2249/file/vRChJJgFbvuucwzt_Hn9q.png)

**输入** 

```
3 7
```

**输出** 

```
28
```

- $1 <= m, n <= 20$
- 题目数据保证答案小于等于 $2 * 10^9$

**思路**

问题模型：给定一个矩阵，从左上角出发走到右下角，每次从下或者从右移动 ， 询问方案数。

这类问题一个重要性质是：一个点不能多次访问，每次移动都是走到一个从未访问过的格子。所以可以使用动态规划来求解：

**1.问什么定义什么：**

状态：$dp_{i,j}$ 代表从$(1,1)$ 走到$(i,j)$  位置的不同路径个数。

**2.考虑最后一个元素的状态：**

$(i,j)$的上一步只有可能从$(i - 1 , j)$ 和  $(i , j - 1)$  来，则

$dp_{i,j} = dp_{i-1,j} + dp_{i,j-1}$

**边界条件：**

$dp_{1,1} = 1$ ， 因为从$(1,1)$ 留在原地就是一种方案。

**答案就是:$dp_{m,n}$**



**特别注意**：在代码实现的过程中(动画层面也有体现)，我们开到了$(n + 1) * (m + 1)$ 的矩阵，而不是$n * m$ 。这样以来，我们对于第一行和第一列的转移，不需要特判下标越界的情况。如果开$n * m$ , 我们还得判断$i == 0$ 时$dp[i][j] = dp[i][j - 1]$    ，这样代码就不够简洁了。

```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        # dp[i][j] 表示从左上角走到第 i 行第 j 列的不同路径数
        # 多开一行一列，让下标从 1 开始，避免第一行和第一列越界特判
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # 起点留在原地也是一种方案
        dp[1][1] = 1

        # 从左上到右下逐格计算
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 起点已经初始化，跳过
                if i == 1 and j == 1:
                    continue

                # 当前位置只能从上方或者左方走来
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1]

        # 右下角就是答案
        return dp[m][n]
```

## LeetCode 64. 最小路径和

[在线刷题](https://codefun2000.com/p/P4034)

给定一个包含非负整数的 $m× n$网格 $grid$ ，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

**说明**:每次只能向下或者向右移动一步。

**输入** 

```
3 3
1 3 1
1 5 1
4 2 1
```

**输出** 

```
7
```

- $m == grid.length$
- $n == grid[i].length$
- $1 <= m, n <= 200$
- $0 <= grid[i][j] <= 200$

**思路**

问题模型和上一题几乎一样。

**1.问什么定义什么：**

状态：$dp_{i,j}$ 代表从$(1,1)$ 走到$(i,j)$ 位置的最小数字总和

**2.考虑最后一个元素的状态：**

$(i,j)$的上一步只有可能从$(i - 1 , j)$ 和  $(i , j - 1)$  来，则

$dp_{i,j} = min (dp_{i-1,j} , dp_{i,j-1}) + a_{i,j}$

答案就是:$dp_{m,n}$
#code-switcher
```python
class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        m = len(grid)
        n = len(grid[0])

        # 这里开 m + 1 和 n + 1，是为了让下标从 1 开始，方便统一转移
        dp = [[float('inf')] * (n + 1) for _ in range(m + 1)]

        # 起点左边人为设置为 0，这样 dp[1][1] 可以通过统一公式算出来
        dp[0][1] = 0

        # 从左上角开始，逐格计算到每个位置的最小路径和
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 当前位置只能从上方或者左方走来，取较小值再加上当前格子的数字
                dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i - 1][j - 1]

        # 右下角就是最终答案
        return dp[m][n]
```

## LeetCode 5. 最长回文子串

[在线刷题](https://codefun2000.com/p/P4098)

给定一个字符串 `s`，找到 `s` 中最长的回文子串。

**输入**

```
babad
```

**输出**

```
bab
```

- `s` 仅由 **数字** 和 **英文字母** 组成。  
- `s` 至少包含 **1 个字符**。  
- 若存在多个答案，返回 **任意一个**。

**思路：动态规划优化枚举**

一个朴素的算法是：$O(n^2)$ 枚举所有子串，然后$O(n)$的判断这个子串是否是回文串，总复杂度$O(n^3)$
#code-switcher
```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        # 判断 s[left:right] 这一段是否是回文串
        def is_palindrome(left, right):
            # 从两端向中间判断字符是否相等
            while left < right:
                if s[left] != s[right]:
                    return False
                left += 1
                right -= 1
            return True

        n = len(s)
        # 记录最长回文子串长度
        ans = 0
        # 记录最长回文子串
        res = ""

        # 枚举所有子串的起点
        for i in range(n):
            # 枚举所有子串的终点
            for j in range(i, n):
                # 判断当前子串是否是回文串
                if is_palindrome(i, j):
                    length = j - i + 1
                    # 如果当前回文子串更长，则更新答案
                    if length > ans:
                        ans = length
                        res = s[i:j + 1]

        return res
```

```cpp
class Solution {

    bool isPalindrome(string& s, int left, int right) {
        // 从两端向中间判断字符是否相等

            if (s[left] != s[right]) {
                return false;
            }
            left++;
            right--;
        }

                        ans = length;

                    }
                }
            }
```

考虑判断一个字符串是不是回文串，可以拆成子问题：

**一个字符串是回文串，等价于 内部是回文串 + 两个端点的字符相等👇**

![](/file/2/WJecuPb56Yjx28T1ez2gF.png)



而`内部是否是回文串` 和原问题结构是相似的，可以使用动态规划解决

定义状态:$dp_{i,j}$ 代表子串$s[i:j]$是否是回文字符串。

转移:$dp_{i,j} = dp_{i+1,j-1}\ \&\&\ [s[i]\ ==\ s[j]]$ 

**这里给一个具体的例子来理解 状态  ， 转移 和 字符串之间到底是怎么对应上的👇**

![](/file/2/wL-QF8qEKs1ijHfjqpVH-.png)

这个问题在[背包模型](https://codefun2000.com/codenote/hot100/P0027)里有过探讨。核心关键就是将$dp$ 看成数组，看它的转移涉及到哪些格子。要么按行转移，要么按列转移。这里我们看一个图示👇

![](/file/2/0-wSGFd3UoLx986hufE4x.png)


从图上我们可以发现，**01背包那种从上到下的按行转移失效了** 。 因为从数组层面看，**我们需要每个数的左下角先算出来**，所以应当从最后一行，按行 **从下往上的 计算**。

![](/file/2/kWEoMq6YFHd6n4NPSTLLr.png)


**从枚举的角度理解**，就是左端点$i$从后往前枚举，$j$从$i\rightarrow n$ 去枚举。如此以来，子问题会在之前就被算出来，这样才能正确的转移。

**边界条件:**

1.任意字符$x$本身就是回文串 ： $dp_{i,i} = True$  

2.任意空字符串都是回文串：$dp_{i,i-1} = True$  



现在我们看一段动画，针对$abcbca$这个样例 , $dp$值到底是怎么被计算出来的。

注意在代码求解中，所有的$dp[i][j] , i > j$ 的位置都是不会被计算的，因为这种状态本身就不合法（左端点在右端点的右边...） ，**所以只更新上三角区域**。

现在我们用$O(n^2)$ 的时间计算出了$dp_{i,j}$ ， 这意味着，对于任意一个子串$s[i:j]$ , 我们可以在$O(1)$ 时间内判断它是否是回文串。

那么我们可以再使用$O(n^2)$ 的时间双重循环枚举所有子串，如果是回文子串，则更新答案长度。

这个时候，复杂度就从原先的$O(n^3)$ ， 被我们用动态规划提前预处理，优化掉了第三层循环，复杂度降低至$O(n^2)$

```python id="x7nv4p"
class Solution:
    def longestPalindrome(self, s: str) -> str:
        """ 使用动态规划找到最长回文子串 """
        n = len(s)
        if n == 0:
            return ""

        # 初始化 DP 数组，dp[i][j] 表示 s[i:j+1] 是否是回文
        dp = [[False] * n for _ in range(n)]

        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                if i == j:
                    dp[i][j] = True  # 单个字符是回文
                    continue

                # 如果两端相等，再看内部是否是回文
                if s[i] == s[j]:
                    if i == j - 1:  # 内部是空串
                        dp[i][j] = True
                    else:
                        dp[i][j] = dp[i + 1][j - 1]

        # 和暴力循环唯一的不同，就是使用 DP 数组来判断是否是回文串，避免了重复计算，提高效率
        ans = 0
        res = ""

        for i in range(n):
            for j in range(i, n):
                if dp[i][j]:
                    length = j - i + 1
                    if length > ans:
                        ans = length
                        res = s[i:j + 1]

        return res
```

### 面试问答

**1. 本题的核心思路是什么**

先用动态规划预处理出数组$dp_{i,j}$ 来判断字符串$s[i:j]$ 是否是回文串。然后用两层循环枚举所有子字符串，利用$dp$数组快速判断回文串，如果是回文串则更新答案长度，记录对应子字符串即可。

时间复杂度为$O(n^2)$ ，预处理动态规划数组为$n^2$次计算，枚举子字符串为$n^2$次计算。空间复杂度为$O(n^2)$

## LeetCode 1143. 最长公共子序列

[在线刷题](https://codefun2000.com/p/P4099)

给定两个字符串 `text1` 和 `text2`，返回这两个字符串的 **最长公共子序列** 的长度。如果不存在公共子序列，则返回 `0`。

**定义：**

- **子序列**：从原字符串中删除 **某些字符（可不删除）**，但不改变剩余字符的 **相对顺序**，得到的新字符串。
- **公共子序列**：两个字符串都包含的 **子序列**。

**输入**

```
abcde
ace
```

**输出**

```
3
```

**思路**

先想清楚一个问题：找公共子序列，其实可以把他看作：

从text1中删除若干个字符，再从text2中删除若干个字符，要求剩下的字符所形成的字符串恰好相等，且长度最长👇

![](/file/2/Hr351QppgV0UCP25n-hvC.png)


**从整体(递归)的视角看**

不妨拿这两个字符串末尾的字符进行考虑

![](/file/2/uCLtebFm6beq94447NBwt.png)

情况1：如果两个字符相等，则自然的进行匹配，答案长度 + 1

情况2：如果两个字符不等，那在最后的结果中，**这两个字符一定要删掉一个,不然不可能完全相等**。删除两个中的哪一个字符




在这个过程中我们发现，只要我们每次是考虑字符串末尾的字符，那么所有局面都符合同一个性质：

#warning-box
**性质**：任意局面下第一行字符串一定是`text1` 的一个前缀，第二行字符串一定是`text2` 的一个前缀。
#warning-box

而且本问题涉及到两个字符串，自然定义二维状态，而不是一维状态。

**状态**：$dp_{i,j}$ 代表 考虑了 **$text1$的前$i$个字符**  与 **$text2$的前$j$个字符** 的情况下，最长公共子序列长度。

**为了让大家进一步理解这个状态的含义，我们再给几个例子来说明**👇

![](/file/2/lsoGY1JiYxJsbl56m2ng3.png)



**转移:**

**对于情况1：尾部恰好相等的情况**
贪心：这种情况下，直接匹配一定是最优解。

$dp_{i - 1,j - 1} + 1 \rightarrow dp_{i , j}$

**有的同学可能没想明白，为什么相等就非得匹配，我不匹配行不行啊？**

![](/file/2/Mwb2bgZJ-gYGAOW-1i14G.png)


**说明**：现在末尾的两个`e`可以直接匹配，但是我们强行删除第一行的这个`e` ，此时留下来的这个`e`要去前面匹配其他的`e`,导致本来前面可以匹配成功的一对`e`匹配失败，**这样局面被我们搞得更差了**。

换句话说，如果一个字符能够匹配多个位置，贪心的匹配最后一个位置是最优的，这样可以给前面的其他字符更自由的去匹配。

![](/file/2/hQpJioiQWfh2PW8lrSMgy.png)


**case2:尾部不等**：

在第二张图的例子中，将两个e匹配完成后，我们发现尾部`d`和`c`并不相等。

此时有两种决策：要么将$d$删掉，要么将$c$删掉。

这样就分成两个子问题，这两个子问题的结构和原问题是相似的，我们可以从这两个子问题中选一个最大的情况。

$max(dp_{i - 1 , j} , dp_{i , j - 1}) \rightarrow dp_{i , j}$

**注意: 这种情况下没有字符被成功匹配，答案不会`+1`**

**答案**： $dp_{m,n}$  , 其中$m$是`text1`的长度,$n$是`text2`的长度。

**边界条件**：

1.$dp_{i,0} = 0 , i \in [0 , m]$

2.$dp_{0,i} = 0 , i \in [1 , n]$

3.$dp_{0 , 0} = 0$

**如下图所示👇**

![](/file/2/u0vDm96QZjTz1eh4W-ZGf.png)

在代码实现中，我们将整个数组都初始化为$0$ ，这样边界条件自然也就被满足了。

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m = len(text1)
        n = len(text2)

        # dp[i][j] 表示 text1 前 i 个字符和 text2 前 j 个字符的最长公共子序列长度
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # 按照前缀长度从小到大计算
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 如果两个前缀的最后一个字符相等，可以直接匹配，答案加 1
                if text1[i - 1] == text2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    # 如果最后一个字符不相等，就删掉其中一个字符，取更优结果
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

        # 最终答案是两个完整字符串的最长公共子序列长度
        return dp[m][n]
```

```c
int longestCommonSubsequence(char* text1, char* text2) {
    int m = strlen(text1);
    int n = strlen(text2);

    // dp[i][j] 表示 text1 前 i 个字符和 text2 前 j 个字符的最长公共子序列长度
    int total = (m + 1) * (n + 1);
    int* dp = (int*)malloc(sizeof(int) * total);

    // 初始化为 0，表示空串和任意字符串的最长公共子序列长度都是 0
    for (int i = 0; i < total; i++) {
        dp[i] = 0;
    }

    // 按照前缀长度从小到大计算
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            int cur = i * (n + 1) + j;

            // 如果两个前缀的最后一个字符相等，可以直接匹配，答案加 1
            if (text1[i - 1] == text2[j - 1]) {
                dp[cur] = dp[(i - 1) * (n + 1) + (j - 1)] + 1;
            } else {
                // 如果最后一个字符不相等，就删掉其中一个字符，取更优结果
                int a = dp[(i - 1) * (n + 1) + j];
                int b = dp[i * (n + 1) + (j - 1)];
                dp[cur] = a > b ? a : b;
            }
        }
    }

    int ans = dp[m * (n + 1) + n];
```

**说明**

**插入** 一个字符:

在`word1[:i]`的末尾添加一个`word2[j]` ，使得`word2[j]`得到匹配。

$dp_{i , j - 1} + 1 \rightarrow dp_{i , j}$


**删除** 一个字符:

删掉`word1[i]` ,让子问题去匹配

$dp_{i - 1, j} + 1 \rightarrow dp_{i , j}$

**替换** 一个字符  

替换`word1[i] = word2[j]`

$dp_{i - 1, j - 1} + 1 \rightarrow dp_{i , j}$

三种情况取最小值即可：

$dp_{i,j} = min(dp_{i - 1 , j - 1} , dp_{i - 1 , j} , dp_{i , j - 1}) + 1$

**边界条件**:

$dp_{i,0} = i$ （将`word1[:i]`变为空字符串需要`i`次）
$dp_{0,j} = j$ （将空字符串变为 `word2[j]`，需要 `j` 次插入）

答案:$dp_{n , m}$

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        # 获取两个字符串的长度
        m = len(word1)
        n = len(word2)

        # dp[i][j] 表示 word1 前 i 个字符转换成 word2 前 j 个字符的最少操作数
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # word1 前 i 个字符转换为空字符串，需要删除 i 次
        for i in range(m + 1):
            dp[i][0] = i

        # 空字符串转换成 word2 前 j 个字符，需要插入 j 次
        for j in range(n + 1):
            dp[0][j] = j

        # 逐行计算每个状态
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 如果两个末尾字符相同，直接匹配，不需要额外操作
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1]
```
