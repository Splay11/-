### 思路:枚举+相向双指针

**本题整体的思路是：先排序，然后枚举三个下标中的某一个下标，剩下的两个下标由相向双指针确定。**

**枚举**：本题枚举$i,j,k$任意一个下标都可以得到正确的答案，这里固定$i$，

外层循环枚举$i$ ，接着需要在$[i+1,n]$ 这个范围里找两个下标$j,k$使得$num[j]+num[k]=-num[i]$ 。

**双指针**：根据上一个小节我们所学习到的双指针技巧，不难想到一种相向双指针算法:令$j=i+1,k=n$

**一句话概括**：当$num[j]+num[k] < -num[i]$ 时, $j += 1$ ， 反之$k -= 1$ 。

思想：当总和小于目标值$-num[i]$ 时，需要移动左指针让总和变大，反之移动右指针让总和变小。

注意：数组可能有重复数字，遍历过程中忽略重复的$num[i]$

```python id="p2xg8h"
from typing import List


class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        # 获取数组长度
        n = len(nums)
        
        # 先排序，方便后面使用相向双指针
        nums.sort()
        
        # 用来保存所有不重复的三元组
        ans = []
        
        # 枚举第一个数
        for i in range(n):
            # 如果 nums[i] 和前一个数相同，说明会得到重复答案，直接跳过
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            
            # 在区间 [i + 1, n - 1] 内用相向双指针寻找另外两个数
            j, k = i + 1, n - 1
            
            while j < k:
                # 计算当前三数之和
                s = nums[i] + nums[j] + nums[k]
                
                if s == 0:
                    # 找到一组三元组
                    ans.append([nums[i], nums[j], nums[k]])
                    
                    # 左右指针同时收缩，继续寻找下一组
                    j += 1
                    k -= 1
                    
                    # 跳过重复的 nums[j]
                    while j < k and nums[j] == nums[j - 1]:
                        j += 1
                    
                    # 跳过重复的 nums[k]
                    while j < k and nums[k] == nums[k + 1]:
                        k -= 1
                
                elif s < 0:
                    # 和太小，需要让总和变大
                    j += 1
                else:
                    # 和太大，需要让总和变小
                    k -= 1
        
        return ans
```

```go id="z0b6rk"
	// 获取数组长度
	n := len(nums)

	// 先排序，方便后面使用相向双指针
	sort.Ints(nums)

	// 用来保存所有不重复的三元组
```

```c
#include <stdlib.h>

static int cmp(const void* a, const void* b) {
    return (*(int*)a) - (*(int*)b);
}

int** threeSum(
    int* nums,
    int numsSize,
    int* returnSize,
    int** returnColumnSizes
) {
    // 初始化返回结果
    *returnSize = 0;
    
    int capacity = 16;
    int** ans = (int**)malloc(sizeof(int*) * capacity);
    *returnColumnSizes = (int*)malloc(sizeof(int) * capacity);
    
    // 先排序，方便后面使用相向双指针
    qsort(nums, numsSize, sizeof(int), cmp);
    
    // 枚举第一个数
    for (int i = 0; i < numsSize; i++) {
        // 如果 nums[i] 和前一个数相同，说明会得到重复答案，直接跳过
        if (i > 0 && nums[i] == nums[i - 1]) {
            continue;
        }
        
        // 在区间 [i + 1, numsSize - 1] 内用相向双指针寻找另外两个数
        int j = i + 1;
        int k = numsSize - 1;
        
        while (j < k) {
            long long sum = (long long)nums[i] + nums[j] + nums[k];
            
            if (sum == 0) {
                // 扩容
                if (*returnSize == capacity) {
                    capacity *= 2;
                    ans = (int**)realloc(ans, sizeof(int*) * capacity);
                    *returnColumnSizes = (int*)realloc(
                        *returnColumnSizes,
                        sizeof(int) * capacity
                    );
                }
                
                // 保存一组三元组
                ans[*returnSize] = (int*)malloc(sizeof(int) * 3);
                ans[*returnSize][0] = nums[i];
                ans[*returnSize][1] = nums[j];
                ans[*returnSize][2] = nums[k];
                (*returnColumnSizes)[*returnSize] = 3;
                (*returnSize)++;
                
                // 左右指针同时收缩，继续寻找下一组
                j++;
                k--;
                
                // 跳过重复的 nums[j]
                while (j < k && nums[j] == nums[j - 1]) {
                    j++;
                }
                
                // 跳过重复的 nums[k]
                while (j < k && nums[k] == nums[k + 1]) {
                    k--;
                }
            } else if (sum < 0) {
                // 和太小，需要让总和变大
                j++;
            } else {
                // 和太大，需要让总和变小
                k--;
            }
        }
    }
    
    return ans;
}
```

### 面试问答

**1.这道题的整体思路是什么？**

这道题的整体思路是：**先排序，再枚举一个数，把问题转化成有序数组中的两数之和问题，最后用相向双指针解决。**

**2.这道题双指针背后的思想/为什么双指针是对的？**

双指针之所以正确，是因为排序+枚举后，左指针右移会使和变大，右指针左移会使和变小，搜索具有单调性。

**3.这道题的时间复杂度是多少？**

时间复杂度是$O(n^2)$ ，外层循环枚举$i$ 有$n$ 次， 内层循环的双指针$j,k$相对着移动，总移动量有$n$次。根据分步相乘的思想，复杂度是$O(n \times n) = O(n^2)$

**4.除了双指针的做法，还有没有别的做法？**

有，比较直接的替代做法是：**枚举一个数后，用哈希表做两数之和。** 具体请见哈希章节中的

该做法的时间复杂度一样，但空间复杂度稍微差一些，因为哈希表需要开辟空间，额外占用$O(n)$的空间
