**思路**

从二维网格中的每个单元格出发，作为搜索单词的起点进行递归搜索。

**递归搜索**：从当前单元格开始搜索，判断该位置是否与单词对应字符匹配。如果匹配，则继续向上、下、左、右四个方向搜索下一个字符。

**减枝操作：**

搜索时需要时刻保证以下条件：

- 当前坐标在网格范围内；
- 当前单元格字符与单词当前位置字符一致；
- 同一单元格在一个搜索路径中只使用一次（因此需要标记已访问的单元格）。

**回溯处理:**
在搜索过程中，若某一路径无法匹配完整单词，则回溯并恢复现场，尝试其它路径。

**终止条件(递归出口):**

当搜索的索引等于单词长度时，说明整个单词已经成功匹配，返回 true；若所有起点均未匹配成功，则返回 false。

```python
class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        rows = len(board)
        cols = len(board[0])
        used = [[False] * cols for _ in range(rows)]

        # 四个方向：右、下、左、上
        dx = [0, 1, 0, -1]
        dy = [1, 0, -1, 0]

        def dfs(x, y, k):
            # 如果已经匹配完整个单词，说明搜索成功
            if k == len(word):
                return True

            # 剪枝：坐标越界，直接失败
            if x < 0 or x >= rows or y < 0 or y >= cols:
                return False

            # 剪枝：同一条路径中不能重复使用同一个单元格
            if used[x][y]:
                return False

            # 剪枝：当前字符不匹配，直接失败
            if board[x][y] != word[k]:
                return False

            # 标记当前单元格已经使用
            used[x][y] = True

            # 向上下左右四个方向继续搜索下一个字符
            for d in range(4):
                newx = x + dx[d]
                newy = y + dy[d]
                if dfs(newx, newy, k + 1):
                    return True

            # 回溯，恢复当前单元格状态
            used[x][y] = False
            return False

        # 枚举每个单元格作为搜索起点
        for i in range(rows):
            for j in range(cols):
                if dfs(i, j, 0):
                    return True

        return False
```

```c
bool dfs(char** board, int boardSize, int* boardColSize, char* word, int x, int y, int k) {
    // 如果已经匹配完 word，说明整条路径匹配成功
    if (word[k] == '\0') {
        return true;
    }

    // 越界，直接返回 false
    if (x < 0 || x >= boardSize || y < 0 || y >= boardColSize[x]) {
        return false;
    }

    // 当前单元格已经访问过，或者字符不匹配，直接返回 false
    if (board[x][y] == '#' || board[x][y] != word[k]) {
        return false;
    }

    // 临时标记当前格子已经访问，避免同一路径中重复使用
    char temp = board[x][y];
    board[x][y] = '#';

    // 向上、下、左、右四个方向继续搜索下一个字符
    bool ok = dfs(board, boardSize, boardColSize, word, x + 1, y, k + 1) ||
              dfs(board, boardSize, boardColSize, word, x - 1, y, k + 1) ||
              dfs(board, boardSize, boardColSize, word, x, y + 1, k + 1) ||
              dfs(board, boardSize, boardColSize, word, x, y - 1, k + 1);

    // 回溯，恢复当前格子字符，方便其它路径继续使用
    board[x][y] = temp;

    return ok;
}

bool exist(char** board, int boardSize, int* boardColSize, char* word) {
    // 枚举每个单元格作为搜索起点
    for (int i = 0; i < boardSize; i++) {
        for (int j = 0; j < boardColSize[i]; j++) {
            // 如果从当前起点可以匹配完整单词，直接返回 true
            if (dfs(board, boardSize, boardColSize, word, i, j, 0)) {
                return true;
            }
        }
    }

    // 所有起点都无法匹配，返回 false
    return false;
}
```

**面试问答**

**1. 本题的核心思路是什么？**
 

思路:**枚举起点 + 回溯搜索**。先遍历每一个格子，把它当作单词第一个字符的起点。如果当前格子和 `word[0]` 匹配，就继续从这个位置向上下左右四个方向搜索下一个字符。递归参数记录当前所在位置`x,y`以及已经匹配到的位置`k`。搜索过程中需要保证三个条件：坐标不能越界、当前字符要和 `word[k]` 一致、同一个格子在当前路径中不能重复使用。

为了避免重复使用格子，用 `used` 数组标记当前路径中已经走过的位置。进入某个格子后先标记为已访问，然后递归搜索四个方向；如果这条路径走不通，就回溯，把这个格子恢复成未访问，继续尝试其他方向。只要某一次搜索成功匹配到单词最后一个字符，就说明答案存在，可以用 `ok = True` 记录结果并提前结束搜索。
