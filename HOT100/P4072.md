**前置知识：如何判断一个括号序列合法？**

考虑将`(` 视作 `1` , `)` 视作 `-1`  ，这样一对括号的匹配可以被视作`1-1 = 0` 

那么满足以下**两个条件**，这个括号序列就是合法的：

1.**整体角度**：整个序列的总和需要是`0` ，不然就代表左右括号个数不一致，**这样不管内部实际是什么顺序，都不可能匹配的。**

2.从左往右累加`cnt` 的过程中，任意时刻需要满足`cnt >= 0`  。 **因为如果`cnt < 0` 就代表此刻前缀中右括号多于左括号，那不管后续括号是什么状态，这个多出来的右括号都不可能得到匹配了。**

例如:`(()))...` ,  扫描到第5个位置，此时$cnt = -1$  ，  代表第五个位置的右括号没有得到匹配。

**思路**

$n$对括号，代表总长度为$2n$。

一个最简单的思路是直接递归搜索这$2n$个位置的括号状态，在递归出口`index == 2 * n`的时候判断整个括号的合法性。

每个位置可以填两种括号 ， 复杂度为$0(2^{2n} * n)$

```python
class Solution:
    def generateParenthesis(self, n):
        # res 存放所有合法的括号组合
        res = []
        # curr 表示当前正在构造的括号序列
        curr = []

        # 判断当前括号序列是否合法
        def check(path):
            cnt = 0
            for ch in path:
                if ch == '(':
                    cnt += 1
                else:
                    cnt -= 1

                # 如果某个前缀中右括号数量超过左括号，说明不合法
                if cnt < 0:
                    return False

            # 最后左右括号数量相等才合法
            return cnt == 0

        def dfs(index):
            # 当长度达到 2 * n 时，说明生成了一个完整的括号序列
            if index == 2 * n:
                # 只有合法序列才加入答案
                if check(curr):
                    res.append("".join(curr))
                return

            # 当前这一位选择左括号
            curr.append('(')
            dfs(index + 1)
            curr.pop()

            # 当前这一位选择右括号
            curr.append(')')
            dfs(index + 1)
            curr.pop()

        dfs(0)
        return res
```

```cpp
class Solution {
public:
    vector<string> res;
    vector<char> curr;
    int m;

    bool check(vector<char>& path) {
        int cnt = 0;

        for (char ch : path) {
            if (ch == '(') {
                cnt++;
            } else {
                cnt--;
            }

            // 如果某个前缀中右括号数量超过左括号，说明不合法
            if (cnt < 0) {
                return false;
            }
        }

        // 最后左右括号数量相等才合法
        return cnt == 0;
    }

    void dfs(int index) {
        // 当长度达到 2 * n 时，说明生成了一个完整的括号序列
        if (index == 2 * m) {
            // 只有合法序列才加入答案
            if (check(curr)) {
                res.push_back(string(curr.begin(), curr.end()));
            }
            return;
        }

        // 当前这一位选择左括号
        curr.push_back('(');
        dfs(index + 1);
        curr.pop_back();

        // 当前这一位选择右括号
        curr.push_back(')');
        dfs(index + 1);
        curr.pop_back();
    }

    vector<string> generateParenthesis(int n) {
        res.clear();
        curr.clear();
        m = n;

        dfs(0);
        return res;
    }
};
```

```c
void dfs(int index, int n, char* curr, char** res, int* returnSize) {
    // 当长度达到 2 * n 时，说明生成了一个完整的括号序列
    if (index == 2 * n) {
        // 只有合法序列才加入答案
        if (check(curr, 2 * n)) {
            char* str = (char*)malloc(sizeof(char) * (2 * n + 1));
            for (int i = 0; i < 2 * n; i++) {
                str[i] = curr[i];
            }
            str[2 * n] = '\0';
            res[*returnSize] = str;
            (*returnSize)++;
        }
        return;

    curr[index] = '(';
    dfs(index + 1, n, curr, res, returnSize);

    // 当前这一位选择右括号
    curr[index] = ')';
    dfs(index + 1, n, curr, res, returnSize);
}
```

**剪枝优化**

回顾我们的前置知识不难发现，其实在递归生成的过程中，一旦当前的生成不合法，我们没必要继续递归了。

比如:`curr = ())???`  ， 生成出来的前缀已经不合法的情况下，往后再怎么填写括号，到递归出口时都一定被判不合法。

所以其实上述代码有大量的无意义计算！**而优化很简单，考虑在`dfs`的过程中，边生成边保证当前括号状态合法。**

具体的：`dfs`的过程中，维护一个参数`cnt` 代表当前生成的括号序列的总和，**通过`cnt`的大小限制递归与判断合法性。**

1.限制递归：当`cnt == 0` 时只能生成`(`  

2.递归出口`index == 2 * n`时，当`cnt == 0` 时才能统计答案。

**这样以来，`check`函数被我们消融到`dfs`函数的过程中，同时还减少了大量计算**

```python
class Solution:
    def generateParenthesis(self, n):
        # res 用于存放所有有效的括号组合
        res = []
        # curr 表示当前正在构造的括号序列
        curr = []

        def dfs(index, cnt):
            # 如果已经构造了 2 * n 个字符
            if index == 2 * n:
                # 只有未匹配的左括号数量为 0，才是合法括号序列
                if cnt == 0:
                    res.append("".join(curr))
                return

            # 添加左括号，未匹配的左括号数量加 1
            curr.append("(")
            dfs(index + 1, cnt + 1)
            curr.pop()

            # 只有当前存在未匹配的左括号时，才可以添加右括号
            if cnt > 0:
                curr.append(")")
                dfs(index + 1, cnt - 1)
                curr.pop()

        # 从第 0 个位置开始搜索，初始未匹配左括号数量为 0
        dfs(0, 0)
        return res
```

**面试问答**

**1. 本题的核心思路是什么？**

**回溯**。我们从左到右递归生成长度为 `2n` 的括号序列，每个位置都可以尝试放左括号或右括号。递归过程中，用 `cnt` 记录当前左括号比右括号多多少个，也就是当前还未匹配的左括号数量；如果 `cnt == 0`，说明当前不能再放右括号，只能放左括号。等递归到长度 `2n` 时，只有 `cnt == 0` 的序列才是合法答案。时间复杂度是 $O(2^{2n} × n)$，空间复杂度是 **O(n)**。



ps:严谨来讲，有效答案数是卡特兰数: $C_n = \frac{1}{n+1}\binom{2n}{n}$ ，  所以复杂度是$O(\frac{n}{n+1}\binom{2n}{n})$，不过这个面试基本不会问的。 按上面的回答也不会错。因为大$O$标志描述的是复杂度上界。只是$2^n \times n$ 不够贴近算法真实上界。

说人话就是：$1 \leq 2$ 和 $1 \leq 10$ 都是对，显然前者描述更准确一些，但后者也不能算错啊。
