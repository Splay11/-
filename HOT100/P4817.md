**思路:枚举2 + 贪心 + 单调栈**

"132"模式中，`2`是三个数里最靠右的，考虑从左往右枚举`2`，回头看前缀区域去找`13` :

先不考虑`1`的限制，当我们枚举到某个`2`的时候，考虑左侧有若干个`3` ，如下图所示👇

![](/file/2/XZV48YjNnxEDrT-Z4qN5K.png)


此时我们应该选哪个`3`才**最有可能**满足132条件？  

这里有些同学可能会想不明白，觉得我们选最大的那个`3`才行，但其实不然。

我们先选图中最大的那个`3`试试看👇

![](/file/2/eRF3yaQj7idN3vVlLJii2.png)


说明：选定`32`后我们发现，`1`要从`3`的左侧选的。又因为`1`是三个数里的最小值，所以贪心的思考，一定是去选`3`左侧最小的元素（即前缀最小值）。因为选出来的`1`越小，越容易满足`132`模式。

所以对于这些`3`，一定是选最靠右的位置。只有这样才能让`1`的选择范围尽可能大👇

![](/file/2/YHADS22oAB4aE2p9dDn6c.png)

#warning-box 

**补充说明**: 有些同学可能有疑问，我选靠右侧的`3` ， 这样`3`有可能变小了呀。

**但是其实这个地方的瓶颈不在`3`而是`2`**。因为我们不管选哪个`3`，都比当前的`2`要大。所以选最靠右的`3`，是为了找到一个数去比`2`更小，跟`3`多大是不搭嘎的。

#warning-box 


所以如何得到`2`左侧第一个比`2`大的`3`？单调栈即可。 找到之后，再考虑`3`之前的前缀最小值`min` , 如果`min < 2`，则满足132条件。

到这里做法就很显然了：

1.先预处理一遍前缀最小值，用于后续方便选出`1`。

2.从左到右枚举`2`,同时维护一个单调栈，对于每个`2`，贪心的考虑左侧第一个比`2`大的`3`。如果`3`对应位置的前缀最小值`min` < `2`，则满足132条件。

整个算法结束，如果没有满足132条件的`2`，则返回`false`。

```python id="v5ex1p"
class Solution:
    def find132pattern(self, nums: List[int]) -> bool:
        # 单调栈，维护可能作为 nums[j] 的元素
        stack = []

        # third 表示当前找到的 nums[k]
        # 也就是 132 模式中的 “2”
        third = float("-inf")

        # 从右往左枚举 nums[i]
        for i in range(len(nums) - 1, -1, -1):
            # 如果 nums[i] < third，说明找到了 nums[i] < nums[k] < nums[j]
            if nums[i] < third:
                return True

            # 如果当前 nums[i] 比栈顶大
            # 那么栈顶可以作为 nums[k]，当前 nums[i] 可以作为 nums[j]
            while stack and nums[i] > stack[-1]:
                third = stack.pop()

            # 当前元素入栈，作为后续可能的 nums[j]
            stack.append(nums[i])

        return False
```

```cpp id="z1tkv9"
class Solution {
public:
    bool find132pattern(vector<int>& nums) {
        // 单调栈，维护可能作为 nums[j] 的元素
        vector<int> stack;

        // third 表示当前找到的 nums[k]
        // 也就是 132 模式中的 “2”
        int third = INT_MIN;

        // 从右往左枚举 nums[i]
        for (int i = nums.size() - 1; i >= 0; i--) {
            // 如果 nums[i] < third，说明找到了 nums[i] < nums[k] < nums[j]
            if (nums[i] < third) {
                return true;
            }

            // 如果当前 nums[i] 比栈顶大
            // 那么栈顶可以作为 nums[k]，当前 nums[i] 可以作为 nums[j]
            while (!stack.empty() && nums[i] > stack.back()) {
                third = stack.back();
                stack.pop_back();
            }

            // 当前元素入栈，作为后续可能的 nums[j]
            stack.push_back(nums[i]);
        }

        return false;
    }
};
```

```go id="utt94g"
func find132pattern(nums []int) bool {
    // 单调栈，维护可能作为 nums[j] 的元素
    stack := []int{}

    // third 表示当前找到的 nums[k]
    // 也就是 132 模式中的 “2”
    third := -1 << 31

    // 从右往左枚举 nums[i]
    for i := len(nums) - 1; i >= 0; i-- {
        // 如果 nums[i] < third，说明找到了 nums[i] < nums[k] < nums[j]
        if nums[i] < third {
            return true
        }

        // 如果当前 nums[i] 比栈顶大
        // 那么栈顶可以作为 nums[k]，当前 nums[i] 可以作为 nums[j]
        for len(stack) > 0 && nums[i] > stack[len(stack)-1] {
            third = stack[len(stack)-1]
            stack = stack[:len(stack)-1]
        }

        stack = append(stack, nums[i])
    }

    return false
}
```

```c id="tx6l67"
bool find132pattern(int* nums, int numsSize) {
    // 单调栈，维护可能作为 nums[j] 的元素
    int* stack = (int*)malloc(sizeof(int) * numsSize);
    int top = 0;

    // third 表示当前找到的 nums[k]
    // 也就是 132 模式中的 “2”
    int third = INT_MIN;

    // 从右往左枚举 nums[i]
    for (int i = numsSize - 1; i >= 0; i--) {
        // 如果 nums[i] < third，说明找到了 nums[i] < nums[k] < nums[j]
        if (nums[i] < third) {
            free(stack);
            return true;
        }

        // 如果当前 nums[i] 比栈顶大
        // 那么栈顶可以作为 nums[k]，当前 nums[i] 可以作为 nums[j]
        while (top > 0 && nums[i] > stack[top - 1]) {
            third = stack[--top];
        }

        // 当前元素入栈，作为后续可能的 nums[j]
        stack[top++] = nums[i];
    }

    free(stack);
    return false;
}
```

一句话总结：枚举`2`,用单调栈找`3`，再用前缀最小值找`1`

**面试问答**

**本题是什么思路？**

考虑枚举`2`,用单调栈去找左侧离`2`最近的`3`,再通过预处理出来的前缀最小值去找`1`。这样一定是最优的，因为离`2`最近的`3`意味着我们最大化了`1`的寻找范围，然后找前缀最小值也是为了最可能满足`132`的`1`。

时间复杂度：O(n) , 每个元素枚举一次，单调栈最多进去n次，出去n次，前缀最小值预处理是n次
空间复杂度：O(n) ， 开销来源于单调栈和前缀最小值数组
