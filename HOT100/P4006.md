#### 思路

**做这道题前，先搞懂上一题。**

考虑得到每个柱子上面能存储的雨水高度，累加这些高度即可👇

![](/file/2/wlvTwDCsNc6Ky2IBLHvQ9.png)

而每个柱子上面能存储的雨水高度，取决于它左侧最高柱子以及它右侧最高柱子的高度之间的最小值👇
![](/file/2/mZ7eRsVyvotSvnDxVoUvQ.png)

基于上一题的双指针做法，我们在这个过程中，动态维护一个变量$left\_max$ 和  $right\_max$ 分别代表此刻左指针$i$之前和右指针$j$之后的最大高度。

在向中间逼近的过程中，依旧是让更短的柱子那边的指针往中间走。指针在移动之前将它所指向的柱子的答案计算累加即可，这样指针相遇的时候每一个柱子都会被计算到。

```python
from typing import List


class Solution:
    def trap(self, height: List[int]) -> int:
        # 获取数组长度
        n = len(height)
        
        # 双指针，分别指向最左端和最右端
        i, j = 0, n - 1
        
        # left_max 表示左侧目前最高柱子，right_max 表示右侧目前最高柱子
        left_max, right_max = 0, 0
        
        # 记录最终接到的雨水总量
        ans = 0
        
        while i < j:
            # 先更新左右两侧的最高柱子
            left_max = max(left_max, height[i])
            right_max = max(right_max, height[j])
            
            # 哪边更矮，就先结算哪边
            if height[i] < height[j]:
                # 左边这一格能接的水量 = 左侧最高柱子 - 当前柱子高度
                ans += left_max - height[i]
                i += 1
            else:
                # 右边这一格能接的水量 = 右侧最高柱子 - 当前柱子高度
                ans += right_max - height[j]
                j -= 1
        
        return ans
```

#code-switcher

**为什么这样移动双指针是对的？**

观察一下：某一位置能接的雨水量是：$ans_i=min(left\_max_i,right\_max_i)−当前位置高度$

这里的唯一问题是我们还无法确定哪边更短，但一旦我们知道当前了$left\_max_i$和$right\_max_i$的大小关系之后，这个值可以被唯一确定了。

想象一下，如果当前 `height[i] < height[j]`，说明左边这一侧更矮

**结论**：此时的$height[j]$是要大于所有的$height[k],k\in[1,2,...,i-1]$的

此时$min(left\_max_i,right\_max_i)=left\_max_i$ , 所以可以确定$ans_i$ ，计算之后$i$往右移动即可。如下图所示

![](/file/2/ebGUARSvnLXRoK0uxWiKz.png)


**说明**：虽然$height[j]$ 并不一定就是$right\_max_i$ ,或许$[i+1,j-1]$ 之间存在更高的柱子，但是计算$ans_i$并不是要去同时得到$i$左右两边的最高点。我们只需要找到更小的那边的值就能算答案。而$height[j] > height[i]$ 就已经能够说明$left\_max_i < height[j]$了 (反过来想想，如果$left\_max_i$更大，那左指针就不会跑到后面的那个比$height[j]$小的地方去了。) ，  

这个结论是对称成立的，所以移动模式是：**哪边短缩哪边**。而且我们也知道，指针移动的那一刻，答案是能够被确定的。

### 面试问答

**1.这道题的整体思路是什么？**

直觉是去计算每个柱子上方能接住的雨水的高度，把他们累加起来即可。而某一位置能接的雨水量是它左侧最高柱和右侧最高柱中较短的那个柱子的高度。

而求解柱子上方高度的思路是使用相向移动的双指针，每次移动较短的那一个柱子。在移动的过程中维护左侧已知最大值和右侧已知最大值。每次移动指针之前利用维护好的左侧最大值和右侧最大值来计算该柱子上方的雨水高度，一直到左右指针重叠为止。

**2.这道题双指针背后的思想/为什么双指针是对的？**

每次移动较短的一侧，是因为较短一侧当前格子的接水量已经可以由这一侧的最大值所确定。

**3.这道题的时间复杂度是多少？**

$O(n)$ , 考虑两个指针往中间逼近，遇到就停止，则$i,j$ 的移动总量为$n$次。
