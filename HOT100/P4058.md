**思路**

由于这个数组本身就是有序的，所以可以每次取区间的中间位置的值作为根节点，然后递归左右两边的区间进行建树即可。

# 方法：自底向上的DFS

## 递归定义

定义递归函数 `dfs(l, r)`：

含义：用 `nums[l...r]` 这段有序区间构造一棵平衡 BST，并返回根节点

递归规则：

1.`l > r`：区间为空，返回 `None`

2.取 `mid = (l + r) // 2` 作为根节点

3.递归构造左子树：`dfs(l, mid - 1)`

4.递归构造右子树：`dfs(mid + 1, r)`

class Solution:
    def sortedArrayToBST(self, nums):
        # dfs(l, r): 用 nums[l...r] 这段有序区间构造一棵平衡 BST
        def dfs(l, r):
            # 区间为空，返回空节点
            if l > r:
                return None

            # 每次选择中间位置作为根节点，保证左右子树规模尽量接近
            mid = (l + r) // 2
            root = TreeNode(nums[mid])

            # 递归构造左子树
            root.left = dfs(l, mid - 1)

            # 递归构造右子树
            root.right = dfs(mid + 1, r)

            return root

        return dfs(0, len(nums) - 1)

## 复杂度分析

时间复杂度：`O(n)` ：每个数组元素都会且只会被创建成一个树节点一次。

空间复杂度：`O(log n)`主要是递归栈深度；因为每次对半分，平衡情况下栈深约为 `log n`。
