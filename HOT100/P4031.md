### 思路

接下来的分析，我不拽花里胡哨的名词，也不需要任何前置知识，**从最笨的方法出发：列出所有可能，看看能找到啥规律。**

![](/file/2/OdlQsRXTqOnaqCxHdcix6.png =80%x)


我们可以将这5种方案划分为两类：上一步从$2$来的 + 上一步从$3$来的。

4的上一步从$3$来的所有方案 等价于 $n = 3$ 的所有情况

4的上一步从$2$来的所有方案 等价于 $n = 2$ 的所有情况


![](/file/2/j4mEj78nEP0NVeI5TLgyB.png =80%x)



如果定义出$f(4)$代表$n = 4$ 的所有可能的情况**数量**，不难发现：
$$
f(4) = f(3) + f(2)
$$

由上面的分析，我们可以总结规律：考虑到$n$的方案数，**它由两类方案相加得到**：

**方案一**:先到$n - 1$ 号台阶然后最后跨一步到$n$的方案数。

**分步相乘**：到$n - 1$ 号台阶 的方案数是$f(n - 1)$ ， 跨一步从$n - 1$ 到 $n$ 的方案数为 $1$ ， 由于是先后关系，分步相乘得到：$f(n - 1) * 1 = f(n - 1)$

**方案二**:先到$n - 2$ 号台阶，然后最后跨两步到$n$的方案数。

**分步相乘**：从1到$n - 2$ 号台阶 的方案数是$f(n - 2)$ , 跨两步从$n - 2$ 到 $n$ 的方案数为 $1$ ，由于是先后关系，分步相乘得到：$f(n - 2) * 1 = f(n - 2)$

所以转移:$f(n) = f(n - 1) + f(n - 2)$

![](/file/2/vX_wmO10IoRp1yfKmkpXC.png =70%x)


总结来讲：到$n$号台阶的方案数$f(n)$，按上一步从哪里来的分成两类子问题$f(n - 1)$ , $f(n - 2)$，因为分类相加原理，所以是**相加**得到结果，不是相乘，也不是相减。



**回到我们的解题技巧上来，看看这道题是否能套用我们的解题技巧：**

1.题目问什么，我们定义什么状态:
定义函数:$f(i)$ 为 爬到第$i$个台阶的不同方法数。

2.转移：总是考虑`最后一个元素`的状态:
考虑第$i$号台阶的情况：它要么是从$i - 1$ 来 ，要么是从$i - 2$ 来，相加得到$f(i) = f(i - 1) + f(i - 2)$

在代码层面，由于$f(0),f(1)$ 无法套用以上转移，因为它不够两项，则从定义考虑它的赋值：

原地不动是一种方案,所以$f(0) = 1$

到1号台阶，只有$0\rightarrow 1$,所以$f(1) = 1$

**怎么理解原地不动要算一种方案？**

从另一个角度来看，我们知道 $f(1) = 1,f(2) = 2$一定是对的 。 为了他俩能被正确计算，$f(0)$ 需要等于$f(2) - f(1) = 1$

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        # f(i) 表示爬到第 i 个台阶的不同方法数
        # f(0) = 1，表示原地不动也是一种方案
        # f(1) = 1，只有一种走法：走 1 阶
        if n <= 1:
            return 1

        # 下标从 0 开始，所以数组长度开到 n + 1
        dp = [0] * (n + 1)
        dp[0] = 1
        dp[1] = 1

        # 爬到第 i 阶，最后一步要么从 i - 1 来，要么从 i - 2 来
        for i in range(2, n + 1):
            dp[i] = dp[i - 1] + dp[i - 2]

        return dp[n]
```

int climbStairs(int n) {
    // f(i) 表示爬到第 i 个台阶的不同方法数
    // f(0) = 1，表示原地不动也是一种方案
    // f(1) = 1，只有一种走法：走 1 阶

        cur = prev1 + prev2;
        prev2 = prev1;
        prev1 = cur;
    }

    return prev1;
}

**空间优化：滚动变量法**

由于$f(n)$ 只依赖$f(n - 1) , f(n - 2)$ 这两项，而$f(n-3),f(n-4),...,f(1)$ **对计算后续项来说已经没有任何用处了。**

**我们可以使用三个变量，只保存我们计算下一项所需要的最少元素，滚动计算**

```python
class Solution:
    def climbStairs(self, n):
        # f(0) = 1，表示原地不动也是一种方案
        # f(1) = 1，表示爬到第 1 阶只有一种方案
        if n == 1:
            return 1

        # dp2 表示 f(i - 2)，dp1 表示 f(i - 1)
        dp2 = 1
        dp1 = 1

        # 从第 2 阶开始滚动计算
        for i in range(2, n + 1):
            # f(i) = f(i - 1) + f(i - 2)
            dp_now = dp1 + dp2
            # 滚动更新，下一轮继续使用最近的两个状态
            dp2 = dp1
            dp1 = dp_now

        return dp1
```

### 面试问答

**1.这个算法的思想是什么？**

动态规划。设 $dp[i]$ 表示爬到第 $i$ 阶的方法数。考虑爬到第 $i$ 阶时，上一步可能从第 $i-1$ 阶迈一步上来，也可能从第 $i-2$ 阶跨两步上来，因此有：$dp[i] = dp[i-1] + dp[i-2]$。

又由于每一项只依赖前两项，所以使用三个变量滚动计算：其中两个变量保存上两项的结果，一个变量用于计算下一项的结果。

时间复杂度$O(n)$ ， 空间复杂度$O(1)$
