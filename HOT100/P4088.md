**思路：贪心+双指针**

**重要性质**：当片段包含某个字符$x$ 时，需要至少包含到$x$**在字符串中最后出现的位置**

考虑从左往右计算第一个片段，$right$来表示这个片段至少要到达的位置。类似**跳跃游戏Ⅱ**的，根据每个遍历到的字符的最后一个位置来更新$right$，直到$i == right$ 的时候，一个新的片段才能结束。

```python
class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        # last 记录每个字母最后一次出现的位置
        last = {}
        n = len(s)

        for i in range(n):
            last[s[i]] = i

        ans = []
        # left 是当前片段的左边界，right 是当前片段至少需要到达的右边界
        left = 0
        right = 0

        # 从左往右遍历字符串
        for i in range(n):
            ch = s[i]

            # 当前片段包含了 ch，就必须至少覆盖到 ch 最后出现的位置
            right = max(right, last[ch])

            # 当 i 到达 right，说明当前片段中的所有字符都不会出现在后面
            if i == right:
                ans.append(right - left + 1)
                left = i + 1

        return ans
```

```c
int* partitionLabels(char* s, int* returnSize) {
    // last 记录每个字母最后一次出现的位置
    int last[26];
    int n = strlen(s);

    for (int i = 0; i < 26; i++) {
        last[i] = 0;
    }

    for (int i = 0; i < n; i++) {
        last[s[i] - 'a'] = i;
    }

    int* ans = (int*)malloc(sizeof(int) * n);
    *returnSize = 0;

    // left 是当前片段的左边界，right 是当前片段至少需要到达的右边界
    int left = 0;
    int right = 0;

    // 从左往右遍历字符串
    for (int i = 0; i < n; i++) {
        int idx = s[i] - 'a';

        // 当前片段包含了这个字母，就必须至少覆盖到它最后出现的位置
        if (last[idx] > right) {
            right = last[idx];
        }

        // 当 i 到达 right，说明当前片段中的所有字符都不会出现在后面
        if (i == right) {
            ans[*returnSize] = right - left + 1;
            (*returnSize)++;
            left = i + 1;
        }
    }

    return ans;
}
```

### 面试问答

**1. 本题的思路是什么？**

贪心+双指针。先用哈希表计算出每一个字母的最后出现的位置，也就是代码中的$last$。然后从左往右枚举每一个位置$i$，再用指针$right$来表示当前片段至少要到达的位置 ， 不停的用$last[s[i]]$ 来更新$right$。直到$i == right$ 时就找到了一个新的片段。

时间复杂度:$O(n)$ , 所有指针单方向移动。
