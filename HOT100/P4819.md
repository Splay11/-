**思路：哈希表**

结合[哈希表使用基础](https://codefun2000.com/codenote/hot100/P0018)所学到的语法知识，我们可以想到用一个哈希集合记录已经出现过的数字。

遍历数组时，如果当前数字已经在集合里，说明它之前出现过，直接返回 `true`；如果不在，就把它加入集合。

如果遍历结束都没发现重复元素，就返回 `false`。

```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        # 使用哈希集合记录已经出现过的元素
        seen = set()

        # 遍历数组
        for num in nums:
            # 如果当前元素已经存在，说明有重复
            if num in seen:
                return True

            # 否则加入集合
            seen.add(num)

        # 遍历结束仍无重复
        return False
```

```c
static int cmp(const void* a, const void* b) {
    int x = *(const int*)a;
    int y = *(const int*)b;
    return (x > y) - (x < y);
}

bool containsDuplicate(int* nums, int numsSize) {
    // 先对数组排序
    qsort(nums, numsSize, sizeof(int), cmp);

    // 排序后，只需要检查相邻元素是否相等
    for (int i = 1; i < numsSize; i++) {
        // 如果相邻元素相同，说明存在重复
        if (nums[i] == nums[i - 1]) {
            return true;
        }
    }

    // 遍历结束仍无重复
    return false;
}
```

**1. 本题的核心思路是什么？**

本题主要运用了哈希表（或字典）的思想。遍历数组时，如果当前数字已经在集合里，说明它之前出现过，直接返回 `true`；如果不在，就把它加入集合。如果遍历结束都没发现重复元素，就返回 `false`。

**时间复杂度是 `O(n)`**，因为每个元素只检查和加入一次。

**空间复杂度是 `O(n)`**，最坏情况下需要把所有元素都存进集合。
