**思路：前缀和 + 哈希**

考虑一个子数组$[a_i,a_{i+1},a_{i+2},...,a_{j}]$的和，

它可以被表示为两段**前缀数组**的差分：

$$a_i+a_{i+1}+a_{i+2}+...+a_{j} =  (a_1+a_{2}+a_{3}+...+a_{j}) - (a_1+a_{2}+a_{3}+...+a_{i-1})$$

如下图所示:

![](/file/2/7DCac19z70Jzndp4M45sC.png =70%x)


那么我们可以先计算出前缀和数组:$suf[i] = a_1+a_2+...+a_{i} = suf[i - 1] + a_{i}$

如此，任意一个子数组$(i,j)$的和都可以通过访问前缀和数组$suf[j] - suf[i - 1]$来$O(1)$计算。

#### 问题转化：**两数之和**

$a_i+a_{i+1}+a_{i+2}+...+a_{j} = k$ 被我们通过前缀和数组转化为:

$suf[j] - suf[i - 1] = k$

此时问题转化为：在前缀和数组$suf$中，选出两个数使得它们的差是$k。

本题和两数之和的变化在于：两数之和只需要知道其中一组解，而本题需要计算解的数量。

所以哈希存储的是<键:前缀和 , 值:该值出现的次数>

**注意** ：代码里的哈希初始化为`hash[suf[0]] = 1` , 是为了考虑$suf[i]$本身就是答案的情况。

因为如果一个子数组$(1 , i)$ 满足条件，此时$suf[i] - suf[0] = k$ , 查询的值是$suf[i] - k = 0$ 。 为了不漏掉这个方案，一开始我们需要把`suf[0]` 放入 `hash`里。

### 空间优化

其实这个过程，我们并不需要先把所有位置的前缀和算出来，再去进行哈希寻找。

**因为哈希寻找的过程和前缀和计算过程都是从左往右的**，所以我们可以用一个变量`nowSuf`来动态计算当前位置的前缀和，同时往哈希里插入这个变量`nowSuf`即可。

```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)

        # 求解前缀和
        suf = [0] * (n + 1)

        # 为了更好地处理边界情况，值从 1 开始存储
        # suf[0] = 0 表示空子数组的前缀和
        for i in range(1, n + 1):
            suf[i] = suf[i - 1] + nums[i - 1]

        # 记录满足条件的子数组数量
        ans = 0

        # 哈希表，记录前缀和出现的次数
        st = {}
        st[suf[0]] = 1

        for i in range(1, n + 1):
            # 在之前的前缀和中寻找 suf[i] - k
            target = suf[i] - k

            if target in st:
                ans += st[target]

            # 将当前前缀和加入哈希表
            st[suf[i]] = st.get(suf[i], 0) + 1

        return ans
```

```c
typedef struct {
    long long key;
    int value;
    bool used;
} HashEntry;

static unsigned int hashValue(long long key, int capacity) {
    unsigned long long x = (unsigned long long)key;
    x ^= x >> 33;
    x *= 0xff51afd7ed558ccdULL;
    x ^= x >> 33;
    return (unsigned int)(x % capacity);
}

static int getCount(HashEntry* table, int capacity, long long key) {
    unsigned int pos = hashValue(key, capacity);

    while (table[pos].used) {
        if (table[pos].key == key) {
            return table[pos].value;
        }
        pos = (pos + 1) % capacity;
    }

    return 0;
}

static void addCount(HashEntry* table, int capacity, long long key) {
    unsigned int pos = hashValue(key, capacity);

    while (table[pos].used) {
        if (table[pos].key == key) {
            table[pos].value++;
            return;
        }
        pos = (pos + 1) % capacity;
    }

    table[pos].used = true;
    table[pos].key = key;
    table[pos].value = 1;
}

int subarraySum(int* nums, int numsSize, int k) {
    int n = numsSize;

    // 求解前缀和
    long long* suf = (long long*)malloc(sizeof(long long) * (n + 1));
    suf[0] = 0;

    // 为了更好地处理边界情况，值从 1 开始存储
    // suf[0] = 0 表示空子数组的前缀和
    for (int i = 1; i <= n; i++) {
        suf[i] = suf[i - 1] + nums[i - 1];
    }

    // 记录满足条件的子数组数量
    int ans = 0;

    // 哈希表，记录前缀和出现的次数
    int capacity = n * 3 + 1;
    HashEntry* table = (HashEntry*)calloc(capacity, sizeof(HashEntry));

    addCount(table, capacity, suf[0]);

    for (int i = 1; i <= n; i++) {
        // 在之前的前缀和中寻找 suf[i] - k
        long long target = suf[i] - k;

        ans += getCount(table, capacity, target);

        // 将当前前缀和加入哈希表
        addCount(table, capacity, suf[i]);
    }

    free(suf);
    free(table);

    return ans;
}
```

### 面试问答

**这道题的整体思路是什么？**

这题用的是 前缀和 + 哈希表。

因为子数组和可以转化成两个前缀和的差，所以对于每个位置，我们只需要看之前有没有出现过 当前前缀和 - k。如果有，出现几次，就说明有几个子数组以当前位置结尾，和等于 k。

这个过程用哈希表来存前缀和出现的次数，这样每次查询都是 O(1)。 总的复杂度自然是$O(n)$的
