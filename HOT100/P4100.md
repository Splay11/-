本题和上一题的区别是，这题允许操作`word1` , 且多了`替换`和`增加`操作。我们一起看看转移有哪些变化。

**1.问什么定义什么：**

状态：$dp_{i,j}$ 代表`word1`的前$i$个字符  与 `word2`的前$j$个字符 的情况下，将`word1`转化为`text2` 的最少操作数。

**2.考虑最后一个元素的状态：**

**case1**:当`word1[i]` == `word2[j]`

贪心：显然直接匹配，不做任何操作是最优的。这样可以同时缩短两个字符串的长度，同时还不增加开销。
反过来想想，在这个时候进行那三个操作不管哪一个，**最好的效果也是将问题缩短1个字符的长度，但是它们甚至需要增加开销**。所以直接匹配代价最小。

**case2**:当`word1[i]` != `word2[j]`

**说明**

**插入** 一个字符:

在`word1[:i]`的末尾添加一个`word2[j]` ，使得`word2[j]`得到匹配。

$dp_{i , j - 1} + 1 \rightarrow dp_{i , j}$


**删除** 一个字符:

删掉`word1[i]` ,让子问题去匹配

$dp_{i - 1, j} + 1 \rightarrow dp_{i , j}$

**替换** 一个字符  

替换`word1[i] = word2[j]`

$dp_{i - 1, j - 1} + 1 \rightarrow dp_{i , j}$

三种情况取最小值即可：

$dp_{i,j} = min(dp_{i - 1 , j - 1} , dp_{i - 1 , j} , dp_{i , j - 1}) + 1$

**边界条件**:

$dp_{i,0} = i$ （将`word1[:i]`变为空字符串需要`i`次）
$dp_{0,j} = j$ （将空字符串变为 `word2[j]`，需要 `j` 次插入）

答案:$dp_{n , m}$

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        # 获取两个字符串的长度
        m = len(word1)
        n = len(word2)

        # dp[i][j] 表示 word1 前 i 个字符转换成 word2 前 j 个字符的最少操作数
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # word1 前 i 个字符转换为空字符串，需要删除 i 次
        for i in range(m + 1):
            dp[i][0] = i

        # 空字符串转换成 word2 前 j 个字符，需要插入 j 次
        for j in range(n + 1):
            dp[0][j] = j

        # 逐行计算每个状态
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 如果两个末尾字符相同，直接匹配，不需要额外操作
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1]
                else:
                    # 三种操作：删除、插入、替换，取最小值再加 1
                    dp[i][j] = min(
                        dp[i - 1][j],      # 删除 word1[i - 1]
                        dp[i][j - 1],      # 插入 word2[j - 1]
                        dp[i - 1][j - 1]   # 替换 word1[i - 1]
                    ) + 1

        # 返回 word1 转换成 word2 的最少操作数
        return dp[m][n]
```

```cpp
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

        for (int j = 0; j <= n; j++) {
```

```go
	m := len(word1)
	n := len(word2)

	// dp[i][j] 表示 word1 前 i 个字符转换成 word2 前 j 个字符的最少操作数
	dp := make([][]int, m+1)
	for i := 0; i <= m; i++ {
		dp[i] = make([]int, n+1)
	}

	// word1 前 i 个字符转换为空字符串，需要删除 i 次
	for i := 0; i <= m; i++ {
		dp[i][0] = i
	}

	// 空字符串转换成 word2 前 j 个字符，需要插入 j 次
	for j := 0; j <= n; j++ {
		dp[0][j] = j
	}

	// 逐行计算每个状态
	for i := 1; i <= m; i++ {
		for j := 1; j <= n; j++ {
			// 如果两个末尾字符相同，直接匹配，不需要额外操作

				dp[i][j] = dp[i-1][j-1]

				// 三种操作：删除、插入、替换，取最小值再加 1

				if dp[i][j-1] < best {
					best = dp[i][j-1]
				}
				if dp[i-1][j-1] < best {
					best = dp[i-1][j-1]
				}
				dp[i][j] = best + 1
			}
		}
	}

	// 返回 word1 转换成 word2 的最少操作数

}
```

```c
int minDistance(char* word1, char* word2) {
    // 获取两个字符串的长度
    int m = strlen(word1);
    int n = strlen(word2);

    // dp[i][j] 表示 word1 前 i 个字符转换成 word2 前 j 个字符的最少操作数
    int* dp = (int*)malloc(sizeof(int) * (m + 1) * (n + 1));

    // word1 前 i 个字符转换为空字符串，需要删除 i 次
    for (int i = 0; i <= m; i++) {
        dp[i * (n + 1) + 0] = i;
    }

    // 空字符串转换成 word2 前 j 个字符，需要插入 j 次
    for (int j = 0; j <= n; j++) {
        dp[0 * (n + 1) + j] = j;
    }

    // 逐行计算每个状态
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            // 如果两个末尾字符相同，直接匹配，不需要额外操作
            if (word1[i - 1] == word2[j - 1]) {
                dp[i * (n + 1) + j] = dp[(i - 1) * (n + 1) + j - 1];
            } else {
                // 三种操作：删除、插入、替换，取最小值再加 1
                int deleteCost = dp[(i - 1) * (n + 1) + j];
                int insertCost = dp[i * (n + 1) + j - 1];
                int replaceCost = dp[(i - 1) * (n + 1) + j - 1];

                int best = deleteCost;
                if (insertCost < best) {
                    best = insertCost;
                }
                if (replaceCost < best) {
                    best = replaceCost;
                }

                dp[i * (n + 1) + j] = best + 1;
            }
        }
    }

    // 返回 word1 转换成 word2 的最少操作数
    int ans = dp[m * (n + 1) + n];
    free(dp);
    return ans;
}
```

### 面试问答

**1. 本题的核心思路是什么**

动态规划。定义状态：$dp_{i,j}$ 代表 考虑 $word1$的前$i$个字符  与 $word2$的前$j$个字符 的情况下，最小编辑距离。转移分情况讨论。若末尾两个字符相等则直接匹配，两个字符长度各减1。两个字符不相等则需要进行一次操作 操作：1.要么把`text1` 中的末尾字符删掉2.要么在末尾插入一个和`text2`末尾字符一致的字符进行匹配 3.要么替换`text1` 末尾的字符为`text2`末尾相同的字符进行匹配。如此进行转移计算即可。

时间复杂度$O(nm)$ , 其中$n,m$分别为`word1`和`word2`的长度，开销来自于$dp$数组的计算。 空间复杂度为$O(nm)$ ，开销来自于$dp$数组
