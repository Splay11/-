**思路：**

问题本质：给定一个数组$a_1,a_2,...,a_n$ ， 求从里面选出若干个互不相邻的元素使得和最大。

**1.问什么定义什么**

定义 $f(i)$ 考虑了前$i$个元素的最优解。

**2.考虑`最后一个元素`的状态**

分$a_i$ 选不选去转移：

如果$a_i$不选，不妨从数组中拿掉$a_i$，问题变成：从前$i - 1$个元素中选出最优解，对应到$f(i - 1)$

如果$a_i$选，则$a_{i - 1}$一定不能选，此时不妨从数组中拿掉$a_{i - 1}$，问题变成：从前$i - 2$个元素中选出最优解，对应到$f(i - 2)$

转移:$f(i) = max(f(i - 1) , f(i - 2) + a_i)$

```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)

        # 如果没有房屋，偷到的金额为 0
        if n == 0:
            return 0

        # 如果只有一间房屋，只能偷这一间
        if n == 1:
            return nums[0]

        # dp[i] 表示考虑前 i 间房屋时，能够偷到的最高金额
        dp = [0] * n
        dp[0] = nums[0]
        dp[1] = max(nums[0], nums[1])

        # 枚举每一间房屋，考虑最后一间房屋偷还是不偷
        for i in range(2, n):
            # 不偷第 i 间：答案是 dp[i - 1]
            # 偷第 i 间：第 i - 1 间不能偷，答案是 dp[i - 2] + nums[i]
            dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])

        return dp[n - 1]
```

```c
int rob(int* nums, int numsSize) {
    // 如果没有房屋，偷到的金额为 0
    if (numsSize == 0) {
        return 0;
    }

    // 如果只有一间房屋，只能偷这一间
    if (numsSize == 1) {
        return nums[0];
    }

    // dp[i] 表示考虑前 i 间房屋时，能够偷到的最高金额
    int* dp = (int*)malloc(sizeof(int) * numsSize);
    dp[0] = nums[0];
    dp[1] = nums[0] > nums[1] ? nums[0] : nums[1];

    // 枚举每一间房屋，考虑最后一间房屋偷还是不偷
    for (int i = 2; i < numsSize; i++) {
        // 不偷第 i 间：答案是 dp[i - 1]
        // 偷第 i 间：第 i - 1 间不能偷，答案是 dp[i - 2] + nums[i]
        int notChoose = dp[i - 1];
        int choose = dp[i - 2] + nums[i];
        dp[i] = notChoose > choose ? notChoose : choose;
    }

    int ans = dp[numsSize - 1];
    free(dp);
    return ans;
}
```

### 面试问答

**1.这个算法的思想是什么？**

动态规划。我们定义$ dp[i]$ 表示偷到第 i 个房屋时的最大收益。然后考虑最后一个房屋选不选：如果不选当前房屋，那就是前一个房屋的最优结果$dp[i - 1]$； 如果选当前房屋，那前一个房屋就不能选，只能加上第$i - 2$个房屋的最优结果$dp[i - 2]$。所以每一步就是在“选当前 or 不选当前”房屋里取最大值。 而且每一步只依赖前两个状态，所以可以用两个变量滚动优化，空间做到 O(1)。时间复杂度$O(n)$
