**思路：指针夹逼**

本题和上一题问题结构一模一样，建议先搞懂上一题。

该数组由两段连续递增的区间构成，先搞清楚$T$在哪一段。

原理是一样的：$T>= a[n]$ , 则$T \in 第一段$ , 反之$T \in 第二段$

**接着二分过程就是不停的判断$T$ , $mid$两者的位置关系，以此来逼近$T$的真实位置**

1.当$mid$ 和 $T$ 不属于同一段，根据**位置关系**缩短区间：

​	1.1 $mid$在第一段 ,$T$在第二段， 直接$L = mid + 1$

​	1.2  $mid$在第二段 ,$T$在第一段 , 直接$R = mid - 1$ 

![](/file/2/WfVaLUkZPqvZi7KObJuyp.png =40%x)

2.当$mid$ 和 $T$ 属于同一段时，根据**实际大小关系**缩短区间：

​	2.1 $a[mid] < T$ 时 , $L = mid + 1$

​	2.2 $a[mid] > T$ 时 ，$R = mid - 1$

![](/file/2/WJoI9Z0KaJA_xYJuffp_B.png =40%x)


​	2.3 $a[mid] == T$ 时 ，输出答案。

def _segment(value: int, nums: List[int]) -> int:
    # 判断 value 属于旋转数组的哪一段
    # 大于最后一个元素，说明在第一段；否则在第二段
    return 0 if value > nums[-1] else 1


class Solution:
    def search(self, nums: List[int], target: int) -> int:
        # 先判断 target 属于哪一段
        target_value = _segment(target, nums)

        left, right = 0, len(nums) - 1

        while left <= right:
            mid = (left + right) // 2

            # 判断 nums[mid] 属于哪一段
            mid_value = _segment(nums[mid], nums)

            # 如果 mid 和 target 在同一段，就按照普通有序数组二分
            if mid_value == target_value:
                if nums[mid] < target:
                    left = mid + 1
                elif nums[mid] > target:
                    right = mid - 1
                else:
                    return mid

            # 如果 mid 和 target 不在同一段，就根据两段的位置关系移动指针
            else:
                # mid 在第一段，target 在第二段，答案在右边
                if mid_value < target_value:
                    left = mid + 1

                # mid 在第二段，target 在第一段，答案在左边
                else:
                    right = mid - 1

        return -1

### 面试问答

**1. 本题的核心思路是什么？**

本题的核心思路是：利用二分查找，不断逼近target的真实位置。

具体的，二分时先判断$target$和$nums[mid]$在哪一段，如果同一段，则根据实际值的大小关系来确定左右指针的移动方向。如果不同段，则根据$mid$和$target$的位置关系来确定左右指针的移动方向。

时间复杂度：$O(log\ n)$ ，因为每次二分都将问题规模缩小一半。

空间复杂度：$O(1)$
