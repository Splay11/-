**思路**

受到[LeetCode 543. 二叉树的直径](https://codefun2000.com/codenote/hot100/P0064#)的启发，我们不难得到一个**结论**：

**二叉树上任意一条路径，都可以看成是： `左子树链(或空) -> 拐点 -> 右子树链(或空)` 的结构**

**下图中的四种情况，表征了树上路径的所有可能结构**

![img](https://codefun2000.com/p/4252/file/%E8%B7%AF%E5%BE%84%E7%A4%BA%E6%84%8F.svg?type=additional_file)


现在要我们求解最大和的路径，那么我们可以枚举每个拐点，接着求解**经过这个拐点的最优解**

即形如：`左子树中的最大和的路径 -> 拐点 -> 右子树中的最大和的路径` 的路径结构。


## 自底向上的DFS

模仿树的直径的做法，我们可以枚举拐点 , 先递归求解左右子树的最优解，然后合并答案即可。

具体步骤:

1.定义`dfs(node)` 代表求解从`node`出发往下走，能够走出的最大路径和，返回这个路径和.

2.每次递归求解`node`的左子树的向下的最大路径`left_best` 以及 以 `node`的右子树的向下的最大路径`right_best`，

3.计算以`node`为拐点的最优解:`max(left_best , right_best) + node.val`

注意:left_best和right_best 要和 0 取一个最大值。因为可能子树中每一个节点都是负数，这种情况下应当不进入该子树。

```python
class Solution:
    def maxPathSum(self, root):
        # 全局最优答案，路径至少包含一个节点
        ans = -10**18

        # dfs(node): 返回从 node 出发向下走的最大链和
        # 这条链只能选择左子树或右子树中的一边，方便父节点继续拼接
        def dfs(node):
            nonlocal ans

            # 空节点对路径没有贡献，返回 0
            if node is None:
                return 0

            # 递归求左子树向下的最大链和
            left_best = dfs(node.left)
            if left_best < 0:
                left_best = 0

            # 递归求右子树向下的最大链和
            right_best = dfs(node.right)
            if right_best < 0:
                right_best = 0

            # 枚举当前节点作为拐点，路径为：左链 + 当前节点 + 右链
            cur = left_best + node.val + right_best
            if cur > ans:
                ans = cur

            # 返回给父节点时，只能选择一条向下的单链
            if left_best > right_best:
                return node.val + left_best
            return node.val + right_best

        dfs(root)
        return ans
```

### 面试问答

**1. 本题的核心思路是什么？**

总的思路是枚举每个点作为拐点的最大路径和，总的取最大值就是答案。接着对每个节点，先递归拿到左右子树“从子节点出发向下走的最大链和”，和小于 0 的链直接舍弃（当成 0），因为负贡献只会拖累答案。然后以当前节点为拐点的候选答案就是：`left_best + node.val + right_best`，用它更新全局最大值。接着函数返回给父节点时，返回的是一条最优单链，供父亲节点拼接： `node.val + max(left_best, right_best)`。时间复杂度 `O(n)`，每个节点只处理一次。
