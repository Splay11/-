**思路**

**1.题目问什么，我们定义什么状态**

定义$dp(i)$代表以$i$为结尾的最长的有效括号子串长度。

**转移：**

如果$s[i] = ($ , 那么 $dp(i) = 0$。 **因为一个合法的括号序列的右端点一定要是一个右括号**。

如果$s[i] = )$ ，结构如下图所式：

![](/file/2/Oummv6aSUGhBMMcSoJtJy.png =90%x)



**说明**：考虑以第$i - 1$个位置为结尾的最长括号序列（也就是图中红色省略号所代表的区域）的左侧，令其下标为$j=i - dp_{i-1} - 1$：

如果$s[j]$ 是右括号，那么**无法**和第$i$个位置的右括号进行匹配。

如果$s[j]$ 是左括号，那么可以和第$i$个位置的右括号进行匹配。此时$j$的左侧可能还能拼接更长的合法括号序列（也就是图中绿色省略号）。

根据贪心的思想，要拼就拼最长的，所以直接拼接上$dp_{j-1}$。

那么总共的长度就是两段括号子序列的长度加上$2$ ，也就是这一对新匹配的括号的长度。

即：$dp_i = dp_{i-1}+2+dp_{i-dp_{i-1}-2}$

class Solution:
    def longestValidParentheses(self, s: str) -> int:
        n = len(s)
        if n == 0:
            return 0

        dp = [0] * n
        dp[0] = 0 # 第一个位置不管是什么括号，都不可能合法。

        for i in range(1, n):
            if s[i] == '(':
                dp[i] = 0
            else:
                # 形如 ...(...) 的结构
                inner_length = dp[i - 1]
                j = i - inner_length - 1

                if j < 0 or s[j] == ')':
                    continue

                if j - 1 >= 0:
                    dp[i] = dp[i - 1] + 2 + dp[i - dp[i - 1] - 2]
                else:
                    dp[i] = dp[i - 1] + 2

        return max(dp)

int longestValidParentheses(char* s) {
    int n = 0;
    while (s[n] != '\0') {
        n++;
    }

    if (n == 0) {
        return 0;
    }

    int* dp = (int*)malloc(sizeof(int) * n);
    for (int i = 0; i < n; i++) {
        dp[i] = 0;
    }

    dp[0] = 0; // 第一个位置不管是什么括号，都不可能合法。

    for (int i = 1; i < n; i++) {
        if (s[i] == '(') {
            dp[i] = 0;
        } else {
            // 形如 ...(...) 的结构
            int inner_length = dp[i - 1];
            int j = i - inner_length - 1;

            if (j < 0 || s[j] == ')') {
                continue;
            }

            if (j - 1 >= 0) {
                dp[i] = dp[i - 1] + 2 + dp[i - dp[i - 1] - 2];
            } else {
                dp[i] = dp[i - 1] + 2;
            }
        }
    }

    int ans = 0;
    for (int i = 0; i < n; i++) {
        if (dp[i] > ans) {
            ans = dp[i];
        }
    }

    free(dp);
    return ans;
}

### 面试问答

**1.这道题的思路是什么？**

动态规划。定义 dp[i] 表示以第 i 个位置结尾的最长有效括号长度。然后就去考虑最后一个字符的状态：如果当前位置是左括号则没法作为合法括号串的结尾，dp[i] = 0；如果当前位置是右括号，那就尝试去和前面某个左括号匹配。具体来说，先看 i-1 位置结尾的那段最长合法括号，把它整段跳过去，再看它左边那个位置能不能和当前这个右括号配成一对；如果能配上，那么当前答案就是“中间那段长度 + 这一对括号的 2 + 更左边还能拼接的合法长度”。本质上就是在判断当前位置这个右括号能不能把前面的结构接起来。最后答案取所有 dp[i] 里的最大值。时间复杂度是 O(n)，空间复杂度是 O(n)。
