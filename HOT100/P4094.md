**思路：**


**1.问什么定义什么**

定义$f(i)$ 代表以$a_i$为结尾的最长上升子序列长度。

**2.考虑最后一个元素的状态**

$a_i$ 之前有$a_1,a_2,...,a_{i-1}$这$i - 1$个元素。

只要满足$a_k < a_i , k < i$ ，我们就尝试让$a_i$ 和 以$a_k$为结尾的最长序列进行拼接:

转移:$f(i) = max(f(k) , k < i 且 a_k < a_i) + 1$



**转移示意图如下👇**

![](/file/2/dRNXShE3F4lrq8q9jHmdx.png =70%x)



由于状态$i$ 依赖的是比他小的位置（或者说数组左侧的位置），所以我们计算的顺序为下标从小到大（或者说从左到右）。

class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)

        # dp[i] 表示以 nums[i] 作为结尾的最长递增子序列长度
        dp = [1] * n

        # ans 记录所有 dp[i] 中的最大值
        ans = 1

        # 从左到右枚举每个位置作为子序列结尾
        for i in range(n):
            # 枚举 i 前面的所有位置
            for j in range(i):
                # 只有 nums[j] < nums[i]，nums[i] 才能接在 nums[j] 后面
                if nums[j] < nums[i]:
                    dp[i] = max(dp[i], dp[j] + 1)

            # 更新最长递增子序列长度
            ans = max(ans, dp[i])

        return ans

### 面试问答

**1.这个算法的思想是什么？**

动态规划。定义 $dp[i]$ 表示以第 $i$ 个元素结尾的最长递增子序列长度。然后对每个位置 $i$，去看它前面的所有位置 $j$：只要 $nums[j]$ 比 $nums[i]$ 小，就可以把 $i$ 接到 $j$ 后面，更新 $dp[i]$。本质就是：尝试把当前元素接在之前所有“能接”的位置后面，取一个最长的。

最后答案就是所有 $dp[i]$ 里的最大值。 时间复杂度是 $O(n²)$
