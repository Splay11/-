**思路**

枚举每一天去卖出股票。假设在第$i$天卖，那么一定是在前缀区域$[1,i - 1]$ 去找一个$j$使得 $prices[j]$  最小， 这样答案

$$ans = price[i] - price[j]$$  

才能最大。

所以从左到右枚举所有天数，同时维护一个前缀区域中的最小值，边统计答案边更新

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        # 维护前缀区域中的最低价格
        minPrice = prices[0]
        # 记录当前能够获得的最大利润
        ans = 0

        # 枚举每一天作为卖出日
        for price in prices:
            # 如果今天卖出，利润 = 今天价格 - 前面最低买入价格
            ans = max(ans, price - minPrice)
            # 更新到目前为止的最低价格
            minPrice = min(minPrice, price)

        return ans
```

int maxProfit(int* prices, int pricesSize) {
    // 维护前缀区域中的最低价格
    int minPrice = prices[0];
    // 记录当前能够获得的最大利润
    int ans = 0;

    // 枚举每一天作为卖出日
    for (int i = 0; i < pricesSize; i++) {

        // 如果今天卖出，利润 = 今天价格 - 前面最低买入价格
        if (price - minPrice > ans) {
            ans = price - minPrice;
        }

        // 更新到目前为止的最低价格
        if (price < minPrice) {
            minPrice = price;
        }
    }

    return ans;
}

### 面试问答

**1. 本题的思路是什么？**

贪心。从左往右枚举每一天去卖出股票。在过程中维护过去这些天里最低的买入价格，两者相减就是第$i$天的最优解。最后答案就是所有天数中的最优解。
