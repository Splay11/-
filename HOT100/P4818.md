**思路：栈**

我们按 `'/'` 分割后，会得到这些片段：

```
["", "...", "a", "", "..", "b", "c", "..", "d", ".", ""]
```

这些空串都可以直接忽略。去除空串得到：

```
[ "...", "a",  "..", "b", "c", "..", "d", "."]
```

**分析题目的规则**

`'.'` 表示当前目录本身，说明需要**保留前一个目录**，例如示例中的`["d", "."]`，简化为`["d"]`

`'..'` 表示将目录切换到上一级，说明需要**跳过前一个目录**，例如示例中的`["...", "a",  ".."]`，简化为`["..."]`

**为什么使用栈？**

因为这个过程天然就符合**栈“后进先出”**的特点。

每进入一个新目录，就相当于把这个目录压进栈里；而遇到 `".."` 时，表示返回上一级目录，实际上就是把**最近进入的那个目录**删掉。

而“最近进入的目录最先退出”，这正好就是栈的规则。

我们可以总结以下步骤：

1. 先将路径按`'/'`分割成不包含空串的字符串数组
2. 从左到右遍历
   - 遇到`'.'` ，直接跳过继续遍历，
   - 遇到`'..'`，弹出栈顶，
   - 其它情况，将字符串放入栈中。
3. 最后把栈中的目录重新拼起来。

```python
class Solution:
    def simplifyPath(self, path: str) -> str:
        # 用栈保存规范路径中的目录
        stack = []

        # 按 '/' 分割路径
        for name in path.split("/"):
            # 依次处理每一段
            if name == "" or name == ".":
                # 空串和 '.' 都直接忽略
                continue
            elif name == "..":
                # '..' 表示返回上一级目录
                if stack:
                    stack.pop()
            else:
                # 普通目录名入栈
                stack.append(name)

        # 如果栈为空，说明结果是根目录
        if not stack:
            return "/"

        # 拼接成规范路径
        return "/" + "/".join(stack)
```

```cpp
class Solution {
public:
    string simplifyPath(string path) {
        // 用栈保存规范路径中的目录
        vector<string> stack;

        // 按 '/' 分割路径
        stringstream ss(path);
        string name;

        // 依次处理每一段
        while (getline(ss, name, '/')) {
            if (name == "" || name == ".") {
                // 空串和 '.' 都直接忽略
                continue;
            } else if (name == "..") {
                // '..' 表示返回上一级目录
                if (!stack.empty()) {
                    stack.pop_back();
                }
            } else {
                // 普通目录名入栈
                stack.push_back(name);
            }
        }

        // 如果栈为空，说明结果是根目录
        if (stack.empty()) {
            return "/";
        }

        // 拼接成规范路径
        string ans = "";
        for (string name : stack) {
            ans += "/" + name;
        }

        return ans;
    }
};
```

```java
class Solution {
    public String simplifyPath(String path) {
        // 用栈保存规范路径中的目录
        Deque<String> stack = new ArrayDeque<>();

        // 按 '/' 分割路径
        String[] names = path.split("/");

        // 依次处理每一段
        for (String name : names) {
            if (name.equals("") || name.equals(".")) {
                // 空串和 '.' 都直接忽略
                continue;
            } else if (name.equals("..")) {
                // '..' 表示返回上一级目录
                if (!stack.isEmpty()) {
                    stack.pollLast();
                }
            } else {
                // 普通目录名入栈
                stack.offerLast(name);
            }
        }

        // 如果栈为空，说明结果是根目录
        if (stack.isEmpty()) {
            return "/";
        }

        // 拼接成规范路径
        StringBuilder ans = new StringBuilder();
        while (!stack.isEmpty()) {
            ans.append("/").append(stack.pollFirst());
        }

        return ans.toString();
    }
}
```

```go
func simplifyPath(path string) string {
    // 用栈保存规范路径中的目录
    stack := []string{}

    // 按 '/' 分割路径
    names := strings.Split(path, "/")

    // 依次处理每一段
    for _, name := range names {
        if name == "" || name == "." {
            // 空串和 '.' 都直接忽略
            continue
        } else if name == ".." {
            // '..' 表示返回上一级目录
            if len(stack) > 0 {
                stack = stack[:len(stack)-1]
            }
        } else {
            // 普通目录名入栈
            stack = append(stack, name)
        }
    }

    // 如果栈为空，说明结果是根目录
    if len(stack) == 0 {
        return "/"
    }

    // 拼接成规范路径
    return "/" + strings.Join(stack, "/")
}
```

```c
char* simplifyPath(char* path) {
    int n = strlen(path);

    // 用栈保存规范路径中的目录
    char** stack = (char**)malloc(sizeof(char*) * (n + 1));
    int top = 0;

    char* copy = (char*)malloc(sizeof(char) * (n + 1));
    strcpy(copy, path);

    // 按 '/' 分割路径
    char* token = strtok(copy, "/");

    // 依次处理每一段
    while (token != NULL) {
        if (strcmp(token, ".") == 0) {
            // 空串和 '.' 都直接忽略
        } else if (strcmp(token, "..") == 0) {
            // '..' 表示返回上一级目录
            if (top > 0) {
                free(stack[--top]);
            }
        } else {
            // 普通目录名入栈
            stack[top] = (char*)malloc(sizeof(char) * (strlen(token) + 1));
            strcpy(stack[top], token);
            top++;
        }

        token = strtok(NULL, "/");
    }

    // 如果栈为空，说明结果是根目录
    if (top == 0) {
        char* ans = (char*)malloc(sizeof(char) * 2);
        strcpy(ans, "/");

        free(stack);
        free(copy);

        return ans;
    }

    int totalLen = 1;
    for (int i = 0; i < top; i++) {
        totalLen += strlen(stack[i]) + 1;
    }

    char* ans = (char*)malloc(sizeof(char) * (totalLen + 1));
    ans[0] = '\0';

    // 拼接成规范路径
    for (int i = 0; i < top; i++) {
        strcat(ans, "/");
        strcat(ans, stack[i]);
    }

    for (int i = 0; i < top; i++) {
        free(stack[i]);
    }
    free(stack);
    free(copy);

    return ans;
}
```

### 面试问答

**1. 本题的核心思路是什么？**

先把路径按 `/` 切开，再用一个栈模拟走目录。遇到普通文件夹名就进去，也就是入栈；遇到 `".."` 就退回上一级，也就是弹栈；遇到 `"."` 或空串就直接跳过。最后把栈里的内容重新用 `/` 拼起来，就是规范路径。

**时间复杂度是 `O(n)`**，因为整个字符串只需要遍历一遍。

**空间复杂度是 `O(n)`**，因为栈最多存储整个路径。
