**思路**

先想清楚本题所有可能情况:共$2^n$ 种， 因为每个数可以选可以不选。

回溯本质是在生成一颗二叉树（知不知道这玩意也无所谓），向左走是选中数字，向右走是不选中数字。

具体的，$[1,2,3]$的所有情况是如何被代码计算得到的？

1.二叉树的第一层代表选第一个数的状态，第二层代表选第二个数的状态以此类推。最终选出的结果是最后一层所对应的结果。

2.由于每个节点会分裂出两个节点，所以到第三层的时候有$2^3=8$种结果，能够计算出所有情况

这个过程中，我们发现每个节点都存储了一个值`curr`，这个值是当前生成的子集状态，每次将这个子集传递给下方的节点，让之后的节点在此基础上进行操作，最后叶子节点（也就是最后一层的节点）才能够得到最终结果。

对应到代码里就很好理解了，递归时存储两个参数:

`index` 记录当前走到第几层了。不记录这个我们无法知道这个回溯什么时候该结束。

`curr` 记录当前子集状态。

每次分两路递归，要么选`nums[index]` , 要么不选`nums[index]`

终止条件：当走到第$n + 1$ 层，代表考虑完了所有数字的选择状态，说明一个完整的子集已经构造完成。

```python
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        # res 用来存储所有子集
        res = []
        # curr 表示当前正在构造的子集状态
        curr = []
        n = len(nums)

        def dfs(index):
            # 当 index 走到 n，说明所有数字都已经考虑完，得到一个完整子集
            if index == n:
                res.append(curr[:])
                return

            # 选择 nums[index]，继续往下一层递归
            curr.append(nums[index])
            dfs(index + 1)

            # 回溯，撤销选择
            curr.pop()

            # 不选择 nums[index]，继续往下一层递归
            dfs(index + 1)

        dfs(0)
        return res
```

```java
class Solution {
    // res 用来存储所有子集
    private List<List<Integer>> res = new ArrayList<>();
    // curr 表示当前正在构造的子集状态
    private List<Integer> curr = new ArrayList<>();

    public List<List<Integer>> subsets(int[] nums) {
        dfs(nums, 0);
        return res;
    }

    private void dfs(int[] nums, int index) {
        // 当 index 走到 nums.length，说明所有数字都已经考虑完，得到一个完整子集
        if (index == nums.length) {
            res.add(new ArrayList<>(curr));
            return;
        }

        // 选择 nums[index]，继续往下一层递归
        curr.add(nums[index]);
        dfs(nums, index + 1);

        // 回溯，撤销选择
        curr.remove(curr.size() - 1);

        // 不选择 nums[index]，继续往下一层递归
        dfs(nums, index + 1);
    }
}
```

```go
func subsets(nums []int) [][]int {
	// res 用来存储所有子集
	res := [][]int{}
	// curr 表示当前正在构造的子集状态
	curr := []int{}
	n := len(nums)

	var dfs func(int)
	dfs = func(index int) {
		// 当 index 走到 n，说明所有数字都已经考虑完，得到一个完整子集
		if index == n {
			tmp := make([]int, len(curr))
			copy(tmp, curr)
			res = append(res, tmp)
			return
		}

		// 选择 nums[index]，继续往下一层递归
		curr = append(curr, nums[index])
		dfs(index + 1)

		// 回溯，撤销选择
		curr = curr[:len(curr)-1]

		// 不选择 nums[index]，继续往下一层递归
		dfs(index + 1)
	}

	dfs(0)
	return res
}
```

```javascript
function subsets(nums) {
    // res 用来存储所有子集
    const res = [];
    // curr 表示当前正在构造的子集状态
    const curr = [];
    const n = nums.length;

    function dfs(index) {
        // 当 index 走到 n，说明所有数字都已经考虑完，得到一个完整子集
        if (index === n) {
            res.push([...curr]);
            return;
        }

        // 选择 nums[index]，继续往下一层递归
        curr.push(nums[index]);
        dfs(index + 1);

        // 回溯，撤销选择
        curr.pop();

        // 不选择 nums[index]，继续往下一层递归
        dfs(index + 1);
    }

    dfs(0);
    return res;
}
```

```c
void dfs(int* nums, int numsSize, int index, int* curr, int currSize, int** res, int* returnSize, int** returnColumnSizes) {
    // 当 index 走到 numsSize，说明所有数字都已经考虑完，得到一个完整子集
    if (index == numsSize) {
        res[*returnSize] = (int*)malloc(sizeof(int) * currSize);
        for (int i = 0; i < currSize; i++) {
            res[*returnSize][i] = curr[i];
        }
        (*returnColumnSizes)[*returnSize] = currSize;
        (*returnSize)++;
        return;
    }

    // 选择 nums[index]，继续往下一层递归
    curr[currSize] = nums[index];
    dfs(nums, numsSize, index + 1, curr, currSize + 1, res, returnSize, returnColumnSizes);

    // 不选择 nums[index]，继续往下一层递归
    dfs(nums, numsSize, index + 1, curr, currSize, res, returnSize, returnColumnSizes);
}

int** subsets(int* nums, int numsSize, int* returnSize, int** returnColumnSizes) {
    // 子集总数为 2^n
    int total = 1 << numsSize;

    // res 用来存储所有子集
    int** res = (int**)malloc(sizeof(int*) * total);
    *returnColumnSizes = (int*)malloc(sizeof(int) * total);
    *returnSize = 0;

    // curr 表示当前正在构造的子集状态
    int* curr = (int*)malloc(sizeof(int) * numsSize);

    dfs(nums, numsSize, 0, curr, 0, res, returnSize, returnColumnSizes);

    return res;
}
```

#code-switcher
特别注意：代码里，在选择`nums[index]` 的递归调用前后分别有一个`push` 和 `pop`的操作，这个是回溯的精髓。

例如在第二层到第三层的时候，往下走选中，`curr.push(nums[index])` , 得到一种结果之后，**还需要往上回到过去的状态** ,需要把之前`push` 过的内容给`pop`掉。**所以这个操作总是对称出现的**

**注意：**递归时所占用的空间复杂度不是$O(2^n)$的。因为有回溯的操作，当一个节点（一次递归函数）算完之后，它会`return` 返回上一层，此时**内存会被当场销毁，给下一次递归复用这片空间**。换句话说，回溯的计算过程是串行计算的，每次只调用一个递归函数，而不是同时运行$2^n$个递归函数。

递归时总的空间开销是递归树的高度（又称栈深），为$O(n)$的。因为递归的瞬间，当前递归函数会暂存于内存中，等后续递归完成，返回之后才销毁。

### 面试问答

**1. 本题的核心思路是什么？**

这道题的核心思路是**回溯枚举所有选择情况**。对于每个数字来说，都只有两种决策：选或者不选，所以递归依次处理每个位置的“选 / 不选”状态，最终到递归出口一共会形成 $2^n$ 种结果。递归过程中，用 `index` 表示当前处理到第几个数，用 `curr` 记录当前已经构造出的子集；每次递归分成两路，一路把当前数字加入子集，另一路跳过当前数字。当所有数字都处理完时，就说明一个完整的子集已经生成出来了。

时间复杂度是 $O(n·2^n)$，因为一共有 $2^n$ 个子集，而每个子集在加入答案时最多需要拷贝 $n$ 次；空间复杂度是 $O(n)$，其中`curr`数组占用$O(n)$空间，递归栈的空间开销为$O(n)$。
