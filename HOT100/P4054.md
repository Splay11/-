## 解法1：递归交换左右子树（自底向下的DFS）

核心:**对每个节点，先递归让左右子树内部交换，然后再交换左右子树即可**

完整流程：

1.到达当前节点 `node`

2.递归翻转左子树

3.递归翻转右子树

4.交换 `node.left` 和 `node.right`

5.终止条件是当前节点为空，直接返回。

```python id="uyq1d9"
class Solution:
    def invertTree(self, root):
        def dfs(node):
            # 终止条件：当前节点为空，直接返回
            if node is None:
                return

            # 先递归翻转左子树
            dfs(node.left)

            # 再递归翻转右子树
            dfs(node.right)

            # 最后交换当前节点的左右子树
            node.left, node.right = node.right, node.left

        dfs(root)
        return root
```

## 面试问答

**1. 本题的核心思路是什么？**

自底向上的DFS。递归遍历每个节点，先递归让左右子树内部翻转，接着交换左右儿子节点即可。因为每个节点都恰好交换一次，所以时间复杂度是 `O(n)`。
