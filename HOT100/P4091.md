**思路**

将要组成的整数$n$看成长度为$n$的木板， 完全平方数$x^2$ 看成长度为$x^2$的木板。

问题转化成：将一个长度$n$的木板分割成最少的部分，要求每个部分的长度恰好是完全平方数。

![](/file/2/WyIUgt_nPPshjxbBcmq4d.png =80%x   )


**1.问什么定义什么**

定义$f(i)$ 代表长度为$n$的木板能分割出的最少个数。 对于任意的$i$ ， 答案$f(i)$一定存在，因为可以用$i$个$1$ 相加得到。

**2.考虑最后一个元素的状态**

接着考虑最后一个部分的可能长度为:$j = 1^2,2^2,...,(\sqrt{i})^2$

我们枚举这些长度，分割出来后得到$i - j$  长度的木板。此时该子问题和原问题类似，只是规模变小了。这符合了动态规划的要求，于是我们可以写出状态转移方程。

$$f(i) = f(i - k^2 , k \in [1, \lfloor\sqrt{i}\rfloor]) + 1 $$

![](/file/2/Vc3ZWjVVYZMkjGtzL3Dxw.png =90%x)




由于依赖的状态$i - k^2 < i$ , 则 计算顺序为从小到大。

注意边界条件:$f(0) = 0$ ， 因为长度为$0$的木板，我们不需要切割就能满足要求。

另外一个角度来说，当$i - k^2 = 0$ 时，转移式为:$f(i) = f(0) + 1$。  这种情况是 木板本身长度就是完全平方数，无需切割。此时为了满足$f(i) = 1$ , 需要$f(0) = 0$

```python
class Solution:
    def numSquares(self, n: int) -> int:
        # dp[i] 表示组成整数 i 所需要的最少完全平方数数量
        dp = [n + 1] * (n + 1)
        # 组成 0 不需要任何完全平方数
        dp[0] = 0

        # 从小到大计算每个整数的答案
        for i in range(1, n + 1):
            j = 1
            # 枚举最后一个完全平方数 j * j
            while j * j <= i:
                # 如果最后选 j * j，那么前面还需要组成 i - j * j
                dp[i] = min(dp[i], dp[i - j * j] + 1)
                j += 1

        return dp[n]
```

### 面试问答

**1.这道题的思路是什么？**

动态规划。我们定义 dp[i] 表示组成数字 i 所需要的最少完全平方数个数。然后考虑最后一个数一定是某个平方数

所以枚举所有小于等于 $i$ 的平方数 $j²$，把它减掉之后，问题就变成了 $i - j²$ 的最优解，也就是$dp[i - j^2]$，再加上当前这个平方数即可。

初始化 dp[0] = 0，因为组成 0 不需要任何数。最后答案就是 $dp[n]$。时间复杂度是 $O(n\sqrt{n})$，因为外层循环枚举$n$次，内层循环最多枚举$\sqrt{n}$次。
