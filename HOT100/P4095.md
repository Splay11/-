**思路**

**1.题目问什么，我们定义什么状态**

学习了 LeetCode 53. 最大子数组和 过后，下意识的我们会定义$dp(i)$ 代表以$i$为结尾的最大乘积。

但是本题有个重要的问题是：**数组中可能有负数！**

例如:$[-10,5,-10,...]$  ， 此时对于$dp(3)$ 而言 , 它应该是让 $-10 * (-10 * 5) = 500$ 才是最大的 ，而不是$-10 * 5 = -50$

也就是说：当$a_i < 0$ 时，我们应该是**贪心的 让 以$i - 1$ 为结尾的最小乘积** 乘上 $a_i$ 才变成**最大乘积。**

换句话说，在每一个点，我们不仅要知道最大乘积，还需要额外计算一个最小乘积，让之后的不管是正数还是负数能够正确计算结果。

所以这里我们定义一个二维状态:

定义$dp(i,0/1)$代表以$i$为结尾的最大/最小乘积。

**转移**

**思想：要么不拼，要拼就拼最值的**

当$a_i > 0$ 时, 

$dp(i,0) = max(dp(i - 1 , 0) * a_i , a_i)$

$dp(i,1) = min(dp(i - 1 , 1) * a_i , a_i)$

当$a_i < 0$ 时,

$dp(i,0) = max(dp(i - 1 , 1) * a_i , a_i)$

$dp(i,1) = min(dp(i - 1 , 0) * a_i , a_i)$

**优化：**

观察上式：$a_i$ 和 $dp(i-1,0),  dp(i - 1 , 1)$ 之间的组合情况就两种，可以两者取最值来得到转移，**这样不用判断数值的正负性了。**

 $dp(i,0) = max(dp(i - 1 , 0) * a_i , dp(i - 1 , 1) * a_i , a_i)$

 $dp(i,1) = min(dp(i - 1 , 0) * a_i , dp(i - 1 , 1) * a_i , a_i)$

```python id="h1wp2k"
class Solution:
    # 返回数组中乘积最大的连续子数组乘积
    def maxProduct(self, nums: List[int]) -> int:
        dp = [[0, 0] for _ in range(len(nums))]
        dp[0][0] = dp[0][1] = nums[0]

        for i in range(1, len(nums)):
            dp[i][0] = max(dp[i - 1][0] * nums[i], dp[i - 1][1] * nums[i], nums[i])
            dp[i][1] = min(dp[i - 1][0] * nums[i], dp[i - 1][1] * nums[i], nums[i])

        return max(dp[i][0] for i in range(len(nums)))
```

```go id="9g5uer"
func maxProduct(nums []int) int {
	// 返回数组中乘积最大的连续子数组乘积
	dp := make([][]int, len(nums))
	for i := 0; i < len(nums); i++ {
		dp[i] = make([]int, 2)
	}

	dp[0][0] = nums[0]
	dp[0][1] = nums[0]

	for i := 1; i < len(nums); i++ {
		dp[i][0] = dp[i-1][0] * nums[i]
		if dp[i-1][1]*nums[i] > dp[i][0] {
			dp[i][0] = dp[i-1][1] * nums[i]
		}
		if nums[i] > dp[i][0] {
			dp[i][0] = nums[i]
		}

		dp[i][1] = dp[i-1][0] * nums[i]
		if dp[i-1][1]*nums[i] < dp[i][1] {
			dp[i][1] = dp[i-1][1] * nums[i]
		}
		if nums[i] < dp[i][1] {
			dp[i][1] = nums[i]
		}
	}

	ans := dp[0][0]
	for i := 0; i < len(nums); i++ {
		if dp[i][0] > ans {
			ans = dp[i][0]
		}
	}

	return ans
}
```

```c id="db839v"
int maxProduct(int* nums, int numsSize) {
    // 返回数组中乘积最大的连续子数组乘积
    int** dp = (int**)malloc(sizeof(int*) * numsSize);
    for (int i = 0; i < numsSize; i++) {
        dp[i] = (int*)malloc(sizeof(int) * 2);
    }

    dp[0][0] = nums[0];
    dp[0][1] = nums[0];

    for (int i = 1; i < numsSize; i++) {
        int a = dp[i - 1][0] * nums[i];
        int b = dp[i - 1][1] * nums[i];

        dp[i][0] = a;
        if (b > dp[i][0]) {
            dp[i][0] = b;
        }
        if (nums[i] > dp[i][0]) {
            dp[i][0] = nums[i];
        }

        dp[i][1] = a;
        if (b < dp[i][1]) {
            dp[i][1] = b;
        }
        if (nums[i] < dp[i][1]) {
            dp[i][1] = nums[i];
        }
    }

    int ans = dp[0][0];
    for (int i = 0; i < numsSize; i++) {
        if (dp[i][0] > ans) {
            ans = dp[i][0];
        }
    }

    for (int i = 0; i < numsSize; i++) {
        free(dp[i]);
    }
    free(dp);

    return ans;
}
```

**空间优化**

这一步的优化 和 LeetCode 53. 最大子数组和 这一题一样。由于$dp(i,0/1)$ 都只依赖$dp(i-1)$中的两个状态，所以可以定义`cur_max`和`cur_min` 来表示当前项的上一项的$dp$值。

```python
class Solution:
    def maxProduct(self, nums):
        # 和最大子数组和类似，定义以当前位置结尾的最大乘积和最小乘积
        cur_max = nums[0]
        cur_min = nums[0]
        ans = nums[0]

        for i in range(1, len(nums)):
            x = nums[i]

            # 因为 x 可能是负数，所以最大乘积可能由之前的最小乘积乘 x 得到
            # cur_max 和 cur_min 都会更新，所以先用 tmp_max、tmp_min 暂存结果
            tmp_max = max(x, cur_max * x, cur_min * x)
            tmp_min = min(x, cur_max * x, cur_min * x)

            # 所有转移计算完后，再更新当前最大乘积和最小乘积
            cur_max = tmp_max
            cur_min = tmp_min

            # 答案是所有位置结尾的最大乘积中的最大值
            ans = max(ans, cur_max)

        return ans
```

### 面试问答

**1.这道题的思路是什么？**

动态规划。考虑“以当前位置结尾”的最优解，由于有负数，负数乘上最小值反而可能变成最大值，所以不能只维护一个最大乘积，还要同时维护一个最小乘积。我们定义两个状态，分别表示以第 i 个位置结尾的最大乘积和最小乘积。转移时，当前位置要么自己单独成段，要么接在前面的最大乘积后面，要么接在前面的最小乘积后面，三种情况分别取最大和最小即可。这样无论当前数是正数、负数还是 0，都能统一处理。最后答案就是所有位置结尾时最大乘积里的最大值。时间复杂度是 O(n)，空间复杂度可以优化到 O(1)。
