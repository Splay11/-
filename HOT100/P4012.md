**思路**

重叠性质：考虑两个区间$[x_1,y_1]$ 和 $[x_2,y_2]$ 重叠，等价于$y_1 \geq x_2$

所以我们对所有区间的左端点$x_i$排序，从左到右遍历，判断对应的$y_i$  是否大于等于 下一个区间的左端点$x_{i+1}$ ，若重叠则合并区间$y_i = max(y_i,y_{i+1})$ , 如此往复合并所有可能的区间 ，直到$y_i < x_{i + 1}$  ，区间断开。

**为什么要对左端点排序？贪心**

对左端点排序后考虑任意一个相邻的区间$[x_i,y_i] , [x_{i+1},y_{i+1}]$ ，它满足，选中$[x_i,y_i]$的情况下，$x_i \leq x_{i+1}$且$x_i,x_{i+1}$他俩离的最近。这等价于$y_i$ 和$x_{i+1}$ 离的最近，那么重叠性质$y_i \geq x_{i+1}$ 最容易被满足。

换句话说，**对左端点排序之后，每一个区间$i+1$ 都是 最容易和 $i$ 发生重叠的区间。自然从左往右扫描能够考虑到所有重叠情况。**

所以可以这么说：排序保证了每次只需和前一个区间比较即可覆盖所有重叠情况

class Solution:

        # 如果区间数组为空，直接返回空数组
        if not intervals:
            return []
        # 按照区间左端点从小到大排序
        intervals.sort()
        # merged 用来保存合并后的区间
        merged = []

        # 依次遍历每一个区间
        for interval in intervals:
            # 如果 merged 为空，或者当前区间和上一个区间不重叠
            # 直接把当前区间加入答案
            if not merged or merged[-1][1] < interval[0]:
                merged.append(interval)
            else:
                # 否则说明两个区间有重叠
                # 更新上一个区间的右端点
                merged[-1][1] = max(merged[-1][1], interval[1])

        # 返回合并后的所有区间
        return merged

func merge(intervals [][]int) [][]int {
	// 如果区间数组为空，直接返回空数组
	if len(intervals) == 0 {
		return [][]int{}
	}

	// 按照区间左端点从小到大排序
	sort.Slice(intervals, func(i, j int) bool {
		return intervals[i][0] < intervals[j][0]
	})

	// merged 用来保存合并后的区间
	merged := make([][]int, 0)

	// 依次遍历每一个区间
	for _, interval := range intervals {
		// 如果 merged 为空，或者当前区间和上一个区间不重叠
		// 直接把当前区间加入答案
		if len(merged) == 0 || merged[len(merged)-1][1] < interval[0] {
			merged = append(merged, interval)
		} else {
			// 否则说明两个区间有重叠
			// 更新上一个区间的右端点
			if interval[1] > merged[len(merged)-1][1] {
				merged[len(merged)-1][1] = interval[1]
			}
		}
	}

	// 返回合并后的所有区间
	return merged
}

/**
 * 返回合并后的二维数组。
 * returnSize 表示返回的区间数量。
 * returnColumnSizes 表示每个返回区间的长度，这里每个区间长度都是 2。
 */
int cmp(const void* a, const void* b) {
    // 取出两个区间
    int* x = *(int**)a;
    int* y = *(int**)b;

    // 按照区间左端点从小到大排序
    return x[0] - y[0];
}

int** merge(int** intervals, int intervalsSize, int* intervalsColSize,
            int* returnSize, int** returnColumnSizes) {
    // 如果区间数组为空，直接返回空
    if (intervalsSize == 0) {
        *returnSize = 0;
        *returnColumnSizes = NULL;
        return NULL;
    }

    // 按照区间左端点从小到大排序
    qsort(intervals, intervalsSize, sizeof(int*), cmp);

    // ans 用来保存合并后的区间
    int** ans = (int**)malloc(sizeof(int*) * intervalsSize);

    // returnColumnSizes 用来记录每个区间的长度
    *returnColumnSizes = (int*)malloc(sizeof(int) * intervalsSize);

    // 当前已经合并出的区间数量
    *returnSize = 0;

    // 依次遍历每一个区间
    for (int i = 0; i < intervalsSize; i++) {
        // 如果 ans 为空，或者当前区间和上一个区间不重叠
        // 直接把当前区间加入答案
        if (*returnSize == 0 || ans[*returnSize - 1][1] < intervals[i][0]) {
            ans[*returnSize] = (int*)malloc(sizeof(int) * 2);
            ans[*returnSize][0] = intervals[i][0];
            ans[*returnSize][1] = intervals[i][1];

            // 每个区间都有两个元素：起点和终点
            (*returnColumnSizes)[*returnSize] = 2;

            // 合并后的区间数量加一
            (*returnSize)++;
        } else {
            // 否则说明两个区间有重叠
            // 更新上一个区间的右端点
            if (intervals[i][1] > ans[*returnSize - 1][1]) {
                ans[*returnSize - 1][1] = intervals[i][1];
            }
        }
    }

    // 返回合并后的所有区间
    return ans;
}

### **面试问答**

**1.这道题的整体思路是什么？**

先按区间的左端点升序排序，然后从左到右进行贪心合并：依次遍历每个区间，如果当前区间与结果数组最后一个区间，也就是当前正在合并的区间不重叠（即前者右端点小于当前左端点），就直接加入到结果数组末尾；否则说明有重叠，就更新右端点为两者的最大值，从而实现区间合并。排序保证了每次只需和前一个区间比较即可覆盖所有重叠情况

时间复杂度为 **O(n log n)**（排序开销），遍历合并为 **O(n)**，总体为 **O(n log n)**；空间复杂度为 **O(n)**（用于存储结果）。
