**思路**

本题所给的数组如下所示👇

![](/file/2/a8A_zeL_Yxu04CWsH4fVt.png =60%x)


从上图我们不难发现，整个数组由两个连续递增区间构成。我们不妨给每个元素编号：属于第一个区间的编号为$0$，属于第二个区间的编号为$1$。

例如:$a=[4,5,6,7,0,1,2]$  , 编号数组$b=[0,0,0,0,1,1,1]$

**考虑一个问题：给定下标$i$ , 如何判断$a[i]$ 属于哪个区间？**


由于第一段中任意的数都**大于**第二段的最大值(也就是数组最后一个元素)都大，而第二段中的任意元素都**小于等于**第二段的最大值。

所以如果$a[i] > a[n]$  , 则$i \in 第一个区间$ , 反之$i \in 第二个区间$ 。

即：
$$
b_i =
\begin{cases}
1, & a[i] > a[n] \\
0, & a[i] \le a[n]
\end{cases}
$$

这里我多举几个例子，来确保大家能理解这个$b$数组是怎么回事👇

![](/file/2/suF1j0hCr4ECBgbI2NFCu.png)

**目标：找到这个编号数组的第一个1出现的位置**


知道每个位置的编号如何计算之后，我们就能二分了👇

1.将数组$b$划分成:$<1$ 和 $\geq 1$ 两个部分

2.二分，让$L$停在`Suf`的第一个位置，直接输出$L$即可。

#warning-box
**注意**:在实际的计算过程中，我们肯定不能先预处理出$b$数组再去二分，那样还不如直接扫一遍$a$数组直接找。所以我们在二分过程中只计算$mid$位置所在的编号值。在代码中使用的`get_value`函数来专门获得编号。

```python
def _rotated_segment(index: int, nums: List[int]) -> int:
    # 从 nums 数组映射到编号数组
    # 第一段元素都大于最后一个元素，编号为 0
    # 第二段元素都小于等于最后一个元素，编号为 1
    return 0 if nums[index] > nums[-1] else 1


class Solution:
    def findMin(self, nums: List[int]) -> int:
        left, right = 0, len(nums) - 1

        # 本质上是在一个先 0 后 1 的数组中找到第一个 1
        while left <= right:
            mid = (left + right) // 2
            value = _rotated_segment(mid, nums)

            # 当前在第一段，最小值一定在右边
            if value == 0:
                left = mid + 1

            # 当前在第二段，当前位置可能是最小值，继续往左找
            else:
                right = mid - 1

        # left 停在第二段的第一个位置，也就是最小值位置
        return nums[left]
```

class Solution {
public:
    int get_value(int index, vector<int>& nums) {
        // 从 nums 数组映射到编号数组
        // 第一段元素都大于最后一个元素，编号为 0
        // 第二段元素都小于等于最后一个元素，编号为 1
        return nums[index] > nums[nums.size() - 1] ? 0 : 1;

            else {
                right = mid - 1;
            }
        }

        return nums[left];
    }
};

### 面试问答

**1. 本题的核心思路是什么？**

二分。数组由两段组成，目标是找到第二段的第一个元素。本题的一个关键性质是：第一段的所有数都大于第二段的最大值。依此性质，我们二分的时候，根据$a[mid]$和$a[n]$的大小来判断它属于第一段还是第二段。如果$mid$在第一段则$left = mid + 1$ 反之$right = mid - 1$ 。整个过程结束时$left$ 就停在第二段的第一个位置，输出即可。复杂度$O(logn)$
