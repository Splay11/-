**1.朴素的大根堆排序做法**

学习过[实战2:堆排序](https://codefun2000.com/codenote/hot100/P0043#%E5%AE%9E%E6%88%982%EF%BC%9A%E5%A0%86%E6%8E%92%E5%BA%8F)的同学应该不难想到一个淳朴的做法：用大根堆排序，然后连续取堆顶的$k$个元素，最后一个取出来的就是答案。

但是堆排序的复杂度是$O(nlogn)$的。

class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        # 使用 heapq.nlargest 找到前 k 大的元素
        # 前 k 大元素中的最后一个就是第 k 大元素
        return heapq.nlargest(k, nums)[-1]

```cpp
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        // 使用大根堆存储所有元素
        priority_queue<int> heap;

        // 将数组元素加入大根堆
        for (int num : nums) {
            heap.push(num);
        }

        // 弹出前 k - 1 大的元素
        for (int i = 1; i < k; i++) {
            heap.pop();
        }

        // 堆顶元素就是第 k 大的元素
        return heap.top();
    }
};

	old := *h
	n := len(old)
	x := old[n-1]

	return x

var findKthLargest = function (nums, k) {
    // 使用大根堆存储所有元素
    let heap = [];

    // 向上调整
    function heapifyUp(index) {
        while (index > 0) {
            let parent = Math.floor((index - 1) / 2);

            if (heap[parent] >= heap[index]) {
                break;
            }

            let temp = heap[parent];
            heap[parent] = heap[index];
            heap[index] = temp;

            index = parent;
        }
    }

    // 向下调整
    function heapifyDown(index) {
        while (true) {
            let left = index * 2 + 1;
            let right = index * 2 + 2;
            let largest = index;

            if (left < heap.length && heap[left] > heap[largest]) {
                largest = left;
            }

            if (right < heap.length && heap[right] > heap[largest]) {
                largest = right;
            }

            if (largest === index) {
                break;
            }

            let temp = heap[index];
            heap[index] = heap[largest];
            heap[largest] = temp;

            index = largest;
        }
    }

    // 插入元素到大根堆
    function push(x) {
        heap.push(x);
        heapifyUp(heap.length - 1);
    }

    // 弹出堆顶最大值
    function pop() {
        let ans = heap[0];

        heap[0] = heap[heap.length - 1];
        heap.pop();

        if (heap.length > 0) {
            heapifyDown(0);
        }

        return ans;
    }

    // 将数组元素加入大根堆
    for (let num of nums) {
        push(num);
    }

    // 弹出前 k - 1 大的元素
    for (let i = 1; i < k; i++) {
        pop();
    }

    // 堆顶元素就是第 k 大的元素
    return heap[0];
};

    // 向下调整，维护大根堆
    while (1) {
        int left = index * 2 + 1;
        int right = index * 2 + 2;
        int largest = index;

        if (left < size && heap[left] > heap[largest]) {
            largest = left;
        }

        if (right < size && heap[right] > heap[largest]) {
            largest = right;
        }

        if (largest == index) {
            break;
        }

        int temp = heap[index];
        heap[index] = heap[largest];
        heap[largest] = temp;

        index = largest;
    }
}

void push(int* heap, int* size, int x) {
    // 将元素加入大根堆
    heap[*size] = x;
    (*size)++;

    heapifyUp(heap, *size - 1);
}

int pop(int* heap, int* size) {
    // 弹出堆顶最大值
    int ans = heap[0];

    heap[0] = heap[*size - 1];
    (*size)--;

    if (*size > 0) {
        heapifyDown(heap, *size, 0);
    }

    return ans;
}

int findKthLargest(int* nums, int numsSize, int k) {
    // 使用大根堆存储所有元素
    int* heap = (int*)malloc(sizeof(int) * numsSize);
    int size = 0;

    // 将数组元素加入大根堆
    for (int i = 0; i < numsSize; i++) {
        push(heap, &size, nums[i]);
    }

    // 弹出前 k - 1 大的元素
    for (int i = 1; i < k; i++) {
        pop(heap, &size);
    }

    // 堆顶元素就是第 k 大的元素
    int ans = heap[0];

    free(heap);
    return ans;
}

**2.残酷的末位淘汰法(小根堆)**

考虑已经知道前$i$个数中的前$k$大元素，当我们新增第$i + 1$个元素$a_{i+1}$进来之后，共$k + 1$ 个元素，此时应当删除哪个元素呢？

举个例子:假设一开始枚举完前$k$个元素，那么里面的每一个元素都是 前$k$大的元素，不需要删任何数👇

![](/file/2/yUD0aw8Ngyn4t67GPcL2I.png =80%x)



**考虑数组新增到了第$k + 1$个元素，此时必须有一个数得滚蛋，因为我们只要前$k$大的元素**。此时显然就是把最小值删了👇

![](/file/2/l9y0J2Jn1m8XIIz5ACQqX.png =80%x)



下一步，第$k + 2$个位置的元素加入进来之后，这里面的最小值也可以直接被删除。

整个过程结束，剩下的自然是整个数组的前$k$大元素，输出最小值即可👇

![](/file/2/5_jjx5UGbjuKxN9tMUoH1.png =80%x)



所以做法很简单：从左到右枚举这个数组，同时维护大小为$k$的**小根堆**（即若堆大小超过$k$,则删除堆顶最小值）。结束的时候堆里存储了数组的前$k$大元素，而堆顶就是答案。

这里我们再看一个完整的动画来进一步理解该思想👇

class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        # 构建一个大小为 k 的小根堆
        heap = []

        # 遍历数组中的每个元素
        for num in nums:
            # 将当前元素加入小根堆
            heapq.heappush(heap, num)

            # 如果堆的大小超过 k，就弹出堆顶最小元素
            if len(heap) > k:
                heapq.heappop(heap)

        # 堆中剩下的是前 k 个最大的元素，堆顶就是第 k 大的元素
        return heap[0]
```

**小总结**

这个方法就像互联网大厂中的**末尾淘汰机制**。

**hc**固定就$k$个 ， 而公司非得招$k + 1$ 个人，然后用所谓的末尾淘汰法，把能力最差的踢掉，同时再招一个进来。如此往复，迭代一段时间之后，公司里剩下的就是能力"前$k$大"的人了...

#warning-box

**这个做法的优势是？**

**1.复杂度更低**

由于我们只需要维护$k$个元素，复杂度为$O(nlogk)$

**2.应用常见：处理流式数据**

应用场景是：假设线上有一个流式数据（你可以理解为数组长度不是固定的，是逐渐增长的），要求任意时刻下的第$k$大元素。


### 面试问答

**1. 本题的核心思路是什么？**

从左到右枚举这个数组，同时维护大小为$k$的小根堆，时刻维护当前遍历过的元素集合中的前$k$大元素。每次新增一个元素则将元素插入到堆中，结束的时候堆顶就是答案。复杂度为$O(nlogk)$

**2. 这个做法的应用场景是？**

假设线上有一个流式数据，要求任意时刻下的第$k$大元素。此时可以维护大小为$k$的小根堆。每一个时刻可以以$O(logk)$的复杂度来查询所有数据中的第$k$大元素。
