# **思路**

1.**直接算阶乘，不现实**：因为$n$ 很大，数据量大了之后就超出计算机能够存储的整数范围了。



2.**大数模拟呢？也不现实**：

因为每次$n * (n + 1)$ ,数位几乎是成线性增长的。当$n = 10^5$ 时，$n!$的数位长度是$4 *10^5$ 。

![](/file/2/ivPANNcv4B8gkEhzGlJkB.png)

考虑每一次乘法的复杂度是$\Omega(n)$的，一共要做$n$次乘法计算，复杂度是$\Omega(n^2)$的。$10^{10}$次运算，计算机大概要跑$200$秒左右。显然不符合要求。




3.正确解法：**想清楚阶乘中末尾的$0$是怎么来的**

一个数末尾为什么会有$0$ ？ 因为它的因子里有$10$ 。 

而$10 = 2 \times 5$

所以问题本质上就变成了：

**在 $n!$ 的质因子分解里，一共能凑出多少对 $2 \times 5$。**

**例如7的阶乘后面为什么有1个0？因为它质因分解后能凑出一对$2 \times 5$**👇 

![](/file/2/WD4B6ZKxwz50TX8A8QPH3.png =80%x) 


根据下图结果不难发现，阶乘里的因子$2$ 的个数永远比 因子$5$ 多👇

![](/file/2/66JPJeFhhpiBmtGxnThy3.png)


$[1,n]$ 中含有因子$2$的数，也就是偶数，有$\frac{n}{2}$ 个

$[1,n]$ 中含有因子$5$的数，也就是$5$的倍数的数，有$\frac{n}{5}$ 个。 明显是少于偶数的个数的。

所以问题变成了:$n!$里有多少个因子$5$ 。

从数轴上来看，就是统计方块5的个数👇
![](/file/2/1WCgKAUgkdy1p5fvAw-Zs.png)



那么我们可以循环$[1,n]$中的每个数，不停的从这个数里除掉$5$ ， 直到没有因子$5$为止

```python
def trailingZeroes(n):
    # 记录阶乘结果中因子 5 的个数
    ans_5 = 0

    # 枚举 1 到 n 的每一个数
    for i in range(1, n + 1):
        # 统计当前数字中有多少个因子 5
        x = i
        while x % 5 == 0:
            x //= 5
            ans_5 += 1

    # 阶乘末尾 0 的个数由因子 5 的个数决定
    return ans_5
```

## **优化：逐行计算**

相对于$[1,n]$ , 含有因子$5$的数是稀疏的，也就是上述循环中很多<**不是$5$的倍数的数**>是完全没必要去统计的👇

![](/file/2/DKIGZwbcDRUmG5SVp5pvf.png)


所以比起统计所有正整数，更直接的办法是：

有多少个数能提供 1 个 5

有多少个数能提供 2 个 5

有多少个数能提供 3 个 5

...



而一个个去找含有因子$5$的数复杂度过高，**我们考虑逐行计算！**

![](/file/2/ZBxEMkBgr6ubR7DVdK6Bu.png)


先考虑第一行的5的个数，它本质上就是在计算：有多少个数至少包含一个因子$5$ ， 这个个数显然是$\frac{n}{5}$

再考虑第二行的5的个数，它本质上就是在计算：有多少个数至少包含两个$5$ ， 这个个数显然是$\frac{n}{5^2}=\frac{n}{25}$

**所以逐行计算我们的答案就是:$\frac{n}{5} + \frac{n}{25} + \frac{n}{125} + ...$  ， 一直到分式为零为止**

![](/file/2/nMnfaMXVB2C7opnV6g-Ui.png)

**代码实现如下👇**

```python
def trailingZeroes(n):
    # 统计阶乘末尾 0 的个数，本质是统计因子 5 的个数
    ans_5 = 0
    i = 5

    # 逐行统计 5、25、125... 的倍数个数
    while i <= n:
        # n // i 表示有多少个数至少能提供当前这一行的一个因子 5
        ans_5 += n // i
        i *= 5

    return ans_5
```

# 面试问答


**1.本题的算法思路是什么？(朴素做法)**

一道经典的数学题。阶乘末尾零的个数取决有多少个因子$10$ , 而因子$10$由质因子对$2,5$ 所决定。又由于$5$的因子个数一定少于$2$的。所以考虑直接计算阶乘中因子$5$的个数。循环枚举$[1,n]$ , 每次不断用$5$除尽这个数， 从而得到每个数中因子$5$的个数，最后输出答案即可。

时间复杂度：外层循环$n$次，内层循环并不是每次都会触发，它本质在计算$[1,n]$范围内因子$5$的总个数，总共计算$\frac{n}{5} + \frac{n}{25}+\frac{n}{125}+... < log_5 n$ 次。总的循环次数不超过$log_5 n$ , 则复杂度为$O(log_5 n)$


> 一般面试中大概率不要用最优解法，可以先实现朴素解法。如果面试官要求进一步优化，可以再考虑写最优解。
