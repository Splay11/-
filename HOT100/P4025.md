**思路：栈**

我们先来观察一下，括号到底是怎么匹配的。

比如样例：

```
([])
```

从左往右看，先出现的是$'('$，后出现的是$'['$

但真正匹配的时候，却是$'['$和$']'$先匹配，最后才轮到$'('$和$')'$匹配

也就是说：

**最后出现的左括号，反而是最先被匹配掉**

这个特点恰好与**栈**的**后进先出**特点吻合

由此得到启发，我们可以用栈来解决这道题

我们现在用栈来模拟样例进行匹配的过程。

比如字符串：

```
s = "{()}[]"
```

以及字符串

```
s = "{}(][{"
```

通过动画的模拟我们可以总结出这题做法：

遍历每个字符，对于当前字符：

- 如果它是左括号，那么直接入栈。
- 如果它是右括号，那么它应该匹配某一种固定的左括号。

对于本题来说：

- `')'` 应该匹配 `'('`
- `']'` 应该匹配 `'['`
- `'}'` 应该匹配 `'{'`

```python 
class Solution:
    def isValid(self, s: str) -> bool:
        # 创建栈，用来存放还没有匹配的左括号
        stack = []

        # 括号匹配字典：右括号 -> 对应的左括号
        brackets = {
            ')': '(',
            ']': '[',
            '}': '{'
        }

        # 遍历字符串中的每个字符
        for char in s:
            # 如果是左括号，直接入栈
            if char in '([{':
                stack.append(char)

            # 如果是右括号，需要和栈顶左括号匹配
            elif char in ')]}':
                # 如果栈为空，说明没有左括号可以匹配
                # 如果栈顶元素不是对应的左括号，说明匹配失败
                if not stack or stack.pop() != brackets[char]:
                    return False

        # 最后栈为空，说明所有左括号都被正确匹配
        return len(stack) == 0
```

```cpp 
class Solution {
public:
    bool isValid(string s) {
        // 创建栈，用来存放还没有匹配的左括号
        vector<char> stack;

        // 括号匹配字典：右括号 -> 对应的左括号
        unordered_map<char, char> brackets = {
            {')', '('},
            {']', '['},
            {'}', '{'}
        };

        // 遍历字符串中的每个字符
        for (char ch : s) {
            // 如果是左括号，直接入栈
            if (ch == '(' || ch == '[' || ch == '{') {
                stack.push_back(ch);
            }

            // 如果是右括号，需要和栈顶左括号匹配
            else if (ch == ')' || ch == ']' || ch == '}') {
                // 如果栈为空，说明没有左括号可以匹配
                // 如果栈顶元素不是对应的左括号，说明匹配失败
                if (stack.empty() || stack.back() != brackets[ch]) {
                    return false;
                }

                // 匹配成功，弹出栈顶左括号
                stack.pop_back();
            }
        }

        // 最后栈为空，说明所有左括号都被正确匹配
        return stack.empty();
    }
};
```

```go 
func isValid(s string) bool {
	// 创建栈，用来存放还没有匹配的左括号
	stack := []byte{}

	// 遍历字符串中的每个字符
	for i := 0; i < len(s); i++ {
		ch := s[i]

		// 如果是左括号，直接入栈
		if ch == '(' || ch == '[' || ch == '{' {
			stack = append(stack, ch)
		} else {
			// 如果是右括号，需要和栈顶左括号匹配
			if len(stack) == 0 {
				return false
			}

			top := stack[len(stack)-1]

			// 判断括号是否匹配
			if (ch == ')' && top != '(') ||
				(ch == ']' && top != '[') ||
				(ch == '}' && top != '{') {
				return false
			}

			// 匹配成功，弹出栈顶左括号
			stack = stack[:len(stack)-1]
		}
	}

	// 最后栈为空，说明所有左括号都被正确匹配
	return len(stack) == 0
}
```

```c 
bool isValid(char* s) {
    int n = strlen(s);

    // 创建栈，用来存放还没有匹配的左括号
    char* stack = (char*)malloc(sizeof(char) * (n + 1));
    int top = 0;

    // 遍历字符串中的每个字符
    for (int i = 0; i < n; i++) {
        char ch = s[i];

        // 如果是左括号，直接入栈
        if (ch == '(' || ch == '[' || ch == '{') {
            stack[top++] = ch;
        } else {
            // 如果是右括号，需要和栈顶左括号匹配
            if (top == 0) {
                free(stack);
                return false;
            }

            char left = stack[--top];

            // 判断括号是否匹配
            if ((ch == ')' && left != '(') ||
                (ch == ']' && left != '[') ||
                (ch == '}' && left != '{')) {
                free(stack);
                return false;
            }
        }
    }

    // 最后栈为空，说明所有左括号都被正确匹配
    bool ans = (top == 0);

    free(stack);
    return ans;
}
```

### 面试问答

**1. 本题的核心思路是什么？**

先观察括号匹配的规律，会发现**最后出现的左括号一定要最先被匹配掉**，这正好符合栈“后进先出”的特点，所以可以用栈来维护当前还没有匹配的左括号。遍历字符串时，遇到左括号就入栈，遇到右括号就拿它和栈顶元素进行匹配；如果栈为空或者类型不对应，说明当前括号无法合法闭合，直接返回 `false`。最后如果栈为空，说明所有括号都被正确匹配，字符串有效。

**时间复杂度是 `O(n)`**，因为我们只需要从左到右遍历一遍字符串，每个字符最多只会入栈或出栈一次，所以整体是线性的。

**空间复杂度是 `O(n)`**，最坏情况下如果字符串全部都是左括号，那么这些括号都会被压入栈中，此时栈的大小会达到 `n`。
