## **归并排序法**

由于两个数组本身有序，所以可以每次从两个数组的开头中取较小的一个元素放入新数组中。

得到归并后的数组$res$ , 直接取中位数即可。

这个过程不需要动态删除数组的开头元素，用双指针解决即可。

class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        res = []
        i, j = 0, 0

        # 归并两个有序数组，每次取较小的元素加入 res
        while i < len(nums1) and j < len(nums2):
            if nums1[i] < nums2[j]:
                res.append(nums1[i])
                i += 1
            else:
                res.append(nums2[j])
                j += 1

        # 如果 nums1 还有剩余元素，继续加入 res
        while i < len(nums1):
            res.append(nums1[i])
            i += 1

        # 如果 nums2 还有剩余元素，继续加入 res
        while j < len(nums2):
            res.append(nums2[j])
            j += 1

        n = len(res)

        # 如果总长度为奇数，直接返回中间元素
        if n % 2 == 1:
            return res[n // 2]

        # 如果总长度为偶数，返回中间两个元素的平均值
        return (res[n // 2 - 1] + res[n // 2]) / 2

## 双指针法

我们并不需要真的合并数组，而是获得中位数。那么可以在两个数组上先遍历完前$\frac{n + m - 1}{2}$ 个元素，然后计算中位数👇

@[video](https://codefun2000.com/p/4179/file/%E5%8F%8C%E6%8C%87%E9%92%88%E6%B3%95.mp4)
#code-switcher
```python
class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        # 分别记录两个有序数组
        A, B = nums1, nums2

        # 获取两个数组的长度
        n, m = len(A), len(B)

        # 获取合并后的总长度
        length = n + m

        # 定义两个指针，分别指向两个数组当前的位置
        i, j = 0, 0

        # 获取当前两个数组中较小的下一个数
        def get_next():
            nonlocal i, j

            # 如果第一个数组已经遍历完了，则返回第二个数组的下一个数
            if i >= n:
                val = B[j]
                j += 1
                return val

            # 如果第二个数组已经遍历完了，则返回第一个数组的下一个数
            if j >= m:
                val = A[i]
                i += 1
                return val

            # 如果第一个数组当前的数小于第二个数组当前的数，则返回第一个数组的下一个数
            if A[i] < B[j]:
                val = A[i]
                i += 1
                return val

            # 否则返回第二个数组的下一个数
            val = B[j]
            j += 1
            return val

        # 先跳过前面的 (length - 1) // 2 个数
        for _ in range((length - 1) // 2):
            get_next()

        # 如果总长度为奇数，则返回下一个数
        if length % 2 == 1:
            return float(get_next())

        # 如果总长度为偶数，则返回中间两个数的平均值
        left = get_next()
        right = get_next()
        return (left + right) / 2.0

## **切割数组法**

令归并后的数组名为$res$  ， 长度为$n + m$

先了解三个重要性质👇

#warning-box

**性质1.中位数性质**

给定一个数组$arr$

**如果$arr$ 长度为偶数，则将$arr$ 对半切开，中位数就是左侧区域的最大值 和 右侧区域的最小值的 平均值。**

**如果$arr$是奇数，则将$arr$对半切开，把多的那一个丢给左侧，那么中位数就是左侧区域的最大值**

#warning-box

**性质2.前缀构成性质**

归并后的数组的左侧区域，一定是由$nums1$和$nums2$ 的各自的某一个前缀区域共同构成的，因为它们有序👇

**性质3:长度定理**

如果$res$的左侧区域所对应的 $nums1$的前缀长度 为$x$ , 那么$nums2$的前缀长度就一定是$\frac{n + m}{2} - x$

**结论：**

根据以上三个性质，问题可以转化成：在$nums1$和$nums2$里各切一刀，使得切出来的两个前缀区域恰好对应$res$的左半边区域。答案根据性质1得出即可。

#warning-box
**问题：给定一个切割方案，如何判断合法性**

根据**性质1** ,我们只需要判断**两个数组切口附近的四个元素**的值。

定义$nums1$切口左右的值为$A\_left,A\_right$

定义$nums2$切口左右的值为$B\_left,B\_right$

两个数组切口左边所形成的左侧区域的最大值为$max(A\_left,B\_left)$

两个数组切口右边所形成的右侧区域的最小值为$min(A\_right,B\_right)$

那么合法性 等价于 $max(A\_left,B\_left) \leq min(A\_right,B\_right)$

## **二分优化切割数组法**

本题最优的解法，就是在切割数组法的基础上，二分优化枚举$nums1$的过程。

一切二分的基础是问题有单调性。本问题的单调性在于：

1.如果$nums1$切少了，则$nums2[B\_right] > nums1[A\_left]$

2.如果$nums1$切多了，则$nums2[B\_right] < nums1[A\_left]$

**如下图所示👇**

![](/file/2/bGxxDA_xTm3tpx3Rob6fH.png =80%x) 


所以我们可以二分$nums1$的分割位置，根据大小条件来判断，如果给$nums1$分多了，则收缩右边界。如果给$nums1$分少了，则收缩左边界，直到找到正确的分割点。

class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        # 分别记录两个有序数组
        A, B = nums1, nums2

        # 保证 A 数组的长度小于等于 B 数组的长度，这样二分的是较短数组
        if len(A) > len(B):
            A, B = B, A

        # 获取两个数组的长度
        n, m = len(A), len(B)

        # 计算两个数组的长度之和
        total = n + m

        # 计算左半部分需要包含的元素个数
        half = (total + 1) // 2

        # 二分切割较短的数组 A
        left, right = 0, n

        while left <= right:
            # A 的切割位置
            i = (left + right) // 2

            # B 的切割位置
            j = half - i

            # 获取 A 数组切割位置左右两边的值
            A_left = A[i - 1] if i > 0 else float("-inf")
            A_right = A[i] if i < n else float("inf")

            # 获取 B 数组切割位置左右两边的值
            B_left = B[j - 1] if j > 0 else float("-inf")
            B_right = B[j] if j < m else float("inf")

            # 如果左半部分所有元素都小于等于右半部分所有元素，说明切割合法
            if A_left <= B_right and B_left <= A_right:
                # 如果总长度为奇数，中位数就是左半部分最大值
                if total % 2 == 1:
                    return float(max(A_left, B_left))

                # 如果总长度为偶数，中位数是左半部分最大值和右半部分最小值的平均值
                return (max(A_left, B_left) + min(A_right, B_right)) / 2.0

            # 如果 A 左边的值大于 B 右边的值，说明 A 切割位置需要左移
            elif A_left > B_right:
                right = i - 1

            # 否则 A 切割位置需要右移
            else:
                left = i + 1

        return 0.0

        // 如果 A 左边的值大于 B 右边的值，说明 A 切割位置需要左移
        else if (ALeft > BRight) {
            right = i - 1;
        }

        // 否则 A 切割位置需要右移
        else {
            left = i + 1;
        }
    }

    return 0.0;
};

double findMedianSortedArrays(int* nums1, int nums1Size, int* nums2, int nums2Size) {
    // 保证 nums1 数组的长度小于等于 nums2 数组的长度，这样二分的是较短数组
    if (nums1Size > nums2Size) {
        return findMedianSortedArrays(nums2, nums2Size, nums1, nums1Size);
    }

    // 分别记录两个有序数组
    int* A = nums1;
    int* B = nums2;

    // 获取两个数组的长度
    int n = nums1Size;
    int m = nums2Size;

    // 计算两个数组的长度之和
    int total = n + m;

    // 计算左半部分需要包含的元素个数
    int half = (total + 1) / 2;

    // 二分切割较短的数组 A
    int left = 0;
    int right = n;

    while (left <= right) {
        // A 的切割位置
        int i = left + (right - left) / 2;

        // B 的切割位置
        int j = half - i;

        // 获取 A 数组切割位置左右两边的值
        double A_left = i > 0 ? A[i - 1] : -1e18;
        double A_right = i < n ? A[i] : 1e18;

        // 获取 B 数组切割位置左右两边的值
        double B_left = j > 0 ? B[j - 1] : -1e18;
        double B_right = j < m ? B[j] : 1e18;

        // 如果左半部分所有元素都小于等于右半部分所有元素，说明切割合法
        if (A_left <= B_right && B_left <= A_right) {
            // 左半部分最大值
            double max_left = A_left > B_left ? A_left : B_left;

            // 如果总长度为奇数，中位数就是左半部分最大值
            if (total % 2 == 1) {
                return max_left;
            }

            // 右半部分最小值
            double min_right = A_right < B_right ? A_right : B_right;

            // 如果总长度为偶数，中位数是左半部分最大值和右半部分最小值的平均值
            return (max_left + min_right) / 2.0;
        }

        // 如果 A 左边的值大于 B 右边的值，说明 A 切割位置需要左移
        else if (A_left > B_right) {
            right = i - 1;
        }

        // 否则 A 切割位置需要右移
        else {
            left = i + 1;
        }
    }

    return 0.0;
}
```

### 面试问答

**1. 本题的核心思路是什么？**

二分法。我们把这两个有序数组各切一刀，让左边一共刚好有 `(m+n+1)//2` 个元素，并且满足：左边所有数都小于等于右边所有数。因为数组本身有序，所以只需要比较切口附近的四个数：`A_left、A_right、B_left、B_right`。只要满足 `A_left <= B_right` 且 `B_left <= A_right`，说明切割合法，中位数就可以直接由左边最大值和右边最小值得到。

为了做到 $O(log(min(n , m)))$，我们只在较短的数组上二分切割位置。假设当前在 `A` 里切了 `i` 个数，那么 `B` 里应该切 `half - i` 个数。每次检查切口：如果 `A_left > B_right`，说明 `A` 左边拿多了，要把 `i` 往左调；如果 `B_left > A_right`，说明 `A` 左边拿少了，要把 `i` 往右调。这样不断二分，最终找到合法切割点，再根据总长度奇偶返回答案。
