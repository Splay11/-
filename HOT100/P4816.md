**思路：**

这题第一眼看上去是区间题，但实际上做法非常直接。

因为题目已经把两个区间**列表都排好序了**，并且**每个列表内部互不相交**。这两个条件一给出来，双指针基本就呼之欲出了。

**先想最核心的问题：两个区间什么时候有交集？**

假设现在有两个区间：

$$
[a,b],\quad [c,d]
$$

它们的交集是什么？

其实直接取：

* 左端点取较大值
* 右端点取较小值

也就是：

$$
[\max(a,c),\min(b,d)]
$$

但这个区间不一定存在，只有当

$$
\max(a,c)\le \min(b,d)
$$

时，它们才真的有交集。

比如：

* $[0,2]$ 和 $[1,5]$ 的交集是 $[1,2]$
* $[5,10]$ 和 $[8,12]$ 的交集是 $[8,10]$
* $[0,2]$ 和 $[3,4]$ 没有交集，因为左端点已经比右端点大了

所以这题最基本的结论就是：

> 两个闭区间的交集，直接取左端点最大值、右端点最小值；如果左不超过右，那么这个交集有效。

---

**那么双指针该怎么动？**

设：

* `i` 指向 `firstList` 当前区间
* `j` 指向 `secondList` 当前区间

也就是说，我们每次只看：

* `firstList[i]`
* `secondList[j]`

先判断这两个区间有没有交集，如果有，就把交集加入答案。

接下来关键问题来了：

> 处理完这两个区间后，谁该往后走？

这一步才是整道题的核心。

---

**为什么每次移动右端点更小的那个区间？**

假设当前比较的是：

$$
[a,b],\quad [c,d]
$$

如果 $b<d$，说明第一个区间更早结束。

那第一个区间和第二个区间的交集已经算完了，第一个区间以后**不可能再和 `secondList[j]` 后面的更靠右区间产生更好的重叠机会**，因为它自己已经结束了。

所以这时候应该让第一个区间往后走，也就是 `i += 1`。

同理：

* 如果 $d<b$，就让 `j += 1`
* 如果 $b=d$，两个区间同时结束，移动哪个都可以，通常移动任意一个即可；当然两个都移动也可以

```python
class Solution:
    def intervalIntersection(self, firstList: List[List[int]], secondList: List[List[int]]) -> List[List[int]]:
        # 定义两个指针，分别指向两个区间列表
        i = 0
        j = 0
        
        # 存储所有交集区间
        ans = []

        # 当两个指针都没有越界时，继续比较
        while i < len(firstList) and j < len(secondList):
            # 取出当前两个区间
            a, b = firstList[i]
            c, d = secondList[j]

            # 计算当前两个闭区间的交集
            left = max(a, c)
            right = min(b, d)

            # 如果 left <= right，说明存在交集
            if left <= right:
                ans.append([left, right])

            # 谁的右端点更小，谁先结束，谁就先向后移动
            if b < d:
                i += 1
            else:
                j += 1

        # 返回所有交集区间
        return ans
```

int max(int a, int b) {
    return a > b ? a : b;

int min(int a, int b) {

int** intervalIntersection(
    int** firstList,
    int firstListSize,
    int* firstListColSize,
    int** secondList,
    int secondListSize,
    int* secondListColSize,
    int* returnSize,
    int** returnColumnSizes
) {
    // 定义两个指针，分别指向两个区间列表
    int i = 0;
    int j = 0;

    // 交集数量最多不会超过 firstListSize + secondListSize
    int maxSize = firstListSize + secondListSize + 5;

    // 存储所有交集区间
    int** ans = (int**)malloc(sizeof(int*) * maxSize);

    // 记录每个交集区间的列数，都是 2
    *returnColumnSizes = (int*)malloc(sizeof(int) * maxSize);

    // 记录交集区间数量
    *returnSize = 0;

    // 当两个指针都没有越界时，继续比较
    while (i < firstListSize && j < secondListSize) {
        // 取出当前两个区间
        int a = firstList[i][0];
        int b = firstList[i][1];
        int c = secondList[j][0];
        int d = secondList[j][1];

        // 计算当前两个闭区间的交集
        int left = max(a, c);
        int right = min(b, d);

        // 如果 left <= right，说明存在交集
        if (left <= right) {
            ans[*returnSize] = (int*)malloc(sizeof(int) * 2);
            ans[*returnSize][0] = left;
            ans[*returnSize][1] = right;

            (*returnColumnSizes)[*returnSize] = 2;
            (*returnSize)++;
        }

        // 谁的右端点更小，谁先结束，谁就先向后移动
        if (b < d) {
            i++;
        } else {
            j++;
        }
    }

    // 返回所有交集区间
    return ans;
}

### 面试问答

**1. 本题的核心思路是什么？**

利用两个区间列表都已经按起点排序，且各自内部互不相交这一性质，使用同向双指针分别扫描两个列表。每次取当前两个区间，先用 $\max(l_1,l_2),\min(r_1,r_2)$ 判断是否存在交集；如果存在就加入答案。然后比较两个区间的右端点，**谁的右端点更小，谁就先结束，谁的指针就先后移**，因为这个区间不可能再和后面的区间产生新的交集。这样两个指针都只会单调向右移动一次。

**时间复杂度是$O(n+m)$，其中 $n,m$ 分别是两个区间列表的长度；**
