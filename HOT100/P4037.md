**思路：数组翻转法**

这道题本质就是要将前 n-k 个元素 和 后 k 个元素进行调转

那么我们可以先将整个数组进行翻转，然后再分别翻转前 k 个元素和后 n-k 个元素

```python
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        # 获取数组长度
        n = len(nums)
        
        # 如果数组为空，直接返回
        if n == 0:
            return
        
        # 避免 k 超过数组长度
        k %= n
        
        # 翻转整个数组
        nums.reverse()
        
        # 翻转前 k 个元素
        nums[:k] = reversed(nums[:k])
        
        # 翻转后 n - k 个元素
        nums[k:] = reversed(nums[k:])
```

        /*
            旋转数组
        */
        int n = nums.size();
        
        if (n == 0) {
            return;
        }

        reverse(nums.begin(), nums.end());  // 翻转整个数组
        
        reverse(nums.begin(), nums.begin() + k);  // 翻转前 k 个元素
        
        reverse(nums.begin() + k, nums.end());  // 翻转后 n - k 个元素
    }
};

class Solution {
    public void rotate(int[] nums, int k) {
        /*
            旋转数组
        */
        int n = nums.length;
        
        if (n == 0) {
            return;
        }
        
        k %= n;  // 避免 k 超过 n
        
        reverse(nums, 0, n - 1);  // 翻转整个数组
        
        reverse(nums, 0, k - 1);  // 翻转前 k 个元素
        
        reverse(nums, k, n - 1);  // 翻转后 n - k 个元素
    }
    
    public void reverse(int[] nums, int left, int right) {
        while (left < right) {
            int temp = nums[left];
            nums[left] = nums[right];
            nums[right] = temp;
            left++;
            right--;
        }
    }
}

void reverse(int* nums, int left, int right) {
    while (left < right) {
        int temp = nums[left];
        nums[left] = nums[right];
        nums[right] = temp;
        left++;
        right--;
    }
}

void rotate(int* nums, int numsSize, int k) {

    }

    k %= numsSize;

    reverse(nums, 0, numsSize - 1);
    reverse(nums, 0, k - 1);
    reverse(nums, k, numsSize - 1);
}

**k为什么要取余？**

因为要考虑$k \geq n$ 的情况，例如：

$k = n$ 时，轮转完会回到原位置，等价于$k = 0$

$k = n + 1$ 的时候，等价于往后挪了一格,$k=1$。

所以对于$k \geq n$ 的情况，自然是需要取余的。

### 面试问答

**1.本题是什么思路？**

本题需要将前 n-k 个元素 和 后 k 个元素进行调转 ， 我们可以先将整个数组进行翻转，然后再分别翻转前 k 个元素和后 n-k 个元素。

三轮操作不会超过$2n$ 次计算，时间复杂度为$O(n)$ , 由于没有使用额外的空间辅助计算，空间复杂度为$O(1)$
