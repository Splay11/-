**思路**

## 直径的形态

**重要结论**：由于直径是最长的路径，那么它的两个端点**不可能是二叉树的内部节点** ， 只能是根 / 叶子节点

证明:

假设一条路径的某一个端点：

如果不是叶子节点，那么它一定可以往下走一步得到更长的路径。

如果它不是根节点，那么它一定可以往上走一步得到更长的路径。


![img](https://codefun2000.com/p/4251/file/%E7%9B%B4%E5%BE%84%E7%9A%84%E7%AB%AF%E7%82%B9%E5%88%86%E6%9E%90.svg?type=additional_file)

所以直径的起点和终点只能是：$\{根,叶子节点\}$中的一种 ,**不可能是树的内部节点**


由此我们可以推出直径的**两种可能形态**：

1.从根节点出发的最长路径 ： 起点是根，终点是叶子节点

2.以树中某个节点为拐点 , 路径结构为：`左子树的最长路径 -> 拐点 -> 右子树的最长路径` 。 即起点和终点都是叶子节点。

## 统一形态

对于直径的第一种形态，它同样可以被规约到`左子树的最长路径 -> 拐点 -> 右子树的最长路径` 这种结构下。**我们只需要将其中一个子树的最长路径长度看作-1即可**

受到[LeetCode 104. 二叉树的最大深度](https://codefun2000.com/codenote/hot100/P0062#%E8%A7%A3%E6%B3%952%EF%BC%9A%E8%87%AA%E5%BA%95%E5%90%91%E4%B8%8A%E7%9A%84dfs)的启发，左子树的最长路径 ， 右子树的最长路径 这两个部分可以使用**自底向上的DFS**求解得到。

此时唯一的问题就是我们并不知道哪个点是直径的拐点，那么我们就只需要**枚举**所有点作为拐点，然后计算答案的最大值即可。


## 做法：自底向上的DFS

对于节点`node` , 先递归求解左子树的最长路径长度`maxDepth_L`，再递归求解右子树的最长路径长度`maxDepth_R`。

接着以该点为拐点的答案为:`maxDepth_L + maxDepth_R + 2`（$2$是该节点连向左右两个儿子的边） 。对所有节点的答案取最大值就是直径。
 
接着返回值为`max(left_max+right_max + 1)` （$1$是该节点连向左右两个儿子中的**其中一条边**）

具体的

1.定义 `dfs(node)`  的返回值：以`node` 为拐点的最长路径长度。

2.定义 全局变量 `ans` 代表全局答案最大值。

2.每次`dfs`时，
    2.1 计算`left_max = dfs(左儿子)`
    2.2 计算`right_max = dfs(右儿子)`
    2.3 `ans = max(ans , left_max + right_max + 2)`
    2.4 返回以`node`为根的最长路径长度:`return max(left_max+right_max + 1)`

3.整个算法结束之后，`ans` 就是直径长度

```python
class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        # 空树直径为 0
        if root is None:
            return 0

        # ans 记录全局最长路径长度，路径长度按边数计算
        ans = 0

        # dfs(node): 返回以 node 为起点，向下走到最深叶子的最长路径长度
        # 空节点返回 -1，这样叶子节点左右子树都是 -1，叶子节点返回 0
        def dfs(node):
            nonlocal ans

            if node is None:
                return -1

            # 先递归求左子树向下的最长路径
            left_max = dfs(node.left)

            # 再递归求右子树向下的最长路径
            right_max = dfs(node.right)

            # 枚举当前节点作为拐点
            # 左边贡献 left_max + 1 条边，右边贡献 right_max + 1 条边
            cur = left_max + right_max + 2

            # 更新全局直径最大值
            if cur > ans:
                ans = cur

            # 返回当前节点向下走的最长路径长度
            return 1 + max(left_max, right_max)

        dfs(root)
        return ans
```

### 面试问答

**1. 本题的核心思路是什么？**

枚举每个节点作为拐点，计算经过该拐点的最长路径长度。所有拐点的最长路径长度中的最大值就是直径。

所以我们可以自底向上的DFS,定义`dfs(node)` 返回以 `node` 为根向下的最长路径长度（按边数）。接着每次递归得到左子树最长路径 `left_max` 和右子树最长路径 `right_max` 后，用 `left_max + right_max + 2` 更新全局最优解。递归结束得到直径长度。
