## 解法1:自顶向下的DFS

#warning-box

**什么是自顶向下的DFS**？

这个方法也称作爆搜法。

本方法的特征是：

1.不拆分子问题，而是用递归暴力的搜寻所有可能。每次搜寻到一种结果就记录下来。

2.无需定义递归函数的返回值，使用**全局变量**记录答案。但是需要在递归函数中记录当前搜寻的状态。

#warning-box

既然我们不能确定最远的叶子节点在哪，那么我们利用递归，**直接搜寻 根节点到所有叶子节点的路径长度 ， 每次到达一个新的叶子节点，就说明找到了一个可能的方案，记录下来** 。 

最后全局最大值就是答案。因为此时我们已经到达过了所有叶子节点，那么最远的那一个肯定也被我们访问并记录下来过了！

## 代码实现

```python
class Solution:
    def maxDepth(self, root):
        # 空树深度为 0
        if root is None:
            return 0

        # 全局记录答案
        ans = 0

        # dfs(node, depth): 当前来到 node，且 node 所在深度为 depth
        def dfs(node, depth):
            nonlocal ans

            if node is None:
                return

            # 到达叶子节点，尝试更新答案
            if node.left is None and node.right is None:
                if depth > ans:
                    ans = depth
                return

            # 继续向下搜索左右子树
            dfs(node.left, depth + 1)
            dfs(node.right, depth + 1)

        dfs(root, 1)
        return ans
```

## 解法2：自底向上的DFS

#warning-box

**什么是自底向上的DFS**？

将当前问题拆解成若干个**子问题**，让递归函数先去算子问题的解，最后将子问题合并。

本方法的特征是：

1.需要定义递归函数的返回值。

2.实际计算顺序是从底向上的。比如在这个问题里，是一开始先计算叶子节点的结果，然后逐步往上计算其他内部节点的值，最后才会得到根节点的值。

#warning-box

从根节点出发的最大深度 可以拆分成两个子问题： 

子问题1：从根节点走到**左子树**，在左子树中继续寻找最大深度

子问题2：从根节点走到**右子树**，在右子树中继续寻找最大深度

两个子问题的答案合并取最大值即可：最大深度 :1(来自根节点) +  max(左子树的最大深度 , 右子树的最大深度)，如此递归即可求解。

具体的：

1.定义 `dfs(node)`  的返回值：以`node` 为根节点的最大深度。

2.返回值逻辑:`return max(dfs(左儿子) , dfs(右儿子)) + 1`

```python
class Solution:
    def maxDepth(self, root):
        # 空树深度为 0
        if root is None:
            return 0

        # dfs(node): 返回以 node 为根节点的最大深度
        def dfs(node):
            # 空节点深度为 0
            if node is None:
                return 0

            # 先递归求左子树的最大深度
            left_depth = dfs(node.left)

            # 再递归求右子树的最大深度
            right_depth = dfs(node.right)

            # 当前节点的最大深度 = 1 + 左右子树最大深度的较大值
            return 1 + max(left_depth, right_depth)

        return dfs(root)
```

### 面试问答

**1.解法1（自顶向下的DFS）的核心思路是什么**？

把“当前深度”作为递归参数一路往下传。每到一个叶子节点，就得到一条根到叶子的路径长度，用全局变量更新最大值，最终得到整棵树的最大深度。

**2.解法2（自底向上的DFS）的核心思路是什么**？

从根节点出发的最大深度，要么往左子树走找到一个最大深度，要么往右子树走找到一个最大深度，两者取最值即可。这个过程利用递归求解。

**3. 解法1和解法2的主要区别是什么**？

解法1是自顶向下，思想是直接暴力搜索所有可能。`dfs(node, depth)` 传递状态，在叶子处更新全局答案，不依赖返回值合并。

解法2是自底向上，思想是我不亲自搜索所有可能，而是让递归函数帮我把子问题算好，然后我再去合并。所以`dfs(node)` 有明确返回值，返回子树最大深度，再做 `1 + max(...)` 合并。
