**思路**

维护一个当前能到达的最大右边界$right$，一开始$right = 1$ 。 从左往右循环，每次考虑$i + nums[i]$ 是否能将右边界$right$ 往右推进，即$right = max(right,i + nums[i])$ 。 当循环过程中$i > right$ 则循环终止。

class Solution:
    def canJump(self, nums: List[int]) -> bool:
        right = 0  # 当前可以跳跃到的最远下标
        n = len(nums)

        for i in range(n):
            # 如果当前位置不可达，则返回 False
            if i > right:
                return False

            # 更新最远可以到达的下标
            right = max(right, i + nums[i])

            # 如果可以到达最后一个下标，直接返回 True
            if right >= n - 1:
                return True

        return False

### 面试问答

**1. 本题的核心思路是什么？**

贪心。维护一个当前能到达的最大右边界，一开始等于$1$。 从左往右循环，每次考虑当前位置能跳跃到的位置是否能推动右边界， 如果可以则更新右边界。 循环过程中任意时刻下标超过右边界则循环终止。循环结束时，如果右边界大于等于最后一个下标则满足，否则无法到达。
