**思路**

在上一章里我们使用了线性dp的思路解决本题。而本题同时也可以使用完全背包模型解决。

本问题可以建模成：

给定一个物品数组$a_1,a_2,...,a_n$ 分别代表它们的容积。使用最少的物品装满容积为$amount$的背包。**每个物品有无限个**

**做过了第一题，大家先自行想想本题的状态和转移。**


状态，不难想到：

$dp_{i , j}$ 代表使用前$i$个物品，装满容积为$j$的背包，所需要的最少物品个数。

转移： 

选不选$a_i$来转移。

不选:$dp_{i-1,j} \rightarrow dp_{i,j}$


选:$dp_{i,j - a_i } \rightarrow dp_{i,j}$

**这也是和01背包的重要区别：**因为物品有无限个，所以选中$a_i$ 之后，手上的物品集合还是$\{a_1,a_2,...,a_i\}$

转移:$dp_{i , j} = min(dp_{i - 1 , j} , dp_{i , j - a_i} + 1)$

边界条件:$dp_{i,0} = 0$

$dp_{i,k} = +\infty , k > 0$

因为一开始时我们应当假定任意容积的物品都组成不了。

换句话说，要求最小值，一开始数组应该定义为最大值。

```python id="vi3s2y"
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        # 初始化 dp 数组，大小为 amount+1，初始值为 inf
        n = len(coins)
        dp = [[float('inf')] * (amount + 1) for _ in range(n + 1)]

        for i in range(n + 1):
            dp[i][0] = 0  # 金额为 0 时需要 0 个硬币

        for i in range(1, n + 1):
            for j in range(amount + 1):
                dp[i][j] = dp[i - 1][j]  # 不选当前硬币

                if j >= coins[i - 1]:  # 如果当前金额不小于当前硬币面值
                    dp[i][j] = min(dp[i][j], dp[i][j - coins[i - 1]] + 1)  # 选当前硬币

        return dp[n][amount] if dp[n][amount] != float('inf') else -1
```

```c id="ll0aus"
int coinChange(int* coins, int coinsSize, int amount) {
    // 初始化 dp 数组，大小为 amount+1，初始值为 inf
    int n = coinsSize;
    int inf = amount + 1;

    int** dp = (int**)malloc(sizeof(int*) * (n + 1));
    for (int i = 0; i <= n; i++) {
        dp[i] = (int*)malloc(sizeof(int) * (amount + 1));
        for (int j = 0; j <= amount; j++) {
            dp[i][j] = inf;
        }
    }

    for (int i = 0; i <= n; i++) {
        dp[i][0] = 0; // 金额为 0 时需要 0 个硬币
    }

    for (int i = 1; i <= n; i++) {
        for (int j = 0; j <= amount; j++) {
            dp[i][j] = dp[i - 1][j]; // 不选当前硬币

            if (j >= coins[i - 1]) { // 如果当前金额不小于当前硬币面值
                if (dp[i][j - coins[i - 1]] + 1 < dp[i][j]) {
                    dp[i][j] = dp[i][j - coins[i - 1]] + 1; // 选当前硬币
                }
            }
        }
    }

    int ans = dp[n][amount] != inf ? dp[n][amount] : -1;

    for (int i = 0; i <= n; i++) {
        free(dp[i]);
    }
    free(dp);

    return ans;
}
```

**原地优化**

**用一行数组$f$原地顺序转移**   ：$f[j] = min(f[j]\ ,\ f[j - a_i])$

相较于01背包，完全背包的转移是:$dp_{i , j} = min(dp_{i - 1 , j} , dp_{i , j - a_i})$   ， 如下图所示👇

那么如果用一行数组，$f[j - a_i]$ 应当先于$f[j]$  从含义$dp[i - 1]$ 转移至 $dp[i]$

```python
class Solution:
    def coinChange(self, coins, amount):
        # f[j] 表示凑出金额 j 所需要的最少硬币数
        # 一开始假设所有金额都无法凑出，用 amount + 1 表示无穷大
        f = [amount + 1] * (amount + 1)
        # 金额为 0 时，不需要任何硬币
        f[0] = 0

        # 枚举每一种硬币
        for coin in coins:
            # 完全背包中，每种硬币可以无限使用，所以金额从小到大枚举
            for j in range(coin, amount + 1):
                # 选当前硬币：从 j - coin 转移过来，再多用 1 枚硬币
                f[j] = min(f[j], f[j - coin] + 1)

        # 如果仍然是无穷大，说明无法凑出 amount
        return -1 if f[amount] == amount + 1 else f[amount]
```
