**思路**

本题相对简单，不涉及过多的分析。写过第一题基本就会。我们只需要从左到右维护一个**固定大小**的滑动窗口，以及两个哈希表。一个哈希表用来维护这个窗口内字符出现的频次，另一个哈希表用来维护$p$的字符出现频次即可。

class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        n, m = len(s), len(p)

        # 如果 s 的长度小于 p 的长度，
        # 那么 s 中不可能存在 p 的异位词子串
        if n < m:
            return []

        cnt_p = [0] * 26   # 统计字符串 p 中每个字母出现的次数
        cnt_s = [0] * 26   # 统计当前滑动窗口中每个字母出现的次数

        # 统计 p 中每个字符的频次
        for ch in p:
            cnt_p[ord(ch) - ord('a')] += 1

        # 统计 s 的第一个长度为 m 的窗口中每个字符的频次
        for i in range(m):
            cnt_s[ord(s[i]) - ord('a')] += 1

        ans = []   # 用来保存所有满足条件的起始下标

        # 先检查第一个窗口是否和 p 的字符频次完全相同
        if cnt_s == cnt_p:
            ans.append(0)

        # 固定大小滑动窗口：每次向右移动一格
        for i in range(m, n):
            # 将新进入窗口的字符 s[i] 加入统计
            cnt_s[ord(s[i]) - ord('a')] += 1

            # 将滑出窗口的字符 s[i - m] 移出统计
            cnt_s[ord(s[i - m]) - ord('a')] -= 1

            # 如果当前窗口和 p 的字符频次完全相同，
            # 说明当前窗口是 p 的一个异位词
            if cnt_s == cnt_p:
                ans.append(i - m + 1)

        return ans

### 面试问答

#### 1.这个算法的整体思路是什么？

这道题的整体思路是：**固定长度滑动窗口 + 哈希表统计频次**。

具体的，先用一个哈希表统计字符串$p$的出现频次。再用一个固定大小的滑动窗口+哈希表去从左往右枚举每一个子串，统计当前子串的字符频次，过程中动态地更新哈希表。

#### 2.这个算法的复杂度是多少？

假设$s,p$的长度都是$n$这个量级 ,则时间复杂度是 $O(n)$ 。 因为窗口小于等于$n$个 ， 而哈希的插入和删除为$O(1) $，对于每个窗口，哈希表的比较次数最多为26次（小写字母的个数）。所以计算次数是$26 * n = O(n)$ ，26这个常数在复杂度中是忽略不计的。
