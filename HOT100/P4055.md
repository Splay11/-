## 解法1：镜像递归（自顶向下的DFS）

对于根节点来说，要想整棵树对称，必须满足：

1.左子树的根值 == 右子树的根值

2.左子树的左孩子 和 右子树的右孩子 互为镜像

3.左子树的右孩子 和 右子树的左孩子 互为镜像

所以我们定义一个递归函数 `is_mirror(a, b)`：

1.如果 `a` 和 `b` 都空，说明这一层对称，返回 `True`

2.如果一个空一个非空，不对称，返回 `False`

3.如果值不等，不对称，返回 `False`

4.否则继续递归比较“外侧”和“内侧”两组孩子

最后调用 `is_mirror(root.left, root.right)` 即可。

```python id="vuo3kt"
class Solution:
    def isSymmetric(self, root):
        # 空树天然对称
        if root is None:
            return True

        def is_mirror(a, b):
            # 两边都为空，说明这一层对称
            if a is None and b is None:
                return True

            # 一边为空，一边不为空，说明不对称
            if a is None or b is None:
                return False

            # 当前两个节点的值不同，说明不对称
            if a.val != b.val:
                return False

            # 继续递归比较外侧和内侧
            return is_mirror(a.left, b.right) and is_mirror(a.right, b.left)

        # 整棵树是否对称，等价于根节点的左右子树是否互为镜像
        return is_mirror(root.left, root.right)
```

### 面试问答

**1. 本题的核心思路是什么？**

核心就是把“整棵树是否对称”转成“左右两棵子树是否互为镜像”。我会写一个 `is_mirror(a, b)`，每次同时看两边节点：值要相等，且左边的左孩子要和右边的右孩子对应，左边的右孩子要和右边的左孩子对应。这个递归把镜像关系层层往下传，最终就能判断整棵树是否轴对称。

**2. 为什么比较的是 `a.left` 对 `b.right`，而不是 `a.left` 对 `b.left`？**

因为我们比较的是“镜像”而不是“相同”。镜像要求左右翻转，所以必须交叉比较：外侧对外侧、内侧对内侧。若写成同侧比较，就变成判断两棵树是否相同了，不是本题目标。

**3. 复杂度是多少？**

每个节点最多访问一次，时间复杂度 `O(n)`；递归栈深度最坏 `O(n)`（退化链），平衡树时约 `O(log n)`。
