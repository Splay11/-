### 思路

其实很简单，考虑一个函数:$f(i)$ , 代表 固定左端点$i$，右端点最远能达到的下标，用一个动画来演示一下👇

@[video](https://codefun2000.com/p/3934/file/%E6%97%A0%E9%87%8D%E5%A4%8D%E5%AD%97%E7%AC%A6%E7%9A%84%E6%9C%80%E9%95%BF%E5%AD%90%E4%B8%B2.mp4)


很容易感觉出来，**$f(i)$ 随$i$ 单调非减**，因为$f(i)$ 相较于$f(i-1)$ 而言少了一个`s[i-1]` , 相当于冲突的概率下降了👇

![](/file/2/YDU3BIg_72aCbt4hSNLHn.png =70%x)


答案就是$max(f(1)-1+1,f(2)-2+1,...,f(n)-n+1)$ , 因为这考虑了所有的情况。所以我们如果能对每个$i$都求出$f(i)$ , 取最大值不就完事了。

**双指针呼之欲出**:枚举左端点$i$ , **让右端点$j$找$f(i)$ **,  找到之后$i$ 右移动 ， 右端点基于$f(i)$ 寻找$f(i + 1)$

总结：左端点$i$枚举起点，右端点$j$寻找$f(i)$ 。 两个指针各司其职。不回退的原因是$f$ 单调非减。

class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        # 维护当前窗口中的字符集合
        st = set()
        
        # 获取字符串长度
        n = len(s)
        
        # j 表示当前窗口的右端点
        j = -1
        
        # 记录最长无重复字符子串的长度
        ans = 0
        
        # i 枚举窗口左端点
        for i in range(n):
            # 不断向右扩展 j，直到遇到重复字符或到达字符串末尾
            while j < n - 1 and s[j + 1] not in st:
                st.add(s[j + 1])
                j += 1
            
            # 更新最长无重复字符子串的长度
            ans = max(ans, j - i + 1)
            
            # 左端点右移前，将当前左端点字符从集合中移除
            st.remove(s[i])
        
        # 返回最长无重复字符子串的长度
        return ans

### 面试问答

#### 1.这个算法的整体思路是什么？

双指针做法里，左指针 $i$ 负责枚举每个位置作为子串起点，右指针 $j$ 负责在当前左端点下尽量向右扩展，找到最远的不重复子串。
每次求出当前窗口的答案后，再移动左指针继续处理下一个起点。

#### 2.为什么这么做是对的？

这个算法本质上是在枚举每个左端点，并维护对应的最远合法右端点；由于这个右端点随着左端点具有单调性，所以指针无需回退。
也就是说，右指针整体只会单调向右移动，不会漏掉答案，因此时间复杂度是 $O(n)$

#### 思考题

大部分讲解是枚举右端点，缩左端点，其实本质一样，大家自行思考这份代码正确性：

int lengthOfLongestSubstring(char *s) {
    // 记录当前窗口内出现过的字符
    int st[256] = {0};

    // 获取字符串长度
    int n = strlen(s);

    // 左指针
    int i = 0;

    // 记录最长无重复字符子串长度
    int ans = 0;

    // 右指针不断向右扩展
    for (int j = 0; j < n; j++) {
        unsigned char ch = s[j];

        // 如果 s[j] 已经在集合中，说明当前窗口出现重复
        while (st[ch]) {
            // 移除左指针对应字符，缩小窗口
            unsigned char leftChar = s[i];
            st[leftChar] = 0;
            i++;
        }

        // 将当前字符加入窗口
        st[ch] = 1;

        // 当前窗口 [i, j] 一定无重复，更新答案
        if (j - i + 1 > ans) {
            ans = j - i + 1;
        }
    }

    // 返回最长无重复字符子串长度
    return ans;
}
