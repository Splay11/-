**思路**

我们要找的是当前数组的 **下一个排列**。

所谓“下一个排列”，就是找：**刚好比当前排列大一点点的排列。**

也就是说，字典序要变大，但增长幅度要尽可能小。

## **发现 1：下一个排列一定会让某个靠前的位置变大**

字典序是从左往右比较的。

比如：

```
123654
124356
```

这两个排列从左往右比较：

```
1 = 1
2 = 2
3 < 4
```

所以 `124356` 比 `123654` 大。

因此，如果想让排列变大，就需要找到一对位置 `i, j`，满足：

```
i < j 且 nums[i] < nums[j]
```

然后把右边更大的数 `nums[j]` 换到前面来，让位置 `i` 的值变大。

例如：

```
123 -> 132
```

交换的是 `2` 和 `3`。

## **发现 2：交换位置 `i` 要尽量靠右**

**越靠前的位置变大，对整体字典序的影响就越大**

举个例子，当前排列是：

```
1 2 3 6 5 4
```

如果我们一开始就把很靠前的 `1` 换大，可能得到：

```
2 1 3 6 5 4
```

这个排列当然变大了，但是变得太多了。

如果我们让更靠后的 `3` 变大，可能得到：

```
1 2 4 6 5 3
```

这个排列也比原来大，但前面的 `1 2` 都没有变，只是更靠后的位置变大了，所以整体增长更小。

**那么如何找到最靠右的，满足存在$j \in [i+1,n]$ ，使得$nums[i] < nums[j]$的位置$i$呢？**

## 发现 3：当 `i` 确定后，`j` 要选尽量小的那个

还是这个数组：

```
1 2 3 6 5 4
```

我们已经确定要让 `3` 这个位置变大。

它右边有：

```
6 5 4
```

这些数都比 `3` 大，都可以拿来交换。

如果和 `6` 交换：

```
1 2 6 3 5 4
```

如果和 `5` 交换：

```
1 2 5 6 3 4
```

如果和 `4` 交换：

```
1 2 4 6 5 3
```

此时关注它们的前缀部分:

```
1 2 4 ...
1 2 5 ...
1 2 6 ...
```

显然，选择$min(4,5,6)=4$ 是让字典序增长尽量小的选择。

## 发现 4：交换完成后，`i` 后面的部分要变成最小（升序序列）

举个例子：

```
1 2 3 6 5 4
```

我们已经知道，应该让 `3` 和右边最小的较大数 `4` 交换：

```
1 2 4 6 5 3
```

**但是这个结果还不是下一个排列，因为`i` 后面的部分还是降序状态**

```
6 5 3
```

为了让整体尽可能小，后面应该**翻转成升序**：

```
3 5 6
```

所以最终结果应该是：

```
1 2 4 3 5 6
```

也就是：

```
123654 -> 124356
```

这才是 `123654` 的下一个排列。

**为什么直接翻转即可？**

因为我们找 `i` 的方式是：

> 从右往左找第一个满足 `nums[i] < nums[i + 1]` 的位置。

这说明在 `i` 的右边，原本就是一个 **降序区间**。

例如：

```
1 2 3 6 5 4
```

从左往右看：

```
6 5 4
```

是降序的。

也就是说，`i` 后面的部分本来就是从大到小排好的：

```
6 5 4
```

交换之后，**这一段一定会继续保持降序结构**：

```
6 5 3
```

想让它变成最小，只需要翻转一下：

```
6 5 3 -> 3 5 6
```

所以最后一步是：

> 交换 `nums[i]` 和 `nums[j]` 后，把 `i + 1` 到数组末尾这一段翻转。

#warning-box

## **完整步骤**

1. 从右往左找到第一个位置 $i$，满足 $nums[i] < nums[i + 1]$

2. 如果找不到，说明整个数组是降序的
   此时已经是最大排列，直接翻转整个数组，变成最小排列

3. 如果找到了 $i$
   再从右往左找到第一个位置 $j$，满足 $nums[j] > nums[i]$

4. 交换 $nums[i]$ 和 $nums[j]$

5. 翻转 $i + 1$ 到数组末尾这一段

#warning-box

from typing import List
class Solution:
    def nextPermutation(self, nums: List[int]) -> None:
        n = len(nums)
        # 从后往前找第一个比后面小的数
        pos = -1
        for i in range(n-2, -1, -1):
            if nums[i] < nums[i+1]:
                pos = i
                break
        if pos == -1:
            # 没有找到，说明已经是最大的排列了，反转整个数组
            nums.reverse()
            return nums
        # 找到第一个比nums[pos]大的数
        for j in range(n-1, pos, -1):
            if nums[j] > nums[pos]:
                break

        # 交换nums[pos]和nums[j]
        nums[pos], nums[j] = nums[j], nums[pos]

        # 反转pos+1到n-1的元素
        nums[pos+1:] = reversed(nums[pos+1:])
        return nums

class Solution {
public:
    vector<int> nextPermutation(vector<int>& nums) {
        int n = nums.size();

        // 从后往前找第一个比后面小的数
        int pos = -1;
        for (int i = n - 2; i >= 0; i--) {
            if (nums[i] < nums[i + 1]) {
                pos = i;
                break;
            }
        }

        if (pos == -1) {
            // 没有找到，说明已经是最大的排列了，反转整个数组
            reverse(nums.begin(), nums.end());
            return nums;
        }

        // 找到第一个比nums[pos]大的数
        int j;
        for (j = n - 1; j > pos; j--) {
            if (nums[j] > nums[pos]) {
                break;
            }
        }

        // 交换nums[pos]和nums[j]
        swap(nums[pos], nums[j]);

        // 反转pos+1到n-1的元素
        reverse(nums.begin() + pos + 1, nums.end());

        return nums;
    }
};

class Solution {
    public int[] nextPermutation(int[] nums) {
        int n = nums.length;

        // 从后往前找第一个比后面小的数
        int pos = -1;
        for (int i = n - 2; i >= 0; i--) {
            if (nums[i] < nums[i + 1]) {
                pos = i;
                break;
            }
        }

        if (pos == -1) {
            // 没有找到，说明已经是最大的排列了，反转整个数组
            reverse(nums, 0, n - 1);
            return nums;
        }

        // 找到第一个比nums[pos]大的数
        int j;
        for (j = n - 1; j > pos; j--) {
            if (nums[j] > nums[pos]) {
                break;
            }
        }

        // 交换nums[pos]和nums[j]
        int temp = nums[pos];
        nums[pos] = nums[j];
        nums[j] = temp;

        // 反转pos+1到n-1的元素
        reverse(nums, pos + 1, n - 1);

        return nums;
    }

    public void reverse(int[] nums, int left, int right) {
        while (left < right) {
            int temp = nums[left];
            nums[left] = nums[right];
            nums[right] = temp;
            left++;
            right--;
        }
    }
}

var nextPermutation = function (nums) {
    const n = nums.length;
    // 从后往前找第一个比后面小的数
    let pos = -1;
    for (let i = n - 2; i >= 0; i--) {
        if (nums[i] < nums[i + 1]) {
            pos = i;
            break;
        }
    }
    if (pos === -1) {
        // 没有找到，说明已是最大排列，反转整个数组
        nums.reverse();
        return;
    }
    // 从后往前找第一个比 nums[pos] 大的数
    let j = n - 1;
    for (; j > pos; j--) {
        if (nums[j] > nums[pos]) {
            break;
        }
    }
    // 交换 nums[pos] 和 nums[j]
    [nums[pos], nums[j]] = [nums[j], nums[pos]];
    // 反转 pos+1 到末尾，使后缀变为最小字典序
    let left = pos + 1;
    let right = n - 1;
    while (left < right) {
        [nums[left], nums[right]] = [nums[right], nums[left]];
        left++;
        right--;
    }
};

static void reverse_range(int* nums, int left, int right) {
    while (left < right) {
        int tmp = nums[left];
        nums[left] = nums[right];
        nums[right] = tmp;
        ++left;
        --right;
    }
}

void nextPermutation(int* nums, int numsSize) {
    // 从后往前找第一个比后面小的数
    int pos = -1;
    for (int i = numsSize - 2; i >= 0; --i) {
        if (nums[i] < nums[i + 1]) {
            pos = i;
            break;
        }
    }
    if (pos == -1) {
        /* 没有找到，说明已是最大排列，反转整个数组 */
        reverse_range(nums, 0, numsSize - 1);
        return;
    }
    /* 从后往前找第一个比 nums[pos] 大的数 */
    int j = numsSize - 1;
    for (; j > pos; --j) {
        if (nums[j] > nums[pos]) {
            break;
        }

        nums[pos] = nums[j];
        nums[j] = tmp;
    }

    reverse_range(nums, pos + 1, numsSize - 1);

## **总结**

1.**$i$ 尽量靠右**：从后往前循环，找到第一个$nums[i] < nums[i + 1]$ 的位置

2.**$j$尽量小** : 从后往前循环，在$[i + 1 , n]$ 中找到大于$nums[i]$的 最小值的位置。

3.**翻转使后缀变最小** ： 交换完成后，把 $i$ 后面的部分翻转成升序。

## 面试问答

**1. 本题的核心思路是什么？**

思路是找到“刚好比当前排列大一点点”的排列。因为字典序从左往右比较，所以我们希望尽量靠右的位置发生变大，这样整体增幅最小。具体做法是先从右往左找到第一个满足 `nums[i] < nums[i + 1]` 的位置，这个位置就是需要变大的位置；如果找不到，说明整个数组已经是降序，也就是最大排列，直接翻转成最小排列即可。找到 `i` 之后，再从右往左找到第一个比 `nums[i]` 大的数 `nums[j]`，由于右侧本身是降序的，所以从右往左找到的第一个更大值，就是比 `nums[i]` 大的最小值。交换 `nums[i]` 和 `nums[j]` 后，前缀已经变成了刚好更大的状态，最后只需要把 `i + 1` 后面的后缀翻转成升序，让后缀尽可能小，这样得到的就是整个数组的下一个排列。
