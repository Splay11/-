**思路**

这题思路和上面两题模型是一模一样的。

定义$f(i)$代表字符串$s$的前$i$个字符组成的前缀，是否能由字符串列表中的单词组成。

$f(i) \in \{True , False\}$

**转移：**

枚举当前字符串`s[:i]`的一个分割点$j$， 字符串变成:`s[:j]` 和 `s[j+1:i] `， 检查`s[j+1:i]`是否出现在字典中，出现过则判断$f(j)$ 是否合法即可。如果前缀也也能被组成(即$f(j) = true$)，那么整体的$s[:i]$ 能够被组成。

```python
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        n = len(s)

        # dp[i] 表示字符串 s 的前 i 个字符，是否可以由字典中的单词拼接出来
        dp = [False] * (n + 1)

        # 空串可以被成功拼接，作为后续转移的起点
        dp[0] = True

        # 枚举前缀长度 i，判断 s[0:i] 是否可以被拼接
        for i in range(1, n + 1):
            # 枚举最后一次切分的位置 j
            for j in range(i):
                # 如果前 j 个字符可以被拼接，并且 s[j:i] 在字典中
                # 那么前 i 个字符也可以被拼接
                if dp[j] and s[j:i] in wordDict:
                    dp[i] = True
                    break

        return dp[n]
```

```cpp
class Solution {

                // 那么前 i 个字符也可以被拼接

                    break;
                }
            }
        }

        return dp[n];
    }
```

```c
bool wordBreak(char* s, char** wordDict, int wordDictSize) {
    int n = 0;

    // 计算字符串长度
    while (s[n] != '\0') {
        n++;
    }

    // dp[i] 表示字符串 s 的前 i 个字符，是否可以由字典中的单词拼接出来
    bool* dp = (bool*)malloc(sizeof(bool) * (n + 1));

    for (int i = 0; i <= n; i++) {
        dp[i] = false;
    }

    // 空串可以被成功拼接，作为后续转移的起点
    dp[0] = true;

    // 枚举前缀长度 i，判断 s[0:i] 是否可以被拼接
    for (int i = 1; i <= n; i++) {
        // 枚举最后一次切分的位置 j
        for (int j = 0; j < i; j++) {
            if (!dp[j]) {
                continue;
            }

            // 枚举字典中的每个单词，判断它是否等于 s[j:i]
            for (int k = 0; k < wordDictSize; k++) {
                char* word = wordDict[k];
                int len = 0;

                while (word[len] != '\0') {
                    len++;
                }

                if (len != i - j) {
                    continue;
                }

                bool same = true;
                for (int p = 0; p < len; p++) {
                    if (s[j + p] != word[p]) {
                        same = false;
                        break;
                    }
                }

                // 如果前 j 个字符可以被拼接，并且 s[j:i] 在字典中
                // 那么前 i 个字符也可以被拼接
                if (same) {
                    dp[i] = true;
                    break;
                }
            }

            // 找到一种切分方式即可退出
            if (dp[i]) {
                break;
            }
        }
    }

    bool ans = dp[n];
    free(dp);

    return ans;
}
```

### 面试问答

**1.这道题的思路是什么？**

动态规划。定义 dp[i] 表示字符串前 i 个字符能不能被字典里的单词拼出来。我们去枚举一个切分点 j，把字符串分成两部分：前缀 s[0:j] 和 后缀 s[j:i]。如果前面这一段是可以拼出来的，并且后面这一段刚好在字典里，那当前这个位置 i 就是可以拼出来的。所以本质就是：枚举最后一段，看看能不能合法切开。初始化 dp[0] = True，表示空字符串是可以被拼出来的。从小往大进行枚举计算dp数组， 最后答案就是 dp[n]的结果。时间复杂度是 O(n²)。
