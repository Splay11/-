# 题目内容

给定一个包含数字 $2-9 $的字符串，返回该数字可能

表示的所有字母组合。以字典顺序返回答案。数字与字母的映射(就像电话按钮上的数字一样)

如下所示。请注意，数字$1$不对应任何字母。映射关系如下:

$2$ -> "$abc$"，$ 3$-> "$def$", $4$-> "$ghi$"，$5$-> "$jkl$"， $6$->"$mno$"，$7$->"$pqrs$"，$8$-> "$tuv$"，$9$-> "$wxyz$"。

# 输入描述

输入为一个仅包含数字$2-9$的字符串，生成所有可能的字母组合。

# 输出描述

输出是一个字符串列表



## 样例1 

**输入** 

```
89
```

**输出** 

```
tw
tx
ty
tz
uw
ux
uy
uz
vw
vx
vy
vz
```


## 样例2

**输入** 

```
6
```

**输出** 

```
m
n
o
```
