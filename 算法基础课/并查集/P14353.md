# 题目描述
如题，现在有一个并查集，你需要完成合并和查询操作。

# 输入格式
第一行包含两个整数 $N,M$ ,表示共有 $N$ 个元素和 $M$个操作。

接下来 $M$ 行，每行包含三个整数 $Z_i,X_i,Y_i$ 。

1. 当 $Z_i=1$ 时，将 $X_i$ 与 $Y_i$ 所在的集合合并。
2. 当 $Z_i=2$ 时，输出 $X_i$ 与 $Y_i$ 是否在同一集合内，是的输出
Y ；否则输出 N 。

$1<=N,M<=10^5$

$1<=X_i,Y_i<=N$
# 输出格式
对于每一个 $Z_i=2$ 的操作，都有一行输出，每行包含一个大写字母，为 $Y$ 或者 $N$ 。

# 样例 
**样例输入**
```
4 7
2 1 2
1 1 2
2 1 2
1 3 4
2 1 4
1 2 3
2 1 4
```
**样例输出**
```
N
Y
N
Y
```
