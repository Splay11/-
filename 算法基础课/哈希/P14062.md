# 题目内容

小红有一个长度为$n$的排列$p$，他想知道$p$中有多少个$i,j$对满足:$i< j$且$p_i+p_j=i+j$。

请你帮他算算吧。

# 输入描述

输入包含两行。

第一行一个正整数$n(1≤n≤200000)$，表示排列的长度。

第二行$n$个正整数$p_i(1≤p_i≤n)$，表示排列$p$。(保证输入是一个排列。)

# 输出描述



输出一行一个整数表示好对的个数。



## 样例1 

**输入** 

```
5
2 1 3 5 4
```

**输出** 

```
4
```

**说明**

$p_1+p_2=2+1$，

$p_1+p_5=2+4$，

$p_2+p_4=1+5$，

$p_4+p_5=4+5$。

共这四对。
