
**题目描述：**

给定一个正整数 $n$，你需要统计从 $1$ 到 $n$ 的所有整数中，满足以下条件的整数个数：对于每个整数 $i$，将 $i$ 的各位数字相加的结果对 $10$ 取模等于 $i$ 的末尾数字。

具体来说，设 $S(i)$ 为整数 $i$ 的各位数字之和，$d(i)$ 为整数 $i$ 的末尾数字（即 $i \mod 10$），我们需要满足以下条件：

 $$ S(i) \mod 10 = d(i) $$


请你计算出满足上述条件的整数的个数。

**输入：**

- 一行一个正整数 $n$ $(1 \leq n \leq 10^4)$。

**输出：**

- 一行一个整数，表示满足条件的整数个数。

**样例输入：**

```
20
```

**样例输出：**

```
9
```
