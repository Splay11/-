## 题目描述：

二叉树是一种每个结点最多有两个儿子的树，这两个儿子分别称为左儿子和右儿子。

现在用**层序数组**给出一棵二叉树：按层从左到右依次写出每个结点的权值；如果某个位置没有结点，则在数组里用 $-1$ 表示。数组中的第一个元素是根结点的权值。

请根据这个数组把二叉树构建出来，然后按结点权值依次输出它的前序遍历、中序遍历和后序遍历。

## 输入：

第一行一个整数 $n$，表示层序数组的长度。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，表示层序数组。$a_i = -1$ 表示该位置为空结点，否则 $a_i$ 为对应结点的权值。

## 输出：

共三行。

- 第一行输出前序遍历得到的权值序列。
- 第二行输出中序遍历得到的权值序列。
- 第三行输出后序遍历得到的权值序列。

同一行内相邻权值之间用一个空格分隔，行末不要有多余空格。

## 数据范围：

- $1 \leq n \leq 2000$
- $a_1 \neq -1$（根结点不为空）
- 若 $a_i \neq -1$，则 $1 \leq a_i \leq 10^9$
- 输入保证是一棵合法二叉树的层序表示：只有非空结点才会在数组中继续给出左右儿子；空结点不再展开

## 示例1

**输入：**

```
5
1 2 3 4 5
```

**输出：**

```
1 2 4 5 3
4 2 5 1 3
4 5 2 3 1
```

**说明：**

层序数组 $1,2,3,4,5$ 对应的树为：

```
      1
     / \
    2   3
   / \
  4   5
```

- 前序（根-左-右）：$1,\ 2,\ 4,\ 5,\ 3$
- 中序（左-根-右）：$4,\ 2,\ 5,\ 1,\ 3$
- 后序（左-右-根）：$4,\ 5,\ 2,\ 3,\ 1$

## 示例2

**输入：**

```
4
1 -1 2 3
```

**输出：**

```
1 2 3
1 3 2
3 2 1
```

**说明：**

层序数组 $1,-1,2,3$ 表示：根的权值为 $1$，左儿子为空，右儿子权值为 $2$；结点 $2$ 的左儿子权值为 $3$，右儿子为空。树的结构为：

```
  1
   \
    2
   /
  3
```
