# 【树1】二叉树的构建

## 层序数组

题目给出的是一层一层从左到右写成的数组。数组第一个元素是根；某个位置如果没有结点，就记成 $-1$。

例如 $1,2,3,4,5$ 表示：

```
      1
     / \
    2   3
   / \
  4   5
```

再如 $1,-1,2,3$ 表示根没有左儿子，右儿子是 $2$，结点 $2$ 的左儿子是 $3$：

```
  1
   \
    2
   /
  3
```

空结点不再往下展开，所以数组里不会出现「空结点的左右儿子」。

## 用队列建树

结点本身只保存权值和左右儿子。建树时用队列按层处理：

1. 用数组第一个元素创建根，并放进队列。
2. 每次取出队头结点，数组里接下来两个位置依次是它的左儿子、右儿子。
3. 如果对应位置不是空，就创建新结点挂上去，并入队；如果是空，这个方向保持为空，且不入队。
4. 下标走到数组末尾，或队列为空时结束。

建好之后再做一次层序遍历：队列里只放非空结点，依次输出权值。不要把 $-1$ 当成一个真结点。

## 题解

### 思路

1. 读入层序数组。题面用 $-1$ 表示空，先转成空，再调用建树函数。
2. 用队列按上面的规则把 `TreeNode` 接起来。
3. 再从根做层序遍历，只输出非空结点的权值。

### 复杂度分析

- 时间复杂度：$O(n)$，每个数组位置处理一次。
- 空间复杂度：$O(n)$，队列。

## 代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def build_tree(tree_arr):
    # 空树
    if not tree_arr or tree_arr[0] is None:
        return None

    q = []
    rt = TreeNode(tree_arr[0])
    q.append(rt)

    index = 1
    while q and index < len(tree_arr):
        node = q.pop(0)

        # 左孩子
        if index < len(tree_arr) and tree_arr[index] is not None:
            node.left = TreeNode(tree_arr[index])
            q.append(node.left)
        index += 1

        # 右孩子
        if index < len(tree_arr) and tree_arr[index] is not None:
            node.right = TreeNode(tree_arr[index])
            q.append(node.right)
        index += 1

    return rt


def level_order(root):
    # 层序：只访问非空结点
    if root is None:
        return []
    q = [root]
    res = []
    while q:
        node = q.pop(0)
        res.append(node.val)
        if node.left is not None:
            q.append(node.left)
        if node.right is not None:
            q.append(node.right)
    return res


def main():
    n = int(input())
    raw = list(map(int, input().split()))
    tree_arr = [None if x == -1 else x for x in raw]  # -1 换成空
    root = build_tree(tree_arr)
    print(" ".join(str(x) for x in level_order(root)))


if __name__ == "__main__":
    main()
```

以样例 2 为例：数组是 $1,-1,2,3$。先建根 $1$。取出根后，下一个是 $-1$，左儿子为空且不入队；再下一个是 $2$，挂到右儿子并入队。再取出 $2$，下一个是 $3$，挂到左儿子。层序遍历得到 $1\ 2\ 3$。
