# 题目内容

实现 Batch Normalization（批归一化）的训练模式前向传播。

给定输入张量 $X$（$N \times d$）、可学习参数 $\gamma$（$d$）、$\beta$（$d$）和数值稳定项 $\varepsilon$，沿 batch 维度进行归一化：

$$
\mu_j = \frac{1}{N}\sum_{i=1}^{N} x_{i,j}, \qquad \sigma_j^2 = \frac{1}{N}\sum_{i=1}^{N}(x_{i,j} - \mu_j)^2
$$

$$
\hat{x}_{i,j} = \frac{x_{i,j} - \mu_j}{\sqrt{\sigma_j^2 + \varepsilon}}, \qquad y_{i,j} = \gamma_j \cdot \hat{x}_{i,j} + \beta_j
$$

# 输入描述

第一行包含两个整数 $N, d$（$2 \le N \le 128$，$1 \le d \le 64$），表示 batch 大小和特征维度。

接下来 $N$ 行，每行 $d$ 个浮点数，表示输入张量 $X$。

接下来一行，$d$ 个浮点数，表示缩放参数 $\gamma$。

接下来一行，$d$ 个浮点数，表示偏移参数 $\beta$。

最后一行，$1$ 个浮点数，表示 $\varepsilon$。

# 输出描述

输出三部分：

1. 第一行：$d$ 个浮点数，表示 batch 均值 $\mu$，保留 $2$ 位小数。
2. 第二行：$d$ 个浮点数，表示 batch 方差 $\sigma^2$，保留 $2$ 位小数。
3. 接下来 $N$ 行：每行 $d$ 个浮点数，表示归一化结果，保留 $2$ 位小数。

## 样例 $1$

**输入**

```text
4 2
1.0 2.0
2.0 4.0
3.0 6.0
4.0 8.0
1.0 1.0
0.0 0.0
1e-5
```

**输出**

```text
2.50 5.00
1.25 5.00
-1.34 -1.34
-0.45 -0.45
0.45 0.45
1.34 1.34
```

**说明**

特征 1（列 1：$[1, 2, 3, 4]$）：均值 $\mu_1 = 2.5$，方差 $\sigma_1^2 = 1.25$，标准化 $(x - 2.5) / \sqrt{1.25} = [-1.342, -0.447, 0.447, 1.342]$。

特征 2（列 2：$[2, 4, 6, 8]$）：均值 $\mu_2 = 5$，方差 $\sigma_2^2 = 5$，标准化 $(x - 5) / \sqrt{5} = [-1.342, -0.447, 0.447, 1.342]$。

归一化结果里第二行的符号按该标准化序列写成 $-0.45$。

## 样例 $2$

**输入**

```text
2 3
0.0 0.0 0.0
2.0 4.0 6.0
2.0 2.0 2.0
1.0 1.0 1.0
1e-5
```

**输出**

```text
1.00 2.00 3.00
1.00 4.00 9.00
-1.00 -1.00 -1.00
3.00 3.00 3.00
```

**说明**

$\gamma = 2$，$\beta = 1$，标准化后乘以 $2$ 加 $1$。
