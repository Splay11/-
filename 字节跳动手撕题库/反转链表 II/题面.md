# 题目内容

给你单链表的头指针 $head$ 和两个整数 $left$ 和 $right$，其中 $left \le right$。请你反转从位置 $left$ 到位置 $right$ 的链表节点，返回反转后的链表。

# 输入描述

第一行输入三个整数 $n,left,right(1 \le n \le 500, 1 \le left \le right \le n)$，分别表示链表长度和反转区间。

第二行输入 $n$ 个整数 $(-500 \le val[i] \le 500)$，表示链表节点值。

# 输出描述

输出反转后的链表节点值，数字之间以空格分隔。

## 样例 $1$

**输入**

```text
5 2 4
1 2 3 4 5
```

**输出**

```text
1 4 3 2 5
```

**说明**

反转位置 $2$ 到 $4$ 的节点：$[1,2,3,4,5] \to [1,4,3,2,5]$。

## 样例 $2$

**输入**

```text
1 1 1
5
```

**输出**

```text
5
```
