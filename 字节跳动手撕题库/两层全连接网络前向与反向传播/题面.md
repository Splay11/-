# 题目内容

实现一个两层全连接网络的前向传播和反向传播。

网络结构：输入 $x$（$1 \times d_{in}$）→ 第一层 $W_1$（$d_{in} \times d_h$）$+ b_1$ → ReLU → 第二层 $W_2$（$d_h \times d_{out}$）$+ b_2$ → 输出 $\hat{y}$（$1 \times d_{out}$）。

损失函数：均方误差 $L = \dfrac{1}{d_{out}}\sum_j (\hat{y}_j - y_j)^2$。

给定输入 $x$、权重 $W_1, b_1, W_2, b_2$ 和目标 $y$，计算：

1. 前向传播得到 $\hat{y}$ 和损失 $L$。
2. 反向传播得到 $\dfrac{\partial L}{\partial W_1}$、$\dfrac{\partial L}{\partial b_1}$、$\dfrac{\partial L}{\partial W_2}$、$\dfrac{\partial L}{\partial b_2}$。

# 输入描述

第一行包含三个整数 $d_{in}, d_h, d_{out}$（$1 \le d_{in}, d_h, d_{out} \le 8$）。

第二行 $d_{in}$ 个浮点数，表示输入 $x$。

接下来 $d_{in}$ 行，每行 $d_h$ 个浮点数，表示 $W_1$。

一行 $d_h$ 个浮点数，表示 $b_1$。

接下来 $d_h$ 行，每行 $d_{out}$ 个浮点数，表示 $W_2$。

一行 $d_{out}$ 个浮点数，表示 $b_2$。

一行 $d_{out}$ 个浮点数，表示目标 $y$。

# 输出描述

第一行：$d_{out}$ 个浮点数，表示预测值 $\hat{y}$，保留 $4$ 位小数。

第二行：损失值 $L$，保留 $4$ 位小数。

接下来 $d_{in}$ 行，每行 $d_h$ 个浮点数，表示 $\dfrac{\partial L}{\partial W_1}$，保留 $4$ 位小数。

一行 $d_h$ 个浮点数，表示 $\dfrac{\partial L}{\partial b_1}$，保留 $4$ 位小数。

接下来 $d_h$ 行，每行 $d_{out}$ 个浮点数，表示 $\dfrac{\partial L}{\partial W_2}$，保留 $4$ 位小数。

一行 $d_{out}$ 个浮点数，表示 $\dfrac{\partial L}{\partial b_2}$，保留 $4$ 位小数。
