# 题目内容

请实现一个支持**按时间段预约车位**的停车场系统。

共有 $n$ 个车位，编号 $0,1,\ldots,n-1$，初始全部空闲。

一次预约用两个整数描述占用时段：

- `start`：开始占用的时刻（含）
- `end`：结束占用的时刻（不含）

即车辆占用半开区间 $[\textit{start},\,\textit{end})$：从时刻 `start` 起占着车位，到时刻 `end` 起不再占用。因此：

- 时刻 $t$ 正在占用 $\iff \textit{start} \le t < \textit{end}$
- 两段预约可同占一车位，当且仅当它们的区间**不相交**（例如 $[0,5)$ 与 $[5,10)$ 不相交，可以先后使用同一车位）

每辆车在取消前最多保留一段有效预约；不同车辆占用同一车位的区间不得相交。

## 需要实现的接口

- `ParkingLot(int n)`：初始化 $n$ 个空车位。
- `reserve(int carId, int start, int end)`：为车辆 `carId` 预约时段 $[\textit{start},\textit{end})$。
  - 若该车已有未取消的预约，或 $\textit{start}\ge \textit{end}$，返回 `-1`
  - 否则在所有能完整容纳该区间的车位中，选**编号最小**者分配，返回车位编号；若无法分配返回 `-1`
- `cancel(int carId)`：取消该车当前预约。无预约返回 `false`，否则释放占用并返回 `true`
- `spotOf(int carId)`：返回该车当前车位编号；无预约返回 `-1`
- `busyCount(int time)`：返回在时刻 `time` 正在占用中的车辆数（$\textit{start}\le \textit{time} < \textit{end}$）

## 输入描述

每行一次函数调用。首行 `ParkingLot(n)`。累计调用不超过 $3000$ 次。

- $1 \le n \le 200$
- $1 \le \textit{carId} \le 10^4$
- $0 \le \textit{start} < \textit{end} \le 10^9$（若调用时 $\textit{start}\ge \textit{end}$，`reserve` 返回 `-1`）

## 输出描述

- 构造返回 `null`
- `reserve` / `spotOf` / `busyCount` 返回整数
- `cancel` 返回 `true` / `false`

## 样例1

输入：

```
ParkingLot(2)
reserve(1, 0, 10)
reserve(2, 5, 15)
reserve(3, 0, 6)
busyCount(5)
cancel(1)
reserve(3, 0, 5)
spotOf(3)
busyCount(4)
reserve(2, 0, 1)
```

输出：

```
null
0
1
-1
2
true
0
0
1
-1
```

说明：

- 车 `1` 预约 $[0,10)$，分到车位 $0$
- 车 `2` 预约 $[5,15)$，与车位 $0$ 冲突，分到车位 $1$
- 车 `3` 预约 $[0,6)$：与车位 $0$ 的 $[0,10)$、车位 $1$ 的 $[5,15)$ 都相交，失败返回 `-1`
- 时刻 $5$：两车都在场，`busyCount` 为 $2$
- 取消车 `1` 后，车 `3` 可预约 $[0,5)$ 到车位 $0$（与 $[5,15)$ 在时刻 $5$ 处「首尾相接」不相交）
- 车 `2` 仍有预约，再次 `reserve` 失败
