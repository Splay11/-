# 固定布局字段抽取

# 题目内容

给定一段长度为 $20$ 字节的二进制数据，字段划分如下图：自上而下、自左而右为顺序；括号内为所占 bit 数；每行宽 $32$ 位。

![](file://65Io73ptVPd9rhjF2hTRr.png)

请从图中取出高亮的两项：片偏移、源 IP 地址。片偏移等于「标志$(5)$ + 片偏移$(11)$」所在 $16$ bit 的低 $11$ 位。

## 输入描述

仅含 `[0-9A-F]` 的十六进制字符串：每两个字符一个字节，长度固定为 $40$。

## 输出描述

字符串，格式 `片偏移,源IP地址`。前者为十进制整数；后者为点分十进制，例如 `192.168.1.2`。

## 样例1

输入：

```
4500003C7C48123480060000C0A80A01C0A814B8
```

输出：

```
564,192.168.10.1
```

**说明：**

第 $7$–$8$ 字节为 `0x1234`，低 $11$ 位 `0x234`＝$564$。第 $13$–$16$ 字节 `C0 A8 0A 01`＝`192.168.10.1`。

## 样例2

输入：

```
46000014000107FF80010000010101020A0A0A0A
```

输出：

```
2047,1.1.1.2
```

**说明：**

`0x07FF` 低 $11$ 位为 $2047$；源地址四字节 `01 01 01 02`＝`1.1.1.2`。
