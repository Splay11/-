## 解题思路

报文头固定 20 字节，由 40 位十六进制字符给出（每两位一字节，大端序）。

按字段布局：

- **片偏移**：位于第 7–8 字节（下标 6、7）组成的 16 bit 无符号整数的**低 11 位**，即 `((b6<<8)|b7) & 0x7FF`；
- **源 IP**：第 13–16 字节（下标 12..15），按字节依次点分输出。

将十六进制串转为字节数组后按上式拼接即可。

**常见假解**：

- 按标准 IPv4 取低 13 位（`& 0x1FFF`）——与本题图示「标志 5 + 片偏移 11」及样例不符；
- 字节序搞反或 IP 字节下标偏移错误。

## 复杂度分析

- 时间：$O(1)$（固定 20 字节）；
- 空间：$O(1)$。

## 代码实现

### Python

```python
class Solution:
    def parsePacketHeader(self, header: str) -> str:
        b = bytes.fromhex(header)
        # 字节 6–7 的低 11 位为片偏移
        frag = ((b[6] << 8) | b[7]) & 0x7FF
        # 字节 12–15 为源 IP
        ip = f"{b[12]}.{b[13]}.{b[14]}.{b[15]}"
        return f"{frag},{ip}"
```

### Java

```java
public class Solution {
    private static int hexVal(char c) {
        if (c >= '0' && c <= '9') return c - '0';
        return c - 'A' + 10;
    }

    public String parsePacketHeader(String header) {
        int[] b = new int[20];
        for (int i = 0; i < 20; i++) {
            b[i] = (hexVal(header.charAt(2 * i)) << 4) | hexVal(header.charAt(2 * i + 1));
        }
        // 低 11 位片偏移
        int frag = ((b[6] << 8) | b[7]) & 0x7FF;
        return frag + "," + b[12] + "." + b[13] + "." + b[14] + "." + b[15];
    }
}
```

### C++

```cpp
#include <cstdio>
#include <string>

using namespace std;

class Solution {
    static int hexVal(char c) {
        if (c >= '0' && c <= '9') return c - '0';
        return c - 'A' + 10;
    }

   public:
    string parsePacketHeader(string header) {
        unsigned char b[20];
        for (int i = 0; i < 20; i++) {
            b[i] = (unsigned char)((hexVal(header[2 * i]) << 4) | hexVal(header[2 * i + 1]));
        }
        int frag = ((b[6] << 8) | b[7]) & 0x7FF;
        char buf[64];
        snprintf(buf, sizeof(buf), "%d,%u.%u.%u.%u", frag, b[12], b[13], b[14], b[15]);
        return string(buf);
    }
};
```
