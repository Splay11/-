# 题目内容

一个网络报文头及所包含的各信息的关系如图所示：

![](file://65Io73ptVPd9rhjF2hTRr.png)


- 图中从上到下、从左到右依次表示各信息在网络报文头中的顺序。
- 各信息括号内的数字表示所占位数，如：标识`(16)`，表示标识部分占 `16` 个 `bit` 位即 `2` 个字节长度。

现给定一个十六进制格式的网络报文头数据，请解析输出其中的片偏移、源IP地址：

## 输入描述

十六进制字符串 `[0-9A-F]`，表示合法的网络报文头数据，每两位字符表示一个字节，字符串长度固定为 `40`。

## 输出描述

一个字符串，表示解析结果：`片偏移,源IP地址`，以 `,` 间隔。

- 片偏移为十进制整数
- 源`IP`地址为点分十进制格式，如：`192.168.1.2`

## 样例1

输入：

```
4500003C7C48200380060000C0A80102C0A814B8
```

输出：

```
3,192.168.1.2
```

解释：

对照图示的各信息所在位置：

- 片偏移：`0x2003` 的低 11 位，2 进制为 `00000000011`，10 进制值为 `3`
- 源IP地址：`0xC0A80102`，点分十进制为 `192.168.1.2`

## 样例2

输入：

```
450000FF0234A58180060000000A01028090A0B0
```

输出：

```
1409,0.10.1.2
```

解释：

- 片偏移：`0xA581` 的低 11 位，2 进制为 `10110000001`，10 进制值为 `1409`
- 源IP地址：`0x000A0102`，点分十进制为 `0.10.1.2`
