## 解题思路

本题要找最小窗口长度 $k$，使每个长度为 $k$ 的子数组的**按位或**都等于整个数组的或值 $T$。

先求出 $T$。若 $T=0$，说明全是 `0`，任意窗口或都是 `0`，答案为 `1`。

$T$ 里出现过的每一位 $b$，都必须出现在**每一个**长度为 $k$ 的窗口里。这等价于：把该位取 `1` 的下标列出，再在两端加上哨兵 `-1` 与 $n$，相邻下标的最大间距就是这位所要求的最小 $k$。对所有位取最大值即为答案。

直观上，某位两次出现之间隔得越远，窗口就要越长才能「兜住」这一位。

接口 `minForceWindow(hits)` 对每个相关位扫一遍数组即可。

常见假解：

- 直接返回 $n$，或返回「出现过的不同值个数」。
- 只看 $T$ 的二进制位数，忽略各位在数组中的分布。
- 漏掉两端哨兵：只算中间相邻间隔，会把开头/结尾的空档漏掉（如 `[8,1,2]`）。

## 复杂度分析

- 时间：$O(31 \cdot n)$，常数位次扫描。
- 空间：$O(1)$ 额外空间。

## 代码实现

### Python

```python
from typing import List


class Solution:
    def minForceWindow(self, hits: List[int]) -> int:
        n = len(hits)
        tot = 0
        for x in hits:
            tot |= x
        if tot == 0:
            return 1
        ans = 1
        for b in range(31):
            if ((tot >> b) & 1) == 0:
                continue
            prev = -1
            mx = 0
            # 该位相邻两次出现（含两端哨兵）的最大间距
            for i, x in enumerate(hits):
                if (x >> b) & 1:
                    mx = max(mx, i - prev)
                    prev = i
            mx = max(mx, n - prev)
            ans = max(ans, mx)
        return ans
```

### Java

```java
class Solution {
    public int minForceWindow(int[] hits) {
        int n = hits.length;
        int tot = 0;
        for (int x : hits) tot |= x;
        if (tot == 0) return 1;
        int ans = 1;
        for (int b = 0; b < 31; b++) {
            if (((tot >> b) & 1) == 0) continue;
            int prev = -1, mx = 0;
            // 该位相邻出现的最大间距，含左右哨兵
            for (int i = 0; i < n; i++) {
                if (((hits[i] >> b) & 1) != 0) {
                    mx = Math.max(mx, i - prev);
                    prev = i;
                }
            }
            mx = Math.max(mx, n - prev);
            ans = Math.max(ans, mx);
        }
        return ans;
    }
}
```

```javascript
            ans = Math.max(ans, mx);
        }
        return ans;
    }
}
```

### C

```c
int minForceWindow(int* hits, int hitsSize) {
    int tot = 0;
    for (int i = 0; i < hitsSize; i++) tot |= hits[i];
    if (tot == 0) return 1;
    int ans = 1;
    for (int b = 0; b < 31; b++) {
        if (((tot >> b) & 1) == 0) continue;
        int prev = -1, mx = 0;
        // 含哨兵的最大间距
        for (int i = 0; i < hitsSize; i++) {
            if ((hits[i] >> b) & 1) {
                int g = i - prev;
                if (g > mx) mx = g;
                prev = i;
            }
        }
        int g = hitsSize - prev;
        if (g > mx) mx = g;
        if (mx > ans) ans = mx;
    }
    return ans;
}
```
