# 五子连珠检测

# 题目内容

在 $19\times 19$ 棋盘上（坐标 $x,y\in[0,18]$，$x$ 向右、$y$ 向上），给定互不相同的黑棋坐标列表 `blackChessPoses`。判断是否存在某一方向（横、竖、两条对角）上**连续 5 颗**黑棋。

方向向量可取：$(1,0)$、$(0,1)$、$(1,1)$、$(1,-1)$。连续指相邻两子坐标差恰为该方向的一步。

请实现：

```text
hasFiveInRow(blackChessPoses: int[][]) -> string
```

返回 `"YES"` 或 `"NO"`。

## 输入描述

一行二维整型数组，形如：

```
[[0,0],[1,0],[2,0],[3,0],[4,0]]
```

每项为 `[x, y]`。约束：$1\le n\le 361$，$0\le x,y\le 18$，坐标互异。

## 输出描述

一行带双引号的字符串：`"YES"` 或 `"NO"`。

## 样例1

输入：

```
[[0,0],[1,0],[2,0],[3,0],[4,0]]
```

输出：

```
"YES"
```

**说明：** $y=0$ 上横向五连。

## 样例2

输入：

```
[[0,0],[1,1],[2,2],[3,3],[4,4]]
```

输出：

```
"YES"
```

**说明：** 主对角线五连。

## 样例3

输入：

```
[[0,0],[1,0],[2,0],[4,0],[5,0]]
```

输出：

```
"NO"
```

**说明：** 中间断开，无一处连续满 5。
