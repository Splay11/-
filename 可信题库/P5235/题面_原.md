# 题目内容

五子棋是一种两人对弈的棋类游戏，在 19×19 的棋盘上，黑白双方轮流落子，率先在横、竖、斜任意方向上形成**连续五颗同色棋子**的一方获胜。

棋盘坐标系统如下：
- X 轴：水平方向，范围 `0 ~ 18`（从左到右）
- Y 轴：垂直方向，范围 `0 ~ 18`（从下到上）

现在给定一个**黑棋**的坐标集合 `blackChessPoses`，请判断黑棋是否已经在棋盘上形成 **五子连珠**（即横、竖、斜任一方向上存在连续的 5 颗黑棋）。

## 输入描述

第一行输入一个整数 `n`，表示黑棋的数量。  
接下来 `n` 行，每行两个整数 `x` 和 `y`，表示一个黑棋的坐标。  
坐标范围：`0 ≤ x ≤ 18`，`0 ≤ y ≤ 18`。

## 输出描述

如果黑棋已形成五子连珠，输出 `"YES"`，否则输出 `"NO"`。

## 样例1

输入：

```
5
0 0
1 0
2 0
3 0
4 0
```

输出：

```
YES
```

**说明：** 在 `y=0` 这一行上，`(0,0)` 到 `(4,0)` 形成横向五连珠。

## 样例2

输入：

```
5
0 0
1 1
2 2
3 3
4 4
```

输出：

```
YES
```

**说明：** 斜线方向 `(0,0)` 到 `(4,4)` 形成五连珠。

## 样例3

输入：

```
5
0 0
1 0
2 0
4 0
5 0
```

输出：

```
NO
```

**说明：** 虽有片段连续，但没有连续的 5 颗。

## 数据范围

- `1 ≤ n ≤ 361`
- 输入保证坐标不重复

## 提示

可枚举每个黑棋，检查四个方向是否有连续 5 颗：`(1,0)`、`(0,1)`、`(1,1)`、`(1,-1)`。
