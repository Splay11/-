## 解题思路

本题是**前缀和 + 贪心判定**。

操作只会把练习册从左桌传到右桌，总份数不变，且任何课桌都不能被搬空到 `0`（因为每次传出要求该桌仍大于 `1`）。因此最终若存在严格递增数组，则每张桌至少为 `1,2,3,\ldots`，即：

- 前 $k$ 张桌（$k=1,2,\ldots,n$）最终至少需要 $1+2+\cdots+k = k(k+1)/2$ 份。

由于练习册**只能向右传、不能向左传**，前 $k$ 张桌最终能用到的册子，最多就是它们**现在**拥有的那些（再往右的桌帮不上忙）。所以：

- 记前 $k$ 张桌的当前份数之和为 $S_k$
- 若某个 $k$ 满足 $S_k < k(k+1)/2$，则前 $k$ 张桌永远凑不齐最小递增前缀，答案为 `false`
- 若对所有 $k$ 都有 $S_k \ge k(k+1)/2$，则可以把左边多出来的册子不断右传，填出 `1,2,\ldots` 并把剩余全堆在最右边，答案为 `true`

接口 `canPassBooks(desks)` 从左到右累加并检查即可。前缀和与 $k(k+1)/2$ 都会超过 32 位整数，须用 64 位。

常见假解：

- 只检查「当前是否已严格递增」（`[10,1,1]` 会误判 `false`）。
- 只检查总和是否 $\ge n(n+1)/2$，不查每个前缀（`[1,1,3,5]` 总和够但第二个前缀只有 `2 < 3`）。
- 用 32 位整数累加导致溢出。
- 以为可以把练习册向左传。

## 复杂度分析

- 时间：$O(n)$，每张课桌访问一次。
- 空间：$O(1)$ 额外空间。

## 代码实现

### Python

```python
from typing import List


class Solution:
    def canPassBooks(self, desks: List[int]) -> bool:
        s = 0
        for i, x in enumerate(desks):
            s += x
            k = i + 1
            # 前 k 张桌至少需要 1+2+...+k 份，且册子不能从右边借回来
            if s < k * (k + 1) // 2:
                return False
        return True
```

### Java

```java
class Solution {
    public boolean canPassBooks(int[] desks) {
        long s = 0;
        for (int i = 0; i < desks.length; i++) {
            s += desks[i];
            long k = i + 1L;
            // 用 64 位检查前缀最小需求，避免溢出
            if (s < k * (k + 1) / 2) return false;
        }
        return true;
    }
}
```

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    bool canPassBooks(vector<int>& desks) {
        long long s = 0;
        for (int i = 0; i < (int)desks.size(); i++) {
            s += desks[i];
            long long k = i + 1;
            // 前 k 张桌的册子只能来自当前前缀
            if (s < k * (k + 1) / 2) return false;
        }
        return true;
    }
};
```
