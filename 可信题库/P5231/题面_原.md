# 题目内容

某网络设备的转发芯片处理业务报文时，会分配整数个字节的存储空间来存放由一个或多个字段组成的关键数据。为节省空间，采用「紧凑排列」：

- 各字段有固定位宽，依次记录在数组 `sectionWidth` 中，按该位宽顺序紧挨排列；
- 待存数值在 `sectionValues` 中给出，`sectionValues[i]` 写入对应位宽的字段；若数值有效位数不足位宽，则在该字段**左侧（高位）补 0**；
- `sectionWidth.length == sectionValues.length`，且一一对应；
- 若全部字段的总位数不是 8 的倍数，则在**整段比特串右侧补 0**，补齐到下一个字节边界。

用例保证补齐后总位数不超过 48 bit。请输出所分配存储空间的内容，表示为十六进制字符串。

## 输入描述

- 参数一：`sectionWidth`，$1\le \texttt{sectionWidth.length}\le 10$，$1\le \texttt{sectionWidth}[i]\le 31$
- 参数二：`sectionValues`，$0\le \texttt{sectionValues}[i] < 2^{\texttt{sectionWidth}[i]}$

## 输出描述

十六进制字符串：每个字节对应恰好两位 `[0-9A-F]`，字母大写。

## 样例1

输入：

```
[7, 3, 4]
[29, 2, 15]
```

输出：

```
"3ABC"
```

解释：

- 位宽 7、值 29 → `0011101`
- 位宽 3、值 2 → `010`
- 位宽 4、值 15 → `1111`
- 拼接得 `00111010101111`，共 14 bit，右侧补 2 个 0 得 `0011101010111100`
- 按字节：`00111010`→`3A`，`10111100`→`BC`，结果 `"3ABC"`

## 样例2

输入：

```
[31]
[0]
```

输出：

```
"00000000"
```

解释：

仅一个字段，位宽 31；存入后整段右侧补 1 个 0，共 32 bit，四个字节均为 `00`。
