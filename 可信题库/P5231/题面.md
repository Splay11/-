# 定宽字段紧凑拼装

# 题目内容

给定两个等长数组 `sectionWidth` 与 `sectionValues`。将每个 `sectionValues[i]` 写成恰好 `sectionWidth[i]` 位的二进制（不足则在**高位补 0**），再按 $i=0,1,\ldots$ 的顺序首尾相接。若总位数不是 $8$ 的倍数，则在整段比特串**末尾补 0**，直到长度为 $8$ 的倍数。用例保证补齐后总位数不超过 $48$。把结果按字节写成大写十六进制字符串返回（每字节两位，字母取 `A-F`）。

请实现：

```text
packFields(sectionWidth: int[], sectionValues: int[]) -> string
```

## 输入描述

两行：

- 第一行：整数数组 `sectionWidth`（形如 `[7, 3, 4]`），$1\le n\le 10$，$1\le \texttt{sectionWidth}[i]\le 31$，$n=\texttt{sectionWidth.length}$
- 第二行：整数数组 `sectionValues`（形如 `[29, 2, 15]`），满足 $0\le \texttt{sectionValues}[i]<2^{\texttt{sectionWidth}[i]}$

## 输出描述

一行带双引号的十六进制字符串，例如 `"3ABC"`。

## 样例1

输入：

```
[5, 3, 6]
[10, 5, 40]
```

输出：

```
"55A0"
```

**说明：**

$10$→`01010`，$5$→`101`，$40$→`101000`，拼接 `01010101101000`，右侧补 `00` 得 `0101010110100000`，即 `55A0`。

## 样例2

输入：

```
[8]
[255]
```

输出：

```
"FF"
```

**说明：**

恰 8 位 `11111111`，无需补齐。

## 样例3

输入：

```
[31]
[0]
```

输出：

```
"00000000"
```

**说明：**

31 位全 0，右侧补 1 位后共 32 位，四个字节均为 `00`。
