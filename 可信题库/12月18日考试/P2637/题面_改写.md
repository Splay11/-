# 带依赖的实例可用性

# 题目内容

实现类 `ServiceMgrSys`：维护若干命名服务在多台服务器上的运行实例，以及服务之间的有向依赖（保证无环）。

规则：

- 同一服务器上同一服务至多一个实例；同一服务可在多台服务器上各有一个实例。
- 服务可提供服务，当且仅当：自身至少有一个实例在运行，且其每个直接依赖服务也都能提供服务（可递归）。无依赖时只需自身有实例。

# 接口说明

| 方法 | 说明 | 返回值 |
|------|------|--------|
| `ServiceMgrSys()` | 初始化，清空状态 | 无（输出 `null`） |
| `rebootServers(serverIds)` | 所列服务器上全部实例停止，且不自动重启 | 无（`null`） |
| `startService(serverId, serviceName)` | 在该服务器启动该服务；若已在运行则 `false`，否则启动并 `true` | `bool` |
| `addDependency(fromServiceName, toServiceName)` | 令 `from` 依赖 `to`；已存在则 `false`，否则 `true` | `bool` |
| `isServiceAvailable(serviceName)` | 该服务当前是否可提供服务 | `bool` |

签名与平台一致（Python / Java / C++ 同名方法），此处从略。

# 输入描述

每行一次函数调用；首行必为 `ServiceMgrSys()`。累计调用次数不超过 $1000$。

- $0\le \textit{serverId}\le 1000$；$0<\textit{serverIds.length}\le 500$，元素互异且合法。
- 服务名由字母或数字组成，$0<$ 长度 $<15$。
- `addDependency` 不会成环。

# 输出描述

每次调用一行：无返回值输出 `null`；布尔输出小写 `true` / `false`。

# 样例 1

**输入**

```
ServiceMgrSys()
startService(1, "A")
startService(1, "B")
addDependency("B", "A")
isServiceAvailable("B")
rebootServers([1])
isServiceAvailable("A")
startService(2, "A")
startService(2, "B")
isServiceAvailable("B")
```

**输出**

```
null
true
true
true
true
null
false
true
true
true
```

**说明**

先在服务器 $1$ 启动 `A`、`B`，并令 `B` 依赖 `A`，此时 `B` 可用。重启服务器 $1` 后无实例，`A` 不可用。再在服务器 $2` 启动 `A`、`B` 后，`B` 再次可用。

# 样例 2

**输入**

```
ServiceMgrSys()
startService(1, "X")
startService(2, "X")
startService(2, "X")
addDependency("Y", "X")
rebootServers([2])
isServiceAvailable("X")
startService(2, "Y")
isServiceAvailable("Y")
rebootServers([2, 1])
isServiceAvailable("X")
```

**输出**

```
null
true
true
false
true
null
true
true
true
null
false
```

**说明**

`X` 在 $1$、$2$ 各有实例；重复在 $2$ 启动返回 `false`。重启 $2` 后 `X` 仍在 $1$ 上可用。启动依赖 `X` 的 `Y` 后 `Y` 可用；两台都重启后 `X` 不可用。
