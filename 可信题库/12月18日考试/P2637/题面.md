# 题目内容

微服务的运行规则如下：

- **部署**：一个微服务在一台服务器上只能部署一个实例，但可部署在多台服务器上。
- **运行状态**：一个微服务可以不依赖其它微服务独立启动并运行。
- **提供服务**：
  - 无依赖时：只要有至少一个实例处于运行状态，即可提供服务；
  - 有依赖时：当且仅当该微服务自身至少有一个实例在运行，**且**它所依赖的所有微服务都能提供服务时，该微服务才能提供服务。

例如：某时刻微服务 $A$ 依赖 $B$，$B$ 依赖 $C$，$C$ 无依赖，则：

- 若 $C$ 至少有一个实例在运行，则 $C$ 可提供服务；
- 同时若 $B$ 至少有一个实例在运行，则 $B$ 也可提供服务；
- 再者若 $A$ 至少有一个实例在运行，则 $A$ 也可提供服务。

若随后将 $B$ 的所有实例停止，则 $A$、$B$ 都不能提供服务，但 $C$ 仍可提供服务。

请实现微服务管理系统 `ServiceMgrSys`，支持初始化、服务器重启、启动微服务、添加依赖、查询是否可提供服务。

# 接口说明

请实现类 `ServiceMgrSys`，包含以下方法（三种语言签名一致）：

| 方法 | 说明 | 返回值 |
|------|------|--------|
| `ServiceMgrSys()` | 系统初始化。假设机房内所有服务器已上传可供运行的微服务。 | 无（平台对构造调用输出 `null`） |
| `rebootServers(serverIds)` | 批量重启服务器 `serverIds`。这些服务器上的微服务实例全部停止，且**不会**自动启动。 | 无（平台输出 `null`） |
| `startService(serverId, serviceName)` | 在服务器 `serverId` 上启动微服务 `serviceName`。若该服务器上该微服务已在运行，返回 `false`；否则启动并返回 `true`。 | `bool` |
| `addDependency(fromServiceName, toServiceName)` | 令微服务 `fromServiceName` 依赖 `toServiceName`。输入保证无环。若该依赖已存在，返回 `false`；否则添加并返回 `true`（无论两个微服务是否曾启动过）。 | `bool` |
| `isServiceAvailable(serviceName)` | 若指定微服务当前可提供服务，返回 `true`；否则返回 `false`。 | `bool` |

# 输入描述

每行表示一次函数调用。首行一定是构造函数调用 `ServiceMgrSys()`，之后为若干业务调用。累计函数调用次数不超过 $1000$（含构造）。

- $0 \le \textit{serverId} \le 1000$，且为存在的服务器。
- $0 < \textit{serverIds.length} \le 500$；$0 \le \textit{serverIds}[i] \le 1000$，各不相同且为存在的服务器。
- `serviceName` / `fromServiceName` / `toServiceName` 由英文字母或数字组成，$0 <$ 长度 $< 15$。
- `addDependency` 保证不会形成循环依赖。

# 输出描述

由评测框架完成输出：布尔值输出为小写 `true` / `false`；无返回值的调用（构造、`rebootServers`）输出 `null`。每行对应一次调用的结果。

# 样例 1

**输入**

```
ServiceMgrSys()
startService(1, "serviceA")
startService(2, "serviceA")
startService(2, "serviceA")
addDependency("serviceB", "serviceA")
rebootServers([2])
isServiceAvailable("serviceA")
startService(2, "serviceB")
isServiceAvailable("serviceB")
rebootServers([2, 1])
isServiceAvailable("serviceA")
startService(1, "serviceA")
isServiceAvailable("serviceA")
```

**输出**

```
null
true
true
false
true
null
true
true
true
null
false
true
true
```

**说明**

1. 在服务器 $1$、$2$ 上各启动 `serviceA`；再次在 $2$ 上启动返回 `false`。
2. 添加依赖：`serviceB` 依赖 `serviceA`。
3. 重启服务器 $2$ 后，`serviceA` 仍在服务器 $1$ 运行，故仍可提供服务。
4. 在服务器 $2$ 启动 `serviceB` 后，因其依赖的 `serviceA` 可提供服务，故 `serviceB` 也可提供服务。
5. 重启服务器 $2$、$1$ 后，`serviceA` 无实例，不可提供服务；再在服务器 $1$ 启动后恢复。
