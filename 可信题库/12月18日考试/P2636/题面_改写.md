# 窗口频次达标编号

# 题目内容

给定按时间非降序的调用记录 `invokes`，每条为 `[time, interfaceId]`，表示时刻 `time` 上编号 `interfaceId` 被调用一次。再给定窗口长 `timeSegment` 与阈值 `minLimits`。

若某个编号存在时刻 $t$，使得落在半开区间 $[t,\,t+\texttt{timeSegment})$ 内、且属于该编号的调用次数不少于 `minLimits`，则该编号记为达标。求全部达标编号的升序列表；若无则 `[]`。

# 输入描述

- 参数一：`invokes`，$1\le \texttt{invokes.length}\le 10^5$；$0\le \texttt{time}\le 10^6$；$0\le \texttt{interfaceId}\le 10^5$；`time` 非降序。
- 参数二：`timeSegment`，$1\le \texttt{timeSegment}\le 10^5$。
- 参数三：`minLimits`，$1\le \texttt{minLimits}\le \texttt{invokes.length}$。

# 输出描述

达标编号的升序整型列表，可为 `[]`。

## 样例1

**输入**

```
[1, 5],[2, 5],[3, 5],[10, 7],[50, 7],[51, 7]
5
3
```

**输出**

```
[5]
```

**说明**

编号 $5$ 在 $[1,6)$ 内有 $3$ 次调用，达标。编号 $7$ 任意连续 $3$ 次的跨度至少为 $41$，不达标。

## 样例2

**输入**

```
[0, 1],[5, 1],[6, 2],[7, 2]
3
2
```

**输出**

```
[2]
```

**说明**

编号 $1$ 两次调用跨度为 $5$，不小于窗口 $3$。编号 $2$ 两次跨度为 $1$，达标。
