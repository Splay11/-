## 解题思路

本题是一次扫描上的**贪心**。甲要让剩余串字典序尽量大，只能删一个 `0`；乙要让剩余串字典序尽量小，只能删一个 `1`。

关键观察：

- 删掉一个 `0` **不会改变**各个 `1` 的相对顺序，因此乙眼中「最靠前的 `1`」始终是原串里最靠前的那个 `1`。
- 同理，删掉一个 `1` 也不会改变各个 `0` 的相对顺序。
- 对甲来说：在任意位置删 `0`，相当于从原串去掉该位。越靠前的 `0` 越可能处在高位，删掉它更能把后面较大的前缀顶上来，因此甲的最优是删**最左**的 `0`。
- 对乙来说：对称地，应删**最左**的 `1`，才能尽早把更小的后缀顶到高位。

因此答案就是：从 `s` 中同时去掉**最早出现的 `0`** 和**最早出现的 `1`**，其余字符保持原相对顺序。

接口 `reviseMarks(s)` 扫一遍记下两个下标，再扫一遍拼接即可。

常见假解：

- 删掉最**右**的 `0`/`1`（样例 `0001` 会得到 `001` 而不是 `00`）。
- 直接删掉前两个字符（`0001` 会得到 `01`）。
- 以为要枚举甲删哪一个 `0` 再枚举乙删哪一个 `1`（复杂度到 $O(n^2)$，大数据会超时，且最优选择其实唯一）。

## 复杂度分析

- 时间：$O(n)$，每个字符访问常数次。
- 空间：$O(n)$，用于构造返回串；若允许原地压缩则为 $O(1)$ 额外空间。

## 代码实现

### Python

```python
class Solution:
    def reviseMarks(self, s: str) -> str:
        i0 = i1 = -1
        # 记录最左的 0 与最左的 1
        for i, ch in enumerate(s):
            if ch == "0" and i0 < 0:
                i0 = i
            elif ch == "1" and i1 < 0:
                i1 = i
            if i0 >= 0 and i1 >= 0:
                break
        # 去掉这两个下标，保持其余相对顺序
        out = []
        for i, ch in enumerate(s):
            if i != i0 and i != i1:
                out.append(ch)
        return "".join(out)
```

### Java

```java
class Solution {
    public String reviseMarks(String s) {
        int i0 = -1, i1 = -1;
        int n = s.length();
        // 记录最左的 0 与最左的 1
        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);
            if (ch == '0' && i0 < 0) i0 = i;
            if (ch == '1' && i1 < 0) i1 = i;
            if (i0 >= 0 && i1 >= 0) break;
        }
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i != i0 && i != i1) sb.append(s.charAt(i));
        }
        return sb.toString();
    }
}
```

### C++

```cpp
#include <string>
using namespace std;

class Solution {
public:
    string reviseMarks(string s) {
        int i0 = -1, i1 = -1;
        int n = (int)s.size();
        // 记录最左的 0 与最左的 1
        for (int i = 0; i < n; i++) {
            if (s[i] == '0' && i0 < 0) i0 = i;
            if (s[i] == '1' && i1 < 0) i1 = i;
            if (i0 >= 0 && i1 >= 0) break;
        }
        string ans;
        ans.reserve(n);
        for (int i = 0; i < n; i++) {
            if (i != i0 && i != i1) ans.push_back(s[i]);
        }
        return ans;
    }
};
```

```javascript
class Solution {
    reviseMarks(s) {
        let i0 = -1, i1 = -1;
        // 记录最左的 0 与最左的 1
        for (let i = 0; i < s.length; i++) {

            if (s[i] === '1' && i1 < 0) i1 = i;
            if (i0 >= 0 && i1 >= 0) break;
        }
        let out = '';
        for (let i = 0; i < s.length; i++) {
            if (i !== i0 && i !== i1) out += s[i];
        }
        return out;
    }
}
```

### C

```c
#include <stdlib.h>
#include <string.h>

char* reviseMarks(char* s) {
    int n = (int)strlen(s);
    int i0 = -1, i1 = -1;
    // 记录最左的 0 与最左的 1
    for (int i = 0; i < n; i++) {
        if (s[i] == '0' && i0 < 0) i0 = i;
        if (s[i] == '1' && i1 < 0) i1 = i;
        if (i0 >= 0 && i1 >= 0) break;
    }
    int w = 0;
    for (int i = 0; i < n; i++) {
        if (i != i0 && i != i1) s[w++] = s[i];
    }
    s[w] = '\0';
    return s;
}
```
