# 涂卡互改

# 题目内容

期末测验用的答题卡是一排涂点，从左到右记成一条 `0`/`1` 串 `s`：

- `0`：这一格还空着
- `1`：这一格已经涂黑

两位同学要对这张卡做最后修订，**各改恰好一格**，顺序如下：

1. 甲必须把恰好一个 `0` 涂掉（从串里删掉这个字符）。甲希望**剩下的串字典序尽量大**（看起来「前面更满」）。
2. 乙必须把恰好一个 `1` 擦掉。乙希望**剩下的串字典序尽量小**。

甲先动手，双方都按对自己最有利的方式选格子。请返回改完之后剩下的串。

保证卡上至少有一个空格 `0`、至少一个已涂格 `1`。

请实现：

```text
reviseMarks(s: str) -> str
```

## 输入描述

一行：由字符 `0` 和 `1` 组成的字符串 `s`，不含引号，形如 `101`。

约束：

- $2 \le |s| \le 10^5$
- $s[i] \in \{0, 1\}$
- `s` 中至少各有一个 `0` 和一个 `1`

## 输出描述

一行字符串：双方最优修订后的剩余串。

## 样例1

输入：

```
101
```

输出：

```
1
```

说明：

- 卡上只有一个 `0`，甲只能涂掉它，剩余 `11`
- 乙从 `11` 里擦掉一个 `1`（擦哪一个结果相同），剩余 `1`

## 样例2

输入：

```
0001
```

输出：

```
00
```

说明：

- 甲为了让剩余串尽量大，应涂掉**最靠前**的空格 `0`，剩余 `001`
- 乙再擦掉最靠前的 `1`（也是唯一的已涂格），剩余 `00`
- 若甲去涂更靠后的空格，剩余串会更小，对甲更差

## 样例3

输入：

```
110010
```

输出：

```
1010
```

说明：甲涂掉最早的 `0`（下标从 `0` 计的第 `2` 位），乙擦掉最早的 `1`（第 `0` 位），剩下 `1010`。
