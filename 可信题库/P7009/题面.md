# 题目内容

零信任网关要把一次会话从入口节点 `src` 转到目标服务 `dst`。安全域之间有若干**有向**转发通道，第 $i$ 条记为 $\texttt{edges}[i]=[u,v,\textit{delay},\textit{risk}]$：

- 从节点 $u$ 到节点 $v$
- 增加时延 $\textit{delay}$
- 消耗风险额度 $\textit{risk}$（策略引擎按通道敏感度扣减）

会话开始时拥有风险额度 `riskBudget`。一条路径合法，当且仅当路径上所有通道的 $\textit{risk}$ **之和**不超过 `riskBudget`。路径时延为各通道 $\textit{delay}$ 之和。

请返回：在额度内从 `src` 到达 `dst` 的**最小时延**。若没有任何合法路径，返回 $-1$。

补充约定：

- 节点编号为 $0\sim n-1$
- 允许重边；允许自环
- 若 $\textit{src}=\textit{dst}$，视为已在目标处，返回 $0$（不消耗额度）
- 同一节点可能需要以**不同已用额度**到达：只记录「到达该点的最小时延」而丢掉高时延、低风险的走法，可能得到错误答案

请实现：

```text
minTrustDelay(n: int, edges: int[][], src: int, dst: int, riskBudget: int) -> int
```

## 输入描述

五行：

- 第一行：整数 `n`，节点数
- 第二行：二维数组 `edges`，每一项为 `[u, v, delay, risk]`
- 第三行：整数 `src`
- 第四行：整数 `dst`
- 第五行：整数 `riskBudget`

约束：

- $1 \le n \le 200$
- $0 \le \texttt{edges.length} \le 4000$
- $0 \le u,v < n$
- $1 \le \textit{delay} \le 1000$
- $0 \le \textit{risk} \le 1000$
- $0 \le \textit{src},\textit{dst} < n$
- $0 \le \textit{riskBudget} \le 1000$

## 输出描述

一个整数：最小合法时延；不可达时为 $-1$。

## 样例1

输入：

```
3
[[0, 1, 5, 3], [1, 2, 4, 2], [0, 2, 20, 1]]
0
2
5
```

输出：

```
9
```

说明：路径 $0\to 1\to 2$ 时延 $9$、风险 $5$，额度刚好够；直达 $0\to 2$ 时延 $20$ 更大。

## 样例2

输入：

```
3
[[0, 1, 5, 3], [1, 2, 4, 2], [0, 2, 20, 1]]
0
2
4
```

输出：

```
20
```

说明：额度改为 $4$ 后，$0\to 1\to 2$ 的风险 $5$ 超标，只能走直达。

## 样例3

输入：

```
4
[[0, 1, 1, 8], [0, 2, 5, 1], [2, 1, 1, 1], [1, 3, 1, 3]]
0
3
5
```

输出：

```
7
```

说明：走 $0\to 1\to 3$ 时延更小，但风险 $11$ 超标。必须绕 $0\to 2\to 1\to 3$（时延 $7$、风险 $5$）。若到达节点 $1$ 时只保留「时延最小」的那次（风险已用 $8$），会误判不可达。
