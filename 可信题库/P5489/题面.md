# 投篮刷新间隔

# 题目内容

周末篮球加练时，教练按时间顺序记下每次投篮得分，得到数组 $scores$。第一次出手一定记为一次**刷新**；之后只有当某次得分**严格大于**此前所有得分时，才再记一次刷新。

请返回长度为 $2$ 的数组：

- 第 $0$ 项：刷新次数
- 第 $1$ 项：相邻两次刷新之间下标差的最大值（下标从 $0$ 计）。若全程只有一次刷新，该项为 $0$

请实现：

```text
bestShotRecords(scores: int[]) -> int[]
```

## 输入描述

一行整型数组，形如 $[2, 5, 3, 8, 8, 10]$。

约束：

- $1 \le scores.length \le 10^5$
- $1 \le scores[i] \le 10^9$

## 输出描述

一行长度为 $2$ 的整型数组，形如 $[4, 2]$。

## 样例1

输入：

```
[2, 5, 3, 8, 8, 10]
```

输出：

```
[4, 2]
```

说明：

- 下标 $0$ 得分 $2$，第一次必刷新
- 下标 $1$ 得分 $5$，大于 $2$，刷新
- 下标 $2$ 得分 $3$，未超过历史最高 $5$
- 下标 $3$ 得分 $8$，刷新
- 下标 $4$ 得分 $8$，相等不算刷新
- 下标 $5$ 得分 $10$，刷新
- 共 $4$ 次刷新，相邻下标差为 $1$、$2$、$2$，最大为 $2$

## 样例2

输入：

```
[9, 7, 4]
```

输出：

```
[1, 0]
```

说明：后面两次都比第一次低，只有一次刷新，间隔记 $0$。

## 样例3

输入：

```
[1, 3, 5, 7]
```

输出：

```
[4, 1]
```

说明：每次都刷新，相邻下标差都是 $1$。
