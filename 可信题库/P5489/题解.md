## 解题思路

本题是一次**线性扫描**，同时维护前缀最大值。

从左到右遍历 $scores$：

- 下标 $0$ 一定是一次刷新，记下位置，并把当前最高分设为 $scores[0]$。
- 之后仅当 $scores[i]$ **严格大于**当前最高分时，才记一次刷新：用 $i$ 与上一次刷新下标的差更新最大间隔，再把最高分与上一次位置改成当前这次。
- 相等或更小都不刷新，这是易错点。

接口 $bestShotRecords(scores)$ 返回 $[刷新次数, 最大下标差]$。只有一次刷新时，最大间隔保持 $0$。

## 复杂度分析

- 时间复杂度：$O(n)$，每个得分看一次。
- 空间复杂度：$O(1)$（不计返回数组），只需记录次数、上一次位置和当前最高分。

## 代码实现

### Python

```python
from typing import List


class Solution:
    def bestShotRecords(self, scores: List[int]) -> List[int]:
        cnt = 1
        last = 0
        best = scores[0]
        gap = 0
        for i in range(1, len(scores)):
            # 只有严格超过历史最高才算刷新
            if scores[i] > best:
                if i - last > gap:
                    gap = i - last
                last = i
                best = scores[i]
                cnt += 1
        return [cnt, gap]
```

```c
#include <stdlib.h>

int* bestShotRecords(int* scores, int scoresSize, int* returnSize) {
    int* ans = (int*)malloc(2 * sizeof(int));
    *returnSize = 2;
    int cnt = 1, last = 0, best = scores[0], gap = 0;
    for (int i = 1; i < scoresSize; i++) {
        /* 只有严格超过历史最高才算刷新 */
        if (scores[i] > best) {
            if (i - last > gap) {
                gap = i - last;
            }
            last = i;
            best = scores[i];
            cnt++;
        }
    }
    ans[0] = cnt;
    ans[1] = gap;
    return ans;
}
```
