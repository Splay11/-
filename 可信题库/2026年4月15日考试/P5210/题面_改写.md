# 矩形六向对齐

# 题目内容

平面左上角为 $(0,0)$，坐标轴向右、向下为正（如下图）。给定矩形列表 `cards`，`cards[i]=[x,y,width,height]` 表示左上角 $(x,y)$、宽 `width`、高 `height`。按 `alignment` 将它们对齐后，按原顺序返回各矩形的新四元组。宽高不变，只改 `x` 或只改 `y`。

![](file://42RFLxgjkFAhei3M8BI7y.png)

`alignment` 只能取下列之一：

- `top`：所有顶边对齐到当前最靠上的顶边
- `bottom`：所有底边对齐到当前最靠下的底边
- `left`：所有左边对齐到当前最靠左的左边
- `right`：所有右边对齐到当前最靠右的右边
- `horizontal_center`：水平居中——先取全体最左边界 $x_1$ 与最右边界 $x_r$（某矩形右边界为 $x+\textit{width}$），令 $\textit{MiddleX}=\lfloor(x_1+x_r)/2\rfloor$；再使每个矩形的 $\lfloor x+\textit{width}/2\rfloor$ 等于 $\textit{MiddleX}$
- `vertical_center`：垂直居中——同理对 $y$ 与高度计算 $\textit{MiddleY}$ 并上下移动

图中从左到右示意同一组矩形的原位置、右对齐、水平居中对齐。

## 输入描述

- 参数一：`cards`，$1\le \texttt{cards.length}\le 100$，$0\le x,y<1000$，$1\le \textit{width},\textit{height}\le 1000$。
- 参数二：`alignment`（上述六种字符串之一）。

## 输出描述

与 `cards` 等长、顺序相同的列表，元素为对齐后的 `[new_x, new_y, width, height]`。

## 样例1

输入：

```
[[1, 1, 3, 2], [4, 2, 2, 2], [5, 5, 4, 2]]
"right"
```

输出：

```
[[6, 1, 3, 2], [7, 2, 2, 2], [5, 5, 4, 2]]
```

**说明：**

与图中「右对齐」一致。最右边界为 $9$，各矩形右边界对齐到 $9$，得到新 $x$ 为 $6,7,5$。

## 样例2

输入：

```
[[1, 1, 3, 2], [4, 2, 2, 2], [5, 5, 4, 2]]
"horizontal_center"
```

输出：

```
[[4, 1, 3, 2], [4, 2, 2, 2], [3, 5, 4, 2]]
```

**说明：**

与图中「水平居中对齐」一致。$\textit{MiddleX}=\lfloor(1+9)/2\rfloor=5$，各矩形水平中点对齐到 $5$。

## 样例3

输入：

```
[[2, 3, 2, 2], [0, 1, 3, 1], [4, 5, 1, 2]]
"top"
```

输出：

```
[[2, 1, 2, 2], [0, 1, 3, 1], [4, 1, 1, 2]]
```

**说明：**

最靠上的顶边为 $y=1$，三个矩形顶边均移到 $y=1$。
