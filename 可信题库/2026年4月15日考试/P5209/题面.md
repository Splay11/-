# 题目内容

给出一个整数序列 `numbers`，元素值各不相同。请计算所有连续子序列的中位数之和。

**中位数定义**：将一组数据按从小到大顺序排列起来，形成一个新序列，居于新序列中间位置的那个数是中位数。即：

- 如果数据的个数是奇数，则中间那个数是中位数；
- 如果数据的个数是偶数，则中间两个数中较小的那个是中位数。

## 输入描述

`1 <= numbers.length <= 100`，`0 <= numbers[i] <= 10^5`，且元素值各不相同。

## 输出描述

一个整数，表示所计算的中位数之和。

## 样例1

输入：

```
[1, 5, 7, 4]
```

输出：

```
41
```

解释：

所包含的所有连续子序列，及其中位数如下：

- 子序列 `[1]` 的中位数是 `1`
- 子序列 `[1, 5]` 的中位数是 `1`
- 子序列 `[1, 5, 7]` 的中位数是 `5`
- 子序列 `[1, 5, 7, 4]`，排序后为 `[1, 4, 5, 7]`，其中位数是 `4`
- 子序列 `[5]` 的中位数是 `5`
- 子序列 `[5, 7]` 的中位数是 `5`
- 子序列 `[5, 7, 4]` 的中位数是 `5`
- 子序列 `[7]` 的中位数是 `7`
- 子序列 `[7, 4]` 的中位数是 `4`
- 子序列 `[4]` 的中位数是 `4`

所以最终答案为 `1 + 1 + 5 + 4 + 5 + 5 + 5 + 7 + 4 + 4 = 41`。
