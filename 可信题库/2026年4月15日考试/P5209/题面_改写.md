# 连续子数组中位数之和

# 题目内容

给定互异整数数组 `numbers`。对每一个连续子数组，将其元素排序后取中位数并求和。中位数规定为：长度奇数取正中间；长度偶数取中间两个中的较小者。

## 输入描述

`numbers` 满足 $1\le \texttt{numbers.length}\le 100$，$0\le \texttt{numbers}[i]\le 10^5$，且元素两两不同。

## 输出描述

一个整数：所有连续子数组中位数之和。

## 样例1

输入：

```
[2, 8, 3]
```

输出：

```
21
```

**说明：**

子数组及中位数：`[2]→2`，`[2,8]→2`，`[2,8,3]→3`，`[8]→8`，`[8,3]→3`，`[3]→3`。和为 $21$。

## 样例2

输入：

```
[9, 1, 4, 6]
```

输出：

```
38
```

**说明：**

全部 $10$ 个连续子数组的中位数之和为 $38$（可用逐段有序插入手算核对）。
