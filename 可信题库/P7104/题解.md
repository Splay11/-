## 解题思路

半开区间 $[l,r)$ 加 $w$，用**差分数组**：在 $l$ 处 $+w$，在 $r$ 处 $-w$，再从前到后前缀和还原每一段的负载，取最大值。

右端点 $r$ **不加**到第 $r$ 段。$n=10^5$、$m=10^5$ 时不能对每个任务暴力扫区间。

峰值可能很大，累加用 $64$ 位。

**常见假解**：把 $[l,r)$ 当成闭区间（在 $r$ 也加）；差分数组只在 $r-1$ 减；用 $32$ 位溢出。

## 复杂度分析

- 时间复杂度：$O(n+m)$。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
from typing import List


class Solution:
    def maxLinkLoad(self, n: int, ops: List[List[int]]) -> int:
        diff = [0] * (n + 1)
        for l, r, w in ops:
            # 半开 [l, r)：r 处撤回
            diff[l] += w
            diff[r] -= w
        ans = 0
        cur = 0
        for i in range(n):
            cur += diff[i]
            if cur > ans:
                ans = cur
        return ans
```

### Java

```java
class Solution {
    public long maxLinkLoad(int n, int[][] ops) {
        long[] diff = new long[n + 1];
        for (int[] op : ops) {
            diff[op[0]] += op[2];
            diff[op[1]] -= op[2]; // 不含 r
        }
        long ans = 0, cur = 0;
        for (int i = 0; i < n; i++) {
            cur += diff[i];
            if (cur > ans) ans = cur;
        }
        return ans;
    }
}
```

### C

```c
#include <stdlib.h>

long long maxLinkLoad(int n, int* L, int* R, int* W, int m) {
    long long* diff = (long long*)calloc((size_t)n + 1, sizeof(long long));
    for (int i = 0; i < m; i++) {
        diff[L[i]] += W[i];
        diff[R[i]] -= W[i];
    }
    long long ans = 0, cur = 0;
    for (int i = 0; i < n; i++) {
        cur += diff[i];
        if (cur > ans) ans = cur;
    }
    free(diff);
    return ans;
}
```
