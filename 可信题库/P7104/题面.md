# 题目内容

骨干光纤被均分成 $n$ 段，编号 $0,1,\ldots,n-1$。运维下发若干切片任务 `ops`，每一项为 `[l, r, load]`：

- 给半开区间 $[\textit{l},\,\textit{r})$ 上的每一段增加负载 `load`
- 即覆盖编号 $l,l+1,\ldots,r-1$，**不含**第 $r$ 段

保证 $0\le l < r \le n$。若 `ops` 为空，所有段负载为 $0$。

请返回所有任务生效后，各段负载的**最大值**。

请实现：

```text
maxLinkLoad(n: int, ops: int[][]) -> long
```

（峰值可能超过 $32$ 位有符号整数，请使用 $64$ 位整数。）

## 输入描述

两行：

- 第一行：整数 `n`
- 第二行：二维数组 `ops`，形如 `[[0, 2, 3], [1, 4, 2]]`

约束：

- $1 \le n \le 10^5$
- $0 \le m \le 10^5$，$m=\texttt{ops.length}$
- $0 \le l < r \le n$
- $0 \le \textit{load} \le 10^9$

## 输出描述

一个整数：峰值负载。

## 样例1

输入：

```
5
[[0, 2, 3], [1, 4, 2]]
```

输出：

```
5
```

说明：区间 $[0,2)$ 加 $3$、$[1,4)$ 加 $2$。各段负载为 $3,5,2,2,0$，峰值 $5$。右端点 $r$ 对应的第 $r$ 段不加本次负载。

## 样例2

输入：

```
3
[]
```

输出：

```
0
```

说明：没有任何切片，峰值 $0$。

## 样例3

输入：

```
1
[[0, 1, 9]]
```

输出：

```
9
```

说明：唯一一段 $[0,1)$ 加 $9$。
