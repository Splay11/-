# 稀疏单元格转 ASCII 表

# 题目内容

给定若干单元格 `Cell`，每个包含：

- `rowNum`：行号（从 $1$ 起）
- `colNum`：列号（从 $1$ 起）
- `content`：单元格文本

请将它们渲染为一张 ASCII 表格（字符串数组，按行从上到下）。规则：

1. **列数**为 $\max(colNum)$（列编号 $1..C$）；**行**只保留输入中实际出现过的 `rowNum`（升序），不输出中间空行。
2. 未给出的格子视为空串 `""`；同一位置多次出现时，以后出现的为准。
3. 单元格内容区宽度 $w=\max(3,\ \max |content|)$。文本**左对齐**，右侧补空格至宽度 $w$。
4. 仅有顶边与底边水平线（行间不再插入水平线）；列之间用 `|`。水平线为 `+` + 每列 $w$ 个 `-`，再以 `+` 收尾。

请实现：

```text
transformTable(table: Cell[]) -> string[]
```

其中 `Cell` 提供构造 `Cell(rowNum, colNum, content)`。

## 输入描述

一行混合数组，每项为 `[rowNum, colNum, content]`，形如：

```
[[1,3,""],[3,2,""]]
```

约束：$1\le n\le 200$；$1\le rowNum,colNum\le 50$；$|content|\le 20$，仅含可见 ASCII（不含 `"` 与换行）。

## 输出描述

一行字符串数组（JSON 风格，元素带双引号）。

## 样例1

输入：

```
[[1,3,""],[3,2,""]]
```

输出：

```
["+---+---+---+","|   |   |   |","|   |   |   |","+---+---+---+"]
```

**说明：** $\max(colNum)=3$ 故 3 列；出现行号为 $1,3$ 共 2 行；内容全空故 $w=3$。

## 样例2

输入：

```
[[1,1,"A"],[1,2,"BC"],[2,1,"D"]]
```

输出：

```
["+---+---+","|A  |BC |","|D  |   |","+---+---+"]
```

**说明：** 2 行 2 列；最长文本长度 $2$，但 $w$ 下限为 $3$。
