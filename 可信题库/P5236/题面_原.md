# 题目来源手稿推断

接口见 TypeScript 草稿：`Cell(rowNum,colNum,content)` + `Solution.transformTable(table: Cell[]): string[]`。

用例：

输入 `[[1, 3, ""], [3, 2, ""]]`

输出（手稿可见顶/底框与若干内容行；按 $\max+1$ 推得完整 $4\times 4$）：

```
+---+---+---+---+
|   |   |   |   |
|   |   |   |   |
|   |   |   |   |
|   |   |   |   |
+---+---+---+---+
```

手稿图见同目录 `原题手稿.png`。
