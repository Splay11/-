# 记分牌订正

# 题目内容

训练赛用记分牌逐回合记录净胜分：主队这一回合赢记正数，输记负数。赛后裁判发现**恰好有一个回合的符号记反了**，其余回合都没问题。他想知道：把那个回合订正过来之后，全场总净胜分**最大可能是多少**。

数组 `scores` 有 $n$ 项，第 $i$ 项是第 $i$ 个回合记录的净胜分。记反的那一项，真实的值就是它的相反数。请在所有「到底是哪一项记反了」的可能性里算出订正后的总净胜分，并返回其中**最大**的那个值。

请实现：

```text
bestCorrectedTotal(scores: int[]) -> int
```

## 输入描述

一行整型数组，形如 `[3, -5, 4]`。

约束：

- $1 \le \texttt{scores.length} \le 10^5$
- $-10^9 \le \texttt{scores}[i] \le 10^9$

## 输出描述

一个整数：订正后可能的最大总净胜分。

## 样例1

输入：

```
[3, -5, 4]
```

输出：

```
12
```

说明：原总分是 `2`。若记反的是第 `2` 项（`-5`），它真实应为 `5`，订正后总分 `3 + 5 + 4 = 12`；若订正第 `1` 项得 `-4`，订正第 `3` 项得 `-6`，所以最大是 `12`。

## 样例2

输入：

```
[2, 2]
```

输出：

```
0
```

说明：原总分 `4`；订正任一项后都是 `4 - 4 = 0`。

## 样例3

输入：

```
[-1]
```

输出：

```
1
```

说明：只有一个回合，订正后总分是 `1`。
