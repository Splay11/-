# 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin 一行整型数组，形如 `[3, -5, 4]`，与题面样例同形。

| 组 | 说明 |
|---:|---|
| 1 | 样例1：[3, -5, 4] |
| 2 | 样例2：[2, 2] |
| 3 | 样例3：[-1] |
| 4 | 只有一个元素的正数 [5] |
| 5 | 全部为正 [1, 2, 3] |
| 6 | 全部为负 [-1, -2, -3] |
| 7 | 最小项在末尾 [4, 9, 2, 7, -5] |
| 8 | 最小负值 -1000000000 夹在正数中，答案超 32 位 |
| 9 | 中等随机 n=1000，含负数 |
| 10 | 极限 n=100000，元素在 ±10^9 之间 |
