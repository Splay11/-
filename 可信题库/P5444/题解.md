## 解题思路

本题是**贪心**：只要把「哪一项记反了」这件事想清楚，就不用逐项去试。

- 先把所有记录加起来，得到原总分 $S$。
- 如果记反的是第 $i$ 项，它真实的值应该是 `-scores[i]`。把原来的 `scores[i]` 换成 `-scores[i]`，总分的变化量就是 `-2 * scores[i]`，所以订正后的总分是 $S - 2 \times \texttt{scores}[i]$。
- 要让订正后的总分**最大**，就要让减掉的那部分**最小**，也就是挑 `scores` 里**最小**的那一项去订正。
- 所以答案就是 $S - 2 \times \min(\texttt{scores})$。

求和与求最小值可以在**同一趟循环**里完成：一边累加总和，一边用更小的元素更新最小值。不需要排序，也不需要枚举每一项重算一次总分。

订正后的答案最大能到 $10^{14}$ 量级，超出了 `32` 位整数范围，所以 C++、Java、C 里保存总和与答案要用 `long long`/`long`。

接口 `bestCorrectedTotal(scores)` 照着这个观察直接写：先把第一项当作最小值，然后从数组开头扫到结尾。

## 复杂度分析

- 时间：$O(n)$，每个元素只被访问常数次，只有一趟循环。
- 空间：$O(1)$，只用两个变量保存总和与最小值。

## 代码实现

### Python

```python
from typing import List


class Solution:
    def bestCorrectedTotal(self, scores: List[int]) -> int:
        total = 0
        # 数组非空，先把第一项当作最小值
        mn = scores[0]
        # 一趟循环同时求出原总分与最小项
        for v in scores:
            total += v
            if v < mn:
                mn = v
        # 订正最小项后总分是 total - 2 * mn，这是所有选择里最大的
        return total - 2 * mn
```

### Java

```java
class Solution {
    public long bestCorrectedTotal(int[] scores) {
        long total = 0;
        // 数组非空，先把第一项当作最小值
        int mn = scores[0];
        // 一趟循环同时求出原总分与最小项
        for (int v : scores) {
            total += v;
            if (v < mn) mn = v;
        }
        // 订正最小项得到最大总分 total - 2 * mn；总和可能超 32 位，用 long
        return total - 2L * mn;
    }
}
```

### C

```c
long long bestCorrectedTotal(int* scores, int n) {
    long long total = 0;
    /* 数组非空，先把第一项当作最小值 */
    int mn = scores[0];
    /* 一趟循环同时求出原总分与最小项 */
    for (int i = 0; i < n; i++) {
        total += scores[i];
        if (scores[i] < mn) mn = scores[i];
    }
    /* 订正最小项得到最大总分 total - 2 * mn；总和可能超 32 位，用 long long */
    return total - 2LL * mn;
}
```
