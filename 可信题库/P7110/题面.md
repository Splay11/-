# 题目内容

某团队要在连续 $n$ 个工作日内完成 $m$ 门**合规认证科目**的上机考核（科目编号为 $1\sim m$）。排班表是长度为 $n$ 的数组 `slots`：

- $\texttt{slots}[i]=t$（$1\le t\le m$）：第 $i$ 天（从 $0$ 起）**只允许**参加科目 $t$ 的考试
- $\texttt{slots}[i]=0$：这一天不能考试，只能复习或休息

规则如下：

1. 每门科目必须**恰好考试一次**，且只能在 `slots` 允许该科目的某一天考试
2. 同一天最多考一门（由 `slots` 本身保证至多一个科目）
3. 考科目 $t$ 之前，必须累计完成 $\texttt{prep}[t-1]$ 天**复习**（复习天可以不连续，也可以穿插复习别的科目；考试当天不算复习）
4. 某一天要么用来考试，要么用来复习/休息，不能同时做两件事

请返回：从第 `0` 天起，至少需要占用前多少天（即最短前缀长度），才能让 $m$ 门科目全部考完。若在全部 $n$ 天内仍不可能，返回 `-1`。

补充约定：

- 复习天数可以来自「`slots` 为 `0` 的天」以及「有考试名额但你选择不在那天考、拿来复习」的天
- 为了尽早结束，对每个候选前缀，最优策略是：**每门科目都尽量安排在该前缀内最后一次可考日考试**

请实现：

```text
minPassDays(slots: int[], prep: int[]) -> int
```

## 输入描述

两行：

- 第一行：整型数组 `slots`
- 第二行：整型数组 `prep`

约束：

- $1 \le n \le 10^5$，$n=\texttt{slots.length}$
- $1 \le m \le 10^5$，$m=\texttt{prep.length}$
- $0 \le \texttt{slots}[i] \le m$
- $1 \le \texttt{prep}[j] \le 10^5$

## 输出描述

一个整数：最短前缀天数；不可能则 `-1`。

## 样例1

输入：

```
[0, 1, 0, 2, 1, 0, 2]
[2, 1]
```

输出：

```
5
```

说明：只看前 `5` 天 `[0,1,0,2,1]`。一种方案：第 `0`、`1` 天复习科目 `1`，第 `4` 天考科目 `1`；第 `2` 天复习科目 `2`，第 `3` 天考科目 `2`。前 `4` 天不够完成两门。

## 样例2

输入：

```
[0, 0, 1, 2, 3, 0, 2, 0, 1, 2]
[1, 1, 4]
```

输出：

```
9
```

说明：科目 `3` 需要 `4` 天复习，必须尽早囤复习日，并在第 `4` 天考掉；之后再安排科目 `2`、`1`。前 `9` 天刚好够，更短前缀不够。

## 样例3

输入：

```
[1, 1, 1, 1, 1]
[5]
```

输出：

```
-1
```

说明：唯一科目需要 `5` 天复习再考试，但总共只有 `5` 天且每天都只能考试、挤不出 `5` 个复习日。
