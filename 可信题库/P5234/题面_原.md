# 题目内容

给定一个由字母组成的字符串 `lettersStr`，请按照以下规则对其进行变换：

1. **排序**：将字符串中的每个字符按照其 **ASCII 码值** 从小到大（升序）进行排列，得到排序后的字符串。

2. **位置变换**：对排序后的每个字符依次进行如下计算：
   - 获取该字母在字母表中的位置（不区分大小写，即 `A/a = 1`，`B/b = 2`，...，`Z/z = 26`）。
   - 计算该位置的 **平方**。
   - 将平方结果对 26 取余数，然后 **加 1**，得到新位置。
   - 根据新位置取出对应的字母（`1 → A`，`2 → B`，...，`26 → Z`）。

3. **大小写取反**：变换后的字母，其大小写与**原字符**（排序后该位置的字符）相反（即原字符为大写则变为小写，原字符为小写则变为大写）。

## 输入描述

输入一个字符串 `lettersStr`，仅包含大小写字母。

## 输出描述

输出变换后的字符串。

## 样例1

输入：

```
abB
```

输出：

```
eBE
```

**过程说明：**

1. 按 ASCII 码升序排列：`B`(66)、`a`(97)、`b`(98) → `"Bab"`
2. 依次变换：
   - `B`：位置 2 → $2^2=4$ → $4\%26+1=5$ → `E`，原大写取反 → `e`
   - `a`：位置 1 → $1^2=1$ → $1\%26+1=2$ → `B`，原小写取反 → `B`
   - `b`：位置 2 → $2^2=4$ → $4\%26+1=5$ → `E`，原小写取反 → `E`
3. 结果：`eBE`

## 补充说明

- 字母表位置：`A=1,...,Z=26`，大小写位置相同。
- 变换公式：`newPos = (pos² % 26) + 1`
- 结果中每个字母大小写与排序后对应字符的大小写相反。
