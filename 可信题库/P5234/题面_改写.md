# 字母串排序变换

# 题目内容

给定仅含大小写英文字母的字符串 `lettersStr`，按下列三步变换后返回结果串：

1. **按 ASCII 升序**重排所有字符。
2. 对重排后的每个字符：令字母表位置 $pos\in[1,26]$（大小写相同，`A/a=1,\ldots,Z/z=26`），计算
   $$
   newPos=(pos^2\bmod 26)+1
   $$
   再取对应大写字母（$1\to\texttt{A},\ldots,26\to\texttt{Z}$）。
3. **大小写取反**：上一步得到的字母，大小写与重排后该位置**原字符**相反（原大写→结果小写，原小写→结果大写）。

请实现：

```text
sortLetter(lettersStr: string) -> string
```

## 输入描述

一行带双引号的字符串，形如：

```
"abB"
```

约束：$1\le |lettersStr|\le 10^4$，仅含大小写英文字母。

## 输出描述

一行带双引号的结果字符串，例如 `"eBE"`。

## 样例1

输入：

```
"abB"
```

输出：

```
"eBE"
```

**说明：**

ASCII 排序得 `"Bab"`。  
`B`：$pos=2\to 4\%26+1=5\to\texttt{E}$，取反小写 `e`；  
`a`：$pos=1\to 1\%26+1=2\to\texttt{B}$，取反大写 `B`；  
`b`：$pos=2\to 5\to\texttt{E}$，取反大写 `E`。
