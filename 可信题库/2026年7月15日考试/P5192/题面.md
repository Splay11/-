# 题目内容

现有一个正整数数组 `numbers`，请按如下规则对其进行排序：

- 奇数仍在奇数所在的位置，进行升序排序
- 偶数仍在偶数所在的位置，进行降序排序

# 输入描述

`1 <= numbers.length <= 100`，每个元素值范围 `[1, 1000]`

# 输出描述

一个整数序列，表示排序后的数组

## 样例1

**输入：**

```
[5,2,2,3,6,5]
```

**输出：**

```
[3,6,2,5,2,5]
```

解释：

下标 0、3、5 的值为奇数，分别为 5、3、5，按升序排序后，下标 0、3、5 的值变为 3、5、5。

下标 1、2、4 的值为偶数，分别为 2、2、6，按降序排序后，下标 1、2、4 的值变为 6、2、2。

## 样例2

**输入：**

```
[5,3]
```

**输出：**

```
[3,5]
```
