# 题目内容

在一个字符矩阵中，处于同一行（只能从左往右）或同一列（只能从上往下）的连续相邻的字母可以组成一个单词。例如下图所示的 ACEI、NX：

![](file://zTgqZDhzWgX4n5ZSt2SEg.png)


给定一个字符矩阵 `charMatrix` 和目标单词列表 `words`，请计算这个字符矩阵可以组成多少个 `words` 中的单词。

矩阵中每个格子的字符，在不同的单词之间可以重复使用。

## 输入描述

第一个参数为字符矩阵 `charMatrix`，字符矩阵仅由大写字母组成，`1 <= charMatrix.length <= 10`，`1 <= charMatrix[i].length <= 10`，用例保证列宽相同。

第二个参数为单词列表 `words`，单词仅由大写字母组成，`1 <= words.length <= 100`，`1 <= words[i].length <= 10`，`words` 中单词不重复。

## 输出描述

一个整数，表示可组成的单词的数量

## 样例1

输入：

```
["ACEI","EXNI","USXJ"]
["A","ACEI","ACCE","NX","CX","X","EXN","XC","ACX","AA","UX"]
```

输出：

```
6
```

解释：

A、ACEI、NX、CX、X、EXN 这 6 个单词符合规则。XC 不满足从上往下，ACX 不在同一行或同一列，ACCE、AA 和 UX 也不符合规则。

## 样例2

输入：

```
["JSWGWLTOA"]
["VA","S","AA","TA","AO"]
```

输出：

```
1
```
