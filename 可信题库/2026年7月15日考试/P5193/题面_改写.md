# 行列单向子串计数

# 题目内容

在大写字母字符矩阵 `charMatrix` 中，一个串合法当且仅当它是某一行从左到右的连续子串，或某一列从上到下的连续子串（不可反向，不可拐弯）。给定不重复单词表 `words`，统计其中有多少个能在矩阵里按上述规则找到。不同单词之间格子可重复使用。

## 输入描述

- 参数一：`charMatrix`，仅含大写字母；行数、列数均不超过 $10$，且不少于 $1$；各行列宽一致。
- 参数二：`words`，仅含大写字母；单词个数不超过 $100$，每个单词长度不超过 $10$，且互不相同。

## 输出描述

返回可匹配到的单词个数（整数）。

## 样例1

输入：

```
["AB","CD"]
["A","AB","AC","CD","BD","DC","B"]
```

输出：

```
6
```

**说明：**

行子串含 `A`、`B`、`AB`、`C`、`D`、`CD`；列子串含 `A`、`C`、`AC`、`B`、`D`、`BD`。因此 `A`、`AB`、`AC`、`CD`、`BD`、`B` 共 $6$ 个合法；`DC` 是反向，不计。

## 样例2

输入：

```
["XYZ"]
["XY","YZ","ZY","X"]
```

输出：

```
3
```

**说明：**

只有一行，合法子串为 `X`、`Y`、`Z`、`XY`、`YZ`、`XYZ`。`XY`、`YZ`、`X` 命中；`ZY` 方向相反，不命中。
