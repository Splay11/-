## 解题思路

本题是经典的**一次扫描模拟**：从左到右遍历心跳数组 `beats`。

- 用 `cur` 记录当前连续健康（值为 `1`）的长度。
- 遇到 `1` 时 `cur += 1`，并用 `best` 维护历史最大值。
- 遇到 `0` 时把 `cur` 清零，表示连续段被打断。
- 若全程没有 `1`，`best` 保持为 `0`。

接口 `longestHealthy(beats)` 只需返回 `best`。

## 复杂度分析

- 时间：$O(n)$，每个元素访问一次。
- 空间：$O(1)$，仅用常数个计数变量。

## 代码实现

### Python

```python
from typing import List


class Solution:
    def longestHealthy(self, beats: List[int]) -> int:
        best = cur = 0
        for x in beats:
            if x == 1:
                # 延续当前健康段，并更新全局最长
                cur += 1
                if cur > best:
                    best = cur
            else:
                # 失败心跳打断连续段
                cur = 0
        return best
```
