# 题目内容

运维系统按时间顺序记录某服务的心跳结果 `beats`。数组中每个元素只取两种值：

- `1`：该次心跳健康
- `0`：该次心跳失败

请返回**最长连续健康心跳**的长度。若一次健康都没有，返回 `0`。

请实现：

```text
longestHealthy(beats: int[]) -> int
```

## 输入描述

一行：整型数组 `beats`，形如 `[1, 1, 0, 1, 1, 1]`。

约束：

- $0 \le \texttt{beats.length} \le 10^5$
- $\texttt{beats}[i] \in \{0, 1\}$

## 输出描述

一个整数：最长连续 `1` 的长度。

## 样例1

输入：

```
[1, 1, 0, 1, 1, 1]
```

输出：

```
3
```

说明：末尾连续三个 `1` 最长，长度为 $3$。中间还有一段长度为 $2$ 的连续健康。

## 样例2

输入：

```
[0, 0, 0]
```

输出：

```
0
```

说明：没有健康心跳。

## 样例3

输入：

```
[1]
```

输出：

```
1
```
