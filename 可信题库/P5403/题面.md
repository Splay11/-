# 练歌房麦序

# 题目内容

社区练歌房用一块麦序看板给等候的曲子排队。每首曲子有编号 `songId` 和当前热度 `heat`。下一位开唱的规则是：

- **热度更高的先唱**
- 热度相同则 **编号更小的先唱**

请实现类 `MicQueue`：

- `MicQueue()`：空队列。
- `enroll(songId, heat)`：把曲子加入等候。若该 `songId` **已经在队列里**，失败返回 `false`；否则加入并返回 `true`。
- `nextPlay()`：弹出并返回下一位应唱的 `songId`。队列为空返回 `-1`。
- `boost(songId, addHeat)`：给仍在等候的曲子增加热度（$addHeat \ge 1$）。不在队列中则返回 `false`，否则改热度并返回 `true`。
- `cancel(songId)`：从队列中撤下该曲。成功 `true`，本来就不在队列则 `false`。
- `waiting()`：当前仍在等候的曲子数量。

`boost` 只影响尚未 `nextPlay` 的曲子。已经唱过或被 `cancel` 的编号可以再次 `enroll`（当作新点的一首）。多次加热后热度可能超过 $10^9$，请使用 $64$ 位整数保存热度。

## 输入描述

每行一次调用。首行必须是 `MicQueue()`。累计调用不超过 `8000` 次。

- $1 \le \textit{songId},\textit{heat},\textit{addHeat} \le 10^9$

## 输出描述

每次调用一行：

- 构造返回 `null`
- `enroll` / `boost` / `cancel` 返回 `true` 或 `false`
- `nextPlay` / `waiting` 返回整数

## 样例1

输入：

```
MicQueue()
enroll(3, 10)
enroll(5, 10)
enroll(3, 20)
waiting()
nextPlay()
boost(5, 5)
enroll(8, 20)
nextPlay()
nextPlay()
cancel(9)
waiting()
```

输出：

```
null
true
true
false
2
3
true
true
8
5
false
0
```

说明：

- 两首热度都是 `10` 时，编号更小的 `3` 先唱
- 重复 `enroll(3,20)` 失败，因为 `3` 还在队列里
- `boost(5,5)` 后 `5` 热度为 `15`；再加入热度 `20` 的 `8`，下一位是 `8` 然后是 `5`

## 样例2

输入：

```
MicQueue()
nextPlay()
boost(1, 1)
cancel(1)
enroll(2, 1)
cancel(2)
waiting()
enroll(2, 3)
nextPlay()
```

输出：

```
null
-1
false
false
true
true
0
true
2
```

说明：空队列上的弹出、加热、撤销都失败；撤掉后再 `enroll` 同一编号是允许的。

## 样例3

输入：

```
MicQueue()
enroll(9, 1)
enroll(4, 100)
boost(9, 50)
nextPlay()
waiting()
```

输出：

```
null
true
true
true
4
1
```

说明：`4` 热度 `100` 仍高于被加热到 `51` 的 `9`，所以先唱 `4`。
