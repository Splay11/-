# 题目内容

风控侧按时间顺序收到 $n$ 次探针读数，第 $i$ 次读数为正整数 $\texttt{loads}[i]$（下标从 $0$ 开始）。值班同学可以任选一段连续窗口 $[L,R]$，按从左到右顺序回放这段读数，并维护一个信誉水位 $g$，初始为 $0$。阈值是正整数 `cap`。

回放时，每读入一个值 $k$ 依次发生：

1. 先执行 $g \leftarrow g + k$
2. 若此时 $g \le \textit{cap}$，继续；否则把 $g$ **清零**为 $0$，再继续后面的读数

回放整段结束后，若最终 $g \ne 0$，称该窗口为**存活窗口**。

请返回：一共有多少个有序对 $(L,R)$（$0\le L\le R<n$）对应的窗口是存活窗口。

请实现：

```text
countLiveWindows(loads: int[], cap: int) -> long
```

（答案可能很大，请使用 64 位整数。）

## 输入描述

两行：

- 第一行：整型数组 `loads`
- 第二行：整数 `cap`

约束：

- $1 \le n \le 2\times 10^5$，$n=\texttt{loads.length}$
- $1 \le \texttt{loads}[i] \le 10^9$
- $1 \le \textit{cap} \le 10^9$

## 输出描述

一个整数：存活窗口的个数。

## 样例1

输入：

```
[1, 1, 1, 1]
2
```

输出：

```
8
```

说明：共 $10$ 个窗口，其中不存活的只有 $[0,2]$ 与 $[1,3]$（回放后水位被清成 $0$），故存活 $8$ 个。

## 样例2

输入：

```
[1, 2, 3]
2
```

输出：

```
2
```

说明：只有单点窗口 `[1]` 与 `[2]` 最终水位非零。

## 样例3

输入：

```
[10]
6
```

输出：

```
0
```

说明：唯一窗口回放时 $10>6$，水位被清零，最终为 $0$。
