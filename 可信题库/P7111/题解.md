## 解题思路

回放规则会在水位超过 `cap` 时清零，因此「最终 $g\neq 0$」**不等于**「整段和 $\le \textit{cap}$」。需要用 DP 处理可能发生的多次清零。

令前缀和 $\textit{pref}[0]=0$，$\textit{pref}[i]=\texttt{loads}[0]+\cdots+\texttt{loads}[i-1]$。

定义 $dp[i]$：左端点固定为 $i$ 时，有多少个右端点 $R$ 使窗口 $[i,R]$ 存活。

从右往左算。对固定左端点 $i$，在前缀和上二分出最小的 $q$，满足

$$
\textit{pref}[q] > \textit{pref}[i] + \textit{cap}
$$

含义：从 $i$ 起连续累加，到下标 $q-1$ 结束的这一段会**第一次**把水位顶破并清零。于是：

- 右端点落在 $[i,\,q-2]$ 的窗口，回放过程中不会触发清零，且最终和 $>0$（因为元素为正），共 $q-i-1$ 个，全部存活；
- 若右端点 $\ge q-1$，等价于：先完整走过一次「顶破清零」，再从位置 $q$ 当作新的左端点继续——存活个数恰好是 $dp[q]$。

因此转移：

$$
dp[i] = dp[q] + (q - i - 1)
$$

（若没有这样的 $q$，则 $q=n+1$，$dp[n+1]=0$，此时所有 $n-i$ 个右端点都存活。）

答案为 $\sum_i dp[i]$。

**常见假解**

- 只统计「子段和 $\le \textit{cap}$」的个数（忽略清零后还能继续累加）。
- 暴力模拟每个 $[L,R]$（$n=2\cdot 10^5$ 超时）。
- 二分写成找 $\ge$ 而不是严格 $>$，少算或多算一次清零点。

## 复杂度分析

- 时间：$O(n\log n)$（每个左端点一次二分）。
- 空间：$O(n)$。

## 代码实现

### Python

```python
from typing import List
import bisect


class Solution:
    def countLiveWindows(self, loads: List[int], cap: int) -> int:
        n = len(loads)
        pref = [0] * (n + 1)
        for i, x in enumerate(loads):
            pref[i + 1] = pref[i] + x
        dp = [0] * (n + 2)
        for i in range(n - 1, -1, -1):
            # 首次使前缀和超过 pref[i]+cap 的位置
            q = bisect.bisect_right(pref, pref[i] + cap)
            dp[i] = dp[q] + (q - i - 1)
        return sum(dp[: n + 1])
```

### Java

```java
class Solution {
    public long countLiveWindows(int[] loads, int cap) {
        int n = loads.length;
        long[] pref = new long[n + 1];
        for (int i = 0; i < n; i++) pref[i + 1] = pref[i] + loads[i];
        long[] dp = new long[n + 2];
        for (int i = n - 1; i >= 0; i--) {
            int q = upperBound(pref, pref[i] + cap); // 严格大于
            dp[i] = dp[q] + (q - i - 1);
        }
        long ans = 0;
        for (int i = 0; i <= n; i++) ans += dp[i];
        return ans;
    }

    private int upperBound(long[] pref, long target) {
        int lo = 0, hi = pref.length;
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (pref[mid] <= target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

```c
#include <stdlib.h>

static int upper_bound_ll(long long* pref, int len, long long target) {
    int lo = 0, hi = len;
    while (lo < hi) {
        int mid = (lo + hi) / 2;
        if (pref[mid] <= target) lo = mid + 1;
        else hi = mid;
    }
    return lo;
}

long long countLiveWindows(int* loads, int loadsSize, int cap) {
    int n = loadsSize;
    long long* pref = (long long*)malloc(sizeof(long long) * (n + 1));
    long long* dp = (long long*)calloc(n + 2, sizeof(long long));
    pref[0] = 0;
    for (int i = 0; i < n; ++i) pref[i + 1] = pref[i] + loads[i];
    for (int i = n - 1; i >= 0; --i) {
        int q = upper_bound_ll(pref, n + 1, pref[i] + (long long)cap);
        dp[i] = dp[q] + (q - i - 1);
    }
    long long ans = 0;
    for (int i = 0; i <= n; ++i) ans += dp[i];
    free(pref);
    free(dp);
    return ans;
}
```
