## 解题思路

本题是一次**线性扫描**。从左到右遍历字符串 $note$ 的每个字符：

- 若当前字符落在 $'0'$～$'9'$，立刻把它转成对应整数并返回。
- 若扫完全串都没有数字，返回 $-1$。

接口 $firstTasteLevel(note)$ 只关心**第一个**数字字符，后面的字母或数字都不必再处理。注意 $'0'$ 也是合法档位，不能当成「没有数字」而跳过。

## 复杂度分析

- 时间复杂度：$O(n)$，其中 $n$ 为 $note$ 的长度，每个字符最多看一次。
- 空间复杂度：$O(1)$，只用常数个变量。

## 代码实现

### Python

```python
class Solution:
    def firstTasteLevel(self, note: str) -> int:
        for ch in note:
            # 遇到第一个数字字符就转换成档位并返回
            if "0" <= ch <= "9":
                return ord(ch) - ord("0")
        # 整串没有数字
        return -1
```

### Java

```java
class Solution {
    public int firstTasteLevel(String note) {
        for (int i = 0; i < note.length(); i++) {
            char ch = note.charAt(i);
            // 遇到第一个数字字符就转换成档位并返回
            if (ch >= '0' && ch <= '9') {
                return ch - '0';
            }
        }
        // 整串没有数字
        return -1;
    }
}
```
