# 试味笔记首档

# 题目内容

家常炒菜时，值班师傅会在一张纸条上随手记下试味评语：小写字母是口感描述，数字 $0$ 到 $9$ 表示咸淡档。纸条从左到右写，**最先出现的那个数字**才是本次要采用的档位。

给定字符串 $note$，请返回从左到右第一个数字字符对应的整数档位。若整张纸条里一个数字都没有，返回 $-1$。

请实现：

```text
firstTasteLevel(note: str) -> int
```

## 输入描述

一行字符串，用双引号包裹，形如样例中的输入。引号内只含小写字母与数字。

约束：

- $1 \le note.length \le 10^5$
- $note$ 仅由小写字母 $a$～$z$ 与数字 $0$～$9$ 组成

## 输出描述

一个整数：第一个数字字符的数值；若不存在则输出 $-1$。

## 样例1

输入：

```
"taste3ok"
```

输出：

```
3
```

说明：从左到右先遇到数字 $3$，其后即使还有别的字符也不再看。

## 样例2

输入：

```
"nolevel"
```

输出：

```
-1
```

说明：全是字母，没有档位数字。

## 样例3

输入：

```
"0mild"
```

输出：

```
0
```

说明：开头的 $0$ 也是合法档位，不能跳过。
