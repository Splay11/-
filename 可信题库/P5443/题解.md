## 解题思路

题目要的只是「挨着的两盘差了多少」里面最小的那个，所以把每一对相邻的烤盘都算一遍、取最小值就行。

从左往右扫一遍数组，对每个位置 `i` 计算 `|cookies[i + 1] - cookies[i]|` 来更新当前的最小值；差值不分方向，统一取绝对值。第一对相邻烤盘的差可以直接当作初始答案，后面每算出一对就和它比一次——数组长度保证至少是 `2`，第一对一定存在，不用特判。

本题就是一次**模拟**：按规则扫一遍即可，不需要排序，也不需要额外的数组。

## 复杂度分析

- 时间：$O(n)$，数组只扫一遍，每对相邻元素做一次减法、一次取绝对值和一次比较。
- 空间：$O(1)$，只用了几个变量，不计输入数组本身。

## 代码实现

### Python

```python
from typing import List


class Solution:
    def minAdjacentGap(self, cookies: List[int]) -> int:
        # 先把第一对相邻烤盘的差当作当前最小答案
        ans = abs(cookies[1] - cookies[0])
        for i in range(1, len(cookies) - 1):
            # 算第 i 盘和第 i+1 盘的差，差值不分方向，取绝对值
            gap = abs(cookies[i + 1] - cookies[i])
            # 出现更小的差就更新答案
            if gap < ans:
                ans = gap
        return ans
```

```java
class Solution {
    public int minAdjacentGap(int[] cookies) {
        // 先把第一对相邻烤盘的差当作当前最小答案
        int ans = Math.abs(cookies[1] - cookies[0]);
        // 从第 1 对相邻烤盘开始往后扫
        for (int i = 1; i + 1 < cookies.length; i++) {
            // 算第 i 盘和第 i+1 盘的差，差值不分方向，取绝对值
            int gap = Math.abs(cookies[i + 1] - cookies[i]);
            // 出现更小的差就更新答案
            if (gap < ans) {
                ans = gap;
            }
        }
        return ans;
    }
}
```

### C

```c
/* C 不支持类，写成独立函数：数组首地址 + 元素个数 */
int minAdjacentGap(int* cookies, int n) {
    /* 先把第一对相邻烤盘的差当作当前最小答案 */
    int ans = cookies[1] - cookies[0];
    if (ans < 0) ans = -ans;
    /* 从第 1 对相邻烤盘开始往后扫 */
    for (int i = 1; i + 1 < n; i++) {
        /* 算第 i 盘和第 i+1 盘的差，是负数就取反当绝对值 */
        int gap = cookies[i + 1] - cookies[i];
        if (gap < 0) gap = -gap;
        /* 出现更小的差就更新答案 */
        if (gap < ans) ans = gap;
    }
    return ans;
}
```
