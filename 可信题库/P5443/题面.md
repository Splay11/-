# 烤盘份数最接近

# 题目内容

烘焙间里，一排共 `n` 个烤盘按顺序摆在操作台上，从左到右第 `i` 个烤盘有 `cookies[i]` 块饼干（`i` 从 `0` 开始）。

值班师傅想先拿件数最接近的两盘去做装袋对照，但他只肯从挨着的两盘里挑：请找出**相邻两盘**饼干数之差（取绝对值）的**最小值**，返回这个最小差值。

请实现：

```text
minAdjacentGap(cookies: int[]) -> int
```

## 输入描述

一行整型数组，形如 `[4, 9, 6, 6, 12]`。

约束：

- $2 \le \texttt{cookies.length} \le 10^5$
- $0 \le \texttt{cookies}[i] \le 10^9$

## 输出描述

一行整数：所有相邻两盘饼干数之差里的最小值。

## 样例1

输入：

```
[4, 9, 6, 6, 12]
```

输出：

```
0
```

说明：第 `3` 盘和第 `4` 盘都是 `6` 块，相差 `0`，已经没有更小的差。

## 样例2

输入：

```
[3, 10, 8]
```

输出：

```
2
```

说明：`10` 与 `8` 相差 `2`，`3` 与 `10` 相差 `7`，最小是 `2`。

## 样例3

输入：

```
[1, 100]
```

输出：

```
99
```

说明：只有两盘，直接算它们之差。
