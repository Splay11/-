# 测试数据说明

主造数脚本：题目根目录 `gen.py`。
stdin 一行整型数组（形如 `[4, 9, 6, 6, 12]`，数字之间用 `, ` 分隔），与题面样例同形。

| 组 | 说明 |
|---:|---|
| 1 | 样例1：第 3、4 盘都是 6，答案 0 |
| 2 | 样例2：三盘，10 与 8 相差 2 最小 |
| 3 | 样例3：只有两盘，答案 99 |
| 4 | 两盘件数相同 [7, 7]，答案 0 |
| 5 | 两盘分别取 0 与 10^9，答案 10^9 |
| 6 | 单调递增 n=100000 |
| 7 | 单调递减 n=100000 |
| 8 | 最小差在数组中间（首尾差都很大），答案 1 |
| 9 | 中等随机 n=1000 |
| 10 | 大 n=100000，含 0 与 10^9 |
