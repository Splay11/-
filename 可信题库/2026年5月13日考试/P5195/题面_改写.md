# 相邻值最大下标距

# 题目内容

`numbers` 是 $1..n$ 的一个排列（$n=\texttt{numbers.length}$）。求所有满足 $|\texttt{numbers}[i]-\texttt{numbers}[j]|=1$ 的下标对中，$|i-j|$ 的最大值。

## 输入描述

整数数组 `numbers`，满足 $2\le \texttt{numbers.length}\le 100$。

## 输出描述

一个整数：所求最大下标距离。

## 样例1

输入：

```
[1, 4, 2, 5, 3]
```

输出：

```
3
```

**说明：**

数值相邻对中，例如 $2$ 与 $3$ 的下标为 $2$ 与 $4$，距离 $2$；$4$ 与 $5$ 距离 $1$；$1$ 与 $2$ 距离 $2$；$3$ 与 $4$ 距离 $3$。最大为 $3$。

## 样例2

输入：

```
[3, 1, 4, 2]
```

输出：

```
3
```

**说明：**

$1$ 与 $2$ 下标为 $1$ 与 $3$，距离 $3$，为最大。
