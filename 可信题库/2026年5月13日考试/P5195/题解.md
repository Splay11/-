## 解题思路

数组是 $1..n$ 的排列，数值连续的数对只有 $(1,2),(2,3),\ldots,(n-1,n)$ 共 $n-1$ 对。

因此只需记录每个值出现的下标 `pos[v]`，再对每个 $v=1..n-1$ 计算 $\lvert\mathrm{pos}[v]-\mathrm{pos}[v+1]\rvert$，取最大值即可。

**常见假解**：枚举所有下标对只检查差为 $1$ 但写成 $O(n^2)$ 无妨（$n\le 100$），真正易错是误把「相邻下标」当成「相邻数值」，或只看相邻下标的值差。

## 复杂度分析

- 时间：$O(n)$，一次建表 + 一次扫描相邻值。
- 空间：$O(n)$，下标数组。

## 代码实现

### Python

```python
from typing import List


class Solution:
    def maxConsecutiveDistance(self, numbers: List[int]) -> int:
        n = len(numbers)
        pos = [0] * (n + 1)
        # 记录每个数值所在下标
        for i, v in enumerate(numbers):
            pos[v] = i
        ans = 0
        # 只检查数值相邻的 n-1 对
        for v in range(1, n):
            ans = max(ans, abs(pos[v] - pos[v + 1]))
        return ans
```

### Java

```java
public class Solution {
    public int maxConsecutiveDistance(int[] numbers) {
        int n = numbers.length;
        int[] pos = new int[n + 1];
        // 记录每个数值所在下标
        for (int i = 0; i < n; i++) pos[numbers[i]] = i;
        int ans = 0;
        // 只检查数值相邻的 n-1 对
        for (int v = 1; v < n; v++) {
            ans = Math.max(ans, Math.abs(pos[v] - pos[v + 1]));
        }
        return ans;
    }
}
```

### C

```c
#include <stdlib.h>

int maxConsecutiveDistance(int* numbers, int numbersSize) {
    int n = numbersSize;
    int* pos = (int*)malloc((n + 1) * sizeof(int));
    // 记录每个数值出现的下标
    for (int i = 0; i < n; i++) pos[numbers[i]] = i;
    int ans = 0;
    // 只考察数值相邻的 n-1 对
    for (int v = 1; v < n; v++) {
        int d = pos[v] - pos[v + 1];
        if (d < 0) d = -d;
        if (d > ans) ans = d;
    }
    free(pos);
    return ans;
}
```
