# 题目内容

现给定数组 `numbers` 记录了从 1 到 `numbers.length` 的乱序排列的整数，请找到整数值连续但相隔最远的两数之间的距离。

- **数值连续**，指绝对值 `|numbers[i] - numbers[j]| == 1`
- **两数 `numbers[i]` 与 `numbers[j]` 的距离**，指下标差绝对值 `|i - j|`

## 输入描述

`2 <= numbers.length <= 100`

## 输出描述

一个整数，表示所求最远的距离

## 样例1

输入：

```
[6, 4, 2, 5, 1, 3]
```

输出：

```
4
```

解释：

`numbers[1] = 4, numbers[5] = 3;` 连续整数 4、3 之间的距离（即下标差）为 4，最远。

其它距离都小于 4，例如 6 和 5 的距离为 3。

## 样例2

输入：

```
[2, 3, 6, 5, 7, 1, 4]
```

输出：

```
5
```

解释：

2 和 1 的距离为 5，3 和 4 的距离也为 5。
