# 特征数字段反转

# 题目内容

给定长度恰为 $9$ 的字符串。若符合格式则做变换并返回结果；否则返回 `ERROR`。

**合法格式：** 一个英文字母 + 若干（可为 $0$ 个）字符 `0` + 特征数字段 + 若干（可为 $0$ 个）字符 `0`。

- 特征数字段：长度至少为 $1$，仅由数字组成，且首尾都不是 `0`（中间可以有 `0`）。

**变换：** 去掉首字母；只把特征数字段反转；其前后 `0` 的个数保持不变；再拼成新串返回。

## 输入描述

由 `[a-zA-Z0-9]` 组成、长度恰为 $9$ 的字符串。

## 输出描述

合法则返回变换后的字符串；否则返回 `ERROR`。

## 样例1

输入：

```
"c00034010"
```

输出：

```
"00010430"
```

**说明：**

去掉 `c` 后为 `00034010`：前导三个 `0`，特征段 `3401`，尾随一个 `0`。特征段反转得 `1043`，拼回 `00010430`。

## 样例2

输入：

```
"x12345678"
```

输出：

```
"87654321"
```

**说明：**

无前后多余 `0`，特征段即后 $8$ 位，整体反转。

## 样例3

输入：

```
"a00b00000"
```

输出：

```
"ERROR"
```

**说明：**

首字母后出现非数字字符，非法。
