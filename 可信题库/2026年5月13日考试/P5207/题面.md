# 题目内容

给出一个长度固定为 9 的字符串，若该字符串符合下述格式要求，请生成工号并返回；否则，返回字符串 `ERROR`。

## 格式要求

一个英文字母 + 任意个 `0` + 特征数字段 + 任意个 `0`

- **特征数字段**：仅由数字组成，首尾不能为 `0`，中间可以有 `0`；其长度大于等于 1
- **注**：“任意个”表示 0 个或多个

## 生成工号方法

1. 去掉首字母
2. 将“特征数字段”部分进行翻转
3. 特征数字段前后的 `0` 的数量保持不变
4. 拼接后的新字符串即为工号

## 输入描述

由 `[a-zA-Z0-9]` 组成，且长度为 9 的字符串。

## 输出描述

若输入符合格式要求，返回生成的工号字符串；否则返回字符串 `ERROR`。

## 样例1

输入：

```
"b00101250"
```

输出：

```
"00521010"
```

解释：

符合格式要求。去掉首字母；特征数字段 `10125` 翻转后为 `52101`，前后 `0` 的数量保持不动。新生成的字符串为 `00521010`。

## 样例2

输入：

```
"a0012B456"
```

输出：

```
"ERROR"
```

解释：

除了首字母外，其它位置含有字母，不符合格式要求，输出字符串 `ERROR`。
