# 题目内容

采购系统要在预算内选一个带宽套餐。给定二维数组 `packages`，每一项为 `[bandwidth, price]`：

- `bandwidth`：套餐带宽（越大越好）
- `price`：套餐价格

以及整数 `budget`：可用预算。

选择规则：

1. 只能买**一个**套餐，且必须满足 `price <= budget`
2. 在所有买得起的套餐中，选择 `bandwidth` **最大**的
3. 若最大带宽有多个套餐，选择其中 `price` **最小**的
4. 若没有任何套餐买得起，返回 `-1`

请返回最终选中的套餐带宽；买不起时返回 `-1`。

请实现：

```text
bestBandwidth(packages: int[][], budget: int) -> int
```

## 输入描述

两行：

- 第一行：二维数组 `packages`，形如 `[[100, 50], [200, 120], [150, 80]]`
- 第二行：整数 `budget`

约束：

- $0 \le \texttt{packages.length} \le 10^4$
- $1 \le \texttt{bandwidth}_i,\texttt{price}_i \le 10^9$
- $0 \le \textit{budget} \le 10^9$

## 输出描述

一个整数：选中的带宽，或 `-1`。

## 样例1

输入：

```
[[100, 50], [200, 120], [150, 80]]
100
```

输出：

```
150
```

说明：预算 $100$。`[200,120]` 买不起；`[100,50]` 与 `[150,80]` 中带宽更大的是 $150$。

## 样例2

输入：

```
[[300, 200], [100, 50]]
40
```

输出：

```
-1
```

说明：所有套餐都买不起。

## 样例3

输入：

```
[[100, 60], [100, 40], [80, 30]]
60
```

输出：

```
100
```

说明：买得起的最大带宽是 $100$，对应价格 $60$ 与 $40$，按规则选更便宜的那个，返回的带宽仍是 $100$。
