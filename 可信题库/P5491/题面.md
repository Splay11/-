# 数字串拆积

# 题目内容

给定一串只由数字构成的字符串 $seq$。现在要放上恰好一个乘号，把它拆成左右两段（两段都不能空），各自视为十进制整数。请找出一种拆法，使两段乘积尽可能大，并返回该最大值。

前导 $0$ 按通常十进制取值，例如 $05$ 读成 $5$。

请实现：

```text
maxSplitProduct(seq: str) -> int
```

## 输入描述

一行字符串，用双引号包裹。引号内只含数字字符。

约束：

- $2 \le seq.length \le 9$
- $seq$ 仅由数字 $0$～$9$ 组成

## 输出描述

一个整数：所有合法拆法中，左右两段十进制值乘积的最大值。

## 样例1

输入：

```
"2222"
```

输出：

```
484
```

说明：

- 拆成 $2$ 与 $222$，乘积 $444$
- 拆成 $22$ 与 $22$，乘积 $484$
- 拆成 $222$ 与 $2$，乘积 $444$
- 最大为 $484$

## 样例2

输入：

```
"4051"
```

输出：

```
2040
```

说明：

- $4 \times 051 = 204$
- $40 \times 51 = 2040$
- $405 \times 1 = 405$
- 最大为 $2040$

## 样例3

输入：

```
"10"
```

输出：

```
0
```

说明：只有一种拆法 $1 \times 0$，乘积为 $0$。
