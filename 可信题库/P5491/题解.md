## 解题思路

本题是**枚举切分位置**。设 $seq$ 长度为 $n$，切点 $k$ 表示左段取前 $k$ 个字符、右段取后面 $n-k$ 个，$k$ 只能取 $1,2,\ldots,n-1$，保证两段非空。

对每个 $k$：

- 把左段、右段各自转成十进制整数（前导 $0$ 按字面转换，与 $int$ 语义一致）
- 用乘积更新答案

$n \le 9$，枚举量很小。接口 $maxSplitProduct(seq)$ 返回最大乘积。

## 复杂度分析

- 时间复杂度：$O(n^2)$。切点 $O(n)$ 个，每次转换数字不超过 $O(n)$。
- 空间复杂度：$O(1)$，不计输入串本身。

## 代码实现

### Python

```python
class Solution:
    def maxSplitProduct(self, seq: str) -> int:
        n = len(seq)
        ans = 0
        for k in range(1, n):
            # 左段 [0,k)、右段 [k,n)，两段都非空
            left = int(seq[:k])
            right = int(seq[k:])
            prod = left * right
            if prod > ans:
                ans = prod
        return ans
```

### Java

```java
class Solution {
    public int maxSplitProduct(String seq) {
        int n = seq.length();
        int ans = 0;
        for (int k = 1; k < n; k++) {
            // 左段 [0,k)、右段 [k,n)
            int left = Integer.parseInt(seq.substring(0, k));
            int right = Integer.parseInt(seq.substring(k));
            int prod = left * right;
            if (prod > ans) {
                ans = prod;
            }
        }
        return ans;
    }
}
```

### C++

```cpp
#include <string>
using namespace std;

class Solution {
public:
    int maxSplitProduct(string seq) {
        int n = (int)seq.size();
        int ans = 0;
        for (int k = 1; k < n; k++) {
            // 左段 [0,k)、右段 [k,n)
            int left = stoi(seq.substr(0, k));
            int right = stoi(seq.substr(k));
            int prod = left * right;
            if (prod > ans) ans = prod;
        }
        return ans;
    }
};
```

### C

```c
int maxSplitProduct(char* seq, int seqLen) {
    int ans = 0;
    for (int k = 1; k < seqLen; k++) {
        /* 左段 [0,k)、右段 [k,n) */
        int left = 0, right = 0;
        for (int i = 0; i < k; i++) left = left * 10 + (seq[i] - '0');
        for (int i = k; i < seqLen; i++) right = right * 10 + (seq[i] - '0');
        int prod = left * right;
        if (prod > ans) ans = prod;
    }
    return ans;
}
```
