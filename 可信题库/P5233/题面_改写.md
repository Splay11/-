# URI 最长前缀分组计数

# 题目内容

给定互不相同的 URI 字符串数组 `uriReqs`。每个 URI 以 `/` 开头、不以 `/` 结尾、无 `//`；按 `/` 切开后得到若干**子段**。

若干 URI 的**公共前缀长度**定义为：从首段起连续相同的子段个数。

按下述贪心反复分组，返回形成的组数（可为 0）：

1. 组内至少 2 个 URI；每个 URI 至多进一组。
2. 在尚未入组的 URI 中，找出公共前缀长度的最大值 $L\ge 1$，并取一个达到该长度的前缀 $P$；将所有仍未入组且拥有前缀 $P$ 的 URI 归为同一组。
3. 若无法再找到 $L\ge 1$ 且至少覆盖 2 个未入组 URI 的前缀，则结束。

请实现：

```text
countSimilarGroups(uriReqs: string[]) -> int
```

## 输入描述

一行字符串数组，形如：

```
["/a/b/c/d", "/a/b/c", "/a"]
```

约束：$2\le n\le 200$；每 URI 子段数 $\in[1,20]$；单 URI 长度 $\le 300$；字符为小写字母、数字、`-`、`_`、`/`；URI 互异且格式合法（如上）。

## 输出描述

一个整数：相似组个数。

## 样例1

输入：

```
["/a/b/c/d", "/a/b/c", "/a/b/d", "/a/b/c/d/e", "/a/b/c/d/f", "/a", "/b"]
```

输出：

```
2
```

**说明：**

先按最长前缀 `/a/b/c/d`（$L=4$）聚成 1 组（3 个 URI）；再按 `/a/b`（$L=2$）聚成 1 组；其余无法成组。

## 样例2

输入：

```
["/aa/b/c", "/aa/b/c/d/e", "/b/c", "/b/c/d", "/b", "/b/e/o/p/p/r/s/t", "/b/d/e", "/b/d/h"]
```

输出：

```
4
```

**说明：**

- `/aa/b/c` 与 `/aa/b/c/d/e`（$L=3$）
- `/b/c` 与 `/b/c/d`（$L=2$）
- `/b/d/e` 与 `/b/d/h`（$L=2$）
- `/b` 与 `/b/e/o/p/p/r/s/t`（$L=1$）
