# 题目内容

URI 请求分组：给定 URI 列表 `uriReqs`，按相似度规则分成若干「相似组」，返回相似组个数（可为 0）。

**URI 子段**：以 `/` 分割得到的非空子串。

**公共前缀**：若干 URI 从第一个子段起连续相同的子段序列；公共前缀长度为相同子段的个数。

**相似组规则**：

1. 一个相似组至少包含 2 个 URI；每个 URI 至多属于一个组。
2. 在尚未归组的 URI 中，优先将**公共前缀最长**的那些 URI 归为一组（取该最长前缀下、仍未归组且拥有该前缀的全部 URI）。
3. 重复上述过程，直到无法再形成规模至少为 2 的相似组。

## 输入描述

参数 `uriReqs`：

- $2\le \texttt{uriReqs.length}\le 200$
- 每个 URI 子段个数在 $[1,20]$
- 字符集：小写字母、数字、`-`、`_`、`/`
- 单个 URI 长度不超过 $300$
- URI 互不相同；均以 `/` 开头、不以 `/` 结尾；无连续 `//`

## 输出描述

一个整数：相似组个数。

## 样例1

输入：

```
["/a/b/c/d", "/a/b/c", "/a/b/d", "/a/b/c/d/e", "/a/b/c/d/f", "/a", "/b"]
```

输出：

```
2
```

解释：

先将公共前缀 `/a/b/c/d`（长度 4）下的三个 URI 归为一组；再将剩余中公共前缀 `/a/b`（长度 2）的 `/a/b/c` 与 `/a/b/d` 归为一组；`/a` 与 `/b` 无法成组。共 2 组。

## 样例2

输入：

```
["/aa/b/c", "/aa/b/c/d/e", "/b/c", "/b/c/d", "/b", "/b/e/o/p/p/r/s/t", "/b/d/e", "/b/d/h"]
```

输出：

```
4
```

解释：

四组分别为：`/aa/b/c` 与 `/aa/b/c/d/e`（前缀长 3）；`/b/c` 与 `/b/c/d`（长 2）；`/b/d/e` 与 `/b/d/h`（长 2）；`/b` 与 `/b/e/...`（长 1）。
