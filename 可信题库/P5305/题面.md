# 题目内容

生产环境同一时刻通常只允许执行一个变更窗口，避免多业务线同时停机互相踩踏。各业务线向变更日历申报候选窗口，每一项为 `[start, end, value]`：

- 占用半开时间区间 $[\textit{start},\,\textit{end})$
- `value` 表示该窗口的业务收益分（例如覆盖的核心交易量评估分）

排期规则：

1. 最多选若干窗口，**任意两个选中窗口的时间区间不能相交**（首尾相接允许：如 $[1,3)$ 与 $[3,5)$ 可同时入选）
2. 使选中窗口的 `value` **之和最大**
3. 若申报列表为空，返回 $0$
4. `value` 可能为负（例如窗口代价高于收益）；负分窗口可以不选

请实现：

```text
maxMaintenanceScore(windows: int[][]) -> int
```

## 输入描述

一行：二维数组 `windows`，形如 `[[1, 3, 5], [2, 4, 4], [3, 6, 6]]`

约束：

- $0 \le n \le 10^4$，$n=\texttt{windows.length}$
- $0 \le \textit{start} < \textit{end} \le 10^9$
- $-10^6 \le \textit{value} \le 10^6$

## 输出描述

一个整数：最大收益分之和。

## 样例1

输入：

```
[[1, 3, 5], [2, 4, 4], [3, 6, 6]]
```

输出：

```
11
```

说明：选 $[1,3)$ 与 $[3,6)$，收益 $5+6=11$。

## 样例2

输入：

```
[[1, 10, -5], [2, 3, 4]]
```

输出：

```
4
```

说明：长窗口收益为负，放弃；只排短窗口。

## 样例3

输入：

```
[]
```

输出：

```
0
```

说明：无申报窗口。
