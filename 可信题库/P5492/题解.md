## 解题思路

本题求 $p < q$ 时 $loads[p] - loads[q]$ 的最大值，也就是「左侧某个值减去右侧某个值」的最大下降。

一次**线性扫描**即可：从左到右维护已经见过的前缀最大值 $peak$。扫到位置 $q$ 时，用 $peak - loads[q]$ 更新答案，再把 $peak$ 与当前值取最大。

若全程不下降，答案保持 $0$。不要用「全局最大减全局最小」，因为最大可能出现在最小后面，那样 $p < q$ 不成立。

接口 $maxLoadDrop(loads)$ 返回该非负整数。

## 复杂度分析

- 时间复杂度：$O(n)$，每个元素看一次。
- 空间复杂度：$O(1)$。

## 代码实现

### Python

```python
from typing import List


class Solution:
    def maxLoadDrop(self, loads: List[int]) -> int:
        peak = loads[0]
        ans = 0
        for x in loads:
            # 用此前前缀最大值减去当前值，才满足 p < q
            drop = peak - x
            if drop > ans:
                ans = drop
            if x > peak:
                peak = x
        return ans
```

### C

```c
int maxLoadDrop(int* loads, int loadsSize) {
    int peak = loads[0];
    int ans = 0;
    for (int i = 0; i < loadsSize; i++) {
        /* 用此前前缀最大值减去当前值 */
        int drop = peak - loads[i];
        if (drop > ans) ans = drop;
        if (loads[i] > peak) peak = loads[i];
    }
    return ans;
}
```
