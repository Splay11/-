## 解题思路

本题是经典的**扫描线 / 差分**思想：半开区间 `[s, e)` 在时刻 `s` 开始占用、在时刻 `e` 释放。

把所有 `starts` 与 `ends` 分别排序，用双指针扫描：

- 若下一个开始时刻严格小于下一个结束时刻，则并发 `+1`，并更新答案。
- 否则先处理结束（并发 `-1`）。半开区间下，`s == e` 时必须先结束再开始，因此比较用严格小于。

接口 `peakConcurrent(starts, ends)` 返回扫描过程中的最大并发。

易错点：把区间当成闭区间导致首尾相接误判重叠；未排序；只按起点贪心。

## 复杂度分析

- 时间：$O(n\log n)$，主要来自排序；双指针扫描 $O(n)$。
- 空间：$O(1)$ 额外（若允许原地排序）；否则 $O(n)$ 拷贝。

## 代码实现

### Python

```python
from typing import List


class Solution:
    def peakConcurrent(self, starts: List[int], ends: List[int]) -> int:
        starts = sorted(starts)
        ends = sorted(ends)
        i = j = 0
        cur = ans = 0
        n = len(starts)
        while i < n:
            # 半开区间：终点与起点重合时先结束再开始
            if starts[i] < ends[j]:
                cur += 1
                if cur > ans:
                    ans = cur
                i += 1
            else:
                cur -= 1
                j += 1
        return ans
```

### Java

import java.util.Arrays;

class Solution {
    public int peakConcurrent(int[] starts, int[] ends) {
        Arrays.sort(starts);
        Arrays.sort(ends);
        int i = 0, j = 0, cur = 0, ans = 0, n = starts.length;
        while (i < n) {
            // 半开区间：终点与起点重合时先结束再开始
            if (starts[i] < ends[j]) {
                cur++;
                if (cur > ans) ans = cur;
                i++;
            } else {
                cur--;
                j++;
            }
        }
        return ans;
    }
}

### C++

```cpp
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int peakConcurrent(vector<int>& starts, vector<int>& ends) {
        sort(starts.begin(), starts.end());
        sort(ends.begin(), ends.end());
        int i = 0, j = 0, cur = 0, ans = 0, n = (int)starts.size();
        while (i < n) {
            // 半开区间：终点与起点重合时先结束再开始
            if (starts[i] < ends[j]) {
                ++cur;
                if (cur > ans) ans = cur;
                ++i;
            } else {
                --cur;
                ++j;
            }
        }
        return ans;
    }
};
```
