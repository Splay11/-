# 题目内容

直播平台要统计同一时刻最多有多少场预约直播同时进行，以便扩容带宽。每场直播占用半开时间区间 $[s,\,e)$，即包含时刻 $s$、不包含时刻 $e$。

给定两个等长数组 `starts`、`ends`，第 $i$ 场直播为 $[\texttt{starts}[i],\,\texttt{ends}[i])$。求任意时刻的最大并发场次数。

请实现：

```text
peakConcurrent(starts: int[], ends: int[]) -> int
```

## 输入描述

两行：

- 第一行：整数数组 `starts`（形如 `[1, 2, 3]`）
- 第二行：整数数组 `ends`（形如 `[3, 5, 4]`），与 `starts` 等长

约束：$1\le n\le 10^4$，$n=\texttt{starts.length}$；$0\le \texttt{starts}[i]<\texttt{ends}[i]\le 10^5$。

## 输出描述

一个整数：峰值并发场次数。

## 样例1

输入：

```
[1, 2, 3]
[3, 5, 4]
```

输出：

```
2
```

**说明：**

三场为 $[1,3)$、$[2,5)$、$[3,4)$。时刻 $2$ 起前两场重叠，并发为 $2$；$3$ 时刻第一场刚结束、第三场刚开始，并发仍为 $2$，从未到 $3$。

## 样例2

输入：

```
[1, 2]
[2, 3]
```

输出：

```
1
```

**说明：**

$[1,2)$ 与 $[2,3)$ 在 $2$ 处首尾相接、互不重叠。

## 样例3

输入：

```
[0, 0, 0]
[10, 10, 10]
```

输出：

```
3
```

**说明：**

三场完全重叠，峰值为 $3$。
