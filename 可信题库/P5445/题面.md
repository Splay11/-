# 食堂取餐叫号

# 题目内容

食堂新开了一个打包窗口，同学先在取号机上取号，窗口按取号先后**依次**叫号出餐。同一个号不能被取两次，免得有人重复排队。取到的号要能查还有多少人在等。

请实现类 `PickupDesk`：

- `PickupDesk()`：构造一个空的取餐台，没有任何号在等待。返回 `null`。
- `order(ticketId)`：取一个号为 `ticketId` 的号。
  - 若这个号**已经在等待队列里**（还没被叫到），不改变任何状态，返回 `false`
  - 否则把它加到**队尾**，返回 `true`
- `serve()`：叫号出餐，把**队首**的号叫走并返回该号。
  - 若队列为空，不改变任何状态，返回 `-1`
- `waiting()`：返回当前还在等待的号数

## 输入描述

每行一次调用，首行必须是 `PickupDesk()`。累计调用不超过 `10000` 次。

约束：

- $1 \le \textit{ticketId} \le 10^9$

## 输出描述

每次调用输出一行：

- 构造返回 `null`
- `order` 返回 `true` 或 `false`
- `serve` / `waiting` 返回整数

## 样例1

输入：

```
PickupDesk()
order(101)
order(102)
waiting()
serve()
serve()
serve()
waiting()
```

输出：

```
null
true
true
2
101
102
-1
0
```

说明：

- `101` 先取号所以在前面
- `serve()` 按先后叫出 `101`、`102`
- 队列空后再叫返回 `-1`

## 样例2

输入：

```
PickupDesk()
order(7)
order(7)
waiting()
serve()
order(7)
waiting()
```

输出：

```
null
true
false
1
7
true
1
```

说明：第二次 `order(7)` 失败，因为号 `7` 还在等待；叫走之后同一个号可以重新取。

## 样例3

输入：

```
PickupDesk()
serve()
waiting()
order(5)
serve()
serve()
```

输出：

```
null
-1
0
true
5
-1
```

说明：一开始没人等待，`serve()` 返回 `-1`；取号 `5` 后立刻被叫走，之后队列又为空。
