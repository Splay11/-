# 题目内容

安全审计需要检查登录流水。给定按时间顺序排列的用户编号数组 `users`，请找出**第一次出现重复**的用户编号：

- 从左到右扫描
- 某个用户编号若此前已经出现过，则它就是答案（取最早发生重复的那一次）
- 若全程没有重复，返回 `-1`

请实现：

```text
firstDuplicate(users: int[]) -> int
```

## 输入描述

一行：整型数组 `users`，形如 `[3, 1, 4, 1, 5]`。

约束：

- $0 \le \texttt{users.length} \le 10^5$
- $1 \le \texttt{users}[i] \le 10^9$

## 输出描述

一个整数：首次重复的用户编号；若无重复则为 `-1`。

## 样例1

输入：

```
[3, 1, 4, 1, 5]
```

输出：

```
1
```

说明：扫描到第二个 `1` 时发现重复，答案为 `1`。后面即使还有别的重复也不再考虑。

## 样例2

输入：

```
[1, 2, 3, 4]
```

输出：

```
-1
```

说明：全部互不相同。

## 样例3

输入：

```
[7, 7]
```

输出：

```
7
```
