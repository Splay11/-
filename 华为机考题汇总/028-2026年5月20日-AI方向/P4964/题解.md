## 解题思路

题目可以拆成两个阶段：

1. 找出所有敏感模式串在主序列中的出现区间，并把相交或首尾相邻的区间合并成敏感块。
2. 根据敏感块计算每个位置 $i$ 在因果约束 $j \le i$ 下能看到多少个 Token。

对于第一阶段，可以对每个敏感模式串使用 KMP，在主序列中查找所有出现位置。

假设某个模式串长度为 $M$，在位置 $i$ 匹配结束，那么它对应的敏感区间为：

$$
[i-M+1, i]
$$

我们不需要真的把所有区间存下来再排序合并。可以用差分数组 `diff` 标记区间覆盖：

$$
diff[L] += 1,\quad diff[R+1] -= 1
$$

最后对 `diff` 做前缀和，如果当前位置覆盖次数大于 $0$，说明它属于某个敏感区间。由于相邻区间中间没有普通 Token，扫描时它们会自然形成同一个连续敏感块。

第二阶段扫描整个序列，维护：

* `normal`：当前已经扫描过的普通 Token 数量；
* `base`：当前敏感块开始前已经出现的普通 Token 数量；
* `inside`：当前敏感块内已经扫描到的 Token 数量。

对于位置 $i$：

* 如果 $i$ 是普通 Token，那么它能看到的只有前缀中的普通 Token，因此答案是 `normal + 1`。
* 如果 $i$ 位于敏感块中，那么它能看到：

  * 当前敏感块之前的所有普通 Token；
  * 当前敏感块内从块起点到 $i$ 的 Token。

所以答案为：

$$
base + inside
$$

注意：虽然敏感块内部 Token 可以互相可见，但仍然要满足因果约束 $j \le i$，因此只能统计当前敏感块内不超过 $i$ 的部分。

## 复杂度分析

设主序列长度为 $N$，敏感模式串数量为 $K$，所有敏感模式串总长度为 $S$。

对每个模式串使用一次 KMP，时间复杂度为：

$$
O(KN + S)
$$

题目中：

$$
N \le 10^5,\quad K \le 100,\quad S \le 10^5
$$

因此最多约为 $10^7$ 级别的匹配操作，可以通过。

差分扫描和答案计算各需要 $O(N)$。

总时间复杂度：

$$
O(KN + S)
$$

空间复杂度主要来自主序列、模式串、差分数组和答案数组：

$$
O(N + S)
$$

## 代码实现

### Python

```python
import sys


def mark_pattern(arr, pat, diff):
    m = len(pat)

    # 构造 KMP 前缀函数，pi[i] 表示 pat[0..i] 的最长相等真前后缀长度
    pi = [0] * m
    j = 0
    for i in range(1, m):
        while j > 0 and pat[i] != pat[j]:
            j = pi[j - 1]
        if pat[i] == pat[j]:
            j += 1
        pi[i] = j

    # 使用 KMP 在主序列中匹配当前敏感模式串
    j = 0
    for i, x in enumerate(arr):
        while j > 0 and x != pat[j]:
            j = pi[j - 1]

        if x == pat[j]:
            j += 1

        # 找到一个完整匹配区间 [l, i]
        if j == m:
            l = i - m + 1
            diff[l] += 1
            diff[i + 1] -= 1

            # 继续查找可能重叠的下一个匹配
            j = pi[j - 1]


def solve(arr, patterns):
    n = len(arr)

    # diff 用来标记所有敏感区间的覆盖情况
    diff = [0] * (n + 1)

    for pat in patterns:
        mark_pattern(arr, pat, diff)

    ans = [0] * n

    cover = 0          # 当前点被多少个敏感区间覆盖
    normal = 0         # 已扫描过的普通 Token 数量
    in_block = False   # 当前是否正在敏感块内
    base = 0           # 当前敏感块开始前的普通 Token 数量
    inside = 0         # 当前敏感块内已扫描 Token 数量

    for i in range(n):
        cover += diff[i]

        if cover > 0:
            # 进入一个新的敏感块
            if not in_block:
                in_block = True
                base = normal
                inside = 0

            # 敏感块内部只能看到本块内不超过当前位置的 Token
            inside += 1
            ans[i] = base + inside
        else:
            # 普通 Token 可以被所有后续 Token 看到
            in_block = False
            normal += 1
            ans[i] = normal

    return ans


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return

    idx = 0
    n = data[idx]
    k = data[idx + 1]
    idx += 2

    arr = data[idx:idx + n]
    idx += n

    patterns = []
    for _ in range(k):
        m = data[idx]
        idx += 1
        pat = data[idx:idx + m]
        idx += m
        patterns.append(pat)

    ans = solve(arr, patterns)
    sys.stdout.write(" ".join(map(str, ans)))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {

    static void markPattern(long[] arr, long[] pat, int[] diff) {
        int n = arr.length;
        int m = pat.length;

        // 构造 KMP 前缀函数
        int[] pi = new int[m];
        int j = 0;
        for (int i = 1; i < m; i++) {
            while (j > 0 && pat[i] != pat[j]) {
                j = pi[j - 1];
            }
            if (pat[i] == pat[j]) {
                j++;
            }
            pi[i] = j;
        }

        // 在主序列中匹配当前敏感模式串
        j = 0;
        for (int i = 0; i < n; i++) {
            while (j > 0 && arr[i] != pat[j]) {
                j = pi[j - 1];
            }

            if (arr[i] == pat[j]) {
                j++;
            }

            // 找到一个完整匹配区间 [l, i]
            if (j == m) {
                int l = i - m + 1;
                diff[l]++;
                diff[i + 1]--;

                // 继续查找可能重叠的下一个匹配
                j = pi[j - 1];
            }
        }
    }

    static int[] solve(long[] arr, long[][] patterns) {
        int n = arr.length;

        // diff 用来记录敏感区间覆盖情况
        int[] diff = new int[n + 1];

        for (long[] pat : patterns) {
            markPattern(arr, pat, diff);
        }

        int[] ans = new int[n];

        int cover = 0;        // 当前点被多少个敏感区间覆盖
        int normal = 0;       // 已扫描过的普通 Token 数量
        boolean inBlock = false;
        int base = 0;         // 当前敏感块开始前的普通 Token 数量
        int inside = 0;       // 当前敏感块内已扫描 Token 数量

        for (int i = 0; i < n; i++) {
            cover += diff[i];

            if (cover > 0) {
                // 进入一个新的敏感块
                if (!inBlock) {
                    inBlock = true;
                    base = normal;
                    inside = 0;
                }

                // 敏感块内部只能看到本块中不超过当前位置的 Token
                inside++;
                ans[i] = base + inside;
            } else {
                // 普通 Token 可以被所有后续 Token 看到
                inBlock = false;
                normal++;
                ans[i] = normal;
            }
        }

        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        if (!sc.hasNextInt()) {
            return;
        }

        int n = sc.nextInt();
        int k = sc.nextInt();

        long[] arr = new long[n];
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextLong();
        }

        long[][] patterns = new long[k][];
        for (int i = 0; i < k; i++) {
            int m = sc.nextInt();
            patterns[i] = new long[m];
            for (int j = 0; j < m; j++) {
                patterns[i][j] = sc.nextLong();
            }
        }

        int[] ans = solve(arr, patterns);

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) {
                sb.append(' ');
            }
            sb.append(ans[i]);
        }

        System.out.print(sb.toString());
    }
}
```
