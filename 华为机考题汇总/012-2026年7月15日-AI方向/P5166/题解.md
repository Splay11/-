## 解题思路

核心思路

首先模拟原轨迹，得到两个信息：

1. 原轨迹结束后 Agent 的最终位置。
2. 每个格子的最终状态值。

对于同一个格子，所有增加和减少操作都可以合并。假设某个格子的最终状态为 $v$：

* 当 $v>0$ 时，在新轨迹中到达该格子后执行一次 `I v`。
* 当 $v<0$ 时，在新轨迹中到达该格子后执行一次 `D -v`。
* 当 $v=0$ 时，不需要在该格子执行有效操作。

因此，新轨迹只需要满足：

* 从网格中心出发；
* 访问所有最终状态非零的格子；
* 最后到达原轨迹的终点。

设最终状态非零的格子数量为 $p$。题目保证 $p\leq 12$，因此可以使用状态压缩动态规划。

网格中没有障碍物，两个不同格子 $(x_1,y_1)$ 和 $(x_2,y_2)$ 之间的最短移动距离就是曼哈顿距离：

$$
\operatorname{dist}((x_1,y_1),(x_2,y_2))
=
|x_1-x_2|+|y_1-y_2|
$$

越界移动只会让 Agent 停留在原地，不可能缩短两个不同格子之间的移动距离，因此计算最短路时不需要考虑越界移动。

需要特别处理起点格子的状态非零的情况。Agent 每个时间步必须先移动，再执行操作，不能在初始时刻直接操作起点。由于起点是网格中心，不在边界上，若要在起点执行操作，至少需要先移动到相邻格子，再返回起点，共需要 $2$ 步。

定义状态：

$$
dp[mask][i]
$$

表示从网格中心出发，已经完成了集合 $mask$ 中所有非零格子的操作，并且当前位于第 $i$ 个非零格子时的最少步数。

初始化：

* 如果第 $i$ 个非零格子不是起点：

$$
dp[2^i][i]=\operatorname{dist}(start,i)
$$

* 如果第 $i$ 个非零格子就是起点：

$$
dp[2^i][i]=2
$$

状态转移：

从当前格子 $i$ 移动到一个尚未处理的格子 $j$：

$$
dp[mask\cup{j}][j]
=
\min\left(
dp[mask\cup{j}][j],
dp[mask][i]+\operatorname{dist}(i,j)
\right)
$$

所有非零格子处理完后，还需要从最后一个非零格子移动到原轨迹终点。答案为：

$$
\min_{0\leq i<p}
\left(
dp[(1\ll p)-1][i]
+
\operatorname{dist}(i,end)
\right)
$$

如果所有格子的最终状态都是 $0$，则不需要执行任何有效操作，只需要从起点移动到原轨迹终点，答案就是二者之间的曼哈顿距离。若终点也是起点，则最短轨迹长度可以为 $0$。

实现方法

1. 从网格中心开始模拟原轨迹。
2. 每一步先根据移动指令尝试更新位置，越界时保持原位置。
3. 在移动后的格子上累加状态变化。
4. 记录模拟结束后的 Agent 位置。
5. 收集所有最终状态非零的格子。
6. 对这些格子进行状态压缩动态规划。
7. 在所有状态完成后，加上移动到原终点的距离。

正确性说明：

任意一条语义等价轨迹都必须至少到达每个最终状态非零的格子一次，否则无法改变该格子的状态。记录这些格子第一次完成有效操作的先后顺序，相邻两个格子之间的步数不可能小于它们的曼哈顿距离；若第一个操作格子是起点，则至少需要离开并返回，共 $2$ 步。因此，任意合法轨迹的长度都不会小于动态规划枚举出的对应路径长度。

反过来，对于动态规划得到的访问顺序，可以在相邻格子之间沿曼哈顿最短路移动，并在第一次到达每个非零格子时执行合并后的操作。最后再沿曼哈顿最短路到达原终点。因此，动态规划得到的结果一定可以构造出一条合法轨迹。

所以该动态规划计算出的就是最短语义等价轨迹长度。

## 复杂度分析

设最终状态非零的格子数量为 $p$，题目保证 $p\leq 12$。

模拟原轨迹需要：

$$
O(K)
$$

状态压缩动态规划共有 $2^p\times p$ 个状态，每个状态最多枚举 $p$ 个下一个格子，因此时间复杂度为：

$$
O(K+2^p p^2)
$$

动态规划数组的空间复杂度为：

$$
O(2^p p)
$$

此外还需要使用 $O(nm)$ 的空间记录网格最终状态，因此总空间复杂度为：

$$
O(nm+2^p p)
$$

当 $p\leq 12$ 时，状态数量最多为 $4096\times 12$，复杂度可以满足要求。

## 代码实现

### Python

```python
import sys


def min_steps(n, m, moves, ops, vals):
    grid = [[0] * m for _ in range(n)]

    sr = n // 2
    sc = m // 2
    r, c = sr, sc

    # 模拟原轨迹，同时计算每个格子的最终状态和原轨迹终点
    for i in range(len(moves)):
        nr, nc = r, c

        if moves[i] == 'U':
            nr -= 1
        elif moves[i] == 'D':
            nr += 1
        elif moves[i] == 'L':
            nc -= 1
        else:
            nc += 1

        if 0 <= nr < n and 0 <= nc < m:
            r, c = nr, nc

        if ops[i] == 'I':
            grid[r][c] += vals[i]
        elif ops[i] == 'D':
            grid[r][c] -= vals[i]

    er, ec = r, c

    # 收集所有最终状态非零、必须执行有效操作的格子
    pos = []
    for i in range(n):
        for j in range(m):
            if grid[i][j] != 0:
                pos.append((i, j))

    p = len(pos)

    # 没有需要操作的格子时，只需移动到原轨迹终点
    if p == 0:
        return abs(sr - er) + abs(sc - ec)

    total = 1 << p
    inf = 10 ** 9
    dp = [[inf] * p for _ in range(total)]

    # 初始化第一次完成操作的格子
    for i in range(p):
        x, y = pos[i]
        dis = abs(sr - x) + abs(sc - y)

        # 起点不能在初始时刻直接操作，必须离开后再返回
        if x == sr and y == sc:
            dis = 2

        dp[1 << i][i] = dis

    # 枚举已经完成操作的格子集合和当前所在格子
    for mask in range(total):
        for i in range(p):
            if dp[mask][i] == inf:
                continue

            for j in range(p):
                if mask & (1 << j):
                    continue

                dis = (
                    abs(pos[i][0] - pos[j][0])
                    + abs(pos[i][1] - pos[j][1])
                )

                next_mask = mask | (1 << j)
                next_val = dp[mask][i] + dis

                if next_val < dp[next_mask][j]:
                    dp[next_mask][j] = next_val

    # 完成所有操作后，再移动到原轨迹终点
    full = total - 1
    ans = inf

    for i in range(p):
        dis = abs(pos[i][0] - er) + abs(pos[i][1] - ec)
        ans = min(ans, dp[full][i] + dis)

    return ans


def main():
    input_data = sys.stdin.readline

    n, m = map(int, input_data().split())
    k = int(input_data())

    moves = []
    ops = []
    vals = []

    for _ in range(k):
        move, op, val = input_data().split()
        moves.append(move)
        ops.append(op)
        vals.append(int(val))

    print(min_steps(n, m, moves, ops, vals))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.Scanner;

public class Main {

    static int minSteps(int n, int m, char[] moves, char[] ops, int[] vals) {
        int[][] grid = new int[n][m];

        int sr = n / 2;
        int sc = m / 2;
        int r = sr;
        int c = sc;

        // 模拟原轨迹，同时计算每个格子的最终状态和原轨迹终点
        for (int i = 0; i < moves.length; i++) {
            int nr = r;
            int nc = c;

            if (moves[i] == 'U') {
                nr--;
            } else if (moves[i] == 'D') {
                nr++;
            } else if (moves[i] == 'L') {
                nc--;
            } else {
                nc++;
            }

            if (nr >= 0 && nr < n && nc >= 0 && nc < m) {
                r = nr;
                c = nc;
            }

            if (ops[i] == 'I') {
                grid[r][c] += vals[i];
            } else if (ops[i] == 'D') {
                grid[r][c] -= vals[i];
            }
        }

        int er = r;
        int ec = c;

        // 收集所有最终状态非零、必须执行有效操作的格子
        List<int[]> pos = new ArrayList<>();

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (grid[i][j] != 0) {
                    pos.add(new int[]{i, j});
                }
            }
        }

        int p = pos.size();

        // 没有需要操作的格子时，只需移动到原轨迹终点
        if (p == 0) {
            return Math.abs(sr - er) + Math.abs(sc - ec);
        }

        int total = 1 << p;
        int inf = 1 << 29;
        int[][] dp = new int[total][p];

        for (int i = 0; i < total; i++) {
            Arrays.fill(dp[i], inf);
        }

        // 初始化第一次完成操作的格子
        for (int i = 0; i < p; i++) {
            int[] cur = pos.get(i);
            int dis = Math.abs(sr - cur[0]) + Math.abs(sc - cur[1]);

            // 起点不能在初始时刻直接操作，必须离开后再返回
            if (cur[0] == sr && cur[1] == sc) {
                dis = 2;
            }

            dp[1 << i][i] = dis;
        }

        // 枚举已经完成操作的格子集合和当前所在格子
        for (int mask = 0; mask < total; mask++) {
            for (int i = 0; i < p; i++) {
                if (dp[mask][i] == inf) {
                    continue;
                }

                for (int j = 0; j < p; j++) {
                    if ((mask & (1 << j)) != 0) {
                        continue;
                    }

                    int[] a = pos.get(i);
                    int[] b = pos.get(j);
                    int dis = Math.abs(a[0] - b[0])
                            + Math.abs(a[1] - b[1]);

                    int nextMask = mask | (1 << j);
                    int nextVal = dp[mask][i] + dis;

                    if (nextVal < dp[nextMask][j]) {
                        dp[nextMask][j] = nextVal;
                    }
                }
            }
        }

        // 完成所有操作后，再移动到原轨迹终点
        int full = total - 1;
        int ans = inf;

        for (int i = 0; i < p; i++) {
            int[] cur = pos.get(i);
            int dis = Math.abs(cur[0] - er) + Math.abs(cur[1] - ec);
            ans = Math.min(ans, dp[full][i] + dis);
        }

        return ans;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int n = scanner.nextInt();
        int m = scanner.nextInt();
        int k = scanner.nextInt();

        char[] moves = new char[k];
        char[] ops = new char[k];
        int[] vals = new int[k];

        for (int i = 0; i < k; i++) {
            moves[i] = scanner.next().charAt(0);
            ops[i] = scanner.next().charAt(0);
            vals[i] = scanner.nextInt();
        }

        System.out.println(minSteps(n, m, moves, ops, vals));
    }
}
```

```cpp
#include <vector>
#include <climits>

int minSteps(int n, int m,
             const vector<char>& moves,
             const vector<char>& ops,
             const vector<int>& vals) {
    vector<vector<int>> grid(n, vector<int>(m, 0));

    int sr = n / 2;
    int sc = m / 2;
    int r = sr;
    int c = sc;

    // 模拟原轨迹，同时计算每个格子的最终状态和原轨迹终点
    for (int i = 0; i < (int)moves.size(); i++) {
        int nr = r;
        int nc = c;

        if (moves[i] == 'U') {
            nr--;
        } else if (moves[i] == 'D') {
            nr++;
        } else if (moves[i] == 'L') {
            nc--;
        } else {
            nc++;
        }

        if (nr >= 0 && nr < n && nc >= 0 && nc < m) {
            r = nr;
            c = nc;
        }

        if (ops[i] == 'I') {
            grid[r][c] += vals[i];
        } else if (ops[i] == 'D') {
            grid[r][c] -= vals[i];
        }
    }

    int er = r;
    int ec = c;

    // 收集所有最终状态非零、必须执行有效操作的格子
    vector<pair<int, int>> pos;

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (grid[i][j] != 0) {
                pos.push_back({i, j});
            }
        }
    }

    int p = pos.size();

    // 没有需要操作的格子时，只需移动到原轨迹终点
    if (p == 0) {
        return abs(sr - er) + abs(sc - ec);
    }

    int total = 1 << p;
    int inf = INT_MAX / 2;
    vector<vector<int>> dp(total, vector<int>(p, inf));

    // 初始化第一次完成操作的格子
    for (int i = 0; i < p; i++) {
        int dis = abs(sr - pos[i].first)
                + abs(sc - pos[i].second);

        // 起点不能在初始时刻直接操作，必须离开后再返回
        if (pos[i].first == sr && pos[i].second == sc) {
            dis = 2;
        }

        dp[1 << i][i] = dis;
    }

    // 枚举已经完成操作的格子集合和当前所在格子
    for (int mask = 0; mask < total; mask++) {
        for (int i = 0; i < p; i++) {
            if (dp[mask][i] == inf) {
                continue;
            }

            for (int j = 0; j < p; j++) {
                if (mask & (1 << j)) {
                    continue;
                }

                int dis = abs(pos[i].first - pos[j].first)
                        + abs(pos[i].second - pos[j].second);

                int nextMask = mask | (1 << j);
                int nextVal = dp[mask][i] + dis;

                dp[nextMask][j] = min(dp[nextMask][j], nextVal);
            }
        }
    }

    // 完成所有操作后，再移动到原轨迹终点
    int full = total - 1;
    int ans = inf;

    for (int i = 0; i < p; i++) {
        int dis = abs(pos[i].first - er)
                + abs(pos[i].second - ec);

        ans = min(ans, dp[full][i] + dis);
    }

    return ans;
}
```
