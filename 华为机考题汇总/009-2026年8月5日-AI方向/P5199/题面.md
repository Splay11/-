# 题目内容

在一个多 $Agent$ 系统中，不同 $Agent$ 擅长不同类型的子任务。

对于一个复杂任务，系统会根据需要多次调用不同 $Agent$，让整体任务不断推进。

假设共有 $N$ 个 $Agent$。第 $i$ 个 $Agent$ 每调用一次：
- 可以让任务进度增加 $p_i$ 个百分点
- 需要花费 $c_i$ 的代价

同一个 $Agent$ 可以被调用任意次。

为了避免系统长期依赖单一 $Agent$，调度器增加了一条限制：
- 不能连续两次调用同一个 $Agent$

当总进度达到或超过 $100\%$ 时，认为任务完成。注意，总进度允许超过 $100\%$。

现在请你计算：在满足上述限制的前提下，完成任务所需的最小总代价。

如果无法完成任务，输出 $-1$。



# 输入描述

第一行输入一个整数 $N$，表示 $Agent$ 的数量。

接下来 $N$ 行，每行输入两个整数：
$p_i$ $c_i$

表示第 $i$ 个 $Agent$ 每调用一次可推进 $p_i$ 个百分点，需要花费 $c_i$ 的代价。



# 输出描述


输出一个整数，表示完成任务所需的最小总代价。
如果无法完成任务，输出 $-1$。


## 样例1 



**输入** 



```
1
60 5
```



**输出** 



```
-1
```



**说明**

只有 $1$ 个 $Agent$。

调用 $1$ 次后，总进度为 $60$，还未完成。

若继续调用，就会连续两次调用同一个 $Agent$，违反规则。

因此无法完成任务，答案为 $-1$。

### 样例2

**输入**

```
2
60 5
50 4
```

**输出**

```
9
```

**说明**

可以按如下顺序调用：

* 调用第 1 个 Agent：进度增加 60%，花费 5
* 调用第 2 个 Agent：进度增加 50%，花费 4

总进度：

```
60% + 50% = 110%
```

达到任务完成条件，总代价为：

```
5 + 4 = 9
```

且两次调用的 Agent 不同，满足不能连续调用同一个 Agent 的限制。
