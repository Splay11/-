## 解题思路

长度为 $n$ 的 $r$ 进制回文数由前半段唯一确定，按编号直接构造即可，不必枚举。

1. 设前半段长度 $h=\lfloor (n+1)/2 \rfloor$。$n$ 为奇数时，最中间那一位也算在前半段里。
2. 最高位只能取 $1,2,\ldots,r-1$，其余 $h-1$ 位每位可取 $0,1,\ldots,r-1$。把这些回文数从小到大排好，第 $t$ 个就对应把 $t-1$ 按这种混合进制拆开。
3. 令 $x=t-1$。从右往左，前半段的低 $h-1$ 位依次取 $x\bmod r$，再令 $x\leftarrow \lfloor x/r \rfloor$；最后最高位为 $x+1$。
4. 把前半段左右对称抄到长度为 $n$ 的数组 $digits$ 上，得到完整的 $r$ 进制表示。
5. 用霍纳法则把 $digits$ 转成十进制：$val\leftarrow val\cdot r + digits[i]$。答案可能超过 $32$ 位整数，需使用 $64$ 位。

## 复杂度分析

时间复杂度为 $O(n)$，只需构造 $n$ 位数字并做一次进制转换。

空间复杂度为 $O(n)$，用于存放前半段和完整数位。

## 代码实现

### Python

```python
def kth_palindrome(r, n, t):
    # 前半段长度：奇数时中间那一位也算在前半段里
    h = (n + 1) // 2
    half = [0] * h
    x = t - 1
    # 从右往左填前半段的低位，每一位都是0到r-1
    for i in range(h - 1, 0, -1):
        half[i] = x % r
        x //= r
    # 最高位不能为0，所以在余下的数上再加1
    half[0] = x + 1
    digits = [0] * n
    # 左右对称写下完整的n位
    for i in range(h):
        digits[i] = half[i]
        digits[n - 1 - i] = half[i]
    val = 0
    # 按r进制 Horner 法则转成十进制
    for d in digits:
        val = val * r + d
    return val


def main():
    r, n, t = map(int, input().split())
    print(kth_palindrome(r, n, t))


if __name__ == "__main__":
    main()
```

### Java

import java.util.Scanner;

public class Main {
    static long kthPalindrome(int r, int n, int t) {
        // 前半段长度：奇数时中间那一位也算在前半段里
        int h = (n + 1) / 2;
        int[] half = new int[h];
        long x = t - 1L;
        // 从右往左填前半段的低位，每一位都是 0 到 r-1
        for (int i = h - 1; i > 0; i--) {
            half[i] = (int) (x % r);
            x /= r;
        }
        // 最高位不能为 0，所以在余下的数上再加 1
        half[0] = (int) x + 1;
        int[] digits = new int[n];
        // 左右对称写下完整的 n 位
        for (int i = 0; i < h; i++) {
            digits[i] = half[i];
            digits[n - 1 - i] = half[i];
        }
        long val = 0;
        // 按 r 进制 Horner 法则转成十进制
        for (int i = 0; i < n; i++) {
            val = val * r + digits[i];
        }
        return val;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int r = sc.nextInt();
        int n = sc.nextInt();
        int t = sc.nextInt();
        System.out.println(kthPalindrome(r, n, t));
        sc.close();
    }
}
