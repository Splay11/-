## 思路：二分查找 + 贪心

先将所有对手等级排序，记为 `a[0..n-1]`。

由于每次只能选择“**当前被挑战次数最少**”的对手，所以整个过程实际上是按“**轮**”进行的：

* 每完整一轮，会把所有 `n` 个对手各打一次；
* 最后一轮可以只打一部分人。

如果当前轮开始时塔子哥等级是 `x`，那么这一轮里他一定应该优先打当前能赢的、并且等级更低的对手。
因此，若排序后满足：

$$
a_i \le x+i
$$

则说明这一轮中第 `i` 个对手可以在前面若干次胜利后被击败。

于是定义：

$$
diff[i] = \max_{0\le j\le i}(a_j-j)
$$

那么当且仅当 `diff[i] <= x` 时，说明当前这一轮可以连续赢下前 `i+1` 个对手。

设这一轮最多能赢 `k` 个对手，那么这一轮结束后的等级变化为：

$$
x \leftarrow x + k - (n-k) = x + 2k - n
$$

也就是每完整一轮的净增量为：

$$
base = 2k-n
$$



### 贪心推进

每次根据当前等级 `x`，二分找到最大的 `k`，满足：

$$
diff[k-1] \le x
$$

也就是这一轮最多能赢 `k` 场。

然后分情况讨论：

1. **如果 `x + k >= y`**
   说明这一轮里直接打赢 `y-x` 场就够了，答案加上 `y-x`。

2. **如果 `base <= 0`**
   说明完整一轮后等级不会上升，无法继续逼近目标，输出 `-1`。

3. **否则 `base > 0`**
   说明可以通过若干整轮提升等级。
   设下一次 `k` 增大的临界等级是 `diff[k]`，那么可以一次性跳过若干整轮，直到：

   * 等级达到 `y-k`，从而下一轮内可直接到达 `y`；
   * 或者等级达到 `diff[k]`，使本轮可赢场数继续增加。

这样整体复杂度为：

* 排序：`O(n log n)`
* 每次二分：`O(log n)`
* 总复杂度：`O(n log n)`



## 具体实现

1. **对手等级排序**：先将所有对手等级从小到大排序。

2. **构造 `diff` 数组**：
   `diff[i]` 表示要想在某一轮内连续打赢前 `i+1` 个对手，当前轮开始时至少需要的等级。

3. **二分当前这一轮最多能赢几个**：
   每次用二分找满足 `diff[i] <= x` 的最大 `i`，记可赢场数为 `k=i+1`。

4. **按轮跳跃**：

   * 若当前轮就能达到目标，则直接更新答案；
   * 否则若一整轮净增量 `base<=0`，则无法到达；
   * 否则就整轮跳跃，快速更新当前等级和比赛次数。

5. **输出结果**：输出最少比赛次数；若无法达到则输出 `-1`。


## 时间复杂度

* 排序：`O(n log n)`
* 每次循环二分：`O(log n)`
* 总复杂度：`O(n log n)`

## 代码实现

### C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

using int64 = long long;
const long long INF = (1LL << 62);

int main() {
    int n;
    int64 x, y;
    cin >> n >> x >> y;

    vector<int64> nums(n);
    for (int i = 0; i < n; i++) cin >> nums[i];

    sort(nums.begin(), nums.end());

    vector<int64> diff(n);
    for (int i = 0; i < n; i++) {
        diff[i] = nums[i] - i;
        if (i) diff[i] = max(diff[i], diff[i - 1]);
    }

    int64 ans = 0;

    while (x < y) {
        int k = upper_bound(diff.begin(), diff.end(), x) - diff.begin(); // 当前轮最多能赢 k 个

        if (x + k >= y) {
            cout << ans + (y - x) << '\n';
            return 0;
        }

        int64 base = 2LL * k - n; // 一整轮净增量
        if (base <= 0) {
            cout << -1 << '\n';
            return 0;
        }

        int64 need1 = y - k; // 达到这个等级后，下一轮内可直接到 y
        int64 need2 = (k < n ? diff[k] : INF); // 下一个 k 增大的临界点

        int64 target = min(need1, need2);
        int64 t = (target - x + base - 1) / base; // 至少跳多少整轮
        if (t <= 0) t = 1;

        ans += t * n;
        x += t * base;
    }

    cout << ans << '\n';
    return 0;
}
```

```python
import bisect

n, x, y = map(int, input().split())
a = sorted(map(int, input().split()))

diff = [0] * n
for i in range(n):
    diff[i] = a[i] - i
    if i > 0:
        diff[i] = max(diff[i], diff[i - 1])

ans = 0
INF = 10**30

while x < y:
    k = bisect.bisect_right(diff, x)  # 当前轮最多能赢 k 个

    if x + k >= y:
        print(ans + (y - x))
        break

    base = 2 * k - n  # 一整轮净增量
    if base <= 0:
        print(-1)
        break

    need1 = y - k                 # 达到后下一轮可直接到 y
    need2 = diff[k] if k < n else INF  # 下一个临界点
    target = min(need1, need2)

    t = (target - x + base - 1) // base
    if t <= 0:
        t = 1

    ans += t * n
    x += t * base
```



### Java 

```java
import java.util.*;

public class Main {
    static final long INF = (long) 4e18;

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        int n = in.nextInt();
        long x = in.nextLong();
        long y = in.nextLong();

        long[] nums = new long[n];
        for (int i = 0; i < n; i++) nums[i] = in.nextLong();

        Arrays.sort(nums);

        long[] diff = new long[n];
        for (int i = 0; i < n; i++) {
            diff[i] = nums[i] - i;
            if (i > 0) diff[i] = Math.max(diff[i], diff[i - 1]);
        }

        long ans = 0;

        while (x < y) {
            int k = upperBound(diff, x); // 当前轮最多能赢 k 个

            if (x + k >= y) {
                System.out.println(ans + (y - x));
                return;
            }

            long base = 2L * k - n; // 一整轮净增量
            if (base <= 0) {
                System.out.println(-1);
                return;
            }

            long need1 = y - k; // 达到后下一轮内可直接到 y
            long need2 = (k < n ? diff[k] : INF); // 下一个临界点
            long target = Math.min(need1, need2);

            long t = (target - x + base - 1) / base;
            if (t <= 0) t = 1;

            ans += t * n;
            x += t * base;
        }

        System.out.println(ans);
    }

    static int upperBound(long[] a, long x) {
        int l = 0, r = a.length;
        while (l < r) {
            int mid = (l + r) >>> 1;
            if (a[mid] <= x) l = mid + 1;
            else r = mid;
        }
        return l;
    }
}
```
