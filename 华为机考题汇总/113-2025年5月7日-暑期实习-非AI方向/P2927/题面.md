# 题目内容

有一棵二叉树，每个节点上都住了一户居民。现在要给这棵树上的居民建设基站，每个基站只能覆盖她所在与相邻的节点，请问信号覆盖这棵树最少需要建设多少个基站

# 输入描述

一个整数数组$nums(1<=num.length<=3000)$，用空格分隔，表示二叉树的节点值，正整数表示存在节点，$N$表示不存在节点，如$[1\ 2\ 3\ 4\ N\ 5\ 6]$表示一颗如下所示的树，最少需要建设$2$个基站

# 输出描述



最少需要建设的基站个数



## 样例1 

**输入** 

```
1 2 3 4 N 5 6
```

**输出** 

```
2
```

如图,$2$个基站可以覆盖所有节点
