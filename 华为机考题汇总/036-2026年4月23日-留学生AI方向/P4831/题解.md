## 解题思路

本题可以分成两个阶段：

1. 先按照给定阈值，把连续特征离散化为 $0/1$
2. 再用离散后的训练数据构建 $ID3$ 决策树，并对新样本分类

本题的特征在离散化后都是二值特征，因此非常适合直接使用 $ID3$ 算法。

### 核心思路

#### 1. 特征离散化

题目已经给出了每个特征对应的阈值。对于任意一个原始特征值 $x$：

* 若 $x < threshold$，则离散化为 $0$
* 若 $x \ge threshold$，则离散化为 $1$

这样，原来连续的运行指标就被转换成了 “是否告警” 的二值信号。

设第 $j$ 个特征阈值为 $t_j$，则离散化规则为：

$$
b_j =
\begin{cases}
0, & x_j < t_j \
1, & x_j \ge t_j
\end{cases}
$$



#### 2. 使用 $ID3$ 构建决策树

$ID3$ 的核心是：每次选择 **信息增益最大** 的特征作为当前结点的划分特征。

##### （1）信息熵

对于当前样本集 $D$，若标签中有两类：正常 $0$ 和故障 $1$，设其占比分别为 $p_0, p_1$，则信息熵为：

$$
H(D) = -\sum_{k \in {0,1}} p_k \log_2 p_k
$$

当某一类概率为 $0$ 时，对应项视为 $0$。



##### （2）条件熵

如果按某个特征 $A$ 划分，由于本题中特征只有 $0/1$ 两种取值，那么可分成两个子集：

* $D_0$：该特征取值为 $0$ 的样本
* $D_1$：该特征取值为 $1$ 的样本

条件熵为：

$$
H(D|A) = \frac{|D_0|}{|D|}H(D_0) + \frac{|D_1|}{|D|}H(D_1)
$$



##### （3）信息增益

$$
Gain(D, A) = H(D) - H(D|A)
$$

对于当前还未使用的每一个特征，都计算一次信息增益，选择信息增益最大的特征作为当前结点。

若出现信息增益相同的情况，为了保证结果稳定，可以选择 **编号更小的特征**。



#### 3. 递归建树

对当前样本集合递归处理：

##### 终止条件

1. 当前样本标签全部相同
   直接建立叶子结点，类别就是该标签

2. 已经没有可用特征
   建立叶子结点，类别取当前样本中的多数类

3. 某个划分后子集为空
   该分支直接设为当前样本集的多数类叶子结点



#### 4. 多数类的确定

当需要返回多数类时：

* 若标签 $1$ 的数量大于标签 $0$，返回 $1$
* 否则返回 $0$

也就是相等时返回 $0$，这样规则固定，代码实现稳定。



#### 5. 预测过程

对待测样本先按阈值离散化，再从根结点开始：

* 若当前结点是叶子结点，直接返回类别
* 否则看该结点使用的特征值是 $0$ 还是 $1$，进入对应子树
* 直到走到叶子结点为止

由于训练和测试都经过同样的阈值离散化，所以预测过程就是普通的二叉决策过程。



### 实现方法

1. 读入 $N, M$
2. 读入 $M$ 个阈值
3. 读入训练数据，并完成离散化
4. 使用递归实现 $ID3$ 建树

   * 结点中保存：

     * 是否为叶子
     * 叶子类别
     * 当前划分特征编号
     * 两个孩子结点
     * 当前结点多数类（用于兜底）
5. 读入查询样本，离散化后逐个预测
6. 输出所有预测结果



## 复杂度分析

设：

* 训练样本数为 $N$
* 特征数为 $M$
* 待预测样本数为 $q$

### 时间复杂度

#### 1. 离散化训练数据

每个样本有 $M$ 个特征，因此复杂度为：

$$
O(NM)
$$

#### 2. 构建决策树

在每个结点上，需要枚举当前所有可用特征，并统计对应的信息增益。
单次统计大致与当前样本数和可用特征数成正比。

在最坏情况下，树高为 $M$，每层都可能扫描大量样本，因此总复杂度可估计为：

$$
O(NM^2)
$$

在本题数据范围 $N \le 10^3,\ M \le 20$ 下，这个复杂度完全可接受。

#### 3. 预测

每个查询样本最多沿树走 $M$ 层，因此复杂度为：

$$
O(qM)
$$

#### 4. 总时间复杂度

$$
O(NM^2 + qM)
$$



### 空间复杂度

* 存储离散化后的训练数据需要：

$$
O(NM)
$$

* 决策树结点数在最坏情况下不超过样本划分产生的规模，整体仍可认为不超过：

$$
O(NM)
$$

因此总空间复杂度为：

$$
O(NM)
$$

在题目范围内同样是合适的。

```python
import math
import sys


# 决策树结点
class Node:
    def __init__(self):
        # 是否为叶子结点
        self.is_leaf = False
        # 叶子结点的类别
        self.label = 0
        # 当前结点选择的划分特征下标
        self.feature = -1
        # 左右子树，分别对应特征值 0 和 1
        self.children = {}
        # 当前结点样本的多数类，作为兜底返回
        self.majority = 0


# 计算当前样本集合的信息熵
def entropy(indices, labels):
    total = len(indices)
    if total == 0:
        return 0.0

    cnt1 = 0
    for idx in indices:
        if labels[idx] == 1:
            cnt1 += 1
    cnt0 = total - cnt1

    res = 0.0
    for cnt in (cnt0, cnt1):
        if cnt > 0:
            p = cnt / total
            res -= p * math.log2(p)
    return res


# 计算当前样本集合的多数类
def majority_label(indices, labels):
    cnt1 = 0
    for idx in indices:
        if labels[idx] == 1:
            cnt1 += 1
    cnt0 = len(indices) - cnt1
    # 相等时返回 0
    return 1 if cnt1 > cnt0 else 0


# 判断当前样本标签是否全相同
def all_same_label(indices, labels):
    first = labels[indices[0]]
    for idx in indices:
        if labels[idx] != first:
            return False
    return True


# 构建 ID3 决策树
def build_tree(indices, features, labels, available_features):
    node = Node()
    node.majority = majority_label(indices, labels)

    # 如果当前样本标签完全一致，直接作为叶子结点
    if all_same_label(indices, labels):
        node.is_leaf = True
        node.label = labels[indices[0]]
        return node

    # 如果没有可用特征，返回多数类叶子结点
    if not available_features:
        node.is_leaf = True
        node.label = node.majority
        return node

    base_entropy = entropy(indices, labels)

    best_feature = -1
    best_gain = -1.0

    # 枚举当前所有可用特征，选择信息增益最大的特征
    for f in available_features:
        groups = {0: [], 1: []}
        for idx in indices:
            groups[features[idx][f]].append(idx)

        cond_entropy = 0.0
        total = len(indices)
        for v in (0, 1):
            subset = groups[v]
            if subset:
                cond_entropy += (len(subset) / total) * entropy(subset, labels)

        gain = base_entropy - cond_entropy

        # 若信息增益更大则更新
        # 若相等则选择编号更小的特征，保证结果稳定
        if gain > best_gain + 1e-12 or (abs(gain - best_gain) <= 1e-12 and f < best_feature):
            best_gain = gain
            best_feature = f

    node.feature = best_feature

    next_features = []
    for f in available_features:
        if f != best_feature:
            next_features.append(f)

    # 按最优特征的 0/1 取值划分子集
    for v in (0, 1):
        subset = []
        for idx in indices:
            if features[idx][best_feature] == v:
                subset.append(idx)

        # 如果子集为空，则该分支直接接一个多数类叶子结点
        if not subset:
            child = Node()
            child.is_leaf = True
            child.label = node.majority
            child.majority = node.majority
            node.children[v] = child
        else:
            node.children[v] = build_tree(subset, features, labels, next_features)

    return node


# 使用决策树预测单个样本
def predict(root, sample):
    cur = root
    while not cur.is_leaf:
        v = sample[cur.feature]
        if v in cur.children:
            cur = cur.children[v]
        else:
            return cur.majority
    return cur.label


def solve():
    input = sys.stdin.readline

    # 读入训练样本数量和特征数量
    N, M = map(int, input().split())

    # 读入各个特征的阈值
    thresholds = list(map(float, input().split()))

    features = []
    labels = []

    # 读入训练数据并离散化
    for _ in range(N):
        arr = list(map(float, input().split()))
        row = []
        for j in range(M):
            row.append(1 if arr[j] >= thresholds[j] else 0)
        features.append(row)
        labels.append(int(arr[M]))

    # 所有样本下标
    indices = list(range(N))
    # 初始可用特征集合
    available_features = list(range(M))

    # 建树
    root = build_tree(indices, features, labels, available_features)

    # 读入待预测样本数量
    q = int(input())
    ans = []

    # 逐个离散化并预测
    for _ in range(q):
        arr = list(map(float, input().split()))
        sample = []
        for j in range(M):
            sample.append(1 if arr[j] >= thresholds[j] else 0)
        ans.append(str(predict(root, sample)))

    print(" ".join(ans))


if __name__ == "__main__":
    solve()
```

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Main {

    // 决策树结点
    static class Node {
        // 是否为叶子结点
        boolean isLeaf;
        // 叶子结点类别
        int label;
        // 当前结点划分使用的特征编号
        int feature;
        // 当前结点样本的多数类
        int majority;
        // 两个孩子结点，0 和 1
        Node[] children;

        Node() {
            isLeaf = false;
            label = 0;
            feature = -1;
            majority = 0;
            children = new Node[2];
        }
    }

    // 训练数据的离散特征
    static int[][] features;
    // 训练标签
    static int[] labels;

    // 计算样本集合的信息熵
    static double entropy(List<Integer> indices) {
        int total = indices.size();
        if (total == 0) {
            return 0.0;
        }

        int cnt1 = 0;
        for (int idx : indices) {
            if (labels[idx] == 1) {
                cnt1++;
            }
        }
        int cnt0 = total - cnt1;

        double res = 0.0;
        if (cnt0 > 0) {
            double p = (double) cnt0 / total;
            res -= p * (Math.log(p) / Math.log(2));
        }
        if (cnt1 > 0) {
            double p = (double) cnt1 / total;
            res -= p * (Math.log(p) / Math.log(2));
        }
        return res;
    }

    // 计算多数类，相等时返回 0
    static int majorityLabel(List<Integer> indices) {
        int cnt1 = 0;
        for (int idx : indices) {
            if (labels[idx] == 1) {
                cnt1++;
            }
        }
        int cnt0 = indices.size() - cnt1;
        return cnt1 > cnt0 ? 1 : 0;
    }

    // 判断当前样本标签是否完全相同
    static boolean allSameLabel(List<Integer> indices) {
        int first = labels[indices.get(0)];
        for (int idx : indices) {
            if (labels[idx] != first) {
                return false;
            }
        }
        return true;
    }

    // 构建 ID3 决策树
    static Node buildTree(List<Integer> indices, List<Integer> availableFeatures) {
        Node node = new Node();
        node.majority = majorityLabel(indices);

        // 当前样本标签完全一致，直接建立叶子结点
        if (allSameLabel(indices)) {
            node.isLeaf = true;
            node.label = labels[indices.get(0)];
            return node;
        }

        // 没有可用特征时，返回多数类叶子结点
        if (availableFeatures.isEmpty()) {
            node.isLeaf = true;
            node.label = node.majority;
            return node;
        }

        double baseEntropy = entropy(indices);
        int bestFeature = -1;
        double bestGain = -1.0;

        // 枚举当前所有可用特征，选取信息增益最大的特征
        for (int f : availableFeatures) {
            List<Integer> group0 = new ArrayList<>();
            List<Integer> group1 = new ArrayList<>();

            for (int idx : indices) {
                if (features[idx][f] == 0) {
                    group0.add(idx);
                } else {
                    group1.add(idx);
                }
            }

            double condEntropy = 0.0;
            int total = indices.size();

            if (!group0.isEmpty()) {
                condEntropy += (double) group0.size() / total * entropy(group0);
            }
            if (!group1.isEmpty()) {
                condEntropy += (double) group1.size() / total * entropy(group1);
            }

            double gain = baseEntropy - condEntropy;

            // 若信息增益相同，则选择编号更小的特征
            if (gain > bestGain + 1e-12 || (Math.abs(gain - bestGain) <= 1e-12 && f < bestFeature)) {
                bestGain = gain;
                bestFeature = f;
            }
        }

        node.feature = bestFeature;

        // 构造下一层可用特征列表
        List<Integer> nextFeatures = new ArrayList<>();
        for (int f : availableFeatures) {
            if (f != bestFeature) {
                nextFeatures.add(f);
            }
        }

        // 按 0/1 两个分支递归建树
        for (int v = 0; v <= 1; v++) {
            List<Integer> subset = new ArrayList<>();
            for (int idx : indices) {
                if (features[idx][bestFeature] == v) {
                    subset.add(idx);
                }
            }

            // 若子集为空，则该分支接多数类叶子结点
            if (subset.isEmpty()) {
                Node child = new Node();
                child.isLeaf = true;
                child.label = node.majority;
                child.majority = node.majority;
                node.children[v] = child;
            } else {
                node.children[v] = buildTree(subset, nextFeatures);
            }
        }

        return node;
    }

    // 使用决策树预测单个样本
    static int predict(Node root, int[] sample) {
        Node cur = root;
        while (!cur.isLeaf) {
            int v = sample[cur.feature];
            if (cur.children[v] == null) {
                return cur.majority;
            }
            cur = cur.children[v];
        }
        return cur.label;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // 读入训练样本数和特征数
        int N = sc.nextInt();
        int M = sc.nextInt();

        // 读入阈值
        double[] thresholds = new double[M];
        for (int i = 0; i < M; i++) {
            thresholds[i] = sc.nextDouble();
        }

        features = new int[N][M];
        labels = new int[N];

        // 读入训练数据并离散化
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < M; j++) {
                double x = sc.nextDouble();
                features[i][j] = x >= thresholds[j] ? 1 : 0;
            }
            labels[i] = (int) sc.nextDouble();
        }

        // 初始样本下标集合
        List<Integer> indices = new ArrayList<>();
        for (int i = 0; i < N; i++) {
            indices.add(i);
        }

        // 初始可用特征集合
        List<Integer> availableFeatures = new ArrayList<>();
        for (int i = 0; i < M; i++) {
            availableFeatures.add(i);
        }

        // 建树
        Node root = buildTree(indices, availableFeatures);

        // 读入查询数量
        int q = sc.nextInt();
        StringBuilder sb = new StringBuilder();

        // 逐个离散化并预测
        for (int i = 0; i < q; i++) {
            int[] sample = new int[M];
            for (int j = 0; j < M; j++) {
                double x = sc.nextDouble();
                sample[j] = x >= thresholds[j] ? 1 : 0;
            }

            int ans = predict(root, sample);
            if (i > 0) {
                sb.append(" ");
            }
            sb.append(ans);
        }

        System.out.println(sb.toString());
        sc.close();
    }
}
```

```cpp
            double x;
            cin >> x;
            features[i][j] = (x >= thresholds[j]) ? 1 : 0;
        }
        double y;
        cin >> y;
        labels[i] = (int)y;
    }

    // 初始样本下标集合
    vector<int> indices;
    for (int i = 0; i < N; i++) {
        indices.push_back(i);
    }

    // 初始可用特征集合
    vector<int> availableFeatures;
    for (int i = 0; i < M; i++) {
        availableFeatures.push_back(i);
    }

    // 建树
    Node* root = buildTree(indices, availableFeatures);

    // 读入查询数量
    int q;
    cin >> q;

    // 逐个离散化并预测
    for (int i = 0; i < q; i++) {
        vector<int> sample(M);
        for (int j = 0; j < M; j++) {
            double x;
            cin >> x;
            sample[j] = (x >= thresholds[j]) ? 1 : 0;
        }

        if (i > 0) {
            cout << " ";
        }
        cout << predict(root, sample);
    }
    cout << "\n";

    return 0;
}
```
