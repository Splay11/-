## 解题思路

MMR 的定义是：

$$
MMR(i)=\lambda \cdot rel[i]-(1-\lambda)\cdot \max_{j \in S} sim[i][j]
$$

其中：

* $rel[i]$ 表示文档 $i$ 与用户问题的相关性
* $S$ 表示已经被选中的文档集合
* $\max_{j \in S} sim[i][j]$ 表示候选文档 $i$ 与当前已选文档中最相似的那个文档的相似度
* 当 $S$ 为空时，第二项视为 $0$

题目要求按 MMR 规则贪心选择 $K$ 个文档，并输出选择顺序对应的文档 ID。

核心思路就是模拟题目给出的贪心过程：

1. 初始时没有选中文档，$S=\varnothing$
2. 每一轮在所有未选文档中，计算当前的 MMR 分数
3. 选择 MMR 分数最大的文档加入集合
4. 如果 MMR 分数相同，选择文档 ID 更小的那个
5. 重复执行，直到选出 $K$ 个文档

如果直接按照定义计算，每次都重新枚举已选集合求最大相似度，那么第 $t$ 轮会对每个候选文档再扫一遍已选文档，效率较低。

这里可以做一个关键优化：

设 $bestSim[i]$ 表示当前文档 $i$ 与已选集合 $S$ 中任意文档的最大相似度，即：

$$
bestSim[i]=\max_{j \in S} sim[i][j]
$$

那么每次新选出一个文档 $p$ 后，只需要用它去更新所有未选文档的 $bestSim$：

$$
bestSim[i]=\max(bestSim[i],\ sim[i][p])
$$

这样每轮就只需要：

* 扫一遍所有未选文档，计算当前 MMR
* 选出最优文档
* 再扫一遍所有未选文档，更新 $bestSim$

整体过程就是一个带维护数组的贪心。

实现方法如下：

1. 读入所有文档的相关性分数和 ID
2. 读入相似度矩阵 $sim$
3. 用布尔数组 `selected` 记录文档是否已被选中
4. 用数组 `bestSim` 维护每个文档到已选集合的最大相似度
5. 重复 $K$ 轮：

   * 对每个未选文档计算
     $$
     score=\lambda \cdot rel[i]-(1-\lambda)\cdot bestSim[i]
     $$
   * 选出分数最大的文档；若分数相同，取 ID 更小者
   * 将其对应的 ID 加入答案
   * 用该文档更新所有未选文档的 `bestSim`

需要注意两点：

1. 比较相等分数时是按“文档 ID 更小”优先，不是按输入下标优先
2. 浮点数比较时，代码里最好加一个很小的误差值 `eps`，避免精度问题导致判断异常

## 复杂度分析

设文档数量为 $N$，最终需要选择 $K$ 个文档。

读入相似度矩阵本身就需要 $O(N^2)$。

在贪心选择过程中，每一轮：

* 扫描所有未选文档计算当前最优答案，复杂度为 $O(N)$
* 用新选文档更新所有未选文档的 `bestSim`，复杂度为 $O(N)$

共进行 $K$ 轮，因此选择过程复杂度为：

$$
O(NK)
$$

总时间复杂度为：

$$
O(N^2 + NK)
$$

由于 $K \le N$，所以该复杂度在 $N \le 1000$ 的范围内是完全可行的。

空间方面，需要存储：

* 相关性数组：$O(N)$
* ID 数组：$O(N)$
* 选中标记数组：$O(N)$
* 最大相似度数组：$O(N)$
* 相似度矩阵：$O(N^2)$

总空间复杂度为：

$$
O(N^2)
$$

### Python

```python
import sys


# 按照 MMR 规则选择 K 个文档，返回被选中文档的 ID 顺序
def mmr_select(n, rel, ids, sim, lambd, k):
    # selected[i] 表示第 i 个文档是否已经被选中
    selected = [False] * n

    # best_sim[i] 表示文档 i 与当前已选集合中任意文档的最大相似度
    # 初始已选集合为空，因此最大相似度都为 0
    best_sim = [0.0] * n

    # 记录最终选择顺序对应的文档 ID
    ans = []

    # 浮点数比较时使用的误差范围
    eps = 1e-12

    # 共选择 k 轮
    for _ in range(k):
        best_idx = -1
        best_score = -10**100

        # 在所有未选文档中找当前 MMR 分数最大的文档
        for i in range(n):
            if selected[i]:
                continue

            score = lambd * rel[i] - (1.0 - lambd) * best_sim[i]

            # 分数更大，直接更新
            if score > best_score + eps:
                best_score = score
                best_idx = i
            # 分数相同，按文档 ID 更小优先
            elif abs(score - best_score) <= eps:
                if ids[i] < ids[best_idx]:
                    best_idx = i

        # 将当前选中的文档加入答案
        selected[best_idx] = True
        ans.append(ids[best_idx])

        # 用新选中的文档更新其余未选文档的最大相似度
        for i in range(n):
            if not selected[i]:
                if sim[i][best_idx] > best_sim[i]:
                    best_sim[i] = sim[i][best_idx]

    return ans


def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        return

    ptr = 0

    # 读入文档数量
    n = int(data[ptr])
    ptr += 1

    # 读入每个文档的相关性分数和 ID
    rel = [0.0] * n
    ids = [0] * n
    for i in range(n):
        rel[i] = float(data[ptr])
        ptr += 1
        ids[i] = int(data[ptr])
        ptr += 1

    # 读入相似度矩阵
    sim = [[0.0] * n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            sim[i][j] = float(data[ptr])
            ptr += 1

    # 读入 lambda 和 K
    lambd = float(data[ptr])
    ptr += 1
    k = int(data[ptr])
    ptr += 1

    # 调用外部函数完成题面要求的功能
    ans = mmr_select(n, rel, ids, sim, lambd, k)

    # 输出答案
    if k == 0:
        print()
    else:
        print(" ".join(map(str, ans)))


if __name__ == "__main__":
    main()
```

    static class FastReader {

        public FastReader() {
            br = new BufferedReader(new InputStreamReader(System.in));
        }

        String next() throws IOException {
            while (st == null || !st.hasMoreElements()) {
                st = new StringTokenizer(br.readLine());
            }
            return st.nextToken();
        }

        // 读取 int
        int nextInt() throws IOException {
            return Integer.parseInt(next());
        }

        // 读取 double
        double nextDouble() throws IOException {
            return Double.parseDouble(next());
        }
    }

        boolean[] selected = new boolean[n];

        List<Integer> ans = new ArrayList<>();

        double eps = 1e-12;

            for (int i = 0; i < n; i++) {

    // 记录答案
    vector<int> ans;

    // 浮点数比较误差
    const double eps = 1e-12;

    // 共进行 k 轮选择
    for (int round = 0; round < k; ++round) {
        int bestIdx = -1;
        double bestScore = -1e100;

        for (int i = 0; i < n; ++i) {

            // 分数更大，直接更新

            else if (fabs(score - bestScore) <= eps) {

                }
