# T7

**答案：A. 召回文档  $d_1$， 得分为4**  
**解析：**  
计算两个内积：

$q \cdot d_1 = [1,2]\cdot[2,1] = 1\times 2 + 2\times 1 = 4$

$q \cdot d_2 = [1,2]\cdot[-1,2] = 1\times (-1) + 2\times 2 = -1 + 4 = 3$

因为 MIPS 选择**内积更大**的文档，所以系统会召回：

**文档 $d_1$，得分为 4**

# T8

**答案：D. $ \sum(X_i - \mu) = 0 $**  
**解析：** 极大化 $ L(\mu) $ 等价于最小化 $ \sum(X_i - \mu)^2 $，对 $ \mu $ 求导得 $ \sum(X_i - \mu) = 0 $。

# T16

**答案：**  

- **A.** 若 $ |E_0| < 1 $，则迭代二次收敛到 $ A^{-1} $，且误差满足 $ |E_k| < |E_0|^{2^k} $。  
- **B.** 若谱半径 $ \rho(E_0) < 1 $，则迭代收敛到 $ A^{-1} $。
