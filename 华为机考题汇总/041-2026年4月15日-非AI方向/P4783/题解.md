## 解题思路

这题的关键是正确判断“可见”。

窗口之间的遮挡规则本质上是一个优先级比较：

* 层级更大的窗口会盖住层级更小的窗口
* 层级相同，后创建的窗口会盖住先创建的窗口
* $move$ 和 $resize$ 只改位置和大小，不改变创建先后顺序

所以，一个窗口是否可见，可以转化为：

> 该窗口在屏幕内的区域，是否存在至少一个点，没有被所有“比它优先级高”的窗口完全盖住。

### 相关算法

这里使用的是 矩形覆盖 + 坐标离散化（坐标压缩） 的做法。

因为操作数最多只有 $100$，不需要上复杂的扫描线。
每次查询可见性时，直接把：

* 当前待判断区域的左右边界
* 所有可能遮挡它的窗口在该区域内的投影边界

全部取出来做坐标离散化。这样二维平面会被切成很多小矩形格子。
对于每个小格子，只要它被更高优先级窗口覆盖，就标记为已覆盖；最后只要还有任意一个未覆盖的小格子，说明该窗口可见。

### 核心思路

设一个窗口矩形为 $(x, y, w, h)$，则实际区域是：

* 左上角：$(x, y)$
* 右下角：$(x+w, y+h)$

先和屏幕求交，屏幕外部分不算可见区域。

#### $1.$ 如何判断单个窗口是否可见

对于目标窗口：

1. 先求它和屏幕的交集区域
2. 再枚举所有能盖住它的窗口：

   * 层级更高
   * 或层级相同且创建时间更晚
3. 只保留这些遮挡窗口与目标区域的交集
4. 对这些边界做坐标离散化
5. 在离散后的网格中标记被遮挡的小块
6. 只要目标区域内还存在一个未被遮挡的小块，就返回 $true$，否则返回 $false$

#### $2.$ 如何判断某个查询区域内的所有可见窗口

对于每个窗口：

1. 先求“窗口区域 $\cap$ 查询区域 $\cap$ 屏幕区域”
2. 如果这个交集为空，说明它在查询区域内不可能可见
3. 否则用上面的单窗口可见性判断，只不过目标区域换成这个交集区域
4. 把可见窗口加入答案

最后按题意排序：

* 先按窗口层级降序
* 层级相同按窗口名字典序升序

若没有可见窗口，输出 `"NoVisibleWindow"`。

### 实现方法

用一个窗口系统类维护：

* 屏幕宽高
* 窗口表：窗口名 $\to$ 窗口对象
* 创建顺序编号

支持以下操作：

* $init$
* $createWindow$
* $removeWindow$
* $resize$
* $move$
* $queryVisibility$
* $queryAllVisibleWindows$

其中，真正的难点统一交给一个函数：

* 判断“某窗口在指定区域内是否仍有可见部分”

这样逻辑最清晰，也方便复用。

## 复杂度分析

设当前窗口数为 $n$。

### 单次可见性判断

最多会收集 $n$ 个可能遮挡窗口。
离散化后的横纵坐标数量都不超过 $2n+2$，网格规模为 $O(n^2)$。
每个遮挡窗口在网格上做覆盖标记，因此总复杂度为：

$$
O(n^3)
$$

但本题中 $n \le 100$，这个复杂度完全可以通过。

### 各操作复杂度

* $init$：$O(1)$
* $createWindow$：$O(1)$
* $removeWindow$：$O(1)$
* $resize$：$O(1)$
* $move$：$O(1)$
* $queryVisibility$：$O(n^3)$
* $queryAllVisibleWindows$：最多对每个窗口判断一次，因此为

$$
O(n^4)
$$

但由于总操作数最多只有 $100$，实际运行足够快。

### 空间复杂度

主要是窗口存储和离散化网格：

$$
O(n^2)
$$

```python
import sys


# 窗口类
class Window:
    def __init__(self, name, x, y, w, h, level, order):
        self.name = name
        self.x = x
        self.y = y
        self.w = w
        self.h = h
        self.level = level
        self.order = order  # 创建顺序，越大表示越晚创建

    # 返回矩形的左右上下边界
    def rect(self):
        return (self.x, self.y, self.x + self.w, self.y + self.h)


# 窗口系统类
class WindowSystem:
    def __init__(self):
        self.screen_w = 0
        self.screen_h = 0
        self.windows = {}
        self.order_id = 0

    # 求两个矩形的交集，矩形格式为 (x1, y1, x2, y2)
    def intersect(self, a, b):
        x1 = max(a[0], b[0])
        y1 = max(a[1], b[1])
        x2 = min(a[2], b[2])
        y2 = min(a[3], b[3])
        if x1 >= x2 or y1 >= y2:
            return None
        return (x1, y1, x2, y2)

    # 判断 b 是否能遮挡 a
    def higher(self, b, a):
        if b.level != a.level:
            return b.level > a.level
        return b.order > a.order

    # 判断某个窗口在指定区域内是否还有可见部分
    def visible_in_region(self, target, region):
        # 先裁剪到屏幕内
        screen_rect = (0, 0, self.screen_w, self.screen_h)
        target_rect = self.intersect(region, screen_rect)
        if target_rect is None:
            return False

        # 收集所有可能遮挡它的窗口
        covers = []
        for other in self.windows.values():
            if other.name == target.name:
                continue
            if not self.higher(other, target):
                continue
            inter = self.intersect(target_rect, other.rect())
            if inter is not None:
                covers.append(inter)

        # 坐标离散化
        xs = [target_rect[0], target_rect[2]]
        ys = [target_rect[1], target_rect[3]]
        for r in covers:
            xs.append(r[0])
            xs.append(r[2])
            ys.append(r[1])
            ys.append(r[3])

        xs = sorted(set(xs))
        ys = sorted(set(ys))

        x_id = {}
        y_id = {}
        for i, v in enumerate(xs):
            x_id[v] = i
        for i, v in enumerate(ys):
            y_id[v] = i

        # 标记被遮挡的小格子
        covered = [[False] * (len(ys) - 1) for _ in range(len(xs) - 1)]
        for r in covers:
            x1 = x_id[r[0]]
            x2 = x_id[r[2]]
            y1 = y_id[r[1]]
            y2 = y_id[r[3]]
            for i in range(x1, x2):
                for j in range(y1, y2):
                    covered[i][j] = True

        # 只要存在一个未被遮挡的小格子，就说明可见
        tx1 = x_id[target_rect[0]]
        tx2 = x_id[target_rect[2]]
        ty1 = y_id[target_rect[1]]
        ty2 = y_id[target_rect[3]]
        for i in range(tx1, tx2):
            for j in range(ty1, ty2):
                if not covered[i][j]:
                    return True
        return False

    # 初始化屏幕
    def init(self, w, h):
        if w <= 0 or h <= 0:
            return False
        self.screen_w = w
        self.screen_h = h
        self.windows.clear()
        self.order_id = 0
        return True

    # 创建窗口
    def createWindow(self, name, x, y, w, h, level):
        if w <= 0 or h <= 0:
            return False
        if name in self.windows:
            return False
        self.order_id += 1
        self.windows[name] = Window(name, x, y, w, h, level, self.order_id)
        return True

    # 删除窗口
    def removeWindow(self, name):
        if name not in self.windows:
            return False
        del self.windows[name]
        return True

    # 修改窗口大小
    def resize(self, name, w, h):
        if name not in self.windows:
            return False
        if w <= 0 or h <= 0:
            return False
        self.windows[name].w = w
        self.windows[name].h = h
        return True

    # 移动窗口
    def move(self, name, x, y):
        if name not in self.windows:
            return False
        self.windows[name].x = x
        self.windows[name].y = y
        return True

    # 查询单个窗口是否可见
    def queryVisibility(self, name):
        if name not in self.windows:
            return False
        win = self.windows[name]
        return self.visible_in_region(win, win.rect())

    # 查询某个区域内所有可见窗口
    def queryAllVisibleWindows(self, x, y, w, h):
        query_rect = (x, y, x + w, y + h)
        ans = []

        for win in self.windows.values():
            region = self.intersect(win.rect(), query_rect)
            if region is None:
                continue
            if self.visible_in_region(win, region):
                ans.append(win)

        # 按层级降序，名字升序排序
        ans.sort(key=lambda win: (-win.level, win.name))

        if not ans:
            return "NoVisibleWindow"
        return ";".join(win.name for win in ans)


def main():

    out = []

    for line in sys.stdin:
        line = line.strip()
```

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.ArrayList;
import java.util.Collections;
import java.util.Comparator;
import java.util.HashMap;
import java.util.List;

public class Main {

    // 窗口类
    static class Window {
        String name;
        int x, y, w, h, level, order;

        public Window(String name, int x, int y, int w, int h, int level, int order) {
            this.name = name;
            this.x = x;
            this.y = y;
            this.w = w;
            this.h = h;
            this.level = level;
            this.order = order;
        }

        // 返回矩形边界
        int[] rect() {
            return new int[]{x, y, x + w, y + h};
        }
    }

    // 窗口系统类
    static class WindowSystem {
        int screenW = 0, screenH = 0;
        int orderId = 0;
        HashMap<String, Window> windows = new HashMap<>();

        // 求两个矩形交集
        int[] intersect(int[] a, int[] b) {
            int x1 = Math.max(a[0], b[0]);
            int y1 = Math.max(a[1], b[1]);
            int x2 = Math.min(a[2], b[2]);
            int y2 = Math.min(a[3], b[3]);
            if (x1 >= x2 || y1 >= y2) return null;
            return new int[]{x1, y1, x2, y2};
        }

        // 判断 b 是否能遮挡 a
        boolean higher(Window b, Window a) {
            if (b.level != a.level) return b.level > a.level;
            return b.order > a.order;
        }

        // 判断目标窗口在指定区域内是否可见
        boolean visibleInRegion(Window target, int[] region) {
            int[] screenRect = new int[]{0, 0, screenW, screenH};
            int[] targetRect = intersect(region, screenRect);
            if (targetRect == null) return false;

            List<int[]> covers = new ArrayList<>();

            for (Window other : windows.values()) {
                if (other.name.equals(target.name)) continue;
                if (!higher(other, target)) continue;
                int[] inter = intersect(targetRect, other.rect());
                if (inter != null) covers.add(inter);
            }

            // 坐标离散化
            List<Integer> xs = new ArrayList<>();
            List<Integer> ys = new ArrayList<>();
            xs.add(targetRect[0]);
            xs.add(targetRect[2]);
            ys.add(targetRect[1]);
            ys.add(targetRect[3]);

            for (int[] r : covers) {
                xs.add(r[0]);
                xs.add(r[2]);
                ys.add(r[1]);
                ys.add(r[3]);
            }

            Collections.sort(xs);
            Collections.sort(ys);

            List<Integer> ux = new ArrayList<>();
            List<Integer> uy = new ArrayList<>();
            for (int v : xs) {
                if (ux.isEmpty() || ux.get(ux.size() - 1) != v) ux.add(v);
            }
            for (int v : ys) {
                if (uy.isEmpty() || uy.get(uy.size() - 1) != v) uy.add(v);
            }

            HashMap<Integer, Integer> xId = new HashMap<>();
            HashMap<Integer, Integer> yId = new HashMap<>();
            for (int i = 0; i < ux.size(); i++) xId.put(ux.get(i), i);
            for (int i = 0; i < uy.size(); i++) yId.put(uy.get(i), i);

            boolean[][] covered = new boolean[ux.size() - 1][uy.size() - 1];

            // 标记被遮挡区域
            for (int[] r : covers) {
                int x1 = xId.get(r[0]);
                int x2 = xId.get(r[2]);
                int y1 = yId.get(r[1]);
                int y2 = yId.get(r[3]);
                for (int i = x1; i < x2; i++) {
                    for (int j = y1; j < y2; j++) {
                        covered[i][j] = true;
                    }
                }
            }

            // 查找是否存在未被遮挡的小格子
            int tx1 = xId.get(targetRect[0]);
            int tx2 = xId.get(targetRect[2]);
            int ty1 = yId.get(targetRect[1]);
            int ty2 = yId.get(targetRect[3]);

            for (int i = tx1; i < tx2; i++) {
                for (int j = ty1; j < ty2; j++) {
                    if (!covered[i][j]) return true;
                }
            }
            return false;
        }

        // 初始化
        boolean init(int w, int h) {
            if (w <= 0 || h <= 0) return false;
            screenW = w;
            screenH = h;
            windows.clear();
            orderId = 0;
            return true;
        }

        // 创建窗口
        boolean createWindow(String name, int x, int y, int w, int h, int level) {
            if (w <= 0 || h <= 0) return false;
            if (windows.containsKey(name)) return false;
            orderId++;
            windows.put(name, new Window(name, x, y, w, h, level, orderId));
            return true;
        }

        // 删除窗口
        boolean removeWindow(String name) {
            if (!windows.containsKey(name)) return false;
            windows.remove(name);
            return true;
        }

        // 改变大小
        boolean resize(String name, int w, int h) {
            if (!windows.containsKey(name)) return false;
            if (w <= 0 || h <= 0) return false;
            Window win = windows.get(name);
            win.w = w;
            win.h = h;
            return true;
        }

        // 移动窗口
        boolean move(String name, int x, int y) {
            if (!windows.containsKey(name)) return false;
            Window win = windows.get(name);
            win.x = x;
            win.y = y;
            return true;
        }

        // 查询单个窗口是否可见
        boolean queryVisibility(String name) {
            if (!windows.containsKey(name)) return false;
            Window win = windows.get(name);
            return visibleInRegion(win, win.rect());
        }

        // 查询某个区域内所有可见窗口
        String queryAllVisibleWindows(int x, int y, int w, int h) {
            int[] queryRect = new int[]{x, y, x + w, y + h};
            List<Window> ans = new ArrayList<>();

            for (Window win : windows.values()) {
                int[] region = intersect(win.rect(), queryRect);
                if (region == null) continue;
                if (visibleInRegion(win, region)) {
                    ans.add(win);
                }
            }

            // 按层级降序，名字升序排序
            ans.sort(new Comparator<Window>() {
                @Override
                public int compare(Window a, Window b) {
                    if (a.level != b.level) return b.level - a.level;
                    return a.name.compareTo(b.name);
                }
            });

            if (ans.isEmpty()) return "NoVisibleWindow";

            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < ans.size(); i++) {
                if (i > 0) sb.append(";");
                sb.append(ans.get(i).name);
            }
            return sb.toString();
        }
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String line;
        StringBuilder out = new StringBuilder();
        WindowSystem ws = new WindowSystem();

        while ((line = br.readLine()) != null) {
            line = line.trim();
            if (line.length() == 0) continue;

            String[] parts = line.split("\\s+");
            String op = parts[0];

            if (op.equals("init")) {
                int w = Integer.parseInt(parts[1]);
                int h = Integer.parseInt(parts[2]);
                out.append(ws.init(w, h) ? "true" : "false").append("\n");
            } else if (op.equals("createWindow")) {
                String name = parts[1];
                int x = Integer.parseInt(parts[2]);
                int y = Integer.parseInt(parts[3]);
                int w = Integer.parseInt(parts[4]);
                int h = Integer.parseInt(parts[5]);
                int level = Integer.parseInt(parts[6]);
                out.append(ws.createWindow(name, x, y, w, h, level) ? "true" : "false").append("\n");
            } else if (op.equals("removeWindow")) {
                String name = parts[1];
                out.append(ws.removeWindow(name) ? "true" : "false").append("\n");
            } else if (op.equals("resize")) {
                String name = parts[1];
                int w = Integer.parseInt(parts[2]);
                int h = Integer.parseInt(parts[3]);
                out.append(ws.resize(name, w, h) ? "true" : "false").append("\n");
            } else if (op.equals("move")) {
                String name = parts[1];
                int x = Integer.parseInt(parts[2]);
                int y = Integer.parseInt(parts[3]);
                out.append(ws.move(name, x, y) ? "true" : "false").append("\n");
            } else if (op.equals("queryVisibility")) {
                String name = parts[1];
                out.append(ws.queryVisibility(name) ? "true" : "false").append("\n");
            } else if (op.equals("queryAllVisibleWindows")) {
                int x = Integer.parseInt(parts[1]);
                int y = Integer.parseInt(parts[2]);
                int w = Integer.parseInt(parts[3]);
                int h = Integer.parseInt(parts[4]);
                out.append(ws.queryAllVisibleWindows(x, y, w, h)).append("\n");
            }
        }

        System.out.print(out.toString());
    }
}
```

```cpp
#include <iostream>
#include <vector>
#include <unordered_map>
#include <algorithm>
using namespace std;

// 矩形结构
struct Rect {
    int x1, y1, x2, y2;
};

// 窗口结构
struct Window {
    string name;
    int x, y, w, h, level, order;
};

// 窗口系统类
class WindowSystem {
public:
    int screenW = 0, screenH = 0;
    int orderId = 0;
    unordered_map<string, Window> windows;

    // 返回窗口矩形
    Rect getRect(const Window& win) {
        return {win.x, win.y, win.x + win.w, win.y + win.h};
    }

    // 求两个矩形交集
    bool intersect(const Rect& a, const Rect& b, Rect& c) {
        c.x1 = max(a.x1, b.x1);
        c.y1 = max(a.y1, b.y1);
        c.x2 = min(a.x2, b.x2);
        c.y2 = min(a.y2, b.y2);
        return c.x1 < c.x2 && c.y1 < c.y2;
    }

    // 判断 b 是否能遮挡 a
    bool higher(const Window& b, const Window& a) {
        if (b.level != a.level) return b.level > a.level;
        return b.order > a.order;
    }

    // 判断目标窗口在指定区域内是否可见
    bool visibleInRegion(const Window& target, const Rect& region) {
        Rect screenRect = {0, 0, screenW, screenH};
        Rect targetRect;
        if (!intersect(region, screenRect, targetRect)) return false;

        vector<Rect> covers;

        for (auto& it : windows) {
            const Window& other = it.second;
            if (other.name == target.name) continue;
            if (!higher(other, target)) continue;

            Rect interRect;
            if (intersect(targetRect, getRect(other), interRect)) {
                covers.push_back(interRect);
            }
        }

        // 坐标离散化
        vector<int> xs, ys;
        xs.push_back(targetRect.x1);
        xs.push_back(targetRect.x2);
        ys.push_back(targetRect.y1);
        ys.push_back(targetRect.y2);

        for (auto& r : covers) {
            xs.push_back(r.x1);
            xs.push_back(r.x2);
            ys.push_back(r.y1);
            ys.push_back(r.y2);
        }

        sort(xs.begin(), xs.end());
        sort(ys.begin(), ys.end());
        xs.erase(unique(xs.begin(), xs.end()), xs.end());
        ys.erase(unique(ys.begin(), ys.end()), ys.end());

        int xn = xs.size(), yn = ys.size();
        vector<vector<bool>> covered(xn - 1, vector<bool>(yn - 1, false));

        // 标记被遮挡的小格子
        for (auto& r : covers) {
            int x1 = lower_bound(xs.begin(), xs.end(), r.x1) - xs.begin();
            int x2 = lower_bound(xs.begin(), xs.end(), r.x2) - xs.begin();
            int y1 = lower_bound(ys.begin(), ys.end(), r.y1) - ys.begin();
            int y2 = lower_bound(ys.begin(), ys.end(), r.y2) - ys.begin();

            for (int i = x1; i < x2; i++) {
                for (int j = y1; j < y2; j++) {
                    covered[i][j] = true;
                }
            }
        }

        // 判断目标区域内是否仍有未覆盖部分
        int tx1 = lower_bound(xs.begin(), xs.end(), targetRect.x1) - xs.begin();
        int tx2 = lower_bound(xs.begin(), xs.end(), targetRect.x2) - xs.begin();
        int ty1 = lower_bound(ys.begin(), ys.end(), targetRect.y1) - ys.begin();
        int ty2 = lower_bound(ys.begin(), ys.end(), targetRect.y2) - ys.begin();

        for (int i = tx1; i < tx2; i++) {
            for (int j = ty1; j < ty2; j++) {
                if (!covered[i][j]) return true;
            }
        }
        return false;
    }

    // 初始化
    bool init(int w, int h) {
        if (w <= 0 || h <= 0) return false;
        screenW = w;
        screenH = h;
        windows.clear();
        orderId = 0;
        return true;
    }

    // 创建窗口
    bool createWindow(string name, int x, int y, int w, int h, int level) {
        if (w <= 0 || h <= 0) return false;
        if (windows.count(name)) return false;
        orderId++;
        windows[name] = {name, x, y, w, h, level, orderId};
        return true;
    }

    // 删除窗口
    bool removeWindow(string name) {
        if (!windows.count(name)) return false;
        windows.erase(name);
        return true;
    }

    // 修改大小
    bool resize(string name, int w, int h) {
        if (!windows.count(name)) return false;
        if (w <= 0 || h <= 0) return false;
        windows[name].w = w;
        windows[name].h = h;
        return true;
    }

    // 移动窗口
    bool move(string name, int x, int y) {
        if (!windows.count(name)) return false;
        windows[name].x = x;
        windows[name].y = y;
        return true;
    }

    // 查询单个窗口是否可见
    bool queryVisibility(string name) {
        if (!windows.count(name)) return false;
        Window& win = windows[name];
        return visibleInRegion(win, getRect(win));
    }

    // 查询某个区域内所有可见窗口
    string queryAllVisibleWindows(int x, int y, int w, int h) {
        Rect queryRect = {x, y, x + w, y + h};
        vector<Window> ans;

        for (auto& it : windows) {
            Window& win = it.second;
            Rect region;
            if (!intersect(getRect(win), queryRect, region)) continue;
            if (visibleInRegion(win, region)) {
                ans.push_back(win);
            }
        }

        // 按层级降序，名字升序排序
        sort(ans.begin(), ans.end(), [](const Window& a, const Window& b) {
            if (a.level != b.level) return a.level > b.level;
            return a.name < b.name;
        });

        if (ans.empty()) return "NoVisibleWindow";

        string res = "";
        for (int i = 0; i < (int)ans.size(); i++) {
            if (i > 0) res += ";";
            res += ans[i].name;
        }
        return res;
    }
};

int main() {

    vector<string> output;

        } else if (op == "removeWindow") {

            string name;

        } else if (op == "move") {
            string name;
            int x, y;
```
