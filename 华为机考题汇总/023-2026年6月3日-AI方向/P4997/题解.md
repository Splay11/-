## 解题思路

本题需要在不断新增样本的过程中，实时回答当前所有样本拟合出的最小二乘直线在某个 $x_0$ 处的预测值。

对于当前样本集合 $(x_i,y_i)$，一元线性回归模型为：

$$
y=a*x+b
$$

最小二乘法需要最小化：

$$
\sum (y_i-(a*x_i+b))^2
$$

如果每次 `QUERY` 都重新遍历所有样本计算回归参数，最坏情况下时间复杂度会达到 $O(Q^2)$，无法通过本题数据范围。

观察最小二乘法公式：

$$
a=\frac{n*Sxy-Sx*Sy}{n*Sxx-Sx^2}
$$

$$
b=\frac{Sy-a*Sx}{n}
$$

其中只需要维护以下统计量：

$$
Sx=\sum x_i
$$

$$
Sy=\sum y_i
$$

$$
Sxx=\sum x_i^2
$$

$$
Sxy=\sum x_i*y_i
$$

因此每次 `ADD x y` 时，只需要更新：

$$
n=n+1
$$

$$
Sx=Sx+x
$$

$$
Sy=Sy+y
$$

$$
Sxx=Sxx+x^2
$$

$$
Sxy=Sxy+x*y
$$

每次 `QUERY x0` 时，根据当前统计量直接计算答案。

需要特别处理退化情况。

当 $n=0$ 时，没有任何样本，按照题意输出：

$$
0.000000
$$

当 $n \ge 1$ 且最优解不唯一时，等价于所有样本的 $x$ 都相同。此时公式中的分母：

$$
n*Sxx-Sx^2
$$

等于 $0$。

根据题目退化规则，使用常数模型：

$$
a=0
$$

$$
b=\frac{Sy}{n}
$$

所以预测值为：

$$
\hat y=\frac{Sy}{n}
$$

否则分母不为 $0$，最优解唯一，可以直接根据公式计算：

$$
a=\frac{n*Sxy-Sx*Sy}{n*Sxx-Sx^2}
$$

$$
b=\frac{Sy-a*Sx}{n}
$$

最终输出：

$$
\hat y=a*x_0+b
$$

实现时，$Sx, Sy, Sxx, Sxy$ 使用整数类型维护。题目保证中间统计量在 $64$ 位有符号整数范围内，因此 C++ 使用 `long long`，Java 使用 `long` 即可。计算预测值时需要转为浮点数。

## 复杂度分析

设操作总数为 $Q$。

每次 `ADD` 只更新常数个统计量，时间复杂度为 $O(1)$。

每次 `QUERY` 只根据统计量计算答案，时间复杂度为 $O(1)$。

因此总时间复杂度为：

$$
O(Q)
$$

只需要维护 $n, Sx, Sy, Sxx, Sxy$ 这几个变量，不需要保存所有历史样本，因此空间复杂度为：

$$
O(1)
$$

该复杂度可以满足 $Q \le 200000$ 的数据范围。

## 代码实现

### Python

```python
import sys
import numpy as np


def get_ans(n, sx, sy, sxx, sxy, x0):
    # 当前没有样本，按照题意返回 0
    if n == 0:
        return np.float64(0.0)

    # 最小二乘公式中的分母
    den = n * sxx - sx * sx

    # 分母为 0，说明所有样本的 x 都相同，使用常数模型
    if den == 0:
        return np.float64(sy) / np.float64(n)

    # 根据最小二乘公式计算斜率 a
    a = np.float64(n * sxy - sx * sy) / np.float64(den)

    # 根据斜率计算截距 b
    b = (np.float64(sy) - a * np.float64(sx)) / np.float64(n)

    # 返回 x0 处的预测值
    return a * np.float64(x0) + b


def main():
    data = sys.stdin.buffer.read().split()

    q = int(data[0])
    idx = 1

    # n 表示当前样本数量
    n = np.int64(0)

    # 维护最小二乘法所需的四个统计量
    sx = np.int64(0)
    sy = np.int64(0)
    sxx = np.int64(0)
    sxy = np.int64(0)

    ans = []

    for _ in range(q):
        op = data[idx]
        idx += 1

        if op == b"ADD":
            x = np.int64(int(data[idx]))
            y = np.int64(int(data[idx + 1]))
            idx += 2

            # 新增样本数量
            n += np.int64(1)

            # 在线更新统计量
            sx += x
            sy += y
            sxx += x * x
            sxy += x * y
        else:
            x0 = np.int64(int(data[idx]))
            idx += 1

            # 根据当前统计量计算预测值
            val = get_ans(n, sx, sy, sxx, sxy, x0)
            ans.append(f"{float(val):.6f}")

    sys.stdout.write("\n".join(ans))


if __name__ == "__main__":
    main()
```


### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {

    static double getAns(long n, long sx, long sy, long sxx, long sxy, long x0) {
        // 当前没有样本时，按照题意直接返回 0
        if (n == 0) {
            return 0.0;
        }

        // 计算最小二乘公式中的分母
        long den = n * sxx - sx * sx;

        // 分母为 0，说明所有 x 都相同，最优解不唯一
        if (den == 0) {
            return (double) sy / n;
        }

        // 计算斜率 a
        double a = (double) (n * sxy - sx * sy) / den;

        // 计算截距 b
        double b = ((double) sy - a * sx) / n;

        // 返回 x0 处的预测值
        return a * x0 + b;
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder out = new StringBuilder();

        int q = Integer.parseInt(br.readLine());

        // n 表示当前样本数量
        long n = 0;

        // 维护最小二乘法所需的四个统计量
        long sx = 0;
        long sy = 0;
        long sxx = 0;
        long sxy = 0;

        for (int i = 0; i < q; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            String op = st.nextToken();

            if (op.equals("ADD")) {
                long x = Long.parseLong(st.nextToken());
                long y = Long.parseLong(st.nextToken());

                // 新增一个样本
                n++;

                // 更新统计量
                sx += x;
                sy += y;
                sxx += x * x;
                sxy += x * y;
            } else {
                long x0 = Long.parseLong(st.nextToken());

                // 根据当前统计量计算预测值
                double val = getAns(n, sx, sy, sxx, sxy, x0);
                out.append(String.format("%.6f", val)).append('\n');
            }
        }

        System.out.print(out.toString());
    }
}
```
