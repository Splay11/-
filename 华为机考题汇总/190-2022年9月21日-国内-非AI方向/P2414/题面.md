# 题目内容

小明拿到了一个长度为$n$的数组，他有一种操作:将数组里的每个数和$x$ 取$min$($x$自己选定)。小明想知道，使得数组的总和不超过$tot$的情况下,$x$最大可以是多少？

如果数组的总和原本就已经小于等于$tot$了，直接输出-1.

# 输入描述
输入第一行包含两个整数$n，tot(1 \leq n,tot \leq 100000)$.

第二行包含n个整数，代表数组的每个元素$(1 \leq a_i \leq 100000)$。

# 输出描述
输出为一个整数，代表$x$最大可以取到多少，如果不需要进行操作则输出-1。

# 样例

## 样例一
**输入**

```
5 20
3 2 5 12 6
```

**输出**

```
5
```

## 样例二
**输入**

```
5 20
1 1 1 1 1
```

**输出**

```
-1
```
