## 解题思路

滑动窗口注意力与标准自注意力的区别在于：对于位置 $i$ 的 Query，只计算其附近窗口中的 Key，而不再与全部 $N$ 个 Key 计算注意力。

设序列长度为 $N$，窗口大小为 $w$，对于位置 $i$，实际参与计算的位置范围为：

$$
l=\max(0,i-w)
$$

$$
r=\min(N-1,i+w)
$$

因此位置 $i$ 只需要与 $[l,r]$ 中的 Key 计算注意力分数。

对于每个位置 $i$，按照以下步骤计算：

1. 计算缩放因子：

$$
scale=\sqrt{d_k}
$$

2. 对窗口中的每个位置 $j$ 计算注意力分数：

$$
score_j=\frac{Q_i\cdot K_j}{\sqrt{d_k}}
$$

其中点积为：

$$
Q_i\cdot K_j=\sum_{t=0}^{d_k-1}Q_{i,t}K_{j,t}
$$

3. 为保证 Softmax 的数值稳定性，先求当前窗口内的最大分数：

$$
m=\max_j(score_j)
$$

再计算：

$$
e_j=e^{score_j-m}
$$

以及：

$$
sum=\sum_j e_j
$$

最终注意力权重为：

$$
weight_j=\frac{e_j}{sum}
$$

4. 使用这些权重对窗口中的 Value 加权求和：

$$
O_i=\sum_{j=l}^{r}weight_jV_j
$$

由于窗口外的位置完全不参与计算，因此不需要构造完整的 $N\times N$ 注意力矩阵。

实现时，对每个 batch 独立处理。对于每个 Query 位置，只保存当前窗口中的注意力分数和 Softmax 中间结果，然后直接计算最终输出。

在开始计算前需要检查：

$$
batch_size\ge1
$$

$$
seq_len\ge1
$$

$$
d_k\ge1
$$

$$
1\le window_size\le seq_len
$$

如果任意约束不满足，直接输出 `0`。

## 复杂度分析

对于每个位置，窗口中最多包含：

$$
2w+1
$$

个位置，其中 $w=window_size$。

每一对 Query 和 Key 的点积需要 $O(d_k)$ 时间，对 Value 的加权求和同样需要 $O(d_k)$ 时间，因此单个位置的时间复杂度为：

$$
O(w\cdot d_k)
$$

一个 batch 的时间复杂度为：

$$
O(N\cdot w\cdot d_k)
$$

总时间复杂度为：

$$
O(batch_size\cdot seq_len\cdot window_size\cdot d_k)
$$

相比标准自注意力的：

$$
O(batch_size\cdot N^2\cdot d_k)
$$

当 $w\ll N$ 时可以显著降低计算量。

每组数据需要保存 $Q$、$K$、$V$ 和输出矩阵，占用：

$$
O(N\cdot d_k)
$$

当前窗口的注意力分数最多为 $2w+1$ 个，占用 $O(w)$ 空间。

因此单组数据的空间复杂度为：

$$
O(N\cdot d_k+w)
$$

通常 $w\le N$，因此可以写为：

$$
O(N\cdot d_k)
$$

## 代码实现


### Python

```python
import sys
import math


def attention(q, k, v, n, d, w):
    # 缩放因子 sqrt(d_k)
    scale = math.sqrt(d)

    # 保存当前 batch 的最终输出
    ans = [[0.0] * d for _ in range(n)]

    for i in range(n):
        # 当前 Query 能访问的左右边界
        left = max(0, i - w)
        right = min(n - 1, i + w)

        scores = []

        # 计算当前窗口内 Q[i] 与各个 K[j] 的注意力分数
        for j in range(left, right + 1):
            dot = 0.0
            for t in range(d):
                dot += q[i][t] * k[j][t]
            scores.append(dot / scale)

        # Softmax 前减去最大值，保证数值稳定性
        mx = max(scores)

        exps = []
        total = 0.0

        for score in scores:
            e = math.exp(score - mx)
            exps.append(e)
            total += e

        # 使用完整精度的 Softmax 权重对 Value 加权求和
        for idx in range(len(scores)):
            j = left + idx
            weight = exps[idx] / total

            for t in range(d):
                ans[i][t] += weight * v[j][t]

    return ans


def main():
    data = sys.stdin.buffer.read().split()

    if len(data) < 4:
        print(0)
        return

    b = int(data[0])
    n = int(data[1])
    d = int(data[2])
    w = int(data[3])

    # 检查题目规定的参数范围
    if b < 1 or n < 1 or d < 1 or w < 1 or w > n:
        print(0)
        return

    pos = 4
    all_ans = []

    for _ in range(b):
        q = [[0.0] * d for _ in range(n)]
        k = [[0.0] * d for _ in range(n)]
        v = [[0.0] * d for _ in range(n)]

        # 读取 Query 矩阵
        for i in range(n):
            for j in range(d):
                q[i][j] = float(data[pos])
                pos += 1

        # 读取 Key 矩阵
        for i in range(n):
            for j in range(d):
                k[i][j] = float(data[pos])
                pos += 1

        # 读取 Value 矩阵
        for i in range(n):
            for j in range(d):
                v[i][j] = float(data[pos])
                pos += 1

        all_ans.append(attention(q, k, v, n, d, w))

    # 最终结果保留 2 位小数
    for x in range(b):
        for row in all_ans[x]:
            vals = []

            for val in row:
                s = f"{val:.2f}"

                # 避免输出 -0.00
                if s == "-0.00":
                    s = "0.00"

                vals.append(s)

            print(" ".join(vals))

        if x != b - 1:
            print()


if __name__ == "__main__":
    main()
```

```java
import java.util.*;
import java.lang.Math;

public class Main {

    public static double[][] attention(double[][] q, double[][] k,
                                       double[][] v, int n, int d, int w) {
        // 缩放因子 sqrt(d_k)
        double scale = Math.sqrt(d);

        // 保存当前 batch 的最终输出
        double[][] ans = new double[n][d];

        for (int i = 0; i < n; i++) {
            // 当前 Query 能访问的左右边界
            int left = Math.max(0, i - w);
            int right = Math.min(n - 1, i + w);
            int len = right - left + 1;

            double[] scores = new double[len];

            // 计算当前窗口内 Q[i] 与各个 K[j] 的注意力分数
            for (int j = left; j <= right; j++) {
                double dot = 0.0;

                for (int t = 0; t < d; t++) {
                    dot += q[i][t] * k[j][t];
                }

                scores[j - left] = dot / scale;
            }

            // 找到当前窗口中的最大值，用于稳定计算 Softmax
            double mx = scores[0];

            for (int j = 1; j < len; j++) {
                mx = Math.max(mx, scores[j]);
            }

            double[] exps = new double[len];
            double total = 0.0;

            for (int j = 0; j < len; j++) {
                exps[j] = Math.exp(scores[j] - mx);
                total += exps[j];
            }

            // 使用完整精度的 Softmax 权重对 Value 加权求和
            for (int idx = 0; idx < len; idx++) {
                int j = left + idx;
                double weight = exps[idx] / total;

                for (int t = 0; t < d; t++) {
                    ans[i][t] += weight * v[j][t];
                }
            }
        }

        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int b = sc.nextInt();
        int n = sc.nextInt();
        int d = sc.nextInt();
        int w = sc.nextInt();

        // 检查题目规定的参数范围
        if (b < 1 || n < 1 || d < 1 || w < 1 || w > n) {
            System.out.println(0);
            sc.close();
            return;
        }

        for (int batch = 0; batch < b; batch++) {
            double[][] q = new double[n][d];
            double[][] k = new double[n][d];
            double[][] v = new double[n][d];

            // 读取 Query 矩阵
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < d; j++) {
                    q[i][j] = sc.nextDouble();
                }
            }

            // 读取 Key 矩阵
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < d; j++) {
                    k[i][j] = sc.nextDouble();
                }
            }

            // 读取 Value 矩阵
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < d; j++) {
                    v[i][j] = sc.nextDouble();
                }
            }

            double[][] ans = attention(q, k, v, n, d, w);

            // 最终结果保留 2 位小数
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < d; j++) {
                    if (j > 0) {
                        System.out.print(" ");
                    }

                    double val = ans[i][j];

                    // 避免输出 -0.00
                    if (val < 0 && val > -0.005) {
                        val = 0.0;
                    }

                    System.out.printf("%.2f", val);
                }
                System.out.println();
            }

            if (batch != b - 1) {
                System.out.println();
            }
        }

        sc.close();
    }
}
```
