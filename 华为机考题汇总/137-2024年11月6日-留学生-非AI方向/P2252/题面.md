# 题目内容

现在有$L$个黑球、白球从左到右依次排开，现在要求每一个黑球的左边不能有白球，为此可以对已有的L个球重新涂颜色(白涂黑或黑涂白)，至少需要涂几个球才能满足要求。

# 输入描述

输入只有一行，包含一个字符串$S$，且只包含'$B$'(代表黑球)或者'$W$'(代表白球)。

我们保证字符串$S$的长度$L$的范围是($0<L<10000$)。

# 输出描述

需要被重新涂颜色的球最少数量。

## 样例1 

**输入** 

```
BWBWB		
```

**输出** 

```
2
```







## 样例2

**输入** 

```
BBBWWW
```

**输出** 

```
0
```
