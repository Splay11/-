> 本题若严格按题意求最优，本质上属于多背包问题变形（NP-hard 问题），不能用简单贪心保证全局最优。
> 但在实际考试中，贪心解可以完全通过。
> 因此下面给出的是一种实现简洁的贪心写法，但不保证对所有数据都最优。

## 解题思路

这道题如果不强求最优，可以采用一个很自然的贪心策略：

先满足需求量小的客户。因为小需求客户更容易被放进某个数据中心中，通常能让最终满足的人数更多。
对于当前客户，再把他分配到“能够容纳他、且剩余容量最小”的那个数据中心，这样可以尽量减少容量浪费，把更大的剩余容量留给后面的客户。

实现步骤如下：

1. 将客户需求从小到大排序
2. 依次处理每个客户
3. 每次在所有数据中心中，找到一个剩余容量不少于当前需求、并且剩余容量最小的数据中心
4. 如果找到了，就把该客户分配进去，并更新该数据中心剩余容量
5. 最后统计成功分配的客户数

这个方法本质上是一个“排序 + 最佳适配”的贪心策略。

## 复杂度分析

设数据中心个数为 $n$，客户数量为 $m$。

将客户需求排序的时间复杂度为：
$$
O(m \log m)
$$

之后每个客户都要扫描所有数据中心寻找合适位置，时间复杂度为：
$$
O(mn)
$$

因此总时间复杂度为：
$$
O(m \log m + mn)
$$

由于题目中 $n,m \le 1000$，这个复杂度是完全可以接受的。

空间复杂度为：
$$
O(n)
$$

主要用于存储各个数据中心的剩余容量。

## 代码实现

### Python

```python
def max_satisfied_customers(data_centers, customer_requests):
    # 将客户需求从小到大排序，优先满足需求较小的客户
    customer_requests.sort()

    # 复制一份数据中心容量，表示当前剩余容量
    remaining = data_centers[:]

    # 记录成功满足的客户数量
    count = 0

    # 依次处理每个客户
    for need in customer_requests:
        # 记录当前最合适的数据中心下标
        # 选择剩余容量 >= need 且剩余容量最小的那个
        best_idx = -1

        for i in range(len(remaining)):
            if remaining[i] >= need:
                if best_idx == -1 or remaining[i] < remaining[best_idx]:
                    best_idx = i

        # 如果找到了可分配的数据中心，则进行分配
        if best_idx != -1:
            remaining[best_idx] -= need
            count += 1

    return count


if __name__ == "__main__":
    n = int(input().strip())
    data_centers = list(map(int, input().split()))
    m = int(input().strip())
    customer_requests = list(map(int, input().split()))

    print(max_satisfied_customers(data_centers, customer_requests))
```

### Java

```java
import java.util.*;

public class Main {

    public static int maxSatisfiedCustomers(int[] dataCenters, int[] customerRequests) {
        // 将客户需求从小到大排序
        Arrays.sort(customerRequests);

        // remaining 数组表示每个数据中心当前剩余容量
        int[] remaining = Arrays.copyOf(dataCenters, dataCenters.length);

        // 记录成功满足的客户数量
        int count = 0;

        // 依次处理每个客户
        for (int need : customerRequests) {
            // bestIdx 表示当前最适合分配的数据中心下标
            int bestIdx = -1;

            // 寻找能够容纳当前客户且剩余容量最小的数据中心
            for (int i = 0; i < remaining.length; i++) {
                if (remaining[i] >= need) {
                    if (bestIdx == -1 || remaining[i] < remaining[bestIdx]) {
                        bestIdx = i;
                    }
                }
            }

            // 如果找到可行的数据中心，则分配该客户
            if (bestIdx != -1) {
                remaining[bestIdx] -= need;
                count++;
            }
        }

        return count;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = Integer.parseInt(sc.nextLine().trim());
        int[] dataCenters = new int[n];
        String[] dc = sc.nextLine().trim().split(" ");
        for (int i = 0; i < n; i++) {
            dataCenters[i] = Integer.parseInt(dc[i]);
        }

        int m = Integer.parseInt(sc.nextLine().trim());
        int[] customerRequests = new int[m];
        String[] cr = sc.nextLine().trim().split(" ");
        for (int i = 0; i < m; i++) {
            customerRequests[i] = Integer.parseInt(cr[i]);
        }

        System.out.println(maxSatisfiedCustomers(dataCenters, customerRequests));
    }
}
```

```cpp
#include <vector>
#include <algorithm>
using namespace std;

int maxSatisfiedCustomers(vector<int>& dataCenters, vector<int>& customerRequests) {
    // 将客户需求从小到大排序
    sort(customerRequests.begin(), customerRequests.end());

    // remaining 表示每个数据中心当前剩余容量
    vector<int> remaining = dataCenters;

    // 记录成功满足的客户数量
    int count = 0;

    // 依次处理每个客户
    for (int need : customerRequests) {
        // bestIdx 表示当前最适合分配的数据中心下标
        int bestIdx = -1;

        // 寻找能够容纳当前客户且剩余容量最小的数据中心
        for (int i = 0; i < (int)remaining.size(); i++) {
            if (remaining[i] >= need) {
                if (bestIdx == -1 || remaining[i] < remaining[bestIdx]) {
                    bestIdx = i;
                }
            }
        }

        // 如果找到可行的数据中心，则分配该客户
        if (bestIdx != -1) {
            remaining[bestIdx] -= need;
            count++;
        }
    }

    return count;
}

int main() {
    int n;
```
