## 解题思路

使用 $KMP$ 算法中的前缀函数。

设字符串长度为 $n$，前缀函数最后一个值为 $\pi[n-1]$，表示整个字符串最长的相同前后缀长度。

那么最短循环节长度可能为：

$len = n - \pi[n-1]$

如果满足：

$n \bmod len = 0$

并且 $len < n$，说明字符串可以由长度为 $len$ 的子串重复多次组成。

此时输出：

$最短重复段 + 重复次数$

否则输出原字符串 $s$。

## 复杂度分析

时间复杂度为 $O(n)$，因为 $KMP$ 前缀函数只需要线性扫描一次字符串。

空间复杂度为 $O(n)$，需要一个数组保存前缀函数。

该复杂度可以满足 $n \le 10^6$ 的数据范围。

## 代码实现

### Python

```python
import sys


def get_answer(s):
    n = len(s)
    pi = [0] * n

    # 计算 KMP 前缀函数
    for i in range(1, n):
        j = pi[i - 1]

        # 失配时不断回退
        while j > 0 and s[i] != s[j]:
            j = pi[j - 1]

        # 匹配成功，前缀长度加一
        if s[i] == s[j]:
            j += 1

        pi[i] = j

    # 最短循环节长度
    length = n - pi[n - 1]

    # 判断是否能由更短字符串重复构成
    if length < n and n % length == 0:
        return s[:length] + str(n // length)

    return s


def main():
    s = sys.stdin.readline().strip()
    print(get_answer(s))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;

public class Main {

    public static String getAnswer(String s) {
        int n = s.length();
        int[] pi = new int[n];

        // 计算 KMP 前缀函数
        for (int i = 1; i < n; i++) {
            int j = pi[i - 1];

            // 失配时不断回退
            while (j > 0 && s.charAt(i) != s.charAt(j)) {
                j = pi[j - 1];
            }

            // 匹配成功，前缀长度加一
            if (s.charAt(i) == s.charAt(j)) {
                j++;
            }

            pi[i] = j;
        }

        // 最短循环节长度
        int len = n - pi[n - 1];

        // 判断是否能由更短字符串重复构成
        if (len < n && n % len == 0) {
            return s.substring(0, len) + (n / len);
        }

        return s;
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String s = br.readLine();
        System.out.print(getAnswer(s));
    }
}
```
