# 题目内容
在一款游戏中，玩家需要依次释放三种颜色的能量球：红色（`r`）、绿色（`g`）、蓝色（`b`）。每个能量球的基础能量值分别为：红色 `1` 点，绿色 `2` 点，蓝色 `3` 点。释放时若与之前连续释放的相同颜色的能量球产生共鸣，还会获得额外的共鸣奖励。具体而言，对于序列中的第 $i$ 个能量球（$i$ 从 $1$ 开始），如果它与紧邻的前一个球颜色相同，则奖励 `1` 点；如果与前两个球颜色都相同，则再奖励 `1` 点，依此类推。换言之，设第 $i$ 个球之前有 $k$ 个连续相同颜色的球，则它额外获得 $k$ 点奖励。总能量为所有能量球的基础能量与共鸣奖励之和。请计算给定能量球序列的总能量。

约束条件：字符串的长度 $n$ 满足 $1 \le n \le 10000$。

# 输入描述
输入包含一行，一个仅由字符 `r`、`g`、`b` 组成的字符串，长度 $n$ 满足 $1 \le n \le 10000$。

# 输出描述
输出一个整数，表示最终计算得到的总能量。

## 样例1

**输入**

```
rgr
```

**输出**

```
4
```

**说明**

技能序列为 `r`（火，基础 `1` 点）、`g`（水，基础 `2` 点）、`r`（火，基础 `1` 点）。

该序列中没有连续相同的技能，因此无法触发共鸣奖励。总能量仅为基础能量之和：$1 + 2 + 1 = 4$。

## 样例2

**输入**

```
rrr
```

**输出**

```
6
```

**说明**

技能序列由三个 `r`（火）组成，基础能量均为 `1` 点。

- 第 `1` 个 `r` 前无相同技能，只得基础分 `1`。
- 第 `2` 个 `r` 前有 `1` 个连续相同的 `r`，共鸣奖励 `1`，加上基础分共得 `2`。
- 第 `3` 个 `r` 前有 `2` 个连续相同的 `r`，共鸣奖励 `2`，加上基础分共得 `3`。

总能量为 $1 + 2 + 3 = 6$。

## 样例3

**输入**

```
rggb
```

**输出**

```
9
```

**说明**

技能序列为 `r`（火）、`g`（水）、`g`（水）、`b`（土）。

- `r`：基础 `1`，无奖励。
- 第一个 `g`：基础 `2`，前一个为 `r`，无奖励。
- 第二个 `g`：基础 `2`，前有 `1` 个连续相同的 `g`，奖励 `1`，合计 `3`。
- `b`：基础 `3`，前一个为 `g`，无奖励。

总能量为 $1 + 2 + 3 + 3 = 9$。

## 样例4

**输入**

```
b
```

**输出**

```
3
```

**说明**

序列中只有一个技能 `b`（土），基础能量为 `3` 点。没有前面的技能，无法触发共鸣奖励。总能量为 `3`。
