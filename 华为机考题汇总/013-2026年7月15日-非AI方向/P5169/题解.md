## 解题思路

由于只能向源字符串 $S$ 中插入字符，不能删除或修改原有字符，因此应尽可能利用 $S$ 中已经存在的字符来匹配目标字符串 $T$。

能够直接利用的字符必须同时满足：

* 在 $T$ 中的相对顺序不变。
* 在 $S$ 中的相对顺序不变。

因此，能够利用的最大字符数量就是 $T$ 和 $S$ 的最长公共子序列长度，即 $LCS$。

设最长公共子序列长度为 $L$，目标字符串长度为 $|T|$，那么剩余未匹配的字符都需要插入，答案为：

$$
|T|-L
$$

使用动态规划计算最长公共子序列，并用一维数组优化空间。

状态定义：

$$
dp[j]
$$

表示当前处理到 $T$ 的某个位置时，与 $S$ 的前 $j$ 个字符的最长公共子序列长度。

状态转移：

* 如果当前两个字符相同，则：

$$
dp[j]=leftTop+1
$$

* 如果当前两个字符不同，则：

$$
dp[j]=\max(dp[j],dp[j-1])
$$

其中 $leftTop$ 保存更新前的左上角状态。

## 复杂度分析

设目标字符串 $T$ 的长度为 $n$，源字符串 $S$ 的长度为 $m$。

时间复杂度：

$$
O(nm)
$$

空间复杂度：

$$
O(m)
$$

在 $n,m\le 2500$ 的数据范围内可以通过。

## 代码实现

### Python

```python
def min_insertions(t, s):
    m = len(s)
    dp = [0] * (m + 1)

    # 计算 T 和 S 的最长公共子序列
    for i in range(1, len(t) + 1):
        left_top = 0

        for j in range(1, m + 1):
            old = dp[j]

            if t[i - 1] == s[j - 1]:
                # 当前字符相同，接在左上角状态后面
                dp[j] = left_top + 1
            else:
                # 当前字符不同，取上方和左方的较大值
                dp[j] = max(dp[j], dp[j - 1])

            left_top = old

    # 未匹配的目标字符都需要插入
    return len(t) - dp[m]


def main():
    t = input().strip()
    s = input().strip()

    print(min_insertions(t, s))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;

public class Main {

    static int minInsertions(String t, String s) {
        int m = s.length();
        int[] dp = new int[m + 1];

        // 计算 T 和 S 的最长公共子序列
        for (int i = 1; i <= t.length(); i++) {
            int leftTop = 0;

            for (int j = 1; j <= m; j++) {
                int old = dp[j];

                if (t.charAt(i - 1) == s.charAt(j - 1)) {
                    // 当前字符相同，接在左上角状态后面
                    dp[j] = leftTop + 1;
                } else {
                    // 当前字符不同，取上方和左方的较大值
                    dp[j] = Math.max(dp[j], dp[j - 1]);
                }

                leftTop = old;
            }
        }

        // 未匹配的目标字符都需要插入
        return t.length() - dp[m];
    }

    public static void main(String[] args) throws Exception {
        BufferedReader reader =
                new BufferedReader(new InputStreamReader(System.in));

        String t = reader.readLine();
        String s = reader.readLine();

        System.out.println(minInsertions(t, s));
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

int minInsertions(const string& t, const string& s) {
    int m = s.size();
    vector<int> dp(m + 1, 0);

    // 计算 T 和 S 的最长公共子序列
    for (int i = 1; i <= (int)t.size(); i++) {
        int leftTop = 0;

        for (int j = 1; j <= m; j++) {
            int old = dp[j];

            if (t[i - 1] == s[j - 1]) {
                // 当前字符相同，接在左上角状态后面
                dp[j] = leftTop + 1;
            } else {
                // 当前字符不同，取上方和左方的较大值
                dp[j] = max(dp[j], dp[j - 1]);
            }

            leftTop = old;
        }
    }

    // 未匹配的目标字符都需要插入
    return t.size() - dp[m];
}

int main() {
    string t, s;
    cin >> t >> s;

    cout << minInsertions(t, s) << '\n';

    return 0;
}
```
