# 题目内容

某个幼儿园有未知个小朋友，部分小朋友我出跟自己衣服一样颜色的小朋友个数,将数据汇总到一个整数数组$colors$，其中$colors[i]$是第$i$个小朋友看到的个数，不包括小朋友自己。现在给你一个数组$colors$，请计算幼儿园中小朋友最少有几个。

# 输入描述

以空格隔开的数组$colors，colors[i] = j, 1<=i<=1000000; 1<=j<=100000$

# 输出描述

一个整数，小朋友最少有几个

## 样例1 

**输入** 

```
1 1 2
```

**输出** 

```
5
```

**说明**

 $1$、第一个小朋友看到同色$1$个人，第二个小朋友看到同色$1$个人，第三个小朋友看到同色$2$个。幼儿园至少有$5$个小朋友。

$2$、算法步骤: 第一个小朋友和第二个小朋友他他们看到的同色都是$1$个，最少是他们互相看见，这样就有$2$个小朋友;第三个小朋友看到同色$2$个，最少$3$是$3$个小朋友;$2$个加上$3$个就是$5$个
