# DFS暴力解法

这个解法用 DFS 按顺序枚举每只怪兽“跳过”或“能打就打”两种选择，递归维护当前下标 `i`、当前能量 `energy` 和已击败数量 `cnt`，当处理完所有怪兽时更新最大答案；在枚举过程中加一个很弱的剪枝：如果当前怪兽能打，并且 `reward[i] >= damage[i]`，说明打完后能量不会减少，同时击败数还能加一，所以这种情况下“打”一定不比“跳过”差，可以直接打而不枚举跳过分支。
## DFS解法

```python
def max_defeat(E, damage, reward):
    n = len(damage)
    ans = 0

    def dfs(i, energy, cnt):
        nonlocal ans

        if i == n:
            ans = max(ans, cnt)
            return

        if energy > damage[i] and reward[i] >= damage[i]:
            dfs(i + 1, energy - damage[i] + reward[i], cnt + 1)
            return

        dfs(i + 1, energy, cnt)

        if energy > damage[i]:
            dfs(i + 1, energy - damage[i] + reward[i], cnt + 1)

    dfs(0, E, 0)
    return ans
```

# 正确解法

## 题目分析

这是一个典型的动态规划问题。

由于怪兽必须按顺序处理，每只怪兽只有两种选择：

1. 跳过当前怪兽；
2. 如果当前能量值满足 $E > damage[i]$，则可以击败它，能量变为 $E - damage[i] + reward[i]$。

题目的目标是最大化击败怪兽的数量，而不是最大化剩余能量。因此可以设计如下状态：

设 $dp[j]$ 表示：

处理到当前怪兽位置时，恰好击败了 $j$ 个怪兽后，能够剩下的最大能量值。

为什么这样设计可行？

因为对于“已经击败了同样数量的怪兽”这一类状态来说，剩余能量越大一定越优。
若两个方案都击败了 $j$ 个怪兽，其中一个剩余能量更大，那么它之后的选择只会更多，不会更差。
所以每个 $j$ 只需要保留“最大剩余能量”即可。

状态转移：

对于第 $i$ 个怪兽：

* 跳过：$dp[j]$ 不变；
* 击败：如果 $dp[j] > damage[i]$，那么可以转移到

$$
dp[j+1] = \max(dp[j+1],\ dp[j] - damage[i] + reward[i])
$$

为了避免一只怪兽被重复使用，$j$ 必须从大到小枚举。

初始状态：

$$
dp[0] = E
$$

其余状态设为不可达。

最后答案就是最大的 $j$，满足 $dp[j]$ 可达。

相关算法：动态规划。

## 复杂度分析

怪兽数量为 $n$，其中 $1 \le n \le 100$。

动态规划一共有 $n$ 轮，每轮最多枚举 $n$ 个击败数量状态，因此：

* 时间复杂度：$O(n^2)$
* 空间复杂度：$O(n)$

这个复杂度对于题目数据范围是完全可行的。

### Python

```python
def max_defeat(E, damage, reward):
    n = len(damage)
    NEG = -1
    # dp[j] 表示击败 j 个怪兽后，最多剩余多少能量
    dp = [NEG] * (n + 1)
    dp[0] = E

    for i in range(n):
        # 倒序枚举，避免同一只怪兽被重复计算
        for j in range(i, -1, -1):
            # 当前状态可达，且能量足以击败当前怪兽
            if dp[j] != NEG and dp[j] > damage[i]:
                dp[j + 1] = max(dp[j + 1], dp[j] - damage[i] + reward[i])

    # 从大到小找最大可达的击败数量
    for j in range(n, -1, -1):
        if dp[j] != NEG:
            return j
    return 0
```

```java
import java.util.*;

public class Main {

    // 计算最多能击败多少个怪兽
    public static int maxDefeat(long E, long[] damage, long[] reward) {
        int n = damage.length;
        long[] dp = new long[n + 1];

        // -1 表示该状态不可达
        Arrays.fill(dp, -1);
        dp[0] = E;

        for (int i = 0; i < n; i++) {
            // 倒序枚举，避免同一只怪兽被重复使用
            for (int j = i; j >= 0; j--) {
                // 当前状态可达，且能量足以击败当前怪兽
                if (dp[j] != -1 && dp[j] > damage[i]) {
                    dp[j + 1] = Math.max(dp[j + 1], dp[j] - damage[i] + reward[i]);
                }
            }
        }

        // 从大到小寻找最大可达击败数量
        for (int j = n; j >= 0; j--) {
            if (dp[j] != -1) {
                return j;
            }
        }
        return 0;
    }
```
