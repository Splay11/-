## 解题思路

本题可以使用直接模拟的方法实现二维空洞卷积。普通卷积核中相邻元素对应输入矩阵中的相邻位置，而空洞卷积中相邻卷积核元素之间需要间隔 $d-1$ 个位置，因此卷积核的有效尺寸为：

$$
K_{eff}=K+(K-1)(d-1)
$$

其中 $K$ 是卷积核边长，$d$ 是膨胀率。

根据卷积输出尺寸公式，输出矩阵的高和宽分别为：

$$
H_{out}=\left\lfloor \frac{H+2p-K_{eff}}{s} \right\rfloor+1
$$

$$
W_{out}=\left\lfloor \frac{W+2p-K_{eff}}{s} \right\rfloor+1
$$

其中 $s$ 是步长，$p$ 是填充大小。

实现时不需要真的构造 padding 后的矩阵。对于输出矩阵中的每个位置 $(i,j)$，先计算当前卷积窗口左上角在原始输入矩阵中的位置：

$$
x_0=i \times s-p
$$

$$
y_0=j \times s-p
$$

然后遍历卷积核中的每个位置 $(u,v)$，它对应原始输入矩阵中的坐标为：

$$
x=x_0+u \times d
$$

$$
y=y_0+v \times d
$$

如果 $(x,y)$ 在原始输入矩阵范围内，就累加输入值和卷积核值的乘积；如果越界，说明该位置属于 padding 区域，按 $0$ 处理，不参与累加。

题目中的卷积核不需要翻转，按照输入顺序直接相乘累加即可。

## 复杂度分析

设输入矩阵大小为 $H \times W$，卷积核大小为 $K \times K$，输出矩阵大小为 $H_{out} \times W_{out}$。

对于输出矩阵中的每一个位置，都需要遍历整个卷积核，因此时间复杂度为：

$$
O(H_{out} \times W_{out} \times K^2)
$$

算法需要保存输出矩阵，因此空间复杂度为：

$$
O(H_{out} \times W_{out})
$$

如果不计算输入矩阵和卷积核本身，只看额外辅助变量，则额外空间复杂度为 $O(1)$。

## 代码实现

### Python

```python
import sys
import numpy as np


def cal(a, b, s, p, d):
    n, m = a.shape
    k = b.shape[0]

    # 计算空洞卷积核的有效尺寸
    e = k + (k - 1) * (d - 1)

    # 根据卷积公式计算输出矩阵大小
    oh = (n + 2 * p - e) // s + 1
    ow = (m + 2 * p - e) // s + 1

    # 对输入矩阵四周补 0
    pa = np.pad(a, ((p, p), (p, p)), mode="constant", constant_values=0)

    ans = np.zeros((oh, ow), dtype=np.int64)

    # 枚举输出矩阵中的每一个位置
    for i in range(oh):
        for j in range(ow):
            # 当前窗口左上角在补零矩阵中的坐标
            x = i * s
            y = j * s

            # 按 dilation 从窗口中取出对应位置
            win = pa[x:x + e:d, y:y + e:d]

            # 卷积核不翻转，直接对应位置相乘求和
            ans[i, j] = np.sum(win * b)

    return ans


def main():
    nums = list(map(int, sys.stdin.read().split()))
    idx = 0

    n = nums[idx]
    m = nums[idx + 1]
    idx += 2

    a = np.array(nums[idx:idx + n * m], dtype=np.int64).reshape(n, m)
    idx += n * m

    k = nums[idx]
    idx += 1

    b = np.array(nums[idx:idx + k * k], dtype=np.int64).reshape(k, k)
    idx += k * k

    s = nums[idx]
    p = nums[idx + 1]
    d = nums[idx + 2]

    ans = cal(a, b, s, p, d)

    for row in ans:
        print(" ".join(map(str, row)))


if __name__ == "__main__":
    main()

```

### Java

```java
import java.util.Scanner;

public class Main {

    public static long[][] cal(long[][] a, long[][] b, int s, int p, int d) {
        int n = a.length;
        int m = a[0].length;
        int k = b.length;

        // 计算空洞卷积核的有效尺寸
        int e = k + (k - 1) * (d - 1);

        // 根据卷积公式计算输出矩阵大小
        int oh = (n + 2 * p - e) / s + 1;
        int ow = (m + 2 * p - e) / s + 1;

        long[][] ans = new long[oh][ow];

        // 枚举输出矩阵中的每一个位置
        for (int i = 0; i < oh; i++) {
            for (int j = 0; j < ow; j++) {
                long res = 0;

                // 计算当前窗口左上角对应到原始矩阵中的坐标
                int x0 = i * s - p;
                int y0 = j * s - p;

                // 枚举卷积核中的每一个元素
                for (int u = 0; u < k; u++) {
                    for (int v = 0; v < k; v++) {
                        // 根据 dilation 映射到原始输入矩阵中的位置
                        int x = x0 + u * d;
                        int y = y0 + v * d;

                        // 越界位置属于 padding 区域，值为 0
                        if (x >= 0 && x < n && y >= 0 && y < m) {
                            res += a[x][y] * b[u][v];
                        }
                    }
                }

                ans[i][j] = res;
            }
        }

        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int m = sc.nextInt();

        long[][] a = new long[n][m];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                a[i][j] = sc.nextLong();
            }
        }

        int k = sc.nextInt();

        long[][] b = new long[k][k];
        for (int i = 0; i < k; i++) {
            for (int j = 0; j < k; j++) {
                b[i][j] = sc.nextLong();
            }
        }

        int s = sc.nextInt();
        int p = sc.nextInt();
        int d = sc.nextInt();

        long[][] ans = cal(a, b, s, p, d);

        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < ans.length; i++) {
            for (int j = 0; j < ans[0].length; j++) {
                if (j > 0) {
                    sb.append(' ');
                }
                sb.append(ans[i][j]);
            }
            if (i + 1 < ans.length) {
                sb.append('\n');
            }
        }

        System.out.print(sb.toString());
        sc.close();
    }
}
```
