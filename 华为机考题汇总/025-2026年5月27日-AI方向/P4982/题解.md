## 解题思路

本题要求把 $N$ 层网络划分成 $K$ 段连续区间，每段分给一个 NPU。

每个区间需要同时满足：

1. 显存和不超过 $M$
2. 阶段耗时为该区间计算耗时之和
3. 最小化所有区间阶段耗时的最大值

这是典型的“连续分段 + 最小化最大值”问题，可以使用二分答案。

设答案为 $x$，表示每个 NPU 的计算耗时上限不能超过 $x$。

我们判断是否可以在以下两个限制下，把所有层划分成不超过 $K$ 段：

* 每段计算耗时和 $\le x$
* 每段显存需求和 $\le M$

判断方法使用贪心：

从左到右扫描网络层，尽量把当前层放入当前 NPU。如果加入后计算耗时或显存超过限制，就新开一个 NPU。

由于每段必须连续，且每段越长越有利于减少 NPU 数量，所以这种贪心可以得到在当前限制 $x$ 下所需的最少 NPU 数量。

如果最少需要的 NPU 数量 $\le K$，并且 $K \le N$，则可以进一步把某些非空段拆开，使 NPU 数量恰好变为 $K$。

需要先判断无解情况：

* 如果 $K > N$，每个 NPU 至少一层，必然无解
* 如果存在某层显存 $W_i > M$，该层无法放入任何 NPU，必然无解

二分范围：

* 左边界为 $\max C_i$
* 右边界为 $\sum C_i$

## 复杂度分析

设网络层数为 $N$，计算耗时总和为 $S=\sum C_i$。

每次判断需要扫描一次数组，时间复杂度为 $O(N)$。

二分答案次数为 $O(\log S)$。

因此总时间复杂度为：

$$
O(N \log S)
$$

只使用了常数个额外变量，空间复杂度为：

$$
O(1)
$$


## 代码实现

### Python

```python
import sys

def can_split(n, k, m, c, w, limit):
    # cnt 表示当前已经使用的 NPU 数量
    cnt = 1
    cs = 0
    ws = 0

    for i in range(n):
        # 单层计算耗时或显存超过限制时，当前 limit 不可行
        if c[i] > limit or w[i] > m:
            return False

        # 如果当前层可以加入当前 NPU，就继续累加
        if cs + c[i] <= limit and ws + w[i] <= m:
            cs += c[i]
            ws += w[i]
        else:
            # 否则新开一个 NPU，并从当前层开始
            cnt += 1
            cs = c[i]
            ws = w[i]

    # 最少使用的 NPU 数量不超过 k，则可以通过拆分达到恰好 k 个
    return cnt <= k

def solve(n, k, m, c, w):
    # NPU 数量多于层数时，每个 NPU 至少一层，必然无解
    if k > n:
        return -1

    # 任意一层显存超过单卡上限，必然无解
    for x in w:
        if x > m:
            return -1

    left = max(c)
    right = sum(c)
    ans = -1

    # 二分最小可行的最大阶段耗时
    while left <= right:
        mid = (left + right) // 2

        if can_split(n, k, m, c, w, mid):
            ans = mid
            right = mid - 1
        else:
            left = mid + 1

    return ans

def main():
    n, k, m = map(int, sys.stdin.readline().split())
    c = list(map(int, sys.stdin.readline().split()))
    w = list(map(int, sys.stdin.readline().split()))

    print(solve(n, k, m, c, w))

if __name__ == "__main__":
    main()
```

                cnt++;
                cs = c[i];

            }

    }

    static long solve(int n, int k, long m, long[] c, long[] w) {
        // NPU 数量多于层数时，每个 NPU 至少一层，必然无解
        if (k > n) {
            return -1;
        }

        // 任意一层显存超过单卡上限，必然无解
        for (int i = 0; i < n; i++) {
            if (w[i] > m) {
                return -1;
            }

        long left = 0;
        long right = 0;

        for (int i = 0; i < n; i++) {
            left = Math.max(left, c[i]);
            right += c[i];
        }

        long ans = -1;

        // 二分最小可行的最大阶段耗时
        while (left <= right) {
            long mid = left + (right - left) / 2;

            if (canSplit(n, k, m, c, w, mid)) {
                ans = mid;
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }

        return ans;
    }

        Scanner sc = new Scanner(System.in);

        long m = sc.nextLong();

        long[] c = new long[n];
        long[] w = new long[n];
