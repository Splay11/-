## 本题递归解法 Python

```python
m = int(input())
n = int(input())
weight = list(map(int, input().split()))
value_1 = list(map(int, input().split()))
value_2 = list(map(int, input().split()))
value = [min(value_1[i], value_2[i]) for i in range(n)]

# step : 选到第几个物品
# now_weight : 已经选了的物品的空间大小
# now_value : 已经选了的物品的总价值
ans = -1
def dfs(step , now_weight , now_value): 
    # 当已经考虑完所有物品时，判断是否满足条件
    if step == n:
        global ans
        if now_weight >= m:
            if ans == -1:
                ans = now_value
            else:
                ans = min(ans, now_value)
        return
    dfs(step + 1, now_weight, now_value) # 不选当前物品
    dfs(step + 1, now_weight + weight[step], now_value + value[step]) # 选当前物品

dfs(0, 0, 0)
print(ans if ans != -1 else "error")
```

> 考虑所有可能的解法，本质上是一个$2^n$种情况。等于说从$n$个物品中，DFS搜索出所有可能的子集选择情况，对于每个情况都判断一下。递归解法见文章末尾

## 解题思路

对于每个张量，都有两种释放方式：$swap$ 或者 重计算。
但无论选哪一种，这个张量都只能贡献一次可释放空间，大小都是对应的张量大小。

所以对第 $i$ 个张量而言：

* 可释放空间为 $a_i$
* 释放代价为 $\min(b_i, c_i)$

这样题目就转化成了一个经典的 $0/1$ 背包问题：

* 有 $n$ 个物品
* 第 $i$ 个物品的“体积”为 $a_i$
* 第 $i$ 个物品的“代价”为 $\min(b_i, c_i)$
* 目标是在总释放空间不少于 $m$ 的前提下，使总代价最小

### 核心做法

设 $dp[j]$ 表示“恰好或累计考虑后，释放空间达到 $j$ 时的最小代价”。

由于我们只关心是否达到 $m$，所以状态可以压成：

* $j$ 的范围为 $[0, m]$
* 如果某次转移后空间超过了 $m$，就直接记到 $m$

转移方式为：

$$
dp[\min(m, j + a_i)] = \min(dp[\min(m, j + a_i)],\ dp[j] + \min(b_i, c_i))
$$

这里使用的是 $0/1$ 背包的倒序枚举，保证每个张量只被使用一次。

### 实现方法

1. 读入 $m$
2. 读入 $n$
3. 读入数组 $a$
4. 读入数组 $b$
5. 读入数组 $c$
6. 对每个张量先算出最小释放代价 $w_i=\min(b_i,c_i)$
7. 用一维 $dp$ 做 $0/1$ 背包
8. 若最终 $dp[m]$ 仍不可达，输出 `error`，否则输出最小代价

## 复杂度分析

共有 $n$ 个张量，背包容量为 $m$。

* 时间复杂度：$O(nm)$
* 空间复杂度：$O(m)$

在题目给定的数据范围下，这个复杂度是合适的。

## 代码实现

### Python

```python
import sys


def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return

    it = iter(data)
    m = int(next(it))
    n = int(next(it))

    a = [int(next(it)) for _ in range(n)]
    b = [int(next(it)) for _ in range(n)]
    c = [int(next(it)) for _ in range(n)]

    # 每个张量只需要付出 swap / 重计算中的较小代价
    w = [min(b[i], c[i]) for i in range(n)]

    # 如果所有张量空间总和都不够，直接无解
    if sum(a) < m:
        print("error")
        return

    INF = 10**18
    dp = [INF] * (m + 1)
    dp[0] = 0

    # 0/1 背包：倒序枚举，保证每个张量只使用一次
    for i in range(n):
        space = a[i]
        cost = w[i]

        for j in range(m, -1, -1):
            if dp[j] == INF:
                continue
            nj = min(m, j + space)
            new_cost = dp[j] + cost
            if new_cost < dp[nj]:
                dp[nj] = new_cost

    if dp[m] == INF:
        print("error")
    else:
        print(int(dp[m]))


if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.*;

public class Main {
    public static Object solve(int m, int n, int[] sizes, int[] swapCost, int[] recomputeCost) {
        // 计算每个张量的最小释放代价
        int[] costs = new int[n];
        for (int i = 0; i < n; i++) {
            costs[i] = Math.min(swapCost[i], recomputeCost[i]);
        }

        long INF = (long) 1e18;
        // dp[j] 表示释放空间达到 j 时的最小代价
        long[] dp = new long[m + 1];
        Arrays.fill(dp, INF);
        dp[0] = 0;

        // 0/1 背包
        for (int i = 0; i < n; i++) {
            int size = sizes[i];
            int cost = costs[i];
            // 倒序枚举，保证每个张量只使用一次
            for (int j = m; j >= 0; j--) {
                if (dp[j] == INF) {
                    continue;
                }
                int nj = Math.min(m, j + size); // 超过 m 直接记为 m
                dp[nj] = Math.min(dp[nj], dp[j] + cost);
            }
        }

        if (dp[m] == INF) {
            return "error";
        }
        return dp[m];
    }

    public static void main(String[] args) {
       
        Scanner sc = new Scanner(System.in);

        int m = sc.nextInt();
        int n = sc.nextInt();

        int[] sizes = new int[n];
        int[] swapCost = new int[n];
        int[] recomputeCost = new int[n];

        for (int i = 0; i < n; i++) {
            sizes[i] = sc.nextInt();
        }
        for (int i = 0; i < n; i++) {
            swapCost[i] = sc.nextInt();
        }
        for (int i = 0; i < n; i++) {
            recomputeCost[i] = sc.nextInt();
        }

        Object ans = solve(m, n, sizes, swapCost, recomputeCost);
        System.out.println(ans);

        sc.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

string ERROR_STR = "error";

long long solve(int m, int n, vector<int>& sizes, vector<int>& swapCost, vector<int>& recomputeCost, bool& ok) {
    // 计算每个张量的最小释放代价
    vector<int> costs(n);
    for (int i = 0; i < n; i++) {
        costs[i] = min(swapCost[i], recomputeCost[i]);
    }

    const long long INF = (long long)4e18;
    // dp[j] 表示释放空间达到 j 时的最小代价
    vector<long long> dp(m + 1, INF);
    dp[0] = 0;

    // 0/1 背包
    for (int i = 0; i < n; i++) {
        int size = sizes[i];
        int cost = costs[i];
        // 倒序枚举，保证每个张量只选一次
        for (int j = m; j >= 0; j--) {
            if (dp[j] == INF) continue;
            int nj = min(m, j + size); // 超过 m 直接压到 m
            dp[nj] = min(dp[nj], dp[j] + cost);
        }
    }

    if (dp[m] == INF) {
        ok = false;
        return -1;
    }
    ok = true;
    return dp[m];
}

int main() {
    
    int m, n;
    cin >> m >> n;

    vector<int> sizes(n), swapCost(n), recomputeCost(n);

    for (int i = 0; i < n; i++) cin >> sizes[i];
    for (int i = 0; i < n; i++) cin >> swapCost[i];
    for (int i = 0; i < n; i++) cin >> recomputeCost[i];

    bool ok;
    long long ans = solve(m, n, sizes, swapCost, recomputeCost, ok);

    if (!ok) {
        cout << "error" << endl;
    } else {
        cout << ans << endl;
    }

    return 0;
}
```
