# 题目描述

给定两个多项式的系数，第i项表示指数为n-i的系数。输出两个多项式的求和结果。

# 输入描述

第一行表示一个多项式的系数，第二行表示另一行多项式的系数，第三行表示多项式运算符

运算符只包含+、-、*。数组长度小于等于128，数组范围为$[-512, 512]$

# 输出描述

输出运算后的系数数组，需要去除前缀零。

# 样例

**输入**

```
[1 2 3 4 5 6]
[-4 -5 -6]
+
```

**输出**

```
[1 2 3 0 0 0]
```

**说明**

多项式系数数组$[1$ $2$ $3$ $4$ $5$ $6]$

表示多项式$A(x)=x^5+2x^4+3x^3+4x^2+5x+6$

多项式系数数组$[-4$ $-5$ $-6]$

表示多项式$B(X)=-4x^2-5x-6$

$A(x)+B(X)=x^5 +2x^4 + 3x^3$，对应的多项式系数数组为$[1$ $2$ $3$ $0$ $0$ $0]$
