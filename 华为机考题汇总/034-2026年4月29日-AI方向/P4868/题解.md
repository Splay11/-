## T1

选 **C：数据非负且需解释性的场景（如文本聚类）**。

NMF（非负矩阵分解）要求原始矩阵元素通常为**非负值**，分解后的两个矩阵也非负，因此结果更容易解释成“部件组合”或“主题权重”。常见应用包括文本主题建模、文本聚类、图像分解、推荐系统等。

A 错：NMF 不适合含负值的数据。
B 错：NMF 不是用于矩阵求逆。
D 不够准确：NMF 可以用于降维，但核心前提是**非负性**和**可解释性**，所以 C 更佳。

## T15

**答案：**：D.传统Attention的KV Cache显存占用与序列长度正相关，PagedAttention可突破该关联

**解析：** KV Cache 本质上需要为每个已生成/输入 token 保存 K/V，因此显存占用仍然与序列长度正相关，约为 $O(L)$。 PagedAttention 只是把 KV Cache 切成页/块来管理，减少连续显存分配带来的碎片和浪费，提高显存利用率，但不能突破 KV Cache 随序列长度增长这一基本关系。

## T17

**答案：**：A. 向量之间的内积 $\langle Qu,Qv\rangle$；B. 向量之间的欧几里得距离 $|Qu-Qv|_2$；D. 向量之间的余弦相似度 $\frac{(Qu)^T(Qv)}{|Qu|_2|Qv|_2}$

**解析：**：正交矩阵满足 $Q^TQ=I$，因此
$\langle Qu,Qv\rangle=(Qu)^T(Qv)=u^TQ^TQv=u^Tv$，内积保持不变，A正确；
$|Qu-Qv|_2=|Q(u-v)|_2=|u-v|_2$，欧几里得距离保持不变，B正确；
$|Qu-Qv|_1$ 一般不保持不变，因为正交变换可能改变向量各坐标的绝对值之和，曼哈顿距离不是正交变换下的不变量，C错误；
又因为 $|Qu|_2=|u|_2,\ |Qv|_2=|v|_2$，且 $(Qu)^T(Qv)=u^Tv$，所以余弦相似度保持不变，D正确。

## T18

**答案：**：A.若 $ P(A) = P(A|B) $ 且 $ P(B) > 0 $，则 $ A $ 和 $ B $ 独立；C.若 $ A $ 与 $ B $ 独立，则 $ P(A \cap B) = P(A)P(B) $ 

**解析：**：A正确，$ P(A|B)=P(A) $ 即独立性定义；B错误，条件独立一般不成立；C正确，独立定义；D错误，独立不具有传递性，$ A $ 与 $ B $ 且与 $ C $ 独立不能推出与 $ B \cap C $ 独立。

## T19

**答案：**：A.当 Batch Size 足够大时，模型梯度的分布通常会趋向于高斯分布；B.假设某层权重的联合分布服从多元正态分布，若已知各神经元权重之间相互独立，则它们的协方差矩阵必然是一个对角矩阵；D.为了最小化 MSE (mean square error)，最优化最优解阈值通常小于观测最大值  

**解析：**：A由中心极限定理，大Batch下梯度近似高斯；B独立正态则协方差为对角阵；C错误，Laplace分布下非线性量化（如对数量化）更优；D正确，MSE最优阈值通常取分位数而非最大值，故小于观测最大值。

**答案：**：A.如果学习率过大，可能导致权重更新幅度过大，使得神经元永远落在 ReLU 的负半轴区域；B.Leaky ReLU 可以有效缓解 Dead ReLU 问题；C.当输入小于 0 时，ReLU 的梯度值为 0，导致权重无法更新
