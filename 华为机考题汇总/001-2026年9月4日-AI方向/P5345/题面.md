##### 3、PCA 与 LDA 都能把高维样本投影到低维空间，但优化目标并不相同。下列关于二者的对比，哪一项最为准确？

{{ select(3) }}

##### 16、在流水线并行中，若个别 stage 的耗时明显长于其余 stage，气泡会加重。下列哪些做法更合理？

 {{ multiselect(16) }}

- 改为异步流水线，允许各 stage 不必严格对齐，再用额外信息弥补数值一致性。
- 把模型切得更细、增加 stage 数量，使各段计算量尽量接近。
- 在偏慢的 stage 前后插入空操作（no-op），用空转对齐节拍。
- 对偏慢 stage 进一步拆分微批，并在该 stage 内引入张量并行或算子并行，同时权衡额外开销。

##### 19、采用 5 折交叉验证评估模型时，下列说法正确的是？

 {{ multiselect(19) }}

- 最终报告的性能等于 5 次训练误差的算术平均
- 每一折用 20% 样本做验证，同时用另外 80% 样本计算测试误差
- 得到的 5 个模型都可以参与最终预测（例如做集成）
- 一共训练 5 次，每个样本恰好有 1 次被划入验证折



##### 20、某在线教育平台用多 Agent 协作批改作业：主 Agent 把请求拆成若干子任务，再分发给题目解析 Agent、评分 Agent、评语 Agent 等。设计该系统时，下列哪些做法是合理的？
 {{ multiselect(20) }}
- 主 Agent 一旦发现某个子 Agent 失败，整体时延就会明显下降，吞吐也会上升
- 拆分任务时必须考虑依赖：下游 Agent 要用到上游产出时，应保证执行顺序
- 记子任务数为 $n$。若各子任务彼此独立且可并行，总耗时大致由最慢的那个 Agent 决定，而不是各 Agent 耗时之和
- 即便子任务之间没有依赖，也应全部串行执行，以节省通信
