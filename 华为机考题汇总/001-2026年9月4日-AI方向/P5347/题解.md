## 解题思路

设输入的原始值为 $v_i$，按照题目给出的四个阶段依次处理。

### 1. 数据清洗

只有 $q=0$ 的数据属于有效数据，因此对于每个 $q=2$ 的位置，需要找到：

* 左侧最近的 $q=0$ 位置 $l$；
* 右侧最近的 $q=0$ 位置 $r$。

可以分别从左向右、从右向左扫描，预处理每个位置最近的有效前驱和后继。

若前后都有有效数据，根据时间戳进行线性插值：

$$
v_i
=
v_l+
(v_r-v_l)
\frac{t_i-t_l}{t_r-t_l}
$$

若只有左侧有效数据，则：

$$
v_i=v_l
$$

若只有右侧有效数据，则：

$$
v_i=v_r
$$

若两侧都没有有效数据，则保持原值。

注意，一段连续的 $q=2$ 数据都应该以原本的 $q=0$ 数据作为有效端点，已经插值出来的数据不会继续作为其他位置的有效端点。

### 2. 异常值检测

异常检测必须基于第一阶段得到的同一份序列进行，不能检测一个位置后立即修改原序列，否则后面位置的窗口统计量会受到前面修改结果的影响。

设：

$$
h=\frac{w-1}{2}
$$

对于位置 $i$，实际窗口范围为：

$$
l=\max(0,i-h)
$$

$$
r=\min(n-1,i+h)
$$

窗口长度为：

$$
m=r-l+1
$$

如果直接遍历每个窗口计算均值和标准差，最坏时间复杂度会达到 $O(nw)$。

可以预处理前缀和：

$$
P_i=\sum_{j=0}^{i-1}v_j
$$

以及平方前缀和：

$$
Q_i=\sum_{j=0}^{i-1}v_j^2
$$

于是窗口元素之和为：

$$
sum=P_{r+1}-P_l
$$

平方和为：

$$
sum_2=Q_{r+1}-Q_l
$$

窗口均值为：

$$
\mu=\frac{sum}{m}
$$

根据总体标准差计算方式，窗口方差可以写成：

$$
\sigma^2
=

\frac{sum_2}{m}-\mu^2
$$

因此：

$$
\sigma=
\sqrt{
\frac{sum_2}{m}-\mu^2
}
$$

由于浮点误差，理论上为 $0$ 的方差可能得到一个很小的负数，所以实现时取：

$$
\sigma=
\sqrt{
\max\left(0,\frac{sum_2}{m}-\mu^2\right)
}
$$

如果满足：

$$
|v_i-\mu|>k\sigma
$$

则把第二阶段的输出值修改为：

$$
v_i=\mu
$$

否则保持不变。

### 3. 标准化

对第二阶段完成后的整个序列计算：

$$
\bar{x}=\frac{1}{n}\sum_{i=1}^{n}v_i
$$

总体标准差：

$$
s=
\sqrt{
\frac{1}{n}
\sum_{i=1}^{n}(v_i-\bar{x})^2
}
$$

然后：

$$
z_i=\frac{v_i-\bar{x}}{s}
$$

如果 $s=0$，说明所有数据完全相同，没有任何离散程度，可以认为所有 $z_i=0$，最终特征分数也为 $0$。

### 4. 特征评分

根据质量标记得到：

$$
p_i=
\begin{cases}
1,&q_i=0\
0.5,&q_i=1\
0.25,&q_i=2
\end{cases}
$$

这里评分公式中的 $v_i$ 使用第二阶段完成后的、尚未标准化的数据。

先计算：

$$
D=\sum_{i=1}^{n}p_i|v_i|
$$

则：

$$
w_i=\frac{p_i|v_i|}{D}
$$

最后：

$$
S=
\sum_{i=1}^{n}
w_i|z_i|
$$

答案为：

$$
\operatorname{round}(100S)
$$

由于 $S\ge 0$，代码中可以通过：

$$
\left\lfloor100S+0.5\right\rfloor
$$

实现通常意义上的四舍五入，避免 Python 自带 `round` 的银行家舍入规则。

如果 $D=0$，所有参与权重计算的绝对值均为 $0$，此时直接输出 $0$。

## 复杂度分析

寻找每个位置左右最近的有效数据需要 $O(n)$。

异常检测阶段建立前缀和、平方前缀和需要 $O(n)$，之后每个位置都可以在 $O(1)$ 时间内得到窗口均值和标准差，因此整个异常检测需要 $O(n)$。

标准化和特征评分各遍历常数次数组，同样需要 $O(n)$。

所以总时间复杂度为：

$$
O(n)
$$

需要保存原始数据、左右有效位置、两个处理阶段的序列以及前缀和，因此空间复杂度为：

$$
O(n)
$$

```python
import sys
import math


def calc(t, v, q, w, k):
    n = len(v)

    # left[i] 表示位置 i 左侧最近的 q=0 有效数据下标
    left = [-1] * n
    last = -1
    for i in range(n):
        left[i] = last
        if q[i] == 0:
            last = i

    # right[i] 表示位置 i 右侧最近的 q=0 有效数据下标
    right = [-1] * n
    last = -1
    for i in range(n - 1, -1, -1):
        right[i] = last
        if q[i] == 0:
            last = i

    # 第一阶段：只处理 q=2 的无效数据
    a = [float(x) for x in v]
    for i in range(n):
        if q[i] != 2:
            continue

        l = left[i]
        r = right[i]

        if l != -1 and r != -1:
            # 前后都有有效数据，根据时间戳进行线性插值
            a[i] = v[l] + (v[r] - v[l]) * (t[i] - t[l]) / (t[r] - t[l])
        elif l != -1:
            # 只有前继有效数据，使用前继值
            a[i] = v[l]
        elif r != -1:
            # 只有后继有效数据，使用后继值
            a[i] = v[r]

    # 建立第一阶段序列的前缀和与平方前缀和
    pre = [0.0] * (n + 1)
    pre2 = [0.0] * (n + 1)
    for i in range(n):
        pre[i + 1] = pre[i] + a[i]
        pre2[i + 1] = pre2[i] + a[i] * a[i]

    # 第二阶段：所有窗口统计量都基于第一阶段序列 a
    b = a[:]
    h = (w - 1) // 2

    for i in range(n):
        l = max(0, i - h)
        r = min(n - 1, i + h)
        cnt = r - l + 1

        sm = pre[r + 1] - pre[l]
        sm2 = pre2[r + 1] - pre2[l]

        mu = sm / cnt
        var = sm2 / cnt - mu * mu
        var = max(0.0, var)
        sig = math.sqrt(var)

        # 偏差严格大于 k 倍标准差时才进行平滑
        if abs(a[i] - mu) > k * sig:
            b[i] = mu

    # 第三阶段：计算第二阶段序列的均值和总体标准差
    avg = sum(b) / n

    var = 0.0
    for x in b:
        var += (x - avg) * (x - avg)
    var /= n

    std = math.sqrt(var)

    # 所有值相同时 z-score 均视为 0
    if std == 0.0:
        return 0

    # 第四阶段：计算质量权重对应的分母
    den = 0.0
    for i in range(n):
        if q[i] == 0:
            p = 1.0
        elif q[i] == 1:
            p = 0.5
        else:
            p = 0.25

        den += p * abs(b[i])

    if den == 0.0:
        return 0

    # 根据未标准化值的权重和 z-score 绝对值计算最终分数
    score = 0.0
    for i in range(n):
        if q[i] == 0:
            p = 1.0
        elif q[i] == 1:
            p = 0.5
        else:
            p = 0.25

        weight = p * abs(b[i]) / den
        z = (b[i] - avg) / std
        score += weight * abs(z)

    # score 非负，使用 floor(x + 0.5) 实现普通四舍五入
    return int(math.floor(score * 100.0 + 0.5))


def main():
    input = sys.stdin.readline
    n, w, k = map(int, input().split())

    t = [0] * n
    v = [0] * n
    q = [0] * n

    for i in range(n):
        t[i], v[i], q[i] = map(int, input().split())

    print(calc(t, v, q, w, k))


if __name__ == "__main__":
    main()
```

```java
import java.io.*;
import java.util.*;

public class Main {

    static long calc(long[] t, double[] v, int[] q, int w, int k) {
        int n = v.length;

        // left[i] 表示位置 i 左侧最近的 q=0 有效数据下标
        int[] left = new int[n];
        Arrays.fill(left, -1);

        int last = -1;
        for (int i = 0; i < n; i++) {
            left[i] = last;
            if (q[i] == 0) {
                last = i;
            }
        }

        // right[i] 表示位置 i 右侧最近的 q=0 有效数据下标
        int[] right = new int[n];
        Arrays.fill(right, -1);

        last = -1;
        for (int i = n - 1; i >= 0; i--) {
            right[i] = last;
            if (q[i] == 0) {
                last = i;
            }
        }

        // 第一阶段：处理 q=2 的无效数据
        double[] a = v.clone();

        for (int i = 0; i < n; i++) {
            if (q[i] != 2) {
                continue;
            }

            int l = left[i];
            int r = right[i];

            if (l != -1 && r != -1) {
                // 前后都有有效数据，根据时间戳进行线性插值
                a[i] = v[l] + (v[r] - v[l])
                        * (double) (t[i] - t[l])
                        / (double) (t[r] - t[l]);
            } else if (l != -1) {
                // 只有前继有效数据，使用前继值
                a[i] = v[l];
            } else if (r != -1) {
                // 只有后继有效数据，使用后继值
                a[i] = v[r];
            }
        }

        // 建立前缀和与平方前缀和，使每个窗口可以 O(1) 计算统计量
        double[] pre = new double[n + 1];
        double[] pre2 = new double[n + 1];

        for (int i = 0; i < n; i++) {
            pre[i + 1] = pre[i] + a[i];
            pre2[i + 1] = pre2[i] + a[i] * a[i];
        }

        // 第二阶段：异常检测统一基于第一阶段序列 a
        double[] b = a.clone();
        int h = (w - 1) / 2;

        for (int i = 0; i < n; i++) {
            int l = Math.max(0, i - h);
            int r = Math.min(n - 1, i + h);
            int cnt = r - l + 1;

            double sum = pre[r + 1] - pre[l];
            double sum2 = pre2[r + 1] - pre2[l];

            double mu = sum / cnt;
            double var = sum2 / cnt - mu * mu;
            var = Math.max(0.0, var);

            double sig = Math.sqrt(var);

            // 只有偏差严格大于阈值时才替换为窗口均值
            if (Math.abs(a[i] - mu) > k * sig) {
                b[i] = mu;
            }
        }

        // 第三阶段：计算第二阶段序列的均值
        double avg = 0.0;
        for (double x : b) {
            avg += x;
        }
        avg /= n;

        // 按总体标准差公式计算标准差
        double var = 0.0;
        for (double x : b) {
            double d = x - avg;
            var += d * d;
        }
        var /= n;

        double std = Math.sqrt(var);

        // 所有值相同时所有 z-score 均视为 0
        if (std == 0.0) {
            return 0;
        }

        // 第四阶段：计算权重分母
        double den = 0.0;

        for (int i = 0; i < n; i++) {
            double p;

            if (q[i] == 0) {
                p = 1.0;
            } else if (q[i] == 1) {
                p = 0.5;
            } else {
                p = 0.25;
            }

            den += p * Math.abs(b[i]);
        }

        if (den == 0.0) {
            return 0;
        }

        // 根据数据权重和 z-score 的绝对值累加最终特征分数
        double score = 0.0;

        for (int i = 0; i < n; i++) {
            double p;

            if (q[i] == 0) {
                p = 1.0;
            } else if (q[i] == 1) {
                p = 0.5;
            } else {
                p = 0.25;
            }

            double weight = p * Math.abs(b[i]) / den;
            double z = (b[i] - avg) / std;

            score += weight * Math.abs(z);
        }

        // score 非负，floor(x + 0.5) 实现普通四舍五入
        return (long) Math.floor(score * 100.0 + 0.5);
    }

        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

            v[i] = Long.parseLong(st.nextToken());
            q[i] = Integer.parseInt(st.nextToken());
        }

        System.out.println(calc(t, v, q, w, k));
    }
}
```
