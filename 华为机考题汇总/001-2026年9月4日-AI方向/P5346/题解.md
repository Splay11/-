## 解题思路

每个训练任务都必须从两个方案中选择一个，因此这是一个典型的“分组背包”问题：共有 $n$ 组，每组有两个方案，并且每组必须且只能选择一个方案。

定义：

$$
dp[j]
$$

表示处理完当前若干个任务后，恰好消耗 $j$ 单位资源时能够得到的最小总训练耗时。

初始时还没有选择任何任务：

$$
dp[0]=0
$$

其他状态均不可达，设为无穷大。

对于第 $i$ 个任务，它有两个方案：

$$
(c_{1i},t_{1i}),\quad(c_{2i},t_{2i})
$$

使用新的数组 $ndp$ 进行状态转移。

如果当前 $dp[j]$ 可达，则选择方案 1：

$$
ndp[j+c_{1i}]
=

\min(ndp[j+c_{1i}],dp[j]+t_{1i})
$$

前提是：

$$
j+c_{1i}\le C
$$

选择方案 2：

$$
ndp[j+c_{2i}]
=
\min(ndp[j+c_{2i}],dp[j]+t_{2i})
$$

前提是：

$$
j+c_{2i}\le C
$$

由于每处理一个任务都会使用一个新的 $ndp$ 数组，因此可以保证每个任务恰好选择一个方案，不会出现同一个任务重复选择或者不选择的情况。

处理完全部 $n$ 个任务后，枚举：

$$
0\le j\le C
$$

找到最小的 $dp[j]$。

此时：

* $dp[j]$ 为最小总训练耗时；
* $j$ 为对应的实际总资源消耗；
* $C-j$ 为剩余资源。

如果存在多个方案具有相同的最小总训练耗时，则选择其中实际资源消耗最小的方案，使输出结果确定。实现时从小到大枚举资源消耗，并且只在总耗时严格更小时更新答案即可。

## 复杂度分析

共有 $n$ 个任务，每个任务需要枚举最多 $C+1$ 个资源状态，每个状态只进行两个方案的转移，因此时间复杂度为：

$$
O(nC)
$$

使用两个长度为 $C+1$ 的一维数组进行动态规划，因此空间复杂度为：

$$
O(C)
$$

在：

$$
n\le100,\quad C\le1000
$$

的数据范围下，时间和空间复杂度都可以满足要求。

## 代码实现

### Python

```python
import sys


def calc(n, C, a):
    INF = 10 ** 9

    # dp[j] 表示恰好使用 j 单位资源时的最小总耗时
    dp = [INF] * (C + 1)
    dp[0] = 0

    for c1, t1, c2, t2 in a:
        # 每个任务必须且只能选择一个方案，因此使用新的状态数组
        ndp = [INF] * (C + 1)

        for j in range(C + 1):
            if dp[j] == INF:
                continue

            # 当前任务选择方案 1
            if j + c1 <= C:
                nj = j + c1
                ndp[nj] = min(ndp[nj], dp[j] + t1)

            # 当前任务选择方案 2
            if j + c2 <= C:
                nj = j + c2
                ndp[nj] = min(ndp[nj], dp[j] + t2)

        dp = ndp

    # 从小到大枚举资源消耗，相同最小耗时时保留资源消耗更小的方案
    min_time = INF
    use = 0

    for j in range(C + 1):
        if dp[j] < min_time:
            min_time = dp[j]
            use = j

    return min_time, use, C - use


def main():
    n, C = map(int, sys.stdin.readline().split())

    a = []
    for _ in range(n):
        c1, t1, c2, t2 = map(int, sys.stdin.readline().split())
        a.append((c1, t1, c2, t2))

    min_time, use, left = calc(n, C, a)
    print(min_time, use, left)


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.*;

public class Main {

    static int[] calc(int n, int C, int[][] a) {
        int INF = 1000000000;

        // dp[j] 表示恰好使用 j 单位资源时的最小总耗时
        int[] dp = new int[C + 1];
        Arrays.fill(dp, INF);
        dp[0] = 0;

        for (int i = 0; i < n; i++) {
            int c1 = a[i][0];
            int t1 = a[i][1];
            int c2 = a[i][2];
            int t2 = a[i][3];

            // 每个任务必须且只能选择一个方案，因此使用新的状态数组
            int[] ndp = new int[C + 1];
            Arrays.fill(ndp, INF);

            for (int j = 0; j <= C; j++) {
                if (dp[j] == INF) {
                    continue;
                }

                // 当前任务选择方案 1
                if (j + c1 <= C) {
                    int nj = j + c1;
                    ndp[nj] = Math.min(ndp[nj], dp[j] + t1);
                }

                // 当前任务选择方案 2
                if (j + c2 <= C) {
                    int nj = j + c2;
                    ndp[nj] = Math.min(ndp[nj], dp[j] + t2);
                }
            }

            dp = ndp;
        }

        // 从小到大枚举资源消耗，相同最小耗时时保留资源消耗更小的方案
        int minTime = INF;
        int use = 0;

        for (int j = 0; j <= C; j++) {
            if (dp[j] < minTime) {
                minTime = dp[j];
                use = j;
            }
        }

        return new int[]{minTime, use, C - use};
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int C = sc.nextInt();

        int[][] a = new int[n][4];

        for (int i = 0; i < n; i++) {
            a[i][0] = sc.nextInt();
            a[i][1] = sc.nextInt();
            a[i][2] = sc.nextInt();
            a[i][3] = sc.nextInt();
        }

        int[] ans = calc(n, C, a);

        System.out.println(ans[0] + " " + ans[1] + " " + ans[2]);

        sc.close();
    }
}
```
