# 题面改写知识库

本目录沉淀「原题面 → 改写题面」时**实际改了什么、什么不能改**，供下次改题直接对照。

## 配套 skill

| Skill | 路径 | 何时用 |
|-------|------|--------|
| **业务点缀版**（可改多测/单组包装） | `.cursor/skills/problem-statement-restyle-flavor/SKILL.md` | 允许有 Σ 时改真单组、换业务壳 |
| **保 I/O 结构版** | `.cursor/skills/problem-statement-restyle-io-preserve/SKILL.md` | 多组必须仍多组、单组仍单组；变量全换；短题加厚/长题压薄 |

题面爬取：`utils/get_problem.py`（详见 `utils/README.md`）。  
标程提交：`utils/submit_code_and_get_result.py`（见下表「标程生成与在线提交」）。

| 文档 | 用途 |
|------|------|
| [改写对照清单.md](./改写对照清单.md) | 改动维度总表 + 注意点（普适） |
| [案例-P5215.md](./案例-P5215.md) | 原题 vs 改写题逐项对照（可当模板抄） |
| [业务背景词库.md](./业务背景词库.md) | 业务点缀分类词条；改写时随机抽取组合（**禁止公司名**） |
| [标程生成与在线提交.md](./标程生成与在线提交.md) | 两 skill 共用：生成三语言并交原题、反馈未通过 |

**保 IO 文风**：改写题干须 **LeetCode 式极简**（说清给什么/做什么/求什么）+ **一句业务**；禁止照搬「更形式化地」等二次复述。

## 使用方式

1. 选对 skill：要保持多测/单组结构 → **io-preserve**；允许换包装 → **flavor**  
2. 带上 PID。**完成标准**：原题 `题面.md` + 对应改写文件 + `std.cpp` / `Main.java` / `std.py` + 三语言提交结果（含未通过列表）  
3. 缺原题则先爬取；改写不得写回 `题面.md`  
4. 打开 **业务背景词库** 抽词条；打开 **标程生成与在线提交** 做生成与评测  
5. 标程 **I/O 协议始终对齐原题**（网站测的是原题），即使 flavor 把题面改成了单组叙述

## 底线（一句话）

**算法核不变**（同一数据实例答案不变）；表面名称、变量、公式形态、样例数字、I/O 措辞、业务背景可换；**io-preserve 额外冻结单组/多组结构**。
