# 题面改写对照清单

下次改题时按表勾选。核心问题：**改后看起来不像原题，但还是同一道题。**

---

## 一、文件与版式（先定规矩）

| 项 | 怎么做 |
|----|--------|
| 原题面 | **不改**；只读 |
| 产出 | **新建** markdown（如 `题面_改写.md`） |
| 章节骨架 | 保持原 `# 题目内容` / `# 输入描述` / `# 输出描述` / `## 样例k` 等结构与标题风格 |
| 代码块/空行习惯 | 尽量跟原题同构；可增补同构的 `## 样例2`、`**说明**` |
| 特殊标记 | `{{ select(n) }}` 等原样保留 |

---

## 二、必须改 / 建议改（表面）

| 维度 | 原常见写法 | 改写方向 | 注意 |
|------|------------|----------|------|
| 题目名字 | 无，或原平台旧名 | 文首新增 `# 中文题名`（在 `# 题目内容` 前） | 短、贴题；勿照抄旧名；可与题解题名对齐 |
| 业务点缀 | 无，或「小苯」叙事 | 加 1～3 句轻场景（运维/仓储等） | 不引入新约束（时限、权限、有序性等） |
| 题意篇幅 | 较长、重复解释 | 压成几句说清：给什么、求什么、硬规则 | 不能少硬规则 |
| 自造定义名 | 「平衡度」等题目发明的词 | **必须换名**（如「波动贡献」） | — |
| 自造函数名 | `B(l,r)` | **必须换**（如 `H(L,R)`） | 全文一致 |
| 标准术语 | 子段、子序列、树、边… | **不换** | 勿把「子段」改成可非连续 |
| 序列变量 | `a_i` | 可换 `v_i` / `b_i` / `c_i`… | 全文同一映射 |
| 下标变量 | `l,r` | 可换 `L,R` / `s,t` / `p,q`… | 全文同一映射 |
| 公式步数 | 一步写完 | 可拆：先「其长度为 …」，再「… 定义为 …」；多步也可合并 | **禁止**「先令其长度」「先取」 |
| 公式下标 | `\max_{i=l}^{r} a_i`；`\min_{0\le y\le m} f(y)` | 展开为 `\max(a_l,\ldots,a_r)`；`\min(f(0),f(1),\ldots,f(m))` | min/求和/对参数枚举的 min/max 同理；语义不变 |
| 数据范围 | $2\times 10^5$、$10^9$ 等 | **改写法且可轻微改数** | 同复杂度量级；形式互换如 $2\times 10^5$↔$200000$，$10^9+7$↔$1000000007$；勿改到另一档 |
| I/O 措辞 | 输入/输出、整数、数组 | 读入/写出、整型、列表… | 类型与分隔不变 |
| 输出值域措辞 | 「一个整数」 | 可略宽为「非负整数」（若答案恒 ≥0） | **输入下界语义不要放宽**（如正整数勿改成可含 0，除非原就允许） |
| 多测 → 真单组 | 有多组 **且** 有总和规模（如「$n$ 之和不超过」） | 可去组数与总和约束，拆多个小样例 | **不要写「单组测试」** |
| 多测 → 多询问 | 有多组但**无**总和规模（如仅 $T\le 10^5$） | **必须保留多询问**（防复杂度/做法漂移） | **不要写「多组测试/$T$」**；写成「第一行 $n$ 为行数，接下来 $n$ 行每行一个…，对每个逐一计算」 |
| 样例结构 | 原多样例形态 | 真单组→多个 `## 样例k`；多询问→样例内多行 | 数字重造 |
| 样例数字 | 原样例数组/串/排列 | **重新造**小样例（好手算、能展示规则） | 答案按原算法核算对；禁止把原多测各组原样拆开复用 |
| 样例说明 | 常无 | **每个样例都加 `**说明**`** | 只解释，不新增规则 |
| 题面内举例 | 如「例如 $5$ xor $3=6$」 | **换一套数字/对象**，勿照抄 | 例子算式必须正确；正反例同一设定；反例要说明原因 |

## 三、不能改（算法核）

| 项 | 说明 |
|----|------|
| 目标语义 | 仍是同一优化/判定/构造问题 |
| 硬规则 | 如：非空连续子段、必须铺满全序列 |
| 值域与规模 | 可换写法、可轻微改数，但**复杂度档不变**；字段类型与合法性不变 |
| 同一实例的答案 | 换皮后同一组数，答案必须相同 |
| 精度 / 多解约定 / Yes-No 大小写 | 评测细节不动 |

> 无总和规模的多询问题不可改成真单组。保留多询问时用「$n$ 行逐一计算」表述，不要写「多组测试」。读入形态变了时标程读写可能要同步，算法核仍应正确。

## 四、改写时自检（短清单）

- [ ] 文首是否新起了中文题名（且未照抄旧名）？  
- [ ] 删掉业务句后，还是原目标 + 原硬规则吗？  
- [ ] 自造名换了吗？子段等标准词没乱改吗？  
- [ ] 变量/函数名全文一致吗？  
- [ ] 公式拆并/展开后，数值含义一样吗？（无「先令」套话）  
- [ ] 单组有没有误写「单组测试」？多询问有没有误写「多组测试」？（应写成「$n$ 行逐一计算」）  
- [ ] 无 Σ 规模的多测题是否误改成单组了？（会改复杂度则必须保留多询问）  
- [ ] 数据范围是否换过写法/轻改数（未照抄原表述，且未改到另一复杂度档）？  
- [ ] 新样例是小样例吗？每个都有说明吗？答案验过吗？  
- [ ] 题面里的「例如…」示意例子换过了吗（未照抄原题）？  
- [ ] 原 `题面.md` 是否完全未动？
