给定一个大小为 $n$ 的数组 $nums$ ，返回其中的多数元素。多数元素是指在数组中出现次数 大于 $⌊ n/2 ⌋$的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素

**输入** 

```
2 2 1 1 1 2 2
```

**输出** 

```
2
```

**思路**

## 理解"消消乐"操作

定义消消乐操作：**从数组中取两个不相等的数进行消除**

**结论**：重复进行“消消乐”操作直到数组只剩下相同的数时，这些数就是众数。

接下来我们看个例子👇

@[video](https://codefun2000.com/p/4201/file/%E9%9A%8F%E6%9C%BA%E5%8F%96%E6%95%B0%E6%B3%95%E6%B0%B4%E5%8D%B0.mp4)

**证明**：每次“消消乐操作”最多消耗一个众数，又因为一个长度为$n$的数组最多执行$\frac{n}{2}$ （向下取整）次操作。所以最差情况下，众数也不会被其他数彻底抵消完，会至少剩一个。

**接下来我们的目的就很清晰了：设计一种高效的算法来执行消消乐操作直到无法操作，获取剩下来的数**

## **解法1:栈做法**

一种朴素的想法是：从左往右逐个扫描元素，压入栈中。

1.当$a[i]$与栈顶元素不同时，对$(s.top() , a[i])$ 执行一次消消乐操作。

2.当$a[i]$与栈顶元素相同时，则压入栈中暂存，供后续元素消除。

3.当栈中无元素时，同理，压入栈中暂存，供后续元素消除。

**正确性**：

这样的过程本质上是：对每个元素，寻找左侧第一个和它不同的元素进行消除。这样每个元素一定会被考虑到。而最终剩下来的元素一定就是无法被消除的元素，即众数。

```python
from typing import List

class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        stack = []
        # 遍历数组中的每个数字
        for num in nums:
            # 如果栈不为空且栈顶元素与当前元素不同，则弹出栈顶元素
            if stack and stack[-1] != num:
                stack.pop()
            # 如果栈为空或栈顶元素与当前元素相同，则将当前元素压入栈中
            else:
                stack.append(num)
        # 返回栈底元素
        return stack[0]
```

```javascript
var majorityElement = function (nums) {
    // 栈消去法：成对抵消不同元素，最终栈顶即为多数元素（题目保证存在）
    const stack = [];

        if (stack.length > 0 && stack[stack.length - 1] !== num) {

            stack.push(num);
        }
    }
    // 栈中剩余元素均为同一值，即多数元素
    return stack[0];
};
```

```go
	for _, num := range nums {
		// 栈非空且栈顶与当前元素不同 → 弹出栈顶（一对不同元素抵消）
```

```c
int majorityElement(int* nums, int numsSize) {
    int* stack = (int*)malloc((size_t)numsSize * sizeof(int));
    if (!stack) {
        return 0;
    }
    int top = -1; /* 栈顶下标，-1 表示空栈 */
    /* 遍历数组中的每个数字 */
    for (int i = 0; i < numsSize; ++i) {
        int num = nums[i];
        /* 栈非空且栈顶与当前元素不同 → 弹出栈顶（一对不同元素抵消） */
        if (top >= 0 && stack[top] != num) {
            --top;
        } else {
            /* 栈为空，或栈顶与当前元素相同 → 压入当前元素 */
            stack[++top] = num;
        }
    }
    /* 栈中剩余元素均为同一值，即多数元素 */
    int ans = stack[0];
    free(stack);
    return ans;
}
```

## **解法2：摩尔投票法**

该做法本质是栈做法的空间优化版本。

在栈做法中，有一个明显的特点是：**栈中不会存在不同的元素，因为不同的元素会在压入栈之前被栈顶元素消除**。所以在<栈只记录相同数字>的情况下，其实可以优化掉栈结构，用两个变量记录:当前栈中的元素`now`以及该元素出现的次数`cnt`。

**做法**：从左往右扫描每个数，过程中维护一个`now` 代表后续要被抵消的数，`cnt` 代表`now`出现过多少次。每次如果:

1.$a[i] = now$  , 此时$cnt += 1$

2.$a[i] \neq now$ , 进行一次消消乐操作  ，将$now$和$a[i]$进行消除，即 $cnt -= 1$

过程中如果$cnt = 0$  代表此时栈为空，直接$now = a[i] , cnt = 1$ 即可。

```python
from typing import List

class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        # 初始化待被抵消的元素和计数器
        now = -1
        cnt = 0         # 计数器
        # 遍历数组中的每个数字
        for num in nums:
            if cnt == 0:
                now = num  # 当计数器为0时，更新待被抵消的元素
                cnt = 1
            elif num == now:
                cnt += 1       # 当前数字与待被抵消的元素相同，计数器加1
            else:
                cnt -= 1       # 不同则计数器减1 , 相当于抵消了当前数字
        return now
```

## 面试问答

**1. 本题的核心思路是什么？**

摩尔投票法。 从左往右扫描每个数，过程中维护一个`now` 代表后续要被抵消的数，`cnt` 代表`now`出现过多少次。每次如果`a[i]=now` , 则`cnt += 1` ，否则进行一次抵消，`cnt -= 1` , 整个过程结束，`now` 就是众数。 

**2.该算法的原理什么？为什么是对的？**

原理：将不同的数两两消除，最终剩下来的就是众数。

正确性：因为众数的个数超过数组的一半。所以每次抵消操作最多消耗一个众数。最差情况下，众数也不会被其他数彻底抵消完，至少剩余一个。
