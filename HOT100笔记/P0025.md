## LeetCode 70. 爬楼梯

[在线刷题](https://codefun2000.com/p/P4031)

[视频讲解](https://www.bilibili.com/video/BV1NTLg6VENq?spm_id_from=333.788.videopod.sections&vd_source=0f2b5f5dae4beb99b68547471f7432e0)

假设你正在爬楼梯。需要 $n$ 阶你才能到达楼顶。

每次你可以爬 $1$ 或 $2$ 个台阶。你有多少种不同的方法可以爬到楼顶呢？

**输入** 

```
2
```

**输出** 

```
2
```

**说明**

有两种方法可以爬到楼顶。

1. $1$ 阶 + $1$ 阶
2. $2$ 阶

### 思路

接下来的分析，我不拽花里胡哨的名词，也不需要任何前置知识，**从最笨的方法出发：列出所有可能，看看能找到啥规律。**

![](/file/2/OdlQsRXTqOnaqCxHdcix6.png =80%x)


我们可以将这5种方案划分为两类：上一步从$2$来的 + 上一步从$3$来的。

4的上一步从$3$来的所有方案 等价于 $n = 3$ 的所有情况

4的上一步从$2$来的所有方案 等价于 $n = 2$ 的所有情况


![](/file/2/j4mEj78nEP0NVeI5TLgyB.png =80%x)



如果定义出$f(4)$代表$n = 4$ 的所有可能的情况**数量**，不难发现：
$$
f(4) = f(3) + f(2)
$$

由上面的分析，我们可以总结规律：考虑到$n$的方案数，**它由两类方案相加得到**：

**方案一**:先到$n - 1$ 号台阶然后最后跨一步到$n$的方案数。

**分步相乘**：到$n - 1$ 号台阶 的方案数是$f(n - 1)$ ， 跨一步从$n - 1$ 到 $n$ 的方案数为 $1$ ， 由于是先后关系，分步相乘得到：$f(n - 1) * 1 = f(n - 1)$

**方案二**:先到$n - 2$ 号台阶，然后最后跨两步到$n$的方案数。

**分步相乘**：从1到$n - 2$ 号台阶 的方案数是$f(n - 2)$ , 跨两步从$n - 2$ 到 $n$ 的方案数为 $1$ ，由于是先后关系，分步相乘得到：$f(n - 2) * 1 = f(n - 2)$

所以转移:$f(n) = f(n - 1) + f(n - 2)$

![](/file/2/vX_wmO10IoRp1yfKmkpXC.png =70%x)


总结来讲：到$n$号台阶的方案数$f(n)$，按上一步从哪里来的分成两类子问题$f(n - 1)$ , $f(n - 2)$，因为分类相加原理，所以是**相加**得到结果，不是相乘，也不是相减。



**回到我们的解题技巧上来，看看这道题是否能套用我们的解题技巧：**

1.题目问什么，我们定义什么状态:
定义函数:$f(i)$ 为 爬到第$i$个台阶的不同方法数。

2.转移：总是考虑`最后一个元素`的状态:
考虑第$i$号台阶的情况：它要么是从$i - 1$ 来 ，要么是从$i - 2$ 来，相加得到$f(i) = f(i - 1) + f(i - 2)$

在代码层面，由于$f(0),f(1)$ 无法套用以上转移，因为它不够两项，则从定义考虑它的赋值：

原地不动是一种方案,所以$f(0) = 1$

到1号台阶，只有$0\rightarrow 1$,所以$f(1) = 1$

**怎么理解原地不动要算一种方案？**

从另一个角度来看，我们知道 $f(1) = 1,f(2) = 2$一定是对的 。 为了他俩能被正确计算，$f(0)$ 需要等于$f(2) - f(1) = 1$

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        # f(i) 表示爬到第 i 个台阶的不同方法数
        # f(0) = 1，表示原地不动也是一种方案
        # f(1) = 1，只有一种走法：走 1 阶
        if n <= 1:
            return 1

        # 下标从 0 开始，所以数组长度开到 n + 1
        dp = [0] * (n + 1)
        dp[0] = 1
        dp[1] = 1

        # 爬到第 i 阶，最后一步要么从 i - 1 来，要么从 i - 2 来
        for i in range(2, n + 1):
            dp[i] = dp[i - 1] + dp[i - 2]

        return dp[n]
```

    // f(i) 表示爬到第 i 个台阶的不同方法数
    // f(0) = 1，表示原地不动也是一种方案

}

**空间优化：滚动变量法**

由于$f(n)$ 只依赖$f(n - 1) , f(n - 2)$ 这两项，而$f(n-3),f(n-4),...,f(1)$ **对计算后续项来说已经没有任何用处了。**

**我们可以使用三个变量，只保存我们计算下一项所需要的最少元素，滚动计算**
#code-switcher
```python
class Solution:
    def climbStairs(self, n: int) -> int:
        # f(0) = 1，表示原地不动也是一种方案
        # f(1) = 1，表示爬到第 1 阶只有一种方案
        if n == 1:
            return 1

        # dp2 表示 f(i - 2)，dp1 表示 f(i - 1)
        dp2 = 1
        dp1 = 1

        # 从第 2 阶开始滚动计算
        for i in range(2, n + 1):
            # f(i) = f(i - 1) + f(i - 2)
            dp_now = dp1 + dp2
            # 滚动更新，下一轮继续使用最近的两个状态
            dp2 = dp1
            dp1 = dp_now

        return dp1
```

### 面试问答

**1.这个算法的思想是什么？**

动态规划。设 $dp[i]$ 表示爬到第 $i$ 阶的方法数。考虑爬到第 $i$ 阶时，上一步可能从第 $i-1$ 阶迈一步上来，也可能从第 $i-2$ 阶跨两步上来，因此有：$dp[i] = dp[i-1] + dp[i-2]$。

又由于每一项只依赖前两项，所以使用三个变量滚动计算：其中两个变量保存上两项的结果，一个变量用于计算下一项的结果。

时间复杂度$O(n)$ ， 空间复杂度$O(1)$

## LeetCode 53. 最大子数组和

[在线刷题](https://codefun2000.com/p/P4011)

给你一个整数数组 $nums $，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），输出其最大和。

子数组是数组中的一个连续部分。

**输入样例**

```
9
-2 1 -3 4 -1 2 1 -5 4	
```

### **输出样例**

```
6
```

**说明**

连续子数组 $[4,-1,2,1]$ 的和最大，为$ 6 $

**思路：**

**1.问什么定义什么**

先将问题拆解一下：

**定义函数$f(i)$代表以$i$ 为右端点时，它能够得到的最大子数组和**

最终答案就是以所有位置作为右端点时能够得到的最大子数组和的最大值：

$$ans = max(f(i), i \in [1,n])$$

例如:$[1,2,-1,-4,5,6]$

- `f(1) = 1`，对应子数组 `[1]`
- `f(2) = 3`，对应子数组 `[1,2]`
- `f(3) = 2`，对应子数组 `[1,2,-1]`
- `f(4) = -2`，对应子数组 `[1,2,-1,-4]`
- `f(5) = 5`，对应子数组 `[5]`
- `f(6) = 11`，对应子数组 `[5,6]`

> 其中比如 `f(6)=11`，表示以第 6 个位置结尾时，最大子数组和是 `11`，对应子数组 `[5,6]`。

所以这一组的 `f(i)` 值就是：

```text
[1, 3, 2, -2, 5, 11]
```

答案`ans = max(f) = max([1,3,2,-2,5,11]) = 11`

**这里我们用一个实际的动画来演示👇**
@[video](https://codefun2000.com/p/3956/file/%E6%9C%80%E5%A4%A7%E5%AD%90%E6%AE%B5%E5%92%8C.mp4)

**2.考虑最后一个元素的状态**

先看看以$i$ 为结尾的子数组：

![](/file/2/TGY1-0uMCG_65UPPBKh2k.png =30%x)


$f(i)$ **就是要从上面这些子数组中找一个和最大的子数组**

由于这些子数组都以$a_i$为结尾，所以必包含$a_i$ ，考虑统一拿掉$a_i$，不难发现剩下来的数组由两部分组成：

①以$i - 1$ 为结尾的子数组 

②$\emptyset$

**如图所示👇**

![](/file/2/iFC2hWj1FGo3jqlROjFNd.png =70%x)


对于①，显然是去找以$i - 1$ 为结尾的子数组和中最大的那个，即$f(i - 1)$ 

对于②，则是$a_i$ 单独成段的情况。

$$ f(i) = max(f(i - 1) + a_i , 0 + a_i) = max(f(i - 1) , 0) + a_i $$

上面我们是从“所有情况分类”推出转移，**让大家知道转移不是凭空想出来的。**

接下来再从直觉上理解一下这个式子为什么合理。这个式子其实就是一个简单的**贪心**：

如果前面的最大子数组和是正数，那就接上当前元素更优

如果前面的最大子数组和是负数，那它只会拖后腿，不如从当前元素重新开始

一句话总结：要么接在前面最优的一段后面，要么从当前位置另起一段。

有了状态和转移我们可以直接写代码了👇
#code-switcher
```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        n = len(nums)

        # dp[i] 表示以 i 为右端点时，能够得到的最大子数组和
        dp = [0] * n
        dp[0] = nums[0]

        # ans 记录所有 dp[i] 中的最大值
        ans = nums[0]

        for i in range(1, n):
            # 如果前面的最大子数组和接上当前数更大，就接上
            # 否则从当前 nums[i] 重新开始一段
            dp[i] = max(dp[i - 1] + nums[i], nums[i])

            # 更新最终答案
            ans = max(ans, dp[i])

        return ans
```

func maxSubArray(nums []int) int {
	n := len(nums)

	// dp[i] 表示以 i 为右端点时，能够得到的最大子数组和
	dp := make([]int, n)
	dp[0] = nums[0]

class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)

        # 如果没有房屋，偷到的金额为 0
        if n == 0:
            return 0

        # 如果只有一间房屋，只能偷这一间
        if n == 1:
            return nums[0]

        # dp[i] 表示考虑前 i 间房屋时，能够偷到的最高金额
        dp = [0] * n
        dp[0] = nums[0]
        dp[1] = max(nums[0], nums[1])

        # 枚举每一间房屋，考虑最后一间房屋偷还是不偷
        for i in range(2, n):

            # 偷第 i 间：第 i - 1 间不能偷，答案是 dp[i - 2] + nums[i]
            dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])

        return 0;

**1.问什么定义什么**

**2.考虑最后一个元素的状态**

$a_i$ 之前有$a_1,a_2,...,a_{i-1}$这$i - 1$个元素。

只要满足$a_k < a_i , k < i$ ，我们就尝试让$a_i$ 和 以$a_k$为结尾的最长序列进行拼接:

## LeetCode 279. 完全平方数

[在线刷题](https://codefun2000.com/p/P4091)

给你一个整数 $n$ ，返回 和为 $n$ 的完全平方数的最少数量 。

**完全平方数** 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，$1、4、9和 16$ 都是完全平方数，而 $3$和 $11$ 不是。

**输入** 

```
12
```

**输出** 

```
3
```

**说明**

$12 = 4 + 4 + 4$

数据范围：$1 <= n <= 10^4$

**思路**

将要组成的整数$n$看成长度为$n$的木板， 完全平方数$x^2$ 看成长度为$x^2$的木板。

问题转化成：将一个长度$n$的木板分割成最少的部分，要求每个部分的长度恰好是完全平方数。

![](/file/2/WyIUgt_nPPshjxbBcmq4d.png =80%x   )


**1.问什么定义什么**

定义$f(i)$ 代表长度为$n$的木板能分割出的最少个数。 对于任意的$i$ ， 答案$f(i)$一定存在，因为可以用$i$个$1$ 相加得到。

**2.考虑最后一个元素的状态**

接着考虑最后一个部分的可能长度为:$j = 1^2,2^2,...,(\sqrt{i})^2$

我们枚举这些长度，分割出来后得到$i - j$  长度的木板。此时该子问题和原问题类似，只是规模变小了。这符合了动态规划的要求，于是我们可以写出状态转移方程。

$$f(i) = f(i - k^2 , k \in [1, \lfloor\sqrt{i}\rfloor]) + 1 $$

![](/file/2/Vc3ZWjVVYZMkjGtzL3Dxw.png =90%x)




由于依赖的状态$i - k^2 < i$ , 则 计算顺序为从小到大。

注意边界条件:$f(0) = 0$ ， 因为长度为$0$的木板，我们不需要切割就能满足要求。

另外一个角度来说，当$i - k^2 = 0$ 时，转移式为:$f(i) = f(0) + 1$。  这种情况是 木板本身长度就是完全平方数，无需切割。此时为了满足$f(i) = 1$ , 需要$f(0) = 0$

class Solution:
    def numSquares(self, n: int) -> int:
        # dp[i] 表示组成整数 i 所需要的最少完全平方数数量
        dp = [n + 1] * (n + 1)
        # 组成 0 不需要任何完全平方数
        dp[0] = 0

        # 从小到大计算每个整数的答案
        for i in range(1, n + 1):
            j = 1
            # 枚举最后一个完全平方数 j * j
            while j * j <= i:
                # 如果最后选 j * j，那么前面还需要组成 i - j * j
                dp[i] = min(dp[i], dp[i - j * j] + 1)
                j += 1

        return dp[n]

## LeetCode 322. 零钱兑换

[在线刷题](https://codefun2000.com/p/P4092)

本题和上一题本质一样，考虑定义:

$f(i)$ 代表组成整数$i$的最少硬币个数

转移:枚举最后一个硬币的大小，从子状态的最小值中转移:

$f(i) = f(i - coins[i]) + 1$

转移的时候注意：

边界条件:$f(0) = 0$ , $f(i) = -1 , i >0$   。因为一开始先默认所有面额都无法组成

class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        # dp[i] 表示组成金额 i 所需的最少硬币个数
        # amount + 1 表示一个不可能达到的较大值，因为最多只需要 amount 个 1 元硬币
        dp = [amount + 1] * (amount + 1)

        # 金额 0 不需要任何硬币
        dp[0] = 0

        # 从小到大枚举每个金额
        for i in range(1, amount + 1):
            # 枚举最后一个使用的硬币面额
            for coin in coins:
                # 只有当前金额 i 能放下这个硬币时，才能从 i - coin 转移过来
                if i >= coin:
                    dp[i] = min(dp[i], dp[i - coin] + 1)

        # 如果最终仍然是不可达状态，返回 -1
        if dp[amount] > amount:
            return -1
        return dp[amount]

## LeetCode 139. 单词拆分

**思路**

这题思路和上面两题模型是一模一样的。

bool wordBreak(char* s, char** wordDict, int wordDictSize) {
    int n = 0;

    // 计算字符串长度
    while (s[n] != '\0') {
        n++;
    }

    // dp[i] 表示字符串 s 的前 i 个字符，是否可以由字典中的单词拼接出来
    bool* dp = (bool*)malloc(sizeof(bool) * (n + 1));

    for (int i = 0; i <= n; i++) {
        dp[i] = false;
    }

    // 空串可以被成功拼接，作为后续转移的起点
    dp[0] = true;

    // 枚举前缀长度 i，判断 s[0:i] 是否可以被拼接
    for (int i = 1; i <= n; i++) {
        // 枚举最后一次切分的位置 j
        for (int j = 0; j < i; j++) {
            if (!dp[j]) {
                continue;
            }

            // 枚举字典中的每个单词，判断它是否等于 s[j:i]
            for (int k = 0; k < wordDictSize; k++) {
                char* word = wordDict[k];
                int len = 0;

                while (word[len] != '\0') {
                    len++;
                }

                if (len != i - j) {
                    continue;
                }

                bool same = true;
                for (int p = 0; p < len; p++) {
                    if (s[j + p] != word[p]) {
                        same = false;
                        break;
                    }
                }

                // 如果前 j 个字符可以被拼接，并且 s[j:i] 在字典中
                // 那么前 i 个字符也可以被拼接
                if (same) {
                    dp[i] = true;
                    break;
                }
            }

            // 找到一种切分方式即可退出
            if (dp[i]) {
                break;
            }
        }
    }

    bool ans = dp[n];
    free(dp);

    return ans;
}

**1.题目问什么，我们定义什么状态**

定义$dp(i)$代表以$i$为结尾的最长的有效括号子串长度。

**转移：**

如果$s[i] = ($ , 那么 $dp(i) = 0$。 **因为一个合法的括号序列的右端点一定要是一个右括号**。

如果$s[i] = )$ ，结构如下图所式：

![](/file/2/Oummv6aSUGhBMMcSoJtJy.png =90%x)



**说明**：考虑以第$i - 1$个位置为结尾的最长括号序列（也就是图中红色省略号所代表的区域）的左侧，令其下标为$j=i - dp_{i-1} - 1$：

如果$s[j]$ 是右括号，那么**无法**和第$i$个位置的右括号进行匹配。

如果$s[j]$ 是左括号，那么可以和第$i$个位置的右括号进行匹配。此时$j$的左侧可能还能拼接更长的合法括号序列（也就是图中绿色省略号）。

根据贪心的思想，要拼就拼最长的，所以直接拼接上$dp_{j-1}$。

那么总共的长度就是两段括号子序列的长度加上$2$ ，也就是这一对新匹配的括号的长度。

即：$dp_i = dp_{i-1}+2+dp_{i-dp_{i-1}-2}$

    def longestValidParentheses(self, s: str) -> int:
        n = len(s)

        # dp[i] 表示以 s[i] 结尾的最长有效括号长度
        dp = [0] * n
        ans = 0

        # 从第二个字符开始枚举右端点
        for i in range(1, n):
            # 有效括号子串的右端点一定是右括号
            if s[i] == ")":
                # inner 表示以 i - 1 结尾的最长有效括号长度
                inner = dp[i - 1]

                # j 是可能和当前右括号 s[i] 匹配的左括号位置
                j = i - inner - 1

                # 如果 j 没有越界，并且 s[j] 是左括号，说明可以匹配

                        dp[i] += dp[j - 1]

                    # 更新答案

## LeetCode 152. 乘积最大子数组

[在线刷题](https://codefun2000.com/p/P4095)

给你一个整数数组$nums$ ，请你找出数组中乘积最大的非空连续 子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 $32$-位整数。

**样例输入 1**

```
2 3 -2 4
```

**样例输出 1**

```
6
```

子数组$[2,3]$有最大乘积66。

**提示：**

- $1 <= nums.length <= 2 * 10^4$
- $-10 <= nums[i] <= 10$
- $nums$ 的任何子数组的乘积都保证是一个 $32$-位 整数

**思路**

**1.题目问什么，我们定义什么状态**

学习了 LeetCode 53. 最大子数组和 过后，下意识的我们会定义$dp(i)$ 代表以$i$为结尾的最大乘积。

但是本题有个重要的问题是：**数组中可能有负数！**

例如:$[-10,5,-10,...]$  ， 此时对于$dp(3)$ 而言 , 它应该是让 $-10 * (-10 * 5) = 500$ 才是最大的 ，而不是$-10 * 5 = -50$

也就是说：当$a_i < 0$ 时，我们应该是**贪心的 让 以$i - 1$ 为结尾的最小乘积** 乘上 $a_i$ 才变成**最大乘积。**

换句话说，在每一个点，我们不仅要知道最大乘积，还需要额外计算一个最小乘积，让之后的不管是正数还是负数能够正确计算结果。

所以这里我们定义一个二维状态:

定义$dp(i,0/1)$代表以$i$为结尾的最大/最小乘积。

**转移**

**思想：要么不拼，要拼就拼最值的**

当$a_i > 0$ 时, 

$dp(i,0) = max(dp(i - 1 , 0) * a_i , a_i)$

$dp(i,1) = min(dp(i - 1 , 1) * a_i , a_i)$

当$a_i < 0$ 时,

$dp(i,0) = max(dp(i - 1 , 1) * a_i , a_i)$

$dp(i,1) = min(dp(i - 1 , 0) * a_i , a_i)$

**优化：**

观察上式：$a_i$ 和 $dp(i-1,0),  dp(i - 1 , 1)$ 之间的组合情况就两种，可以两者取最值来得到转移，**这样不用判断数值的正负性了。**

 $dp(i,0) = max(dp(i - 1 , 0) * a_i , dp(i - 1 , 1) * a_i , a_i)$

 $dp(i,1) = min(dp(i - 1 , 0) * a_i , dp(i - 1 , 1) * a_i , a_i)$

    def maxProduct(self, nums: List[int]) -> int:
        # maxProd 表示以当前位置结尾的最大乘积
        # minProd 表示以当前位置结尾的最小乘积
        maxProd = nums[0]
        minProd = nums[0]

        # ans 记录所有位置结尾的最大乘积中的最大值

            maxProd = curMax
            minProd = curMin

        cur_max = nums[0]
        cur_min = nums[0]

            cur_min = tmp_min

### 面试问答

**1.这道题的思路是什么？**

动态规划。考虑“以当前位置结尾”的最优解，由于有负数，负数乘上最小值反而可能变成最大值，所以不能只维护一个最大乘积，还要同时维护一个最小乘积。我们定义两个状态，分别表示以第 i 个位置结尾的最大乘积和最小乘积。转移时，当前位置要么自己单独成段，要么接在前面的最大乘积后面，要么接在前面的最小乘积后面，三种情况分别取最大和最小即可。这样无论当前数是正数、负数还是 0，都能统一处理。最后答案就是所有位置结尾时最大乘积里的最大值。时间复杂度是 O(n)，空间复杂度可以优化到 O(1)。
