## 01背包：LeetCode 416. 分割等和子集

[在线刷题](https://codefun2000.com/p/P4096)

给你一个 只包含正整数 的 非空 数组 $nums$。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

**输入** 

```
1 5 11 5
```

**输出** 

```
true
```

**提示：**

- $1 <= nums.length <= 200$
- $1 <= nums[i] <= 100$

**思路**
问题转化：给定一个数组，是否能从数组中选出一个子集，使得其和恰好为数组总和的一半。（这样没被选中的那一半一定也是 数组总和的一半，两者的和相等）

**1.问什么定义什么**

$dp_{i,j}$ 代表 **是否能从前$i$个数中选出一个子集使得其和恰好为$j$**

$dp_{i,j} \in \{True , False\}$

如果同学们初次见这个定义，可能会比较难理解，似懂非懂。塔子哥从实际例子出发带大家理解这个算法：

给定数组:$[4 , 3 , 2 , 6]$  , 我们看看这几个状态👇

![](/file/2/7jtw978xvFhP1D8j5_iwD.png)




①$dp_{4,5}$ 所描述的是这样的**局面** : 从$[4 , 3 , 2 , 6]$ 中选择一个子集使得和 恰好等于 $5$

$dp_{4 , 5} = True$ ，因为我们可以选择$3+2$ 或者 $4 + 6$ 

②而$dp_{4,16}=False$ , 因为$4+3+2+6 = 15$ ， 即使我们把所有元素选上都不能达到$16$

③$dp_{3,7}$ 所描述的是这样的**局面** : 从$[4 , 3 , 2]$ 中选择一个子集使得和 恰好等于 $7$

$dp_{3 , 7} = True$ ，可以选择$4+3$

④$dp_{3,1}=False$ , 因为所有元素都大于$1$

**转移:考虑最后一个元素的状态**

1.子集中**不允许**包含第$i$个数，则等价于 从前$i - 1$个数中选出一个子集使得其和恰好为$j$ :

$dp_{i - 1, j} \rightarrow dp_{i , j}$

2.子集中**必须**包含第$i$个数，则等价于 从前$i - 1$个数中选出一个子集使得其和恰好为$j - a_i$ :

$dp_{i - 1, j - a_i } \rightarrow dp_{i , j}$

总结：$dp_{i , j} =dp_{i - 1 , j}\ || \ dp_{i - 1 , j - a_i}$

注意：若$j < a_i$ , 则第二种情况无法得到转移:
$dp_{i , j} = dp_{i - 1, j}$

**还是从实际例子出发：**

计算$dp_{4,8}$  ， 考虑最后一个元素$6$ 是否被选中。

如果选$6$ ， 则等价于从前$3$个数里选出$2$ ， 局面演化成:$dp_{3,2}$ 

如果不选$6$ ， 则等价于从前$3$个数里选出$8$ ， 局面演化成:$dp_{3,8}$

如下图所式：

![](/file/2/SQ-fBjnQTdwOsU1oHtHJc.png)





可以继续对$dp_{3,2}$ 进行拆分，当拆分到$dp_{2,0}$ 的时候，触发**边界条件**：$dp_{2,0} = True$ 。 因为我们什么都不选就可以组成$0$的空间👇

![](/file/2/-LgI768yS5Kanj0s9wrHX.png)


此时我们就知道$dp_{4,8} = True$ 了。

接着可以自然归纳出本题的边界条件:$dp_{i,0} = True , i \in [0,n]$

**为什么这样递推一定是正确的？** 

1.因为$dp_{i,j}$ 的定义考虑了前$i$个数每个数选或不选的所有$2^i$种情况

2.转移考虑将这$2^i$个选择状态 按照 $a_i$ 是否被选中**不重不漏的**划分成两种局面。


**这个问题为什么叫做01背包？** 

这个问题可以看成：给定$n$个体积分别为$a_1,a_2,...,a_n$的物品，问是否能选出一些物品使得其恰好装进体积为$k$的背包。

这类问题就是背包问题。


**计算顺序的确定**

一切动态规划计算顺序的核心都是：在计算本状态的时候，依赖的所有状态都有被求出来。

而动态规划在计算机层面本质上就是在填数组，所以不妨从二维数组的视角去看该问题

举个例子，$dp_{3,3}$ 依赖的是它上一行的$dp_{2,1}$ 和 $dp_{2,3}$ 。 所以只要上一行计算出来了，下一行的所有元素也能被计算出来了👇

![](/file/2/yzIEyaIl1JpQq7BADxj7Z.png =80%x)




即逐行计算是一种可行的方案👇

![](/file/2/6aBtPUZ-ezBbTwpMwi2e7.png)

```python
class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        # 先计算数组总和，如果总和是奇数，不可能分成两个相等子集
        total = sum(nums)
        if total % 2 != 0:
            return False

        # 目标变成：能否从 nums 中选出一些数，使得和恰好为 total / 2
        target = total // 2
        n = len(nums)

        # dp[i][j] 表示能否从前 i 个数中选出一个子集，使得和恰好为 j
        dp = [[False] * (target + 1) for _ in range(n + 1)]

        # 边界：什么都不选，就可以组成 0
        for i in range(n + 1):
            dp[i][0] = True

        # 逐行计算，每次考虑第 i 个数选或不选
        for i in range(1, n + 1):
            for j in range(target + 1):
                # 不选当前元素 nums[i - 1]
                dp[i][j] = dp[i - 1][j]

                # 如果当前容量 j 放得下 nums[i - 1]，可以尝试选择它
                if j >= nums[i - 1]:
                    dp[i][j] = dp[i][j] or dp[i - 1][j - nums[i - 1]]

        return dp[n][target]
```

```c
bool canPartition(int* nums, int numsSize) {
    // 先计算数组总和，如果总和是奇数，不可能分成两个相等子集
    int total = 0;
    for (int i = 0; i < numsSize; i++) {
        total += nums[i];
    }

    if (total % 2 != 0) {
        return false;
    }

    // 目标变成：能否从 nums 中选出一些数，使得和恰好为 total / 2
    int target = total / 2;

    // dp[i][j] 表示能否从前 i 个数中选出一个子集，使得和恰好为 j
    bool** dp = (bool**)malloc(sizeof(bool*) * (numsSize + 1));
    for (int i = 0; i <= numsSize; i++) {
        dp[i] = (bool*)malloc(sizeof(bool) * (target + 1));
        for (int j = 0; j <= target; j++) {
            dp[i][j] = false;
        }
    }

    // 边界：什么都不选，就可以组成 0
    for (int i = 0; i <= numsSize; i++) {
        dp[i][0] = true;
    }

    // 逐行计算，每次考虑第 i 个数选或不选
    for (int i = 1; i <= numsSize; i++) {
        for (int j = 0; j <= target; j++) {
            // 不选当前元素 nums[i - 1]
            dp[i][j] = dp[i - 1][j];

            // 如果当前容量 j 放得下 nums[i - 1]，可以尝试选择它
            if (j >= nums[i - 1]) {
                dp[i][j] = dp[i][j] || dp[i - 1][j - nums[i - 1]];
            }
        }
    }

    bool ans = dp[numsSize][target];

    for (int i = 0; i <= numsSize; i++) {
        free(dp[i]);
    }
    free(dp);

    return ans;
}
```

**滚动数组优化**

从刚刚的图示，我们很容易看出来： 计算到第$i$行的时候，只依赖第$i - 1$ 行的结果，前$i - 2$ 行已经没有任何作用。

![](/file/2/WqSXVy8R9IEsDDZ0hxiSO.png)


所以可以使用两个数组，来回”倒腾“的去转移：每次计算完$dp[1][:]$ 之后，把整行移动到$dp[0][:]$ ，为下一次循环做准备。

```python
class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        # 计算数组总和，如果总和是奇数，一定不能分成两个相等子集
        total = sum(nums)
        if total % 2 != 0:
            return False

        # 目标是选出一些数，使它们的和等于 total 的一半
        target = total // 2
        n = len(nums)

        # dp[i % 2][j] 表示从前 i 个数中，是否能选出和为 j 的子集
        # 由于第 i 行只依赖第 i - 1 行，所以只保留两行滚动计算
        dp = [[False] * (target + 1) for _ in range(2)]

        # 和为 0 时，什么都不选就是一种合法方案
        dp[0][0] = True

        # 逐个考虑每个数字
        for i in range(1, n + 1):
            for j in range(target + 1):
                # 不选当前数字 nums[i - 1]
                dp[i % 2][j] = dp[(i - 1) % 2][j]

                # 如果当前容量 j 放得下 nums[i - 1]，可以尝试选择它
                if j >= nums[i - 1]:
                    dp[i % 2][j] = dp[i % 2][j] or dp[(i - 1) % 2][j - nums[i - 1]]

        return dp[n % 2][target]
```

```c
            dp[i % 2][j] = dp[(i - 1) % 2][j];

            // 如果当前容量 j 放得下 nums[i - 1]，可以尝试选择它
            if (j >= nums[i - 1]) {
                dp[i % 2][j] = dp[i % 2][j] || dp[(i - 1) % 2][j - nums[i - 1]];
            }
        }
    }

    bool ans = dp[numsSize % 2][target];

    free(dp[0]);
    free(dp[1]);
    free(dp);

    return ans;
}
```

![](/file/2/AVHWhN9XkWxxzdIm3QDAU.png)




**说明：**

假设现在已经计算完第$i - 1$轮循环，此时$f[j]$ 的意义是$dp[i-1][j]$ ， 对于任意的$j$都成立👇

![](/file/2/5uwB1kPhgrVmg4GoGem0J.png)



此时内层循环发生第一次转移:$f[n] = f[n]\ ||\ f[n - a_i]$ ， 它等于是将$f[n]$ 的含义从$dp[i - 1][n]$ 推向了 $dp[i][n]$


此时$f[1\rightarrow n-1]$ 的含义依旧还是$dp[i - 1][1 \rightarrow n - 1]$ 👇

![](/file/2/oT1s-QFdR7YGl34XRTJKt.png)


所以在循环的过程中，我们可以理解$j$是一个分割线，分割线左边的区域还是$dp[i - 1]$的含义 ，而分割线右边的区域含义已经变成了$dp[i]$  👇

![](/file/2/3qJtyajmGK6HAHpE9YCVm.png)


**为什么要倒序循环**？因为 左边的元素$f[j - a_i]$ 的含义不能先于$f[j]$  从$dp[i - 1]$ 变成 $dp[i]$ 。 

换句话说，如果正序循环，那么一个数将可以被选很多次，而不是只能选$1$次。

### 面试问答

**1. 本题的核心思路是什么？（二维朴素做法思路）**

经典的01背包问题，可以转化为"子集和"问题。首先计算数组总和 S，若S 为奇数则直接返回 False；否则判断能否从数组中选出一个子集，使其和恰好等于和的一半。定义 DP 数组，令 $dp_{i,j}$ 表示"是否能从前 $i$个元素中选出一个子集使得其和恰好为 $j$ 。 状态转移时，对于第 $i$ 个元素 分两种情况：不选它则继承 $dp_{i-1,j}$，选它则 继承$dp_{i-1,j-a_i}$ ， 两个情况取或即可。最终返回 $dp_{n,S/2}$ 即为答案。

时间复杂度 $O(n \cdot S)$，空间复杂度为 $O(n \cdot S)$

**思路**

在上一章里我们使用了线性dp的思路解决本题。而本题同时也可以使用完全背包模型解决。

本问题可以建模成：

给定一个物品数组$a_1,a_2,...,a_n$ 分别代表它们的容积。使用最少的物品装满容积为$amount$的背包。**每个物品有无限个**

**做过了第一题，大家先自行想想本题的状态和转移。**


状态，不难想到：

$dp_{i , j}$ 代表使用前$i$个物品，装满容积为$j$的背包，所需要的最少物品个数。

转移： 

选不选$a_i$来转移。

不选:$dp_{i-1,j} \rightarrow dp_{i,j}$


选:$dp_{i,j - a_i } \rightarrow dp_{i,j}$

**这也是和01背包的重要区别：**因为物品有无限个，所以选中$a_i$ 之后，手上的物品集合还是$\{a_1,a_2,...,a_i\}$

转移:$dp_{i , j} = min(dp_{i - 1 , j} , dp_{i , j - a_i} + 1)$

边界条件:$dp_{i,0} = 0$

$dp_{i,k} = +\infty , k > 0$

因为一开始时我们应当假定任意容积的物品都组成不了。

换句话说，要求最小值，一开始数组应该定义为最大值。

```python
class Solution:
    def coinChange(self, coins, amount):
        # dp[j] 表示凑满金额 j 所需要的最少硬币个数
        # amount + 1 表示一个不可能达到的较大值
        dp = [amount + 1] * (amount + 1)

        # 金额为 0 时，不需要任何硬币
        dp[0] = 0

        # 完全背包：每种硬币可以使用无限次
        for coin in coins:
            # 原地优化后，从 coin 开始从小到大枚举金额
            for j in range(coin, amount + 1):
                # 选当前硬币：dp[j - coin] + 1
                # 不选当前硬币：dp[j]
                dp[j] = min(dp[j], dp[j - coin] + 1)

        # 如果仍然是初始的大值，说明无法凑出 amount
        if dp[amount] > amount:
            return -1
        return dp[amount]
```
