[在线刷题](https://codefun2000.com/p/P4017)

给定一个二叉树的根节点$root$ ，输出它的中序遍历 。

**输入** 

```
4 1 2 1 2
```

**输出** 

```
4
```

**思路**

中序遍历的定义: 对于一棵二叉树，先遍历左子树，再访问根节点，最后遍历右子树。

也就是按 `左子树 -> 根节点 -> 右子树` 的顺序遍历。

所以以我们只需要写一个递归函数 dfs(root)：

1.如果当前节点为空，直接返回。

2.先递归遍历左子树。

3.再把当前节点的值加入答案。

4.最后递归遍历右子树。

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def inorderTraversal(root):
    result = []

    def dfs(node):
        # 如果当前节点为空，直接返回
        if not node:
            return

        # 先递归遍历左子树
        dfs(node.left)

        # 再访问根节点
        result.append(node.val)

        # 最后递归遍历右子树
        dfs(node.right)

    dfs(root)
    return result
```

```cpp
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> result;

        // 从根节点开始进行中序遍历
        dfs(root, result);

        return result;
    }

private:
    void dfs(TreeNode* node, vector<int>& result) {
        // 如果当前节点为空，直接返回
        if (node == nullptr) {
            return;
        }

        // 先递归遍历左子树
        dfs(node->left, result);

        // 再访问根节点
        result.push_back(node->val);

        // 最后递归遍历右子树
        dfs(node->right, result);
    }
};
```

### 面试问答

**1. 本题的核心思路是什么？**

递归实现中序遍历,即先遍历左子树，再访问根节点，最后遍历右子树。
