## LeetCode 215. 数组中的第K个最大元素

[在线刷题](https://codefun2000.com/p/P4027)

给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。  

请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。  

你必须设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

**输入** 

```
6 2
3 2 1 5 6 4
```

**输出** 

```
5
```

**1.朴素的大根堆排序做法**

学习过[实战2:堆排序](https://codefun2000.com/codenote/hot100/P0043#%E5%AE%9E%E6%88%982%EF%BC%9A%E5%A0%86%E6%8E%92%E5%BA%8F)的同学应该不难想到一个淳朴的做法：用大根堆排序，然后连续取堆顶的$k$个元素，最后一个取出来的就是答案。

但是堆排序的复杂度是$O(nlogn)$的。
#code-switcher
```python
class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        # 使用 heapq.nlargest 找到前 k 大的元素
        # 前 k 大元素中的最后一个就是第 k 大元素
        return heapq.nlargest(k, nums)[-1]
```

```cpp
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        // 使用大根堆存储所有元素
        priority_queue<int> heap;

        // 将数组元素加入大根堆
        for (int num : nums) {
            heap.push(num);
        }

        // 弹出前 k - 1 大的元素
        for (int i = 1; i < k; i++) {
            heap.pop();
        }

        // 堆顶元素就是第 k 大的元素
        return heap.top();
    }
};
```

```javascript
var findKthLargest = function (nums, k) {
    // 使用大根堆存储所有元素
    let heap = [];

    // 向上调整
    function heapifyUp(index) {
        while (index > 0) {
            let parent = Math.floor((index - 1) / 2);

            if (heap[parent] >= heap[index]) {
                break;
            }

            let temp = heap[parent];
            heap[parent] = heap[index];
            heap[index] = temp;

            index = parent;
        }
    }

    // 向下调整
    function heapifyDown(index) {
        while (true) {
            let left = index * 2 + 1;
            let right = index * 2 + 2;
            let largest = index;

            if (left < heap.length && heap[left] > heap[largest]) {
                largest = left;
            }

            if (right < heap.length && heap[right] > heap[largest]) {
                largest = right;
            }

            if (largest === index) {
                break;
            }

            let temp = heap[index];
            heap[index] = heap[largest];
            heap[largest] = temp;

            index = largest;
        }
    }

    // 插入元素到大根堆
    function push(x) {
        heap.push(x);
        heapifyUp(heap.length - 1);
    }

    // 弹出堆顶最大值
    function pop() {
        let ans = heap[0];

        heap[0] = heap[heap.length - 1];
        heap.pop();

        if (heap.length > 0) {
            heapifyDown(0);
        }

        return ans;
    }

    // 将数组元素加入大根堆
    for (let num of nums) {
        push(num);
    }

    // 弹出前 k - 1 大的元素
    for (let i = 1; i < k; i++) {
        pop();
    }

    // 堆顶元素就是第 k 大的元素
    return heap[0];
};
```

```c
void heapifyDown(int* heap, int size, int index) {
    // 向下调整，维护大根堆
    while (1) {
        int left = index * 2 + 1;
        int right = index * 2 + 2;
        int largest = index;

        if (left < size && heap[left] > heap[largest]) {
            largest = left;
        }

        if (right < size && heap[right] > heap[largest]) {
            largest = right;
        }

        if (largest == index) {
            break;
        }

        int temp = heap[index];
        heap[index] = heap[largest];
        heap[largest] = temp;

        index = largest;
    }
}

void push(int* heap, int* size, int x) {
    // 将元素加入大根堆
    heap[*size] = x;
    (*size)++;

    heapifyUp(heap, *size - 1);
}

int pop(int* heap, int* size) {
    // 弹出堆顶最大值
    int ans = heap[0];

    heap[0] = heap[*size - 1];
    (*size)--;

    if (*size > 0) {
        heapifyDown(heap, *size, 0);
    }

    return ans;
}

int findKthLargest(int* nums, int numsSize, int k) {
    // 使用大根堆存储所有元素
    int* heap = (int*)malloc(sizeof(int) * numsSize);
    int size = 0;

    // 将数组元素加入大根堆
    for (int i = 0; i < numsSize; i++) {
        push(heap, &size, nums[i]);
    }

    // 弹出前 k - 1 大的元素
    for (int i = 1; i < k; i++) {
        pop(heap, &size);
    }

    // 堆顶元素就是第 k 大的元素
    int ans = heap[0];

    free(heap);
    return ans;
}
```

**2.残酷的末位淘汰法(小根堆)**

考虑已经知道前$i$个数中的前$k$大元素，当我们新增第$i + 1$个元素$a_{i+1}$进来之后，共$k + 1$ 个元素，此时应当删除哪个元素呢？

举个例子:假设一开始枚举完前$k$个元素，那么里面的每一个元素都是 前$k$大的元素，不需要删任何数👇

![](/file/2/yUD0aw8Ngyn4t67GPcL2I.png =80%x)



**考虑数组新增到了第$k + 1$个元素，此时必须有一个数得滚蛋，因为我们只要前$k$大的元素**。此时显然就是把最小值删了👇

![](/file/2/l9y0J2Jn1m8XIIz5ACQqX.png =80%x)



下一步，第$k + 2$个位置的元素加入进来之后，这里面的最小值也可以直接被删除。

整个过程结束，剩下的自然是整个数组的前$k$大元素，输出最小值即可👇

![](/file/2/5_jjx5UGbjuKxN9tMUoH1.png =80%x)



所以做法很简单：从左到右枚举这个数组，同时维护大小为$k$的**小根堆**（即若堆大小超过$k$,则删除堆顶最小值）。结束的时候堆里存储了数组的前$k$大元素，而堆顶就是答案。

这里我们再看一个完整的动画来进一步理解该思想👇

```python
class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        # 构建一个大小为 k 的小根堆
        heap = []

        # 遍历数组中的每个元素
        for num in nums:
            # 将当前元素加入小根堆
            heapq.heappush(heap, num)

            # 如果堆的大小超过 k，就弹出堆顶最小元素
            if len(heap) > k:
                heapq.heappop(heap)

        # 堆中剩下的是前 k 个最大的元素，堆顶就是第 k 大的元素
        return heap[0]
```

**小总结**

这个方法就像互联网大厂中的**末尾淘汰机制**。

**hc**固定就$k$个 ， 而公司非得招$k + 1$ 个人，然后用所谓的末尾淘汰法，把能力最差的踢掉，同时再招一个进来。如此往复，迭代一段时间之后，公司里剩下的就是能力"前$k$大"的人了...

#warning-box

**这个做法的优势是？**

**1.复杂度更低**

由于我们只需要维护$k$个元素，复杂度为$O(nlogk)$

**2.应用常见：处理流式数据**

应用场景是：假设线上有一个流式数据（你可以理解为数组长度不是固定的，是逐渐增长的），要求任意时刻下的第$k$大元素。


### 面试问答

**1. 本题的核心思路是什么？**

从左到右枚举这个数组，同时维护大小为$k$的小根堆，时刻维护当前遍历过的元素集合中的前$k$大元素。每次新增一个元素则将元素插入到堆中，结束的时候堆顶就是答案。复杂度为$O(nlogk)$

**2. 这个做法的应用场景是？**

假设线上有一个流式数据，要求任意时刻下的第$k$大元素。此时可以维护大小为$k$的小根堆。每一个时刻可以以$O(logk)$的复杂度来查询所有数据中的第$k$大元素。

## LeetCode 347. 前K个高频元素

[在线刷题](https://codefun2000.com/p/P4028)

给你一个整数数组 $nums$ 和一个整数 $k$ ，请你返回其中出现频率前 $k$ 高的元素。你可以按任意顺序返回答案。

**输入** 

```
6 2
1 1 1 2 2 3
```

**输出** 

```
1 2
```

**思路**

本题和上一题极其类似。我们只需要先用哈希统计元素出现频次。然后对(频次,值)二元组用固定大小为$k$的小根堆维护，最后输出小根堆的前$k$小的值即可

```python
import heapq
from typing import List

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        # 统计每个元素的频率
        freq = {}
        for num in nums:
            freq[num] = freq.get(num, 0) + 1

        # 构建一个大小为k的小根堆
        heap = []
        for num, freq in freq.items():
            heapq.heappush(heap, [freq, num])
            if len(heap) > k:
                heapq.heappop(heap)

        # 堆中剩下的就是前k个高频元素，堆顶就是第k个高频元素
        return [item[1] for item in heap]
```

```cpp
class Solution {
public:
    vector<int> topKFrequent(vector<int>& nums, int k) {
        // 统计每个元素的频率
        unordered_map<int, int> freq;
        for (int num : nums) {
            freq[num]++;
        }

        // 构建一个大小为k的小根堆
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> heap;

        for (auto& item : freq) {
            int num = item.first;
            int count = item.second;

            heap.push({count, num});
            if ((int)heap.size() > k) {
                heap.pop();
            }
        }

        // 堆中剩下的就是前k个高频元素，堆顶就是第k个高频元素
        vector<int> ans;
        while (!heap.empty()) {
            ans.push_back(heap.top().second);
            heap.pop();
        }

        return ans;
    }
};
```

```java
class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        // 统计每个元素的频率
        Map<Integer, Integer> freq = new HashMap<>();

        for (int num : nums) {
            freq.put(num, freq.getOrDefault(num, 0) + 1);
        }

        // 构建一个大小为k的小根堆
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> {
            if (a[0] != b[0]) {
                return a[0] - b[0];
            }
            return a[1] - b[1];
        });

        for (Map.Entry<Integer, Integer> item : freq.entrySet()) {
            int num = item.getKey();
            int count = item.getValue();

            heap.offer(new int[]{count, num});
            if (heap.size() > k) {
                heap.poll();
            }
        }

        // 堆中剩下的就是前k个高频元素，堆顶就是第k个高频元素
        int[] ans = new int[k];
        int index = 0;

        while (!heap.isEmpty()) {
            ans[index++] = heap.poll()[1];
        }

        return ans;
    }
}
```

```c
typedef struct {
    int num;
    int count;
} Node;

int less(Node a, Node b) {
    if (a.count != b.count) {
        return a.count < b.count;
    }
    return a.num < b.num;
}

void heapifyUp(Node* heap, int index) {
    while (index > 0) {
        int parent = (index - 1) / 2;

        if (!less(heap[index], heap[parent])) {
            break;
        }

        Node temp = heap[index];
        heap[index] = heap[parent];
        heap[parent] = temp;

        index = parent;
    }
}

void heapifyDown(Node* heap, int size, int index) {
    while (1) {
        int left = index * 2 + 1;
        int right = index * 2 + 2;
        int smallest = index;

        if (left < size && less(heap[left], heap[smallest])) {
            smallest = left;
        }
        if (right < size && less(heap[right], heap[smallest])) {
            smallest = right;
        }

        if (smallest == index) {
            break;
        }

        Node temp = heap[index];
        heap[index] = heap[smallest];
        heap[smallest] = temp;

        index = smallest;
    }
}

void heapPush(Node* heap, int* size, Node node) {
    heap[*size] = node;
    (*size)++;
    heapifyUp(heap, *size - 1);
}

void heapPop(Node* heap, int* size) {
    heap[0] = heap[*size - 1];
    (*size)--;

    if (*size > 0) {
        heapifyDown(heap, *size, 0);
    }
}

int* topKFrequent(int* nums, int numsSize, int k, int* returnSize) {
    // 统计每个元素的频率
    int capacity = numsSize * 4 + 1;
    int* keys = (int*)malloc(sizeof(int) * capacity);
    int* counts = (int*)malloc(sizeof(int) * capacity);
    int* used = (int*)malloc(sizeof(int) * capacity);

    for (int i = 0; i < capacity; i++) {
        used[i] = 0;
        counts[i] = 0;
    }

    for (int i = 0; i < numsSize; i++) {
        int num = nums[i];
        int index = getHash(num) % capacity;

        while (used[index] && keys[index] != num) {
            index++;
            if (index == capacity) {
                index = 0;
            }
        }

        if (!used[index]) {
            used[index] = 1;
            keys[index] = num;
            counts[index] = 1;
        } else {
            counts[index]++;
        }
    }

    // 构建一个大小为k的小根堆
    Node* heap = (Node*)malloc(sizeof(Node) * (k + 1));
    int heapSize = 0;

    for (int i = 0; i < capacity; i++) {
        if (!used[i]) {
            continue;
        }

        Node node;
        node.num = keys[i];
        node.count = counts[i];

        heapPush(heap, &heapSize, node);
        if (heapSize > k) {
            heapPop(heap, &heapSize);
        }
    }

    // 堆中剩下的就是前k个高频元素，堆顶就是第k个高频元素
    int* ans = (int*)malloc(sizeof(int) * k);
    *returnSize = k;

    for (int i = 0; i < k; i++) {
        ans[i] = heap[i].num;
    }

    free(keys);
    free(counts);
    free(used);
    free(heap);

    return ans;
}
```

## LeetCode 295. 数据流的中位数

[在线刷题](https://codefun2000.com/p/P4083)

中位数是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

- 例如 $arr = [2,3,4]$ 的中位数是 $3$ 。
- 例如 $arr = [2,3]$ 的中位数是 $(2 + 3) / 2 = 2.5$ 。

实现 $MedianFinder$ 类:

- $MedianFinder() $初始化 $MedianFinder$对象。
- $void\  addNum(int\  num)$ 将数据流中的整数 $num$添加到数据结构中。
- $double\  findMedian()$ 返回到目前为止所有元素的中位数。与实际答案相差 $10^{-5}$以内的答案将被接受。

**输入** 

```
5
add 1
add 2
median
add 3
median
```

**输出** 

```
1.5
2.0
```

- $-10^5 <= num <= 10^5$
- 在调用 $findMedian$之前，数据结构中至少有一个元素
- 最多 $5 * 10^4$ 次调用 $addNum$和 $findMedian$

**思路**

使用两个堆，大根堆维护左半边的元素（也就是小于中位数的那些数），小根堆维护右半边的元素（也就是大于等于中位数的那些数）

查询的时候，如果两个堆的大小相等，此时数组长度为偶数，则取两者的堆顶的平均值，否则取大小更大的那个堆的堆顶即可👇

```python
import heapq

class MedianFinder:
    def __init__(self):
        self.left = [] # 大根堆
        self.right = [] # 小根堆

    def addNum(self, num):
        # 先插入到正确的堆
        if self.right and num >= self.right[0]:
            heapq.heappush(self.right, num)
        else:
            heapq.heappush(self.left, -num)

        # 平衡两个堆
        if len(self.left) > len(self.right) + 1:
            heapq.heappush(self.right, -heapq.heappop(self.left))
        if len(self.right) > len(self.left) + 1:
            heapq.heappush(self.left, -heapq.heappop(self.right))

    def findMedian(self):
        # 如果堆不平衡，则输出个数多的堆的堆顶
        if len(self.left) > len(self.right):
            return -self.left[0]
        elif len(self.left) < len(self.right):
            return self.right[0]

        # 如果堆平衡，此时元素总数为偶数，输出两个堆顶的平均值
        else:
            return (-self.left[0] + self.right[0]) / 2
```

**1. 本题的核心思路是什么？**

本题核心思路：使用两个堆，一个堆存储小于等于中位数的元素，一个堆存储大于中位数的元素。

1.当插入一个元素时，先插入到正确的堆，然后平衡两个堆，保证两个堆的元素个数差不超过1。

2.当查找中位数时，如果堆不平衡，则输出个数多的堆的堆顶。

3.如果堆平衡，此时元素总数为偶数，输出两个堆顶的平均值。
