回溯的本质是暴力递归求解所有情况，所以也可以称作暴力搜索。

而一个问题的所有情况，通常表现为两种基础形式：**排列 / 组合。**

**1.组合型回溯 (搜索空间大小通常是$2^n$)**

**2.排列型回溯(搜索空间大小通常是$n!$)**

接下来我们分这两类讲述回溯思想。高效起见，在分析过程中会介绍回溯的基础和思想，这里不放大段枯燥定义了。

**解题技巧**：大家如果决定用回溯解题之前，先想清楚这个问题是排列还是组合，**也就是它的所有可能情况是$2^n$种还是$n!$ 种。**

## LeetCode 78. 子集

[在线刷题](https://codefun2000.com/p/P4022)

给你一个整数数组$nums$，数组中的元素互不相同 。返回该数组所有可能的子集（幂集）。

解集不能包含重复的子集。按照任意顺序返回解集。

**输入** 

```
1 2 3
```

**输出** 

```
1
1 2
1 2 3
1 3 
2
2 3
3
```

- $1 <= nums.length <= 10$
- $-10 <= nums[i] <= 10$
- $nums$中的所有元素互不相同

**思路**

先想清楚本题所有可能情况:共$2^n$ 种， 因为每个数可以选可以不选。

回溯本质是在生成一颗二叉树（知不知道这玩意也无所谓），向左走是选中数字，向右走是不选中数字。

具体的，$[1,2,3]$的所有情况是如何被代码计算得到的？

1.二叉树的第一层代表选第一个数的状态，第二层代表选第二个数的状态以此类推。最终选出的结果是最后一层所对应的结果。

2.由于每个节点会分裂出两个节点，所以到第三层的时候有$2^3=8$种结果，能够计算出所有情况

这个过程中，我们发现每个节点都存储了一个值`curr`，这个值是当前生成的子集状态，每次将这个子集传递给下方的节点，让之后的节点在此基础上进行操作，最后叶子节点（也就是最后一层的节点）才能够得到最终结果。

对应到代码里就很好理解了，递归时存储两个参数:

`index` 记录当前走到第几层了。不记录这个我们无法知道这个回溯什么时候该结束。

`curr` 记录当前子集状态。

每次分两路递归，要么选`nums[index]` , 要么不选`nums[index]`

终止条件：当走到第$n + 1$ 层，代表考虑完了所有数字的选择状态，说明一个完整的子集已经构造完成。

```python
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        # res 用来存储所有子集
        res = []
        # curr 表示当前正在构造的子集状态
        curr = []
        n = len(nums)

        def dfs(index):
            # 当 index 走到 n，说明所有数字都已经考虑完，得到一个完整子集
            if index == n:
                res.append(curr[:])
                return

            # 选择 nums[index]，继续往下一层递归
            curr.append(nums[index])
            dfs(index + 1)

            # 回溯，撤销选择
            curr.pop()

            # 不选择 nums[index]，继续往下一层递归
            dfs(index + 1)

        dfs(0)
        return res
```

```c
void dfs(int* nums, int numsSize, int index, int* curr, int currSize, int** res, int* returnSize, int** returnColumnSizes) {
    // 当 index 走到 numsSize，说明所有数字都已经考虑完，得到一个完整子集
    if (index == numsSize) {
        res[*returnSize] = (int*)malloc(sizeof(int) * currSize);
        for (int i = 0; i < currSize; i++) {
            res[*returnSize][i] = curr[i];
        }
        (*returnColumnSizes)[*returnSize] = currSize;
        (*returnSize)++;
        return;
    }

    // 选择 nums[index]，继续往下一层递归
    curr[currSize] = nums[index];
    dfs(nums, numsSize, index + 1, curr, currSize + 1, res, returnSize, returnColumnSizes);

    // 不选择 nums[index]，继续往下一层递归
    dfs(nums, numsSize, index + 1, curr, currSize, res, returnSize, returnColumnSizes);
}

int** subsets(int* nums, int numsSize, int* returnSize, int** returnColumnSizes) {
    // 子集总数为 2^n
    int total = 1 << numsSize;

    int** res = (int**)malloc(sizeof(int*) * total);
    *returnColumnSizes = (int*)malloc(sizeof(int) * total);
    *returnSize = 0;

    // curr 表示当前正在构造的子集状态
    int* curr = (int*)malloc(sizeof(int) * numsSize);

    dfs(nums, numsSize, 0, curr, 0, res, returnSize, returnColumnSizes);

    return res;
}
```

#code-switcher
特别注意：代码里，在选择`nums[index]` 的递归调用前后分别有一个`push` 和 `pop`的操作，这个是回溯的精髓。

例如在第二层到第三层的时候，往下走选中，`curr.push(nums[index])` , 得到一种结果之后，**还需要往上回到过去的状态** ,需要把之前`push` 过的内容给`pop`掉。**所以这个操作总是对称出现的**

![](/file/2/FboX-noBSoFJvdq-kiNXn.png =80%x)

**注意：**递归时所占用的空间复杂度不是$O(2^n)$的。因为有回溯的操作，当一个节点（一次递归函数）算完之后，它会`return` 返回上一层，此时**内存会被当场销毁，给下一次递归复用这片空间**。换句话说，回溯的计算过程是串行计算的，每次只调用一个递归函数，而不是同时运行$2^n$个递归函数。

递归时总的空间开销是递归树的高度（又称栈深），为$O(n)$的。因为递归的瞬间，当前递归函数会暂存于内存中，等后续递归完成，返回之后才销毁。

### 面试问答

**1. 本题的核心思路是什么？**

这道题的核心思路是**回溯枚举所有选择情况**。对于每个数字来说，都只有两种决策：选或者不选，所以递归依次处理每个位置的“选 / 不选”状态，最终到递归出口一共会形成 $2^n$ 种结果。递归过程中，用 `index` 表示当前处理到第几个数，用 `curr` 记录当前已经构造出的子集；每次递归分成两路，一路把当前数字加入子集，另一路跳过当前数字。当所有数字都处理完时，就说明一个完整的子集已经生成出来了。

时间复杂度是 $O(n·2^n)$，因为一共有 $2^n$ 个子集，而每个子集在加入答案时最多需要拷贝 $n$ 次；空间复杂度是 $O(n)$，其中`curr`数组占用$O(n)$空间，递归栈的空间开销为$O(n)$。



## LeetCode 39. 组合总和

[在线刷题](https://codefun2000.com/p/P4071)

给定一个无重复元素的整数数组 `candidates` 和一个目标整数 `target`，找出 `candidates` 中可以使数字和为 `target` 的所有不同组合，并以任意顺序输出。  

`candidates` 中的同一个数字可以被无限制重复选取。如果至少一个数字的被选数量不同，则两种组合视为不同组合。

保证不同组合的数量少于 150 个。

**输入**

```
4 7
2 3 6 7
```

**输出**

```
2 2 3
7
```

**思路**

这题和上一题的区别在于：

1.每个数可以选多次

2.选出来的数字的总和需要恰好为`target`

**每个数可以选多次：**

回想一下，上一题枚举了一个元素的所有可能状态：选或不选。

而本题中，每个元素可能状态是：

选0个，选1个，选2个，...，选$\frac{target}{candidates[i]}$ 个。

> 因为有总和限制，且每个数都是正数，所以一个数不可能选得超过目标值。

**不难想到，上一题是二路递归，而本题是$k$路递归。**

所以在函数中，我们需要用一个循环来枚举选多少个`candidates[index]`来调用递归，同时参数需要额外记录一个当前总和`total` 
#code-switcher
```python
class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        # ans 用来存储所有满足总和为 target 的组合
        ans = []
        n = len(candidates)

        # index 表示当前枚举到哪个数，total 表示当前组合的总和，curr 表示当前组合
        def dfs(index, total, curr):
            # 如果已经考虑完所有候选数
            if index == n:
                # 只有当前总和恰好等于 target，才是合法组合
                if total == target:
                    ans.append(curr[:])
                return

            # 剩余还需要凑出的数值
            rest = target - total
            # 当前数字最多可以选 rest // candidates[index] 次
            up = rest // candidates[index]

            # 枚举当前数字选 0 次、1 次、2 次 ... up 次
            for cnt in range(up + 1):
                # 把当前数字选 cnt 次加入 curr
                for _ in range(cnt):
                    curr.append(candidates[index])

                # 继续递归考虑下一个数字
                dfs(index + 1, total + cnt * candidates[index], curr)

                # 回溯，撤销刚才加入的 cnt 个数字
                for _ in range(cnt):
                    curr.pop()

        dfs(0, 0, [])
        return ans
```

#code-switcher
**递归完全体做法！**

上一种写法里，我们在当前层直接做一件事：枚举当前数字选 `0` 个、`1` 个、`2` 个、...

一个更"递归"的思路是：当前层不再一次性决定“选几个”，而是每次只决定一件事：**当前这个数，是再选一个，还是彻底不选了**。

这样一来，原本“选 0 个、1 个、2 个、3 个...”这种多路递归，**就被拆成了递归层数更多的二路递归：**

1.不选这个数了，直接看下一个数

2.选一个这个数，然后**留在当前下标**，下一层再继续决定还要不要再选。

```python
                return

                dfs(index, total + candidates[index])

                # 回溯，撤销这次选择
                curr.pop()

        # 从下标 0 开始，当前总和为 0
        dfs(0, 0)
```

### 面试问答

**1. 本题的核心思路是什么？**

这道题的核心思路是**回溯**，从左到右依次考虑每个数字。当递归到某个数字时，有两种决策：一种是**不再使用当前数字**，直接去处理下一个数字；另一种是**使用当前数字一次**，然后继续停留在当前位置，下一层再决定要不要继续选它。这样就把所有可能的组合搜索出来。

时间复杂度是所有可行解的长度之和，本题比较难估计精准的复杂度，比较宽松的上界是$O(n * 2^n)$ 





## LeetCode 131. 分割回文串

[在线刷题](https://codefun2000.com/p/P4074)

给你一个字符串 $s$，请你将 $s$ 分割成一些 子串，使每个子串都是回文串 。返回 $s$ 所有可能的分割方案。

**输入** 

```
aab
```

**输出** 

```
a a b
aa b
```

**思路**

回文串的判定：判断`str` 和 `reversed(str)` 是否全等。

本题所有可能情况是$2^{n-1}$ 。 **考虑分割的本质是：在两个相邻的字符中间插入一个隔板 。**   

一个长度为$n$的字符串有$n-1$个相邻位置可以插入或者不插入隔板。

例如:`aab`  可以分割成 `aab` , `aa|b` ,`a|ab` ,`a|a|b`  共$2^{3-1} = 2^2 = 4$ 种情况。

所以不难发现，这个题的递归，每一层枚举的是某个隔板。`index` 指向的是隔板的位置，而不是某个字符的位置。

而由于我们要判断某一段子字符串是不是回文串，**而子串由当前的隔板 + 上一个隔板唯一确定。**

所以我们递归的时候除了`index` ， 还需要记录上一个隔板的位置`last_index` ， 每次决定分割的时候，判断子串是否为回文串，如果是回文串则放入`curr`里。

```python
class Solution:
    def partition(self, s: str) -> List[List[str]]:
        # result 用来存储所有合法的分割方案
        result = []
        # curr 表示当前已经切出来的回文子串
        curr = []
        n = len(s)

        # 判断一个字符串是否是回文串
        def is_palindrome(sub):
            return sub == sub[::-1]

        def dfs(index, last_index):
            # index 走到 n，说明所有隔板都已经考虑完，得到一个完整方案
            if index == n:
                result.append(curr[:])
                return

            # 当前子串由上一个隔板 last_index 和当前隔板 index 唯一确定
            sub = s[last_index + 1:index + 1]

            # 如果当前子串是回文串，才可以在这里放隔板
            if is_palindrome(sub):
                curr.append(sub)
                dfs(index + 1, index)
                curr.pop()

            # 如果不是最后一个位置，可以选择当前不放隔板，继续往后看
            if index != n - 1:
                dfs(index + 1, last_index)

        dfs(0, -1)
        return result
```

```c
void dfs(char* s, int n, int index, int lastIndex, char** curr, int currSize, char**** result, int* returnSize, int** returnColumnSizes) {
    // index 走到 n，说明所有隔板都已经考虑完，得到一个完整方案
    if (index == n) {
        (*result)[*returnSize] = (char**)malloc(sizeof(char*) * currSize);
        (*returnColumnSizes)[*returnSize] = currSize;

        for (int i = 0; i < currSize; i++) {
            int len = strlen(curr[i]);
            (*result)[*returnSize][i] = (char*)malloc(sizeof(char) * (len + 1));
            strcpy((*result)[*returnSize][i], curr[i]);
        }

        (*returnSize)++;
        return;
    }

    // 当前子串由上一个隔板 lastIndex 和当前隔板 index 唯一确定
    int left = lastIndex + 1;
    int len = index - lastIndex;

    // 如果当前子串是回文串，才可以在这里放隔板
    if (isPalindrome(s, left, index)) {
        curr[currSize] = (char*)malloc(sizeof(char) * (len + 1));

        for (int i = 0; i < len; i++) {
            curr[currSize][i] = s[left + i];
        }
        curr[currSize][len] = '\0';

        dfs(s, n, index + 1, index, curr, currSize + 1, result, returnSize, returnColumnSizes);

        free(curr[currSize]);
    }

    // 如果不是最后一个位置，可以选择当前不放隔板，继续往后看
    if (index != n - 1) {
        dfs(s, n, index + 1, lastIndex, curr, currSize, result, returnSize, returnColumnSizes);
    }
}

    int n = strlen(s);
```

**1. 本题的核心思路是什么？**

回溯枚举所有分割方案。枚举 `n-1` 个可以切割的位置，每个位置考虑切或者不切来得到所有可能的分割方案。递归时用 `index` 表示当前考虑到哪个隔板位置，用 `last_index` 记录上一个隔板所在的位置，每当决定在当前位置分割时，就取出这段子串，若是回文串则把它加入当前方案并继续向下递归，最终找出所有由回文子串组成的分割方案。

时间复杂度:总共可能有$2^n$种分割方案，而递归时每次分割之前都需要判断子串是否为回文串，这部分开销为$O(n)$ ， 分步相乘得到$O(n * 2^n)$。

空间复杂度:$O(n)$。其中`curr`数组开销为$O(n)$，递归栈的空间开销为$O(n)$。

**前置知识：如何判断一个括号序列合法？**

考虑将`(` 视作 `1` , `)` 视作 `-1`  ，这样一对括号的匹配可以被视作`1-1 = 0` 

那么满足以下**两个条件**，这个括号序列就是合法的：

1.**整体角度**：整个序列的总和需要是`0` ，不然就代表左右括号个数不一致，**这样不管内部实际是什么顺序，都不可能匹配的。**

2.从左往右累加`cnt` 的过程中，任意时刻需要满足`cnt >= 0`  。 **因为如果`cnt < 0` 就代表此刻前缀中右括号多于左括号，那不管后续括号是什么状态，这个多出来的右括号都不可能得到匹配了。**

例如:`(()))...` ,  扫描到第5个位置，此时$cnt = -1$  ，  代表第五个位置的右括号没有得到匹配。

**思路**

$n$对括号，代表总长度为$2n$。

一个最简单的思路是直接递归搜索这$2n$个位置的括号状态，在递归出口`index == 2 * n`的时候判断整个括号的合法性。

每个位置可以填两种括号 ， 复杂度为$0(2^{2n} * n)$

**剪枝优化**

回顾我们的前置知识不难发现，其实在递归生成的过程中，一旦当前的生成不合法，我们没必要继续递归了。

比如:`curr = ())???`  ， 生成出来的前缀已经不合法的情况下，往后再怎么填写括号，到递归出口时都一定被判不合法。

所以其实上述代码有大量的无意义计算！**而优化很简单，考虑在`dfs`的过程中，边生成边保证当前括号状态合法。**

具体的：`dfs`的过程中，维护一个参数`cnt` 代表当前生成的括号序列的总和，**通过`cnt`的大小限制递归与判断合法性。**

1.限制递归：当`cnt == 0` 时只能生成`(`  

2.递归出口`index == 2 * n`时，当`cnt == 0` 时才能统计答案。

**这样以来，`check`函数被我们消融到`dfs`函数的过程中，同时还减少了大量计算**

```python

            if index == 2 * n:

                curr.pop()

        # 从第 0 个位置开始搜索，初始未匹配左括号数量为 0
        dfs(0, 0)
        return res
```

**面试问答**

**1. 本题的核心思路是什么？**

**回溯**。我们从左到右递归生成长度为 `2n` 的括号序列，每个位置都可以尝试放左括号或右括号。递归过程中，用 `cnt` 记录当前左括号比右括号多多少个，也就是当前还未匹配的左括号数量；如果 `cnt == 0`，说明当前不能再放右括号，只能放左括号。等递归到长度 `2n` 时，只有 `cnt == 0` 的序列才是合法答案。时间复杂度是 $O(2^{2n} × n)$，空间复杂度是 **O(n)**。



ps:严谨来讲，有效答案数是卡特兰数: $C_n = \frac{1}{n+1}\binom{2n}{n}$ ，  所以复杂度是$O(\frac{n}{n+1}\binom{2n}{n})$，不过这个面试基本不会问的。 按上面的回答也不会错。因为大$O$标志描述的是复杂度上界。只是$2^n \times n$ 不够贴近算法真实上界。

说人话就是：$1 \leq 2$ 和 $1 \leq 10$ 都是对，显然前者描述更准确一些，但后者也不能算错啊。
