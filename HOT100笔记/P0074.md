给定一个二叉搜索树的根节点 $root$ ，和一个整数 $k$，请你设计一个算法查找其中第 $k$ 小的元素（从$1$ 开始计数）。

**输入** 

```
5 1
3 1 4 null 2
```

**输出** 

```
1
```

**思路**

```python
class Solution:
    def kthSmallest(self, root, k):
        # BST 的中序遍历结果是升序序列
        # 所以中序遍历访问到的第 k 个节点就是第 k 小的元素
        self.k = k
        self.ans = -1

        def dfs(node):
            # 如果节点为空，或者已经找到答案，直接返回
            if node is None or self.k == 0:
                return

            # 先遍历左子树
            dfs(node.left)

            # 如果左子树已经找到答案，直接返回
            if self.k == 0:
                return

            # 访问当前节点，计数减 1
            self.k -= 1

            # 当前节点就是第 k 小的元素
            if self.k == 0:
                self.ans = node.val
                return

            # 最后遍历右子树
            dfs(node.right)

        dfs(root)
        return self.ans
```

### 面试问答

**1. 本题的核心思路是什么？**

BST 的中序序列是递增的。对 BST 做中序遍历时，第 `k` 次访问到的节点值就是第 `k` 小元素。
