[在线刷题](https://codefun2000.com/p/P4065)

给定一个二叉树的根节点 $root$，和一个整数 $targetSum$，求该二叉树里节点值之和等于 $targetSum$ 的 路径的数目。

**路径** 不需要从根节点开始，也不需要在叶子节点结束，但是路径方向必须是向下的（只能从父节点到子节点）

**样例1**

**输入** 

```
11
10 5 -3 3 2 null 11 3 -2 null 1
8
```

**输出** 

```
3
```

**说明**

和等于$ 8$ 的路径有 $3$ 条，如图所示

**样例2**

**输入** 

```
13
5 4 8 11 null 13 4 7 2 null null 5 1
22
```

**输出** 

```
3
```

**提示**

- 二叉树的节点个数的范围是$[0,1000]$
- $-10^9 <= Node.val <= 10^9$ 
- $-1000 <= targetSum <= 1000$


**思路**

## 解法1：自顶向下的DFS

枚举每个节点作为根节点，向下搜寻所有的路径中满足 ： 和恰好为`target`的路径。

此时我们需要两个递归函数，一个用来枚举所有点，一个用来寻找合法路径👇

1.`dfs(node)`函数 : 用来枚举所有节点作为根节点 

2.`findTarget(node , cur_sum)`函数 : 用来从某个点出发，向下搜索所有合法的路径,其中`cur_sum` 记录当前经过的路径的和

```python
class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> int:
        # 记录满足条件的路径数量
        ans = 0

        # 从 node 出发，向下搜索路径和等于 targetSum 的路径
        def findTarget(node, curSum):
            nonlocal ans

            # 空节点直接返回
            if node is None:
                return

            # 当前路径加入当前节点的值
            curSum += node.val

            # 如果当前路径和等于目标值，答案加一
            if curSum == targetSum:
                ans += 1

            # 继续向左右子树搜索
            findTarget(node.left, curSum)
            findTarget(node.right, curSum)

        # 枚举每个节点作为路径起点
        def dfs(node):
            # 空节点直接返回
            if node is None:
                return

            # 以当前节点作为起点，向下寻找合法路径
            findTarget(node, 0)

            # 继续枚举左右子树中的节点作为起点
            dfs(node.left)
            dfs(node.right)

        dfs(root)
        return ans
```

**复杂度分析**

**考虑一个问题：每个节点总共会被遍历多少次**？

不难想到，一个节点有多少个祖先节点，他就会被访问多少次。因为每个祖先节点的findTarget 都会访问到这个节点。

换句话说，一个节点的遍历次数等价于 它的深度。 那么总计算次数$T(n) = \sum_{i = 1}^{n} Depth(i)$

最差情况为：这棵树是一条链，那么所有节点的深度加起来恰好是:$1+2+3+4+...+n$ , 则复杂度为$O(n^2)$



### 面试问答

**1. 本题的核心思路是什么？**

双重 DFS：外层 `dfs` 枚举每个节点作为路径起点，内层 `findTarget` 从这个起点往下搜所有路径，并用当前累计和判断是否等于 `targetSum`。同一个节点会被多个祖先起点反复访问，最坏（链状树）复杂度会到 `O(n^2)`。

#warning-box

如果这颗二叉树退化成一条链，那么问题就变成：在一个数组上寻找一段子区间的和恰好为$target$。

恰好对应[Leetcode 560.和为k的子数组](https://codefun2000.com/codenote/hot100/P0017#leetcode-560.%E5%92%8C%E4%B8%BAk%E7%9A%84%E5%AD%90%E6%95%B0%E7%BB%84)  ， 所以先搞清楚这道前置题。

和 560 题一样的套路：一边遍历二叉树，一边用哈希表 cnt 统计当前访问的这条路径的前缀和的出现次数。设从根到终点 node 的路径和为 s，那么起点的个数就是 cnt[s−targetSum]，加入答案。

```python id="49cfbz"
from collections import defaultdict
from typing import Optional

class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> int:
        # 最终答案：满足和为 targetSum 的路径数量
        ans = 0

        # cnt 记录当前路径上，每个前缀和出现的次数
        cnt = defaultdict(int)

        # 空路径前缀和为 0，出现 1 次
        # 这样可以统计从根节点开始的合法路径
        cnt[0] = 1

        def dfs(node, s):
            nonlocal ans

            # 空节点直接返回
            if node is None:
                return

            # 当前根到 node 的前缀和
            s += node.val

            # 如果之前出现过前缀和 s - targetSum
            # 说明从那个位置之后到当前节点的路径和正好是 targetSum
            ans += cnt[s - targetSum]

            # 把当前前缀和加入哈希表，供子树使用
            cnt[s] += 1

            # 继续递归左右子树
            dfs(node.left, s)
            dfs(node.right, s)

            # 回溯：离开当前节点时，撤销当前前缀和
            # 保证 cnt 中只保留当前递归路径上的信息
            cnt[s] -= 1

        # 从根节点开始，初始前缀和为 0
        dfs(root, 0)

        return ans
```

```c id="jgj4m4"
int ans;
int targetSumValue;

long long keys[2005];
int values[2005];
int cntSize;

// 查询某个前缀和出现了多少次
int getCount(long long key) {
    for (int i = 0; i < cntSize; i++) {
        if (keys[i] == key) {
            return values[i];
        }
    }
    return 0;
}

// 给某个前缀和的出现次数加上 delta
void addCount(long long key, int delta) {
    for (int i = 0; i < cntSize; i++) {
        if (keys[i] == key) {
            values[i] += delta;
            return;
        }
    }

    keys[cntSize] = key;
    values[cntSize] = delta;
    cntSize++;
}

// dfs(node, s)：当前走到 node，根到 node 父节点的前缀和为 s
void dfs(struct TreeNode* node, long long s) {
    // 空节点直接返回
    if (node == NULL) {
        return;
    }

    // 当前根到 node 的前缀和
    s += node->val;

    // 如果之前出现过前缀和 s - targetSum
    // 说明从那个位置之后到当前节点的路径和正好是 targetSum
    ans += getCount(s - targetSumValue);

    addCount(s, 1);

    // 保证计数表中只保留当前递归路径上的信息
    addCount(s, -1);
}

    // 从根节点开始，初始前缀和为 0
    dfs(root, 0);

    return ans;
}
```

### 面试问答

**1. 本题的核心思路是什么？**

树上的前缀和。DFS 过程中维护当前前缀和 `s`，并用哈希表 `cnt` 记录“当前递归路径上”每个前缀和出现次数。到当前节点时，能形成合法路径的起点数就是 `cnt[s - targetSum]`，直接加到答案里。然后把 `s` 加入 `cnt` 递归子树，回溯时再 `cnt[s] -= 1` 撤销影响。这样每个节点只处理一次，时间复杂度 `O(n)`。
