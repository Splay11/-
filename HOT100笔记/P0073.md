[在线刷题](https://codefun2000.com/p/P4060)

给你一个二叉树的根节点 `root` ，判断其是否是一个有效的二叉搜索树。

有效二叉搜索树定义如下：

- 节点的左子树只包含小于当前节点的数。
- 节点的右子树只包含大于当前节点的数。
- 所有左子树和右子树自身必须也是二叉搜索树。

**样例1**

![img](https://assets.leetcode.com/uploads/2020/12/01/tree1.jpg)

**输入**

```
2 1 3
```

**输出**

```
true
```

**样例2**

![img](https://assets.leetcode.com/uploads/2020/12/01/tree2.jpg)

**输入**

```
5 1 4 null null 3 6
```

**输出**

```
false
```

**说明**

根节点的值是 `5` ，但是右子节点的值是 `4`。  
虽然 `4 > 1`，但它并不大于根节点 `5`，违反了 BST 全局有序性。

**思路**

# 方法1：中序遍历 + 序列校验

利用前置知识中所学习到的性质：对一棵 BST 做中序遍历，得到的序列一定是**严格递增**的。

所以我们只要中序遍历整棵树，得到它的中序序列，然后扫一遍判断有序性即可。

class Solution:
    def isValidBST(self, root):
        # seq 用来保存中序遍历得到的节点值
        seq = []

        # 中序遍历：左子树 -> 当前节点 -> 右子树
        def inorder(node):
            if node is None:
                return

            # 先遍历左子树
            inorder(node.left)

            # 再访问当前节点
            seq.append(node.val)

            # 最后遍历右子树
            inorder(node.right)

        inorder(root)

        # 有效二叉搜索树的中序遍历结果必须严格递增
        for i in range(len(seq) - 1):
            if seq[i] >= seq[i + 1]:
                return False

        return True
```

# 方法2(优化)：中序遍历 + 相邻元素校验

其实我们并不需要实际的得到中序序列。只要我们能确保相邻元素的有序性即可。

**具体到递归的场景下，对于一个节点`node` , 我们如何知道它在中序序列中的上一个元素呢**？

每个节点，它在中序序列中的上一个元素 **一定存在于左子树当中，且是最后一个访问的元素**。所以我们可以先递归完左子树，然后判断左子树的最后一次访问的元素 和 当前节点的元素的大小关系。

class Solution:
    def __init__(self):
        self.prev = None
        self.ok = True

    def isValidBST(self, root):
        # prev 记录中序遍历中上一个访问到的节点值
        self.prev = None
        self.ok = True

        # 中序遍历：左子树 -> 当前节点 -> 右子树
        def dfs(node):
            # 如果已经发现不合法，可以直接返回
            if node is None or not self.ok:
                return

            # 先递归左子树
            dfs(node.left)

            # 当前节点必须严格大于中序遍历的上一个节点
            if self.prev is not None and node.val <= self.prev:
                self.ok = False
                return

            # 更新上一个访问到的节点值
            self.prev = node.val

            # 再递归右子树
            dfs(node.right)

        dfs(root)
        return self.ok
```

## 面试问答

**1. 本题的核心思路是什么？**

利用 BST 的中序遍历严格递增性质：边遍历边比较当前值与前一个值(前一个值的赋值是在左子树递归到最后一个节点赋值成`prev`的)，一旦出现 `<=` 就不是 BST。
