# 枚举朴素解法

这道题的正解是 $单调栈$（柱状图最大矩形），但是我们用朴素解法 $向左右扩展$ 也能在考试时拿到一定的分数。

题意：对数组 $nums$ 的任意连续子数组，其「组合质量系数」为「子数组最小值 $\times$ 长度」。求所有连续子数组中该值的最大值。

朴素做法：把每个下标 $i$ 当作子数组里的最小值，尽量向左、向右扩展，直到遇到比 $nums[i]$ 更小的元素为止。此时以 $nums[i]$ 为最小值的最长区间长度为 $R-L+1$，系数为 $nums[i]\times(R-L+1)$，对所有 $i$ 取最大。

$n$ 较小时 $O(n^2)$ 可通过；当 $n$ 接近 $10^5$ 时会超时，需要后面的单调栈做法。
## 枚举解法
#code-switcher
```python
def max_quality(nums):
    n = len(nums)
    ans = 0
    for i in range(n):
        # 以 nums[i] 为最小值，向左扩展
        L = i
        while L > 0 and nums[L - 1] >= nums[i]:
            L -= 1
        # 向右扩展
        R = i
        while R + 1 < n and nums[R + 1] >= nums[i]:
            R += 1
        area = nums[i] * (R - L + 1)
        if area > ans:
            ans = area
    return ans


def main():
    n = int(input())
    nums = []
    for _ in range(n):
        nums.append(int(input()))
    print(max_quality(nums))


if __name__ == "__main__":
    main()
```

# 正确解法

## 题目分析

核心观察：最优子数组一定可以写成「以某个位置 $i$ 为最小值」。对每个 $i$，需要求出它作为最小值时能向左、向右延伸到哪里。

用单调栈在 $O(n)$ 内求出边界：

* $left[i]$：左侧最近的**严格小于** $nums[i]$ 的位置（没有则为 $-1$）
* $right[i]$：右侧最近的**小于等于** $nums[i]$ 的位置（没有则为 $n$）

则宽度为 $right[i]-left[i]-1$，系数为 $nums[i]\times$ 宽度。对所有 $i$ 取最大即可。这与「柱状图中最大的矩形」同一思路。

求边界时：

* 从左到右维护单调递增栈，得到 $left$
* 从右到左维护单调栈，得到 $right$（一侧用严格、一侧用非严格，避免相等高度被重复计算）

## 复杂度分析

* 时间复杂度：$O(n)$，每个下标最多进栈、出栈一次。
* 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
def max_quality(nums):
    n = len(nums)
    left = [-1] * n   # 左侧最近严格更小
    right = [n] * n   # 右侧最近小于等于

    # 求 left：单调递增栈
    stack = []
    for i in range(n):
        while stack and nums[stack[-1]] >= nums[i]:
            stack.pop()
        left[i] = stack[-1] if stack else -1
        stack.append(i)

    # 求 right
    stack.clear()
    for i in range(n - 1, -1, -1):
        while stack and nums[stack[-1]] > nums[i]:
            stack.pop()
        right[i] = stack[-1] if stack else n
        stack.append(i)

    ans = 0
    for i in range(n):
        width = right[i] - left[i] - 1
        area = nums[i] * width
        if area > ans:
            ans = area
    return ans


def main():
    n = int(input())
    nums = []
    for _ in range(n):
        nums.append(int(input()))
    print(max_quality(nums))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Deque;
import java.util.Scanner;

public class Main {

    static int maxQuality(int[] nums) {
        int n = nums.length;
        int[] left = new int[n];
        int[] right = new int[n];
        Arrays.fill(left, -1);
        Arrays.fill(right, n);

        Deque<Integer> stack = new ArrayDeque<>();
        // 求 left：左侧最近严格更小
        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && nums[stack.peek()] >= nums[i]) {
                stack.pop();
            }
            left[i] = stack.isEmpty() ? -1 : stack.peek();
            stack.push(i);
        }

        stack.clear();
        // 求 right：右侧最近小于等于
        for (int i = n - 1; i >= 0; i--) {
            while (!stack.isEmpty() && nums[stack.peek()] > nums[i]) {
                stack.pop();
            }
            right[i] = stack.isEmpty() ? n : stack.peek();
            stack.push(i);
        }

        int ans = 0;
        for (int i = 0; i < n; i++) {
            int width = right[i] - left[i] - 1;
            int area = nums[i] * width;
            if (area > ans) {
                ans = area;
            }
        }
        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = sc.nextInt();
        }
        System.out.println(maxQuality(nums));
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

int max_quality(const vector<int>& nums) {
    int n = (int)nums.size();
    vector<int> left(n, -1);  // 左侧最近严格更小
    vector<int> right(n, n);  // 右侧最近小于等于
    vector<int> st;

    // 求 left
    for (int i = 0; i < n; i++) {
        while (!st.empty() && nums[st.back()] >= nums[i]) {
            st.pop_back();
        }
        left[i] = st.empty() ? -1 : st.back();
        st.push_back(i);
    }

    // 求 right
    st.clear();
    for (int i = n - 1; i >= 0; i--) {
        while (!st.empty() && nums[st.back()] > nums[i]) {
            st.pop_back();
        }
        right[i] = st.empty() ? n : st.back();
        st.push_back(i);
    }

    long long ans = 0;
    for (int i = 0; i < n; i++) {
        long long width = right[i] - left[i] - 1;
        long long area = 1LL * nums[i] * width;
        if (area > ans) {
            ans = area;
        }
    }
    return (int)ans;
}

int main() {
    int n;
    cin >> n;
    vector<int> nums(n);
    for (int i = 0; i < n; i++) {
        cin >> nums[i];
    }
    cout << max_quality(nums) << "\n";
    return 0;
}
```
