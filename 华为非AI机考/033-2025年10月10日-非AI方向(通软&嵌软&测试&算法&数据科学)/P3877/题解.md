## 解题思路

本题需将 $N$ 个旅行团（成员数存于数组 $P[0\dots N-1]$）按 ID 连续分配到**恰好** $M$ 节非空车厢中，满足各车厢乘客总数（连续段和）的最大值 $X$ 与最小值 $Y$ 的差异 $X-Y$ 最小，并输出该最优方案下的 $X$。

采用**动态规划**算法解决。
首先预处理前缀和数组 $prefix[0\dots N]$，其中 $prefix[i]$ 表示前 $i$ 个旅行团的总人数（$prefix[0]=0$）。

定义状态：

* $dp[k][i]$ 表示用恰好 $k$ 节车厢分配前 $i$ 个旅行团所能达到的**最小差异** $D=X-Y$；
* $maxp[k][i]$ 表示在该最小差异下对应的**最大车厢人数** $X$。

初始化（$k=1$）：
对于所有 $1\leq i\leq N$，$dp[1][i]=0$，$maxp[1][i]=prefix[i]$（单个车厢差异为 $0$）。

转移方程（$k\geq2$，$k\leq i\leq N$）：

枚举最后一段的起点 $j$（$k-1\leq j<i$），

新段和 $S=prefix[i]-prefix[j]$，

前 $k-1$ 段的 $prev_x=maxp[k-1][j]$，$prev_d=dp[k-1][j]$，$prev_y=prev_x-prev_d$

则新差异 $n_d=\max(prev_x,S)-\min(prev_y,S)$

新最大值 $n_x=\max(prev_x,S)$。
若 $n_d<dp[k][i]$，更新 $dp[k][i]=n_d$、$maxp[k][i]=n_x$；

若 $n_d=dp[k][i]$，则 $maxp[k][i]=\min(maxp[k][i],n_x)$（差异相同时取较小 $X$）。

特殊情况：若 $M=1$，直接返回总和 $prefix[N]$。
最终答案为 $maxp[M][N]$。该 DP 保证了最优子结构：任意前缀的最优差异划分在扩展时仍为全局最优。

## 复杂度分析

时间复杂度：$O(M N^2)$

空间复杂度：$O(M N)$（$dp$ 和 $maxp$ 二维数组）。

## 代码实现

### Python

```python
import sys

# 外部函数：实现题面核心功能（动态规划计算最优X）
def compute_X(N, M, P):
    if M == 1:
        return sum(P)
    # 预处理前缀和
    prefix = [0] * (N + 1)
    for i in range(1, N + 1):
        prefix[i] = prefix[i - 1] + P[i - 1]
    INF = 10**18
    dp = [[INF] * (N + 1) for _ in range(M + 1)]      # 最小差异
    maxp_arr = [[0] * (N + 1) for _ in range(M + 1)]  # 对应X
    # 初始化1节车厢
    for i in range(1, N + 1):
        dp[1][i] = 0
        maxp_arr[1][i] = prefix[i]
    # DP转移
    for k in range(2, M + 1):
        for i in range(k, N + 1):
            min_d = INF
            best_x = INF
            for j in range(k - 1, i):
                S = prefix[i] - prefix[j]
                prev_d = dp[k - 1][j]
                if prev_d == INF:
                    continue
                prev_x = maxp_arr[k - 1][j]
                prev_min = prev_x - prev_d
                n_min = min(prev_min, S)
                n_max = max(prev_x, S)
                n_d = n_max - n_min
                if n_d < min_d:
                    min_d = n_d
                    best_x = n_max
                elif n_d == min_d:
                    if n_max < best_x:
                        best_x = n_max
            dp[k][i] = min_d
            maxp_arr[k][i] = best_x
    return maxp_arr[M][N]

# 主函数：输入输出
input = sys.stdin.read
data = input().split()
index = 0
N = int(data[index])
index += 1
M = int(data[index])
index += 1
P = [int(data[index + i]) for i in range(N)]
print(compute_X(N, M, P))
```

### Java

```java
import java.util.*;

public class Main {
    // 外部函数：实现题面核心功能（动态规划计算最优X）
    public static int computeX(int N, int M, int[] P) {
        if (M == 1) {
            int sum = 0;
            for (int p : P) sum += p;
            return sum;
        }
        // 预处理前缀和
        int[] prefix = new int[N + 1];
        for (int i = 1; i <= N; i++) {
            prefix[i] = prefix[i - 1] + P[i - 1];
        }
        final int INF = 2000000000;
        int[][] dp = new int[M + 1][N + 1];      // 最小差异
        int[][] maxpArr = new int[M + 1][N + 1]; // 对应X
        // 初始化dp和maxpArr
        for (int i = 0; i <= M; i++) {
            for (int j = 0; j <= N; j++) {
                dp[i][j] = INF;
            }
        }
        // 初始化1节车厢
        for (int i = 1; i <= N; i++) {
            dp[1][i] = 0;
            maxpArr[1][i] = prefix[i];
        }
        // DP转移
        for (int k = 2; k <= M; k++) {
            for (int i = k; i <= N; i++) {
                int minD = INF;
                int bestX = INF;
                for (int j = k - 1; j < i; j++) {
                    int S = prefix[i] - prefix[j];
                    int prevD = dp[k - 1][j];
                    if (prevD == INF) continue;
                    int prevX = maxpArr[k - 1][j];
                    int prevMin = prevX - prevD;
                    int nMin = Math.min(prevMin, S);
                    int nMax = Math.max(prevX, S);
                    int nD = nMax - nMin;
                    if (nD < minD) {
                        minD = nD;
                        bestX = nMax;
                    } else if (nD == minD) {
                        if (nMax < bestX) {
                            bestX = nMax;
                        }
                    }
                }
                dp[k][i] = minD;
                maxpArr[k][i] = bestX;
            }
        }
        return maxpArr[M][N];
    }

    // 主函数：输入输出
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int N = sc.nextInt();
        int M = sc.nextInt();
        int[] P = new int[N];
        for (int i = 0; i < N; i++) {
            P[i] = sc.nextInt();
        }
        System.out.println(computeX(N, M, P));
    }
}
```
