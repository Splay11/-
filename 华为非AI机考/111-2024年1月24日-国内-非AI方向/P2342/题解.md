## 题面描述:

在一款游戏中，玩家需要依次释放三种元素技能：火（`F`）、水（`W`）、土（`E`）。每个技能的基础能量值分别为：`F` 获得 `1` 点，`W` 获得 `2` 点，`E` 获得 `3` 点。技能释放时若与之前连续释放的相同技能产生共鸣，还会获得额外的共鸣奖励。具体而言，对于序列中的第 $i$ 个技能，如果它与紧邻的前一个技能相同，则奖励 `1` 点；如果与前两个技能都相同，则再奖励 `1` 点，依此类推。换言之，设第 $i$ 个技能之前有 $k$ 个连续相同的技能，则它额外获得 $k$ 点奖励。总能量为所有技能的基础能量与共鸣奖励之和。请计算给定技能序列的总能量。

## 思路：模拟遍历

由于string的长度只有1e4，可以直接暴力做，n^2也只有1e8，小常数1s内可以跑完。直接往前遍历有几个字符和它相同即可。

或者基于简单dp的方式，每个位置保存它前面与它相等且串联的字符数量，每个字符只需要看其是否与上一个字符相等即可，相等则加1，否则置为0。

### 题解

本题要求计算给定技能序列的总能量。每种技能对应不同的基础能量值，其中火（`F`）为1点，水（`W`）为2点，土（`E`）为3点。此外，当释放的技能与之前连续释放的相同技能产生共鸣时，会获得额外的共鸣奖励。具体来说，设第 $i$ 个技能之前有 $k$ 个连续相同的技能，则它额外获得 $k$ 点奖励。

由于字符串的最大长度为10,000，暴力算法的复杂度为O(n^2)，在最坏情况下的操作次数为1亿，这在1秒内是可以接受的。因此，我们可以采用暴力方式逐个比较字符，也可以基于动态规划的思想来优化。

以下是基于暴力法的实现思路：

1. 遍历字符串中的每一个技能字符。
2. 对于每个字符，向前遍历其之前的字符，判断是否与当前字符相同。
3. 若相同，则根据相同的数量增加奖励能量；若不相同，则停止继续向前查找。
4. 每个技能的基础能量值加到总能量中。
5. 输出最终总能量。


### JavaScript

```javascript
// 读取输入字符串
let s = readline(); 

// 初始化总能量
let ans = 0;

// 定义每种技能的基础能量值
let score = { "r": 1, "g": 2, "b": 3 };

// 遍历字符串中的每一个字符
for (let i = 0; i < s.length; i++) {
    // 内层循环向前查找与当前字符相同的字符
    for (let j = i - 1; j >= 0; j--) {
        // 如果当前字符与前面的字符相同
        if (s[i] == s[j]) {
            ans += 1; // 增加相同字符的共鸣奖励
        } else {
            break; // 如果不相同，则停止查找
        }
    }
    // 加上当前字符的基础能量值
    ans += score[s[i]];
}

// 输出最终总能量
print(ans);

```



### Java

```java
import java.util.HashMap;
import java.util.Map;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        // 创建一个Scanner对象，用于读取输入
        Scanner scanner = new Scanner(System.in);
        
        // 读取输入字符串
        String s = scanner.next();

        // 初始化总能量
        int ans = 0;

        // 定义每种技能的基础能量值
        Map<Character, Integer> score = new HashMap<>();
        score.put('r', 1); // 火(F)获得1点
        score.put('g', 2); // 水(W)获得2点
        score.put('b', 3); // 土(E)获得3点

        // 遍历字符串中的每一个字符
        for (int i = 0; i < s.length(); i++) {
            // 内层循环向前查找与当前字符相同的字符
            for (int j = i - 1; j >= 0; j--) {
                // 如果当前字符与前面的字符相同
                if (s.charAt(i) == s.charAt(j)) {
                    ans += 1; // 增加相同字符的共鸣奖励
                } else {
                    break; // 如果不相同，则停止查找
                }
            }
            // 加上当前字符的基础能量值
            ans += score.get(s.charAt(i));
        }

        // 输出最终总能量
        System.out.println(ans);
    }
}

```

### C++

```cpp
#include <iostream>
#include <string>
#include <map>

using namespace std;

int main() {
    // 读取输入字符串
    string s;
    cin >> s;

    // 初始化总能量
    int ans = 0;

    // 定义每种技能的基础能量值
    map<char, int> score = { {'r', 1}, {'g', 2}, {'b', 3} };

    // 遍历字符串中的每一个字符
    for (int i = 0; i < s.length(); i++) {
        // 初始化当前字符与前面相同的数量
        int sameCount = 0;
        
        // 向前遍历，判断当前字符与前面的字符是否相同
        for (int j = i - 1; j >= 0; j--) {
            if (s[i] == s[j]) {
                sameCount++; // 相同的字符数量增加
            } else {
                break; // 遇到不同的字符，停止查找
            }
        }

        // 将相同字符的数量加入总能量（相同数量会产生额外的共鸣奖励）
        ans += sameCount; // 共鸣奖励
        ans += score[s[i]]; // 当前字符的基础能量值
    }

    // 输出最终总能量
    cout << ans << endl;

    return 0;
}
