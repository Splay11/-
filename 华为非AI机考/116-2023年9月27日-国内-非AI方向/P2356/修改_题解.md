# 向左扫描朴素解法

这道题的正解是 $单调栈$，但是我们用朴素解法 $向左暴力扫描$ 也能在考试时拿到一定的分数。

题意：对每个下标 $i$，它的美好值是左边最近的、满足 $a[j]\le a[i]$ 的 $a[j]$；若没有则为 $0$。求所有位置美好值之和。

朴素做法：对每个 $i$，从 $i-1$ 往左扫，遇到第一个 $\le a[i]$ 的数就停下，把它累加到答案里。

$n$ 较小时 $O(n^2)$ 可通过；当 $n$ 接近 $10^5$ 时会超时，需要后面的单调栈做法。
## 向左扫描解法
#code-switcher
```python
def sum_beauty(a):
    n = len(a)
    ans = 0
    for i in range(n):
        # 从 i-1 向左找最近的 <= a[i]
        beauty = 0
        for j in range(i - 1, -1, -1):
            if a[j] <= a[i]:
                beauty = a[j]
                break
        ans += beauty
    return ans


n = int(input())
```

# 正确解法

## 题目分析

我们需要的是：对每个位置 $i$，找到左边最近的满足 $a[j]\le a[i]$ 的值。

从左到右扫描，用栈维护「还可能成为答案」的候选值，并保持栈内单调不降（从栈底到栈顶递增）：

1. 遇到当前值 $x$ 时，先不断弹出栈顶所有 $>x$ 的元素——它们不可能再作为 $x$ 及之后更小元素的「左边最近 $\le$」。
2. 弹完后若栈非空，栈顶就是左边最近的 $\le x$ 的值，累加进答案。
3. 再把 $x$ 压入栈。

每个元素最多入栈、出栈一次，总时间 $O(n)$。

## 复杂度分析

- 时间复杂度：$O(n)$，每个下标进出栈各至多一次。
- 空间复杂度：$O(n)$，最坏栈内存满整个数组。

## 代码实现

### Python

```python
def sum_beauty(a):
    # 单调递增栈：栈顶是当前左边最近的候选
    stack = []
    ans = 0
    for x in a:
        # 弹出所有比 x 大的，它们不是「<= x」
        while stack and stack[-1] > x:
            stack.pop()
        if stack:
            ans += stack[-1]
        stack.append(x)
    return ans


n = int(input())
a = list(map(int, input().split()))
print(sum_beauty(a))
```

### Java

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Scanner;

public class Main {
    static long sumBeauty(int[] a) {
        // 单调递增栈：栈顶是当前左边最近的候选
        Deque<Integer> stack = new ArrayDeque<>();
        long ans = 0;
        for (int x : a) {
            // 弹出所有比 x 大的，它们不是「<= x」
            while (!stack.isEmpty() && stack.peek() > x) {
                stack.pop();
            }
            if (!stack.isEmpty()) {
                ans += stack.peek();
            }
            stack.push(x);
        }
        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }
        System.out.println(sumBeauty(a));
    }
}
```

### C++

```cpp
#include <iostream>
#include <stack>
#include <vector>
using namespace std;

long long sum_beauty(const vector<int>& a) {
    // 单调递增栈：栈顶是当前左边最近的候选
    stack<int> stk;
    long long ans = 0;
    for (int x : a) {
        // 弹出所有比 x 大的，它们不是「<= x」
        while (!stk.empty() && stk.top() > x) {
            stk.pop();
        }
        if (!stk.empty()) {
            ans += stk.top();
        }
        stk.push(x);
    }
    return ans;
}

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    cout << sum_beauty(a) << "\n";
    return 0;
}
```
