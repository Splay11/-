# DFS朴素解法

这道题的正解是 $加权区间调度 + 0/1$ 背包二维 $DP$，但是我们用朴素解法 $DFS$ 枚举每个项目选或不选也能在考试时拿到一定的分数。

题意：有 $n$ 个项目，每个有开始时间 $s$、结束时间 $e$、工作量 $w$、收益 $v$。所选项目两两时间不重叠（若某项目在时刻 $X$ 结束，可立刻接在 $X$ 开始的项目），且总工作量不超过 $maxEffort$，求最大收益。

朴素做法：

1. 先按结束时间从小到大排序，方便按「结束早晚」依次决策。
2. 用 $DFS$ 从前往后枚举：对每个项目，可以选择「不选」，或在不与已选最后结束时间冲突、且剩余工作量够用时「选」。
3. 搜完所有项目后，用当前收益更新答案。

$n$ 较小时可以算出正确答案；$n$ 接近 $2000$ 时 $2^n$ 会超时，需要后面的 $DP$。

```python
def max_profit(start, end, effort, profit, maxEffort):
    n = len(start)
    if n == 0 or maxEffort == 0:
        return 0

    # 按结束时间排序
    jobs = sorted(zip(start, end, effort, profit), key=lambda x: x[1])
    s = [x[0] for x in jobs]
    e = [x[1] for x in jobs]
    w = [x[2] for x in jobs]
    v = [x[3] for x in jobs]

    ans = 0

    def dfs(i, last_end, rem, cur):
        nonlocal ans
        if i == n:
            ans = max(ans, cur)
            return
        # 不选第 i 个
        dfs(i + 1, last_end, rem, cur)
        # 选第 i 个：开始时间不早于上次结束，且工作量够
        if s[i] >= last_end and w[i] <= rem:
            dfs(i + 1, e[i], rem - w[i], cur + v[i])

    dfs(0, 0, maxEffort, 0)
    return ans

    maxEffort = int(input().replace(",", " ").strip())
```

```cpp
long long ans_dfs;

void dfs(int i, long long last_end, int rem, long long cur, int n,
         const vector<long long>& s, const vector<long long>& e,
         const vector<int>& w, const vector<long long>& v) {
    if (i == n) {
        ans_dfs = max(ans_dfs, cur);
        return;
    }
    // 不选
    dfs(i + 1, last_end, rem, cur, n, s, e, w, v);

        dfs(i + 1, e[i], rem - w[i], cur + v[i], n, s, e, w, v);
    }
}
```

# 正确解法

## 题目分析

把「时间不重叠」和「工作量上限」合在一起做二维 $DP$。

1. 将项目按结束时间从小到大排序，记第 $i$ 个项目为 $(s[i], e[i], w[i], v[i])$。
2. 预处理前驱 $pre[i]$：排序后在 $i$ 之前、且 $e[pre]\le s[i]$ 的最后一个下标（没有则为 $-1$）。可在结束时间数组上二分得到。
3. 设 $dp[i][E]$ 表示只考虑前 $i$ 个项目、可用工作量为 $E$ 时的最大收益：
   * 不选第 $i$ 个：$dp[i][E]=dp[i-1][E]$
   * 选第 $i$ 个（若 $w[i]\le E$）：$dp[i][E]=\max(dp[i][E],\ dp[pre[i]+1][E-w[i]]+v[i])$
4. 答案为 $dp[n][maxEffort]$。

## 复杂度分析

* 时间复杂度：$O(n\log n+n\cdot maxEffort)$。$n\le 2000$，$maxEffort\le 1000$，可以通过。
* 空间复杂度：$O(n\cdot maxEffort)$。

## 代码实现

### Python

```python
from bisect import bisect_right


def max_profit(start, end, effort, profit, maxEffort):
    n = len(start)
    if n == 0 or maxEffort == 0:
        return 0

    # 按结束时间排序
    jobs = sorted(zip(start, end, effort, profit), key=lambda x: x[1])
    s = [x[0] for x in jobs]
    e = [x[1] for x in jobs]
    w = [x[2] for x in jobs]
    v = [x[3] for x in jobs]

    # pre[i]：结束时间 <= s[i] 的最右下标
    pre = []
    for i in range(n):
        pre.append(bisect_right(e, s[i]) - 1)

    # dp[i][E]：前 i 个项目、容量 E 的最大收益
    dp = [[0] * (maxEffort + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for E in range(maxEffort + 1):
            dp[i][E] = dp[i - 1][E]  # 不选
        wi, vi = w[i - 1], v[i - 1]
        pi = pre[i - 1] + 1
        if wi <= maxEffort:
            for E in range(wi, maxEffort + 1):
                cand = dp[pi][E - wi] + vi
                if cand > dp[i][E]:
                    dp[i][E] = cand
    return dp[n][maxEffort]

    end = read_ints()
    effort = read_ints()
    profit = read_ints()
    maxEffort = int(input().replace(",", " ").strip())
```

```java
import java.util.Arrays;
import java.util.Scanner;

public class Main {

    static long maxProfit(long[] start, long[] end, int[] effort, long[] profit, int maxEffort) {
        int n = start.length;
        if (n == 0 || maxEffort == 0) {
            return 0;
        }

        Integer[] idx = new Integer[n];
        for (int i = 0; i < n; i++) {
            idx[i] = i;
        }
        Arrays.sort(idx, (a, b) -> Long.compare(end[a], end[b]));

        long[] s = new long[n], e = new long[n], v = new long[n];
        int[] w = new int[n];
        for (int i = 0; i < n; i++) {
            int id = idx[i];
            s[i] = start[id];
            e[i] = end[id];
            w[i] = effort[id];
            v[i] = profit[id];
        }

        // pre[i]：结束时间 <= s[i] 的最右下标
        int[] pre = new int[n];
        for (int i = 0; i < n; i++) {
            pre[i] = upperBound(e, s[i]) - 1;
        }

        // dp[i][E]：前 i 个项目、容量 E 的最大收益
        long[][] dp = new long[n + 1][maxEffort + 1];
        for (int i = 1; i <= n; i++) {
            for (int E = 0; E <= maxEffort; E++) {
                dp[i][E] = dp[i - 1][E];
            }
            int wi = w[i - 1];
            long vi = v[i - 1];
            int pi = pre[i - 1] + 1;
            if (wi <= maxEffort) {
                for (int E = wi; E <= maxEffort; E++) {
                    dp[i][E] = Math.max(dp[i][E], dp[pi][E - wi] + vi);
                }
            }
        }
        return dp[n][maxEffort];
    }

    // 返回第一个 > key 的位置
    static int upperBound(long[] a, long key) {
        int l = 0, r = a.length;
        while (l < r) {
            int m = (l + r) >>> 1;
            if (a[m] <= key) {
                l = m + 1;
            } else {
                r = m;
            }
        }
        return l;
    }

    static long[] parseLine(String line) {
        line = line.trim().replace(",", " ");
        if (line.isEmpty()) {
            return new long[0];
        }
        String[] parts = line.split("\\s+");
        long[] a = new long[parts.length];
        for (int i = 0; i < parts.length; i++) {
            a[i] = Long.parseLong(parts[i]);
        }
        return a;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        long[] start = parseLine(sc.nextLine());
        long[] end = parseLine(sc.nextLine());
        long[] effortL = parseLine(sc.nextLine());
        long[] profit = parseLine(sc.nextLine());
        int maxEffort = Integer.parseInt(sc.nextLine().trim().replace(",", " ").trim());

        int[] effort = new int[effortL.length];
        for (int i = 0; i < effortL.length; i++) {
            effort[i] = (int) effortL[i];
        }
        System.out.println(maxProfit(start, end, effort, profit, maxEffort));
    }
}
```
