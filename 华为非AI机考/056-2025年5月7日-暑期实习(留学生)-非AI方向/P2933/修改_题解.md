# 二重循环枚举朴素解法

这道题的正解是 $树状数组$，但是我们用朴素解法 $二重循环枚举$ 也能在考试时拿到一定的分数。

题意：给定数组 $record$ 和阈值 $threshold$，统计满足 $i<j$ 且 $record[i]-record[j]>threshold$ 的下标对个数（严重性能逆序对）。

朴素做法：两重循环枚举所有 $0\le i<j<n$，若 $record[i]-record[j]>threshold$，答案加 $1$。

小数据可以过；当 $n$ 达到 $10^5$ 时，$O(n^2)$ 会超时，需要后面的树状数组做法。

* 时间复杂度：$O(n^2)$。
* 空间复杂度：$O(1)$（不计输入数组）。

## 二重循环枚举解法

# 正确解法

## 题目分析

条件 $record[i]-record[j]>threshold$ 且 $i<j$，等价于：对固定的左边元素 $x=record[i]$，统计右边有多少个 $y$ 满足 $y<x-threshold$。

从右往左扫描数组，用树状数组维护「已经扫过的（即右边的）元素」的出现次数：

1. 值域 $1\le record[i]\le 50000$，树状数组大小取 $MAXV=50000$。
2. 对当前位置的 $x$，查询前缀 $[1..limit]$ 的个数，其中 $limit=x-threshold-1$（即 $y\le x-threshold-1$）。
3. 查询后把 $x$ 在树状数组里加 $1$。

每个位置一次查询、一次更新，总复杂度 $O(n\log MAXV)$。

## 复杂度分析

* 时间复杂度：$O(n\log MAXV)$，其中 $MAXV=50000$。
* 空间复杂度：$O(MAXV)$。

## 代码实现

### Python

```python
class BIT:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 1)

    def update(self, x, delta):
        # 在下标 x 加上 delta
        while x <= self.n:
            self.bit[x] += delta
            x += x & -x

    def query(self, x):
        # 前缀和 [1..x]
        s = 0
        while x > 0:
            s += self.bit[x]
            x -= x & -x
        return s


def count_severe(record, threshold):
    MAXV = 50000
    bit = BIT(MAXV)
    ans = 0
    # 从右往左：bit 里存的是当前位置右边的数
    for i in range(len(record) - 1, -1, -1):
        x = record[i]
        limit = x - threshold - 1
        if limit >= 1:
            ans += bit.query(limit)
        bit.update(x, 1)
    return ans


def main():
    threshold = int(input())
    n = int(input())
    record = list(map(int, input().split()))
    print(count_severe(record, threshold))


if __name__ == "__main__":
    main()
```

    int n;
    vector<int> bit;

    void update(int x, int delta) {
        // 在下标 x 加上 delta
        for (; x <= n; x += x & -x) {
            bit[x] += delta;
        }
    }

    int query(int x) {
        // 前缀和 [1..x]
        int s = 0;
        for (; x > 0; x -= x & -x) {
            s += bit[x];
        }
        return s;
    }
};

        int limit = x - threshold - 1;

        bit.update(x, 1);

    return ans;
}
