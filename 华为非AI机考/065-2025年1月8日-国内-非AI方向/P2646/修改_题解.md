# 枚举访问排列朴素解法

这道题的正解是 $状压DP$，但是我们用朴素解法 $枚举访问排列$ 也能在考试时拿到一定的分数。

要从景区入口出发，逛完所有景点再回到入口，总耗时尽量短。图可能缺边、边有方向，但允许路上重复经过景点。

朴素解可以这样做：

1. 对距离矩阵跑一遍 $Floyd$，得到任意两点最短路。
2. 用深度优先搜索枚举景点的访问排列：每次选一个还没逛过的景点，沿最短路跳过去；全部逛完后加上回到入口的耗时。
3. 搜索过程中若当前路程已经不优于已知答案，就剪枝。

小数据能过；$N$ 到 $15$ 时排列太多会超时，所以还需要状压正解。

* 时间复杂度：$O(N^3 + N!)$。
* 空间复杂度：$O(N^2)$。

## 枚举访问排列解法

```python
INF = 10 ** 9


def floyd(n, g):
    for k in range(n + 1):
        for i in range(n + 1):
            for j in range(n + 1):
                if g[i][k] < INF and g[k][j] < INF:
                    g[i][j] = min(g[i][j], g[i][k] + g[k][j])


def min_time(n, g):
    floyd(n, g)
    best = [INF]
    used = [0]

    def dfs(cnt, cur, cost):
        # cnt：已访问景点个数；cur：当前位置；cost：累计耗时
        if cost >= best[0]:
            return
        if cnt == n:
            if g[cur][0] < INF:
                best[0] = min(best[0], cost + g[cur][0])
            return
        for nxt in range(1, n + 1):
            bit = 1 << (nxt - 1)
            if used[0] & bit:
                continue
            if g[cur][nxt] >= INF:
                continue
            used[0] |= bit
            dfs(cnt + 1, nxt, cost + g[cur][nxt])
            used[0] ^= bit

    dfs(0, 0, 0)
    return best[0]


def main():
    n = int(input())
    g = []
    for _ in range(n + 1):
        row = list(map(int, input().split()))
        g.append([INF if x == -1 else x for x in row])
    print(min_time(n, g))


if __name__ == "__main__":
    main()
```

# 正确解法

## 题目分析

正解仍是先 $Floyd$，再对访问集合做 $状压DP$（旅行商）。

* $dp[mask][u]$：已经访问的景点集合为 $mask$，人现在在 $u$ 时的最短耗时。
* 从 $dp[0][0]=0$ 出发，每次走向一个未访问景点 $v$，更新 $dp[mask|(1<<(v-1))][v]$。
* 全集访问完后，再加上回到入口 $0$ 的最短路，取最小值。

$Floyd$ 已经处理了绕行与经入口中转，因此 DP 里不必再显式重复走已访问点。

## 复杂度分析

* 时间复杂度：$O(N^3 + N^2\cdot 2^N)$。
* 空间复杂度：$O(N\cdot 2^N)$。

```python
def floyd(n, g):

    size = 1 << n
    # dp[mask][u]：访问集合 mask、位于 u 的最短耗时

        for u in range(n + 1):

                continue
            for v in range(1, n + 1):
```

```java
import java.util.Arrays;
import java.util.Scanner;

public class Main {

    static final int INF = 1000000000;

    static void floyd(int n, int[][] g) {
        for (int k = 0; k <= n; k++) {
            for (int i = 0; i <= n; i++) {
                for (int j = 0; j <= n; j++) {
                    if (g[i][k] < INF && g[k][j] < INF) {
                        g[i][j] = Math.min(g[i][j], g[i][k] + g[k][j]);
                    }
                }
            }
        }
    }

    static int minTime(int n, int[][] g) {
        floyd(n, g);
        int size = 1 << n;
        // dp[mask][u]：访问集合 mask、位于 u 的最短耗时
        int[][] dp = new int[size][n + 1];
        for (int i = 0; i < size; i++) {
            Arrays.fill(dp[i], INF);
        }
        dp[0][0] = 0;

        for (int mask = 0; mask < size; mask++) {
            for (int u = 0; u <= n; u++) {
                if (dp[mask][u] >= INF) {
                    continue;
                }
                for (int v = 1; v <= n; v++) {
                    int bit = 1 << (v - 1);
                    if ((mask & bit) != 0) {
                        continue;
                    }
                    if (g[u][v] >= INF) {
                        continue;
                    }
                    int nmask = mask | bit;
                    dp[nmask][v] = Math.min(dp[nmask][v], dp[mask][u] + g[u][v]);
                }
            }
        }

        int full = (1 << n) - 1;
        int ans = INF;
        for (int u = 0; u <= n; u++) {
            if (dp[full][u] < INF && g[u][0] < INF) {
                ans = Math.min(ans, dp[full][u] + g[u][0]);
            }
        }
        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[][] g = new int[n + 1][n + 1];
        for (int i = 0; i <= n; i++) {
            for (int j = 0; j <= n; j++) {
                int val = sc.nextInt();
                g[i][j] = (val == -1) ? INF : val;
            }
        }
        System.out.println(minTime(n, g));
        sc.close();
    }
}
```
