# 题目描述

塔子哥准备占领一个地盘，可以将这个地盘看成一个$10000 \times 10000$的矩阵，每个士兵可以占领他自身周围$3 \times 3$的矩阵。现在塔子哥已经在地图上布置了一些士兵。现在他想在不减少占领的地盘的情况少收回尽可能多的士兵。现在塔子哥想要知道他留下了多少士兵，占领了多少地盘。

# 输入描述

第一行一个整数n，表示士兵的个数。$(1 \leq n \leq 10000)$

接下来n行每行两个整数x, y表示一个士兵的位置 $(1 < x,y < 10000)$

# 输出描述

输出留下士兵的个数和占领的格子数，使用空格隔开。

# 样例

**输入**

```
4
2 2
3 3
4 4
5 5
```

**输出**

```
4 24
```
