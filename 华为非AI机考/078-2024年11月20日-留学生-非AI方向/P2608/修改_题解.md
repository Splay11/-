# 枚举访问排列朴素解法

这道题的正解是 $状压DP$，但是我们用朴素解法 $枚举访问排列$ 也能在考试时拿到一定的分数。

题意：从入口 $0$ 出发，经过全部 $N$ 个景点至少一次，最后回到入口，求最短耗时。道路可能是有向的，也可能不直接连通（$-1$），途中允许重复经过景点。

朴素做法：

1. 先用 $Floyd$ 求出任意两点之间的最短路，把 $-1$ 补成可经中转到达的最短耗时。之后任意两点都可以直接按最短路走。
2. 游览顺序等价于景点 $1\sim N$ 的一个排列。用 $DFS$ 枚举「下一个首次访问哪个未访问景点」，从当前点沿最短路跳过去，全部访问完后加上回到入口的距离，取最小值。
3. 用当前已走路程做剪枝：若已经不小于当前最优答案，直接返回。

$N$ 较小时可以算出正确答案；$N$ 接近 $15$ 时排列数是 $N!$，会超时，需要后面的正解。

* 时间复杂度：$O(N^3 + N!)$。$Floyd$ 为 $O(N^3)$，枚举排列最坏 $O(N!)$。
* 空间复杂度：$O(N^2)$。

INF = 10 ** 9


def floyd(n, g):
    # 任意两点最短路
    for k in range(n + 1):
        for i in range(n + 1):
            for j in range(n + 1):
                if g[i][k] < INF and g[k][j] < INF:
                    g[i][j] = min(g[i][j], g[i][k] + g[k][j])


def shortest_tour(n, g):
    floyd(n, g)
    ans = [INF]

    def dfs(visited, u, cost):
        # visited：已访问景点数；u：当前所在点；cost：已耗时
        if cost >= ans[0]:
            return
        if visited == n:
            if g[u][0] < INF:
                ans[0] = min(ans[0], cost + g[u][0])
            return
        for v in range(1, n + 1):
            if not (visited_mask[0] & (1 << (v - 1))):
                if g[u][v] >= INF:
                    continue
                visited_mask[0] |= 1 << (v - 1)
                dfs(visited + 1, v, cost + g[u][v])
                visited_mask[0] ^= 1 << (v - 1)

    visited_mask = [0]
    dfs(0, 0, 0)
    return ans[0]


def main():
    n = int(input())
    g = []
    for _ in range(n + 1):
        row = list(map(int, input().split()))
        g.append([INF if x == -1 else x for x in row])
    print(shortest_tour(n, g))


if __name__ == "__main__":
    main()

# 正确解法

## 题目分析

$N\le 15$，适合用 $Floyd$ 预处理最短路后，再做旅行商问题的 $状压DP$。

1. 用 $Floyd$ 把任意两点最短路算出来，得到完整距离矩阵 $g$。
2. 用二进制 $mask$ 表示已经访问过哪些景点（第 $i$ 位对应景点 $i+1$）。
3. 定义 $dp[mask][u]$：已经访问集合为 $mask$，当前在点 $u$（含入口 $0$）时的最短耗时。
4. 初始：$dp[0][0]=0$。
5. 转移：若当前在 $u$，可走到尚未访问的景点 $v$，令 $new\_mask=mask|(1<<(v-1))$，用 $dp[mask][u]+g[u][v]$ 更新 $dp[new\_mask][v]$。
6. 答案：对全集 $mask=(1<<N)-1$，取 $\min_u(dp[mask][u]+g[u][0])$。

因为已经用最短路代替直接边，转移时只需「首次」走到未访问景点即可；$Floyd$ 已经把需要绕路、经入口中转等情况压进边权里。

## 复杂度分析

* 时间复杂度：$O(N^3 + N^2\cdot 2^N)$。$Floyd$ 为 $O(N^3)$，状压转移枚举 $mask$、$u$、$v$。
* 空间复杂度：$O(N\cdot 2^N)$。

$N\le 15$ 可以通过。

def floyd(n, g):

        for i in range(n + 1):
            for j in range(n + 1):

    floyd(n, g)
    size = 1 << n
    # dp[mask][u]：访问集合为 mask、当前在 u 的最短耗时
    dp = [[INF] * (n + 1) for _ in range(size)]
    dp[0][0] = 0

        for u in range(n + 1):
            if dp[mask][u] >= INF:
                continue
            # 前往尚未访问的景点 v
            for v in range(1, n + 1):

                if mask & bit:
                    continue
                if g[u][v] >= INF:

                dp[new_mask][v] = min(dp[new_mask][v], dp[mask][u] + g[u][v])

    full = size - 1
    ans = INF
    for u in range(n + 1):
        if dp[full][u] < INF and g[u][0] < INF:
            ans = min(ans, dp[full][u] + g[u][0])
    return ans

import java.util.Arrays;
import java.util.Scanner;

public class Main {

    static final int INF = 1000000000;

    static void floyd(int n, int[][] g) {
        for (int k = 0; k <= n; k++) {
            for (int i = 0; i <= n; i++) {
                for (int j = 0; j <= n; j++) {
                    if (g[i][k] < INF && g[k][j] < INF) {
                        g[i][j] = Math.min(g[i][j], g[i][k] + g[k][j]);
                    }
                }
            }
        }
    }

    static int shortestTour(int n, int[][] g) {
        floyd(n, g);
        int size = 1 << n;
        // dp[mask][u]：访问集合为 mask、当前在 u 的最短耗时
        int[][] dp = new int[size][n + 1];
        for (int i = 0; i < size; i++) {
            Arrays.fill(dp[i], INF);
        }
        dp[0][0] = 0;

        for (int mask = 0; mask < size; mask++) {
            for (int u = 0; u <= n; u++) {
                if (dp[mask][u] >= INF) {
                    continue;
                }
                // 前往尚未访问的景点 v
                for (int v = 1; v <= n; v++) {
                    int bit = 1 << (v - 1);
                    if ((mask & bit) != 0) {
                        continue;
                    }
                    if (g[u][v] >= INF) {
                        continue;
                    }
                    int newMask = mask | bit;
                    dp[newMask][v] = Math.min(dp[newMask][v], dp[mask][u] + g[u][v]);
                }
            }
        }

        int full = size - 1;
        int ans = INF;
        for (int u = 0; u <= n; u++) {
            if (dp[full][u] < INF && g[u][0] < INF) {
                ans = Math.min(ans, dp[full][u] + g[u][0]);
            }
        }
        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[][] g = new int[n + 1][n + 1];
        for (int i = 0; i <= n; i++) {
            for (int j = 0; j <= n; j++) {
                int val = sc.nextInt();
                g[i][j] = (val == -1) ? INF : val;
            }
        }
        System.out.println(shortestTour(n, g));
        sc.close();
    }
}

int shortest_tour(int n, vector<vector<int>>& g) {
