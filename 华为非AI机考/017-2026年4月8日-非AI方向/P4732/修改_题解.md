## 解题思路

题目中一次优化只会影响一个模块，并且总耗时等于所有模块耗时之和，所以可以把问题看成：

* 初始总和为 $\sum a_i$
* 每次操作选择一个模块，让总和尽量减少
* 做 $m$ 次后，总和最小

对于某个模块，若当前耗时为 $t$，下限为 $b_i$，那么一次优化后变成：

$$
t'=\max\left(\left\lceil \dfrac{t}{2}\right\rceil,b_i\right)
$$

这次操作带来的收益是：

$$
\Delta=t-t'
$$

显然，每一天都应该优先选择“当前能让总耗时下降最多”的那个模块。因为总和是否最小，只取决于每一步减少了多少，所以用贪心即可。

具体做法：

1. 用数组保存每个模块的当前耗时，先算初始总耗时 $total$
2. 重复最多 $m$ 次：
   * 枚举全部 $n$ 个模块，计算各自当前的 $\Delta$
   * 找出 $\Delta$ 最大的模块（若最大 $\Delta\le 0$，说明都已到下限，提前结束）
   * 用这次收益去减少 $total$，并更新该模块的当前耗时
3. 输出最终的 $total$

这里用到的相关算法是：

* 贪心：每次都选当前收益最大的模块
* 暴力枚举：每天扫一遍所有模块找最大收益

核心实现方法就是每天线性扫描，选出下一次优化能减少最多耗时的模块。

## 复杂度分析

* 每天枚举 $n$ 个模块，最多做 $m$ 天
* 总时间复杂度为 $O(nm)$，最坏约 $10^6$
* 空间复杂度为 $O(n)$

在数据范围 $n,m \le 10^3$ 下，这个复杂度完全合适。

## 代码实现

### Python

```python
# 计算某个模块优化一次后的新耗时
def next_value(t, b):
    # 向上取整除以2，再和下限取最大值
    return max((t + 1) // 2, b)


# 计算m天后的最小总耗时
def solve(n, m, a, b):
    total = sum(a)

    # 最多进行m次优化，每次扫一遍找最大收益
    for _ in range(m):
        best_gain = 0
        best_idx = -1
        for i in range(n):
            nt = next_value(a[i], b[i])
            gain = a[i] - nt
            if gain > best_gain:
                best_gain = gain
                best_idx = i

        # 所有模块都已到下限，无法再优化
        if best_gain == 0:
            break

        total -= best_gain
        a[best_idx] = next_value(a[best_idx], b[best_idx])

    return total


def main():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    print(solve(n, m, a, b))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {

    // 计算某个模块优化一次后的新耗时
    static int nextValue(int t, int b) {
        // 向上取整除以2，再和下限取最大值
        return Math.max((t + 1) / 2, b);
    }

    // 计算m天后的最小总耗时
    static long solve(int n, int m, int[] a, int[] b) {
        long total = 0;
        for (int x : a) {
            total += x;
        }

        // 最多进行m次优化，每次扫一遍找最大收益
        for (int day = 0; day < m; day++) {
            int bestGain = 0;
            int bestIdx = -1;
            for (int i = 0; i < n; i++) {
                int nt = nextValue(a[i], b[i]);
                int gain = a[i] - nt;
                if (gain > bestGain) {
                    bestGain = gain;
                    bestIdx = i;
                }
            }

            // 所有模块都已到下限，无法再优化
            if (bestGain == 0) {
                break;
            }

            total -= bestGain;
            a[bestIdx] = nextValue(a[bestIdx], b[bestIdx]);
        }

        return total;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int m = sc.nextInt();

        int[] a = new int[n];
        int[] b = new int[n];

        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }
        for (int i = 0; i < n; i++) {
            b[i] = sc.nextInt();
        }

        System.out.println(solve(n, m, a, b));
    }
}
```
