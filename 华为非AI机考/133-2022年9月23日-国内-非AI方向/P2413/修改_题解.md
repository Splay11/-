# DFS暴力解法

这道题的正解是 $Floyd$ 最短路加 $状态压缩DP$，但是我们用朴素解法 $DFS$ 枚举游览顺序也能在考试时拿到一定的分数。

题意：从城市 $0$ 出发，逛完全部 $n$ 个城市后回到 $0$，城市之间费用由邻接矩阵给出，允许重复经过城市，求最低总费用。

朴素思路：

1. 先用 $Floyd$ 把邻接矩阵变成任意两点最短路 $d[u][v]$（允许途经其他城市）。
2. 再用 $DFS$：当前在 $u$、已访问集合为 $visited$、已花费用 $cost$，枚举下一个尚未计入“逛过”的城市 $v$，转移到 $v$。
3. 当 $visited$ 覆盖全部城市时，再加上回到 $0$ 的费用 $d[u][0]$，更新答案。

$n$ 较小时可过；接近 $15$ 时排列搜索会很慢，需要状压 $DP$。

* 时间复杂度：$O(n^3+n\cdot n!)$。
* 空间复杂度：$O(n^2)$。

## DFS解法

```python
INF = 10**18


def floyd(d):
    n = len(d)
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if d[i][k] + d[k][j] < d[i][j]:
                    d[i][j] = d[i][k] + d[k][j]
    return d


def min_cost(graph):
    n = len(graph)
    d = [row[:] for row in graph]
    floyd(d)
    ans = [INF]

    def dfs(u, visited, cost):
        if cost >= ans[0]:
            return
        if visited == (1 << n) - 1:
            ans[0] = min(ans[0], cost + d[u][0])
            return
        for v in range(n):
            if (visited >> v) & 1:
                continue
            dfs(v, visited | (1 << v), cost + d[u][v])

    dfs(0, 1, 0)  # 必须从 0 出发
    return ans[0]


def main():
    n = int(input())
    graph = [list(map(int, input().split())) for _ in range(n)]
    print(min_cost(graph))


if __name__ == "__main__":
    main()
```

# 正确解法

## 题目分析

允许重复经过，两点之间的移动费用取最短路。因此：

1. $Floyd$ 预处理 $d[i][j]$。
2. 状态压缩 $DP$：令 $dp[j][mask]$ 表示当前在城市 $j$、已逛过集合为 $mask$ 时的最少费用。
3. 从城市 $0$ 出发，初始化 $dp[0][1]=0$。
4. 转移：对每个 $mask$ 与当前点 $j$，枚举前驱 $k$，用 $dp[k][last]+d[k][j]$ 更新。
5. 答案：$\min_i(dp[i][(1\ll n)-1]+d[i][0])$，即逛完后回到 $0$。

## 复杂度分析

* 时间复杂度：$O(n^3+n^2\cdot 2^n)$。
* 空间复杂度：$O(n\cdot 2^n)$。

$n\le 15$ 可以通过。

## 代码实现

### Python

```python
INF = 10**18


def min_cost(graph):
    n = len(graph)
    d = [row[:] for row in graph]
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if d[i][k] + d[k][j] < d[i][j]:
                    d[i][j] = d[i][k] + d[k][j]

    state = 1 << n
    dp = [[INF] * state for _ in range(n)]
    dp[0][1] = 0  # 从 0 出发，已访问 {0}

    for mask in range(1, state):
        for j in range(n):
            if ((mask >> j) & 1) == 0:
                continue
            last = mask ^ (1 << j)
            if last == 0:
                continue
            for k in range(n):
                if ((last >> k) & 1) == 0:
                    continue
                if dp[k][last] >= INF:
                    continue
                dp[j][mask] = min(dp[j][mask], dp[k][last] + d[k][j])

    full = state - 1
    ans = INF
    for i in range(n):
        ans = min(ans, dp[i][full] + d[i][0])
    return ans


def main():
    n = int(input())
    graph = [list(map(int, input().split())) for _ in range(n)]
    print(min_cost(graph))


if __name__ == "__main__":
    main()
```

```java
import java.util.Arrays;
import java.util.Scanner;

public class Main {
    static final long INF = (long) 1e18;

    static long minCost(long[][] graph) {
        int n = graph.length;
        long[][] d = new long[n][n];
        for (int i = 0; i < n; i++) {
            System.arraycopy(graph[i], 0, d[i], 0, n);
        }
        for (int k = 0; k < n; k++) {
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    if (d[i][k] + d[k][j] < d[i][j]) {
                        d[i][j] = d[i][k] + d[k][j];
                    }
                }
            }
        }

        int state = 1 << n;
        long[][] dp = new long[n][state];
        for (int i = 0; i < n; i++) {
            Arrays.fill(dp[i], INF);
        }
        dp[0][1] = 0;

        for (int mask = 1; mask < state; mask++) {
            for (int j = 0; j < n; j++) {
                if (((mask >> j) & 1) == 0) {
                    continue;
                }
                int last = mask ^ (1 << j);
                if (last == 0) {
                    continue;
                }
                for (int k = 0; k < n; k++) {
                    if (((last >> k) & 1) == 0) {
                        continue;
                    }
                    if (dp[k][last] >= INF) {
                        continue;
                    }
                    dp[j][mask] = Math.min(dp[j][mask], dp[k][last] + d[k][j]);
                }
            }
        }

        int full = state - 1;
        long ans = INF;
        for (int i = 0; i < n; i++) {
            ans = Math.min(ans, dp[i][full] + d[i][0]);
        }
        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long[][] graph = new long[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                graph[i][j] = sc.nextLong();
            }
        }
        System.out.println(minCost(graph));
        sc.close();
    }
}
```

```cpp
    for (int k = 0; k < n; k++) {
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {

                }
            }
        }
    }

    int state = 1 << n;
    vector<vector<long long>> dp(n, vector<long long>(state, INF));
    dp[0][1] = 0;

    for (int mask = 1; mask < state; mask++) {
        for (int j = 0; j < n; j++) {
            if (((mask >> j) & 1) == 0) {
                continue;
            }
            int last = mask ^ (1 << j);
            if (last == 0) {
                continue;
            }

    long long ans = INF;
```
