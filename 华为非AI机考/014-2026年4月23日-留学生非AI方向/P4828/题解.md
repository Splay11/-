## 解题思路

题目的本质是：

给定总预算 $budget$ 和数组 $prices$，其中每个元素表示一种奖品的价格。
要求每种奖品至少买 $1$ 件，并且总花费恰好等于 $budget$，问一共有多少种采购方案。

注意两点：

$1.$ 即使两种奖品价格相同，只要它们在数组中的位置不同，也视为不同奖品。
$2.$ 方案只和每种奖品买了多少件有关，与购买顺序无关。

先设第 $i$ 种奖品购买数量为 $x_i$，因为每种都至少买一件，所以有：

$x_i \ge 1$

并且需要满足：

$\sum prices[i] \cdot x_i = budget$

### 核心转化

先给每种奖品都买 $1$ 件，设所有奖品价格总和为：

$sum = \sum prices[i]$

如果 $sum > budget$，说明连基本要求都无法满足，直接返回 $0$。

否则还剩下预算：

$rest = budget - sum$

此时问题就转化成：

每种奖品还可以再买若干件（可以是 $0$ 件），问用所有奖品价格组成总和 $rest$ 的方案数。

这就是标准的“完全背包计数”问题。

### 动态规划做法

定义一维数组 $dp[j]$ 表示：

凑出总金额 $j$ 的方案数。

初始条件：

$dp[0] = 1$

表示凑出金额 $0$ 有 $1$ 种方案，即什么都不再买。

然后把每一种奖品价格 $p$ 依次当作完全背包物品转移：

$dp[j] += dp[j - p]$

其中 $j$ 从 $p$ 到 $rest$ 递增枚举。
之所以递增，是因为每种奖品可以使用无限次，这是完全背包的标准写法。

最终答案就是 $dp[rest]$。

## 复杂度分析

设奖品种类数为 $n$，剩余预算为 $rest$。

时间复杂度为 $O(n \times rest)$

空间复杂度为 $O(rest)$

根据题目范围，$n \le 10$，$budget \le 100$，这样的复杂度完全可以通过。

## 代码实现

### Python

```python
# 奖品采购
# ACM风格

import sys


def count_plans(budget, prices):
    # 先计算每种奖品各买1件的总花费
    total = sum(prices)

    # 如果连每种买1件都做不到，直接返回0
    if total > budget:
        return 0

    # 剩余预算
    rest = budget - total

    # dp[j] 表示凑出金额 j 的方案数
    dp = [0] * (rest + 1)
    dp[0] = 1

    # 完全背包计数
    for price in prices:
        for j in range(price, rest + 1):
            dp[j] += dp[j - price]

    return dp[rest]


def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return

    # 第一行是 budget，后面一行是 prices
    budget = int(data[0])
    prices = list(map(int, data[1:]))

    print(count_plans(budget, prices))


if __name__ == "__main__":
    main()
```

### Java

```java
// 奖品采购
// ACM风格

import java.util.*;

public class Main {

    // 统计方案数
    public static int countPlans(int budget, int[] prices) {
        // 先计算每种奖品各买1件的总花费
        int total = 0;
        for (int price : prices) {
            total += price;
        }

        // 如果连每种买1件都做不到，直接返回0
        if (total > budget) {
            return 0;
        }

        // 剩余预算
        int rest = budget - total;

        // dp[j] 表示凑出金额 j 的方案数
        int[] dp = new int[rest + 1];
        dp[0] = 1;

        // 完全背包计数
        for (int price : prices) {
            for (int j = price; j <= rest; j++) {
                dp[j] += dp[j - price];
            }
        }

        return dp[rest];
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        List<Integer> list = new ArrayList<>();

        // 读入所有整数
        while (sc.hasNextInt()) {
            list.add(sc.nextInt());
        }

        if (list.size() == 0) {
            return;
        }

        // 第一个数是 budget，其余是 prices
        int budget = list.get(0);
        int[] prices = new int[list.size() - 1];
        for (int i = 1; i < list.size(); i++) {
            prices[i - 1] = list.get(i);
        }

        System.out.println(countPlans(budget, prices));
    }
}
```

### C++

```cpp
// 奖品采购
// ACM风格

#include <iostream>
#include <vector>
using namespace std;

// 统计方案数
int countPlans(int budget, const vector<int>& prices) {
    // 先计算每种奖品各买1件的总花费
    int total = 0;
    for (int price : prices) {
        total += price;
    }

    // 如果连每种买1件都做不到，直接返回0
    if (total > budget) {
        return 0;
    }

    // 剩余预算
    int rest = budget - total;

    // dp[j] 表示凑出金额 j 的方案数
    vector<int> dp(rest + 1, 0);
    dp[0] = 1;

    // 完全背包计数
    for (int price : prices) {
        for (int j = price; j <= rest; j++) {
            dp[j] += dp[j - price];
        }
    }

    return dp[rest];
}

int main() {
    int budget;
    cin >> budget;

    vector<int> prices;
    int x;

    // 读入第二行所有价格
    while (cin >> x) {
        prices.push_back(x);
    }

    cout << countPlans(budget, prices) << endl;

    return 0;
}
```
