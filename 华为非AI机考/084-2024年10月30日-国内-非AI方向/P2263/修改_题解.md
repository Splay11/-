# DFS暴力解法

这道题的正解是 $Floyd$ 最短路加 $状态压缩DP$，但是我们用朴素解法 $DFS$ 枚举游览顺序也能在考试时拿到一定的分数。

题意：有 $n$ 个景点，邻接矩阵里 $1$ 表示有直达公交。可重复经过景点，求逛完所有景点的最少乘坐次数；不可达则输出 $0$。可从任意景点出发，不必回到起点。

朴素思路：

1. 先用 $Floyd$ 算出任意两点之间最少乘坐次数 $dist[u][v]$（允许途经其他点）。
2. 再用 $DFS$：当前在 $u$、已访问集合为 $visited$、已花代价 $cost$，枚举下一个尚未算作“逛过”的景点 $v$，转移到 $v$，代价加 $dist[u][v]$，并标记 $v$ 已逛过。
3. 当 $visited$ 覆盖全部景点时，用 $cost$ 更新答案。

小规模（例如 $n\le 10$）可过；当 $n$ 接近 $20$ 时，$n!$ 级搜索会超时，需要后面的状压 $DP$。

* 时间复杂度：$O(n^3+n\cdot n!)$（$Floyd$ 加全排列式搜索）。
* 空间复杂度：$O(n^2)$。

INF = 10**9


def floyd(edge):
    n = len(edge)
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
        for j in range(n):
            if edge[i][j] == 1:
                dist[i][j] = 1
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    return dist


def min_bus(edge):
    n = len(edge)
    dist = floyd(edge)
    ans = [INF]

    def dfs(u, visited, cost):
        if cost >= ans[0]:
            return
        if visited == (1 << n) - 1:
            ans[0] = cost
            return
        for v in range(n):
            if (visited >> v) & 1:
                continue
            if dist[u][v] >= INF:
                continue
            dfs(v, visited | (1 << v), cost + dist[u][v])

    # 枚举起点
    for s in range(n):
        dfs(s, 1 << s, 0)

    return 0 if ans[0] >= INF else ans[0]


def main():
    n = int(input())
    edge = [list(map(int, input().split())) for _ in range(n)]
    print(min_bus(edge))


if __name__ == "__main__":
    main()

# 正确解法

## 题目分析

允许重复经过景点，等价于：两点之间的移动代价取最短路。因此：

1. $Floyd$ 预处理 $dist[i][j]$：景点 $i$ 到 $j$ 的最少乘坐次数。
2. 状态压缩 $DP$：令 $dp[j][mask]$ 表示当前在景点 $j$、已逛过的景点集合为 $mask$ 时的最少乘坐次数。
3. 转移：若 $j$ 属于 $mask$，令 $last=mask\oplus(1\ll j)$，枚举 $last$ 中的前驱 $k$，用 $dp[k][last]+dist[k][j]$ 更新 $dp[j][mask]$。
4. 初始化：$dp[i][1\ll i]=0$（可从任意点出发）。答案为所有 $dp[i][(1\ll n)-1]$ 的最小值；若仍为无穷大则输出 $0$。

$DP$ 里的“已访问”是人为定序，保证每种集合只算一次；实际最短路上途经的点不必改 $mask$。

## 复杂度分析

* 时间复杂度：$O(n^3+n^2\cdot 2^n)$。
* 空间复杂度：$O(n\cdot 2^n)$。

$n\le 20$ 可以通过。

INF = 10**9


def min_bus(edge):
    n = len(edge)
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
        for j in range(n):
            if edge[i][j] == 1:
                dist[i][j] = 1
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    state = 1 << n
    dp = [[INF] * state for _ in range(n)]
    for i in range(n):
        dp[i][1 << i] = 0

    for mask in range(1, state):
        for j in range(n):
            if ((mask >> j) & 1) == 0:
                continue
            last = mask ^ (1 << j)
            if last == 0:
                continue
            for k in range(n):
                if ((last >> k) & 1) == 0:
                    continue
                if dp[k][last] >= INF or dist[k][j] >= INF:
                    continue
                dp[j][mask] = min(dp[j][mask], dp[k][last] + dist[k][j])

    ans = INF
    full = state - 1
    for i in range(n):
        ans = min(ans, dp[i][full])
    return 0 if ans >= INF else ans


def main():
    n = int(input())
    edge = [list(map(int, input().split())) for _ in range(n)]
    print(min_bus(edge))


if __name__ == "__main__":

import java.util.Arrays;
import java.util.Scanner;

public class Main {
    static final int INF = 1000000000;

    static int minBus(int[][] edge) {
        int n = edge.length;
        int[][] dist = new int[n][n];
        for (int i = 0; i < n; i++) {
            Arrays.fill(dist[i], INF);
            dist[i][i] = 0;
        }
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (edge[i][j] == 1) {
                    dist[i][j] = 1;
                }
            }
        }
        for (int k = 0; k < n; k++) {
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    if (dist[i][k] + dist[k][j] < dist[i][j]) {
                        dist[i][j] = dist[i][k] + dist[k][j];
                    }
                }
            }
        }

        int state = 1 << n;
        int[][] dp = new int[n][state];
        for (int i = 0; i < n; i++) {
            Arrays.fill(dp[i], INF);
            dp[i][1 << i] = 0;
        }

        for (int mask = 1; mask < state; mask++) {
            for (int j = 0; j < n; j++) {
                if (((mask >> j) & 1) == 0) {
                    continue;
                }
                int last = mask ^ (1 << j);
                if (last == 0) {
                    continue;
                }
                for (int k = 0; k < n; k++) {
                    if (((last >> k) & 1) == 0) {
                        continue;
                    }
                    if (dp[k][last] >= INF || dist[k][j] >= INF) {
                        continue;
                    }
                    dp[j][mask] = Math.min(dp[j][mask], dp[k][last] + dist[k][j]);
                }
            }
        }

        int ans = INF;
        int full = state - 1;
        for (int i = 0; i < n; i++) {
            ans = Math.min(ans, dp[i][full]);
        }
        return ans >= INF ? 0 : ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[][] edge = new int[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                edge[i][j] = sc.nextInt();
            }
        }
        System.out.println(minBus(edge));
        sc.close();
    }
}
