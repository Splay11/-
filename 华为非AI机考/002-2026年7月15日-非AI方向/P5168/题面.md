# 题目内容

在手机通信中，为了提升网速，基站可以同时使用多个频段（称为载波聚合），每个频段提供一定的带宽，但存在以下限制：
1. **每个频段最多选一个载波**（不能同时选择同一频段的多个载波）。
2. **冲突频段不能同时使用**（如 $n1$ 和 $n2$ 冲突，只能选其中一个）。
3. **最多选择$K$个载波**（可以少于 $K$）。

你的任务是：

- **选择一组载波**，使得 **总带宽最大**，同时满足上述约束。

- **输出最大总带宽**，并给出所选载波的 **编号**。


![](file://plKMJIhq3nz6sHdI0UfRc.png)




# 输入描述


**第一行**：$N$（载波总数，$1 \le N \le 25$）和 $K$（最多选 $K$ 个载波，$1 \le K \le 8$，$K \le N$）。

**第二行**：$b1\ b2\ ...\ bN$（每个载波的带宽，$1 \le bi \le 1000$）。

**第三行**：$f1\ f2\ ...\ fN$（每个载波所属的频段，为 $n$ 开头的字符串，如 $n1$、$n2$，不区分大小写，字符串长度不超过 $10$）。

**第四行**：$C$（冲突频段对数，$0 \le C \le 25$）。

**接下来$C$行**：每行两个频段$fa\ fb$，表示 $fa$ 和 $fb$ 不能同时选（冲突关系不传递）。


# 输出描述

**第一行**：最大总带宽。

**第二行**：所选载波的 **编号**（从 $0$ 开始，按升序排列，数值序最小；组合有多种时，则输出数值序最小的一组）。




## 样例1 



**输入** 



```
6 2
100 200 150 300 250 180
n78 n41 n78 n28 n41 n28
1
n28 n41
```



**输出** 



```
450
2 3
```



**说明**

选择带宽索引为 $2$ 和 $3$ 的两个带宽，即 $150$ 和 $300$，总带宽为 $450$


## 样例2



**输入** 



```
3 2
10 10 10
n1 n2 n3
0
```



**输出** 



```
20
0 1
```



**说明**

最大带宽为 $20$，因为每个频段带宽都相同，因此有 $3$ 种组合：$(0,1)$、$(0,2)$、$(1,2)$，输出排序后第一个组合 $(0,1)$
