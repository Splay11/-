## 解题思路

由于只能向源字符串 $S$ 中插入字符，不能删除或修改原有字符，因此应尽可能利用 $S$ 中已经存在的字符来匹配目标字符串 $T$。

能够直接利用的字符必须同时满足：

* 在 $T$ 中的相对顺序不变。
* 在 $S$ 中的相对顺序不变。

因此，能够利用的最大字符数量就是 $T$ 和 $S$ 的最长公共子序列长度，即 $LCS$。

设最长公共子序列长度为 $L$，目标字符串长度为 $|T|$，那么剩余未匹配的字符都需要插入，答案为：

$$
|T|-L
$$

使用动态规划计算最长公共子序列。

设目标字符串 $T$ 的长度为 $n$，源字符串 $S$ 的长度为 $m$。

状态定义：

$$
dp[i][j]
$$

表示 $T$ 的前 $i$ 个字符与 $S$ 的前 $j$ 个字符的最长公共子序列长度。

状态转移：

* 如果 $T[i-1]=S[j-1]$，则当前字符可以接在公共子序列后面：

$$
dp[i][j]=dp[i-1][j-1]+1
$$

* 如果两个字符不同，则只能从「丢掉 $T$ 当前字符」或「丢掉 $S$ 当前字符」中选较大值：

$$
dp[i][j]=\max(dp[i-1][j],dp[i][j-1])
$$

边界：$dp[0][j]=0$，$dp[i][0]=0$（任一串为空时，公共子序列长度为 $0$）。

最终答案为：

$$
n-dp[n][m]
$$

## 复杂度分析

时间复杂度：

$$
O(nm)
$$

空间复杂度：

$$
O(nm)
$$

在 $n,m\le 2500$ 的数据范围内可以通过。

## 代码实现

### Python

```python
def min_insertions(t, s):
    n = len(t)
    m = len(s)
    # dp[i][j]：T 前 i 个字符与 S 前 j 个字符的 LCS 长度
    dp = [[0] * (m + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if t[i - 1] == s[j - 1]:
                # 当前字符相同，接在左上角状态后面
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                # 当前字符不同，取上方和左方的较大值
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    # 未匹配的目标字符都需要插入
    return n - dp[n][m]


def main():
    t = input().strip()
    s = input().strip()
    print(min_insertions(t, s))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {

    static int minInsertions(String t, String s) {
        int n = t.length();
        int m = s.length();
        // dp[i][j]：T 前 i 个字符与 S 前 j 个字符的 LCS 长度
        int[][] dp = new int[n + 1][m + 1];

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (t.charAt(i - 1) == s.charAt(j - 1)) {
                    // 当前字符相同，接在左上角状态后面
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    // 当前字符不同，取上方和左方的较大值
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        // 未匹配的目标字符都需要插入
        return n - dp[n][m];
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String t = scanner.nextLine();
        String s = scanner.nextLine();
        System.out.println(minInsertions(t, s));
    }
}
```

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

int minInsertions(const string& t, const string& s) {
    int n = (int)t.size();
    int m = (int)s.size();
    // dp[i][j]：T 前 i 个字符与 S 前 j 个字符的 LCS 长度
    vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (t[i - 1] == s[j - 1]) {
                // 当前字符相同，接在左上角状态后面
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                // 当前字符不同，取上方和左方的较大值
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }

    // 未匹配的目标字符都需要插入
    return n - dp[n][m];
}

int main() {
    string t, s;
    cin >> t >> s;
    cout << minInsertions(t, s) << '\n';
    return 0;
}
```
