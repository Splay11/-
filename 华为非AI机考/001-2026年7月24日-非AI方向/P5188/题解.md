## 解题思路

设地砖编号为 $1$ 到 $n$，玩家初始位于地砖外的 $0$ 号位置。每个回合可以前进 $1$、$2$ 或 $3$ 块地砖，落在某块地砖时获得该地砖上的财宝。

首先判断是否能够到达终点：

* 每个回合最多前进 $3$ 块，因此 $m$ 个回合最多前进 $3m$ 块。
* 如果 $n>3m$，一定无法到达第 $n$ 块地砖，输出 $-1$。

由于所有财宝价值都不小于 $0$，在不超过回合上限的情况下，经过的地砖越多不会使答案变小。因此可以令实际使用的回合数为：

$$
k=\min(n,m)
$$

当 $m<n$ 时使用 $m$ 个回合；当 $m\ge n$ 时，可以每次前进 $1$ 块，经过所有地砖。

使用动态规划算法。

定义：

$$
dp[i]
$$

表示使用当前回合数恰好到达第 $i$ 块地砖时，能够获得的最大财宝价值。

到达第 $i$ 块地砖之前，玩家可能位于第 $i-1$、$i-2$ 或 $i-3$ 块地砖，因此状态转移为：

$$
dp[i]=\max(dp[i-1],dp[i-2],dp[i-3])+value[i]
$$

为了避免计算不可能到达终点的状态，在已经使用 $t$ 个回合时，只计算满足以下条件的位置：

$$
\max(t,n-3(k-t))\le i\le \min(3t,n-(k-t))
$$

其中：

* $t\le i\le 3t$ 表示前 $t$ 个回合可以到达的位置。
* 剩余 $k-t$ 个回合必须能够从第 $i$ 块地砖到达第 $n$ 块地砖。

每一层状态只依赖上一层，因此使用两个一维数组滚动更新。

## 复杂度分析

设实际使用的回合数为 $k=\min(n,m)$。

每一层最多计算：

$$
\min(n-k,3k-n)+1
$$

个有效位置，因此时间复杂度为：

$$
O\left(k\left(\min(n-k,3k-n)+1\right)\right)
$$

其上界为：

$$
O(nk)
$$

使用两个长度为 $n+1$ 的滚动数组，空间复杂度为：

$$
O(n)
$$

## 代码实现

### Python

```python
import sys


def get_max_treasure(n, m, treasure):
    # 每回合最多前进三块地砖
    if n > 3 * m:
        return -1

    # 财宝价值非负，可以使用尽可能多的回合
    k = min(n, m)
    negative = -10 ** 9

    previous = [negative] * (n + 1)
    current = [negative] * (n + 1)

    # 初始位于地宫外的零号位置
    previous[0] = 0
    previous_left = 0
    previous_right = 0

    for turn in range(1, k + 1):
        remaining = k - turn

        # 当前能够到达，并且之后仍能到达终点的位置范围
        left = max(turn, n - 3 * remaining)
        right = min(3 * turn, n - remaining)

        for position in range(left, right + 1):
            best = negative

            # 从前一块地砖移动过来
            last_position = position - 1
            if previous_left <= last_position <= previous_right:
                best = previous[last_position]

            # 跳过一块地砖移动过来
            last_position = position - 2
            if previous_left <= last_position <= previous_right:
                if previous[last_position] > best:
                    best = previous[last_position]

            # 跳过两块地砖移动过来
            last_position = position - 3
            if previous_left <= last_position <= previous_right:
                if previous[last_position] > best:
                    best = previous[last_position]

            # 落在当前地砖后获得财宝
            current[position] = best + treasure[position - 1]

        previous, current = current, previous
        previous_left = left
        previous_right = right

    return previous[n]


if __name__ == "__main__":
    data = list(map(int, sys.stdin.buffer.read().split()))

    n = data[0]
    m = data[1]
    treasure = data[2:2 + n]

    answer = get_max_treasure(n, m, treasure)
    print(answer)
```

import java.util.Scanner;

public class Main {

    public static int getMaxTreasure(int n, int m, int[] treasure) {
        // 每回合最多前进三块地砖
        if (n > 3 * m) {
            return -1;
        }

        // 财宝价值非负，可以使用尽可能多的回合
        int k = Math.min(n, m);
        int negative = -1000000000;

        int[] previous = new int[n + 1];
        int[] current = new int[n + 1];

        for (int i = 0; i <= n; i++) {
            previous[i] = negative;
            current[i] = negative;
        }

        // 初始位于地宫外的零号位置
        previous[0] = 0;
        int previousLeft = 0;
        int previousRight = 0;

        for (int turn = 1; turn <= k; turn++) {
            int remaining = k - turn;

            // 当前能够到达，并且之后仍能到达终点的位置范围
            int left = Math.max(turn, n - 3 * remaining);
            int right = Math.min(3 * turn, n - remaining);

            for (int position = left; position <= right; position++) {
                int best = negative;

                // 从前一块地砖移动过来
                int lastPosition = position - 1;
                if (lastPosition >= previousLeft && lastPosition <= previousRight) {
                    best = previous[lastPosition];
                }

                // 跳过一块地砖移动过来
                lastPosition = position - 2;
                if (lastPosition >= previousLeft && lastPosition <= previousRight
                        && previous[lastPosition] > best) {
                    best = previous[lastPosition];
                }

                // 跳过两块地砖移动过来
                lastPosition = position - 3;
                if (lastPosition >= previousLeft && lastPosition <= previousRight
                        && previous[lastPosition] > best) {
                    best = previous[lastPosition];
                }

                // 落在当前地砖后获得财宝
                current[position] = best + treasure[position - 1];
            }

            int[] temp = previous;
            previous = current;
            current = temp;

            previousLeft = left;
            previousRight = right;
        }

        return previous[n];
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int n = scanner.nextInt();
        int m = scanner.nextInt();

        int[] treasure = new int[n];
        for (int i = 0; i < n; i++) {
            treasure[i] = scanner.nextInt();
        }

        int answer = getMaxTreasure(n, m, treasure);
        System.out.println(answer);

        scanner.close();
    }
}

int getMaxTreasure(int n, int m, const vector<int>& treasure) {

    if (n > 3 * m) {

    int previousRight = 0;

        int left = max(turn, n - 3 * remaining);
        int right = min(3 * turn, n - remaining);

            int best = negative;

            // 从前一块地砖移动过来
            int lastPosition = position - 1;
            if (lastPosition >= previousLeft && lastPosition <= previousRight) {
                best = previous[lastPosition];
            }

            // 跳过一块地砖移动过来
            lastPosition = position - 2;
            if (lastPosition >= previousLeft && lastPosition <= previousRight) {
                best = max(best, previous[lastPosition]);
            }

            // 跳过两块地砖移动过来

        previousRight = right;
    }

    return previous[n];
}
