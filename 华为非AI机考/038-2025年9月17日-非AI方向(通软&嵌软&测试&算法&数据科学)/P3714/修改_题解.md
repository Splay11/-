# 枚举朴素解法

这道题的正解是 $单调队列优化DP$，但是我们用朴素解法 $枚举窗口最大值$ 也能在考试时拿到一定的分数。

题意：从下标 $0$ 跳到 $n-1$，每次最多前进 $K$ 步，路径上分数之和最大（分数可正可负）。

设 $dp[i]$ 为到达下标 $i$ 时的最大累计得分，则：

$$dp[i]=\max_{j\in[i-K,i-1]}dp[j]+node\_scores[i]$$

（下标不够 $K$ 时从 $0$ 开始取）。$dp[0]=node\_scores[0]$。

朴素做法：对每个 $i$，直接枚举窗口 $[i-K,i-1]$ 里所有 $dp[j]$ 取最大值，再转移。时间 $O(nK)$。

小数据可以过；当 $n,K$ 达到 $10^5$ 时会超时，需要后面的单调队列做法。
## 枚举解法

```python
def max_score(node_scores, K):
    n = len(node_scores)
    INF = 10**18
    dp = [-INF] * n
    dp[0] = node_scores[0]

    for i in range(1, n):
        # 枚举窗口 [i-K, i-1] 内的最大值
        best = -INF
        left = max(0, i - K)
        for j in range(left, i):
            if dp[j] > best:
                best = dp[j]
        dp[i] = best + node_scores[i]

    return dp[n - 1]
```

# 正确解法

## 题目分析

转移仍然是 $dp[i]=\max_{j\in[i-K,i-1]}dp[j]+node\_scores[i]$，只是用单调队列在 $O(1)$ 摊还时间内取出窗口最大值。

维护双端队列 $dq$，存下标，并保证队内 $dp$ 值从队首到队尾单调递减：

1. 处理 $i$ 时，先弹出队首中小于 $i-K$ 的下标（滑出窗口）。
2. 队首就是窗口最大值下标，令 $dp[i]=dp[dq.front()]+node\_scores[i]$。
3. 再从队尾弹出所有 $dp$ 不大于 $dp[i]$ 的下标，把 $i$ 入队。

每个下标进出队列各一次，整体 $O(n)$。

## 复杂度分析

* 时间复杂度：$O(n)$。
* 空间复杂度：$O(n)$。

$n\le 10^5$ 可以通过。

## 代码实现

### Python

```python
from collections import deque


def max_score(node_scores, K):
    n = len(node_scores)
    INF = 10**18
    dp = [-INF] * n
    dp[0] = node_scores[0]

    dq = deque([0])  # 存下标，对应 dp 单调递减
    for i in range(1, n):
        # 弹出滑出窗口的下标
        while dq and dq[0] < i - K:
            dq.popleft()
        dp[i] = dp[dq[0]] + node_scores[i]
        # 维护单调递减
        while dq and dp[dq[-1]] <= dp[i]:
            dq.pop()
        dq.append(i)

    return dp[n - 1]


def main():
    K = int(input())
    n = int(input())
    node_scores = list(map(int, input().split()))
    print(max_score(node_scores, K))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Scanner;

public class Main {

    static long maxScore(int[] nodeScores, int K) {
        int n = nodeScores.length;
        long INF = (long) 1e18;
        long[] dp = new long[n];
        for (int i = 0; i < n; i++) {
            dp[i] = -INF;
        }
        dp[0] = nodeScores[0];

        Deque<Integer> dq = new ArrayDeque<>();
        dq.addLast(0); // 存下标，对应 dp 单调递减

        for (int i = 1; i < n; i++) {
            // 弹出滑出窗口的下标
            while (!dq.isEmpty() && dq.peekFirst() < i - K) {
                dq.pollFirst();
            }
            dp[i] = dp[dq.peekFirst()] + nodeScores[i];
            // 维护单调递减
            while (!dq.isEmpty() && dp[dq.peekLast()] <= dp[i]) {
                dq.pollLast();
            }
            dq.addLast(i);
        }
        return dp[n - 1];
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int K = sc.nextInt();
        int n = sc.nextInt();
        int[] nodeScores = new int[n];
        for (int i = 0; i < n; i++) {
            nodeScores[i] = sc.nextInt();
        }
        System.out.println(maxScore(nodeScores, K));
        sc.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <deque>
using namespace std;

long long max_score(const vector<int>& node_scores, int K) {
    int n = (int)node_scores.size();
    const long long INF = (long long)1e18;
    vector<long long> dp(n, -INF);
    dp[0] = node_scores[0];

    deque<int> dq;
    dq.push_back(0); // 存下标，对应 dp 单调递减

    for (int i = 1; i < n; i++) {
        // 弹出滑出窗口的下标
        while (!dq.empty() && dq.front() < i - K) {
            dq.pop_front();
        }
        dp[i] = dp[dq.front()] + node_scores[i];
        // 维护单调递减
        while (!dq.empty() && dp[dq.back()] <= dp[i]) {
            dq.pop_back();
        }
        dq.push_back(i);
    }
    return dp[n - 1];
}

int main() {
    ios::sync_with_stdio(false); // n 较大，加速读写
    cin.tie(nullptr);

    int K, n;
    cin >> K >> n;
    vector<int> node_scores(n);
    for (int i = 0; i < n; i++) {
        cin >> node_scores[i];
    }
    cout << max_score(node_scores, K) << "\n";
    return 0;
}
```
