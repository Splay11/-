## 解题思路

题目要求：在连续采样序列中，找最长子段 $[l, r]$，使得段内每个温度 $T$ 都满足 $18\le T\le 24$，且 $\max-\min\le 4$。若有多段同为最长，按左端点升序逐行输出起止下标（从 $0$ 开始）。

温度取值只有 $[0,30]$，合法窗口里更只有 $[18,24]$ 共 $7$ 个值，因此用**双指针滑动窗口 + 计数桶**即可，不必维护单调队列：

1. 右指针 $r$ 从左到右枚举；用数组 $cnt[0..30]$ 记录当前窗口 $[l,r]$ 内各温度出现次数。
2. 若 $a[r]$ 不在 $[18,24]$：清空计数桶，令 $l=r+1$，窗口断开。
3. 否则把 $a[r]$ 加入窗口；用桶从低到高 / 从高到低扫一遍得到当前 $\min$、$\max$。若 $\max-\min>4$，不断把 $a[l]$ 移出窗口并 $l\mathrel{+}=1$，直到温差合法。
4. 此时 $[l,r]$ 是以 $r$ 为右端点的最长合法窗口。用 $bestLen$ 记录全局最长长度；长度更大则重置答案列表，相等则追加 $(l,r)$。

每个下标最多进、出窗口一次，每次查 $\min/\max$ 只扫常数个温度值，整体线性。

## 复杂度分析

* 时间复杂度：$O(N)$。每个位置进出窗口 $O(1)$ 次，查 $\min/\max$ 为 $O(1)$（值域固定为 $7$）。
* 空间复杂度：$O(N)$。主要用于存放答案；计数桶为常数大小。

## 代码实现

### Python

```python
def find_best_intervals(a):
    n = len(a)
    cnt = [0] * 31  # 温度计数桶
    l = 0
    best_len = 0
    ans = []

    def clear_window():
        for t in range(18, 25):
            cnt[t] = 0

    def get_min():
        for t in range(18, 25):
            if cnt[t] > 0:
                return t
        return 0

    def get_max():
        for t in range(24, 17, -1):
            if cnt[t] > 0:
                return t
        return 0

    for r in range(n):
        v = a[r]
        # 不在承诺温度范围，窗口断开
        if v < 18 or v > 24:
            clear_window()
            l = r + 1
            continue

        cnt[v] += 1
        # 温差过大则从左侧收缩
        while get_max() - get_min() > 4:
            cnt[a[l]] -= 1
            l += 1

        length = r - l + 1
        if length > best_len:
            best_len = length
            ans = [(l, r)]
        elif length == best_len:
            ans.append((l, r))

    return ans


def main():
    n = int(input())
    a = list(map(int, input().split()))
    for s, e in find_best_intervals(a[:n]):
        print(s, e)


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.*;

public class Main {

    // 找所有最长合法恒温区间
    static List<int[]> findBestIntervals(int[] a) {
        int n = a.length;
        int[] cnt = new int[31]; // 温度计数桶
        int l = 0, bestLen = 0;
        List<int[]> ans = new ArrayList<>();

        for (int r = 0; r < n; r++) {
            int v = a[r];
            // 不在承诺温度范围，窗口断开
            if (v < 18 || v > 24) {
                for (int t = 18; t <= 24; t++) cnt[t] = 0;
                l = r + 1;
                continue;
            }

            cnt[v]++;
            // 温差过大则从左侧收缩
            while (getMax(cnt) - getMin(cnt) > 4) {
                cnt[a[l]]--;
                l++;
            }

            int length = r - l + 1;
            if (length > bestLen) {
                bestLen = length;
                ans.clear();
                ans.add(new int[]{l, r});
            } else if (length == bestLen) {
                ans.add(new int[]{l, r});
            }
        }
        return ans;
    }

    static int getMin(int[] cnt) {
        for (int t = 18; t <= 24; t++) {
            if (cnt[t] > 0) return t;
        }
        return 0;
    }

    static int getMax(int[] cnt) {
        for (int t = 24; t >= 18; t--) {
            if (cnt[t] > 0) return t;
        }
        return 0;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = sc.nextInt();
        for (int[] p : findBestIntervals(a)) {
            System.out.println(p[0] + " " + p[1]);
        }
    }
}
```
