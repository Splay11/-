## 解题思路

题目要求选择一条从左上角到右下角的路径，并把路径上所有格子的颜色修改成同一个颜色，使总代价最小。

假设最终统一修改成颜色 $x$，其中 $1 \le x \le C$。

那么路径经过格子 $(i,j)$ 时，需要支付的代价就是：

$$
|a_{ij} - x|
$$

此时问题就变成了：在一个 $N \times M$ 的网格中，每个格子都有一个权值 $|a_{ij} - x|$，只能向右或向下走，求从左上角到右下角的最小路径权值和。

这是经典的动态规划问题。

定义 $dp[i][j]$ 表示当最终统一颜色为 $x$ 时，从 $(0,0)$ 走到 $(i,j)$ 的最小修改代价。

状态转移为：

$$
dp[i][j] = \min(dp[i-1][j], dp[i][j-1]) + |a_{ij} - x|
$$

边界情况：

* 起点：

$$
dp[0][0] = |a_{00} - x|
$$

* 第一行只能从左边走来：$dp[0][j] = dp[0][j-1] + |a_{0j} - x|$
* 第一列只能从上边走来：$dp[i][0] = dp[i-1][0] + |a_{i0} - x|$

由于最终统一的颜色 $x$ 可能是 $1$ 到 $C$ 中的任意颜色，因此枚举所有颜色 $x$，分别计算一次最小路径代价，最后取最小值即可。

整体答案为：

$$
\min_{1 \le x \le C} dp_x[N-1][M-1]
$$

其中 $dp_x[N-1][M-1]$ 表示当路径颜色统一修改为 $x$ 时的最小代价。

对每个颜色 $x$：

1. 新建二维数组 $dp$。
2. 先填起点，再填第一行、第一列。
3. 对其余格子按「上方 / 左方取较小值再加当前代价」转移。
4. 用 $dp[N-1][M-1]$ 更新答案。

## 复杂度分析

设矩阵大小为 $N \times M$，颜色数量为 $C$。

需要枚举每一种最终颜色，共 $C$ 种。

对于每一种颜色，需要遍历整个矩阵一次，时间复杂度为：

$$
O(C \times N \times M)
$$

由于 $1 \le N,M,C \le 50$，最大计算量约为：

$$
50 \times 50 \times 50 = 125000
$$

可以轻松通过。

二维动态规划数组的空间复杂度为：

$$
O(N \times M)
$$

复杂度满足题目要求。

## 代码实现

### Python

```python
def min_cost(n, m, c, a):
    # ans 记录所有最终颜色下的最小路径代价
    ans = 10 ** 18

    # 枚举最终统一修改成的颜色
    for color in range(1, c + 1):
        # dp[i][j]：颜色定为 color 时，走到 (i,j) 的最小代价
        dp = [[0] * m for _ in range(n)]
        dp[0][0] = abs(a[0][0] - color)

        # 第一行只能从左边走来
        for j in range(1, m):
            dp[0][j] = dp[0][j - 1] + abs(a[0][j] - color)

        # 第一列只能从上边走来
        for i in range(1, n):
            dp[i][0] = dp[i - 1][0] + abs(a[i][0] - color)

        for i in range(1, n):
            for j in range(1, m):
                cost = abs(a[i][j] - color)
                # 可以从上方或左方走来，取较小值
                dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + cost

        ans = min(ans, dp[n - 1][m - 1])

    return ans


def main():
    n, m, c = map(int, input().split())
    a = []
    for _ in range(n):
        a.append(list(map(int, input().split())))
    print(min_cost(n, m, c, a))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static int minCost(int n, int m, int c, int[][] a) {
        // ans 记录所有最终颜色下的最小路径代价
        int ans = Integer.MAX_VALUE;

        // 枚举最终统一修改成的颜色
        for (int color = 1; color <= c; color++) {
            // dp[i][j]：颜色定为 color 时，走到 (i,j) 的最小代价
            int[][] dp = new int[n][m];
            dp[0][0] = Math.abs(a[0][0] - color);

            // 第一行只能从左边走来
            for (int j = 1; j < m; j++) {
                dp[0][j] = dp[0][j - 1] + Math.abs(a[0][j] - color);
            }

            // 第一列只能从上边走来
            for (int i = 1; i < n; i++) {
                dp[i][0] = dp[i - 1][0] + Math.abs(a[i][0] - color);
            }

            for (int i = 1; i < n; i++) {
                for (int j = 1; j < m; j++) {
                    int cost = Math.abs(a[i][j] - color);
                    // 可以从上方或左方走来，取较小值
                    dp[i][j] = Math.min(dp[i - 1][j], dp[i][j - 1]) + cost;
                }
            }

            ans = Math.min(ans, dp[n - 1][m - 1]);
        }

        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int m = sc.nextInt();
        int c = sc.nextInt();

        int[][] a = new int[n][m];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                a[i][j] = sc.nextInt();
            }
        }

        System.out.println(minCost(n, m, c, a));
    }
}
```
