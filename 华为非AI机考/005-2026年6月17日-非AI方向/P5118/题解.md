## 解题思路

题目要求选择一条从左上角到右下角的路径，并把路径上所有格子的颜色修改成同一个颜色，使总代价最小。

假设最终统一修改成颜色 $x$，其中 $1 \le x \le C$。

那么路径经过格子 $(i,j)$ 时，需要支付的代价就是：

$$
|a_{ij} - x|
$$

此时问题就变成了：在一个 $N \times M$ 的网格中，每个格子都有一个权值 $|a_{ij} - x|$，只能向右或向下走，求从左上角到右下角的最小路径权值和。

这是经典的动态规划问题。

定义 $dp[i][j]$ 表示当最终统一颜色为 $x$ 时，从 $(0,0)$ 走到 $(i,j)$ 的最小修改代价。

状态转移为：

$$
dp[i][j] = \min(dp[i-1][j], dp[i][j-1]) + |a_{ij} - x|
$$

边界情况：

* 起点：

$$
dp[0][0] = |a_{00} - x|
$$

* 第一行只能从左边走来。
* 第一列只能从上边走来。

由于最终统一的颜色 $x$ 可能是 $1$ 到 $C$ 中的任意颜色，因此枚举所有颜色 $x$，分别计算一次最小路径代价，最后取最小值即可。

整体答案为：

$$
\min_{1 \le x \le C} dp_x[N-1][M-1]
$$

其中 $dp_x[N-1][M-1]$ 表示当路径颜色统一修改为 $x$ 时的最小代价。

实现时可以使用一维数组优化空间。令 $dp[j]$ 表示当前处理到某一行时，到达第 $j$ 列的最小代价。

对于每个颜色 $x$：

1. 初始化 $dp$ 数组。
2. 从左到右、从上到下遍历矩阵。
3. 对每个格子计算当前颜色修改成 $x$ 的代价。
4. 根据当前位置是否在第一行或第一列进行状态转移。
5. 用右下角的结果更新答案。

## 复杂度分析

设矩阵大小为 $N \times M$，颜色数量为 $C$。

需要枚举每一种最终颜色，共 $C$ 种。

对于每一种颜色，需要遍历整个矩阵一次，时间复杂度为：

$$
O(C \times N \times M)
$$

由于 $1 \le N,M,C \le 50$，最大计算量约为：

$$
50 \times 50 \times 50 = 125000
$$

可以轻松通过。

使用一维动态规划数组，空间复杂度为：

$$
O(M)
$$

复杂度满足题目要求。

## 代码实现

### Python

```python
import sys


def min_cost(n, m, c, a):
    # ans 记录所有最终颜色下的最小路径代价
    ans = 10 ** 18

    # 枚举最终统一修改成的颜色
    for color in range(1, c + 1):
        # dp[j] 表示当前行到达第 j 列的最小代价
        dp = [0] * m

        for i in range(n):
            for j in range(m):
                # 当前格子修改成 color 的代价
                cost = abs(a[i][j] - color)

                if i == 0 and j == 0:
                    # 起点只能由自身产生
                    dp[j] = cost
                elif i == 0:
                    # 第一行只能从左边走来
                    dp[j] = dp[j - 1] + cost
                elif j == 0:
                    # 第一列只能从上边走来
                    dp[j] = dp[j] + cost
                else:
                    # 其他位置可以从上方或左方走来，取较小值
                    dp[j] = min(dp[j], dp[j - 1]) + cost

        # 当前颜色下右下角的最小代价
        ans = min(ans, dp[m - 1])

    return ans


def main():
    data = sys.stdin.read().strip().split()
    n = int(data[0])
    m = int(data[1])
    c = int(data[2])

    a = []
    idx = 3
    for _ in range(n):
        row = []
        for _ in range(m):
            row.append(int(data[idx]))
            idx += 1
        a.append(row)

    print(min_cost(n, m, c, a))


if __name__ == "__main__":
    main()
```
