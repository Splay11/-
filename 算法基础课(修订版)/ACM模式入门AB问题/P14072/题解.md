## 【入门题】【输入篇3】A+B+C+... Problem (多行输入版)

## 前言

本题知识讲解:
- 不定行输入
- 使用终端结束输入

### 1. 不定行输入

在 Python 中，处理多行不定数量的输入数据是一个常见的需求，特别是在面对不确定数据量的情况下。可以使用循环来不断读取输入，直到输入结束（EOF）。

#### 1.1 使用 `for` 循环和 `sys.stdin`

Python 提供了多种方式来处理不定组输入，其中一种常用的方法是使用 `sys.stdin` 结合 `for` 循环来逐行读取输入数据。

```python
import sys

def main():
    for line in sys.stdin:
        numbers = list(map(int, line.strip().split()))
        total = sum(numbers)
        print(total)

if __name__ == "__main__":
    main()
```

- `sys.stdin` 是 Python 中的标准输入流对象（standard input stream）。`sys.stdin`代表输入的所有数据。
- 当你使用 `for line in sys.stdin` 时，**它本质上就是一个迭代器**，会**逐行读取输入**。
- 每次循环会从标准输入中读取一整行（直到遇到换行符为止）

#### 1.2 使用 `try-except` 和 `input()`

另一种方法是使用 `while` 循环结合 `try-except` 来处理不定组输入：

```python
def main():
    while True:
        try:
            line = input()
            numbers = list(map(int, line.strip().split()))
            total = sum(numbers)
            print(total)
        except EOFError:
            break

if __name__ == "__main__":
    main()
```

- 在正常情况下，用户会一直输入；但如果用户输入结束并发送了 EOF（结束符），`input()` 无法继续读取，会抛出 `EOFError` 异常。
- 输入结束，`input()`抛出异常，退出循环，从而实现了多行输入。

### 2. 使用终端结束输入

输入 EOF（End Of File，文件结束符），比如：
  - Linux/macOS：按 `Ctrl+D`
  - Windows：按 `Ctrl+Z` 然后回车

输入结束，程序开始运行，输出结果。

## 题解

### 题面分析

题目的意思很简单，输入多行数，每一行包含若干整数，要求计算每一行所有整数的和并输出。由于输入的行数和每行的整数数量不固定，我们需要使用不定组输入的方法来处理。

### 思路

1. **读取输入**：使用循环不断读取每一行的输入，直到输入结束。
2. **处理每一行**：
   - 将每一行的字符串按空格分割成多个部分。
   - 将分割后的字符串转换为整数。
   - 计算这些整数的和。
3. **输出结果**：输出每一行整数的和。

### 代码

```python
# 读取一行输入并转换为整数列表
numbers = list(map(int, input().split()))

# 计算这些数的和并输出
print(sum(numbers))
```

#### 代码解释

1. **读取输入**
    ```python
    numbers = list(map(int, input().split()))
    ```
    - `input()` 函数用于从标准输入（通常是键盘）读取一行输入。
    - `split()` 方法将输入的字符串按空格分割成多个部分，返回一个列表。例如，输入 `"1 2 3"` 会被分割成 `["1", "2", "3"]`。
    - `map(int, ...)` 将列表中的每个元素转换为整数类型。
    - `list(...)` 将 `map` 对象转换为列表。
    - **示例：**
      ```
      输入:
      1 2 3
    
      变量值:
      numbers = [1, 2, 3]
      ```

2. **计算和并输出结果**
    ```python
    print(sum(numbers))
    ```
    - `sum(numbers)` 计算列表中所有整数的和。
    - `print()` 函数用于将结果输出到标准输出（通常是屏幕）。
    - **示例输出:**
      ```
      6
      ```

### 代码

```python
# 读取多行输入并计算每行的和
import sys

def main():
    for line in sys.stdin:
        numbers = list(map(int, line.strip().split()))
        total = sum(numbers)
        print(total)

if __name__ == "__main__":
    main()
```

#### 总结

- **输入**：使用 `input()` 函数或 `sys.stdin` 结合循环读取不定数量的输入。
- **类型转换**：使用 `map(int, ...)` 将输入的字符串转换为整数类型，并使用 `list()` 将其转换为列表。
- **计算和**：使用内置的 `sum()` 函数计算列表中所有数的和。
- **输出**：使用 `print()` 函数输出结果。
