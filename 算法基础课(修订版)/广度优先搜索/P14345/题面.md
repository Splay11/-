# 题目内容

小塔最近正在学习魔法，通过魔法可以改变纸上的数字。

小塔一共会两种魔法，第一种魔法可以将纸上数字变为它的$a$倍，比如在$a=3$时，他可以将$666$变成$1998$;第二种魔法可以让纸上的数字循环右移一次，比如$12345$在施加第二种魔法后会变成$51234$，$119$会变$911$，需要注意的是，小塔无法对小于$10$或是以$0$为结尾的数施加第二种魔法。

纸上的数字初始是$1$，小塔想将它变成自己的幸运数字$b$，那么请问小塔至少需要施加几次魔法。如果无论如何
都无法将它变成$b$,请输出$-1$。

# 输入描述

输入一行，包含两个正整数$a,b$
$2≤a,b<10^6$

# 输出描述

输出一行一个数，表示最少的魔法次数，或输出$-1$表示无解。

## 样例1 

**输入** 

```
3 621
```

**输出** 

```
6
```

**说明**

样例解释$1$

一种可行的方法为:$1->3->9->27->72->216->621$

## 样例2
**输入**
```
3 666
```

**输出**
```
-1
```
