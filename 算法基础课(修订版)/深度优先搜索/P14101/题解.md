## 题解

### 题目描述

给定一张有向无环图（DAG），节点编号从 `1` 到 `n`，每条边由一个起点和终点组成，采用邻接表存储。求从指定起点 `s` 到指定终点 `t` 的路径总数。

---

### 解题步骤与对应代码

#### **1. 输入与图的存储**
   - 读取节点数 `n` 和边数 `m`。
   - 使用邻接表 `g` 存储图。
   - 遍历输入，构建从起点到终点的边。

```python
from collections import defaultdict

def main():
    # 读取节点数和边数
    n, m = map(int, input().split())
    
    # 初始化邻接表
    g = {i: [] for i in range(1,n+1)}
    
    # 读取边的信息并构建邻接表
    for _ in range(m):
        u, v = map(int, input().split())
        g[u].append(v)
```

#### **2. 读取起点和终点**
   - 输入起点 `s` 和终点 `t`。

```python
    # 读取起点s和终点t
    s, t = map(int, input().split())
```


#### **3. 深度优先搜索 (DFS)**
   - 定义递归函数 `dfs(u)`，计算从当前节点 `u` 到终点 `t` 的路径数。
   - 如果当前节点是终点，返回 `1`。
   - 否则，遍历从 `u` 出发的所有邻接节点，递归调用 `dfs(v)`，并累加路径数。
   - 返回累加的路径数。

```python
    def dfs(u):
        """
        递归函数，计算从节点u到终点t的路径数
        """
        # 如果到达终点t，说明找到了一条路径
        if u == t:
            return 1
        
        # 初始化路径数量
        res = 0
        
        # 遍历所有邻接节点并递归计算
        for v in g[u]:
            res += dfs(v)
        
        return res
```

#### **4. 计算结果并输出**
   - 调用 `dfs(s)` 从起点 `s` 开始计算路径总数。
   - 将结果存储到变量 `ans`，并输出。

```python
    # 调用dfs从起点s开始计算路径数量
    ans = dfs(s)
    
    # 输出路径数量
    print(ans)
```

#### **完整代码**

将上述步骤汇总，得到以下完整代码：

```python
from collections import defaultdict

def main():
    # 读取节点数和边数
    n, m = map(int, input().split())
    
    # 初始化邻接表
    g = defaultdict(list)
    
    # 读取边的信息并构建邻接表
    for _ in range(m):
        u, v = map(int, input().split())
        g[u].append(v)
    
    # 读取起点s和终点t
    s, t = map(int, input().split())
    
    def dfs(u):
        """
        递归函数，计算从节点u到终点t的路径数
        """
        # 如果到达终点t，说明找到了一条路径
        if u == t:
            return 1
        
        # 初始化路径数量
        res = 0
        
        # 遍历所有邻接节点并递归计算
        for v in g[u]:
            res += dfs(v)
        
        return res

    # 调用dfs从起点s开始计算路径数量
    ans = dfs(s)
    
    # 输出路径数量
    print(ans)

if __name__ == '__main__':
    main()
```
