### 思路

* **频次统计**：设不同取值共有 $m$ 种，第 $i$ 种值的出现次数为 $n_i$。

* **组合计数**：选择两种不同的值 $i\ne j$，从其中一种取 $3$ 个，另一种取 $2$ 个。对固定的 $(i,j)$，可行子序列数为
  $\binom{n_i}{3}\binom{n_j}{2}$。对所有有序对求和，答案为

  
  ![image](/file/2/nvBvtpF9AzIS1Us7uBLyq.png) 

* **化简到线性**：令
  $S_2=\sum_i\binom{n_i}{2}$，$S_3=\sum_i\binom{n_i}{3}$。则
  
  ![image](/file/2/KJDwbUndhlZ46kFIl-rUv.png) 

* **实现**：统计频次并一次遍历计算 $S_2$、$S_3$ 与自项 $\sum_i \binom{n_i}{3}\binom{n_i}{2}$，最终答案为
  $S_3S_2-\sum_i \binom{n_i}{3}\binom{n_i}{2}$。

* **正确性**：对子序列而言，只需选择位置，不受交错顺序影响；因此对每对取值分别独立选择 $3$ 与 $2$ 个位置并合并即得唯一子序列。
### Python

```python
import sys
from collections import Counter

def C2(c: int) -> int:
    return c * (c - 1) // 2 if c >= 2 else 0

def C3(c: int) -> int:
    return c * (c - 1) * (c - 2) // 6 if c >= 3 else 0

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    arr = [int(next(it)) for _ in range(n)]
    cnt = Counter(arr)

    S2 = 0
    S3 = 0
    self_sum = 0
    for c in cnt.values():
        c2 = C2(c)
        c3 = C3(c)
        S2 += c2
        S3 += c3
        self_sum += c2 * c3

    ans = S3 * S2 - self_sum
    print(ans)

if __name__ == "__main__":
    main()
```
