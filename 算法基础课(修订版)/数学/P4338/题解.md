## 解题思路

先统计每个数位的洞数：

* $0,4,6,9$ 的洞数都是 $1$
* $8$ 的洞数是 $2$
* $1,2,3,5,7$ 的洞数都是 $0$

因此：

* 数字 $0\sim 9$ 的洞数总和为
  $1+0+0+0+1+0+1+0+2+1=6$
* 数字 $1\sim 9$ 的洞数总和为
  $0+0+0+1+0+1+0+2+1=5$

这题需要分两种情况。

对于 $n=1$：

答案直接为：

$$
6
$$

对于 $n\ge 2$：

所有长度为 $n$ 且不含前导 $0$ 的数字，一共有 $9\times 10^{n-1}$ 个。

按数位位置分别统计贡献。

第 $1$ 位：

* 只能取 $1\sim 9$
* 每个数字都会出现 $10^{n-1}$ 次
* 首位总贡献为

$$
5\times 10^{n-1}
$$

后面的第 $2\sim n$ 位：

* 一共有 $n-1$ 位
* 每一位上，$0\sim 9$ 每个数字都会出现 $9\times 10^{n-2}$ 次
* 单独一位的总贡献为

$$
6\times 9\times 10^{n-2}=54\times 10^{n-2}
$$

所以总答案为：

$$
5\times 10^{n-1}+(n-1)\times 54\times 10^{n-2}
$$

提取 $10^{n-2}$：

$$
10^{n-2}\times (50+54(n-1))
$$

化简得：

$$
10^{n-2}\times (54n-4)
$$

所以最终结论是：

* 当 $n=1$ 时，答案为 $6$
* 当 $n\ge 2$ 时，答案为

$$
10^{n-2}\times (54n-4)\bmod 998244353
$$

由于 $n$ 很大，需要用**快速幂算法**计算 $10^{n-2}\bmod 998244353$。

实现方法：

1. 若 $n=1$，直接输出 $6$
2. 否则计算 $10^{n-2}\bmod 998244353$
3. 代入公式
   $(54n-4)\times 10^{n-2}\bmod 998244353$

## 复杂度分析

对于每组测试数据：

* 时间复杂度为 $O(\log n)$，因为使用了快速幂
* 空间复杂度为 $O(1)$

这样的复杂度可以通过题目要求。

## 代码实现

### Python

```python
MOD = 998244353

# 快速幂：计算 a^b % MOD
def qpow(a, b):
    res = 1
    a %= MOD
    while b > 0:
        if b & 1:
            res = res * a % MOD
        a = a * a % MOD
        b >>= 1
    return res

# 计算长度为 n 的所有数字的洞数总和
def solve(n):
    # 特判：n=1 时，0 也算一个一位数
    if n == 1:
        return 6
    # n>=2 时使用推导公式
    return qpow(10, n - 2) * ((54 * (n % MOD) - 4) % MOD) % MOD

if __name__ == "__main__":
    T = int(input())
    for _ in range(T):
        n = int(input())
        print(solve(n))
```
