## 解题思路

* 末尾连续零来源于因子 2 与 5 的配对，某段乘积末尾零的个数等于 `min(2 的总次数, 5 的总次数)`。
* 将每个元素 `a[i]` 拆成 `(cnt2[i], cnt5[i])`，其中 `cntp[i]` 是 `a[i]` 中质因子 `p` 的个数（只需分解 2 和 5，反复整除即可）。
* 问题转化为：统计区间 `[l, r]` 使得
  `sum2(l, r) ≥ k 且 sum5(l, r) ≥ k`。
  这是一个**双指针/滑动窗口**问题（所有计数均为非负）。
* 具体做法

  1. 预处理得到 `cnt2[i], cnt5[i]`。
  2. 维护窗口 `[l, r)` 的当前和 `cur2, cur5`。对每个 `l`，向右移动 `r`，直到同时满足 `cur2 ≥ k 且 cur5 ≥ k`，
     此时以 `l` 为起点的合法子数组个数为 `n - r + 1`（任意更远的右端点都满足）；
     然后把 `l` 向右移动一格并从 `cur2/cur5` 中减去对应计数，继续进行。
* 算法核心：只分解 2 和 5 + 单调扩展的双指针，整体线性遍历一次。

## 复杂度分析

* 分解每个数对 2 和 5 的次数，复杂度为 `O(log a[i])`；
  双指针线性扫描 `O(n)`。
* 总时间复杂度：`O(n + Σ log a[i])`，在数据范围内可行。
* 额外空间复杂度：`O(n)` 存储两组计数（也可边读边计算降到 `O(1)`，此处实现使用 `O(n)` 更直观）。

## 代码实现

### Python

```python
# -*- coding: utf-8 -*-
import sys

def count_factor(x: int, p: int) -> int:
    """计算 x 中质因子 p 的个数"""
    c = 0
    while x % p == 0:
        x //= p
        c += 1
    return c

def solve(a, k):
    n = len(a)
    c2 = [0]*n
    c5 = [0]*n
    # 只分解 2 和 5
    for i, v in enumerate(a):
        c2[i] = count_factor(v, 2)
        c5[i] = count_factor(v, 5)

    ans = 0
    l = 0
    r = 0
    cur2 = 0
    cur5 = 0
    # 滑动窗口 [l, r)
    while l < n:
        while r < n and (cur2 < k or cur5 < k):
            cur2 += c2[r]
            cur5 += c5[r]
            r += 1
        if cur2 >= k and cur5 >= k:
            ans += (n - r + 1)
        # 移动左端点
        cur2 -= c2[l]
        cur5 -= c5[l]
        l += 1
    return ans

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); k = int(next(it))
    a = [int(next(it)) for _ in range(n)]
    print(solve(a, k))

if __name__ == "__main__":
    main()
```
