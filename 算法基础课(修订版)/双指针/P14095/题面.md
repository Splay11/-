### 题目描述：

给定一个字符串 `s`，要求找到其中一个最短的子串，使得该子串包含了所有的小写字母（`a` 至 `z`）。如果不存在这样的子串，返回 `-1`。

请注意，字符串中的字母不需要按顺序排列，且可能包含重复字母。

### 输入：
- 一个字符串 `s`，长度 `n`，满足 $1 \leq n \leq 10^5$。

### 输出：
- 返回一个整数，表示满足条件的最短子串的长度。如果不存在这样的子串，返回 `-1`。

### 示例：

#### 输入 1：
```
ykjygvedtysvyymzfizzwkjamefxjnrnphqwnfhrnbhwjhqcgqnplodeestu
```

#### 输出 1：
```
49
```

#### 输入 2：
```
aabccabc
```

#### 输出 2：
```
-1
```
