# 题目内容

给定一个长度为 $n$ 的**非递减**整数数组 $a_0,a_1,\ldots,a_{n-1}$（已排好序，允许重复），以及一个整数 $T$。数组下标从 $0$ 开始。

请输出四个整数，依次表示：

1. $T$ 在数组中**第一次出现**的下标；若不存在，输出 $-1$。
2. $T$ 在数组中**最后一次出现**的下标；若不存在，输出 $-1$。
3. 满足 $a_i < T$ 的**最大下标**；若不存在这样的 $i$，输出 $-1$。
4. 满足 $a_i > T$ 的**最小下标**；若不存在这样的 $i$，输出 $-1$。

# 输入描述

第一行两个整数 $n$、$T$。

第二行 $n$ 个整数 $a_0,a_1,\ldots,a_{n-1}$，保证 $a_0\le a_1\le \cdots\le a_{n-1}$。

### 约束

$1 \le n \le 10^5$

$-10^9 \le a_i,T \le 10^9$

# 输出描述

输出一行四个整数，分别对应上述四个答案，相邻整数之间用一个空格分隔。

## 样例1

**输入**

```text
5 2
1 2 2 2 4
```

**输出**

```text
1 3 0 4
```

**说明**

$T=2$ 出现在下标 $1,2,3$。第一次出现是 $1$，最后一次出现是 $3$。小于 $2$ 的最大下标是 $0$（值为 $1$），大于 $2$ 的最小下标是 $4$（值为 $4$）。

## 样例2

**输入**

```text
4 3
1 2 4 5
```

**输出**

```text
-1 -1 1 2
```

**说明**

数组中没有 $3$，因此前两个答案为 $-1$。小于 $3$ 的最大下标是 $1$（值为 $2$），大于 $3$ 的最小下标是 $2$（值为 $4$）。
