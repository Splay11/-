# P5416 测试数据说明

下标从 $0$ 开始。四个答案依次为：$T$ 首次、$T$ 末次、严格小于 $T$ 的最大下标、严格大于 $T$ 的最小下标；不存在则 $-1$。

| 组别 | 规模/分布 | 生成逻辑 | 卡掉的错误解 |
|---|---|---|---|
| 1 | n=5，样例1 | 数组 [1,2,2,2,4]，T=2，覆盖一段重复值的两端邻居 | 1-indexed 输出；把 last 写成 first+1 |
| 2 | n=4，样例2 | T=3 夹在 2 与 4 之间，数组中不出现 | T 不存在时把 first/last 写成插入点而不是 -1 |
| 3 | n=1，命中 | 单元素等于 T | pred/succ 误写成 0；first/last 写成 1 |
| 4 | n=1，T 小于唯一元素 | 没有小于 T 的下标，succ 应为 0 | pred 写成 0；succ 写成 1 或 n |
| 5 | n=12，全相等 | 每个元素都是 T，first=0，last=n-1，左右邻居都不存在 | pred 写成 -1 以外的值；succ 输出 n |
| 6 | n=7，含负数与值域边界 | T 大于全部元素，first/last/succ 均为 -1，pred=n-1 | succ 输出 n；整数比较时把 1e9 当越界 |
| 7 | n=9，两段重复夹空档 | T=0 不出现，pred 落在 -2 段末尾，succ 落在 4 段开头 | 把 < 写成 <=，pred 会落到 4 段；lower/upper 搞反 |
| 8 | n=22，随机重复簇 | 八段随机长度的重复簇，T 取中间某个已有值 | 重复值时二分左右边界写错，last 不等于整段右端 |
| 9 | n=100000，中间 80000 个 7 | T 命中超长重复段，first/last 跨度很大 | 只找到第一个就当 last；或线性扫错写成 first+1 |
| 10 | n=100000，T=1e9 不在数组 | 严格递增填满约 [-5e4,5e4)，T 大于全部 | succ 输出 n；T 不存在时 first 写成 n 或 0 |
