# 【二分】有序数组的四个位置

数组已经非递减排好。四个答案都可以由两次二分得到，不必从左扫到右。

把数组想成两段分界：

- $lower$：第一个满足 $a_i \ge T$ 的下标；若不存在，记为 $n$。
- $upper$：第一个满足 $a_i > T$ 的下标；若不存在，记为 $n$。

于是数组被切成三段：

```
[0, lower)     全是 < T
[lower, upper) 全是 = T（可能为空）
[upper, n)     全是 > T
```

四个答案直接从这两道分界读出来：

1. $T$ 第一次出现：若 $lower < n$ 且 $a_{lower}=T$，答案是 $lower$，否则 $-1$。
2. $T$ 最后一次出现：若 $upper>0$ 且 $a_{upper-1}=T$，答案是 $upper-1$，否则 $-1$。
3. 满足 $a_i < T$ 的最大下标：就是 $lower-1$；若 $lower=0$，没有更小的数，答案 $-1$。
4. 满足 $a_i > T$ 的最小下标：就是 $upper$；若 $upper=n$，没有更大的数，答案 $-1$。

$lower$ 用「找第一个 $\ge T$」：$a[mid] < T$ 时左边界右移，否则右边界收到 $mid$。
$upper$ 用「找第一个 $> T$」：$a[mid] \le T$ 时左边界右移，否则右边界收到 $mid$。

注意下标从 $0$ 开始。找不到时输出 $-1$，不要输出 $n$。

样例 $1$ 中 $T=2$ 占下标 $1..3$，所以四个答案是 $1,\ 3,\ 0,\ 4$。样例 $2$ 中没有 $3$，$lower$ 与 $upper$ 都是 $2$，前两个答案为 $-1$，后两个仍由插入点给出。

## 复杂度分析

- 时间复杂度：$O(\log n)$，两次二分。
- 空间复杂度：$O(1)$（不计读入数组）。

$n \le 10^5$，线性扫描也能过小数据，最大数据用二分更稳妥。

## 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 返回四个答案：首次、末次、小于 T 的最大下标、大于 T 的最小下标
vector<int> queryPositions(const vector<int>& a, int T) {
    int n = (int)a.size();

    // 求第一个 >= T 的下标（即 lower_bound），找不到则等于 n
    int left = 0, right = n;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (a[mid] < T) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }
    int lower = left;

    // 求第一个 > T 的下标（即 upper_bound），找不到则等于 n
    left = 0;
    right = n;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (a[mid] <= T) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }
    int upper = left;

    // T 的首次出现就是 lower；该位置越界或值不是 T 则不存在
    int first = (lower < n && a[lower] == T) ? lower : -1;
    // T 的末次出现就是 upper-1；该位置合法且值是 T 才算找到
    int last = (upper > 0 && a[upper - 1] == T) ? upper - 1 : -1;
    // 小于 T 的数全在 lower 左侧，最大下标是 lower-1
    int pred = (lower > 0) ? lower - 1 : -1;
    // 大于 T 的数从 upper 开始，越界则不存在
    int succ = (upper < n) ? upper : -1;
    return {first, last, pred, succ};
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // 第一行：长度与目标值
    int n, T;
    cin >> n >> T;
    // 第二行：非递减数组
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    vector<int> ans = queryPositions(a, T);
    cout << ans[0] << ' ' << ans[1] << ' ' << ans[2] << ' ' << ans[3] << '\n';
    return 0;
}
```
