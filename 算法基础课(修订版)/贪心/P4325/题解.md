## 解题思路

### 核心贪心：能切就立刻切

从左到右维护当前未结束段的 $\gcd$ 与长度。当第一次出现

$$
\gcd \le \text{当前长度}
$$

时，**立即在这里切一刀**，计数 $+1$，然后从下一个位置重新开始一段。

这么做的正确性在于：

* $\gcd$ 只会随着段的延长而**不增**，而长度只会**变大**，因此一旦满足条件，继续延长也只会“更容易”满足，但为了**最大化段数**，应当尽早切。
* 如果最终有一段尾巴一直没有满足条件，那么将这段尾巴并回**上一个已完成的优美段**。设上一个完成段的 $\gcd$ 为 $g_{\text{pre}}$，长度为 $len_{\text{pre}}$，则合并后的 $\gcd\le g_{\text{pre}}$$\le len_{\text{pre}}$ < $len_{\text{pre}}+\text{尾巴长度}$，因此合并后**仍是优美段**。
  于是最终合法划分的段数就是“已完成的段数”。
  如果从头到尾一次都没能完成一段，则答案为 `-1`。

### 算法步骤

1. 初始化 `g=0, len=0, ans=0`。
2. 依次枚举每个元素 `x`：

   * `g = gcd(g, x)`，`len += 1`。
   * 若 `g <= len`：则完成一个优美段，`ans += 1`，并重置 `g=0, len=0`。
3. 扫描结束后：

   * 若 `ans == 0`，输出 `-1`（全程没有形成任何一段）。
   * 否则输出 `ans`（若有尾巴则与上一段合并，但段数不变）。

### 复杂度分析

* 每个元素被处理常数次；$\gcd$ 的均摊复杂度很低。
* 总体时间复杂度：$O(n \log A_{\max})$，满足 $\sum n \le 2\times10^5$ 的要求。
* 额外空间复杂度：$O(1)$。

## 参考实现

### Python

```python
import sys
import math

def solve_one(a):
    g = 0
    ln = 0
    ans = 0
    for x in a:
        g = math.gcd(g, x)
        ln += 1
        if g <= ln:          # 能切就切
            ans += 1
            g = 0
            ln = 0
    return -1 if ans == 0 else ans

def main():
    data = sys.stdin.read().strip().split()
    it = iter(data)
    T = int(next(it))
    out = []
    for _ in range(T):
        n = int(next(it))
        arr = [int(next(it)) for _ in range(n)]
        out.append(str(solve_one(arr)))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```
