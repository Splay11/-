### 思路

本题核心在于：

* 相同点赞数的 $Plog$ 不能在同一个连续序列中重复出现（因为点赞数唯一性要求），所以同一个点赞值的 $Plog$ 一定会分散到不同收藏夹中
* 收藏夹的连续性要求，意味着我们会按点赞数**排序**，并将其划分为若干段连续区间
* 每个收藏夹的成本（杂乱度）由该段中最大$c_i$决定

---

#### 思路步骤

1. **按点赞数 $a_i$ 分组**
   建立一个映射 $map[a]$，存储该点赞值的所有 $c_i$，因为相同点赞值的 $Plog$ 会被分散到不同收藏夹中。

2. **每组按 $c_i$ 降序或升序排序**
   我们会不断从这些组中取出一个 $Plog$ 组成一个收藏夹的连续序列。

3. **贪心组收藏夹**
   从点赞值的集合中选择最大值开始，向左延伸，直到连续性被打破（比如缺少点赞值，或者点赞值不连续）。
   在延伸的过程中：

   * 从每个点赞值组中取出一个杂乱度（**取最大的一个，因为收藏夹中最终会选最大 $c_i$**）
   * 用该收藏夹所有取出的 $c_i$ 中最大的一个作为该收藏夹成本，加到总和上

4. **重复操作，直到所有 $Plog$ 都被分组**

---

### 贪心正确性

* 同一组点赞值内取最大的 $c_i$（剩余时再取次大的），能保证该收藏夹成本最小化，因为若延续收藏夹，增加的点赞值会直接影响收藏夹成本。
* 从最高点赞值往下取，保证一次性尽可能多地延续区间，减少收藏夹数量，从而减少成本累积。
### Python 

```python
import sys
input = sys.stdin.readline

T = int(input())
for _ in range(T):
    n = int(input().strip())
    a = list(map(int, input().split()))
    c = list(map(int, input().split()))

    # 点赞值 -> 杂乱度列表
    mp = {}
    for ai, ci in zip(a, c):
        mp.setdefault(ai, []).append(ci)

    # 每个点赞值对应的杂乱度排序
    for k in mp:
        mp[k].sort()

    # 所有点赞值排序
    keys = sorted(mp.keys())
    ans = 0

    # 贪心组收藏夹
    while keys:
        while keys and keys[-1] not in mp:
            keys.pop()
        if not keys:
            break
        cur_max = 0
        # 从最大点赞值向左延续
        for i in range(len(keys) - 1, -1, -1):
            if i != len(keys) - 1 and keys[i] != keys[i + 1] - 1:
                break
            if keys[i] not in mp:
                break
            cur_max = max(cur_max, mp[keys[i]].pop())
            if not mp[keys[i]]:
                del mp[keys[i]]
        ans += cur_max
    print(ans)
```
