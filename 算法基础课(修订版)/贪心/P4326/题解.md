## 解题思路

### 关键观察

* 每个数只能不断对半下降，最终可能变为 `0`；因此一个数最终能变成的值集合是它不断对半后的所有值。
* 目标是让每个 `1..n` 都恰好被占用一次。

### 贪心策略（正确性直观说明）

* 将数组按从大到小排序，依次尝试把大的数“压缩”到当前仍可用且不超过 `n` 的值：

  * 对当前数 `x`：当 `x > n` 或该值已被占用时，将其设为$\lfloor \frac {x} {2} \rfloor$，直至可用或为 `0`。
  * 若最后变为 `0` 仍不可用，则失败（输出 NO）。
* 先处理大的数更安全：大的数选择空间更小，优先分配能避免与小数“抢”小位置，经典贪心交换论证可证其最优。

### 算法步骤

* 对每组数据：

  * 将数组降序排序。
  * 维护 `used[1..n]` 记录哪些位置被占用。
  * 依次处理每个数，按上面的规则对半并占位。
  * 若全部成功占满则 YES，否则 NO。

## 复杂度分析

* 每个元素最多对半约 `log2(ai)` 次（`ai ≤ 1e9`，约 30 次）。
* 时间复杂度：O(n log n + n log A) ≈ O(n log n)，`A` 为数值上界。
* 空间复杂度：O(n)。

## 代码

### Python

```python
import sys

# 读入多组数据并判定是否能构成 1..n 的排列
def main():
	data = list(map(int, sys.stdin.buffer.read().split()))
	if not data:
		return
	t = data[0]
	idx = 1
	out = []
	for _ in range(t):
		n = data[idx]; idx += 1
		a = data[idx:idx + n]; idx += n
		a.sort(reverse=True)  # 降序
		used = [False] * (n + 1)
		ok = True
		for x in a:
			while x > n or (x > 0 and used[x]):
				x //= 2
			if x == 0:
				ok = False
				break
			used[x] = True
		out.append("YES" if ok else "NO")
	print("\n".join(out))

if __name__ == "__main__":
	main()
```
