### 递归反转字符串 - Python 实现

#### 题目描述

本题要求使用递归算法来实现一个函数，将给定的字符串反转。你需要编写一个递归函数，该函数接受一个字符串，并返回该字符串的反转版本。要注意，递归的基准条件是当字符串的长度为1或为空时，直接返回原字符串。

#### 思路解析

我们可以使用递归的方法来实现字符串的反转。具体思路如下：

1. **递归终止条件**：当字符串的长度为1或为空时，返回字符串本身，因为单个字符或者空字符串本身就是其反转。  
   
   代码：
   ```python
   if len(s) <= 1:
       return s
   ```

2. **递归分解**：对于一个长度大于1的字符串，我们将字符串分解为两部分：第一个字符和剩余部分。然后，递归地反转剩余部分，再将第一个字符拼接到反转后的剩余部分的末尾。  
   
   代码：
   ```python
   return reverse_string(s[1:]) + s[0]
   ```

   这里使用了字符串切片 `s[1:]` 获取去掉第一个字符后的子字符串，然后递归反转剩余部分，再将当前字符 `s[0]` 加到结果的末尾。

3. **递归的基本过程**：
   - 将字符串分解成首字符和剩余部分。
   - 递归反转剩余部分。
   - 拼接首字符到反转结果的末尾。

#### 代码实现

```python
# 递归函数：反转字符串
def reverse_string(s):
    # 基准条件：如果字符串为空或长度为1，直接返回原字符串
    if len(s) <= 1:
        return s
    # 递归：反转剩余部分，拼接当前字符
    return reverse_string(s[1:]) + s[0]

# 主函数
if __name__ == "__main__":
    s = input()  # 输入字符串
    print(reverse_string(s))  # 输出反转后的字符串
```

#### 递归流程示例

假设输入为字符串 `"abcde"`，递归的调用过程如下：

1. `reverse_string("abcde")`
   - 递归调用 `reverse_string("bcde")`，并将 `"a"` 添加到结果末尾。

2. `reverse_string("bcde")`
   - 递归调用 `reverse_string("cde")`，并将 `"b"` 添加到结果末尾。

3. `reverse_string("cde")`
   - 递归调用 `reverse_string("de")`，并将 `"c"` 添加到结果末尾。

4. `reverse_string("de")`
   - 递归调用 `reverse_string("e")`，并将 `"d"` 添加到结果末尾。

5. `reverse_string("e")`
   - 由于字符串长度为1，返回 `"e"`。

然后，递归逐层回溯，并拼接结果：

```
reverse_string("e") → "e"
reverse_string("de") → "e" + "d" = "ed"
reverse_string("cde") → "ed" + "c" = "edc"
reverse_string("bcde") → "edc" + "b" = "edcb"
reverse_string("abcde") → "edcb" + "a" = "edcba"
```

最终输出 `"edcba"`。
