## 解题思路与方法

### 问题描述

给定一个只包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。映射关系同电话按键：

```
2 → abc, 3 → def, 4 → ghi, 5 → jkl,
6 → mno, 7 → pqrs,8 → tuv, 9 → wxyz
```

要求按字典序返回所有组合。

### 回溯（DFS）

1. **定义映射**：用数组或哈希表保存每个数字对应的字母串。
2. **回溯流程**：

   * 维护一个临时字符序列 `path`，以及当前遍历到的下标 `idx`。
   * 如果 `idx == n`（已处理完所有数字），将 `path` 拼成字符串加入结果。
   * 否则，取出当前数字对应的所有字母，依次将该字母添加到 `path`，递归处理下一个位置；回溯时撤销添加。
3. **初始调用**：从 `idx=0`，空 `path` 开始。


## 复杂度分析

* 设输入长度为 `n`，平均每个数字对应 `k` 个字母（最多 4），总组合数为 `O(k^n)`。
* **时间复杂度**：`O(k^n)`，生成每个组合需要 `O(n)` 时间，整体约 `O(n·k^n)`。
* **空间复杂度**：递归栈深度 `O(n)`，以及结果集存储 `O(n·k^n)`。

## 代码实现

### Python 版本

```python
def comb(digits):
    # 电话按键映射
    mp = {
        '2': "abc", '3': "def", '4': "ghi", '5': "jkl",
        '6': "mno", '7': "pqrs", '8': "tuv", '9': "wxyz"
    }
    res = []
    n = len(digits)
    if n == 0:
        return res

    # 回溯函数
    def dfs(idx, path):
        if idx == n:
            res.append("".join(path))
            return
        for ch in mp[digits[idx]]:
            path.append(ch)       # 选择
            dfs(idx+1, path)      # 递归
            path.pop()            # 撤销

    dfs(0, [])
    return res

# 示例
if __name__ == "__main__":
    s = input().strip()
    for out in comb(s):
        print(out)
```
