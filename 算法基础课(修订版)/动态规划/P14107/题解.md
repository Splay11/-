# 【动态规划2】二维矩阵路线方案数问题

## 题解
### 解题思路

这是一个典型的组合数学与动态规划相结合的问题。我们需要计算从起点 $(1, 1)$ 到终点 $(n, n)$ 的所有可能路径的数量，每一步只能向右或向下移动一个格子。通过分析小规模的情况，我们可以总结出适用于任意 $n$ 的递推关系，从而高效地解决问题。

---

### Step1: 讨论 \(n = 3\) 的情况

对于 $n = 3$，即一个 $3 \times 3$ 的矩阵，从起点 $(1, 1)$ 到终点 $(3, 3)$ 的所有可能路径如下（共6种）：

1. 右 → 右 → 下 → 下
2. 右 → 下 → 右 → 下
3. 右 → 下 → 下 → 右
4. 下 → 右 → 右 → 下
5. 下 → 右 → 下 → 右
6. 下 → 下 → 右 → 右

将这些方案的集合定义为 $D_3$，那么集合的大小 $|D_3| = 6$就是问题的答案。

---

### Step2: 情况分类

考虑到达终点 $(3, 3)$ 的方式，可以从两种途径到达：

1. **最后一步从 $(3, 2)$ 向右移动到 $(3, 3)$**。
2. **最后一步从 $(2, 3)$ 向下移动到 $(3, 3)$**。

根据这两种情况，我们可以将集合 $D_3$ 分为两部分：

- $D_{3, (3,2) \rightarrow (3,3)}$：最后一步从 $(3, 2)$ 向右移动到 $(3, 3)$。
- $D_{3, (2,3) \rightarrow (3,3)}$：最后一步从 $(2, 3)$ 向下移动到 $(3, 3)$。

---

### Step3: 等价映射

通过集合的划分可以观察到：

- **$D_{3, (3,2) \rightarrow (3,3)}$**：将最后的 $(3,3)$ 去掉，得到的方案**等价于**从 $(1, 1)$ 到 $(3, 2)$ 的所有方案，即 $|D_{3, (3,2) \rightarrow (3,3)}| = |D_{3,2}|$。
  
- **$D_{3, (2,3) \rightarrow (3,3)}$**：将最后的 $(3,3)$ 去掉，得到的方案**等价于**从 $(1, 1)$ 到 $(2, 3)$ 的所有方案，即 $|D_{3, (2,3) \rightarrow (3,3)}| = |D_{2,3}|$。

由于从 $(1, 1)$ 到 $(3, 2)$ 和 $(2, 3)$ 的路径数分别等于从 $(1, 1)$ 到 $(2, 2)$ 和 $(1, 1)$ 到 $(1, 3)$ 的路径数，我们可以进一步简化。

---

### Step4: 递推方程

通过上述分析，可以得出递推关系：

$$
|D_{i,j}| = |D_{i-1,j}| + |D_{i,j-1}|
$$

其中，$D_{i,j}$ 表示从起点 $(1, 1)$ 到达位置 $(i, j)$ 的路径总数。

---

### Step5: 推广情况

对于任意 $n \times n$ 的矩阵，定义 $D[i][j]$表示从 $(1, 1)$ 到达 $(i, j)$ 的路径总数。根据递推关系，我们有：

$$
D[i][j] = D[i-1][j] + D[i][j-1]
$$

这意味着，到达 $(i, j)$ 的路径数等于从上方 $(i-1, j)$ 到达该点的路径数加上从左方 $(i, j-1)$ 到达该点的路径数。

---

### Step6: 边界条件

在动态规划中，需要明确边界条件来初始化状态转移：

1. **起点 $(1, 1)$ 的路径数**：只能停留在起点，因此 $D[1][1] = 1$。

2. **第一行和第一列的路径数**：
   - 对于第一行的每个位置 $(1, j)$，只能一直向右移动到达，因此 $D[1][j] = 1$。
   - 对于第一列的每个位置 $(i, 1)$，只能一直向下移动到达，因此 $D[i][1] = 1$。

---

### Step7: 总结

1. **状态定义**：  
   $D[i][j]$ 表示从起点 $(1, 1)$ 到达位置 $(i, j)$ 的路径总数。

2. **状态转移方程**：  
   $$
   D[i][j] = D[i-1][j] + D[i,j-1]
   $$

3. **边界条件**：  
   - $D[1][1] = 1$
   - $D[1][j] = 1$（对于所有 $1 \leq j \leq n$）
   - $D[i][1] = 1$（对于所有 $1 \leq i \leq n$）

通过动态规划的方法，我们可以高效地计算出从起点到终点的所有可能路径数。

---

### python完整代码
```python
n = int(input())  # 读取输入的整数n，表示网格的大小（n x n）

# 初始化二维动态规划数组dp，大小为n x n，所有元素初始为0
dp = [[0] * n for _ in range(n)]

dp[0][0] = 1  # 设置起点dp[0][0]为1，表示从起点到起点有1种路径

# 遍历每一个网格单元
for i in range(n):
    for j in range(n):
        if i > 0:
            dp[i][j] += dp[i - 1][j]  # 如果不是第一行，则可以从上方单元到达当前单元
        if j > 0:
            dp[i][j] += dp[i][j - 1]  # 如果不是第一列，则可以从左侧单元到达当前单元

print(dp[n - 1][n - 1])  # 输出从起点(0,0)到终点(n-1,n-1)的路径总数
```
