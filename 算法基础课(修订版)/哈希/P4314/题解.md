## 思路解析

题目要求：对每个前缀，统计所有子串中首字母和尾字母不相等的个数。

关键点：

1. **子串总数**：长度为 `i` 的前缀一共有 `i*(i+1)/2` 个子串。
2. **包裹字符串数量**：子串首尾相等，来源于相同字母的出现位置。

   * 如果某个字母在前缀中出现了 `f` 次，那么它能构成的“包裹子串”数量是 `f*(f+1)/2`。
3. **答案计算**：
   每个前缀答案 = 子串总数 − 包裹子串数。

### 增量计算方式

我们可以一边遍历字符串，一边维护：

* `tot`：前缀子串总数，每次加上当前下标 `i`。
* `wrap`：前缀中的包裹子串数量。当前字符 `x` 在前面已经出现过 `f` 次，那么新加进来的所有新包裹子串数量正好是 `f+1`（包括单个新字符本身）。
* 更新频次数组 `freq[x]++`。

这样每一步就能快速算出答案，时间复杂度 O(n)，空间复杂度 O(1)。


## 复杂度分析

* 时间复杂度：O(n)，只遍历一遍字符串。
* 空间复杂度：O(1)，仅需统计 26 个小写字母频次。


## 代码实现

### Python

```python
import sys

def main():
    n = int(sys.stdin.readline().strip())
    s = sys.stdin.readline().strip()

    freq = [0] * 26
    tot = 0
    wrap = 0
    res = []

    for i, ch in enumerate(s, 1):
        tot += i                 # 前缀子串总数增加 i
        k = ord(ch) - 97
        wrap += freq[k] + 1      # 新增包裹子串数量
        freq[k] += 1
        res.append(str(tot - wrap))

    print("\n".join(res))

if __name__ == "__main__":
    main()
```
