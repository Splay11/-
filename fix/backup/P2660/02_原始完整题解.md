### 题目描述

给定一个只由字符 $'0'$ 和 $'1'$ 构成的字符串 $s$（长度范围为 $[2,200000]$）。操作为：  
选择两个不同位置 $i$ 和 $j$（满足 $i \neq j$），交换 $s_i$ 和 $s_j$。  
要求计算经过恰好一次操作后，能够得到多少个不同的字符串。

---

### 思路分析

1. **交换相同字符的情况**  
   - 当交换的是两个相同的字符（例如两个 $'0'$ 或两个 $'1'$）时，交换后字符串保持不变，即仍为原字符串。  
   - 只要字符串中存在至少一对相同的字符（即满足 $cnt_0 \ge 2$ 或 $cnt_1 \ge 2$），原字符串就会作为一种结果被计算在内。

2. **交换不同字符的情况**  
   - 当交换的是不同字符，即一个 $'0'$ 和一个 $'1'$ 时，交换后字符串必然发生改变。  
   - 设字符串中 $'0'$ 的个数为 $cnt_0$，$'1'$ 的个数为 $cnt_1$，则不同字符交换的方案数为 $cnt_0 \times cnt_1$。  
   - 注意，每一对交换后产生的新字符串都不同，因为交换后位置发生了变化。

---

## C++ 实现

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    string s;
    cin >> s;
    // 统计 '0' 和 '1' 的个数
    long long cnt0 = 0, cnt1 = 0;
    for (char c : s) {
        if (c == '0') cnt0++;
        else if (c == '1') cnt1++;
    }
    
    // 不同字符交换的结果数为 cnt0 * cnt1
    long long res = cnt0 * cnt1;
    // 如果存在相同字符的交换（至少有一对相同字符），则结果中包含原字符串
    if (cnt0 >= 2 || cnt1 >= 2) res++;
    
    cout << res << "\n";
    return 0;
}
```
## Python 实现

```python
# 读取输入字符串
s = input().strip()

# 统计 '0' 和 '1' 的个数
cnt0 = s.count('0')
cnt1 = s.count('1')

# 计算不同字符交换结果数
res = cnt0 * cnt1

# 如果存在相同字符交换，则加上原字符串的情况
if cnt0 >= 2 or cnt1 >= 2:
    res += 1

# 输出结果
print(res)
```
## Java 实现

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        // 读取输入字符串
        String s = sc.next();
        sc.close();
        
        // 统计 '0' 和 '1' 的个数
        long cnt0 = 0, cnt1 = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '0') cnt0++;
            else if (c == '1') cnt1++;
        }
        
        // 计算不同字符交换结果数
        long res = cnt0 * cnt1;
        // 如果存在相同字符交换，则加上原字符串的情况
        if (cnt0 >= 2 || cnt1 >= 2) res++;
        
        // 输出结果
        System.out.println(res);
    }
}
```
