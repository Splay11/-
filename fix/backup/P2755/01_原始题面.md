# 题目内容

小红有一个长度为$n$的字符串，字符串仅包含$e,l,m$三种字符。如果一个字符串满足，不存在连续的$ee、lm、ml、ll、mm$子串，则称这个字符串为 $eleme$ 型字符串。

小红想知道，这个字符串能否重排为$eleme$型字符串。



# 输入描述

输入一个长度为不超过$100000$的字符串$s$，字符串仅包含$e,l,m$三种字符。

# 输出描述

输出一个字符串，如果可以重排为$eleme$型字符串，则输出重排后的字符串，否则输出$No$。

如果存在多个解决方案，您可以输出任意一个，系统会自动判定是否正确。注意，自测运行功能可能因此返回错误结果，请自行检查答案正确性。



## 样例1 

**输入** 

```
eeelm
```

**输出** 

```
eleme
```

#### **说明**

输出$emele$也是可以的。

## 样例2

**输入** 

```
eeelme
```

**输出** 

```
No
```
