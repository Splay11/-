# 题目内容

在数据中心网络中，每条链路有对应的安全等级，需要通过对应等级的通行许可才能穿越。网络中的特权节点可以免费为途经者颁发任意等级的通行许可。

给定一张 $n$ 个节点的有向图，初始位于节点 $1$，目标为节点 $n$。图中共有 $k$ 个安全等级。你需要经过**至少一个**特权节点，问最小的通行许可总开销是多少。

# 输入描述

第一行三个整数 $n, m, k$ ($1 \le n, k, m \le 200000$)，分别表示节点数、链路数、安全等级数。

接下来 $k$ 行，每行一个整数 $r_i$ ($1 \le r_i \le n$)，表示每个特权节点所在的位置。保证各 $r_i$ 互不相同。

接下来 $m$ 行，每行三个整数 $u_i, v_i, w_i$ ($1 \le u_i, v_i \le n$, $1 \le w_i \le k$)，表示一条从 $u_i$ 指向 $v_i$、安全等级为 $w_i$ 的有向链路。

# 输出描述

输出一行一个整数，表示能到达节点 $n$ 且至少经过一个特权节点所需的最小总开销。若无法满足条件，输出 $-1$。

## 样例1

**输入**

```
5 4 2
3
4
1 2 1
2 3 2
3 5 1
4 5 2
```

**输出**

```
3
```

**说明**

先花费等级 1 的开销从 $1$ 走到 $2$（开销 $1$），再花费等级 2 的开销从 $2$ 走到特权节点 $3$（开销 $2$）。到达特权节点 $3$ 后获得任意等级的免费许可，走等级 1 的链路 $3 \to 5$（免费，因为已有许可）。总开销 $1 + 2 = 3$。
