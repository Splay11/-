# 题目描述

小红正在开发一个指令系统。系统允许注册多个同名指令，只要它们的参数类型列表不同，就可以同时存在。

每个指令实际上可以看作一个函数，你需要模拟这些函数的**定义**与**调用**。

系统共有两种操作。

### 1. 定义函数

输入格式为：

```text
返回类型 函数名(变量类型1 变量名1,变量类型2 变量名2,...)
```

函数体被省略。

对于同一个函数名，如果已经存在一个**参数类型列表完全相同**的函数，则不能再次定义。

注意，判断是否重复定义时，只考虑**函数名和参数类型列表**，不考虑返回类型和参数名。

若定义成功，输出：

```text
Yes.
```

若发生重复定义，输出：

```text
redefinition of xxx.
```

其中 `xxx` 表示函数名。

### 2. 调用函数

输入格式为：

```text
函数名(变量类型1,变量类型2,...)
```

调用时，需要找到一个函数名相同，并且参数类型列表完全相同的已定义函数。

若调用成功，输出：

```text
Yes.
```

若不存在该函数名，输出：

```text
There is no function xxx.
```

若存在该函数名，但不存在参数类型列表完全匹配的函数，输出：

```text
xxx was not declared in this scope.
```

其中 `xxx` 表示函数名。

请你依次处理所有操作，并输出系统对于每次操作的反馈。

# 输入描述

第一行输入一个正整数 $q$，表示操作次数。

接下来共输入 $2q$ 行，每两行描述一次操作。

第一行输入一个整数 $op$：

* $op=1$，表示定义一个函数；
* $op=2$，表示调用一个函数。

第二行输入一个字符串，表示本次函数定义或函数调用。

数据保证：

$$
1\leq q\leq 100
$$

$$
1\leq op\leq 2
$$

每个操作字符串的长度不超过 $100$，且输入格式保证合法。

# 输出描述

输出 $q$ 行。

第 $i$ 行表示系统对第 $i$ 次操作给出的反馈。

# 样例

**输入**

```text
8
1
void send(int id)
1
int send(String msg,int level)
2
send(int)
2
send(double)
1
double calc(double x,int y)
2
calc(double,int)
2
close(int)
1
String send(int value)
```

**输出**

```text
Yes.
Yes.
Yes.
send was not declared in this scope.
Yes.
Yes.
There is no function close.
redefinition of send.
```

**说明**

第一次操作定义了参数类型为 `int` 的 `send` 函数，定义成功。

第二次操作定义了参数类型为 `String,int` 的另一个 `send` 函数。虽然函数名相同，但参数类型列表不同，因此属于合法重载。

第三次调用 `send(int)`，能够找到完全匹配的函数，调用成功。

第四次调用 `send(double)`。虽然已经存在名为 `send` 的函数，但没有参数类型为 `double` 的重载，因此调用失败。

第五次定义 `calc(double,int)`，定义成功；第六次调用时能够找到对应函数。

第七次调用 `close(int)`，但此前从未定义过名为 `close` 的函数。

最后一次尝试定义 `send(int)`。虽然参数名和返回类型与第一次定义不同，但函数名及参数类型列表完全相同，因此属于重复定义。
