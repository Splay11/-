## 题目思路

将大的哈哈数提出因子233剩余的每个数位就是最小的哈哈数组成的组成情况

## 代码

**Python代码**

```python
t = int(input())
for i in range(t):
    x = int(input())
    if (x % 233 != 0):
        print(-1)
    else:
        x = x//233
        print(sum(int(j) for j in str(x)))
```

**C++代码**

```c++
#include <iostream>
using namespace std;

int main(){
    int t;
    cin>>t;
    while(t--) {
        long long x;
        cin>>x;
        if (x%233!=0)
            cout<<-1<<endl;
        else
        {
            x/=233;
            int ans=0;
            while(x)
            {
                ans+=x%10;
                x/=10;
            }
            cout<<ans<<endl;
        }
    }
    return 0;
}

```

**Java代码**

```java
import java.util.Scanner;

class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int t = scanner.nextInt();
        for (int i = 0; i < t; i++) {
            Long x = scanner.nextLong();
            int ans = 0;
            if (x % 233 != 0)
                System.out.println(-1);
            else {
                x /= 233;
                while (x != 0) {
                    ans += x % 10;
                    x /= 10;
                }
                System.out.println(ans);
            }
        }
    }
}
```
