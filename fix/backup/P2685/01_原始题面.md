# 题目内容

游游有一个长度为$n$的数组$a$，初始时所有元素都是白色的，游游希望选择一些数字涂黑，他的得分计算为:黑色数字的最小值$+$黑色数字的个数。

请你帮他算算，他最高可以得到多少分吧。



# 输入描述

第一行一个正整数 $T(1 ≤T ≤100)$，表示测试数据的组数。

接下来对于每组测试数据，输入包含两行。

第一行一个正整数$n(1≤n≤2×10^5)$，表示数组$a$的长度。

第二行$n$个整数 $a_i(1≤a_i≤10^9)$，表示数组$a$。

(保证所有测试数据中$n,m$ 的总和都不超过$3x10^5$。)

# 输出描述

输出$T$行，每行一个整数表示答案。



## 样例1 

**输入** 

```
1
5
3 5 4 2 2
```

**输出** 

```
7
```

#### **说明**

可以选择涂黑所有数字，得分为$2+5=7$最大。
