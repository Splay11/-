## 题解

## 题面描述

题目给定一个长度为 $n$ 的数组 $a$，初始时所有元素均为白色。你可以选择部分数字涂成黑色，涂黑后的得分定义为黑色数字的最小值 $+$ 黑色数字的个数。要求求出能够获得的最高得分。

---

## 思路

首先将数组升序排序，然后依次考虑每个数字 $a[i]$ 作为黑色数字中的最小值，此时可将该数字及其后所有数字都涂黑，得到的得分为 $a[i] + (n-i)$，遍历所有位置，选择最大得分即为最终答案。


1. **观察得分公式**  
   得分计算公式为：  
   $$
   score = m + k
   $$  
   其中 $m$ 为黑色数字中的最小值，$k$ 为黑色数字的个数。

2. **确定选择策略**  
   如果固定选定某个数字 $x$ 作为黑色数字中的最小值，则为了使 $k$ 尽可能大，应该将所有不小于 $x$ 的数字都涂黑。也就是说，选定 $x$ 后，黑色数字个数为数组中所有大于等于 $x$ 的数字个数。

3. **利用排序统计**  
   将数组 $a$ 升序排序后，对于每个位置 $i$，可以将 $a[i]$ 作为黑色数字的最小值，则黑色数字个数为 $n-i$。此时得分为  
   $$
   score = a[i] + (n-i)
   $$
   遍历所有位置，取最大值即为答案。

4. **时间复杂度**  
   排序的时间复杂度为 $O(n\log n)$，遍历求最大值为 $O(n)$，总体满足题目要求。

## C++ 代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
 
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T;
    cin >> T;
    while(T--){
        int n;
        cin >> n;
        vector<long long> a(n);
        for (int i = 0; i < n; i++){
            cin >> a[i];
        }
        // 对数组进行排序
        sort(a.begin(), a.end());
        long long ans = 0;
        // 遍历排序后的数组
        for (int i = 0; i < n; i++){
            // 计算得分: a[i] 为最小值，黑色数字个数为 n - i
            long long score = a[i] + (n - i);
            ans = max(ans, score);
        }
        cout << ans << "\n";
    }
    return 0;
}
```

## Python 代码

```python
def main():
    import sys
    input = sys.stdin.readline
    T = int(input())
    for _ in range(T):
        n = int(input())
        a = list(map(int, input().split()))
        # 对数组进行排序
        a.sort()
        ans = 0
        for i in range(n):
            # 计算得分: a[i] 为最小值，黑色数字个数为 n - i
            score = a[i] + (n - i)
            if score > ans:
                ans = score
        print(ans)
        
if __name__ == "__main__":
    main()
```

## Java 代码

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        // 使用 BufferedReader 提高输入效率
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        // 读取测试用例数
        int T = Integer.parseInt(br.readLine());
        StringBuilder sb = new StringBuilder();
        while(T-- > 0) {
            int n = Integer.parseInt(br.readLine());
            StringTokenizer st = new StringTokenizer(br.readLine());
            long[] a = new long[n];
            for (int i = 0; i < n; i++) {
                a[i] = Long.parseLong(st.nextToken());
            }
            // 对数组进行排序
            Arrays.sort(a);
            long ans = 0;
            // 遍历排序后的数组
            for (int i = 0; i < n; i++) {
                // 计算得分: a[i] 为最小值，黑色数字个数为 n - i
                long score = a[i] + (n - i);
                ans = Math.max(ans, score);
            }
            sb.append(ans).append("\n");
        }
        System.out.print(sb);
    }
}
```
