## 思路：模拟

二维循环输出倒立金字塔型的$n$

第一维循环$i$倒序从$n$到$1$

第二维循环$j$从$1$到$i$



## 代码

### C++

```c++
#include <bits/stdc++.h>
using namespace std;
#define ll long long

int n; 
int a,b;

void printNumber(int x){
	if(x>=10) printNumber(x/10);
	printf("%c",'0'+x%10);
}

int main() {
    scanf("%d",&n);
    for(int i=n;i>0;--i){
    	for(int j=1;j<=i;++j){
    		printNumber(n);
		}
		printf("\n");
	}
    
    return 0;
}
```

### java
``` java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int i = n;
        while(i>=1){
            String str = String.valueOf(n);
            System.out.println(str.repeat(i));
            i--;
        }


    }
}
```
