# 特征掩码合成

# 题目内容

产线侧维护一组 $10$ 位二进制特征寄存器初值。

可任意次执行：选取当前列表中两个下标 $p,q$，计算按位与 $blend = feat_p \& feat_q$，并将 $blend$ 追加到列表末尾。

问经过任意次操作后，列表中最多能有多少个**互不相同**的数值。

`&` 为按位与：对应二进制位均为 $1$ 时结果位为 $1$，否则为 $0$。

# 输入描述

每个测试文件包含多组测试数据。

1. 第一行一个整数 $tc$（$1 \le tc \le 10^4$），表示测试组数。
2. 每组数据两行：
   - 第一行整数 $m$（$1 \le m \le 2 \times 10^5$），为初值个数；
   - 第二行 $m$ 个整数 $feat_1,\dots,feat_m$（$0 \le feat_i \le 1023$）。
3. 单个测试文件中所有 $m$ 之和不超过 $2 \times 10^5$。

# 输出描述

每组测试数据输出一行一个整数，表示可达的不同数值个数的最大值。

## 样例1

**输入**

```
2
3
6 2 4
4
3 6 12 24
```

**输出**

```
4
8
```

**说明**

- 组 1：初值 $\{6,2,4\}$，最多可得 $4$ 种不同数值。
- 组 2：初值 $\{3,6,12,24\}$，最多可得 $8$ 种不同数值。
