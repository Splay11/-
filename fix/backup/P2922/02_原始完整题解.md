## 题目分析
给定一个长度为 n 的字符串 s，只包含字符 ‘M’ （男性）和 ‘W’ （女性）。从第 1 时刻到第 n 时刻，依次有用户进入网站。我们需要统计在多少个时刻，累计进入的男性数量严格多于女性数量。

本质上是对前缀进行计数：遍历字符串每一步记录男性和女性的累计次数，判断二者大小关系。

## 解题思路与算法
1. **初始化**  
   - `mCnt = 0`：累计男性计数  
   - `wCnt = 0`：累计女性计数  
   - `ans  = 0`：满足“男性多于女性”的时刻个数  

2. **遍历字符串**  
   - 对于每个字符 `c = s[i]`：  
     - 若 `c == 'M'`，则 `mCnt++`  
     - 否则（`c == 'W'`），则 `wCnt++`  
   - 判断当前 `mCnt > wCnt`，若成立则 `ans++`  

3. **返回答案**  
   - 遍历结束后，`ans` 即为所求。

该算法只需一次遍历，额外空间常数，时间复杂度 O(n)。

## 复杂度分析
- **时间复杂度**：O(n)，其中 n 为字符串长度，只需一次线性扫描。  
- **空间复杂度**：O(1)，仅使用若干固定的计数变量。

## 代码实现

### Python 代码
```python
def solve():
    n = int(input().strip())
    s = input().strip()
    mCnt = 0
    wCnt = 0
    ans = 0
    for c in s:
        if c == 'M':
            mCnt += 1
        else:
            wCnt += 1
        if mCnt > wCnt:
            ans += 1
    print(ans)

if __name__ == "__main__":
    solve()
```

### Java 代码
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        String s = in.next();
        int mCnt = 0, wCnt = 0, ans = 0;
        for (char c : s.toCharArray()) {
            if (c == 'M') {
                mCnt++;
            } else {
                wCnt++;
            }
            if (mCnt > wCnt) {
                ans++;
            }
        }
        System.out.println(ans);
        in.close();
    }
}
```
