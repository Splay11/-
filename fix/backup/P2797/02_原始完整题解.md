# 题解

## 题面描述

给定一个长度为 $n$ 的序列 $a$。你需要将该序列划分为 $m$ 个不相交的连续区间，记为 $[l_1,r_1],[l_2,r_2],\ldots,[l_m,r_m]$，其中必须满足对于任意 $j$ 满足 $r_j+1=l_{j+1}$。定义区间函数为  
$f(l_j, r_j) $= max($a_{l_j}$,$a_{l_j+1}$,......,$a_{r_j}$)
得到的新序列为  
$b = \{f(l_1, r_1),f(l_2, r_2),\ldots,f(l_m, r_m)\}$
要求使得 $b_1+b_2+\ldots+b_m$ 最大化，求该最大值。

---

## 思路

为了最大化各区间内最大值的和，我们需要让每个区间都包含一个尽可能大的数。直观上，最优方案就是让每个区间的最大值均为序列 $a$ 中最大的 $m$ 个数。因此，算法可以分为以下几个步骤：

- **第一步**：从序列 $a$ 中找到最大的 $m$ 个数。  
  由于区间必须连续，且我们最终的划分会依照这些最大的数在序列中的位置来确定。

- **第二步**：对这 $m$ 个数的下标进行排序，这样可以保证分段时每个区间都包含一个最大的数，并且划分合法。  
  注意：虽然题目还可以求划分方案的种数，但本题只要求最大和。

- **第三步**：答案即为这 $m$ 个数的和。  
  因为每个区间必然能包含这 $m$ 个数中的一个，而其他数字不会对区间内的最大值产生贡献。

---

## 代码分析

1. **$C++$ 解法**  
   - 读入 $T$ 组测试数据。  
   - 对于每组数据，读入 $n$ 和 $m$ 以及序列 $a$。  
   - 将每个数和其下标存储为一对，通过数值降序排序。  
   - 取出最大的 $m$ 个数并求和。  
   - 输出答案。

2. **$Python$ 解法**  
   - 读入输入数据。  
   - 同样将每个元素和其下标存储，然后排序取最大的 $m$ 个数。  
   - 计算并输出答案。

3. **$Java$ 解法**  
   - 使用 $Scanner$ 读入输入数据。  
   - 对于每组数据，同样存储每个数和其下标，然后对数值降序排序。  
   - 取出前 $m$ 个数的和并输出。

## C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
typedef long long ll;
 
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T;
    cin >> T;
    while(T--){
        int n, m;
        cin >> n >> m;
        vector<ll> a(n);
        for(int i=0; i<n; i++){
            cin >> a[i]; // 读入序列中的每个数
        }
        // 将每个数和其下标构成一对
        vector<pair<ll,int>> vp;
        for(int i=0; i<n; i++){
            vp.push_back({a[i], i});
        }
        // 按照数值降序排序
        sort(vp.begin(), vp.end(), [](const pair<ll,int>& p1, const pair<ll,int>& p2){
            return p1.first > p2.first;
        });
        ll ans = 0;
        // 取出最大的 m 个数求和
        for(int i=0; i<m; i++){
            ans += vp[i].first;
        }
        cout << ans << "\n";
    }
    return 0;
}
```
## Python

```python
# -*- coding: utf-8 -*-
import sys

def main():
    # 读入所有输入
    input_data = sys.stdin.read().split()
    t = int(input_data[0])  # 读入测试组数T
    index = 1
    results = []
    for _ in range(t):
        n = int(input_data[index])    # 序列长度n
        m = int(input_data[index+1])  # 区间数m
        index += 2
        # 读入序列a
        a = list(map(int, input_data[index:index+n]))
        index += n
        
        # 将数值与下标组成元组
        pairs = [(a[i], i) for i in range(n)]
        # 按数值降序排序
        pairs.sort(key=lambda x: x[0], reverse=True)
        # 取出最大的m个数并求和
        ans = sum(p[0] for p in pairs[:m])
        results.append(ans)
    
    # 输出所有测试数据的结果
    sys.stdout.write("\n".join(map(str, results)) + "\n")

if __name__ == "__main__":
    main()
```

## Java

```java
import java.util.*;
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        // 使用 BufferedReader 提高输入效率
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
     
        int T = Integer.parseInt(br.readLine().trim());
        StringBuilder sb = new StringBuilder();
        for (int t = 0; t < T; t++) {
         
            String[] parts = br.readLine().trim().split("\\s+");
            int n = Integer.parseInt(parts[0]);
            int m = Integer.parseInt(parts[1]);
            
            // 读入序列a
            String[] numStr = br.readLine().trim().split("\\s+");
            int[] a = new int[n];
            for (int i = 0; i < n; i++) {
                a[i] = Integer.parseInt(numStr[i]);
            }
            
            // 定义数组存储每个数与其下标的对
            Pair[] pairs = new Pair[n];
            for (int i = 0; i < n; i++) {
                pairs[i] = new Pair(a[i], i);
            }
            
            // 对 pairs 按数值降序排序
            Arrays.sort(pairs, new Comparator<Pair>(){
                public int compare(Pair p1, Pair p2) {
                    return Integer.compare(p2.value, p1.value);
                }
            });
            
            // 求取最大的m个数的和
            long ans = 0;
            for (int i = 0; i < m; i++) {
                ans += pairs[i].value;
            }
            
            sb.append(ans).append("\n");
        }
        System.out.print(sb.toString());
    }
}

// 定义 Pair 类，存储数值和下标
class Pair {
    int value;
    int index;
    public Pair(int value, int index) {
        this.value = value;
        this.index = index;
    }
}
```
