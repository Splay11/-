# 题目描述

某电子时钟采用 $24$ 小时制显示时间，格式为 `hh:mm`。

如果忽略中间的冒号，将小时和分钟的四个数字直接拼接后得到的字符串正着读和反着读完全相同，那么称这个时刻为**回文时刻**。

例如，时间 `13:31` 去掉冒号后得到 `1331`，正着读和反着读相同，因此 `13:31` 是一个回文时刻。

现在给定一个合法的当前时间，请你计算从当前时刻开始，最少经过多少分钟能够到达一个回文时刻。

如果当前时刻本身就是回文时刻，则答案为 $0$。

一天共有 $24$ 小时，每小时共有 $60$ 分钟。若经过午夜，则时间从 `23:59` 进入下一天的 `00:00`。

# 输入描述

输入一行一个时间，格式为 `hh:mm`。

其中 `hh` 表示小时，`mm` 表示分钟，采用 $24$ 小时制，并保证输入时间合法。

小时和分钟均使用两位数字表示。

# 输出描述

输出一个整数，表示从当前时间到达最早回文时刻至少需要经过多少分钟。

# 样例 1

**输入**

```text
15:49
```

**输出**

```text
2
```

**说明**

从 `15:49` 开始经过 $2$ 分钟后到达 `15:51`。

去掉冒号后得到 `1551`，它是一个回文串，因此答案为 $2$。

# 样例 2

**输入**

```text
20:02
```

**输出**

```text
0
```

**说明**

当前时间去掉冒号后为 `2002`，本身就是回文串，因此不需要等待，答案为 $0$。

# 样例 3

**输入**

```text
23:59
```

**输出**

```text
1
```

**说明**

经过 $1$ 分钟后时间变为下一天的 `00:00`。

去掉冒号后得到 `0000`，是一个回文串，因此答案为 $1$。
