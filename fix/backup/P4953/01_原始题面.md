# 题目内容

录入员想输入一串仅含小写字母的文本，但键盘一开始就有且仅有一个按键失灵，该字母的全部出现都不会被打出，最终得到串 $z$。

还已知：完整原文中任意相邻两字符都不相同。

对每个可能的失灵字母 $x$（`'a'`～`'z'`），统计有多少个合法原文删掉全部 $x$ 后恰好得到 $z$；再把这 $26$ 种情况的数量求和，对 $10^9+7$ 取模。

# 输入描述

共有多组独立用例，需逐组求解。

- 首行给出整型 $q$（$1 \le q \le 10^5$），表示用例个数。
- 每组用例两行：
  - 第一行整型 $m$（$1 \le m \le 2\times 10^5$），表示串长。
  - 第二行长度为 $m$、仅含小写字母的字符串 $z$。
- 全体用例的串长之和不超过 $5\times 10^5$。

# 输出描述

对每组用例输出一行一个整数，为上述总和对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
3
2
xy
2
bb
3
abc
```

**输出**

```
192
100
368
```

**说明**

- 第一组：$z$ 中出现 $2$ 种字母，相邻不同位置 $1$ 处，答案为 $24\times 2^{3}=192$。
- 第二组：仅出现字母 `b`，相邻均相同，答案为 $25\times 2^{2}=100$。
- 第三组：出现 $3$ 种字母，相邻均不同，答案为 $23\times 2^{4}=368$。
