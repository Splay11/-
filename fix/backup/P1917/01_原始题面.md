### 题目内容：

我们定义一个长度为偶数字符串为重复字符串，当且仅当该字符串的前半段等于后半段。

例如“$aaaa$”、“$abhabh$”是重复字符串。

小塔拿到了一个字符串，她每次操作可以选择一个字符，将其修改为任意一个字符。

小塔想知道，她最少多少次操作后，可以把该字符串变成重复字符串？



#### 输入描述

一个长度为偶数的字符串，长度不超过$10^5$。



#### 输出描述

将其变成重复字符串的最小操作次数。



### 示例1

**输入**

```
abhabh
```



**输出**

```
0
```



**说明**

$abhabh$本身就是重复字符串，不再需要操作
