## 思路
将一个字符串前半段和后半段逐字符进行对比，有一个字符不同便需要修改一次，因为只能够单个字符修改，所以每一个字符单独看待，对应位置的两个字符不同那么就将其中一个字符变为另外一个字符便是最优
## 代码
### C++

```cpp
#include<iostream>
#include<cstring>
using namespace std;
int ans=0;
int main()
{
    string str;
    cin>>str;
    int n=str.size();
    for(int i=0;i<n/2;i++)
    {
        if(str[i]!=str[i+n/2])ans++;
    }
    cout<<ans<<endl;
}
```
### python
```cpp
ans = 0
str = input()  # Input string
n = len(str)

for i in range(n // 2):
    if str[i] != str[i + n // 2]:
        ans += 1

print(ans)
```
### java
```cpp
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int ans = 0;
        String str = sc.next();
        int n = str.length();
        
        for (int i = 0; i < n / 2; i++) {
            if (str.charAt(i) != str.charAt(i + n / 2)) {
                ans++;
            }
        }
        
        System.out.println(ans);
    }
}
```
