# 题目内容



小塔喜欢数数，他想知道在由$0$到$n$这些数字组成的$m$位数中(每个数最多只能用一次)，有多少个是大于$k$的。



# 输入描述

第一行输入三个整数$n,m,k$。

$(1≤n≤7,1≤m≤n+1,0≤k≤10^8)$



# 输出描述



输出一个整数表示答案。



## 样例1 



**输入** 



```
5 1 0 
```



**输出** 



```
5
```



**说明**

大于$0$的是$1,2,3,4,5$这$5$个数



## 样例2



**输入** 



```
4 2 35
```



**输出** 



```
4
```



**说明**

大于$35$的是$40,41,42,43$这$4$个数。

注意，由于每个数不能重复使用，所以无法拼出$44$。
