#### 思路

由于 $l$ 和 $r$ 的范围可以达到 $10^{18}$，暴力枚举所有三元组是不可行的。我们需要通过数学分析来简化问题。

1. **简化条件**
   根据条件 $l \leq a < b < c \leq r$，我们知道 $\max(a, b, c) = c$ 且 $\text{sum}(a, b, c) = a+b+c$。
   因此，核心不等式条件可以改写为：
   $c < \text{lcm}(a, b, c) < a + b + c$

2. **分析 $\text{lcm}(a, b, c)$**
   我们知道 $\text{lcm}(a, b, c)$ 必然是 $c$ 的倍数。我们可以设 $\text{lcm}(a, b, c) = k \cdot c$，其中 $k$ 是一个正数。

   * 因为 $\text{lcm}(a,b,c)$ 必须是 $a, b, c$ 的公倍数，所以 $k \cdot c$ 必须能被 $a$ 和 $b$ 整除。
   * 不等式 $c < \text{lcm}(a, b, c)$ 意味着 $c < k \cdot c$，这要求 $k > 1$。由于 $\text{lcm}(a,b,c)$ 是 $c$ 的最小公倍数，所以 $k$ 必须是整数（除非 $\text{lcm}(a,b) = \infty$，这是不可能的）。因此 $k \geq 2$。

3. **约束 $k$ 的范围**
   我们有另一个不等式 $\text{lcm}(a, b, c) < a + b + c$。
   将 $\text{lcm}(a, b, c) = k \cdot c$ 代入，得到 $k \cdot c < a + b + c$。
   因为 $a < c$ 且 $b < c$，所以 $a + b + c < c + c + c = 3c$。
   结合起来，我们有 $k \cdot c < 3c$，这意味着 $k < 3$。

   综合 $k \geq 2$ 和 $k < 3$，并且 $k$ 是整数，我们得出结论：$k$ 唯一可能的值是 $2$。

4. **问题转化**
   现在问题转化为寻找满足以下条件的三元组 $(a, b, c)$ 的数量：

   1. $l \leq a < b < c \leq r$
   2. $\text{lcm}(a, b, c) = 2c$
   3. $c < a + b$ (源自 $2c < a + b + c$)

5. **刻画满足 $\text{lcm}(a, b, c) = 2c$ 的三元组**
   条件 $\text{lcm}(a, b, c) = 2c$ 意味着 $a$ 和 $b$ 都必须是 $2c$ 的因子。
   我们可以令 $a = \frac{2c}{k_a}$ 和 $b = \frac{2c}{k_b}$，其中 $k_a, k_b$ 是整数。

   * 从 $a < b < c$ 我们得到 $\frac{2c}{k_a} < \frac{2c}{k_b} < c$。
   * $\frac{2c}{k_b} < c \implies 2 < k_b$。
   * $\frac{2c}{k_a} < \frac{2c}{k_b} \implies k_b < k_a$。
     所以我们有 $2 < k_b < k_a$。

   现在分析 $\text{lcm}(a, b, c)$ = $\text{lcm}(\frac{2c}{k_a}, \frac{2c}{k_b}, c) = 2c$。
   
   ![image](/file/2/ysCg01Vyi68AN7AFiXVqp.png) 

   为了使上式等于 $2c$，必须有 $\text{gcd}(k_a, k_b) = 1$。

6. **求解 $k_a, k_b$**
   我们还需要满足条件 $c < a + b$。
   $c$ < $\frac{2c}{k_a}$ + $\frac{2c}{k_b} \implies 1$ < $\frac{2}{k_a}$ + $\frac{2}{k_b} \implies k_a k_b$ < $2k_b$ + $2k_a$
   整理得 $k_a k_b - 2k_a - 2k_b < 0$，配方后为 $(k_a - 2)(k_b - 2) < 4$。

   我们来寻找满足以下条件的整数对 $(k_a, k_b)$：

   * $2 < k_b < k_a$
   * $\text{gcd}(k_a, k_b) = 1$
   * $(k_a - 2)(k_b - 2) < 4$

   因为 $k_b > 2$，所以 $k_b - 2 > 0$。令 $K_b = k_b - 2$，则 $K_b \geq 1$。

   * **情况 1**: $K_b = 1 \implies k_b = 3$。
     代入不等式：$1 \cdot (k_a - 2) < 4 \implies k_a < 6$。
     结合 $k_a > k_b = 3$ 和 $\text{gcd}(k_a, 3) = 1$，$k_a$ 的可能值为 $4$ 或 $5$。

     * $(k_a, k_b) = (4, 3)$。$\text{gcd}(4, 3) = 1$，满足条件。
     * $(k_a, k_b) = (5, 3)$。$\text{gcd}(5, 3) = 1$，满足条件。
   * **情况 2**: $K_b \geq 2 \implies k_b \geq 4$。
     由于 $k_a > k_b$，所以 $k_a - 2 > k_b - 2 \geq 2$。
     此时 $(k_a - 2)(k_b - 2) > 2 \cdot 2 = 4$，不满足不等式。

   所以，只存在两组可能的 $(k_a, k_b)$：$(4, 3)$ 和 $(5, 3)$。

7. **构造三元组**

   * **第一类**: $(k_a, k_b) = (4, 3)$。
     $a = \frac{2c}{4} = \frac{c}{2}$，$b = \frac{2c}{3}$。
     为了使 $a, b$ 为整数，$c$ 必须是 $\text{lcm}(2, 3) = 6$ 的倍数。
     令 $c = 6k$ (其中 $k$ 为正整数)，则 $a = 3k$，$b = 4k$。
     三元组形式为 $(3k, 4k, 6k)$。
   * **第二类**: $(k_a, k_b) = (5, 3)$。
     $a = \frac{2c}{5}$，$b = \frac{2c}{3}$。
     为了使 $a, b$ 为整数，$c$ 必须是 $\text{lcm}(5, 3) = 15$ 的倍数。
     令 $c = 15k$ (其中 $k$ 为正整数)，则 $a = 6k$，$b = 10k$。
     三元组形式为 $(6k, 10k, 15k)$。

   这两类三元组没有交集（除了 $k=0$ 时的 $(0,0,0)$），因为它们的比值不同 ($3:4:6$ vs $6:10:15$)。

8. **计数**
   我们的任务是计算在 $[l, r]$ 范围内有多少个这样的三元组。

   * 对于第一类 $(3k, 4k, 6k)$：
     需要满足 $l \leq 3k$ 和 $6k \leq r$。
     即 $\frac{l}{3} \leq k \leq \frac{r}{6}$。
     $k$ 的最小整数值为 $k_{min} = \lceil \frac{l}{3} \rceil$，最大整数值为 $k_{max} = \lfloor \frac{r}{6} \rfloor$。
     使用整数除法，$k_{min} = (l+2)/3$，$k_{max} = r/6$。
     数量为 $\max(0LL, k_{max} - k_{min} + 1)$。
   * 对于第二类 $(6k, 10k, 15k)$：
     需要满足 $l \leq 6k$ 和 $15k \leq r$。
     即 $\frac{l}{6} \leq k \leq \frac{r}{15}$。
     $k$ 的最小整数值为 $k_{min} = \lceil \frac{l}{6} \rceil = (l+5)/6$，最大整数值为 $k_{max} = \lfloor \frac{r}{15} \rfloor = r/15$。
     数量为 $\max(0LL, k_{max} - k_{min} + 1)$。

   总数就是这两类三元组的数量之和。由于 $l, r$ 很大，计算时需要使用64位整型（`long long`）。

### C++ 

```cpp
#include <iostream>
#include <algorithm>

// 使用 long long 来处理大整数
using ll = long long;

void solve() {
    ll l, r;
    std::cin >> l >> r;

    ll count = 0;

    // 第一类三元组: (3k, 4k, 6k)
    // 条件: l <= 3k  且  6k <= r
    // k 的范围: ceil(l/3) <= k <= floor(r/6)
    ll k_min1 = (l + 3 - 1) / 3; // 计算 ceil(l/3)
    ll k_max1 = r / 6;           // 计算 floor(r/6)
    if (k_max1 >= k_min1) {
        count += (k_max1 - k_min1 + 1);
    }

    // 第二类三元组: (6k, 10k, 15k)
    // 条件: l <= 6k  且  15k <= r
    // k 的范围: ceil(l/6) <= k <= floor(r/15)
    ll k_min2 = (l + 6 - 1) / 6; // 计算 ceil(l/6)
    ll k_max2 = r / 15;          // 计算 floor(r/15)
    if (k_max2 >= k_min2) {
        count += (k_max2 - k_min2 + 1);
    }

    std::cout << count << std::endl;
}

int main() {
    // 优化输入输出
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(NULL);

    int t;
    std::cin >> t;
    while (t--) {
        solve();
    }

    return 0;
}
```

```python
import math

def solve():
    """
    解决单个测试用例
    """
    l, r = map(int, input().split())

    count = 0

    # 第一类三元组: (3k, 4k, 6k)
    # 条件: l <= 3k  且  6k <= r
    # k 的范围: ceil(l/3) <= k <= floor(r/6)
    # math.ceil(x/y) 等价于 (x + y - 1) // y 使用整数运算
    k_min1 = (l + 3 - 1) // 3
    k_max1 = r // 6
    if k_max1 >= k_min1:
        count += (k_max1 - k_min1 + 1)

    # 第二类三元组: (6k, 10k, 15k)
    # 条件: l <= 6k  且  15k <= r
    # k 的范围: ceil(l/6) <= k <= floor(r/15)
    k_min2 = (l + 6 - 1) // 6
    k_max2 = r // 15
    if k_max2 >= k_min2:
        count += (k_max2 - k_min2 + 1)

    print(count)

def main():
    """
    主函数，处理多个测试用例
    """
    try:
        t = int(input())
        for _ in range(t):
            solve()
    except (IOError, ValueError):
        # 处理可能的输入结束或格式错误
        pass

if __name__ == "__main__":
    main()
```
