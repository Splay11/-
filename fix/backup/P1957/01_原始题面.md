# 题目内容

​     小塔家里打算铺地砖，他一共准备了$n$块如图所示的正方形地砖，每一块由$4$个半径一致的半圆组成。

现在小塔想要使得铺完后的地砖产生的圆最多。请你以任意方式的摆放后，帮他找到全部可行的摆放方式中，拼出的圆的数量最多的一种。直接输出的圆的数量。

![](https://s3.bmp.ovh/imgs/2024/08/30/60c52da2ab2d7817.png)



# 输入描述

在一行上输入一个整数$n(1≤n≤10^6)$表示地砖的数量。

# 输出描述

在一行上输出一个整数$n(1≤n≤10^6)$代表全部可行的摆放方式中，拼出的圆的数量最多的一种的圆的数量。

## 样例1 

**输入** 

```
3
```

**输出** 

```
2
```
