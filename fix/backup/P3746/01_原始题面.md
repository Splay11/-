# 题目内容

小红定义一个正整数$x$ 为完美偶数，当且仅当：

- $x$是偶数；
- $l≤x≤r$

小红拿到了一长度为$n$ 的数组$(a_1,a_2,...,a_n)$，她想知道该数组中有多少个完美偶数。

# 输入描述

第一行输入三个整数$n,l,r(1≤n≤100;1≤l≤r≤100)$ ，表示数组长度和区间。

第二行输入$n$ 个整数$(a_1,a_2,...a_n)$ ，$(1≤a_i≤100)$。

# 输出描述

输出一个整数，表示数组中完美偶数的数量。



## 样例1 

**输入** 

```
5 3 8
1 2 6 8 7
```

**输出** 

```
2
```
