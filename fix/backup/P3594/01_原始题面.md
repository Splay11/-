# 题目内容

给定一个正整数 $s$ ，请构造一个二次函数：

$f(x)=ax^2+bx+c$

使得该函数的顶点处的数值等于 $s$ 。要求 $a≠0$ 。 

# 输入描述

第一行一个整数 $T(1≤T≤10^4)$ ，表示数据组数。

接下来 $T$ 行，每行一个正整数 $s(1≤s≤10^9)$ 。

# 输出描述

对于每组数据，输出一行，包含三个整数 $a,b,c$，表示所构造的二次函数。

要求：$−2×10^9≤a,b,c≤2×10^9$ ，且 $a≠0$ 。



## 样例1 



**输入** 



```
2
1
10
```



**输出** 



```
1 0 1
1 0 10
```
