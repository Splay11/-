# 小红练字

## 题解思路

### 题目分析

我们需要将给定的字分成若干行，每行的字数不能超过 `k`，并且每行中不能有相同笔画数的字。要求我们最少需要多少行。

### 解题思路

1. **频率统计**：首先，我们需要知道每个字的笔画数出现的频率。如果某个笔画数出现的次数较多，就需要更多的行来容纳这些字，因为同一行不能有相同笔画数的字。
   
2. **行数计算**：
    - 如果某个笔画数的字出现次数大于 `k`，那么单独一行就不能容纳这些字。此时，我们必须分开这些字。
    - 对于每个笔画数的字，我们可以考虑将这些字分到不同的行中，每行最多容纳 `k` 个字。换句话说，对于一个笔画数出现频率为 `freq` 的字，最少需要 `ceil(freq / k)` 行来容纳它们。

3. **综合考虑**：
    - 我们需要计算出所有字的最小行数，并且需要保证每行的字数不超过 `k`。

4. **最终行数**：
    - 最终所需要的最少行数，应该是所有字的频率中最常见的字数所需的行数和每行最多 `k` 个字的行数之间的最大值。

### 步骤：

1. 统计每个笔画数出现的频率。
2. 计算每个笔画数对应的行数。
3. 计算并输出最少需要的行数。

### 复杂度分析

- 时间复杂度：
  - 统计每个字的笔画数频率：O(n)
  - 计算最少行数：O(频率种类数) <= O(n)
  - 总体时间复杂度：O(n)
  
- 空间复杂度：O(n)，用于存储频率统计。

## 代码实现

### C++代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    vector<int> a(n);
    unordered_map<int, int> freq;
    
    // 输入并统计笔画数的频率
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        freq[a[i]]++;
    }
    
    int maxFreq = 0;
    for (auto &p : freq) {
        // 更新最大频率
        maxFreq = max(maxFreq, p.second);
    }
    
    // 每行最多k个字
    int rowsByK = (n + k - 1) / k;
    
    // 最少需要的行数是最大频率和每行最多k个字所需行数的最大值
    int ans = max(maxFreq, rowsByK);
    
    cout << ans << "\n";
    return 0;
}
```

### Python代码

```python
from collections import Counter

def min_lines_needed(n, k, a):
    freq = Counter(a)  # 统计每个笔画数出现的次数
    max_freq = max(freq.values())  # 找出出现频率最高的笔画数
    rows_by_k = (n + k - 1) // k  # 每行最多k个字所需的最小行数
    return max(max_freq, rows_by_k)

# 输入处理
n, k = map(int, input().split())
a = list(map(int, input().split()))

# 输出结果
print(min_lines_needed(n, k, a))
```

### Java代码

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        int n = scanner.nextInt();
        int k = scanner.nextInt();
        
        int[] a = new int[n];
        Map<Integer, Integer> freq = new HashMap<>();
        
        // 输入并统计笔画数的频率
        for (int i = 0; i < n; i++) {
            a[i] = scanner.nextInt();
            freq.put(a[i], freq.getOrDefault(a[i], 0) + 1);
        }
        
        // 计算最大频率
        int maxFreq = 0;
        for (int value : freq.values()) {
            maxFreq = Math.max(maxFreq, value);
        }
        
        // 每行最多k个字
        int rowsByK = (n + k - 1) / k;
        
        // 最少需要的行数
        System.out.println(Math.max(maxFreq, rowsByK));
        
        scanner.close();
    }
}
```
