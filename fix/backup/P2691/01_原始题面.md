# 题目内容

小红拿到一份英文报纸，由一个长度为n的字符串组成，字符串仅由'$o$','$x$','$s$'.'$z$'.'$m$'.'$w$'，组成。

小红把这份报纸抄了一遍，后来发现拿报纸的时候拿反了，即抄完的字符串和报纸实际上表达的字符串上下颠倒了，比如'$w$'写作了'$m$'，'$m$'写做了 '$w$'，其他字母不变。

现在给出小红抄完的字符串，请你还原报纸上所表达的字符串。



# 输入描述

第一行一个长度为$n(1≤n≤10^5)$,表示字符串长度。

第二行一个长度为$n$目仅由'$o$','$x$','$s$','$z$','$m$','$w$'组成的字符串，表示小红纱的字符串。

# 输出描述

一个长度为$n$的字符串，表示报纸上的字符串。



## 样例1 

**输入** 

```
5
oxszw
```

**输出** 

```
oxszm
```
