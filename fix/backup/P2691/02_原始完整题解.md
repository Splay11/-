# 小红的字符串

## 题目背景
小红拿到一份由特定字符组成的英文报纸，抄写时拿反了，导致某些字符被错误地抄写。题目要求根据抄写的字符串，还原出报纸上的原始字符串。

字符映射关系
根据题目描述，字符的映射关系如下：
- `'w'` 和 `'m'` 互相颠倒，即 `'w'` 写成 `'m'`，`'m'` 写成 `'w'`。
- 其他字符（`'o'`, `'x'`, `'s'`, `'z'`）保持不变。

## 解题思路
1. 字符替换：遍历抄写的字符串，根据字符映射关系进行替换。
2. 复杂度分析：由于只需要遍历一次字符串，时间复杂度为 O(n)，空间复杂度为 O(1)。

## 代码实现

**Python 代码**
```python
def restore_newspaper(s):
    # 创建字符映射字典
    char_map = {'w': 'm', 'm': 'w'}
    # 遍历字符串，进行字符替换
    result = []
    for char in s:
        if char in char_map:
            result.append(char_map[char])
        else:
            result.append(char)
    return ''.join(result)

n = int(input())
s = input().strip()
print(restore_newspaper(s))
```

**Java 代码**
```java
import java.util.Scanner;

public class Main {
    public static String restoreNewspaper(String s) {
        // 创建字符映射字典
        char[] charMap = new char[128];
        charMap['w'] = 'm';
        charMap['m'] = 'w';
        // 遍历字符串，进行字符替换
        StringBuilder result = new StringBuilder();
        for (char c : s.toCharArray()) {
            if (charMap[c] != 0) {
                result.append(charMap[c]);
            } else {
                result.append(c);
            }
        }
        return result.toString();
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        String s = scanner.next();
        // 输出结果
        System.out.println(restoreNewspaper(s));
    }
}
```

**C++ 代码**
```cpp
#include <iostream>
#include <unordered_map>
#include <string>

using namespace std;

string restoreNewspaper(string s) {
    // 创建字符映射字典
    unordered_map<char, char> charMap = {{'w', 'm'}, {'m', 'w'}};
    // 遍历字符串，进行字符替换
    string result;
    for (char c : s) {
        if (charMap.find(c) != charMap.end()) {
            result += charMap[c];
        } else {
            result += c;
        }
    }
    return result;
}

int main() {
    int n;
    string s;
    cin >> n >> s;
    // 输出结果
    cout << restoreNewspaper(s) << endl;
    return 0;
}
```
