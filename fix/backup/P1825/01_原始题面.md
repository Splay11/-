### 问题描述

塔子哥有一座神奇的花园，花园中种植了 $n + 1$ 株神秘的花朵，每株花朵都有一个美丽值。花朵的美丽值以数组 $a$ 表示，其中 $a_i$ 表示第 $i$ 株花朵的美丽值。

花园里除了最后一株花 $a_{n + 1}$ 其美丽值为 $x$，其它每株花的美丽值都由下一株花的美丽值决定，具体为：

$$
a_i = a_{i+1} \bmod i \quad (1 \leq i \leq n)
$$

塔子哥希望知道第 $k$ 株花的美丽值是多少。请你帮助他计算。

### 输入格式

第一行输入一个整数 $T(1 \leq T \leq 10^5)$，表示询问的次数。

接下来 $T$ 行，每行输入三个整数 $n(1 \leq n \leq 10^9)$，$x(0 \leq x \leq 10^9)$，$k(1 \leq k \leq n + 1)$，表示一次询问。

### 输出格式

对于每次询问，输出一个整数表示第 $k$ 株花的美丽值。

### 样例输入

```
2
1 1 1
5 1 4
```

### 样例输出 
```
0
1
```
