# 题目描述

小林面前摆着一排字符卡片，共有 $n$ 张，每张卡片上写着一个小写英文字母。将这些卡片从左到右拼接，可以得到一个长度为 $n$ 的字符串 $S$，下标从 $1$ 开始。

接下来，小林会依次进行 $n$ 次操作。

在第 $i$ 次操作中，他会将**当前位于第 $i$ 个位置的字符卡片**取出，并移动到整排卡片的末尾，其余卡片的相对顺序保持不变。

请你输出完成全部 $n$ 次操作后得到的字符串。

例如，字符串 `abqde` 的变化过程如下：

`abqde` → `bqdea` → `bdeaq` → `bdaqe` → `bdaeq` → `bdaeq`

最终得到字符串 `bdaeq`。

# 输入描述

在一行中输入一个仅由小写英文字母组成的字符串 $S$。

字符串长度记为 $n$，满足：

$$
1\leq n\leq 10^6
$$

# 输出描述

在一行中输出完成全部 $n$ 次操作后得到的字符串。

# 样例 1

**输入**

```text
abcdef
```

**输出**

```text
bdfcae
```

**说明**

整个操作过程为：

`abcdef` → `bcdefa` → `bdefac` → `bdface` → `bdfcea` → `bdfcae` → `bdfcae`

因此最终得到字符串 `bdfcae`。
