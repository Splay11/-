# 题目内容

$Tk$ 有一个长度为$n$仅由大小写字母组成的字符串$s$(下标从$1$开始)。

$Tk$ 给你一个字符转换器，该转换器有阴阳两种状态，初始状态为阴。

你需要按照下标从小到大依次对字符串进行以下操作:

- 如果当前状态为阴且下标对应的字符为小写字母，则将其转换为对应的大写字母，并将转换器状态切换为阳;
- 如果当前状态为阳且下标对应的字符为大写字母，则将其转换为对应的小写字母，并将转换器状态切换为阴;

对于不满足上述条件的字符，不进行操作，转换器状态保持不变。

请输出操作完成后的字符串.



# 输入描述

第一行输入一个正整数$n(1≦n≦2×10^5)$表示字符串长度

# 输出描述

输出一个字符串，表示操作完成后的字符串.

## 样例1 

**输入** 

```
5
abCCd
```

**输出** 

```
AbcCD
```

#### 说明

下标 $1$时为阴，字符$a$为小写，转换为大写$A$，状态切换为阳;

下标$ 2$时状态为阳，字符$b$为小写，无法操作，状态保持为阳;

下标$3$时状态为阳，字符$C$为大写，转换为小写$c$，状态切换为阴;

下标$4$时状态为阴，字符$C$为大写，无法操作，状态保持为阴;

下标$5$时状态为阴，字符$d$为小写，转换为大写 $D$，状态切换为阳。
