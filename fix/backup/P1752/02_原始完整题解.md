# 题解

## 题意说明：  
- 有三种元素：火（个数 a）、水（个数 b）、风（个数 c）。  
- 规则：
  1. 若盒子中放有火元素，则该盒子中元素总数不能超过 2。  
  2. 若盒子中放有水元素，则该盒子中元素总数必须不少于 3。  
  3. 风元素没有额外要求。  
- 所有元素必须全部放进盒子中，并且要求方案合法（即放入盒子的每种牌数量不超过牌库中出现的次数；这里本题只关心能否分盒子、盒子数最少和最多是多少）。  
- 由于水元素要求所在盒子至少 3 个元素，所以当水存在时必须与至少另外 2 个（水或风）放在同一个盒子中，从而要求水+风的总数至少为 3，否则无解。  

分析得到：
1. **最少盒子数**  
   为了减少盒子数，我们希望“多装”盒子。注意：  
   - 火元素由于盒子中若含火最多只能放 2 个，所以火元素最优打包是两两放入同一盒中，所需盒数为 ⌈a/2⌉。  
   - 水元素必须放在不含火的盒子中（否则火盒最多 2 个而无法满足水盒至少 3 个的要求），因此所有水元素和所有风元素可以全部合并到一个盒子中（前提是 b+c≥3，否则无法满足水元素的要求）。  
   因此最少盒子数 = ⌈a/2⌉ + 1.  

2. **最多盒子数**  
   为了增加盒子数，我们希望“尽量拆开”  
   - 火元素无额外要求，且盒子中含火时最多 2 个，所以每个火元素单独放一个盒子是可行的（盒子中只有 1 个火，满足 ≤2 的要求）。  
   - 风元素没有限制，可以每个单独放一盒。  
   - 水元素所在盒子必须至少 3 个元素，故水不能单独放；为尽可能拆开水，尽量没三个水元素一组，多余的不额外分组，例如b=7，分为3，4两组
     - 当 b≥3 时，每三个一组，多余的不额外分组；  
     - 当 b==2 时，1 个水盒中只有 2 个水，不够 3 个，则必须额外放入 1 个风；  
     - 当 b==1 时，必须放入 2 个风。  
     
   由于我们希望风元素尽量单独成盒，所以水盒如果消耗了部分风作为“补充”，这些风就不能单独放盒了。  
   综合得到：  
   - 如果 b≥3，则最多盒数 =（火盒数：a，每个火单独） +（风单独盒：c）+（水盒：b/3，向下取整），即 a + c + b/3.  
   - 如果 b==2，则水盒需要 1 个风作为补充，最多盒数 = a + (c - 1) + 1 = a + c.  
   - 如果 b==1，则水盒需要 2 个风补充，最多盒数 = a + (c - 2) + 1 = a + c - 1.  
   
   （注意：题目输入保证 a,b,c 均 ≥1；同时合法方案必须满足 b+c ≥ 3，否则无解。）

### cpp
```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main(){
    ios::sync_with_stdio(false);
    cin.tie(NULL);

    int g;
    cin >> g;
    while(g--){
        ll a,b,c;
        cin >> a >> b >> c;
        bool ok = true;
        if(b == 1 && c < 2) ok = false;
        if(b == 2 && c < 1) ok = false;
        if(!ok){
            cout << -1 << '\n';
            continue;
        }
        ll X = (a + 1) / 2;
        ll nmin;
        if(b > 0) nmin = X + 1;
        else nmin = X + (c > (a % 2) ? 1 : 0);
        ll nmax;
        if(b == 1) nmax = a + c - 1;
        else nmax = a + c + b / 3;
        cout << nmin << ' ' << nmax << '\n';
    }
    return 0;
}
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int g = sc.nextInt();  

        for (int i = 0; i < g; i++) {
            long a = sc.nextLong();
            long b = sc.nextLong();
            long c = sc.nextLong();
            boolean ok = true;
            
            if (b == 1 && c < 2) {
                ok = false;
            }
            if (b == 2 && c < 1) {
                ok = false;
            }
            if (!ok) {
                System.out.println("-1");
                continue;
            }
            
            long X = (a + 1) / 2;
            long nmin;
            if (b > 0) {
                nmin = X + 1;
            } else {
                nmin = X + (c > (a % 2) ? 1 : 0);
            }
            
            long nmax;
            if (b == 1) {
                nmax = a + c - 1;
            } else {
                nmax = a + c + b / 3;
            }
            
            System.out.println(nmin + " " + nmax);
        }
        
        sc.close();
    }
}
```

```python
def main():
    import sys
    input = sys.stdin.readline  
    g = int(input().strip())
    for _ in range(g):
        a, b, c = map(int, input().split())
        ok = True
        if b == 1 and c < 2:
            ok = False
        if b == 2 and c < 1:
            ok = False
        if not ok:
            print(-1)
            continue

        X = (a + 1) // 2
        if b > 0:
            nmin = X + 1
        else:
            nmin = X + (1 if c > (a % 2) else 0)

        if b == 1:
            nmax = a + c - 1
        else:
            nmax = a + c + b // 3

        print(nmin, nmax)


if __name__ == "__main__":
    main()
```
