### 问题描述

在小红的魔法世界中，他拥有三种魔法元素：火元素、水元素和风元素，分别有 $a$ 个、$b$ 个和 $c$ 个。他需要将这些元素储存在魔法盒子中以便使用，但由于魔法元素的特性，存放时必须遵守以下规则：

1. 每个火元素所在盒子中的元素个数不得超过 $2$ 个。
2. 每个水元素所在盒子中的元素个数不得少于 $3$ 个。

风元素没有特殊要求，可以随意放置。小红希望用尽可能少的盒子来储存所有元素，同时也想知道最多可以使用多少个盒子。请帮助小红计算出最少和最多需要的盒子数量。

### 输入格式

第一行输入一个正整数 $g$，表示询问的次数。

接下来的 $g$ 行，每行输入三个正整数 $a, b, c$，表示一组询问。

### 输出格式

对于每一组询问，输出一行结果。

如果不存在合法的存放方案，则输出 `-1`。

否则，输出两个正整数，分别表示最少和最多需要的盒子数量。

### 样例输入

```
2
3 3 3
1 1 1
```

### 样例输出

```
3 7
-1
```

### 评测数据与规模

- $1 \leq g \leq 10^5$，$1 \leq a, b, c \leq 10^9$。
