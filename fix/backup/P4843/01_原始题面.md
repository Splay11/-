# 题目内容
某条产品分拣线上，每个产品会经过多个传感器测量得到若干数值，并被标记为放行（标签 `1`）或剔除（标签 `0`）。由于设备限制，分拣机只能依据某一个传感器的一次简单比较来决策：如果该传感器读数不超过某个阈值，则预测为一种结果，否则预测为另一种结果。

现在给出一个训练数据集，请你找出使得划分效果最好的传感器编号和阈值，并用该规则对新的产品样本做出预测。

对于由某传感器 $j$ 和阈值 $	heta$ 决定的一次划分，将训练样本分为左集合 $x_j \le 	heta$ 和右集合 $x_j > 	heta$。定义一个集合的混杂度 $h$ 为：

$$h = 1 - p_0^2 - p_1^2$$

其中 $p_0$ 和 $p_1$ 分别为该集合中标签 `0` 和标签 `1` 的比例。整个划分的加权混杂度定义为：

$$H = \frac{n_L}{n} h_L + \frac{n_R}{n} h_R$$

其中 $n$ 为训练样本总数，$n_L, n_R$ 分别为左、右集合的样本数，$h_L, h_R$ 分别为左、右集合的混杂度。

在训练过程中，需要对每一个传感器独立寻找最优阈值：
- 将该传感器对应的全部样本读数按升序进行**稳定排序**（即相等值保持原顺序）。
- 构造候选阈值集合：包括任意相邻不同读数的中点，以及“最小读数减去一个极小常数 $\varepsilon = 10^{-7}$”。
- 对每个候选阈值计算加权混杂度 $H$。如果该阈值导致左集合或右集合为空，则直接跳过。
- 记录该传感器下使 $H$ 最小的阈值（若 $H$ 相等，取阈值最小者）。

在所有传感器中比较各自的最优划分，选出全局 $H$ 最小的传感器和阈值。如果多个组合的 $H$ 并列最小，则优先选择传感器编号较小的，若仍并列则选择阈值较小的。

对于最终选定的划分，左集合的预测标签取集合内出现次数更多的标签（若 `0` 和 `1` 次数相等，则取 `0`），右集合同理。如果没有找到任何有效划分（即所有候选阈值都会导致一侧为空），则直接使用训练集全体样本的多数标签作为全局预测标签（相等时取 `0`）。

测试时，对每个新样本，检查其在选定传感器上的读数：若读数 $\le 	heta$，则给予左集合的预测标签；否则给予右集合的预测标签。

**数据范围与约束**
- 训练样本数 $n \ge 2$，传感器数（特征数） $m \ge 1$，待预测的测试样本数 $k \ge 1$。
- 所有传感器读数及标签均为整数或浮点数，数据中不存在缺失值。
- 极小常数 $\varepsilon = 10^{-7}$，仅用于构造最小值左侧的候选阈值。

# 输入描述
输入为一行 JSON 字符串，包含两个键："train" 和 "test"。
- "train" 是一个二维数组，每个元素是一个一维数组，其前 $m$ 个数为该样本的 $m$ 个传感器读数（数值类型），最后一个元素为标签（整数 `0` 或 `1`）。
- "test" 是一个二维数组，每个元素是一个长度为 $m$ 的数值数组，表示一个待测样本的传感器读数。

# 输出描述
输出一行 JSON 数组，依次包含每个测试样本的预测标签（整数 `0` 或 `1`）。

## 样例1

**输入**

```
{"train":[[0.1,1.0,0],[0.2,1.1,0],[0.3,1.2,1],[0.4,1.3,1]],"test":[[0.25,1.5],[1.0,0.5]]}
```

**输出**

```
[0, 1]
```

**说明**

训练集有 `4` 个样本，`2` 个传感器。

对传感器 `0`：读数升序为 `0.1`、`0.2`、`0.3`、`0.4`，对应标签 `0`、`0`、`1`、`1`。候选阈值有 `0.15`、`0.25`、`0.35`。当阈值 $	heta = 0.25$ 时，左集合 $\{0.1, 0.2\}$ 标签全 `0`，右集合 $\{0.3, 0.4\}$ 标签全 `1`，二者混杂度 $h_L = h_R = 0$，加权混杂度 $H = \frac{2}{4} 	imes 0 + \frac{2}{4} 	imes 0 = 0$，为该传感器最优。

对传感器 `1`：读数 `1.0`、`1.1`、`1.2`、`1.3`，标签 `0`、`1`、`0`、`1`，最优阈值为 `1.05`，对应的 $H = \frac{1}{3}$。全局比较，传感器 `0` 的 $H=0$ 更小，因此选定传感器 `0`，阈值 `0.25`，左集合预测标签 `0`，右集合预测标签 `1`。

测试样本 `[0.25, 1.5]` 在传感器 `0` 的读数为 `0.25`，满足 $\le 0.25$，预测左标签 `0`；样本 `[1.0, 0.5]` 读数为 `1.0 > 0.25`，预测右标签 `1`。故输出 `[0, 1]`。

## 样例2

**输入**

```
{"train":[[1.0,1.0,0],[1.0,1.0,1]],"test":[[1.0,1.0],[2.0,3.0]]}
```

**输出**

```
[0, 0]
```

**说明**

训练集有 `2` 个样本，所有传感器读数均为 `1.0`，标签分别为 `0` 和 `1`。

对每个传感器，排序后只有一个不同的读数值，唯一的候选阈值为 $\min - \varepsilon = 1.0 - 10^{-7}$。该阈值会导致左集合为空，按规则必须跳过，因此没有任何有效划分。此时无法训练决策树桩，直接使用训练集全体样本的多数标签作为全局预测。标签 `0` 和 `1` 数量相等，取 `0`。

测试集的两个样本在所有传感器上的读数不会影响预测，均输出全局标签 `0`。故输出 `[0, 0]`。

## 样例3

**输入**

```
{"train":[[0.1,0.5,0],[0.2,0.6,0],[0.3,0.7,1],[0.4,0.8,1]],"test":[[0.2,100],[0.5,0.2]]}
```

**输出**

```
[0, 1]
```

**说明**

训练集有 `4` 个样本，`2` 个传感器。

传感器 `0` 读数 `0.1`、`0.2`、`0.3`、`0.4`，对应标签 `0`、`0`、`1`、`1`。阈值 `0.25` 可以完美划分，加权混杂度 $H = 0$。

传感器 `1` 读数 `0.5`、`0.6`、`0.7`、`0.8`，标签 `0`、`0`、`1`、`1`。阈值 `0.65` 同样完美划分，$H = 0$。

两个传感器 $H$ 并列最小，根据优选规则：先比较传感器编号（小者优先），因此选用传感器 `0`，阈值 `0.25`。左集合（$\le 0.25$）包含标签 `0`、`0`，预测为 `0`；右集合（$> 0.25$）包含标签 `1`、`1`，预测为 `1`。

测试样本 `[0.2, 100]` 在传感器 `0` 的读数为 `0.2 \le 0.25`，预测 `0`；样本 `[0.5, 0.2]` 读数为 `0.5 > 0.25`，预测 `1`。故输出 `[0, 1]`。
