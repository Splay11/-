# 题目内容

分拣线上有长为 $L$ 的传送带，工位编号 $1,2,\dots,L$；每位有导向牌 `L`（向左）或 `R`（向右）。

包裹从起点 $s$ 出发，规则如下：

- 记当前工位为 $p$。若 $p$ 处为 `L` 则向左走，为 `R` 则向右走。
- 沿该方向持续移动，直到遇到**此前从未到达过**的第一个工位后停下，再按该工位导向继续；本轮只认出发工位的导向，途经工位忽略。
- 重复直至从左侧出界（位置 $0$，记 `L`）或右侧出界（位置 $L+1$，记 `R`）。

对每个起点 $s=1,2,\dots,L$，输出包裹最终出界方向。

# 输入描述

共有多组独立用例，需逐组求解。

- 首行给出整型 $q$（$1 \le q \le 2\times 10^5$），表示用例个数。
- 每组用例两行：
  - 第一行整型 $L$（$1 \le L \le 2\times 10^5$）。
  - 第二行长度为 $L$、仅含 `L`/`R` 的字符串 $g$，$g_i$ 为工位 $i$ 的导向。
- 全体用例的 $L$ 之和不超过 $2\times 10^5$。

# 输出描述

每组输出一行长度为 $L$ 的字符串；第 $i$ 个字符为起点 $i$ 时的出界方向（`L` 或 `R`）。

## 样例1

**输入**

```
2
4
RLRL
6
RRRLLL
```

**输出**

```
LLRR
LLLRRR
```

**说明**

- 第一组：`L` 共 $2$ 个，前 $2$ 个起点出 `L`，后 $2$ 个出 `R`。
- 第二组：`L` 共 $3$ 个，答案为 `LLLRRR`。
