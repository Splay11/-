# 题目内容

传感阵列给出长度为 $m$ 的整型读数 $v$。要从中选出长度为 $t$ 的子序列，使相邻两项的 $\gcd > 1$，并在所有合法子序列中最小化子序列的最大元素。若不存在合法子序列，输出 $-1$。

# 输入描述

第一行两个整型 $m,t$（$1 \le t \le m$；$2 \le m \le 200000$）。

第二行 $m$ 个整型 $v_1,v_2,\dots,v_m$（$1 \le v_i \le 1000000000$）。

# 输出描述

输出一个整数：合法子序列中最大元素的最小可能值；不存在则输出 $-1$。

## 样例1

**输入**

```
4 3
6 10 15 7
```

**输出**

```
15
```

**说明**

可选 $\{6,10,15\}$：$\gcd(6,10)=2$，$\gcd(10,15)=5$，最大值为 $15$。

## 样例2

**输入**

```
3 3
8 4 2
```

**输出**

```
8
```

**说明**

整段 $\{8,4,2\}$ 相邻均有公因子，最大值为 $8$。

## 样例3

**输入**

```
3 2
9 25 49
```

**输出**

```
-1
```

**说明**

任意两数 $\gcd$ 均为 $1$，无法选出长度为 $2$ 的合法子序列。
