# 题目内容



洗车收费分洗车费和附加费。你需要编写一个提示词，让AI根据以下规则计算费用。
1. 车型基础价小型车$38$元、SUV$58$元、MPV$78$元。精洗基础价加$80\%$向上取整，打蜡基础价加$150\%$向上取整，普通洗不加价。会员洗车费打$85$折向下取整，在洗车类型加价之后算。
2. 附加费内饰清洁每次$28$元、发动机清洗每次$45$元。
3. 节假日的话，会员折扣之后的洗车费和附加费一起加$20\%$向上取整。
4. 停车费室内停车$15$元、露天停车$0$元，停车费不参与节假日加成。



# 输入描述

输入为一段自然语言文本。



# 输出描述


输出一个标准JSON格式字符串，包含 $total\_bill$、$wash\_cost$ 和 $car\_type$ 三个字段。
- $total\_bill$：洗车费附加费加停车费（元）
- $wash\_cost$：节假日加成前的折后洗车费（元）
- $car\_type$：车型（"小型车"/"SUV"/"MPV"）

评测仅对照要求输出的字段，多余字段会被忽略。
