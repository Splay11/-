# 题目描述

塔子哥在玩一个数学游戏，他出一个正整数$s$，你需要找出两个正整数$x$，$y$相加等于这个数，即$x+y==s$。但是他觉得这样他简单了，所以他限制了一些数不能使用，即$x$，$y$都不能使用禁止的数。现在问你有多少种$x$，$y$满足这个条件。

# 输入描述

第一行输入一个正整数n，表示限制的个数。

第二行输入n个正整数$a_i$，表示限制该数的使用。

第三行输入一个正整数s。

$1≤n≤200000,1≤aᵢ,s≤10⁹$,保证每个禁着点都是不相等的。

# 输出描述

多少种满足条件的x，y。

# 示例1

**输入**

```
4
1 2 3 5
10
```

**输出**

```
2
```

**说明**
可以选择的方案有: <4,6>,<6,4>这两种。
