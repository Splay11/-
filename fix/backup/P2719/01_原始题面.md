# 题目内容

定义一个正整数$n$是有序数，当且仅当将其全部数位取出放入集合后，集合中的元素是连续的。

例如，$456$和$5446$都是有序数，因为将数位取出后放入集合，均得到{4,5,6}，是连续的。

现在，对于给定的区间$[l,r]$，你需要计算出这个区间内有多少个有序数。

# 输入描述

在一行上输入两个整数$l,r(1≤l≤r≤10^5)$代表询问的区间。

# 输出描述

输出一个整数，表示区间中的有序数个数。

## 样例1 

**输入** 

```
1 12
```

**输出** 

```
12
```

**说明**

前12个正整数均是有序数。





## 样例2

**输入** 

```
13 21
```

**输出** 

```
1 
```
