## 题目内容

通信系统收到一条长度为 $n$ 的信号串，每个字符为 `0`、`1` 或 `?`。需要把每个 `?` 独立替换为 `0` 或 `1`，得到最终信号串 $t$。

要求 $t$ 中每一段由相同字符组成的连续段（相同字符的极大连续子串）长度均为奇数。请计算共有多少种不同的补全方案，答案对 $10^9+7$ 取模。

## 输入描述

每个测试文件包含多组测试数据。第一行输入一个整数 $T\ (1 \le T \le 10^5)$ 表示数据组数，每组测试数据描述如下：

- 第一行输入一个整数 $n\ (1 \le n \le 2 \times 10^5)$，表示信号串长度。
- 第二行输入一个仅包含字符 `0`、`1`、`?` 的信号串 $s$，长度为 $n$。

保证所有测试数据的 $n$ 之和不超过 $2 \times 10^5$。

## 输出描述

对于每组测试数据，输出一个整数，表示满足要求的补全方案数，结果对 $10^9+7$ 取模。

## 样例1

**输入**

```
2
2
??
4
0?1?
```

**输出**

```
2
0
```

**说明**

- 第一组：$n=2$，信号串 `??`，合法补全只有 `01`、`10` 两种，两段长度均为 $1$（奇数），共 $2$ 种方案。
- 第二组：$n=4$，信号串 `0?1?`，无论中间两位如何补全，都会出现长度为 $2$ 的连续段，无合法方案，输出 $0$。
