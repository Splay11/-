# 题目描述

小红有一个长度为$n$的数组$a$，他想知道有多少对$\{a_i,a_j,a_k,a_l\},(i \lt j \lt k \lt l)$满足$a_i +a_j =a_k⊕a_l$

答案可能太大，请对$10^9+7$取模后再输出。

# 输出描述

第一行一个正整数$n$。
第二行$n$个正整数$a_i$

$1 \leq n \leq 10^4$

$1 \leq a_i \leq 100$

# 输出描述

一个整数，表示对$10^9+7$取模后的答案。

# 样例

**输入**

```
5
4 5 5 1 8
```

**输出**

```
2
```

**说明**

满足要求的四元组有$(1,2,4,5)$和$(1,3,4,5)$，即：$4+5=1⊕8=9$
