## 思路：构造

考虑对于一个字符串$s$，我们需要操作多少次可以将其所有的字符都变为相同字符

例如s=abbaaaccc...，除了字符a以外还有8个字符，考虑一种情况就是这8个字符都是相邻字符，没法一次性删除

- 第一次删除：删除不相邻的4个字符，还剩下4个字符
- 第二次删除：删除不相邻的2个字符，还剩2个字符
- 第三次删除：删除不相邻的1个字符，还剩1个字符
- 第四次删除：删除最后一个字符

对应的操作次数$k=4$，反推当$k=4$时则需要删除$2^{k-1}$个字母

剩余相同字母数为$n-2^{k-1}$

然后按照字母表的顺序进行构造即可

## 时间复杂度

$O(n)$

### c++代码

```cpp
#include <bits/stdc++.h>

using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    int pre = pow(2, k-1);
    int residual = n-pow(2,k-1);
    if(residual < 1 || 25*residual < pre){
        cout << -1 << endl;
    }else{
        string result(residual, 'z');
        for(int i=0; i<pre; i++){
            result += i%25+'a';
        }
        cout << result << endl;
    }

    return 0;
}
```

**python代码**

```python
n_k=[]
for i in input().split():
    n_k.append(i)
n=int(n_k[0])
k=int(n_k[1])

deleteCount = 1 << (k-1)
survivorCount=n-deleteCount
if survivorCount < 1:
    print(-1)
else:
    groupCount = 1
    groupSize = deleteCount
    while(groupSize>survivorCount):
        groupCount = groupCount * 2
        groupSize = deleteCount//groupCount 
    sb=""
    for i in range(groupCount):
        for j in range(groupSize):
            sb+=chr(ord('a')+(i%26))
    survivor = (chr)(ord(sb[-1])+1)
    for i in range(survivorCount):
        sb+=survivor
    print(sb)
```

**Java代码**

```java
import java.util.Scanner;
import java.lang.Math;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int k = scanner.nextInt();
        int pre = (int) Math.pow(2, k-1);
        int residual = n - pre;
        if(residual < 1 || 25*residual < pre){
            System.out.println(-1);
        }else{
            StringBuilder result = new StringBuilder();
            for(int i=0; i<residual; i++){
                result.append('z');
            }
            for(int i=0; i<pre; i++){
                result.append((char)(i%25+'a'));
            }
            System.out.println(result.toString());
        }
    }
}
```
