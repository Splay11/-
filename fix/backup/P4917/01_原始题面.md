# 题目内容

标定模块要构造长度为 $m$ 的整型序列 $w_1,w_2,\dots,w_m$，满足：

- 所有元素之和为 $0$；
- $\{|w_1|,|w_2|,\dots,|w_m|\}$ 恰为 $1\sim m$ 的一个排列；
- 每个 $w_i$ 满足 $-m \le w_i \le m$ 且 $w_i \ne 0$。

若无解输出 $-1$；否则输出任意一组合法序列。

# 输入描述

共有多组独立用例，需逐组求解。

- 首行给出整型 $q$（$1 \le q \le 10^4$），表示用例个数。
- 每组用例一行一个整型 $m$（$1 \le m \le 2\times 10^5$）。
- 全体用例的 $m$ 之和不超过 $2\times 10^5$。

# 输出描述

每组用例一行：

- 无解输出 $-1$；
- 否则输出 $m$ 个整数 $w_1,w_2,\dots,w_m$（多解输出任意一种）。

## 样例1

**输入**

```
4
1
4
5
8
```

**输出**

```
-1
1 -2 -3 4
-1
1 -2 -3 4 5 -6 -7 8
```

**说明**

- 第一组：$m=1$ 时总和不可能为 $0$。
- 第二组：$1-2-3+4=0$，绝对值恰为 $1\sim 4$。
- 第三组：$m \bmod 4 = 1$，无解。
- 第四组：按四元组 $x,-(x+1),-(x+2),x+3$ 拼接即可。
