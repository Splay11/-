# 题面描述

这天塔子哥有点困了，于是晚上十一点不到就躺在床上睡觉，但是他感觉没什么睡意，突然塔子哥想到了一个正整数，但他想将它切割成两部分，使得它们的和为偶数。塔子哥想知道有多少种合法的切割方案？注：切割后的正整数允许出现前导零。

# 输入描述

输入一个整数 $n$, $n$ $\leq$ $10^{100000}$

# 输出描述

输出一个整数，代表切割的方案数

# 示例1

**输入**

```
10086
```

**输出**

```
3
```



解释：可以切割成 $1008$ + $6$ = $1014$，$10 + 086 = 96$ , $100 + 86 =186$。共三种合法方案
