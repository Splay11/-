# 题目内容
在分析一批样本时，每个样本 $i$ 有两个整数特征 $p_i$ 和 $q_i$。定义样本 $i$ 与 $j$ 之间的差异度 $D(i,j) = (p_i - p_j)^2 + (q_i - q_j)^2$。

对于每个样本 $i$，我们考察除 $i$ 以外的所有样本，并按差异度从低到高排序。对于另一个样本 $j$（$j 
eq i$），令 $R(i,j)$ 表示满足 $k 
eq i, k 
eq j$ 且 $D(i,k) \le D(i,j)$ 的样本 $k$ 的个数。此外，约定 $R(i,i) = 0$。

请对于给定的 $n$ 个样本，计算出 $n 	imes n$ 的矩阵 $R$。

约束条件：
- 测试数据组数不超过 `100`；
- 每组的样本数 $n$ 不小于 `1`，且所有组的 $n$ 之和不超过 `2000`；
- 所有特征值均为不超过 `10^9` 的正整数。

# 输入描述
第一行包含一个整数 $T$（$1 \le T \le 100$），表示测试数据组数。
对于每组数据：
- 第一行包含一个整数 $n$，表示样本的个数；
- 接下来的 $n$ 行，每行包含两个整数 $p_i, q_i$（$1 \le p_i, q_i \le 10^9$），表示第 $i$ 个样本的两个特征值。

保证所有 $n$ 的总和不超过 $2000$。

# 输出描述
对于每组测试数据，输出 $n$ 行，每行包含 $n$ 个整数，表示矩阵 $R$ 的对应行。具体地，第 $i$ 行的第 $j$ 个整数表示 $R(i,j)$。同一行内的整数以单个空格分隔。
各组测试数据的输出之间不需要额外的空行。

## 样例1

**输入**

```
2
1
1 1
2
1 1
2 2
```

**输出**

```
0
0 0
0 0
```

**说明**

第一组数据中 $n=1$，只有样本 `1`，由定义 $R(1,1)=0$。
第二组数据中 $n=2$，样本 `1` 和 `2` 之间的差异度不为 `0`，但由于不存在满足 $k 
eq i$ 且 $k 
eq j$ 的第三个样本 $k$，因此所有非对角线元素均为 `0`。综合得到如上输出。

## 样例2

**输入**

```
1
3
1 1
2 1
4 1
```

**输出**

```
0 0 1
0 0 1
1 0 0
```

**说明**

三个样本的特征值分别为 $(1,1)$、$(2,1)$、$(4,1)$。
对于样本 `1`：$D(1,2)=1$，$D(1,3)=9$。满足 $D(1,k) \le D(1,2)$ 的 $k$（$k 
eq 1,2$）不存在，故 $R(1,2)=0$；满足 $D(1,k) \le D(1,3)$ 的有 $k=2$，故 $R(1,3)=1$。
对于样本 `2`：$D(2,1)=1$，$D(2,3)=4$。类似可得 $R(2,1)=0$，$R(2,3)=1$。
对于样本 `3`：$D(3,2)=4$，$D(3,1)=9$。类似可得 $R(3,2)=0$，$R(3,1)=1$。
因此输出如上矩阵。

## 样例3

**输入**

```
1
4
1 1
2 1
4 1
4 5
```

**输出**

```
0 0 1 2
0 0 1 2
1 0 0 2
2 1 0 0
```

**说明**

四个样本记为 $A(1,1)$、$B(2,1)$、$C(4,1)$、$D(4,5)$。
对于 $A$：距离平方 $AB=1$，$AC=9$，$AD=25$。从小到大排序为 $B,C,D$。$R(A,B)=0$；$R(A,C)=1$（含 $B$）；$R(A,D)=2$（含 $B,C$）。故第一行 `0 0 1 2`。
对于 $B$：$BA=1$，$BC=4$，$BD=20$。排序 $A,C,D$。$R(B,A)=0$，$R(B,C)=1$，$R(B,D)=2$。第二行 `0 0 1 2`。
对于 $C$：$CB=4$，$CA=9$，$CD=16$。排序 $B,A,D$。$R(C,B)=0$，$R(C,A)=1$，$R(C,D)=2$。注意列顺序为 $A,B,C,D$，因此第三行 `1 0 0 2`。
对于 $D$：$DC=16$，$DB=20$，$DA=25$。排序 $C,B,A$。$R(D,C)=0$，$R(D,B)=1$，$R(D,A)=2$。第四行 `2 1 0 0`。
