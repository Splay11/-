## 思路

这个问题的核心在于“连续”、“非空”以及“乘积均相同”这几个条件。

1. **乘积相同的含义**
   数组中的元素只有 $1$ 和 $2$。任何一个子数组的乘积都是 $2$ 的某个次幂（包括 $2^0=1$）。要想让 $z$ 个子数组的乘积都相同，那么它们的乘积必然都等于同一个值 $P$。这个值 $P$ 也必须是 $2$ 的幂。

2. **与 2 的数量挂钩**
   一个子数组的乘积由其中 $2$ 的数量决定。如果一个子数组有 $k$ 个 $2$，那么它的乘积就是 $2^k$。因此，“所有子数组乘积相同”等价于“所有子数组包含的 $2$ 的数量相同”。

3. **推导核心条件**

   * 设整个数组中 $2$ 的总数量为 $c_2$。
   * 如果我们要将数组分为 $z$ 段，每段的 $2$ 的数量都相同，设为 $k$。那么总的 $2$ 的数量必然满足 $c_2 = z \times k$。这意味着 $c_2$ 必须是 $z$ 的整数倍。如果 $c_2 % z \ne 0$，那么无论如何也无法满足条件，直接输出 `No`。
   * 如果 $c_2 % z = 0$，我们计算出每段应有的 $2$ 的数量 $k = c_2 / z$。现在问题转化为：能否将数组切分成 $z$个连续非空的子数组，使得每个子数组都恰好包含 $k$ 个 $2$？

4. **分情况讨论**

   * **情况一：$c_2 = 0$**
     此时数组中全是 $1$。任何子数组的乘积都是 $1$。我们只需要判断能否将长度为 $n$ 的数组分成 $z$个非空的段。只要分的段数 $z$ 不超过数组总长度 $n$（即 $z \le n$），就一定可以做到（例如，前 $z-1$ 个段都只包含一个元素，最后一个段包含剩下所有元素）。因此，当 $c_2=0$ 时，只要 $z \le n$，答案就是 Yes。

   * **情况二：$c_2 > 0$ 且 $c_2 % z = 0$**
     我们需要进行 $z-1$ 次切割，来得到 $z$ 个分段。假设第 $i$ 个分段的结尾是原数组的第 $p_i$ 个位置。为了让最后一段 $[p_{z-1}+1, n]$ 非空，我们最晚的切割点 $p_{z-1}$ 必须小于 $n$，即 $p_{z-1} \le n-1$。

     前 $z-1$ 个分段合起来，是从数组开头到 $p_{z-1}$ 位置。这些分段总共应包含 $(z-1) \times k$ 个 $2$。

     为了能找到这样一个小于 $n$ 的切割点 $p_{z-1}$，我们必须确保在数组的前 $n-1$ 个元素中，至少有 $(z-1) \times k$ 个 $2$。

     令 `prefix_twos_n_minus_1` 表示数组 $a[1...n-1]$ 中 $2$ 的数量。最终的条件就是：
     $(z-1)$ $\times$ $k$ $\le$ $prefix_twos_n_minus_1$

     如果这个条件成立，我们总能找到合适的切割点。因为数组中 $2$ 的前缀和是递增的，必然能找到一个位置，其前缀和恰好等于 $(z-1) \times k$，并且这个位置一定小于 $n$。

5. **高效计算**
   由于有 $m$ 次操作，每次都重新计算 $c_2$和 $prefix_twos_n_minus_1$ 会导致超时。我们需要一种快速更新的方法。

   * 在读入初始数组时，一次性计算出总的 $2$ 的数量 $c_2$。
   * 每次修改操作 $(x, y, z)$，我们只关心 $a_x$ 的值是否从 $1$ 变 $2$ 或从 $2$ 变 $1$。

     * 如果 $a_x 从 $1 \to 2$，则 $c_2$ 加一。
     * 如果 $a_x 从 $2 \to 1$，则 $c_2$ 减一。
     * 如果是 $1 \to 1$ 或 $2 \to 2$，$c_2$不变。
   * $prefix_twos_n_minus_1$ 可以由更新后的 $c_2$ 和数组的最后一个元素 $a_n$ 快速得到：$prefix_twos_n_minus_1$ = $c_2$ - ($a_n$ == $2$? $1$ : $0$)。
   * 这样，每次操作和判断都可以在 $O(1)$的时间内完成。

### C++ 

```cpp
#include <iostream>
#include <vector>
#include <numeric>

// 使用快速 I/O
void fast_io() {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(NULL);
}

void solve() {
    int n, m;
    std::cin >> n >> m;
    std::vector<int> a(n);
    long long count_twos = 0; // 存储数组中 '2' 的总数

    // 读取初始数组并计算 '2' 的个数
    for (int i = 0; i < n; ++i) {
        std::cin >> a[i];
        if (a[i] == 2) {
            count_twos++;
        }
    }

    for (int k_op = 0; k_op < m; ++k_op) {
        long long x, y, z;
        std::cin >> x >> y >> z;
        --x; // 转换为 0-based 索引

        // 更新操作
        // 如果新旧值不同，需要更新 count_twos
        if (a[x] != y) {
            if (a[x] == 2) {
                count_twos--; // 从 2 变为 1
            } else {
                count_twos++; // 从 1 变为 2
            }
            a[x] = y; // 更新数组
        }

        // 判断逻辑
        if (z > n) { // 无法分成比数组长度还多的非空段
            std::cout << "No\n";
            continue;
        }

        if (count_twos == 0) { // 如果全是1，只要 z <= n 就可以
            std::cout << "Yes\n";
            continue;
        }

        // 如果2的总数无法被z整除，则无法均分
        if (count_twos % z != 0) {
            std::cout << "No\n";
        } else {
            long long k = count_twos / z; // 每段需要 k 个 2
            
            // 前 n-1 个元素中 2 的数量
            // 等于总数减去最后一个元素（如果是2的话）
            long long prefix_twos_n_minus_1 = count_twos;
            if (a[n - 1] == 2) {
                prefix_twos_n_minus_1--;
            }

            // 前 z-1 段总共需要 (z-1)*k 个 2
            // 这些 2 必须全部来自于数组的前 n-1 个位置
            if ((z - 1) * k <= prefix_twos_n_minus_1) {
                std::cout << "Yes\n";
            } else {
                std::cout << "No\n";
            }
        }
    }
}

int main() {
    fast_io();
    int t;
    std::cin >> t;
    while (t--) {
        solve();
    }
    return 0;
}
```

### Python
```python
import sys

def solve():
    """
    处理单个测试用例
    """
    # 使用 sys.stdin.readline 加速输入
    n, m = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    
    # 统计初始数组中 '2' 的个数
    count_twos = a.count(2)

    for _ in range(m):
        x, y, z = map(int, sys.stdin.readline().split())
        x -= 1 # 转换为 0-based 索引

        # 更新操作
        # 如果新旧值不同，需要更新 count_twos
        if a[x] != y:
            if a[x] == 2:
                count_twos -= 1 # 从 2 变为 1
            else:
                count_twos += 1 # 从 1 变为 2
            a[x] = y # 更新数组

        # 判断逻辑
        if z > n: # 无法分成比数组长度还多的非空段
            print("No")
            continue

        if count_twos == 0: # 如果全是1，只要 z <= n 就可以
            print("Yes")
            continue
            
        # 如果2的总数无法被z整除，则无法均分
        if count_twos % z != 0:
            print("No")
        else:
            k = count_twos // z # 每段需要 k 个 2
            
            # 前 n-1 个元素中 2 的数量
            # 等于总数减去最后一个元素（如果是2的话）
            prefix_twos_n_minus_1 = count_twos
            if a[n - 1] == 2:
                prefix_twos_n_minus_1 -= 1

            # 前 z-1 段总共需要 (z-1)*k 个 2
            # 这些 2 必须全部来自于数组的前 n-1 个位置
            if (z - 1) * k <= prefix_twos_n_minus_1:
                print("Yes")
            else:
                print("No")


def main():
    """
    主函数，处理多组测试数据
    """
    try:
        # 读取测试数据组数
        num_tests = int(sys.stdin.readline())
        for _ in range(num_tests):
            solve()
    except (IOError, ValueError):
        # 处理可能的输入结束或格式错误
        pass

if __name__ == "__main__":
    main()
```

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.PrintWriter;
import java.util.StringTokenizer;

public class Main {

    // 使用静态内部类实现快速输入
    static class FastReader {
        BufferedReader br;
        StringTokenizer st;

        public FastReader() {
            br = new BufferedReader(new InputStreamReader(System.in));
        }

        String next() {
            while (st == null || !st.hasMoreElements()) {
                try {
                    st = new StringTokenizer(br.readLine());
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
            return st.nextToken();
        }

        int nextInt() {
            return Integer.parseInt(next());
        }
        
        long nextLong() {
            return Long.parseLong(next());
        }
    }

    public static void solve() {
        FastReader sc = new FastReader();
        PrintWriter out = new PrintWriter(System.out);

        int n = sc.nextInt();
        int m = sc.nextInt();
        int[] a = new int[n];
        long countTwos = 0;

        // 读取初始数组并计算 '2' 的个数
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
            if (a[i] == 2) {
                countTwos++;
            }
        }

        for (int k_op = 0; k_op < m; k_op++) {
            int x = sc.nextInt();
            int y = sc.nextInt();
            long z = sc.nextLong();
            x--; // 转换为 0-based 索引

            // 更新操作
            // 如果新旧值不同，需要更新 countTwos
            if (a[x] != y) {
                if (a[x] == 2) {
                    countTwos--; // 从 2 变为 1
                } else {
                    countTwos++; // 从 1 变为 2
                }
                a[x] = y; // 更新数组
            }

            // 判断逻辑
            if (z > n) { // 无法分成比数组长度还多的非空段
                out.println("No");
                continue;
            }

            if (countTwos == 0) { // 如果全是1，只要 z <= n 就可以
                out.println("Yes");
                continue;
            }

            // 如果2的总数无法被z整除，则无法均分
            if (countTwos % z != 0) {
                out.println("No");
            } else {
                long k = countTwos / z; // 每段需要 k 个 2
                
                // 前 n-1 个元素中 2 的数量
                // 等于总数减去最后一个元素（如果是2的话）
                long prefixTwosNMinus1 = countTwos;
                if (a[n - 1] == 2) {
                    prefixTwosNMinus1--;
                }
                
                // 前 z-1 段总共需要 (z-1)*k 个 2
                // 这些 2 必须全部来自于数组的前 n-1 个位置
                if ((z - 1) * k <= prefixTwosNMinus1) {
                    out.println("Yes");
                } else {
                    out.println("No");
                }
            }
        }
        out.flush(); // 确保所有输出都被打印
    }

    public static void main(String[] args) {
        FastReader sc = new FastReader();
        int t = sc.nextInt();
        while (t-- > 0) {
            solve();
        }
    }
}
```
