# 题目内容

日志模块拿到三条等长为 $m$ 的整型序列 $x$、$y$ 与下标序列 $p$。统计有序对 $(u,v)$ 的个数，满足 $1 \le u \le v \le m$ 且 $x_u = y_{p_v}$。

# 输入描述

共有多组独立用例，需逐组求解。首行给出整型 $q$（$1 \le q \le 200000$）表示用例个数；全体用例的 $m$ 合计不超过 $200000$。每组格式如下：

- 第一行一个整型 $m$（$1 \le m \le 100000$）；
- 第二行 $m$ 个整型 $x_1,\dots,x_m$（$1 \le x_i \le 1000000000$）；
- 第三行 $m$ 个整型 $y_1,\dots,y_m$（$1 \le y_i \le 1000000000$）；
- 第四行 $m$ 个整型 $p_1,\dots,p_m$（$1 \le p_v \le m$）。

# 输出描述

每组用例新起一行，输出一个整数表示有序对数量。

## 样例1

**输入**

```
2
3
1 1 2
2 1 1
1 2 3
2
5 5
5 1
1 1
```

**输出**

```
4
3
```

**说明**

- 第一组：满足条件的有序对共 $4$ 个。
- 第二组：共 $3$ 个。
