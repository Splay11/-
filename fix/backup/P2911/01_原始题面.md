# 题目内容

给定一条长度为$n$的数轴，包含$0$到$n$共$n+1$个整数坐标点。初始时你位于坐标$x$处，需要到达整数坐标$y$。

你每次可以从以下四种移动方式中选择一种进行移动:向左移动$1$格(即坐标 $-1$)，向左移动$2$格(即
坐标 $-2$)，向右移动$1$格(即坐标$+1$)，向右移动$2$格 (即坐标$+2$)。

每个整数坐标最多访问一次(起点视为已访问)，并且移动后坐标必须保持在$[0,n]$范围内。且到达终点后
立即停止移动。

现在你想知道，有多少种不同的移动方案，能够使得你成功到达出口$y$处?



# 输入描述

在一行上输入三个整数$n,x,y(1≦n≦25;0≦x,y≦n; x≠y) $代表数轴长度，你初始位置，出口位置。

# 输出描述

输出一个整数，表示有多少种不同的移动方案能够使得你成功到达出口$y$处。

## 样例1 

**输入** 

```
3 2 3
```

**输出** 

```
3
```

#### 说明

在这个样例中，有以下三种移动方案:

- $2→3$;
- $2→1→3$;
- $2→0→1→3$
