# 题目内容
在一个任务调度系统中，共有 $n$ 个待处理任务，每个任务有一个重要程度评级 $a_i$。由于系统资源有限，需要取消 $m$ 个最不重要的任务，腾出资源。具体规则为：每次取消当前剩余任务中重要程度评级最小的一个；若有多个任务评级相同，则取消提交时间最早的那个（即原序列中最靠前的）。

现在给出初始的任务评级序列，请你输出经过 $m$ 次取消后，剩余的任务评级序列（保持原始相对顺序）。

**数据约束：**

- 测试数据组数 $T$ 满足 $1 \le T \le 2 	imes 10^5$。
- 每组数据中，任务数量 $n$ 满足 $1 \le n \le 2 	imes 10^5$，取消次数 $m$ 满足 $0 \le m < n$。
- 每个评级 $a_i$ 均为整数，满足 $1 \le a_i \le n$。
- 所有测试数据的 $n$ 之和不超过 $4 	imes 10^5$。

# 输入描述
第一行输入一个整数 $T$，表示数据组数。
接下来依次描述每组数据：
第一行包含两个整数 $n$ 和 $m$，分别表示任务总数和需要取消的任务数。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$，表示初始的任务评级序列。

# 输出描述
对于每组数据，输出一行，包含剩余的任务评级，按原始相对顺序用空格分隔。

## 样例1

**输入**

```
1
6 2
2 1 3 1 4 2
```

**输出**

```
2 3 4 2
```

**说明**

初始序列为 $a=[2,1,3,1,4,2]$，$n=6$，$m=2$。评级最小的任务为 `1`，共有 `2` 个，分别位于原序列的第 `2` 和第 `4` 个位置。由于 $m=2$，两个评级为 `1` 的任务均被取消。剩余任务依次为 `2`，`3`，`4`，`2`，按原顺序输出。

## 样例2

**输入**

```
1
5 3
3 3 3 1 2
```

**输出**

```
3 3
```

**说明**

初始序列 $a=[3,3,3,1,2]$，$n=5$，$m=3$。

取消过程：首先取消评级最小的 `1`（位于原序列的第 `4` 个位置），剩余可取消次数 $m$ 减为 `2`；接着取消评级 `2`（第 `5` 个位置），$m$ 减为 `1`；此时剩余任务评级均为 `3`，共有 `3` 个，只需再取消其中提交最早的一个，即原序列中第 `1` 个位置的任务。

最终剩余第 `2` 和第 `3` 个位置的任务，评级均为 `3`，按原顺序输出为 `3 3`。

## 样例3

**输入**

```
1
4 3
4 1 3 2
```

**输出**

```
4
```

**说明**

初始序列 $a=[4,1,3,2]$，$n=4$，$m=3$。依次取消评级最小的任务：`1`（第 `2` 个位置），`2`（第 `4` 个位置），`3`（第 `3` 个位置）。最终仅剩评级 `4` 的任务（第 `1` 个位置），输出 `4`。
