# 题目描述

塔子哥来到一家商场购物。

这家商场正在优惠促销，部分商品可以参加每满 $300$ 减 $50$ 的活动。

现在给定你塔子哥购买的每个物品的价格，以及每个物品是否参加满减活动。

你需要告诉塔子哥，在满减后，他实际需要支付的价格。

# 输入描述

第一行，一个整数 $n(1 \leq n \leq 10^5)$，表示塔子哥购买的物品数。

接下来$n$行，每行两个整数，第一个整数 $p(1\leq p\leq 10^4)$ 表示物品的价格，第二个整数 $q(0\leq q\leq 1)$ 表示该物品是否参加活动，$p=1$ 表示参加，$p=0$ 表示不参加 

# 样例

**输入**

```
5
114 0
514 1
998 0
244 1
353 1
```

**输出**

```
2073
```

**说明**

参加满减活动的物品的总价格为 514+244+353=1111\
每 300 减 50 ，一共可以减 150 ，故最后总价格为 (114+998) + (1111-150)=2073
