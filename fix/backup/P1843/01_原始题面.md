# 题目描述

塔子哥有 $n$ 个数字 $A_1, A_2, \ldots, A_n$，他想知道这些数字中出现次数小于等于 $k$ 的最小的数。

# 输入描述

第一行包含两个正整数 $n$ 和 $k$，接下来一行包含 $n$ 个正整数，第 $i$ 个表示 $A_i$。其中 $1 \leq k \leq n \leq 10^5$，$1 \leq A_i \leq 10^9$。

# 输出描述

输出一行一个整数，表示答案。如果不存在出现次数小于等于 $k$ 次的数字，输出 $-1$。

## 样例输入

```
5 2
1 1 1 2 3
```

## 样例输出

```
2
```

## 样例输入

```
8 2
1 1 4 5 7 1 3 3
```

## 样例输出

```
3
```
