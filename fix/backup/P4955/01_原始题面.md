# 题目内容
在一片辽阔的平原上散落着 $n$ 个村庄，编号依次为 `0`, `1`, $\dots$, `n-1`，每个村庄拥有唯一的二维坐标。现因行政规划需要，要将所有村庄归并为恰好 $K$ 个管理区。

初始时每个村庄自成一个管理区。随后反复执行以下合并操作，直到管理区总数等于 $K$：

1. 定义两个管理区 $A$ 与 $B$ 之间的距离为其中任意两个村庄之间欧几里德距离的最小值：
   $$D(A,B)=\min_{p\in A,\,q\in B} d(p,q),$$
   其中 $d(p,q)=\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}$ 为村庄的欧氏距离。

2. 找出距离最小的所有管理区对。若有多个平局对，则采用以下规则确定合并目标：对每一对管理区，记两个管理区中所含村庄的最小编号分别为 $a$ 和 $b$（设 $a<b$），构造有序对 $(a,b)$。比较所有这些有序对，选取字典序最小的那对。

3. 将选出的两个管理区合并为一个新的管理区，其成员村庄为原来两个管理区村庄的并集。

当管理区数量恰好为 $K$ 时，停止合并，进入编号分配阶段。设此时 $K$ 个管理区为 $G_0,G_1,\dots,G_{K-1}$。对每个管理区计算其行政中心，即所有成员村庄坐标的算术平均。按照以下优先级对管理区进行升序排序，并依次赋予编号 `0`, `1`, $\dots$, `K-1`：
- 第一关键字：行政中心的 $x$ 坐标；
- 若两个行政中心的 $x$ 坐标之差的绝对值小于 $10^{-12}$，则比较 $y$ 坐标；
- 若 $x,y$ 仍无法区分，则比较管理区内所含村庄的最小编号。

最终，你需要给出每个村庄依据上述排序所获得的管理区编号。

**数据范围**
- 村庄总数 $n$ 满足 $2 \le K \le n \le 100$。
- 所有坐标均为整数或浮点数，绝对值不超过 $10^6$。

# 输入描述
输入只有一行，包含一个 JSON 字符串。该 JSON 对象包含两个字段：
- `"K"`：一个整数，表示最终需要保留的管理区个数；
- `"villages"`：一个二维数组，按输入顺序给出每个村庄的坐标，形如 `[[x0,y0],[x1,y1],...]`，所有坐标的绝对值均不超过 $10^6$。

# 输出描述
输出一行，包含一个 JSON 数组，其长度等于村庄总数 $n$。数组的第 $i$ 个元素为输入中第 $i$ 个村庄最终所属管理区的编号（编号从 `0` 开始且连续）。

## 样例1

**输入**

```
{"K":1,"villages":[[0,0],[2,0],[1,2]]}
```

**输出**

```
[0,0,0]
```

**说明**

村庄总数 $n=3$，目标管理区数 $K=1$。初始管理区为 `{0}`，`{1}`，`{2}`。计算距离：$d(0,1)=2$，$d(0,2)=\sqrt{5}$，$d(1,2)=\sqrt{5}$。最小距离为 `2`，对应管理区对 `(0,1)`，合并得 `{0,1}`。

当前管理区为 `{0,1}` 与 `{2}`，距离 $D(\{0,1\},\{2\})=\min(\sqrt{5},\sqrt{5})=\sqrt{5}$，合并得 `{0,1,2}`。此时管理区总数等于 `1`，停止合并。

唯一管理区的行政中心为 $\big(\frac{0+2+1}{3},\frac{0+0+2}{3}\big)=(1,\frac{2}{3})$，直接赋予编号 `0`。所有村庄均属于编号 `0` 的管理区，故输出 `[0,0,0]`。

## 样例2

**输入**

```
{"K":2,"villages":[[0,0],[2,2],[2,0],[0,2]]}
```

**输出**

```
[1,1,1,0]
```

**说明**

村庄坐标构成正方形，$n=4$，$K=2$。初始管理区 `{0}`，`{1}`，`{2}`，`{3}`。距离：$d(0,2)=2$，$d(0,3)=2$，$d(1,2)=2$，$d(1,3)=2$，其余大于 `2`。最小距离 `2`，平局对为 `(0,2)`、`(0,3)`、`(1,2)`、`(1,3)`。按字典序取最小编号对 `(0,2)` 合并，得到 `{0,2}`。

此时管理区 `{0,2}`、`{1}`、`{3}`。所有对距离均为 `2`，平局对包括 `({0,2},{1})`（$a=0,b=1$）、`({0,2},{3})`（$a=0,b=3$）、`({1},{3})`（$a=1,b=3$）。字典序最小为 `(0,1)`，合并得 `{0,1,2}`。

现有 `{0,1,2}` 和 `{3}`，总数等于 $K=2$，停止。行政中心：`{0,1,2}` 为 $(\frac{4}{3},\frac{2}{3})$，`{3}` 为 $(0,2)$。比较 $x$ 坐标：$0 < \frac{4}{3}$，故 `{3}` 获编号 `0`，`{0,1,2}` 获编号 `1`。输出村庄 `0`、`1`、`2` 为 `1`，村庄 `3` 为 `0`，即 `[1,1,1,0]`。

## 样例3

**输入**

```
{"K":2,"villages":[[10,10],[20,20]]}
```

**输出**

```
[0,1]
```

**说明**

边界情况：$n=2$，$K=2$，村庄数等于目标管理区数，无需合并。两个管理区 `{0}` 和 `{1}` 的行政中心分别为 $(10,10)$ 与 $(20,20)$。按 $x$ 坐标升序，`{0}` 获编号 `0`，`{1}` 获编号 `1`。输出 `[0,1]`。

## 样例4

**输入**

```
{"K":2,"villages":[[-1,0],[1,0],[0,2],[0,-2]]}
```

**输出**

```
[1,1,1,0]
```

**说明**

$n=4$，$K=2$。初始管理区 `{0}`，`{1}`，`{2}`，`{3}`。距离：$d(0,1)=2$，其余均大于 `2`。最小距离 `2` 只有对 `(0,1)`，合并为 `{0,1}`。

当前管理区 `{0,1}`、`{2}`、`{3}`。距离：$D(\{0,1\},\{2\})=\sqrt{5}$，$D(\{0,1\},\{3\})=\sqrt{5}$，$d(2,3)=4$。平局对 `({0,1},{2})`（$a=0,b=2$）与 `({0,1},{3})`（$a=0,b=3$）。字典序最小 `(0,2)`，合并得 `{0,1,2}`。此时管理区 `{0,1,2}` 和 `{3}`，总数 $K=2$，停止。

行政中心：`{0,1,2}` 为 $(0,\frac{2}{3})$，`{3}` 为 $(0,-2)$。两者 $x$ 坐标均为 `0`，差小于 $10^{-12}$，比较 $y$ 坐标：$-2 < \frac{2}{3}$，故 `{3}` 编号 `0`，`{0,1,2}` 编号 `1`。输出 `[1,1,1,0]`。
