## 题解思路

### 1. 预处理点与点之间的距离

题目要求使用欧氏距离：

$$
d((x_1,y_1),(x_2,y_2))=\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}
$$

但在比较距离大小时，是否开根号不影响结果，所以代码里可以直接使用**平方距离**：

$$
d^2=(x_1-x_2)^2+(y_1-y_2)^2
$$

这样可以避免不必要的开方计算。



### 2. 初始化管理区

一开始每个点自己构成一个管理区。

例如有 5 个点：

```python
[{0}, {1}, {2}, {3}, {4}]
```

其中集合中的数字表示原始输入点的下标。



### 3. 每一轮寻找要合并的两个管理区

假设当前有若干个管理区。

对于任意两个管理区 $A, B$，距离定义为：

$$
D(A,B)=\min_{p \in A, q \in B} d(p,q)
$$

也就是说，两个管理区之间的距离等于两个管理区中**最近两个点的距离**。

遍历所有管理区对，找到距离最小的一对。



### 4. 处理距离相同的平局情况

如果有多个管理区对距离相同，需要按题目规则选择。

对于两个管理区 $A, B$，令：

```python
a = min(A)
b = min(B)
```

再让较小的下标放前面，得到关键字：

```python
(min(a, b), max(a, b))
```

如果两个管理区对距离相同，就选择关键字字典序更小的管理区对。

例如：

```python
(0, 3) < (1, 2)
```

所以优先合并包含最小编号更靠前的管理区对。



### 5. 合并管理区

找到目标管理区对后，将它们合并：

```python
A = A | B
```

然后删除原来的另一个管理区。

不断重复这个过程，直到管理区的数量等于目标管理区数 $K$。



### 6. 重新映射最终管理区编号

合并结束后，得到 $K$ 个管理区。

题目要求最终编号不是按合并顺序给，而是按每个管理区的行政中心排序。

对每个管理区计算行政中心：

$$
center_x = \frac{x_1+x_2+\cdots+x_k}{k}
$$

$$
center_y = \frac{y_1+y_2+\cdots+y_k}{k}
$$

排序规则为：

1. 先按行政中心 $x$ 升序；
2. 若 $x$ 相等，即 $|\Delta x| < 1e-12$，再按行政中心 $y$ 升序；
3. 若还相等，再按管理区内所含村庄的最小编号升序。

排序后，第一个管理区编号为 `0`，第二个管理区编号为 `1`，依次类推。



## 代码实现

### Python

```python
import sys
import json
import numpy as np

EPS = 1e-12


def cluster_less(a, b):
    # 最终管理区排序规则：先比行政中心 x，再比行政中心 y，最后比管理区内最小编号
    if abs(a[0] - b[0]) >= EPS:
        return a[0] < b[0]
    if abs(a[1] - b[1]) >= EPS:
        return a[1] < b[1]
    return a[2] < b[2]


def hac_single_linkage(C, points):
    points = np.array(points, dtype=float)
    n = len(points)

    # 预处理所有点之间的欧氏距离
    diff = points[:, None, :] - points[None, :, :]
    dist = np.sqrt(np.sum(diff * diff, axis=2))

    # 初始化：每个点自成一管理区
    clusters = [[i] for i in range(n)]

    # 不断合并，直到管理区数等于 K
    while len(clusters) > C:
        best_d = float("inf")
        best_key = None
        best_pair = (0, 1)
        m = len(clusters)

        # 枚举所有管理区对
        for i in range(m):
            for j in range(i + 1, m):
                A = clusters[i]
                B = clusters[j]

                # 管理区之间最近点对的距离
                d = np.min(dist[np.ix_(A, B)])

                # 平局比较关键字：(min(A), min(B))，并保证前小后大
                x = A[0]
                y = B[0]
                if x > y:
                    x, y = y, x
                key = (x, y)

                # 更新最优合并管理区对
                if d < best_d - EPS:
                    best_d = d
                    best_key = key
                    best_pair = (i, j)
                elif abs(d - best_d) <= EPS and key < best_key:
                    best_key = key
                    best_pair = (i, j)

        i, j = best_pair

        # 合并两个管理区，保持内部下标有序
        new_cluster = sorted(clusters[i] + clusters[j])

        # 先删除下标大的管理区，避免下标变化
        clusters.pop(j)
        clusters.pop(i)
        clusters.append(new_cluster)

    # 计算每个管理区的行政中心和最小编号
    infos = []
    for cluster in clusters:
        arr = points[cluster]
        cx = float(np.mean(arr[:, 0]))
        cy = float(np.mean(arr[:, 1]))
        infos.append([cx, cy, cluster[0], cluster])

    # 按行政中心 x、行政中心 y、管理区内最小编号排序
    for i in range(len(infos)):
        pos = i
        for j in range(i + 1, len(infos)):
            if cluster_less(infos[j], infos[pos]):
                pos = j
        infos[i], infos[pos] = infos[pos], infos[i]

    # 生成每个村庄对应的管理区编号
    ans = [0] * n
    for label, info in enumerate(infos):
        cluster = info[3]
        for idx in cluster:
            ans[idx] = label

    return ans


def main():
    data = json.loads(sys.stdin.readline())
    C = data["C"]
    points = data["points"]

    ans = hac_single_linkage(C, points)

    # 默认 json.dumps 会在逗号后输出空格，与样例格式一致
    print(json.dumps(ans))


if __name__ == "__main__":
    main()

```
