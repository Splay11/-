## 解题思路

本题要求通过最多 $k$ 次相邻交换操作，使得最终得到的 $0/1$ 序列字典序最小。  
为了最小化字典序，我们需要**尽可能地将 $0$ 移动到序列的前面**，因为 $0$ 比 $1$ 小，更靠前的 $0$ 能让整个序列更优。

可采用**贪心**策略：
1. 从左到右遍历原字符串，维护一个计数器 `cnt`，记录在当前位置前已经遇到的 $1$ 的个数（这些 $1$ 在将 $0$ 前移时会成为“障碍”）。
2. 对于每个字符：
   - 如果是 `'1'`，则 `cnt` 加 $1$。
   - 如果是 `'0'`，则判断当前剩余操作次数 $k$ 是否足够将它移动到所有已遇到 $1$ 的前面：
     - 若 $k \ge cnt$，说明可以将这个 $0$ 完全移动到这些 $1$ 之前。在答案末尾追加一个 `'0'`，消耗 $cnt$ 次操作（$k \leftarrow k - cnt$），`cnt` 保持不变（这些 $1$ 的相对顺序和个数不变，之后遇到的 $0$ 依然需要越过它们）。
     - 若 $k < cnt$，说明无法将该 $0$ 移到所有 $1$ 前面，只能向前移动 $k$ 个位置。此时答案中应依次追加：  
       ① $cnt - k$ 个 `'1'`（留在 $0$ 前面的部分 $1$），  
       ② 一个 `'0'`（本次处理的 $0$），  
       ③ $k$ 个 `'1'`（被 $0$ 越过并放在后面的部分 $1$）。  
       然后将原字符串剩余的未处理部分直接接在答案末尾，结束循环（因为 $k$ 已用完，无法再做任何前移）。
3. 若遍历完整个字符串后仍未触发 $k < cnt$ 的情况（即 $k$ 足够将所有 $0$ 移到最前），则将当前计数器 `cnt` 中剩余的 `'1'` 全部追加到答案末尾。

这种方法保证了每一步都是局部最优：遇到 $0$ 时总是尽可能将它前移，且用最少的次数让最靠前的 $0$ 出现在更优的位置，从而得到全局字典序最小的序列。

## 复杂度分析

- 时间复杂度：$O(n)$  
  每个字符至多被访问一次，构建答案字符串的操作也是线性的，不会存在嵌套循环导致复杂度退化。
- 空间复杂度：$O(n)$  
  需要额外的存储空间保存结果字符串，与输入规模成正比。

## 代码实现

### Python

```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
s = input().strip()

ans = []          # 用于构建结果字符串
cnt = 0           # 当前已经遇到的 '1' 的个数

for i, ch in enumerate(s):
    if ch == '1':
        cnt += 1
    else:  # ch == '0'
        if k >= cnt:
            # 能将这个 0 移到所有已遇到 1 的前面
            ans.append('0')
            k -= cnt
        else:
            # 只能向前移动 k 个位置
            # 先放 cnt - k 个 '1'，再放 '0'，再放 k 个 '1'
            ans.append('1' * (cnt - k))
            ans.append('0')
            ans.append('1' * k)
            # 剩余部分直接拼接并结束
            ans.append(s[i + 1:])
            cnt = 0   # 避免结束后重复添加
            break

# 如果循环正常结束，则将所有剩余的 '1' 补到末尾
if cnt > 0:
    ans.append('1' * cnt)

print(''.join(ans))
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int k = sc.nextInt();
        String s = sc.next();

        StringBuilder ans = new StringBuilder();
        int cnt = 0; // 当前遇到的 '1' 的个数

        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);
            if (ch == '1') {
                cnt++;
            } else { // ch == '0'
                if (k >= cnt) {
                    // 能将这个 '0' 移到所有已遇到 '1' 的前面
                    ans.append('0');
                    k -= cnt;
                } else {
                    // 只能向前移动 k 位
                    // 追加 cnt - k 个 '1'
                    ans.append("1".repeat(cnt - k));
                    // 追加 '0'
                    ans.append('0');
                    // 追加 k 个 '1'
                    ans.append("1".repeat(k));
                    // 剩余部分直接拼入并结束
                    ans.append(s.substring(i + 1));
                    cnt = 0; // 防止后面重复添加
                    break;
                }
            }
        }

        // 补上末尾剩余的 '1'
        if (cnt > 0) {
            ans.append("1".repeat(cnt));
        }

        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    string s;
    cin >> n >> k >> s;

    string ans;
    int cnt = 0; // 当前遇到的 '1' 的个数

    for (int i = 0; i < n; ++i) {
        if (s[i] == '1') {
            ++cnt;
        } else { // s[i] == '0'
            if (k >= cnt) {
                // 能将这个 '0' 移到所有已遇到 '1' 的前面
                ans.push_back('0');
                k -= cnt;
            } else {
                // 只能向前移动 k 位
                // 追加 cnt - k 个 '1'
                ans.append(cnt - k, '1');
                // 追加 '0'
                ans.push_back('0');
                // 追加 k 个 '1'
                ans.append(k, '1');
                // 剩余部分直接拼接并结束
                ans += s.substr(i + 1);
                cnt = 0; // 防止结束后重复添加
                break;
            }
        }
    }

    // 补上末尾剩余的 '1'
    if (cnt > 0) {
        ans.append(cnt, '1');
    }

    cout << ans << "\n";
    return 0;
}
```
