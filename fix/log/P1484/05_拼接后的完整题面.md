# 题目内容
有 $n$ 个排成一行的格子，每个格子里有一个数字，只能是 $0$ 或 $1$。
一次操作可以选择两个相邻的格子，交换它们中的数字。你最多可以进行 $k$ 次操作。
我们希望最终得到的数字序列在如下规则下尽可能小：从左到右依次比较每一个格子里的数字，一旦发现不同，数字为 $0$ 的序列更小；如果所有格子都相同，则两个序列相等。
请你求出经过不超过 $k$ 次操作后，能得到的满足上述规则的最优序列。

约束：$n \le 10^5$，$k \le 10^9$。

# 输入描述
第一行包含两个整数 $n$ 和 $k$，分别表示格子的数量与允许的最多操作次数。
第二行包含一个长度为 $n$ 的字符串，由字符 $0$ 和 $1$ 构成，表示初始每个格子中的数字。

# 输出描述
输出一个长度为 $n$ 的字符串，表示经过最多 $k$ 次操作后能得到的最优序列。

## 样例1

**输入**

```
5 2
10100
```

**输出**

```
01010
```

**说明**

初始序列为 `10100`，允许操作次数 $k=2$。

- 首先将位置 `1` 的 `1` 与位置 `2` 的 `0` 交换，消耗 `1` 次操作，序列变为 `01100`，剩余 $k=1$。
- 当前序列最靠前的 `1` 在位置 `2`，之后最近的 `0` 位于位置 `4`，距离为 `2`，大于剩余次数。将该 `0` 向左移动 `1` 步（交换位置 `3` 与位置 `4`），得到序列 `01010`。

总共使用 `2` 次操作，得到字典序最小的序列 `01010`。

## 样例2

**输入**

```
4 0
1101
```

**输出**

```
1101
```

**说明**

允许操作次数 $k=0$，无法进行任何交换，因此序列保持初始状态 `1101`。

## 样例3

**输入**

```
6 10
111000
```

**输出**

```
000111
```

**说明**

初始序列为 `111000`，$k=10$。将所有 `0` 移到前排需要让每个 `0` 跨过前面所有的 `1`。序列中有 `3` 个 `1`，每个 `0` 需交换 `3` 次，总共 $3 \times 3 = 9$ 次，$9 \le 10$。因此可以使用 `9` 次操作将序列完全排序，得到最小序列 `000111`。
