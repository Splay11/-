# 题目内容
一位设计师有一张矩形画布，左下角坐标为 $(0,0)$，右上角坐标为 $(C,R)$，其中 $R$ 表示高度，$C$ 表示宽度。
他计划用若干条斜向的裁剪线将画布划分成多个独立区域。出于美学考虑，所有裁剪线必须与坐标轴成 $45^\circ$ 角，即斜率只能为 $1$ 或 $-1$。
设计师在画布上画了 $M$ 条参考线。每条参考线通过两个不同的整数坐标点 $(x_1,y_1)$ 和 $(x_2,y_2)$ 给出，表示裁剪线所在的直线。如果多条参考线对应完全相同的直线，则仅视为一条裁剪线。
现在，请你计算出按照这些裁剪线切割后，画布被分割成了多少个互不连通的区域。

约束条件：
- 高度 $R$ 和宽度 $C$ 均为不超过 $500$ 的正整数。
- 参考线数量 $M$ 不超过 $1000$。
- 所有坐标点满足 $0 \le x_1, x_2 \le C$，$0 \le y_1, y_2 \le R$，且 $(x_1,y_1) 
eq (x_2,y_2)$。

# 输入描述
第一行包含两个整数 $R$ 和 $C$，分别表示画布的高度和宽度。
第二行包含一个整数 $M$，表示参考线的条数。
接下来的 $M$ 行，每行包含四个整数 $x_1, y_1, x_2, y_2$，依次表示一条参考线的两个端点坐标。

# 输出描述
输出一个整数，表示切割后得到的独立区域数量。

## 样例1

**输入**

```
1 1
0
```

**输出**

```
1
```

**说明**

画布尺寸为高度 $R=1$，宽度 $C=1$。没有裁剪线，整个画布为一个连通区域，故输出 `1`。

## 样例2

**输入**

```
3 3
1
0 0 3 3
```

**输出**

```
2
```

**说明**

矩形尺寸 $3 \times 3$，裁剪线从 $(0,0)$ 到 $(3,3)$，斜率为 $1$。
该直线将矩形沿对角线分割成两个三角形区域。
根据公式，区域总数 = 斜率 $1$ 的直线数 + $1 = 2$，因此输出 `2`。

## 样例3

**输入**

```
2 2
2
0 0 2 2
0 2 2 0
```

**输出**

```
4
```

**说明**

矩形宽 $C=2$，高 $R=2$。
两条裁剪线分别为斜率为 $1$ 的直线 $y=x$ 和斜率为 $-1$ 的直线 $y=-x+2$。
它们相交于点 $(1,1)$，位于矩形内部。
由平面分割公式：区域数 = 斜率 $1$ 的直线数 + 斜率 $-1$ 的直线数 + $1$ + 内部交点数 = $1 + 1 + 1 + 1 = 4$。
因此输出 `4`。

## 样例4

**输入**

```
5 5
2
0 2 3 5
0 2 2 0
```

**输出**

```
3
```

**说明**

矩形高 $R=5$，宽 $C=5$。
第一条裁剪线为 $y = x + 2$，从 $(0,2)$ 到 $(3,5)$；第二条裁剪线为 $y = -x + 2$，从 $(0,2)$ 到 $(2,0)$。
两者的交点为 $(0,2)$，位于矩形左边界上（$x=0$），不属于严格内部，因此不产生额外的区域分割。
区域总数 = $1 + 1 + 1 + 0 = 3$。具体分割：第一条线将矩形分为两块，第二条线将其中的一块再分为两块，总共 `3` 个区域。
