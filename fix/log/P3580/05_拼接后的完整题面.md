# 题目内容
货架上从左到右摆放着 $n$ 件货物，第 $i$ 件的库存量为 $a_i$。有 $q$ 次相互独立的预案，每次给出区间 $[l, r]$ 与整数 $k$。

在该预案中，把下标 $l$ 到 $r$ 的库存改写成交替序列：对所有 $j \in [l, r]$，若 $j-l$ 为偶数，则令库存为 $k$；若 $j-l$ 为奇数，则令库存为 $k+1$。其余位置保持原值。

所有预案均基于原始库存独立判断。请回答改写后整排货物库存之和是否为奇数。

约束：测试组数不超过 `10^4`，单组 $n$ 与 $q$ 均不超过 `2×10^5`，库存量不超过 `10^9`，且单个测试文件中 $n$ 之和、$q$ 之和均不超过 `2×10^5`。

# 输入描述
每个测试文件包含多组数据。第一行一个整数 $t$，表示测试组数。
每组数据格式如下：
第一行两个整数 $n$、$q$，分别表示货物件数与预案次数；
第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$，表示原始库存；
接下来 $q$ 行，每行三个整数 $l$、$r$、$k$，表示一次预案。
保证 $1 \le t \le 10^4$，$1 \le n, q \le 2 \times 10^5$，$1 \le a_i \le 10^9$，$1 \le l \le r \le n$，$0 \le k \le 10^9$，且单个文件中 $n$ 之和与 $q$ 之和均不超过 $2 \times 10^5$。

# 输出描述
对每次预案输出一行。若改写后库存总和为奇数，输出 `YES`；否则输出 `NO`。

## 样例1

**输入**

```
2
5 4
1 2 3 4 5
1 3 2
2 5 1
1 5 10
3 3 0
3 3
1 1 1
1 3 0
2 2 5
1 1 2
```

**输出**

```
NO
YES
NO
NO
YES
YES
NO
```

**说明**

第一组原始库存为 $1,2,3,4,5$，总和为 `15`（奇数）。
预案 $(1,3,2)$ 把前三段改成 $2,3,2$，全局和变为偶数，输出 `NO`。
预案 $(2,5,1)$ 把后四段改成 $1,2,1,2$，全局和为奇数，输出 `YES`。其余预案同理。
第二组三次预案分别得到 `YES`、`YES`、`NO`。

## 样例2

**输入**

```
1
1 2
7
1 1 0
1 1 1
```

**输出**

```
NO
YES
```

**说明**

只有一件货物，库存为 `7`（奇数）。
第一次把该位置改成 $k=0$，和为偶数，输出 `NO`。
第二次改成 $k=1$，和为奇数，输出 `YES`。这是 $n=1$ 的边界。

## 样例3

**输入**

```
1
4 1
1 1 1 1
2 3 8
```

**输出**

```
YES
```

**说明**

原始总和为 `4`（偶数）。区间 $[2,3]$ 长度为 `2`，改写成 $8,9$，原区间和为 `2`，新区间和为 `17`，全局和变为 $4-2+17=19$（奇数），输出 `YES`。
