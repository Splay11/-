# 题目内容
存储模块用游程编码保存一条整型占用序列：记号 $v(c)$ 表示值 $v$ 连续出现 $c$ 次，整段写成 $[v_1(c_1),v_2(c_2),\ldots]$ 的形式。历史压缩可能不彻底，相邻两段的值仍可能相同，导致目录占用统计被拆成多段。需要把相邻且值相同的段合并，次数相加，再输出同样格式的编码。

输入可能已经部分压缩，也可能夹杂尚未合并的同值邻段。请完成合并。

约束：输入字符串长度不超过 `100000`，每个值满足 $-1000000000 \le v \le 1000000000$。

# 输入描述
一行一个字符串，表示待合并的游程编码数组，格式为 $[v(c),\ldots]$。

# 输出描述
输出合并后的游程编码数组，格式相同。

## 样例1

**输入**

```
[2(1),2(4),3(1)]
```

**输出**

```
[2(5),3(1)]
```

**说明**

按题意模拟计算得到。
