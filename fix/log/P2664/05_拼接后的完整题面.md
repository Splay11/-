# 题目内容
小 A 有一本笔记本，总共有 $n$ 个页码，依次编号为 $1$ 到 $n$。他常常在两个页码之间添加互相参见的标记，使得它们可以直接跳转。每次添加标记都是双向的：即如果页码 $u$ 和 $v$ 互相参见，那么从 $u$ 可以直接查阅 $v$，反之亦然；重复的标记不会生效。

现在你需要设计一个程序，支持以下两种操作：

1. 添加标记：指定两个页码 $u$ 和 $v$，在它们之间建立互相参见的关系。如果此前已经存在该关系，则忽略。
2. 查询参见：给定页码 $u$ 和一个正整数 $k$，请找出所有与 $u$ 直接参见的页码中，编号第 $k$ 大的页码。若直接参见的页码数量不足 $k$，则返回 $-1$。

约束：页码总数 $n$ 和操作总数 $q$ 均满足 $1 \le n, q \le 10^5$；$k \le 10$；所有页码编号均为 $1$ 到 $n$ 的整数。

# 输入描述
第一行包含两个整数 $n$ 和 $q$。接下来的 $q$ 行，每行表示一个操作。每行第一个整数为操作类型：若为 $1$，则后跟两个整数 $u$ 和 $v$，表示在页码 $u$ 和 $v$ 之间添加互相参见标记；若为 $2$，则后跟两个整数 $u$ 和 $k$，表示查询页码 $u$ 直接参见的页码中，编号第 $k$ 大的页码。

# 输出描述
对于每个类型为 $2$ 的查询操作，输出一行一个整数，表示答案。如果满足条件的页码不存在，则输出 $-1$。

## 样例1

**输入**

```
4 6
1 1 2
1 1 3
1 1 4
2 1 1
2 1 3
2 1 5
```

**输出**

```
4
2
-1
```

**说明**

首先通过 `3` 次操作在页码 `1` 与 `2`、`3`、`4` 之间添加互相参见标记。页码 `1` 的直接参见集合为 $\{2,3,4\}$，按编号降序排列为 $4, 3, 2$。

第 `1` 次查询 $u=1, k=1$：第 $1$ 大的邻居为 `4`。
第 `2` 次查询 $u=1, k=3$：第 $3$ 大的邻居为 `2`。
第 `3` 次查询 $u=1, k=5$：邻居总数只有 $3$，不足 $5$ 个，故输出 $-1$。

## 样例2

**输入**

```
2 5
1 1 2
1 1 2
2 1 1
2 1 2
2 1 3
```

**输出**

```
2
-1
-1
```

**说明**

第 `1` 次操作添加了页码 `1` 与 `2` 之间的标记；第 `2` 次操作试图重复添加同一对标记，按规则被忽略。因此页码 `1` 的直接参见集合仅包含 `2`，降序排列为 $2$。

查询 $u=1, k=1$ 时第 $1$ 大的邻居是 `2`；查询 $k=2$ 和 $k=3$ 时均因邻居数量不足而返回 $-1$。

## 样例3

**输入**

```
5 7
1 3 5
1 3 1
1 3 4
1 3 2
2 3 2
2 3 4
2 3 5
```

**输出**

```
4
1
-1
```

**说明**

经过 `4` 次添加操作，页码 `3` 拥有了邻居 $\{1,2,4,5\}$，按降序排列为 $5, 4, 2, 1$。

第 `1` 次查询 $u=3, k=2$：第 $2$ 大的页码是 `4`。
第 `2` 次查询 $u=3, k=4$：第 $4$ 大的页码是 `1`。
第 `3` 次查询 $u=3, k=5$：共有 $4$ 个邻居，不存在第 $5$ 大，输出 $-1$。

## 样例4

**输入**

```
1 1
2 1 1
```

**输出**

```
-1
```

**说明**

只有 `1` 个页码且没有任何添加标记的操作。查询页码 `1` 直接参见的页码时，集合为空，任意的 $k\ge 1$ 都无法满足，因此输出 $-1$。这是一个边界情况，用于测试空邻居时的行为。
