# 题目内容
一条航道上的货船初始最高航速为 $v_0$。出发前可以在泊位预热 $t$ 个时间单位，预热后最高航速变为 $v_0+t\times x$，航行途中速度保持不变。需要行驶总里程 $y$，航行时间等于里程除以当时最高航速。总耗时为预热时间加航行时间。

$t$ 可以是任意非负实数。请计算完成航行的最小总耗时。

约束：$0 \le v_0 \le 1000000000$，$1 \le x,y \le 1000000000$。

# 输入描述
一行三个整数 $v_0$ $x$ $y$，用空格隔开。

# 输出描述
输出一个浮点数，保留五位小数，表示最小总耗时。

## 样例1

**输入**

```
2 4 8
```

**输出**

```
2.32843
```
