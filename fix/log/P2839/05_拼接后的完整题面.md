# 题目内容
给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。你可以执行任意次以下操作：选择一个位置 $i$ ($1 \le i < n$)，将 $a_i$ 和 $a_{i+1}$ 的值同时增加 `1`。

经过操作后的序列若满足对任意 $1 \le i \le n$ 均有 $b_i = b_{n+1-i}$，则称其为镜像序列。

请你判断能否使序列变为镜像序列，若能，请输出一个总操作次数最小的方案；否则输出 $-1$。

数据范围：序列长度 $n$ 不超过 `10^5`。序列中的元素均为正整数，且不超过 `10^9`。

# 输入描述
第一行包含一个正整数 $n$，表示序列的长度。
第二行包含 $n$ 个整数，表示初始序列 $a_1, a_2, \dots, a_n$。

# 输出描述
若无法变为镜像序列，输出一行 $-1$。
否则，第一行输出一个整数 $m$ 表示操作的条数，满足 $0 \le m \le n$。接下来 $m$ 行，每行输出两个整数 $i$ 和 $x$，表示对第 $i$ 和第 $i+1$ 个元素执行 $x$ 次增加 `1` 的操作。要求 $x > 0$ 且总操作次数 $\sum x$ 最小。若有多组合法解，输出任意一组即可。

## 样例1

**输入**

```
3
2 2 4
```

**输出**

```
1
1 2
```

**说明**

初始序列为 `[2, 2, 4]`。目标为使序列变为镜像（回文）。对称位置为 $a_1$ 和 $a_3$。
$a_1=2$，$a_3=4$，需使它们相等。操作位置 $1$ 会同时增加 $a_1$ 与 $a_2$；操作位置 $2$ 会增加 $a_2$ 与 $a_3$。
为最小化操作次数，直接对位置 $1$ 执行 $4-2=2$ 次操作，序列变为 `[4, 4, 4]`，满足镜像条件，总操作次数 $2$。
因此输出 $1$ 条操作，内容为位置 $1$ 操作 $2$ 次。

## 样例2

**输入**

```
4
1 5 3 3
```

**输出**

```
-1
```

**说明**

序列长度为 $4$，元素为 `[1, 5, 3, 3]`。设对位置 $1,2,3$ 的操作次数分别为 $x_1, x_2, x_3$。
最终序列为：
$b_1 = 1 + x_1$
$b_2 = 5 + x_1 + x_2$
$b_3 = 3 + x_2 + x_3$
$b_4 = 3 + x_3$
要求 $b_1 = b_4$ 得 $1 + x_1 = 3 + x_3$，即 $x_1 - x_3 = 2$。
要求 $b_2 = b_3$ 得 $5 + x_1 + x_2 = 3 + x_2 + x_3$，即 $x_1 - x_3 = -2$。
两方程矛盾，故不存在合法的操作方案，输出 $-1$。

## 样例3

**输入**

```
1
10
```

**输出**

```
0
```

**说明**

序列长度为 $1$，仅含元素 `10`。单个元素的序列天然满足镜像条件（$b_1 = b_1$），无需任何操作。最小总操作次数为 $0$，因此输出 $0$（其后不跟任何操作行）。
