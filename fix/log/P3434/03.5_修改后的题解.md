## 解题思路

- 按位或运算有一个关键性质：随着区间长度增加，按位或的值只会单调增加（二进制位只会被置为 1，不会被清为 0）。因此，对于固定的右端点 $r$，以 $r$ 结尾的所有子区间的融合值（按位或结果）的种类数是非常有限的。由于序列中的整数不超过 $10^9$，二进制位数最多约 30 位，所以以某一个位置为右端点时，不同的融合值数量至多为 $O(\log M)$，其中 $M$ 是序列元素的最大可能值。
- 基于上述观察，我们可以从左到右扫描序列。对于每个位置 $i$，维护一个集合 `cur`，存放所有以 $i$ 结尾的子区间的融合值。
- 递推过程：
  1. 当从位置 $i-1$ 移动到 $i$ 时，新的 `cur` 由两部分组成：  
     - 仅包含 $b_i$ 自身的值（即区间 $[i, i]$ 的融合值）；  
     - 将前一个位置的集合 `prev` 中的每一个值 $v$ 与 $b_i$ 做按位或，得到 $v \mid b_i$（相当于把以前缀结尾的区间延伸到 $i$）。
  2. 将 `cur` 中的所有值添加到一个全局集合 `all_values`，用于去重统计。
- 处理完所有位置后，全局集合 `all_values` 的大小就是所有不同融合值的个数。

## 复杂度分析

- 时间复杂度：对于每个位置 $i$，其 `cur` 集合的大小不超过 $O(\log M) \approx 30$，因此每一步的更新和合并操作都是 $O(\log M)$ 的。总共有 $n$ 个位置，所以整体时间复杂度为 $O(n \log M)$，这里 $M = 10^9$。对于 $n \le 10^5$ 的数据完全可行。
- 空间复杂度：过程中需要存储 `prev`、`cur` 以及全局 `all_values`。`prev` 和 `cur` 的大小始终为 $O(\log M)$。全局集合 `all_values` 在最坏情况下可能包含 $O(n \log M)$ 个不同值，因此空间复杂度为 $O(n \log M)$，可以接受。

## 代码实现

### Python

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    b = [int(next(it)) for _ in range(n)]

    prev = set()
    all_values = set()

    for x in b:
        cur = {x}                     # 区间 [i, i]
        for v in prev:
            cur.add(v | x)            # 将之前的区间延伸到当前位置
        all_values |= cur             # 并入全局集合
        prev = cur                    # 更新，准备处理下一个位置

    print(len(all_values))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());
        int[] b = new int[n];
        StringTokenizer st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            b[i] = Integer.parseInt(st.nextToken());
        }

        Set<Integer> prev = new HashSet<>();
        Set<Integer> allValues = new HashSet<>();

        for (int x : b) {
            Set<Integer> cur = new HashSet<>();
            cur.add(x);                     // 区间 [i, i]
            for (int v : prev) {
                cur.add(v | x);             // 延伸区间
            }
            allValues.addAll(cur);          // 存入全局结果
            prev = cur;                     // 为下一个位置做准备
        }

        System.out.println(allValues.size());
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> b(n);
    for (int i = 0; i < n; ++i) {
        cin >> b[i];
    }

    unordered_set<int> prev, cur, all_values;
    prev.reserve(64);
    cur.reserve(64);
    all_values.reserve(min<long long>(1e6, 1LL * n * 32));

    for (int x : b) {
        cur.clear();
        cur.insert(x);                     // 区间 [i, i]
        for (int v : prev) {
            cur.insert(v | x);             // 延伸之前的区间
        }
        for (int v : cur) {
            all_values.insert(v);          // 并入全局集合
        }
        prev = cur;                        // 递推
    }

    cout << all_values.size() << "\n";
    return 0;
}
```
