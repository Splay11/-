# 题目内容
小蓝有一个长度为 $n$ 的整数序列 $b_1, b_2, \dots, b_n$。对于任意区间 $[l, r]$（$1 \le l \le r \le n$），定义其融合值为区间内所有整数的按位或运算结果。序列共有 $n(n+1)/2$ 个不同的区间，请计算所有这些区间对应的融合值中，不同的取值有多少个。

序列的长度 $n$ 不超过 $10^5$，序列中的每个元素均为正整数且不超过 $10^9$。

# 输入描述
第一行包含一个整数 $n$（$1 \le n \le 10^5$），表示序列的长度。
第二行包含 $n$ 个整数 $b_1, b_2, \dots, b_n$（$1 \le b_i \le 10^9$），表示给定序列。

# 输出描述
输出一个整数，表示不同融合值的个数。

## 样例1

**输入**

```
1
5
```

**输出**

```
1
```

**说明**

序列只有 `1` 个元素，区间只有 $[1,1]$，融合值为 `5`，不同取值个数为 `1`。

## 样例2

**输入**

```
2
1 1
```

**输出**

```
1
```

**说明**

共有 `3` 个区间：$[1,1]$ 融合值为 `1`；$[2,2]$ 融合值为 `1`；$[1,2]$ 融合值为 $1 \mid 1 = 1$。所有融合值均为 `1`，不同取值个数为 `1`。

## 样例3

**输入**

```
4
2 4 8 16
```

**输出**

```
10
```

**说明**

序列中的元素 $2, 4, 8, 16$ 均为 $2$ 的幂次，且二进制位互不重叠，因此任意区间的按位或结果等价于区间内元素的和，且这些和值两两不同。区间总数为 $4 \times 5 / 2 = 10$，故不同融合值个数为 `10`。
