# 题目内容
一条检测线上依次安装了 $n$ 个传感器，第 $i$ 个传感器的读数为 $h_i$。一段连续安装的传感器构成一个检测段。长度为 $x$ 的检测段，是指任意 $x$ 个相邻传感器组成的区间；该检测段的瓶颈值定义为区间内所有读数的最小值。

对于每一个长度 $x$（$1 \le x \le n$），考虑所有长度为 $x$ 的检测段，求出这些检测段瓶颈值中的最大值。

约束：传感器个数 $n$ 不超过 `100000`，且至少为 `1`。每个读数 $h_i$ 为正整数，且不超过 `10^9`。

# 输入描述
第一行输入一个正整数 $n$，表示传感器的个数，满足 $1 \le n \le 100000$。
第二行输入 $n$ 个整数 $h_1, h_2, \ldots, h_n$，依次表示每个传感器的读数，满足 $1 \le h_i \le 10^9$。

# 输出描述
输出一行 $n$ 个整数，第 $x$ 个数表示长度为 $x$ 的所有检测段中瓶颈值的最大值。

## 样例1

**输入**

```
1
4 5 3 1 3 4
```

**输出**

```
4
```

**说明**

按题意模拟计算得到。
