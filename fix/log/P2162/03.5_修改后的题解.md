## 解题思路

每次出库都会让剩余件数至少减半量级，操作次数约为 $O(\log n)$。$n$ 最大为 `1000000000000`，对当前值做一次素性判断需要 $O(\sqrt n)$，随着 $n$ 迅速变小，总复杂度可以接受。

模拟即可：

- 若当前 $n$ 是素数，令 $n \leftarrow n-(\lfloor n/3\rfloor+1)$；
- 否则令 $n \leftarrow n-(\lfloor n/2\rfloor+1)$；
- 直到 $n=0$，天数加一计数。

`1` 及以下不是素数。

## 复杂度分析

时间复杂度 $O(\sqrt n\log n)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
import math

def is_prime(n):
    if n <= 1:
        return False
    for i in range(2, int(math.sqrt(n)) + 1):
        if n % i == 0:
            return False
    return True

n = int(input())
days = 0
while n > 0:
    days += 1
    if is_prime(n):
        n -= (n // 3 + 1)
    else:
        n -= (n // 2 + 1)
print(days)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static boolean isPrime(long n) {
        if (n <= 1) {
            return false;
        }
        for (long i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                return false;
            }
        }
        return true;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        long n = scanner.nextLong();
        int days = 0;
        while (n > 0) {
            days++;
            if (isPrime(n)) {
                n -= (n / 3 + 1);
            } else {
                n -= (n / 2 + 1);
            }
        }
        System.out.println(days);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

bool isPrime(long long n) {
    if (n <= 1) {
        return false;
    }
    for (long long i = 2; i * i <= n; ++i) {
        if (n % i == 0) {
            return false;
        }
    }
    return true;
}

int main() {
    long long n;
    cin >> n;
    int ans = 0;
    while (n > 0) {
        ans += 1;
        if (isPrime(n)) {
            n = n - (n / 3 + 1);
        } else {
            n = n - (n / 2 + 1);
        }
    }
    cout << ans << '\n';
    return 0;
}
```
