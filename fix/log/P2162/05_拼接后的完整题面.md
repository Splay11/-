# 题目内容
市立药库按日清点并出库。仓管规程规定：若当天开始时剩余件数 $n$ 是素数，则当天出库 $\lfloor n/3 \rfloor + 1$ 件；否则当天出库 $\lfloor n/2 \rfloor + 1$ 件。每天只执行一轮，直到一件不剩为止。请计算把库存全部出完一共需要多少天。这里 $\lfloor x \rfloor$ 表示对 $x$ 向下取整。

约束：$1 \le n \le 1000000000000$。

# 输入描述
输入一个整数 $n$，表示初始库存件数。
保证 $1 \le n \le 1000000000000$。

# 输出描述
输出一个整数，表示把库存全部出库完所需的天数。

## 样例1

**输入**

```
1
```

**输出**

```
1
```

**说明**

`1` 不是素数，当天消耗 $\lfloor 1/2 \rfloor + 1 = 1$ 件，一天结束。

## 样例2

**输入**

```
7
```

**输出**

```
3
```

**说明**

过程如下：

- `7` 是素数，消耗 $\lfloor 7/3 \rfloor + 1 = 3$，剩余 `4`；
- `4` 不是素数，消耗 `3`，剩余 `1`；
- `1` 不是素数，消耗 `1`。

共 `3` 天。

## 样例3

**输入**

```
15
```

**输出**

```
4
```

**说明**

`15` 不是素数，消耗 `8` 后剩余 `7`，此后与样例 `2` 相同再需 `3` 天，合计 `4` 天。
