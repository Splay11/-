# 题目内容
在一款古老的消除游戏中，有 $n$ 个宝石排成一行，宝石只有两种类型，且任意相邻两颗宝石的类型都不相同。宝石依次编号为 $1$ 到 $n$。

在两颗相邻宝石 $i$ 和 $i+1$ 之间，存在一个隐藏的奖励数值 $b_i$ ($1 \le i \le n-1$)。当你选择一对相邻宝石并消除它们时，你将获得对应的奖励 $b_i$。消除后，剩余的宝石保持原有相对顺序重新拼接在一起。由于任意相邻宝石类型都不同，因此每次选择任意一对相邻宝石都是合法的。

奖励数组 $b$ 的长度固定为 $n-1$，且**不会因为消除操作而改变**。也就是说，即使在消除操作之后，当你选择当前序列中第 $i$ 颗和第 $i+1$ 颗宝石时，你获得的奖励依然是初始数组中 $b_i$ 的值（奖励值与其在原始序列中的位置绑定，直到该位置不再存在）。

你可以不断进行消除操作，直到无法继续（剩余宝石数量不超过 $1$）。设你总共进行了 $m$ 次消除，获得的奖励之和为 $S$。现在，请你分别求出在所有可行的消除方案中，$S$ 可能取得的最大值以及最小值。

**数据范围与约束**
- 测试数据组数 $T$ 满足 $1 \le T \le 10^4$。
- 每组数据的宝石数量 $n$ 满足 $2 \le n \le 2 \times 10^5$。
- 奖励数组 $b$ 的长度为 $n-1$，每个奖励值均为整数，满足 $1 \le b_i \le 10^9$。
- 单个测试文件中所有测试数据的 $n$ 之和不超过 $2 \times 10^5$。

# 输入描述
第一行输入一个整数 $T$，表示测试数据组数。

接下来对于每组数据：
第一行输入一个整数 $n$，表示初始宝石的个数。
第二行输入 $n-1$ 个整数 $b_1, b_2, \dots, b_{n-1}$，依次表示每对相邻宝石之间对应的奖励值，相邻整数之间以空格分隔。

# 输出描述
对于每组测试数据，新起一行，输出两个整数，第一个整数表示能够获得的总奖励的最大值，第二个整数表示能够获得的总奖励的最小值，两者之间用一个空格隔开。

## 样例1

**输入**

```
1
2
100
```

**输出**

```
100 100
```

**说明**

只有两颗宝石，只能进行一次消除。无论消除哪一对相邻宝石，获得的奖励都是固定的 $b_1 = 100$。因此总奖励的最大值和最小值均为 `100`。

## 样例2

**输入**

```
1
3
5 2
```

**输出**

```
5 2
```

**说明**

初始有 $3$ 颗宝石，进行一次消除后剩下 $1$ 颗，故只能消除一次。可以选择消除第 $1$ 对（获得奖励 $5$），或消除第 $2$ 对（获得奖励 $2$）。因此最大总奖励为 `5`，最小总奖励为 `2`。

## 样例3

**输入**

```
1
4
3 1 4
```

**输出**

```
7 4
```

**说明**

共 $4$ 颗宝石，需要进行 $2$ 次消除。
第一步可选的奖励为 $b_1 = 3, b_2 = 1, b_3 = 4$；第二步剩余可选范围缩小至 $b_1 = 3$。
为最大化总和：第一步取最大值 $4$，第二步取 $3$，总和为 $7$。
为最小化总和：第一步取最小值 $1$，第二步取 $3$，总和为 $4$。

## 样例4

**输入**

```
1
5
10 20 5 30
```

**输出**

```
50 15
```

**说明**

共 $5$ 颗宝石，消除次数为 $\lfloor 5/2 \rfloor = 2$。
第一步可选的奖励为 $b_1=10, b_2=20, b_3=5, b_4=30$，前缀最大值为 $30$，最小值为 $5$。
第二步可选范围缩减为 $b_1=10, b_2=20$，前缀最大值为 $20$，最小值为 $10$。
因此最大总奖励为 $30+20=50$，最小总奖励为 $5+10=15$。
