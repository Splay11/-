# 题目内容
电竞赛事有 $n=2^k$ 支战队，能力值由数组 $s$ 给出，按初始签位编号 `1` 到 $n$。你是 `1` 号种子。赛制为单败淘汰：每一轮按当前顺序相邻两队对决 $(1,2),(3,4),\ldots$，能力值较高者胜出并保持相对顺序进入下一轮，直到只剩一支战队。能力值两两不同。请计算你在整场比赛中赢下的场次；若首轮即被淘汰则为 `0`。当 $n=1$ 时无需比赛，胜场为 `0`。

约束：测试组数不超过 `100000`；每组 $n$ 是 `2` 的整次幂且不超过 `100000`；所有测试中 $n$ 之和不超过 `200000`；能力值两两不同且满足 $0 \le s_i \le 100000$。

# 输入描述
第一行一个整数 $T$，表示测试组数。
每组数据：第一行整数 $n$；第二行 $n$ 个两两不同的整数 $s_1,s_2,\ldots,s_n$。
保证 $1 \le T \le 100000$，$1 \le n \le 100000$ 且 $n$ 是 `2` 的整次幂，$0 \le s_i \le 100000$，所有测试中 $n$ 之和不超过 `200000`。

# 输出描述
对每组数据输出一行一个整数，表示 `1` 号种子的胜场数。

## 样例1

**输入**

```
3
1
9
2
8 3
8
9 1 2 4 3 0 5 6
```

**输出**

```
0
1
3
```

**说明**

$n=`1`$ 无需比赛，胜场 `0`；$n=`2`$ 且 `8>3`，胜 `1` 场；$n=`8`$ 时 `9` 大于前缀区间最大值，连胜 `3` 场。

## 样例2

**输入**

```
2
4
1 10 2 3
4
20 4 5 6
```

**输出**

```
0
2
```

**说明**

第一组 `1` 首轮不敌 `10`，胜场 `0`；第二组 `20` 大于区间内其余值，连胜 `2` 场。
