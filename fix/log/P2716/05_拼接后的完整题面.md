# 题目内容
在基因组数据库中，需要快速判断查询序列是否与参考序列的特定片段匹配。给定一个参考字符串 $R$，以及一个匹配长度限制 $L$（$1 \le L \le 10$）。现有 $m$ 次询问，每次提供一个查询字符串 $Q$。对于每个 $Q$，如果其开头长度为 $L$ 的连续子串或者结尾长度为 $L$ 的连续子串（仅当 $|Q| \ge L$ 时存在）在 $R$ 中出现过，则认为 $Q$ 满足条件；否则不满足。

数据范围：参考字符串 $R$ 的长度不超过 $10^5$，询问次数 $m$ 不超过 $10^5$，所有查询字符串 $Q$ 的总长度之和不超过 $10^5$。所有字符串均由小写字母组成。

# 输入描述
第一行包含一个由小写字母组成的字符串 $R$。
第二行包含两个正整数 $m$ 和 $L$，分别表示询问次数和匹配长度限制。
接下来 $m$ 行，每行包含一个由小写字母组成的字符串 $Q$，表示一次询问。

# 输出描述
输出共 $m$ 行。对于每个询问，如果 $Q$ 满足条件则输出 `YES`，否则输出 `NO`。

## 样例1

**输入**

```
abacaba
3 2
aba
cab
a
```

**输出**

```
YES
YES
NO
```

**说明**

参考字符串 $R = \text{abacaba}$，长度限制 $L = 2$。
预处理得到 $R$ 中所有长度为 `2` 的子串集合：$\{\text{ab}, \text{ba}, \text{ac}, \text{ca}\}$（已去重）。

- 第 `1` 次询问：$Q = \text{aba}$，长度 $|Q| = 3 \ge 2$，前缀 $\text{ab}$ 出现在集合中，输出 `YES`。
- 第 `2` 次询问：$Q = \text{cab}$，长度满足要求，前缀 $\text{ca}$ 在集合中，输出 `YES`。
- 第 `3` 次询问：$Q = \text{a}$，长度 `1` 小于 $L$，无法构成有效的前缀或后缀，直接输出 `NO`。

## 样例2

**输入**

```
z
3 1
a
z
zz
```

**输出**

```
NO
YES
YES
```

**说明**

$R = \text{z}$，$L = 1$，这是允许的最小长度限制。
$R$ 中唯一的长度为 `1` 的子串为 $\text{z}$。

- 询问 `a`：长度 $1 \ge 1$，前缀 `a` 和后缀 `a` 均不在子串集合中，输出 `NO`。
- 询问 `z`：前缀 `z` 在集合中，输出 `YES`。
- 询问 `zz`：长度 $2 \ge 1$，前缀 `z` 和后缀 `z` 均在集合中，因此输出 `YES`。

## 样例3

**输入**

```
abcdef
3 3
xyzdef
abc
a
```

**输出**

```
YES
YES
NO
```

**说明**

$R = \text{abcdef}$，$L = 3$。
$R$ 的长度为 `3` 的子串集合为 $\{\text{abc}, \text{bcd}, \text{cde}, \text{def}\}$。

- 询问 `xyzdef`：长度 $6 \ge 3$，前缀 `xyz` 不在集合中，但后缀 `def` 出现在集合中，输出 `YES`。
- 询问 `abc`：长度 $3 \ge 3$，前缀 `abc`（也是后缀）在集合中，输出 `YES`。
- 询问 `a`：长度 `1` 小于 $L$，直接输出 `NO`。
