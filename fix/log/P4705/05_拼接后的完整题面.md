# 题目内容
智能仓库要把货位编号逐步校准到与通道容量 $b$ 相容的状态。当前货位编号为 $a$，调度系统规定一次校准为 $f(x)=\min(x,b)+\gcd(x,b)$：先把编号截到不超过 $b$，再加上它与 $b$ 的最大公约数，以保证后续分拣单元能整除。

需要连续执行 $n$ 次校准，即求 $f^{(n)}(a)$，其中 $f^{(1)}(x)=f(x)$，$f^{(k+1)}(x)=f(f^{(k)}(x))$。$\gcd(x,b)$ 表示 $x$ 与 $b$ 的最大公约数。

约束：测试组数不超过 `2000`，$a$ 与 $b$ 不超过 `1000000000000`，$n$ 不超过 `1000000000000000000`。

# 输入描述
第一行一个整数 $T$，表示测试组数，满足 $1 \le T \le 2000$。
接下来 $T$ 行，每行三个整数 $a$、$b$、$n$，满足 $1 \le a,b \le 1000000000000$，$1 \le n \le 1000000000000000000$。

# 输出描述
输出 $T$ 行，每行一个整数，表示对应数据的 $f^{(n)}(a)$。

## 样例1

**输入**

```
3
8 5 2
15 6 1
4 12 5
```

**输出**

```
6
9
24
```

**说明**

第一组：$f(8)=5+\gcd(8,5)=6$，再作用一次仍为 `6`。
第二组只迭代 `1` 次：$f(15)=6+\gcd(15,6)=9$。
第三组：$4\to 8\to 12\to 24$，之后停在不动点 `24`。

## 样例2

**输入**

```
2
1 1 10
9 4 3
```

**输出**

```
2
5
```

**说明**

$a=b=1$ 时很快进入不动点 $b+\gcd(a,b)$。
另一组从 `9` 开始对参数 `4` 迭代 `3` 次。

## 样例3

**输入**

```
1
20 7 2
```

**输出**

```
8
```

**说明**

$x=20>b=7$，一次变换后 $x=7+\gcd(20,7)=8$，再一次仍为不动点 `8`。
