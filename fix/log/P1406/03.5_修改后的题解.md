## 解题思路

用栈扫描表达式。空格与左括号可以忽略；数字和运算符逐个入栈。遇到右括号时，栈顶一定是「一个运算符后面跟着若干操作数」（操作数可能已是内层算完的结果）。

弹出连续的非运算符得到操作数序列（弹出顺序与从左到右相反，因此需要再反转），再弹出运算符，按从左到右依次结合：

- `+`：累加
- `-`：依次相减
- `*`：累乘

把得到的整数再压回栈，作为外层表达式的一个操作数。扫描结束后栈中只剩最终结果。

由于操作数都是个位数字，按字符入栈即可；内层计算结果可能是多位或负数，以字符串形式压栈，随后用整型解析。

## 复杂度分析

时间复杂度 $O(L)$，空间复杂度 $O(L)$，其中 $L$ 为表达式长度。

## 代码实现

### Python

```python
s = input()
stack = []


def is_operator(op):
    return op in ('+', '-', '*')


def calc(op, val):
    res = val[0]
    for i in range(1, len(val)):
        if op == '+':
            res += val[i]
        elif op == '-':
            res -= val[i]
        else:
            res *= val[i]
    return res


for x in s:
    if x == ' ' or x == '(':
        continue
    if x == ')':
        val = []
        while stack and not is_operator(stack[-1]):
            val.append(int(stack.pop()))
        op = stack.pop()
        val.reverse()
        stack.append(str(calc(op, val)))
    else:
        stack.append(x)
print(stack.pop())
```

### Java

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.Scanner;
import java.util.Stack;

public class Main {
    public static int calc(String op, List<Integer> val) {
        int res = val.get(0);
        for (int i = 1; i < val.size(); i++) {
            if (op.equals("+")) {
                res += val.get(i);
            } else if (op.equals("-")) {
                res -= val.get(i);
            } else {
                res *= val.get(i);
            }
        }
        return res;
    }

    public static boolean isOperator(String op) {
        return op.equals("+") || op.equals("-") || op.equals("*");
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String s = scanner.nextLine();
        Stack<String> stack = new Stack<>();
        for (char x : s.toCharArray()) {
            if (x == ' ' || x == '(') {
                continue;
            }
            if (x == ')') {
                List<Integer> val = new ArrayList<>();
                while (!stack.empty() && !isOperator(stack.peek())) {
                    val.add(Integer.parseInt(stack.pop()));
                }
                String op = stack.pop();
                Collections.reverse(val);
                stack.push(String.valueOf(calc(op, val)));
            } else {
                stack.push(String.valueOf(x));
            }
        }
        System.out.println(stack.pop());
    }
}
```

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <stack>
#include <string>
#include <vector>
using namespace std;

bool isOperator(const string& op) {
    return op == "+" || op == "-" || op == "*";
}

int calc(const string& op, const vector<int>& val) {
    int res = val[0];
    for (size_t i = 1; i < val.size(); i++) {
        if (op == "+") {
            res += val[i];
        } else if (op == "-") {
            res -= val[i];
        } else {
            res *= val[i];
        }
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    getline(cin, s);
    stack<string> st;
    for (char x : s) {
        if (x == ' ' || x == '(') {
            continue;
        }
        if (x == ')') {
            vector<int> val;
            while (!st.empty() && !isOperator(st.top())) {
                val.push_back(stoi(st.top()));
                st.pop();
            }
            string op = st.top();
            st.pop();
            reverse(val.begin(), val.end());
            st.push(to_string(calc(op, val)));
        } else {
            st.push(string(1, x));
        }
    }
    cout << st.top() << '\n';
    return 0;
}
```
