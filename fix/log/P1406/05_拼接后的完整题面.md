# 题目内容
计算用括号包裹的前缀 $s$ 表达式，操作符为 `+`、`-`、`*`，操作数可多个、可嵌套，空格分隔。例如 `(+ 1 2 3)` 结果为 `6`。

# 输入描述
一行字符串，表示一个 $s$ 表达式。

# 输出描述
一行一个整数，表示表达式的值。

## 样例1

**输入**

```
(+ 1 2 3)
```

**输出**

```
6
```

**说明**

同一层从左到右累加：$1 + 2 + 3 = 6$。

## 样例2

**输入**

```
(- (* (+ 1 2) 2) 3 1)
```

**输出**

```
2
```

**说明**

先算最内层 $(+ 1 2)$ 得到 `3`。
再算 $(* 3 2)$ 得到 `6`。
最外层 $(- 6 3 1)$ 从左到右计算：$6 - 3 - 1 = 2$。

## 样例3

**输入**

```
(* 2 3 4)
```

**输出**

```
24
```

**说明**

从左到右连乘：$2 \times 3 \times 4 = 24$。

## 样例4

**输入**

```
(- 5 3)
```

**输出**

```
2
```

**说明**

两个操作数的减法：$5 - 3 = 2$。
