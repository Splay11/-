## 解题思路

采用贪心策略，并配合排序做批量处理。

每个工厂的机器数只能减少，且不能低于 `1`。总产能是各工厂最终机器数的乘积。设当前有两个可调整的工厂，机器数满足 $x\ge y>1$：

* 将 $x$ 减一，乘积变为原来的 $\frac{x-1}{x}$；
* 将 $y$ 减一，乘积变为原来的 $\frac{y-1}{y}$。

由于 $\frac{x-1}{x}\ge\frac{y-1}{y}$，每次降低当前机器数最多的工厂，产能损失最小。

因此最优策略是不断降低最大的元素，使机器数较大的若干工厂逐渐拉齐。直接模拟 $k$ 次会超时，可以排序后批量处理：

1. 将数组从小到大排序。

2. 从最大值开始，维护当前被一起降低的工厂数量 $cnt$ 和它们的机器数 $level$。

3. 将这 $cnt$ 个工厂全部降低到下一个较小值，需要的调整次数为：

   $$
   (level-a_i)\times cnt
   $$

4. 若剩余调整次数足够，则整体降低并扩大处理范围。

5. 否则，设：

   $$
   q=\left\lfloor\frac{k}{cnt}\right\rfloor,\qquad r=k\bmod cnt
   $$

   最终有 $cnt-r$ 个工厂等于 $level-q$，有 $r$ 个工厂等于 $level-q-1$。

6. 若 $k\ge\sum(a_i-1)$，所有工厂最终都只剩 `1` 台机器，答案为 `1`。

乘积使用模快速幂计算，并对 $10^9+7$ 取模。

## 复杂度分析

每组数据需要排序，时间复杂度为 $O(n\log n)$。

计算最终乘积需要 $O(n)$，因此总时间复杂度为 $O(n\log n)$。

排序数组需要 $O(n)$ 的空间，空间复杂度为 $O(n)$。

所有测试数据的 $n$ 之和不超过 $4\times 10^5$，该复杂度满足要求。

## 代码实现

### Python

```python
import sys

MOD = 1000000007


def max_product(a, k):
    """计算调整后的最大总产能"""
    a.sort()
    n = len(a)

    # 所有工厂最多能够减少的总次数
    total = sum(x - 1 for x in a)
    if k >= total:
        return 1

    level = a[-1]
    cnt = 1

    # 从大到小批量降低机器数较多的工厂
    for i in range(n - 2, -1, -1):
        cost = (level - a[i]) * cnt

        if k >= cost:
            k -= cost
            level = a[i]
            cnt += 1
        else:
            q, r = divmod(k, cnt)
            high = level - q

            ans = 1

            # 机器数较小的工厂保持不变
            for j in range(i + 1):
                ans = ans * a[j] % MOD

            # 当前最大的 cnt 个工厂最终只相差一台机器
            ans = ans * pow(high, cnt - r, MOD) % MOD
            ans = ans * pow(high - 1, r, MOD) % MOD
            return ans

    # 所有工厂已经被降低到相同机器数
    q, r = divmod(k, n)
    high = level - q

    ans = pow(high, n - r, MOD)
    ans = ans * pow(high - 1, r, MOD) % MOD
    return ans


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    pos = 0

    T = data[pos]
    pos += 1
    answers = []

    for _ in range(T):
        n = data[pos]
        k = data[pos + 1]
        pos += 2

        a = data[pos:pos + n]
        pos += n

        answers.append(str(max_product(a, k)))

    print("\n".join(answers))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.Arrays;
import java.util.StringTokenizer;

public class Main {
    static final long MOD = 1000000007L;

    // 模快速幂
    static long modPow(long base, long exp) {
        long result = 1;
        base %= MOD;

        while (exp > 0) {
            if ((exp & 1) == 1) {
                result = result * base % MOD;
            }
            base = base * base % MOD;
            exp >>= 1;
        }

        return result;
    }

    // 计算调整后的最大总产能
    static long maxProduct(long[] a, long k) {
        Arrays.sort(a);
        int n = a.length;

        // 所有工厂最多能够减少的总次数
        long total = 0;
        for (long value : a) {
            total += value - 1;
        }

        if (k >= total) {
            return 1;
        }

        long level = a[n - 1];
        long cnt = 1;

        // 从大到小批量降低机器数较多的工厂
        for (int i = n - 2; i >= 0; i--) {
            long cost = (level - a[i]) * cnt;

            if (k >= cost) {
                k -= cost;
                level = a[i];
                cnt++;
            } else {
                long q = k / cnt;
                long r = k % cnt;
                long high = level - q;

                long ans = 1;

                // 机器数较小的工厂保持不变
                for (int j = 0; j <= i; j++) {
                    ans = ans * (a[j] % MOD) % MOD;
                }

                // 当前最大的 cnt 个工厂最终只相差一台机器
                ans = ans * modPow(high, cnt - r) % MOD;
                ans = ans * modPow(high - 1, r) % MOD;
                return ans;
            }
        }

        // 所有工厂已经被降低到相同机器数
        long q = k / n;
        long r = k % n;
        long high = level - q;

        long ans = modPow(high, n - r);
        ans = ans * modPow(high - 1, r) % MOD;
        return ans;
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(
                new InputStreamReader(System.in)
        );

        int T = Integer.parseInt(br.readLine().trim());
        StringBuilder answer = new StringBuilder();

        for (int test = 0; test < T; test++) {
            StringTokenizer st = new StringTokenizer(br.readLine());

            int n = Integer.parseInt(st.nextToken());
            long k = Long.parseLong(st.nextToken());

            long[] a = new long[n];
            int index = 0;

            // 读取当前测试的 n 个工厂机器数
            while (index < n) {
                st = new StringTokenizer(br.readLine());

                while (st.hasMoreTokens() && index < n) {
                    a[index++] = Long.parseLong(st.nextToken());
                }
            }

            answer.append(maxProduct(a, k)).append('\n');
        }

        System.out.print(answer);
    }
}
```
