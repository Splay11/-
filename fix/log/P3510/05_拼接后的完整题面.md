# 题目内容
给定一个仅由小写英文字母构成的字符串 $s$。允许先将 $s$ 中的字符任意重排，再把它划分成若干个连续片段，使得每个字符恰好属于一个片段，且每个片段都是对称串。

对称串指从左往右读与从右往左读完全相同的字符串。连续片段指在重排后的串中取一段连续字符。

求最少需要划分成多少个片段。

字符串长度不超过 $10^5$。

# 输入描述
输入一行一个仅由小写英文字母构成的字符串 $s$。
保证 $1 \le |s| \le 10^5$。

# 输出描述
输出一个整数，表示最少需要划分成的片段个数。

## 样例1

**输入**

```
aaaa
```

**输出**

```
1
```

**说明**

只有 `a` 且出现偶数次，$k=0$，整串可排成一个对称串，答案为 `1`。

## 样例2

**输入**

```
a
```

**输出**

```
1
```

**说明**

单字符本身就是对称串，$k=1$，答案为 `1`。
