## 解题思路

因为字符可以任意重排，片段是否对称只取决于各字母的出现次数，与原始顺序无关。

一个对称串的频率结构是：

- 长度为偶数时，每个字符出现次数都是偶数；
- 长度为奇数时，恰好有一个字符出现奇数次，其余为偶数。

每个对称片段最多只能“消化”一个出现次数为奇数的字符（作为中心）。因此，若有 $k$ 种字符出现奇数次，至少需要 $k$ 个片段。

特例：若没有任何字符出现奇数次，整串本身就可以排成一个对称串，答案为 `1`。

综上，设 $k$ 为出现次数为奇数的字符种数，答案为 $\max(1, k)$。统计 `a` 到 `z` 的频率即可。

## 复杂度分析

扫描字符串一次并统计 `26` 个小写字母的奇偶。

- 时间复杂度：$O(|s|)$。
- 空间复杂度：$O(1)$。

在 $|s| \le 10^5$ 的限制下可以通过。

## 代码实现

### Python

```python
s = input().strip()
freq = [0] * 26
for c in s:
    freq[ord(c) - ord('a')] += 1

odd_count = sum(1 for cnt in freq if cnt % 2 == 1)
if odd_count == 0:
    odd_count = 1
print(odd_count)
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        int[] freq = new int[26];
        for (char c : s.toCharArray()) {
            freq[c - 'a']++;
        }
        int odd_count = 0;
        for (int cnt : freq) {
            if (cnt % 2 == 1) {
                odd_count++;
            }
        }
        if (odd_count == 0) odd_count = 1;
        System.out.println(odd_count);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    vector<int> freq(26, 0);
    for (char c : s) {
        freq[c - 'a']++;
    }
    int odd_count = 0;
    for (int cnt : freq) {
        if (cnt % 2 == 1) {
            odd_count++;
        }
    }
    if (odd_count == 0) odd_count = 1;
    cout << odd_count << endl;
    return 0;
}
```
