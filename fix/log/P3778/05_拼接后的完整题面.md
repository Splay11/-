# 题目内容
实验室共有 $n$ 台仪器。第 $i$ 台仪器单次实验的额定时长为 $a_i$ 秒。平台还给定一个阈值参数 $x$：一次实验被记为有效时，占用时长至少为 $\min(a_i, x)$ 秒，且不得超过该仪器的额定时长 $a_i$ 秒。

所有仪器上的有效实验总次数恰好为 $m$。第 $i$ 台仪器的实验次数 $v_i$ 必须落在闭区间 $[l_i, r_i]$ 内。保证存在一组满足上述条件的次数分配。

请计算：在所有合法的次数分配下，全部实验占用时长之和的最小值与最大值。

约束：仪器台数不超过 $10^5$；$x$、$a_i$、$l_i$、$r_i$ 均为正整数且不超过 $10^6$；并且 $\sum l_i \le m \le \sum r_i$。

# 输入描述
第一行包含三个整数 $n$、$x$ 和 $m$，分别表示仪器台数、阈值参数以及有效实验总次数。
第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$，表示各仪器的额定时长。
第三行包含 $n$ 个整数 $l_1, l_2, \ldots, l_n$，表示各仪器实验次数的下界。
第四行包含 $n$ 个整数 $r_1, r_2, \ldots, r_n$，表示各仪器实验次数的上界。
保证 $1 \le n \le 10^5$，$1 \le x, a_i, l_i, r_i \le 10^6$，且 $\sum l_i \le m \le \sum r_i$。

# 输出描述
输出一行两个整数 $L$ 和 $R$，用空格分隔，分别表示占用时长之和的最小值与最大值。

## 样例1

**输入**

```
2 5 8
4 7
3 3
9 9
```

**输出**

```
35 47
```

**说明**

两台仪器额定时长分别为 `4` 与 `7`，阈值 $x=5$，总次数 $m=8$。先各分配下界 `3` 次，还剩 `2` 次可分配。
一次实验的最小占用为 $\min(a_i,x)$，即 `4` 与 `5`。把剩余 `2` 次分给系数更小的第一台，总时长为 $5 \times 4 + 3 \times 5 = 35$。
一次实验的最大占用为额定时长 `4` 与 `7`。把剩余 `2` 次分给第二台，总时长为 $3 \times 4 + 5 \times 7 = 47$。

## 样例2

**输入**

```
1 10 5
8
5
5
```

**输出**

```
40 40
```

**说明**

只有一台仪器，次数被夹在 $[5,5]$ 内，只能做 `5` 次。
最小占用为 $\min(8,10)=8$，最大占用为 `8`，因此最小与最大总时长都是 $5 \times 8 = 40$。

## 样例3

**输入**

```
3 3 6
1 5 10
1 1 1
3 3 3
```

**输出**

```
12 41
```

**说明**

三台仪器先各分配 `1` 次，剩余 `3` 次，每台还可再加至多 `2` 次。
最小系数分别为 $\min(1,3)=1$、$3$、$3$。先给系数为 `1` 的仪器加 `2` 次，再给下一台加 `1` 次，总时长为 $1+3+3+2 \times 1 + 1 \times 3 = 12$。
最大系数分别为 `1`、`5`、`10`。先给 `10` 加 `2` 次，再给 `5` 加 `1` 次，总时长为 $1+5+10+2 \times 10 + 1 \times 5 = 41$。

## 样例4

**输入**

```
2 1 4
2 2
1 1
3 3
```

**输出**

```
4 8
```

**说明**

两台仪器额定时长均为 `2`，阈值 $x=1$，先各分配 `1` 次，剩余 `2` 次。
最小系数均为 $\min(2,1)=1$，再分配 `2` 次后总时长为 $1+1+2 \times 1 = 4$。
最大系数均为 `2`，再分配 `2` 次后总时长为 $2+2+2 \times 2 = 8$。
