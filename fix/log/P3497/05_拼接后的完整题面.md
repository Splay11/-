# 题目内容
给定一个非负整数 $x$（可能非常大，以十进制字符串给出）。请构造一个非负整数 $y$，满足 $y < x$，且 $x$ 与 $y$ 的十进制数位之和相等。

若存在满足条件的 $y$，输出任意一个即可；否则输出 `-1`。

数据范围：$x$ 的十进制位数不超过 $10^5$，且 $0 \le x$。

# 输入描述
输入一行，包含一个整数 $x$（$0 \le x$，位数不超过 $10^5$），以十进制字符串形式给出，可能含前导零。

# 输出描述
若存在满足条件的 $y$，输出任意一个合法的 $y$（不要输出无意义的前导零，数字 `0` 本身除外）；否则输出 `-1`。

## 样例1

**输入**

```
0
```

**输出**

```
-1
```

**说明**

$x=0$ 时不存在更小的非负整数，输出 `-1`。

## 样例2

**输入**

```
123
```

**输出**

```
6
```

**说明**

$x=123$ 的数位和为 $1+2+3=6$。可以取 $y=6$，满足 $6<123$ 且数位和同为 `6`。

## 样例3

**输入**

```
10
```

**输出**

```
1
```

**说明**

$x=10$ 的数位和为 $1+0=1$。取 $y=1$，满足 $1<10$ 且数位和为 `1`。

## 样例4

**输入**

```
99
```

**输出**

```
-1
```

**说明**

$x=99$ 形如“非零数字后全为 `9`”。任何更小的数要么数位更少导致数位和无法达到 `18`，要么某一位减小后后缀无法补足，故无解，输出 `-1`。
