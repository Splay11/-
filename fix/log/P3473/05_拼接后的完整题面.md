# 题目内容
定义正整数 $n$ 的得分为它的正因子个数，记作 $c(n)$。

给定一个正整数 $x$，你可以将其表示为 $k$ 个大于 $1$ 的正整数 $a_1,a_2,\dots,a_k$ 的乘积（$k\ge 1$），即 $x = a_1 \times a_2 \times \dots \times a_k$。

你希望最大化这些整数的得分之和 $\sum_{i=1}^k c(a_i)$。

请你求出在最优拆分方案下，该和的最大值。

约束：测试数据组数 $T$ 满足 $1 \le T \le 10^4$，每一组的整数 $x$ 满足 $2 \le x \le 2 \times 10^5$。

# 输入描述
第一行包含一个整数 $T$ ($1 \le T \le 10^4$)，表示测试数据组数。
接下来 $T$ 行，每行包含一个整数 $x$ ($2 \le x \le 2 \times 10^5$)，表示需要拆分的正整数。

# 输出描述
对于每组数据，输出一行一个整数，表示能够得到的最大得分总和。

## 样例1

**输入**

```
3
4
30
36
```

**输出**

```
4
8
8
```

**说明**

对于第一组 $x=4$，质因数分解为 $2^2$，最大重数 $M=2$。第 $1$ 组包含指数 $\ge 1$ 的质数 $\{2\}$，得分 $2^1=2$；第 $2$ 组包含指数 $\ge 2$ 的质数 $\{2\}$，得分 $2^1=2$。总和为 `4`，对应拆分 $2 \times 2$，得分 $c(2)+c(2)=2+2=4$。

对于第二组 $x=30$，分解为 $2 \times 3 \times 5$，$M=1$。唯一一组包含所有三种质数，得分 $2^3=8$。对应不拆分 $30$，$c(30)=8$。

对于第三组 $x=36$，分解为 $2^2 \times 3^2$，$M=2$。第 $1$ 组包含指数 $\ge 1$ 的质数 $\{2,3\}$，得分 $2^2=4$；第 $2$ 组包含指数 $\ge 2$ 的质数 $\{2,3\}$，得分 $2^2=4$。总和为 `8`，对应拆分 $6 \times 6$，得分 $c(6)+c(6)=4+4=8$。
