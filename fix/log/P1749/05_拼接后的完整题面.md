# 题目内容
你在维护一座能量站，站内有 $n$ 个能量核心，初始能量值分别为 $c_1, c_2, \dots, c_n$。你需要按顺序进行 $m$ 次强化操作：每次选择当前能量值最低的核心，为其注入能量 $v_j$，使该核心的能量值增加 $v_j$。每次强化完成后，你想立刻知道此时所有核心中的最大能量值是多少。

核心数量 $n$ 和强化次数 $m$ 均为正整数，不超过 $10^5$。所有初始能量值和每次注入的能量值均为非负整数，且不超过 $10^9$。

# 输入描述
第一行包含两个整数 $n$ 和 $m$，分别表示核心的个数和强化操作的次数。
第二行包含 $n$ 个整数 $c_1, c_2, \dots, c_n$，表示每个核心的初始能量值。
第三行包含 $m$ 个整数 $v_1, v_2, \dots, v_m$，依次表示每次强化操作所注入的能量值。

# 输出描述
输出 $m$ 行，每行一个整数，表示完成对应的强化操作后，所有核心能量值中的最大值。

## 样例1

**输入**

```
2 2
10 20
5 10
```

**输出**

```
20
25
```

**说明**

初始核心能量值为 $10$ 和 $20$。
第 `1` 次强化：当前最小能量值为 $10$，注入 $5$ 后变为 $15$。此时核心能量值为 $[15, 20]$，最大值为 $20$，输出 `20`。
第 `2` 次强化：当前最小能量值为 $15$，注入 $10$ 后变为 $25$。此时核心能量值为 $[25, 20]$，最大值为 $25$，输出 `25`。

## 样例2

**输入**

```
3 3
100 200 300
50 100 150
```

**输出**

```
300
300
350
```

**说明**

初始核心能量值为 $100, 200, 300$。
第 `1` 次强化：最小值为 $100$，注入 $50$ 变为 $150$。核心能量值为 $[150, 200, 300]$，最大值为 $300$，输出 `300`。
第 `2` 次强化：最小值为 $150$，注入 $100$ 变为 $250$。核心能量值为 $[250, 200, 300]$，最大值为 $300$，输出 `300`。
第 `3` 次强化：此时最小值为 $200$，注入 $150$ 变为 $350$。核心能量值为 $[250, 350, 300]$，最大值为 $350$，输出 `350`。

## 样例3

**输入**

```
4 3
1 2 3 4
10 10 10
```

**输出**

```
11
12
13
```

**说明**

初始核心能量值为 $1, 2, 3, 4$。
第 `1` 次强化：最小值为 $1$，注入 $10$ 变为 $11$。此时数组为 $[11, 2, 3, 4]$，最大值为 $11$，输出 `11`。
第 `2` 次强化：最小值为 $2$，注入 $10$ 变为 $12$。此时数组为 $[11, 12, 3, 4]$，最大值为 $12$，输出 `12`。
第 `3` 次强化：最小值为 $3$，注入 $10$ 变为 $13$。此时数组为 $[11, 12, 13, 4]$，最大值为 $13$，输出 `13`。
