## 解题思路

本题需要模拟一系列强化操作，每次选取当前能量值最低的核心进行能量注入，并立即给出所有核心中的最大能量值。关键点在于既要快速找到最小值，又要能够知道更新后的全局最大值。

**算法思路**：
1. 维护一个**小根堆**（优先队列），用于存储所有核心的当前能量值，这样可以高效地获取并移除最小值。
2. 另外维护一个变量 `max_val`，记录当前所有核心能量值中的最大值。初始时，将所有初始能量值 $c_i$ 插入堆中，并计算出初始最大值赋给 `max_val`。
3. 依次处理 $m$ 次强化操作，对于第 $j$ 次操作：
   - 从堆中弹出当前最小能量值 `cur_min`。
   - 注入能量 $v_j$，得到新值 `new_val = cur_min + v_j`。
   - 若 `new_val > max_val`，则更新 `max_val = new_val`。
   - 将 `new_val` 重新插入堆中。
   - 输出 `max_val`，即本次操作后的最大能量值。
4. 在 C++ 中也可直接使用 `multiset`，其自带有序性，可以同时访问最小值和最大值；逻辑与上述堆+手动维护最大值一致。

该算法正确性基于：每次我们只增加被选中的最小元素，其他元素保持不变，因此全局最大值只可能在原来最大值或新增加后的值中产生。用变量跟踪最大值即可，无需每次遍历所有核心。

## 复杂度分析

- 时间复杂度：$O((n + m) \log n)$  
  初始建堆需要 $O(n)$ 时间；每次强化操作需要一次弹出最小值和一次插入，堆操作复杂度为 $O(\log n)$，共 $m$ 次操作，总复杂度 $O((n+m)\log n)$。若使用 `multiset`，每次删除和插入同为 $O(\log n)$。

- 空间复杂度：$O(n)$  
  堆（或 `multiset`）中始终存储 $n$ 个核心的能量值，仅需线性额外空间。

## 代码实现

### Python

```python
import sys
import heapq

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    
    # 初始化能量值，建立最小堆，并计算初始最大值
    heap = []
    max_val = 0
    for _ in range(n):
        c = int(next(it))
        heapq.heappush(heap, c)
        if c > max_val:
            max_val = c
    
    out_lines = []
    # 依次处理 m 次强化操作
    for _ in range(m):
        v = int(next(it))
        # 取出当前最小值
        cur_min = heapq.heappop(heap)
        new_val = cur_min + v
        if new_val > max_val:
            max_val = new_val
        heapq.heappush(heap, new_val)
        out_lines.append(str(max_val))
    
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String[] firstLine = br.readLine().split(" ");
        int n = Integer.parseInt(firstLine[0]);
        int m = Integer.parseInt(firstLine[1]);

        // 读取初始能量值
        String[] cLine = br.readLine().split(" ");
        PriorityQueue<Long> pq = new PriorityQueue<>();
        long maxVal = 0;
        for (int i = 0; i < n; i++) {
            long c = Long.parseLong(cLine[i]);
            pq.offer(c);
            if (c > maxVal) {
                maxVal = c;
            }
        }

        // 读取所有注入值
        String[] vLine = br.readLine().split(" ");
        StringBuilder sb = new StringBuilder();
        for (int j = 0; j < m; j++) {
            long v = Long.parseLong(vLine[j]);
            long curMin = pq.poll();
            long newVal = curMin + v;
            if (newVal > maxVal) {
                maxVal = newVal;
            }
            pq.offer(newVal);
            sb.append(maxVal).append("\n");
        }
        System.out.print(sb);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    multiset<ll> st;
    // 读入初始能量值
    for (int i = 0; i < n; ++i) {
        ll c;
        cin >> c;
        st.insert(c);
    }
    // 依次处理每次强化操作
    for (int j = 0; j < m; ++j) {
        ll v;
        cin >> v;
        // 取出最小值
        ll cur_min = *st.begin();
        st.erase(st.begin());
        ll new_val = cur_min + v;
        st.insert(new_val);
        // 输出当前最大值（multiset 中最大元素在末尾）
        cout << *st.rbegin() << "\n";
    }
    return 0;
}
```
