# 题目内容
某通信公司正在部署一个由 $n$ 个路由器和 $n-1$ 条光纤连接组成的骨干网络。该网络的拓扑结构是一个由 $n$ 个顶点和 $n-1$ 条边组成的连通无环图。为了保证信号不互相干扰，任意两个直接相连的路由器必须使用不同的通信频道。频道用正整数编号，由于设备限制，每个路由器可使用的频道编号不能超过一个给定的上限 $K$（$K \ge 2$）。现在希望所有路由器的频道编号之和尽可能小，请计算这个最小总和。

测试数据组数 $T$ 满足 $1 \le T \le 10^4$。每组数据中，$n$ 满足 $1 \le n \le 2 \times 10^5$，$K$ 满足 $2 \le K \le 10^9$。保证所有测试数据的 $n$ 之和不超过 $2 \times 10^5$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据组数。
接下来每组数据按以下格式给出：
- 第一行包含两个整数 $n$ 和 $K$，分别表示路由器数量和频道编号上限。
- 接下来 $n-1$ 行，每行包含两个整数 $u$ 和 $v$（$1 \le u, v \le n$，$u 
e v$），表示一条光纤直接连接路由器 $u$ 和 $v$。

# 输出描述
对于每组测试数据，输出一行一个整数，表示在满足相邻路由器频道不同且所有频道编号不超过 $K$ 的条件下，所有路由器的频道编号之和的最小可能值。

## 样例1

**输入**

```
1
1 5
```

**输出**

```
1
```

**说明**

只有一个路由器，无需考虑相邻约束，只需分配一个不超过上限 $K=5$ 的最小正整数频道，即 `1`。
此时二分图层划分中，偶层节点数 $|A|=1$，奇层节点数 $|B|=0$，$\min(|A|,|B|)=0$。
由公式 $ans=n+\min(|A|,|B|)$ 得总和为 $1+0=1$。

## 样例2

**输入**

```
1
4 100
1 2
2 3
3 4
```

**输出**

```
6
```

**说明**

树为一条链 $1-2-3-4$。以路由器 `1` 为根进行分层：偶层 $A=\{1,3\}$ 共 `2` 个节点，奇层 $B=\{2,4\}$ 共 `2` 个节点。
$\min(|A|,|B|)=2$，总路由器数 $n=4$，因此最小总和为 $n+\min(|A|,|B|)=4+2=6$。
一种可行分配：节点 `1`、`3` 取频道 `1`，节点 `2`、`4` 取频道 `2`，相邻均不同，总和 $1+2+1+2=6$。

## 样例3

**输入**

```
1
4 10
1 2
1 3
1 4
```

**输出**

```
5
```

**说明**

星型树：路由器 `1` 为根，连接 `2`、`3`、`4`。分层后偶层 $A=\{1\}$（`1` 个节点），奇层 $B=\{2,3,4\}$（`3` 个节点）。
较大的集合 $B$ 分配 `1`，较小的集合 $A$ 分配 `2`，邻接均可不同。总和 $n+\min(|A|,|B|)=4+1=5$（$1\times 3+2=5$）。
