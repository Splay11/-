# 题目内容
工位抽检得到一张 $n$ 行 $m$ 列的小写字母编码表。质检规则关注每一个 $2 \times 2$ 窗口：若该窗口四个格子的字符集合同时包含 `y`、`o`、`u` 三种字母，则记为一次命中。需要统计命中窗口的个数，用于评估编码表是否出现异常聚集。

请输出命中窗口的数量。

约束：$1 \le n,m \le 1000$。

# 输入描述
第一行两个正整数 $n$ 和 $m$。
接下来 $n$ 行，每行一个长度为 $m$ 的小写字母串。

# 输出描述
输出一个整数，表示符合条件的 $2\times 2$ 子矩阵个数。

**输入**

```
2 2
```

**输出**
