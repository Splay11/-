# 题目内容
在一个游戏中，有 $N$ 个连续关卡，每个关卡有一个得分（可能为负数）。玩家需要将这些关卡恰好划分为 $K$ 个连续的非空阶段，每个阶段的总分构成序列 $S_1, S_2, \dots, S_K$。计算总得分时，奇数编号的阶段（第 $1, 3, 5, \dots$ 个阶段）按原分数值累加，偶数编号的阶段（第 $2, 4, 6, \dots$ 个阶段）按原分数值的两倍累加。求所有划分方案中，可能获得的最大总得分。

本题包含多组测试数据，所有数据满足以下约束：
- 测试数据组数 $T$ 满足 $1 \le T \le 100$。
- 每组数据中，关卡数量 $N$ 和阶段数 $K$ 满足 $1 \le K \le N \le 3000$。
- 所有测试数据的 $N$ 之和不超过 $3000$。
- 每个关卡的得分 $a_i$ 满足 $|a_i| \le 10^9$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据的组数。

接下来包含 $T$ 组数据，每组数据的格式如下：
- 第一行包含两个整数 $N$ 和 $K$，分别表示关卡总数和需要划分的阶段数。
- 第二行包含 $N$ 个整数，依次表示各关卡的得分。

# 输出描述
对于每组测试数据，输出一行一个整数，表示可能获得的最大总得分。

## 样例1

**输入**

```
1
3 2
10 -5 20
```

**输出**

```
45
```

**说明**

序列长度为 $3$，需要划分成 $2$ 段。

可能的划分共有两种：
- 第一段 $[10]$，第二段 $[-5, 20]$。奇数段（第 $1$ 段）按原值计算，偶数段（第 $2$ 段）乘以 $2$，总得分为 $10 + 2 \times (-5 + 20) = 40$。
- 第一段 $[10, -5]$，第二段 $[20]$。总得分为 $(10 - 5) + 2 \times 20 = 45$。

两种方案中较大值为 `45`，故输出 `45`。

## 样例2

**输入**

```
1
4 3
-1 -2 -3 -4
```

**输出**

```
-12
```

**说明**

所有关卡得分均为负数，共 $4$ 个关卡，需要恰好划分为 $3$ 个非空连续阶段。

由于 $3$ 段中奇数编号的阶段（第 $1, 3$ 段）按原值累加，偶数编号的阶段（第 $2$ 段）按原值的 $2$ 倍累加，为最大化总得分，应尽量让偶数段包含的负数之和尽可能“大”（即绝对值尽可能小）。

所有三段划分方案如下：
- $[ -1 ], [ -2 ], [ -3, -4 ]$：得分 $(-1) + 2 \times (-2) + (-7) = -12$；
- $[ -1 ], [ -2, -3 ], [ -4 ]$：得分 $(-1) + 2 \times (-5) + (-4) = -15$；
- $[ -1, -2 ], [ -3 ], [ -4 ]$：得分 $(-3) + 2 \times (-3) + (-4) = -13$。

最优得分为 `-12`，输出 `-12`。

## 样例3

**输入**

```
1
1 1
5
```

**输出**

```
5
```

**说明**

边界情况：只有一个关卡，需要划分为 $1$ 段，该段编号为 $1$（奇数），按原值累加。

唯一方案的总得分为 `5`。
