# 题目内容
对于一个整数集合，定义它的「缺省数」为未出现在该集合中的最小非负整数。例如，集合 $\{1,2,3\}$ 的缺省数为 $0$，集合 $\{0,2,5\}$ 的缺省数为 $1$。

现在给定一个长度为 $n$ 的整数序列 $x_1, x_2, \dots, x_n$，序列中的每个元素只可能是 $0$、$1$ 或 $2$。考虑该序列的所有非空连续子段，求每个子段的缺省数之和。

序列的长度 $n$ 满足 $1 \le n \le 2 \times 10^5$，且每个 $x_i$ 均为 $0$、$1$ 或 $2$。

# 输入描述
第一行包含一个整数 $n$。
第二行包含 $n$ 个整数，依次表示序列元素 $x_1, x_2, \dots, x_n$，每个整数均为 $0$、$1$ 或 $2$。

# 输出描述
输出一个整数，表示所有非空连续子段的缺省数之和。

## 样例1

**输入**

```
4
0 1 2 0
```

**输出**

```
14
```

**说明**

序列长度为 `4`，所有非空子数组共 `10` 个。分别计算每个子数组的缺省数：
子数组 $[0]$ 缺少 `1`，缺省数为 $1$；$[1]$ 缺少 `0`，缺省数为 $0$；$[2]$ 缺少 `0`，缺省数为 $0$；第二个 $[0]$ 缺省数为 $1$。
$[0,1]$ 包含 $0,1$ 但缺少 $2$，缺省数为 $2$；$[1,2]$ 缺少 $0$，缺省数为 $0$；$[2,0]$ 缺少 $1$，缺省数为 $1$。
$[0,1,2]$ 包含 $0,1,2$，缺省数为 $3$；$[1,2,0]$ 缺省数为 $3$；$[0,1,2,0]$ 缺省数为 $3$。
全部相加：$1+0+0+1+2+0+1+3+3+3=14$。

## 样例2

**输入**

```
3
2 1 0
```

**输出**

```
6
```

**说明**

序列长度为 `3`，共有 `6` 个非空子数组。
$[2]$ 缺少 `0`，缺省数为 $0$；$[1]$ 缺少 `0`，缺省数为 $0$；$[0]$ 缺少 `1`，缺省数为 $1$。
$[2,1]$ 缺少 $0$，缺省数为 $0$；$[1,0]$ 包含 $0,1$ 但缺少 $2$，缺省数为 $2$；$[2,1,0]$ 包含 $0,1,2$，缺省数为 $3$。
总和为 $0+0+1+0+2+3=6$。

## 样例3

**输入**

```
1
0
```

**输出**

```
1
```

**说明**

序列只有一个元素 `0`，子数组 $[0]$ 缺少 `1`，缺省数为 $1$。总和为 $1$。

## 样例4

**输入**

```
6
1 2 0 1 0 2
```

**输出**

```
35
```

**说明**

序列长度为 `6`，所有非空子数组共 `21` 个。按缺省数分类统计：
- 不含 $0$ 的子数组（缺省数 $0$）共有 `5` 个，如 $[1]$、$[2]$、$[1,2]$ 等。
- 包含 $0$ 但不包含 $1$ 的子数组（缺省数 $1$）共有 `5` 个，如 $[0]$、$[2,0]$ 等。
- 同时包含 $0$ 和 $1$ 但不包含 $2$ 的子数组（缺省数 $2$）共有 `3` 个，如 $[0,1]$、$[1,0]$ 等。
- 同时包含 $0,1,2$ 的子数组（缺省数 $3$）共有 `8` 个，如 $[1,2,0]$、$[0,1,0,2]$ 等。
总和为 $0 \times 5 + 1 \times 5 + 2 \times 3 + 3 \times 8 = 35$。
