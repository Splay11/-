## 解题思路

由于序列 $x$ 中的元素取值仅为 $0,1,2$，对于任意一个非空连续子段，其缺省数（未出现的最小非负整数）只可能是 $0,1,2,3$ 中的一种，具体分类如下：

1. 缺省数为 $0$：子段中没有出现 $0$；
2. 缺省数为 $1$：子段中出现了 $0$，但没有出现 $1$；
3. 缺省数为 $2$：子段中同时出现了 $0$ 和 $1$，但没有出现 $2$；
4. 缺省数为 $3$：子段中同时出现了 $0,1,2$。

设所有非空子段的总数为 $total = \frac{n(n+1)}{2}$。我们只需求出上述四类子段的个数，再加权求和即可得到答案。

为了统计不包含某个或某几个数字的子段个数，可以扫描序列，把连续的不含目标数字的区间找出来。对于长度为 $L$ 的连续区间，其内部产生的非空子段数量为 $\frac{L(L+1)}{2}$。

定义两个辅助函数：

- $F(x)$：统计不包含数字 $x$ 的子段数量；
- $F(x,y)$：统计同时不包含数字 $x$ 和 $y$ 的子段数量（即子段中只出现剩下的那个数字）。

通过三次线性扫描分别计算 $F(0), F(1), F(2)$，再通过三次线性扫描分别计算 $F(0,1), F(0,2), F(1,2)$。

根据容斥原理，各类子段的数量为：

- $cnt_0 = F(0)$；
- $cnt_1 = F(1) - F(0,1)$；
- $cnt_2 = F(2) - F(0,2) - F(1,2)$；
- $cnt_3 = total - \big(F(0)+F(1)+F(2)\big) + \big(F(0,1)+F(0,2)+F(1,2)\big)$。

最终答案 $ans = 0\times cnt_0 + 1\times cnt_1 + 2\times cnt_2 + 3\times cnt_3$。

## 复杂度分析

- 时间复杂度：$O(n)$。每一项统计函数都只需对序列进行一次遍历，整个算法总共执行常数次线性扫描。
- 空间复杂度：$O(n)$。需要存储长度为 $n$ 的序列。如果使用在线处理，空间复杂度可优化至 $O(1)$，但当前实现直接存储序列。

## 代码实现

### Python

```python
import sys

def count_no(arr, x):
    """统计不包含数字 x 的子段数"""
    res = 0
    cnt = 0
    for v in arr:
        if v == x:
            res += cnt * (cnt + 1) // 2
            cnt = 0
        else:
            cnt += 1
    res += cnt * (cnt + 1) // 2
    return res

def count_no_pair(arr, x, y):
    """统计同时不包含 x 和 y 的子段数（即只包含剩余数字）"""
    res = 0
    cnt = 0
    for v in arr:
        if v == x or v == y:
            res += cnt * (cnt + 1) // 2
            cnt = 0
        else:
            cnt += 1
    res += cnt * (cnt + 1) // 2
    return res

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    x = list(map(int, data[1:]))

    total = n * (n + 1) // 2

    cnt0 = count_no(x, 0)            # 不含0的子段数
    cnt1_all = count_no(x, 1)        # 不含1的子段数
    cnt2_all = count_no(x, 2)        # 不含2的子段数

    cnt01 = count_no_pair(x, 0, 1)   # 不含0和1的子段数
    cnt02 = count_no_pair(x, 0, 2)   # 不含0和2的子段数
    cnt12 = count_no_pair(x, 1, 2)   # 不含1和2的子段数

    # 各类缺省数对应的子段个数
    cnt_mex0 = cnt0                              # 缺省数=0
    cnt_mex1 = cnt1_all - cnt01                  # 缺省数=1
    cnt_mex2 = cnt2_all - cnt02 - cnt12          # 缺省数=2
    cnt_mex3 = total - (cnt0 + cnt1_all + cnt2_all) + (cnt01 + cnt02 + cnt12)  # 缺省数=3

    ans = 1 * cnt_mex1 + 2 * cnt_mex2 + 3 * cnt_mex3
    print(ans)

if __name__ == '__main__':
    main()
```

```java
import java.io.*;
import java.util.*;

public class Main {
    // 统计不包含数字 x 的子段数
    public static long countNo(int[] arr, int x) {
        long res = 0;
        long cnt = 0;
        for (int v : arr) {
            if (v == x) {
                res += cnt * (cnt + 1) / 2;
                cnt = 0;
            } else {
                cnt++;
            }
        }
        res += cnt * (cnt + 1) / 2;
        return res;
    }

    // 统计同时不包含 x 和 y 的子段数（只包含剩余数字）
    public static long countNoPair(int[] arr, int x, int y) {
        long res = 0;
        long cnt = 0;
        for (int v : arr) {
            if (v == x || v == y) {
                res += cnt * (cnt + 1) / 2;
                cnt = 0;
            } else {
                cnt++;
            }
        }
        res += cnt * (cnt + 1) / 2;
        return res;
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());
        String[] tokens = br.readLine().split("\\s+");
        int[] x = new int[n];
        for (int i = 0; i < n; i++) {
            x[i] = Integer.parseInt(tokens[i]);
        }

        long total = (long) n * (n + 1) / 2;

        long cnt0 = countNo(x, 0);            // 不含0的子段数
        long cnt1_all = countNo(x, 1);        // 不含1的子段数
        long cnt2_all = countNo(x, 2);        // 不含2的子段数

        long cnt01 = countNoPair(x, 0, 1);    // 不含0和1的子段数
        long cnt02 = countNoPair(x, 0, 2);    // 不含0和2的子段数
        long cnt12 = countNoPair(x, 1, 2);    // 不含1和2的子段数

        // 各类缺省数对应的子段个数
        long cnt_mex0 = cnt0;                                // 缺省数=0
        long cnt_mex1 = cnt1_all - cnt01;                    // 缺省数=1
        long cnt_mex2 = cnt2_all - cnt02 - cnt12;            // 缺省数=2
        long cnt_mex3 = total - (cnt0 + cnt1_all + cnt2_all) + (cnt01 + cnt02 + cnt12); // 缺省数=3

        long ans = 1 * cnt_mex1 + 2 * cnt_mex2 + 3 * cnt_mex3;
        System.out.println(ans);
    }
}
```
