# 题目内容
施工现场有两块三角形作业面，需要用一顶圆形防尘罩把它们同时完全罩住。罩子可以放在平面上任意位置，半径可以任选，但必须覆盖两块三角形的全部区域。工地只关心半径越小越好，以便降低搭设成本。

保证每个三角形由三个不共线的顶点确定。答案为实数，设你的输出为 $a$、标准答案为 $b$，当且仅当 $\dfrac{|a-b|}{\max(1, |b|)} \le 0.000001$ 时视为正确。

约束：所有顶点坐标的绝对值不超过 $10^2$。

# 输入描述
第一行六个整数，依次为第一个三角形三个顶点的坐标。
第二行六个整数，依次为第二个三角形三个顶点的坐标。
保证每个三角形存在（三点不共线），且所有坐标满足绝对值不超过 $10^2$。

# 输出描述
输出一个实数，表示最小覆盖圆的半径。相对误差不超过 `0.000001` 即视为正确。

## 样例1

**输入**

```
0 0 4 0 0 3
10 10 12 10 10 13
```

**输出**

```
8.200609733428363
```

**说明**

两个直角三角形相距较远，最小覆盖圆由最远的一对顶点确定直径。半径约为 `8.200609733428363`。

## 样例2

**输入**

```
0 0 6 0 0 8
1 1 2 1 1 3
```

**输出**

```
5.0
```

**说明**

第二个三角形落在第一个直角三角形内部。边长为 `6`、`8`、`10` 的直角三角形外接圆半径为 `5`，该圆已覆盖全部 `6` 个顶点。

## 样例3

**输入**

```
-10 -10 -10 10 10 0
8 1 9 2 8 2
```

**输出**

```
12.5
```

**说明**

第一个三角形跨度较大，第二个三角形靠近其内部。最小覆盖圆半径为 `12.5`。
