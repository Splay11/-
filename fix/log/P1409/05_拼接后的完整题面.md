# 题目内容
一条输油管由 $n$ 节依次相连的管段组成。其中恰好有一节已经泄漏，在输入序列中用 `-1` 标记；其余管段给出拆除代价，均为正整数。泄漏节不在整条管线的两端。

要隔离泄漏，必须在其左侧拆除恰好一节管段、在其右侧拆除恰好一节管段，使泄漏节与两端断开。总代价为这两节拆除代价之和。请计算最小总代价。

约束：管段数满足 $3 \le n \le 2 \times 10^5$，非泄漏管段的拆除代价均在 `1` 到 $10^9$ 之间。输入保证恰好有一个 `-1`，且它不出现在序列两端。

# 输入描述
第一行一个整数 $n$，表示管段数量。
第二行 $n$ 个整数，按从左到右给出各管段信息：泄漏节为 `-1`，其余为对应管段的拆除代价。
保证 $3 \le n \le 2 \times 10^5$，拆除代价均满足 $1 \le a_i \le 10^9$，且 `-1` 不在两端。

# 输出描述
输出一个整数，表示最小总代价。

## 样例1

**输入**

```
3
1 -1 2
```

**输出**

```
3
```

**说明**

这是 $n=`3`$ 的最小规模。左右两侧各只有一节，答案只能是 $1+2=`3`。
