## 解题思路

泄漏节把整条管线分成左右两段，且题目保证它不在两端，因此左右两侧都至少有一节可拆除的管段。

隔离泄漏只需要在左侧拆一节、在右侧拆一节。两侧各自独立，最优策略就是：

- 在左侧所有管段中选拆除代价最小的一节；
- 在右侧所有管段中选拆除代价最小的一节；
- 答案为二者之和。

扫描一遍序列，找到值为 `-1` 的位置 $p$，再分别求 $a[0..p-1]$ 与 $a[p+1..n-1]$ 的最小值即可。

## 复杂度分析

只需线性扫描一次数组。

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
n = int(input())
a = list(map(int, input().split()))
pos = a.index(-1)
print(min(a[:pos]) + min(a[pos + 1:]))
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] a = new int[n];
        int pos = -1;
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
            if (a[i] == -1) {
                pos = i;
            }
        }
        int left = Integer.MAX_VALUE;
        int right = Integer.MAX_VALUE;
        for (int i = 0; i < pos; i++) {
            left = Math.min(left, a[i]);
        }
        for (int i = pos + 1; i < n; i++) {
            right = Math.min(right, a[i]);
        }
        System.out.println(left + right);
        sc.close();
    }
}
```
