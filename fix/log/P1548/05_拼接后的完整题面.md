# 题目内容
文博馆正在整理一块 $n$ 行 $m$ 列的展柜网格，每个格子上贴有一个小写字母标签。策展方案要求从网格中选出三个格子作为一组导览点：三个顶点上的字符必须恰好是 `t`、`z`、`g` 各一个。同时，这三个格子必须构成直角边分别沿水平和竖直方向的直角三角形，即三点中恰有两点同行、恰有两点同列。请统计有多少组满足条件的导览点。

约束：$1 \le n,m \le 10^3$。

# 输入描述
第一行两个正整数 $n$ 和 $m$，表示网格的行数和列数。
接下来 $n$ 行，每行一个长度为 $m$ 的小写字母字符串，表示网格的一行。
保证 $1 \le n,m \le 10^3$。

# 输出描述
输出一个整数，表示满足条件的导览点组数。

## 样例1

**输入**

```
1 3
tgz
```

**输出**

```
0
```

**说明**

只有 `1` 行，任何三点都无法做到“两点同列”，因此直角三角形个数为 `0`。

## 样例2

**输入**

```
3 3
ttt
zzz
ggg
```

**输出**

```
0
```

**说明**

`t`、`z`、`g` 分别占满三行。对任意一个 `t`，与它同行没有 `z` 或 `g`，因此不能形成一条水平直角边，答案为 `0`。

## 样例3

**输入**

```
2 2
tg
zt
```

**输出**

```
2
```

**说明**

矩阵为

- 第 `1` 行：`t g`
- 第 `2` 行：`z t`

两个直角三角形是：`t(1,1)`、`g(1,2)`、`z(2,1)`（直角在左上 `t`）；以及 `t(2,2)`、`g(1,2)`、`z(2,1)`（直角在右下 `t`）。答案为 `2`。

## 样例4

**输入**

```
3 4
ttzz
zggt
gztg
```

**输出**

```
28
```

**说明**

先统计每个字符在各行、各列的出现次数。对每个格子作为直角顶点：

- 若为 `t`，把同行 `z` 与同列 `g`、同行 `g` 与同列 `z` 配对；
- 若为 `z` 或 `g`，对另外两个字母做同样配对。

累加得到 `28`。
