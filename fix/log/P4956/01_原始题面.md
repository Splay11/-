# 题目内容
在整数研究中，我们称满足以下条件的大于 $1$ 的整数 $p$ 为**纯净数**：$p$ 除了 $1$ 和它自身外没有其他正约数。对于一个正整数 $N$，若存在一个纯净数 $p$ 使得 $p^2$ 能整除 $N$，则称 $p^2$ 为 $N$ 的一个**纯净平方因子**。

给定 $N$，请你找出它的所有纯净平方因子，并按从小到大的顺序输出。如果 $N$ 不存在任何纯净平方因子，则输出 `-1`。

保证测试数据的组数 $T$ 不超过 $300$，且对于每组询问，正整数 $N$ 满足 $1 \le N \le 10^{18}$。

# 输入描述
第一行包含一个整数 $T$ ($1 \le T \le 300$)，表示询问的总组数。
接下来 $T$ 行，每行包含一个整数 $N$ ($1 \le N \le 10^{18}$)，表示一次询问。

# 输出描述
对于每组询问输出一行：若存在纯净平方因子，则按升序将它们依次输出，相邻两个数之间用一个空格隔开；否则输出 `-1`。

## 样例1

**输入**

```
1
1
```

**输出**

```
-1
```

**说明**

$N=1$，没有大于 $1$ 的正约数，因此不存在纯净平方因子。

## 样例2

**输入**

```
2
16
36
```

**输出**

```
4
4 9
```

**说明**

对于第一组询问，$N=16=2^4$，质因子 $2$ 出现次数为 `4`，存在纯净平方因子 $2^2=4$，故输出 $4$。对于第二组询问，$N=36=2^2\times3^2$，质因子 $2$ 和 $3$ 的出现次数均为 `2`，对应的纯净平方因子分别为 $2^2=4$ 和 $3^2=9$，按升序输出为 `4 9`。

## 样例3

**输入**

```
1
999966000289
```

**输出**

```
999966000289
```

**说明**

$N=999966000289=999983^2$，其中 $999983$ 是一个大于 $10^6$ 的质数。由于 $999983^2$ 能整除 $N$，因此 $999983^2$ 是纯净平方因子。没有其他质因子的平方满足条件，故输出本身。

## 样例4

**输入**

```
1
4000024000036
```

**输出**

```
4 1000006000009
```

**说明**

$N=4000024000036=2^2\times 1000003^2$。其中 $1000003$ 是一个大于 $10^6$ 的质数，满足 $1000003^2$ 整除 $N$。因此纯净平方因子包括 $2^2=4$ 和 $1000003^2=1000006000009$，按升序输出。
