# 题目内容
机房温感阵列按时间记下 $n$ 个正整数读数。运维把一段连续读数称为缓变窗，当且仅当其中每一对相邻读数之差的绝对值都不超过 `1`。需要找出最长缓变窗的长度，用来评估设备是否处于平稳工作段。

请输出该长度。

约束：$1 \le n \le 10^5$，读数为正整数且不超过 `1000000000`。

# 输入描述
第一行一个正整数 $n$。
第二行 $n$ 个正整数。
保证 $1 \le n \le 10^5$，$1 \le a_i \le 1000000000$。

# 输出描述
输出一个正整数，表示最长缓变连续子数组的长度。
