# 题目内容
平面上有 $n$ 个监测点，第 $i$ 个点的坐标为 $(x_i, y_i)$。你需要把一个信号基站放在坐标轴上（横轴或纵轴），并以该点为圆心画一个圆，使得圆至少覆盖 $\lceil n/2 \rceil$ 个监测点。求满足条件的最小半径。

横轴是所有形如 $(x, 0)$ 的点，纵轴是所有形如 $(0, y)$ 的点。若点到圆心的欧氏距离不超过半径，则称该点被覆盖。

约束：点数不超过 `10^5`，坐标的绝对值不超过 `10^5`。

# 输入描述
第一行一个整数 $n$，表示监测点个数。
接下来 $n$ 行，每行两个整数 $x_i$ 和 $y_i$，表示第 $i$ 个点的坐标。
保证 $2 \le n \le 10^5$，$-10^5 \le x_i, y_i \le 10^5$。

# 输出描述
输出一个实数，表示最小半径。相对或绝对误差不超过 $10^{-6}$ 即视为正确：设你的输出为 $a$、标准答案为 $b$，当 $\dfrac{|a-b|}{\max(1, |b|)} \le 10^{-6}$ 时通过。

## 样例1

**输入**

```
3
0 1
0 -1
5 5
```

**输出**

```
1.000000
```

**说明**

需覆盖 `2` 个点。纵轴上圆心 $(0,0)$、半径 `1` 可覆盖 $(0,1)$ 与 $(0,-1)$。
