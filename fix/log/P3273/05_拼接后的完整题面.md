# 题目内容
冷链仓库把货架按字母表 $a, b, \ldots, z$ 排成一条直线通道（`a` 与 `z` 不相邻，通道不环形）。两个小写字母 $x, y$ 的间隔定义为：它们在字母表中位置之差的绝对值再减 `1`；若两者相同，则间隔为 `0`。仓管员每次会指定三个货架标签 $a, b, c$ 以及一个基准标签 $p$，需要把基准分别到这三个货架的间隔加总，用于估算搬运距离。

请对每组询问计算 $p$ 分别到 $a$、$b$、$c$ 的间隔之和。

约束：测试组数 $T$ 满足 $1 \le T \le 1000$。

# 输入描述
第一行一个整数 $T$，表示测试组数。
每组两行：第一行三个小写字母 $a, b, c$，第二行一个小写字母 $p$。
保证 $1 \le T \le 1000$。

# 输出描述
对每组数据输出一行一个整数，表示间隔之和。

## 样例1

**输入**

```
3
x y z
m
d d d
e
p q r
s
```

**输出**

```
33
0
3
```

**说明**

第一组：$p=$ `m` 到 `x`、`y`、`z` 的间隔分别为 `10`、`11`、`12`，和为 `33`。
第二组：`e` 到三个 `d` 的间隔均为 `0`。
第三组：`s` 到 `p`、`q`、`r` 的间隔为 `2`、`1`、`0`，和为 `3`。

## 样例2

**输入**

```
2
k k k
k
f h j
g
```

**输出**

```
0
2
```

**说明**

第一组目标字母与三个字母都相同，间隔和为 `0`。
第二组：$p=$ `g` 到 `f`、`h`、`j` 的间隔为 `0`、`0`、`2`，和为 `2`。
