# 题目内容
小蓝在翻阅数学书籍时，注意到一类特殊的正整数：如果一个大于 $1$ 的整数恰好有三个不同的正因子，她就称之为“三叶数”。例如，$4$ 的因子有 $1,2,4$，一共三个，因此 $4$ 是一个三叶数；而 $6$ 的因子有 $1,2,3,6$，共四个，不是三叶数。

现在她有一个长度为 $Q$ 的查询列表，每个查询给出一个区间 $[L,R]$。你需要帮助小蓝计算每个区间内有多少个三叶数。

数据范围：查询次数 $Q$ 不超过 $10^4$，区间端点的绝对值不超过 $10^{14}$，且保证 $1 \le L \le R \le 10^{14}$。

# 输入描述
第一行包含一个整数 $Q$（$1 \le Q \le 10^4$），表示查询的次数。
接下来 $Q$ 行，每行包含两个整数 $L$ 和 $R$（$1 \le L \le R \le 10^{14}$），表示一个查询区间的左右端点。

# 输出描述
输出共 $Q$ 行，每行一个整数，依次表示对应区间 $[L,R]$ 内三叶数的数量。

## 样例1

**输入**

```
3
1 20
5 10
19 30
```

**输出**

```
2
1
1
```

**说明**

区间 `[1,20]` 中的整数，只有 $4 = 2^2$ 和 $9 = 3^2$ 恰好有三个不同的正因子，因此共有 `2` 个三叶数。
区间 `[5,10]` 中仅包含 $9$，共 `1` 个三叶数。
区间 `[19,30]` 中包含 $25 = 5^2$，共 `1` 个三叶数。

## 样例2

**输入**

```
2
100 200
1000 2000
```

**输出**

```
2
3
```

**说明**

在 `[100,200]` 中，$11^2 = 121$ 和 $13^2 = 169$ 是三叶数，其余质数的平方不在该区间内，故有 `2` 个三叶数。
在 `[1000,2000]` 中，质数的平方有 $31^2 = 961$（小于 `1000`），$37^2 = 1369$，$41^2 = 1681$，$43^2 = 1849$，$47^2 = 2209$（大于 `2000`），因此落在区间内的三叶数为 $1369, 1681, 1849$，共 `3` 个。

## 样例3

**输入**

```
3
4 4
49 49
50 50
```

**输出**

```
1
1
0
```

**说明**

当区间退化为单个整数时：
- `[4,4]` 中的 `4` 是 $2^2$，为三叶数，输出 `1`。
- `[49,49]` 中的 `49` 是 $7^2$，为三叶数，输出 `1`。
- `[50,50]` 中的 `50` 不是质数的平方，因子个数多于 `3`，输出 `0`。
