# 题目内容
你正在整理一批编号依次为 $1$ 到 $n$ 的魔法符文。由于符文之间的共鸣规则，对于任意两个编号 $i$ 和 $j$（$i 
eq j$），若它们的最大公约数大于 $1$，则这两个符文不能使用相同的属性，否则会产生能量冲突。

你的任务是使用尽可能少的不同属性，为所有符文分配属性，并满足上述共鸣规则。请计算最少需要多少种不同的属性。

符文的编号数量 $n$ 不超过 `10^9`，且 $1 \le n \le 10^9$。

# 输入描述
第一行包含一个整数 $n$（$1 \le n \le 10^9$），表示符文的总数。

# 输出描述
输出一个整数，表示所需属性的最少种类数。

## 样例1

**输入**

```
1
```

**输出**

```
1
```

**说明**

只有 `1` 个符文，编号为 `1`。由于符文之间不存在不同的编号对，没有任何共鸣冲突，因此只需要 `1` 种属性即可满足要求。

## 样例2

**输入**

```
5
```

**输出**

```
2
```

**说明**

符文编号为 $1$ 到 $5$。其中偶数 $2, 4$ 的最大公约数为 $2 > 1$，不能使用相同属性，因此至少需要 $2$ 种属性。奇数 $1, 3, 5$ 与所有偶数的最大公约数均为 $1$，不会产生冲突，可以共用偶数的属性。所以最少属性数为 $\lfloor 5/2 \rfloor = 2$。

## 样例3

**输入**

```
8
```

**输出**

```
4
```

**说明**

偶数有 $2,4,6,8$，它们两两之间的最大公约数至少为 $2$，因此这 $4$ 个偶数构成一个完全图，需要 $4$ 种属性。奇数 $1,3,5,7$ 与偶数之间以及奇数之间的最大公约数均为 $1$（$3$ 与 $6$ 的公约数为 $3$，但 $3$ 与 $2,4,8$ 互质），可以分配到已有的 $4$ 种属性中，不会增加需求。因此答案为 $\lfloor 8/2 \rfloor = 4$。

## 样例4

**输入**

```
100
```

**输出**

```
50
```

**说明**

在 $1$ 到 $100$ 中，偶数共有 $\lfloor 100/2 \rfloor = 50$ 个。任意两个不同偶数的最小公约数至少为 $2$，它们之间必须使用不同属性，构成大小为 $50$ 的团。奇数可以通过与偶数共用属性而不产生新的冲突。因此最少需要的属性数量即为 $50$。
