# 题目内容
给定长度为 $n$ 的正整数数组 $a_1, a_2, \ldots, a_n$。你可以多次进行如下操作：选择一个尚未被删除的数 $x$，获得 $x$ 分，并删除数组中所有等于 $x$ 的数，同时删除所有等于 $x-1$ 或 $x+1$ 的数（被连带删除的数不得分）。已被删除的数不能再被选择。
你可以进行任意多次操作（也可以一次都不做），求能获得的最高总分。

约束条件：
- 数组长度 $n$ 不超过 $10^5$。
- 每个 $a_i$ 为正整数，且不超过 $10^5$。

# 输入描述
第一行包含一个正整数 $n$，表示数组长度。
第二行包含 $n$ 个正整数 $a_1, a_2, \ldots, a_n$。

# 输出描述
输出一个整数，表示能获得的最高总分。

## 样例1

**输入**

```
5
1 2 3 4 5
```

**输出**

```
9
```

**说明**

数 `1` 到 `5` 各出现一次。选择 `1,3,5`：得分为 $1+3+5=9$，相邻值被连带删除后不能再选。
选择 `2,4` 仅得 `6`。最高分为 `9`。

## 样例2

**输入**

```
6
7 9 4 3 5 7
```

**输出**

```
31
```

**说明**

值为 `7` 的数出现两次。选择全部 `7`（得分 `14`）、`9`（得分 `9`）、`5`（得分 `5`）与 `3`（得分 `3`）。
`4` 与 `5`、`3` 相邻，不能再选。总分为 $14+9+5+3=31$。

## 样例3

**输入**

```
4
2 2 2 2
```

**输出**

```
8
```

**说明**

所有数都等于 `2`，选择该值即可获得 $2 \times 4=8$ 分，没有相邻值会被连带删除。

## 样例4

**输入**

```
1
5
```

**输出**

```
5
```

**说明**

数组中只有一个数 `5`，选择它得到 `5` 分。
