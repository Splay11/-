# 题目内容
在实验室中，科学家记录了一种单细胞生物的分裂过程，形成了一个包含 $n$ 个细胞的谱系树，其结构是一棵二叉树。每个细胞都有一个从 $1$ 到 $n$ 的编号，并可能分裂出左子细胞和右子细胞。

定义一棵子树为“饱和谱系”，当且仅当该子树中每一代（层）的细胞数量都达到了该代的最大可能数量，即无法在同一层增加新的细胞。换言之，饱和谱系是一棵每个非叶子节点都有两个子节点且所有叶子节点深度相同的二叉树。

现在给定这棵细胞谱系树，请你计算有多少个细胞，满足以该细胞为根的子树是饱和谱系。

节点总数 $n$ 满足 $1 \le n \le 10^5$。

# 输入描述
第一行输入一个正整数 $n$，表示细胞的总数。
接下来的 $n$ 行，第 $i$ 行包含两个整数 $l_i$ 和 $r_i$，分别表示第 $i$ 个细胞的左子细胞编号和右子细胞编号。若某个子细胞不存在，则对应整数为 $-1$。
这些关系构成一棵二叉树，数据保证恰有一个细胞没有父细胞，即为树的根。

# 输出描述
输出一个整数，表示子树为饱和谱系的细胞数量。

## 样例1

**输入**

```
1
-1 -1
```

**输出**

```
1
```

**说明**

只有一个细胞 `1`，其左右子细胞均为 `-1`，即没有子细胞。
因此该细胞是叶子节点。根据饱和谱系（满二叉树）的定义，每个叶子节点自身构成一棵饱和谱系。
由题解算法，$dp[1] = 1$（叶子节点高度为 `1` 的满二叉树）。
最终统计 $dp[i] 
eq 0$ 的节点个数，得到答案 `1`。

## 样例2

**输入**

```
3
2 3
-1 -1
-1 -1
```

**输出**

```
3
```

**说明**

谱系树结构如下：
- 细胞 `1` 的左子为 `2`，右子为 `3`。
- 细胞 `2` 与 `3` 均为叶子（无子细胞）。

计算 $dp$ 值：
$dp[2] = 1$，$dp[3] = 1$（叶子节点）。
对于细胞 `1`，左右子细胞 $dp$ 值相等且不为 `0`，即 $dp[2] = dp[3] = 1$，因此 $dp[1] = dp[2] + 1 = 2$。
所有细胞的 $dp$ 均不为 `0`，故饱和谱系子树的数量为 `3`。

## 样例3

**输入**

```
5
2 3
-1 -1
4 5
-1 -1
-1 -1
```

**输出**

```
4
```

**说明**

树结构：
- 根 `1` 有左子 `2` 和右子 `3`。
- `2` 为叶子。
- `3` 有左子 `4` 和右子 `5`，均为叶子。

计算 $dp$：
$dp[2] = 1$，$dp[4] = 1$，$dp[5] = 1$。
对于 `3`，左右子 $dp$ 相等且不为 `0`，故 $dp[3] = dp[4] + 1 = 2$。
对于根 `1`，左子 $dp[2]=1$，右子 $dp[3]=2$，两者不相等，因此 $dp[1] = 0$，表示以 `1` 为根的子树不是饱和谱系。
统计 $dp[i] 
eq 0$ 的节点：`2`、`3`、`4`、`5` 共 `4` 个。

## 样例4

**输入**

```
7
2 3
4 5
6 7
-1 -1
-1 -1
-1 -1
-1 -1
```

**输出**

```
7
```

**说明**

这是一棵高度为 `3` 的完美满二叉树：
- 根 `1` 有左右子 `2` 和 `3`。
- `2` 有左右子 `4`、`5`；`3` 有左右子 `6`、`7`。
- 所有最底层细胞均为叶子。

递推 $dp$ 值：
第 `3` 层叶子节点 $dp = 1$（`4`、`5`、`6`、`7`）。
第 `2` 层节点 `2` 和 `3` 左右子 $dp$ 相等且不为 `0`，故 $dp[2] = dp[3] = 1 + 1 = 2$。
根 `1` 的左子 $dp[2]=2$ 与右子 $dp[3]=2$ 相等，故 $dp[1] = 2 + 1 = 3$。
所有 $7$ 个细胞的 $dp 
eq 0$，即每一个子树都是饱和谱系，答案为 `7`。
