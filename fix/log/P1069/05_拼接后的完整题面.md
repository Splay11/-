# 题目内容
装配线旁从左到右摆了 $n$ 种物料，第 $i$ 种标价为偶数 $a_i$，带来的装配收益为 $b_i$。采购员必须按从左到右的顺序决定买或不买，总花费不能超过预算 $x$。

若某件按原价买入，则其右侧相邻下一件可以选择半价；若某件按半价买入，则右侧下一件不能再半价，只能原价买或放弃。未购买的物料不会把半价资格传给更右侧。第一件不能半价。

请计算花费不超过 $x$ 时能获得的最大收益之和。若一件都买不起，答案为 `0`。

约束：$1 \le n,x,a_i \le 10^3$，$1 \le b_i \le 1000000000$，且所有 $a_i$ 均为偶数。

# 输入描述
第一行包含两个正整数 $n$ 和 $x$，分别表示物料种数与预算，满足 $1 \le n,x \le 10^3$。

第二行包含 $n$ 个正偶数 $a_1, a_2, \ldots, a_n$，表示标价，满足 $1 \le a_i \le 10^3$。

第三行包含 $n$ 个正整数 $b_1, b_2, \ldots, b_n$，表示收益，满足 $1 \le b_i \le 1000000000$。

# 输出描述
输出一个整数，表示不超过预算时能获得的最大收益之和。

## 样例1

**输入**

```
4 12
2 8 4 6
3 5 7 4
```

**输出**

```
15
```

**说明**

一种最优方案是：第 `1` 件原价购买（花费 `2`，收益 `3`），第 `2` 件半价购买（花费 `4`，收益 `5`），第 `3` 件原价购买（花费 `4`，收益 `7`）。

总花费 `10`，总收益 `15`。

## 样例2

**输入**

```
1 5
6
9
```

**输出**

```
0
```

**说明**

仅有一件商品，标价 `6` 超过预算 `5`，且第一件不能半价，无法购买，答案为 `0`。

## 样例3

**输入**

```
3 20
10 10 10
1 2 3
```

**输出**

```
5
```

**说明**

购买第 `2` 件原价（`10`）和第 `3` 件半价（`5`），花费 `15`，收益 $2+3=5$。

这是预算 `20` 下的最大收益。

## 样例4

**输入**

```
2 6
4 4
10 10
```

**输出**

```
20
```

**说明**

第 `1` 件原价、第 `2` 件半价，花费 $4+2=6$，收益 $10+10=20$。
