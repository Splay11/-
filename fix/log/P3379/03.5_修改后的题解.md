## 解题思路

一次操作会把某个字母在大小写之间切换。目标是恰好操作 $k$ 次后，大写字母尽可能多。

设初始大写个数为 $U$，小写个数为 $L=n-U$。把小写翻成大写会增加大写个数，把大写翻成小写会减少。

- 若 $k\le L$，优先把 $k$ 个小写翻成大写，答案为 $U+k$。
- 若 $k>L$，先把全部小写翻成大写，此时大写个数为 $n$，剩余 $r=k-L$ 次操作必须继续切换：
  - $r$ 为偶数时，可以成对地来回翻，答案仍为 $n$；
  - $r$ 为奇数时，最后必然多翻一次，答案为 $n-1$。

## 复杂度分析

扫描字符串统计大小写个数，之后 $O(1)$ 计算。

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(1)$。

## 代码实现

### Python

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if len(data) < 3:
        return
    n = int(data[0])
    k = int(data[1])
    s = data[2]

    U = sum(1 for c in s if 'A' <= c <= 'Z')
    L = n - U

    if k <= L:
        ans = U + k
    else:
        r = k - L
        ans = n if r % 2 == 0 else n - 1

    print(ans)

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        long n = Long.parseLong(st.nextToken());
        long k = Long.parseLong(st.nextToken());
        String s = br.readLine();

        long U = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c >= 'A' && c <= 'Z') U++;
        }
        long L = n - U;

        long ans;
        if (k <= L) {
            ans = U + k;
        } else {
            long r = k - L;
            ans = (r % 2 == 0) ? n : (n - 1);
        }
        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n, k;
    if (!(cin >> n >> k)) return 0;
    string s;
    cin >> s;

    long long U = 0;
    for (char c : s) {
        if ('A' <= c && c <= 'Z') ++U;
    }
    long long L = n - U;

    long long ans = 0;
    if (k <= L) {
        ans = U + k;
    } else {
        long long r = k - L;
        if (r % 2 == 0) ans = n;
        else ans = n - 1;
    }
    cout << ans << "\n";
    return 0;
}
```
