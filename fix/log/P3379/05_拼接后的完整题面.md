# 题目内容
给定一个仅由大小写英文字母构成、长度为 $n$ 的字符串 $s$。一次操作可以把某个字符在大小写之间切换一次（例如把 `a` 变成 `A`，或把 `Y` 变成 `y`）。

需要恰好进行 $k$ 次操作，使得最终字符串中大写字母的数量尽可能多。输出这个最大数量。

字符串长度不超过 $10^5$，操作次数不超过 $10^9$。

# 输入描述
第一行两个整数 $n$ 和 $k$，分别表示字符串长度和必须执行的操作次数。
第二行一个长度为 $n$、仅由大小写英文字母构成的字符串 $s$。
保证 $1 \le n \le 10^5$，$1 \le k \le 10^9$。

# 输出描述
输出一个整数，表示恰好 $k$ 次操作后大写字母个数的最大值。

## 样例1

**输入**

```
3 1
abc
```

**输出**

```
1
```

**说明**

三个小写。只需翻 `1` 次，把其中一个变成大写即可，答案为 `1`。

## 样例2

**输入**

```
4 10
AbCd
```

**输出**

```
4
```

**说明**

初始大写 `2`、小写 `2`。先把 `2` 个小写全部翻成大写，剩余 `8` 次为偶数，可成对抵消，答案为 `4`。

## 样例3

**输入**

```
5 1
AAAAA
```

**输出**

```
4
```

**说明**

全是大写，小写个数为 `0`。必须再翻 `1` 次（奇数），答案为 $5-1=4$。
