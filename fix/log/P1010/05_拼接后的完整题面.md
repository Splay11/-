# 题目内容
精密装配线上有 $n$ 个工位，第 $i$ 个工位的节拍读数为 $a_i$。工艺标准把序列称为 $g$ 节拍均衡：每一个长度为 $g$ 的连续工位段，读数之和都必须相等。每次校准只能把某一个工位的读数加 `1`，且最多校准 $d$ 次。请在完成均衡后，最大化所有工位读数中的最大值；若即使用完 $d$ 次校准也无法达到均衡，输出 `-1`。

约束：$1 \le n,d \le 10^5$，$1 \le g \le n$，$-1000000000 \le a_i \le 1000000000$。

# 输入描述
第一行三个整数 $n$、$g$、$d$，分别表示工位数、节拍长度以及校准次数上限。
第二行 $n$ 个整数 $a_1,a_2,\ldots,a_n$，表示各工位读数。
保证 $1 \le n,d \le 10^5$，$1 \le g \le n$，$-1000000000 \le a_i \le 1000000000$。

# 输出描述
输出一个整数：若无法在 $d$ 次校准内变成 $g$ 节拍均衡，输出 `-1`；否则输出完成后读数中的最大可能值。

## 样例1

**输入**

```
4 2 10
1 3 2 5
```

**输出**

```
8
```

**说明**

$g=`2`$ 时，下标模 `2` 相同的位置必须最终相等。

- 奇位 `[1,2]` 先齐到 `2`，花费 `1`；
- 偶位 `[3,5]` 先齐到 `5`，花费 `2`。

共花费 `3`，剩余 `7` 次。把剩余操作全部加到某一组，奇位最大到 $2+\lfloor 7/2 \rfloor=`5`$，偶位最大到 $5+\lfloor 7/2 \rfloor=`8`。答案取 `8`。

## 样例2

**输入**

```
3 3 5
1 8 4
```

**输出**

```
13
```

**说明**

$g=`3`$ 且 $n=`3`$，每组只有一个数，已经是 `3` 阶序列，花费 `0`。剩余 `5` 次可全部加到某一个数上，最大值为 $8+`5`=`13`。

## 样例3

**输入**

```
3 1 1
1 5 2
```

**输出**

```
-1
```

**说明**

$g=`1`$ 要求所有数最终相等。先齐到当前最大值 `5` 需要 $(5-1)+(5-2)=`7`$ 次，超过上限 `1`，输出 `-1`。

## 样例4

**输入**

```
5 2 4
2 6 4 6 3
```

**输出**

```
6
```

**说明**

奇位 `[2,4,3]` 齐到 `4` 花费 `3`，偶位已全是 `6`。剩余 `1` 次不足以再抬高任一组的整体值，序列最大仍为 `6`。
