# 题目内容
仓库里有 $n$ 个货箱，容量上限分别为 $h_i$，初始装满。容量降到 $0$ 及以下即视为清空。

有两种操作，均可使用任意次：
- 全局抽吸：消耗 $1$ 点能耗，使所有尚未清空的货箱容量各减 $1$；
- 定向清空：消耗 $2$ 点能耗，立即清空一个已经不满的货箱（当前容量严格小于其上限）。

请计算清空全部货箱所需的最少能耗。

货箱数量 $n$ 满足 $2 \le n \le 10^5$，每个上限 $h_i$ 满足 $1 \le h_i \le 10^9$。

# 输入描述
第一行输入一个整数 $n$，表示货箱数量，满足 $2 \le n \le 10^5$。
第二行输入 $n$ 个整数 $h_1, h_2, \dots, h_n$，表示各货箱的容量上限，满足 $1 \le h_i \le 10^9$。

# 输出描述
输出一个整数，表示清空全部货箱所需的最少能耗。

## 样例1

**输入**

```
3
1 1 4
```

**输出**

```
3
```

**说明**

先全局抽吸 $1$ 次，两个上限为 $1$ 的货箱被清空；再对剩余上限 $4$ 的货箱定向清空，费用 $2$。总能耗 $1+2=3$。
若一直抽吸到 $4$，费用为 $4$，更差。

## 样例2

**输入**

```
2
1 1
```

**输出**

```
1
```

**说明**

一次全局抽吸即可同时清空两个货箱，能耗 $1$。

## 样例3

**输入**

```
2
5 5
```

**输出**

```
5
```

**说明**

排序后枚举：抽吸 $5$ 次清空全部，费用 $5$；若只清空其中一个再定向清空另一个，费用不会更优。答案为 $5$。

## 样例4

**输入**

```
3
1 2 3
```

**输出**

```
3
```

**说明**

枚举抽吸次数对应排序后的上限：$1+4=5$、$2+2=4$、$3+0=3$，最小值为 $3$，即三次全局抽吸清空全部。
