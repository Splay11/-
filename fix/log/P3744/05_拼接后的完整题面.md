# 题目内容
小蓝在分析一个通信协议时，遇到了一个由若干简单因子连乘得到的代数表达式。该表达式形如 $E = (t + c_1)(t - c_2)(t + c_3) \cdots$ ，其中每个因子是 $(t + d)$ 或 $(t - d)$ 的形式，$d$ 是 `1` 到 `9` 之间的整数。

为了验证校验码，他需要计算将表达式 $E$ 完全展开并合并同类项后，$t$ 的线性项（即 $t^1$ 项）的系数。由于系数可能很大，请输出该系数对 `10007` 取模后的结果。

约束：
- 给定的字符串长度在 `5` 到 `10^5` 之间，且长度是 `5` 的倍数。
- 字符串严格由若干个形如 `(t+d)` 或 `(t-d)` 的子串拼接而成，其中 $d$ 为 `1` 到 `9` 的数字。
- 结果需要对 `10007` 取模。

# 输入描述
输入仅有一行，包含一个字符串 $s$，表示给定的乘积表达式。

# 输出描述
输出一个整数，表示展开后 $t$ 的一次项系数对 `10007` 取模的结果。

## 样例1

**输入**

```
(t+7)
```

**输出**

```
1
```

**说明**

表达式仅有一个因子 $(t+7)$，展开后即为 $t+7$。其中 $t$ 的系数为 `1`，对 `10007` 取模后仍为 `1`。

## 样例2

**输入**

```
(t-1)(t+1)
```

**输出**

```
0
```

**说明**

表达式为 $(t-1)(t+1)$，展开得到 $t^2 - 1$，不包含 $t$ 的一次项，因此一次项系数为 `0`。对 `10007` 取模后结果依然为 `0`。

## 样例3

**输入**

```
(t+1)(t+2)(t+3)
```

**输出**

```
11
```

**说明**

三个因子相乘：$(t+1)(t+2)(t+3)$。
先计算 $(t+1)(t+2)=t^2+3t+2$，再乘以 $(t+3)$：
$(t^2+3t+2)(t+3)=t^3+3t^2+3t^2+9t+2t+6=t^3+6t^2+11t+6$。
其中 $t$ 的一次项系数为 `11`，模 `10007` 后输出 `11`。

## 样例4

**输入**

```
(t-1)(t+2)(t-3)(t+4)
```

**输出**

```
9993
```

**说明**

四个因子分别为 $(t-1)$、$(t+2)$、$(t-3)$、$(t+4)$。
记 $c_1=-1,\ c_2=2,\ c_3=-3,\ c_4=4$。
展开后一次项系数等于依次相乘时的递推结果，我们逐步计算：
初始常数项 $p_0=1$，一次项系数 $p_1=0$。
乘 $(t-1)$：$p_0' = p_0\times (-1) = -1$，$p_1' = p_0 + p_1\times (-1) = 1$。
乘 $(t+2)$：$p_0' = -1\times 2 = -2$，$p_1' = -1 + 1\times 2 = 1$。
乘 $(t-3)$：$p_0' = -2\times (-3) = 6$，$p_1' = -2 + 1\times (-3) = -5$。
乘 $(t+4)$：$p_0' = 6\times 4 = 24$，$p_1' = 6 + (-5)\times 4 = -14$。
最终一次项系数为 $-14$。
对 `10007` 取模：$-14 \equiv 10007 - 14 = 9993 \pmod{10007}$。因此输出 `9993`。
