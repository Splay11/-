# 题目内容
传送带上依次放着 $n$ 个货箱，第 $i$ 个货箱的重量为 $w_i$。需要取出一段连续的货箱，使得重量之和至少为 $k$，并希望取出的货箱个数尽可能少。

请输出这段连续货箱的最短长度。数据保证存在至少一段连续货箱，其重量之和不小于 $k$。

约束：$n$ 与 $k$ 均为正整数，每个货箱重量为正整数且不超过 `10`。

# 输入描述
第一行一个正整数 $n$，表示货箱个数。
第二行一个正整数 $k$，表示重量下限。
接下来 $n$ 行，每行一个正整数，依次给出各货箱的重量（均不超过 `10`）。

# 输出描述
输出一个整数，表示满足重量之和至少为 $k$ 的最短连续段长度。

## 样例1

**输入**

```
2
10
10
1
```

**输出**

```
1
```

**说明**

第一个货箱重量已等于 $k=`10`$，长度为 `1` 的窗口即可。这是最短窗口为单箱的情形。

## 样例2

**输入**

```
3
6
1
2
3
```

**输出**

```
3
```

**说明**

三段之和 $1+2+3=`6`$ 恰好等于 $k$，长度为 `3`；前缀 $1+2=`3`$、后缀 $2+3=`5`$ 都不足。答案为 `3`。

## 样例3

**输入**

```
2
10
10
2
```

**输出**

```
1
```

**说明**

按题意模拟计算得到。
