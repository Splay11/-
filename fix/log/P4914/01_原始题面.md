# 题目内容
一架无人机沿着海岸线飞行，记录下沿途 $n$ 个测量点的海拔高度 $h_1, h_2, \dots, h_n$。现有一个平稳性阈值 $d$。
定义一段连续的测量点 $[l, r]$ 为“平飞段”，当且仅当对任意 $i \in [l, r-1]$ 都满足 $|h_{i+1} - h_i| \le d$。换句话说，相邻两点的海拔变化幅度不超过 $d$。
请你找出所有平飞段中最长的一段长度。

共有 $T$ 组独立的飞行记录。对于每组数据，保证测量点个数 $n$ 不超过 $2 	imes 10^5$，所有组 $n$ 的总和也不超过 $2 	imes 10^5$；阈值 $d$ 为 $0$ 到 $10^9$ 之间的整数；每个海拔高度的绝对值不超过 $10^9$。

# 输入描述
第一行输入一个整数 $T$，表示测试数据组数。
每组测试数据占两行：
第一行包含两个整数 $n$ 和 $d$，分别表示测量点数量和阈值。
第二行包含 $n$ 个整数 $h_1, h_2, \dots, h_n$，表示依次记录的海拔高度。

# 输出描述
对于每组测试数据，输出一行一个整数，表示最长平飞段的长度。

## 样例1

**输入**

```
1
6 2
1 3 2 4 6 8
```

**输出**

```
6
```

**说明**

相邻高度差依次为：$|3-1|=2 \le d$，$|2-3|=1 \le d$，$|4-2|=2 \le d$，$|6-4|=2 \le d$，$|8-6|=2 \le d$，全部不超过阈值 $d=2$，因此整个序列均为平飞段，最长长度为 `6`。

## 样例2

**输入**

```
2
4 1
1 3 2 5
3 0
2 2 3
```

**输出**

```
2
2
```

**说明**

第一组：$|3-1|=2 > 1$ 断开；$|2-3|=1 \le 1$ 延伸；$|5-2|=3 > 1$ 断开，最长平飞段为 `[2,3]`，长度 `2`。第二组：$|2-2|=0 \le 0$ 延伸；$|3-2|=1 > 0$ 断开，最长平飞段为 `[1,2]`，长度 `2`。

## 样例3

**输入**

```
1
1 10
100
```

**输出**

```
1
```

**说明**

仅有一个测量点，不存在相邻点，可视为长度为 `1` 的平飞段，答案为 `1`。
