# 题目内容
市档案馆新上线了一套卷宗编号清洗程序。每份卷宗的编号是一条长度为 $n$、仅由大小写英文字母构成的字符串 $s$（下标从 `1` 开始）。清洗必须按下面两步顺序全部做完，不能跳过。

第一步从左到右依次处理每个位置：若 $s_i$ 是小写字母，把它换成字母表中的循环前驱（`'a'` 的循环前驱为 `'z'`）；若是大写字母，把它换成循环后继（`'Z'` 的循环后继为 `'A'`）。第二步在全部替换完成后，从右到左依次处理每个位置：若该字符不是当前串的最后一个字符，且它右侧紧邻字符与它是同字母异大小写，则删除该字符。每次删除后剩余字符按原顺序拼接，继续向左判断，直到处理完毕。

同字母异大小写：忽略大小写后相同，且一个小写、一个大写，例如 `'a'` 与 `'A'`。请输出清洗结束后的字符串。

约束：字符串长度不超过 `200000`。

# 输入描述
第一行一个整数 $n$，表示卷宗编号的长度。
第二行一个长度为 $n$ 的字符串 $s$，仅由大小写英文字母构成。
保证 $1 \le n \le 200000$。

# 输出描述
输出一行字符串，表示清洗后的结果。

## 样例1

**输入**

```
1
a
```

**输出**

```
z
```

**说明**

长度为 `1`，只有字符 `'a'`。

第一步：小写循环前驱，`'a'` 变成 `'z'`。

第二步：它已是最后一个字符，不会被删除，结果为 `z`。

## 样例2

**输入**

```
4
dBcY
```

**输出**

```
CbZ
```

**说明**

初始串为 `dBcY`。

第一步替换：`'d'\to'c'`，`'B'\to'C'`，`'c'\to'b'`，`'Y'\to'Z'`，得到 `cCbZ`。

第二步从右向左：右端 `'Z'` 保留；`'b'` 与 `'Z'` 不同字母，保留；`'C'` 与 `'b'` 不同字母，保留；最左 `'c'` 与右邻 `'C'` 同字母异大小写，删除。最终为 `CbZ`。

## 样例3

**输入**

```
3
XyY
```

**输出**

```
YxZ
```

**说明**

第一步：`'X'\to'Y'`，`'y'\to'x'`，`'Y'\to'Z'`，得到 `YxZ`。

第二步从右向左，相邻均不同字母，全部保留，结果为 `YxZ`。
