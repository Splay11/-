# 题目内容
港口调度中心把一天内的靠泊计划记成 $n$ 段占用。第 $i$ 段覆盖闭区间 $[l_i, r_i]$（端点计入）。两艘船的占用时段一旦相交，就不能同时使用同一泊位，调度员需要事先清点这样的冲突对。

两段不同占用 $u$ 与 $v$（$u 
e v$）发生冲突，当且仅当它们的覆盖区间有交集，即

$\min(r_u, r_v) \ge \max(l_u, l_v)$。

请统计有多少对占用发生冲突。

约束：占用段数 $n$ 满足 $1 \le n \le 100000$，端点满足 $0 \le l_i \le r_i \le 1000000000$。

# 输入描述
第一行一个整数 $n$，表示占用段数。
接下来 $n$ 行，第 $i$ 行两个整数 $l_i$ 和 $r_i$，表示第 $i$ 段占用的左右端点。
保证 $1 \le n \le 100000$，$0 \le l_i \le r_i \le 1000000000$。

# 输出描述
输出一个整数，表示发生冲突的占用对数。

## 样例1

**输入**

```
4
0 10
11 20
5 15
21 21
```

**输出**

```
2
```

**说明**

四段预约为 $[0,10]$、$[11,20]$、$[5,15]$、$[21,21]$。
有交集的只有 $[0,10]$ 与 $[5,15]$，以及 $[11,20]$ 与 $[5,15]$，共 `2` 对。

## 样例2

**输入**

```
3
0 0
0 0
1 2
```

**输出**

```
1
```

**说明**

两段 $[0,0]$ 彼此相交；它们与 $[1,2]$ 都不交。答案为 `1`。

## 样例3

**输入**

```
6
10 20
15 25
30 40
35 45
50 60
0 100
```

**输出**

```
7
```

**说明**

局部三对冲突：$[10,20]$ 与 $[15,25]$、$[30,40]$ 与 $[35,45]$。
另有覆盖全局的 $[0,100]$ 与前五段都相交，再加 `2` 对局部，共 `7` 对。
