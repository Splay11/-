# 题目内容
有 $n$ 片区域和 $m$ 条光缆，区域编号从 $1$ 到 $n$。每条光缆连接两片区域，并带有一个收益值。部分光缆被标记为“可拆除”（标记为 `1`），拆除它们可以获得其收益值；其余光缆被标记为“不可拆除”（标记为 `0`），必须保留。

初始时所有光缆完好，整个网络是连通的。你可以选择拆除若干条可拆除光缆，每拆除一条便获得对应的收益。拆除光缆后，网络可能会分裂为若干个孤岛（即连通块）。

现在需要你为每一个 $k = 1, 2, \dots, n$ 回答：在最终孤岛数量**不超过** $k$ 的条件下，最多能获得的总收益是多少。

数据范围：区域数 $n$ 与光缆数 $m$ 均不超过 $10^5$，收益值 $w$ 满足 $1 \le w < 10^9$。每条光缆的标记 $c$ 为 $0$ 或 $1$。保证没有自环和重边，且初始网络连通。

# 输入描述
第一行包含两个整数 $n$ 和 $m$，表示区域数量和光缆数量。
接下来 $m$ 行，每行四个整数 $u, v, w, c$，表示一条光缆连接区域 $u$ 和 $v$，收益值为 $w$，标记为 $c$。其中 $c = 1$ 表示可拆除，$c = 0$ 表示不可拆除。

# 输出描述
输出一行包含 $n$ 个整数，第 $i$ 个整数表示当要求最终孤岛数量不超过 $i$ 时，最多可以获得的收益总和。

## 样例1

**输入**

```
3 3
1 2 10 1
2 3 5 0
1 3 8 1
```

**输出**

```
10 18 18
```

**说明**

不可拆除的光缆仅有 $(2,3)$，收益为 $5$。仅保留该光缆时，连通块数为 $C_0 = 2$（区域 $1$ 孤立，区域 $2,3$ 连通）。所有可拆除光缆的总收益 $S = 10 + 8 = 18$。
- 当 $k = 1$ 时，要求连通块数不超过 $1$，必须从可拆除光缆中保留一条将区域 $1$ 与 $\{2,3\}$ 连接。最小保留代价为选择收益为 $8$ 的光缆 $(1,3)$，因此最大拆除收益为 $18 - 8 = 10$。
- 当 $k \ge 2$ 时，连通块数限制已经不低于 $C_0$，可以拆除所有可拆除光缆，获得全部收益 $18$。
因此对应 $k = 1, 2, 3$ 的输出依次为 `10`, `18`, `18`。

## 样例2

**输入**

```
4 4
1 2 3 1
2 3 2 0
3 4 1 1
4 1 4 1
```

**输出**

```
4 7 8 8
```

**说明**

不可拆除的光缆为 $(2,3)$，收益 $2$。仅保留它时，连通块共 $3$ 个：$\{1\}$、$\{2,3\}$、$\{4\}$。可拆除总收益 $S = 3+1+4 = 8$。
为了减少连通块数量，需要选择可拆除光缆进行保留：
- 合并 $\{2,3\}$ 与 $\{4\}$ 的最小代价为光缆 $(3,4)$，收益 $1$。
- 合并剩余部分与 $\{1\}$ 的最小代价为光缆 $(1,2)$，收益 $3$。
若 $k = 3$，不需合并，收益 $8$。
若 $k = 2$，需合并一次，代价 $1$，收益 $8-1=7$。
若 $k = 1$，需合并两次，总代价 $1+3=4$，收益 $8-4=4$。
$k=4$ 时同样无需合并，收益 $8$。
答案为 `4`, `7`, `8`, `8`。

## 样例3

**输入**

```
2 1
1 2 100 1
```

**输出**

```
0 100
```

**说明**

仅有一条可拆除光缆，总收益 $S = 100$。没有不可拆除光缆，因此仅保留不可拆除光缆时连通块数 $C_0 = 2$。
- $k = 1$：必须保留该光缆以保持连通，拆除收益为 $0$。
- $k = 2$：可以拆除，获得全部收益 $100$。
输出依次对应 $k=1,2$ 的结果 `0` 和 `100`。
