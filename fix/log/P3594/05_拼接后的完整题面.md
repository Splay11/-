# 题目内容
给定一个正整数 $H$，请你构造一条开口向上的抛物线 $y = p x^2 + q x + r$，使得该抛物线最低点的纵坐标恰好等于 $H$。

你需要输出三个整数 $p,q,r$ 作为抛物线的系数。要求 $-2 \times 10^9 \le p,q,r \le 2 \times 10^9$ 且 $p 
eq 0$。

数据范围与约定：测试数据组数 $T$ 满足 $1 \le T \le 10^4$，每组数据中的 $H$ 均为正整数且 $H \le 10^9$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据组数。
接下来 $T$ 行，每行包含一个正整数 $H$，表示目标最低点的纵坐标。

# 输出描述
对于每组数据，输出一行三个整数 $p,q,r$，用空格分隔，表示所构造抛物线的系数。

## 样例1

**输入**

```
1
5
```

**输出**

```
1 0 5
```

**说明**

取 $p = 1, q = 0$，此时抛物线为 $y = x^2 + 5$。最低点横坐标为 $0$，纵坐标为 $5$，恰好等于 $H = 5$。系数均在 $[-2 \times 10^9, 2 \times 10^9]$ 范围内。

## 样例2

**输入**

```
1
7
```

**输出**

```
2 4 9
```

**说明**

取 $p = 2, q = 4$。抛物线 $y = 2x^2 + 4x + 9$ 的顶点横坐标为 $-\frac{q}{2p} = -1$，纵坐标为 $r - \frac{q^2}{4p} = 9 - \frac{16}{8} = 7$，恰好等于 $H = 7$。所有系数均处于 $[-2 \times 10^9, 2 \times 10^9]$ 之间，且 $p 
eq 0$。

## 样例3

**输入**

```
1
1000000000
```

**输出**

```
1 0 1000000000
```

**说明**

取 $p = 1, q = 0, r = H = 10^9$。抛物线 $y = x^2 + 10^9$ 的最低点为 $(0, 10^9)$，纵坐标恰好等于 $H = 10^9$。所有值均未超过 $2 \times 10^9$ 的限制。
