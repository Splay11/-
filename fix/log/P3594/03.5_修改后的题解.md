## 解题思路

1. 对于开口向上的抛物线 $y = p x^2 + q x + r$，其最低点的纵坐标即为顶点的函数值。  
2. 利用顶点式 $y = p(x - h)^2 + k$，顶点坐标为 $(h, k)$。若取 $h = 0$，则顶点位于 $x=0$ 处，最低点纵坐标恰好为 $k$。  
3. 将 $h=0$ 的顶点式展开：$y = p x^2 + k$，与一般式对比可得 $q = 0$，$r = k$。为保证开口向上，只需 $p > 0$。  
4. 对于给定的目标高度 $H$，取最简单的一组构造：$p = 1$，$q = 0$，$r = H$，即抛物线 $y = x^2 + H$。  
   - $p = 1 \neq 0$，开口向上；  
   - 系数范围满足 $-2 \times 10^9 \le p,q,r \le 2 \times 10^9$（因为 $1 \le H \le 10^9$）；  
   - 构造在每轮测试中仅需常数时间。  
5. 对每组数据的 $H$，直接输出 `1 0 H` 即可。

## 复杂度分析

- 时间复杂度：每组数据只需 $O(1)$ 次输出，总时间复杂度 $O(T)$。  
- 空间复杂度：仅使用常数额外空间，$O(1)$。

## 代码实现

### Python

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    t = int(data[0])
    out = []
    # 从 data[1] 开始依次为每组数据的 H
    for i in range(1, t + 1):
        H = int(data[i])
        out.append(f"1 0 {H}")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        String line = br.readLine();
        if (line == null || line.trim().isEmpty()) {
            System.out.print("");
            return;
        }
        int T = Integer.parseInt(line.trim());
        for (int i = 0; i < T; i++) {
            String hLine = br.readLine();
            // 跳过可能的空行
            while (hLine != null && hLine.trim().isEmpty()) {
                hLine = br.readLine();
            }
            int H = Integer.parseInt(hLine.trim());
            sb.append("1 0 ").append(H).append("\n");
        }
        System.out.print(sb);
    }
}
```
