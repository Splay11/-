## 解题思路

枚举进制 $B=2,3,\ldots,36$，把 $n$ 按 $B$ 进制逐位取余。每一位余数 $z$ 写成十进制字符串后，统计其中字符 `1` 的个数并累加；再在所有进制上取最大值。

由于 $n \le 3\times 10^5$，每个进制下的位数为 $O(\log n)$，直接模拟即可。

## 复杂度分析

- 时间复杂度：$O(35\log n)$。
- 空间复杂度：$O(1)$。

## 代码实现

### Python

```python
n = int(input())
ans = 0
for b in range(2, 37):
    t, cnt = n, 0
    while t:
        z = t % b
        cnt += str(z).count('1')
        t //= b
    ans = max(ans, cnt)
print(ans)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int ans = 0;
        for (int b = 2; b <= 36; b++) {
            int t = n, cnt = 0;
            while (t > 0) {
                int z = t % b;
                cnt += String.valueOf(z).chars().filter(ch -> ch == '1').count();
                t /= b;
            }
            ans = Math.max(ans, cnt);
        }
        System.out.println(ans);
        sc.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    int ans = 0;
    for (int b = 2; b <= 36; b++) {
        int t = n, cnt = 0;
        while (t) {
            int z = t % b;
            string s = to_string(z);
            cnt += count(s.begin(), s.end(), '1');
            t /= b;
        }
        ans = max(ans, cnt);
    }
    cout << ans << endl;
    return 0;
}
```
