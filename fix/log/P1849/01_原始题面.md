# 题目描述

工程师顾言正在研究一种多进制编码系统。

对于大于 $10$ 的数码，系统沿用常见的表示方式：用 `a` 表示 $10$，`b` 表示 $11$，依此类推，直到 `z` 表示 $35$。因此，系统可以使用 $2$ 进制到 $36$ 进制表示一个正整数。

现在给定一个十进制正整数 $n$。顾言会分别将它转换成 $2,3,\ldots,36$ 进制，并统计每种进制表示中字符 `1` 出现的次数。

请你求出，在所有这些进制表示中，字符 `1` 最多能够出现多少次。

例如，十进制数 $4$ 在二进制下表示为 $(100)_2$，其中只出现了一个 `1`；而在三进制下表示为 $(11)_3$，其中出现了两个 `1`。

# 输入描述

在一行中输入一个整数 $n$（$1\leq n\leq3\times10^5$），表示给定的十进制正整数。

# 输出描述

输出一个整数，表示 $n$ 在 $2$ 到 $36$ 进制的所有表示中，字符 `1` 出现次数的最大值。

# 样例 1

**输入**

```text
13
```

**输出**

```text
3
```

**说明**

$13$ 在三进制下表示为

$$
(111)_3
$$

其中共有 $3$ 个 `1`，因此答案为 $3$。

# 样例 2

**输入**

```text
40
```

**输出**

```text
4
```

**说明**

$40$ 在三进制下表示为

$$
(1111)_3
$$

其中共有 $4$ 个 `1`，因此答案为 $4$。
