# 题目内容
编码系统可以把一个十进制正整数写成 $2$ 到 $36$ 进制。对于大于 `9` 的数码，沿用常见写法：`a` 表示 `10`，`b` 表示 `11`，依此类推，直到 `z` 表示 `35`。

给定十进制正整数 $n$。把它分别转换成 $2,3,\ldots,36$ 进制后，统计每种表示里字符 `1` 出现的次数，求这些次数的最大值。

例如 $n=4$ 的二进制是 $(100)_2$，只含 `1` 个字符 `1`；三进制是 $(11)_3$，含 `2` 个字符 `1`。

$n$ 不超过 `3×10^5`。

# 输入描述
在一行中输入一个整数 $n$（$1 \le n \le 3 \times 10^5$），表示给定的十进制正整数。

# 输出描述
输出一个整数，表示 $n$ 在 $2$ 到 $36$ 进制的所有表示中，字符 `1` 出现次数的最大值。

## 样例1

**输入**

```
1
```

**输出**

```
1
```

**说明**

$n=1$ 在任意进制下都是单个数码 `1`，最大次数为 `1`。

## 样例2

**输入**

```
4
```

**输出**

```
2
```

**说明**

二进制 $(100)_2$ 含 `1` 个 `1`；三进制 $(11)_3$ 含 `2` 个 `1`。最大值为 `2`。

## 样例3

**输入**

```
2
```

**输出**

```
1
```

**说明**

按题意模拟计算得到。
