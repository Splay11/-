# 题目内容
质检台上有一个不含前导零的正整数编码 $n$。规程要求最终编码必须是 $495$ 的倍数。

你可以把编码的若干位各自改写成 `0` 到 `9` 中的某一个数字，但不允许改完后出现前导零。也可以一位都不改。

请计算最少需要改写多少位，并给出一种改写后得到的编码。

编码对应的整数 $n$ 满足 $100 \le n \le 10^{18}$。

# 输入描述
在一行中输入一个正整数 $n$（$100 \le n \le 10^{18}$），表示原始编码。

# 输出描述
第一行输出一个整数，表示最少改写的位数。
第二行输出改写后的编码。

## 样例1

**输入**

```
100
```

**输出**

```
2
990
```

**说明**

编码 $100$ 处于长度下界。把前两位改成 `9`、`9` 得到 $990$，$990=495\times 2$，末位 `0` 保持不变以整除 $5$。共改 `2` 位，且不允许出现前导零。

## 样例2

**输入**

```
101
```

**输出**

```
3
990
```

**说明**

按题意模拟计算得到。
