# 题目内容
定义一个长度为 $n$ 的排列（$1 \sim n$ 的排列）的“活跃位置”如下：对于位置 $i$（$1 \le i < n$），若存在某个位置 $j$ 满足 $i < j \le n$ 且 $a_i > a_j$，则称 $i$ 是活跃的。

现在给出一个排列 $p$，请你构造另一个排列 $q$，要求 $q$ 与 $p$ 不同，但它们的活跃位置个数完全相同。若不存在这样的 $q$，则说明无解。

约束条件：
- 测试数据组数不超过 $10^4$。
- 每组排列的长度 $n$ 不超过 $2 \times 10^5$，且所有数据的 $n$ 总和不超过 $2 \times 10^5$。
- $p$ 是 $1$ 到 $n$ 的一个排列。

# 输入描述
第一行包含一个整数 $T$（$1 \le T \le 10^4$），表示测试数据的组数。
接下来对于每组数据：
第一行包含一个整数 $n$（$1 \le n \le 2 \times 10^5$），表示排列的长度。
第二行包含 $n$ 个整数 $p_1, p_2, \dots, p_n$（$1 \le p_i \le n$），表示给定的排列，保证是一个排列。

# 输出描述
对于每组测试数据：
- 若可以构造出满足条件的排列 $q$，则先输出一行 `YES`，接着在下一行输出 $n$ 个整数，表示构造出的排列 $q$（任意一组合法解均可）。
- 若无法构造，则输出一行 `NO`。

## 样例1

**输入**

```
1
1
1
```

**输出**

```
NO
```

**说明**

当 $n = 1$ 时，唯一的排列是 $[1]$。由于要求构造的排列 $q$ 必须与 $p$ 不同，但不存在其他排列，因此无解。

## 样例2

**输入**

```
1
2
1 2
```

**输出**

```
NO
```

**说明**

当 $n = 2$ 时，可能的排列只有 $[1, 2]$ 和 $[2, 1]$。
在 $p = [1, 2]$ 中，位置 $1$ 后面的数字是 $2$，没有比 $1$ 更小的数字，所以活跃位置个数为 $0$。
在另一个排列 $[2, 1]$ 中，位置 $1$ 后面的数字是 $1$，满足 $2 > 1$，因此活跃位置个数为 $1$。
两者的活跃位置个数不同，故无法构造出满足条件的排列 $q$。

## 样例3

**输入**

```
1
4
2 1 3 4
```

**输出**

```
YES
1 3 2 4
```

**说明**

给定排列 $p = [2, 1, 3, 4]$：
- 位置 $1$：存在 $j = 2$ 使得 $2 > 1$，活跃。
- 位置 $2$：后面的数字为 $3, 4$，没有比 $1$ 小的数，不活跃。
- 位置 $3$：后面的数字为 $4$，没有比 $3$ 小的数，不活跃。
活跃位置个数为 $1$。
构造排列 $q = [1, 3, 2, 4]$：
- 位置 $1$：后面的数字均大于 $1$，不活跃。
- 位置 $2$：存在 $j = 3$ 使得 $3 > 2$，活跃。
- 位置 $3$：后面为 $4$，没有比 $2$ 小的数，不活跃。
活跃位置个数也为 $1$，且 $q 
eq p$，满足要求。

## 样例4

**输入**

```
1
5
3 1 4 2 5
```

**输出**

```
YES
2 1 4 3 5
```

**说明**

给定排列 $p = [3, 1, 4, 2, 5]$：
- 位置 $1$：存在 $j = 2$ 使 $3 > 1$，活跃。
- 位置 $2$：后面为 $4, 2, 5$，没有比 $1$ 小的数，不活跃。
- 位置 $3$：存在 $j = 4$ 使 $4 > 2$，活跃。
- 位置 $4$：后面为 $5$，没有比 $2$ 小的数，不活跃。
活跃位置个数为 $2$。
构造排列 $q = [2, 1, 4, 3, 5]$：
- 位置 $1$：存在 $j = 2$ 使 $2 > 1$，活跃。
- 位置 $2$：后面均大于 $1$，不活跃。
- 位置 $3$：存在 $j = 4$ 使 $4 > 3$，活跃。
- 位置 $4$：后面为 $5$，没有比 $3$ 小的数，不活跃。
活跃位置个数也为 $2$，且 $q 
eq p$，满足要求。
