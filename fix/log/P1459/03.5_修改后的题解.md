## 解题思路

先求出 $s$ 的字母表 $S$。

- 若 $|S|=1$，每一位只能填这一种字母，无法与原串对应位不同，输出 `-1`。
- 若 $|S|\ge 2$，一定能构造。为了保证 $t$ 用到 $S$ 中的每一个字母，按从左到右的顺序，优先把尚未在 $t$ 中出现过、且与 $s_i$ 不同的字母放到当前位置，用过后从“尚未使用”集合中删去。若集合里已经找不到与 $s_i$ 不同的字母，则在字母表里任取两个不同字母中那个不等于 $s_i$ 的即可。

这样每个字母至少出现一次，且每一位都与 $s$ 不同。

## 复杂度分析

时间复杂度 $O(n\cdot |\Sigma|)$，其中 $|\Sigma|\le 26$。空间复杂度 $O(|\Sigma|)$。

## 代码实现

### Python

```python
def main():
    s = input()
    ch = set()
    for i in s:
        ch.add(i)
    if len(ch) == 1:
        print("-1")
        return
    lst = list(ch)
    ans = []
    for i in s:
        flag = False
        for j in ch:
            if j != i:
                ans.append(j)
                ch.remove(j)
                flag = True
                break
        if not flag:
            if lst[0] != i:
                ans.append(lst[0])
            else:
                ans.append(lst[1])
    print("".join(ans))


main()
```

### Java

```java
import java.util.HashSet;
import java.util.Scanner;
import java.util.Set;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String s = scanner.nextLine();
        Set<Character> ch = new HashSet<>();
        for (char c : s.toCharArray()) ch.add(c);
        if (ch.size() == 1) {
            System.out.println("-1");
            return;
        }
        char[] lst = new char[ch.size()];
        int index = 0;
        for (char c : ch) lst[index++] = c;
        StringBuilder ans = new StringBuilder();
        for (char c : s.toCharArray()) {
            boolean flag = false;
            for (char j : ch) {
                if (j != c) {
                    ans.append(j);
                    ch.remove(j);
                    flag = true;
                    break;
                }
            }
            if (!flag) {
                if (lst[0] != c) ans.append(lst[0]);
                else ans.append(lst[1]);
            }
        }
        System.out.println(ans.toString());
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    unordered_set<char> ch;
    for (char c : s) ch.insert(c);
    if (ch.size() == 1) {
        cout << "-1\n";
        return 0;
    }
    vector<char> lst(ch.begin(), ch.end());
    string ans;
    for (char c : s) {
        bool flag = false;
        for (char j : ch) {
            if (j != c) {
                ans.push_back(j);
                ch.erase(j);
                flag = true;
                break;
            }
        }
        if (!flag) {
            if (lst[0] != c) ans.push_back(lst[0]);
            else ans.push_back(lst[1]);
        }
    }
    cout << ans << "\n";
    return 0;
}
```
