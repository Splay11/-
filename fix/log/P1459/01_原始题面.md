# 题目内容

小红有一个长度为 $n$ 的字符串 $s$ ，定义一个字符串的字符集为字符串中所有不同的字符构成的集合。

小红想让你构造出一个新的字符串 $t$ ，满足 $t$ 的字符集和 $s$ 的字符集相同，但是 $s_i \neq t_i (0\leq i < n)$ 。

如果可以构造出来，请输出任意一个满足条件的字符串 $t$ ，否则输出 $-1$ 。

# 输入描述

一行，一个字符串 $s$ ，该字符串中的字符只包括小写字母。

# 输出描述

如果可以构造出 $t$ ，则输出 $t$ ，否则输出 $-1$

# 样例

**输入**

```
aabbccdd
```

**输出**

```
bbccddaa
```
