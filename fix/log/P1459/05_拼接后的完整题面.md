# 题目内容
给定一个只由小写英文字母组成的字符串 $s$。定义一个字符串的字母表为其中出现过的所有不同字符构成的集合。

请构造一个与 $s$ 等长的字符串 $t$，满足：$t$ 的字母表与 $s$ 的字母表相同，且对每一个位置 $i$ 都有 $t_i 
eq s_i$。

若可以构造，输出任意一个合法的 $t$；否则输出 `-1`。

字符串长度不超过 `10^5`，且仅由小写英文字母构成。

# 输入描述
一行，一个由小写英文字母组成的字符串 $s$（长度不超过 `10^5`）。

# 输出描述
若可以构造出 $t$，输出 $t$；否则输出 `-1`。

## 样例1

**输入**

```
ab
```

**输出**

```
ba
```

**说明**

字母表为 $\{a,b\}$。第一位不能为 $a$，第二位不能为 $b$，且必须用到 $a$ 与 $b$，因此得到 `ba`。

## 样例2

**输入**

```
aaaa
```

**输出**

```
-1
```

**说明**

字母表大小为 `1`，每一位都只能填 $a$，无法与原串对应位不同，输出 `-1`。

## 样例3

**输入**

```
aab
```

**输出**

```
bba
```

**说明**

字母表为 $\{a,b\}$。前两位不能为 $a$，填 $b$；第三位不能为 $b$，填 $a$，得到 `bba`，字母表仍为 $\{a,b\}$。

## 样例4

**输入**

```
abab
```

**输出**

```
baba
```

**说明**

字母表大小为 `2`，每位只有另一种字母可选，逐位替换得到 `baba`。
