# 题目内容
展会把 $n$ 个展位按 `1` 到 $n$ 编号，第 $i$ 号展位的结算金额为 $a_i$。财务按掩码 $x$ 做一次汇总：把所有满足

$$(x\ \&\ i)=i$$

的展位金额加总，也就是 $i$ 的二进制 `1` 位必须全部落在 $x$ 中。符号 $\&$ 表示按位与：对应位都为 `1` 时结果位为 `1`，否则为 `0`。现有多组测试，每组给出展位金额和若干询问掩码，请按询问顺序输出每次汇总结果。

约束：测试组数不超过 `100000`；每组展位数与询问数均不超过 `200000`；所有测试中 $n+q$ 之和不超过 `500000`；金额满足 $-10 \le a_i \le 1000000000$；询问掩码满足 $0 \le x \le 200000$。

# 输入描述
第一行一个整数 $T$，表示测试组数。
每组数据：
第一行两个整数 $n$ 和 $q$，表示展位数与询问数；
第二行 $n$ 个整数 $a_1,a_2,\ldots,a_n$，表示金额；
第三行 $q$ 个整数 $x_1,x_2,\ldots,x_q$，表示询问掩码。
保证 $1 \le T \le 100000$，$1 \le n,q \le 200000$，所有测试中 $n+q$ 的总和不超过 `500000`，$-10 \le a_i \le 1000000000$，$0 \le x \le 200000$。

# 输出描述
对每组数据按询问顺序输出 $q$ 行，每行一个整数，表示该询问的金额总和。

## 样例1

**输入**

```
2
4 3
8 1 -3 2
1 3 8
5 2
4 4 4 4 4
0 15
```

**输出**

```
8
6
0
0
20
```

**说明**

第一组 $n=`4`$，$a=[8,1,-3,2]$：
- $x=`1`$ 时仅 $i=`1`$ 合法，和为 `8`；
- $x=`3`$ 时 $i\in\{1,2,3\}$，和为 `6`；
- $x=`8`$ 时 `1` 到 `4` 均不是其按位子集，和为 `0`。
第二组五个权值均为 `4`：$x=`0`$ 无合法下标，和为 `0`；$x=`15`$ 时 `1` 到 `5` 都合法，和为 `20`。

## 样例2

**输入**

```
1
6 2
7 -2 5 1 0 3
2 9
```

**输出**

```
-2
7
```

**说明**

$n=`6`$，$a=[7,-2,5,1,0,3]$：
- $x=`2`$ 时仅 $i=`2`$ 合法，和为 `-2`；
- $x=`9`$（二进制 `1001`）时合法下标为 $i=`1`$ 与 $i=`8$（超出 $n$），故只有 $i=`1`$，和为 `7`。
