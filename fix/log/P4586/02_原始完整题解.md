## 解题思路

题目要求对于每个询问 $x$，计算

$$
\sum_{\substack{1 \leq i \leq n \\(x \& i)=i}} a_{i}
$$

也就是把所有满足 $i$ 的二进制 1 位都出现在 $x$ 中的下标 $i$ 的权值加起来。

换句话说，条件 $(x \& i) = i$ 等价于：

* $i$ 的每一个 1 位，$x$ 对应位置也必须是 1；
* 即 $i$ 是 $x$ 的一个“按位子集”。

### 相关算法

这里使用的核心思想是：

* 位运算拆分
* 子集枚举
* 分治预处理（按高位和低位拆开）

### 核心思路

直接对每个询问暴力检查所有下标 $i$，复杂度是 $O(nq)$，显然无法通过。

注意到题目中的数满足：

* $n \le 2\times 10^5$
* $x \le 2\times 10^5$

而 $2\times 10^5 < 2^{18}$，所以所有相关下标和查询都只需要看 18 个二进制位。

于是可以把这 18 位拆成两部分：

* 低 10 位
* 高 8 位

设一个下标 $i$ 拆成：

$$
i = (h_i, l_i)
$$

其中：

* $h_i$ 表示高 8 位
* $l_i$ 表示低 10 位

同理，一个询问 $x$ 拆成：

$$
x = (h_x, l_x)
$$

那么条件

$$
(x \&\ i)=i
$$

就等价于：

* $(h_x \&\ h_i)=h_i$
* $(l_x \&\ l_i)=l_i$

也就是说，高位和低位可以分别判断。



### 预处理方法

我们按高位分组。

对于每一个高位状态 $h$，开一个长度为 $2^{10}=1024$ 的数组，记为 `dp[h]`：

* `dp[h][l]` 表示高位等于 $h$、低位恰好等于 $l$ 的所有下标权值之和。

也就是把所有下标 $i$ 的 $a_i$ 放到对应的 $(h_i,l_i)$ 位置中。

接下来，对每个高位组 `dp[h]` 做一次低位上的子集和预处理。

处理后，`dp[h][mask]` 表示：

$$
\sum_{s\subseteq mask} \text{原来高位为 } h \text{ 且低位为 } s \text{ 的权值和}
$$

这样一来，如果查询低位是 $l_x$，那么 `dp[h][l_x]` 就已经表示：

* 高位固定为 $h$
* 低位满足是 $l_x$ 的子集

的所有贡献之和。

---

### 如何回答一个询问

对于询问 $x=(h_x,l_x)$：

1. 枚举 $h_x$ 的所有子集 $s$
2. 把所有 `dp[s][l_x]` 累加起来

因为：

* 枚举的高位子集 $s$ 保证 $(h_x \&\ s)=s$
* `dp[s][l_x]` 保证低位满足 $(l_x \&\ l)=l$

两者合起来，恰好就是所有满足 $(x \&\ i)=i$ 的下标贡献。

---

### 为什么这样拆分是高效的

如果直接做完整 18 位子集和，代价偏大。

现在拆成：

* 低位 10 位做预处理，数组长度只有 1024
* 高位只有 8 位，查询时最多只需枚举 $2^8=256$ 个子集

这样每次查询最多只需要 256 次累加，速度很快。

---

### 实现细节

1. 下标是从 1 开始的，所以遍历数组时下标也要从 1 到 $n$。
2. 对于每个下标 $i$：

   * 高位：`i >> 10`
   * 低位：`i & ((1 << 10) - 1)`
3. 查询 $x$ 时：

   * 高位：`x >> 10`
   * 低位：`x & ((1 << 10) - 1)`
4. 枚举一个数的所有子集可以用经典写法：

```text
s = mask
while True:
    ...
    if s == 0: break
    s = (s - 1) & mask
```

## 复杂度分析

设低位拆成 10 位，则低位状态数为 $2^{10}=1024$，高位状态数为 $2^8=256$。

对于每组测试数据：

### 时间复杂度

1. 建表插入所有下标：$O(n)$
2. 对每个出现过的高位组做低位子集和预处理
   每组代价为 $O(10\times 1024)$
   设实际出现的高位组个数为 $g$，则这部分是：

$$
O(g \times 10 \times 1024)
$$

由于一个高位组对应 1024 个连续下标，所以 $g$ 很少，且有 $g\le 256$。

3. 每个询问枚举高位所有子集，最多 $2^8=256$ 个，因此查询总复杂度为：

$$
O(q \times 256)
$$

综上，总时间复杂度可以写为：

$$
O\left(n + g\times 10240 + q\times 256\right)
$$

### 空间复杂度

需要存储若干个高位组，每个组长度为 1024，因此空间复杂度为：

$$
O(g \times 1024)
$$

## 代码实现

### Python

```python
import sys


# 计算一组测试数据所有询问的答案
def solve_case(n, q, a, queries):
    LOW_BITS = 10
    LOW_SIZE = 1 << LOW_BITS
    LOW_MASK = LOW_SIZE - 1
    HIGH_SIZE = 1 << (18 - LOW_BITS)

    # groups[h] 是一个长度为 1024 的数组
    # groups[h][l] 表示高位为 h、低位恰好为 l 的权值和
    groups = [None] * HIGH_SIZE

    # 按下标 i 的二进制高低位拆分，把 a_i 放入对应位置
    for i in range(1, n + 1):
        h = i >> LOW_BITS
        l = i & LOW_MASK
        if groups[h] is None:
            groups[h] = [0] * LOW_SIZE
        groups[h][l] += a[i - 1]

    # 对每个出现过的高位组做低位上的子集和预处理
    # 处理后 groups[h][mask] 表示低位是 mask 的子集的所有贡献和
    for h in range(HIGH_SIZE):
        if groups[h] is None:
            continue
        dp = groups[h]
        for b in range(LOW_BITS):
            bit = 1 << b
            for mask in range(LOW_SIZE):
                if mask & bit:
                    dp[mask] += dp[mask ^ bit]

    ans = []

    # 回答每个询问
    for x in queries:
        hx = x >> LOW_BITS
        lx = x & LOW_MASK

        total = 0

        # 枚举 hx 的所有子集 s
        s = hx
        while True:
            if groups[s] is not None:
                total += groups[s][lx]
            if s == 0:
                break
            s = (s - 1) & hx

        ans.append(str(total))

    return ans


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    t = data[0]
    idx = 1
    out = []

    for _ in range(t):
        n = data[idx]
        q = data[idx + 1]
        idx += 2

        a = data[idx: idx + n]
        idx += n

        queries = data[idx: idx + q]
        idx += q

        out.extend(solve_case(n, q, a, queries))

    sys.stdout.write("\n".join(out))


if __name__ == "__main__":
    main()
```

```java
import java.io.BufferedInputStream;
import java.io.IOException;
import java.util.ArrayList;
import java.util.List;

public class Main {

    // 计算一组测试数据所有询问的答案
    public static List<Long> solveCase(int n, int q, long[] a, int[] queries) {
        final int LOW_BITS = 10;
        final int LOW_SIZE = 1 << LOW_BITS;
        final int LOW_MASK = LOW_SIZE - 1;
        final int HIGH_SIZE = 1 << (18 - LOW_BITS);

        // groups[h] 是长度为 1024 的数组
        // groups[h][l] 表示高位为 h、低位恰好为 l 的权值和
        long[][] groups = new long[HIGH_SIZE][];

        // 按下标 i 拆分高低位，把 a_i 放入对应位置
        for (int i = 1; i <= n; i++) {
            int h = i >> LOW_BITS;
            int l = i & LOW_MASK;
            if (groups[h] == null) {
                groups[h] = new long[LOW_SIZE];
            }
            groups[h][l] += a[i];
        }

        // 对每个出现过的高位组做低位上的子集和预处理
        for (int h = 0; h < HIGH_SIZE; h++) {
            if (groups[h] == null) {
                continue;
            }
            long[] dp = groups[h];
            for (int b = 0; b < LOW_BITS; b++) {
                int bit = 1 << b;
                for (int mask = 0; mask < LOW_SIZE; mask++) {
                    if ((mask & bit) != 0) {
                        dp[mask] += dp[mask ^ bit];
                    }
                }
            }
        }

        List<Long> ans = new ArrayList<>();

        // 回答每个询问
        for (int x : queries) {
            int hx = x >> LOW_BITS;
            int lx = x & LOW_MASK;

            long total = 0;

            // 枚举 hx 的所有子集
            int s = hx;
            while (true) {
                if (groups[s] != null) {
                    total += groups[s][lx];
                }
                if (s == 0) {
                    break;
                }
                s = (s - 1) & hx;
            }

            ans.add(total);
        }

        return ans;
    }

    public static void main(String[] args) throws Exception {
        FastScanner fs = new FastScanner();

        int T = fs.nextInt();
        StringBuilder sb = new StringBuilder();

        for (int tc = 0; tc < T; tc++) {
            int n = fs.nextInt();
            int q = fs.nextInt();

            // a 从 1 开始存，方便和题目下标一致
            long[] a = new long[n + 1];
            for (int i = 1; i <= n; i++) {
                a[i] = fs.nextLong();
            }

            int[] queries = new int[q];
            for (int i = 0; i < q; i++) {
                queries[i] = fs.nextInt();
            }

            List<Long> ans = solveCase(n, q, a, queries);
            for (long v : ans) {
                sb.append(v).append('\n');
            }
        }

        System.out.print(sb.toString());
    }

    // 读入工具，使用 BufferedInputStream，适合本题数据范围
    static class FastScanner {
        private final BufferedInputStream in = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int ptr = 0;
        private int len = 0;

        private int read() throws IOException {
            if (ptr >= len) {
                len = in.read(buffer);
                ptr = 0;
                if (len <= 0) {
                    return -1;
                }
            }
            return buffer[ptr++];
        }

        public long nextLong() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ');

            int sign = 1;
            if (c == '-') {
                sign = -1;
                c = read();
            }

            long val = 0;
            while (c > ' ') {
                val = val * 10 + c - '0';
                c = read();
            }
            return val * sign;
        }

        public int nextInt() throws IOException {
            return (int) nextLong();
        }
    }
}
```

```cpp
#include <bits/stdc++.h>
using namespace std;


// 计算一组测试数据所有询问的答案
vector<long long> solve_case(int n, int q, const vector<long long>& a, const vector<int>& queries) {
    const int LOW_BITS = 10;
    const int LOW_SIZE = 1 << LOW_BITS;
    const int LOW_MASK = LOW_SIZE - 1;
    const int HIGH_SIZE = 1 << (18 - LOW_BITS);

    // groups[h] 是一个长度为 1024 的数组
    // groups[h][l] 表示高位为 h、低位恰好为 l 的权值和
    vector<vector<long long>> groups(HIGH_SIZE);

    // 按下标 i 拆分高低位，把 a_i 放入对应位置
    for (int i = 1; i <= n; i++) {
        int h = i >> LOW_BITS;
        int l = i & LOW_MASK;
        if (groups[h].empty()) {
            groups[h].assign(LOW_SIZE, 0);
        }
        groups[h][l] += a[i];
    }

    // 对每个出现过的高位组做低位上的子集和预处理
    for (int h = 0; h < HIGH_SIZE; h++) {
        if (groups[h].empty()) {
            continue;
        }
        for (int b = 0; b < LOW_BITS; b++) {
            int bit = 1 << b;
            for (int mask = 0; mask < LOW_SIZE; mask++) {
                if (mask & bit) {
                    groups[h][mask] += groups[h][mask ^ bit];
                }
            }
        }
    }

    vector<long long> ans;
    ans.reserve(q);

    // 回答每个询问
    for (int x : queries) {
        int hx = x >> LOW_BITS;
        int lx = x & LOW_MASK;

        long long total = 0;

        // 枚举 hx 的所有子集
        int s = hx;
        while (true) {
            if (!groups[s].empty()) {
                total += groups[s][lx];
            }
            if (s == 0) {
                break;
            }
            s = (s - 1) & hx;
        }

        ans.push_back(total);
    }

    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    while (T--) {
        int n, q;
        cin >> n >> q;

        // a 从 1 开始存，方便和题目下标一致
        vector<long long> a(n + 1);
        for (int i = 1; i <= n; i++) {
            cin >> a[i];
        }

        vector<int> queries(q);
        for (int i = 0; i < q; i++) {
            cin >> queries[i];
        }

        vector<long long> ans = solve_case(n, q, a, queries);
        for (long long v : ans) {
            cout << v << '\n';
        }
    }

    return 0;
}
```
