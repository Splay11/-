# 题目内容
有 $m$ 个探测点与 $n$ 台探针。第 $i$ 台探针能覆盖哪些探测点，用一个长度为 $m$、仅含字符 `'0'` 和 `'1'` 的字符串 $s_i$ 表示：第 $j$ 个字符为 `'1'` 表示能覆盖第 $j$ 个探测点，为 `'0'` 表示不能。

一次最多启用 `8` 台探针（至少启用 `1` 台）。多台探针覆盖同一探测点时只计一次。请给出：在最优启用方案下能覆盖的探测点个数，以及能达到该覆盖数的不同启用方案数。

探针台数 $n$ 满足 $1 \le n \le 25$，探测点个数 $m$ 满足 $1 \le m \le 100$。保证至少有一台探针能覆盖至少一个探测点。

# 输入描述
第一行包含两个正整数 $n$ 和 $m$，分别表示探针台数和探测点个数。
接下来 $n$ 行，第 $i$ 行包含一个长度为 $m$、仅由字符 `'0'` 和 `'1'` 组成的字符串 $s_i$。

# 输出描述
输出一行两个整数，依次表示最多能覆盖的探测点个数，以及达到该覆盖数的方案数。

## 样例1

**输入**

```
3 4
1111
0010
1101
```

**输出**

```
4 5
```

**说明**

三台探针覆盖分别为四个点、第 `3` 个点、三个点。最大覆盖数为 `4`。达到 `4` 的方案有：只选第 `1` 台；第 `1`+`2`；第 `1`+`3`；第 `2`+`3`；三台全选，共 `5` 种。

## 样例2

**输入**

```
2 2
10
01
```

**输出**

```
2 1
```

**说明**

两台探针分别覆盖第 `1`、第 `2` 个探测点。单独启用只能覆盖 `1` 个点，同时启用才能覆盖 `2` 个点。最大覆盖为 `2`，方案数 `1`。

## 样例3

**输入**

```
1 3
101
```

**输出**

```
2 1
```

**说明**

只有一台探针，覆盖第 `1`、第 `3` 个探测点，覆盖数为 `2`，方案数 `1`。
