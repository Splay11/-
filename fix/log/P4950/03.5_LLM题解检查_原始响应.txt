## 解题思路

本题可以转化为一个边权只有 $0$ 和 $1$ 的最短路问题，适合用 **0-1 BFS** 解决。

- 将每个房间看作图中的一个顶点，编号 $1 \sim n$。
- 从房间 $i$ 出发有两种移动方式，对应两种有向边：
  1. **跃迁**：花费 0 体力转移到房间 $a_i$，边权为 $0$。
  2. **向右步行**：如果 $i < n$，花费 1 体力移动到房间 $i+1$，边权为 $1$。
- 目标是从房间 $1$ 到达房间 $n$ 所需的最小体力，即求 $1$ 到 $n$ 的最短距离。

因为所有边的权值只有 $0$ 和 $1$，可以使用双端队列进行 BFS：
- 维护距离数组 `dis[i]`，初始时 `dis[1] = 0`，其余设为无穷大。
- 初始将房间 $1$ 放入双端队列。
- 每次从队首取出当前房间 $x$：
  1. 对于跃迁目标 $y = a_x$，若 `dis[y] > dis[x]`，则更新 `dis[y] = dis[x]`，并将 $y$ 加入队**首**（因为边权为 $0$）。
  2. 若 $x < n$，对于步行目标 $x+1$，若 `dis[x+1] > dis[x] + 1`，则更新 `dis[x+1] = dis[x] + 1`，并将 $x+1$ 加入队**尾**（因为边权为 $1$）。
- 最终 `dis[n]` 即为答案。

由于总点数不超过 $5\times 10^5$，每组数据使用 0-1 BFS 即可高效求解。

## 复杂度分析

对于每组测试数据：
- 每个房间最多被扩展一次，且每次扩展只处理两条边（跃迁和步行），时间复杂度为 $O(n)$。
- 距离数组及双端队列的空间复杂度为 $O(n)$。

所有测试数据的总房间数 $\sum n \le 5\times 10^5$，因此总体时间复杂度 $O(\sum n)$，空间复杂度 $O(\max n)$，可以满足题目要求。

## 代码实现

### Python

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    q = int(next(it))
    out_lines = []
    INF = 10**18
    
    for _ in range(q):
        n = int(next(it))
        a = [0] + [int(next(it)) for _ in range(n)]  # a[i] 为房间 i 的跃迁目标
        
        dis = [INF] * (n + 1)
        dis[1] = 0
        dq = deque([1])
        
        while dq:
            x = dq.popleft()
            # 跃迁，花费 0 体力
            y = a[x]
            if dis[y] > dis[x]:
                dis[y] = dis[x]
                dq.appendleft(y)
            # 向右步行，花费 1 体力
            if x < n and dis[x + 1] > dis[x] + 1:
                dis[x + 1] = dis[x] + 1
                dq.append(x + 1)
        out_lines.append(str(dis[n]))
    
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int q = Integer.parseInt(br.readLine().trim());
        StringBuilder sb = new StringBuilder();
        final long INF = (long) 1e18;
        
        while (q-- > 0) {
            int n = Integer.parseInt(br.readLine().trim());
            int[] a = new int[n + 1];
            StringTokenizer st = new StringTokenizer(br.readLine());
            for (int i = 1; i <= n; i++) {
                a[i] = Integer.parseInt(st.nextToken());
            }
            
            long[] dis = new long[n + 1];
            Arrays.fill(dis, INF);
            dis[1] = 0;
            
            Deque<Integer> dq = new ArrayDeque<>();
            dq.addLast(1);
            
            while (!dq.isEmpty()) {
                int x = dq.pollFirst();
                // 跃迁，花费 0 体力
                int y = a[x];
                if (dis[y] > dis[x]) {
                    dis[y] = dis[x];
                    dq.addFirst(y);
                }
                // 向右步行，花费 1 体力
                if (x < n && dis[x + 1] > dis[x] + 1) {
                    dis[x + 1] = dis[x] + 1;
                    dq.addLast(x + 1);
                }
            }
            sb.append(dis[n]).append('\n');
        }
        System.out.print(sb);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int q;
    cin >> q;
    const long long INF = 1e18;
    
    while (q--) {
        int n;
        cin >> n;
        vector<int> a(n + 1);
        for (int i = 1; i <= n; ++i) {
            cin >> a[i];
        }
        
        vector<long long> dis(n + 1, INF);
        dis[1] = 0;
        deque<int> dq;
        dq.push_back(1);
        
        while (!dq.empty()) {
            int x = dq.front();
            dq.pop_front();
            
            // 跃迁，花费 0 体力
            int y = a[x];
            if (dis[y] > dis[x]) {
                dis[y] = dis[x];
                dq.push_front(y);
            }
            // 向右步行，花费 1 体力
            if (x < n && dis[x + 1] > dis[x] + 1) {
                dis[x + 1] = dis[x] + 1;
                dq.push_back(x + 1);
            }
        }
        cout << dis[n] << '\n';
    }
    return 0;
}
```
