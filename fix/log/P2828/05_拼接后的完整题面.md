# 题目内容
小蓝经营一家魔法杂货店，货架上从左到右摆着一排共 $n$ 件商品。每件商品都有一个唯一的「魔力等级」，恰好为 $1$ 到 $n$ 的一个排列，第 $i$ 个位置上的商品魔力等级记为 $a_i$。

为了让货架恢复美观，小蓝需要把这些商品按照魔力等级从小到大排列（即最终状态为 $1, 2, \dots, n$）。他唯一能使用的是一种「空间调换术」：每次可以选择货架上的任意两件商品，如果它们的魔力等级之差的绝对值不超过 $k$，就可以瞬间交换这两件商品的位置。调换的代价根据魔力等级之差决定：
- 若两件商品的魔力等级相差恰好为 $1$，这次交换将消耗 $1$ 点魔力；
- 若魔力等级相差大于 $1$ 且不超过 $k$，则不消耗魔力。

魔力等级相差超过 $k$ 的商品无法直接交换。请你帮小蓝计算：最少需要消耗多少点魔力，才能将整排商品恢复为严格递增顺序。

数据范围：$n$ 不超过 $2 \times 10^5$，$k$ 满足 $1 \le k \le n-1$，输入保证 $a_1, a_2, \dots, a_n$ 是 $1$ 到 $n$ 的一个排列。

# 输入描述
第一行包含两个整数 $n$ 和 $k$，表示商品数量和能力界限 $k$。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$，表示从左到右各位置上的商品魔力等级。

# 输出描述
输出一个整数，表示达成目标所需的最少魔力消耗。

## 样例1

**输入**

```
4 1
2 1 4 3
```

**输出**

```
1
```

**说明**

魔力界限 $k=1$，只能交换魔力等级相差恰好为 $1$ 的商品，每次消耗 $1$ 点魔力。最少消耗等于初始排列中的逆序对数量。排列 `2 1 4 3` 中存在逆序对 $(2,1)$ 和 $(4,3)$，共 $2$ 对，因此需要消耗 $2$ 点魔力。

## 样例2

**输入**

```
5 2
2 4 1 5 3
```

**输出**

```
1
```

**说明**

$k=2$ 时，魔力等级相差为 $2$ 的商品可以免费互相交换。因此所有奇数之间、所有偶数之间都可以无消耗地任意调换位置；而奇数与偶数之间的交换（相差 $1$）需要消耗 $1$ 点魔力。

最终目标排列要求所有奇数位于奇数位置、所有偶数位于偶数位置。最少消耗就等于初始时放错奇偶位置的对数：即位于偶数位置上的奇数个数（等于位于奇数位置上的偶数个数）。

初始排列 `2 4 1 5 3`，位置 $1$ 到 $5$：
- 位 $1$（奇）：`2`（偶）→ 偶数在奇数位
- 位 $2$（偶）：`4`（偶）→ 正确
- 位 $3$（奇）：`1`（奇）→ 正确
- 位 $4$（偶）：`5`（奇）→ 奇数在偶数位
- 位 $5$（奇）：`3`（奇）→ 正确

错位的奇数只有位置 $4$ 的 `5`，共 $1$ 个，故最少消耗为 $1$。

## 样例3

**输入**

```
4 3
4 3 2 1
```

**输出**

```
0
```

**说明**

当 $k \ge 3$ 时，可以免费交换魔力等级相差在 $[2, k]$ 之间的商品。此时由差值 $2$ 和 $3$ 生成的所有整数线性组合覆盖了全体整数，这意味着任意两件商品都能通过一系列免费交换互相到达，整个商品集合在免费交换下是连通的。

因此无论初始排列如何，总可以仅用 $0$ 代价的交换将商品恢复为严格递增顺序，最少魔力消耗为 $0$。

## 样例4

**输入**

```
2 1
2 1
```

**输出**

```
1
```

**说明**

边界情况 $n=2, k=1$。只能交换等级相差 $1$ 的商品，每次消耗 $1$ 点魔力。初始排列 `2 1` 包含一个逆序对 $(2,1)$，交换这两个商品即可变为 `1 2`，消耗 $1$ 点魔力。
