## 解题思路

我们需要构造一个 $2 \times n$ 的矩阵 $A$，满足：
- 第一行是 $1$ 到 $n$ 的一个排列；
- 第二行也是 $1$ 到 $n$ 的一个排列；
- 矩阵中上下左右相邻（曼哈顿距离为 $1$）的两个元素互质，即它们的最大公约数为 $1$。

已知一个简单的性质：**任意两个相邻整数互质**，即对于正整数 $k$，有 $\gcd(k, k+1) = 1$。另外，$1$ 与任何正整数都互质。

利用这一性质，我们可以构造如下矩阵：
- 第一行：依次为 $1, 2, 3, \dots, n$；
- 第二行：依次为 $2, 3, 4, \dots, n, 1$。

下面验证该构造的正确性：

1. **行内水平相邻**：
   - 第一行中相邻元素为 $k$ 和 $k+1$，满足 $\gcd(k, k+1) = 1$；
   - 第二行中相邻元素也是 $k$ 和 $k+1$（对于 $k=2,\dots,n-1$），以及末尾的 $n$ 与开头的 $1$，显然 $\gcd(n, 1) = 1$。

2. **列间垂直相邻**：
   - 对于第 $j$ 列（$1 \le j \le n-1$），第一行为 $j$，第二行为 $j+1$，它们的最大公约数为 $1$；
   - 对于第 $n$ 列，第一行为 $n$，第二行为 $1$，同样互质。

当 $n=1$ 时，矩阵为两行一列，两个位置都填 $1$，显然 $\gcd(1,1)=1$，构造依然合法。

综上，按照上述规则构造即可得到一个符合条件的矩阵。该构造对于所有 $n \ge 1$ 均成立。

## 复杂度分析

构造过程中只需按顺序生成两行排列并输出，因此：
- 时间复杂度：$O(n)$，因为只需遍历 $1$ 到 $n$ 一次。
- 空间复杂度：$O(n)$，若需要存储输出字符串或数组，最坏情况下存储 $n$ 个整数；也可以采用逐个数输出的方式优化到 $O(1)$ 额外空间，但这里给出的参考代码使用了数组/列表，因此空间为 $O(n)$。

## 代码实现

### Python

```python
import sys

def main():
    data = sys.stdin.read().strip()
    if not data:
        return
    n = int(data)

    # 特殊情况 n=1
    if n == 1:
        print(1)
        print(1)
        return

    # 第一行：1 到 n
    first_row = list(range(1, n + 1))
    # 第二行：2 到 n，最后接一个 1
    second_row = list(range(2, n + 1)) + [1]

    # 输出结果
    print(' '.join(map(str, first_row)))
    print(' '.join(map(str, second_row)))

if __name__ == '__main__':
    main()
```

### Java

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());

        // n = 1 特判
        if (n == 1) {
            System.out.println(1);
            System.out.println(1);
            return;
        }

        // 第一行：1 到 n
        StringBuilder first = new StringBuilder();
        for (int i = 1; i <= n; i++) {
            first.append(i);
            if (i < n) first.append(' ');
        }
        System.out.println(first);

        // 第二行：2 到 n，最后补 1
        StringBuilder second = new StringBuilder();
        for (int i = 2; i <= n; i++) {
            second.append(i).append(' ');
        }
        second.append(1);
        System.out.println(second);
    }
}
```

### C++

```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    // 特殊情况 n = 1
    if (n == 1) {
        cout << 1 << '\n' << 1 << '\n';
        return 0;
    }

    // 第一行：1, 2, ..., n
    for (int i = 1; i <= n; ++i) {
        cout << i;
        if (i < n) cout << ' ';
    }
    cout << '\n';

    // 第二行：2, 3, ..., n, 1
    for (int i = 2; i <= n; ++i) {
        cout << i << ' ';
    }
    cout << 1 << '\n';

    return 0;
}
```
