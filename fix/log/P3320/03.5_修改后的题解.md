## 解题思路

对每个位置 $i$，需要统计左侧与 $s_i$ 不同的字符个数。用两个计数器 $\mathrm{cnt0}$、$\mathrm{cnt1}$ 记录已经扫过的 `0` 与 `1` 的个数。

从左到右扫描：若当前是 `0`，则答案为当前的 $\mathrm{cnt1}$，随后 $\mathrm{cnt0}$ 加一；若当前是 `1`，则答案为当前的 $\mathrm{cnt0}$，随后 $\mathrm{cnt1}$ 加一。一次扫描即可得到全部 $a_i$。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(n)$（用于存放答案）。

## 代码实现

### Python

```python
def count_diff(s):
    n = len(s)
    ans = [0] * n
    cnt0, cnt1 = 0, 0
    for i, ch in enumerate(s):
        if ch == '0':
            ans[i] = cnt1
            cnt0 += 1
        else:
            ans[i] = cnt0
            cnt1 += 1
    return ans

if __name__ == '__main__':
    T = int(input().strip())
    for _ in range(T):
        n = int(input().strip())
        s = input().strip()
        res = count_diff(s)
        print(' '.join(map(str, res)))
```

### Java

```java
import java.util.Scanner;

public class Main {
    static int[] countDiff(String s) {
        int n = s.length();
        int[] ans = new int[n];
        int cnt0 = 0, cnt1 = 0;
        for (int i = 0; i < n; i++) {
            char c = s.charAt(i);
            if (c == '0') {
                ans[i] = cnt1;
                cnt0++;
            } else {
                ans[i] = cnt0;
                cnt1++;
            }
        }
        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();
        while (T-- > 0) {
            int n = sc.nextInt();
            String s = sc.next();
            int[] res = countDiff(s);
            for (int i = 0; i < n; i++) {
                System.out.print(res[i] + (i + 1 < n ? " " : ""));
            }
            System.out.println();
        }
        sc.close();
    }
}
```

### C++

#include <bits/stdc++.h>
using namespace std;

vector<int> countDiff(const string &s) {
    int n = s.size();
    vector<int> ans(n);
    int cnt0 = 0, cnt1 = 0;
    for (int i = 0; i < n; i++) {
        if (s[i] == '0') {
            ans[i] = cnt1;
            cnt0++;
        } else {
            ans[i] = cnt0;
            cnt1++;
        }
    }
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int n;
        string s;
        cin >> n >> s;
        vector<int> res = countDiff(s);
        for (int i = 0; i < n; i++) {
            cout << res[i] << (i + 1 < n ? ' ' : '\n');
        }
    }
    return 0;
}
