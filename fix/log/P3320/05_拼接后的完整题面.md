# 题目内容
有一条长度为 $n$ 的双态记录，记为只含字符 `0` 和 `1` 的字符串 $s=s_1 s_2 \ldots s_n$（下标从 `1` 开始）。

对每个位置 $i$（$1 \le i \le n$），定义 $a_i$ 为：在 $i$ 左侧（下标小于 $i$ 的位置）中，字符与 $s_i$ 不同的位置个数。请输出整个序列 $a_1, a_2, \ldots, a_n$。

约束：测试组数不超过 `100`，单组长度不超过 `10^3`。

# 输入描述
每个测试文件包含多组数据。第一行一个整数 $T$，表示数据组数。
每组数据格式如下：
第一行一个整数 $n$，表示字符串长度；
第二行一个长度为 $n$、仅由字符 `0` 和 `1` 组成的字符串 $s$。
保证 $1 \le T \le 100$，$1 \le n \le 10^3$。

# 输出描述
对每组数据输出一行，包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$，相邻整数用一个空格分隔。

## 样例1

**输入**

```
1
3
000
```

**输出**

```
0 0 0
```

**说明**

全为 `0`，每个位置左侧都不存在不同字符，答案为 `0 0 0`。

## 样例2

**输入**

```
1
1
1
```

**输出**

```
0
```

**说明**

长度为 `1` 的边界：左侧为空，答案为 `0`。

## 样例3

**输入**

```
1
3
1
```

**输出**

```
0
```

**说明**

按题意模拟计算得到。
