# 题目内容
有 $n$ 份文档依次进入处理通道。第 $i$ 份文档的处理时长为 $t_i$。一份文档的完成耗时，等于它前面所有文档的处理时长之和，再加上它自己的处理时长。所有文档的完成耗时之和即为通道的总耗时。

你恰好可以交换两个位置上的文档一次。请给出一组交换，使得总耗时尽可能小。若任何交换都不能降低总耗时，则报告无法改进。

文档份数不超过 `2000`。各文档的处理时长为不超过 `10^9` 的非负整数。

# 输入描述
第一行包含一个整数 $n$（$1 \le n \le 2000$），表示文档份数。
第二行包含 $n$ 个非负整数 $t_1, t_2, \ldots, t_n$（$0 \le t_i \le 10^9$），依次表示当前队列中每份文档的处理时长。

# 输出描述
若任何一次交换都不能降低总耗时，输出 `-1`。
否则输出两个正整数 $i$ 和 $j$（$1 \le i < j \le n$），表示交换第 $i$ 个位置与第 $j$ 个位置上的文档。

## 样例1

**输入**

```
5
1 2 1 3 1
```

**输出**

```
2 5
```

**说明**

交换位置 $i$ 与 $j$（$i<j$）后，总耗时的减少量为 $(j-i)\times(t_i-t_j)$。
枚举所有数对，减少量最大的是 $i=`2`$，$j=`5`$，减少量为 $(5-2)\times(2-1)=`3`$。

## 样例2

**输入**

```
3
1 2 3
```

**输出**

```
-1
```

**说明**

序列非降，任意 $i<j$ 都有 $t_i-t_j\le `0`$，减少量不可能为正，无法改进，输出 `-1`。

## 样例3

**输入**

```
4
5 4 3 2
```

**输出**

```
1 4
```

**说明**

序列严格递减。交换两端 $i=`1`$ 与 $j=`4`$ 的减少量为 $(4-1)\times(5-2)=`9`$，在所有数对中最大。

## 样例4

**输入**

```
2
3 1
```

**输出**

```
1 2
```

**说明**

只有一对位置可交换，减少量为 $(2-1)\times(3-1)=`2`$>`0`$，输出 `1 2`。
