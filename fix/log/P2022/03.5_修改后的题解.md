## 解题思路

第 $k$ 份文档的完成耗时是 $t_1+\cdots+t_k$，总耗时为

$$
\sum_{k=1}^{n}(n-k+1)\,t_k.
$$

只能交换一次。设交换位置 $i$ 与 $j$（$1\le i<j\le n$），总耗时的减少量为

$$
(j-i)\times(t_i-t_j).
$$

直观含义：把较大的处理时长往后移（或把较小的往前移）时，中间每一份文档以及被交换的两份文档都会少等一段时间。

枚举所有 $i<j$，记录减少量最大的那一对。若最大减少量为 $0$，说明无法改进，输出 `-1`；否则输出对应的 $i$ 和 $j$（从 $1$ 开始编号）。

## 复杂度分析

时间复杂度 $O(n^2)$，空间复杂度 $O(n)$。

## 代码实现

### Python

```python
n = int(input())
t = list(map(int, input().split()))

ans = 0
x = 0
y = 0
for i in range(n - 1):
    for j in range(i + 1, n):
        temp = (j - i) * (t[i] - t[j])
        if temp > ans:
            ans = temp
            x = i + 1
            y = j + 1

if ans == 0:
    print("-1")
else:
    print(x, y)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        long[] t = new long[n + 1];
        for (int i = 1; i <= n; i++) {
            t[i] = scanner.nextLong();
        }
        long ans = 0;
        int x = 0, y = 0;
        for (int i = 1; i < n; i++) {
            for (int j = i + 1; j <= n; j++) {
                long temp = (j - i) * (t[i] - t[j]);
                if (temp > ans) {
                    ans = temp;
                    x = i;
                    y = j;
                }
            }
        }
        if (ans == 0) {
            System.out.println("-1");
        } else {
            System.out.println(x + " " + y);
        }
    }
}
```

### C++

```cpp
#include <iostream>
using namespace std;
typedef long long ll;

int main() {
    int n;
    cin >> n;
    ll t[100010];
    for (int i = 1; i <= n; i++) cin >> t[i];
    ll ans = 0;
    int x = 0, y = 0;
    for (int i = 1; i < n; i++) {
        for (int j = i + 1; j <= n; j++) {
            ll temp = (ll)(j - i) * (t[i] - t[j]);
            if (temp > ans) {
                ans = temp;
                x = i;
                y = j;
            }
        }
    }
    if (ans == 0) cout << -1 << endl;
    else cout << x << ' ' << y << endl;
    return 0;
}
```
