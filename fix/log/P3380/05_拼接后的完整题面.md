# 题目内容
给定一个长度为 $n$ 的非降序列 $a_1 \le a_2 \le \cdots \le a_n$。至多可以进行一次如下操作：

选择区间 $[l, r]$（$1 \le l \le r \le n$），对区间内每个下标 $i$，令 $a_i$ 增加 $(r - i + 1) \times m$。

希望操作后存在某个 $j$ 使得 $a_j > a_{j+1}$。求为此需要选择的区间长度 $r-l+1$ 的最小值；若一次操作无法做到，输出 `-1`。

数据组数不超过 $10^4$，单组 $n$ 不超过 $2 \times 10^5$，所有数据 $n$ 之和不超过 $2 \times 10^5$，$m$ 与 $a_i$ 均不超过 $10^9$。

# 输入描述
每个测试文件包含多组数据。
第一行一个整数 $T$，表示数据组数。
每组数据格式如下：
第一行两个整数 $n$ 和 $m$；
第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$。
保证 $1 \le T \le 10^4$，$2 \le n \le 2 \times 10^5$，$1 \le m, a_i \le 10^9$，且所有数据的 $n$ 之和不超过 $2 \times 10^5$。输入序列满足 $a_1 \le a_2 \le \cdots \le a_n$。

# 输出描述
对每组数据输出一行一个整数：所求的最小区间长度；若无法通过一次操作打破非降，输出 `-1`。

## 样例1

**输入**

```
1
2 5
1 10
```

**输出**

```
-1
```

**说明**

相邻差为 `9`，不小于 $m=5$，答案为 `-1`。

## 样例2

**输入**

```
1
2 10
1 5
```

**输出**

```
1
```

**说明**

相邻差为 `4`，小于 $m=10$，单点操作即可，答案为 `1`。

## 样例3

**输入**

```
1
2 5
2 11
```

**输出**

```
-1
```

**说明**
