## 解题思路

本题要求在原信号序列 $s$ 长度为 $n$ 的基础上，依次考虑每个位置 $k$ 单独翻转（$0$ 变 $1$，$1$ 变 $0$）后，整个序列中**增长对**的总数。增长对定义为满足 $i < j$ 且 $s_i = 0, s_j = 1$ 的有序下标对 $(i, j)$。

题目的核心在于快速计算每一个位置翻转后的结果，而不是每次都重新统计，因为 $n \le 10^5$ 不允许平方级做法。

算法分为以下三个步骤：

1. **预处理前缀和后缀信息**  
   - 定义数组 `leftZero[i]`：表示位置 $i$ **左侧**（下标小于 $i$）有多少个 `0`。  
   - 定义数组 `rightOne[i]`：表示位置 $i$ **右侧**（下标大于 $i$）有多少个 `1`。  
   通过从左到右和从右到左的一次遍历，可以在 $O(n)$ 时间内完成。

2. **计算原序列的增长对总数**  
   原序列的增长对数量 `total` 可以由所有为 `0` 的位置贡献的右侧 `1` 的个数求和得到：
   $$
   \text{total} = \sum_{i=0}^{n-1}  
   \begin{cases}
   \text{rightOne}[i], & \text{如果 } s_i = 0 \\
   0, & \text{否则}
   \end{cases}
   $$
   这一步也可以等价地理解为：每个 `1` 会和它左侧所有的 `0` 组成增长对。

3. **独立计算每个位置翻转后的增长对数**  
   对于位置 $i$：
   
   - **若原信号为 `0`，翻转后变为 `1`**  
     原来它作为左侧的 `0` 贡献了 `rightOne[i]` 个增长对（与右侧的 `1` 配对），翻转后不再贡献；  
     翻转后它变成右侧的 `1`，会与左侧的所有 `0` 产生新的增长对，数量为 `leftZero[i]`。  
     因此翻转后的总数 = `total - rightOne[i] + leftZero[i]`。
   
   - **若原信号为 `1`，翻转后变为 `0`**  
     原来它作为右侧的 `1` 被左侧所有 `0` 配对，贡献了 `leftZero[i]` 个增长对，翻转后不再贡献；  
     翻转后它变成左侧的 `0`，会与右侧的所有 `1` 产生新的增长对，数量为 `rightOne[i]`。  
     因此翻转后的总数 = `total - leftZero[i] + rightOne[i]`。

   遍历每个位置，按照上述公式计算并输出即可，整体仍然为 $O(n)$ 时间。

## 复杂度分析

- **时间复杂度**：  
  预处理 `leftZero` 和 `rightOne` 数组、计算原始总数、以及计算每个位置的答案，各需要 $O(n)$ 时间，因此总时间复杂度为 $O(n)$。

- **空间复杂度**：  
  需要存储 `leftZero` 和 `rightOne` 两个长度为 $n$ 的数组，以及输出结果数组，空间复杂度为 $O(n)$。

在 $n \le 10^5$ 的限制下，算法可以高效运行。

## 代码实现

注意：当 $n = 10^5$ 且序列内容极端时，增长对总数可能达到约 $2.5 \times 10^9$，因此需要使用 64 位整数（C++ 使用 `long long`，Java 使用 `long`，Python 整数自动扩展）。

### Python

```python
def solve(n, s):
    # left_zero[i] 表示位置 i 左侧 0 的个数
    left_zero = [0] * n
    cnt0 = 0
    for i in range(n):
        left_zero[i] = cnt0
        if s[i] == '0':
            cnt0 += 1

    # right_one[i] 表示位置 i 右侧 1 的个数
    right_one = [0] * n
    cnt1 = 0
    for i in range(n - 1, -1, -1):
        right_one[i] = cnt1
        if s[i] == '1':
            cnt1 += 1

    # 计算原序列中增长对总数
    total = 0
    for i in range(n):
        if s[i] == '0':
            total += right_one[i]

    # 计算每个位置翻转后的答案
    res = [0] * n
    for i in range(n):
        if s[i] == '0':
            # 0 -> 1
            res[i] = total - right_one[i] + left_zero[i]
        else:
            # 1 -> 0
            res[i] = total - left_zero[i] + right_one[i]

    return res


if __name__ == "__main__":
    n = int(input())
    s = input().strip()
    ans = solve(n, s)
    print(*ans)
```

### Java

```java
import java.util.*;

public class Main {

    public static long[] solve(int n, String s) {
        // leftZero[i] 表示位置 i 左侧 0 的个数
        long[] leftZero = new long[n];
        long cnt0 = 0;
        for (int i = 0; i < n; i++) {
            leftZero[i] = cnt0;
            if (s.charAt(i) == '0') {
                cnt0++;
            }
        }

        // rightOne[i] 表示位置 i 右侧 1 的个数
        long[] rightOne = new long[n];
        long cnt1 = 0;
        for (int i = n - 1; i >= 0; i--) {
            rightOne[i] = cnt1;
            if (s.charAt(i) == '1') {
                cnt1++;
            }
        }

        // 计算原序列中增长对总数
        long total = 0;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '0') {
                total += rightOne[i];
            }
        }

        // 计算每个位置翻转后的答案
        long[] res = new long[n];
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '0') {
                // 0 -> 1
                res[i] = total - rightOne[i] + leftZero[i];
            } else {
                // 1 -> 0
                res[i] = total - leftZero[i] + rightOne[i];
            }
        }

        return res;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        String s = sc.next();

        long[] ans = solve(n, s);
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(' ');
            sb.append(ans[i]);
        }
        System.out.println(sb.toString());
    }
}
```
