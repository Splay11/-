# 题目内容
质检实验室给每批样品编制批次号。可用的数字符号是 `0` 到 $n$ 共 $n+1$ 种，且同一批次号里每种符号至多出现一次，以免扫码冲突。质检规程要求只保留恰好 $m$ 位、且十进制数值严格大于阈值 $k$ 的批次号，用于筛掉低优先级样本。多位批次号不允许前导 `0`；若 $m=1$，编号 `0` 本身是允许的。请统计有多少个合法批次号满足上述条件。

约束：$1 \le n \le 7$，$1 \le m \le n+1$，$0 \le k \le 100000000$。

# 输入描述
输入一行三个整数 $n$、$m$ 和 $k$，分别表示最大可用数字、批次号位数与比较阈值。
保证 $1 \le n \le 7$，$1 \le m \le n+1$，$0 \le k \le 100000000$。

# 输出描述
输出一个整数，表示合法且数值严格大于 $k$ 的批次号个数。

## 样例1

**输入**

```
3 2 10
```

**输出**

```
8
```

**说明**

可用数字为 `0` 到 `3`，做 `2` 位编号且各位不重复、不能有前导零。
大于 `10` 的有：$12,13,20,21,23,30,31,32$，共 `8` 个。

## 样例2

**输入**

```
6 1 3
```

**输出**

```
3
```

**说明**

一位编号就是数字 `0` 到 `6` 本身。其中大于 `3` 的是 `4`、`5`、`6`，共 `3` 个。

## 样例3

**输入**

```
2 2 0
```

**输出**

```
4
```

**说明**

可用数字为 `0`、`1`、`2`。两位不重复且无前导零的编号为：$10,12,20,21$，均大于 `0`，共 `4` 个。
