# 题目内容
考虑一个数据传输协议：你需要为 $n$ 个不同的数据包分配互不相同的正整数编号 $a_1, a_2, \dots, a_n$。

所有数据包两两配对时，会产生一个校验开销。对于编号 $x$ 与 $y$，定义它们的配对开销为 $x \oplus y$，其中 $\oplus$ 表示按位异或运算（即二进制无进位相加）。

定义整个系统的总校验开销为：

$$
S = \sum_{1 \le i < j \le n} (a_i \oplus a_j)
$$

你需要选择这 $n$ 个互不相同的正整数编号，使得总开销 $S$ 尽可能小。

约束：整数 $n$ 的范围是 $2 \le n \le 2 \times 10^5$。你输出的每个编号必须是满足 $1 \le a_i \le 2^{31} - 1$ 的正整数。

# 输入描述
输入仅包含一行，一个整数 $n$，表示需要分配的编号数量。

# 输出描述
输出一行，包含 $n$ 个以空格分隔的正整数，表示你分配的各编号。如果有多种使总开销最小的方案，输出任意一种即可。

## 样例1

**输入**

```
2
```

**输出**

```
2 3
```

**说明**

当 $n=`2`$ 时，最小的不小于 $n$ 的 $2$ 的幂为 $p=`2`$。
我们选择从 $p$ 开始的连续整数：$`2`,`3`$。
此时仅有一对配对 $(2,3)$，总开销 $S = 2 \oplus 3 = `1`$。
若选择 $`1`,`2`$，则 $S = 1 \oplus 2 = `3`$；若选择 $`1`,`3`$，则 $S = 1 \oplus 3 = `2`$。
该构造使总开销达到理论最小值 $`1`$，且所有编号均为正整数。

## 样例2

**输入**

```
4
```

**输出**

```
4 5 6 7
```

**说明**

当 $n=`4`$ 时，$p=`4`$。构造编号 $`4`,`5`,`6`,`7`$。
这些数的二进制分别为 `100`、`101`、`110`、`111`，最高两位（第 $2$ 位，权值 $4$）均为 $1$，因此高位的异或贡献为 $0$。
总开销仅由低两位（权值 $1$ 和 $2$）产生，等价于对 $`0`,`1`,`2`,`3`$ 求所有配对异或和，其值在所有可能的 $4$ 个不同正整数构造中是最小的。

## 样例3

**输入**

```
5
```

**输出**

```
8 9 10 11 12
```

**说明**

当 $n=`5`$ 时，$p=`8`$（$2^3$）。构造编号 $`8`$ 到 $`12`$。
这些数的二进制最高位（第 $3$ 位，权值 $8$）全部为 $1$，避免了出现 $0$ 和 $1$ 混杂的半区，从而消除了高位跨区贡献。
总开销等于对 $`0`,`1`,`2`,`3`,`4`$ 的配对异或总和，该值在所有合法方案中是最小的。

## 样例4

**输入**

```
6
```

**输出**

```
8 9 10 11 12 13
```

**说明**

当 $n=`6`$ 时，$p=`8`$。
输出连续整数 $`8`$ 至 $`13`$，所有数的最高位（$2^3=8$）均为 $1$，使高位异或开销为 $0$。
该构造的总开销等价于对 $`0`$ 到 $`5`$ 这 $6$ 个数的所有配对求异或和，达到了题目要求的最小总校验开销。
