# 题目内容
平面上有 $n$ 座测站，第 $i$ 座测站的坐标为 $(x_i, y_i)$。两座测站 $i$ 与 $j$ 之间的距离定义为
$$d(i,j)=|x_i-x_j|+|y_i-y_j|.$$

对于每一座测站 $i$，求它到其余测站的距离的最大值。

测站个数 $n$ 满足 $2 \le n \le 2 \times 10^5$。坐标满足 $-10^9 \le x_i, y_i \le 10^9$。

# 输入描述
第一行包含一个整数 $n$，表示测站个数。
接下来 $n$ 行，每行两个整数 $x_i$ 和 $y_i$，表示第 $i$ 座测站的坐标。

# 输出描述
输出一行 $n$ 个整数，第 $i$ 个数表示第 $i$ 座测站到其余测站的最大距离。相邻整数之间用一个空格隔开。

## 样例1

**输入**

```
3
1 2
4 5
2 1
```

**输出**

```
6 6 6
```

**说明**

三座测站坐标为 $(1,2)$、$(4,5)$、$(2,1)$。
两两距离分别为 $|1-4|+|2-5|=6$、$|1-2|+|2-1|=2$、$|4-2|+|5-1|=6$。
因此每座测站到最远测站的距离均为 `6`，输出 `6 6 6`。

## 样例2

**输入**

```
2
0 0
1 0
```

**输出**

```
1 1
```

**说明**

仅有两座测站 $(0,0)$ 与 $(1,0)$，距离为 $|0-1|+|0-0|=1$。两座测站的最远距离都是 `1`。

## 样例3

**输入**

```
3
0 0
3 4
-1 2
```

**输出**

```
7 7 6
```

**说明**

三座测站为 $(0,0)$、$(3,4)$、$(-1,2)$。
- $(0,0)$ 到 $(3,4)$ 的距离为 `7`，到 $(-1,2)$ 的距离为 `3`，最大为 `7`。
- $(3,4)$ 到 $(0,0)$ 为 `7`，到 $(-1,2)$ 为 `6`，最大为 `7`。
- $(-1,2)$ 到 $(0,0)$ 为 `3`，到 $(3,4)$ 为 `6`，最大为 `6`。
输出 `7 7 6`。
