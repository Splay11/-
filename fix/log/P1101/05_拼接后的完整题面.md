# 题目内容
小镇节日期间布置了一条由灯泡组成的灯带，每个灯泡只有亮和灭两种状态，分别用字符 `1` 和 `0` 表示。你可以进行如下操作：选择相邻的两盏灯泡，同时切换它们的亮灭状态（亮变灭、灭变亮）。你希望最终亮着的灯泡数量尽可能多，并在达到这一最大数量的前提下，使操作次数尽可能少。请你计算出最少需要多少次操作。

保证灯带长度（即字符串长度）不超过 $2 \times 10^5$。

# 输入描述
输入共一行，包含一个仅由字符 `0` 和 `1` 组成的字符串 $s$，表示灯带的初始状态。字符串长度不超过 $2 \times 10^5$。

# 输出描述
输出一个整数，表示所需的最小操作次数。

## 样例1

**输入**

```
00
```

**输出**

```
1
```

**说明**

灯带初始状态为 `"00"`，长度为 $2$，亮灯数量为 `0`。选择相邻的两盏灯泡（第 `1` 盏和第 `2` 盏）执行一次操作，两者同时切换状态，灯带变为 `"11"`，亮灯数量变为 `2`。此时亮灯数已达到理论上限（全亮），且无法用更少的操作完成，因此最少操作次数为 `1`。

## 样例2

**输入**

```
01
```

**输出**

```
0
```

**说明**

灯带初始状态为 `"01"`，亮灯数量为 `1`。每次操作会同时改变两盏灯的亮灭，因此整个灯带中亮灯总数的奇偶性不会改变。初始亮灯数为奇数 `1`，而全亮需要偶数 `2` 个亮灯，所以全亮不可能达到。最大可能的亮灯数即为 `1`，当前已经达到，无需任何操作，故最少操作次数为 `0`。

## 样例3

**输入**

```
010
```

**输出**

```
2
```

**说明**

灯带初始状态为 `"010"`，长度为 $3$，亮灯数量为 `1`。因为长度与亮灯数量同为奇数，全亮（`"111"`，亮灯数 $3$）是可以达到的。最少操作次数的一种方案为：
第一步翻转第 `1`、`2` 盏灯，`"010"` 变为 `"100"`；
第二步翻转第 `2`、`3` 盏灯，`"100"` 变为 `"111"`。
共操作 `2` 次，无法用更少的操作达到全亮，因此答案为 `2`。

## 样例4

**输入**

```
000
```

**输出**

```
2
```

**说明**

灯带初始状态为 `"000"`，长度为 $3$，亮灯数量为 `0`（偶数）。全亮需要 $3$ 个亮灯（奇数），受奇偶性限制无法达到。最大可能的亮灯数为 $2$。一种最优操作序列为：
第一步翻转第 `1`、`2` 盏灯，得到 `"110"`；
第二步翻转第 `2`、`3` 盏灯，得到 `"101"`，此时亮灯数达到最大值 $2$。
经过两次操作实现该目标且次数最少，故答案为 `2`。
