## 解题思路

- **核心性质**：每次操作会同时改变相邻两盏灯的状态，改变亮灯数量的奇偶性？实际上，操作一次会使亮灯数量变化 $-2$、$0$ 或 $+2$，即亮灯数量的奇偶性保持不变。因此，初始字符串中灭灯（`0`）的个数的奇偶性决定了能否全部变亮：
  - 若灭灯个数为偶数，则最终所有灯都可以变亮（亮灯数达到最大 $n$）。
  - 若灭灯个数为奇数，则最终必定有一盏灯保持灭，其余全部变亮（亮灯数达到最大 $n-1$）。
- **操作模型**：操作相邻两盏灯可以理解为将两盏灭灯“搬运”到一起，然后同时切换为亮。对于两个位置分别为 $i$ 和 $j$（$i<j$）的灭灯，将它们配对并变为亮所需的最小操作次数恰好为它们的距离 $j-i$（每一步操作相当于将一盏灭灯向另一盏靠近一步）。
- **偶数个灭灯的处理**：设所有灭灯的出现位置为 $p_1 < p_2 < \dots < p_{2m}$。贪心策略是相邻配对：第 $1$ 个和第 $2$ 个配对、第 $3$ 个和第 $4$ 个配对……总操作次数为
  $$\sum_{k=1}^{m} (p_{2k} - p_{2k-1})$$
  这是最优解，因为任何交叉配对都不会减少总距离。
- **奇数个灭灯的处理**：设灭灯位置为 $p_1 < p_2 < \dots < p_{2m+1}$。需要放弃其中一个灭灯不操作，使得剩下的 $2m$ 个灭灯可以完全配对变亮，且配对代价最小。由于剩下的灭灯必须被分成左右两段，且每段内灭灯个数为偶数，因此被放弃的灭灯在排序后的位置必须是**第奇数个**（$p_1, p_3, \dots$）。枚举所有可行的放弃位置 $p_{2k-1}$（$k=1,3,5,\dots,2m+1$），计算左侧前缀配对代价和右侧后缀配对代价之和，取最小值即为答案。具体步骤：
  - 预处理后缀代价数组 $last[i]$：表示从第 $i$ 个灭灯开始，将剩余灭灯按相邻配对（$i$ 与 $i+1$，$i+2$ 与 $i+3$……）所需的总代价。递推式为 $last[i] = last[i+2] + (p_{i+1} - p_i)$。
  - 枚举放弃第 $i$ 个灭灯（$i=1,3,5,\dots$），维护前缀已配对代价 $pre$，当前答案为 $\min(pre + last[i+1])$，然后 $pre$ 累加上 $p_{i+1} - p_i$（即把 $p_i$ 和 $p_{i+1}$ 配对）。

## 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 为字符串长度。只需一次遍历找出所有 `0` 的位置，再经过常数次线性扫描计算前缀/后缀代价。
- **空间复杂度**：$O(n)$。需要存储灭灯位置数组和辅助后缀数组，数组长度均不超过 $n$。

## 代码实现

### Python

```python
def solve():
    s = input().strip()
    n = len(s)
    zero_pos = []
    # 记录所有灭灯（'0'）的下标
    for i, ch in enumerate(s):
        if ch == '0':
            zero_pos.append(i)
    m = len(zero_pos)
    
    if m % 2 == 0:
        # 偶数个灭灯：相邻配对
        ans = 0
        for i in range(0, m, 2):
            ans += zero_pos[i + 1] - zero_pos[i]
        print(ans)
    else:
        # 奇数个灭灯：需要放弃一个，预处理后缀和
        last = [0] * (m + 2)
        # last[i] 表示从第i个灭灯开始的后缀配对代价（下标从0开始）
        for i in range(m - 2, -1, -2):
            last[i] = last[i + 2] + (zero_pos[i + 1] - zero_pos[i])
        INF = 10**18
        ans = INF
        pre = 0
        # 枚举放弃第 i 个灭灯（i为0, 2, 4, ...，即原始第奇数个）
        for i in range(0, m, 2):
            # 放弃 zero_pos[i]，左边 pre，右边 last[i+1]
            ans = min(ans, pre + last[i + 1])
            # 把当前这对 (i, i+1) 配对，更新 pre
            if i + 1 < m:
                pre += zero_pos[i + 1] - zero_pos[i]
        print(ans)

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        int n = s.length();
        int[] zeroPos = new int[n + 1];
        int cnt = 0;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '0') {
                zeroPos[++cnt] = i;   // 1‑based
            }
        }
        if (cnt % 2 == 0) {
            long sum = 0;
            for (int i = 1; i <= cnt; i += 2) {
                sum += zeroPos[i + 1] - zeroPos[i];
            }
            System.out.println(sum);
        } else {
            int[] lastSum = new int[cnt + 3];
            lastSum[cnt + 1] = 0;
            for (int i = cnt - 1; i >= 1; i -= 2) {
                lastSum[i] = lastSum[i + 2] + (zeroPos[i + 1] - zeroPos[i]);
            }
            long ans = (long) 1e18;
            long pre = 0;
            for (int i = 1; i <= cnt; i += 2) {
                ans = Math.min(ans, pre + lastSum[i + 1]);
                pre += zeroPos[i + 1] - zeroPos[i];
            }
            System.out.println(ans);
        }
    }
}
```

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    int n = s.size();
    vector<int> zeroPos;
    zeroPos.push_back(-1); // 占位，让下标从1开始
    for (int i = 0; i < n; ++i) {
        if (s[i] == '0') {
            zeroPos.push_back(i);
        }
    }
    int cnt = zeroPos.size() - 1; // 实际灭灯个数
    if (cnt % 2 == 0) {
        long long sum = 0;
        for (int i = 1; i <= cnt; i += 2) {
            sum += zeroPos[i + 1] - zeroPos[i];
        }
        cout << sum << '\n';
    } else {
        vector<int> lastSum(cnt + 3, 0);
        for (int i = cnt - 1; i >= 1; i -= 2) {
            lastSum[i] = lastSum[i + 2] + (zeroPos[i + 1] - zeroPos[i]);
        }
        long long ans = 1e18;
        long long pre = 0;
        for (int i = 1; i <= cnt; i += 2) {
            ans = min(ans, pre + lastSum[i + 1]);
            pre += zeroPos[i + 1] - zeroPos[i];
        }
        cout << ans << '\n';
    }
    return 0;
}
```
