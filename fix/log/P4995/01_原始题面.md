# 题目内容

线上日志预处理模块拿到长度为 $m$ 的小写字母串 $z$。需要对 $z$ 依次执行 $r$ 次变换。一次变换按位置 $p=1,2,\dots,m$ 从左到右处理，每次修改立即生效：

- 设当前位置字符为 $c$；
- 设 $x$ 为位置 $1$ 至 $p-1$ 中等于 $c$ 的个数，$y$ 为位置 $p+1$ 至 $m$ 中等于 $c$ 的个数；
- 若 $x=y$，则将位置 $p$ 改为字母表中的下一个字母（`'z'` 变为 `'a'`），否则不动。

输出执行完 $r$ 次变换后的字符串。

# 输入描述

每个测试文件均包含多组测试数据。

- 第一行读入一个整型 $q$（$1 \le q \le 200000$）代表数据组数，每组测试数据描述如下：

  1. 第一行读入两个整型 $m$ 和 $r$（$1 \le m \le 100000$；$1 \le r \le 100000$），分别表示串长与变换次数。
  2. 第二行读入一个长度为 $m$ 的字符串 $z$，保证仅由小写英文字母组成。

- 除此之外，保证单个测试文件的 $m$ 之和不超过 $100000$，$r$ 之和不超过 $100000$。

# 输出描述

对于每一组测试数据，新起一行写出做完 $r$ 次变换后的最终字符串。

## 样例1

**输入**

```
2
1 3
a
4 1
abab
```

**输出**

```
d
abab
```

**说明**

- 第一组：单字符每次必变。`a` → `b` → `c` → `d`。
- 第二组：`abab` 中各位置左右同字母个数均不相等，一次变换后不变，仍为 `abab`。
