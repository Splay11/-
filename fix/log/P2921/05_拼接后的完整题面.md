# 题目内容
对于一个由小写英文字母组成的字符串，定义它的一个\textbf{子列}为从该字符串中删除任意个字符后保持原顺序得到的字符串。如果一个字符串正读与反读完全相同，则称其为\textbf{镜像串}。对于任意一个子列，可以多次进行\textbf{字符变更}操作（每次可将任一字符替换为任意小写字母），将其变为镜像串所需的最少变更次数称为该子列的\textbf{代价}。

现给定一个长度为 $n$ 的字符串 $s$，请你求出 $s$ 的所有非空子列的代价之和，并对 $10^9+7$ 取模。

约束：字符串 $s$ 仅由小写英文字母组成，且长度 $n$ 满足 $1 \le n \le 200$。

# 输入描述
输入包含一行，为一个仅由小写英文字母构成的字符串 $s$。

# 输出描述
输出一个整数，表示所有非空子列的代价之和对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
a
```

**输出**

```
0
```

**说明**

字符串长度为 `1`，唯一的非空子列为 `"a"`。该子列本身已是镜像串，不需要进行任何字符变更操作，其代价为 `0`。因此所有非空子列的代价之和为 $0$。

## 样例2

**输入**

```
ab
```

**输出**

```
1
```

**说明**

字符串 $s = \text{``ab''}$，长度 $n=2$。其所有非空子列及代价如下：

- 长度为 `1` 的子列：`"a"`、`"b"`，均为镜像串，代价均为 $0$。
- 长度为 `2` 的子列：`"ab"`。将其变为镜像串至少需要修改 `1` 个字符（例如将 `'a'` 改为 `'b'` 得到 `"bb"`，或将 `'b'` 改为 `'a'` 得到 `"aa"`），代价为 $1$。

所有非空子列的代价之和为 $0+0+1=1$。

从组合角度来看，配对的对称位置 $(i,j)=(1,2)$ 满足 $s[1] 
eq s[2]$，根据公式 $\binom{i-1+n-j}{i-1} \times 2^{j-i-1}$ 计算贡献为 $\binom{0+0}{0} \times 2^0 = 1$，与结果一致。

## 样例3

**输入**

```
abc
```

**输出**

```
4
```

**说明**

字符串 $s = \text{``abc''}$，长度 $n=3$。所有非空子列及其代价：

- 长度为 `1` 的子列：`"a"`、`"b"`、`"c"`，代价均为 $0$。
- 长度为 `2` 的子列：`"ab"`（代价 $1$）、`"ac"`（代价 $1$）、`"bc"`（代价 $1$）。
- 长度为 `3` 的子列：`"abc"`，对称配对为 $(1,3)$ 字符 `'a'` 与 `'c'` 不同，修改其中一个即可变为镜像串（如 `"aba"` 或 `"cbc"`），代价为 $1$。

总代价为 $0+0+0+1+1+1+1 = 4$。

使用公式验证：所有满足 $i<j$ 且 $s[i] 
eq s[j]$ 的位置对 $(i,j)$ 的贡献之和为：
- $(1,2)$：$\binom{0+1}{0} \times 2^{0} = 1$
- $(1,3)$：$\binom{0+0}{0} \times 2^{1} = 2$
- $(2,3)$：$\binom{1+0}{1} \times 2^{0} = 1$

累加得到 $1+2+1=4$，与枚举结果一致。

## 样例4

**输入**

```
aab
```

**输出**

```
3
```

**说明**

字符串 $s = \text{``aab''}$，长度 $n=3$。非空子列代价：

- 长度 `1`：`"a"`（前一个）、`"a"`（后一个）、`"b"`，代价均为 $0$。
- 长度 `2`：`"aa"` 为镜像串，代价 $0$；`"ab"`（第 $1$ 个 `'a'` 与 `'b'`）代价 $1$；`"ab"`（第 $2$ 个 `'a'` 与 `'b'`）代价 $1$。
- 长度 `3`：`"aab"`，对称配对 $(1,3)$ 为 `'a'` 与 `'b'` 不同，代价 $1$。

总代价为 $0+0+0+0+1+1+1=3$。

公式计算：仅对 $s[i] 
eq s[j]$ 的 $(1,3)$ 和 $(2,3)$ 计算。
- $(1,3)$：$\binom{0+0}{0} \times 2^{1}=2$
- $(2,3)$：$\binom{1+0}{1} \times 2^{0}=1$

总和为 $2+1=3$。
