## 解题思路

设函数 $f(n)$ 表示区间 $[1, n]$ 中十进制下首尾数字相等的整数个数，则答案可表示为

$$
\text{答案} = f(R) - f(L-1)
$$

因此问题转化为如何快速计算 $f(n)$。

设 $n$ 的十进制位数为 $m$，将 $n$ 写成字符串 $s$，记最高位为 $\text{first}$，最低位为 $\text{last}$，中间部分构成的数值为 $\text{mid}$（若 $m \le 2$ 则 $\text{mid}=0$）。计算 $f(n)$ 时可以分成两类：

1. **位数小于 $m$ 的数**  
   - $1$ 位数（$1 \sim 9$）全部满足，共 $9$ 个。  
   - 对于位数 $len \ge 2$ 的数：首位可取 $1 \sim 9$（$9$ 种），末位必须与首位相同，中间 $len-2$ 位可以任取 $0 \sim 9$，共 $10^{len-2}$ 种。因此位数 $len$ 的贡献为 $9 \times 10^{len-2}$。  
   对所有 $len = 2, 3, \dots, m-1$ 求和即可。

2. **位数等于 $m$ 且不超过 $n$ 的数**  
   - **首位小于 $\text{first}$**：首位可取 $1 \sim \text{first}-1$，共 $(\text{first}-1)$ 种；末位必须与首位相同；中间 $m-2$ 位可以任意填，共 $10^{m-2}$ 种。  
     这一部分贡献为 $(\text{first}-1) \times 10^{m-2}$。  
   - **首位等于 $\text{first}$**：此时中间部分和末位共同决定该数是否 $\le n$。  
     - 中间部分取 $0 \sim \text{mid}-1$ 时，整个数一定小于 $n$，共 $\text{mid}$ 种。  
     - 中间部分恰好等于 $\text{mid}$ 时，只有当 $\text{last} \ge \text{first}$ 时，该数才 $\le n$，贡献为 $1$（条件成立）或 $0$。  
     因此这一部分贡献为 $\text{mid} + [\text{last} \ge \text{first}]$，其中 $[P]$ 表示条件 $P$ 成立时取 $1$，否则取 $0$。

将以上所有贡献相加即得 $f(n)$。由于 $R \le 10^{18}$，位数不超过 $19$，算法运行极快。

## 复杂度分析

设数字 $n$ 的位数为 $k$。  
- 时间复杂度：$O(k)$，其中 $k \le 19$（因为 $R \le 10^{18}$）。  
- 空间复杂度：$O(k)$，主要用于数字转字符串；若不计字符串空间可视为 $O(1)$。

## 代码实现

### Python

```python
# 计算 1 到 n 中首尾数字相等的数字个数
def count_same(n):
    if n <= 0:
        return 0

    s = str(n)
    m = len(s)

    # 1 位数全部满足
    if m == 1:
        return n

    ans = 0

    # 先统计位数小于 m 的所有合法数字
    ans += 9            # 1 位数的贡献
    p = 1               # 10^{len-2}，从 len=2 开始为 1
    for length in range(2, m):
        ans += 9 * p
        p *= 10

    # 再统计位数等于 m 的合法数字
    first = int(s[0])
    last = int(s[-1])

    # 处理中间部分
    if m == 2:
        mid = 0
    else:
        mid = int(s[1:-1])

    # 首位比 first 小的情况
    ans += (first - 1) * (10 ** (m - 2))

    # 首位等于 first 的情况
    ans += mid
    if last >= first:
        ans += 1

    return ans


def main():
    L, R = map(int, input().split())
    print(count_same(R) - count_same(L - 1))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {

    // 计算 1 到 n 中首尾数字相等的数字个数
    public static long countSame(long n) {
        if (n <= 0) {
            return 0;
        }

        String s = String.valueOf(n);
        int m = s.length();

        // 1 位数全部满足
        if (m == 1) {
            return n;
        }

        long ans = 0;

        // 先统计位数小于 m 的所有合法数字
        ans += 9; // 1 位数的贡献
        long p = 1;              // 10^{len-2}
        for (int len = 2; len < m; len++) {
            ans += 9 * p;
            p *= 10;
        }

        // 再统计位数等于 m 的合法数字
        int first = s.charAt(0) - '0';
        int last = s.charAt(m - 1) - '0';

        // 处理中间部分
        long mid = 0;
        if (m > 2) {
            mid = Long.parseLong(s.substring(1, m - 1));
        }

        // 计算 10^(m-2)
        long pow = 1;
        for (int i = 0; i < m - 2; i++) {
            pow *= 10;
        }

        // 首位比 first 小的情况
        ans += (long) (first - 1) * pow;

        // 首位等于 first 的情况
        ans += mid;
        if (last >= first) {
            ans += 1;
        }

        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        long L = sc.nextLong();
        long R = sc.nextLong();
        System.out.println(countSame(R) - countSame(L - 1));
    }
}
```
