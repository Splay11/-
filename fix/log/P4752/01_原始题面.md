# 题目内容

小明非常喜欢与区间相关的问题。

这一次他有一对数字$l$和$r$。小明想找出有多少个数字$x (l <= x <= r)$，满足$x$的十进制表示的第一位数字和最后一位数字相等，当然$x$不能含有前导$0$。比如$989，2，1001$就是满足条件的数字，但是$49，10，972$都不满足条件。

请你帮助小明计算出结果

# 输入描述

两个数字$l$和$r$，用一个空格分隔。

满足$1<=1<=r<=10^{18}$

# 输出描述

一个整数，满足条件的数字的个数。



## 样例1 

**输入** 

```
1 10
```

**输出** 

```
9
```





## 样例1 

**输入** 

```
88 100
```

**输出** 

```
2
```
