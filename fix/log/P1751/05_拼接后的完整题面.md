# 题目内容
有一个长度为 $n$ 的序列，每个位置上的字符是 `R` 或 `W`。你希望经过若干次操作后，使序列中所有位置都变为 `R`。

每一次操作可以选择一个起始位置，并将从这个位置开始的连续 $k$ 个字符全部改为 `R`。你最多只能进行 $m$ 次操作，并且每一次操作使用的 $k$ 必须相同。

你需要求出最小的 $k$，使得存在一种操作方案，在不超过 $m$ 次操作的前提下，能将整个序列全部变为 `R`。如果序列初始时已经全部是 `R`，则不需要任何操作，此时的答案视为 `0`。

约束条件：
- 序列长度 $n$ 满足 $1 \le n \le 2 \times 10^5$；
- 最大操作次数 $m$ 是一个正整数。

# 输入描述
第一行包含两个整数 $n$ 和 $m$，分别表示序列的长度与允许的最大操作次数。
第二行包含一个长度为 $n$ 的字符串，字符串仅由字符 `R` 和 `W` 组成，描述序列的初始状态。

# 输出描述
输出一个整数，表示满足要求的最小 $k$ 值。如果序列初始时已经全部是 `R`，则输出 `0`。

## 样例1

**输入**

```
3 2
RRR
```

**输出**

```
0
```

**说明**

序列初始已经全部为 `R`，不需要任何操作，根据题意答案视为 `0`。

## 样例2

**输入**

```
5 3
WRWWR
```

**输出**

```
1
```

**说明**

序列长度为 $n=5$，最大操作次数 $m=3$。序列中有 `3` 个 `W`（位置 $1,3,4$）。当 $k=1$ 时，每次操作可以修改 $1$ 个字符，分别对这 $3$ 个位置各进行一次操作，共需 $3$ 次，恰好满足 $m=3$ 的限制。由于 $k$ 必须是正整数，最小可行的 $k$ 为 `1`。

## 样例3

**输入**

```
9 3
WWWRRRWWW
```

**输出**

```
3
```

**说明**

序列长度为 $n=9$，最大操作次数 $m=3$。前 $3$ 个字符为 `W`，中间 $3$ 个为 `R`，最后 $3$ 个为 `W`。考虑 $k=3$，第一次操作从位置 $1$ 开始，将 $[1,3]$ 区间变为 `R`；第二次操作从位置 $7$ 开始（下一个 `W` 的位置），将 $[7,9]$ 区间变为 `R`。共需 $2$ 次操作，满足 $2 \le 3$。若 $k=2$，则至少需要 $4$ 次操作（分别覆盖 $1$～$2$、$3$～$4$、$7$～$8$、$9$ 单独一次），超出 $m=3$。因此最小的 $k$ 为 `3`。
