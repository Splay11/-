# 题目内容
你正在分析一份用户反馈数据集，其中每一条反馈都被标记为 `'positive'` 或 `'negative'` 两种情感倾向。为了找出与情感倾向相关性最强的词汇，你需要设计一个统计指标来量化每个单词的区分能力。

具体做法如下：
- 将每段反馈用词袋模型表示，即只关注每个单词是否出现（同一反馈中相同单词只计一次），且大小写字母视为不同。
- 对于每一个在至少一条反馈中出现过的单词，统计它在 `'positive'` 类与 `'negative'` 类中分别出现的反馈数量，并由此构建一个 $2 \times 2$ 的频数表。
- 根据频数表计算该单词的关联度得分 $S$。设 $A$ 为 `'positive'` 类包含该单词的反馈数，$B$ 为 `'negative'` 类包含该单词的反馈数； $C$ 为 `'positive'` 类不包含该单词的反馈数，$D$ 为 `'negative'` 类不包含该单词的反馈数。总反馈数记为 $N$，`'positive'` 类总数记为 $n_p$，`'negative'` 类总数记为 $n_n$。则四个单元格的期望频数分别为：
$$E_{11} = \frac{(A+B) \times n_p}{N}, \quad E_{12} = \frac{(A+B) \times n_n}{N}, \quad E_{21} = \frac{(C+D) \times n_p}{N}, \quad E_{22} = \frac{(C+D) \times n_n}{N}$$
 关联度得分定义为
$$S = \sum_{i=1}^{2} \sum_{j=1}^{2} \frac{(O_{ij} - E_{ij})^2}{E_{ij}}$$
其中 $O_{ij}$ 为对应的实际观测频数 $A,B,C,D$。若某个期望频数为 $0$ 则对应的项不计入。

你需要对所有单词计算得分，并按照得分从大到小排序，若得分相同则按单词的字典序升序排列，最后输出前 $k$ 个单词。

如果输入数据不满足格式要求（例如行数不正确、标签不是 `'positive'` 或 `'negative'`、缺少必要字段），请直接输出 `-1`。

**数据范围与约束**
- 反馈总数 $N$ 不超过 $10^4$。
- 每个反馈的单词数不超过 $1000$，单词只由大小写英文字母组成，长度不超过 $30$。
- 需要挑选的特征数量 $k$ 满足 $1 \le k \le 10^4$，且不超过实际不同单词的总数。

# 输入描述
第一行包含一个整数 $N$，表示反馈的数量。
接下来的 $N$ 行，每行对应一条反馈，格式为：
`<label>` `\t` `<text>`
其中 `<label>` 为字符串 `'positive'` 或 `'negative'`，`\t` 是一个制表符，`<text>` 为由空格分隔的若干单词（仅包含大小写英文字母）。
最后一行包含一个整数 $k$，表示需要输出的单词个数。

# 输出描述
对于合法的输入，输出 $k$ 行，每行一个单词，按照关联度得分 $S$ 降序排列；若两个单词得分相同，则按单词的字典序升序排列。
如果输入数据格式不正确，则输出仅一行，包含整数 `-1`。

## 样例1

**输入**

```
4
positive A B C
negative A B D
positive A C
negative B D
2
```

**输出**

```
C
D
```

**说明**

该样例共有 `4` 条反馈，其中 `'positive'` 和 `'negative'` 各 `2` 条，因此 $n_p = 2$，$n_n = 2$，总文档数 $N = 4$。

各单词的频数统计如下：
- 单词 `A`：正类出现 `2` 次，负类出现 `1` 次 → $A = 2, B = 1, C = 0, D = 1$
- 单词 `B`：正类出现 `1` 次，负类出现 `2` 次 → $A = 1, B = 2, C = 1, D = 0$
- 单词 `C`：正类出现 `2` 次，负类出现 `0` 次 → $A = 2, B = 0, C = 0, D = 2$
- 单词 `D`：正类出现 `0` 次，负类出现 `2` 次 → $A = 0, B = 2, C = 2, D = 0$

计算卡方值 $S$：
- $S(\text{C}) = 4.0$，$S(\text{D}) = 4.0$
- $S(\text{A}) \approx 1.333$，$S(\text{B}) \approx 1.333$

按得分降序排列，得分相同时按字典序升序。由于 `C` 和 `D` 得分相同且 `C` 的字典序较小，因此前 `2` 个单词为 `C` 和 `D`。

## 样例2

**输入**

```
6
positive word1 word2 word3
positive word1 word4
positive word2
negative word1 word3
negative word2 word3
negative word3
3
```

**输出**

```
word3
word4
word1
```

**说明**

该样例包含 `6` 条反馈，其中正类 `3` 条，负类 `3` 条，$n_p = 3$，$n_n = 3$，$N = 6$。

各单词频数：
- `word1`：正类 `2` 次，负类 `1` 次 → $A = 2, B = 1, C = 1, D = 2$
- `word2`：正类 `2` 次，负类 `1` 次 → $A = 2, B = 1, C = 1, D = 2$
- `word3`：正类 `1` 次，负类 `3` 次 → $A = 1, B = 3, C = 2, D = 0$
- `word4`：正类 `1` 次，负类 `0` 次 → $A = 1, B = 0, C = 2, D = 3$

计算出的得分分别为：
- $S(\text{word3}) = 3.0$
- $S(\text{word4}) \approx 1.2$
- $S(\text{word1}) \approx 0.667$
- $S(\text{word2}) \approx 0.667$

得分相同时按字典序排序，`word1` < `word2`，因此最终前 `3` 个单词为 `word3`、`word4`、`word1`。

## 样例3

**输入**

```
2
positive A B
negative A
2
```

**输出**

```
B
A
```

**说明**

仅包含 `2` 条反馈，正负类各 `1` 条，边界情况 $N = 2, n_p = 1, n_n = 1$。

单词统计：
- `A`：正类出现 `1` 次，负类出现 `1` 次 → $A = 1, B = 1, C = 0, D = 0$
- `B`：正类出现 `1` 次，负类出现 `0` 次 → $A = 1, B = 0, C = 0, D = 1$

计算得 $S(\text{B}) = 2.0$，$S(\text{A}) = 0.0$。按得分降序输出，`k = 2` 恰好等于词汇总数，因此输出 `B` 和 `A`。

## 样例4

**输入**

```
2
neutral Hello
positive World
1
```

**输出**

```
-1
```

**说明**

输入格式错误：第一行给出 `N = 2`，但第二行的标签 `'neutral'` 不是合法的 `'positive'` 或 `'negative'`，因此程序直接输出 `-1` 并结束。
