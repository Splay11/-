# 题目内容
在数字世界中，有两个能量核心，它们的初始能量分别为 $p$ 和 $q$。你可以进行最多 $m$ 次充能操作，每次操作可以选择一个能量核心，将其能量增加 $1$。操作完成后，两个能量核心会以它们能量的最大公约数为频率产生共振。你希望这个共振频率尽可能大。

请你计算，经过不超过 $m$ 次充能后，两个能量值最大可能的公约数是多少。

输入包含多组测试用例，组数不超过 `20`。每个测试用例中的三个整数均满足 $1 \le p, q, m \le 10^5$。

# 输入描述
第一行包含一个整数 $T$，表示测试用例的数量。
接下来 $T$ 行，每行包含三个整数 $p$、$q$、$m$，分别表示两个能量核心的初始能量和最多充能次数。

# 输出描述
输出 $T$ 行，每行一个整数，表示对应测试用例能达到的最大共振频率。

## 样例1

**输入**

```
2
2 4 0
3 5 1
```

**输出**

```
2
3
```

**说明**

第一组数据：初始能量为 $p=2$, $q=4$，无法进行任何充能 ($m=0$)。两数的最大公约数就是它们本身的公约数 $\gcd(2,4)=2$。

第二组数据：初始为 $p=3$, $q=5$，最多充能 `1` 次。如果把仅有的一次充能给 $q$，使其变为 `6`，则 $\gcd(3,6)=3$；若充能给 $p$ 变为 `4`，则 $\gcd(4,5)=1$。最优选择是得到 $3$。

## 样例2

**输入**

```
1
7 11 3
```

**输出**

```
4
```

**说明**

初始能量 $p=7$, $q=11$，最多充能 $m=3$ 次。
尝试让最终公约数为 $g=4$：需要将 $p$ 增加到不小于 `7` 的最小 `4` 的倍数，即 `8`，耗费 $8-7=1$ 次；将 $q$ 增加到不小于 `11` 的最小 `4` 的倍数，即 `12`，耗费 $12-11=1$ 次。总耗费 `2` 次 $\le 3$，可行。
若尝试 $g=5$：$p$ 需增至 `10`（耗费 `3` 次），$q$ 需增至 `15`（耗费 `4` 次），总耗费 `7` 次 $>3$，不可行。更大的 $g$ 同样不可行。因此最大可达公约数为 $4$。

## 样例3

**输入**

```
1
1 1 100000
```

**输出**

```
50001
```

**说明**

初始能量两者均为 `1`，充能次数 $m=100000$。
对于某个目标公约数 $g$，需要将两个 `1` 都增加到 $g$ 的倍数 $\lceil 1/g \rceil \times g = g$，各自需要 $g-1$ 次操作，总耗费 $2(g-1)$ 次。要求 $2(g-1) \le 100000$，解得 $g \le 50001$。
当 $g=50001$ 时，两个数均变为 `50001`，每数耗费 `50000` 次，总耗费恰好 $100000$，满足条件。此时公约数为 `50001`，达到最大。
