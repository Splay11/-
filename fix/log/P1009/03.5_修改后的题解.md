## 解题思路

问题要求在不超过 $m$ 次充能的前提下，最大化两个能量核心最终能量值的最大公约数。  
设最终第一个核心的能量为 $p + a$，第二个为 $q + b$，其中 $a,b \ge 0$ 且 $a + b \le m$。我们需要让 $\gcd(p+a, q+b)$ 尽可能大。

直接枚举所有可能的 $(a,b)$ 组合会超时，但我们可以转换思路：  
枚举**最终公约数的可能值** $g$，并判断是否能够通过合法操作使得两个能量值同时被 $g$ 整除。

- 对于固定的 $g$，为了让 $p$ 变为 $g$ 的倍数，至少需要增加  
  $\text{add}_p = (g - p \bmod g) \bmod g$ 次充能。  
- 同理，对于 $q$ 至少需要增加  
  $\text{add}_q = (g - q \bmod g) \bmod g$ 次充能。  
- 若 $\text{add}_p + \text{add}_q \le m$，说明我们可以通过不超过 $m$ 次操作让两个数都成为 $g$ 的倍数，此时公约数至少为 $g$。此时剩余的充能次数可以任意分配，不会使公约数变小。

因为 $p, q, m \le 10^5$，最终两个能量值之和不会超过 $p+q+m \le 3\times 10^5$，所以公约数 $g$ 的上限也是 $3\times 10^5$。  
我们从大到小枚举 $g$，第一个满足 $\text{add}_p + \text{add}_q \le m$ 的 $g$ 即为答案。这样每组测试数据的枚举量与 $p+q+m$ 同阶，可以在时限内完成。

## 复杂度分析

- 时间复杂度：对于每组测试数据，$g$ 的取值范围上界为 $p+q+m$，最大约为 $3\times 10^5$，每次判断只需常数时间。总测试组数 $T \le 20$，因此总时间复杂度为 $O(T \cdot (p+q+m))$，可以接受。  
- 空间复杂度：仅使用常数个变量，空间复杂度为 $O(1)$。

## 代码实现

### Python

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    T = int(next(it))
    out_lines = []
    for _ in range(T):
        p = int(next(it))
        q = int(next(it))
        m = int(next(it))
        # 公约数不可能超过总和的上限
        upper = p + q + m
        ans = 1
        for g in range(upper, 0, -1):
            # 计算使 p 和 q 分别成为 g 的倍数所需的最小增加量
            add_p = (g - p % g) % g
            add_q = (g - q % g) % g
            if add_p + add_q <= m:
                ans = g
                break
        out_lines.append(str(ans))
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine().trim());
        StringBuilder sb = new StringBuilder();
        while (T-- > 0) {
            String[] parts = br.readLine().trim().split("\\s+");
            int p = Integer.parseInt(parts[0]);
            int q = Integer.parseInt(parts[1]);
            int m = Integer.parseInt(parts[2]);
            int upper = p + q + m;
            int ans = 1;
            for (int g = upper; g >= 1; g--) {
                int addP = (g - p % g) % g;
                int addQ = (g - q % g) % g;
                if (addP + addQ <= m) {
                    ans = g;
                    break;
                }
            }
            sb.append(ans).append("\n");
        }
        System.out.print(sb);
    }
}
```

                break;
            }
        }
        cout << ans << '\n';
    }
    return 0;
}
