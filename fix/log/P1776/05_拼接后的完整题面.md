# 题目内容
小蓝有一个长度为偶数的正整数序列，他想通过若干次变换，使得序列中奇数的个数和偶数的个数恰好相等。

小蓝可以对序列中的任意一个数字进行以下两种变换之一：
1. 将该数字乘以 $2$；
2. 将该数字除以 $2$，并舍去小数部分（即向下取整）。

例如，将 $6$ 除以 $2$ 后变为 $3$；将 $3$ 乘以 $2$ 后变为 $6$。

小蓝希望用最少的变换次数达到目标。请你帮他计算，最少需要多少次变换。

约束条件：
- 序列的长度 $n$ 为偶数，且 $2 \le n \le 10^5$。
- 序列中的每个数字均为正整数，且值不超过 $10^9$。

# 输入描述
第一行包含一个正偶数 $n$，表示序列的长度。
第二行包含 $n$ 个正整数，表示初始序列。

# 输出描述
输出一个整数，表示达成目标所需的最少变换次数。

## 样例1

**输入**

```
4
2 3 4 5
```

**输出**

```
0
```

**说明**

序列长度 $n=4$，目标奇数和偶数个数各为 $n/2=2$。初始序列中有 `2` 个奇数（`3`、`5`）和 `2` 个偶数（`2`、`4`），奇偶个数已经相等，无需任何变换，答案为 $0$。

## 样例2

**输入**

```
4
3 5 2 7
```

**输出**

```
1
```

**说明**

序列长度 $n=4$，目标各 $2$ 个。初始序列中有 `3` 个奇数（`3`、`5`、`7`）和 `1` 个偶数（`2`）。奇数比目标多出 $1$ 个，需要将 $1$ 个奇数变为偶数。将任意一个奇数乘以 $2$ 只需 $1$ 次操作即可变成偶数，因此最少操作次数为 $1$。

## 样例3

**输入**

```
4
6 8 10 1
```

**输出**

```
1
```

**说明**

序列长度 $n=4$，目标各 $2$ 个。初始有 `1` 个奇数（`1`）和 `3` 个偶数（`6`、`8`、`10`）。偶数比目标多 $1$ 个，需将 $1$ 个偶数变为奇数。

将偶数不断除以 $2$ 直至变成奇数所需操作次数：$6 \div 2 = 3$，次数 $1$；$8 \div 2 \div 2 \div 2 = 1$，次数 $3$；$10 \div 2 = 5$，次数 $1$。选择最小操作次数 $1$，故答案为 $1$。

## 样例4

**输入**

```
6
16 32 64 2 4 1
```

**输出**

```
3
```

**说明**

序列长度 $n=6$，目标各 $3$ 个。初始有 `1` 个奇数（`1`）和 `5` 个偶数（`16`、`32`、`64`、`2`、`4`）。偶数多出 $2$ 个，需要选择 $2$ 个偶数变为奇数。

每个偶数变为奇数所需最小操作次数为其质因数中 $2$ 的幂次：$2$ 需要 $1$ 次，$4$ 需要 $2$ 次，$16$ 需要 $4$ 次，$32$ 需要 $5$ 次，$64$ 需要 $6$ 次。将次数排序后取最小的 $2$ 个：$1$ 和 $2$，总和为 $3$。因此最少操作次数为 $3$。
