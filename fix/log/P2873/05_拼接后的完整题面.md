# 题目内容
小蓝有一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。她定义一个“彩虹阶梯”为满足以下条件的长度为 `5` 的序列：将其所有元素按从小到大排序后，每个元素恰好比前一个元素大 `1`。

现在，小蓝想知道，原序列有多少个长度为 `5` 的子序列是“彩虹阶梯”。这里，一个序列的子序列是指从原序列中删除若干个（可以为零个）元素后，保持原有顺序得到的新序列。

由于答案可能很大，请将结果对 $10^9+7$ 取模。

序列的长度 $n$ 满足 $1 \le n \le 10^5$，序列中的每个整数 $a_i$ 满足 $1 \le a_i \le 10^9$。

# 输入描述
第一行包含一个整数 $n$，表示序列的长度。
第二行包含 $n$ 个整数，表示序列 $a_1, a_2, \dots, a_n$。

# 输出描述
输出一个整数，表示“彩虹阶梯”子序列的数量对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
5
1 2 3 4 5
```

**输出**

```
1
```

**说明**

序列中 `1`、`2`、`3`、`4`、`5` 各出现一次，且值集合恰好是 $\{1,2,3,4,5\}$。唯一的长度为 `5` 的子序列就是原序列本身，将其排序后每个元素恰比前一个大 `1`，是一个彩虹阶梯。因此答案为 `1`。

## 样例2

**输入**

```
7
1 1 2 2 3 4 5
```

**输出**

```
4
```

**说明**

统计各值出现次数：`1` 出现 `2` 次，`2` 出现 `2` 次，`3`、`4`、`5` 各出现 `1` 次。

要组成彩虹阶梯，子序列的值必须恰好是 $1,2,3,4,5$。对于值 `1` 有 `2` 种选择（两个位置），值 `2` 有 `2` 种选择，值 `3`、`4`、`5` 各有 `1` 种选择。且不论我们为每个值选取哪个位置，这五个位置的升序排列总能给出一个合法的子序列。因此总方法数为 $2 \times 2 \times 1 \times 1 \times 1 = 4$，对 $10^9+7$ 取模后仍为 `4`。

## 样例3

**输入**

```
6
1 3 5 7 9 11
```

**输出**

```
0
```

**说明**

序列中只包含奇数，任意五个连续整数必然包含偶数，因此不存在满足条件的五个连续整数。没有任何长度为 `5` 的子序列能成为彩虹阶梯，答案为 `0`。
