# 题目内容
有两组长度均为 $n$ 的读数 $a_1, a_2, \ldots, a_n$ 与 $b_1, b_2, \ldots, b_n$。对任意一个读数，你可以把它乘以 $-1$（取相反数），也可以保持不变。每个读数的决策相互独立。

校准误差定义为 $\sum_{i=1}^{n} |a_i' - b_i'|$，其中 $a_i'$、$b_i'$ 表示经过取反决策之后的对应值。请计算可能达到的最小校准误差。

约束：$1 \le n \le 10^5$，每个读数的绝对值不超过 $10^9$。

# 输入描述
第一行一个正整数 $n$，表示每组读数的长度。
第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$。
第三行 $n$ 个整数 $b_1, b_2, \ldots, b_n$。
保证 $1 \le n \le 10^5$，且 $-10^9 \le a_i, b_i \le 10^9$。

# 输出描述
输出一个整数，表示最小校准误差。

## 样例1

**输入**

```
2
5 -3
5 3
```

**输出**

```
0
```

**说明**

第一个位置 $\min(|5-5|,|5+5|)=`0`$；第二个位置 $\min(|-3-3|,|-3+3|)=`0`。答案为 `0`。

## 样例2

**输入**

```
1
-10
7
```

**输出**

```
3
```

**说明**

只有一个位置，$n=`1`$。$\min(|-10-7|,|-10+7|)=\min(`17`,`3`)=`3`。
