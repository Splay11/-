## 解题思路

不同下标的读数互不影响，因此可以对每个位置单独最小化 $|a_i' - b_i'|$，再把结果相加。

对第 $i$ 个位置，$a_i$ 与 $b_i$ 各自可以选择取反或不取反，共四种组合，对应的差的绝对值为

$$
\min\bigl(|a_i - b_i|, |a_i + b_i|, |-a_i - b_i|, |-a_i + b_i|\bigr).
$$

由于 $|-a_i - b_i| = |a_i + b_i|$，$|-a_i + b_i| = |a_i - b_i|$，上式化简为

$$
\min(|a_i - b_i|, |a_i + b_i|).
$$

对所有位置累加即可。答案可能超过 `32` 位整数范围，需要使用 `64` 位整数。

## 复杂度分析

每个位置常数时间计算，共扫描 $n$ 个位置。

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))
ans = 0
for i in range(n):
    ans += min(abs(a[i] - b[i]), abs(a[i] + b[i]))
print(ans)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] a = new int[n];
        int[] b = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }
        for (int i = 0; i < n; i++) {
            b[i] = sc.nextInt();
        }
        long ans = 0;
        for (int i = 0; i < n; i++) {
            ans += Math.min(Math.abs(a[i] - b[i]), Math.abs(a[i] + b[i]));
        }
        System.out.println(ans);
        sc.close();
    }
}
```
