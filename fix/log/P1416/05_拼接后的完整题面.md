# 题目内容
请实现一个简易表达式计算器。表达式是一行字符串，仅可能包含下列字符：左括号 `(`、右括号 `)`、加号 `+`、减号 `-`、乘号 `*`、除号 `/`、十进制数字以及空格。

运算规则如下：

- `+`、`-`、`*`、`/` 表示四则运算，其中 `*` 与 `/` 的优先级高于 `+` 与 `-`，同一优先级从左到右计算；
- 括号用于改变运算顺序；
- 数字均为非负整数；
- 除法为整数除法，不能整除时向上取整；
- 空格应被忽略。

不能调用编程语言自带的表达式求值接口。

约束：字符串长度 $n$ 满足 $1 \le n \le 1024$。

# 输入描述
一行字符串，表示待求值的算术表达式。字符串仅由 `(`、`)`、`+`、`-`、`*`、`/`、数字和空格组成，长度满足 $1 \le n \le 1024$。

# 输出描述
输出一个整数，表示表达式的计算结果。

## 样例1

**输入**

```
10/3
```

**输出**

```
4
```

**说明**

整数除法向上取整：$\lceil 10/3 \rceil=`4`。

## 样例2

**输入**

```
1+2*3
```

**输出**

```
7
```

**说明**

乘法优先于加法：$2 \times 3=`6`$，再加 `1` 得到 `7`。

## 样例3

**输入**

```
( 1 + 2 ) * 3
```

**输出**

```
9
```

**说明**

空格被忽略。括号内 $1+2=`3`$，再乘 `3` 得到 `9`。这是含空格与括号的情形。
