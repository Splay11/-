# 题目内容
在某银河联邦中，有 $n$ 个空间站，编号 $1$ 到 $n$，由 $n-1$ 条双向通道连接成一棵以 $1$ 号站为总部的树形网络。每个空间站上铭刻着一个小写字母作为其标识符。

对于任意空间站 $i$，我们考虑从其辖区（即 $i$ 及其所有后代空间站构成的集合）中选取两个空间站 $x$ 和 $y$（允许 $x=y$），要求：
- $i$ 是从总部通往 $x$ 和 $y$ 的两条路径上最后重合的节点（即最近公共枢纽）；
- $x$ 到 $i$ 所经过的空间站数目（包含 $x$ 和 $i$）等于 $y$ 到 $i$ 所经过的空间站数目。

若沿着 $x$ 到 $y$ 的唯一通道，依次读取途径空间站的标识符，得到的字符串是一个回文（即正读与反读相同），则称 $(x,y)$ 构成一次“镜像航行”。定义 $i$ 的「航行半径」为所有镜像航行中 $x$ 与 $y$ 之间沿途空间站总数（即路径上的节点数）的最大值。

你的任务是求出每个空间站的航行半径。

数据规模：空间站数量 $n$ 满足 $1 \le n \le 10^5$，所有标识符均为小写英文字母。

# 输入描述
第一行包含一个整数 $n$（$1 \le n \le 10^5$），表示空间站的数量。
第二行包含一个长度为 $n$ 的字符串 $s$，其中第 $i$ 个字符表示编号为 $i$ 的空间站的标识符。
接下来 $n-1$ 行，每行包含两个整数 $u$ 和 $v$（$1 \le u, v \le n$），表示一条双向通道连接 $u$ 和 $v$。输入保证构成一棵树。

# 输出描述
输出一行，包含 $n$ 个整数，用空格分隔，第 $i$ 个整数表示空间站 $i$ 的航行半径。

## 样例1

**输入**

```
1
x
```

**输出**

```
1
```

**说明**

仅有 `1` 个空间站，它自身构成镜像航行，路径仅包含 `1` 个节点，标识符为 `x`，是回文。因此航行半径为 `1`。

## 样例2

**输入**

```
5
abbaa
1 2
1 3
2 4
3 5
```

**输出**

```
5 1 1 1 1
```

**说明**

树形：`1` 为根，子节点 `2`、`3`；`2` 的子节点 `4`；`3` 的子节点 `5`。标识符依次为：`1`='a'、`2`='b'、`3`='b'、`4`='a'、`5`='a'。
对于空间站 `1`：选取 $x=4$，$y=5$，它们的最近公共枢纽为 `1`。$x$ 到 `1` 经过节点 $4,2,1$，共 `3` 个；$y$ 到 `1` 经过 $5,3,1$，共 `3` 个，距离相等。从 $4$ 到 $5$ 的路径为 $4 	o 2 	o 1 	o 3 	o 5$，标识符依次为 `a`、`b`、`a`、`b`、`a`，形成回文 `ababa`，路径总节点数为 `5`。因此 `1` 的航行半径为 `5`。其他空间站无法找到长度大于 `1` 的镜像航行，半径均为 `1`。

## 样例3

**输入**

```
7
zaabbbc
1 2
1 3
2 4
2 5
3 6
3 7
```

**输出**

```
5 3 1 1 1 1 1
```

**说明**

树形：根 `1` 有子 `2`、`3`；`2` 有子 `4`、`5`；`3` 有子 `6`、`7`。标识符依次为：`1`='z'、`2`='a'、`3`='a'、`4`='b'、`5`='b'、`6`='b'、`7`='c'。
- 对于空间站 `2`：取 $x=4$，$y=5$，LCA 为 `2`，二者到 `2` 的距离均为 $1$。路径 $4 	o 2 	o 5$ 的标识符为 `b`、`a`、`b`，是回文，路径节点数为 $2 	imes 1 + 1 = 3$。故 `2` 的航行半径为 `3`。
- 对于空间站 `1`：取 $x=4$（属于子树 `2`），$y=6$（属于子树 `3`），LCA 为 `1`，二者到 `1` 的距离均为 $2$。路径 $4 	o 2 	o 1 	o 3 	o 6$ 的标识符为 `b`、`a`、`z`、`a`、`b`，是回文，路径节点数为 $2 	imes 2 + 1 = 5$。因此 `1` 的航行半径为 `5`。
其他空间站（`3`、`4`、`5`、`6`、`7`）仅能自身构成镜像航行，半径均为 `1`。
