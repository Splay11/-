## 解题思路

所求为所有区间 $[L, R]$ 的累积代价之和：

$$
S = \sum_{1 \le L \le R \le n} C(L, R) = \sum_{1 \le L \le R \le n} \sum_{k=L}^R \min(a_L, \dots, a_k).
$$

交换求和顺序，固定左端点 $L$ 和区间内位置 $k$（满足 $L \le k$），则右端点 $R$ 可取 $k, \dots, n$ 共 $n - k + 1$ 种。因此

$$
S = \sum_{k=1}^n (n - k + 1) \cdot G(k),
$$

其中

$$
G(k) = \sum_{L=1}^k \min(a_L, \dots, a_k).
$$

$G(k)$ 表示以 $k$ 为右端点的所有前缀区间的最小值之和。

我们可以在从左到右扫描序列的过程中，利用**单调栈**增量式维护 $G(k)$：

- 栈中每个元素为二元组 $(v, c)$，表示在当前右端点 $k$ 处，有 $c$ 个左端点 $L$ 对应的区间最小值为 $v$，且栈中 $v$ 值严格递增。
- 初始时栈为空，当前 $G$ 值 `cur = 0`，答案 `ans = 0`。
- 遍历 $k = 1$ 到 $n$，设当前元素 $x = a_k$：
  1. 初始化 `cnt = 1`（表示以 $k$ 为左端点的新段，最小值暂时为 $x$）。
  2. 当栈非空且栈顶的 $v \ge x$ 时：
     - 弹出栈顶 $(v, c)$；
     - `cur = cur - v * c`（这些段的最小值从 $v$ 变为更小的 $x$ 或与 $x$ 合并）；
     - `cnt = cnt + c`（这些段将合并到新的最小值段中）。
  3. 将 $(x, cnt)$ 压入栈中；
  4. `cur = cur + x * cnt`（得到新的 $G(k)$）；
  5. 累加答案：`ans = ans + cur * (n - k + 1)`。
- 所有加减和乘法过程中都对 $1000000007$ 取模，注意处理负数取模。

## 复杂度分析

对于每个测试用例，序列中的每个元素最多入栈一次、出栈一次，因此单用例时间复杂度为 $O(n)$。  
所有测试用例的长度总和不超过 $3 \times 10^5$，因此总时间复杂度为 $O(\sum n)$。  
空间复杂度：单调栈最多存储 $n$ 个元素，故单用例空间复杂度为 $O(n)$，总空间复杂度也为 $O(\sum n)$。

## 代码实现

### Python

```python
MOD = 1000000007

q = int(input())
for _ in range(q):
    n = int(input())
    a = list(map(int, input().split()))
    st = []          # 栈中保存 (最小值, 段数)
    cur = 0          # 当前 G(k)
    ans = 0
    for k, x in enumerate(a, 1):
        cnt = 1
        while st and st[-1][0] >= x:
            v, c = st.pop()
            cur = (cur - v * c) % MOD
            cnt += c
        st.append((x, cnt))
        cur = (cur + x * cnt) % MOD
        ans = (ans + cur * (n - k + 1)) % MOD
    print(ans)
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    static final long MOD = 1000000007L;
    
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int q = Integer.parseInt(br.readLine().trim());
        StringBuilder output = new StringBuilder();
        
        while (q-- > 0) {
            int n = Integer.parseInt(br.readLine().trim());
            long[] a = new long[n];
            StringTokenizer st = new StringTokenizer(br.readLine());
            for (int i = 0; i < n; i++) {
                a[i] = Long.parseLong(st.nextToken());
            }
            
            ArrayDeque<long[]> stack = new ArrayDeque<>(); // {value, count}
            long cur = 0, ans = 0;
            
            for (int k = 1; k <= n; k++) {
                long x = a[k - 1];
                long cnt = 1;
                while (!stack.isEmpty() && stack.peekLast()[0] >= x) {
                    long[] top = stack.pollLast();
                    cur = (cur - top[0] * top[1]) % MOD;
                    cnt += top[1];
                }
                stack.addLast(new long[]{x, cnt});
                cur = (cur + x * cnt) % MOD;
                if (cur < 0) cur += MOD;
                ans = (ans + cur * (n - k + 1)) % MOD;
            }
            output.append(ans).append('\n');
        }
        System.out.print(output);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const long long MOD = 1000000007LL;
    
    int q;
    cin >> q;
    while (q--) {
        int n;
        cin >> n;
        vector<long long> a(n);
        for (int i = 0; i < n; ++i) cin >> a[i];
        
        vector<pair<long long, long long>> st; // (最小值, 段数)
        long long cur = 0, ans = 0;
        
        for (int k = 1; k <= n; ++k) {
            long long x = a[k - 1];
            long long cnt = 1;
            while (!st.empty() && st.back().first >= x) {
                cur = (cur - st.back().first * st.back().second) % MOD;
                cnt += st.back().second;
                st.pop_back();
            }
            st.push_back({x, cnt});
            cur = (cur + x * cnt) % MOD;
            if (cur < 0) cur += MOD;
            ans = (ans + cur * (n - k + 1)) % MOD;
        }
        cout << ans << '\n';
    }
    return 0;
}
```
