# 题目内容

运维侧拿到长度为 $m$ 的整型指标序列 $h$。

对区间 $[L,R]$ 定义

$$
F(L,R)=\sum_{k=L}^{R}\min(h_L,\ldots,h_k)。
$$

求所有 $1\le L\le R\le m$ 的 $F(L,R)$ 之和，结果对 $1000000007$ 取模。

# 输入描述

共有多组独立用例，需逐组求解。

- 首行给出整型 $q$（$1 \le q \le 100000$），表示用例个数。
- 每组格式如下：
  1. 第一行一个整型 $m$（$1 \le m \le 200000$）；
  2. 第二行 $m$ 个整型 $h_1,\dots,h_m$（$0 \le h_i \le 1000000000$）。
- 全体用例的 $m$ 之和不超过 $300000$。

# 输出描述

每组一行一个整数：上述总和对 $1000000007$ 取模的结果。

## 样例1

**输入**

```
2
2
1 2
1
5
```

**输出**

```
5
5
```

**说明**

- 第一组：$F(1,1)=1$，$F(1,2)=1+\min(1,2)=2$，$F(2,2)=2$，和为 $5$。
- 第二组：仅一段 $[5]$，答案 $5$。
