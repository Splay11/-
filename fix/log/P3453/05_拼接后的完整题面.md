# 题目内容
值班室把所有偶数工号按从小到大的顺序写成十进制，再依次拼接成一条无限长的数字串，得到 `0246810121416...`。

给定正整数 $n$，请确定该串的第 $n$ 个字符（下标从 `1` 开始）。

$n$ 不超过 $10^5$。

# 输入描述
一行一个整数 $n$，表示要求的位置。
保证 $1 \le n \le 10^5$。

# 输出描述
输出一个字符，表示该数字串的第 $n$ 个字符。

## 样例1

**输入**

```
2
```

**输出**

```
2
```

**说明**

串的前两位是 `0` 和 `2`，第 `2` 个字符是 `2`。

## 样例2

**输入**

```
11
```

**输出**

```
4
```

**说明**

前缀 `02468101214` 长度为 `11`，末位来自工号 `14` 的个位，答案为 `4`。

## 样例3

**输入**

```
3
```

**输出**

```
4
```

**说明**

按题意模拟计算得到。
