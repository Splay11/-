## 解题思路

不必真正拼接出整条数字串。从工号 `0` 开始，每次加 `2`，按十进制写出当前偶数 $k$，用累加器记录已经覆盖的字符数。

设已覆盖长度为 $acc$，当前偶数写成字符串 $t$。若 $acc+|t|\ge n$，则第 $n$ 个字符落在 $t$ 内，其在 $t$ 中从 `0` 开始的下标为 $n-acc-1$。否则把 $|t|$ 累加进 $acc$，继续下一个偶数。

因为 $n\le 10^5$，枚举到的偶数规模有限，直接模拟即可。

## 复杂度分析

每个偶数贡献的字符数随位数缓慢增长，枚举次数远小于 $n$。

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(1)$。

## 代码实现

### Python

```python
n = int(input().strip())

acc = 0
k = 0

while True:
    t = str(k)
    if acc + len(t) >= n:
        print(t[n - acc - 1])
        break
    acc += len(t)
    k += 2
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String line = br.readLine();
        long n = Long.parseLong(line.trim());

        long acc = 0;
        for (long k = 0;; k += 2) {
            String t = Long.toString(k);
            if (acc + t.length() >= n) {
                int idx = (int)(n - acc - 1);
                System.out.println(t.charAt(idx));
                break;
            }
            acc += t.length();
        }
    }
}
```
