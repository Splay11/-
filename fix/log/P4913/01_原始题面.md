# 题目内容
给定 $n$ 个非负整数，你可以先对它们进行任意重新排列。随后，你需要将重排后的序列划分成若干**连续段**，每个元素必须恰好属于一段。设一段中包含的元素个数为 $t$，其中的最小值为 $m$，最大值为 $M$，则该段必须满足以下两个条件：

- $1 \le t \le L$；
- $M - m \le D + E 	imes (t - 1)$。

你的目标是使划分的段数尽可能少，请计算最少段数。

**数据范围：** 测试数据组数不超过 $10^5$。对于每组数据，元素个数 $n$ 不超过 $2 	imes 10^5$，所有组的 $n$ 之和也不超过 $2 	imes 10^5$。整数 $D$ 和 $E$ 满足 $0 \le D, E \le 10^9$，整数 $L$ 满足 $1 \le L \le n$。每个元素的值均在 $0$ 到 $10^9$ 之间。

# 输入描述
第一行包含一个整数 $T$，表示测试数据组数。
接下来依次描述每组数据：
第一行包含四个整数 $n, D, E, L$，含义如题目所述。
第二行包含 $n$ 个整数，表示序列中的元素。

# 输出描述
对于每组测试数据，输出一行一个整数，表示最少可以划分的段数。

## 样例1

**输入**

```
1
1 0 0 1
5
```

**输出**

```
1
```

**说明**

只有一个元素 `5`，必须且只能将它单独划分为一段。该段的元素个数 $t = 1$，满足 $1 \le L$（$L=1$）；最大值和最小值均为 `5`，差值 $M - m = 0$，满足 $0 \le D + E 	imes (t-1)$（此时 $D = 0, E = 0$）。因此最少段数为 `1`。

## 样例2

**输入**

```
1
4 0 0 2
2 2 3 3
```

**输出**

```
2
```

**说明**

给定序列为 `[2, 2, 3, 3]`，可以将其排序（本身已有序）。因为 $D = 0, E = 0$，每一段必须满足 $M - m \le 0$，即段内所有元素必须相等。同时每段长度上限 $L = 2$。

最优方案是将两个 `2` 划分为一段（$t=2, M=m=2$），两个 `3` 划分为另一段（$t=2, M=m=3$），总段数为 `2`。由于元素不全相同，无法合并为一段，因此最少段数就是 `2`。

## 样例3

**输入**

```
1
5 2 1 5
1 3 5 7 9
```

**输出**

```
2
```

**说明**

对序列排序得到 `[1, 3, 5, 7, 9]`。可以将其划分为两段：第一段为 `[1, 3, 5]`，元素个数 $t = 3$，最大值 $M = 5$，最小值 $m = 1$，差值 $M - m = 4$，而 $D + E 	imes (t - 1) = 2 + 1 	imes 2 = 4$，满足条件。第二段为 `[7, 9]`，$t = 2$，$M - m = 2$，$D + E 	imes (t - 1) = 2 + 1 	imes 1 = 3$，满足条件。

若尝试合并为一段，则 $t = 5$，差值 $9 - 1 = 8$，而 $D + E 	imes (t - 1) = 2 + 1 	imes 4 = 6$，不满足要求。因此最少段数为 `2`。
