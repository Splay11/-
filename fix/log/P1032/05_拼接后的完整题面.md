# 题目内容
小明正在为数据备份项目采购云存储空间。市场上有两家服务商 X 和 Y，各自只提供一种固定规格的存储套餐：

- X 套餐：每份包含 $b$ GB，售价 $a$ 元；
- Y 套餐：每份包含 $d$ GB，售价 $c$ 元。

每种套餐均可购买任意多份，但小明只能选择其中一家服务商，不能混买。

现在小明需要至少 $k$ GB 的存储空间，他希望“全部从 X 购买的总花费”严格小于“全部从 Y 购买的总花费”。
请你帮助小明找出任意一个满足条件的正整数 $k$。若这样的 $k$ 不存在，则输出 `-1`。

注意：购买一份套餐即可获得对应容量，不够时可购买多份，多买的容量不会被浪费，但花费按整数份计算。换句话说，至少需要 $k$ GB 时，从 X 购买需要 $\lceil k/b \rceil$ 份，花费 $a \times \lceil k/b \rceil$；从 Y 购买需要 $\lceil k/d \rceil$ 份，花费 $c \times \lceil k/d \rceil$。

约束条件：
- 询问次数 $t$ 不超过 $10^3$。
- 所有单价和容量参数 $a, b, c, d$ 均为正整数且不超过 $10^9$。
- 输出的 $k$ 必须满足 $0 < k < 2^{31}$。

# 输入描述
第一行包含一个整数 $t$，代表询问次数。
接下来 $t$ 行，每行包含四个整数 $a, b, c, d$，依次表示 X 套餐的单价、X 套餐的容量、Y 套餐的单价、Y 套餐的容量。

# 输出描述
对于每个询问，输出一个整数 $k$，满足“全部从 X 购买的花费”严格小于“全部从 Y 购买的花费”。如果有多个解，输出任意一个；若不存在这样的 $k$，则输出 `-1`。每行一个结果。

## 样例1

**输入**

```
2
2 3 3 5
1 5 3 10
```

**输出**

```
3
5
```

**说明**

第一个询问：$a=2, b=3, c=3, d=5$。选择 $k=3$。从 X 购买需 $\lceil 3/3 \rceil = 1$ 份，花费 $2 \times 1 = 2$ 元；从 Y 购买需 $\lceil 3/5 \rceil = 1$ 份，花费 $3 \times 1 = 3$ 元。由于 $2 < 3$，满足条件，输出 `3`。
第二个询问：$a=1, b=5, c=3, d=10$。选择 $k=5$。从 X 购买需 $\lceil 5/5 \rceil = 1$ 份，花费 $1$ 元；从 Y 购买需 $\lceil 5/10 \rceil = 1$ 份，花费 $3$ 元。$1 < 3$，满足条件，输出 `5`。

## 样例2

**输入**

```
1
5 1 1 10
```

**输出**

```
-1
```

**说明**

$a=5, b=1, c=1, d=10$。X 每份 `1` GB 售价 `5` 元，相当于单价 `5` 元/GB；Y 每份 `10` GB 售价 `1` 元，相当于单价 `0.1` 元/GB。无论 $k$ 取何值，从 X 购买的花费总是 $5 \times k$，从 Y 购买的花费为 $1 \times \lceil k/10 \rceil$。对于任意正整数 $k$，$5k \ge 5 > 1 \ge \lceil k/10 \rceil$，因此 X 花费永远不可能严格小于 Y 花费，输出 `-1`。

## 样例3

**输入**

```
1
1 1000000000 1000000000 1
```

**输出**

```
1
```

**说明**

$a=1, b=1000000000, c=1000000000, d=1$。选择 $k=1$。从 X 购买需 $\lceil 1/1000000000 \rceil = 1$ 份，花费 `1` 元；从 Y 购买需 $\lceil 1/1 \rceil = 1$ 份，花费 `1000000000` 元。满足 $1 < 1000000000$，因此输出 `1`。该解满足 $0 < k < 2^{31}$。
