## 解题思路

1. **问题转化**  
   我们需要从原字符串中删除尽可能少的字符，使得剩下的字符串能够被完全划分成若干个长度为 $2$ 的、由相同字母组成的块（即“双字母对”）。换言之，剩余字符串中，每两个相邻的字符必须相等，并且总长度为偶数。

2. **动态规划定义**  
   令 $dp[i]$ 表示考虑原字符串的前 $i$ 个字符（下标 $1 \dots i$）时，使得处理后的字符串成为好串所需的最少删除次数。  
   最终答案即为 $dp[n]$，其中 $n$ 是字符串长度。

3. **状态转移**  
   对于第 $i$ 个字符 $s_{i}$（注意编程时索引从 $0$ 开始），有两种选择：
   - **删除该字符**：则前 $i$ 个字符的最小删除数为 $dp[i-1] + 1$。
   - **不删除该字符**：若保留该字符，它必须与前面某个相同字母 $s_{j}$（$j < i$）配对，并且它们之间所有的字符都必须被删除（因为只有两个配对字符之间不能有其他保留的字符）。为了使删除数最小，我们当然选择最靠近 $i$ 的相同字母 $j$，这样中间需要删除的字符数 $i - j - 1$ 最少。此时，前 $i$ 个字符的最小删除数为 $dp[j-1] + (i - j - 1)$，因为配对字符 $s_{j}$ 和 $s_{i}$ 之间的字符全部删除，而 $s_{j}$ 之前的部分需要保证自身是合法的好串。  
   
   综合两种情况，取最小值：  
   $$dp[i] = \min(dp[i-1] + 1,\ \min_{j < i,\ s_j = s_i} (dp[j-1] + i - j - 1))$$

4. **优化**  
   为了快速找到最近的相同字母位置，我们可以用一个数组 `last_pos[26]` 记录每个小写字母在当前遍历过程中最后一次出现的结尾位置（即该字母作为保留字符并参与配对时的位置）。这样在计算 $dp[i]$ 时，若 `last_pos[idx]` 不为 $-1$（`idx = s[i-1] - 'a'`），则最近配对位置 $j$ 就是 `last_pos[idx]`，直接带入转移即可。  
   同时，每次处理完 $dp[i]$ 后，更新 `last_pos[idx] = i`，表示当前字母的最新出现位置为结尾下标 $i$。

5. **边界条件**  
   $dp[0] = 0$，表示空字符串无需删除。  
   `last_pos` 数组初始化为 $-1$，表示尚未出现过。

## 复杂度分析

- **时间复杂度**：整个动态规划只对字符串进行了一次从左到右的扫描，每次状态转移是 $O(1)$ 的，因此总时间复杂度为 $O(n)$，其中 $n$ 是字符串长度。
- **空间复杂度**：使用了长度为 $n+1$ 的 $dp$ 数组，以及常量大小的 $last\_pos$ 数组，整体空间复杂度为 $O(n)$。

## 代码实现

### Python

```python
s = input().strip()
n = len(s)

# dp[i] 表示前 i 个字符使得剩余串成为好串的最小删除数
dp = [0x3f3f3f3f] * (n + 1)
last_pos = [-1] * 26  # 记录每个字母最近一次出现的位置（1-based）

dp[0] = 0
for i in range(1, n + 1):
    idx = ord(s[i - 1]) - ord('a')
    
    # 情况1：删除第 i 个字符
    dp[i] = dp[i - 1] + 1
    
    # 情况2：保留第 i 个字符，并与前面最近的相同字母配对
    if last_pos[idx] != -1:
        j = last_pos[idx]
        dp[i] = min(dp[i], dp[j - 1] + i - j - 1)
    
    # 更新当前字母的最新位置
    last_pos[idx] = i

print(dp[n])
```

### Java

```java
import java.util.Arrays;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String s = scanner.nextLine();
        int n = s.length();
        
        int[] dp = new int[n + 1];
        Arrays.fill(dp, 0x3f3f3f3f);
        int[] lastPos = new int[26];
        Arrays.fill(lastPos, -1);
        
        dp[0] = 0;
        for (int i = 1; i <= n; i++) {
            int idx = s.charAt(i - 1) - 'a';
            
            // 删除第 i 个字符
            dp[i] = dp[i - 1] + 1;
            
            // 保留第 i 个字符，尝试与前面最近的相同字母配对
            if (lastPos[idx] != -1) {
                int j = lastPos[idx];
                dp[i] = Math.min(dp[i], dp[j - 1] + i - j - 1);
            }
            
            lastPos[idx] = i;
        }
        
        System.out.println(dp[n]);
    }
}
```

        if (last_pos[idx] != -1) {
            int j = last_pos[idx];
            dp[i] = min(dp[i], dp[j - 1] + i - j - 1);
        }
        
        last_pos[idx] = i;
    }
    
    cout << dp[n] << "\n";
    return 0;
}
