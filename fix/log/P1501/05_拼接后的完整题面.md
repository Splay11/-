# 题目内容
考古学家发现了一段由小写字母组成的密码。密码本应由若干连续的“双字母对”构成，每个双字母对由两个相同的字母组成（例如 `aa`、`bb`）。然而，由于部分字母被腐蚀擦除，剩下的字母仍然保持原来的顺序，但不再满足上述结构。

你可以选择删除其中一些字符（其余字符的相对顺序不变），使得剩下的字符串能够被完全划分成若干个长度为 $2$ 的、由相同字母组成的块。换言之，剩余字符串的长度 $L$ 必须是偶数，且对于每一个满足 $0 \le 2k < L$ 的整数 $k$，都有 $s_{2k} = s_{2k+1}$。请你求出最少需要删除多少个字符。

字符串的长度不超过 $10^5$，只包含小写字母。

# 输入描述
输入包含一行，一个仅由小写字母构成的字符串 $s$，其长度不超过 $10^5$。

# 输出描述
输出一个整数，表示最少需要删除的字符数量。

## 样例1

**输入**

```
abccdde
```

**输出**

```
3
```

**说明**

原字符串长度为 `7`。我们可以删除开头的 `a`、`b` 和末尾的 `e`，保留子序列 `ccdd`，长度为 `4`，可以完全划分为 `cc` 和 `dd` 两个双字母对。不存在保留更多字符的合法方案，因此最少需要删除 `3` 个字符。

## 样例2

**输入**

```
a
```

**输出**

```
1
```

**说明**

字符串长度为 `1`，无法形成任何由两个相同字母组成的块。必须将唯一的字符删除，最少删除数为 `1`。

## 样例3

**输入**

```
aaa
```

**输出**

```
1
```

**说明**

字符串长度为 `3`，由三个 `a` 组成。我们可以保留前两个 `a` 成为 `aa` 对，或者保留后两个 `a`。无论如何，剩余长度最大为 `2`，因此最少需要删除 `1` 个字符。

## 样例4

**输入**

```
caabb
```

**输出**

```
1
```

**说明**

字符串长度为 `5`。开头的 `c` 会阻碍构造更长的双字母序列，将其删除后可以得到子序列 `aabb`，长度为 `4`，可划分为 `aa` 和 `bb` 两个合法的双字母对。最少删除数为 `1`。
