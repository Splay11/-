# 题目内容
某智能设备养护平台需要根据自然语言订单自动计算服务费用。费用由基础养护费、附加费和场地费三部分组成。请编写提示词，指导 AI 按照以下规则从订单描述中提取信息并输出规范 JSON。

1. 设备类型基础价：标准型 `38` 元、加强型 `58` 元、旗舰型 `78` 元。服务等级加价：基础养护不加价；深度养护在基础价上增加 $80\%$ 后向上取整；晶镀养护在基础价上增加 $150\%$ 后向上取整。会员对加价后的基础养护费打 `85` 折并向下取整；非会员不打折。
2. 附加费：除尘维护每次 `28` 元；液路清理每次 `45` 元；多项选择时费用累加，未选择则为 `0` 元。
3. 节假日加成：先计算折后基础养护费与附加费之和；若为节假日，则将该金额增加 $20\%$ 后向上取整；非节假日不变。
4. 场地费：室内场地 `15` 元；露天场地 `0` 元。场地费在节假日加成之后加入，不参与节假日上浮。

最终费用 `total_bill` 为节假日处理后的基础养护费与附加费之和再加上场地费；`wash_cost` 为节假日加成前的折后基础养护费；`car_type` 为设备类型。

约束：输入文本长度不超过 `200` 个字符；所有金额均为整数且不超过 `1000` 元。

# 输入描述
输入为一段自然语言文本，长度不超过 `200` 个字符。文本中会描述设备类型、服务等级、会员身份、是否节假日、附加服务和场地方式等订单信息。文本可能包含否定表达，需要结合完整语义进行判断。

# 输出描述
输出一个标准 JSON 格式字符串，包含 `total_bill`、`wash_cost` 和 `car_type` 三个字段。`total_bill` 为最终应付总额（元），等于节假日处理后的基础养护费与附加费之和再加上场地费；`wash_cost` 为节假日加成前的折后基础养护费（元）；`car_type` 为设备类型，只能为 `标准型`、`加强型` 或 `旗舰型` 三者之一。评测仅对照要求输出的字段，多余字段会被忽略。

## 样例1

**输入**

```
客户不是会员，非节假日，选择旗舰型基础养护，不加附加项目，露天场地。
```

**输出**

```
{"total_bill":78,"wash_cost":78,"car_type":"旗舰型"}
```

**说明**

设备类型为旗舰型，基础价为 `78` 元。基础养护不加价；文本含有“不是会员”，按非会员处理，因此折后基础养护费 `wash_cost` 仍为 `78`。

“不加附加项目”表示两项附加服务均未选择，附加费为 `0`。非节假日不加成，露天场地费为 `0`。最终 `total_bill` $=$ `78` $+$ `0` $+$ `0` $=$ `78`。

## 样例2

**输入**

```
王工是会员，非节假日，旗舰型晶镀养护，加液路清理，室内场地。
```

**输出**

```
{"total_bill":225,"wash_cost":165,"car_type":"旗舰型"}
```

**说明**

旗舰型基础价为 `78` 元。晶镀养护在基础价上增加 $150\%$ 后向上取整：`78` $\times$ `2.5` $=$ `195`。会员打 `85` 折并向下取整：`195` $\times$ `0.85` $=$ `165.75`，得到 `wash_cost` $=$ `165`。

液路清理附加费为 `45` 元。非节假日不加成，金额为 `165` $+$ `45` $=$ `210`。室内场地费 `15` 元在加成之后加入，因此 `total_bill` $=$ `210` $+$ `15` $=$ `225`。

## 样例3

**输入**

```
陈女士不是会员，节假日，标准型深度养护，加除尘维护和液路清理，露天场地。
```

**输出**

```
{"total_bill":171,"wash_cost":69,"car_type":"标准型"}
```

**说明**

标准型基础价为 `38` 元。深度养护增加 $80\%$ 后向上取整：`38` $\times$ `1.8` $=$ `68.4`，向上取整得到 `69`。不是会员，故 `wash_cost` $=$ `69`。

除尘维护 `28` 元与液路清理 `45` 元累加，附加费为 `73` 元。节假日对 `69` $+$ `73` $=$ `142` 增加 $20\%$ 后向上取整：`142` $\times$ `1.2` $=$ `170.4`，向上取整为 `171`。露天场地费为 `0`，因此 `total_bill` $=$ `171`。

## 样例4

**输入**

```
会员，非节假日，加强型基础养护，无附加服务，室内场地。
```

**输出**

```
{"total_bill":64,"wash_cost":49,"car_type":"加强型"}
```

**说明**

加强型基础价为 `58` 元，基础养护不加价。会员打 `85` 折并向下取整：`58` $\times$ `0.85` $=$ `49.3`，故 `wash_cost` $=$ `49`。

无附加服务，附加费为 `0`。非节假日不加成，室内场地费 `15` 元后加入，因此 `total_bill` $=$ `49` $+$ `15` $=$ `64`。
