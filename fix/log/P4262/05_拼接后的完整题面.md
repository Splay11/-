# 题目内容
仓库里有两段传送带铭文 $u$ 和 $v$，它们都是仅由小写英文字母构成的非空字符串。将两段铭文按先后顺序拼接时，需要计算接缝长度：若先放置字符串 $x$、再放置字符串 $y$，则接缝长度定义为最大的整数 $k$，使得 $x$ 的长度为 $k$ 的后缀与 $y$ 的长度为 $k$ 的前缀完全相同。

可以选择先放 $u$ 再放 $v$，也可以先放 $v$ 再放 $u$。请输出两种放置顺序下接缝长度的较小值。

约束：每个字符串的长度至少为 `1`，且不超过 `1000`。字符串仅由小写英文字母构成。

# 输入描述
第一行输入一个仅由小写英文字母构成的字符串 $u$。
第二行输入一个仅由小写英文字母构成的字符串 $v$。
两个字符串的长度均至少为 `1`，且不超过 `1000`。

# 输出描述
输出一个整数，表示两种放置顺序下接缝长度的较小值。

## 样例1

**输入**

```
ababab
babaa
```

**输出**

```
1
```

**说明**

按题意模拟计算得到。
