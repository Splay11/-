# 题目内容
对于一个正整数 $n$，定义它的“贡献值” $C(n)$ 为其正因子的个数（$1$ 和 $n$ 自身均计入）。

给定一个正整数 $x$，你可以将其表示为 $k$ 个大于 `1` 的正整数的乘积：
$p_1 \times p_2 \times \dots \times p_k = x$，其中 $k \ge 1$ 且每个 $p_i > 1$。
你的目标是最大化所有被乘数的贡献值之和：
$\sum_{i=1}^k C(p_i)$。

请你计算并输出这个最大可能值。

约束条件：
- 测试数据组数 $T$ 不超过 $10^4$。
- 每个给定的正整数 $x$ 满足 $2 \le x \le 2 \times 10^5$。

# 输入描述
第一行包含一个整数 $T$（$1 \le T \le 10^4$），表示测试数据组数。
接下来 $T$ 行，每行包含一个整数 $x$（$2 \le x \le 2 \times 10^5$）。

# 输出描述
对于每组测试数据，输出一行一个整数，表示所求的最大贡献值之和。

## 样例1

**输入**

```
1
4
```

**输出**

```
4
```

**说明**

对于 $x = 4$，其质因数分解为 $2^2$。若保持原数不拆分，贡献值为 $C(4) = 3$；若拆分为 $2 \times 2$，贡献值之和为 $C(2) + C(2) = 2 + 2 = 4$。比较后可知，最大值为 `4`，因此输出 `4`。

## 样例2

**输入**

```
1
12
```

**输出**

```
6
```

**说明**

对于 $x = 12$，质因数分解为 $2^2 \times 3$。不拆分的贡献值 $C(12) = 6$。若拆分为 $6 \times 2$，和为 $C(6) + C(2) = 4 + 2 = 6$；若完全拆为质数 $2 \times 2 \times 3$，和为 $2 + 2 + 2 = 6$。其他拆分方式均无法超过 `6`，故最大值为 `6`。

## 样例3

**输入**

```
1
36
```

**输出**

```
9
```

**说明**

对于 $x = 36$，质因数分解为 $2^2 \times 3^2$。不拆分时的贡献值 $C(36) = 9$。考虑拆分：最优方式是将质因数组成两个 $6$，即 $36 = 6 \times 6$，此时和为 $C(6) + C(6) = 4 + 4 = 8$；其他拆分（如 $4 \times 9$ 或全部拆为质数）的和均不超过 `8`。由于 $9 > 8$，保留原数不拆分是最优选择，输出 `9`。
