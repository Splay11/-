# 题目内容
编码模块要把 $n$ 组独立排列方案拼接：第 $i$ 组的方案数为 $a_i!$，总方案数为 $P = a_1! \times a_2! \times \cdots \times a_n!$。验收时需要统计 $P$ 有多少个正因子，作为密钥空间评估。由于答案可能很大，请对 `1000000007` 取模。

请输出取模后的结果。

约束：$1 \le n \le 200000$，$1 \le a_i \le 1000000$。

# 输入描述
第一行包含一个正整数 $n$，表示整数的个数，满足 $1 \le n \le 200000$。

第二行包含 $n$ 个正整数 $a_1, a_2, \ldots, a_n$，满足 $1 \le a_i \le 1000000$。

# 输出描述
输出一个整数，表示 $P$ 的正因子个数对 `1000000007` 取模后的结果。

## 样例1

**输入**

```
2
4 5
```

**输出**

```
42
```

**说明**

$4! \times 5! = 24 \times 120 = 2880 = 2^6 \times 3^2 \times 5^1$。

因子个数为 $(6+1)\times(2+1)\times(1+1) = 42$。

## 样例2

**输入**

```
1
1
```

**输出**

```
1
```

**说明**

$1! = 1$，只有 `1` 这一个正因子。

## 样例3

**输入**

```
4
6 6 7 2
```

**输出**

```
784
```

**说明**

把四个阶乘连乘后做质因数分解，各指数加 `1` 再相乘，并对 $10^9+7$ 取模，得到 `784`。
