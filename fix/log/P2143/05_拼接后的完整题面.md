# 题目内容
有一条长度为 $n$ 的库存序列 $a_1, a_2, \ldots, a_n$（下标从 `1` 开始）。共有 $q$ 次彼此独立的核算：每次给出两个闭区间 $[L_1, R_1]$ 与 $[L_2, R_2]$，先把第一个区间内的元素全部乘以 `2`，再把第二个区间内的元素全部乘以 `2`，然后求整条序列的元素之和。每次核算结束后序列会恢复到初始状态。

序列长度与核算次数均不超过 `2×10^5`，每个元素的绝对值不超过 `10^5`。

# 输入描述
第一行两个整数 $n$ 和 $q$（$1 \le n, q \le 2 \times 10^5$），表示序列长度与核算次数。
第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$-10^5 \le a_i \le 10^5$）。
接下来 $q$ 行，每行四个整数 $L_1, R_1, L_2, R_2$（$1 \le L_1 \le R_1 \le n$，$1 \le L_2 \le R_2 \le n$）。

# 输出描述
输出 $q$ 行，每行一个整数，表示该次核算后序列的元素之和。

## 样例1

**输入**

```
4 1
5 -1 3 2
1 2 3 4
```

**输出**

```
18
```

**说明**

两个区间 $[1,2]$ 与 $[3,4]$ 不相交。
每个元素恰好乘 `2`，总和由 $5-1+3+2=9$ 变为 `18`。

## 样例2

**输入**

```
1 1
8
1 1 1 1
```

**输出**

```
32
```

**说明**

只有一个元素 `8`，两个区间都覆盖它，因此乘以 `4`，答案为 `32`。这是 $n=1$ 的边界情况。

## 样例3

**输入**

```
4 1
6 0 4 3
1 2 3 4
```

**输出**

```
26
```

**说明**

按题意模拟计算得到。
