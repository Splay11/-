# 题目内容
一场电竞积分赛按最高分计分：每位选手每张地图可多次提交成绩，该地图只保留历史最高分，总分是各地图最高分之和。选手编号与地图编号均为 `1` 到 `100`。

按时间顺序有 $n$ 次提交，第 $i$ 次为 $(a,b,c)$，表示选手 $a$ 在地图 $b$ 上得到分数 $c$。每次提交处理后，输出编号为 `1` 的选手当前名次。

名次规则：总分高者靠前；总分相同则并列，但占用多个名次位置。例如前四名分数为 `100`、`100`、`100`、`80` 时，名次为 `1`、`1`、`1`、`4`。

约束：提交次数不超过 `200000`。

# 输入描述
第一行一个整数 $n$，表示提交次数，满足 $1 \le n \le 200000$。
接下来 $n$ 行，每行三个整数 $a$、$b$、$c$，满足 $1 \le a,b \le 100$，$0 \le c \le 100$。

# 输出描述
输出 $n$ 行，第 $i$ 行一个整数，表示第 $i$ 次提交处理后编号为 `1` 的选手的名次。

## 样例1

**输入**

```
5
7 2 40
1 1 25
7 2 55
1 1 70
9 3 90
```

**输出**

```
2
2
2
1
2
```

**说明**

作业按最高分计。
`1` 号同学两次提交同一作业，只保留 `70`。
每次提交后输出 `1` 号的名次。

## 样例2

**输入**

```
3
1 4 10
1 4 10
2 4 11
```

**输出**

```
1
1
2
```

**说明**

重复提交同分不改变成绩。
另一位同学该作业更高后，`1` 号名次变为 `2`。

## 样例3

**输入**

```
4
2 1 50
3 1 50
1 2 50
1 1 50
```

**输出**

```
2
3
1
1
```

**说明**

多人同分时并列，占用多个名次位置。
`1` 号追平最高总分后名次为 `1`。
