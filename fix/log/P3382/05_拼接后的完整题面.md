# 题目内容
有一个包含 $n$ 个整数的序列 $e_1,e_2,\dots,e_n$，表示 $n$ 个能量核心的初始能量。你可以进行任意多次操作，每次操作选择两个不同的位置 $i,j$（$1 \le i, j \le n$，$i 
eq j$），将 $e_i$ 修改为 $e_i + e_j$，并将 $e_j$ 修改为 $0$。

请计算经过若干次操作后，序列全部前缀最大值之和的最大可能值，即 $\sum_{i=1}^{n} \max(e_1, e_2, \dots, e_i)$ 的最大值。

数据范围：测试数据组数 $T$ 不超过 $10^4$，每组数据中 $n$ 不超过 $2 \times 10^5$，所有测试数据的 $n$ 总和也不超过 $2 \times 10^5$。每个能量的绝对值不超过 $n$。

# 输入描述
第一行包含一个整数 $T$（$1 \le T \le 10^4$），表示测试数据组数。接下来每组数据：第一行包含一个整数 $n$（$1 \le n \le 2 \times 10^5$），表示序列长度；第二行包含 $n$ 个整数 $e_1, e_2, \dots, e_n$（$-n \le e_i \le n$），表示初始能量。保证所有测试数据的 $n$ 总和不超过 $2 \times 10^5$。

# 输出描述
对于每组测试数据，输出一行一个整数，表示前缀最大值之和的最大可能值。

## 样例1

**输入**

```
1
4
-2 3 -1 4
```

**输出**

```
28
```

**说明**

序列中包含正数，最优策略是将所有正数合并到第一个位置。正数之和为 $3 + 4 = 7$，将 `7` 放在第一个位置，其余位置放置非正数或 `0`。经过操作后，序列的前缀最大值全部为 `7`，总和为 $4 \times 7 = 28$。

## 样例2

**输入**

```
1
3
-5 -2 -9
```

**输出**

```
-6
```

**说明**

序列中全为负数，没有正数。任何合并操作都会使数值变得更小，因此不应合并。我们只需将最大的元素 `-2` 移动到第一个位置（不与其他负数合并），其余元素放在后面。此时前缀最大值保持为 `-2`，总和为 $3 \times (-2) = -6$。

## 样例3

**输入**

```
1
1
5
```

**输出**

```
5
```

**说明**

序列中只有一个元素 `5`，无法进行操作。前缀最大值之和就是该元素本身 `5`。

## 样例4

**输入**

```
1
2
0 0
```

**输出**

```
0
```

**说明**

序列中全为 `0`，没有正数，最大值为 `0`。无论是否操作，前缀最大值均为 `0`，总和为 $2 \times 0 = 0$。
