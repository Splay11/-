## 解题思路

本题可以模拟每个工件依次通过所有加工阶段的过程，直接计算出每个工件完成全部阶段的时间，最后取最大值即可。  
由于阶段内的机器可以并行加工，每个工件在进入某阶段时，需要在该阶段的一台机器上加工，只需选择该阶段中**最早空闲**的机器即可。

具体算法如下：

1. 用一个数组 `cur_time` 记录每个工件当前累积的加工时间，初始全为 $0$（表示到达第 $1$ 个阶段前的状态）。
2. 按阶段编号 $1$ 到 $k$ 依次处理。对于每个阶段 $i$：
   - 已知该阶段有 $c_i$ 台机器，单件加工时间为 $t_i$。
   - 使用一个**小根堆**（优先队列）维护这 $c_i$ 台机器的空闲时间，初始均为 $0$（表示一开始所有机器空闲）。
   - 遍历所有 $n$ 个工件（顺序无所谓，因为工件之间没有优先级，且所有工件都需要经过该阶段）：
     * 从堆中取出最早空闲的机器的可用时间 `machine_time`。
     * 工件在该阶段的开始时间 `start` = $\max(cur\_time[j], machine\_time)$（工件必须已经完成前一个阶段，且机器必须空闲）。
     * 工件在该阶段的完成时间 `finish` = `start` + $t_i$。
     * 更新 `cur_time[j] = finish`，并将 `finish` 重新压入堆中（表示该机器加工完当前工件后的新空闲时间）。
3. 所有阶段处理完毕后，`cur_time` 中存储的就是每个工件完成第 $k$ 个阶段的时间。输出这些时间的最大值即为完成所有工件的最短时间。

该方法本质上是对经典的 “多阶段流水车间（有并行机）” 问题的一种高效模拟，核心在于利用优先队列动态维护每个阶段内机器的空闲状态。

## 复杂度分析

- 时间复杂度：共有 $k$ 个阶段，每个阶段需要维护一个大小不超过 $c_i$ 的小根堆，并对 $n$ 个工件进行一轮处理。每次堆操作为 $O(\log c_i)$，因此总时间复杂度为 $O(n \cdot k \cdot \log C)$，其中 $C = \max\{c_i\}$。由于 $n,k,c_i \le 1000$，该复杂度完全可接受。
- 空间复杂度：需要存储 $n$ 个工件的当前时间 `cur_time`，以及每个阶段的小根堆（大小不超过最大机器数），因此空间复杂度为 $O(n + C)$。

## 代码实现

### Python

```python
import sys
import heapq

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    k = int(next(it))
    stages = [(int(next(it)), int(next(it))) for _ in range(k)]
    
    cur_time = [0] * n  # 每个工件当前完成上一个阶段的时间
    
    for c, t in stages:
        # 当前阶段 c 台机器的空闲时间，初始均为0
        heap = [0] * c
        heapq.heapify(heap)
        for j in range(n):
            machine_time = heapq.heappop(heap)        # 最早空闲的机器
            start = max(cur_time[j], machine_time)
            finish = start + t
            cur_time[j] = finish
            heapq.heappush(heap, finish)              # 更新该机器的空闲时间
    
    print(max(cur_time))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.PriorityQueue;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int k = sc.nextInt();
        
        long[] curTime = new long[n];  // 每个工件当前完成上一个阶段的时间
        
        for (int i = 0; i < k; i++) {
            int c = sc.nextInt();
            int t = sc.nextInt();
            
            // 小根堆，存放当前阶段所有机器的空闲时间
            PriorityQueue<Long> pq = new PriorityQueue<>();
            for (int j = 0; j < c; j++) {
                pq.offer(0L);
            }
            
            for (int j = 0; j < n; j++) {
                long machineTime = pq.poll();
                long start = Math.max(curTime[j], machineTime);
                long finish = start + t;
                curTime[j] = finish;
                pq.offer(finish);
            }
        }
        
        long ans = 0;
        for (long time : curTime) {
            if (time > ans) ans = time;
        }
        System.out.println(ans);
    }
}
```

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, k;
    cin >> n >> k;
    vector<ll> cur_time(n, 0);  // 每个工件当前完成上一个阶段的时间
    
    for (int i = 0; i < k; ++i) {
        int c, t;
        cin >> c >> t;
        
        // 小根堆，存放当前阶段所有机器的空闲时间
        priority_queue<ll, vector<ll>, greater<ll>> pq;
        for (int j = 0; j < c; ++j) {
            pq.push(0);
        }
        
        for (int j = 0; j < n; ++j) {
            ll machine_time = pq.top();
            pq.pop();
            ll start = max(cur_time[j], machine_time);
            ll finish = start + t;
            cur_time[j] = finish;
            pq.push(finish);
        }
    }
    
    cout << *max_element(cur_time.begin(), cur_time.end()) << '\n';
    return 0;
}
```
