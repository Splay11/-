# 题目内容
某智能工厂需要加工 $n$ 个相同的工作。加工过程包含 $k$ 个阶段，必须按编号 $1$ 到 $k$ 的顺序依次进行。

第 $i$ 个阶段配备了 $c_i$ 台相同的自动化机器，因此同一时刻最多可以有 $c_i$ 个工作在该阶段被同时加工。每个工作在阶段 $i$ 的单件加工时间为 $t_i$。

初始时刻所有机器均空闲，任何机器完成一个工作后可立即开始加工下一个到达该阶段的工作。请你计算完成所有 $n$ 个工作所需的最短时间。

约束条件：
- 工作总数 $n$ 和阶段数 $k$ 均不超过 $1000$。
- 机器数 $c_i$ 不超过 $1000$。
- 加工时间 $t_i$ 为不超过 $10^9$ 的正整数。
- 所有输入均为整数。

# 输入描述
第一行包含两个整数 $n$ 和 $k$，分别表示工作数量与阶段数量。
接下来 $k$ 行，每行包含两个整数 $c_i$ 和 $t_i$，依次表示第 $i$ 个阶段的机器数量与单个工作的加工时间。

# 输出描述
输出一个整数，表示完成所有工作的最少用时。

## 样例1

**输入**

```
4 2
2 3
1 2
```

**输出**

```
11
```

**说明**

共有两个阶段。第一阶段 $c_1=2$ 台机器，单件加工时间 $t_1=3$。`4` 个工件分两批加工：工件 `1` 和 `2` 在时刻 `0` 开始，`3` 时完成；工件 `3` 和 `4` 在时刻 `3` 开始，`6` 时完成。第二阶段 $c_2=1$ 台机器，单件时间 $t_2=2$。由于仅有一台机器，工件需逐一加工：工件 `1` 于 `3` 时开始，`5` 完成；工件 `2` 等待至 `5` 开始，`7` 完成；工件 `3` 于 `7` 开始，`9` 完成；工件 `4` 于 `9` 开始，`11` 完成。全部工件完成的最少用时为 `11`。

## 样例2

**输入**

```
5 1
3 4
```

**输出**

```
8
```

**说明**

只有一个阶段，拥有 $c_1=3$ 台机器，每件加工耗时 $t_1=4$。`5` 个工件中，第一批 `3` 个工件在时刻 `0` 开始加工，`4` 时完成；剩余 `2` 个工件在 `4` 时开始，`8` 时完成。因此完成全部工件的最短时间为 `8`。

## 样例3

**输入**

```
1 3
1 10
2 5
1 2
```

**输出**

```
17
```

**说明**

仅 `1` 个工件，需依次经过三个阶段。第一阶段 $c_1=1, t_1=10$，耗时 `10`；第二阶段 $c_2=2, t_2=5$，耗时 `5`；第三阶段 $c_3=1, t_3=2$，耗时 `2`。总加工时间 $10+5+2=17$。
