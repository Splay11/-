# 题目内容
在一个名为“平方积”的数字挑战中，你会得到一个正整数 $n$。你需要将 $1$ 到 $n$ 这 $n$ 个整数排列成一个序列 $a_1, a_2, \dots, a_n$，每个数字恰好出现一次。序列的得分定义为满足 $a_i \times a_{i+1}$ 是一个完全平方数的位置 $i$ 的个数（$1 \le i < n$）。请你构造一个序列，使得得分尽可能大。

本题包含多组测试数据。数据组数不超过 $10^4$，每组数据中的 $n$ 满足 $2 \le n \le 2 \times 10^5$，且所有测试数据的 $n$ 之和不超过 $2 \times 10^5$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据的组数。接下来 $T$ 行，每行包含一个整数 $n$，表示本组数据中序列的长度。

# 输出描述
对于每组测试数据，输出一行，包含 $n$ 个用空格分隔的整数，表示你构造的得分最大的序列。如果存在多种合法方案，输出任意一种即可。

## 样例1

**输入**

```
1
2
```

**输出**

```
1 2
```

**说明**

数字 `1` 和 `2` 的“平方自由部分”分别为 `1` 和 `2`，它们不相同，因此 $1 \times 2 = 2$ 不可能是完全平方数。得分为 `0`，这也是该长度下唯一可能的结果。

## 样例2

**输入**

```
1
5
```

**输出**

```
1 4 2 3 5
```

**说明**

在 $n=5$ 时，将平方自由部分相同的 `1` 和 `4` 放在相邻位置，可得 $1 \times 4 = 4 = 2^2$ 为完全平方数，获得 `1` 分；其余相邻对均无法得分。所有数字的平方自由部分共有 `4` 种（`1,2,3,5`），因此理论最大得分为 $5 - 4 = 1$，本序列达到了该上界。

## 样例3

**输入**

```
2
4
8
```

**输出**

```
1 4 2 3
1 4 2 8 3 5 6 7
```

**说明**

对于第一组 $n=4$：`1` 和 `4` 的平方自由部分均为 `1`，将它们相邻可得 $1 \times 4 = 4$，为完全平方数，其余位置无法得分，总得分 `1`，达到最大值 $4 - 3 = 1$。对于第二组 $n=8$：数字按平方自由部分分组为 `{1,4}`（部分 `1`）、`{2,8}`（部分 `2`）以及各自独立的 `3,5,6,7`，共 `6` 组。理论最大得分为 $8 - 6 = 2$。输出序列中 $1 \times 4 = 4$ 与 $2 \times 8 = 16$ 均为完全平方数，获得 `2` 分，达到上界。
