# 题目内容
给定长度为 $n$ 的数组 $a_1, a_2, \ldots, a_n$，需要把它划分成恰好 $k$ 个非空子序列，每个元素属于且仅属于一个子序列。子序列不必连续。
一个子序列的均价定义为该子序列所有元素之和除以元素个数。请找到一种划分，使得这 $k$ 个子序列的均价之和最小，并输出该最小值。
结果保留恰好 `5` 位小数。

约束条件：
- $1 \le k \le n \le 10^5$。
- 每个 $a_i$ 的绝对值不超过 $10^9$。
- 保证数组中的元素互不相同。

# 输入描述
第一行包含两个正整数 $n$ 和 $k$，分别表示数组长度和子序列个数。
第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$，表示数组元素。

# 输出描述
输出一个小数，表示 $k$ 个子序列均价之和的最小值，保留恰好 `5` 位小数。

## 样例1

**输入**

```
7 3
9 4 5 6 2 1 7
```

**输出**

```
9.20000
```

**说明**

最优策略是把最小的 $k-1=2$ 个数各自单独成一个子序列，其余数放在同一子序列。
排序后为 $1,2,4,5,6,7,9$。两个单元素子序列均价为 `1` 和 `2`，剩余五个数的均价为 $\dfrac{4+5+6+7+9}{5}=6.2$。
均价之和为 $1+2+6.2=9.2$，输出 `9.20000`。

## 样例2

**输入**

```
3 1
3 1 2
```

**输出**

```
2.00000
```

**说明**

$k=1$ 时只能分成一个子序列，均价为 $\dfrac{3+1+2}{3}=2$，输出 `2.00000`。

## 样例3

**输入**

```
4 4
4 1 3 2
```

**输出**

```
10.00000
```

**说明**

$k=n$ 时每个元素单独成一个子序列，均价之和等于所有元素之和 $4+1+3+2=10$，输出 `10.00000`。

## 样例4

**输入**

```
2 2
-5 10
```

**输出**

```
5.00000
```

**说明**

两个元素必须各成一个子序列，均价之和为 $-5+10=5$，输出 `5.00000`。
