# 题目内容
实验室同时记录了两路长度为 $n$ 的采样序列 $p$ 和 $q$。从全部下标中选出一个非空集合，按下标递增顺序取出对应位置上的数值，会得到两个等长的新序列。

称这次选取是**同频**的，当且仅当被选中的每一个下标 $i$ 都满足：$p_i + q_i$ 的值全部相同。

请计算有多少种不同的非空同频选取方案。答案可能很大，输出对 $10^9+7$ 取模后的结果。

约束条件：
- 序列长度 $n$ 满足 $1 \le n \le 10^5$；
- 序列中每个数满足 $1 \le p_i, q_i \le 10^9$。

# 输入描述
第一行包含一个整数 $n$（$1 \le n \le 10^5$），表示两路采样序列的长度。
第二行包含 $n$ 个整数 $p_1, p_2, \ldots, p_n$（$1 \le p_i \le 10^9$），表示第一路采样。
第三行包含 $n$ 个整数 $q_1, q_2, \ldots, q_n$（$1 \le q_i \le 10^9$），表示第二路采样。

# 输出描述
输出一个整数，表示非空同频选取方案数对 $10^9+7$ 取模后的结果。

## 样例1

**输入**

```
1
3
5
```

**输出**

```
1
```

**说明**

只有一个下标可选，两路之和为 $3+5=8$。唯一的非空选取就是选中这一个位置，方案数为 `1`。

## 样例2

**输入**

```
5
2 1 4 3 6
5 6 2 4 1
```

**输出**

```
16
```

**说明**

各下标的两路之和依次为 $7,7,6,7,7$。

和为 `7` 的位置有 `4` 个，非空子集数为 $2^4-1=15$。

和为 `6` 的位置有 `1` 个，贡献 `1` 种方案。

总方案数为 $15+1=16$，再对 $10^9+7$ 取模仍为 `16`。

## 样例3

**输入**

```
3
1 1 1
2 2 2
```

**输出**

```
7
```

**说明**

三个下标的两路之和都是 `3`，可以从 `3` 个位置中任选非空子集，方案数为 $2^3-1=7$。
