## 解题思路

令 $dp[i]$ 表示把前缀 $s[0..i-1]$（长度为 $i$）切成同端片段的最多段数；若无法切分则为 $-1$。空前缀 $dp[0]=0$。

对每个字符 $c$，记录一个二元组 $(\textit{MAX}[c], \textit{index}[c])$：在以往某个位置 $index$ 处，字符恰好为 $c$，且当时前缀 $s[0..index-1]$ 的最优段数为 $\textit{MAX}$。

从左到右扫描，处理第 $i$ 个字符 $s[i-1]$ 时：

- 若该字符曾经作为某段的起点被记录过（$\textit{MAX}\ne -1$），则可以把 $s[index..i-1]$ 作为新的一段同端片段（首尾都是这个字符，且长度至少为 `2`），于是 $dp[i]=dp[index]+1$。
- 随后，若当前 $dp[i-1]$ 优于该字符已记录的 $\textit{MAX}$，则把记录更新为 $(dp[i-1], i-1)$，表示以后再遇到同一字符时，可以从这里开启新的一段。

最终输出 $dp[n]$。若整个串无法切完，该值保持为 $-1$。

## 复杂度分析

每个位置只做常数次查表与更新，字母表大小为 `26`。

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(n)$。

在 $n\le 2\times 10^5$ 时可以通过。

## 代码实现

### Python

```python
s = input()
n = len(s)
dp = [-1] * (n + 1)
dp[0] = 0
MAX = {chr(i + ord("a")): (-1, -1) for i in range(26)}

for i in range(1, n + 1):
    MAXX, index = MAX[s[i - 1]]
    if MAXX != -1:
        dp[i] = dp[index] + 1
    if MAXX < dp[i - 1]:
        MAX[s[i - 1]] = (dp[i - 1], i - 1)
print(dp[-1])
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String s = scanner.nextLine();
        int n = s.length();
        int[] dp = new int[n + 1];
        java.util.Arrays.fill(dp, -1);
        dp[0] = 0;
        int[] maxVal = new int[26];
        int[] maxIdx = new int[26];
        java.util.Arrays.fill(maxVal, -1);
        java.util.Arrays.fill(maxIdx, -1);

        for (int i = 1; i <= n; i++) {
            int c = s.charAt(i - 1) - 'a';
            if (maxVal[c] != -1) {
                dp[i] = dp[maxIdx[c]] + 1;
            }
            if (maxVal[c] < dp[i - 1]) {
                maxVal[c] = dp[i - 1];
                maxIdx[c] = i - 1;
            }
        }
        System.out.println(dp[n]);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    int n = (int)s.size();
    vector<int> dp(n + 1, -1);
    dp[0] = 0;
    int maxVal[26], maxIdx[26];
    fill(maxVal, maxVal + 26, -1);
    fill(maxIdx, maxIdx + 26, -1);

    for (int i = 1; i <= n; ++i) {
        int c = s[i - 1] - 'a';
        if (maxVal[c] != -1) {
            dp[i] = dp[maxIdx[c]] + 1;
        }
        if (maxVal[c] < dp[i - 1]) {
            maxVal[c] = dp[i - 1];
            maxIdx[c] = i - 1;
        }
    }
    cout << dp[n] << "\n";
    return 0;
}
```
