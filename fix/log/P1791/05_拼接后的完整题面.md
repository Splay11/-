# 题目内容
有 $n$ 根木条，第 $i$ 根长度为 $a_i$。每次可以把一根长度为 $s$ 的木条切成两段正整数长度 $x$ 和 $y$，满足 $x+y=s$。切出的新木条还可以继续切。最多允许切割 $k$ 次。

判断能否通过不超过 $k$ 次切割，使最终所有木条长度完全相同。

本题有多组测试数据。

约束条件：
- 测试组数 $T$ 满足 $1 \le T \le 10^4$；
- 每组木条根数 $n$ 满足 $1 \le n \le 10^5$，切割次数上限 $k$ 满足 $0 \le k \le 10^{14}$；
- 每根长度满足 $1 \le a_i \le 10^9$；
- 所有测试数据中 $n$ 的总和不超过 $10^5$。

# 输入描述
第一行包含一个正整数 $T$（$1 \le T \le 10^4$），表示测试组数。
对每组测试数据：第一行包含两个整数 $n$ 和 $k$（$1 \le n \le 10^5$，$0 \le k \le 10^{14}$），分别表示木条根数和最多切割次数；第二行包含 $n$ 个正整数 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 10^9$），表示各木条长度。所有测试数据中 $n$ 的总和不超过 $10^5$。

# 输出描述
对每组测试数据输出一行。若能在不超过 $k$ 次切割内使所有木条等长，输出 `YES`；否则输出 `NO`。

## 样例1

**输入**

```
3
3 3
2 4 6
4 2
6 6 9 3
5 0
7 7 7 7 7
```

**输出**

```
YES
NO
YES
```

**说明**

第一组：最大公约数为 `2`。把 `4` 切成两段 `2` 需 `1` 次，把 `6` 切成三段 `2` 需 `2` 次，共 `3` 次，不超过 $k=3$，输出 `YES`。

第二组：切成最大公约数 `3` 至少需要超过 `2` 次，输出 `NO`。

第三组：已经全部等长，切割次数为 `0`，输出 `YES`。

## 样例2

**输入**

```
1
1 0
9
```

**输出**

```
YES
```

**说明**

只有一根木条，无需切割即已等长，即使 $k=0$ 也输出 `YES`。

## 样例3

**输入**

```
1
2 0
2 4
```

**输出**

```
NO
```

**说明**

最大公约数为 `2`，把 `4` 切成两段需要 `1` 次，但 $k=0$，输出 `NO`。
