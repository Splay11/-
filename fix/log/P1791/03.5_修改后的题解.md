## 解题思路

要把所有木条切成相同长度，最终长度必须是所有 $a_i$ 的公约数。切的次数越少越好，因此应切成最大公约数 $g=\gcd(a_1,\ldots,a_n)$。

一根长度为 $a_i$ 的木条要变成 $a_i/g$ 段长度为 $g$ 的木条，需要切割 $a_i/g-1$ 次。全部木条的切割次数之和为

$$\sum_{i=1}^{n}\left(\frac{a_i}{g}-1\right)$$

若该值不超过 $k$，则输出 `YES`，否则输出 `NO`。已经全部等长时，次数为 `0`，即使 $k=0$ 也合法。

## 复杂度分析

每组数据时间复杂度 $O(n\log A)$，其中 $A$ 为长度上界。空间复杂度 $O(n)$。所有数据的 $n$ 之和不超过 $10^5$。

## 代码实现

### Python

```python
import math

t = int(input())


def solve():
    n, k = map(int, input().split())
    nums = list(map(int, input().split()))
    target = nums[0]
    for x in nums:
        target = math.gcd(target, x)
    res = 0
    for x in nums:
        res += x // target - 1
        if res > k:
            print("NO")
            return
    print("YES")


for _ in range(t):
    solve()
```

### Java

```java
import java.util.Scanner;

public class Main {
    static long gcd(long a, long b) {
        return b == 0 ? a : gcd(b, a % b);
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int T = in.nextInt();
        while (T-- > 0) {
            int n = in.nextInt();
            long k = in.nextLong();
            long[] arr = new long[n];
            long g = 0;
            for (int i = 0; i < n; i++) {
                arr[i] = in.nextLong();
                g = gcd(g, arr[i]);
            }
            long res = 0;
            boolean ok = true;
            for (int i = 0; i < n; i++) {
                res += arr[i] / g - 1;
                if (res > k) {
                    ok = false;
                    break;
                }
            }
            System.out.println(ok ? "YES" : "NO");
        }
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

long long gcdll(long long a, long long b) {
    return b == 0 ? a : gcdll(b, a % b);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int n;
        long long k;
        cin >> n >> k;
        vector<long long> a(n);
        long long g = 0;
        for (int i = 0; i < n; i++) {
            cin >> a[i];
            g = gcdll(g, a[i]);
        }
        long long res = 0;
        bool ok = true;
        for (int i = 0; i < n; i++) {
            res += a[i] / g - 1;
            if (res > k) {
                ok = false;
                break;
            }
        }
        cout << (ok ? "YES" : "NO") << '\n';
    }
    return 0;
}
```
