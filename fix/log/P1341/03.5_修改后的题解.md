## 解题思路

这是经典的区间动态规划。设字符串为 $s$，长度为 $n$。令 $dfs(l,r)$ 表示把子串 $s[l..r]$ 改成合法配方的最少修改次数。

空区间代价为 $0$。对非空区间，枚举与位置 $l$ 配对的右端点 $i$（$l<i\le r$），把 $s[l]$ 与 $s[i]$ 配成一对括号，再分别处理内部 $s[l+1..i-1]$ 与右侧 $s[i+1..r]$：
$$
dfs(l,r)=\min_{l<i\le r}\bigl(dfs(l+1,i-1)+\mathrm{cost}(s[l],s[i])+dfs(i+1,r)\bigr)
$$

配对代价 $\mathrm{cost}$ 按左右括号种类计算：记左括号集合为 `([{<`，右括号集合为 `)]}>`，且它们按下标一一对应。

- 若左端不是左括号、右端也不是右括号，需要改两下，代价为 `2`；
- 若恰好一端类型不对，代价为 `1`；
- 若两端类型都对但不是同一对，代价为 `1`；
- 否则已经匹配，代价为 `0`。

答案为 $dfs(0,n-1)$。用记忆化避免重复计算。题目保证 $n$ 为偶数。

## 复杂度分析

区间状态 $O(n^2)$，每个状态枚举配对点 $O(n)$。

- 时间复杂度：$O(n^3)$。
- 空间复杂度：$O(n^2)$。

在 $n\le 200$ 时可以通过。

## 代码实现

### Python

```python
from functools import cache

s = input().rstrip()

ls = '([{<'
rs = ')]}>'

@cache
def dfs(l, r):
    if l > r:
        return 0
    ans = float('inf')
    for i in range(l + 1, r + 1):
        sl = s[l]
        sr = s[i]
        cost = 0
        if sl not in ls and sr not in rs:
            cost = 2
        elif sl not in ls or sr not in rs:
            cost = 1
        elif rs[ls.index(sl)] != sr:
            cost = 1
        ans = min(ans, dfs(l + 1, i - 1) + cost + dfs(i + 1, r))
    return ans

print(dfs(0, len(s) - 1))
```

### Java

```java
import java.util.Arrays;
import java.util.Scanner;

public class Main {
    static String s;
    static String ls = "([{<";
    static String rs = ")]}>";
    static int[][] memo;

    static int cost(char sl, char sr) {
        int il = ls.indexOf(sl);
        int ir = rs.indexOf(sr);
        if (il < 0 && ir < 0) return 2;
        if (il < 0 || ir < 0) return 1;
        if (il != ir) return 1;
        return 0;
    }

    static int dfs(int l, int r) {
        if (l > r) return 0;
        if (memo[l][r] != -1) return memo[l][r];
        int ans = Integer.MAX_VALUE / 4;
        for (int i = l + 1; i <= r; i++) {
            ans = Math.min(ans, dfs(l + 1, i - 1) + cost(s.charAt(l), s.charAt(i)) + dfs(i + 1, r));
        }
        memo[l][r] = ans;
        return ans;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        s = scanner.next();
        int n = s.length();
        memo = new int[n][n];
        for (int i = 0; i < n; i++) Arrays.fill(memo[i], -1);
        System.out.println(dfs(0, n - 1));
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

string s;
string ls = "([{<";
string rs = ")]}>";
int memo[205][205];

int cost(char sl, char sr) {
    int il = ls.find(sl);
    int ir = rs.find(sr);
    if (il == string::npos && ir == string::npos) return 2;
    if (il == string::npos || ir == string::npos) return 1;
    if (il != ir) return 1;
    return 0;
}

int dfs(int l, int r) {
    if (l > r) return 0;
    if (memo[l][r] != -1) return memo[l][r];
    int ans = 1e9;
    for (int i = l + 1; i <= r; i++) {
        ans = min(ans, dfs(l + 1, i - 1) + cost(s[l], s[i]) + dfs(i + 1, r));
    }
    return memo[l][r] = ans;
}

int main() {
    cin >> s;
    int n = (int)s.size();
    memset(memo, -1, sizeof(memo));
    cout << dfs(0, n - 1) << "\n";
    return 0;
}
```
