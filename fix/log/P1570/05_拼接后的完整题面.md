# 题目内容
模拟函数定义与调用。定义：`返回类型 函数名(类型 名,...)`；调用：`函数名(类型,...)`。重载只看函数名与参数类型列表。成功输出 `Yes.`；重复定义 `redefinition of xxx.`；无此函数名 `There is no function xxx.`；有名无匹配 `xxx was not declared in this scope.`。

$1 \le q \le 100$，串长不超过 $100$。

# 输入描述
第一行 $q$。每次操作两行：第一行 $op$（`1` 定义，`2` 调用），第二行操作字符串。

# 输出描述
共 $q$ 行，每行一次反馈。

## 样例1

**输入**

```
8
1
void emit(int id)
1
int emit(String msg,int level)
2
emit(int)
2
emit(double)
1
double mix(double x,int y)
2
mix(double,int)
2
halt(int)
1
String emit(int value)
```

**输出**

```
Yes.
Yes.
Yes.
emit was not declared in this scope.
Yes.
Yes.
There is no function halt.
redefinition of emit.
```

**说明**

第一次登记参数类型为 `int` 的 `emit`，成功。
第二次登记参数类型为 `String,int` 的另一个 `emit`，类型列表不同，属于合法重载。
第三次调用 `emit(int)`，存在完全匹配，输出 `Yes.`。
第四次调用 `emit(double)`：名字 `emit` 已存在，但没有 `double` 重载，输出 `emit was not declared in this scope.`。
第五次登记 `mix(double,int)` 成功，第六次调用匹配成功。
第七次调用 `halt(int)`，该名字从未登记，输出 `There is no function halt.`。
最后一次登记 `emit(int)`：返回类型与参数名不同，但名字和参数类型列表与第一次相同，输出 `redefinition of emit.`。

## 样例2

**输入**

```
3
1
int ping()
2
ping()
2
ping(int)
```

**输出**

```
Yes.
Yes.
ping was not declared in this scope.
```

**说明**

登记无参接口 `ping` 成功。
调用 `ping()` 与空参数列表匹配，输出 `Yes.`。
调用 `ping(int)` 时名字存在但类型列表不匹配，输出 `ping was not declared in this scope.`。

## 样例3

**输入**

```
2
2
open(int)
1
void open(int fd)
```

**输出**

```
There is no function open.
Yes.
```

**说明**

尚未登记任何接口就调用 `open`，输出 `There is no function open.`。
随后登记 `open(int)` 成功，输出 `Yes.`。
