# 题目内容
在一个长度为 $n$ 的能量阵列中，每个节点存储着一个非负能量值。系统将依次执行 $m$ 轮衰减操作，每轮操作规则如下：

- 找出当前所有节点中能量值最低的一个（若存在多个能量值相同的节点，选中编号最小的那个）。
- 除了被选中的节点保持不变外，其余所有节点的能量值均减少 $k$。

你的任务是：给定初始能量阵列、操作总轮数 $m$ 和衰减幅度 $k$，求出经过全部 $m$ 轮操作后每个节点的最终能量值。

**数据范围与约束**

- 测试数据组数 $T$ 不超过 $100$。
- 每个测试数据中，阵列长度 $n$、操作轮数 $m$ 和衰减幅度 $k$ 均为不超过 $2 \times 10^5$ 的正整数。
- 初始能量值均为不超过 $10^9$ 的正整数。
- 对于单个测试文件，所有数据的 $n$ 总和与 $m$ 总和分别不超过 $2 \times 10^5$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据组数。

接下来对于每组测试数据：

第一行包含三个整数 $n$、$m$、$k$，依次表示阵列长度、操作轮数和衰减幅度。

第二行包含 $n$ 个整数，表示初始能量值，整数之间用空格分隔。

# 输出描述
对于每组测试数据，输出一行 $n$ 个整数，表示所有操作完成后的最终能量值，整数之间用空格分隔。

## 样例1

**输入**

```
1
3 3 2
5 5 5
```

**输出**

```
1 1 1
```

**说明**

三个节点初始能量值均为 `5`，$k=2$，$m=3$。第一轮操作前，所有节点能量值均为 `5`，最小能量节点中编号最小的为 `1` 号节点，保持不变，`2` 号和 `3` 号节点各减少 $k=2$，因此第一轮后能量值变为 `[5, 3, 3]`。第二轮操作时，当前能量值最低的为 `3`（`2` 号和 `3` 号），编号最小的为 `2` 号节点，保持不变，`1` 号和 `3` 号减少 $2$，变为 `[3, 3, 1]`。第三轮操作时，最低能量值为 `1`（`3` 号节点），保持不变，`1` 号和 `2` 号减少 $2$，最终所有节点能量值均为 `1`。通过公式 $a_i^{\text{final}} = a_i - (m - t_i) \times k$ （其中 $t_i$ 为节点 $i$ 被保留的次数），每个节点最终均被保留了 `1` 次，因此结果均为 `1`。

## 样例2

**输入**

```
1
4 5 3
10 20 10 30
```

**输出**

```
4 5 1 15
```

**说明**

初始数组为 `[10, 20, 10, 30]`，$m=5$，$k=3$。

我们按每轮选择当前键值 $a_i + t_i \times k$ 最小的节点进行保留，模拟过程如下：
- 初始 $t=[0,0,0,0]$，键值 `[10, 20, 10, 30]`。第 `1` 轮：选 `1` 号节点（$t_1=1$，键值 $13$）。
- 第 `2` 轮：键值 `[13, 20, 10, 30]`，选 `3` 号节点（$t_3=1$，键值 $13$）。
- 第 `3` 轮：键值 `[13, 20, 13, 30]`，选 `1` 号节点（$t_1=2$，键值 $16$）。
- 第 `4` 轮：键值 `[16, 20, 13, 30]`，选 `3` 号节点（$t_3=2$，键值 $16$）。
- 第 `5` 轮：键值 `[16, 20, 16, 30]`，选 `1` 号节点（$t_1=3$，键值 $19$）。

操作结束，保留次数 $t$ 为 `[3, 0, 2, 0]`。代入最终公式 $a_i^{\text{final}} = a_i - (m - t_i) \times k$：
- 节点 `1`：$10 - (5-3) \times 3 = 4$
- 节点 `2`：$20 - (5-0) \times 3 = 5$
- 节点 `3`：$10 - (5-2) \times 3 = 1$
- 节点 `4`：$30 - (5-0) \times 3 = 15$

最终输出 `4 5 1 15`。

## 样例3

**输入**

```
2
1 5 100
7
2 3 2
4 4
```

**输出**

```
7
2 0
```

**说明**

本样例包含两组测试数据。

**第一组**：只有 `1` 个节点，初始能量为 `7`，$m=5$，$k=100$。根据规则，每次均选中该唯一节点保持不变，而“其余节点”并不存在，因此该节点能量值不受任何衰减影响，始终为 `7`。

**第二组**：两个节点初始能量均为 `4`，$m=3$，$k=2$。过程如下：
- 第 `1` 轮：两节点能量均为 `4`，选编号较小的 `1` 号保持不变，`2` 号能量减 $2$，变为 `[4, 2]`。
- 第 `2` 轮：当前最低能量为 `2`（`2` 号节点），选 `2` 号保持不变，`1` 号能量减 $2$，变为 `[2, 2]`。
- 第 `3` 轮：两节点能量均为 `2`，选编号较小的 `1` 号保持不变，`2` 号能量减 $2$，变为 `[2, 0]`。

最终 `1` 号保留 `2` 次，`2` 号保留 `1` 次，代入公式得到 `2` 和 `0`。
