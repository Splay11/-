# 题目内容
印花车间有一块 $n$ 行 $m$ 列的网版，每个格子是字符 `o` 或 `p`：`o` 表示尚未固色，`p` 表示已经固色。一次操作可以把任意一个 `o` 改成 `p`（不能把 `p` 改回 `o`）。成品要求网版中心对称：绕中心旋转 $180^\circ$ 后必须与原网版完全相同。

也就是说，对所有位置 $(i, j)$（行、列均从 `1` 编号），格子 $(i, j)$ 与格子 $(n+1-i, m+1-j)$ 上的字符相同。

求使网版变成中心对称所需的最少操作次数。

约束：$1 \le n, m \le 10^3$。

# 输入描述
第一行两个整数 $n$ 和 $m$，表示行数和列数。
接下来 $n$ 行，每行一个长度为 $m$、仅由字符 `o` 和 `p` 组成的字符串，表示该行的格子。
保证 $1 \le n, m \le 10^3$。

# 输出描述
输出一个整数，表示最少操作次数。

## 样例1

**输入**

```
3 3
ppp
ppo
ppp
```

**输出**

```
1
```

**说明**

位置 $(2,3)$ 为 `o`，与它中心对称的 $(2,1)$ 为 `p`，需要把该 `o` 改成 `p`，最少 `1` 次。

## 样例2

**输入**

```
1 4
pppo
```

**输出**

```
1
```

**说明**

一行四列时，第 `1` 格与第 `4` 格互为中心对称：`p` 与 `o` 不同，把 `o` 改成 `p` 即可，答案为 `1`。

## 样例3

**输入**

```
2 3
ppo
ppp
```

**输出**

```
1
```

**说明**

左上 `p` 与右下 `p` 相同；右上 `o` 与左下 `p` 不同，改 `1` 次。

## 样例4

**输入**

```
4 1
p
o
p
p
```

**输出**

```
1
```

**说明**

一列四行中，第 `2` 格 `o` 与第 `3` 格 `p` 不对称，改 `1` 次。
