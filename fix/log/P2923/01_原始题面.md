# 题目内容

游游有一个大小为 $n×m$ 的只由字母 $'o'，'p'$ 组成的矩阵。游游每次操作可以将一个字母 $'o'$ 变成 $'p'$ ，她想知道将矩阵变成中心对称至少需要操作几次。

中心对称是指，把矩阵绕着中心点旋转 $180°$ 后，仍与原矩阵一样。

# 输入描述

第一行输入两个整数 $n,m(1≤n,m≤1000)$ ，表示矩阵大小。

接下来 $n$ 行,每行输入一个长度为 $m$ ，且只由字母 $'o','p'$ 组成的字符串 $S_i$ 。

# 输出描述

输出一个整数表示答案




## 样例1 



**输入** 



```
2 2
oo
op
```



**输出** 



```
1
```



**说明**

将左上角的字母 $'o'$ 变成 $'p'$ ，矩阵变成了：

$po$

$op$
