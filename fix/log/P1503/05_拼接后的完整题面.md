# 题目内容
在一个空间站中，有 $n$ 个核心模块，它们通过 $n$ 条单向链路连接成一个闭合环。初始时这些链路的传输方向并不一致，导致部分模块之间无法互相通信。工程师可以调整任意一条链路的方向，但每次调整需要消耗一定的能源储备。对于第 $i$ 条链路，它从模块 $u_i$ 指向模块 $v_i$，调整方向需要花费 $c_i$ 单位能源。你的任务是选择一些链路翻转方向，使得最终每个模块都可以通过链路到达其他任意模块，并且总能源消耗最小。

模块数量 $n$ 满足 $2 \le n \le 10^5$，每条链路的调整代价 $c_i$ 不超过 $10^4$。输入的链路集合保证恰好构成一个环，即每个模块恰好出现在两条链路中。

# 输入描述
第一行包含一个整数 $n$，表示模块数量。
接下来 $n$ 行，每行包含三个整数 $u_i$、$v_i$ 和 $c_i$，表示一条从模块 $u_i$ 到模块 $v_i$ 的单向链路，将其调整为反向需要消耗 $c_i$ 单位能源。

# 输出描述
输出一个整数，表示使所有模块互相可达所需的最小总能源消耗。

## 样例1

**输入**

```
4
1 2 5
2 3 6
3 4 7
4 1 8
```

**输出**

```
0
```

**说明**

初始所有边已经沿着同一个方向 $1 \\to 2 \\to 3 \\to 4 \\to 1$ 构成强连通环，无需翻转任何链路，因此最小总能源消耗为 `0`。

## 样例2

**输入**

```
3
1 2 1
3 2 2
3 1 3
```

**输出**

```
2
```

**说明**

无向环为 $1-2-3-1$。边的方向与代价分别为：`1 2 1` 表示 $1 \\to 2$（代价 `1`），`3 2 2` 表示 $3 \\to 2$（代价 `2`），`3 1 3` 表示 $3 \\to 1$（代价 `3`）。

如果统一为顺时针方向 $1 \\to 2 \\to 3 \\to 1$，则 $3 \\to 2$ 与目标方向 $2 \\to 3$ 相反，需要翻转，代价 `2`；其余两条边方向一致，无需翻转，总代价 `2`。

如果统一为逆时针方向 $1 \\to 3 \\to 2 \\to 1$，则需要翻转 $1 \\to 2$ 和 $3 \\to 1$，代价 $1 + 3 = 4$。

取两种方案的最小值，答案为 `2`。

## 样例3

**输入**

```
2
1 2 10
1 2 20
```

**输出**

```
10
```

**说明**

两个模块 `1` 和 `2` 之间有两条单向链路，初始方向均为 $1 \\to 2$，此时模块 `2` 无法到达模块 `1`。只需选择其中代价较小的一条进行翻转（代价 `10`），即可形成 $1 \\to 2$ 和 $2 \\to 1$ 的双向可达，总能源消耗 `10`。

## 样例4

**输入**

```
5
1 2 3
2 3 4
3 4 5
5 4 6
5 1 7
```

**输出**

```
6
```

**说明**

无向环为 $1-2-3-4-5-1$。边的方向与代价如下：$1 \\to 2$（代价 `3`），$2 \\to 3$（代价 `4`），$3 \\to 4$（代价 `5`），$5 \\to 4$（代价 `6`），$5 \\to 1$（代价 `7`）。

若统一为 $1 \\to 2 \\to 3 \\to 4 \\to 5 \\to 1$ 的方向，仅有 $5 \\to 4$ 与目标方向 $4 \\to 5$ 相反，需翻转，代价 `6`。

若统一为反向，则需翻转 $1 \\to 2$、$2 \\to 3$、$3 \\to 4$ 和 $5 \\to 1$，总代价 $3+4+5+7=19$。

最小总消耗为 `6`。
