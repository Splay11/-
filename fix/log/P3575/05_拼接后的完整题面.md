# 题目内容
给定一个长度为 $n$ 的字符串 $s$，仅由字符 `r`、`e`、`d` 组成。对于任意满足 $1 \le i < j < k \le n$ 且 $s_i$ 为字符 `r`、$s_j$ 为字符 `e`、$s_k$ 为字符 `d` 的三元组 $(i,j,k)$，定义其跨度为 $|i-j|+|j-k|+|i-k|$。请你计算所有这样的三元组的跨度总和。

数据范围：字符串的长度 $n$ 满足 $1 \le n \le 2\times 10^5$，且字符串中仅包含字符 `r`、`e`、`d`。

# 输入描述
第一行包含一个整数 $n$（$1 \le n \le 2\times 10^5$），表示字符串的长度。
第二行包含一个长度为 $n$ 的字符串，仅由字符 `r`、`e`、`d` 组成。

# 输出描述
输出一个整数，表示所有满足条件的三元组的跨度总和。

## 样例1

**输入**

```
3
red
```

**输出**

```
4
```

**说明**

字符串中仅有 `1` 个符合条件的三元组 $(1,2,3)$，对应字符分别为 `r`、`e`、`d`。其跨度计算为 $|1-2|+|2-3|+|1-3| = 1+1+2 = 4$，也可以简化为 $2 \times (3-1) = 4$。因此总和为 `4`。

## 样例2

**输入**

```
6
rreedd
```

**输出**

```
64
```

**说明**

字符 `r` 的位置为 $1, 2$，`e` 的位置为 $3, 4$，`d` 的位置为 $5, 6$。
共有 $2 \times 2 \times 2 = 8$ 个三元组。
对于每一对 $(i, k)$，其中 $i$ 是 `r` 的索引、$k$ 是 `d` 的索引，两者之间的 `e` 数量均为 $2$。
跨度总和为 $2 \times \sum_{i<k} (k-i) \times 2 = 2 \times [(5-1)\times2 + (6-1)\times2 + (5-2)\times2 + (6-2)\times2] = 2 \times (8+10+6+8) = 64$。
因此输出 `64`。

## 样例3

**输入**

```
3
der
```

**输出**

```
0
```

**说明**

字符串为 `der`，不存在满足 $i<j<k$ 且依次为 `r`、`e`、`d` 的三元组，因此跨度总和为 `0`。

## 样例4

**输入**

```
5
rrred
```

**输出**

```
18
```

**说明**

`r` 位置为 $1, 2, 3$，`e` 位置为 $4$，`d` 位置为 $5$。
共有 $3$ 个三元组：$(1,4,5)$、$(2,4,5)$、$(3,4,5)$。
跨度分别为 $2 \times (5-1) = 8$、$2 \times (5-2) = 6$、$2 \times (5-3) = 4$。
总和为 $8+6+4=18$，输出 `18`。
