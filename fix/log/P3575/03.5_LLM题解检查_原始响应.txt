## 解题思路

1. **跨度化简**  
   对于任意满足 $i<j<k$ 且 $s_i='r'$、$s_j='e'$、$s_k='d'$ 的三元组 $(i,j,k)$，其跨度为：
   $$
   |i-j|+|j-k|+|i-k| = (j-i)+(k-j)+(k-i) = 2(k-i)
   $$
   由此可见，每个合法三元组的跨度只与其首尾位置 $i$ 和 $k$ 有关，与中间 $j$ 无关，且等于 $2(k-i)$。

2. **拆解贡献**  
   固定中间字符 `'e'` 所在的位置 $j$，设：
   - $R_L$ 为所有在 $j$ 左侧且字符为 `'r'` 的位置集合；
   - $D_R$ 为所有在 $j$ 右侧且字符为 `'d'` 的位置集合。
   则以该 $j$ 为中间元素的所有三元组的跨度总和为：
   $$
   \sum_{i \in R_L} \sum_{k \in D_R} 2(k-i) = 2 \left( |R_L| \cdot \sum_{k \in D_R} k - |D_R| \cdot \sum_{i \in R_L} i \right)
   $$
   其中 $|R_L|$ 表示左侧 `'r'` 的个数，$\sum_{i \in R_L} i$ 表示这些位置的下标和；$|D_R|$ 和 $\sum_{k \in D_R} k$ 同理。

3. **预处理前缀与后缀信息**  
   - 从左到右预处理两个前缀数组：  
     `preRcnt[i]` 表示前 $i$ 个字符中 `'r'` 的个数；  
     `preRsum[i]` 表示前 $i$ 个字符中所有 `'r'` 的位置下标之和（下标从 $1$ 开始）。
   - 从右到左预处理两个后缀数组：  
     `sufDcnt[i]` 表示从第 $i$ 个字符开始到末尾 `'d'` 的个数；  
     `sufDsum[i]` 表示这些 `'d'` 的位置下标之和。
   以上数组均可使用 1‑based 下标，在 $O(n)$ 时间内计算完成。

4. **合并答案**  
   遍历所有位置 $j = 1 \dots n$，当 $s_j = $ `'e'` 时，用预处理的数据直接计算：
   $$
   \text{ans} \mathrel{+}= 2 \times \big( \text{preRcnt}[j] \times \text{sufDsum}[j] - \text{sufDcnt}[j] \times \text{preRsum}[j] \big)
   $$
   最终输出 `ans` 即可。由于最终答案可能很大，全程使用 64 位有符号整数（`long long` / `long` / Python 的 `int`）。

## 复杂度分析

- **时间复杂度**：$O(n)$。预处理前缀和后缀数组各扫描一次，之后对每个位置 $O(1)$ 计算贡献，总操作次数与 $n$ 成正比。
- **空间复杂度**：$O(n)$。需要存储四个长度为 $n+2$ 的辅助数组（`preRcnt`、`preRsum`、`sufDcnt`、`sufDsum`）。

## 代码实现

### Python

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    n = int(data[0])
    s = data[1].strip()

    # 前缀信息：左侧 'r' 的个数与下标和（1‑based）
    preRcnt = [0] * (n + 1)
    preRsum = [0] * (n + 1)
    for i in range(1, n + 1):
        preRcnt[i] = preRcnt[i - 1] + (1 if s[i - 1] == 'r' else 0)
        preRsum[i] = preRsum[i - 1] + (i if s[i - 1] == 'r' else 0)

    # 后缀信息：右侧 'd' 的个数与下标和（1‑based）
    sufDcnt = [0] * (n + 2)
    sufDsum = [0] * (n + 2)
    for i in range(n, 0, -1):
        sufDcnt[i] = sufDcnt[i + 1] + (1 if s[i - 1] == 'd' else 0)
        sufDsum[i] = sufDsum[i + 1] + (i if s[i - 1] == 'd' else 0)

    ans = 0
    for j in range(1, n + 1):
        if s[j - 1] == 'e':
            ans += 2 * (preRcnt[j] * sufDsum[j] - sufDcnt[j] * preRsum[j])

    print(ans)

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String line = br.readLine();
        if (line == null || line.trim().isEmpty()) return;
        int n = Integer.parseInt(line.trim());
        String s = br.readLine().trim();

        // 前缀信息：左侧 'r' 的个数与下标和（1‑based）
        long[] preRcnt = new long[n + 1];
        long[] preRsum = new long[n + 1];
        for (int i = 1; i <= n; i++) {
            preRcnt[i] = preRcnt[i - 1] + (s.charAt(i - 1) == 'r' ? 1 : 0);
            preRsum[i] = preRsum[i - 1] + (s.charAt(i - 1) == 'r' ? i : 0);
        }

        // 后缀信息：右侧 'd' 的个数与下标和（1‑based）
        long[] sufDcnt = new long[n + 2];
        long[] sufDsum = new long[n + 2];
        for (int i = n; i >= 1; i--) {
            sufDcnt[i] = sufDcnt[i + 1] + (s.charAt(i - 1) == 'd' ? 1 : 0);
            sufDsum[i] = sufDsum[i + 1] + (s.charAt(i - 1) == 'd' ? i : 0);
        }

        long ans = 0;
        for (int j = 1; j <= n; j++) {
            if (s.charAt(j - 1) == 'e') {
                ans += 2L * (preRcnt[j] * sufDsum[j] - sufDcnt[j] * preRsum[j]);
            }
        }

        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    string s;
    cin >> s;

    // 前缀信息：左侧 'r' 的个数与下标和（1‑based）
    vector<long long> preRcnt(n + 1, 0), preRsum(n + 1, 0);
    for (int i = 1; i <= n; ++i) {
        preRcnt[i] = preRcnt[i - 1] + (s[i - 1] == 'r');
        preRsum[i] = preRsum[i - 1] + (s[i - 1] == 'r' ? i : 0);
    }

    // 后缀信息：右侧 'd' 的个数与下标和（1‑based）
    vector<long long> sufDcnt(n + 2, 0), sufDsum(n + 2, 0);
    for (int i = n; i >= 1; --i) {
        sufDcnt[i] = sufDcnt[i + 1] + (s[i - 1] == 'd');
        sufDsum[i] = sufDsum[i + 1] + (s[i - 1] == 'd' ? i : 0);
    }

    long long ans = 0;
    for (int j = 1; j <= n; ++j) {
        if (s[j - 1] == 'e') {
            ans += 2LL * (preRcnt[j] * sufDsum[j] - sufDcnt[j] * preRsum[j]);
        }
    }

    cout << ans << "\n";
    return 0;
}
```
