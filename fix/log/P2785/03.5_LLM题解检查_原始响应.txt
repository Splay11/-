## 解题思路

1. **操作等价与转化**  
   一次合并操作会将两个元素从序列中移除，并将它们的和插入到序列的任意位置。如果我们只关心最终序列是否非递减（每个元素均不大于其后继元素），那么合并操作可以看作一次性去掉了两个“不希望保留”的元素。  
   因此，若需要从原序列中删去 $\Delta$ 个元素才能使剩余部分非递减，那么最少操作次数就是 $\lceil \frac{\Delta}{2} \rceil$（等价于 $(\Delta + 1) / 2$ 次合并）。

2. **最小删除数**  
   要使剩余部分非递减，等价于保留一个尽可能长的非递减子序列。设原序列长度为 $n$，最长非递降子序列（Longest Non-Decreasing Subsequence, LNDS）的长度为 $L$，则最少需要删除的元素个数为：  
   $\Delta = n - L$

3. **求最长非递降子序列长度 $L$**  
   采用 Patience Sorting 方法（二分优化的动态规划）。维护一个数组 `tail`，其中 `tail[i]` 表示当前找到的长度为 $i+1$ 的所有非递降子序列中，末尾元素能够取到的最小值。  
   遍历序列中的每一个元素 $x$：
   - 在 `tail` 中用二分查找**第一个大于 $x$** 的位置（对应 `bisect_right` 或 `upper_bound`），记作 $pos$；
   - 若 $pos$ 等于当前 `tail` 的长度，说明 $x$ 不小于 `tail` 的所有元素，可以直接追加，得到一个更长的非递降子序列；
   - 否则，用 $x$ 替换 `tail[pos]`，这样既不破坏已有的最长长度，又可能使该长度的末尾值变得更小，有利于后续构造。
   遍历结束后，`tail` 的长度即为 $L$。

4. **计算最终答案**  
   操作次数为：  
   $ans = \lceil \frac{n - L}{2} \rceil = (n - L + 1) // 2$  
   对每一组测试数据依此计算并输出结果。

## 复杂度分析

- **时间复杂度**：对于每组数据，需要遍历 $n$ 个元素，每次在 `tail` 数组上二分查找，单组时间复杂度为 $O(n \log n)$。所有测试数据的 $n$ 总和不超过 $2 \times 10^5$，总时间复杂度 $O(\sum n \log n)$，可以在时限内完成。
- **空间复杂度**：每组数据需要存储长度为 $n$ 的序列以及长度不超过 $n$ 的 `tail` 数组，空间复杂度为 $O(n)$。

## 代码实现

### Python

```python
import sys
import bisect

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    T = int(data[0])
    idx = 1
    out = []
    for _ in range(T):
        n = int(data[idx]); idx += 1
        arr = list(map(int, data[idx:idx + n])); idx += n
        
        tail = []
        for x in arr:
            # 非递降子序列：找第一个大于 x 的位置（bisect_right）
            pos = bisect.bisect_right(tail, x)
            if pos == len(tail):
                tail.append(x)
            else:
                tail[pos] = x
        
        L = len(tail)               # 最长非递降子序列长度
        ans = (n - L + 1) // 2      # 合并操作次数
        out.append(str(ans))
    
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.*;
import java.io.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();
        StringBuilder sb = new StringBuilder();

        while (T-- > 0) {
            int n = sc.nextInt();
            int[] arr = new int[n];
            for (int i = 0; i < n; i++) {
                arr[i] = sc.nextInt();
            }

            // tail 用于维护最长非递降子序列的末尾元素
            ArrayList<Integer> tail = new ArrayList<>();
            for (int x : arr) {
                // 找到 tail 中第一个大于 x 的位置（对应 bisect_right）
                int pos = binarySearchRight(tail, x);
                if (pos == tail.size()) {
                    tail.add(x);
                } else {
                    tail.set(pos, x);
                }
            }

            int L = tail.size();
            int ans = (n - L + 1) / 2;   // (n - L + 1) // 2
            sb.append(ans).append("\n");
        }
        System.out.print(sb);
    }

    // 返回 tail 中第一个大于 x 的下标，若不存在则返回 tail.size()
    private static int binarySearchRight(ArrayList<Integer> tail, int x) {
        int left = 0, right = tail.size();
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (tail.get(mid) <= x) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left;
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        vector<long long> arr(n);
        for (int i = 0; i < n; ++i) {
            cin >> arr[i];
        }

        vector<long long> tail;
        tail.reserve(n);
        for (long long x : arr) {
            // upper_bound 返回第一个大于 x 的位置（对应 bisect_right）
            auto pos = upper_bound(tail.begin(), tail.end(), x);
            if (pos == tail.end()) {
                tail.push_back(x);
            } else {
                *pos = x;
            }
        }

        int L = (int)tail.size();           // 最长非递降子序列长度
        int ans = (n - L + 1) / 2;          // 最少合并次数
        cout << ans << "\n";
    }

    return 0;
}
```
