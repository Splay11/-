# 题目内容
给定一个由正整数组成的序列。你希望通过最少的操作次数，把序列变成一个非递减的序列，即每个元素都不大于它后面的元素。

你可以执行的操作如下：
- 选择序列中两个不同位置的元素，将它们合并为一个新的元素。新元素的值等于被选中的两个元素之和。
- 将原来的两个元素从序列中删去，然后把新元素插入到序列的任意位置（可以是第一个元素之前、最后一个元素之后，或者任意两个相邻元素之间）。

请问，最少需要执行多少次这样的合并操作，才能使最终的序列成为非递减序列？

数据范围：
- 测试数据组数 $T$ 满足 $1 \le T \le 100$。
- 单个序列的长度 $n$ 满足 $1 \le n \le 10^5$，所有测试数据中 $n$ 的总和不超过 $2 \times 10^5$。
- 序列中的每个数均为正整数，且不超过 $10^9$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据的组数。
接下来依次给出每组测试数据。对于每组数据：
第一行包含一个整数 $n$，表示序列的长度。
第二行包含 $n$ 个正整数，表示序列的初始值，相邻整数之间以空格分隔。

# 输出描述
对于每组测试数据，输出一行一个整数，表示将该序列变为非递减序列所需的最少操作次数。

## 样例1

**输入**

```
1
1
10
```

**输出**

```
0
```

**说明**

只有 `1` 个元素，序列 `[10]` 已经是非递减的，不需要任何合并操作，因此操作次数为 `0`。

## 样例2

**输入**

```
2
3
3 2 1
5
4 1 3 2 2
```

**输出**

```
1
1
```

**说明**

第一组数据：序列为 `[3, 2, 1]`。我们可以将 `2` 和 `1` 合并，得到新元素 $2+1=3$，并将其插入到原序列中 `3` 的后面，得到序列 `[3, 3]`，满足非递减条件。无法用 `0` 次操作完成，因此最少需要 `1` 次操作。

第二组数据：序列为 `[4, 1, 3, 2, 2]`。我们可以保留原序列中的子序列 `[1, 2, 2]`（对应原序列第 `2, 4, 5` 个元素），它们已经是非递减的。将剩余的两个元素 `4` 和 `3` 合并为一个新元素 $4+3=7$，并将其插入到序列末尾，最终得到 `[1, 2, 2, 7]`，满足非递减。此过程只用 `1` 次操作。同样无法用 `0` 次操作完成，故答案也为 `1`。

## 样例3

**输入**

```
1
5
5 4 3 2 1
```

**输出**

```
2
```

**说明**

原序列 `[5, 4, 3, 2, 1]` 严格递减。可以保留元素 `1`，并执行两次合并操作：第一次合并 `5` 和 `4` 得到 `9`，第二次合并 `3` 和 `2` 得到 `5`。将新元素 `9` 和 `5` 与保留的 `1` 按非递减顺序排列，得到 `[1, 5, 9]`。注意，如果只进行 `1` 次操作，只能合并两个元素，序列中仍会留下逆序对，无法使整个序列非递减。因此最少操作次数为 `2`。
