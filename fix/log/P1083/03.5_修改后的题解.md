## 解题思路

1. 题目要求在 $n$ 个符文灵力值中，选出三个符文，使得最大值与最小值之差恰好为 $1$，即满足 $\max - \min = 1$。分析可知，这样的三元组一定由两种灵力值组成，且两种灵力值相差 $1$，并且三元组中必有两个元素相等：
   - 情况一：两个 $x$ 和一个 $x-1$，即 $(x-1,\;x,\;x)$。
   - 情况二：两个 $x-1$ 和一个 $x$，即 $(x-1,\;x-1,\;x)$。

2. 使用哈希表（桶）统计每种灵力值出现的次数。记灵力值 $v$ 的出现次数为 $\text{cnt}[v]$。

3. 遍历哈希表中的每一种灵力值 $x$，计算其对答案的贡献：
   - 贡献一：从 $\text{cnt}[x]$ 个 $x$ 中选 $2$ 个，再从 $\text{cnt}[x-1]$ 个 $x-1$ 中选 $1$ 个，组合数为 $C(\text{cnt}[x],\,2) \times \text{cnt}[x-1]$。
   - 贡献二：从 $\text{cnt}[x-1]$ 个 $x-1$ 中选 $2$ 个，再从 $\text{cnt}[x]$ 个 $x$ 中选 $1$ 个，组合数为 $C(\text{cnt}[x-1],\,2) \times \text{cnt}[x]$。
   将两部分相加，即为所有以 $x$ 和 $x-1$ 构成的共鸣三元组数量。

4. 将所有灵力值的贡献累加，得到最终答案。注意答案可能超过 $32$ 位整数范围，需要使用 $64$ 位整数（`long long` / `int64`）。

## 复杂度分析

- 时间复杂度：$O(n)$。第一次遍历统计频次，第二次遍历哈希表中的所有不同灵力值，不同灵力值的数量不超过 $n$，整体仍为线性。
- 空间复杂度：$O(n)$。哈希表最坏需要存储所有 $n$ 个灵力值的计数信息。

## 代码实现

### Python

```python
import sys
from collections import defaultdict

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    n = int(data[0])
    values = list(map(int, data[1:1 + n]))
    
    cnt = defaultdict(int)
    for v in values:
        cnt[v] += 1
    
    ans = 0
    for x, cx in cnt.items():
        # 两个 x 和一个 x-1
        if cx >= 2:
            cx_m1 = cnt.get(x - 1, 0)
            ans += cx * (cx - 1) // 2 * cx_m1
        
        # 两个 x-1 和一个 x 的情况，会在遍历到 x-1 时被统计，
        # 但为了逻辑对称，这里直接按公式计算，需要保证 x-1 存在时才计算，
        # 否则 cnt[x-1] 的默认值 0 会使贡献为 0，因此统一使用 cnt.get 即可。
        cx_m1 = cnt.get(x - 1, 0)
        if cx_m1 >= 2:
            ans += cx_m1 * (cx_m1 - 1) // 2 * cx
    
    print(ans)

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());
        String[] parts = br.readLine().trim().split("\\s+");
        
        Map<Integer, Long> cnt = new HashMap<>();
        for (int i = 0; i < n; i++) {
            int v = Integer.parseInt(parts[i]);
            cnt.put(v, cnt.getOrDefault(v, 0L) + 1);
        }
        
        long ans = 0;
        for (Map.Entry<Integer, Long> entry : cnt.entrySet()) {
            int x = entry.getKey();
            long cx = entry.getValue();
            long cx_m1 = cnt.getOrDefault(x - 1, 0L);
            
            // 两个 x 和一个 x-1
            if (cx >= 2) {
                ans += cx * (cx - 1) / 2 * cx_m1;
            }
            // 两个 x-1 和一个 x
            if (cx_m1 >= 2) {
                ans += cx_m1 * (cx_m1 - 1) / 2 * cx;
            }
        }
        
        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n;
    cin >> n;
    unordered_map<int, long long> cnt;
    
    for (int i = 0; i < n; ++i) {
        int v;
        cin >> v;
        cnt[v]++;
    }
    
    long long ans = 0;
    // 遍历时避免使用 operator[] 引发插入操作，改用 find
    for (auto& p : cnt) {
        int x = p.first;
        long long cx = p.second;
        long long cx_m1 = 0;
        auto it = cnt.find(x - 1);
        if (it != cnt.end()) {
            cx_m1 = it->second;
        }
        
        // 两个 x 和一个 x-1
        if (cx >= 2) {
            ans += cx * (cx - 1) / 2 * cx_m1;
        }
        // 两个 x-1 和一个 x
        if (cx_m1 >= 2) {
            ans += cx_m1 * (cx_m1 - 1) / 2 * cx;
        }
    }
    
    cout << ans << '\n';
    return 0;
}
```
