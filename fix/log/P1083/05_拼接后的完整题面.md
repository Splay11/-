# 题目内容
魔法师从卷轴中解封了一组共 $n$ 个符文，每个符文都有一个整数灵力值。他想要从中挑选三个符文进行共鸣实验：若这三个符文的灵力值中最大值与最小值之差恰好为 $1$，则它们可以形成一次共鸣。请你计算出所有可行的三符文组合数。

符文总数 $n$ 满足 $3 \le n \le 200000$。每个灵力值均为 $1$ 到 $10^9$ 之间的整数。

# 输入描述
第一行包含一个整数 $n$，表示符文的数量。
第二行包含 $n$ 个整数，表示每个符文的灵力值。

# 输出描述
输出一个整数，表示共鸣三元组的方案数。

## 样例1

**输入**

```
3
1 1 2
```

**输出**

```
1
```

**说明**

符文灵力值为 $1,1,2$。最大值 $2$ 与最小值 $1$ 之差为 $1$，可形成共鸣。
三元组模式为“两个 $1$ 一个 $2$”：从两个 $1$ 中选两个的方案数为 $C(2,2)=1$，从 $2$ 中选一个的方案数为 $1$，总方案数 $1 \times 1 = 1$。

## 样例2

**输入**

```
5
1 2 2 3 3
```

**输出**

```
5
```

**说明**

灵力值出现次数：$d[1]=1$，$d[2]=2$，$d[3]=2$。
对于相邻值 $(1,2)$：两个 $2$ 和一个 $1$ 的方案数为 $C(2,2) \times d[1] = 1 \times 1 = 1$；两个 $1$ 和一个 $2$ 需 $d[1] \ge 2$ 不满足，贡献 $0$。
对于相邻值 $(2,3)$：两个 $2$ 和一个 $3$ 的方案数为 $C(2,2) \times d[3] = 1 \times 2 = 2$；两个 $3$ 和一个 $2$ 的方案数为 $C(2,2) \times d[2] = 1 \times 2 = 2$。
总计 $1 + 0 + 2 + 2 = 5$。

## 样例3

**输入**

```
6
1 1 1 2 2 2
```

**输出**

```
18
```

**说明**

灵力值 $1$ 出现 $3$ 次，$2$ 出现 $3$ 次。
两个 $1$ 和一个 $2$：$C(3,2) \times d[2] = 3 \times 3 = 9$。
两个 $2$ 和一个 $1$：$C(3,2) \times d[1] = 3 \times 3 = 9$。
总方案数为 $9+9=18$。

## 样例4

**输入**

```
3
5 5 5
```

**输出**

```
0
```

**说明**

三个符文灵力值均为 $5$，最大值与最小值之差为 $0 
eq 1$，无法形成共鸣，方案数为 $0$。
