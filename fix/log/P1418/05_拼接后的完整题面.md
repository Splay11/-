# 题目内容
一份配额已经用掉了 $\dfrac{A}{B}$，现在需要算出还剩多少，即 $1 - \dfrac{A}{B}$。结果仍表示成分数，并且分母必须保持为 $B$，分子为 $B-A$，中间用空格隔开，无需再约分。

约束：分子 $A$ 与分母 $B$ 满足 $1 \le A < B \le 10^3$。

# 输入描述
一行两个整数 $A$ 和 $B$，分别表示已用份额的分子与分母。保证 $1 \le A < B \le 10^3$。

# 输出描述
输出两个整数，用空格隔开，依次表示剩余份额的分子与分母（分母必须为 $B$）。

## 样例1

**输入**

```
1 2
```

**输出**

```
1 2
```

**说明**

$1-\dfrac{1}{2}=\dfrac{1}{2}$，输出 `1 2`。这是 $A=1$ 的较小边界。

## 样例2

**输入**

```
999 1000
```

**输出**

```
1 1000
```

**说明**

$1-\dfrac{999}{1000}=\dfrac{1}{1000}$，输出 `1 1000`。这是接近上限 $B=10^3$ 的情形。

## 样例3

**输入**

```
2 3
```

**输出**

```
1 3
```

**说明**

按题意模拟计算得到。
