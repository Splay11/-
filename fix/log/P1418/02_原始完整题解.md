## 思路：模拟

输出$b-a$，$b$即可

### c++代码

```cpp
#include <iostream>

using namespace std;

int main()
{
    int a, b;
    cin >> a >> b;
    cout << b - a << ' ' << b << endl;
    return 0;
}
```

**python代码**

```python
a, b = map(int, input().split())
print(b-a, b)
```

**Java代码**

```java
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int A = sc.nextInt();
        int B = sc.nextInt();
        System.out.print(B - A);
        System.out.println(" " + B);
    }
}
```
