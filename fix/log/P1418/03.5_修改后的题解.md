## 解题思路

剩余份额为
$$
1-\dfrac{A}{B}=\dfrac{B-A}{B}
$$
题目要求分母保持为 $B$、不必约分，因此直接输出 $B-A$ 与 $B$ 即可。

## 复杂度分析

只做一次减法。

- 时间复杂度：$O(1)$。
- 空间复杂度：$O(1)$。

## 代码实现

### Python

```python
a, b = map(int, input().split())
print(b - a, b)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int A = sc.nextInt();
        int B = sc.nextInt();
        System.out.print(B - A);
        System.out.println(" " + B);
    }
}
```

### C++

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << b - a << ' ' << b << endl;
    return 0;
}
```
