# 题目内容
在一棵有 $n$ 个节点的树上，节点编号为 $1$ 到 $n$，每个节点有一个正整数的评分 $a_i$。定义树上的一个点集 $S$ 为“连通点集”，当且仅当对于 $S$ 中任意两个节点 $u$ 和 $v$，从 $u$ 到 $v$ 的简单路径上所有节点都属于 $S$。特别地，只包含一个节点的集合也算作连通点集。

如果一个连通点集中所有节点评分的乘积能被 $10$ 整除（即乘积的十进制表示末尾至少有一个 $0$），则称该连通点集为“幸运集”。请你计算树上幸运集的总数。由于答案可能很大，需要对 $10^9+7$ 取模。

节点数 $n$ 不超过 $10^5$，每个节点的评分 $a_i$ 均为正整数且不超过 $10^9$。

# 输入描述
第一行包含一个整数 $n$，表示树的节点数。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$，表示每个节点的评分。
接下来 $n-1$ 行，每行包含两个整数 $u$ 和 $v$，表示树上的一条边。

# 输出描述
输出一个整数，表示幸运集的总数对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
1
10
```

**输出**

```
1
```

**说明**

树中只有一个节点，评分 $a_1 = 10$，同时包含因子 $2$ 和因子 $5$（状态为 `3`），乘积末尾有零，因此该单节点连通块就是幸运集。总数为 `1`。

## 样例2

**输入**

```
3
2 5 1
1 2
2 3
```

**输出**

```
2
```

**说明**

树形成一条链 `1-2-3`。评分分别为 $a_1=2$（只含因子 $2$），$a_2=5$（只含因子 $5$），$a_3=1$（不含因子）。

单个节点均不满足条件。

两个节点的连通块：`{1,2}` 乘积为 $2 \times 5 = 10$，能被 $10$ 整除，是幸运集；`{2,3}` 乘积为 $5$，不是幸运集。

三个节点的连通块 `{1,2,3}` 乘积为 $2 \times 5 \times 1 = 10$，是幸运集。

因此共有 `2` 个幸运集。

## 样例3

**输入**

```
4
2 5 10 3
1 2
1 3
1 4
```

**输出**

```
7
```

**说明**

树以节点 `1` 为中心，连接 `2`、`3`、`4`。评分：$a_1=2$（只含因子 $2$），$a_2=5$（只含因子 $5$），$a_3=10$（同时含因子 $2$ 和 $5$），$a_4=3$（不含因子）。

单个节点中仅 `{3}` 是幸运集。

任何包含节点 `3` 的连通块一定同时含有因子 $2$ 和 $5$，均为幸运集：`{3}`、`{1,3}`、`{1,2,3}`、`{1,3,4}`、`{1,2,3,4}`，共 $5$ 个。

不包含节点 `3` 但能同时获得因子 $2$ 和 $5$ 的连通块必须同时包含 `1` 和 `2`：`{1,2}`、`{1,2,4}`，共 $2$ 个。

总计 $5 + 2 = 7$ 个幸运集。
