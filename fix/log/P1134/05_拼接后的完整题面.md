# 题目内容
有一棵 $n$ 个节点的有根树，根节点编号为 `1`。节点 $i$ 有一个正整数权值 $val_i$。树上有 $n-1$ 条无向边。
接下来进行 $q$ 次操作。每次操作给定节点 $t$ 与正整数 $g$，将「以 $t$ 为根的子树」中每个节点的权值都乘上 $g$。
全部操作结束后，对每个节点 $i$，考虑以 $i$ 为根的子树中所有节点权值的乘积，求出该乘积十进制表示末尾有多少个 `0`。

约束条件：
- 节点数 $n$ 与操作次数 $q$ 均不超过 $10^5$。
- 每个初始权值 $val_i$ 以及每次操作中的乘数 $g$ 均为不超过 $10^9$ 的正整数。
- 节点编号均在 `1` 到 $n$ 之间。

# 输入描述
第一行包含一个正整数 $n$，表示节点个数。
第二行包含 $n$ 个正整数 $val_1, val_2, \ldots, val_n$，表示各节点的初始权值。
接下来 $n-1$ 行，每行两个正整数 $u$ 和 $v$，表示节点 $u$ 与节点 $v$ 之间有一条边。
接下来一行包含一个正整数 $q$，表示操作次数。
接下来 $q$ 行，每行两个正整数 $t$ 和 $g$，表示一次操作。

# 输出描述
输出一行 $n$ 个整数，第 $i$ 个数表示以节点 $i$ 为根的子树中所有权值乘积末尾 `0` 的个数，相邻整数之间用空格分隔。

## 样例1

**输入**

```
6
1 2 3 4 5 6
1 2
2 3
1 4
2 5
4 6
2
2 5
4 5
```

**输出**

```
4 1 0 2 0 1
```

**说明**

树以 `1` 为根。两次操作分别把节点 `2` 的子树（节点 `2,3,5`）和节点 `4` 的子树（节点 `4,6`）乘上 `5`。
最终各节点权值为 $1,10,15,20,25,30$。
以 `1` 为根的子树乘积含 `4` 个因子 `2` 与 `6` 个因子 `5`，末尾 `0` 的个数为 $\min(4,6)=4$。
其余节点同理，得到 `4 1 0 2 0 1`。

## 样例2

**输入**

```
1
10
0
```

**输出**

```
1
```

**说明**

只有一个节点，权值为 `10`，没有操作。
$10=2 \times 5$，末尾恰好有 `1` 个 `0`。

## 样例3

**输入**

```
3
1 1 1
1 2
2 3
0
```

**输出**

```
0 0 0
```

**说明**

三个节点权值均为 `1`，没有操作。任意子树乘积都是 `1`，末尾没有 `0`，故输出 `0 0 0`。
