# 题目内容
在数字世界中，有一种跃迁操作：对于一个正整数 $x$，可以将其变成 $x + S(x)$，其中 $S(x)$ 表示 $x$ 的各位数字之和。

现在设定一个上限 $N$，我们只关心 $1$ 到 $N$ 之间的数字。若 $x + S(x) \le N$，则在 $x$ 与 $x + S(x)$ 之间建立一条双向通道。这样所有数字和通道构成了一张图。

给定两个不同的起点 $u$ 和 $v$（$1 \le u, v \le N$，且 $u 
e v$），请你判断它们能否通过这些通道相互到达，并且它们所在的连通分量能一路跃迁最终到达 $N$。如果可以，输出从 $u$ 到 $v$ 所需经过的最少通道数；否则输出 `NO`。

约束：$N$ 不超过 $10^6$，$u$ 和 $v$ 均不超过 $N$ 且互不相同。

# 输入描述
输入仅一行，包含三个整数 $N$、$u$ 和 $v$，用空格分隔。

# 输出描述
如果满足条件，输出一个整数，表示最少需要经过的通道数；否则输出 `NO`。

## 样例1

**输入**

```
2 1 2
```

**输出**

```
1
```

**说明**

对于 `1` 到 `2`，跃迁操作 $1 + S(1) = 1 + 1 = 2$，且 $2 \le 2$，因此在 `1` 和 `2` 之间建立一条通道。两条节点均连通且最终可到达 $N=2$。从 `1` 到 `2` 只需经过 `1` 条通道。

## 样例2

**输入**

```
30 21 24
```

**输出**

```
1
```

**说明**

从 `21` 开始跃迁：$21 + S(21) = 21 + 3 = 24 \le 30$，建立通道。从 `24` 继续跃迁：$24 + S(24) = 24 + 6 = 30 = N$，因此 `21` 和 `24` 所在连通分量包含 $N$。

$u=21$ 与 $v=24$ 之间有一条直接通道，经过的最少通道数为 `1`。

## 样例3

**输入**

```
20 1 2
```

**输出**

```
NO
```

**说明**

从 `1` 跃迁到 `2`（$1 + 1 = 2 \le 20$），$u$ 与 $v$ 可以相遇。从相遇点 `2` 继续跃迁：$2 \to 4 \to 8 \to 16 \to 23$。由于 $23 > 20$，无法恰好到达 $N=20$。连通分量不包含 $N$，故输出 `NO`。

## 样例4

**输入**

```
30 10 15
```

**输出**

```
NO
```

**说明**

`10` 的跃迁路径为 $10 \to 11 \to 13 \to 17 \to 25 \to 32$（$32 > 30$ 停止）。
`15` 的跃迁路径为 $15 \to 21 \to 24 \to 30$。

两条路径在不超过 $N=30$ 的范围内没有公共节点，因此 `10` 与 `15` 无法相互到达，输出 `NO`。
