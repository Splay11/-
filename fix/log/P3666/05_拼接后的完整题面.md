# 题目内容
一个大于 `1` 的正整数 $x$ 的指数强度定义为：将其质因数分解后，各质因子指数的最大值。例如 $90=2^{1}\times 3^{2}\times 5^{1}$，指数强度为 `2`。

给定长度为 $n$ 的正整数序列 $a_1,a_2,\ldots,a_n$。请选出一段长度不超过 $k$ 的连续区间，使得区间内各数的指数强度之和最大，并输出这个最大和。

约束：测试组数不超过 `2×10^5`，单组序列长度不超过 `2×10^5`，且单个测试文件中序列长度之和不超过 `2×10^5`。每个数不超过 `10^7`，且至少为 `2`。

# 输入描述
每个测试文件包含多组数据。第一行一个整数 $T$，表示数据组数。
每组数据格式如下：
第一行两个整数 $n$ 和 $k$，分别表示序列长度与区间长度上限；
第二行 $n$ 个整数 $a_1,a_2,\ldots,a_n$。
保证 $1 \le T \le 2 \times 10^5$，$1 \le k \le n \le 2 \times 10^5$，$2 \le a_i \le 10^7$，且单个文件中 $n$ 之和不超过 $2 \times 10^5$。

# 输出描述
对每组数据输出一行一个整数，表示最大的指数强度之和。

## 样例1

**输入**

```
2
4 2
4 6 8 9
3 1
8 4 16
```

**输出**

```
5
4
```

**说明**

第一组强度依次为 $2,1,3,2$（对应 $4=2^2$、$6=2\times 3$、$8=2^3$、$9=3^2$）。长度不超过 `2` 的最大和为 $3+2=`5`。
第二组强度为 $3,2,4$，长度上限为 `1`，最大值为 `4`。

## 样例2

**输入**

```
1
1 1
2
```

**输出**

```
1
```

**说明**

只有一个数 `2`，指数强度为 `1`，答案为 `1`。这是 $n=1$ 的边界情形。

## 样例3

**输入**

```
2
4 2
4 6 8 9
3 1
9 5 17
```

**输出**

```
5
2
```

**说明**

按题意模拟计算得到。
