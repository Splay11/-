# 题目内容
有 $n$ 个能量槽，初始能量均为 `0`。每次操作选定两个不同下标 $i,j$，把这两个槽的能量同时增加同一个正整数 $m$。

给定目标数组 $b_1,b_2,\ldots,b_n$，问有多少个正整数 $m$，使得经过若干次上述操作后，各槽能量恰好等于 $b$。

测试组数不超过 $10^3$，单组长度 $n$ 满足 $2 \le n \le 2\times 10^5$，且所有测试中 $n$ 之和不超过 $2\times 10^5$；$b_i$ 为正整数且不超过 $10^9$。

# 输入描述
每个测试文件包含多组数据。第一行包含一个整数 $T$，表示数据组数，满足 $1 \le T \le 10^3$。
每组数据第一行包含一个整数 $n$（$2 \le n \le 2\times 10^5$）。
第二行包含 $n$ 个正整数 $b_1,b_2,\ldots,b_n$（$1 \le b_i \le 10^9$）。
保证单个文件中所有 $n$ 之和不超过 $2\times 10^5$。

# 输出描述
对每组数据输出一行一个整数，表示可行正整数 $m$ 的个数。

## 样例1

**输入**

```
2
3
2 4 6
2
3 5
```

**输出**

```
2
0
```

**说明**

第一组：总和 $S=`12`$ 为偶数，且 $2\cdot\max b_i=`12`\le S$。可行 $m$ 为 $\gcd(2,4,6,S/2)=`2`$ 的正因子 `1` 与 `2`，共 `2` 个。
第二组：$2\cdot `5`=`10`>`8`，不存在成对加 $m$ 的方案，答案为 `0`。

## 样例2

**输入**

```
1
2
1 1
```

**输出**

```
1
```

**说明**

两个槽目标均为 `1`。只能取 $m=`1`$ 并操作一次，答案为 `1`。

## 样例3

**输入**

```
1
3
1 1 1
```

**输出**

```
0
```

**说明**

总和为奇数，每次操作使总和增加 $2m$（偶数），无法达到目标，答案为 `0`。

## 样例4

**输入**

```
1
4
1 1 1 1
```

**输出**

```
1
```

**说明**

$S=`4`$ 为偶数，$2\cdot\max=`2`\le `4$。$d=\gcd(1,2)=`1`$ 只有一个正因子，答案为 `1`（即 $m=`1$）。
