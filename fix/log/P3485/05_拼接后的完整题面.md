# 题目内容
若一个正整数的十进制表示中，从左向右每一位数字都不小于其左侧的数字（即数字单调不减），则称其为“平稳数”。例如 $123$、$5$、$112$ 都是平稳数，而 $321$、$10$ 不是。

现在给定一个上限 $N$ 和 $Q$ 个独立的查询。每个查询给定一个正整数 $k$，请你统计在不超过 $N$ 的所有平稳数中，各位数字之和恰好是 $k$ 的倍数的数的个数。

约束：
- $N$ 不超过 $10^{18}$；
- 查询次数 $Q$ 不超过 $500$；
- 每个查询的模数 $k$ 不超过 $200$。

# 输入描述
第一行包含两个整数 $N$ 和 $Q$，分别表示数值上限和查询次数。
接下来 $Q$ 行，每行包含一个整数 $k$，表示一次查询的模数。

# 输出描述
输出共 $Q$ 行，第 $i$ 行输出一个整数，表示对于第 $i$ 个查询，不超过 $N$ 的平稳数中各位数字之和能被 $k$ 整除的个数。

## 样例1

**输入**

```
20 2
2
3
```

**输出**

```
9
6
```

**说明**

不超过 $20$ 的平稳数共有 $18$ 个：$1,2,\dots,9$ 以及 $11,12,\dots,19$。它们的各位数字之和分别为 $1$ 到 $9$ 和 $2$ 到 $10$。
对于 $k=2$，数字之和为偶数的有 $2,4,6,8$ 以及 $11,13,15,17,19$（和分别为 $2,4,6,8,10$），共 `9` 个。
对于 $k=3$，数字之和为 $3$ 的倍数的有 $3,6,9$ 以及 $12,15,18$（和分别为 $3,6,9$），共 `6` 个。

## 样例2

**输入**

```
100 1
9
```

**输出**

```
10
```

**说明**

不超过 $100$ 的平稳数包括：$1$ 到 $9$，$11$ 到 $19$，$22$ 到 $29$，……，$99$。其中各位数字之和是 $9$ 的倍数的有：$9$（和为 $9$），$18$（和为 $9$），$27$（和为 $9$），$36$（和为 $9$），$45$（和为 $9$），$54$（和为 $9$），$63$（和为 $9$），$72$（和为 $9$），$81$（和为 $9$），$99$（和为 $18$），共 `10` 个。

## 样例3

**输入**

```
1 1
100
```

**输出**

```
0
```

**说明**

不超过 $1$ 的平稳数只有 $1$，其数字之和为 $1$，不能被 $100$ 整除，故答案为 `0`。
