# 题目内容
需要把正整数 $N$ 印成一个倒叠铭牌：第 $1$ 行把 $N$ 的十进制写法连续重复 $N$ 次，第 $2$ 行重复 $N-1$ 次，依此类推，最后一行只印一次。每一行内部没有分隔符。

$N$ 是不超过 `100` 的正整数。

# 输入描述
第一行一个正整数 $N$（$1 \le N \le 100$）。

# 输出描述
输出倒叠铭牌，共 $N$ 行，第 $i$ 行将 $N$ 的十进制写法连续重复 $N-i+1$ 次。

## 样例1

**输入**

```
1
```

**输出**

```
1
```

**说明**

$N=1$ 时铭牌只有一行，内容就是 `1`。这是规模最小的边界情形。

## 样例2

**输入**

```
2
```

**输出**

```
22
2
```
