## 解题思路

按行从多到少打印即可。外层循环让重复次数 $i$ 从 $N$ 递减到 $1$，内层把 $N$ 的十进制字符串连续拼接 $i$ 次后输出一行。

当 $N\ge 10$ 时，$N$ 本身占两位或三位，一行里是把完整写法重复 $i$ 次，而不是只重复个位。

## 复杂度分析

第 $i$ 行输出长度为 $O(i\cdot |N|)$，其中 $|N|$ 为 $N$ 的十进制位数。总输出规模为 $O(N^2\cdot |N|)$。

- 时间复杂度：$O(N^2)$。
- 空间复杂度：$O(N)$。

## 代码实现

### Python

```python
n = int(input())

for i in range(n, 0, -1):
    print(str(n) * i)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int i = n;
        while (i >= 1) {
            String str = String.valueOf(n);
            System.out.println(str.repeat(i));
            i--;
        }
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;

void printNumber(int x){
    if(x>=10) printNumber(x/10);
    printf("%c",'0'+x%10);
}

int main() {
    scanf("%d",&n);
    for(int i=n;i>0;--i){
        for(int j=1;j<=i;++j){
            printNumber(n);
        }
        printf("\n");
    }
    return 0;
}
```
