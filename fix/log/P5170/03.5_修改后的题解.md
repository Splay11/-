## 解题思路

本题与「闸机走廊」描述的计算任务一致。按输入格式读入数据后，沿用原题解的算法即可。

1. 核心思路

按照传送门的顺序模拟 Tk 到达和通过每个传送门的时间。

设 Tk 到达第 $i$ 个传送门前的时刻为 $t$，该传送门的完整周期长度为：

$$
p_i=a_i+b_i
$$

由于所有传送门都从时刻 $0$ 开始开启，因此当前时刻在本周期中的位置为：

$$
r=t\bmod p_i
$$

传送门在每个周期的前 $a_i$ 秒开启，因此：

* 当 $r<a_i$ 时，传送门处于开启状态，Tk 可以立即通过；
* 当 $r\geq a_i$ 时，传送门处于关闭状态，需要等待 $p_i-r$ 秒，才能到达下一个周期的开启时刻。

无论是否需要等待，通过传送门本身都需要 $1$ 秒。

因此时间更新方式为：

$$
t=
\begin{cases}
t+1, & r<a_i \
t+(p_i-r)+1, & r\geq a_i
\end{cases}
$$

题目只要求判断 Tk 开始通过传送门时，传送门是否开启，不要求传送门在通过的整个 $1$ 秒内持续开启。

2. 实现方法

使用变量 $t$ 表示 Tk 当前到达传送门前的最早时刻，初始时 $t=0$。

依次处理每个传送门：

1. 计算周期长度 $p=a_i+b_i$；
2. 计算当前周期位置 $r=t\bmod p$；
3. 如果 $r\geq a_i$，说明传送门关闭，将 $t$ 增加 $p-r$，等待到下一次开启；
4. 将 $t$ 增加 $1$，表示通过当前传送门所需的时间。

处理完所有传送门后，$t$ 就是 Tk 到达终点的最早时刻。

由于每个传送门的等待时间最多为 $b_i$，最终答案最大约为：

$$
\sum_{i=1}^{n}(b_i+1)
$$

其数量级可能达到 $10^{15}$，因此 Java 和 C++ 必须使用 $64$ 位整数。

## 复杂度分析

设一组测试数据包含 $n$ 个传送门。

* 时间复杂度：$O(n)$，每个传送门只处理一次。
* 空间复杂度：$O(n)$，代码中保存了当前测试数据的所有传送门。

设整个输入中所有测试数据的传送门数量之和为 $N$，则总时间复杂度为 $O(N)$。题目保证 $N\leq 10^6$，可以满足要求。

## 代码实现

### Python

```python
import sys
from io import StringIO


def get_time(doors):
    # t 表示到达当前传送门前的最早时刻
    t = 0

    for a, b in doors:
        # 当前传送门的完整开关周期
        p = a + b

        # r 表示当前时刻在本周期中的位置
        r = t % p

        # r >= a 时，当前处于关闭阶段
        if r >= a:
            # 等待到下一个周期开始，即下一次开启
            t += p - r

        # 通过当前传送门需要 1 秒
        t += 1

    return t


def main():
    input = sys.stdin.buffer.readline
    out = StringIO()

    T = int(input())

    for _ in range(T):
        n = int(input())
        doors = []

        for _ in range(n):
            a, b = map(int, input().split())
            doors.append((a, b))

        out.write(str(get_time(doors)))
        out.write("\n")

    sys.stdout.write(out.getvalue())


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {

    public static long getTime(long[][] doors) {
        // t 表示到达当前传送门前的最早时刻
        long t = 0;

        for (int i = 0; i < doors.length; i++) {
            long a = doors[i][0];
            long b = doors[i][1];

            // 当前传送门的完整开关周期
            long p = a + b;

            // r 表示当前时刻在本周期中的位置
            long r = t % p;

            // r >= a 时，当前处于关闭阶段
            if (r >= a) {
                // 等待到下一个周期开始，即下一次开启
                t += p - r;
            }

            // 通过当前传送门需要 1 秒
            t++;
        }

        return t;
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(
                new InputStreamReader(System.in)
        );
        StringBuilder ans = new StringBuilder();

        int T = Integer.parseInt(br.readLine().trim());

        for (int tc = 0; tc < T; tc++) {
            int n = Integer.parseInt(br.readLine().trim());
            long[][] doors = new long[n][2];

            for (int i = 0; i < n; i++) {
                StringTokenizer st = new StringTokenizer(br.readLine());
                doors[i][0] = Long.parseLong(st.nextToken());
                doors[i][1] = Long.parseLong(st.nextToken());
            }

            ans.append(getTime(doors)).append('\n');
        }

        System.out.print(ans);
    }
}
```

```cpp
#include <iostream>
#include <vector>
#include <utility>
using namespace std;

long long getTime(const vector<pair<long long, long long>>& doors) {
    // t 表示到达当前传送门前的最早时刻
    long long t = 0;

    for (int i = 0; i < (int)doors.size(); i++) {
        long long a = doors[i].first;
        long long b = doors[i].second;

        // 当前传送门的完整开关周期
        long long p = a + b;

        // r 表示当前时刻在本周期中的位置
        long long r = t % p;

        // r >= a 时，当前处于关闭阶段
        if (r >= a) {
            // 等待到下一个周期开始，即下一次开启
            t += p - r;
        }

        // 通过当前传送门需要 1 秒
        t++;
    }

    return t;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    while (T--) {
        int n;
        cin >> n;

        vector<pair<long long, long long>> doors(n);

        for (int i = 0; i < n; i++) {
            cin >> doors[i].first >> doors[i].second;
        }

        cout << getTime(doors) << '\n';
    }

    return 0;
}
```
