# 题目内容
产业园里有 $n$ 个站点，用 $n-1$ 条双向链路连成一棵树，站点编号为 `1` 到 $n$。站点 $i$ 的信号强度为 $a_i$。一条简单路径的耦合度定义为路径上所有站点信号强度的最大公因数 $\gcd$；若路径只含一个站点，则耦合度就是该点强度。路径 $u \to v$ 与 $v \to u$ 视为同一条，单点路径 $u \to u$ 也要计入。请统计耦合度为偶数的简单路径条数。

约束：$1 \le n \le 200000$，$1 \le a_i \le 1000000$。

# 输入描述
第一行一个整数 $n$，表示站点数。
第二行 $n$ 个整数 $a_1,a_2,\ldots,a_n$，表示信号强度。
接下来 $n-1$ 行，每行两个整数 $u$、$v$，表示一条双向链路。
保证 $1 \le n \le 200000$，$1 \le a_i \le 1000000$，$1 \le u,v \le n$ 且 $u 
e v$，输入构成一棵树。

# 输出描述
输出一个整数，表示耦合度为偶数的简单路径条数。

## 样例1

**输入**

```
3
2 4 6
1 2
2 3
```

**输出**

```
6
```

**说明**

三个点权都是偶数，整棵树构成一个偶数连通块，大小 $k=`3`。简单路径数为 $\dfrac{k(k+1)}{2}=`6`$（三条边路径加上三个单点）。

## 样例2

**输入**

```
1
7
```

**输出**

```
0
```

**说明**

只有一个奇权结点。单点路径的权值是 `7`（奇数），因此偶权路径数为 `0`。

## 样例3

**输入**

```
5
8 1 4 9 6
1 2
2 3
3 4
4 5
```

**输出**

```
3
```

**说明**

偶权结点为 `1`、`3`、`5`，两两被奇权结点隔开，形成三个大小为 `1` 的连通块。每个连通块贡献 `1` 条单点路径，答案为 `3`。
