# 题目内容
给定一张 $n$ 个点、$m$ 条边的无向带权图。每删除一条边可以获得该边的边权。目标是删除若干条边后，图中**恰好**剩下 `2` 个连通块，并使获得的边权之和最大。

若初始连通块数量已经不少于 `3`，则无法通过删边使连通块恰好为 `2`（删边只会增加连通块数量），此时输出 `-1`。

约束条件：
- 点数 $n$ 满足 $2 \le n \le 10^5$；
- 边数 $m$ 满足 $0 \le m \le 10^5$；
- 每条边的端点满足 $1 \le u, v \le n$，边权满足 $1 \le w \le 10^9$。

# 输入描述
第一行包含两个整数 $n$ 和 $m$（$2 \le n \le 10^5$，$0 \le m \le 10^5$），分别表示点数和边数。
接下来 $m$ 行，每行三个正整数 $u, v, w$（$1 \le u, v \le n$，$1 \le w \le 10^9$），表示点 $u$ 与点 $v$ 之间有一条边权为 $w$ 的无向边。

# 输出描述
若初始连通块数量不少于 `3`，输出 `-1`；否则输出一个整数，表示能够获得的最大边权之和。

## 样例1

**输入**

```
3 3
1 2 4
2 3 3
1 3 2
```

**输出**

```
7
```

**说明**

图初始连通。最小生成树边权为 `2` 和 `3`，树上最大边为 `3`。总边权 `9`，答案为 $9-2-3+3=7$，即删除边权 `4` 与 `3` 的两条边，留下边权 `2` 的边，恰好两块。

## 样例2

**输入**

```
4 2
1 2 4
3 4 3
```

**输出**

```
0
```

**说明**

初始已有两个连通块，再删任何边都会变成至少三块，因此不能删边，最大收益为 `0`。

## 样例3

**输入**

```
3 0
```

**输出**

```
-1
```

**说明**

三个孤立点，初始连通块数为 `3`，无法变成恰好两块，输出 `-1`。
