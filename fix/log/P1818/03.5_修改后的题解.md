## 解题思路

删边只会让连通块变多或不变，因此：

- 初始连通块 $\ge 3$：不可能变成恰好 `2` 块，答案 `-1`；
- 初始恰好 `2` 块：不能再删掉连接同一连通块内部、会破坏连通性的桥接生成树边，只能删掉各连通块内部的非树边。最大收益等于总边权减去两个连通块各自最小生成树的边权和；
- 初始 `1` 块：先求整张图的最小生成树，再额外删掉树上的一条边把树拆成两块。为了收益最大，应删树上权最大的那条边。即答案 = 总边权 − MST 边权和 + MST 最大边权。

用 Kruskal 一次完成：按边权升序加边，能连通则加入 MST（从总边权中减去该边，并记录 MST 最大边），同时统计最终连通块数。

## 复杂度分析

时间复杂度 $O(m \log m)$，空间复杂度 $O(n+m)$。

## 代码实现

### Python

```python
import sys
sys.setrecursionlimit(1 << 25)

n, m = map(int, input().split())

def find(p, x):
    if p[x] != x:
        p[x] = find(p, p[x])
    return p[x]

p = list(range(n + 1))
total = 0
cnt = n
roads = []
max_W = 0
for _ in range(m):
    u, v, w = map(int, input().split())
    total += w
    roads.append((u, v, w))

roads.sort(key=lambda x: x[2])
for r in roads:
    u, v, w = r
    u = find(p, u)
    v = find(p, v)
    if u != v:
        p[u] = v
        cnt -= 1
        total -= w
        max_W = max(max_W, w)

if cnt > 2:
    print(-1)
elif cnt == 2:
    print(total)
else:
    print(total + max_W)
```

### Java

```java
import java.util.*;

public class Main {
    static int find(int[] parent, int x) {
        if (parent[x] != x) parent[x] = find(parent, parent[x]);
        return parent[x];
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        long total = 0;
        List<int[]> edges = new ArrayList<>();
        for (int i = 0; i < m; i++) {
            int a = sc.nextInt(), b = sc.nextInt(), c = sc.nextInt();
            edges.add(new int[]{a, b, c});
            total += c;
        }
        int[] parent = new int[n + 1];
        for (int i = 1; i <= n; i++) parent[i] = i;
        edges.sort(Comparator.comparingInt(e -> e[2]));
        int components = n;
        long maxEdge = 0;
        for (int[] e : edges) {
            int ra = find(parent, e[0]), rb = find(parent, e[1]);
            if (ra != rb) {
                parent[ra] = rb;
                total -= e[2];
                components--;
                maxEdge = Math.max(maxEdge, e[2]);
            }
        }
        if (components == 1) System.out.println(total + maxEdge);
        else if (components == 2) System.out.println(total);
        else System.out.println(-1);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n, m;
    cin >> n >> m;
    int su = 0;
    vector<array<int, 3>> v;
    for (int i = 0; i < m; i++) {
        int a, b, c;
        cin >> a >> b >> c;
        v.push_back({a, b, c});
        su += c;
    }
    vector<int> p(n + 1);
    iota(p.begin(), p.end(), 0);
    function<int(int)> find = [&](int x) -> int {
        return p[x] ^ x ? p[x] = find(p[x]) : x;
    };
    sort(v.begin(), v.end(), [&](array<int, 3>& a, array<int, 3>& b) {
        return a[2] < b[2];
    });
    int cnt = n;
    int maxv = 0;
    for (auto& t : v) {
        int a = find(t[0]), b = find(t[1]), c = t[2];
        if (a ^ b) {
            p[a] = b;
            su -= c;
            cnt--;
            maxv = max(maxv, c);
        }
    }
    if (cnt == 1) cout << su + maxv << "\n";
    else if (cnt == 2) cout << su << "\n";
    else cout << -1 << "\n";
    return 0;
}
```
