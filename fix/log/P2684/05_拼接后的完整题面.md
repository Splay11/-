# 题目内容
平面设计师拿到一段只含小写字母的文案 $s$，要把它排成阶梯海报：第 `1` 行写下接下来的 `1` 个字符，第 `2` 行写下接下来的 `2` 个字符，……，第 $i$ 行写下接下来的 $i$ 个字符。若某一行需要的字符数多于剩余字符，就把剩余字符全部写完后停止。客户只要每行第一个字符按行从上到下连接得到的缩写。

约束：$1 \le |s| \le 100000$。

# 输入描述
输入一行一个只含小写字母的字符串 $s$，长度满足 $1 \le |s| \le 100000$。

# 输出描述
输出一行一个字符串，表示每一行首字符依次连接得到的缩写。

## 样例1

**输入**

```
abcde
```

**输出**

```
abd
```

**说明**

按行书写：

- 第 `1` 行：`a`，行首 `a`；
- 第 `2` 行：`bc`，行首 `b`；
- 剩余 `de` 不足 `3` 个，写成第 `3` 行，行首 `d`。

连接得 `abd`。

## 样例2

**输入**

```
codefun
```

**输出**

```
coen
```

**说明**

分组为 `c` | `od` | `efu` | 剩余 `n`。各行首字母依次为 `c`、`o`、`e`、`n`，答案为 `coen`。

## 样例3

**输入**

```
a
```

**输出**

```
a
```

**说明**

只有 `1` 个字符，恰好写成第 `1` 行，答案就是 `a`。

## 样例4

**输入**

```
qwertyuiop
```

**输出**

```
qwru
```

**说明**

分组为 `q` | `we` | `rty` | `uiop`。行首依次为 `q`、`w`、`r`、`u`，答案为 `qwru`。
