## 解题思路

用下标 $\mathrm{idx}$ 指向当前尚未排入海报的第一个字符，行宽 $\mathrm{line}$ 从 $1$ 开始递增。每一轮：

- 若剩余字符不少于 $\mathrm{line}$ 个，则本行完整，取 $s[\mathrm{idx}]$ 作为行首，然后 $\mathrm{idx}$ 增加 $\mathrm{line}$，$\mathrm{line}$ 加一；
- 否则把剩余部分排成最后一行，取剩余部分的首字符后结束。

最后把收集到的行首字符拼接成缩写输出。

## 复杂度分析

时间复杂度 $O(|s|)$，空间复杂度 $O(|s|)$（用于存放答案）。

## 代码实现

### Python

```python
s = input().strip()

ans = []
idx = 0
line = 1

while idx < len(s):
    if len(s) - idx >= line:
        ans.append(s[idx])
        idx += line
    else:
        ans.append(s[idx])
        break
    line += 1

print("".join(ans))
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.next();

        int n = s.length();
        StringBuilder ans = new StringBuilder();
        int idx = 0;
        int line = 1;

        while (idx < n) {
            if (n - idx >= line) {
                ans.append(s.charAt(idx));
                idx += line;
            } else {
                ans.append(s.charAt(idx));
                break;
            }
            line++;
        }

        System.out.println(ans.toString());
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;

    int n = s.size();
    string ans = "";
    int idx = 0;
    int line = 1;

    while (idx < n) {
        if (n - idx >= line) {
            ans.push_back(s[idx]);
            idx += line;
        } else {
            ans.push_back(s[idx]);
            break;
        }
        line++;
    }

    cout << ans << endl;
    return 0;
}
```
