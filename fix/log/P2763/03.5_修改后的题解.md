## 解题思路

题目要求修改初始状态序列 $a$ 中最少的工位，使得修改后的序列满足关系序列 $b$ 的所有相邻约束。由于每个工位只有 $0$ 或 $1$ 两种状态，并且约束只涉及相邻两个工位的关系，可以采用动态规划求解。

- **状态定义**  
  令 $dp[i][0]$ 表示考虑前 $i$ 个工位，且第 $i$ 个工位的状态最终为 $0$ 时，所需的最少操作次数。  
  令 $dp[i][1]$ 表示考虑前 $i$ 个工位，且第 $i$ 个工位的状态最终为 $1$ 时，所需的最少操作次数。

- **初始化**（第 $1$ 个工位）  
  没有任何前置约束，直接将初始状态 $a_1$ 变为目标状态即可：
  $$dp[1][0] = (a_1 == 0 \; ? \; 0 : 1)$$
  $$dp[1][1] = (a_1 == 1 \; ? \; 0 : 1)$$

- **状态转移**（$i$ 从 $2$ 到 $n$）  
  对于当前工位 $i$ 和目标状态 $b \in \{0,1\}$，首先计算将 $a_i$ 修改为 $b$ 的代价：
  $$cost = (a_i == b \; ? \; 0 : 1)$$
  然后根据 $b_{i-1}$ 的要求进行转移：
  - 若 $b_{i-1}=0$，要求 $a_{i-1}$ 与 $a_i$ **相同**，则 $a_{i-1}$ 也必须是 $b$：
    $$dp[i][b] = dp[i-1][b] + cost$$
  - 若 $b_{i-1}=1$，要求 $a_{i-1}$ 与 $a_i$ **不同**，则 $a_{i-1}$ 必须是 $1-b$：
    $$dp[i][b] = dp[i-1][1-b] + cost$$

- **最终答案**  
  完成所有 $n$ 个工位的决策后，最后一位为 $0$ 或 $1$ 的最小值即为答案：
  $$answer = \min(dp[n][0], \; dp[n][1])$$

该算法只需扫描一次序列，每次转移仅涉及常数次计算，因此非常高效。

## 复杂度分析

- **时间复杂度**：对于每组数据，需要遍历长度为 $n$ 的状态序列一次，每次进行常数次状态转移，时间复杂度为 $O(n)$。所有测试用例的 $n$ 总和不超过 $10^6$，因此总复杂度为 $O(\sum n) = O(10^6)$，可以在时限内轻松运行。
- **空间复杂度**：若保留完整的 DP 表格，空间复杂度为 $O(n)$（每组数据）。通过观察状态转移只依赖前一位，可以使用滚动变量将空间优化至 $O(1)$。本题解给出的代码为便于理解保留了 $O(n)$ 的 DP 数组，实际应用中可根据需要自行优化。

## 代码实现

### Python

```python
import sys
input = sys.stdin.readline

T = int(input())
for _ in range(T):
    n = int(input().strip())
    a = input().strip()
    b = input().strip()
    
    # dp[i][0] 表示前 i 个工位，且第 i 个状态为 '0' 时的最小修改次数
    # dp[i][1] 表示前 i 个工位，且第 i 个状态为 '1' 时的最小修改次数
    INF = 10**9
    dp = [[INF, INF] for _ in range(n + 1)]
    
    # 初始化第 1 个工位
    dp[1][0] = 0 if a[0] == '0' else 1
    dp[1][1] = 0 if a[0] == '1' else 1
    
    for i in range(2, n + 1):
        for target in range(2):
            # 将 a[i-1] 修改为目标字符的代价
            cost = 0 if a[i - 1] == str(target) else 1
            if b[i - 2] == '0':       # 要求相邻相同
                dp[i][target] = dp[i - 1][target] + cost
            else:                     # 要求相邻不同
                dp[i][target] = dp[i - 1][1 - target] + cost
                
    ans = min(dp[n][0], dp[n][1])
    sys.stdout.write(str(ans) + "\n")
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader in = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(in.readLine());
        while (T-- > 0) {
            int n = Integer.parseInt(in.readLine());
            String a = in.readLine();
            String b = in.readLine();
            
            // dp[i][0] 前 i 个工位，第 i 个状态为 '0' 的最小修改次数
            // dp[i][1] 前 i 个工位，第 i 个状态为 '1' 的最小修改次数
            int[][] dp = new int[n + 1][2];
            int INF = 1000000000;
            for (int i = 0; i <= n; i++) {
                dp[i][0] = INF;
                dp[i][1] = INF;
            }
            
            // 初始化第 1 个工位
            dp[1][0] = (a.charAt(0) == '0' ? 0 : 1);
            dp[1][1] = (a.charAt(0) == '1' ? 0 : 1);
            
            for (int i = 2; i <= n; i++) {
                for (int target = 0; target < 2; target++) {
                    // 将 a[i-1] 修改为字符 (target + '0') 的代价
                    int cost = (a.charAt(i - 1) == (char)(target + '0') ? 0 : 1);
                    if (b.charAt(i - 2) == '0') {   // 要求相邻相同
                        dp[i][target] = dp[i - 1][target] + cost;
                    } else {                        // 要求相邻不同
                        dp[i][target] = dp[i - 1][1 - target] + cost;
                    }
                }
            }
            
            int ans = Math.min(dp[n][0], dp[n][1]);
            System.out.println(ans);
        }
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
#include <algorithm>
#include <vector>
using namespace std;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while(T--){
        int n;
        cin >> n;
        string a, b;
        cin >> a >> b;
        // dp[i][0] 表示前 i 个工位，且第 i 个状态为 '0' 的最小修改次数
        // dp[i][1] 表示前 i 个工位，且第 i 个状态为 '1' 的最小修改次数
        vector<vector<int>> dp(n + 1, vector<int>(2, 1000000000));
        // 初始化第 1 个工位
        dp[1][0] = (a[0] == '0' ? 0 : 1);
        dp[1][1] = (a[0] == '1' ? 0 : 1);
        for(int i = 2; i <= n; i++){
            for(int target = 0; target < 2; target++){
                // 将 a[i-1] 修改为字符 '0'+target 的代价
                int cost = (a[i-1] - '0' == target ? 0 : 1);
                if(b[i-2] == '0'){          // 要求相邻相同
                    dp[i][target] = dp[i-1][target] + cost;
                } else {                    // 要求相邻不同
                    dp[i][target] = dp[i-1][1-target] + cost;
                }
            }
        }
        int ans = min(dp[n][0], dp[n][1]);
        cout << ans << "\n";
    }
    return 0;
}
```
