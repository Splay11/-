# 题目内容
在某个自动化流水线上，工件依次经过 $n$ 个检测工位，每个工位会记录一个二进制状态（$0$ 或 $1$），形成长度为 $n$ 的状态序列 $a$。质量规范给出一个长度为 $n-1$ 的关系序列 $b$，其中 $b_i=1$ 要求相邻工位状态不同，即 $a_i 
eq a_{i+1}$；$b_i=0$ 要求相邻工位状态相同，即 $a_i = a_{i+1}$。初始序列 $a$ 可能不满足规范，每次操作可以选择一个工位并翻转其状态（$0$ 变为 $1$，$1$ 变为 $0$）。问最少执行多少次操作，才能使所有相邻关系都得到满足。

约束：测试用例的数量 $T$ 满足 $1 \le T \le 100$。对于每组数据，状态序列长度 $n$ 满足 $2 \le n \le 10^6$，且单个输入文件内所有 $n$ 的总和不超过 $10^6$。

# 输入描述
第一行输入一个整数 $T$，表示测试数据组数。接下来每组数据包含三行：第一行一个整数 $n$，表示序列长度；第二行一个长度为 $n$ 的字符串，由字符 `0` 和 `1` 组成，表示初始状态序列 $a$；第三行一个长度为 $n-1$ 的字符串，由字符 `0` 和 `1` 组成，表示关系序列 $b$。

# 输出描述
对于每组数据，输出一行一个整数，表示最少需要调整的工位数量。

## 样例1

**输入**

```
1
3
010
01
```

**输出**

```
1
```

**说明**

序列长度 $n=3$，初始 $a$ 为 `010`，约束 $b$ 为 `01`。$b_1=0$ 要求 $a_1 = a_2$，但初始 $a_1=0, a_2=1$ 不等；$b_2=1$ 要求 $a_2 
eq a_3$，初始 $a_2=1, a_3=0$ 满足。要使所有约束成立，最终序列可以是 `001` 或 `110`。从 `010` 变为 `001` 只需翻转第 `2` 位（`1` 变 `0`），操作 `1` 次；变为 `110` 需翻转第 `1` 和第 `3` 位，操作 `2` 次。故最少操作次数为 `1`。

## 样例2

**输入**

```
1
2
01
0
```

**输出**

```
1
```

**说明**

$n=2$，$a$ 为 `01`，$b$ 为 `0`。$b_1=0$ 要求 $a_1 = a_2$，初始不相等。只需翻转任意一位即可使它们相同，最少操作 `1` 次。

## 样例3

**输入**

```
1
4
0000
111
```

**输出**

```
2
```

**说明**

$n=4$，$a$ 为 `0000`，$b$ 为 `111`，所有 $b_i=1$ 要求相邻位均不同（$a_1 
eq a_2$，$a_2 
eq a_3$，$a_3 
eq a_4$）。满足条件的序列只有 `0101` 和 `1010`。从全 `0` 变为 `0101` 需将第 `2` 位和第 `4` 位翻转为 `1`，共 `2` 次；变为 `1010` 需翻转第 `1` 位和第 `3` 位，也是 `2` 次。因此最少操作次数为 `2`。
