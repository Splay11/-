# 题目内容
实验室里有 $n$ 份依次编号的检测样本，第 $i$ 份的读数为 $a_i$。从这些样本中删除任意份（可以不删，也可以全删），并保持剩余样本的相对顺序，得到一个子序列。

定义长度为 $m$ 的子序列 $b$ 的峰值为 $f(b)=\max(b_1,b_2,\ldots,b_m)$。对于每一个 $k=1,2,\ldots,n$，求所有长度为 $k$ 的子序列的峰值之和。答案可能很大，请对 $998244353$ 取模后输出。

约束：样本份数不超过 `5000`，每份读数为不超过 `10^9` 的正整数。

# 输入描述
第一行一个正整数 $n$，表示样本份数。
第二行 $n$ 个正整数 $a_1,a_2,\ldots,a_n$，表示各份读数。
保证 $1 \le n \le 5 \times 10^3$，$1 \le a_i \le 10^9$。

# 输出描述
输出一行 $n$ 个整数，第 $k$ 个整数表示所有长度为 $k$ 的子序列峰值之和对 $998244353$ 取模后的结果。

## 样例1

**输入**

```
1
10
```

**输出**

```
10
```

**说明**

只有一份样本，读数为 `10`。
唯一的长度为 `1` 的子序列峰值就是 `10`。这是 $n=1$ 的边界情形。

## 样例2

**输入**

```
3
2 2 2
```

**输出**

```
6 6 2
```

**说明**

三份读数全为 `2`。
任意非空子序列的峰值都是 `2`。
长度为 `1`、`2`、`3` 的子序列个数分别为 `3`、`3`、`1`，因此答案为 $6\ 6\ 2$。

## 样例3

**输入**

```
1
11
```

**输出**

```
11
```

**说明**

按题意模拟计算得到。
