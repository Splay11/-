# 题目内容
一条产线按顺序处理长度为 $n$ 的整数序列 $a$。调度要把整条产线从某个相邻位置切开，左边前缀交给班组 $b$，右边后缀交给班组 $c$，两段都必须非空。班组 $b$ 的绩效 $f$ 定义为其所负责元素之和，班组 $c$ 的状态码 $g$ 定义为其所负责元素的按位或。财务要对账，希望 $|f(b) - g(c)|$ 尽可能小。

请枚举所有合法切点，输出该绝对值的最小值。

约束：测试组数 $T$ 满足 $1 \le T \le 10^2$，$2 \le n \le 200000$，所有测试中 $n$ 的总和不超过 `2000000`，$0 \le a_i \le 1000000000$。

# 输入描述
第一行一个正整数 $T$，表示测试组数。
每组数据两行：第一行一个正整数 $n$，第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$。
保证 $1 \le T \le 10^2$，$2 \le n \le 200000$，所有测试中 $n$ 的总和不超过 `2000000`，$0 \le a_i \le 1000000000$。

# 输出描述
对每组数据输出一行一个整数，表示 $|f(b) - g(c)|$ 的最小值。

## 样例1

**输入**

```
2
4
8 1 2 4
3
0 0 7
```

**输出**

```
1
7
```

**说明**

第一组在第一个元素后切开：$f(b)=`8`$，$g(c)=1|2|4=`7`$，绝对值为 `1`，已是最小。
第二组无论在何处切，$g(c)$ 都含 `7` 而前缀和为 `0`，答案为 `7`。

## 样例2

**输入**

```
1
6
16 8 4 2 1 0
```

**输出**

```
1
```

**说明**

在第一个元素后切开：$f(b)=`16`$，$g(c)=8|4|2|1|0=`15`$，绝对值为 `1`。其余切点差值更大。
