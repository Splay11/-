# 题目内容
你有 $n$ 个任务，每个任务有一个难度值 $a_i$。你可以在分配前对任务进行任意重新排序。

你需要将所有任务分配给若干名工人，每个工人至少承担 $1$ 个任务，至多承担 $K$ 个任务。对于某名承担了 $t$ 个任务的工人，记他所承担的任务中难度最大值为 $M$，最小值为 $m$，则须满足

$$M - m \le D + E 	imes (t-1)$$

每个任务必须且只能分配给一名工人。

你的目标是使用尽可能少的工人，请求出最少需要的工人数量。

所有测试数据中，$n$ 的总和不超过 $2 	imes 10^5$。$D, E$ 的取值范围为 $0$ 到 $10^9$。$K$ 的取值范围为 $1$ 到 $n$。难度值均为非负整数且不超过 $10^9$。

# 输入描述
第一行包含一个整数 $T$ ($1 \le T \le 10^5$)，表示测试数据组数。
每组测试数据格式如下：
第一行包含四个整数 $n$, $D$, $E$, $K$ ($1 \le n \le 2 	imes 10^5$, $0 \le D, E \le 10^9$, $1 \le K \le n$)，含义如题目描述。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$ ($0 \le a_i \le 10^9$)，表示每个任务的难度值。

# 输出描述
对于每组测试数据，输出一行一个整数，表示最少需要的工人数量。

## 样例1

**输入**

```
1
3 0 0 2
1 2 2
```

**输出**

```
2
```

**说明**

对于这组数据，$n = 3$，$D = 0$，$E = 0$，$K = 2$。 约束条件为 $M - m \le 0$，即同一名工人承担的所有任务难度必须完全相同。 将难度值排序后为 `1, 2, 2`。 工人 `1` 只能承担难度为 `1` 的任务，共 `1` 个任务；工人 `2` 可以承担难度为 `2` 的两个任务，共 `2` 个任务（不超过 $K = 2$）。 因此最少需要 `2` 名工人。

## 样例2

**输入**

```
1
5 2 0 3
1 3 5 7 9
```

**输出**

```
3
```

**说明**

本组数据中 $n = 5$，$D = 2$，$E = 0$，$K = 3$。 此时约束变为 $M - m \le 2$，即每个工人的任务难度极差不能超过 `2`，且每人最多承担 `3` 个任务。 排序后的难度为 `1, 3, 5, 7, 9`。 一种最优划分方案为：$[1, 3]$（极差 `2`，长度 `2`），$[5, 7]$（极差 `2`，长度 `2`），$[9]$（极差 `0`，长度 `1`）。 无法用少于 `3` 名工人完成任务（例如 $[1, 3, 5]$ 极差为 `4` 不满足条件）。 因此答案为 `3`。

## 样例3

**输入**

```
1
4 1 2 4
1 4 7 10
```

**输出**

```
2
```

**说明**

这里 $n = 4$，$D = 1$，$E = 2$，$K = 4$。 对于承担 $t$ 个任务的工人，允许的难度极差为 $D + E 	imes (t-1) = 1 + 2 	imes (t-1)$。 排序后难度为 `1, 4, 7, 10`。 若将全部 `4` 个任务分给同一工人，$t = 4$，允许极差为 $1 + 2 	imes 3 = 7$，但实际极差 $10 - 1 = 9 > 7$，不可行。 若分为两段 $[1, 4]$ 和 $[7, 10]$：第一段 $t = 2$，允许极差 $1 + 2 	imes 1 = 3$，实际极差 $4 - 1 = 3 \le 3$，可行；第二段同样满足。 因此最少需要 `2` 名工人。

## 样例4

**输入**

```
1
1 0 0 1
42
```

**输出**

```
1
```

**说明**

本组为边界情况：$n = 1$，$D = 0$，$E = 0$，$K = 1$。 唯一任务的难度为 `42`。 显然只需要 `1` 名工人承担该任务，且满足所有约束。 答案为 `1`。
