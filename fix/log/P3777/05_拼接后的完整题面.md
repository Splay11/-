# 题目内容
港口仓库沿一条直线排列了 $n$ 个集装箱，从左到右依次编号为 `1` 到 $n$。第 $i$ 个集装箱装载的货物品类用正整数 $a_i$ 表示。

调度员给出 $m$ 个起始货位 $b_1, b_2, \ldots, b_m$（满足 $1 \le b_i \le n$）。对于每一个货位 $b$，需要统计从第 $b$ 个集装箱到第 $n$ 个集装箱这一段中，一共出现了多少种不同的货物品类。

请对每个询问给出答案。

约束：集装箱数量与询问个数均不超过 $10^5$，每个品类编号为正整数且不超过 $10^5$。

# 输入描述
第一行包含两个整数 $n$ 和 $m$，分别表示集装箱的个数和询问的个数。
第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$，表示各集装箱的货物品类。
接下来 $m$ 行，第 $i$ 行包含一个整数 $b_i$，表示第 $i$ 个询问的起始货位。
保证 $1 \le n, m \le 10^5$，$1 \le a_i \le 10^5$，$1 \le b_i \le n$。

# 输出描述
输出 $m$ 行，每行一个整数。第 $i$ 行表示从第 $b_i$ 个集装箱到第 $n$ 个集装箱中不同货物品类的数量。

## 样例1

**输入**

```
7 4
2 4 2 6 8 4 10
2
4
5
7
```

**输出**

```
5
4
3
1
```

**说明**

品类序列为 $2,4,2,6,8,4,10$。
从货位 `2` 到 `7` 的序列为 $4,2,6,8,4,10$，不同品类有 `5` 种。
从货位 `4` 到 `7` 为 $6,8,4,10$，不同品类有 `4` 种。
从货位 `5` 到 `7` 为 $8,4,10$，不同品类有 `3` 种。
从货位 `7` 到 `7` 仅为 $10$，不同品类有 `1` 种。

## 样例2

**输入**

```
1 1
5
1
```

**输出**

```
1
```

**说明**

只有 `1` 个集装箱，品类为 `5`。询问从货位 `1` 开始，后缀中只有这一种品类，答案为 `1`。

## 样例3

**输入**

```
5 3
1 1 1 1 1
1
3
5
```

**输出**

```
1
1
1
```

**说明**

五个集装箱的品类全部相同，任意后缀中都只有 `1` 种品类，因此三个询问的答案均为 `1`。

## 样例4

**输入**

```
4 2
3 1 3 2
1
2
```

**输出**

```
3
3
```

**说明**

品类序列为 $3,1,3,2$。
从货位 `1` 到 `4` 出现的品类集合为 $\{3,1,2\}$，共 `3` 种。
从货位 `2` 到 `4` 出现的品类集合为 $\{1,3,2\}$，同样是 `3` 种。
