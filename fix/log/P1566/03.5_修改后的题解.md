## 解题思路

本题与「最大收支偏差」描述的计算任务一致。按输入格式读入数据后，沿用原题解的算法即可。

详见下方代码实现。

## 复杂度分析

- 时间复杂度与原题解相同。
- 空间复杂度与原题解相同。

## 代码实现

### Python

```python
n = int(input())
a = list(map(int,input().split()))
b = list(map(int,input().split()))
n = len(a)
c = [0] * n
for i in range(n):
    c[i] = a[i] - b[i]
c.sort()
sum1 = 0
sum2 = 0
for i in range(n - 1, -1, -1):
    if c[i] > 0:
        sum1 += c[i]
    else: sum2 += -c[i]
print(max(sum1, sum2))
```
