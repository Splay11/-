# 题目内容
某气象站维护着一个长度为 `n` 的温度序列，编号从 `1` 到 `n`，初始时每个位置的温度已知。在持续的监测过程中，会依次发生 `q` 个事件，每个事件为以下两种之一：
1. 将第 `i` 个位置的温度更新为 `x`；
2. 查询区间 `[l, r]` 内温度数据的方差。

方差的定义如下：对于一个包含 `m` 个数的序列 $b_1, b_2, \dots, b_m$，记其平均值为 $\bar{b} = \frac{1}{m}\sum_{i=1}^{m} b_i$，则方差定义为 $Var = \frac{1}{m}\sum_{i=1}^{m} (b_i - \bar{b})^2$。

请你依次处理所有事件，对于每个查询，输出对应的方差值。

## 约束条件
- 序列长度 `n` 和事件总数 `q` 均满足 $1 \le n, q \le 10^5$。
- 初始温度值以及更新操作中的 `x` 均为整数，且绝对值不超过 $10^5$。
- 查询的区间满足 $1 \le l \le r \le n$。

# 输入描述
第一行包含两个整数 `n` 和 `q`（$1 \le n, q \le 10^5$），分别表示温度序列的长度和事件个数。
第二行包含 `n` 个整数，依次表示编号为 `1` 到 `n` 的初始温度值（绝对值不超过 $10^5$）。
接下来 `q` 行，每行对应一个事件。每行的第一个整数 `t` 表示事件类型：
- 若 `t = 1`，则其后跟随两个整数 `i` 和 `x`（$1 \le i \le n$，绝对值 $\le 10^5$），表示将第 `i` 个位置的温度修改为 `x`。
- 若 `t = 2`，则其后跟随两个整数 `l` 和 `r`（$1 \le l \le r \le n$），表示查询区间 `[l, r]` 内温度的方差。

# 输出描述
对于每个类型为 `2` 的事件，输出一行一个实数，表示该区间温度的方差。建议输出保留 `6` 位小数。当你的答案与标准答案之间的相对误差或绝对误差不超过 $10^{-6}$ 时，即被视为正确。

## 样例1

**输入**

```
3 1
1 2 3
2 1 3
```

**输出**

```
0.666667
```

**说明**

查询区间 `[1,3]` 的元素为 `1`, `2`, `3`。平均值 $\bar{b} = 2$，平方和 $\sum b_i^2 = 1^2 + 2^2 + 3^2 = 14$，元素个数 $m = 3$。根据方差公式 $Var = \frac{1}{m}\sum b_i^2 - \bar{b}^2$，计算得 $\frac{14}{3} - 4 = \frac{2}{3} \approx 0.666667$。

## 样例2

**输入**

```
5 3
5 5 5 5 5
2 1 5
1 3 10
2 1 5
```

**输出**

```
0.000000
4.000000
```

**说明**

初始所有元素均为 `5`，查询区间 `[1,5]` 时，所有数据相同，方差为 `0.000000`。随后将第 `3` 个元素更新为 `10`，此时区间元素变为 `5, 5, 10, 5, 5`。平均值 $\bar{b} = 6$，平方和 $\sum b_i^2 = 5^2+5^2+10^2+5^2+5^2 = 200$，$m = 5$。方差 $Var = \frac{200}{5} - 6^2 = 40 - 36 = 4.000000$。

## 样例3

**输入**

```
2 2
100 -100
2 1 2
1 2 100
2 1 2
```

**输出**

```
10000.000000
0.000000
```

**说明**

初始区间 `[1,2]` 包含 `100` 和 `-100`。平均值 $\bar{b} = 0$，平方和 $100^2 + (-100)^2 = 20000$，$m = 2$，方差 $\frac{20000}{2} - 0^2 = 10000.000000$。之后将位置 `2` 更新为 `100`，区间变为两个 `100`，所有元素相同，方差为 `0.000000`。该样例覆盖了绝对值较大的边界数据和单次更新后的查询。
