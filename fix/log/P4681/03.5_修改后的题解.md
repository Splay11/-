## 解题思路

我们需要判断：是否存在一个长度为 $n$ 的非负整数序列 $a_1, a_2, \dots, a_n$，满足

- $\sum_{i=1}^n a_i = m$；
- 变化点（$a_i \neq a_{i+1}$ 的位置）的数量 $\le k$；
- 波动值 $V(a) = \sum_{i=1}^{n-1} |a_{i} - a_{i+1}| \ge g$。

该问题可以转化为：在给定 $n, m, k$ 的条件下，求出 **波动值的最大可能值** $maxV$。  
如果能够构造出合法序列，且 $maxV \ge g$，则回答 `YES`，否则回答 `NO`。  
如果根本不存在满足变化点限制的序列，则 $maxV = -1$，此时只能回答 `NO`。

下面分情况讨论 $maxV$ 的计算方式。

---

### 1. 只有一个元素（$n = 1$）

序列没有相邻元素，波动值恒为 $0$。  
因此 $maxV = 0$，只有 $g = 0$ 时答案为 `YES`。

---

### 2. 不允许任何变化点（$k = 0$）

序列中所有相邻元素必须相等，即 $a_1 = a_2 = \dots = a_n$。  
此时若 $m \bmod n \neq 0$，则无法构造出合法序列，$maxV = -1$。  
若 $m \bmod n = 0$，则序列唯一（所有元素均为 $m/n$），波动值 $V(a) = 0$，故 $maxV = 0$。  
因此只有当 $m \bmod n = 0$ 且 $g = 0$ 时答案为 `YES`。

---

### 3. 允许变化点且长度 $\ge 2$（$n \ge 2$，$k \ge 1$）

#### 3.1 长度 $n = 2$

只有两个元素，最多存在一个变化点。  
可以将所有总和 $m$ 放在一个元素上，另一个元素为 $0$，构造为 $[m, 0]$ 或 $[0, m]$。  
此时 $V(a) = m$，且不可能超过 $m$，因此  
$$maxV = m$$

#### 3.2 长度 $n \ge 3$

- **若 $k = 1$**  
  只能出现一段连续相等值的改变（一个变化点），最大值可通过将 $m$ 放在端点实现，例如 $[m, 0, 0, \dots, 0]$。  
  此时 $V(a) = m$。无法构造出更大的值，所以  
  $$maxV = m$$

- **若 $k \ge 2$**  
  可以制造两个变化点，将 $m$ 放在序列中间，例如 $[0, \dots, 0, m, 0, \dots, 0]$。  
  此时波动值 $V(a) = |0 - m| + |m - 0| = 2m$。  
  由于总和只有 $m$，波动值的理论上界就是 $2m$（先“上升” $m$，再“下降” $m$），因此  
  $$maxV = 2m$$

---

### 4. 特殊情况 $m = 0$

若 $m = 0$，所有元素只能全为 $0$，波动值恒为 $0$。上述所有分类仍然成立（例如 $n\ge 2, k\ge 1$ 时 $maxV = 0$，即 $m$ 的值），不会有影响。

---

### 5. 回答询问

对每个询问 $(k, g)$，计算 $maxV$：

1. 若 $maxV = -1$（不存在合法序列），输出 `NO`；
2. 若 $maxV \ge g$，输出 `YES`；
3. 否则输出 `NO`。

## 复杂度分析

每个询问的计算仅包含常数次判断和整数运算，因此单次询问时间复杂度为 $O(1)$。  
设所有测试用例的询问总数 $Q = \sum q$，则：

- **时间复杂度**：$O(Q)$  
- **空间复杂度**：$O(1)$（只使用了常数个变量）

在题目给定的数据范围下（$Q \le 2 \times 10^5$），该算法可以高效通过。

## 代码实现

### Python

```python
import sys

def max_volatility(n, m, k):
    """返回在给定 n, m, k 下波动值的最大可能值，若不存在合法序列则返回 -1"""
    if n == 1:
        # 没有相邻元素
        return 0

    if k == 0:
        # 所有元素必须相等
        if m % n == 0:
            return 0
        return -1

    # 此时 n >= 2 且 k >= 1
    if n == 2:
        return m

    # n >= 3
    if k == 1:
        return m
    else:               # k >= 2
        return 2 * m

def solve():
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    idx = 1
    out_lines = []

    for _ in range(t):
        n = int(data[idx]); m = int(data[idx + 1]); q = int(data[idx + 2])
        idx += 3

        for _ in range(q):
            k = int(data[idx]); g = int(data[idx + 1])
            idx += 2

            max_v = max_volatility(n, m, k)

            if max_v != -1 and max_v >= g:
                out_lines.append("YES")
            else:
                out_lines.append("NO")

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.Scanner;

public class Main {
    // 返回波动值的最大可能值，若不存在合法序列返回 -1
    public static long maxVolatility(long n, long m, long k) {
        if (n == 1) {
            return 0;
        }
        if (k == 0) {
            if (m % n == 0) {
                return 0;
            }
            return -1;
        }
        if (n == 2) {
            return m;
        }
        // n >= 3
        if (k == 1) {
            return m;
        } else {
            return 2L * m;
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        StringBuilder sb = new StringBuilder();

        int t = sc.nextInt();
        while (t-- > 0) {
            long n = sc.nextLong();
            long m = sc.nextLong();
            int q = sc.nextInt();

            while (q-- > 0) {
                long k = sc.nextLong();
                long g = sc.nextLong();

                long maxV = maxVolatility(n, m, k);

                if (maxV != -1 && maxV >= g) {
                    sb.append("YES\n");
                } else {
                    sb.append("NO\n");
                }
            }
        }

        sc.close();
        System.out.print(sb.toString());
    }
}
```
