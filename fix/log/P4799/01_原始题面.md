# 题目内容
在一场策略战斗中，敌军单位从左到右排成一列，共有 $n$ 个单位，每个单位有一个正整数威胁值。指挥官将发动 $m$ 轮点名清除：每轮都会锁定当前阵列中威胁值最小的单位并将其消灭；若有多个单位威胁值同为最小，则消灭其中排在最左侧（即出现最早）的那一个。请你在执行完所有清除操作后，输出剩余单位的威胁值序列。

约束：
- 测试数据组数 $T$ 不超过 $2 	imes 10^5$。
- 每组数据中，单位数量 $n$ 不超过 $2 	imes 10^5$，清除轮数 $m$ 满足 $0 \le m < n$。
- 每个单位的威胁值均为 $1$ 到 $n$ 之间的整数。
- 所有测试数据中 $n$ 的总和不超过 $4 	imes 10^5$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据的组数。接下来每组数据包含两行：第一行有两个整数 $n$ 和 $m$，分别表示单位数量和清除轮数；第二行有 $n$ 个整数，依次给出从左到右每个单位的威胁值。

# 输出描述
对于每组测试数据，在一行内输出剩余单位的威胁值，整数之间用空格分隔。

## 样例1

**输入**

```
1
4 2
2 1 2 1
```

**输出**

```
2 2
```

**说明**

初始序列为 `2 1 2 1`，$m = 2$。当前威胁值最小的单位是 `1`，共有两个（下标 `1` 和 `3`）。因为需要清除的数量 $m = 2$ 不小于 `1` 的数量（$2$），所以两个 `1` 全部消灭。此时 $m$ 减为 `0`，清除结束。剩余单位按原顺序输出 `2 2`。

## 样例2

**输入**

```
1
3 0
3 1 2
```

**输出**

```
3 1 2
```

**说明**

$m = 0$，表示没有清除操作，因此剩余单位即为原序列 `3 1 2`。

## 样例3

**输入**

```
1
3 2
2 1 2
```

**输出**

```
2
```

**说明**

初始序列为 `2 1 2`，$m = 2$。第一轮：当前最小威胁值为 `1`，只有一个，直接消灭，$m$ 变为 `1`。当前阵列变为 `2 2`。第二轮：最小威胁值为 `2`，有两个。按照规则，优先消灭最左侧的 `2`（原序列第一个 `2`），消灭后 $m$ 变为 `0`。最终剩余最后一个 `2`。输出 `2`。

## 样例4

**输入**

```
1
6 3
5 2 2 1 3 2
```

**输出**

```
5 3 2
```

**说明**

初始序列为 `5 2 2 1 3 2`，$m = 3$。最小威胁值 `1` 有一个，消灭后 $m = 2$。剩余 `5 2 2 3 2`。接下来最小威胁值为 `2`，共有三个。因为剩余清除次数 $m = 2 < 3$，只消灭最左侧的两个 `2`（原序列下标 `1` 和 `2` 的 `2`），$m$ 变为 `0`。剩余未被消灭的单位为 `5`（下标 `0`）、`3`（下标 `4`）和最后一个 `2`（下标 `5`），按原顺序输出 `5 3 2`。
