# 题目内容
市立美术馆常设展厅陈列了 `26` 件展品，目录编号依次为 `1` 到 `26`。巡展手册把参观顺序压成一串不含分隔符的数字字符 $s$，每一位都是字符 `0` 到 `9`。馆方规定：每次只能按编号领取一件展品，编号必须是 `1` 到 `26` 的正整数；不存在编号为 `0` 的展品，因此单独的字符 `0` 不能成段。现在需要把 $s$ 从左到右切成若干段，使每一段都对应一件合法展品。

切分规则如下：

- 可以取 `1` 位数字 $d$，必须满足 $1 \le d \le 9$；
- 也可以取连续 `2` 位数字，其十进制值必须落在 `10` 到 `26` 之间。

两种切分只要存在某一处分段不同，即视为不同方案。请计算本质不同的合法切分方案数，结果对 `1000000007` 取模。

约束：测试组数 $T$ 满足 $1 < T < 10$，数字串长度 $n$ 满足 $1 < n < 100000$。

# 输入描述
第一行一个整数 $T$，表示测试组数。
接下来有 $T$ 组数据，每组两行：
第一行一个整数 $n$，表示数字串长度。
第二行一个长度为 $n$ 的字符串 $s$，仅由字符 `0` 到 `9` 组成。
保证 $1 < T < 10$，$1 < n < 100000$。

# 输出描述
输出 $T$ 行，每行一个整数，表示该组数据的合法切分方案数对 `1000000007` 取模后的结果。

## 样例1

**输入**

```
2
3
226
4
2101
```

**输出**

```
3
1
```

**说明**

第一组 $s=$ `226`：三种切分 `2|2|6`、`22|6`、`2|26`，答案为 `3`。
第二组 $s=$ `2101`：单独的 `0` 不合法，`01` 也不在 `10` 到 `26` 内，唯一合法切分为 `2|10|1`，答案为 `1`。

## 样例2

**输入**

```
2
5
11106
3
272
```

**输出**

```
2
1
```

**说明**

第一组 $s=$ `11106`：合法切分为 `11|10|6` 与 `1|11|0` 不成立（含单独 `0`），实际仅 `1|1|10|6` 与 `11|10|6` 两种，答案为 `2`。
第二组 $s=$ `272`：`27` 超出 `26`，只能切成 `2|7|2`，答案为 `1`。
