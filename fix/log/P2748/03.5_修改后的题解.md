## 解题思路

数字串 $s$ 需要切成若干段，每段是 `1` 到 `26` 的展品编号。这与经典“译码方案数”相同，用动态规划求解。

设 $dp[i]$ 表示前缀 $s[0..i)$ 的合法切分方案数，模 `1000000007`。

- $dp[0] = 1$（空前缀有一种空切分）。
- 若 $s[i-1] \ne$ `0`，则可把最后一位单独成段，转移 $dp[i] \leftarrow dp[i] + dp[i-1]$。
- 若 $i \ge 2$ 且 $s[i-2..i)$ 对应的两位数在 `10` 到 `26` 之间，则可把最后两位成段，转移 $dp[i] \leftarrow dp[i] + dp[i-2]$。

答案为 $dp[n]$。单独的 `0` 以及 `00`～`09` 都不能作为一段，因此会被上述条件自然排除。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(n)$。对多组数据，总时间与所有数字串长度之和成线性。

## 代码实现

### Python

```python
MOD = 10**9 + 7

def count_valid_ways(s):
    n = len(s)
    dp = [0] * (n + 1)
    dp[0] = 1
    for i in range(1, n + 1):
        if s[i - 1] != '0':
            dp[i] = (dp[i] + dp[i - 1]) % MOD
        if i > 1:
            two_digit = int(s[i - 2:i])
            if 10 <= two_digit <= 26:
                dp[i] = (dp[i] + dp[i - 2]) % MOD
    return dp[n]

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        print(count_valid_ways(s))

if __name__ == '__main__':
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    private static final int MOD = 1000000007;

    public static int countValidWays(String s) {
        int n = s.length();
        int[] dp = new int[n + 1];
        dp[0] = 1;
        for (int i = 1; i <= n; i++) {
            if (s.charAt(i - 1) != '0') {
                dp[i] = (dp[i] + dp[i - 1]) % MOD;
            }
            if (i > 1) {
                int twoDigit = (s.charAt(i - 2) - '0') * 10 + (s.charAt(i - 1) - '0');
                if (twoDigit >= 10 && twoDigit <= 26) {
                    dp[i] = (dp[i] + dp[i - 2]) % MOD;
                }
            }
        }
        return dp[n];
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        while (t-- > 0) {
            int n = sc.nextInt();
            String s = sc.next();
            System.out.println(countValidWays(s));
        }
        sc.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

const int MOD = 1e9 + 7;

int countValidWays(const string& s) {
    int n = s.length();
    vector<int> dp(n + 1, 0);
    dp[0] = 1;
    for (int i = 1; i <= n; i++) {
        if (s[i - 1] != '0') {
            dp[i] = (dp[i] + dp[i - 1]) % MOD;
        }
        if (i > 1) {
            int two_digit = (s[i - 2] - '0') * 10 + (s[i - 1] - '0');
            if (two_digit >= 10 && two_digit <= 26) {
                dp[i] = (dp[i] + dp[i - 2]) % MOD;
            }
        }
    }
    return dp[n];
}

int main() {
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        string s;
        cin >> s;
        cout << countValidWays(s) << endl;
    }
    return 0;
}
```
