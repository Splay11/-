## 解题思路

每次法术可以选择相邻的两个水晶同时翻转符号。可以证明，通过若干次这种操作，我们能够**翻转任意偶数个水晶的符号**，但无法改变奇数个水晶的符号（因为每次操作总是同时改变两个水晶）。

基于这个性质，我们可以得到最优策略：

- 如果初始能量值中负数的个数为偶数，我们可以把所有负数全部变为正数，此时最大总和就是**所有水晶能量绝对值之和**。
- 如果初始能量值中负数的个数为奇数，则最终必然会剩下一个负数。为了让总和最大，我们应选择**绝对值最小的那个水晶**保持负值（或将其变成负值），其余全部变为正数。此时最大总和为**所有水晶能量绝对值之和减去两倍的最小绝对值**。

具体实现只需扫描一遍数组，同时统计：
1. 所有能量值的绝对值之和 `abs_sum`；
2. 绝对值最小的能量值 `min_abs`；
3. 负能量值的个数 `neg_count`。

最后根据 `neg_count` 的奇偶性输出答案即可。

## 复杂度分析

- 时间复杂度：对于每组数据，只需遍历一次数组，时间复杂度为 $O(n)$。所有测试数据 $n$ 总和不超过 $2\times10^5$，总时间复杂度为 $O(\sum n)$，可以高效通过。
- 空间复杂度：仅使用了常数额外空间，空间复杂度为 $O(1)$。

## 代码实现

### Python

```python
def solve():
    n = int(input())
    arr = list(map(int, input().split()))
    
    # 计算所有能量值的绝对值之和
    abs_sum = sum(abs(x) for x in arr)
    # 找到绝对值最小的能量值
    min_abs = min(abs(x) for x in arr)
    # 统计负能量值的个数
    neg_count = sum(1 for x in arr if x < 0)
    
    # 偶数个负数：全部可以变为非负
    if neg_count % 2 == 0:
        return abs_sum
    # 奇数个负数：必须保留一个绝对值最小的为负
    else:
        return abs_sum - 2 * min_abs

T = int(input())
for _ in range(T):
    print(solve())
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();
        
        for (int t = 0; t < T; t++) {
            int n = sc.nextInt();
            int[] arr = new int[n];
            for (int i = 0; i < n; i++) {
                arr[i] = sc.nextInt();
            }
            System.out.println(solve(arr));
        }
        sc.close();
    }
    
    public static long solve(int[] arr) {
        long absSum = 0;          // 绝对值之和
        int minAbs = Integer.MAX_VALUE; // 最小绝对值
        int negCount = 0;        // 负数个数
        
        for (int x : arr) {
            absSum += Math.abs((long)x);
            minAbs = Math.min(minAbs, Math.abs(x));
            if (x < 0) {
                negCount++;
            }
        }
        
        // 偶数个负数：全部可变为非负
        if (negCount % 2 == 0) {
            return absSum;
        }
        // 奇数个负数：保留一个最小绝对值为负
        else {
            return absSum - 2L * minAbs;
        }
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <climits>
#include <cstdlib>
using namespace std;

long long solve(vector<int>& arr) {
    long long abs_sum = 0;        // 绝对值之和
    int min_abs = INT_MAX;        // 最小绝对值
    int neg_count = 0;            // 负数个数
    
    for (int x : arr) {
        abs_sum += abs(x);
        min_abs = min(min_abs, abs(x));
        if (x < 0) {
            neg_count++;
        }
    }
    
    // 偶数个负数：全部可变为非负
    if (neg_count % 2 == 0) {
        return abs_sum;
    }
    // 奇数个负数：保留一个最小绝对值为负
    else {
        return abs_sum - 2LL * min_abs;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        vector<int> arr(n);
        for (int i = 0; i < n; ++i) {
            cin >> arr[i];
        }
        cout << solve(arr) << "\n";
    }
    return 0;
}
```
