# 题目内容
给定一个由 $0$ 到 $9$ 整数构成的序列 $a_1, a_2, \dots, a_n$。每次操作你可以选择一个位置，将其数值增加 $1$ 或减少 $1$，但不能将 $0$ 减少，也不能将 $9$ 增加。

请计算最少需要多少次操作，可以使得序列中存在一个长度为 $k$ 的连续子序列，该子序列内的所有数字完全相同。

约束：序列长度 $n$ 不超过 $10^5$，$1 \le k \le n$，每个元素的取值范围为 $0$ 到 $9$。

# 输入描述
第一行包含两个整数 $n$ 和 $k$，用空格分隔。
第二行包含 $n$ 个整数，用空格分隔，表示给定的序列。

# 输出描述
输出一个整数，表示所需的最小操作次数。

## 样例1

**输入**

```
5 3
1 2 3 4 5
```

**输出**

```
2
```

**说明**

枚举最终相同的数字 $d$。当 $d=2$ 时，第一个窗口 $[1,2,3]$ 变为全 `2` 的代价为 $|1-2|+|2-2|+|3-2|=2$；第二个窗口 $[2,3,4]$ 变为全 `3` 的代价为 $2$；第三个窗口 $[3,4,5]$ 变为全 `4` 的代价也为 $2$。其他数字或窗口的代价均不小于 $2$。故最小操作次数为 $2$。

## 样例2

**输入**

```
3 3
0 9 5
```

**输出**

```
9
```

**说明**

整个序列必须变成同一个数字。枚举目标数字 $d$，计算总代价：$d=5$ 时代价为 $|0-5|+|9-5|+|5-5|=5+4+0=9$；$d=4$ 时为 $4+5+1=10$；$d=6$ 时为 $6+3+1=10$；其余 $d$ 代价均大于等于 $9$。因此最小为 $9$。

## 样例3

**输入**

```
6 2
0 9 0 9 0 9
```

**输出**

```
9
```

**说明**

窗口长度为 $2$。无论目标数字取何值，每个窗口的代价均为 $9$。如取 $d=0$，窗口 $[0,9]$ 代价 $|0-0|+|9-0|=9$；滑动后下一个窗口 $[9,0]$ 代价 $|9-0|+|0-0|=9$。任何目标数字下的最小窗口代价恒为 $9$，故最终最小操作次数为 $9$。
