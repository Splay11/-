## 解题思路

题目要求通过最少次数的加 $1$ 或减 $1$ 操作（数字只能在 $0$ 到 $9$ 之间变化），使得序列中存在一个长度为 $k$ 的连续子序列，其内部所有数字完全相同。

由于最终相同的数字只可能是 $0$ 到 $9$ 中的某一个，我们可以采用以下策略：

1. **枚举目标数字**：依次假设最终相同的数字为 $d$（$d = 0, 1, \dots, 9$）。
2. **计算窗口代价**：对于每一个目标数字 $d$，我们需要找到一个长度为 $k$ 的子数组 $a[i\ldots i+k-1]$，将它里面的所有元素都变成 $d$ 所需的操作总次数 $\sum_{j=i}^{i+k-1} |a_j - d|$ 最小。
3. **滑动窗口优化**：对固定的 $d$，如果对每一个长度为 $k$ 的子数组都重新求和，复杂度会很高。我们可以先计算第一个窗口 $[0, k-1]$ 的代价，然后窗口向右滑动时，去掉左边移出窗口的元素 $a[i-k]$ 的贡献，加上右边新进入窗口的元素 $a[i]$ 的贡献，即 `cost = cost - |a[i-k] - d| + |a[i] - d|`，从而实现 $O(1)$ 更新。
4. **取最小代价**：在所有目标数字 $d$ 和所有窗口的代价中，记录最小值即为答案。

由于数字种类只有 $10$，数组长度 $n \le 10^5$，使用滑动窗口后整体效率完全可以接受。

## 复杂度分析

- **时间复杂度**：需要枚举 $10$ 种目标数字，对每种目标数字用滑动窗口遍历一遍整个数组，单次复杂度为 $O(n)$，总时间复杂度为 $O(10n)$，即 $O(n)$。
- **空间复杂度**：需要存储长度为 $n$ 的输入序列，空间复杂度为 $O(n)$。除序列外只使用了常数个额外变量。

## 代码实现

### Python

```python
def main():
    import sys
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    n = int(input_data[0])
    k = int(input_data[1])
    a = list(map(int, input_data[2:2 + n]))
    
    # 答案可能较大，初始化为一个很大的数
    ans = float('inf')
    
    # 枚举最终相同的数字 d，从 0 到 9
    for d in range(10):
        # 计算第一个长度为 k 的窗口的代价
        cost = 0
        for i in range(k):
            cost += abs(a[i] - d)
        ans = min(ans, cost)
        
        # 滑动窗口枚举剩余窗口
        for i in range(k, n):
            cost += abs(a[i] - d) - abs(a[i - k] - d)
            if cost < ans:
                ans = cost
                
    print(ans)

if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int k = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }
        
        long ans = Long.MAX_VALUE;
        
        // 枚举最终相同的数字 d
        for (int d = 0; d <= 9; d++) {
            long cost = 0;
            // 计算第一个窗口的代价
            for (int i = 0; i < k; i++) {
                cost += Math.abs(a[i] - d);
            }
            ans = Math.min(ans, cost);
            
            // 滑动窗口
            for (int i = k; i < n; i++) {
                cost += Math.abs(a[i] - d) - Math.abs(a[i - k] - d);
                if (cost < ans) {
                    ans = cost;
                }
            }
        }
        
        System.out.println(ans);
        sc.close();
    }
}
```
