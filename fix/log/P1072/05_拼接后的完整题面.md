# 题目内容
给定长度为 $n$ 的非零整数序列 $a_1, a_2, \ldots, a_n$。一个连续子数组的符号由其所有元素的乘积决定：乘积小于 `0` 称为负段，乘积大于 `0` 称为正段。
请分别统计负段的个数与正段的个数。两个子数组不同，当且仅当它们的左右端点不完全相同。

约束条件：
- 序列长度 $n$ 为正整数，且不超过 $2 \times 10^5$。
- 每个 $a_i$ 为非零整数，绝对值不超过 $10^9$。

# 输入描述
第一行包含一个整数 $n$，表示序列长度。
第二行包含 $n$ 个非零整数 $a_1, a_2, \ldots, a_n$。

# 输出描述
输出两个整数，依次表示负段的个数和正段的个数，相邻整数之间用空格分隔。

## 样例1

**输入**

```
6
6 -1 -3 5 3 -5
```

**输出**

```
10 11
```

**说明**

长度为 `6` 的序列共有 $\dfrac{6 \times 7}{2}=21$ 个连续子数组。
其中乘积为负的有 `10` 个，乘积为正的有 `11` 个。输出 `10 11`。

## 样例2

**输入**

```
3
1 2 3
```

**输出**

```
0 6
```

**说明**

全部元素为正，任意连续子数组乘积都为正。
子数组共 `6` 个，故负段 `0` 个、正段 `6` 个。

## 样例3

**输入**

```
2
-1 -2
```

**输出**

```
2 1
```

**说明**

子数组 $[-1]$ 与 $[-2]$ 乘积为负，$[-1,-2]$ 乘积为正。
负段 `2` 个，正段 `1` 个。

## 样例4

**输入**

```
1
-8
```

**输出**

```
1 0
```

**说明**

只有一个负数，唯一子数组乘积为负，输出 `1 0`。
