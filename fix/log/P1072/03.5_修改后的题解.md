## 解题思路

每个元素非零，连续子数组乘积的正负只取决于区间内负数的个数：奇数个则为负段，偶数个则为正段。

从左到右扫描，用 $val$ 维护前缀乘积的符号（$+1$ 或 $-1$），并用 $po$、$ne$ 分别记录已经出现过的正前缀、负前缀个数。

枚举右端点 $i$：
- 若当前前缀符号为正，则以 $i$ 结尾的负段个数等于此前负前缀个数 $ne$，正段个数等于正前缀个数 $po$ 再加 $1$（包含从起点开始的整段前缀）；
- 若当前前缀符号为负，则对称地把两类计数交换。

处理完位置 $i$ 后再把当前前缀计入 $po$ 或 $ne$。最终 $ans_1$ 为负段个数，$ans_2$ 为正段个数。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(n)$。

## 代码实现

### Python

```python
n = int(input())
arr = list(map(int, input().split()))
val, ne, po, ans1, ans2 = 1, 0, 0, 0, 0
for i in range(n):
    val = val * (1 if arr[i] > 0 else -1)
    if val > 0:
        ans1 += ne
        ans2 += po + 1
    else:
        ans1 += po + 1
        ans2 += ne
    if val > 0:
        po += 1
    else:
        ne += 1
print(ans1, ans2)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int val = 1, ne = 0, po = 0;
        long ans1 = 0, ans2 = 0;
        for (int i = 0; i < n; i++) {
            int x = in.nextInt();
            val *= (x > 0 ? 1 : -1);
            if (val > 0) {
                ans1 += ne;
                ans2 += po + 1;
                po++;
            } else {
                ans1 += po + 1;
                ans2 += ne;
                ne++;
            }
        }
        System.out.println(ans1 + " " + ans2);
    }
}
```
