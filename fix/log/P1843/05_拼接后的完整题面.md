# 题目内容
仓库清单里记录了 $n$ 件货物的货号 $a_1, a_2, \ldots, a_n$。称一个货号是冷门的，当且仅当它在清单中出现的次数不超过 $k$。

请找出所有冷门货号中数值最小的那个。若清单里不存在任何冷门货号，则答案为 `-1`。

货物件数 $n$ 不超过 `10^5`，且 $1 \le k \le n$，每个货号为正整数且不超过 `10^9`。

# 输入描述
第一行两个正整数 $n$ 和 $k$（$1 \le k \le n \le 10^5$），分别表示货物件数与冷门阈值。
第二行 $n$ 个正整数 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 10^9$），表示各件货物的货号。

# 输出描述
输出一个整数：最小的冷门货号；若不存在，输出 `-1`。

## 样例1

**输入**

```
3 1
2 2 2
```

**输出**

```
-1
```

**说明**

清单里只有货号 `2`，出现 `3` 次，大于 $k=1$，不存在冷门货号，输出 `-1`。

## 样例2

**输入**

```
1 1
9
```

**输出**

```
9
```

**说明**

$n=1$ 的边界：$9$ 只出现一次，不超过 $k=1$，输出 `9`。

## 样例3

**输入**

```
3 1
3 3 3
```

**输出**

```
-1
```

**说明**

按题意模拟计算得到。
