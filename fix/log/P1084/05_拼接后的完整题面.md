# 题目内容
在一个数字信号处理系统中，你得到了一组长度为 $n$ 的信号值 $a_1, a_2, \dots, a_n$。你可以使用一台调节器对其中恰好 $k$ 个信号值进行调节，每个信号值最多被调节一次。调节方式有两种：放大（将当前值乘以 $2$）或衰减（将当前值除以 $2$，结果向下取整）。未被选择的信号值保持原样。你希望经过调节后，整个序列的最大值与最小值之差尽可能小。请你计算这个最小可能的极差值。

序列长度 $n$ 不超过 $10^5$，选择的信号值个数 $k$ 满足 $1 \le k \le n$，每个信号值 $a_i$ 均为不超过 $10^9$ 的正整数。

# 输入描述
第一行包含两个整数 $n$ 和 $k$，表示序列长度和需要操作的信号值个数。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$，表示初始信号值序列。

# 输出描述
输出一个整数，表示操作后信号序列极差的最小值。

## 样例1

**输入**

```
3 2
1 2 3
```

**输出**

```
0
```

**说明**

初始序列为 `1 2 3`，已排序。

我们枚举将最小的 `i` 个数放大、最大的 `k-i` 个数衰减的方案：
- 当 $i = 0$ 时：没有数放大，最后 $2$ 个数衰减。
  `2` 衰减为 $\lfloor 2/2 \rfloor = 1$，`3` 衰减为 $\lfloor 3/2 \rfloor = 1$，`1` 保持不变。序列变为 `1 1 1`，极差为 `0`。
- 当 $i = 1$ 时：前 `1` 个放大，后 `1` 个衰减。
  `1` 放大为 $2$，`3` 衰减为 $1$，`2` 保持不变。序列变为 `2 2 1`，极差为 `1`。
- 当 $i = 2$ 时：前 `2` 个放大，没有数衰减。
  `1` 变为 `2`，`2` 变为 `4`，`3` 不变。序列变为 `2 4 3`，极差为 `2`。

所有方案中的最小极差为 `0`，故输出 `0`。

## 样例2

**输入**

```
4 1
5 5 5 5
```

**输出**

```
3
```

**说明**

四个信号值全部为 `5`，且必须恰好操作 `1` 个信号。

考虑两种可能：
- 若对一个 `5` 做衰减操作，变为 $\lfloor 5/2 \rfloor = 2$，剩余三个保持 `5`，序列变为 `2 5 5 5`，极差为 $5 - 2 = 3$。
- 若对一个 `5` 做放大操作，变为 $10$，序列变为 `10 5 5 5`，极差为 $10 - 5 = 5$。

从算法角度看，枚举 $i=0$（后 `1` 个衰减）得到极差 `3`，$i=1$（前 `1` 个放大）得到极差 `5`。因此最小极差为 `3`。

## 样例3

**输入**

```
5 3
10 20 30 40 50
```

**输出**

```
10
```

**说明**

排序后的序列为 `10 20 30 40 50`，需要操作 $k=3$ 个数。

枚举不同的 $i$（前 $i$ 个放大，后 $3-i$ 个衰减）：
- $i=0$：后 `3` 个衰减得 $15, 20, 25$，前两个不变（`10, 20`），最小 `10`，最大 `25`，极差 `15`。
- $i=1$：前 `1` 个放大得 `20`，后 `2` 个衰减得 $20, 25$，中间不变部分为 `20, 30`，总体最小 `20`，最大 `30`，极差 `10`。
- $i=2$：前 `2` 个放大得 `20, 40`，后 `1` 个衰减得 $25$，中间不变为 `30`，最小 `20`，最大 `40`，极差 `20`。
- $i=3$：前 `3` 个放大得 `20, 40, 60`，后 `0` 个衰减，剩余不变为 `40, 50`，最小 `20`，最大 `60`，极差 `40`。

在所有方案中，最小极差为 `10`，因此输出 `10`。
