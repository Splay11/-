## 解题思路

需要统计长度为 $n$、取值在 $[0,m]$ 内的非递减序列个数，使得全部元素的按位异或恰好为 $m$，答案对 $10^9+7$ 取模。

定义 $dp[i][j][k]$ 表示：已经确定前 $i$ 个位置，最后一个数恰好为 $j$，且前 $i$ 个数的异或和为 $k$ 的方案数。其中 $k$ 只需考虑到 $2m$ 即可。

朴素转移为
$$
dp[i][j][k]=\sum_{p=0}^{j} dp[i-1][p][k \oplus j]
$$
即上一位可以是任意不超过 $j$ 的值 $p$。直接枚举 $p$ 的复杂度为 $O(nm^3)$，无法通过。

观察上式，对固定的 $i$、$k$、$j$，转移是对上一层 $p\le j$ 的前缀求和。令
$$
s[j][k]=\sum_{p=0}^{j} dp[i-1][p][k]
$$
则
$$
dp[i][j][k]=s[j][k \oplus j]
$$
每次先用上一层 $dp$ 做出 $s$，再 $O(1)$ 完成转移。初始令 $dp[0][0][0]=1$，表示还没有填任何数时异或和为 $0$。最终答案为 $\sum_{j=0}^{m} dp[n][j][m]$。

## 复杂度分析

每一层需要枚举末位 $j$ 与异或和 $k$，并用前缀和做到 $O(1)$ 转移。

- 时间复杂度：$O(n m^2)$。
- 空间复杂度：$O(n m^2)$。

在 $n,m\le 300$ 的范围内可以通过。

## 代码实现

### Python

```python
mod = 10**9 + 7
N = 301

# dp[i][j][k]: 前 i 个数、末位为 j、异或和为 k 的方案数
dp = [[[0 for _ in range(N << 1)] for _ in range(N)] for _ in range(N)]
# s[j][k]: dp[i-1][0..j][k] 的前缀和
s = [[0 for _ in range(N << 1)] for _ in range(N)]

n, m = map(int, input().split())

dp[0][0][0] = 1

for i in range(1, n + 1):
    for j in range(m + 1):
        for k in range(2 * m + 1):
            s[j][k] = dp[i - 1][j][k]
            if j > 0:
                s[j][k] = (s[j][k] + s[j - 1][k]) % mod

    for j in range(m + 1):
        for k in range(2 * m + 1):
            if k ^ j <= 2 * m:
                dp[i][j][k] = s[j][k ^ j]

res = sum(dp[n][j][m] for j in range(m + 1)) % mod
print(res)
```

### Java

```java
import java.util.Scanner;

public class Main {
    static final int mod = 1000000007;
    static final int N = 310;

    static int[][][] dp = new int[N][N][N << 1];
    static int[][] s = new int[N][N << 1];

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int m = scanner.nextInt();

        dp[0][0][0] = 1;

        for (int i = 1; i <= n; i++) {
            for (int j = 0; j <= m; j++) {
                for (int k = 0; k <= m + m; k++) {
                    s[j][k] = dp[i - 1][j][k];
                    if (j > 0) {
                        s[j][k] = (s[j][k] + s[j - 1][k]) % mod;
                    }
                }
            }
            for (int j = 0; j <= m; j++) {
                for (int k = 0; k <= m + m && (k ^ j) <= 2 * m; k++) {
                    dp[i][j][k] = s[j][k ^ j];
                }
            }
        }

        int res = 0;
        for (int j = 0; j <= m; ++j) {
            res = (res + dp[n][j][m]) % mod;
        }
        System.out.println(res);
    }
}
```

### C++

```cpp
#include <iostream>
using namespace std;

const int mod = 1e9 + 7;
const int N = 310;

int dp[N][N][N << 1];
int s[N][N << 1];

int main() {
    int n, m;
    cin >> n >> m;

    dp[0][0][0] = 1;

    for (int i = 1; i <= n; i++) {
        for (int j = 0; j <= m; j++) {
            for (int k = 0; k <= m + m; k++) {
                s[j][k] = dp[i - 1][j][k];
                if (j) {
                    s[j][k] += s[j - 1][k];
                    s[j][k] %= mod;
                }
            }
        }
        for (int j = 0; j <= m; j++) {
            for (int k = 0; k <= m + m && (k ^ j) <= 2 * m; k++) {
                dp[i][j][k] = s[j][k ^ j];
            }
        }
    }

    int res = 0;
    for (int j = 0; j <= m; ++j)
        res = (res + dp[n][j][m]) % mod;

    cout << res << "\n";
    return 0;
}
```
