# 题目内容
实验室要为一条产线指定长度为 $n$ 的能级序列 $h_1, h_2, \ldots, h_n$。可用的能级共有 $m+1$ 种，编号为 $0$ 到 $m$ 的整数。

为了让功率只升不降，序列必须非递减，即 $h_1 \le h_2 \le \cdots \le h_n$，并且每个能级都满足 $0 \le h_i \le m$。与此同时，全部能级的按位异或必须恰好等于 $m$，作为出厂校验值：

$$h_1 \oplus h_2 \oplus \cdots \oplus h_n = m$$

其中 $\oplus$ 表示按位异或。请计算有多少个不同的序列满足上述全部条件。由于答案可能很大，将结果对 $10^9+7$ 取模后输出。

约束：序列长度不超过 `300`，能级编号的最大值不超过 `300`。

# 输入描述
一行两个整数 $n$ 和 $m$，分别表示序列长度与能级编号的最大值。保证 $1 \le n \le 300$，$0 \le m \le 300$。

# 输出描述
输出一个整数，表示满足条件的序列个数对 $10^9+7$ 取模后的结果。

## 样例1

**输入**

```
1 0
```

**输出**

```
1
```

**说明**

长度 $n=1$，能级上限 $m=0$。唯一合法序列是 $[0]$，其异或和为 `0`，等于 $m$。
这是最小规模的边界情形，答案为 `1`。
