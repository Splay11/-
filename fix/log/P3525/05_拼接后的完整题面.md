# 题目内容
小明在一条由 $n$ 块石板铺成的小路上。每块石板有一个状态：$0$ 表示这块石板是稳固的，可以安全站立；$1$ 表示这块石板是松动的，不能踩上去。小明一开始站在第 $1$ 块石板上，他想到达第 $n$ 块石板。他每次跳跃可以向前移动 $1$ 块或 $2$ 块石板，但只能落在稳固的石板上（状态为 $0$）。已知第 $1$ 块和第 $n$ 块石板总是稳固的，且题目保证小明总能到达终点。请你计算小明从起点到终点所需的最少跳跃次数。

约束：石板的总数 $n$ 满足 $2 \le n \le 100$；每块石板的状态为 $0$ 或 $1$，且 $s_1 = s_n = 0$。

# 输入描述
第一行包含一个整数 $n$，表示石板的总数。
第二行包含 $n$ 个用空格分隔的整数 $s_1, s_2, \ldots, s_n$，依次表示第 $1$ 块到第 $n$ 块石板的状态（$0$ 表示稳固，$1$ 表示松动）。

# 输出描述
输出一个整数，表示小明到达第 $n$ 块石板所需的最少跳跃次数。

## 样例1

**输入**

```
2
0 0
```

**输出**

```
1
```

**说明**

只有两块石板，小明从第 `1` 块开始，只能向前跳 `1` 步到达第 `2` 块石板，因此最少跳跃次数为 `1`。

## 样例2

**输入**

```
5
0 1 0 0 0
```

**输出**

```
2
```

**说明**

石板状态为 `[0, 1, 0, 0, 0]`。小明从第 `1` 块出发：第 `2` 块松动（状态 `1`），不能跳一步，只能跳两步到第 `3` 块（状态 `0`）。接着从第 `3` 块可以直接跳两步到第 `5` 块（终点，状态 `0`）。总共跳跃 `2` 次，这也是最少的次数。

## 样例3

**输入**

```
8
0 0 1 0 0 1 0 0
```

**输出**

```
5
```

**说明**

初始在第 `1` 块（状态 `0`）。贪心过程：
- 在第 `1` 块，检查第 `3` 块为松动，只能跳一步到第 `2` 块（状态 `0`）。
- 在第 `2` 块，检查第 `4` 块为稳固，跳两步到第 `4` 块。
- 在第 `4` 块，检查第 `6` 块为松动，跳一步到第 `5` 块（状态 `0`）。
- 在第 `5` 块，检查第 `7` 块为稳固，跳两步到第 `7` 块。
- 在第 `7` 块，跳两步会超出边界，跳一步到达第 `8` 块终点。
累计跳跃 `5` 次。
