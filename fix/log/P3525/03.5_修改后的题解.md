## 解题思路

本题要求从起点（第 1 块石板）到终点（第 n 块石板）的最少跳跃次数，每次只能向前跳 1 块或 2 块，且只能落在稳固石板（状态为 0）上。已知起点和终点总是稳固的，且题目保证一定有解。

采用**贪心策略**：在每一步，优先尝试跳跃 2 块石板。
- 若当前位置 `i` 满足 `i + 2 < n` 且第 `i + 2` 块石板为稳固石板（`s[i+2] == 0`），则直接跳到 `i + 2`；
- 否则只能跳 1 块石板到 `i + 1`。

**正确性说明**：跳跃 2 块总是比跳跃 1 块更高效（移动相同距离需要更少步数），并且因为题目保证存在到达终点的路径，选择跳 2 块不会导致进入“死胡同”而无法到达终点；若一个位置能跳 2 块却选择跳 1 块，只会白白增加跳跃次数，不可能更优。

实现时，用变量 `ans` 记录跳跃次数，从 `i = 0` 开始模拟，直到 `i` 到达 `n - 1` 为止。

## 复杂度分析

- **时间复杂度**：$O(n)$。每个石板最多被检查一次，指针 `i` 单向移动，总操作次数与石板数量成正比。
- **空间复杂度**：$O(1)$。仅使用了常数个额外的变量，不随输入规模增长。

## 代码实现

### Python

```python
# 贪心解法：能跳2块就跳2块，否则跳1块
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    n = int(data[0])
    stones = list(map(int, data[1:1 + n]))
    i = 0          # 当前位置（0 表示第1块石板）
    ans = 0        # 累计跳跃次数
    while i < n - 1:
        # 若跳2块后的石板是稳固的，则优先跳2块
        if i + 2 < n and stones[i + 2] == 0:
            i += 2
        else:
            i += 1
        ans += 1
    print(ans)

if __name__ == "__main__":
    solve()
```

### Java

```java
// 贪心解法：能跳2块就跳2块，否则跳1块
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String s;
        // 读 n
        s = br.readLine();
        while (s != null && s.trim().isEmpty()) s = br.readLine();
        int n = Integer.parseInt(s.trim());
        // 读石板状态
        String line = br.readLine();
        while (line != null && line.trim().isEmpty()) line = br.readLine();
        StringTokenizer st = new StringTokenizer(line);
        int[] stones = new int[n];
        for (int i = 0; i < n; i++) {
            if (!st.hasMoreTokens()) {   // 若当前行没有足够数字，继续读下一行
                line = br.readLine();
                if (line == null) break;
                st = new StringTokenizer(line);
            }
            stones[i] = Integer.parseInt(st.nextToken());
        }
        int i = 0, ans = 0;
        while (i < n - 1) {
            if (i + 2 < n && stones[i + 2] == 0) i += 2;  // 优先跳2块
            else i += 1;                                   // 否则跳1块
            ans++;
        }
        System.out.println(ans);
    }
}
```

// 贪心解法：能跳2块就跳2块，否则跳1块
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    if (!(cin >> n)) return 0;
    vector<int> stones(n);
    for (int i = 0; i < n; ++i) cin >> stones[i];
    int i = 0, ans = 0;
    while (i < n - 1) {
        if (i + 2 < n && stones[i + 2] == 0) i += 2;  // 优先跳2块
        else i += 1;                                   // 否则跳1块
        ++ans;
    }
    cout << ans << "\n";
    return 0;
}
