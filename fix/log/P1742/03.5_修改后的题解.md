## 解题思路

将 $x$ 质因数分解。分两种情况讨论：

**只有一种质因子**，即 $x = a^y$。若拆成 $a^{p_1},\ldots,a^{p_k}$，则因子贡献总和为

$$\sum_{i=1}^{k}(p_i+1)=k+y$$

$k$ 越大越好，最优是拆成 $y$ 个 $a$，答案为 $2y$。不拆时贡献为 $y+1$，由于 $y \ge 1$ 时 $2y \ge y+1$，拆分更优。

**有多种质因子**，即 $x = a_1^{y_1}\cdots a_m^{y_m}$（$m \ge 2$，$y_i \ge 1$）。不拆时因子个数为 $\prod(y_i+1)$。每个 $y_i+1 \ge 2$，而对任意 $u,v \ge 2$ 有 $u \times v \ge u+v$，因此把 $x$ 拆成若干部分后再把因子贡献相加，不会超过不拆时的因子个数。此时答案就是 $x$ 本身的正因子个数。

实现时对每个 $x$ 做试除分解即可。

## 复杂度分析

时间复杂度 $O(T\sqrt{x})$，空间复杂度 $O(\log x)$。

## 代码实现

### Python

```python
def solve():
    x = int(input())
    u = 2
    res = []
    while u * u <= x:
        if x % u == 0:
            c = 0
            while x % u == 0:
                c += 1
                x //= u
            res.append((u, c))
        u += 1
    if x > 1:
        res.append((x, 1))
    if len(res) == 1:
        print(res[0][1] * 2)
    else:
        ans = 1
        for _, y in res:
            ans *= (y + 1)
        print(ans)

T = int(input())
for _ in range(T):
    solve()
```

### Java

```java
import java.util.*;

public class Main {
    static long solve(int x) {
        List<int[]> list = new ArrayList<>();
        for (int i = 2; (long) i * i <= x; i++) {
            if (x % i == 0) {
                int cnt = 0;
                while (x % i == 0) {
                    cnt++;
                    x /= i;
                }
                list.add(new int[]{i, cnt});
            }
        }
        if (x > 1) {
            list.add(new int[]{x, 1});
        }
        if (list.size() == 1) {
            return 2L * list.get(0)[1];
        }
        long ans = 1;
        for (int[] a : list) {
            ans *= (a[1] + 1);
        }
        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();
        while (T-- > 0) {
            System.out.println(solve(sc.nextInt()));
        }
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

long long solve(int x) {
    vector<pair<int, int>> res;
    for (int i = 2; 1LL * i * i <= x; i++) {
        if (x % i == 0) {
            int c = 0;
            while (x % i == 0) {
                c++;
                x /= i;
            }
            res.push_back({i, c});
        }
    }
    if (x > 1) res.push_back({x, 1});
    if (res.size() == 1) return 2LL * res[0].second;
    long long ans = 1;
    for (auto &p : res) ans *= (p.second + 1);
    return ans;
}

int main() {
    int T;
    cin >> T;
    while (T--) {
        int x;
        cin >> x;
        cout << solve(x) << endl;
    }
    return 0;
}
```
