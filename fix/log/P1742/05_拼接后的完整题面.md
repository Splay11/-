# 题目内容
仓库里有一张编号为 $x$ 的货单。对任意正整数 $v$，定义它的**因子贡献**为 $v$ 的正因子个数。

可以把 $x$ 拆成若干个均大于 `1` 的正整数 $x_1,x_2,\ldots,x_k$，使得

$$x_1 \times x_2 \times \cdots \times x_k = x$$

也可以选择完全不拆，此时只保留 $x$ 本身。

一次拆分方案的总贡献，定义为拆出的各个整数的因子贡献之和。请找出能使总贡献尽可能大的拆法，并输出这个最大总贡献。

本题有多组询问。

约束条件：
- 询问组数 $T$ 满足 $1 \le T \le 10^4$；
- 每组货单编号 $x$ 满足 $2 \le x \le 2 \times 10^5$。

# 输入描述
第一行包含一个正整数 $T$（$1 \le T \le 10^4$），表示询问组数。
接下来 $T$ 行，每行一个正整数 $x$（$2 \le x \le 2 \times 10^5$），表示当前货单编号。

# 输出描述
输出共 $T$ 行。对于每组询问，输出一个正整数，表示能够得到的最大总贡献。

## 样例1

**输入**

```
3
8
12
15
```

**输出**

```
6
6
4
```

**说明**

第一组：$8=2^3$，只有一种质因子，最优拆成三个 `2`，每个因子贡献为 `2`，总贡献 $2+2+2=6$。

第二组：$12=2^2\times 3$，有多种质因子，不拆更优，正因子个数为 `6`。

第三组：$15=3\times 5$，拆成 `3` 和 `5`，总贡献 $2+2=4$；不拆时正因子个数也是 `4`。

## 样例2

**输入**

```
2
2
7
```

**输出**

```
2
2
```

**说明**

`2` 和 `7` 都是质数，相当于 $a^1$。最优方案是不继续拆（或视为一个质因子本身），答案均为 $2\times 1=2$。

## 样例3

**输入**

```
1
16
```

**输出**

```
8
```

**说明**

$16=2^4$，只有一种质因子，最优拆成四个 `2`，总贡献 $2\times 4=8$。
