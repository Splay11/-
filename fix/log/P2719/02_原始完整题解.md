# 有序数

## 解题思路
本题数据范围较小（最大到 $ 10^5 $），我们可采用暴力枚举的方法：

1. 遍历区间内每个整数。
2. 对于每个整数，提取其数位，存入集合。
3. 判断集合中最大数与最小数之差是否等于集合元素数量减一：$\text{max} - $$\text{min} = |S| - 1$
4. 满足条件，则计数加一。

由于题目数据较小，不需要优化，直接暴力判断即可满足需求。

## 复杂度分析
- 时间复杂度：$ O(N \log M) $，其中 $ N = r-l+1 $，$ M $ 为区间中最大的数（取数位的复杂度）。
- 空间复杂度：$ O(1) $（每次使用的集合最大只有10个元素，空间可视为常数级别）。

## 代码实现

### Python实现：
```python
l, r = map(int, input().split())
ans = 0
for i in range(l, r + 1):
    s = set(str(i))              # 提取数位组成集合
    mi, ma = min(s), max(s)      # 找到最小和最大数位
    if int(ma) - int(mi) == len(s) - 1:
        ans += 1                 # 判断连续条件成立，计数加1
print(ans)
```

### Java实现：
```java
import java.util.*;

public class Main {
    // 判断是否为有序数的方法
    static boolean isOrderedNum(int x) {
        Set<Integer> set = new HashSet<>();
        int max = -1, min = 10;
        while (x > 0) {
            int digit = x % 10;
            set.add(digit);
            max = Math.max(max, digit);
            min = Math.min(min, digit);
            x /= 10;
        }
        return (max - min) == (set.size() - 1);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int l = sc.nextInt();
        int r = sc.nextInt();
        int ans = 0;
        for (int i = l; i <= r; i++) {
            if (isOrderedNum(i)) ans++;
        }
        System.out.println(ans);
    }
}
```

### C++实现：
```cpp
#include <iostream>
#include <set>
using namespace std;

// 判断是否为有序数的函数
bool isOrderedNum(int x) {
    set<int> digits;
    int ma = -1, mi = 10;
    while (x) {
        int digit = x % 10;
        digits.insert(digit);
        ma = max(ma, digit);
        mi = min(mi, digit);
        x /= 10;
    }
    return ma - mi == digits.size() - 1;
}

int main() {
    int l, r, ans = 0;
    cin >> l >> r;
    for (int i = l; i <= r; i++) {
        if (isOrderedNum(i)) ans++;
    }
    cout << ans << endl;
    return 0;
}
```
