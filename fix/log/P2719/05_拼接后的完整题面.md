# 题目内容
称一个正整数为连号，当且仅当把它的全部数位放入集合后，集合中的元素构成一段连续整数。例如 `456` 与 `5446` 都是连号，因为数位集合均为 $\{4,5,6\}$。

给定闭区间 $[l, r]$，请统计该区间内有多少个连号。

区间端点满足 $1 \le l \le r \le 10^5$。

# 输入描述
在一行上输入两个整数 $l$ 和 $r$，表示询问的闭区间两端。

# 输出描述
输出一个整数，表示区间 $[l, r]$ 中连号的个数。

## 样例1

**输入**

```
1 12
```

**输出**

```
12
```

**说明**

区间 $[1,12]$ 内每个正整数的数位集合都是连续的（单位数显然连续，`10`--`12` 的集合分别为 $\{0,1\}$、$\{0,1\}$、$\{1,2\}$），因此答案为 `12`。

## 样例2

**输入**

```
13 21
```

**输出**

```
1
```

**说明**

`13` 到 `20` 的数位集合都不连续，只有 `21` 的集合 $\{1,2\}$ 连续，故答案为 `1`。

## 样例3

**输入**

```
1 1
```

**输出**

```
1
```

**说明**

单点 `1` 的数位集合为 $\{1\}$，长度为 `1` 的区间视为连续，答案为 `1`。

## 样例4

**输入**

```
5446 5446
```

**输出**

```
1
```

**说明**

`5446` 的数位集合为 $\{4,5,6\}$，$6-4=2$ 且集合大小为 `3`，满足连续性。
