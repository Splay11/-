## 解题思路

1. **判定条件**：把一个正整数的各位数字放入集合 $S$。若 $S$ 中的元素构成一段连续整数，当且仅当 $\max(S) - \min(S) = |S| - 1$。
2. **枚举**：区间上界仅为 $10^5$，直接枚举 $[l, r]$ 中每个整数，提取数位后按上式判断即可。
3. **重复数位**：集合会自动去重，例如 `5446` 的数位集合为 $\{4,5,6\}$，仍满足连续性。

## 复杂度分析

时间复杂度 $O((r-l+1) \log r)$，每个数提取数位的代价与位数成正比。空间复杂度 $O(1)$，每次判定所用集合大小不超过 `10`。

## 代码实现

### Python

```python
l, r = map(int, input().split())
ans = 0
for i in range(l, r + 1):
    s = set(str(i))
    mi, ma = min(s), max(s)
    if int(ma) - int(mi) == len(s) - 1:
        ans += 1
print(ans)
```

### Java

```java
import java.util.*;

public class Main {
    static boolean isOrderedNum(int x) {
        Set<Integer> set = new HashSet<>();
        int max = -1, min = 10;
        while (x > 0) {
            int digit = x % 10;
            set.add(digit);
            max = Math.max(max, digit);
            min = Math.min(min, digit);
            x /= 10;
        }
        return (max - min) == (set.size() - 1);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int l = sc.nextInt();
        int r = sc.nextInt();
        int ans = 0;
        for (int i = l; i <= r; i++) {
            if (isOrderedNum(i)) ans++;
        }
        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <iostream>
#include <set>
using namespace std;

bool isOrderedNum(int x) {
    set<int> digits;
    int ma = -1, mi = 10;
    while (x) {
        int digit = x % 10;
        digits.insert(digit);
        ma = max(ma, digit);
        mi = min(mi, digit);
        x /= 10;
    }
    return ma - mi == (int)digits.size() - 1;
}

int main() {
    int l, r, ans = 0;
    cin >> l >> r;
    for (int i = l; i <= r; i++) {
        if (isOrderedNum(i)) ans++;
    }
    cout << ans << endl;
    return 0;
}
```
