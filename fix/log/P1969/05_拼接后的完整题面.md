# 题目内容
在一个数字王国里，收藏着编号为 `1` 到 `n` 的卷轴。你需要将这些卷轴排成一列。定义一对相邻卷轴为一个「下沉」，如果左边卷轴的编号大于右边卷轴。

给定整数 `n` 和 `m`，请你构造一个由 `1` 到 `n` 组成的序列，每个整数恰好出现一次，且序列中恰好有 `m` 个下沉。如果存在多种合法方案，任意输出一种即可。

约束：`n` 不超过 `10^5`，`m` 为整数且满足 $0 \le m < n$。

# 输入描述
输入只有一行，包含两个整数 `n` 和 `m`，用空格分隔。

# 输出描述
输出一行，包含 `n` 个整数，表示构造的序列，相邻整数之间用单个空格隔开。

## 样例1

**输入**

```
4 0
```

**输出**

```
1 2 3 4
```

**说明**

$m = 0$，表示不允许出现任何下沉，因此整个序列必须严格升序。按照构造方法，令 $k = m + 1 = 1$，反转前 $1$ 个元素得到 `[1]`，剩余 $n - k = 3$ 个元素升序排列为 `[2, 3, 4]`，拼接后即为 `1 2 3 4`。序列中所有相邻关系均为左小右大，下沉数为 `0`，满足要求。

## 样例2

**输入**

```
4 3
```

**输出**

```
4 3 2 1
```

**说明**

$m = 3$ 是允许的最大下沉数（因为 $m < n$ 且 $n=4$，最多有 $3$ 个下沉）。此时 $k = m + 1 = 4$，需要反转整个序列。将前 $4$ 个元素反转得到 `[4, 3, 2, 1]`，剩余元素个数为 $0$，最终序列为 `4 3 2 1`。相邻比较：$4 > 3$、$3 > 2$、$2 > 1$，恰好有 $3$ 个下沉，满足条件。

## 样例3

**输入**

```
6 2
```

**输出**

```
3 2 1 4 5 6
```

**说明**

$m = 2$，需要恰好 $2$ 个下沉。令 $k = m + 1 = 3$，反转前 $3$ 个元素得到降序前缀 `[3, 2, 1]`，剩余 $3$ 个元素升序后缀为 `[4, 5, 6]`。拼接得序列 `3 2 1 4 5 6`。检查下沉情况：前缀中 $3 > 2$ 和 $2 > 1$ 贡献 $2$ 个下沉；后缀 $4 < 5$、$5 < 6$ 均为上升；交界处 $1 < 4$ 也是上升。因此总下沉数恰好为 $2$，符合要求。

## 样例4

**输入**

```
1 0
```

**输出**

```
1
```

**说明**

边界情况：$n = 1$，$m = 0$。此时序列只有一个元素 `1`，不存在相邻对，下沉数自然为 $0$。按照构造，$k = m + 1 = 1$，反转前缀后仍为 `[1]`，无后缀，输出 `1`。
