# 题目内容
当一个正整数的十进制表示中不出现数字 `2` 和 `4` 时，我们称其为**纯净数**。

现在给定一个正整数 $n$，你需要计算有多少个无序三元组 $(a, b, c)$ 满足：
- $a, b, c$ 均为纯净数；
- $a + b + c = n$；
- $a, b, c$ 两两不同。

调换三个数的顺序视为同一种方法。例如，当 $n=9$ 时，只有 $1 + 3 + 5$ 这一种拆分方式，不会将 $3+5+1$ 等重复计算。

你需要回答多组询问。

**数据范围**
- 询问组数 $T$ 不超过 $10^4$；
- 每组询问中的 $n$ 满足 $1 \le n \le 10^6$。

# 输入描述
第一行输入一个整数 $T$，表示询问的组数。
接下来 $T$ 行，每行输入一个整数 $n$，代表一个询问。

# 输出描述
对于每一组询问，输出一行一个整数，表示满足条件的三元组数量。

## 样例1

**输入**

```
3
8
10
14
```

**输出**

```
0
1
4
```

**说明**

对于 $n=8$: 最小的三个不同纯净数是 `1`，`3`，`5`，其和为 `9`，大于 `8`，因此不存在满足条件的三元组，答案为 `0`。

对于 $n=10$: 纯净数有 `1, 3, 5, 6, 7, 8, 10, ...`。唯一的一组三个不同纯净数之和为 `10` 的是 $1 + 3 + 6 = 10$，故答案为 `1`。

对于 $n=14$: 所有可能的三元组为 $1+3+10=14$，$1+5+8=14$，$1+6+7=14$，$3+5+6=14$，其中每个数都满足纯净数且两两不同，共有 `4` 组，故答案为 `4`。
