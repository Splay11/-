# 题目内容
在一个 $n \times n$ 的网格区域中，标有 $n$ 处避难所，它们恰好位于主对角线上的所有网格点 $(i, i)$（$1 \le i \le n$）。

现在该区域中有 $m$ 名幸存者，第 $j$ 名幸存者的初始位置为 $(x_j, y_j)$。幸存者每一步可以移动至上下左右紧邻的格子，即四连通方向。他们需要尽快进入某个避难所。两个格子 $(x_1,y_1)$ 与 $(x_2,y_2)$ 之间的最短移动步数定义为 $|x_1-x_2|+|y_1-y_2|$。

每名幸存者都会选择距离自己最近的避难所作为目标；若存在多个距离相等的最近避难所，幸存者们会彼此协调分配，以最大化成功进入避难所的总人数。每个避难所容量仅为 $1$，一旦有人进入便会关闭，后续无法再使用。

给定网格规模和所有幸存者的初始坐标，请计算最多有多少名幸存者能够成功进入避难所。

约束条件：整数 $n$ 和 $m$ 满足 $2 \le n, m \le 10^6$；所有坐标 $x_j, y_j$ 均为整数，满足 $1 \le x_j, y_j \le n$。

# 输入描述
第一行包含两个整数 $n$ 和 $m$，分别表示网格边长与幸存者个数。
接下来 $m$ 行，每行包含两个整数 $x_j$ 和 $y_j$，表示一名幸存者的初始行坐标与列坐标。

# 输出描述
输出一个整数，表示最多能够成功进入避难所的幸存者人数。

## 样例1

**输入**

```
3 4
1 2
2 1
2 3
3 2
```

**输出**

```
3
```

**说明**

网格大小为 $3 \times 3$，共有 `3` 个避难所，分别位于 $(1,1)$、$(2,2)$、$(3,3)$。
幸存者有 `4` 名：
- $(1,2)$ 的最近避难所区间为 $[1,2]$；
- $(2,1)$ 的最近避难所区间为 $[1,2]$；
- $(2,3)$ 的最近避难所区间为 $[2,3]$；
- $(3,2)$ 的最近避难所区间为 $[2,3]$。
避难所容量各为 `1`，而幸存者数量多于避难所，因此最多只有 `3` 名幸存者能进入。通过合理分配（例如 $(1,2)$ 进入 $(1,1)$，$(2,1)$ 进入 $(2,2)$，$(2,3)$ 进入 $(3,3)$），即可达到最大值 `3`。

## 样例2

**输入**

```
3 3
2 2
2 2
2 2
```

**输出**

```
1
```

**说明**

网格中有 `3` 个避难所 $(1,1)$、$(2,2)$、$(3,3)$，但 `3` 名幸存者的初始位置都是 $(2,2)$。
对于位置 $(2,2)$，到避难所 $(2,2)$ 的距离为 $0$，到其他避难所的距离均大于 $0$，因此三人的最近避难所都是 $(2,2)$。
由于每个避难所容量仅为 `1`，最多只能有一名幸存者进入 $(2,2)$，其余两人无法进入任何避难所。因此答案为 `1`。

## 样例3

**输入**

```
4 5
1 3
2 4
3 1
4 2
2 2
```

**输出**

```
4
```

**说明**

网格为 $4 \times 4$，有 `4` 个避难所：$(1,1)$、$(2,2)$、$(3,3)$、$(4,4)$。
`5` 名幸存者及其最近避难所区间如下：
- $(1,3)$: 区间 $[1,3]$
- $(2,4)$: 区间 $[2,4]$
- $(3,1)$: 区间 $[1,3]$
- $(4,2)$: 区间 $[2,4]$
- $(2,2)$: 区间 $[2,2]$（正好在避难所上）
为了最大化进入人数，可将避难所按右端点贪心分配：$(2,2)$ 的幸存者进入 $(2,2)$；剩余区间中，$(1,3)$ 进入 $(1,1)$，$(3,1)$ 进入 $(3,3)$，$(2,4)$ 进入 $(4,4)$；$(4,2)$ 无法分配到避难所。共 `4` 人进入，为最大值。

## 样例4

**输入**

```
5 3
1 1
3 3
5 5
```

**输出**

```
3
```

**说明**

所有幸存者都恰好位于主对角线上的避难所位置。
- $(1,1)$ 的最近避难所就是自身，距离 $0$；
- $(3,3)$ 同样最近为自身；
- $(5,5)$ 也一样。
三名幸存者分别进入各自所在的避难所，互相不冲突，全部成功进入，答案为 `3`。
