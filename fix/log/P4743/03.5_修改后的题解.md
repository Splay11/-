## 解题思路

小蓝定义的数列生成规则为：从 $x = 1$ 开始，反复将 $x$ 更新为 $(x \times p) \bmod q$。由于 $x$ 的取值只有 $0$ 到 $q-1$ 这 $q$ 种可能，整个序列在更新足够多次后必然会进入循环。题目要求“无限次操作中一共会产生多少个不同的 $x$ 值”，这等价于从初始值 $1$ 开始，沿着更新规则一直走，直到第一次遇到之前出现过的值为止，其间访问过的不同值的个数。

具体模拟过程如下：

1. 维护一个布尔数组 `visited`（或等效的标记结构），用于记录某个值是否已经被访问过。
2. 将初始值设为 $x = 1$。
3. 重复以下步骤，直到当前 $x$ 已经出现在 `visited` 中：
   - 将当前 $x$ 标记为已访问；
   - 计数器加一；
   - 计算下一个值 $x \gets (x \times p) \bmod q$。
4. 循环结束时，计数器的值就是答案。

**边界情况处理**：当 $q = 1$ 时，$x$ 的取值范围只有 $0$。初始值 $1$ 虽然不在 $0$ 到 $q-1$ 中，但题目中“不同 $x$ 值”指的是在生成过程中实际出现过的值。此时序列为：$1$，然后 $(1 \times p) \bmod 1 = 0$，之后永远为 $0$，因此不同值的个数为 $2$。可在代码中对 $q = 1$ 直接返回 $2$，从而避免 $1$ 在访问标记数组时越界。

## 复杂度分析

设最终访问到的不同值个数为 $t$，显然 $t \le q$。

- 时间复杂度：$O(q)$，每个值最多被访问一次。
- 空间复杂度：$O(q)$，需要长度为 $q$ 的布尔数组记录访问状态。

## 代码实现

### Python

```python
def count_distinct_values(p: int, q: int) -> int:
    # 特判 q == 1，此时序列为 1, 0, 0, ... 共两个不同值
    if q == 1:
        return 2

    # visited[x] 表示值 x 是否已经出现过
    visited = [False] * q

    # 初始值 x = 1
    x = 1
    ans = 0

    # 模拟过程，直到遇到已经出现过的值
    while not visited[x]:
        visited[x] = True   # 标记当前值
        ans += 1            # 不同值个数加一
        x = (x * p) % q     # 按规则更新

    return ans


def main():
    # 读取输入
    p, q = map(int, input().split())
    # 输出答案
    print(count_distinct_values(p, q))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static int countDistinctValues(int p, int q) {
        // 特判 q == 1，此时序列为 1, 0, 0, ... 共两个不同值
        if (q == 1) {
            return 2;
        }

        // visited[x] 表示值 x 是否已经出现过
        boolean[] visited = new boolean[q];

        // 初始值 x = 1
        int x = 1;
        int ans = 0;

        // 模拟过程，直到遇到已经出现过的值
        while (!visited[x]) {
            visited[x] = true;            // 标记当前值
            ans++;                        // 不同值个数加一
            x = (int) ((long) x * p % q); // 按规则更新，用 long 防止溢出
        }

        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int p = sc.nextInt();
        int q = sc.nextInt();
        System.out.println(countDistinctValues(p, q));
        sc.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

int countDistinctValues(int p, int q) {
    // 特判 q == 1，此时序列为 1, 0, 0, ... 共两个不同值
    if (q == 1) {
        return 2;
    }

    // visited[x] 表示值 x 是否已经出现过
    vector<bool> visited(q, false);

    // 初始值 x = 1
    int x = 1;
    int ans = 0;

    // 模拟过程，直到遇到已经出现过的值
    while (!visited[x]) {
        visited[x] = true;               // 标记当前值
        ans++;                           // 不同值个数加一
        x = (int)((1LL * x * p) % q);     // 按规则更新，用 long long 防止溢出
    }

    return ans;
}

int main() {
    int p, q;
    cin >> p >> q;
    cout << countDistinctValues(p, q) << '\n';
    return 0;
}
```
