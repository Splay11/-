# 题目内容
超市一条货架上从左到右摆着 $n$ 件商品，第 $i$ 件的拣货优先级为整数 $a_i$。理货员至多可以把某一个连续区间 $[l,r]$ 整体倒序一次（也可以不操作），以便减少“左边优先级反而更高、拣货路径交叉”的情况。区间反转是指把 $[a_l,a_{l+1},\ldots,a_r]$ 变成 $[a_r,a_{r-1},\ldots,a_l]$；若 $l=r$ 则等价于不操作。

逆序对是满足 $1 \le i < j \le n$ 且 $a_i > a_j$ 的有序对数量（相等不计入）。请在至多一次区间反转后，使逆序对数量尽可能小，并输出该最小值。

约束：序列长度不超过 `2000`，每个元素为正整数且不超过 `1000000000`。

# 输入描述
第一行一个整数 $n$，表示货架上的商品件数。
第二行 $n$ 个整数 $a_1,a_2,\ldots,a_n$。
保证 $1 \le n \le 2000$，$1 \le a_i \le 1000000000$。

# 输出描述
输出一个整数，表示至多一次区间反转后可达的最小逆序对数。

## 样例1

**输入**

```
4
4 3 2 1
```

**输出**

```
0
```

**说明**

整段反转后得到 $1,2,3,4$，已完全有序，逆序对为 `0`。

## 样例2

**输入**

```
3
1 1 1
```

**输出**

```
0
```

**说明**

三个元素全相等，任何区间反转都不产生 $a_i>a_j$ 的对，答案为 `0`。

## 样例3

**输入**

```
6
5 1 4 2 8 3
```

**输出**

```
5
```

**说明**

反转区间 $[1,4]$ 得到 $2,4,1,5,8,3$，逆序对为 `5`。可以证明这是最小值。
