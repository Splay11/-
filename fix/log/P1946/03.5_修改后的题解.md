## 解题思路

1. 功能码兼容关系就是二进制下的超集关系：$x$ 兼容 $y$ 当且仅当 $y$ 的 `1` 位都是 $x$ 的 `1` 位，即 $y$ 是 $x$ 的子集。每个功能码都兼容自身，因此若某个 $w$ 在集合中存在真超集 $w'$，则选 $w'$ 一定能覆盖 $w$，不必再选 $w$。
2. 于是答案等于：去重后的功能码中，**不存在集合内真超集**的个数，也就是偏序下的极大元个数。
3. 值域为 $[0,2^{18})$，可以用子集 DP 判断「是否存在真超集」。令 $\textit{has}[x]$ 表示 $x$ 是否在输入中出现过，$\textit{dp}[x]$ 表示是否存在 $x$ 的真超集（出现在集合中，或该真超集自身还有超集）。
4. 从大到小枚举 $x$，对每一位 `0` 尝试把它翻成 `1` 得到 $x' = x\lor 2^j$，转移
   $$\textit{dp}[x]\ \leftarrow\ \textit{dp}[x]\ \lor\ \textit{dp}[x']\ \lor\ \textit{has}[x'].$$
   因为比 $x$ 大的数已经处理完，所有真超集的信息都会沿「恰好多一个 `1`」的边传到 $x$。
5. 对去重后的每个 $x$，若 $\textit{dp}[x]$ 为真则删去，剩下的个数就是答案。

## 复杂度分析

设功能码个数为 $n$，二进制位数 $B=18$，$U=2^B$。

- 时间复杂度：$O(UB + n)$。
- 空间复杂度：$O(U + n)$。

## 代码实现

### Python

```python
bit_len = 18
all_bits = 1 << bit_len

n = int(input())
arr = list(map(int, input().split()))

has_bits = [False] * all_bits
for x in arr:
    has_bits[x] = True

# dp[x]：是否存在 x 的真超集
dp = [False] * all_bits
for i in range(all_bits - 1, -1, -1):
    for j in range(bit_len):
        if i & (1 << j) == 0:
            dp[i] = dp[i] or dp[i | (1 << j)] or has_bits[i | (1 << j)]

unique = list(set(arr))
ans = len(unique)
for x in unique:
    if dp[x]:
        ans -= 1
print(ans)
```

### Java

```java
import java.util.HashSet;
import java.util.Scanner;
import java.util.Set;

public class Main {
    public static void main(String[] args) {
        int bitLen = 18;
        int allBits = 1 << bitLen;
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }

        boolean[] hasBits = new boolean[allBits];
        for (int x : arr) {
            hasBits[x] = true;
        }

        boolean[] dp = new boolean[allBits];
        for (int i = allBits - 1; i >= 0; i--) {
            for (int j = 0; j < bitLen; j++) {
                if ((i & (1 << j)) == 0) {
                    dp[i] = dp[i] || dp[i | (1 << j)] || hasBits[i | (1 << j)];
                }
            }
        }

        Set<Integer> unique = new HashSet<>();
        for (int x : arr) {
            unique.add(x);
        }
        int ans = unique.size();
        for (int x : unique) {
            if (dp[x]) {
                ans--;
            }
        }
        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <algorithm>
#include <cstdio>

using namespace std;

const int N = 200010;
const int U = 1 << 18;

int a[N];
bool hasBits[U], dp[U];

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
        hasBits[a[i]] = true;
    }

    for (int i = (1 << 18) - 1; i >= 0; i--) {
        for (int j = 0; j < 18; j++) {
            if ((i & (1 << j)) == 0) {
                dp[i] = dp[i] || dp[i | (1 << j)] || hasBits[i | (1 << j)];
            }
        }
    }

    sort(a + 1, a + n + 1);
    int m = unique(a + 1, a + n + 1) - a - 1;

    int ans = m;
    for (int i = 1; i <= m; i++) {
        if (dp[a[i]]) {
            ans--;
        }
    }
    printf("%d\n", ans);
    return 0;
}
```
