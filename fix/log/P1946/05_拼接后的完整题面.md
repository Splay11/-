# 题目内容
每台仪器的功能用一个非负整数刻画。将该整数写成二进制后，第 $i$ 位为 `1` 表示具备第 $i$ 项功能。

称功能码 $x$ **兼容**功能码 $y$，当且仅当 $(x \mid y) = x$，其中 $\mid$ 表示按位或。也就是说，$y$ 中所有为 `1` 的二进制位，在 $x$ 中也都为 `1`。任意功能码都兼容自身。

现有 $n$ 个功能码 $w_1,w_2,\ldots,w_n$。需要从中选出尽量少的功能码作为「基准机型」，使得每一个 $w_i$ 都被至少一个被选中的功能码兼容。

请输出最少需要选出多少个基准机型。

约束：功能码个数 $n$ 满足 $1 \le n \le 2 \times 10^5$，每个功能码 $w_i$ 满足 $0 \le w_i < 262144$。

# 输入描述
第一行输入一个正整数 $n$，表示功能码的个数，满足 $1 \le n \le 2 \times 10^5$。
第二行输入 $n$ 个整数 $w_1,w_2,\ldots,w_n$，表示各台仪器的功能码，满足 $0 \le w_i < 262144$。

# 输出描述
输出一行一个整数，表示最少需要选出的基准机型数量。

## 样例1

**输入**

```
1
3 7 6 8 4
```

**输出**

```
2
```

**说明**

按题意模拟计算得到。
