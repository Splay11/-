## 解题思路

本题要求在给定的 $n$ 首歌曲中选出恰好 $k$ 首，使得被选中次数最多的流派编号尽可能大。可以按以下步骤解决：

1. **统计频率**：统计曲库中每种流派编号的出现次数，形成「频率-编号」对。
2. **按频率升序排序**：将所有「频率-编号」对按频率从小到大排序，如果频率相同则编号任意排列。
3. **贪心判断**：从频率最小的流派开始遍历，维护变量 $t$ 表示已经“确定可以贡献”的歌曲总数。
   - 假设当前遍历到频率为 $L$、编号为 $R$ 的流派；
   - 还有 $cnt$ 个未处理的更大频率流派，它们每个流派最多可以提供 $L$ 首歌曲（因为当前频率 $L$ 是最小值，如果想让编号 $R$ 成为众数，其它流派至多选择 $L$ 首，否则会超过 $R$ 的频率）；
   - 因此最多能选到的总歌曲数为 $L + t + cnt \times L$（即当前流派的全部 $L$ 首、之前确定的 $t$ 首、剩余流派各选 $L$ 首）；
   - 如果这个总数 $\ge k$，说明存在一种选择方案使编号 $R$ 成为众数（出现次数最多），更新答案为 $\max(答案, R)$。
4. **更新已选数量**：将当前流派的频率 $L$ 累加到 $t$ 中，继续处理下一个频率更大的流派。
5. 遍历结束后，输出记录的最大流派编号。

**为什么这样判断？** 要使编号 $R$ 成为众数，它的出现次数必须 $\ge$ 其它任何流派。若当前频率 $L$ 是所有流派中第 $x$ 小的频率，则其它频率更大的流派最多只能选 $L$ 首（否则该流派的出现次数会超过 $L$，使 $R$ 不再是唯一众数）。因此，当频率升序排序后，依次检查每个流派是否可能成为众数，第一个满足条件的大频率编号未必最大，需要全部检查并取最大编号。

## 复杂度分析

- **时间复杂度**：统计频率需遍历 $n$ 首歌曲，复杂度 $O(n)$；设去重后的流派种类数为 $m$（$m \le n$），对 $m$ 个元素排序复杂度 $O(m\log m)$，总复杂度为 $O(n\log n)$。
- **空间复杂度**：需要哈希表存储频率，以及存储排序后的数组，总空间 $O(n)$。

## 代码实现

### Python

```python
from collections import Counter

T = int(input())
for _ in range(T):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    # 统计每个流派编号的出现次数
    freq = Counter(a)
    v = []
    for genre, cnt in freq.items():
        v.append((cnt, genre))
    
    # 按频率升序排序
    v.sort()
    
    t = 0          # 已经确定可以选入的歌曲数量
    res = 0        # 记录最大可行流派编号
    cnt = len(v)   # 未处理的流派数量
    
    for L, R in v:
        cnt -= 1
        # 当前流派选 L 首，之前已选 t 首，剩余 cnt 个流派各选最多 L 首
        if L + t + cnt * L >= k:
            res = max(res, R)
        t += L
    
    print(res)
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int T = scanner.nextInt();

        for (int tCase = 0; tCase < T; tCase++) {
            int n = scanner.nextInt();
            int k = scanner.nextInt();
            int[] a = new int[n];
            for (int i = 0; i < n; i++) {
                a[i] = scanner.nextInt();
            }

            // 统计频率
            Map<Integer, Integer> freqMap = new HashMap<>();
            for (int num : a) {
                freqMap.put(num, freqMap.getOrDefault(num, 0) + 1);
            }

            // 存储（频率, 流派编号）对
            List<int[]> list = new ArrayList<>();
            for (Map.Entry<Integer, Integer> entry : freqMap.entrySet()) {
                list.add(new int[]{entry.getValue(), entry.getKey()});
            }

            // 按频率升序排序
            list.sort(Comparator.comparingInt(o -> o[0]));

            long t = 0;               // 已确定可选入的歌曲数量
            int res = 0;
            int cnt = list.size();    // 剩余流派数量

            for (int[] pair : list) {
                int L = pair[0];
                int R = pair[1];
                cnt--;
                if (L + t + (long) cnt * L >= k) {
                    res = Math.max(res, R);
                }
                t += L;
            }

            System.out.println(res);
        }

        scanner.close();
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        int n, k;
        cin >> n >> k;
        vector<int> a(n);
        for (int i = 0; i < n; ++i) cin >> a[i];

        // 统计频率
        unordered_map<int, int> freq;
        for (int x : a) freq[x]++;

        // 存储（频率, 流派编号）对
        vector<pair<int, int>> v;
        for (auto &p : freq) {
            v.emplace_back(p.second, p.first);
        }

        // 按频率升序排序
        sort(v.begin(), v.end(),
             [](const pair<int, int>& x, const pair<int, int>& y) {
                 return x.first < y.first;
             });

        long long t = 0;         // 已确定可选入的歌曲总数
        int res = 0;
        int cnt = v.size();      // 剩余未处理的流派数

        for (auto &p : v) {
            int L = p.first;
            int R = p.second;
            cnt--;
            if (L + t + 1LL * cnt * L >= k) {
                res = max(res, R);
            }
            t += L;
        }

        cout << res << "\n";
    }

    return 0;
}
```
