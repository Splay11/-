# 题目内容
剧院检票系统只找回了一条长度为 $n$ 的座位号残片 $a_1,a_2,\ldots,a_n$，其中每个 $a_i$ 都是正整数。对每个前缀 $a_1,\ldots,a_i$，把它的元素集合 $S_i$ 补成某个排列 $\{1,2,\ldots,m\}$：必须有 $m$ 不小于 $S_i$ 中的任何元素，且插入尽可能少的缺失整数。系统要据此估计每个前缀至少还缺多少个座位号。

长度为 $m$ 的排列是 `1` 到 $m$ 各出现一次的序列。请对每个前缀输出最少需要插入的个数。

约束：序列长度不超过 `200000`，每个 $a_i$ 不超过 `1000000000`。

# 输入描述
第一行一个整数 $n$，表示残片长度。
第二行 $n$ 个整数 $a_1,a_2,\ldots,a_n$。
保证 $1 \le n \le 200000$，$1 \le a_i \le 1000000000$。

# 输出描述
输出一行 $n$ 个整数，第 $i$ 个数表示前缀 $a_1,\ldots,a_i$ 最少需要插入的元素个数。

## 样例1

**输入**

```
4
4 2 1 8
```

**输出**

```
3 2 1 4
```

**说明**

- 前缀 $\{4\}$：取 $m=4$，缺 `1,2,3`，插入 `3` 个。
- 前缀 $\{4,2\}$：取 $m=4$，缺 `1,3`，插入 `2` 个。
- 前缀 $\{4,2,1\}$：取 $m=4$，只缺 `3`，插入 `1` 个。
- 前缀 $\{4,2,1,8\}$：取 $m=8$，缺 `3,5,6,7`，插入 `4` 个。

## 样例2

**输入**

```
2
7 7
```

**输出**

```
6 6
```

**说明**

两个前缀的最大值都是 `7`，不同元素个数分别为 `1` 和 `1`（重复不增加），答案均为 $7-1=6$。

## 样例3

**输入**

```
6
2 5 2 1 9 3
```

**输出**

```
1 3 3 2 5 4
```

**说明**

对每个前缀用“当前最大值减去不同元素个数”得到插入数：`1`、`3`、`3`、`2`、`5`、`4`。
