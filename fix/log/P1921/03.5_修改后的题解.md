## 解题思路

1. **操作性质分析**  
   - 增加操作：对一个前缀加上同一个整数 $x$，不会改变该前缀内柱子之间的相对大小顺序。  
   - 取模操作：对一个前缀的所有高度取模 $x$，会使这些高度都严格小于 $x$。  
   - 因此，可以先利用取模将所有高度限制在一个很小的范围内，再利用增加操作构造出严格递减的最终高度。

2. **构造方案**  
   - 取 $x = 2$ 作为基准。  
   - **第一步**：对整个序列（前缀长度 $k = n$）执行取模操作，参数 $x = 2$。此时所有石柱的高度都变为 $0$ 或 $1$。  
   - **后续 $n-1$ 步**：依次对前缀长度 $k = 1, 2, \dots, n-1$ 执行增加操作，参数 $x = 2$。即第 $2$ 次操作：长度为 $1$ 的前缀加 $2$；第 $3$ 次操作：长度为 $2$ 的前缀加 $2$；……；第 $m$ 次操作：长度为 $n-1$ 的前缀加 $2$。

3. **正确性说明**  
   - 在上述操作下，第 $i$ 根柱子（$1 \le i \le n$）共经历了：  
     * 初始时的取模操作；  
     * 所有前缀长度 $\ge i$ 的增加操作，即从第 $i$ 次增加操作开始，每次都作用于它。  
   - 因此，第 $i$ 根柱子被增加操作的次数为 $n - i$ 次，每次增加 $2$。  
   - 最终高度 $H_i = (h_i \bmod 2) + 2 \times (n - i)$。  
   - 相邻高度之差为：  
     \[
     H_i - H_{i+1} = [\,(h_i \bmod 2) + 2(n-i)\,] - [\,(h_{i+1} \bmod 2) + 2(n-i-1)\,] = 2 + [(h_i \bmod 2) - (h_{i+1} \bmod 2)].
     \]
     由于括号内的差只能是 $-1,0,1$，故 $H_i - H_{i+1} \ge 2 - 1 = 1 > 0$，满足严格递减。

4. **操作次数**  
   - 总共执行 $1$ 次取模和 $n-1$ 次增加操作，总操作次数 $m = n$，满足 $0 \le m \le n$ 的限制。  
   - 当 $n = 1$ 时，仅输出取模操作（$m = 1$）或直接输出 $m = 0$ 均可，本题解采用前一种方式。

## 复杂度分析

- **时间复杂度**：$O(n)$。只需读取 $n$ 个初始高度，然后直接输出 $n$ 行操作，每行输出可在常数时间内完成。  
- **空间复杂度**：$O(1)$ 或 $O(n)$（存储初始数组）。如果仅为了输出方案，可以只记录 $n$ 而不使用高度数组，代码为简洁起见保留了存放初始高度的数组，空间复杂度为 $O(n)$。

## 代码实现

### Python

```python
n = int(input())
heights = list(map(int, input().split()))

# 总操作次数为 n
print(n)

# 第一步：对整个前缀取模 2
print(f"2 {n} 2")

# 后续 n-1 步：依次对前缀长度 1 到 n-1 加 2
for i in range(1, n):
    print(f"1 {i} 2")
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] heights = new int[n];
        for (int i = 0; i < n; i++) {
            heights[i] = sc.nextInt();
        }
        
        // 总操作次数为 n
        System.out.println(n);
        
        // 第一步：对整个前缀取模 2
        System.out.println("2 " + n + " 2");
        
        // 后续 n-1 步：依次对前缀长度 1 到 n-1 加 2
        for (int i = 1; i < n; i++) {
            System.out.println("1 " + i + " 2");
        }
        
        sc.close();
    }
}
```
