# 题目内容
建筑师小蓝有一排 $n$ 根石柱，从左到右高度为 $h_1, h_2, \dots, h_n$。他希望这些高度变得严格递减，即对于每个 $i$ ( $1 \le i < n$ )，满足 $h_i > h_{i+1}$。

小蓝可以进行两种操作，每种操作都作用于从最左端开始的连续若干根柱子（即一个前缀）：
1. 增加操作：选择一个前缀长度 $k$ 和一个整数 $x$ ($1 \le x \le 10^9$)，将该前缀内所有柱子的高度加上 $x$。
2. 取模操作：选择一个前缀长度 $k$ 和一个整数 $x$ ($1 \le x \le 10^9$)，将该前缀内所有柱子的高度对 $x$ 取模。

请你帮小蓝构造一组操作序列，使得在不超过 $n$ 次操作后，石柱的高度变为严格递减。题目保证存在合法方案。

约束条件：
- 柱子数量 $n$ 满足 $1 \le n \le 3000$。
- 初始高度 $h_i$ 满足 $1 \le h_i \le 10^5$。
- 每次操作中的参数 $x$ 满足 $1 \le x \le 10^9$。
- 操作总次数 $m$ 需满足 $0 \le m \le n$。
- 前缀长度 $k$ 满足 $1 \le k \le n$。

# 输入描述
第一行包含一个整数 $n$，表示石柱的数量。
第二行包含 $n$ 个整数 $h_1, h_2, \dots, h_n$，表示每根石柱的初始高度，相邻整数之间用一个空格分隔。

# 输出描述
第一行输出一个整数 $m$ ($0 \le m \le n$)，表示操作的总次数。若初始时已满足严格递减，则 $m = 0$。
接下来 $m$ 行，每行输出三个整数，依次表示操作类型（`1` 表示增加操作，`2` 表示取模操作）、前缀长度 $k$ 和参数 $x$，均为整数且用空格分隔。
如果有多种合法方案，输出任意一种即可。

## 样例1

**输入**

```
1
5
```

**输出**

```
0
```

**说明**

只有一根柱子，已经满足严格递减的条件，不需要进行任何操作，因此 $m = 0$。

## 样例2

**输入**

```
4
7 5 3 1
```

**输出**

```
0
```

**说明**

初始高度序列为 $7, 5, 3, 1$，满足 $7 > 5 > 3 > 1$，已经是严格递减的。操作次数 $m = 0$。

## 样例3

**输入**

```
3
1 1 1
```

**输出**

```
2
1 1 100
1 2 10
```

**说明**

初始序列为 $[1, 1, 1]$，不满足严格递减。通过两次增加操作进行构造：
1. 对前缀长度 $k=1$ 增加 $x=100$，序列变为 $[101, 1, 1]$；
2. 对前缀长度 $k=2$ 增加 $x=10$，序列变为 $[111, 11, 1]$。
最终序列 $111 > 11 > 1$，达成严格递减，操作次数 $m=2$，满足 $m \le n$。
