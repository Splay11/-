## 解题思路

本题需要模拟从左到右的处理过程，当前位置的变换规则取决于**左侧已完成部分**和**右侧未处理部分**中与当前字符相同的个数。

直接对每个位置暴力统计左右个数会导致 $O(n^2)$ 的时间复杂度，无法通过 $n$ 总和高达 $4\times 10^5$ 的数据范围。因此，我们使用两个计数数组来高效维护左右信息。

**核心思想**：

1. 用两个长度为 26 的整型数组 `leftCnt` 和 `rightCnt`，分别记录：
   - `leftCnt[k]`：已经处理完毕的左侧部分中，字母 `'a'+k` 出现的次数；
   - `rightCnt[k]`：尚未处理的右侧原始字符中，字母 `'a'+k` 出现的次数。

2. 初始状态：
   - `leftCnt` 全部为 0（左侧尚无任何已处理字符）；
   - 遍历整个原始字符串 $s$，将每个字符的出现次数累加到 `rightCnt` 中（此时右侧就是整个串）。

3. 从左到右依次处理每个字符 $c = s[i]$（$i$ 从 $0$ 开始）：
   - 当前字符 $c$ 处在“待处理”状态，即将被处理，它**不再属于右侧**。因此，先将 `rightCnt[c]` 减 $1$。此时 `rightCnt` 反映的是位置 $i+1$ 到 $n-1$ 的原始字符计数。
   - 现在左侧部分中等于 $c$ 的字符个数 $L = leftCnt[c]$。
   - 右侧部分中等于 $c$ 的字符个数 $R = rightCnt[c]$。
   - 判断：如果 $L = R$，则将 $c$ 替换为字母表上的下一个字母（`'z'` 的下一个字母为 `'a'`），得到新字符 $nc$；否则 $nc = c$（保持不变）。
   - 将 $nc$ 作为该位置的最终结果，拼接到答案字符串中。
   - 将 $nc$ 计入左侧：`leftCnt[nc]` 加 $1$，表示它已经成为已处理部分的一员，供后续位置使用。

4. 处理完所有字符后，输出拼接得到的完整字符串。

该算法保证了每位处理只需 $O(1)$ 时间，总复杂度与字符串长度成正比。

## 复杂度分析

设单个测试用例的字符串长度为 $n$，所有测试用例的长度之和为 $N$（题目保证 $N \le 4\times 10^5$）。

- **时间复杂度**：$O(n)$（每个字符访问常数次），所有测试用例总计 $O(N)$。  
  用 $O(N)$ 表示：$O\left(\sum n\right)$。
- **空间复杂度**：$O(1)$。我们只使用了两个固定大小的计数数组（大小为 $26$），不随 $n$ 增长。
  辅助数组和答案字符串的空间属于必要输出存储，不计入额外空间复杂度，因此整体额外空间为常数级。

## 代码实现

### Python

```python
import sys

def solve_one(n: int, s: str) -> str:
    # rightCnt 统计当前位右侧尚未处理的原始字符数量
    right_cnt = [0] * 26
    for ch in s:
        right_cnt[ord(ch) - ord('a')] += 1

    # leftCnt 统计左侧已确定的最终字符数量
    left_cnt = [0] * 26

    ans = []

    for ch in s:
        idx = ord(ch) - ord('a')

        # 当前字符即将被处理，不再属于右侧，先减去
        right_cnt[idx] -= 1

        # 左侧该字符个数 L 和右侧该字符个数 R
        L = left_cnt[idx]
        R = right_cnt[idx]

        if L == R:
            new_idx = (idx + 1) % 26   # 字母表循环
        else:
            new_idx = idx

        ans.append(chr(new_idx + ord('a')))
        # 最终字符计入左侧
        left_cnt[new_idx] += 1

    return ''.join(ans)

def main():
    data = sys.stdin.read().split()
    t = int(data[0])
    pos = 1
    out_lines = []
    for _ in range(t):
        n = int(data[pos]); pos += 1
        s = data[pos]; pos += 1
        out_lines.append(solve_one(n, s))
    sys.stdout.write('\n'.join(out_lines))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class Main {
    public static String solveOne(int n, String s) {
        // rightCnt 统计当前位右侧尚未处理的原始字符数量
        int[] rightCnt = new int[26];
        for (int i = 0; i < n; i++) {
            rightCnt[s.charAt(i) - 'a']++;
        }

        // leftCnt 统计左侧已确定的最终字符数量
        int[] leftCnt = new int[26];

        StringBuilder ans = new StringBuilder();

        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);
            int idx = ch - 'a';

            // 当前字符即将被处理，不再属于右侧，先减去
            rightCnt[idx]--;

            int L = leftCnt[idx];
            int R = rightCnt[idx];

            int newIdx;
            if (L == R) {
                newIdx = (idx + 1) % 26;   // 字母表循环
            } else {
                newIdx = idx;
            }

            ans.append((char) ('a' + newIdx));
            // 最终字符计入左侧
            leftCnt[newIdx]++;
        }

        return ans.toString();
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int t = Integer.parseInt(br.readLine().trim());
        StringBuilder out = new StringBuilder();

        for (int i = 0; i < t; i++) {
            int n = Integer.parseInt(br.readLine().trim());
            String s = br.readLine().trim();
            out.append(solveOne(n, s)).append('\n');
        }

        System.out.print(out);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

string solveOne(int n, const string& s) {
    // rightCnt 统计当前位右侧尚未处理的原始字符数量
    vector<int> rightCnt(26, 0);
    for (char ch : s) {
        rightCnt[ch - 'a']++;
    }

    // leftCnt 统计左侧已确定的最终字符数量
    vector<int> leftCnt(26, 0);

    string ans;
    ans.reserve(n);

    for (char ch : s) {
        int idx = ch - 'a';

        // 当前字符即将被处理，不再属于右侧，先减去
        rightCnt[idx]--;

        int L = leftCnt[idx];
        int R = rightCnt[idx];

        int newIdx;
        if (L == R) {
            newIdx = (idx + 1) % 26;   // 字母表循环
        } else {
            newIdx = idx;
        }

        ans.push_back(char('a' + newIdx));
        // 最终字符计入左侧
        leftCnt[newIdx]++;
    }

    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;

    while (t--) {
        int n;
        string s;
        cin >> n >> s;
        cout << solveOne(n, s) << '\n';
    }

    return 0;
}
```
