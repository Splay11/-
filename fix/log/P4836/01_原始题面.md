# 链路标签轮询校正

# 题目内容

链路侧收到一条由小写字母组成的标签串，需从左到右逐位校正。

处理到第 $i$ 位时，左侧 $1\sim i-1$ 已是最终字符，右侧 $i+1\sim len$ 仍为原始字符。

对每一位执行一次：

- 记当前位字符为 $glyph$（处理前）；
- 记 $leftCnt$ 为左侧已处理字符中等于 $glyph$ 的个数；
- 记 $rightCnt$ 为右侧未处理原串中等于 $glyph$ 的个数；
- 若 $leftCnt = rightCnt$，将当前位改为字典序下一个小写字母（`'z'` 变为 `'a'`）；
- 否则保持不变。

输出校正后的完整标签串。

# 输入描述

每个测试文件包含多组测试数据。

1. 第一行一个整数 $tc$（$1 \le tc \le 2 \times 10^5$），表示测试组数。
2. 每组数据两行：
   - 第一行整数 $len$，为标签串长度；
   - 第二行长度为 $len$ 的字符串 $tag$，仅含小写英文字母。
3. 单个测试文件中所有 $len$ 之和不超过 $4 \times 10^5$。

# 输出描述

每组测试数据输出一行，为校正后的标签串 $tag$。

## 样例1

**输入**

```
2
1
b
3
cdc
```

**输出**

```
c
cec
```

**说明**

- 组 1：仅一位 `'b'`，左右计数均为 $0$，变为 `'c'`。
- 组 2：三位依次校正，最终为 `"cec"`。
