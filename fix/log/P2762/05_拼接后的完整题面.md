# 题目内容
考古学家在遗迹中发现了一排共 $n$ 块符文石，每块石头拥有一个整数能量值。他们可以随意重新排列这些石头的顺序（进行任意次两两交换，也可以不交换），随后将执行一种名为“共鸣”的操作。

一次共鸣操作定义为：选取**相邻**的两块石头，让它们产生共鸣。共鸣后，能量较低的那块石头会粉碎消失，能量较高的那块石头保留在原位，且能量值不变。这次操作的代价等于被保留石头（即两者中能量较高者）的能量值。共鸣后，石头的总数量减少 $1$。

整个仪式需要恰好执行 $n-1$ 次共鸣操作，直到现场仅剩一块石头。

请设计一种交换策略以及随后的共鸣顺序，使得所有共鸣操作的总代价最小。你需要求出这个最小的总代价。

**约束条件**
- 石头的数量 $n$ 满足 $1 \le n \le 10^5$。
- 每块石头的初始能量值为整数，且 $1 \le a_i \le 10^9$。

# 输入描述
第一行输入一个整数 $n$，表示石头的数量。
第二行输入 $n$ 个用空格分隔的整数，依次表示每块石头的初始能量值。

# 输出描述
输出一个整数，表示所有共鸣操作的最小总代价。若 $n=1$，则不需要任何操作，总代价为 $0$。

## 样例1

**输入**

```
5
4 1 3 2 5
```

**输出**

```
14
```

**说明**

可以通过重新排列将石头按能量从小到大排序为 $1, 2, 3, 4, 5$。根据最优策略，先合并 $1$ 与 $2$（代价 $2$，剩下 $2,3,4,5$），再合并 $2$ 与 $3$（代价 $3$，剩下 $3,4,5$），接着合并 $3$ 与 $4$（代价 $4$），最后合并 $4$ 与 $5$（代价 $5$）。总代价为 $2+3+4+5=14$，恰好等于排序后除最小元素外所有元素之和。

## 样例2

**输入**

```
1
42
```

**输出**

```
0
```

**说明**

只有 $1$ 块石头，能量值为 $42$。此时 $n=1$，不需要进行任何共鸣操作，总代价为 $0$。

## 样例3

**输入**

```
4
10 10 10 10
```

**输出**

```
30
```

**说明**

所有石头能量相等，排列任意。共需 $3$ 次合并，每次代价均为 $10$，总代价为 $10+10+10=30$。排序后数组为 $[10,10,10,10]$，除第一个元素外其余元素之和也为 $30$，符合题解公式。
