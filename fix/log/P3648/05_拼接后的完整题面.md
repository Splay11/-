# 题目内容
在一条自动化生产线上，希望通过传感器数据判断产品是否合格。你得到了两组数据：一组是已知合格产品的测量值（校准集），另一组是待判定的产品测量值（检测集）。每个样本由若干个实数特征表示。

请实现一种基于重构误差的状态判定算法，具体流程如下：
1. 将校准集与检测集按行拼接，然后对每个特征进行标准化处理，使每个特征列均值为 $0$、方差为 $1$。
2. 在标准化后的全体数据上，使用奇异值分解（SVD）提取第一个主成分（保留成分个数为 $1$，随机种子固定为 $42$），得到投影方向。将所有样本投影到该方向后，再反变换回原标准化空间，获得重构值。
3. 在标准化空间中，对校准集部分的每个样本计算重构误差：$e_i = \sum_j (z_{ij} - \hat{z}_{ij})^2$。
4. 取校准集全部样本重构误差的第 $95$ 百分位数作为阈值 $T$。
5. 对于检测集的每个样本，利用相同的标准化参数和投影方向计算其在标准化空间中的重构值及对应的重构误差 $e$。若 $e \le T$ 则判定为合格（输出 $0$），否则判定为不合格（输出 $1$）。

限制条件：
- 校准集和检测集的样本总数不超过 $2 \times 10^4$。
- 每个样本的特征维度 $d$ 满足 $2 \le d \le 100$。
- 所有数值均为绝对值不超过 $10^9$ 的实数。

# 输入描述
标准输入仅有一行，包含一个 JSON 对象，该对象拥有两个键：`"train"` 对应校准集，其值为二维数值列表；`"test"` 对应检测集，其值为与校准集具有相同特征维度的二维数值列表。特征维度至少为 $2$。所有值均为整数或浮点数。

# 输出描述
输出一行，一个 JSON 数组，元素仅为 $0$ 或 $1$，长度等于检测集样本数量，顺序与输入中检测集保持一致。$0$ 表示该样本被判定为合格，$1$ 表示不合格。

## 样例1

**输入**

```
{"train":[[0,0],[2,2]],"test":[[1,1]]}
```

**输出**

```
[0]
```

**说明**

校准集仅包含 `[[0,0],[2,2]]`，检测集包含 `[[1,1]]`。将两者按行拼接后，所有点均落在同一直线 $y=x$ 上。经过标准化，数据的协方差结构使得 PCA 的第一主成分方向恰为该直线方向。所有样本在该方向上投影并反变换回标准化空间后，重构值与原始值完全一致，每一个样本的重构误差 $e_i=\sum_j (z_{ij}-\hat{z}_{ij})^2$ 均为 `0`。

取校准集两个零误差的第 $95$ 百分位数，阈值 $T = 0$。检测样本的重构误差同样为 `0`，满足 $e \le T$，故判定为合格，输出 `[0]`。

## 样例2

**输入**

```
{"train":[[0,0],[2,2]],"test":[[0,2]]}
```

**输出**

```
[1]
```

**说明**

校准集为 `[[0,0],[2,2]]`，检测集为 `[[0,2]]`。三个样本中，前两个位于直线 $y=x$ 上，第三个 `[0,2]` 偏离该直线。

拼接后，每列均值分别为 $\frac{2}{3}$ 与 $\frac{4}{3}$，标准差均为 $\sqrt{\frac{8}{9}}$。标准化后进行 PCA，第一主成分方向为 $[1/\sqrt{2},\, 1/\sqrt{2}]$。校准集两个样本的重构误差均为 $\frac{1}{4}$，因此取第 $95$ 百分位数得到阈值 $T = \frac{1}{4}$。

检测样本 `[0,2]` 在标准化空间中对应的重构误差为 $1$，大于阈值 $T$，故判定为不合格，输出 `[1]`。

## 样例3

**输入**

```
{"train":[[0,0],[2,2]],"test":[[1,1],[0,2]]}
```

**输出**

```
[0, 1]
```

**说明**

校准集与上例相同，检测集包含两个样本： `[1,1]` 位于直线 $y=x$ 上，`[0,2]` 偏离该直线。

四个样本拼接后标准化，PCA 的第一主成分方向仍为 $[1/\sqrt{2},\, 1/\sqrt{2}]$。在标准化空间中，校准集两个样本的重构误差均为 $\frac{2}{11}$，阈值 $T = \frac{2}{11}$。

检测样本 `[1,1]` 的重构误差为 $\frac{2}{11}$，满足 $e \le T$，判定为合格（`0`）；`[0,2]` 的重构误差为 $\frac{18}{11}$，远大于 $T$，判定为不合格（`1`）。最终输出 `[0, 1]`。
