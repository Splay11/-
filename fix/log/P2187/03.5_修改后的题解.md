## 解题思路

1. 设灯牌上当前字母序列为 $s$，长度为 $n$。第 $i$ 次操作（$i$ 从 `1` 开始）需要把**当前第 $i$ 个位置**的字母接到序列末尾。
2. 直接用数组删除并拼接的朴素模拟代价过高。可以换一种等价实现：不真正删除已被取走的字母，只把该位置标记为已失效，同时把取走的字母追加到序列末尾。有效字母按从左到右的顺序，就是当前灯牌上的真实排列。
3. 用指针 `pos` 指向当前要取走的字母。每次操作：
   - 把 $s[\textit{pos}]$ 追加到序列末尾；
   - 将 $s[\textit{pos}]$ 标记为失效；
   - 若还未做完 $n$ 次，则从当前位置向右扫描，跳过已失效位置，直到又遇到 `2` 个仍然有效的字母，停在第 `2` 个上。这是因为：取走当前第 $i$ 个有效字母后，新序列中下一次要取的是第 $i+1$ 个位置，相当于在「剩余有效字母」上再往右数一个。
4. 指针 `pos` 只会向右移动，总共移动 $O(n)$ 次，因此整场模拟是线性的。最后按顺序输出所有未被标记的字母即可。

## 复杂度分析

设字符串长度为 $n$。指针只增不减，每轮追加一个字符：

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
def main():
    s = list(input().strip())
    n = len(s)
    pos = 0

    for i in range(n):
        # 把当前要取走的字母接到末尾
        s.append(s[pos])
        # 标记原位置已失效
        s[pos] = '?'
        if i == n - 1:
            break

        # 向右找到下一个应被取走的有效位置
        c = 0
        while c < 2:
            if s[pos] != '?':
                c += 1
            pos += 1
            if c == 2:
                pos -= 1
                break

    print(''.join(ch for ch in s if ch != '?'))


if __name__ == '__main__':
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String raw = scanner.nextLine().trim();
        int n = raw.length();

        char[] s = new char[2 * n];
        for (int i = 0; i < n; i++) {
            s[i] = raw.charAt(i);
        }
        int len = n;
        int pos = 0;

        for (int i = 0; i < n; i++) {
            s[len++] = s[pos];
            s[pos] = '?';
            if (i == n - 1) {
                break;
            }

            int c = 0;
            while (c < 2) {
                if (s[pos] != '?') {
                    c++;
                }
                pos++;
                if (c == 2) {
                    pos--;
                    break;
                }
            }
        }

        StringBuilder result = new StringBuilder();
        for (int i = 0; i < len; i++) {
            if (s[i] != '?') {
                result.append(s[i]);
            }
        }
        System.out.println(result.toString());
    }
}
```

    int n = (int)s.size();
    int pos = 0;

    for (int i = 0; i < n; i++) {
        s.push_back(s[pos]);
        s[pos] = '?';
        if (i == n - 1) {
            break;
        }

        int c = 0;
        while (c < 2) {
            c += (s[pos] != '?');
            pos++;
            if (c == 2) {
                pos--;
                break;
            }
        }
    }

    for (char ch : s) {
        if (ch != '?') {
            cout << ch;
        }
    }

}
