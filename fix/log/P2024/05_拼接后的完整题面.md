# 题目内容
有 $n$ 台主机，第 $i$ 台的算力为 $w_i$。初始时每台主机自成一个集群，集群的规模等于其中所有主机的算力之和。

共发生 $m$ 次并网：在时刻 $t$，把给定的若干台主机所在的集群合并成一个。共有 $q$ 次询问：在时刻 $t$ 询问某台主机当前所在集群的规模。

同一时刻若既有并网又有询问，先完成该时刻的全部并网，再回答询问。

主机编号从 `1` 开始。主机数不超过 `10^5` 且至少为 `1`，并网次数与询问次数均不超过 `10^5` 且可以为 `0`。算力与时刻均为不超过 `10^9` 的非负整数。每次并网至少涉及 `1` 台主机。

# 输入描述
第一行包含三个整数 $n$、$m$ 和 $q$（$1 \le n \le 10^5$，$0 \le m,q \le 10^5$），分别表示主机个数、并网次数和询问次数。
第二行包含 $n$ 个非负整数 $w_1, w_2, \ldots, w_n$（$0 \le w_i \le 10^9$），表示各主机的算力。
接下来 $m$ 行，每行首先是并网时刻 $t$（$0 \le t \le 10^9$）和本次连接的主机个数 $c$（$c \ge 1$），随后 $c$ 个整数表示这些主机的编号。
接下来 $q$ 行，每行两个整数 $t$ 和 $x$（$0 \le t \le 10^9$，$1 \le x \le n$），表示在时刻 $t$ 询问编号为 $x$ 的主机所在集群的规模。

# 输出描述
输出 $q$ 行，每行一个整数，依次给出每个询问的答案。

## 样例1

**输入**

```
5 3 3
1 2 3 4 5
1 2 1 3
3 2 2 5
6 2 3 4
1 1
7 3
5 2
```

**输出**

```
4
8
7
```

**说明**

时刻 `1` 合并主机 `1` 与 `3`，规模为 $1+3=`4`$；此时询问主机 `1`，答案为 `4`。
时刻 `3` 合并 `2` 与 `5`，规模为 $2+5=`7`$。时刻 `5` 询问主机 `2`，答案为 `7`。
时刻 `6` 把主机 `3` 所在集群与 `4` 合并，规模为 $1+3+4=`8`$；时刻 `7` 询问主机 `3`，答案为 `8`。

## 样例2

**输入**

```
3 1 2
10 20 30
5 2 1 2
4 1
6 3
```

**输出**

```
10
30
```

**说明**

时刻 `4` 尚无并网，主机 `1` 规模为 `10`。
时刻 `5` 合并 `1` 与 `2` 后，主机 `3` 仍独自成簇，时刻 `6` 询问主机 `3` 得到 `30`。

## 样例3

**输入**

```
2 0 2
7 8
1 1
1 2
```

**输出**

```
7
8
```

**说明**

没有并网事件，两台主机始终各自成簇，询问结果分别是 `7` 与 `8`。
