# 题目内容
给定一个 $n$ 行 $m$ 列的网格。每个格子有两种状态：`R` 表示该格子为激活态，`W` 表示该格子为未激活态。

现在进行以下操作：等概率随机选择一个格子，将其状态变为激活态（若本来已是激活态，则不做任何改变）。

我们称两个激活态格子连通，当且仅当它们共用一条边。一个激活连通片定义为由彼此连通的激活态格子构成的极大集合。

你需要计算操作完成后，激活连通片数量的期望值。可以证明，该期望是一个有理数。请你输出它对 $10^9+7$ 取模的结果。

分数取模定义：若期望为 $E = \frac{a}{b}$，求一个整数 $x$ 满足 $x \cdot b \equiv a \pmod{10^9+7}$ 且 $0 \le x < 10^9+7$，该 $x$ 即为输出的结果。

约束：行数 $n$ 和列数 $m$ 均不小于 $1$，且均不超过 $10^3$。

# 输入描述
第一行包含两个正整数 $n$ 和 $m$，用空格隔开。
接下来的 $n$ 行，每行包含一个长度为 $m$ 的字符串，字符串仅由字符 `R` 和 `W` 组成。`R` 表示该格子初始为激活态，`W` 表示该格子初始为未激活态。

# 输出描述
输出一个整数，表示操作后激活连通片数量的期望对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
1 2
RW
```

**输出**

```
1
```

**说明**

总格子数 $N=2$，初始连通片数 $C_0=1$，未激活格子数 $W=1$。唯一的未激活格子位于第 `1` 行第 `2` 列，其相邻激活格子仅有左边一个，因此 $k=1$，$\sum k=1$。期望 $E = \frac{2\times 1 + 1 - 1}{2} = 1$。无论选中哪个格子，操作后连通片数均为 `1`，故期望为 `1`，取模后仍为 `1`。

## 样例2

**输入**

```
3 1
R
W
R
```

**输出**

```
666666673
```

**说明**

$N=3$，初始有两个不连通的 `R`，$C_0=2$；$W=1$。中间的 `W` 格子上下相邻两个不同的连通片，因此 $k=2$，$\sum k=2$。期望 $E = \frac{3\times 2 + 1 - 2}{3} = \frac{5}{3}$。对 $10^9+7$ 取模，$3$ 的逆元为 $333333336$，$5 \times 333333336 \bmod (10^9+7) = 666666673$。

## 样例3

**输入**

```
2 2
RW
WR
```

**输出**

```
500000005
```

**说明**

总格子 $N=4$，初始有两个 `R` 在対角，互不连通，$C_0=2$；未激活格子 $W=2$。位于 `(1,2)` 和 `(2,1)` 的每个 `W` 都恰好与两个不同连通片的 `R` 相邻，故 $k=2$，$\sum k=4$。期望 $E = \frac{4\times 2 + 2 - 4}{4} = \frac{3}{2}$。对 $10^9+7$ 取模，$2$ 的逆元为 $500000004$，$3 \times 500000004 \bmod (10^9+7) = 500000005$。

## 样例4

**输入**

```
2 3
RWR
WRW
```

**输出**

```
500000006
```

**说明**

$N=6$，初始有三个 `R` 分别位于 `(1,1)`、`(1,3)`、`(2,2)`，互不连通，$C_0=3$；$W=3$。三个 `W` 每个都恰好与两个不同连通片的 `R` 相邻，$k=2$，$\sum k=6$。期望 $E = \frac{6\times 3 + 3 - 6}{6} = \frac{15}{6} = \frac{5}{2}$。对 $10^9+7$ 取模，结果为 $5 \times 500000004 \bmod (10^9+7) = 500000006$。
