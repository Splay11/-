# 题目内容
园区闸机按二进制校验规则发放当日通行编号。系统把正整数写成不含前导 `0` 的二进制；若其中数字 `1` 的个数与数字 `0` 的个数相等，则称该编号为**均衡号**。安保规程要求：给定整数 $x$，必须分配一个不小于 $x$ 的最小均衡号。请对每组询问求出该编号。

约束：测试组数不超过 `100000`，每组 $1 \le x \le 1000000000$。

# 输入描述
第一行一个整数 $T$，表示测试组数。
接下来 $T$ 行，每行一个整数 $x$。
保证 $1 \le T \le 100000$，$1 \le x \le 1000000000$。

# 输出描述
对每组数据输出一行一个整数，表示不小于 $x$ 的最小均衡号。

## 样例1

**输入**

```
4
7
16
32
100
```

**输出**

```
9
35
35
135
```

**说明**

$x=`7`$（`111`）长度为奇数，下一偶数长度最小均衡数为 `9`（`1001`）；$x=`16`,`32`$ 同长度无解或需扩到长度 `6`，答案均为 `35`（`100011`）；$x=`100`$ 答案为 `135`。

## 样例2

**输入**

```
3
11
35
64
```

**输出**

```
12
35
135
```

**说明**

$x=`11`$（`1011`）同长度下最小合法均衡数为 `12`（`1100`）；$x=`35`$ 本身已是均衡数；$x=`64`$ 长度为奇数，答案为长度 `8` 的最小均衡数 `135`。
