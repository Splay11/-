# 题目内容
给定 $n$ 个整数 $a_1,a_2,\dots,a_n$。若两个下标 $i
eq j$ 满足 $a_i+a_j$ 是“纯元数”，则在 $i$ 与 $j$ 之间连一条无向边，边权为 $a_i+a_j$。这里一个正整数被称为纯元数，当且仅当它大于 $1$ 且除 $1$ 和自身外没有其他正因子。

图中所有边均按上述规则生成，图可能由多个连通分量构成。现只考虑点数（即包含的节点数目）最多的连通分量：若这样的连通分量有多个，则对每一个都分别求一棵连通树，使得在该连通分量内所有节点连通且无环，并希望所选边的权值总和尽可能小。你需要输出这些连通分量各自的最小边权和中的最小值。保证每个连通分量都存在至少一棵连通树。

数据范围：$n$ 不超过 `10^3`，每个 $a_i$ 均为整数且满足 $0\le a_i\le 10^6$。

# 输入描述
第一行包含一个整数 `n`，表示整数的个数。
第二行包含 `n` 个整数 $a_1,a_2,\dots,a_n$，相邻整数之间用空格分隔。

# 输出描述
输出一个整数，表示点数最多的连通分量中，连通树的最小边权总和。

## 样例1

**输入**

```
4
2 3 5 7
```

**输出**

```
12
```

**说明**

数组 `2, 3, 5, 7`。检查两数和：$2+3=5$ 是素数，$2+5=7$ 是素数，其余和（$2+7=9$，$3+5=8$，$3+7=10$，$5+7=12$）均不是素数。因此图中只在 $(2,3)$ 与 $(2,5)$ 之间连边，边权分别为 `5` 和 `7`。节点 `2, 3, 5` 连通形成一个大小为 `3` 的连通分量，节点 `7` 孤立。点数最多的连通分量为 $\{2,3,5\}$，其中的最小生成树必须包含两条边，权值和为 $5+7=12$。输出 `12`。

## 样例2

**输入**

```
1
0
```

**输出**

```
0
```

**说明**

只有一个整数 `0`，图中没有边。唯一的节点自成一个连通分量，点数为 `1`，这也是点数最多的连通分量。该连通树没有边，边权总和为 `0`。输出 `0`。

## 样例3

**输入**

```
4
0 2 6 25
```

**输出**

```
2
```

**说明**

数组 `0, 2, 6, 25`。两数和为素数的情况有：$0+2=2$（素数），$6+25=31$（素数）。其余组合如 $0+6=6$，$0+25=25$，$2+6=8$，$2+25=27$ 均不是素数。图中形成两个连通分量：$\{0,2\}$ 和 $\{6,25\}$，两者点数均为 `2`，都是点数最多的连通分量。对 $\{0,2\}$ 求最小生成树，唯一边权为 `2`，总和 `2`；对 $\{6,25\}$ 求最小生成树，边权 `31`，总和 `31`。取最小值即为 `2`。输出 `2`。
