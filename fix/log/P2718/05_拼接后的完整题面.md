# 题目内容
给定两个长度均为 $n$ 的二进制序列 $P$ 和 $Q$，序列中的元素仅包含 $0$ 或 $1$。

构造一个 $n \times n$ 的矩阵 $G$，其中第 $i$ 行第 $j$ 列的元素定义为 $G[i][j] = P_i \oplus Q_j$（$\oplus$ 表示按位异或运算）。

现需要计算矩阵 $G$ 中所有可能的子矩阵的元素值之和。一个子矩阵是指由矩阵中连续若干行与连续若干列相交所构成的区域。由于答案可能很大，请输出结果对 $10^9+7$ 取模后的值。

约束条件：序列长度 $n$ 不超过 $2 \times 10^5$，序列中的所有元素均为 $0$ 或 $1$。

# 输入描述
第一行包含一个整数 $n$，表示序列的长度。
第二行包含 $n$ 个用空格分隔的整数，表示序列 $P$ 的每个元素。
第三行包含 $n$ 个用空格分隔的整数，表示序列 $Q$ 的每个元素。

# 输出描述
输出一个整数，表示所有子矩阵元素之和对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
1
0
0
```

**输出**

```
0
```

**说明**

矩阵 $G$ 仅有一个元素 $G[1][1] = P_1 \oplus Q_1 = 0 \oplus 0 = `0`$。所有子矩阵仅有 $1$ 个，其和为 `0`。

## 样例2

**输入**

```
2
1 0
1 1
```

**输出**

```
8
```

**说明**

首先计算每个位置的行权重 $W_i = i \times (n - i + 1)$ 和列权重 $V_j = j \times (n - j + 1)$。对于 $n=2$，$W = [2, 2]$，$V = [2, 2]$。
矩阵 $G$ 的元素：$G[1][1] = 1 \oplus 1 = `0`$，$G[1][2] = 1 \oplus 1 = `0`$，$G[2][1] = 0 \oplus 1 = `1`$，$G[2][2] = 0 \oplus 1 = `1`$。
总贡献为 $0 \times 2 \times 2 + 0 \times 2 \times 2 + 1 \times 2 \times 2 + 1 \times 2 \times 2 = 8$。

## 样例3

**输入**

```
3
1 1 0
0 0 1
```

**输出**

```
58
```

**说明**

行权重 $W = [1\times3, 2\times2, 3\times1] = [3, 4, 3]$，列权重 $V = [3, 4, 3]$。
矩阵 $G$ 的元素：
第 $1$ 行：$1\oplus0=`1`$, $1\oplus0=`1`$, $1\oplus1=`0`$；
第 $2$ 行：$1\oplus0=`1`$, $1\oplus0=`1`$, $1\oplus1=`0`$；
第 $3$ 行：$0\oplus0=`0`$, $0\oplus0=`0`$, $0\oplus1=`1`$。
总贡献为 $1\times3\times3 + 1\times3\times4 + 0 + 1\times4\times3 + 1\times4\times4 + 0 + 0 + 0 + 1\times3\times3 = 9+12+12+16+9 = 58$。

## 样例4

**输入**

```
4
1 0 1 0
0 1 0 1
```

**输出**

```
200
```

**说明**

行权重 $W = [4, 6, 6, 4]$，列权重 $V = [4, 6, 6, 4]$。
序列 $Q$ 中，值为 `0` 的列有 $1,3$，其 $V$ 之和为 $4+6=10$；值为 `1` 的列有 $2,4$，其 $V$ 之和为 $6+4=10$。
当 $P_i = `1`$ 时，只有与 $Q_j = `0`$ 的列异或才得 `1`；当 $P_i = `0`$ 时，与 $Q_j = `1`$ 的列异或得 `1`。因此总贡献为：$\sum_{i: P_i=1} W_i \times 10 + \sum_{i: P_i=0} W_i \times 10 = (4+6)\times 10 + (6+4)\times 10 = 100 + 100 = 200$。
