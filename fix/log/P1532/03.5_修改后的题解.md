## 解题思路

我们需要在 $n$ 个标记互不相同的节点之间连尽可能多的无向边，且图中不能出现三个不同节点 $u,v,w$ 满足 $a_u \le a_v \le a_w$ 且 $u$ 与 $v$ 相连、$v$ 与 $w$ 相连。

**关键观察**：  
- 若存在一条边连接标记为 $x$ 和 $y$ 的节点且 $x \le y$，则标记为 $y$ 的节点不能再与任何标记 $\le y$ 的其他节点相连，否则会立刻形成 $x \le y \le z$ 的连通三元组。  
- 这等价于：我们可以将所有节点按标记值的大小分成两个集合 $L$ 和 $R$，要求 $L$ 中所有标记严格小于 $R$ 中所有标记，并且**所有边都只能连接 $L$ 和 $R$ 中的节点**（即完全二分图）。此时任意边的一个端点属于 $L$，另一个属于 $R$，不会出现中间节点同时连接两边的情况。  
- 标记值相同的节点必须被完整地划分到同一侧（不能拆分），否则同一标记值的节点若分在两边，会存在 $a_u = a_v$ 且 $a_u \le a_v \le a_w$ 的可能，破坏限制。

**算法步骤**：
1. 将 $n$ 个标记 $a_1, a_2, \dots, a_n$ **从小到大排序**。  
2. 遍历排序后的数组，将相同标记值的节点视为一个完整的块。对于每一个块的**右边界**（即下一个不同标记值的起始下标 $j$），考虑以 $j$ 为分割点：左边包含前 $j$ 个节点，右边包含剩余的 $n-j$ 个节点。此时左边所有标记均小于右边所有标记，满足条件。  
3. 计算该分割方式下的最大可能边数 $j \times (n-j)$，并用它更新答案。  
4. 特殊情况：当所有标记值都相同时，无法分出 $L,R$，此时最多能构成的边是一个匹配，即 $\lfloor n/2 \rfloor$ 条边（每个节点度数不超过 $1$）。而上述遍历过程会在全等情况下得到 $j=n$，乘积为 $0$，因此我们只需将初始答案设为 $\lfloor n/2 \rfloor$，并取所有分割乘积的最大值即可。

最终答案即为 $\max(\lfloor n/2 \rfloor, \max\limits_{j}(j \times (n-j)))$，其中 $j$ 取遍排序后每个值块的右边界。

## 复杂度分析

- 时间复杂度：排序需要 $O(n \log n)$，后续遍历数组寻找值块边界只需 $O(n)$。整体时间复杂度为 $O(n \log n)$。  
- 空间复杂度：取决于排序方式，一般为 $O(n)$ 或 $O(\log n)$（不计输入存储）。这里输入数组需保存，故空间复杂度 $O(n)$。

## 代码实现

### Python

```python
n = int(input())
a = list(map(int, input().split()))
a.sort()

# 特殊情况：如果所有值都相同，答案最多为 n // 2
ans = n // 2

i = 0
while i < n:
    # 找到当前值块的右边界（第一个不同值的位置）
    j = i
    while j < n and a[j] == a[i]:
        j += 1
    # 以 j 为分割点，左边 j 个，右边 n-j 个
    ans = max(ans, j * (n - j))
    i = j

print(ans)
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }
        Arrays.sort(a);

        long ans = n / 2;  // 处理全等的情况
        int i = 0;
        while (i < n) {
            int j = i;
            while (j < n && a[j] == a[i]) {
                j++;
            }
            // 以 j 为分界，左边 j 个，右边 n-j 个
            long cur = (long) j * (n - j);
            if (cur > ans) {
                ans = cur;
            }
            i = j;
        }
        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
    }
    sort(a.begin(), a.end());

    long long ans = n / 2;   // 全等时的答案
    for (int i = 0; i < n; ) {
        int j = i;
        while (j < n && a[j] == a[i]) {
            ++j;
        }
        // 以 j 作为分割点：前 j 个为一部分，剩余 n-j 个为另一部分
        ans = max(ans, 1LL * j * (n - j));
        i = j;
    }
    cout << ans << "\n";
    return 0;
}
```
