# 题目内容
给定 $n$ 个不同的节点，第 $i$ 个节点上标记着一个整数 $a_i$。你需要在这些节点之间连尽可能多的无向边，构成一个简单图。唯一的限制是：图中不能出现三个互不相同的节点 $u, v, w$，使得 $(u, v)$ 和 $(v, w)$ 都是边，且标记满足 $a_u \le a_v \le a_w$。

请你计算在满足上述条件的前提下，最多可以连多少条边。

节点总数 $n$ 满足 $2 \le n \le 10^5$，每个标记的值满足 $1 \le a_i \le 10^5$。

# 输入描述
第一行包含一个整数 $n$，表示节点的数量。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$，依次表示每个节点上的标记值。

# 输出描述
输出一个整数，表示最多可以连接的边数。

## 样例1

**输入**

```
5
1 2 3 4 5
```

**输出**

```
6
```

**说明**

节点标记全部不同。可以将节点划分为标记较小的一组和标记较大的一组，例如前 `2` 个节点（标记 $\{1,2\}$）与后 `3` 个节点（标记 $\{3,4,5\}$）。两组之间所有边均可连接，共 $2 \times 3 = 6$ 条边，此时较小组的每个节点只连接标记更大的节点，较小组的每个节点只连接标记更小的节点，满足题目限制。也可划分为前 `3` 后 `2`，同样得到 `6` 条边。这是可能的最大边数。

## 样例2

**输入**

```
6
1 2 2 3 3 4
```

**输出**

```
9
```

**说明**

标记排序为 `1, 2, 2, 3, 3, 4`。只能在标记值严格增大的位置进行划分，使得左侧所有节点的标记严格小于右侧所有节点的标记。若按值 $<2$ 和 $\ge 3$ 划分，左侧有 `3` 个节点（一个 `1` 和两个 `2`），右侧有 `3` 个节点（两个 `3` 和一个 `4`），边数可达 $3 \times 3 = 9$。其他划分方式（如左侧 `1` 个、左侧 `5` 个）得到的边数均不超过 `9`，且相等标记必须分在同一侧。

## 样例3

**输入**

```
4
5 5 5 5
```

**输出**

```
2
```

**说明**

所有节点标记相同。若在两个标记相等的节点之间连边，则这两个节点都不能再与其他任何节点相连，否则会出现 $a_u \le a_v \le a_w$ 的情况。因此每条边必须是孤立的，图退化为一个匹配。最大边数即最多不相交边的对数，为 $\lfloor 4 / 2 \rfloor = 2$ 条边。

## 样例4

**输入**

```
4
1 2 3 3
```

**输出**

```
4
```

**说明**

标记排序为 `1, 2, 3, 3`。值 `3` 出现了两次，这两个节点必须划分在同一侧。选择前 `2` 个节点（`1, 2`）与后 `2` 个节点（两个 `3`）划分，两侧标记严格满足左侧最大 `2` 小于右侧最小 `3`，边数为 $2 \times 2 = 4$。这是在此约束下的最大边数。
