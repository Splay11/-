# 题目内容
流水线上有一列托盘高度记录。质检把一段连续记录称为「轮转可排」，当且仅当把它的某个后缀整体搬到最前面后，高度变为非降序。空操作（搬动整段、结果不变）也允许，因此本身已是非降序的记录同样合格。

给定长度为 $n$ 的正整数数组 $a$，请统计有多少个非空连续子数组是轮转可排的。连续子数组指从原数组中取一段下标连续的元素。

约束：$1 \le n \le 100000$，$1 \le a_i \le 1000000000$。

# 输入描述
第一行一个正整数 $n$，表示数组长度。
第二行 $n$ 个正整数 $a_1, a_2, \ldots, a_n$。
保证 $1 \le n \le 100000$，$1 \le a_i \le 1000000000$。

# 输出描述
输出一个正整数，表示轮转可排的非空连续子数组个数。

## 样例1

**输入**

```
5
1 3 2 4 0
```

**输出**

```
10
```

**说明**

长度为 `1` 的子数组都可轮转有序，共 `5` 个。
长度为 `2` 的 `4` 段也都合法。长度为 `3` 时只有 $[2,4,0]$ 合法（把 `0` 搬到前面得到 $[0,2,4]$）。更长的子数组下降次数过多或不满足首尾衔接。合计 `10`。

## 样例2

**输入**

```
4
5 5 5 5
```

**输出**

```
10
```

**说明**

数组本身非降序，全部 $n(n+1)/2=`10`$ 个非空连续子数组都合法。

## 样例3

**输入**

```
6
4 1 2 3 0 5
```

**输出**

```
16
```

**说明**

双指针维护“至多一次下降，且若有下降则末元 $\le$ 首元”的窗口，统计得到 `16` 个可轮转有序子数组。
