## 解题思路

我们要统计满足 $1 \le i \le j \le n$ 且 $A_i = B_{K_j}$ 的有序对 $(i, j)$ 的个数。

考虑固定右端点 $j$：条件要求 $1 \le i \le j$，且 $A_i$ 的值等于 $B_{K_j}$。因此，在已知 $j$ 和 $B_{K_j}$ 的情况下，答案只需要累加前缀 $A_1 \sim A_j$ 中值等于 $B_{K_j}$ 的元素个数即可。

具体做法如下：
- 从左到右遍历 $j = 1, 2, \dots, n$。
- 维护一个哈希表（或计数器），记录当前已经遍历过的 $A_1 \sim A_j$ 中每个值的出现次数。
- 对于当前的 $j$：
  1. 先将 $A_j$ 加入哈希表（使其成为前缀的一部分）；
  2. 然后查询哈希表中值为 $B_{K_j}$ 的个数，并将该个数累加到最终答案中。
- 遍历结束后，输出累加的总数。

由于所有测试用例的 $n$ 之和不超过 $2 \times 10^5$，上述线性扫描是可行的。

## 复杂度分析

- 时间复杂度：对于每组数据，我们只进行一次从 $1$ 到 $n$ 的遍历，哈希表的插入和查询均摊为 $O(1)$，因此单组时间复杂度为 $O(n)$。所有测试用例的总时间复杂度为 $O(\sum n)$，在 $2 \times 10^5$ 范围内可以高效运行。
- 空间复杂度：需要 $O(n)$ 的空间存储序列 $A, B, K$ 以及哈希表，因此总空间复杂度为 $O(n)$（或 $O(\sum n)$ 若多组数据不重用空间）。

## 代码实现

### Python

```python
from collections import Counter

t = int(input())
for _ in range(t):
    n = int(input())
    A = list(map(int, input().split()))
    B = list(map(int, input().split()))
    K = list(map(int, input().split()))  # 1 下标，指向 B 的索引
    freq = Counter()
    ans = 0
    for j in range(n):
        # 先将 A[j] 加入前缀（此时前缀包含 A[0..j]，对应下标 1..j+1）
        freq[A[j]] += 1
        # 查询 B[K[j]-1] 的出现次数并累加
        ans += freq[B[K[j] - 1]]
    print(ans)
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int t = Integer.parseInt(br.readLine().trim());
        StringBuilder out = new StringBuilder();
        while (t-- > 0) {
            int n = Integer.parseInt(br.readLine().trim());
            long[] A = new long[n];
            long[] B = new long[n];
            int[] K = new int[n];
            
            StringTokenizer st = new StringTokenizer(br.readLine());
            for (int i = 0; i < n; i++) A[i] = Long.parseLong(st.nextToken());
            st = new StringTokenizer(br.readLine());
            for (int i = 0; i < n; i++) B[i] = Long.parseLong(st.nextToken());
            st = new StringTokenizer(br.readLine());
            for (int i = 0; i < n; i++) K[i] = Integer.parseInt(st.nextToken());
            
            HashMap<Long, Integer> freq = new HashMap<>();
            long ans = 0;
            for (int j = 0; j < n; j++) {
                // 将 A[j] 加入前缀
                freq.put(A[j], freq.getOrDefault(A[j], 0) + 1);
                // 累加 B[K[j]-1] 的出现次数
                ans += freq.getOrDefault(B[K[j] - 1], 0);
            }
            out.append(ans).append('\n');
        }
        System.out.print(out);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        vector<long long> A(n), B(n);
        vector<int> K(n);
        for (int i = 0; i < n; ++i) cin >> A[i];
        for (int i = 0; i < n; ++i) cin >> B[i];
        for (int i = 0; i < n; ++i) cin >> K[i];
        
        unordered_map<long long, int> freq;
        freq.reserve(n * 2);
        long long ans = 0;
        for (int j = 0; j < n; ++j) {
            // 将 A[j] 加入前缀
            ++freq[A[j]];
            // 累加等于 B[K[j]-1] 的个数
            ans += freq[B[K[j] - 1]];
        }
        cout << ans << '\n';
    }
    return 0;
}
```
