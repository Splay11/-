# 题目内容
小艾在研究数字序列时，提出了一种名为“完美阶梯”的子序列概念。对于给定的整数序列 $S = [S_1, S_2, \ldots, S_n]$，一个子序列是指从 $S$ 中保持原有顺序选取若干个元素得到的序列。我们称一个长度为 $k$ 的子序列为 **完美阶梯**，当且仅当该子序列严格递增，且其元素恰好依次为 $1, 2, \ldots, k$。定义一个完美阶梯的 **高度** 就是其长度 $k$。现在小艾想知道序列 $S$ 的所有子序列中，所有完美阶梯的高度之和是多少。由于答案可能很大，请你输出结果对 $10^9+7$ 取模的值。

数据范围：测试数据组数 $T$ 不超过 `100`；每一组中，序列长度 $n$ 不超过 `2*10^5`；所有测试数据的 $n$ 总和不超过 `3*10^5`；对于每个元素 $S_i$，都有 $1 \le S_i \le n$。

# 输入描述
第一行包含一个整数 $T$（$1 \le T < 100$），表示测试数据组数。接下来每组数据包含两行：第一行一个正整数 $n$（$1 \le n \le 2 \times 10^5$），表示序列长度；第二行包含 $n$ 个整数 $S_1, S_2, \ldots, S_n$（$1 \le S_i \le n$），表示序列中的元素。

# 输出描述
对于每组测试数据，输出一行一个整数，表示所有完美阶梯的高度之和对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
2
1
1
3
2 2 2
```

**输出**

```
1
0
```

**说明**

第一组数据：序列为 `[1]`，可以构成唯一的完美阶梯 `[1]`，高度为 `1`，总和为 `1`。

第二组数据：序列为 `[2, 2, 2]`，所有元素均大于 `1`，无法形成任何以 `1` 开头的完美阶梯，因此高度之和为 `0`。

## 样例2

**输入**

```
1
4
1 2 1 2
```

**输出**

```
8
```

**说明**

完美阶梯 `[1]`：可从第 `1` 个或第 `3` 个位置选取，共 `2` 种，贡献 `2`。
完美阶梯 `[1,2]`：可选 (第1个 `1`, 第2个 `2`)、(第1个 `1`, 第4个 `2`)、(第3个 `1`, 第4个 `2`)，共 `3` 种，高度 `2`，贡献 `6`。
总和为 `2 + 6 = 8`。

## 样例3

**输入**

```
1
6
1 2 3 1 2 3
```

**输出**

```
20
```

**说明**

完美阶梯 `[1]`：有 `2` 个 `1` 可选，贡献 `2`。
完美阶梯 `[1,2]`：共 `3` 种选法，贡献 `3 * 2 = 6`。
完美阶梯 `[1,2,3]`：共 `4` 种选法，贡献 `4 * 3 = 12`。
总和为 `2 + 6 + 12 = 20`。
