## 解题思路

在本题中，一个长度为 $k$ 的 **完美阶梯** 是指序列 $S$ 中的一个严格递增子序列，且其元素恰好依次为 $1,2,\dots,k$。完美阶梯的 **高度** 就是它的长度 $k$。题目要求所有完美阶梯的高度之和，结果对 $10^9+7$ 取模。

问题的核心是统计每种可能的完美阶梯出现了多少次。由于完美阶梯必须是 $[1,2,\dots,k]$ 的形式，我们可以通过动态规划，只在顺序扫描序列的过程中维护以每个值结尾的“前缀完美阶梯”的数量。

**动态规划设计：**

- 定义 `dp[x]` 表示子序列 $[1,2,\dots,x]$ 出现的次数（即高度为 $x$ 的完美阶梯的个数）。
- 遍历序列 $S$，对于当前元素 $v = S_i$：
  - 若 $v = 1$，则可以开启一个新的只含 $[1]$ 的完美阶梯，因此 `dp[1]` 增加 1。
  - 若 $v > 1$，则所有以 $v-1$ 结尾的完美阶梯 $[1,\dots,v-1]$ 后接上这个 $v$，都能形成一个以 $v$ 结尾的完美阶梯。因此 `dp[v]` 累加 `dp[v-1]`。
- 每一步都对 `dp` 值取模 $10^9+7$。
- 遍历结束后，`dp[x]` 即为序列中所有完美阶梯 $[1,2,\dots,x]$ 的出现次数。

**答案计算：**
完美阶梯的高度就是其长度，所以总高度之和等于 $\sum_{x=1}^{n} x \times dp[x]$，再对 $10^9+7$ 取模。

因为序列中每个元素 $S_i$ 都满足 $1 \le S_i \le n$，所以 `dp` 数组长度设为 $n+1$，足够覆盖所有可能的 $v$。多组数据独立处理即可。

## 复杂度分析

- 时间复杂度：对于每组数据，需要遍历一次长度为 $n$ 的序列，并在最后累加答案，总操作次数为 $O(n)$；设所有测试数据的 $n$ 总和为 $\sum n \le 3\times10^5$，因此总体时间复杂度为 $O(\sum n)$。
- 空间复杂度：每组数据需要一个长度为 $n+1$ 的 `dp` 数组，额外空间为 $O(n)$。在总数据范围内，空间占用可控。

## 代码实现

### Python

```python
MOD = 10**9 + 7

def solve():
    import sys
    data = sys.stdin.read().split()
    it = iter(data)
    T = int(next(it))
    out_lines = []
    for _ in range(T):
        n = int(next(it))
        S = [int(next(it)) for _ in range(n)]
        
        dp = [0] * (n + 1)
        for v in S:
            if v == 1:
                dp[1] = (dp[1] + 1) % MOD
            else:
                dp[v] = (dp[v] + dp[v - 1]) % MOD
        
        ans = 0
        for x in range(1, n + 1):
            ans = (ans + x * dp[x]) % MOD
        out_lines.append(str(ans))
    
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.*;
import java.io.*;

public class Main {
    static final long MOD = 1000000007;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        
        int T = Integer.parseInt(br.readLine().trim());
        while (T-- > 0) {
            int n = Integer.parseInt(br.readLine().trim());
            int[] S = new int[n];
            String[] parts = br.readLine().trim().split("\\s+");
            for (int i = 0; i < n; i++) {
                S[i] = Integer.parseInt(parts[i]);
            }
            
            long[] dp = new long[n + 1];
            for (int v : S) {
                if (v == 1) {
                    dp[1] = (dp[1] + 1) % MOD;
                } else {
                    dp[v] = (dp[v] + dp[v - 1]) % MOD;
                }
            }
            
            long ans = 0;
            for (int x = 1; x <= n; x++) {
                ans = (ans + x * dp[x]) % MOD;
            }
            sb.append(ans).append("\n");
        }
        
        System.out.print(sb);
    }
}
```

            }
        }
        
        long long ans = 0;
        for (int x = 1; x <= n; ++x) {
            ans = (ans + x * dp[x]) % MOD;
        }
        cout << ans << '\n';
    }
    
    return 0;
}
