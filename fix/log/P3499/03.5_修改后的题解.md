## 解题思路

$L,R$ 可达 $10^{18}$，不能枚举三元组，需要化简条件。

由于 $L \le a < b < c \le R$，有 $\max(a,b,c)=c$。$\operatorname{lcm}(a,b,c)$ 必为 $c$ 的倍数，设其为 $k\cdot c$。由 $c < k\cdot c$ 得 $k \ge 2$；又 $a+b+c < 3c$，结合 $k\cdot c < a+b+c$ 得 $k < 3$。故 $k$ 只能为 `2`，即 $\operatorname{lcm}(a,b,c)=2c$，且 $c < a+b$。

进一步分析可知，满足条件的三元组只有两类比例：

- $(3t,4t,6t)$，要求 $L \le 3t$ 且 $6t \le R$，即 $\lceil L/3 \rceil \le t \le \lfloor R/6 \rfloor$；
- $(6t,10t,15t)$，要求 $L \le 6t$ 且 $15t \le R$，即 $\lceil L/6 \rceil \le t \le \lfloor R/15 \rfloor$。

两类互不相交，答案为两段整数 $t$ 的个数之和。计算时使用 `64` 位整数。

## 复杂度分析

- **时间复杂度**：$O(t)$。每组数据 $O(1)$ 完成计数。
- **空间复杂度**：$O(1)$。

## 代码实现

### Python

```python
def solve():
    l, r = map(int, input().split())
    count = 0

    k_min1 = (l + 3 - 1) // 3
    k_max1 = r // 6
    if k_max1 >= k_min1:
        count += (k_max1 - k_min1 + 1)

    k_min2 = (l + 6 - 1) // 6
    k_max2 = r // 15
    if k_max2 >= k_min2:
        count += (k_max2 - k_min2 + 1)

    print(count)

def main():
    try:
        t = int(input())
        for _ in range(t):
            solve()
    except (IOError, ValueError):
        pass

if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void solve() {
        Scanner scanner = new Scanner(System.in);
        int t = scanner.nextInt();
        while (t-- > 0) {
            long l = scanner.nextLong();
            long r = scanner.nextLong();
            long count = 0;

            long k_min1 = (l + 3 - 1) / 3;
            long k_max1 = r / 6;
            if (k_max1 >= k_min1) {
                count += (k_max1 - k_min1 + 1);
            }

            long k_min2 = (l + 6 - 1) / 6;
            long k_max2 = r / 15;
            if (k_max2 >= k_min2) {
                count += (k_max2 - k_min2 + 1);
            }

            System.out.println(count);
        }
        scanner.close();
    }

    public static void main(String[] args) {
        solve();
    }
}
```
