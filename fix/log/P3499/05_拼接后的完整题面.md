# 题目内容
给定两个正整数 $L$ 和 $R$，统计满足下列条件的三元组 $(a,b,c)$ 的个数：

- $L \le a < b < c \le R$；
- $\max(a,b,c) < \operatorname{lcm}(a,b,c) < a+b+c$。

其中 $\max$ 表示三者中的最大值，$\operatorname{lcm}$ 表示三者的最小公倍数（能同时被它们整除的最小正整数）。

数据范围：测试组数 $t$ 满足 $1 \le t \le 10^4$；每组满足 $1 \le L \le R \le 10^{18}$ 且 $R-L+1 \ge 3$。

# 输入描述
第一行包含一个整数 $t$（$1 \le t \le 10^4$），表示测试组数。
接下来 $t$ 行，每行包含两个整数 $L$ 和 $R$（$1 \le L \le R \le 10^{18}$，$R-L+1 \ge 3$），表示区间端点。

# 输出描述
对于每个测试组，在一行输出一个整数，表示满足条件的三元组个数。

## 样例1

**输入**

```
3
1 10
3 5
1 10000
```

**输出**

```
1
0
2332
```

**说明**

第一组中唯一合法三元组为 $(3,4,6)$：最大值为 `6`，最小公倍数为 `12`，和为 `13`，满足 $6<12<13$。
第二组区间过短，没有合法三元组。
第三组按两类比例 $(3k,4k,6k)$ 与 $(6k,10k,15k)$ 计数，得到 `2332`。

## 样例2

**输入**

```
1
1 6
```

**输出**

```
1
```

**说明**

区间 $[1,6]$ 内只有 $(3,4,6)$ 这一类 $k=1$ 的三元组，答案为 `1`。

## 样例3

**输入**

```
1
6 15
```

**输出**

```
2
```

**说明**

合法三元组为 $(6,8,12)$ 与 $(6,10,15)$，共 `2` 个。

## 样例4

**输入**

```
1
1 15
```

**输出**

```
3
```

**说明**

合法三元组为 $(3,4,6)$、$(6,8,12)$、$(6,10,15)$，共 `3` 个。
