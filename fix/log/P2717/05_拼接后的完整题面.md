# 题目内容
在一条无限长的直线上，你从位置 $0$ 开始。有一串长度为 $n$ 的指令序列 $s$，仅包含字符 `'<'` 和 `'>'`，`'<'` 表示向左移动 $1$ 单位，`'>'` 表示向右移动 $1$ 单位。

对于每个起始下标 $i$（$0 \le i < n$），你会从 $s_i$ 开始，依次执行指令：$s_i, s_{i+1}, s_{i+2}, \ldots$。你可以在执行任意条指令后停止（至少执行一条指令）。我们想知道，是否存在某个停止的时机，使得你恰好回到起点 $0$。

对于所有的 $i$，你需要独立判断：是否存在某个 $k \ge 1$，使得从 $s_i$ 到 $s_{i+k-1}$ 这段指令的累计位移为 $0$。如果存在，答案为 $1$，否则为 $0$。

指令序列的长度 $n$ 满足 $1 \le n \le 2 \times 10^5$。

# 输入描述
第一行包含一个整数 $n$，表示指令序列的长度。
第二行包含一个长度为 $n$ 的字符串 $s$，仅由字符 `'<'` 和 `'>'` 组成。

# 输出描述
输出一行，包含 $n$ 个整数，第 $i$ 个整数（从 $0$ 开始计数）表示从下标 $i$ 开始执行指令，是否有机会回到原点。有机会则输出 $1$，否则输出 $0$。整数之间用一个空格隔开。

## 样例1

**输入**

```
1
>
```

**输出**

```
0
```

**说明**

指令序列长度为 `1`，仅包含一个 `'>'`。从起始下标 `0` 开始，只能执行一步，位移为 $+1$，无法恰好回到起点 $0$。因此输出 `0`。

## 样例2

**输入**

```
2
<>
```

**输出**

```
1 0
```

**说明**

指令序列为 `"<>"`。
- 起始下标 `0`：依次执行 `'<'`（位移 $-1$）和 `'>'`（位移 $+1$），累计位移为 $0$，存在停止时机回到原点，答案为 `1`。
- 起始下标 `1`：只能执行一步 `'>'`，位移为 $+1$，无法回到原点，答案为 `0`。
因此输出 `1 0`。

## 样例3

**输入**

```
5
>><><
```

**输出**

```
0 1 1 1 0
```

**说明**

指令序列 $s = \texttt{>><><}$，长度 $n=5$。
- $i=0$（从 `'>'` 开始）：连续执行各步的累计位移依次为 $+1, +2, +1, +2, +1$，始终不为 $0$，答案为 `0`。
- $i=1$（从 `'><><'` 开始）：位移依次为 $+1$、$0$（由 $+1$ 和 $-1$ 抵消），可以在第 `2` 步停止并回到原点，答案为 `1`。
- $i=2$（从 `'<><'` 开始）：位移依次为 $-1$、$0$（由 $-1$ 和 $+1$ 抵消），可以回到原点，答案为 `1`。
- $i=3$（从 `'><'` 开始）：位移依次为 $+1$、$0$，可以回到原点，答案为 `1`。
- $i=4$（只有一个 `'<'`）：位移为 $-1$，无法回到原点，答案为 `0`。
最终输出 `0 1 1 1 0`。
