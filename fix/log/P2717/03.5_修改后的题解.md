## 解题思路

1. **问题转化**：将指令序列中的字符转化为移动量，用 `+1` 表示 `>`（向右移动 $1$ 单位），用 `-1` 表示 `<`（向左移动 $1$ 单位）。
2. **前缀和数组**：定义长度为 $n+1$ 的前缀和数组 $P$，其中 $P[0]=0$，$P[k] = a_0 + a_1 + \dots + a_{k-1}$ （$1 \le k \le n$），$a_j$ 为第 $j$ 条指令对应的移动量。
3. **区间位移计算**：从起始下标 $i$ 开始，连续执行 $L$ 条指令（$L\ge 1$）后的累计位移为 $P[i+L] - P[i]$。
4. **回到原点的条件**：如果能在某个 $L \ge 1$ 时回到原点，则位移为 $0$，即 $P[i+L] = P[i]$。这意味着在位置 $i$ 之后（$i+1, i+2, \dots, n$），存在某个下标 $k$ 使得 $P[k] = P[i]$。
5. **高效判定**：预处理整个前缀和数组，用哈希表记录每个前缀和值**最后出现的位置**。对于每个起始下标 $i$，若 $P[i]$ 的最后出现位置大于 $i$，说明后面至少还有一个位置与该前缀和相等，答案为 $1$；否则答案为 $0$。
6. **输出**：按顺序输出每个 $i$（$0\le i < n$）的判断结果，用空格分隔。

## 复杂度分析

- **时间复杂度**：$O(n)$。计算前缀和、记录最后出现位置、查询答案均只需线性扫描。
- **空间复杂度**：$O(n)$。需要存储长度为 $n+1$ 的前缀和数组，以及哈希表记录不同前缀和值的最后位置，最坏情况存储 $n+1$ 个键值对。

## 代码实现

### Python

```python
# -*- coding: utf-8 -*-
# 读入数据
n = int(input().strip())
s = input().strip()

# 计算前缀和, P[0] = 0, P[i+1] = P[i] + (1 if s[i]=='>' else -1)
P = [0] * (n + 1)
for i in range(n):
    P[i + 1] = P[i] + (1 if s[i] == '>' else -1)

# 记录每个前缀和最后出现的位置
last_pos = {}
for i in range(n + 1):
    last_pos[P[i]] = i  # 每次覆盖即为最后出现的位置

# 对于每个起始下标 i, 判断是否存在 k (i+1 <= k <= n) 使得 P[k] == P[i]
res = []
for i in range(n):
    if last_pos[P[i]] > i:
        res.append("1")
    else:
        res.append("0")

print(" ".join(res))
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        // 使用 BufferedReader 加速输入
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());
        String s = br.readLine().trim();

        // 计算前缀和, P[0] = 0, P[i+1] = P[i] + (s.charAt(i)=='>' ? 1 : -1)
        int[] P = new int[n + 1];
        for (int i = 0; i < n; i++) {
            P[i + 1] = P[i] + (s.charAt(i) == '>' ? 1 : -1);
        }

        // 使用 HashMap 记录每个前缀和最后出现的位置
        HashMap<Integer, Integer> lastPos = new HashMap<>();
        for (int i = 0; i <= n; i++) {
            lastPos.put(P[i], i); // 每次 put 覆盖即为最后出现位置
        }

        // 对于每个起始下标 i, 判断是否存在 k (i+1 <= k <= n) 使得 P[k] == P[i]
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (lastPos.get(P[i]) > i)
                sb.append("1 ");
            else
                sb.append("0 ");
        }

        System.out.println(sb.toString().trim());
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <unordered_map>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    string s;
    cin >> s;

    // 计算前缀和, P[0]=0, P[i+1]=P[i]+(s[i]=='>'? 1 : -1)
    vector<int> P(n + 1, 0);
    for (int i = 0; i < n; i++) {
        P[i + 1] = P[i] + (s[i] == '>' ? 1 : -1);
    }

    // 记录每个前缀和最后出现的位置
    unordered_map<int, int> lastPos;
    for (int i = 0; i <= n; i++) {
        lastPos[P[i]] = i; // 每次覆盖即为最后出现位置
    }

    // 对于每个起始下标 i, 判断是否存在 k (i+1 <= k <= n) 使得 P[k]==P[i]
    for (int i = 0; i < n; i++) {
        if (lastPos[P[i]] > i)
            cout << 1 << " ";
        else
            cout << 0 << " ";
    }

    return 0;
}
```
