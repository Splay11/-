## 解题思路

两瓶试液体积比相加：

$$
\frac{a}{b}+\frac{c}{d}=\frac{ad+cb}{bd}.
$$

令分子 $num=ad+cb$，分母 $den=bd$，用 $\gcd$ 约分得到 $den'$。十进制有限位小数当且仅当约分后分母的质因子只有 `2` 和 `5`。因此不断除掉 $den'$ 中的 `2` 和 `5`，剩余为 `1` 则输出 `YES`，否则 `NO`。整数对应 $den'=1$ 的情形，同样被覆盖。

## 复杂度分析

每组约分与试除为 $O(\log(10^{18}))$，总体时间复杂度 $O(T\log V)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
import math

T = int(input())
for _ in range(T):
    a, b, c, d = map(int, input().split())
    num = a * d + c * b
    den = b * d
    g = math.gcd(num, den)
    num //= g
    den //= g
    while den % 2 == 0:
        den //= 2
    while den % 5 == 0:
        den //= 5
    if den == 1:
        print("YES")
    else:
        print("NO")
```

### Java

```java
import java.util.*;
import java.io.*;

public class Main {
    static long gcd(long a, long b) {
        while (b != 0) {
            long t = a % b;
            a = b;
            b = t;
        }
        return a;
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine());
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < T; i++) {
            String[] parts = br.readLine().split(" ");
            long a = Long.parseLong(parts[0]);
            long b = Long.parseLong(parts[1]);
            long c = Long.parseLong(parts[2]);
            long d = Long.parseLong(parts[3]);
            long num = a * d + c * b;
            long den = b * d;
            long g = gcd(num, den);
            num /= g;
            den /= g;
            while (den % 2 == 0) den /= 2;
            while (den % 5 == 0) den /= 5;
            if (den == 1) sb.append("YES\n");
            else sb.append("NO\n");
        }
        System.out.print(sb.toString());
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

long long gcd_ll(long long x, long long y) {
    while (y) {
        long long t = x % y;
        x = y;
        y = t;
    }
    return x;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        long long a, b, c, d;
        cin >> a >> b >> c >> d;
        long long num = a * d + c * b;
        long long den = b * d;
        long long g = gcd_ll(num, den);
        num /= g;
        den /= g;
        while (den % 2 == 0) den /= 2;
        while (den % 5 == 0) den /= 5;
        if (den == 1) cout << "YES\n";
        else cout << "NO\n";
    }
    return 0;
}
```
