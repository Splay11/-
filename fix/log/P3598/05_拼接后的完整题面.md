# 题目内容
药研所要把两瓶试液按体积比兑到同一只十进制刻度量筒里：第一瓶取 $a$ 份、分母刻度为 $b$，第二瓶取 $c$ 份、分母刻度为 $d$。只有当混合后的总量 $\dfrac{a}{b}+\dfrac{c}{d}$ 在十进制下是整数或有限位小数时，液面才能落在量筒的有限刻度上，实验员才能一次性读尽；否则需要改用无限循环小数对应的估读流程。

有限位小数：有理数 $x$ 在十进制下写成小数后，小数点后只有有限位。即存在正整数 $k$、整数 $p$ 以及数字 $q_1,\ldots,q_k$（$0 \le q_i \le 9$），使得 $x = p + \sum_{i=1}^{k} q_i \times 10^{-i}$。请判断该混合量能否被读尽。

约束：测试组数不超过 `10000`，每个参数不超过 `1000000000`。

# 输入描述
第一行一个整数 $T$，表示测试组数。
接下来 $T$ 行，每行四个整数 $a,b,c,d$。
保证 $1 \le T \le 10000$，$1 \le a,b,c,d \le 1000000000$。

# 输出描述
对每组数据输出一行：若 $\dfrac{a}{b}+\dfrac{c}{d}$ 是十进制整数或有限位小数，输出 `YES`，否则输出 `NO`。

## 样例1

**输入**

```
3
1 2 1 4
1 6 1 7
5 8 3 8
```

**输出**

```
YES
NO
YES
```

**说明**

第一组：$\dfrac{1}{2}+\dfrac{1}{4}=\dfrac{3}{4}$，约分后分母为 `4`，只含质因子 `2`，是有限位小数，输出 `YES`。

第二组：$\dfrac{1}{6}+\dfrac{1}{7}=\dfrac{13}{42}$，约分后分母 $42=2\times 3\times 7$，去掉 `2` 和 `5` 后仍剩 `21`，输出 `NO`。

第三组：$\dfrac{5}{8}+\dfrac{3}{8}=1$，是整数，输出 `YES`。

## 样例2

**输入**

```
1
1 1 1 1
```

**输出**

```
YES
```

**说明**

$\dfrac{1}{1}+\dfrac{1}{1}=2$，是整数，输出 `YES`。
