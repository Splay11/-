# 题目内容
考古队发现五张只含数字字符的纸条，上面分别写着 $a$、$b$、$c$、$d$、$e$。它们本应满足同一未知进制 $x$（$2 \le x \le 10$）下的等式 $a+b=c$，其中加法在该进制下进行。

称 $x$ 是合法进制，当且仅当这五个字符串中的每个字符在进制 $x$ 下都是合法数字，即该字符代表的数值严格小于 $x$。

在所有同时满足「合法」且「$a+b=c$ 成立」的进制 $x$ 中，把 $d$ 与 $e$ 按进制 $x$ 解释成十进制整数后相加。若所有这些进制得到的和完全相同，则输出该和；否则输出 `baka`。

保证每组数据至少存在一个 $x$（$2 \le x \le 10$），使得 $a$、$b$、$c$ 在该进制下每位都合法且 $a+b=c$。并保证对任一满足条件的 $x$，五个数以及 $d+e$ 的十进制值都落在 $[0, 2^{31}-1]$ 内。

约束：测试组数不超过 `2\times 10^5`，每个字符串长度不超过 `9`。字符串非空、无前导零（数值为 `0` 时字符串为 `0`），字符仅含 `0` 到 `9`。

# 输入描述
每个测试文件包含多组数据。第一行包含一个整数 $t$，表示测试组数。保证 $1 \le t \le 2 \times 10^5$。
接下来 $t$ 行，每行五个字符串 $a$、$b$、$c$、$d$、$e$，以单个空格分隔，分别表示同一未知进制下的五个非负整数。保证每个字符串长度在 $1$ 到 $9$ 之间，非空且无前导零（若值为 `0` 则字符串为 `0`），字符仅属于 `0` 到 `9`。

# 输出描述
对每组数据输出一行：若所有满足条件的进制算出的 $d+e$ 都相同，输出该值；否则输出 `baka`。若不存在任何满足条件的进制，也输出 `baka`。

## 样例1

**输入**

```
1
0 0 0 0 0
```

**输出**

```
0
```

**说明**

五个串都是 `0`。从进制 `2` 到 `10` 均合法且 $0+0=0$ 成立，$d+e$ 恒为 `0`。
结果唯一，输出 `0`。

## 样例2

**输入**

```
1
8 1 10 1 1
```

**输出**

```
2
```

**说明**

最大数字为 `8`，合法进制从 `9` 开始。
进制 `9` 下 $8+1$ 等于 `10`（十进制 `9`），且 $d+e=1+1=2$。进制 `10` 下 $8+1=9
eq 10$，等式不成立。因此只有一种合格进制，输出 `2`。

## 样例3

**输入**

```
1
1 1 1 1 1
```

**输出**

```
baka
```

**说明**

按题意模拟计算得到。
