## 解题思路

本题需要为给定的排列 $a_1, a_2, \dots, a_n$（$1\dots n$ 的一个排列）中的每个数赋予正号或负号，使得带符号的和等于目标值 $x$。

设所有数的总和为 $S = 1+2+\cdots+n = \frac{n(n+1)}{2}$，也就是输入数组元素的总和。  
设正号部分的和为 $P$，负号部分所有数的绝对值之和为 $N$，则有：

$$
P - N = x, \quad P + N = S
$$

解得：

$$
P = \frac{x+S}{2}, \quad N = \frac{S-x}{2}
$$

因此，问题转化为：从集合 $\{1,2,\dots,n\}$ 中选出一些数，使得它们的和恰好等于 $N = \frac{S-x}{2}$。只要找出这样的子集，将其中的数标记为负号，其余数标记为正号即可。

**必要条件与充分性**  
1. 若 $S < x$ 或 $(S - x)$ 为奇数，则 $N$ 不是非负整数，直接判定无解。  
2. 对于连续的整数 $1$ 到 $n$，使用贪心策略一定能构造出任意不超过 $S$ 且奇偶性合法的子集和：从大到小考虑每个整数 $i$（$i=n,n-1,\dots,1$），若当前剩余目标和 $target \ge i$，就选定 $i$ 并令 $target = target - i$。最终 $target$ 一定变为 $0$。

**构造符号字符串**  
根据输入顺序遍历排列 $a$，如果 $a_i$ 出现在被选为负号的集合中，则该位置输出 `'-'`，否则输出 `'+'`。若有多解，输出任意一种即可；若 $target$ 不能减至 $0$，则输出 `-1`。

## 复杂度分析

- **时间复杂度**：$O(n)$。计算总和、贪心选择负号数字（至多 $n$ 次）以及生成答案字符串均只需线性扫描。
- **空间复杂度**：$O(n)$。需要额外的哈希集合存储选为负号的数字，以及长度为 $n$ 的答案字符串。

## 代码实现

### Python

```python
def solve(n, x, a):
    total = sum(a)                     # 所有数的总和
    if total < x or (total - x) % 2 != 0:
        return "-1"
    
    target = (total - x) // 2          # 负号部分的和
    chosen = set()
    # 从大到小贪心选择数字
    for i in range(n, 0, -1):
        if target >= i:
            target -= i
            chosen.add(i)
    
    if target != 0:
        return "-1"
    
    # 根据选择结果生成答案字符串
    ans = []
    for num in a:
        if num in chosen:
            ans.append('-')
        else:
            ans.append('+')
    return ''.join(ans)

# 输入处理
n, x = map(int, input().strip().split())
a = list(map(int, input().strip().split()))
print(solve(n, x, a))
```

### Java

```java
import java.util.Scanner;
import java.util.HashSet;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long x = sc.nextLong();            // 目标值可能较大，用 long
        
        int[] a = new int[n];
        long total = 0;
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
            total += a[i];
        }
        
        // 无解情况：总和过小或奇偶性不符
        if (total < x || (total - x) % 2 != 0) {
            System.out.println(-1);
            return;
        }
        
        long target = (total - x) / 2;     // 负号部分需要的和
        HashSet<Integer> chosen = new HashSet<>();
        
        // 从大到小贪心选取
        for (int i = n; i >= 1; i--) {
            if (target >= i) {
                target -= i;
                chosen.add(i);
            }
        }
        
        if (target != 0) {
            System.out.println(-1);
            return;
        }
        
        StringBuilder sb = new StringBuilder();
        for (int num : a) {
            if (chosen.contains(num)) {
                sb.append('-');
            } else {
                sb.append('+');
            }
        }
        System.out.println(sb);
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <unordered_set>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n;
    long long x;
    cin >> n >> x;
    
    vector<int> a(n);
    long long total = 0;
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
        total += a[i];
    }
    
    // 检查必要条件
    if (total < x || (total - x) % 2 != 0) {
        cout << -1 << "\n";
        return 0;
    }
    
    long long target = (total - x) / 2;
    unordered_set<int> chosen;
    
    // 贪心选择负号数字
    for (int i = n; i >= 1; --i) {
        if (target >= i) {
            target -= i;
            chosen.insert(i);
        }
    }
    
    if (target != 0) {
        cout << -1 << "\n";
        return 0;
    }
    
    // 构造输出
    for (int num : a) {
        if (chosen.count(num)) {
            cout << '-';
        } else {
            cout << '+';
        }
    }
    cout << "\n";
    
    return 0;
}
```
