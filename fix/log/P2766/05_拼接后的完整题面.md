# 题目内容
魔法师准备激活一组符文石，符文石上刻有编号 $1$ 到 $n$，但它们的排列顺序被打乱了，形成了一个长度为 $n$ 的序列 $a_1, a_2, \dots, a_n$，其中每个编号恰好出现一次。激活第 $i$ 个符文石时，可以选择正向激活，释放大小为 $a_i$ 的能量；或者反向激活，释放大小为 $-a_i$ 的能量。魔法师希望所有符文石释放的总能量恰好等于 $x$。

请你为每个符文石指定激活方向，即决定其前面的符号为 `'+'` 或 `'-'`，使得 $\sum_{i=1}^n s_i \cdot a_i = x$，其中 $s_i \in \{+1, -1\}$。

约束：序列长度 $n$ 不超过 $10^5$，目标值 $x$ 满足 $0 \le x \le 10^9$，序列中的元素均为整数且满足 $1 \le a_i \le n$，且所有 $a_i$ 互不相同。

# 输入描述
第一行包含两个正整数 `n` 和 `x`。
第二行包含 `n` 个两两不同的正整数 `a_1, a_2, ..., a_n`。

# 输出描述
如果无解，输出 `-1`。
否则输出一个长度为 `n` 的字符串，仅由 `'+'` 和 `'-'` 两种字符组成，第 `i` 个字符表示 `a_i` 的符号。如果有多种方案，输出任意一种均可。

## 样例1

**输入**

```
4 0
2 4 1 3
```

**输出**

```
+--+
```

**说明**

总和为 $1+2+3+4 = 10$，要使得总和为 `0`，需正数部分和为 `5`，负数部分和为 `5`。选择 $2+3=5$ 为正，$4+1=5$ 为负，符号依次为 `+2` `-4` `-1` `+3`，即字符串 `+--+`。

## 样例2

**输入**

```
2 2
1 2
```

**输出**

```
-1
```

**说明**

$n=2$，序列为 $1, 2$，总和为 `3`。所有可能的和只有 $-3, -1, 1, 3$，无法得到 `2`，故无解输出 `-1`。

## 样例3

**输入**

```
5 7
5 1 2 3 4
```

**输出**

```
++++-
```

**说明**

总和为 $15$，目标 `7`。设正数和为 $S$，负数和为 $15-S$，则 $S - (15-S) = 7$，得 $S = 11$。选择 $5+1+2+3=11$ 为正，$4$ 为负。对应符号：`+5` `+1` `+2` `+3` `-4`，即 `++++-`。

## 样例4

**输入**

```
1 0
1
```

**输出**

```
-1
```

**说明**

$n=1$，只能选择 $+1$ 或 $-1$，无法得到 `0`，故无解。
