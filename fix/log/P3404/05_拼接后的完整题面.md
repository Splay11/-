# 题目内容
你正在设计一个简单的分类系统。给定一批参考样本和一批查询样本，你需要通过一种三中心迭代算法对查询样本进行归类。

算法流程如下：
1. 初始化：取参考样本集的前 $3$ 个样本作为三个初始中心点 $c_0, c_1, c_2$。
2. 迭代更新（最多 $100$ 轮）：
   - 计算每个参考样本到三个中心点的欧氏距离，将其分配给距离最近的中心点（若距离相同，选择下标最小的中心点）。
   - 对每个中心点，用分配到的所有样本的算术平均作为新的中心点；若某中心点未分配到任何样本，则它的位置保持不变。
   - 若本轮所有中心点的每一个坐标分量相较于上一轮的变化量绝对值均小于 $10^{-6}$，则认为算法已收敛，停止迭代。
3. 中心点排序与重标号：迭代结束后，将三个中心点按坐标字典序升序排列（优先比较第一维，若相同再比较第二维，依此类推）。然后将排序后的中心点依次记为类别 $0$、$1$、$2$。
4. 查询样本归类：用最终得到的三个中心点，为每一个查询样本计算欧氏距离，选取距离最小的中心点对应的类别编号作为预测标签（若并列，取编号最小者）。最终按输入顺序输出所有查询样本的预测标签列表。

约束条件：
- 参考样本的数量 $n \ge 3$，特征维度 $m \ge 1$。
- 查询样本的数量 $k \ge 1$，且每个样本的特征维度与参考样本相同。
- 所有数值均为整数或浮点数，绝对值不超过 $10^9$。

# 输入描述
输入仅一行，为一个 JSON 对象，包含两个字段：
- "train"：二维数组，表示参考样本集，每行是一个样本的特征向量。
- "test"：二维数组，表示查询样本集，每行是一个样本的特征向量。
所有样本的特征维度相同，行与行之间无额外空白。

# 输出描述
输出一行 JSON 数组，包含按输入顺序给出的每个查询样本的预测类别编号（整数 $0$、$1$ 或 $2$）。

## 样例1

**输入**

```
{"train":[[0,0],[10,0],[0,10]],"test":[[1,1],[9,1],[1,9]]}
```

**输出**

```
[0,2,1]
```

**说明**

训练集共 $3$ 个样本，初始中心点为 $(0,0)$、$(10,0)$、$(0,10)$。
每个样本即为中心点本身，第一轮迭代后各簇均只包含自身，中心位置不变，变化量为 $0$，满足收敛阈值 $10^{-6}$ 并停止迭代。
将收敛后的三个中心按坐标字典序升序排列，得到顺序 $(0,0)$、$(0,10)$、$(10,0)$，依次标记为类别 `0`、`1`、`2`。
对测试样本：
- $(1,1)$ 距离三类中心的欧氏距离分别为 $\sqrt{2}$、$\sqrt{82}$、$\sqrt{82}$，最近为类别 `0`；
- $(9,1)$ 距离分别为 $\sqrt{82}$、$\sqrt{162}$、$\sqrt{2}$，最近为类别 `2`；
- $(1,9)$ 距离分别为 $\sqrt{82}$、$\sqrt{2}$、$\sqrt{162}$，最近为类别 `1`。
故预测标签为 $[0,2,1]$。

## 样例2

**输入**

```
{"train":[[1],[2],[3],[10],[11],[12]],"test":[[1.5],[3],[9]]}
```

**输出**

```
[0,1,2]
```

**说明**

训练样本为一维数据。取前三个样本作为初始中心：`1`、`2`、`3`。
- 第 `1` 轮迭代：根据最近距离分配，中心 `1` 只包含 `1`，中心 `2` 包含 `2`，中心 `3` 包含 `3,10,11,12`。更新后中心变为 `1`、`2`、`9`。
- 第 `2` 轮：`1` 仍属于第一个中心；`2` 和 `3` 被分配给第二个中心；`10,11,12` 分配给第三个中心。更新后中心为 `1`、`2.5`、`11`。
- 第 `3` 轮：分配结果不变，中心不再变化，变化量 $0$ 满足收敛条件。最终中心为 $1$、$2.5$、$11$，按升序排列，类别 `0`、`1`、`2` 分别对应 $1$、$2.5$、$11$。
测试样本预测：
- $1.5$ 距离 $1$ 最近（$0.5$），属类别 `0`；
- $3$ 距离 $2.5$ 最近（$0.5$），属类别 `1`；
- $9$ 距离 $11$ 最近（$2$），属类别 `2`。
输出 $[0,1,2]$。

## 样例3

**输入**

```
{"train":[[0,0],[2,0],[0,2]],"test":[[1,1]]}
```

**输出**

```
[0]
```

**说明**

训练集包含 $3$ 个二维样本，初始中心为 $(0,0)$、$(2,0)$、$(0,2)$，且各点自成簇，迭代后中心不变。
按字典序排序得中心 $(0,0)$（类别 `0`）、$(0,2)$（类别 `1`）、$(2,0)$（类别 `2`）。
测试样本 $(1,1)$ 到三个中心的欧氏距离均为 $\sqrt{2}$，根据规则当距离并列时选择编号最小的类别，因此预测为类别 `0`，故输出 $[0]$。
