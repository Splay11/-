# 题目内容
实验室走廊上从左到右摆放着 $n$ 根能量柱，第 $i$ 根的能级记为 $h_i$。所有能级互不相同。

在当前仍保留的能量柱序列中，两端的能量柱永远不会被清除。对于其余能量柱，若其能级严格小于左右相邻两根，则称为凹点；若其能级严格大于左右相邻两根，则称为凸点。

清除按轮次进行：奇数轮同时清除全部凹点，偶数轮同时清除全部凸点。每一轮必须先根据当前序列判定所有将被清除的位置，再同时清除；某根被清除后，其左右仍存在的能量柱视为相邻。

从第 `1` 轮清除凹点开始。请计算第一次没有任何能量柱被清除的轮次编号。若当前能量柱少于 `3` 根，则不可能出现凹点或凸点。

约束：能量柱的数量不超过 $10^5$，每根能量柱的能级为正整数且不超过 $10^9$。

# 输入描述
第一行包含一个整数 $n$，表示能量柱的数量。
第二行包含 $n$ 个整数 $h_1, h_2, \ldots, h_n$，依次表示各能量柱的能级。
保证 $1 \le n \le 10^5$，$1 \le h_i \le 10^9$，且所有 $h_i$ 互不相同。

# 输出描述
输出一个整数，表示第一次没有任何能量柱被清除的轮次编号。

## 样例1

**输入**

```
1
5 7 1 2 8 3
```

**输出**

```
4
```

**说明**

按题意模拟计算得到。
