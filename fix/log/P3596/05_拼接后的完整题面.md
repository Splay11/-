# 题目内容
某通信网络由 $n$ 个基站构成，基站间通过 $n-1$ 条光纤连接形成一棵树。每个基站 $i$ 有一个初始工作频率 $f_i$（整数）。为避免相邻基站间产生严重干扰，要求相邻基站的频率之差尽可能小。定义网络的 **干扰度** 为所有相邻基站对 $(u,v)$ 的频率差绝对值的最大值：

$$D(f)=\max_{(u,v)\in E}|f_u-f_v|$$

技术人员可以对至多 $k$ 个基站进行频率重设，每个重设后的频率可以是任意整数（不受初始范围限制）。你的目标是选择重设方案，使重设后网络的干扰度达到最小。求出这个最小的干扰度。

约束条件：
- 基站数量 $n$ 满足 $1 \le n \le 1000$；
- 可重设基站数 $k$ 满足 $0 \le k \le n-1$；
- 每个基站的初始频率 $f_i$ 满足 $0 \le f_i \le 100$。

# 输入描述
第一行包含两个整数 $n$ 和 $k$，分别表示基站个数和最多可重设频率的基站个数。
第二行包含 $n$ 个整数 $f_1, f_2, \dots, f_n$，表示各基站的初始频率。
接下来 $n-1$ 行，每行包含两个整数 $u, v$，表示基站 $u$ 与基站 $v$ 之间有一条光纤直接相连。输入保证这些边构成一棵树。

# 输出描述
输出一个整数，表示在至多重设 $k$ 个基站频率的前提下，网络可能达到的最小干扰度。

## 样例1

**输入**

```
1 0
5
```

**输出**

```
0
```

**说明**

网络中只有 `1` 个基站，不存在任何相邻基站对，因此干扰度为 `0`。

## 样例2

**输入**

```
3 0
10 20 10
1 2
2 3
```

**输出**

```
10
```

**说明**

不允许重设任何基站的频率。相邻基站对 $(1,2)$ 的频率差为 $|10-20|=10$，$(2,3)$ 的频率差为 $|20-10|=10$。因此干扰度为 $\max(10,10)=10$。

## 样例3

**输入**

```
3 1
10 100 10
1 2
2 3
```

**输出**

```
0
```

**说明**

可以重设 `1` 个基站的频率。将基站 `2` 的频率从 `100` 改为 `10`，则相邻基站对 $(1,2)$ 和 $(2,3)$ 的频率差均变为 $|10-10|=0$，干扰度降为 `0`。

## 样例4

**输入**

```
4 1
0 100 50 50
1 2
1 3
1 4
```

**输出**

```
25
```

**说明**

树结构以基站 `1` 为中心，连接三个叶子 `2`、`3`、`4`。仅可重设 `1` 个基站。若重设中心基站 `1`，将其频率调整为 $x$，我们需要最小化 $\max(|x-100|, |x-50|, |x-50|)$。当 $x=75$ 时，该最大值为 $25$。若改为重设某个叶子节点（例如将 `2` 的频率改为 `0` 或 `50`），最大频率差仍为 `50`。因此最小干扰度为 `25`。
