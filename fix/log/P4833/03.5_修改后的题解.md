## 解题思路

两种纸包装订量为 $n$ 和 $n+1$。若一共使用 $k$ 个纸包，总张数构成连续区间 $[kn,\ k(n+1)]$，因为每把一个 $n$ 换成 $n+1$，总量恰好加 `1`。

需要最小的 $k$ 使得右端点 $k(n+1) \ge m$，即

$$
k = \left\lceil \frac{m}{n+1} \right\rceil.
$$

此时：

- 若 $m \ge kn$，则 $m$ 落在该区间内，可以恰好印出，答案为 `0`；
- 若 $m < kn$，区间内不小于 $m$ 的最小值是 $kn$，答案为 $kn-m$。

即 $\max(0,\ kn-m)$。纸包个数尽量少时区间整体更靠左，更容易得到最少浪费。

## 复杂度分析

每组 $O(1)$。时间复杂度 $O(T)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
def solve_one(n, m):
    k = (m + n) // (n + 1)
    return max(0, k * n - m)


def main():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        print(solve_one(n, m))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {

    public static long solveOne(long n, long m) {
        long k = (m + n) / (n + 1);
        return Math.max(0L, k * n - m);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        while (t-- > 0) {
            long n = sc.nextLong();
            long m = sc.nextLong();
            System.out.println(solveOne(n, m));
        }
        sc.close();
    }
}
```
