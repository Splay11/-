## 解题思路

1. 设密码字符串 $S$ 的长度为 $n$，第 $i$ 位数字为 $S[i]$（字符 `0`～`9`）。  
2. 操作过程：先等概率选择一个位置 $i$，概率为 $1/n$；然后将该位置上的字符等概率修改为 `0`～`9` 中的任意一个字符，概率为 $1/10$。因此整个操作对应的样本空间大小为 $n \times 10$。  
3. 因为只有一位被修改，其他位均保持不变，新字符串 $T$ 与原串 $S$ 的字典序大小关系完全由被修改的这一位决定。  
   - 若修改后该位数字 $y$ 满足 $y > S[i]$，则 $T$ 字典序严格大于 $S$；  
   - 若 $y \le S[i]$，则 $T$ 字典序小于或等于 $S$。  
4. 对于第 $i$ 位，能使 $T$ 字典序严格大于 $S$ 的可选数字有 $(9 - S[i])$ 个（即 $S[i]+1$ 到 $9$）。  
5. 因此，所有成功情况的方案总数为  

   \[
   p = \sum_{i=0}^{n-1} \bigl(9 - S[i]\bigr)
   \]  

   所有等可能情况的方案总数为  

   \[
   q = 10n
   \]  

   则概率为 $\frac{p}{q}$。  
6. 题目要求输出 $p \cdot q^{-1} \bmod M$，其中 $M$ 是输入的质数，且保证 $q=10n$ 与 $M$ 互质，因此 $q$ 在模 $M$ 下的逆元存在。  
7. 利用费马小定理求逆元：$q^{-1} \equiv q^{M-2} \pmod M$，使用快速幂计算。  
8. 最终答案为 $(p \bmod M) \times q^{-1} \bmod M$。  

## 复杂度分析

- **时间复杂度**：$O(n + \log M)$。需要遍历整个字符串累加分子，以及进行一次快速幂。  
- **空间复杂度**：$O(1)$，仅使用少数变量，不计入输入字符串的存储开销。  

## 代码实现

### Python

```python
def qpow(a, b, mod):
    """快速幂，计算 a^b % mod"""
    res = 1
    a %= mod
    while b:
        if b & 1:
            res = res * a % mod
        a = a * a % mod
        b >>= 1
    return res


def solve(S: str, M: int) -> int:
    p = 0
    # 累加分子 p = sum(9 - 当前位数字)
    for ch in S:
        p += 9 - int(ch)
    p %= M

    n = len(S)
    # 分母 q = 10 * n
    q = (10 * n) % M

    # 计算逆元 q^(M-2) mod M
    q_inv = qpow(q, M - 2, M)

    return (p * q_inv) % M


if __name__ == '__main__':
    S, M_str = input().split()
    M = int(M_str)
    print(solve(S, M))
```

### Java

```java
import java.util.Scanner;

public class Main {

    // 快速幂 a^b % mod
    private static long qpow(long a, long b, long mod) {
        long res = 1;
        a %= mod;
        while (b > 0) {
            if ((b & 1) == 1) {
                res = res * a % mod;
            }
            a = a * a % mod;
            b >>= 1;
        }
        return res;
    }

    // 计算答案
    private static long solve(String S, long M) {
        long p = 0;
        // 累加分子 p = sum(9 - 当前位数字)
        for (int i = 0; i < S.length(); i++) {
            int d = S.charAt(i) - '0';
            p = (p + 9 - d) % M;
        }

        // 分母 q = 10 * n
        long n = S.length();
        long q = (10 * n) % M;

        // 逆元
        long qInv = qpow(q, M - 2, M);

        return (p * qInv) % M;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String S = sc.next();
        long M = sc.nextLong();
        System.out.println(solve(S, M));
        sc.close();
    }
}
```

```cpp
long long solve(const string& S, long long M) {
```
