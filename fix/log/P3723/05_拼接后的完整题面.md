# 题目内容
省级广播中心给每套节目分配一个三位频道号 $n$。为防止号段被误登记进播出表，中心规定了一条自洽规则：频道号必须恰好等于其百位、十位、个位三个数字的立方之和，才允许写入正式表；否则必须退回重编。值班员拿到一个待审频道号，需要立刻给出校验结论。

形式化地：设 $n$ 的十进制表示为 $abc$（$a,b,c$ 为各位数字且 $a 
eq 0$），当且仅当 $n = a^3 + b^3 + c^3$ 时输出 `YES`，否则输出 `NO`。

约束：输入保证 $n$ 是三位正整数，即 $10^2 \le n \le 999$。

# 输入描述
输入一行一个整数 $n$，表示待判定的频道号。
保证 $10^2 \le n \le 999$。

# 输出描述
输出一行，为 `YES` 或 `NO`，表示 $n$ 是否通过自洽校验。

## 样例1

**输入**

```
370
```

**输出**

```
YES
```

**说明**

编号 $370$ 的各位为 `3`、`7`、`0`。

立方和为 $3^3+7^3+0^3=27+343+0=370$，与自身相等，输出 `YES`。

## 样例2

**输入**

```
200
```

**输出**

```
NO
```

**说明**

编号 $200$ 的各位为 `2`、`0`、`0`。

立方和为 $2^3+0^3+0^3=8$，不等于 $200$，输出 `NO`。

## 样例3

**输入**

```
407
```

**输出**

```
YES
```

**说明**

编号 $407$ 满足 $4^3+0^3+7^3=64+0+343=407$，输出 `YES`。
