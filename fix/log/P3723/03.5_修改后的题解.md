## 解题思路

判断三位频道号 $n$ 是否等于其百位、十位、个位的立方和。

1. 拆位：$a = n // 100$，$b = (n // 10) \bmod 10$，$c = n \bmod 10$。
2. 计算 $s = a^3 + b^3 + c^3$。
3. 若 $s = n$ 输出 `YES`，否则输出 `NO`。

只需若干次整数运算，无需枚举其它编号。

## 复杂度分析

时间复杂度 $O(1)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
def is_cubic(n: int) -> bool:
    a = n // 100
    b = (n // 10) % 10
    c = n % 10
    return a**3 + b**3 + c**3 == n

def main():
    n = int(input().strip())
    print("YES" if is_cubic(n) else "NO")

if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static boolean isCubic(int n) {
        int a = n / 100;
        int b = (n / 10) % 10;
        int c = n % 10;
        int sum = a * a * a + b * b * b + c * c * c;
        return sum == n;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        System.out.println(isCubic(n) ? "YES" : "NO");
        sc.close();
    }
}
```
