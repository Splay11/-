# 题目内容
研究员获得一张 $n$ 行 $m$ 列的生态网格地图，每个格子栖息一种昆虫，用小写字母 $c_{i,j}$ 表示其类别。定义两个格子在上下左右相邻时 $(|x_1-x_2|+|y_1-y_2|=1)$ 称为相邻。连通的同类格子构成一个“栖息群落”，即同一群落内任意两个格子可通过若干步相邻移动到达且途中格子类别相同。

对于网格中每一个格子，请回答：该格子所属的栖息群落与多少种其他昆虫相邻（即群落边界上存在相邻的不同类别格子，统计这些不同类别的数量，不包含自身类别）。

数据范围：行数 $n$ 与列数 $m$ 满足 $1 \le n, m \le 500$。网格中所有字符均为小写字母。

# 输入描述
第一行包含两个整数 $n$ 和 $m$，表示网格的行数和列数。
接下来 $n$ 行，每行一个长度为 $m$ 的由小写字母组成的字符串，第 $i$ 行第 $j$ 个字符代表格子 $(i,j)$ 的昆虫类别。

# 输出描述
输出 $n$ 行，每行 $m$ 个由空格分隔的整数。第 $i$ 行第 $j$ 个整数表示格子 $(i,j)$ 所在栖息群落相邻的其他昆虫种类数。

## 样例1

**输入**

```
2 2
ab
ba
```

**输出**

```
1 1 
1 1
```

**说明**

网格为 $2 \times 2$，所有相邻格子类别均不相同。
左上角 `a` 的相邻格子为右方的 `b` 与下方的 `b`，相邻不同种类只有 `b`，故答案为 `1`。
右上角 `b` 的相邻格子为左方的 `a` 与下方的 `a`，相邻种类只有 `a`，答案为 `1`。
左下角 `b` 同理答案为 `1`，右下角 `a` 答案为 `1`。
每个格子所属群落仅包含自身，边界上均只有 `1` 种其他昆虫。

## 样例2

**输入**

```
3 3
aaa
bbb
aaa
```

**输出**

```
1 1 1 
1 1 1 
1 1 1
```

**说明**

网格中出现三个连通群落：上方 `a` 群落（第 `1` 行）、中间 `b` 群落（第 `2` 行）、下方 `a` 群落（第 `3` 行）。
上方 `a` 群落与中间的 `b` 相邻，相邻其他昆虫种类数为 `1`（只有 `b`）。
中间 `b` 群落与上下两个 `a` 群落均相邻，但这两个群落属于同一种昆虫 `a`，因此统计不同类别时只计 `1` 种（即 `a`）。
下方 `a` 群落与中间的 `b` 相邻，种类数也为 `1`。
所有格子输出均为 `1`，因为题目统计的是不同昆虫的类别数量，而不是群落数量。

## 样例3

**输入**

```
3 3
abc
def
ghi
```

**输出**

```
2 3 2 
3 4 3 
2 3 2
```

**说明**

网格中所有字母互不相同，每个格子自成一个群落。
四角的格子（`a`、`c`、`g`、`i`）均只有 `2` 个相邻格子，且类别都不同，故答案为 `2`。
四条边中间的格子（`b`、`d`、`f`、`h`）有 `3` 个相邻格子，答案为 `3`。
中心的格子 `e` 有 `4` 个相邻格子，且类别分别为 `b`、`d`、`f`、`h`，答案为 `4`。
该样例体现了角落、边缘、中心的不同相邻计数。

## 样例4

**输入**

```
3 4
aabb
aacc
aadd
```

**输出**

```
3 3 2 2 
3 3 3 3 
3 3 2 2
```

**说明**

左侧 `a` 形成一个 $3 \times 2$ 的连通群落，右侧 `b`、`c`、`d` 各为 $1 \times 2$ 的群落。
`a` 群落右边界同时与 `b`、`c`、`d` 三种昆虫相邻，因此该群落内所有 `a` 格子的答案均为 `3`。
`b` 群落左邻 `a`，下方邻 `c`，故相邻种类数为 `2`（`a` 与 `c`）。
`c` 群落左邻 `a`，上方邻 `b`，下方邻 `d`，种类数为 `3`（`a`、`b`、`d`）。
`d` 群落左邻 `a`，上方邻 `c`，种类数为 `2`。
该样例展示了一个群落同时与多个不同类别相邻的情形。
