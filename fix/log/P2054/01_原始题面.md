# 题目内容

小明认为一个整数是完美数，当且仅当这个数字上的数位包含$0$~$9$的所有数字。

小明有一个整数$x$，他希望你帮他构造一个大于$x$的整数$y$，使得$x×y$是一个完美数。

# 输入描述

每个测试文件均包含多组测试数据。第一行输入一个整数$T(1≤T≤1000)$代表数据组数，每组测试数据描述如下：

在一行上输入一个整数$x(1≤x≤10^8)$代表小明的初始数字。

# 输出描述

对于每一组测试数据，在一行上输出一个整数$y$代表答案。你需要保证$x<y≤2×10^{10}$ 。

如果存在多个解决方案，您可以输出任意一个，系统会动判定是否正确。

注意，自测运行功能可能因此返回错误结果，请自行检查答案正确性。

## 示例1

**输入**

```
2
500
63
```

**输出**

```
18469033416
1994203
```
