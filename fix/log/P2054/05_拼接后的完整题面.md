# 题目内容
我们称一个正整数是“全数字数”，当且仅当它的十进制表示中，数字 $0$ 到 $9$ 每个都至少出现一次。

给定一个正整数 $x$，请你构造一个大于 $x$ 的整数 $y$，使得乘积 $x \times y$ 是一个全数字数。你必须保证 $x < y \le 2 \times 10^{10}$。可以证明这样的 $y$ 总是存在。如果存在多个可行的 $y$，输出任意一个均视为正确。

约束条件：测试数据组数 $T$ 不超过 $1000$，给定的整数 $x$ 满足 $1 \le x \le 10^8$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据组数。接下来 $T$ 行，每行包含一个整数 $x$，含义如题目所述。

# 输出描述
对于每组测试数据，输出一行一个整数 $y$，要求满足 $x < y \le 2 \times 10^{10}$，且 $x \times y$ 为全数字数。

## 样例1

**输入**

```
1
2
```

**输出**

```
6172839451
```

**说明**

$x = 2$。
构造数字 $P = 12345678902$（在 `1234567890` 后拼接 $x$），$P$ 的十进制表示已包含数字 $0\sim9$。
计算 $y = P \,/\, 2 = 6172839451$。
验证：$2 \times 6172839451 = 12345678902$，仍为全数字数；同时 $2 < 6172839451 \le 2 \times 10^{10}$，符合要求。

## 样例2

**输入**

```
1
100000000
```

**输出**

```
12345678901
```

**说明**

$x = 10^8 = 100000000$。
构造 $P = 1234567890100000000$。
$y = P \,/\, 10^8 = 12345678901$。
乘积 $x \times y = 1234567890100000000$ 包含完整的 $0\sim9$，且 $10^8 < 12345678901 \le 2 \times 10^{10}$，满足条件。

## 样例3

**输入**

```
2
11
25
```

**输出**

```
11223344455
4938271561
```

**说明**

第一组：$x = 11$，$P = 123456789011$，$y = \lfloor P \,/\, 11 \rfloor = 11223344455$。乘积 $11 \times 11223344455 = 123456789005$，包含 $0\sim9$ 所有数字。
第二组：$x = 25$，$P = 123456789025$，$y = P \,/\, 25 = 4938271561$，乘积 $25 \times 4938271561 = 123456789025$ 为全数字数。
两组输出均满足 $x < y \le 2 \times 10^{10}$。
