# 题目内容
有 $n$ 个工位排成一行，编号为 $1$ 到 $n$。第 $i$ 个工位上原本放有 $a_i$ 件工件，且初始时每个工位上的工件数量恰好构成 $1$ 到 $n$ 的一个排列（即每个整数出现一次）。

你可以进行如下调整操作：
选择两个不同的工位 $i$ 和 $j$（$i 
eq j$），从工位 $j$ 取出一件工件放到工位 $i$ 上。这一操作会使 $a_i$ 增加 $1$，同时 $a_j$ 减少 $1$。操作必须满足：在操作完成后，所有工位的工件数量仍然构成 $1$ 到 $n$ 的一个排列。

你的目标是通过若干次操作，将序列变为严格递增的排列 $[1, 2, \dots, n]$，即对于每个 $i$，第 $i$ 个工位恰好有 $i$ 件工件。

请找出一组操作次数最少的方案。

数据范围：工位数量 $n$ 满足 $1 \le n \le 10^3$，初始序列 $a_1, a_2, \dots, a_n$ 是 $1$ 到 $n$ 的一个排列。

# 输入描述
第一行输入一个整数 $n$，表示工位数量。
第二行输入 $n$ 个整数 $a_1, a_2, \dots, a_n$，描述每个工位的初始工件数量。输入保证这 $n$ 个数构成 $1$ 到 $n$ 的一个排列。

# 输出描述
第一行输出一个整数 $k$，表示最少需要的操作次数。
接下来 $k$ 行，每行输出两个整数 $x_i, y_i$（$1 \le x_i, y_i \le n$，$x_i 
eq y_i$），表示第 $i$ 次操作选择的下标：将 $a_{x_i}$ 增加 $1$，$a_{y_i}$ 减少 $1$。
如果有多种最优方案，输出任意一种即可。

## 样例1

**输入**

```
1
1
```

**输出**

```
0
```

**说明**

工位数量 $n = 1$，初始序列为 $[1]$，已经等于目标排列 $[1]$，因此不需要任何操作，最少操作次数为 `0`。

## 样例2

**输入**

```
4
2 1 4 3
```

**输出**

```
2
2 1
4 3
```

**说明**

初始序列为 $[2,1,4,3]$。值为 $1$ 和 $2$ 的两个工位互相错位，值为 $3$ 和 $4$ 的两个工位也互相错位。最少操作次数等于排列的逆序对数 `2`。一种最优方案：
- 操作 `2 1`：将值为 `1` 和 `2` 的工位交换，序列变为 $[1,2,4,3]$；
- 操作 `4 3`：将值为 `3` 和 `4` 的工位交换，序列变为 $[1,2,3,4]$。

## 样例3

**输入**

```
4
4 3 2 1
```

**输出**

```
6
2 1
3 1
4 1
3 2
4 2
4 3
```

**说明**

初始序列为 $[4,3,2,1]$，是完全逆序的排列。最少操作次数等于值域位置排列的逆序对数 `6`。一种最优方案如下：
- 操作 `2 1`：交换值为 $3$ 和 $4$ 的位置，得 $[3,4,2,1]$；
- 操作 `3 1`：交换值为 $2$ 和 $3$ 的位置，得 $[2,4,3,1]$；
- 操作 `4 1`：交换值为 $1$ 和 $2$ 的位置，得 $[1,4,3,2]$；
- 操作 `3 2`：交换值为 $3$ 和 $4$ 的位置，得 $[1,3,4,2]$；
- 操作 `4 2`：交换值为 $2$ 和 $3$ 的位置，得 $[1,2,4,3]$；
- 操作 `4 3`：交换值为 $3$ 和 $4$ 的位置，得 $[1,2,3,4]$。

## 样例4

**输入**

```
5
2 3 1 5 4
```

**输出**

```
3
3 1
3 2
5 4
```

**说明**

初始序列为 $[2,3,1,5,4]$。值为 $1$、$2$、$3$ 的位置关系构成 $2$ 个逆序对，值为 $4$、$5$ 构成 $1$ 个逆序对，总最少操作次数为 `3`。一种最优方案：
- 操作 `3 1`：交换值为 $1$ 和 $2$ 的位置，得 $[1,3,2,5,4]$；
- 操作 `3 2`：交换值为 $2$ 和 $3$ 的位置，得 $[1,2,3,5,4]$；
- 操作 `5 4`：交换值为 $4$ 和 $5$ 的位置，得 $[1,2,3,4,5]$。
