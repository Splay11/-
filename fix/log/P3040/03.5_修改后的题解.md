## 解题思路

- **问题转化**：宝石呈圆环排列，小智的第一步可以任意选择一颗宝石，这等价于在圆环上选定一个突破口，使得剩余的宝石形成一个线性序列。因此，可以枚举所有可能的起始位置，将圆形序列转化为线性序列，然后分别求解，最后取最大值。
- **动态规划定义**：对于某个固定的起始点得到的线性宝石序列 `v[0..N-1]`，定义 `DP[l][r]` 表示当前剩下的宝石为区间 `[l, r]`，且**轮到小智行动**时，小智最终能获得的最大宝石价值总和。
- **状态转移**：
  - 若小智选择左端宝石 `v[l]`，则小智立即获得 `v[l]`。此后轮到小贪行动，他会比较当前缺口两端 `v[l+1]` 和 `v[r]` 的价值，并取走较大的那一颗：
    - 若 `v[l+1] >= v[r]`，小贪取走 `v[l+1]`，区间变为 `[l+2, r]`；
    - 否则小贪取走 `v[r]`，区间变为 `[l+1, r-1]`。
    小智在后续子区间中仍为先手，因此该选择下小智能获得的总价值为 `v[l] + DP[子区间]`。
  - 若小智选择右端宝石 `v[r]`，则小智获得 `v[r]`，小贪比较 `v[l]` 和 `v[r-1]` 并取走较大者：
    - 若 `v[l] >= v[r-1]`，区间变为 `[l+1, r-1]`；
    - 否则区间变为 `[l, r-2]`。
    总价值为 `v[r] + DP[子区间]`。
  - `DP[l][r]` 取上述两种选择中的较大值。
- **边界条件**：当区间长度为 1 时（`l == r`），只剩一颗宝石，小智直接取走，故 `DP[l][l] = v[l]`。
- **求解顺序**：按照区间长度 `len` 从 2 到 `N` 递增的顺序计算 DP 表，最终 `DP[0][N-1]` 即为在该线性序列下小智能获得的最大总价值。
- **答案**：枚举所有可能的 `N` 个起始位置，对每个起始点构建线性数组并计算 `DP[0][N-1]`，取全局最大值输出。

## 复杂度分析

- **时间复杂度**：外层枚举起始点需要 $O(N)$ 次；每轮计算 DP 表时有 $O(N^2)$ 个状态，每次转移仅需 $O(1)$ 时间，因此总时间复杂度为 $O(N^3)$。根据题目限制 $N < 500$，最坏情况约为 $1.25 \times 10^8$ 次运算，在 C++/Java 的较优实现下可以通过，Python 可能需要额外优化或运行稍慢。
- **空间复杂度**：DP 表大小为 $N \times N$，可以复用，整体空间复杂度为 $O(N^2)$。

## 代码实现

### Python

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    N = int(next(it))
    values = []
    for _ in range(N):
        values.append(int(next(it)))
    
    max_score = 0
    
    for start in range(N):
        # 构建以 start 为起点的线性宝石序列
        linear = values[start:] + values[:start]
        
        # DP[l][r] 表示当前区间 [l, r] 轮到小智时，他能获得的最大总价值
        dp = [[0] * N for _ in range(N)]
        
        # 区间长度为 1
        for i in range(N):
            dp[i][i] = linear[i]
        
        # 按区间长度递推
        for length in range(2, N + 1):
            for l in range(0, N - length + 1):
                r = l + length - 1
                
                # 小智选择左端
                take_left = linear[l]
                if linear[l + 1] >= linear[r]:
                    # 小贪取走 l+1
                    next_val = dp[l + 2][r] if l + 2 <= r else 0
                else:
                    # 小贪取走 r
                    next_val = dp[l + 1][r - 1] if l + 1 <= r - 1 else 0
                total_left = take_left + next_val
                
                # 小智选择右端
                take_right = linear[r]
                if linear[l] >= linear[r - 1]:
                    # 小贪取走 l
                    next_val = dp[l + 1][r - 1] if l + 1 <= r - 1 else 0
                else:
                    # 小贪取走 r-1
                    next_val = dp[l][r - 2] if l <= r - 2 else 0
                total_right = take_right + next_val
                
                dp[l][r] = max(total_left, total_right)
        
        max_score = max(max_score, dp[0][N - 1])
    
    print(max_score)

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine().trim());
        long[] values = new long[N];
        for (int i = 0; i < N; i++) {
            values[i] = Long.parseLong(br.readLine().trim());
        }
        
        long maxScore = 0;
        
        for (int start = 0; start < N; start++) {
            long[] linear = new long[N];
            for (int i = 0; i < N; i++) {
                linear[i] = values[(start + i) % N];
            }
            
            long[][] dp = new long[N][N];
            
            // 初始化长度为1的区间
            for (int i = 0; i < N; i++) {
                dp[i][i] = linear[i];
            }
            
            // 按区间长度递推
            for (int len = 2; len <= N; len++) {
                for (int l = 0; l + len <= N; l++) {
                    int r = l + len - 1;
                    
                    // 小智选左端
                    long takeLeft = linear[l];
                    long nextLeft;
                    if (linear[l + 1] >= linear[r]) {
                        nextLeft = (l + 2 <= r) ? dp[l + 2][r] : 0;
                    } else {
                        nextLeft = (l + 1 <= r - 1) ? dp[l + 1][r - 1] : 0;
                    }
                    long totalLeft = takeLeft + nextLeft;
                    
                    // 小智选右端
                    long takeRight = linear[r];
                    long nextRight;
                    if (linear[l] >= linear[r - 1]) {
                        nextRight = (l + 1 <= r - 1) ? dp[l + 1][r - 1] : 0;
                    } else {
                        nextRight = (l <= r - 2) ? dp[l][r - 2] : 0;
                    }
                    long totalRight = takeRight + nextRight;
                    
                    dp[l][r] = Math.max(totalLeft, totalRight);
                }
            }
            
            maxScore = Math.max(maxScore, dp[0][N - 1]);
        }
        
        System.out.println(maxScore);
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

typedef long long ll;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int N;
    cin >> N;
    vector<ll> gems(N);
    for (int i = 0; i < N; ++i) {
        cin >> gems[i];
    }
    
    ll maxScore = 0;
    
    // 枚举起始宝石
    for (int start = 0; start < N; ++start) {
        vector<ll> linear(N);
        for (int i = 0; i < N; ++i) {
            linear[i] = gems[(start + i) % N];
        }
        
        vector<vector<ll>> dp(N, vector<ll>(N, 0));
        
        // 区间长度为 1
        for (int i = 0; i < N; ++i) {
            dp[i][i] = linear[i];
        }
        
        // 按区间长度递推
        for (int len = 2; len <= N; ++len) {
            for (int l = 0; l + len <= N; ++l) {
                int r = l + len - 1;
                
                // 小智选择左端
                ll takeLeft = linear[l];
                ll nextLeft = 0;
                if (linear[l + 1] >= linear[r]) {
                    if (l + 2 <= r) nextLeft = dp[l + 2][r];
                } else {
                    if (l + 1 <= r - 1) nextLeft = dp[l + 1][r - 1];
                }
                ll totalLeft = takeLeft + nextLeft;
                
                // 小智选择右端
                ll takeRight = linear[r];
                ll nextRight = 0;
                if (linear[l] >= linear[r - 1]) {
                    if (l + 1 <= r - 1) nextRight = dp[l + 1][r - 1];
                } else {
                    if (l <= r - 2) nextRight = dp[l][r - 2];
                }
                ll totalRight = takeRight + nextRight;
                
                dp[l][r] = max(totalLeft, totalRight);
            }
        }
        
        maxScore = max(maxScore, dp[0][N - 1]);
    }
    
    cout << maxScore << "\n";
    return 0;
}
```
