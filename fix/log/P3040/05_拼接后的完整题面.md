# 题目内容
小智和小贪发现了一座古老神坛上呈圆环排列的一圈宝石，共有奇数颗。每颗宝石的价值都可以用一个正整数衡量，且所有宝石的价值互不相同。
两人决定通过轮流取宝石的方式来分配这些宝石，规则如下：
- 由小智先手，他可以任意选择一颗宝石取走，此时圆环出现一个缺口；
- 此后双方轮流行动，每次轮到的一方必须从缺口的两端（即紧邻已经取走区域的左右两颗宝石）中选择一颗取走；
- 小贪的策略非常直接：每次都会拿走缺口两端中价值更大的那一颗；
- 小智完全清楚小贪的这一策略，并会采取最优行动，以最大化自己最终获得的宝石总价值。
请你计算小智最多能拿走的宝石价值总和。
宝石的数量 `N` 为奇数，满足 $3 \le N < 500$。每颗宝石的价值均为正整数，且互不相同，范围在 $1 \le a_i \le 2147483647$。

# 输入描述
第一行包含一个奇数 `N`，表示宝石的数量。接下来 `N` 行，每行包含一个正整数，按顺时针顺序依次给出每颗宝石的价值。

# 输出描述
输出一个整数，表示小智能获得的最大宝石总价值。

## 样例1

**输入**

```
3
1
2
4
```

**输出**

```
5
```

**说明**

圆环上有 $3$ 颗宝石，价值依次为 `1`、`2`、`4`。
小智第一步可以选择任意一颗宝石。若他直接取走价值 `4` 的宝石，圆环断开后剩下的两颗宝石价值为 `1` 和 `2`，此时轮到小贪行动，小贪会取走两端中较大的 `2`，最后小智取走 `1`。小智总价值为 $4 + 1 = 5$。
若小智第一步取走 `1` 或 `2`，小贪随后都会取走 `4`，小智最终总价值为 $3$。因此小智最多能获得的总价值为 `5`。

## 样例2

**输入**

```
5
10
4
9
2
7
```

**输出**

```
21
```

**说明**

圆环按顺时针顺序有 $5$ 颗宝石，价值依次为 `10`、`4`、`9`、`2`、`7`。
小智第一步取走价值 `9` 的宝石，圆环出现缺口，缺口两端恰好是其左右邻居 `4` 和 `2`。小贪取走两端中较大的 `4`。此时剩余宝石形成一条链，两端为 `10` 和 `2`（例如顺序 `10, 7, 2`）。小智选择取走 `10`，剩余链两端为 `7` 和 `2`；小贪取走较大的 `7`，小智得到最后一颗 `2`。小智总价值为 $9 + 10 + 2 = 21$。
若第一步选择其他宝石，模拟可验证总价值均不超过 `21`。因此小智最优总和为 `21`。

## 样例3

**输入**

```
5
5
8
1
6
3
```

**输出**

```
15
```

**说明**

圆环宝石价值顺序为 `5`、`8`、`1`、`6`、`3`。
小智第一步取走 `6`，缺口两端为 `1` 和 `3`（`6` 的左右邻居）。小贪取走较大的 `3`，剩余宝石形成链，两端变为 `5` 和 `1`。小智取走 `5`，剩余链两端为 `8` 和 `1`；小贪取走 `8`，小智得到最后一颗 `1`。小智总价值为 $6 + 5 + 1 = 12$？此处需仔细模拟：
实际上第一步取 `6` 后，剩余宝石为 `5, 8, 1, 3`，两端是 `5` 和 `3`。小贪取走较大的 `5`，剩余链变为 `8, 1, 3`（两端 `8` 和 `3`）。小智取走 `8`，剩余 `1, 3`（两端 `1` 和 `3`），小贪取走 `3`，小智得 `1`。总价值 $6 + 8 + 1 = 15$。
若第一步取 `8`，总价值为 $12$；取 `5` 或 `3` 总价值为 $9$；取 `1` 总价值为 $10$。因此最优总价值为 `15`。
