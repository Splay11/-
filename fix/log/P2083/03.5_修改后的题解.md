## 解题思路

探测器在球形护盾内部做匀速直线运动，其坐标随时间变化满足：
$$
x = x_0 + u_x t,\quad y = y_0 + u_y t,\quad z = z_0 + u_z t
$$

当探测器首次触及球形护盾边界时，其位置落在球面上，即满足球面方程：
$$
x^2 + y^2 + z^2 = R^2
$$

将运动方程代入球面方程，整理后可得到关于时间 $t$ 的一元二次方程：
$$
a t^2 + b t + c = 0
$$

其中：
$$
a = u_x^2 + u_y^2 + u_z^2
$$
$$
b = 2\,(x_0 u_x + y_0 u_y + z_0 u_z)
$$
$$
c = x_0^2 + y_0^2 + z_0^2 - R^2
$$

题目保证初始时刻探测器在球形护盾内部（含球面），因此 $c \le 0$；同时速度向量非零，即 $a > 0$。此时一元二次方程必定存在两个实根（一个非正根，一个非负根），取非负根即为探测器首次触及球形护盾边界的最早时刻：

$$
t = \frac{-b + \sqrt{b^2 - 4ac}}{2a}
$$

算法直接利用上述公式计算即可。

## 复杂度分析

对于每组测试数据，只需要进行一次一元二次方程的求根计算，涉及常数次算术运算与一次开平方运算。

- 时间复杂度：$O(1)$（单组），总复杂度 $O(t)$，其中 $t$ 为数据组数。
- 空间复杂度：$O(1)$，仅使用常数个变量。

## 代码实现

### Python

```python
import math

def solve_one(x0, y0, z0, ux, uy, uz, r):
    # 二次项系数
    a = ux * ux + uy * uy + uz * uz
    # 一次项系数
    b = 2.0 * (x0 * ux + y0 * uy + z0 * uz)
    # 常数项
    c = x0 * x0 + y0 * y0 + z0 * z0 - r * r
    # 判别式
    delta = b * b - 4.0 * a * c
    # 取较大的非负根
    ans = (-b + math.sqrt(delta)) / (2.0 * a)
    return ans

def main():
    t = int(input())
    for _ in range(t):
        x0, y0, z0, ux, uy, uz, r = map(float, input().split())
        ans = solve_one(x0, y0, z0, ux, uy, uz, r)
        print(f"{ans:.10f}")

if __name__ == "__main__":
    main()
```

import java.util.Scanner;

public class Main {

    public static double solveOne(double x0, double y0, double z0,
                                  double ux, double uy, double uz, double r) {
        // 二次项系数
        double a = ux * ux + uy * uy + uz * uz;
        // 一次项系数
        double b = 2.0 * (x0 * ux + y0 * uy + z0 * uz);
        // 常数项
        double c = x0 * x0 + y0 * y0 + z0 * z0 - r * r;
        // 判别式
        double delta = b * b - 4.0 * a * c;
        // 取较大的非负根
        return (-b + Math.sqrt(delta)) / (2.0 * a);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        while (t-- > 0) {
            double x0 = sc.nextDouble();

            System.out.printf("%.10f%n", ans);
        }
        sc.close();
    }
}
