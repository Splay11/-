# 题目内容
某印刷厂按开本序号管理装订单。质检规程规定：第 $n$ 种开本的装订校验位必须取 $n!$ 的个位数字，用来核对装订线是否漏页。车间不必算出完整阶乘，只要给出这个个位数字。给定正整数 $n$，请输出对应的装订校验位。

其中

$$n! = 1 \times 2 \times \cdots \times n.$$

约束：开本序号至少为 `1`，且不超过 `1000000000`。

# 输入描述
输入一行一个整数 $n$，表示开本序号。
保证 $1 \le n \le 1000000000$。

# 输出描述
输出一个整数，表示 $n!$ 的个位数字。

## 样例1

**输入**

```
2
```

**输出**

```
2
```

**说明**

当 $n=`2`$ 时，$2!=2$，个位为 `2`。

## 样例2

**输入**

```
4
```

**输出**

```
4
```

**说明**

当 $n=`4`$ 时，$4!=24$，个位为 `4`。

## 样例3

**输入**

```
8
```

**输出**

```
0
```

**说明**

当 $n=`8`$ 时，$n\ge `5`$，阶乘中同时含因子 `2` 与 `5`，个位为 `0`。

## 样例4

**输入**

```
12
```

**输出**

```
0
```

**说明**

当 $n=`12`$ 时同样 $n\ge `5`$，校验尾码为 `0`。
