## 解题思路

题目要求输出第 $n$ 种开本的装订校验位，即 $n!$ 的个位数字，其中

$$
n! = 1 \times 2 \times 3 \times \cdots \times n
$$

不必真正把 $1$ 到 $n$ 乘起来。当 $n \ge 5$ 时，$n!$ 中一定同时含有因子 $2$ 和 $5$，从而含有因子 $10$，个位必为 $0$。

因此：

* $n = 1$ 时，$1! = 1$，校验位为 $1$
* $n = 2$ 时，$2! = 2$，校验位为 $2$
* $n = 3$ 时，$3! = 6$，校验位为 $6$
* $n = 4$ 时，$4! = 24$，校验位为 $4$
* $n \ge 5$ 时，校验位一定是 $0$

读入 $n$ 后按上述规则直接输出即可。

## 复杂度分析

时间复杂度 $O(1)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
def get_last_digit(n):
    # 当 n 大于等于 5 时，n! 一定含有因子 10，个位为 0
    if n >= 5:
        return 0

    # 处理 n 小于 5 的情况
    if n == 1:
        return 1
    if n == 2:
        return 2
    if n == 3:
        return 6
    return 4


def main():
    # 读入整数 n
    n = int(input())

    # 输出 n! 的个位数字
    print(get_last_digit(n))


if __name__ == "__main__":
    main()
```
