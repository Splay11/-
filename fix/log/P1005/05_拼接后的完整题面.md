# 题目内容
在一条无限长的星际航线上，有 $n$ 艘飞船正在匀速航行。每艘飞船有两个固有属性：初始坐标 $x_i$ 和恒定速度 $v_i$（向右为正方向，速度可以为负数）。

飞船上的智能系统允许任意交换飞船之间的初始坐标，但无法改变各自的航行速度。现在需要你通过若干次坐标交换，使得所有飞船在未来的任意时刻都不会发生碰撞（即任意两艘飞船的坐标永不相等）。

请你输出一种交换后的初始坐标分配方案，按原始飞船的编号顺序给出每艘飞船最终的初始坐标和速度。

数据范围：

飞船数量 $n$ 不超过 $10^5$。

初始坐标 $x_i$ 和速度 $v_i$ 的绝对值均不超过 $10^9$。

题目保证初始时所有飞船的坐标互不相同。

# 输入描述
第一行包含一个整数 $n$，表示飞船的数量。

接下来的 $n$ 行，每行包含两个用空格分隔的整数 $x_i$ 和 $v_i$，分别表示第 $i$ 艘飞船的初始坐标和恒定速度。

# 输出描述
输出 $n$ 行，每行两个整数，表示交换后第 $i$ 艘飞船最终的初始坐标和速度。如果存在多种合法方案，输出任意一种即可。

## 样例1

**输入**

```
2
0 1
5 -1
```

**输出**

```
5 1
0 -1
```

**说明**

初始有两艘飞船：飞船 `1` 位于 $x_1=0$ 以速度 $v_1=1$ 航行；飞船 `2` 位于 $x_2=5$ 以速度 $v_2=-1$ 航行。

原始方案中，它们相向而行：$0+t=5-t$ 解得 $t=2.5$，会在未来发生碰撞。

一种避免碰撞的交换方式是：将全部坐标 $[0,5]$ 按升序排序，全部速度 $[-1,1]$ 同样按升序排序。
将最小坐标 $0$ 分配给最小速度 $-1$（原飞船 `2`），将坐标 $5$ 分配给速度 $1$（原飞船 `1`）。

交换后：飞船 `1` 获得坐标 $5$、速度 $1$；飞船 `2` 获得坐标 $0$、速度 $-1$。此时两飞船背向航行，任意 $t \ge 0$ 时刻坐标之差为 $|(5+t)-(0-t)|=5+2t>0$，永不相等。

## 样例2

**输入**

```
3
10 2
20 2
30 1
```

**输出**

```
20 2
30 2
10 1
```

**说明**

三艘飞船：编号 `1` 速度 $2$，编号 `2` 速度 $2$，编号 `3` 速度 $1$。

将速度排序：最小速度 $1$（编号 `3`），其次两个速度 $2$（编号 `1` 和 `2`）。
同时将坐标 $[10,20,30]$ 升序排列。

分配：最小坐标 $10$ 分配给速度最小的飞船 `3`，坐标 $20$ 分配给飞船 `1`，坐标 $30$ 分配给飞船 `2`。

最终方案中，慢速飞船位于左侧（$x=10$），快速飞船位于右侧（$x=20,\,30$），它们之间的距离只会越来越大。两艘同速飞船分别位于 $20$ 和 $30$，速度相同且初始坐标不同，永不相遇。

## 样例3

**输入**

```
4
-10 -5
0 10
5 -10
-5 5
```

**输出**

```
-5 -5
5 10
-10 -10
0 5
```

**说明**

四艘飞船，包含负坐标与负速度。将速度升序排列：$-10$（飞船 `3`）、$-5$（飞船 `1`）、$5$（飞船 `4`）、$10$（飞船 `2`）。

将所有坐标升序排列：$-10,\,-5,\,0,\,5$。

按顺序一一对应：最小速度 $-10$ 获得最左坐标 $-10$，速度 $-5$ 获得 $-5$，速度 $5$ 获得 $0$，速度 $10$ 获得 $5$。

此时对于任意两艘飞船，若 $v_i < v_j$，必有 $x_i \le x_j$，相对速度向右且起始位置不交叉，未来不会碰撞；若速度相等，因坐标互异也不会相遇。

## 样例4

**输入**

```
1
100 50
```

**输出**

```
100 50
```

**说明**

仅有一艘飞船，无需交换坐标，直接输出原始坐标 $100$ 与速度 $50$。单个飞船不存在碰撞问题。
