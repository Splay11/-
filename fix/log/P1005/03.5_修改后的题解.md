## 解题思路

本题的目标是通过交换飞船的初始坐标，使得任意两艘飞船在未来的任意时刻都不会发生碰撞。碰撞的定义是两艘飞船的坐标在某一时刻相等。已知每艘飞船的速度不变，我们可以自由分配初始坐标集合，每艘飞船恰好获得一个不同的初始坐标。

**关键分析**：
- 对于两艘速度不同的飞船，设速度分别为 $v_i$ 和 $v_j$（不妨假设 $v_i < v_j$）。
  - 若最终坐标关系为 $x_i < x_j$，则慢的飞船在左、快的飞船在右，距离会越拉越大，永远不会碰撞。
  - 若最终坐标关系为 $x_i > x_j$，则快的飞船在左、慢的飞船在右，快的飞船会追上慢的飞船，发生碰撞。
- 对于两艘速度相同的飞船，它们之间的距离始终保持不变，只要初始坐标不同就不会碰撞（题目保证初始坐标互不相同，且交换后坐标集合不会改变，因此速度相同的飞船坐标必然不同）。

因此，一个充分且必要的无碰撞分配方案是：**将飞船按照速度从小到大排序，同时将所有初始坐标从小到大排序，然后将排序后第 $k$ 小的坐标分配给第 $k$ 小的速度的飞船**。这样就保证了对于任意 $v_i < v_j$，有 $x_i < x_j$，永远不会碰撞；速度相同的情况则不会出现坐标相等。

**算法步骤**：
1. 读入所有飞船的初始坐标 $x_i$ 和速度 $v_i$，并记录每艘飞船的原始编号（$1$ 到 $n$）。
2. 将所有坐标 $x_i$ 从小到大排序，得到有序的坐标列表。
3. 将所有飞船按速度 $v_i$ 从小到大排序。
4. 将排序后的坐标依次分配给排序后的飞船：速度最小的飞船得到最小的坐标，速度次小的飞船得到次小的坐标，依此类推。
5. 将飞船按照原始编号重新排序，然后依次输出每艘飞船最终分配的坐标和它的速度。

由于题目只要求输出任意一种合法方案，上述分配方案可以保证正确性。

## 复杂度分析

- **时间复杂度**：需要两次排序（坐标排序和飞船按速度排序）以及一次按编号排序，每次排序的时间复杂度均为 $O(n \log n)$，因此总时间复杂度为 $O(n \log n)$，其中 $n$ 是飞船数量。
- **空间复杂度**：需要存储坐标数组和飞船信息数组，额外空间为 $O(n)$。

## 代码实现

### Python

```python
n = int(input())
# ships: 存储 (速度, 原始编号), point: 存储所有初始坐标
ships = []
points = []

for i in range(n):
    x, v = map(int, input().split())
    points.append(x)
    ships.append([v, i])   # i 作为原始编号，从0开始

points.sort()               # 坐标从小到大排序
ships.sort()                # 按速度从小到大排序（默认按第一维速度排序）

# 将坐标分配给排序后的飞船
for k in range(n):
    ships[k].append(points[k])   # ships[k] 变成 [速度, 编号, 分配的坐标]

# 按原始编号排序，准备输出
ships.sort(key=lambda x: x[1])

for v, idx, x in ships:
    print(x, v)
```

### Java

```java
import java.util.*;

class Ship {
    int id;   // 原始编号
    int x;    // 分配后的坐标
    int v;    // 速度
}

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        Ship[] ships = new Ship[n];
        int[] points = new int[n];

        for (int i = 0; i < n; i++) {
            ships[i] = new Ship();
            ships[i].id = i;
            points[i] = sc.nextInt();
            ships[i].v = sc.nextInt();
        }

        // 坐标从小到大排序
        Arrays.sort(points);
        // 飞船按速度从小到大排序
        Arrays.sort(ships, Comparator.comparingInt(s -> s.v));

        // 分配坐标
        for (int i = 0; i < n; i++) {
            ships[i].x = points[i];
        }

        // 按原始编号排序
        Arrays.sort(ships, Comparator.comparingInt(s -> s.id));

        // 输出结果
        for (Ship s : ships) {
            System.out.println(s.x + " " + s.v);
        }
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

struct Ship {
    int id;   // 原始编号
    int x;    // 分配后的坐标
    int v;    // 速度
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<Ship> ships(n);
    vector<int> points(n);

    for (int i = 0; i < n; i++) {
        ships[i].id = i;
        cin >> points[i] >> ships[i].v;
    }

    // 坐标从小到大排序
    sort(points.begin(), points.end());
    // 飞船按速度从小到大排序
    sort(ships.begin(), ships.end(), [](const Ship& a, const Ship& b) {
        return a.v < b.v;
    });

    // 分配坐标
    for (int i = 0; i < n; i++) {
        ships[i].x = points[i];
    }

    // 按原始编号排序
    sort(ships.begin(), ships.end(), [](const Ship& a, const Ship& b) {
        return a.id < b.id;
    });

    // 输出
    for (const auto& s : ships) {
        cout << s.x << " " << s.v << '\n';
    }
    return 0;
}
```
