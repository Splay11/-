## 解题思路

本题要求从 $n$ 块符文石中选出至少一块构成非空的“和谐组合”，即所选符文石上数字的乘积是一个完全平方数。因为 $n \le 20$，可以采用状态压缩与子集枚举的方法求解。

1. **质因子奇偶性压缩**  
   一个数是完全平方数当且仅当它的每个质因子的指数均为偶数。  
   对于第 $i$ 块符文石的数字 $a_i$，将其质因数分解，并只关心每个质因子指数的奇偶性（模 2）。  
   用一个二进制掩码（mask）表示 $a_i$ 的质因子奇偶性：若某个质因子的指数为奇数，则对应二进制位为 1，否则为 0。  
   由于 $a_i \le 100$，涉及的素数不超过 25 个，因此掩码可以用一个 32 位整数表示。

2. **子集异或判零**  
   对于任意一个非空子集，其乘积的质因子总指数的奇偶性，等于该子集中所有元素的掩码进行**按位异或**的结果。  
   若异或结果为 0，说明每个质因子的总指数均为偶数，乘积即为完全平方数，该子集是一个和谐组合。

3. **枚举所有非空子集**  
   使用二进制掩码 `bm` 从 `1` 到 `2^n-1` 枚举所有非空子集。  
   对每一个子集，遍历所有符文石，若第 $i$ 块石头在子集中（`bm` 对应位为 1），则将它的掩码异或到临时变量 `x` 上。  
   统计 `x == 0` 的子集个数，即为答案。

## 复杂度分析

- **时间复杂度**：  
  - 预处理每块符文石的掩码：$O(n \cdot P \cdot \log a_i)$，其中 $P$ 为不超过 $100$ 的素数个数（约 25），可视为常数。  
  - 枚举所有子集并计算异或和：$O(2^n \cdot n)$。  
  当 $n=20$ 时，$2^{20} \approx 10^6$，总操作次数约 $2 \times 10^7$，可在时限内完成。  
  整体时间复杂度为 $O(2^n \cdot n)$。

- **空间复杂度**：  
  需要存储所有符文石的掩码以及素数列表，空间复杂度为 $O(n + P)$，约 $O(n)$。

## 代码实现

### Python

```python
import sys
input = sys.stdin.readline

# 读取输入
n = int(input().strip())
a = list(map(int, input().split()))

# 生成2~100范围内素数列表
primes = []
for x in range(2, 101):
    is_p = True
    for d in range(2, int(x**0.5) + 1):
        if x % d == 0:
            is_p = False
            break
    if is_p:
        primes.append(x)

# 计算每块符文石的质因子奇偶掩码
mask = [0] * n
for i, v in enumerate(a):
    value = v
    for j, p in enumerate(primes):
        cnt = 0
        while value % p == 0:
            value //= p
            cnt ^= 1          # 只保留奇偶性
        if cnt:
            mask[i] |= (1 << j)

# 枚举所有非空子集，统计异或和为0的方案
ans = 0
for bm in range(1, 1 << n):
    x = 0
    for i in range(n):
        if bm & (1 << i):
            x ^= mask[i]
    if x == 0:
        ans += 1

print(ans)
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        // 读取n块符文石
        int n = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }

        // 生成2~100范围内所有素数
        List<Integer> primes = new ArrayList<>();
        for (int x = 2; x <= 100; x++) {
            boolean isP = true;
            for (int d = 2; d * d <= x; d++) {
                if (x % d == 0) {
                    isP = false;
                    break;
                }
            }
            if (isP) primes.add(x);
        }

        int P = primes.size();
        int[] mask = new int[n];   // mask[i] 为第i块符文石的质因子奇偶掩码

        // 计算掩码
        for (int i = 0; i < n; i++) {
            int v = a[i];
            for (int j = 0; j < P; j++) {
                int cnt = 0;
                while (v % primes.get(j) == 0) {
                    v /= primes.get(j);
                    cnt ^= 1;
                }
                if (cnt == 1) {
                    mask[i] |= (1 << j);
                }
            }
        }

        long ans = 0;
        int total = 1 << n;
        // 枚举所有非空子集
        for (int bm = 1; bm < total; bm++) {
            int x = 0;
            for (int i = 0; i < n; i++) {
                if ((bm & (1 << i)) != 0) {
                    x ^= mask[i];
                }
            }
            if (x == 0) ans++;
        }

        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // 读取符文石数量及数字
    int n;
    cin >> n;
    vector<int> a(n);
    for(int i = 0; i < n; i++){
        cin >> a[i];
    }

    // 生成2~100范围内所有素数
    vector<int> primes;
    for(int x = 2; x <= 100; x++){
        bool isP = true;
        for(int d = 2; d*d <= x; d++){
            if(x % d == 0){ isP = false; break; }
        }
        if(isP) primes.push_back(x);
    }

    int P = primes.size();
    // mask[i] 的第 j 位表示 primes[j] 在 a[i] 中的指数模 2
    vector<int> mask(n, 0);

    // 计算每块符文石的掩码
    for(int i = 0; i < n; i++){
        int v = a[i];
        for(int j = 0; j < P; j++){
            int cnt = 0;
            while(v % primes[j] == 0){
                v /= primes[j];
                cnt ^= 1;      // 只关心奇偶性
            }
            if(cnt) mask[i] |= (1 << j);
        }
    }

    long long ans = 0;
    int total = 1 << n;
    // 枚举所有非空子集
    for(int bm = 1; bm < total; bm++){
        int x = 0;
        for(int i = 0; i < n; i++){
            if(bm & (1 << i)) x ^= mask[i];
        }
        if(x == 0) ans++;
    }

    cout << ans << "\n";
    return 0;
}
```
