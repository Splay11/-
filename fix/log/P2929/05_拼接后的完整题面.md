# 题目内容
在古老的魔法阵中，符文师拥有若干块符文石，每块石头上刻有一个正整数。如果一组符文石上的数字乘积恰好是一个完全平方数，则称这组符文石是“和谐组合”。

现在符文师希望从所有符文石中挑选出至少一块，使得这些符文石构成一个和谐组合。你需要计算一共有多少种不同的挑选方案。注意，不同位置上的符文石即使数字相同，也被视为不同的选择。

约束条件：
- 符文石的总数 $n$ 满足 $n \le 20$。
- 每块符文石上的数字 $a_i$ 满足 $1 \le a_i \le 100$。

# 输入描述
第一行包含一个整数 $n$，表示符文石的数量。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$，表示每块符文石上的数字，相邻整数之间用空格分隔。
输入保证 $n \le 20$ 且所有 $a_i$ 均为不超过 $100$ 的正整数。

# 输出描述
输出一个整数，表示挑选出非空和谐组合的方案总数。

## 样例1

**输入**

```
3
1 4 9
```

**输出**

```
7
```

**说明**

每块符文石都是完全平方数（`1`=$1^2$，`4`=$2^2$，`9`=$3^2$），其质因子指数均为偶数，对应的奇偶性向量为零向量。因此任意非空子集的向量异或和均为零向量，乘积均为完全平方数。非空子集总数为 $2^3 - 1 = 7$，故答案为 `7`。

## 样例2

**输入**

```
2
2 2
```

**输出**

```
1
```

**说明**

两块符文石数字均为 `2`。`2` 的质因子只有 $2^1$，指数为奇数，对应向量 $(1)$。只有同时选取两块符文石，向量异或和为 $(1)\oplus(1)=0$，乘积 $2\times2=4=2^2$ 为完全平方数。单独选取任一块乘积为 `2`，不是完全平方数。因此只有 `1` 种方案。

## 样例3

**输入**

```
4
2 3 6 1
```

**输出**

```
3
```

**说明**

将数字转化为质因子奇偶性向量（考虑质因子 $2$ 和 $3$）：`2`→$(1,0)$，`3`→$(0,1)$，`6`→$(1,1)$，`1`→$(0,0)$。要求所选向量异或和为 $(0,0)$。四个向量秩为 $2$，解空间维数 $n-r=4-2=2$，包含空集共 $2^2=4$ 个解。非空解有 `3` 个：仅选 `1`；选 `2,3,6`；选 `1,2,3,4`。它们的乘积分别为 $1=1^2$，$2\times3\times6=36=6^2$，$1\times2\times3\times6=36=6^2$，均为完全平方数。

## 样例4

**输入**

```
1
5
```

**输出**

```
0
```

**说明**

只有一块符文石，数字 `5`。`5` 的质因子 $5^1$ 指数为奇数，不是完全平方数。无法选出非空和谐组合，答案为 `0`。
