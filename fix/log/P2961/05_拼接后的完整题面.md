# 题目内容
你面前有一排 $n$ 个货箱，每个货箱上贴有一个唯一的优先级编号，这些编号恰好是 $1$ 到 $n$ 的一个排列。第 $i$ 个货箱的优先级为 $a_i$。你希望将货箱按照优先级从小到大的顺序重新排列（即最终排列为 $1, 2, \dots, n$）。

由于货架空间的限制，每次你只能选择两个优先级相差不超过 $k$ 的货箱，并交换它们在序列中的位置。交换时，若两个货箱的优先级之差的绝对值为 $1$，你会因为操作精细而消耗 $1$ 单位体力；若差的绝对值大于 $1$，则不消耗体力。

请你计算，想要完成排序，最少需要消耗多少体力。

数据范围：货箱数量 $n$ 满足 $4 \le n \le 2 \times 10^5$，操作限制参数 $k$ 满足 $1 \le k \le n-1$。优先级序列 $a_1, a_2, \dots, a_n$ 是 $1$ 到 $n$ 的一个排列。

# 输入描述
第一行包含两个整数 $n$ 和 $k$，分别表示货箱的数量和交换时允许的最大优先级差。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$，表示初始时从左到右每个货箱的优先级，保证这 $n$ 个数是 $1$ 到 $n$ 的一个排列。

# 输出描述
输出一个整数，表示完成排序所需的最少体力消耗。

## 样例1

**输入**

```
4 1
4 3 2 1
```

**输出**

```
6
```

**说明**

参数 $k=1$，只能交换优先级差为 $1$ 的货箱，即只能交换数值相邻的货箱，每次交换消耗 $1$ 体力。此时问题等价于只允许相邻值交换的冒泡排序。初始排列 `4 3 2 1` 的逆序对数为 $6$，要将其变为目标排列 `1 2 3 4`，至少需要 $6$ 次相邻值交换，因此最少体力消耗为 `6`。

## 样例2

**输入**

```
5 2
2 3 1 5 4
```

**输出**

```
2
```

**说明**

参数 $k=2$，允许交换优先级差为 $1$（消耗 $1$ 体力）或 $2$（不消耗体力）。差值为 $2$ 的交换只能在同为奇数或同为偶数的货箱之间进行，无法改变元素所在位置的奇偶性。目标排列中奇数位置（第 $1,3,5$ 个）应放奇数，偶数位置（第 $2,4$ 个）应放偶数。

初始排列 `2 3 1 5 4` 中，奇数 `1,3,5` 位于位置 `2,3,4`（其中 $2$ 个在偶数位置），偶数 `2,4` 位于位置 `1,5`（均在奇数位置）。共有 $2$ 个奇数错放在偶数位置，$2$ 个偶数错放在奇数位置。每次差值为 $1$ 的交换可以纠正一对奇偶错位，且无法通过差值为 $2$ 的交换减少错位数，因此至少需要 $2$ 次消耗 $1$ 体力的交换。可以构造方案恰好消耗 $2$ 体力，故答案为 `2`。

## 样例3

**输入**

```
5 3
5 4 3 2 1
```

**输出**

```
0
```

**说明**

参数 $k=3$，允许交换优先级差为 $2$ 或 $3$ 的货箱，且这些交换均不消耗体力。优先级编号 $1$ 到 $5$ 中，差值为 $2$ 或 $3$ 的货箱对构成一张连通图（例如 $1$ 连 $3,4$；$2$ 连 $4,5$ 等），并且对换是奇置换，因此这些无代价交换可以生成整个置换群 $S_5$。

对于任意初始排列，都可以仅通过体力消耗为 $0$ 的交换将其变为目标排列 `1 2 3 4 5`。因此对排列 `5 4 3 2 1`，最少体力消耗为 `0`。
