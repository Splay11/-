# 题目内容
展陈设计师要在一条长度为 $n$ 的直线展台上摆放展品。馆方规定：各展位件数必须是正整数，且陈列必须左右对称，即对任意 $i$（$1 \le i \le n$）都有 $a_i = a_{n-i+1}$。策划部进一步要求确认：是否对所有满足 $m \ge n$ 的正整数总件数 $m$，都存在一种长度为 $n$ 的对称陈列，使其件数之和恰好等于 $m$。若是，输出 `Yes`；否则输出 `No`。

约束：测试组数不超过 `10000`，每组的 $n$ 不超过 `1000000000`。

# 输入描述
第一行一个整数 $T$，表示组数。
接下来 $T$ 行，每行一个整数 $n$，表示展台长度。
保证 $1 \le T \le 10000$，$1 \le n \le 1000000000$。

# 输出描述
对每组数据输出一行 `Yes` 或 `No`。

## 样例1

**输入**

```
5
3
4
7
8
11
```

**输出**

```
Yes
No
Yes
No
Yes
```

**说明**

长度为奇数时中间位置可调，任意 $m \ge n$ 都能构成对称正整数序列，输出 `Yes`；长度为偶数时元素和只能是偶数，无法覆盖所有 $m$，输出 `No`。

因此 `3,7,11` 输出 `Yes`，`4,8` 输出 `No`。

## 样例2

**输入**

```
2
9
100
```

**输出**

```
Yes
No
```

**说明**

`9` 为奇数，输出 `Yes`；`100` 为偶数，输出 `No`。
