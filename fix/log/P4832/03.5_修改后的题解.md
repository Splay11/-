## 解题思路

长度为 $n$ 的对称陈列，必须满足 $a_i = a_{n-i+1}$，且各展位件数为正整数。

当 $n$ 为偶数时，展位成对出现，例如长度为 `4` 时形如 $[x,y,y,x]$，总和 $2(x+y)$ 恒为偶数。但 $m \ge n$ 中既有奇数也有偶数，无法对所有总件数 $m$ 都构造，故答案为 `No`。

当 $n$ 为奇数时，两侧成对、中间有一个可自由取值的位置。把两侧都放 `1`，中间放 $x = m-(n-1)$。由 $m \ge n$ 得 $x \ge 1$，因此任意 $m \ge n$ 都可以构造，答案为 `Yes`。

结论：奇数输出 `Yes`，偶数输出 `No`。

## 复杂度分析

每组 $O(1)$。总时间复杂度 $O(T)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
def solve(n):
    return "Yes" if n % 2 == 1 else "No"


if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        n = int(input())
        print(solve(n))
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static String solve(long n) {
        return (n % 2 == 1) ? "Yes" : "No";
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        while (t-- > 0) {
            long n = sc.nextLong();
            System.out.println(solve(n));
        }
        sc.close();
    }
}
```
