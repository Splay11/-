# 题目内容
你需要构造一个 $R$ 行 $C$ 列的矩阵，矩阵中的每个元素都是正整数。要求矩阵的每一行、每一列均构成等差数列，且所有元素之和恰好等于 $S$。
如果存在这样的矩阵，请输出任意一个；如果无解，输出 $-1$。

行数 $R$ 和列数 $C$ 均不超过 $500$，目标和 $S$ 不超过 $10^{18}$。

# 输入描述
第一行包含三个正整数 $R, C, S$，分别表示矩阵的行数、列数和目标总和。

# 输出描述
若有解，输出 $R$ 行，每行 $C$ 个正整数，表示构造出的矩阵。若无法构造，仅输出 $-1$。

## 样例1

**输入**

```
3 3 45
```

**输出**

```
4 4 4
5 5 5
6 6 6
```

**说明**

输入矩阵规模 $R=3$, $C=3$，目标和 $S=45$。构造方法：令每行内所有元素相等，每行间构成公差为 $d$ 的等差数列，首行值为 $a_1$。矩阵总和可表示为 $R \times C \times a_1 + \frac{R(R-1)}{2} \times C \times d$，化简得到 $2S / (R \times C) = 2a_1 + (R-1)d$。这里 $2S/(R \times C) = 90/9 = 10$，即 $2a_1 + 2d = 10$。取 $d=1$，解得 $a_1=4$，均为正整数。因此构造矩阵：每行均为常数，第 $1$ 行全为 `4`，第 $2$ 行全为 `5`，第 $3$ 行全为 `6`。该矩阵每一行（常数列）和每一列（`4,5,6` 公差 $1$）均构成等差数列，且总和为 $3 \times (4+5+6) = 45$，满足要求。

## 样例2

**输入**

```
2 2 3
```

**输出**

```
-1
```

**说明**

输入 $R=2$, $C=2$, $S=3$。根据推导，若存在满足条件的正整数矩阵，则 $2S$ 必须能被 $R \times C$ 整除。这里 $2S = 6$，$R \times C = 4$，$6$ 不是 $4$ 的倍数，无法继续构造，因此无解，输出 `-1`。

## 样例3

**输入**

```
2 2 5
```

**输出**

```
1 1
1 2
```

**说明**

输入 $R=2$, $C=2$, $S=5$。此时 $R \le 2$ 且 $C \le 2$，且 $R \times C = 4 \le 5 = S$，属于特殊情形。采用特殊构造：前 $R-1=1$ 行全部元素填 `1`，最后一行前 $C-1=1$ 个元素填 `1`，最后一个元素填 $S - R \times C + 1 = 5 - 4 + 1 = 2$。得到的矩阵为第 $1$ 行 `1 1`，第 $2$ 行 `1 2`。该矩阵每一行和每一列（均为两个元素）都构成等差数列，且总和为 $1+1+1+2 = 5$，符合要求。

## 样例4

**输入**

```
2 3 12
```

**输出**

```
1 1 1
3 3 3
```

**说明**

输入 $R=2$, $C=3$, $S=12$。根据构造公式 $2S/(R \times C) = 2a_1 + (R-1)d$，计算得 $24/6 = 4$，即 $2a_1 + d = 4$。尝试令公差 $d=2$，解得 $a_1=1$，均为正整数。因此构造矩阵：每行内元素相等，第 $1$ 行全为 `1`，第 $2$ 行全为 $a_1+d=3$。此时每一行是常数列，每一列构成 `1, 3`，公差为 $2$，满足等差数列要求。矩阵总和为 $(1+3) \times 3 = 12$，符合条件。
