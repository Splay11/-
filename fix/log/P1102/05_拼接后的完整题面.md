# 题目内容
一位统计学家正在翻阅一本从第 $1$ 页开始、页码无限延伸的书籍。定义 $f(n)$ 为从第 $1$ 页到第 $n$ 页所有页码的十进制表示中，数字 `0` 出现的总次数。

现有 $t$ 次独立的询问，每次询问给定一个正整数 $k$。请你找出最小的页码 $n$，使得 $f(n) \ge k$。

数据范围：询问次数 $t$ 不超过 $1000$，每次给定的 $k$ 不超过 $10^{13}$。

# 输入描述
第一行包含一个整数 $t$，表示询问次数。
接下来 $t$ 行，每行包含一个整数 $k$，表示一次询问的目标值。

# 输出描述
输出 $t$ 行，每行一个整数，表示对应询问的答案。

## 样例1

**输入**

```
1
1
```

**输出**

```
10
```

**说明**

询问 `1` 次，目标值 $k = 1$。

计算前 $n$ 页中数字 `0` 的出现次数 $f(n)$：页码 $1$ 到 $9$ 没有 `0`，即 $f(9)=0$；页码 `10` 包含 `1` 个 `0`，所以 $f(10)=1$。因此最小的满足 $f(n) \ge 1$ 的 $n$ 是 `10`。

## 样例2

**输入**

```
1
11
```

**输出**

```
100
```

**说明**

询问 `1` 次，目标值 $k = 11$。

计算 $f(n)$：在页码 `1` 到 `99` 中，`0` 仅出现在 `10,20,\dots,90` 的个位上，共 $9$ 次，即 $f(99)=9$。页码 `100` 包含 `2` 个 `0`，因此 $f(100)=f(99)+2=11$。$f(99) < 11$ 而 $f(100) \ge 11$，故最小的 $n$ 为 `100`。

## 样例3

**输入**

```
2
9
20
```

**输出**

```
90
190
```

**说明**

共有 `2` 次询问。

第一问 $k = 9$：页码 `1` 到 `90` 中，`0` 出现在 `10,20,\dots,90`，恰好 $9$ 个 `0$，即 $f(90)=9$。而 $f(89)=8$，故最小 $n=90$。

第二问 $k = 20$：先看 $f(99)=9$。页码 `100` 有 $2$ 个 `0`，所以 $f(100)=11$；`101`～`109` 各 $1$ 个 `0`；`110`、`120`、…、`190` 各 $1$ 个 `0`。因此 $f(190)=f(100)+9+9=2+9+9=20$，且 $f(189)=19$。最小满足条件的 $n$ 为 `190`。
