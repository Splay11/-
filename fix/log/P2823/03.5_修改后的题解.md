## 解题思路

1. **值域压缩**：$a_i\le 1000$，先统计每个值的出现次数 $cnt[v]$。
2. **枚举值对**：枚举 $1\le u\le v\le 1000$。令 $w=u\oplus v$，判断 $u,v,w$ 能否构成非退化三角形，即
   $$u+v>w,\quad u+w>v,\quad v+w>u.$$
3. **贡献计算**：
   - 若 $u<v$，贡献 $cnt[u]\times cnt[v]$；
   - 若 $u=v$，贡献 $cnt[u]\times(cnt[u]-1)/2$。
4. **累加**即为下标对数量。

## 复杂度分析

- **时间复杂度**：$O(n+V^2)$，其中 $V=1000$。读入统计 $O(n)$，枚举值对 $O(V^2)$。
- **空间复杂度**：$O(V)$。频次数组大小为 $1001$。

## 代码实现

### Python

```python
import sys

n = int(sys.stdin.readline())
cnt = [0] * 1001
for x in map(int, sys.stdin.readline().split()):
    cnt[x] += 1

ans = 0
for u in range(1, 1001):
    if cnt[u] == 0:
        continue
    for v in range(u, 1001):
        if cnt[v] == 0:
            continue
        w = u ^ v
        if u + v > w and u + w > v and v + w > u:
            if u < v:
                ans += cnt[u] * cnt[v]
            else:
                ans += cnt[u] * (cnt[u] - 1) // 2

print(ans)
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine());
        int[] cnt = new int[1001];
        String[] parts = br.readLine().split(" ");
        for (String p : parts) {
            cnt[Integer.parseInt(p)]++;
        }
        long ans = 0;
        for (int u = 1; u <= 1000; u++) {
            if (cnt[u] == 0) continue;
            for (int v = u; v <= 1000; v++) {
                if (cnt[v] == 0) continue;
                int w = u ^ v;
                if (u + v > w && u + w > v && v + w > u) {
                    if (u < v) {
                        ans += (long) cnt[u] * cnt[v];
                    } else {
                        ans += (long) cnt[u] * (cnt[u] - 1) / 2;
                    }
                }
            }
        }
        System.out.println(ans);
    }
}
```

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> cnt(1001, 0);
    for (int i = 0, x; i < n; i++) {
        cin >> x;
        cnt[x]++;
    }
    long long ans = 0;
    for (int u = 1; u <= 1000; u++) {
        if (cnt[u] == 0) continue;
        for (int v = u; v <= 1000; v++) {
            if (cnt[v] == 0) continue;
            int w = u ^ v;
            if (u + v > w && u + w > v && v + w > u) {
                if (u < v) ans += 1LL * cnt[u] * cnt[v];
                else ans += 1LL * cnt[u] * (cnt[u] - 1) / 2;
            }
        }
    }
    cout << ans << "\n";
    return 0;
}
