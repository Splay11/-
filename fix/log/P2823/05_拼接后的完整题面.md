# 题目内容
给定长度为 $n$ 的正整数数组 $a$。称一对下标 $(i,j)$（$1 \le i < j \le n$）是可行对，当且仅当 $a_i$、$a_j$ 与 $a_i \oplus a_j$ 可以作为三条边构成一个非退化三角形。其中 $\oplus$ 表示按位异或。

求可行对的数量。

数组长度 $n$ 满足 $1 \le n \le 10^5$。数组元素满足 $1 \le a_i \le 1000$。

# 输入描述
第一行包含一个正整数 $n$，表示数组长度。
第二行包含 $n$ 个正整数 $a_i$，表示数组元素。

# 输出描述
输出一个整数，表示可行对的数量。

## 样例1

**输入**

```
4
2 3 4 5
```

**输出**

```
1
```

**说明**

数组为 `2,3,4,5`。唯一满足三角形条件的下标对是 $(2,4)$（下标从 `1` 开始），对应值 `3` 与 `5`：$3\oplus 5=6$，且 $3,5,6$ 能构成非退化三角形。答案为 `1`。

## 样例2

**输入**

```
5
5 6 5 6 7
```

**输出**

```
4
```

**说明**

数组为 `5,6,5,6,7`。枚举值对后，满足条件的下标对共有 `4` 对。

## 样例3

**输入**

```
1
5
```

**输出**

```
0
```

**说明**

只有一个数，不存在下标对 $(i,j)$ 满足 $i<j$，答案为 `0`。

## 样例4

**输入**

```
2
1 1
```

**输出**

```
0
```

**说明**

唯一数对为 `1` 与 `1`，$1\oplus 1=0$。边长 `1,1,0` 不能满足三角形不等式，答案为 `0`。
