# 题目内容
在考古发掘中，发现了一种由小写字母 `a` 到 `z` 和数字字符 `1`、`2`、`3`、`4` 构成的远古符号系统。每个小写字母对应一个数字：`a` 视为 `0`，`b` 视为 `1`，……，`z` 视为 `25`。数字字符 `1`、`2`、`3`、`4` 分别代表四种操作：`1` 表示加法，`2` 表示减法，`3` 表示乘法，`4` 表示整除（向下取整）。一段合法的表达式由一个数字字符和左右各一至四个小写字母组成，例如 `c3d`。计算时，先将左右两侧的字母序列分别转换为对应的数字，再将这些数字按从左到右的顺序拼接成十进制整数（可能包含前导零，但拼接后按正常整数解析）。然后根据中间的数字字符执行对应的运算。如果运算结果是一个负数，取它的绝对值作为最终结果（因为这种符号体系中没有负数的概念）。如果运算符是 `4` 且右侧拼接得到的整数为 `0`，则表达式无效，此时返回 `-1` 表示错误。

表达式字符串的长度不超过 $9$，运算符左右两侧的连续字母子串长度均在 $1$ 到 $4$ 之间，且保证输入格式正确。

# 输入描述
输入参数为一个字符串 `formula`，表示一条远古表达式。字符串有且仅有一个字符 `1`、`2`、`3` 或 `4`，其余字符均为小写字母 `a` 至 `z`，且该数字字符左右两侧的连续字母序列长度均在 $1$ 到 $4$ 之间。

# 输出描述
返回一个整数，代表按照规则计算出的最终结果。如果发生除数为 $0$ 的错误，返回 $-1$。

## 样例1

**输入**

```
"a1a"
```

**输出**

```
0
```

**说明**

左侧字母序列 `a` 对应数字 $0$，拼接得到整数 $0$；右侧字母序列 `a` 同样得到 $0$。
运算符 `1` 表示加法，$0 + 0 = 0$，最终结果为 `0`。

## 样例2

**输入**

```
"c2d"
```

**输出**

```
1
```

**说明**

左侧字母序列 `c` 对应数字 $2$，拼接得到整数 $2$；右侧字母序列 `d` 对应数字 $3$，拼接得到整数 $3$。
运算符 `2` 表示减法，$2 - 3 = -1$。结果为负数，取绝对值得到 $1$，最终输出 `1`。

## 样例3

**输入**

```
"ab3ba"
```

**输出**

```
10
```

**说明**

左侧字母序列 `ab`：`a` 视为 $0$，`b` 视为 $1$，拼接为 `"01"`，解析为整数 $1$。
右侧字母序列 `ba`：`b` 视为 $1$，`a` 视为 $0$，拼接为 `"10"`，解析为整数 $10$。
运算符 `3` 表示乘法，$1 \times 10 = 10$，最终结果为 `10`。

## 样例4

**输入**

```
"x4a"
```

**输出**

```
-1
```

**说明**

左侧字母序列 `x` 对应数字 $23$，拼接得到整数 $23$；右侧字母序列 `a` 对应数字 $0$，拼接得到整数 $0$。
运算符 `4` 表示整除，由于右侧整数为 $0$，触发除数为零的错误，根据规则返回 `-1`。
