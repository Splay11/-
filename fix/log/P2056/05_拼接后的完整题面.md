# 题目内容
在一个物流中心，有一排共 $m$ 个存储格，编号为 $1$ 到 $m$。每个存储格内放置了一个包裹，第 $i$ 个包裹有一个**最迟提取日** $e_i$，表示该包裹可以在第 $e_i$ 天或之前被提取。

现在有 $n$ 名员工依次来处理订单。第 $i$ 名员工在第 $day_i$ 天来到仓库，并需要从编号在 $[l_i, r_i]$ 区间内的存储格中提取一个包裹。提取规则如下：在该区间内，所有**尚未被提取**的包裹中，选择**最迟提取日最大**的包裹；如果最大值对应多个包裹，则选择**编号最小**（即最靠左）的那一个。如果区间内所有包裹的最迟提取日均小于 $day_i$（即全部已失效），则该员工无法提取任何包裹。

当一名员工提取了一个包裹后，该存储格随即被清空，后续员工无法再从中提取。

请你计算出每一名员工最终提取的包裹所在存储格的编号；如果某员工未能提取，对应输出 $-1$。

**数据范围**
- $1 \le n, m \le 10^5$
- $1 \le e_i \le 10^9$
- $1 \le day_i \le 10^5$
- $1 \le l_i \le r_i \le m$

输入保证员工按输入顺序依次处理（同一天内也按此顺序）。

# 输入描述
第一行包含两个整数 $n$ 和 $m$（$1 \le n, m \le 10^5$），分别表示员工数量和存储格数量。
第二行包含 $m$ 个整数 $e_1, e_2, \dots, e_m$（$1 \le e_i \le 10^9$），表示第 $1$ 到第 $m$ 个存储格中包裹的最迟提取日。
接下来 $n$ 行，每行包含三个整数 $day_i, l_i, r_i$（$1 \le day_i \le 10^5$，$1 \le l_i \le r_i \le m$），依次表示第 $i$ 名员工的到达日期和查询的存储格区间。

# 输出描述
输出一行 $n$ 个整数，依次表示每名员工所提取的存储格编号（从 $1$ 开始），如果某员工未能提取任何包裹，则对应输出 $-1$。

## 样例1

**输入**

```
3 3
5 3 4
4 1 3
4 1 3
4 1 3
```

**输出**

```
1 3 -1
```

**说明**

第一位员工在第 `4` 天查询区间 `[1,3]`，各包裹最迟提取日为 $e_1=5$，$e_2=3$，$e_3=4$。最大值为 $5$，且 $5 \ge 4$，选取编号最小的 `1` 号存储格，随后该格被清空。
第二位员工同样查询该区间，剩余包裹中最迟提取日最大为 $4$（`3` 号格），$4 \ge 4$，提取 `3` 号格。
第三位员工查询时仅剩 `2` 号格，其最迟提取日 $e_2=3 < 4$，无法提取，输出 `-1`。

## 样例2

**输入**

```
4 4
2 2 2 2
1 1 4
1 1 4
3 1 4
```

**输出**

```
1 2 -1
```

**说明**

所有包裹的最迟提取日均为 $2$。第一位员工在第 `1` 天查询区间 `[1,4]`，最大值 $2 \ge 1$，所有值相同，选取最小编号 `1`。
第二位员工同样查询，剩余包裹中最小编号为 `2`，提取 `2` 号格。
第三位员工在第 `3` 天查询，剩余包裹最迟提取日 $2 < 3$，无法提取，输出 `-1`。

## 样例3

**输入**

```
2 3
1000000000 1 1000000000
2 2 2
1 1 3
```

**输出**

```
-1 1
```

**说明**

第一位员工在第 `2` 天查询区间 `[2,2]`，包裹最迟提取日 $e_2=1$。由于 $1 < 2$，无法提取，输出 `-1`，该包裹保持不变。
第二位员工在第 `1` 天查询区间 `[1,3]`，最迟提取日最大值为 $10^9$，出现在 `1` 号格和 `3` 号格，按规则选取编号最小的 `1` 号格，输出 `1`。
