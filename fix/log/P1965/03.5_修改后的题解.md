## 解题思路

设灯带下标从 `1` 到 $n$，第 $i$ 位为 `0` 表示熄灭、为 `1` 表示点亮。目标是把至多 $k$ 个 `0` 改成 `1` 后，最大化所有极大连续 `1` 段长度平方之和。

用动态规划。令 $dp[i][g]$ 表示只考虑前 $i$ 个位置、恰好把 $g$ 个 `0` 改成 `1` 时的最大积分。转移时枚举最后一段连续点亮是否以位置 $i$ 结尾：

1. 若以 $i$ 结尾：枚举该段左端点 $j$，把 $[j,i]$ 中所有 `0` 都点亮，设其中 `0` 的个数为 $z$。若 $z \le g$，则可从 $dp[j-1][g-z]$ 转移，并加上该段贡献 $(i-j+1)^2$。
2. 若不以 $i$ 结尾：直接继承 $dp[i-1][g]$。

实现时对每个右端点 $i$ 从右往左扫 $j$，同步维护 $z$，当 $z$ 超过 $k$ 即可停止。答案为 $dp[n][k]$。

## 复杂度分析

时间复杂度 $O(n^2 k)$，空间复杂度 $O(nk)$。在 $n,k \le 500$ 的范围内可以通过。

## 代码实现

### Python

```python
n, k = map(int, input().split())
s = input()

dp = [[0] * (k + 1) for _ in range(n + 1)]

for i in range(1, n + 1):
    zero_cnt = 0
    for j in range(i, 0, -1):
        if s[j - 1] == '0':
            zero_cnt += 1
        if zero_cnt - 1 > k:
            break
        for g in range(zero_cnt, k + 1):
            length = i - j + 1
            dp[i][g] = max(dp[i][g], dp[j - 1][g - zero_cnt] + length * length)
    for g in range(k + 1):
        dp[i][g] = max(dp[i][g], dp[i - 1][g])

print(dp[n][k])
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int k = sc.nextInt();
        String s = sc.next();
        int[][] dp = new int[n + 1][k + 1];
        for (int i = 1; i <= n; i++) {
            int zeroCnt = 0;
            for (int j = i; j >= 1; j--) {
                if (s.charAt(j - 1) == '0') {
                    zeroCnt++;
                }
                if (zeroCnt - 1 > k) {
                    break;
                }
                for (int g = zeroCnt; g <= k; g++) {
                    int length = i - j + 1;
                    dp[i][g] = Math.max(dp[i][g], dp[j - 1][g - zeroCnt] + length * length);
                }
            }
            for (int g = 0; g <= k; g++) {
                dp[i][g] = Math.max(dp[i][g], dp[i - 1][g]);
            }
        }
        System.out.println(dp[n][k]);
        sc.close();
    }
}
```

            for (int g = zero_cnt; g <= k; g++) {
                int length = i - j + 1;
                dp[i][g] = max(dp[i][g], dp[j - 1][g - zero_cnt] + length * length);
            }
        }
        for (int g = 0; g <= k; g++) {
            dp[i][g] = max(dp[i][g], dp[i - 1][g]);
        }
    }
    cout << dp[n][k] << '\n';
    return 0;
}
