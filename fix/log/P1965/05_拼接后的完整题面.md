# 题目内容
一条长度为 $n$ 的灯带上，每个位置的状态只能是熄灭 `0` 或点亮 `1`。一段连续点亮区间的贡献等于其长度的平方，整条灯带的积分定义为所有极大连续点亮区间的贡献之和。

你可以进行至多 $k$ 次操作，每次操作把一个熄灭位置改为点亮。请计算操作结束后，灯带积分的最大可能值。

灯带长度不超过 `500`，操作次数不超过 `500`。

# 输入描述
第一行包含两个整数 $n$ 和 $k$（$1 \le n \le 500$，$0 \le k \le 500$），分别表示灯带长度与最多操作次数。
第二行包含一个长度为 $n$、仅由字符 `0` 和 `1` 组成的字符串，表示灯带的初始状态。

# 输出描述
输出一个整数，表示操作后能得到的最大积分。
