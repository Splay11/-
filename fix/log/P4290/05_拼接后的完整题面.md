# 题目内容
实验室里有一套砝码，重量分别为 $1, 2, \dots, n$ 克，每种重量恰好有一枚。

现在要进行 $m$ 次称量任务，每次给定一个目标重量 $k$ 克，你需要从这些砝码中选出若干枚，使得选出的砝码总重量恰好为 $k$。

请按重量升序输出你选中的砝码。如果无论如何都无法凑出 $k$，则输出 `-1`。若存在多种合法选法，输出任意一种即可。每次称量任务互相独立。

**数据约束**

- 测试数据组数 $T$ 不超过 $10^4$；
- 每组数据中，砝码数量 $n$ 和任务次数 $m$ 均不超过 $2 \times 10^5$；
- 目标重量 $k$ 不超过 $10^{12}$；
- 所有测试数据的 $n \times m$ 之和不超过 $2 \times 10^6$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据组数。

对于每组测试数据：
- 第一行包含两个整数 $n$ 和 $m$，表示砝码数量和称量任务次数；
- 接下来 $m$ 行，每行包含一个整数 $k$，表示本次任务的目标重量。

# 输出描述
对于每组测试数据的每一个称量任务，按顺序输出答案：
- 若有解，先输出一行一个整数，表示所选砝码的数量；紧接着输出一行，按升序输出所选砝码的重量，重量之间用单个空格分隔；
- 若无解，输出一行 `-1`。

## 样例1

**输入**

```
1
4 2
3
8
```

**输出**

```
1
1
3
1 3 4
```

**说明**

第一组数据：$n=4$，砝码为 $1, 2, 3, 4$ 克，最大可表示重量 $S = 1+2+3+4 = 10$。

- 任务 $k=3$：从大到小贪心，$4 > 3$ 跳过，$3 \le 3$ 选取，剩余 $0$，答案为 $[3]$，输出 `1` 和 `1`。
- 任务 $k=8$：$4 \le 8$，取 $4$，剩余 $4$；$3 \le 4$，取 $3$，剩余 $1$；$2 > 1$ 跳过；$1 \le 1$，取 $1$，剩余 $0$。选取的砝码升序为 $1, 3, 4$，输出 `3` 和 `1 3 4`。

## 样例2

**输入**

```
1
1 2
1
2
```

**输出**

```
1
1
-1
```

**说明**

$n=1$，仅有 $1$ 克砝码，最大可表示重量 $S = 1$。

- $k=1$：选取 $1$，输出 `1` 和 `1`。
- $k=2$：$2 > S$，无法表示，输出 `-1`。

## 样例3

**输入**

```
2
3 3
6
5
1
5 2
14
12
```

**输出**

```
3
1 2 3
2
2 3
1
1
4
2 3 4 5
3
3 4 5
```

**说明**

第一组数据：$n=3$，砝码 $1,2,3$，最大重量 $S=6$。
- $k=6$：贪心选取 $3,2,1$，升序 $1,2,3$。
- $k=5$：选取 $3,2$，升序 $2,3$。
- $k=1$：选取 $1$。

第二组数据：$n=5$，砝码 $1,2,3,4,5$，最大重量 $S=15$。
- $k=14$：依次取 $5,4,3,2$，升序 $2,3,4,5$。
- $k=12$：依次取 $5,4,3$，升序 $3,4,5$。
