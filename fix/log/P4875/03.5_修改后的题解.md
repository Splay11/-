## 解题思路

本题要求我们为包含占位符 `?` 的符文序列（由 `0`/`1`/`?` 构成）进行填充，使得最终的完整序列满足：每一个极长同属性段（连续且不能向两端扩展的相同属性符文组成的子串）的长度均为奇数。求所有合法填充方案的总数，结果对 $10^9+7$ 取模。

由于序列只包含 `0` 和 `1` 两种属性，我们可以使用动态规划，从左到右扫描序列，维护当前最后一个极长同属性段的状态。对于当前已经处理的前缀，我们只关心以下两种信息：

- 最后一段的属性是 `c`（`c=0` 表示阴，`c=1` 表示阳），且该段的当前长度为奇数，此时的方案数记为 $odd[c]$；
- 最后一段的属性是 `c`，且该段的当前长度为偶数，此时的方案数记为 $even[c]$。

当加入下一个字符时，根据该字符与当前段末字符的关系，可以分情况讨论：

1. **延续当前段（新字符与上一段属性相同）**  
   如果加入后依然保持相同属性，该段的长度会增加 1，奇偶性翻转：
   - 原来长度为偶数的段会变成长度为奇数的段：$odd[c]$ 应加上 $even[c]$；
   - 原来长度为奇数的段会变成长度为偶数的段：$even[c]$ 应加上 $odd[c]$。

2. **开启新段（新字符与上一段属性不同）**  
   只有当上一段已经是奇数长度时，才能合法地结束上一段，并开启一个长度为 1（奇数）的新段。因此：
   - 对于属性 `c`，可以从上一段属性为 `1-c` 且长度为奇数的状态转移而来：$odd[c]$ 应加上 $odd[1-c]$。

处理字符时，如果当前位置是 `?`，可以同时尝试填充 `0` 或 `1`；如果是确定的 `0` 或 `1`，则只能使用对应属性进行转移。

最终，整个序列处理完毕后，最后一段也必须是奇数长度，因此答案为 $(odd[0] + odd[1]) \bmod (10^9+7)$。

## 复杂度分析

对于每组测试数据，我们只需要遍历一遍长度为 $n$ 的字符串，每次转移只涉及常数个状态（$0$ 和 $1$ 两种属性）。因此：

- 时间复杂度：$O(n)$；
- 空间复杂度：$O(1)$（只使用了常数大小的数组存储状态）。

所有测试数据的 $n$ 之和不超过 $2\times 10^5$，算法完全可以在时限内运行。

## 代码实现

### Python

```python
MOD = 10 ** 9 + 7

def count_ways(s):
    # odd[c]: 最后一段属性为 c，且该段长度为奇数的方案数
    # even[c]: 最后一段属性为 c，且该段长度为偶数的方案数
    odd = [0, 0]
    even = [0, 0]

    # 初始化第一个字符
    for c in range(2):
        ch = '0' if c == 0 else '1'
        if s[0] == '?' or s[0] == ch:
            odd[c] = 1

    # 从第二个字符开始动态规划
    for i in range(1, len(s)):
        new_odd = [0, 0]
        new_even = [0, 0]
        for c in range(2):
            ch = '0' if c == 0 else '1'
            if s[i] != '?' and s[i] != ch:
                continue

            # 放相同字符：当前段长度奇偶性翻转
            new_odd[c] = (new_odd[c] + even[c]) % MOD
            new_even[c] = (new_even[c] + odd[c]) % MOD

            # 放不同字符：上一段必须已经是奇数长度，才能开启新段
            new_odd[c] = (new_odd[c] + odd[c ^ 1]) % MOD

        odd, even = new_odd, new_even

    # 最后一段也必须是奇数长度
    return (odd[0] + odd[1]) % MOD


def main():
    t = int(input())
    ans = []
    for _ in range(t):
        n = int(input())
        s = input().strip()
        ans.append(str(count_ways(s)))
    print("\n".join(ans))


if __name__ == "__main__":
    main()
```

import java.io.BufferedReader;
import java.io.InputStreamReader;

public class Main {
    static final long MOD = 1000000007L;

    // 计算合法填充方案数
    static long countWays(String s) {
        // odd[c]: 最后一段属性为 c，且长度为奇数的方案数
        // even[c]: 最后一段属性为 c，且长度为偶数的方案数
        long[] odd = new long[2];
        long[] even = new long[2];

        // 初始化第一个字符
        for (int c = 0; c < 2; c++) {
            char ch = (c == 0) ? '0' : '1';
            if (s.charAt(0) == '?' || s.charAt(0) == ch) {
                odd[c] = 1;
            }
        }

        // 从第二个字符开始动态规划
        for (int i = 1; i < s.length(); i++) {
            long[] newOdd = new long[2];
            long[] newEven = new long[2];

            for (int c = 0; c < 2; c++) {
                char ch = (c == 0) ? '0' : '1';
                if (s.charAt(i) != '?' && s.charAt(i) != ch) {
                    continue;
                }

                // 放相同字符：当前段长度奇偶性翻转
                newOdd[c] = (newOdd[c] + even[c]) % MOD;
                newEven[c] = (newEven[c] + odd[c]) % MOD;

                // 放不同字符：上一段必须是奇数长度才能开启新段
                newOdd[c] = (newOdd[c] + odd[c ^ 1]) % MOD;
            }

            odd = newOdd;
            even = newEven;
        }

        // 最后一段必须是奇数长度
        return (odd[0] + odd[1]) % MOD;
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int T = Integer.parseInt(br.readLine().trim());
        for (int tc = 0; tc < T; tc++) {
            int n = Integer.parseInt(br.readLine().trim());
            String s = br.readLine().trim();
            sb.append(countWays(s)).append('\n');
        }

        System.out.print(sb.toString());
    }
}

const long long MOD = 1000000007LL;

// 计算合法填充方案数
long long countWays(const string& s) {
    // odd[c]: 最后一段属性为 c，且长度为奇数的方案数
    // even[c]: 最后一段属性为 c，且长度为偶数的方案数
    long long odd[2] = {0, 0};
    long long even[2] = {0, 0};

    // 初始化第一个字符

        char ch = (c == 0) ? '0' : '1';
        if (s[0] == '?' || s[0] == ch) {
            odd[c] = 1;
        }
    }

    // 从第二个字符开始动态规划
    for (int i = 1; i < (int)s.size(); i++) {
        long long newOdd[2] = {0, 0};
        long long newEven[2] = {0, 0};

        for (int c = 0; c < 2; c++) {
            char ch = (c == 0) ? '0' : '1';
            if (s[i] != '?' && s[i] != ch) {
                continue;
            }

            // 放相同字符：当前段长度奇偶性翻转

            newOdd[c] = (newOdd[c] + odd[c ^ 1]) % MOD;

            odd[c] = newOdd[c];
            even[c] = newEven[c];

}
