# 题目内容
在一个由 $n$ 个用户组成的社交网络中，初始时没有任何好友关系。接下来会按顺序进行 $m$ 次添加好友的操作。每次操作会选择两个不同的用户，在他们之间建立一条无向的好友关系。如果某次操作后，该操作所连接的两个用户所在的连通群体中，好友关系的数量恰好等于用户的数量，且该群体此前从未满足过这一条件，则称这个群体在此次操作中**首次形成闭环群体**，你需要输出 `Yes`；否则输出 `No`。

一个连通群体被定义为“闭环群体”当且仅当：
- 该群体内的用户数量等于好友关系数量；
- 群体内不存在自己与自己的好友关系，也不存在重复的好友关系（即所有好友关系构成一个简单无向图）。

需要注意：
- 初始时每个用户独立构成一个只含自己的群体，此时关系数为 $0$，不等于用户数，因此不是闭环群体。
- 一旦某个群体首次成为闭环群体，此后即使该群体因合并或其他原因增加新的好友关系，也不再输出 `Yes`（因为已经形成过闭环）。
- 如果两次操作尝试添加完全相同的无向好友关系（即重边），该操作无效，不会改变图的结构，并输出 `No`。输入保证不会出现自环（$u=v$）。

约束：用户数量 $n$ 和操作次数 $m$ 均不超过 $10^5$，所有用户编号在 $1$ 到 $n$ 之间，且保证每次操作提供的 $u$ 和 $v$ 满足 $u 
eq v$。

# 输入描述
第一行包含两个整数 $n$ 和 $m$，分别表示用户数量和操作次数。接下来 $m$ 行，每行包含两个整数 $u$ 和 $v$，表示本次操作在两个用户 $u$ 和 $v$ 之间添加好友关系。

# 输出描述
对于每次操作，输出一行 `Yes` 或 `No`。

## 样例1

**输入**

```
3 4
1 2
2 3
1 3
1 2
```

**输出**

```
No
No
Yes
No
```

**说明**

初始有 `3` 个独立用户。
- 第 `1` 次操作：加入 $(1,2)$，`1` 与 `2` 不连通，合并后形成包含 `2` 个点和 `1` 条边的连通分量，边数 $1 
eq 2$，不构成闭环群体，输出 `No`。
- 第 `2` 次操作：加入 $(2,3)$，`3` 与已有分量不连通，合并后得到 `3` 个点和 `2` 条边，$2 
eq 3$，输出 `No`。
- 第 `3` 次操作：加入 $(1,3)$，此时 `1` 和 `3` 已在同一分量中，当前分量有 `3` 个点、`2` 条边且从未闭环。添加此边后边数变为 `3`，等于点数 `3`，首次满足闭环条件，输出 `Yes`，该分量随即被标记为已闭环。
- 第 `4` 次操作：再次加入 $(1,2)$，这是一条重复边，操作无效，输出 `No`。

## 样例2

**输入**

```
4 5
1 2
3 4
2 3
1 4
1 3
```

**输出**

```
No
No
No
Yes
No
```

**说明**

初始有 `4` 个独立用户。
- 第 `1` 次操作：加入 $(1,2)$，形成 `2` 个点、`1` 条边的分量，$1 
eq 2$，输出 `No`。
- 第 `2` 次操作：加入 $(3,4)$，同样形成 `2` 个点、`1` 条边的分量，输出 `No`。
- 第 `3` 次操作：加入 $(2,3)$，将两个分量合并，新分量包含 `4` 个点和 `3` 条边，$3 
eq 4$，不构成闭环，输出 `No`。
- 第 `4` 次操作：加入 $(1,4)$，`1` 和 `4` 已处于同一分量（`4` 点 `3` 边）。添加此边后边数变为 `4`，等于点数 `4`，首次形成闭环群体，输出 `Yes`，并标记该分量已闭环。
- 第 `5` 次操作：加入 $(1,3)$，虽仍在同一分量且会增加边数，但因为该群体已经形成过闭环，不再重复输出 `Yes`，输出 `No`。

## 样例3

**输入**

```
2 2
1 2
1 2
```

**输出**

```
No
No
```

**说明**

只有 `2` 个用户，要构成闭环群体至少需要 `3` 个点和 `3` 条边。
- 第 `1` 次操作：加入 $(1,2)$，合并后形成 `2` 个点、`1` 条边的分量，$1 
eq 2$，不满足条件，输出 `No`。
- 第 `2` 次操作：再次加入 $(1,2)$，属于重复边，操作无效，输出 `No`。
因此两次操作均输出 `No`，符合预期。
