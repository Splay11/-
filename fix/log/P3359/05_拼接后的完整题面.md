# 题目内容
有一棵 $n$ 个站点的通信树，站点编号为 `1` 到 $n$。每个站点带有一个协议标记 $s_i$，只能是 `d`、`p` 或 `?`。

你可以把任意站点的标记改成 `d` 或 `p`，每次改动计一次。最终必须满足：

- 所有站点的标记都是 `d` 或 `p`（不能再保留 `?`）；
- 每条边连接的两个站点标记互不相同。

求最少需要改动多少次。

约束：站点数不超过 `2×10^5`。

# 输入描述
第一行一个整数 $n$，表示站点个数。
第二行一个长度为 $n$ 的字符串 $s$，只含字符 `d`、`p` 和 `?`，依次给出站点 `1` 到 $n$ 的初始标记。
接下来 $n-1$ 行，每行两个整数 $u$ 和 $v$，表示站点 $u$ 与 $v$ 之间有一条无向边。
保证 $2 \le n \le 2 \times 10^5$，$1 \le u, v \le n$ 且 $u 
e v$，输入构成一棵树。

# 输出描述
输出一个整数，表示最少改动次数。

## 样例1

**输入**

```
2
pp
1 2
```

**输出**

```
1
```

**说明**

两个相邻站点都是 `p`，最终必须一 `d` 一 `p`，至少改 `1` 次。

## 样例2

**输入**

```
3
dpd
1 2
2 3
```

**输出**

```
0
```

**说明**

链 $1-2-3$ 上标签已是 `d,p,d`，本身就是合法二分染色，无需重绘，答案为 `0`。

## 样例3

**输入**

```
4
????
1 2
2 3
3 4
```

**输出**

```
4
```

**说明**

四个站点都是 `?`，每种合法染色都要把它们全部填成 `d` 或 `p`，最少重绘次数为 `4`。
