# 题目内容
在一维无限直线上，存在若干段危险区域，每段危险区域覆盖一段连续整数闭区间 $[l_i, r_i]$。你现在位于整数位置 $s$，需要走到一个不处于任何危险区域内的整数位置 $x$，使得移动距离 $|x - s|$ 最小。请计算这个最小距离。

数据范围：
- 测试数据组数 $T$ 满足 $1 \le T \le 2 \times 10^5$。
- 每组中危险区域个数 $n$ 满足 $1 \le n \le 2 \times 10^5$，所有测试数据中的 $n$ 之和不超过 $5 \times 10^5$。
- 当前位置 $s$ 与区间端点 $l_i, r_i$ 均为整数，绝对值不超过 $10^6$。

# 输入描述
第一行包含一个整数 $T$，表示测试用例的组数。接下来依次给出每组测试数据。

每组数据的第一行包含两个整数 $n$ 和 $s$，分别表示危险区间的数量以及你的当前坐标。
之后的 $n$ 行，每行包含两个整数 $l_i$ 和 $r_i$，表示一个危险区间的左右端点（闭区间）。

# 输出描述
对于每组测试数据，输出一行一个整数，表示你能到达最近安全点所需的最小移动距离。

## 样例1

**输入**

```
2
1 10
1 5
2 7
2 4
6 8
```

**输出**

```
0
2
```

**说明**

测试数据共 `2` 组。
第一组：危险区间为 $[1,5]$，当前位置 $s=10$。`10` 不在任何危险区间内，因此最小移动距离为 `0`。
第二组：两个危险区间 $[2,4]$ 和 $[6,8]$，当前位置 $s=7$。由于 $4+1=5 < 6$，两个区间不合并。`7` 落在区间 $[6,8]$ 内。最近的安全点为 $5$（即 $6-1$）或 $9$（即 $8+1$）。距离分别为 $|5-7|=2$ 和 $|9-7|=2$，取最小值，答案为 `2`。

## 样例2

**输入**

```
1
1 2
10 20
```

**输出**

```
1
```

**说明**

仅有一组数据。危险区间为 $[10,20]$，当前位置 $s=10$ 落在区间内。最近的安全点为 $9$（$10-1$）或 $21$（$20+1$）。距离分别为 $10-9=1$ 和 $21-10=11$，即 $\min(10-10+1,\,20-10+1) = \min(1,11)=1$。答案为 `1`。

## 样例3

**输入**

```
1
2 5
1 3
4 8
```

**输出**

```
4
```

**说明**

仅有一组数据。两个危险区间 $[1,3]$ 和 $[4,8]$。由于 $3+1=4$，它们相邻，合并为 $[1,8]$。当前位置 $s=5$ 在合并区间内。最近的安全点为 $0$（$1-1$）或 $9$（$8+1$）。距离 $\min(5-1+1,\,8-5+1) = \min(5,4)=4$，故最小移动距离为 `4`。
