# 导轨最近可用工位

# 题目内容

产线侧沿无限长导轨部署工位，每个整数坐标对应一个工位。你当前位于坐标 $s$。

共有 $k$ 名作业员（含你），第 $i$ 人禁止进入闭区间 $[L_i,R_i]$ 内的任意工位。请选一个整数工位坐标 $x$，使 $x \notin [L_i,R_i]$ 对所有 $i$ 成立，且步行距离 $|x-s|$ 最小，输出该最小距离。

# 输入描述

每个测试文件包含多组测试数据。

1. 第一行一个整数 $T$（$1 \le T \le 2 \times 10^5$），表示组数。
2. 每组数据：
   - 第一行两个整数 $k,s$（$1 \le k \le 2 \times 10^5$，$-10^6 \le s \le 10^6$）；
   - 接下来 $k$ 行，每行两个整数 $L_i,R_i$（$-10^6 \le L_i \le R_i \le 10^6$），表示第 $i$ 人的禁入区间。
3. 所有测试中 $k$ 之和不超过 $5 \times 10^5$。

# 输出描述

输出 $T$ 行，每行一个整数，表示该组的最小步行距离。

## 样例1

**输入**

```
3
2 4
2 3
6 7
1 12
5 15
3 -1
-3 0
1 3
5 8
```

**输出**

```
0
4
2
```

**说明**

- 第一组：禁入区间为 $[2,3] \cup [6,7]$，当前位置 $s=4$ 可用，距离为 $0$。
- 第二组：$s=12$ 落在 $[5,15]$ 内，最近可用工位为 $4$ 或 $16$，距离为 $\min(12-5+1,\,15-12+1)=4$。
- 第三组：$s=-1$ 落在合并后的 $[-3,3]$ 内，最近可用工位距离为 $2$。
