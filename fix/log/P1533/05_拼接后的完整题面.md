# 题目内容
密码学家在研究一段密文时，得到了一个仅由小写字母组成的序列。他想统计该序列中有多少个非空连续片段，满足片段的第一个字母与最后一个字母相同。

序列的长度至少为 `1`，至多不超过 `10^5`。

# 输入描述
输入包含一行，一个仅由小写字母构成的字符串，其长度不超过 `10^5`。

# 输出描述
输出一个整数，表示满足条件的连续片段数量。

## 样例1

**输入**

```
a
```

**输出**

```
1
```

**说明**

字符串 `a` 中仅包含一个字符 `'a'`，出现次数为 `1`。满足条件的连续片段只有 `"a"` 自身，其首尾字母都是 `a`。根据公式 $cnt \times (cnt+1) / 2$，当 $cnt=1$ 时结果为 `1`。

## 样例2

**输入**

```
abcde
```

**输出**

```
5
```

**说明**

字符串 `abcde` 中，每个字母 `a`、`b`、`c`、`d`、`e` 均只出现 `1` 次。对于任意一个出现次数为 $cnt$ 的字母，满足首尾相同的连续片段数为 $cnt \times (cnt+1) / 2$。当 $cnt=1$ 时，结果均为 `1`。因此所有字母的贡献之和为 `5`。对应的片段分别为 `"a"`、`"b"`、`"c"`、`"d"`、`"e"`。

## 样例3

**输入**

```
abacaba
```

**输出**

```
14
```

**说明**

统计每个字母的出现次数：`a` 出现 `4` 次，`b` 出现 `2` 次，`c` 出现 `1` 次。
根据公式 $cnt \times (cnt+1) / 2$ 计算：
- `a` 的贡献为 $4 \times 5 / 2 = 10$
- `b` 的贡献为 $2 \times 3 / 2 = 3$
- `c` 的贡献为 $1 \times 2 / 2 = 1$
总和为 $10 + 3 + 1 = 14$，即满足条件的连续片段数量为 `14`。
