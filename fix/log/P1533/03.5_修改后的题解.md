## 解题思路

我们需要统计字符串中所有非空连续片段，满足片段的第一个字母与最后一个字母相同。注意，长度为 1 的片段也自然满足条件，因为首尾字母相同。

**核心思路：**

- 遍历字符串，依次将每个字符视为片段的**尾字母**。
- 对于当前尾字母，能够与它组成合法片段的**首字母**，必须是该字母本身，且出现在尾字母之前（包括当前位置，即长度为 1 的片段）。
- 具体做法：使用一个长度为 26 的计数器数组 `cnt`，下标 0∼25 对应字母 `a`∼`z`。
- 从左到右扫描字符串，对于每个字符 `c`：
  - 先将 `c` 的计数 `cnt[c - 'a']` 加 1，表示该字母又多出现了一次。
  - 然后将 `cnt[c - 'a']` 累加到答案中。这一步的含义是：以当前位置为结尾、且首字母等于 `c` 的所有片段的个数，恰好等于截止目前该字母出现的总次数（包括当前这次）。因为前面每一次出现的位置都可以作为起点，当前自身也可以构成长度为 1 的片段。
- 遍历结束后，累加的和即为答案。

该算法只需一次遍历，即可统计出所有满足条件的片段数量。

## 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 是字符串的长度。我们对字符串进行了一次扫描，每次操作是常数时间。
- **空间复杂度**：$O(1)$。仅使用了一个长度为 26 的计数器数组，与输入规模无关。

## 代码实现

### Python

```python
s = input().strip()

cnt = [0] * 26      # 统计 a-z 的出现次数
ans = 0

for ch in s:
    idx = ord(ch) - ord('a')
    cnt[idx] += 1          # 当前字母计数加 1
    ans += cnt[idx]        # 累加以 ch 结尾的合法片段数量

print(ans)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String s = scanner.next();
        scanner.close();

        int[] cnt = new int[26]; // 统计 a-z 的出现次数
        long ans = 0;

        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            int idx = ch - 'a';
            cnt[idx]++;          // 当前字母计数加 1
            ans += cnt[idx];     // 累加以 ch 结尾的合法片段数量
        }

        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;

    vector<int> cnt(26, 0);   // 统计 a-z 的出现次数
    long long ans = 0;

    for (char ch : s) {
        int idx = ch - 'a';
        cnt[idx]++;           // 当前字母计数加 1
        ans += cnt[idx];      // 累加以 ch 结尾的合法片段数量
    }

    cout << ans << "\n";
    return 0;
}
```
