# 题目内容
在一家公司中，共有 $n$ 名员工，编号为 $1$ 到 $n$，其中员工 $1$ 为 CEO。公司内部的管理关系构成一棵树，CEO 是树的根节点。若员工 $u$ 是员工 $v$ 的直接上级，则 $u$ 与 $v$ 之间有一条边相连。

定义一名员工的**层级**为其到 CEO（员工 $1$）的简单路径所经过的边数。CEO 的层级为 $0$。

现在 CEO 希望对公司结构进行一次调整，以降低全体员工的层级总和。他可以选择任意一名非 CEO 的员工 $x$，将以 $x$ 为最高负责人的整个团队（包含 $x$ 及其所有直接或间接的下属）整体划归 CEO 直接领导，即让 $x$ 成为 CEO 的直接下级。在调整之后，CEO 仍为根，其余组织关系保持不变。

请你计算，在最优的选择下，调整后全公司所有员工的层级之和的最小值是多少。

员工总数 $n$ 不超过 $2 \times 10^5$，树的边数为 $n-1$，保证输入构成一棵合法的树。

# 输入描述
第一行包含一个整数 $n$，表示员工总数。
接下来 $n-1$ 行，每行包含两个整数 $u$ 和 $v$，表示员工 $u$ 与员工 $v$ 之间存在一条直接上下级关系（即一条边）。

# 输出描述
输出一个整数，表示经过一次最优调整后，全公司员工层级之和的最小可能值。

## 样例1

**输入**

```
6
1 2
1 3
2 4
2 5
3 6
```

**输出**

```
7
```

**说明**

公司共有 $n = 6$ 名员工，树结构为：员工 `1`（CEO）有两个直接下级 `2` 和 `3`；`2` 的下级为 `4` 和 `5`；`3` 的下级为 `6`。

初始时各员工层级（深度）为：`1` 的层级 $0$；`2`、`3` 层级 $1$；`4`、`5`、`6` 层级 $2$。全体层级总和为 $0 + 1 + 1 + 2 + 2 + 2 = 8$。

考虑将某个非 CEO 员工的团队整体划归 CEO 直接领导，即便该员工的深度变为 $1$，其所有下属深度也同步减少。对于员工 $x$，可减少的层级总量为 $(\text{depth}[x] - 1) \times \text{size}[x]$。
- $x=4$：深度 $2$，子树大小 $1$，减少量 $(2-1)\times1=1$；
- $x=5$：同样减少 $1$；
- $x=6$：同样减少 $1$；
- 其他节点减少量均为 $0$。

最优选择下最大减少量为 $1$，因此调整后层级总和的最小值为 $8 - 1 = 7$。

## 样例2

**输入**

```
7
1 2
2 3
2 4
3 5
5 6
5 7
```

**输出**

```
10
```

**说明**

员工总数 $n = 7$，树形结构为一条深度较长的分支：`1 - 2 - 3 - 5 - 6` 和 `1 - 2 - 3 - 5 - 7`，以及一个分支 `2 - 4`。

初始层级（深度）分布：`1` 为 $0$；`2` 为 $1$；`3`、`4` 为 $2$；`5` 为 $3$；`6`、`7` 为 $4$。总和为 $0+1+2+2+3+4+4=16$。

各非 CEO 节点 $x$ 的减少量 $(\text{depth}[x]-1)\times\text{size}[x]$：
- `3`：深度 $2$，子树包含 `3,5,6,7` 共 $4$ 人，减少量 $(2-1)\times4=4$；
- `5`：深度 $3$，子树包含 `5,6,7` 共 $3$ 人，减少量 $(3-1)\times3=6$；
- 其余节点减少量均不超过 $3$。

选择员工 `5` 可获得最大减少量 $6$。调整后（将 `5` 连到 `1` 下），层级分布变为：`1` 为 $0$；`2`、`5` 为 $1$；`3`、`4`、`6`、`7` 为 $2$。总和为 $0+1+1+2+2+2+2=10$，即 $16-6=10$。

## 样例3

**输入**

```
2
1 2
```

**输出**

```
1
```

**说明**

边界情况：公司只有 $n = 2$ 名员工，CEO `1` 和唯一的下属 `2`。

初始层级：`1` 为 $0$，`2` 为 $1$，总和为 $1$。
非 CEO 员工仅有 `2`，其深度为 $1$，减少量 $(1-1)\times1=0$。调整后层级总和仍为 $1$。
