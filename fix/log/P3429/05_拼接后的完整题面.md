# 题目内容
工坊要为 $n$ 个工位分配正整数刻度 $a_1,a_2,\ldots,a_n$，并给定正整数基准 $x$。要求同时满足：

- 对任意两个不同下标 $i,j$，均有 $\operatorname{lcm}(a_i,a_j)=\operatorname{lcm}(i,j)\times x$；
- 对任意下标 $i$，均有 $a_i 
eq i\times x$。

其中 $\operatorname{lcm}$ 表示最小公倍数。若存在多种合法方案，输出任意一种即可。

工位数不超过 $10^6$，基准不超过 $10^{18}$。

# 输入描述
第一行包含两个整数 $n$ 和 $x$，分别表示工位数量与基准，满足 $2 \le n \le 10^6$，$1 \le x \le 10^{18}$。

# 输出描述
若存在合法数组，第一行输出字符串 $Yes$，第二行输出 $n$ 个整数表示刻度 $a_1,a_2,\ldots,a_n$；否则只输出一行字符串 $No$。多解时输出任意一组即可。

## 样例1

**输入**

```
2 2
```

**输出**

```
Yes
4 2
```

**说明**

仅有两个工位。取 $a_1=`2`\times x=`4$，$a_2=x=`2$。
此时 $\operatorname{lcm}(4,2)=`4`=\operatorname{lcm}(1,2)\times `2$，且 $a_1
eq `1`\times `2$、$a_2
eq `2`\times `2$，故输出 $Yes$ 及该数组。

## 样例2

**输入**

```
3 7
```

**输出**

```
No
```

**说明**

工位数 $n=`3`\ge `3$。此时任意满足最小公倍数条件的刻度都必须取 $a_i=i\times x$，但这又违反第二条限制，因此无解，输出 $No$。

## 样例3

**输入**

```
2 1
```

**输出**

```
Yes
2 1
```

**说明**

基准 $x=`1$。构造 $a=(`2`,`1`)$，即 $a_1=`2`x$、$a_2=x$。
$\operatorname{lcm}(2,1)=`2`=\operatorname{lcm}(1,2)\times `1$，且两项均不等于对应下标乘基准。

## 样例4

**输入**

```
4 100
```

**输出**

```
No
```

**说明**

$n=`4`\ge `3$，与 $n=`3$ 同样会产生矛盾，输出 $No$。
