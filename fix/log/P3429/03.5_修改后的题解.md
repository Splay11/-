## 解题思路

设 $a_i = x \cdot c_i$，则两条限制分别化为：

- 对任意 $i \neq j$，有 $\operatorname{lcm}(c_i,c_j)=\operatorname{lcm}(i,j)$；
- 对任意 $i$，有 $c_i \neq i$。

观察各数的质因数指数后可以发现：当 $n \ge 3$ 时，要使所有两两最小公倍数与下标一致，必须有 $c_i=i$ 对每个 $i$ 成立。这与 $c_i \neq i$ 矛盾，因此 $n \ge 3$ 时无解。

当 $n=2$ 时，可取 $c_1=2$、$c_2=1$，即 $a_1=2x$、$a_2=x$。此时

$$
\operatorname{lcm}(2x,x)=2x=\operatorname{lcm}(1,2)\times x,
$$

且 $a_1 \neq x$、$a_2 \neq 2x$，两条限制均满足。

结论：若 $n=2$，输出 `Yes` 以及 $2x$ 与 $x$；否则输出 `No`。注意 $2x$ 可达 $2\times 10^{18}$，需使用 64 位整数。

## 复杂度分析

时间复杂度 $O(1)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
import sys

n, x = map(int, sys.stdin.readline().split())
if n == 2:
    print("Yes")
    print(2 * x, x)
else:
    print("No")
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        long n = Long.parseLong(st.nextToken());
        long x = Long.parseLong(st.nextToken());
        if (n == 2) {
            System.out.println("Yes");
            System.out.println((2 * x) + " " + x);
        } else {
            System.out.println("No");
        }
    }
}
```
