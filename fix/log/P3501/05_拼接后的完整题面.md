# 题目内容
在数据分析中，经常需要衡量一组标注数据的标签分布情况。给定一个数据集，每一条记录由若干特征和一个类别标签组成。类别标签为字符 `'0'` 或 `'1'`，表示两种不同的类别。为了评估类别分布的均衡程度，定义 **混杂度** $H$ 的计算公式为：

$$H = -\sum_{k} p_k \log_2 p_k$$

其中 $p_k$ 表示数据集中标签为类别 $k$ 的样本所占的比例，当某个类别比例为 $0$ 时，该项贡献为 $0$。请根据给定的数据集，计算其混杂度，并保留三位小数输出。

**约束条件**：数据集的样本总数不超过 $10^4$，每条记录的特征维度不超过 $10$。标签只可能为 `'0'` 或 `'1'`，特征值均为整数。

# 输入描述
输入仅有一行，包含一个二维列表，格式如 `[[...], ...]`。每个内部列表的最后一个元素为字符串 `'0'` 或 `'1'` 形式的类别标签，其余元素为整数类型的特征值。输入可直接通过 `eval` 解析为 Python 列表结构。

# 输出描述
输出一个浮点数，表示数据集的混杂度，结果四舍五入保留三位小数。

## 样例1

**输入**

```
[[1, 2, '0'], [3, 4, '0']]
```

**输出**

```
0.000
```

**说明**

数据集中所有样本的类别标签均为 `'0'`，样本总数 `2`。此时 $p_0 = 1$，$p_1 = 0$，根据公式，有 $p_1 \log_2 p_1$ 项贡献为 `0`。混杂度 $H = -1 \times \log_2 1 - 0 = 0.000$。

## 样例2

**输入**

```
[[5, '0'], [6, '1']]
```

**输出**

```
1.000
```

**说明**

数据集包含两个样本，标签分别为 `'0'` 和 `'1'`，两类各占比 $p_0 = p_1 = 0.5$。混杂度 $H = -0.5 \log_2 0.5 - 0.5 \log_2 0.5 = -0.5 \times (-1) - 0.5 \times (-1) = 1.000$，达到两类别时的最大值。

## 样例3

**输入**

```
[[0,'1'], [1,'1'], [2,'1'], [3,'0']]
```

**输出**

```
0.811
```

**说明**

数据集共有 `4` 个样本。其中标签为 `'1'` 的样本有 `3` 个，占比 $p_1 = 0.75$；标签为 `'0'` 的样本有 `1` 个，占比 $p_0 = 0.25$。
混杂度计算：$H = -0.75 \log_2 0.75 - 0.25 \log_2 0.25 \approx -0.75 \times (-0.415) - 0.25 \times (-2) = 0.311 + 0.5 = 0.811$，四舍五入保留三位小数为 `0.811`。
