# 题目内容
给定一个仅由字符 `0` 和 `1` 构成的字符串。你必须恰好执行一次操作：选择两个不同下标 $i$ 和 $j$（$i 
eq j$），交换这两个位置上的字符。

不同的操作可能得到相同的字符串。请计算：所有可能的操作中，最终能够得到多少个互不相同的字符串。

字符串长度不小于 `2`，不大于 `200000`。

# 输入描述
一行，一个仅由字符 `0` 和 `1` 构成的字符串，长度在 `2` 到 `200000` 之间。

# 输出描述
输出一个整数，表示恰好交换一次后能够得到的不同字符串个数。

## 样例1

**输入**

```
1100
```

**输出**

```
5
```

**说明**

串中有 `2` 个 `1`、`2` 个 `0`。交换不同字符会得到 $2\times 2=`4`$ 个新串；交换两个相同字符会得到原串本身。
因此不同结果共 $4+1=`5`$ 个。

## 样例2

**输入**

```
01
```

**输出**

```
1
```

**说明**

只有一对不同字符可交换，得到 `10`。没有两个相同字符，原串不会作为结果出现，答案为 `1`。

## 样例3

**输入**

```
000
```

**输出**

```
1
```

**说明**

全是 `0`，任意交换都不改变字符串，只有原串这一种结果。

## 样例4

**输入**

```
10101
```

**输出**

```
7
```

**说明**

`0` 出现 `2` 次，`1` 出现 `3` 次。不同字符交换产生 $2\times 3=`6`$ 个新串，再加上交换相同字符得到的原串，共 `7` 种。
