## 解题思路

设字符串中 `0` 的个数为 $c_0$，`1` 的个数为 $c_1$。恰好交换两个不同位置，分两类：

1. 交换两个不同字符（一个 `0` 和一个 `1`）。每种选择都会改变字符串，且不同位置对对应不同的结果串，共有 $c_0\times c_1$ 种。
2. 交换两个相同字符。交换后字符串不变，仍是原串。只要 $c_0\ge 2$ 或 $c_1\ge 2$，原串就会作为结果出现一次。

因此答案为 $c_0\times c_1$，若存在一对相同字符可交换再加 $1$。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
s = input().strip()
cnt0 = s.count("0")
cnt1 = s.count("1")
res = cnt0 * cnt1
if cnt0 >= 2 or cnt1 >= 2:
    res += 1
print(res)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        long cnt0 = 0, cnt1 = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '0') cnt0++;
            else if (s.charAt(i) == '1') cnt1++;
        }
        long res = cnt0 * cnt1;
        if (cnt0 >= 2 || cnt1 >= 2) res++;
        System.out.println(res);
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    long long cnt0 = 0, cnt1 = 0;
    for (char c : s) {
        if (c == '0') cnt0++;
        else if (c == '1') cnt1++;
    }
    long long res = cnt0 * cnt1;
    if (cnt0 >= 2 || cnt1 >= 2) res++;
    cout << res << "\n";
    return 0;
}
```
