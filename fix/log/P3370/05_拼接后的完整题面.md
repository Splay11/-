# 题目内容
需要构造长度为 $n$ 的正整数序列 $a_1,a_2,\ldots,a_n$，使得这些数的按位异或等于它们的按位或，即

$$a_1\oplus a_2\oplus\cdots\oplus a_n = a_1\lor a_2\lor\cdots\lor a_n.$$

按位异或（$\oplus$）对二进制每一位做异或；按位或（$\lor$）对二进制每一位做或。可以证明解一定存在；多解时输出任意一组，且每个 $a_i$ 不超过 $10^9$。

测试组数不超过 $10^4$，单组 $1 \le n \le 2\times 10^5$，且所有测试中 $n$ 之和不超过 $2\times 10^5$。

# 输入描述
每个测试文件包含多组数据。第一行包含一个整数 $T$，表示数据组数，满足 $1 \le T \le 10^4$。
接下来 $T$ 行，每行一个整数 $n$（$1 \le n \le 2\times 10^5$），表示要构造的序列长度。
保证所有 $n$ 之和不超过 $2\times 10^5$。

# 输出描述
对每组数据输出一行 $n$ 个正整数 $a_1,a_2,\ldots,a_n$（$1 \le a_i \le 10^9$）。多解输出任意一组即可。

## 样例1

**输入**

```
2
4
1
```

**输出**

```
1 1 1 2
1
```

**说明**

$n=`4`$ 为偶数：可取三个 `1` 与一个 `2`。最低位出现奇数次、次低位出现 `1` 次，异或与或均为 `3`。
$n=`1`$ 为奇数：单个 `1` 的异或与或都是 `1`。

## 样例2

**输入**

```
1
3
```

**输出**

```
1 1 1
```

**说明**

$n=`3`$ 为奇数，三个 `1` 的最低位出现奇数次，其余位为 `0`，异或与或均为 `1`。

## 样例3

**输入**

```
1
2
```

**输出**

```
1 2
```

**说明**

$n=`2`$ 为偶数，构造 `1 2`。$1\oplus 2=`3$，$1\lor 2=`3$。
