# 题目内容
有两卷磁带记录，分别记为字符串 $s$ 与 $t$，其中 $t$ 的长度为偶数。把 $t$ 的后半段接到 $s$ 的末尾，然后输出接驳后的第一条记录，以及 $t$ 的前半段。

字符串由 ASCII 码在 `32` 到 `126` 之间的字符组成，即大小写字母、数字、标点符号和空格。

约束：$s$ 的长度不超过 `100`，$t$ 的长度不超过 `100` 且为偶数。

# 输入描述
第一行输入字符串 $s$，长度为 $n$（$1 \le n \le 100$）。
第二行输入字符串 $t$，长度为 $m$（$2 \le m \le 100$），保证 $m$ 为偶数。
两行均可能包含空格，读入时按整行处理。保证 $s$ 与 $t$ 只含 ASCII 码在 `32` 到 `126` 之间的字符。

# 输出描述
第一行输出把 $t$ 的后半段接到 $s$ 末尾后得到的字符串。
第二行输出 $t$ 的前半段。

## 样例1

**输入**

```
alpha
bridge
```

**输出**

```
alphadge
bri
```

**说明**

$s=\texttt{alpha}$，$t=\texttt{bridge}$ 长度为 `6`。后半段为 $\texttt{dge}$，前半段为 $\texttt{bri}$。
接驳后第一条为 $\texttt{alphadge}$，第二行输出 $\texttt{bri}$。

## 样例2

**输入**

```
A
xy
```

**输出**

```
Ay
x
```

**说明**

$s$ 只有一个字符，$t$ 长度为 `2`。后半为 $\texttt{y}$，前半为 $\texttt{x}$，输出 $\texttt{Ay}$ 与 $\texttt{x}$。
