## 解题思路

读入两行字符串 $s$ 与 $t$。设 $m=|t|$，令 $h=m/2$。把 $t$ 分成前半段 $t[0..h)$ 与后半段 $t[h..m)$，将后半段接到 $s$ 末尾，依次输出接驳结果与前半段。读入必须按整行处理，以保留空格。

## 复杂度分析

时间复杂度 $O(|s|+|t|)$，空间复杂度 $O(|s|+|t|)$。

## 代码实现

### Python

```python
def main():
    s = input().rstrip('\n')
    t = input().rstrip('\n')
    m = len(t)
    h = m // 2
    pre = t[:h]
    suf = t[h:]
    print(s + suf)
    print(pre)

if __name__ == '__main__':
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader rd = new BufferedReader(new InputStreamReader(System.in));
        String s = rd.readLine();
        String t = rd.readLine();
        int m = t.length();
        int h = m / 2;
        String pre = t.substring(0, h);
        String suf = t.substring(h);
        System.out.println(s + suf);
        System.out.println(pre);
    }
}
```
