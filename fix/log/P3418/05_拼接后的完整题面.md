# 题目内容
沿一条公路依次设置了 $n$ 个观测站，第 $i$ 个观测站的海拔为 $a_i$。定义该序列的起伏度为相邻观测站海拔差的绝对值之和，即 $|a_1-a_2|+|a_2-a_3|+\cdots+|a_{n-1}-a_n|$。长度为 `1` 的序列起伏度为 `0`。

现在要撤掉若干观测站（不能全部撤完），使得剩下的观测站按原相对顺序组成的新序列起伏度与原来相同。请计算在最优策略下最多可以撤掉多少个观测站。

约束：观测站数量不超过 $10^5$，各海拔为正整数且不超过 $10^9$。

# 输入描述
第一行包含一个整数 $n$，表示观测站的数量。
第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$，依次表示各观测站的海拔。
保证 $1 \le n \le 10^5$，$1 \le a_i \le 10^9$。

# 输出描述
输出一个整数，表示最多可以撤掉的观测站数量。

## 样例1

**输入**

```
1
1 2 8 8 9 1 1 1 5 5
```

**输出**

```
-3
```

**说明**

按题意模拟计算得到。
