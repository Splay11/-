# 题目内容
某系统的标准口令是字符串 `Baidu`（大小写必须完全一致）。现在有 $t$ 组询问，每组给出一个仅含英文字母的字符串。请判断该字符串能否通过重新排列字符，得到恰好等于 `Baidu` 的口令。
注意：重新排列后必须与 `Baidu` 的大小写完全相同，不能改写任何字符。

约束条件：
- 询问组数 $t$ 为正整数。
- 每个字符串仅包含英文字母。
- 所有字符串的长度之和不超过 $200000$。

# 输入描述
第一行包含一个正整数 $t$，表示询问次数。
接下来 $t$ 行，每行一个仅包含英文字母的字符串。

# 输出描述
对于每组询问输出一行：若该字符串能重排为 `Baidu`，输出 `Yes`；否则输出 `No`。

## 样例1

**输入**

```
3
aiBdu
Bduai
bdaui
```

**输出**

```
Yes
Yes
No
```

**说明**

第一串 `aiBdu` 与第二串 `Bduai` 都恰好含有字符 `B`、`a`、`i`、`d`、`u` 各一次，重排后可得 `Baidu`，输出 `Yes`。
第三串 `bdaui` 中 `B` 变成了小写 `b`，与标准口令大小写不一致，输出 `No`。

## 样例2

**输入**

```
1
Baidu
```

**输出**

```
Yes
```

**说明**

字符串本身就是 `Baidu`，无需重排，输出 `Yes`。

## 样例3

**输入**

```
2
Bai
Baiduu
```

**输出**

```
No
No
```

**说明**

第一串长度为 `3`，字符个数不足。
第二串多了一个 `u`，多重集合与 `Baidu` 不同。
两组均输出 `No`。
