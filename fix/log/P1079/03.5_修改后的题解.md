## 解题思路

标准口令 `Baidu` 是一个确定的多重集合。一个字符串能重排得到它，当且仅当排序后与 `Baidu` 排序后完全相同（大小写敏感）。

对标准口令排序一次得到目标串。对每组询问，把输入字符串排序后与目标串比较：相等则输出 `Yes`，否则输出 `No`。

## 复杂度分析

设所有询问字符串长度之和为 $L$。时间复杂度 $O(L \log L)$（每组排序），空间复杂度 $O(L)$。

## 代码实现

### Python

```python
t = int(input())
a = list("Baidu")
a.sort()
a = "".join(a)
for i in range(t):
    x = list(input().strip())
    x.sort()
    x = "".join(x)
    if a == x:
        print("Yes")
    else:
        print("No")
```

### Java

```java
import java.util.Arrays;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int t = in.nextInt();
        char[] target = "Baidu".toCharArray();
        Arrays.sort(target);
        String std = new String(target);
        for (int i = 0; i < t; i++) {
            char[] x = in.next().toCharArray();
            Arrays.sort(x);
            if (std.equals(new String(x))) {
                System.out.println("Yes");
            } else {
                System.out.println("No");
            }
        }
    }
}
```

### C++

```cpp
#include <iostream>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    int t;
    cin >> t;
    string a = "Baidu";
    sort(a.begin(), a.end());
    while (t--) {
        string x;
        cin >> x;
        sort(x.begin(), x.end());
        if (x == a) cout << "Yes" << endl;
        else cout << "No" << endl;
    }
    return 0;
}
```
