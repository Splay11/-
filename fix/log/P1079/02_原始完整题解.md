## 题目思路

对字符串排序，然后判断是否与"Badiu"相等即可。

## 代码

### C++

```c++
#include<bits/stdc++.h>
using namespace std;
int main (){
    int t;
    cin >> t;
    string a = "Baidu";
    sort(a.begin() , a.end());
    while (t--){
        string x;
        cin >> x;
        sort(x.begin() , x.end());
        if (x == a) cout << "Yes" << endl;
        else cout << "No" << endl;
    }
    return 0;
}
```

### python

```python
n = int(input())
a = list("Baidu")
a.sort()
a = "".join(a)
for i in range (n):
    x = list(input())
    x.sort()
    x = "".join(x)
    if a == x:
        print("Yes")
    else:
        print("No")
```
