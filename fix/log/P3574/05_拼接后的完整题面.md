# 题目内容
你正在开发一套图书管理工具，需要为馆藏书籍的英文简介建立一个相似度查询功能。请根据给定的若干条简介，完成以下任务：

1. 对每条简介进行预处理：统一转为小写，按空格和标点分离出词语，并剔除常见英文停用词（如 "the"、"is" 等）。
2. 为每条简介生成一个权值向量。向量的每一维对应一个在整个简介集合中出现的词，其权值由两部分决定：
   - 词在当前简介中出现的频次；
   - 词的稀有程度，即在多少条简介中出现过。出现越少的词，当它出现在某条简介中时，赋予越高的权重。
3. 将所有向量做 L2 归一化（使向量的欧几里得长度为 1），然后计算任意两条简介对应向量之间的余弦相似度，定义为 $\displaystyle \cos\theta = \frac{\mathbf{v}_i \cdot \mathbf{v}_j}{\|\mathbf{v}_i\| \|\mathbf{v}_j\|}$。
4. 构建一个 $n \times n$ 的相似度矩阵，其中的每个数值保留两位小数并以字符串形式表示（例如 `'0.24'`），自身与自身的相似度为 `'1.00'`。

约束条件：
- 简介数目 $n$ 满足 $1 \le n \le 500$。
- 每条简介的长度不超过 $10^4$ 个字符。
- 输入保证只包含 ASCII 可打印字符。
- 若所有简介在去除停用词后均为空，则相似度矩阵对角线为 `'1.00'`，其余位置为 `'0.00'`。

# 输入描述
输入仅一行，包含一个合法的 JSON 数组。数组的每个元素都是一个字符串，表示一条英文简介。保证数组非空，且字符串长度不超过上限。

# 输出描述
输出共 $n$ 行，每行是一个 Python 列表，包含 $n$ 个字符串。第 $i$ 行第 $j$ 列的字符串表示第 $i$ 条简介与第 $j$ 条简介之间的相似度（保留两位小数）。每行的列表格式可直接被 Python 解析。

## 样例1

**输入**

```
["Hello, world! This is a test.", "hello, world! this is a test.", "Goodbye universe."]
```

**输出**

```
['1.00','1.00','0.00']
['1.00','1.00','0.00']
['0.00','0.00','1.00']
```

**说明**

预处理过程将文本统一转为小写并剔除标点与英文停用词。"Hello, world! This is a test." 与 "hello, world! this is a test." 处理后均仅保留 `hello`、`world`、`test` 三个词，因此两条简介的 TF-IDF 向量完全相同。经过 L2 归一化后，两者的余弦相似度为 `1.00`。第三条简介 "Goodbye universe." 处理后得到 `goodbye` 与 `universe`，与前两条没有共享词汇，余弦相似度为 `0.00`。每条简介与自身的相似度均为 `1.00`。

## 样例2

**输入**

```
["apple banana", "apple orange"]
```

**输出**

```
['1.00','0.34']
['0.34','1.00']
```

**说明**

两条简介均不含停用词。词汇表为 `apple`、`banana`、`orange`。`apple` 在两个文档中都出现，文档频率较高，故其逆文档频率（IDF）较低；`banana` 和 `orange` 各只出现在一个文档中，IDF 较高。计算 TF-IDF 并做 L2 归一化后，两向量的点积约为 $0.336$，四舍五入保留两位小数得 `'0.34'`。自身与自身的相似度恒为 `1.00`。

## 样例3

**输入**

```
["the is a", "a the"]
```

**输出**

```
['1.00','0.00']
['0.00','1.00']
```

**说明**

输入的两条简介全部由常见英文停用词构成。在预处理阶段，所有词均被停用词表过滤，导致词汇表为空。按照题目边界规则，相似度矩阵的对角线元素设为 `'1.00'`，其余位置设为 `'0.00'`。

## 样例4

**输入**

```
["Artificial intelligence"]
```

**输出**

```
['1.00']
```

**说明**

仅含一条简介 `n = 1`。其自身与自身的余弦相似度为 `1.00`，因此输出一个 $1 \times 1$ 的矩阵。
