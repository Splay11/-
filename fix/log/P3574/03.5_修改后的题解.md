## 解题思路

1. **输入解析**：输入为一行 JSON 数组，使用 JSON 库将其解析为字符串列表，每个字符串代表一条馆藏英文简介。设简介总数为 $n$。
2. **文本预处理**：
   - 将所有简介统一转为小写。
   - 按非字母字符（空格、标点等）对每条简介进行切分，提取出连续的字母序列作为词语。
   - 过滤掉常见的英文停用词（例如 “the”,“is”,“a”,“an”,“of” 等），保留有实际语义的词语。若一条简介在去除停用词后没有剩余词，则该简介对应的权值向量视为零向量。
3. **构建词汇表与文档频率**：
   - 遍历所有预处理后的简介，统计每个词在多少条简介中出现过（文档频率 $df$），同时为每条简介记录其内部各词的出现次数（词频 $tf$）。
   - 所有出现的词构成词汇表，便于后续索引，但实际实现中使用字典（映射）存储每个简介的稀疏词频向量，避免构建巨大稠密矩阵。
4. **计算权值向量（TF‑IDF）**：
   - 对词汇表中的每个词 $w$，计算逆文档频率 $idf(w) = \log \frac{1 + n}{1 + df(w)} + 1$，该公式能平滑 $idf$ 并保证非负，且赋予稀有词更高的权重。
   - 每条简介 $d$ 中词 $w$ 的权值 $v_{d,w} = tf(w,d) \times idf(w)$。最终得到每条简介的稀疏权值向量。
5. **L2 归一化**：
   - 计算每个向量的欧几里得范数 $\|\mathbf{v}\|_2 = \sqrt{\sum_w v_{d,w}^2}$。若范数大于 0，则将向量每个分量除以该范数；否则向量保持全 0。
6. **计算余弦相似度**：
   - 两条简介 $i$ 与 $j$ 的相似度定义为 $\cos\theta_{ij} = \frac{\mathbf{v}_i \cdot \mathbf{v}_j}{\|\mathbf{v}_i\| \|\mathbf{v}_j\|}$。由于向量已 L2 归一化，范数为 1（或 0），相似度等价于两个归一化向量的点积。
   - 对于零向量，规定其与自身的相似度为 $1.00$，与其它向量的相似度为 $0.00$。
   - 为实现高效计算，利用稀疏表示：对每对文档 $i,j$，只遍历其中一个文档中出现的词，检查另一个文档是否包含该词，累加权值乘积即可。
7. **结果构造**：
   - 生成 $n \times n$ 的相似度矩阵，每个元素保留两位小数并以字符串形式存储（例如 `'0.24'`）。对角线固定为 `'1.00'`。
8. **边界情况**：若所有简介预处理后均为空（词汇表为空），则直接返回对角线为 `'1.00'`、其余位置为 `'0.00'` 的矩阵。

## 复杂度分析

- **时间复杂度**：设 $n$ 为简介条数，$L$ 为简介平均长度（字符数）。预处理分词与停用词过滤耗时为 $O(n L)$。统计词频和文档频率可在相同扫描过程中完成，同样为 $O(n L)$。计算 IDF 和为每条简介生成 TF‑IDF 权值向量的复杂度为 $O(\sum_i |W_i|)$，其中 $|W_i|$ 为第 $i$ 条简介的词汇数，总和不超过 $O(n L)$。L2 归一化也是对每条简介的词汇数线性。计算 $n^2$ 个相似度时，每对简介只遍历较短词汇列表，总复杂度为 $O(n^2 \cdot \overline{|W|})$，最坏 $O(n^2 L)$。因 $n \le 500$，$L \le 10^4$，整体运算可在合理时间内完成。

- **空间复杂度**：需要存储每条简介的稀疏权值向量（大小正比于 $|W_i|$），总计 $O(n L)$。此外需要存储文档频率表（大小 $O(V)$，$V$ 为总词汇量），以及最终的相似度矩阵 $O(n^2)$。因此空间复杂度为 $O(n L + V + n^2)$，在给定数据范围内完全可行。

def tokenize(text: str):
    """ 小写化并按非字母字符分词，返回有效词语列表（已去除停用词） """
    tokens = re.findall(r'[a-zA-Z]+', text.lower())
    return [w for w in tokens if w not in STOP_WORDS]

def compute_tfidf_vectors(docs):
    n = len(docs)
    # 每条文档的词频字典：doc_tf[i] = {word: tf}
    doc_tf = []
    # 每个词的文档频率
    df = defaultdict(int)

    for text in docs:
        tokens = tokenize(text)
        tf_dict = {}
        for w in tokens:
            tf_dict[w] = tf_dict.get(w, 0) + 1
        # 更新文档频率（每个词在当前文档中最多贡献一次）
        for w in tf_dict.keys():
            df[w] += 1
        doc_tf.append(tf_dict)

    # 若所有文档均无有效词
    if not df:
        return [], 0

    V = len(df)
    # 计算 IDF
    idf = {}
    for w, cnt in df.items():
        idf[w] = math.log((1 + n) / (1 + cnt)) + 1

    # 生成 TF-IDF 向量（稀疏表示）
    vectors = []
    for tf_dict in doc_tf:
        vec = {}
        sq_sum = 0.0
        for w, tf in tf_dict.items():
            if w in idf:  # 所有词都应该在idf中
                val = tf * idf[w]
                vec[w] = val
                sq_sum += val * val
        # L2 归一化
        if sq_sum > 0:
            norm = math.sqrt(sq_sum)
            for w in vec:
                vec[w] /= norm
        vectors.append(vec)
    return vectors, n

def similarity_matrix(vectors, n):
    """ 计算余弦相似度矩阵，若vectors为空则返回对角1其余0的矩阵 """
    if not vectors:
        return [[("1.00" if i == j else "0.00") for j in range(n)] for i in range(n)]

    mat = [[""] * n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            if i == j:
                mat[i][j] = "1.00"
                continue
            vi = vectors[i]
            vj = vectors[j]
            # 计算点积
            dot = 0.0
            # 遍历较小的字典以加速
            if len(vi) < len(vj):
                for w, val in vi.items():
                    if w in vj:
                        dot += val * vj[w]
            else:
                for w, val in vj.items():
                    if w in vi:
                        dot += val * vi[w]
            mat[i][j] = f"{dot:.2f}"
    return mat

def main():
    data = sys.stdin.read().strip()
    if not data:
        return
    try:
        texts = json.loads(data)
    except json.JSONDecodeError:
        # 简单容错：如果json解析失败则退出
        return
    vectors, n = compute_tfidf_vectors(texts)
    mat = similarity_matrix(vectors, n)
    for row in mat:
        # 直接打印 Python 列表格式
        print(row)

if __name__ == "__main__":
    main()

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        String line;
        while ((line = br.readLine()) != null) {
            sb.append(line);
        }
        String input = sb.toString().trim();
        if (input.isEmpty()) {
            return;
        }
        // 简单解析 JSON 数组（假设格式标准，直接按逗号和引号拆分，更健壮可使用 org.json 库，这里用最小实现）
        // 实际题目保证为合法 JSON 数组，此处使用正则提取双引号内的字符串
        List<String> texts = new ArrayList<>();
        Matcher m = Pattern.compile("\"((?:[^\"]|\\\\\")*)\"").matcher(input);

        }

        if (df.isEmpty()) {
            // 所有文档去停用词后为空
            for (int i = 0; i < n; i++) {
                List<String> row = new ArrayList<>();

                }
                System.out.println(row.toString());
            }
            return;

        Map<String, Double> idf = new HashMap<>();
        for (Map.Entry<String, Integer> e : df.entrySet()) {
            String w = e.getKey();
            int cnt = e.getValue();
            idf.put(w, Math.log((1.0 + n) / (1.0 + cnt)) + 1.0);

        // 生成 TF-IDF 稀疏向量并 L2 归一化
        List<Map<String, Double>> vectors = new ArrayList<>();
        for (Map<String, Integer> tfMap : docTf) {
            Map<String, Double> vec = new HashMap<>();

            for (Map.Entry<String, Integer> e : tfMap.entrySet()) {

                    for (Map.Entry<String, Double> e : vi.entrySet()) {
                        Double val2 = vj.get(e.getKey());
                        if (val2 != null) {
                            dot += e.getValue() * val2;
                        }
                    }

                    for (Map.Entry<String, Double> e : vj.entrySet()) {
                        Double val1 = vi.get(e.getKey());
                        if (val1 != null) {
                            dot += e.getValue() * val1;
                        }
                    }
                }

            }
            rowStr.append("]");

    vector<string> tokens;
    string lower;
    for (char c : text) lower += tolower(c);
    regex word_regex("[a-zA-Z]+");
    auto words_begin = sregex_iterator(lower.begin(), lower.end(), word_regex);

        string token = it->str();
        if (STOP_WORDS.find(token) == STOP_WORDS.end()) {

            sq_sum += val * val;

            for (auto& p : vec) {
                p.second /= norm;
            }
