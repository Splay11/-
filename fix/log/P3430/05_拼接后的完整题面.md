# 题目内容
档案系统用正整数作为密钥。称一个素数 $p$ 为残核密钥，当且仅当反复删去其十进制表示的最后一位后，每一步得到的数（包括 $p$ 本身以及最终剩下的一位数字）都仍是素数。

例如 $739$ 是残核密钥：它本身是素数，去掉末位得到 $73$ 仍是素数，再去掉末位得到 $7$ 仍是素数。

给定若干闭区间 $[l,r]$，请统计每个区间内残核密钥的个数。

询问组数不超过 $10^5$，区间端点为正整数且不超过 $10^{18}$。

# 输入描述
每个测试文件包含多组询问。
第一行包含一个整数 $T$，表示询问组数，满足 $1 \le T \le 10^5$。
接下来 $T$ 行，每行两个整数 $l$ 和 $r$，表示一个查询区间，满足 $1 \le l \le r \le 10^{18}$。

# 输出描述
对每组询问输出一行一个整数，表示闭区间 $[l,r]$ 内残核密钥的个数。

## 样例1

**输入**

```
3
1 10
100 300
1000 3000
```

**输出**

```
4
3
5
```

**说明**

区间 $[1,10]$ 内的残核密钥为 $2,3,5,7$，共 `4` 个。
区间 $[100,300]$ 内为 $233,239,293$，共 `3` 个。
区间 $[1000,3000]$ 内为 $2333,2339,2393,2399,2939$，共 `5` 个。

## 样例2

**输入**

```
1
8 10
```

**输出**

```
0
```

**说明**

$8,9,10$ 均不是素数，因此该区间内残核密钥个数为 `0`。

## 样例3

**输入**

```
2
2 2
739 739
```

**输出**

```
1
1
```

**说明**

$2$ 是一位素数，属于残核密钥，答案为 `1`。
$739$ 按题意逐步截去末位后均为素数，答案为 `1`。

## 样例4

**输入**

```
1
100000000 1000000000000000000
```

**输出**

```
0
```

**说明**

残核密钥最多只有 `8` 位。该询问区间左端已超过所有残核密钥，答案为 `0`。
