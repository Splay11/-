# 题目内容
有一条长度为 $n$ 的寄存器序列 $a_1,a_2,\ldots,a_n$。一次操作可以选定下标 $i$（$1 \le i \le n$）和非负整数 $x$（$0 \le x \le 10^9$），把前缀 $a_1,a_2,\ldots,a_i$ 的每一个值都异或上 $x$。

求最少操作次数，使得序列中所有值变成相同。

测试组数不超过 `1000`，单组 $1 \le n \le 2\times 10^5$，$1 \le a_i \le 10^8$，且所有测试中 $n$ 之和不超过 $2\times 10^5$。

# 输入描述
每个测试文件包含多组数据。第一行包含一个整数 $T$，表示数据组数，满足 $1 \le T \le 1000$。
每组数据第一行包含一个整数 $n$（$1 \le n \le 2\times 10^5$）。
第二行包含 $n$ 个整数 $a_1,a_2,\ldots,a_n$（$1 \le a_i \le 10^8$）。
保证单个文件中所有 $n$ 之和不超过 $2\times 10^5$。

# 输出描述
对每组数据输出一行一个整数，表示将序列全部变为相同值所需的最少操作次数。

## 样例1

**输入**

```
2
4
1 1 2 2
5
1 2 3 4 5
```

**输出**

```
1
4
```

**说明**

第一组：对前缀长度 `2` 异或 `3`，序列变为 $2,2,2,2$，操作 `1` 次。
第二组：从右往左看，每个位置都需要一次前缀操作才能与末位对齐，最少 `4` 次。

## 样例2

**输入**

```
1
3
7 7 7
```

**输出**

```
0
```

**说明**

已经全部相同，无需操作，答案为 `0`。

## 样例3

**输入**

```
1
1
42
```

**输出**

```
0
```

**说明**

只有一个数，已经相同，答案为 `0`。

## 样例4

**输入**

```
1
2
5 8
```

**输出**

```
1
```

**说明**

对长度为 `1` 的前缀异或一次即可与末位对齐，答案为 `1`。
