# 题目内容
给定一个包含 $n$ 个正整数的序列 $a_1,a_2,\dots,a_n$。你可以对该序列进行至多两次操作，每次操作可以选择一个元素，将其值增加 $1$。最终，你需要让序列中所有元素的乘积在二进制表示下末尾的零尽可能多。请计算最多能获得多少个末尾零。

序列长度 $n$ 不超过 $10^5$，所有 $a_i$ 均为不超过 $10^9$ 的正整数。

# 输入描述
第一行包含一个整数 $n$，表示序列的长度。
第二行包含 $n$ 个整数，依次表示序列 $a_1,a_2,\dots,a_n$。

# 输出描述
输出一个整数，表示经过至多两次加 $1$ 操作后，序列元素乘积的二进制表示末尾零的最大可能数量。

## 样例1

**输入**

```
3
1 1 1
```

**输出**

```
2
```

**说明**

初始乘积为 $1 \times 1 \times 1 = 1$，二进制表示为 `1`，末尾 `0` 个零。
我们可以进行至多两次操作。最优方案：将前两个 `1` 各自增加 `1`，序列变为 `2, 2, 1`。乘积为 $2 \times 2 \times 1 = 4$，二进制表示为 `100`，末尾有 `2` 个零。
也可以将同一个 `1` 加两次变成 `3`，乘积为 `3`，末尾零个数为 `0`，不如前者。因此最多获得 `2` 个末尾零。

## 样例2

**输入**

```
2
2 3
```

**输出**

```
3
```

**说明**

初始乘积为 $2 \times 3 = 6$，二进制 `110`，末尾 `1` 个零（$6=2^1 \times 3$）。
我们只需一次操作：将 `3` 增加 `1` 变成 `4`（$4=2^2$）。新序列 `2, 4`，乘积为 `8`，二进制 `1000`，末尾 `3` 个零。
其他操作方案：不操作得 `1`；将 `2` 加 `1` 变成 `3`，乘积 `9`（二进制 `1001`，末尾 `0` 个零）；将 `3` 加 `2` 变成 `5`，乘积 `10`（末尾 `1` 个零）。均不超过 `3`。故答案为 `3`。

## 样例3

**输入**

```
2
7 1
```

**输出**

```
4
```

**说明**

初始乘积 $7 \times 1 = 7$（二进制 `111`），末尾 `0` 个零。
使用两次操作：将 `7` 加 `1` 得到 `8`（$8=2^3$），将 `1` 加 `1` 得到 `2`（$2=2^1$）。序列变为 `8, 2`，乘积为 `16`，二进制 `10000`，末尾 `4` 个零。
其他方案：仅将 `7` 加 `2` 得 `9`，乘积 `9`，零个数为 `0`；仅将 `7` 加 `1` 得 `8`，`1` 不变，乘积 `8`，零个数为 `3`；均不如 `4`。所以最多 `4` 个。

## 样例4

**输入**

```
1
1
```

**输出**

```
1
```

**说明**

只有一个元素，初始为 `1`（乘积 `1`，零个数 `0`）。我们可以将其加 `1` 得到 `2`（$2=2^1$），乘积 `2`，二进制 `10`，末尾 `1` 个零。加两次得到 `3`，零个数 `0`。故最优为 `1`。
