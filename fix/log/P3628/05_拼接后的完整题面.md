# 题目内容
有 $n$ 个排成一列的储物格，编号依次为 $1$ 到 $n$，需要将总量为 $m$ 个单位的物资全部放入这些储物格中。分配必须满足：每个储物格至少分到 $1$ 个单位，且任意两个相邻储物格中的物资数量之差的绝对值不超过 $1$。在所有符合要求的分配方案中，我们想让编号为 $k$ 的储物格获得尽可能多的物资。问该储物格最多可以分到多少单位物资。
约束：$1 \le n \le m \le 10^9$，$1 \le k \le n$，输入均为整数。

# 输入描述
第一行包含三个整数 $n$、$m$ 和 $k$，分别表示储物格的数量、物资总量以及关注的储物格编号。

# 输出描述
输出一个整数，表示编号为 $k$ 的储物格能获得的最大物资数量。

## 样例1

**输入**

```
3 10 2
```

**输出**

```
4
```

**说明**

储物格数量 $n=3$，物资总量 $m=10$，关注第 $k=2$ 个储物格。要使 $a_2$ 尽可能大，两侧需在相邻差 $\le 1$ 的前提下尽量紧凑。当 $a_2=4$ 时，最优分配为 $[3, 4, 3]$，总和恰为 $10$，满足条件。若 $a_2=5$，则最小总和为 $4+5+4=13 > 10$，不可行。因此 $k=2$ 最多能分到 `4` 个单位。

## 样例2

**输入**

```
10 20 1
```

**输出**

```
5
```

**说明**

有 $n=10$ 个储物格，物资 $m=20$，关注位于左边界 $k=1$ 的位置。此时没有左侧，只需考虑右侧按步长 $1$ 递减。假设 $a_1=x$，最优序列为 $x, x-1, x-2, \dots$ 直至 $1$，之后全部填 $1$。当 $x=5$ 时，序列为 $[5,4,3,2,1,1,1,1,1,1]$，总和 $=19 \le 20$。当 $x=6$ 时最小总和为 $24 > 20$。因此最大值为 `5`。

## 样例3

**输入**

```
5 5 3
```

**输出**

```
1
```

**说明**

当物资总量恰好等于储物格数量 $m=n=5$ 时，由于每个储物格至少分到 $1$ 个单位，唯一的分配方案是所有储物格均为 $1$。因此第 $k=3$ 个储物格也只能分到 $1$，这是典型的边界情况，答案为 `1`。
