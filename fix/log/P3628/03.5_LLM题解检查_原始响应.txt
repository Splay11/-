## 解题思路

题目要求在满足每个储物格至少分配 $1$ 个单位物资、相邻储物格物资数量之差的绝对值不超过 $1$ 的前提下，最大化编号 $k$ 的储物格中的物资数量。由于答案具有单调性——若编号 $k$ 的储物格能分配到 $x$ 个物资，则也能分配到 $x-1$ 个物资——因此可以采用**二分答案**的方法求解。

1. **二分查找的思想**  
   设定二分范围 `low = 1`，`high = m`，每次取中间值 `mid`，检查能否让编号 $k$ 的储物格分配到 `mid` 个单位物资，并且总物资消耗不超过 $m$。若可行，则尝试更大的值；否则减小 `mid`。

2. **检查函数 `check(x)`**  
   给定一个目标值 $x$，我们希望验证是否有一种分配方案，使得编号 $k$ 的储物格恰好获得 $x$ 个物资，同时总消耗最小。为了最小化总消耗，其他储物格的物资应尽可能减少，同时满足相邻差不超过 $1$ 的约束。  
   - 从编号 $k$ 开始，物资数量向两侧递减，形成“山峰”形状： $k$ 位置为 $x$，$k-1$ 和 $k+1$ 位置至少为 $x-1$，$k-2$ 和 $k+2$ 位置至少为 $x-2$，依此类推。  
   - 一直递减到 $1$ 后，更远的储物格不能再少于 $1$，必须至少分配 $1$。  
   - 因此，可以将 $k$ 左侧和右侧分别计算最少需要的物资总量。

3. **左右两侧的计算**  
   - 左侧有 $left = k-1$ 个储物格。其中能形成递减序列的最大长度为 $L = \min(k-1, x-1)$，这些位置的物资分别为 $x-1, x-2, \dots, x-L$，总数为等差数列求和 $\sum_{i=1}^{L}(x-i) = L \cdot x - \frac{L(L+1)}{2}$。剩余 $k-1-L$ 个位置每个至少分配 $1$。  
   - 右侧有 $right = n-k$ 个储物格，同理 $R = \min(n-k, x-1)$，总数为 $R \cdot x - \frac{R(R+1)}{2} + (n-k-R)$。  
   - 加上编号 $k$ 自身的 $x$，即可得到所需的总物资数 $S(x)$。若 $S(x) \le m$，则 $x$ 可行；否则不可行。

4. **二分求解**  
   根据 `check(mid)` 的结果更新 `low` 和 `high`，最终输出最大可行的 `ans`。

## 复杂度分析

- 时间复杂度：二分查找的范围为 $1$ 到 $m$，共 $O(\log m)$ 次迭代；每次 `check` 函数仅进行常数次算术运算，时间复杂度为 $O(1)$。因此总时间复杂度为 $O(\log m)$。  
- 空间复杂度：仅使用了常数个变量，不需要额外数组存储，空间复杂度为 $O(1)$。

## 代码实现

### Python

```python
def check(x, n, m, k):
    """
    检查给编号 k 的储物格分配 x 个物资是否可行
    n: 储物格总数, m: 物资总量, k: 目标储物格编号
    """
    if x == 0:
        return True

    needed = x  # 编号 k 自身需要的物资

    # 左侧最少物资计算
    left_kids = k - 1
    if left_kids > 0:
        l = min(left_kids, x - 1)
        needed += l * x - l * (l + 1) // 2
        if left_kids > l:
            needed += (left_kids - l)

    # 右侧最少物资计算
    right_kids = n - k
    if right_kids > 0:
        r = min(right_kids, x - 1)
        needed += r * x - r * (r + 1) // 2
        if right_kids > r:
            needed += (right_kids - r)

    return needed <= m


def solve():
    n, m, k = map(int, input().split())
    low, high = 1, m
    ans = 0

    while low <= high:
        mid = low + (high - low) // 2
        if check(mid, n, m, k):
            ans = mid
            low = mid + 1
        else:
            high = mid - 1

    print(ans)


if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.Scanner;

public class Main {

    private static boolean check(long x, long n, long m, long k) {
        if (x == 0) {
            return true;
        }

        long needed = x; // 编号 k 自身需要的物资

        // 左侧最少物资计算
        long leftKids = k - 1;
        if (leftKids > 0) {
            long l = Math.min(leftKids, x - 1);
            needed += l * x - l * (l + 1) / 2;
            if (leftKids > l) {
                needed += (leftKids - l);
            }
        }

        // 右侧最少物资计算
        long rightKids = n - k;
        if (rightKids > 0) {
            long r = Math.min(rightKids, x - 1);
            needed += r * x - r * (r + 1) / 2;
            if (rightKids > r) {
                needed += (rightKids - r);
            }
        }

        return needed <= m;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        long n = scanner.nextLong();
        long m = scanner.nextLong();
        long k = scanner.nextLong();

        long low = 1, high = m, ans = 0;
        while (low <= high) {
            long mid = low + (high - low) / 2;
            if (check(mid, n, m, k)) {
                ans = mid;
                low = mid + 1;
            } else {
                high = mid - 1;
            }
        }

        System.out.println(ans);
        scanner.close();
    }
}
```
