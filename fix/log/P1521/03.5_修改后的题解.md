## 解题思路

本题要求统计满足三个条件的序列个数，可以使用动态规划进行计数。

设 `dp[i][j]` 表示：考虑了前 `i` 个位置（即 `a_1, a_2, …, a_i`），且这些位置上已选的数字之和模 `n` 的余数为 `j` 的方案数。

**初始化：**  
`dp[0][0] = 1`，表示还没有选择任何数字时，和为 0，模 `n` 余 0，方案数为 1。

**状态转移：**  
对于第 `i` 个位置，需要选择一个整数 `a_i`，满足：
- `1 ≤ a_i ≤ m`；
- `a_i` 能被 `i` 整除，即 `a_i ∈ {i, 2i, 3i, …, ⌊m/i⌋·i}`。

枚举所有可能的 `a_i` 取值，记为 `p`。若前 `i-1` 个数的和模 `n` 余数为 `(j - p % n + n) % n`，那么加上 `p` 后总和模 `n` 的余数就变为 `j`。因此转移方程为：

```
dp[i][j] = Σ dp[i-1][(j - p % n + n) % n]   （对所有合法的p求和）
```

为了方便计算，可以按照以下循环顺序进行：
- 外层枚举 `i` 从 1 到 n；
- 中层枚举余数 `j` 从 0 到 n-1；
- 内层枚举合法的 `p`，从 `i` 开始，每次增加 `i`，直到 `m`。

每次转移时对结果取模 `10^9+7`。

**最终答案：**  
所有 n 个位置选完后，总和模 n 余 0 的方案数即为 `dp[n][0]`，直接输出即可。

数据范围 n, m ≤ 1000，上述三重循环的总操作次数大约为 n × n × (m/i 之和) ≈ n·m·H_n，在时限内足够。

## 复杂度分析

- 时间复杂度：$O(n \cdot m \log n)$。  
  对于每个长度 i，合法取值的数量约为 m/i；枚举 j 需要 O(n)；因此总操作次数为 n·Σ_{i=1}^n (m/i) = n·m·H_n ≈ n·m·ln(n)，在实际数据范围内可以接受。

- 空间复杂度：$O(n^2)$。  
  需要一个 (n+1) × n 的二维数组存储 DP 状态，这里 n ≤ 1000，空间允许。

## 代码实现

### Python

```python
mod = 1000000007

n, m = map(int, input().split())

# dp[i][j] 表示前 i 个位置，和模 n 余 j 的方案数
dp = [[0] * (n + 1) for _ in range(n + 1)]
dp[0][0] = 1

for i in range(1, n + 1):
    for j in range(n):
        # 枚举所有满足条件的 a_i
        for p in range(i, m + 1, i):
            dp[i][j] = (dp[i][j] + dp[i - 1][(j - p % n + n) % n]) % mod

print(dp[n][0])
```

### Java

```java
import java.util.Scanner;

public class Main {
    static final long MOD = 1000000007;

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        
        // dp[i][j] 表示前 i 个位置，和模 n 余 j 的方案数
        long[][] dp = new long[n + 1][n];
        dp[0][0] = 1;

        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < n; j++) {
                for (int p = i; p <= m; p += i) {
                    dp[i][j] = (dp[i][j] + dp[i - 1][(j - p % n + n) % n]) % MOD;
                }
            }
        }

        System.out.println(dp[n][0]);
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int MOD = 1000000007;

int main() {
    int n, m;
    cin >> n >> m;

    // dp[i][j] 表示前 i 个位置，和模 n 余 j 的方案数
    vector<vector<long long>> dp(n + 1, vector<long long>(n, 0));
    dp[0][0] = 1;

    for (int i = 1; i <= n; ++i) {
        for (int j = 0; j < n; ++j) {
            for (int p = i; p <= m; p += i) {
                dp[i][j] = (dp[i][j] + dp[i - 1][(j - p % n + n) % n]) % MOD;
            }
        }
    }

    cout << dp[n][0] << endl;
    return 0;
}
```
