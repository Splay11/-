# 题目内容
在算学中，我们称一个大于 $1$ 的整数为 **基元数**，当且仅当它除了 $1$ 和自身之外没有其他正因数。

现在给出一个整数 $n$，请你判断它是否可以写成 $4$ 个基元数的和。如果可以，请给出任意一种拆分方案；否则，说明无解。

数据约束：测试数据组数不超过 `10`，每组的整数 $n$ 满足 $8 \le n \le 10^9$。

# 输入描述
第一行包含一个整数 $t$，表示测试数据的数量。
接下来 $t$ 行，每行包含一个整数 $n$，表示需要判断的整数。

# 输出描述
输出 $t$ 行，每行对应一组数据的答案：
若存在解，则在同一行输出 $4$ 个以空格分隔的基元数，表示 $n$ 的一种拆分方案；若不存在解，则输出 $-1$。

## 样例1

**输入**

```
1
8
```

**输出**

```
2 2 2 2
```

**说明**

$n=8$ 是满足 $n \ge 8$ 的最小值，且为偶数。按照构造策略，先固定选出两个 `2`，剩余部分 $m = n - 4 = 4$。将偶数 $4$ 拆分为两个素数，即 `2` 和 `2`，最终得到四个素数 `2`、`2`、`2`、`2`，它们的和正好等于 `8`。

## 样例2

**输入**

```
1
9
```

**输出**

```
2 3 2 2
```

**说明**

$n=9$ 是大于 `8` 的最小奇数。根据策略，先取出 `2` 和 `3`，剩余部分 $m = n - 5 = 4$。将偶数 $4$ 拆分为 `2` 与 `2`，因此得到四个素数 `2`、`3`、`2`、`2`，满足和为 `9`。

## 样例3

**输入**

```
2
10
11
```

**输出**

```
2 2 3 3
2 3 3 3
```

**说明**

共两组数据。
第一组 $n=10$ 为偶数：先选两个 `2`，剩余 $m = 10 - 4 = 6$；将 $6$ 拆分为两个素数 `3` 与 `3`，最终方案为 `2 2 3 3`。
第二组 $n=11$ 为奇数：先选 `2` 和 `3`，剩余 $m = 11 - 5 = 6$；同样将 $6$ 拆为 `3` 与 `3`，方案为 `2 3 3 3`。

## 样例4

**输入**

```
1
17
```

**输出**

```
2 3 5 7
```

**说明**

$n=17$ 为奇数，先固定选出 `2` 和 `3`，剩余部分 $m = 17 - 5 = 12$。将偶数 $12$ 拆分为两个素数：依次尝试奇数 $p$，发现 $p=5$ 时 $12-5=7$ 也为素数，故得到拆分 `5` 和 `7`。最终四个素数为 `2`、`3`、`5`、`7`，其和恰好为 `17`。
