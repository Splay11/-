# 题目内容
有 $n$ 条开关记录，每条记录是长度为 $m$ 的字符串，仅由字符 `'0'` 和 `'1'` 组成。你可以选择至少一条记录，将所选记录按位或，得到一个长度为 $m$ 的二进制串，再把它解释为十进制整数。

统计：所有非空选择方案中，能够得到多少个互不相同的质数。

开关记录条数 $n$ 满足 $1 \le n \le 20$，每条记录长度 $m$ 满足 $1 \le m \le 14$。

# 输入描述
第一行包含两个正整数 $n$ 和 $m$，分别表示记录条数和每条记录的长度。
接下来 $n$ 行，第 $i$ 行包含一个长度为 $m$、仅由字符 `'0'` 和 `'1'` 组成的字符串 $s_i$。

# 输出描述
输出一个整数，表示能得到的不同质数的个数。

## 样例1

**输入**

```
3 4
0010
1000
1010
```

**输出**

```
1
```

**说明**

三条记录对应十进制 `2`、`8`、`10`。非空子集按位或的结果有 `2,8,10,10,10,10,10`，其中只有 `2` 是质数，不同质数个数为 `1`。

## 样例2

**输入**

```
3 3
100
001
110
```

**输出**

```
2
```

**说明**

记录对应 `4`、`1`、`6`。
- 选择第 `1`、`2` 条：按位或得到 `5`，是质数。
- 选择第 `2`、`3` 条：按位或得到 `7`，是质数。
其余非空或值为 `4`、`1`、`6`（均非质数）以及再次得到的 `7`，不同质数为 `2`。

## 样例3

**输入**

```
2 4
1000
0000
```

**输出**

```
0
```

**说明**

记录对应 `8` 与 `0`，所有非空或值仅为 `8` 与 `0`，都不是质数，答案为 `0`。

## 样例4

**输入**

```
2 2
11
10
```

**输出**

```
2
```

**说明**

记录对应 `3` 与 `2`，二者都是质数；按位或为 `3`，不产生新质数。不同质数为 `2`。
