## 解题思路

1. **枚举非空子集**：共有 $2^n-1$ 种选择方式，用位掩码从 $1$ 枚举到 $2^n-1$。
2. **按位或合并**：把每条被选中的 `'0'`/`'1'` 字符串看作二进制整数，对所选记录做按位或，得到十进制值 $key$。
3. **质数判定**：由于 $m\le 14$，$key\le 2^{14}-1$，用试除法判断 $key$ 是否为质数。
4. **去重**：用集合保存所有合法质数，答案为集合大小。

## 复杂度分析

- **时间复杂度**：$O(2^n\cdot n\cdot m+\sqrt{2^m})$ 量级。子集枚举为主项，$n\le 20$、$m\le 14$ 时可以接受。
- **空间复杂度**：$O(2^m)$。集合中不同 $key$ 至多 $2^m$ 个。

## 代码实现

### Python

```python
def is_prime(num):
    if num < 2:
        return False
    i = 2
    while i * i <= num:
        if num % i == 0:
            return False
        i += 1
    return True

n, m = map(int, input().split())
fragments = [input().strip() for _ in range(n)]
prime_set = set()

total = 1 << n
for mask in range(1, total):
    key = 0
    for i in range(n):
        if mask & (1 << i):
            fragment_value = int(fragments[i], 2)
            key |= fragment_value
    if is_prime(key):
        prime_set.add(key)
print(len(prime_set))
```

### Java

```java
import java.util.*;
public class Main {
    public static boolean isPrime(int num) {
        if (num < 2) return false;
        for (int i = 2; i * i <= num; i++) {
            if (num % i == 0) return false;
        }
        return true;
    }
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt(), m = sc.nextInt();
        String[] fragments = new String[n];
        for (int i = 0; i < n; i++) {
            fragments[i] = sc.next();
        }
        HashSet<Integer> primeSet = new HashSet<>();
        int total = 1 << n;
        for (int mask = 1; mask < total; mask++) {
            int key = 0;
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) {
                    int fragmentValue = Integer.parseInt(fragments[i], 2);
                    key |= fragmentValue;
                }
            }
            if (isPrime(key)) {
                primeSet.add(key);
            }
        }
        System.out.println(primeSet.size());
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <set>
using namespace std;

bool isPrime(int num) {
    if (num < 2) return false;
    for (int i = 2; i * i <= num; i++) {
        if (num % i == 0) return false;
    }
    return true;
}

int main() {
    int n, m;
    cin >> n >> m;
    vector<string> fragments(n);
    for (int i = 0; i < n; i++) cin >> fragments[i];
    set<int> primes;
    int total = 1 << n;
    for (int mask = 1; mask < total; mask++) {
        int key = 0;
        for (int i = 0; i < n; i++) {
            if (mask & (1 << i)) {
                int fragmentValue = 0;
                for (char c : fragments[i]) {
                    fragmentValue = (fragmentValue << 1) | (c - '0');
                }
                key |= fragmentValue;
            }
        }
        if (isPrime(key)) primes.insert(key);
    }
    cout << primes.size() << endl;
    return 0;
}
```
