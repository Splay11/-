## 解题思路

1. **问题转化**：  
   - 每次操作要么改变一个信号的强度（加 $1$ 或减 $1$），要么从序列两端删除信号。  
   - 最终保留的序列必须是原序列的一个**非空连续子数组**，设为 $s[i..j]$（下标从 $1$ 开始）。  
   - 对于保留子数组中的每个信号 $s_k$，我们需要使其强度**不在 $[L, R]$ 范围内**。

2. **单点调整代价**：  
   对于任意信号值 $x$，将其移出区间 $[L, R]$ 的最小操作次数为：
   \[
   b(x) = \begin{cases}
   0, & x < L \text{ 或 } x > R \\
   \min(x - L + 1,\; R - x + 1), & L \le x \le R
   \end{cases}
   \]
   公式含义：若信号已在区间外则无需调整；否则将其变为 $L-1$ 或 $R+1$ 中更近的那一个。

3. **总操作数表达式**：  
   保留子数组 $[i..j]$ 的总代价包括：
   - 前端删除 $(i-1)$ 次，后端删除 $(n-j)$ 次；
   - 保留元素的强度调整代价 $\sum_{k=i}^{j} b(s_k)$。  
   \[
   \text{cost}(i,j) = (i-1) + (n-j) + \sum_{k=i}^{j} b(s_k)
   \]
   令子数组长度 $\text{len} = j-i+1$，可化简：
   \[
   \text{cost}(i,j) = n - \text{len} + \sum_{k=i}^{j} b(s_k) = n + \sum_{k=i}^{j} \big(b(s_k) - 1\big)
   \]
   定义新数组 $c_k = b(s_k) - 1$，则总代价为 $n + \sum_{k=i}^{j} c_k$。

4. **等价问题**：  
   原问题等价于在数组 $c$ 中找一个**非空连续子数组**，使其和最小。答案即为：
   \[
   \text{ans} = n + \min_{\text{非空子段}} \sum c_k
   \]
   由于 $c_k = b(s_k)-1$，而 $b(s_k) \ge 0$，故 $c_k \ge -1$，不会出现无界情况。

5. **最小子段和的求解（Kadane 变种）**：  
   令 $f_i$ 表示**以位置 $i$ 结尾**的最小子段和。状态转移：
   \[
   f_i = \min(c_i,\; f_{i-1} + c_i)
   \]
   维护全局最小值 $\text{mn} = \min(\text{mn}, f_i)$。  
   遍历结束后，答案 $= n + \text{mn}$。

6. **边界与正确性**：  
   - 序列最终必须非空，等价于子段非空，而 Kadane 求的是非空子段最小和，天然满足。  
   - 所有操作次数均为非负整数，$c_k \ge -1$ 保证了最小子段和 $\ge -n$，因此答案 $\ge 0$。

## 复杂度分析

- **时间复杂度**：每组测试数据处理时需要对序列进行一次扫描计算 $c_k$ 与 Kadane 最小子段和，复杂度为 $O(n)$。所有测试数据的 $n$ 之和不超过 $2 \times 10^5$，因此总时间 $O(\sum n)$，可以在时限内运行。
- **空间复杂度**：仅需常数级别的额外变量，空间复杂度 $O(1)$（若不存储整个序列也可做到 $O(1)$，但代码中为方便可存储整个数组，空间 $O(n)$，总和可控；若面试或特殊要求可优化为滚动变量）。

## 代码实现

### Python

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    T = int(next(it))
    out_lines = []
    for _ in range(T):
        n = int(next(it))
        L = int(next(it))
        R = int(next(it))
        s = [int(next(it)) for _ in range(n)]
        
        # Kadane 求最小非空子段和
        min_sum = None
        cur = 0
        for x in s:
            if L <= x <= R:
                # 将 x 移到区间外的最近端点
                b = min(x - L + 1, R - x + 1)
            else:
                b = 0
            c = b - 1
            # cur 表示以当前元素结尾的最小子段和
            if cur + c < c:
                cur = cur + c
            else:
                cur = c
            if min_sum is None or cur < min_sum:
                min_sum = cur
        ans = n + min_sum
        out_lines.append(str(ans))
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        String line;
        while ((line = br.readLine()) != null) {
            sb.append(line).append(' ');
        }
        StringTokenizer st = new StringTokenizer(sb.toString());
        int T = Integer.parseInt(st.nextToken());
        StringBuilder out = new StringBuilder();
        
        while (T-- > 0) {
            int n = Integer.parseInt(st.nextToken());
            int L = Integer.parseInt(st.nextToken());
            int R = Integer.parseInt(st.nextToken());
            int[] s = new int[n];
            for (int i = 0; i < n; i++) {
                s[i] = Integer.parseInt(st.nextToken());
            }
            
            long minSum = Long.MAX_VALUE;
            long cur = 0;
            for (int x : s) {
                int b;
                if (L <= x && x <= R) {
                    int toLow = x - L + 1;
                    int toHigh = R - x + 1;
                    b = Math.min(toLow, toHigh);
                } else {
                    b = 0;
                }
                long c = b - 1;
                cur = Math.min(c, cur + c);
                if (cur < minSum) {
                    minSum = cur;
                }
            }
            long ans = n + minSum;
            out.append(ans).append('\n');
        }
        System.out.print(out);
    }
}
```
