# 题目内容
在一次通信实验中，你获得了一个长度为 $n$ 的信号序列 $s_1, s_2, \dots, s_n$，每个信号的强度均为正整数。

已知所有强度位于区间 $[L, R]$ 内的信号会互相干扰，导致实验失败。你希望通过若干次操作，使得最终序列**不包含任何强度落在 $[L, R]$ 内的信号**，并且序列必须保持非空。

每次操作你只可以从以下四种行为中选择一种：
- 选择当前序列中的任意一个信号，将其强度减少 $1$；
- 选择当前序列中的任意一个信号，将其强度增加 $1$；
- 移除序列最前端的信号；
- 移除序列最末端的信号。

请你计算并输出达成目标所需的**最少操作次数**。

**约束条件：**

- 测试数据组数 $T$ 不超过 $10^4$。
- 单个序列长度 $n$ 不超过 $2 \times 10^5$，且所有测试数据的 $n$ 之和不超过 $2 \times 10^5$。
- $L$ 和 $R$ 满足 $1 \le L \le R \le n$。
- 每个信号强度 $s_i$ 均为 $1$ 到 $n$ 之间的整数。

# 输入描述
第一行包含一个整数 $T$，表示测试数据组数。

接下来依次给出每组测试数据：

第一行包含三个整数 $n, L, R$，分别表示信号序列的长度、需要排除的强度区间的下界与上界。

第二行包含 $n$ 个整数 $s_1, s_2, \dots, s_n$，表示初始的信号强度序列。

# 输出描述
对于每组测试数据，输出一行一个整数，表示所需的最少操作次数。

## 样例1

**输入**

```
1
4 2 3
2 1 3 4
```

**输出**

```
2
```

**说明**

序列长度为 `4`，需排除区间 $[2,3]$。信号强度分别为 `[2,1,3,4]`。

- 强度 `2` 在区间内，改成区间外的最小代价为 $\min(2-2+1, 3-2+1)=1$；
- `1` 已在区间外，无需修改；
- `3` 在区间内，改成区间外的最小代价为 $\min(3-2+1, 3-3+1)=1$；
- `4` 在区间外，无需修改。

保留整个序列，修改 `2` 和 `3` 各 `1` 次，总操作次数 `2`。其他方案如只保留 `[1]` 或 `[4]` 需要删除 `3` 个元素，代价 `3`；只保留 `[1,3]` 不连续。故最少操作数为 `2`。

## 样例2

**输入**

```
1
3 3 3
1 1 1
```

**输出**

```
0
```

**说明**

序列长度为 `3`，须排除区间 $[3,3]$，即强度为 `3` 的信号。当前序列为 `[1,1,1]`，所有元素均小于 `3`，不在区间内。无需任何修改或删除即可满足要求，因此最少操作数为 `0`。

## 样例3

**输入**

```
1
5 2 5
3 1 1 1 1
```

**输出**

```
1
```

**说明**

序列长度为 `5`，需排除区间 $[2,5]$。信号为 `[3,1,1,1,1]`。

- 强度 `3` 在区间内，修改到最近区间外需改为 `1` 或 `6`，代价 $\min(3-2+1, 5-3+1)=2$；
- 其余 `1` 均小于 `2`，已在区间外，代价为 `0`。

如果保留全部序列，需修改 `3`，操作 `2` 次。但如果删除第一个元素 `3`，保留子序列 `[1,1,1,1]`，仅需 `1` 次删除，无需修改。这对应保留连续子数组 $[2,5]$，代价为删除 `1` 次，总操作数 `1`。其他方案均不更优，故答案为 `1`。

## 样例4

**输入**

```
1
2 1 1
1 2
```

**输出**

```
1
```

**说明**

序列长度 `2`，需排除区间 $[1,1]$。信号 `[1,2]`：`1` 在区间内，修改代价为 $\min(1-1+1, 1-1+1)=1$；`2` 在区间外。可保留全部并修改 `1`，代价 `1`；或删除 `1` 保留 `[2]`，代价 `1`。最少操作为 `1`。
