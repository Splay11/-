# 题目内容
有 $n$ 项工程，第 $i$ 项的工期是闭区间 $[l_i, r_i]$。现有 $m$ 次查询，每次给出一个时间窗口 $[l, r]$。

对于每次查询，统计工期完全落在该窗口内的工程数量，即同时满足 $l \le l_i$ 且 $r_i \le r$ 的工程个数。

工程数与查询次数均不超过 $5 \times 10^5$，时间坐标不超过 $10^9$。

# 输入描述
第一行两个整数 $n$ 和 $m$，分别表示工程数量和查询次数。
接下来 $n$ 行，每行两个整数 $l_i$ 和 $r_i$，表示第 $i$ 项工程的工期。
随后 $m$ 行，每行两个整数 $l$ 和 $r$，表示一次查询的时间窗口。
保证 $1 \le n, m \le 5 \times 10^5$，$1 \le l_i \le r_i \le 10^9$，$1 \le l \le r \le 10^9$。

# 输出描述
输出 $m$ 行，每行一个整数，表示对应查询的答案。

## 样例1

**输入**

```
1 2
5 5
5 5
6 7
```

**输出**

```
1
0
```

**说明**

仅一项工期 $[5,5]$。窗口 $[5,5]$ 恰好包含它，答案 `1`；窗口 $[6,7]$ 不包含，答案 `0`。
