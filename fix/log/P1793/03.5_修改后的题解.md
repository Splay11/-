## 解题思路

本题要求在 $N$ 枚徽章中挑选恰好 $K$ 枚，使得展示盒中不同的款式编号种类数尽量多。  
问题的本质是：给定 $N$ 个数（款式编号），从中选择 $K$ 个，最多能选中多少个不同的数值。

解题步骤：

1. 统计所有徽章中不同款式编号的个数。可以用哈希集合（如 `set` / `HashSet` / `unordered_set`）将所有输入的款式编号去重。
2. 设去重后的款式种类总数为 $distinct\_cnt$。
3. 因为最多只能挑选 $K$ 枚徽章，所以展示盒里的款式种类数不可能超过 $K$。  
   若 $distinct\_cnt \ge K$，则最优选择下可以凑出 $K$ 种不同的款式；  
   若 $distinct\_cnt < K$，则即使拿走所有不同款式的徽章，也达不到 $K$ 种，答案即为 $distinct\_cnt$。
4. 综上，答案为 $\min(distinct\_cnt, K)$。

## 复杂度分析

- **时间复杂度**：$O(N)$。只需遍历所有 $N$ 个款式编号一次，每次向哈希集合插入的操作平均为 $O(1)$。
- **空间复杂度**：$O(N)$。最坏情况下所有徽章款式都不同，哈希集合需要存储 $N$ 个元素。

## 代码实现

### Python

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    k = int(next(it))
    
    # 使用集合统计不同的款式编号
    types = set()
    for _ in range(n):
        types.add(int(next(it)))
    
    ans = min(k, len(types))
    print(ans)

if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();   // 徽章总数
        int k = sc.nextInt();   // 需要挑选的数量
        
        Set<Integer> types = new HashSet<>();
        for (int i = 0; i < n; i++) {
            types.add(sc.nextInt());
        }
        
        // 答案 = min(K, 不同款式总数)
        System.out.println(Math.min(k, types.size()));
        sc.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <unordered_set>
#include <algorithm>

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);
    
    int n, k;
    std::cin >> n >> k;
    
    std::unordered_set<int> types;
    for (int i = 0; i < n; ++i) {
        int x;
        std::cin >> x;
        types.insert(x);
    }
    
    // 最多能展示的不同款式数
    std::cout << std::min(k, (int)types.size()) << std::endl;
    return 0;
}
```
