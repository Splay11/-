# 题目内容
小蓝最近迷上了收集徽章。她手上一共有 $N$ 枚徽章，每一枚徽章都属于某一种款式，款式用一个整数编号表示。

现在小蓝打算挑选出恰好 $K$ 枚徽章，放进展示盒里。她希望展示盒中的徽章款式尽可能多样，也就是说，**这 $K$ 枚徽章中不同的款式编号越多越好**。

请你帮她计算，在最优的选择下，展示盒里最多能够出现多少种不同的款式编号。

**约束条件**
- 徽章总数 $N$ 满足 $1 \le K \le N \le 10^5$。
- 每枚徽章的款式编号 $a_i$ 满足 $1 \le a_i \le 10^9$。

# 输入描述
第一行包含两个正整数 $N$ 和 $K$（$1 \le K \le N \le 10^5$），分别表示徽章的总数和小蓝需要挑选的徽章数量，两者之间用一个空格隔开。
第二行包含 $N$ 个正整数 $a_1, a_2, \dots, a_N$（$1 \le a_i \le 10^9$），表示每枚徽章的款式编号，相邻整数之间用一个空格隔开。

# 输出描述
输出一行一个整数，表示在挑选的 $K$ 枚徽章中，最多能包含的不同款式编号的种类数。

## 样例1

**输入**

```
5 3
10 20 30 10 20
```

**输出**

```
3
```

**说明**

徽章序列为 `10 20 30 10 20`，去重后得到的款式编号有 `10`、`20`、`30`，共 $3$ 种。需要挑选 $K = 3$ 枚徽章，因此可以刚好把 $3$ 种款式全部收入展示盒，最多款式数为 $\min(3, 3) = 3$。

## 样例2

**输入**

```
5 4
1 1 1 2 3
```

**输出**

```
3
```

**说明**

徽章序列为 `1 1 1 2 3`，去重后款式编号分别为 `1`、`2`、`3`，共 $3$ 种。虽然需要挑选 $K = 4$ 枚徽章，但总体只有 $3$ 种不同款式，即使将 `1` 全部选上也最多涵盖 $3$ 种款式，答案为 $\min(4, 3) = 3$。

## 样例3

**输入**

```
1 1
100
```

**输出**

```
1
```

**说明**

只有 $N = 1$ 枚徽章，款式编号为 `100`。需要挑选 $K = 1$ 枚，能够获得的不同款式数即为 $1$ 种。这是 $N = K = 1$ 的边界情况。
