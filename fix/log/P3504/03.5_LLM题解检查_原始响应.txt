## 解题思路

### 等价转化

设 $s$ 是长度为 $3k$ 的十进制字符串，将其均分为三个子串 $s_1, s_2, s_3$，每个长度为 $k$。

题目要求 $s_1 s_2$ 和 $s_2 s_3$ 都是镜像串（即回文串）。由回文的性质可知：

- $s_1 s_2$ 是回文串 $\iff$ $s_1 = \text{reverse}(s_2)$
- $s_2 s_3$ 是回文串 $\iff$ $s_2 = \text{reverse}(s_3)$

联立两式可得：

$$s_1 = s_3, \quad s_2 = \text{reverse}(s_1)$$

因此，任何满足条件的双镜数必然具有如下结构：

$$s = A + \text{reverse}(A) + A$$

其中 $A$ 是一个长度为 $k$ 的十进制字符串，且 $A$ 的首字符不能为 `'0'`（保证整体无前导零）。反之，具有该结构的数显然也满足题目要求。至此，问题转化为：统计所有可能的 $k \ge 1$ 以及对应的 $A$（首位非零），使得对应的整数值落在区间 $[l, r]$ 内。

### 计数方法

定义函数 $f(x)$ 表示 $\le x$ 的双镜数个数，则答案可以表示为 $f(r) - f(l - 1)$。

对于给定的 $x$，按 $k$ 的大小分类统计：

- 数字长度 $= 3k$，由于 $x \le 10^{18}$，最多只需考虑 $k = 1, 2, \dots, 6$。

对每一个 $k$：

1. **若 $3k < \text{len}(x)$**：此时所有长度为 $3k$ 的双镜数都必然 $\le x$。  
   $A$ 的首位可取 $1\sim 9$，其余 $k-1$ 位可取 $0\sim 9$，因此数量为 $9 \times 10^{k-1}$。

2. **若 $3k = \text{len}(x)$**：只需要统计那些 $\le x$ 的长度为 $3k$ 的双镜数。  
   注意到，由 $A$ 构造出的数值 $\text{make\_num}(A) = A \cdot 10^{2k} + \text{reverse}(A) \cdot 10^{k} + A$ 是关于 $A$ 单调递增的。  
   因此可以在区间 $A \in [10^{k-1}, 10^{k} - 1]$ 上二分，找到最大的 $A^*$ 使得 $\text{make\_num}(A^*) \le x$，则这一长度贡献的数量为 $\max(0, A^* - 10^{k-1} + 1)$。

所有 $k$ 的贡献累加即得 $f(x)$。

### 数值构造细节

- 预处理 $10^0 \sim 10^{18}$ 的幂，用于快速拼接。
- $\text{reverse}(A)$ 可以通过循环提取 $A$ 的十进制最低位来生成；由于 $A$ 可能含有末尾的 $0$，反转后中间部分允许出现前导零，这不影响双镜数的定义（只要求字符串反转相同）。

### 算法流程

对于每一组询问 $(l, r)$：

1. 计算 $f(r)$ 和 $f(l-1)$；
2. 输出 $f(r) - f(l-1)$。

## 复杂度分析

- 对于每个询问，枚举 $k \in [1, 6]$，二分查找时循环约 $\log_{10} 10^{k} \le 20$ 次，常数极小。
- 预处理 $10$ 的幂只需要 $O(1)$ 时间。
- 整体时间复杂度为 $O(T)$，其中 $T \le 10^4$，可以轻松通过。
- 空间复杂度：仅需存储 $10$ 的幂和少量临时变量，为 $O(1)$。

## 代码实现

### Python

```python
import sys

# 预计算 10 的幂
POW10 = [1]
for _ in range(19):
    POW10.append(POW10[-1] * 10)

def rev_int(x, k):
    """将 k 位整数 x 按十进制反转，返回整数"""
    r = 0
    for _ in range(k):
        r = r * 10 + x % 10
        x //= 10
    return r

def make_num(a, k):
    """由 A 和 k 构造 A + rev(A) + A 的数值"""
    return a * POW10[2 * k] + rev_int(a, k) * POW10[k] + a

def count_leq(x):
    """统计 <= x 的双镜数个数"""
    if x < 0:
        return 0
    s = str(x)
    n = len(s)
    ans = 0
    for k in range(1, 7):          # 3k <= 18
        if 3 * k < n:
            # 长度更短，全部计入
            ans += 9 * POW10[k - 1]
        elif 3 * k == n:
            # 等长，二分计数
            lo = POW10[k - 1]
            hi = POW10[k] - 1
            L, R, best = lo, hi, lo - 1
            while L <= R:
                mid = (L + R) // 2
                val = make_num(mid, k)
                if val <= x:
                    best = mid
                    L = mid + 1
                else:
                    R = mid - 1
            if best >= lo:
                ans += best - lo + 1
    return ans

def main():
    data = sys.stdin.read().strip().split()
    it = iter(data)
    T = int(next(it))
    out_lines = []
    for _ in range(T):
        l = int(next(it))
        r = int(next(it))
        out_lines.append(str(count_leq(r) - count_leq(l - 1)))
    print("\n".join(out_lines))

if __name__ == "__main__":
    main()
```

```java
import java.io.*;
import java.util.*;

public class Main {
    static long[] pow10 = new long[20];
    static {
        pow10[0] = 1L;
        for (int i = 1; i < 20; i++) {
            pow10[i] = pow10[i - 1] * 10L;
        }
    }

    // 将 k 位整数 a 按十进制反转
    static long revInt(long a, int k) {
        long r = 0;
        for (int i = 0; i < k; i++) {
            r = r * 10 + a % 10;
            a /= 10;
        }
        return r;
    }

    // 构造 A + rev(A) + A
    static long makeNum(long a, int k) {
        return a * pow10[2 * k] + revInt(a, k) * pow10[k] + a;
    }

    // 统计 <= x 的双镜数个数
    static long countLeq(long x) {
        if (x < 0) return 0;
        int n = Long.toString(x).length();
        long ans = 0;
        for (int k = 1; k <= 6; k++) {
            if (3 * k < n) {
                ans += 9L * pow10[k - 1];
            } else if (3 * k == n) {
                long lo = pow10[k - 1];
                long hi = pow10[k] - 1;
                long L = lo, R = hi, best = lo - 1;
                while (L <= R) {
                    long mid = (L + R) >>> 1;
                    long v = makeNum(mid, k);
                    if (v <= x) {
                        best = mid;
                        L = mid + 1;
                    } else {
                        R = mid - 1;
                    }
                }
                if (best >= lo) {
                    ans += best - lo + 1;
                }
            }
        }
        return ans;
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine().trim());
        StringBuilder sb = new StringBuilder();
        for (int t = 0; t < T; t++) {
            String[] parts = br.readLine().trim().split("\\s+");
            long l = Long.parseLong(parts[0]);
            long r = Long.parseLong(parts[1]);
            sb.append(countLeq(r) - countLeq(l - 1)).append('\n');
        }
        System.out.print(sb.toString());
    }
}
```
