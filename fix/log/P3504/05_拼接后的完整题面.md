# 题目内容
给定一个正整数的十进制表示（不含前导零），将其视作字符串 $s$。若 $|s|$ 是 $3$ 的倍数，且将 $s$ 等分为三个长度相等的子串 $s_1, s_2, s_3$（即 $s = s_1 s_2 s_3$），使得 $s_1 s_2$ 与 $s_2 s_3$ 均为镜像串，则称该数为双镜数。

这里，一个字符串被称为镜像串，当且仅当它从左往右读和从右往左读的结果完全相同。

现在给出 $T$ 个询问，每个询问给定一段区间 $[l, r]$，请计算该区间内有多少个双镜数。

数据范围：$T$ 不超过 $10^4$，所有 $l, r$ 满足 $1 \le l \le r \le 10^{18}$。

# 输入描述
第一行包含一个整数 $T$（$1 \le T \le 10^4$），表示询问的组数。
接下来 $T$ 行，每行包含两个整数 $l$ 和 $r$（$1 \le l \le r \le 10^{18}$），表示一次询问的区间。

# 输出描述
对于每一组询问，输出一行一个整数，表示区间 $[l, r]$ 内双镜数的个数。

## 样例1

**输入**

```
2
1 200
1000 100000
```

**输出**

```
1
0
```

**说明**

对于区间 $[1, 200]$，满足条件的双镜数只有 $s = 111$（即 $A = 1$，$k = 1$ 时构造出的 $111$），共 $1$ 个。

对于区间 $[1000, 100000]$，没有双镜数。长度为 $3$（$k = 1$）的双镜数从 `111` 到 `999` 均小于 $1000$；而 $k = 2$ 的最小双镜数为 $A = 10$ 对应的 `100110`，已经大于 $100000$，因此个数为 $0$。

## 样例2

**输入**

```
2
1 100000000
1 1000000000
```

**输出**

```
99
999
```

**说明**

区间 $[1, 10^8]$：包含所有 $k = 1$ 和 $k = 2$ 的双镜数。$k = 1$ 有 $9$ 个（`111` 到 `999`），$k = 2$ 有 $90$ 个（$A$ 从 $10$ 到 $99$），共 $9 + 90 = 99$ 个。$k = 3$ 的最小白镜数 `100001100` 已经大于 $10^8$，故不计入。

区间 $[1, 10^9]$：除上述 $99$ 个外，$k = 3$ 的 $900$ 个双镜数（$A$ 从 $100$ 到 $999$）全部小于 $10^9$，因此总数为 $99 + 900 = 999$ 个。

## 样例3

**输入**

```
1
111 111
```

**输出**

```
1
```

**说明**

区间仅包含数字 $111$。该数字长度 $3$，可等分为 $s_1 = \texttt{1}$，$s_2 = \texttt{1}$，$s_3 = \texttt{1}$。$s_1s_2 = \texttt{11}$ 与 $s_2s_3 = \texttt{11}$ 均为镜像串，因此 `111` 是一个双镜数。故答案为 $1$。
