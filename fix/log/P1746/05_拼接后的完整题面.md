# 题目内容
一家画廊正在布置一条长廊，长廊一侧有 $n$ 块连续的展板。策展人为每块展板准备了两种不同风格的画作，分别称为类型 $A$ 和类型 $B$。出于视觉流畅的考虑，相邻的展板上不能悬挂同一种类型的画作。

对于第 $i$ 块展板，若选择类型 $A$ 可带来 $a_i$ 点吸引力，若选择类型 $B$ 可带来 $b_i$ 点吸引力。请你帮助策展人决定每块展板的画作类型，使得所有展板在满足相邻不同类型的前提下，获得的总吸引力最大。

展板的数量 $n$ 不超过 $10^5$，每个吸引力值均为正且不超过 $10^9$。

# 输入描述
第一行包含一个整数 $n$，表示展板的数量。
接下来 $n$ 行，每行包含两个整数 $a_i$ 和 $b_i$，分别表示第 $i$ 块展板选择类型 $A$ 和类型 $B$ 时获得的吸引力。

# 输出描述
输出一个整数，表示能获得的最大总吸引力。

## 样例1

**输入**

```
1
5 3
```

**输出**

```
5
```

**说明**

只有 `1` 块展板，不存在相邻约束，直接选取吸引力较大的类型即可。

第 `1` 块展板选 $A$ 得吸引力 `5`，选 $B$ 得吸引力 `3`，最大值为 $\max(5, 3) = 5$。

## 样例2

**输入**

```
3
10 20
30 10
40 50
```

**输出**

```
100
```

**说明**

展板数量 $n = 3$，满足相邻不同类型的方案只有两种交替方式：
- 方案一：$A,B,A$，总吸引力 $a_1 + b_2 + a_3 = 10 + 10 + 40 = 60$；
- 方案二：$B,A,B$，总吸引力 $b_1 + a_2 + b_3 = 20 + 30 + 50 = 100$。

比较可知最大总吸引力为 `100`。

## 样例3

**输入**

```
4
1 2
3 4
5 6
7 8
```

**输出**

```
18
```

**说明**

当 $n = 4$ 时，同样只有两种交替方案：
- 方案一：$A,B,A,B$，总吸引力 $a_1 + b_2 + a_3 + b_4 = 1 + 4 + 5 + 8 = 18$；
- 方案二：$B,A,B,A$，总吸引力 $b_1 + a_2 + b_3 + a_4 = 2 + 3 + 6 + 7 = 18$。

两种方案吸引力相等，最大总吸引力为 `18`。
