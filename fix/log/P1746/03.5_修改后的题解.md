## 解题思路

本题要求从两种类型的画作中选择一种放在每块展板上，且相邻展板类型不能相同，目标是最大化总吸引力。这是一个典型的动态规划问题，核心在于**状态定义**和**相邻约束的处理**。

- **状态定义**：  
  设 `dp[i][0]` 表示考虑前 `i+1` 块展板，且第 `i` 块展板选择类型 `A` 时能获得的最大总吸引力；  
  `dp[i][1]` 表示第 `i` 块展板选择类型 `B` 时能获得的最大总吸引力。

- **状态转移**：  
  由于相邻展板类型不能相同，若第 `i` 块选 `A`，则第 `i-1` 块只能选 `B`，反之亦然。因此：
  ```
  dp[i][0] = dp[i-1][1] + a_i
  dp[i][1] = dp[i-1][0] + b_i
  ```
  其中 `a_i` 和 `b_i` 分别为第 `i` 块展板选 `A` 和 `B` 的吸引力。

- **边界条件**：  
  当 `i = 0` 时，前面没有展板，可以直接选择任意类型：
  ```
  dp[0][0] = a_0
  dp[0][1] = b_0
  ```

- **最终答案**：  
  最后一块展板可以选 `A` 或 `B`，答案为 `max(dp[n-1][0], dp[n-1][1])`。

由于每个状态只依赖前一个位置的状态，可以用滚动变量将空间优化到常数级，但为代码清晰，本题解仍使用长度为 `n` 的 dp 数组，空间复杂度也为 `O(n)`，对于 `n ≤ 10^5` 完全可行。

## 复杂度分析

- 时间复杂度：$O(n)$  
  只需要遍历所有展板一次，每次进行常数次比较和加法运算。

- 空间复杂度：$O(n)$ 或 $O(1)$  
  若存储整个 dp 数组，空间复杂度为 $O(n)$；若使用滚动变量优化，可降至 $O(1)$。以下代码为便于理解，采用 $O(n)$ 空间写法，读者可自行优化。

## 代码实现

### Python

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    a = [0] * n
    b = [0] * n
    for i in range(n):
        a[i] = int(next(it))
        b[i] = int(next(it))
    
    # dp[i][0]: 第i块选A的最大总值，dp[i][1]: 选B的最大总值
    dp0 = a[0]
    dp1 = b[0]
    for i in range(1, n):
        new_dp0 = dp1 + a[i]   # 当前选A，前一块只能选B
        new_dp1 = dp0 + b[i]   # 当前选B，前一块只能选A
        dp0, dp1 = new_dp0, new_dp1
    
    ans = max(dp0, dp1)
    print(ans)

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long[] a = new long[n];
        long[] b = new long[n];
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextLong();
            b[i] = sc.nextLong();
        }
        // dpA: 当前展板选A的最大值，dpB: 选B的最大值
        long dpA = a[0];
        long dpB = b[0];
        for (int i = 1; i < n; i++) {
            long newDpA = dpB + a[i];   // 前一块只能选B
            long newDpB = dpA + b[i];   // 前一块只能选A
            dpA = newDpA;
            dpB = newDpB;
        }
        long ans = Math.max(dpA, dpB);
        System.out.println(ans);
    }
}
```

    long long dp0 = a[0];
    long long dp1 = b[0];

        long long new_dp1 = dp0 + b[i];   // 前一块只能选A
        dp0 = new_dp0;
        dp1 = new_dp1;
    }
    long long ans = max(dp0, dp1);
    cout << ans << "\n";

}
