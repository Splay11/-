## 解题思路

本题要求构造一个长度为 $n$ 的排列（每个整数 $1$ 到 $n$ 恰好出现一次），使得排列的“错位”总数恰好等于给定的 $k$。这里“错位”的定义即为通常的逆序对：若 $i < j$ 且 $a_i > a_j$，则 $(i, j)$ 是一对错位。

我们可以使用贪心策略，从 $1$ 到 $n$ 依次确定每个位置的数字。用两个指针 $L = 1$ 和 $R = n$ 维护当前还未使用的数字区间 $[L, R]$：

1. **选择最大值 $R$**：如果我们将当前剩余数字中的最大值 $R$ 放在序列的下一个位置，由于后面将要放置的 $R - L$ 个数字都比 $R$ 小，它们会和 $R$ 形成 $R - L$ 个错位。
2. **选择最小值 $L$**：如果我们把最小值 $L$ 放在下一个位置，则它和后面所有剩余数字都不会形成错位（因为后面的数字都大于 $L$）。

根据这一性质，贪心地决定每一步的选择：
- 如果当前还需要构造的错位数量 $k \ge R - L$，我们就放置最大值 $R$，这样一次性“购买” $R - L$ 个错位，并将 $k$ 减去 $R - L$，同时 $R$ 减 $1$。
- 否则，说明剩余的 $k$ 已经小于本轮能获得的最大错位数，此时放置最小值 $L$，本轮不产生新的错位，$L$ 加 $1$。

重复这个过程 $n$ 次后，得到的排列恰好包含 $k$ 个错位。该贪心的正确性在于：在任一时刻，本轮“购买” $R - L$ 个错位是可能的最大收益，如果 $k$ 不小于它，立即购买一定不会劣于延后购买；如果 $k$ 小于它，保留 $R$ 也无法在本轮产生足够错位，应当通过后续多步累积达到目标。

## 复杂度分析

- 时间复杂度：$O(n)$，只需从左到右扫描 $n$ 次，每次 $O(1)$ 决策并构造结果。
- 空间复杂度：$O(n)$，需要存储构造出来的排列，也可以直接输出而仅用 $O(1)$ 额外空间，但一般实现使用数组辅助存储。

## 代码实现

### Python

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    n = int(data[0])
    k = int(data[1])

    L = 1           # 当前剩余的最小数字
    R = n           # 当前剩余的最大数字
    ans = []

    for _ in range(n):
        # 如果放 R 可以产生的错位数 (R - L) 不超过剩余的 k，则放 R
        if k >= (R - L):
            ans.append(R)
            k -= (R - L)   # 用掉这些错位
            R -= 1
        else:
            ans.append(L)   # 放 L 不产生新的错位
            L += 1

    print(' '.join(map(str, ans)))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String[] parts = br.readLine().trim().split("\\s+");
        int n = Integer.parseInt(parts[0]);
        long k = Long.parseLong(parts[1]);  // k 可能较大，使用 long

        List<Integer> ans = new ArrayList<>(n);
        int L = 1;      // 当前剩余的最小数字
        int R = n;      // 当前剩余的最大数字

        for (int i = 0; i < n; i++) {
            // 若放 R 能产生的错位数 (R - L) <= 剩余需要的 k
            if (k >= (long)(R - L)) {
                ans.add(R);
                k -= (R - L);
                R--;
            } else {
                ans.add(L);
                L++;
            }
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < ans.size(); i++) {
            if (i > 0) sb.append(' ');
            sb.append(ans.get(i));
        }
        System.out.println(sb.toString());
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n, k;
    if (!(cin >> n >> k)) return 0;

    vector<long long> ans;
    ans.reserve(n);

    long long L = 1, R = n;       // 当前剩余的最小和最大数字
    for (long long i = 0; i < n; ++i) {
        // 如果把 R 放在当前位置，可以产生 (R - L) 个错位
        if (k >= (R - L)) {
            ans.push_back(R);
            k -= (R - L);         // 购买这些错位
            --R;
        } else {
            ans.push_back(L);     // 放最小值，不产生错位
            ++L;
        }
    }

    for (size_t i = 0; i < ans.size(); ++i) {
        if (i) cout << ' ';
        cout << ans[i];
    }
    cout << '\n';
    return 0;
}
```
