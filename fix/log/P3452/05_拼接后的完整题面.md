# 题目内容
小明在整理一套编号为 `1` 到 `n` 的卡片。他将卡片排成一排，发现如果较大的编号排在了较小编号的前面，就会形成一个“错位”。具体来说，对于一个序列 $a_1, a_2, \dots, a_n$（每个整数 `1` 到 `n` 恰好出现一次），如果存在 $1 \le i < j \le n$ 满足 $a_i > a_j$，则称 $(i, j)$ 为一对错位。序列的错位总数就是所有错位的对数。

现在小明想要重新排列这些卡片，使得最终的错位总数恰好为 $k$。请你帮他找到一种满足条件的排列方式。

整数 $n$ 满足 $1 \le n \le 1000$，整数 $k$ 满足 $0 \le k \le \frac{n(n-1)}{2}$。

# 输入描述
输入包含一行两个正整数 $n$ 和 $k$，用一个空格分隔。

# 输出描述
输出一行由 $n$ 个空格隔开的整数，表示你构造的卡片序列。如果存在多个合法排列，输出任意一个即可。

## 样例1

**输入**

```
1 0
```

**输出**

```
1
```

**说明**

当 $n=1$ 时，只有一张卡片，排列只能是 `[1]`，其逆序对数为 $0$，恰好满足 $k=0$。

## 样例2

**输入**

```
3 2
```

**输出**

```
3 1 2
```

**说明**

初始可用区间 $[L,R]=[1,3]$，目标 $k=2$。
第一步：$R-L=2$，由于 $k\ge2$，放入最大值 $R=3$，$k$ 减少 $2$ 变为 $0$，更新 $R=2$。
第二步：$R-L=1$，此时 $k=0<1$，放入最小值 $L=1$，更新 $L=2$。
第三步：只剩 $2$，直接放入。得到排列 `3 1 2`，逆序对为 $(3,1)$ 和 $(3,2)$，共 $2$ 对，符合要求。

## 样例3

**输入**

```
4 5
```

**输出**

```
4 3 1 2
```

**说明**

初始 $[L,R]=[1,4]$，目标 $k=5$。
第一步：$R-L=3$，$k=5\ge3$，放入 $4$，$k$ 变为 $2$，$R$ 变为 $3$。
第二步：$R-L=2$，$k=2\ge2$，放入 $3$，$k$ 变为 $0$，$R$ 变为 $2$。
第三步：$R-L=1$，$k=0<1$，放入 $1$，$L$ 变为 $2$。
第四步：放入 $2$。最终排列 `4 3 1 2`，逆序对包括 $4$ 与 $3,1,2$（$3$ 对）以及 $3$ 与 $1,2$（$2$ 对），共 $5$ 对。

## 样例4

**输入**

```
5 10
```

**输出**

```
5 4 3 2 1
```

**说明**

最大逆序对数 $k=\frac{5\times4}{2}=10$。贪心每一步都满足 $k\ge R-L$，因此始终选取当前最大值，依次放入 $5,4,3,2,1$，构成完全逆序排列。该排列中每个较大的数都排在所有较小数的前面，逆序对总数恰为 $10$。
