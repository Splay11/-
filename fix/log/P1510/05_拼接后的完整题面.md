# 题目内容
在一个数字序列中，每个数字的“封闭区域数”定义为：在十进制表示下，数码 `0`、`6`、`9` 各含有 $1$ 个封闭区域，数码 `8` 含有 $2$ 个封闭区域，其他数码不含封闭区域。一个整数的封闭区域数等于其各位数码封闭区域数之和。

现在你可以选择至多一段连续的数字，并将该段内的每个数字都增加 $1$（也可以不选任何段）。你需要求出操作后整个序列的封闭区域数总和的最大可能值。

序列长度 $n$ 满足 $1 \le n \le 10^5$，序列中的每个整数 $a_i$ 满足 $0 \le a_i \le 10^9$。

# 输入描述
第一行包含一个整数 $n$ $(1 \le n \le 10^5)$，表示序列长度。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$ $(0 \le a_i \le 10^9)$，表示序列中的数字。

# 输出描述
输出一个整数，表示操作后序列封闭区域数总和的最大可能值。

## 样例1

**输入**

```
5
0 6 8 9 10
```

**输出**

```
6
```

**说明**

初始序列的封闭区域数分别为 `0` 的 $1$、`6` 的 $1$、`8` 的 $2$、`9` 的 $1$、`10` 的 $1$（`1` 贡献 $0$，`0` 贡献 $1$），总和为 $1+1+2+1+1=6$。
每个数字加 $1$ 后的变化量：`0`$\to$`1` 减少 $1$，`6`$\to$`7` 减少 $1$，`8`$\to$`9` 减少 $1$，`9`$\to$`10` 不变，`10`$\to$`11` 减少 $1$，所有变化量均非正。因此不选择任何区间，最大总和为 $6$。

## 样例2

**输入**

```
6
5 7 6 8 9 4
```

**输出**

```
7
```

**说明**

初始封闭区域数：`5`($0$), `7`($0$), `6`($1$), `8`($2$), `9`($1$), `4`($0$)，总和 $4$。
加 $1$ 后的变化量：`5`$\to$`6` 增加 $1$，`7`$\to$`8` 增加 $2$，`6`$\to$`7` 减少 $1$，`8`$\to$`9` 减少 $1$，`9`$\to$`10` 不变，`4`$\to$`5$ 不变。
变化量序列为 $[1, 2, -1, -1, 0, 0]$，最大子段和为选择前两个数字 $1+2=3$。因此最大总和为 $4+3=7$。

## 样例3

**输入**

```
1
8
```

**输出**

```
2
```

**说明**

只有一个数字 `8`，其封闭区域数为 $2$。加 $1$ 变成 `9` 后封闭区域数为 $1$，变化量为 $-1$，所以不操作更优，答案为 $2$。

## 样例4

**输入**

```
3
18 80 99
```

**输出**

```
7
```

**说明**

初始封闭区域数：`18`（`1` 贡献 $0$，`8` 贡献 $2$）为 $2$；`80`（`8` 贡献 $2$，`0` 贡献 $1$）为 $3$；`99`（两个 `9` 各贡献 $1$）为 $2$，总和 $7$。
加 $1$ 后：`18`$\to$`19` 减少 $1$，`80`$\to$`81` 减少 $1$，`99`$\to$`100`（`1` 贡献 $0$，两个 `0` 各贡献 $1$）封闭区域数为 $2$，变化量为 $0$。所有变化量非正，最大总和仍为 $7$。
