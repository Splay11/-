# 题目内容
小明在超市购买了 $n$ 件商品，每件商品有一个价格和一个类别标记。类别标记为 $1$ 表示该商品参与优惠活动，类别标记为 $0$ 表示不参与。

优惠规则为：所有参与活动的商品的原始总价，每满 $250$ 元即可减免 $40$ 元，减免金额向下取整。不参与活动的商品按原价计算。你需要计算小明最终需要支付的总金额。

约束条件：
- 商品数量 $n$ 不超过 $10^5$。
- 每件商品的价格 $p$ 满足 $1 \le p \le 10^4$。
- 类别标记 $q$ 的取值为 $0$ 或 $1$。

# 输入描述
第一行包含一个整数 $n$，表示商品数量。
接下来 $n$ 行，每行包含两个整数 $p$ 和 $q$，分别表示商品的价格和类别标记（$q = 1$ 表示参与活动，$q = 0$ 表示不参与）。

# 输出描述
输出一个整数，表示实际支付的总金额。

## 样例1

**输入**

```
3
100 0
200 0
300 0
```

**输出**

```
600
```

**说明**

所有商品均不参与活动，类别标记均为 `0`。总价为 $100+200+300=600$ 元。由于没有参与活动的商品，无任何减免，最终支付 `600` 元。

## 样例2

**输入**

```
3
125 1
125 1
250 1
```

**输出**

```
420
```

**说明**

所有商品均参与活动，总价为 $125+125+250=500$ 元。参与活动总价正好是 `250` 的整数倍，满减次数为 $\lfloor 500 / 250 \rfloor = 2$，减免金额为 $2 \times 40 = 80$ 元。最终支付 $500 - 80 = 420$ 元。

## 样例3

**输入**

```
5
100 0
550 1
200 1
50 1
300 0
```

**输出**

```
1080
```

**说明**

不参与活动的商品为价格为 `100` 和 `300` 的两件，总价 $100+300=400$ 元。
参与活动的商品为价格为 `550`、`200`、`50` 的三件，总价 $550+200+50=800$ 元。
满减计算：$\lfloor 800 / 250 \rfloor = 3$，减免 $3 \times 40 = 120$ 元。
最终支付 $400 + 800 - 120 = 1080$ 元。
