## 解题思路

题目要求计算分类优惠后的总支付金额。优惠规则为：所有类别标记为 $1$（参与活动）的商品，其原始总价每满 $250$ 元即可减免 $40$ 元，减免金额向下取整；类别标记为 $0$（不参与活动）的商品按原价计算。

解题步骤如下：
1. 读入商品数量 $n$，依次处理每一件商品。
2. 使用变量 `sum_all` 累加所有商品的原价总额。
3. 使用变量 `sum_act` 累加所有参与活动商品（$q = 1$）的原价总额。
4. 计算参与活动商品可享受的满减次数：`cnt = sum_act // 250`（整除，向下取整）。
5. 总减免金额为 `cnt * 40`。
6. 最终支付金额为 `sum_all - 减免金额`，输出结果。

该方法只需遍历一次所有商品，直接模拟即可。

## 复杂度分析

- 时间复杂度：$O(n)$，只需对 $n$ 件商品进行一次遍历。
- 空间复杂度：$O(1)$，仅使用了常数个额外变量。

## 代码实现

### Python

```python
n = int(input())
sum_all = 0
sum_act = 0

for _ in range(n):
    p, q = map(int, input().split())
    sum_all += p
    if q == 1:
        sum_act += p

ans = sum_all - (sum_act // 250) * 40
print(ans)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int sumAll = 0;
        int sumAct = 0;

        for (int i = 0; i < n; i++) {
            int p = scanner.nextInt();
            int q = scanner.nextInt();
            sumAll += p;
            if (q == 1) {
                sumAct += p;
            }
        }
        int ans = sumAll - (sumAct / 250) * 40;
        System.out.println(ans);
        scanner.close();
    }
}
```
