# 题目内容
在一所推行个性化教学的学校中，系统收集了 $N$ 名学生对于 $M$ 道习题的掌握程度评分，评分范围是 $1$ 到 $5$ 的整数，数字越大表示掌握越好。如果某位学生尚未作答某道习题，则对应位置用 $0$ 表示。

现在要为编号为 $U$ 的学生推荐他最值得练习的前 $T$ 道习题。推荐过程采用基于用户的协同筛选方法：首先计算所有学生之间的相似度，然后根据与目标学生最相似的 $K = 3$ 名学生的作答情况，预测目标学生在其未作答习题上的可能评分，最后输出预测评分最高的前 $T$ 道习题的编号。

相似度采用皮尔逊相关系数（Pearson Correlation Coefficient）计算。对于学生 $u$ 和学生 $v$，设 $I_{uv}$ 为两人都作答过的习题集合，$r_{u,i}$ 为学生 $u$ 对习题 $i$ 的评分，$\bar{r}_u$ 为学生 $u$ 所有已作答习题的平均评分（若未作答任何习题，则 $\bar{r}_u = 0$），则相似度定义为：

$$
\text{sim}(u, v) = \frac{\sum_{i \in I_{uv}} (r_{u,i} - \bar{r}_u)(r_{v,i} - \bar{r}_v)}{\sqrt{\sum_{i \in I_{uv}} (r_{u,i} - \bar{r}_u)^2} \sqrt{\sum_{i \in I_{uv}} (r_{v,i} - \bar{r}_v)^2}}
$$

如果 $I_{uv}$ 为空或者分母为 $0$，则令 $\text{sim}(u, v) = 0$。

对目标学生 $u$ 尚未作答的习题 $j$，选择与 $u$ 最相似的前 $3$ 名学生构成的集合 $K_u$，预测评分公式为：

$$
\hat{r}_{u,j} = \bar{r}_u + \frac{\sum_{v \in K_u} \text{sim}(u, v) \cdot (r_{v,j} - \bar{r}_v)}{\sum_{v \in K_u} |\text{sim}(u, v)|}
$$

若所有 $v \in K_u$ 都未作答习题 $j$（即分母为 $0$），则令 $\hat{r}_{u,j} = \bar{r}_u$。

推荐时，将所有未作答习题按照预测评分从高到低排序，若预测评分相同则按习题编号从小到大排序，取前 $T$ 个编号作为输出。

约束条件：学生数量 $N$ 和习题数量 $M$ 均不超过 $500$，推荐数量 $T \le M$，评分均为 $1$ 到 $5$ 的整数，$0$ 表示未作答。

# 输入描述
输入通过标准输入给出，格式如下：
第一行包含两个整数 $N$ 和 $M$，表示学生数量和习题数量。
接下来的 $N$ 行，每行包含 $M$ 个整数，表示该学生对每道习题的评分，$0$ 表示未作答，评分范围为 $1$ 到 $5$。
接下来一行包含一个整数 $U$，表示目标学生的编号（编号从 $0$ 开始）。
最后一行包含一个整数 $T$，表示需要推荐的习题数量。
数据保证输入合法，且 $T$ 不超过未作答习题的总数。

# 输出描述
输出一行，包含 $T$ 个整数，表示推荐的习题编号（编号从 $0$ 开始），按预测评分从高到低排序，若预测评分相同则按习题编号从小到大排序，相邻编号之间用一个空格分隔。

## 样例1

**输入**

```
3 3
5 0 3
4 2 0
0 5 4
0
1
```

**输出**

```
1
```

**说明**

学生平均评分：$\bar{r}_0 = 4$，$\bar{r}_1 = 3$，$\bar{r}_2 = 4.5$。计算相似度：学生 `0` 与学生 `1` 共同作答题 `0`，$sim(0,1)=1.0$；学生 `0` 与学生 `2` 共同作答题 `2`，$sim(0,2)=1.0$。取最相似的前 $K=3$ 名用户（此处为全部其他用户）。学生 `0` 未作答题 `1`，根据预测公式 $\hat{r}_{0,1} = 4 + \frac{1.0 \times (2-3) + 1.0 \times (5-4.5)}{1.0 + 1.0} = 3.75$。只有一道未作答题，推荐编号 `1`。

## 样例2

**输入**

```
4 3
1 0 0
0 2 0
0 0 3
1 2 3
0
2
```

**输出**

```
1 2
```

**说明**

学生 `0` 仅作答题 `0`，评分 `1`，$\bar{r}_0=1$。学生 `0` 与其他任何学生均无共同作答的习题，或像学生 `3` 在共同题上的评分无偏差导致分母为 $0$，因此所有 $sim(0,v)=0$。此时最相似用户集合 $K_u$ 中相似度全为 `0`，加权求和的分母为 $0$，预测评分直接取 $\bar{r}_0=1$。未作答题 `1` 和 `2` 的预测分均为 `1`，按编号从小到大排序，输出 `1 2`。

## 样例3

**输入**

```
4 4
4 0 2 0
5 3 0 1
2 0 4 0
0 5 0 5
0
2
```

**输出**

```
1 3
```

**说明**

学生平均评分：$\bar{r}_0=3$，$\bar{r}_1=3$，$\bar{r}_2=3$，$\bar{r}_3=5$。相似度：$sim(0,1)=1.0$，$sim(0,2)=-1.0$，$sim(0,3)=0$。选取最相似的前 $3$ 名用户参与预测。对未作答题 `1`，仅学生 `1` 有评分 $3$，预测 $\hat{r}_{0,1}=3+0=3$；对未作答题 `3`，学生 `1` 评分为 $1$，预测 $\hat{r}_{0,3}=3+\frac{1.0\times(1-3)}{1.0}=1$。预测分 $3 > 1$，推荐 `1 3`。
