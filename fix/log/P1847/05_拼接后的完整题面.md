# 题目内容
珠宝店的砝码每枚质量都必须写成 $2^{x}\cdot 3^{y}$ 的形式，其中 $x,y$ 为非负整数，且任意两枚砝码质量互不相同。

给定正整数 $n$，需要选出若干枚这样的砝码，使它们的质量之和恰好等于 $n$。可以证明，对题目范围内的每个 $n$ 都至少存在一种方案。

请输出任意一种方案，并按砝码质量从大到小排列。

测试组数 $T$ 满足 $1 < T < 100$，每组目标质量 $n$ 不超过 `10^9`。

# 输入描述
每个测试文件包含多组数据。
第一行一个整数 $T$（$1 < T < 100$），表示数据组数。
接下来 $T$ 行，每行一个整数 $n$（$1 \le n \le 10^9$），表示目标质量。

# 输出描述
对每组数据输出两行：第一行一个整数 $m$，表示砝码枚数；第二行 $m$ 个互不相同的整数，表示各枚砝码的质量，按从大到小排列，且每一项均可写成 $2^{x}\cdot 3^{y}$。若有多种方案，输出任意一种即可。

## 样例1

**输入**

```
3
7
20
1
```

**输出**

```
3
4 2 1
2
16 4
1
1
```

**说明**

一种合法做法是令所有 $y=0$，即把 $n$ 拆成互不相同的二的幂。
$7=4+2+1$，输出 `3` 枚：`4 2 1`。
$20=16+4$，输出 `2` 枚：`16 4`。
$1=1$，输出 `1` 枚：`1`。

## 样例2

**输入**

```
2
45
100
```

**输出**

```
4
32 8 4 1
3
64 32 4
```

**说明**

$45=32+8+4+1$，从大到小输出 `32 8 4 1`。
$100=64+32+4$，从大到小输出 `64 32 4`。
每一项都是 $2^{x}\cdot 3^{0}$，满足题意。

## 样例3

**输入**

```
2
8
15
```

**输出**

```
1
8
4
8 4 2 1
```

**说明**

$8$ 本身就是 $2^3$，只需一枚砝码 `8`。
$15=8+4+2+1$，输出四枚 `8 4 2 1`。
