## 解题思路

形如 $2^x\cdot 3^y$ 的正整数有很多，但取 $y=0$ 时就退化成纯二的幂。把 $n$ 写成二进制，每一位上的 `1` 对应一项 $2^{x}$，这些项两两不同、均为 $2^{x}\cdot 3^{0}$，且之和恰好为 $n$。

因此只需从高位到低位枚举 $n$ 的二进制中为 `1` 的位，依次输出对应的 $2^{x}$ 即可，自然满足从大到小。

## 复杂度分析

每组数据扫描不超过 `32` 个二进制位。

- 时间复杂度：$O(T)$。
- 空间复杂度：$O(1)$。

## 代码实现

### Python

```python
T = int(input())
for _ in range(T):
    n = int(input())
    v = [(1 << i) for i in range(31, -1, -1) if (n >> i) & 1]
    print(len(v))
    print(*v)
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();
        for (int t = 0; t < T; t++) {
            int n = sc.nextInt();
            List<Integer> v = new ArrayList<>();
            for (int i = 31; i >= 0; i--) {
                if (((n >> i) & 1) == 1) {
                    v.add(1 << i);
                }
            }
            System.out.println(v.size());
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < v.size(); i++) {
                if (i > 0) sb.append(' ');
                sb.append(v.get(i));
            }
            System.out.println(sb);
        }
        sc.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        vector<int> v;
        for (int i = 31; i >= 0; i--) {
            if ((n >> i) & 1) v.push_back(1 << i);
        }
        cout << v.size() << "\n";
        for (int i = 0; i < (int)v.size(); i++) {
            if (i) cout << ' ';
            cout << v[i];
        }
        cout << "\n";
    }
    return 0;
}
```
