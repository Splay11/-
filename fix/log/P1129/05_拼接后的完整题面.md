# 题目内容
某生产线上，关键质量指标 $X$ 在区间 $[1,10]$ 上的概率密度函数为 $p(x) = \frac{\sin(\sqrt{x})}{5.68}$。工程师需要快速判断 $X$ 落入给定子区间 $[a,b] \subset [1,10]$ 的概率是否超过 $0.5$，以便决定是否调整工艺参数。

由于积分 $P(a \le X \le b) = \int_a^b \frac{\sin(\sqrt{x})}{5.68} \, dx$ 没有简单的闭式解，采用数值积分方法：将 $[a,b]$ 均匀划分为 $500$ 个小区间，步长 $\Delta x = \frac{b-a}{500}$，并用矩形公式近似：
$$
P(a \le X \le b) \approx \sum_{i=0}^{499} \frac{\sin(\sqrt{x_i})}{5.68} \Delta x,
$$
其中 $x_i = a + i \cdot \Delta x$。

现给定一组区间参数 $a$ 和 $b$，请按上述方法计算近似概率，并判断其是否大于 $0.5$。

**约束条件：**
- $a$ 和 $b$ 均为整数，满足 $1 \le a < b \le 10$。
- 数值积分固定等分为 $500$ 份。

# 输入描述
第一行包含一个整数 $T$，表示测试数据组数。
接下来的 $T$ 行，每行包含两个整数 $a$ 和 $b$，代表要评估的区间，保证 $1 \le a < b \le 10$。

# 输出描述
对于每组数据，输出一行。若计算出的近似概率大于 $0.5$，输出 `1`，否则输出 `0`。

## 样例1

**输入**

```
1
1 2
```

**输出**

```
0
```

**说明**

区间为 $[1,2]$，步长 $\Delta x = \frac{2-1}{500}=0.002$。在 $[1,2]$ 上，函数 $\sin(\sqrt{x})$ 的值约在 $0.84$ 到 $0.99$ 之间，除以 $5.68$ 后密度整体较小。经数值积分求得近似概率远小于 $0.5$，因此输出 `0`。

## 样例2

**输入**

```
1
1 10
```

**输出**

```
1
```

**说明**

区间为整个定义域 $[1,10]$，$\Delta x = \frac{10-1}{500}=0.018$。对该区间上的 $\frac{\sin(\sqrt{x})}{5.68}$ 积分，总面积可通过换元计算，结果约为 $1.005$，超过 $0.5$。矩形法近似同样会得到大于 $0.5$ 的结果，因此输出 `1`。

## 样例3

**输入**

```
1
9 10
```

**输出**

```
0
```

**说明**

区间 $[9,10]$ 位于定义域尾部，此时 $\sqrt{x}$ 接近 $3$ 到 $\pi$，$\sin(\sqrt{x})$ 的值由正转负且绝对值很小，密度函数取值极低。即使将区间分为 `500` 等份求和，累计概率仍远小于 $0.5$，故输出 `0`。

## 样例4

**输入**

```
1
4 7
```

**输出**

```
0
```

**说明**

区间 $[4,7]$ 跨度较大，步长 $\Delta x = \frac{7-4}{500}=0.006$。在 $x>4$ 后 $\sin(\sqrt{x})$ 逐渐减小并最终变为负值，使得整体概率密度降低。使用矩形公式累加 $500$ 项后，近似概率约为 $0.374$，未超过 $0.5$，因此输出 `0`。
