# 题目内容
在某个数字世界中，一个大于 $1$ 的整数若只能被 $1$ 和自身整除，则称为“纯数”。一个整数若恰好等于某个整数的平方，则称为“整方数”。

现在给定一个正整数，你需要通过反复进行以下操作，将它变成一个整方数。如果一开始就是整方数，则不需要任何操作。

操作规则如下：
1. 如果当前数是纯数，则将它减去 $1$；
2. 否则，将它除以它最小的大于 $1$ 的因数。

请你计算最少需要多少次操作。

约束：给定的正整数 $x$ 满足 $1 \le x \le 10^9$。

# 输入描述
输入包含一行，一个正整数 $x$。

# 输出描述
输出一个整数，表示将 $x$ 变为整方数所需的最少操作次数。

## 样例1

**输入**

```
8
```

**输出**

```
1
```

**说明**

$8$ 不是纯数，其最小的大于 $1$ 的因数为 $2$。执行操作 $8 \div 2 = 4$，$4 = 2^2$ 为整方数。整个过程仅需 `1` 次操作。

## 样例2

**输入**

```
6
```

**输出**

```
3
```

**说明**

初始 $6$ 不是纯数，最小因数为 $2$，操作得 $3$；
$3$ 是纯数，执行减 $1$ 得 $2$；
$2$ 是纯数，执行减 $1$ 得 $1$；
$1=1^2$ 为整方数。
共进行 `3` 次操作。

## 样例3

**输入**

```
1
```

**输出**

```
0
```

**说明**

初始 $1=1^2$ 已经是整方数，不需要任何操作，答案为 `0`。
