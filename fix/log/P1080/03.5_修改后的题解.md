## 解题思路

长度为 $len$ 的相同字符连续段，其回文子串个数为 $\dfrac{len(len+1)}{2}$（每一段连续子串都是回文）。若相邻两段使用不同字符，则不会产生跨段回文，总回文子串数等于各段贡献之和。

字符只有 `r`、`e`、`d` 三种，按 `r,e,d,r,e,d,\ldots` 轮流放置各段，即可保证相邻段字符不同。

由于 $x$ 最大可达 $10^9$，而字符串长度不能超过 $10^5$，应尽量使用较长的段。每次贪心取最大的 $len$，使得 $\dfrac{len(len+1)}{2} \le$ 剩余需求。实现上把需求乘 `2`，二分最大的 $len$ 满足 $len(len+1) \le$ 剩余值，然后从剩余中减去该贡献，继续构造下一段。

## 复杂度分析

段数很少（每次贡献约为当前剩余的平方根量级），每段二分 $O(\log 10^5)$。时间复杂度 $O(\sqrt{x}\log 10^5)$ 量级，且输出长度不超过 $10^5$，空间复杂度 $O(|s|)$。

## 代码实现

### Python

```python
def get_min_num(tar):
    L, R, ans = 1, 10 ** 5, -1
    while L <= R:
        mid = (L + R) // 2
        if mid * mid + mid <= tar:
            ans = mid
            L = mid + 1
        else:
            R = mid - 1
    return ans

n = int(input())
n = n * 2
ch = ['r', 'e', 'd']
now = 0
s = []
while n > 0:
    val = get_min_num(n)
    n -= val * val + val
    s.append(ch[now] * val)
    now = (now + 1) % 3
print("".join(s))
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static long getMinNum(long tar) {
        long L = 1, R = (long) 1e5, ans = -1;
        while (L <= R) {
            long mid = (L + R) / 2;
            if (mid * mid + mid <= tar) {
                ans = mid;
                L = mid + 1;
            } else {
                R = mid - 1;
            }
        }
        return ans;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        long n = in.nextLong();
        n = n * 2L;
        StringBuilder sb = new StringBuilder();
        char[] ch = new char[] {'r', 'e', 'd'};
        int now = 0;
        while (n > 0) {
            long val = getMinNum(n);
            n -= val * val + val;
            for (int j = 0; j < val; j++) {
                sb.append(ch[now]);
            }
            now = (now + 1) % 3;
        }
        System.out.println(sb.toString());
    }
}
```

typedef long long ll;

ll getMinNum(ll tar) {
    ll L = 1, R = (ll)1e5, ans = -1;
    while (L <= R) {
        ll mid = (L + R) / 2;
        if (mid * mid + mid <= tar) {
            ans = mid;

int main() {
    ll n;
    cin >> n;
    n = n * 2;
    char ch[3] = {'r', 'e', 'd'};
    string str = "";
    int now = 0;
    while (n > 0) {
        ll val = getMinNum(n);
        n -= val * val + val;
        for (int j = 0; j < val; j++) {
            str += ch[now];
        }
        now = (now + 1) % 3;
    }
    cout << str << endl;
    return 0;
}
