# 题目内容
需要构造一个仅由字符 `r`、`e`、`d` 组成的字符串 $s$，使得 $s$ 中回文子串的个数恰好等于给定的正整数 $x$。
回文子串按起止位置计数：只要两个子串的左右端点不完全相同，即使内容相同也视为不同的回文子串。单字符一定是回文。
构造出的字符串长度不得超过 $10^5$。题目保证在此限制下一定存在合法构造。

约束条件：
- $x$ 为正整数，且不超过 $10^9$。
- 输出字符串仅含字符 `r`、`e`、`d`，长度不超过 $10^5$。

# 输入描述
输入一行，包含一个正整数 $x$，表示需要恰好达到的回文子串个数。

# 输出描述
输出一行，一个由字符 `r`、`e`、`d` 组成的字符串，其回文子串个数恰好为 $x$。

## 样例1

**输入**

```
4
```

**输出**

```
rre
```

**说明**

字符串 `rre` 的全部子串为：`r`、`r`、`e`、`rr`、`re`、`rre`。
其中回文子串为两个单字符 `r`、一个单字符 `e` 以及 `rr`，共 `4` 个，恰好等于 $x=4$。

## 样例2

**输入**

```
1
```

**输出**

```
r
```

**说明**

单个字符 `r` 本身是回文，回文子串个数为 `1`。

## 样例3

**输入**

```
15
```

**输出**

```
rrrrr
```

**说明**

连续 `5` 个相同字符 `r` 的回文子串个数为 $\dfrac{5 \times 6}{2}=15$，恰好等于 $x$。
因此输出 `rrrrr`。

## 样例4

**输入**

```
14
```

**输出**

```
rrrreed
```

**说明**

采用分段相同字符、相邻段使用不同字符的构造：先放 `4` 个 `r`（贡献 $10$ 个回文），再放 `2` 个 `e`（贡献 $3$ 个），再放 `1` 个 `d`（贡献 `1` 个）。
相邻段字符不同，不会产生跨段回文，总数为 $10+3+1=14$，输出 `rrrreed`。
