# 题目内容
在一段长度为 $n$ 的数据序列中，我们需要提取不同尺度下的异或特征。

对于任意长度 $k$ ($1 \le k \le n$)，定义第 $k$ 阶特征值 $C_k$ 为：所有长度为 $k$ 的连续子段各自内部元素的异或和，再将这些异或和进行异或运算得到的最终结果。

换句话说，设序列为 $a_1, a_2, \dots, a_n$，子段 $[i,i+k-1]$ 的内部异或和为 $X_i = a_i \oplus a_{i+1} \oplus \cdots \oplus a_{i+k-1}$。则
$C_k = X_1 \oplus X_2 \oplus \cdots \oplus X_{n-k+1}$。

现在给定序列的全部数值，请计算出 $C_1, C_2, \dots, C_n$。

约束：序列长度 $n$ 满足 $1 \le n \le 2\times 10^5$，每个元素 $a_i$ 是满足 $0 \le a_i < 2^{30}$ 的整数。

# 输入描述
第一行包含一个整数 $n$，表示序列的长度。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$，表示序列元素。

# 输出描述
输出一行，包含 $n$ 个整数，依次表示 $C_1, C_2, \dots, C_n$，整数之间用空格分隔。

## 样例1

**输入**

```
1
5
```

**输出**

```
5
```

**说明**

序列长度为 $n=1$，仅包含元素 `5`。对于 $k=1$，只有一个长度为 `1` 的子段，异或和为 `5`。因此 $C_1=5$，直接输出 `5`。

## 样例2

**输入**

```
3
0 0 0
```

**输出**

```
0 0 0
```

**说明**

序列所有元素均为 `0`，对于任意子段，内部异或和恒为 `0`。

- $k=1$：三个子段 `[0]` 异或和均为 `0`，$C_1 = 0 \oplus 0 \oplus 0 = 0$；
- $k=2$：两个子段 `[0,0]` 异或和为 `0`，$C_2 = 0 \oplus 0 = 0$；
- $k=3$：唯一子段 `[0,0,0]` 异或和为 `0`，$C_3 = 0$。

因此输出三个 `0`。

## 样例3

**输入**

```
4
1 2 3 4
```

**输出**

```
4 5 5 4
```

**说明**

序列为 `[1,2,3,4]`，依次计算各阶特征值：

- $k=1$：子段有 `[1]`、`[2]`、`[3]`、`[4]`，异或和分别为 `1,2,3,4`。$C_1 = 1 \oplus 2 \oplus 3 \oplus 4 = 4$；
- $k=2$：子段有 `[1,2]`（异或和 $1 \oplus 2 = 3$）、`[2,3]`（$2 \oplus 3 = 1$）、`[3,4]`（$3 \oplus 4 = 7$）。$C_2 = 3 \oplus 1 \oplus 7 = 5$；
- $k=3$：子段有 `[1,2,3]`（异或和 $1 \oplus 2 \oplus 3 = 0$）、`[2,3,4]`（$2 \oplus 3 \oplus 4 = 5$）。$C_3 = 0 \oplus 5 = 5$；
- $k=4$：唯一子段 `[1,2,3,4]` 异或和为 $1 \oplus 2 \oplus 3 \oplus 4 = 4$，故 $C_4 = 4$。

最终输出 `4 5 5 4`。
