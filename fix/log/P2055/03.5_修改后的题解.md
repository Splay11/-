## 解题思路

我们要求序列的层级异或特征 $C_1, C_2, \dots, C_n$，其中 $C_k$ 定义为所有长度为 $k$ 的连续子段异或和的异或。直接对每个 $k$ 重新计算所有子段异或和的复杂度为 $O(n^2)$，无法通过 $n\le 2\times 10^5$ 的数据范围。我们需要利用异或的性质进行递推。

1. **前缀异或和**  
   构造前缀异或和数组 $s$，其中 $s[i] = a_1 \oplus a_2 \oplus \cdots \oplus a_i$（规定 $s[0]=0$）。利用前缀异或和可以在 $O(1)$ 时间内求出任意区间 $[l, r]$ 的异或和：  
   $$X(l, r) = s[r] \oplus s[l-1]$$

2. **递推关系**  
   设 $ans$ 表示当前长度下的特征值，初始 $ans=0$。我们按长度 $k$ 从 $1$ 到 $n$ 递推：
   - 从 $C_{k-1}$ 变为 $C_k$ 时，所有长度变为 $k$ 的子段都会比原来长度为 $k-1$ 的子段多出一个末尾元素。这些新增的末尾元素恰好覆盖了区间 $[k, n]$ 中的所有元素，每个恰出现一次，因此新增贡献为 $X(k, n)$。
   - 同时，原本起点为 $n-k+2$、长度为 $k-1$ 的子段因为达到了序列右边界而无法继续向右扩展，需要从答案中移除。该子段的异或和为 $X(n-k+2, n)$，由于异或的逆运算仍为异或，我们只需再次异或这个值即可抵消。
   - 综上，得到递推公式：
     $$C_k = C_{k-1} \oplus X(k, n) \oplus X(n-k+2, n)$$

3. **实现细节**  
   按照 $k=1$ 到 $n$ 的顺序，利用前缀异或和数组实时更新 $ans$ 并输出。当 $n-k+2 > n$ 时，对应的区间非法，但我们的区间异或函数 $X(l,r)$ 在 $l = r+1$ 时会计算 $s[r] \oplus s[r] = 0$，恰好符合“没有需要抵消的区间”的语义，无需特判。

## 复杂度分析

- **时间复杂度**：$O(n)$。计算前缀异或和与递推每一步都只需常数时间，总时间与序列长度成线性关系。  
- **空间复杂度**：$O(n)$。需要长度为 $n+1$ 的数组存储前缀异或和。

## 代码实现

### Python

```python
def range_xor(prefix, l, r):
    """返回区间[l, r]的异或和，使用前缀异或数组"""
    return prefix[r] ^ prefix[l - 1]

def main():
    n = int(input())
    a = list(map(int, input().split()))
    # 前缀异或数组，多开一位方便处理 s[0] = 0
    s = [0] * (n + 1)
    for i in range(1, n + 1):
        s[i] = s[i - 1] ^ a[i - 1]

    ans = 0
    res = []
    for i in range(1, n + 1):
        # 递推更新
        ans ^= range_xor(s, i, n) ^ range_xor(s, n - i + 2, n)
        res.append(str(ans))
    # 输出一行，空格分隔
    print(' '.join(res))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    // 计算区间[l, r]的异或和
    private static int rangeXor(int[] s, int l, int r) {
        return s[r] ^ s[l - 1];
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] a = new int[n + 1];
        int[] s = new int[n + 1];  // 前缀异或数组

        for (int i = 1; i <= n; i++) {
            a[i] = sc.nextInt();
            s[i] = s[i - 1] ^ a[i];
        }

        int ans = 0;
        StringBuilder sb = new StringBuilder();
        for (int i = 1; i <= n; i++) {
            ans ^= rangeXor(s, i, n) ^ rangeXor(s, n - i + 2, n);
            sb.append(ans).append(' ');
        }
        // 去掉末尾多余空格后输出
        System.out.println(sb.toString().trim());
        sc.close();
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

// 计算区间[l, r]的异或和
int range_xor(const vector<int>& s, int l, int r) {
    return s[r] ^ s[l - 1];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> a(n + 1);
    vector<int> s(n + 1, 0); // 前缀异或数组

    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        s[i] = s[i - 1] ^ a[i];
    }

    int ans = 0;
    for (int i = 1; i <= n; i++) {
        ans ^= range_xor(s, i, n) ^ range_xor(s, n - i + 2, n);
        cout << ans << " \n"[i == n]; // 非末尾输出空格，末尾输出换行
    }

    return 0;
}
```
