## 思路

题目大意

好子串的定义为：所有前缀的0的数量严格大于1的数量。给定字符串，找出所有好子串。

思路

题目要求的好子串为所有前缀0的数量严格大于1的。

若区间[i,j]为好子串，则区间[i,j-1]也为好子串

固定子串的左端点为i,找到最近的右端点使得[i,j]为非好子串，[i，j-1]为好子串，显然,[i,i],[i,i+1]...[i,j-1]都是好子串，[i,j],[i,j+1]..[i,n]都不是好子串

定义p[i]为最近的右端点使得[i,j]为非好子串,即上述的j .最终的答案为sum(p[i]-i)
求解p[i]

根据p[i]的定义(离i最近的...)，便可以想到用二分，或者栈(单调栈同样可以求最近的点）。。。。题解采用的是栈。

先考虑 假设好子串的定义为：：所有前缀的0的数量大于等于1的的串   (在原题意的基础上划了个等号)

因此等价的定义为:每一个'1'它的前面都有一个‘0’和它配对。(eg: "01001",第一个1与第一个0配对，最后一个1与第二个或第3三个0配对，因此"01001"为好子串。“011”不是好子串，因为第一个‘1’和第一个‘0’配对，最后一个'1'没有'0'配对)

所以可以用一个栈来存放所有还没匹配‘0’的字符'1'的位置，倒着遍历原字符串：若当前字符为'1'，则将当前位置i放入栈中。若当前字符为'0'，则将栈顶的一个元素弹出，表示栈顶的‘1’和‘0’配对。因此遍历到第i个位置时，我们就知道了当前的栈顶元素就是p[i]

刚才求的p[i]实际上是不严格的，题目要的是所有前缀的0的数量严格大于1的数量

累加答案:左端点i的s[i]一定是‘0’。所以只考虑s[i]=='0'的情况。若当前i是最后一个位置，那么答案只能加1。否则答案加上p[i+1]-i,因为[i+1,p[i+1]]为不严格的最长区间，那么[i,p[i+1]]就是严格的最长区间.

答案为sum(p[i+1]-i) 。此时的p[i]是不严格的定义 。 代码中没有直接去求p[i]了，可以仔细理解一下上述栈的模拟过程。


## 代码
###  java
```java
import java.util.*;
class Main {
    static Scanner sc = new Scanner(System.in);
    static int[] b=new int[100010];
    public static void main(String[] args) {
        String str=sc.next();
        int n=str.length();
        b[0]=n;
        int wei=0;
        long res=0;
        for(int i=n-1;i>=0;i--)
        {
            if(str.charAt(i)!='0')
            {
                b[++wei]=i;
            }
            else 
            {
                if(i+1<n)res+=b[wei]-i;//注意这里实际就是p[i+1],自身没有配对
                else res++;
                if(wei>=1) wei--;
            }
        }
    System.out.println(res);
    }
}
```
### C++
```cpp
#include <iostream>
using namespace std;

int b[100010];

int main() {
    string str;
    cin >> str;
    int n = str.length();
    b[0] = n;
    int wei = 0;
    long long res = 0;
    
    for (int i = n - 1; i >= 0; i--) {
        if (str[i] != '0') {
            b[++wei] = i;
        } else {
            if (i + 1 < n)
                res += b[wei] - i;  // 注意这里实际就是 p[i+1]，自身没有配对
            else
                res++;
            if (wei >= 1)
                wei--;
        }
    }
    
    cout << res << endl;
    return 0;
}
```
