# 题目内容
地铁站闸机把一次班次内的刷卡结果记成只含字符 `0` 和 `1` 的字符串 $s$。其中 `0` 表示进站成功，`1` 表示出站成功。调度员把一段连续日志称为进站占优段，当且仅当它的每一个前缀里，字符 `0` 的个数都严格大于字符 `1` 的个数。请统计 $s$ 中有多少个进站占优段。

约束：字符串长度不超过 $10^5$。

# 输入描述
输入一行一个只含字符 `0` 和 `1` 的字符串 $s$，长度满足 $1 \le |s| \le 10^5$。

# 输出描述
输出一个整数，表示进站占优段的个数。

## 样例1

**输入**

```
0
```

**输出**

```
1
```

**说明**

单个字符 `0` 的唯一前缀就是它自己，`0` 的个数为 `1`，严格大于 `1` 的个数 `0`，因此答案为 `1`。

## 样例2

**输入**

```
00
```

**输出**

```
3
```

**说明**

三个子串 `0`（左）、`0`（右）、`00` 的每个前缀都只含 `0`，均为偏零串，答案为 `3`。

## 样例3

**输入**

```
0001
```

**输出**

```
8
```

**说明**

以每个 `0` 为左端点，向右延伸直到某个前缀不再偏零为止。

- 从第 `1` 个 `0` 出发，四个前缀 `0`、`00`、`000`、`0001` 都合法；
- 从第 `2` 个 `0` 出发，三个前缀合法；
- 从第 `3` 个 `0` 出发，仅自身合法。

合计 `8`。以 `1` 开头的子串第一个前缀就不合法。

## 样例4

**输入**

```
0110
```

**输出**

```
2
```

**说明**

只有两个单字符 `0` 是偏零串：位置 `1` 的 `0`，以及位置 `4` 的 `0`。以 `1` 开头的子串非法；`01` 的第二个前缀中 `0` 与 `1` 个数相等，也不合法。答案为 `2`。
