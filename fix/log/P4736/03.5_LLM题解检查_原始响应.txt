## 解题思路

本题要求统计字符串 $s$ 中所有满足条件的“奇异子序列”数量。  
一个子序列是奇异的，当且仅当：
1. 不含前导零（单个数字 `'0'` 视为没有前导零）；
2. 子序列中奇数数字（`1,3,5,7,9`）的个数与偶数数字（`0,2,4,6,8`）的个数不相等。

我们可以将问题转化为：

\[
\text{奇异子序列总数} = \text{所有合法子序列总数} - \text{奇偶数量相等的合法子序列数}
\]

### 1. 统计所有合法子序列

合法的子序列必须满足“无前导零”的规则。因此我们按子序列的首位进行分类：

- 若 $s[i] = 0$，该 `'0'` 只能作为一个独立的子序列 `"0"` 计数一次；
- 若 $s[i] \ne 0$，则可以将其作为首字符，后面的每个字符都可以任意选或不选，因此以该位置开头的子序列共有 $2^{\,n-i-1}$ 个（$n$ 为字符串长度）。

对所有位置累加即可得到合法子序列总数。

### 2. 计算奇偶数量相等的子序列数（平衡子序列）

对于以 $s[i]$ 为首位的子序列（$s[i]\ne 0$），设后缀中奇数个数为 $O$，偶数个数为 $E$。  
根据首位的奇偶性，分两种情况：

- **首字符为奇数**：要求最终奇数个数 $=$ 偶数个数。  
  首字符已贡献 $1$ 个奇数，因此需要从后缀中选出 $x$ 个奇数和 $x+1$ 个偶数，方案数为  
  $$\sum_{x}\binom{O}{x}\binom{E}{x+1}$$  
  利用范德蒙德恒等式可化简为 $\binom{O+E}{E-1}$（当 $E\ge 1$ 时；否则为 $0$）。

- **首字符为偶数**：要求最终奇数个数 $=$ 偶数个数。  
  首字符已贡献 $1$ 个偶数，需要从后缀中选出 $x$ 个偶数和 $x+1$ 个奇数，方案数为  
  $$\sum_{x}\binom{E}{x}\binom{O}{x+1} = \binom{O+E}{O-1}$$  
  （当 $O\ge 1$ 时；否则为 $0$）。

将这部分非零起点的平衡子序列从总数中扣除，即可得到奇异子序列的数量。

### 3. 算法流程

1. 预处理组合数 $C_{n}^{k}$ 以及 $2$ 的幂次（用于快速计算 $2^{\text{后缀长度}}$），同时对后缀的奇数、偶数个数进行后缀和统计。
2. 遍历字符串的每个位置 $i$：
   - 若 $s[i] = 0$，答案直接 $+1$；
   - 若 $s[i] \ne 0$，累加 $2^{n-i-1}$ 作为合法子序列总数，再根据首位的奇偶性减去上述平衡子序列数。
3. 所有运算均对 $10^9+7$ 取模，最后输出答案。

## 复杂度分析

- **时间复杂度**：预处理组合数需要 $O(n^2)$，遍历字符串统计答案需要 $O(n)$，整体时间复杂度为 $O(n^2)$，其中 $n \le 5000$ 完全可接受。
- **空间复杂度**：组合数表格占用 $O(n^2)$ 空间，其余辅助数组为 $O(n)$，因此空间复杂度为 $O(n^2)$。

## 代码实现

### Python

```python
import sys

MOD = 10**9 + 7

def init_comb(n):
    C = [[0] * (n + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        C[i][0] = 1
        for j in range(1, i + 1):
            C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD
    return C

def solve(n, s):
    C = init_comb(n)
    
    # 2 的幂
    pow2 = [1] * (n + 1)
    for i in range(1, n + 1):
        pow2[i] = pow2[i-1] * 2 % MOD
    
    # 后缀奇数、偶数个数
    suf_odd = [0] * (n + 1)
    suf_even = [0] * (n + 1)
    for i in range(n - 1, -1, -1):
        suf_odd[i] = suf_odd[i+1]
        suf_even[i] = suf_even[i+1]
        if int(s[i]) % 2 == 1:
            suf_odd[i] += 1
        else:
            suf_even[i] += 1
    
    ans = 0
    for i in range(n):
        # 单独的 '0'
        if s[i] == '0':
            ans = (ans + 1) % MOD
            continue
        
        # 以 s[i] 为首位的合法子序列总数
        total = pow2[n - i - 1]
        O = suf_odd[i + 1]
        E = suf_even[i + 1]
        
        # 平衡子序列数（奇偶相等）
        bad = 0
        if int(s[i]) % 2 == 1:      # 首字符奇数
            if E >= 1:
                bad = C[O + E][E - 1]
        else:                        # 首字符偶数
            if O >= 1:
                bad = C[O + E][O - 1]
        
        ans = (ans + total - bad) % MOD
    
    return ans

if __name__ == "__main__":
    n = int(sys.stdin.readline().strip())
    s = sys.stdin.readline().strip()
    print(solve(n, s))
```

### Java

```java
import java.util.*;

public class Main {
    static final int MOD = 1000000007;

    static long[][] initComb(int n) {
        long[][] C = new long[n + 1][n + 1];
        for (int i = 0; i <= n; i++) {
            C[i][0] = 1;
            for (int j = 1; j <= i; j++) {
                C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % MOD;
            }
        }
        return C;
    }

    static long solve(int n, String s) {
        long[][] C = initComb(n);

        long[] pow2 = new long[n + 1];
        pow2[0] = 1;
        for (int i = 1; i <= n; i++) {
            pow2[i] = pow2[i - 1] * 2 % MOD;
        }

        int[] sufOdd = new int[n + 1];
        int[] sufEven = new int[n + 1];
        for (int i = n - 1; i >= 0; i--) {
            sufOdd[i] = sufOdd[i + 1];
            sufEven[i] = sufEven[i + 1];
            int d = s.charAt(i) - '0';
            if (d % 2 == 1) sufOdd[i]++;
            else sufEven[i]++;
        }

        long ans = 0;
        for (int i = 0; i < n; i++) {
            // 单独的 '0'
            if (s.charAt(i) == '0') {
                ans = (ans + 1) % MOD;
                continue;
            }

            long total = pow2[n - i - 1];
            int O = sufOdd[i + 1];
            int E = sufEven[i + 1];
            long bad = 0;
            int d = s.charAt(i) - '0';

            if (d % 2 == 1) {          // 首字符奇数
                if (E >= 1) bad = C[O + E][E - 1];
            } else {                   // 首字符偶数
                if (O >= 1) bad = C[O + E][O - 1];
            }

            ans = (ans + total - bad + MOD) % MOD;
        }

        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        String s = sc.next();
        System.out.println(solve(n, s));
    }
}
```
