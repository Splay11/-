## 解题思路

本题是一个在二维网格上的双人零和博弈问题，可以使用动态规划 + 极小化极大（minimax）思想解决。

- **游戏模型**  
  令牌从左上角 $(1,1)$ 出发，每次只能向右或向下移动一格，到达右下角 $(n,m)$ 后游戏结束。  
  总步数固定为 $(n-1)+(m-1)=n+m-2$，因此路径是一条 DAG（有向无环图）。  
  Alice 先手，两人轮流移动。进入新格子时，根据格子内容获得分数：`'1'` 使当前移动者获得 $+1$ 分，`'0'` 使其获得 $-1$ 分。起点 $(1,1)$ 不计分。  
  双方均采取最优策略：Alice 希望最大化「自己总分 $-$ Bob 总分」的差值，Bob 希望最小化该差值。

- **状态定义**  
  设 $dp[i][j]$ 表示**当前令牌位于格子 $(i,j)$，且接下来轮到应行动的玩家操作时**，从该状态出发直到游戏结束，最终的「Alice 总分 $-$ Bob 总分」的最优结果。  
  代码实现中，网格使用 $0$ 基下标，即第一行第一列对应 $i=0,\ j=0$，最后一行最后一列对应 $i=n-1,\ j=m-1$。

- **轮到谁操作**  
  走到格子 $(i,j)$ 时，已经走过的步数为 $(i-1)+(j-1)=i+j-2$（从 $(1,1)$ 开始）。  
  - 若已走步数为偶数（即 $(i+j)$ 为偶数），下一步轮到 Alice 操作；  
  - 若已走步数为奇数（即 $(i+j)$ 为奇数），下一步轮到 Bob 操作。  

- **状态转移**  
  从 $(i,j)$ 出发，下一步只能走到 $(i+1,j)$ 或 $(i,j+1)$（前提是未越界）。  
  设走到的新格子得分为 $w$：若格子为 `'1'` 则 $w=+1$，若为 `'0'` 则 $w=-1$。  
  - **轮到 Alice 时**：她希望最大化差值，因此选择所有合法走法中结果最大的一个。  
    转移方程：
    $$dp[i][j] = \max_{\text{valid moves}}\big(dp[\text{next}] + w\big)$$
  - **轮到 Bob 时**：Bob 获得分数 $w$，这会使得「Alice 总分 $-$ Bob 总分」减少 $w$。因此他会在所有合法走法中选择使得差值最小的一个。  
    转移方程：
    $$dp[i][j] = \min_{\text{valid moves}}\big(dp[\text{next}] - w\big)$$

- **边界条件**  
  当令牌已经在终点 $(n,m)$（即 $(n-1,m-1)$）时，游戏结束，后续没有得分，因此：
  $$dp[n-1][m-1] = 0$$

- **实现顺序**  
  采用从右下角向左上角的倒序动态规划，每个格子只计算一次。最终答案即为 $dp[0][0]$。

---

## 复杂度分析

- **时间复杂度**：棋盘共有 $O(nm)$ 个格子，每个格子最多考察两个方向（向下和向右），因此时间复杂度为 $O(nm)$。  
- **空间复杂度**：需要一个 $n \times m$ 的二维数组存储 $dp$ 状态，空间复杂度为 $O(nm)$。  
  在题目约束 $n \times m \le 4 \times 10^5$ 下，该复杂度完全可行。

## 代码实现

### Python

```python
import sys

def solve(n, m, grid):
    # dp[i][j] 表示当前令牌在 (i,j)，从此处开始在最优策略下，
    # 最终“Alice总分 - Bob总分”的差值
    dp = [[0] * m for _ in range(n)]

    # 从右下角向左上角倒序计算
    for i in range(n - 1, -1, -1):
        for j in range(m - 1, -1, -1):
            # 终点，游戏结束
            if i == n - 1 and j == m - 1:
                dp[i][j] = 0
                continue

            # (i + j) 为偶数表示当前轮到 Alice 操作
            if (i + j) % 2 == 0:
                best = -10**18

                # 向下走
                if i + 1 < n:
                    score = 1 if grid[i + 1][j] == '1' else -1
                    best = max(best, dp[i + 1][j] + score)

                # 向右走
                if j + 1 < m:
                    score = 1 if grid[i][j + 1] == '1' else -1
                    best = max(best, dp[i][j + 1] + score)

                dp[i][j] = best

            # (i + j) 为奇数表示当前轮到 Bob 操作
            else:
                best = 10**18

                # 向下走
                if i + 1 < n:
                    score = 1 if grid[i + 1][j] == '1' else -1
                    best = min(best, dp[i + 1][j] - score)

                # 向右走
                if j + 1 < m:
                    score = 1 if grid[i][j + 1] == '1' else -1
                    best = min(best, dp[i][j + 1] - score)

                dp[i][j] = best

    return dp[0][0]

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    n, m = int(data[0]), int(data[1])
    grid = data[2:2 + n]
    print(solve(n, m, grid))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class Main {

    public static int solve(int n, int m, String[] grid) {
        // dp[i][j] 表示当前令牌在 (i,j)，从此处开始在最优策略下，
        // 最终“Alice总分 - Bob总分”的差值
        int[][] dp = new int[n][m];

        for (int i = n - 1; i >= 0; i--) {
            for (int j = m - 1; j >= 0; j--) {
                if (i == n - 1 && j == m - 1) {
                    dp[i][j] = 0;
                    continue;
                }

                // (i + j) 为偶数 -> Alice 操作
                if ((i + j) % 2 == 0) {
                    int best = Integer.MIN_VALUE;

                    // 向下走
                    if (i + 1 < n) {
                        int score = grid[i + 1].charAt(j) == '1' ? 1 : -1;
                        best = Math.max(best, dp[i + 1][j] + score);
                    }

                    // 向右走
                    if (j + 1 < m) {
                        int score = grid[i].charAt(j + 1) == '1' ? 1 : -1;
                        best = Math.max(best, dp[i][j + 1] + score);
                    }

                    dp[i][j] = best;
                }
                // (i + j) 为奇数 -> Bob 操作
                else {
                    int best = Integer.MAX_VALUE;

                    if (i + 1 < n) {
                        int score = grid[i + 1].charAt(j) == '1' ? 1 : -1;
                        best = Math.min(best, dp[i + 1][j] - score);
                    }

                    if (j + 1 < m) {
                        int score = grid[i].charAt(j + 1) == '1' ? 1 : -1;
                        best = Math.min(best, dp[i][j + 1] - score);
                    }

                    dp[i][j] = best;
                }
            }
        }

        return dp[0][0];
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String[] firstLine = br.readLine().split(" ");
        int n = Integer.parseInt(firstLine[0]);
        int m = Integer.parseInt(firstLine[1]);

        String[] grid = new String[n];
        for (int i = 0; i < n; i++) {
            grid[i] = br.readLine();
        }

        System.out.println(solve(n, m, grid));
    }
}
```

```cpp
int solve(int n, int m, const vector<string>& grid) {

    // 最终“Alice总分 - Bob总分”的差值
    vector<vector<int>> dp(n, vector<int>(m, 0));

    for (int i = n - 1; i >= 0; i--) {

                dp[i][j] = 0;
                continue;
            }

            // (i + j) 为偶数 -> Alice 操作
            if ((i + j) % 2 == 0) {
                int best = INT_MIN;

                // 向下走
                if (i + 1 < n) {
                    int score = (grid[i + 1][j] == '1' ? 1 : -1);
                    best = max(best, dp[i + 1][j] + score);
                }

                // 向右走
                if (j + 1 < m) {
                    int score = (grid[i][j + 1] == '1' ? 1 : -1);
                    best = max(best, dp[i][j + 1] + score);
                }

                dp[i][j] = best;
            }
            // (i + j) 为奇数 -> Bob 操作
            else {
                int best = INT_MAX;

                if (i + 1 < n) {

        }

}
```
