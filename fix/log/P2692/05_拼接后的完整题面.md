# 题目内容
需要把 $1$ 到 $n$ 这 $n$ 个互不相同的工号排成一个长度为 $n$ 的排列 $a_1, a_2, \ldots, a_n$，使得加权和 $\sum_{i=1}^{n} i \cdot a_i$ 能被 `3` 整除。

请构造任意一个满足条件的排列。若无解，输出 $-1$。

测试组数 $t$ 满足 $1 \le t \le 10^4$。每组的 $n$ 满足 $1 \le n \le 10^5$，且单个测试文件中所有 $n$ 之和不超过 $10^5$。

# 输入描述
第一行包含一个正整数 $t$，表示测试用例数量。
接下来 $t$ 行，每行包含一个正整数 $n$。

# 输出描述
对于每组测试用例：若无解，输出一行 $-1$；否则输出一行 $n$ 个正整数，表示构造出的排列。有多解时输出任意合法解即可。

## 样例1

**输入**

```
2
3
4
```

**输出**

```
-1
1 2 3 4
```

**说明**

$n=3$ 时不存在使 $\sum i \cdot a_i$ 被 `3` 整除的排列，输出 $-1$。$n=4$ 时恒等排列 $1^2+2^2+3^2+4^2=30$ 已被 `3` 整除。

## 样例2

**输入**

```
3
1
5
7
```

**输出**

```
-1
2 1 3 4 5
2 1 4 3 5 6 7
```

**说明**

$n=1$ 无解。$n=5$ 时恒等排列加权和模 `3` 为 `1`，交换前两个位置得到 `2 1 3 4 5`。$n=7$ 时余数为 `2`，再交换第 `3`、`4` 位得到 `2 1 4 3 5 6 7`。

## 样例3

**输入**

```
1
2
```

**输出**

```
-1
```

**说明**

$n=2$ 的全部排列加权和都不能被 `3` 整除，输出 $-1$。
