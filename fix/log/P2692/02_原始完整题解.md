# 小红的排列构造

## 思路分析

1. **问题描述**  
   给定一个正整数 n，要求构造一个 1 到 n 的排列（即每个数各出现一次），使得加权和（即所有位置 i 与该位置上数字 a[i] 的乘积之和）能被 3 整除。例如，对于排列 [1,2,3,4]，加权和为 1×1 + 2×2 + 3×3 + 4×4 = 30，30 能被 3 整除。

2. **初始排列的性质**  
   我们先考虑初始排列为顺序排列 [1,2,...,n]。此时加权和为 1² + 2² + … + n²。注意：对于任意正整数 i，其平方模 3 的值只有两种情况：
   - 当 i 能被 3 整除时，i² mod 3 = 0；
   - 否则，i² mod 3 = 1。  
   因此，顺序排列下的加权和模 3 等于 (n - floor(n/3)) mod 3，也就是所有不被 3 整除的数的个数模 3。

3. **调整方法**  
   观察交换操作对加权和的影响。假设初始排列为 [1,2,3,…,n]，如果交换位置 i 与 j（假设 i < j），原本对这两个位置的贡献分别为 i×i 和 j×j，交换后变成 i×j 和 j×i，总变化量为：
   
   ```
   Δ = [i×j + j×i] - [i×i + j×j] = 2×i×j - (i² + j²) = -(i - j)².
   ```
   
   因此，交换操作实际上使加权和减少了 (i - j)²，而 (i - j)² 模 3 的值只能为 0 或 1（因为只有当 i-j 能被 3 整除时，其平方才为 0，否则为 1）。  
   由此，我们可以根据顺序排列下加权和模 3 的余数 r 采取以下措施：
   
   - 如果 r 等于 0，则顺序排列已满足条件，直接输出。
   - 如果 r 等于 1，则只需交换前两个数（位置1和位置2）。因为 (1-2)² = 1，加权和会减少 1，从而使余数变为 0。
   - 如果 r 等于 2，则可以做两次交换：先交换位置1与位置2，再交换位置3与位置4。这样总共减少 1+1 = 2，使得加权和变为 0 模 3。
   
4. **特殊情况**  
   经过简单验证，对于 n = 1, 2, 3 均无解（所有排列加权和模 3 均不为 0），因此当 n ≤ 3 时输出 -1。

## 代码实现

**Python代码实现**

```python
def main():
    t = int(input())  # 读取测试用例数量
    for _ in range(t):
        n = int(input())
        # 对于 n <= 3，不存在满足条件的排列
        if n <= 3:
            print(-1)
            continue
        
        # 构造初始排列：1, 2, …, n
        perm = list(range(1, n + 1))
        
        # 计算顺序排列下的加权和模 3
        # 注意：对于每个 i，不被 3 整除时 i² mod 3 = 1，被 3 整除时为 0
        # 因此加权和 mod 3 = (n - floor(n/3)) mod 3
        r = (n - n // 3) % 3
        
        if r == 0:
            # 顺序排列已满足要求，无需调整
            pass
        elif r == 1:
            # 交换前两个数，位置1和位置2
            perm[0], perm[1] = perm[1], perm[0]
        else:  # r == 2
            # 先交换位置1与位置2，再交换位置3与位置4（保证 n >= 4）
            perm[0], perm[1] = perm[1], perm[0]
            perm[2], perm[3] = perm[3], perm[2]
        
        # 输出最终排列
        print(" ".join(map(str, perm)))

if __name__ == "__main__":
    main()
```

**Java代码**

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();  // 输入测试用例的数量
        while (t-- > 0) {
            int n = sc.nextInt();  // 输入n
            if (n <= 3) {
                System.out.println(-1);  // 如果n小于3，输出-1
            } else {
                int s = 0;
                // 计算加权和
                for (int i = 1; i <= n; i++) {
                    s += (i % 3) * (i % 3);
                }

                // 根据加权和的结果决定排列的顺序
                if (s % 3 == 0) {
                    // 按顺序输出1到n
                    for (int i = 1; i <= n; i++) {
                        System.out.print(i + " ");
                    }
                } else if (s % 3 == 1) {
                    // 将前两个元素交换位置
                    System.out.print("2 1 ");
                    for (int i = 3; i <= n; i++) {
                        System.out.print(i + " ");
                    }
                } else {
                    // 将前两个元素交换位置，并做一些其他调整
                    System.out.print("3 4 1 2 ");
                    for (int i = 5; i <= n; i++) {
                        System.out.print(i + " ");
                    }
                }
                System.out.println();
            }
        }
        sc.close();
    }
}
```
