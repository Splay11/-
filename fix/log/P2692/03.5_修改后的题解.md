## 解题思路

1. **目标**：构造 $1$ 到 $n$ 的排列 $a$，使 $S = \sum_{i=1}^{n} i \cdot a_i$ 能被 `3` 整除。
2. **小 $n$**：当 $n \le 3$ 时，所有排列的 $S$ 都不能被 `3` 整除，输出 $-1$。
3. **恒等排列**：先取 $a_i = i$，此时 $S = \sum i^2$。由于 $i^2 \bmod 3$ 只可能是 `0` 或 `1`（当且仅当 $3 \nmid i$ 时为 `1`），故 $S \bmod 3 = (n - \lfloor n/3 \rfloor) \bmod 3$，记为 $r$。
4. **交换修正**：交换位置 $i,j$ 会使 $S$ 减少 $(i-j)^2$，而 $(i-j)^2 \bmod 3 \in \{0,1\}$。
   - $r = 0$：恒等排列已合法。
   - $r = 1$：交换位置 `1` 与 `2`，减少量模 `3` 为 `1`。
   - $r = 2$：再额外交换位置 `3` 与 `4`（此时 $n \ge 4$），共减少 `2`。

## 复杂度分析

时间复杂度 $O(\sum n)$，每组构造并输出一个排列。空间复杂度 $O(n)$。

## 代码实现

### Python

```python
def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        if n <= 3:
            print(-1)
            continue
        perm = list(range(1, n + 1))
        r = (n - n // 3) % 3
        if r == 0:
            pass
        elif r == 1:
            perm[0], perm[1] = perm[1], perm[0]
        else:
            perm[0], perm[1] = perm[1], perm[0]
            perm[2], perm[3] = perm[3], perm[2]
        print(" ".join(map(str, perm)))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        while (t-- > 0) {
            int n = sc.nextInt();
            if (n <= 3) {
                System.out.println(-1);
            } else {
                int s = 0;
                for (int i = 1; i <= n; i++) {
                    s += (i % 3) * (i % 3);
                }
                if (s % 3 == 0) {
                    for (int i = 1; i <= n; i++) {
                        System.out.print(i + " ");
                    }
                } else if (s % 3 == 1) {
                    System.out.print("2 1 ");
                    for (int i = 3; i <= n; i++) {
                        System.out.print(i + " ");
                    }
                } else {
                    System.out.print("2 1 4 3 ");
                    for (int i = 5; i <= n; i++) {
                        System.out.print(i + " ");
                    }
                }
                System.out.println();
            }
        }
        sc.close();
    }
}
```
