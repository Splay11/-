# 题目内容
园区供水管网是一棵 $n$ 个节点、$n-1$ 条边的无向树，`1` 号节点为水源（根），第 $i$ 个节点有收益 $a_i$（可能为负）。运维规程允许在管网非空时反复修剪，以便去掉亏损支路、保留高收益骨干。只要树非空，就可以反复执行下面两类删点操作（每种都可以任意次）：

- 选择一个度数恰好为 `1` 的非根节点，删除该点及其关联边；
- 选择一个度数恰好为 `2` 的非根节点，删除该点，并将其两个邻点直接连边。

水源必须保留。请计算操作结束后，剩余节点收益之和的最大值。

约束：测试组数 $T$ 满足 $1 \le T \le 10^3$，$2 \le n \le 200000$，所有测试中 $n$ 的总和不超过 `300000`，收益满足 $|a_i| \le 1000000000$。

# 输入描述
第一行一个正整数 $T$，表示测试组数。
每组数据格式如下：
第一行一个正整数 $n$，表示节点数。
第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$，表示各节点收益。
接下来 $n-1$ 行，每行两个正整数 $u, v$，表示一条边。
保证 $1 \le T \le 10^3$，$2 \le n \le 200000$，所有测试中 $n$ 的总和不超过 `300000`，$-1000000000 \le a_i \le 1000000000$，输入构成一棵树。

# 输出描述
输出 $T$ 行，每行一个整数，表示该组数据操作后剩余收益之和的最大值。

## 样例1

**输入**

```
2
4
3 -1 5 -2
1 2
1 3
3 4
3
10 -5 -8
1 2
1 3
```

**输出**

```
8
10
```

**说明**

第一组：根权 `3`，可丢掉负权叶子，保留权为 `5` 的子节点，最大和为 `8`。
第二组：根权 `10`，两个负权儿子都应删掉，答案为 `10`。

## 样例2

**输入**

```
1
6
4 -2 3 -7 8 -1
1 2
2 3
2 4
1 5
5 6
```

**输出**

```
15
```

**说明**

保留根 `4`、其右子树上的 `8`，以及左子树中点权 `3` 的那条链，丢掉其余负权点，最大和为 $4+3+8=`15`。
