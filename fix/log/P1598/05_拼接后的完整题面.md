# 题目内容
在数字王国中，如果一个正整数的十进制表示里任意两个相邻数字都不相同，则称这个数为“流畅数”。例如，`1234` 是流畅数，而 `112` 和 `1223` 不是。

现在给定一个正整数 $N$，请你计算所有不大于 $N$ 的正整数中，流畅数的个数。由于答案可能很大，请将其对 $10^9+7$ 取模后输出。

数据范围：$N$ 的十进制位数不超过 $10^5$。

# 输入描述
输入只有一行，包含一个长度不超过 $10^5$ 的字符串，表示正整数 $N$。字符串不含前导零。

# 输出描述
输出一行一个整数，表示不大于 $N$ 的流畅数个数对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
10
```

**输出**

```
10
```

**说明**

不大于 `10` 的正整数依次为 `1` 到 `10`。其中 `10` 的十位 `1` 与个位 `0` 不同，满足流畅数定义。因此所有 `10` 个数都是流畅数，答案为 `10`。

## 样例2

**输入**

```
100
```

**输出**

```
90
```

**说明**

考虑位数：
- `1` 位数：`1` ~ `9` 共 `9` 个流畅数；
- `2` 位数：十位可取 `1` ~ `9`，个位可取 `0` ~ `9` 但不能与十位相同，共 $9 \times 9 = 81$ 个流畅数；
- `3` 位数不超过 `100` 的只有 `100` 本身，其十位与个位均为 `0`，相邻相同，不是流畅数。
因此总数为 $9 + 81 = 90$。由于答案小于 $10^9+7$，直接输出 `90`。

## 样例3

**输入**

```
123
```

**输出**

```
101
```

**说明**

先统计 `1` ~ `99` 中的流畅数：`1` 位数 `9` 个，`2` 位数 $9 \times 9 = 81$ 个，共 `90` 个。
再统计 `100` ~ `123` 中不大于 `123` 的流畅数：百位固定为 `1`，十位不能是 `1`。满足条件的数有：
- `102`, `103`, `104`, `105`, `106`, `107`, `108`, `109`（共 `8` 个）；
- `120`, `121`, `123`（注意 `122` 中十位 `2` 与个位 `2` 相同，不是流畅数。共 `3` 个）；
总计 $90 + 8 + 3 = 101$ 个。答案取模后仍为 `101`。
