## 解题思路

本题要求统计不大于 $N$ 的流畅数个数，$N$ 的位数最多可达 $10^5$，直接暴力枚举不可行，因此需要采用**数位 DP**（动态规划）来解决。

1. **状态定义**  
   定义递归函数 $dp(pos, last, isLimit, isNum)$，其中：
   - $pos$：当前构造到第 $pos$ 位数（从高位向低位，$pos$ 从 $0$ 开始）；
   - $last$：上一位选择的数字（$0\sim9$）。特别地，在还没有选择任何数字时，用 $last=0$ 作为占位（后续会通过 $isNum$ 区分）；
   - $isLimit$：布尔值，表示当前是否受到 $N$ 的限制。若为真，则当前位只能填 $0\sim s[pos]$（$s[pos]$ 为 $N$ 当前位的数字）；否则可以填 $0\sim9$；
   - $isNum$：布尔值，表示当前位之前是否已经选择了数字（是否已经是一个有效的数字前缀）。若为假，则当前位可以跳过（不选数字，继续向后构造），也可以从 $1$ 开始选数字（因为流畅数没有前导零）；若为真，则当前位可以选 $0\sim9$。

2. **状态转移**  
   对于当前位 $pos$：
   - 如果 $isNum$ 为假，可以**跳过当前位**，即不选任何数字，递归到 $dp(pos+1, last, false, false)$，相当于构造位数更短的数字；
   - 确定当前位可以填的数字上限 $up$：若 $isLimit$ 为真，则 $up = s[pos] - '0'$；否则 $up = 9$；
   - 枚举当前位填的数字 $d$：
     - 若 $isNum$ 为假，$d$ 从 $1$ 开始（避免前导零）；若 $isNum$ 为真，$d$ 可以从 $0$ 开始；
     - 必须满足 $d \ne last$，以保证相邻数字不相同（流畅数性质）；
     - 递归计算 $dp(pos+1, d, isLimit \land (d == up), true)$，并累加结果；
     - 所有累加结果对 $10^9+7$ 取模。

3. **记忆化**  
   为了降低复杂度，使用记忆化数组 $f[pos][last]$ 记录状态。只有当 $isLimit$ 为假且 $isNum$ 为真时，当前状态才与 $N$ 无关，可以缓存，避免重复计算。

4. **初始调用与答案**  
   最终答案为 $dp(0, 0, true, false)$。

## 复杂度分析

- **时间复杂度**：$O(10 \times |N|)$，其中 $|N|$ 表示 $N$ 的十进制位数。每个状态 $(pos, last)$ 的计算量是常数级别（枚举 $0\sim9$ 中的合法数字），总状态数为 $O(10 \times |N|)$，因此时间复杂度为 $O(|N|)$（因为 $10$ 是常数）。
- **空间复杂度**：$O(10 \times |N|)$，主要用于记忆化数组 $f$ 以及递归调用栈的空间。$|N| \le 10^5$，所以空间占用在可接受范围内。

## 代码实现

### Python

```python
import sys
sys.setrecursionlimit(200000)
MOD = 10**9 + 7

def solve():
    s = sys.stdin.readline().strip()
    n = len(s)
    # 记忆化数组，初始化为 -1 表示未计算
    f = [[-1] * 10 for _ in range(n)]
    
    def dp(pos, last, is_limit, is_num):
        if pos == n:
            # 构造完毕，如果已经选了数字则得到 1 个合法数字
            return 1 if is_num else 0
        
        # 当不受限制且已经选过数字时，可以取记忆化结果
        if not is_limit and is_num and f[pos][last] != -1:
            return f[pos][last]
        
        res = 0
        # 如果前面还没有数字，可以跳过当前位（相当于数字长度更短）
        if not is_num:
            res = dp(pos + 1, last, False, False)
        
        # 当前位的上限
        up = int(s[pos]) if is_limit else 9
        # 枚举当前位选的数字
        start = 1 if not is_num else 0
        for d in range(start, up + 1):
            if d != last:  # 流畅数条件：相邻数字不相同
                res = (res + dp(pos + 1, d, is_limit and (d == up), True)) % MOD
        
        # 缓存结果
        if not is_limit and is_num:
            f[pos][last] = res
        return res
    
    ans = dp(0, 0, True, False)
    print(ans)

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.Arrays;
import java.util.Scanner;

public class Main {
    static final int MOD = 1000000007;
    static int[][] f;
    static String s;
    static int n;

    static int dp(int pos, int last, boolean isLimit, boolean isNum) {
        if (pos == n) {
            return isNum ? 1 : 0;
        }
        if (!isLimit && isNum && f[pos][last] != -1) {
            return f[pos][last];
        }

        int res = 0;
        // 跳过当前位
        if (!isNum) {
            res = dp(pos + 1, last, false, false);
        }

        int up = isLimit ? s.charAt(pos) - '0' : 9;
        int start = isNum ? 0 : 1;
        for (int d = start; d <= up; d++) {
            if (d != last) { // 满足流畅数条件
                res = (res + dp(pos + 1, d, isLimit && (d == up), true)) % MOD;
            }
        }

        if (!isLimit && isNum) {
            f[pos][last] = res;
        }
        return res;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        s = sc.nextLine().trim();
        n = s.length();
        f = new int[n][10];
        for (int[] row : f) {
            Arrays.fill(row, -1);
        }
        int ans = dp(0, 0, true, false);
        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MOD = 1e9 + 7;
const int N = 1e5 + 10;

int f[N][10];
string s;
int n;

int dp(int pos, int last, bool is_limit, bool is_num) {
    if (pos == n) {
        return is_num ? 1 : 0;
    }
    if (!is_limit && is_num && f[pos][last] != -1) {
        return f[pos][last];
    }

    int res = 0;
    // 跳过当前位
    if (!is_num) {
        res = dp(pos + 1, last, false, false);
    }

    int up = is_limit ? s[pos] - '0' : 9;
    int start = is_num ? 0 : 1;
    for (int d = start; d <= up; ++d) {
        if (d != last) { // 满足流畅数条件
            res = (res + dp(pos + 1, d, is_limit && (d == up), true)) % MOD;
        }
    }

    if (!is_limit && is_num) {
        f[pos][last] = res;
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> s;
    n = s.size();
    memset(f, -1, sizeof(f));
    int ans = dp(0, 0, true, false);
    cout << ans << '\n';
    return 0;
}
```
