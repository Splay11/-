## 解题思路

本题可以看作一个 **步长不断变化的约瑟夫环** 问题。

- 所有人围成一圈，从 $1$ 开始依次报数。当报到“纯净数”时，该人被淘汰。
- 由定义可知，纯净数就是素数。令第 $i$ 个纯净数为 $p_i$（$p_1=2,\ p_2=3,\ p_3=5,\ p_4=7,\ \dots$）。
- 第一次淘汰发生在报到 $2$ 时，相当于从第 $1$ 个人开始走了 $2$ 步，因此第一次的淘汰步长 $k_1 = 2$。
- 第二次淘汰发生在报到 $3$ 时，距离上一次多走了 $1$ 步，所以第二次步长 $k_2 = 3-2 = 1$。
- 第三次淘汰发生在报到 $5$ 时，步长 $k_3 = 5-3 = 2$，依此类推。

于是淘汰步长序列为相邻纯净数之差，并将第一个步长写作 $p_1-0=2$：

$$
k_1,\ k_2,\ k_3,\ \dots = 2,\ 1,\ 2,\ 2,\ 4,\ \dots
$$

对于共有 $n$ 个人的情况，一共需要 $n-1$ 次淘汰，因此需要前 $n-1$ 个步长。

---

采用 **约瑟夫环递推** 求解最终幸存者：

- 设 $f(m)$ 表示当前有 $m$ 个人时，最后幸存者的下标（下标从 $0$ 开始）。
- 正向淘汰时，第一次使用步长 $k_1$，第二次使用 $k_2$，……；而递推时是从 $1$ 个人反推回 $n$ 个人，因此步长的使用顺序是倒过来的。
- 递推式：$f(1)=0$，对于 $m=2,3,\dots,n$：
  $$
  f(m) = (f(m-1) + k_{n-m+1}) \bmod m
  $$
  代码实现中，我们将步长依次存入数组 `steps[0..n-2]`，然后在递推时使用 `steps[n - m]`。

---

算法步骤：
1. 生成前 $n-1$ 个纯净数（用试除法检验素数）；
2. 计算相邻纯净数之差，得到步长数组；
3. 用上述递推式计算最终幸存者的 $0$ 基准下标；
4. 将下标 $+1$ 转换为题目要求的初始编号（编号从 $1$ 开始）。  
  当 $n=1$ 时，无需淘汰，直接输出 $1$。

## 复杂度分析

设第 $n-1$ 个纯净数约为 $p$。

- 生成前 $n-1$ 个纯净数时，对每个候选数使用试除法，检查 $[2,\sqrt{x}]$ 内的整除性。时间复杂度约为 $O(p\sqrt{p})$，在 $n\le 10^4$ 的范围下完全可行。
- 约瑟夫环递推只需一重循环，时间复杂度 $O(n)$。
- 总时间复杂度为 $O(p\sqrt{p} + n)$。

空间复杂度：需要存储 $n-1$ 个纯净数及步长，为 $O(n)$。

## 代码实现

### Python

```python
def get_answer(n):
    # 只有 1 个人时，答案就是 1
    if n == 1:
        return 1

    pure_nums = []
    x = 2

    # 求前 n-1 个纯净数
    while len(pure_nums) < n - 1:
        ok = True
        i = 2
        while i * i <= x:
            if x % i == 0:
                ok = False
                break
            i += 1
        if ok:
            pure_nums.append(x)
        x += 1

    # 构造步长数组（相邻纯净数之差）
    steps = []
    prev = 0
    for p in pure_nums:
        steps.append(p - prev)
        prev = p

    # 约瑟夫环递推，f 表示 0 下标答案
    f = 0
    for m in range(2, n + 1):
        f = (f + steps[n - m]) % m

    return f + 1


def main():
    n = int(input())
    print(get_answer(n))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    // 计算最终留下来的编号
    public static int getAnswer(int n) {
        // 只有 1 个人时，答案就是 1
        if (n == 1) {
            return 1;
        }

        int[] pure_nums = new int[n - 1];
        int count = 0;
        int x = 2;

        // 求前 n-1 个纯净数
        while (count < n - 1) {
            boolean ok = true;
            for (int i = 2; i * i <= x; i++) {
                if (x % i == 0) {
                    ok = false;
                    break;
                }
            }
            if (ok) {
                pure_nums[count++] = x;
            }
            x++;
        }

        // 构造步长数组
        int[] steps = new int[n - 1];
        int prev = 0;
        for (int i = 0; i < n - 1; i++) {
            steps[i] = pure_nums[i] - prev;
            prev = pure_nums[i];
        }

        // 约瑟夫环递推，f 表示 0 下标答案
        int f = 0;
        for (int m = 2; m <= n; m++) {
            f = (f + steps[n - m]) % m;
        }

        return f + 1;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        System.out.println(getAnswer(n));
    }
}
```

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 计算最终留下来的编号
int getAnswer(int n) {
    // 只有 1 个人时，答案就是 1
    if (n == 1) {
        return 1;
    }

    vector<int> pure_nums;
    int x = 2;

    // 求前 n-1 个纯净数
    while ((int)pure_nums.size() < n - 1) {
        bool ok = true;
        for (int i = 2; i * i <= x; i++) {
            if (x % i == 0) {
                ok = false;
                break;
            }
        }
        if (ok) {
            pure_nums.push_back(x);
        }
        x++;
    }

    // 构造步长数组
    vector<int> steps;
    int prev = 0;
    for (int p : pure_nums) {
        steps.push_back(p - prev);
        prev = p;
    }

    // 约瑟夫环递推，f 表示 0 下标答案
    int f = 0;
    for (int m = 2; m <= n; m++) {
        f = (f + steps[n - m]) % m;
    }

    return f + 1;
}

int main() {
    int n;
    cin >> n;
    cout << getAnswer(n) << endl;
    return 0;
}
```
