# 题目内容
有一条长度为 $n$ 的能量带 $a_1, a_2, \ldots, a_n$。若从位置 $x$ 出发，初始区间为 $[x,x]$，初始收获为 $a_x$。每次可以把当前区间向左或向右扩展一格（不能越界），且被并入位置上的值必须严格大于当前收获之和；并入后，收获加上该位置的值。

请对每个起点 $x=1,2,\ldots,n$ 分别求出能达到的最大收获。

能量带长度不超过 `10^5`，每个位置的值不超过 `10^9`。

# 输入描述
第一行一个正整数 $n$（$1 \le n \le 10^5$），表示能量带长度。
第二行 $n$ 个正整数 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 10^9$）。

# 输出描述
输出一行 $n$ 个整数，依次表示从每个起点出发能达到的最大收获。

## 样例1

**输入**

```
1
7
```

**输出**

```
7
```

**说明**

只有一个位置，无法向两侧扩展，答案就是该位置本身的值 `7`。

## 样例2

**输入**

```
1
8
```

**输出**

```
8
```

**说明**

按题意模拟计算得到。

**输入**

```
1
9
```

**输出**

```
9
```

**说明**

按题意模拟计算得到。
