# 题目内容
在一个自动化检测系统中，需要对 $n$ 个待检项进行标记比对。每个标记由字母 `W`、`X`、`Y`、`Z` 组成的字符串表示，长度介于 $1$ 到 $4$ 之间。

对于第 $i$ 项，已知系统给出的实际标记 $s_i$ 与预设的期望标记 $t_i$。计分规则如下：
- 若 $s_i$ 与 $t_i$ 完全相同，则该项得 $3$ 分；
- 若 $s_i$ 中的每个字母均在 $t_i$ 中出现过，且 $t_i$ 的长度严格大于 $s_i$，则得 $1$ 分；
- 其余情况得 $0$ 分。

试计算所有项的总得分。

约束：项数 $n$ 不超过 $10^4$，每个字符串仅由 `W`、`X`、`Y`、`Z` 构成，长度在 $1$ 到 $4$ 之间。

# 输入描述
第一行包含一个整数 $n$，表示待检项的数量。
第二行包含 $n$ 个由空格分隔的字符串，依次表示每一项的实际标记 $s_i$。
第三行包含 $n$ 个由空格分隔的字符串，依次表示每一项的期望标记 $t_i$。
每个字符串仅由大写字母 `W`、`X`、`Y`、`Z` 组成，长度在 $1$ 到 $4$ 之间。

# 输出描述
输出一个整数，表示所有项的总得分。

## 样例1

**输入**

```
4
W X Y Z
W XX YZ X
```

**输出**

```
5
```

**说明**

共有 `4` 组标记对：

- 第 `1` 组：$s_1 = \text{W}$，$t_1 = \text{W}$，两者完全相同，得 `3` 分；
- 第 `2` 组：$s_2 = \text{X}$，$t_2 = \text{XX}$。$s_2$ 的每个字母均在 $t_2$ 中出现，且 $t_2$ 的长度 $2$ 严格大于 $s_2$ 的长度 $1$，得 `1` 分；
- 第 `3` 组：$s_3 = \text{Y}$，$t_3 = \text{YZ}$。$s_3$ 的字母 $\text{Y}$ 在 $t_3$ 中出现，且 $t_3$ 的长度 $2$ 大于 $s_3$ 的长度 $1$，得 `1` 分；
- 第 `4` 组：$s_4 = \text{Z}$，$t_4 = \text{X}$。$s_4$ 的字母 $\text{Z}$ 未在 $t_4$ 中出现，属于其余情况，得 `0` 分。

总分为 $3 + 1 + 1 + 0 = 5$。

## 样例2

**输入**

```
3
WXYZ WXY W
WXYZ WXYZ X
```

**输出**

```
4
```

**说明**

共有 `3` 组标记对：

- 第 `1` 组：$s_1 = \text{WXYZ}$，$t_1 = \text{WXYZ}$，两者完全相同，得 `3` 分；
- 第 `2` 组：$s_2 = \text{WXY}$，$t_2 = \text{WXYZ}$。$s_2$ 中的所有字母 $\text{W}, \text{X}, \text{Y}$ 均出现在 $t_2$ 中，且 $t_2$ 的长度 $4$ 严格大于 $s_2$ 的长度 $3$，得 `1` 分；
- 第 `3` 组：$s_3 = \text{W}$，$t_3 = \text{X}$。$s_3$ 的字母 $\text{W}$ 不在 $t_3$ 中，得 `0` 分。

总分为 $3 + 1 + 0 = 4$。

## 样例3

**输入**

```
1
Z
Z
```

**输出**

```
3
```

**说明**

只有 `1` 组标记对：$s_1 = \text{Z}$，$t_1 = \text{Z}$，两者完全相同，得 `3` 分。

这是一个简单的边界情况，总分为 $3$。
