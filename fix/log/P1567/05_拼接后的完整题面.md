# 题目内容
$n$ 名测试员初始疲劳 $0$，上限 $a_i$。$m$ 次测试，第 $i$ 次给区间 $[l,r]$ 每人 $+1$。若有人严格超过上限则停在第 $i-1$ 版；否则用第 $m$ 版。初始为第 $0$ 版。

$1 \le n,m \le 10^5$，$0 \le a_i \le 10^5$。

# 输入描述
第一行 $n,m$。第二行 $n$ 个 $a_i$。接下来 $m$ 行每行 $l,r$。

# 输出描述
一个整数，最终版本号。

## 样例1

**输入**

```
4 5
1 2 1 3
1 2
2 4
1 3
3 4
1 4
```

**输出**

```
2
```

**说明**

按题意模拟计算得到。
