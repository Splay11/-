## 解题思路

我们需要构造一个最短的字符串，使得其中包含至少 $T$ 个与 $P$ 完全相同的连续子串。为了让总长度尽可能短，可以让相邻的 $P$ 尽可能多地重叠在一起。重叠的部分其实就是 $P$ 的某个后缀与它相同长度的前缀完全一致的部分，也就是说，重叠长度等于 $P$ 的最长相等前后缀（不能是整个字符串本身）。

记 $n$ 为字符串 $P$ 的长度，$k$ 为 $P$ 的最长相等前后缀的长度（$k < n$）。那么：

- 第一个 $P$ 占据长度 $n$；
- 之后每多一个 $P$，由于可以与前一个 $P$ 共享长度为 $k$ 的前后缀，实际增加的长度为 $n - k$；
- 要出现 $T$ 个 $P$，总长度最小为：
  \[
  \text{ans} = n + (T - 1) \times (n - k)
  \]

因此，关键在于求出最大的 $k$。由于 $n \le 1000$，我们可以直接暴力枚举前缀长度 $len$ 从 $1$ 到 $n-1$，比较前缀 $P[0:len]$ 与后缀 $P[n-len:n]$ 是否相等，相等则更新答案。最后带入公式计算即可。

注意 $T$ 最大可达 $10^9$，计算结果可能超过 32 位整数范围，需要使用 64 位整数（C++ 用 `long long`，Java 用 `long`，Python 整数不限）。

## 复杂度分析

- **时间复杂度**：枚举前缀长度是 $O(n)$，每次比较子串需要 $O(len)$，因此最坏时间复杂度为 $O(n^2)$。在 $n \le 1000$ 的范围内完全可行。
- **空间复杂度**：除了存储字符串 $P$ 外，只使用了少量额外变量，空间复杂度为 $O(n)$。若采用索引比较可以优化到 $O(1)$，但暴力取子串同样满足限制。

## 代码实现

### Python

```python
# 读取字符串 P 和整数 T
P = input().strip()
T = int(input())

n = len(P)
k = 0  # 最长相等前后缀的长度

# 枚举可能的前后缀长度
for length in range(1, n):
    pre = P[:length]
    suf = P[n - length:]
    if pre == suf:
        k = length  # 相等则记录更长的长度

# 最短充分序列长度公式
ans = n + (T - 1) * (n - k)
print(ans)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String P = scanner.next();
        long T = scanner.nextInt();   // T 可能很大，使用 long

        int n = P.length();
        long k = 0;                   // 最长相等前后缀的长度

        // 枚举前缀长度 1 到 n-1
        for (int len = 1; len < n; len++) {
            String pre = P.substring(0, len);
            String suf = P.substring(n - len);
            if (pre.equals(suf)) {
                k = len;              // 更新为更长的长度
            }
        }

        // 计算最短充分序列长度并输出
        long ans = n + (T - 1) * (n - k);
        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
using namespace std;
typedef long long ll;

int main() {
    string P;
    ll T;
    cin >> P >> T;

    int n = P.size();
    ll k = 0;  // 最长相等前后缀的长度

    // 枚举可能的前后缀长度
    for (int len = 1; len < n; len++) {
        string pre = P.substr(0, len);
        string suf = P.substr(n - len);
        if (pre == suf) {
            k = len; // 记录更长的长度
        }
    }

    // 最短充分序列长度 = n + (T-1) * (n - k)
    ll ans = n + (T - 1) * (n - k);
    cout << ans << endl;

    return 0;
}
```
