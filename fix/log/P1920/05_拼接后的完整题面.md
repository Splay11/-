# 题目内容
对于一个只包含小写字母的字符串 $P$，如果某个字符串中存在至少 $T$ 个与 $P$ 完全相同的连续子串（允许这些子串的起始位置不同），则称该字符串是 $P$ 的“充分序列”。

现在给定 $P$ 和 $T$，请你求出 $P$ 的最短充分序列的长度。

约束条件：
- 字符串 $P$ 的长度不超过 $1000$。
- 整数 $T$ 满足 $2 \le T \le 10^9$。

# 输入描述
输入共两行。
第一行包含一个只由小写字母组成的字符串 $P$，长度不超过 $1000$。
第二行包含一个整数 $T$，表示需要出现的最少次数，满足 $2 \le T \le 10^9$。

# 输出描述
输出一个整数，表示 $P$ 的最短充分序列的长度。

## 样例1

**输入**

```
a
5
```

**输出**

```
5
```

**说明**

字符串 $P$ 为 `"a"`，长度 $|P| = 1$。需要出现至少 $T = 5$ 次。由于每个字符都可以作为 $P$ 的起始，最简单的构造是连续重复 `5` 个 `"a"` 得到 `"aaaaa"`。其长度为 `5`，且不可能更短。因此最短充分序列的长度为 `5`。

## 样例2

**输入**

```
abc
2
```

**输出**

```
6
```

**说明**

字符串 $P$ 为 `"abc"`，长度 $|P| = 3$，需要出现 $T = 2$ 次。

检查 $P$ 的前后缀重叠情况：`"abc"` 没有任何非空真前缀等于非空真后缀，重叠长度为 $0$。因此两个子串无法共享任何字符，必须完整拼接，构造为 `"abcabc"`。长度 $= |P| \times T = 3 \times 2 = 6$。这是最短的可能。

## 样例3

**输入**

```
aba
3
```

**输出**

```
7
```

**说明**

字符串 $P$ 为 `"aba"`，长度 $|P| = 3$，需要出现 $T = 3$ 次。

`"aba"` 的最长公共前后缀为 `"a"`，重叠长度 $= 1$。利用重叠可以缩短总长度。构造序列 `"abababa"`，其中 $P$ 出现的位置为 $0, 2, 4$，共计 $3$ 次。

总长度计算公式为 $|P| + (|P| - \text{重叠长度}) \times (T - 1) = 3 + (3 - 1) \times 2 = 7$。因此最短充分序列长度为 `7`。

## 样例4

**输入**

```
aaaa
3
```

**输出**

```
6
```

**说明**

字符串 $P$ 为 `"aaaa"`，长度 $|P| = 4$，需要出现 $T = 3$ 次。

`"aaaa"` 的最长公共前后缀为 `"aaa"`，重叠长度 $= 3$。构造序列 `"aaaaaa"`，出现位置为 $0,1,2$，共 $3$ 次。

总长度 $= |P| + (|P| - \text{重叠长度}) \times (T - 1) = 4 + (4 - 3) \times 2 = 6$。
