## 解题思路

题目中的交换操作只能作用于奇数编号的列 $j$（$1\le j < n$），且只能交换“左上↔右下”或“右上↔左下”的对角元素。因为 $j$ 为奇数时，其相邻列 $j+1$ 为偶数，交换仅发生在第 $j$ 列与第 $j+1$ 列之间，且两种交换互不影响。因此整个 $2\times n$ 的网格可以被划分为若干个独立的 $2\times2$ 小块：

- 第 $1$ 块：列 $1,2$
- 第 $2$ 块：列 $3,4$
- ……

对于每个小块，四个格子分别记为：

```
a[1][j]   a[1][j+1]
a[2][j]   a[2][j+1]
```

其中 $j$ 为奇数。

1. **路径特征**  
从 $(1,1)$ 出发，每次只能向右或向下，最终到达 $(2,n)$。由于只有两行，路径必须恰好向下移动一次。也就是说，路径形状为：先在第 $1$ 行向右走若干格，然后向下到第 $2$ 行，再继续向右走到终点。因此，答案的关键是选择在哪个位置向下。

2. **小块贡献分析**  
对于一个小块（列 $j$ 和 $j+1$，$j$ 为奇数），路径与该块的关系只有两种：

   - **情况一：不在该块内向下**  
     若路径经过该块时已经处于某一行（全部在上方或全部在下方），通过交换可以让行内经过的两个格子尽可能大：  
     - 若只在第 $1$ 行，可令左格取 $\max(a_{1,j}, a_{2,j+1})$，右格取 $\max(a_{1,j+1}, a_{2,j})$；  
     - 若只在第 $2$ 行，同理贡献相同。  
     因此这一块的“普通经过”贡献为  
     $$S_j = \max(a_{1,j},\ a_{2,j+1}) + \max(a_{1,j+1},\ a_{2,j}).$$

   - **情况二：在该块内向下**  
     无论向下发生在左列还是右列，路径一定会经过左上角 $a_{1,j}$ 和右下角 $a_{2,j+1}$ 这一条对角线，而另一条对角线中只能再选一个较大值 $\max(a_{1,j+1}, a_{2,j})$。此时该块贡献为  
     $$T_j = a_{1,j} + a_{2,j+1} + \max(a_{1,j+1}, a_{2,j}).$$  
     与情况一相比，多出的增量恰好为  
     $$T_j - S_j = \min(a_{1,j},\ a_{2,j+1}).$$  
     也就是说，若选择在第 $j$ 个小块内向下，可以额外获得 $\min(a_{1,j}, a_{2,j+1})$ 的收益。

3. **整体答案构造**  
   令 $\text{base} = \sum_{j\text{ 奇数}} S_j$，即所有小块按“不在该块内向下”处理的总和。  
   维护 $\text{best} = \max_{j\text{ 奇数}} \min(a_{1,j},\ a_{2,j+1})$，表示选择某个小块向下时的最大增量。

   - 若 $n=1$，只有一列，无法交换，路径只能从 $(1,1)$ 向下到 $(2,1)$，答案为 $a_{1,1}+a_{2,1}$。
   - 若 $n$ 为偶数，全部由完整小块组成，且必须在一个小块内向下，答案为 $\text{base} + \text{best}$。
   - 若 $n$ 为奇数，前面有 $\frac{n-1}{2}$ 个完整小块，最后一列（第 $n$ 列）单独存在，无法参与交换。此时有两种向下选择：
     * 在前面的某个小块内向下：则最后一列只能经过下方的格子 $a_{2,n}$，答案 = $\text{base} + a_{2,n} + \text{best}$。
     * 在最后一列直接向下：则最后一列可以同时拿到上下两个格子 $a_{1,n}+a_{2,n}$，相当于在情况一的基础上额外多取一个 $a_{1,n}$。  
     因此奇数情况的总答案为  
     $$\text{base} + a_{2,n} + \max(\text{best},\ a_{1,n}).$$

4. **算法流程**  
   - 特判 $n=1$ 的情况。
   - 初始化 $\text{base}=0$，$\text{best}=0$。
   - 遍历所有奇数 $j$（$1\le j < n$），累加 $\max(a_{1,j}, a_{2,j+1}) + \max(a_{1,j+1}, a_{2,j})$ 到 $\text{base}$，同时用 $\min(a_{1,j}, a_{2,j+1})$ 更新 $\text{best}$。
   - 根据 $n$ 的奇偶性代入公式得到最终答案。
   - 整个过程只需一次线性扫描。

## 复杂度分析

- **时间复杂度**：$O(n)$。对于每组数据，只需要遍历所有奇数索引列一次，计算贡献和更新最大值。所有测试数据的 $n$ 总和不超过 $2\times 10^5$，因此总体时间为 $O(\sum n)$，非常高效。
- **空间复杂度**：$O(1)$ 额外空间（不计输入存储）。只使用了常数个变量维护中间结果。

## 代码实现

### Python

```python
import sys

def solve_case(n, row0, row1):
    # 只有一列，无法进行任何交换，路径直接向下
    if n == 1:
        return row0[0] + row1[0]

    base = 0           # 所有完整 2x2 块按“普通经过”的贡献和
    best_extra = 0     # 选择在某一块向下时的最大额外收益

    # 遍历每一对奇数列 j（在代码中下标从 0 开始，j 为偶数对应题面奇数）
    for j in range(0, n - 1, 2):
        # 普通经过：上下两个可能位置取较大值
        base += max(row0[j], row1[j + 1]) + max(row0[j + 1], row1[j])
        # 向下经过的增量：左上和右下之间取较小值
        best_extra = max(best_extra, min(row0[j], row1[j + 1]))

    # n 为偶数，一定在某个小块内向下
    if n % 2 == 0:
        return base + best_extra

    # n 为奇数，最后一列单独处理
    # 可以选择在前面某块向下，或直接在最后一列向下
    return base + row1[n - 1] + max(best_extra, row0[n - 1])

def main():
    input = sys.stdin.readline
    t = int(input().strip())
    out = []
    for _ in range(t):
        n = int(input().strip())
        row0 = list(map(int, input().split()))
        row1 = list(map(int, input().split()))
        out.append(str(solve_case(n, row0, row1)))
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;
import java.util.StringTokenizer;

public class Main {
    static long solveCase(int n, long[] row0, long[] row1) {
        if (n == 1) {
            return row0[0] + row1[0];
        }
        long base = 0;
        long bestExtra = 0;
        for (int j = 0; j + 1 < n; j += 2) {
            base += Math.max(row0[j], row1[j + 1]) + Math.max(row0[j + 1], row1[j]);
            bestExtra = Math.max(bestExtra, Math.min(row0[j], row1[j + 1]));
        }
        if (n % 2 == 0) {
            return base + bestExtra;
        }
        return base + row1[n - 1] + Math.max(bestExtra, row0[n - 1]);
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        int t = Integer.parseInt(br.readLine().trim());
        while (t-- > 0) {
            int n = Integer.parseInt(br.readLine().trim());
            long[] row0 = new long[n];
            long[] row1 = new long[n];
            StringTokenizer st = new StringTokenizer(br.readLine());
            for (int i = 0; i < n; ++i) row0[i] = Long.parseLong(st.nextToken());
            st = new StringTokenizer(br.readLine());
            for (int i = 0; i < n; ++i) row1[i] = Long.parseLong(st.nextToken());
            sb.append(solveCase(n, row0, row1)).append('\n');
        }
        System.out.print(sb);
    }
}
```
