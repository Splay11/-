# 题目内容
仓库里有 $n$ 件待分装的货物，第 $i$ 件货物的规格编号为 $a_i$。管理员需要把这些货物放到若干托盘上。

同一托盘内不允许出现规格编号相同的两件货物，并且每个托盘上至多放置 $k$ 件货物。货物之间没有先后顺序限制。

请计算至少需要多少个托盘才能装完所有货物。

货物件数 $n$ 与单托盘容量 $k$ 均满足 $1 \le n,k \le 10^5$。每个规格编号 $a_i$ 满足 $1 \le a_i \le 10^9$。

# 输入描述
第一行包含两个整数 $n$ 和 $k$，分别表示货物件数和单个托盘最多可放置的件数。
第二行包含 $n$ 个整数，第 $i$ 个数为 $a_i$，表示第 $i$ 件货物的规格编号。

# 输出描述
输出一个整数，表示最少需要的托盘个数。

## 样例1

**输入**

```
3 1
2 2 1
```

**输出**

```
3
```

**说明**

共有 `3` 件货物，单托盘容量 $k=1$。每个托盘只能放 `1` 件，因此至少需要 `3` 个托盘。规格频次最大为 `2`，不超过容量下界，答案为 `3`。

## 样例2

**输入**

```
3 2
2 2 1
```

**输出**

```
2
```

**说明**

货物规格为 `2,2,1`，最大频次为 `2`（规格 `2` 出现两次，必须分到不同托盘）。容量下界为 $\lceil 3/2 \rceil=2$。取二者最大值，答案为 `2`。一种方案是：托盘一放规格 `2` 与 `1`，托盘二放另一件规格 `2`。

## 样例3

**输入**

```
1 1
7
```

**输出**

```
1
```

**说明**

只有 `1` 件货物，容量 $k=1$，一个托盘即可装完，答案为 `1`。

## 样例4

**输入**

```
5 3
1 1 1 2 3
```

**输出**

```
3
```

**说明**

规格 `1` 出现 `3` 次，最大频次为 `3`；容量下界 $\lceil 5/3 \rceil=2$。答案取最大值 `3`。
