## 解题思路

1. **问题转化**：同一托盘不能放两件规格相同的货物，因此同规格货物必须分到不同托盘。同时每个托盘最多放 $k$ 件，因此托盘数还要能装下全部 $n$ 件货物。
2. **频率瓶颈**：统计每个规格编号出现的次数，记最大频次为 $\textit{maxFreq}$。同规格货物必须各占一行托盘，所以至少需要 $\textit{maxFreq}$ 个托盘。
3. **容量瓶颈**：每个托盘最多 $k$ 件，装完 $n$ 件至少需要 $\lceil n/k \rceil = \lfloor (n+k-1)/k \rfloor$ 个托盘。
4. **取最大值**：上述两个下界都可以同时达到（按规格轮流放入不同托盘即可），因此答案为 $\max(\textit{maxFreq},\lceil n/k \rceil)$。

## 复杂度分析

- **时间复杂度**：$O(n)$。一次扫描统计频率并求最大值。
- **空间复杂度**：$O(n)$。哈希表存储各规格的出现次数，最坏情况每种规格各出现一次。

## 代码实现

### Python

```python
from collections import Counter

def min_trays(n, k, a):
    freq = Counter(a)
    max_freq = max(freq.values())
    rows_by_k = (n + k - 1) // k
    return max(max_freq, rows_by_k)

n, k = map(int, input().split())
a = list(map(int, input().split()))
print(min_trays(n, k, a))
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int k = scanner.nextInt();
        Map<Integer, Integer> freq = new HashMap<>();
        for (int i = 0; i < n; i++) {
            int x = scanner.nextInt();
            freq.put(x, freq.getOrDefault(x, 0) + 1);
        }
        int maxFreq = 0;
        for (int value : freq.values()) {
            maxFreq = Math.max(maxFreq, value);
        }
        int rowsByK = (n + k - 1) / k;
        System.out.println(Math.max(maxFreq, rowsByK));
        scanner.close();
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    unordered_map<int, int> freq;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        freq[x]++;
    }
    int maxFreq = 0;
    for (auto &p : freq) {
        maxFreq = max(maxFreq, p.second);
    }
    int rowsByK = (n + k - 1) / k;
    cout << max(maxFreq, rowsByK) << "\n";
    return 0;
}
```
