# 题目内容

小红正在练字，一共有n个字，第$i$个字的笔画数为$a_i$，文字之前没有顺序要求。

现在小红准备将$n$个字分成若干行来写，小红认为同一行中如果存在两个笔画数一样的字会感觉到厌

同时每行的数字个数不能超过$k$个，请问现在至少需要分成多少行。



# 输入描述

第一行两个整数$n,k(1≤n≤10^5,1≤k≤10^5)$ 表示字数和单行限制总数。

第二行$n$个整数，第$i$个数为$a_i(1≤a_i≤10^9)$表示字的笔画数

# 输出描述

一个整数，表示最少需要写的行数



## 样例1 

**输入** 

```
3 1
2 2 1
```

**输出** 

```
3
```



## 样例2

**输入** 

```
3 2
2 2 1
```

**输出** 

```
2
```
