# 题目内容
考古学家发现了两段古老的铭文，现在需要找出它们之间连续相同的最长文字片段，以推测它们的共同起源。

给定两个文本序列 $S$ 和 $T$，请你找出它们最长的公共连续片段。题目保证这样的最长连续片段存在且唯一。

两个文本序列的长度均不小于 $1$ 且小于 $5000$。

# 输入描述
输入仅有一行，包含两个使用英文双引号括起并以逗号分隔的字符串，分别表示文本序列 $S$ 和 $T$。

# 输出描述
输出一行，包含一个被英文双引号括起的字符串，表示这两个文本序列的最长公共连续片段。

## 样例1

**输入**

```
"programming","programmer"
```

**输出**

```
"programm"
```

**说明**

$S$ 为 `"programming"`，$T$ 为 `"programmer"`。两串的最长公共前缀为 `"programm"`，长度为 `8`，且该片段在各自序列中唯一最长的连续公共部分，因此输出 `"programm"`。

## 样例2

**输入**

```
"x","x"
```

**输出**

```
"x"
```

**说明**

两个文本序列长度均为 `1` 且内容相同，因此最长公共连续片段即为该字符本身 `"x"`。

## 样例3

**输入**

```
"OpenAI","OpenAI"
```

**输出**

```
"OpenAI"
```

**说明**

两个文本序列完全一致，因此最长公共连续片段就是整个字符串 `"OpenAI"`，长度为 `6`。
