# 题目内容
一块 $n$ 行 $m$ 列的信号面板上，每个格子是一个非负整数，但格子里的数值已经丢失。只留下了每一行所有格子的按位异或结果，以及每一列所有格子的按位异或结果。

请判断能否还原出一块面板，使得第 $i$ 行所有格子的按位异或等于给定的行校验值 $r_i$，第 $j$ 列所有格子的按位异或等于给定的列校验值 $c_j$。若可以还原，给出任意一种合法填法；否则报告无法还原。

行数和列数均不超过 `1000`。行校验值与列校验值均为不超过 `10^9` 的非负整数。可以证明，若存在解，则一定存在所有格子均不超过 `10^{18}` 的填法。若有多种合法填法，输出其中任意一种即可。

# 输入描述
第一行包含两个整数 $n$ 和 $m$（$1 \le n,m \le 1000$），表示面板的行数与列数。
第二行包含 $n$ 个整数 $r_1, r_2, \ldots, r_n$（$0 \le r_i \le 10^9$），依次表示每一行的按位异或校验值。
第三行包含 $m$ 个整数 $c_1, c_2, \ldots, c_m$（$0 \le c_j \le 10^9$），依次表示每一列的按位异或校验值。

# 输出描述
若无法还原，输出一行 `NO`。
若可以还原，第一行输出 `YES`，随后输出 $n$ 行，每行 $m$ 个整数，表示一种合法的面板填法，每个格子的值应满足 $0 \le \mathrm{val} \le 10^{18}$。

## 样例1

**输入**

```
3 3
0 7 6
2 15 12
```

**输出**

```
YES
3 15 12
7 0 0
6 0 0
```

**说明**

全体行校验值的异或为 $0 \oplus 7 \oplus 6=`1`$，全体列校验值的异或为 $2 \oplus 15 \oplus 12=`1`$，二者相等，因此有解。
一种构造是：除第 `1` 行与第 `1` 列外均填 `0`，第 `1` 列（除左上角）填对应行校验，第 `1` 行（除左上角）填对应列校验，再反推左上角为 `3`。验证三行异或分别为 `0`、`7`、`6`，三列异或分别为 `2`、`15`、`12`。

## 样例2

**输入**

```
1 1
5
5
```

**输出**

```
YES
5
```

**说明**

只有 `1` 行 `1` 列时，格子本身必须同时等于行校验与列校验。二者都是 `5`，填入 `5` 即可。

## 样例3

**输入**

```
1 2
3
1 1
```

**输出**

```
NO
```

**说明**

唯一一行的校验值为 `3`，两列校验值的异或为 $1 \oplus 1=`0`$。行列总异或不相等，不存在任何填法。

## 样例4

**输入**

```
2 2
1 2
3 0
```

**输出**

```
YES
1 0
2 0
```

**说明**

行校验异或 $1 \oplus 2=`3`$，列校验异或 $3 \oplus 0=`3`$，有解。构造得到矩阵第一列为 `1`、`2`，其余为 `0`，满足各行列校验。
