# 题目内容
有 $n$ 个盒子排成一行，从左到右编号为 $1$ 到 $n$。初始时，第 $i$ 个盒子中放有数字 $i$。

接下来，按照步长 $d$ 从 $1$ 到 $n$ 依次执行以下操作：
找到所有盒子编号为 $d$ 的倍数的盒子，将这些盒子当前的数字按照盒子编号从小到大的顺序取出，形成一个序列。如果序列长度不小于 $2$，则将该序列向右循环移动一位（即序列最后一个数字移动到第一个位置，其余数字依次后移一位），然后将移动后的数字按原顺序放回这些盒子中；如果序列长度不足 $2$，则不做任何改动。

请你计算所有操作完成后，每个盒子中的数字是多少。

数据范围：$n$ 是一个整数，满足 $1 \le n \le 10^5$。

# 输入描述
第一行包含一个整数 $n$，表示盒子的数量。

# 输出描述
输出一行，包含 $n$ 个整数，第 $i$ 个整数表示最终第 $i$ 个盒子中的数字。整数之间用空格分隔。

## 样例1

**输入**

```
1
```

**输出**

```
1
```

**说明**

只有 `1` 个盒子，初始数字为 `1`。对于任意步长 $d$，被选中的盒子数量均不超过 `1`，不满足长度不小于 `2` 的条件，因此不进行任何操作。最终盒子中的数字仍为 `1`。

## 样例2

**输入**

```
3
```

**输出**

```
3 1 2
```

**说明**

初始时盒子内的数字为 `1 2 3`。

步长 $d = 1$：选中所有盒子，取出数字序列 $[1,2,3]$，向右循环移动一位得到 $[3,1,2]$，放回后盒子数字变为 `3 1 2`。

步长 $d = 2$：选中盒子编号为 $2$ 的倍数的盒子（即盒子 `2`），取出数字为 `1`，序列长度不足 `2`，不做操作。

步长 $d = 3$：选中盒子 `3`，取出数字为 `2`，长度不足 `2`，不做操作。

最终结果为 `3 1 2`。

## 样例3

**输入**

```
6
```

**输出**

```
6 5 3 1 4 2
```

**说明**

初始序列为 `1 2 3 4 5 6`。

步长 $d = 1$：全选并循环右移一位，得到 `6 1 2 3 4 5`。

步长 $d = 2$：选中盒子 `2, 4, 6`，当前数字依次为 `1, 3, 5`，循环右移一位变为 $[5,1,3]$，放回后数组变为 `6 5 2 1 4 3`。

步长 $d = 3$：选中盒子 `3, 6`，当前数字为 `2, 3`，循环右移一位变为 $[3,2]$，放回后数组变为 `6 5 3 1 4 2`。

步长 $d = 4, 5, 6$ 时选中的盒子数量均不足 `2`，无操作。最终输出 `6 5 3 1 4 2`。
