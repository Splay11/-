# 题目内容
通信基站用整数 $a$ 表示当前增益档位，并用上限 $b$ 约束一次调整。一次调整定义为 $f(x)=\min(x,b)+\gcd(x,b)$：先把档位截到不超过 $b$，再加上它与 $b$ 的最大公约数，以保证后续功放单元能整除。

需要连续调整 $n$ 次，即求 $f^{(n)}(a)$，其中 $f^{(1)}(x)=f(x)$，$f^{(k+1)}(x)=f(f^{(k)}(x))$。$\gcd(x,b)$ 表示二者最大公约数。

约束：测试组数不超过 `2000`，$a$ 与 $b$ 不超过 `1000000000000`，$n$ 不超过 `1000000000000000000`。

# 输入描述
第一行一个整数 $T$，表示测试组数，满足 $1 \le T \le 2000$。
接下来 $T$ 行，每行三个整数 $a$、$b$、$n$，满足 $1 \le a,b \le 1000000000000$，$1 \le n \le 1000000000000000000$。

# 输出描述
输出 $T$ 行，每行一个整数，表示对应数据经过 $n$ 次调整后的结果。

## 样例1

**输入**

```
3
9 4 3
20 7 2
5 15 8
```

**输出**

```
5
8
30
```

**说明**

第一组：$f(9)=4+1=5$，之后保持 `5`。
第二组：$f(20)=7+1=8$，再一次仍为不动点 `8`。
第三组：$5\to 10\to 15\to 30$，之后保持 `30`。

## 样例2

**输入**

```
2
12 8 1
2 2 100
```

**输出**

```
12
4
```

**说明**

只变换 `1` 次时直接计算 $f(12)=8+\gcd(12,8)=12$。
$a=b=2$ 且步数很多时会停在不动点。

## 样例3

**输入**

```
1
30 18 4
```

**输出**

```
24
```

**说明**

从 `30` 开始对 `18` 连续变换 `4` 次，利用质因子分段跳跃加速。
