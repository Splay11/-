## 解题思路

设连续 $m$ 个非负整数的起点为 $x \ge 0$，则

$$
x + (x+1) + \cdots + (x+m-1) = m x + \frac{m(m-1)}{2} = n.
$$

记 $S = \dfrac{m(m-1)}{2}$。存在合法 $x$ 当且仅当 $n \ge S$ 且 $(n-S)$ 能被 $m$ 整除（此时 $x = \dfrac{n-S}{m} \ge 0$）。

由于 $m$ 可达 `1000000000`、$n$ 可达 `1000000000000000000`，计算时使用 64 位整数。

## 复杂度分析

每组判断 $O(1)$，总时间复杂度 $O(T)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
T = int(input().strip())
for _ in range(T):
    n, m = map(int, input().split())
    S = m * (m - 1) // 2
    if n < S:
        print("NO")
    elif (n - S) % m == 0:
        print("YES")
    else:
        print("NO")
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int T = scanner.nextInt();
        for (int t = 0; t < T; t++) {
            long n = scanner.nextLong();
            long m = scanner.nextLong();
            long S = m * (m - 1) / 2;
            if (n < S) {
                System.out.println("NO");
                continue;
            }
            if ((n - S) % m == 0)
                System.out.println("YES");
            else
                System.out.println("NO");
        }
        scanner.close();
    }
}
```

    cin >> T;
    while (T--) {
        long long n, m;
        cin >> n >> m;
        long long S = m * (m - 1) / 2;
        if (n < S) {
            cout << "NO" << "\n";
            continue;
        }
        if ((n - S) % m == 0)
            cout << "YES" << "\n";
        else
            cout << "NO" << "\n";
    }
    return 0;
}
