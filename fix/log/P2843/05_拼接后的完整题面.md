# 题目内容
仓储中心要把总计 $n$ 件货物分到恰好 $m$ 个连号货格里。货格按编号排成一排后，相邻货格的件数必须恰好相差 `1`，且每个货格的件数都是非负整数。调度员想确认：是否存在一种分法，使这 $m$ 个货格的件数之和恰好等于 $n$。

更形式地：是否存在整数 $x \ge 0$，使得

$x + (x+1) + \cdots + (x+m-1) = n$。

若将这些数从小到大放入数组 $b$，则 $b_1 \ge 0$，且对任意 $1 < i \le m$ 都有 $b_i = b_{i-1} + 1$。

约束：测试组数 $T$ 满足 $1 \le T \le 10000$，$1 \le n \le 1000000000000000000$，$1 \le m \le 1000000000$。

# 输入描述
第一行一个整数 $T$，表示测试组数。
接下来 $T$ 行，每行两个正整数 $n$ 和 $m$。
保证 $1 \le T \le 10000$，$1 \le n \le 1000000000000000000$，$1 \le m \le 1000000000$。

# 输出描述
对每组数据输出一行：若可以按上述规则分件则输出 `YES`，否则输出 `NO`。

## 样例1

**输入**

```
4
10 4
15 5
6 4
100 1
```

**输出**

```
YES
YES
YES
YES
```

**说明**

`10` 可写成 $1+2+3+4$；`15` 可写成 $1+2+3+4+5$；`6` 可写成 $0+1+2+3$；`100` 本身就是 `1` 个数。四组均为 `YES`。

## 样例2

**输入**

```
4
7 3
20 6
1 2
45 9
```

**输出**

```
NO
NO
YES
YES
```

**说明**

前两组不存在非负起点 $x$ 使连续 $m$ 项之和等于 $n$。
第三组 $0+1=`1`$；第四组 $1+2+\cdots+9=`45`$。

## 样例3

**输入**

```
3
4 3
11 5
21 6
```

**输出**

```
NO
NO
YES
```

**说明**

`4` 无法拆成 `3` 个连续非负整数；`11` 无法拆成 `5` 个。
`21` 可写成 $1+2+3+4+5+6$，输出 `YES`。
