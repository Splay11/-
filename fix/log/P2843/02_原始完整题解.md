# 题解

## 题面描述

给定两个正整数 $n$ 和 $m$，要求将 $n$ 分解为恰好 $m$ 个连续（排好序后满足后一项等于前一项加 $1$）非负整数，使得这 $m$ 个数的和为 $n$。  
连续的非负整数定义为：假设将这 $m$ 个整数从小到大存入数组 $b$，则有 $b_1 \ge 0$ 且对任意 $i (1 < i \le m)$ 有 $b_i = b_{i-1} + 1$。

---

## 思路分析

1. **核心思路：**

   如果我们设这 $m$ 个连续非负整数的最小值为 $x$，那么这 $m$ 个数可以表示为  
   $x, x+1, x+2, \dots, x+m-1$。  
   这 $m$ 个数的和为  
   $\text{sum} = m \cdot x + \frac{m \cdot (m - 1)}{2}$。  
   要满足 $\text{sum} = n$，可以整理得到  
   $m \cdot x = n - \frac{m \cdot (m - 1)}{2}$。

2. **判断条件：**  
   记  
   $S = \frac{m \cdot (m - 1)}{2}$。  
   - 若 $n < S$，则无论如何 $x$ 都不可能非负，此时答案为 $NO$。  
   - 若 $n \ge S$，则令  
     $x = \frac{n - S}{m}$，必须要求 $n - S$ 能被 $m$ 整除，且求出的 $x \ge 0$。  
   - 综上，只需判断 $n \ge S$ 且 $n - S$ 是否能被 $m$ 整除。

3. **复杂度分析：**  
   - 计算 $S$ 和进行一次除法与取余运算均为 $O(1)$ 操作。  
   - 由于每组测试数据的判断时间均为常数时间，故在 $T$ 组数据下，总时间复杂度为 $O(T)$，满足题目 $T \le 10^4$ 的要求。

## C++
```cpp
#include <iostream>
using namespace std;

int main(){
    ios::sync_with_stdio(false);  // 提升 I/O 效率
    cin.tie(nullptr);
    
    int T;
    cin >> T;
    while(T--){
        // 读取输入的正整数 n 和 m
        long long n, m;
        cin >> n >> m;
        
        // 计算 S = m * (m - 1) / 2
        // 使用 long long 以防 n、m 数据范围较大产生溢出
        long long S = m * (m - 1) / 2;
        
        // 如果 n 小于 S，则不可能构成序列
        if(n < S){
            cout << "NO" << "\n";
            continue;
        }
        
        // 如果 n - S 能被 m 整除，则存在非负整数 x，使得
        // m * x + S == n
        if((n - S) % m == 0)
            cout << "YES" << "\n";
        else
            cout << "NO" << "\n";
    }
    return 0;
}
```
## Python 
```python
# 读取测试组数
T = int(input().strip())
for _ in range(T):
    # 读取 n 和 m
    n, m = map(int, input().split())
    
    # 计算 S = m * (m - 1) / 2
    S = m * (m - 1) // 2
    
    # 判断 n 是否小于 S 或 (n - S) 是否能被 m 整除
    if n < S:
        print("NO")
    elif (n - S) % m == 0:
        print("YES")
    else:
        print("NO")
```

## Java
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        // 读取测试组数 T
        int T = scanner.nextInt();
        
        for (int t = 0; t < T; t++) {
            // 读取正整数 n 和 m
            long n = scanner.nextLong();
            long m = scanner.nextLong();
            
            // 计算 S = m * (m - 1) / 2
            long S = m * (m - 1) / 2;
            
            // 如果 n 小于 S，则不可能构成连续非负整数的序列
            if(n < S) {
                System.out.println("NO");
                continue;
            }
            
            // 如果 n - S 能被 m 整除，则存在非负整数 x
            if((n - S) % m == 0)
                System.out.println("YES");
            else
                System.out.println("NO");
        }
        scanner.close();
    }
}
```
