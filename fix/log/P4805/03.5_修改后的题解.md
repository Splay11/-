## 解题思路

先锋的策略固定：每一轮必定取走当前剩余宝物中估价最高的一件。  
谋士的目标是让「先锋累计估价 - 谋士累计估价」尽可能小（允许为负），且采取最优策略。

可以证明，谋士的最优策略同样也是每一轮取走当前剩余宝物中估价最高的一件。  
若谋士不取当前最大值，该最大值会在后续轮次中被先锋取走，导致先锋的累计估价增加，从而差值（先锋 - 谋士）不会变得更小，甚至可能变大。

因此，将全部宝物的估价 $v_1, v_2, \dots, v_m$ 降序排序后，双方会按顺序轮流选取：

- 先锋取第 $1, 3, 5, \dots$ 件（奇数位，0‑based 下标为偶数）；
- 谋士取第 $2, 4, 6, \dots$ 件（偶数位，0‑based 下标为奇数）。

答案即为先锋所选宝物的估价总和减去谋士所选宝物的估价总和。

## 复杂度分析

- 时间复杂度：$O(m \log m)$，主要花费在对估价数组进行降序排序上；遍历求和只需 $O(m)$。对于所有测试数据，$\sum m \le 4 \times 10^5$，总复杂度在可接受范围内。  
- 空间复杂度：$O(m)$，需要存储一组宝物的估价数组。

## 代码实现

### Python

```python
import sys

def solve_case(m, v):
    # 降序排序
    v.sort(reverse=True)
    pioneer = 0
    strategist = 0
    for i in range(m):
        if i % 2 == 0:
            pioneer += v[i]      # 先锋取奇数位（0-based 偶数）
        else:
            strategist += v[i]   # 谋士取偶数位（0-based 奇数）
    return pioneer - strategist

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    t = data[0]
    idx = 1
    out = []
    for _ in range(t):
        m = data[idx]
        idx += 1
        v = data[idx:idx + m]
        idx += m
        out.append(str(solve_case(m, v)))
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    static long solveCase(int m, int[] v) {
        // 升序排序后从后向前遍历，等效于降序处理
        Arrays.sort(v);
        long pioneer = 0, strategist = 0;
        boolean pioneerTurn = true; // 先锋先手
        for (int i = m - 1; i >= 0; i--) {
            if (pioneerTurn) {
                pioneer += v[i];
            } else {
                strategist += v[i];
            }
            pioneerTurn = !pioneerTurn;
        }
        return pioneer - strategist;
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine());
        StringBuilder sb = new StringBuilder();
        while (T-- > 0) {
            int m = Integer.parseInt(br.readLine());
            String[] parts = br.readLine().split(" ");
            int[] v = new int[m];
            for (int i = 0; i < m; i++) {
                v[i] = Integer.parseInt(parts[i]);
            }
            sb.append(solveCase(m, v)).append('\n');
        }
        System.out.print(sb);
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
using ll = long long;

ll solve_case(int m, vector<int>& v) {
    // 降序排序
    sort(v.begin(), v.end(), greater<int>());
    ll pioneer = 0, strategist = 0;
    for (int i = 0; i < m; i++) {
        if (i % 2 == 0)
            pioneer += v[i];   // 先锋取奇数位（0-based 偶数）
        else
            strategist += v[i]; // 谋士取偶数位（0-based 奇数）
    }
    return pioneer - strategist;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int m;
        cin >> m;
        vector<int> v(m);
        for (int i = 0; i < m; i++) cin >> v[i];
        cout << solve_case(m, v) << '\n';
    }
    return 0;
}
```
