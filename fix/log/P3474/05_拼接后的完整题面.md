# 题目内容
在一个物联网监测系统中，每个传感器节点会记录不同类型信号的接收次数。工程师需要评估每个节点的信号多样性，以判断其工作状态的均匀程度。

对于某个传感器节点，设其共收到 $n$ 种信号类型，第 $i$ 种信号的接收次数为 $c_i$（$c_i \ge 0$），总接收次数为 $C = \sum_{j=1}^{n} c_j$。若 $C = 0$，则定义该节点的分布复杂度为 $0$；否则，定义第 $i$ 种信号的出现频率 $p_i = \frac{c_i}{C}$，节点分布复杂度 $H$ 的计算公式为：

$H = -\sum_{i=1}^{n} p_i \log_2 p_i$

其中，当 $c_i = 0$ 时，对应的项视为 $0$ 且不参与求和。

输入数据以 JSON 格式从标准输入给出，你需要读取数据，计算每个节点的分布复杂度，将结果保留三位小数，并输出一个 JSON 对象。

约束：节点总数不超过 $1000$，每个节点的信号类型数量不超过 $100$，每种信号的接收次数均为非负整数且不超过 $10^6$。

# 输入描述
标准输入包含一个 JSON 对象。对象的每个键是字符串，表示传感器节点的唯一标识；对应的值是一个字典，该字典的键为信号类型名称（字符串），值为该类型的接收次数（非负整数）。输入可能跨越多行。

# 输出描述
输出一个 JSON 对象，其中每个键与输入中的节点标识一一对应，每个键对应的值是一个字典，该字典仅包含一个键 "entropy"，其值为该节点的分布复杂度（保留三位小数的数值）。输出使用双引号且为合法 JSON 格式。

## 样例1

**输入**

```
{"nodeA":{"signalX":10,"signalY":30}}
```

**输出**

```
{"nodeA":{"entropy":0.811}}
```

**说明**

对于节点 `nodeA`，总次数 $C = 10 + 30 = 40$。
频率分别为 $p_X = \frac{10}{40} = 0.25$，$p_Y = \frac{30}{40} = 0.75$。
熵 $H = -0.25 \log_2 0.25 - 0.75 \log_2 0.75$。
计算得 $0.25 \times 2 + 0.75 \times (-\log_2 0.75) \approx 0.5 + 0.31125 = 0.81125$。
保留三位小数得 `0.811`。

## 样例2

**输入**

```
{"sensor2":{"alpha":0,"beta":10,"gamma":20}}
```

**输出**

```
{"sensor2":{"entropy":0.918}}
```

**说明**

对于节点 `sensor2`，总次数 $C = 0 + 10 + 20 = 30$。
$\alpha$ 类次数为 `0`，对应项视为 `0` 且不参与求和。
$\beta$ 类频率 $p_{\beta} = \frac{10}{30} \approx 0.3333$，$\gamma$ 类频率 $p_{\gamma} = \frac{20}{30} \approx 0.6667$。
熵 $H = -p_{\beta} \log_2 p_{\beta} - p_{\gamma} \log_2 p_{\gamma} \approx 0.5283 + 0.3899 = 0.9182$。
保留三位小数得 `0.918`。说明即使有 `0` 次信号接收，也不影响多样性计算。

## 样例3

**输入**

```
{"sensor3":{"A":0,"B":0}}
```

**输出**

```
{"sensor3":{"entropy":0.0}}
```

**说明**

对于节点 `sensor3`，总次数 $C = 0 + 0 = 0$。
根据定义，当 $C = 0$ 时，分布复杂度为 `0`。
输出 `0.0`，展示了空数据或全部信号接收次数为零的边界情况。
