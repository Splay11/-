# 题目内容
小蓝发现了一个有趣的数字游戏。给定一个非负整数 $x$，初始能量值为 $1$。随后反复执行以下操作：
- 若 $x$ 为奇数，则将当前能量值乘以 $2$；
- 将 $x$ 替换为 $\lfloor x/2 \rfloor$（即向下取整的一半）。
当 $x$ 变为 $0$ 时停止操作，此时得到的能量值记为 $E(x)$。

现有 $q$ 次询问，每次给定一个整数 $x$，请你计算并输出 $E(x)$ 的值。

**约束条件**：询问次数 $q$ 满足 $1 \le q \le 10^5$，每次询问的整数 $x$ 满足 $0 \le x \le 10^9$。

# 输入描述
第一行包含一个整数 $q$，表示询问的次数。
接下来 $q$ 行，每行包含一个整数 $x$，表示一次询问。

# 输出描述
对于每个询问，输出一行一个整数，表示对应的 $E(x)$ 值。

## 样例1

**输入**

```
1
0
```

**输出**

```
1
```

**说明**

$x$ 为 `0` 时，二进制表示中没有 `1`，即 `1` 的个数 $c=0$，因此 $E(0)=2^0=1$。初始能量为 $1$，且操作未执行即停止，结果一致。

## 样例2

**输入**

```
3
1
4
7
```

**输出**

```
2
2
8
```

**说明**

- 对于 $x=1$：二进制为 `1`，包含 $c=1$ 个 `1`，故 $E(1)=2^1=2$。
- 对于 $x=4$：二进制为 `100`，包含 $c=1$ 个 `1`，故 $E(4)=2^1=2$。
- 对于 $x=7$：二进制为 `111`，包含 $c=3$ 个 `1`，故 $E(7)=2^3=8$。

可见 $E(x)$ 仅取决于 $x$ 二进制中 `1` 的个数。

## 样例3

**输入**

```
3
100
1000000000
1024
```

**输出**

```
8
8192
2
```

**说明**

- $x=100$ 的二进制为 `1100100`，共 $c=3$ 个 `1`，因此 $E(100)=2^3=8$。
- $x=1000000000$ 的二进制表示中包含 $c=13$ 个 `1`，所以 $E(1000000000)=2^{13}=8192$。
- $x=1024$ 是 $2^{10}$，二进制为 `10000000000`，只有 $c=1$ 个 `1`，因此 $E(1024)=2^1=2$。

这展示了不同规模的输入下，函数仅与二进制位中 `1` 的个数有关。
