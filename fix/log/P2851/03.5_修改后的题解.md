## 解题思路

1. 题目定义了一个能量计算过程：初始能量 $E=1$，反复执行：
   - 若当前 $x$ 为奇数，则 $E \gets E \times 2$；
   - $x \gets \lfloor x/2 \rfloor$。
   直到 $x=0$ 时停止，最终的能量值记为 $E(x)$。

2. 观察上述操作本质：
   - 每次判断 $x$ 是否为奇数，等价于检查 $x$ 二进制表示的最低位是否为 $1$；
   - 若为 $1$，能量乘以 $2$；
   - 随后 $x$ 右移一位（整除 $2$），相当于丢弃最低位。
   
3. 整个过程就是从低位到高位扫描 $x$ 的所有二进制位，**每遇到一个 $1$，能量值就翻倍**。因此，最终能量值等于 $2^c$，其中 $c$ 是 $x$ 二进制中 $1$ 的个数，即 $c = \operatorname{popcount}(x)$。

4. 特别地，当 $x=0$ 时，二进制中没有 $1$（$c=0$），能量保持初值 $1=2^0$，符合定义。

5. 因此，对于每次询问，只需：
   - 计算 $c = \operatorname{popcount}(x)$（使用内置函数或位运算）；
   - 输出 $2^c$，可通过位左移 `1 << c` 实现。

## 复杂度分析

- 时间复杂度：对于每次询问，统计二进制中 $1$ 的个数可以在整数位宽内完成，$x \le 10^9$ 的位宽不超过 $30$，可视为常数时间，因此总时间复杂度为 $O(q)$。
- 空间复杂度：仅使用了常数个变量，空间复杂度为 $O(1)$。

## 代码实现

### Python

```python
import sys
input = sys.stdin.readline

def main():
    q = int(input())                  # 读入询问次数
    for _ in range(q):
        x = int(input())              # 读入当前 x
        # 统计 x 二进制中 '1' 的个数
        cnt = bin(x).count('1')
        # 能量值 = 2 的 cnt 次幂，等价于 1 << cnt
        print(1 << cnt)

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader in = new BufferedReader(new InputStreamReader(System.in));
        int q = Integer.parseInt(in.readLine());  // 读入询问次数 q
        
        while (q-- > 0) {
            int x = Integer.parseInt(in.readLine());
            // 统计 x 二进制中 '1' 的个数
            int cnt = Integer.bitCount(x);
            // 输出能量值 2 的 cnt 次幂
            System.out.println(1 << cnt);
        }
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int q;
    cin >> q;                       // 读入询问次数
    while (q--) {
        int x;
        cin >> x;                   // 读入当前 x
        // __builtin_popcount 计算 x 二进制中 '1' 的个数
        int cnt = __builtin_popcount(x);
        // 输出能量值 2 的 cnt 次幂
        cout << (1 << cnt) << '\n';
    }
    return 0;
}
```
