## 解题思路

1. 根据协议规则，序列的相邻字符关系由参考序列 $P$ 完全确定：
   - 若 $P_i = 1$，则要求 $S'_i \neq S'_{i+1}$；
   - 若 $P_i = 0$，则要求 $S'_i = S'_{i+1}$。
   这等价于递推关系：$S'_{i+1} = S'_i \oplus P_i$（$\oplus$ 表示异或）。

2. 因此，只要确定了修改后序列的第一位 $S'_1$，整个序列就能唯一确定。$S'_1$ 只有两种可能取值：`0` 或 `1`。

3. 分别假设 $S'_1 = 0$ 和 $S'_1 = 1$，按上述递推生成目标序列（可以在生成过程中直接与原始序列 $S$ 比较，无需显式存储整个序列）。

4. 对于每个假设，统计目标序列与原始序列 $S$ 在不同位置的字符个数（即需要修改的次数），最后取两种情况的最小值作为答案。

5. 该算法只需遍历序列一次，对于每组测试数据可在 $O(n)$ 时间内完成。

## 复杂度分析

- 时间复杂度：$O(n)$，其中 $n$ 为序列长度。每组数据需要线性扫描并计算两种假设的差异数量。
- 空间复杂度：$O(1)$，仅使用了常数级别的额外变量，不需要存储整个目标序列。若显式存储目标序列则为 $O(n)$，本题解采用 $O(1)$ 方式。

## 代码实现

### Python

```python
import sys
input = sys.stdin.readline

def solve() -> None:
    T = int(input())
    for _ in range(T):
        n = int(input())
        S = input().strip()
        P = input().strip()

        # diff0: 假设 S'[0] = '0' 时的修改次数
        # diff1: 假设 S'[0] = '1' 时的修改次数
        diff0 = 0
        diff1 = 0
        cur0 = 0  # 当前 S'[0]='0' 假设下，当前位置的目标字符
        cur1 = 1  # 当前 S'[0]='1' 假设下，当前位置的目标字符

        for i in range(n):
            # 统计与原始字符不同的位置
            if int(S[i]) != cur0:
                diff0 += 1
            if int(S[i]) != cur1:
                diff1 += 1

            # 若未到末尾，根据 P[i] 更新下一位的目标字符
            if i < n - 1:
                v = int(P[i])
                cur0 ^= v
                cur1 ^= v

        print(min(diff0, diff1))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine());

        while (T-- > 0) {
            int n = Integer.parseInt(br.readLine());
            String S = br.readLine().trim();
            String P = br.readLine().trim();

            long diff0 = 0, diff1 = 0;   // 修改次数
            int cur0 = 0, cur1 = 1;      // 当前目标字符

            for (int i = 0; i < n; i++) {
                int si = S.charAt(i) - '0';
                if (si != cur0) diff0++;
                if (si != cur1) diff1++;

                if (i < n - 1) {
                    int v = P.charAt(i) - '0';
                    cur0 ^= v;
                    cur1 ^= v;
                }
            }

            System.out.println(Math.min(diff0, diff1));
        }
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        string S, P;
        cin >> S >> P;

        long long diff0 = 0, diff1 = 0;
        int cur0 = 0, cur1 = 1;   // 当前目标位：假设首位为0或1

        for (int i = 0; i < n; ++i) {
            // 比较原始序列与两种目标序列
            if (S[i] - '0' != cur0) ++diff0;
            if (S[i] - '0' != cur1) ++diff1;

            // 还未到末尾，根据 P[i] 更新下一位的目标值
            if (i < n - 1) {
                int v = P[i] - '0';
                cur0 ^= v;
                cur1 ^= v;
            }
        }

        cout << min(diff0, diff1) << "\n";
    }
    return 0;
}
```
