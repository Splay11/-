# 题目内容
工程师正在调试一条由 `0` 和 `1` 组成的传输序列 $S$，长度为 $n$。为了检测是否符合协议，他还拥有一个长度为 $n-1$ 的参考序列 $P$。协议规定：
- 若 $P_i = 1$，则要求最终序列的第 $i$ 位与第 $i+1$ 位必须不同；
- 若 $P_i = 0$，则要求最终序列的第 $i$ 位与第 $i+1$ 位必须相同。

当前序列 $S$ 可能不满足该协议。你可以进行修改操作：每次选择任意一个位置，将其字符翻转（`0` 变为 `1`，`1` 变为 `0`）。请求出最少需要进行多少次修改，才能使修改后的序列完全符合上述协议要求。

测试数据组数不超过 `100`。序列长度 $n$ 满足 $2 \le n \le 10^6$，且单个测试文件中所有 $n$ 的总和不超过 $10^6$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据组数。接下来 $T$ 组数据，每组数据格式如下：
- 第一行包含一个整数 $n$，表示序列的长度。
- 第二行包含一个长度为 $n$ 且仅由 `0` 和 `1` 组成的字符串，表示初始序列 $S$。
- 第三行包含一个长度为 $n-1$ 且仅由 `0` 和 `1` 组成的字符串，表示参考序列 $P$。

# 输出描述
对于每组测试数据，输出一行一个整数，表示最少需要修改的次数。

## 样例1

**输入**

```
1
2
00
1
```

**输出**

```
1
```

**说明**

参考序列 $P$ 长度为 `1`，要求 $x_1 
eq x_2$。原串 $S =$ `00`，两种合法目标串分别为：以 `0` 开头得到 `01`，需修改 `1` 次；以 `1` 开头得到 `10`，也需修改 `1` 次。因此最少修改次数为 `1`。

## 样例2

**输入**

```
1
5
11000
1010
```

**输出**

```
2
```

**说明**

$P =$ `1010` 要求相邻关系为：$x_1 
eq x_2$、$x_2 = x_3$、$x_3 
eq x_4$、$x_4 = x_5$。
以 `0` 开头的目标串为 `01100`，与原串 `11000` 有 `2` 处不同（第 `1`、`2` 位）；以 `1` 开头的目标串为 `10011`，有 `3` 处不同。
取最小值，答案为 `2`。

## 样例3

**输入**

```
1
3
010
11
```

**输出**

```
0
```

**说明**

$P =$ `11` 要求 $x_1 
eq x_2$ 且 $x_2 
eq x_3$。原串 $S =$ `010` 已经完全满足这两条要求，无需任何修改，因此最少修改次数为 `0`。
