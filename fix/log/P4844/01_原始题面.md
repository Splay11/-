# 题目内容
你有一组 $n$ 个传感器，每个传感器会返回一个非负整数读数。你可以多次对任意传感器进行校准：选择一个传感器 $i$ 和一个修正量 $y$（$0 \le y \le M$），将它的当前读数 $a_i$ 更新为 $a_i \oplus y$，其中 $\oplus$ 表示两个数在二进制下逐位模 $2$ 加法（无进位和）。每次校准需要消耗 $y$ 单位的能量，总能耗为所有操作消耗之和。

完成所有校准后，定义整体差异度为所有无序传感器对的读数逐位模 $2$ 和的总值：
$$\sum_{1 \le i < j \le n} a_i \oplus a_j$$
你的目标是使得差异度尽可能大，在差异度达到最大的前提下，总能耗应尽可能小。请你求出能够获得的最大差异度，以及对应的最小总能耗。

约束条件：
- 传感器个数 $n$ 满足 $2 \le n \le 10^5$；
- 修正量上限 $M$ 满足 $1 \le M < 2^{30}$；
- 初始读数 $a_i$ 满足 $0 \le a_i < 2^{30}$；
- 所有数值均为整数。

# 输入描述
第一行包含两个整数 $n$ 和 $M$，分别表示传感器个数和修正量上限。
第二行包含 $n$ 个整数，依次表示每个传感器的初始读数 $a_1, a_2, \dots, a_n$。

# 输出描述
输出一行两个整数，第一个整数表示能够获得的最大差异度，第二个整数表示达到该最大差异度所需的最小总能耗。

## 样例1

**输入**

```
2 1
0 1
```

**输出**

```
1 0
```

**说明**

只有两个传感器，读数分别为 `0` 和 `1`。初始差异度 $\sum_{1\le i<j\le n} a_i \oplus a_j = 0 \oplus 1 = 1$。修正上限 $M=1$，只能改变最低位（$b=0$）。当前最低位已是一 `0` 一 `1`，达到了该位的最大贡献，因此无需校准，总能耗为 `0`。

## 样例2

**输入**

```
3 3
0 0 0
```

**输出**

```
6 3
```

**说明**

三个传感器初始均为 `0`。$M=3$，不超过 $M$ 的最大 $2$ 的幂为 $p=2$，因此可修改位 $b=0$ 和 $b=1$（权重分别为 $1$ 和 $2$）。对于 $n=3$，任一位的最大贡献在 `1` 个 `1` 与 `2` 个 `0`（或反之）时取得，需要将位 $0$ 和位 $1$ 各翻转为 `1` 个 `1`。最优方案是将其中一个传感器的读数加上 $y=3$（即同时翻两位），能耗为 `3`，得到 `[3,0,0]`。此时差异度为 $3 \oplus 0 + 3 \oplus 0 + 0 \oplus 0 = 6$，达到最大，且总能耗最小为 `3`。

## 样例3

**输入**

```
4 5
1 2 3 4
```

**输出**

```
28 4
```

**说明**

$n=4$，$M=5$。不超过 $M$ 的最大 $2$ 的幂为 $p=4$，可修改位 $b=0,1,2$（值 $1,2,4$）。初始读数的最低三位中：位 $0$ 有 `2` 个 `1`（`1` 和 `3`），位 $1$ 有 `2` 个 `1`（`2` 和 `3`），均已达到 $n/2=2$ 的最优分布，无需变动；位 $2$ 仅有 `1` 个 `1`（来自 `4`），需要增加 `1` 个 `1`。将读数 `1` 加上 $y=4$ 变为 `5`，总能耗 `4`。得到数组 `[5,2,3,4]`，所有对的异或和为 $5\oplus2+5\oplus3+5\oplus4+2\oplus3+2\oplus4+3\oplus4=28$。高位不可修改且原本均为 `0`，贡献为 `0`。因此最大差异度为 `28`，最小总能耗为 `4`。
