# 题目内容
某数字图书馆收集了每位读者的历史借阅记录，希望通过读者之间的兴趣相似度为每位读者推荐一本他们尚未借阅的书籍。你的任务是设计一个推荐算法。

将每本书籍看作一个维度，每位读者的借阅情况可表示为一个 0-1 向量（借阅过则对应分量为 1，否则为 0）。两位读者之间的相似度定义为这两个向量的夹角余弦值。

对于每一位读者，你需要：
1. 找出除其自身外相似度最高的 3 位读者作为邻居；
2. 收集这 3 位邻居借阅过的所有书籍，过滤掉该读者已经借阅过的书籍，剩余书籍作为候选；
3. 对于每一本候选书籍，定义其推荐得分为所有拥有该书的邻居与该读者之间的最大相似度；
4. 从候选书籍中选择推荐得分最高的那一本；如果存在多本得分相同的书籍，则选择书籍 ID 最小的那一本；
5. 如果没有任何候选书籍（即所有邻居的书籍该读者均已借阅），则推荐结果记为 None，对应的相似度记为 0.000。

输入数据规模：读者的数量不超过 $10^3$，书籍 ID 均为不超过 $10^4$ 的正整数，每个读者借阅的书籍数量不超过 $500$，所有书籍的种类总数不超过 $2 \times 10^3$。

# 输入描述
输入共一行，包含一个列表。列表的每个元素是一个长度为 2 的列表，第一个元素为读者 ID（整数），第二个元素为该读者借阅的书籍 ID 列表（整数列表）。所有数据通过标准输入给出。

# 输出描述
输出包含若干行，每行对应一个输入中的读者，按照读者在输入中的出现顺序依次输出。每行输出一个列表，包含三个元素：读者 ID、推荐的书籍 ID（若无可推荐则为 None）以及对应的相似度（浮点数，保留三位小数）。

## 样例1

**输入**

```
[[1, [101]]]
```

**输出**

```
[1, None, 0.000]
```

**说明**

只有一位读者 `1`，不存在其他读者作为邻居，候选书籍集合为空。根据规则，推荐结果记为 `None`，对应的相似度记为 `0.000`。

## 样例2

**输入**

```
[[1, [101, 102]], [2, [101]], [3, [102]]]
```

**输出**

```
[1, None, 0.000]
[2, 102, 0.707]
[3, 101, 0.707]
```

**说明**

所有出现过的书籍为 `101` 和 `102`，因此读者向量维度为 $2$。读者 `1` 的向量为 $(1, 1)$，读者 `2` 为 $(1, 0)$，读者 `3` 为 $(0, 1)$。

余弦相似度计算如下：
$\text{sim}(1,2) = \frac{1 \times 1 + 1 \times 0}{\sqrt{2} \times 1} = \frac{1}{\sqrt{2}} \approx 0.707$
$\text{sim}(1,3) = \frac{1 \times 0 + 1 \times 1}{\sqrt{2} \times 1} = \frac{1}{\sqrt{2}} \approx 0.707$
$\text{sim}(2,3) = \frac{1 \times 0 + 0 \times 1}{1 \times 1} = 0.000$

对于读者 `1`：除自身外只有两位邻居 `2` 和 `3`，相似度均为 `0.707`。邻居借阅的书籍为 `101` 和 `102`，读者 `1` 均已借阅，无候选书籍，故推荐 `None`，相似度 `0.000`。

对于读者 `2`：邻居为 `1`（相似度 `0.707`）和 `3`（相似度 `0.000`）。邻居 `1` 拥有 `102`（读者 `2` 未借阅），候选书籍只有 `102`，其得分为所有拥有该书的邻居与读者 `2` 之间的最大相似度，即 $\max(0.707, 0.000) = 0.707$。推荐 `102`，相似度 `0.707`。

对于读者 `3`：邻居为 `1`（`0.707`）和 `2`（`0.000`）。邻居 `1` 拥有 `101`，未借阅，候选书籍 `101` 的得分同样为 `0.707`，推荐 `101`，相似度 `0.707`。

## 样例3

**输入**

```
[[1, [101, 102]], [2, [101, 103, 104]], [3, [102, 103, 105]], [4, [103, 104, 105]]]
```

**输出**

```
[1, 103, 0.408]
[2, 105, 0.667]
[3, 104, 0.667]
[4, 101, 0.667]
```

**说明**

所有书籍种类为 `101`, `102`, `103`, `104`, `105`，读者借阅向量表示为这 $5$ 维的 $0$-$1$ 向量。
读者 `1`: $(1,1,0,0,0)$
读者 `2`: $(1,0,1,1,0)$
读者 `3`: $(0,1,1,0,1)$
读者 `4`: $(0,0,1,1,1)$

计算两两余弦相似度（保留三位小数）：
$\text{sim}(1,2) = \frac{1}{\sqrt{2}\sqrt{3}} = \frac{1}{\sqrt{6}} \approx 0.408$
$\text{sim}(1,3) = \frac{1}{\sqrt{6}} \approx 0.408$
$\text{sim}(1,4) = 0.000$
$\text{sim}(2,3) = \frac{1}{\sqrt{3}\sqrt{3}} = \frac{1}{3} \approx 0.333$
$\text{sim}(2,4) = \frac{2}{3} \approx 0.667$
$\text{sim}(3,4) = \frac{2}{3} \approx 0.667$

对于读者 `1`：相似度最高的 $3$ 位邻居（除自己外）依次为 `2`（$0.408$）、`3`（$0.408$）、`4`（$0.000$）。候选书籍为邻居已借但读者 `1` 未借阅的 `103`、`104`、`105`。
- 书籍 `103` 被邻居 `2`、`3`、`4` 拥有，对应相似度 $0.408$、$0.408$、$0.000$，最大得分 $0.408$。
- 书籍 `104` 被邻居 `2`、`4` 拥有，最大得分 $\max(0.408, 0.000) = 0.408$。
- 书籍 `105` 被邻居 `3`、`4` 拥有，最大得分 $\max(0.408, 0.000) = 0.408$。
三本书得分均为 `0.408`，根据规则选择书籍 ID 最小的 `103`，输出相似度 `0.408`。

对于读者 `2`：邻居为 `4`（$0.667$）、`1`（$0.408$）、`3`（$0.333$）。候选书籍为 `102` 和 `105`。`102` 的最大相似度来自邻居 `1` 和 `3`，为 $\max(0.408, 0.333) = 0.408$；`105` 的最大相似度来自邻居 `3` 和 `4`，为 $\max(0.333, 0.667) = 0.667$。得分最高的为 `105`，推荐它并输出相似度 `0.667`。

对于读者 `3`：邻居为 `4`（$0.667$）、`1`（$0.408$）、`2`（$0.333$）。候选书籍为 `101` 和 `104`。`101` 得分为 $\max(0.408, 0.333) = 0.408$；`104` 得分为 $\max(0.333, 0.667) = 0.667$。推荐 `104`，相似度 `0.667`。

对于读者 `4`：邻居为 `2`（$0.667$）、`3`（$0.667$）、`1`（$0.000$）。候选书籍为 `101` 和 `102`。两本书的得分均为 $0.667$（分别来自邻居 `2` 和 `3`），得分相同时取 ID 更小的 `101`，输出相似度 `0.667`。
