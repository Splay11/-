# 题目内容
你驾驶一辆能源车沿着一条直线依次经过 $n$ 个能源站，从第 $1$ 个站出发，目标是到达第 $n$ 个站。能源车每从一个站行驶到相邻的下一站需要消耗恰好 $1$ 单位能量。你可以在任意能源站购买任意数量的能量，第 $i$ 个站的单位能量价格为 $p_i$。由于能量存储不稳定，若当前携带超过 $1$ 单位能量，每多出 $1$ 单位能量并且行驶一站，就需要支付 $1$ 单位的维护费用。换句话说，如果在第 $j$ 个站购买了若干能量，将其中的 $1$ 单位能量用于从第 $i-1$ 个站到第 $i$ 个站的行驶（$i > j$），该单位能量的总花费等于 $p_j$ 加上沿途的维护费用 $i-j$。你希望合理规划在哪些站购买能量，使得总花费最小。请计算从起点到达终点所需的最小总花费。

能源站的数量 $n$ 满足 $1 \le n \le 10^5$，每个站的单价 $p_i$ 满足 $1 \le p_i \le 10^9$。

# 输入描述
第一行包含一个整数 $n$，表示能源站的数量。
第二行包含 $n$ 个整数 $p_1, p_2, \dots, p_n$，依次表示每个能源站的单位能量价格。

# 输出描述
输出一个整数，表示从起点到达终点所需的最小总花费。

## 样例1

**输入**

```
2
5 10
```

**输出**

```
5
```

**说明**

只有两个能源站，需要从站 $1$ 行驶到站 $2$，消耗 `1` 单位能量。在站 $1$ 购买该单位能量，价格 $p_1=5$，不需要维护费，总花费 $5$。

## 样例2

**输入**

```
3
1 100 1
```

**输出**

```
3
```

**说明**

站数 $n=3$，价格依次为 $p_1=1, p_2=100, p_3=1$。需要完成两段行驶：

- 从站 $1$ 到站 $2$：必须在出发时携带能量，在站 $1$ 购买 `1` 单位花费 $1$。
- 从站 $2$ 到站 $3$：可以在站 $1$ 提前多买 `1` 单位并携带至站 $2$ 使用，也可在站 $2$ 即时购买。若在站 $1$ 购买，该单位能量经过一段携带，维护费为 $2-1=1$，总花费 $p_1+(2-1)=2$；若在站 $2$ 购买则花费 $p_2=100$。显然选前者更优。

总最小花费为 $1+2=3$。

## 样例3

**输入**

```
4
3 1 2 1
```

**输出**

```
6
```

**说明**

价格依次为 $p_1=3, p_2=1, p_3=2, p_4=1$。需三段行驶：

- 站 $1$ 到站 $2$：必须在站 $1$ 购买 `1` 单位，花费 $3$。
- 站 $2$ 到站 $3$：可从站 $1$ 提前购买（维护费 $2-1=1$，总花费 $3+1=4$）或在站 $2$ 即时购买（花费 $1$）。选择站 $2$ 即时购买，花费 $1$。
- 站 $3$ 到站 $4$：可从站 $2$ 提前购买（维护费 $3-2=1$，总花费 $1+1=2$）或在站 $3$ 即时购买（花费 $2$）。两者花费相等，均为 $2$。

总最小花费 $3+1+2=6$。
