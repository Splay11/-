# 题目内容
给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。
每个数 $x$ 的 **极性** 由其除以 $2$ 的余数决定：若余数为 $0$ 则称为 **$0$‑极性**，若余数为 $1$ 则称为 **$1$‑极性**。

现在希望序列中所有数的极性全部相同（即全部为 $0$‑极性，或全部为 $1$‑极性）。
为此，你可以进行任意次操作，一次操作描述为：
- 选择两个相邻的元素 $a_i$ 与 $a_{i+1}$，将它们从序列中删除，并在原位置插入它们的乘积 $a_i \times a_{i+1}$。

操作后，新元素的极性由乘积的极性自然决定：
- 两个 $1$‑极性数相乘，结果为 $1$‑极性；
- 其他情况（只要有一个 $0$‑极性数参与乘法），结果均为 $0$‑极性。

请计算：使得序列中所有元素极性一致所需的 **最少操作次数**。

约束条件：
- 测试数据组数 $T$ 满足 $1 \le T \le 10^4$；
- 对于每组数据，$n \ge 1$，且单个测试文件内所有 $n$ 之和不超过 $2 \times 10^5$；
- 序列中的每个整数满足 $1 \le a_i \le 10^9$。

# 输入描述
第一行输入一个整数 $T$，表示测试数据组数。
接下来依次描述每组测试数据，格式如下：
第一行包含一个整数 $n$，表示序列长度；
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$，含义如上所述。
保证数据满足题面中的约束。

# 输出描述
对于每组测试数据，输出一行一个整数，表示使得序列极性一致所需的最少操作次数。

## 样例1

**输入**

```
1
3
3 5 7
```

**输出**

```
0
```

**说明**

序列中所有元素均为 $1$‑极性（奇数），已经满足极性一致的条件，因此不需要进行任何操作，最少操作次数为 `0`。

## 样例2

**输入**

```
1
5
2 1 3 4 5
```

**输出**

```
3
```

**说明**

序列中共有 $3$ 个奇数（`1`、`3`、`5`），且存在偶数。由于只要存在偶数，最终只能实现全为 $0$‑极性（偶数）。每一次操作最多可以将一个奇数合并为偶数（例如用偶数 `2` 依次合并相邻的奇数，或者先将两个奇数合并为奇数再与偶数合并），因此最少需要 $3$ 次操作，答案为 `3`。

## 样例3

**输入**

```
1
1
8
```

**输出**

```
0
```

**说明**

序列中只有一个元素 $8$，本身就是 $0$‑极性（偶数），已经满足极性一致的条件，不需要任何操作，答案为 `0`。这个边界情况说明当 $n = 1$ 时答案总是 $0$。
