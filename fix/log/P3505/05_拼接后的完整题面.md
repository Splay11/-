# 题目内容
在整数区间 $[l, r]$ 中，任取四个不同的整数并按从小到大排序，记为 $a < b < c < d$。如果最大的数 $d$ 能被前三个数 $a,b,c$ 中的每一个整除，则称 $(a,b,c,d)$ 为一个“完美四元组”。

给定若干个区间，请你统计每个区间内完美四元组的数量。

题目保证测试用例的数量 $t$ 不超过 $10$，区间端点满足 $1 \le l \le r \le 10^5$，且 $r-l+1 \ge 4$。

# 输入描述
第一行包含一个整数 $t$，表示测试用例的数量。
接下来 $t$ 行，每行包含两个整数 $l$ 和 $r$，表示一个区间的左右端点。

# 输出描述
对于每个测试用例，输出一行一个整数，表示该区间内完美四元组的个数。

## 样例1

**输入**

```
1
1 5
```

**输出**

```
0
```

**说明**

区间 $[1, 5]$ 中的整数为 `1, 2, 3, 4, 5`。从中任取四个不同整数并按从小到大排序，所有可能的四元组分别为 $(1,2,3,4)$、$(1,2,3,5)$、$(1,2,4,5)$、$(1,3,4,5)$、$(2,3,4,5)$。对于每一个四元组 $(a,b,c,d)$，需要检查 $d$ 是否能被 $a,b,c$ 中的每一个整除：

- $(1,2,3,4)$：$4$ 不能被 $3$ 整除；
- $(1,2,3,5)$：$5$ 不能被 $2$ 和 $3$ 整除；
- $(1,2,4,5)$：$5$ 不能被 $2$ 和 $4$ 整除；
- $(1,3,4,5)$：$5$ 不能被 $3$ 和 $4$ 整除；
- $(2,3,4,5)$：$5$ 不能被 $2,3,4$ 整除。

没有任何一个四元组满足条件，因此完美四元组的数量为 `0`。

## 样例2

**输入**

```
1
1 12
```

**输出**

```
13
```

**说明**

在区间 $[1, 12]$ 中，完美四元组要求 $d$ 能被 $a,b,c$ 中的每一个整除，因此 $a,b,c$ 必须是 $d$ 的小于 $d$ 的正约数。我们枚举所有可能的 $d$ 并统计满足条件的 $(a,b,c)$ 组合数：

- $d=6$：小于 $6$ 的约数为 $1,2,3$，恰好选三个，得到 $(1,2,3,6)$，共 `1` 组；
- $d=8$：小于 $8$ 的约数为 $1,2,4$，得到 $(1,2,4,8)$，共 `1` 组；
- $d=9$：约数 $1,3$（不含 $9$），不足三个，`0` 组；
- $d=10$：约数 $1,2,5$，得到 $(1,2,5,10)$，`1` 组；
- $d=12$：小于 $12$ 的约数有 $1,2,3,4,6$，从中任选三个均可，共 $C(5,3)=10$ 组。

总计 $1+1+0+1+10=13$，因此输出 `13`。

## 样例3

**输入**

```
2
1 8
2 20
```

**输出**

```
2
13
```

**说明**

第一组区间 $[1, 8]$：枚举 $d$ 的可能取值。$d=6$ 时有 $(1,2,3,6)$；$d=8$ 时有 $(1,2,4,8)$；其余 $d$ 均无法选出三个不同的小于 $d$ 的约数。因此完美四元组数量为 `2`。

第二组区间 $[2, 20]$：此时 $a \ge 2$，因此要求 $d$ 拥有至少三个不同且位于 $[2, d-1]$ 的约数。对 $d \le 20$ 逐一检查：
- $d=12$：符合要求的约数集合为 $\{2,3,4,6\}$，选三个有 $C(4,3)=4$ 组；
- $d=16$：约数 $\{2,4,8\}$，`1` 组；
- $d=18$：约数 $\{2,3,6,9\}$，`4` 组；
- $d=20$：约数 $\{2,4,5,10\}$，`4` 组。

其余 $d$ 均不满足条件，总和为 $4+1+4+4=13$。
