# 题目内容
一座补给站网络由 $n$ 个站点与 $n-1$ 条通道组成，整体构成一棵树。站点编号为 $1$ 到 $n$，其中站点 $1$ 为根。第 $i$ 个站点的库存为 $a_i$。记站点 $i$ 的父节点为 $fa_i$，并规定 $fa_1=1$。

现在要在这棵树上找一条最长的简单链，使链上涉及的站点满足以下两种条件之一：

- 对链上的相关站点，均满足 $a_{fa_i} \le a_i$；
- 对链上的相关站点，均满足 $a_{fa_i} \ge a_i$。

也就是说，整条链上各站点相对其父节点的库存比较方向必须保持一致。请输出满足条件的最长链包含多少个站点。

站点个数不超过 `10^5`，每个库存值不超过 `10^5`。

# 输入描述
第一行一个整数 $n$（$1 \le n \le 10^5$），表示站点个数。
第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 10^5$），表示各站点库存。
接下来 $n-1$ 行，每行两个整数 $u_i, v_i$（$1 \le u_i, v_i \le n$，$u_i 
e v_i$），表示站点 $u_i$ 与 $v_i$ 之间有一条通道。
保证输入构成一棵连通的树，且不存在重边。

# 输出描述
输出一个整数，表示满足条件的最长链所包含的站点数量。

## 样例1

**输入**

```
1
9
```

**输出**

```
1
```

**说明**

只有一个站点，最长链就是它本身，答案为 `1`。这是 $n=1$ 的边界情形。

## 样例2

**输入**

```
3
3 2 1
1 2
2 3
```

**输出**

```
3
```

**说明**

三个站点连成一条链，库存为 $3,2,1$，沿根向下单调不增。整条链上相对父节点均满足 $a_{fa_i}\ge a_i$，长度为 `3`。

## 样例3

**输入**

```
1
10
```

**输出**

```
1
```

**说明**

按题意模拟计算得到。
