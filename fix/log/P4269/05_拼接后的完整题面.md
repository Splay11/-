# 题目内容
传送带上依次经过 $n$ 件货物，第 $i$ 件货物的重量用一个数字字符表示，这些字符依次构成长度为 $n$ 的字符串 $s$。字符串仅由字符 `0` 到 `9` 组成，字符对应的整数值即为该件货物的重量。

给定一个偶数 $m$（满足 $2 \le m \le n$）。将 $s$ 中任意一段长度为 $m$ 的连续货物称为一个货窗。若某个货窗的前 $m/2$ 件货物重量之和等于后 $m/2$ 件货物重量之和，则称该货窗为**均载货窗**。

请统计字符串 $s$ 中均载货窗的个数。

约束：每个测试文件包含多组测试数据。测试组数大于 `1` 且小于 `10^4`。每组数据中，货物件数 $n$ 满足 $2 \le n \le 10^6$，货窗宽度 $m$ 为偶数且 $2 \le m \le n$。单个测试文件中所有 $n$ 之和不超过 `10^6`。

# 输入描述
第一行输入一个整数 $q$，表示测试数据组数，满足大于 `1` 且小于 `10^4`。

对于每组测试数据：
第一行输入两个整数 $n$ 和 $m$，分别表示货物件数与货窗宽度，其中 $m$ 为偶数；
第二行输入一个长度为 $n$ 的字符串 $s$，仅由字符 `0` 到 `9` 构成。
保证所有测试数据中 $n$ 的总和不超过 `10^6`。

# 输出描述
对于每组测试数据，输出一行一个整数，表示均载货窗的数量。

## 样例1

**输入**

```
2
4 2
1122
6 4
121212
```

**输出**

```
2
3
```

**说明**

按题意模拟计算得到。
