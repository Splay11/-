# 题目内容
质检线上有 $n$ 个采样点，读数为数组 $a$。对任意窗口 $[l,r]$（$1 \le l < r \le n$），其劣点个数定义为：内部满足 $l < i < r$ 且 $(a_i < a_l)$ 或 $(a_i < a_r)$ 的下标 $i$ 的个数。质量报告需要所有窗口劣点个数之和。请对每组数据输出该总和。

约束：测试组数不超过 `200000`；单组采样点数不超过 `200000`；单个文件中所有 $n$ 之和不超过 `200000`；读数为正整数且不超过 `1000000000`。

# 输入描述
第一行一个整数 $T$，表示测试组数。
每组数据：第一行整数 $n$；第二行 $n$ 个整数 $a_1,a_2,\ldots,a_n$。
保证 $1 \le T \le 200000$，$1 \le n \le 200000$，$1 \le a_i \le 1000000000$，且单个测试文件中所有 $n$ 之和不超过 `200000`。

# 输出描述
对每组数据输出一行一个整数，表示答案。

## 样例1

**输入**

```
3
1
5
5
4 1 3 2 5
3
1 1 1
```

**输出**

```
0
9
0
```

**说明**

长度为 `1` 没有区间，答案 `0`；后两组按三元组容斥：总 $\binom{n}{3}$ 减去两端都不大于中间值的三元组个数。

## 样例2

**输入**

```
2
4
5 1 4 2
6
1 6 2 5 3 4
```

**输出**

```
3
12
```

**说明**

两组分别统计所有夹心位置劣于至少一端点的贡献之和。
