# 题目内容
县域急救路网是一棵 $n$ 个节点的无向带权树，道路 $(u,v)$ 的通行时间为正整数 $w_{uv}$。网上已经建成 $m$ 个互不相同的急救站。调度规程还给出整数 $K$（$1 \le K \le m$）：对每个路口 $v$，把 $v$ 到所有急救站的带权距离从小到大排序，取前 $K$ 个记为 $d_1(v) \le \cdots \le d_K(v)$，定义覆盖指标 $F(v) = \sum_{i=1}^{K} d_i(v)$。

请对每个路口计算 $F(v)$，供值班表评估就近支援能力。

约束：$2 \le m \le n \le 200000$，$1 \le K \le \min(10^2,m)$，边权不超过 `1000000`。

# 输入描述
第一行三个整数 $n,m,K$，分别表示节点数、急救站数和 $K$。
第二行 $m$ 个互不相同的整数 $r_1,\ldots,r_m$，表示急救站编号。
接下来 $n-1$ 行，每行三个整数 $u_i,v_i,w_i$，表示一条无向带权边。
保证 $2 \le m \le n \le 200000$，$1 \le K \le \min(10^2,m)$，$1 \le r_i \le n$，$1 \le u_i,v_i \le n$，$u_i 
eq v_i$，$1 \le w_i \le 1000000$，输入构成一棵树。

# 输出描述
输出一行 $n$ 个整数 $F(1),F(2),\ldots,F(n)$，用空格分隔。

## 样例1

**输入**

```
4 2 1
1 4
1 2 3
2 3 4
3 4 5
```

**输出**

```
0 3 5 0
```

**说明**

$K=1$，即每个点到最近仓储节点的距离。仓储在 `1` 和 `4`，链上边权为 `3,4,5`，因此 $F=(0,3,5,0)$。

## 样例2

**输入**

```
6 3 2
1 3 6
1 2 2
2 3 3
3 4 4
4 5 5
2 6 6
```

**输出**

```
5 5 5 13 23 8
```

**说明**

$K=2$，对每个节点取到最近两个仓储节点的距离之和。例如节点 `1` 到仓储 `1` 距离 `0`、到仓储 `3` 距离 `5`，和为 `5`；节点 `5` 距离仓储较远，和为 `23`。

## 样例3

**输入**

```
3 3 2
1 2 3
1 2 10
2 3 10
```

**输出**

```
10 10 10
```

**说明**

三个节点都是仓储。$K=2$ 时，每个点贡献自身距离 `0` 再加到另一仓储的最近距离 `10`，因此三个 $F$ 都是 `10`。
