# 题目内容
在一条无限长的操作台上，从左到右依次摆放着若干个桶，初始时桶均为空。现在要依次放入 $n$ 个球，第 $i$ 个球的质量为 $w_i$。放置规则如下：
- 从最左侧的桶开始向右检查；
- 若当前桶为空，或者该桶最上方球的质量严格大于当前球的质量，则将当前球放入这个桶的顶部；
- 否则继续检查下一个桶；
- 若检查完所有非空桶后仍未放入，则在最右侧新建一个空桶，并将当前球放入其中。

每次放入一个球后，记每个桶的高度为该桶中球的个数。请你求出每次放入后所有桶高度的异或和，并依次输出。

数据范围：一个输入文件可能包含多组测试数据，组数 $T$ 满足 $1 \le T \le 2	imes 10^5$，每组中 $n$ 的总和不超过 $4	imes 10^5$。单个 $n$ 满足 $1 \le n \le 4	imes 10^5$。所有球的质量 $w_i$ 满足 $1 \le w_i \le 10^9$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据组数。接下来每组数据由两行构成：第一行包含一个整数 $n$，表示球的数量；第二行包含 $n$ 个整数 $w_1, w_2, \dots, w_n$，依次表示每个球的质量。

# 输出描述
对于每组数据，输出一行，包含 $n$ 个整数（以空格分隔），第 $i$ 个整数表示放入前 $i$ 个球后，所有桶高度的异或和。

## 样例1

**输入**

```
1
1
5
```

**输出**

```
1
```

**说明**

只有 `1` 个球，质量 $w_1=5$。初始无桶，放入时新建一个桶，该桶高度变为 `1`。所有桶高度的异或和即为 `1`。

## 样例2

**输入**

```
1
4
2 1 2 3
```

**输出**

```
1 2 3 2
```

**说明**

共 `4` 个球，质量依次为 `2, 1, 2, 3`。
- 放入 `2`：无桶，新建桶，高度 $h=[1]$，异或和 `1`；
- 放入 `1`：最左侧桶顶为 `2`，$2>1$，放入该桶，高度变为 `2`，异或和变为 $1 \oplus 1 \oplus 2 = 2$；
- 放入 `2`：第一个桶顶为 `1`，不大于 `2`；没有桶顶严格大于 `2`，新建桶，$h=[2,1]$，异或和 $2 \oplus 1 = 3$；
- 放入 `3`：没有桶顶大于 `3`，新建桶，$h=[2,1,1]$，异或和 $3 \oplus 1 = 2$。

## 样例3

**输入**

```
1
5
10 20 10 20 5
```

**输出**

```
1 0 3 2 1
```

**说明**

共 `5` 个球，质量 `10, 20, 10, 20, 5`。
- 放入 `10`：新建桶，$h=[1]$，异或和 `1`；
- 放入 `20`：无桶顶 $>20$，新建桶，$h=[1,1]$，异或和 `0`；
- 放入 `10`：第一个桶顶 `10` 不大于 `10`，第二个桶顶 `20>10`，放入第二个桶，其高度由 `1` 变为 `2`，异或和 $0 \oplus 1 \oplus 2 = 3$；
- 放入 `20`：无桶顶 $>20$，新建桶，$h=[1,2,1]$，异或和 $3 \oplus 1 = 2$；
- 放入 `5`：第一个桶顶 `10>5`，放入第一个桶，高度由 `1` 变为 `2`，异或和 $2 \oplus 1 \oplus 2 = 1$。
