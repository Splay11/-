# 题目内容
在炼制一种新型药剂时，炼金术师需要从 $n$ 种原料中选取 $3$ 种不同的原料混合。每种原料有一个稳定值 $a_i$。如果选取的三种原料中，稳定值最高的那一个的数值不低于另外两种的稳定值之和，混合过程就会发生剧烈爆炸。

现在，炼金术师完全随机地挑选三种不同原料，每种组合被选中的概率相等。请你计算发生爆炸的概率。

更形式化地，给定长度为 $n$ 的序列 $a_1, a_2, \dots, a_n$。称一个由三个不同下标构成的三元组 $(i, j, k)$ 是危险的，若将对应的值排序后得到 $x \le y \le z$，满足 $z \ge x + y$。你需要求出危险三元组在所有 $\binom{n}{3}$ 个三元组中所占的比例，即概率 $P/Q$（其中 $Q = \binom{n}{3}$，$P$ 为危险三元组数量）。

答案需要对 $M = 10^9+7$ 取模，即输出一个整数 $x \in [0, M)$，使得 $x \cdot Q \equiv P \pmod{M}$。保证 $Q$ 与 $M$ 互质，因此这样的 $x$ 唯一存在。

约束条件：
- 原料数量 $n$ 满足 $3 \le n \le 2 \times 10^5$。
- 每个稳定值 $a_i$ 均为整数，且 $1 \le a_i \le 5000$。

# 输入描述
第一行包含一个整数 $n$，表示原料的数量。
第二行包含 $n$ 个整数，第 $i$ 个整数为 $a_i$，表示第 $i$ 种原料的稳定值，相邻整数之间用一个空格分隔。

# 输出描述
输出一个整数，表示爆炸概率对 $10^9+7$ 取模后的结果。

## 样例1

**输入**

```
3
5 5 10
```

**输出**

```
1
```

**说明**

原料为 `5`, `5`, `10`。共有 $\binom{3}{3}=1$ 个三元组，取出的三个值为 $(5, 5, 10)$。排序后 $x=5$, $y=5$, $z=10$，满足 $z = 10 \ge 5 + 5 = 10$，因此该三元组是危险三元组。危险三元组数量 $P=1$，总三元组数量 $Q=1$，概率为 $1$，取模后输出 `1`。

## 样例2

**输入**

```
4
1 1 1 1
```

**输出**

```
0
```

**说明**

所有原料的稳定值均为 `1`。任意一个三元组排序后都有 $x=y=z=1$。此时 $z = 1$，$x + y = 2$，条件 $z \ge x + y$ 始终不成立，因此不存在任何危险三元组。$P=0$，概率为 $0$，输出 `0`。

## 样例3

**输入**

```
4
2 2 3 4
```

**输出**

```
250000002
```

**说明**

原料稳定值为 `2`, `2`, `3`, `4`。总三元组数 $Q = \binom{4}{3} = 4$，具体为：
- $(2,2,3)$：$x=2$, $y=2$, $z=3$，$3 < 4$，不危险；
- $(2,2,4)$：$x=2$, $y=2$, $z=4$，$4 \ge 4$，危险；
- $(2,3,4)$（有两个 $2$，故该组合出现两次）：$x=2$, $y=3$, $z=4$，$4 < 5$，不危险。
因此危险三元组数量 $P=1$。概率为 $1/4$。在模 $10^9+7$ 下，$4^{-1} \equiv 250000002$，所以输出 `250000002`。

## 样例4

**输入**

```
5
1 2 3 4 5
```

**输出**

```
900000007
```

**说明**

原料为 `1`, `2`, `3`, `4`, `5`。总三元组数 $Q = \binom{5}{3} = 10$。
满足 $z \ge x + y$ 的危险三元组有：
$(1,2,3)$, $(1,2,4)$, $(1,2,5)$, $(1,3,4)$, $(1,3,5)$, $(1,4,5)$, $(2,3,5)$，共 $7$ 个。
其余 $3$ 个三元组 $(2,3,4)$, $(2,4,5)$, $(3,4,5)$ 不满足条件。
因此 $P = 7$，概率为 $7/10$。模 $10^9+7$ 下 $10^{-1} \equiv 700000005$，$7 \times 700000005 = 900000007$，输出 `900000007`。
