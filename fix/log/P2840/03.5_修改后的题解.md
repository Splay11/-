## 解题思路

本题要求在所有 $\binom{n}{3}$ 个三元组中，计算危险三元组（排序后最大稳定值不小于另两个稳定值之和）所占的比例，并对 $M=10^9+7$ 取模。  
记 $P$ 为危险三元组的数量，$Q=\binom{n}{3}$，则需要输出 $P\cdot Q^{-1}\bmod M$。

由于稳定值 $a_i$ 的范围很小（$1\le a_i\le 5000$），可以采用 **频数统计 + 前缀和** 的方法枚举所有危险三元组。

1. **统计频数与构造前缀和**  
   设 `cnt[v]` 表示稳定值为 $v$ 的原料数量（$v=1\dots 5000$）。  
   再构造前缀和数组 `pre[v] = cnt[1] + cnt[2] + \dots + cnt[v]`。

2. **枚举危险三元组**  
   三个不同元素排序后记作 $x\le y\le z$，其危险的充要条件为 $z\ge x+y$。  
   我们可以枚举最大的稳定值 $z$（$1\le z\le 5000$，且 `cnt[z]>0`），对每个 $z$ 统计满足 $x\le y<z,\;x+y\le z$ 的二元组 $(x,y)$ 的选取方式数，再乘以挑选该 $z$ 的方式数 `cnt[z]`，累加即得到所有危险三元组数 $P$。  

   对于固定的 $z$，枚举较小的值 $x$（只需 $x\le \lfloor z/2\rfloor$，因为当 $x>z/2$ 时有 $x+x>z$，不可能再满足 $x+y\le z$）。  
   令 $y$ 的上界 $j_{\max}=z-x$，此时 $y$ 的取值范围为 $[x,\, j_{\max}]$。  
   - 若 $y=x$，组合数为 $\binom{cnt[x]}{2}$；  
   - 若 $y>x$，组合数为 $cnt[x] \times \big(\sum_{y=x+1}^{j_{\max}} cnt[y]\big) = cnt[x] \times (pre[j_{\max}] - pre[x])$。  
   将两部分的组合数相加，模 $M$ 后即为对应该 $x$ 的二元组数目。累加所有 $x$ 得到 `pairCount`，再乘以 `cnt[z]` 累加进 $P$。

3. **计算概率**  
   总三元组数 $Q = \binom{n}{3} = \frac{n(n-1)(n-2)}{6}$，模 $M$ 下用乘法逆元计算。  
   最终答案 $= P \times \big(Q\big)^{-1} \bmod M$，使用费马小定理求逆元即可。

## 复杂度分析

- **时间复杂度**：$O(V^2)$，其中 $V=5000$ 是稳定值的最大值。  
  外循环 $z$ 从 $1$ 至 $5000$，内循环 $x$ 从 $1$ 至 $z/2$，总循环次数约 $\frac{V^2}{4}\approx 6.25\times 10^6$，可以轻松通过。  
- **空间复杂度**：$O(V)$，主要用于存储 `cnt` 和 `pre` 数组。

## 代码实现

### Python

```python
MOD = 1000000007

def main():
    import sys
    input = sys.stdin.readline
    
    n = int(input())
    a = list(map(int, input().split()))
    
    MAX = 5000
    cnt = [0] * (MAX + 1)
    for v in a:
        cnt[v] += 1
        
    pre = [0] * (MAX + 1)
    for i in range(1, MAX + 1):
        pre[i] = pre[i - 1] + cnt[i]
        
    inv6 = pow(6, MOD - 2, MOD)
    
    P = 0  # 危险三元组数量
    for z in range(1, MAX + 1):
        if cnt[z] == 0:
            continue
        pair_cnt = 0
        for x in range(1, z // 2 + 1):
            jmax = z - x
            # y == x
            ways_same = 0
            if cnt[x] >= 2:
                ways_same = (cnt[x] * (cnt[x] - 1) // 2) % MOD
            # y > x
            ways_diff = (cnt[x] * (pre[jmax] - pre[x])) % MOD
            pair_cnt = (pair_cnt + ways_same + ways_diff) % MOD
        P = (P + pair_cnt * cnt[z]) % MOD
        
    Q = (n * (n - 1) % MOD * (n - 2) % MOD) * inv6 % MOD
    ans = P * pow(Q, MOD - 2, MOD) % MOD
    print(ans)

if __name__ == '__main__':
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    static final long MOD = 1000000007;
    
    static long modPow(long base, long exp, long mod) {
        long res = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) res = (res * base) % mod;
            base = (base * base) % mod;
            exp >>= 1;
        }
        return res;
    }
    
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        PrintWriter out = new PrintWriter(System.out);
        
        int n = Integer.parseInt(br.readLine().trim());
        int MAX = 5000;
        long[] cnt = new long[MAX + 1];
        
        StringTokenizer st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            int v = Integer.parseInt(st.nextToken());
            cnt[v]++;
        }
        
        long[] pre = new long[MAX + 1];
        for (int i = 1; i <= MAX; i++) {
            pre[i] = pre[i - 1] + cnt[i];
        }
        
        long inv6 = modPow(6, MOD - 2, MOD);
        long P = 0;
        
        for (int z = 1; z <= MAX; z++) {
            if (cnt[z] == 0) continue;
            long pairCnt = 0;
            for (int x = 1; x <= z / 2; x++) {
                int jmax = z - x;
                // y == x
                long waysSame = 0;
                if (cnt[x] >= 2) {
                    waysSame = (cnt[x] * (cnt[x] - 1) / 2) % MOD;
                }
                // y > x
                long waysDiff = (cnt[x] * ((pre[jmax] - pre[x]) % MOD)) % MOD;
                pairCnt = (pairCnt + waysSame + waysDiff) % MOD;
            }
            P = (P + (pairCnt * (cnt[z] % MOD)) % MOD) % MOD;
        }
        
        long Q = (((long)n * (n - 1) % MOD) * (n - 2) % MOD) * inv6 % MOD;
        long ans = (P * modPow(Q, MOD - 2, MOD)) % MOD;
        out.println(ans);
        out.flush();
        out.close();
    }
}
```
