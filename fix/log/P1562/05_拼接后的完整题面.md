# 题目内容
在一次探险中，你发现了一个古老的密码盘，上面记录着一种特殊的排列构造规则。对于一个长度为 $n$ 的排列 $p$（即包含 $1$ 到 $n$ 每个整数恰好一次的数组），要求它满足：对于每个 $1 \le i \le n$，都有 $p_{p_i} = n - i + 1$。

你的任务是：给定整数 $n$，还原出任意一个满足上述条件的排列，如果不存在则输出 $-1$。

数据范围：$n$ 不超过 $10^5$。

# 输入描述
第一行包含一个整数 $n$ ($1 \le n \le 10^5$)，表示排列的长度。

# 输出描述
如果存在满足条件的排列，在一行内输出 $n$ 个整数，以空格分隔，表示该排列；如果不存在，则输出 $-1$。如果有多个解，输出任意一个即可。

## 样例1

**输入**

```
1
```

**输出**

```
1
```

**说明**

当 $n=1$ 时，排列只有 $p=[1]$。
验证：$p_{p_1}=p_1=1$，而 $n-1+1=1$，条件满足。
因此输出 `1`。

## 样例2

**输入**

```
2
```

**输出**

```
-1
```

**说明**

当 $n=2$ 时，尝试所有可能排列 $[1,2]$ 和 $[2,1]$。
对于 $[1,2]$，$p_{p_1}=1$，但 $n-1+1=2$，不满足。
对于 $[2,1]$，$p_{p_1}=1$，要求 $2$，也不满足。
因此不存在合法排列，输出 `-1`。

## 样例3

**输入**

```
4
```

**输出**

```
2 4 1 3
```

**说明**

当 $n=4$ 时，构造排列 $p=[2,4,1,3]$。
验证：$i=1$: $p_{p_1}=p_2=4=4-1+1$；$i=2$: $p_{p_2}=p_4=3=4-2+1$；$i=3$: $p_{p_3}=p_1=2=4-3+1$；$i=4$: $p_{p_4}=p_3=1=4-4+1$。
全部满足条件。

## 样例4

**输入**

```
9
```

**输出**

```
2 9 4 7 5 3 6 1 8
```

**说明**

当 $n=9$ 时，将元素分为两个长度为 $4$ 的循环和一个固定点。
循环 $(1,2,9,8)$：$p_1=2$，$p_2=9$，$p_9=8$，$p_8=1$。
循环 $(3,4,7,6)$：$p_3=4$，$p_4=7$，$p_7=6$，$p_6=3$。
固定点 $p_5=5$。
得到排列 $[2,9,4,7,5,3,6,1,8]$，经验证满足 $p_{p_i}=10-i$。
