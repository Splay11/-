## 解题思路

本题要求构造一个排列 $p$，满足对于任意 $1\le i\le n$ 都有 $p_{p_i}=n-i+1$。通过分析条件可以得出，只有当 $n$ 除以 $4$ 余 $0$ 或余 $1$ 时才有解，否则输出 $-1$。  
原因：将等式两边再次应用条件可以得到 $p_i$ 与索引之间的关系，经推导和尝试可知，当 $n \bmod 4 = 2$ 或 $n \bmod 4 = 3$ 时，无法形成合法的闭环映射，而 $n \bmod 4 = 0$ 或 $1$ 时存在构造方案。

构造方法如下（使用 $1$ 为起始索引）：

- 从 $i=1$ 开始，每次增加 $2$，直到 $i\le \lfloor n/2\rfloor$。对于每一个 $i$，同时设置四个位置的值：
  - $p_i = i+1$
  - $p_{i+1} = n-i+1$
  - $p_{n-i+1} = n-i$
  - $p_{n-i} = i$
- 如果 $n$ 是奇数（即 $n \bmod 4 = 1$），还需要设置中间位置 $p_{\lfloor n/2\rfloor + 1} = \lfloor n/2\rfloor + 1$。

这样构造出的排列能够满足题目要求，且所有数在 $1$ 到 $n$ 之间恰好出现一次。

例如：
- $n=4$（$4\bmod 4=0$）：按上述步骤得到 $[2,4,1,3]$。
- $n=5$（$5\bmod 4=1$）：中间位置为 $3$，其余按照规则填充，得到 $[2,4,5,1,3]$（其中 $5$ 实际为中间值 $3$，这里符合题意：$n=5$ 时中间值为 $3$）。具体构造结果为 $[2,4,3,1,5]$？需要校验，但原题解 C++ 代码生成的是：对于 $n=5$，i=1 时 p[1]=2, p[2]=5, p[5]=4, p[4]=1；然后 i=3 超出 n/2=2 不执行；奇数时中间 p[3]=3，最终得到 [2,5,3,1,4]？再检查原题解 C++ 代码逻辑：n=5，i从1到2步长2，i=1：a[1]=2, a[2]=5, a[5]=4, a[4]=1。然后奇数情况 a[3]=3。结果数组 a[1..5]=[2,5,3,1,4]。但原题解给了例子 n=5 得到 [2,4,5,1,3] 是错误的，可能是原题解举例有误。但是方法确实满足条件，我们只是输出任意合法解。因此我们按照代码逻辑构造即可，不必纠结例子。代码能通过题目检查。所以解题思路中只描述正确构造算法即可，不举错误例子。

## 复杂度分析

- 时间复杂度：$O(n)$。只需一次线性扫描到 $n/2$ 进行赋值，奇数时额外赋值一次，总操作次数与 $n$ 成正比。
- 空间复杂度：$O(n)$。需要长度为 $n+1$ 的数组存储排列（输出不计入额外空间）。

## 代码实现

### Python

```python
n = int(input())

if n % 4 != 0 and n % 4 != 1:
    print(-1)
else:
    # 使用 1-indexed 数组，多开一位
    p = [0] * (n + 1)
    # 按照步长 2 构造对称位置
    for i in range(1, n // 2 + 1, 2):
        p[i] = i + 1
        p[i + 1] = n - i + 1
        p[n - i + 1] = n - i
        p[n - i] = i
    # 如果 n 为奇数，设置中心点
    if n % 2 == 1:
        mid = n // 2 + 1
        p[mid] = mid
    # 输出排列
    print(' '.join(map(str, p[1:])))
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        if (n % 4 != 0 && n % 4 != 1) {
            System.out.println(-1);
            return;
        }
        int[] p = new int[n + 1];
        for (int i = 1; i <= n / 2; i += 2) {
            p[i] = i + 1;
            p[i + 1] = n - i + 1;
            p[n - i + 1] = n - i;
            p[n - i] = i;
        }
        if (n % 2 == 1) {
            int mid = n / 2 + 1;
            p[mid] = mid;
        }
        for (int i = 1; i <= n; i++) {
            System.out.print(p[i] + (i == n ? "\n" : " "));
        }
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n % 4 != 0 && n % 4 != 1) {
        cout << -1 << endl;
        return 0;
    }
    vector<int> p(n + 1);
    for (int i = 1; i <= n / 2; i += 2) {
        p[i] = i + 1;
        p[i + 1] = n - i + 1;
        p[n - i + 1] = n - i;
        p[n - i] = i;
    }
    if (n % 2 == 1) {
        int mid = n / 2 + 1;
        p[mid] = mid;
    }
    for (int i = 1; i <= n; i++) {
        cout << p[i] << (i == n ? "\n" : " ");
    }
    return 0;
}
```
