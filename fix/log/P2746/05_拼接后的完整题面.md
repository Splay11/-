# 题目内容
高铁站到发屏采用 `24` 小时制显示当前时刻，格式为 `hh:mm`。值班员把小时和分钟的四位数字直接拼接（不足两位时补前导 `0`），若得到的长度为 `4` 的字符串正读与反读相同，则称该时刻为对称到点。给定一个合法的当前时刻，求从此时刻起最少再过多少分钟会到达一个对称到点。若当前已经是对称到点，答案为 `0`。一天有 `24` 小时，每小时 `60` 分钟；经过 `23:59` 后进入下一天的 `00:00`。

# 输入描述
输入一行一个合法时间，格式为 `hh:mm`，其中 `hh` 为小时、`mm` 为分钟，均用两位数字表示，采用 `24` 小时制。

# 输出描述
输出一个整数，表示到达最近对称到点还需要经过的分钟数。

## 样例1

**输入**

```
00:00
```

**输出**

```
0
```

**说明**

拼接得到 `0000`，正反读相同，当前已是镜像时刻，答案为 `0`。

## 样例2

**输入**

```
12:10
```

**输出**

```
11
```

**说明**

从 `12:10` 起逐分钟检查，经过 `11` 分钟到达 `12:21`。拼接为 `1221`，正反读相同。

## 样例3

**输入**

```
11:11
```

**输出**

```
0
```

**说明**

拼接得到 `1111`，本身就是镜像时刻，答案为 `0`。

## 样例4

**输入**

```
22:58
```

**输出**

```
34
```

**说明**

从 `22:58` 继续走 `34` 分钟到达 `23:32`。拼接为 `2332`，正反读相同。
