## 解题思路

一天最多只有 $24\times 60=1440$ 个时刻，直接从当前时间开始每次加一分钟并检查即可。把小时和分钟格式化成四位字符串（不足两位补 `0`），判断它是否等于自己的反转。找到第一个对称到点时，累加的分钟数就是答案。分钟到 `60` 时小时进位，小时到 `24` 时归零进入下一天。

## 复杂度分析

时间复杂度 $O(1)$（最多检查 $1440$ 个时刻），空间复杂度 $O(1)$。

## 代码实现

### Python

```python
def is_palindrome(h, m):
    time_str = f"{h:02d}{m:02d}"
    return time_str == time_str[::-1]

time = input().strip()
h, m = map(int, time.split(':'))
minutes = 0

while True:
    if is_palindrome(h, m):
        print(minutes)
        break
    m += 1
    minutes += 1
    if m == 60:
        m = 0
        h += 1
        if h == 24:
            h = 0
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static boolean isPalindrome(int h, int m) {
        String timeStr = String.format("%02d%02d", h, m);
        return timeStr.equals(new StringBuilder(timeStr).reverse().toString());
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String time = scanner.next();
        String[] parts = time.split(":");
        int h = Integer.parseInt(parts[0]);
        int m = Integer.parseInt(parts[1]);
        int minutes = 0;

        while (true) {
            if (isPalindrome(h, m)) {
                System.out.println(minutes);
                break;
            }
            m++;
            minutes++;
            if (m == 60) {
                m = 0;
                h++;
                if (h == 24) {
                    h = 0;
                }
            }
        }
    }
}
```

    return timeStr == string(timeStr.rbegin(), timeStr.rend());
}
