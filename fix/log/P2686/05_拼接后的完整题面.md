# 题目内容
质检线上依次放着 $n$ 件样品，第 $i$ 件的批次编号为 $a_i$。一件样品的风险指数定义为它的不同质因子个数（例如 `4` 只有质因子 `2`，指数为 `1`；`1` 没有质因子，指数为 `0`）。必须整段下线一段长度恰好为 $k$ 的连续样品，使得留下样品的风险指数之和最大。求这个最大和。

约束：$1 \le k \le n \le 100000$，$1 \le a_i \le 10000$。

# 输入描述
第一行两个整数 $n$ 和 $k$，表示样品件数和必须下线的连续段长度。
第二行 $n$ 个正整数 $a_1,a_2,\ldots,a_n$。
保证 $1 \le k \le n \le 100000$，$1 \le a_i \le 10000$。

# 输出描述
输出一个整数，表示下线一段长度为 $k$ 的连续样品后，剩余风险指数之和的最大值。

## 样例1

**输入**

```
4 1
1 30 7 1
```

**输出**

```
4
```

**说明**

各数权值：`1` 为 `0`，`30`=$2 \times 3 \times 5$ 为 `3`，`7` 为 `1`。总权值和为 `4`。删除长度为 `1` 的最小权值窗口即可删掉某个 `0`，剩余仍为 `4`。

## 样例2

**输入**

```
6 3
10 15 21 14 8 1
```

**输出**

```
6
```

**说明**

权值序列为 `2,2,2,2,1,0`，总和 `9`。长度为 `3` 的窗口权值和最小是末尾 $2+1+0=`3`$，删除后剩余 `6`。

## 样例3

**输入**

```
3 3
2 4 8
```

**输出**

```
0
```

**说明**

$k=n$，必须删掉整个数组，剩余为空，权值和为 `0`。
