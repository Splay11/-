# 题目内容
在一个数轴的正整数点上，探险家从初始位置 $N$ 出发。每一步可以将当前位置加 $1$ 或减 $1$，但移动过程中必须始终停留在正整数上（即位置不能变为 $0$ 或负数）。

对于一个正整数 $x$，定义它的**数位能量** $E(x)$ 为 $x$ 在十进制下各位数字之和。例如 $E(123)=1+2+3=6$。

给定最大移动步数 $K$，探险家希望从 $N$ 出发，在不超过 $K$ 步的前提下，到达一个数位能量尽可能大的位置。请你求出能够获得的最大数位能量。

约束条件：初始位置 $N$ 满足 $1 \le N \le 10^9$，最大步数 $K$ 满足 $1 \le K \le 10^6$。

# 输入描述
第一行包含两个整数 $N$ 和 $K$，分别表示初始位置和最大移动步数，两者之间用空格分隔。

# 输出描述
输出一个整数，表示在不超过 $K$ 步的移动限制下，能够到达的位置的数位能量的最大值。

## 样例1

**输入**

```
19 2
```

**输出**

```
10
```

**说明**

从 `19` 出发，最多移动 `2` 步。可到达的位置有 `17`、`18`、`19`、`20`、`21`。分别计算数位能量：$E(17)=1+7=8$，$E(18)=9$，$E(19)=10$，$E(20)=2$，$E(21)=3$。最大值是 `10`，因此输出 `10`。

## 样例2

**输入**

```
1 1000000
```

**输出**

```
54
```

**说明**

初始位置 $N=1$，最大步数 $K=1000000$。由于不能移动到 `0` 或负数，只能向右移动。经过最多 `1000000` 步后，可到达区间 $[1, 1000001]$ 内的任意整数。在这个区间内，数位和最大的数是 `999999`，其各位数字之和为 $9+9+9+9+9+9=54$。不可能获得更大的数位和，因此输出 `54`。

## 样例3

**输入**

```
1000000000 1
```

**输出**

```
81
```

**说明**

初始位置 $N=10^9$，最大步数 $K=1$。可到达的位置有 `999999999`（向左移动 `1` 步）、`1000000000`（不动）和 `1000000001`（向右移动 `1` 步）。数位能量分别为 $E(999999999)=9 \times 9 = 81$，$E(1000000000)=1$，$E(1000000001)=2$。最大值为 `81`，因此输出 `81`。
