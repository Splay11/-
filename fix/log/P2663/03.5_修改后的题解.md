## 解题思路

1. 问题等价于：在最多移动 $K$ 步的条件下，探险家能从初始位置 $N$ 到达的所有整数位置中，找出**数位能量** $E(x)$ 的最大值。
2. 每次移动只能将位置加 $1$ 或减 $1$，且过程中不能踏足 $0$ 或负数。因此，经过不超过 $K$ 步之后，可到达的位置集合恰好是区间  
   \[
   [\max(1,\ N-K),\ N+K]
   \]  
   中的所有正整数。这区间内的任何一个位置都可以在不超过 $K$ 步内安全到达。
3. 直接枚举该区间内的每一个正整数 $x$，计算其数位能量 $E(x)$（即 $x$ 的十进制各位数字之和），并记录最大值即可。
4. 由于 $K$ 最大为 $10^6$，区间长度最多约 $2\times 10^6$，每次求数字和的复杂度为 $O(\log_{10} x)$，整体运算量在可接受范围内。

## 复杂度分析

- **时间复杂度**：$O(K \log_{10} (N+K))$。枚举区间长度约为 $2K+1$，每个数计算数位能量的复杂度为 $O(\log_{10} (N+K))$。
- **空间复杂度**：$O(1)$。仅使用若干个变量存储中间结果，不需要额外数据结构。

## 代码实现

### Python

```python
# 计算正整数 x 的数位能量 (各位数字之和)
def digit_energy(x):
    s = 0
    while x > 0:
        s += x % 10
        x //= 10
    return s

def main():
    N, K = map(int, input().split())
    
    # 枚举的下界（不能小于 1）
    start = max(1, N - K)
    # 枚举的上界
    end = N + K
    
    max_energy = 0
    # 遍历所有可达位置，记录最大的数位能量
    for x in range(start, end + 1):
        e = digit_energy(x)
        if e > max_energy:
            max_energy = e
    
    print(max_energy)

if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    // 计算正整数 x 的数位能量
    public static int digitEnergy(long x) {
        int sum = 0;
        while (x > 0) {
            sum += (x % 10);
            x /= 10;
        }
        return sum;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        long N = sc.nextLong();
        long K = sc.nextLong();
        sc.close();

        // 枚举下界（不能小于 1）
        long start = Math.max(1, N - K);
        // 枚举上界
        long end = N + K;

        int maxEnergy = 0;
        for (long x = start; x <= end; x++) {
            int e = digitEnergy(x);
            if (e > maxEnergy) {
                maxEnergy = e;
            }
        }

        System.out.println(maxEnergy);
    }
}
```

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

// 计算正整数 x 的数位能量
int digitEnergy(long long x) {
    int sum = 0;
    while (x > 0) {
        sum += x % 10;
        x /= 10;
    }
    return sum;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long N, K;
    cin >> N >> K;

    // 枚举下界（不能小于 1）
    long long start = max(1LL, N - K);
    // 枚举上界
    long long end = N + K;

    int maxEnergy = 0;
    for (long long x = start; x <= end; x++) {
        int e = digitEnergy(x);
        if (e > maxEnergy) {
            maxEnergy = e;
        }
    }

    cout << maxEnergy << "\n";
    return 0;
}
```
