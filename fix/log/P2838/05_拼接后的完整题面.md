# 题目内容
在数据分析中，工程师小蓝采集了一组随时间变化的数据序列。为了衡量一段连续时间段内数据的波动程度，定义该时间段内相邻两个采集点之差的绝对值之和为“波动和”。现在小蓝需要快速回答多次关于不同时间区间的波动和查询。

给定一个长度为 $n$ 的序列 $a_1, a_2, \dots, a_n$。对于区间 $[l, r]$，其波动和定义为 $\sum_{i=l}^{r-1} |a_i - a_{i+1}|$。若区间长度为 $1$（即 $l = r$），规定波动和为 $0$。请你帮助小蓝高效地回答多次查询。

数据规模：序列长度 $n$ 与查询次数 $q$ 均不超过 $10^5$；序列中的每个数值 $a_i$ 满足 $1 \le a_i \le 10^9$；每次查询的区间 $[l, r]$ 满足 $1 \le l \le r \le n$。

# 输入描述
第一行包含一个正整数 $n$，表示序列的长度。
第二行包含 $n$ 个正整数 $a_1, a_2, \dots, a_n$，相邻数字之间以空格分隔。
第三行包含一个正整数 $q$，表示查询的次数。
接下来的 $q$ 行，每行包含两个正整数 $l$ 和 $r$，表示一次查询的区间左右端点。

# 输出描述
输出 $q$ 行，每行一个整数，依次表示每次查询对应区间的波动和。

## 样例1

**输入**

```
4
10 20 30 40
4
1 1
2 4
3 4
1 4
```

**输出**

```
0
20
10
30
```

**说明**

序列为 $a = [10, 20, 30, 40]$。

首先计算相邻元素之差的绝对值：$|20-10| = 10$，$|30-20| = 10$，$|40-30| = 10$。

- 查询 $[1, 1]$ 区间长度为 `1`，波动和规定为 `0`。
- 查询 $[2, 4]$ 对应子数组 $[20, 30, 40]$，波动和为 $|30-20| + |40-30| = 10 + 10 = 20$。
- 查询 $[3, 4]$ 对应 $[30, 40]$，波动和为 $|40-30| = 10$。
- 查询 $[1, 4]$ 对应整个序列，波动和为 $10 + 10 + 10 = 30$。

## 样例2

**输入**

```
3
5 5 5
2
1 2
1 3
```

**输出**

```
0
0
```

**说明**

序列 $a = [5, 5, 5]$ 中所有元素均相等，因此任意相邻差绝对值均为 $0$。对于任何区间，无论长度如何，波动和始终为 `0`。

## 样例3

**输入**

```
5
1 5 2 6 3
4
1 5
2 4
3 3
4 5
```

**输出**

```
14
7
0
3
```

**说明**

序列 $a = [1, 5, 2, 6, 3]$。相邻差绝对值依次为：$|5-1| = 4$，$|2-5| = 3$，$|6-2| = 4$，$|3-6| = 3$。

前缀和：设 $pre[0]=0$，$pre[1]=0$，$pre[2]=4$，$pre[3]=4+3=7$，$pre[4]=7+4=11$，$pre[5]=11+3=14$。

- 查询 $[1, 5]$：波动和为 $pre[5] - pre[1] = 14$。
- 查询 $[2, 4]$：波动和为 $pre[4] - pre[2] = 11 - 4 = 7$（对应 $|2-5| + |6-2| = 3+4=7$）。
- 查询 $[3, 3]$：长度为 `1`，波动和为 `0`。
- 查询 $[4, 5]$：波动和为 $|3-6| = 3$。
