## 解题思路

本题需要多次查询序列某个区间内相邻元素之差的绝对值之和（称为波动和）。若直接对每个查询遍历区间求和，时间复杂度为 $O(n \times q)$，在 $n,q \le 10^5$ 时会超时。我们可以利用前缀和技巧将单次查询优化到 $O(1)$。

1. **定义辅助数组**  
   令 `diff[i] = |a[i] - a[i-1]|`，表示第 $i-1$ 个数据与第 $i$ 个数据之间的波动贡献（采用 $0$ 基下标时，`diff[1]` 对应于 $|a_2 - a_1|$，以此类推）。

2. **构建前缀和数组**  
   定义 `pre[i]` 表示前 $i$ 个相邻差值的总和，即：
   \[
   pre[0] = 0,\quad pre[i] = pre[i-1] + |a_i - a_{i-1}| \quad (1 \le i < n)
   \]
   这里为了方便处理，我们在代码中使用长度为 $n$ 的数组，`pre[i]` 表示从第 $1$ 个数到第 $i$ 个数之间所有相邻差的绝对值之和（即区间 $[1, i]$ 的波动和）。

3. **快速回答查询**  
   对于查询 $[l, r]$，若 $l = r$，区间长度为 $1$，波动和直接为 $0$。  
   当 $l < r$ 时，波动和定义为 $\sum_{i=l}^{r-1} |a_i - a_{i+1}|$。  
   利用前缀和，该值等于 `pre[r-1] - pre[l-1]`（数组下标从 $0$ 开始）。  
   解释：`pre[r-1]` 包含了从第 $1$ 到第 $r-1$ 个相邻差的总和，`pre[l-1]` 包含了从第 $1$ 到第 $l-1$ 个相邻差的总和，相减即得到第 $l$ 到第 $r-1$ 个相邻差的和。

4. 按照上述方法，预处理前缀和的时间为 $O(n)$，每个查询 $O(1)$，总时间复杂度 $O(n+q)$，可以轻松通过本题。

## 复杂度分析

- 时间复杂度：$O(n+q)$。预处理前缀和需要遍历一次数组，每次查询直接使用前缀和相减。
- 空间复杂度：$O(n)$。需要存储原数组（可选）以及前缀和数组。

## 代码实现

### Python

```python
n = int(input())                      # 序列长度
a = list(map(int, input().split()))   # 序列元素
q = int(input())                      # 查询次数

# 预处理前缀和数组 pre，pre[i] 表示区间 [1, i] 的波动和（0-indexed）
pre = [0] * n
for i in range(1, n):
    pre[i] = pre[i - 1] + abs(a[i] - a[i - 1])

# 依次处理查询
for _ in range(q):
    l, r = map(int, input().split())
    # 区间长度为1时结果为0，公式同样适用（pre[l-1] - pre[l-1] = 0）
    print(pre[r - 1] - pre[l - 1])
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        
        // 输入序列
        int n = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }
        
        // 预处理前缀和，pre[i] 表示前 i 个相邻差绝对值的总和（i 从 1 开始）
        long[] pre = new long[n];
        for (int i = 1; i < n; i++) {
            pre[i] = pre[i - 1] + Math.abs(a[i] - a[i - 1]);
        }
        
        // 处理查询
        int q = sc.nextInt();
        for (int i = 0; i < q; i++) {
            int l = sc.nextInt();
            int r = sc.nextInt();
            // 区间 [l, r] 波动和 = pre[r-1] - pre[l-1]
            System.out.println(pre[r - 1] - pre[l - 1]);
        }
        
        sc.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <cmath>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    
    // 预处理前缀和，pre[i] 存储区间 [1, i] 的波动和（0-indexed）
    vector<long long> pre(n, 0);
    for (int i = 1; i < n; i++) {
        pre[i] = pre[i - 1] + abs(a[i] - a[i - 1]);
    }
    
    int q;
    cin >> q;
    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << pre[r - 1] - pre[l - 1] << "\n";
    }
    
    return 0;
}
```
