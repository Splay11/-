# 题目内容
你有一个长度为 $n$ 的非负整数序列 $A = [A_1, A_2, \dots, A_n]$。对于任意区间 $[l, r]$（$1 \le l \le r \le n$），定义其“能量值”为 $A_l \times A_{l+1} \times \dots \times A_r$，即 $\prod_{i=l}^r A_i$。如果某个区间的能量值严格大于 $10^9$，则将其视为 $0$。现在需要进行 $q$ 次查询，每次查询给定一个整数 $L$，请你计算所有长度恰好为 $L$ 的区间的能量值之和。

输入包含多组测试数据。第一行包含一个整数 $T$（$1 \le T \le 10^3$），表示数据组数。保证所有测试数据中 $n$ 的总和不超过 $3 \times 10^5$，$q$ 的总和也不超过 $3 \times 10^5$。序列中的每个元素 $A_i$ 满足 $0 \le A_i \le 10^9$，每次查询的 $L$ 满足 $1 \le L \le n$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据组数。接下来依次描述每组数据：
每组数据的第一行包含两个整数 $n$ 和 $q$，分别表示序列长度和查询次数。
第二行包含 $n$ 个整数 $A_1, A_2, \dots, A_n$，表示序列中的元素。
接下来 $q$ 行，每行包含一个整数 $L$，表示一次查询的长度。

# 输出描述
对于每个查询，输出一行一个整数，表示所有长度为 $L$ 的区间的能量值之和。

## 样例1

**输入**

```
1
5 3
1 1 2 0 3
1
2
3
```

**输出**

```
7
3
2
```

**说明**

序列被 $0$ 分割为两个非零段：$[`1`, `1`, `2`]$ 和 $[`3`]$。包含 $0$ 的区间乘积为 $0$，不参与求和。

段 $[`1`, `1`, `2`]$ 不是全 $1$ 段，采用累乘计算：
- 从第 $1$ 个元素开始：子区间乘积依次为 $`1`$、$`1 \\times 1 = 1`$、$`1 \\times 1 \\times 2 = 2`$；
- 从第 $2$ 个元素开始：$`1`$、$`1 \\times 2 = 2`$；
- 从第 $3$ 个元素开始：$`2`$。
累加各长度贡献：长度 $1$ 共 $`1+1+2=4`$，长度 $2$ 共 $`1+2=3`$，长度 $3$ 共 $`2`$。

段 $[`3`]$ 只有一个元素，为长度 $1$ 贡献 $`3`$。

汇总所有段，得到：长度 $1$ 的区间能量值之和为 $`4+3=7`$；长度 $2$ 为 $`3`$；长度 $3$ 为 $`2`$。

## 样例2

**输入**

```
1
4 2
1 1 1 2
2
4
```

**输出**

```
4
2
```

**说明**

序列 $[`1`, `1`, `1`, `2`]$ 是一个非零段，但包含大于 $1$ 的元素，因此不是全 $1$ 段，采用累乘方式计算。

从第 $1$ 个元素出发：乘积依次为 $`1`$、$`1`$、$`1`$、$`2`$。
从第 $2$ 个元素出发：$`1`$、$`1`$、$`2`$。
从第 $3$ 个元素出发：$`1`$、$`2`$。
从第 $4$ 个元素出发：$`2`$。

统计各长度贡献：
- 长度 $1$：$`1+1+1+2=5`$；
- 长度 $2$：$`1+1+2=4`$；
- 长度 $3$：$`1+2=3`$；
- 长度 $4$：$`2`$。

查询 $L=`2`$ 时输出 $`4`$，$L=`4`$ 时输出 $`2`$。

## 样例3

**输入**

```
1
3 2
1000000000 2 1
1
2
```

**输出**

```
1000000003
2
```

**说明**

序列 $[`1000000000`, `2`, `1`]$ 是非全 $1$ 段，累乘时乘积上限为 $10^9$。

从第 $1$ 个元素出发：乘积 $`1000000000`$ 贡献给长度 $1$；下一个元素乘 $`2`$ 将得到 $`2000000000`$，超过 $10^9$，因此后续区间视为 $0$，不再计算。
从第 $2$ 个元素出发：$`2`$ 贡献长度 $1$；接着乘 $`1`$ 得到 $`2`$（不超过 $10^9$），贡献给长度 $2$。
从第 $3$ 个元素出发：$`1`$ 贡献长度 $1$。

长度 $1$ 的总和为 $`1000000000 + 2 + 1 = 1000000003`$；长度 $2$ 的总和为 $`2`$（来自区间 $[2,1]$ 的乘积 $`2 \\times 1 = 2`$）。
