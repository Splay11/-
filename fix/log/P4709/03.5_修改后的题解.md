## 解题思路

由于操作只能将元素的值减少 $1$，且目标是对所有 $i$ 都达到 $p_i = q_i$，因此最终两个序列相同位置的值必然变为某个 $c_i$，并且有 $c_i \le \min(p_i, q_i)$。为了让总操作次数尽量少，应使最终值尽可能大，因此最优选择是：
$$
c_i = \min(p_i, q_i)
$$
这样，每个位置上多出来的部分都必须被单独减掉：

- 若 $p_i > q_i$，则 $p_i - q_i$ 必须从 $p_i$ 中减去；
- 若 $q_i > p_i$，则 $q_i - p_i$ 必须从 $q_i$ 中减去。

定义两个变量：

- $\text{needP} = \sum_{i=1}^{n} \max(p_i - q_i, 0)$，表示序列 $p$ 中必须单独减少的总量；
- $\text{needQ} = \sum_{i=1}^{n} \max(q_i - p_i, 0)$，表示序列 $q$ 中必须单独减少的总量。

操作 $3$（同时将某个 $p_i$ 和某个 $q_j$ 各减 $1$）可以同时消耗 $\text{needP}$ 和 $\text{needQ}$ 各 $1$ 的需求。因此最少的操作次数就是两边需求的较大值：
$$
\boxed{\text{ans} = \max(\text{needP},\ \text{needQ})}
$$

算法只需遍历一次两个序列，分别累加差值即可得到答案。

## 复杂度分析

- 时间复杂度：每组数据只需遍历一次长度为 $n$ 的序列，单组时间复杂度 $O(n)$，总时间复杂度 $O(\sum n)$。
- 空间复杂度：仅使用常数个额外变量，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
import sys

def solve_one(n, p, q):
    # needP 表示序列 p 中必须单独减少的总量
    needP = 0
    # needQ 表示序列 q 中必须单独减少的总量
    needQ = 0

    for i in range(n):
        if p[i] > q[i]:
            needP += p[i] - q[i]
        else:
            needQ += q[i] - p[i]

    # 操作3可以同时消耗两边的需求，最少次数取较大值
    return max(needP, needQ)

def main():
    data = sys.stdin.read().split()
    it = iter(data)
    T = int(next(it))
    out_lines = []

    for _ in range(T):
        n = int(next(it))
        p = [int(next(it)) for _ in range(n)]
        q = [int(next(it)) for _ in range(n)]
        out_lines.append(str(solve_one(n, p, q)))

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.*;
import java.io.*;

public class Main {
    // 计算一组数据的最少操作次数
    public static long solveOne(int n, int[] p, int[] q) {
        // needP 表示序列 p 中必须单独减少的总量
        long needP = 0;
        // needQ 表示序列 q 中必须单独减少的总量
        long needQ = 0;

        for (int i = 0; i < n; i++) {
            if (p[i] > q[i]) {
                needP += (long) p[i] - q[i];
            } else {
                needQ += (long) q[i] - p[i];
            }
        }

        // 最少操作次数为两边需求的较大值
        return Math.max(needP, needQ);
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int T = Integer.parseInt(br.readLine());
        while (T-- > 0) {
            int n = Integer.parseInt(br.readLine());
            int[] p = new int[n];
            int[] q = new int[n];

            String[] lineP = br.readLine().split(" ");
            for (int i = 0; i < n; i++) {
                p[i] = Integer.parseInt(lineP[i]);
            }

            String[] lineQ = br.readLine().split(" ");
            for (int i = 0; i < n; i++) {
                q[i] = Integer.parseInt(lineQ[i]);
            }

            sb.append(solveOne(n, p, q)).append('\n');
        }

        System.out.print(sb);
    }
}
```
