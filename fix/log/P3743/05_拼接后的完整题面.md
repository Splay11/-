# 题目内容
你正在指挥一场战术清剿。战场是一个 $n \times n$ 的网格，每个格子有三种状态：
- `'.'` 表示空地，可以部署我方单位；
- `'x'` 表示敌方单位；
- `'o'` 表示我方单位。

敌方单位可以通过上下左右四个方向连成一片，称为“敌群”。一个敌群的“逃生口”定义为与它相邻（上下左右）的所有空地。
如果我方在某个空地部署单位后，某个敌群不再有任何逃生口（即所有相邻格子全为我方单位、敌方单位或战场边界），则该敌群会被立即消灭，消灭的敌军数量等于该敌群的单位数。

实际上，如果一个敌群当前恰有 $1$ 个逃生口，那么我方在该逃生口部署单位即可消灭整个敌群。若有多个敌群共享同一个逃生口，部署后它们会同时被消灭，总消灭数会累加。

你的任务是：找出所有满足条件的逃生口，计算在每个位置部署后能消灭的敌军总数。

约束：战场边长 $n$ 满足 $5 \le n \le 1000$。初始战场保证没有已处于无逃生口状态的敌群（即每个敌群至少有一个逃生口），且部署单位只能放在 `'.'` 位置上。

# 输入描述
第一行包含一个整数 $n$，表示战场大小为 $n \times n$。
接下来 $n$ 行，每行一个长度为 $n$ 的字符串，只包含字符 `'.'`、`'x'`、`'o'`，分别表示空地、敌方单位、我方单位。

# 输出描述
第一行输出一个整数 $k$，表示存在 $k$ 个空地可以部署单位并消灭至少一个敌人。
此后 $k$ 行，每行输出三个整数 $r_i, c_i, s_i$，表示在 $(r_i, c_i)$ 部署单位后能消灭的敌方单位总数为 $s_i$。坐标从 $1$ 开始计数，输出按 $(r_i, c_i)$ 升序排列。

## 样例1

**输入**

```
5
ooooo
oxxoo
ox.oo
ooooo
ooooo
```

**输出**

```
1
3 3 3
```

**说明**

敌群由位于 $(2,2)$、$(2,3)$ 和 $(3,2)$（1‑based 坐标）的 `3` 个敌方单位连接而成。

该敌群四周除 $(3,3)$ 为空地（`.`）外，其余相邻格子均被我方单位（`o`）或边界阻挡，因此唯一逃生口为 $(3,3)$。在此部署我方单位可立即消灭敌群，消灭总数为 `3`。

无其他符合条件的位置，故输出 $k=1$ 及对应坐标与数量。

## 样例2

**输入**

```
5
x.xoo
ooooo
ooooo
ooooo
ooooo
```

**输出**

```
1
1 2 2
```

**说明**

两个大小为 `1` 的独立敌群分别位于 $(1,1)$ 和 $(1,3)$。

敌群 $(1,1)$ 的左、上为边界，下方为 `o`，唯一空地（气）是 $(1,2)$；敌群 $(1,3)$ 的右方是 `o`，上、下方同为 `o` 或边界，唯一空地也是 $(1,2)$。因此两个敌群共享同一个逃生口。

在 $(1,2)$ 部署我方单位后，两个敌群同时被消灭，消灭总数 $= 1 + 1 = 2$。故输出该坐标及累加值 `2`。

## 样例3

**输入**

```
5
.....
.x.x.
.....
.....
.....
```

**输出**

```
0
```

**说明**

战场中有两个大小为 `1` 的敌群，分别位于 $(2,2)$ 和 $(2,4)$。它们四周均为空地 `.`。

每个敌群的逃生口数量（相邻空地数）均为 `4`，均大于 `1`，不存在“唯一逃生口”的敌群。因此无法通过部署来消灭任何敌人，输出 $k=0$。

## 样例4

**输入**

```
5
x....
ooo..
..xoo
..o..
.....
```

**输出**

```
2
1 2 1
3 2 1
```

**说明**

战场中存在两个符合条件的敌群：
- 敌群 A 位于 $(1,1)$，相邻空地仅有 $(1,2)$，唯一逃生口为 $(1,2)$，大小 `1`。
- 敌群 B 位于 $(3,3)$，相邻空地仅有 $(3,2)$，唯一逃生口为 $(3,2)$，大小 `1`。

两个逃生口互不相同，分别在 $(1,2)$ 和 $(3,2)$ 部署可各消灭 `1` 个敌人。按坐标升序输出两行。
