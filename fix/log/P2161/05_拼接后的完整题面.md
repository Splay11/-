# 题目内容
气象台站把测点通道名写成若干小写单词，单词之间用 `_` 连接，例如 `max_score`。新的台账规范要求统一改成：去掉所有 `_`，并把每个单词的首字母变成大写，其余字母保持小写，以便和监测平台的字段对齐。现在有 $T$ 组待改名的通道，请按输入顺序依次输出转换结果。

约束：$1 \le T \le 10^3$，$1 \le |s| \le 10^2$。

# 输入描述
第一行一个正整数 $T$，表示数据组数。
接下来 $T$ 行，每行一个字符串 $s$，仅由小写字母和字符 `_` 组成。
保证 $1 \le T \le 10^3$，$1 \le |s| \le 10^2$。

# 输出描述
输出 $T$ 行，每行一个字符串，表示转换后的通道名。

## 样例1

**输入**

```
3
file_path
get_name
x
```

**输出**

```
FilePath
GetName
X
```

**说明**

按下划线分词后把每段首字母大写：

- `file_path` $\rightarrow$ `FilePath`；
- `get_name` $\rightarrow$ `GetName`；
- 单个字母 `x` $\rightarrow$ `X`。

## 样例2

**输入**

```
1
hello
```

**输出**

```
Hello
```

**说明**

没有下划线，只需把首字母改为大写，得到 `Hello`。

## 样例3

**输入**

```
2
a_b_c
start
```

**输出**

```
ABC
Start
```

**说明**

`a_b_c` 三段都是单字母，转换后为 `ABC`；`start` 变为 `Start`。
