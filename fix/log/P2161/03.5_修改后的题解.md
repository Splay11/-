## 解题思路

这是字符串模拟。从左到右扫描通道名：

- 遇到 `_` 直接跳过；
- 若当前字符是首字符，或前一个字符是 `_`，则把它变成大写后加入答案；
- 其余小写字母原样保留。

按组处理 $T$ 次即可。

## 复杂度分析

设所有字符串长度之和为 $L$，时间复杂度 $O(L)$，空间复杂度 $O(|s|)$。

## 代码实现

### Python

```python
T = int(input())
for _ in range(T):
    s = input().strip()
    result = []
    i = 0
    while i < len(s):
        if s[i] == '_':
            i += 1
            continue
        if i == 0 or s[i - 1] == '_':
            result.append(s[i].upper())
        else:
            result.append(s[i])
        i += 1
    print(''.join(result))
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int t = scanner.nextInt();
        scanner.nextLine();
        while (t-- > 0) {
            String s = scanner.nextLine();
            StringBuilder result = new StringBuilder();
            for (int i = 0; i < s.length(); i++) {
                char c = s.charAt(i);
                if (c == '_') continue;
                if (i == 0 || s.charAt(i - 1) == '_') {
                    result.append(Character.toUpperCase(c));
                } else {
                    result.append(c);
                }
            }
            System.out.println(result.toString());
        }
        scanner.close();
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        string s;
        cin >> s;
        for (int i = 0; i < (int)s.length(); i++) {
            if (s[i] == '_') continue;
            if (i == 0 || s[i - 1] == '_') {
                s[i] += 'A' - 'a';
            }
            cout << s[i];
        }
        cout << '\n';
    }
    return 0;
}
```
