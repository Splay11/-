## 解题思路

本题目标是训练一个线性二分类器，其决策函数为 $f(x)=w\cdot x+b$，预测类别为 $\operatorname{sign}(f(x))$。训练数据集 $T=\{(x_i,y_i)\}_{i=1}^N$，其中每个样本 $x_i=(x_i^1,x_i^2)$，标签 $y_i\in\{1,-1\}$。

定义损失函数为所有被误分类样本到超平面 $w\cdot x+b=0$ 的总距离，忽略常数系数后损失函数可写为：

$$
L(w,b)=-\sum_{\text{误分类}} y_i(w\cdot x_i+b)
$$

对参数求梯度：

$$
\frac{\partial L}{\partial w} = -\sum_{\text{误分类}} y_i x_i,\qquad
\frac{\partial L}{\partial b} = -\sum_{\text{误分类}} y_i
$$

采用批量梯度下降（每轮对所有样本检验并累加误分类样本的梯度，然后统一更新参数），更新规则为：

$$
w \leftarrow w + \eta \sum_{\text{误分类}} y_i x_i,\qquad
b \leftarrow b + \eta \sum_{\text{误分类}} y_i
$$

其中 $\eta$ 为给定的学习率。

算法步骤：
1. 初始化权重 $w=(w_1,w_2)=(0,0)$，偏置 $b=0$。
2. 进行 `epoch` 轮迭代，每轮执行：
   - 初始化累加量 `sum_w = (0,0)`，`sum_b = 0`。
   - 遍历所有训练样本 $(x_i,y_i)$，计算 $score = w\cdot x_i + b$。
   - 若 $y_i \cdot score \le 0$，则该样本被误分类，进行累加：  
     `sum_w += y_i * x_i`，`sum_b += y_i`。
   - 本轮遍历结束后，按学习率更新：  
     $w \leftarrow w + \eta \cdot sum\_w$，  
     $b \leftarrow b + \eta \cdot sum\_b$。
3. 所有迭代完成后，输出 $[w_1, w_2, b]$，每个数值保留至多三位小数。

## 复杂度分析

- 时间复杂度：每轮遍历全部 $N$ 个样本，共迭代 $\text{epoch}$ 轮，每轮中对每个样本进行常数次向量内积与加法运算，因此总时间复杂度为 $O(N \times \text{epoch})$。
- 空间复杂度：需要存储所有训练样本的特征和标签，空间复杂度为 $O(N)$。

## 代码实现

三种语言的实现均按照题目描述的输入格式进行解析：第一行为 Python 风格的列表字符串，第二行为 `[epoch, learning_rate]`。输出为 `[w1, w2, b]` 且数值保留三位小数。

### Python

```python
import sys

def parse_line(line):
    # 简单安全地解析输入，避免直接使用 eval
    # 输入格式固定，直接 eval 亦可，这里用 ast.literal_eval 更安全
    import ast
    return ast.literal_eval(line.strip())

def main():
    data = parse_line(sys.stdin.readline())   # 列表，元素为 [(x1,x2),y]
    epoch, lr = parse_line(sys.stdin.readline())  # [epoch, lr]

    # 分离特征和标签
    X = [item[0] for item in data]
    y = [item[1] for item in data]
    n = len(y)

    w1, w2, b = 0.0, 0.0, 0.0

    for _ in range(epoch):
        sum_w1, sum_w2, sum_b = 0.0, 0.0, 0.0
        for i in range(n):
            xi1, xi2 = X[i]
            yi = y[i]
            score = w1 * xi1 + w2 * xi2 + b
            if yi * score <= 0:
                sum_w1 += yi * xi1
                sum_w2 += yi * xi2
                sum_b += yi
        w1 += lr * sum_w1
        w2 += lr * sum_w2
        b += lr * sum_b

    # 输出列表，保留三位小数
    print([round(w1, 3), round(w2, 3), round(b, 3)])

if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String line1 = sc.nextLine().trim();
        String line2 = sc.nextLine().trim();
        sc.close();

        // 解析第一行：提取所有数值（支持正负整数和小数）
        List<Double> values1 = extractNumbers(line1);
        // 每三个数字一组：(x1, x2, y)
        int N = values1.size() / 3;
        double[][] X = new double[N][2];
        int[] y = new int[N];
        for (int i = 0; i < N; i++) {
            X[i][0] = values1.get(i * 3);
            X[i][1] = values1.get(i * 3 + 1);
            y[i] = (int) Math.round(values1.get(i * 3 + 2));
        }

        // 解析第二行：epoch 和 learning_rate
        List<Double> values2 = extractNumbers(line2);
        int epoch = (int) Math.round(values2.get(0));
        double lr = values2.get(1);

        double w1 = 0.0, w2 = 0.0, b = 0.0;

        for (int e = 0; e < epoch; e++) {
            double sum_w1 = 0.0, sum_w2 = 0.0, sum_b = 0.0;
            for (int i = 0; i < N; i++) {
                double score = w1 * X[i][0] + w2 * X[i][1] + b;
                if (y[i] * score <= 0) {
                    sum_w1 += y[i] * X[i][0];
                    sum_w2 += y[i] * X[i][1];
                    sum_b  += y[i];
                }
            }
            w1 += lr * sum_w1;
            w2 += lr * sum_w2;
            b  += lr * sum_b;
        }

        System.out.printf("[%.3f, %.3f, %.3f]%n", w1, w2, b);
    }

    // 提取字符串中的所有数值（整数或浮点数，支持负号）
    private static List<Double> extractNumbers(String s) {
        List<Double> list = new ArrayList<>();
        Pattern p = Pattern.compile("-?\\d+(\\.\\d+)?");
        Matcher m = p.matcher(s);
        while (m.find()) {
            list.add(Double.parseDouble(m.group()));
        }
        return list;
    }
}
```

```cpp
// 提取字符串中的所有数值（整数或浮点数，支持负号）
vector<double> extractNumbers(const string& s) {
    vector<double> res;
    regex re("-?\\d+(\\.\\d+)?");
    auto it_begin = sregex_iterator(s.begin(), s.end(), re);
    auto it_end = sregex_iterator();
    for (auto it = it_begin; it != it_end; ++it) {
        res.push_back(stod(it->str()));
    }
    return res;
}
```
