# 题目内容
在数字研究中，如果一组正整数的乘积恰好是一个平方数（即可以表示为某个整数的平方），那么这组数被称为**完美积**。

现在给定一个包含 $n$ 个正整数的数组，你需要从中选出至少一个元素，使得选出的所有数构成一个完美积。请你计算一共有多少种满足条件的选取方案。

数据范围：数组长度 $n$ 满足 $1 \le n \le 20$，每个数的值满足 $1 \le a_i \le 100$。

# 输入描述
第一行包含一个整数 $n$（$1 \le n \le 20$），表示数组的长度。

第二行包含 $n$ 个正整数，表示数组中的元素，每个数均不超过 $100$。

# 输出描述
输出一个整数，表示不同的选取方案数。

## 样例1

**输入**

```
3
1 2 2
```

**输出**

```
3
```

**说明**

数组为 `1`, `2`, `2`。我们枚举所有非空子集，并判断乘积是否为完全平方数（完美积）：

- 子集 `{1}`：乘积为 `1`，$1 = 1^2$，是完全平方数，符合条件。
- 子集 `{2}`：乘积为 `2`，不是平方数。
- 另一个单元素 `{2}` 同理不符合。
- 子集 `{1, 2}`：乘积为 `2`，不符合。
- 子集 `{2, 2}`：乘积为 `4`，$4 = 2^2$，符合条件。
- 子集 `{1, 2, 2}`：乘积为 `4`，符合条件。

因此共有 `3` 种选取方案。

## 样例2

**输入**

```
4
1 2 3 6
```

**输出**

```
3
```

**说明**

数组为 `1`, `2`, `3`, `6`。对每个数做质因数分解并保留指数模 $2$ 的信息：
- `1` 没有质因子，模 $2$ 向量为全零。
- `2` 的质因子为 $2^1$，模 $2$ 向量记为 $(1,0,\dots)$。
- `3$ 的质因子为 $3^1$，模 $2$ 向量记为 $(0,1,\dots)$。
- `6 = 2 \times 3$，模 $2$ 向量为 $(1,1,\dots)$。

非空子集中异或和为全零的包括：
- `{1}` 异或和为 $\mathbf{0}$。
- `{2, 3, 6}`：$(1,0) \oplus (0,1) \oplus (1,1) = (0,0)$，乘积 $2 \times 3 \times 6 = 36 = 6^2$ 是完全平方数。
- `{1, 2, 3, 6}` 加入 `1` 不改变异或和，仍为 $\mathbf{0}$。

共 `3` 种方案。

## 样例3

**输入**

```
2
4 9
```

**输出**

```
3
```

**说明**

数组为 `4` 和 `9`。两者本身都是完全平方数：$4 = 2^2$，$9 = 3^2$。它们质因数分解后的指数均为偶数，模 $2$ 向量全为零。

因此任意非空子集的异或和均为零：`{4}` 乘积 `4` 是平方数，`{9}` 乘积 `9` 是平方数，`{4, 9}` 乘积 $36 = 6^2$ 也是平方数。一共 `3` 种选取方案。

## 样例4

**输入**

```
5
2 3 5 7 11
```

**输出**

```
0
```

**说明**

数组由 `5` 个互不相同的质数组成：`2`, `3`, `5`, `7`, `11`。每个数在质因数分解中恰好有一个指数为奇数的质因子，对应模 $2$ 向量中只有一位为 `1`，且彼此不重叠。

任何非空子集的异或和相当于将这些不重叠的位进行组合，结果不可能为全零向量，因此没有子集的乘积是完全平方数。答案为 `0`。
