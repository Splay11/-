# 题目内容
一块铭文由长度为 $n$ 的字符串构成，字符只可能是 `'o'`、`'x'`、`'s'`、`'z'`、`'m'`、`'w'`。抄录时把铭文上下颠倒了：在这套字符里，`'w'` 颠倒后看起来像 `'m'`，`'m'` 颠倒后看起来像 `'w'`，其余字符上下颠倒后外形不变。

现在给出抄录得到的字符串，请还原铭文原本的内容。

字符串长度 $n$ 满足 $1 \le n \le 10^5$。

# 输入描述
第一行包含一个整数 $n$，表示字符串长度。
第二行包含一个长度为 $n$ 的字符串，仅由字符 `'o'`、`'x'`、`'s'`、`'z'`、`'m'`、`'w'` 组成，表示抄录结果。

# 输出描述
输出一行长度为 $n$ 的字符串，表示还原后的铭文。

## 样例1

**输入**

```
5
oxszw
```

**输出**

```
oxszm
```

**说明**

只有最后一个字符 `'w'` 需要还原为 `'m'`，其余 `'o'`、`'x'`、`'s'`、`'z'` 颠倒后外形不变。

## 样例2

**输入**

```
3
mmm
```

**输出**

```
www
```

**说明**

三个 `'m'` 颠倒后都应还原为 `'w'`。

## 样例3

**输入**

```
6
oxszmw
```

**输出**

```
oxszwm
```

**说明**

前四个字符不变；倒数第二个 `'m'` 还原为 `'w'`，最后一个 `'w'` 还原为 `'m'`，得到 `oxszwm`。

## 样例4

**输入**

```
1
o
```

**输出**

```
o
```

**说明**

单字符 `'o'` 上下颠倒后仍是 `'o'`，答案为其本身。
