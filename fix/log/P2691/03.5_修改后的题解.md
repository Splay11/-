## 解题思路

1. **颠倒规则**：字符集为 `'o'`、`'x'`、`'s'`、`'z'`、`'m'`、`'w'`。上下颠倒后，只有 `'w'` 与 `'m'` 会互换外形，其余四个字符保持不变。
2. **还原**：抄录结果里的 `'w'` 对应原文 `'m'`，抄录结果里的 `'m'` 对应原文 `'w'`，其它字符原样写回。
3. **实现**：线性扫描字符串，按上述映射替换即可。第一行的 $n$ 用于确认长度。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(n)$（用于构造答案字符串）。

## 代码实现

### Python

```python
def restore_newspaper(s):
    char_map = {'w': 'm', 'm': 'w'}
    result = []
    for char in s:
        if char in char_map:
            result.append(char_map[char])
        else:
            result.append(char)
    return ''.join(result)

n = int(input())
s = input().strip()
print(restore_newspaper(s))
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static String restoreNewspaper(String s) {
        char[] charMap = new char[128];
        charMap['w'] = 'm';
        charMap['m'] = 'w';
        StringBuilder result = new StringBuilder();
        for (char c : s.toCharArray()) {
            if (charMap[c] != 0) {
                result.append(charMap[c]);
            } else {
                result.append(c);
            }
        }
        return result.toString();
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        String s = scanner.next();
        System.out.println(restoreNewspaper(s));
    }
}
```

### C++

```cpp
#include <iostream>
#include <unordered_map>
#include <string>

using namespace std;

string restoreNewspaper(string s) {
    unordered_map<char, char> charMap = {{'w', 'm'}, {'m', 'w'}};
    string result;
    for (char c : s) {
        if (charMap.find(c) != charMap.end()) {
            result += charMap[c];
        } else {
            result += c;
        }
    }
    return result;
}

int main() {
    int n;
    string s;
    cin >> n >> s;
    cout << restoreNewspaper(s) << endl;
    return 0;
}
```
