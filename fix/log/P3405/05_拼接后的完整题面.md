# 题目内容
在一个由 $n$ 个区域组成的试炼场中，你是一位星能收集者，初始星能为 `1`。第 $i$ 个区域中有 $k_i$ 名星能守卫，第 $j$ 名守卫的星能值为 $b_{ij}$。你可以按顺序挑战区域，初始位于第 `1` 个区域。在每个区域中，你可以反复执行以下操作之一，直到无法继续：
- 在当前区域中，选择一名星能值不低于你当前星能的守卫并击败；击败数增加 `1`，且你的星能变为 $b_{ij}+1$；
- 如果当前区域不是最后一个，可以进入下一个区域（编号加 `1`），该操作不可逆。
你的目标是最大化击败的守卫总数。请你计算这个最大值。

区域数量 $n$ 不超过 `10^4`，所有区域的守卫总数不超过 `2×10^5`，每个守卫的星能值 $b_{ij}$ 不超过 `10^9`。

# 输入描述
第一行包含一个整数 $n$，表示区域数。
接下来 $n$ 行，第 $i$ 行首先包含一个整数 $k_i$，表示第 $i$ 个区域的守卫数量；随后 $k_i$ 个整数 $b_{i,1}, b_{i,2}, \dots, b_{i,k_i}$，表示每个守卫的星能值。

# 输出描述
输出一个整数，表示最多可以击败的守卫数量。

## 样例1

**输入**

```
1
3 3 4 5
```

**输出**

```
0
```

**说明**

初始星能为 `1`。区域 `1` 中的三名守卫星能分别为 `3`、`4`、`5`，均大于 `1`，因此无法击败任意一名守卫。同时只有一个区域，无法前进。最大击败数为 `0`。

## 样例2

**输入**

```
1
4 2 1 5 3
```

**输出**

```
3
```

**说明**

初始星能为 `1`。区域 `1` 的守卫按照星能不高于当前星能的顺序依次挑战：先击败星能 `1` 的守卫（星能变为 `2`），再击败星能 `2` 的守卫（星能变为 `3`），最后击败星能 `3` 的守卫（星能变为 `4`）。剩余星能 `5` 的守卫无法击败。共击败 `3` 名守卫。

## 样例3

**输入**

```
2
5 1 2 3 4 1
2 5 6
```

**输出**

```
6
```

**说明**

初始星能 `1`。在区域 `1` 中，依次击败 `1`、`2`、`3`、`4` 后星能达到 `5`。此时区域 `1` 还剩一名星能为 `1` 的守卫。

若贪心将其击败，星能骤降为 `2`，进入区域 `2` 后无法击败守卫 `5` 和 `6`，总击败数为 `5`。

若选择跳过该守卫直接进入区域 `2`，凭借星能 `5` 可以连续击败 `5`（星能 `6`）和 `6`（星能 `7`），总击败数为 $4 + 2 = 6$。因此最优策略是跳过弱守卫以保持高星能，最大击败数为 `6`。

## 样例4

**输入**

```
3
6 1 2 3 4 5 1
2 6 7
2 2 8
```

**输出**

```
9
```

**说明**

初始星能 `1`。区域 `1` 中有守卫 `[1, 2, 3, 4, 5, 1]`。

若在区域 `1` 击败 `1`～`5` 后（星能 `6`），再击败最后的弱守卫 `1`，星能降为 `2`；进入区域 `2` 无法击败 `[6,7]`；进入区域 `3` 只能击败 `2`（星能 `3`），无法击败 `8`。总击败数为 $6 + 0 + 1 = 7$。

若在区域 `1` 击败 `1`～`5` 后跳过弱守卫，以星能 `6` 进入区域 `2`，连续击败 `6`（星能 `7`）、`7`（星能 `8`）；再进入区域 `3`，先击败 `8`（星能 `9`），再击败 `2`（星能 `3`）。总击败数为 $5 + 2 + 2 = 9$。

可见，保留高星能进入后续区域能带来更大收益，最大击败数为 `9`。
