# 题目内容
对于正整数 $x$，定义 $\varphi(x)$ 为 $x$ 的所有正约数的立方之和。例如 $\varphi(12)=1^3+2^3+3^3+4^3+6^3+12^3$。

再定义 $\Phi(n)=\sum_{i=1}^{n} \varphi(i)$。请计算 $\Phi(n)$ 对 $10^9+7$ 取模后的结果。

正约数指能整除给定正整数的正整数。

数据范围：$n$ 满足 $1 \le n \le 10^9$。

# 输入描述
输入仅包含一个整数 $n$（$1 \le n \le 10^9$）。

# 输出描述
输出一个整数，表示 $\Phi(n)$ 对 $10^9+7$ 取模后的结果。

## 样例1

**输入**

```
3
```

**输出**

```
38
```

**说明**

$\varphi(1)=1^3=1$，$\varphi(2)=1^3+2^3=9$，$\varphi(3)=1^3+3^3=28$。因此 $\Phi(3)=1+9+28=38$。

## 样例2

**输入**

```
12
```

**输出**

```
6685
```

**说明**

将每个约数 $d$ 的贡献按出现次数汇总，有 $\Phi(n)=\sum_{d=1}^{n} d^3 \left\lfloor n/d \right\rfloor$。当 $n=12$ 时直接计算该式得到 `6685`。

## 样例3

**输入**

```
1
```

**输出**

```
1
```

**说明**

$n=1$ 时只有 $\varphi(1)=1$，故答案为 `1`。

## 样例4

**输入**

```
100
```

**输出**

```
27643219
```

**说明**

对 $n=100$ 用整除分块计算 $\sum_{d=1}^{100} d^3 \left\lfloor 100/d \right\rfloor$，再对 $10^9+7$ 取模，结果为 `27643219`。
