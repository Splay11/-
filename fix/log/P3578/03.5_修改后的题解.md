## 解题思路

1. **按约数聚合**  
   $$
   \Phi(n)=\sum_{i=1}^{n}\sum_{d\mid i}d^3=\sum_{d=1}^{n}d^3\left\lfloor\frac{n}{d}\right\rfloor.
   $$
   于是只需计算 $\sum_{d=1}^{n} d^3 \lfloor n/d \rfloor$。

2. **整除分块**  
   记 $q=\lfloor n/d \rfloor$。在一段连续区间 $[L,R]$ 上 $q$ 保持不变，且
   $$
   R=\left\lfloor\frac{n}{q}\right\rfloor,
   $$
   于是该段贡献为 $q\cdot\sum_{d=L}^{R}d^3$。令 $L\leftarrow R+1$ 跳到下一段，段数为 $O(\sqrt{n})$。

3. **立方前缀和闭式**  
   $$
   S(m)=\sum_{i=1}^{m}i^3=\left(\frac{m(m+1)}{2}\right)^2,
   $$
   故 $\sum_{d=L}^{R}d^3=S(R)-S(L-1)$。全部在模 $M=10^9+7$ 下运算，$\frac12$ 用逆元 $2^{-1}\equiv 500000004\pmod{M}$。

## 复杂度分析

- **时间复杂度**：$O(\sqrt{n})$。整除分块的区间个数为 $O(\sqrt{n})$，每段 $O(1)$ 计算。
- **空间复杂度**：$O(1)$。

## 代码实现

### Python

```python
import sys
MOD = 10**9 + 7
INV2 = 500000004  # 2 的逆元

def sum_cubes(m: int) -> int:
    # S(m) = (m(m+1)/2)^2  (mod MOD)
    if m <= 0:
        return 0
    m %= MOD
    t = m * ((m + 1) % MOD) % MOD
    t = t * INV2 % MOD
    return t * t % MOD

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    n = int(data[0])
    ans = 0
    L = 1
    while L <= n:
        q = n // L
        R = n // q
        part = (sum_cubes(R) - sum_cubes(L - 1)) % MOD
        ans = (ans + part * (q % MOD)) % MOD
        L = R + 1
    print(ans % MOD)

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.io.*;

public class Main {
    static final long MOD = 1_000_000_007L;
    static final long INV2 = 500_000_004L;

    static long sumCubes(long m) {
        if (m <= 0) return 0;
        m %= MOD;
        long t = m * ((m + 1) % MOD) % MOD;
        t = t * INV2 % MOD;
        return t * t % MOD;
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        long n = Long.parseLong(br.readLine().trim());

        long ans = 0, L = 1;
        while (L <= n) {
            long q = n / L;
            long R = n / q;
            long seg = (sumCubes(R) - sumCubes(L - 1)) % MOD;
            if (seg < 0) seg += MOD;
            ans = (ans + seg * (q % MOD)) % MOD;
            L = R + 1;
        }
        System.out.println(ans % MOD);
    }
}
```
