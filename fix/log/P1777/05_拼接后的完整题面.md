# 题目内容
某系统记录了 $n$ 个事件，按时间顺序编号为 $1$ 到 $n$。每个事件有一个严重性级别 $a_i$，级别满足 $a_1 \le a_2 \le \cdots \le a_n$。系统将每个用户的连续操作视为一个会话，共有 $m$ 个会话。第 $j$ 个会话包含 $b_j$ 条事件访问记录，按先后顺序给出事件编号 $c_{j,1}, c_{j,2}, \ldots, c_{j,b_j}$，同一会话内不会重复访问同一事件。

系统根据以下规则判定会话是否异常：
1. 若会话访问了最高严重性级别为 $x$ 的事件，但存在严重性级别不超过 $x-500$ 的事件未被访问，则判定该会话异常。
2. 若会话中存在相邻访问的两个事件编号之差的绝对值不小于 $r$，即存在 $k$ 使得 $|c_{j,k+1} - c_{j,k}| \ge r$，则判定该会话异常。

只要满足任一规则，会话即被标记为异常。请你计算所有 $m$ 个会话中异常会话的数量。

**约束条件**
- 事件数量 $n$ 满足 $1 \le n \le 10^5$。
- 阈值 $r$ 满足 $1 \le r \le n$。
- 严重性级别 $a_i$ 为整数且 $1 \le a_i \le 4 \times 10^9$，数组单调不减。
- 会话总数 $m$ 满足 $1 \le m \le 10^5$。
- 每个会话的记录数 $b_j$ 满足 $1 \le b_j \le n$，且所有会话的总记录数 $\sum_{j=1}^{m} b_j \le 2 \times 10^5$。
- 事件编号均为 $1$ 到 $n$ 范围内的整数，同一会话内编号不重复。

# 输入描述
第一行包含两个整数 $n$ 和 $r$，分别表示事件数量与相邻事件编号差的阈值。
第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$，表示每个事件的严重性级别，顺序由时间从早到晚给出，保证单调不减。
第三行包含一个整数 $m$，表示会话总数。
接下来共有 $m$ 组数据，每组对应一个会话，格式如下：
- 第一行包含一个整数 $b_j$，表示该会话的访问记录数量。
- 第二行包含 $b_j$ 个整数 $c_{j,1}, c_{j,2}, \ldots, c_{j,b_j}$，按访问顺序给出事件编号。

# 输出描述
输出一个整数，表示被判定为异常的会话数量。

## 样例1

**输入**

```
5 100
1 300 800 1200 2000
1
3
1 2 4
```

**输出**

```
0
```

**说明**

会话访问的事件编号为 `1, 2, 4`，其中最大编号为 `4`，对应严重性级别 $a_4 = 1200$。按照规则一，需要检查所有严重性级别不超过 $1200 - 500 = 700$ 的事件是否都被访问。

严重性级别不超过 `700` 的事件是编号 `1` ($a_1=1$) 和 `2` ($a_2=300$)，共 `2` 个。该会话恰好访问了这两个事件，因此规则一不判定异常。

相邻事件编号差的绝对值为 $|2-1|=1$ 和 $|4-2|=2$，均小于阈值 $r=100$，规则二也不判定异常。因此该会话正常，异常会话数量为 `0`。

## 样例2

**输入**

```
5 2
10 20 30 40 50
1
3
1 5 2
```

**输出**

```
1
```

**说明**

会话访问序列为 `1, 5, 2`。检查相邻差：第一个相邻差 $|5-1| = 4$，而阈值 $r=2$，由于 $4 \ge 2$，满足规则二的异常条件。因此该会话直接被判定为异常，无需检查规则一。异常会话数量为 `1`。

## 样例3

**输入**

```
5 100
100 200 800 900 1000
1
2
5 3
```

**输出**

```
1
```

**说明**

会话访问序列为 `5, 3`。最大编号为 `5`，对应严重性级别 $a_5 = 1000$。规则一要求检查所有严重性级别不超过 $1000 - 500 = 500$ 的事件。

数组中满足 $a_i \le 500$ 的事件为编号 `1` ($a_1=100$) 和 `2` ($a_2=200$)，共 `2` 个。该会话未访问这两个事件中的任何一个（`5` 和 `3` 均大于 `2`），因此规则一判定异常。

相邻差 $|3-5|=2 < r=100$，规则二不触发。但任意规则满足即异常，故会话异常，异常会话数量为 `1`。
