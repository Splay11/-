# 题目内容
给定长度为 $n$ 的字符串 $s$，仅含字符 `'e'`、`'l'`、`'m'`。你可以把 $s$ 中若干互不相交的连续子串分别匹配为下列模式并计分（未匹配的字符不计分）：

- 子串恰好为 `ele`，得 $x$ 分；
- 子串恰好为 `me`，得 $y$ 分；
- 子串恰好为 `eleme`，得 $z$ 分。

每个字符至多被使用一次。求能获得的最高分数。

字符串长度 $n$ 满足 $1 \le n \le 10^5$。分数 $x,y,z$ 满足 $1 \le x,y,z \le 1000$。

# 输入描述
第一行包含一个整数 $n$，表示字符串长度。
第二行包含一个长度为 $n$ 的字符串 $s$，仅由字符 `'e'`、`'l'`、`'m'` 组成。
第三行包含三个整数 $x$、$y$、$z$，分别表示匹配 `ele`、`me`、`eleme` 所能获得的分数。

# 输出描述
输出一个整数，表示能获得的最高分数。

## 样例1

**输入**

```
5
eleme
1 2 3
```

**输出**

```
3
```

**说明**

字符串为 `eleme`。可以匹配整段 `eleme` 得 $z=3$ 分；也可以先匹配 `ele` 再匹配 `me`，得 $x+y=1+2=3$ 分。最高分为 `3`。

## 样例2

**输入**

```
2
me
1 10 1
```

**输出**

```
10
```

**说明**

整个字符串恰好为 `me`，匹配该模式得 $y=10$ 分。

## 样例3

**输入**

```
1
e
1 1 1
```

**输出**

```
0
```

**说明**

单个字符 `'e'` 无法匹配 `ele`、`me` 或 `eleme`，得分为 `0`。

## 样例4

**输入**

```
6
eleele
4 1 10
```

**输出**

```
8
```

**说明**

字符串 `eleele` 可拆成两段 `ele`，各得 $x=4$ 分，总分 `8`。其中不含 `me` 或 `eleme`。
