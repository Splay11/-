### 题目描述

给定一个由字符 `e`、`l`、`m` 组成的字符串，每个字符初始为白色。可以选择以下三种未被染色的子串进行染色以获得分数：

- **红色**：连续子串 `ele`，得分为 $x$。
- **蓝色**：连续子串 `me`，得分为 $y$。
- **绿色**：连续子串 `eleme`，得分为 $z$。

求能获得的最大分数。

### 解题思路

使用动态规划来解决问题。定义 `dp[i]` 表示前 `i` 个字符能获得的最大分数。状态转移时，考虑以第 `i` 个字符结尾的子串是否满足三种染色条件，并取最大值。

1. **不选择任何子串**：`dp[i] = dp[i-1]`。
2. **选择 `me`（蓝色）**：若 `i >= 2` 且子串为 `me`，则 `dp[i] = max(dp[i], dp[i-2] + y)`。
3. **选择 `ele`（红色）**：若 `i >= 3` 且子串为 `ele`，则 `dp[i] = max(dp[i], dp[i-3] + x)`。
4. **选择 `eleme`（绿色）**：若 `i >= 5` 且子串为 `eleme`，则 `dp[i] = max(dp[i], dp[i-5] + z)`。

最终答案即为 `dp[n]`，其中 `n` 为字符串长度。

#### C++ 

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

int main() {
    int n;
    string s;
    int x, y, z;
    cin >> n >> s >> x >> y >> z;
    vector<long long> dp(n + 1, 0); // dp[i]表示前i个字符的最大得分
    
    for (int i = 1; i <= n; ++i) {
        dp[i] = dp[i - 1]; // 不选当前字符结尾的子串
        
        // 检查me（蓝色）
        if (i >= 2 && s[i-2] == 'm' && s[i-1] == 'e') {
            dp[i] = max(dp[i], dp[i-2] + y);
        }
        
        // 检查ele（红色）
        if (i >= 3 && s[i-3] == 'e' && s[i-2] == 'l' && s[i-1] == 'e') {
            dp[i] = max(dp[i], dp[i-3] + x);
        }
        
        // 检查eleme（绿色）
        if (i >= 5 && s[i-5] == 'e' && s[i-4] == 'l' && s[i-3] == 'e' && s[i-2] == 'm' && s[i-1] == 'e') {
            dp[i] = max(dp[i], dp[i-5] + z);
        }
    }
    
    cout << dp[n] << endl;
    return 0;
}
```

#### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        String s = scanner.next();
        int x = scanner.nextInt();
        int y = scanner.nextInt();
        int z = scanner.nextInt();
        long[] dp = new long[n + 1]; // dp[i]表示前i个字符的最大得分
        
        for (int i = 1; i <= n; ++i) {
            dp[i] = dp[i - 1]; // 不选当前字符结尾的子串
            
            // 检查me（蓝色）
            if (i >= 2 && s.charAt(i-2) == 'm' && s.charAt(i-1) == 'e') {
                dp[i] = Math.max(dp[i], dp[i-2] + y);
            }
            
            // 检查ele（红色）
            if (i >= 3 && s.charAt(i-3) == 'e' && s.charAt(i-2) == 'l' && s.charAt(i-1) == 'e') {
                dp[i] = Math.max(dp[i], dp[i-3] + x);
            }
            
            // 检查eleme（绿色）
            if (i >= 5 && s.charAt(i-5) == 'e' && s.charAt(i-4) == 'l' && s.charAt(i-3) == 'e' 
                && s.charAt(i-2) == 'm' && s.charAt(i-1) == 'e') {
                dp[i] = Math.max(dp[i], dp[i-5] + z);
            }
        }
        
        System.out.println(dp[n]);
    }
}
```
