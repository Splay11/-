## 解题思路

1. **状态定义**：令 $dp[i]$ 表示处理完前 $i$ 个字符能得到的最高分数。未匹配的字符可以直接跳过。
2. **转移**：
   - 不匹配第 $i$ 个字符：$dp[i]=\max(dp[i], dp[i-1])$。
   - 若 $s[i-2..i-1]=\texttt{me}$，则可匹配该模式：$dp[i]=\max(dp[i], dp[i-2]+y)$。
   - 若 $s[i-3..i-1]=\texttt{ele}$，则：$dp[i]=\max(dp[i], dp[i-3]+x)$。
   - 若 $s[i-5..i-1]=\texttt{eleme}$，则：$dp[i]=\max(dp[i], dp[i-5]+z)$。
3. **答案**：$dp[n]$。三种模式互不相交地覆盖，动态规划自动取最优组合。

## 复杂度分析

- **时间复杂度**：$O(n)$。每个位置做常数次转移。
- **空间复杂度**：$O(n)$。保存 $dp$ 数组。

## 代码实现

### Python

```python
n = int(input())
s = input().strip()
x, y, z = map(int, input().split())
dp = [0] * (n + 1)

for i in range(1, n + 1):
    dp[i] = dp[i - 1]
    if i >= 2 and s[i - 2] == 'm' and s[i - 1] == 'e':
        dp[i] = max(dp[i], dp[i - 2] + y)
    if i >= 3 and s[i - 3] == 'e' and s[i - 2] == 'l' and s[i - 1] == 'e':
        dp[i] = max(dp[i], dp[i - 3] + x)
    if i >= 5 and (s[i - 5] == 'e' and s[i - 4] == 'l' and s[i - 3] == 'e'
                   and s[i - 2] == 'm' and s[i - 1] == 'e'):
        dp[i] = max(dp[i], dp[i - 5] + z)

print(dp[n])
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        String s = scanner.next();
        int x = scanner.nextInt();
        int y = scanner.nextInt();
        int z = scanner.nextInt();
        long[] dp = new long[n + 1];
        for (int i = 1; i <= n; ++i) {
            dp[i] = dp[i - 1];
            if (i >= 2 && s.charAt(i - 2) == 'm' && s.charAt(i - 1) == 'e') {
                dp[i] = Math.max(dp[i], dp[i - 2] + y);
            }
            if (i >= 3 && s.charAt(i - 3) == 'e' && s.charAt(i - 2) == 'l' && s.charAt(i - 1) == 'e') {
                dp[i] = Math.max(dp[i], dp[i - 3] + x);
            }
            if (i >= 5 && s.charAt(i - 5) == 'e' && s.charAt(i - 4) == 'l' && s.charAt(i - 3) == 'e'
                    && s.charAt(i - 2) == 'm' && s.charAt(i - 1) == 'e') {
                dp[i] = Math.max(dp[i], dp[i - 5] + z);
            }
        }
        System.out.println(dp[n]);
    }
}
```

        if (i >= 2 && s[i - 2] == 'm' && s[i - 1] == 'e') {
            dp[i] = max(dp[i], dp[i - 2] + y);
        }
        if (i >= 3 && s[i - 3] == 'e' && s[i - 2] == 'l' && s[i - 1] == 'e') {
            dp[i] = max(dp[i], dp[i - 3] + x);
        }
        if (i >= 5 && s[i - 5] == 'e' && s[i - 4] == 'l' && s[i - 3] == 'e'
            && s[i - 2] == 'm' && s[i - 1] == 'e') {
            dp[i] = max(dp[i], dp[i - 5] + z);
        }
    }
    cout << dp[n] << endl;
    return 0;
}
