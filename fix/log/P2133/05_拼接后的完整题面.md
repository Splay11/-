# 题目内容
在星际工坊中，所有能量核心的初始星级均为 $1$ 星。提升核心的星级需要消耗星尘碎片：从 $i$ 星提升到 $i+1$ 星，需要恰好 $r^{i}$ 个碎片（$i \ge 1$）。
因此，要获得一个 $k$ 星核心，需要预先准备 $\sum_{j=1}^{k-1} r^{j}$ 个碎片（$k=1$ 时无需碎片）。
现在，你需要一次性备齐全部碎片，使得最终拥有 $a_i$ 个 $i$ 星核心（$1 \le i \le n$）。请你计算总共需要预先收集多少个星尘碎片。
由于答案可能很大，请将其对 $998\ 244\ 353$ 取模后输出。

约束：目标最高星级 $n$ 不超过 $10^5$，升级基数 $r$ 不超过 $10^8$，每个需求量 $a_i$ 不超过 $10^9$。

# 输入描述
第一行包含两个整数 $n$ 和 $r$（$1 \le n \le 10^5$，$1 \le r \le 10^8$），分别表示目标最高星级与升级消耗的基数。
第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$0 \le a_i \le 10^9$），其中 $a_i$ 表示需要拥有的 $i$ 星级核心的数量。

# 输出描述
输出一行一个整数，表示所需星尘碎片总数对 $998\ 244\ 353$ 取模后的结果。

## 样例1

**输入**

```
1 100
10
```

**输出**

```
0
```

**说明**

需要 `10` 个 `1` 星核心。根据规则，获得 `1` 星核心无需消耗任何星尘碎片（即 $\sum_{j=1}^{0} r^j = 0$）。因此，总共需要预先收集的碎片数为 `0`。

## 样例2

**输入**

```
3 2
1 2 1
```

**输出**

```
10
```

**说明**

需要 `1` 个 `1` 星核心、`2` 个 `2` 星核心和 `1` 个 `3` 星核心。
- 每个 `1` 星核心需要 $0$ 碎片。
- 每个 `2` 星核心需要 $r^1 = 2^1 = 2$ 碎片，共 $2 \times 2 = 4$ 碎片。
- 每个 `3` 星核心需要 $r^1 + r^2 = 2 + 4 = 6$ 碎片，共 $1 \times 6 = 6$ 碎片。
总碎片数为 $0 + 4 + 6 = 10$。

## 样例3

**输入**

```
3 1
2 3 1
```

**输出**

```
5
```

**说明**

升级基数为 $r=1$，此时所有 $r^i$ 均为 $1$。需要 `2` 个 `1` 星核心、`3` 个 `2` 星核心和 `1` 个 `3` 星核心。
- `1` 星核心无需碎片。
- 每个 `2` 星核心需要 $1^1 = 1$ 碎片，共 $3 \times 1 = 3$ 碎片。
- 每个 `3` 星核心需要 $1^1 + 1^2 = 2$ 碎片，共 $1 \times 2 = 2$ 碎片。
总碎片数为 $0 + 3 + 2 = 5$。对 $998244353$ 取模后结果仍为 `5`。
