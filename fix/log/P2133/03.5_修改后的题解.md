## 解题思路

1. 问题等价于：对于每个星级 $i$（$1 \le i \le n$），需要我们准备 $a_i$ 个 $i$ 星核心。  
   从 $1$ 星升级到 $i$ 星需要经历 $i-1$ 次升阶，第 $j$ 次（从 $j$ 升 $j+1$）消耗 $r^j$ 个碎片。  
   因此，**获得一个 $i$ 星核心** 需要消耗的碎片总数为  
   $$
   S_i = \sum_{j=1}^{i-1} r^{\,j} \qquad (i=1 \text{ 时 } S_1 = 0)
   $$
   最终需要的总碎片数为  
   $$
   \text{ans} = \sum_{i=1}^n a_i \cdot S_i
   $$

2. 对于一般的 $r \neq 1$，$S_i$ 是等比数列求和，首项 $r$，公比 $r$，项数 $i-1$。由等比数列求和公式：
   $$
   S_i = \frac{r \cdot (r^{\,i-1} - 1)}{r - 1}
   $$
   答案需要对 $998244353$ 取模，因此除法转化为乘逆元。记 $\text{MOD} = 998244353$，则 $(r-1)^{-1}$ 在模 $\text{MOD}$ 下的逆元可通过费马小定理求得：
   $$
   (r-1)^{-1} \equiv (r-1)^{\text{MOD}-2} \pmod{\text{MOD}}
   $$
   使用快速幂计算即可。最终单项贡献为：
   $$
   a_i \cdot \left( r \cdot (r^{\,i-1} - 1) \cdot (r-1)^{-1} \right) \bmod \text{MOD}
   $$
   累加时注意随时取模。

3. **特殊情况 $r = 1$**：  
   此时 $r-1 = 0$，不能求逆元。实际上升阶每次固定消耗 $1$ 个碎片，$i$ 星核心需要 $i-1$ 个碎片。因此直接计算：
   $$
   S_i = i-1
   $$
   贡献为 $a_i \times (i-1) \bmod \text{MOD}$，同样累加即可。

4. 实现时，可以用快速幂计算幂次，并复用逆元函数。对于每个 $i$ 计算 $S_i$ 并乘 $a_i$，累加到答案中，全程取模。

## 复杂度分析

- **时间复杂度**：对于每个星级 $i$，若 $r \neq 1$ 需要计算一次快速幂 $r^{i-1}$，一次快速幂的时间复杂度为 $O(\log \text{MOD})$，共 $n$ 次，因此整体 $O(n \log \text{MOD})$。当 $r=1$ 时退化为 $O(n)$。  
- **空间复杂度**：需要存储数组 $a$，空间 $O(n)$。若采用在线处理可以做到 $O(1)$，但本题 $n \le 10^5$，使用数组完全可行。

## 代码实现

### Python

```python
MOD = 998244353

def ksm(a, b):
    """快速幂，返回 a^b % MOD"""
    res = 1
    while b:
        if b & 1:
            res = (res * a) % MOD
        a = (a * a) % MOD
        b >>= 1
    return res

def inv(x):
    """求 x 在模 MOD 意义下的逆元，要求 MOD 为质数且 x 不被 MOD 整除"""
    return ksm(x, MOD - 2)

def geometric_sum(n, a1, d):
    """
    计算等比数列前 n 项和：a1 * (d^n - 1) / (d - 1) % MOD
    当 n=0 时返回 0。
    """
    if n == 0:
        return 0
    numerator = a1 % MOD
    numerator = numerator * ((ksm(d, n) - 1 + MOD) % MOD) % MOD
    denominator = (d - 1) % MOD
    return numerator * inv(denominator) % MOD

# 输入
n, r = map(int, input().split())
a = list(map(int, input().split()))

ans = 0
if r == 1:
    # 特判 r=1，每次升阶固定消耗 1 碎片
    for i in range(1, n + 1):
        # i 星核心需要 i-1 个碎片
        need = (i - 1) % MOD
        ans = (ans + a[i - 1] * need) % MOD
else:
    for i in range(1, n + 1):
        # 计算得到 i 星核心所需的碎片数
        si = geometric_sum(i - 1, r, r)  # 首项 r，公比 r，项数 i-1
        ans = (ans + a[i - 1] * si) % MOD

print(ans)
```

### Java

```java
import java.util.Scanner;

public class Main {
    static final long MOD = 998244353;

    // 快速幂 a^b % MOD
    static long ksm(long a, long b) {
        long res = 1;
        while (b > 0) {
            if ((b & 1) == 1) {
                res = (res * a) % MOD;
            }
            a = (a * a) % MOD;
            b >>= 1;
        }
        return res;
    }

    // 逆元
    static long inv(long x) {
        return ksm(x, MOD - 2);
    }

    // 等比数列求和，首项 a1，公比 d，项数 n
    static long geometricSum(long n, long a1, long d) {
        if (n == 0) return 0;
        long num = (a1 % MOD) * ((ksm(d, n) - 1 + MOD) % MOD) % MOD;
        long den = (d - 1 + MOD) % MOD;
        return num * inv(den) % MOD;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long r = sc.nextLong();

        long[] a = new long[n];
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextLong();
        }

        long ans = 0;
        if (r == 1) {
            for (int i = 1; i <= n; i++) {
                long need = (i - 1) % MOD;
                ans = (ans + a[i - 1] * need) % MOD;
            }
        } else {
            for (int i = 1; i <= n; i++) {
                long si = geometricSum(i - 1, r, r);
                ans = (ans + a[i - 1] * si) % MOD;
            }
        }

        System.out.println(ans);
        sc.close();
    }
}
```
