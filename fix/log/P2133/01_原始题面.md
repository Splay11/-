# 题目内容

在游戏中，装备的初始等级为一级，此后，每升一级需要融合一定数量的材料:一级升二级需要$t$个材料，二级升三级需要$t^2$个材料，$......$，$i$级升$i+1$级需要$t^i$个材料。
小红想要升级一些装备到目标的等级，他喜欢一次性收集完全部材料,请你帮助他计算出一共需要预先收集多少材料。

# 输入描述

第一行输入两个整数$n,t$($1≤n≤10^5;1≤t≤10^8$)代表装备数量、材料底数。
第二行输入$n$个整数$a_1,a_2,...,a_n$($0≤a_i≤10^9$)代表需要$a_i$个等级为$i$的装备。

# 输出描述

在一行上输出一个数字代表需要的材料数量。由于答案可能很大，请将答案对$998\ 244\ 353$取模后输出。

## 样例1 

**输入** 

```
5 2
0 0 1 2 3
```

**输出** 

```
124
```

**说明**

一个三级装备需要$21+22=6$个材料;两个四级装备需要$2*$（$2+2^2+2^3$）个材料
