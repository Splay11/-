## 解题思路

本题的目标是重排序列 $A$，使得 $\sum_{i=1}^{n} |a'_i - b_i|$ 最小。

1. **贪心配对策略**  
   可以证明，将两个序列分别按数值从小到大排序后，让相同排名的元素两两配对，得到的绝对差之和最小。  
   因此，我们对 $A$ 和 $B$ 分别排序，排序后的 $A$ 的第 $k$ 小元素就应该对应排序后的 $B$ 的第 $k$ 小元素。

2. **处理 $B$ 不能移动的限制**  
   题目要求输出一个重排后的 $A'$，而 $B$ 的原始顺序不能改变。  
   我们可以在排序 $B$ 之前，记录每个元素在原始序列中的下标。具体做法是创建一个辅助数组，其中每个元素包含两个信息：$b_i$ 的值和它的原始下标 $i$。  
   然后，按照**数值大小**对辅助数组排序（相当于对 $B$ 排序，同时保留原始位置信息）。

3. **构造 $A'$**  
   将 $A$ 排序后，按顺序将 $A$ 中的元素依次填入辅助数组中排序后的对应位置（覆盖原来的 $b_i$ 值）。  
   此时辅助数组记录的是：排序后的第 $k$ 个位置上，存放着对应的 $a$ 值，以及 $B$ 该位置元素的原始下标。  
   最后，再按照**原始下标**对辅助数组重新排序，恢复 $B$ 的原始顺序。此时辅助数组中每个位置上的值，就是最终重排后 $A'$ 对应位置的元素。  
   输出这些值即可。

4. **正确性说明**  
   整个过程的本质是：先将 $A$ 和 $B$ 分别排序，建立“第 $k$ 大对第 $k$ 大”的映射关系；然后利用辅助数组保留的原始下标，将 $A$ 的元素放回 $B$ 原始顺序所对应的位置上，从而得到满足条件的 $A'$。

## 复杂度分析

- **时间复杂度**：整段代码中最耗时的部分是两次排序（对 $A$ 排序、对辅助数组按数值排序、按原始下标排序），每次排序的时间复杂度为 $O(n \log n)$，其余操作为线性。因此总时间复杂度为 $O(n \log n)$，其中 $n$ 是序列长度。
- **空间复杂度**：需要额外的辅助数组存储 $B$ 的数值和原始下标，以及排序后的 $A$，空间复杂度为 $O(n)$。

## 代码实现

### Python

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    a = [int(next(it)) for _ in range(n)]
    b = [int(next(it)) for _ in range(n)]
    
    # 辅助数组，记录 B 的数值和原始下标
    aux = [[b[i], i] for i in range(n)]
    
    # 按数值排序
    aux.sort(key=lambda x: x[0])
    a.sort()
    
    # 将排序后的 A 填入对应位置
    for i in range(n):
        aux[i][0] = a[i]
    
    # 按原始下标排序，恢复 B 的原始顺序
    aux.sort(key=lambda x: x[1])
    
    # 输出结果
    res = [str(x[0]) for x in aux]
    sys.stdout.write(' '.join(res))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());
        int[] a = new int[n];
        String[] aStr = br.readLine().trim().split(" ");
        for (int i = 0; i < n; i++) {
            a[i] = Integer.parseInt(aStr[i]);
        }
        int[] b = new int[n];
        String[] bStr = br.readLine().trim().split(" ");
        for (int i = 0; i < n; i++) {
            b[i] = Integer.parseInt(bStr[i]);
        }

        // 辅助数组，记录 B 的数值和原始下标
        int[][] aux = new int[n][2];
        for (int i = 0; i < n; i++) {
            aux[i][0] = b[i];
            aux[i][1] = i;
        }

        // 按数值排序
        Arrays.sort(aux, Comparator.comparingInt(o -> o[0]));
        Arrays.sort(a);

        // 将排序后的 A 填入对应位置
        for (int i = 0; i < n; i++) {
            aux[i][0] = a[i];
        }

        // 按原始下标排序，恢复 B 的原始顺序
        Arrays.sort(aux, Comparator.comparingInt(o -> o[1]));

        // 输出结果
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            sb.append(aux[i][0]);
            if (i < n - 1) sb.append(" ");
        }
        System.out.println(sb.toString());
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> a(n), b(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    for (int i = 0; i < n; ++i) cin >> b[i];

    // 辅助数组，记录 B 的数值和原始下标
    vector<pair<int, int>> aux(n);
    for (int i = 0; i < n; ++i) {
        aux[i] = {b[i], i};
    }

    // 按数值排序
    sort(aux.begin(), aux.end(), 
         [](const pair<int, int>& x, const pair<int, int>& y) {
             return x.first < y.first;
         });

    sort(a.begin(), a.end());

    // 将排序后的 A 填入对应位置
    for (int i = 0; i < n; ++i) {
        aux[i].first = a[i];
    }

    // 按原始下标排序，恢复 B 的原始顺序
    sort(aux.begin(), aux.end(), 
         [](const pair<int, int>& x, const pair<int, int>& y) {
             return x.second < y.second;
         });

    // 输出结果
    for (int i = 0; i < n; ++i) {
        cout << aux[i].first;
        if (i < n - 1) cout << " ";
    }
    cout << endl;

    return 0;
}
```
