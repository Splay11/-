# 题目内容
小智获得了一个正整数 $N$，他需要从严格小于 $N$ 的正整数中挑选一个数 $M$，使得表达式 $(N + M) \times G(N, M)$ 的结果尽可能大。

这里 $G(a, b)$ 表示 $a$ 与 $b$ 的最大公因子，即能同时整除 $a$ 和 $b$ 的最大正整数。

请帮助小智计算这个最大值。

数据范围：测试组数不超过 $10^3$，给定的整数 $N$ 满足 $2 \le N \le 10^9$。

# 输入描述
第一行包含一个整数 $T$（$1 \le T \le 10^3$），表示测试数据的组数。
接下来 $T$ 行，每行包含一个整数 $N$（$2 \le N \le 10^9$），表示每次询问的基准数。

# 输出描述
对于每组测试数据，输出一行一个整数，表示 $(N + M) \times G(N, M)$ 的最大可能值。

## 样例1

**输入**

```
4
2
12
25
17
```

**输出**

```
3
108
225
33
```

**说明**

对于 $N=2$，严格小于 `2` 的正整数只有 `1`，因此只能选择 $M=1$。此时 $\gcd(2, 1)=1$，表达式值为 $(2+1) \times 1 = 3$，这也是唯一可能的值。

对于 $N=12$，其真因子包括 $1, 2, 3, 4, 6$。设 $d$ 为 $N$ 与 $M$ 的最大公因子，即 $d|N$ 且 $d \le N/2$。令 $a=N/d$，为了最大化 $(N+M) \times d = d^2 (a+b)$，其中 $b=M/d$ 且 $b<a$、$\gcd(a,b)=1$，应取 $b=a-1$。此时表达式为 $2Nd - d^2$，它随 $d$ 增大而增大，故取最大的真因子 $d=6$（$a=2$）。对应的 $M=6 \times (2-1) = 6$，表达式值为 $(12+6) \times 6 = 108$。

对于 $N=25$，真因子为 $1, 5$，最大真因子 $d=5$（$a=5$）。取 $b=4$，则 $M=5 \times 4 = 20$，$\gcd(25,20)=5$，表达式值为 $(25+20) \times 5 = 225$。

对于 $N=17$，它是素数，最大真因子仅为 $d=1$。此时 $a=17$，取 $b=16$，$M=16$，$\gcd(17,16)=1$，表达式值为 $(17+16) \times 1 = 33$。
