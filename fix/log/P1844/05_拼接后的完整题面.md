# 题目内容
工作室里有 $n$ 台调音器，第 $i$ 台当前刻度为 $a_i$。对某一台调音器，可以任选下面两种调整方式之一，并连续使用多次：

- 把刻度乘以 `2`；
- 把刻度变为 $\left\lfloor x/2 \right\rfloor$。

同一台调音器不能既做乘法又做除法。

希望用最少的调整次数，使这 $n$ 个刻度从左到右单调不降。

调音器台数 $n$ 不超过 `20000`，每个初始刻度为不超过 `20000` 的正整数。

# 输入描述
第一行一个整数 $n$（$1 \le n \le 20000$），表示调音器台数。
第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 20000$），表示各台的初始刻度。

# 输出描述
输出一个整数，表示使刻度序列单调不降所需的最少调整次数。

## 样例1

**输入**

```
1
1
```

**输出**

```
0
```

**说明**

只有一台调音器，序列已经单调，无需调整，输出 `0`。

## 样例2

**输入**

```
3
1 2 4
```

**输出**

```
0
```

**说明**

初始刻度已经单调不降，每台都可以选择不操作，输出 `0`。

## 样例3

**输入**

```
1
2
```

**输出**

```
0
```

**说明**

按题意模拟计算得到。
