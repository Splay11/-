# 题目内容
在一个能量核心系统中，工程师需要依次处理 $n$ 个能量核心，每个核心有一个类型编号。系统会为每种类型维护一个“能量值”，初始时所有类型的能量值均为 $0$。处理过程按以下规则进行：

- 处理每个核心之前，系统先执行一次衰减：所有当前能量值大于 $0$ 的类型，其能量值减少 $1$。若某个类型的能量值在衰减后变为 $0$，则该类型变为未激活状态。
- 随后，处理当前核心。设其类型编号为 $c$，并且这是该类型从开始到当前第 $k$ 次出现（$k$ 从 $1$ 开始计数）。
  - 若衰减后该类型的能量值为 $0$，则将其能量值设为 $k^2$。
  - 若衰减后该类型的能量值大于 $0$，则将其能量值增加 $k^2$。

任意时刻，能量值大于 $0$ 的类型视为处于激活状态。你需要计算在整个处理过程中，同时处于激活状态的类型数量的最大值。

约束：设序列长度为 $n$。在所有测试数据中，$n$ 的总和不超过 $2 \times 10^5$。每个测试数据的 $n$ 满足 $1 \le n \le 2 \times 10^5$。类型编号 $c_i$ 满足 $1 \le c_i \le n$。

# 输入描述
第一行输入一个整数 $T$（$1 \le T \le 10^4$），表示测试数据的组数。
接下来每组数据包含两行：
- 第一行一个整数 $n$，表示核心序列的长度；
- 第二行 $n$ 个整数 $c_1, c_2, \dots, c_n$，依次表示每个核心的类型编号。
题目保证所有测试数据的 $n$ 之和不超过 $2 \times 10^5$。

# 输出描述
对于每组测试数据，输出一行一个整数，表示在整个处理过程中，同时激活的类型的最大数量。

## 样例1

**输入**

```
1
1
1
```

**输出**

```
1
```

**说明**

只有 `1` 个核心，类型为 `1`。初始所有能量值为 `0`。

处理核心前无衰减。处理核心时，类型 `1` 第 `1` 次出现，衰减后能量值为 `0`，因此能量值设为 $1^2 = 1$。此时激活类型集合为 $\{1\}$，激活数量为 `1`。

整个过程最大同时激活类型数量为 `1`。

## 样例2

**输入**

```
1
4
1 2 1 2
```

**输出**

```
2
```

**说明**

逐步模拟：

- 初始：无激活类型。
- 处理第 `1` 个核心（类型 `1`）：衰减无，类型 `1` 第 `1` 次出现，衰减后能量值为 `0`，设为 $1^2 = 1$。激活类型 $\{1\}$，数量 `1`。
- 处理第 `2` 个核心前衰减：类型 `1` 能量 `1` 减为 `0`（未激活）。处理第 `2` 个核心（类型 `2`）：第 `1` 次出现，设为 $1^2 = 1$。激活类型 $\{2\}$，数量 `1`。
- 处理第 `3` 个核心前衰减：类型 `2` 能量 `1` 减为 `0`。处理第 `3` 个核心（类型 `1`）：第 `2` 次出现，设为 $2^2 = 4$。激活类型 $\{1\}$，数量 `1`。
- 处理第 `4` 个核心前衰减：类型 `1` 能量 `4` 减为 `3`（仍激活）。处理第 `4` 个核心（类型 `2`）：第 `2` 次出现，衰减后能量值为 `0`，设为 $2^2 = 4$。此时激活类型 $\{1, 2\}$，数量 `2`。

整个过程最大同时激活类型数量为 `2`。

## 样例3

**输入**

```
1
6
1 2 3 2 1 3
```

**输出**

```
3
```

**说明**

逐步模拟：

- 初始：无激活类型。
- 第 `1` 个核心（类型 `1`）：第 `1` 次出现，能量设为 $1^2 = 1$，激活 $\{1\}$，数量 `1`。
- 第 `2` 个核心前衰减：类型 `1` 能量 `1` 减为 `0`。处理类型 `2`：第 `1` 次出现，设为 $1^2 = 1$，激活 $\{2\}$，数量 `1`。
- 第 `3` 个核心前衰减：类型 `2` 能量 `1` 减为 `0`。处理类型 `3`：第 `1` 次出现，设为 $1^2 = 1$，激活 $\{3\}$，数量 `1`。
- 第 `4` 个核心前衰减：类型 `3` 能量 `1` 减为 `0`。处理类型 `2`：第 `2` 次出现，设为 $2^2 = 4$，激活 $\{2\}$，数量 `1`。
- 第 `5` 个核心前衰减：类型 `2` 能量 `4` 减为 `3`（仍激活）。处理类型 `1`：第 `2` 次出现，衰减后能量值为 `0`，设为 $2^2 = 4$。此时激活类型 $\{2, 1\}$，能量分别为 `3` 和 `4`，数量 `2`。
- 第 `6` 个核心前衰减：类型 `2` 能量 `3` 减为 `2`，类型 `1` 能量 `4` 减为 `3`。处理类型 `3`：第 `2` 次出现，衰减后能量值为 `0`，设为 $2^2 = 4$。此时激活类型 $\{2, 1, 3\}$，能量分别为 `2`、`3`、`4`，数量 `3`。

整个过程最大同时激活类型数量为 `3`。
