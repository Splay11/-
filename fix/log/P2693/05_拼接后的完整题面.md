# 题目内容
有 $n$ 枚依次编号为 $1, 2, \ldots, n$ 的芯片。对所有满足 $1 \le i < j \le n$ 的无序对 $(i, j)$，定义其配对权值为 $\dfrac{i+j}{\gcd(i,j)}$，其中 $\gcd$ 表示最大公因数。

请计算全部配对权值之和。答案可能很大，对 $10^9+7$ 取模后输出。

测试组数 $T$ 满足 $1 \le T \le 10^5$。每组给定的整数 $n$ 满足 $1 \le n \le 10^6$。保证单个测试文件中所有 $n$ 之和不超过 $10^9$。

# 输入描述
每个测试文件包含多组数据。第一行包含一个整数 $T$，表示数据组数。
接下来 $T$ 行，每行包含一个整数 $n$。

# 输出描述
对于每一组测试数据，新起一行输出一个整数，表示答案对 $10^9+7$ 取模后的结果。

## 样例1

**输入**

```
4
2
3
10
114514
```

**输出**

```
3
12
396
853391453
```

**说明**

$n=2$ 只有一对 $(1,2)$，权值为 $\frac{1+2}{1}=3$。$n=3$ 的三对权值分别为 `3`、`4`、`5`，和为 `12`。其余两组由预处理后的前缀答案直接读出。

## 样例2

**输入**

```
1
1
```

**输出**

```
0
```

**说明**

$n=1$ 时不存在满足 $i<j$ 的数对，和为 `0`。

## 样例3

**输入**

```
2
1
2
```

**输出**

```
0
3
```

**说明**

第一组 $n=1$ 答案为 `0`；第二组 $n=2$ 答案为 `3`。
