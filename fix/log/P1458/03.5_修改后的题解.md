## 解题思路

对每条记录，需要判断实际归还时刻 $f$ 是否严格晚于规定时限 $d$。时刻以 `时:分` 给出，可能跨过午夜。

以申请时刻 $s$ 为参照：

- 若 $s$ 在钟面上晚于 $d$，说明时限已经跨过午夜，把 $d$ 的小时数加上 $24$；
- 若 $s$ 在钟面上晚于 $f$，说明实际归还已经跨过午夜，把 $f$ 的小时数加上 $24$。

这样 $d$ 和 $f$ 都被对齐到申请时刻之后，再按“小时优先、分钟其次”比较即可。相等不算超时。超时输出 `Yes`，否则输出 `No`。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
n = int(input())


def gt(h1, m1, h2, m2):
    return h1 > h2 or (h1 == h2 and m1 > m2)


for i in range(n):
    h1, m1 = input().split(":")
    h1, m1 = int(h1), int(m1)
    h2, m2 = input().split(":")
    h2, m2 = int(h2), int(m2)
    h3, m3 = input().split(":")
    h3, m3 = int(h3), int(m3)

    if gt(h1, m1, h2, m2):
        h2 += 24
    if gt(h1, m1, h3, m3):
        h3 += 24

    if gt(h3, m3, h2, m2):
        print("Yes")
    else:
        print("No")
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static boolean gt(int h1, int m1, int h2, int m2) {
        return h1 > h2 || (h1 == h2 && m1 > m2);
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        for (int i = 0; i < n; i++) {
            String[] p1 = scanner.next().split(":");
            String[] p2 = scanner.next().split(":");
            String[] p3 = scanner.next().split(":");
            int h1 = Integer.parseInt(p1[0]), m1 = Integer.parseInt(p1[1]);
            int h2 = Integer.parseInt(p2[0]), m2 = Integer.parseInt(p2[1]);
            int h3 = Integer.parseInt(p3[0]), m3 = Integer.parseInt(p3[1]);
            if (gt(h1, m1, h2, m2)) h2 += 24;
            if (gt(h1, m1, h3, m3)) h3 += 24;
            if (gt(h3, m3, h2, m2)) System.out.println("Yes");
            else System.out.println("No");
        }
    }
}
```

### C++

#include <bits/stdc++.h>
using namespace std;

bool gt(int h1, int m1, int h2, int m2) {
    return h1 > h2 || (h1 == h2 && m1 > m2);
}

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        int h1, m1, h2, m2, h3, m3;
        char dummy;
        cin >> h1 >> dummy >> m1;
        cin >> h2 >> dummy >> m2;
        cin >> h3 >> dummy >> m3;
        if (gt(h1, m1, h2, m2)) h2 += 24;
        if (gt(h1, m1, h3, m3)) h3 += 24;
        if (gt(h3, m3, h2, m2)) cout << "Yes\n";
        else cout << "No\n";
    }
    return 0;
}
