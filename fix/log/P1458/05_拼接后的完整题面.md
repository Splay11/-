# 题目内容
实验室预约设备时，每条记录包含三个时刻：提出申请的时刻 $s$，规定归还时限 $d$，以及实际归还时刻 $f$。若实际归还晚于规定时限，则该记录判定为超时。

申请之后的实际归还与规定时限均不会超过 `2` 小时，但时刻可能跨过午夜 `0` 点。

记录数不超过 `10^5`。每个时刻以 `时:分` 的形式给出。

# 输入描述
第一行包含一个整数 $n$（$1 \le n \le 10^5$），表示记录条数。
接下来 $3\times n$ 行，每连续三行描述一条记录：第一行是申请时刻 $s$，第二行是规定时限 $d$，第三行是实际归还时刻 $f$。每个时刻格式为 `时:分`。

# 输出描述
输出 $n$ 行。第 $i$ 行表示第 $i$ 条记录是否超时：超时输出 `Yes`，未超时输出 `No`。

## 样例1

**输入**

```
4
11:00
11:30
11:40
17:00
17:20
17:19
20:00
20:30
20:30
23:40
00:20
00:10
```

**输出**

```
Yes
No
No
No
```

**说明**

第一条：`11:40` 晚于 `11:30`，超时，输出 `Yes`。
第二条：`17:19` 早于 `17:20`，输出 `No`。
第三条：实际时刻与时限同为 `20:30`，不算晚于，输出 `No`。
第四条：时限与实际均跨过午夜，将小时数加 `24` 后比较，`00:10` 不晚于 `00:20`，输出 `No`。

## 样例2

**输入**

```
1
09:00
09:10
09:10
```

**输出**

```
No
```

**说明**

实际归还时刻与时限同为 `09:10`，不晚于时限，输出 `No`。

## 样例3

**输入**

```
1
23:50
00:10
00:20
```

**输出**

```
Yes
```

**说明**

申请时刻 `23:50` 晚于 `00:10` 与 `00:20`，说明后两者已跨过午夜，小时数加 `24` 后比较：`24:20` 晚于 `24:10`，输出 `Yes`。

## 样例4

**输入**

```
2
10:00
10:05
10:04
22:00
22:30
22:31
```

**输出**

```
No
Yes
```

**说明**

第一条 `10:04` 不晚于 `10:05`，输出 `No`。
第二条 `22:31` 晚于 `22:30`，输出 `Yes`。
