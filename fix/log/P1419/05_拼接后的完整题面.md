# 题目内容
给定两个长度为 $n$ 的整数序列 $p$ 和 $q$。允许且必须对 $p$ 执行恰好一次区间翻转：选定闭区间 $[L, R]$（下标从 `1` 开始），将 $p_L, p_{L+1}, \ldots, p_R$ 前后倒置。例如序列 $2,3,4,1,5,6$ 翻转区间 $[3,6]$ 后变为 $2,3,6,5,1,4$。

请计算有多少种不同的区间选择，能在这次翻转后使 $p$ 与 $q$ 完全相同。

约束：序列长度不超过 `10^4`，序列中每个元素均为不超过 `10^4` 的正整数。

# 输入描述
第一行一个正整数 $n$，表示两个序列的长度。
第二行 $n$ 个正整数，表示序列 $p$。
第三行 $n$ 个正整数，表示序列 $q$。
保证 $1 \le n, p_i, q_i \le 10^4$。

# 输出描述
输出一个整数，表示能使两个序列变得完全相同的区间个数。

## 样例1

**输入**

```
3
1 2 3
1 3 4
```

**输出**

```
0
```

**说明**

不相同的区间是 $[2,3]$。$p$ 的 $2,3$ 翻转后是 $3,2$，与 $q$ 的 $3,4$ 不一致。
无法通过一次翻转对齐，答案为 `0`。

## 样例2

**输入**

```
4
1 2 3 4
1 3 2 4
```

**输出**

```
1
```

**说明**

只需要翻转中间的 $[2,3]$，把 $2,3$ 变成 $3,2$。两端的 `1` 与 `4` 不相等，不能再扩张。
答案为 `1`。

## 样例3

**输入**

```
1
5
5
```

**输出**

```
1
```

**说明**

长度为 `1` 且两序列已经相同，翻转唯一的区间 $[1,1]$ 后仍然相同。
这是最小规模的边界情形，答案为 `1`。
