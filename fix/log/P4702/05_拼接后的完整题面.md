# 题目内容
实验台上横排放着恰好 `5` 瓶试剂，位置编号从 `1` 开始。五瓶试剂的标签恰好由字符 `a`、`b`、`c`、`d`、`e` 各出现一次组成。实验员需要立刻取出标签为 `a` 的那一瓶。请输出字符 `a` 所在的位置编号。

约束：字符串长度恰好为 `5`，且为 `a` 到 `e` 的一个排列。

# 输入描述
一行，一个长度为 `5` 的字符串，保证恰好由一个 `a`、一个 `b`、一个 `c`、一个 `d`、一个 `e` 组成。

# 输出描述
输出一个整数，表示字符 `a` 的位置（下标从 `1` 开始）。

## 样例1

**输入**

```
edcba
```

**输出**

```
5
```

**说明**

字符串为 `edcba`，字符 `a` 在第 `5` 个位置。

## 样例2

**输入**

```
baedc
```

**输出**

```
2
```

**说明**

从左到右扫描，`a` 出现在第 `2` 位。

## 样例3

**输入**

```
cdeab
```

**输出**

```
4
```

**说明**

`a` 位于第 `4` 个位置。
