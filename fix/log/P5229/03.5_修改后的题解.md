## 解题思路

设第 $i$ 个工位分配的能力等级为 $v_i$，其中 $1 \le i \le n$。

一个连续工位段 $[l,r]$ 包含第 $i$ 个工位，当且仅当 $l \le i \le r$。因此：

- 左端点 $l$ 可以从 $1$ 到 $i$ 选择，共 $i$ 种；
- 右端点 $r$ 可以从 $i$ 到 $n$ 选择，共 $n-i+1$ 种。

所以第 $i$ 个工位出现在 $i \times (n-i+1)$ 个连续工位段中。

总增益可以表示为：

$$
\sum_{i=1}^{n} v_i \cdot i \cdot (n-i+1)
$$

其中 $v_i$ 必须是 $1,2,\dots,n$ 的一个排列。

目标是使该和最大化。根据排序不等式，应该让权重大的位置分配更大的等级。

权重：

$$
w_i = i \times (n-i+1)
$$

关于中间位置对称，并且从两端向中间逐渐增大。因此可以采用如下贪心构造：

1. 维护左右指针 `left`、`right`，分别指向当前未分配区间的两端。
2. 维护当前待分配的最小等级 `value`。
3. 每次将 `value` 放在左端，然后将下一个等级放在右端（如果左右端不同）。
4. 左右指针向中间移动。
5. 重复直到所有工位分配完成。

这样能保证两端放较小等级，中间放较大等级，从而最大化总增益。

最后遍历 $1 \sim n$，按公式累计贡献，并对 $10^9+7$ 取模。

## 复杂度分析

构造等级序列只需要从两端向中间扫描一次，计算总增益也只需要遍历一次数组。

- 时间复杂度：$O(n)$
- 空间复杂度：$O(n)$，用于保存等级序列

## 代码实现

### Python

```python
MOD = 10**9 + 7

def solve(n):
    level = [0] * n
    left = 0
    right = n - 1
    value = 1

    # 从两端向中间依次放置较小等级
    while left <= right:
        level[left] = value
        value += 1

        if left != right:
            level[right] = value
            value += 1

        left += 1
        right -= 1

    # 计算最大总增益
    ans = 0
    for i in range(n):
        weight = (i + 1) * (n - i)
        ans = (ans + level[i] * weight) % MOD

    return ans, level


def main():
    n = int(input())
    ans, level = solve(n)

    print(ans)
    print(*level)


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    static final long MOD = 1000000007L;

    static long solve(int n, int[] level) {
        int left = 0;
        int right = n - 1;
        int value = 1;

        // 从两端向中间依次放置较小等级
        while (left <= right) {
            level[left] = value;
            value++;

            if (left != right) {
                level[right] = value;
                value++;
            }

            left++;
            right--;
        }

        long ans = 0;

        for (int i = 0; i < n; i++) {
            long weight = (long) (i + 1) * (n - i);
            ans = (ans + (weight % MOD) * level[i]) % MOD;
        }

        return ans;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int n = scanner.nextInt();
        int[] level = new int[n];

        long ans = solve(n, level);

        System.out.println(ans);

        StringBuilder result = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) {
                result.append(' ');
            }
            result.append(level[i]);
        }

        System.out.println(result);
        scanner.close();
    }
}
```
