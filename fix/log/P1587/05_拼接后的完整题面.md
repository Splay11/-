# 题目内容
实验室要依次完成 $n$ 项彼此独立的校准任务。处理第 $i$ 项任务时，每一次尝试有 $p_i$ 的概率失败、有 $1-p_i$ 的概率成功；一旦成功即完成该任务并进入下一项。同一项任务若已经连续失败三次，则下一次尝试必定成功。

全部任务完成后，设全过程的失败总次数为 $S$。每累计失败 `3` 次会产生一次熔断，因此熔断次数为 $\lfloor S/3 \rfloor$。

请计算熔断次数的期望。

任务数不超过 `500`，$p_i$ 为正实数且不超过 `1`（精确到小数点后 `5` 位）。答案的绝对误差不超过 `10^{-5}` 即视为正确。

# 输入描述
第一行包含一个整数 $n$，表示任务数量，满足 $1 \le n \le 500$。
第二行包含 $n$ 个实数 $p_1, p_2, \ldots, p_n$，其中 $p_i$ 表示第 $i$ 项任务单次尝试失败的概率，精确到小数点后 `5` 位，满足 $0 < p_i \le 1$。

# 输出描述
输出一个实数，表示熔断次数的期望。绝对误差不超过 $10^{-5}$ 即视为正确。

## 样例1

**输入**

```
2
0.50000 0.50000
```

**输出**

```
0.328125000
```

**说明**

两项任务失败概率均为 `0.5`。对单任务，失败次数为 $0,1,2,3$ 的概率依次为 $0.5$、$0.25$、$0.125$、$0.125$。
用动态规划卷积得到总失败次数 $S$ 的分布，再对每种 $S$ 累加 $P(S)\cdot \lfloor S/3 \rfloor$，期望为 `0.328125`。

## 样例2

**输入**

```
1
1.00000
```

**输出**

```
1.000000000
```

**说明**

只有一项任务且每次必失败，因此必然连续失败 `3` 次后被强制成功。$S=`3`$，$\lfloor 3/3 \rfloor=`1`$，期望为 `1`。

## 样例3

**输入**

```
1
0.50000
```

**输出**

```
0.125000000
```

**说明**

失败次数为 $0,1,2$ 时 $\lfloor S/3 \rfloor=`0`$；仅当失败 `3` 次时熔断 `1` 次，该概率为 $0.5^{3}=0.125$。期望为 `0.125`。

## 样例4

**输入**

```
3
0.20000 0.80000 0.10000
```

**输出**

```
0.567950656
```

**说明**

三项任务的失败次数相互独立，取值均在 $\{0,1,2,3\}$。按任务依次做概率卷积，得到 $S$ 的分布后计算 $E[\lfloor S/3 \rfloor]$，结果约为 `0.567950656`。
