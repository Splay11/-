# 题目内容
调度模块要把额度 $n$ 拆成两份正整数 $a$ 和 $b$，满足 $a+b=n$，并希望对冲指标 $\mathrm{lcm}(a,b)$ 尽可能大。共有 $t$ 次独立查询，每次给出一个 $n$。

请对每次查询输出一组使最小公倍数最大的 $a$ 和 $b$。

约束：询问次数不超过 `100000`，$2 \le n \le 10000000000000$。

# 输入描述
第一行一个正整数 $t$。
接下来 $t$ 行，每行一个正整数 $n$。
保证 $1 \le t \le 100000$，$2 \le n \le 10000000000000$。

# 输出描述
对每组询问输出一行两个正整数 $a$ 和 $b$，用空格隔开。

**输入**

```
3
3
6
9
```

**输出**

```
1 2
1 5
4 5
```
