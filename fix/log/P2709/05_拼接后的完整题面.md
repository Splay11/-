# 题目内容
对于一个非负整数 $x$，如果存在非负整数 $k$ 满足 $x = 2^k$，则定义 $x$ 的纯净度为 $k$；否则纯净度为 $0$。

给定一个长度为 $n$ 的数组 $a$，请你计算所有连续子数组之和的纯净度总和，即：
$$\sum_{l=1}^{n}\sum_{r=l}^{n} g\Bigl(\sum_{i=l}^{r} a_i\Bigr)$$
其中 $g(x)$ 表示 $x$ 的纯净度。

约束：数组长度 $n$ 不超过 $3 \times 10^5$，一个测试点中所有数据组的 $n$ 之和也不超过 $3 \times 10^5$，数组中的元素均为小于 $2^{30}$ 的非负整数。

# 输入描述
第一行包含一个整数 $T$（$1 \le T \le 10^4$），表示测试数据的组数。对于每组数据：第一行包含一个整数 $n$（$1 \le n \le 3 \times 10^5$），表示数组长度；第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$（$0 \le a_i < 2^{30}$），表示数组元素。保证所有测试数据的 $n$ 之和不超过 $3 \times 10^5$。

# 输出描述
对于每组数据，输出一行一个整数，表示该组数组所有连续子数组和的纯净度总和。

## 样例1

**输入**

```
1
1
0
```

**输出**

```
0
```

**说明**

数组仅有一个元素 `0`，唯一的连续子数组 `[0]` 的和为 `0`。`0` 不是 `2` 的幂，纯净度为 `0`，总贡献为 `0`。

## 样例2

**输入**

```
1
3
1 3 4
```

**输出**

```
7
```

**说明**

数组元素为 `[1, 3, 4]`。枚举所有连续子数组：
- `[1]` 和为 `1`，纯净度 `0`；
- `[3]` 和为 `3`，纯净度 `0`；
- `[4]` 和为 `4 = 2^2`，纯净度 `2`；
- `[1, 3]` 和为 `4 = 2^2`，纯净度 `2`；
- `[3, 4]` 和为 `7`，纯净度 `0`；
- `[1, 3, 4]` 和为 `8 = 2^3`，纯净度 `3`。
总贡献为 `2 + 2 + 3 = 7`。

## 样例3

**输入**

```
2
2
3 5
4
1 1 2 2
```

**输出**

```
3
7
```

**说明**

第一组数组 `[3, 5]`：
- `[3]` 和为 `3`，纯净度 `0`；
- `[5]` 和为 `5`，纯净度 `0`；
- `[3, 5]` 和为 `8 = 2^3`，纯净度 `3`。
总和为 `3`。

第二组数组 `[1, 1, 2, 2]`：
- 单个元素子数组：两个 `1` 的和均为 `1`（纯净度 `0`），两个 `2` 的和均为 `2 = 2^1`（各贡献 `1`），共贡献 `2`；
- 长度为 `2` 的子数组：`[1, 1]` 和为 `2`（纯净度 `1`），`[1, 2]` 和为 `3`（纯净度 `0`），`[2, 2]` 和为 `4 = 2^2`（纯净度 `2`），共贡献 `1 + 0 + 2 = 3`；
- 长度为 `3` 的子数组：`[1, 1, 2]` 和为 `4 = 2^2`（纯净度 `2`），`[1, 2, 2]` 和为 `5`（纯净度 `0`），共贡献 `2`；
- 整个数组 `[1, 1, 2, 2]` 和为 `6`，纯净度 `0`。
总贡献为 `2 + 3 + 2 + 0 = 7`。
