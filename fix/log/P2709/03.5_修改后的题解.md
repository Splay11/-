## 解题思路

1. **定义纯净度**：对于非负整数 $x$，若存在非负整数 $k$ 使得 $x = 2^k$，则纯净度 $g(x) = k$；否则 $g(x) = 0$。特别地，当 $x = 1 = 2^0$ 时纯净度为 $0$。
2. **前缀和转换**：设前缀和数组 $P$，其中 $P[0] = 0$，$P[i] = \sum_{j=1}^{i} a_j$。任意子数组 $[l, r]$ 的和可以表示为 $S = P[r] - P[l-1]$。因此，问题转化为统计所有满足 $P[r] - P[l-1] = 2^k$ 的前缀对 $(l-1, r)$ 的贡献，贡献值为 $k$（$k \ge 1$ 时有效，$k=0$ 时贡献为 $0$）。
3. **哈希表优化**：固定右端点 $r$，维护一个哈希表（字典）记录所有已出现的前缀和 $P[l-1]$ 及其出现次数。对于当前前缀和 $P[r]$，枚举可能的 $k$ 值，计算目标值 $\text{target} = P[r] - 2^k$，若该 target 在哈希表中存在，则答案增加 $k \times \text{freq}[\text{target}]$。枚举 $k$ 的上限由前缀和的上限决定：数组元素最大 $<2^{30}$，长度最大 $3\times 10^5$，前缀和上限在 $2^{60}$ 以内，枚举 $k$ 从 $1$ 到 $60$ 已完全足够。
4. **边界处理**：初始时前缀和 $0$ 已出现一次（对应 $l=1$ 时 $l-1=0$ 的情况）。
5. 输出：对于每组数据输出答案，答案可能较大，需使用 64 位整数（`long long` / `int64`）。

## 复杂度分析

- **时间复杂度**：对于每组数据，枚举每个元素的一次遍历 $O(n)$，每个位置枚举常数个 $k$（最多约 $60$ 个），哈希表操作期望 $O(1)$，因此总时间复杂度为 $O(n \log \max S)$，其中 $\max S$ 是最大前缀和。所有数据的总 $n$ 不超过 $3\times 10^5$，可以高效通过。
- **空间复杂度**：需要存储前缀和的哈希表，其大小与 $n$ 同阶，空间复杂度 $O(n)$。输入数组可以边读边处理，不额外存储也可，但为清晰可存储数组，空间仍为 $O(n)$。

## 代码实现

### Python

```python
import sys

def main():
    data = sys.stdin.read().split()
    t = int(data[0])
    idx = 1
    out_lines = []
    for _ in range(t):
        n = int(data[idx]); idx += 1
        a = list(map(int, data[idx:idx + n])); idx += n
        
        freq = {0: 1}   # 前缀和出现次数，初始时前缀和0出现1次
        prefix = 0
        ans = 0
        for v in a:
            prefix += v
            # 枚举 2^k，k >= 1
            for k in range(1, 61):
                power = 1 << k       # 2^k
                target = prefix - power
                if target in freq:
                    ans += k * freq[target]
            # 更新当前前缀和次数
            freq[prefix] = freq.get(prefix, 0) + 1
        
        out_lines.append(str(ans))
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        PrintWriter out = new PrintWriter(new OutputStreamWriter(System.out));
        int T = Integer.parseInt(br.readLine().trim());
        while (T-- > 0) {
            int n = Integer.parseInt(br.readLine().trim());
            String[] parts = br.readLine().trim().split(" ");
            long[] a = new long[n];
            for (int i = 0; i < n; i++) {
                a[i] = Long.parseLong(parts[i]);
            }
            
            // 哈希表记录前缀和出现次数
            Map<Long, Long> freq = new HashMap<>();
            freq.put(0L, 1L);   // 前缀和0出现一次
            long prefix = 0;
            long ans = 0;
            
            for (int i = 0; i < n; i++) {
                prefix += a[i];
                // 枚举 2^k，k 从 1 到 60
                for (int k = 1; k <= 60; k++) {
                    long power = 1L << k;          // 2^k
                    long target = prefix - power;
                    Long cnt = freq.get(target);
                    if (cnt != null) {
                        ans += k * cnt;
                    }
                }
                // 更新当前前缀和出现次数
                freq.put(prefix, freq.getOrDefault(prefix, 0L) + 1L);
            }
            out.println(ans);
        }
        out.flush();
        out.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <unordered_map>
#include <vector>
using namespace std;
typedef long long ll;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        vector<ll> a(n);
        for (int i = 0; i < n; ++i) {
            cin >> a[i];
        }
        
        unordered_map<ll, ll> freq;
        freq[0] = 1;          // 前缀和0出现一次
        ll prefix = 0;
        ll ans = 0;
        
        for (int i = 0; i < n; ++i) {
            prefix += a[i];
            // 枚举 2^k，k 从 1 到 60
            for (int k = 1; k <= 60; ++k) {
                ll power = 1LL << k;        // 2^k
                ll target = prefix - power;
                auto it = freq.find(target);
                if (it != freq.end()) {
                    ans += k * it->second;
                }
            }
            // 更新当前前缀和次数
            freq[prefix]++;
        }
        cout << ans << "\n";
    }
    return 0;
}
```
