# 题目内容
小蓝正在整理一些数据，她非常偏爱数字 `3` 和 `5`，却不想看到数字 `4` 的影子。现在她手头有一个数组，她想从中选出若干元素构成一个子序列，使得子序列中所有元素的和既是 `3` 的倍数，又是 `5` 的倍数，但不能是 `4` 的倍数。

请你帮她计算一共有多少种不同的子序列满足上述条件。由于答案可能非常大，请输出结果对 $10^9+7$ 取模后的值。

数组的长度不超过 $10^5$，每个元素为不超过 $10^9$ 的正整数。

# 输入描述
第一行包含一个整数 $n$（$1 \le n \le 10^5$），表示数组的长度。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$（$1 \le a_i \le 10^9$），表示数组中的元素。

# 输出描述
输出一个整数，表示满足条件的子序列个数对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
1
15
```

**输出**

```
1
```

**说明**

只有选取 `15` 这一个元素的子序列满足条件。空子序列和为 `0`，虽然同时是 `3` 和 `5` 的倍数，但也是 `4` 的倍数，不符合要求。因此答案为 `1`。

## 样例2

**输入**

```
3
15 30 45
```

**输出**

```
6
```

**说明**

数组元素都是 `15` 的倍数。每个元素模 `4` 的余数分别为 $3, 2, 1$。所有非空子序列的和均为 `15` 的倍数，需要排除和是 `4` 的倍数的子序列。
- 单个元素：`[15]`, `[30]`, `[45]`，均合法，共 `3` 个。
- 两个元素：`[15,30]` 和为 `45`（模 `4` 余 `1`），合法；`[15,45]` 和为 `60`（模 `4` 余 `0`），不合法；`[30,45]` 和为 `75`（模 `4` 余 `3`），合法；共 `2` 个。
- 三个元素：`[15,30,45]` 和为 `90`（模 `4` 余 `2`），合法，共 `1` 个。
空子序列不合法。总计 $3+2+1 = 6$ 个。

## 样例3

**输入**

```
4
15 30 20 10
```

**输出**

```
6
```

**说明**

需要子序列和是 `15` 的倍数且不是 `4` 的倍数。满足条件的子序列有：
- `[15]`，和为 `15`（模 `4` 余 `3`）
- `[30]`，和为 `30`（模 `4` 余 `2`）
- `[15,30]`，和为 `45`（模 `4` 余 `1`）
- `[20,10]`，和为 `30`（模 `4` 余 `2`）
- `[15,20,10]`，和为 `45`（模 `4` 余 `1`）
- `[15,30,20,10]`，和为 `75`（模 `4` 余 `3`）
其他非空子序列的和要么不是 `15` 的倍数，要么是 `4` 的倍数（如 `[30,20,10]` 和为 `60`，是 `4` 的倍数，排除）。空子序列不合规。总数为 `6`。
