## 解题思路

题目要求从数组中选出若干元素组成子序列，使得子序列元素之和既是 3 的倍数又是 5 的倍数，但不能是 4 的倍数。

- “既是 3 的倍数又是 5 的倍数”等价于 **该和是 15 的倍数**。
- 在 15 的倍数中剔除 4 的倍数，相当于要求 **和是 15 的倍数但不是 60 的倍数**（因为 15 和 4 的最小公倍数是 60）。
- 在模 60 的意义下，15 的倍数有 0, 15, 30, 45；其中 0 同时也是 4 的倍数（60 的倍数），需要排除。因此满足条件的和的模 60 余数只能是 **15, 30, 45**。

问题转化为：求所有子序列中，元素之和模 60 等于 15、30 或 45 的方案数，对 $10^9+7$ 取模。

采用动态规划：

- 定义 `dp[j]` 表示当前已处理前缀中，子序列之和模 60 等于 `j` 的个数。
- 初始时，空序列的和为 0，因此 `dp[0] = 1`，其余为 0。
- 依次遍历数组中的每个元素 $x$，记 $r = x \bmod 60$。
- 对于当前元素，每个旧的子序列都可以选择“不包含当前元素”或“包含当前元素”。
  - 不包含：`dp[j]` 保持不变（沿用旧值）。
  - 包含：若之前有一个和为 $s$ 的子序列，加入 $x$ 后新和为 $(s + r) \bmod 60$。也就是说，所有旧状态 `old[(j - r) % 60]` 都会贡献到新的 `dp[j]` 上。
- 因此，用旧状态数组 `old` 保存上一轮的值，更新方式为：
  ```
  dp[j] = (old[j] + old[(j - r) % 60]) % MOD
  ```
- 处理完所有元素后，答案即为 `(dp[15] + dp[30] + dp[45]) % MOD`。

## 复杂度分析

- 时间复杂度：对每个元素，都需要遍历模 60 的所有余数进行状态转移，共 $O(60n)$，即 $O(n)$，$n$ 最大 $10^5$，可以在时限内完成。
- 空间复杂度：使用滚动数组仅保存一个长度为 60 的数组和一份旧状态副本，空间复杂度 $O(60) = O(1)$。也可使用二维数组，空间复杂度 $O(60n)$。

## 代码实现

### Python

```python
MOD = 10**9 + 7

n = int(input())
a = list(map(int, input().split()))

dp = [0] * 60
dp[0] = 1  # 空序列

for x in a:
    r = x % 60
    old = dp[:]  # 保存旧状态
    for j in range(60):
        dp[j] = (old[j] + old[(j - r) % 60]) % MOD

ans = (dp[15] + dp[30] + dp[45]) % MOD
print(ans)
```

### Java

```java
import java.util.Scanner;

public class Main {
    private static final long MOD = 1000000007L;

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }
        sc.close();

        long[] dp = new long[60];
        dp[0] = 1; // 空序列

        for (int x : a) {
            int r = x % 60;
            long[] old = dp.clone(); // 保存旧状态
            for (int j = 0; j < 60; j++) {
                dp[j] = (old[j] + old[(j - r + 60) % 60]) % MOD;
            }
        }

        long ans = (dp[15] + dp[30] + dp[45]) % MOD;
        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int MOD = 1000000007;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
    }

    vector<long long> dp(60, 0);
    dp[0] = 1; // 空序列

    for (int x : a) {
        int r = x % 60;
        vector<long long> old = dp; // 保存旧状态
        for (int j = 0; j < 60; ++j) {
            dp[j] = (old[j] + old[(j - r + 60) % 60]) % MOD;
        }
    }

    long long ans = (dp[15] + dp[30] + dp[45]) % MOD;
    cout << ans << "\n";

    return 0;
}
```
