# 题目内容
边缘网关按节拍向外广播固定口令，供对账模块核对。第 $i$ 个节拍（从 `1` 开始编号）若为奇数则正序发送 `you`，若为偶数则倒序发送 `uoy`。值班同学需要把即将发出的 $n$ 个节拍口令依次拼接，得到完整报文。

请输出这 $n$ 个片段按规则拼接后的字符串。

约束：$n$ 是正整数，满足 $1 \le n \le 100000$。

# 输入描述
第一行包含一个正整数 $n$，表示节拍总数，满足 $1 \le n \le 100000$。

# 输出描述
输出一个字符串，表示 $n$ 个口令片段按规则拼接后的结果。

## 样例1

**输入**

```
1
```

**输出**

```
you
```

**说明**

只有第 `0` 个节拍，偶数下标对应片段 `you`。

## 样例2

**输入**

```
2
```

**输出**

```
youuoy
```

**说明**

第 `0` 拍为 `you`，第 `1` 拍为 `uoy`，拼接得到 `youuoy`。

## 样例3

**输入**

```
4
```

**输出**

```
youuoyyouuoy
```

**说明**

四个片段依次为 `you`、`uoy`、`you`、`uoy`，拼接后长度为 `12`。

## 样例4

**输入**

```
7
```

**输出**

```
youuoyyouuoyyouuoyyou
```

**说明**

七个片段按偶奇交替排列，最后一段下标为 `6`（偶数），因此以 `you` 结尾。
