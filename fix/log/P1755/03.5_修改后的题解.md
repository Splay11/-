## 解题思路

按节拍编号奇偶交替输出 `you` 与 `uoy`，共 $n$ 个节拍。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(1)$（不计输出）。

## 代码实现

### Python

```python
n=int(input())
print(''.join('you' if i%2==0 else 'uoy' for i in range(n)))
```

### Java

```java
import java.util.*;
public class Main {
    public static void main(String[] args) {
        int n = new Scanner(System.in).nextInt();
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) sb.append(i % 2 == 0 ? "you" : "uoy");
        System.out.println(sb);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    vector<string> s = {"you", "uoy"};
    for (int i = 0; i < n; i++) cout << s[i % 2];
}
```
