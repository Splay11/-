# 题目内容
在一个自动化包裹分拣系统中，有一批编号为 $1$ 到 $n$ 的待处理包裹，它们按编号顺序排列在传送带上。操作员可以对最前面的包裹执行两种操作：
- `In`：将当前最前面的包裹从传送带上取下，放入一个暂存箱。暂存箱具有后进先出的特性，即每次只能看到和取出最顶部的一个包裹。
- `Out`：将暂存箱最顶部的包裹取出并丢弃。

初始时暂存箱为空。现给定一个目标包裹序列，表示操作结束后希望暂存箱中保留的包裹从底到顶的顺序。多余包裹必须在操作过程中通过 `Out` 丢弃。请你输出一个合法的操作序列（以逗号分隔的指令串），使得最终暂存箱中的包裹序列恰好与给定的目标序列一致。

保证待处理包裹总数 $n$ 和目标保留包裹数量 $m$ 均不超过 $100$，且输入保证存在合法的指令序列。

# 输入描述
第一行包含两个整数 $n$ 和 $m$，分别表示待处理包裹的总数和目标保留包裹的数量。
第二行包含 $m$ 个整数，表示目标保留包裹的编号序列（这些编号来自 $1$ 到 $n$），顺序为从暂存箱底部到顶部。

# 输出描述
输出一行，由若干指令组成，相邻指令之间用逗号 `,` 分隔。指令仅为 `In` 和 `Out`。

## 样例1

**输入**

```
5 3
1 4 5
```

**输出**

```
In,In,Out,In,Out,In,In
```

**说明**

目标保留包裹从底到顶为 `1, 4, 5`。

- 处理目标 `1`：此时下一个待处理包裹编号 $nxt = 1$，执行 `In` 将包裹 `1` 放入暂存箱并保留，$nxt$ 更新为 `2`。
- 处理目标 `4`：$nxt=2 \le 4$，对包裹 `2` 执行 `In`，因其不是目标，紧接着执行 `Out` 丢弃；$nxt$ 变为 `3`，同理对包裹 `3` 执行 `In` 和 `Out` 丢弃；$nxt$ 变为 `4`，对包裹 `4` 执行 `In` 并保留。
- 处理目标 `5`：$nxt=5 \le 5$，对包裹 `5` 执行 `In` 并保留。

最终暂存箱自底向顶恰为 `1, 4, 5`，操作序列为 `In,In,Out,In,Out,In,In`。

## 样例2

**输入**

```
4 2
2 4
```

**输出**

```
In,Out,In,In,Out,In
```

**说明**

目标序列为 `2, 4`。

- 处理目标 `2`：$nxt=1 \le 2$，包裹 `1` 执行 `In` 后立刻 `Out` 丢弃；$nxt$ 变为 `2`，执行 `In` 并保留。
- 处理目标 `4`：$nxt=3 \le 4$，包裹 `3` 执行 `In` 后立刻 `Out` 丢弃；$nxt$ 变为 `4`，执行 `In` 并保留。

最终栈底到顶为 `2, 4`，指令序列为 `In,Out,In,In,Out,In`。

## 样例3

**输入**

```
3 3
1 2 3
```

**输出**

```
In,In,In
```

**说明**

目标序列包含全部包裹 `1, 2, 3`。

依次对 `1`、`2`、`3` 执行 `In`，每个恰好是当前等待的编号且都是目标，不需要任何 `Out` 操作。最终栈底到顶为 `1, 2, 3`。

## 样例4

**输入**

```
1 1
1
```

**输出**

```
In
```

**说明**

当 $n = 1$ 且目标仅包含包裹 `1` 时，直接执行 `In` 放入并保留，无需丢弃。暂存箱中自底向顶即为 `1`。
