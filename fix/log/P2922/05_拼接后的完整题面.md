# 题目内容
客服中心按时刻记录接入类型：连续 $n$ 个时刻各发生一次接入，用长度为 $n$、仅含字符 `M` 与 `W` 的字符串 $s$ 描述。第 $i$ 个时刻若 $s_i$ 为 `M`，表示一次人工坐席接入；若为 `W`，表示一次机器人接入。值班长要评估人工通道是否更繁忙，统计有多少个时刻，截至该时刻（含）累计的人工接入次数严格多于机器人接入次数。

请输出这样的时刻个数。

约束：时刻数 $n$ 满足 $1 \le n \le 100000$。

# 输入描述
第一行一个整数 $n$，表示时刻个数。
第二行一个长度为 $n$ 的字符串 $s$，仅由字符 `M` 和 `W` 组成。
保证 $1 \le n \le 100000$。

# 输出描述
输出一个整数，表示满足“人工累计次数严格更多”的时刻个数。

## 样例1

**输入**

```
6
MMWWWM
```

**输出**

```
3
```

**说明**

六个时刻后，主站累计依次为 `1,2,2,2,2,3`，备站累计为 `0,0,1,2,3,3`。
严格领先的时刻为第 `1`、`2`、`6` 个，共 `3` 个。

## 样例2

**输入**

```
1
W
```

**输出**

```
0
```

**说明**

仅一个备站信标，主站从未更多，答案为 `0`。

## 样例3

**输入**

```
5
MMMMM
```

**输出**

```
5
```

**说明**

五个时刻全是主站信标，每个时刻都严格领先，答案为 `5`。

## 样例4

**输入**

```
8
WMWMWMWM
```

**输出**

```
0
```

**说明**

主站与备站交替出现且备站总是先到，任意前缀中主站都不更多，答案为 `0`。
