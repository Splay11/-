## 解题思路

从左到右扫描字符串 $s$，维护人工接入累计 $mCnt$ 与机器人接入累计 $wCnt$。遇到 `M` 则 $mCnt$ 加一，遇到 `W` 则 $wCnt$ 加一。若当前 $mCnt > wCnt$，答案加一。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
def solve():
    n = int(input().strip())
    s = input().strip()
    mCnt = 0
    wCnt = 0
    ans = 0
    for c in s:
        if c == 'M':
            mCnt += 1
        else:
            wCnt += 1
        if mCnt > wCnt:
            ans += 1
    print(ans)

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        String s = in.next();
        int mCnt = 0, wCnt = 0, ans = 0;
        for (char c : s.toCharArray()) {
            if (c == 'M') mCnt++;
            else wCnt++;
            if (mCnt > wCnt) ans++;
        }
        System.out.println(ans);
        in.close();
    }
}
```
