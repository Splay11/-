# 题目内容
一座观测站的定向天线每 `60` 秒匀速转过整整一圈。值班日志按时间先后记下了 $n$ 个时刻，每个时刻写成 `hh:mm:ss` 的形式，其中 $hh$、$mm$、$ss$ 分别为时、分、秒，满足 $0 \le hh < 24$、$0 \le mm < 60$、$0 \le ss < 60$。

相邻两次记录之间，天线转过的圈数等于这两次时刻的最小正向间隔秒数除以 `60`。计算间隔时：若后一时刻严格早于前一时刻，则视为已经跨过一次零点，需在后一时刻上加上 `24` 小时；若两个时刻完全相同，则间隔为 `0` 秒。

请对每一对相邻记录，求出天线至少转过的圈数。

约束：记录个数 $n$ 满足 $2 \le n \le 10^5$。

# 输入描述
第一行输入一个整数 $n$，表示记录的时刻个数，满足 $2 \le n \le 10^5$。
第二行输入 $n$ 个字符串，相邻字符串之间用空格分隔。每个字符串的格式为 `hh:mm:ss`，表示一个时刻，其中 $0 \le hh < 24$、$0 \le mm < 60$、$0 \le ss < 60$。

# 输出描述
输出一行 $n-1$ 个数，相邻两个数之间用空格分隔。第 $i$ 个数表示第 $i$ 个时刻到第 $i+1$ 个时刻天线转过的圈数，保留恰好两位小数。
