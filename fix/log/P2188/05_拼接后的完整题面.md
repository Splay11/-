# 题目内容
实验室里有 $n$ 份试剂，第 $i$ 份的浓度为整数 $v_i$。每一次「交错调和」会把当前长度为 $k$ 的序列 $x_1,x_2,\ldots,x_k$ 变成长度为 $k-1$ 的新序列 $y$：指定起始符号 $\sigma\in\{+1,-1\}$，令
$$y_i = x_i + (-1)^{i-1}\sigma\, x_{i+1}\qquad (1\le i\le k-1).$$
需要连续调和 $n-1$ 次，直到只剩一份试剂。第 $t$ 次调和的起始符号 $\sigma_t$ 由初始长度 $n$ 决定：
- 若 $n$ 为偶数：第一次的起始符号 $\sigma_1=+1$（当 $n$ 不是 `4` 的倍数）或 $\sigma_1=-1$（当 $n$ 是 `4` 的倍数），此后每次将起始符号取反，即 $\sigma_t=(-1)^{t-1}\sigma_1$。
- 若 $n$ 为奇数：第一次固定 $\sigma_1=+1$；从第二次起，将 $n-1$ 视为上面的偶数情形来确定起始符号，并继续每次取反。
请输出最终那份试剂的浓度对 $10^9+7$ 取模的结果。

约束：试剂份数 $n$ 满足 $1 \le n \le 10^5$，每个浓度 $v_i$ 为不超过 $10^9$ 的非负整数。

# 输入描述
第一行输入一个整数 $n$，表示试剂的份数，满足 $1 \le n \le 10^5$。
第二行输入 $n$ 个非负整数 $v_1,v_2,\ldots,v_n$，表示各份试剂的浓度，每个浓度不超过 $10^9$。

# 输出描述
输出一行一个整数，表示最终浓度对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
1
7
```

**输出**

```
7
```

**说明**

边界情况：只有 `1` 份试剂，浓度为 `7`。无需调和，答案为 $7 \bmod (10^9+7)=7$。

## 样例2

**输入**

```
2
3 5
```

**输出**

```
8
```

**说明**

长度为 $n=2$，是偶数且不是 `4` 的倍数，因此 $\sigma_1=+1$。一次调和得到 $3+5=8$。

答案为 $8 \bmod (10^9+7)=8$。

## 样例3

**输入**

```
3
1 2 3
```

**输出**

```
2
```

**说明**

$n=3$ 为奇数，第一次以 $\sigma_1=+1$ 调和：新序列为 $(1+2,\ 2-3)=(3,-1)$，长度变为 `2`。

$n-1=2$ 不是 `4` 的倍数，第二次起始符号为 $+1$，得到 $3+(-1)=2$。

答案为 `2`。

## 样例4

**输入**

```
4
1 2 3 4
```

**输出**

```
1000000005
```

**说明**

$n=4$ 是 `4` 的倍数，故 $\sigma_1=-1$，此后每次取反。

第一次：$y=(1-2,\ 2+3,\ 3-4)=(-1,5,-1)$。

第二次 $\sigma_2=+1$：$z=(-1+5,\ 5-(-1))=(4,6)$。

第三次 $\sigma_3=-1$：$4-6=-2$。

对 $10^9+7$ 取模得 $10^9+5$，即 `1000000005`。
