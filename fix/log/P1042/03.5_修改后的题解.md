## 解题思路

取件员需要支持“队首出队、队尾入队”，用双端队列保存规格序列 $p$。货箱只能从栈顶取走，用栈保存序列 $b$（将 $b$ 倒序压栈后，栈顶即为 $b_0$）。

之后按规则模拟：

- 若队首规格等于栈顶规格，双方各弹出一个，并将连续失配计数清零；
- 否则把队首取件员移到队尾，连续失配计数加 `1`。

若连续失配次数超过人数上界（实现中取 `200`，因为 $n \le 100$），说明剩余取件员都无法匹配当前栈顶，停止模拟。答案即为队列中剩余人数。

## 复杂度分析

每次匹配会永久减少一名取件员；每次失配只是轮转。在失配上限为常数倍 $n$ 的约束下：

- 时间复杂度：$O(n^2)$。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
from collections import deque

n = int(input())
p = list(map(int, input().split()))
b = list(map(int, input().split()))

q = deque(p)
stk = b[::-1]
cnt = 0
while q and stk and cnt <= 200:
    if stk[-1] == q[0]:
        stk.pop()
        q.popleft()
        cnt = 0
    else:
        q.append(q.popleft())
        cnt += 1
print(len(q))
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] p = new int[n];
        int[] b = new int[n];
        for (int i = 0; i < n; i++) p[i] = sc.nextInt();
        for (int i = 0; i < n; i++) b[i] = sc.nextInt();

        Deque<Integer> q = new ArrayDeque<>();
        for (int x : p) q.addLast(x);
        Deque<Integer> stk = new ArrayDeque<>();
        for (int i = n - 1; i >= 0; i--) stk.push(b[i]);

        int cnt = 0;
        while (!q.isEmpty() && !stk.isEmpty() && cnt <= 200) {
            if (stk.peek().equals(q.peekFirst())) {
                stk.pop();
                q.pollFirst();
                cnt = 0;
            } else {
                q.addLast(q.pollFirst());
                cnt++;
            }
        }
        System.out.println(q.size());
        sc.close();
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> p(n), b(n);
    for (int i = 0; i < n; i++) cin >> p[i];
    for (int i = 0; i < n; i++) cin >> b[i];

    deque<int> q(p.begin(), p.end());
    stack<int> stk;
    for (int i = n - 1; i >= 0; i--) stk.push(b[i]);

    int cnt = 0;
    while (!q.empty() && !stk.empty() && cnt <= 200) {
        if (stk.top() == q.front()) {
            stk.pop();
            q.pop_front();
            cnt = 0;
        } else {
            int g = q.front();
            q.pop_front();
            q.push_back(g);
            cnt++;
        }
    }
    cout << q.size() << "\n";
    return 0;
}
```
