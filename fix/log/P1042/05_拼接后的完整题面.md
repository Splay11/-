# 题目内容
物流仓里有一条竖直货架，上面自下而上叠放着 $n$ 个货箱；同时有 $n$ 名取件员排成一队。货箱与取件员都只区分两种规格，分别用 `0` 和 `1` 表示。每位取件员只会取走与自己规格相同的货箱。

领取规则如下：

- 每一轮只能由队首的取件员操作：若当前最上方（栈顶）货箱的规格与其相同，则取走该货箱并离开队列；否则该取件员立刻走到队尾，等待下一轮。
- 上述过程一直进行，直到队列为空，或剩余取件员的规格全都与当前栈顶货箱不同为止。

给定两个长度均为 $n$ 的整数序列 $p$ 与 $b$：$p_i$ 表示初始队列中第 $i$ 名取件员的规格（下标从 `0` 开始，$i=0$ 为队首），$b_j$ 表示第 $j$ 个货箱的规格（$j=0$ 为当前栈顶）。

请计算最终无法取到货箱的取件员人数。

人数 $n$ 不超过 `100`，序列 $p$ 与 $b$ 长度相等，且其中每个数都是 `0` 或 `1`。

# 输入描述
第一行一个整数 $n$，表示取件员人数（也是货箱个数）。
第二行 $n$ 个整数 $p_0, p_1, \ldots, p_{n-1}$，表示初始队列中各取件员的规格（$p_0$ 为队首）。
第三行 $n$ 个整数 $b_0, b_1, \ldots, b_{n-1}$，表示货箱规格（$b_0$ 为当前栈顶）。
保证 $1 \le n \le 100$，且每个 $p_i$、$b_j$ 均为 `0` 或 `1`。

# 输出描述
输出一个整数，表示最终无法取到货箱的取件员人数。
