# 题目内容
给定一个长度为 $L$ 的排列 $p_1, p_2, \dots, p_L$，对于 $i \ge 3$，若满足 $p_i \ge \max(p_{i-2}, p_{i-1})$，则称位置 $i$ 为一个“跃升点”。

请构造一个长度为 $L$ 的排列，使得跃升点的个数恰好为 $K$。如果有多种可能的构造，输出任意一种即可。

约束条件：测试用例总数 $T$ 不超过 $10^5$，每个测试用例的长度 $L$ 满足 $3 \le L \le 2 \times 10^5$，跃升点个数 $K$ 满足 $0 \le K \le L - 2$。所有测试用例的 $L$ 之和不超过 $2 \times 10^5$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据组数。
接下来 $T$ 行，每行包含两个整数 $L$ 和 $K$，分别表示排列的长度和需要的跃升点个数。

# 输出描述
对于每组测试数据，输出一行，包含 $L$ 个整数，表示一个满足条件的排列，整数之间用空格分隔。

## 样例1

**输入**

```
1
3 1
```

**输出**

```
1 2 3
```

**说明**

$L=3$，$K=1$。要使跃升点个数为 `1`，只需构造严格递增排列。此时唯一的候选位置 $i=3$ 满足 $p_3 = 3 \ge \max(p_1, p_2) = 2$，因此恰有一个跃升点。

## 样例2

**输入**

```
1
3 0
```

**输出**

```
1 3 2
```

**说明**

$L=3$，$K=0$。将排列构造为 `1 3 2`。此时 $p_3=2$，而 $\max(p_1, p_2)=\max(1,3)=3$，不满足 $p_3 \ge 3$，故没有跃升点。

## 样例3

**输入**

```
1
5 2
```

**输出**

```
1 2 3 5 4
```

**说明**

$L=5$，$K=2$。构造 `1 2 3 5 4`。检查所有 $i \ge 3$：$i=3$ 时 $p_3=3 \ge \max(1,2)=2$，是跃升点；$i=4$ 时 $p_4=5 \ge \max(2,3)=3$，是跃升点；$i=5$ 时 $p_5=4 < \max(3,5)=5$，不是跃升点。总计 `2` 个跃升点。

## 样例4

**输入**

```
1
6 0
```

**输出**

```
1 6 5 4 3 2
```

**说明**

$L=6$，$K=0$。排列为 `1 6 5 4 3 2`。所有 $i \ge 3$ 的位置，当前元素均小于前两个元素的最大值，因此跃升点个数为 `0`。例如 $i=3$ 时 $\max(1,6)=6$，$5<6$；$i=4$ 时 $\max(6,5)=6$，$4<6$；后续同理。
