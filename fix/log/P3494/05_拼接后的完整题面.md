# 题目内容
一块展板被划分成 $n$ 行 $m$ 列的格子，第 $i$ 行第 $j$ 列的标签值为 $A_{i,j}$。

一次操作可以选择两个**不相邻**的格子并交换它们的标签。形式化地，选定坐标 $(i_1,j_1)$ 与 $(i_2,j_2)$，满足 $|i_1-i_2|+|j_1-j_2| 
eq 1$，然后交换这两格的值。

请在所有可通过任意次操作得到的布局中，找出**矩阵字典序最大**的一种。

矩阵字典序：对两个 $n \times m$ 的矩阵 $p,q$，按行优先（先第 `1` 行到第 $n$ 行，同一行内从左到右）依次比较。在第一个不同的位置，数值更大的矩阵字典序更大；若全部相等则字典序相等。

数据范围：$2 \le n,m \le 500$；每个标签满足 $1 \le A_{i,j} \le 10^9$。

# 输入描述
第一行包含两个整数 $n$ 和 $m$（$2 \le n,m \le 500$），表示展板的行数与列数。
接下来 $n$ 行，每行 $m$ 个整数，表示矩阵 $A$ 的元素，满足 $1 \le A_{i,j} \le 10^9$。

# 输出描述
输出 $n$ 行，每行 $m$ 个整数，表示字典序最大的布局。同行相邻整数之间用单个空格分隔。

## 样例1

**输入**

```
2 3
1 2 3
4 5 6
```

**输出**

```
6 5 4
3 2 1
```

**说明**

$2 \times 3$ 的展板可以通过非相邻交换实现任意重排。将全部标签按降序填回，得到字典序最大布局。

## 样例2

**输入**

```
2 2
1 2
3 4
```

**输出**

```
4 3
2 1
```

**说明**

$2 \times 2$ 时只允许两条对角线交换。四种可达布局中，字典序最大的是将主、副对角线都交换后的
`4 3`
`2 1`。

## 样例3

**输入**

```
3 3
9 1 2
3 8 4
5 6 7
```

**输出**

```
9 8 7
6 5 4
3 2 1
```

**说明**

非 $2 \times 2$ 时可以任意重排，按降序填回即可。

## 样例4

**输入**

```
2 2
4 3
2 1
```

**输出**

```
4 3
2 1
```

**说明**

初始布局已经是四种可达状态中字典序最大的，保持不变。
