# 题目内容
一位通信工程师拥有 $n$ 种谐振晶体，第 $i$ 种晶体的谐振频率为 $f_i$。他可以选择 $k$ 种（$1 \le k \le n$）晶体组合使用，所有被选晶体频率的最大公因子（记作 $\text{gcf}(f_{b_1}, \dots, f_{b_k})$）将决定合成后的工作频率。当仅选一种晶体时，合成频率等于该晶体本身的频率。

现在工程师想知道，通过任意挑选晶体种类和数量，可达到的最低合成频率与最高合成频率分别是多少。

最大公因子指能够同时整除给定整数的全体正因数中最大的那个数。

晶体种数 $n$ 不超过 $10^5$，所有频率 $f_i$ 为整数且满足 $1 \le f_i \le 10^9$。

# 输入描述
第一行包含一个整数 $n$，表示谐振晶体的种数。
第二行包含 $n$ 个整数 $f_1, f_2, \dots, f_n$，表示每种晶体的谐振频率。

# 输出描述
输出两个整数，用空格分隔，分别表示任意组合可达到的最低合成频率和最高合成频率。

## 样例1

**输入**

```
3
3 5 7
```

**输出**

```
1 7
```

**说明**

选取全部 `3` 种晶体，频率分别为 `3`、`5`、`7`，它们的最大公因子为 $\text{gcf}(3,5,7)=1$，这是任何非空子集能够达到的最低合成频率。
最高合成频率可通过单独选取频率最高的晶体 `7` 得到，此时合成频率等于 `7`。

## 样例2

**输入**

```
4
6 9 12 15
```

**输出**

```
3 15
```

**说明**

四种晶体的频率最大公因子为 $\text{gcf}(6,9,12,15)=3$，因此最低合成频率为 `3`。
最高合成频率可直接选取频率最大的晶体 `15` 实现，结果为 `15`。

## 样例3

**输入**

```
1
123456789
```

**输出**

```
123456789 123456789
```

**说明**

只有一种晶体，无论怎样选择（必须选至少一种），合成频率都等于该晶体自身的频率。
因此最低合成频率与最高合成频率相同，均为 `123456789`。
