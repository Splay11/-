## 解题思路

从 $l$ 向右做前缀按位或，结果只会把某些二进制位从 `0` 变成 `1`，不会丢失已经出现的 `1`。因此：

- $k$ 中为 `1` 的每一位，都必须在某个前缀中出现；
- $k$ 中为 `0` 的每一位，一旦在前缀中出现，该前缀及之后都不可能等于 $k$。

先对每个二进制位做前缀和，即可 $O(1)$ 查询区间 $[l,m]$ 内某位是否出现过。再在 $[l,r]$ 上二分最小的 $m$，使得 $k$ 中所有为 `1` 的位都已出现。最后检查该前缀或是否恰好等于 $k$：每一位该出现的都出现了、不该出现的都没出现。若 $k \ge 2^{30}$ 则直接判不存在。

## 复杂度分析

预处理 $O(30n)$，每次询问二分 $O(30 \log n)$。时间复杂度 $O(30n + 30 Q \log n)$，空间复杂度 $O(30n)$。

## 代码实现

### Python

```python
n, q = map(int, input().split())
a = list(map(int, input().split()))

MAXBIT = 30
MAXV = 2**30 - 1
pre = [[0 for _ in range(MAXBIT)] for i in range(n + 1)]
for i in range(1, n + 1):
    for j in range(MAXBIT):
        pre[i][j] = pre[i - 1][j]
        if a[i - 1] >> j & 1:
            pre[i][j] += 1

for i in range(q):
    l, r, k = map(int, input().split())
    if k > MAXV:
        print(-1)
        continue
    kbit = [0] * MAXBIT
    for j in range(MAXBIT):
        kbit[j] = k >> j & 1
    left, right = l, r
    while left < right:
        mid = (left + right) >> 1
        ok = True
        for j in range(MAXBIT):
            if kbit[j] == 1 and pre[mid][j] - pre[l - 1][j] == 0:
                ok = False
                break
        if ok:
            right = mid
        else:
            left = mid + 1
    ok = True
    for j in range(MAXBIT):
        if kbit[j] == 1 and pre[right][j] - pre[l - 1][j] == 0:
            ok = False
            break
        if kbit[j] == 0 and pre[right][j] - pre[l - 1][j] > 0:
            ok = False
            break
    print(right if ok else -1)
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int q = Integer.parseInt(st.nextToken());
        int[] a = new int[n];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) a[i] = Integer.parseInt(st.nextToken());

        int MAXBIT = 30;
        long MAXV = (1L << 30) - 1;
        int[][] pre = new int[n + 1][MAXBIT];
        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < MAXBIT; j++) {
                pre[i][j] = pre[i - 1][j];
                if (((a[i - 1] >> j) & 1) == 1) pre[i][j]++;
            }
        }

        StringBuilder out = new StringBuilder();
        for (int t = 0; t < q; t++) {
            st = new StringTokenizer(br.readLine());
            int l = Integer.parseInt(st.nextToken());
            int r = Integer.parseInt(st.nextToken());
            long k = Long.parseLong(st.nextToken());
            if (k > MAXV) {
                out.append(-1).append('\n');
                continue;
            }
            int[] kbit = new int[MAXBIT];
            for (int j = 0; j < MAXBIT; j++) kbit[j] = (int) ((k >> j) & 1);
            int left = l, right = r;
            while (left < right) {
                int mid = (left + right) >> 1;
                boolean ok = true;
                for (int j = 0; j < MAXBIT; j++) {
                    if (kbit[j] == 1 && pre[mid][j] - pre[l - 1][j] == 0) {
                        ok = false;
                        break;
                    }
                }
                if (ok) right = mid;
                else left = mid + 1;
            }
            boolean ok = true;
            for (int j = 0; j < MAXBIT; j++) {
                if (kbit[j] == 1 && pre[right][j] - pre[l - 1][j] == 0) ok = false;
                if (kbit[j] == 0 && pre[right][j] - pre[l - 1][j] > 0) ok = false;
            }
            out.append(ok ? right : -1).append('\n');
        }
        System.out.print(out);
    }
}
```

```cpp
        vector<long long> kbit(MAXBIT, 0);
        for (int j = 0; j < MAXBIT; j++) kbit[j] = k >> j & 1;

            int mid = (left + right) >> 1;
            bool ok = true;
            for (int j = 0; j < MAXBIT; j++) {

        for (int j = 0; j < MAXBIT; j++) {

}
```
