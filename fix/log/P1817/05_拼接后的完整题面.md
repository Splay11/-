# 题目内容
给定长度为 $n$ 的序列 $A$。有 $Q$ 次询问，每次给出三个整数 $l,r,k$，需要判断闭区间 $[l,r]$ 中是否存在下标 $i$，使得

$$A_l \mid A_{l+1} \mid \cdots \mid A_i = k$$

其中 $\mid$ 表示按位或。若存在，输出满足条件的最小 $i$；否则输出 `-1`。下标从 `1` 开始。

约束条件：
- 序列长度与询问次数满足 $1 \le n, Q \le 10^6$；
- 询问区间满足 $1 \le l \le r \le n$；
- 序列元素与目标值满足 $0 \le A_i, k < 2^{30}$。

# 输入描述
第一行包含两个正整数 $n$ 和 $Q$（$1 \le n, Q \le 10^6$），分别表示序列长度和询问次数。
第二行包含 $n$ 个整数 $A_1, A_2, \ldots, A_n$（$0 \le A_i < 2^{30}$）。
接下来 $Q$ 行，每行三个整数 $l, r, k$（$1 \le l \le r \le n$，$0 \le k < 2^{30}$），表示一次询问。

# 输出描述
对每次询问输出一行一个整数：满足条件的最小下标 $i$，若不存在则输出 `-1`。

## 样例1

**输入**

```
5 5
3 2 3 3 6
1 2 3
1 5 7
1 4 7
2 2 2
2 3 7
```

**输出**

```
1
5
-1
2
-1
```

**说明**

序列为 $3,2,3,3,6$。

询问 $[1,2]$、$k=3$：位置 `1` 上 $3=3$，答案 `1`。

询问 $[1,5]$、$k=7$：前缀或在位置 `5` 首次变为 $3\mid 2\mid 3\mid 3\mid 6=7$，答案 `5`。

询问 $[1,4]$、$k=7$：前缀或最大为 `3`，得不到 `7`，输出 `-1`。

询问 $[2,2]$、$k=2$：单点 $2=2$，答案 `2`。

询问 $[2,3]$、$k=7$：区间或为 $2\mid 3=3$，输出 `-1`。

## 样例2

**输入**

```
1 1
0
1 1 0
```

**输出**

```
1
```

**说明**

只有一个数 `0`，区间 $[1,1]$ 的前缀或为 `0`，等于 $k=0$，答案为 `1`。
