# 题目内容
有 $n$ 座信标，编号为 $1$ 到 $n$。每座信标恰好指向一座信标：第 $i$ 座指向第 $a_i$ 座（可以指向自己）。

从 `1` 号信标出发，沿着指向关系前进。出发时已位于 `1` 号。设当前已走步数为 $i$，初始 $i=`0`$。只要 $i \le k$，并且当前信标的后继尚未出现在已经过的路径中，就走到该后继，并将 $i$ 加 `1`。若后继已经出现过，则停止。

请给出路径中出现过的所有信标编号。

信标座数不超过 `10^5`，步数上限 $k$ 不超过 `10^{18}`，每座信标的指向目标满足 $1 \le a_i \le n$。

# 输入描述
第一行包含两个整数 $n$ 和 $k$，分别表示信标座数与步数上限，满足 $1 \le n \le 10^5$，$1 \le k \le 10^{18}$。
第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$，其中 $a_i$ 表示第 $i$ 座信标指向的目标编号，满足 $1 \le a_i \le n$。

# 输出描述
在一行中按从小到大的顺序输出路径中出现过的所有信标编号，相邻编号之间用空格分隔。

## 样例1

**输入**

```
4 100
2 3 4 1
```

**输出**

```
1 2 3 4
```

**说明**

指向关系为 $1 \to 2 \to 3 \to 4 \to 1$。从 `1` 号出发，$k=`100`$ 足够走完整圈，遇到重复信标后停止，路径包含全部 `4` 座信标。升序输出为 `1 2 3 4`。

## 样例2

**输入**

```
3 50
1 1 1
```

**输出**

```
1
```

**说明**

`1` 号指向自己。出发时已在 `1` 号，后继已经出现过，立即停止。路径中只有 `1`。

## 样例3

**输入**

```
6 1000000000000000000
3 1 4 5 6 2
```

**输出**

```
1 2 3 4 5 6
```

**说明**

指向为 $1 \to 3 \to 4 \to 5 \to 6 \to 2 \to 1$。$k$ 很大，会沿环走完整条简单路径后因重复而停止，六个编号均出现。升序输出为 `1 2 3 4 5 6`。

## 样例4

**输入**

```
5 100
5 4 5 2 3
```

**输出**

```
1 3 5
```

**说明**

从 `1` 出发：$1 \to 5 \to 3$，而 `3` 的后继是 `5`，已经经过，停止。路径编号为 `1,3,5`。
