## 解题思路

每座信标恰好一条出边，整个结构是内向基环树的并（功能图）。从 `1` 号出发的轨迹是一条简单路径，末端可能进入一个环。

按题意模拟即可：

1. 路径初始只含 `1`，已走步数 $i=`0`$；
2. 当 $i \le k$ 且当前信标的后继尚未出现在路径中时，把后继加入路径，并将 $i$ 加 `1`；
3. 后继已经出现过则停止（避免在环上无限走下去）。

由于每个编号最多入路径一次，循环至多执行 $n$ 次，即使 $k$ 达到 $10^{18}$ 也不会超时。最后将路径中的编号升序输出。

用布尔数组标记是否已出现，查询后继是否重复是 $O(1)$ 的。

## 复杂度分析

时间复杂度 $O(n\log n)$（排序输出；遍历本身是 $O(n)$），空间复杂度 $O(n)$。

## 代码实现

### Python

```python
n, k = map(int, input().split())
to = list(map(int, input().split()))

path = [1]
seen = [False] * (n + 1)
seen[1] = True
i = 0
while i <= k:
    nxt = to[path[-1] - 1]
    if seen[nxt]:
        break
    path.append(nxt)
    seen[nxt] = True
    i += 1

path.sort()
for j in path:
    print(j, end=" ")
```

### Java

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        long k = in.nextLong();
        int[] to = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            to[i] = in.nextInt();
        }
        boolean[] seen = new boolean[n + 1];
        ArrayList<Integer> path = new ArrayList<>();
        path.add(1);
        seen[1] = true;
        long steps = 0;
        while (steps <= k) {
            int nxt = to[path.get(path.size() - 1)];
            if (seen[nxt]) break;
            path.add(nxt);
            seen[nxt] = true;
            steps++;
        }
        Collections.sort(path);
        StringBuilder sb = new StringBuilder();
        for (int id : path) {
            sb.append(id).append(' ');
        }
        System.out.print(sb.toString());
    }
}
```

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long k;
    cin >> n >> k;
    vector<int> to(n + 1);
    for (int i = 1; i <= n; i++) cin >> to[i];
    vector<char> seen(n + 1, 0);
    vector<int> path;
    path.push_back(1);
    seen[1] = 1;
    long long steps = 0;
    while (steps <= k) {
        int nxt = to[path.back()];
        if (seen[nxt]) break;
        path.push_back(nxt);
        seen[nxt] = 1;
        steps++;
    }
    sort(path.begin(), path.end());
    for (int id : path) cout << id << ' ';
    return 0;
}
```
