# 题目内容
铁路编组站有 $n$ 节待整列车厢，优先级序列为 $a$，相邻股道闸口的固定等级序列为 $b$（整场过程中 $b$ 不变）。调度规程要求必须用标准冒泡排序把 $a$ 排成非递减：

- 对于 $i = 1, 2, \dots, n-1$ 依次做一趟扫描；
- 第 $i$ 趟按 $j = 1, 2, \dots, n-i$ 检查相邻两节；
- 若 $a_j > a_{j+1}$ 则交换这两节，否则不交换。

每次实际发生交换时，代价由闸口等级决定：若 $b_j \ge b_{j+1}$，这次交换代价为 `0`；若 $b_j < b_{j+1}$，这次交换代价为 `1`。请计算按上述固定过程完成后，所有实际交换的总代价。

约束：测试组数不超过 `100000`，单组 $n$ 不超过 `200000`，所有组 $n$ 之和不超过 `500000`，$a_i$、$b_i$ 的绝对值均不超过 `1000000000`。

# 输入描述
每个测试文件包含多组数据。第一行一个整数 $T$，表示组数。
每组第一行一个整数 $n$；第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$；第三行 $n$ 个整数 $b_1, b_2, \dots, b_n$。
保证 $1 \le T \le 100000$，$1 \le n \le 200000$，$|a_i|, |b_i| \le 1000000000$，且所有组 $\sum n \le 500000$。

# 输出描述
对每组数据输出一行一个整数，表示该组冒泡过程中所有实际交换的代价之和。

## 样例1

**输入**

```
2
3
5 1 4
2 2 9
5
9 8 7 6 5
4 3 2 1 0
```

**输出**

```
1
0
```

**说明**

第一组 $a=[5,1,4]$，$b=[2,2,9]$。冒泡过程中 `1` 向左经过边，其中 $b_1=b_2$ 代价为 `0`，$b_2<b_3$ 的边被经过时计 `1`，总代价为 `1`。

第二组 $a$ 严格递减，$b$ 严格递减，所有相邻边代价为 `0`，总代价为 `0`。

## 样例2

**输入**

```
1
1
0
0
```

**输出**

```
0
```

**说明**

$n=`1`$，无需交换，代价为 `0`。

## 样例3

**输入**

```
1
4
4 3 2 1
0 1 2 3
```

**输出**

```
6
```

**说明**

$a$ 严格递减，$b$ 严格递增，每条相邻边代价均为 `1`。每个逆序都会跨过对应边，总代价为 `6`。
