# 题目内容
一位天文学家在整理来自外星信标的数据时，发现了一组脉冲信号。按照设计，该信标会以一个固定的整数间隔 $T$ 发射脉冲（即在时刻 $0, T, 2T, 3T, \dots$ 向外发送信号），但由于宇宙间的干扰，部分脉冲在传播过程中丢失了。现在，你已经记录到了 $n$ 个实际接收到的脉冲到达时刻。你的任务是推断该信标原本可能采用的最大发射间隔 $T$ 是多少。

数据范围：接收到脉冲的次数 $n$ 满足 $2 \le n \le 2 \times 10^5$，每个到达时刻 $t_i$ 均为非负整数且不超过 $10^9$。保证 $t_0 = 0$，且给出的到达时刻序列严格单调递增。

# 输入描述
第一行包含一个整数 $n$，表示记录到的脉冲个数。
第二行包含 $n$ 个整数 $t_0, t_1, \dots, t_{n-1}$，依次表示每个脉冲的到达时刻。保证 $t_0 = 0$，且序列严格单调递增，每个 $t_i$ 满足 $0 \le t_i \le 10^9$。

# 输出描述
输出一个整数，表示原信标可能的最大发射间隔 $T$。

## 样例1

**输入**

```
3
0 6 15
```

**输出**

```
3
```

**说明**

记录到的非零时刻为 `6` 和 `15`。发射间隔 $T$ 必须能整除所有记录时刻，即 $T$ 是 `6` 和 `15` 的公约数。最大可能的 $T$ 即为它们的最大公约数：$\gcd(6, 15) = 3$。
当 $T=3$ 时，发射序列为 $0, 3, 6, 9, 12, 15, \dots$，记录到的 `0, 6, 15` 均为发射时刻，中间的 `3, 9, 12` 等脉冲视为丢失，符合题意。若取更大的 $T$（如 `6`），则无法整除 `15`，因此 `3` 是最大间隔。

## 样例2

**输入**

```
4
0 2 6 9
```

**输出**

```
1
```

**说明**

记录时刻的非零部分为 `2, 6, 9`。求这些数的最大公约数：$\gcd(2, 6, 9) = 1$。因此最大发射间隔 $T=1$。
这意味着信标每隔 `1` 单位时间就发射一次脉冲，信号在传播过程中大量丢失，最终只接收到 `0, 2, 6, 9` 这四个时刻的脉冲。

## 样例3

**输入**

```
2
0 42
```

**输出**

```
42
```

**说明**

当 $n=2$ 时，仅有 `0` 和另一个到达时刻 `42`。唯一的非零时刻是 `42`，它必须能被 $T$ 整除。取 $T=42$ 时，发射时刻为 $0, 42, 84, \dots$，记录的 `0` 和 `42` 都是 $T$ 的整数倍，中间没有任何其他脉冲被记录，均视为丢失。此时 $T$ 达到最大值，即为 `42` 本身。
