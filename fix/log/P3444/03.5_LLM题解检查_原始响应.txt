## 解题思路

题目要求根据接收到的脉冲到达时刻序列，推断外星信标原本可能采用的最大发射间隔 $T$。已知信标会按照固定的整数间隔 $T$ 发射脉冲（即发送时刻为 $0, T, 2T, \dots$），由于干扰部分脉冲丢失，我们只观测到了一部分到达时刻。

设记录的到达时刻为 $t_0, t_1, \dots, t_{n-1}$，且 $t_0 = 0$。对于真正的发射间隔 $T$，任何两个实际到达时刻的间隔必须是 $T$ 的整数倍（因为所有发射时刻都是 $T$ 的倍数，到达时刻是这些时刻的子集）。因此，所有相邻到达时刻的差值：

$$
d_i = t_{i+1} - t_i \quad (i = 0, 1, \dots, n-2)
$$

必须都能被 $T$ 整除。要使 $T$ 尽可能大，$T$ 就是所有差值 $d_i$ 的最大公约数（GCD）。这是因为最大公约数是能整除所有这些差值的最大整数。

算法步骤：
1. 读入脉冲个数 $n$ 和到达时刻数组 $t$。
2. 计算相邻到达时刻的差值 $d_i$。
3. 计算所有 $d_i$ 的最大公约数。
4. 输出该最大公约数作为最大可能的发射间隔 $T$。

## 复杂度分析

- **时间复杂度**：计算相邻差值需要 $O(n)$，计算 $n-1$ 个数的最大公约数，每次辗转相除的时间为 $O(\log M)$，其中 $M$ 为最大差值（不超过 $10^9$）。因此总时间复杂度为 $O(n \log M)$。
- **空间复杂度**：只需要几个变量存储差值和当前公约数，或者存储输入数组。若存储整个数组则空间复杂度为 $O(n)$，也可以优化到 $O(1)$ 额外空间（边读边算），此处为代码清晰，使用 $O(n)$ 空间。

## 代码实现

### Python

```python
import sys
import math

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    n = int(data[0])
    t = list(map(int, data[1:1+n]))
    
    # 计算相邻到达时刻的差值
    diffs = [t[i+1] - t[i] for i in range(n-1)]
    
    # 计算所有差值的最大公约数
    ans = diffs[0]
    for d in diffs[1:]:
        ans = math.gcd(ans, d)
    
    # 输出最大发射间隔 T
    print(ans)

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine());
        String[] parts = br.readLine().split(" ");
        int[] t = new int[n];
        for (int i = 0; i < n; i++) {
            t[i] = Integer.parseInt(parts[i]);
        }
        
        // 计算初始差值和最大公约数
        int ans = t[1] - t[0];
        for (int i = 1; i < n - 1; i++) {
            int diff = t[i+1] - t[i];
            ans = gcd(ans, diff);
        }
        
        System.out.println(ans);
    }
    
    private static int gcd(int a, int b) {
        while (b != 0) {
            int tmp = b;
            b = a % b;
            a = tmp;
        }
        return a;
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <numeric>
#include <algorithm>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n;
    cin >> n;
    vector<int> t(n);
    for (int i = 0; i < n; ++i) {
        cin >> t[i];
    }
    
    // 计算相邻差值的最大公约数
    int ans = t[1] - t[0];
    for (int i = 1; i < n - 1; ++i) {
        int diff = t[i + 1] - t[i];
        ans = gcd(ans, diff);
    }
    
    // 输出最大发射间隔 T
    cout << ans << '\n';
    
    return 0;
}
```
