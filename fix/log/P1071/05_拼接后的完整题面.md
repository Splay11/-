# 题目内容
有 $T$ 组数据。每组给定一个长度为 $n$ 的序列 $a_1, a_2, \ldots, a_n$，保证其中元素互不相同，且每个 $a_i$ 满足 $1 \le a_i \le n$。
称区间 $[l, r]$ 是一个排列区间，当且仅当其中的数 $a_l, a_{l+1}, \ldots, a_r$ 恰好构成某个长度的排列：即存在正整数 $k$，使得这些数是 $1$ 到 $k$ 各出现一次。
请对每组数据求出排列区间的个数。

约束条件：
- $1 \le T \le 2$。
- 所有数据的 $n$ 之和不超过 $2 \times 10^5$。
- 对 $90\%$ 的测试点有 $T = 1$ 且 $n \le 2 \times 10^5$。

# 输入描述
第一行包含一个正整数 $T$，表示数据组数。
每组数据第一行包含一个正整数 $n$，表示序列长度。
每组数据第二行包含 $n$ 个正整数 $a_1, a_2, \ldots, a_n$。

# 输出描述
对每组数据输出一行一个整数，表示该组中排列区间的个数。

## 样例1

**输入**

```
3
3
3 1 2
5
5 3 1 4 2
7
1 2 3 4 5 6 7
```

**输出**

```
3
3
7
```

**说明**

第一组 $[3,1,2]$：长度为 `1` 且含 `1` 的区间、含 $[1,2]$ 的区间以及整个数组都是排列区间，共 `3` 个。
第二组 $[5,3,1,4,2]$ 中排列区间有 `3` 个。
第三组 $[1,2,3,4,5,6,7]$ 的前缀 $[1],[1,2],\ldots,[1..7]$ 都是排列，共 `7` 个。

## 样例2

**输入**

```
1
1
1
```

**输出**

```
1
```

**说明**

只有一个元素 `1`，区间 $[1,1]$ 是长度为 `1` 的排列，答案为 `1`。

## 样例3

**输入**

```
1
2
2 1
```

**输出**

```
2
```

**说明**

序列为 $[2,1]$。区间 $[2,2]$ 不含 `1`，不是排列；区间 $[1,1]$ 是 $[1]$；整个 $[2,1]$ 是 $[1,2]$。
排列区间共 `2` 个。
