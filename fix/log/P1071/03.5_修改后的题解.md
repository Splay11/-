## 解题思路

序列是 $1 \sim n$ 的一个排列。一个区间能构成排列，当且仅当它包含的数恰好是 $1,2,\ldots,k$（$k$ 为区间长度）。

因此只需检查：对每个 $k=1,2,\ldots,n$，数值 $1,2,\ldots,k$ 在原序列中出现的位置是否构成一段连续下标。若这些位置的最大下标与最小下标之差加一等于 $k$，则它们挤在长度为 $k$ 的区间里，该区间就是一个排列区间。

实现时把每个值与其下标组成二元组，按值升序排序，然后扫 $k$ 从 `1` 到 $n$，维护前 $k$ 个值下标的最小值与最大值并判断即可。

## 复杂度分析

每组数据时间复杂度 $O(n \log n)$（排序），空间复杂度 $O(n)$。所有数据 $n$ 之和不超过 $2 \times 10^5$。

## 代码实现

### Python

```python
t = int(input())
for _ in range(t):
    n = int(input())
    nums = list(map(int, input().split()))
    arr = [(nums[i], i) for i in range(n)]
    arr.sort()
    minn = 10 ** 9
    maxn = -1
    ans = 0
    for i in range(n):
        minn = min(arr[i][1], minn)
        maxn = max(arr[i][1], maxn)
        if maxn - minn <= i:
            ans += 1
    print(ans)
```

### Java

```java
import java.util.Arrays;
import java.util.Comparator;
import java.util.Scanner;

public class Main {
    static class TwoTuple {
        int a, b;
        public TwoTuple(int a, int b) {
            this.a = a;
            this.b = b;
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int t = in.nextInt();
        while (t-- > 0) {
            int n = in.nextInt();
            TwoTuple[] arr = new TwoTuple[n];
            for (int i = 0; i < n; i++) {
                int num = in.nextInt();
                arr[i] = new TwoTuple(num, i);
            }
            Arrays.sort(arr, new Comparator<TwoTuple>() {
                @Override
                public int compare(TwoTuple o1, TwoTuple o2) {
                    return o1.a - o2.a;
                }
            });
            int maxn = -1, minn = (int) 1e9;
            int ans = 0;
            for (int i = 0; i < n; i++) {
                minn = Math.min(arr[i].b, minn);
                maxn = Math.max(arr[i].b, maxn);
                if (maxn - minn <= i) {
                    ans++;
                }
            }
            System.out.println(ans);
        }
    }
}
```

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <utility>
using namespace std;

const int MAXN = 200005;
typedef pair<int, int> pii;
pii arr[MAXN];

int main() {
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        for (int i = 1; i <= n; i++) {
            int num;
            cin >> num;
            arr[i] = {num, i};
        }
        sort(arr + 1, arr + n + 1);
        int minn = (int)1e9;
        int maxn = -1;
        int ans = 0;
        for (int i = 1; i <= n; i++) {
            maxn = max(maxn, arr[i].second);
            minn = min(minn, arr[i].second);
            if (maxn - minn + 1 <= i) ans++;
        }
        cout << ans << endl;
    }
    return 0;
}
```
