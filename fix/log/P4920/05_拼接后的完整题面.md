# 题目内容
两家连锁门店的会员账户分别记有 $x$ 点和 $y$ 点积分。总部下发的调剂规则是：任一门店只要账户里至少还剩 `1` 点，就可以核销自己的 `1` 点，同时给另一家门店到账 `2` 点。该操作可由任一方发起，次数不限。运营人员需要判断，能否经过若干次调剂，使两家门店积分完全相等。

约束：测试组数不超过 `100000`，每组的 $x$、$y$ 均不超过 `1000000000`。

# 输入描述
每个测试文件包含多组数据。第一行一个整数 $T$，表示组数。
接下来 $T$ 行，每行两个整数 $x$ 和 $y$，表示两家门店的初始积分。
保证 $1 \le T \le 100000$，$0 \le x, y \le 1000000000$。

# 输出描述
对每组数据输出一行：若可以使两家积分相等，输出 `YES`；否则输出 `NO`。

## 样例1

**输入**

```
5
0 0
1 2
9 3
4 10
1000000000 1
```

**输出**

```
YES
NO
YES
YES
YES
```

**说明**

差值对 `3` 取模为 `0` 则可对等。

$(0-0)\bmod 3=`0`$，输出 `YES`。

$(1-2)\bmod 3 
e `0`$，输出 `NO`。

$(9-3)\bmod 3=`0`$，输出 `YES`。

$(4-10)\bmod 3=`0`$，输出 `YES`。

$10^9 \equiv 1\pmod{3}$，故 $(10^9-1)\bmod 3=`0`$，输出 `YES`。

## 样例2

**输入**

```
2
3 0
2 2
```

**输出**

```
YES
YES
```

**说明**

$(3-0) \bmod 3 = `0`$，可以操作至相等，输出 `YES`。

双方已经相等，输出 `YES`。
