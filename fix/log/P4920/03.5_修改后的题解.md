## 解题思路

一次调剂后，两家门店积分差变化 $3$。设当前差值为 $x-y$：

- 甲方核销 `1` 点、乙方到账 `2` 点后，差值变为 $(x-1)-(y+2)=x-y-3$；
- 乙方核销、甲方到账后，差值变为 $x-y+3$。

因此差值对 `3` 取模是不变量。最终相等当且仅当差值为 `0`，故初始必须满足

$$
(x-y) \bmod 3 = 0.
$$

满足该条件时，始终让积分较多的一方发起调剂，差值每次减少 `3`，最终一定能持平。

## 复杂度分析

每组 $O(1)$ 判断。时间复杂度 $O(T)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
import sys

def can_equal(x, y):
    # 差值对 3 取模不变，最终相等时差值必须为 0
    return (x - y) % 3 == 0

def main():
    data = sys.stdin.read().split()
    t = int(data[0])
    ans = []
    idx = 1

    for _ in range(t):
        x = int(data[idx])
        y = int(data[idx + 1])
        idx += 2

        if can_equal(x, y):
            ans.append("YES")
        else:
            ans.append("NO")

    print("\n".join(ans))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {

    static boolean canEqual(long x, long y) {
        return (x - y) % 3 == 0;
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int t = Integer.parseInt(br.readLine().trim());

        for (int i = 0; i < t; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());

            long x = Long.parseLong(st.nextToken());
            long y = Long.parseLong(st.nextToken());

            if (canEqual(x, y)) {
                sb.append("YES\n");
            } else {
                sb.append("NO\n");
            }
        }

        System.out.print(sb.toString());
    }
}
```

### C++

```cpp
#include <iostream>
using namespace std;

bool canEqual(long long x, long long y) {
    return (x - y) % 3 == 0;
}

int main() {
    int T;
    cin >> T;

    while (T--) {
        long long x, y;
        cin >> x >> y;

        if (canEqual(x, y)) {
            cout << "YES\n";
        } else {
            cout << "NO\n";
        }
    }

    return 0;
}
```
