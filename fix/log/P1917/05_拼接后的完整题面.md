# 题目内容
研究者发现了一段古老的镜像咒文，其定义如下：一个长度为偶数的字符串被称为镜像咒文，当且仅当其前半部分与后半部分完全相同。

现在，你获得了一个残缺的咒文（一个长度为偶数的字符串），每一次操作你可以选择任意一个位置，将其字符修改为任意一个小写字母。

请你计算最少需要多少次操作，才能将该字符串变成一个镜像咒文。

字符串的长度 $n$ 满足 $2 \le n \le 10^5$ 且 $n$ 为偶数，字符串仅由小写英文字母组成。

# 输入描述
输入包含一行一个字符串 $s$，表示初始的残缺咒文。

# 输出描述
输出一个整数，表示最少需要进行的修改次数。

## 样例1

**输入**

```
aa
```

**输出**

```
0
```

**说明**

字符串长度为 `2`，前半部分为第 `0` 个字符 `a`，后半部分为第 `1` 个字符 `a`，两者相同。因此不需要修改，答案为 `0`。

## 样例2

**输入**

```
ab
```

**输出**

```
1
```

**说明**

字符串长度为 `2`，前半部分为 `a`，后半部分为 `b`，两者不同。只需要将其中一个字符修改为另一个（例如将 `a` 改为 `b`），即可使前后相同。因此最少操作次数为 `1`。

## 样例3

**输入**

```
helloheelo
```

**输出**

```
2
```

**说明**

字符串长度为 `10`，前半部分为 `"hello"`，后半部分为 `"heelo"`。
比较第 $i$ 个字符与第 $i+5$ 个字符：
- $i=0$：`h` 与 `h`，相同；
- $i=1$：`e` 与 `e`，相同；
- $i=2$：`l` 与 `e`，不同；
- $i=3$：`l` 与 `e`，不同；
- $i=4$：`o` 与 `o`，相同。
共有 `2` 处不同，答案为 `2`。

## 样例4

**输入**

```
abcdabcx
```

**输出**

```
1
```

**说明**

字符串长度为 `8`，前半部分为 `"abcd"`，后半部分为 `"abcx"`，一半长度为 $\frac{n}{2}=4$。
比较对应位置：
- 第 `0` 位：`a` 与 `a`，相同；
- 第 `1` 位：`b` 与 `b`，相同；
- 第 `2` 位：`c` 与 `c`，相同；
- 第 `3` 位：`d` 与 `x`，不同。
仅有 `1` 处不同，因此最少需要修改 `1` 次。
