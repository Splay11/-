## 解题思路

设 $S_p = \sum p_i$，$S_q = \sum q_i$。把某个 $p_i$ 加倍后，新的 $p$ 序列总和为 $S_p + p_i$。要与 $q$ 平衡，当且仅当

$$S_p + p_i = S_q \iff p_i = S_q - S_p$$

因此只需统计有多少个 $p_i$ 恰好等于 $S_q - S_p$。注意总和可能超出 32 位整数范围，需使用 64 位整数。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(n)$。

## 代码实现

### Python

```python
import sys
input = lambda: sys.stdin.readline().strip()
n = int(input())
p = list(map(int, input().split()))
sq = sum(list(map(int, input().split())))
sp = sum(p)
res = sum(1 if sp + val == sq else 0 for val in p)
print(res)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long[] p = new long[n];
        long sp = 0;
        for (int i = 0; i < n; i++) {
            p[i] = sc.nextLong();
            sp += p[i];
        }
        long sq = 0;
        for (int i = 0; i < n; i++) {
            sq += sc.nextLong();
        }
        int res = 0;
        for (int i = 0; i < n; i++) {
            if (sp + p[i] == sq) res++;
        }
        System.out.println(res);
    }
}
```
