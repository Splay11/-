# 题目描述

塔子哥定义两个数组是相似的，当且仅当两个数组的总和相等。

塔子哥有两个长度为$n$的数组$a$和$b$，塔子哥想知道有多少个$i(1≤i≤n)$满足将$a_i$翻倍一次后，$a$数组和$b$数组是相似的。

# 输入描述

第一行输入一个整数 $n(1<n≤10^5)$表示数组长度

第二行输入$n$个整數表示数组$a(-10^9≤ a_i≤ 10^9)$

第三行输入$n$个整数表示数组$b(-10^9≤ b_i< 10^9)$

# 输出描述

输出反转后的字符串(包含"")

# 样例

**输入**

```
3
1 1 1
1 2 1
```

**输出**

```
3
```
