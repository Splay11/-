# 题目内容
有两条长度均为 $n$ 的产量序列 $p$ 和 $q$。定义两条序列**平衡**，当且仅当它们的元素总和相等。

你必须恰好选择一个下标 $i$（$1 \le i \le n$），把 $p_i$ 变为 $2p_i$（只加倍一次），然后判断此时 $p$ 与 $q$ 是否平衡。

请统计有多少个下标 $i$ 在单独加倍后能使两条序列平衡。

约束条件：
- 序列长度 $n$ 满足 $2 \le n \le 10^5$；
- 序列中每个数的绝对值不超过 $10^9$。

# 输入描述
第一行包含一个整数 $n$（$2 \le n \le 10^5$），表示序列长度。
第二行包含 $n$ 个整数 $p_1, p_2, \ldots, p_n$（绝对值不超过 $10^9$）。
第三行包含 $n$ 个整数 $q_1, q_2, \ldots, q_n$（绝对值不超过 $10^9$）。

# 输出描述
输出一个整数，表示能使两条序列平衡的下标个数。

## 样例1

**输入**

```
3
1 1 1
1 2 1
```

**输出**

```
3
```

**说明**

$S_p=3$，$S_q=4$。加倍 $p_i$ 后总和变为 $3+p_i$，需要等于 `4`，即 $p_i=1$。三个位置都是 `1`，因此答案为 `3`。

## 样例2

**输入**

```
2
5 3
10 3
```

**输出**

```
1
```

**说明**

$S_p=8$，$S_q=13$，需要 $p_i=5$。只有第一个位置满足，答案为 `1`。

## 样例3

**输入**

```
2
1 2
3 4
```

**输出**

```
0
```

**说明**

$S_p=3$，$S_q=7$，需要 $p_i=4$，序列中不存在该值，答案为 `0`。
