## 解题思路

题目中的空间站和航道构成一棵树。可以修建的新航道等价于：对于任意一个空间站 $w$，若存在两条原始航道 $(u,w)$ 和 $(w,v)$，则可以在 $u$ 和 $v$ 之间修建新航道。也就是说，**所有距离恰好为 2 的空间站对均可以修建直达航道**。管理部门可以自由选择部分或全部这样的候选航道进行修建，目标是使 $\sum_{i=1}^n \sum_{j=1}^n d(i,j)$ 最小。

我们把所有可能的新航道按照形态分为两类：
- **横向新航道**：连接某个空间站的两个不同子节点，即“兄弟节点”之间的航道。
- **纵向新航道**：连接一个空间站与其父节点的父节点，即“祖孙节点”之间的航道（中间经过一个空间站 $w$）。

任何一条新航道被修建后，原本需要走 2 步的最短路径变为 1 步，使得通过该路径的有序对距离之和减少 1。问题转化为：在原始树的总距离和上，尽量多地减去新航道能够“节省”的距离。

### 算法步骤

1. **计算原始总距离和**  
   对原始树做一次 DFS，计算每个子树大小 `sum[u]`。树中每条边被经过的次数为 $2 \times sum[v] \times (n - sum[v])$（$v$ 是较深的端点，有序对需要考虑双向）。将所有边贡献累加得到无新航道时的总距离和 `ans`。

2. **定义“跳跃节点”与动态统计**  
   引入数组 `tiao[u]`，表示在当前考虑的状态下，以 $u$ 为根的子树内有多少个节点可以通过纵向新航道“瞬间向上跳两级”到达 $u$ 的父节点的父节点。初始时每个节点自身可以视作一个跳跃单元，故 `tiao[u] = 1`，并在从下到上的过程中不断将子树的 `tiao` 累加到父节点，模拟“向上跳跃”的节点汇聚。

3. **计算新航道的贡献（减少的距离）**  
   第二次 DFS 自底向上计算两类新航道的节省量：

   - **横向新航道**：对于空间站 $u$，考虑它的所有子节点 $c_1, c_2, \dots$。在这些子节点之间修建横向新航道，能够使一个子树的跳跃节点集合与另一个子树的跳跃节点集合中的任意一对节点距离减少 1。因此，$u$ 处横向新航道的总节省量为  
     $\sum_c tiao[c] \times \big( tt[u] - tiao[c] \big)$，其中 $tt[u] = \sum_{c} tiao[c]$ 是 $u$ 的直接子节点跳跃节点数之和。每条航道仅被计数一次。

   - **纵向新航道**：对于非根节点 $u$，考虑从它的子节点 $v$ 向上通过 $u$ 连接到 $u$ 的父节点 $fa$ 的纵向新航道（即 $v$ 与 $fa$ 直连）。这样一条新航道能够让 $v$ 子树内的所有跳跃节点直接绕过 $u$ 到达 $fa$，从而这些节点到**子树外**的所有空间站的距离减少 1。有序对双向合计节省量为  
     $\sum_v tiao[v] \times (n - sum[u]) \times 2$。

   在计算纵向新航道贡献的同时，将子节点 $v$ 的 `tiao` 累加到父节点 $u$ 上，表示这些节点“已经跳跃”到了 $u$（或更高层），后续在更上层统计横向航道时将以 $u$ 为单位参与计算，这恰好对应了“可以不断选用纵向航道向上跳跃”的动态效果。

4. **答案计算**  
   最终答案为原始总距离和 `ans` 减去上述所有横向与纵向新航道的节省量之和。

### 示例验证
对于任意输入树，算法通过两次 DFS 即可完成统计，正确性基于：任意新航道的实际作用等价于将部分节点向上“压缩”，而压缩过程不影响其他航道的计数，每条航道的节省量都可以独立累加。

## 复杂度分析

- 时间复杂度：$O(n)$。仅进行两次深度优先搜索，每条边被访问常数次。
- 空间复杂度：$O(n)$。需要存储邻接表、子树大小、跳跃节点数等辅助数组，均与 $n$ 线性相关。

## 代码实现

### Python

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    n = int(sys.stdin.readline())
    adj = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, sys.stdin.readline().split())
        adj[u].append(v)
        adj[v].append(u)

    dp = [0] * (n + 1)      # dp[u] 表示 u 子树内原始距离和（贡献形式）
    size = [0] * (n + 1)    # 子树大小
    tiao = [0] * (n + 1)    # 跳跃节点数
    tt = [0] * (n + 1)      # 直接子节点的跳跃节点数之和

    def dfs1(u, fa):
        size[u] = 1
        tiao[u] = 1
        for v in adj[u]:
            if v == fa:
                continue
            dfs1(v, u)
            size[u] += size[v]
            dp[u] += dp[v] + (n - size[v]) * size[v] * 2
            if u != 1:
                tiao[fa] += tiao[v]   # 将子节点跳跃信息向上传递
            tt[u] += tiao[v]

    def dfs2(u, fa):
        nonlocal ans
        for v in adj[u]:
            if v == fa:
                continue
            dfs2(v, u)
            # 横向新航道贡献
            ans -= tiao[v] * (tt[u] - tiao[v])
            if u != 1:
                # 纵向新航道贡献（双向乘2）
                ans -= tiao[v] * (n - size[u]) * 2

    dfs1(1, 0)
    ans = dp[1]
    dfs2(1, 0)
    print(ans)

if __name__ == "__main__":
    solve()
```

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const int N = 200010;
int n;
vector<int> adj[N];
ll dp[N], sz[N], tiao[N], tt[N];
ll ans;

void dfs1(int u, int fa) {
    sz[u] = 1;
    tiao[u] = 1;
    for (int v : adj[u]) {
        if (v == fa) continue;
        dfs1(v, u);
        sz[u] += sz[v];
        dp[u] += dp[v] + (n - sz[v]) * sz[v] * 2;
        if (u != 1) {
            tiao[fa] += tiao[v];   // 向上传递跳跃信息
        }
        tt[u] += tiao[v];
    }
}

void dfs2(int u, int fa) {
    for (int v : adj[u]) {
        if (v == fa) continue;
        dfs2(v, u);
        // 横向新航道
        ans -= tiao[v] * (tt[u] - tiao[v]);
        if (u != 1) {
            // 纵向新航道
            ans -= tiao[v] * (n - sz[u]) * 2;
        }
    }
}

int main() {
    ios::sync_with_stdio(false);

}
