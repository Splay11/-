# 题目内容
在宇宙中有 $n$ 个空间站，初始时空间站之间通过 $n-1$ 条双向航道连接，保证任意两个空间站可达，且不存在环。航道管理部门发现，若存在一个空间站 $w$，使得在初始航道中存在 $(u,w)$ 和 $(w,v)$，那么可以额外在 $u$ 与 $v$ 之间修建一条新航道。管理部门可以在这些候选新航道中任意选择若干条进行修建。

定义 $d(i,j)$ 为修建后网络中空间站 $i$ 到 $j$ 的最短路径长度（即经过的最少航道数）。管理部门希望最小化所有有序空间站对距离之和，即 $\sum_{i=1}^{n}\sum_{j=1}^{n} d(i,j)$。请你计算这个最小值。

约束：空间站数量 $n$ 满足 $2 \le n \le 2 \times 10^5$。初始航道信息为 $n-1$ 行，每行两个整数表示一条航道的两端点，编号均为 $1$ 到 $n$ 之间，保证输入是一棵树。

# 输入描述
第一行输入一个整数 $n$，表示空间站的数量。
接下来 $n-1$ 行，每行包含两个整数 $u$ 和 $v$，表示初始存在连接 $u$ 与 $v$ 的航道。

# 输出描述
输出一个整数，表示所有有序空间站对之间最短距离之和的最小可能值。

## 样例1

**输入**

```
2
1 2
```

**输出**

```
2
```

**说明**

空间站只有 `2` 个，初始航道只有一条 $(1,2)$。不存在任何候选新航道。此时空间中只有一对不同站点，距离 $d(1,2)=d(2,1)=1$，自身距离均为 $0$。因此有序对距离总和为 $1+1=2$。

## 样例2

**输入**

```
3
1 2
2 3
```

**输出**

```
6
```

**说明**

初始树呈链状 $1$—$2$—$3$。节点 $2$ 同时与 $1$、$3$ 相邻，因此可以修建新航道 $(1,3)$。将这条新航道加入后，三个站点两两直接相连，任意两点间最短距离均为 $1$。无序点对共有 $\binom{3}{2}=3$ 对，每对贡献两个有序对距离 $1$，故总和为 $3 \times 2 = 6$。若不加边，距离和为 $8$，加边后达到最小值 $6$。

## 样例3

**输入**

```
4
1 2
2 3
3 4
```

**输出**

```
14
```

**说明**

树为链 $1$—$2$—$3$—$4$。候选新边为：以 $2$ 为中转的 $(1,3)$，以及以 $3$ 为中转的 $(2,4)$。将这两条边全部修建后，任意两点间的最短距离变为 $d(i,j) = \lceil d_0(i,j)/2 \rceil$，其中 $d_0$ 是原树距离。具体地：相邻点（原边）距离为 $1$；距离为 $2$ 的点对 $(1,3)$、$(2,4)$ 变为 $1$；距离为 $3$ 的点对 $(1,4)$ 变为 $2$。将所有有序对的距离相加，得 $14$。

## 样例4

**输入**

```
5
1 2
1 3
1 4
1 5
```

**输出**

```
20
```

**说明**

该树为星型，中心节点 $1$ 连接四个叶子 $2,3,4,5$。对于中心节点 $1$，其任意两个叶子之间均满足“存在 $1$ 且 $(u,1)$ 与 $(1,v)$ 都在树中”的条件，因此所有叶子两两之间的新航道均可修建。全部修建后，叶子之间距离变为 $1$，中心到叶子距离为 $1$，等价于这 $5$ 个点构成的图中除自身外所有点对距离均为 $1$。总点对数为 $5 \times 4 = 20$，每对距离 $1$，自身 $5$ 对距离 $0$，总和为 $20$。若不修建新航道，叶子间距离为 $2$，总和将更大，故 $20$ 为最小值。
