# 题目内容
在一门新兴编程语言中，标识符的命名需要满足以下全部「优雅」条件，才被视为合规：
- 以大写字母开头（首字符为大写英文字母）；
- 以小写字母结尾（末字符为小写英文字母）；
- 对于任意一个字母，其大写形式与小写形式不能同时出现在同一个标识符中（可以只出现其中一种，或两种都不出现）。
现在给你 `n` 个仅由大小写英文字母构成的字符串作为候选标识符，请你计算其中有多少个是优雅标识符。

约束：标识符总数 `n` 满足 $1 \le n \le 10^4$，每个标识符的长度 $l_i$ 满足 $1 \le l_i \le 2 \times 10^5$，且所有标识符的长度之和 $\sum_{i=1}^n l_i \le 2 \times 10^5$。

# 输入描述
第一行包含一个整数 `n`，表示标识符的个数。接下来 `n` 组数据，每组包含两行：第一行是一个整数 `l_i`，表示第 `i` 个标识符的长度；第二行是一个长度为 `l_i` 的字符串，仅由大小写英文字母组成。

# 输出描述
输出一个整数，表示这些标识符中满足优雅条件的个数。

## 样例1

**输入**

```
4
2
Aa
3
AbC
4
XyZz
5
Hello
```

**输出**

```
1
```

**说明**

逐个检查每个标识符：
- `Aa`：首字母为大写 `A`，尾字母为小写 `a`，但字母 `A` 的大小写形式同时出现，违反第 `3` 条规则，不合规；
- `AbC`：首字母为大写 `A`，但尾字母为大写 `C`，不满足"以小写字母结尾"，不合规；
- `XyZz`：首字母为大写 `X`，尾字母为小写 `z`，但字母 `Z` 的大小写 `Z` 和 `z` 同时出现，违反第 `3` 条规则，不合规；
- `Hello`：首字母为大写 `H`，尾字母为小写 `o`，出现的所有字母（`H`、`e`、`l`、`o`）均没有对应的大小写形式同时存在，因此合规。
最终合规的标识符只有 `1` 个。

## 样例2

**输入**

```
3
1
A
5
AbCdE
6
Abcdef
```

**输出**

```
1
```

**说明**

边界与典型情况的组合：
- `A`：长度为 $1$，首字母和尾字母都是大写 `A`，不满足"以小写字母结尾"，不合规；
- `AbCdE`：首字母为大写 `A`，尾字母为大写 `E`，同样不以小写字母结尾，不合规；
- `Abcdef`：首字母为大写 `A`，尾字母为小写 `f`，且字符串中出现的 `A`、`b`、`c`、`d`、`e`、`f` 没有任何一个字母的大小写同时存在，完全满足所有优雅条件，合规。
因此合规总数为 `1`。

## 样例3

**输入**

```
5
4
Data
6
Python
2
Py
6
Stream
3
AIX
```

**输出**

```
4
```

**说明**

检查 5 个候选标识符：
- `Data`：首大写 `D`，尾小写 `a`，包含字母 `D`、`a`、`t`，无大小写冲突，合规；
- `Python`：首大写 `P`，尾小写 `n`，包含字母 `P`、`y`、`t`、`h`、`o`、`n`，无冲突，合规；
- `Py`：首大写 `P`，尾小写 `y`，仅两个字母且无对应大小写共存，合规；
- `Stream`：首大写 `S`，尾小写 `m`，所有字母均无大小写冲突，合规；
- `AIX`：首大写 `A`，尾大写 `X`，不满足以小写字母结尾，不合规。
前 `4` 个全部合规，因此输出 `4`。
