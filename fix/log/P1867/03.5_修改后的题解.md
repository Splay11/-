## 解题思路

工位之间虽然连成一棵树，但一次操作可以交换任意两个工位上的工牌，因此走廊结构并不影响答案。问题等价于：给定 $1$ 到 $n$ 的一个排列 $a$，通过交换把 $a$ 变成恒等排列，求最少交换次数。

将一个元素直接换到它应该在的位置上：若位置 $i$ 上的工牌编号为 $t$ 且 $t\neq i$，则把位置 $i$ 与位置 $t$ 上的工牌交换，这样编号 $t$ 就回到了工位 $t$。从 $n$ 到 $1$ 依次处理，每个位置不断执行上述交换，直到该位置已经放对。

每次交换都会让至少一个工牌回到正确工位，总次数等于 $n$ 减去排列中的环个数。

## 复杂度分析

每个工牌最多被放到正确位置一次，总交换次数不超过 $n$。

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
n = int(input())
a = [0] + [int(x) for x in input().split()]

for _ in range(1, n):
    input()

index_map = {a[i]: i for i in range(1, n + 1)}
res = 0

for i in range(n, 0, -1):
    while a[i] != i:
        res += 1
        temp = a[i]
        a[i] = a[temp]
        a[temp] = temp
        index_map[a[temp]] = temp
        index_map[a[i]] = i

print(res)
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int[] a = new int[n + 1];
        Map<Integer, Integer> indexMap = new HashMap<>();

        for (int i = 1; i <= n; i++) {
            a[i] = scanner.nextInt();
            indexMap.put(a[i], i);
        }

        for (int i = 1; i < n; i++) {
            scanner.nextInt();
            scanner.nextInt();
        }

        int res = 0;
        for (int i = n; i > 0; i--) {
            while (a[i] != i) {
                res++;
                int temp = a[i];
                a[i] = a[temp];
                a[temp] = temp;
                indexMap.put(a[temp], temp);
                indexMap.put(a[i], i);
            }
        }

        System.out.println(res);
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <unordered_map>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n + 1);
    unordered_map<int, int> index_map;

    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
        index_map[a[i]] = i;
    }

    for (int i = 1; i < n; ++i) {
        int u, v;
        cin >> u >> v;
    }

    int res = 0;
    for (int i = n; i > 0; --i) {
        while (a[i] != i) {
            res++;
            int temp = a[i];
            a[i] = a[temp];
            a[temp] = temp;
            index_map[a[temp]] = temp;
            index_map[a[i]] = i;
        }
    }

    cout << res << endl;
    return 0;
}
```
