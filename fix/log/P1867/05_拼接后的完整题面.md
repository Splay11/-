# 题目内容
实验室有 $n$ 个工位，编号为 $1$ 到 $n$。工位之间用 $n-1$ 条走廊相连，整体构成一棵树。每个工位上放着一张工牌，第 $i$ 个工位上的工牌编号为 $a_i$。这 $n$ 张工牌恰好构成 $1$ 到 $n$ 的一个排列。

一次操作可以任选两个工位，交换它们上面的工牌。目标是让第 $i$ 个工位上的工牌编号恰好等于 $i$。保证一定有解。

请计算最少需要多少次交换。

工位个数满足 $2 \le n \le 1000$，工牌编号与走廊两端点均在 $1$ 到 $n$ 之间。

# 输入描述
第一行一个正整数 $n$，表示工位个数。
第二行 $n$ 个正整数 $a_1, a_2, \ldots, a_n$，表示各工位上当前的工牌编号，保证这 $n$ 个数互不相同。
接下来 $n-1$ 行，每行两个正整数 $u$ 和 $v$，表示工位 $u$ 与工位 $v$ 之间有一条走廊。
保证 $2 \le n \le 1000$，$1 \le u, v, a_i \le n$。

# 输出描述
输出一个整数，表示最少交换次数。

## 样例1

**输入**

```
2
1 2
1 2
```

**输出**

```
0
```

**说明**

两个工位上的工牌已经分别是 `1` 和 `2`，无需交换，答案为 `0`。这是已经归位的边界情形。

## 样例2

**输入**

```
3
3 2 1
1 2
2 3
```

**输出**

```
1
```

**说明**

排列为 $3,2,1$。将工位 `3` 上的 `1` 与工位 `1` 交换后得到 $1,2,3$，只需 `1` 次交换。

## 样例3

**输入**

```
2
1 2
2 3
```

**输出**

```
0
```

**说明**

按题意模拟计算得到。
