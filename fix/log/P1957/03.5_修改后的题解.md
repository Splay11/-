## 解题思路

目标是将 $n$ 个相同的正方形拼图块全部摆放在无限大的方格网格中，每个拼图块恰好占据一个格子，且互不重叠。摆放完成后，相邻拼图块之间的每条共享边会产生一个完整的星形图案。我们需要最大化这些共享边的数量，即星形图案的总数。

1. **基本思路**  
   尽量将拼图块排列成接近矩形的形状，这样可以最大化内部相邻边的数量。如果拼图块不能恰好排成一个完整矩形，多出的块可以放在矩形的一侧（例如作为新的一列，只放多出的那几行），这样也能增加额外的共享边。

2. **枚举摆放的行数**  
   设我们决定将拼图块摆成 $i$ 行（$1 \le i \le n$），那么尽可能让每一行的块数相等。令 $j = \lfloor n / i \rfloor$ 表示除最后可能多出的列之外，每行有 $j$ 个拼图块。此时可以填满一个 $i \times j$ 的矩形，剩余 $r = n \bmod i$ 个拼图块（$0 \le r < i$）。

3. **计算共享边数量（星星数）**  
   - 矩形部分内部的共享边：  
     水平方向（同一行相邻块之间）：每行有 $j-1$ 条边，$i$ 行共 $i \times (j-1)$ 条。  
     垂直方向（同一列相邻行之间）：每列有 $i-1$ 条边，$j$ 列共 $(i-1) \times j$ 条。  
     所以矩形内部产生的星星数为 $(i-1) \times j + i \times (j-1)$。
   - 多出块的处理：  
     若 $r > 0$，可以将这 $r$ 个块作为新的一列，放在前 $r$ 行的末尾。它们与左侧矩形之间的垂直共享边有 $r$ 条；这 $r$ 个块从上到下排成一列，它们之间的水平共享边有 $r-1$ 条（相邻两个之间）。因此额外产生的星星数为 $r + (r-1) = 2r - 1$。  
     若 $r = 0$，则没有额外贡献，星星数为 0。

   总星星数 = $(i-1) \times j + i \times (j-1) + \begin{cases} 2r-1, & r > 0 \\ 0, & r = 0 \end{cases}$。

4. **遍历所有可能行数**  
   对 $i$ 从 $1$ 到 $n$ 枚举，计算对应的总星星数并取最大值。当 $i = 1$ 时，所有块排成一行，星星数为 $n-1$（仅有相邻块之间的 $n-1$ 条边）；可以将 $n-1$ 作为初始最优答案，循环从 $i = 2$ 开始即可。

   最终的最大值即为最多能获得的完整星形图案数量。

## 复杂度分析

- **时间复杂度**：$O(n)$。需要枚举行数 $i$ 从 $2$ 到 $n$，每次计算是 $O(1)$ 的，总计算量线性。
- **空间复杂度**：$O(1)$。仅使用了常数个变量。

## 代码实现

### Python

```python
n = int(input())
ans = n - 1  # 全排成一行的情况

for i in range(2, n + 1):
    j = n // i          # 每行的块数
    r = n % i           # 多出的块数
    # 矩形内部的星星数 + 多出块的额外星星数
    cur = (i - 1) * j + i * (j - 1) + (2 * r - 1 if r > 0 else 0)
    if cur > ans:
        ans = cur

print(ans)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int ans = n - 1;  // 全排成一行的情况

        for (int i = 2; i <= n; i++) {
            int j = n / i;          // 每行的块数
            int r = n % i;          // 多出的块数
            // 矩形内部的星星数 + 多出块的额外星星数
            int cur = (i - 1) * j + i * (j - 1) + (r > 0 ? 2 * r - 1 : 0);
            if (cur > ans) {
                ans = cur;
            }
        }

        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    int ans = n - 1;  // 全排成一行的情况

    for (int i = 2; i <= n; ++i) {
        int j = n / i;          // 每行的块数
        int r = n % i;          // 多出的块数
        // 矩形内部的星星数 + 多出块的额外星星数
        int cur = (i - 1) * j + i * (j - 1) + (r > 0 ? 2 * r - 1 : 0);
        ans = max(ans, cur);
    }

    cout << ans << endl;
    return 0;
}
```
