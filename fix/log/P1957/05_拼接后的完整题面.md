# 题目内容
小明有 $n$ 个相同的正方形拼图块，每个拼图块的四条边上各有一个半星形凸起。当两个拼图块在平面上边与边完全贴合放置时，它们贴合边上的两个半星形凸起会恰好拼合成一个完整的星形图案。

小明希望将这 $n$ 个拼图块全部摆放在无限大的方格网格内，每个拼图块恰好占据一个格子，且任意两个拼图块不能重叠。摆放完成后，所有相邻拼图块之间的共享边上都会产生一个完整的星形图案。靠在边缘没有邻居的边则不会产生图案。

小明可以自由决定拼图块的摆放方式，目标是最多能获得多少个完整的星形图案。请你帮他计算这个最大值。

拼图块的数量 $n$ 满足 $1 \le n \le 10^6$。

# 输入描述
输入包含一行，一个整数 $n$（$1 \le n \le 10^6$），表示拼图块的数量。

# 输出描述
输出一个整数，表示最多能产生的完整星形图案数量。

## 样例1

**输入**

```
1
```

**输出**

```
0
```

**说明**

只有 `1` 个拼图块，无法与其他拼图块形成相邻边，因此无法产生任何完整的星形图案。答案为 `0`。

## 样例2

**输入**

```
4
```

**输出**

```
4
```

**说明**

将 `4` 个拼图块摆放成 $2 \times 2$ 的矩形。内部共享边的数量为：行相邻边 $(2-1) \times 2 = 2$ 条，列相邻边 $(2-1) \times 2 = 2$ 条，共计 `4` 条。每条共享边产生一个星形图案，因此答案为 `4`。

## 样例3

**输入**

```
5
```

**输出**

```
5
```

**说明**

将 `5` 个拼图块摆放成 $2$ 行 $2$ 列的矩形后，还剩余 `1` 个拼图块。可以将其放在矩形的边上，例如放在第二列的第三行（形成 $3 \times 2$ 缺一角的形状）。
矩形部分的共享边：$(2-1) \times 2 + (2-1) \times 2 = 4$ 条。额外放置的 `1` 个块与相邻块产生 $2 \times 1 - 1 = 1$ 条共享边。总共享边数为 `5`，所以答案为 `5`。

## 样例4

**输入**

```
6
```

**输出**

```
7
```

**说明**

将 `6` 个拼图块摆放成 $2 \times 3$ 的矩形。内部共享边分为行相邻边 $(2-1) \times 3 = 3$ 条，列相邻边 $(3-1) \times 2 = 4$ 条，总计 `7` 条。也可以摆放成 $3 \times 2$ 的矩形得到相同结果。答案为 `7`。
