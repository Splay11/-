## 解题思路

设经过 $m$ 秒后所有工单额度之和为 $f(n,m)$。

拆分规则：

* 若当前额度为偶数 $a$，生成两个 $\left\lfloor \dfrac{a}{2} \right\rfloor + 1$
* 若当前额度为奇数 $a$，除上面两个外，再额外生成一个 `2`

设 $b=\left\lfloor \dfrac{n}{2} \right\rfloor + 1$，则

* $n$ 为偶数时：$f(n,m)=2\times f(b,m-1)$
* $n$ 为奇数时：$f(n,m)=2\times f(b,m-1)+f(2,m-1)$

特判：

* $f(2,m)=2^{m+1}$
* $f(1,m)=(m+1)\times 2^m$

每次递归把额度变成 $\left\lfloor n/2 \right\rfloor+1$，层数为 $O(\log n)$。先用快速幂求出 $2^m \bmod 1000000007$，递归时用模意义下 `2` 的逆元同步得到 $2^{m-1}$。奇数时额外项 $f(2,m-1)=2^m$。

## 复杂度分析

单组时间复杂度 $O(\log m+\log n)$，空间复杂度 $O(\log n)$。

## 代码实现

### Python

```python
MOD = 10**9 + 7
INV2 = (MOD + 1) // 2  # 2 在模 MOD 下的逆元


# 快速幂：计算 a^b % MOD
def qpow(a, b):
    res = 1
    a %= MOD
    while b > 0:
        if b & 1:
            res = res * a % MOD
        a = a * a % MOD
        b >>= 1
    return res


# 递归计算 f(n, m)，其中 p = 2^m % MOD
def solve(n, m, p):
    # 递归边界：不再裂变
    if m == 0:
        return n % MOD

    # 数字 1 的特判公式：f(1, m) = (m + 1) * 2^m
    if n == 1:
        return (m + 1) % MOD * p % MOD

    # 数字 2 的特判公式：f(2, m) = 2^(m + 1) = 2 * 2^m
    if n == 2:
        return 2 * p % MOD

    # 下一层的 2^(m-1)
    next_p = p * INV2 % MOD

    # 主要裂变出的数字
    b = n // 2 + 1

    # 两个相同的 b
    ans = 2 * solve(b, m - 1, next_p) % MOD

    # 如果 n 是奇数，还会额外裂变出一个 2
    if n & 1:
        ans = (ans + p) % MOD  # f(2, m-1) = 2^m = p

    return ans


def main():
    t = int(input().strip())
    for _ in range(t):
        n, m = map(int, input().split())
        p = qpow(2, m)  # 先算出 2^m
        print(solve(n, m, p))


if __name__ == "__main__":
    main()
```
