# 题目内容
有一块长为 $a$、宽为 $b$ 的矩形板材，需要把它分成面积相等的 $n$ 块。每次切割必须平行于当前矩形的某条边，并把该矩形切成两块。一共恰好切 $n-1$ 次。

切完后，定义每块矩形的形状比为较长边除以较短边。请在所有合法切法中，最小化这 $n$ 块形状比的最大值。

$a$、$b$、$n$ 均为正整数。

# 输入描述
一行三个正整数 $a$、$b$、$n$，分别表示板材的长、宽以及要分成的块数。

# 输出描述
输出一个浮点数，保留恰好 `6` 位小数，表示最小化后的最大形状比。

## 样例1

**输入**

```
2 1 1
```

**输出**

```
2.000000
```

**说明**

只需分成 `1` 块，即板材本身。较长边与较短边之比为 `2`，输出 `2.000000`。这是 $n=1$ 的边界情况。

## 样例2

**输入**

```
4 4 2
```

**输出**

```
2.000000
```

**说明**

正方形均分成两块，最优为切成两个 $2\times 4$ 的矩形，形状比为 `2`，输出 `2.000000`。

## 样例3

**输入**

```
3 2 2
```

**输出**

```
1.333333
```

**说明**

按题意模拟计算得到。
