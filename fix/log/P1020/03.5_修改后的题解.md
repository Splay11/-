## 解题思路

每次切割必须把当前矩形沿平行于边的方向切成两块，且最终 $n$ 块面积相等。因此，若当前矩形面积要分成 $n$ 份，则每次切开的两块面积比只能是 $i:(n-i)$（$1 \le i \le \lfloor n/2 \rfloor$）。

对当前长 $x$、宽 $y$、块数 $n$：

- 若 $n=1$，形状比为 $\max(x,y)/\min(x,y)$。
- 否则尝试沿长边或宽边切开，一块再分成 $i$ 份、另一块分成 $n-i$ 份，递归求两块的最大形状比，并在所有切法中取最小值。

搜索即可得到最小化后的最大形状比。

## 复杂度分析

每次将块数分成两部分并递归，状态由矩形比例与剩余块数决定。时间复杂度关于 $n$ 为指数级，空间复杂度 $O(n)$。题目中 $n$ 较小，可以直接搜索。

## 代码实现

### Python

```python
def dfs(x, y, n):
    x, y = max(x, y), min(x, y)
    if n == 1:
        return x / y
    dx, dy = x / n, y / n
    ans = 1e9
    for i in range(1, n // 2 + 1):
        ans = min(ans, max(dfs(dx * i, y, i), dfs(x - dx * i, y, n - i)))
        ans = min(ans, max(dfs(x, dy * i, i), dfs(x, y - dy * i, n - i)))
    return ans

x, y, n = map(int, input().split())
print("%.6f" % dfs(x, y, n))
```

### Java

```java
import java.util.Scanner;

class Main {
    public static double dfs(double x, double y, int n) {
        double a = Math.min(x, y);
        double b = Math.max(x, y);
        x = b;
        y = a;
        if (n == 1)
            return x / y;
        double dx = x / n, dy = y / n;
        double ans = 1e9;
        for (int i = 1; i <= n / 2; i++) {
            ans = Math.min(ans, Math.max(dfs(dx * i, y, i), dfs(x - dx * i, y, n - i)));
            ans = Math.min(ans, Math.max(dfs(x, dy * i, i), dfs(x, y - dy * i, n - i)));
        }
        return ans;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        double x = scanner.nextDouble();
        double y = scanner.nextDouble();
        int n = scanner.nextInt();
        System.out.printf("%.6f", dfs(x, y, n));
    }
}
```
