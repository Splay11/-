# 题目内容
在数据分析中，我们有时需要衡量一个数值序列在平移后与原序列的相似程度。给定一个长度为 $n$ 的实数序列 $a_0, a_1, \dots, a_{n-1}$。

首先定义该序列的均值 $\mu$ 与方差 $V$：
$$\mu = \frac{1}{n} \sum_{i=0}^{n-1} a_i$$
$$V = \frac{1}{n} \sum_{i=0}^{n-1} (a_i - \mu)^2$$

对于偏移量 $k$（$0 \le k < n$），定义未归一化的关联系数 $S_k$：
$$S_k = \sum_{i=0}^{n-k-1} (a_{i+k} - \mu)(a_i - \mu)$$

则第 $k$ 偏移的平移关联系数 $R_k$ 定义为：
$$R_k = \begin{cases}\frac{S_k}{V}, & V 
eq 0 \\ 0, & V = 0\end{cases}$$
当 $k \ge n$ 时，规定 $R_k = 0$。

请你计算并输出序列 $a$ 在 $k=0,1,\dots,n-1$ 时对应的所有 $R_k$。每个结果均保留一位小数。

序列长度 $n$ 满足 $2 \le n \le 5000$，序列中所有实数的绝对值均不超过 $10^5$。

# 输入描述
输入包含一行，其中有 $n$ 个浮点数，数与数之间以空格分隔。

# 输出描述
输出一个列表，格式与 Python 列表相同，列表中依次包含 $R_0, R_1, \dots, R_{n-1}$，每个元素均为保留一位小数的浮点数。

## 样例1

**输入**

```
3.0 3.0 3.0
```

**输出**

```
[0.0, 0.0, 0.0]
```

**说明**

所有输入数据均为 `3.0`，计算得到均值 $\mu = 3.0$，方差 $V = 0$。根据定义，当 $V = 0$ 时，所有 $R_k$ 直接取 `0.0`（$k = 0, 1, 2$），因此输出三个 `0.0`。

## 样例2

**输入**

```
2.0 5.0
```

**输出**

```
[2.0, -1.0]
```

**说明**

输入序列为 $[2.0, 5.0]$，长度 $n = 2$。均值 $\mu = (2.0 + 5.0) / 2 = 3.5$。方差 $V = \frac{1}{2}[(2.0 - 3.5)^2 + (5.0 - 3.5)^2] = 2.25$。
当 $k=0$ 时，$S_0 = (2.0 - 3.5)^2 + (5.0 - 3.5)^2 = 4.5$，$R_0 = S_0 / V = 2.0$。
当 $k=1$ 时，$S_1 = (5.0 - 3.5)(2.0 - 3.5) = -2.25$，$R_1 = -2.25 / 2.25 = -1.0$。
保留一位小数后结果为 $[2.0, -1.0]$。

## 样例3

**输入**

```
-1.0 0.0 1.0
```

**输出**

```
[3.0, 0.0, -1.5]
```

**说明**

输入序列为 $[-1.0, 0.0, 1.0]$，长度 $n = 3$。均值 $\mu = 0.0$。方差 $V = \frac{1}{3}[(-1.0)^2 + 0^2 + 1.0^2] = \frac{2}{3}$。
当 $k=0$：$S_0 = (-1.0)^2 + 0^2 + 1.0^2 = 2.0$，$R_0 = 2.0 / (2/3) = 3.0$。
当 $k=1$：$S_1 = (0.0)(-1.0) + (1.0)(0.0) = 0$，$R_1 = 0.0$。
当 $k=2$：$S_2 = (1.0)(-1.0) = -1.0$，$R_2 = -1.0 / (2/3) = -1.5$。
输出 $[3.0, 0.0, -1.5]$。
