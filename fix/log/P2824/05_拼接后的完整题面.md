# 题目内容
工坊里有一块长度为 $n$ 的铭牌，上面刻着仅由大小写英文字母组成的字符串 $s$。工匠最多可以施展 $k$ 次重铸，每次选择下列操作之一：
- 将某个大写字母改成与它对应的小写字母（例如将 $A$ 改成 $a$）；
- 将某个小写字母改成与它对应的大写字母（例如将 $k$ 改成 $K$）；
- 将某个大写字母改成任意一个大写字母；
- 将某个小写字母改成任意一个小写字母。

请给出重铸后字典序最小的铭牌内容。

字典序从左到右逐位比较 ASCII 码：满足 $A < B < \cdots < Z < a < \cdots < z$，编码更小的更靠前；若其中一个是另一个的前缀，则较短者更小。

字符串长度 $n$ 与操作次数 $k$ 均不超过 $2 \times 10^5$。

# 输入描述
第一行输入两个正整数 $n$ 和 $k$，分别表示铭牌长度以及最多可以施展的重铸次数，满足 $1 \le n, k \le 2 \times 10^5$。
第二行输入一个长度为 $n$ 的字符串 $s$，仅由大小写英文字母构成。

# 输出描述
输出一个字符串，表示重铸后可以得到的字典序最小的铭牌内容。

## 样例1

**输入**

```
3 2
Aab
```

**输出**

```
AAB
```

**说明**

铭牌为 $Aab$，最多重铸 $2$ 次。
- 首位 $A$ 已是最优，不操作；
- 将 $a$ 用 $1$ 次大小写转换变为 $A$，剩余额度 $1$；
- 将 $b$ 用最后 $1$ 次转为对应大写 $B$。
得到 $AAB$，这是额度内的字典序最小结果。

## 样例2

**输入**

```
1 5
Y
```

**输出**

```
A
```

**说明**

只有一个大写字母 $Y$，用 $1$ 次「大写改任意大写」即可变成 $A$。剩余额度不用。

## 样例3

**输入**

```
1 0
a
```

**输出**

```
a
```

**说明**

额度为 $0$，无法把小写 $a$ 转成 $A$，只能保持原串 $a$。

## 样例4

**输入**

```
4 1
bCdE
```

**输出**

```
BCdE
```

**说明**

仅有 $1$ 次额度。最左侧的 $b$ 不是 $a$，用这 $1$ 次转为对应大写 $B$（不足以再变成 $A$）。后续字符没有额度，保持 $CdE$。结果为 $BCdE$。
