## 解题思路

目标是把铭牌变成字典序最小的字符串。ASCII 中大写字母一律小于小写字母，因此每个位置的最优结果是字符 $A$。

从左到右贪心处理，优先把更靠前的位置变得更小：

- 若当前是大写字母：已经是 $A$ 则无需操作；否则用 $1$ 次「大写改任意大写」即可变成 $A$。
- 若当前是小写 $a$：用 $1$ 次大小写转换即可变成 $A$。
- 若当前是其它小写字母：有 $2$ 次额度时，先转成对应大写再改成 $A$；只剩 $1$ 次时，至少转成对应大写（仍优于原小写）；没有额度则保持不变。

操作彼此独立，且字典序由最左侧不同字符决定，因此上述局部最优即可得到全局最优。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(n)$（或就地修改时为 $O(1)$ 额外空间）。

## 代码实现

### Python

```python
n, k = map(int, input().split())
s = list(input().strip())

for i in range(n):
    c = s[i]
    if 'A' <= c <= 'Z':
        if c != 'A' and k >= 1:
            s[i] = 'A'
            k -= 1
    else:
        if c == 'a':
            if k >= 1:
                s[i] = 'A'
                k -= 1
        else:
            if k >= 2:
                s[i] = 'A'
                k -= 2
            elif k >= 1:
                s[i] = c.upper()
                k -= 1

print("".join(s))
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int k = sc.nextInt();
        String s = sc.next();
        char[] arr = s.toCharArray();

        for (int i = 0; i < n; i++) {
            char c = arr[i];
            if (c >= 'A' && c <= 'Z') {
                if (c != 'A' && k >= 1) {
                    arr[i] = 'A';
                    k -= 1;
                }
            } else {
                if (c == 'a') {
                    if (k >= 1) {
                        arr[i] = 'A';
                        k -= 1;
                    }
                } else {
                    if (k >= 2) {
                        arr[i] = 'A';
                        k -= 2;
                    } else if (k >= 1) {
                        arr[i] = Character.toUpperCase(c);
                        k -= 1;
                    }
                }
            }
        }

        System.out.println(new String(arr));
        sc.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    cin >> n >> k;
    string s;
    cin >> s;

    for (int i = 0; i < n; i++) {
        char c = s[i];
        if (c >= 'A' && c <= 'Z') {
            if (c != 'A' && k >= 1) {
                s[i] = 'A';
                k -= 1;
            }
        } else {
            if (c == 'a') {
                if (k >= 1) {
                    s[i] = 'A';
                    k -= 1;
                }
            } else {
                if (k >= 2) {
                    s[i] = 'A';
                    k -= 2;
                } else if (k >= 1) {
                    s[i] = c - 'a' + 'A';
                    k -= 1;
                }
            }
        }
    }

    cout << s << "\n";
    return 0;
}
```
