# 题目内容
小蓝有一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。

对于下标 $i$，定义左累积频数 $L(i)$ 为 $a_i$ 在前缀 $a_1 \dots a_i$ 中出现的次数；对于下标 $j$，定义右累积频数 $R(j)$ 为 $a_j$ 在后缀 $a_j \dots a_n$ 中出现的次数。

小蓝想知道有多少对下标 $(i, j)$ 满足 $1 \le i < j \le n$，且 $L(i) > R(j)$。

序列长度 $n$ 不超过 $10^5$，序列中的每个整数均为正数且不超过 $10^9$。

# 输入描述
第一行包含一个整数 $n$，表示序列的长度。
第二行包含 $n$ 个由空格分隔的整数，依次表示序列中的元素 $a_1, a_2, \dots, a_n$。

# 输出描述
输出一个整数，表示满足条件的下标对 $(i, j)$ 的数量。

## 样例1

**输入**

```
4
2 2 3 2
```

**输出**

```
2
```

**说明**

序列为 $a=[2,2,3,2]$。

首先计算左累积频数 $L(i)$：
- $i=1$，$a_1=2$，在前缀 $[2]$ 中出现 `1` 次，$L(1)=1$
- $i=2$，$a_2=2$，在前缀 $[2,2]$ 中出现 `2` 次，$L(2)=2$
- $i=3$，$a_3=3$，在前缀 $[2,2,3]$ 中出现 `1` 次，$L(3)=1$
- $i=4$，$a_4=2$，在前缀 $[2,2,3,2]$ 中出现 `3` 次，$L(4)=3$

计算右累积频数 $R(j)$：
- $j=2$，$a_2=2$，后缀 $[2,3,2]$ 中 `2` 出现 `2` 次，$R(2)=2$
- $j=3$，$a_3=3$，后缀 $[3,2]$ 中 `3` 出现 `1` 次，$R(3)=1$
- $j=4$，$a_4=2$，后缀 $[2]$ 中 `2` 出现 `1` 次，$R(4)=1$

枚举满足 $i<j$ 的对：
- $(1,2)$：$L(1)=1$，$R(2)=2$，不满足。
- $(1,3)$：$L(1)=1$，$R(3)=1$，不满足。
- $(1,4)$：$L(1)=1$，$R(4)=1$，不满足。
- $(2,3)$：$L(2)=2$，$R(3)=1$，满足条件。
- $(2,4)$：$L(2)=2$，$R(4)=1$，满足条件。
- $(3,4)$：$L(3)=1$，$R(4)=1$，不满足。

共 `2` 对，答案为 `2`。

## 样例2

**输入**

```
1
5
```

**输出**

```
0
```

**说明**

序列长度为 $n=1$，不存在满足 $1 \le i < j \le n$ 的下标对 $(i,j)$，因此满足条件的对数为 `0`。

## 样例3

**输入**

```
5
1 2 1 2 1
```

**输出**

```
7
```

**说明**

序列为 $a=[1,2,1,2,1]$。

计算 $L(i)$：
- $i=1$（$a_1=1$）：$L(1)=1$
- $i=2$（$a_2=2$）：$L(2)=1$
- $i=3$（$a_3=1$）：$L(3)=2$
- $i=4$（$a_4=2$）：$L(4)=2$
- $i=5$（$a_5=1$）：$L(5)=3$

计算 $R(j)$：
- $j=2$（$a_2=2$），后缀 $[2,1,2,1]$：$R(2)=2$
- $j=3$（$a_3=1$），后缀 $[1,2,1]$：$R(3)=2$
- $j=4$（$a_4=2$），后缀 $[2,1]$：$R(4)=1$
- $j=5$（$a_5=1$），后缀 $[1]$：$R(5)=1$

枚举配对：
- $i=1$（$L=1$）：$j=2$（$R=2$）否，$j=3$（$R=2$）否，$j=4$（$R=1$）是，$j=5$（$R=1$）是 → `2` 对
- $i=2$（$L=1$）：$j=3$（$R=2$）否，$j=4$（$R=1$）是，$j=5$（$R=1$）是 → `2` 对
- $i=3$（$L=2$）：$j=4$（$R=1$）是，$j=5$（$R=1$）是 → `2` 对
- $i=4$（$L=2$）：$j=5$（$R=1$）是 → `1` 对

合计 $2+2+2+1=7$，答案为 `7`。

## 样例4

**输入**

```
3
1 1 1
```

**输出**

```
1
```

**说明**

序列为 $a=[1,1,1]$。

$L(i)$：$L(1)=1$，$L(2)=2$，$L(3)=3$。
$R(j)$：$j=2$ 时后缀 $[1,1]$，$R(2)=2$；$j=3$ 时后缀 $[1]$，$R(3)=1$。

对 $(1,2)$：$L(1)=1 
ot> R(2)=2$；
对 $(1,3)$：$L(1)=1 
ot> R(3)=1$；
对 $(2,3)$：$L(2)=2 > R(3)=1$，满足。

共 `1` 对，答案为 `1`。
