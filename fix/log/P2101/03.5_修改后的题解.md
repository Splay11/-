## 解题思路

司机与提货单都在数轴上。将两边分别排序后，最优分配一定是某段连续的 $n$ 张提货单与 $n$ 名司机按坐标顺序一一匹配：交叉匹配只会让最大路程变大。

于是枚举提货单排序后的每个长度为 $n$ 的窗口，计算

$$
\max_{1\le i\le n}\bigl(|a_i-b_{s+i-1}|+|b_{s+i-1}-p|\bigr)
$$

取所有窗口中的最小值即可。

## 复杂度分析

时间复杂度 $O((k-n+1)\cdot n)$，空间复杂度 $O(n+k)$。

## 代码实现

### Python

```python
def main():
    import sys
    n, k, p = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    b = list(map(int, sys.stdin.readline().split()))
    a = [0] + sorted(a)
    b = [0] + sorted(b)
    ans = 10**18
    for i in range(1, k - n + 2):
        res = 0
        for l1 in range(1, n + 1):
            res = max(res, abs(a[l1] - b[i + l1 - 1]) + abs(b[i + l1 - 1] - p))
        ans = min(ans, res)
    print(ans)

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int k = Integer.parseInt(st.nextToken());
        int p = Integer.parseInt(st.nextToken());
        long[] a = new long[n + 1];
        st = new StringTokenizer(br.readLine());
        for (int i = 1; i <= n; i++) {
            a[i] = Long.parseLong(st.nextToken());
        }
        long[] b = new long[k + 1];
        st = new StringTokenizer(br.readLine());
        for (int i = 1; i <= k; i++) {
            b[i] = Long.parseLong(st.nextToken());
        }
        Arrays.sort(a, 1, n + 1);
        Arrays.sort(b, 1, k + 1);
        long ans = Long.MAX_VALUE;
        for (int i = 1; i + n - 1 <= k; i++) {
            long res = 0;
            for (int l1 = 1, l2 = i; l1 <= n; l1++, l2++) {
                res = Math.max(res, Math.abs(a[l1] - b[l2]) + Math.abs(b[l2] - p));
            }
            ans = Math.min(ans, res);
        }
        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define N 5005
int n, k, p;
int a[N], b[N];
int dis(int x, int y) {
    return abs(x - y) + abs(y - p);
}
signed main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cin >> n >> k >> p;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 1; i <= k; i++) cin >> b[i];
    sort(a + 1, a + n + 1);
    sort(b + 1, b + k + 1);
    int ans = 1e18;
    for (int i = 1; i + n - 1 <= k; i++) {
        int res = 0;
        for (int l1 = 1, l2 = i; l1 <= n; l1++, l2++) {
            res = max(res, dis(a[l1], b[l2]));
        }
        ans = min(ans, res);
    }
    cout << ans << '\n';
    return 0;
}
```
