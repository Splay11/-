## 解题思路

所有工位的零件数均为正数，因此可以用滑动窗口维护当前连续区间的零件和。

- 右端点 $r$ 不断向右扩张，把 $w_r$ 加入当前和 $s$；
- 若 $s > c$，不断右移左端点 $l$ 并减去 $w_l$，直到 $s \le c$；
- 每当 $s \le c$ 时，用 $r-l+1$ 更新答案。

每个元素最多被左右指针各访问一次，整体线性。

## 复杂度分析

- **时间复杂度**：$O(n)$。每个工位进出窗口各一次。
- **空间复杂度**：$O(1)$。除输入数组外只需若干指针与累加变量。

## 代码实现

### Python

```python
import sys

def solve():
    data = list(map(int, sys.stdin.read().strip().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    k = next(it)
    a = [next(it) for _ in range(n)]

    l = 0
    s = 0
    ans = 0
    for r in range(n):
        s += a[r]
        while s > k and l <= r:
            s -= a[l]
            l += 1
        if s <= k:
            ans = max(ans, r - l + 1)
    print(ans)

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        long k = Long.parseLong(st.nextToken());

        st = new StringTokenizer(br.readLine());
        long[] a = new long[n];
        for (int i = 0; i < n; i++) a[i] = Long.parseLong(st.nextToken());

        int l = 0;
        long sum = 0;
        int ans = 0;
        for (int r = 0; r < n; r++) {
            sum += a[r];
            while (sum > k && l <= r) {
                sum -= a[l++];
            }
            if (sum <= k) {
                ans = Math.max(ans, r - l + 1);
            }
        }
        System.out.println(ans);
    }
}
```
