# 题目内容
一条传送带上依次排列着 $n$ 个工位，第 $i$ 个工位堆放了 $w_i$ 件零件。你需要选取一段连续工位 $[L,R]$（$1 \le L \le R \le n$），一次性取走这段上的全部零件。手推车的容量为 $c$，因此取走的零件总数不能超过 $c$，即 $\sum_{i=L}^{R} w_i \le c$。

请计算合法区间的最大长度 $R-L+1$。若不存在任何合法区间，则输出 `0`。

数据范围：工位个数 $n$ 满足 $1 \le n \le 2 \times 10^5$；容量 $c$ 满足 $1 \le c \le 10^{12}$；每个工位的零件数满足 $1 \le w_i \le 10^9$。

# 输入描述
第一行包含两个整数 $n$ 和 $c$（$1 \le n \le 2 \times 10^5$，$1 \le c \le 10^{12}$），分别表示工位个数与手推车容量。
第二行包含 $n$ 个整数 $w_1,w_2,\ldots,w_n$（$1 \le w_i \le 10^9$），表示各工位的零件数量。

# 输出描述
输出一个整数，表示一次合法取样能覆盖的最大连续工位个数。若不存在合法区间，输出 `0`。

## 样例1

**输入**

```
5 7
2 1 5 2 3
```

**输出**

```
2
```

**说明**

容量为 `7`。区间 $[1,2]$ 的零件和为 $2+1=3 \le 7$，长度为 `2`；区间 $[4,5]$ 的零件和为 $2+3=5 \le 7$，长度为 `2`。更长的连续区间都会超过容量，因此答案为 `2`。

## 样例2

**输入**

```
1 1
12
```

**输出**

```
0
```

**说明**

仅有 `1` 个工位，零件数为 `12`，大于容量 `1`，不存在合法区间，输出 `0`。

## 样例3

**输入**

```
3 10
1 2 3
```

**输出**

```
3
```

**说明**

整段零件和为 $1+2+3=6 \le 10$，可以覆盖全部 `3` 个工位，答案为 `3`。

## 样例4

**输入**

```
4 3
4 4 1 1
```

**输出**

```
2
```

**说明**

前两个工位各自已超过容量 `3`，不能单独选中。最后两个工位零件和为 $1+1=2 \le 3$，长度为 `2`，这是最长合法区间。
