# 题目内容
给定一个长度为 $n$ 的数列 $a_1, a_2, \dots, a_n$，其中所有元素互不相同。对于第 $i$ 个元素，定义它的**贡献度**为：在所有包含 $a_i$ 的子集中，满足子集内所有元素之和大于等于 $0$ 的子集个数。定义整个数列的**总贡献度**为所有元素的贡献度之和。请你计算给定数列的总贡献度。

数列的长度 $n$ 不超过 $18$，每个元素的绝对值不超过 $10^9$，且所有元素互不相同。

# 输入描述
第一行包含一个正整数 $n$，表示数列的长度。
第二行包含 $n$ 个整数，依次表示 $a_1, a_2, \dots, a_n$，每个整数的绝对值不超过 $10^9$，且保证所有整数互不相同。

# 输出描述
输出一个整数，表示该数列的总贡献度。

## 样例1

**输入**

```
1
5
```

**输出**

```
1
```

**说明**

数列仅包含一个元素 $a_1 = 5$。包含 $a_1$ 的子集只有一个：$\{5\}$，其元素之和为 $5 \ge 0$，满足条件。

因此 $a_1$ 的贡献度为 `1`，总贡献度为 `1`。

## 样例2

**输入**

```
2
-1 2
```

**输出**

```
3
```

**说明**

数列包含 $-1$ 和 $2$。
- 包含 $-1$ 的子集有 $\{-1\}$（和为 $-1 < 0$，不计）和 $\{-1, 2\}$（和为 $1 \ge 0$，计 `1` 次），贡献度为 `1`。
- 包含 $2$ 的子集有 $\{2\}$（和为 $2 \ge 0$，计 `1` 次）和 $\{-1, 2\}$（和为 $1 \ge 0$，计 `1` 次），贡献度为 `2`。
总贡献度为 $1 + 2 = 3$。

## 样例3

**输入**

```
3
1 2 3
```

**输出**

```
12
```

**说明**

数列元素均为正数，任意子集的和均大于等于 $0$。包含某个元素的子集个数为 $2^{3-1}=4$ 个，且全部满足条件。

每个元素的贡献度均为 `4`，总贡献度为 $3 \times 4 = 12$。

## 样例4

**输入**

```
2
0 -5
```

**输出**

```
1
```

**说明**

数列包含 $0$ 和 $-5$。
- 包含 $0$ 的子集有 $\{0\}$（和为 $0 \ge 0$，计 `1` 次）和 $\{0, -5\}$（和为 $-5 < 0$，不计），贡献度为 `1`。
- 包含 $-5$ 的子集有 $\{-5\}$（和为 $-5 < 0$，不计）和 $\{0, -5\}$（和为 $-5 < 0$，不计），贡献度为 `0`。
总贡献度为 $1 + 0 = 1$。
