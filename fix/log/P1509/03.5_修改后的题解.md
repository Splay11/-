## 解题思路

- 题目要求计算所有元素的**总贡献度**，即对于每个 $a_i$，统计包含 $a_i$ 且子集和 $\ge 0$ 的子集个数，再对所有 $i$ 求和。
- 由于 $n \le 18$，可以直接枚举 $2^n$ 个可能的子集（包括空集，空集的和为 $0$，元素个数为 $0$，不影响答案）。
- 用二进制掩码 $mask$ 从 $0$ 到 $2^n-1$ 表示每个子集：第 $j$ 位为 $1$ 表示选中 $a_j$，为 $0$ 表示不选。
- 对于每个子集：
  - 遍历所有 $j$，累加选中的元素得到子集和 $total$，同时统计元素个数 $cnt$。
  - 若 $total \ge 0$，则子集中每个元素对总贡献度都有 $1$ 次贡献，将 $cnt$ 累加入答案 $ans$。
- 最终 $ans$ 即为整个数列的总贡献度。
- 注意元素和可能超过 32 位整数范围（最大 $18\times 10^9$），需要使用 64 位整数存储。

## 复杂度分析

- 时间复杂度：$O(n \cdot 2^n)$。需要枚举 $2^n$ 个子集，每个子集遍历所有 $n$ 个元素进行判断和累加。
- 空间复杂度：$O(n)$。仅需存储长度为 $n$ 的数列 $a$，以及少数循环变量，不依赖额外的大空间。

## 代码实现

### Python

```python
n = int(input())
a = list(map(int, input().split()))

ans = 0
for mask in range(1 << n):
    total = 0
    cnt = 0
    for j in range(n):
        if mask >> j & 1:
            total += a[j]
            cnt += 1
    if total >= 0:
        ans += cnt

print(ans)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = scanner.nextInt();
        }

        int ans = 0;
        int totalMasks = 1 << n;
        for (int mask = 0; mask < totalMasks; mask++) {
            long total = 0;
            int cnt = 0;
            for (int j = 0; j < n; j++) {
                if ((mask >> j & 1) == 1) {
                    total += a[j];
                    cnt++;
                }
            }
            if (total >= 0) {
                ans += cnt;
            }
        }

        System.out.println(ans);
        scanner.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<int> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
    }

    int ans = 0;
    int totalMasks = 1 << n;
    for (int mask = 0; mask < totalMasks; ++mask) {
        long long total = 0;
        int cnt = 0;
        for (int j = 0; j < n; ++j) {
            if (mask >> j & 1) {
                total += a[j];
                cnt++;
            }
        }
        if (total >= 0) {
            ans += cnt;
        }
    }

    cout << ans << '\n';
    return 0;
}
```
