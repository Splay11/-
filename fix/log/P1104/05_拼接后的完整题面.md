# 题目内容
在一个大型项目开发中，有一个总工作量为 `total` 的功能模块需要由两名程序员接力完成。为了公平，两人需要完成完全相同的工作量，即每人恰好承担 `total/2` 的工作。整个实现过程被划分为若干连续的子任务，每个子任务的工作量均为正整数，且子任务的先后顺序具有重要意义。已知子任务的总数为 `k`，第一名程序员完成前 `i` 个子任务，第二名程序员完成剩下的 `k-i` 个子任务。给定 `total` 和 `k`，请你计算所有可能的子任务拆分方案数。由于方案数可能很大，请输出对 $10^9+7$ 取模后的结果。注意：若 `total` 为奇数，则无法平分工作量，方案数为 `0`。总工作量 `total` 满足 $1 \le total \le 2 \times 10^5$，子任务总数 `k` 满足 $1 \le k \le total$。

# 输入描述
输入仅一行，包含两个整数 `total` 和 `k`，分别表示总工作量和子任务总数。

# 输出描述
输出一个整数，表示方案数对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
5 3
```

**输出**

```
0
```

**说明**

`total = 5` 为奇数，无法将总工作量平均分给两名程序员（每人需完成 `5/2`，不是整数），所以没有任何可行方案，答案为 `0`。

## 样例2

**输入**

```
4 2
```

**输出**

```
1
```

**说明**

`total = 4`，每人需要完成 `2` 的工作量。子任务总数 `k = 2`，第一名完成前 `i` 个，第二名完成后 `2 - i` 个，其中 `i` 只能为 `1`。

唯一方案是子任务工作量分别为 `[2, 2]`，两人各完成一个子任务，工作量相等。根据公式，令 $n = \text{total} / 2 = 2$，答案为 $C(1, 0) \times C(1, 0) = 1$。

## 样例3

**输入**

```
6 3
```

**输出**

```
4
```

**说明**

`total = 6`，每人工作量 $n = 3$。子任务总数 `k = 3`，`i` 从 `1` 到 `2` 枚举。

- $i = 1$：第一名完成 `1` 个子任务，和为 `3`（只有 `[3]`）；第二名完成 `2` 个子任务，和为 `3`（有 `[1, 2]` 和 `[2, 1]` 两种），方案数为 $C(2, 0) \times C(2, 1) = 2$。
- $i = 2$：第一名完成 `2` 个子任务，和为 `3`（两种）；第二名完成 `1` 个子任务，和为 `3`（一种），方案数为 $C(2, 1) \times C(2, 0) = 2$。

总方案数为 $2 + 2 = 4$，输出 `4`。

## 样例4

**输入**

```
4 4
```

**输出**

```
1
```

**说明**

`total = 4`，每人工作量 $n = 2$。子任务总数 `k = 4`，`i` 从 `1` 到 `3` 枚举。

- $i = 1$：第一名完成 `1` 个子任务和为 `2`，只有 `[2]`；第二名完成 `3` 个子任务和为 `2`，但 `3` 个正整数之和为 `2` 不可能，方案数为 `0`。
- $i = 2$：第一名完成 `2` 个子任务和为 `2`，只能是 `[1, 1]`；第二名完成 `2` 个子任务和为 `2`，也只能是 `[1, 1]`，方案数为 $C(1, 1) \times C(1, 1) = 1$。
- $i = 3$：与 $i = 1$ 对称，方案数为 `0`。

因此唯一方案是子任务划分 `[1, 1, 1, 1]`，第一名完成前 `2` 个，输出 `1`。
