## 解题思路

题目中的「本原数」定义为大于 1 且只能被 1 和自身整除的正整数，实际上就是通常所说的质数。  
因此，问题转化为：对于每个给定的整数 $x$，找出与 $x$ 绝对差值最小的本原数；若左右两边各存在一个等距的本原数，输出较小的那个。

核心做法：

- 编写一个判断本原数的函数（试除法）：
  - 小于 $2$ 的数不是本原数；
  - $2$ 是本原数；
  - 大于 $2$ 的偶数不是本原数；
  - 其余情况只需检查是否能被 $3$ 到 $\sqrt{n}$ 之间的奇数整除。
- 对于给定的 $x$，从距离 $d=0$ 开始，依次增大 $d$：
  - 先检查 $x-d$ 是否为本原数，若是，直接返回 $x-d$；
  - 否则检查 $x+d$（当 $d>0$ 时）是否为本原数，若是，返回 $x+d$。
- 按照这种左侧优先的查找顺序，第一个被找到的本原数一定满足：与 $x$ 的绝对差最小；当左右两侧各有一个等距的本原数时，会优先返回较小的左侧数。

由于数据范围中 $x\le 10^9$ 且测试组数 $T\le 30$，每一次询问都可以用上述方法快速得出答案。

## 复杂度分析

设最终找到的最近本原数与 $x$ 的距离为 $d$。

- 单次判断一个数是否为本原数的时间复杂度为 $O(\sqrt{x})$。
- 在查找过程中最多检查约 $2d+1$ 个数，因此总时间复杂度为 $O(d \cdot \sqrt{x})$。对于 $x\le 10^9$，$d$ 在实际数据中通常很小，足以通过。

空间复杂度：只使用了常数个辅助变量，空间复杂度为 $O(1)$。

## 代码实现

### Python

```python
def is_primitive(n):
    """判断 n 是否为本原数（质数）"""
    if n < 2:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False

    # 只需检验奇数因子，范围到 sqrt(n)
    i = 3
    while i * i <= n:
        if n % i == 0:
            return False
        i += 2
    return True


def nearest_primitive(x):
    """返回与 x 绝对差最小的本原数"""
    d = 0
    while True:
        left = x - d
        right = x + d

        # 优先判断左侧，保证等距离时取较小的数
        if is_primitive(left):
            return left
        if d != 0 and is_primitive(right):
            return right

        d += 1


def main():
    t = int(input())
    for _ in range(t):
        x = int(input())
        print(nearest_primitive(x))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {

    // 判断 n 是否为本原数（质数）
    public static boolean isPrimitive(int n) {
        if (n < 2) {
            return false;
        }
        if (n == 2) {
            return true;
        }
        if (n % 2 == 0) {
            return false;
        }

        // 只需检验奇数因子
        for (int i = 3; (long) i * i <= n; i += 2) {
            if (n % i == 0) {
                return false;
            }
        }
        return true;
    }

    // 返回与 x 绝对差最小的本原数
    public static int nearestPrimitive(int x) {
        int d = 0;
        while (true) {
            int left = x - d;
            int right = x + d;

            // 优先判断左侧，保证等距离时取较小的数
            if (isPrimitive(left)) {
                return left;
            }
            if (d != 0 && isPrimitive(right)) {
                return right;
            }

            d++;
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        while (t-- > 0) {
            int x = sc.nextInt();
            System.out.println(nearestPrimitive(x));
        }
        sc.close();
    }
}
```
