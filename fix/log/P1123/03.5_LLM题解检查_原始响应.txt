## 解题思路

题目要求在 $N$ 个卡片组中各选一张卡片，按组号顺序拼成一个长度为 $N$ 的字母序列，且序列中不能出现相同字母。需要统计所有不同的合法序列个数。

由于 $N \le 6$，每组卡片数不超过 $8$，总搜索空间很小，可以使用深度优先搜索（DFS）回溯枚举所有可能的序列，并通过以下两点保证正确性：

1. **字符互不相同**：搜索过程中维护一个计数数组（或哈希表）`used`，记录当前路径上每个字母是否已被使用。只有当前卡片上的字母未被使用时，才允许将其加入序列，并继续向下一组搜索。
2. **序列不重复**：由于同一组内可能有重复字母（例如字符串 `"aab"`），直接枚举会生成多条相同的序列。为了避免重复计数，需要将所有构造出的序列存入一个集合 `seen` 中（如哈希集合），最后以集合的大小作为答案。也可以在每组内部先对字符去重，但全局去重更加通用。

搜索从第 $1$ 组（索引 `0`）开始，当处理完最后一组（索引 `N`）时，将构造出的字符串加入集合，回溯时撤销当前选择。最终输出集合中的序列总数。

## 复杂度分析

- **时间复杂度**：最坏情况下每组有 $8$ 种不同的字母，需要枚举所有可能的序列，数量上限为 $O(8^N)$。由于 $N \le 6$，最多约 $2.6 \times 10^5$ 个序列，每个序列加入集合并进行哈希操作的时间可以忽略。因此总时间复杂度为 $O(8^N \cdot N)$（$N$ 为拼接字符串的长度），在本题数据范围内可以瞬间完成。
- **空间复杂度**：递归栈深度为 $O(N)$，字符使用记录数组大小为常数（$26$），集合最多存储 $O(8^N)$ 个长度为 $N$ 的字符串，因此空间复杂度为 $O(8^N \cdot N)$。

## 代码实现

### Python

```python
def solve():
    n = int(input())
    groups = [input().strip() for _ in range(n)]
    
    used = [0] * 26          # 记录字母是否使用：0 未使用，1 已使用
    path = []                # 当前构建的序列
    seen = set()             # 存储所有不同的合法序列
    
    def dfs(idx):
        if idx == n:                     # 已经处理完所有组
            seen.add(''.join(path))
            return
        for ch in groups[idx]:
            key = ord(ch) - ord('a')
            if used[key] == 0:           # 保证序列中字符互不相同
                used[key] = 1
                path.append(ch)
                dfs(idx + 1)             # 进入下一组
                path.pop()               # 回溯
                used[key] = 0
    
    dfs(0)
    print(len(seen))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.*;

public class Main {
    static int n;
    static String[] groups;
    static boolean[] used;
    static StringBuilder path;
    static Set<String> seen;

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        n = sc.nextInt();
        groups = new String[n];
        for (int i = 0; i < n; i++) {
            groups[i] = sc.next();
        }
        
        used = new boolean[26];
        path = new StringBuilder();
        seen = new HashSet<>();
        
        dfs(0);
        System.out.println(seen.size());
    }

    static void dfs(int idx) {
        if (idx == n) {                 // 已选完 N 张卡片
            seen.add(path.toString());
            return;
        }
        String curGroup = groups[idx];
        for (int i = 0; i < curGroup.length(); i++) {
            char c = curGroup.charAt(i);
            int key = c - 'a';
            if (!used[key]) {           // 该字母尚未使用
                used[key] = true;
                path.append(c);
                dfs(idx + 1);
                path.deleteCharAt(path.length() - 1); // 回溯
                used[key] = false;
            }
        }
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <unordered_set>
using namespace std;

int n;
vector<string> groups;
bool used[26];
string path;
unordered_set<string> seen;

void dfs(int idx) {
    if (idx == n) {                     // 所有组均已选择
        seen.insert(path);
        return;
    }
    for (char c : groups[idx]) {
        int key = c - 'a';
        if (!used[key]) {               // 保证字母不重复
            used[key] = true;
            path.push_back(c);
            dfs(idx + 1);
            path.pop_back();            // 回溯
            used[key] = false;
        }
    }
}

int main() {
    cin >> n;
    groups.resize(n);
    for (int i = 0; i < n; ++i) {
        cin >> groups[i];
    }
    
    fill(used, used + 26, false);
    path = "";
    seen.clear();
    
    dfs(0);
    cout << seen.size() << endl;
    return 0;
}
```
