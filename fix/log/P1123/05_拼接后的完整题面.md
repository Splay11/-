# 题目内容
梦梦在玩一个组合游戏。她有 $N$ 个卡片组，编号从 $1$ 到 $N$。每个组里有若干张卡片，每张卡片上印着一个小写英文字母 $\text{a} \sim \text{z}$，同一组内的字母可以重复。

她需要从第 $1$ 组到第 $N$ 组依次各挑选一张卡片，并将这些卡片上的字母按组号顺序拼接成一个长度为 $N$ 的字母序列。梦梦希望这个序列中的字母互不相同，即不能出现相同的字母。

请你计算共有多少种不同的字母序列能够被拼出。两个序列只要在任意位置上的字母不同，就视为不同的序列。

约束：
- 卡片组数量 $N$ 满足 $2 \le N \le 6$。
- 每个卡片组的卡片张数在 $1$ 到 $8$ 之间。

# 输入描述
第一行包含一个整数 $N$，表示卡片组的个数。
接下来 $N$ 行，每行包含一个由小写英文字母组成的非空字符串，表示对应卡片组中每张卡片上的字母（字符串中每个字符代表一张卡片，字符可能重复）。

# 输出描述
输出一个整数，表示能够拼出的不同字母序列的总数。

## 样例1

**输入**

```
2
ab
ab
```

**输出**

```
2
```

**说明**

从第 `1` 组选择 `'a'`，则第 `2` 组只能选择不同的字母 `'b'`，得到序列 "ab"；
从第 `1` 组选择 `'b'`，则第 `2` 组只能选择 `'a'`，得到序列 "ba"。
其余选择均会导致字母重复，因此总共有 `2` 种不同的序列。

## 样例2

**输入**

```
3
a
bc
def
```

**输出**

```
6
```

**说明**

第 `1` 组只能选择 `'a'`。
第 `2` 组可以选择 `'b'` 或 `'c'`：
- 若选 `'b'`，第 `3` 组的 `'d'`、`'e'`、`'f'` 均与已选字母不重复，贡献 $3$ 种；
- 若选 `'c'`，同理贡献 $3$ 种。
根据乘法原理，总序列数为 $3 + 3 = 6$。

## 样例3

**输入**

```
2
aa
a
```

**输出**

```
0
```

**说明**

第 `1` 组无论选择哪一张卡片，得到字母 `'a'`；
第 `2` 组也只有字母 `'a'`，任何选择都会使序列中出现重复的 `'a'`。
因此无法拼出符合要求的序列，答案为 `0`。

## 样例4

**输入**

```
4
ab
ac
bd
c
```

**输出**

```
1
```

**说明**

通过搜索所有可能的选择：
- 若第 `1` 组选 `'a'`，则第 `2` 组必须选 `'c'`，第 `3` 组无论选 `'b'` 还是 `'d'`，都会导致第 `4` 组的 `'c'` 与已选字母重复，无解。
- 若第 `1` 组选 `'b'`：
  - 第 `2` 组选 `'a'`，已用 $\{b,a\}$，第 `3` 组只能选 `'d'`（`'b'` 重复），已用 $\{b,a,d\}$，第 `4` 组选 `'c'` 不冲突，得到序列 "badc"。
  - 第 `2` 组选 `'c'`，已用 $\{b,c\}$，第 `3` 组只能选 `'d'`，已用 $\{b,c,d\}$，第 `4` 组的 `'c'` 重复，无解。
唯一有效序列为 "badc"，故答案为 `1`。
