# 题目内容
冷链中转站的一条传送线上依次放着 $n$ 托货品，第 $i$ 托的制冷负荷为 $a_i$。安全规程要求：任意连续 $k$ 托的负荷之和都不能超过上限 $S$。每次调整可以选择一托，把它的负荷减少 `1`，但负荷不能变成负数。站长希望用尽可能少的调整次数，使整条传送线满足限载规程。

约束：$1 \le k \le n \le 200000$，$1 \le S \le 10000000000000$，$0 \le a_i \le 1000000000$。

# 输入描述
第一行三个整数 $n$、$k$ 和 $S$，分别表示托数、窗口长度与负荷上限。
第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$，表示各托制冷负荷。
保证 $1 \le k \le n \le 200000$，$1 \le S \le 10000000000000$，$0 \le a_i \le 1000000000$。

# 输出描述
输出一个整数，表示最少调整次数。

## 样例1

**输入**

```
4 2 5
3 4 2 8
```

**输出**

```
7
```

**说明**

任意相邻两箱之和不能超过 `5`。

- 先处理前两箱 $3+4=7$，把第二箱减 `2` 变成 `2`；
- 再处理末两箱，当前为 $2+8=10$，把第四箱减 `5` 变成 `3`。

共操作 `7` 次，得到 $[3,2,2,3]$。

## 样例2

**输入**

```
3 3 100
1 2 3
```

**输出**

```
0
```

**说明**

整个序列之和为 `6`，不超过上限 `100`，无需任何削减，答案为 `0`。

## 样例3

**输入**

```
6 2 3
5 1 4 0 2 9
```

**输出**

```
12
```

**说明**

相邻两箱之和需不超过 `3`。从左到右每次超限时优先削减窗口右端，累计需要削减 `12`。
