# 题目内容
在一种古老的符文系统中，有三种基础符文，分别用字符 `r`、`e`、`d` 表示。一位学者获得了一串由这些符文组成的序列 $s_1 s_2 \dots s_n$，他想研究其中按顺序出现的符文组合 $(i, j, k)$ 满足 $1 \le i < j < k \le n$，且 $s_i =$ `r`, $s_j =$ `e`, $s_k =$ `d`，这样的组合被称为一个“共鸣三元组”。

对于一个共鸣三元组，定义其共鸣效能为三个符文位置之间的距离之和：$|i - j| + |i - k| + |j - k|$。

请你帮助学者计算序列中所有共鸣三元组的效能之和。

**约束条件**
- 序列长度 $n$ 满足 $1 \le n \le 2 \times 10^5$。
- 序列中的字符仅由 `r`、`e`、`d` 组成。

# 输入描述
第一行输入一个整数 $n$，表示符文序列的长度。
第二行输入一个长度为 $n$ 的字符串，仅包含字符 `r`、`e`、`d`，表示符文序列。

# 输出描述
输出一个整数，表示所有共鸣三元组的效能之和。

## 样例1

**输入**

```
3
red
```

**输出**

```
4
```

**说明**

序列为 `r` `e` `d`，长度为 `3`。唯一的共鸣三元组为 $(1, 2, 3)$，满足 $i < j < k$ 且字符依次为 `r`、`e`、`d`。

效能计算：$|1-2| + |1-3| + |2-3| = 1 + 2 + 1 = 4$，也可化简为 $2 \times (k - i) = 2 \times (3 - 1) = 4$。因此输出 `4`。

## 样例2

**输入**

```
4
rrrr
```

**输出**

```
0
```

**说明**

序列中仅包含字符 `r`，没有 `e` 和 `d`，无法构成任何 $(i, j, k)$ 满足 $s_i =$ `r`，$s_j =$ `e`，$s_k =$ `d` 的共鸣三元组。

因此共鸣三元组的个数为 `0`，效能之和为 `0`。

## 样例3

**输入**

```
5
reded
```

**输出**

```
20
```

**说明**

序列为 `r e d e d`，索引 $1$ 到 $5$。其中 $s_1 =$ `r`，$s_2$ 和 $s_4$ 为 `e`，$s_3$ 和 $s_5$ 为 `d`。

所有共鸣三元组为：$(1,2,3)$，$(1,2,5)$ 和 $(1,4,5)$。
效能计算：
- $(1,2,3)$：$2 \times (3 - 1) = 4$
- $(1,2,5)$：$2 \times (5 - 1) = 8$
- $(1,4,5)$：$2 \times (5 - 1) = 8$

效能之和为 $4 + 8 + 8 = 20$。
