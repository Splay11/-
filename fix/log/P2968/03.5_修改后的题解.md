## 解题思路

1. **化简效能公式**  
   对于任意共鸣三元组 $(i, j, k)$，由于 $i < j < k$，绝对值符号可以直接去掉：
   $$|i - j| + |i - k| + |j - k| = (j - i) + (k - i) + (k - j) = 2(k - i)$$
   因此，每个三元组的效能只由首尾两个位置 $i$（字符 `r`）和 $k$（字符 `d`）决定，与中间字符 `e` 的具体位置无关。

2. **统计中间 `e` 的个数**  
   在 $i$ 与 $k$ 之间的 `e` 有多少个，这个三元组对答案的贡献就会倍增多少次。即对于一对 $(i, k)$，若它们之间有 $c$ 个 `e`，则总贡献为 $2(k - i) \times c$。  
   所有共鸣三元组的总效能为：
   $$\sum_{1 \le i < k \le n,\, s_i=\text{'r'},\, s_k=\text{'d'}} 2(k - i) \times \bigl(\text{preE}[k-1] - \text{preE}[i]\bigr)$$
   其中 $\text{preE}[t]$ 表示前 $t+1$ 个字符（下标 $0$ 到 $t$）中 `e` 出现的次数。

3. **在线维护统计量**  
   遍历字符串时，我们一边维护所有已经遇到的 `r` 的统计信息，一边在遇到 `d` 时快速计算上式。  
   设当前遍历到位置 $k$（下标从 $0$ 开始），维护以下变量：
   - $\text{cntR}$：已经遇到的 `r` 的个数；
   - $\text{sumI}$：这些 `r` 的下标之和；
   - $\text{sumPE}$：这些 `r` 对应位置的 $\text{preE}$ 值之和；
   - $\text{sumIPI}$：这些 `r` 的下标乘上对应 $\text{preE}$ 值之和。

   当遇到字符 `r` 时（位置 $i = k$），更新：
   ```text
   cntR += 1
   sumI += i
   sumPE += preE[i]
   sumIPI += i * preE[i]
   ```
   当遇到字符 `d` 时（位置 $k$ 即为当前的 `d`），令 $E = \text{preE}[k-1]$（$k=0$ 时 $E=0$），则所有已记录的 `r` 与当前 `d` 配对产生的贡献为：
   ```text
   contrib = E * (cntR * k - sumI) - (k * sumPE - sumIPI)
   ```
   将 $2 \times \text{contrib}$ 累加到答案中。

4. **整体流程**  
   - 预处理前缀数组 $\text{preE}$。
   - 初始化统计变量 $\text{cntR} = 0,\ \text{sumI} = 0,\ \text{sumPE} = 0,\ \text{sumIPI} = 0$。
   - 从左到右遍历字符串，根据当前字符是 `r` 还是 `d` 执行上述更新或累加操作。
   - 输出最终累加的结果。

## 复杂度分析

- **时间复杂度**：$O(n)$。预处理 $\text{preE}$ 数组以及单次遍历字符串均只需线性时间，每一步计算均为常数时间。
- **空间复杂度**：$O(n)$。需要一个长度为 $n$ 的数组 $\text{preE}$ 存储前缀信息。当然可以进一步优化到 $O(1)$，但为了代码清晰仍然使用数组。

## 代码实现

### Python

```python
def calc_total_energy(s):
    n = len(s)
    # preE[i] 表示下标 0..i 中字符 'e' 的个数
    preE = [0] * n
    for i, ch in enumerate(s):
        preE[i] = (preE[i - 1] + (ch == 'e')) if i > 0 else (ch == 'e')

    cntR = sumI = sumPE = sumIPI = 0
    ans = 0

    for k, ch in enumerate(s):
        if ch == 'r':
            # 记录一个 'r' 的信息（下标 k）
            cntR += 1
            sumI += k
            sumPE += preE[k]
            sumIPI += k * preE[k]
        elif ch == 'd':
            if cntR == 0:
                continue
            # 计算当前 'd' 与之前所有 'r' 产生的贡献
            E = preE[k - 1] if k > 0 else 0
            M, A, B, C = cntR, sumI, sumPE, sumIPI
            contrib = E * (M * k - A) - (k * B - C)
            ans += 2 * contrib

    return ans


if __name__ == '__main__':
    import sys
    data = sys.stdin.read().split()
    n = int(data[0])
    s = data[1].strip()
    print(calc_total_energy(s))
```

### Java

```java
import java.io.*;

public class Main {
    static long solve(String s) {
        int n = s.length();
        long[] preE = new long[n];
        for (int i = 0; i < n; i++) {
            preE[i] = (s.charAt(i) == 'e' ? 1 : 0) + (i > 0 ? preE[i - 1] : 0);
        }

        long cntR = 0, sumI = 0, sumPE = 0, sumIPI = 0;
        long ans = 0;

        for (int k = 0; k < n; k++) {
            char c = s.charAt(k);
            if (c == 'r') {
                cntR++;
                sumI += k;
                sumPE += preE[k];
                sumIPI += k * preE[k];
            } else if (c == 'd') {
                if (cntR == 0) continue;
                long E = k > 0 ? preE[k - 1] : 0;
                long M = cntR, A = sumI, B = sumPE, C = sumIPI;
                long contrib = E * (M * k - A) - (k * B - C);
                ans += 2 * contrib;
            }
        }
        return ans;
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());
        String s = br.readLine().trim();
        System.out.println(solve(s));
    }
}
```
