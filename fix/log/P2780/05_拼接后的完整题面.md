# 题目内容
魔法师有 $n$ 颗魔法水晶，第 $i$ 颗的魔力值为 $a_i$。她可以反复施展一种共鸣术：选定两个下标 $i$ 和 $j$（$1 \le i, j \le n$），同时将 $a_i$ 变为 $a_i \times a_j$，将 $a_j$ 变为 $\operatorname{lcm}(a_i, a_j)$。她希望经过若干次操作后，所有水晶的魔力值都能被 $2$ 整除。请求出所需的最少操作次数；如果无法达成目标，请输出 $-1$。

数据范围：水晶数量 $n$ 满足 $1 \le n \le 10^5$，每颗水晶的初始魔力值 $a_i$ 满足 $1 \le a_i \le 10^9$。

# 输入描述
第一行包含一个整数 $n$（$1 \le n \le 10^5$），表示水晶的数量。
第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 10^9$），表示每颗水晶的初始魔力值，相邻整数间以空格分隔。

# 输出描述
输出一个整数，表示所需的最少操作次数；若无法达成目标，则输出 $-1$。

## 样例1

**输入**

```
3
2 4 8
```

**输出**

```
0
```

**说明**

所有水晶的魔力值 $a_1=2$, $a_2=4$, $a_3=8$ 均为偶数，已经满足全部可被 $2$ 整除的条件，无需进行任何操作。因此最少操作次数为 `0`。

## 样例2

**输入**

```
4
1 3 2 4
```

**输出**

```
2
```

**说明**

初始阵列中存在偶数 $2$ 和 $4$，奇数有 `2` 个（$1$ 和 $3$）。

每次操作可以选择一个奇数和一个偶数：将奇数变为 $奇数 \times 偶数$（偶数），偶数所在位置变为 $\operatorname{lcm}(奇数,偶数)$（偶数）。因此用现有的偶数分别与每个奇数进行一次操作，即可将所有奇数转变为偶数。最少需要 `2` 次操作。

## 样例3

**输入**

```
3
111 333 555
```

**输出**

```
-1
```

**说明**

三个水晶的魔力值 $111$, $333$, $555$ 均为奇数。

当两个数都是奇数时，它们的乘积与最小公倍数仍为奇数，无法产生任何偶数。由于数组中不存在偶数，无论进行多少次操作都无法得到偶数，因此目标无法实现，输出 `-1`。

## 样例4

**输入**

```
1
1000000000
```

**输出**

```
0
```

**说明**

只有一个水晶，其魔力值 $1000000000$ 是偶数，已经满足可被 $2$ 整除的条件，无需操作。答案为 `0`。该样例展示了 $n=1$ 且初始即为偶数的边界情况。
