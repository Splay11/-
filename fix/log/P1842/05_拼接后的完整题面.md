# 题目内容
一条传感带上依次记录了 $n$ 个脉冲，构成长度为 $n$ 的字符串 $s$，其中每个字符只能是 `0` 或 `1`。

对于每一个位置 $i$（下标从 `1` 开始），需要回望它左侧最近一次与 $s_i$ 不同的脉冲，并记下该位置的下标。若左侧不存在不同脉冲，则该位置的答案为 `-1`。

测试文件包含多组数据。测试组数不超过 `100`，每组脉冲个数不超过 `1000`。

# 输入描述
第一行一个正整数 $T$（$1 \le T \le 100$），表示数据组数。
每组数据包含两行：第一行一个正整数 $n$（$1 \le n \le 1000$），表示脉冲个数；第二行一个长度为 $n$ 的字符串 $s$，仅由字符 `0` 和 `1` 组成。

# 输出描述
对每组数据输出一行 $n$ 个整数 $a_1, a_2, \ldots, a_n$，其中 $a_i$ 表示第 $i$ 个脉冲左侧最近的不同脉冲下标；若不存在则输出 `-1`。

## 样例1

**输入**

```
2
1
0
5
01010
```

**输出**

```
-1
-1 1 2 3 4
```

**说明**

第一组只有一个脉冲 `0`，左侧不存在位置，输出 `-1`。
第二组为 `01010`：每位都与前一位不同，因此从第 `2` 位起答案依次为前一位置的下标，输出 `-1 1 2 3 4`。

## 样例2

**输入**

```
1
3
000
```

**输出**

```
-1 -1 -1
```

**说明**

三个脉冲全是 `0`，任意位置左侧都不存在不同脉冲，输出 `-1 -1 -1`。

## 样例3

**输入**

```
2
1
0
4
01010
```

**输出**

```
-1
-1 1 2 3
```

**说明**

按题意模拟计算得到。
