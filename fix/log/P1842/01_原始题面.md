# 题目描述

塔子哥拥有一个长度为 $n$ 的 01 串，现在他想知道，对于每个字符，在它前面的最近的不同字符的下标是多少。

# 输入描述

本题为多组测试数据，第一行输入一个正整数 $T$（$1 \leq T \leq 100$），代表测试数据组数。对于每组测试数据，第一行输入一个正整数 $n$（$1 \leq n \leq 1000$），代表初始 01 串的长度。第二行输入一个长度为 $n$ 的 01 串，代表初始字符串。

# 输出描述

对于每组测试数据，输出一行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$，其中 $a_i$ 代表初始字符串中第 $i$ 个位置的字符前面，最近的不同字符的下标是 $a_i$。特殊的，如果前面不存在不同字符，则输出 $-1$ 表示不存在。

## 样例输入

```
1
4
1101
```

## 样例输出

```
-1 -1 2 3
```
