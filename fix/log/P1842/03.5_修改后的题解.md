## 解题思路

从左到右扫描脉冲串 $s$，同时维护两个变量：

- $last_0$：最近一次字符 `0` 出现的下标（从 `1` 开始编号），尚未出现则为 `-1`；
- $last_1$：最近一次字符 `1` 出现的下标，尚未出现则为 `-1`。

扫到位置 $i$（`0`-下标）时：

- 若 $s_i$ 为 `1`，则答案就是当前的 $last_0$，再把 $last_1$ 更新为 $i+1$；
- 若 $s_i$ 为 `0`，则答案就是当前的 $last_1$，再把 $last_0$ 更新为 $i+1$。

这样每个位置只需常数时间即可得到“左侧最近的不同脉冲”。

## 复杂度分析

每组数据线性扫描一次字符串。

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(n)$。

在 $T \le 100$、$n \le 1000$ 的限制下可以通过。

## 代码实现

### Python

```python
T = int(input())
for _ in range(T):
    n = int(input())
    s = input().strip()
    last0, last1 = -1, -1
    ans = []
    for i in range(n):
        if s[i] == '1':
            ans.append(last0)
            last1 = i + 1
        else:
            ans.append(last1)
            last0 = i + 1
    print(' '.join(map(str, ans)))
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();
        for (int t = 0; t < T; t++) {
            int n = sc.nextInt();
            String s = sc.next();
            int last0 = -1, last1 = -1;
            int[] ans = new int[n];
            for (int i = 0; i < n; i++) {
                if (s.charAt(i) == '1') {
                    ans[i] = last0;
                    last1 = i + 1;
                } else {
                    ans[i] = last1;
                    last0 = i + 1;
                }
            }
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < n; i++) {
                if (i > 0) sb.append(' ');
                sb.append(ans[i]);
            }
            System.out.println(sb);
        }
        sc.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int n;
        string s;
        cin >> n >> s;
        int last0 = -1, last1 = -1;
        vector<int> ans(n);
        for (int i = 0; i < n; i++) {
            if (s[i] == '1') {
                ans[i] = last0;
                last1 = i + 1;
            } else {
                ans[i] = last1;
                last0 = i + 1;
            }
        }
        for (int i = 0; i < n; i++) {
            if (i) cout << ' ';
            cout << ans[i];
        }
        cout << '\n';
    }
    return 0;
}
```
