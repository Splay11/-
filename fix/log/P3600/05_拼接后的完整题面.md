# 题目内容
林区防火通道构成一棵 $n$ 个节点的无向连通树，通道 $(u,v)$ 的通行耗时为正权 $w_{uv}$。其中有 $m$ 个互不相同的火险点需要重点监视。指挥部决定恰好设立 `2` 座瞭望台（可以建在任意节点上，包括火险点本身），每个火险点由距离它更近的那座瞭望台负责；带权距离指路径上边权之和。

为了把最坏情况下的响应时间压到最低，需要使所有火险点到最近瞭望台的最大带权距离 $D$ 最小。求该最小的 $D$。

约束：火险点数满足 $2 \le m \le n \le 200000$，边权不超过 `100000`。

# 输入描述
第一行两个整数 $n,m$，表示节点数与火险点数。
第二行 $m$ 个互不相同的整数 $r_1,\ldots,r_m$，表示火险点编号。
接下来 $n-1$ 行，每行三个整数 $u_i,v_i,w_i$，表示一条无向带权边。
保证 $2 \le m \le n \le 200000$，$1 \le r_i \le n$，$1 \le u_i,v_i \le n$，$u_i 
eq v_i$，$1 \le w_i \le 100000$，输入构成一棵树。

# 输出描述
输出一个整数 $D$，表示恰好选择 `2` 座瞭望台时，所有火险点到最近瞭望台的最大带权距离的最小值。

## 样例1

**输入**

```
4 3
1 3 4
1 2 5
2 3 5
3 4 7
```

**输出**

```
5
```

**说明**

告警节点为 `1`、`3`、`4`。把基站放在节点 `2` 和 `4`：告警 `1` 距离 `5`，告警 `3` 距离 `5`，告警 `4` 距离 `0`，最大值为 `5`。可以证明不能更小。

## 样例2

**输入**

```
5 2
1 5
1 2 3
2 3 4
3 4 2
4 5 6
```

**输出**

```
0
```

**说明**

只有 `2` 个告警节点，两个基站可以直接放在它们上面，最大服务距离为 `0`。

## 样例3

**输入**

```
6 4
1 2 5 6
1 3 2
3 2 3
3 4 4
4 5 5
4 6 6
```

**输出**

```
6
```

**说明**

四个告警节点分布在以 `3`、`4` 为枢纽的树上。最优两个基站可使最大带权距离降到 `6`。
