# 题目内容
仓库货架上摆着 $n$ 件货物，第 $i$ 件的型号为 $a_i$。定义货架的品类数为其中不同型号的个数。

现在要从货架上撤下尽可能多的货物，但不能让品类数发生变化，即每种原先出现过的型号至少还要留下一件。求最多可以撤下多少件。

货物件数与每个型号均不超过 `100`。

# 输入描述
第一行一个正整数 $n$，表示货物件数。
第二行 $n$ 个正整数 $a_1, a_2, \ldots, a_n$，表示每件货物的型号。
保证 $1 \le n, a_i \le 100$。

# 输出描述
输出一个整数，表示最多可以撤下的货物件数。

## 样例1

**输入**

```
3
7 7 7
```

**输出**

```
2
```
