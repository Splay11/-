## 解题思路

货架的品类数等于不同型号的个数。设不同型号共有 $k$ 种。

要保持品类数不变，每种原先出现过的型号至少要留下 `1` 件，因此最少需要保留 $k$ 件货物。其余货物都可以撤下。

所以最多可撤下的件数就是 $n-k$。用集合统计不同型号即可。

## 复杂度分析

扫描一遍货物并插入集合。

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(k)$，其中 $k$ 为不同型号个数。

在 $n \le 100$ 的限制下可以通过。

## 代码实现

### Python

```python
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    if not data:
        return
    n = data[0]
    arr = data[1:1 + n]
    k = len(set(arr))
    print(n - k)

if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        if (!sc.hasNextInt()) return;
        int n = sc.nextInt();
        Set<Integer> set = new HashSet<>();
        for (int i = 0; i < n; i++) {
            set.add(sc.nextInt());
        }
        int k = set.size();
        System.out.println(n - k);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    if (!(cin >> n)) return 0;
    unordered_set<int> s;
    for (int i = 0; i < n; ++i) {
        int x; cin >> x;
        s.insert(x);
    }
    int k = (int)s.size();
    cout << (n - k) << "\n";
    return 0;
}
```
