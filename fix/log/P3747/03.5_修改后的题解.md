## 解题思路

两个不同的非空连续片段若字符多重集合完全相同，则它们互为相同构成。

关键观察：只要某个小写字母在 $s$ 中出现至少 `2` 次，就可以各取这两个位置作为长度为 `1` 的片段，二者构成相同，答案为 `Yes`。

反之，若每个字母都只出现 `1` 次，则任意两个不同连续片段所覆盖的位置集合必然不同，因而字符多重集合也不同，答案为 `No`。

因此问题等价于判断 $s$ 是否存在重复字符。用长度为 `26` 的布尔数组线性扫描即可。

## 复杂度分析

扫描一次字符串，额外只使用常数大小的标记数组。

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(1)$。

## 代码实现

### Python

```python
import sys

data = sys.stdin.read().strip().split()
if not data:
    sys.exit(0)
n = int(data[0])
s = data[1]

seen = [False] * 26
for ch in s:
    idx = ord(ch) - 97
    if seen[idx]:
        print("Yes")
        break
    seen[idx] = True
else:
    print("No")
```

### Java

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String line1 = br.readLine();
        if (line1 == null) return;
        String line2 = br.readLine();
        long n = Long.parseLong(line1.trim());
        String s = line2.trim();
        boolean[] seen = new boolean[26];
        for (int i = 0; i < s.length(); i++) {
            int idx = s.charAt(i) - 'a';
            if (seen[idx]) {
                System.out.println("Yes");
                return;
            }
            seen[idx] = true;
        }
        System.out.println("No");
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    string s;
    if (!(cin >> n)) return 0;
    cin >> s;
    bool seen[26] = {false};
    for (char c : s) {
        int x = c - 'a';
        if (seen[x]) {
            cout << "Yes\n";
            return 0;
        }
        seen[x] = true;
    }
    cout << "No\n";
    return 0;
}
```
