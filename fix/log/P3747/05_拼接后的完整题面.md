# 题目内容
一条长度为 $n$ 的信号串 $s$ 仅由小写英文字母组成。请判断是否存在两个不同的非空连续片段，它们包含的字符种类以及每种字符的出现次数完全相同。

约束：串长不超过 `10^6`，字符串仅由小写英文字母构成。

# 输入描述
第一行一个整数 $n$，表示信号串长度。
第二行一个长度为 $n$ 的字符串 $s$，仅由小写英文字母组成。
保证 $1 \le n \le 10^6$。

# 输出描述
若存在这样的两个片段，输出 `Yes`；否则输出 `No`。

## 样例1

**输入**

```
1
z
```

**输出**

```
No
```
