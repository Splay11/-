# 题目内容
小蓝有一个 $n \times n$ 的空白方格表，初始所有格子内的数值均为 $0$。她有两种操作：
- 行变换：选定第 $i$ 行，将该行所有格子的数值与行密钥 $a_i$ 按位异或；
- 列变换：选定第 $j$ 列，将该列所有格子的数值与列密钥 $b_j$ 按位异或。
两种操作的次数不限，可以按任意顺序进行。

现在知道操作结束后，位于对角线上（即第 $i$ 行第 $i$ 列，以下称为同标格）的 $n$ 个格子的最终数值依次为 $d_1, d_2, \dots, d_n$。给定 $q$ 次询问，每次给出一个行号 $u$ 和列号 $v$，你需要求出第 $u$ 行第 $v$ 列格子的最终数值。

已知行密钥 $a_1,\dots,a_n$ 互不相同，列密钥 $b_1,\dots,b_n$ 互不相同，且数据保证存在合法的操作序列使得同标格值恰好为给定的 $d_i$。方格表的维度 $n$ 与询问次数 $q$ 均满足 $1 \le n, q \le 10^5$，所有 $a_i$、$b_i$ 均为不超过 $10^6$ 的正整数，$d_i$ 满足 $0 \le d_i \le 10^6$。

# 输入描述
第一行包含两个整数 $n$ 和 $q$，表示方格表的规模和询问次数。
第二行包含 $n$ 个互不相同的正整数 $a_1, a_2, \dots, a_n$，表示各行对应的行密钥。
第三行包含 $n$ 个互不相同的正整数 $b_1, b_2, \dots, b_n$，表示各列对应的列密钥。
第四行包含 $n$ 个整数 $d_1, d_2, \dots, d_n$，表示操作后同标格的最终值。
接下来 $q$ 行，每行包含两个整数 $u$ 和 $v$（$1 \le u, v \le n$），表示询问的行号和列号。

# 输出描述
对于每次询问，输出一行一个整数，表示对应格子的最终数值。如果存在多种可能的合法值，输出任意一种即可。

## 样例1

**输入**

```
4 4
1 2 3 4
5 6 7 8
0 2 7 12
1 2
2 3
3 4
4 1
```

**输出**

```
0
2
8
1
```

**说明**

首先根据对角线上的值 $d_i$ 反推出每一行和每一列对应的“有效异或值” $R_i$ 与 $C_i$：
- $d_1 = 0$，说明第 `1` 行和第 `1` 列均未操作，即 $R_1 = 0$, $C_1 = 0$；
- $d_2 = 2 = a_2$，说明仅第 `2` 行被操作，即 $R_2 = 2$, $C_2 = 0$；
- $d_3 = 7 = b_3$，说明仅第 `3` 列被操作，即 $R_3 = 0$, $C_3 = 7$；
- $d_4 = 12 = a_4 \oplus b_4 = 4 \oplus 8 = 12$，说明第 `4` 行和第 `4` 列均被操作，即 $R_4 = 4$, $C_4 = 8$。

对于任意询问 $(u,v)$，答案为 $R_u \oplus C_v$：
- `(1,2)`：$0 \oplus 0 = 0$；
- `(2,3)`：$2 \oplus 0 = 2$；
- `(3,4)`：$0 \oplus 8 = 8$；
- `(4,1)`：$4 \oplus 5 = 1$。

## 样例2

**输入**

```
1 1
100
200
200
1 1
```

**输出**

```
200
```

**说明**

当 $n = 1$ 时，只有一个对角线格子。已知 $a_1 = 100$, $b_1 = 200$, $d_1 = 200$。根据规则，$d_1 = b_1$ 表明仅第 `1` 列被操作了一次，即 $R_1 = 0$, $C_1 = 200$。询问 `(1,1)` 的结果为 $R_1 \oplus C_1 = 0 \oplus 200 = 200$。

## 样例3

**输入**

```
3 2
10 20 30
11 21 31
10 21 1
1 2
3 1
```

**输出**

```
31
30
```

**说明**

根据对角线上的值确定 $R_i$ 和 $C_i$：
- $d_1 = 10 = a_1$，所以 $R_1 = 10$, $C_1 = 0$；
- $d_2 = 21 = b_2$，所以 $R_2 = 0$, $C_2 = 21$；
- $d_3 = 1 = a_3 \oplus b_3 = 30 \oplus 31 = 1$，所以 $R_3 = 30$, $C_3 = 31$。

对于询问：
- `(1,2)`：$R_1 \oplus C_2 = 10 \oplus 21 = 31$；
- `(3,1)`：$R_3 \oplus C_1 = 30 \oplus 0 = 30$。
