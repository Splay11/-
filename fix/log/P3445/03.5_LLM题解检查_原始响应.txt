## 解题思路

1. 初始方格表所有格子均为 $0$。每次行操作可将第 $i$ 行全部异或上行密钥 $a_i$；每次列操作可将第 $j$ 列全部异或上列密钥 $b_j$。  
   设 $r_i \in \{0,1\}$ 表示第 $i$ 行是否被操作了奇数次，$c_j \in \{0,1\}$ 表示第 $j$ 列是否被操作了奇数次。  
   则任意格子 $(i,j)$ 的最终值为：
   $$
   \text{ans}(i,j) = (r_i \cdot a_i) \oplus (c_j \cdot b_j)
   $$
   其中 $(r_i \cdot a_i)$ 表示当 $r_i=1$ 时取 $a_i$，否则取 $0$；列部分同理。

2. 对角线上的同标格 $(i,i)$ 给出已知值 $d_i$，即：
   $$
   d_i = (r_i \cdot a_i) \oplus (c_i \cdot b_i)
   $$
   因为 $a_i$ 互不相同、$b_i$ 互不相同且均为正，集合 $\{0,\ a_i,\ b_i,\ a_i \oplus b_i\}$ 中的四个值两两不同。  
   因此，根据 $d_i$ 的取值可以唯一确定 $(r_i, c_i)$：
   - $d_i = 0$：$(r_i,c_i) = (0,0)$
   - $d_i = a_i$：$(r_i,c_i) = (1,0)$
   - $d_i = b_i$：$(r_i,c_i) = (0,1)$
   - $d_i = a_i \oplus b_i$：$(r_i,c_i) = (1,1)$

3. 确定所有 $r_i, c_i$ 后，预处理两个数组：
   - $R_i = r_i \cdot a_i$
   - $C_j = c_j \cdot b_j$
   回答任意查询 $(u,v)$ 时，直接输出 $R_u \oplus C_v$ 即可。

## 复杂度分析

- 时间复杂度：预处理需要遍历 $1 \sim n$，每次常数时间；回答 $q$ 次询问每次 $O(1)$。总复杂度 $O(n + q)$。
- 空间复杂度：需要存储行密钥、列密钥、同标格值以及 $R$、$C$ 数组，均为 $O(n)$。

## 代码实现

### Python

```python
import sys

def main():
    data = list(map(int, sys.stdin.read().strip().split()))
    it = iter(data)
    n = next(it)
    q = next(it)

    a = [0] * (n + 1)
    b = [0] * (n + 1)
    d = [0] * (n + 1)

    for i in range(1, n + 1):
        a[i] = next(it)
    for i in range(1, n + 1):
        b[i] = next(it)
    for i in range(1, n + 1):
        d[i] = next(it)

    R = [0] * (n + 1)
    C = [0] * (n + 1)

    for i in range(1, n + 1):
        ai = a[i]
        bi = b[i]
        di = d[i]
        if di == 0:
            R[i] = 0
            C[i] = 0
        elif di == ai:
            R[i] = ai
            C[i] = 0
        elif di == bi:
            R[i] = 0
            C[i] = bi
        else:          # 必为 ai ^ bi
            R[i] = ai
            C[i] = bi

    out = []
    for _ in range(q):
        u = next(it)
        v = next(it)
        out.append(str(R[u] ^ C[v]))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```

import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sbAll = new StringBuilder();
        String line;
        while ((line = br.readLine()) != null) {
            sbAll.append(line).append(' ');
        }
        StringTokenizer st = new StringTokenizer(sbAll.toString());

        int n = Integer.parseInt(st.nextToken());
        int q = Integer.parseInt(st.nextToken());

        int[] a = new int[n + 1];
        int[] b = new int[n + 1];
        int[] d = new int[n + 1];

        for (int i = 1; i <= n; i++) a[i] = Integer.parseInt(st.nextToken());
        for (int i = 1; i <= n; i++) b[i] = Integer.parseInt(st.nextToken());
        for (int i = 1; i <= n; i++) d[i] = Integer.parseInt(st.nextToken());

        int[] R = new int[n + 1];
        int[] C = new int[n + 1];

        for (int i = 1; i <= n; i++) {
            int ai = a[i], bi = b[i], di = d[i];
            if (di == 0) {
                R[i] = 0;
                C[i] = 0;
            } else if (di == ai) {
                R[i] = ai;
                C[i] = 0;
            } else if (di == bi) {
                R[i] = 0;
                C[i] = bi;
            } else { // 必为 ai ^ bi
                R[i] = ai;
                C[i] = bi;
            }
        }

        StringBuilder out = new StringBuilder();
        for (int k = 0; k < q; k++) {
            int u = Integer.parseInt(st.nextToken());
            int v = Integer.parseInt(st.nextToken());
            out.append(R[u] ^ C[v]).append('\n');
        }
        System.out.print(out.toString());
    }
}
