# 题目内容
小歪正在处理一种用竖线 `|` 划分的文本。文本被竖线分成若干节，每节内部仅由小写字母和短横线 `-` 构成。例如，`|ab-c|d--|` 包含两个节。

现在需要生成一个延迟同步的版本：给定一个非负整数 $p$，对于每个节，在其开头插入 $p$ 个下划线 `_`，然后从这个新串中截取与原节等长的前缀，多余部分丢弃。最后，将每个处理后的节用竖线包裹，并按照原行的顺序输出。

例如，原文本 `|do-do-re|re--|`，节长度分别为 $8$ 和 $5$。当 $p=2$ 时，第一个节 `do-do-re` 前插入两个下划线得到 `__do-do-re`，截取前 $8$ 个字符得到 `__do-do-`；第二个节 `re--` 插入两个下划线得到 `__re--`，截取前 $5$ 个字符得到 `__re-`，最终输出 `|__do-do-|__re-|`。

请你实现这一过程。

约束：
- 原始文本总字符数 $n$（包含竖线）满足 $1 \le n \le 3 \times 10^5$。
- 延迟长度 $p$ 满足 $0 \le p \le 10^9$。
- 输入仅包含竖线 `|`、小写字母 `a`-`z` 和短横线 `-`。每个节的长度至少为 $1$。

# 输入描述
第一行包含两个整数 $n$ 和 $p$，分别表示原始文本的总字符数和延迟长度。
接下来的若干行，总字符数为 $n$，代表原文本。保证每行均以竖线 `|` 开始并以竖线 `|` 结束，行内字符仅由小写字母和短横线 `-` 组成。

# 输出描述
输出若干行，表示处理后的文本，每行同样以竖线 `|` 开始并以竖线 `|` 结束，行数与输入一致。

## 样例1

**输入**

```
7 0
|a-b|c|
```

**输出**

```
|a-b|c|
```

**说明**

当 $p=0$ 时，不需要插入下划线，截取前缀后每个节保持不变。原文本有 `2` 个节，长度分别为 `3` 和 `1`，处理后均不变，因此输出与原文本相同。

## 样例2

**输入**

```
6 10
|xy|z|
```

**输出**

```
|__|_|
```

**说明**

原文本包含两个节：`xy`（长度 `2`）和 `z`（长度 `1`）。延迟长度 $p=10$ 大于每个节的长度。

对于节 `xy`，前插 $10$ 个下划线后得到 `__________xy`，截取前 `2` 个字符，结果为 `__`。
对于节 `z`，前插 $10$ 个下划线得到 `__________z`，截取前 `1` 个字符，结果为 `_`。
最终用竖线包裹后得到 `|__|_|`。

## 样例3

**输入**

```
14 3
|ab|c|de|
|fgh|
```

**输出**

```
|__|_|__|
|___|
```

**说明**

输入包含两行。第一行有 `3` 个节：`ab`（长度 `2`）、`c`（长度 `1`）、`de`（长度 `2`）。第二行有 `1` 个节：`fgh`（长度 `3`）。延迟长度 $p=3$。

对于长度 `2` 的节 `ab` 和 `de`，插入 $3$ 个下划线后变为 `___ab` 和 `___de`，截取前 `2` 个字符均得到 `__`。
对于长度 `1` 的节 `c`，插入后变为 `___c`，截取前 `1` 个字符得到 `_`。
对于长度 `3` 的节 `fgh`，插入后变为 `___fgh`，截取前 `3` 个字符得到 `___`。
因此第一行输出 `|__|_|__|`，第二行输出 `|___|`，与输入行数保持一致。

## 样例4

**输入**

```
18 1
|do-re|mi-|fa|sol|
```

**输出**

```
|_do-r|_mi|_f|_so|
```

**说明**

原文本包含 `4` 个节：`do-re`（长度 `5`）、`mi-`（长度 `3`）、`fa`（长度 `2`）、`sol`（长度 `3`）。延迟长度 $p=1$。

每个节前插 `1` 个下划线后截取原长度：
- `_do-re` 截前 `5` 得 `_do-r`；
- `_mi-` 截前 `3` 得 `_mi`；
- `_fa` 截前 `2` 得 `_f`；
- `_sol` 截前 `3` 得 `_so`。
处理后的各节用竖线拼接，最终输出 `|_do-r|_mi|_f|_so|`。
