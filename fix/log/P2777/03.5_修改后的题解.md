## 解题思路

本题的目标是对输入文本中的每一“节”进行延迟填充处理，并输出相同行数的结果。每一行文本由竖线`|`包裹，内部各节由竖线分隔。算法步骤如下：

1. 读取第一行的两个整数 $n$ 和 $p$，分别表示原始文本总字符数和延迟长度。
2. 后续按行读取剩余的文本，每行保证以竖线开头和结尾。对于每一行：
   - 去掉首尾的竖线，得到中间部分。
   - 按照竖线`|`对中间部分进行分割，得到该行的所有节（由于每节长度至少为1，不会出现空节）。
   - 对每个节单独处理，生成新的节：
     - 设原节长度为 $L$。
     - 在原节的开头插入 $p$ 个下划线`_`，形成临时字符串。
     - 从临时字符串中截取前 $L$ 个字符作为新节，多余部分直接丢弃。
     - 这等价于：
       - 若 $p \ge L$：新节完全由 $L$ 个下划线组成。
       - 若 $p < L$：新节由 $p$ 个下划线后拼接原节的前 $L-p$ 个字符组成。
   - 将所有新节用竖线`|`连接，并在首尾分别加上一个竖线，形成处理后的完整行。
3. 每处理完一行立即输出，行数与输入保持一致。

该方法只需对字符串进行单次扫描和简单的字符串构建，与 $n$ 成正比。

## 复杂度分析

- **时间复杂度**：每个输入字符仅被读取、分割和拼接一次，总时间复杂度为 $O(n)$，其中 $n$ 是输入文本的总字符数。
- **空间复杂度**：需要存储当前行的字符串以及构建结果，额外的辅助空间与行长度相关，总体为 $O(n)$。

## 代码实现

### Python

```python
import sys

def main():
    data = sys.stdin.read().splitlines()
    if not data:
        return
    n, p = map(int, data[0].split())
    
    # 处理后续的每一行
    for i in range(1, len(data)):
        line = data[i].strip()
        if not line:
            continue
        
        # 去掉首尾的 '|'
        inner = line[1:-1]
        # 按 '|' 分割得到每个节
        sections = inner.split('|')
        result_parts = []
        
        for sec in sections:
            L = len(sec)
            if p >= L:
                # 延迟长度大于等于节长度，全部为下划线
                result_parts.append('_' * L)
            else:
                # 前面 p 个下划线，后面接原节前 L-p 个字符
                result_parts.append('_' * p + sec[:L - p])
        
        # 组装输出
        print('|' + '|'.join(result_parts) + '|')

if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long p = sc.nextLong();
        sc.nextLine(); // 吸收第一行换行符
        
        while (sc.hasNextLine()) {
            String line = sc.nextLine().trim();
            if (line.isEmpty()) continue;
            
            // 去掉首尾竖线
            String inner = line.substring(1, line.length() - 1);
            String[] sections = inner.split("\\|");
            StringBuilder sb = new StringBuilder("|");
            
            for (int i = 0; i < sections.length; i++) {
                String sec = sections[i];
                int L = sec.length();
                if (p >= L) {
                    for (int j = 0; j < L; j++) {
                        sb.append('_');
                    }
                } else {
                    for (int j = 0; j < p; j++) {
                        sb.append('_');
                    }
                    sb.append(sec, 0, (int)(L - p));
                }
                if (i < sections.length - 1) {
                    sb.append('|');
                }
            }
            sb.append('|');
            System.out.println(sb.toString());
        }
        sc.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n;
    long long p;
    cin >> n >> p;
    cin.ignore(); // 忽略换行符
    
    string line;
    while (getline(cin, line)) {
        if (line.empty()) continue;
        
        // 去掉首尾的 '|'
        string inner = line.substr(1, line.size() - 2);
        vector<string> sections;
        size_t start = 0, end;
        while ((end = inner.find('|', start)) != string::npos) {
            sections.push_back(inner.substr(start, end - start));
            start = end + 1;
        }
        sections.push_back(inner.substr(start)); // 最后一段
        
        string result = "|";
        for (size_t i = 0; i < sections.size(); ++i) {
            const string& sec = sections[i];
            int L = (int)sec.size();
            if (p >= L) {
                result.append(L, '_');
            } else {
                result.append(p, '_');
                result.append(sec.substr(0, L - p));
            }
            if (i < sections.size() - 1) {
                result += '|';
            }
        }
        result += '|';
        cout << result << '\n';
    }
    
    return 0;
}
```
