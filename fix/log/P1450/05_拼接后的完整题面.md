# 题目内容
一条乐谱由 $n$ 个音符组成，用长度为 $n$ 的小写字母串 $s$ 表示。演奏者初始能量为 $k$。从第 `2` 个音符开始，每前进一格消耗的能量等于相邻两个字符的 ASCII 码之差 $s_i - s_{i-1}$（若差值为负，则表示恢复相应能量）。

能量一旦变成负数，演奏立即失败。请计算完整奏完后的剩余能量；若中途失败，输出 `-1`。

音符个数与初始能量均不超过 `10^5`。

# 输入描述
第一行两个整数 $n$ 和 $k$（$1 \le n, k \le 10^5$），分别表示音符个数与初始能量。
第二行一个长度为 $n$ 的小写英文字母串 $s$。

# 输出描述
输出一个整数：若能奏完，输出剩余能量；否则输出 `-1`。

## 样例1

**输入**

```
2 1
az
```

**输出**

```
-1
```

**说明**

从 `a` 到 `z` 的 ASCII 码差为 `25`，能量变为 $1-25<0$，演奏失败，输出 `-1`。

## 样例2

**输入**

```
3 1
cba
```

**输出**

```
3
```

**说明**

从 `c` 到 `b` 差为 `-1`，能量变为 `2`；再从 `b` 到 `a` 差为 `-1`，能量变为 `3`。全程非负，输出 `3`。

## 样例3

**输入**

```
1 5
z
```

**输出**

```
5
```

**说明**

只有一个音符，不发生转移，剩余能量仍为 `5`。这是 $n=1$ 的边界情况。
