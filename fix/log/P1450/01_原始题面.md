# 题目描述

塔子哥又在打游戏了。

这款游戏有$n$个关卡，塔子哥必须从第一个关卡开始，逐关打通到第$n$关，才能获得胜利。

塔子哥初始有$k$点血，每关的Boss有$a_i$点血(以字符形式呈现)。由于塔子哥点了秘技，打赢第$a_{i+1}$个Boss消耗的血量将会是$a_{i+1}-a_i$(如果为负，那么塔子哥会恢复$a_i-a_{i+1}$的血)。同时，塔子哥只有降到0血以下时，才会失败。

塔子哥想知道，当他打完$n$关时，还剩多少血？如果塔子哥无法通关，请输出$-1$。

# 输入描述

第一行两个整数$n,k(1≤n,k≤10^5)$。

第二行一个长度为$n$字符串s。

# 输出描述

一行一个整数，表示他的剩余体力值。若无法走到，则输出-1。

# 示例1

**输入**

```
3 2
aaa
```

**输出**

```
2
```

**说明**

塔子哥开始在第一关，挑战第二关时，消耗体力为0。

在第二关挑战第三关时，消耗体力为0。

最终剩余2点体力。
