## 解题思路

本题与「音程耗能」描述的计算任务一致。按输入格式读入数据后，沿用原题解的算法即可。

详见下方代码实现。

## 复杂度分析

- 时间复杂度与原题解相同。
- 空间复杂度与原题解相同。

## 代码实现

### Python

```python
n, k = input().strip().split(" ")
n = int(n)
s = input()
k = int(k)

for i in range(1, len(s)):
    k -= int(ord(s[i]) - ord(s[i - 1]))
    if k < 0:
        break

if k < 0:
    print(-1)
else:
    print(k)
```

#include <iostream>
#include <cstdio>

int n,k;
string s;

	cin>>n>>k;
	cin>>s;
	for(int i=1;i<s.length();i++){

		if(k<0) break;
	}
