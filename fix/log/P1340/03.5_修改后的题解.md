## 解题思路

把每个 `XX:XX` 时刻换成从当天 `00:00` 起经过的分钟数：若小时为 $h$、分钟为 $m$，则对应值为 $h\times 60+m$。当前时刻同样换算成分钟数 $t$。

将所有发车时刻按分钟数升序排序后，找到第一个严格大于 $t$ 的时刻即可。由于保证当天内一定还有未发出的班次，这个位置一定存在，不必考虑跨日。

也可以不排序，直接扫描所有班次，在大于 $t$ 的时刻中取分钟数最小者。

## 复杂度分析

排序后二分（或线性扫描）定位下一班。

- 时间复杂度：$O(n\log n)$。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
import sys
from bisect import bisect_left

input = sys.stdin.readline


def get_minutes(s):
    hours, minutes = [int(x) for x in s.split(':')]
    return hours * 60 + minutes


cur = get_minutes(input().strip())
data = []
n = int(input())
for _ in range(n):
    s = input().strip()
    data.append((get_minutes(s), s))
data.sort()
i = bisect_left(data, (cur + 1, ))
print(data[i][-1])
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static int Tim;
    public static int n;
    public static int ans = 1440;
    public static char[] s = new char[10];
    public static char[] out = new char[10];

    public static int get() {
        int number = 0, tmp = 0;
        for (int i = 1; i <= 5; ++i) {
            if (s[i] >= '0' && s[i] <= '9') {
                number = number * 10 + s[i] - '0';
            } else if (s[i] == ':') {
                tmp = number * 60;
                number = 0;
            }
        }
        return tmp + number;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String input = scanner.next();
        for (int i = 0; i < input.length(); i++) {
            s[i + 1] = input.charAt(i);
        }
        Tim = get();
        n = scanner.nextInt();
        for (int i = 1, tmp; i <= n; ++i) {
            input = scanner.next();
            for (int j = 0; j < input.length(); j++) {
                s[j + 1] = input.charAt(j);
            }
            tmp = get();
            if (tmp > Tim && tmp - Tim < ans) {
                ans = tmp - Tim;
                for (int j = 1; j <= 5; ++j) {
                    out[j] = s[j];
                }
            }
        }
        for (int i = 1; i <= 5; ++i) {
            System.out.print(out[i]);
        }
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int time;
    string clock;
};

int strToInt(string& str) {
    int h = (str[0] - '0') * 10 + (str[1] - '0');
    int min = (str[3] - '0') * 10 + (str[4] - '0');
    return h * 60 + min;
}

int main() {
    string str;
    cin >> str;
    int curt = strToInt(str);
    int n;
    cin >> n;
    vector<Node> nums(n);
    for (int i = 0; i < n; i++) {
        cin >> nums[i].clock;
        nums[i].time = strToInt(nums[i].clock);
    }
    sort(nums.begin(), nums.end(), [&](const Node& A, const Node& B) {
        return A.time < B.time;
    });
    string ans;
    for (auto x : nums) {
        if (x.time > curt) {
            ans = x.clock;
            break;
        }
    }
    cout << ans;
    return 0;
}
```
