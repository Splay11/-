# 题目内容
一条流水线上有 $n$ 个连续工位，第 $i$ 个工位的偏差值为 $a_i$（可以为负）。整条流水线的总偏差 $S$ 定义为所有 $a_i$ 之和。

需要判断是否存在一对整数 $l,r$ 满足 $1 \le l \le r \le n$，且区间 $[l,r]$ 不是整段 $[1,n]$，使得该区间内偏差值之和大于等于 $S$。

输入包含多组测试。若存在这样的区间，输出 `Yes`；否则输出 `No`。

约束：测试组数不超过 `5`。每组工位数量至少为 `3` 且不超过 $5 \times 10^4$。每个偏差值的绝对值不超过 `100`。

# 输入描述
第一行包含一个整数 $T$，表示测试组数。
接下来有 $T$ 组数据。每组数据的第一行包含一个整数 $n$，表示工位数量；第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$，依次表示各工位的偏差值。
保证 $1 \le T \le 5$，$3 \le n \le 5 \times 10^4$，$-100 \le a_i \le 100$。

# 输出描述
对于每一组测试数据，输出一行：若存在满足条件的区间，输出 `Yes`；否则输出 `No`。

## 样例1

**输入**

```
1
4
1 2 3 4
```

**输出**

```
No
```
