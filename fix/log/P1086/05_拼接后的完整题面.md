# 题目内容
机房里有 $n$ 行 $m$ 列设备格点，格子 $(i,j)$ 上的端口频点为 $a_{i,j}$。运维从左上角走到右下角，每一步可以走到上、下、左、右相邻格子，耗时为两格频点差的绝对值。

此外至多使用一次同频跳线：从某个格子瞬间转移到另一个频点相同的格子，这次转移不耗时。跳线全图限用一次。

请计算从左上角走到右下角的最少耗时。

约束：$1 \le n,m \le 5 \times 10^{2}$，$1 \le a_{i,j} \le 1000000000$。

# 输入描述
第一行包含两个正整数 $n$ 和 $m$，表示网格的行数与列数，满足 $1 \le n,m \le 5 \times 10^{2}$。

接下来 $n$ 行，每行 $m$ 个正整数 $a_{i,j}$，满足 $1 \le a_{i,j} \le 1000000000$。

# 输出描述
输出一个整数，表示从左上角走到右下角的最少花费。

## 样例1

**输入**

```
2 3
4 8 4
9 1 7
```

**输出**

```
3
```

**说明**

第一行两端都是 `4`，可以一次跃迁从 $(1,1)$ 到达 $(1,3)$，再走到 $(2,3)$，花费 $|4-7|=3$。

不使用跃迁的路径花费更大。

## 样例2

**输入**

```
1 1
5
```

**输出**

```
0
```

**说明**

起点与终点重合，花费为 `0`。

## 样例3

**输入**

```
2 2
3 3
3 8
```

**输出**

```
5
```

**说明**

可以在三个 `3` 之间免费跃迁，最后一步从某个 `3` 走到 `8`，花费 $|3-8|=5$。

## 样例4

**输入**

```
3 4
10 20 30 40
11 21 5 41
12 5 6 7
```

**输出**

```
11
```

**说明**

网格中有两个 `5`，可在它们之间使用一次免费跃迁，再结合相邻格子的绝对差最短路，最少花费为 `11`。
