## 解题思路

同一通道内的草稿字符可以任意重排。要对账成功，等价于：对每个通道 $g \in \{0,1\}$，把该通道内 $s$ 的小写字母转成大写后得到的多重集合，必须与该通道内 $t$ 的多重集合完全相同。

对每组数据：

1. 按 $a_i$ 分成 `0` 通道与 `1` 通道。
2. 分别统计两组里 `26` 个字母的出现次数：$s$ 用 $s_i - \texttt{'a'}$ 映射，$t$ 用 $t_i - \texttt{'A'}$ 映射。
3. 两组 `26` 维频次数组都一致则输出 `Yes`，否则输出 `No`。

## 复杂度分析

统计与比较均为线性扫描。

- 时间复杂度：$O(n)$，总复杂度 $O(\sum n)$。
- 空间复杂度：$O(1)$（两个 $2 \times 26$ 的计数数组）。

## 代码实现

### Python

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    T = int(next(it))
    out = []
    for _ in range(T):
        n = int(next(it))
        a = [int(next(it)) for _ in range(n)]
        s = next(it).decode()
        t = next(it).decode()
        cntS = [[0] * 26 for _ in range(2)]
        cntT = [[0] * 26 for _ in range(2)]
        for i in range(n):
            g = a[i]
            si = ord(s[i]) - ord('a')
            ti = ord(t[i]) - ord('A')
            cntS[g][si] += 1
            cntT[g][ti] += 1
        ok = (cntS[0] == cntT[0]) and (cntS[1] == cntT[1])
        out.append("Yes" if ok else "No")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    static class FastIn {
        BufferedReader br;
        StringTokenizer st;
        FastIn(InputStream in) { br = new BufferedReader(new InputStreamReader(in)); }
        String next() throws IOException {
            while (st == null || !st.hasMoreElements()) {
                String line = br.readLine();
                if (line == null) return null;
                st = new StringTokenizer(line);
            }
            return st.nextToken();
        }
    }

    public static void main(String[] args) throws Exception {
        FastIn in = new FastIn(System.in);
        String tok = in.next();
        if (tok == null) return;
        int T = Integer.parseInt(tok);
        StringBuilder sb = new StringBuilder();
        while (T-- > 0) {
            int n = Integer.parseInt(in.next());
            int[] a = new int[n];
            for (int i = 0; i < n; i++) a[i] = Integer.parseInt(in.next());
            String s = in.next();
            String t = in.next();
            int[][] cntS = new int[2][26];
            int[][] cntT = new int[2][26];
            for (int i = 0; i < n; i++) {
                int g = a[i];
                int si = s.charAt(i) - 'a';
                int ti = t.charAt(i) - 'A';
                cntS[g][si]++;
                cntT[g][ti]++;
            }
            boolean ok = true;
            for (int g = 0; g < 2 && ok; g++) {
                for (int c = 0; c < 26; c++) {
                    if (cntS[g][c] != cntT[g][c]) { ok = false; break; }
                }
            }
            sb.append(ok ? "Yes" : "No").append('\n');
        }
        System.out.print(sb.toString());
    }
}
```
