# 题目内容
有长度为 $n$ 的草稿串 $s$（仅含小写字母）、台账串 $t$（仅含大写字母），以及长度为 $n$ 的通道标记数组 $a$（每个 $a_i$ 只能是 `0` 或 `1`）。

对任意两个不同下标 $i < j$，若 $a_i = a_j$，则允许交换 $s$ 中下标 $i$ 与 $j$ 的字符。也就是说，同一通道内的草稿字符可以任意重排。

若可以通过上述交换，使得对所有位置都有 $t_i$ 恰好是 $s_i$ 对应的大写字母，则称对账成功。请判断能否对账成功。

约束：测试组数不超过 `10^4`，单组长度不超过 `2×10^5`，且单个测试文件中长度之和不超过 `2×10^5`。

# 输入描述
每个测试文件包含多组数据。第一行一个整数 $T$，表示数据组数。
每组数据格式如下：
第一行一个整数 $n$，表示长度；
第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$，每个为 `0` 或 `1`；
第三行一个长度为 $n$ 的小写字母字符串 $s$；
第四行一个长度为 $n$ 的大写字母字符串 $t$。
保证 $1 \le T \le 10^4$，$1 \le n \le 2 \times 10^5$，且单个文件中 $n$ 之和不超过 $2 \times 10^5$。

# 输出描述
对每组数据输出一行。若可以对账成功，输出 `Yes`；否则输出 `No`。

## 样例1

**输入**

```
2
6
0 1 0 1 0 1
abccba
CAACBB
3
0 0 1
abc
AAC
```

**输出**

```
Yes
No
```

**说明**

第一组通道 `0` 的位置为 $1,3,5$，草稿大写后为 $\{A,C,B\}$，台账为 $\{C,A,B\}$，多重集合相同；通道 `1` 同样匹配，输出 `Yes`。
第二组通道 `0` 的位置为 $1,2$，草稿大写后为 $\{A,B\}$，台账为 $\{A,A\}$，不一致，输出 `No`。

## 样例2

**输入**

```
1
1
0
a
A
```

**输出**

```
Yes
```

**说明**

只有一个位置，通道为 `0`。草稿 `a` 对应大写正好是 `A`，无需交换，输出 `Yes`。这是 $n=1$ 的边界。

## 样例3

**输入**

```
1
2
1 1
ab
BA
```

**输出**

```
Yes
```

**说明**

两个位置同属通道 `1`，可以互换。草稿 $\{a,b\}$ 大写后为 $\{A,B\}$，与台账 `BA` 的多重集合相同，输出 `Yes`。

## 样例4

**输入**

```
1
4
0 0 0 0
abcd
DCBA
```

**输出**

```
Yes
```

**说明**

全部位置同属通道 `0`，草稿可任意重排。$\{A,B,C,D\}$ 与台账 `DCBA` 一致，输出 `Yes`。
