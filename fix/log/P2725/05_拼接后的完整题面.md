# 题目内容
在信号处理任务中，需要将两个等长的字符串 $A$ 和 $B$ 按位置合成为一个结果字符串。首先定义字符的类别：小写字母归为 $\alpha$ 类，大写字母归为 $\beta$ 类，数字归为 $\gamma$ 类；其余字符归为 $\omega$ 类（无关类）。对任意两个字符 $x, y$，记 $\operatorname{code}(x)$ 为其 ASCII 码整数值，定义它们的中位码值为 $\lceil (\operatorname{code}(x) + \operatorname{code}(y)) / 2 \rceil$，其中 $\lceil \cdot \rceil$ 表示向上取整。对于每个位置 $i = 1, 2, \dots, n$，按以下规则生成结果序列的第 $i$ 个字符块：
- 若 $A[i]$ 和 $B[i]$ 的类别均不是 $\omega$ 且类别相同，则输出中位码值对应的 ASCII 字符；
- 若 $A[i]$ 和 $B[i]$ 的类别均不是 $\omega$ 但类别不同，则直接将该中位码值的十进制表示拼接在后面（例如中位码值为 `84` 时输出字符串 `84`）；
- 否则，输出一个下划线 `_`。
最终将所有位置的输出拼接得到完整的结果字符串。

数据约束：字符串长度 $n$ 满足 $1 \le n \le 3 \times 10^5$。字符串 $A$ 和 $B$ 仅由数字、大小写字母、空格以及 `!?.+-*/` 七个半角符号构成，且保证字符串的首字符和尾字符均不为空格。

# 输入描述
第一行输入一个整数 $n$ ($1 \le n \le 3 \times 10^5$)，代表字符串的长度。
第二行输入一个长度为 $n$ 的字符串 $A$。
第三行输入一个长度为 $n$ 的字符串 $B$。
字符串中仅包含数字、大小写字母、空格以及 `!?.+-*/` 七个符号，且不会以空格开头或结尾。

# 输出描述
输出一行一个字符串，表示按规则生成的结果。

## 样例1

**输入**

```
5
aA1!b
bB2?c
```

**输出**

```
bB2_c
```

**说明**

位置 $1$：`a` 和 `b` 均为 $\alpha$ 类，均非 $\omega$ 且类别相同，中位码值 $\lceil (97+98)/2 \rceil = 98$，对应 ASCII 字符 `b`。
位置 $2$：`A` 和 `B` 均为 $\beta$ 类，$\lceil (65+66)/2 \rceil = 66$，对应 `B`。
位置 $3$：`1` 和 `2` 均为 $\gamma$ 类，$\lceil (49+50)/2 \rceil = 50$，对应 `2`。
位置 $4$：`!` 和 `?` 均为 $\omega$ 类，输出 `_`。
位置 $5$：`b` 和 `c` 均为 $\alpha$ 类，$\lceil (98+99)/2 \rceil = 99$，对应 `c`。
按位置拼接后得到 `bB2_c`。

## 样例2

**输入**

```
4
a1B!
A2c?
```

**输出**

```
81283_
```

**说明**

位置 $1$：`a`($\alpha$) 与 `A`($\beta$) 类别不同且均非 $\omega$，中位码值 $\lceil (97+65)/2 \rceil = 81$，输出其十进制表示为 `81`。
位置 $2$：`1`($\gamma$) 与 `2`($\gamma$) 类别相同，$\lceil (49+50)/2 \rceil = 50$，对应字符 `2`。
位置 $3$：`B`($\beta$) 与 `c`($\alpha$) 类别不同，$\lceil (66+99)/2 \rceil = 83$，输出 `83`。
位置 $4$：`!` 和 `?` 均为 $\omega$ 类，输出 `_`。
最终结果为 `81283_`。

## 样例3

**输入**

```
1
a
B
```

**输出**

```
82
```

**说明**

长度 $n=1$。`a` 为 $\alpha$ 类，`B` 为 $\beta$ 类，均非 $\omega$ 但类别不同。中位码值 $\lceil (97+66)/2 \rceil = \lceil 81.5 \rceil = 82$，输出字符串 `82`。
