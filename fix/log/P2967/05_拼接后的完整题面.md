# 题目内容
你在分析一批实验样本，每个样本记录了若干个数值型观测指标和一个类别标签。现在你想找出哪一个观测指标对样本类别的区分效果最好。为此定义一种衡量标准：

对于任意一个样本集合 $S$，定义它的类别混杂度（Mixing Degree）为
$$H(S)=1-\sum_{c\in C}\left(\frac{|S_c|}{|S|}\right)^2$$
其中 $C$ 是所有可能类别的集合，$S_c$ 是 $S$ 中类别为 $c$ 的样本子集，$|\cdot|$ 表示集合的大小。

对于第 $j$ 个观测指标（$j$ 从 $0$ 开始编号），按该指标的取值将全部样本分组，具有相同取值的样本分到同一组。记分组后的组集合为 $\mathcal{G}_j$，则该观测指标的加权平均混杂度定义为
$$H_j=\sum_{G\in\mathcal{G}_j}\frac{|G|}{n}\,H(G)$$
其中 $n$ 为样本总数。

请计算使得 $H_j$ 最小的观测指标索引 $j$，并输出该索引及对应的 $H_j$（四舍五入保留一位小数）。如果有多个指标取得相同的最小加权平均混杂度，输出索引最小的那一个。

**约束条件**：
- 样本总数 $n$ 不超过 $2000$。
- 观测指标个数 $m$ 不超过 $100$。
- 每个观测值均为实数，绝对值不超过 $10^4$。
- 标签为长度不超过 $50$ 的字符串，类别总数不超过 $1000$。
- 保证至少有一条样本，且每条样本至少包含一个观测指标和一个标签。

# 输入描述
输入只有一行，包含一个二维列表，表示数据集。二维列表的每个内层列表代表一条样本，内层列表的前若干项为数值型观测值，最后一项为字符串标签。你可以使用与 `eval(input())` 等价的方式读取该二维列表。

# 输出描述
输出一个元组，格式为 `(索引, 最小加权平均混杂度)`，其中索引是从 `0` 开始的整数，最小加权平均混杂度四舍五入保留一位小数。

## 样例1

**输入**

```
[[1.0, 20.0, 'A'], [1.0, 30.0, 'B'], [2.0, 40.0, 'A']]
```

**输出**

```
(1, 0.0)
```

**说明**

样本总数 $n = 3$，特征数 $m = 2$。

对于索引 `0` 的特征：取值有 $1.0$ 和 $2.0$。取 $1.0$ 的样本有 `2` 个，标签为 `A` 和 `B`，混杂度 $H = 1 - (1/2)^2 - (1/2)^2 = 0.5$。取 $2.0$ 的样本有 `1` 个，标签为 `A`，混杂度 $0$。加权平均 $H_0 = \frac{2}{3} \times 0.5 + \frac{1}{3} \times 0 = 0.333...$，四舍五入保留一位小数为 $0.3$。

对于索引 `1` 的特征：取值 $20, 30, 40$ 均不相同，每组只有 `1` 个样本，混杂度均为 $0$，加权平均 $H_1 = 0.0$。

$H_1$ 最小，因此输出 `(1, 0.0)`。

## 样例2

**输入**

```
[[10.0, 1.0, 'x'], [20.0, 2.0, 'y'], [30.0, 3.0, 'x']]
```

**输出**

```
(0, 0.0)
```

**说明**

样本总数 $n = 3$，特征数 $m = 2$。

特征 `0` 的取值 $10, 20, 30$ 均不同，每组样本数均为 `1`，混杂度均为 $0$，故 $H_0 = 0.0$。

特征 `1` 的取值 $1, 2, 3$ 也均不同，同理 $H_1 = 0.0$。

两者均为最小值 $0.0$，根据规则「如果有多个指标取得相同的最小加权平均混杂度，输出索引最小的那一个」，选择索引 `0`。输出 `(0, 0.0)`。

## 样例3

**输入**

```
[[3.14, 'ok']]
```

**输出**

```
(0, 0.0)
```

**说明**

仅有一个样本，特征数为 $1$。该特征取值为 $3.14$，只分一组，组内仅有一个类别 `ok`。

混杂度 $H = 1 - \left(\frac{1}{1}\right)^2 = 0.0$，加权平均 $H_0 = 0.0$。因此输出 `(0, 0.0)`。
