# 题目内容
市立实验室要把 $n$ 种待展试剂瓶排成一列，供参观通道两侧陈列。每种试剂有唯一编号，分别为 `1` 到 $n$，且必须各出现一次。安全手册规定：若相邻两瓶编号之和为素数，会在展示柜内引发不稳定反应，因此这样的排列一律禁止。请统计有多少种合法排列。

约束：$n$ 为正整数，且 $2 \le n \le 10$。

# 输入描述
输入一行一个正整数 $n$，表示试剂种数，满足 $2 \le n \le 10$。

# 输出描述
输出一个整数，表示合法排列的数量。

## 样例1

**输入**

```
2
```

**输出**

```
0
```

**说明**

$n=`2`$ 时只有两种排列：`1 2` 与 `2 1`。相邻和均为 `3`，而 `3` 是素数，因此合法排列数为 `0`。

## 样例2

**输入**

```
5
```

**输出**

```
4
```

**说明**

$n=`5`$ 时共有 $5!=`120`$ 种排列。枚举后可知，只有 `4` 种排列满足每一对相邻编号之和都不是素数。

## 样例3

**输入**

```
6
```

**输出**

```
24
```

**说明**

$n=`6`$ 时相邻两数之和最大为 `11`，仍落在 `20` 以内的素数表中。枚举全部 $6!$ 种排列，合法者有 `24` 种。

## 样例4

**输入**

```
8
```

**输出**

```
1164
```

**说明**

$n=`8`$ 时仍可用全排列枚举。相邻和不超过 `15`，素数判定范围不变，得到合法排列 `1164` 种。
