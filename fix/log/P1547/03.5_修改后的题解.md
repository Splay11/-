## 解题思路

$n$ 最大只有 $10$，可以直接枚举 $1$ 到 $n$ 的全部排列。对每个排列检查每一对相邻编号之和是否为素数：相邻两数之和不超过 $19$，因此只需对照 $20$ 以内的素数表 $\{2,3,5,7,11,13,17,19\}$。若所有相邻和都不在表中，则该排列合法，答案加一。

## 复杂度分析

时间复杂度 $O(n\cdot n!)$，空间复杂度 $O(n)$。

## 代码实现

### Python

```python
from itertools import permutations

n = int(input())
a = list(range(1, n + 1))
pri = [2, 3, 5, 7, 11, 13, 17, 19]

ans = 0
for perm in permutations(a):
    ok = False
    for i in range(1, n):
        if perm[i - 1] + perm[i] in pri:
            ok = True
            break
    ans += not ok

print(ans)
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int[] a = new int[15];
        int[] pri = {2, 3, 5, 7, 11, 13, 17, 19};

        for (int i = 1; i <= n; i++) {
            a[i] = i;
        }

        int ans = 0;
        do {
            boolean ok = false;
            for (int i = 2; i <= n; i++) {
                for (int j = 0; j < 8; j++) {
                    if (a[i - 1] + a[i] == pri[j]) {
                        ok = true;
                    }
                }
            }
            ans += ok ? 0 : 1;
        } while (nextPermutation(a, 1, n));

        System.out.println(ans);
    }

    public static boolean nextPermutation(int[] a, int left, int right) {
        int i = right;
        while (i > left && a[i - 1] >= a[i]) {
            i--;
        }
        if (i <= left) {
            return false;
        }

        int j = right;
        while (a[j] <= a[i - 1]) {
            j--;
        }

        int temp = a[i - 1];
        a[i - 1] = a[j];
        a[j] = temp;

        j = right;
        while (i < j) {
            temp = a[i];
            a[i] = a[j];
            a[j] = temp;
            i++;
            j--;
        }

        return true;
    }
}
```
