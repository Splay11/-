# 题目内容
魔法师获得了一串长度为 $n$ 的符文串 $s$，它仅由字符 `0`、`1` 和 `Z` 组成，同时得到一个长度为 $n$ 的整数能量数组 $a_1,a_2,\dots,a_n$。

我们称能量数组与符文串**匹配**，当且仅当对每个位置 $i$ ($1 \le i \le n$) 满足：
- 若符文 $s_i$ 为 `0`，则 $a_i \le 0$；
- 若符文 $s_i$ 为 `1`，则 $a_i \ge 0$；
- 若符文 $s_i$ 为 `Z`，则 $a_i = 0$，并且当 $1 < i < n$ 时，还需要额外满足 $a_{i-1} \times a_{i+1} \ge 0$（两端位置无此额外限制）。

魔法师可以将能量数组中的任意元素修改为任意整数，每次修改仅改变一个元素的值。请求出最少需要修改多少个元素，才能使修改后的能量数组与给定的符文串匹配。

**约束条件**：
- 符文串长度 $n$ 满足 $1 \le n < 2 \times 10^5$。
- 符文串 $s$ 仅由字符 `0`、`1`、`Z` 组成。
- 初始能量数组 $a_i$ 的绝对值不超过 $10^6$。

# 输入描述
第一行输入一个整数 $n$，表示符文串的长度。
第二行输入一个长度为 $n$ 的字符串 $s$，仅包含字符 `0`、`1`、`Z`。
第三行输入 $n$ 个整数 $a_1,a_2,\dots,a_n$，表示初始的能量数组。

# 输出描述
输出一个整数，表示最少需要修改的元素个数。

## 样例1

**输入**

```
1
0
10
```

**输出**

```
1
```

**说明**

符文串长度为 `1`，仅有一个字符 `0`，要求 $a_1 \le 0$。初始 $a_1 = 10 > 0$，不满足条件，必须将其修改为一个 $\le 0$ 的整数（例如 `0` 或负数），最少修改次数为 `1`。

## 样例2

**输入**

```
3
1Z0
2 0 -1
```

**输出**

```
1
```

**说明**

符文串为 `1Z0`，初始能量数组 $a = [2, 0, -1]$。

检查每个位置：
- $s_1 = 1$，要求 $a_1 \ge 0$，$a_1 = 2$ 满足；
- $s_2 = Z$，要求 $a_2 = 0$，已满足，且需额外满足 $a_1 \times a_3 \ge 0$。$a_1 \times a_3 = 2 \times (-1) = -2 < 0$，不满足；
- $s_3 = 0$，要求 $a_3 \le 0$，$a_3 = -1$ 满足。

为同时满足 $s_3$ 和 $s_2$ 的乘积约束，可将 $a_3$ 修改为 `0`。此时 $a_3 = 0 \le 0$ 满足 $s_3$，且 $a_1 \times a_3 = 2 \times 0 = 0 \ge 0$ 满足 $s_2$ 的额外条件。若修改 $a_1$ 则会导致其不满足 $s_1$。因此最少修改次数为 `1`。

## 样例3

**输入**

```
5
Z0Z1Z
0 1 0 -2 0
```

**输出**

```
2
```

**说明**

符文串 `Z0Z1Z`，初始数组 $[0, 1, 0, -2, 0]$。

检查各位置：
- $s_1 = Z$：$a_1 = 0$ 满足，无相邻乘积限制；
- $s_2 = 0$：要求 $a_2 \le 0$，但 $a_2 = 1 > 0$，不满足；
- $s_3 = Z$：$a_3 = 0$ 满足，但要求 $a_2 \times a_4 \ge 0$；
- $s_4 = 1$：要求 $a_4 \ge 0$，但 $a_4 = -2 < 0$，不满足；
- $s_5 = Z$：$a_5 = 0$ 满足，无额外限制。

$a_2$ 和 $a_4$ 均不满足自身符文要求，且 $a_2 \times a_4$ 需非负。
若只修改其中一个，另一个仍不合法；若都修改，还需保证乘积约束。
最优方案：将 $a_2$ 改为 `0`（满足 `0`），$a_4$ 改为 `0`（满足 `1`），乘积 $0 \times 0 = 0 \ge 0$ 满足 $s_3$ 的额外限制。共修改 `2` 次。因此答案为 `2`。
