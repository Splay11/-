## 解题思路

1. 记序列为 $a_1, a_2, \dots, a_m$，定义相邻差分为 $d_i = a_{i+1} - a_i$（$1 \le i < m$）。
2. 对于一个长度至少为 3 的子段，其内部位置 $a_i$（$l+1 \le i \le r-1$）满足条件：
   > $(a_i \le a_{i-1}$ 且 $a_i \le a_{i+1})$ 或 $(a_i \ge a_{i-1}$ 且 $a_i \ge a_{i+1})$
   
   这等价于“该位置为波峰或波谷（允许相邻相等）”。该条件用差分可表示为：
   > $d_{i-1} \times d_i \le 0$
3. 因此，一个原数组的子段 $a_l, a_{l+1}, \dots, a_r$（$r-l+1 \ge 3$）是 **理想波形段** 当且仅当它对应的差分区间 $d_l, d_{l+1}, \dots, d_{r-1}$ 中，任意相邻两个差分都满足乘积 $\le 0$。
4. 我们将问题转化为：在差分数组 $d_1, d_2, \dots, d_{m-1}$ 中，找出所有极长的、满足相邻乘积 $\le 0$ 的连续段。设某个极长段长度为 $s$（即包含 $s$ 个差分），那么该段内部任意长度至少为 $2$ 的连续差分子段都对应一个理想波形段。
5. 若一个差分子段长度为 $q$（$2 \le q \le s$），对应原数组子段长度为 $q+1$。该理想波形段内部满足条件的采样点个数恰好为 $(q+1)-2 = q-1$。
6. 该极长段产生的总贡献为：
   \[
   \sum_{q=2}^{s} (\text{长度为 } q \text{ 的差分子段个数}) \times (q-1) = \sum_{q=2}^{s} (s-q+1)(q-1)
   \]
   化简得：
   \[
   \frac{s(s-1)(s+1)}{6}
   \]
7. 算法流程：
   - 若 $m < 3$，直接输出 $0$。
   - 遍历 $i$ 从 $1$ 到 $m-2$（对应判断 $a_{i+1}$ 是否为内部满足条件的端点），计算 $d_1 = a_{i} - a_{i-1}$，$d_2 = a_{i+1} - a_i$。
   - 若 $d_1 \times d_2 \le 0$，则当前极长合法差分段长度 `cur` 增加 $1$；否则结算当前段贡献，`cur` 重置为 $1$。
   - 遍历结束后结算最后一段。
   - 所有贡献累加并对 $10^9+7$ 取模。

## 复杂度分析

- 时间复杂度：对于每组数据，只需扫描一次数组，复杂度为 $O(m)$。所有测试数据 $m$ 之和不超过 $200000$，总时间复杂度 $O(\sum m)$，可以高效运行。
- 空间复杂度：除了存储输入数组外，只使用了常数个临时变量，空间复杂度为 $O(m)$（若不计输入数组则为 $O(1)$）。

## 代码实现

### Python

```python
import sys

MOD = 10 ** 9 + 7

def calc(s: int) -> int:
    # 长度为 s 的合法差分段的贡献：s * (s - 1) * (s + 1) // 6
    return s * (s - 1) * (s + 1) // 6

def solve(m: int, a: list) -> int:
    if m < 3:
        return 0
    
    ans = 0
    cur = 1  # 当前极长合法差分段长度至少为1
    
    for i in range(1, m - 1):
        d1 = a[i] - a[i - 1]
        d2 = a[i + 1] - a[i]
        if d1 * d2 <= 0:
            cur += 1
        else:
            ans = (ans + calc(cur)) % MOD
            cur = 1
    
    ans = (ans + calc(cur)) % MOD
    return ans

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    t = data[0]
    idx = 1
    out_lines = []
    for _ in range(t):
        m = data[idx]
        idx += 1
        a = data[idx:idx + m]
        idx += m
        out_lines.append(str(solve(m, a)))
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    main()
```

import java.util.Scanner;

public class Main {
    static final long MOD = 1000000007L;

    static long calc(long s) {
        // 长度为 s 的合法差分段的贡献：s * (s - 1) * (s + 1) / 6
        return s * (s - 1) * (s + 1) / 6;
    }

    static long solve(int m, long[] a) {
        if (m < 3) {
            return 0;
        }

        long ans = 0;

        for (int i = 1; i < m - 1; i++) {
            long d1 = a[i] - a[i - 1];
            long d2 = a[i + 1] - a[i];

            if (d1 * d2 <= 0) {
                cur++;
            } else {
                ans = (ans + calc(cur)) % MOD;
                cur = 1;
            }
        }

        ans = (ans + calc(cur)) % MOD;
        return ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();
        StringBuilder sb = new StringBuilder();

        while (T-- > 0) {
            int m = sc.nextInt();
            long[] a = new long[m];
            for (int i = 0; i < m; i++) {
                a[i] = sc.nextLong();
            }
            sb.append(solve(m, a)).append('\n');
        }

        System.out.print(sb);
