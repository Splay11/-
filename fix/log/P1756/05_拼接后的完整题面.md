# 题目内容
产线侧有一块 $n$ 行 $m$ 列的质检面板，每个格子是字符 `0` 或 `1`。一次贴片必须覆盖同一行里相邻的两列（即 $1 \times 2$，不能选 $2 \times 1$），并把这两格都变成 `1`；本来就是 `1` 的格子保持为 `1`。贴片允许重叠。

请计算把面板上所有字符都变成 `1` 所需的最少贴片次数。

约束：$2 \le n,m \le 10^3$，矩阵仅由字符 `0` 和 `1` 组成。

# 输入描述
第一行包含两个正整数 $n$ 和 $m$，用空格隔开，表示行数与列数，满足 $2 \le n,m \le 10^3$。

接下来 $n$ 行，每行一个长度为 $m$ 的字符串，仅由字符 `0` 和 `1` 组成。

# 输出描述
输出一个整数，表示把所有字符变成 `1` 的最少操作次数。

## 样例1

**输入**

```
3 3
011
101
110
```

**输出**

```
3
```

**说明**

每一行独立处理：遇到尚未变成 `1` 的 `0` 就操作一次，并同时覆盖其右侧格子。

三行分别需要 `1`、`1`、`1` 次操作，合计 `3`。

## 样例2

**输入**

```
2 2
00
00
```

**输出**

```
2
```

**说明**

每一行两个 `0` 可以被一次 $1 \times 2$ 操作全部覆盖，两行共 `2` 次。

## 样例3

**输入**

```
2 3
111
111
```

**输出**

```
0
```

**说明**

面板已经全是 `1`，无需操作。

## 样例4

**输入**

```
3 5
01010
00100
11101
```

**输出**

```
6
```

**说明**

从左到右贪心覆盖后，三行分别需要 `3`、`2`、`1` 次操作，最少次数为 `6`。
