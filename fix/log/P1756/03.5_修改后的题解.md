## 解题思路

贴片只能覆盖同一行里的 $1\times 2$ 区域，因此每一行互相独立。

对每一行从左到右扫描：一旦遇到字符 `0`，必须立刻贴一次把它变成 `1`。贪心地同时覆盖它右侧的格子（若存在），这样能顺带消除后续可能的 `0`，次数最少。

若 `0` 落在该行最后一列，这次贴片与左侧已是 `1` 的格子组成 $1\times 2$，效果上只新涂这一格。

把所有行的贴片次数相加即为答案。

## 复杂度分析

时间复杂度 $O(nm)$，空间复杂度 $O(nm)$。

## 代码实现

### Python

```python
n, m = map(int, input().split())
s = [list(input().strip()) for _ in range(n)]
ans = 0
for i in range(n):
    for j in range(m):
        if s[i][j] == '0':
            ans += 1
            s[i][j] = '1'
            if j + 1 < m:
                s[i][j + 1] = '1'
print(ans)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        char[][] words = new char[n][m];
        for (int i = 0; i < n; i++) {
            String str = sc.next();
            words[i] = str.toCharArray();
        }
        int ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (words[i][j] == '0') {
                    ans++;
                    words[i][j] = '1';
                    if (j + 1 < m) {
                        words[i][j + 1] = '1';
                    }
                }
            }
        }
        System.out.println(ans);
        sc.close();
    }
}
```

### C++

#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<string> matrix(n);
    for (int i = 0; i < n; i++) cin >> matrix[i];
    int operations = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (matrix[i][j] == '0') {
                operations++;
                matrix[i][j] = '1';
                if (j + 1 < m) matrix[i][j + 1] = '1';
            }
        }
    }
    cout << operations << endl;
    return 0;
}
