## 解题思路

1. **分析圣物对最终分差的贡献**  
   对于任意一件圣物 $i$，定义其“魂力差”为 $S_i = C_i - D_i$。  
   - 若该圣物被先行者选中，先行者的净收益增加 $C_i - D_i = S_i$，后行者收益不变，因此最终分差 $X - Y$ 直接增加 $S_i$。  
   - 若该圣物被后行者选中，后行者的净收益增加 $D_i - C_i = -S_i$，则 $Y$ 增加 $-S_i$。此时 $X - Y$ 的变化为：  
     $$X - (Y + (-S_i)) = (X - Y) + S_i$$
     即分差同样增加 $S_i$。

   由此可见，**无论圣物被哪位角斗士取走，它对 $X - Y$ 的贡献恒为 $S_i = C_i - D_i$**。

2. **计算最终分差**  
   由于每一件圣物都会被选走一次，且双方的决策不会改变每件圣物的贡献值，最终分差就是所有圣物魂力差的总和：
   $$X - Y = \sum_{i=1}^{n} (C_i - D_i)$$

3. **博弈无关性**  
   该问题中，先行者与后行者的最优博弈实际上不影响最终分差，因为分差是一个不变量。因此不需要模拟选择过程或使用博弈算法，直接求和即可得到答案。

## 复杂度分析

- 对于每组测试数据，只需遍历所有 $n$ 件圣物并累加 $C_i - D_i$，时间复杂度为 $O(n)$。  
- 除了存储输入数据外，算法只需常数级别的额外空间，空间复杂度为 $O(1)$（若将输入数组计算在内则为 $O(n)$，对于大规模输入是合理的）。

## 代码实现

### Python

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    t = int(data[0])
    idx = 1
    out = []
    for _ in range(t):
        n = int(data[idx]); idx += 1
        C = list(map(int, data[idx:idx+n])); idx += n
        D = list(map(int, data[idx:idx+n])); idx += n
        # 每件圣物的贡献为 C_i - D_i，全部选完后的分差即为总和
        total = sum(c - d for c, d in zip(C, D))
        out.append(str(total))
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine().trim());
        StringBuilder sb = new StringBuilder();
        for (int t = 0; t < T; t++) {
            int n = Integer.parseInt(br.readLine().trim());
            String[] cStr = br.readLine().trim().split(" ");
            String[] dStr = br.readLine().trim().split(" ");
            long sum = 0;
            for (int i = 0; i < n; i++) {
                long ci = Long.parseLong(cStr[i]);
                long di = Long.parseLong(dStr[i]);
                sum += ci - di;      // 每件圣物的固定贡献
            }
            sb.append(sum).append("\n");
        }
        System.out.print(sb);
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        vector<long long> C(n), D(n);
        for (int i = 0; i < n; i++) cin >> C[i];
        for (int i = 0; i < n; i++) cin >> D[i];
        long long ans = 0;
        for (int i = 0; i < n; i++) {
            ans += C[i] - D[i];      // 每件圣物的固定贡献
        }
        cout << ans << '\n';
    }
    return 0;
}
```
