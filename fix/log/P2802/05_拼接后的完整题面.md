# 题目内容
在一棵以 $1$ 为根、由 $n$ 个节点组成的树上，每个节点 $i$ 有一个初始整数值 $a_i$。你可以多次执行如下操作：

- 选择一个节点 $v$ 以及一个非负整数 $x$ ；
- 将 $v$ 以及 $v$ 的子树中所有与 $v$ 距离为偶数的节点的值同时异或 $x$ ；
- 该次操作的花费等于 $x$ 。

你的目标是经过若干次操作后，使树上所有节点的值均变为 $0$。试求达成目标所需的最小总花费。

这里，节点 $v$ 的子树由 $v$ 及其所有后代节点构成；树上两个节点之间的距离定义为它们之间简单路径上的边数。操作的花费为每次操作所用 $x$ 的总和。

约束：节点总数 $n$ 满足 $1 \le n \le 2 \times 10^5$，每个节点的初始数值 $a_i$ 满足 $0 \le a_i \le 10^9$。

# 输入描述
第一行包含一个整数 $n$ ，表示树的节点个数。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$ ，表示每个节点的初始数值。
接下来 $n-1$ 行，每行包含两个整数 $u$ 和 $v$ ，表示树中的一条边。保证输入的边构成一棵以 $1$ 号节点为根的有根树。

# 输出描述
输出一个整数，表示将所有节点数值变为 $0$ 所需的最小总花费。

## 样例1

**输入**

```
3
2 3 4
1 2
1 3
```

**输出**

```
9
```

**说明**

树以节点 `1` 为根，共有 `3` 个节点。
节点 `1` 深度为 `0`（偶数），节点 `2`、`3` 深度为 `1`（奇数）。
根据深度奇偶性将问题拆分为两部分：
- 偶数深度节点仅受偶数深度祖先的操作影响。偶数深度节点集合为 $\{1\}$，无祖先，所需操作 $x_1 = a_1 = 2$。
- 奇数深度节点仅受奇数深度祖先的操作影响。奇数深度节点集合为 $\{2, 3\}$，二者均无奇数深度祖先（根为偶数），故各自为根：$x_2 = a_2 = 3$，$x_3 = a_3 = 4$。
总代价为 $x_1 + x_2 + x_3 = 2 + 3 + 4 = 9$。

## 样例2

**输入**

```
4
1 2 3 4
1 2
2 3
3 4
```

**输出**

```
11
```

**说明**

树是一条链：`1` — `2` — `3` — `4`。
深度：`1`（偶），`2`（奇），`3`（偶），`4`（奇）。

偶数深度部分：节点 $\{1, 3\}$。节点 `3` 最近的偶数祖先为 `1`。
$x_1 = a_1 = 1$；
$x_3 = a_3 \oplus a_1 = 3 \oplus 1 = 2$。

奇数深度部分：节点 $\{2, 4\}$。节点 `4` 最近的奇数祖先为 `2`。
$x_2 = a_2 = 2$；
$x_4 = a_4 \oplus a_2 = 4 \oplus 2 = 6$。

总代价为 $1 + 2 + 2 + 6 = 11$。

## 样例3

**输入**

```
1
5
```

**输出**

```
5
```

**说明**

只有 `1` 个节点，它是深度为 `0` 的偶数深度节点。
没有祖先，因此只需一次操作：对节点 `1` 异或 $x_1 = a_1 = 5$，花费 $5$。

## 样例4

**输入**

```
3
0 0 0
1 2
1 3
```

**输出**

```
0
```

**说明**

所有节点初始值已经是 `0`，不需要任何操作即可达成目标，总花费为 `0`。
无论按奇偶深度如何划分，每一部分的 $a_i$ 均为 `0`，对应的异或值 $x_v$ 也均为 `0`。
