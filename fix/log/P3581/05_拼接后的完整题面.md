# 题目内容
有 $n$ 块信号模块，每块都带有相同的基础增益 $b$，第 $i$ 块的指纹值为 $a_i$。选择其中 $t$ 块（不可重复），记所选指纹为 $a_{i_1}, \ldots, a_{i_t}$，则总增益为

$$(a_{i_1} \oplus a_{i_2} \oplus \cdots \oplus a_{i_t}) + b \times t$$

其中 $\oplus$ 表示按位异或。也可以一块都不选，此时总增益为 `0`。

请在总增益最大的前提下，使所选模块数 $t$ 尽可能少，并同时输出这个最少模块数与最大总增益。

约束：测试组数不超过 `20`，单组模块数不超过 `10^3`，基础增益 $b$ 满足 $-25 \le b \le 25$，指纹值满足 $0 \le a_i < 2^{12}$，且单个测试文件中模块数之和不超过 `10^3`。

# 输入描述
每个测试文件包含多组数据。第一行一个整数 $T$，表示数据组数。
每组数据格式如下：
第一行两个整数 $n$ 和 $b$，分别表示模块数与基础增益；
第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$，表示各模块指纹。
保证 $1 \le T \le 20$，$1 \le n \le 10^3$，$-25 \le b \le 25$，$0 \le a_i < 2^{12}$，且单个文件中 $n$ 之和不超过 $10^3$。

# 输出描述
对每组数据输出一行两个整数：最少模块数与最大总增益。须先保证总增益最大，再使模块数最少。

## 样例1

**输入**

```
2
3 1
1 2 3
2 -1
0 0
```

**输出**

```
2 5
0 0
```

**说明**

第一组 $b=1>0$，选前两块：指纹异或 $1 \oplus 2=3$，再加 $b \times 2=2$，总增益 `5`。可以验证没有更大增益。
第二组 $b=-1$，选任何非空集合都会使增益变负，空集增益为 `0`，因此答案是 `0 0`。

## 样例2

**输入**

```
1
3 0
1 2 3
```

**输出**

```
1 3
```

**说明**

$b=0$ 时总增益就是指纹异或值。单独选第三块得到 `3`，选前两块得到 $1 \oplus 2=3$ 但件数更多。最大增益为 `3`，最少件数为 `1`。

## 样例3

**输入**

```
1
1 5
7
```

**输出**

```
1 12
```

**说明**

只有一块模块。空集增益为 `0`；选中后增益为 $7+5 \times 1=12$。应选择这一块，答案为 `1 12`。

## 样例4

**输入**

```
1
2 2
0 0
```

**输出**

```
2 4
```

**说明**

两块指纹都是 `0`，$b=2>0$。选得越多越好：两块异或仍为 `0`，总增益 $0+2 \times 2=4$，答案为 `2 4`。
