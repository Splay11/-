# 题目内容
小 R 正在设计一套健身计划。他每次可以选择迈出一步，步长可以是 $1$ 米或 $2$ 米。他想完成总距离恰好为 $k$ 米的训练，并且规定：第一步不能迈 $1$ 米，除非整个计划只包含一步（即 $k=1$ 时允许第一步迈 $1$ 米）。请你计算有多少种不同的步长序列可以实现他的计划，序列的顺序不同视为不同的方案。由于答案可能很大，请输出对 $998244353$ 取模的结果。

约束：$k$ 是正整数，满足 $1 \le k \le 10^9$；测试数据组数 $T$ 满足 $1 \le T \le 10^4$。

# 输入描述
第一行包含一个整数 $T$ ($1 \le T \le 10^4$)，表示测试数据组数。接下来 $T$ 行，每行包含一个整数 $k$ ($1 \le k \le 10^9$)，表示目标总距离。

# 输出描述
对于每组测试数据，输出一行一个整数，表示合法步长序列的数量对 $998244353$ 取模的结果。

## 样例1

**输入**

```
3
1
2
3
```

**输出**

```
1
1
1
```

**说明**

当 $k=1$ 时，只有步长序列 $[1]$ 一种方案，输出 `1`；
当 $k=2$ 时，第一步不能为 `1`，只能迈 `2`，序列为 $[2]$，输出 `1`；
当 $k=3$ 时，第一步必为 `2`，剩余 `1` 米只能迈 `1`，序列为 $[2,1]$，输出 `1`。

## 样例2

**输入**

```
3
4
5
6
```

**输出**

```
2
3
5
```

**说明**

当 $k=4$ 时，合法序列有 $[2,2]$ 和 $[2,1,1]$，共 `2` 种；
当 $k=5$ 时，合法序列为 $[2,2,1]$、$[2,1,2]$、$[2,1,1,1]$，共 `3` 种；
当 $k=6$ 时，方案数满足 $f(k)=F_{k-1}$，$F_5=5$（$F_0=0,F_1=1$），具体序列为 $[2,2,2]$、$[2,2,1,1]$、$[2,1,2,1]$、$[2,1,1,2]$、$[2,1,1,1,1]$，输出 `5`。

## 样例3

**输入**

```
4
15
20
30
50
```

**输出**

```
377
4181
514229
791031578
```

**说明**

$k=15$ 时，$f(15)=F_{14}=377$，未超过模数，输出 `377`；
$k=20$ 时，$f(20)=F_{19}=4181$，输出 `4181`；
$k=30$ 时，$f(30)=F_{29}=514229$，输出 `514229`；
$k=50$ 时，$F_{49}=7778742049$，对 $998244353$ 取余后得到 $791031578$，输出 `791031578`，展示了取模操作。
