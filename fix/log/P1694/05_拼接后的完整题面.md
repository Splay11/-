# 题目内容
产线侧对一批测点做了抽检，得到长度为 $n$ 的正整数读数。质检规程允许对任意一个测点做一次微调：把它的读数加 `1` 或减 `1`，每次计一次操作。为了让整条样本带落到同一校准档，需要把所有读数都改成与某个已有测点 $a_i$ 完全相同。

请对每个下标 $i$，求出以 $a_i$ 作为目标档时的最少操作次数。

约束：测点个数不超过 `100000`，每个读数为正整数且不超过 `1000000000`。

# 输入描述
第一行一个正整数 $n$。
第二行 $n$ 个正整数 $a_i$。
保证 $1 \le n \le 100000$，$1 \le a_i \le 1000000000$。

# 输出描述
输出 $n$ 行，第 $i$ 行表示目标值为 $a_i$ 时的最少操作次数。

## 样例1

**输入**

```
4
3 1 5 2
```

**输出**

```
5
7
9
5
```

**说明**

按题意模拟计算得到。
