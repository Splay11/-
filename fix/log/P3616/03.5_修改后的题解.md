## 解题思路

- 设从第 $i$ 级台阶向右一直走到第 $n$ 级台阶，相邻两步的能量变化量为 $h_k - h_{k+1}$（$k = i, i+1, \dots, n-1$）。从 $i$ 走到 $j$ 的前缀和为 $\sum_{t=i}^{j-1} (h_t - h_{t+1}) = h_i - h_j$。  
- 为了保证全程储能不为负数，初始能量必须能够抵消最不利的前缀和（即最大亏空）。等价地，向右走到达终点所需的最小初始能量为：
  $$
  E_{i \to \text{右}} = \max\Bigl(0,\ \max_{j \in [i, n]} h_j - h_i\Bigr)
  $$
- 对称地，向左走到达终点所需的最小初始能量为：
  $$
  E_{i \to \text{左}} = \max\Bigl(0,\ \max_{j \in [1, i]} h_j - h_i\Bigr)
  $$
- 从第 $i$ 级台阶出发到达任意一端所需的最小初始能量为两者中的较小值：
  $$
  ans_i = \min\Bigl(\max_{j \in [1,i]} h_j,\ \max_{j \in [i,n]} h_j\Bigr) - h_i
  $$
  由于前缀最大值 $\ge h_i$ 且后缀最大值 $\ge h_i$，因此 $ans_i$ 始终为非负整数，无需额外取 $\max$。
- 预处理前缀最大值数组 $\text{prefMax}[i] = \max_{1 \le j \le i} h_j$ 和后缀最大值数组 $\text{sufMax}[i] = \max_{i \le j \le n} h_j$。  
- 对每个 $i$，直接计算 $\text{ans}_i = \min(\text{prefMax}[i], \text{sufMax}[i]) - h_i$ 并输出即可。

## 复杂度分析

- 时间复杂度：预处理前缀最大值和后缀最大值各需一次遍历，计算答案需一次遍历，总时间复杂度为 $O(n)$。
- 空间复杂度：需额外存储两个长度为 $n+2$ 的数组 $\text{prefMax}$ 和 $\text{sufMax}$，空间复杂度为 $O(n)$。

## 代码实现

### Python

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    h = [0] + [int(next(it)) for _ in range(n)]  # 1-indexed

    # 前缀最大值
    pref_max = [0] * (n + 1)
    for i in range(1, n + 1):
        pref_max[i] = h[i] if i == 1 else max(pref_max[i - 1], h[i])

    # 后缀最大值
    suf_max = [0] * (n + 2)
    for i in range(n, 0, -1):
        suf_max[i] = h[i] if i == n else max(suf_max[i + 1], h[i])

    # 计算答案
    ans = [str(min(pref_max[i], suf_max[i]) - h[i]) for i in range(1, n + 1)]
    sys.stdout.write(" ".join(ans))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String line = br.readLine();
        if (line == null || line.isEmpty()) return;
        int n = Integer.parseInt(line.trim());
        String[] parts = br.readLine().trim().split("\\s+");
        long[] h = new long[n + 1];  // 1-indexed
        for (int i = 1; i <= n; i++) {
            h[i] = Long.parseLong(parts[i - 1]);
        }

        // 前缀最大值
        long[] prefMax = new long[n + 1];
        for (int i = 1; i <= n; i++) {
            prefMax[i] = (i == 1) ? h[i] : Math.max(prefMax[i - 1], h[i]);
        }

        // 后缀最大值
        long[] sufMax = new long[n + 2];
        for (int i = n; i >= 1; i--) {
            sufMax[i] = (i == n) ? h[i] : Math.max(sufMax[i + 1], h[i]);
        }

        // 计算答案并输出
        StringBuilder sb = new StringBuilder();
        for (int i = 1; i <= n; i++) {
            long need = Math.min(prefMax[i], sufMax[i]) - h[i];
            if (i > 1) sb.append(' ');
            sb.append(need);
        }
        System.out.println(sb.toString());
    }
}
```
