# 题目内容
一个清洁机器人需要清理一条由 $n$ 级台阶组成的走廊。台阶从左到右编号为 $1$ 到 $n$，第 $i$ 级台阶的高度为 $h_i$。

机器人可以从任意一级台阶出发，并选择始终向左或始终向右单向移动，直到抵达最左端或最右端的台阶。当机器人从高度为 $h$ 的台阶移动到相邻高度为 $h'$ 的台阶时：
- 若 $h' \le h$（下台阶），机器人的储能单元会回收能量，储能增加 $h - h'$；
- 若 $h' > h$（上台阶），机器人需要消耗储能，储能减少 $h' - h$。

为了保证在整个移动过程中储能始终不为负数，出发前需要为机器人预充一定的初始能量。对于每一个出发台阶 $i$ ($1 \le i \le n$)，请你计算：如果机器人从 $i$ 出发，并选择向左一直走到台阶 $1$，或向右一直走到台阶 $n$，这两种方案所需的最小初始能量分别是多少，最终取两者的较小值作为从 $i$ 出发到达任意一端所需的最小初始能量。

约束条件：台阶数 $n$ 不超过 $10^5$，每个台阶的高度 $h_i$ 满足 $0 \le h_i \le 10^9$。

# 输入描述
第一行包含一个整数 $n$ ($1 \le n \le 10^5$)，表示台阶的数量。
第二行包含 $n$ 个整数 $h_1, h_2, \dots, h_n$ ($0 \le h_i \le 10^9$)，用空格分隔，表示从左到右每级台阶的高度。

# 输出描述
输出一行包含 $n$ 个整数，用空格分隔。其中第 $i$ 个整数表示从第 $i$ 级台阶出发，到达任意一端所需的最小初始能量。

## 样例1

**输入**

```
1
10
```

**输出**

```
0
```

**说明**

台阶只有一级，高度 $h_1 = 10$。机器人从唯一台阶出发，无需移动，因此所需初始能量为 `0`。

## 样例2

**输入**

```
5
5 3 4 1 2
```

**输出**

```
0 1 0 1 0
```

**说明**

台阶高度为 $[5, 3, 4, 1, 2]$。

- 第 `1` 级：向左已是最左端，所需能量 `0`；向右最高 $\max\{5,3,4,1,2\}=5$，与 $h_1$ 差值为 `0`，取较小值 `0`。
- 第 `2` 级：$h_2=3$。向左最高 $5$，需能量 $5-3=2$；向右最高 $4$，需能量 $4-3=1$。取较小值 `1`。
- 第 `3` 级：$h_3=4$。向左最高 $5$，需 $1$；向右最高 $4$，需 $0$。取 `0`。
- 第 `4` 级：$h_4=1$。向左最高 $5$，需 $4$；向右最高 $2$，需 $1$。取 `1`。
- 第 `5` 级：向右已是最右端，所需 `0`。

## 样例3

**输入**

```
6
2 5 3 4 6 1
```

**输出**

```
0 0 2 1 0 0
```

**说明**

高度为 $[2,5,3,4,6,1]$。

- 第 `1` 级：向左不需移动，能量 `0`；向右最高 $6$，需要 $6-2=4$，取 `0`。
- 第 `2` 级：$h_2=5$。向左最高 $2$，不需能量；向右最高 $6$，需 $1$，取 `0`。
- 第 `3` 级：$h_3=3$。左侧最高 $5$，需 $2$；右侧最高 $6$，需 $3$，取较小值 `2`。
- 第 `4` 级：$h_4=4$。左侧最高 $5$，需 $1$；右侧最高 $6$，需 $2$，取较小值 `1`。
- 第 `5` 级：$h_5=6$ 为全局最高，向左向右均无需额外能量，取 `0`。
- 第 `6` 级：向右已是最右端，所需 `0`。
