# 题目内容
给定一个由 $n$ 个整数构成的序列 $a_1, a_2, \dots, a_n$。

如果一个子序列的长度为 `1`，或者其中任意相邻两项之和均为 `3` 的倍数，则称该子序列为 **和谐子序列**。子序列需保持原序列中的相对顺序，但不要求连续。

请你从原序列中选出一个和谐子序列，使得其中所有元素之和最大，并输出这个最大和。

约束条件：数组长度 $n$ 满足 $1 \le n \le$ `2\times 10^5`，所有元素 $a_i$ 均为正整数且 $a_i \le$ `10^6`。

# 输入描述
输入共两行。
第一行包含一个整数 $n$ ($1 \le n \le$ `2\times 10^5`)，表示序列的长度。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$ ($1 \le a_i \le$ `10^6`)，依次表示序列中的元素，相邻整数之间用空格分隔。

# 输出描述
输出一个整数，表示所有和谐子序列中可以取得的最大元素之和。

## 样例1

**输入**

```
3
1 2 3
```

**输出**

```
3
```

**说明**

序列为 $a = [1, 2, 3]$。我们考虑所有和谐子序列：

- 长度为 `1` 的子序列 `[1]`、`[2]`、`[3]` 都符合条件，和分别为 `1`、`2`、`3`。
- 长度为 `2` 的子序列中，$1 + 2 = 3$ 是 `3` 的倍数，所以 `[1,2]` 是和谐子序列，和为 `3`；$1 + 3 = 4$ 不是 `3` 的倍数；$2 + 3 = 5$ 也不是。
- 长度为 `3` 的子序列 `[1,2,3]` 中，$1+2=3$ 满足，但 $2+3=5$ 不满足，因此不是和谐子序列。

综上，最大和为 `3`，可以由子序列 `[3]` 或 `[1,2]` 得到。

## 样例2

**输入**

```
4
3 6 9 12
```

**输出**

```
30
```

**说明**

序列为 $a = [3, 6, 9, 12]$。所有元素模 $3$ 均为 `0`，因此任意相邻两项之和都是 `3` 的倍数。整个序列本身即为和谐子序列，和为 $3 + 6 + 9 + 12 = 30$，这也是可能的最大和。

## 样例3

**输入**

```
4
1 2 3 4
```

**输出**

```
7
```

**说明**

序列为 $a = [1, 2, 3, 4]$，模 $3$ 分别为 `[1, 2, 0, 1]`。

我们可以在保持相对顺序的前提下选择子序列 `[1, 2, 4]`：
- $1 + 2 = 3$ 是 `3` 的倍数（$1 \pmod 3$ 与 $2 \pmod 3$ 互补）；
- $2 + 4 = 6$ 也是 `3` 的倍数。

该子序列的和为 $1 + 2 + 4 = 7$。其他如 `[2, 4]` 和为 `6`，单个元素最大为 `4`，均小于 `7`，因此最大和为 `7`。

## 样例4

**输入**

```
1
5
```

**输出**

```
5
```

**说明**

当序列长度为 `1` 时，唯一的子序列即为其本身，长度为 `1` 的子序列自动满足和谐条件。因此最大和就是该元素本身，输出 `5`。
