# 题目描述

数据分析师阿澈得到了一串由小写英文字母组成的标签序列 $s$，字符串长度为 $n$。

现在可以从原序列中选择若干个位置，并保持它们在原序列中的相对顺序不变，从而得到一个**非空子序列**。

对于一个子序列，定义它的**标签种类数**为其中出现过的不同字符数量。

例如，子序列 `abac` 中出现了 `a`、`b`、`c` 三种字符，因此它的标签种类数为 $3$。

一个长度为 $n$ 的字符串共有 $2^n-1$ 个非空子序列。阿澈想知道，所有非空子序列的标签种类数之和是多少。

由于答案可能很大，请输出答案对 $10^9+7$ 取模后的结果。

# 输入描述

输入一行一个仅由小写英文字母组成的字符串 $s$。

字符串长度满足

$$
1\leq |s|\leq 10^5
$$

# 输出描述

输出一个整数，表示所有非空子序列的标签种类数之和对 $10^9+7$ 取模后的结果。

# 样例 1

**输入**

```text
aab
```

**输出**

```text
10
```

**说明**

按照选择的位置不同，共有 $2^3-1=7$ 个非空子序列。

其中只包含一种字符的子序列贡献 $1$，同时包含 `a` 和 `b` 的子序列贡献 $2$。

将所有子序列的标签种类数相加，最终得到 $10$。

# 样例 2

**输入**

```text
abca
```

**输出**

```text
28
```

**说明**

统计所有非空子序列中出现的不同字符数量之和，最终结果为 $28$。
