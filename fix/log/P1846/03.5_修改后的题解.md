## 解题思路

考虑每个字母对答案的贡献，而不是枚举子序列。

对某个字母 $c$，记它在 $s$ 中出现 $r$ 次。一个子序列会让 $c$ 计入种类数，当且仅当该子序列至少选出一个 $c$。此时：

- $c$ 的 $r$ 个出现位置不能全不选，有 $2^r-1$ 种选法；
- 其余 $n-r$ 个位置可任意选或不选，有 $2^{n-r}$ 种选法。

因此字母 $c$ 的贡献为 $(2^r-1)\cdot 2^{n-r}$。对所有出现过的字母累加，再对 $10^9+7$ 取模。

## 复杂度分析

统计频次后，不同字母最多 `26` 个，每个贡献用快速幂计算。

- 时间复杂度：$O(n+\lvert \Sigma\rvert\log n)$，其中 $\lvert\Sigma\rvert\le 26$。
- 空间复杂度：$O(\lvert\Sigma\rvert)$。

## 代码实现

### Python

```python
import sys
from collections import Counter

s = sys.stdin.read().strip()
mod = 10**9 + 7
n = len(s)
cnt = Counter(s)
res = 0
for c in cnt:
    r = cnt[c]
    res = (res + (pow(2, r, mod) - 1) * pow(2, n - r, mod)) % mod
print(res)
```

### Java

```java
import java.util.*;

public class Main {
    static final int MOD = 1000000007;

    static long qmi(long a, long b) {
        long res = 1 % MOD;
        while (b > 0) {
            if ((b & 1) == 1) res = res * a % MOD;
            a = a * a % MOD;
            b >>= 1;
        }
        return res;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        Map<Character, Integer> mp = new HashMap<>();
        for (char ch : s.toCharArray()) {
            mp.put(ch, mp.getOrDefault(ch, 0) + 1);
        }
        long res = 0;
        int n = s.length();
        for (int r : mp.values()) {
            res = (res + (qmi(2, r) - 1) * qmi(2, n - r)) % MOD;
        }
        System.out.println(res);
        sc.close();
    }
}
```
