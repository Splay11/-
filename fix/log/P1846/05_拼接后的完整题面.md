# 题目内容
乐谱上有一段由小写英文字母组成的旋律 $s$，长度为 $n$。可以从中选出若干个位置，并保持它们在原旋律中的相对顺序，得到一个非空子序列。

一个子序列的种类数定义为其中出现过的不同字母个数。例如子序列 `abac` 中出现了 `a`、`b`、`c`，种类数为 `3`。

长度为 $n$ 的串共有 $2^n-1$ 个非空子序列。请计算所有非空子序列的种类数之和。答案可能很大，对 $10^9+7$ 取模。

旋律长度不超过 `10^5`，且仅由小写英文字母构成。

# 输入描述
输入一行一个字符串 $s$，仅由小写英文字母组成，长度满足 $1 \le |s| \le 10^5$。

# 输出描述
输出一个整数，表示所有非空子序列种类数之和对 $10^9+7$ 取模后的结果。

## 样例1

**输入**

```
a
```

**输出**

```
1
```

**说明**

只有一个字母，唯一非空子序列的种类数为 `1`，输出 `1`。

## 样例2

**输入**

```
abc
```

**输出**

```
12
```

**说明**

三个字母各出现一次，每个贡献 $(2^1-1)\cdot 2^{2}=4$，总和为 `12`。
