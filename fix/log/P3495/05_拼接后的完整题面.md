# 题目内容
定义两个长度为 $n$ 的排列 $x,y$ **错位**，当且仅当对于除区间 $[1,n]$ 以外的每一个区间 $[l,r]$（$1 \le l \le r \le n$），都有
$$\sum_{i=l}^{r} x_i 
eq \sum_{i=l}^{r} y_i.$$

现在给定一个长度为 $n$ 的排列 $p$，请构造一个与 $p$ 错位的排列。

长度为 $n$ 的排列：由 $1,2,\ldots,n$ 这 $n$ 个整数按任意顺序组成、每个整数恰好出现一次的序列。

数据范围：测试组数 $T$ 满足 $1 \le T \le 10^3$；每组 $n$ 满足 $1 \le n \le 2 \times 10^4$；保证 $p$ 是一个排列。单个测试文件中所有 $n$ 之和不超过 $2 \times 10^5$。

# 输入描述
每个测试文件包含多组测试数据。第一行输入一个整数 $T$（$1 \le T \le 10^3$），表示数据组数。
每组测试数据格式如下：
- 第一行包含一个整数 $n$（$1 \le n \le 2 \times 10^4$），表示排列长度；
- 第二行包含 $n$ 个两两不同的整数 $p_1,p_2,\ldots,p_n$（$1 \le p_i \le n$），表示给定排列。
保证单个测试文件中所有 $n$ 之和不超过 $2 \times 10^5$。

# 输出描述
对于每一组测试数据，新起一行输出 $n$ 个整数，表示所构造的排列。若有多个合法方案，输出任意一个即可。

## 样例1

**输入**

```
2
4
1 2 3 4
4
2 1 3 4
```

**输出**

```
2 3 4 1
1 3 4 2
```

**说明**

将给定排列整体向左循环移动一位即可。第一组得到 $2,3,4,1$，第二组得到 $1,3,4,2$。对任意真子区间，循环后的区间和与原区间和之差等于两端位置上两个不同元素之差，因而一定不相等。

## 样例2

**输入**

```
1
1
1
```

**输出**

```
1
```

**说明**

$n=1$ 时只有整个区间，不存在需要错开的真子区间，输出 `1` 即可。

## 样例3

**输入**

```
1
3
3 1 2
```

**输出**

```
1 2 3
```

**说明**

左旋一位得到 $1,2,3$。例如区间 $[1,2]$ 原和为 $3+1=4$，新和为 $1+2=3$，不相等。

## 样例4

**输入**

```
1
5
5 4 3 2 1
```

**输出**

```
4 3 2 1 5
```

**说明**

左旋一位得到 $4,3,2,1,5$，与原排列在所有真子区间上的和均不同。
