## 解题思路

把 $p$ **整体向左循环平移一位**得到 $q$：

$$
q_i = p_{i+1}\ (1 \le i < n),\qquad q_n = p_1.
$$

对任意区间 $[l,r]$，

$$
\sum_{i=l}^{r} q_i - \sum_{i=l}^{r} p_i = p_{r+1} - p_l
$$

（当 $r=n$ 时约定 $p_{n+1}=p_1$）。

- 当 $[l,r]=[1,n]$ 时，差为 $0$，整个区间的和允许相等。
- 当 $[l,r]$ 是真子区间时，$r+1 \notin [l,r]$。由于 $p$ 是排列，元素互异，故 $p_{r+1} \ne p_l$，从而两段区间和不相等。

因此 $q$ 与 $p$ 一定错位。对每组数据输出左旋一位即可。

## 复杂度分析

- **时间复杂度**：$O(n)$。每组线性扫描一次，整份文件 $O(\sum n)$。
- **空间复杂度**：$O(n)$。用于存放排列（输出除外可视为 $O(1)$ 额外空间）。

## 代码实现

### Python

```python
import sys

it = iter(sys.stdin.read().strip().split())
t = int(next(it))
out = []
for _ in range(t):
    n = int(next(it))
    a = [int(next(it)) for _ in range(n)]
    b = a[1:] + a[:1]
    out.append(" ".join(map(str, b)))
print("\n".join(out))
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        StringTokenizer st;

        int T = Integer.parseInt(br.readLine().trim());
        while (T-- > 0) {
            int n = Integer.parseInt(br.readLine().trim());
            st = new StringTokenizer(br.readLine());
            int[] a = new int[n];
            for (int i = 0; i < n; i++) a[i] = Integer.parseInt(st.nextToken());

            for (int i = 0; i < n - 1; i++) {
                if (i > 0) sb.append(' ');
                sb.append(a[i + 1]);
            }
            if (n > 1) sb.append(' ');
            sb.append(a[0]);
            if (T > 0) sb.append('\n');
        }
        System.out.print(sb.toString());
    }
}
```

#include <bits/stdc++.h>

int main() {
    ios::sync_with_stdio(false);

    int T;
    if (!(cin >> T)) return 0;
    while (T--) {
        int n; cin >> n;
        vector<int> a(n);
        for (int i = 0; i < n; ++i) cin >> a[i];

        for (int i = 1; i < n; ++i) {
            if (i > 1) cout << ' ';
            cout << a[i];
        }
        if (n > 1) cout << ' ';
        cout << a[0];
        if (T) cout << '\n';
    }
    return 0;
}
