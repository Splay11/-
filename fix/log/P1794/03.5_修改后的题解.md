## 解题思路

1. 登山者需要从 1 号营地移动到 n 号营地，共有 n-1 次移动，每次消耗 1 单位氧气，因此总共需要购买 n-1 单位氧气。
2. 对于第 i 次移动（从 i 到 i+1），可供选择的购买地点是营地 1 到 i。为了让总支出最少，我们应贪心地选择当前已遍历营地中 **氧气单价最低** 的营地购买这 1 单位氧气。
3. 为了保证“所有营地中最大购买次数最小”（即购买次数尽可能均衡），当有多个营地的单价同为最低时，优先选择 **已购买次数最少** 的那个营地。若仍并列，可任意选择（例如选编号较大的营地）。
4. 具体实现采用 **反悔贪心 + 优先队列**：
   - 遍历 i 从 0 到 n-2（表示需要决定第 i+1 段移动的氧气来源）：
     - 将第 i 个营地（单价 p_i，当前购买次数 0）加入优先队列。
     - 弹出队头元素（满足：价格最低；价格相同则次数最少；均相同则编号最大），将其购买次数加 1，更新该营地的购买数量，然后重新压入队列。
   - 遍历结束后，每个营地的购买次数即为最终答案。
5. 该做法正确的原因是：任何总花费最小的方案都可以等价地转化为“每次需要氧气时，从已出现的营地中挑选价格最低者购买”，而我们的 tie-breaking 策略可以在不影响总花费的前提下，尽量摊平各营地的购买次数，使最大购买次数最小化。

## 复杂度分析

- 时间复杂度：共 n-1 次操作，每次操作涉及优先队列的插入和弹出，复杂度为 $O(\log n)$，因此总时间复杂度为 $O(n \log n)$。
- 空间复杂度：优先队列中最多同时存放 n 个元素，记录答案需要长度为 n 的数组，因此空间复杂度为 $O(n)$。

## 代码实现

### Python

```python
import sys
import heapq

def solve():
    input = sys.stdin.readline
    n = int(input())
    p = list(map(int, input().split()))
    ans = [0] * n
    heap = []
    # 我们需要购买 n-1 单位氧气
    for i in range(n - 1):
        # 将第 i 个营地加入候选
        # 堆中元素为 (单价, 已购买次数, -编号) ，这样能保证:
        # 1. 单价最低优先
        # 2. 单价相同时已购买次数较少优先
        # 3. 前两者都相同时，编号较大者优先(因为我们取了负号)
        heapq.heappush(heap, (p[i], 0, -i))
        # 取出当前最优营地
        price, cnt, neg_idx = heapq.heappop(heap)
        cnt += 1
        idx = -neg_idx
        ans[idx] = cnt
        # 重新放入堆，供后续选择
        heapq.heappush(heap, (price, cnt, neg_idx))
    print(' '.join(map(str, ans)))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    static class Node implements Comparable<Node> {
        int price;
        int cnt;
        int idx;

        Node(int price, int cnt, int idx) {
            this.price = price;
            this.cnt = cnt;
            this.idx = idx;
        }

        @Override
        public int compareTo(Node other) {
            if (this.price != other.price) {
                return Integer.compare(this.price, other.price);
            }
            if (this.cnt != other.cnt) {
                return Integer.compare(this.cnt, other.cnt);
            }
            // 价格和次数都相同，选择编号较大的（通过取反实现降序）
            return Integer.compare(other.idx, this.idx);
        }
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine());
        int[] p = new int[n];
        String[] parts = br.readLine().split(" ");
        for (int i = 0; i < n; i++) {
            p[i] = Integer.parseInt(parts[i]);
        }

        int[] ans = new int[n];
        PriorityQueue<Node> pq = new PriorityQueue<>();

        for (int i = 0; i < n - 1; i++) {
            pq.offer(new Node(p[i], 0, i));
            Node top = pq.poll();
            top.cnt++;
            ans[top.idx] = top.cnt;
            pq.offer(top);
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            sb.append(ans[i]);
            if (i < n - 1) sb.append(' ');
        }
        System.out.println(sb);
    }
}
```

### C++

```cpp
#include <iostream>
#include <queue>
#include <vector>
#include <tuple>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> p(n);
    for (int i = 0; i < n; ++i) {
        cin >> p[i];
    }

    vector<int> ans(n, 0);
    // 自定义比较：价格小优先；价格相同则次数少优先；两者均相同则编号大优先
    auto cmp = [](const tuple<int, int, int>& a, const tuple<int, int, int>& b) {
        if (get<0>(a) != get<0>(b))
            return get<0>(a) > get<0>(b); // 价格更大的优先级更低
        if (get<1>(a) != get<1>(b))
            return get<1>(a) > get<1>(b); // 次数更多的优先级更低
        return get<2>(a) < get<2>(b);     // 编号更小的优先级更低，即编号大优先
    };
    priority_queue<tuple<int, int, int>, vector<tuple<int, int, int>>, decltype(cmp)> pq(cmp);

    for (int i = 0; i < n - 1; ++i) {
        pq.emplace(p[i], 0, i);
        auto [price, cnt, idx] = pq.top();
        pq.pop();
        ++cnt;
        ans[idx] = cnt;
        pq.emplace(price, cnt, idx);
    }

    for (int i = 0; i < n; ++i) {
        cout << ans[i];
        if (i < n - 1) cout << ' ';
    }
    cout << '\n';

    return 0;
}
```
