# 题目内容
登山者计划从 $1$ 号营地出发，依次经过 $2,3,\dots,n$ 号营地，最终到达 $n$ 号营地。从第 $i$ 号营地移动到第 $i+1$ 号营地需要消耗恰好 $1$ 单位的氧气。在每个营地 $i$，登山者可以购买任意整数单位的氧气，每单位价格为 $p_i$。

登山者希望总支出最少，同时希望任意一个营地的氧气购买量尽可能均衡，即所有营地中最大购买次数最小。如果有多种总花费最小的方案，请输出任意一种满足上述均衡要求的方案。

你需要给出在每个营地的氧气购买数量。数据保证 $n \ge 2$，所有价格均为正整数。

**约束条件**：
- 营地数量 $n$ 不超过 $10^5$。
- 每个营地的氧气单价 $p_i$ 满足 $1 \le p_i \le 10^5$。

# 输入描述
第一行包含一个整数 $n$，表示营地的数量。
第二行包含 $n$ 个整数 $p_1, p_2, \ldots, p_n$，依次表示每个营地的氧气单价。

# 输出描述
输出一行 $n$ 个整数，第 $i$ 个整数表示在第 $i$ 号营地购买的氧气数量。如果某个营地无需购买，则输出 $0$。

## 样例1

**输入**

```
2
10 20
```

**输出**

```
1 0
```

**说明**

营地数量 $n=2$，价格分别为 $10, 20$。

从 `1` 号营地到 `2` 号营地只需要移动 $1$ 段，消耗 `1` 单位氧气。在出发前，登山者只能访问 `1` 号营地，因此必须在 `1` 号营地购买这 `1` 单位氧气，花费 $10$。

到达 `2` 号营地后无需再购买。总购买方案为 `1` 号营地购买 `1` 单位，`2` 号营地购买 `0` 单位，总花费最小，且购买次数最大值为 $1$，已是最均衡方案。

## 样例2

**输入**

```
3
3 1 2
```

**输出**

```
1 1 0
```

**说明**

营地数量 $n=3$，价格依次为 $3, 1, 2$。

从 `1` 到 `3` 需要移动 $2$ 段，共消耗 $2$ 单位氧气。
- 第 `1` 段（`1` → `2`）：出发时只能访问 `1` 号营地，价格为 $3$，必须在此购买 `1` 单位。
- 第 `2` 段（`2` → `3`）：此时可访问 `1`、`2` 号营地，最低价格为 `2` 号营地的 $1$，选择在 `2` 号营地购买 `1` 单位。

最终购买量：`1` 号营地 `1` 单位，`2` 号营地 `1` 单位，`3` 号营地 `0` 单位。总花费 $1 \times 3 + 1 \times 1 = 4$，是最小花费，且最大购买次数为 $1$，已满足均衡要求。

## 样例3

**输入**

```
5
5 1 5 1 5
```

**输出**

```
1 2 0 1 0
```

**说明**

营地数量 $n=5$，价格依次为 $5, 1, 5, 1, 5$。

共需 $4$ 单位氧气，过程如下：
- 第 `1` 段（`1` → `2`）：只能选 `1` 号营地（价格 $5$），购买 `1` 单位，累计 `1` 号营地 $1$ 次。
- 第 `2` 段（`2` → `3`）：可访问 `1`（价格 $5$，已购 $1$ 次）、`2`（价格 $1$，已购 $0$ 次）。价格最低且次数最少的是 `2` 号，购买 `1` 单位，累计 `2` 号营地 $1$ 次。
- 第 `3` 段（`3` → `4`）：可访问 `1`（$5$, $1$次）、`2`（$1$, $1$次）、`3`（$5$, $0$次）。最低价格仍为 $1$，`2` 号营地次数最少，再次选择 `2` 号购买 `1` 单位，累计 `2` 号营地 $2$ 次。
- 第 `4` 段（`4` → `5`）：可访问 `1`（$5$, $1$次）、`2`（$1$, $2$次）、`3`（$5$, $0$次）、`4`（$1$, $0$次）。最低价格 $1$，`4` 号营地次数 $0$ 少于 `2` 号的 $2$，选择 `4` 号购买 `1` 单位。

最终方案：`1` 号 `1` 单位，`2` 号 `2` 单位，`3` 号 `0` 单位，`4` 号 `1` 单位，`5` 号 `0` 单位。总花费 $1 \times 5 + 2 \times 1 + 1 \times 1 = 8$，为最小花费。最大购买次数为 $2$，通过在不同 $1$ 价格营地间分配，达到了最均衡的状态。
