## 解题思路

一年 `12` 个月的出库量是固定周期：普通月出库 $m$，促销月（第 $p$ 月到第 $p+q-1$ 月）出库 $2m$。一年总出库量为

$$
Y=(12-q)\cdot m+q\cdot(2m)=(12+q)\cdot m.
$$

先按整年跳跃：可完整跳过的年数为 $k=\left\lfloor\dfrac{n-1}{Y}\right\rfloor$，跳过 $12k$ 个月后剩余库存 $n\leftarrow n-kY$。用 $(n-1)//Y$ 可以避免“恰好整年结束”的边界误差。

剩余部分最多再扫 `12` 个月：从一月起累加每月出库量，第一次使累计出库量 $\ge$ 剩余库存的月份即为清仓月。总月数等于 $12k$ 加上该月份序号。

## 复杂度分析

时间复杂度 $O(1)$（整年跳过后只需扫描 `12` 个月），空间复杂度 $O(1)$。

## 代码实现

### Python

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    n, m, p, q = map(int, data[:4])

    drop = [m] * 12
    for i in range(p - 1, p - 1 + q):
        drop[i] = 2 * m

    yearly = sum(drop)
    years = (n - 1) // yearly
    months = years * 12
    rem = n - years * yearly

    acc = 0
    for i in range(12):
        acc += drop[i]
        months += 1
        if acc >= rem:
            print(months)
            return

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        if (!sc.hasNextLong()) return;
        long n = sc.nextLong();
        long m = sc.nextLong();
        int p = sc.nextInt();
        int q = sc.nextInt();

        long[] drop = new long[12];
        Arrays.fill(drop, m);
        for (int i = p - 1; i < p - 1 + q; i++) drop[i] = 2 * m;

        long yearly = 0;
        for (long x : drop) yearly += x;

        long years = (n - 1) / yearly;
        long months = years * 12;
        long rem = n - years * yearly;

        long acc = 0;
        for (int i = 0; i < 12; i++) {
            acc += drop[i];
            months++;
            if (acc >= rem) {
                System.out.println(months);
                return;
            }
        }
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n, m;
    int p, q;
    if (!(cin >> n >> m >> p >> q)) return 0;

    vector<long long> drop(12, m);
    for (int i = p - 1; i < p - 1 + q; ++i) drop[i] = 2 * m;

    long long yearly = 0;
    for (auto x : drop) yearly += x;

    long long years = (n - 1) / yearly;
    long long months = years * 12;
    long long rem = n - years * yearly;

    long long acc = 0;
    for (int i = 0; i < 12; ++i) {
        acc += drop[i];
        ++months;
        if (acc >= rem) {
            cout << months;
            return 0;
        }
    }
    return 0;
}
```
