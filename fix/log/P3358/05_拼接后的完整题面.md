# 题目内容
仓库里现有 $n$ 件货物。每个自然月会出库一批货物：普通月份每月出库 $m$ 件；每年从第 $p$ 个月起连续 $q$ 个月为促销期，促销期每月出库 $2m$ 件。

一年固定为 `12` 个月，且促销期不会跨年。当库存降至不超过 `0` 时视为已清仓。求从一月开始，直到清仓为止一共需要多少个月。

约束：初始货物件数不超过 `10^6`，每月常规出库量不超过初始件数，促销起始月在 `1` 到 `12` 之间，促销持续月数不超过当年剩余月份。

# 输入描述
一行输入四个整数 $n$、$m$、$p$ 和 $q$，依次表示初始货物件数、普通月每月出库量、促销起始月份以及促销持续月数。
保证 $1 \le n \le 10^6$，$1 \le m \le n$，$1 \le p \le 12$，$1 \le q \le 13-p$。

# 输出描述
输出一个整数，表示清仓所需的月数。

## 样例1

**输入**

```
1 1 12 1
```

**输出**

```
1
```

**说明**

只有 `1` 件货物，一月即可出库清仓，答案为 `1`。促销排在十二月不影响首月。

## 样例2

**输入**

```
11 2 2 4
```

**输出**

```
4
```

**说明**

按题意模拟计算得到。

## 样例3

**输入**

```
12 3 3 5
```

**输出**

```
3
```

**说明**

按题意模拟计算得到。
