## 解题思路

闸门初始全部开启。用一个集合维护当前处于关闭状态的编号。

每次操作编号 $p$：

- 若 $p$ 不在集合中，说明它当前开启，将其关闭并插入集合；若 $p\le x$，则区间 $[1,x]$ 的关闭数加 $1$；若 $p\ge y$，则区间 $[y,n]$ 的关闭数加 $1$。
- 若 $p$ 已在集合中，说明它当前关闭，将其开启并删除；相应区间的关闭数减 $1$。

区间 $[1,x]$ 中开启数量为 $x$ 减去其中的关闭数；区间 $[y,n]$ 中开启数量为 $n-y+1$ 减去其中的关闭数。每次操作后直接输出这两个值。

## 复杂度分析

每组数据中每次操作对哈希集合做一次插入或删除。

- 时间复杂度：$O(\sum m)$。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
t = int(input())
for _ in range(t):
    n, m, x, y = map(int, input().split())
    ans1, ans2 = 0, 0
    st = set()
    for i in range(m):
        p = int(input())
        if p not in st:
            st.add(p)
            if p <= x:
                ans1 += 1
            if p >= y:
                ans2 += 1
        else:
            st.remove(p)
            if p <= x:
                ans1 -= 1
            if p >= y:
                ans2 -= 1
        print(x - ans1, n - y + 1 - ans2)
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();
        while (T-- > 0) {
            int n = sc.nextInt();
            int m = sc.nextInt();
            int x = sc.nextInt();
            int y = sc.nextInt();
            int ans1 = 0, ans2 = 0;
            Set<Integer> st = new HashSet<>();
            for (int i = 0; i < m; i++) {
                int p = sc.nextInt();
                if (!st.contains(p)) {
                    st.add(p);
                    if (p <= x) ans1++;
                    if (p >= y) ans2++;
                } else {
                    st.remove(p);
                    if (p <= x) ans1--;
                    if (p >= y) ans2--;
                }
                System.out.println((x - ans1) + " " + (n - y + 1 - ans2));
            }
        }
    }
}
```

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int n, m, x, y;
        cin >> n >> m >> x >> y;
        int ans1 = 0, ans2 = 0;
        unordered_set<int> st;
        for (int i = 0; i < m; i++) {
            int p;
            cin >> p;
            if (!st.count(p)) {
                st.insert(p);
                if (p <= x) ans1++;
                if (p >= y) ans2++;
            } else {
                st.erase(p);
                if (p <= x) ans1--;
                if (p >= y) ans2--;
            }
            cout << (x - ans1) << ' ' << (n - y + 1 - ans2) << '\n';
        }
    }
    return 0;
}
```
