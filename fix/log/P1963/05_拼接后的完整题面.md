# 题目内容
有 $n$ 扇闸门，编号为 $1,2,\ldots,n$，初始全部处于开启状态。接下来进行 $m$ 次操作：每次给出一个编号 $p$，若第 $p$ 扇闸门当前开启，则将其关闭；若当前关闭，则将其重新开启。

每一次操作之后，需要分别统计闭区间 $[1,x]$ 与 $[y,n]$ 中处于开启状态的闸门数量。

本题有多组测试数据。测试组数不超过 `1000`。单组 $n$ 不超过 $2 \times 10^5$，$m$ 不超过 $4 \times 10^5$。所有测试中 $n$ 之和不超过 $2 \times 10^5$，$m$ 之和不超过 $4 \times 10^5$。

# 输入描述
第一行一个正整数 $T$（$1 \le T \le 1000$），表示测试组数。
对于每组数据，第一行四个正整数 $n,m,x,y$（$1 \le n \le 2 \times 10^5$；$1 \le m \le 4 \times 10^5$；$1 \le x,y \le n$），依次表示闸门数量、操作次数以及两个闭区间的边界。
接下来 $m$ 行，每行一个正整数 $p$（$1 \le p \le n$），表示对编号为 $p$ 的闸门执行一次翻转。
保证所有测试的 $n$ 之和不超过 $2 \times 10^5$，$m$ 之和不超过 $4 \times 10^5$。

# 输出描述
对于每一次操作，输出一行两个整数：第一个表示闭区间 $[1,x]$ 中开启的闸门数量，第二个表示闭区间 $[y,n]$ 中开启的闸门数量。

## 样例1

**输入**

```
1
3 2 2 2
1
1
```

**输出**

```
1 2
2 2
```

**说明**

三扇闸门初始全开，$[1,2]$ 有 `2` 扇开启，$[2,3]$ 有 `2` 扇开启。
第一次翻转 `1` 后，$[1,2]$ 变为 `1`，$[2,3]$ 仍为 `2`。
第二次再翻转 `1`，闸门 `1` 重新开启，两段恢复为 `2` `2`。
