# 题目内容
有一排共 $n$ 盏灯，每盏灯只有亮起或熄灭两种状态。一次操作可以选择相邻的两盏灯，将它们的状态同时翻转（亮起变熄灭，熄灭变亮起）。
对于任意一个初始状态序列，若经过若干次操作能将所有灯变为熄灭状态，则定义其得分 $g$ 为所需的最少操作次数；否则不计入得分。
现在给定整数 $n$，考虑所有长度为 $n$ 的可能的初始状态序列（共有 $2^n$ 种）。请计算所有合法序列的得分之和。由于答案可能很大，请将结果对 $998244353$ 取模后输出。

数据范围：整数 $n$ 满足 $1 \le n \le 10^9$。

# 输入描述
输入共一行，包含一个整数 $n$，表示灯的数量（即序列长度）。

# 输出描述
输出一行一个整数，表示所有合法序列的得分之和对 $998244353$ 取模后的结果。

## 样例1

**输入**

```
1
```

**输出**

```
0
```

**说明**

当 $n = 1$ 时，只有 $2^1 = 2$ 种初始状态：`0`（熄灭）和 `1`（亮起）。
由于每次操作必须选择相邻的两盏灯，而只有 `1` 盏灯时无法执行任何操作。
初始状态 `0` 本身已是全灭状态，得分为 `0`；初始状态 `1` 含有奇数个 `1`，无法通过操作变为全灭，不计入得分。
因此所有合法序列的得分总和为 $0$。

## 样例2

**输入**

```
3
```

**输出**

```
4
```

**说明**

当 $n = 3$ 时，根据公式 $(n-1) \times 2^{n-2} = (3-1) \times 2^{1} = 2 \times 2 = 4$。
结果对 $998244353$ 取模后仍为 $4$。

我们可以验证：长度为 $3$ 且含有偶数个 `1` 的序列共 $2^{2}=4$ 种（`000`、`011`、`101`、`110`）。
`000` 本身全灭，操作次数为 $0$；`011` 中两盏亮灯位于位置 `2` 和 `3`，距离为 $1$，操作次数为 $1$；类似地 `101` 亮灯位于 `1` 和 `3`，距离为 $2$；`110` 亮灯位于 `1` 和 `2`，距离为 $1$。
总和为 $0+1+2+1=4$，与公式一致。

## 样例3

**输入**

```
4
```

**输出**

```
12
```

**说明**

当 $n = 4$ 时，根据公式 $(n-1) \times 2^{n-2} = (4-1) \times 2^{2} = 3 \times 4 = 12$。
结果对 $998244353$ 取模后仍为 $12$。
长度为 $4$ 的合法序列共有 $2^{3}=8$ 种，其得分之和可用组合计数推导得出 $12$。

## 样例4

**输入**

```
10
```

**输出**

```
2304
```

**说明**

当 $n = 10$ 时，计算公式为 $(10-1) \times 2^{10-2} = 9 \times 2^{8} = 9 \times 256 = 2304$。
结果对 $998244353$ 取模后为 $2304$。
此处 $n$ 较小，答案未超过模数。
