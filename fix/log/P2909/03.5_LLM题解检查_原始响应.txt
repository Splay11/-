## 解题思路

1. **可行性分析**  
   - 一次操作选择相邻两盏灯并同时翻转，不改变亮灯个数（即状态为1的个数）的奇偶性。  
   - 因此，只有当初始序列中亮灯的个数 $M$ 为偶数时，才有可能通过一系列操作将所有灯变为熄灭状态；否则该序列不合法，不计入得分。

2. **单个合法序列的最少操作数**  
   - 设一个合法序列中亮灯的位置为 $p_1 < p_2 < \dots < p_M$（$M$ 为偶数）。  
   - 最优策略：将第 $2k-1$ 盏亮灯与第 $2k$ 盏亮灯配对消除，每对所需的操作次数恰好为 $p_{2k} - p_{2k-1}$。  
   - 因此该序列的得分 $g = \sum_{k=1}^{M/2} (p_{2k} - p_{2k-1})$。

3. **全局求和与公式化简**  
   - 需要计算所有长度为 $n$ 且亮灯个数为偶数的序列的得分之和。  
   - 通过组合计数或插值法，可以将这一求和化简为简洁的闭合形式：  
     \[
     \text{总和} = (n-1) \cdot 2^{n-2} \quad (\bmod 998244353)
     \]
   - 特殊情况：当 $n=1$ 时，两个序列（全0和全1）中仅全0合法（得分为0），总和为0。公式在 $n=1$ 时不适用，需要单独处理。

4. **大数计算**  
   - $n$ 最大可达 $10^9$，需要利用快速幂在 $O(\log n)$ 时间内计算 $2^{n-2} \bmod 998244353$。  
   - 取模后与 $n-1$ 相乘并再次取模即得答案。

## 复杂度分析

- 时间复杂度：仅进行常数次取模运算和一次快速幂，时间复杂度为 $O(\log n)$。  
- 空间复杂度：仅使用几个变量，空间复杂度为 $O(1)$。

## 代码实现

### Python

```python
MOD = 998244353

def solve():
    n = int(input().strip())
    if n == 1:
        print(0)
        return
    # ans = (n-1) * 2^(n-2) % MOD
    ans = ((n - 1) % MOD) * pow(2, n - 2, MOD) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.Scanner;

public class Main {
    static final int MOD = 998244353;

    // 快速幂：计算 a^e % MOD
    static long powMod(long a, long e) {
        long r = 1;
        while (e > 0) {
            if ((e & 1) == 1) {
                r = r * a % MOD;
            }
            a = a * a % MOD;
            e >>= 1;
        }
        return r;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        long n = sc.nextLong();
        sc.close();

        if (n == 1) {
            System.out.println(0);
            return;
        }
        // ans = (n-1) * 2^(n-2) % MOD
        long ans = ((n - 1) % MOD) * powMod(2, n - 2) % MOD;
        System.out.println(ans);
    }
}
```

```cpp
const int MOD = 998244353;

long long powMod(long long a, long long e) {
    long long r = 1;
    while (e) {
        if (e & 1) {
            r = r * a % MOD;
        }
        a = a * a % MOD;
        e >>= 1;
    }
    return r;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n;
    cin >> n;

    if (n == 1) {
        cout << 0;
        return 0;

    // ans = (n-1) * 2^(n-2) % MOD
    long long ans = ((n - 1) % MOD) * powMod(2, n - 2) % MOD;

}
```
