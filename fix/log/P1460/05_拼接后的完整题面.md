# 题目内容
地图上有 $n$ 个驿站，由 $m$ 条双向道路连接。你需要从 `1` 号驿站出发，把物资送到指定驿站后必须返回 `1` 号驿站，一共配送 $q$ 次。每次配送都从 `1` 号重新出发，互不影响。

请计算完成全部 $q$ 次往返配送所需的最短路程之和。

驿站数、道路数与配送次数均不超过 `10^5`。道路长度为不超过 `10^4` 的正整数。驿站编号为 `1` 到 $n$。保证给定的道路满足 $u 
eq v$。

# 输入描述
第一行包含三个整数 $n$、$m$ 和 $q$（$1 \le n,m,q \le 10^5$），分别表示驿站数、道路数和配送次数。
接下来 $m$ 行，每行三个整数 $u$、$v$（$1 \le u,v \le n$，$u 
eq v$）和 $w$（$1 \le w \le 10^4$），表示驿站 $u$ 与 $v$ 之间有一条长度为 $w$ 的双向道路。
最后一行包含 $q$ 个整数，表示每次配送需要送达的驿站编号。

# 输出描述
输出一个整数，表示全部往返配送的最短路程之和。

## 样例1

**输入**

```
4 3 3
1 2 1
2 3 2
3 4 3
2 3 4
```

**输出**

```
20
```

**说明**

`1` 号到 `2`、`3`、`4` 号的最短路分别为 `1`、`3`、`6`。
三次往返路程为 $2\times(1+3+6)=`20`$。

## 样例2

**输入**

```
3 2 1
1 2 5
2 3 5
3
```

**输出**

```
20
```

**说明**

`1` 号到 `3` 号最短路为 `10`，一次往返为 $2\times 10=`20`$。

## 样例3

**输入**

```
2 1 2
1 2 10
2 2
```

**输出**

```
40
```

**说明**

两次都送到 `2` 号驿站，单程 `10`，每次往返 `20`，总和为 `40`。
