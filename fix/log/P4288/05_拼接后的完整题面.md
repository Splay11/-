# 题目内容
在一个数据处理任务中，需要维护一个长度为 $n$ 的整数序列，并依次响应用户的 $q$ 次操作。操作分为两种类型：

- **询问**：给定一个整数 $k$，统计当前序列中能被 $k$ 整除的元素个数。
- **更新**：将序列中第 $i$ 个元素的值修改为 $x$（下标从 $1$ 开始）。

请你为每次询问输出对应的答案。

序列的长度 $n$ 与操作总数 $q$ 均不超过 $2 \times 10^5$，所有涉及到的整数值（包括初始序列的元素、询问中的 $k$ 以及更新中的 $x$）均不超过 $2 \times 10^5$。

# 输入描述
第一行包含两个整数 $n$ 和 $q$，表示序列长度与操作次数。
第二行包含 $n$ 个整数，表示初始序列。
接下来 $q$ 行，每行描述一个操作：
- 若为询问，则格式为 `1 k`，其中 $k$ 为需要整除的整数。
- 若为更新，则格式为 `2 i x`，表示将第 $i$ 个元素的值改为 $x$。

# 输出描述
对于每个询问操作，输出一行一个整数，表示当前序列中能被 $k$ 整除的元素个数。

## 样例1

**输入**

```
5 6
1 2 4 5 10
1 1
1 5
2 2 6
1 2
2 4 7
1 10
```

**输出**

```
5
2
3
1
```

**说明**

初始序列为 $[1, 2, 4, 5, 10]$。
- 询问 $k=1$：任意整数都能被 `1` 整除，因此当前序列中所有 `5` 个元素均满足，答案为 `5`。
- 询问 $k=5$：序列中能被 `5` 整除的元素为 $5$ 和 $10$，共 `2` 个，答案为 `2`。
- 更新操作：将第 `2` 个元素从 $2$ 修改为 $6$，序列变为 $[1, 6, 4, 5, 10]$。
- 询问 $k=2$：更新后的序列中，能被 `2` 整除的元素为 $6, 4, 10$，共 `3` 个，答案为 `3`。
- 更新操作：将第 `4` 个元素从 $5$ 修改为 $7$，序列变为 $[1, 6, 4, 7, 10]$。
- 询问 $k=10$：序列中能被 `10` 整除的元素只有 $10$，共 `1` 个，答案为 `1`。

## 样例2

**输入**

```
1 3
3
1 3
2 1 5
1 3
```

**输出**

```
1
0
```

**说明**

初始序列为 $[3]$，仅有 `1` 个元素。
- 询问 $k=3$：元素 $3$ 能被 $3$ 整除，答案为 `1`。
- 更新操作：将第 `1` 个元素修改为 $5$，序列变为 $[5]$。
- 询问 $k=3$：元素 $5$ 不能被 $3$ 整除，答案为 `0`。

## 样例3

**输入**

```
3 4
2 4 6
1 8
2 1 8
1 8
1 1
```

**输出**

```
0
1
3
```

**说明**

初始序列为 $[2, 4, 6]$。
- 询问 $k=8$：序列中没有元素能被 `8` 整除（$8$ 大于所有元素），答案为 `0`。
- 更新操作：将第 `1` 个元素修改为 $8$，序列变为 $[8, 4, 6]$。
- 询问 $k=8$：元素 $8$ 能被 `8` 整除，答案为 `1`。
- 询问 $k=1$：所有元素都能被 `1` 整除，共 `3` 个，答案为 `3`。
