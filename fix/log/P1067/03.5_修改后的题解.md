## 解题思路

用可变序列存储字符串。每次从 $r$ 倒到 $l$，在位置 $i$ 处插入 $s_{i}$（1-based 的第 $i$ 个字符）。$q$ 很小，直接模拟即可。

## 复杂度分析

时间复杂度与最终串长及 $q$ 有关，在给定范围内可接受；空间复杂度 $O(L)$，$L$ 为最终长度。

## 代码实现

### Python

```python
n, q = map(int, input().split())
s = list(input().strip())
for _ in range(q):
    l, r = map(int, input().split())
    for i in range(r, l - 1, -1):
        s.insert(i, s[i - 1])
print(''.join(s))
```

### Java

```java
import java.util.*;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt(), q = sc.nextInt();
        String str = sc.next();
        StringBuilder s = new StringBuilder(str);
        for (int t = 0; t < q; t++) {
            int l = sc.nextInt(), r = sc.nextInt();
            for (int i = r; i >= l; i--) s.insert(i, s.charAt(i - 1));
        }
        System.out.println(s);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, q; cin >> n >> q;
    string s; cin >> s;
    while (q--) {
        int l, r; cin >> l >> r;
        for (int i = r; i >= l; --i) s.insert(s.begin() + i, s[i - 1]);
    }
    cout << s << '\n';
}
```
