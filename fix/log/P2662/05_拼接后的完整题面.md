# 题目内容
货仓里维护着一批货物编号。初始时货仓为空，随后会依次发生 $n$ 次操作，操作共有三种：

- 类型 `1`：向货仓放入一个编号为 $x$ 的货物（允许出现相同编号）；
- 类型 `2`：从货仓取出一个编号为 $x$ 的货物（保证取出前货仓中至少有一件该编号）；
- 类型 `3`：询问当前货仓中，哪一个编号与给定整数 $x$ 的按位异或值最大。若货仓为空，则该次询问的答案为 $-1$。

对于每一次类型 `3` 的询问，你需要输出对应答案。保证至少发生一次询问。

操作次数 $n$ 满足 $1 \le n \le 2 \times 10^5$。每次操作的参数 $x$ 满足 $1 \le x \le 10^9$。

# 输入描述
第一行包含一个正整数 $n$，表示操作次数。
接下来 $n$ 行，每行包含两个整数 $op$ 和 $x$，其中 $op$ 为操作类型（$1 \le op \le 3$），$x$ 为该次操作的参数。

# 输出描述
对于每一次类型为 `3` 的询问，输出一行一个整数，表示答案。

## 样例1

**输入**

```
10
1 5
1 7
1 4
3 8
2 4
1 2
1 6
3 9
2 6
3 9
```

**输出**

```
15
15
14
```

**说明**

货仓依次放入 `5`、`7`、`4`。询问 $x=8$ 时，$8 \oplus 7 = 15$ 最大。取出 `4` 后再放入 `2`、`6`，询问 $x=9$ 时 $9 \oplus 6 = 15$ 最大。取出 `6` 后询问 $x=9$，$9 \oplus 7 = 14$ 最大。

## 样例2

**输入**

```
1
3 1
```

**输出**

```
-1
```

**说明**

货仓初始为空，第一次操作就是询问，按题意输出 $-1$。

## 样例3

**输入**

```
2
1 1
3 2
```

**输出**

```
3
```

**说明**

放入编号 `1` 后询问 $x=2$。$1 \oplus 2 = 3$，货仓中只有这一件货物，答案为 `3`。
