# 题目内容
一条骨干光缆上依次设有 $n$ 个中继点，第 $i$ 个中继点的信号强度为 $a_i$。调度规范把整条链路的质量定义为所有中继点信号强度的最小值，因此最弱的那一处会拖垮全线。运维窗口里只有 $k$ 次校准机会，每次可以把连续不超过 $l$ 个中继点的信号强度改成任意正整数。请计算在这些限制下，校准后链路质量能达到的最大值。

约束：$2 \le n \le 100000$，$1 \le k \cdot l < n$，$1 \le a_i \le 1000000000$。

# 输入描述
第一行三个整数 $n$、$k$ 和 $l$，分别表示中继点数、校准次数与单次最长连续长度。
第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$，表示各中继点的初始信号强度。
保证 $2 \le n \le 100000$，$1 \le k \cdot l < n$，$1 \le a_i \le 1000000000$。

# 输出描述
输出一个整数，表示校准后链路质量（即全局最小值）能达到的最大值。

## 样例1

**输入**

```
6 1 2
3 9 1 8 2 5
```

**输出**

```
2
```

**说明**

只有 `1` 次、长度 `2` 的翻修。若目标最小值设为 `3`，则 `1` 与 `2` 两处低点无法被同一段覆盖。目标为 `2` 时，只需覆盖值为 `1` 的那一段即可，答案为 `2`。

## 样例2

**输入**

```
5 2 1
10 1 10 1 10
```

**输出**

```
10
```

**说明**

两次单点翻修恰好覆盖两个 `1`，可以把它们抬到不小于 `10`，全局最小值变为 `10`。

## 样例3

**输入**

```
4 1 1
2 8 3 6
```

**输出**

```
3
```

**说明**

只能改一个位置。把 `2` 抬高后，剩下的最小值为 `3`；无法同时处理 `2` 和 `3`，因此答案为 `3`。
