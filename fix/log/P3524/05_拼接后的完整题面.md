# 题目内容
在一条智能生产线上，有三种基础零件，分别标记为 `A`、`L`、`I`。生产线按照固定的 `A` → `L` → `I` 的顺序循环抓取零件进行组装。

当某种零件暂时短缺时，机器人会自动跳过它，继续按顺序尝试后续零件，直到所有零件全部用完。

现在给你一个包含大写字母的原料序列，其中可能含有其他无关字符。请你统计序列中 `A`、`L`、`I` 这三种零件的数量，然后模拟上述组装过程，输出组装后的零件序列。

如果序列中完全没有 `A`、`L`、`I` 中任何一个，则输出 `-1`。

约束条件：
- 需要处理多个测试用例，测试用例数量不超过 `5`。
- 每个原料序列的长度不超过 `100`。

# 输入描述
第一行包含一个整数 $n$，表示测试用例的数量。接下来 $n$ 行，每行包含一个由大写字母 `A` 至 `Z` 组成的字符串，表示原料序列。$n$ 不超过 `5`，字符串长度不超过 `100`。

# 输出描述
对于每个测试用例，输出一行结果字符串。如果没有任何有效零件，输出 `-1`。

## 样例1

**输入**

```
4
ABICDIEA
XALYIZA
BCDEFG
AAA
```

**输出**

```
AIAI
ALIA
-1
AAA
```

**说明**

第一个字符串 "ABICDIEA"：
统计：$A$ 出现 `2` 次，$L$ 出现 `0` 次，$I$ 出现 `2` 次，总有效零件 `4` 个。模拟组装：
- 起始指针 $p=0$（对应 $A$），$A$ 有剩余，输出 `A`，剩余 $A=1$，$p$ 移至 `1`（$L$）；
- $p=1$，$L$ 无剩余，跳过；尝试 $I$（$p=2$），$I$ 有剩余，输出 `I`，剩余 $I=1$，$p$ 移至 $0$；
- $p=0$，$A$ 有剩余，输出 `A`，剩余 $A=0$，$p$ 移至 $1$；
- $p=1$，$L$ 无剩余，跳过；尝试 $I$，输出 `I`，剩余 $I=0$，结束。
得到结果 `AIAI`。

第二个字符串 "XALYIZA"：
统计 $A=2$, $L=1$, $I=1$。按 $A \to L \to I \to A$ 顺序输出，得到 `ALIA`。

第三个字符串 "BCDEFG" 不含 $A,L,I$，输出 `-1`。

第四个字符串 "AAA" 仅含 `3` 个 $A$，按顺序每次从 $A$ 开始，用完一个后指针移向 $L$、$I$ 均空，回绕到 $A$，连续输出 `AAA`。
