## 解题思路

桩位很少（$n \le 25$），本质是在一条链上做回溯：从 $x$ 出发，每次尝试 $\pm 1$、$\pm 2$，要求新坐标落在 $[0,n]$ 且未被访问。到达 $y$ 即记一种方案并停止延伸。

起点视为已访问。用 DFS / 回溯搜索全部路径，到达目标后立即返回，不再继续走。

## 复杂度分析

状态为当前点与已访问集合，最坏约 $O(n \cdot 2^n)$；因 $n \le 25$ 且步长受限，实际可接受。空间复杂度 $O(n)$。

## 代码实现

### Python

```python
def dfs(current, visited, n, y):
    if current == y:
        return 1

    visited[current] = True
    total_paths = 0
    moves = [-1, -2, 1, 2]

    for move in moves:
        next_pos = current + move
        if 0 <= next_pos <= n and not visited[next_pos]:
            total_paths += dfs(next_pos, visited, n, y)

    visited[current] = False
    return total_paths

def main():
    n, x, y = map(int, input().split())
    visited = [False] * (n + 1)
    print(dfs(x, visited, n, y))

if __name__ == '__main__':
    main()
```

### Java

```java
import java.util.*;

public class Main {
    static int n, x, y;
    static boolean[] visited;

    public static int dfs(int current) {
        if (current == y) {
            return 1;
        }

        visited[current] = true;
        int totalPaths = 0;
        int[] moves = {-1, -2, 1, 2};

        for (int move : moves) {
            int next = current + move;
            if (next >= 0 && next <= n && !visited[next]) {
                totalPaths += dfs(next);
            }
        }

        visited[current] = false;
        return totalPaths;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        n = sc.nextInt();
        x = sc.nextInt();
        y = sc.nextInt();
        visited = new boolean[n + 1];
        System.out.println(dfs(x));
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>

using namespace std;

int n, x, y;
vector<bool> visited;

int dfs(int current) {
    if (current == y) {
        return 1;
    }

    visited[current] = true;
    int totalPaths = 0;
    int moves[] = {-1, -2, 1, 2};

    for (int i = 0; i < 4; i++) {
        int next = current + moves[i];
        if (next >= 0 && next <= n && !visited[next]) {
            totalPaths += dfs(next);
        }
    }

    visited[current] = false;
    return totalPaths;
}

int main() {
    cin >> n >> x >> y;
    visited = vector<bool>(n + 1, false);
    cout << dfs(x) << endl;
    return 0;
}
```
