## 题解

### 题面描述

我们需要从数轴上的坐标 $x$ 出发，使用四种不同的移动方式（向左移动 $1$ 格，向左移动 $2$ 格，向右移动 $1$ 格，向右移动 $2$ 格），最终到达坐标 $y$。每个坐标点最多访问一次，且移动时必须保持在数轴的范围内，即坐标值始终在 $[0, n]$ 之间。

我们要计算从 $x$ 到 $y$ 的所有可能的移动路径的数量。

### 思路

这个问题本质上是一个**图的遍历**问题，可以使用**深度优先搜索（DFS）**来解决。每次从当前位置出发，尝试四种可能的移动方式（向左或向右）。在每次移动时，我们需要确保：

1. 移动后的位置不超出数轴范围，即 $0 \leq \text{新位置} \leq n$。
2. 每个位置最多访问一次，起始点视为已访问。

我们可以使用 DFS 或者回溯算法来搜索所有可能的路径。在搜索过程中，当我们到达目标位置 $y$ 时，记录一个方案。

#### C++ 

```cpp
#include <iostream>
#include <vector>

using namespace std;

int n, x, y;
vector<bool> visited;  // 用来标记是否已经访问过某个位置

// 深度优先搜索
int dfs(int current) {
    // 如果当前坐标已经到达目标点y，返回1
    if (current == y) {
        return 1;
    }
    
    // 标记当前位置为已访问
    visited[current] = true;
    int totalPaths = 0;
    
    // 四种可能的移动方式
    int moves[] = {-1, -2, 1, 2};
    
    for (int i = 0; i < 4; i++) {
        int next = current + moves[i];
        
        // 如果新位置合法且没有被访问过
        if (next >= 0 && next <= n && !visited[next]) {
            totalPaths += dfs(next);  // 递归调用
        }
    }
    
    // 恢复当前位置的访问状态
    visited[current] = false;
    return totalPaths;
}

int main() {
    cin >> n >> x >> y;
    visited = vector<bool>(n + 1, false);  // 初始化visited数组
    
    // 从起点x开始深度优先搜索
    cout << dfs(x) << endl;
    
    return 0;
}
```
#### Python 

```python
def dfs(current, visited, n, y):
    # 如果当前坐标已经到达目标点y，返回1
    if current == y:
        return 1
    
    # 标记当前位置为已访问
    visited[current] = True
    total_paths = 0
    
    # 四种可能的移动方式
    moves = [-1, -2, 1, 2]
    
    for move in moves:
        next_pos = current + move
        
        # 如果新位置合法且没有被访问过
        if 0 <= next_pos <= n and not visited[next_pos]:
            total_paths += dfs(next_pos, visited, n, y)  # 递归调用
    
    # 恢复当前位置的访问状态
    visited[current] = False
    return total_paths

def main():
    n, x, y = map(int, input().split())
    visited = [False] * (n + 1)  # 初始化visited数组
    
    # 从起点x开始深度优先搜索
    print(dfs(x, visited, n, y))

if __name__ == '__main__':
    main()
```
