# 题目内容
小蓝有一个环形灯阵，灯阵上依次排列着 `n` 盏灯。每盏灯都有一个非负整数亮度值，按顺时针顺序记为 $a_1, a_2, \dots, a_n$。她想通过以下方式计算灯阵的“交错能量”：

1. 任意选择一盏灯作为起点，从该灯开始顺时针遍历整个环形灯阵，得到一个长度为 `n` 的线性序列 $b_1, b_2, \dots, b_n$。
2. 对该线性序列计算交错和：$S = b_1 - b_2 + b_3 - b_4 + \dots + (-1)^{n-1} b_n$。

小蓝希望知道，在所有可能的起点中，交错和 $S$ 的最大值是多少。请你输出这个最大值。

约束条件：灯的数量 $n$ 满足 $1 \le n \le 2 \times 10^5$；每盏灯的亮度 $a_i$ 满足 $0 \le a_i < n$。

# 输入描述
第一行包含一个整数 `n`，表示灯的数量。
第二行包含 `n` 个整数 $a_1, a_2, \dots, a_n$，依次表示顺时针排列的各盏灯的亮度值，相邻整数之间用空格分隔。

# 输出描述
输出一个整数，表示所有可能的起点所对应的交错和的最大值。

## 样例1

**输入**

```
1
0
```

**输出**

```
0
```

**说明**

灯阵只有 `n = 1` 盏灯，亮度为 $a_1 = 0$。无论选择哪一盏灯作为起点（这里只有唯一的选择），线性序列都是 $b = [0]$。交错和 $S = b_1 = 0$。因此最大交错和为 `0`。

## 样例2

**输入**

```
4
0 3 2 1
```

**输出**

```
2
```

**说明**

共有 `4` 盏灯，亮度依次为 $0, 3, 2, 1$，因为 $n$ 是偶数，交错和的计算形式为 $S = b_1 - b_2 + b_3 - b_4$。

枚举所有可能的起点：
- 以第 `1` 盏灯为起点，序列为 $0, 3, 2, 1$，$S = 0 - 3 + 2 - 1 = -2$；
- 以第 `2` 盏灯为起点，序列为 $3, 2, 1, 0$，$S = 3 - 2 + 1 - 0 = 2$；
- 以第 `3` 盏灯为起点，序列为 $2, 1, 0, 3$，$S = 2 - 1 + 0 - 3 = -2$；
- 以第 `4` 盏灯为起点，序列为 $1, 0, 3, 2$，$S = 1 - 0 + 3 - 2 = 2$。

所有可能交错和的最大值为 `2`。

## 样例3

**输入**

```
3
1 2 1
```

**输出**

```
2
```

**说明**

有 `3` 盏灯，亮度依次为 $1, 2, 1$，$n$ 为奇数，交错和的形式为 $S = b_1 - b_2 + b_3$。

枚举所有起点：
- 起点为第 `1` 盏灯，序列 $1, 2, 1$，$S = 1 - 2 + 1 = 0$；
- 起点为第 `2` 盏灯，序列 $2, 1, 1$，$S = 2 - 1 + 1 = 2$；
- 起点为第 `3` 盏灯，序列 $1, 1, 2$，$S = 1 - 1 + 2 = 2$。

最大值是 `2`。
