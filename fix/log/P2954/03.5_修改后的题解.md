## 解题思路

我们需要在一个环形灯阵中，选定任意一盏灯作为起点，顺时针得到一个长度为 $n$ 的线性序列 $b_1, \dots, b_n$，并计算交错和
$$S = b_1 - b_2 + b_3 - b_4 + \cdots + (-1)^{n-1} b_n$$
求所有可能起点的 $S$ 的最大值。

直接对每一个起点单独计算交错和的复杂度为 $O(n^2)$，在 $n \le 2\times 10^5$ 时无法满足要求。可以利用递推关系在 $O(1)$ 时间内从一个起点的交错和转移到顺时针下一个起点的交错和。

设 $S_k$ 表示从第 $k$ 个位置作为起点时的交错和（这里位置下标按输入顺序从 $1$ 到 $n$ 记，即 $S_1$ 对应起点 $a_1$）。我们可以先计算出 $S_1$ 的值，然后推导 $S_{k+1}$ 与 $S_k$ 的关系：

- $S_k = a_k - a_{k+1} + a_{k+2} - \cdots + (-1)^{n-1} a_{k-1}$ （下标均对 $n$ 取模）。
- 去掉第一个元素 $a_k$ 后，剩下的 $n-1$ 项正好是以 $a_{k+1}$ 为起点的交替和，但符号相反：
  $$S_k - a_k = -(a_{k+1} - a_{k+2} + \cdots + (-1)^{n-2} a_{k-1})$$
- 再补上最后一项，即原序列移动后，末尾应添加 $(-1)^{n-1} a_k$，于是
  $$S_{k+1} = -(S_k - a_k) + (-1)^{n-1} a_k$$

因此，只需计算一次初始交错和 $S_1$，然后遍历 $k = 1, 2, \dots, n-1$，不断更新 $S_{k+1}$ 并跟踪最大值即可。

算法步骤：
1. 读取 $n$ 和亮度数组 $a_1 \dots a_n$。
2. 计算 $S_1 = \sum_{i=0}^{n-1} (-1)^i a_{i+1}$（编程时下标从 $0$ 开始）。
3. 令常数 $c = (-1)^{n-1}$，并设答案 $ans = S_1$。
4. 对 $k$ 从 $1$ 到 $n-1$（数组下标 $0$ 到 $n-2$）：
   $$S = -(S - a_k) + c \cdot a_k$$
   并更新 $ans = \max(ans, S)$。
5. 输出 $ans$。

## 复杂度分析

- 时间复杂度：初始计算 $S_1$ 需要遍历一次数组，递推更新也需要遍历一次数组，总时间复杂度为 $O(n)$。
- 空间复杂度：需要存储亮度数组，空间复杂度为 $O(n)$；除了输入数组外，仅使用了常数个额外变量。

## 代码实现

### Python

```python
import sys

def main():
    data = sys.stdin.read().split()
    if not data:
        return
    n = int(data[0])
    a = list(map(int, data[1:1 + n]))

    # 1. 计算从第一盏灯开始的交错和 S1
    S = 0
    for i in range(n):
        if i % 2 == 0:
            S += a[i]
        else:
            S -= a[i]

    # c = (-1)^(n-1)
    c = 1 if n % 2 == 1 else -1

    ans = S
    # 2. 递推计算其他起点的交错和
    for k in range(n - 1):
        S = -(S - a[k]) + c * a[k]
        if S > ans:
            ans = S

    print(ans)

if __name__ == "__main__":
    main()
```

import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine());
        StringTokenizer st = new StringTokenizer(br.readLine());
        long[] a = new long[n];
        for (int i = 0; i < n; i++) {
            a[i] = Long.parseLong(st.nextToken());
        }

        // 1. 计算从第一盏灯开始的交错和 S1
        long S = 0;
        for (int i = 0; i < n; i++) {
            if (i % 2 == 0) {
                S += a[i];
            } else {
                S -= a[i];
            }
        }

        // c = (-1)^(n-1)
        long c = (n % 2 == 1) ? 1L : -1L;

        long ans = S;
        // 2. 递推计算其他起点的交错和
        for (int k = 0; k < n - 1; k++) {
            S = -(S - a[k]) + c * a[k];
            if (S > ans) {
                ans = S;
            }
        }

        System.out.println(ans);
    }
}
