# 题目内容
给定 $1\ldots n$ 的排列。最多交换一次两个位置，问是否存在长度为 $k$ 的连续子段构成排列。若能，输出 `YES` 及交换方案；否则 `NO`。

# 输入描述
第一行 $n,k$。第二行 $n$ 个整数。$1 \le k \le n \le 10^5$。

# 输出描述
能则第一行 `YES`，第二行整数 $x$（$0$ 或 $1$），若 $x=1$ 再一行两个位置 $u,v$。否则一行 `NO`。

## 样例1

**输入**

```
5 3
1 2 3 4 5
```

**输出**

```
YES
0
```

**说明**

`1` 到 `3` 出现在位置 $1,2,3$，已经连续，子段 $[1,2,3]$ 本身就是长度为 `3` 的排列。
无需交换，输出 `YES` 与 `0`。

## 样例2

**输入**

```
5 3
1 2 4 3 5
```

**输出**

```
YES
1
3 4
```

**说明**

`1` 到 `3` 的位置为 $1,2,4$，尚未连续。
去掉最右端位置 `4` 后，剩余位置跨度恰好缺一个空位 `3`。
交换位置 `3` 与 `4` 后序列变为 $1,2,3,4,5$，窗口 $[1,2,3]$ 成为长度为 `3` 的排列。

## 样例3

**输入**

```
11 3
1 8 9 2 10 11 3 4 5 6 7
```

**输出**

```
NO
```

**说明**

`1`、`2`、`3` 分别出现在位置 $1,4,7$，彼此间隔过远。
丢掉任意一端后，剩余两个位置之间仍不止一个空洞，一次交换无法使它们挤进长度为 `3` 的窗口，故输出 `NO`。

## 样例4

**输入**

```
1 1
1
```

**输出**

```
YES
0
```

**说明**

序列只有一个数 `1`，本身就是长度为 `1` 的排列，无需交换。
