# 题目内容
小蓝定义了一种有趣的数字性质。

- 对于一个自然数 $x$，若将其各位数字反序排列后得到的整数与 $x$ 相等，则称 $x$ 为「镜像数」。例如 $12321$ 就是镜像数。
- 若存在整数 $k$ 使得 $y = k^2$，则称 $y$ 为「完全平方数」。
- 一个正整数 $N$ 被称为「星光数」，当且仅当它可以表示为一个镜像数 $P$ 与一个完全平方数 $Q$ 的和，即 $N = P + Q$。

现在给定一个正整数 $N$，请你判断它是否为星光数。如果是，你需要找出一种满足条件的拆分方式，并要求完全平方数 $Q$ 尽可能小。

输入的整数 $N$ 满足 $1 \le N \le 10^5$。

# 输入描述
输入共一行，包含一个整数 $N$（$1 \le N \le 10^5$），表示待判断的正整数。

# 输出描述
若 $N$ 是星光数，第一行输出 `YES`，第二行输出两个整数 $P$ 和 $Q$，中间用一个空格隔开，表示满足条件的镜像数和完全平方数，且 $Q$ 是所有可行方案中最小的。若 $N$ 不是星光数，则仅输出一行 `NO`。

## 样例1

**输入**

```
10
```

**输出**

```
YES
9 1
```

**说明**

对于 $N = 10$，我们从小到大枚举完全平方数 $Q$，寻找是否存在镜像数 $P$ 使得 $10 = P + Q$。

当 $Q = 1$ 时，$P = 10 - 1 = 9$，而 `9` 是镜像数（反序排列仍为 `9`）。此时 $Q = 1$ 已经是可能的最小完全平方数，因此输出 `9` 和 `1`。

## 样例2

**输入**

```
45
```

**输出**

```
YES
44 1
```

**说明**

对于 $N = 45$，首先尝试 $Q = 1$，得到 $P = 45 - 1 = 44$。

`44` 的各位数字反序排列后仍为 `44`，因此它是一个镜像数。此时 $Q = 1$ 为最小完全平方数，故输出 `44` 和 `1`。

## 样例3

**输入**

```
99
```

**输出**

```
NO
```

**说明**

对于 $N = 99$，我们枚举所有不超过 `99` 的完全平方数 $Q$，并检查对应的 $P = 99 - Q$ 是否为镜像数。

完全平方数 $Q$ 依次为 $1, 4, 9, 16, 25, 36, 49, 64, 81$，对应的 $P$ 分别为 `98, 95, 90, 83, 74, 63, 50, 35, 18`。这些数字均不是镜像数（例如 `98` 反序为 `89`，`95` 反序为 `59`，均不相等）。

由于枚举完所有可能的 $Q$ 仍未找到满足条件的拆分，因此 `99` 不是星光数，输出 `NO`。

## 样例4

**输入**

```
100
```

**输出**

```
YES
99 1
```

**说明**

对于 $N = 100$，从最小的完全平方数开始尝试。

当 $Q = 1$ 时，$P = 100 - 1 = 99$。`99` 反序排列后依旧是 `99`，是镜像数。此时 $Q = 1$ 为最小完全平方数，满足题目要求，因此输出 `99` 和 `1`。
