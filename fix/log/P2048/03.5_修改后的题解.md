## 解题思路

我们需要判断正整数 $N$ 能否拆分为一个镜像数 $P$ 和一个完全平方数 $Q = k^2$ 的和，并且在所有可行方案中，要求 $Q$ 尽可能小。

由于 $Q$ 是完全平方数，可以从小到大枚举 $k = 1, 2, \dots$，令 $Q = k^2$，直到 $k^2 > N$。对于每个 $Q$，计算 $P = N - Q$，然后检查 $P$ 是否为镜像数（即将数字反转后与原数相等）。若 $P$ 是镜像数，则当前 $Q$ 就是所有可行方案中最小的完全平方数（因为 $k$ 是从小到大枚举的），直接按要求输出并结束程序。

若枚举完所有可能的 $Q$ 后仍未找到满足条件的 $P$，则说明 $N$ 不是星光数，输出 `NO`。

判断一个整数是否为镜像数，可以将其转换为字符串，然后检查该字符串是否与其反转后的字符串相等。

## 复杂度分析

- **时间复杂度**：$k$ 最多枚举到 $\sqrt{N}$，即 $O(\sqrt{N})$ 次迭代。每次判断镜像数需要将整数转换为字符串并反转，字符串长度 $L = O(\log_{10} N)$，反转操作耗时 $O(L)$。当 $N \le 10^5$ 时，$\sqrt{N} \le 316$，$L \le 6$，总操作次数极少。时间复杂度可记为 $O(\sqrt{N} \log_{10} N)$。
- **空间复杂度**：仅使用了常数个变量，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
n = int(input())
k = 1
while k * k <= n:
    p = n - k * k
    s = str(p)
    # 判断 p 是否为镜像数（回文数）
    if s == s[::-1]:
        print("YES")
        print(p, k * k)
        exit()
    k += 1
print("NO")
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int k = 1;

        while (k * k <= n) {
            int p = n - k * k;
            if (isMirror(p)) {
                System.out.println("YES");
                System.out.println(p + " " + (k * k));
                return;
            }
            k++;
        }
        System.out.println("NO");
    }

    // 判断一个数是否为镜像数（反转后相等）
    private static boolean isMirror(int num) {
        String s = String.valueOf(num);
        String rev = new StringBuilder(s).reverse().toString();
        return s.equals(rev);
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
using namespace std;

// 判断一个数是否为镜像数
bool isMirror(int num) {
    string s = to_string(num);
    string rev(s.rbegin(), s.rend());
    return s == rev;
}

int main() {
    int n;
    cin >> n;
    int k = 1;

    while (k * k <= n) {
        int p = n - k * k;
        if (isMirror(p)) {
            cout << "YES" << endl;
            cout << p << " " << (k * k) << endl;
            return 0;
        }
        k++;
    }
    cout << "NO" << endl;
    return 0;
}
```
