# 题目内容
给定一个仅由字符 `+` 和 `-` 组成的字符串，我们称它的一个前缀是合法的，当且仅当从前往后扫描该前缀时，维护一个累加值（初始为 `0`），每遇到一个 `+` 就将累加值加 `1`，每遇到一个 `-` 就将累加值减 `1`，且在整个扫描过程中累加值始终不小于 `0`，并且扫描结束时累加值恰好为 `0`。空前缀视为合法。请你找出该字符串的最长合法前缀的长度。

字符串的长度 $n$ 满足 $1 \le n \le 10^5$，且保证字符串仅由字符 `+` 和 `-` 组成。

# 输入描述
第一行包含一个整数 $n$，表示字符串的长度。
第二行包含一个长度为 $n$ 的字符串，仅由字符 `+` 和 `-` 组成。

# 输出描述
输出一个整数，表示最长合法前缀的长度。

## 样例1

**输入**

```
7
++-+---
```

**输出**

```
6
```

**说明**

设累加值初始为 $0$。
- 遇到第 `1` 个字符 `+`，累加值变为 $1$；
- 第 `2` 个 `+`，累加值变为 $2$；
- 第 `3` 个 `-`，累加值变为 $1$；
- 第 `4` 个 `+`，累加值变为 $2$；
- 第 `5` 个 `-`，累加值变为 $1$；
- 第 `6` 个 `-`，累加值变为 $0$。
此时扫描过程始终不小于 $0$，且结束时累加值恰好为 $0$，因此前缀 `++-+--` 长度 $6$ 是合法的。
继续扫描第 `7` 个 `-`，累加值变为 $-1 < 0$，不再满足条件，因此后续不存在更长的合法前缀。最长合法前缀长度为 `6`。

## 样例2

**输入**

```
1
-
```

**输出**

```
0
```

**说明**

字符串仅有一个字符 `-`。扫描开始时累加值为 $0$，遇到 `-` 后累加值变为 $-1$，立即小于 $0$，因此任何非空前缀均不合法。根据定义，空前缀视为合法，长度为 `0`。故最长合法前缀长度为 `0`。

## 样例3

**输入**

```
5
++--+
```

**输出**

```
4
```

**说明**

累加值初始为 $0$。
- 扫描第 `1` 个 `+`，累加值 $1$；
- 第 `2` 个 `+`，累加值 $2$；
- 第 `3` 个 `-`，累加值 $1$；
- 第 `4` 个 `-`，累加值 $0$。
前 `4` 个字符构成的前缀扫描过程中累加值始终不小于 $0$，且结束时恰好为 $0$，是合法前缀，长度为 $4$。
再扫描第 `5` 个 `+`，累加值变为 $1$，最终不为 $0$，故整个字符串不合法。
虽然空前缀也合法（长度为 `0`），但 `4` 更大，因此最长合法前缀长度为 `4`。
