## 解题思路

题目要求寻找字符串的最长合法前缀，其中合法前缀需满足两个条件：

1. **平衡条件**：从前向后扫描前缀时，维护一个累加值 `balance`（初始为 0）。遇到 `+` 则 `balance` 加 1，遇到 `-` 则 `balance` 减 1。扫描结束后，`balance` 必须恰好为 0。
2. **非负条件**：整个扫描过程中，`balance` 必须始终大于或等于 0。

基于这两个条件，可以采用一次遍历的方法：

- 从左到右遍历字符串的每一个字符，更新 `balance`。
- 每当 `balance` 小于 0 时，说明当前前缀（及任何包含它的更长前缀）不可能再满足非负条件，可以直接终止遍历。
- 每当 `balance` 等于 0 时，说明从开头到当前位置的子串是一个合法前缀，记录其长度 `i + 1` 作为当前找到的最长合法前缀。
- 遍历结束后，最后记录的长度即为答案。
- 空字符串（长度为 0）视为合法前缀，因此初始答案可设为 0。

该算法只需遍历一次字符串，无需额外空间。

## 复杂度分析

- 时间复杂度：$O(n)$，其中 $n$ 是字符串的长度。我们只对字符串进行一次遍历。
- 空间复杂度：$O(1)$，仅使用了常数额外空间来维护累加值和答案。

## 代码实现

### Python

```python
n = int(input())
s = input()

balance = 0
ans = 0

for i in range(n):
    if s[i] == '+':
        balance += 1
    else:
        balance -= 1
    # 如果累加值小于0，后续前缀均不合法，直接退出
    if balance < 0:
        break
    # 累加值等于0时，找到一个合法前缀，记录其长度
    elif balance == 0:
        ans = i + 1

print(ans)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        String s = scanner.next();

        int balance = 0;
        int ans = 0;

        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '+') {
                balance += 1;
            } else {
                balance -= 1;
            }
            // 累加值小于0，无法继续构成合法前缀
            if (balance < 0) {
                break;
            }
            // 累加值等于0时，更新最长合法前缀长度
            else if (balance == 0) {
                ans = i + 1;
            }
        }

        System.out.println(ans);
        scanner.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    string s;
    cin >> n >> s;

    int balance = 0;
    int ans = 0;

    for (int i = 0; i < n; ++i) {
        if (s[i] == '+') {
            balance += 1;
        } else {
            balance -= 1;
        }
        // 累加值小于0，终止扫描
        if (balance < 0) {
            break;
        }
        // 累加值为0时，找到一个合法前缀
        else if (balance == 0) {
            ans = i + 1;
        }
    }

    cout << ans << endl;
    return 0;
}
```
