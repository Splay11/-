## 解题思路

题目要求判断一个 $r$ 行 $c$ 列的表格是否满足“对角一致”：对于所有 $1 \le i \le r-1$ 且 $1 \le j \le c-1$ 的位置，格子内数值 $g_{i,j}$ 必须与右下角格子 $g_{i+1,j+1}$ 相等。  
这说明表格中每一条从左上到右下的对角线上的所有元素都必须相等。

因此只需要用模拟检查即可：

1. 读入表格的全部数据，存储在一个二维数组或列表中。
2. 遍历除最后一行和最后一列外的所有格子，即 $i$ 从 $0$ 到 $r-2$，$j$ 从 $0$ 到 $c-2$。
3. 对于每个位置，比较 $g_{i,j}$ 与 $g_{i+1,j+1}$：
   - 若发现某一对不相等，则说明表格不满足对角一致，直接输出 `No`。
   - 若所有位置都满足相等条件，则输出 `Yes`。

因为所有测试数据的 $r \times c$ 总和不超过 $10^6$，该模拟算法可以在时限内完成。

## 复杂度分析

- 时间复杂度：需要遍历表格中每一个可与右下角比较的位置，共 $(r-1)\times(c-1)$ 个，因此时间复杂度为 $O(r \times c)$。
- 空间复杂度：需要存储整个表格，空间复杂度为 $O(r \times c)$。

## 代码实现

### Python

```python
def check_matrix(a, r, c):
    # 检查所有可以和右下角比较的位置
    for i in range(r - 1):
        for j in range(c - 1):
            if a[i][j] != a[i + 1][j + 1]:
                return False
    return True

def main():
    t = int(input())
    ans = []
    for _ in range(t):
        r, c = map(int, input().split())
        # 读入 r 行 c 列的表格
        a = []
        for _ in range(r):
            a.append(list(map(int, input().split())))
        if check_matrix(a, r, c):
            ans.append("Yes")
        else:
            ans.append("No")
    print("\n".join(ans))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    // 判断表格是否对角一致
    public static boolean checkMatrix(int[][] a, int r, int c) {
        for (int i = 0; i < r - 1; i++) {
            for (int j = 0; j < c - 1; j++) {
                if (a[i][j] != a[i + 1][j + 1]) {
                    return false;
                }
            }
        }
        return true;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        StringBuilder sb = new StringBuilder();
        int t = sc.nextInt();
        while (t-- > 0) {
            int r = sc.nextInt();
            int c = sc.nextInt();
            int[][] a = new int[r][c];
            for (int i = 0; i < r; i++) {
                for (int j = 0; j < c; j++) {
                    a[i][j] = sc.nextInt();
                }
            }
            if (checkMatrix(a, r, c)) {
                sb.append("Yes\n");
            } else {
                sb.append("No\n");
            }
        }
        System.out.print(sb);
        sc.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

bool checkMatrix(const vector<vector<int>>& a, int r, int c) {
    for (int i = 0; i < r - 1; i++) {
        for (int j = 0; j < c - 1; j++) {
            if (a[i][j] != a[i + 1][j + 1]) {
                return false;
            }
        }
    }
    return true;
}

int main() {
    int t;
    cin >> t;
    while (t--) {
        int r, c;
        cin >> r >> c;
        vector<vector<int>> a(r, vector<int>(c));
        for (int i = 0; i < r; i++) {
            for (int j = 0; j < c; j++) {
                cin >> a[i][j];
            }
        }
        if (checkMatrix(a, r, c)) {
            cout << "Yes\n";
        } else {
            cout << "No\n";
        }
    }
    return 0;
}
```
