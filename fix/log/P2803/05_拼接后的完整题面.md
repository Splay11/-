# 题目内容
小蓝正在分析一条自动化流水线的操作日志。日志由若干条记录顺序组成，每条记录用一个字符表示，可能是 `a`、`b`、`c` 或 `d`，分别对应四种不同类型的动作。

在分析过程中，小蓝发现一个完整的标准作业流程恰好需要依次执行动作 `a`、动作 `b` 和动作 `c`。换句话说，如果从整个日志序列中可以抽取出一个子序列恰好等于 `abc`，就代表完成了一次标准作业。子序列是指从原序列中删除任意个（可以为 $0$ 个，也可以为全部）字符，保持剩余字符的相对顺序得到的新序列。

现在给定一个操作日志字符串，请你计算出在该日志中，一共存在多少种不同的方式可以抽出子序列 `abc`。

字符串仅由字符 `a`、`b`、`c`、`d` 组成，长度 $n$ 满足 `1 ≤ n ≤ 10^5`。

# 输入描述
第一行包含一个字符串 $s$，由字符 `a`、`b`、`c`、`d` 组成，表示操作日志序列。长度 $n$ 满足 `1 ≤ n ≤ 10^5`。

# 输出描述
输出一个整数，表示可以从日志序列中提取出子序列 `abc` 的不同方式的总数。

## 样例1

**输入**

```
abc
```

**输出**

```
1
```

**说明**

字符串为 `abc`，恰好依次出现 `a`、`b`、`c`。

遍历过程：
- 第 `1` 个字符 `a`：$count\_a$ 变为 `1`；
- 第 `2` 个字符 `b`：可与之前的 `1` 个 `a` 组成 $count\_ab = 1$；
- 第 `3` 个字符 `c`：可与之前的 $1$ 个 `ab` 组成 $count\_abc = 1$。

最终子序列 `abc` 的总方式数为 `1`。

## 样例2

**输入**

```
adbc
```

**输出**

```
1
```

**说明**

字符串为 `adbc`，其中包含一个无关字符 `d`。

遍历过程：
- 字符 `a`：$count\_a$ 变为 `1`；
- 字符 `d`：不影响任何计数；
- 字符 `b`：$count\_ab$ 累加 $count\_a$，变为 $0 + 1 = 1$；
- 字符 `c`：$count\_abc$ 累加 $count\_ab$，变为 $0 + 1 = 1$。

最终可以抽出 `1` 个子序列 `abc`（即选取第 `1`、`3`、`4` 个字符）。

## 样例3

**输入**

```
aabbcc
```

**输出**

```
8
```

**说明**

字符串为 `aabbcc`，包含重复的 `a`、`b`、`c`。

遍历过程：
- 前两个 `a` 使得 $count\_a = 2$；
- 第一个 `b`：$count\_ab$ 变为 $0 + 2 = 2$；
- 第二个 `b`：$count\_ab$ 再次累加当前 $count\_a=2$，变为 $2 + 2 = 4$；
- 第一个 `c`：$count\_abc$ 变为 $0 + 4 = 4$；
- 第二个 `c`：$count\_abc$ 再次累加当前 $count\_ab=4$，变为 $4 + 4 = 8$。

因此，总共存在 `8` 种不同的方式抽出子序列 `abc`。

## 样例4

**输入**

```
ddd
```

**输出**

```
0
```

**说明**

字符串仅由 `d` 组成，不包含任何 `a`、`b`、`c`。

所有计数器 $count\_a$、$count\_ab$、$count\_abc$ 始终保持为 `0`，无法构成子序列 `abc`，因此输出 `0`。
