# 题目内容

小红正在批改同学的试卷,试卷由$n$道单项选择题构成,每道题只有$a ,b,c,d$ 四个选项.

如果在答案序列中存在恰好为"$abc$"的子序列,那么小红会认为只是随手写的答案,会产生一点愤怒值.
给你这个答案序列,你需要求出小红会产生多少愤怒值

子序列为从原字符串中删除任意个(可以为零、可以为全部)字符得到的新字符串。



# 输入描述

第一行输出一个长度为$n$的只存在$a, b, c, d$字符串序列，表示答案序列$(1≤n≤10^5)$

# 输出描述

输出一个整数,表示结果。



## 样例1 

**输入** 

```
abcc
```

**输出** 

```
2
```
