## 解题思路

1. **状态**：把坐标平移到 $[0, n-1]$，其中 $n = r-l+1$。用 `dp[i][j]` 表示当前甲在相对坐标 $i$、乙在相对坐标 $j$ 的概率（模 $10^9+7$）。初始 `dp[x-l][y-l] = 1`。
2. **一步转移**：甲在真实坐标 $p$ 时，下一步均匀落在 $[L_p, R_p] = [\max(l,p-a), \min(r,p+a)]$，共 $c_p$ 个点，每个点概率为 $c_p^{-1}$。乙同理，步长为 $b$。两人独立，因此原状态概率乘上 $c_p^{-1} c_q^{-1}$ 后，会均匀加到矩形 $[L_p,R_p] \times [L_q,R_q]$ 上。
3. **二维差分**：对每个非零状态，把上述矩形加到差分数组上，再做二维前缀和还原下一秒的 `dp`。逆元用费马小定理（模为质数）计算。
4. **答案**：重复 $t$ 秒后，累加所有 `dp[i][i]`，即两人坐标相同的概率。

## 复杂度分析

时间复杂度 $O(t \cdot n^2)$，其中 $n = r-l+1 \le 201$。空间复杂度 $O(n^2)$。

## 代码实现

### Python

```python
MOD = 10**9 + 7

def inv(a, mod):
    return pow(a, mod - 2, mod)

l, r, x, y, a, b, t = map(int, input().split())
n = r - l + 1

dp = [[0] * n for _ in range(n)]
dp[x - l][y - l] = 1

for _ in range(t):
    diff = [[0] * (n + 2) for _ in range(n + 2)]
    for i in range(n):
        for j in range(n):
            if dp[i][j] == 0:
                continue
            p = i + l
            left_p = max(l, p - a)
            right_p = min(r, p + a)
            cnt_p = right_p - left_p + 1
            inv_p = inv(cnt_p, MOD)
            q = j + l
            left_q = max(l, q - b)
            right_q = min(r, q + b)
            cnt_q = right_q - left_q + 1
            inv_q = inv(cnt_q, MOD)
            prob = dp[i][j] * inv_p % MOD * inv_q % MOD
            ni_min = left_p - l
            ni_max = right_p - l
            nj_min = left_q - l
            nj_max = right_q - l
            diff[ni_min][nj_min] = (diff[ni_min][nj_min] + prob) % MOD
            diff[ni_min][nj_max + 1] = (diff[ni_min][nj_max + 1] - prob) % MOD
            diff[ni_max + 1][nj_min] = (diff[ni_max + 1][nj_min] - prob) % MOD
            diff[ni_max + 1][nj_max + 1] = (diff[ni_max + 1][nj_max + 1] + prob) % MOD
    for i in range(n):
        for j in range(n):
            if i > 0:
                diff[i][j] = (diff[i][j] + diff[i - 1][j]) % MOD
            if j > 0:
                diff[i][j] = (diff[i][j] + diff[i][j - 1]) % MOD
            if i > 0 and j > 0:
                diff[i][j] = (diff[i][j] - diff[i - 1][j - 1]) % MOD
            dp[i][j] = diff[i][j]

result = 0
for i in range(n):
    result = (result + dp[i][i]) % MOD
print(result)
```

            a = (int)((long)a * a % mod);
            b >>= 1;
