# 题目内容
两条巡检机器人在同一条整数坐标轨道上独立移动。轨道范围为闭区间 $[l, r]$。初始时甲位于 $x$，乙位于 $y$。

每一秒两人同时各移动一次：

- 若甲当前在 $p$，则下一步均匀随机落到 $[\max(l, p-a), \min(r, p+a)]$ 中的某个整数点；
- 若乙当前在 $q$，则下一步均匀随机落到 $[\max(l, q-b), \min(r, q+b)]$ 中的某个整数点。

求恰好经过 $t$ 秒后两人位于同一坐标的概率。可以证明该概率可写成不可约分数 $\frac{p}{q}$。为避免浮点误差，请输出 $p \cdot q^{-1} \bmod (10^9+7)$，其中 $q^{-1}$ 是 $q$ 在模 $10^9+7$ 意义下的逆元。

参数满足：$-100 \le l \le r \le 100$，$l \le x, y \le r$，$1 \le a, b \le 100$，$1 \le t \le 1000$。

# 输入描述
输入一行，包含 `7` 个整数 $l, r, x, y, a, b, t$，依次表示轨道左右端点、两人初始位置、甲的最大步长、乙的最大步长以及经过的秒数。

# 输出描述
输出一个整数，表示所求概率在模 $10^9+7$ 下的值。

## 样例1

**输入**

```
1 3 1 3 1 1 1
```

**输出**

```
250000002
```

**说明**

轨道为 $[1,3]$，甲从 `1`、乙从 `3` 出发，步长均为 `1`，只走 `1` 秒。甲可到 `{1,2}`，乙可到 `{2,3}`，各 `2` 个点。同时走到 `2` 的概率为 $\frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$。输出 $1 \cdot 4^{-1} \equiv 250000002 \pmod{10^9+7}$。

## 样例2

**输入**

```
62 68 68 67 13 97 1
```

**输出**

```
142857144
```

**说明**

轨道很短而步长很大，一步即可覆盖整段。按均匀转移计算两人落在同一格的概率，模 $10^9+7$ 后为 `142857144`。

## 样例3

**输入**

```
0 0 0 0 1 1 1
```

**输出**

```
1
```

**说明**

轨道只有一个点 `0`，无论步长多少，下一步仍只能停在 `0`。经过 `1` 秒后两人必然重合，概率为 `1`。
