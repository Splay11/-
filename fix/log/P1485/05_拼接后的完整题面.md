# 题目内容
小蓝有一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。

对于该序列，可以删除其中任意个元素（包括零个），并保持剩余元素的相对顺序不变，这样得到的序列称为原序列的一个**提取序列**。

如果一个序列的长度为 $k$，并且其中恰好包含 `1` 到 $k$ 的所有整数各一次（顺序任意），则称该序列为一个**完整序列**。例如 $[1,3,2,4]$ 就是一个长度为 $4$ 的完整序列。

现在需要计算原序列的所有提取序列中，有多少个是完整序列。

由于答案可能很大，请输出结果对 `10^9+7` 取模后的值。

**约束条件：**
- 序列的长度 $n$ 不超过 `10^5`。
- 序列中的每个整数 $a_i$ 的值在 `1` 到 `10^9` 之间。

# 输入描述
第一行包含一个整数 $n$，表示序列的长度。保证 $n$ 不超过 `10^5`。
第二行包含 $n$ 个整数，依次为 $a_1, a_2, \dots, a_n$，表示序列中的元素。保证每个整数的值在 `1` 到 `10^9` 之间。

# 输出描述
输出一个整数，表示满足条件的提取序列个数对 `10^9+7` 取模的结果。

## 样例1

**输入**

```
3
2 3 4
```

**输出**

```
0
```

**说明**

序列中不包含数字 `1`。根据完整序列的定义，任何完整序列必须包含 `1` 到其长度 $k$ 的所有整数，因此第一个元素必须是 `1`。原序列中没有 `1`，不存在任何提取序列是完整序列，答案为 `0`。

## 样例2

**输入**

```
5
1 2 2 4 5
```

**输出**

```
3
```

**说明**

统计原序列中连续从 `1` 开始的数字出现次数：$cnt_1 = 1$，$cnt_2 = 2$，$cnt_3 = 0$（数字 `3` 缺失）。

对于长度 $k=1$，完整序列只能由 `1` 组成，方案数为 $cnt_1 = 1$。
对于长度 $k=2$，需要恰好包含 `1` 和 `2`，方案数为 $cnt_1 \times cnt_2 = 1 \times 2 = 2$，这两个完整序列分别为子序列 $[1,2]$（选取位置 `1` 和 `2` 或 `1` 和 `3`）以及 $[2,1]$（选取位置 `2` 和 `1`？不，`1` 只能在 `2` 之后？原序列为 `1,2,2,4,5`， `1` 在位置 `1`，两个 `2` 在位置 `2` 和 `3`。选取位置 `2` 的 `2` 和位置 `1` 的 `1` 无法形成递增索引，只能选择位置 `1` 的 `1` 和后面的某个 `2` 得到 $[1,2]$；也可以只选 `2` 不选 `1`？不，长度为 $2$ 的完整序列必须包含 `1` 和 `2` 各一次，由于 `1` 的位置在最前，所以只能形成 $[1,2]$，共有 $2$ 种不同的位置组合：$(1,2)$ 和 $(1,3)$）。实际上，只要每个值选一个出现位置，并按索引排序即可。$cnt_1 \times cnt_2 = 2$ 涵盖了所有可能。
对于 $k \ge 3$，因为 `3` 未出现，方案数为 `0`。
总答案为 $1 + 2 = 3$。

## 样例3

**输入**

```
4
1 2 3 4
```

**输出**

```
4
```

**说明**

序列中 `1` 到 `4` 各恰好出现一次：$cnt_1 = cnt_2 = cnt_3 = cnt_4 = 1$。
长度为 $k=1$ 的完整序列：`1` 出现 $1$ 次，方案数为 $1$。
$k=2$：包含 `1,2`，方案数为 $1 \times 1 = 1$（子序列 $[1,2]$）。
$k=3$：包含 `1,2,3`，方案数为 $1 \times 1 \times 1 = 1$（子序列 $[1,2,3]$）。
$k=4$：包含 `1,2,3,4`，方案数为 $1$（子序列 $[1,2,3,4]$）。
总数为 $1+1+1+1 = 4$。

## 样例4

**输入**

```
6
1 1 2 3 3 3
```

**输出**

```
10
```

**说明**

统计连续数字的出现次数：$cnt_1 = 2$，$cnt_2 = 1$，$cnt_3 = 3$，$cnt_4 = 0$。
长度为 $k=1$：方案数 $cnt_1 = 2$（两个不同的 `1`）。
$k=2$：方案数 $cnt_1 \times cnt_2 = 2 \times 1 = 2$（从两个 `1` 中选一个，与唯一的 `2` 组合，按索引排序后分别得到 $[1,2]$ 和 $[2,1]$？原序列 `1,1,2,3,3,3`：两个 `1` 的位置是 `1` 和 `2`，`2` 的位置是 `3`。若选第一个 `1` 和 `2`，索引 `1<3`，得 $[1,2]$；若选第二个 `1` 和 `2`，索引 `2<3`，得 $[1,2]$，这里似乎只能得到 $[1,2]$？等等，因为 `2` 在所有 `1` 的后面，无法形成 `2` 在前 `1` 在后的排列。所以 $cnt_1 \times cnt_2$ 实际上计数的是所有位置组合，包含 `1` 取后面、`2` 取前面？但原序列中 `2` 的位置只有 `3`，`1` 的位置有 `1` 和 `2`，都在 `2` 之前，所以只能形成 $[1,2]$。然而公式 $cnt_1 \times cnt_2 = 2$ 仍然成立，因为只要为每个值各选一个位置，总是能形成合法的子序列（位置自动有递增顺序），这个例子中两个组合分别是 $(pos_1=1, pos_2=3)$ 和 $(pos_1=2, pos_2=3)$，对应的值序列都是 $[1,2]$，是不同的提取序列。完整序列只看索引集合，值序列可以相同。所以 $2$ 是正确的。
$k=3$：方案数 $2 \times 1 \times 3 = 6$。
总答案为 $2 + 2 + 6 = 10$。
