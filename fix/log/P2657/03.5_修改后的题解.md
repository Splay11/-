## 解题思路

1. **单点贡献**：只取一块矿石 $a_i$ 时，$f = g = a_i$，乘积为 $a_i^2$。因此答案至少是数组最大值的平方。
2. **多元素不会更优**：连续多块时，$g(b)$ 不会超过段内最小值，更不会超过全局最大值；$f(b)$ 作为异或和也难以同时把两项都抬到超过最大值平方的程度。直观上，最优值就是最大能量值的平方。
3. **实现**：对每组数据扫描一遍序列，记下最大值 $M$，输出 $M^2$。注意用 $64$ 位整数防止平方溢出。
4. **零值**：若出现 $0$，由于 $\gcd(0,x)=x$，单点 $0$ 的贡献为 $0$，不会超过正的最大值平方。

## 复杂度分析

时间复杂度 $O(\sum n)$，每组线性扫描一次。空间复杂度 $O(1)$。

## 代码实现

### Python

```python
def solve():
    import sys
    input_data = sys.stdin.read().strip().split()
    T = int(input_data[0])
    index = 1
    output_lines = []
    for _ in range(T):
        n = int(input_data[index])
        index += 1
        max_val = 0
        for __ in range(n):
            x = int(input_data[index])
            index += 1
            if x > max_val:
                max_val = x
        output_lines.append(str(max_val * max_val))
    print("\n".join(output_lines))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.*;
import java.io.*;

public class Main {
    public static void main(String[] args) {
        FastReader in = new FastReader(System.in);
        int T = in.nextInt();
        StringBuilder sb = new StringBuilder();
        while (T-- > 0) {
            int n = in.nextInt();
            long maxVal = 0;
            for (int i = 0; i < n; i++) {
                long x = in.nextLong();
                if (x > maxVal) {
                    maxVal = x;
                }
            }
            sb.append(maxVal * maxVal).append("\n");
        }
        System.out.print(sb.toString());
    }

    static class FastReader {
        BufferedReader br;
        StringTokenizer st;
        public FastReader(InputStream stream) {
            br = new BufferedReader(new InputStreamReader(stream));
        }
        String next() {
            while (st == null || !st.hasMoreTokens()) {
                try {
                    String line = br.readLine();
                    if (line == null) return null;
                    st = new StringTokenizer(line);
                } catch (IOException e) {
                    throw new RuntimeException(e);
                }
            }
            return st.nextToken();
        }
        int nextInt() {
            return Integer.parseInt(next());
        }
        long nextLong() {
            return Long.parseLong(next());
        }
    }
}
```
