# 题目内容
一条矿道上依次埋着 $n$ 块矿石，第 $i$ 块的能量值为 $a_i$。对于一段连续矿段 $b$（即原序列的一个非空连续子数组），定义：

- $f(b)$ 为该段所有能量值的按位异或和；
- $g(b)$ 为该段所有能量值的最大公约数。

约定 $\gcd(0, x) = x$（对任意 $x$ 成立）。请选出一段连续矿段，使得 $f(b) \times g(b)$ 最大，并输出这个最大值。

测试组数 $T$ 满足 $1 \le T \le 1000$。每组中矿石数量 $n$ 满足 $1 \le n \le 2 \times 10^5$，能量值满足 $0 \le a_i \le 10^9$。保证单个测试文件中所有 $n$ 之和不超过 $3 \times 10^5$。

# 输入描述
第一行包含一个正整数 $T$，表示测试数据组数。
对于每组测试数据：第一行包含一个正整数 $n$，表示序列长度；第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$，表示各块矿石的能量值。

# 输出描述
对于每组测试数据，输出一行一个整数，表示最大的 $f(b) \times g(b)$。

## 样例1

**输入**

```
1
4
1 1 1 1
```

**输出**

```
1
```

**说明**

最大能量值为 `1`，单点贡献 $1^2 = 1$。取三段连续的 `1` 时异或与公约数仍为 `1`，乘积不超过 `1`。

## 样例2

**输入**

```
2
1
0
3
0 5 1
```

**输出**

```
0
25
```

**说明**

第一组只有 `0`，答案为 $0^2 = 0$。第二组最大值为 `5`，答案为 $5^2 = 25$；单点取 `5` 即可达到。

## 样例3

**输入**

```
1
1
9
```

**输出**

```
81
```

**说明**

只有一块矿石 `9`，唯一子数组的 $f$ 与 $g$ 都是 `9`，乘积为 `81`。
