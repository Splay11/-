# 题目内容
考古学家发现了一块刻有神秘文字的石板，上面是一个仅由小写字母组成的串。为了解读信息，他需要按照一种特殊的流程重新整理该串的所有“起始片段”。

具体来说，对于一个长度为 $n$ 的串 $s$，定义它的 $n$ 个起始片段依次为 $s$ 的前 $1,2,\dots,n$ 个字符构成的子串。接下来进行两步操作：首先，对每一个起始片段，将其内部的字母按照从 `'a'` 到 `'z'` 的自然顺序从小到大重新排列，得到该片段的“整理后片段”；然后，将所有 $n$ 个整理后片段按照标准比较顺序从小到大排序。标准比较顺序定义如下：从两个片段的第一个字符开始逐个比较，直到找到第一个不同的字符，字符在自然顺序中更靠前（`'a'` 最小，`'z'` 最大）的片段的顺序靠前；若一直比较到其中一个片段的末尾仍相同，则较短的片段的顺序靠前。

现在，考古学家想知道，排序完成后的整理后片段中，排在第 $k$ 小的那一个是什么。请帮助他求出结果。

约束：字符串长度 $n$ 满足 $1 \le n \le 2 \times 10^5$，$k$ 满足 $1 \le k \le n$。测试用例的数量 $T$ 不超过 $100$，且所有测试用例的 $n$ 之和不超过 $2 \times 10^5$。

# 输入描述
第一行包含一个整数 $T$，表示测试用例组数。接下来对于每组数据，格式如下：第一行包含两个整数 $n$ 和 $k$，分别表示字符串的长度和目标排名。第二行包含一个长度为 $n$ 的字符串 $s$，仅由小写字母 `'a'` 至 `'z'` 组成。

# 输出描述
对于每组数据，输出一行一个字符串，表示排序后第 $k$ 小的整理后片段。

## 样例1

**输入**

```
1
3 2
cba
```

**输出**

```
bc
```

**说明**

输入包含 `1` 组数据，$n = 3$，$k = 2$，字符串为 `cba`。长度为 `3` 的串有 `3` 个起始片段：前缀 `c`、`cb` 和 `cba`。将它们按字母升序整理后，分别得到 `c`、`bc` 和 `abc`。三个整理片段按字典序从小到大排序为 `abc`、`bc`、`c`。其中第 `2` 小的片段是 `bc`，因此输出 `bc`。

## 样例2

**输入**

```
1
1 1
z
```

**输出**

```
z
```

**说明**

输入为 `1` 组数据，$n = 1$，$k = 1$，字符串 `z`。唯一的起始片段为 `z`，排序后仍为 `z`。因此第 `1` 小即为 `z`，输出 `z`。

## 样例3

**输入**

```
2
5 3
edcba
3 2
aba
```

**输出**

```
cde
aab
```

**说明**

输入包含 `2` 组数据。第一组：$n = 5$，$k = 3$，字符串 `edcba`。五个起始片段整理后分别为 `e`、`de`、`cde`、`bcde`、`abcde`。按字典序排序为 `abcde`、`bcde`、`cde`、`de`、`e`，第 `3` 小为 `cde`。第二组：$n = 3$，$k = 2$，字符串 `aba`。三个起始片段整理后分别为 `a`、`ab`、`aab`。字典序排序为 `a`、`aab`、`ab`，第 `2` 小为 `aab`。因此输出两行分别为 `cde` 和 `aab`。
