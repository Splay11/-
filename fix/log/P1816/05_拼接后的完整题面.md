# 题目内容
仓库里有 $n$ 个货品编号。编号 `1` 是占位无效码，不计入统计；其余每个互不相同的编号都视为一种有效编号。

请统计有效编号一共有多少种。

约束条件：
- 货品个数 $n$ 满足 $1 \le n \le 2 \times 10^5$；
- 每个编号 $a_i$ 满足 $1 \le a_i \le 2 \times 10^5$。

# 输入描述
第一行包含一个整数 $n$（$1 \le n \le 2 \times 10^5$），表示货品个数。
第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 2 \times 10^5$），表示各个货品编号。

# 输出描述
输出一个整数，表示有效编号的种类数。

## 样例1

**输入**

```
3
20 2 4
```

**输出**

```
3
```

**说明**

三个编号 `20`、`2`、`4` 互不相同且都不是 `1`，有效种类数为 `3`。

## 样例2

**输入**

```
4
1 1 2 2
```

**输出**

```
1
```

**说明**

去重后得到 `{1,2}`，去掉无效码 `1`，只剩 `2` 这一种，答案为 `1`。

## 样例3

**输入**

```
1
1
```

**输出**

```
0
```

**说明**

只有无效码 `1`，有效种类数为 `0`。
