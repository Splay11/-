## 解题思路

本题要求统计所有满足条件的下标区间个数，条件为区间内每个位置上的两个序列元素均不相同（即 $x_i \neq y_i$）。

可以按以下步骤进行线性扫描求解：

1. 初始化答案变量 $res = 0$，以及一个计数器 $cnt = 0$，表示**以当前位置作为结尾的连续互异区间的最大长度**。
2. 从左到右遍历下标 $i$（从 $1$ 到 $n$）：
   - 若 $x_i \neq y_i$，则说明可以将当前元素接到之前的连续互异段后面，令 $cnt = cnt + 1$。此时所有以 $i$ 为右端点、长度不超过 $cnt$ 的区间均为互异区间，数量恰好为 $cnt$ 个，将 $cnt$ 累加到 $res$ 中。
   - 若 $x_i = y_i$，则从 $i$ 开始重新计算连续互异段，将 $cnt$ 置为 $0$。
3. 遍历完成后，$res$ 即为所有互异区间的总个数。

**正确性说明**：  
对于任意一段连续的满足 $x_i \neq y_i$ 的位置，其长度为 $len$。该段内任意子区间都是互异的。因此这一段内部贡献的互异区间数为 $len(len+1)/2$。而上述累加过程中，当 $cnt$ 逐步从 $1$ 增长到 $len$ 时，答案累加的值正好是 $1+2+\cdots+len$，与公式等价。

## 复杂度分析

- **时间复杂度**：只需对两个序列进行一次线性扫描，每次操作常数时间，因此时间复杂度为 $O(n)$。
- **空间复杂度**：需要存储两个长度为 $n$ 的序列，空间复杂度为 $O(n)$。

## 代码实现

### Python

```python
n = int(input())
x = list(map(int, input().split()))
y = list(map(int, input().split()))

res = 0
cnt = 0

for i in range(n):
    if x[i] != y[i]:
        cnt += 1
        res += cnt
    else:
        cnt = 0

print(res)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int[] x = new int[n];
        int[] y = new int[n];

        for (int i = 0; i < n; i++) {
            x[i] = scanner.nextInt();
        }
        for (int i = 0; i < n; i++) {
            y[i] = scanner.nextInt();
        }

        long res = 0;
        int cnt = 0;

        for (int i = 0; i < n; i++) {
            if (x[i] != y[i]) {
                cnt++;
                res += cnt;
            } else {
                cnt = 0;
            }
        }

        System.out.println(res);
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> x(n), y(n);

    for (int i = 0; i < n; ++i) cin >> x[i];
    for (int i = 0; i < n; ++i) cin >> y[i];

    long long res = 0;
    int cnt = 0;

    for (int i = 0; i < n; ++i) {
        if (x[i] != y[i]) {
            cnt++;
            res += cnt;
        } else {
            cnt = 0;
        }
    }

    cout << res << "\n";
    return 0;
}
```
