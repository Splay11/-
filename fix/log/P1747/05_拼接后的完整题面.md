# 题目内容
给定两个长度均为 $n$ 的整数序列 $x_1, x_2, \dots, x_n$ 和 $y_1, y_2, \dots, y_n$。
对于一个下标区间 $[L, R]$（$1 \le L \le R \le n$），如果对于任意 $i \in [L, R]$ 均满足 $x_i 
eq y_i$，则称该区间是**互异的**。

请你计算互异区间的总个数。

**数据范围**
- 序列的长度 $n$ 满足 $1 \le n \le 10^5$。
- 两个序列中的每个整数均在 $[0, 10^9]$ 范围内，即 $0 \le x_i, y_i \le 10^9$。

# 输入描述
输入共三行。
第一行包含一个整数 $n$，表示序列的长度。
第二行包含 $n$ 个整数，用空格分隔，依次表示序列 $x_1, x_2, \dots, x_n$。
第三行包含 $n$ 个整数，用空格分隔，依次表示序列 $y_1, y_2, \dots, y_n$。

# 输出描述
输出共一行，包含一个整数，表示互异区间的总个数。

## 样例1

**输入**

```
3
1 2 3
4 5 6
```

**输出**

```
6
```

**说明**

序列长度为 `3`。遍历所有位置：$x_1=1 
eq 4=y_1$, $x_2=2 
eq 5=y_2$, $x_3=3 
eq 6=y_3$，所有位置均满足互异条件，整个序列构成一个长度为 `3` 的连续互异段。互异区间个数为该段内所有子区间的个数，即 $\frac{(1+3) \times 3}{2} = 6$。这些区间为 `[1,1]`, `[1,2]`, `[1,3]`, `[2,2]`, `[2,3]`, `[3,3]`，故答案为 `6`。

## 样例2

**输入**

```
4
1 2 1 2
1 1 2 2
```

**输出**

```
3
```

**说明**

序列长度为 `4`。位置 `1`：$x_1=1 = y_1$，位置 `4`：$x_4=2 = y_4$，不满足互异条件。位置 `2` 和 `3` 满足 $x_2=2 
eq 1=y_2$ 和 $x_3=1 
eq 2=y_3$，构成一个长度为 `2` 的连续互异段。该段贡献的互异区间数为 $\frac{(1+2) \times 2}{2} = 3$，具体为 `[2,2]`, `[2,3]`, `[3,3]`。其余位置贡献为 `0`，总数为 `3`。

## 样例3

**输入**

```
1
5
5
```

**输出**

```
0
```

**说明**

序列长度为 `1`。唯一位置 $x_1=5 = y_1$，不满足互异条件。连续互异段长度为 `0`，互异区间个数为 `0`。

## 样例4

**输入**

```
5
1 2 3 4 5
1 2 0 4 5
```

**输出**

```
1
```

**说明**

序列长度为 `5`。位置 `1`,`2`,`4`,`5` 均有 $x_i = y_i$，不满足条件。只有位置 `3` 满足 $x_3=3 
eq 0=y_3$，构成一个长度为 `1` 的连续互异段。该段贡献互异区间数为 $\frac{(1+1) \times 1}{2} = 1$，即区间 `[3,3]`。其余位置贡献为 `0`，总数为 `1`。
