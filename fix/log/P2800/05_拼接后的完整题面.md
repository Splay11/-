# 题目内容
我们有 $k$ 个盒子，第 $i$ 个盒子（$1 \le i \le k$）中装有 $n_i$ 张卡片，每张卡片上写有一个正整数。定义盒子的总分为该盒子中所有卡片上的数字之和。现在，如果从盒子 $i$ 和盒子 $j$（$i 
e j$）中各抽出一张卡片后，两个盒子剩余卡片的总分相等，则称 $(i, j)$ 是一对“可匹配盒子”。请你判断：给定的 $k$ 个盒子中是否存在一对可匹配盒子？

数据范围：
- 盒子数量 $k$ 不超过 $10$。
- 每个盒子的卡片数 $n_i$ 不超过 $10^5$。
- 所有盒子的卡片总数 $\sum n_i$ 不超过 $5 \times 10^5$。
- 每张卡片上的数字均为 $1$ 到 $2 \times 10^4$ 之间的整数。
- 测试数据组数 $T$ 不超过 $10$。

# 输入描述
第一行包含一个整数 $T$ ($1 \le T \le 10$)，表示测试数据组数。
对于每组测试数据：
第一行包含一个整数 $k$ ($1 \le k \le 10$)，表示盒子数量。
接下来依次描述每个盒子。对于第 $i$ 个盒子：
第一行包含一个整数 $n_i$ ($1 \le n_i \le 10^5$)，表示该盒子的卡片数量。
第二行包含 $n_i$ 个整数，每个整数均在 $1$ 到 $2 \times 10^4$ 之间。
保证一组测试数据中所有盒子的卡片总数 $\sum n_i$ 不超过 $5 \times 10^5$。

# 输出描述
对于每组测试数据，输出一行，如果存在一对可匹配盒子，输出 `YES`，否则输出 `NO`。

## 样例1

**输入**

```
2
2
2
4 6
2
6 6
1
3
1 2 3
```

**输出**

```
YES
NO
```

**说明**

第一组数据：有 `2` 个盒子。
盒子 `1` 有 `2` 张卡片：`4` 和 `6`，总和为 $4+6=10$。若删除 `4` 则剩余和为 $10-4=6$；若删除 `6` 则剩余和为 $10-6=4$。
盒子 `2` 有 `2` 张卡片：`6` 和 `6`，总和为 $6+6=12$。删除任意一张 `6` 后剩余和均为 $12-6=6$。
剩余和 `6` 同时出现在盒子 `1` 和盒子 `2` 中，因此存在可匹配盒子，输出 `YES`。

第二组数据：只有 `1` 个盒子，无法选出两个不同的盒子，因此不存在可匹配盒子，输出 `NO`。

## 样例2

**输入**

```
1
3
2
1 9
2
2 8
2
3 7
```

**输出**

```
NO
```

**说明**

三个盒子的卡片总分为别为 $1+9=10$、$2+8=10$、$3+7=10$。
盒子 `1` 删除一张卡片后的可能剩余和为 $10-1=9$ 和 $10-9=1$。
盒子 `2` 的可能剩余和为 $10-2=8$ 和 $10-8=2$。
盒子 `3` 的可能剩余和为 $10-3=7$ 和 $10-7=3$。
所有剩余和集合为 $\{1,9\}$、$\{2,8\}$、$\{3,7\}$，任意两个盒子之间没有相同的剩余和，因此输出 `NO`。

## 样例3

**输入**

```
1
2
4
1 2 3 4
3
5 5 1
```

**输出**

```
YES
```

**说明**

盒子 `1` 有 `4` 张卡片：`1 2 3 4`，总和为 $1+2+3+4=10$。删除 `1` 剩 $9$，删除 `2` 剩 $8$，删除 `3` 剩 $7$，删除 `4` 剩 $6$。可能剩余和为 $\{6,7,8,9\}$。
盒子 `2` 有 `3` 张卡片：`5 5 1`，总和为 $5+5+1=11$。删除 `5` 剩 $6$，删除另外一张 `5` 也剩 $6$，删除 `1` 剩 $10$。可能剩余和为 $\{6,10\}$。
剩余和 `6` 在两个盒子的剩余和集合中均出现（盒子 `1` 删除 `4` 得 `6`；盒子 `2` 删除 `5` 得 `6`），因此存在可匹配盒子，输出 `YES`。
