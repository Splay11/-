# 题目内容
给定一个长度为 `n` 的整数序列 $x_1, x_2, \dots, x_n$ 和一个长度为 `m` 的允许值集合 $Y = \{y_1, y_2, \dots, y_m\}$。每次操作可以选择序列中的一个元素 $x_i$，将其加 `1` 或减 `1`。你需要经过若干次操作，使得最终序列满足以下两个条件：
1. 序列中每个元素都属于集合 $Y$；
2. 最终序列是非递减的，即 $x_1 \le x_2 \le \dots \le x_n$。
求所需的最少操作次数。

序列的长度 `n` 和集合的大小 `m` 均不超过 `2000`。所有整数均为正整数且不超过 `10^9`。

# 输入描述
第一行包含两个整数 `n` 和 `m`，分别表示序列长度和允许值集合的大小。
第二行包含 `n` 个整数，依次表示序列的初始值 $x_1, x_2, \dots, x_n$。
第三行包含 `m` 个整数，表示允许值集合中的元素。

# 输出描述
输出一个整数，表示最少操作次数。

## 样例1

**输入**

```
3 3
1 5 9
2 4 7
```

**输出**

```
4
```

**说明**

将 $b$ 排序为 $[2, 4, 7]$。最终序列可以选择 $[2, 4, 7]$，操作次数为 $|1-2| + |5-4| + |9-7| = 1 + 1 + 2 = 4$。其他可行序列如 $[2, 2, 7]$ 需要 $1+3+2=6$，$[4, 4, 7]$ 需要 $3+1+2=6$，均不如 $4$ 优。因此最少操作次数为 `4`。

## 样例2

**输入**

```
1 1
5
10
```

**输出**

```
5
```

**说明**

只有一个元素 $x_1 = 5$，允许值集合仅包含 $10$。必须将 $5$ 变为 $10$，操作次数为 $|5-10| = 5$。最终序列为 $[10]$，满足条件。所以最少操作次数为 `5`。

## 样例3

**输入**

```
3 3
10 1 10
1 5 10
```

**输出**

```
9
```

**说明**

$b$ 排序后为 $[1, 5, 10]$。要使最终序列非递减且均在 $b$ 中，可能方案：
- 选择 $[1, 1, 10]$：操作 $|10-1| + |1-1| + |10-10| = 9$
- 选择 $[5, 5, 10]$：操作 $|10-5| + |1-5| + |10-10| = 5+4+0 = 9$
- 选择 $[1, 5, 10]$：操作 $9+4+0 = 13$
最优为 `9`。

## 样例4

**输入**

```
4 2
5 3 6 4
4 7
```

**输出**

```
4
```

**说明**

$b$ 排序后为 $[4, 7]$。最终序列只能由 `4` 和 `7` 组成且非递减。
若选 $[4, 4, 4, 4]$，操作次数为 $|5-4|+|3-4|+|6-4|+|4-4| = 1+1+2+0 = 4$
若选 $[4, 4, 7, 7]$，操作次数 $1+1+1+3=6$
若选 $[7, 7, 7, 7]$，操作次数 $2+4+1+3=10$
最少为 `4`。
