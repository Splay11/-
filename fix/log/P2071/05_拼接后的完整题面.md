# 题目内容
某社交平台记录了 $n$ 个用户和 $m$ 对好友关系。现在需要挑选两对好友关系，要求这两对关系共涉及的 $4$ 名用户全部互不相同。请你计算一共有多少种选择方案。

用户数量 $n$ 与好友关系数量 $m$ 均不超过 $10^5$，用户编号 $u, v$ 满足 $1 \le u, v \le n$。保证所有好友关系两两不同，且不存在自己与自己的好友关系（即无重边、无自环）。

# 输入描述
第一行包含两个正整数 $n$ 和 $m$，分别表示用户总数和好友关系总数。
接下来的 $m$ 行，每行包含两个正整数 $u$ 和 $v$，表示用户 $u$ 与用户 $v$ 之间存在一对好友关系。

# 输出描述
输出一个整数，表示满足条件的选择方案数。

## 样例1

**输入**

```
3 3
1 2
2 3
1 3
```

**输出**

```
0
```

**说明**

总共有 $m=3$ 对好友关系，任意选择两对共有 $C_3^2 = 3$ 种组合。度数为 $d_1=2, d_2=2, d_3=2$，共享至少一个用户的组合数为 $C_2^2 + C_2^2 + C_2^2 = 3$。因此满足条件的方案数为 $3-3=0$。没有两对关系涉及 `4` 个互不相同的用户。

## 样例2

**输入**

```
5 6
1 2
1 3
1 4
1 5
2 3
2 4
```

**输出**

```
4
```

**说明**

从 $m=6$ 对好友关系中任选两对，共有 $C_6^2 = 15$ 种组合。各个用户的度数分别为：$d_1=4$（边 `1-2`, `1-3`, `1-4`, `1-5`），$d_2=3$（边 `1-2`, `2-3`, `2-4`），$d_3=2$（边 `1-3`, `2-3`），$d_4=2$（边 `1-4`, `2-4`），$d_5=1$（边 `1-5`）。共享至少一个用户的组合数为 $C_4^2 + C_3^2 + C_2^2 + C_2^2 + C_1^2 = 6 + 3 + 1 + 1 + 0 = 11$。满足条件的方案数为 $15 - 11 = 4$。

## 样例3

**输入**

```
4 2
1 2
3 4
```

**输出**

```
1
```

**说明**

只有 $m=2$ 对好友关系，唯一的组合就是这两对。它们涉及的 `4` 个用户 `1,2,3,4` 互不相同，因此恰好有 `1` 种选择方案。此时共享用户的组合数为 $0$，总组合数 $C_2^2 = 1$，结果也为 $1$。
