# 题目内容
仓库里有 $n$ 根栏杆，第 $i$ 根长度为 $a_i$。要用其中恰好 $k$ 根、且这 $k$ 根长度全部相同的栏杆围成正 $k$ 边形（栏杆不可拼接或截断）。正多边形要求边数至少为 `3`、各边等长。

对每个 $k=3,4,\ldots,n$，计算方案数（从相同长度的栏杆中选 $k$ 根的组合数之和），并对 $998244353$ 取模。

栏杆根数满足 $3 \le n \le 5\times 10^3$，每根长度为正整数且不超过 $10^9$。

# 输入描述
第一行包含一个整数 $n$，表示栏杆根数，满足 $3 \le n \le 5\times 10^3$。
第二行包含 $n$ 个正整数 $a_1,a_2,\ldots,a_n$，表示各根长度，满足 $1 \le a_i \le 10^9$。

# 输出描述
输出一行 $n-2$ 个整数。其中第 $i$ 个数表示围成正 $(i+2)$ 边形的方案数对 $998244353$ 取模后的结果。

## 样例1

**输入**

```
8
1 2 1 1 3 2 2 2
```

**输出**

```
5 1 0 0 0 0
```

**说明**

长度 `1` 出现 `3` 次，`2` 出现 `4` 次，`3` 出现 `1` 次。
正三角形：$C(3,3)+C(4,3)=`1`+`4`=`5$；正四边形：$C(4,4)=`1$；更大的 $k$ 没有足够的等长栏杆，均为 `0`。

## 样例2

**输入**

```
3
5 5 5
```

**输出**

```
1
```

**说明**

三根等长，只能围正三角形，方案数 $C(3,3)=`1$。输出一个数 `1`。

## 样例3

**输入**

```
4
1 1 1 1
```

**输出**

```
4 1
```

**说明**

正三角形 $C(4,3)=`4$，正四边形 $C(4,4)=`1$，输出 `4 1`。

## 样例4

**输入**

```
3
1 2 3
```

**输出**

```
0
```

**说明**

三种长度各出现一次，无法选出 `3` 根等长栏杆，答案为 `0`。
