## 解题思路

一次操作会把某个货箱的重量改成**另一个已存在的重量**，因此最终能得到的重量集合，只能来自当前数组中已经出现过的模 `3` 余数。只需记录余数 $0,1,2$ 是否出现过。

1. **已经齐整**：若当前总和 $s \equiv 0 \pmod{3}$，直接输出 `Yes`。
2. **出现过余数 $0$**：把所有货箱都改成那个余数为 `0` 的重量，总和一定是 `3` 的倍数，输出 `Yes`。
3. **只出现余数 $1$ 或只出现余数 $2$**：所有重量只能变成同一种余数，总和模 `3` 等于 $n \times 1$ 或 $n \times 2$。当且仅当 $n \equiv 0 \pmod{3}$ 时输出 `Yes`，否则 `No`。
4. **同时出现余数 $1$ 和 $2$**：若 $n=1$，不可能；若 $n \ge 2$，总能配出若干个 `1` 与 `2` 使 $1$ 的个数与 $2$ 的个数模 `3` 相等（例如两两配对 $1+2=3$），输出 `Yes`。

扫描一遍数组即可完成判定。

## 复杂度分析

- **时间复杂度**：$O(n)$。每组数据只遍历一次数组，整份文件总时间为 $O(\sum n)$。
- **空间复杂度**：$O(1)$。只需常数个布尔标记与总和变量。

## 代码实现

### Python

```python
import sys

def solve():
    it = iter(sys.stdin.read().strip().split())
    t = int(next(it))
    out = []
    for _ in range(t):
        n = int(next(it))
        s = 0
        has = [False, False, False]  # 余数 0/1/2 是否出现
        for _ in range(n):
            x = int(next(it))
            s += x
            has[x % 3] = True

        if s % 3 == 0:
            out.append("Yes")
            continue

        if has[0]:
            out.append("Yes")
        else:
            only1 = has[1] and not has[2]
            only2 = has[2] and not has[1]
            if only1 or only2:
                out.append("Yes" if n % 3 == 0 else "No")
            else:
                out.append("No" if n == 1 else "Yes")
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        StringTokenizer st = new StringTokenizer(br.readLine());
        int T = Integer.parseInt(st.nextToken());

        for (int tc = 0; tc < T; tc++) {
            st = new StringTokenizer(br.readLine());
            int n = Integer.parseInt(st.nextToken());
            st = new StringTokenizer(br.readLine());
            long sum = 0;
            boolean[] has = new boolean[3];
            for (int i = 0; i < n; i++) {
                long x = Long.parseLong(st.nextToken());
                sum += x;
                has[(int) (x % 3)] = true;
            }

            if (sum % 3 == 0) {
                sb.append("Yes\n");
                continue;
            }

            if (has[0]) {
                sb.append("Yes\n");
            } else {
                boolean only1 = has[1] && !has[2];
                boolean only2 = has[2] && !has[1];
                if (only1 || only2) {
                    sb.append(n % 3 == 0 ? "Yes\n" : "No\n");
                } else {
                    sb.append(n == 1 ? "No\n" : "Yes\n");
                }
            }
        }
        System.out.print(sb.toString());
    }
}
```

#include <bits/stdc++.h>

int main() {
    ios::sync_with_stdio(false);

    int T;
    if (!(cin >> T)) return 0;
    while (T--) {
        int n;
        cin >> n;
        long long sum = 0;
        bool has[3] = {false, false, false};
        for (int i = 0; i < n; ++i) {
            long long x;
            cin >> x;
            sum += x;
            has[x % 3] = true;
        }

        if (sum % 3 == 0) {
            cout << "Yes\n";
            continue;
        }

        if (has[0]) {
            cout << "Yes\n";
        } else {
            bool only1 = has[1] && !has[2];
            bool only2 = has[2] && !has[1];
            if (only1 || only2) {
                cout << (n % 3 == 0 ? "Yes\n" : "No\n");
            } else {
                cout << (n == 1 ? "No\n" : "Yes\n");
            }
        }
    }
    return 0;
}
