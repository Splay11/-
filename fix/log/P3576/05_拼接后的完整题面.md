# 题目内容
仓库里依次摆放着 $n$ 个货箱，第 $i$ 个货箱的重量为 $a_i$。当且仅当所有货箱重量之和能被 `3` 整除时，称当前排布是**齐整**的。

你可以进行任意次（也可以一次都不进行）如下操作：选择两个不同的下标 $i,j$（满足 $1 \le i,j \le n$ 且 $i 
eq j$），将 $a_i$ 修改为当前的 $a_j$。

请判断是否可以通过若干次操作，使排布变为齐整。

数据范围：测试组数 $T$ 满足 $1 \le T \le 10^4$；每组货箱个数 $n$ 满足 $1 \le n \le 2 \times 10^5$；每个重量满足 $1 \le a_i \le 10^9$。单个测试文件中所有 $n$ 之和不超过 $2 \times 10^5$。

# 输入描述
每个测试文件包含多组测试数据。第一行输入一个整数 $T$（$1 \le T \le 10^4$），表示数据组数。
每组测试数据格式如下：
- 第一行包含一个整数 $n$（$1 \le n \le 2 \times 10^5$），表示货箱个数；
- 第二行包含 $n$ 个整数 $a_1,a_2,\ldots,a_n$（$1 \le a_i \le 10^9$），表示各货箱重量。
保证单个测试文件中所有 $n$ 之和不超过 $2 \times 10^5$。

# 输出描述
对于每一组测试数据，新起一行输出：若可以通过若干次操作使排布变为齐整，输出 `Yes`；否则输出 `No`。大小写必须与上述字符完全一致。

## 样例1

**输入**

```
3
3
1 1 1
3
1 2 2
2
1 1
```

**输出**

```
Yes
Yes
No
```

**说明**

共有 `3` 组数据。
第一组重量为 $1,1,1$，总和为 `3`，已能被 `3` 整除，输出 `Yes`。
第二组可将第一个重量改为 `2`，得到 $2,2,2$，总和为 `6`，输出 `Yes`。
第三组只能得到 $1,1$，总和为 `2`，无法被 `3` 整除，输出 `No`。

## 样例2

**输入**

```
1
1
2
```

**输出**

```
No
```

**说明**

仅有 `1` 个货箱，重量为 `2`。无法选择两个不同下标进行操作，总和模 `3` 为 `2`，不能齐整，输出 `No`。

## 样例3

**输入**

```
2
4
1 1 1 1
1
3
```

**输出**

```
No
Yes
```

**说明**

第一组只有余数 `1`，且 $n=4$ 不能被 `3` 整除，无论怎样复制已有重量，总和模 `3` 都不是 `0`，输出 `No`。
第二组仅有一个重量 `3`，总和已是 `3` 的倍数，输出 `Yes`。

## 样例4

**输入**

```
1
3
4 5 7
```

**输出**

```
Yes
```

**说明**

重量模 `3` 后分别为 $1,2,1$，同时出现余数 `1` 与 `2`，且 $n \ge 2$，可以把若干货箱改成已有的另一种余数，使总和被 `3` 整除，输出 `Yes`。
