# 题目内容
市立档案馆新到一批案卷，编号恰好是 `1` 到 $n$，每种编号各一份。馆员需要把它们排成一列上架，供读者按目录查阅。抽查规程规定：在保持相对顺序的前提下，能挑出的最长严格递增编号子序列长度必须恰好为 $k$，以便按年代分层检索。同时，印刷封面目录时又要求整列编号的字典序尽可能小。请构造同时满足上述要求的排列。

长度为 $n$ 的排列是指由 `1` 到 $n$ 这 $n$ 个整数各出现一次组成的序列。最长严格递增子序列指从序列中按原相对顺序取出若干元素（可以不相邻），使其严格递增，并取其中长度最大者。字典序比较时，从左到右找到第一个不同的位置，该位置更小的序列字典序更小。

约束：$1 \le k \le n \le 200000$。

# 输入描述
输入一行两个整数 $n$ 和 $k$，分别表示案卷份数与要求的最长严格递增子序列长度。
保证 $1 \le k \le n \le 200000$。

# 输出描述
输出一行 $n$ 个整数，用空格隔开，表示满足条件且字典序最小的排列。

## 样例1

**输入**

```
6 2
```

**输出**

```
1 6 5 4 3 2
```

**说明**

需要长度为 `2` 的最长严格递增子序列。

- 先固定递增前缀 `1`，把 `3` 到 `6` 逆序插在 `1` 与 `2` 之间，得到 $1,6,5,4,3,2$。
- 其最长严格递增子序列长度为 `2`（例如 $1,6$），且把较大货号尽量靠后，字典序最小。

## 样例2

**输入**

```
4 4
```

**输出**

```
1 2 3 4
```

**说明**

当 $k=n$ 时，唯一能让最长严格递增子序列长度为 `4` 的排列就是升序 $1,2,3,4$，它同时也是字典序最小的。

## 样例3

**输入**

```
7 1
```

**输出**

```
7 6 5 4 3 2 1
```

**说明**

当 $k=1$ 时，序列必须严格递减，否则会出现长度至少为 `2` 的递增子序列。因此答案为 $7,6,5,4,3,2,1$。
