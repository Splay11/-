# 题目内容
一位炼金术士手头有 $n$ 种原料。第 $i$ 种原料由 $p_i$ 份精华与 $q_i$ 份杂质组成。为了保证炼金产物的纯度，所选原料混合后，精华的总份数不能低于杂质的总份数。术士希望最大化能得到的精华总份数，请你帮他计算这个最大值。

原料的种类数 $n$ 满足 $1 \le n \le 10^5$，对于每种原料，$p_i$ 和 $q_i$ 均为整数，满足 $0 \le p_i, q_i \le 100$，且总有 $p_i + q_i = 100$。

# 输入描述
第一行包含一个整数 $n$，表示原料的种类数。
第二行包含 $n$ 个整数 $p_1, p_2, \dots, p_n$，依次表示每种原料的精华份数。
第三行包含 $n$ 个整数 $q_1, q_2, \dots, q_n$，依次表示每种原料的杂质份数。

# 输出描述
输出一个整数，表示在满足纯度要求的前提下，最多可以获得的精华总份数。

## 样例1

**输入**

```
4
60 50 40 20
40 50 60 80
```

**输出**

```
150
```

**说明**

将原料按照精华数量从大到小排序，顺序为：`60`/`40`、`50`/`50`、`40`/`60`、`20`/`80`。

依次尝试加入：
- 加入 `60` 精华与 `40` 杂质，总精华 $60$，总杂质 $40$，满足 $60 \ge 40$，选择该原料；
- 加入 `50` 精华与 `50` 杂质，总精华 $110$，总杂质 $90$，满足 $110 \ge 90$，选择；
- 加入 `40` 精华与 `60` 杂质，总精华 $150$，总杂质 $150$，满足 $150 \ge 150$，选择；
- 加入 `20` 精华与 `80` 杂质，总精华 $170$，总杂质 $230$，此时 $170 < 230$，不满足纯度要求，停止选择。

最终获得的精华总数为 `150`。

## 样例2

**输入**

```
1
60
40
```

**输出**

```
60
```

**说明**

仅有 `1` 种原料，精华 `60`，杂质 `40`。将其加入后总精华 $60$，总杂质 $40$，满足 $60 \ge 40$，因此选择该原料，获得精华 `60`。

## 样例3

**输入**

```
1
30
70
```

**输出**

```
0
```

**说明**

仅有 `1` 种原料，精华 `30`，杂质 `70`。若加入该原料，总精华 $30$，总杂质 $70$，此时 $30 < 70$，不满足纯度要求，因此不选择任何原料，精华总数为 `0`。

## 样例4

**输入**

```
3
90 80 70
10 20 30
```

**输出**

```
240
```

**说明**

所有原料的精华均大于等于杂质。按精华从大到小排序后顺序为：`90`/`10`、`80`/`20`、`70`/`30`。

- 加入 `90` 精华与 `10` 杂质：总精华 $90$，总杂质 $10$，$90 \ge 10$，选择；
- 加入 `80` 精华与 `20` 杂质：总精华 $170$，总杂质 $30$，$170 \ge 30$，选择；
- 加入 `70` 精华与 `30` 杂质：总精华 $240$，总杂质 $60$，$240 \ge 60$，选择。

所有原料均被选中，最终精华总数为 `240`。
