## 解题思路

记第 $i$ 种原料的精华份数为 $p_i$，杂质份数为 $q_i$。题目要求在所选原料的精华总份数不低于杂质总份数的前提下，最大化精华总份数。

关键观察：由于 $p_i + q_i = 100$ 且两者均为非负整数，因此 $p_i$ 越大，对应的杂质 $q_i = 100 - p_i$ 就越小，该原料的“精华‑杂质差值” $p_i - q_i = 2p_i - 100$ 也越大。显然，我们应该优先选择 $p_i$ 较大的原料，因为这样可以在增加精华的同时，尽可能少地增加杂质，更容易满足纯度约束。

基于上述分析，可以采用贪心策略：

1. **排序**：将所有原料按精华份数 $p_i$ **降序**排列。
2. **贪心选取**：依次遍历排序后的原料，维护已选原料的精华总和 $S_p$ 和杂质总和 $S_q$（初始均为 $0$）。对于当前原料 $(p_i, q_i)$：
   - 若加入该原料后仍满足条件 $S_p + p_i \ge S_q + q_i$，则将其选入，并更新 $S_p \leftarrow S_p + p_i$，$S_q \leftarrow S_q + q_i$；
   - 否则，直接停止选择。因为后续原料的 $p_i$ 更小（杂质更多，差值更小），当前原料已经无法满足条件，后面的更不可能满足。
3. **输出答案**：最终的 $S_p$ 即为可以获得的最大精华总份数。

该贪心策略的正确性由排序后原料的“优劣”单调性保证：若一个原料不可选，则所有精华份数小于等于它的原料同样不可选。

## 复杂度分析

- **时间复杂度**：排序需要 $O(n \log n)$，贪心遍历需要 $O(n)$，总时间复杂度为 $O(n \log n)$，其中 $n \le 10^5$，完全可行。
- **空间复杂度**：存储原料信息需要 $O(n)$ 的额外空间，其余变量为常数级，因此空间复杂度为 $O(n)$。

## 代码实现

### Python

```python
n = int(input())
p = list(map(int, input().split()))
q = list(map(int, input().split()))

# 将每种原料的精华和杂质配对，并按精华份数降序排序
items = list(zip(p, q))
items.sort(key=lambda x: -x[0])  # 按精华降序

sum_p = 0  # 已选原料的精华总和
sum_q = 0  # 已选原料的杂质总和

for pi, qi in items:
    if sum_p + pi >= sum_q + qi:
        sum_p += pi
        sum_q += qi
    else:
        break

print(sum_p)
```

### Java

```java
import java.util.Arrays;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] p = new int[n];
        int[] q = new int[n];

        for (int i = 0; i < n; i++) {
            p[i] = sc.nextInt();
        }
        for (int i = 0; i < n; i++) {
            q[i] = sc.nextInt();
        }

        // 将原料信息存入二维数组，每行 {精华, 杂质}
        int[][] items = new int[n][2];
        for (int i = 0; i < n; i++) {
            items[i][0] = p[i];
            items[i][1] = q[i];
        }

        // 按精华份数降序排序
        Arrays.sort(items, (a, b) -> Integer.compare(b[0], a[0]));

        int sumP = 0, sumQ = 0;
        for (int i = 0; i < n; i++) {
            int pi = items[i][0];
            int qi = items[i][1];
            if (sumP + pi >= sumQ + qi) {
                sumP += pi;
                sumQ += qi;
            } else {
                break;
            }
        }

        System.out.println(sumP);
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> p(n), q(n);
    for (int i = 0; i < n; ++i) cin >> p[i];
    for (int i = 0; i < n; ++i) cin >> q[i];

    // 将每种原料的精华和杂质组合，并按精华份数降序排序
    vector<pair<int, int>> items(n);
    for (int i = 0; i < n; ++i) {
        items[i] = {p[i], q[i]};
    }
    sort(items.begin(), items.end(),
         [](const pair<int, int>& a, const pair<int, int>& b) {
             return a.first > b.first;  // 精华降序
         });

    int sum_p = 0, sum_q = 0;
    for (const auto& item : items) {
        int pi = item.first, qi = item.second;
        if (sum_p + pi >= sum_q + qi) {
            sum_p += pi;
            sum_q += qi;
        } else {
            break;
        }
    }

    cout << sum_p << endl;
    return 0;
}
```
