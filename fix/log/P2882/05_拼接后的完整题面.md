# 题目内容
给定一个仅由数字 $0$ 到 $9$ 构成的流水号字符串 $t$。系统会考察 $t$ 的所有非空子序列并累计积分。

一个子序列有效，当且仅当同时满足：
- 它所表示的整数不含前导零（例如 $01$、$007$ 非法），但单独一个 $0$ 合法；
- 子序列中各位数字之和能被 $5$ 整除。

每个有效子序列按下列规则计分：
- 若首位属于 $\{2,3,5,7\}$ 且末位为偶数，得 $4$ 分；
- 若首位属于 $\{2,3,5,7\}$（但末位不是偶数），得 $3$ 分；
- 其余有效子序列得 $1$ 分。

子序列须保持原串中字符的相对顺序。请输出所有非空有效子序列的积分之和对 $10^9+7$ 取模的结果。

流水号长度不超过 $10^5$。

# 输入描述
输入一行，一个仅由数字 $0$ 到 $9$ 组成的字符串 $t$，其长度满足 $1 \le |t| \le 10^5$。

# 输出描述
输出一个整数，表示所有非空有效子序列的累计积分对 $10^9+7$ 取模后的值。

## 样例1

**输入**

```
248
```

**输出**

```
4
```

**说明**

非空子序列中，数字和能被 $5$ 整除且无前导零的只有 $28$（$2+8=10$）。
首位 $2$ 属于 $\{2,3,5,7\}$，末位 $8$ 为偶数，计 $4$ 分。其余子序列数字和均不能被 $5$ 整除。

## 样例2

**输入**

```
205
```

**输出**

```
4
```

**说明**

单独的 $0$ 合法且和为 $0$，计 $1$ 分。
单独的 $5$ 和为 $5$，首位属于 $\{2,3,5,7\}$ 且末位为奇数，计 $3$ 分。
含前导零的扩展非法。累计 $1+3=4$。

## 样例3

**输入**

```
0
```

**输出**

```
1
```

**说明**

只有一个字符 $0$，单独的 $0$ 合法且和能被 $5$ 整除，计 $1$ 分。

## 样例4

**输入**

```
5
```

**输出**

```
3
```

**说明**

单独的 $5$ 和为 $5$，首位属于 $\{2,3,5,7\}$，末位为奇数，计 $3$ 分。
