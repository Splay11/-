# 题目内容
有两条长度均为 $n$ 的记录 $x$ 与 $y$。需要分别从 $x$ 和 $y$ 中各取出 $m$ 个数（$1 \le m \le n$），将取出的数分别排成非降序序列 $p$ 与 $q$，使得

$$(p_1+\cdots+p_m)\times(q_1+\cdots+q_m)=m\times(p_1 q_1+\cdots+p_m q_m).$$

请找出满足条件的最大 $m$。

测试组数不超过 `100`。单组记录长度不超过 `10^5`，所有测试中长度之和不超过 `10^5`。记录中的元素均为不超过 $2\times 10^9$ 的正整数。

# 输入描述
第一行包含一个整数 $T$（$1 \le T \le 100$），表示测试组数。
每组测试数据格式如下：
第一行包含一个整数 $n$（$1 \le n \le 10^5$），表示每条记录的长度，并保证所有测试的 $n$ 之和不超过 `10^5`。
第二行包含 $n$ 个整数 $x_1, x_2, \ldots, x_n$（$1 \le x_i \le 2\times 10^9$），表示第一条记录。
第三行包含 $n$ 个整数 $y_1, y_2, \ldots, y_n$（$1 \le y_i \le 2\times 10^9$），表示第二条记录。

# 输出描述
对于每一组测试数据，输出一行一个整数，表示满足条件的最大 $m$。

## 样例1

**输入**

```
2
3
1 2 3
2 2 3
1
6
8
```

**输出**

```
2
1
```

**说明**

第一组中，$x$ 各出现 `1` 次，$y$ 中 `2` 出现 `2` 次，最大频次为 `2`。例如取 $p=(1,3)$、$q=(2,2)$，因 $q$ 全相等，等式成立。
第二组长度均为 `1`，只能取 $m=`1`$。

## 样例2

**输入**

```
1
5
1 1 1 2 2
3 4 5 6 7
```

**输出**

```
3
```

**说明**

$x$ 中 `1` 出现 `3` 次，$y$ 中各数均只出现 `1` 次。最大频次为 `3`，取 $p$ 为三个 `1` 即可使等式成立。

## 样例3

**输入**

```
1
4
1 2 3 4
5 5 5 5
```

**输出**

```
4
```

**说明**

$y$ 四个元素全是 `5`，最大频次为 `4`，因此可以取 $m=n=`4`$。
