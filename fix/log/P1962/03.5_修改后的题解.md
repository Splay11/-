## 解题思路

将等式展开并移项，可以得到

$$
\sum_{1\le i<j\le m}(p_i-p_j)(q_i-q_j)=0.
$$

$p$、$q$ 都已排成非降序，因此每个差的符号确定。要使上式成立，必须有一侧序列为常数，即取出的 $m$ 个数全部相同。

反过来，若从 $x$ 中取出的数全相同，或从 $y$ 中取出的数全相同，代入原式后等式必然成立。

因此最大的 $m$ 就是 $x$ 中某个值的最大出现次数，与 $y$ 中某个值的最大出现次数，二者取更大者。用哈希表（或平衡树）统计频次即可。

## 复杂度分析

时间复杂度 $O(n\log n)$（若用哈希表则为期望 $O(n)$），空间复杂度 $O(n)$。对全部测试求和后仍受 $\sum n\le 10^5$ 约束。

## 代码实现

### Python

```python
from collections import Counter

T = int(input())
for _ in range(T):
    n = int(input())
    x = list(map(int, input().split()))
    y = list(map(int, input().split()))
    cx = Counter(x)
    cy = Counter(y)
    ans = max(max(cx.values()), max(cy.values()))
    print(ans)
```

### Java

```java
import java.util.HashMap;
import java.util.Map;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int T = in.nextInt();
        while (T-- > 0) {
            int n = in.nextInt();
            int ans = 1;
            Map<Integer, Integer> cx = new HashMap<>();
            for (int i = 0; i < n; i++) {
                int v = in.nextInt();
                int c = cx.getOrDefault(v, 0) + 1;
                cx.put(v, c);
                ans = Math.max(ans, c);
            }
            Map<Integer, Integer> cy = new HashMap<>();
            for (int i = 0; i < n; i++) {
                int v = in.nextInt();
                int c = cy.getOrDefault(v, 0) + 1;
                cy.put(v, c);
                ans = Math.max(ans, c);
            }
            System.out.println(ans);
        }
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        vector<int> x(n), y(n);
        map<int, int> cx, cy;
        for (int i = 0; i < n; ++i) {
            cin >> x[i];
            ++cx[x[i]];
        }
        for (int i = 0; i < n; ++i) {
            cin >> y[i];
            ++cy[y[i]];
        }
        int ans = 0;
        for (int i = 0; i < n; ++i) {
            ans = max({ans, cx[x[i]], cy[y[i]]});
        }
        cout << ans << '\n';
    }
    return 0;
}
```
