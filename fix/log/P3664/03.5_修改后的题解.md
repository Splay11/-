## 解题思路

$n$ 的上界为 `15`，$15!\approx 1.3\times 10^{12}$，可以放进 `64` 位整数。因此先直接算出 $n!$，再统计其十进制表示中数字 `0` 的个数。

统计方式有两种：把结果转成字符串后统计字符 `0`；或反复对 `10` 取模、整除，逐位检查是否为 `0`。本题范围内两种方法都正确。

## 复杂度分析

阶乘循环最多 `15` 次，逐位检查的位数也是常数级。

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(1)$。

## 代码实现

### Python

```python
import math

def count_zeros_in_factorial():
    try:
        n = int(input())
    except (ValueError, EOFError):
        return
    factorial_result = math.factorial(n)
    zero_count = str(factorial_result).count('0')
    print(zero_count)

if __name__ == "__main__":
    count_zeros_in_factorial()
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        long factorial = 1;
        for (int i = 1; i <= n; i++) {
            factorial *= i;
        }
        int zeroCount = 0;
        if (factorial == 0) {
            zeroCount = 1;
        } else {
            long temp = factorial;
            while (temp > 0) {
                if (temp % 10 == 0) {
                    zeroCount++;
                }
                temp /= 10;
            }
        }
        System.out.println(zeroCount);
        scanner.close();
    }
}
```
