# 题目内容
给出一个正整数 $n$，先计算 $n$ 的阶乘，再把它写成十进制。请统计这个十进制表示里数字 `0` 出现了多少次。

约束：$n$ 不超过 `15`。

# 输入描述
一行一个正整数 $n$。
保证 $1 \le n \le 15$。

# 输出描述
输出一个整数，表示 $n$ 的阶乘的十进制表示中数字 `0` 的出现次数。

## 样例1

**输入**

```
1
```

**输出**

```
0
```

**说明**

$1!=1$，不包含数字 `0`，答案为 `0`。这是最小规模边界。

## 样例2

**输入**

```
10
```

**输出**

```
2
```

**说明**

$10!=3628800$，其中数字 `0` 出现了 `2` 次。

## 样例3

**输入**

```
2
```

**输出**

```
0
```

**说明**

按题意模拟计算得到。
