# 题目内容

小红拿到一个长度为$n$的字符串数组，每个字符串由若干个小写字母组成。

定义一个字符串数组的权值为最长连续相同字符串的区间长度。

小红想知道，若恰好删除一段连续非空区间，剩下的字符串数组的权值最大是多少。



# 输入描述

第一行一个整数$n(2 ≤n≤10^5)$，表示字符串数组的长度。

接下来$n$ 行，每行一个字符串，保证仅由小写字母组成。

保证所有字符串的长度之和不超过$10^6$。

# 输出描述

一个整数，表示删除一段连续非空区间后，剩下的字符串数组的权值最大是多少。



## 样例1 

**输入** 

```
3
aab
qwq
aab
```

**输出** 

```
2
```
