# 题目内容
一个安全系统记录了长度为 $n$ 的登录口令序列，每个口令均由若干个小写字母组成。
定义该序列的“稳固度”为：最长的连续相同口令的片段长度（即连续相同口令的最大重复次数）。
现在，系统需要剔除一次连续的攻击尝试，即删除序列中一段连续且非空的子序列。
请计算出：删除一段连续非空区间后，剩余序列的稳固度最大可以达到多少。

约束：
- 口令序列的长度 $n$ 满足 $2 \le n \le 10^5$。
- 所有口令的字符总数不超过 $10^6$。
- 每个口令仅由小写字母组成。

# 输入描述
第一行包含一个整数 $n$，表示口令的数量。
接下来 $n$ 行，每行一个由小写字母组成的字符串，代表一个口令。

# 输出描述
输出一个整数，表示删除一段连续非空片段后，剩余口令序列所能达到的最大稳固度。

## 样例1

**输入**

```
5
a
a
b
a
a
```

**输出**

```
4
```

**说明**

原始序列为 `a, a, b, a, a`，最长的连续相同口令片段是前两个 `a` 和后两个 `a`，长度均为 `2`。
我们可以删除中间那个 `b`（删除区间为第 `3` 个口令，长度为 `1` 的连续非空子序列），剩余序列变为 `a, a, a, a`，全部为相同的口令 `a`，此时连续相同口令的最大重复次数为 `4`。
由于必须删除一段连续非空区间，这是能达到的最大稳固度，因此输出 `4`。

## 样例2

**输入**

```
7
abc
def
abc
abc
ghi
abc
abc
```

**输出**

```
4
```

**说明**

原始口令序列：`abc, def, abc, abc, ghi, abc, abc`。其中 `abc` 出现了多次，但被 `def` 和 `ghi` 隔断，最长连续相同片段为 `abc, abc`（第 `3`、`4` 个）或 `abc, abc`（第 `6`、`7` 个），稳固度为 `2`。
如果删除位于第 `5` 个位置的 `ghi`（一个连续非空区间），剩余序列变为 `abc, def, abc, abc, abc, abc`。重新排列后为：第 `1` 个 `abc`，第 `2` 个 `def`，接着是连续的四个 `abc`（原第 `3`、`4`、`6`、`7` 个）。此时最长连续相同片段为这四个 `abc`，稳固度达到 `4`。
其他删除方式（例如删除 `def` 或删除一段长区间）都无法得到比 `4` 更大的稳固度，因此答案为 `4`。

## 样例3

**输入**

```
2
hello
world
```

**输出**

```
1
```

**说明**

当 $n=2$ 时，只有两个不同的口令。无论删除哪一个（删除一段连续非空子序列，此处只能删除其中一个），剩余序列均只包含 `1` 个口令，最长连续相同片段长度即为 `1`。因此最大稳固度为 `1`。

## 样例4

**输入**

```
4
yes
yes
yes
yes
```

**输出**

```
3
```

**说明**

全部 `4` 个口令均为 `yes`，原始稳固度为 `4`。题目要求必须删除一段连续非空子序列，因此删除后至多剩下 `3` 个口令。
例如删除第 `1` 个口令，剩余 `yes, yes, yes`，最长连续相同片段长度为 `3`；删除中间的任何一个或一段，剩余部分也由连续的 `yes` 组成，稳固度同样为 `3`。因此输出 `3`。
