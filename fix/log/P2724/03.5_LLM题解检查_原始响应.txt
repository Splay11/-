## 解题思路

本题的目标是：给定一个长度为 $n$ 的口令序列，在恰好删除一段连续非空区间后，使得剩余序列中连续相同口令的最长长度（稳固度）最大。  
问题可以转化为：对于每种口令，统计其在原序列中连续出现的各个片段长度，然后考虑删除某段区间后，能否将同一口令的两个较长片段合并在一起。

1. **特殊情况——所有口令均相同**  
   - 如果序列中每一个口令都与第一个口令相同，那么无论删除哪一段连续非空区间，剩下的部分都会被截断成两段（或一段，如果删除的是边缘片段），最大稳固度一定为 $n-1$。
   - 此时直接输出 $n-1$ 并结束。

2. **一般情况——分段统计每个口令的连续段**  
   - 遍历整个口令序列，将连续相同的口令压缩成一个“连续段”，并记录该段的口令字符串和长度。
   - 使用哈希表（字典）维护每个口令对应的所有连续段长度的列表。例如，序列 `a, a, b, a, a` 中，口令 `a` 拥有两个段，长度分别为 2 和 2；口令 `b` 拥有一个段，长度为 1。

3. **合并两个相同口令的段**  
   - 对于任意一种口令，如果它存在至少两个不重叠的连续段，则可以通过删除这两个段之间的所有口令（以及可能包含这些段的一部分？实际上最优删除是只删除它们之间的部分，使这两个段首尾相连），从而将这两个段的长度合并。
   - 由于删除的区间必须是**连续非空**的，一次删除最多只能将两个位于删除区间两侧的段连接起来。因此，对于每种口令，最优的合并方案是从它的所有段中选出**长度最大的两个**，将它们相加。
   - 如果某种口令只有一个段，则无法与其他段合并，只能保留该段本身。
   - 对所有口令执行上述操作，取所有可能结果（包括不合并的单段长度和合并后的两段之和）的最大值，即为所求的最大稳固度。

4. **不需要真正删除区间**  
   - 上述分析证明，我们只需关注每种口令的段长列表，而不需要枚举具体的删除区间。最终答案即为：所有口令的段长列表中，最大单段长度与“最大两个段长度之和”的最大值。

## 复杂度分析

- 遍历一次序列进行分段统计，时间复杂度 $O(n)$。
- 对每种口令的段长列表进行排序（从大到小），以便快速取出最大的两个长度。设第 $i$ 种口令拥有 $k_i$ 个连续段，则所有 $k_i$ 之和等于 $n$。排序总开销为 $O(\sum k_i \log k_i) \le O(n \log n)$。
- 因此整体时间复杂度为 $O(n \log n)$，在 $n \le 10^5$ 的范围内可以高效运行。
- 空间复杂主要用在存储口令序列和哈希表，每个口令的段长列表总和为 $n$，故空间复杂度 $O(n)$。

## 代码实现

### Python

```python
from collections import defaultdict

def solve():
    import sys
    input = sys.stdin.read
    data = input().split()
    if not data:
        return
    n = int(data[0])
    passwords = data[1:1+n]

    # 特判：所有口令完全相同
    first = passwords[0]
    all_same = True
    for pwd in passwords:
        if pwd != first:
            all_same = False
            break
    if all_same:
        print(n - 1)
        return

    # 统计每个口令的连续段长度
    seg = defaultdict(list)
    cur_pwd = passwords[0]
    cur_len = 1
    for i in range(1, n):
        if passwords[i] == cur_pwd:
            cur_len += 1
        else:
            seg[cur_pwd].append(cur_len)
            cur_pwd = passwords[i]
            cur_len = 1
    seg[cur_pwd].append(cur_len)  # 处理最后一段

    max_ans = 0
    for lengths in seg.values():
        lengths.sort(reverse=True)
        if len(lengths) == 1:
            max_ans = max(max_ans, lengths[0])
        else:
            max_ans = max(max_ans, lengths[0] + lengths[1])
    print(max_ans)

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        String[] passwords = new String[n];
        for (int i = 0; i < n; i++) {
            passwords[i] = sc.next();
        }

        // 特判：所有口令完全相同
        String first = passwords[0];
        boolean allSame = true;
        for (int i = 1; i < n; i++) {
            if (!passwords[i].equals(first)) {
                allSame = false;
                break;
            }
        }
        if (allSame) {
            System.out.println(n - 1);
            return;
        }

        // 统计每个口令的连续段长度
        Map<String, List<Integer>> seg = new HashMap<>();
        String cur = passwords[0];
        int len = 1;
        for (int i = 1; i < n; i++) {
            if (passwords[i].equals(cur)) {
                len++;
            } else {
                seg.putIfAbsent(cur, new ArrayList<>());
                seg.get(cur).add(len);
                cur = passwords[i];
                len = 1;
            }
        }
        seg.putIfAbsent(cur, new ArrayList<>());
        seg.get(cur).add(len);

        int maxAns = 0;
        for (List<Integer> lengths : seg.values()) {
            lengths.sort(Comparator.reverseOrder());
            if (lengths.size() == 1) {
                maxAns = Math.max(maxAns, lengths.get(0));
            } else {
                maxAns = Math.max(maxAns, lengths.get(0) + lengths.get(1));
            }
        }
        System.out.println(maxAns);
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <unordered_map>
#include <algorithm>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<string> passwords(n);
    for (int i = 0; i < n; ++i) {
        cin >> passwords[i];
    }

    // 特判：所有口令完全相同
    string first = passwords[0];
    bool allSame = true;
    for (int i = 1; i < n; ++i) {
        if (passwords[i] != first) {
            allSame = false;
            break;
        }
    }
    if (allSame) {
        cout << n - 1 << '\n';
        return 0;
    }

    // 统计每个口令的连续段长度
    unordered_map<string, vector<int>> seg;
    string cur = passwords[0];
    int len = 1;
    for (int i = 1; i < n; ++i) {
        if (passwords[i] == cur) {
            ++len;
        } else {
            seg[cur].push_back(len);
            cur = passwords[i];
            len = 1;
        }
    }
    seg[cur].push_back(len);  // 最后一段

    int maxAns = 0;
    for (auto &entry : seg) {
        auto &lengths = entry.second;
        sort(lengths.rbegin(), lengths.rend());  // 降序
        if (lengths.size() == 1) {
            maxAns = max(maxAns, lengths[0]);
        } else {
            maxAns = max(maxAns, lengths[0] + lengths[1]);
        }
    }
    cout << maxAns << '\n';
    return 0;
}
```
