# 题目内容
有一个任务调度系统，里面有 $N$ 个待处理的任务。每个任务 $i$ 有两个属性：一个初始优先级数值 $p_i$，以及一个类别标签 $t_i \in \{0,1,2\}$。系统需要为这 $N$ 个任务分配 $1$ 到 $N$ 的一个排列 $s_1,\dots,s_N$ 作为最终的处理顺序，其中 $s_i$ 表示任务 $i$ 的处理编号。

编号分配必须满足类别约束：如果两个任务 $i$ 和 $j$ 的类别满足 $t_i > t_j$，则要求 $s_i > s_j$。换句话说，类别较小的任务最终的处理编号也必须较小，同类别内部没有严格顺序要求。

我们希望在满足约束的前提下，使得分配的处理编号与初始优先级之差的绝对值之和尽可能小，即最小化
$\displaystyle \sum_{i=1}^{N} |p_i - s_i|$
的值。请你计算这个最小值。

约束条件：
- 任务数量 $N$ 满足 $1 \le N \le 2 \times 10^5$。
- 每个初始优先级 $p_i$ 为整数且满足 $1 \le p_i \le 10^9$。
- 类别 $t_i$ 为 $0$、$1$ 或 $2$。

# 输入描述
第一行包含一个整数 $N$，表示任务的数量。
第二行包含 $N$ 个整数，表示每个任务的初始优先级 $p_1, p_2, \dots, p_N$。
第三行包含 $N$ 个整数，表示每个任务的类别 $t_1, t_2, \dots, t_N$，取值范围为 $[0,2]$。

# 输出描述
输出一个整数，表示能达到的最小绝对值差之和。

## 样例1

**输入**

```
3
10 20 30
0 1 2
```

**输出**

```
54
```

**说明**

任务共有 `3` 个，类别分别为 `0`、`1`、`2`。根据类别约束，类别 `0` 的编号必须最小，类别 `2` 的编号必须最大。因此三个任务的最终处理编号只能依次为 `1`、`2`、`3`。
最小绝对值差之和为 $|10-1|+|20-2|+|30-3|=9+18+27=54$。

## 样例2

**输入**

```
5
5 2 8 4 1
0 0 1 1 2
```

**输出**

```
13
```

**说明**

`5` 个任务按类别分组：
- 类别 `0` 的初始优先级为 $[5,2]$，内部排序后得到 $[2,5]$，分配编号 `1`、`2`；
- 类别 `1` 的初始优先级为 $[8,4]$，内部排序后得到 $[4,8]$，分配编号 `3`、`4`；
- 类别 `2` 的初始优先级为 $[1]$，分配编号 `5`。
这样分配满足类别约束，且同类别内部通过排序匹配最小化差值。总和为 $|2-1|+|5-2|+|4-3|+|8-4|+|1-5|=1+3+1+4+4=13$。

## 样例3

**输入**

```
4
100 1 50 20
0 0 0 0
```

**输出**

```
161
```

**说明**

所有任务类别相同（均为 `0`），因此编号顺序只需在同类别内最优匹配。将初始优先级排序为 $[1,20,50,100]$，并按顺序分配编号 `1`、`2`、`3`、`4`。
最小差之和为 $|1-1|+|20-2|+|50-3|+|100-4|=0+18+47+96=161$。

## 样例4

**输入**

```
1
5
0
```

**输出**

```
4
```

**说明**

只有一个任务，类别为 `0`，其处理编号只能为 `1`。差值为 $|5-1|=4$，这也是唯一可能的值，因此答案为 `4`。该样例展示了 $N=1$ 的边界情况。
