# 题目内容
给定一个仅由小写字母构成的字符串，考虑其所有子序列（子序列可通过删除任意字符得到，但要求剩余字符的相对顺序保持不变）。

对于一个子序列，若其中恰好有一种字符出现了恰好 $2$ 次，而其他所有种类的字符出现的次数均不等于 $2$，则称该子序列是“唯一双现”的。

现在请你计算该字符串的所有子序列中，“唯一双现”子序列的个数。

由于答案可能非常大，你需要输出这个数目对 $10^9+7$ 取模的结果。

字符串长度不超过 $2 \times 10^5$，且仅包含小写字母。

# 输入描述
输入只有一行，包含一个仅由小写字母组成的字符串 $s$，其长度不超过 $2 \times 10^5$。

# 输出描述
输出一个整数，表示所有“唯一双现”子序列的数量对 $10^9+7$ 取模后的值。

## 样例1

**输入**

```
a
```

**输出**

```
0
```

**说明**

字符串 `"a"` 的长度为 `1`，其所有非空子序列仅有 `"a"` 本身。在该子序列中，字符 `'a'` 出现了 `1` 次，没有出现 `2` 次的字符，因此不存在“唯一双现”的子序列，故答案为 `0`。

## 样例2

**输入**

```
aabb
```

**输出**

```
6
```

**说明**

字符串 `"aabb"` 中，`'a'` 和 `'b'` 各出现 `2` 次。按子序列长度分析符合条件的子序列：
- 长度为 `2`：子序列 `"aa"` 中 `'a'` 出现 `2` 次且无其他字符，符合条件；子序列 `"bb"` 同理符合。`"aa"` 只有一种选法（选择两个 `'a'`），`"bb"` 也只有一种选法，共 $2$ 种。
- 长度为 `3`：子序列需包含两个 `'a'` 和一个 `'b'`（即 `"aab"`），此时 `'a'` 恰出现 `2` 次，`'b'` 出现 `1` 次（不等于 `2`），符合条件；同理子序列 `"bba"` 也符合。选择两个 `'a'` 和任意一个 `'b'` 有 $2$ 种方式（因为 `'b'` 有两个位置可选）；同理 `"bba"` 也有 $2$ 种方式，共 $4$ 种。
- 长度为 `4`：子序列 `"aabb"` 中 `'a'` 和 `'b'` 均出现 `2` 次，不满足“恰好一种字符出现 `2` 次”的要求。
合计 $2 + 4 = 6$。

## 样例3

**输入**

```
abcc
```

**输出**

```
4
```

**说明**

字符串 `"abcc"` 包含 `'a'`、`'b'` 各 `1` 次，`'c'` 出现 `2` 次。符合条件的子序列如下：
- 仅选择两个 `'c'` 得到 `"cc"`：`'c'` 出现 `2` 次，无其他字符，符合。共 $1$ 种。
- 选择两个 `'c'` 和一个 `'a'` 得到 `"acc"`：`'c'` 恰出现 `2` 次，`'a'` 出现 `1` 次（不等于 `2`），符合。共 $1$ 种。
- 选择两个 `'c'` 和一个 `'b'` 得到 `"bcc"`：同理符合。共 $1$ 种。
- 选择全部字符得到 `"abcc"`：`'c'` 出现 `2` 次，`'a'` 和 `'b'` 各出现 `1` 次（均不等于 `2`），符合。共 $1$ 种。
合计 $1+1+1+1 = 4$。

## 样例4

**输入**

```
aaaa
```

**输出**

```
6
```

**说明**

字符串由相同字符 `'a'` 构成。要使子序列中恰有一种字符出现 `2` 次且其他字符出现次数不等于 `2`，仅需子序列中 `'a'` 恰好出现 `2` 次。因此所有长度为 `2` 的子序列均符合条件。从 `4` 个位置中任选 `2` 个，共有 $\binom{4}{2}=6$ 种。
