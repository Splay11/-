## 解题思路

本题采用**贡献法**与**乘法原理**进行计数。考虑每一个字符作为那个“恰好出现2次”的字符时，对答案的贡献，再将所有贡献累加。

1. **统计频数**  
   令字符串长度为 $n$。首先统计每个小写字母的出现次数，记作 `cnt[ch]`。

2. **枚举出现两次的字符**  
   遍历 26 个小写字母，假设当前字符 $i$ 恰好出现 $2$ 次（若 `cnt[i] < 2` 则跳过）。  
   从该字符的所有出现位置中选出 $2$ 个作为子序列中的对应字符，方案数为：
   \[
   \text{ways}_i = \binom{cnt[i]}{2} = \frac{cnt[i] \times (cnt[i]-1)}{2}
   \]

3. **处理其他字符的约束**  
   对于任意一个不等于 $i$ 的字符 $j$，它必须在子序列中出现的次数**不等于 $2$**。  
   一个字符出现在子序列中的方案总数是：要么不选，要么选其中若干个位置，但保持相对顺序（子序列由删除字符得到，实际上从出现次数中选任意 $k$ 个方案数为 $\binom{cnt[j]}{k}$）。总方案数为：
   \[
   2^{cnt[j]} = \binom{cnt[j]}{0} + \binom{cnt[j]}{1} + \binom{cnt[j]}{2} + \cdots
   \]
   其中出现恰好 $2$ 次的方案数为 $\binom{cnt[j]}{2}$。因此，**不出现恰好2次**的方案数为：
   \[
   cur_j = 2^{cnt[j]} - \binom{cnt[j]}{2}
   \]

4. **乘法原理累加贡献**  
   对固定的字符 $i$，将所有其他字符 $j$ 的方案数连乘，再乘上 $\text{ways}_i$，即得到以 $i$ 为“唯一双现”字符的子序列个数：
   \[
   \text{contribution}_i = \text{ways}_i \times \prod_{j \neq i} \left( 2^{cnt[j]} - \binom{cnt[j]}{2} \right)
   \]
   总答案为：
   \[
   \text{ans} = \sum_{i=0}^{25} \text{contribution}_i \pmod{10^9+7}
   \]

5. **快速幂计算 $2^k$**  
   使用快速幂（或预处理 $2$ 的幂表）计算 $2^{cnt[j]} \bmod (10^9+7)$。由于字母集仅 $26$，直接快速幂即可，不会成为瓶颈。

6. **取模注意事项**  
   所有乘法、减法运算均在模 $10^9+7$ 下进行，减法后需要加上模数再取模以防止负数。

## 复杂度分析

- **时间复杂度**：  
  统计频数需 $O(n)$，$n$ 为字符串长度。  
  枚举 $i$ 与 $j$ 共 $26 \times 26 = 676$ 次，每次需计算组合数（$O(1)$）和一次快速幂（$O(\log n)$）。  
  总时间复杂度为 $O(n + 26^2 \log n)$，在 $n \le 2\times 10^5$ 时完全可以接受。  
  若预处理 $2^k$ 表，可优化至 $O(n + 26^2)$。

- **空间复杂度**：  
  仅需长度为 $26$ 的频数数组以及若干临时变量，空间复杂度 $O(1)$（字母集大小可视为常数）。

## 代码实现

### Python

```python
MOD = 10**9 + 7

def qmi(a, b):
    """快速幂: 计算 a^b % MOD"""
    res = 1
    while b:
        if b & 1:
            res = res * a % MOD
        a = a * a % MOD
        b >>= 1
    return res

def solve():
    s = input().strip()
    cnt = [0] * 26
    for ch in s:
        cnt[ord(ch) - ord('a')] += 1

    ans = 0
    for i in range(26):
        if cnt[i] < 2:
            continue
        # 当前字符 i 选择 2 个的方案数
        ways = cnt[i] * (cnt[i] - 1) // 2
        # 计算其他字符的方案数乘积
        prod = 1
        for j in range(26):
            if j == i:
                continue
            # 总方案 2^cnt[j] 减去恰好出现2次的方案
            cur = (qmi(2, cnt[j]) - cnt[j] * (cnt[j] - 1) // 2) % MOD
            prod = (prod * cur) % MOD
        ans = (ans + ways * prod) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.*;

public class Main {
    static final int MOD = 1_000_000_007;

    static long qmi(long a, long b) {
        long res = 1;
        while (b > 0) {
            if ((b & 1) == 1) {
                res = res * a % MOD;
            }
            a = a * a % MOD;
            b >>= 1;
        }
        return res;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String s = scanner.next();
        int[] cnt = new int[26];
        for (char ch : s.toCharArray()) {
            cnt[ch - 'a']++;
        }

        long ans = 0;
        for (int i = 0; i < 26; i++) {
            if (cnt[i] < 2) {
                continue;
            }
            // 当前字符 i 选择 2 个的方案数
            long ways = (long) cnt[i] * (cnt[i] - 1) / 2;
            long prod = 1;
            for (int j = 0; j < 26; j++) {
                if (j == i) {
                    continue;
                }
                // 总方案 2^cnt[j] 减去恰好出现2次的方案
                long cur = (qmi(2, cnt[j]) - (long) cnt[j] * (cnt[j] - 1) / 2) % MOD;
                if (cur < 0) {
                    cur += MOD;
                }
                prod = (prod * cur) % MOD;
            }
            ans = (ans + ways * prod) % MOD;
        }

        System.out.println(ans);
        scanner.close();
    }
}
```

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MOD = 1e9 + 7;

long long qmi(long long a, long long b) {
    long long res = 1;
    while (b) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    vector<int> cnt(26, 0);
    for (char ch : s) {
        cnt[ch - 'a']++;
    }

    long long ans = 0;
    for (int i = 0; i < 26; ++i) {
        if (cnt[i] < 2) continue;
        // 当前字符 i 选择 2 个的方案数
        long long ways = 1LL * cnt[i] * (cnt[i] - 1) / 2;
        long long prod = 1;
        for (int j = 0; j < 26; ++j) {
            if (j == i) continue;
            // 总方案 2^cnt[j] 减去恰好出现2次的方案
            long long cur = (qmi(2, cnt[j]) - 1LL * cnt[j] * (cnt[j] - 1) / 2) % MOD;
            if (cur < 0) cur += MOD;
            prod = (prod * cur) % MOD;
        }
        ans = (ans + ways * prod) % MOD;
    }

    cout << ans << '\n';
    return 0;
}
```
