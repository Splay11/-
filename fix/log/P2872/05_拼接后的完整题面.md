# 题目内容
小 S 有一串由英文字母组成的密文 $s$，长度为 $n$，仅包含大小写字母。

他可以对密文进行若干次操作，每次操作如下：
- 选择两个不同的位置 $i$ 和 $j$，若 $s_i$ 与 $s_j$ 在计算机内部对应的编码值（整数值）之差的绝对值为偶数，则交换这两个位置上的字母。

经过任意多次操作后，小 S 希望得到字典序最小的密文。请你输出这个最终字符串。

字典序的定义：从字符串的第一个字符开始逐个比较，直到找到第一个不同的位置，以该位置上字符编码值的大小决定字符串的大小，这一比较方式称为字典序。

字符串的长度 $n$ 满足 $1 \le n \le 2 \times 10^5$，字符串仅由大小写英文字母构成。

# 输入描述
第一行输入一个正整数 $n$，表示字符串的长度。
第二行输入一个长度为 $n$ 的字符串，仅包含大小写英文字母。

# 输出描述
输出一个字符串，表示经过操作后能得到的字典序最小的字符串。

## 样例1

**输入**

```
6
DfcbAa
```

**输出**

```
DbAfac
```

**说明**

字符按 ASCII 码奇偶性分为两类：偶数字符有 `D`(68)、`f`(102)、`b`(98)，按升序排列为 `D`、`b`、`f`；奇数字符有 `c`(99)、`A`(65)、`a`(97)，排列为 `A`、`a`、`c`。
按照原字符串每个位置的奇偶属性依次填入：位置 `1` 为偶取 `D`，位置 `2` 为偶取 `b`，位置 `3` 为奇取 `A`，位置 `4` 为偶取 `f`，位置 `5` 为奇取 `a`，位置 `6` 为奇取 `c`。最终得到字典序最小的字符串 `DbAfac`。

## 样例2

**输入**

```
1
K
```

**输出**

```
K
```

**说明**

当字符串长度 $n=1$ 时，只有一个字符，无法执行任何操作，结果为原字符 `K`。

## 样例3

**输入**

```
4
JdPb
```

**输出**

```
JPbd
```

**说明**

所有字符的 ASCII 码均为偶数：`J`(74)、`d`(100)、`P`(80)、`b`(98)。偶数类内部可以任意交换，因此直接对所有字符按 ASCII 升序排序，得到 `J`、`P`、`b`、`d`，即 `JPbd`。这是字典序最小的结果。
