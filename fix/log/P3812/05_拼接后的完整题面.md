# 题目内容
仓库要印制一批层叠编号条。给定正整数 $n$，把 $n$ 的十进制写法记为记号串 $t$（例如 $n=10$ 时 $t$ 为 `10`）。

需要输出 $n$ 行：从上到下第 $i$ 行（$1 \le i \le n$）把 $t$ 连续重复恰好 $(n-i+1)$ 次，中间不加任何分隔符。也就是说，第一行重复 $n$ 次，第二行重复 $n-1$ 次，……，最后一行只出现一次 $t$。

约束：$n$ 为正整数且不超过 `100`。

# 输入描述
第一行包含一个正整数 $n$，表示层叠编号条的层数。保证 $1 \le n \le 100$。

# 输出描述
输出 $n$ 行。第 $i$ 行是记号串 $t$ 连续重复 $(n-i+1)$ 次得到的字符串。

## 样例1

**输入**

```
1
```

**输出**

```
1
```

**说明**

$n=1$ 时只有一层，记号串就是 `1`，输出一行 `1`。这是最小规模边界。

## 样例2

**输入**

```
2
```

**输出**

```
22
2
```

**说明**

按题意模拟计算得到。

3
