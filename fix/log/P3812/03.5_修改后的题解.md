## 解题思路

本题是模拟构造。把 $n$ 的十进制写法记为记号串 $t$（例如 $n=10$ 时 $t$ 为 `10`）。

从上到下共 $n$ 行：第 $i$ 行（$1\le i\le n$）把 $t$ 连续重复 $(n-i+1)$ 次。也就是重复次数从 $n$ 递减到 $1$。

实现时用一个函数完成“把字符串重复指定次数”，主程序读入 $n$ 后从 $n$ 循环到 $1$ 逐行输出即可。

## 复杂度分析

设 $|t|$ 为 $n$ 的十进制位数（$n\le 100$ 时至多为 $3$）。总输出长度为 $|t|\cdot n(n+1)/2$。

时间复杂度 $O(n^2)$（按重复次数计），额外空间 $O(|t|)$（每次只构造当前行）。

## 代码实现

### Python

```python
def repeat_token(s: str, cnt: int) -> str:
    """将字符串 s 重复 cnt 次并返回"""
    return s * cnt


def main():
    n = int(input().strip())
    s = str(n)  # n 的十进制表示

    for i in range(n, 0, -1):
        line = repeat_token(s, i)
        print(line)


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static String repeatToken(String s, int cnt) {
        StringBuilder sb = new StringBuilder(s.length() * cnt);
        for (int i = 0; i < cnt; i++) {
            sb.append(s);
        }
        return sb.toString();
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        if (!sc.hasNextInt()) {
            sc.close();
            return;
        }
        int n = sc.nextInt();
        String s = String.valueOf(n);

        for (int i = n; i >= 1; i--) {
            String line = repeatToken(s, i);
            System.out.println(line);
        }
        sc.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
using namespace std;

string repeatToken(const string& s, int cnt) {
    string res;
    res.reserve(s.size() * cnt);
    for (int i = 0; i < cnt; ++i) {
        res += s;
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);

    }

}
```
