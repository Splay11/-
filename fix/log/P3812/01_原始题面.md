# 题目内容

给出正整数 $N$，输出由 $N$ 组成的倒立金字塔。倒立金字塔的形状请参考样例。



# 输入描述

第一行给出一个正整数 $N$ 。

$1≤N≤100$

# 输出描述

输出倒立金字塔。



## 样例1 



**输入** 



```
5
```



**输出** 



```
55555
5555
555
55
5
```





## 样例2



**输入** 



```
10
```



**输出** 



```
10101010101010101010
101010101010101010
1010101010101010
10101010101010
101010101010
1010101010
10101010
101010
1010
10
```
