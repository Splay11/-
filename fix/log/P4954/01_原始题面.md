# 题目内容

监控系统维护长度为 $m$ 的 $01$ 串 $z$。

串的权值定义为：仅由字符 `'1'` 构成的非空连续子串的个数。

共有 $r$ 次操作；每次给出位置 $p$（$1$ 起下标），把 $z_p$ 取反（`0`↔`1`）。

请输出每次操作后的权值。

# 输入描述

单组用例。

- 第一行两个整型 $m,r$（$1 \le m \le 2\times 10^5$；$1 \le r \le 2\times 10^5$）。
- 第二行长度为 $m$ 的 $01$ 串 $z$。
- 随后 $r$ 行，每行一个整型 $p$（$1 \le p \le m$），表示本次翻转位置。

# 输出描述

输出 $r$ 行，每行一个整数，为该次操作后的权值。

## 样例1

**输入**

```
4 3
0110
1
3
2
```

**输出**

```
6
3
1
```

**说明**

- 初始串 `0110`，权值为 $3$。
- 翻转第 $1$ 位得 `1110`，权值为 $6$。
- 翻转第 $3$ 位得 `1100`，权值为 $3$。
- 翻转第 $2$ 位得 `1000`，权值为 $1$。
