# 题目内容
对于一个小写字母 $c$，定义其“伙伴”字母为 $	ext{partner}(c) = 	ext{'a'} + (	ext{'z'} - c)$。即 `'a'` 与 `'z'` 互为伙伴，`'b'` 与 `'y'` 互为伙伴，……，`'m'` 与 `'n'` 互为伙伴。

给定一个仅由小写字母组成的字符串 $s$，你可以选择至多一个连续区间，将区间内每个字符替换为其伙伴字母。你也可以不进行任何操作。

请你在至多一次操作后，使得到的字符串字典序尽可能小，并输出该最小结果。

**字典序**：按通常的字母顺序从左向右逐字符比较，先出现更小字符的字符串更小；若一方为另一方的前缀，则更短者更小。

**数据范围**

- 测试数据组数 $T$ 满足 $1 \le T \le 10^5$。
- 每个字符串的长度不超过 $10^5$。
- 所有字符串的总长度不超过 $2 	imes 10^5$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据组数。接下来 $T$ 行，每行包含一个仅由小写字母组成的字符串 $s$。

# 输出描述
输出 $T$ 行，每行一个字符串，表示在至多一次伙伴替换后可得到的字典序最小的字符串。

## 样例1

**输入**

```
1
zigzag
```

**输出**

```
aigzag
```

**说明**

对于字符串 `zigzag`，从左向右找到第一个大于 `'m'` 的字符是开头的 `'z'`。
将 `'z'` 替换为其伙伴字母 `'a'`，得到 `aigzag`。
此时字符串已经是开头最小的可能，因此这是字典序最小的结果。

## 样例2

**输入**

```
3
abc
nba
mzz
```

**输出**

```
abc
mba
maa
```

**说明**

- `abc`：所有字符都在 `'a'` 到 `'m'` 之间，无需操作，结果为 `abc`。
- `nba`：第一个大于 `'m'` 的字符是 `'n'`，将其替换为伙伴 `'m'`；后面的 `'b'` 小于 `'n'`，停止替换，得到 `mba`。
- `mzz`：开头 `'m'` 不大于 `'m'`，跳过；在索引 $1$ 处遇到 `'z'`，连续将两个 `'z'` 替换为 `'a'` 和 `'a'`，得到 `maa`。

## 样例3

**输入**

```
2
codeforces
zzzzz
```

**输出**

```
cldeforces
aaaaa
```

**说明**

- `codeforces`：从左向右扫描，第一个大于 `'m'` 的字符是 `'o'`，将其替换为伙伴 `'l'`；紧随的 `'d'` 小于 `'n'`，所以不再继续替换，结果为 `cldeforces`。
- `zzzzz`：全为 `'z'`，从位置 $0$ 开始连续替换每一个 `'z'` 为 `'a'`，得到 `aaaaa`。
