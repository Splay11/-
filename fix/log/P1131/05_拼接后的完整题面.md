# 题目内容
小蓝在学习序列分析时，提出了一种称为“完整阶”的片段。

对于一个序列，若将其按升序排列后，任意相邻两个元素的差值恰好为 $1$，则称该序列为一个“完整阶”。直观上看，一个完整阶片段包含的整数应当连续且互不相同。因此，序列 $B$ 是完整阶的充要条件为：$B$ 中所有元素互不相同，且最大值与最小值之差等于 $|B|-1$。

现在给定一个长度为 $n$ 的整数序列 $A_1, A_2, \dots, A_n$，请你帮小蓝统计有多少个长度为 $k$ 的连续子段恰好构成一个完整阶。

约束：
- $1 \le k \le n \le 3 \times 10^5$
- $1 \le A_i \le 10^6$

# 输入描述
第一行包含两个整数 $n$ 和 $k$，用一个空格隔开。
第二行包含 $n$ 个整数 $A_1, A_2, \dots, A_n$，相邻整数之间用一个空格隔开。

# 输出描述
输出一个整数，表示长度为 $k$ 的连续子段中是完整阶的片段个数。

## 样例1

**输入**

```
5 3
1 2 3 4 5
```

**输出**

```
3
```

**说明**

序列为 `1 2 3 4 5`，需要统计长度为 $k=3$ 且为完整阶的连续子段。

- 子段 `1 2 3`：元素互不相同，最大值 $3$，最小值 $1$，差为 $2=k-1$，是完整阶。
- 子段 `2 3 4`：元素互不相同，最大值 $4$，最小值 $2$，差为 $2$，是完整阶。
- 子段 `3 4 5`：元素互不相同，最大值 $5$，最小值 $3$，差为 $2$，是完整阶。

没有其他长度为 $3$ 的子段，因此答案为 `3`。

## 样例2

**输入**

```
6 4
4 5 6 4 7 8
```

**输出**

```
1
```

**说明**

序列为 `4 5 6 4 7 8`，$k=4$。

- 子段 `4 5 6 4`：元素 `4` 出现两次，不满足“互不相同”，不是完整阶。
- 子段 `5 6 4 7`：元素互不相同，最大值 $7$，最小值 $4$，差为 $3=k-1$，是完整阶。
- 子段 `6 4 7 8`：元素互不相同，最大值 $8$，最小值 $4$，差为 $4
eq k-1$，不是完整阶。

三个长度为 $4$ 的子段中只有 `1` 个满足条件。

## 样例3

**输入**

```
4 1
3 1 4 1
```

**输出**

```
4
```

**说明**

当 $k=1$ 时，任何长度为 $1$ 的子段都只包含一个元素，自然满足“互不相同”。最大值与最小值相等，差值为 $0=k-1$。因此每一个元素都独立构成完整阶。

序列 `3 1 4 1` 有 $4$ 个子段（`3`、`1`、`4`、`1`），全部符合，答案为 `4`。

## 样例4

**输入**

```
5 2
1 2 1 3 2
```

**输出**

```
3
```

**说明**

序列 `1 2 1 3 2`，$k=2$，完整阶需要两个不同的数且差为 $1$。

- 子段 `1 2`：无重复，差 $1$，符合。
- 子段 `2 1`：无重复，差 $1$，符合。
- 子段 `1 3`：无重复，但差为 $2
eq1$，不符合。
- 子段 `3 2`：无重复，差 $1$，符合。

共 `3` 个符合的子段。
