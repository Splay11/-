# 题目内容
作为一名珠宝工匠，你有一串共 $n$ 颗宝石。每颗宝石有一个基础价值 $v_i$ 和一个极性标记。极性标记由一个长度为 $n$ 且仅包含字符 `0` 和 `1` 的字符串 $t$ 给出。对于第 $i$ 颗宝石，若 $t_i$ 为 `1`，则其极性系数 $p_i = 1$；若 $t_i$ 为 `0`，则 $p_i = -1$。

你需要将宝石序列顺次划分为至多 $k$ 个连续非空段，每段将被加工成一件首饰。首饰按顺序编号 $1,2,\dots$。对于第 $j$ 段中的第 $i$ 颗宝石，它对总效用的贡献为 $p_i \times (v_i + j)$。总效用为所有宝石贡献之和。

你可以自由选择划分方案，目标是最大化总效用。请求出这个最大总效用。

数据范围：宝石个数 $n$ 满足 $2 \le n \le 10^5$，最多段数 $k$ 满足 $1 \le k \le n$。所有基础价值 $v_i$ 均满足 $1 \le v_i \le 10^9$。字符串 $t$ 的长度为 $n$，仅由字符 `0` 和 `1` 构成。

# 输入描述
输入共三行。第一行包含两个整数 $n$ 和 $k$，分别表示宝石的数量以及最多可划分的段数。第二行包含 $n$ 个整数 $v_1, v_2, \dots, v_n$，表示每颗宝石的基础价值。第三行包含一个长度为 $n$ 的字符串，仅由字符 `0` 和 `1` 组成，表示对应的极性标记。

# 输出描述
输出一个整数，表示能够获得的最大总效用。

## 样例1

**输入**

```
5 3
10 20 30 40 50
10101
```

**输出**

```
33
```

**说明**

宝石数量 $n=5$，最多段数 $k=3$。极性字符串 $t = \texttt{10101}$，对应的极性系数 $p = [1, -1, 1, -1, 1]$。

首先计算所有宝石都处于第 `1` 段时的基础效用：
$\text{base} = 1\times(10+1) + (-1)\times(20+1) + 1\times(30+1) + (-1)\times(40+1) + 1\times(50+1) = 11 - 21 + 31 - 41 + 51 = 31$。

计算从后向前极性系数的后缀和，作为在每个位置后切割所能带来的额外贡献：
在第 `1` 颗后切割，后续位置 `2~5` 的段号均增加 `1`，额外贡献为 $p_2+p_3+p_4+p_5 = -1+1-1+1=0$；
在第 `2` 颗后切割，额外贡献为 $p_3+p_4+p_5 = 1-1+1=1$；
在第 `3` 颗后切割，额外贡献为 $p_4+p_5 = -1+1=0$；
在第 `4` 颗后切割，额外贡献为 $p_5 = 1$。
正贡献的切割点有 `2` 处：切割在第 `2` 颗后（贡献 `1`）和第 `4` 颗后（贡献 `1`）。

由于最多可以切割 $k-1=2$ 次，我们选择这两处正贡献切割点，额外总收益 $\text{extra}=1+1=2$。
最终最大总效用为 $\text{base} + \text{extra} = 31 + 2 = 33$。

## 样例2

**输入**

```
3 1
5 5 5
111
```

**输出**

```
18
```

**说明**

当 $k=1$ 时，不允许任何切割，所有宝石只能在第 `1` 段中。
极性全为 `1`，系数 $p_i=1$。基础效用即为总效用：$\text{base} = 1\times(5+1) + 1\times(5+1) + 1\times(5+1) = 6+6+6 = 18$。
没有可用的切割次数，因此最大总效用就是 `18`。

## 样例3

**输入**

```
4 2
1 2 3 4
0000
```

**输出**

```
-14
```

**说明**

极性字符串全为 `0`，所有极性系数 $p_i = -1$。
基础效用（全部在第 `1` 段）：
$\text{base} = -1\times(1+1) + -1\times(2+1) + -1\times(3+1) + -1\times(4+1) = -2 - 3 - 4 - 5 = -14$。

后缀和全为负数：切割点贡献分别是 $-3, -5, -7$，均为负。因为最多允许 $k-1=1$ 次切割，但任何切割都会进一步降低总效用，因此最优方案是不切割。
最终最大总效用为 $-14$。

## 样例4

**输入**

```
6 4
1 1 1 1 1 1
111111
```

**输出**

```
24
```

**说明**

所有极性系数 $p_i=1$，基础效用 $\text{base} = 6\times(1+1)=12$。

从后向前后缀和：
在第 `1` 颗后切割贡献 $5$，第 `2` 颗后贡献 $4$，第 `3` 颗后贡献 $3$，第 `4` 颗后贡献 $2$，第 `5` 颗后贡献 $1$。所有贡献均为正数。

由于 $k=4$，最多可以选择 $k-1=3$ 个贡献最大的切割点，即贡献为 $5,4,3$ 的三处。
额外收益 $\text{extra} = 5+4+3 = 12$。
最大总效用 $= 12 + 12 = 24$。
