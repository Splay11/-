## 解题思路

把一段 `01` 指示灯全部点亮的最少前缀翻转次数，等价于从右往左扫描：每遇到一个 `0` 就对当前前缀翻转一次。由此可以观察到：

- 以 `1` 开头的子串，权值一定是偶数；
- 以 `0` 开头的子串，权值一定是奇数。

因此只需统计长度为奇数、且以 `0` 开头的连续子串个数。

用 $dp[i][lenParity][wParity]$ 表示以位置 $i$ 结尾、长度奇偶为 $lenParity$、权值奇偶为 $wParity$ 的子串个数（`0` 表示偶，`1` 表示奇）。转移时：

- 当前位单独构成长度为 `1` 的子串：若为 `1` 则权值为偶，若为 `0` 则权值为奇；
- 再把以前一位结尾的所有子串接到当前位后面，长度奇偶翻转，权值奇偶不变。

答案累加以 $i$ 结尾且 $lenParity=1$、$wParity=1$ 的数量。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(n)$。

## 代码实现

### Python

```python
n = int(input())
s = input()

dp = [[[0, 0] for _ in range(2)] for _ in range(n)]
ans = 0

for i in range(n):
    if s[i] == '1':
        dp[i][1][0] += 1
        if i > 0:
            dp[i][0][0] += dp[i - 1][1][0]
            dp[i][0][1] += dp[i - 1][1][1]
            dp[i][1][0] += dp[i - 1][0][0]
            dp[i][1][1] += dp[i - 1][0][1]
    else:
        dp[i][1][1] += 1
        if i > 0:
            dp[i][0][0] += dp[i - 1][1][0]
            dp[i][0][1] += dp[i - 1][1][1]
            dp[i][1][0] += dp[i - 1][0][0]
            dp[i][1][1] += dp[i - 1][0][1]
    ans += dp[i][1][1]

print(ans)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        String s = scanner.next();
        int[][][] dp = new int[n][2][2];
        int ans = 0;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '1') {
                dp[i][1][0] += 1;
                if (i > 0) {
                    dp[i][0][0] += dp[i - 1][1][0];
                    dp[i][0][1] += dp[i - 1][1][1];
                    dp[i][1][0] += dp[i - 1][0][0];
                    dp[i][1][1] += dp[i - 1][0][1];
                }
            } else {
                dp[i][1][1] += 1;
                if (i > 0) {
                    dp[i][0][0] += dp[i - 1][1][0];
                    dp[i][0][1] += dp[i - 1][1][1];
                    dp[i][1][0] += dp[i - 1][0][0];
                    dp[i][1][1] += dp[i - 1][0][1];
                }
            }
            ans += dp[i][1][1];
        }
        System.out.println(ans);
    }
}
```
