# 题目内容
地铁换乘通道两侧安装了一排指示灯，从左到右共 $n$ 盏，状态用长度为 $n$ 的 `01` 字符串 $s$ 表示：`0` 表示熄灭，`1` 表示点亮。检修规程规定，一次操作可以选定下标 $i$（$1 \le i \le n$），把从左端到 $i$ 的所有灯全部取反（`0` 变 `1`，`1` 变 `0`）。把某一段连续灯全部点亮所需的最少操作次数，称为该段的检修代价。调度室需要统计：$s$ 中有多少个长度为正奇数的连续子串，其检修代价也是奇数。

连续子串是指从原串中取出一段相邻字符得到的非空字符串。

约束：$1 \le n \le 100000$。

# 输入描述
第一行一个整数 $n$，表示指示灯盏数。
第二行一个长度为 $n$ 的 `01` 字符串 $s$。
保证 $1 \le n \le 100000$，$s$ 仅含字符 `0` 和 `1`。

# 输出描述
输出一个整数，表示长度与检修代价均为奇数的非空连续子串个数。

## 样例1

**输入**

```
1
0
```

**输出**

```
1
```

**说明**

只有一个子串 `0`。将其变为 `1` 需操作一次（选定唯一位置取反），长度为 `1`、权值为 `1`，都是奇数，答案为 `1`。

## 样例2

**输入**

```
4
1100
```

**输出**

```
2
```

**说明**

长度为奇数的子串如下：

- 长度 `1`：`1`、`1`、`0`、`0`，权值分别为 `0`、`0`、`1`、`1`，奇数权值 `2` 个；
- 长度 `3`：`110`、`100`，均以 `1` 开头，权值为偶数。

合计 `2`。

## 样例3

**输入**

```
6
100111
```

**输出**

```
5
```

**说明**

以 `0` 开头的子串权值为奇数，以 `1` 开头的权值为偶数。只需统计长度为奇数且以 `0` 开头的连续子串：

- 长度 `1`：第 `2`、`3` 位的 `0`，共 `2` 个；
- 长度 `3`：`001`、`011`，共 `2` 个；
- 长度 `5`：`00111`，共 `1` 个。

合计 `5`。
