## 解题思路

- 使用栈来模拟处理槽，栈顶对应槽的顶部，栈底对应槽的底部。初始栈为空。
- 期望的弹出顺序是 $1,2,\dots,n$，设置一个指针 `target` 表示下一个希望弹出的编号，初始值为 $1$。
- 依次处理 $2n$ 条操作：
  - **`push val`**：将编号为 $val$ 的物品直接压入栈顶。
  - **`pop`**：检查栈顶元素是否等于 `target`。
    - 若相等，说明无需额外操作即可弹出期望编号，直接弹出栈顶，并将 `target` 自增 $1$。
    - 若不相等，则说明当前栈内顺序无法自然给出期望编号，必须进行一次**整理**：
      1. 整理次数加 $1$。
      2. 将栈内所有物品按照编号**从小到大**重新排列，使得槽的顶部（栈顶）恰好是最小编号。
      3. 此时栈顶一定为 `target`，弹出该物品，并将 `target` 自增 $1$。
- 为什么上述“延迟整理”策略是最优的？  
  整理可以在任意一次 `push` 后立即进行，但将其推迟到不得不整理的时刻（即下一次 `pop` 发现栈顶不匹配时）不会增加整理次数，因为一次整理的效果总是让栈内完全有序，且只要后续 `pop` 正常就不需要额外整理。因此上述模拟过程中记录的整理次数即为答案。
- 题目保证至少存在一种可行方案，且每次 `pop` 时槽内一定非空，故模拟过程不会出错。

## 复杂度分析

- 在最坏情况下，每次 `pop` 都可能触发整理，而每次整理需要将栈内元素全部取出并排序。当前栈的大小最大为 $n$，排序需要 $O(k\log k)$，其中 $k$ 为栈大小。整理次数最多为 $O(n)$，因此最坏时间复杂度为 $O(n^2\log n)$。
- 栈以及整理时用到的临时数组空间均为 $O(n)$，故空间复杂度为 $O(n)$。

## 代码实现

### Python

```python
def main():
    n = int(input())
    stack = []
    target = 1
    sort_cnt = 0

    for _ in range(2 * n):
        parts = input().split()
        if parts[0] == 'push':
            val = int(parts[1])
            stack.append(val)
        else:  # pop
            if stack[-1] == target:
                stack.pop()
                target += 1
            else:
                sort_cnt += 1
                # 整理：将栈内物品从小到大排列，顶部（列表末尾）为最小
                stack.sort(reverse=True)
                stack.pop()  # 此时栈顶必为 target
                target += 1

    print(sort_cnt)

if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        Deque<Integer> stack = new ArrayDeque<>();
        int target = 1;
        int sortCnt = 0;

        for (int i = 0; i < 2 * n; i++) {
            String op = sc.next();
            if (op.equals("push")) {
                int val = sc.nextInt();
                stack.push(val);
            } else { // pop
                if (!stack.isEmpty() && stack.peek() == target) {
                    stack.pop();
                    target++;
                } else {
                    sortCnt++;
                    // 整理：取出全部物品，从小到大排序后重新放回，使顶部为最小
                    List<Integer> temp = new ArrayList<>();
                    while (!stack.isEmpty()) {
                        temp.add(stack.pop());
                    }
                    Collections.sort(temp);
                    for (int j = temp.size() - 1; j >= 0; j--) {
                        stack.push(temp.get(j));
                    }
                    stack.pop(); // 弹出 target
                    target++;
                }
            }
        }
        System.out.println(sortCnt);
    }
}
```

### C++

```cpp
#include <iostream>
#include <stack>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    int n;
    cin >> n;
    stack<int> st;
    int target = 1;
    int sort_cnt = 0;

    for (int i = 0; i < 2 * n; ++i) {
        string op;
        cin >> op;
        if (op == "push") {
            int val;
            cin >> val;
            st.push(val);
        } else { // pop
            if (!st.empty() && st.top() == target) {
                st.pop();
                target++;
            } else {
                sort_cnt++;
                // 整理：取出全部物品，从小到大排序后重新放回，使顶部为最小
                vector<int> temp;
                while (!st.empty()) {
                    temp.push_back(st.top());
                    st.pop();
                }
                sort(temp.begin(), temp.end());
                for (int j = temp.size() - 1; j >= 0; --j) {
                    st.push(temp[j]);
                }
                st.pop(); // 弹出 target
                target++;
            }
        }
    }
    cout << sort_cnt << endl;
    return 0;
}
```
