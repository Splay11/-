# 题目内容
在一个处理槽里初始放着 $n$ 件物品，它们的编号恰好是 $1$ 到 $n$。现在依次执行 $2 \times n$ 条操作，操作类型有两种：
- `push val`：将编号为 $val$ 的物品放入槽内，新放入的物品位于槽的顶部；
- `pop`：从槽的顶部取出一件物品。

你希望在 $pop$ 操作中取出的物品编号恰好依次为 $1, 2, \dots, n$。为此，每次 `push` 指令执行后，你可以选择立即对槽内的所有物品进行一次整理：将它们按照编号从大到小重新排布，使得编号最小的物品恰好出现在顶部（后续可以自然拿出）。每次整理需要付出 $1$ 的代价。

已知至少存在一种操作方案可以达到目标，且每次 `pop` 时槽内一定非空。请你计算最少需要进行多少次整理，才能让 $pop$ 取出的编号序列恰好为 $1, 2, \dots, n$。

元素个数 $n$ 不超过 $10^5$，每次插入的物品编号 $val$ 满足 $1 \le val \le n$。

# 输入描述
第一行输入一个整数 $n$，表示物品的种类数。
接下来 $2 \times n$ 行，每行描述一条操作。操作格式为以下两种之一：
- 字符串 `push` 后跟一个整数 $val$，表示进行一次放入操作；
- 字符串 `pop`，表示进行一次取出操作。
所有操作字符串均为小写，且保证指令与数据均符合约束。

# 输出描述
输出一个整数，表示最少需要的整理次数。

## 样例1

**输入**

```
1
push 1
pop
```

**输出**

```
0
```

**说明**

只有一件物品编号为 `1`，`push 1` 后槽顶为 `1`，接下来的 `pop` 直接取出 `1`，已经满足目标序列 $1$，无需进行任何整理。

## 样例2

**输入**

```
3
push 1
pop
push 2
pop
push 3
pop
```

**输出**

```
0
```

**说明**

每次 `push` 的物品恰好是当前期望取出的编号。
- `push 1` 后槽顶为 `1`，`pop` 得到 `1`，期望变为 `2`；
- `push 2` 后槽顶为 `2`，`pop` 得到 `2`，期望变为 `3`；
- `push 3` 后槽顶为 `3`，`pop` 得到 `3`。
所有 `pop` 均自然满足顺序，不需要整理。

## 样例3

**输入**

```
3
push 3
push 1
push 2
pop
pop
pop
```

**输出**

```
1
```

**说明**

操作过程：`push 3` 槽 $[3]$；`push 1` 槽 $[3,1]$（顶 `1`）；`push 2` 槽 $[3,1,2]$（顶 `2`）。
此时需要 `pop` 出 $1$，但栈顶为 `2`。我们必须在 `push 2` 后执行一次整理，将槽内物品按编号从大到小排序，变为 $[3,2,1]$（顶 `1`）。
随后依次 `pop` 得到 $1,2,3$。最少整理次数为 $1$。

## 样例4

**输入**

```
4
push 2
push 1
push 3
pop
pop
push 4
pop
pop
```

**输出**

```
2
```

**说明**

模拟操作：
- `push 2`：槽 $[2]$；
- `push 1`：槽 $[2,1]$（顶 `1`）；
- `push 3`：槽 $[2,1,3]$（顶 `3`）。此时需要 `pop` 出期望 $1$，栈顶却是 `3`，必须在 `push 3` 后进行第 $1$ 次整理，槽变成 $[3,2,1]$。
- `pop`：得到 $1$，期望变为 $2$，槽 $[3,2]$；
- `pop`：得到 $2$，期望变为 $3$，槽 $[3]$；
- `push 4`：槽 $[3,4]$（顶 `4`）。接下来 `pop` 期望 $3$，栈顶为 `4`，只能在 `push 4` 后立即进行第 $2$ 次整理，槽变为 $[4,3]$。
- `pop`：得到 $3$，槽 $[4]$；
- `pop`：得到 $4$。
共整理 $2$ 次。
