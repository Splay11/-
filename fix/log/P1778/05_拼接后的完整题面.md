# 题目内容
在一个由 $n$ 个网络节点和 $m$ 条双向链路构成的通信网络中，节点编号 $1$ 到 $n$。每条链路固定使用两种通道类型之一（类型 `1` 或类型 `2`），通过该链路需要花费 $w$ 个单位时间。

每个节点 $i$ 有一个切换延迟 $c_i$。当数据包到达某个节点后，如果接下来要使用的链路通道类型与当前持有的通道类型不同，则必须在该节点花费 $c_i$ 的时间完成切换。数据包从节点 $1$ 出发时，可以任意选择一种通道类型且不产生切换延迟；到达目的节点 $n$ 后任务完成，无需再进行切换。

请你计算从节点 $1$ 到节点 $n$ 所需的最短总时间。

数据范围：
- 节点数 $n$ 和链路数 $m$ 满足 $1 \le n, m \le 10^5$。
- 切换延迟 $c_i$ 满足 $0 \le c_i \le 10^9$。
- 链路传输时间 $w$ 满足 $1 \le w \le 10^9$。
- 通道类型 $t$ 为 `1` 或 `2`。
- 保证从节点 $1$ 可以到达节点 $n$。

# 输入描述
第一行包含两个整数 `n` 和 `m`，分别表示节点数量和链路数量。
第二行包含 `n` 个整数 $c_1, c_2, \dots, c_n$，表示每个节点的切换延迟。
接下来 `m` 行，每行包含四个整数 `u`, `v`, `w`, `t`，表示一条连接节点 `u` 和 `v` 的双向链路，通过时间为 `w`，通道类型为 `t`（`1` 或 `2`）。

# 输出描述
输出一个整数，表示从节点 `1` 到节点 `n` 的最短总时间。

## 样例1

**输入**

```
3 3
0 0 0
1 2 1 1
2 3 2 2
1 3 5 1
```

**输出**

```
3
```

**说明**

网络中有 `3` 个节点，所有切换延迟均为 `0`。
最优路径：从节点 `1` 出发选择类型 `1`（无切换延迟），沿边 $1 \rightarrow 2$（类型 `1`，耗时 `1`）到达节点 `2`，当前持有类型 `1`；再沿边 $2 \rightarrow 3$（类型 `2`，耗时 `2`），由于类型不同，切换延迟 $c_2 = 0$，总时间 $1 + 0 + 2 = 3$。
若选择直接走 $1 \rightarrow 3$（类型 `1`，耗时 `5`），总时间为 `5`。
若出发选择类型 `2`，则需要切换或绕行，均不会优于 `3`。故最短时间为 `3`。

## 样例2

**输入**

```
2 1
10 20
1 2 5 1
```

**输出**

```
5
```

**说明**

只有 `2` 个节点和 `1` 条链路。节点 `1` 的切换延迟 $c_1 = 10$，节点 `2` 的切换延迟 $c_2 = 20$。
从节点 `1` 出发时，可以任选一种通道类型且无切换延迟。若直接选择类型 `1`，则沿链路 $1 \rightarrow 2$（类型 `1`，耗时 `5`）无需切换，总时间 `5`。
若出发选择类型 `2`，则必须在节点 `1` 花费 $c_1 = 10$ 的时间切换到类型 `1` 才能通过链路，总时间 $10 + 5 = 15$。
因此最短总时间为 `5`。

## 样例3

**输入**

```
4 4
1 2 3 4
1 2 1 1
2 3 1 2
2 4 10 1
3 4 1 2
```

**输出**

```
5
```

**说明**

网络有 `4` 个节点。切换延迟分别为 $c_1 = 1$, $c_2 = 2$, $c_3 = 3$, $c_4 = 4$。
最优路径为 $1 \rightarrow 2 \rightarrow 3 \rightarrow 4$：
- 从节点 `1` 出发选择类型 `1`。
- 沿 $1 \rightarrow 2$（类型 `1`，耗时 `1`）到达节点 `2`，持有类型 `1`。
- 沿 $2 \rightarrow 3$（类型 `2`，耗时 `1`），需切换，花费切换延迟 $c_2 = 2$，累计 $1 + 2 + 1 = 4$，到达节点 `3` 持有类型 `2`。
- 沿 $3 \rightarrow 4$（类型 `2`，耗时 `1`），无切换，总时间 $4 + 1 = 5$。
另一条路径 $1 \rightarrow 2 \rightarrow 4$（类型 `1` 全程）耗时为 $1 + 10 = 11$，更长。
故最短时间为 `5`。

## 样例4

**输入**

```
1 0
5
```

**输出**

```
0
```

**说明**

网络中只有节点 `1`，且没有任何链路。起点即为终点，无需任何移动，总花费时间为 `0`。切换延迟 $c_1 = 5$ 无需使用，不影响结果。
