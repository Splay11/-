# 题目内容
你需要在一条生产线上完成 $n$ 个工序，工序编号为 $0$ 到 $n-1$。一些工序之间存在先后约束：给定若干对关系 $[a, b]$，表示完成工序 $a$ 之前必须先完成工序 $b$。

请你设计一个能够完成全部工序的顺序，并将工序编号按顺序排列。如果因为约束冲突导致无法完成所有工序，则返回一个空列表。

**数据范围**：
- 工序总数 $n$ 满足 $1 \le n < 2000$。
- 依赖关系的数量 $m$ 满足 $0 \le m \le n(n-1)$，且保证不会出现完全相同的依赖对。

# 输入描述
输入只有一行，格式为：一个二维整数列表和一个整数 $n$，中间用逗号分隔。二维列表的每个元素是一个包含两个整数的列表 $[a, b]$，表示要完成工序 $a$ 必须先完成工序 $b$。工序编号均从 $0$ 开始。$n$ 为工序总数，满足 $1 \le n < 2000$。依赖关系总数 $m$ 满足 $0 \le m \le n(n-1)$，且无重复的依赖对。

# 输出描述
输出一行，包含一个列表，表示一个可行的工序完成顺序。如果不存在这样的顺序，则输出空列表 `[]`。列表格式与输入中的二维列表类似，例如 `[0,1,2]`。

## 样例1

**输入**

```
[[2,0],[3,1],[3,2]],4
```

**输出**

```
[0,1,2,3]
```

**说明**

给定 $n=4$ 个工序，依赖关系为：完成工序 `2` 需要先完成 `0`（$0 \\to 2$），完成 `3` 需要先完成 `1` 和 `2`（$1 \\to 3$，$2 \\to 3$）。

初始时工序 `0` 和 `1` 的入度为 `0`，可以开始。优先选择编号较小的 `0`，完成后 `2` 变为可做；接着做 `1`，完成后 `3` 的入度减少但仍未归零；再做 `2`，使得 `3` 入度归零；最后完成 `3`。因此一个可行的顺序为 `0,1,2,3`。小根堆保证了在多个候选时优先选择编号最小的工序。

## 样例2

**输入**

```
[[0,1],[1,2],[2,0]],3
```

**输出**

```
[]
```

**说明**

工序数 $n=3$。依赖对形成循环：`0` 依赖 `1`，`1` 依赖 `2`，`2` 又依赖 `0`，构成有向环 $0 \\to 1 \\to 2 \\to 0$。

此时没有任何工序的入度为 `0`，无法开始，因此任务不可能全部完成，返回空列表 `[]`。

## 样例3

**输入**

```
[],1
```

**输出**

```
[0]
```

**说明**

只有一个工序 `0`，且没有任何依赖关系。直接执行即可，顺序为 `[0]`。

## 样例4

**输入**

```
[[1,0],[3,2],[4,0]],5
```

**输出**

```
[0,1,2,3,4]
```

**说明**

$n=5$，依赖关系：`1` 依赖 `0`，`3` 依赖 `2`，`4` 依赖 `0`。形成两条独立链：$0 \\to 1$ 和 $0 \\to 4$，以及 $2 \\to 3$。

初始入度为 `0` 的有 `0` 和 `2`。小根堆优先取出 `0`，解锁 `1` 和 `4`；接着取出 `1`；然后取出 `2` 解锁 `3`；之后依次完成 `3` 和 `4`。最终顺序为 `[0,1,2,3,4]`。注意其他合法顺序亦可，但本题解使用小根堆以保证输出确定。
