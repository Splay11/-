# 题目内容
给定一棵包含 $n$ 个节点的无向树，节点编号为 $1$ 到 $n$。你需要为每个节点 $i$ 分配一个非负整数 $a_i$，满足 $0 \le a_i < 2^{30}$。

每条边 $(u,v)$ 带有一个权值 $c$，它对该边两端节点施加如下二进制位限制：考虑所有二进制位 $k$（$k \ge 0$），记 $c$ 的第 $k$ 位为 $c_k \in \{0,1\}$，
- 若 $c_k = 1$，则 $a_u$ 与 $a_v$ 的第 $k$ 位都必须为 $1$；
- 若 $c_k = 0$，则 $a_u$ 与 $a_v$ 的第 $k$ 位不能同时为 $1$。

你的目标是在满足所有边限制的前提下，最大化所有节点值之和 $\sum_{i=1}^n a_i$，并输出该最大值。

数据保证至少存在一种合法分配方案。

约束条件：
- 节点个数 $n$ 不超过 $2 \times 10^5$。
- 每条边的权值 $c$ 满足 $0 \le c < 2^{30}$。

# 输入描述
第一行包含一个整数 $n$，表示树的节点数。
接下来 $n-1$ 行，每行包含三个整数 $u$、$v$、$c$，表示节点 $u$ 与节点 $v$ 之间有一条边，且边的限制值为 $c$。节点编号从 $1$ 到 $n$，输入保证构成一棵树。

# 输出描述
输出一个整数，表示在所有合法分配下，所有节点值之和的最大可能值。

## 样例1

**输入**

```
1
```

**输出**

```
1073741823
```

**说明**

当只有 `1` 个节点且没有边时，不存在任何限制。节点 $1$ 可以取到最大值 $a_1 = 2^{30}-1 = 1073741823$，因此总和最大值为 `1073741823`。

## 样例2

**输入**

```
2
1 2 0
```

**输出**

```
1073741823
```

**说明**

共有 `30` 个二进制位。对于每一位 $k$，边权 $c=0$ 表示 $a_1$ 和 $a_2$ 的第 $k$ 位不能同时为 `1`。为了最大化每一位的贡献，我们可以让其中一个节点该位为 `1`，另一个为 `0`，这样该位的和最大为 `1`。由于每一位独立，总和最大为 $\sum_{k=0}^{29} 2^k = 2^{30}-1 = 1073741823$。

## 样例3

**输入**

```
2
1 2 1
```

**输出**

```
1073741824
```

**说明**

对于第 $0$ 位（权重 $2^0=1$），边权 $c=1$ 的第 $0$ 位为 `1`，强制 $a_1$ 和 $a_2$ 的第 $0$ 位都为 `1`，贡献为 `2`。对于其余 $k \ge 1$ 的位，$c_k=0$，限制是不能同时为 `1`，因此贡献最大为 `1`。总和为 $2 \times 1 + \sum_{k=1}^{29} 1 \times 2^k = 2 + (2^{30}-2) = 2^{30} = 1073741824$。

## 样例4

**输入**

```
4
1 2 1
2 3 2
3 4 0
```

**输出**

```
2147483647
```

**说明**

按位独立计算：
- 对于第 $0$ 位（$2^0$）：边 $(1,2)$ 要求 $1$ 和 $2$ 均为 `1`；边 $(2,3)$ 的第 $0$ 位为 `0`，禁止 $2$ 和 $3$ 同时为 `1`，故 $3$ 为 `0`；边 $(3,4)$ 第 $0$ 位为 `0`，禁止 $3$ 和 $4$ 同时为 `1`，$3$ 已经是 `0`，故 $4$ 可取 `1`。因此第 $0$ 位为 `1` 的节点集合为 $\{1,2,4\}$，贡献 $3$。
- 对于第 $1$ 位（$2^1$）：边 $(2,3)$ 的第 $1$ 位为 `1`，强制 $2$ 和 $3$ 为 `1`；边 $(1,2)$ 的第 $1$ 位为 `0`，$2$ 为 `1` 则 $1$ 必须为 `0`；边 $(3,4)$ 的第 $1$ 位为 `0`，$3$ 为 `1` 则 $4$ 必须为 `0`。因此第 $1$ 位为 `1` 的集合为 $\{2,3\}$，贡献 $2 \times 2 = 4$。
- 对于 $k \ge 2$ 的位：所有边权在该位均为 `0`，转化为树上的最大独立集问题。在 $4$ 个节点的链上，最大独立集大小为 `2`，贡献为 $2 \times \sum_{k=2}^{29} 2^k = 2 \times (2^{30}-4)$。
总和为 $3 + 4 + 2 \times (2^{30}-4) = 2^{31}-1 = 2147483647$。
