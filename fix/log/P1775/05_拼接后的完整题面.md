# 题目内容
在一个 $8 \times 8$ 的样品台上，行用数字 $1$ 到 $8$ 编号，列用小写字母 $a$ 到 $h$ 编号。在某一个格子中安装了一台激光扫描仪，它能同时向八个方向发射激光：正上、正下、正左、正右以及四个对角线方向。激光会沿直线传播并覆盖沿途所有格子，直到样品台的边界。扫描仪自身所在的格子不会被激光覆盖。

给定扫描仪的安装位置，请计算出所有会被激光覆盖的格子，并按字典序输出。

约束：样品台大小固定为 $8 \times 8$，输入的位置保证合法，即列标号为 $a$ 到 $h$ 之一，行编号为 $1$ 到 $8$ 之一的数字。

# 输入描述
输入包含一行，一个长度为 $2$ 的字符串，第一个字符为列标号（小写字母 $a$ 到 $h$），第二个字符为行编号（数字 $1$ 到 $8$），表示扫描仪的安装位置。

# 输出描述
第一行输出一个整数，表示被激光覆盖的格子数量（不包含安装位置）。第二行输出这些格子的位置，每个位置表示为一个长度为 $2$ 的字符串（列标号后跟行编号），按字典序从小到大排列，相邻字符串之间用一个空格分隔。

## 样例1

**输入**

```
a1
```

**输出**

```
21
a2 a3 a4 a5 a6 a7 a8 b1 b2 c1 c3 d1 d4 e1 e5 f1 f6 g1 g7 h1 h8
```

**说明**

扫描仪位于 `a1`，激光向八个方向发射。正上方经过 `a2` 到 `a8`（`7` 个格子）；正右方经过 `b1` 到 `h1`（`7` 个格子）；右上方对角线经过 `b2`, `c3`, `d4`, `e5`, `f6`, `g7`, `h8`（`7` 个格子）。其余方向（正下、正左、左上、左下、右下）因到达边界而没有覆盖任何格子。总共 $7+7+7 = 21$ 个格子被覆盖，按字典序排序后输出。

## 样例2

**输入**

```
e4
```

**输出**

```
27
a4 a8 b1 b4 b7 c2 c4 c6 d3 d4 d5 e1 e2 e3 e5 e6 e7 e8 f3 f4 f5 g2 g4 g6 h1 h4 h7
```

**说明**

扫描仪位于 `e4`。八个方向的覆盖情况如下：正上 `e1 e2 e3`（`3` 个）；正下 `e5 e6 e7 e8`（`4` 个）；正左 `a4 b4 c4 d4`（`4` 个）；正右 `f4 g4 h4`（`3` 个）；左上对角线 `b1 c2 d3`（`3` 个）；右上对角线 `h1 g2 f3`（`3` 个）；左下对角线 `a8 b7 c6 d5`（`4` 个）；右下对角线 `f5 g6 h7`（`3` 个）。总共 $3+4+4+3+3+3+4+3 = 27$ 个格子。按字典序排列输出。

## 样例3

**输入**

```
h8
```

**输出**

```
21
a1 a8 b2 b8 c3 c8 d4 d8 e5 e8 f6 f8 g7 g8 h1 h2 h3 h4 h5 h6 h7
```

**说明**

扫描仪位于 `h8`。正左方向覆盖 `a8` 到 `g8`（`7` 个）；正下方向覆盖 `h1` 到 `h7`（`7` 个）；左下对角线覆盖 `g7`, `f6`, `e5`, `d4`, `c3`, `b2`, `a1`（`7` 个）。其余方向（正上、正右、左上、右上、右下）均到达边界无覆盖。总共 $7+7+7 = 21$ 个格子。按字典序输出。
