# 题目内容
投资机构手头有 $n$ 个候选项目，第 $i$ 个项目的估值为 $a_i$。需要选出一个非空子集立项（按下标区分，相同估值也可同时入选）。收益规则由风控给出：所选估值中的最小值，加上入选项目的个数。请计算可能达到的最高收益。

约束：测试组数不超过 $10^2$，单组 $1 \le n \le 200000$，且所有测试中 $n$ 之和不超过 $300000$。$1 \le a_i \le 1000000000$。

# 输入描述
第一行一个正整数 $T$，表示测试组数，满足 $1 \le T \le 10^2$。
对每组测试：第一行一个正整数 $n$；第二行 $n$ 个正整数 $a_1,a_2,\ldots,a_n$。
保证 $1 \le n \le 200000$，$1 \le a_i \le 1000000000$，且所有 $n$ 之和不超过 $300000$。

# 输出描述
对每组测试输出一行一个整数，表示最高收益。

## 样例1

**输入**

```
2
3
1 10 5
1
8
```

**输出**

```
11
9
```

**说明**

将数组排序后，枚举最小值取排序后的 $a_i$，则可以选中它及右边全部元素，得分 $a_i+(n-i)$。

- `[1,5,10]`：三种取法得分 `4`、`7`、`11`，最高 `11`；
- 单个 `8`：得分为 $8+`1`=`9`。

## 样例2

**输入**

```
1
4
7 7 7 7
```

**输出**

```
11
```

**说明**

四个数全是 `7`。全选时最小值为 `7`、个数为 `4`，得分 `11`。少选只会减小个数，得分不会更高。

## 样例3

**输入**

```
1
6
9 1 4 8 2 6
```

**输出**

```
10
```

**说明**

排序后为 `1 2 4 6 8 9`。分别以它们为最小值，得分依次为 `7`、`7`、`8`、`9`、`10`、`10`，最高为 `10`。
