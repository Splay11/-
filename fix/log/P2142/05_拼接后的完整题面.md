# 题目内容
给定若干仅由小写英文字母组成的产品编号。编号从左到右第 $p$ 个字符的下标为 $p$（从 `1` 开始）。若 $p$ 的二进制表示中 `1` 的个数为奇数，则把该位置的小写字母改为对应的大写字母；否则保持不变。

请对每组编号输出升格后的结果。

测试组数不超过 `2000`，单个编号长度不超过 `500`。

# 输入描述
第一行一个整数 $T$（$1 \le T \le 2000$），表示数据组数。
接下来 $T$ 行，每行一个仅含小写英文字母的字符串 $s$（$1 \le |s| \le 500$）。

# 输出描述
输出 $T$ 行，每行一个字符串，表示对应编号升格后的结果。

## 样例1

**输入**

```
1
xyz
```

**输出**

```
XYz
```
