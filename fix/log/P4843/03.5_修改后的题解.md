## 解题思路

本题需要找出最优的特征和阈值，实现一次划分。

核心算法是：枚举每个特征的所有候选阈值，计算按照该阈值划分后的加权混乱度，选择全局最小的划分。

对每个特征 $j$：

先将训练样本按第 $j$ 个特征稳定排序，然后只在相邻不同值之间产生候选阈值。若相邻值为 $a$ 和 $b$，则候选阈值为：

$ \theta = \frac{a + b}{2} $

划分规则为：

左子集：$x_j \le \theta$

右子集：$x_j > \theta$

每个子集的混乱度为：

$ g = 1 - \sum_{c \in \{0,1\}} p_c^2 $

加权混乱度为：

$ G = \frac{n_L}{n}g_L + \frac{n_R}{n}g_R $

为了提高效率，排序后使用前缀统计 $0$ 类和 $1$ 类数量，可以在 $O(1)$ 时间计算每个候选阈值的左右混乱度。

若多个划分的加权混乱度相同，先选择特征下标更小的；若特征也相同，选择阈值更小的。

确定最优划分后，左右子集分别使用多数类作为预测结果；若 $0$ 和 $1$ 数量相同，则预测 $0$。

## 复杂度分析

设训练样本数为 $n$，特征数为 $m$，测试样本数为 $k$。

每个特征需要排序一次，时间复杂度为 $O(n \log n)$，共 $m$ 个特征，因此训练阶段时间复杂度为：

$O(mn \log n)$

预测阶段每个测试样本只需要判断一次阈值，时间复杂度为：

$O(k)$

总时间复杂度为：

$O(mn \log n + k)$

排序和前缀数组需要额外空间，空间复杂度为：

$O(n)$

## 代码实现

### Python

```python
import sys
import json
import numpy as np
import pandas as pd


# 计算一组标签的多数类，若数量相同则返回0
def majority_label(labels):
    cnt0 = np.sum(labels == 0)
    cnt1 = np.sum(labels == 1)
    return 0 if cnt0 >= cnt1 else 1


# 根据0类和1类数量计算混乱度
def calc_gini(cnt0, cnt1):
    total = cnt0 + cnt1
    if total == 0:
        return 0.0
    p0 = cnt0 / total
    p1 = cnt1 / total
    return 1.0 - p0 * p0 - p1 * p1


# 训练最优划分模型，返回最优特征、阈值和左右叶子类别
def train_stump(train_data):
    eps = 1e-7

    # 使用pandas读取数据，前m列为特征，最后一列为标签
    df = pd.DataFrame(train_data)
    X = df.iloc[:, :-1].values.astype(float)
    y = df.iloc[:, -1].values.astype(int)

    n, m = X.shape
    best_g = float("inf")
    best_feature = -1
    best_theta = 0.0

    # 若不存在有效划分，则整体预测多数类
    default_label = majority_label(y)
    best_left_label = default_label
    best_right_label = default_label

    # 枚举每一个特征
    for j in range(m):
        # 稳定排序，保证相同值保持原顺序
        order = np.argsort(X[:, j], kind="mergesort")
        x_sorted = X[order, j]
        y_sorted = y[order]

        # 前缀统计1类数量，便于快速计算左右子集类别数
        prefix_one = np.cumsum(y_sorted)
        total_one = prefix_one[-1]
        total_zero = n - total_one

        # 题目要求包含最小值减eps的候选阈值，但该阈值左子集为空，需要跳过
        _ = x_sorted[0] - eps

        # 只在相邻不同值之间产生候选阈值
        for i in range(n - 1):
            if x_sorted[i] == x_sorted[i + 1]:
                continue

            theta = (x_sorted[i] + x_sorted[i + 1]) / 2.0

            # 左子集为前i+1个样本
            left_n = i + 1
            right_n = n - left_n

            # 若某一侧为空，则跳过该阈值
            if left_n == 0 or right_n == 0:
                continue

            left_one = prefix_one[i]
            left_zero = left_n - left_one
            right_one = total_one - left_one
            right_zero = total_zero - left_zero

            # 计算加权混乱度
            g_left = calc_gini(left_zero, left_one)
            g_right = calc_gini(right_zero, right_one)
            g = left_n / n * g_left + right_n / n * g_right

            # 按混乱度、特征下标、阈值大小进行比较
            better = False
            if g < best_g - 1e-12:
                better = True
            elif abs(g - best_g) <= 1e-12:
                if best_feature == -1 or j < best_feature:
                    better = True
                elif j == best_feature and theta < best_theta:
                    better = True

            if better:
                best_g = g
                best_feature = j
                best_theta = theta

                # 记录左右叶子的预测类别
                left_labels = y_sorted[:left_n]
                right_labels = y_sorted[left_n:]
                best_left_label = majority_label(left_labels)
                best_right_label = majority_label(right_labels)

    return best_feature, best_theta, best_left_label, best_right_label, default_label


# 使用训练好的划分模型预测测试样本
def predict(test_data, model):
    feature, theta, left_label, right_label, default_label = model

    X_test = np.array(test_data, dtype=float)
    ans = []

    # 若没有找到有效划分，则全部预测整体多数类
    if feature == -1:
        return [int(default_label) for _ in range(len(X_test))]

    # 根据阈值判断进入左叶还是右叶
    for row in X_test:
        if row[feature] <= theta:
            ans.append(int(left_label))
        else:
            ans.append(int(right_label))

    return ans


def main():
    # 读取单行JSON输入
    data = json.loads(sys.stdin.readline().strip())

    train_data = data["train"]
    test_data = data["test"]

    # 训练模型并预测
    model = train_stump(train_data)
    ans = predict(test_data, model)

    # 输出JSON数组
    print(json.dumps(ans))


if __name__ == "__main__":
    main()
```
