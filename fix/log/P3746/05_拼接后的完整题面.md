# 题目内容
货仓里依次摆着 $n$ 个货架，第 $i$ 个货架的编号为 $a_i$。一个货架被称为双号货架，当且仅当它的编号是偶数，并且落在闭区间 $[l,r]$ 内。请统计这 $n$ 个货架中双号货架的个数。

约束：货架个数不超过 `100`，区间端点与货架编号均为不超过 `100` 的正整数。

# 输入描述
第一行三个整数 $n$、$l$、$r$，分别表示货架个数与闭区间端点。
第二行 $n$ 个整数 $a_1,a_2,\ldots,a_n$，表示各货架编号。
保证 $1 \le n \le 100$，$1 \le l \le r \le 100$，$1 \le a_i \le 100$。

# 输出描述
输出一个整数，表示双号货架的个数。

## 样例1

**输入**

```
4 1 2
1 3 5 7
```

**输出**

```
0
```

**说明**

四个编号全是奇数，不存在双号货架，答案为 `0`。

## 样例2

**输入**

```
3 2 10
2 4 6
```

**输出**

```
3
```

**说明**

三个编号都是偶数，且都落在 $[2,10]$ 内，答案为 `3`。

## 样例3

**输入**

```
4 1 2
2 4 6 8
```

**输出**

```
1
```

**说明**

按题意模拟计算得到。
