# 题目内容
给定一个由小写字母构成的字符串 $s$，下标从 $1$ 开始。另有一个正整数 $d$。

首先，将所有下标能被 $d$ 整除的字符取出，按字典序升序排列，然后按照这些字符在原串中的位置顺序依次放回（即最小的字符放到第一个 $d$ 的倍数位置，次小的放到第二个 $d$ 的倍数位置，以此类推）。
然后，将剩余下标上的字符（即下标不能被 $d$ 整除的字符）取出，按字典序降序排列，同样按原位置顺序依次放回。

请输出操作后得到的字符串。

字符串的长度不超过 `10^5`，$d$ 的取值范围为 $1 \le d \le 10^5$。

# 输入描述
第一行包含一个整数 $d$。
第二行包含一个由小写字母组成的字符串 $s$。

# 输出描述
输出一行，包含一个字符串，表示操作后的结果。

## 样例1

**输入**

```
3
abcdefghi
```

**输出**

```
hgcedfbai
```

**说明**

首先，下标能被 $d=3$ 整除的位置有 `3`、`6`、`9`，对应字符为 `c`、`f`、`i`。这三个字符取出后按字典序升序排列，结果仍为 `c`、`f`、`i`，放回原位置后保持不变。剩余下标 `1`、`2`、`4`、`5`、`7`、`8` 对应的字符为 `a`、`b`、`d`、`e`、`g`、`h`。将这些字符取出并按字典序降序排列，得到 `h`、`g`、`e`、`d`、`b`、`a`，按原位置顺序依次放回。最终字符串为 `hgcedfbai`。

## 样例2

**输入**

```
1
hello
```

**输出**

```
ehllo
```

**说明**

当 $d=1$ 时，所有下标都能被 `1` 整除。因此将全部字符取出并按字典序升序排列，得到 `e`、`h`、`l`、`l`、`o`，按原位置顺序放回后，字符串变为 `ehllo`。此时没有剩余字符参与降序排列。

## 样例3

**输入**

```
10
abc
```

**输出**

```
cba
```

**说明**

字符串长度为 `3`，而 $d=10$ 大于字符串长度，所有下标 `1`、`2`、`3` 都不能被 `10` 整除。因此整除部分为空，没有字符参与升序排列。剩余字符为 `a`、`b`、`c`，取出后按字典序降序排列为 `c`、`b`、`a`，按原位置顺序放回，得到结果 `cba`。

## 样例4

**输入**

```
2
a
```

**输出**

```
a
```

**说明**

字符串仅包含一个字符 `a`，下标 `1` 不能被 $d=2$ 整除，因此整除部分为空。剩余字符 `a` 取出后降序排列仍为 `a`，放回原位置后结果保持不变，输出仍为 `a`。此样例展示了长度为 `1` 的边界情况。
