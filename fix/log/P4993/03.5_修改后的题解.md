## 解题思路

本题要求在序列中统计满足特定距离关系的“中心石碑”个数。对于每个可能成为中心石碑的位置 $p$（$2 \le p \le m-1$），需要找到左侧参考石碑 $u$ 和右侧参考石碑 $v$：

- 左侧参考石碑 $u$：编号 $1$ 到 $p-1$ 中 **数值最大** 的石碑；若有多个最大值，取 **编号最大** 的那个（即距离 $p$ 最近）。
- 右侧参考石碑 $v$：编号 $p+1$ 到 $m$ 中 **数值最大** 的石碑；若有多个最大值，取 **编号最小** 的那个（即距离 $p$ 最近）。

若 $p - u = v - p$，则 $p$ 是一个中心石碑。最终统计所有满足条件的 $p$ 的个数。

解题步骤：

1. **预处理左侧参考石碑**：从左到右扫描数组，维护当前前缀中的最大值 `mx` 以及该最大值出现的 **最靠右位置** `pos`（即编号最大的最大值位置）。对于当前位置 $i$，它的左侧参考石碑下标就是扫描到 $i$ 之前的 `pos`，记录为 `L[i]`。扫描过程中，若当前石碑数值 $a[i] > mx$，则更新 `mx = a[i], pos = i`；若 $a[i] == mx$，则更新 `pos = i`（因为要取编号最大的）。

2. **预处理右侧参考石碑**：从右到左扫描数组，维护当前后缀中的最大值 `mx` 以及该最大值出现的 **最靠左位置** `pos`（即编号最小的最大值位置）。对于当前位置 $i$，它的右侧参考石碑下标就是扫描到 $i$ 之前的 `pos`，记录为 `R[i]`。扫描过程中，若 $a[i] > mx$，则更新 `mx = a[i], pos = i`；若 $a[i] == mx$，则更新 `pos = i`（因为这里需要编号最小的，从右向左扫时，遇到相等值需要覆盖为更靠左的新位置）。

3. **统计中心石碑**：遍历所有 $p$（$1 \le p \le m-2$，即下标 $p$ 从 $1$ 到 $m-2$），若 $p - L[p] = R[p] - p$，则答案加一。

## 复杂度分析

- **时间复杂度**：每组数据需要两次线性扫描预处理 `L` 和 `R` 数组，再线性遍历统计答案，总体时间复杂度为 $O(m)$。所有测试数据的 $m$ 总和不超过 $2\times 10^5$，因此总时间复杂度为 $O(\sum m)$，完全可接受。
- **空间复杂度**：需要两个长度均为 $m$ 的辅助数组 `L` 和 `R`，空间复杂度 $O(m)$。

## 代码实现

### Python

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    out_lines = []
    for _ in range(q):
        m = int(next(it))
        a = [int(next(it)) for _ in range(m)]
        L = [0] * m
        R = [0] * m
        
        # 从左到右扫描，维护前缀最大值及其最右位置
        mx = -1
        pos = -1
        for i in range(m):
            L[i] = pos
            if a[i] > mx:
                mx = a[i]
                pos = i
            elif a[i] == mx:
                pos = i
        
        # 从右到左扫描，维护后缀最大值及其最左位置
        mx = -1
        pos = -1
        for i in range(m - 1, -1, -1):
            R[i] = pos
            if a[i] > mx:
                mx = a[i]
                pos = i
            elif a[i] == mx:
                pos = i
        
        ans = 0
        for p in range(1, m - 1):
            if p - L[p] == R[p] - p:
                ans += 1
        out_lines.append(str(ans))
    
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int q = Integer.parseInt(br.readLine().trim());
        StringBuilder sb = new StringBuilder();
        
        while (q-- > 0) {
            int m = Integer.parseInt(br.readLine().trim());
            long[] a = new long[m];
            StringTokenizer st = new StringTokenizer(br.readLine());
            for (int i = 0; i < m; i++) {
                a[i] = Long.parseLong(st.nextToken());
            }
            
            int[] L = new int[m];
            int[] R = new int[m];
            
            // 从左到右扫描，维护前缀最大值及其最右位置
            long mx = -1;
            int pos = -1;
            for (int i = 0; i < m; i++) {
                L[i] = pos;
                if (a[i] > mx) {
                    mx = a[i];
                    pos = i;
                } else if (a[i] == mx) {
                    pos = i;
                }
            }
            
            // 从右到左扫描，维护后缀最大值及其最左位置
            mx = -1;
            pos = -1;
            for (int i = m - 1; i >= 0; i--) {
                R[i] = pos;
                if (a[i] > mx) {
                    mx = a[i];
                    pos = i;
                } else if (a[i] == mx) {
                    pos = i;
                }
            }
            
            int ans = 0;
            for (int p = 1; p + 1 < m; p++) {
                if (p - L[p] == R[p] - p) {
                    ans++;
                }
            }
            sb.append(ans).append('\n');
        }
        System.out.print(sb);
    }
}
```
