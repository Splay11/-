# 题目内容

产线温感得到长度为 $m$ 的整型序列 $h_1,h_2,\dots,h_m$。对每个满足 $1<p<m$ 的下标 $p$，在左侧取最大值所在位置中距 $p$ 最近者 $u$，在右侧同理取最近者 $v$；若 $p-u=v-p$，则 $p$ 计入答案。求这样的下标个数。

# 输入描述

每个测试文件均包含多组测试数据。

- 第一行读入一个整型 $q$（$1 \le q \le 10000$），代表数据组数。
- 每组测试数据描述如下：
  1. 第一行读入一个整型 $m$（$3 \le m \le 200000$），表示序列长度。
  2. 第二行读入 $m$ 个整型 $h_1,h_2,\dots,h_m$（$1 \le h_i \le 1000000000$），表示序列读数。
- 保证单个测试文件的 $m$ 之和不超过 $200000$。

# 输出描述

对于每一组测试数据，新起一行，写出一个非负整数表示结果。

## 样例1

**输入**

```
2
3
5 1 5
5
3 1 4 1 5
```

**输出**

```
1
2
```

**说明**

- 第一组：仅 $p=2$，左右最近峰值距离均为 $1$，答案 $1$。
- 第二组：$p=3$ 与 $p=4$ 满足等距，答案 $2$。
