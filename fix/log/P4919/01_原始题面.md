# 题目内容

混频系统给定种子值 $s$（$0 \le s < 2^{31}$）。

在区间 $[p_L,p_R]$ 取参数 $p$，在 $[q_L,q_R]$ 取参数 $q$，得分 $s \oplus p \oplus q$。

「最优配对」指使得分取到全局最大值的 $(p,q)$。求不同最优配对的个数（有序对，$p,q$ 可相同）。

# 输入描述

共有多组独立用例，需逐组求解。

- 首行给出整型 $q$（$1 \le q \le 10^4$），表示用例个数。
- 每组用例三行：
  - 第一行整型 $s$（$0 \le s < 2^{31}$）。
  - 第二行两个整型 $p_L,p_R$（$0 \le p_L \le p_R < 2^{31}$）。
  - 第三行两个整型 $q_L,q_R$（$0 \le q_L \le q_R < 2^{31}$）。

# 输出描述

每组输出一行一个整数，为最优配对个数。

## 样例1

**输入**

```
2
0
0 1
0 1
5
1 7
6 9
```

**输出**

```
2
2
```

**说明**

- 第一组：最大得分为 $1$，对应 $(0,1)$ 与 $(1,0)$ 共 $2$ 种。
- 第二组：最大得分为 $15$，对应 $(2,8)$ 与 $(3,9)$ 共 $2$ 种。
