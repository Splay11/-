## 解题思路

1. **核心观察**  
   定义 $Y = X \oplus \lfloor X/2 \rfloor$。  
   设 $X$ 的二进制表示中第 $i$ 位为 $b_i$（最低位为第 $0$ 位），则 $Y$ 的第 $i$ 位为 $b_i \oplus b_{i+1}$。  
   因此 $Y$ 中为 $1$ 的位恰好对应 $X$ 中相邻位 **不同** 的位置（即 $0$ 与 $1$ 的交界处）。  

2. **段合并与边界提取**  
   输入序列 $c$ 从高位到低位描述了 $X$ 的二进制位流，其中 $c_i$ 表示连续 $c_i$ 个相同的位（奇数为 $1$，偶数为 $0$）。  
   若两个相邻的段奇偶性相同，它们在边界处不会产生 $Y$ 中的 $1$，可以合并。  
   因此我们从低位到高位遍历 $c$，将奇偶性相同的连续元素合并成一个“段”，并记录每个段的长度。  
   具体做法：  
   - 从最后一个 $c_K$ 向前遍历，维护当前段的奇偶性 `curr` 和累计长度 `cnt`。  
   - 若 $c_i \bmod 2 = curr$，则累加 $c_i$；  
   - 否则，将 `cnt` 存入长度数组 $b$，更新 `curr` 为 $c_i \bmod 2$，并令 `cnt = c_i$。  
   - 最后将剩下的 `cnt` 也加入 $b$。  
   这样得到的 $b$ 按 **从低位到高位** 的顺序存储了所有段的长度。  

3. **去掉前导零**  
   若 $c_1$ 是偶数，则 $X$ 的最高位段为 $0$，对 $X$ 的值和 $Y$ 的结果均无贡献。此时应丢弃 $b$ 的最后一个元素（即最高段的长度）。  

4. **计算贡献**  
   设已累计的总位数为 `exponent`（从低位开始的位长）。  
   遍历 $b$ 中的每个长度 $len$：  
   - `exponent += len`  
   - 此时 `exponent` 表示当前段最高位的下一位距离最低位的位置，该位置在 $Y$ 中会产生一个 $1$。其值为 $2^{exponent-1} \bmod M$。  
   累加所有贡献即可得到最终结果。  
   为提高效率，使用快速幂计算 $2^{exponent-1} \bmod M$。  

5. **边界情况**  
   - 若 $b$ 最终为空（$X = 0$），结果直接为 $0$。  
   - $M = 1$ 时任何结果均为 $0$，代码可直接输出 $0$。

## 复杂度分析

- **时间复杂度**：$O(K \log S)$，其中 $S = \sum c_i \le 10^9$。  
  合并段需 $O(K)$ 时间，对每个段调用一次快速幂，幂指数不超过 $S$，每次快速幂 $O(\log S)$。  
- **空间复杂度**：$O(K)$，用于存储合并后的段长度数组。

## 代码实现

### Python

```python
def fast_pow(base, exp, mod):
    """快速幂：返回 (base^exp) % mod"""
    res = 1
    base %= mod
    while exp > 0:
        if exp & 1:
            res = (res * base) % mod
        base = (base * base) % mod
        exp >>= 1
    return res

def solve():
    K, M = map(int, input().split())
    c = list(map(int, input().split()))
    
    # 如果模为1，直接输出0
    if M == 1:
        print(0)
        return

    # 从后向前合并奇偶性相同的段，得到从低位到高位的段长度列表 b
    b = []
    curr = c[-1] % 2           # 最后一个元素的奇偶性
    cnt = 0
    for i in range(K - 1, -1, -1):
        if c[i] % 2 == curr:
            cnt += c[i]
        else:
            b.append(cnt)
            curr = c[i] % 2
            cnt = c[i]
    if cnt != 0:
        b.append(cnt)
    
    # 若最高位段是0（c[0]为偶数），丢弃该段
    if c[0] % 2 == 0:
        b.pop()
    
    ans = 0
    exponent = 0
    for length in b:
        exponent += length
        # exponent 对应了当前边界的位权贡献
        ans = (ans + fast_pow(2, exponent - 1, M)) % M
    
    print(ans % M)

if __name__ == "__main__":
    solve()
```

import java.util.*;

public class Main {
    // 快速幂
    static long fastPow(long base, long exp, long mod) {
        long res = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1)
                res = (res * base) % mod;
            base = (base * base) % mod;
            exp >>= 1;
        }
        return res;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int K = sc.nextInt();
        long M = sc.nextLong();
        int[] c = new int[K];
        for (int i = 0; i < K; i++) {
            c[i] = sc.nextInt();
        }

        if (M == 1) {
            System.out.println(0);
            return;
        }

        List<Long> b = new ArrayList<>();
        int curr = c[K - 1] % 2;
        long cnt = 0;
        for (int i = K - 1; i >= 0; i--) {
            if (c[i] % 2 == curr) {
                cnt += c[i];
            } else {
                b.add(cnt);
                curr = c[i] % 2;
                cnt = c[i];
            }
        }
        if (cnt != 0) {
            b.add(cnt);
        }

        // 舍弃最高位的全0段
        if (c[0] % 2 == 0) {
            b.remove(b.size() - 1);
        }

        long ans = 0;
        long exponent = 0;
        for (long len : b) {
            exponent += len;
            ans = (ans + fastPow(2, exponent - 1, M)) % M;
        }

        System.out.println(ans % M);
    }
}
