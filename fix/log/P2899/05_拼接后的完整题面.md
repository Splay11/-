# 题目内容
在一个由 $n$ 台服务器构成的数据中心中，服务器之间通过网线相连，整体拓扑为一棵树。每台服务器都有自己固定的处理能力，用正整数 $w_i$ 表示。

如果某台服务器发生严重故障并宕机，那么它连同所有与它直接相连的网线都将被从网络中移除。移除后，原本的网络会分裂成若干个子网（即连通分量）。对于每一个子网，定义其“子网处理能力”为该子网中所有存活服务器的处理能力的最大值。数据中心在故障发生后的“总剩余处理能力”定义为所有子网的子网处理能力之和。

现在需要你回答：对于每一台服务器，如果它单独宕机（且只宕机这一台），数据中心的总剩余处理能力会变为多少。注意，每一次询问都是独立的，即故障不会累计发生。

输入保证服务器数量 $n$ 满足 $2 \le n \le 10^5$，处理能力 $w_i$ 满足 $0 \le w_i \le 10^9$。

# 输入描述
第一行包含一个整数 $n$ $(2 \le n \le 10^5)$，表示服务器的数量。
第二行包含 $n$ 个整数 $w_1, w_2, \dots, w_n$ $(0 \le w_i \le 10^9)$，依次表示第 $1$ 到第 $n$ 台服务器的处理能力。
接下来 $n-1$ 行，每行包含两个整数 $u, v$ $(1 \le u, v \le n, u 
e v)$，表示服务器 $u$ 与服务器 $v$ 之间有一条网线。保证所有网线构成一棵树。

# 输出描述
输出共一行，包含 $n$ 个整数，依次表示服务器 $1, 2, \dots, n$ 单独宕机后数据中心的总剩余处理能力，数字之间用空格分隔。

## 样例1

**输入**

```
3
10 20 30
1 2
2 3
```

**输出**

```
30 40 20
```

**说明**

服务器形成链 $1 - 2 - 3$，处理能力分别为 $w_1=10$, $w_2=20$, $w_3=30$。

- 删除服务器 `1`：存活部分为 $\{2,3\}$，子网处理能力为 $\max(20,30)=30$，总剩余处理能力为 `30`。
- 删除服务器 `2`：存活部分分裂为 $\{1\}$ 和 $\{3\}$，子网处理能力分别为 `10` 和 `30`，总和为 `40`。
- 删除服务器 `3`：存活部分为 $\{1,2\}$，子网处理能力为 $\max(10,20)=20$，总剩余处理能力为 `20`。
故输出 `30 40 20`。

## 样例2

**输入**

```
4
5 3 9 6
1 2
1 3
1 4
```

**输出**

```
18 9 6 9
```

**说明**

树结构为星型，中心节点 `1` 连接 `2`、`3`、`4`。处理能力: $w_1=5$, $w_2=3$, $w_3=9$, $w_4=6$。

- 删除中心 `1`：网络分裂为三个单节点分量 $\{2\},\{3\},\{4\}$，各自最大值即自身处理能力 `3`、`9`、`6`，总和 `18`。
- 删除 `2`：剩余连通分量 $\{1,3,4\}$，最大值 $\max(5,9,6)=9$，总和 `9`。
- 删除 `3`：剩余分量 $\{1,2,4\}$，最大值 $\max(5,3,6)=6$，总和 `6`。
- 删除 `4`：剩余分量 $\{1,2,3\}$，最大值 $\max(5,3,9)=9$，总和 `9`。
输出 `18 9 6 9`。

## 样例3

**输入**

```
2
0 0
1 2
```

**输出**

```
0 0
```

**说明**

只有两台服务器且权值均为 `0`，之间有一条网线。

- 删除服务器 `1`：仅剩服务器 `2`，其处理能力为 `0`，总剩余 `0`。
- 删除服务器 `2`：仅剩服务器 `1`，其处理能力为 `0`，总剩余 `0`。
因此输出 `0 0`。
