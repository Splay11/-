## 解题思路

1. **目标**：把序列划分成恰好 $m$ 个连续区间，最大化各区间最大值之和。
2. **关键观察**：每个区间贡献一个最大值。为了让这 $m$ 个最大值尽量大，最优策略是让这 $m$ 个区间分别“占有”序列中最大的 $m$ 个数（它们一定可以被分到 $m$ 个不同的连续段中）。
3. **计算**：将 $a$ 降序排序，取前 $m$ 个数求和即为答案。无需真正构造划分。

## 复杂度分析

- **时间复杂度**：$O(n\log n)$（每组数据）。需要对长度为 $n$ 的序列排序。所有测试的 $n$ 之和不超过 $2\times 10^5$。
- **空间复杂度**：$O(n)$。存储序列及排序用的辅助数组。

## 代码实现

### Python

```python
# -*- coding: utf-8 -*-
import sys

def main():
    input_data = sys.stdin.read().split()
    t = int(input_data[0])
    index = 1
    results = []
    for _ in range(t):
        n = int(input_data[index])
        m = int(input_data[index + 1])
        index += 2
        a = list(map(int, input_data[index:index + n]))
        index += n
        pairs = [(a[i], i) for i in range(n)]
        pairs.sort(key=lambda x: x[0], reverse=True)
        ans = sum(p[0] for p in pairs[:m])
        results.append(ans)
    sys.stdout.write("\n".join(map(str, results)) + "\n")

if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.*;
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine().trim());
        StringBuilder sb = new StringBuilder();
        for (int t = 0; t < T; t++) {
            String[] parts = br.readLine().trim().split("\\s+");
            int n = Integer.parseInt(parts[0]);
            int m = Integer.parseInt(parts[1]);
            String[] numStr = br.readLine().trim().split("\\s+");
            int[] a = new int[n];
            for (int i = 0; i < n; i++) {
                a[i] = Integer.parseInt(numStr[i]);
            }
            Pair[] pairs = new Pair[n];
            for (int i = 0; i < n; i++) {
                pairs[i] = new Pair(a[i], i);
            }
            Arrays.sort(pairs, new Comparator<Pair>() {
                public int compare(Pair p1, Pair p2) {
                    return Integer.compare(p2.value, p1.value);
                }
            });
            long ans = 0;
            for (int i = 0; i < m; i++) {
                ans += pairs[i].value;
            }
            sb.append(ans).append("\n");
        }
        System.out.print(sb.toString());
    }
}

class Pair {
    int value;
    int index;
    public Pair(int value, int index) {
        this.value = value;
        this.index = index;
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
typedef long long ll;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int n, m;
        cin >> n >> m;
        vector<ll> a(n);
        for (int i = 0; i < n; i++) cin >> a[i];
        vector<pair<ll, int>> vp;
        for (int i = 0; i < n; i++) vp.push_back({a[i], i});
        sort(vp.begin(), vp.end(), [](const pair<ll, int>& p1, const pair<ll, int>& p2) {
            return p1.first > p2.first;
        });
        ll ans = 0;
        for (int i = 0; i < m; i++) ans += vp[i].first;
        cout << ans << "\n";
    }
    return 0;
}
```
