# 题目内容
给定长度为 $n$ 的序列 $a$。你需要把它划分成恰好 $m$ 个连续且首尾相接的区间 $[l_1,r_1],[l_2,r_2],\ldots,[l_m,r_m]$，满足对任意 $j$（$1 \le j < m$）都有 $r_j+1=l_{j+1}$，且覆盖整个序列。

记每个区间的峰值为该区间内元素的最大值。请最大化这 $m$ 个峰值之和。

本题有多组测试。数据组数 $T$ 满足 $1 \le T \le 100$。每组中 $1 \le m \le n \le 2 \times 10^5$，序列元素满足 $1 \le a_i \le 10^9$。同一测试文件中所有 $n$ 之和不超过 $2 \times 10^5$。

# 输入描述
第一行包含一个正整数 $T$，表示测试组数。
接下来包含 $T$ 组数据，每组格式如下：
第一行包含两个正整数 $n$ 和 $m$，分别表示序列长度和需要划分的区间个数。
第二行包含 $n$ 个正整数，表示序列 $a$。

# 输出描述
对于每组测试数据，输出一行一个整数，表示 $m$ 个区间峰值之和的最大值。

## 样例1

**输入**

```
2
5 2
1 6 2 5 4
4 2
1 1 1 1
```

**输出**

```
11
2
```

**说明**

第一组：$n=5$，$m=2$，序列最大的两个数是 `6` 与 `5`，峰值之和为 $6+5=11$。
第二组：四个数全为 `1`，取最大的两个相加得 `2`。

## 样例2

**输入**

```
1
3 1
9 1 8
```

**输出**

```
9
```

**说明**

只需划分成 `1` 个区间，峰值就是全序列最大值 `9`。

## 样例3

**输入**

```
1
3 3
2 5 3
```

**输出**

```
10
```

**说明**

划分成 `3` 个区间时每个元素各成一段，峰值之和为 $2+5+3=10$。
