# 题目内容
在古文字研究中，学者发现一些字母存在镜像对应关系。具体来说，将字母水平翻转后，会得到另一个字母。已知以下字母对满足这种镜像关系：

- `n` 与 `u` 互为镜像
- `w` 与 `m` 互为镜像
- `p` 与 `d` 互为镜像
- `q` 与 `b` 互为镜像
- `x` 的镜像是 `x`
- `o` 的镜像是 `o`

如果一个字母不在上述配对中，则认为它没有镜像字母。
给定一个仅由小写字母组成的字符串，定义它的“镜像翻转”为：先将字符串左右翻转，再将每个字母替换为其镜像字母（若某字母没有镜像，则无法进行替换）。如果这个字符串经过镜像翻转后与原字符串完全相同，则称它是一个“镜中词”。

请判断多个字符串是否为镜中词。

约束条件：
- 询问的组数 $T$ 满足 $1 \le T \le 10^5$。
- 所有字符串的总长度 $\sum |s| \le 10^6$。每个字符串仅包含小写英文字母。

# 输入描述
第一行包含一个整数 $T$，表示字符串个数。
接下来 $T$ 行，每行一个由小写字母组成的字符串。

# 输出描述
对于每个字符串，输出一行结果：如果是镜中词，输出 `yes`，否则输出 `no`。

## 样例1

**输入**

```
1
x
```

**输出**

```
yes
```

**说明**

字符串长度为 `1`，只有字符 `x`，其镜像为 `x`。镜像翻转：先将字符串左右翻转，仍为 `x`；再将 `x` 替换为其镜像 `x`，得到 `x`。结果与原字符串相同，因此是镜中词。

## 样例2

**输入**

```
3
nu
mw
abc
```

**输出**

```
yes
yes
no
```

**说明**

对于 `nu`：翻转得 `un`，将 `n` 替换为 `u`、`u` 替换为 `n`，得到 `nu`，与原串相同，为镜中词。
对于 `mw`：同理，翻转替换后得 `mw`，是镜中词。
对于 `abc`：字符 `a`、`b`、`c` 均不在镜像对应表中，无法完成镜像替换，因此不是镜中词。

## 样例3

**输入**

```
2
nwmu
poxd
```

**输出**

```
yes
no
```

**说明**

对于 `nwmu`，长度 `4`。对称位置 $s_0 = n$，$s_3 = u$，`n` 与 `u` 互为镜像；$s_1 = w$，$s_2 = m$，`w` 与 `m` 互为镜像。翻转后为 `umwn`，替换镜像得 `nwmu`，相同，是镜中词。
对于 `poxd`，$s_0 = p$，$s_3 = d$，`p` 的镜像是 `d`，满足；但 $s_1 = o$，$s_2 = x$，`o` 的镜像是 `o`，不等于 `x`，因此不是镜中词。
