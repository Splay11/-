# 题目内容
要把 $n$ 个机房用光缆连成一个连通网络。现有 $m$ 条铺设预案，第 $i$ 条连接机房 $u_i$ 与 $v_i$，收益为 $w_i$（正数表示盈利，负数表示亏损，也可以为 `0`）。

可以从预案中挑选任意若干条（条数不限，至少使网络连通），求最大总收益。保证全部预案已经能使 $n$ 个机房互相可达。

机房数不超过 $10^5$，预案数满足 $n-1 \le m \le 10^6$，$|w_i|$ 不超过 $10^9$。

# 输入描述
第一行包含两个整数 $n$ 和 $m$，分别表示机房数量与预案数量，满足 $1 \le n \le 10^5$，$n-1 \le m \le 10^6$。
接下来 $m$ 行，每行三个整数 $u_i$、$v_i$、$w_i$，表示一条连接 $u_i$ 与 $v_i$ 的预案及其收益，满足 $1 \le u_i,v_i \le n$，$u_i 
eq v_i$，$-10^9 \le w_i \le 10^9$。
保证这 $m$ 条预案构成的无向图连通。

# 输出描述
输出一个整数，表示在保持机房网络连通的前提下能获得的最大总收益。

## 样例1

**输入**

```
5 6
1 2 3
2 3 4
3 4 -2
4 5 1
1 5 -3
2 5 2
```

**输出**

```
10
```

**说明**

先选上全部正收益光缆，收益 $3+4+1+2=`10$，此时五个机房已经连通，亏损预案不必再选，答案为 `10`。

## 样例2

**输入**

```
3 3
1 2 -1
2 3 -5
1 3 -2
```

**输出**

```
-3
```

**说明**

没有正收益。按损失从轻到重连接不同连通块：先选 $-1$，再选 $-2$，第三条会成环舍去。答案为 $-3$。

## 样例3

**输入**

```
2 1
1 2 7
```

**输出**

```
7
```

**说明**

只有一条正收益光缆，必须选用，答案为 `7`。

## 样例4

**输入**

```
4 4
1 2 5
2 3 5
3 4 5
1 4 5
```

**输出**

```
20
```

**说明**

四条全是正收益，全部选用（即使成环也增加收益），答案为 `20`。
