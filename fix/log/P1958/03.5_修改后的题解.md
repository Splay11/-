## 解题思路

本题要求用最少的宝石种类，使得对于任意 $1 \le x \le B$，都能用这些宝石（每种至多 $L$ 次）线性组合出总和 $x$。我们可以采用贪心策略进行构造：

1. **初始状态**  
   为了能够合成能量 $1$，必须拥有一颗能量值为 $1$ 的宝石。  
   此时只用这一种宝石，最多可以用 $L$ 次，能连续覆盖的区间为 $[0, L]$。  
   记当前可连续合成的最大值为 $\text{curMax} = L$，已使用的宝石种类数 $\text{ans} = 1$。

2. **扩展范围**  
   如果 $\text{curMax} < B$，则当前无法合成 $\text{curMax}+1$，必须引入一颗新的宝石。  
   为了让增长最快且不产生空隙，新宝石的能量值应恰好为 $\text{curMax}+1$（最小的无法合成的能量值）。  
   加入这颗宝石后，利用它 $0 \sim L$ 次，结合之前的宝石，可以连续覆盖到：  
   $$\text{curMax} + (\text{curMax} + 1) \times L$$
   因此更新 $\text{curMax} = \text{curMax} + (\text{curMax} + 1) \times L$，同时种类数 $\text{ans}$ 加一。

3. **循环终止**  
   重复步骤 2，直到 $\text{curMax} \ge B$。此时已经能够合成 $1 \sim B$ 中的所有能量值，输出 $\text{ans}$ 即为最少需要的宝石种类数。

4. **正确性说明**  
   每次添加的新宝石能量值都是当前无法合成的最小正整数，这种选择保证了在给定使用次数限制下，每步都能得到最大的连续覆盖长度，从而用最少的种类达到目标。

## 复杂度分析

- **时间复杂度**：每个测试用例的循环次数约为 $O(\log_{L+1} B)$，因为每次 $\text{curMax}$ 都会近似乘以 $L+1$，增长极快。总数据组数 $T \le 10^5$，整体时间复杂度为 $O(T \log B)$，可以在时限内完成。
- **空间复杂度**：仅使用常数个变量，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    t = int(data[0])
    out = []
    idx = 1
    for _ in range(t):
        B = int(data[idx]); L = int(data[idx+1])
        idx += 2
        ans = 1
        cur_max = L          # 只用能量为1的宝石，最大可合成值
        while cur_max < B:
            ans += 1
            cur_max += (cur_max + 1) * L
        out.append(str(ans))
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine().trim());
        StringBuilder sb = new StringBuilder();
        while (T-- > 0) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int B = Integer.parseInt(st.nextToken());
            int L = Integer.parseInt(st.nextToken());
            int ans = 1;
            long cur = L;           // 当前可连续合成的最大值
            while (cur < B) {
                ans++;
                cur += (cur + 1) * L;
            }
            sb.append(ans).append("\n");
        }
        System.out.print(sb);
    }
}
```
