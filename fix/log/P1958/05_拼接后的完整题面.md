# 题目内容
你正在设计一种合成系统，需要用若干种原料宝石来合成魔法石。每种原料宝石具有一个正整数能量值，且所有原料宝石互不相同。合成时，你可以使用每种原料宝石至多 $L$ 次（也可以一次都不用），将这些原料宝石的能量值相加得到总能量。

你需要选定尽可能少的原料宝石种类，使得对于任意整数 $x$（$1 \le x \le B$），都存在一种合法的合成方式，恰好得到总能量 $x$。请你求出最少需要的原料宝石种类数。

约束：数据组数 $T$ 不超过 $10^5$，$B$ 和 $L$ 均不超过 $10^9$。

# 输入描述
第一行包含一个整数 $T$（$1 \le T \le 10^5$），表示数据组数。接下来 $T$ 行，每行包含两个整数 $B$ 和 $L$（$1 \le B, L \le 10^9$），分别表示需要合成的最大总能量和每种原料宝石的最大使用次数。

# 输出描述
对于每组数据，输出一行一个整数，表示最少需要的原料宝石种类数。

## 样例1

**输入**

```
2
5 10
6 2
```

**输出**

```
1
2
```

**说明**

第一组数据：$B = 5$，$L = 10$。
首先选择能量值为 `1` 的宝石，至多使用 `10` 次，可以得到 `0` 到 `10` 之间的所有整数能量，已经完全覆盖了 $1 \le x \le 5$ 的范围，因此只需要 `1` 种原料宝石。

第二组数据：$B = 6$，$L = 2$。
首先选择宝石 `1`，使用上限 `2` 次，可以覆盖能量 `0` 到 `2`，此时无法合成能量 `3`。加入一种能量值为 $2+1=3$ 的新宝石，结合原来的宝石 `1`，可覆盖的范围扩展到 $2 + (2+1) \times 2 = 8$（即 `0` 到 `8`），已经包含 $6$，因此需要 `2` 种原料宝石。

## 样例2

**输入**

```
3
1 1
8 1
10 2
```

**输出**

```
1
4
3
```

**说明**

第一组数据：$B = 1$，$L = 1$。
选择宝石 `1`，至多使用 `1` 次，可以合成能量 `1`，已经满足要求，需要 `1` 种。

第二组数据：$B = 8$，$L = 1$。每种宝石至多使用 `1` 次。
初始选择宝石 `1`，可覆盖 `0`～`1`（$< 8$）；加入能量为 $1+1=2$ 的宝石，可覆盖 `0`～$1+(1+1)\times1=3$（$< 8$）；加入能量为 $3+1=4$ 的宝石，可覆盖 `0`～$3+(3+1)\times1=7$（$< 8$）；加入能量为 $7+1=8$ 的宝石，可覆盖 `0`～$7+(7+1)\times1=15$，达到 $8$。共需要 `4` 种宝石。

第三组数据：$B = 10$，$L = 2$。
初始宝石 `1` 覆盖 `0`～`2`（$< 10$）；加入能量为 $2+1=3$ 的宝石后，覆盖 `0`～$2+(2+1)\times2=8$（$< 10$）；再加入能量为 $8+1=9$ 的宝石，覆盖 `0`～$8+(8+1)\times2=26$，达到 $10$。共需要 `3` 种宝石。

## 样例3

**输入**

```
1
100 3
```

**输出**

```
4
```

**说明**

$B = 100$，$L = 3$。
初始选择宝石 `1`，最多使用 `3` 次，当前最大可合成能量为 $3$（$< 100$）。
第一次扩展：加入能量为 $3+1=4$ 的宝石，新的最大能量变为 $3 + (3+1) \times 3 = 15$（$< 100$）。
第二次扩展：加入能量为 $15+1=16$ 的宝石，最大能量变为 $15 + (15+1) \times 3 = 63$（$< 100$）。
第三次扩展：加入能量为 $63+1=64$ 的宝石，最大能量变为 $63 + (63+1) \times 3 = 255$（$\ge 100$）。
此时已覆盖 $100$，共使用了 `4` 种原料宝石。
