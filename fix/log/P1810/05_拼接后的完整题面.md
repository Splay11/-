# 题目内容
在一个气象研究所内，有一片 $n \times n$ 的网格，每个网格上装有一个风标。风标只能指向四个方向之一：`^`（北风）、`v`（南风）、`>`（东风）、`<`（西风）。

一台自动小车从网格中的某个格子出发。每当小车离开一个格子时，该格子上的风标会立即反转方向：`^` 变为 `v`，`v` 变为 `^`，`>` 变为 `<`，`<` 变为 `>`。小车按照脚下格子的风标所指方向移动到相邻的格子；若风标指向网格之外，则小车将在下一步离开网格。

你需要计算小车从初始位置出发，需要多少步才能离开整个网格。

如果步数超过 $10^6$ 仍未离开，则认为小车陷入循环，永远无法走出，此时输出 `-1`。

**约束条件：**
- 网格边长 $n$ 为整数，满足 $2 \le n \le 99$。
- 初始位置的行号和列号均为 $1$ 到 $n$ 之间的整数。
- 网格中只包含字符 `^`、`v`、`>`、`<`。

# 输入描述
第一行包含一个整数 $n$，表示网格的行数和列数。
接下来 $n$ 行，每行包含一个长度为 $n$ 的字符串，仅由字符 `^`、`v`、`>`、`<` 构成，依次表示网格中对应位置风标的初始方向。
最后一行包含两个整数 $r$ 和 $c$，用空格分隔，分别表示小车初始所在的行编号和列编号（行列均从 $1$ 开始）。

# 输出描述
输出一个整数，表示小车离开网格所需要的步数。若在 $10^6$ 步内未能离开，则输出 `-1`。

## 样例1

**输入**

```
2
<>
^v
1 1
```

**输出**

```
1
```

**说明**

初始位于 $(1,1)$，方向为 `<`（西），指向网格之外。小车直接离开该格子，同时该格子风标反转（变为 `>`）。这一步即移出网格，需要 `1` 步。

## 样例2

**输入**

```
3
vvv
vvv
vvv
2 2
```

**输出**

```
2
```

**说明**

网格中所有风标均指 `v`（南）。小车从 $(2,2)$ 出发：
第 `1` 步：从 $(2,2)$ 向南移动至 $(3,2)$，并将 $(2,2)$ 反转为 `^`。
第 `2` 步：从 $(3,2)$ 继续向南移出网格，同时 $(3,2)$ 反转为 `^`。
总共 `2` 步离开。

## 样例3

**输入**

```
3
^v<
>^<
vv>
2 2
```

**输出**

```
4
```

**说明**

初始位于 $(2,2)$，方向为 `^`（北）。
第 `1` 步：向上移动至 $(1,2)$，并将 $(2,2)$ 反转为 `v`。
第 `2` 步：在 $(1,2)$ 方向为 `v`（南），向下移动回 $(2,2)$，并将 $(1,2)$ 反转为 `^`；此时 $(2,2)$ 已变为 `v`。
第 `3` 步：从 $(2,2)$ 向南移动至 $(3,2)$，并将 $(2,2)$ 反转为 `^`。
第 `4` 步：在 $(3,2)$ 方向为 `v`，向南移出网格，同时 $(3,2)$ 反转为 `^`。
总共 `4` 步离开。
