# 题目内容
小蓝正在分析一段由数字组成的密钥。对于一个密钥串，她定义其“有效片段”为：该串的某个连续子串，满足以下两个条件：
- 子串的最后一个数字是偶数（即属于 $\{0,2,4,6,8\}$）；
- 子串不含有前导零，但单个字符 `0` 是允许的。

密钥串的“可靠度”等于它的所有有效片段的个数。现在给定一个长度为 $n$ 的密钥串 $s$，小蓝想知道，$s$ 的所有连续子串的可靠度之和是多少。由于答案可能很大，请输出对 $10^9+7$ 取模后的结果。

字符串的长度 $n$ 不超过 $2 \times 10^5$，且字符串仅由数字字符 `0` 到 `9` 组成。

# 输入描述
第一行包含一个整数 $n$ ($1 \le n \le 2 \times 10^5$)，表示密钥串的长度。
第二行包含一个长度为 $n$ 的字符串，由 `0` 到 `9` 的数字字符组成。

# 输出描述
输出一个整数，表示 $s$ 的所有子串可靠度之和对 $10^9+7$ 取模后的结果。

## 样例1

**输入**

```
4
1203
```

**输出**

```
21
```

**说明**

密钥串为 `1203`，长度 $n=4$。有效片段需要满足最后一个数字为偶数且无前导零（单个 `0` 允许）。偶数数字出现在位置 `2`（数字 `2`）和位置 `3`（数字 `0`）。

对于结束位置 $r=2$：可选的起始位置 $l$ 有 `1` 和 `2`，对应子串 `12` 和 `2`。每个有效片段对总可靠度的贡献为 $l \times (n - r + 1)$。此时 $n - r + 1 = 3$，贡献分别为 $1 \times 3 = 3$，$2 \times 3 = 6$。

对于 $r=3$：由于子串 `120`、`20`、`0` 均无前导零，可选 $l=1,2,3$。此时 $n - r + 1 = 2$，贡献为 $1 \times 2 = 2$，$2 \times 2 = 4$，$3 \times 2 = 6$。

总和为 $3+6+2+4+6=21$。

## 样例2

**输入**

```
1
0
```

**输出**

```
1
```

**说明**

单字符密钥串 `0`。它的唯一连续子串就是自身 `0`，该子串的最后一个数字是偶数且是单个 `0`，无前导零，因此是一个有效片段。可靠度为 `1`，所有子串可靠度之和也为 `1`。

## 样例3

**输入**

```
5
24682
```

**输出**

```
70
```

**说明**

密钥串为 `24682`，所有数字均为偶数且没有 `0`，因此该串的任意连续子串都是有效片段。对于所有满足 $1 \le l \le r \le n$ 的区间 $[l, r]$，其作为有效片段对总和的贡献为 $l \times (n - r + 1)$。

计算总和：$\sum_{l=1}^{5} l \times \sum_{r=l}^{5} (6 - r) = 1 \times 15 + 2 \times 20 + 3 \times 18 + 4 \times 12 + 5 \times 5 = 70$。

## 样例4

**输入**

```
3
102
```

**输出**

```
10
```

**说明**

密钥串为 `102`，长度 $n=3$。偶数数字位于位置 `2`（`0`）和位置 `3`（`2`）。

对于 $r=2$：子串 `10`（$l=1$）和 `0`（$l=2$）均无前导零，贡献为 $1 \times (3-2+1)=2$ 和 $2 \times 2=4$。

对于 $r=3$：子串 `102`（$l=1$）和 `2`（$l=3$）有效，但 `02`（$l=2$）含有前导零，因此无效。贡献为 $1 \times 1=1$ 和 $3 \times 1=3$。

总和为 $2+4+1+3=10$。
