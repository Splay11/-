# 题目内容
小明收集了 $W$ 块单位正方形地砖。他想用这些地砖拼成一个尽可能大的实心正方形（边长为整数），拼装时不能切割地砖，也不要求用完所有地砖。请你帮他计算这个正方形的最大边长。

换句话说，你需要求出满足 $k^2 \le W$ 的最大整数 $k$。

约束条件：整数 $W$ 的取值范围为 $0 \le W \le 2^{31}-1$（即不超过 `2147483647`）。

# 输入描述
输入仅有一行，包含一个整数 $W$，表示单位正方形地砖的总数量。

# 输出描述
输出一个整数，表示能拼成的实心正方形的最大边长。

## 样例1

**输入**

```
0
```

**输出**

```
0
```

**说明**

小明有 `0` 块地砖，无法拼出任何边长为正整数的正方形，因此最大边长只能是 `0`。

## 样例2

**输入**

```
10
```

**输出**

```
3
```

**说明**

小明有 `10` 块地砖。尝试边长 $k=3$：$3^2 = 9 \le 10$；边长 $k=4$：$4^2 = 16 > 10$。因此满足 $k^2 \le 10$ 的最大整数 $k$ 为 `3`，最多可以拼出边长为 `3` 的正方形。

## 样例3

**输入**

```
100
```

**输出**

```
10
```

**说明**

小明有 `100` 块地砖。因为 $10^2 = 100$，刚好用完所有地砖拼成一个边长为 `10` 的正方形。这也是满足 $k^2 \le 100$ 的最大整数。

## 样例4

**输入**

```
2147483647
```

**输出**

```
46340
```

**说明**

小明有 `2147483647` 块地砖，这是题目允许的最大数量（$2^{31}-1$）。计算 $\lfloor\sqrt{2147483647}\rfloor = 46340$：因为 $46340^2 = 2147395600 \le 2147483647$，而 $46341^2 = 2147488281 > 2147483647$。故最大边长为 `46340`。
