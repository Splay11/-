## 解题思路

第 $i$ 个任务每次在队首获得 $m$ 点额度，累计达到 $w_i$ 才会离开。它需要的发放次数为

$$\left\lceil\frac{w_i}{m}\right\rceil=\left\lfloor\frac{w_i+m-1}{m}\right\rfloor$$

模拟队列可以发现：次数更少的任务一定更早离开；次数相同则先进入（下标更小）的更早离开。因此只需按（次数，下标）升序排序。

输入中 $n$ 与 $m$ 可能分行，应用空白分隔一次性读入全部整数，与 `cin` 行为一致。

## 复杂度分析

时间复杂度 $O(n\log n)$，空间复杂度 $O(n)$。

## 代码实现

### Python

```python
import sys

data = list(map(int, sys.stdin.read().split()))
n, m = data[0], data[1]
a = data[2:2 + n]
ans = [((x + m - 1) // m, i + 1) for i, x in enumerate(a)]
ans.sort()
print(*[idx for _, idx in ans])
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner cin = new Scanner(System.in);
        int n = cin.nextInt();
        long m = cin.nextLong();
        long[][] ans = new long[n][2];
        for (int i = 0; i < n; i++) {
            long x = cin.nextLong();
            ans[i][0] = (x + m - 1) / m;
            ans[i][1] = i + 1;
        }
        Arrays.sort(ans, (p, q) -> p[0] != q[0] ? Long.compare(p[0], q[0]) : Long.compare(p[1], q[1]));
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(' ');
            sb.append(ans[i][1]);
        }
        System.out.println(sb);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long m;
    cin >> n >> m;
    vector<pair<long long, int>> ans;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        ans.push_back({(x + m - 1) / m, i + 1});
    }
    sort(ans.begin(), ans.end());
    for (int i = 0; i < (int)ans.size(); i++) {
        if (i) cout << ' ';
        cout << ans[i].second;
    }
    cout << '\n';
    return 0;
}
```
