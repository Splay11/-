# 题目内容
有 $n$ 个任务排成一队领取额度。第 $i$ 个任务需要的额度为 $w_i$。每次总是给当前队首发放 $m$ 点额度：若累计已得额度仍小于 $w_i$，该任务立刻排到队尾继续等待；否则它立即离开队伍。

所有任务最终都会离开。请输出它们离开队伍的先后顺序（任务编号从 `1` 到 $n$，按初始排队位置编号）。

约束条件：
- 任务个数 $n$ 满足 $1 \le n \le 10^5$；
- 每次发放额度 $m$ 满足 $1 \le m \le 10^9$；
- 每个任务所需额度满足 $1 \le w_i \le 10^9$。

# 输入描述
第一行包含一个整数 $n$（$1 \le n \le 10^5$），表示任务个数。
第二行包含一个整数 $m$（$1 \le m \le 10^9$），表示每次给队首发放的额度。
第三行包含 $n$ 个正整数 $w_1, w_2, \ldots, w_n$（$1 \le w_i \le 10^9$），表示每个任务需要的额度。

# 输出描述
输出一行 $n$ 个整数，表示任务离开队伍的先后编号。

## 样例1

**输入**

```
5
2
1 10 9 4 7
```

**输出**

```
1 4 5 2 3
```

**说明**

每次发放额度为 $m=2$，各任务需要的次数为 $\lceil w_i/2 \rceil$，即 $1,5,5,2,4$。

按次数升序、次数相同按下标升序排列，离队编号为 `1`（`1` 次）、`4`（`2` 次）、`5`（`4` 次）、`2` 与 `3`（均为 `5` 次且 `2` 在 `3` 前）。

## 样例2

**输入**

```
1
5
3
```

**输出**

```
1
```

**说明**

只有一个任务，第一次发放 `5` 已不少于所需 `3`，立即离开，顺序为 `1`。

## 样例3

**输入**

```
3
10
10 10 10
```

**输出**

```
1 2 3
```

**说明**

三个任务所需次数都是 `1`，同一轮按初始顺序离队，编号为 `1 2 3`。
