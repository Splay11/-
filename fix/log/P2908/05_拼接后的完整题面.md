# 题目内容
你获得了一个长度为 $n$ 的整数序列 $x_1, x_2, \dots, x_n$。你可以进行任意次调整操作：每次选择一个连续子段 $[l, r]$（$1 \le l \le r \le n$），将该子段内的元素按任意顺序重排。这次调整的消耗等于该子段所有元素之和。

你需要分别求出：
- 通过若干次调整，将序列变为非降序的最小总消耗；
- 将序列变为非增序的最小总消耗。

约束：序列长度 $n$ 不超过 $2 \times 10^5$，所有元素 $x_i$ 的值在 $1$ 到 $10^9$ 之间。

# 输入描述
第一行包含一个整数 $n$，表示序列长度。
第二行包含 $n$ 个整数 $x_1, x_2, \dots, x_n$，表示初始序列。

# 输出描述
输出一行两个整数，分别表示变为非降序和变为非增序的最小总消耗。

## 样例1

**输入**

```
1
5
```

**输出**

```
0 0
```

**说明**

序列长度为 `1`，元素为 $5$。由于只有一个元素，该序列已经同时满足非降序和非增序的要求，不需要任何调整操作。因此变为非降序和变为非增序的最小总消耗均为 $0$。

## 样例2

**输入**

```
3
1 2 3
```

**输出**

```
0 6
```

**说明**

给定序列 $x = [1, 2, 3]$，所有元素之和为 `6`。变为非降序：序列本身已经是不降序，无需操作，消耗为 `0`。变为非增序：目标序列为 $[3, 2, 1]$。在扫描过程中，没有位置同时满足“前缀多重集合与目标一致”且“元素值与目标相等”，因此没有任何元素可以保留在原位，必须至少对整个序列进行一次重排，最小消耗为总和 `6`。因此输出 `0` `6`。

## 样例3

**输入**

```
4
1 3 2 3
```

**输出**

```
5 9
```

**说明**

序列 $x = [1, 3, 2, 3]$，元素总和为 `9`。变为非降序：目标序列为 $[1, 2, 3, 3]$。遍历序列，在位置 `1`（元素 `1`）和位置 `4`（元素 `3`）满足保留条件，保留和为 $1 + 3 = 4$。因此最小消耗为 $9 - 4 = 5$。变为非增序：目标序列为 $[3, 3, 2, 1]$，没有位置可以保留，保留和为 `0`，消耗为 `9`。故输出 `5` `9`。

## 样例4

**输入**

```
4
2 1 4 3
```

**输出**

```
10 10
```

**说明**

序列 $x = [2, 1, 4, 3]$，总和为 `10`。变为非降序：目标序列 $[1, 2, 3, 4]$。没有任何元素满足保留条件，因此不能零代价保留任何元素。一种最优方案：分别对子段 $[2, 1]$ 和 $[4, 3]$ 进行重排，消耗分别为 `3` 和 `7`，总代价 `10`；也可直接操作整个序列，代价仍为 `10`。变为非增序：类似地，最小消耗也是 `10`。故输出 `10` `10`。
