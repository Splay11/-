# 题目内容
园艺师计划在一个矩形花坛中种植一批不同品种的花卉。花坛被划分为 $n$ 行 $m$ 列的方格，每个方格要么是空地（用 `0` 表示），要么已经摆放了石块（用 `1` 表示）。现在需要为同一品种的花卉选择种植位置，但由于它们需要相同的养护条件，因此必须满足：

- 所有花卉必须种植在空地上；
- 全部 $k$ 株花卉必须位于同一行，并且占据连续的 $k$ 个方格；
- 对于每一株花卉所在的方格，其上下左右四个相邻方格（如果存在的话）都不能是石块。换句话说，相邻方格只能是边界外、空地或者同样种有花卉的方格。

由于不同花卉品种彼此不同，即使选择的种植方格集合相同，但花卉的具体排列顺序不同也会被视为不同的种植方案。现在给出花坛的现状以及多次询问，每次询问给定一个整数 $k$，表示需要种植的花卉株数。请你计算每次询问对应的合法种植方案总数。如果没有任何可行方案，则答案为 `0`。由于答案可能很大，请将结果对 $998244353$ 取模后输出。

约束条件：行数 $n$、列数 $m$ 和询问次数 $q$ 均不超过 $100$。方格中的数字仅为 `0` 或 `1`。每次询问的 $k$ 满足 $1 \le k \le n \times m$。

# 输入描述
第一行包含三个整数 $n, m, q$，分别表示花坛的行数、列数以及询问次数。
接下来 $n$ 行，每行包含 $m$ 个整数（`0` 或 `1`），描述花坛中方格的状态，`0` 代表空地，`1` 代表石块。
第 $n+2$ 行包含 $q$ 个整数 $k_1, k_2, \dots, k_q$，依次表示每次询问需要种植的花卉株数。

# 输出描述
输出一行，包含 $q$ 个整数，相邻整数之间用空格分隔，第 $i$ 个整数表示第 $i$ 次询问的合法方案数对 $998244353$ 取模后的结果。

## 样例1

**输入**

```
2 3 3
0 0 0
0 0 0
1 2 3
```

**输出**

```
6 8 12
```

**说明**

花坛为 $2$ 行 $3$ 列，全部为 `0`（空地），没有任何石块。

对于 $k=1$：每行有 $3-1+1=3$ 个长度为 $1$ 的连续段，共有 $2 \times 3 = 6$ 个种植位置，每个位置可排列 $1! = 1$ 种顺序，总方案数为 $6$。

对于 $k=2$：每行有 $2$ 个长度为 $2$ 的连续段，共 $2 \times 2 = 4$ 个位置，乘以 $2! = 2$，总方案数为 $8$。

对于 $k=3$：每行有 $1$ 个长度为 $3$ 的连续段，共 $2 \times 1 = 2$ 个位置，乘以 $3! = 6$，总方案数为 $12$。

答案均远小于模数 $998244353$，取模后不变。

## 样例2

**输入**

```
3 5 3
0 0 1 0 0
1 0 0 0 1
0 0 0 0 0
1 2 3
```

**输出**

```
3 4 6
```

**说明**

花坛中存在石块 `1`，必须考虑相邻方格不能是石块的限制。

首先找出所有能够种植的“安全格子”：自身为 `0` 且上下左右四个邻居（若存在）均不为 `1`。
- 第 $1$ 行：`(1,0)` 的下方是 `1`，不合法；`(1,1)` 右方是 `1`，不合法；`(1,3)` 左方是 `1`，不合法；`(1,4)` 下方是 `1`，不合法。全行无安全格子。
- 第 $2$ 行：`(2,1)` 左方 `1`；`(2,2)` 上方 `1`；`(2,3)` 右方 `1`。全行无安全格子。
- 第 $3$ 行：`(3,0)` 上方 `1`；`(3,4)` 上方 `1`。只有 `(3,1)`、`(3,2)`、`(3,3)` 三个安全格子，且它们连续相邻。

对于 $k=1$：直接选取单个安全格子，共有 $3$ 个位置，$1! = 1$，方案数为 $3$。
对于 $k=2$：需在安全格子连续段中选取长度为 $2$ 的子段。段 `(3,1)~(3,3)` 可选出 `(3,1)~(3,2)` 和 `(3,2)~(3,3)` 两段，且左右相邻空地均非石块，合法。共 $2$ 个位置，乘以 $2! = 2$，方案数为 $4$。
对于 $k=3$：整个连续段 `(3,1)~(3,3)` 恰好长度为 $3$，左右邻地均为空地，合法。$1$ 个位置乘以 $3! = 6$，方案数为 $6$。

## 样例3

**输入**

```
1 5 4
0 1 0 0 0
1 2 3 4
```

**输出**

```
2 2 0 0
```

**说明**

单行花坛，石块 `1` 位于第 $2$ 列，切断了空地区域。

安全格子要求自身为 `0` 且邻居不含 `1`。
- `(1,1)`：右侧邻 `1`，不合法。
- `(1,2)`：为石块，不可用。
- `(1,3)`：左侧邻 `1`，不合法。
- `(1,4)`：左侧 `(1,3)` 为 `0`，右侧 `(1,5)` 为 `0`，上下无石块，合法。
- `(1,5)`：左侧 `(1,4)` 为 `0`，右侧边界，合法。

因此安全格子只有 `(1,4)` 与 `(1,5)`，形成长度为 $2$ 的连续段。

$k=1$：可选取 $2$ 个不同位置，$1! = 1$，方案数为 $2$。
$k=2$：选取连续段 `(1,4)~(1,5)`，$1$ 个位置，乘以 $2! = 2$，方案数为 $2$。
$k=3$ 及 $k=4$：最长连续安全段长度仅为 $2$，没有合法种植位置，方案数为 $0$。
