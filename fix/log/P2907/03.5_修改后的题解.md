## 解题思路

本题要求计算在给定的 $n\times m$ 花坛中，为同一品种的 $k$ 株可区分花卉选择连续种植位置的方案总数。由于花卉可区分，最终方案数需要在位置选择数的基础上乘以 $k!$。

核心思路如下：

1. **定义安全格点**  
   对于花坛中的每个方格 $(i,j)$，我们称其为一个**安全格点**当且仅当：
   - 该方格为**空地**（`a[i][j] == 0`）；
   - 其上方相邻方格（若存在）不是石块，下方相邻方格（若存在）也不是石块。  
   换句话说，安全格点是那些自身为空，且上下邻居（如果有）不为石块的位置。我们用二维数组 `safe[i][j]` 标记，若安全则值为 $1$，否则为 $0$。

2. **按行统计连续安全区间**  
   花卉必须种植在同一行且占据连续的 $k$ 个方格，并且每个花卉所在方格的相邻位置（上下左右）不能有石块。  
   对于每一行 $i$：
   - 构建前缀和数组 `pref`，其中 `pref[j+1]` 表示该行前 $j$ 个方格中安全格点的个数。
   - 枚举可能的长度 $k$（$1\le k\le \min(m, \text{maxk})$），以及起始列 $j$（$0\le j\le m-k$）：
     - 若区间 $[j, j+k-1]$ 全部是安全格点，即 `pref[j+k] - pref[j] == k`；
     - 同时检查**水平相邻**位置：左侧邻居 `a[i][j-1]`（若 $j>0$）不能是石块，右侧邻居 `a[i][j+k]`（若 $j+k<m$）也不能是石块。
     - 满足上述条件时，记录一个合法的连续种植段。  
   对所有行累加，得到 `cnt[k]` 表示长度为 $k$ 的合法连续段的总数。

3. **加入花卉排列方案**  
   对于任意一个选定的连续 $k$ 个安全格点，$k$ 株可区分的花卉共有 $k!$ 种不同的排列方式。因此，询问 $k$ 的最终答案为 $\text{cnt}[k] \times k! \bmod 998244353$。

4. **处理询问**  
   预处理阶乘数组到最大询问值 `maxk`，然后对每个询问 $k$，若 $k > m$ 则答案直接为 $0$；否则输出 $(\text{cnt}[k] \times k!) \bmod 998244353$。

## 复杂度分析

- 预处理安全数组：需要遍历整个 $n\times m$ 矩阵，时间复杂度 $O(nm)$。
- 每行求前缀和 $O(m)$，对每个 $k$ 滑动窗口累加，最坏 $O(m\cdot\min(m,\text{maxk}))$；共 $n$ 行，总时间复杂度 $O(nm\cdot\min(m,\text{maxk}))$。
- 预处理阶乘需要 $O(\text{maxk})$ 时间。
- 空间复杂度：存储矩阵和安全数组等，共 $O(nm)$，阶乘数组 $O(\text{maxk})$，均在约束 $(n,m,q\le 100)$ 下完全可接受。

## 代码实现

### Python

```python
import sys
input = sys.stdin.readline
MOD = 998244353

def main():
    n, m, q = map(int, input().split())
    # 读入花坛矩阵（每行 m 个由空格分隔的整数）
    a = []
    for _ in range(n):
        row = list(map(int, input().split()))
        a.append(row)
    # 读入所有询问 k 值
    qs = list(map(int, input().split()))
    maxk = max(qs)

    # 预处理阶乘
    fac = [1] * (maxk + 1)
    for i in range(1, maxk + 1):
        fac[i] = fac[i-1] * i % MOD

    # 构造安全格点矩阵 safe
    safe = [[0] * m for _ in range(n)]
    for i in range(n):
        for j in range(m):
            if a[i][j] == 0:
                ok = True
                if i > 0 and a[i-1][j] == 1:
                    ok = False
                if i < n - 1 and a[i+1][j] == 1:
                    ok = False
                safe[i][j] = 1 if ok else 0

    # 最大可能的 k 值受限于列数
    maxk_seg = min(m, maxk)
    cnt = [0] * (maxk_seg + 1)

    # 逐行统计连续安全区间
    for i in range(n):
        pref = [0] * (m + 1)
        for j in range(m):
            pref[j+1] = pref[j] + safe[i][j]

        for k in range(1, maxk_seg + 1):
            tot = 0
            for j in range(m - k + 1):
                if pref[j+k] - pref[j] == k:         # 区间内全为安全格点
                    if j > 0 and a[i][j-1] == 1:     # 左侧邻居不能是石块
                        continue
                    if j + k < m and a[i][j+k] == 1: # 右侧邻居不能是石块
                        continue
                    tot += 1
            cnt[k] += tot

    # 输出每次询问的答案
    res = []
    for k in qs:
        if k <= maxk_seg:
            ans = cnt[k] * fac[k] % MOD
        else:
            ans = 0
        res.append(str(ans))
    print(' '.join(res))

if __name__ == '__main__':
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    static final int MOD = 998244353;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());
        int q = Integer.parseInt(st.nextToken());

        int[][] a = new int[n][m];
        // 读入花坛矩阵（每行 m 个空格分隔的整数）
        for (int i = 0; i < n; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < m; j++) {
                a[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        // 读入询问列表
        int[] qs = new int[q];
        st = new StringTokenizer(br.readLine());
        int maxk = 0;
        for (int i = 0; i < q; i++) {
            qs[i] = Integer.parseInt(st.nextToken());
            if (qs[i] > maxk) maxk = qs[i];
        }

        // 预处理阶乘
        long[] fac = new long[maxk + 1];
        fac[0] = 1;
        for (int i = 1; i <= maxk; i++) {
            fac[i] = fac[i-1] * i % MOD;
        }

        // 构造安全格点矩阵
        int[][] safe = new int[n][m];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (a[i][j] == 0) {
                    boolean ok = true;
                    if (i > 0 && a[i-1][j] == 1) ok = false;
                    if (i < n-1 && a[i+1][j] == 1) ok = false;
                    safe[i][j] = ok ? 1 : 0;
                }
            }
        }

        int maxkSeg = Math.min(m, maxk);
        long[] cnt = new long[maxkSeg + 1];

        // 逐行统计连续安全区间
        for (int i = 0; i < n; i++) {
            int[] pref = new int[m + 1];
            for (int j = 0; j < m; j++) {
                pref[j+1] = pref[j] + safe[i][j];
            }
            for (int k = 1; k <= maxkSeg; k++) {
                int tot = 0;
                for (int j = 0; j + k <= m; j++) {
                    if (pref[j+k] - pref[j] == k) {
                        if (j > 0 && a[i][j-1] == 1) continue;
                        if (j + k < m && a[i][j+k] == 1) continue;
                        tot++;
                    }
                }
                cnt[k] += tot;
            }
        }

        // 输出答案
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < q; i++) {
            int k = qs[i];
            long ans = (k >= 1 && k <= maxkSeg) ? (cnt[k] % MOD) * fac[k] % MOD : 0;
            sb.append(ans);
            if (i < q - 1) sb.append(' ');
        }
        System.out.println(sb);
    }
}
```
