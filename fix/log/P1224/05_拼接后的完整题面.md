# 题目内容
一棵 $n$ 个站点的通信树，每个站点标记为 `0` 或 `1`。沿一条至少包含一条边的路径，把沿途标记从起点到终点看成一个二进制数（起点为最高位）。需要统计有多少条有向路径，其数值落在闭区间 $[l,r]$ 内，用于评估链路编码覆盖范围。

单独一个站点不构成合法路径。

约束：$1 \le n \le 1000$，$1 \le l \le r \le 100000000000000$。

# 输入描述
第一行三个正整数 $n$ $l$ $r$。
第二行一个长度为 $n$ 的 `01` 串，第 $i$ 个字符是节点 $i$ 的权值。
接下来 $n-1$ 行，每行两个正整数 $u$ $v$ 表示树边。

# 输出描述
输出一个整数，表示合法有向路径的条数。

**输入**

```
3 1 10

2 3
```

**输出**

