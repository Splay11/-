## 解题思路

本题要求利用正整数 $x$ 的所有十进制数位（卡片）重新排列，拼接成无前导零的整数，并统计其中能被 $k$ 整除的不同整数的个数。由于 $x$ 最多有 $15$ 个数位，直接生成所有排列的时间复杂度过高（阶乘级），需要使用**状态压缩动态规划**进行优化。

把 $x$ 的每一位看作一张独立的卡片，用二进制整数 $i$ 表示已经使用了哪些位置的卡片（$1$ 表示已使用）。定义：

$$
dp[i][j] = \text{使用集合 } i \text{ 中的卡片按某种顺序拼接，组成的整数模 } k \text{ 等于 } j \text{ 的方案数。}
$$

拼接时不允许前导零，因此初始状态中，若只选了一张卡片且该卡片上的数字不为 `'0'`，则对应状态为 $1$，其余状态为 $0$。转移时，枚举当前状态 $i$，再枚举一个尚未使用的位置 $idx$，将对应的数位 $d$ 追加到当前整数的末尾，更新余数：

$$
dp[i \mid (1 << idx)][(j \times 10 + d) \bmod k] \mathrel{+}= dp[i][j]
$$

最终，所有卡片全部使用对应的状态为 $(1 << n) - 1$，其中 $n$ 为 $x$ 的十进制长度。答案的初步结果为 $dp[(1 << n) - 1][0]$。

但上述 DP 将相同数字的不同位置视为不同的卡片，导致相同排列被多次计数。例如数位中有 $2$ 个 `1`，那么这 $2$ 个 `1` 的内部排列会被重复计算 $2!$ 次。因此需要去重：统计 $x$ 中每个数字 $0 \sim 9$ 的出现次数 $cnt[d]$，将初步答案依次除以 $cnt[d]!$，最终结果即为所求。

## 复杂度分析

- 状态总数：$O(2^n \cdot k)$，其中 $n \le 15$，$k \le 100$。
- 转移：每个状态最多枚举 $n$ 个未选位置，并更新 $k$ 种余数，转移复杂度 $O(n \cdot k)$。
- 总时间复杂度：$O(2^n \cdot n \cdot k)$，在极限数据下约 $3.2 \times 10^6$ 次操作，可以轻松通过。
- 空间复杂度：$O(2^n \cdot k)$，用于存储 DP 数组。

## 代码实现

### Python

```python
def solve():
    x = input().strip()
    k = int(input())
    n = len(x)
    # dp[i][j]: 使用集合 i 的数位，组成的整数模 k 为 j 的方案数
    dp = [[0] * k for _ in range(1 << n)]

    # 初始化：只选一张卡片且该卡片不是 '0'（避免前导零）
    for i in range(n):
        if x[i] != '0':
            dp[1 << i][int(x[i]) % k] = 1

    # 状态转移
    for i in range(1 << n):
        for j in range(n):
            if i >> j & 1:          # 位置 j 已使用
                continue
            for rem in range(k):
                if dp[i][rem] == 0:
                    continue
                nxt = (rem * 10 + int(x[j])) % k
                dp[i | (1 << j)][nxt] += dp[i][rem]

    ans = dp[(1 << n) - 1][0]

    # 去重：除以相同数字出现次数的阶乘
    cnt = [0] * 10
    for ch in x:
        cnt[int(ch)] += 1

    for d in range(10):
        for v in range(1, cnt[d] + 1):
            ans //= v

    print(ans)


if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String x = sc.next();
        int k = sc.nextInt();
        int n = x.length();
        long[][] dp = new long[1 << n][k];

        // 初始化：只选一张卡片且不为 '0'
        for (int i = 0; i < n; i++) {
            if (x.charAt(i) != '0') {
                dp[1 << i][(x.charAt(i) - '0') % k] = 1;
            }
        }

        // 状态转移
        for (int i = 0; i < (1 << n); i++) {
            for (int j = 0; j < n; j++) {
                if ((i >> j & 1) == 1) continue;
                for (int rem = 0; rem < k; rem++) {
                    if (dp[i][rem] == 0) continue;
                    int nxt = (rem * 10 + (x.charAt(j) - '0')) % k;
                    dp[i | (1 << j)][nxt] += dp[i][rem];
                }
            }
        }

        long ans = dp[(1 << n) - 1][0];

        // 去重
        int[] cnt = new int[10];
        for (char ch : x.toCharArray()) {
            cnt[ch - '0']++;
        }
        for (int d = 0; d < 10; d++) {
            for (int v = 1; v <= cnt[d]; v++) {
                ans /= v;
            }
        }

        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    string x;
    cin >> x;
    int k;
    cin >> k;
    int n = x.size();
    vector<vector<ll>> dp(1 << n, vector<ll>(k, 0));

    // 初始化：只选一张卡片且该位不是 '0'
    for (int i = 0; i < n; ++i) {
        if (x[i] != '0') {
            dp[1 << i][(x[i] - '0') % k] = 1;
        }
    }

    // 状态转移
    for (int i = 0; i < (1 << n); ++i) {
        for (int j = 0; j < n; ++j) {
            if (i >> j & 1) continue;
            for (int rem = 0; rem < k; ++rem) {
                if (dp[i][rem] == 0) continue;
                int nxt = (rem * 10 + (x[j] - '0')) % k;
                dp[i | (1 << j)][nxt] += dp[i][rem];
            }
        }
    }

    ll ans = dp[(1 << n) - 1][0];

    // 去重：除以相同数字出现次数的阶乘
    int cnt[10] = {0};
    for (char ch : x) {
        cnt[ch - '0']++;
    }
    for (int d = 0; d < 10; ++d) {
        for (int v = 1; v <= cnt[d]; ++v) {
            ans /= v;
        }
    }

    cout << ans << endl;
    return 0;
}
```
