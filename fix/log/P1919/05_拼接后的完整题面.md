# 题目内容
小 Z 有一组数字卡片，每张卡片上写有一个十进制数字，这些卡片原本按顺序组成了正整数 $x$。小 Z 希望用所有卡片（必须全部使用）重新拼接成不同的整数，且不允许产生前导零。请你帮忙计算：在拼接出的所有不同整数中，有多少个能够被给定的整数 $k$ 整除？

注意：相同的整数只算一次。

约束：$x$ 的十进制表示长度不超过 $15$（即 $1 \le x \le 10^{15}$），$k$ 满足 $1 \le k \le 100$。

# 输入描述
第一行包含一个正整数 $x$（$1 \le x \le 10^{15}$）。
第二行包含一个整数 $k$（$1 \le k \le 100$）。

# 输出描述
输出一个整数，表示答案。

## 样例1

**输入**

```
12
2
```

**输出**

```
1
```

**说明**

数字卡片为 `1` 和 `2`。不产生前导零的排列有 $12$ 和 $21$。其中 $12$ 能被 $2$ 整除，$21$ 不能被 $2$ 整除。因此共有 `1` 个满足条件的整数。

## 样例2

**输入**

```
102
3
```

**输出**

```
4
```

**说明**

数字卡片为 `1`、`0`、`2`。不产生前导零的排列有 $102$、$120$、$201$、$210$。计算每个数除以 $3$ 的余数，由于数字和均为 $1+0+2=3$，能被 $3$ 整除，因此这四个数均能被 $3$ 整除。不重复计数，共 `4` 个。

## 样例3

**输入**

```
123
4
```

**输出**

```
2
```

**说明**

数字卡片为 `1`、`2`、`3`。不产生前导零的排列共有 $6$ 个：$123, 132, 213, 231, 312, 321$。一个数能被 $4$ 整除当且仅当它的末两位组成的数能被 $4$ 整除。检查末两位：$123$ 末两位 $23$ 不能；$132$ 末两位 $32$ 能；$213$ 末两位 $13$ 不能；$231$ 末两位 $31$ 不能；$312$ 末两位 $12$ 能；$321$ 末两位 $21$ 不能。因此满足条件的整数为 $132$ 和 $312$，共 `2` 个。
