# 题目内容
给定一个长度为 $n$ 的正整数序列 $p_1, p_2, \dots, p_n$。你需要选择一个下标 $k$ ($1 \le k < n$)，将序列划分成前段 $p_1 \dots p_k$ 和后段 $p_{k+1} \dots p_n$。定义此时的价值为前段每个元素与后段每个元素两两乘积之和，即 $\sum_{i=1}^{k} \sum_{j=k+1}^{n} p_i \times p_j$。

请你找出在所有可能划分中，价值的最大值。由于答案可能很大，请输出结果对 $998244353$ 取模后的值。

约束条件：序列长度 $n$ 不超过 $2 \times 10^5$，每个数字 $p_i$ 满足 $1 \le p_i \le 10^4$。

# 输入描述
第一行包含一个整数 $n$ ($2 \le n \le 2 \times 10^5$)，表示序列长度。
第二行包含 $n$ 个整数 $p_1, p_2, \dots, p_n$ ($1 \le p_i \le 10^4$)，表示序列元素。

# 输出描述
输出一个整数，表示最大价值模 $998244353$ 的结果。

## 样例1

**输入**

```
2
1 2
```

**输出**

```
2
```

**说明**

序列长度为 `2`，只有一种划分方式 $k=1$。前段和为 $p_1=1$，后段和为 $p_2=2$。价值为 $1 \times 2 = 2$。最大值为 `2`，对 $998244353$ 取模后仍为 `2`。

## 样例2

**输入**

```
4
1 2 3 4
```

**输出**

```
24
```

**说明**

总共有 $n=4$ 个元素，总和 $S=1+2+3+4=10$。可能的 $k$ 和对应的价值：
- $k=1$：前段和 $=1$，后段和 $=9$，价值 $1 \times 9 = 9$；
- $k=2$：前段和 $=1+2=3$，后段和 $=7$，价值 $3 \times 7 = 21$；
- $k=3$：前段和 $=6$，后段和 $=4$，价值 $6 \times 4 = 24$。
最大价值为 `24`，取模后输出 `24`。

## 样例3

**输入**

```
10
10000 10000 10000 10000 10000 10000 10000 10000 10000 10000
```

**输出**

```
503511294
```

**说明**

序列含 `10` 个 `10000`，总和 $S = 100000$。价值公式为 $x \times (S-x)$，其中 $x$ 为前段和。由于抛物线对称轴在 $x=S/2=50000$，最接近 $50000$ 的前缀和为 $x=50000$（当 $k=5$ 时）。此时价值为 $50000 \times 50000 = 2\,500\,000\,000$。对 $998244353$ 取模：$2\,500\,000\,000 - 2 \times 998244353 = 2\,500\,000\,000 - 1\,996\,488\,706 = 503\,511\,294$。故输出 `503511294`。
