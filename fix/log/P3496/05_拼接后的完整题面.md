# 题目内容
给定长度为 $n$ 的字符串 $s$，由字符 `B`、`W` 和 `X` 组成。你需要把每一个 `X` 替换成 `B` 或 `W`，得到最终字符串。若最终字符串中至少存在一段长度为 $k$ 的连续子串，且该子串全部由字符 `B` 构成，则称该字符串为**达标串**。

请计算有多少种不同的填充方式能使最终字符串达标，并将结果对 $10^9+7$ 取模后输出。

子串指从原串中选取一段连续字符得到的字符串（可以取整段）。

数据范围：$1 \le k \le n \le 10^6$；字符串仅由字符 `B`、`W`、`X` 组成。

# 输入描述
第一行包含两个整数 $n$ 和 $k$（$1 \le k \le n \le 10^6$），分别表示字符串长度与连续 `B` 的长度阈值。
第二行包含一个长度为 $n$ 的字符串 $s$，仅由字符 `B`、`W` 和 `X` 组成。

# 输出描述
输出一个整数，表示达标填充方案数对 $10^9+7$ 取模后的结果。

## 样例1

**输入**

```
3 2
XXX
```

**输出**

```
3
```

**说明**

长度为 `3` 的串共有 $2^3=8$ 种填充。其中包含连续 `BB` 的有 `BBW`、`BBB`、`WBB` 共 `3` 种。

## 样例2

**输入**

```
4 3
XXXX
```

**输出**

```
3
```

**说明**

长度为 `4` 且包含连续 `BBB` 的填充共有 `3` 种：`BBBW`、`BBBB`、`WBBB`。

## 样例3

**输入**

```
5 2
BWBWB
```

**输出**

```
0
```

**说明**

串中没有 `X`，本身也不含连续两个 `B`，无法达标，答案为 `0`。

## 样例4

**输入**

```
2 1
WX
```

**输出**

```
1
```

**说明**

$k=1$ 时只要出现至少一个 `B` 即达标。`WX` 可填成 `WB`（达标）或 `WW`（不达标），故答案为 `1`。
