# 题目内容
小 L 获得了一个长度为 $n$ 的整数序列 $b_1, b_2, \dots, b_n$，他定义 $W(k)$ 为序列中所有长度为 $k$ 的连续子段之和的总和，即：
$$ W(k) = \sum_{i=1}^{n-k+1} \sum_{j=i}^{i+k-1} b_j $$
现在他要进行 $m$ 次询问，每次询问给定一个区间 $[l, r]$，你需要回答该区间内所有为素数的长度 $p$ 对应的 $W(p)$ 的总和，结果对 $998244353$ 取模。

序列的长度 $n$ 不超过 $10^4$，询问次数 $m$ 不超过 $2 \times 10^5$，序列中的每个数均为正整数且不超过 $10^9$。

# 输入描述
第一行包含两个正整数 $n$ 和 $m$，分别表示序列长度与询问次数。
第二行包含 $n$ 个正整数 $b_1, b_2, \dots, b_n$，表示序列中的元素。
接下来 $m$ 行，每行包含两个整数 $l_i, r_i$，表示一个询问的区间。

# 输出描述
输出共 $m$ 行，对于每个询问，输出一个整数，表示区间 $[l_i, r_i]$ 内所有素数长度对应的 $W$ 值之和对 $998244353$ 取模的结果。

## 样例1

**输入**

```
6 4
1 2 3 4 5 6
2 3
1 6
4 4
1 1
```

**输出**

```
77
112
0
0
```

**说明**

给定序列 $b = [1, 2, 3, 4, 5, 6]$，长度 $n = 6$。
- 前缀和 $P[i] = \sum_{j=1}^{i} b_j$：$P = [0, 1, 3, 6, 10, 15, 21]$。
- 二次前缀和 $Q[i] = \sum_{j=1}^{i} P[j]$：$Q = [0, 1, 4, 10, 20, 35, 56]$。

对于长度 $x$，所有长度为 $x$ 的子数组和的总和为
$$ W(x) = Q[n] - Q[x-1] - Q[n-x] $$
计算得：
$W(1)=56-0-35=21$
$W(2)=56-1-20=35$
$W(3)=56-4-10=42$
$W(4)=56-10-4=42$
$W(5)=56-20-1=35$
$W(6)=56-35-0=21$

长度为 $1$ 到 $6$ 中，素数为 $2, 3, 5$。对应的 $W$ 值分别为 $35, 42, 35$。

查询 $[2,3]$：包含长度 $2$ 和 $3$，和 $35+42=77$。
查询 $[1,6]$：包含素数长度 $2,3,5$，和 $35+42+35=112$。
查询 $[4,4]$：长度 $4$ 不是素数，输出 $0$。
查询 $[1,1]$：长度 $1$ 不是素数，输出 $0$。

## 样例2

**输入**

```
2 1
1 1
2 2
```

**输出**

```
2
```

**说明**

给定序列 $b = [1, 1]$，$n = 2$。
- 前缀和 $P = [0, 1, 2]$。
- 二次前缀和 $Q = [0, 1, 3]$。

$W(1) = Q[2] - Q[0] - Q[1] = 3 - 0 - 1 = 2$。
$W(2) = Q[2] - Q[1] - Q[0] = 3 - 1 - 0 = 2$。

长度为 $1$ 到 $2$ 中，只有 $2$ 是素数。查询区间 $[2,2]$ 包含素数长度 $2$，答案为 $W(2) = 2$。

## 样例3

**输入**

```
5 2
10 20 30 40 50
2 5
1 1
```

**输出**

```
660
0
```

**说明**

给定序列 $b = [10, 20, 30, 40, 50]$，$n = 5$。
- 前缀和 $P = [0, 10, 30, 60, 100, 150]$。
- 二次前缀和 $Q = [0, 10, 40, 100, 200, 350]$。

计算得 $W(1)=150$，$W(2)=240$，$W(3)=270$，$W(4)=240$，$W(5)=150$。
素数长度为 $2, 3, 5$。

查询 $[2,5]$ 包含素数长度 $2,3,5$，和为 $240+270+150=660$。
查询 $[1,1]$ 中无素数长度，输出 $0$。
