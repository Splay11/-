# 题目内容
自动化立体库用一个栈暂存料箱。机械臂的操作记录是一个整数序列：若 $a_i>0$，把编号为 $a_i$ 的料箱放入栈顶；若 $a_i<0$，需要把编号为 $-a_i$ 的料箱从栈顶取出。初始栈空。一段记录合法，当且仅当按顺序执行时每次取出的料箱恰好是当时的栈顶，并且全部操作结束后栈重新为空。原先有一段合法记录，但传输故障把其中某两个相邻位置交换了一次，得到现在的序列 $b$。请找出一对相邻位置 $u,v$，交换 $b_u$ 与 $b_v$ 后序列重新合法。题目保证至少存在一种方案；多解输出任意一种即可。序列中所有非零整数互不相同。

约束：$n$ 为正偶数，$2 \le n \le 100000$，$1 \le |b_i| \le 1048576$。

# 输入描述
第一行一个正偶数 $n$，表示序列长度，满足 $2 \le n \le 100000$。
第二行 $n$ 个互不相同的非零整数 $b_1,b_2,\ldots,b_n$，满足 $1 \le |b_i| \le 1048576$。
保证存在一对相邻位置，交换后序列合法。

# 输出描述
输出两个用空格分隔的整数 $u$ 和 $v$，满足 $1 \le u=v-1 \le n-1$，表示交换第 $u$ 个与第 $v$ 个元素。多解输出任意一种即可。

## 样例1

**输入**

```
4
1 -2 2 -1
```

**输出**

```
2 3
```

**说明**

当前序列在第二次操作就要弹出 `2`，但栈顶是 `1`，不合法。交换第 `2`、`3` 项后得到 `1 2 -2 -1`，入栈出栈均匹配且最终栈空。

## 样例2

**输入**

```
6
6 5 -6 -5 7 -7
```

**输出**

```
1 2
```

**说明**

两个正数 `6`、`5` 相邻入栈，但 `6` 比 `5` 更早出栈，违反后进先出。交换第 `1`、`2` 项后得到 `5 6 -6 -5 7 -7`，是两段合法的配对。

## 样例3

**输入**

```
2
-8 8
```

**输出**

```
1 2
```

**说明**

先弹出 `8` 时栈空，不合法。交换两个位置后变成 `8 -8`，入栈再出栈，序列合法。

## 样例4

**输入**

```
6
10 20 -30 30 -20 -10
```

**输出**

```
3 4
```

**说明**

执行到 `-30` 时栈顶是 `20` 而不是 `30`。交换第 `3`、`4` 项后得到 `10 20 30 -30 -20 -10`，完全匹配括号序列。
