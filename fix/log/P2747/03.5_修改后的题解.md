## 解题思路

合法出入栈序列类似括号匹配：正数表示料箱入栈，对应负数表示取出，且必须满足后进先出。原序列只被交换了一对相邻记录，因此可以扫描每一对相邻位置，判断它是否是那次错误交换。

先记下每个值出现的下标。对相邻两项 $b_i,b_{i+1}$ 分四种情况：

- 两个正数：后入栈者应更早出栈；若 $b_i$ 的出栈位置反而更靠前，则应交换这一对；
- 两个负数：对称地检查对应入栈顺序；
- 负数后接正数：若二者互为相反数，说明把一对匹配的入栈/出栈颠倒了，应交换；
- 正数后接负数：若它们不是一对匹配，且该负数对应的入栈发生在当前位置之前，则应交换。

题目保证有解，扫到第一处即可输出（多解任选）。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(n)$。

## 代码实现

### Python

```python
n = int(input())
ls = list(map(int, input().split()))

mp = {}
for i in range(n):
    mp[ls[i]] = i

for i in range(n - 1):
    if ls[i] > 0 and ls[i + 1] > 0:
        if mp[-ls[i]] < mp[-ls[i + 1]]:
            print(i + 1, i + 2)
            break
    elif ls[i] < 0 and ls[i + 1] < 0:
        if mp[-ls[i]] < mp[-ls[i + 1]]:
            print(i + 1, i + 2)
            break
    elif ls[i] < 0 and ls[i + 1] > 0:
        if -ls[i] == ls[i + 1]:
            print(i + 1, i + 2)
            break
    elif ls[i] > 0 and ls[i + 1] < 0:
        if ls[i] != -ls[i + 1] and mp[-ls[i + 1]] < i:
            print(i + 1, i + 2)
            break
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] ls = new int[n];
        Map<Integer, Integer> mp = new HashMap<>();

        for (int i = 0; i < n; i++) {
            ls[i] = sc.nextInt();
            mp.put(ls[i], i);
        }

        for (int i = 0; i < n - 1; i++) {
            if (ls[i] > 0 && ls[i + 1] > 0) {
                if (mp.get(-ls[i]) < mp.get(-ls[i + 1])) {
                    System.out.println((i + 1) + " " + (i + 2));
                    return;
                }
            } else if (ls[i] < 0 && ls[i + 1] < 0) {
                if (mp.get(-ls[i]) < mp.get(-ls[i + 1])) {
                    System.out.println((i + 1) + " " + (i + 2));
                    return;
                }
            } else if (ls[i] < 0 && ls[i + 1] > 0) {
                if (-ls[i] == ls[i + 1]) {
                    System.out.println((i + 1) + " " + (i + 2));
                    return;
                }
            } else if (ls[i] > 0 && ls[i + 1] < 0) {
                if (ls[i] != -ls[i + 1] && mp.get(-ls[i + 1]) < i) {
                    System.out.println((i + 1) + " " + (i + 2));
                    return;
                }
            }
        }
    }
}
```
