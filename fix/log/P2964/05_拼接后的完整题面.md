# 题目内容
对于一个包含 $1$ 到 $n$ 中每个整数恰好一次的序列 $b = [b_1, b_2, \dots, b_n]$，定义其“跳跃距离”序列为 $d$，其中 $d_i = |b_{i+1} - b_i|$（$1 \le i \le n-1$）。
如果存在一个整数常数 $c$，使得 $d$ 是一个公差恰好为 $c$ 的等差数列（即对于所有 $i$ 有 $d_{i+1} - d_i = c$），就称序列 $b$ 是“和谐的”。

现在给定整数 $n$ 和 $c$，请你构造一个和谐的序列，或者判断这样的序列不存在。

**约束条件：**
- $n$ 是一个整数，满足 $4 \le n \le 2\times 10^5$。
- $c$ 是一个整数，满足 $-n < c < n$。

# 输入描述
第一行包含两个整数 $n$ 和 $c$，用一个空格分隔。

# 输出描述
如果存在满足条件的序列，第一行输出 `YES`，第二行输出 $n$ 个由空格分隔的整数，表示这个和谐的序列；否则直接输出 `NO`。

## 样例1

**输入**

```
4 0
```

**输出**

```
YES
1 2 3 4
```

**说明**

当 $c = 0$ 时，所有相邻差值必须相等。最简单的构造是顺序排列 $[1, 2, 3, 4]$。相邻差值为 $|2-1|=1$，$|3-2|=1$，$|4-3|=1$，差值序列 $[1, 1, 1]$ 是公差为 $0$ 的等差数列。满足条件。

## 样例2

**输入**

```
6 -1
```

**输出**

```
YES
1 6 2 5 3 4
```

**说明**

当 $c = -1$ 时，需要差值序列为 $[n-1, n-2, \dots, 1]$。交替从两端取数可以满足：左端 `1`，右端 `6`，左端 `2`，右端 `5`，左端 `3`，右端 `4`。

差值依次为 $|6-1|=5$，$|2-6|=4$，$|5-2|=3$，$|3-5|=2$，$|4-3|=1$，差值序列 $[5, 4, 3, 2, 1]$ 是公差为 $-1$ 的等差数列。

## 样例3

**输入**

```
6 1
```

**输出**

```
YES
4 3 5 2 6 1
```

**说明**

当 $c = 1$ 时，需要差值序列为 $[1, 2, \dots, n-1]$。将 $c = -1$ 的构造逆序即可：$c=-1$ 时序列为 $[1, 6, 2, 5, 3, 4]$，逆序后得到 $[4, 3, 5, 2, 6, 1]$。

验证差值：$|3-4|=1$，$|5-3|=2$，$|2-5|=3$，$|6-2|=4$，$|1-6|=5$，差值序列 $[1, 2, 3, 4, 5]$ 是公差为 $1$ 的等差数列。

## 样例4

**输入**

```
5 2
```

**输出**

```
NO
```

**说明**

分析差值序列的取值范围可知，等差数列首项 $A$ 满足 $1 \le A \le n-1$，且末项 $A+(n-2)c$ 也必须在 $[1, n-1]$ 范围内。经检验，只有当 $c \in \{-1, 0, 1\}$ 时才有可能。

本题 $n=5$，$c=2$，不存在任何排列满足所有差值均为 $[1, 4]$ 内的整数且构成公差为 $2$ 的等差数列。因此输出 `NO`。
