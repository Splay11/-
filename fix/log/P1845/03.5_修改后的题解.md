## 解题思路

先将分数从小到大排序，记排序后为 $a_0, a_1, \ldots, a_{n-1}$。

观察抽取过程：每次抽的都是当前序列的“偏左中位数”。这等价于从中间向两侧交替取出：

- 令 $mid = \lfloor n/2 \rfloor$；
- 若 $n$ 为奇数，第一次抽的是 $a_{mid}$，之后左右指针分别向两端扩展；
- 若 $n$ 为偶数，第一次抽的是 $a_{mid-1}$，随后与 $a_{mid}$ 成对向外扩展。

用双指针 $i$、$j$ 从中间出发，$i$ 向左、$j$ 向右，每次先输出 $a_i$，若 $i \neq j$ 再输出 $a_j$，直到覆盖整个数组。这样 $O(n)$ 即可得到抽取序列，无需每次真正删除。

## 复杂度分析

- 时间复杂度：$O(n \log n)$（排序主导）。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
import sys

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    a = list(map(int, data[1:]))
    a.sort()
    mid = n // 2
    i = mid - (1 - (n % 2))
    j = mid
    result = []
    while i >= 0 and j < n:
        result.append(a[i])
        if i != j:
            result.append(a[j])
        i -= 1
        j += 1
    print(' '.join(map(str, result)))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = sc.nextInt();
        Arrays.sort(a);
        int mid = n / 2;
        int i = mid - (1 - (n % 2));
        int j = mid;
        StringBuilder sb = new StringBuilder();
        while (i >= 0 && j < n) {
            sb.append(a[i]).append(' ');
            if (i != j) sb.append(a[j]).append(' ');
            i--;
            j++;
        }
        System.out.println(sb.toString().trim());
        sc.close();
    }
}
```

### C++

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    sort(a.begin(), a.end());
    int mid = n >> 1;
    int i = mid - (1 - (n & 1));
    int j = mid;
    while (i >= 0 && j < n) {
        cout << a[i] << ' ';
        if (i != j) cout << a[j] << ' ';
        i--;
        j++;
    }
    return 0;
}
