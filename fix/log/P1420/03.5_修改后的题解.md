## 解题思路

一次操作可以删掉当前串中一组互不相邻的字符。若目标是保留某种字母 $c$，则所有非 $c$ 字符必须被删光；被 $c$ 隔开的每一段连续非 $c$ 字符互相独立，长度为 $L$ 的连续段需要 $\lceil \log_2(L+1)\rceil$ 次操作才能删完。因此字符串的权值等于：对所有出现过的字母，取其「最长待删段」对应操作次数的最小值。

要让权值恰好为 $k$，必须存在某字母的最长待删段长度落在 $[2^{k-1}, 2^k-1]$，且没有任何字母的操作次数更小。由此得到判定：

- 若 $n < 2^k$，则 $2^{k-1} > n/2$，不可能让所有字母的最长待删段都不小于 $2^{k-1}$，无解，输出 `-1`。
- 否则令 $p = 2^{k-1}$，构造 $n-p$ 个字符 `a` 后接 $p$ 个字符 `b`。保留 `a` 时待删段长度恰好为 $p$，操作次数为 $k$；保留 `b` 时待删段更长，操作次数不小于 $k$。故权值恰好为 $k$。

由于 $n \le 2 \times 10^5$，当 $k \ge 18$ 时必有 $2^k > n$，可直接判定无解。

## 复杂度分析

只需根据 $n$、$k$ 判断可行性并生成长度为 $n$ 的字符串。

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
n, k = map(int, input().split())
if k > 17 or n < (1 << k):
    print(-1)
else:
    p = 1 << (k - 1)
    print("a" * (n - p) + "b" * p)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int k = sc.nextInt();
        if (k > 17 || n < (1 << k)) {
            System.out.println(-1);
        } else {
            int p = 1 << (k - 1);
            StringBuilder sb = new StringBuilder(n);
            for (int i = 0; i < n - p; i++) {
                sb.append('a');
            }
            for (int i = 0; i < p; i++) {
                sb.append('b');
            }
            System.out.println(sb.toString());
        }
        sc.close();
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    if (k > 17 || n < (1 << k)) {
        cout << -1 << "\n";
    } else {
        int p = 1 << (k - 1);
        cout << string(n - p, 'a') + string(p, 'b') << "\n";
    }
    return 0;
}
```
