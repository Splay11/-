# 题目内容
气象站记录了连续 $n$ 天的日平均气温，得到一个长度为 $n$ 的整数序列 $t_1, t_2, \ldots, t_n$。如果一段连续的日期 $[l, r]$ 满足对于所有 $i \in [l, r-1]$，都有 $|t_{i+1} - t_i| \le D$，则这段日期被称为一个“温和时期”。

请你求出所有温和时期的最大长度（即最长连续天数）。

数据范围与约定：
- 测试数据组数 $T$ 是一个正整数，且 $T$ 不超过 `2×10^5`。
- 对于每组数据，$n$ 是一个正整数，且不超过 `2×10^5`；$D$ 是一个非负整数，不超过 `10^9`。
- 气温的绝对值 $|t_i|$ 不超过 `10^9`。
- 保证所有测试数据的 $n$ 之和不超过 `2×10^5`。

# 输入描述
第一行包含一个整数 $T$，表示测试数据组数。接下来有 $T$ 组数据。每组数据由两行组成：第一行包含两个整数 $n$ 和 $D$，分别表示气温序列的长度和允许的最大温差；第二行包含 $n$ 个整数，$t_1, t_2, \ldots, t_n$，表示每天的日平均气温。

# 输出描述
对于每组测试数据，输出一行一个整数，表示该组数据中最长温和时期的天数。

## 样例1

**输入**

```
2
3 1
1 2 4
4 0
5 5 6 6
```

**输出**

```
2
2
```

**说明**

第一组数据 $n=3$, $D=1$, 气温 `[1, 2, 4]`。相邻温差： $|2-1|=1 \le 1$， $|4-2|=2 > 1$。最长的连续满足段为 `[1,2]`，长度为 `2`。
第二组数据 $n=4$, $D=0$, 气温 `[5, 5, 6, 6]`。相邻温差： $|5-5|=0 \le 0$， $|6-5|=1 > 0$， $|6-6|=0 \le 0$。最长满足段为 `[1,2]` 或 `[3,4]`，长度均为 `2`。

## 样例2

**输入**

```
1
4 5
1 3 6 10
```

**输出**

```
4
```

**说明**

相邻温差分别为 $|3-1|=2$， $|6-3|=3$， $|10-6|=4$，均 $\le 5$，整段都是温和时期，长度为 `4`。

## 样例3

**输入**

```
1
1 0
5
```

**输出**

```
1
```

**说明**

只有 `1` 天，无论 $D$ 为多少，单天总是温和时期，长度为 `1`。

## 样例4

**输入**

```
1
6 2
1 4 5 8 10 11
```

**输出**

```
3
```

**说明**

气温序列 `[1, 4, 5, 8, 10, 11]`。相邻温差： $|4-1|=3 > 2$（中断）， $|5-4|=1 \le 2$（连续）， $|8-5|=3 > 2$（中断）， $|10-8|=2 \le 2$（连续）， $|11-10|=1 \le 2$（连续）。各连续段长度分别为 `1`（第1天）、`2`（第2~3天）、`3`（第4~6天）。最长温和时期为 `3` 天（第 `4` 到第 `6` 天）。
