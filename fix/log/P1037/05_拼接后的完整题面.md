# 题目内容
两条轨道上分别印有一段由小写字母 `a`～`z` 与数字 `0`～`9` 组成的标记串。允许各从两条轨道上各截取一段连续标记。若两段标记完全相同，则它们可以对齐，并计入长度为该公共片段长度两倍的得分。

请计算可能得到的最大得分。

每条轨道的标记长度为正整数，且不超过 `100`。

# 输入描述
第一行一个字符串，表示第一条轨道的标记。
第二行一个字符串，表示第二条轨道的标记。
两个字符串均仅由小写字母 `a`～`z` 与数字 `0`～`9` 构成，长度均在 `1` 到 `100` 之间。

# 输出描述
输出一个整数，表示最大得分。

## 样例1

**输入**

```
abc123
xyz
```

**输出**

```
0
```

**说明**

第一条含字母与数字，第二条为 `xyz`，没有公共连续片段，最长长度为 `0`，得分 `0`。

## 样例2

**输入**

```
ab12c
ab12c
```

**输出**

```
10
```

**说明**

两条标记完全相同，最长公共连续片段长度为 `5`，得分为 `10`。

## 样例3

**输入**

```
1323467
1378695
```

**输出**

```
4
```

**说明**

按题意模拟计算得到。
