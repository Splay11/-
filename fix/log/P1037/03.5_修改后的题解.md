## 解题思路

题目要求的最大得分等于最长公共连续子串长度的两倍。

轨道长度不超过 `100`，直接枚举第一条标记的所有子串，检查它是否作为连续片段出现在第二条标记中，取最长长度 $L$，答案为 $2L$。

## 复杂度分析

设两条串长度分别为 $n,m$，枚举子串后在第二条中查找，时间复杂度 $O(n^2 m)$，空间复杂度 $O(n+m)$。在长度不超过 `100` 时可以通过。

## 代码实现

### Python

```python
a = input()
b = input()
n = len(a)
ans = 0
for i in range(n):
    for j in range(i, n):
        c = a[i:j + 1]
        if b.find(c) != -1:
            ans = max(ans, j - i + 1)
print(ans * 2)
```

### Java

```java
import java.util.Scanner;

class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String a = scanner.next();
        String b = scanner.next();
        int ans = 0;
        for (int i = 0; i < a.length(); i++) {
            for (int j = i; j < a.length(); j++) {
                String tmp = a.substring(i, j + 1);
                if (b.indexOf(tmp) != -1)
                    ans = Math.max(ans, j - i + 1);
            }
        }
        System.out.println(ans * 2);
    }
}
```

### C++

```cpp
#include <iostream>
using namespace std;

int main() {
    string a, b;
    cin >> a >> b;
    int ans = 0;
    int n = a.size();
    for (int i = 0; i < n; i++) {
        for (int j = i; j < n; j++) {
            string tmp = a.substr(i, j - i + 1);
            if (b.find(tmp, 0) != string::npos)
                ans = max(ans, j - i + 1);
        }
    }
    cout << ans * 2 << endl;
    return 0;
}
```
