# 题目内容
要把总量为 $m$ 的配额分给 $n$ 个站点。每个站点分到的配额必须是整数，且落在闭区间 $[l,r]$ 内。

请构造任意一组满足条件的配额；若不可能完成分发，则输出 $r+1$。

约束：测试组数不超过 `10^4`，单组站点数不超过 `2\times 10^5`，且单个文件中所有 $n$ 之和不超过 `2\times 10^5`。$m$、$l$、$r$ 的绝对值均不超过 `10^9`，且 $l \le r$。

# 输入描述
每个测试文件包含多组数据。
第一行包含一个整数 $T$，表示测试组数。保证 $1 \le T \le 10^4$。
接下来 $T$ 行，每行四个整数 $n$、$m$、$l$ 和 $r$，分别表示站点数、配额总量以及每个站点配额的下界与上界。保证 $1 \le n \le 2 \times 10^5$，$-10^9 \le m \le 10^9$，$-10^9 \le l \le r \le 10^9$，且单个文件中所有 $n$ 之和不超过 $2 \times 10^5$。

# 输出描述
对每组数据输出一行：若有解，输出 $n$ 个整数表示一种可行配额；若无解，输出 $r+1$。

## 样例1

**输入**

```
1
1 5 5 5
```

**输出**

```
5
```

**说明**

只有一个站点，下界与上界都是 `5`，总量也是 `5`。
唯一解就是 `5`。这是 $n=1$ 的边界情形。

## 样例2

**输入**

```
1
3 0 -1 1
```

**输出**

```
1 0 -1
```

**说明**

三个站点配额均在 $[-1,1]$ 内，目标和为 `0`。
先全部分成 `-1`，剩余增量 `3`：第一个加 `2` 变成 `1`，第二个加 `1` 变成 `0`，第三个保持 `-1`，输出 `1 0 -1`。

## 样例3

**输入**

```
1
2 6 6 6
```

**输出**

```
7
```

**说明**

按题意模拟计算得到。
