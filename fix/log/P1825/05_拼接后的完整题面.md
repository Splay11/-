# 题目内容
给定一个长度为 $L+1$ 的整数序列 $s_1, s_2, \dots, s_{L+1}$，已知 $s_{L+1} = X$，且从后向前依次满足递推关系：
$$
s_i = s_{i+1} \bmod i \qquad (1 \le i \le L)
$$
现在有 $Q$ 次询问，每次给出 $L$、$X$ 以及查询位置 $P$，请你求出 $s_P$ 的值。

询问次数 $Q$ 不超过 $10^5$，长度参数 $L$ 不超过 $10^9$，末尾值 $X$ 不超过 $10^9$，查询位置满足 $1 \le P \le L+1$。

# 输入描述
第一行包含一个整数 $Q$，表示询问的次数。
接下来 $Q$ 行，每行依次包含三个整数 $L$、$X$、$P$，分别表示序列长度参数、末尾元素以及查询的位置。

# 输出描述
对于每组询问，输出一行一个整数，表示序列中第 $P$ 个元素 $s_P$ 的值。

## 样例1

**输入**

```
2
5 3 3
5 10 6
```

**输出**

```
0
10
```

**说明**

第一组询问：$L=5$，$X=3$，$P=3$。序列最后一项 $s_6 = 3$。从 $i=5$ 向下递推：
$s_5 = 3 \bmod 5 = 3$；
$s_4 = 3 \bmod 4 = 3$；
$s_3 = 3 \bmod 3 = 0$。
因此 $s_3 = 0$。

第二组询问：$P = 6 = L+1$，直接输出末尾元素 $X = 10$。

## 样例2

**输入**

```
2
10 25 6
10 20 5
```

**输出**

```
5
0
```

**说明**

第一组：$L=10$，$X=25$，$P=6$。末尾项 $s_{11}=25$。
$i=10$：$s_{10}=25 \bmod 10 = 5$；
$i=9$：$5 \bmod 9 = 5$；
$i=8$：$5 \bmod 8 = 5$；
$i=7$：$5 \bmod 7 = 5$；
$i=6$：$5 \bmod 6 = 5$。
所以 $s_6=5$。

第二组：$L=10$，$X=20$，$P=5$。末尾项 $s_{11}=20$。
$i=10$：$20 \bmod 10 = 0$，此后所有项均为 $0$，故 $s_5=0$。

## 样例3

**输入**

```
2
1 100 2
1 100 1
```

**输出**

```
100
0
```

**说明**

第一组：$L=1$，$X=100$，$P=2=L+1$，答案即为 $100$。

第二组：$L=1$，$X=100$，$P=1$。末尾项 $s_2=100$。递推 $i=1$：$s_1 = 100 \bmod 1 = 0$。因此 $s_1=0$。
