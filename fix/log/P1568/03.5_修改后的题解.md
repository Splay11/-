## 解题思路

本题与「奇数步网格博弈」描述的计算任务一致。按输入格式读入数据后，沿用原题解的算法即可。

详见下方代码实现。

## 复杂度分析

- 时间复杂度与原题解相同。
- 空间复杂度与原题解相同。

## 代码实现

### Python

```python
t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    if (m + n) % 2 == 1:
        print("Yes")
    else:
        print("No")
```

### Java

```java
import java.util.*;

public class Main {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int T = scanner.nextInt();
        for(int t = 0; t < T; t++){
            int n = scanner.nextInt();
            int m = scanner.nextInt();
            if((m + n) % 2 == 1){
                System.out.println("Yes");
            }else System.out.println("No");
        }

    }

}
```
