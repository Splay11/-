## 思路：思维题

观察可知，嫌犯无论怎么操作，都不会改变数组的总和，真凶操作一次，就会使得数组总和+1

因此，我们可以使用哈希表统计$n$个数组的总和，出现次数为一次的，即为真凶，操作次数，其实就是嫌犯所在的数组之和与真凶所在的数组之和的差值





## 代码

**C++**

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef pair<int,int>PII;
const int N=100;
int n,w[N],m;
int main(){
    cin>>n>>m;
    map<int,int>mp;
    for(int i=0;i<n;i++){
        int x;
        int sum=0;
        for(int j=0;j<m;j++){
            cin>>x;
            sum+=x;
        }
        mp[sum]++;
        w[i]=sum;
    }
    int pos,sum1,sum;
    for(int i=0;i<n;i++){
        if(mp[w[i]]==1){
            pos=i+1;
            sum=w[i];
        }
        else{
            sum1=w[i];
        }
    }
    int cnt=abs(sum1-sum);
    cout<<pos<<" "<<cnt<<endl;
    return 0;
}
```

**Java**

```java
import java.util.*;
class Main{
    public static void main(String[]args){
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        long minus=0;
        long ma=0;
        for(int i=1;i<=n;i++){
            long tor=0;
            for(int j=1;j<=m;j++){
                int a=sc.nextInt();
                tor+=a;
            }
            if(minus==0&&ma==0){
                minus=tor;
                continue;
            }
            if(minus!=0&&tor!=minus){
                long dif=Math.abs(tor-minus);
                i=tor>minus?i:1;
                System.out.print(i+" "+dif);
                return;
            }
        }
    }
}
```
