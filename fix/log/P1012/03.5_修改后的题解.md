## 解题思路

纪念券面额都是 $233$ 乘以 $10$ 的幂，因此 $x$ 能被凑出当且仅当 $x$ 能被 $233$ 整除。令 $y=x/233$，问题变成：用尽量少个形如 $10^i$ 的数（即各位上的数字）凑出 $y$。

十进制下 $y$ 的每一位数字 $d$ 表示在该数位上使用 $d$ 个 $1$，也就是使用 $d$ 张对应面额的纪念券。各位数字之和就是最少张数。若 $x$ 不能被 $233$ 整除，输出 $-1$。

## 复杂度分析

时间复杂度 $O(t\log x)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
t = int(input())
for i in range(t):
    x = int(input())
    if (x % 233 != 0):
        print(-1)
    else:
        x = x // 233
        print(sum(int(j) for j in str(x)))
```

### Java

```java
import java.util.Scanner;

class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int t = scanner.nextInt();
        for (int i = 0; i < t; i++) {
            Long x = scanner.nextLong();
            int ans = 0;
            if (x % 233 != 0)
                System.out.println(-1);
            else {
                x /= 233;
                while (x != 0) {
                    ans += x % 10;
                    x /= 10;
                }
                System.out.println(ans);
            }
        }
    }
}
```

### C++

```cpp
#include <iostream>
using namespace std;

int main(){
    int t;
    cin >> t;
    while (t--) {
        long long x;
        cin >> x;
        if (x % 233 != 0)
            cout << -1 << endl;
        else {
            x /= 233;
            int ans = 0;
            while (x) {
                ans += x % 10;
                x /= 10;
            }
            cout << ans << endl;
        }
    }
    return 0;
}
```
