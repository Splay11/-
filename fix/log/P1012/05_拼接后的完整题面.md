# 题目内容
文创店发行一批纪念券，面额被规定为形如 $233 \times 10^i$（$i$ 为非负整数）的数，例如 `233`、`2330`、`23300`。顾客每次给出应付金额 $x$，可以用任意张纪念券（面额可重复）恰好凑出 $x$，并希望张数尽量少；若无法恰好凑出，则记为 `-1`。共有 $t$ 组询问。

约束：$1 \le t \le 10^2$，$0 \le x \le 100000000000000$。

# 输入描述
第一行一个整数 $t$，表示询问组数。
接下来 $t$ 行，每行一个整数 $x$。
保证 $1 \le t \le 10^2$，$0 \le x \le 100000000000000$。

# 输出描述
对每组询问输出一行一个整数：最少需要多少张纪念券，无法凑出则输出 `-1`。

## 样例1

**输入**

```
4
0
466
2330
699
```

**输出**

```
0
2
1
3
```

**说明**

不能被 `233` 整除则无解；否则把 $x/233$ 写成十进制，各位数字之和就是最少个数（第 $i$ 位数字 $d$ 表示使用 $d$ 个 $233 \times 10^i$）。

- `0`：$0/233=`0`$，数位和为 `0`；
- `466`：$466/233=`2`$，数位和为 `2`；
- `2330`：$2330/233=`10`$，数位和为 `1`；
- `699`：$699/233=`3`$，数位和为 `3`。

## 样例2

**输入**

```
3
1
1165
46600
```

**输出**

```
-1
5
2
```

**说明**

- `1` 不能被 `233` 整除，输出 `-1`；
- `1165`：$1165/233=`5`$，数位和为 `5`；
- `46600`：$46600/233=`200`$，数位和为 `2`。
