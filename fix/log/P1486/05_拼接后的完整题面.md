# 题目内容
在某个王国中，有 $n$ 座城市，由 $n-1$ 条道路连接成一棵以首都 `1` 为根的树。每座城市都安放了一枚魔法徽章。一名旅人到达城市 $u$ 时，徽章会发出指示：若以 $u$ 为根的子树中存在其他城市，则指引他前往这些城市中编号最小的那一座；若子树中只有 $u$ 自身（即 $u$ 为树叶），则徽章不会给出任何指示。

旅人从某座城市出发，不断遵循徽章的指示前行，直到抵达一座没有指示的城市为止。请问，对于每座城市，从该城市出发的旅人一共能访问多少座不同的城市（包含出发城市）？

城市总数 $n$ 满足 $1 \le n \le 10^5$，城市编号均为 $1$ 至 $n$ 的整数。

# 输入描述
第一行包含一个整数 $n$，表示城市的数量。
接下来 $n-1$ 行，每行包含两个整数 $u$ 和 $v$，表示城市 $u$ 与城市 $v$ 之间有一条直接相连的道路。输入保证构成一棵以城市 `1` 为根的有根树。

# 输出描述
输出一行，包含 $n$ 个整数，第 $i$ 个整数表示从城市 $i$ 出发能够访问的城市总数，数字之间用空格分隔。

## 样例1

**输入**

```
1
```

**输出**

```
1
```

**说明**

只有城市 `1`。以自己为根的子树大小为 $1$，没有其它城市，因此徽章不会给出指示。旅人从城市 `1` 出发，无法前往任何其他城市，只能访问城市 `1` 本身，访问总数为 `1`。

## 样例2

**输入**

```
3
1 3
3 2
```

**输出**

```
2 1 2
```

**说明**

树的结构为 $1$–$3$–$2$，以 `1` 为根。

- 城市 `2`：是叶子，无指示，访问总数 $f(2)=1$。
- 城市 `3`：子树 $\{3,2\}$ 中除自身外最小的城市是 `2`。旅人从 `3` 出发会前往 `2`，再停下，访问 `3` 和 `2`，共 $2$ 座城市，即 $f(3)=1+f(2)=2$。
- 城市 `1`：子树 $\{1,3,2\}$ 中除自身外最小的城市是 `2`（注意 `2` 不是直接孩子，但仍在子树中）。旅人从 `1` 出发直接前往 `2`，然后停下，访问 `1` 和 `2`，共 $2$ 座城市，$f(1)=1+f(2)=2$。

最终输出依次为 $f(1), f(2), f(3)$ 即 `2 1 2`。

## 样例3

**输入**

```
5
1 2
1 3
2 4
2 5
```

**输出**

```
3 2 1 1 1
```

**说明**

树以 `1` 为根，孩子为 `2` 和 `3`；`2` 的孩子为 `4` 和 `5`。叶子节点 `3`、`4`、`5` 均无指示，访问数均为 $1$。

- 城市 `2`：子树包含 $\{2,4,5\}$，除自身外最小的是 `4`（$4<5$），因此指示前往 `4`。访问路径为 $2 \to 4$，访问总数 $f(2)=1+f(4)=2$。
- 城市 `1`：子树包含 $\{1,2,3,4,5\}$，除自身外最小的是 `2`，指示前往 `2`。随后从 `2` 再前往 `4`，最后停下。访问路径为 $1 \to 2 \to 4$，访问总数 $f(1)=1+f(2)=3$。

最终从 `1` 到 `5` 的输出为 `3 2 1 1 1`。
