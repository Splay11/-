# 题目内容
给定两个长度为 $n$ 的排列 $a$ 与 $b$。子段指连续一段元素构成的序列。档案库会记录这两个排列的全部非空子段，但相同的子段只保存一次。

请计算档案库最终保存的不同子段个数。

排列长度不超过 `2×10^5`。

# 输入描述
第一行一个正整数 $n$（$1 \le n \le 2 \times 10^5$），表示排列长度。
第二行 $n$ 个正整数，表示排列 $a$。
第三行 $n$ 个正整数，表示排列 $b$。

# 输出描述
输出一个整数，表示不同子段的个数。

## 样例1

**输入**

```
2
1 2
2 1
```

**输出**

```
4
```
