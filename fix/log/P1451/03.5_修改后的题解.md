## 解题思路

本题与「双谱去重」描述的计算任务一致。按输入格式读入数据后，沿用原题解的算法即可。

详见下方代码实现。

## 代码实现

### Python

```python
def get(x):
    return x * (x + 1) // 2

def main():
    maxn = int(2e5) + 10

    n = int(input())
    a = [0] * maxn
    b = [0] * maxn
    ida = [0] * maxn
    idb = [0] * maxn

    a_input = list(map(int, input().split()))
    b_input = list(map(int, input().split()))

    for i in range(1, n + 1):
        a[i] = a_input[i - 1]
        ida[a[i]] = i
    for i in range(1, n + 1):
        b[i] = b_input[i - 1]
        idb[b[i]] = i

    ans = n * n + n
    r = 1

    while r <= n:
        l = ida[b[r]]
        cnt = 0
        while l <= n and r <= n and a[l] == b[r]:
            l += 1
            r += 1
            cnt += 1
        ans -= get(cnt)

    print(ans)

if __name__ == "__main__":
    main()
```
