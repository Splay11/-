# 题目内容
值班侧从线上日志里抽出一段仅含小写英文字母的关键词流水，准备交给关联分析模块。识别器只会捕获连续三个字符恰好为 `you` 的片段，并希望这类片段尽可能多，以便后续统计共现更稳。现在允许把整段流水任意重排，但不改变每个字母的出现次数。

请给出一种重排方案，使作为连续子串出现的 `you` 最多。若存在多种合法方案，输出任意一种即可。

约束：字符串长度不超过 `100000`，且仅由小写英文字母组成。

# 输入描述
第一行包含一个仅由小写英文字母组成的字符串 $s$，其长度 $n$ 满足 $1 \le n \le 100000$。

# 输出描述
输出一个字符串，表示重排后的关键词流水。若有多解，输出任意一种。

## 样例1

**输入**

```
abcyoux
```

**输出**

```
youabcx
```

**说明**

字符 `y`、`o`、`u` 各出现 `1` 次，因此最多可以拼出 `1` 段连续的 `you`。

一种合法方案是先写出 `you`，再按剩余字母 `a`、`b`、`c`、`x` 依次拼接，得到 `youabcx`。

## 样例2

**输入**

```
zzzz
```

**输出**

```
zzzz
```

**说明**

字符串中没有 `y`、`o`、`u`，无法形成连续片段 `you`。

重排后仍为 `zzzz`，连续 `you` 的个数为 `0`。

## 样例3

**输入**

```
yoyouuabc
```

**输出**

```
youyouabc
```

**说明**

字符 `y`、`o`、`u` 各出现 `2` 次，最多可拼出 `2` 段连续的 `you`。

先写出 `youyou`，剩余字母为 `a`、`b`、`c`，得到 `youyouabc`。

## 样例4

**输入**

```
o
```

**输出**

```
o
```

**说明**

只有一个字符 `o`，无法拼出 `you`，答案即为 `o`。
