# 题目内容
小美最近对字符串的奇特组合性质产生了兴趣。对于一个仅由小写英文字母组成的字符串，定义它的“互异连续子串集”为：取出该字符串的所有连续子串，将内容完全相同的子串视为同一个，最终构成的集合。

现在，她想要请你帮忙构造一个长度为 $n$ 的字符串，使得在它的互异连续子串集中，长度为奇数的子串的个数恰好为奇数。如果存在多种方案，输出任意一个即可。

**约束条件**

- 测试数据组数 $T$ 满足 $1 \le T \le 100$。
- 每组数据中要求的字符串长度 $n$ 满足 $1 \le n \le 2000$。
- 所有测试数据的 $n$ 之和不超过 $2000$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据的组数。
接下来 $T$ 行，每行包含一个整数 $n$，表示需要构造的字符串的长度。

# 输出描述
对于每组测试数据，输出一行一个长度为 $n$ 的字符串，由小写英文字母 `a` 至 `z` 构成。

## 样例1

**输入**

```
1
1
```

**输出**

```
a
```

**说明**

长度为 `1` 的字符串 `"a"` 的互异连续子串仅有 `"a"`，长度为 `1`（奇数），因此奇数长度子串个数为 `1`，是奇数，满足要求。

## 样例2

**输入**

```
1
2
```

**输出**

```
aa
```

**说明**

字符串 `"aa"` 的所有连续子串为 `"a"`, `"a"`, `"aa"`，互异集合为 $\{a, aa\}$。其中长度为奇数的子串只有 `"a"`（长度 `1`），总数为 `1`，是奇数，满足要求。

## 样例3

**输入**

```
1
3
```

**输出**

```
aab
```

**说明**

字符串 `"aab"` 的连续子串共有 `"a"`, `"a"`, `"b"`, `"aa"`, `"ab"`, `"aab"`，互异集合为 $\{a, b, aa, ab, aab\}$。长度为奇数的子串包括 `"a"`, `"b"`（长度 `1`）和 `"aab"`（长度 `3`），总数为 `3`，是奇数，满足要求。

## 样例4

**输入**

```
1
4
```

**输出**

```
abac
```

**说明**

字符串 `"abac"` 的所有连续子串为 `"a"`, `"b"`, `"a"`, `"c"`, `"ab"`, `"ba"`, `"ac"`, `"aba"`, `"bac"`, `"abac"`。互异集合为 $\{a, b, c, ab, ba, ac, aba, bac, abac\}$。其中长度为奇数的子串有 `"a"`, `"b"`, `"c"`（长度 `1`）以及 `"aba"`, `"bac"`（长度 `3`），总数为 `5`，是奇数，满足要求。
