# 题目内容
图书馆的书架上依次摆放着 $n$ 本书，每本书都有一个分类编号。图书管理员计划对书架进行整理，她希望让书架上连续的一段位置上的书全都属于同一个分类。她最多可以进行 $k$ 次操作，每次操作可以选择任意一本书，并将其分类编号改为任意一个已有的分类。最终，她想要知道在最多使用 $k$ 次操作的情况下，能够得到的、分类完全相同的最长连续书段的长度是多少。注意：操作次数可以少于 $k$，也可以一次都不进行。

书架上的书本数量 $n$ 和分类种类数 $m$ 均不超过 $2 \times 10^5$，允许修改的次数 $k$ 满足 $0 \le k \le n$。每本书原本的分类编号均为 $1$ 到 $m$ 之间的整数。

# 输入描述
第一行包含三个整数 $n$、$m$ 和 $k$，分别表示书本的数量、分类种类的数量以及最多允许修改的书本数量。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$，依次表示每本书原本的分类编号。

# 输出描述
输出一个整数，表示经过不超过 $k$ 次修改后，所能得到的最长连续相同分类的书本数量。

## 样例1

**输入**

```
5 3 1
1 2 2 2 1
```

**输出**

```
4
```

**说明**

可以将第 `1` 本书的分类编号从 $1$ 修改为 $2$，修改后书架上的分类依次为 $2,2,2,2,1$，此时前 $4$ 本书分类相同，长度为 $4$。也可以修改第 $5$ 本书的 $1$ 为 $2$，同样能得到长度为 $4$ 的连续段。由于最多允许 $k=1$ 次修改，这是能够达到的最大长度。

## 样例2

**输入**

```
4 2 0
1 1 2 2
```

**输出**

```
2
```

**说明**

当 $k=0$ 时，不允许进行任何修改。书架原本有两本连续的 $1$ 和两本连续的 $2$，因此最长的连续相同分类段长度为 $2$。

## 样例3

**输入**

```
3 5 3
1 2 3
```

**输出**

```
3
```

**说明**

允许修改的次数 $k=3$ 等于书本总数，可以将所有书全部改成同一个分类（例如全部改为 $1$）。此时整个书架上的 $3$ 本书分类完全相同，长度达到 $3$。
