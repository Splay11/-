# 题目内容
给定一个长度为 $n$ 的字符串 $s$（下标从 $1$ 开始），每个字符为英文字母，分为**高位形态**（即 `'A'` 到 `'Z'`）和**低位形态**（即 `'a'` 到 `'z'`）。定义一种变换规则，按下标从小到大的顺序依次处理每个字符 $s_i$：

- 若 $i = 1$，将 $s_1$ 的形态翻转（高位变低位，低位变高位）。
- 若 $i \ge 2$，比较 $s_i$ 与**原始字符串**中的 $s_{i-1}$ 的形态是否不同：
  - 若两者形态不同，则将 $s_i$ 的形态翻转；
  - 否则，将 $s_i$ 在同形态下后移一位（循环：$\tt{'z'} \to \tt{'a'}$，$\tt{'Z'} \to \tt{'A'}$）。

注意：判定形态异同时，总是使用原始字符串中对应位置的字符形态，而非修改后的形态。

字符串的长度 $n$ 不超过 $2 \times 10^5$，且字符串仅由大小写英文字母组成。

# 输入描述
第一行包含一个整数 $n$ $(1 \le n \le 2 \times 10^5)$，表示字符串的长度。
第二行包含一个长度为 $n$ 的字符串 $s$，仅由英文字母组成。

# 输出描述
输出一行一个长度为 $n$ 的字符串，表示按照规则变换后的结果。

## 样例1

**输入**

```
1
z
```

**输出**

```
Z
```

**说明**

字符串长度为 `1`，只包含字符 `z`。
根据规则 $i=1$，直接将 $s_1$ 的形态翻转。`z` 为低位形态，翻转为高位 `Z`。

## 样例2

**输入**

```
3
AAa
```

**输出**

```
aBA
```

**说明**

逐字符处理：
- $i=1$：`A` 形态翻转为 `a`。
- $i=2$：原串中 $s_1=$ `A`，$s_2=$ `A`，两者均为高位，形态相同，将 $s_2$ 在同形态下后移一位，`A` 变为 `B`。
- $i=3$：原串中 $s_2=$ `A`（高位），$s_3=$ `a`（低位），形态不同，将 $s_3$ 翻转为 `A`。
最终结果为 `aBA`。

## 样例3

**输入**

```
5
ZZzzA
```

**输出**

```
zAZaa
```

**说明**

逐字符处理：
- $i=1$：`Z` 翻转为 `z`。
- $i=2$：原串 $s_1=$ `Z` 与 $s_2=$ `Z` 同为高位，形态相同，$s_2$ 后移一位，`Z` 循环后移为 `A`。
- $i=3$：原串 $s_2=$ `Z`（高位）与 $s_3=$ `z`（低位）形态不同，$s_3$ 翻转为 `Z`。
- $i=4$：原串 $s_3=$ `z` 与 $s_4=$ `z` 同为低位，形态相同，$s_4$ 后移一位，`z` 循环后移为 `a`。
- $i=5$：原串 $s_4=$ `z`（低位）与 $s_5=$ `A`（高位）形态不同，$s_5$ 翻转为 `a`。
最终得到 `zAZaa`。
