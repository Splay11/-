# 题目内容
有一个初始值为 `0` 的状态寄存器，以及 $n$ 个只能使用一次的权限模块。第 $i$ 个模块有上限 $a_i$，使用它可以把当前值 $k$ 更新为 $k \mid x$，其中 $x$ 是满足 $0 \le x \le a_i$ 的任意整数，$\mid$ 表示按位或。也可以放弃某些模块不用。

请计算最终状态能达到的最大值。

本题有多组测试数据。

约束条件：
- 测试组数 $T$ 满足 $1 \le T \le 10^4$；
- 每组模块个数 $n$ 满足 $1 \le n \le 2 \times 10^5$；
- 每个上限满足 $0 \le a_i \le 10^9$；
- 所有测试数据中 $n$ 的总和不超过 $2 \times 10^5$。

# 输入描述
第一行包含一个正整数 $T$（$1 \le T \le 10^4$），表示测试组数。
对每组测试数据：第一行包含一个正整数 $n$（$1 \le n \le 2 \times 10^5$），表示模块个数；第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$0 \le a_i \le 10^9$），表示各模块的上限。所有测试数据中 $n$ 的总和不超过 $2 \times 10^5$。

# 输出描述
输出共 $T$ 行。对每组测试数据输出一个整数，表示最终状态能达到的最大值。

## 样例1

**输入**

```
3
4
1 2 2 8
3
0 5 2
2
2 2
```

**输出**

```
11
7
3
```

**说明**

第一组：可分别取 $1$、$2$、$8$，按位或为 $1\mid 2\mid 8=11$。

第二组：取 $5$ 与 $2$，得到 $5\mid 2=7$。

第三组：两个上限都是 `2`。一个取 `1`、另一个取 `2`，得到 $1\mid 2=3$。

## 样例2

**输入**

```
1
1
0
```

**输出**

```
0
```

**说明**

只有一个上限为 `0` 的模块，只能或上 `0`，答案为 `0`。
