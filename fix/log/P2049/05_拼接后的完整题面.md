# 题目内容
在古老符文魔法中，魔法师需要编织一条由 $n$ 枚符文组成的魔力链。每枚符文具有一个正整数魔力值，且后一枚的魔力必须严格大于前一枚。此外，整条链的“共鸣融合”魔力必须恰好等于给定的目标值 $k$。

共鸣融合的规则定义如下：对于两个非负整数，将它们按照二进制位进行逐位逻辑或运算，记作 $\oplus$。对于序列 $a_1, a_2, \dots, a_n$，其共鸣融合结果为 $a_1 \oplus a_2 \oplus \dots \oplus a_n$。

现在给定链的长度 $n$ 和目标值 $k$，请你构造一个魔力值序列 $a_1, a_2, \dots, a_n$ 满足：
- $0 < a_1 < a_2 < \dots < a_n \le 2^{60}$；
- $a_1 \oplus a_2 \oplus \dots \oplus a_n = k$。

如果存在这样的序列，请输出任意一组解；否则指出不存在。

约束：链的长度 $n$ 不超过 $10^5$，目标值 $k$ 满足 $0 \le k \le 2^{60}$。

# 输入描述
一行内输入两个整数 $n$ 和 $k$，用空格分隔。

# 输出描述
如果存在合法序列，第一行输出 `YES`，第二行输出 $n$ 个用空格分隔的整数表示魔力值序列（任意一组合法解均可）；否则输出 `NO`。

## 样例1

**输入**

```
2 0
```

**输出**

```
NO
```

**说明**

要求构造一个严格递增的正整数序列 $a_1 < a_2$，并满足 $a_1 \oplus a_2 = 0$。两个正整数按位异或的结果为 `0`，当且仅当它们完全相等。但这与严格递增的条件矛盾，因此不存在合法的序列。

## 样例2

**输入**

```
1 5
```

**输出**

```
YES
5
```

**说明**

当 $n = 1$ 时，序列只有一个元素 $a_1$。只需令 $a_1 = k = 5$ 即可。`5` 是正整数且不超过 $2^{60}$，满足所有约束。

## 样例3

**输入**

```
3 3
```

**输出**

```
YES
1 4 6
```

**说明**

选取序列 `1 4 6`。验证如下：先计算 $1 \oplus 4 = 5$，再与 `6` 计算 $5 \oplus 6 = 3$，恰好等于目标值 $k = 3$。同时，`1` < `4` < `6` 严格递增，且均为正整数，满足要求。

## 样例4

**输入**

```
5 31
```

**输出**

```
YES
1 2 4 8 16
```

**说明**

选取序列 `1 2 4 8 16`。它们的二进制形式分别为 `00001`、`00010`、`00100`、`01000`、`10000`。将这些数按位异或，其结果正好是 `11111`，即十进制下的 $31$。序列严格递增，且所有数均远小于上界 $2^{60}$。
