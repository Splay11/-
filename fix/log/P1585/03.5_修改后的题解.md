## 解题思路

零件质量互不相同，因此最重、最轻各恰好一个。相邻交换可以把任意零件移动到任意位置，移动距离等于下标差。目标是让这两个极值分别占据下标 $0$ 与 $n-1$（$0$ 起始），谁在左端不限。

设最重零件的下标为 $p_{\max}$，最轻零件的下标为 $p_{\min}$。两种放置方案互不干扰地计算步数后取较小值即可：

* 最重到左端、最轻到右端：需要 $p_{\max} + (n-1-p_{\min})$ 次相邻交换；
* 最轻到左端、最重到右端：需要 $p_{\min} + (n-1-p_{\max})$ 次相邻交换。

若某种方案中两者的移动路径相交，该方案的真实代价还要再减 `1`（一次交换可同时推进两者）。可以证明相交方案绝不优于不相交方案，因此直接取上面两个量的最小值就是答案，无需再修正。

扫描一遍数组记录两个极值下标后，用 $O(1)$ 计算即可。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(n)$（若边读边维护极值下标，空间可降至 $O(1)$）。

## 代码实现

### Python

```python
n = int(input())
w = list(map(int, input().split()))

pmax = pmin = 0
for i, val in enumerate(w):
    if val > w[pmax]:
        pmax = i
    if val < w[pmin]:
        pmin = i

# 两种端点放置方案取较小相邻交换次数
ans = min(pmax + n - pmin - 1, pmin + n - pmax - 1)
print(ans)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int pmax = 0, pmin = 0;
        int mx = Integer.MIN_VALUE, mn = Integer.MAX_VALUE;
        for (int i = 0; i < n; i++) {
            int cur = in.nextInt();
            if (cur > mx) {
                mx = cur;
                pmax = i;
            }
            if (cur < mn) {
                mn = cur;
                pmin = i;
            }
        }
        int ans = Math.min(pmax + n - pmin - 1, pmin + n - pmax - 1);
        System.out.println(ans);
    }
}
```

}
