# 题目内容
流水线上依次摆放着 $n$ 个零件，第 $i$ 个零件的质量为 $w_i$，且所有质量互不相同。因此存在唯一的最重零件和唯一的最轻零件。

需要把最重零件与最轻零件分别调整到流水线的两端（谁在左端、谁在右端均可）。每次操作可以交换相邻两个零件的位置。

请计算完成调整所需的最少相邻交换次数。

零件个数不超过 `10^5`，每个零件的质量为正整数且不超过 `10^9`，且两两不同。

# 输入描述
第一行包含一个整数 $n$，表示零件个数，满足 $1 \le n \le 10^5$。
第二行包含 $n$ 个互不相同的正整数 $w_1, w_2, \ldots, w_n$，表示各零件的质量，满足 $1 \le w_i \le 10^9$。

# 输出描述
输出一个整数，表示让最重零件与最轻零件分别位于两端所需的最少相邻交换次数。

## 样例1

**输入**

```
5
3 8 1 6 4
```

**输出**

```
3
```

**说明**

最重零件质量为 `8`，位于位置 `2`（从 `1` 计）；最轻零件质量为 `1`，位于位置 `3`。
将最重移到左端、最轻移到右端需要 $1+(5-3)=3$ 次相邻交换；将最轻移到左端、最重移到右端需要 $2+(5-2)=5$ 次。
取较小值，答案为 `3`。

## 样例2

**输入**

```
1
10
```

**输出**

```
0
```

**说明**

只有一个零件，它同时处于两端，无需任何交换，答案为 `0`。

## 样例3

**输入**

```
4
10 20 5 15
```

**输出**

```
2
```

**说明**

最重为 `20`（位置 `2`），最轻为 `5`（位置 `3`）。
最重左移、最轻右移需要 `2` 次；另一方向需要 `4` 次。最少交换次数为 `2`。

## 样例4

**输入**

```
2
1 2
```

**输出**

```
0
```

**说明**

两个零件已分别位于两端，答案为 `0`。
