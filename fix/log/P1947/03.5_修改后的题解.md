## 解题思路

每次询问给出正整数 $x$、$y$ 和运算符 $op$，需要比较 $x\ op\ y$ 与 $y\ op\ x$ 的大小，输出 `>`、`<` 或 `=`。

按运算符分类处理：

1. **加法 `+` 与乘法 `*`**：交换律成立，两个结果恒等，直接输出 `=`。
2. **减法 `-`**：比较 $x-y$ 与 $y-x$，等价于比较 $x$ 与 $y$ 本身。
3. **除法 `/`**：在 $x,y>0$ 时，比较 $x/y$ 与 $y/x$ 同样等价于比较 $x$ 与 $y$。
4. **乘方 `^`**：需要比较 $x^{y}$ 与 $y^{x}$。直接幂次会溢出，对两边取常用对数后改为比较
   $$
   y\log_{10} x \quad\text{与}\quad x\log_{10} y.
   $$
   当 $x=`1`$ 时，$1^{y}=1$、$y^{1}=y$，直接比较 $1$ 与 $y$；当 $y=`1`$ 时同理比较 $x$ 与 $1$。这样也可避开对底数为 `1` 取对数时的退化。

对每组询问按上述规则判定并输出一行。

## 复杂度分析

时间复杂度 $O(t)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
import math

t = int(input())


def check(u, v):
    if u == v:
        return "="
    if u > v:
        return ">"
    return "<"


for _ in range(t):
    x, y, op = input().split()
    x, y = int(x), int(y)
    if op == "+":
        print(check(x + y, y + x))
    elif op == "-":
        print(check(x - y, y - x))
    elif op == "*":
        print(check(x * y, y * x))
    elif op == "/":
        print(check(x / y, y / x))
    else:
        # 乘方：1 作为底数时直接比较，否则比较 y*log(x) 与 x*log(y)
        if x == 1:
            left, right = 1, y
        elif y == 1:
            left, right = x, 1
        else:
            left = y * math.log10(x)
            right = x * math.log10(y)
        print(check(left, right))
```

### Java

```java
import java.util.Scanner;

public class Main {
    static String check(double u, double v) {
        if (u == v) return "=";
        if (u > v) return ">";
        return "<";
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int t = in.nextInt();
        for (int i = 0; i < t; i++) {
            long x = in.nextLong();
            long y = in.nextLong();
            String op = in.next();
            if (op.equals("+") || op.equals("*")) {
                System.out.println("=");
            } else if (op.equals("-") || op.equals("/")) {
                if (x == y) System.out.println("=");
                else if (x > y) System.out.println(">");
                else System.out.println("<");
            } else { // ^
                if (x == 1) {
                    System.out.println(y > 1 ? "<" : "=");
                } else if (y == 1) {
                    System.out.println(">");
                } else {
                    double left = y * Math.log10(x);
                    double right = x * Math.log10(y);
                    System.out.println(check(left, right));
                }
            }
        }
    }
}
```

### C++

```cpp
#include <cmath>
#include <iostream>
using namespace std;

char check(double u, double v) {
    if (u > v) return '>';
    if (u < v) return '<';
    return '=';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        long long x, y;
        char op;
        cin >> x >> y >> op;
        if (op == '+' || op == '*') {
            cout << "=\n";
        } else if (op == '-' || op == '/') {
            if (x == y) cout << "=\n";
            else if (x > y) cout << ">\n";
            else cout << "<\n";
        } else { // ^
            if (x == 1) {
                cout << (y > 1 ? "<\n" : "=\n");
            } else if (y == 1) {
                cout << ">\n";
            } else {
                double left = (double)y * log10((double)x);
                double right = (double)x * log10((double)y);
                cout << check(left, right) << '\n';
            }
        }
    }
    return 0;
}
```
