# 题目内容
实验室要对一批二元运算做镜面核对。每次给定两个正整数 $x$、$y$ 以及一个运算符 $op$。先计算 $x\ op\ y$，再把两个操作数对调后计算 $y\ op\ x$，比较这两个结果的大小。

运算符 $op$ 只可能是下列五种之一：`+` 表示加法，`-` 表示减法，`*` 表示乘法，`/` 表示除法，`^` 表示乘方（即比较 $x^{y}$ 与 $y^{x}$）。

若 $x\ op\ y$ 更大，记为 `>`；若 $y\ op\ x$ 更大，记为 `<`；两者相等则记为 `=`。

询问组数不超过 `10^4`，两个操作数均为不超过 `10^9` 的正整数。

# 输入描述
第一行包含一个整数 $t$，表示询问组数，满足 $1 \le t \le 10^4$。
接下来 $t$ 行，每行包含两个正整数 $x$、$y$ 和一个字符 $op$，表示一次询问，满足 $1 \le x,y \le 10^9$，且 $op$ 为 `+`、`-`、`*`、`/`、`^` 中的一个。保证除法运算的除数不为 `0`。

# 输出描述
输出 $t$ 行。对每组询问输出一个字符：`>` 表示 $x\ op\ y$ 更大，`<` 表示 $y\ op\ x$ 更大，`=` 表示两者相等。

## 样例1

**输入**

```
5
3 5 +
7 2 -
4 4 *
9 3 /
1 5 ^
```

**输出**

```
=
>
=
>
<
```

**说明**

共 `5` 组询问。
加法：$3+5=8$，$5+3=8$，两者相等，输出 `=`。
减法：$7-2=5$，$2-7=-5$，前者更大，输出 `>`。
乘法：$4 \times 4 = 4 \times 4$，输出 `=`。
除法：$9/3=3$，$3/9=1/3$，前者更大，输出 `>`。
乘方：$1^{5}=1$，$5^{1}=5$，后者更大，输出 `<`。

## 样例2

**输入**

```
3
2 2 ^
5 1 ^
8 3 -
```

**输出**

```
=
>
>
```

**说明**

第一组底数与指数相同，$2^{2}=2^{2}$，输出 `=`。
第二组：$5^{1}=5$，$1^{5}=1$，前者更大，输出 `>`。
第三组：$8-3=5$，$3-8=-5$，前者更大，输出 `>`。

## 样例3

**输入**

```
4
10 10 +
1 1 ^
6 2 /
2 9 -
```

**输出**

```
=
=
>
<
```

**说明**

加法交换律成立，输出 `=`。
$1^{1}=1^{1}$，输出 `=`。
$6/2=3$，$2/6=1/3$，前者更大，输出 `>`。
$2-9=-7$，$9-2=7$，后者更大，输出 `<`。
