# 题目内容
给定一个只含字符 `0` 和 `1` 的字符串 $s$。一次操作可以选择两个相邻下标，并把这两个位置上的字符各自对 `1` 做异或：`0` 变为 `1`，`1` 变为 `0`。
请判断是否存在若干次操作（可以为零次），使得 $s$ 变成全 `0` 串或全 `1` 串。

约束条件：
- 字符串 $s$ 的长度为正整数，且不超过 $10^6$。
- $s$ 仅由字符 `0` 和 `1` 组成。

# 输入描述
输入一行，包含一个只含字符 `0` 和 `1` 的字符串 $s$。

# 输出描述
若可以将 $s$ 变为全 `0` 串或全 `1` 串，输出 `yes`；否则输出 `no`。

## 样例1

**输入**

```
010
```

**输出**

```
yes
```

**说明**

对下标 `1` 与 `2`（`1`-based）做一次操作：`010` 变为 `001`，再对下标 `2` 与 `3` 操作变为 `010` 的另一种路径。
从左到右把每位改成 `1`：第一位 `0` 需与第二位一起翻转得到 `100`，再翻转后两位得到 `111`。
可以变成全 `1` 串，输出 `yes`。

## 样例2

**输入**

```
0001
```

**输出**

```
no
```

**说明**

无论目标是全 `0` 还是全 `1`，从左到右强制翻转后，最后一位都无法与目标一致。
因此输出 `no`。

## 样例3

**输入**

```
0
```

**输出**

```
yes
```

**说明**

长度为 `1` 的串 `0` 已经是全 `0` 串，无需操作，输出 `yes`。

## 样例4

**输入**

```
01
```

**输出**

```
no
```

**说明**

长度为 `2` 时，一次操作会同时翻转两位：`01` 只能变成 `10`，再操作又变回 `01`。
无法得到 `00` 或 `11`，输出 `no`。
