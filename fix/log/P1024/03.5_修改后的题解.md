## 解题思路

一次操作同时翻转两个相邻字符，等价于把这两位各自异或 `1`。

从左到右贪心：若要把字符串变成全 $c$（$c$ 为 `0` 或 `1`），则遇到第 $i$ 位不等于 $c$ 时，必须翻转第 $i$ 位与第 $i+1$ 位。处理完前 $n-1$ 位后，只需检查最后一位是否等于 $c$。

分别尝试目标全 `0` 与全 `1`，只要有一种成功就输出 `yes`，否则输出 `no`。注意两次尝试应作用在原串的副本上，避免互相干扰。

## 复杂度分析

时间复杂度 $O(|s|)$，空间复杂度 $O(|s|)$。

## 代码实现

### Python

```python
def check(src, flag):
    s = src[:]
    for i in range(len(s) - 1):
        if s[i] == flag:
            continue
        s[i] = '0' if s[i] == '1' else '1'
        s[i + 1] = '0' if s[i + 1] == '1' else '1'
    return s[-1] == flag

s = list(input().strip())
if check(s, '0') or check(s, '1'):
    print("yes")
else:
    print("no")
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static boolean check(String x, char flag) {
        char[] s = x.toCharArray();
        for (int i = 0; i + 1 < s.length; i++) {
            if (s[i] == flag) continue;
            s[i] = (s[i] == '1') ? '0' : '1';
            s[i + 1] = (s[i + 1] == '1') ? '0' : '1';
        }
        return s[s.length - 1] == flag;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String s = scanner.next();
        if (check(s, '1') || check(s, '0')) {
            System.out.println("yes");
        } else {
            System.out.println("no");
        }
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
using namespace std;

bool check(string s, char flag) {
    for (int i = 0; i + 1 < (int)s.size(); i++) {
        if (s[i] == flag) continue;
        s[i] = (s[i] == '1') ? '0' : '1';
        s[i + 1] = (s[i + 1] == '1') ? '0' : '1';
    }
    return s.back() == flag;
}

int main() {
    string s;
    cin >> s;
    if (check(s, '1') || check(s, '0')) cout << "yes" << endl;
    else cout << "no" << endl;
    return 0;
}
```
