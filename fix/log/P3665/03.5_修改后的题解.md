## 解题思路

把 $n$ 拆成若干质数之和，求最短长度 $m$。由哥德巴赫猜想在本题范围内已验证成立，可按 $m$ 从小到大分类：

1. 若 $n$ 本身是质数，则 $m=1$。用试除法判断，检查 $2$ 到 $\sqrt{n}$ 即可。
2. 若 $n$ 是大于 `2` 的偶数，则可写成两个质数之和，故 $m=2$。
3. 若 $n$ 是奇数：若 $n-2$ 是质数，则 $n=2+(n-2)$，故 $m=2$；否则 $n-3$ 是大于 `2` 的偶数，可再拆成两个质数，于是 $m=3$。

因此答案只可能是 `1`、`2` 或 `3`。

## 复杂度分析

质数判定的试除次数约为 $\sqrt{n}$。

- 时间复杂度：$O(\sqrt{n})$。
- 空间复杂度：$O(1)$。

## 代码实现

### Python

```python
import math

def is_prime(n: int) -> bool:
    if n < 2:
        return False
    for i in range(2, int(math.sqrt(n)) + 1):
        if n % i == 0:
            return False
    return True

def solve():
    n = int(input())
    if is_prime(n):
        print(1)
        return
    if n % 2 == 0:
        print(2)
        return
    if is_prime(n - 2):
        print(2)
    else:
        print(3)

solve()
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static boolean isPrime(long n) {
        if (n < 2) {
            return false;
        }
        for (long i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                return false;
            }
        }
        return true;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        long n = scanner.nextLong();
        if (isPrime(n)) {
            System.out.println(1);
        } else if (n % 2 == 0) {
            System.out.println(2);
        } else {
            if (isPrime(n - 2)) {
                System.out.println(2);
            } else {
                System.out.println(3);
            }
        }
        scanner.close();
    }
}
```
