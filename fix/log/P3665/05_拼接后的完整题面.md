# 题目内容
给定一个正整数 $n$。需要把它拆成若干个正整数之和，且每一项都是质数。请找出满足条件的最短拆分长度，即最少需要几项。

约束：$n$ 不超过 `10^9`，且 $n$ 至少为 `2`。

# 输入描述
一行一个整数 $n$。
保证 $2 \le n \le 10^9$。

# 输出描述
输出一个整数，表示最短拆分长度。

## 样例1

**输入**

```
4
```

**输出**

```
2
```

**说明**

`4` 是大于 `2` 的偶数，可写成两个质数之和 $2+2$，答案为 `2`。

## 样例2

**输入**

```
5
```

**输出**

```
1
```

**说明**

按题意模拟计算得到。

## 样例3

**输入**

```
6
```

**输出**

```
2
```

**说明**

按题意模拟计算得到。
