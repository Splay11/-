# 题目内容

找到一个最小的$m$，使得存在一个正整数序列 {$a_1,a_2,...,a_m$}，满足：

- $a_1+a_2+...+a_m=n$

- $a$ 中的每个元素都是质数。

# 输入描述

输入一行一个整数 $n(2 ≦n≦10^9)$ 。



# 输出描述

输出一行一个整数，代表最小的满足条件的 $m$ 。



## 样例1 



**输入** 



```
9
```



**输出** 



```
2
```



**说明**

可以构造 $a=${$7,2$}，其中 $7+2=9$ ，且 $7$ 和 $2$ 都为质数。

可以证明不存在长度小于 $2$ 的满足条件的序列。



## 样例2



**输入** 



```
2
```



**输出** 



```
1
```





## 样例3

**输入**

```
27
```



**输出**

