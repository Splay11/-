# 题目内容
影视后期组有一条长度为 $n$、仅由大小写英文字母组成的字幕轨 $s$（下标为 `0` 到 $n-1$）。校对脚本会下发 $m$ 条立即生效的指令，每条指令必须按输入顺序执行，不能缓存、不能重排。指令只有两种写法，且字面形式固定如下。

- 字符串 `toLowerCase(x)`，其中 $x \in [0,n-1]$，把 $s_x$ 改成对应小写字母（若已是小写则不变）；
- 字符串 `toUpperCase(x)`，其中 $x \in [0,n-1]$，把 $s_x$ 改成对应大写字母（若已是大写则不变）。

请输出全部指令执行完后的字幕轨。

约束：字符串长度与指令条数均不超过 `200000`。

# 输入描述
第一行两个整数 $n$ 和 $m$，表示字幕轨长度与指令条数。
第二行一个长度为 $n$、仅含大小写英文字母的字符串 $s$。
此后 $m$ 行，每行一个字符串，形式为 `toLowerCase(x)` 或 `toUpperCase(x)`，其中 $x$ 为整数且 $0 \le x \le n-1$。
保证 $1 \le n,m \le 200000$。

# 输出描述
输出一行字符串，表示全部指令执行后的结果。

## 样例1

**输入**

```
4 3
AbCd
toUpperCase(1)
toLowerCase(0)
toUpperCase(3)
```

**输出**

```
aBCD
```

**说明**

初始串为 `AbCd`。

- `toUpperCase(1)`：位置 `1` 的 `'b'` 变为 `'B'`，得到 `ABCd`；
- `toLowerCase(0)`：位置 `0` 的 `'A'` 变为 `'a'`，得到 `aBCd`；
- `toUpperCase(3)`：位置 `3` 的 `'d'` 变为 `'D'`，得到 `aBCD`。

## 样例2

**输入**

```
1 1
z
toLowerCase(0)
```

**输出**

```
z
```

**说明**

只有一个字符 `'z'`，对其执行 `toLowerCase(0)` 后仍为 `'z'`。

## 样例3

**输入**

```
3 2
XYZ
toLowerCase(0)
toUpperCase(2)
```

**输出**

```
xYZ
```

**说明**

`toLowerCase(0)` 把 `'X'` 变成 `'x'`，`toUpperCase(2)` 时 `'Z'` 已是大写，保持不变，结果为 `xYZ`。
