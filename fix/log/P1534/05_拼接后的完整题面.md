# 题目内容
给定一棵树，每个结点都带有一个能量值，该值只可能是 $3$ 或 $5$。对于树上的一条简单路径，定义该路径的共鸣能量为：若路径上所有结点的能量值全为 $3$，则共鸣能量为 $3$；若全为 $5$，则共鸣能量为 $5$；若路径上同时出现 $3$ 和 $5$，则共鸣能量为 $15$。

试求树上所有简单路径的共鸣能量之和。

结点数量 $n$ 不超过 $10^5$，所有结点的能量值只可能是 $3$ 或 $5$。

# 输入描述
第一行包含一个整数 $n$，表示树的结点数量。
第二行包含 $n$ 个整数，第 $i$ 个整数 $a_i$ 表示第 $i$ 个结点的能量值，保证 $a_i$ 只可能是 $3$ 或 $5$。
接下来 $n-1$ 行，每行包含两个整数 $u_i$ 和 $v_i$，表示结点 $u_i$ 与结点 $v_i$ 之间有一条边。

# 输出描述
输出一个整数，表示所有简单路径的共鸣能量之和。

## 样例1

**输入**

```
1
3
```

**输出**

```
3
```

**说明**

树中只有 `1` 个结点，其能量为 $3$。
简单路径仅有一条，即结点 `1` 到自身的路径，该路径上所有结点的能量值全为 $3$，共鸣能量为 $3$。
因此和为 $3$。

## 样例2

**输入**

```
2
3 5
1 2
```

**输出**

```
15
```

**说明**

树中有 `2` 个结点，结点 `1` 的能量为 $3$，结点 `2` 的能量为 $5$。
简单路径共有两条：
- 路径 `1`$\to$`1`：仅含结点 `1`，能量全为 $3$，共鸣能量为 $3$。
- 路径 `2`$\to$`2`：仅含结点 `2`，能量全为 $5$，共鸣能量为 $5$。
- 路径 `1`$\to$`2`：同时包含能量 $3$ 和 $5$，共鸣能量为 $15$。

所有路径的共鸣能量之和为 $3+5+15=23$。
（注意：题目中的简单路径通常包含起点和终点之间的所有结点，长度为 $0$ 的路径即单结点路径也计算在内。）

## 样例3

**输入**

```
3
3 3 3
1 2
2 3
```

**输出**

```
18
```

**说明**

树是一条链，结点能量全部为 $3$。
简单路径共有 $\frac{3 \times 4}{2} = 6$ 条，具体为：
- 单结点路径 `1`$\to$`1`、`2`$\to$`2`、`3`$\to$`3`。
- 双结点路径 `1`$\to$`2`、`2`$\to$`3`。
- 三结点路径 `1`$\to$`2`$\to$`3`。

由于所有结点能量均为 $3$，每条路径上的能量值全为 $3$，共鸣能量均为 $3$。
总和为 $6 \times 3 = 18$。

## 样例4

**输入**

```
4
5 5 3 5
1 2
2 3
3 4
```

**输出**

```
98
```

**说明**

树是一条链：`1`$-$`2`$-$`3`$-$`4`，对应能量依次为 $5, 5, 3, 5$。
所有简单路径及其共鸣能量如下：
- 单结点：`1`（$5$）、`2`（$5$）、`3`（$3$）、`4`（$5$）。
- 双结点：`1`$-$`2`（全 $5$，能量 $5$）、`2`$-$`3`（混合 $5,3$，能量 $15$）、`3`$-$`4`（混合 $3,5$，能量 $15$）。
- 三结点：`1`$-$`2`$-$`3`（混合，$15$）、`2`$-$`3`$-$`4`（混合，$15$）。
- 四结点：`1`$-$`2`$-$`3`$-$`4`（混合，$15$）。

将所有共鸣能量相加：$5+5+3+5+5+15+15+15+15+15=98$。
