# 题目内容
要把编号 $0, 1, \ldots, n-1$ 各使用一次，排成长度为 $n$ 的序列 $a$。对任意连续片段 $a_l, a_{l+1}, \ldots, a_r$，定义它的空号为该片段中未出现的最小非负整数。

请最大化所有连续片段的空号之和，即最大化 $\displaystyle \sum_{1 \le l \le r \le n} \mathrm{vac}(a_l, \ldots, a_r)$，其中 $\mathrm{vac}$ 表示空号。输出这个最大值，以及任意一个达到该最大值的序列。

空号：对非负整数构成的集合 $S$，空号是不在 $S$ 中的最小非负整数。例如 $S=\{1,2\}$ 时空号为 `0`，$S=\{0,1,3\}$ 时空号为 `2`。

约束：测试组数不超过 `10^5`，单组 $n$ 不超过 `10^5`，且所有测试中 $n$ 的总和不超过 `2×10^5`。

# 输入描述
每个测试文件包含多组数据。第一行一个整数 $T$，表示数据组数。
每组数据一行，包含一个整数 $n$。
保证 $1 \le T \le 10^5$，$1 \le n \le 10^5$，且所有测试中 $n$ 的总和不超过 $2 \times 10^5$。

# 输出描述
对每组数据输出两行：
第一行一个整数，表示所有连续片段空号之和的最大值；
第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$，表示任意一个达到最大值的序列。若有多种方案，输出任意一种即可。

## 样例1

**输入**

```
3
1
2
3
```

**输出**

```
1
0
3
0 1
7
1 0 2
```

**说明**

当 $n=1$ 时，唯一序列为 $[0]$，仅有一个片段空号为 `1`，总和为 `1`。
当 $n=2$ 时，序列 $[0,1]$ 的三个片段空号分别为 `1`、`0`、`2`，总和为 `3`。
当 $n=3$ 时，构造 $[1,0,2]$ 可使总和达到 `7`。

## 样例2

**输入**

```
1
4
```

**输出**

```
13
2 0 1 3
```

**说明**

$n=4$ 为偶数，闭式 $n(n+2)(2n+5)/24=4 \times 6 \times 13 / 24=13$。
构造为左侧偶数降序、中间 `0`、右侧补齐，得到 $2,0,1,3$。

## 样例3

**输入**

```
2
5
6
```

**输出**

```
22
3 1 0 2 4
34
4 2 0 1 3 5
```

**说明**

$n=5$ 为奇数，闭式 $(n+1)(n+3)(2n+1)/24=6 \times 8 \times 11 / 24=22$，构造 $3,1,0,2,4$。
$n=6$ 为偶数，闭式 $6 \times 8 \times 17 / 24=34$，构造 $4,2,0,1,3,5$。
