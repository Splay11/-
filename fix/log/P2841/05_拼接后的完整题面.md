# 题目内容
装配车间用只含小写字母的字符串记录一条工艺路线：每个字母代表一种原料。质检规程规定，真正用来比对的「首现配方」是：从左到右扫描该串，每种原料只保留它第一次出现的那一次，得到的新串。两条工艺被判定为同源，当且仅当它们的首现配方完全相同。

质检员会提出多组询问，每组给出两条工艺字符串，请判断它们是否同源。

约束：询问组数 $T$ 满足 $1 \le T \le 10^3$，每个字符串只由小写字母组成且长度不超过 `100000`，单个测试文件中所有字符串的长度之和不超过 `100000`。

# 输入描述
第一行一个整数 $T$，表示询问组数。
接下来 $T$ 组，每组两行，每行一个只含小写字母的字符串，分别记为 $s_1$ 和 $s_2$。
保证 $1 \le T \le 10^3$，每个字符串长度不超过 `100000`，且文件内所有字符串长度之和不超过 `100000`。

# 输出描述
对每组询问输出一行：若两条工艺同源，输出 `YES`，否则输出 `NO`。

## 样例1

**输入**

```
3
xyzzy
xyyzx
hello
world
mississippi
misp
```

**输出**

```
YES
NO
YES
```

**说明**

第一组：`xyzzy` 与 `xyyzx` 的指纹都是 `xyz`，输出 `YES`。
第二组：`hello` 的指纹为 `helo`，`world` 的指纹为 `world`，输出 `NO`。
第三组：`mississippi` 与 `misp` 的指纹都是 `misp`，输出 `YES`。

## 样例2

**输入**

```
1
zzzz
z
```

**输出**

```
YES
```

**说明**

两个串的指纹都是 `z`，同源，输出 `YES`。

## 样例3

**输入**

```
2
qwerty
qwyert
unique
uniq
```

**输出**

```
NO
NO
```

**说明**

第一组指纹分别为 `qwerty` 与 `qwyert`，不同。
第二组 `unique` 的指纹为 `uniqe`，`uniq` 的指纹为 `uniq`，不同。两组均为 `NO`。
