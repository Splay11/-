## 解题思路

首现配方就是“每个小写字母只保留第一次出现，并保持相对顺序”。对字符串从左到右扫描，用长度为 `26` 的布尔数组标记字母是否已出现；未出现则追加到结果中。

对 $s_1$、$s_2$ 分别求首现配方后比较：相同则输出 `YES`，否则输出 `NO`。

## 复杂度分析

时间复杂度 $O(L)$，空间复杂度 $O(1)$ 额外标记数组（不计输入串），其中 $L$ 为所有字符串长度之和。

## 代码实现

### Python

```python
def remove_duplicates(s: str) -> str:
    visited = [False] * 26
    result = []
    for ch in s:
        idx = ord(ch) - ord('a')
        if not visited[idx]:
            result.append(ch)
            visited[idx] = True
    return "".join(result)

if __name__ == '__main__':
    T = int(input().strip())
    for _ in range(T):
        s1 = input().strip()
        s2 = input().strip()
        if remove_duplicates(s1) == remove_duplicates(s2):
            print("YES")
        else:
            print("NO")
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static String removeDuplicates(String s) {
        boolean[] visited = new boolean[26];
        StringBuilder result = new StringBuilder();
        for (char ch : s.toCharArray()) {
            int idx = ch - 'a';
            if (!visited[idx]) {
                result.append(ch);
                visited[idx] = true;
            }
        }
        return result.toString();
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();
        for (int i = 0; i < T; i++) {
            String s1 = sc.next();
            String s2 = sc.next();
            if (removeDuplicates(s1).equals(removeDuplicates(s2))) {
                System.out.println("YES");
            } else {
                System.out.println("NO");
            }
        }
        sc.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
using namespace std;

string removeDuplicates(const string &s) {
    bool visited[26] = {false};
    string result = "";
    for (char ch : s) {
        int idx = ch - 'a';
        if (!visited[idx]) {
            result.push_back(ch);
            visited[idx] = true;
        }
    }
    return result;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        string s1, s2;
        cin >> s1 >> s2;
        if (removeDuplicates(s1) == removeDuplicates(s2))
            cout << "YES" << "\n";
        else
            cout << "NO" << "\n";
    }
    return 0;
}
```
