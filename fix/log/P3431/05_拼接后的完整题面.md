# 题目内容
机房有 $n$ 台交换机，用 $n-1$ 条网线连成一棵树（连通无环）。以某台交换机 $r$ 为总控时，每台交换机 $u$ 管辖一棵子树：包含 $u$ 及其全部后代，该子树的规模定义为其中交换机的台数。

对每个可能的总控 $r=1,2,\ldots,n$，统计有多少台交换机的辖区规模为偶数。

交换机台数不超过 $10^5$。

# 输入描述
第一行包含一个整数 $n$，表示交换机台数，满足 $1 \le n \le 10^5$。
接下来 $n-1$ 行，每行两个整数 $u_i$ 和 $v_i$，表示一台交换机 $u_i$ 与 $v_i$ 之间有一条网线，满足 $1 \le u_i,v_i \le n$ 且 $u_i 
eq v_i$。保证这 $n-1$ 条边构成一棵树。

# 输出描述
输出 $n$ 行。第 $i$ 行一个整数，表示以第 $i$ 台交换机为总控时，辖区规模为偶数的交换机台数。

## 样例1

**输入**

```
5
1 2
2 3
3 4
4 5
```

**输出**

```
2
1
2
1
2
```

**说明**

拓扑是一条链 $1-2-3-4-5$。
以 `1` 为总控时，各点辖区规模为 $5,4,3,2,1$，偶数为 `2` 台；以 `2` 为总控时规模为 $1,5,3,2,1$，偶数为 `1` 台；以 `3` 为总控时为 `2` 台；以 `4` 为总控时为 `1` 台；以 `5` 为总控时为 `2` 台。

## 样例2

**输入**

```
7
1 2
1 3
2 4
2 5
3 6
3 7
```

**输出**

```
0
1
1
2
2
2
2
```

**说明**

这是一棵以 `1` 为中心、两层完全二叉树形态的树。
分别以 $1$ 到 $7$ 为总控，偶数辖区台数依次为 $0,1,1,2,2,2,2$。

## 样例3

**输入**

```
1
```

**输出**

```
0
```

**说明**

只有一台交换机。以它为总控时辖区规模为 `1`（奇数），答案为 `0`。

## 样例4

**输入**

```
2
1 2
```

**输出**

```
1
1
```

**说明**

两点一线。以任一点为总控时，根的辖区规模为 `2`（偶数），叶子规模为 `1`（奇数），答案均为 `1`。
