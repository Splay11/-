# 题目内容
生态学家在一系列观测站中记录了不同物种的个体数量。为了量化每个观测站中物种分布的均匀程度，现要求计算各站点物种分布的熵值。

对于包含 $n$ 个物种的观测站，设第 $i$ 个物种的个体数量为 $c_i$，总个体数量 $S = \sum_{i=1}^{n} c_i$，则第 $i$ 个物种出现的比例 $p_i = c_i / S$（若 $S = 0$，则定义熵为 $0$）。该观测站的熵值按下式计算：

$$H = -\sum_{i=1}^{n} p_i \log_2 p_i$$

其中约定若 $p_i = 0$，相应的项视为 $0$。熵值越大，说明物种分布越均匀，多样性越好。

你需要编写程序从标准输入读取数据，计算每个观测站的熵值，并将结果保留三位小数后以 JSON 格式输出。

**约束条件**
- 观测站数量不超过 $10^4$。
- 每个观测站的物种数不超过 $50$。
- 每个物种的个体数量为不超过 $10^6$ 的非负整数。

# 输入描述
输入共一行，为一个 JSON 格式的字符串。该 JSON 对象（字典）的键为观测站的编号（字符串），值为另一个字典，该字典的键为物种名称（字符串），值为对应物种的个体数量（非负整数）。

例如，输入可能形如 `{"station1":{"wolf":10,"rabbit":20,"deer":30},"station2":{...}}`。输入保证是合法 JSON 且满足前述数据约束。

# 输出描述
输出一行 JSON 字符串，表示一个字典，其键与输入中的观测站编号一一对应。每个键对应的值为一个包含单一键 `"entropy"` 的字典，其值为该观测站的熵值，四舍五入保留三位小数的浮点数。

例如，输出形如 `{"station1":{"entropy":1.459},"station2":{"entropy":0.918}}`。注意数值必须保留三位小数（如 `1.200`、`0.000`）。

## 样例1

**输入**

```
{"station1": {"wolf": 10, "rabbit": 10}, "station2": {"deer": 100}}
```

**输出**

```
{"station1": {"entropy": 1.0}, "station2": {"entropy": 0.0}}
```

**说明**

对于 `station1`，总个体数 $S=20$，两个物种比例均为 $p=0.5$，熵 $H = -0.5 \log_2 0.5 - 0.5 \log_2 0.5 = 1.0$。对于 `station2`，仅有一个物种，比例 $p=1.0$，$H = -1.0 \log_2 1.0 = 0.0$。

## 样例2

**输入**

```
{"siteA": {"cat": 1, "dog": 2, "bird": 3}}
```

**输出**

```
{"siteA": {"entropy": 1.459}}
```

**说明**

总个体数 $S=6$，各物种比例为 $p_1=1/6$，$p_2=2/6=1/3$，$p_3=3/6=1/2$。计算熵：$H = -\frac{1}{6} \log_2 \frac{1}{6} - \frac{1}{3} \log_2 \frac{1}{3} - \frac{1}{2} \log_2 \frac{1}{2} \approx 1.459$（四舍五入到三位小数）。

## 样例3

**输入**

```
{"emptyStation": {"a": 0, "b": 0}}
```

**输出**

```
{"emptyStation": {"entropy": 0.0}}
```

**说明**

总个体数 $S=0$，按照约定熵值直接定义为 $0$。
