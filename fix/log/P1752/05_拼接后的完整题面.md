# 题目内容
车间要装箱三种零件：热敏件 $x$ 个、恒温件 $y$ 个、普通件 $z$ 个。每个零件必须放入恰好一个箱子，且满足：

- 若某只箱子里装有热敏件，则该箱零件总数不得超过 `2`；
- 若某只箱子里装有恒温件，则该箱零件总数不得少于 `3`；
- 普通件没有额外限制。

请对每组零件数量，求出合法装箱方案中箱子个数的最小值与最大值。若不存在合法方案，则输出 `-1`。

本题有多组询问。

约束条件：
- 询问次数 $g$ 满足 $1 \le g \le 10^5$；
- 每组三种零件的数量满足 $1 \le x, y, z \le 10^9$。

# 输入描述
第一行包含一个正整数 $g$（$1 \le g \le 10^5$），表示询问次数。
接下来 $g$ 行，每行三个正整数 $x, y, z$（$1 \le x, y, z \le 10^9$），依次表示热敏件、恒温件和普通件的数量。

# 输出描述
对每一组询问输出一行。若不存在合法方案，输出 `-1`；否则输出两个正整数，分别表示最少箱子数和最多箱子数。

## 样例1

**输入**

```
2
3 3 3
1 1 1
```

**输出**

```
3 7
-1
```

**说明**

第一组：热敏件 `3` 个，两两装箱最少需要 `2` 箱，恒温件与普通件合并为一箱，最少 $2+1=3$ 箱。最多时热敏件各占一箱（`3`），普通件各占一箱（`3`），恒温件每三个一箱（`1`），共 `7` 箱。

第二组：$y=1$ 且普通件只有 `1` 个，凑不满恒温箱所需的 `3` 个零件，无解，输出 `-1`。

## 样例2

**输入**

```
1
1 2 1
```

**输出**

```
2 2
```

**说明**

热敏件 `1` 个单独一箱。恒温件 `2` 个必须再配 `1` 个普通件合成一箱。最少 $\lceil 1/2 \rceil + 1 = 2$，最多 $1+1+\lfloor 2/3 \rfloor = 2$。

## 样例3

**输入**

```
1
4 1 2
```

**输出**

```
3 5
```

**说明**

恒温件只有 `1` 个，需占用 `2` 个普通件合成一箱，方案合法。最少 $\lceil 4/2 \rceil + 1 = 3$。最多热敏件 `4` 箱，恒温箱占用普通件后不再额外成箱，为 $4+2-1=5$。
