## 解题思路

热敏件与恒温件不能放在同一箱：热敏箱总数 $\le 2$，恒温箱总数 $\ge 3$，互相矛盾。因此恒温件只能和普通件（以及其它恒温件）放在一起。

**可行性：** 恒温件所在箱至少要 `3` 个零件。当 $y=1$ 时需要至少 `2` 个普通件；当 $y=2$ 时需要至少 `1` 个普通件。不满足则无解，输出 `-1`。题目保证 $y \ge 1$，因此只要普通件够用来“凑满”恒温箱即可。

**最少箱子：** 热敏件尽量两两一箱，需要 $\lceil x/2 \rceil$ 箱。所有恒温件和普通件可以并进同一箱（在有解时 $y+z \ge 3$），再加 `1` 箱。故最少为 $\lceil x/2 \rceil + 1$。

**最多箱子：** 热敏件每个单独一箱（箱内只有 `1` 个，满足 $\le 2$）。普通件尽量单独成箱。恒温件每箱至少 `3` 个零件：

- $y \ge 3$ 时，每 `3` 个恒温件一箱，其余恒温件并入已有恒温箱，普通件全部单独成箱，最多为 $x + z + \lfloor y/3 \rfloor$；
- $y=2$ 时必须占用 `1` 个普通件，最多为 $x+z$；
- $y=1$ 时必须占用 `2` 个普通件，最多为 $x+z-1$。

## 复杂度分析

每组询问 $O(1)$ 计算，总时间复杂度 $O(g)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
import sys
input = sys.stdin.readline
g = int(input().strip())
for _ in range(g):
    x, y, z = map(int, input().split())
    ok = True
    if y == 1 and z < 2:
        ok = False
    if y == 2 and z < 1:
        ok = False
    if not ok:
        print(-1)
        continue
    X = (x + 1) // 2
    if y > 0:
        nmin = X + 1
    else:
        nmin = X + (1 if z > (x % 2) else 0)
    if y == 1:
        nmax = x + z - 1
    else:
        nmax = x + z + y // 3
    print(nmin, nmax)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int g = sc.nextInt();
        for (int i = 0; i < g; i++) {
            long x = sc.nextLong();
            long y = sc.nextLong();
            long z = sc.nextLong();
            boolean ok = true;
            if (y == 1 && z < 2) ok = false;
            if (y == 2 && z < 1) ok = false;
            if (!ok) {
                System.out.println("-1");
                continue;
            }
            long X = (x + 1) / 2;
            long nmin = (y > 0) ? X + 1 : X + (z > (x % 2) ? 1 : 0);
            long nmax = (y == 1) ? x + z - 1 : x + z + y / 3;
            System.out.println(nmin + " " + nmax);
        }
    }
}
```
