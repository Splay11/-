# 题目内容
给定一棵由 $n$ 台服务器组成的树形网络，服务器编号为 $1$ 到 $n$，保证 $n$ 为奇数。每台服务器 $i$ 有一个初始负载值 $L_i$ 和一个代价系数 $C_i$。

你每次操作可以选定一个连通的服务器集合（即树的一个连通子图，集合内任意两台服务器之间的简单路径上的所有服务器都在该集合中），并选择该集合中的一台服务器，将其负载值增加 `1` 或减少 `1`。此次操作的代价等于该连通集合内所有服务器的代价系数之和。

你的目标是将所有服务器的负载值变为相同。你需要首先保证总操作次数最少，在此前提下，使得总代价尽可能小（代价可以为负数）。

请计算并输出这个最小总代价。

约束条件：
- 服务器总数 $n$ 为奇数且满足 $1 \le n < 10^5$。
- 初始负载值 $L_i$ 的范围为 `1` 到 `100`。
- 代价系数 $C_i$ 的范围为 `-100` 到 `100`。

# 输入描述
第一行包含一个奇数 $n$，表示服务器总数。
第二行包含 $n$ 个整数，依次表示每台服务器的初始负载值 $L_1, L_2, \dots, L_n$。
第三行包含 $n$ 个整数，依次表示每台服务器的代价系数 $C_1, C_2, \dots, C_n$。
接下来 $n-1$ 行，每行包含两个整数 $u$ 和 $v$（$1 \le u, v \le n$，$u 
eq v$），表示服务器 $u$ 与服务器 $v$ 之间有一条网络连接。

# 输出描述
输出一个整数，表示在保证总操作次数最少的前提下，所需的最小总代价。

## 样例1

**输入**

```
1
5
10
```

**输出**

```
0
```

**说明**

只有一台服务器，其负载已经是相同的，不需要任何操作。最少操作次数为 `0`，因此总代价为 `0`。

## 样例2

**输入**

```
3
1 2 4
1 2 3
1 2
2 3
```

**输出**

```
7
```

**说明**

服务器负载为 `1`, `2`, `4`，中位数 $T=2$，目标负载为 `2`。操作次数：节点 `1` 需要增加 `1` 次，节点 `2` 需要 `0` 次，节点 `3` 需要减少 `2` 次。所有代价系数均为正数，每个服务器的最优连通块就是其自身。最小总代价为 $|1-2|\times 1 + |2-2|\times 2 + |4-2|\times 3 = 1 + 0 + 6 = 7$。

## 样例3

**输入**

```
3
10 20 30
10 -5 10
1 2
2 3
```

**输出**

```
100
```

**说明**

负载为 `10`, `20`, `30`，中位数 $T=20$。操作次数为 `10`, `0`, `10`。节点 `2` 的代价系数为 $-5$。对于节点 `1`，包含它的最小连通块是 $\{1,2\}$，代价和为 $10+(-5)=5$，优于仅用自身（代价 `10`）。节点 `3` 的最小连通块为 $\{2,3\}$，代价和为 $5$。节点 `2` 不需要操作。总代价为 $10 \times 5 + 0 + 10 \times 5 = 100$。

## 样例4

**输入**

```
5
1 2 3 4 5
1 1 1 1 1
1 2
2 3
3 4
4 5
```

**输出**

```
6
```

**说明**

链状网络，负载依次为 `1` 到 `5`，中位数为 `3`，目标 $T=3$。操作次数分别为 `2`, `1`, `0`, `1`, `2`。所有代价系数都是 `1`，最优连通块均为各节点本身。总代价 $=2\times 1 + 1\times 1 + 0 + 1\times 1 + 2\times 1 = 6$。
