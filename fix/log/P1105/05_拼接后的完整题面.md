# 题目内容
一家公司具有严格的树形层级结构，由一位最高负责人和其下属构成，形成一棵深度为 $n$ 的完全二叉树。负责人编号为 $1$，对于任意编号为 $i$ 的成员（如果其存在下级），他的直接下级编号分别为 $2i$ 和 $2i+1$。成员总数不超过 $2^n-1$。

初始时，所有成员均未接收某项重要通知。接下来会进行 $q$ 次通知下达，每一次操作会指定一个成员编号 $a_i$，该成员及其所有下属（即以该成员为根的子树）将立即标记为“已通知”。如果某个成员此前已被通知，则状态保持不变。请你在每一次通知下达后，计算当前已通知的成员总数。

约束：层数 $n \le 40$，操作次数 $q \le 10^4$，每次下达的编号 $a_i$ 满足 $1 \le a_i \le 2^n$。

# 输入描述
第一行包含两个整数 $n$ 和 $q$，分别表示树的层数和操作次数。
接下来 $q$ 行，每行一个整数 $a_i$，表示本次下达通知的成员编号。

# 输出描述
输出共 $q$ 行，每行一个整数，表示该次通知下达后已通知的成员总数。

## 样例1

**输入**

```
2 2
2
1
```

**输出**

```
1
3
```

**说明**

深度为 `2` 的完全二叉树共有 $2^2 - 1 = 3$ 个节点，编号为 `1`（根）、`2`（左子）、`3`（右子）。初始时所有节点均未通知。
第一次通知 `2`，其子树仅包含自身，因此已通知节点总数变为 `1`。
第二次通知 `1`，其子树包含全部 `3` 个节点，但 `2` 此前已通知，因此新增 `1` 和 `3`，累计已通知总数变为 `3`。

## 样例2

**输入**

```
3 3
4
2
1
```

**输出**

```
1
3
7
```

**说明**

深度为 `3` 的完全二叉树共有 $2^3 - 1 = 7$ 个节点。
第一次通知 `4`（叶子节点），已通知总数变为 `1`。
第二次通知 `2`，其子树包含 `2`、`4`、`5`。其中 `4` 此前已通知，因此新增 `2` 和 `5`，累计已通知总数变为 `3`。
第三次通知 `1`，整棵树剩余节点 `1`、`3`、`6`、`7` 均被标记为已通知，最终累计总数达到 `7`。

## 样例3

**输入**

```
1 1
1
```

**输出**

```
1
```

**说明**

深度为 `1` 的树仅有根节点 `1`，这是最小规模的边界情况。通知 `1` 后，已通知节点总数即为 `1`。

## 样例4

**输入**

```
4 4
8
4
2
1
```

**输出**

```
1
3
7
15
```

**说明**

深度为 `4` 的完全二叉树共有 $2^4 - 1 = 15$ 个节点。
依次通知 `8`、`4`、`2`、`1`，每次通知的子树范围逐步扩大：
- 通知 `8`：仅 `8` 被标记，总数 `1`；
- 通知 `4`：子树 `{4,8,9}` 中 `8` 已通知，新增 `4` 和 `9`，累计 `3`；
- 通知 `2`：子树包含 `2,4,5,8,9,10,11`，新增 `2,5,10,11`，累计 `7`；
- 通知 `1`：整棵树剩余节点全部标记，累计 `15`。
该示例展示了从叶子到根逐层扩大通知范围的累加过程。
