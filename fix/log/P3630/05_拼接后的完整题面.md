# 题目内容
在一个 $H$ 行 $5$ 列的面板中，每个格子里都有一个数字块，上面写有 $1$ 到 $9$ 的整数。当水平方向上出现至少三个连续且数字相同的块时，这些块会立即被消除。消除发生后，上方的数字块会向下掉落，填补出现的空位。如果同一时刻有多组满足消除条件的块，则它们会同时被消除。此后，重复检测与消除、掉落的过程，直到面板中不再存在任何可消除的连续数字块。

你的任务是计算整个过程中所有被消除的数字块上的数字之和。

【数据范围】
测试用例的数量 $T$ 满足 $1 \le T \le 1100$。
对于每个测试用例，行数 $H$ 满足 $1 \le H \le 10$。
面板中的每个数字 $x_{i,j}$ 均为整数，且 $1 \le x_{i,j} \le 9$。

# 输入描述
第一行包含一个整数 $T$，表示测试用例的组数。
对于每组测试用例：
第一行包含一个整数 $H$，表示面板的行数。
接下来的 $H$ 行，每行包含 $5$ 个由空格分隔的整数，依次表示该行从左到右的数字块上的数字。

# 输出描述
对于每组测试用例，输出一行一个整数，表示在整个消除过程中被消除的数字之和。

## 样例1

**输入**

```
1
1
1 2 3 4 5
```

**输出**

```
0
```

**说明**

面板只有一行，数字依次为 `1 2 3 4 5`。
水平方向不存在任何至少三个连续相同的数字，因此没有数字块被消除。
全部被消除的数字之和为 $0$。

## 样例2

**输入**

```
1
2
1 1 1 2 3
4 4 4 5 6
```

**输出**

```
15
```

**说明**

面板有两行：
第一行 `1 1 1 2 3` 中，前三个数字为连续的 `1`，满足消除条件，消除和为 $1+1+1=3$。
第二行 `4 4 4 5 6` 中，前三个数字为连续的 `4`，满足消除条件，消除和为 $4+4+4=12$。
两组消除同时发生。消除后出现的空位上方没有其他数字块，因此不会发生掉落和连锁消除。
总消除和为 $3+12=15$。

## 样例3

**输入**

```
1
3
2 3 3 4 5
3 3 5 5 5
1 2 3 4 6
```

**输出**

```
24
```

**说明**

初始面板有 $3$ 行：
行1: `2 3 3 4 5`
行2: `3 3 5 5 5`
行3: `1 2 3 4 6`

第一步消除：行2的第3～5列出现三个连续的 `5`，立即消除，消除和为 $5+5+5=15$。
消除后，行2的第3～5列变为空位。上方的数字块向下掉落：
- 行1第3列的 `3` 掉落至行2第3列；
- 行1第4列的 `4` 掉落至行2第4列；
- 行1第5列的 `5` 掉落至行2第5列。
掉落后面板变为：
行1: `2 3` 后三列为空
行2: `3 3 3 4 5`
行3: `1 2 3 4 6`

第二步消除：行2的第1～3列出现三个连续的 `3`，消除和为 $3+3+3=9$。
消除后再次掉落：行1第1列的 `2` 和第2列的 `3` 分别掉落至行2对应列。
最终面板中不再有可消除的连续块，消除过程结束。
总消除和为 $15+9=24$。

## 样例4

**输入**

```
1
4
2 2 3 4 5
2 3 3 3 4
3 3 5 5 5
1 2 3 4 5
```

**输出**

```
33
```

**说明**

面板有 $4$ 行：
行1: `2 2 3 4 5`
行2: `2 3 3 3 4`
行3: `3 3 5 5 5`
行4: `1 2 3 4 5`

第一步同时消除：行2的第2～4列有三个连续 `3`（和为 $9$），行3的第3～5列有三个连续 `5`（和为 $15$）。消除后出现大量空位，上方的数字块向下掉落。非空格沉底后，面板变为：
行1: `2` 后四列空
行2: `2 2 空 4 5`
行3: `3 3 3 4 4`
行4: `1 2 3 4 5`

第二步消除：行3的第1～3列出现三个连续 `3`，消除和为 $9$。
再次掉落后，面板中不再有连续三个相同的数字。
总消除和为 $9+15+9=33$。
