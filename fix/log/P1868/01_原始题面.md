# 题目描述

某国际会议系统需要同时显示北京时间和世界协调时间（UTC）。

北京时间采用东八区时间，即 UTC+8，也就是说，北京时间比世界协调时间快 $8$ 个小时。

例如，当北京时间为 `08:00` 时，对应的世界协调时间为 `00:00`；当北京时间为 `03:20` 时，对应的世界协调时间为前一天的 `19:20`。

现在给定若干个北京时间，请你将它们转换为对应的世界协调时间。

一天有 $24$ 个小时。当时间跨过零点时，需要按照 $24$ 小时制循环计算。

# 输入描述

每个测试文件包含多组测试数据。

第一行输入一个整数 $T$（$1<T<10^4$），表示测试数据组数。

接下来 $T$ 行，每行输入一个北京时间，格式为：

```text id="w6ejhy"
小时:分钟
```

输入采用 $24$ 小时制，小时和分钟可能不会补齐前导零。

# 输出描述

对于每组测试数据，输出一行对应的世界协调时间（UTC）。

输出格式为 `hh:mm`，其中小时和分钟均需要补齐为两位数。

# 样例

**输入**

```text id="vf2hpo"
4
12:45
7:05
23:30
3:20
```

**输出**

```text id="d70skt"
04:45
23:05
15:30
19:20
```

**说明**

北京时间比世界协调时间快 $8$ 小时，因此只需要将北京时间向前调整 $8$ 小时。

例如，`12:45` 对应 `04:45`。

而 `03:20` 向前调整 $8$ 小时后会跨过零点，因此对应前一天的 `19:20`。
