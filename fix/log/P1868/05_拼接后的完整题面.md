# 题目内容
调度室主钟比物流站时钟快 $8$ 个小时。一天按 $24$ 小时循环。现在给出若干个主钟时刻，请把它们换成物流站时钟上的对应时刻。

当减去 $8$ 小时后跨过零点时，需要按 $24$ 小时制回绕到前一天的时刻。

测试组数 $T$ 满足 $1 < T < 10^4$。时刻采用 $24$ 小时制，小时与分钟之间用字符 `:` 分隔；输入时小时和分钟可能不含前导零。

# 输入描述
每个测试文件包含多组数据。
第一行一个整数 $T$（$1 < T < 10^4$），表示数据组数。
接下来 $T$ 行，每行一个主钟时刻，格式为小时、字符 `:`、分钟。输入采用 $24$ 小时制，小时和分钟可能不含前导零。

# 输出描述
对每组数据输出一行对应的物流站时刻，格式为 `hh:mm`，其中小时和分钟均需补齐为两位。

## 样例1

**输入**

```
2
0:00
8:00
```

**输出**

```
16:00
00:00
```

**说明**

`0:00` 减去 `8` 小时后回绕为 `16:00`。
`8:00` 恰好减到当天零点 `00:00`。输入小时可以不含前导零，输出必须补齐两位。

## 样例2

**输入**

```
3
7:59
8:00
8:01
```

**输出**

```
23:59
00:00
00:01
```

**说明**

这三个时刻分别位于减去 `8` 小时是否跨零点的分界两侧。
`7:59` 得到 `23:59`。
`8:00` 得到 `00:00`。
`8:01` 得到 `00:01`。
