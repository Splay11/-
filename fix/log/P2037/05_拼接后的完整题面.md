# 题目内容
在一座笔直的公园小道旁，计划安装一排喷泉装置。每个喷泉装置有一个固定的中心坐标 $c$ 和一个喷射半径 $r$，开启后会湿润从 $c-r$ 到 $c+r$ 的一段路面（包含端点）。为了节约用水，管理员希望开启的喷泉湿润区域没有任何公共点（即不能有重叠，也不能端点相接）。给定所有喷泉的中心坐标和半径，请你计算最多可以同时开启多少个喷泉。

喷泉的数量 $n$ 不超过 $10^5$，每个喷泉的中心坐标 $c$ 和半径 $r$ 均为不超过 $10^6$ 的正整数。

# 输入描述
第一行包含一个整数 $n$，表示喷泉的数量。
接下来的 $n$ 行，每行包含两个整数 $c$ 和 $r$，分别表示一个喷泉的中心坐标和喷射半径。

# 输出描述
输出一个整数，表示最多可以开启的喷泉数量。

## 样例1

**输入**

```
3
1 2
5 1
3 2
```

**输出**

```
2
```

**说明**

第一个喷泉：$c=1, r=2$，区间 $[-1,3]$。
第二个：$c=5, r=1$，区间 $[4,6]$。
第三个：$c=3, r=2$，区间 $[1,5]$。
按区间右端点排序：$[-1,3]$、$[1,5]$、$[4,6]$。贪心过程：初始 $now=-10^9$。先选 $[-1,3]$，更新 $now=3$。然后 $[1,5]$ 左端点 `1` 不大于 `3`，跳过。最后 $[4,6]$ 左端点 `4` 大于 `3`，选取，更新 $now=6$。共选取 `2` 个。

## 样例2

**输入**

```
2
2 1
4 1
```

**输出**

```
1
```

**说明**

喷泉1：$c=2, r=1$，区间 $[1,3]$。
喷泉2：$c=4, r=1$，区间 $[3,5]$。
两个区间在点 `3` 处端点相接。题目要求不能有公共点，端点相接也算冲突。贪心排序后，先选 $[1,3]$，$now=3$。下一个区间左端点为 `3`，不满足 $left > now$，不能选取。因此最多开启 `1` 个。

## 样例3

**输入**

```
4
5 4
2 1
4 1
7 1
```

**输出**

```
2
```

**说明**

喷泉区间分别为：$[1,9]$（$c=5,r=4$）、$[1,3]$（$c=2,r=1$）、$[3,5]$（$c=4,r=1$）、$[6,8]$（$c=7,r=1$）。
按右端点排序：$[1,3]$, $[3,5]$, $[6,8]$, $[1,9]$。贪心过程：先选 $[1,3]$，$now=3$。$[3,5]$ 左端点 `3` 不大于 `3`，跳过。$[6,8]$ 左端点 `6` 大于 `3`，选取，$now=8$。$[1,9]$ 左端点 `1` 不大于 `8`，跳过。最终开启 `2` 个。虽然大区间 $[1,9]$ 单独覆盖范围广，但因为与小区间重叠，选择更短且不相交的小区间可以获得更多数量。

## 样例4

**输入**

```
1
10 5
```

**输出**

```
1
```

**说明**

只有一个喷泉，开启它即可，答案为 `1`。
