# 题目内容
有 $n$ 件货物，第 $i$ 件的规格值为 $a_i$。

从中按原相对顺序取出若干件（可以为空或全部）得到的序列称为子序列。定义一段非空子序列 $b$ 的峰值 $f(b)$ 为其中的最大值。

对每个 $k=1,2,\ldots,n$，求所有长度为 $k$ 的子序列的峰值之和。答案可能很大，对 `998244353` 取模后输出。

约束：货物件数不超过 `5\times 10^3`，每件规格值为不超过 `10^9` 的正整数。

# 输入描述
第一行包含一个正整数 $n$，表示货物件数。保证 $1 \le n \le 5 \times 10^3$。
第二行包含 $n$ 个正整数 $a_1, a_2, \ldots, a_n$，表示各件货物的规格值。保证 $1 \le a_i \le 10^9$。

# 输出描述
输出一行 $n$ 个整数。第 $k$ 个数表示所有长度为 $k$ 的子序列的峰值之和对 `998244353` 取模后的结果。

## 样例1

**输入**

```
1
7
```

**输出**

```
7
```

**说明**

只有一件货物，长度为 `1` 的子序列只有它自己，峰值就是 `7`。
这是 $n=1$ 的边界情形。

## 样例2

**输入**

```
3
2 2 2
```

**输出**

```
6 6 2
```

**说明**

三件规格相同。长度为 `1` 的子序列有 `3` 个，峰值和为 `6`；长度为 `2` 有 `3` 个，峰值和为 `6`；长度为 `3` 只有 `1` 个，峰值为 `2`。

## 样例3

**输入**

```
1
8
```

**输出**

```
8
```

**说明**

按题意模拟计算得到。
