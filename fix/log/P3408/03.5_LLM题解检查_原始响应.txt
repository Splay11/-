## 解题思路

首先，将衰减和的公式展开：
$$
S(a)=\sum_{i=1}^{n-1}(a_i-a_{i+1})=a_1-a_n.
$$
也就是说，序列的衰减和完全由首元素和末元素决定。

当对子数组 $a[l..r]$ 进行一次循环右移后，我们只需关心新序列的首元素 $a'_1$ 和末元素 $a'_n$ 分别是谁。根据操作区间的位置，可以分成以下四种情况讨论：

1. **操作区间不含首尾**（$1<l\le r<n$）  
   $a_1$ 和 $a_n$ 保持不变，因此 $S(a')=a_1-a_n$。

2. **操作区间包含开头**（$l=1,\ r<n$）  
   通过适当选择右移步数，可以把区间内任意一个元素 $a_k\ (1\le k\le r)$ 移到序列开头，而 $a_n$ 仍为末元素。此时衰减和为 $a_k-a_n$。为使衰减和最大，应取 $k$ 满足 $a_k$ 尽可能大，即  
   $$S_{\text{max}} = \max_{1\le k\le r} a_k - a_n = \max(a) - a_n.$$

3. **操作区间包含末尾**（$l>1,\ r=n$）  
   可以把区间内任意一个元素 $a_k\ (l\le k\le n)$ 移到序列末尾，而 $a_1$ 仍为首元素。此时衰减和为 $a_1-a_k$。最大值为  
   $$S_{\text{max}} = a_1 - \min_{l\le k\le n} a_k = a_1 - \min(a).$$

4. **操作区间为整个序列**（$l=1,\ r=n$）  
   将整个序列循环右移，可以打破原来的首尾关系。实际上，除了保留原始首尾的情况外，还能让任意相邻对 $(a_{i-1},a_i)\ (2\le i\le n)$ 成为新的末元素和首元素（例如，将原本排在 $a_{i-1}$ 后的 $a_i$ 移到首位，则原 $a_{i-1}$ 变为末元素）。因此该情况下衰减和的候选值包括所有 $a_i-a_{i-1}\ (2\le i\le n)$ 以及原始值 $a_1-a_n$。

综合以上讨论，答案就是下列四个表达式的最大值：

- $a_1 - a_n$
- $a_1 - \min(a)$
- $\max(a) - a_n$
- $\max_{2\le i\le n} (a_i - a_{i-1})$

特别地，当 $n=1$ 时，序列无相邻元素，根据定义衰减和为 $0$。

实现时只需一次线性扫描即可求出最小值、最大值和所有相邻差的最大值，并直接计算上述答案。

## 复杂度分析

时间复杂度：每组数据只需对序列进行一趟线性扫描，故时间复杂度为 $O(n)$；所有测试数据的 $n$ 总和不超过 $2\times 10^5$，总复杂度为 $O(\sum n)$，满足题目要求。  
空间复杂度：仅需常数个额外变量，为 $O(1)$（不计输入存储所用的数组）。

## 代码实现

### Python

```python
import sys

def solve():
    data = list(map(int, sys.stdin.read().strip().split()))
    it = iter(data)
    T = next(it, 0)
    out_lines = []
    for _ in range(T):
        n = next(it)
        a = [next(it) for _ in range(n)]

        # 特判 n = 1
        if n == 1:
            out_lines.append("0")
            continue

        mn = min(a)
        mx = max(a)

        # 候选1: a1 - an
        ans = a[0] - a[-1]

        # 候选2: a1 - min(a)
        ans = max(ans, a[0] - mn)

        # 候选3: max(a) - an
        ans = max(ans, mx - a[-1])

        # 候选4: max(a[i] - a[i-1]) for i=1..n-1
        for i in range(1, n):
            ans = max(ans, a[i] - a[i-1])

        out_lines.append(str(ans))

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    static class FastScanner {
        private final InputStream in;
        private final byte[] buffer = new byte[1 << 16];
        private int ptr = 0, len = 0;

        FastScanner(InputStream is) { in = is; }

        private int read() throws IOException {
            if (ptr >= len) {
                len = in.read(buffer);
                ptr = 0;
                if (len <= 0) return -1;
            }
            return buffer[ptr++];
        }

        long nextLong() throws IOException {
            int c;
            do { c = read(); } while (c <= ' ' && c != -1);
            long sgn = 1;
            if (c == '-') { sgn = -1; c = read(); }
            long x = 0;
            while (c > ' ') { x = x * 10 + (c - '0'); c = read(); }
            return x * sgn;
        }

        int nextInt() throws IOException { return (int) nextLong(); }
    }

    public static void main(String[] args) throws Exception {
        FastScanner fs = new FastScanner(System.in);
        StringBuilder sb = new StringBuilder();
        int T = fs.nextInt();
        while (T-- > 0) {
            int n = fs.nextInt();
            long[] a = new long[n];
            for (int i = 0; i < n; i++) a[i] = fs.nextLong();

            // 特判 n = 1
            if (n == 1) {
                sb.append("0\n");
                continue;
            }

            long mn = a[0], mx = a[0];
            for (int i = 1; i < n; i++) {
                if (a[i] < mn) mn = a[i];
                if (a[i] > mx) mx = a[i];
            }

            // 候选1: a1 - an
            long ans = a[0] - a[n - 1];

            // 候选2: a1 - min(a)
            ans = Math.max(ans, a[0] - mn);

            // 候选3: max(a) - an
            ans = Math.max(ans, mx - a[n - 1]);

            // 候选4: max(a[i] - a[i-1])
            for (int i = 1; i < n; i++) {
                ans = Math.max(ans, a[i] - a[i - 1]);
            }

            sb.append(ans).append('\n');
        }
        System.out.print(sb.toString());
    }
}
```
