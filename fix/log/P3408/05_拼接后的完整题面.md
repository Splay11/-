# 题目内容
给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。

定义该序列的“衰减和”为相邻两项前项与后项的差值之和：
$S(a) = \sum_{i=1}^{n-1} (a_i - a_{i+1})$。

你可以对序列恰好执行一次操作：选择一个连续子数组 $a[l \dots r]$（$1 \le l \le r \le n$），将该子数组循环右移任意正整数步。一次循环右移会将子数组的最后一个元素移到最前面，其余元素依次后移一位。经过若干次循环右移后得到新序列 $a'$。

请计算在恰好执行一次操作后，能够获得的最大衰减和 $S(a')$。

输入包含多组测试数据。测试组数 $T$ 不超过 $10^4$，所有序列的长度 $n$ 之和不超过 $2 \times 10^5$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据组数。
接下来每组数据按以下格式给出：
第一行包含一个整数 $n$，表示序列长度。
第二行包含 $n$ 个整数，表示初始序列 $a_1, a_2, \dots, a_n$。

# 输出描述
对于每组测试数据，输出一行一个整数，表示恰好执行一次操作后可以得到的最大衰减和。

## 样例1

**输入**

```
1
2
-5 3
```

**输出**

```
8
```

**说明**

序列长度为 `2`，唯一的可操作子数组为整个序列 $[a_1, a_2]$。
循环右移 `1` 步后，序列变为 $[3, -5]$。
原衰减和为 $-5 - 3 = -8$，新衰减和为 $3 - (-5) = 8$。
因此最大值为 `8`。

## 样例2

**输入**

```
1
4
10 1 2 9
```

**输出**

```
9
```

**说明**

原衰减和为 $10 - 9 = 1$。
若只改变尾元素，选择子数组 $a[2 \dots 4] = [1, 2, 9]$ 循环右移 $2$ 步，子数组变为 $[2, 9, 1]$，整个序列变为 $[10, 2, 9, 1]$，衰减和为 $10 - 1 = 9$。
其它操作（如只改变首元素或整体循环）均无法得到更大的值，因此最大衰减和为 `9`。

## 样例3

**输入**

```
1
4
1 100 2 3
```

**输出**

```
99
```

**说明**

对整个序列 $[1, 100, 2, 3]$ 选择 $l=1, r=4$ 并循环右移 $3$ 步，得到新序列 $[100, 2, 3, 1]$，衰减和为 $100 - 1 = 99$。
这是因为原序列中 $a_2 - a_1 = 100 - 1 = 99$ 是所有循环相邻差中的最大值，该操作恰好将 $a_2$ 移至首部、$a_1$ 移至尾部，从而获得最大衰减和 `99`。

## 样例4

**输入**

```
1
4
5 1 2 0
```

**输出**

```
5
```

**说明**

原衰减和为 $5 - 0 = 5$。
我们可以选择不影响首尾的中间子数组，例如 $a[2 \dots 3] = [1, 2]$ 循环右移 `1` 步，子数组变为 $[2, 1]$，序列变为 $[5, 2, 1, 0]$。此时首尾元素不变，衰减和仍为 $5 - 0 = 5$。
其它任何操作均无法得到比 `5` 更大的值，因此最大衰减和为 `5`。
