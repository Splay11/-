## 解题思路

设所选子序列中包含 $k$ 个字符 `1` 和 $y$ 个字符 `0`，则子序列长度 $L = k + y$。  
由题目定义，子序列“和谐”需满足 $k > 0$ 且 $L$ 是 $k$ 的整数倍，即  

$$
k + y \equiv 0 \pmod k .
$$

因为 $k \equiv 0 \pmod k$，上式等价于  

$$
y \equiv 0 \pmod k .
$$

所以**选择 $k$ 个 `1` 后，所选的 `0` 的个数必须是 $k$ 的整数倍**（可以为 $0,k,2k,3k,\dots$）。  
这样问题就转化为组合计数：

- 记原串中字符 `1` 的总数为 $\textit{cnt1}$，字符 `0` 的总数为 $\textit{cnt0}$。
- 枚举选择的 `1` 的个数 $k$（$1 \le k \le \textit{cnt1}$）。
- 选择 $k$ 个 `1` 的方案数为 $\binom{\textit{cnt1}}{k}$。
- 在 $\textit{cnt0}$ 个 `0` 中，必须选择 $j \cdot k$ 个（$j \ge 0$ 且 $j \cdot k \le \textit{cnt0}$），方案数为  

$$
\sum_{j=0}^{\lfloor \textit{cnt0} / k \rfloor} \binom{\textit{cnt0}}{j \cdot k}.
$$

最终的答案为  

$$
\text{ans} = \sum_{k=1}^{\textit{cnt1}} \left[ \binom{\textit{cnt1}}{k} \cdot \left( \sum_{j=0}^{\lfloor \textit{cnt0} / k \rfloor} \binom{\textit{cnt0}}{j \cdot k} \right) \right] \pmod{10^9+7}.
$$

实现上，需要支持快速计算组合数 $\binom{n}{m}$，因此预先计算 $[0, N_{\max}]$ 的阶乘和乘法的逆元（使用费马小定理），其中 $N_{\max}$ 取所有字符串长度总和的上界 $500000$。计算一组数据时，先统计 $\textit{cnt1}$ 与 $\textit{cnt0}$，再按上述公式枚举 $k$ 并累加即可。

## 复杂度分析

设单组字符串中 `1` 的个数为 $\textit{cnt1}$，`0` 的个数为 $\textit{cnt0}$。  
对于每个 $k$，内层需要枚举 $0, k, 2k, \dots, \lfloor \textit{cnt0} / k\rfloor \cdot k$ 共 $O(\textit{cnt0}/k)$ 次。总计算量为  

$$
\sum_{k=1}^{\textit{cnt1}} \left( \frac{\textit{cnt0}}{k} + 1 \right) \le \textit{cnt1} + \textit{cnt0} \cdot H_{\textit{cnt1}},
$$

其中 $H_{\textit{cnt1}}$ 是调和级数，约为 $\ln \textit{cnt1} + \gamma$。该复杂度等价于 $O(\textit{cnt1} + \textit{cnt0} \log \textit{cnt1})$，在题目总长度不超过 $5\times 10^5$ 的约束下完全可行。  
空间复杂度来自阶乘与逆阶乘的预处理，为 $O(N_{\max}) = O(5\times 10^5)$。

## 代码实现

### Python

```python
MOD = 10**9 + 7
MAXN = 500000

# 预处理阶乘和逆阶乘
fac = [1] * (MAXN + 1)
inv_fac = [1] * (MAXN + 1)

for i in range(1, MAXN + 1):
    fac[i] = fac[i - 1] * i % MOD

inv_fac[MAXN] = pow(fac[MAXN], MOD - 2, MOD)
for i in range(MAXN, 0, -1):
    inv_fac[i - 1] = inv_fac[i] * i % MOD

def comb(n, k):
    """返回组合数 C(n, k) 模 MOD"""
    if k < 0 or k > n:
        return 0
    return fac[n] * inv_fac[k] % MOD * inv_fac[n - k] % MOD

def solve_case(s: str) -> int:
    cnt1 = s.count('1')
    cnt0 = len(s) - cnt1
    ans = 0

    # 枚举选择 1 的个数
    for k in range(1, cnt1 + 1):
        ways_one = comb(cnt1, k)

        # 选择 0 的个数必须是 k 的倍数
        ways_zero = 0
        for y in range(0, cnt0 + 1, k):
            ways_zero = (ways_zero + comb(cnt0, y)) % MOD

        ans = (ans + ways_one * ways_zero) % MOD

    return ans

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        print(solve_case(s))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class Main {
    static final long MOD = 1000000007L;
    static final int MAXN = 500000;

    static long[] fac = new long[MAXN + 1];
    static long[] invFac = new long[MAXN + 1];

    static long qpow(long a, long b) {
        long res = 1;
        while (b > 0) {
            if ((b & 1) == 1) {
                res = res * a % MOD;
            }
            a = a * a % MOD;
            b >>= 1;
        }
        return res;
    }

    static void init() {
        fac[0] = 1;
        for (int i = 1; i <= MAXN; i++) {
            fac[i] = fac[i - 1] * i % MOD;
        }

        invFac[MAXN] = qpow(fac[MAXN], MOD - 2);
        for (int i = MAXN; i >= 1; i--) {
            invFac[i - 1] = invFac[i] * i % MOD;
        }
    }

    static long comb(int n, int k) {
        if (k < 0 || k > n) {
            return 0;
        }
        return fac[n] * invFac[k] % MOD * invFac[n - k] % MOD;
    }

    static long solveCase(String s) {
        int cnt1 = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '1') {
                cnt1++;
            }
        }
        int cnt0 = s.length() - cnt1;

        long ans = 0;
        for (int k = 1; k <= cnt1; k++) {
            long waysOne = comb(cnt1, k);

            long waysZero = 0;
            for (int y = 0; y <= cnt0; y += k) {
                waysZero = (waysZero + comb(cnt0, y)) % MOD;
            }

            ans = (ans + waysOne * waysZero) % MOD;
        }
        return ans;
    }

    public static void main(String[] args) throws Exception {
        init();
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine().trim());
        StringBuilder sb = new StringBuilder();

        while (T-- > 0) {
            int n = Integer.parseInt(br.readLine().trim()); // n 虽然读入，但可直接用字符串长度
            String s = br.readLine().trim();
            sb.append(solveCase(s)).append('\n');
        }

        System.out.print(sb.toString());
    }
}
```
