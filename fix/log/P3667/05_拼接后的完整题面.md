# 题目内容
一块农田分成 $n$ 行 $m$ 列的格子。需要在每个格子种下一种作物，作物种类编号为 $1$ 到 $k$，并满足：

- 每个格子的作物编号都在 $1$ 到 $k$ 之间；
- 每种编号恰好出现 $\dfrac{n \cdot m}{k}$ 次；
- 对每个 $a \in [1, k]$，所有种有编号 $a$ 的格子在四连通意义下构成一个连通块。

四连通：当 $|x-x'|+|y-y'|=1$ 时，格子 $(x,y)$ 与 $(x',y')$ 相邻。

保证 $k$ 整除 $n \cdot m$。请给出任意一种合法种植方案。

约束：测试组数不超过 `10^4`，每组满足 $2 \le n \cdot m \le 2 \times 10^5$，且所有测试中 $n \cdot m$ 之和不超过 `3×10^5`。

# 输入描述
第一行一个整数 $t$，表示测试组数。
接下来 $t$ 行，每行三个整数 $n$、$m$、$k$，表示行数、列数与作物种类数。
保证 $1 \le t \le 10^4$，$k$ 整除 $n \cdot m$，且 $2 \le n \cdot m \le 2 \times 10^5$，所有测试中 $\sum n \cdot m \le 3 \times 10^5$。

# 输出描述
对每组数据输出 $n$ 行，每行 $m$ 个整数，表示一种满足条件的种植方案。若有多种方案，输出任意一种即可。

## 样例1

**输入**

```
2
2 2 2
2 4 2
```

**输出**

```
1 1
2 2
1 1 1 1
2 2 2 2
```

**说明**

第一组 $n=2,m=2,k=2$，每种作物出现 `2` 次。按蛇形先填两个 `1`、再填两个 `2`，得到两行各一种作物，各自四连通。
第二组每种出现 `4` 次，同样按行填满，每种连成一整行。

## 样例2

**输入**

```
1
3 3 3
```

**输出**

```
1 1 1
2 2 2
3 3 3
```

**说明**

$3 \times 3$ 格子种 `3` 种作物，每种出现 `3` 次。蛇形路径依次走完三行，每种恰好占连续三个格子，因此每行一种作物，均四连通。

## 样例3

**输入**

```
1
2 3 1
```

**输出**

```
1 1 1
1 1 1
```

**说明**

只有一种作物 $k=1$，全部格子都填 `1`。整块农田本身就是一个连通块。

## 样例4

**输入**

```
1
1 4 2
```

**输出**

```
1 1 2 2
```

**说明**

一行四列，$k=2$，每种出现 `2` 次。从左到右先填两个 `1` 再填两个 `2`，各自构成连续段，四连通成立。这是只有一行的边界情形。
