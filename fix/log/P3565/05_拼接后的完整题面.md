# 题目内容
园区设备按整数编号连续排列。运维计划给出闭区间 $[l,r]$，并规定只抽检编号满足 $i \bmod k = x$ 的设备：这些编号对应同一巡检班次。调度员需要快速统计该区间里有多少台设备属于这个班次，以便安排当班人手。

给定四个整数 $l,r,k,x$，求闭区间 $[l,r]$ 中有多少个整数 $i$ 满足 $i \bmod k = x$。

约束：测试组数不超过 `10000`，区间端点不超过 `1000000000`，模数 $k$ 不超过 `1000000000`，且 $0 \le x \le k-1$。

# 输入描述
第一行一个整数 $T$，表示测试组数。
接下来 $T$ 行，每行四个整数 $l,r,k,x$。
保证 $1 \le T \le 10000$，$1 \le l \le r \le 1000000000$，$1 \le k \le 1000000000$，$0 \le x \le k-1$。

# 输出描述
对每组数据输出一行一个整数，表示区间内满足同余条件的数的个数。

## 样例1

**输入**

```
3
2 8 3 2
7 7 5 2
1 100 10 0
```

**输出**

```
3
1
10
```

**说明**

第一组：区间 $[2,8]$ 中模 `3` 余 `2` 的数是 `2,5,8`，共 `3` 个。

第二组：区间退化为单点 `7`，$7 \bmod 5=2$，计 `1` 个。

第三组：$[1,100]$ 中模 `10` 余 `0` 的数是 `10,20,\ldots,100`，共 `10` 个。

## 样例2

**输入**

```
1
100 200 7 3
```

**输出**

```
15
```

**说明**

$[100,200]$ 中第一个满足 $i \bmod 7=3$ 的是 `101`，最后一个是 `199`，个数为 $\lfloor (199-101)/7 \rfloor + 1 = 15$。
