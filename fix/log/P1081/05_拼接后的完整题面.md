# 题目内容
有一棵 $n$ 个节点的无向树。每个节点被涂成两种颜色之一：字符 `R` 或字符 `B`。
删掉树上任意一条边后，树会分成两棵子树。在一棵子树中，颜色相同且通过子树内部边相连的节点构成一个同色连通块。
定义一条边的权值为：删掉该边后，两棵子树的同色连通块个数之差的绝对值。请计算树上所有边的权值之和。

约束条件：
- 节点数 $n$ 为正整数，且不超过 $200000$。
- 颜色字符串长度为 $n$，仅由字符 `R` 和 `B` 组成。
- 边的端点编号均在 `1` 到 $n$ 之间。

# 输入描述
第一行包含一个正整数 $n$，表示节点个数。
第二行包含一个长度为 $n$ 的字符串，仅由字符 `R` 和 `B` 组成，第 $i$ 个字符表示编号为 $i$ 的节点的颜色。
接下来 $n-1$ 行，每行两个正整数 $u$ 和 $v$，表示节点 $u$ 与节点 $v$ 之间有一条边。

# 输出描述
输出一个整数，表示所有边的权值之和。

## 样例1

**输入**

```
5
BRRBB
1 2
2 3
1 4
4 5
```

**输出**

```
3
```

**说明**

节点颜色依次为 `B,R,R,B,B`。整棵树的同色连通块数为 `3`（一块 `B` 在节点 `1`，一块 `R` 为节点 `2,3`，一块 `B` 为节点 `4,5`）。
断开边 $(1,2)$ 后两棵子树的同色连通块数为 `2` 与 `1`，权值为 `1`；断开 $(2,3)$ 权值为 `1`；断开 $(1,4)$ 权值为 `1`；断开 $(4,5)$ 权值为 `0`。
权值之和为 `3`。

## 样例2

**输入**

```
2
RR
1 2
```

**输出**

```
0
```

**说明**

两个节点颜色均为 `R`，整棵树只有 `1` 个同色连通块。
断开唯一的边后，两侧各 `1` 个连通块，差的绝对值为 `0`。

## 样例3

**输入**

```
2
RB
1 2
```

**输出**

```
0
```

**说明**

两个节点颜色不同，整棵树有 `2` 个同色连通块。
断开边后两侧各 `1` 个连通块，差的绝对值为 `0`。

## 样例4

**输入**

```
1
B
```

**输出**

```
0
```

**说明**

只有一个节点，树上没有边，权值之和为 `0`。
