# 题目内容
长度为 $n$ 的排列是指由 `1` 到 $n$ 各出现一次构成的序列。称排列 $a$ 满足镜像条件，当且仅当对每个 $i \in [1, n]$ 都有

$$a_{a_i}=n-a_i+1$$

请在所有满足镜像条件的排列中，找出字典序最大的一个。

排列长度不超过 `10^5`。

# 输入描述
一行一个正整数 $n$（$1 \le n \le 10^5$），表示排列长度。

# 输出描述
输出一行 $n$ 个正整数，用空格隔开，表示字典序最大的镜像排列。

## 样例1

**输入**

```
1
```

**输出**

```
1
```

**说明**

$n=1$ 时唯一排列为 `1`，显然满足镜像条件。这是最小规模边界。

## 样例2

**输入**

```
4
```

**输出**

```
4 3 2 1
```

**说明**

字典序最大的镜像排列为 $4,3,2,1$。对每个 $i$ 均有 $a_{a_i}=5-a_i$。

## 样例3

**输入**

```
2
```

**输出**

```
2 1
```

**说明**

按题意模拟计算得到。
