## 解题思路

本题与「镜像编队」描述的计算任务一致。按输入格式读入数据后，沿用原题解的算法即可。

详见下方代码实现。

## 复杂度分析

- 时间复杂度与原题解相同。
- 空间复杂度与原题解相同。

## 代码实现

### Python

```python
n = int(input())

for i in reversed(range(1, n + 1)):
    print(i, end = ' ')
```

### C++

