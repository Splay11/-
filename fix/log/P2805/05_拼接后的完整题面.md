# 题目内容
有一个初始序列，仅由数字 `0` 和 `1` 组成。在每一轮演变中，序列中的每个数字会按照以下规则同时进行变换，然后将所有变换结果按原顺序拼接形成新序列：

- 若数字为 `0`，则变换为 `1`；
- 若数字为 `1`，则变换为 `0` 后紧跟着 `1`（即产生两个数字 `0` 和 `1`，先 `0` 后 `1`）。

现在给定初始序列以及需要进行的演变轮数 $n$，请你求出经过 $n$ 轮演变后序列的长度。由于结果可能非常大，请输出长度对 $10^9+7$ 取模后的值。

本题包含多组测试数据。序列的长度不超过 $10^5$，轮数 $n$ 不超过 $10^{18}$，所有测试数据中 $n$ 的总和不超过 $3 \times 10^5$。

# 输入描述
第一行包含一个整数 $T$ ($1 \le T \le 10^5$)，表示数据组数。接下来 $T$ 行，每行包含一个由字符 `0` 和 `1` 组成的字符串 $s$ 和一个整数 $n$ ($1 \le n \le 10^{18}$)，两者之间用一个空格分隔，表示初始序列和演变轮数。保证 $1 \le |s| \le 10^5$，且所有测试数据的 $n$ 之和不超过 $3 \times 10^5$。

# 输出描述
对于每组测试数据，输出一行一个整数，表示经过 $n$ 轮演变后序列的长度对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
1
0 1
```

**输出**

```
1
```

**说明**

初始序列为单个字符 `0`，演变轮数 $n=1$。根据规则，`0` 经过 $1$ 轮变换后变为 `1`，长度为 $1$。因此答案为 $1$。

## 样例2

**输入**

```
1
1 2
```

**输出**

```
3
```

**说明**

初始序列为单个字符 `1`，演变轮数 $n=2$。

第 $1$ 轮：`1` 变为 `0` 和 `1`，序列长度为 $2$。

第 $2$ 轮：`0` 变为 `1`，`1` 变为 `0` 和 `1`，得到序列 `1` `0` `1`，长度为 $3$。

或用递推公式：字符 `1` 经 $n$ 轮后长度为斐波那契数 $F_{n+2}$（$F_1=1,F_2=1$），$F_4=3$，故答案为 $3$。

## 样例3

**输入**

```
2
01 3
110 5
```

**输出**

```
8
34
```

**说明**

共 $2$ 组数据。

第 $1$ 组：序列 `01`，$n=3$。字符 `0` 经 $3$ 轮长度为 $F_{4}=3$，字符 `1` 经 $3$ 轮长度为 $F_{5}=5$，总长度 $3+5=8$。

第 $2$ 组：序列 `110`（$2$ 个 `1` 和 $1$ 个 `0`），$n=5$。此时 $F_6=8$，$F_7=13$，总长度为 $2 \times 13 + 8 = 34$。
