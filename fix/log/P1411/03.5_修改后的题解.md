## 解题思路

正整数对满足 $x + y = s$ 且 $x, y \ge 1$，等价于 $x$ 取遍 $1, 2, \ldots, s-1$，对应 $y = s - x$。不计禁用时一共有 $s-1$ 个有序对。

禁用集合会让部分有序对非法。采用「正难则反」：从 $s-1$ 出发减去被禁用破坏的对。把禁用值放入哈希集合，然后枚举每个禁用值 $g$：

- 若 $g \ge s$，它不可能作为 $x$ 或 $y$，忽略；
- 若 $g = s/2$（此时 $s$ 为偶数），只有有序对 $(g, g)$ 被破坏，答案减 `1`；
- 否则有序对 $(g, s-g)$ 与 $(s-g, g)$ 都会非法，答案减 `2`。

每对互补的禁用值只应处理一次，因此处理完 $g$ 后同时从集合中删去 $g$ 与 $s-g$，避免重复扣减。

$s$ 最大为 $10^9$，答案用 `64` 位整数存储。

## 复杂度分析

建集合与枚举禁用值均为线性。

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
n = int(input())
v = list(map(int, input().split()))
s = int(input())
st = set(v)
ans = s - 1
for g in v:
    if g < s and g in st:
        if g * 2 == s:
            ans -= 1
        else:
            ans -= 2
    st.discard(g)
    st.discard(s - g)
print(ans)
```

### Java

```java
import java.util.HashSet;
import java.util.Scanner;
import java.util.Set;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] v = new int[n];
        Set<Integer> st = new HashSet<>();
        for (int i = 0; i < n; i++) {
            v[i] = sc.nextInt();
            st.add(v[i]);
        }
        int s = sc.nextInt();
        long ans = s - 1L;
        for (int g : v) {
            if (g < s && st.contains(g)) {
                if (g * 2L == s) {
                    ans -= 1;
                } else {
                    ans -= 2;
                }
            }
            st.remove(g);
            st.remove(s - g);
        }
        System.out.println(ans);
        sc.close();
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> v(n);
    unordered_set<int> st;
    for (int i = 0; i < n; i++) {
        cin >> v[i];
        st.insert(v[i]);
    }
    int s;
    cin >> s;
    long long ans = s - 1LL;
    for (int g : v) {
        if (g < s && st.count(g)) {
            if (g * 2LL == s) {
                ans -= 1;
            } else {
                ans -= 2;
            }
        }
        st.erase(g);
        st.erase(s - g);
    }
    cout << ans << "\n";
    return 0;
}
```
