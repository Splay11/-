# 题目内容
给定目标和 $s$，以及 $n$ 个互不相同的禁用正整数。请统计有序正整数对 $(x, y)$ 的个数，同时满足：

- $x \ge 1$ 且 $y \ge 1$；
- $x + y = s$；
- $x$ 与 $y$ 都不属于禁用集合。

当 $x 
e y$ 时，$(x, y)$ 与 $(y, x)$ 视为两种不同方案。

约束：$1 \le n \le 2 \times 10^5$，$1 \le a_i, s \le 10^9$，保证所有禁用值互不相同。

# 输入描述
第一行一个正整数 $n$，表示禁用值的个数。
第二行 $n$ 个互不相同的正整数，表示禁用集合。
第三行一个正整数 $s$，表示目标和。
保证 $1 \le n \le 2 \times 10^5$，$1 \le a_i, s \le 10^9$。

# 输出描述
输出一个整数，表示合法有序对的个数。

## 样例1

**输入**

```
1
5
10
```

**输出**

```
8
```

**说明**

不计禁用时有 `9` 个有序对。$s$ 为偶数且 `5` 恰好为 $s/2$，只破坏 $(5,5)$ 这一种，答案为 $9-1=`8`。

## 样例2

**输入**

```
2
1 2
4
```

**输出**

```
0
```

**说明**

可能的有序对为 $(1,3)$、$(2,2)$、$(3,1)$。`1` 与 `2` 都被禁用，三对全部非法，答案为 `0`。

## 样例3

**输入**

```
1
5
11
```

**输出**

```
8
```

**说明**

按题意模拟计算得到。
