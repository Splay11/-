## 解题思路

对每家商户维护成交总价 $\mathrm{sum}$ 与成交次数 $\mathrm{cnt}$。没有成交（$\mathrm{cnt}=0$）的商户不参与统计。

漂移条件为 $\lvert \mathrm{sum}/\mathrm{cnt}-r\rvert>x$。为避免浮点误差，两边同乘 $\mathrm{cnt}$ 得到整数判定

$$
\lvert \mathrm{sum}-r\cdot\mathrm{cnt}\rvert > x\cdot\mathrm{cnt}.
$$

用哈希表把商户名映射到下标，扫一遍成交记录即可。

## 复杂度分析

时间复杂度 $O(n+m)$，空间复杂度 $O(n)$。

## 代码实现

### Python

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    x = int(next(it))
    idx = {}
    r = []
    sumv = []
    cnt = []
    for i in range(n):
        name = next(it)
        ri = int(next(it))
        idx[name] = i
        r.append(ri)
        sumv.append(0)
        cnt.append(0)
    for _ in range(m):
        name = next(it)
        s = int(next(it))
        i = idx[name]
        sumv[i] += s
        cnt[i] += 1
    ans = 0
    for i in range(n):
        if cnt[i] == 0:
            continue
        left = abs(sumv[i] - r[i] * cnt[i])
        right = x * cnt[i]
        if left > right:
            ans += 1
    print(ans)

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());
        long x = Long.parseLong(st.nextToken());
        HashMap<String, Integer> idx = new HashMap<>(n * 2);
        long[] r = new long[n];
        long[] sum = new long[n];
        long[] cnt = new long[n];
        for (int i = 0; i < n; i++) {
            st = new StringTokenizer(br.readLine());
            String name = st.nextToken();
            long ri = Long.parseLong(st.nextToken());
            idx.put(name, i);
            r[i] = ri;
        }
        for (int j = 0; j < m; j++) {
            st = new StringTokenizer(br.readLine());
            String name = st.nextToken();
            long s = Long.parseLong(st.nextToken());
            int i = idx.get(name);
            sum[i] += s;
            cnt[i] += 1;
        }
        int ans = 0;
        for (int i = 0; i < n; i++) {
            if (cnt[i] == 0) continue;
            long left = Math.abs(sum[i] - r[i] * cnt[i]);
            long right = x * cnt[i];
            if (left > right) ans++;
        }
        System.out.println(ans);
    }
}
```
