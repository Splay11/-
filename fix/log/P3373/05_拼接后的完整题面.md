# 题目内容
平台登记了 $n$ 家商户，第 $i$ 家的挂牌价为 $r_i$。随后产生 $m$ 笔成交记录，每笔给出商户名与成交价。对一家商户，若它至少有一笔成交，设其 $k$ 笔成交价之和为 $S$，则当且仅当

$$\left|\frac{S}{k}-r_i\right|>x$$

时称该商户发生报价漂移。没有成交记录的商户不计入统计。

请统计发生报价漂移的商户数量。

商户数不超过 `100`，成交条数不超过 $10^5$，挂牌价、成交价与阈值均为不超过 `5000` 的非负整数。商户名仅由小写字母组成，全部字符串总长不超过 $4\times 10^5$。

# 输入描述
第一行包含三个整数 $n$、$m$ 和 $x$，分别表示商户数量、成交条数与允许的最大价差，满足 $1 \le n \le 100$，$0 \le m \le 10^5$，$0 \le x \le 5000$。
接下来 $n$ 行，第 $i$ 行包含一个由小写字母组成的字符串 $name_i$ 和一个整数 $r_i$（$1 \le r_i \le 5000$），表示第 $i$ 家商户的名称与挂牌价。
接下来 $m$ 行，第 $j$ 行包含一个由小写字母组成的字符串 $name_j$ 和一个整数 $a_j$（$1 \le a_j \le 5000$），表示一笔成交。保证每个成交名都出现在上述 $n$ 家商户中。
全部字符串总长度不超过 $4\times 10^5$。

# 输出描述
输出一个整数，表示发生报价漂移的商户数量。

## 样例1

**输入**

```
2 2 0
alice 4039
bob 1
alice 4039
bob 4039
```

**输出**

```
1
```

**说明**

商户 $alice$ 成交均价为 `4039`，与挂牌价之差为 `0`，不超过阈值 `0`。
商户 $bob$ 成交均价为 `4039`，与挂牌价 `1` 之差为 `4038`，严格大于 `0`。
因此仅 `1` 家商户漂移。

## 样例2

**输入**

```
2 0 10
jly 4039
tou 1
```

**输出**

```
0
```

**说明**

没有任何成交记录，两家商户均不计入统计，答案为 `0`。

## 样例3

**输入**

```
1 2 0
cat 2
cat 1
cat 5
```

**输出**

```
1
```

**说明**

均价为 $(1+5)/2=`3`$，与挂牌价 `2` 之差为 `1`，严格大于阈值 `0`，答案为 `1`。

## 样例4

**输入**

```
3 3 1
aa 5
bb 5
cc 5
aa 5
aa 6
bb 5
```

**输出**

```
0
```

**说明**

$aa$ 两笔成交和为 `11`，$|11-5\times 2|=`1`$ 不大于 $x\times k=`2$，未漂移。
$bb$ 均价恰好等于挂牌价。$cc$ 无成交，不计入。答案为 `0`。
