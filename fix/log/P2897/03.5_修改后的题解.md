## 解题思路

1. **理解光标与已提交前缀的关系**  
   字符串 $s$ 的下标从 $1$ 到 $n$。用 $t$ 表示每个字符是否已提交，$t_i=1$ 表示已提交，$0$ 表示未提交。  
   已提交部分必然是 $s$ 的一个前缀，设当前前缀长度为 $k$（即前 $k$ 个字符已提交）。每次操作将光标左移或右移一个位置，对应将 $k$ 减少 $1$ 或增加 $1$。  
   因此，问题转化为：通过最少次数的 $k \pm 1$ 操作，调整 $k$ 的值，使得 $s$ 的未提交后缀（$s[k+1\ldots n]$）中，字母 `a` 到 `z` 的出现次数分别等于给定的 $c_1,c_2,\dots,c_{26}$。

2. **确定唯一可行的前缀长度**  
   未提交后缀的长度为 $n-k$。该后缀需要包含的总字符数等于目标要求的总和：  
   $$m = \sum_{i=1}^{26} c_i$$  
   要使得后缀能正好满足要求，后缀长度必须等于 $m$，即  
   $$n - k = m \quad\Rightarrow\quad k = n - m$$  
   也就是说，目标前缀长度是唯一确定的：$k^* = n - m$。题目保证至少存在一种可行方案，因此 $0 \le k^* \le n$ 且满足要求。

3. **计算最少操作次数**  
   初始已提交前缀长度 $k_0$ 等于字符串 $t$ 中 `1` 的个数（因为所有 `1` 出现在前缀中）。  
   每次操作只能改变 $k$ 的数值 $1$，所以从 $k_0$ 调整到 $k^*$ 所需的最少操作为它们的绝对差：  
   $$\text{ans} = |\,k_0 - (n - m)\,|$$  
   输出该值即可。

## 复杂度分析

- 时间复杂度：  
  读取 $26$ 个整数并求和需要 $O(26)$。  
  读取字符串 $s$ 和 $t$，并统计 $t$ 中 `1` 的个数需要 $O(n)$。  
  其余为常数时间，总时间复杂度为 $O(n)$。

- 空间复杂度：  
  存储字符串 $s$ 和 $t$ 需要 $O(n)$ 空间；存储 $26$ 个目标次数和若干个变量，空间为 $O(1)$。  
  总空间复杂度为 $O(n)$。

## 代码实现

### Python

```python
def main():
    # 读入26个目标出现次数
    cnt = list(map(int, input().split()))
    m = sum(cnt)          # 目标后缀需要的总字符数
    n = int(input())      # 字符串长度
    s = input()           # 原始字符串
    t = input()           # 提交标记字符串

    # 初始已提交前缀长度 = t中'1'的个数
    k0 = t.count('1')
    # 目标前缀长度
    kt = n - m
    # 最少操作次数
    print(abs(k0 - kt))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        // 读取26个目标次数
        StringTokenizer st = new StringTokenizer(br.readLine());
        int m = 0;
        for (int i = 0; i < 26; i++) {
            m += Integer.parseInt(st.nextToken());
        }

        int n = Integer.parseInt(br.readLine());  // 字符串长度
        String s = br.readLine();                 // 原始字符串（本题算法中用不到）
        String t = br.readLine();                 // 提交标记字符串

        // 计算初始已提交前缀长度（t中'1'的个数）
        int k0 = 0;
        for (int i = 0; i < n; i++) {
            if (t.charAt(i) == '1') {
                k0++;
            } else {
                break; // 所有1都在0之前，遇到0即可停止
            }
        }

        int kt = n - m;  // 目标前缀长度
        System.out.println(Math.abs(k0 - kt));
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // 读入26个目标次数，计算总和 m
    long long m = 0;  // 题目中 m 可能达到 2e5，用int也可，但用 long long 更安全
    for (int i = 0; i < 26; ++i) {
        int x;
        cin >> x;
        m += x;
    }

    int n;
    cin >> n;
    string s, t;
    cin >> s >> t;

    // 计算初始已提交前缀长度（t中'1'的个数）
    int k0 = 0;
    for (char c : t) {
        if (c == '1') k0++;
        else break;   // 所有1都在前面，遇到0即可停止
    }

    int kt = n - m;   // 目标前缀长度
    cout << abs(k0 - kt) << "\n";

    return 0;
}
```
