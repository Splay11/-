# 题目内容
你正在设计一款包含 $n$ 个关卡的闯关游戏。每个关卡 $i$ 有三个参数：基础分 $base_i$、实际得分 $score_i$ 和倍率 $mult_i$。你的总得分定义为

$\sum_{i=1}^{n} (score_i - base_i) \cdot mult_i$

你拥有一次特殊权限：可以选择任意两个关卡，并将它们的基础分交换（即交换数组 $base$ 中的两个元素）。你可以选择不进行任何交换。

请计算最多使用一次交换操作后，总得分的最大可能值。

**数据范围**：关卡数量 $n$ 不超过 `10^5`，所有基础分 $base_i$、实际得分 $score_i$ 和倍率 $mult_i$ 均为整数，且都在 `1` 到 `10^3` 之间。

# 输入描述
第一行包含一个整数 $n$（$1 \le n \le 10^5$）。
第二行包含 $n$ 个整数，表示每个关卡的基础分 $base_i$。
第三行包含 $n$ 个整数，表示每个关卡的实际得分 $score_i$。
第四行包含 $n$ 个整数，表示每个关卡的倍率 $mult_i$。
所有 $base_i, score_i, mult_i$ 的取值范围均为 `1` 到 `1000`。

# 输出描述
输出一个整数，表示最多进行一次基础分交换后的最大总得分。

## 样例1

**输入**

```
2
2 8
5 10
3 1
```

**输出**

```
11
```

**说明**

不进行任何交换时，总得分为 $(5 - 2) \times 3 + (10 - 8) \times 1 = 9 + 2 = 11$。
若交换两个关卡的基础分，增益公式为 $(a_i - a_j)(c_i - c_j)$。交换 `2` 和 `8` 时，增益为 $(2 - 8) \times (3 - 1) = -12$，总得分变为 $11 + (-12) = -1$，比不交换更差。因此最大总得分为 `11`。

## 样例2

**输入**

```
3
1 10 5
10 10 10
1 10 5
```

**输出**

```
115
```

**说明**

原始总得分 $s = (10-1)\times1 + (10-10)\times10 + (10-5)\times5 = 9 + 0 + 25 = 34$。
交换关卡 $1$（$a_1=1$, $c_1=1$）和关卡 $2$（$a_2=10$, $c_2=10$）时，增益为 $(1-10)\times(1-10) = 81$，总得分变为 $34 + 81 = 115$。
其他交换的收益分别为 $16$ 和 $25$，均小于 `81`，因此最大总得分为 `115`。

## 样例3

**输入**

```
1
7
10
3
```

**输出**

```
9
```

**说明**

只有一个关卡，无法进行有意义的交换（或交换自身），增益为 `0`。
原始得分 $(10 - 7) \times 3 = 9$，所以最大总得分为 `9`。
