# 题目内容
在一个古镇中有三座独立的钟楼。每座钟楼会按照一个固定的周期敲响：第一座每 $A$ 分钟敲一次，第二座每 $B$ 分钟敲一次，第三座每 $C$ 分钟敲一次。你可以自由设定每座钟楼第一次敲响的时刻（以整数分钟表示，$0$ 分钟表示起始时刻），此后它们便严格按照各自的周期循环敲响。

请问，是否存在一种设置首次敲钟时间的方案，使得从某个时刻开始，之后的每一分钟都至少有一座钟楼在敲钟？换句话说，这三个敲钟序列的并集能否覆盖所有足够大的自然数分钟？

所有测试用例中的周期 $A, B, C$ 均为不超过 $1500$ 的正整数。测试用例的总数量 $t$ 不超过 $10$。

# 输入描述
第一行包含一个整数 $t$ ($1 \le t \le 10$)，表示测试用例的数量。
接下来 $t$ 行，每行包含三个整数 $A, B, C$ ($1 \le A, B, C \le 1500$)，分别表示三座钟楼的敲钟周期。

# 输出描述
对于每个测试用例，输出一行结果。如果存在满足条件的首次敲钟时间设置，输出 `YES`；否则输出 `NO`。

## 样例1

**输入**

```
2
1 2 3
2 2 5
```

**输出**

```
YES
YES
```

**说明**

该样例包含两个测试用例。

第一个用例周期为 `1 2 3`：第一座钟楼每 `1` 分钟敲一次。只需将其首次敲钟设为第 `0` 分钟，此后每分钟都会敲钟，因此所有自然数分钟均被覆盖，输出 `YES`。

第二个用例周期为 `2 2 5`：其中有两座周期为 `2` 的钟楼。可以将一座设为第 `0` 分钟首次敲钟（覆盖所有偶数分钟），另一座设为第 `1` 分钟首次敲钟（覆盖所有奇数分钟）。两者并集已覆盖全部分钟，第三座钟楼可任意设置，故输出 `YES`。

## 样例2

**输入**

```
2
2 4 8
2 4 4
```

**输出**

```
NO
YES
```

**说明**

该样例包含两个测试用例。

第一个用例周期为 `2 4 8`：三个周期均为偶数，无论首次敲钟设为何值，每座钟楼只会在偶数分钟敲响。所有奇数分钟都无法被覆盖，因此不存在满足要求的方案，输出 `NO`。

第二个用例周期为 `2 4 4`：虽然没有周期为 `1` 的钟楼，但仍可构造出覆盖方案。将周期为 `2` 的钟楼首次敲钟设为 `0`（覆盖偶数分钟）；两个周期为 `4` 的钟楼分别设为 `1` 和 `3`。偏移 `1` 的序列为 $1,5,9,\dots$，覆盖所有模 $4$ 余 $1$ 的奇数；偏移 `3` 的序列为 $3,7,11,\dots$，覆盖所有模 $4$ 余 $3$ 的奇数。三者的并集恰好覆盖全部自然数分钟，因此输出 `YES`。
