## 解题思路

按固定顺序检查三个闭区间：

- $v\in[250,350]$ 则命中 `G`；
- $v\in[160,250]$ 则命中 `D`；
- $v\in[200,300]$ 则命中 `C`。

命中的级别按 `G`、`D`、`C` 顺序、以空格拼接输出；一个都不命中则输出 `other`。端点计入对应区间。

## 复杂度分析

每组 $O(1)$，总体时间复杂度 $O(T)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
import sys

data = sys.stdin.buffer.read().split()
if not data:
    sys.exit(0)

t = int(data[0])
ans = []
idx = 1

for _ in range(t):
    v = int(data[idx]); idx += 1
    parts = []
    if 250 <= v <= 350:
        parts.append('G')
    if 160 <= v <= 250:
        parts.append('D')
    if 200 <= v <= 300:
        parts.append('C')
    if parts:
        ans.append(' '.join(parts))
    else:
        ans.append('other')

sys.stdout.write('\n'.join(ans))
```

### Java

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder out = new StringBuilder();
        String s = br.readLine();
        while (s != null && s.trim().isEmpty()) s = br.readLine();
        if (s == null) {
            System.out.print("");
            return;
        }
        int T = Integer.parseInt(s.trim());
        for (int i = 0; i < T; i++) {
            String line = br.readLine();
            while (line != null && line.trim().isEmpty()) line = br.readLine();
            int v = Integer.parseInt(line.trim());
            boolean first = true;
            if (v >= 250 && v <= 350) {
                out.append("G");
                first = false;
            }
            if (v >= 160 && v <= 250) {
                if (!first) out.append(' ');
                out.append("D");
                first = false;
            }
            if (v >= 200 && v <= 300) {
                if (!first) out.append(' ');
                out.append("C");
                first = false;
            }
            if (first) out.append("other");
            if (i + 1 < T) out.append('\n');
        }
        System.out.print(out.toString());
    }
}
```
