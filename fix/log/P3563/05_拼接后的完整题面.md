# 题目内容
水质监测站按浊度读数把水体划入三类公开标准（单位相同，区间均为闭区间）：G 级标准对应 $[250,350]$，D 级标准对应 $[160,250]$，C 级标准对应 $[200,300]$。值班员读到一台传感器的浊度 $v$ 后，需要判断它可能同时命中哪几级标准。由于区间有交叠，$v$ 可能属于多级；若三级都不属于，则记为其它。

请按固定顺序给出全部命中结果。区间端点计入对应级别。

约束：测试组数不超过 `200000`，浊度 $v$ 满足 $0 \le v \le 400$。

# 输入描述
第一行一个整数 $T$，表示测试组数。
接下来 $T$ 行，每行一个整数 $v$，表示当前浊度读数。
保证 $1 \le T \le 200000$，$0 \le v \le 400$。

# 输出描述
对每组数据输出一行：按固定顺序 `G`、`D`、`C` 列出所有命中的级别，相邻级别以单个空格分隔。若不属于任何一级，输出 `other`。

## 样例1

**输入**

```
5
160
240
0
260
399
```

**输出**

```
D
D C
other
G C
other
```

**说明**

- $v=160$：只落在 D 档 $[160,250]$，输出 `D`。
- $v=240$：同时落在 D 档与 C 档，按顺序输出 `D C`。
- $v=0$：三档都不命中，输出 `other`。
- $v=260$：命中 G 档与 C 档，输出 `G C`。
- $v=399$：超出所有区间，输出 `other`。

## 样例2

**输入**

```
2
180
350
```

**输出**

```
D
G
```

**说明**

$v=180$ 只属于 D 档；$v=350$ 是 G 档右端点，只输出 `G`。
