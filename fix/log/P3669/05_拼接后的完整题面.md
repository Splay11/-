# 题目内容
通信系统中有两个通道编号 $a$、$b$，均需满足 $1 \le a, b \le n$。只有当它们的按位或不超过限额 $K$ 时，这对编号才被接受。

请统计满足条件的有序对 $(a,b)$ 的个数。答案可能很大，请对 $10^9+7$ 取模后输出。

按位或：两个整数对应二进制位做逻辑或，例如 $5 \mid 3 = 7$。

约束：测试组数不超过 `10^4`，$n$ 与 $K$ 均不超过 `10^18`，且 $n$ 至少为 `1`，$K$ 可以为 `0`。

# 输入描述
第一行一个整数 $t$，表示数据组数。
接下来 $t$ 行，每行两个整数 $n$、$K$。
保证 $1 \le t \le 10^4$，$1 \le n \le 10^{18}$，$0 \le K \le 10^{18}$。

# 输出描述
对每组数据输出一行一个整数，表示满足条件的有序对个数对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
3
5 3
5 1
10 5
```

**输出**

```
9
1
17
```

**说明**

当 $n=5,K=3$ 时，$a,b$ 只能取 $\{1,2,3\}$，共 $3 \times 3=9$ 对。
当 $n=5,K=1$ 时，只有 $(1,1)$ 的按位或不超过 `1`，答案为 `1`。
当 $n=10,K=5$ 时，统计结果为 `17`。

## 样例2

**输入**

```
2
1 0
1 1
```

**输出**

```
0
1
```

**说明**

$n=1,K=0$ 时唯一候选是 $(1,1)$，而 $1 \mid 1=1 > 0$，没有合法对，答案为 `0`。
$n=1,K=1$ 时 $(1,1)$ 满足 $1 \le 1$，答案为 `1`。这是最小规模边界。

## 样例3

**输入**

```
1
6 1
```

**输出**

```
1
```

**说明**

$n=6,K=1$ 时，大于 `1` 的编号按位或至少为自身，必然超过限额，因此只有 $(1,1)$ 合法，答案为 `1`。
