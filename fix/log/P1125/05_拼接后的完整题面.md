# 题目内容
小蓝在研究一个由正整数构成的序列，他定义了一种特殊的“平衡子段”：一个连续非空子段，如果它的所有元素的乘积与所有元素的按位异或结果相等，那么这个子段就是平衡的。现在小蓝想知道，给定的序列中一共有多少个不同的平衡子段。请帮他统计一下。

序列的长度不超过 $10^5$，序列中的每个数均为正整数且不超过 $10^9$。

# 输入描述
输入分为两行。第一行包含一个整数 $n$，表示序列的长度。第二行包含 $n$ 个整数，依次表示序列中的元素，数字之间用空格分隔。

# 输出描述
输出一个整数，表示满足条件的平衡子段的数量。

## 样例1

**输入**

```
1
10
```

**输出**

```
1
```

**说明**

序列仅有一个元素 `10`。其乘积为 `10`，按位异或也为 `10`，两者相等。因此唯一的子段即为平衡子段，总数为 `1`。

## 样例2

**输入**

```
4
1 1 1 1
```

**输出**

```
6
```

**说明**

序列为 `[1, 1, 1, 1]`。
- 长度为 `1` 的子段有 `4` 个，每个子段的乘积与异或值均为 `1`，全部为平衡子段。
- 长度为 `2` 的子段有 `3` 个，乘积为 `1`，异或值为 $1 \oplus 1 = 0$，不相等。
- 长度为 `3` 的子段有 `2` 个，乘积为 `1`，异或值为 $1 \oplus 1 \oplus 1 = 1$，相等，这两个子段平衡。
- 长度为 `4` 的子段乘积为 `1`，异或值为 `0`，不相等。
平衡子段总数为 $4 + 0 + 2 + 0 = 6$。

## 样例3

**输入**

```
5
1 2 1 2 1
```

**输出**

```
7
```

**说明**

序列为 `[1, 2, 1, 2, 1]`。
- 长度为 `1` 的子段：`[1]`, `[2]`, `[1]`, `[2]`, `[1]`，乘积与异或各自相等，共 `5` 个。
- 长度为 `2` 的子段：`[1,2]`（乘积 `2`，异或 `3`），`[2,1]`（`2` vs `3`），`[1,2]`（`2` vs `3`），`[2,1]`（`2` vs `3`），均不平衡。
- 长度为 `3` 的子段：`[1,2,1]` 乘积 $1 \times 2 \times 1 = 2$，异或 $1 \oplus 2 \oplus 1 = 2$，平衡；`[2,1,2]` 乘积 `4`，异或 `1`，不平衡；`[1,2,1]` 平衡。共 `2` 个。
- 长度为 `4` 的子段：`[1,2,1,2]` 乘积 `4`，异或 `0`；`[2,1,2,1]` 乘积 `4`，异或 `0`，均不平衡。
- 长度为 `5` 的子段：乘积 `4`，异或 `1`，不平衡。
总数为 $5 + 0 + 2 + 0 + 0 = 7$。

## 样例4

**输入**

```
3
1 2 3
```

**输出**

```
3
```

**说明**

序列为 `[1, 2, 3]`。
单元素子段 `[1]`, `[2]`, `[3]` 各自乘积等于异或值，均为平衡子段。
多元素子段 `[1,2]`（乘积 `2`，异或 `3`）、`[2,3]`（乘积 `6`，异或 `1`）以及 `[1,2,3]`（乘积 `6`，异或 `0`）均不平衡。
总数为 `3`。
