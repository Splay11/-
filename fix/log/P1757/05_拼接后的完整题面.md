# 题目内容
仓储侧有一列长度为 $n$ 的库存记录 $a_i$（可以为负，表示欠货）。调度最多做一次操作：选出一段所有元素都是偶数的连续区间，把这段里的每个数都除以 `2`（按向零取整，与整数除法一致）。也可以不操作。

请最大化操作后所有记录之和。

约束：$1 \le n \le 100000$，数组元素满足 $-1000000000 \le a_i \le 1000000000$。

# 输入描述
第一行包含一个正整数 $n$，表示数组长度，满足 $1 \le n \le 100000$。

第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$，满足 $-1000000000 \le a_i \le 1000000000$。

# 输出描述
输出一个整数，表示操作后数组元素之和的最大值。

## 样例1

**输入**

```
4
6 3 -8 4
```

**输出**

```
9
```

**说明**

原数组之和为 `5`。偶数段 $[-8,4]$ 中，把 $[-8]$ 折半变为 $[-4]$ 后，总和变为 `9`。

这比不操作更优。

## 样例2

**输入**

```
3
1 3 5
```

**输出**

```
9
```

**说明**

三个数都是奇数，不存在全为偶数的区间，无法操作。

答案就是原数组之和 `9`。

## 样例3

**输入**

```
1
-10
```

**输出**

```
-5
```

**说明**

唯一元素是偶数，将其折半得到 `-5`，总和更大。

## 样例4

**输入**

```
6
9 -2 -12 7 8 -4
```

**输出**

```
13
```

**说明**

原数组之和为 `6`。在偶数段 $[-2,-12]$ 上把整段折半，相当于减去该段和的一半，总和变为 `13`。
