## 解题思路

不操作时答案就是原数组之和 $S$。一次操作只能选一段全为偶数的连续区间并全部除以 $2$，等价于从 $S$ 中减去该段和的一半。

因此：

- 先按奇数把数组切成若干极大偶数段；
- 在每个偶数段内，求出最小子段和 $T$（只有 $T<0$ 时折半才会让总和变大）；
- 用 $S - \lfloor T/2\rfloor$ 更新答案。

最小子段和可以用与最大子段和对称的贪心：累加，一旦当前和变为非负就清空。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(n)$。

## 代码实现

### Python

```python
n = int(input())
a = list(map(int, input().split()))
suma = sum(a)
l = 0
ans = suma
while l < n:
    while l < n and a[l] % 2 != 0:
        l += 1
    if l < n:
        r = l
        while r < n and a[r] % 2 == 0:
            r += 1
        cur = 0
        while l < r:
            cur += a[l]
            if cur < 0:
                ans = max(ans, suma - cur // 2)
            else:
                cur = 0
            l += 1
print(ans)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long[] a = new long[n];
        long suma = 0;
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextLong();
            suma += a[i];
        }
        long ans = suma;
        int l = 0;
        while (l < n) {
            while (l < n && a[l] % 2 != 0) l++;
            if (l < n) {
                int r = l;
                while (r < n && a[r] % 2 == 0) r++;
                long cur = 0;
                while (l < r) {
                    cur += a[l];
                    if (cur < 0) ans = Math.max(ans, suma - cur / 2);
                    else cur = 0;
                    l++;
                }
            }
        }
        System.out.println(ans);
        sc.close();
    }
}
```
