# 题目内容
登机口有一排恰好 `5` 个牌槽，编号从 `1` 开始。五个槽位上的登机牌字母恰好是字符 `a`、`b`、`c`、`d`、`e` 各一次。地勤需要找到印有字符 `a` 的那张牌。请输出它的槽位编号。

约束：输入字符串长度恰好为 `5`，且为 `a` 到 `e` 的一个排列。

# 输入描述
一行，一个长度为 `5` 的字符串，保证恰好含一个 `a`、一个 `b`、一个 `c`、一个 `d`、一个 `e`。

# 输出描述
输出一个整数，表示字符 `a` 的槽位编号（从 `1` 计起）。

## 样例1

**输入**

```
debca
```

**输出**

```
5
```

**说明**

密钥带为 `debca`，字符 `a` 在第 `5` 个槽位。

## 样例2

**输入**

```
ecdab
```

**输出**

```
4
```

**说明**

`a` 出现在第 `4` 个槽位。

## 样例3

**输入**

```
bedac
```

**输出**

```
4
```

**说明**

从左扫描，`a` 位于第 `4` 位。
