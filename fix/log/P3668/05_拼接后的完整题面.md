# 题目内容
仪器给出三个整数读数 $a$、$b$、$c$。你必须恰好执行一次如下调整：选择一个整数倍率 $m$，并把 $a$、$b$、$c$ 中恰好一个数乘以 $m$。调整完成后，三个数允许任意重排。

请判断是否存在一种选择，使得最终三个数可以重排成等比数列。等比数列允许公比为 `0` 或负数，例如 $1,0,0$ 的公比为 `0`。

约束：测试组数不超过 `10^4`，每个读数的绝对值不超过 `10^9`。

# 输入描述
每个测试文件包含多组数据。第一行一个整数 $t$，表示数据组数。
每组数据一行，包含三个整数 $a$、$b$、$c$。
保证 $1 \le t \le 10^4$，$-10^9 \le a, b, c \le 10^9$。

# 输出描述
对每组数据输出一行。若存在可行方案，输出 `YES`；否则输出 `NO`。

## 样例1

**输入**

```
4
2 3 6
1 2 3
2 4 8
5 1 25
```

**输出**

```
YES
NO
YES
YES
```

**说明**

第一组把 `3` 乘以 `6` 得到 `18`，重排为 $2,6,18$，公比为 `3`。
第二组 $1,2,3$ 无论乘哪一个整数都无法重排成等比。
第三组本身已是等比，取 $m=1$ 即可。
第四组本身可重排为 $1,5,25$，同样取 $m=1$。

## 样例2

**输入**

```
3
-2 -6 -18
4 6 3
0 1 2
```

**输出**

```
YES
YES
YES
```

**说明**

第一组三个负数本身已成等比，公比为 `3`。
第二组把 `3` 乘以 `3` 得到 `9`，重排为 $4,6,9$，公比为 $\dfrac{3}{2}$。
第三组把 `2` 乘以 `0` 得到 `0`，重排为 $1,0,0$，公比为 `0`。

## 样例3

**输入**

```
2
0 0 0
7 7 7
```

**输出**

```
YES
YES
```

**说明**

三个 `0` 取 $m=1$ 即为等比。
三个相同正数同样已是公比为 `1` 的等比数列。

## 样例4

**输入**

```
1
1 0 0
```

**输出**

```
YES
```

**说明**

已经是 $1,0,0$，公比为 `0`。取 $m=1$ 即可，属于含零的边界情形。
