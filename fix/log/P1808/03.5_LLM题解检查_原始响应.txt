## 解题思路

1. **问题转化**  
   问题相当于：从第 $1$ 个平台出发，每次向前跳跃的距离必须是“光羽数列”（斐波那契数列）中的一项，最终恰好到达第 $N$ 个平台，求沿途收集的能量水晶之和的最大值。  
   定义 $dp[i]$ 表示到达第 $i$ 个平台时能获得的最大总能量。初始化 $dp[1] = s_1$，其余 $dp$ 值设为负无穷（因为能量值可能为负，且初始时不可达）。

2. **预处理光羽数列**  
   生成所有不超过 $N-1$ 的光羽数列的项（因为从第 $1$ 个平台跳到第 $N$ 个平台的最大跳跃距离为 $N-1$）。数列 $F$：$F_1 = 1,\ F_2 = 1,\ F_k = F_{k-1} + F_{k-2}$，生成时终止条件为 $F_k \le N-1$。

3. **动态规划转移**  
   对于每个平台 $i$（从 $2$ 到 $N$），枚举所有可能的光羽跳跃距离 $val$（即 $F$ 中的项），如果 $i - val \ge 1$ 且 $dp[i-val]$ 可达（即不为负无穷），则：  
   $$dp[i] = \max(dp[i],\ dp[i - val] + s_i)$$
   最终答案即为 $dp[N]$。

4. **边界处理**  
   由于能量值可能为负且数据范围较大，需要将 $dp$ 数组初始化为一个足够小的负数（如 $-10^{18}$），只有 $dp[1]$ 已知。同时，跳跃距离 $val$ 必须满足 $i - val \ge 1$，枚举时可提前跳出循环（因为 $F$ 递增，当 $val > i-1$ 时后续都会越界）。

## 复杂度分析

- **时间复杂度**：$O(N \times M)$，其中 $M$ 为不超过 $N$ 的斐波那契数的个数。$M$ 与 $\log_{\phi} N$ 同阶（$\phi$ 为黄金比例），因此实际复杂度为 $O(N \log N)$，在 $N \le 2 \times 10^5$ 时完全可行。
- **空间复杂度**：$O(N)$，主要用于存储 $dp$ 数组和斐波那契数列 $F$。

## 代码实现

### Python

```python
import sys

def main():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    s = [0] * (n + 1)
    for i in range(1, n + 1):
        s[i] = int(next(it))
    
    # 预处理光羽数列，所有不超过 n-1 的项
    fib = [1, 1]
    while fib[-1] <= n - 1:
        fib.append(fib[-1] + fib[-2])
    
    # dp[i] 表示到达第 i 个平台的最大总能量
    INF_NEG = -10**18
    dp = [INF_NEG] * (n + 1)
    dp[1] = s[1]
    
    for i in range(2, n + 1):
        for val in fib:
            if val > i - 1:       # 无法从更远的距离跳过来
                break
            if dp[i - val] != INF_NEG:
                dp[i] = max(dp[i], dp[i - val] + s[i])
    
    print(dp[n])

if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long[] s = new long[n + 1];
        for (int i = 1; i <= n; i++) {
            s[i] = sc.nextLong();
        }
        
        // 预处理光羽数列（不超过 n-1 的项）
        List<Integer> fib = new ArrayList<>();
        fib.add(1);
        fib.add(1);
        while (fib.get(fib.size() - 1) <= n - 1) {
            int size = fib.size();
            fib.add(fib.get(size - 1) + fib.get(size - 2));
        }
        
        long NEG_INF = (long) -1e18;
        long[] dp = new long[n + 1];
        Arrays.fill(dp, NEG_INF);
        dp[1] = s[1];
        
        for (int i = 2; i <= n; i++) {
            for (int val : fib) {
                if (val > i - 1) break;      // 跳跃距离过大
                if (dp[i - val] != NEG_INF) {
                    dp[i] = Math.max(dp[i], dp[i - val] + s[i]);
                }
            }
        }
        
        System.out.println(dp[n]);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n;
    cin >> n;
    vector<ll> s(n + 1);
    for (int i = 1; i <= n; ++i) {
        cin >> s[i];
    }
    
    // 预处理光羽数列，不超过 n-1
    vector<int> fib = {1, 1};
    while (fib.back() <= n - 1) {
        int sz = fib.size();
        fib.push_back(fib[sz - 1] + fib[sz - 2]);
    }
    
    const ll NEG_INF = -1e18;
    vector<ll> dp(n + 1, NEG_INF);
    dp[1] = s[1];
    
    for (int i = 2; i <= n; ++i) {
        for (int val : fib) {
            if (val > i - 1) break;
            if (dp[i - val] != NEG_INF) {
                dp[i] = max(dp[i], dp[i - val] + s[i]);
            }
        }
    }
    
    cout << dp[n] << "\n";
    return 0;
}
```
