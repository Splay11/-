# 题目内容
在神秘的幻境中，有一条由 $N$ 个平台组成的悬空栈道，平台从左到右依次编号为 $1$ 到 $N$。探险者从第 $1$ 个平台出发，每个平台上都放置着一定数量的能量水晶（数值可正可负）。探险者每次可以向前跳跃一段距离，这段距离必须是“光羽数列”中的某一项。光羽数列的定义如下：第一项和第二项均为 $1$，从第三项起，每一项等于前两项之和，即 $F_1=1$，$F_2=1$，$F_k = F_{k-1} + F_{k-2}$（$k \ge 3$）。探险者希望恰好落在第 $N$ 个平台上，沿途收集的水晶总能量最大。请你帮忙计算这个最大总能量。

平台数量 $N$ 不超过 $2 \times 10^5$，每个平台上的能量水晶数值的绝对值不超过 $10^9$。

# 输入描述
第一行包含一个整数 $N$ ($1 \le N \le 2 \times 10^5$)。
第二行包含 $N$ 个整数，第 $i$ 个整数表示第 $i$ 个平台上的能量值 $s_i$ ($|s_i| \le 10^9$)。

# 输出描述
输出一个整数，表示能够获得的最大总能量。

## 样例1

**输入**

```
4
1 -2 3 4
```

**输出**

```
8
```

**说明**

平台数量 $N=4$，能量水晶依次为 $1, -2, 3, 4$。光羽数列的前几项为 $1, 1, 2, 3$，探险者从第 `1` 个平台出发，可以跳跃的距离只能是这些斐波那契数。两种较优的路径：

- 路径 $1 \to 3 \to 4$：先跳跃 $2$ 步到第 `3` 个平台，收集 $3$；再跳跃 $1$ 步到第 `4` 个平台，收集 $4$。总能量为 $1 + 3 + 4 = 8$。
- 路径 $1 \to 4$：直接跳跃 $3$ 步到第 `4` 个平台，总能量为 $1 + 4 = 5$。

最大总能量为 `8`。

## 样例2

**输入**

```
1
5
```

**输出**

```
5
```

**说明**

边界情况：平台数量 $N=1$。探险者一开始就站在第 `1` 个平台上，无法进行任何跳跃，因此总能量就是该平台上的能量水晶值 $5$。最大总能量为 `5`。

## 样例3

**输入**

```
5
10 -5 -5 -5 20
```

**输出**

```
30
```

**说明**

平台数量 $N=5$，能量水晶为 $10, -5, -5, -5, 20$。光羽数列的第 $5$ 项为 $5$，因此可以从第 `1` 个平台直接跳跃 $5$ 步到达第 `5` 个平台。直接跳跃的路径为 $1 \to 5$，收集的能量为 $10 + 20 = 30$。其他路径（如经过中间平台）会收集到负数能量，总和均小于 $30$。因此最大总能量为 `30`。
