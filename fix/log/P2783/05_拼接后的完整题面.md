# 题目内容
给定 $q$ 个询问，每个询问包含两个正整数 $x$ 和 $y$。

对于一个正整数 $x$，若某个正整数 $d$ 满足 $x \bmod d = 0$，则称 $d$ 是 $x$ 的一个 **除数**。其余的正整数称为 $x$ 的 **非除数**。将 $x$ 的所有非除数按从小到大的顺序排列，你需要回答其中第 $y$ 个是多少。

数据范围：$q$ 不超过 $1000$，$x$ 和 $y$ 均不超过 $10^9$。

# 输入描述
第一行包含一个整数 $q$，表示询问的个数。
接下来 $q$ 行，每行包含两个整数 $x$ 和 $y$，用空格分隔。

# 输出描述
对于每个询问，输出一个整数，表示 $x$ 的第 $y$ 个非除数。

## 样例1

**输入**

```
1
4 3
```

**输出**

```
6
```

**说明**

对于 $x=4$，除数有 `1`,`2`,`4`。将所有正整数中不属于除数的非除数从小到大列出：`3`,`5`,`6`, $\dots$。其中第 `3` 个非除数是 `6`。

## 样例2

**输入**

```
2
5 1
5 5
```

**输出**

```
2
9
```

**说明**

对于 $x=5$，除数为 `1`,`5`。非除数序列为 `2`,`3`,`4`,`6`,`7`,`8`,`9`, $\dots$。第 `1` 个非除数是 `2`，第 `5` 个是 `9`。

## 样例3

**输入**

```
2
10 10
1 2
```

**输出**

```
14
3
```

**说明**

第一个询问 $x=10$，除数有 `1`,`2`,`5`,`10`。非除数序列为 `3`,`4`,`6`,`7`,`8`,`9`,`11`,`12`,`13`,`14`, $\dots$，第 `10` 个为 `14`。第二个询问 $x=1$，除数仅有 `1`。非除数从 `2` 开始，第 `2` 个为 `3`。
