## 解题思路

1. **问题转化**：需要找到第 $y$ 个正整数 $d$，使得 $x \bmod d \neq 0$（即 $d$ 不是 $x$ 的除数）。我们将所有正整数按照顺序检查，跳过 $x$ 的除数，找到第 $y$ 个非除数。
2. **收集除数**：首先求出 $x$ 的所有正除数。可以通过从 $1$ 到 $\sqrt{x}$ 的遍历，若 $x \bmod i = 0$，则 $i$ 和 $x/i$ 都是除数。注意去重（当 $i = x/i$ 时只加一个）。将所有除数存入列表并排序，得到递增的除数序列 $d_1, d_2, \dots, d_m$。
3. **利用除数间隔定位**：假设当前已经跳过了 $i$ 个除数，考虑在区间 $[1, d_i]$ 内，共有 $d_i$ 个正整数，其中 $i$ 个是除数，因此**非除数**的个数为 $d_i - i$。如果该值大于等于 $y$，则说明第 $y$ 个非除数一定落在 $[1, d_i]$ 内。由于前 $i$ 个除数占据了 $i$ 个位置，第 $y$ 个非除数恰好是跳过这些除数后的第 $y$ 个正整数，即 $i + y - 1$。如果遍历完所有除数仍没找到满足条件的 $d_i$，则答案为 $m + y$（因为所有 $\le x$ 的非除数都已经数完，从 $x+1$ 继续往后数第 $y$ 个非除数，而 $m$ 是除数总个数，已跳过 $m$ 个除数，所以下一个待选的数是 $m+y$）。
4. **算法步骤**：
   - 对每个询问 $(x, y)$：
     1. 生成并排序 $x$ 的所有除数（列表 `divisors`）。
     2. 初始化已遇到的除数计数器 $i = 0$。
     3. 遍历每个除数 $d$，令 $i \gets i+1$，若 $d - i \ge y$，输出 $i + y - 1$ 并结束该询问。
     4. 若遍历结束仍未输出，输出 $i + y$（即 $|divisors| + y$）。

## 复杂度分析

- **时间复杂度**：对每个询问，求除数需要 $O(\sqrt{x})$ 时间。除数个数最多约为 $1344$（当 $x \approx 10^9$ 时），排序成本 $O(m \log m)$ 可忽略。因此单次询问时间复杂度 $O(\sqrt{x})$。总时间复杂度 $O(q \sqrt{X_{\max}})$，其中 $q \le 1000$，$X_{\max} \le 10^9$，可以在时限内完成。
- **空间复杂度**：需要存储除数列表，空间为 $O(m)$，最坏 $O(\sqrt{x})$，即 $O(10^{4.5})$ 级别，足够小。

## 代码实现

### Python

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    q = int(data[0])
    idx = 1
    out_lines = []
    for _ in range(q):
        x = int(data[idx]); y = int(data[idx+1]); idx += 2
        # 求 x 的所有除数
        divisors = []
        i = 1
        while i * i <= x:
            if x % i == 0:
                divisors.append(i)
                if i != x // i:
                    divisors.append(x // i)
            i += 1
        divisors.sort()
        cnt = 0
        found = False
        for d in divisors:
            cnt += 1
            if d - cnt >= y:
                out_lines.append(str(cnt + y - 1))
                found = True
                break
        if not found:
            out_lines.append(str(cnt + y))
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int q = sc.nextInt();
        StringBuilder sb = new StringBuilder();
        while (q-- > 0) {
            int x = sc.nextInt();
            long y = sc.nextLong();
            
            // 求 x 的所有除数
            ArrayList<Integer> divisors = new ArrayList<>();
            for (int i = 1; i * i <= x; i++) {
                if (x % i == 0) {
                    divisors.add(i);
                    if (i != x / i) {
                        divisors.add(x / i);
                    }
                }
            }
            Collections.sort(divisors);
            
            int cnt = 0;
            boolean found = false;
            for (int d : divisors) {
                cnt++;
                if (d - cnt >= y) {
                    sb.append(cnt + y - 1).append("\n");
                    found = true;
                    break;
                }
            }
            if (!found) {
                sb.append(cnt + y).append("\n");
            }
        }
        System.out.print(sb);
        sc.close();
    }
}
```
