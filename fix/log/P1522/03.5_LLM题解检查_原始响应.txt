## 解题思路

本题要求统计所有“同源游走”的数量。游走本质上是从标牌序列中按原顺序选出的一个非空子序列，并且要求子序列的首尾房间标牌字母相同。

1. **分类统计**：  
   - 长度为 1 的游走：起点与终点是同一个房间，首尾字母天然相同，共有 $n$ 条（其中 $n$ 为字符串长度）。  
   - 长度大于等于 2 的游走：需要首尾字母相同，中间的房间可以任意选择参观或不参观。假设选择了位置 $i$ 和 $j$ 作为起止房间（$i<j$），且 $s[i]=s[j]$，则中间有 $j-i-1$ 个房间，每个房间可选或不选，方案数为 $2^{j-i-1}$。

2. **优化计算**：  
   直接枚举所有 $(i,j)$ 对会超时。可以按字母分类，对每个小写字母 $c$ 单独计算贡献。  
   从左到右扫描字符串，维护一个变量 $\textit{pre}$，表示以某个已经出现的 $c$ 位置作为起点，走到当前扫描位置之前一个位置为止，所有可能游走的方案数之和（包含起点，且中间房间已任意选择）。  
   - 每往后移动一个位置，中间可选的房间多了一个，之前的方案数翻倍：$\textit{pre} = \textit{pre} \times 2 \pmod{998244353}$。  
   - 若前一个房间 $(j-1)$ 的字母恰好是 $c$，则它可以作为一个新的起点（与之后的位置配对），它在中间无房间时方案数为 $1$，因此 $\textit{pre}$ 加 $1$。  
   - 若当前房间 $j$ 的字母是 $c$，则当前找到了一条终点，所有之前累积在 $\textit{pre}$ 中的方案都可以与当前房间组成合法的同源游走，将 $\textit{pre}$ 累加进答案。

3. **合并答案**：  
   对 26 个字母分别进行上述过程，累加得到长度 $\ge 2$ 的游走总数，再加上长度为 $1$ 的游走数 $n$（即每个房间单独成游）。答案对 $998244353$ 取模后输出。

## 复杂度分析

- 时间复杂度：$O(26 \cdot n)$，其中 $n$ 是字符串长度，需要遍历 26 个字母，每次扫描整个字符串。由于 $n \le 10^5$，$26 \times 10^5$ 的运算量完全可以接受。  
- 空间复杂度：$O(1)$，仅使用了常数个额外变量。

## 代码实现

### Python

```python
def solve():
    s = input().strip()
    MOD = 998244353
    ans = 0

    # 按字母分 26 类统计
    for ch in range(26):
        pre = 0
        for j in range(1, len(s)):
            # 中间房间增多一个，方案数翻倍
            pre = (pre * 2) % MOD
            if ord(s[j - 1]) - ord('a') == ch:
                # 前一个房间可以作为新的起点
                pre = (pre + 1) % MOD
            if ord(s[j]) - ord('a') == ch:
                # 当前房间为终点，累加贡献
                ans = (ans + pre) % MOD

    # 加上长度为 1 的游走（每个房间独自成游）
    ans = (ans + len(s)) % MOD
    print(ans)


if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void solve() {
        Scanner scanner = new Scanner(System.in);
        String s = scanner.next();
        final int MOD = 998244353;
        long ans = 0;

        // 按字母分 26 类统计
        for (int ch = 0; ch < 26; ch++) {
            long pre = 0;
            for (int j = 1; j < s.length(); j++) {
                // 中间房间增多一个，方案数翻倍
                pre = (pre * 2) % MOD;
                if (s.charAt(j - 1) - 'a' == ch) {
                    // 前一个房间可以作为新的起点
                    pre = (pre + 1) % MOD;
                }
                if (s.charAt(j) - 'a' == ch) {
                    // 当前房间为终点，累加贡献
                    ans = (ans + pre) % MOD;
                }
            }
        }

        // 加上长度为 1 的游走（每个房间独自成游）
        ans = (ans + s.length()) % MOD;
        System.out.println(ans);
    }

    public static void main(String[] args) {
        solve();
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
using namespace std;

void solve() {
    string s;
    cin >> s;
    const int MOD = 998244353;
    long long ans = 0;

    // 按字母分 26 类统计
    for (int ch = 0; ch < 26; ch++) {
        long long pre = 0;
        for (int j = 1; j < (int)s.size(); j++) {
            // 中间房间增多一个，方案数翻倍
            pre = (pre * 2) % MOD;
            if (s[j - 1] - 'a' == ch) {
                // 前一个房间可以作为新的起点
                pre = (pre + 1) % MOD;
            }
            if (s[j] - 'a' == ch) {
                // 当前房间为终点，累加贡献
                ans = (ans + pre) % MOD;
            }
        }
    }

    // 加上长度为 1 的游走（每个房间独自成游）
    ans = (ans + s.size()) % MOD;
    cout << ans << endl;
}

int main() {
    solve();
    return 0;
}
```
