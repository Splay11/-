# 题目内容
一位炼金术师正在调试一座由 $n$ 行 $m$ 列格子构成的炼金阵，第 $i$ 行第 $j$ 列的格子内初始存放着 $a_{i,j}$ 枚炼金水晶。

他可以任意重新分配水晶：可以把任意一个格子中的若干水晶移动到另一个格子中，但移动后每个格子内的水晶数必须始终为非负整数，且所有格子的水晶总数不能改变。

术师希望最终炼金阵同时满足以下两个镜像条件：
- 对于所有的 $1 \le i \le n$、$1 \le j \le m$，均有 $X_{i,j} = X_{n+1-i,j}$（上下镜像）；
- 对于所有的 $1 \le i \le n$、$1 \le j \le m$，均有 $X_{i,j} = X_{i,m+1-j}$（左右镜像），
其中 $X_{i,j}$ 表示最终第 $i$ 行第 $j$ 列的水晶数量。

请你判断是否存在一种合法的分配方式，若存在则输出任意一种最终布置，否则输出 $-1$。

**数据范围与约束**
- 测试数据组数 $T$ 满足 $1 \le T \le 10^5$。
- 每组数据中，$n$ 和 $m$ 满足 $1 \le n,m \le 2 	imes 10^5$，所有格子的初始水晶数 $0 \le a_{i,j} \le 10^9$。
- 保证单个测试点内所有数据的 $n 	imes m$ 之和不超过 $5 	imes 10^5$。

# 输入描述
第一行包含一个整数 $T$，表示测试数据组数。
接下来每组数据按以下格式给出：
第一行包含两个整数 $n$ 和 $m$，分别表示炼金阵的行数和列数。
接下来 $n$ 行，每行包含 $m$ 个整数，第 $i$ 行第 $j$ 个整数表示初始水晶数量 $a_{i,j}$。

# 输出描述
对于每组测试数据，若不存在满足镜像条件的最终布置，则输出一行 $-1$。
否则输出 $n$ 行，每行包含 $m$ 个非负整数，表示一个合法的最终水晶分布 $X$。

## 样例1

**输入**

```
1
2 2
1 2
3 4
```

**输出**

```
-1
```

**说明**

炼金阵有 `2` 行 `2` 列，$n$ 和 $m$ 均为偶数，每一个对称轨道包含 `4` 个格子。
水晶总数 $1 + 2 + 3 + 4 = 10$，而 `10` 不能被 `4` 整除，无法将水晶均分到大小为 `4` 的轨道上，因此不存在合法的分配方式，输出 $-1$。

## 样例2

**输入**

```
2
2 3
1 0 2
3 1 0
1 1
7
```

**输出**

```
-1
7
```

**说明**

第一组数据 $n=2,m=3$，$n$ 为偶数、$m$ 为奇数，上下镜像轨道大小为 `2`。
水晶总数 $1+0+2+3+1+0=7$，`7` 不能被 `2` 整除，无法构造，输出 $-1$。

第二组数据 $n=1,m=1$，$n$ 和 $m$ 均为奇数，中心格子自身即为一个对称轨道，大小 `1`。
总数 `7` 可以全部放入该格，直接输出 `7`。

## 样例3

**输入**

```
1
1 2
3 3
```

**输出**

```
3 3
```

**说明**

$n=1$ 为奇数，$m=2$ 为偶数，左右镜像轨道大小为 `2`。
两个格子的水晶总数 $3+3=6$，`6` 能被 `2` 整除，可将 `3` 枚水晶分别放在第 $1$ 列和第 $2$ 列，得到 $X_{1,1}=X_{1,2}=3$，满足左右镜像条件。

## 样例4

**输入**

```
1
3 2
1 2
3 0
2 0
```

**输出**

```
0 0
4 4
0 0
```

**说明**

$n=3$ 为奇数，$m=2$ 为偶数，所有格子的对称轨道大小为 `2`，且位于中间行的两个格子上下镜像后重合。
水晶总数 $1+2+3+0+2+0=8$，`8` 能被 `2` 整除，因此可将 `4` 枚水晶放在第 $2$ 行第 $1$ 列，`4` 枚放在第 $2$ 行第 $2$ 列；第 $1$ 行和第 $3$ 行全部置 $0$。此时 $X_{1,j}=X_{3,j}$ 且 $X_{i,1}=X_{i,2}$，满足上下镜像与左右镜像。
