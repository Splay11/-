# 题目内容

塔子哥是一家公司的老板，该公司共有*n*个部门。每个部门的平均考核成绩（取整后）分别记为$s_1$,$s_2$,...,$s_n$，部门编号依次为1,2,...,*n*。

公司被称为优秀公司的条件是满足以下三个条件之一：

1. 这*n*个部门的平均考核成绩的中位数不低于*a*。中位数是将考核成绩排序后处于最中间的数，当n为偶数时，规定中位数为两个中间数的平均值（向下取整）。
2. 平均考核成绩的整数部分不低于*b*，即$\cfrac{\sum_{i=1}^{n}s_i }{n} \geq b$。
3. 把最高分和最低分从总成绩中去除后（减去*x*和*y*），剩余成绩的平均数（取整后）不低于*c*，即$\cfrac{(\sum_{i=1}^{n}s_i)-x-y }{n-2} \geq c$。

只要满足以上三个条件中的任意一个，塔子哥的公司就可被评为优秀公司。

# 输入描述

本题为多组测试数据，第一行输入一个正整数 $T(1 \leq T \leq 1000)$，代表测试数据的组数.

对于每组测试数据，第一行输入一个正数 $n(3 \leq n \leq 100)$代表公司部门数量

第二行依次输入$n$个整数$s_1,s_2,...s_n$($0 \leq s_i \leq 100$)，代表部门考核分数。

第三行依次输入三个整数$a,b,c(0 \leq a,b,c \leq 100)$依次代表优秀公司需要满足的分数要求的判断值。

# 输出描述

对于每组测试数据，如果可以评为优秀公司，则一行输出一个字符串 “$Yes$”，否则输出“$No$”。(输出均不包含两边的双引号)

# 样例

**输入**

```
3
3
66 66 66
99 70 60
4
99 10 60 25
43 49 43
6
46 64 0 100 60 88
62 88 77
```

**输出**

```
Yes
No
Yes
```
