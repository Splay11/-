## 解题思路

对每组数据分别检查三项条件，满足任意一项即输出 `Yes`，否则输出 `No`。

先将读数排序。

1. 中位数：若 $n$ 为奇数，取 $s_{n/2}$（下标从 `0` 开始）；若 $n$ 为偶数，取中间两个数的平均值并向下取整。判断是否不低于 $a$。等价地，偶数时可用 $s_{n/2-1}+s_{n/2}\ge 2a$。
2. 全体平均数：判断 $\sum s_i \ge b\cdot n$。
3. 去掉一个最高和一个最低后：判断 $\sum s_i - \max - \min \ge c\cdot(n-2)$。排序后最高、最低即两端元素。

读数均为非负整数，用乘法比较可避免浮点误差，也与向下取整后的比较等价。

## 复杂度分析

每组数据主要花费在排序上。

- 时间复杂度：$O(n\log n)$。
- 空间复杂度：$O(n)$。

在 $T\le 1000$、$n\le 100$ 时可以通过。

## 代码实现

### Python

```python
T = int(input())

for _ in range(T):
    n = int(input())
    scores = list(map(int, input().split()))
    a, b, c = map(int, input().split())

    s = sorted(scores)
    if n % 2 == 0:
        median = (s[n // 2] + s[n // 2 - 1]) // 2
    else:
        median = s[n // 2]
    condition1 = median >= a

    average_score = sum(scores) // n
    condition2 = average_score >= b

    remaining_scores = sum(scores) - max(scores) - min(scores)
    condition3 = remaining_scores // (n - 2) >= c

    if condition1 or condition2 or condition3:
        print("Yes")
    else:
        print("No")
```

### Java

```java
import java.util.*;

class Main {
    static Scanner sc = new Scanner(System.in);

    public static void solve() {
        int n = sc.nextInt();
        int[] s = new int[n];
        for (int i = 0; i < n; ++i) {
            s[i] = sc.nextInt();
        }
        int a = sc.nextInt();
        int b = sc.nextInt();
        int c = sc.nextInt();

        Arrays.sort(s);

        boolean ok = false;
        if (n % 2 == 1) {
            if (s[n / 2] >= a) ok = true;
        } else {
            if (s[n / 2 - 1] + s[n / 2] >= 2 * a) ok = true;
        }
        if (Arrays.stream(s).sum() >= b * n) ok = true;
        if (Arrays.stream(s).sum() - s[0] - s[n - 1] >= c * (n - 2)) ok = true;

        System.out.println(ok ? "Yes" : "No");
    }

    public static void main(String[] args) {
        int T = sc.nextInt();
        for (int i = 1; i <= T; ++i) {
            solve();
        }
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int n;
    cin >> n;
    vector<int> s(n);
    for (int i = 0; i < n; ++i) cin >> s[i];
    int a, b, c;
    cin >> a >> b >> c;

    sort(s.begin(), s.end());

    bool ok = false;
    if (n % 2 == 1) {
        if (s[n / 2] >= a) ok = true;
    } else {
        if (s[n / 2 - 1] + s[n / 2] >= 2 * a) ok = true;
    }
    if (accumulate(s.begin(), s.end(), 0) >= b * n) ok = true;
    if (accumulate(s.begin(), s.end(), 0) - s[0] - s[n - 1] >= c * (n - 2)) ok = true;

    puts(ok ? "Yes" : "No");
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    for (int i = 1; i <= T; ++i) solve();
    return 0;
}
```
