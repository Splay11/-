## 解题思路

需要枚举所有在序列中出现过的模具型号，将它们分别作为目标型号 $x$，计算该选择下的拆除次数，再取最小值。

选定 $x$ 后，所有不等于 $x$ 的工位都必须被拆除。这些工位被原有的 $x$ 分隔成若干连续段，每一段都可以用一次操作拆除，因此操作次数等于非 $x$ 连续段的个数。

设 $x$ 出现的下标（从 `0` 开始）为 $p_1, p_2, \ldots, p_k$，则：

1. 若 $p_1 > 0$，则开头存在一段非 $x$，计一次操作。
2. 若相邻两次出现满足 $p_{i+1} > p_i + 1$，则中间隔着一段非 $x$，计一次操作。
3. 若 $p_k < n - 1$，则末尾存在一段非 $x$，计一次操作。

实现时先遍历序列，用哈希表记录每个型号出现的全部下标；再对每个型号按上述规则统计，取全局最小。所有下标列表长度之和为 $n$，因此整体线性。

## 复杂度分析

预处理与按型号扫描的总工作量均与序列长度成正比。

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(n)$。

## 代码实现

### Python

```python
import sys
from collections import defaultdict


def solve():
    n = int(sys.stdin.readline())
    a = list(map(int, sys.stdin.readline().split()))

    positions = defaultdict(list)
    for i, num in enumerate(a):
        positions[num].append(i)

    min_ops = n
    for val in positions:
        pos_vec = positions[val]
        current_ops = 0
        if pos_vec[0] > 0:
            current_ops += 1
        for i in range(len(pos_vec) - 1):
            if pos_vec[i + 1] > pos_vec[i] + 1:
                current_ops += 1
        if pos_vec[-1] < n - 1:
            current_ops += 1
        min_ops = min(min_ops, current_ops)

    print(min_ops)


if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.Scanner;
import java.util.Map;
import java.util.HashMap;
import java.util.List;
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();

        Map<Integer, List<Integer>> positions = new HashMap<>();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = scanner.nextInt();
            positions.putIfAbsent(a[i], new ArrayList<>());
            positions.get(a[i]).add(i);
        }

        int minOps = n;
        for (int val : positions.keySet()) {
            List<Integer> posVec = positions.get(val);
            int currentOps = 0;
            if (posVec.get(0) > 0) {
                currentOps++;
            }
            for (int i = 0; i < posVec.size() - 1; i++) {
                if (posVec.get(i + 1) > posVec.get(i) + 1) {
                    currentOps++;
                }
            }
            if (posVec.get(posVec.size() - 1) < n - 1) {
                currentOps++;
            }
            minOps = Math.min(minOps, currentOps);
        }

        System.out.println(minOps);
        scanner.close();
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <map>
#include <algorithm>

int main() {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(NULL);

    int n;
    std::cin >> n;

    std::vector<int> a(n);
    std::map<int, std::vector<int>> positions;
    for (int i = 0; i < n; ++i) {
        std::cin >> a[i];
        positions[a[i]].push_back(i);
    }

    int min_ops = n;
    for (auto const& [val, pos_vec] : positions) {
        int current_ops = 0;
        if (pos_vec[0] > 0) {
            current_ops++;
        }
        for (size_t i = 0; i < pos_vec.size() - 1; ++i) {
            if (pos_vec[i + 1] > pos_vec[i] + 1) {
                current_ops++;
            }
        }
        if (pos_vec.back() < n - 1) {
            current_ops++;
        }
        min_ops = std::min(min_ops, current_ops);
    }

    std::cout << min_ops << std::endl;
    return 0;
}
```
