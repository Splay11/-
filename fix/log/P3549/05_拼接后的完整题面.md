# 题目内容
一条生产线上依次排列着 $n$ 个工位，第 $i$ 个工位当前安装的模具型号为 $a_i$。需要选定一个目标型号 $x$，使得最终所有仍保留模具的工位都安装型号 $x$。

一次拆除操作可以拆除一段连续工位上的模具，但这段连续区间内不能出现任何型号为 $x$ 的模具。被拆除的工位不再保留模具，也不再参与后续操作。

请选择合适的目标型号 $x$，使得完成目标所需的拆除操作次数尽可能少，并输出这个最少次数。

约束：工位数量 $n$ 满足 $3 \le n \le 10^5$，每个模具型号为正整数且不超过 $10^5$。

# 输入描述
第一行包含一个整数 $n$，表示工位数量。
第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$，表示各工位当前的模具型号。
保证 $3 \le n \le 10^5$，$1 \le a_i \le 10^5$。

# 输出描述
输出一个整数，表示最少需要的拆除操作次数。

## 样例1

**输入**

```
7
1 2 3 1 4 5 1
```

**输出**

```
2
```

**说明**

选定目标型号 $x=1$。序列可看成 $1,(2,3),1,(4,5),1$，非 `1` 的连续段有两段，各拆除一次即可，共 `2` 次。
可以验证选其他型号不会更优，因此最少操作次数为 `2`。

## 样例2

**输入**

```
3
1 2 3
```

**输出**

```
1
```

**说明**

三个工位型号互不相同。若选 $x=1$，只需拆除后缀 $2,3$ 这一段；若选 $x=3$，只需拆除前缀 $1,2$。
最少操作次数为 `1`。

## 样例3

**输入**

```
5
2 2 2 2 2
```

**输出**

```
0
```

**说明**

所有工位已经是同一型号 `2`，选定 $x=2$ 后不存在需要拆除的连续段，操作次数为 `0`。

## 样例4

**输入**

```
4
5 5 7 5
```

**输出**

```
1
```

**说明**

选定目标型号 $x=5$，下标为 $0,1,3$。仅在位置 `2` 处隔着一段非 `5` 的模具 $7$，拆除这一段即可，操作次数为 `1`。
若选 $x=7$，开头与末尾各有一段非 `7`，需要 `2` 次，更差。
