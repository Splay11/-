# 题目内容
有 `n` 台开采机和 `m` 口垂直能源井，开采机按照编号顺序依次作业。第 `j` 口井的深度为 $b_j$，每单位深度含有一单位能量晶体。第 `i` 台开采机的作业深度为 $a_i$，即它可以从地表向下覆盖深度范围 $[1, a_i]$，将该范围内的所有晶体（如果尚未被采集）全部取走。井壁设有稳固定位场，即使下部晶体被取走，上方的晶体也不会坠落。每口井的晶体被采集后便消失，后续的开采机只能采集剩余晶体。请计算每台开采机采集到的晶体总量。

开采机的数量 $n$ 和井的数量 $m$ 均不超过 `10^3`，作业深度 $a_i$ 和井深 $b_j$ 均不超过 $10^9$。

# 输入描述
第一行包含两个整数 `n` 和 `m`，表示开采机数量和井的数量。
第二行包含 `n` 个整数 $a_1, a_2, \dots, a_n$，表示每台开采机的作业深度。
第三行包含 `m` 个整数 $b_1, b_2, \dots, b_m$，表示每口井的深度。

# 输出描述
在一行内输出 `n` 个整数，依次表示第 `1` 到第 `n` 台开采机采集到的晶体总量，整数之间用单个空格分隔，并在输出最后一个整数后换行。

## 样例1

**输入**

```
2 2
3 5
2 4
```

**输出**

```
5 1
```

**说明**

共有 `2` 台开采机和 `2` 口井。第一台开采机的作业深度为 $3$，第二台为 $5$；两口井的深度分别为 $2$ 和 $4$。

第一台开采机（深度 $3$）到达时，两口井均未采集：
- 井 `1` 深度 $2$，可采集 $\min(3,2)-0=2$，采集后该井剩余量为 $0$；
- 井 `2` 深度 $4$，可采集 $\min(3,4)-0=3$，采集后该井剩余量为 $1$（高度区间 $(3,4]$）。
合计采集 $2+3=5$。

第二台开采机（深度 $5$）到达时：
- 井 `1` 已无剩余，采集 $0$；
- 井 `2` 剩余高度区间为 $(3,4]$，可采集 $\min(5,4)-3=1$，采集后该井全部采完。
合计采集 $1$。

最终输出 `5 1`。

## 样例2

**输入**

```
1 1
10
10
```

**输出**

```

```

**说明**

只有 `1` 台开采机和 `1` 口井，深度均为 $10$。开采机作业时，该井尚未采集，可采集量 $\min(10,10)-0=10$。因此开采机采集到 `10` 单位晶体。

**输入**

```
3 2
2 5 9
4 6
```

**输出**

```
4 5 1
```

**说明**

`3` 台开采机，作业深度依次为 $2$、$5$、$9$；`2` 口井，深度分别为 $4$ 和 $6$。

第一台开采机（深度 $2$）：
- 井 `1` 深度 $4$，采集 $\min(2,4)-0=2$，剩余区间 $(2,4]$；
- 井 `2` 深度 $6$，采集 $\min(2,6)-0=2$，剩余区间 $(2,6]$。
合计采集 `4`。

第二台开采机（深度 $5$）：
- 井 `1` 当前剩余高度 $4$，已采集 $2$，可采集 $\min(5,4)-2=2$，该井采完；
- 井 `2` 当前剩余高度 $6$，已采集 $2$，可采集 $\min(5,6)-2=3$，剩余区间 $(5,6]$。
合计采集 `5`。

第三台开采机（深度 $9$）：
- 井 `1` 已空；
- 井 `2` 当前剩余高度 $6$，已采集 $5$，可采集 $\min(9,6)-5=1$，该井采完。
合计采集 `1`。

最终输出 `4 5 1`。
