# 题目内容
地质队沿钻孔依次取得 $n$ 段岩芯，第 $i$ 段的矿物指数为 $a_i$。实验室要把整列岩芯送去分组化验，但必须保持取样先后顺序，不能打乱、不能漏段。化验规程要求恰好划成 $m$ 个非空连续段，并以各段内部指数的最大公因数之和作为这套划分的得分，实验室希望得分尽可能大。划分必须连续、非空、互不相交，并集恰好覆盖整列。最大公因数 $\mathrm{gcd}$ 指能够整除若干正整数的最大正整数。

约束：$1 \le m \le n \le 4 \times 10^2$，$1 \le a_i \le 10^5$。

# 输入描述
第一行两个整数 $n$ 和 $m$，分别表示岩芯段数与要分成的组数。
第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$。
保证 $1 \le m \le n \le 4 \times 10^2$，$1 \le a_i \le 10^5$。

# 输出描述
输出一个整数，表示 $m$ 段 $\mathrm{gcd}$ 之和的最大值。

## 样例1

**输入**

```
5 3
8 12 6 9 3
```

**输出**

```
23
```

**说明**

划分成 $[8]\mid[12]\mid[6,9,3]$ 时，三段 $\mathrm{gcd}$ 分别为 `8`、`12`、`3`，之和为 `23`，这是最大值。

## 样例2

**输入**

```
3 1
7 14 21
```

**输出**

```
7
```

**说明**

只能分成 `1` 段，答案就是整个数组的 $\mathrm{gcd}(7,14,21)=7$。

## 样例3

**输入**

```
4 4
10 15 25 35
```

**输出**

```
85
```

**说明**

分成 `4` 段时每段只有一个数，答案为 $10+15+25+35=85$。
