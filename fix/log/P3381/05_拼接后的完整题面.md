# 题目内容
一块广告灯牌由 $n$ 行 $m$ 列灯珠组成，第 $i$ 行第 $j$ 列记为 $a_{i,j}$。初始时所有灯珠均为熄灭状态 `0`。

你将执行 $k$ 次操作，每次给出两个整数 $x$ 与 $y$：

- 当 $x$ 为 `1` 时，将第 $y$ 列的全部灯珠取反；
- 当 $x$ 为 `2` 时，将第 $y$ 行的全部灯珠取反。

取反是指：当前为 `0` 则变为 `1`，当前为 `1` 则变为 `0`。

全部操作结束后，按行优先、从左到右把灯牌上的 `0`/`1` 拼成一个二进制数（最高位为 $a_{1,1}$，最低位为 $a_{n,m}$）。求该二进制数对应的十进制值对 $10^9+7$ 取模的结果。

约束：行数与列数均不超过 `10^9`，操作次数不超过 `2×10^5`。

# 输入描述
第一行包含三个整数 $n$、$m$ 和 $k$，分别表示灯牌的行数、列数与操作次数。
接下来 $k$ 行，每行两个整数 $x$ 和 $y$。当 $x$ 为 `1` 时保证 $1 \le y \le m$，表示对第 $y$ 列取反；当 $x$ 为 `2` 时保证 $1 \le y \le n$，表示对第 $y$ 行取反。
保证 $1 \le n, m \le 10^9$，$1 \le k \le 2 \times 10^5$，$x \in \{1, 2\}$。

# 输出描述
输出一个整数，表示拼成的二进制数对应的十进制值对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
1 1 0
```

**输出**

```
0
```

**说明**

$n=m=`1`$ 且没有操作，灯牌上只有一个 `0`，对应十进制 `0`。这是最小规模边界。

## 样例2

**输入**

```
1 2 1
1 1
```

**输出**

```
2
```

**说明**

一行两列，只对第 `1` 列取反，灯牌变为 `1` `0`。二进制为 $10_2$，十进制为 `2`。

## 样例3

**输入**

```
0 0 -1
```

**输出**

```
0
```

**说明**

按题意模拟计算得到。
