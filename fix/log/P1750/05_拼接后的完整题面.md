# 题目内容
小蓝得到了一个长度为 `n` 的正整数序列，他希望序列是非递减的。一种操作是：选择下标 `l` 和 `r` ($1 \le l \le r \le n$)，删除从第 `l` 个到第 `r` 个元素（含两端），剩余元素按原顺序拼接。如果拼接后的序列满足非递减（即对于所有相邻元素 $x, y$ 有 $x \le y$），则本次操作合法。特别地，若删除后没有剩余元素，也视为合法。

请你帮小蓝计算有多少种合法的下标对 $(l, r)$。

约束：序列长度 `n` 不超过 `2×10^5`，序列中的每个数都是正整数，且不超过 `10^9`。

# 输入描述
第一行包含一个整数 `n` ($1 \le n \le 2\times 10^5$)，代表序列长度。
第二行包含 `n` 个整数 $a_1, a_2, \dots, a_n$ ($1 \le a_i \le 10^9$)，依次表示序列元素。

# 输出描述
输出一个整数，代表合法的方案总数。

## 样例1

**输入**

```
4
2 1 3 4
```

**输出**

```
7
```

**说明**

序列为 `2 1 3 4`。

我们需要统计所有下标对 $(l, r)$，使得删除子数组 $[a_l, a_{l+1}, \dots, a_r]$ 后剩余序列非递减（空序列也合法）。

剩余序列由前缀 $a_1 \dots a_{l-1}$ 和后缀 $a_{r+1} \dots a_n$ 拼接而成，要求前缀自身非递减、后缀自身非递减且前缀末元素 $\le$ 后缀首元素（若两端均存在）。

观察原序列，前缀 $[2]$ 是非递减的，但前缀 $[2, 1]$ 不是。因此 $l$ 只能为 `1` 或 `2`。

- 当 $l = 1$ 时（无前缀）：只需后缀非递减。原序列的非递减后缀可以从下标 `2` 开始（$[1, 3, 4]$），下标 `3` 开始（$[3, 4]$），下标 `4` 开始（$[4]$），或空后缀。对应 $r = 1, 2, 3, 4$，共 `4` 种。
- 当 $l = 2$ 时（前缀 $[2]$ 非递减，$a_{l-1} = 2$）：后缀需从非递减后缀起始，且 $2 \le a_{r+1}$。非递减后缀起始可选下标 `3`（$a_3 = 3$，满足 $2 \le 3$）、下标 `4`（$a_4 = 4$，满足）或空后缀。对应 $r = 2, 3, 4$，共 `3` 种。

总计 $4 + 3 = 7$ 种。

## 样例2

**输入**

```
1
5
```

**输出**

```
1
```

**说明**

序列长度为 `1`，只有元素 `5`。唯一的操作为选择 $l = 1, r = 1$，删除后剩余序列为空，题目规定空序列合法。因此方案数为 `1`。

## 样例3

**输入**

```
5
1 2 2 3 5
```

**输出**

```
15
```

**说明**

序列为 `1 2 2 3 5`，本身已经非递减。

对于任意 $l, r$，删除 $[l, r]$ 后，前缀 $a_1 \dots a_{l-1}$ 与后缀 $a_{r+1} \dots a_n$ 均来自原序列，拼接后仍然保持非递减（因为 $a_{l-1} \le a_{r+1}$ 在原序列中自动成立，且前后缀各自非递减）。因此任意 $(l, r)$ 均合法。

总方案数即所有下标对的个数：$\frac{n(n+1)}{2} = \frac{5 \times 6}{2} = 15$。

## 样例4

**输入**

```
5
3 2 1 4 5
```

**输出**

```
7
```

**说明**

序列为 `3 2 1 4 5`。

首先找出原序列的非递减后缀：从右往左扫描，`5` 非递减，`4 5` 非递减，`1 4 5` 非递减，但 `2 1` 破坏非递减，因此非递减后缀只能从下标 `3`（元素 `1`）或更靠右的位置开始。前缀方面，$[3]$ 非递减，而 $[3, 2]$ 不非递减，故 $l$ 只能为 `1` 或 `2`。

- $l = 1$（无前缀）：后缀只需自身非递减。非递减后缀起始可选下标 `3`、`4`、`5` 或空后缀，对应 $r = 2, 3, 4, 5$，共 `4` 种。
- $l = 2$（前缀 $[3]$，$a_{l-1} = 3$）：后缀需非递减且 $3 \le a_{r+1}$。非递减后缀若从下标 `3` 开始，$a_3 = 1$，不满足 $3 \le 1$；从下标 `4` 开始 $a_4 = 4$ 满足；从下标 `5` 开始 $a_5 = 5$ 满足；空后缀亦满足。对应 $r = 3, 4, 5$，共 `3` 种。

总计 $4 + 3 = 7$ 种。
