# 题目内容
一棵古老的银杏树有 $n$ 个分叉点，编号 $1$ 到 $n$，并由 $n-1$ 条枝条连接成一棵树。第 $i$ 条枝条连接分叉点 $u_i$ 与 $v_i$，长度为 $w_i$。园艺师可以锯掉至多 $k$ 条枝条，将树分割成若干个独立的连通部分。对任意一个部分，定义其 **冠幅** 为部分内任意两个分叉点之间沿枝条的最长距离（即最短路径长度的最大值）。园艺师希望在最多锯掉 $k$ 条枝条的条件下，使得所有部分的冠幅的最大值尽可能小。请计算这个最小的最大值。

约束：分叉点数量 $n$ 满足 $2 \le n \le 2 \times 10^5$，可锯枝条上限 $k$ 满足 $0 \le k \le n-1$，枝条长度 $w_i$ 为不超过 $10^9$ 的正整数。输入保证所有枝条构成一棵连通无环的树。

# 输入描述
第一行包含两个整数 $n$ 和 $k$，分别表示分叉点数量与最多可锯掉的枝条数。
接下来 $n-1$ 行，每行包含三个整数 $u_i, v_i, w_i$，表示一条连接分叉点 $u_i$ 与 $v_i$ 且长度为 $w_i$ 的枝条。

# 输出描述
输出一个整数，表示在最多锯掉 $k$ 条枝条后，所有部分冠幅的最大值可以达到的最小值。

## 样例1

**输入**

```
2 1
1 2 5
```

**输出**

```
0
```

**说明**

树有 $2$ 个分叉点，`1` 条枝条，长度为 `5`。允许锯掉至多 $k=1$ 条枝条。若锯掉唯一的枝条 $(1,2)$，则得到两个部分，每个部分仅包含一个分叉点，冠幅均为 $0$；此时最大冠幅为 $0$。因此最小可能的最大值为 $0$。

## 样例2

**输入**

```
4 1
1 2 1
2 3 1
3 4 1
```

**输出**

```
1
```

**说明**

树为一条链，所有边权均为 `1`，整棵树的冠幅为 $3$。由于 $k=1$，只能锯掉一条枝条。若锯掉中间的枝条 $(2,3)$，得到两个部分 $\{1,2\}$ 与 $\{3,4\}$，每部分的冠幅均为 $1$；若锯掉端点枝条，则一部分为孤点（冠幅 $0$），另一部分的冠幅为 $2$。最优策略是锯掉中间枝条，使最大冠幅最小化到 $1$。

## 样例3

**输入**

```
5 1
1 2 2
2 3 3
3 4 2
4 5 2
```

**输出**

```
5
```

**说明**

树为一条链，边权依次为 `2, 3, 2, 2`，总冠幅为 $7$。$k=1$ 时有四种锯法：锯 $(1,2)$ 得到部分冠幅 $0$ 与 $7$；锯 $(2,3)$ 得到 $2$ 与 $5$；锯 $(3,4)$ 得到 $5$ 与 $2$；锯 $(4,5)$ 得到 $7$ 与 $0$。无论哪种锯法，最大冠幅至少为 $5$。选择锯 $(2,3)$ 或 $(3,4)$ 可将最大冠幅降至 $5$，这也是能达到的最小最大值。

## 样例4

**输入**

```
7 2
1 2 1
1 3 1
2 4 1
2 5 1
3 6 1
3 7 1
```

**输出**

```
2
```

**说明**

树是一棵高度为 $2$ 的完全二叉树，所有边权均为 `1`。整棵树的冠幅为 $4$（例如叶子 $4$ 到叶子 $6$ 的最短路径长度为 $4$）。当 $k=2$ 时，可以锯掉 $(1,2)$ 与 $(1,3)$ 这两条边，树被分成三部分：$\{2,4,5\}$（冠幅 $2$）、$\{3,6,7\}$（冠幅 $2$）以及 $\{1\}$（冠幅 $0$），此时最大冠幅为 $2$。事实上，当 $k=1$ 时最大冠幅已可降至 $2$，因此 $k=2$ 的最小最大冠幅仍为 $2$。
