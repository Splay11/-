# 题目内容
给定一个包含 $n$ 个整数的圆环，你需要选择一个位置将其切断，形成一个线性序列 $x_1, x_2, \ldots, x_n$。
定义该序列的交替加权得分 $S$ 为：
$S = 1 \cdot x_1 - 2 \cdot x_2 + 3 \cdot x_3 - 4 \cdot x_4 + \cdots + (-1)^{n-1} \cdot n \cdot x_n$
请你计算在所有可能的切断位置中，得分 $S$ 能达到的最大值。

数据范围：圆环上的数字个数 $n$ 满足 $1 \le n \le 2000$，每个整数的取值均在 $0$ 到 $n$ 之间。

# 输入描述
第一行包含一个整数 $n$（$1 \le n \le 2000$），表示圆环上的数字个数。
第二行包含 $n$ 个整数，依次表示圆环上各位置的数字，每个整数均在 $0$ 到 $n$ 之间。

# 输出描述
输出一个整数，表示所有切断位置对应的交替加权得分的最大值。

## 样例1

**输入**

```
3
1 2 3
```

**输出**

```
7
```

**说明**

圆环上的数字为 `1`、`2`、`3`，共有 $n=3$ 个位置可以切断。

- 切断在 `1` 之前，线性序列为 $[1,2,3]$，得分 $S = 1 \cdot 1 - 2 \cdot 2 + 3 \cdot 3 = 1 - 4 + 9 = 6$。
- 切断在 `2` 之前，线性序列为 $[2,3,1]$，得分 $S = 1 \cdot 2 - 2 \cdot 3 + 3 \cdot 1 = 2 - 6 + 3 = -1$。
- 切断在 `3` 之前，线性序列为 $[3,1,2]$，得分 $S = 1 \cdot 3 - 2 \cdot 1 + 3 \cdot 2 = 3 - 2 + 6 = 7$。

所有可能得分中的最大值为 `7`。

## 样例2

**输入**

```
1
1
```

**输出**

```
1
```

**说明**

属于 $n=1$ 的边界情况。圆环上只有一个数字 `1`，只能在该位置切断，线性序列为 $[1]$，得分 $S = 1 \cdot 1 = 1$。最大得分即为 `1`。

## 样例3

**输入**

```
2
0 2
```

**输出**

```
2
```

**说明**

圆环上的数字为 `0`、`2`，共有 $n=2$ 个切断位置。

- 切断在 `0` 之前，序列 $[0,2]$，得分 $S = 1 \cdot 0 - 2 \cdot 2 = -4$。
- 切断在 `2` 之前，序列 $[2,0]$，得分 $S = 1 \cdot 2 - 2 \cdot 0 = 2$。

最大得分为 `2`。
