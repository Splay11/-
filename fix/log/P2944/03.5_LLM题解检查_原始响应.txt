## 解题思路

本题要求在一维圆环上选取断开位置，使得形成的线性序列 $x_1,x_2,\dots,x_n$ 的交替加权得分

$$
S = 1\cdot x_1 - 2\cdot x_2 + 3\cdot x_3 - 4\cdot x_4 + \cdots + (-1)^{n-1}\cdot n\cdot x_n
$$

达到最大。

由于数据范围 $n \le 2000$，可以采用直接枚举的方法：

1. **枚举断开位置**：圆环上共有 $n$ 个可能的断开位置（对应线性序列的起点）。使用 $0$‑based 下标，设断开位置为 $k$ （$0 \le k < n$），则线性序列的第 $j$ 个元素（$0 \le j < n$）为原圆环上的 `a[(k+j)%n]`。
2. **计算得分**：对于每个固定的 $k$，从 $j=0$ 到 $n-1$ 累加得分：
   - 系数的绝对值是 $j+1$；
   - 符号交替变化：$j=0$ 时为正，$j=1$ 时为负，$j=2$ 时为正，以此类推。可用一个变量 `sign` 维护当前符号（初值 $1$），每累加一项后将 `sign` 取反。
3. **取最大值**：记录所有 $n$ 个断开位置得分中的最大值即为答案。

因为 $n \le 2000$，双重循环的总运算量约为 $4\times10^6$ 次乘加运算，完全可以在时限内完成。

## 复杂度分析

- **时间复杂度**：$O(n^2)$。外层枚举 $n$ 个断开位置，内层每次 $O(n)$ 计算一个位置的得分。
- **空间复杂度**：$O(n)$。需要存储输入的圆环数组，除此之外仅使用了常数级别的辅助变量。

## 代码实现

### Python

```python
def solve():
    n = int(input().strip())
    a = list(map(int, input().split()))
    ans = -10**18  # 极小初始值

    # 枚举所有可能的断开位置 k
    for k in range(n):
        cur = 0
        sign = 1  # 当前项的符号，1 表示正，-1 表示负
        for j in range(n):
            # 系数 = j+1，数字 = a[(k+j)%n]
            cur += sign * (j + 1) * a[(k + j) % n]
            sign = -sign  # 交替符号
        if cur > ans:
            ans = cur

    print(ans)

if __name__ == "__main__":
    solve()
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }
        sc.close();

        long ans = Long.MIN_VALUE; // 极小初始值

        // 枚举所有可能的断开位置 k
        for (int k = 0; k < n; k++) {
            long cur = 0;
            int sign = 1; // 当前项的符号
            for (int j = 0; j < n; j++) {
                // 使用 long 避免乘法溢出
                cur += sign * (long)(j + 1) * a[(k + j) % n];
                sign = -sign; // 交替符号
            }
            if (cur > ans) {
                ans = cur;
            }
        }

        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <climits>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    long long ans = LLONG_MIN; // 极小初始值

    // 枚举所有可能的断开位置 k
    for (int k = 0; k < n; k++) {
        long long cur = 0;
        int sign = 1; // 当前项的符号
        for (int j = 0; j < n; j++) {
            // 1LL 确保转换为 long long 乘法
            cur += sign * 1LL * (j + 1) * a[(k + j) % n];
            sign = -sign; // 交替符号
        }
        if (cur > ans) {
            ans = cur;
        }
    }

    cout << ans << "\n";
    return 0;
}
```
