# 题目内容
监测系统记录了 $n$ 个读数 $a_1, a_2, \ldots, a_n$，下标从 `1` 开始。其中 $k$ 个读数被判定为故障，故障读数的下标依次为 $b_1, b_2, \ldots, b_k$，保证两两不同。

请计算所有未被判定为故障的读数之和。

约束：读数个数不超过 `2\times 10^5`，每个读数为不超过 `10^9` 的正整数。

# 输入描述
第一行包含两个整数 $n$ 和 $k$，分别表示读数个数与故障读数个数。保证 $1 \le k \le n \le 2 \times 10^5$。
第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$，表示各读数。保证 $1 \le a_i \le 10^9$。
第三行包含 $k$ 个互不相同的整数 $b_1, b_2, \ldots, b_k$，表示故障读数的下标。保证 $1 \le b_i \le n$。

# 输出描述
输出一个整数，表示所有有效读数之和。

## 样例1

**输入**

```
1 1
9
1
```

**输出**

```
0
```

**说明**

只有一个读数且它被判定为故障。
有效读数之和为 `0`。这是全部故障的边界情形。
