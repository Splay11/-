# 题目内容
某市环境监测中心安排值班员对辖区内 $n$ 个水质断面做一轮例行抽检。中心规程写明：只根据本轮读数决定是否取样——浓度严格高于预警阈值 $x$ 的断面，各抽取 $y$ 毫升水样送实验室；未超过阈值的断面本轮不取样。值班员需要一次性统计本轮一共会送出多少毫升水样。

形式化地，给定整数 $n$、$x$、$y$ 以及各断面浓度 $a_1, a_2, \dots, a_n$。对每个 $i$，若 $a_i > x$ 则贡献 $y$，否则贡献 `0`。请计算所有贡献之和。

约束：断面个数不超过 `200000`，阈值 $x$、单次取样量 $y$ 以及每个浓度读数均不超过 `1000000000`，且 $y \le x$。

# 输入描述
第一行包含三个整数 $n$、$x$ 和 $y$，分别表示断面个数、预警阈值和单次取样量。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$，表示各断面的浓度读数。
保证 $1 \le n \le 200000$，$1 \le y \le x \le 1000000000$，$1 \le a_i \le 1000000000$。

# 输出描述
输出一个整数，表示本轮一共送出的水样毫升数。

## 样例1

**输入**

```
4 10 3
8 12 10 20
```

**输出**

```
6
```

**说明**

共有 `4` 个货架，阈值 $x=`10`$，每次发出 $y=`3`$ 件。件数 `12` 与 `20` 严格大于 `10`，各发 `3` 件；`8` 与 `10` 不严格大于阈值，不发。一共发出 $2 \times 3 = `6`$ 件。

## 样例2

**输入**

```
3 5 5
1 2 5
```

**输出**

```
0
```

**说明**

三个货架件数分别为 `1`、`2`、`5`，均不严格大于阈值 `5`，因此发出件数为 `0`。

## 样例3

**输入**

```
1 1 1
2
```

**输出**

```
1
```

**说明**

只有一个货架，件数 `2` 严格大于阈值 `1`，发出 `1` 件。
