## 解题思路

1. **操作效果**：选择第 $i$ 行和第 $j$ 列后，这两条线上的 `'Z'` 都会变成 `'N'`。交点 $(i,j)$ 只应被计算一次。
2. **增量公式**：设初始 `'N'` 的个数为 $\textit{init}$，第 $i$ 行的 `'Z'` 个数为 $r_i$，第 $j$ 列的 `'Z'` 个数为 $c_j$。选择 $(i,j)$ 后新增的 `'N'` 个数为
   $$\Delta(i,j)=r_i+c_j-[grid[i][j]=\texttt{Z}].$$
3. **枚举最优十字**：预处理每行、每列的 `'Z'` 计数后，枚举所有行列表，取最大 $\Delta$，答案为 $\textit{init}+\Delta_{\max}$。

## 复杂度分析

- **时间复杂度**：$O(nm)$。预处理与枚举行列表均与网格规模同阶。
- **空间复杂度**：$O(nm)$。需要保存整个网格以及行、列计数。

## 代码实现

### Python

```python
# -*- coding: utf-8 -*-
n, m = map(int, input().split())
matrix = [input().strip() for _ in range(n)]

init = 0
cntZ_row = [0] * n
cntZ_col = [0] * m

for i in range(n):
    for j in range(m):
        if matrix[i][j] == 'N':
            init += 1
        else:
            cntZ_row[i] += 1
            cntZ_col[j] += 1

delta_max = 0
for i in range(n):
    for j in range(m):
        cur = cntZ_row[i] + cntZ_col[j] - (1 if matrix[i][j] == 'Z' else 0)
        delta_max = max(delta_max, cur)

print(init + delta_max)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        sc.nextLine();
        String[] matrix = new String[n];
        for (int i = 0; i < n; i++) {
            matrix[i] = sc.nextLine();
        }
        int init = 0;
        int[] cntZ_row = new int[n];
        int[] cntZ_col = new int[m];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                char ch = matrix[i].charAt(j);
                if (ch == 'N') {
                    init++;
                } else {
                    cntZ_row[i]++;
                    cntZ_col[j]++;
                }
            }
        }
        int deltaMax = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                int cur = cntZ_row[i] + cntZ_col[j] - (matrix[i].charAt(j) == 'Z' ? 1 : 0);
                deltaMax = Math.max(deltaMax, cur);
            }
        }
        System.out.println(init + deltaMax);
        sc.close();
    }
}
```
