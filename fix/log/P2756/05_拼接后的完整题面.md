# 题目内容
给定一个 $n$ 行 $m$ 列的网格，每个格子上写着大写字母 `'N'` 或 `'Z'`。

你可以恰好选择一整行和一整列，把这条十字区域内所有的 `'Z'` 改写成 `'N'`。请输出操作后网格中 `'N'` 的最大可能数量。

行数 $n$ 与列数 $m$ 满足 $1 \le n,m \le 10^3$。

# 输入描述
第一行包含两个正整数 $n$ 和 $m$，表示网格的行数和列数。
接下来 $n$ 行，每行一个长度为 $m$ 的字符串，仅由大写字母 `'N'` 和 `'Z'` 组成，表示该行的格子。

# 输出描述
输出一个整数，表示操作后 `'N'` 的最大数量。

## 样例1

**输入**

```
3 3
NNZ
NNZ
NNZ
```

**输出**

```
9
```

**说明**

初始 `'N'` 有 `6` 个。选择任意一行与第 `3` 列，可将该列 `3` 个 `'Z'` 全部改为 `'N'`，网格变为全 `'N'`，答案为 `9`。

## 样例2

**输入**

```
3 3
ZNZ
NZN
ZNZ
```

**输出**

```
7
```

**说明**

初始 `'N'` 有 `4` 个。选择第 `1` 行与第 `1` 列（下标从 `1` 开始），十字区域覆盖 `3` 个 `'Z'`（交点本身为 `'Z'`，只计一次），新增 `3` 个 `'N'`，答案为 $4+3=7$。

## 样例3

**输入**

```
1 1
Z
```

**输出**

```
1
```

**说明**

只有一个格子 `'Z'`。必须选择唯一的一行一列，将其改为 `'N'`，答案为 `1`。

## 样例4

**输入**

```
2 2
NZ
ZN
```

**输出**

```
4
```

**说明**

初始 `'N'` 有 `2` 个。选择第 `1` 行第 `1` 列（交点为 `'N'`），该行一列共覆盖 `2` 个 `'Z'`，全部翻新后网格全为 `'N'`，答案为 `4`。
