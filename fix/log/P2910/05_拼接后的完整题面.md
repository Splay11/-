# 题目内容
给定一个长度为 $n$、仅由大小写英文字母组成的字符串 $s$（下标从 $1$ 开始）。你有一台改写器，具有休眠与唤醒两种相位，初始为休眠。

按下标从小到大依次处理每个字符：
- 若当前为休眠且该字符是小写字母，则将其改为对应大写字母，并将相位切换为唤醒；
- 若当前为唤醒且该字符是大写字母，则将其改为对应小写字母，并将相位切换为休眠；
- 其余情况不改写，相位保持不变。

请输出处理完成后的字符串。

字符串长度 $n$ 不超过 $2 \times 10^5$。

# 输入描述
第一行输入一个正整数 $n$，表示字符串长度，满足 $1 \le n \le 2 \times 10^5$。
第二行输入一个长度为 $n$ 的字符串 $s$，仅由大小写英文字母构成。

# 输出描述
输出一个字符串，表示按规则改写完成后的结果。

## 样例1

**输入**

```
5
abCCd
```

**输出**

```
AbcCD
```

**说明**

初始休眠。
- $a$ 小写：改为 $A$，切到唤醒；
- $b$ 小写：唤醒下不处理；
- $C$ 大写：改为 $c$，切回休眠；
- $C$ 大写：休眠下不处理；
- $d$ 小写：改为 $D$，切到唤醒。
结果为 $AbcCD$。

## 样例2

**输入**

```
1
a
```

**输出**

```
A
```

**说明**

初始休眠，$a$ 为小写，改为 $A$。

## 样例3

**输入**

```
1
A
```

**输出**

```
A
```

**说明**

初始休眠，$A$ 为大写，不满足改写条件，保持 $A$。

## 样例4

**输入**

```
3
ABC
```

**输出**

```
ABC
```

**说明**

全程休眠遇到的都是大写，一次改写都不触发，输出原串 $ABC$。
