## 解题思路

要让频谱带字典序最小，应尽可能把靠左的字符变成 $\texttt{a}$。

用双指针配对：

- 左指针 $i$ 从左向右找第一个不是 $\texttt{a}$ 的位置（它可以继续减小）。
- 右指针 $j$ 从右向左找第一个不是 $\texttt{z}$ 的位置（它可以继续增大）。
- 若 $i < j$，对这一对执行尽可能多次操作：$d = \min(s[i]-\texttt{a},\ \texttt{z}-s[j])$，把 $s[i]$ 减小 $d$、$s[j]$ 增大 $d$。然后根据是否碰到边界移动指针。

每次至少让一端到达边界，指针共移动 $O(n)$ 次。无法配对时停止；若自始至终无法配对，结果就是原串。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(n)$。

## 代码实现

### Python

```python
def make_minlex(s: str) -> str:
    n = len(s)
    arr = list(s)
    i, j = 0, n - 1

    while i < j:
        if arr[i] == 'a':
            i += 1
            continue
        if arr[j] == 'z':
            j -= 1
            continue

        d = min(ord(arr[i]) - ord('a'), ord('z') - ord(arr[j]))
        arr[i] = chr(ord(arr[i]) - d)
        arr[j] = chr(ord(arr[j]) + d)

        if arr[i] == 'a':
            i += 1
        if arr[j] == 'z':
            j -= 1

    return ''.join(arr)


if __name__ == "__main__":
    n = int(input().strip())
    s = input().strip()
    print(make_minlex(s))
```

### Java

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());
        char[] s = br.readLine().trim().toCharArray();

        int i = 0, j = n - 1;
        while (i < j) {
            if (s[i] == 'a') {
                i++;
                continue;
            }
            if (s[j] == 'z') {
                j--;
                continue;
            }
            int d = Math.min(s[i] - 'a', 'z' - s[j]);
            s[i] -= d;
            s[j] += d;

            if (s[i] == 'a') i++;
            if (s[j] == 'z') j--;
        }

        System.out.println(new String(s));
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    string s;
    cin >> n;
    cin >> s;

    int i = 0, j = n - 1;
    while (i < j) {
        if (s[i] == 'a') {
            ++i;
            continue;
        }
        if (s[j] == 'z') {
            --j;
            continue;
        }
        int d = min(s[i] - 'a', 'z' - s[j]);
        s[i] -= d;
        s[j] += d;
        if (s[i] == 'a') ++i;
        if (s[j] == 'z') --j;
    }

    cout << s << "\n";
    return 0;
}
```
