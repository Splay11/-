# 题目内容
一条长度为 $n$ 的频谱带记为字符串 $s$，仅由小写英文字母构成。每次允许做如下操作任意次：
- 选择两个不同位置 $i$ 和 $j$（$i 
eq j$），要求 $s[i] 
eq \texttt{a}$ 且 $s[j] 
eq \texttt{z}$；
- 将 $s[i]$ 换成字母表中的前一个字母，同时将 $s[j]$ 换成字母表中的后一个字母。

在所有合法操作序列中，取能得到的字典序最小的频谱带。若一次合法操作都不存在，则保持原串。

字典序从左到右比较字母表顺序，更靠前的字母更小。

字符串长度 $n$ 不超过 $2 \times 10^5$。

# 输入描述
第一行输入一个整数 $n$，表示频谱带长度，满足 $1 \le n \le 2 \times 10^5$。
第二行输入一个长度为 $n$ 的字符串 $s$，仅由小写英文字母构成。

# 输出描述
输出一个字符串，表示经过任意次合法操作后能得到的字典序最小的频谱带。若不存在合法操作，则输出原字符串。

## 样例1

**输入**

```
2
bb
```

**输出**

```
ac
```

**说明**

对位置 $1$ 与 $2$ 操作一次：$b$ 前移为 $a$，另一个 $b$ 后移为 $c$，得到 $ac$。这是字典序最小结果。

## 样例2

**输入**

```
3
aaa
```

**输出**

```
aaa
```

**说明**

所有字符都是 $a$，不存在满足 $s[i] 
eq \texttt{a}$ 的位置，无法操作，输出原串。

## 样例3

**输入**

```
1
z
```

**输出**

```
z
```

**说明**

长度为 $1$，找不到两个不同位置，无法操作，输出原串 $z$。

## 样例4

**输入**

```
3
zab
```

**输出**

```
abz
```

**说明**

左指针处理 $z$，右指针处理 $b$：先把右侧抬到 $z$、左侧降为 $y$，再继续与中间的 $a$ 配对，最终把最左侧降到 $a$，得到 $abz$。
