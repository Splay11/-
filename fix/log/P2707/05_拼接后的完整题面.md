# 题目内容
小蓝定义了一种非负整数序列的稳定性质。对于两个非负整数，定义按位对称差运算 $\oplus$ 和按位交运算 $\odot$：$x \oplus y$ 的结果是将 $x$ 与 $y$ 的二进制表示逐位进行异或；$x \odot y$ 的结果是将 $x$ 与 $y$ 的二进制表示逐位进行与。

给定一个长度为 $n$ 的序列 $a_1, a_2, \dots, a_n$，定义其整体对称差 $X = a_1 \oplus a_2 \oplus \dots \oplus a_n$，整体交 $Y = a_1 \odot a_2 \odot \dots \odot a_n$。若 $X \le Y$，则称该序列是稳定的。

现在小蓝希望统计所有满足以下条件的稳定序列的数量：每个元素都是小于 $2^m$ 的非负整数。由于答案可能很大，请输出结果对 $10^9+7$ 取模的值。

约束：序列长度 $n$ 满足 $1 \le n \le 10^5$，位宽 $m$ 满足 $0 \le m \le 10^5$。

# 输入描述
第一行包含两个整数 $n$ 和 $m$，分别表示序列的长度和元素的二进制位宽。

# 输出描述
输出一个整数，表示满足条件的稳定序列的数量对 $10^9+7$ 取模后的结果。

## 样例1

**输入**

```
1 3
```

**输出**

```
8
```

**说明**

序列长度为 $n=1$，因此整体对称差 $X = a_1$，整体交 $Y = a_1$。稳定条件 $X \le Y$ 即 $a_1 \le a_1$，恒成立。因此任意满足 $0 \le a_1 < 2^3$ 的非负整数均可，共 $2^3 = 8$ 种方案，故答案为 `8`。

## 样例2

**输入**

```
2 3
```

**输出**

```
22
```

**说明**

序列长度 $n=2$ 为偶数，位宽 $m=3$。计算 $T = 2^{n-1} = 2$。根据偶数情况的公式，答案为 $\frac{(T-1)^m \cdot T + (2T)^m}{T+1}$ 对 $10^9+7$ 取模。代入得 $\frac{1^3 \cdot 2 + 4^3}{3} = \frac{2+64}{3} = 22$，故答案为 `22`。

## 样例3

**输入**

```
3 2
```

**输出**

```
25
```

**说明**

序列长度 $n=3$ 为奇数，位宽 $m=2$。计算 $T = 2^{n-1} = 4$。奇数情况下要求每一位都必须满足 $X_b = Y_b$，每位有 $T+1$ 种合法赋值方式，总方案数为 $(T+1)^m = 5^2 = 25$。故答案为 `25`。

## 样例4

**输入**

```
5 0
```

**输出**

```
1
```

**说明**

位宽 $m=0$ 意味着所有元素只能取 $0$（因为 $0 \le a_i < 2^0 = 1$）。无论序列长度 $n$ 是多少，仅存在全 $0$ 序列。此时 $X = Y = 0$，满足 $X \le Y$。因此方案数为 `1`。公式中 $T = 2^{4} = 16$，奇数时 $(T+1)^0 = 1$，与边界情况一致。
