# 题目内容
公司开放了 $m$ 个工位，第 $i$ 个工位有两个参数：满意度 $c_i$ 与报价 $p_i$。有 $n$ 名员工参与认领，第 $j$ 名员工的预算为 $x_j$。

一名员工能够认领某个工位，当且仅当其预算不小于该工位的报价。此外还要满足：

1. 每人最多认领 `1` 个工位；
2. 每个工位最多被 `1` 人认领。

请计算在合法认领方案下，被认领工位的满意度之和的最大值。

人数与工位数均不超过 `2×10^5`，预算、满意度与报价均为不超过 `10^9` 的正整数。

# 输入描述
第一行两个整数 $n$ 和 $m$（$1 \le n, m \le 2 \times 10^5$），分别表示员工人数与工位个数。
第二行 $n$ 个整数 $x_1, x_2, \ldots, x_n$（$1 \le x_i \le 10^9$），表示各名员工的预算。
接下来 $m$ 行，每行两个整数 $c_i$ 和 $p_i$（$1 \le c_i, p_i \le 10^9$），表示第 $i$ 个工位的满意度和报价。

# 输出描述
输出一个整数，表示满意度之和的最大可能值。

## 样例1

**输入**

```
3 3
1 5 10
10 8
4 3
6 6
```

**输出**

```
14
```

**说明**

预算升序为 $1,5,10$。报价 `3` 的工位满意度 `4` 可被预算 `5` 取走；报价 `8` 的工位满意度 `10` 可被预算 `10` 取走；预算 `1` 买不起任何工位。最大和为 $4+10=14$。

## 样例2

**输入**

```
1 1
1
5 10
```

**输出**

```
0
```

**说明**

唯一员工预算为 `1`，工位报价为 `10`，无法认领，输出 `0`。

## 样例3

**输入**

```
2 1
100 100
7 1
```

**输出**

```
7
```

**说明**

只有一个工位，满意度 `7`、报价 `1`，两名员工都能买，但工位只能认领一次，答案为 `7`。
