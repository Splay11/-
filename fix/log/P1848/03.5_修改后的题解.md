## 解题思路

按预算从低到高考虑员工，让预算更紧的人优先在“当前买得起的工位”里挑满意度最高的那个。

具体做法：

1. 将员工预算升序排序，将工位按报价升序排序；
2. 用一个大根堆维护当前所有报价不超过当前员工预算、且尚未被认领的工位满意度；
3. 从穷到富扫描员工：把所有新买得起的工位满意度加入堆，若堆非空则取出堆顶（当前最高满意度）累加到答案。

这样每个人都在自己买得起的集合里贪心拿走当前最优工位，总满意度最大。

## 复杂度分析

排序与堆操作均为对数级。

- 时间复杂度：$O((n+m)\log(n+m))$。
- 空间复杂度：$O(n+m)$。

## 代码实现

### Python

```python
import heapq

n, m = map(int, input().split())
budget = list(map(int, input().split()))
seat = [list(map(int, input().split())) for _ in range(m)]

budget.sort()
seat.sort(key=lambda x: x[1])

heap = []
res = 0
idx = 0
for money in budget:
    while idx < m and money >= seat[idx][1]:
        heapq.heappush(heap, -seat[idx][0])
        idx += 1
    if heap:
        res += -heapq.heappop(heap)
print(res)
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt(), m = sc.nextInt();
        int[] budget = new int[n];
        for (int i = 0; i < n; i++) budget[i] = sc.nextInt();
        int[][] seat = new int[m][2];
        for (int i = 0; i < m; i++) {
            seat[i][0] = sc.nextInt();
            seat[i][1] = sc.nextInt();
        }
        Arrays.sort(budget);
        Arrays.sort(seat, (a, b) -> Integer.compare(a[1], b[1]));
        PriorityQueue<Integer> pq = new PriorityQueue<>(Collections.reverseOrder());
        long res = 0;
        int idx = 0;
        for (int money : budget) {
            while (idx < m && money >= seat[idx][1]) {
                pq.add(seat[idx][0]);
                idx++;
            }
            if (!pq.isEmpty()) res += pq.poll();
        }
        System.out.println(res);
        sc.close();
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

#define int long long
signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> budget(n);
    for (int i = 0; i < n; i++) cin >> budget[i];
    vector<array<int, 2>> seat(m);
    for (auto &e : seat) cin >> e[0] >> e[1];
    sort(budget.begin(), budget.end());
    sort(seat.begin(), seat.end(), [](auto &a, auto &b) { return a[1] < b[1]; });
    priority_queue<int> pq;
    int res = 0, idx = 0;
    for (int money : budget) {
        while (idx < m && money >= seat[idx][1]) {
            pq.push(seat[idx][0]);
            idx++;
        }
        if (!pq.empty()) {
            res += pq.top();
            pq.pop();
        }
    }
    cout << res << "\n";
    return 0;
}
```
