# 题目内容
科创园区地面铺设了 $n$ 行 $m$ 列能量板，左上角为 $(0,0)$，右下角为 $(n-1,m-1)$。格子 $(i,j)$ 的能量值为 $i \times m + j$。巡逻机器人从 $(0,0)$ 出发，每步可以走到上下左右四个方向的相邻格子。每到达一格就收集该格当前能量；离开后再进入时能量会重新刷新，可以再次收集。调度系统给出 $q$ 组询问，每组给出网格规模与步数上限 $k$，求最多走 $k$ 步能收集到的能量总和。起点 $(0,0)$ 的能量为 `0`。

约束：$1 \le q \le 100000$，$1 \le n,m,k \le 10000$，且 $n+m>2$。

# 输入描述
第一行一个整数 $q$，表示询问个数。
接下来 $q$ 行，每行三个整数 $n$、$m$、$k$，表示网格规模与步数上限。
保证 $1 \le q \le 100000$，$1 \le n,m,k \le 10000$，且 $n+m>2$。

# 输出描述
输出 $q$ 行，每行一个整数，表示对应询问能收集到的最大能量。

## 样例1

**输入**

```
2
3 1 4
1 3 2
```

**输出**

```
6
3
```

**说明**

第一组是 $3 \times 1$ 的竖条，走 `4` 步：先向下收集 `1` 和 `2`，再用剩余步数在底端两格之间往返，总积分 `6`。

第二组是 $1 \times 3$ 的横条，走 `2` 步只能向右，依次收集 `1` 和 `2`，总积分 `3`。

## 样例2

**输入**

```
1
4 4 3
```

**输出**

```
24
```

**说明**

步数恰好够一直向下走到第 `4` 行。向下三步收集的积分为 $4+8+12=24$，没有余步。

## 样例3

**输入**

```
1
1 5 10
```

**输出**

```
31
```

**说明**

只有一行，先向右走到最右端收集 $1+2+3+4=10$，剩余 `6` 步在最右两格之间往返，再得 `21`，合计 `31`。
