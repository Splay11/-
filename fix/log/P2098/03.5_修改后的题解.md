## 解题思路

格子 $(i,j)$ 的能量值为 $i\cdot m+j$。向下走一行能量增加 $m$，向右走一列只增加 `1`。因此应优先向下走到最底行，再向右走到最右列；若还有剩余步数，在能量最高的相邻两格之间往返。

具体计算：

- 若 $k\ge n-1$，先沿第一列走到 $(n-1,0)$，收集等差数列 $m,2m,\ldots,(n-1)m$；否则只走 $k$ 步向下。
- 剩余步数再沿底行向右，收集 $(n-1)m+1,(n-1)m+2,\ldots$。
- 若仍有余步：当 $m\neq 1$ 时在底行最右两格往返；当 $m=1$ 时在最底两行之间往返。奇数步取较小的那格，偶数步取较大的那格。

等差数列前 $t$ 项和用公式 $t\cdot(2a_1+(t-1)d)/2$ 一次算完。

## 复杂度分析

每组询问 $O(1)$，总时间复杂度 $O(q)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
import sys

def fun(n, a1, d):
    return n * (2 * a1 + (n - 1) * d) // 2

def main():
    data = sys.stdin.read().split()
    idx = 0
    t = int(data[idx]); idx += 1
    for _ in range(t):
        n = int(data[idx])
        m = int(data[idx + 1])
        k = int(data[idx + 2])
        idx += 3
        res = 0
        if k >= n - 1:
            res += fun(n - 1, m, m)
            k -= n - 1
        else:
            res += fun(k, m, m)
            k = 0
        if k >= m - 1:
            res += fun(m - 1, (n - 1) * m + 1, 1)
            k -= m - 1
        else:
            res += fun(k, (n - 1) * m + 1, 1)
            k = 0
        if m != 1:
            sum2 = (n - 1) * m + m - 1
            sum1 = (n - 1) * m + m - 2
        else:
            sum2 = (n - 1) * m + m - 1
            sum1 = (n - 2) * m + m - 1
        res += ((k + 1) // 2) * sum1
        res += (k // 2) * sum2
        print(res)

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static long fun(long n, long a1, long d) {
        return n * (2 * a1 + (n - 1) * d) / 2;
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        PrintWriter pw = new PrintWriter(System.out);
        StringTokenizer st = new StringTokenizer(br.readLine());
        int t = Integer.parseInt(st.nextToken());
        while (t-- > 0) {
            st = new StringTokenizer(br.readLine());
            long n = Long.parseLong(st.nextToken());
            long m = Long.parseLong(st.nextToken());
            long k = Long.parseLong(st.nextToken());
            long res = 0;
            if (k >= n - 1) {
                res += fun(n - 1, m, m);
                k -= n - 1;
            } else {
                res += fun(k, m, m);
                k = 0;
            }
            if (k >= m - 1) {
                res += fun(m - 1, (n - 1) * m + 1, 1);
                k -= m - 1;
            } else {
                res += fun(k, (n - 1) * m + 1, 1);
                k = 0;
            }
            long sum1, sum2;
            if (m != 1) {
                sum2 = (n - 1) * m + m - 1;
                sum1 = (n - 1) * m + m - 2;
            } else {
                sum2 = (n - 1) * m + m - 1;
                sum1 = (n - 2) * m + m - 1;
            }
            res += ((k + 1) / 2) * sum1;
            res += (k / 2) * sum2;
            pw.println(res);
        }
        pw.flush();
    }
}
```
