# 题目内容
一条长度为 $n$ 的线性探测带上，每个格子的状态用一个字符表示：

- 字符 `*` 表示该格已经确认存在异常源；
- 字符 `0`、`1`、`2` 表示该格没有异常源，且其左右相邻格子中异常源的个数恰好等于该数字；
- 字符 `?` 表示该格尚未判定，既可以是异常源，也可以不是。

请统计有多少种把所有 `?` 填成“有异常源 / 无异常源”的方案，使得整条探测带与已给出的数字约束完全一致。答案对 $10^9+7$ 取模。

约束条件：字符串长度 $n$ 满足 $1 \le n \le 10^5$。

# 输入描述
第一行包含一个字符串 $s$，仅由字符 `*`、`?` 以及 `0`、`1`、`2` 组成，表示探测带的当前记录。字符串长度 $n$ 满足 $1 \le n \le 10^5$。

# 输出描述
输出一个整数，表示合法布局方案数对 $10^9+7$ 取模后的结果。

## 样例1

**输入**

```
??**2?11??
```

**输出**

```
8
```

**说明**

字符串长度为 `10`，其中含有 `*`、`2`、`1` 以及若干 `?`。按从左到右的约束转移后，合法填法共 `8` 种，对 $10^9+7$ 取模仍为 `8`。

## 样例2

**输入**

```
*
```

**输出**

```
1
```

**说明**

只有一个格子且已经是 `*`，布局唯一，方案数为 `1`。

## 样例3

**输入**

```
?
```

**输出**

```
2
```

**说明**

单个 `?` 既可以是异常源，也可以不是，且没有数字约束，方案数为 `2`。

## 样例4

**输入**

```
0
```

**输出**

```
1
```

**说明**

该格不是异常源，左右都没有邻居，异常源个数为 `0`，与数字 `0` 吻合，方案数为 `1`。
