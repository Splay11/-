## 解题思路

这是一条一维探测带上的约束计数。每个非异常源格子上的数字，等于它左右邻居中异常源的个数。

从左到右扫描字符串，维护三个量（均对 $10^9+7$ 取模）：

- $A$：当前格子不能是异常源时的方案数；
- $B$：当前格子必须是异常源时的方案数；
- $C$：还要求下一格是异常源时的方案数。

对当前字符分类转移：

- `0`：左右都不能有异常源，于是 $B=C=0$，并保留“左侧非异常源”的方案；
- `1`：左右恰好一个异常源，把 $(A,B,C)$ 更新为 $(B,0,A)$；
- `2`：左右都必须是异常源，更新为 $(0,0,B)$；
- `*`：当前必须是异常源，更新为 $(0,C)$（$C$ 不变的那一支进入“当前为异常源”）；
- `?`：三种角色都可以尝试，按加法合并。

初值 $A=1,B=0,C=1$。扫完后答案为 $(A+B) \bmod (10^9+7)$，对应最后一个格子“不是异常源或是异常源、且不再要求后面还有异常源”。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
M = 10**9 + 7
A, B, C = 1, 0, 1
s = input()
for x in s:
    if x == '0':
        B = C = 0
    elif x == '1':
        A, B, C = B, 0, A
    elif x == '2':
        A, B, C = 0, 0, B
    elif x == '*':
        A, B = 0, C
    else:
        A, B, C = (A + B) % M, C, (A + B + C) % M
print((A + B) % M)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        long M = 1000000007;
        long A = 1, B = 0, C = 1;
        for (int i = 0; i < s.length(); i++) {
            char x = s.charAt(i);
            if (x == '0') {
                B = C = 0;
            } else if (x == '1') {
                long nA = B, nB = 0, nC = A;
                A = nA; B = nB; C = nC;
            } else if (x == '2') {
                A = 0; C = B; B = 0;
            } else if (x == '*') {
                A = 0; B = C;
            } else {
                long nA = (A + B) % M;
                long nB = C;
                long nC = (A + B + C) % M;
                A = nA; B = nB; C = nC;
            }
        }
        System.out.println((A + B) % M);
    }
}
```

            A = 0; C = B; B = 0;
        } else if (x == '*') {
            A = 0; B = C;
        } else {
            long long nA = (A + B) % M;
            long long nB = C;
            long long nC = (A + B + C) % M;
            A = nA; B = nB; C = nC;
        }
    }

}
