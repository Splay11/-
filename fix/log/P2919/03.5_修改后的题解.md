## 解题思路

本题要求按顺序扫描一个字母序列，并根据历史出现情况和相邻字符关系计算总能耗点数。由于序列长度可达 $10^6$，需要 $O(n)$ 的高效算法。

具体规则：
- **基础消耗**：若当前字母（忽略大小写）之前从未出现过，消耗 500 点；否则消耗 100 点。
- **额外消耗**：
  1. 如果当前字符与前一个字符**完全相同**（区分大小写），额外消耗 23 点。
  2. 否则，如果当前字符与前一个字符在字母表中**相邻**（忽略大小写，且认为 `a` 和 `z` 不相邻），额外消耗 44 点。

**算法步骤**：
1. 维护一个布尔数组 `seen[26]`（或集合），标记某个小写字母是否在之前的扫描中出现过。
2. 用变量 `prev` 记录前一个字符；初始时为特殊值（例如空字符或 0），表示尚未有前一个字符。
3. 遍历序列中的每个字符 `c`：
   - 取小写形式 `lower`。
   - **基础消耗**：若 `seen[lower - 'a']` 为 `false`，总能耗 +500 并标记为 `true`；否则 +100。
   - **额外消耗**：若 `prev` 存在（非首字符）：
     - 若 `c == prev`，总能耗 +23。
     - 否则计算 `|lower - prev.lower|`，若等于 1（即字母表相邻），总能耗 +44。
   - 更新 `prev = c`。
4. 输出累计的总能耗点数。

## 复杂度分析

- **时间复杂度**：只需对字符串进行一次遍历，每次操作均为常数时间 $O(1)$，总时间复杂度 $O(n)$，其中 $n$ 为序列长度。
- **空间复杂度**：仅使用一个大小为 26 的布尔数组记录字母是否出现过，以及若干个辅助变量，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
import sys

def main():
    s = sys.stdin.readline().strip()
    seen = set()           # 已扫描过的字母（小写）
    total = 0              # 总消耗点数
    prev = None            # 前一个字符

    for c in s:
        lower = c.lower()
        # 基础消耗
        if lower not in seen:
            total += 500
            seen.add(lower)
        else:
            total += 100

        # 额外消耗（与前一字符比较）
        if prev is not None:
            if c == prev:
                total += 23
            elif abs(ord(lower) - ord(prev.lower())) == 1:
                total += 44

        prev = c

    print(total)

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader in = new BufferedReader(new InputStreamReader(System.in));
        String s = in.readLine().trim();
        boolean[] seen = new boolean[26];  // 标记字母 a~z 是否已扫描过
        char prev = 0;                     // 前一个字符，0 表示无
        long total = 0;                    // 总消耗点数

        for (char c : s.toCharArray()) {
            char lower = Character.toLowerCase(c);
            int idx = lower - 'a';
            // 基础消耗
            if (!seen[idx]) {
                total += 500;
                seen[idx] = true;
            } else {
                total += 100;
            }
            // 额外消耗
            if (prev != 0) {
                if (c == prev) {
                    total += 23;
                } else if (Math.abs(lower - Character.toLowerCase(prev)) == 1) {
                    total += 44;
                }
            }
            prev = c;
        }
        System.out.println(total);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    vector<bool> seen(26, false);  // 标记字母 a~z 是否已扫描过
    char prev = 0;                  // 前一个字符，0 表示无
    long long total = 0;            // 总消耗点数

    for (char c : s) {
        char lower = tolower(c);
        int idx = lower - 'a';
        // 基础消耗
        if (!seen[idx]) {
            total += 500;
            seen[idx] = true;
        } else {
            total += 100;
        }
        // 额外消耗
        if (prev) {
            if (c == prev) {
                total += 23;
            } else if (abs(lower - tolower(prev)) == 1) {
                total += 44;
            }
        }
        prev = c;
    }

    cout << total << "\n";
    return 0;
}
```
