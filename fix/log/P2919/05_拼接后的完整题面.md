# 题目内容
在一台特殊的文字处理设备中，需要依次扫描一个由大小写英文字母构成的序列。扫描每个字母时，设备将根据历史记录和相邻关系消耗一定的能量点数，规则如下：

- 基础消耗：如果当前字母（不区分大小写）从未被扫描过，消耗 `500` 点；否则消耗 `100` 点。
- 额外消耗：若当前字母与前一个字母完全相同（区分大小写），额外消耗 `23` 点；若当前字母与前一个字母在字母表中相邻（不区分大小写），额外消耗 `44` 点。

字母表中，认为 `a` 和 `z` 不相邻。

现在给定完整的字母序列，请你计算扫描整个序列需要消耗的总点数。序列的长度不小于 `1`，不超过 `10^6`，且仅由大小写英文字母构成。

# 输入描述
输入包含一行，为一个由大小写英文字母组成的序列，其长度在 `1` 到 `10^6` 之间。

# 输出描述
输出一个整数，表示扫描整个序列所消耗的总点数。

## 样例1

**输入**

```
a
```

**输出**

```
500
```

**说明**

序列仅含一个字母 `'a'`。小写 `'a'` 首次被扫描，基础消耗 `500` 点；没有前一个字母，无需计算额外消耗。总点数为 `500`。

## 样例2

**输入**

```
AA
```

**输出**

```
623
```

**说明**

第 1 个字母 `'A'`：小写 `'a'` 首次出现，基础消耗 `500` 点。
第 2 个字母 `'A'`：小写 `'a'` 已经出现过，基础消耗 `100` 点；它与前一个字母 `'A'` 区分大小写完全相同，额外消耗 `23` 点。
总点数 = `500 + 100 + 23 = 623`。

## 样例3

**输入**

```
aB
```

**输出**

```
1044
```

**说明**

第 1 个字母 `'a'`：小写 `'a'` 首次出现，基础消耗 `500` 点。
第 2 个字母 `'B'`：小写 `'b'` 首次出现，基础消耗 `500` 点；它与前一个字母 `'a'` 不区分大小写时，对应字母 $b$ 与 $a$ 在字母表中相邻（$a$ 与 $b$ 相邻），额外消耗 `44` 点。
总点数 = `500 + 500 + 44 = 1044`。

## 样例4

**输入**

```
aAbB
```

**输出**

```
1244
```

**说明**

逐步计算如下：
- 第 1 个字母 `'a'`：小写 `'a'` 首次出现，基础消耗 `500`，无额外消耗。
- 第 2 个字母 `'A'`：小写 `'a'` 已出现过，基础消耗 `100`；与前一字母 `'a'` 区分大小写不同，且小写字母均为 $a$，不满足相邻条件，无额外消耗。
- 第 3 个字母 `'b'`：小写 `'b'` 首次出现，基础消耗 `500`；与前一字母 `'A'` 的小写 $a$ 相邻（$a$ 与 $b$ 相邻），额外消耗 `44`。
- 第 4 个字母 `'B'`：小写 `'b'` 已出现过，基础消耗 `100`；与前一字母 `'b'` 区分大小写不同，且小写均为 $b$，既不相同也不相邻，无额外消耗。
总点数 = `500 + 100 + 500 + 44 + 100 = 1244`。
