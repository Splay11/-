# 题目内容
作曲时使用长度为 `3` 的音节。每个音节由三个小写英文字母组成。给定第一个音节 $s$，需要再接出总共 $n$ 个音节 $s_1, s_2, \ldots, s_n$（其中 $s_1 = s$），并满足：

- 每个音节都是 $s$ 的一个排列，即所含字母种类以及每种字母的出现次数都与 $s$ 相同；
- 对任意 $i \in [2, n]$，音节 $s_i$ 的首字母等于 $s_{i-1}$ 的末字母。

两种方案被视为不同，当且仅当存在某个位置上的音节不同。请计算合法方案数，答案对 $10^9+7$ 取模。

测试组数 $T$ 满足 $1 \le T \le 10$。每组中 $s$ 长度为 `3` 且仅含小写英文字母，整数 $n$ 满足 $1 \le n \le 10^5$。

# 输入描述
每个测试文件包含多组数据。第一行包含一个整数 $T$，表示数据组数。
接下来 $T$ 行，每行包含一个长度为 `3` 的小写字母字符串 $s$ 和一个整数 $n$，以空格分隔。

# 输出描述
对于每组数据，输出一行一个整数，表示方案数对 $10^9+7$ 取模后的结果。

## 样例1

**输入**

```
2
abc 2
abc 1
```

**输出**

```
2
1
```

**说明**

第一组 $n=2$：`abc` 的排列中以末字母 `c` 开头的只有 `cab` 与 `cba`，共 `2` 种接龙。第二组 $n=1$，只能保留给定音节，方案数为 `1`。

## 样例2

**输入**

```
1
aaa 5
```

**输出**

```
1
```

**说明**

三个字母全相同，任意位置都只有一种音节 `aaa`，无论 $n$ 为多少方案数都是 `1`。

## 样例3

**输入**

```
1
aab 2
```

**输出**

```
1
```

**说明**

`aab` 的排列为 `aab`、`aba`、`baa`。当前末字母为 `b`，下一个必须以 `b` 开头，只有 `baa`，故方案数为 `1`。
