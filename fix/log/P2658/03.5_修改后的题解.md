## 解题思路

1. **问题转化**：每个音节必须是 $s$ 的排列，因此只需关心 $s$ 中至多 `3` 种字母的相对顺序。把 $s$ 里出现过的字母按首次出现顺序映射成整数 $0,1,2$。
2. **状态**：设 `dfs(i, x, y, z)` 表示：当前音节映射为 $(x,y,z)$，还需要组成总长为 $i$ 的音节序列时的方案数。当 $i=1$ 时只剩当前音节，方案数为 `1`。
3. **接龙转移**：下一个音节必须是同一多重集的排列，且首字母等于当前音节的末字母 $z$。
   - 若 $x \neq y$，以 $z$ 开头的排列有两种：$(z,x,y)$ 与 $(z,y,x)$，方案数为二者之和。
   - 若 $x = y$，只剩一种：$(z,x,y)$。
4. **记忆化**：把 $(x,y,z)$ 编码为 $x + 3y + 9z$，对每个剩余长度 $i$ 存入哈希表，避免重复搜索。每组数据单独清空记忆化表。答案对 $10^9+7$ 取模。

## 复杂度分析

时间复杂度 $O(n)$ 量级：每种剩余长度至多对应常数个三元组状态。空间复杂度 $O(n)$，用于记忆化。

## 代码实现

### Python

```python
import sys
sys.setrecursionlimit(2000000)

mod = 10**9 + 7
T = int(input())

while T > 0:
    T -= 1
    s, n = input().split()
    n = int(n)
    mp = {}
    p = 0
    for i in s:
        if i not in mp:
            mp[i] = p
            p += 1

    dp = [{} for i in range(n + 3)]

    def dfs(i, x, y, z):
        if i == 1:
            return 1
        k = x + y * 3 + z * 9
        if k in dp[i]:
            return dp[i][k]
        if x != y:
            dp[i][k] = (dfs(i - 1, z, x, y) + dfs(i - 1, z, y, x)) % mod
        else:
            dp[i][k] = dfs(i - 1, z, x, y)
        return dp[i][k]

    print(dfs(n, mp[s[0]], mp[s[1]], mp[s[2]]) % mod)
```

### Java

```java
import java.util.*;

public class Main {
    static final int MOD = (int)1e9 + 7;
    static int T;
    static String s;
    static int n;
    static Map<Character, Integer> mp;
    static List<Map<Integer, Integer>> dp;

    static int dfs(int i, int x, int y, int z) {
        if (i == 1) return 1;
        int k = x + y * 3 + z * 9;
        if (dp.get(i).containsKey(k)) return dp.get(i).get(k);
        if (x != y) {
            dp.get(i).put(k, (dfs(i - 1, z, x, y) + dfs(i - 1, z, y, x)) % MOD);
        } else {
            dp.get(i).put(k, dfs(i - 1, z, x, y));
        }
        return dp.get(i).get(k);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        T = sc.nextInt();
        while (T-- > 0) {
            s = sc.next();
            n = sc.nextInt();
            mp = new HashMap<>();
            int p = 0;
            for (char c : s.toCharArray()) {
                if (!mp.containsKey(c)) {
                    mp.put(c, p++);
                }
            }
            dp = new ArrayList<>();
            for (int i = 0; i <= n; i++) {
                dp.add(new HashMap<>());
            }
            System.out.println(dfs(n, mp.get(s.charAt(0)), mp.get(s.charAt(1)), mp.get(s.charAt(2))) % MOD);
        }
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MOD = 1e9 + 7;
int T;
string s;
int n;
unordered_map<char, int> mp;
vector<unordered_map<int, int>> dp;

int dfs(int i, int x, int y, int z) {
    if (i == 1) return 1;
    int k = x + y * 3 + z * 9;
    if (dp[i].count(k)) return dp[i][k];
    if (x != y) {
        dp[i][k] = (dfs(i - 1, z, x, y) + dfs(i - 1, z, y, x)) % MOD;
    } else {
        dp[i][k] = dfs(i - 1, z, x, y);
    }
    return dp[i][k];
}

int main() {
    cin >> T;
    while (T--) {
        cin >> s >> n;
        mp.clear();
        int p = 0;
        for (char c : s) {
            if (!mp.count(c)) {
                mp[c] = p++;
            }
        }
        dp.assign(n + 1, unordered_map<int, int>());
        cout << dfs(n, mp[s[0]], mp[s[1]], mp[s[2]]) % MOD << endl;
    }
    return 0;
}
```
