# 题目内容
有一条长度为 $n$ 的观测序列 $a$。对每个子序列（不必连续）$A$，定义 $f(A)$ 为将 $A$ 从小到大排序后的第 $k$ 个值；若 $|A| < k$，则 $f(A) = 0$。

请计算 $a$ 的所有子序列的 $f$ 值之和。答案可能很大，对 $998244353$ 取模。

输入包含多组数据。单组满足 $1 \le k \le n \le 2 \times 10^5$，元素 $a_i$ 为正整数且不超过 $10^9$；单个测试文件中所有 $n$ 之和不超过 $2 \times 10^5$。

# 输入描述
第一行输入一个整数 $T$，表示数据组数，满足 $1 \le T \le 100$。
每组数据包含：
第一行两个正整数 $n$ 和 $k$，分别表示序列长度与阈值下标，满足 $1 \le k \le n \le 2 \times 10^5$。
第二行 $n$ 个正整数 $a_1, a_2, \dots, a_n$，表示观测值，满足 $1 \le a_i \le 10^9$。
保证单个测试文件中所有 $n$ 之和不超过 $2 \times 10^5$。

# 输出描述
对于每组数据，输出一行一个整数，表示所有子序列 $f$ 值之和对 $998244353$ 取模的结果。

## 样例1

**输入**

```
2
6 3
1 2 3 4 5 6
3 1
2 2 2
```

**输出**

```
192
14
```

**说明**

第一组：排序后对每个可能成为第 $3$ 小的元素，乘上 $\binom{i}{2} \times 2^{n-i-1}$，累加得 $192$。
第二组：$k=1$ 时 $f$ 就是子序列最小值。三个 $2$ 的全部 $7$ 个非空子序列的 $f$ 都是 $2$，因此 $2 \times 7=14$。

## 样例2

**输入**

```
1
1 1
5
```

**输出**

```
5
```

**说明**

只有一个元素 $5$，且 $k=1$，唯一子序列的第 $1$ 小就是 $5$。

## 样例3

**输入**

```
1
4 2
4 1 3 2
```

**输出**

```
32
```

**说明**

排序后为 $1,2,3,4$。第 $2$ 小分别可能是 $2,3,4$，贡献为 $2\cdot 4 + 3\cdot 4 + 4\cdot 3=8+12+12=32$。
