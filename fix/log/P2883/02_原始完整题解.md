# 题解

## 题面描述
给定一个长度为$n$的序列$a$，定义函数$f(A)$为序列$A$在从小到大排好序后第$k$个值。若$|A|<k$，则$f(A)=0$。求原序列$a$中所有子序列（不要求连续）的$f$值之和，对$998244353$取模。

输入包含多组测试数据。每组输入：

- 第一行：正整数$n,k$，满足$1\le k\le n\le 2\times10^{5}$。
- 第二行：$n$个正整数$a_i(1\le a_i\le10^9)$。

输出每组结果各占一行。

## 思路
将原序列$a$排序为$b_1\le b_2\le\cdots\le b_n$。我们统计在所有子序列中，其第$k$小值等于$b_i$的方案数。要让$b_i$成为第$k$小：

1. 从前面$i-1$个元素中选出恰好$k-1$个，保证$b_i$是第$k$小。
2. 必须选$b_i$。
3. 对后面$n-i$个元素，可选可不选，共$2^{n-i}$种。

因此，对$i\ge k$，方案数为

$$
\binom{i-1}{k-1}\times 2^{n-i}
$$

预处理阶乘和逆元，以$O(n)$复杂度预计算$\binom{\cdot}{\cdot}$；预计算$2^i$数组。

## 代码实现

### C++
```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MOD = 998244353;

// 快速幂运算
ll modpow(ll a, ll e) {
    ll r = 1;
    while (e) {
        if (e & 1) r = r * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return r;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    int maxn = 200000;
    vector<ll> fac(maxn+1), invfac(maxn+1), pow2(maxn+1);
    fac[0] = 1;
    for (int i = 1; i <= maxn; i++) fac[i] = fac[i-1] * i % MOD;
    invfac[maxn] = modpow(fac[maxn], MOD-2);
    for (int i = maxn; i > 0; i--) invfac[i-1] = invfac[i] * i % MOD;
    pow2[0] = 1;
    for (int i = 1; i <= maxn; i++) pow2[i] = pow2[i-1] * 2 % MOD;

    while (T--) {
        int n, k;
        cin >> n >> k;
        vector<ll> a(n);
        for (int i = 0; i < n; i++) cin >> a[i];
        sort(a.begin(), a.end());
        ll ans = 0;
        for (int i = k-1; i < n; i++) {
            // 组合数 C(i, k-1)
            ll comb = fac[i] * invfac[k-1] % MOD * invfac[i-(k-1)] % MOD;
            // 贡献 a[i] * C(i, k-1) * 2^{n-i-1}
            ans = (ans + a[i] % MOD * comb % MOD * pow2[n-i-1]) % MOD;
        }
        cout << ans << '\n';
    }
    return 0;
}
```

```python
for i in range(maxn, 0, -1):

for i in range(1, maxn+1):
```

### Java
```java
import java.io.*;
import java.util.*;

public class Main {
    static final int MOD = 998244353;
    static long modpow(long a, long e) {
        long r = 1;
        a %= MOD;
        while (e > 0) {
            if ((e & 1) == 1) r = r * a % MOD;
            a = a * a % MOD;
            e >>= 1;
        }
        return r;
    }
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(br.readLine());
        int maxn = 200000;
        long[] fac = new long[maxn+1], invfac = new long[maxn+1], pow2 = new long[maxn+1];
        fac[0] = 1;
        for (int i = 1; i <= maxn; i++) fac[i] = fac[i-1] * i % MOD;
        invfac[maxn] = modpow(fac[maxn], MOD-2);
        for (int i = maxn; i > 0; i--) invfac[i-1] = invfac[i] * i % MOD;
        pow2[0] = 1;
        for (int i = 1; i <= maxn; i++) pow2[i] = pow2[i-1] * 2 % MOD;

        while (T-- > 0) {
            String[] nk = br.readLine().split(" ");
            int n = Integer.parseInt(nk[0]);
            int k = Integer.parseInt(nk[1]);
            long[] a = new long[n];
            String[] parts = br.readLine().split(" ");
            for (int i = 0; i < n; i++) a[i] = Long.parseLong(parts[i]);
            Arrays.sort(a);
            long ans = 0;
            for (int i = k-1; i < n; i++) {
                long comb = fac[i] * invfac[k-1] % MOD * invfac[i-(k-1)] % MOD;
                ans = (ans + a[i] % MOD * comb % MOD * pow2[n-i-1]) % MOD;
            }
            System.out.println(ans);
        }
    }
}
```
