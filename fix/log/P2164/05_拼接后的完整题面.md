# 题目内容
监控系统记录了长度为 $n$ 的状态数组 $a$（下标从 `1` 开始）。运维人员会提出 $q$ 次查询，每次给出 $(op,l,r)$：当 $op=1$ 时，从 $a_l$ 起按 $\&$、$|$、$\&$、$|$、$\ldots$ 的顺序从左到右计算到 $a_r$；当 $op=2$ 时，从 $a_l$ 起按 $|$、$\&$、$|$、$\&$、$\ldots$ 的顺序从左到右计算到 $a_r$。本题中 $\&$ 与 $|$ 不区分优先级，一律从左到右求值。$x \& y$ 表示按位与，$x | y$ 表示按位或。

约束：$1 \le n,q \le 200000$，$0 \le a_i < 2^{30}$，$1 \le op \le 2$，$1 \le l \le r \le n$。

# 输入描述
第一行两个整数 $n$ 和 $q$，表示数组长度与查询次数。
第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$。
接下来 $q$ 行，每行三个整数 $op$、$l$、$r$，表示一次查询。
保证 $1 \le n,q \le 200000$，$0 \le a_i < 2^{30}$，$1 \le op \le 2$，$1 \le l \le r \le n$。

# 输出描述
输出 $q$ 行，每行一个整数，表示对应查询的结果。

## 样例1

**输入**

```
4 3
7 1 6 2
1 1 4
2 1 2
1 3 3
```

**输出**

```
2
7
6
```

**说明**

三次询问分别为：

- $7 \& 1 | 6 \& 2$：先得 `1`，再得 `7`，再得 `2`；
- $7 | 1 = 7$；
- 单点即为 `6`。

## 样例2

**输入**

```
3 2
8 5 4
2 1 3
1 1 1
```

**输出**

```
4
8
```

**说明**

$op=2$ 计算 $8 | 5 \& 4$：先得 `13`，再与 `4` 得 `4`。第二次询问是单点 `8`。

## 样例3

**输入**

```
6 1
9 0 3 1 8 2
2 2 6
```

**输出**

```
0
```

**说明**

计算 $0 | 3 \& 1 | 8 \& 2$：依次得到 `3`、`1`、`9`、`0`，答案为 `0`。
