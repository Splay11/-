# 题目内容
下面是一组关于系统可靠性与基础数据结构的客观题。请按题号顺序作答。每题均给出四个选项 `A`、`B`、`C`、`D`；标注为“多选”的题目可以选择多个选项。

1. 某团队使用生成式模型为工单生成摘要，但发现摘要中出现了原始工单没有的信息。为了抑制这种编造现象，更合适的提示约束是？
- A 提高生成随机性，让模型输出更多候选表达
- B 限定依据原始工单内容总结，缺失信息标为未提供
- C 把摘要长度固定得更长，以容纳更多推测细节
- D 要求模型优先补充背景原因，使摘要看起来更完整

2. 某操作系统的文件权限串显示为 `-rw-r-----`。若某用户属于该文件所属组，但不是文件所有者，则该用户通常具有什么权限？
- A 仅可读
- B 无权限
- C 可执行但缺少读取权限
- D 可读可写

3. 某制度问答系统采用检索增强生成，但用户发现回答会引用过期制度。检索日志显示靠前片段的相似度较高，但混有旧版本制度。下列改进更能直接缓解该问题的是？
- A 提高生成温度，让模型用更丰富表述融合多版制度内容
- B 缩短最终答案长度，减少暴露过期引用细节的机会
- C 在召回和重排阶段加入版本、生效时间和来源过滤，再注入命中片段
- D 继续扩大候选片段数量，使新旧版本都有机会进入上下文，由模型综合判断

4. 事务 `T1` 第一次读取某行余额为 `100`。事务 `T2` 随后提交更新，把该余额改为 `120`。`T1` 在同一事务内再次读取同一行得到 `120`。该现象更贴近哪类并发读问题？
- A 幻读：条件范围内行集合变化
- B 死锁：事务之间形成循环等待
- C 不可重复读：同一行两次读取变化
- D 脏读：读取其他事务未提交数据

5. 给定若干任务的开始和结束时间，希望选出数量最多的互不重叠任务。下列贪心策略通常可用于该问题并可通过交换论证证明正确的是？
- A 每次选择开始时间最早的可选任务
- B 每次选择与其他任务重叠最多的任务
- C 每次选择持续时间最长的可选任务
- D 每次选择结束时间最早的可选任务

6. 某列表中存在多个排序键相同的记录，业务要求排序后这些记录仍保持原来的相对先后顺序。下列算法性质最贴近该要求的是？
- A 稳定排序
- B 外部排序
- C 分治排序
- D 原地排序

7. 某风控场景更关注减少误拦正常用户。验证集上模型 `M1` 的 `TP` 为 `80`，`FP` 为 `20`，`FN` 为 `40`；模型 `M2` 的 `TP` 为 `70`，`FP` 为 `10`，`FN` 为 `50`。若主要按“被判高风险的请求中确实高风险的比例”取舍，下列判断更合理的是？
- A 选 `M2`：`Recall = 70/(70+50)`，高于 `M1` 的 `Recall`
- B 选 `M2`：`Precision = 70/(70+10)`，高于 `M1` 的 `Precision`
- C 选 `M1`：`FP = 20`、`FN = 40`，误拦更少且覆盖更高
- D 选 `M1`：`Precision = 80/(80+20)`，`Recall = 80/(80+40)`

8. 某运行记录文件 `run.log` 中每行仅包含一个三位错误码且无其他内容。希望统计错误码 `500` 出现的行数，下列操作更符合该目标的是？
- A 先按 `500` 过滤文件内容，再统计行数
- B 先排除 `500`，再统计字节数
- C 先统计文件行数，再查找 `500`
- D 把文件内容作为输入交给查找 `500` 的命令并计数

9. 某后端服务把一个耗时任务拆成多个线程在同一进程内执行。下列关于这些线程与进程资源关系的说法较合理的是？
- A 线程切换时会重新创建进程页表，因此开销通常高于进程切换
- B 同进程线程共享同一地址空间，但各自有栈和调度上下文
- C 多个线程并发执行时不涉及同步问题，因为它们共享同一份内存
- D 线程拥有独立地址空间，线程间传递对象需要经过内核网络栈

10. 某进程执行一条访存指令时发生可恢复缺页异常。内核完成页表更新并装入目标页后，若该处理器支持精确异常，用户态执行流通常如何恢复？
- A 重启当前进程，从主函数入口重新执行
- B 恢复到触发缺页的访存指令，由该指令重新执行
- C 从异常处理程序入口继续执行原用户逻辑
- D 跳过触发缺页的访存指令，从下一条指令继续执行

11. 某订单回调接口可能因网络抖动被调用方重试。为了避免同一业务事件被重复处理，服务端设计中最关键的是？
- A 要求客户端把超时时间调得更短，让失败更快暴露
- B 在响应体中返回更详细日志，由调用方自行排查
- C 按事件唯一编号做幂等校验，重复请求返回已处理结果
- D 把接口从加密传输改成明文传输，降低握手开销

12. 某关系数据库中表 `orders` 上有联合索引 `(account_id, state, created_at)`。下列查询条件最符合该索引最左前缀使用方式的是？
- A `WHERE account_id = 1001 AND state = 1`
- B `WHERE state = 1 ORDER BY account_id`
- C `WHERE created_at > '2026-01-01'`
- D `WHERE state = 1 AND created_at > '2026-01-01'`

13. 一棵非空二叉树共有 `29` 个结点，其中度为 `1` 的结点有 `6` 个。按二叉树结点度数关系推断，该树中度为 `2` 的结点数为？
- A `12`
- B `13`
- C `11`
- D `10`

14. 某后端系统让语言模型根据用户请求调用“查询订单”工具。关于该工具调用机制的执行边界，下列说法较合理的是？
- A 模型输出调用请求，后端校验参数并执行工具
- B 后端只校验参数格式，把用户身份和资源权限判断留到工具返回后再处理
- C 模型生成结构化调用结果后直接写入业务数据库，不经过后端执行层
- D 工具接口只写自然语言用途说明，参数约束由模型根据上下文临场补齐

15. 某服务按顺序接收操作：`push(4)`、`push(7)`、`pop`、`push(2)`、`push(9)`、`pop`、`pop`。若底层结构是栈，则三次 `pop` 得到的元素顺序为？
- A `7`、`2`、`9`
- B `9`、`2`、`7`
- C `4`、`7`、`2`
- D `7`、`9`、`2`

16. 多选。某团队建设语言模型客服系统。为了降低幻觉和越权工具调用风险，下列设计较合理的有哪些？
- A 允许模型在资料不足时根据常识补全具体制度条款，提高回答完整度
- B 对低置信度或资料冲突的请求进入人工复核或返回无法判断
- C 对工具调用参数做白名单校验和权限校验，再由后端执行
- D 弱化检索片段来源和版本记录，把事实校验主要交给模型最终回答

17. 多选。某推荐服务上线新模型前，需要评估其离线效果和线上风险。下列做法较合理的有哪些？
- A 上线前保留灰度或小流量对照实验方案，观察真实用户反馈
- B 若训练集准确率很高，就可省略线上监控和回滚预案
- C 关注与业务目标一致的指标，而不是只看训练损失
- D 用独立验证集评估模型效果，避免只看训练集表现

18. 多选。某订单表常用查询为 `WHERE account_id = ? AND state = ? ORDER BY created_at DESC LIMIT 20`。关于索引执行代价的判断，正确的有哪些？
- A 把 `created_at` 放在联合索引首列，仍能稳定利用 `account_id` 和 `state` 的等值过滤前缀
- B 覆盖索引能否减少回表，还取决于 `SELECT` 列是否都在索引中
- C 若只有单列索引 `state`，低选择性状态列过滤效果可能较弱
- D 联合索引 `(account_id, state, created_at)` 有机会同时支持过滤和排序

19. 多选。关于某传输层协议在后端服务通信中的可靠传输机制，下列说法正确的有哪些？
- A 该协议会保留应用层消息边界，使接收端每次读取都对应一次发送

- C 该协议的重传机制可在部分报文丢失时补发未确认的数据
- D 该协议通过序号和确认机制支持按字节流确认数据接收进度

20. 多选。某后端服务中多个线程会同时更新共享计数器和任务队列。下列做法中，有助于降低并发错误风险的有哪些？
- A 在临界区中执行长时间网络请求，以减少锁释放次数
- B 把只读配置发布为不可变对象，减少共享状态修改
- C 把共享队列的入队和出队操作纳入一致的同步协议
