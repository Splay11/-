## 解题思路

设展牌字符串中大写字母的个数为 $cnt$。

每次校准只能把一个字符在大小写之间切换：

* 把一个小写字母变成大写，大写个数 $+1$
* 把一个大写字母变成小写，大写个数 $-1$

题目要求恰好进行 $k$ 次校准，并让最终大写字母个数尽可能多。应优先把小写变成大写。设小写字母个数为

$$
low=n-cnt
$$

分情况讨论：

若 $k \le low$，这 $k$ 次都可以用来把小写变成大写，答案为 $cnt+k$。

若 $k > low$，先把所有小写都变成大写，此时字符串已全部为大写，用掉 $low$ 次，大写个数为 $n$。还剩下

$$
rem = k-low
$$

次校准。字符串里已经没有小写，只能对某个大写继续切换：一次把大写变成小写，再一次又变回大写。多出来的两次可以互相抵消。

因此看 $rem$ 的奇偶性：

* $rem$ 为偶数，最终仍可全部为大写，答案为 $n$
* $rem$ 为奇数，最终必然有一个字符为小写，答案为 $n-1$

实现步骤：遍历统计初始大写个数 $cnt$，计算 $low=n-cnt$；若 $k \le low$ 输出 $cnt+k$，否则按 $rem$ 奇偶输出 $n$ 或 $n-1$。

## 复杂度分析

遍历一次字符串即可，其余为常数时间操作。

时间复杂度 $O(n)$，空间复杂度 $O(1)$。

## 代码实现

### Python

```python
def max_uppercase_count(n, k, s):
    # 统计初始大写字母个数
    cnt = 0
    for ch in s:
        if 'A' <= ch <= 'Z':
            cnt += 1

    # 计算小写字母个数
    low = n - cnt

    # 校准次数不超过小写个数时，全部用来变大写
    if k <= low:
        return cnt + k

    # 全部变大写后还剩余 rem 次校准
    rem = k - low

    # 剩余次数为偶数，可以两两抵消，最终仍全部为大写
    if rem % 2 == 0:
        return n

    # 剩余次数为奇数，最终必然有一个字母为小写
    return n - 1


def main():
    n, k = map(int, input().split())
    s = input().strip()
    print(max_uppercase_count(n, k, s))


if __name__ == "__main__":
    main()
```

### Java

```java
import java.util.Scanner;

public class Main {

    public static int maxUppercaseCount(int n, long k, String s) {
        int cnt = 0;
        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch >= 'A' && ch <= 'Z') {
                cnt++;
            }
        }

        int low = n - cnt;

        if (k <= low) {
            return cnt + (int) k;
        }

        long rem = k - low;

        if (rem % 2 == 0) {
            return n;
        }

        return n - 1;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long k = sc.nextLong();
        String s = sc.next();
        System.out.println(maxUppercaseCount(n, k, s));
    }
}
```

#include <iostream>
#include <string>
using namespace std;

int maxUppercaseCount(int n, long long k, const string& s) {
    int cnt = 0;
    for (char ch : s) {
        if (ch >= 'A' && ch <= 'Z') {
            cnt++;
        }
    }

    int low = n - cnt;

    if (k <= low) {
        return cnt + (int)k;
    }

    long long rem = k - low;

    if (rem % 2 == 0) {
        return n;
    }

    return n - 1;
}

int main() {
    int n;
    long long k;
    cin >> n >> k;
    string s;
    cin >> s;
    cout << maxUppercaseCount(n, k, s) << endl;
    return 0;
}
