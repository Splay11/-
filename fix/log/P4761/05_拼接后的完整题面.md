# 题目内容
一块展牌上写着长度为 $n$ 的字符串 $s$，其中每个字符都是英文字母，大小写可以混用。一次校准可以把某一个字符在大写与小写之间切换，例如把 `a` 变成 `A`，或把 `Y` 变成 `y`。

要求恰好进行 $k$ 次校准，并使最终字符串中大写字母的个数尽可能多。请给出这个最大个数。

约束：字符串长度不超过 `10^5`，校准次数不超过 `10^9`。

# 输入描述
第一行包含两个整数 $n$ 和 $k$，分别表示字符串长度与必须执行的校准次数。保证 $1 \le n \le 10^5$，$1 \le k \le 10^9$。
第二行包含一个长度为 $n$ 的字符串 $s$，仅由大小写英文字母组成。

# 输出描述
输出一个整数，表示恰好进行 $k$ 次校准后，字符串中大写字母个数的最大值。

## 样例1

**输入**

```
3 5
ABC
```

**输出**

```
2
```

**说明**

初始已全部大写，小写个数为 `0`。
必须做满 `5` 次校准，剩余次数为奇数，最终会留下一个小写字母，答案为 $3-1=2$。

## 样例2

**输入**

```
1 1
a
```

**输出**

```
1
```

**说明**

只有一个小写字母 `a`，恰好校准 `1` 次，把它变成 `A`。
这是 $n=1$ 的边界情形，答案为 `1`。

## 样例3

**输入**

```
4 6
ABC
```

**输出**

```
3
```

**说明**

按题意模拟计算得到。
