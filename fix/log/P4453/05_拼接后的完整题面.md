# 题目内容
仓库有 $n$ 个连续货道。调度员给出数组 $a$，要求你只用小写英文字母给每个货道打上批次标记，得到字符串 $s$。规则如下：对每个位置 $i$（$1 \le i \le n$），若 $a_i=0$，则 $s_i$ 必须是一个在更早货道 $[1,i-1]$ 中从未出现过的新字母；若 $a_i>0$，则 $1 \le a_i < i$，且 $s_i=s_{a_i}$，并且对所有 $a_i < j < i$ 都有 $s_j 
e s_{a_i}$，也就是 $a_i$ 恰好是该字母上一次出现的位置。输入保证合法，且构造所需不同字母个数不超过 `26`。请输出任意一个满足条件的字符串。

约束：货道数不超过 `200000`，且 $0 \le a_i < i$。

# 输入描述
第一行一个整数 $n$，表示货道个数。
第二行 $n$ 个整数 $a_1,a_2,\ldots,a_n$。
保证 $1 \le n \le 200000$，$0 \le a_i < i$，且存在仅由小写英文字母构成的解。

# 输出描述
输出一行长度为 $n$ 的字符串 $s$。若有多个合法解，输出任意一个即可。

## 样例1

**输入**

```
6
0 1 0 3 2 5
```

**输出**

```
aabbaa
```

**说明**

从左到右：$a_i=`0`$ 时依次分配新字母 `a`,`b`，否则继承 $s_{a_i}$。得到 `aabbaa`。

## 样例2

**输入**

```
4
0 0 0 1
```

**输出**

```
abca
```

**说明**

三个链头各分配 `a`,`b`,`c`，最后一位继承位置 `1` 的 `a`，得到 `abca`。

## 样例3

**输入**

```
1
0
```

**输出**

```
a
```

**说明**

只有一个位置且 $a_1=`0`$，输出 `a`。

## 样例4

**输入**

```
7
0 0 2 1 4 3 0
```

**输出**

```
abbaabc
```

**说明**

链头依次分配 `a`,`b`，再继承前驱，最后再开新字母 `c`，得到 `abbaabc`。
