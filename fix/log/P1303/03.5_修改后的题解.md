## 解题思路

两数之和为偶数当且仅当它们奇偶性相同，即左半段末位与整个数末位同奇偶。枚举切开点（不切开最后一位），统计与末位同奇偶的前缀末位个数。

## 复杂度分析

时间复杂度 $O(|s|)$，空间复杂度 $O(|s|)$。

## 代码实现

### Python

```python
s=input().strip()
b=(ord(s[-1])-48)%2
print(sum(1 for i in range(len(s)-1) if (ord(s[i])-48)%2==b))
```

### Java

```java
import java.util.*;
public class Main {
    public static void main(String[] args) {
        String s = new Scanner(System.in).next();
        int b = (s.charAt(s.length()-1) - '0') % 2, ans = 0;
        for (int i = 0; i < s.length() - 1; i++)
            if ((s.charAt(i) - '0') % 2 == b) ans++;
        System.out.println(ans);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string n; cin >> n;
    int b = (n.back() - '0') % 2, ans = 0;
    for (int i = 0; i + 1 < (int)n.size(); i++)
        if ((n[i] - '0') % 2 == b) ans++;
    cout << ans << '\n';
}
```
