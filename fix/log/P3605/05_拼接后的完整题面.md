# 题目内容
厂区有 $n$ 个规格相同、容积视为无穷的油箱。第 $i$ 个油箱的连通标记为 $g_i$：标记相同的油箱底部互通，油会在组内均分，因此同一组内每个油箱的油量始终相等。初始时全部为空。

共有 $m$ 次操作，操作类型为以下三种之一：
- 类型 `1`：向第 $a$ 个油箱注入 $b$ 毫升油；
- 类型 `2`：从第 $a$ 个油箱所在连通组抽出 $b$ 毫升油，保证该组当前总量至少为 $b$ 毫升；
- 类型 `3`：查询第 $a$ 个油箱当前有多少毫升油。

约束：油箱个数与操作次数均不超过 `10^5`，连通标记不超过油箱个数，注入或抽出的毫升数不超过 `10^4`。保证至少有一次查询。

# 输入描述
第一行两个整数 $n$ 和 $m$，分别表示油箱个数与操作次数。
第二行 $n$ 个整数 $g_1,g_2,\ldots,g_n$，表示各油箱的连通标记。
接下来 $m$ 行，每行先是一个整数 $o$（$1 \le o \le 3$），表示操作类型：
- 若 $o=1$，再给出两个整数 $a$、$b$，表示向第 $a$ 个油箱注入 $b$ 毫升；
- 若 $o=2$，再给出两个整数 $a$、$b$，表示从第 $a$ 个油箱所在连通组抽出 $b$ 毫升；
- 若 $o=3$，再给出一个整数 $a$，表示查询第 $a$ 个油箱。
保证 $1 \le n,m \le 10^5$，$1 \le g_i \le n$，$1 \le a \le n$，$1 \le b \le 10^4$，且至少有一次查询。

# 输出描述
对每个类型为 `3` 的操作，新起一行输出一个实数，表示该油箱当前油量。设你的答案为 $a$、标准答案为 $b$，当 $\dfrac{|a-b|}{\max(1,|b|)} \le 10^{-5}$ 时视为正确。

## 样例1

**输入**

```
3 4
1 1 1
1 2 9
3 1
2 3 3
3 2
```

**输出**

```
3.000000
2.000000
```

**说明**

三个油箱同一组。注入 `9` 毫升后各箱 `3` 毫升。
抽出 `3` 毫升后总量为 `6`，各箱 `2` 毫升。

## 样例2

**输入**

```
1 2
1
1 1 4
3 1
```

**输出**

```
4.000000
```

**说明**

只有一个油箱。注入 `4` 毫升后查询，结果为 `4`。这是 $n=1$ 的边界情形。

## 样例3

**输入**

```
3 4
1 1 1
1 2 9
3 1
2 3 3
4 3
```

**输出**

```
3.000000
2.000000
```

**说明**

按题意模拟计算得到。
