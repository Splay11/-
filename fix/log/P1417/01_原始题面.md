# 题目描述

时间，不在于你拥有多少，而在于你怎样使用。

由于工作太多，塔子哥最近常常加班。塔子哥现在有一张工作安排表，里面有 $N$ 件需要完成的工作的内容，他做完表上的所有工作就能下班了。塔子哥估计自己能在三小时内全部完成工作，且每件工作可以编号为$1~N$，完成时间为$M_1,M_2,…, M_n$分钟。

但是由于长时间的加班，塔子哥再工作一个小时就必须休息后才能继续工作两小时。且每项工作必须连续完成，在做完前不能做其它工作或者休息。

你能计算出塔子哥有多少种三小时（休息之前一小时加休息之后两小时）完成所有工作的方案吗？

# 输入描述

第一行输入一个正整数 $N$， 表示塔子哥需要完成的工作数量。

第二行输入$N$个正整数, 分别为$M_1,M_2,…, M_n$, 表示每个展品参观的时间，且这 $M_1+M_2+…+M_n=180$.

# 输出描述

输出所有合法方案的数量。合法方案指满足休息之前的工作总时间等于1小时、休息之后的工作总时间等于2小时的方案(正整数)， 若没有任何方案或者输入不合法，则输出0。

# 样例

**样例输入**

```
3
60 60 60
```

**样例输出**

```
6
```
