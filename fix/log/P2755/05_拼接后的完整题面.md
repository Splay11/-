# 题目内容
给定一个仅由字符 `'e'`、`'l'`、`'m'` 组成的字符串 $s$。如果一个字符串中不存在连续子串 `'ee'`、`'lm'`、`'ml'`、`'ll'`、`'mm'`，则称它是节律串。

请判断能否将 $s$ 重新排列成一个节律串。若可以，输出任意一种合法重排；否则输出 `No`。

字符串长度不超过 $10^5$。

# 输入描述
输入一行，包含一个长度不超过 $10^5$ 的字符串 $s$，仅由字符 `'e'`、`'l'`、`'m'` 组成。

# 输出描述
若可以将 $s$ 重排为节律串，输出重排后的字符串；否则输出 `No`。若存在多种合法重排，输出任意一种即可。

## 样例1

**输入**

```
eeelm
```

**输出**

```
eleme
```

**说明**

字符串长度为 `5`，含 `3` 个 `'e'`、`1` 个 `'l'`、`1` 个 `'m'`。`'e'` 的个数等于 $\lceil 5/2 \rceil$，可按以 `'e'` 开头的交替模式重排为 `eleme`，其中不出现禁止子串，是合法节律串。

## 样例2

**输入**

```
eeelme
```

**输出**

```
No
```

**说明**

长度为 `6`，含 `4` 个 `'e'` 与 `2` 个非 `'e'`。交替模式需要 `'e'` 的个数为 `3` 或 `3`，与 `4` 不符，无法重排，输出 `No`。

## 样例3

**输入**

```
e
```

**输出**

```
e
```

**说明**

单个字符 `'e'` 不含任何禁止子串，本身即为节律串，输出 `e`。

## 样例4

**输入**

```
lme
```

**输出**

```
lem
```

**说明**

长度为 `3`，含 `1` 个 `'e'` 与 `2` 个非 `'e'`，匹配以非 `'e'` 开头的模式。按先填 `'l'` 再填 `'m'` 得到 `lem`，相邻关系为 `'l'`/`'e'`/`'m'`，合法。
