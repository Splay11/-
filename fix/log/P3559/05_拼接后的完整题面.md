# 题目内容
有一个由 $n \times n$ 个单元格构成的壁画，每个单元格可以涂上金色、银色或铜色中的一种，因此共有 $3^{n \times n}$ 种不同的涂色方案。

壁画的格点用 $(i,j)$ 表示，其中 $i$ 为从上到下的格线编号，$j$ 为从左到右的格线编号，编号从 $0$ 开始。一位画家从左上角的格点 $(0,0)$ 出发，每次可以沿着竖线向下移动一格到 $(i+1,j)$，或者沿着横线向右移动一格到 $(i,j+1)$，最终到达右下角的格点 $(n,n)$。画家走过的路径将壁画上的单元格分成两个区域：路径左下方的区域（由 $(0,0), (n,0), (n,n)$ 与路径围成）和右上方的区域（由 $(0,0), (0,n), (n,n)$ 与路径围成）。

如果一条路径满足：其左下方区域中不包含任何金色单元格，且右上方区域中不包含任何银色单元格，则称这条路径是「优美的」。若对于一种涂色方案，存在至少一条优美的路径，则称该涂色方案是「有效的」。

请计算在所有 $3^{n \times n}$ 种涂色方案中，有效涂色方案的数量。由于答案可能很大，请输出它对 $998244353$ 取模后的结果。

约束：$n$ 是一个整数，满足 $1 \le n \le 5000$。

# 输入描述
输入共一行，包含一个整数 $n$，表示壁画网格的边长（即网格包含 $n \times n$ 个单元格）。

# 输出描述
输出一个整数，表示有效涂色方案数对 $998244353$ 取模后的结果。

## 样例1

**输入**

```
1
```

**输出**

```
3
```

**说明**

当 $n=1$ 时，壁画只有 $1$ 个单元格，共有 $3^1 = 3$ 种涂色方案。无论该单元格涂成金色、银色还是铜色，都存在优美的路径（例如从 $(0,0)$ 先向下再向右，或先向右再向下），因此全部 `3` 种方案均有效。

## 样例2

**输入**

```
2
```

**输出**

```
52
```

**说明**

当 $n=2$ 时，网格包含 $4$ 个单元格，总涂色方案数为 $3^4 = 81$。条件“左下方无金、右上方无银”等价于不存在一个金色格子位于银色格子的左上方。通过容斥原理可求得违反条件的方案有 $29$ 种，因此有效方案数为 $81 - 29 = 52$。故输出 `52`。

## 样例3

**输入**

```
3
```

**输出**

```
4032
```

**说明**

当 $n=3$ 时，网格共 $9$ 个单元格，总方案数为 $3^9 = 19683$。该问题可转化为统计所有从 $(0,3)$ 到 $(3,0)$ 的单调路径中「东南拐角」的个数分布，进而通过组合求和得到有效方案数为 $4032$。对 $998244353$ 取模后仍为 `4032`。
