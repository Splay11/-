## 解题思路

本题要求在满足给定约束的前提下，统计将所有 `-1` 替换为 `0` 或 `1` 的方案数。约束条件可以等价转化为：

- 在任意长度为 $k$ 的连续子数组中，值为 `0` 的元素个数不超过 $1$。
- 这等价于：最终序列中任意两个 `0` 的位置之差至少为 $k$。

因此问题变为：在固定某些位置必须为 `0` 或 `1` 的前提下，将剩余位置（`-1`）填入 `0` 或 `1`，使得所有 `0` 的位置两两距离不小于 $k$。求方案数对 $10^9+7$ 取模。

### 动态规划设计

设 $dp[i]$ 表示考虑前 $i$ 个位置（$a_1$ 到 $a_i$），且满足所有约束的填充方案数。初始化 $dp[0] = 1$（空前缀只有一种方案）。

对于第 $i$ 个位置（$1 \le i \le n$），根据 $a_i$ 的值有两种可能的填法：

1. **第 $i$ 个位置填 `1`**  
   只要原序列中该位置不是固定的 `0`（$a_i \neq 0$），就可以填 `1`。此时前 $i-1$ 个位置的方案完全继承，转移为：
   $$dp[i] \leftarrow dp[i] + dp[i-1]$$

2. **第 $i$ 个位置填 `0`**  
   只要原序列中该位置不是固定的 `1`（$a_i \neq 1$），就可以填 `0`。若第 $i$ 个位置填 `0`，则根据距离约束，区间 $[i-k+1,\, i-1]$ 内的所有位置都必须填 `1`。设
   $$s = \max(1, \, i-k+1)$$
   则区间 $[s,\, i-1]$ 必须全为 `1`。为了保证这是合法的，区间 $[s,\, i-1]$ 中不能有题目已经固定为 `0` 的位置。  
   若该区间内没有已知的 `0`，则前 $s-1$ 个位置的任意合法方案都可以和这段强制全 `1` 的区间拼接，并在第 $i$ 位放 `0`，因此转移为：
   $$dp[i] \leftarrow dp[i] + dp[s-1]$$

所有加法均在模 $10^9+7$ 意义下进行，最后 $dp[n]$ 即为答案。

### 快速判断区间内是否存在已知的 `0`

预处理前缀数组 $pre0$，其中 $pre0[i]$ 表示前 $i$ 个位置中已经固定为 `0` 的数量，即：
$$pre0[i] = pre0[i-1] + [a_i = 0]$$

对于任意区间 $[l, r]$，其中已知 `0` 的个数可以在 $O(1)$ 时间内计算：
$$cnt = pre0[r] - pre0[l-1]$$

因此判断 $[s,\, i-1]$ 内是否存在已知 `0` 只需检查 $pre0[i-1] - pre0[s-1] = 0$ 是否成立。

## 复杂度分析

对于每组数据，序列长度为 $n$。

- 预处理前缀数组 $pre0$ 需要 $O(n)$ 时间；
- 动态规划的每个状态 $dp[i]$ 只进行常数次运算，总时间复杂度 $O(n)$；
- 总空间复杂度为 $O(n)$。

由于所有测试数据的 $n$ 总和不超过 $5\times 10^5$，该算法可以高效运行。

## 代码实现

### Python

```python
import sys

MOD = 10**9 + 7

def solve_one(n, k, a):
    # pre0[i] : 前 i 个位置中已知的 0 的个数
    pre0 = [0] * (n + 1)
    for i in range(1, n + 1):
        pre0[i] = pre0[i - 1] + (1 if a[i - 1] == 0 else 0)
    
    dp = [0] * (n + 1)
    dp[0] = 1
    
    for i in range(1, n + 1):
        # 情况 1：第 i 个位置填 1
        if a[i - 1] != 0:
            dp[i] = (dp[i] + dp[i - 1]) % MOD
        
        # 情况 2：第 i 个位置填 0
        if a[i - 1] != 1:
            s = max(1, i - k + 1)
            # 检查区间 [s, i-1] 中是否有已知的 0
            if pre0[i - 1] - pre0[s - 1] == 0:
                dp[i] = (dp[i] + dp[s - 1]) % MOD
    
    return dp[n]

def main():
    input_data = sys.stdin.read().strip().split()
    it = iter(input_data)
    T = int(next(it))
    out_lines = []
    for _ in range(T):
        n = int(next(it))
        k = int(next(it))
        a = [int(next(it)) for _ in range(n)]
        out_lines.append(str(solve_one(n, k, a)))
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    static final long MOD = 1000000007L;

    static long solveOne(int n, int k, int[] a) {
        // pre0[i] : 前 i 个位置中已知的 0 的个数
        int[] pre0 = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            pre0[i] = pre0[i - 1] + (a[i] == 0 ? 1 : 0);
        }
        
        long[] dp = new long[n + 1];
        dp[0] = 1;
        
        for (int i = 1; i <= n; i++) {
            // 情况 1：第 i 个位置填 1
            if (a[i] != 0) {
                dp[i] = (dp[i] + dp[i - 1]) % MOD;
            }
            // 情况 2：第 i 个位置填 0
            if (a[i] != 1) {
                int s = Math.max(1, i - k + 1);
                if (pre0[i - 1] - pre0[s - 1] == 0) {
                    dp[i] = (dp[i] + dp[s - 1]) % MOD;
                }
            }
        }
        return dp[n];
    }
    
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder output = new StringBuilder();
        int T = Integer.parseInt(br.readLine().trim());
        while (T-- > 0) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int n = Integer.parseInt(st.nextToken());
            int k = Integer.parseInt(st.nextToken());
            int[] a = new int[n + 1]; // 1-indexed
            st = new StringTokenizer(br.readLine());
            for (int i = 1; i <= n; i++) {
                a[i] = Integer.parseInt(st.nextToken());
            }
            output.append(solveOne(n, k, a)).append('\n');
        }
        System.out.print(output);
    }
}
```
