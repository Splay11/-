# 题目内容
你正在分析一个长度为 $n$ 的基因表达序列 $x_1, x_2, \dots, x_n$，该序列是非降的：$x_1 \le x_2 \le \dots \le x_n$。你可以至多执行一次“逆梯度扰动”操作：选择一个连续子序列 $[l, r]$（$1 \le l \le r \le n$），并对每个位置 $i$（$l \le i \le r$）将 $x_i$ 增加 $v \times (r - i + 1)$，其中 $v$ 为给定正整数。换言之，子序列最右侧元素增加 $v$，向左每一步递增 $v$，最左侧增加 $(r-l+1)v$。

操作完成后，若存在某个相邻位置 $j$（$1 \le j < n$）满足 $|x_j - x_{j+1}| > C$，则称引发了“异常”。你希望使用尽可能短的子序列来引发异常。特别地，如果初始序列已经存在这样的相邻位置，你可以选择不进行任何操作（子序列长度视为 `0`）。如果所有可能的子序列都无法引发异常，请判定为不可能。

请你计算所需的最短子序列长度；若不可能，输出 `-1`。

约束：
- 序列长度 $n$ 满足 $2 \le n \le 2 \times 10^5$，且单个测试文件中所有 $n$ 的总和不超过 $2 \times 10^5$。
- 阈值 $C$ 满足 $0 \le C \le 10^{12}$。
- 基本增量 $v$ 满足 $1 \le v \le 10^9$。
- 每个表达值 $x_i$ 满足 $1 \le x_i \le 10^9$。

# 输入描述
输入共包含多组测试数据。第一行一个整数 $T$ ($1 \le T \le 10^4$)，表示数据组数。之后每组数据按以下格式给出：
第一行包含三个整数 $n, C, v$，分别表示序列长度、异常阈值和基本增量，满足 $2 \le n \le 2 \times 10^5$，$0 \le C \le 10^{12}$，$1 \le v \le 10^9$。
第二行包含 $n$ 个整数 $x_1, x_2, \dots, x_n$ ($1 \le x_i \le 10^9$)，表示初始表达值，保证序列非降。
保证所有测试数据的 $n$ 之和不超过 $2 \times 10^5$。

# 输出描述
对于每组测试数据，输出一行一个整数，表示所需的最短子序列长度（可为 `0`）；若无法引发异常，输出 `-1`。

## 样例1

**输入**

```
1
4 5 2
1 2 8 9
```

**输出**

```
0
```

**说明**

初始序列为 $[1, 2, 8, 9]$。相邻差值分别为 $1$, $6$, $1$。其中 $|x_2 - x_3| = 6 > C = 5$，已存在异常，因此不需要执行任何操作，最短子序列长度为 `0`。

## 样例2

**输入**

```
1
2 100 1
1 2
```

**输出**

```
-1
```

**说明**

序列长度 $n=2$，阈值 $C=100$，增量 $v=1$。初始差值 $1$ 未超过 $C$。
可选操作：
- 不操作：长度为 `0`，但无法引发异常。
- 操作子序列 $[1,1]$：$x_1$ 增加 $1$，序列变为 $[2,2]$，相邻差值为 $0$。
- 操作子序列 $[2,2]$：$x_2$ 增加 $1$，序列变为 $[1,3]$，相邻差值为 $2$。
- 操作子序列 $[1,2]$：$x_1$ 增加 $2 \times 1 = 2$，$x_2$ 增加 $1$，序列变为 $[3,3]$，相邻差值为 $0$。
所有可能的操作产生的最大相邻差值均不超过 $100$，因此无法引发异常，输出 `-1`。

## 样例3

**输入**

```
1
4 3 2
1 2 4 5
```

**输出**

```
1
```

**说明**

序列为 $[1, 2, 4, 5]$，$C=3$，$v=2$。初始相邻差值分别为 $1, 2, 1$，均 $\le 3$，无异常。
考虑长度为 `1` 的操作：选择 $[3,3]$，将 $x_3$ 增加 $2 \times (3 - 3 + 1) = 2$，变为 $6$。序列变为 $[1, 2, 6, 5]$。此时 $|x_2 - x_3| = |2 - 6| = 4 > 3$，引发异常。因此最短子序列长度为 `1`。

## 样例4

**输入**

```
1
4 5 4
10 10 10 10
```

**输出**

```
2
```

**说明**

序列全为 $10$，$C=5$，$v=4$。初始所有相邻差值为 $0$，无异常。
尝试长度为 `1` 的操作：选择任意单个元素 $[i,i]$，将其增加 $4$，新序列中该元素与相邻元素的差值为 $4 \le 5$，无法引发异常。
尝试长度为 `2` 的操作：选择子序列 $[2,3]$。此时 $l=2, r=3$。
- $x_2$ 增加 $v \times (3 - 2 + 1) = 4 \times 2 = 8$，变为 $18$。
- $x_3$ 增加 $v \times (3 - 3 + 1) = 4 \times 1 = 4$，变为 $14$。
序列变为 $[10, 18, 14, 10]$。相邻差值分别为 $|10-18|=8$（$>5$），$|18-14|=4$，$|14-10|=4$。引发异常，故最短子序列长度为 `2`。
