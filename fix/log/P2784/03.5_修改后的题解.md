## 解题思路

1. **问题转化**  
   计算 $n \times 2^k$ 并在二进制下输出。由于乘以 $2^k$ 在二进制中相当于将 $n$ 的二进制表示左移 $k$ 位，即在二进制字符串末尾拼接 $k$ 个 `0`。因此核心任务是将十进制大整数 $n$ 转换为二进制字符串。

2. **十进制大整数转二进制**  
   - **Python / Java**：利用语言内置的大整数支持，直接调用 `bin(n)` 或 `BigInteger.toString(2)` 得到二进制字符串，并去除前缀 `0b`（Python）。  
   - **C++**：采用**模拟手动除法**的方法，对存储十进制数字的字符串不断进行 `除以2` 操作，每次记录余数，余数序列的倒序即为二进制表示。  
     - 当数字降为 `"0"` 时停止循环；若初始 $n=0$，直接返回 `"0"`。

3. **拼接 $k$ 个零**  
   在得到的二进制字符串末尾追加 $k$ 个字符 `'0'`，即完成 $n \times 2^k$ 的二进制表示。

4. **边界与细节**  
   - $n$ 可以是 `0`，此时二进制结果为 `"0"`，拼接 $k$ 个零后变为由 `1` 个 `0` 和 $k$ 个 `0` 组成的长度 $k+1$ 的字符串，无前导零问题。  
   - 输入保证 $n$ 的十进制长度不超过 $5000$，$k \le 10^5$，所有操作均在合理范围内。

## 复杂度分析

- **时间复杂度**  
  将十进制字符串转换为二进制需要不断进行大数除2操作。十进制长度 $L \le 5000$，二进制位数 $B \approx L \cdot \log_2 10 \le 5000 \times 3.33 \approx 16650$。每次除法需要遍历当前数字的所有数位，总操作次数级约为 $O(L \cdot B)$。追加 $k$ 个字符需要 $O(k)$ 时间。综合时间复杂度为 $O(L \cdot B + k)$，对于本题数据完全可行。

- **空间复杂度**  
  需要存储转换后的二进制字符串，长度为 $B + k$，因此空间复杂度为 $O(B + k)$。

## 代码实现

### Python

```python
import sys

def main():
    # 读取输入
    data = sys.stdin.read().strip().split()
    if not data:
        return
    n_str, k_str = data[0], data[1]
    n = int(n_str)       # Python 内置大整数
    k = int(k_str)
    
    # 转换为二进制字符串（去掉 '0b' 前缀）
    binary_n = bin(n)[2:]
    
    # 乘以 2^k 即追加 k 个 '0'
    result = binary_n + "0" * k
    
    print(result)

if __name__ == "__main__":
    main()
```

### Java

```java
import java.math.BigInteger;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String nStr = sc.next();
        int k = sc.nextInt();
        sc.close();
        
        // 使用 BigInteger 处理大整数
        BigInteger n = new BigInteger(nStr);
        
        // 转换为二进制字符串
        String binaryN = n.toString(2);
        
        // 追加 k 个 '0'
        StringBuilder result = new StringBuilder(binaryN);
        for (int i = 0; i < k; i++) {
            result.append('0');
        }
        
        System.out.println(result.toString());
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

// 将十进制字符串大数转换为二进制字符串
string decToBinary(string n) {
    if (n == "0") return "0";
    string binary = "";
    while (n != "0") {
        int carry = 0;
        string temp;
        // 逐位除以2
        for (char c : n) {
            int cur = carry * 10 + (c - '0');
            temp.push_back((cur / 2) + '0');
            carry = cur % 2;
        }
        // 当前余数即为二进制的一位
        binary.push_back(carry + '0');
        // 去除前导零
        size_t pos = temp.find_first_not_of('0');
        n = (pos == string::npos) ? "0" : temp.substr(pos);
    }
    // 倒序得到正确的二进制表示
    reverse(binary.begin(), binary.end());
    return binary;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    string n;
    int k;
    cin >> n >> k;
    
    string binaryN = decToBinary(n);
    // 乘以 2^k 等价于末尾追加 k 个 '0'
    binaryN.append(k, '0');
    
    cout << binaryN << "\n";
    return 0;
}
```
