# 题目内容
在星际观测任务中，科学家们记录了一个巨大的能量读数，并用十进制整数 $n$ 表示。为了向地面控制中心发送数据，需要先将该读数放大 $2^k$ 倍，再转换为二进制格式进行传输。请你帮助科学家完成这一计算。

$n$ 的十进制表示长度不超过 `5000`，$k$ 是一个整数，满足 $0 \le k \le 10^5$。

# 输入描述
输入只有一行，包含两个用空格分隔的整数，分别是十进制大整数 $n$ 和指数 $k$。

# 输出描述
输出一行一个二进制字符串，表示 $n \times 2^k$ 的结果，不应包含多余的前导零。

## 样例1

**输入**

```
0 5
```

**输出**

```
0
```

**说明**

当 $n = 0$ 时，无论 $k$ 取何值，$n \times 2^k = 0$，二进制表示为 `0`。
本例中 $k = 5$，结果仍为 `0`。

## 样例2

**输入**

```
1 10
```

**输出**

```
10000000000
```

**说明**

`1` 的二进制表示为 `1`。
乘以 $2^{10}$ 相当于在二进制末尾添加 `10` 个零，得到 `10000000000`。

## 样例3

**输入**

```
13 0
```

**输出**

```
1101
```

**说明**

`13` 的二进制为 `1101`。
当 $k = 0$ 时，$2^0 = 1$，$13 \times 1 = 13$，因此结果二进制仍然是 `1101`。
