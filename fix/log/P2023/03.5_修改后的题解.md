## 解题思路

题中的两种操作，本质就是辗转相减法：每次用较大的数减去较小的数（写成 $(a,b-a)$ 或先交换再减）。反复操作后，两个数都会变成它们的最大公约数 $\gcd(a,b)$，此时偏差 $|a-b|=0$。

因此 $n$ 个数对操作到最后，最小偏差之和恒为 $0$。问题转化为：每个数对最少多少步才能变成 $(\gcd,\gcd)$。

直接模拟减法在 $a$ 远大于 $b$ 时太慢，改用取模加速：

- 若 $a<b$，先交换；
- 若 $b$ 整除 $a$，还需要 $a/b-1$ 次减法把 $a$ 减到与 $b$ 相等；
- 否则做 $a/b$ 次减法，令 $a\leftarrow a\bmod b$，继续循环。

对每个数对累加步数即可。

## 复杂度分析

每个数对的步数与欧几里得算法相当，时间复杂度 $O(n\log A)$，其中 $A$ 为数对分量的上界。空间复杂度 $O(1)$。

## 代码实现

### Python

```python
n = int(input())
sum_val = 0
cnt = 0

for _ in range(n):
    a, b = map(int, input().split())
    while a != b:
        if a < b:
            a, b = b, a
        if a % b == 0:
            cnt += a // b - 1
            a = b
        else:
            cnt += a // b
            a %= b

print(sum_val)
print(cnt)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long sumVal = 0;
        long cnt = 0;
        for (int i = 0; i < n; i++) {
            int a = sc.nextInt();
            int b = sc.nextInt();
            while (a != b) {
                if (a < b) {
                    int temp = a;
                    a = b;
                    b = temp;
                }
                if (a % b == 0) {
                    cnt += a / b - 1;
                    a = b;
                } else {
                    cnt += a / b;
                    a %= b;
                }
            }
        }
        System.out.println(sumVal);
        System.out.println(cnt);
    }
}
```

### C++

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long sum_val = 0, cnt = 0;
    while (n-- > 0) {
        int a, b;
        cin >> a >> b;
        while (a != b) {
            if (a < b) swap(a, b);
            if (a % b == 0) {
                cnt += a / b - 1;
                a = b;
            } else {
                cnt += a / b;
                a %= b;
            }
        }
    }
    cout << sum_val << '\n' << cnt << '\n';
    return 0;
}
```
