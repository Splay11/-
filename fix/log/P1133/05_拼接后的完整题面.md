# 题目内容
货仓里摆着 $n$ 件物品，第 $i$ 件的货值为 $a_i$，并贴有一个标签。标签只可能是字符 `R` 或字符 `B`。
一次合法配对是指选出两件标签恰好为一 `R` 一 `B` 的物品，该配对的收益等于两件货值的乘积。
请计算所有合法配对的收益之和。答案可能很大，需要对 $10^9+7$ 取模。

约束条件：
- 物品数量 $n$ 为正整数，且不超过 $10^5$。
- 每个货值 $a_i$ 为正整数，且不超过 $10^9$。
- 标签字符串长度为 $n$，仅由字符 `R` 和 `B` 组成。

# 输入描述
第一行包含一个正整数 $n$，表示物品的数量。
第二行包含 $n$ 个正整数 $a_1, a_2, \ldots, a_n$，表示每件物品的货值。
第三行包含一个长度为 $n$ 的字符串，仅由字符 `R` 和 `B` 组成，第 $i$ 个字符表示第 $i$ 件物品的标签。

# 输出描述
输出一个整数，表示所有合法配对的收益之和对 $10^9+7$ 取模后的结果。

## 样例1

**输入**

```
5
1 5 3 2 4
RBBRR
```

**输出**

```
56
```

**说明**

标签为 `R` 的货值为 `1`、`2`、`4`，和为 $7$；标签为 `B` 的货值为 `5`、`3$，和为 $8$。
所有一 `R` 一 `B` 配对的收益之和等于两组货值和的乘积：$7 \times 8 = 56$。
对 $10^9+7$ 取模后仍为 `56`。

## 样例2

**输入**

```
3
1 2 3
RRR
```

**输出**

```
0
```

**说明**

三件物品的标签都是 `R`，不存在标签为 `B` 的物品。
合法配对个数为 `0`，收益之和为 `0`。

## 样例3

**输入**

```
2
10 20
RB
```

**输出**

```
200
```

**说明**

第一件标签为 `R`、货值 `10`，第二件标签为 `B`、货值 `20`。
只有一种配对，收益为 $10 \times 20 = 200$。

## 样例4

**输入**

```
1
7
B
```

**输出**

```
0
```

**说明**

只有一件标签为 `B` 的物品，无法组成一 `R` 一 `B` 的配对，答案为 `0`。
