## 解题思路

一次合法配对必须选出一件标签为 `R` 的物品和一件标签为 `B` 的物品，收益为两者货值之积。所有配对收益之和等于：

\[
\Bigl(\sum_{s_i=\texttt{R}} a_i\Bigr) \times \Bigl(\sum_{s_i=\texttt{B}} a_i\Bigr)
\]

因此只需扫一遍数组，分别累加两类标签的货值和，相乘后对 $10^9+7$ 取模。累加过程中先各自对模数取模，避免中间结果过大。

## 复杂度分析

时间复杂度 $O(n)$，空间复杂度 $O(n)$。

## 代码实现

### Python

```python
n = int(input())
a = list(map(int, input().split()))
s = input().strip()
x = 0
y = 0
for i in range(n):
    if s[i] == 'R':
        x += a[i]
    else:
        y += a[i]
mod = 1000000007
x %= mod
y %= mod
print(x * y % mod)
```

### Java

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        long[] a = new long[n];
        for (int i = 0; i < n; i++) {
            a[i] = in.nextLong();
        }
        String s = in.next();
        long x = 0, y = 0;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == 'R') {
                x += a[i];
            } else {
                y += a[i];
            }
        }
        final long MOD = 1000000007L;
        x %= MOD;
        y %= MOD;
        System.out.println(x * y % MOD);
    }
}
```

### C++

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    string s;
    cin >> s;
    long long x = 0, y = 0;
    for (int i = 0; i < n; i++) {
        if (s[i] == 'R') x += a[i];
        else y += a[i];
    }
    const long long MOD = 1000000007LL;
    x %= MOD;
    y %= MOD;
    cout << x * y % MOD << endl;
    return 0;
}
```
