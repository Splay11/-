# 题目内容
给定一个 $n \times n$ 的网格，每个格子中有一个正整数。你可以进行任意次操作：每次选择一个格子，将其数值增加 `1`。目标是使网格满足“四次旋转对称”性质：将网格顺时针旋转 $0^\circ$、$90^\circ$、$180^\circ$、$270^\circ$ 后，得到的网格完全相同。请问最少需要进行多少次操作？

约束条件：网格的行数和列数 $n$ 满足 $1 \le n \le 100$。每个格子的初始数值均为不超过 $10^9$ 的正整数。

# 输入描述
第一行包含一个整数 $n$ ($1 \le n \le 100$)，表示网格的大小。
接下来 $n$ 行，每行包含 $n$ 个整数，表示对应格子的初始数值。每个数值均为不超过 $10^9$ 的正整数。

# 输出描述
输出一个整数，表示最少操作次数。

## 样例1

**输入**

```
1
5
```

**输出**

```
0
```

**说明**

当 $n=1$ 时，网格中只有一个格子。无论旋转 $0^\circ$、$90^\circ$、$180^\circ$ 还是 $270^\circ$，网格都保持不变。因此初始状态已经满足四次旋转对称，不需要任何操作，答案为 `0`。

## 样例2

**输入**

```
2
1 2
3 4
```

**输出**

```
6
```

**说明**

在 $2 \times 2$ 的网格中，四个位置 $(1,1)$、$(1,2)$、$(2,2)$、$(2,1)$ 在四次旋转下属于同一个轨道。
轨道内的初始值为 `1`、`2`、`4`、`3`，最大值为 `4`。为了让旋转后完全相同，必须将其他格子的值都增加到 `4`。
所需操作次数为 $(4-1) + (4-2) + (4-4) + (4-3) = 3 + 2 + 0 + 1 = 6$。

## 样例3

**输入**

```
3
1 2 3
4 5 6
7 8 9
```

**输出**

```
28
```

**说明**

对于 $3 \times 3$ 的网格，旋转对称将所有格子分成三个轨道：
1. 中心位置 $(2,2)$ 单独形成一个轨道，初始值为 `5`，最大值为 `5`，无需操作。
2. 四个角位置 $(1,1)$、$(1,3)$、$(3,3)$、$(3,1)$ 属于同一轨道，初始值依次为 `1`、`3`、`9`、`7`，最大值为 `9`。需要增加的总次数为 $(9-1)+(9-3)+(9-9)+(9-7)=8+6+0+2=16$。
3. 四个边中点 $(1,2)$、$(2,3)$、$(3,2)$、$(2,1)$ 属于同一轨道，初始值依次为 `2`、`6`、`8`、`4`，最大值为 `8`。需要增加的总次数为 $(8-2)+(8-6)+(8-8)+(8-4)=6+2+0+4=12$。
三个轨道的操作次数相加：$0 + 16 + 12 = 28$，即为答案。
