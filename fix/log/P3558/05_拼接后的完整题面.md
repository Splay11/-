# 题目内容
在一场积分赛中，有 $n$ 名选手，编号为 $1 \sim n$，初始积分均为 $0$。接下来依次发生 $m$ 次得分事件，每次事件有一名选手获得 $1$ 积分。每次事件后，积分最高的选手被称为当前领先者；若有多名选手积分相同且均为最高，则他们都视为当前领先者。请你计算每位选手在整个过程中成为当前领先者的次数。

选手人数 $n$ 和得分事件数 $m$ 满足 $1 \le n, m \le 2 \times 10^5$。每次得分事件中获分的选手编号 $p_i$ 满足 $1 \le p_i \le n$。

# 输入描述
第一行包含两个整数 $n$ 和 $m$。
第二行包含 $m$ 个整数 $p_1, p_2, \dots, p_m$（$1 \le p_i \le n$），依次表示每次得分事件中获分的选手编号。

# 输出描述
输出一行 $n$ 个整数，用空格分隔，表示编号 $1$ 至 $n$ 的选手成为当前领先者的次数。

## 样例1

**输入**

```
1 3
1 1 1
```

**输出**

```
3
```

**说明**

只有 `1` 名选手，每次得分事件后该选手的积分都是最高，因此每次事件后都成为当前领先者。共发生 `3` 次事件，所以 `1` 号选手的领先次数为 $3$。

## 样例2

**输入**

```
2 1
2
```

**输出**

```
0 1
```

**说明**

初始 `1` 号和 `2` 号积分均为 $0$。第 `1` 次事件后，`2` 号积分变为 $1$，`1` 号仍为 $0$，`2` 号积分最高，成为当前领先者。`1` 号从未领先，领先次数为 $0$；`2` 号领先了 $1$ 次。

## 样例3

**输入**

```
3 5
1 2 2 3 3
```

**输出**

```
2 4 1
```

**说明**

初始所有人积分 $0$。
第 `1` 次事件后：`1` 号积分 $1$，领先，`1` 号次数 $+1$。
第 `2` 次事件后：`1` 号 $1$，`2` 号 $1$，两人并列最高，`1` 号再 $+1$，`2` 号 $+1$。
第 `3` 次事件后：`2` 号积分变为 $2$，单独最高，`2` 号次数 $+1$。
第 `4` 次事件后：`3` 号积分 $1$，最高仍为 `2` 号 $2$，`2` 号再 $+1$。
第 `5` 次事件后：`3` 号积分变为 $2$，与 `2` 号并列最高，`2` 号再 $+1$，`3` 号 $+1$。
最终次数：`1` 号 $2$ 次，`2` 号 $4$ 次，`3` 号 $1$ 次。

## 样例4

**输入**

```
4 6
1 2 2 3 3 3
```

**输出**

```
2 4 2 0
```

**说明**

初始积分均为 $0$。
第 `1` 次事件：`1` 号 $1$ 分领先，`1` 号次数 $+1$。
第 `2` 次事件：`1` 号 $1$，`2` 号 $1$，并列领先；`1` 号 $+1$，`2` 号 $+1$。
第 `3` 次事件：`2` 号 $2$ 分单独领先，`2` 号 $+1$。
第 `4` 次事件：`3` 号 $1$ 分，最高仍为 `2` 号 $2$，`2` 号 $+1$。
第 `5` 次事件：`2` 号 $2$，`3` 号 $2$，并列领先；`2` 号 $+1$，`3` 号 $+1$。
第 `6` 次事件：`3` 号 $3$ 分单独领先，`3` 号 $+1$。
`4` 号始终 $0$ 分，从未领先。最终：`1` 号 $2$ 次，`2` 号 $4$ 次，`3` 号 $2$ 次，`4` 号 $0$ 次。
