## 解题思路

问题等价于在模 $M$ 的意义下，考虑序列：  
$$
v_i = (s + i \cdot p) \bmod M \quad (i \ge 0)
$$

我们的目标是找出所有可能出现的 $v_i$ 中的最大值。

根据初等数论中的结论，所有能取到的值恰好是满足  
$$x \equiv s \pmod{\gcd(p,\,M)}$$  
的模 $M$ 的数。换句话说，可取值构成一个公差为 $g = \gcd(p, M)$ 的等差序列：

$$
s \bmod g,\ (s \bmod g)+g,\ (s \bmod g)+2g,\ \dots
$$

直到小于 $M$ 为止。

这个序列的最大项就是该等差数列的最后一项。设 $r = s \bmod g$，则最大值为：

$$
r + \left\lfloor \frac{M-1-r}{g} \right\rfloor \cdot g
$$

由于 $g$ 整除 $M$，该式可化简为：

$$
M - g + r
$$

因此，每组数据的解法为：

1. 计算 $g = \gcd(p, M)$  
2. 计算 $r = s \bmod g$  
3. 输出 $M - g + r$

算法核心在于求最大公约数，采用辗转相除法即可。

## 复杂度分析

每组数据仅需计算一次最大公约数以及若干次常数时间的取模和减法操作。

- 时间复杂度：$O(\log \min(p, M))$  
- 空间复杂度：$O(1)$  

总数据组数 $T \le 10^5$ 完全可行。

## 代码实现

### Python

```python
import sys
import math

def solve_one(s, p, M):
    # 计算 g = gcd(p, M)
    g = math.gcd(p, M)
    # r = s mod g
    r = s % g
    # 最大值公式: M - g + r
    return M - g + r

def main():
    data = sys.stdin.read().split()
    if not data:
        return
    T = int(data[0])
    idx = 1
    out_lines = []
    for _ in range(T):
        s = int(data[idx])
        p = int(data[idx+1])
        M = int(data[idx+2])
        idx += 3
        out_lines.append(str(solve_one(s, p, M)))
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    // 辗转相除求最大公约数
    static long gcd(long a, long b) {
        while (b != 0) {
            long t = a % b;
            a = b;
            b = t;
        }
        return a;
    }

    static long solveOne(long s, long p, long M) {
        long g = gcd(p, M);        // g = gcd(p, M)
        long r = s % g;            // r = s mod g
        return M - g + r;          // 最大值公式
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < T; i++) {
            long s = sc.nextLong();
            long p = sc.nextLong();
            long M = sc.nextLong();
            sb.append(solveOne(s, p, M)).append('\n');
        }
        System.out.print(sb.toString());
        sc.close();
    }
}
```
