# 题目内容


有一条从 $1$ 开始编号的无限长一维格子，初始时，所有编号为质数的格子为黑格子，其余格子为白格子。共有 $n$ 个人依次出发，且都从格子 $1$ 起步，给定一个长度为 $n$ 且仅包含字符 $0$ 与 $1$ 的指令串 $s$。第 $i$ 个出发者将顺序执行 $s$ 的前 $i$ 条指令；每条指令的含义如下：
- 当执行到 ‘$0$’ 时，此人从当前位置移动到严格右侧的下一个白格子（即编号大于当前位置且颜色为白的、编号最小的格子）；
- 当第 ‘$1$’ 时，此人从当前位置移动到严格右侧的下一个黑格子（即编号大于当前位置且颜色为黑的、编号最小的格子）。

当第 $i$ 个出发者完成其 $i$ 条指令后，他会将此时所在的格子的颜色翻转。（黑变白、白变黑）。所有人依次出发，后出发者会受到先前颜色翻转的影响。

请输出所有最终颜色与初始颜色不同的格子的编号，按从小到大排列。

【名词解释】
<u>质数</u>：一个大于 $1$ 的正整数，如果除了 $1$ 和它自身以外不再有其他因数，那么这个数被称作质数。特殊地，$1$ 既不是质数也不是合数。



# 输入描述


每个测试文件均包含多组测试数据。第一行输入一个整数 $t$ $(1 \le t \le 10^4)$ 表示数据组数，每组测试数据如下：
- 第一行输入一个整数 $n$ $(1 \le n \le 10^5)$，表示人数以及指令串的长度；
- 第二行输入一个长度为 $n$、仅由字符 ‘$0$’ 与 ‘$1$’ 构成的字符串 $s$，表示行走指令。

除此之外，保证单个测试文件的 $n$ 之和不超过 $10^6$。



# 输出描述

对于每一组测试数据，输出两行：
- 第一行输出一个整数 $l$，表示最终颜色与初始颜色不同的格子数量；
- 第二行输出 $l$ 个互不相同的正整数，表示这些格子的编号，按从小到大输出。若 $(l=0)$，则第二行不输出任何数字，但仍需输出一个空行作为第二行。




## 样例1 



**输入** 



```
2
1
0
2
11
```



**输出** 



```
1
4
2
2 5
```



**说明**

在第二组测试数据中：
- 初始黑格子为所有质数编号（如 $2,3,5,7,\dots$）；
- 第 $1$ 个人执行 $s_1=$ $1$，从 $1$ 移动到下一个黑格子 $2$，结束后将格子 $2$ 翻转为白；
- 第 $2$ 个人依次执行 $s_1=$ $1$、$s_2=$ $1$；此时 $2$ 已为白，从 $1$ 的下一个黑格子是 $3$，再从 $3$ 的下一个黑格子是 $5$；结束后将格子 $5$ 翻转为白；

因此共有 $2$ 个格子颜色发生变化，分别为 $2$ 与 $5$，升序输出为 $2\ 5$。
