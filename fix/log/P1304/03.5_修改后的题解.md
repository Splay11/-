## 解题思路

每次只能把某个正数变成 $\lfloor x/2\rfloor$，数值单调不增。最终所有数相等时，一定是当前最大值被不断折半，直到与最小值对齐；过程中最小值也可能因为某次折半而下降，此时其他数还要继续追赶。

用大根堆维护当前所有数，并动态记录最小值。反复取出最大值：

- 若已等于最小值，结束；
- 否则将其折半放回堆中，并更新最小值与操作次数。

因为每个数至多折半约 $30$ 次，总操作次数不超过 $O(n\log A)$。

## 复杂度分析

时间复杂度 $O(n\log A \cdot \log n)$，空间复杂度 $O(n)$。

## 代码实现

### Python

```python
import heapq

n = int(input())
nums = list(map(int, input().split()))
minv = min(nums)
nums = [-item for item in nums]
heapq.heapify(nums)
ans = 0
f = True
while f:
    cur = -heapq.heappop(nums)
    if cur == minv:
        f = False
    else:
        cur = cur // 2
        minv = min(cur, minv)
        heapq.heappush(nums, -cur)
        ans += 1
print(ans)
```

### Java

```java
import java.util.PriorityQueue;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        PriorityQueue<Integer> heap = new PriorityQueue<>((o1, o2) -> o2 - o1);
        int minv = Integer.MAX_VALUE;
        for (int i = 0; i < n; i++) {
            int x = sc.nextInt();
            heap.offer(x);
            minv = Math.min(minv, x);
        }
        long ans = 0;
        while (heap.peek() != minv) {
            int t = heap.poll();
            t /= 2;
            minv = Math.min(minv, t);
            heap.offer(t);
            ans++;
        }
        System.out.println(ans);
        sc.close();
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    priority_queue<int> heap;
    int minv = 1e9;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        heap.push(x);
        minv = min(minv, x);
    }
    long long res = 0;
    while (heap.top() != minv) {
        int t = heap.top();
        heap.pop();
        t /= 2;
        minv = min(minv, t);
        heap.push(t);
        res++;
    }
    cout << res << endl;
    return 0;
}
```
