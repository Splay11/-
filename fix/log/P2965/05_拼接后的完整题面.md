# 题目内容
在城市的一角，有 $n$ 个广场，由 $n-1$ 条步行街相连，整个网络连通且没有环路（任意两个广场之间有且仅有一条路径）。每个广场上生活着一些鸽子，第 $i$ 个广场上有 $a_i$ 只鸽子。

市长计划关闭一部分步行街，使得整个网络被分割成若干个连通的区域。为了便于鸽子成对飞行，他要求每个区域内部鸽子的总数必须能被 $2$ 整除。

对于每个 $k = 1, 2, \dots, n-1$，请你计算：恰好关闭 $k$ 条步行街之后，能够使得所有区域的鸽子总数均能被 $2$ 整除的方案数。如果不存在任何方案，对应的答案为 $0$。两种方案若关闭的步行街集合不同，则视为不同的方案。

由于答案可能很大，你需要输出每个 $k$ 对应的方案数对 $10^9+7$ 取模的结果。

**数据范围**：广场的数量 $n$ 满足 $2 \le n \le 10^5$，每个广场上的鸽子数量 $a_i$ 满足 $1 \le a_i \le 10^9$。保证输入的步行街构成一个连通且无环的图。

# 输入描述
输入共 $n+1$ 行。

第一行包含一个整数 $n$ $(2 \le n \le 10^5)$，表示广场的数量。

第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$ $(1 \le a_i \le 10^9)$，依次表示每个广场上的鸽子数量。

接下来 $n-1$ 行，每行包含两个整数 $u$ 和 $v$ $(1 \le u, v \le n, u 
eq v)$，表示编号为 $u$ 和 $v$ 的广场之间有一条步行街。保证所有步行街构成一个连通且无环的图。

# 输出描述
输出一行，包含 $n-1$ 个整数，第 $i$ 个整数表示恰好关闭 $i$ 条步行街后满足条件的方案数对 $10^9+7$ 取模的结果。

## 样例1

**输入**

```
2
2 2
1 2
```

**输出**

```
1
```

**说明**

整个广场网络只有 `2` 个广场，总鸽子数为 $2+2=4$，是偶数。每个广场的鸽子数 `2` 均为偶数，因此无论是否关闭步行街，每个连通块的鸽子总数都是偶数。恰好关闭 $k=1$ 条步行街的方案只有 `1` 种（关闭唯一的那条边）。因此答案为 `1`。

## 样例2

**输入**

```
3
1 1 2
1 2
2 3
```

**输出**

```
1 0
```

**说明**

广场网络为链 $1-2-3$，鸽子数依次为 `1`、`1`、`2`，总和为 $4$（偶数）。要使每个连通块内鸽子总数为偶数，等价于每个连通块内包含奇数个鸽子的广场数量为偶数。奇数鸽子广场为 $1$ 和 $2$（权值 `1` 和 `1`）。两个奇数广场必须在同一个连通块内，否则各自所在连通块只有 `1` 个奇数广场，总数为奇数。因此边 $(1,2)$ 不能断开，否则广场 $1$ 单独成块（奇数）。唯一可能断开的是边 $(2,3)$：断开后得到连通块 $\{1,2\}$（权值和 $2$，偶数）和 $\{3\}$（权值和 $2$，偶数），满足条件。所以恰好关闭 $k=1$ 条边时，方案数为 `1`（只断开 $(2,3)$）；$k=2$ 时，两条边都断开不满足条件，方案数为 `0`。因此输出 `1 0`。

## 样例3

**输入**

```
3
1 1 1
1 2
2 3
```

**输出**

```
0 0
```

**说明**

广场网络为链 $1-2-3$，鸽子数均为 `1`，总和为 $3$（奇数）。无论怎样划分连通块，所有连通块的鸽子总数之和等于总和 `3`，而 `3` 是奇数，不可能分解为若干个偶数之和。因此对于任意 $k$，满足条件的方案数均为 `0`。输出 `0 0`。

## 样例4

**输入**

```
5
1 2 1 2 2
1 2
2 3
3 4
2 5
```

**输出**

```
2 1 0 0
```

**说明**

广场网络包含 `5` 个广场，权值见输入。总鸽子数为 `8`（偶数）。广场 $1$ 和 $3$ 的鸽子数为奇数（`1`），其余为偶数。要使每个连通块内鸽子数为偶数，两个奇数广场 $1$ 和 $3$ 必须属于同一连通块。因此连接 $1$ 与 $3$ 的路径上的边 $(1,2)$ 与 $(2,3)$ 必须保留，不能关闭。其余两条边 $(3,4)$ 和 $(2,5)$ 均只连接偶数权值的子树，断开与否均不影响奇偶性。所以可自由选择是否关闭的边只有 `2` 条。恰好关闭 $k$ 条边时，必须从这 `2` 条边中选择 $k$ 条关闭，且不能选择必须保留的边。因此方案数为 $\binom{2}{k}$（当 $k \le 2$），$k > 2$ 时为 `0`。计算得：$k=1$ 时 `2` 种，$k=2$ 时 `1` 种，$k=3,4$ 时 `0` 种。输出 `2 1 0 0`。
