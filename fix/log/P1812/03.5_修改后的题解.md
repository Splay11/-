## 解题思路

1. 由于序列 $a$ 是 $1 \sim n$ 的一个排列，每个节点的出度恰好为 $1$，入度也恰好为 $1$，因此整个有向图由若干个互不相交的环构成。
2. 在同一个环中，从任意节点出发，沿着传送带移动，可以到达环内的所有其他节点（包括自身）。也就是说，环内任意有序对 $(p, q)$ 都是一个可达对。
3. 设某个环包含 $x$ 个节点，则该环内部的可达对数目为 $x \cdot x = x^2$。
4. 因此，可达对的总数 = 所有环的大小的平方之和。问题转化为：找出所有环的大小，计算它们的平方和。
5. 具体实现：
   - 用一个 `visited` 数组标记每个节点是否已经处理过。
   - 遍历所有节点 $i = 1 \dots n$，若 `visited[i]` 为假，则从 $i$ 出发，一直沿 $a$ 向前走，直到回到节点 $i$，同时标记访问过的节点并计数。得到的计数即为当前环的大小 $c$，将 $c^2$ 累加到答案中。
6. 注意答案可能超过 $2^{31}-1$，需使用 64 位整数（Python 的 `int` 自动支持、Java 的 `long`、C++ 的 `long long`）。

## 复杂度分析

- 时间复杂度：每个节点只会被访问常数次，整体为 $O(n)$。
- 空间复杂度：`visited` 数组需要 $O(n)$ 额外空间，其他变量为常数级，整体空间复杂度 $O(n)$。

## 代码实现

### Python

```python
n = int(input())
a = [0] + list(map(int, input().split()))  # 转换为 1-indexed，方便处理

visited = [False] * (n + 1)
ans = 0

for i in range(1, n + 1):
    if not visited[i]:
        # 统计当前环的大小
        cnt = 0
        cur = i
        while not visited[cur]:
            visited[cur] = True
            cnt += 1
            cur = a[cur]
        ans += cnt * cnt

print(ans)
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] a = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            a[i] = sc.nextInt();
        }

        boolean[] visited = new boolean[n + 1];
        long ans = 0;

        for (int i = 1; i <= n; i++) {
            if (!visited[i]) {
                long size = 0;
                int cur = i;
                while (!visited[cur]) {
                    visited[cur] = true;
                    size++;
                    cur = a[cur];
                }
                ans += size * size;
            }
        }

        System.out.println(ans);
    }
}
```

#include <iostream>
#include <vector>

int main() {
    ios::sync_with_stdio(false);

    int n;
    cin >> n;
    vector<int> a(n + 1);
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
    }

    vector<bool> visited(n + 1, false);
    long long ans = 0;

    for (int i = 1; i <= n; ++i) {
        if (!visited[i]) {
            long long size = 0;
            int cur = i;
            while (!visited[cur]) {
                visited[cur] = true;
                ++size;
                cur = a[cur];
            }
            ans += size * size;
        }
    }

    cout << ans << '\n';
    return 0;
}
