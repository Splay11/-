# 题目内容
在一座庞大的迷宫中，有 $n$ 个平台，编号 $1$ 到 $n$。每个平台 $i$ 上设置了一条单向传送带，会将你运送到平台 $a_i$。已知序列 $a$ 包含了 $1$ 到 $n$ 的所有整数，且没有重复。

若从平台 $p$ 出发，通过若干次传送带移动（可以为零次）可以抵达平台 $q$，则称 $(p,q)$ 为一个可达对。请你计算可达对的总数目。

数据范围：平台数 $n$ 满足 $n \le 10^5$，序列 $a$ 中的整数均在 $1$ 到 $n$ 之间，且每个整数恰好出现一次。

# 输入描述
第一行包含一个整数 $n$ ($1 \le n \le 10^5$)，表示平台的数量。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$，表示各平台的传送目标。保证这 $n$ 个整数恰好包含 $1$ 到 $n$ 每个数各一次。

# 输出描述
输出一个整数，表示可达对的总数。

## 样例1

**输入**

```
4
2 3 4 1
```

**输出**

```
16
```

**说明**

该排列形成一个长度为 `4` 的圈：`1` -> `2` -> `3` -> `4` -> `1`。
在同一个圈中，任意两个平台都互相可达，因此可达对数量为 $4^2 = 16$。

## 样例2

**输入**

```
5
2 1 4 5 3
```

**输出**

```
13
```

**说明**

排列包含两个圈。
圈 `1`：`1` 与 `2` 互相传送，大小为 `2`，可达对数量为 $2^2 = 4$。
圈 `2`：`3` -> `4` -> `5` -> `3`，大小为 `3`，可达对数量为 $3^2 = 9$。
两个圈的可达对总和为 `4 + 9 = 13`。

## 样例3

**输入**

```
1
1
```

**输出**

```
1
```

**说明**

仅有一个平台，自己可以到达自己，圈大小为 `1`。
可达对数量为 $1^2 = 1$。
