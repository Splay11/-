## 解题思路

1. **问题转化**：  
   设两颗宝石魔力值分别为 $a_i$ 和 $a_j$，它们之和为 $M$ 的倍数，等价于 $(a_i \bmod M) + (a_j \bmod M)$ 是 $M$ 的倍数（在模 $M$ 意义下为 $0$）。  
   因此只需要考虑每颗宝石的余数 $r_i = a_i \bmod M$。

2. **统计余数**：  
   用哈希表统计每种余数的出现次数，记 $cnt[r]$ 表示余数为 $r$ 的宝石数量。

3. **分类讨论最大可选数量**：  
   - 若某一类余数 $r$ 满足 $r = 0$ 或 $2r = M$（仅当 $M$ 为偶数时后者成立），则从该类中任选两颗宝石，其和为 $M$ 的倍数，因此该类所有宝石可以全部入选。这部分候选答案为 $cnt[r]$。  
   - 对于其他余数 $r$（$r \neq 0$ 且 $2r \neq M$），如果存在互补余数 $M - r$，则可以选取一个 $r$ 和 一个 $M - r$ 组成一对，此时答案为 $2$。  
   - 若上述两种情况均无法使答案达到 $2$，则无法构成有效共鸣阵，输出 $-1$。

4. **答案合成**：  
   遍历哈希表，用变量 $ans$ 记录最大宝石数量：  
   - 对满足 `r == 0 或 2 * r == M` 的余数，用 $cnt[r]$ 更新 $ans$；  
   - 否则若 $M - r$ 存在于哈希表中，用 $2$ 更新 $ans$。  
   最终若 $ans \ge 2$ 则输出 $ans$，否则输出 $-1$。

## 复杂度分析

- 时间复杂度：统计余数遍历数组 $O(n)$，遍历哈希表 $O(\min(n, M))$，总复杂度 $O(n)$。  
- 空间复杂度：哈希表存储不同余数的计数，空间复杂度 $O(\min(n, M))$，即 $O(n)$。

## 代码实现

### Python

```python
from collections import defaultdict

n, M = map(int, input().split())
a = list(map(int, input().split()))

cnt = defaultdict(int)
for val in a:
    cnt[val % M] += 1

ans = 0
for r, c in cnt.items():
    if r == 0 or 2 * r == M:   # 可用全部该类宝石
        if c > ans:
            ans = c
    elif M - r in cnt:         # 至少可选一对互补余数
        ans = max(ans, 2)

print(ans if ans >= 2 else -1)
```

### Java

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int M = sc.nextInt();
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int i = 0; i < n; i++) {
            int val = sc.nextInt();
            int r = val % M;
            cnt.put(r, cnt.getOrDefault(r, 0) + 1);
        }
        int ans = 0;
        for (Map.Entry<Integer, Integer> entry : cnt.entrySet()) {
            int r = entry.getKey();
            int c = entry.getValue();
            if (r == 0 || 2 * r == M) {
                if (c > ans) ans = c;
            } else if (cnt.containsKey(M - r)) {
                ans = Math.max(ans, 2);
            }
        }
        System.out.println(ans >= 2 ? ans : -1);
    }
}
```

### C++

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, M;
    cin >> n >> M;
    unordered_map<int, int> cnt;
    for (int i = 0; i < n; ++i) {
        int val;
        cin >> val;
        int r = val % M;
        cnt[r]++;
    }
    int ans = 0;
    for (auto &p : cnt) {
        int r = p.first;
        int c = p.second;
        if (r == 0 || 2 * r == M) {
            if (c > ans) ans = c;
        } else if (cnt.count(M - r)) {
            ans = max(ans, 2);
        }
    }
    cout << (ans >= 2 ? ans : -1) << endl;
    return 0;
}
```
