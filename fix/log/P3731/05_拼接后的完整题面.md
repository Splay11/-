# 题目内容
一台仪器在闭区间 $[1, 2^{20}]$ 内隐藏了一个整数刻度 $x$。探针按固定规则探测 `20` 轮：始终维护当前可能区间 $[l, r]$（初始 $l=1$，$r=2^{20}$），本轮探测点取 $g=\left\lfloor \dfrac{l+r+1}{2} \right\rfloor$。

若 $g > x$，仪器返回字符 `1`，并把区间更新为 $[l, g-1]$；否则返回字符 `0`，并把区间更新为 $[g, r]$。

现在给出这 `20` 轮返回的字符（从第 `1` 轮到第 `20` 轮），请还原刻度 $x$。

约束：测试组数不超过 `1000`，每组字符串长度恰好为 `20`，且仅由字符 `0` 与 `1` 组成。

# 输入描述
每个测试文件包含多组数据。第一行一个整数 $T$，表示数据组数。
每组数据一行，为一个仅由 `0` 与 `1` 构成、长度恰为 `20` 的字符串，依次对应 `20` 次返回值。
保证 $1 \le T \le 1000$。

# 输出描述
对每组数据输出一行一个整数，即被还原的刻度 $x$（满足 $1 \le x \le 2^{20}$）。

## 样例1

**输入**

```
3
00000000000000000000
11111111111111111111
10110000000000000000
```

**输出**

```
1048576
1
327680
```

**说明**

第一组始终返回 `0`，每次都把下界抬到探测点，区间不断向右收缩，最终刻度为 $2^{20}=1048576$。
第二组始终返回 `1`，每次都把上界降到探测点减一，最终刻度为 `1`。
第三组前几轮左右交替收缩，最终得到 $327680$。

## 样例2

**输入**

```
1
01010101010101010101
```

**输出**

```
699051
```

**说明**

长度为 `20` 的交替串 `0101...01`。第奇数轮返回 `0` 抬升下界，第偶数轮返回 `1` 压低下界，按公式 $g=\left\lfloor (l+r+1)/2 \right\rfloor$ 回放 `20` 轮后得到 $699051$。

## 样例3

**输入**

```
2
10000000000000000000
01111111111111111111
```

**输出**

```
524288
524289
```

**说明**

第一组首轮返回 `1`，把上界压到中点减一，其后全是 `0`，收敛到区间左半部分的右端点 $524288$。
第二组首轮返回 `0`，其后全是 `1`，收敛到右半部分的左端点 $524289$。
