## 解题思路

本题只需按仪器规则回放这 `20` 轮探测。

初始令 $l=1$，$r=2^{20}=1048576$。对返回串中的每个字符：

- 计算本轮探测点 $g=\left\lfloor \dfrac{l+r+1}{2} \right\rfloor$。整数除法即下取整。
- 若字符为 `1`，说明 $g>x$，把上界改为 $g-1$。
- 若字符为 `0`，说明 $g \le x$，把下界改为 $g$。

区间长度初始为 $2^{20}$，每轮大约减半。`20` 轮后 $[l,r]$ 会收缩到一个点，此时 $l=r$，该值就是隐藏刻度 $x$。

## 复杂度分析

每组数据扫描长度为 `20` 的字符串，常数次整数运算。

- 时间复杂度：$O(1)$ 每组，总计 $O(T)$。
- 空间复杂度：$O(1)$。

## 代码实现

### Python

```python
import sys

def solve():
    s = sys.stdin.readline().strip()
    l = 1
    r = 2**20
    for char_code in s:
        g = (l + r + 1) // 2
        if char_code == '1':
            r = g - 1
        else:
            l = g
    print(l)


def main():
    try:
        t_str = sys.stdin.readline().strip()
        if t_str:
            t = int(t_str)
            for _ in range(t):
                solve()
    except (IOError, ValueError):
        pass


if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Main {

    public static void solve() throws IOException {
        BufferedReader reader = new BufferedReader(new InputStreamReader(System.in));
        int t = Integer.parseInt(reader.readLine());

        while (t-- > 0) {
            String s = reader.readLine();
            long l = 1;
            long r = 1L << 20;

            for (char c : s.toCharArray()) {
                long g = (l + r + 1) / 2;
                if (c == '1') {
                    r = g - 1;
                } else {
                    l = g;
                }
            }
            System.out.println(l);
        }
    }

    public static void main(String[] args) {
        try {
            solve();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```
