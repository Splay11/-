## 解题思路

这是一道构造题，对每个给定的正整数 $m$，需要找到两个不同的正整数 $a,b$，满足 $1 \le a,b < m$ 且 $m \bmod a = m \bmod b$。若不存在这样的数对，输出 `-1`。

由于只需输出任意一组合法解，我们可以直接使用分类构造的方法，不需要枚举或暴力比较余数。

### 无解情况
当 $m \le 3$ 时，候选的正整数太少，无法选出满足条件的 $a,b$：
- $m = 1$：没有小于 $1$ 的正整数；
- $m = 2$：只有 $a = 1$，无法选出两个不同整数；
- $m = 3$：只能选 $1, 2$，但 $3 \bmod 1 = 0$，$3 \bmod 2 = 1$，不相等。

因此若 $m \le 3$，直接输出 `-1`。

### 当 $m$ 为偶数
取  
$$
a = 1,\quad b = 2
$$
- $m \bmod 1 = 0$；
- $m$ 是偶数，所以 $m \bmod 2 = 0$。

二者余数相等且 $a,b$ 不同，且当 $m \ge 4$ 时满足 $1 \le a,b < m$。

### 当 $m$ 为奇数（$m \ge 5$）
取  
$$
a = 2,\quad b = m - 1
$$
- $m$ 为奇数，所以 $m \bmod 2 = 1$；
- $m = 1 \cdot (m-1) + 1$，故 $m \bmod (m-1) = 1$。

二者余数相等且 $a,b$ 不同，且当 $m \ge 5$ 时满足 $1 \le a,b < m$。

综上，直接根据 $m$ 的奇偶性构造即可，每组询问只需常数次判断。

## 复杂度分析

对于每组测试数据，只进行常数次运算和判断，因此：
- 时间复杂度：$O(1)$
- 空间复杂度：$O(1)$

## 代码实现

### Python

```python
import sys

def solve_one(m):
    # m <= 3 时不存在两个不同的正整数 a,b 且都小于 m
    if m <= 3:
        return "-1"
    # m 为偶数：取 a=1, b=2
    if m % 2 == 0:
        return "1 2"
    # m 为奇数且 m>=5：取 a=2, b=m-1
    return f"2 {m - 1}"

def main():
    data = sys.stdin.read().strip().split()
    t = int(data[0])
    out_lines = []
    idx = 1
    for _ in range(t):
        m = int(data[idx]); idx += 1
        out_lines.append(solve_one(m))
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    main()
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {
    public static String solveOne(long m) {
        if (m <= 3)
            return "-1";
        if (m % 2 == 0)
            return "1 2";
        return "2 " + (m - 1);
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        PrintWriter pw = new PrintWriter(System.out);
        int T = Integer.parseInt(br.readLine().trim());
        while (T-- > 0) {
            long m = Long.parseLong(br.readLine().trim());
            pw.println(solveOne(m));
        }
        pw.flush();
    }
}
```
