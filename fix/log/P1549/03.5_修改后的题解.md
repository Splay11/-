## 解题思路

一次调度不改变水位总量，只是把 `1` 单位水从一块田移到另一块田。因此：

- 若总量小于 $n\cdot l$ 或大于 $n\cdot r$，则不可能让每块试验田都落入 $[l,r]$，答案为 $-1$；
- 否则一定可行。低于 $l$ 的田必须补足，高于 $r$ 的田必须削减。每一次调度都可以同时服务一次“必补”和一次“必削”（若两者都还有剩余）。因此最少次数等于必补总量与必削总量的较大值。

中间已在 $[l,r]$ 内的田既不必补也不必削。

## 复杂度分析

时间复杂度 $O(\sum n)$，空间复杂度 $O(n)$。

## 代码实现

### Python

```python
T = int(input())

for t in range(1, T + 1):
    n, l, r = map(int, input().split())
    arr = list(map(int, input().split()))
    sum_val = sum(arr)
    minn = 0
    maxn = 0

    for i in range(n):
        if arr[i] < l:
            minn += l - arr[i]
        elif arr[i] > r:
            maxn += arr[i] - r

    if sum_val < n * l or sum_val > n * r:
        print(-1)
    else:
        print(max(minn, maxn))
```

### Java

```java
import java.util.*;
class Main {
    static Scanner sc = new Scanner(System.in);
    static int N = 200010;
    static long T, n, l, r;
    static long[] arr = new long[N];
    public static void main(String[] args) {
        T = sc.nextLong();
        for (int t = 1; t <= T; t++) {
            n = sc.nextLong();
            l = sc.nextLong();
            r = sc.nextLong();
            long sum = 0, minn = 0, maxn = 0;
            for (int i = 1; i <= n; i++) {
                arr[i] = sc.nextLong();
                sum += arr[i];
                if (arr[i] < l) minn += l - arr[i];
                else if (arr[i] > r) maxn += arr[i] - r;
            }
            if (sum < n * l || sum > n * r) System.out.println(-1);
            else System.out.println(Math.max(minn, maxn));
        }
    }
}
```

### C++

```cpp
#include <iostream>
using namespace std;

const int N = 200010;
long long arr[N];

int main() {
    long long T, n, l, r;
    cin >> T;

    for (long long t = 1; t <= T; t++) {
        cin >> n >> l >> r;
        long long sum = 0, minn = 0, maxn = 0;

        for (long long i = 1; i <= n; i++) {
            cin >> arr[i];
            sum += arr[i];

            if (arr[i] < l)
                minn += l - arr[i];
            else if (arr[i] > r)
                maxn += arr[i] - r;
        }

        if (sum < n * l || sum > n * r)
            cout << -1 << endl;
        else
            cout << max(minn, maxn) << endl;
    }

    return 0;
}
```
