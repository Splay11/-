# 题目内容
在一条笔直的通道中，特工小 C 需要从初始位置出发，逃到通道的尽头。通道长度为 $L$，起点为位置 $1$，终点为位置 $L$。

小 C 的初始位置为 $P$ $(1 < P < L)$。与此同时，一名追捕者从起点位置 $1$ 出发，以每秒 $1$ 个单位的速度沿通道追击小 C。小 C 的移动速度同样为每秒 $1$ 个单位，但通道中预先布设有 $M$ 个陷阱，每个陷阱位于位置 $a_i$ $(1 < a_i < L)$，且所有陷阱位置互不相同，也不在小 C 的初始位置。小 C 经过陷阱时必须花费 $t_i$ 秒将其拆除才能继续前进；追捕者则不受陷阱影响，可以径直通过。

你需要判断：在小 C 到达终点 $L$ 之前，追捕者是否会追上或超过他（即追捕者的坐标大于或等于小 C 的坐标）。如果追捕者直到小 C 抵达终点都无法追上，则判定小 C 成功逃脱。

约束条件：
- 测试数据组数 $T$ 不超过 $1000$。
- 通道长度 $L$ 满足 $2 \le L \le 10^9$。
- 陷阱数量 $M$ 满足 $0 < M \le L-2$。
- 小 C 初始位置 $P$ 满足 $1 < P < L$。
- 陷阱位置 $a_i$ 均为整数，满足 $1 < a_i < L$，且不与 $P$ 重合，所有 $a_i$ 两两不同。
- 拆除时间 $t_i$ 满足 $1 \le t_i \le 10^6$。
- 所有测试数据中 $M$ 的总和不超过 $10^5$。

# 输入描述
第一行输入一个整数 $T$，表示测试数据组数。
接下来对于每组测试数据：
第一行包含三个整数 $L$, $M$, $P$，分别表示通道长度、陷阱数量和特工初始位置。
第二行包含 $M$ 个整数 $a_1, a_2, \dots, a_M$，表示每个陷阱的位置。
第三行包含 $M$ 个整数 $t_1, t_2, \dots, t_M$，表示对应陷阱的拆除时间。

# 输出描述
对于每组测试数据，在一行中输出一个字符串。如果小 C 能够逃脱，输出 `YES`，否则输出 `NO`。

## 样例1

**输入**

```
1
10 1 5
7
1
```

**输出**

```
YES
```

**说明**

通道长度 $L=10$，陷阱数量 $M=1$，小C初始位置 $P=5$。陷阱位于 $7$，拆除耗时 $1$ 秒。

小C从 $5$ 移动到 $7$ 需要 $2$ 秒，拆除陷阱再花 $1$ 秒，共 $3$ 秒。此时追捕者从 $1$ 出发，经过 $3$ 秒到达位置 $4$。追捕者位置 $4$ 小于陷阱位置 $7$，未能追上。随后小C从 $7$ 全速跑向终点 $10$，耗时 $3$ 秒，追捕者最终到达 $7$，仍小于 $10$。小C成功逃脱。

## 样例2

**输入**

```
1
10 1 8
9
7
```

**输出**

```
NO
```

**说明**

通道长度 $L=10$，陷阱数量 $M=1$，小C初始位置 $P=8$。陷阱位于 $9$，拆除耗时 $7$ 秒。

小C从 $8$ 移动到 $9$ 需要 $1$ 秒，拆除陷阱再花 $7$ 秒，共 $8$ 秒。在这段时间内，追捕者从 $1$ 出发，同样经过 $8$ 秒到达位置 $1+8=9$。当小C完成拆除时，追捕者恰好到达 $9$，满足追捕者位置 $\ge$ 小C位置，判定被追上，逃脱失败。

## 样例3

**输入**

```
1
20 3 5
10 12 18
2 3 1
```

**输出**

```
NO
```

**说明**

通道长度 $L=20$，陷阱数量 $M=3$，小C初始位置 $P=5$。陷阱依次位于 $10, 12, 18$，对应拆除时间为 $2, 3, 1$ 秒。

首先处理位置 $10$ 的陷阱：小C移动 $10-5=5$ 秒并拆除 $2$ 秒，总耗时 $7$ 秒，追捕者位置变为 $1+7=8 < 10$，未追上；更新小C位置为 $10$。

接着处理位置 $12$ 的陷阱：小C移动 $2$ 秒并拆除 $3$ 秒，总耗时 $5$ 秒，追捕者位置变为 $8+5=13$。此时 $13 \ge 12$，追捕者已超过陷阱位置，小C在到达 $12$ 之前被追上，逃脱失败。

## 样例4

**输入**

```
1
10 2 6
3 8
100 1
```

**输出**

```
YES
```

**说明**

通道长度 $L=10$，陷阱数量 $M=2$，小C初始位置 $P=6$。陷阱位于 $3$ 和 $8$，拆除时间分别为 $100$ 秒和 $1$ 秒。

陷阱 $3$ 在小C初始位置的后方，小C只会向终点前进，因此无需经过该陷阱，其拆除时间不影响逃脱。

小C只需处理位置 $8$ 的陷阱：从 $6$ 移动到 $8$ 耗时 $2$ 秒，拆除耗时 $1$ 秒，共 $3$ 秒。追捕者从 $1$ 出发，$3$ 秒后到达位置 $4 < 8$，未能追上。此后小C直奔终点 $10$，再花 $2$ 秒，追捕者最终到达 $6$，仍小于 $10$。小C成功逃脱。
