# 题目内容
有 $n$ 个人，他们的身高分别为 $1,2,\dots,n$，且互不相同。他们随机排成一列，得到一个排列 $p_1,p_2,\dots,p_n$。

我们称有序对 $(i,j)$ 若满足 $i<j$ 且 $p_i > p_j$ 为一个“遮挡事件”。换句话说，前面的人比后面的人高即为一次遮挡。

现在要求前两个人的身高必须严格递增，即 $p_1 < p_2$。并且，总的遮挡事件次数不超过 $k$。

请你计算满足条件的排列方案总数。由于答案可能很大，需要对 $10^9+7$ 取模。

约束条件：
- $n$ 的范围为 $3 \le n \le 200$。
- $k$ 的范围为 $0 \le k \le 200$。

# 输入描述
输入仅一行，包含两个由空格分隔的整数 $n$ 和 $k$。

# 输出描述
输出一行一个整数，表示满足条件的方案数模 $10^9+7$ 的结果。

## 样例1

**输入**

```
3 0
```

**输出**

```
1
```

**说明**

当 `n=3`、`k=0` 时，只有完全升序排列满足逆序对个数不超过 `0`。在 `n=3` 的排列中，只有 $(1,2,3)$ 是升序排列，且它满足 $p_1 < p_2$，因此方案数为 `1`。

## 样例2

**输入**

```
4 3
```

**输出**

```
9
```

**说明**

对于 `n=4`，满足 $p_1 < p_2$ 的排列共有 `12` 个（即全部 `24` 个排列的一半）。其中逆序对个数不超过 `3` 的有 `9` 个。

逆序对个数分别为 `0`、`1`、`2`、`3` 且满足 $p_1 < p_2$ 的排列数依次为 $A_0=1$、$A_1=2$、$A_2=3$、$A_3=3$，累加得到 $1+2+3+3=9$。

## 样例3

**输入**

```
5 5
```

**输出**

```
41
```

**说明**

当 `n=5` 时，所有排列的逆序对分布为 $f[5][0]=1$，$f[5][1]=4$，$f[5][2]=9$，$f[5][3]=15$，$f[5][4]=20$，$f[5][5]=22$，…。利用关系 $A_j = f[5][j] - A_{j-1}$ 且 $A_0=1$，可求得：

$A_0=1$，$A_1=3$，$A_2=6$，$A_3=9$，$A_4=11$，$A_5=11$。

将这些值累加至 $k=5$ 即得 $1+3+6+9+11+11=41$。

## 样例4

**输入**

```
6 4
```

**输出**

```
64
```

**说明**

`n=6` 时逆序对分布为 $f[6][0]=1$，$f[6][1]=5$，$f[6][2]=14$，$f[6][3]=29$，$f[6][4]=49$，…。同样用 $A_j = f[6][j] - A_{j-1}$ 计算满足 $p_1 < p_2$ 的排列数：

$A_0=1$，$A_1=4$，$A_2=10$，$A_3=19$，$A_4=30$。

累加到 `k=4` 得到 $1+4+10+19+30=64$。
