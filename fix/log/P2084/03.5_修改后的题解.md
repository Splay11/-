## 解题思路

1. **问题转化**  
   题目中的“遮挡事件”即为逆序对，即满足 $i<j$ 且 $p_i>p_j$ 的数对。问题转化为：在所有 $1\sim n$ 的排列中，前两个元素满足 $p_1<p_2$，且逆序对总数不超过 $k$ 的排列个数。

2. **无限制条件下的逆序对计数**  
   记 $f[i][j]$ 表示 $1\sim i$ 的全排列中，逆序对恰好为 $j$ 的方案数。  
   将数字 $i$ 插入到 $1\sim i-1$ 的某个排列中，可以放在不同位置从而增加 $0,1,\dots,i-1$ 个逆序对：  
   $$
   f[i][j] = \sum_{t=0}^{\min(j,\,i-1)} f[i-1][j-t]
   $$
   利用前缀和可以将该 DP 优化到 $O(nk)$ 的时间，即可求出 $f[n][0..k]$。

3. **加入 $p_1 < p_2$ 的条件**  
   设：
   - $A_j$：逆序对恰好为 $j$，且满足 $p_1<p_2$ 的排列数；  
   - $B_j$：逆序对恰好为 $j$，且满足 $p_1>p_2$ 的排列数。  
   显然有 $f[n][j] = A_j + B_j$。

   将一个排列的前两个元素交换：
   - 如果原来满足 $p_1<p_2$ 且逆序对数为 $j$，交换后变为 $p_1>p_2$，此时前两个元素形成的逆序对会增加 $1$，而与后面元素形成的逆序对总数不变，因此逆序对数变成 $j+1$；
   - 反之，若原来满足 $p_1>p_2$ 且逆序对数为 $j$，交换后变为 $p_1<p_2$，逆序对数变成 $j-1$。

   这给出了一一对应关系：  
   $$
   B_j = A_{j-1} \quad (j\ge 1)
   $$
   于是有递推式：
   $$
   A_j = f[n][j] - A_{j-1}
   $$
   初值为 $A_0 = 1$，因为逆序对为 $0$ 时只有升序排列 $1,2,\dots,n$，此时一定满足 $p_1=1<p_2=2$。

4. **最终答案**  
   计算出所有 $A_j\;(0\le j\le k)$ 后，累加即可得到满足条件的方案数：
   $$
   \text{ans} = \sum_{j=0}^{k} A_j \pmod{10^9+7}
   $$

## 复杂度分析

- **时间复杂度**：$O(nk)$。  
  计算 $f[n][j]$ 的动态规划使用了前缀和优化，每次转移只需 $O(k)$，总共有 $n$ 层。后续递推 $A_j$ 及求和同为 $O(k)$。

- **空间复杂度**：$O(k)$。  
  DP 数组仅需保留一层状态（$k+1$ 个元素）。

## 代码实现

### Python

```python
MOD = 10 ** 9 + 7

def solve(n, k):
    # dp[j] 表示当前长度下，逆序对恰好为 j 的排列数
    dp = [0] * (k + 1)
    dp[0] = 1

    # 逆序对计数 DP，前缀和优化
    for i in range(2, n + 1):
        ndp = [0] * (k + 1)
        prefix = 0
        for j in range(k + 1):
            prefix = (prefix + dp[j]) % MOD
            if j >= i:
                prefix = (prefix - dp[j - i]) % MOD
            ndp[j] = prefix
        dp = ndp

    # 计算 A[j]：逆序对恰好为 j 且 p1 < p2 的方案数
    ans = 0
    prev = 0          # A[j-1]
    for j in range(k + 1):
        if j == 0:
            cur = dp[0]
        else:
            cur = (dp[j] - prev) % MOD
        ans = (ans + cur) % MOD
        prev = cur

    return ans

def main():
    n, k = map(int, input().split())
    print(solve(n, k))

if __name__ == "__main__":
    main()
```

import java.util.Scanner;

public class Main {
    static final int MOD = 1_000_000_007;

    static int solve(int n, int k) {
        // dp[j] 表示当前长度下，逆序对恰好为 j 的排列数
        int[] dp = new int[k + 1];
        dp[0] = 1;

        // 逆序对计数 DP，前缀和优化
        for (int i = 2; i <= n; i++) {
            int[] ndp = new int[k + 1];
            long prefix = 0;
            for (int j = 0; j <= k; j++) {
                prefix += dp[j];
                if (j >= i) {
                    prefix -= dp[j - i];
                }
                prefix %= MOD;
                if (prefix < 0) {
                    prefix += MOD;
                }
                ndp[j] = (int) prefix;
            }
            dp = ndp;
        }

        // 计算 A[j]：逆序对恰好为 j 且 p1 < p2 的方案数
        long ans = 0;
        long prev = 0; // A[j-1]
        for (int j = 0; j <= k; j++) {
            long cur;
            if (j == 0) {
                cur = dp[0];
            } else {
                cur = (dp[j] - prev) % MOD;
                if (cur < 0) {
                    cur += MOD;
                }
            }
            ans = (ans + cur) % MOD;
            prev = cur;
        }

        return (int) ans;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int k = sc.nextInt();
        System.out.println(solve(n, k));
    }
}
