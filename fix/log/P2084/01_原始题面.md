# 题目内容

给定两个数$n,k$，你需要求出$1,2,...,n$的所有排列$a_1,a_2,...,a_n$中满足$a_1 < a_2$目逆序对个数$sum ≤ k$的个数整数对$(i,j)$是逆序对即对于两个位置$i, j$满足$i < j,a_i> a_j$

排列$a_1,a_2,…,a_n$即要求$a_i≠a_j(i≠j)$，

且$1 ≤ a_i ≤ n(1 ≤ i ≤ n)$

答案对$10^9 + 7$取模

# 输入描述

一行两个数$n,k$

$3≤n≤ 200,0 ≤ k ≤ 200$

# 输出描述



输出一行一个数代表答案



## 样例1 



**输入** 



```
10 5
```



**输出** 



```
1232
```
