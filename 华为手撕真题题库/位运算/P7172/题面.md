# 题目内容

给定一个长度为 $n$ 的二进制补码数组 $bits$，请计算并输出该补码所表示的十进制整数。

数组中的每个元素均为 $0$ 或 $1$，其中 $bits_0$ 为最高位，同时也是符号位：

* 当 $bits_0=0$ 时，该补码表示一个非负整数。
* 当 $bits_0=1$ 时，该补码表示一个负整数。

对于长度为 $n$ 的补码，其对应的十进制值为

$-bits_0 \times 2^{n-1}+\sum_{i=1}^{n-1} bits_i \times 2^{n-1-i}$

请根据给定的补码数组，求出其对应的十进制整数。

# 输入描述

第一行输入一个整数 $n$，表示二进制补码的位数。

第二行输入 $n$ 个整数 $bits_i$，每个整数为 $0$ 或 $1$，按照从最高位到最低位的顺序给出，相邻整数之间用空格分隔。

### 约束

$1 \le n \le 31$

$bits_i \in {0,1}$

# 输出描述

输出一个整数，表示该二进制补码对应的十进制值。

## 样例1

**输入**

```text
4
0 1 0 1
```

**输出**

```text
5
```

**说明**

最高位为 $0$，表示该数为非负数。

二进制补码为 $0101$，其十进制值为

$0\times(-2^3)+1\times2^2+0\times2^1+1\times2^0=5$

因此输出 $5$。

## 样例2

**输入**

```text
4
1 1 0 1
```

**输出**

```text
-3
```

**说明**

最高位为 $1$，表示该数为负数。

根据补码的计算方式，其十进制值为

$-1\times2^3+1\times2^2+0\times2^1+1\times2^0$

$=-8+4+1=-3$

因此输出 $-3$。

## 样例3

**输入**

```text
8
1 0 0 0 0 0 0 0
```

**输出**

```text
-128
```

**说明**

对于 $8$ 位补码，$10000000$ 表示能够表示的最小整数。

其十进制值为

$-2^7=-128$

因此输出 $-128$。
