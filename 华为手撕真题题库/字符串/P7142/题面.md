# 题目内容

给你一个字符串 $path$，表示指向某一文件或目录的 Unix 风格绝对路径。请将该路径转换为更加简洁的规范路径。

在 Unix 风格的文件系统中，路径遵循以下规则：

* 一个点 $.$ 表示当前目录本身。
* 两个点 $..$ 表示切换到上一级目录。
* 多个连续的斜杠 $/$ 均视为一个斜杠 $/$。
* 其他由点组成的名称，例如 $...$ 或 $....$，均视为普通的文件名或目录名。

化简后的规范路径需要满足以下要求：

* 路径必须以斜杠 $/$ 开头。
* 两个目录名之间只能有一个斜杠 $/$。
* 如果路径不是根目录，则末尾不能以斜杠 $/$ 结尾。
* 路径中不能包含表示当前目录的 $.$ 或表示上一级目录的 $..$。

请输出化简后的规范路径。

# 输入描述

输入一行字符串 $path$，表示一个有效的 Unix 风格绝对路径。

### 约束

$1 \le |path| \le 3000$

字符串 $path$ 仅由英文字母、数字、点 $.$、斜杠 $/$ 和下划线 $_$ 组成。

$path$ 一定是一个有效的 Unix 风格绝对路径。

# 输出描述

输出一行字符串，表示将 $path$ 化简后得到的规范路径。

## 样例1

**输入**

```text
/home/
```

**输出**

```text
/home
```

**说明**

路径末尾多余的斜杠需要删除，因此化简后的路径为 $/home$。

## 样例2

**输入**

```text
/home//foo/
```

**输出**

```text
/home/foo
```

**说明**

多个连续的斜杠 $/$ 需要合并为一个斜杠，同时删除路径末尾多余的斜杠。

因此化简后的路径为 $/home/foo$。

## 样例3

**输入**

```text
/home/user/Documents/../Pictures
```

**输出**

```text
/home/user/Pictures
```

**说明**

目录 $..$ 表示返回上一级目录。

因此从 $Documents$ 返回到其上一级目录后，再进入 $Pictures$，最终得到路径 $/home/user/Pictures$。

## 样例4

**输入**

```text
/../
```

**输出**

```text
/
```

**说明**

当前已经位于根目录，无法继续返回更上一级目录。

因此化简后的路径仍然为根目录 $/$。

## 样例5

**输入**

```text
/.../a/../b/c/../d/./
```

**输出**

```text
/.../b/d
```

**说明**

目录名 $...$ 是一个合法的普通目录名，不能将其视为 $..$。

目录 $a$ 后面的 $..$ 会返回上一级目录，目录 $c$ 后面的 $..$ 也会返回上一级目录，而最后的 $.$ 表示当前目录，可以直接忽略。

因此最终得到规范路径 $/.../b/d$。
