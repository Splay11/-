# 题目内容

给定一个由不同正整数组成的数组 $nums$ 和一个目标整数 $target$。

请从数组 $nums$ 中选择若干个元素，使得所选元素之和恰好等于 $target$，并计算所有可能的组合数量。

数组中的每个元素可以被重复使用任意次。

需要注意的是，如果两个组合中元素的排列顺序不同，则它们被视为不同的组合。

例如，$1,2,1$ 和 $2,1,1$ 虽然包含相同的元素，但由于排列顺序不同，因此属于两种不同的组合。

题目数据保证最终答案在有符号 $32$ 位整数范围内。

# 输入描述

第一行输入两个整数 $n$ 和 $target$，分别表示数组 $nums$ 的长度和目标整数。

第二行输入 $n$ 个整数 $nums_i$，表示数组中的各个元素，相邻整数之间用空格分隔。

### 约束

$1 \le n \le 200$

$1 \le nums_i \le 1000$

数组 $nums$ 中的所有元素互不相同。

$1 \le target \le 1000$

# 输出描述

输出一个整数，表示从数组 $nums$ 中选择元素，使其总和恰好等于 $target$ 的不同组合数量。

不同的元素排列顺序视为不同的组合。

如果不存在满足条件的组合，则输出 $0$。

## 样例1

**输入**

```text
3 4
1 2 3
```

**输出**

```text
7
```

**说明**

所有满足条件的组合共有 $7$ 种：

$1,1,1,1$

$1,1,2$

$1,2,1$

$1,3$

$2,1,1$

$2,2$

$3,1$

虽然部分组合包含相同的元素，但由于排列顺序不同，因此需要分别计数。

所以答案为 $7$。

## 样例2

**输入**

```text
1 3
9
```

**输出**

```text
0
```

**说明**

数组中只有数字 $9$，无法通过选择若干个 $9$ 使元素总和等于 $3$。

因此不存在满足条件的组合，输出 $0$。
