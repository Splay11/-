# 题目内容

你有一个保存员工信息的数据结构，其中记录了每名员工唯一的 $ID$、重要度以及直属下属的 $ID$。

对于第 $i$ 名员工：

$ id_i $ 表示该员工的唯一 $ID$。

$ importance_i $ 表示该员工的重要度。

该员工可能有若干名直属下属，每名直属下属通过其 $ID$ 表示。

现在给定一名员工的 $ID$，请计算该员工自身以及他的所有直接或间接下属的重要度总和。

# 输入描述

第一行输入两个整数 $n$ 和 $id$，分别表示员工数量以及需要查询的员工 $ID$。

接下来输入 $n$ 行员工信息。

第 $i$ 行首先输入三个整数 $id_i$、$importance_i$ 和 $m_i$，分别表示第 $i$ 名员工的 $ID$、重要度以及直属下属数量。

随后输入 $m_i$ 个整数，表示该员工所有直属下属的 $ID$。

当 $m_i=0$ 时，该行不再输入直属下属的 $ID$。

### 约束

$1 \le n \le 2000$

$1 \le id_i \le 2000$

所有员工的 $id_i$ 互不相同。

$-100 \le importance_i \le 100$

每名员工最多有一名直接上级，并且可能有多名直属下属。

所有直属下属的 $ID$ 均为有效的员工 $ID$。

# 输出描述

输出一个整数，表示 $ID$ 为 $id$ 的员工自身以及他的所有直接或间接下属的重要度总和。

## 样例1

**输入**

```text
3 1
1 5 2 2 3
2 3 0
3 3 0
```

**输出**

```text
11
```

**说明**

员工 $1$ 自身的重要度为 $5$，其直属下属为员工 $2$ 和员工 $3$。

员工 $2$ 和员工 $3$ 的重要度均为 $3$。

因此员工 $1$ 及其所有下属的重要度总和为：

$5+3+3=11$

## 样例2

**输入**

```text
2 5
1 2 1 5
5 -3 0
```

**输出**

```text
-3
```

**说明**

员工 $5$ 的重要度为 $-3$，并且没有直属下属。

因此员工 $5$ 及其所有下属的重要度总和为 $-3$。
