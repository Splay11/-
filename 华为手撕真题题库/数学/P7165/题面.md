# 题目内容

给定一个长度为 $4$ 的整数数组 $cards$，表示 $4$ 张卡牌上的数字。每张卡牌上的数字范围均为 $1$ 到 $9$。

你需要使用运算符 $+$、$-$、$*$、$/$ 以及括号，将这 $4$ 个数字组成一个数学表达式，使表达式的计算结果恰好为 $24$。

需要遵守以下规则：

* 每张卡牌上的数字必须使用且只能使用一次。
* 除法运算 $/$ 表示实数除法，而不是整数除法。
* 每个运算符都必须位于两个数字或表达式之间，不能将 $-$ 作为一元运算符。
* 不能将多个数字拼接成一个新的数字。

例如，对于数字 $4$、$1$、$8$、$7$，可以构造表达式

$(8-4)\times(7-1)=24$

因此可以得到结果 $24$。

如果能够构造出结果为 $24$ 的合法表达式，则输出 $true$；否则输出 $false$。

# 输入描述

输入一行 $4$ 个整数 $cards_i$，表示 $4$ 张卡牌上的数字，相邻整数之间用空格分隔。

### 约束

$cards.length=4$

$1 \le cards_i \le 9$

# 输出描述

如果能够使用这 $4$ 个数字以及运算符 $+$、$-$、$*$、$/$ 和括号构造出计算结果为 $24$ 的表达式，输出 $true$。

否则输出 $false$。

## 样例1

**输入**

```text
4 1 8 7
```

**输出**

```text
true
```

**说明**

可以构造表达式

$(8-4)\times(7-1)=24$

因此输出 $true$。

## 样例2

**输入**

```text
1 2 1 2
```

**输出**

```text
false
```

**说明**

无法使用这 $4$ 个数字各一次，并通过合法的四则运算得到 $24$。

因此输出 $false$。
