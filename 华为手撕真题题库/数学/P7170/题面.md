# 题目内容

给定一个 $32$ 位有符号整数 $x$，请将 $x$ 的十进制数字部分反转，并返回反转后的整数。

如果反转后的整数超出了 $32$ 位有符号整数的范围

$[-2^{31},2^{31}-1]$

则输出 $0$。

需要注意的是，反转后产生的前导零应当被忽略。例如，$120$ 反转后为 $21$。

假设运行环境不允许存储 $64$ 位整数，无论是有符号整数还是无符号整数。

# 输入描述

输入一个整数 $x$，表示需要进行数字反转的 $32$ 位有符号整数。

### 约束

$-2^{31} \le x \le 2^{31}-1$

# 输出描述

输出一个整数，表示将 $x$ 的十进制数字部分反转后的结果。

如果反转后的结果超出 $32$ 位有符号整数范围 $[-2^{31},2^{31}-1]$，则输出 $0$。

## 样例1

**输入**

```text
123
```

**输出**

```text
321
```

**说明**

整数 $123$ 的数字顺序反转后得到 $321$。

## 样例2

**输入**

```text
-123
```

**输出**

```text
-321
```

**说明**

负号保持在结果最前面，仅反转整数的数字部分。

因此 $-123$ 反转后得到 $-321$。

## 样例3

**输入**

```text
120
```

**输出**

```text
21
```

**说明**

整数 $120$ 的数字部分反转后为 $021$。

由于整数不能包含前导零，因此结果为 $21$。

## 样例4

**输入**

```text
0
```

**输出**

```text
0
```

**说明**

整数 $0$ 反转后仍然为 $0$。
