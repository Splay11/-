# 题目内容

给定一个整数 $x$，请判断 $x$ 是否为回文整数。

回文整数是指从左向右读取和从右向左读取完全相同的整数。

例如，$121$ 从左向右和从右向左读取都为 $121$，因此它是回文整数；而 $123$ 从两个方向读取的结果不同，因此不是回文整数。

如果 $x$ 是回文整数，输出 $true$；否则输出 $false$。

进阶：尝试在不将整数转换为字符串的情况下解决该问题。

# 输入描述

输入一个整数 $x$，表示需要判断的整数。

### 约束

$-2^{31} \le x \le 2^{31}-1$

# 输出描述

如果 $x$ 是回文整数，输出 $true$。

否则输出 $false$。

## 样例1

**输入**

```text
121
```

**输出**

```text
true
```

**说明**

整数 $121$ 从左向右读取为 $121$，从右向左读取也为 $121$。

因此 $121$ 是回文整数，输出 $true$。

## 样例2

**输入**

```text
-121
```

**输出**

```text
false
```

**说明**

整数 $-121$ 从左向右读取为 $-121$，从右向左读取时负号会位于末尾，因此两者不同。

所以 $-121$ 不是回文整数，输出 $false$。

## 样例3

**输入**

```text
10
```

**输出**

```text
false
```

**说明**

整数 $10$ 从右向左读取相当于 $01$，与原整数 $10$ 不同。

因此 $10$ 不是回文整数，输出 $false$。
