# 题目内容

给定一个仅由小写英文字母组成的字符串 $s$。

请删除字符串中的一些字符，使得最终字符串中的每个字母都只出现一次，并且原字符串中剩余字符的相对位置不能发生改变。

在所有满足条件的结果中，请输出字典序最小的字符串。

# 输入描述

输入一行字符串 $s$，表示给定的字符串。

### 约束

$1 \le |s| \le 10^4$

字符串 $s$ 仅由小写英文字母组成。

# 输出描述

输出一个字符串，表示删除重复字母后得到的字典序最小结果。

要求结果中的每个字母只出现一次，并且不能改变剩余字符在原字符串中的相对位置。

## 样例1

**输入**

```text
bcabc
```

**输出**

```text
abc
```

**说明**

字符串 $s$ 中包含字母 $a$、$b$、$c$。

删除重复字母后，可以得到多个满足每个字母只出现一次的结果。

其中 $abc$ 的字典序最小，因此输出 $abc$。

## 样例2

**输入**

```text
cbacdcbc
```

**输出**

```text
acdb
```

**说明**

字符串 $s$ 中包含字母 $a$、$b$、$c$、$d$。

在保证每个字母只出现一次，并且不改变剩余字符相对位置的情况下，字典序最小的结果为 $acdb$。
