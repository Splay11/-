# 题目内容

给定一个只包含三种字符的字符串 $s$，其中字符只可能是左括号 $($、右括号 $)$ 或星号 $*$。

请判断字符串 $s$ 是否可以表示一个有效的括号字符串。

有效括号字符串需要满足以下规则：

* 每一个左括号 $($ 都必须有一个对应的右括号 $)$。
* 每一个右括号 $)$ 都必须有一个对应的左括号 $($。
* 对于任意一对相匹配的括号，左括号 $($ 必须出现在对应的右括号 $)$ 之前。
* 每个星号 $*$ 都可以被视为一个左括号 $($、一个右括号 $)$，或者一个空字符串。

如果通过合理地解释所有星号 $*$，可以使字符串成为有效的括号字符串，则输出 $true$；否则输出 $false$。

# 输入描述

输入一行字符串 $s$，表示需要判断的字符串。

### 约束

$1 \le |s| \le 100$

$s_i$ 只可能是 $($、$)$ 或 $*$。

# 输出描述

如果字符串 $s$ 可以通过合理解释星号 $*$ 变成有效的括号字符串，输出 $true$。

否则输出 $false$。

## 样例1

**输入**

```text
()
```

**输出**

```text
true
```

**说明**

字符串本身就是一个有效的括号字符串，因此输出 $true$。

## 样例2

**输入**

```text
(*)
```

**输出**

```text
true
```

**说明**

可以将星号 $*$ 视为空字符串，此时原字符串变为 $()$。

$()$ 是有效的括号字符串，因此输出 $true$。

## 样例3

**输入**

```text
(*))
```

**输出**

```text
true
```

**说明**

可以将星号 $*$ 视为一个左括号 $($，此时原字符串变为 $(())$。

$(())$ 是有效的括号字符串，因此输出 $true$。
