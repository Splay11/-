# 题目内容

给定一个仅由小写英文字母组成的字符串 $s$。

每次可以执行一次重复项删除操作：选择字符串中两个相邻且相同的字母，并将它们同时删除。

需要在字符串 $s$ 上反复执行重复项删除操作，直到无法继续删除为止。

请输出完成所有删除操作后得到的最终字符串。

题目保证最终答案唯一。

# 输入描述

输入一行字符串 $s$，表示给定的字符串。

### 约束

$1 \le |s| \le 10^5$

字符串 $s$ 仅由小写英文字母组成。

# 输出描述

输出一行字符串，表示反复删除相邻且相同的两个字符后得到的最终结果。

## 样例1

**输入**

```text
abbaca
```

**输出**

```text
ca
```

**说明**

对于字符串 $abbaca$，首先可以删除相邻且相同的 $bb$，得到字符串 $aaca$。

此时可以继续删除相邻且相同的 $aa$，得到字符串 $ca$。

字符串 $ca$ 中已经不存在相邻且相同的字符，因此最终结果为 $ca$。

## 样例2

**输入**

```text
azxxzy
```

**输出**

```text
ay
```

**说明**

首先删除相邻且相同的 $xx$，得到字符串 $azzy$。

随后删除相邻且相同的 $zz$，得到字符串 $ay$。

此时已经无法继续执行删除操作，因此最终结果为 $ay$。
