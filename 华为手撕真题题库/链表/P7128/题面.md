# 题目内容

给定一个包含 $n$ 个节点的单链表和一个非负整数 $k$，请将链表向右旋转 $k$ 个位置。

每次向右旋转 $1$ 个位置时，链表的最后一个节点会移动到链表的最前面，其余节点依次向后移动。

例如，链表中的节点值依次为 $1,2,3,4,5$，向右旋转 $1$ 个位置后变为 $5,1,2,3,4$；再向右旋转 $1$ 个位置后变为 $4,5,1,2,3$。

请输出链表向右旋转 $k$ 个位置后的节点值序列。

# 输入描述

第一行输入两个整数 $n$ 和 $k$，分别表示链表中的节点数量和向右旋转的位置数。

第二行输入 $n$ 个整数 $a_i$，表示链表从头节点到尾节点的节点值，相邻整数之间用空格分隔。

当 $n=0$ 时，第二行可以省略。

### 约束

$0 \le n \le 500$

$-100 \le a_i \le 100$

$0 \le k \le 2 \times 10^9$

# 输出描述

输出链表向右旋转 $k$ 个位置后的节点值，相邻整数之间用空格分隔。

如果链表为空，则输出空行。

## 样例1

**输入**

```text
5 2
1 2 3 4 5
```

**输出**

```text
4 5 1 2 3
```

**说明**

原链表为 $1,2,3,4,5$。

向右旋转 $1$ 个位置后，链表变为 $5,1,2,3,4$。

再次向右旋转 $1$ 个位置后，链表变为 $4,5,1,2,3$。

因此向右旋转 $2$ 个位置后的结果为 $4,5,1,2,3$。

## 样例2

**输入**

```text
3 4
0 1 2
```

**输出**

```text
2 0 1
```

**说明**

原链表为 $0,1,2$。

向右旋转 $3$ 个位置后，链表恢复为原来的顺序 $0,1,2$。

再向右旋转 $1$ 个位置后，链表变为 $2,0,1$。

因此向右旋转 $4$ 个位置后的结果为 $2,0,1$。
