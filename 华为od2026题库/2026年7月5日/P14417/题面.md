# 二叉树两节点间的最小跳数

# 题目内容

某公司用二叉树来管理服务，用两节点间的跳数来表示两微服务之间的关联关系；所以需要你写一段代码，在给定二叉树中，找到该树中两个指定节点间的最小跳数（边数）。

树采用层序遍历序列表示法表示，树的节点不重名，节点数量范围为 $1 \leq n \leq 10^6$，节点名称用字符串表示；`frm` 和 `to` 节点不为空；若两节点不可达或不存在，则返回 $-1$。

# 输入描述

输入包含：
- 一棵二叉树的层序遍历序列 `treeLevelOrder`，使用逗号分隔节点值，空节点用 `null` 表示；
- 两个节点名称 `frm` 和 `to`。

# 输出描述

输出一个整数，表示从节点 `frm` 到节点 `to` 的最小跳数（边数）。
若两节点不可达或节点不存在，则输出 `-1`。

# 补充说明

层序遍历序列表示法为按树的从上到下、从左到右的顺序依次输出节点。例如：

```
1,2,3,null,null,4,5,null,null,6
```

对应的树结构如下图：

## 样例1

**输入**

```
["3,5,1,6,2,0,8,null,null,7,4","5","1"]
```

**输出**

```
2
```

**说明**

从节点 `5` 到 `3` 再从 `3` 到 `1` 共 `2` 跳。


![](file://t_y8dcuYrG7wSUJWnRnj7.png)

## 样例2

**输入**

```
["3,5,1,6,2,0,8,null,null,7,4","5","4"]
```

**输出**

```
2
```

**说明**

从 `5` 到 `2`，再从 `2` 到 `4`，共 `2` 跳。

![](file://t_y8dcuYrG7wSUJWnRnj7.png)

## 样例3

**输入**

```
["1,2,3,4,5,6,7","2","10"]
```

**输出**

```
-1
```

**说明**

树中不存在节点 `10`。
