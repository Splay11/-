## 解题思路

本题是在一维序列上 **选 $m$ 个位置**，使相邻被选下标之差的绝对值 $\ge k$，并 **最大化需求和**。等价于：若按从小到大选下标 $i_1 < i_2 < \cdots < i_m$，则要求 $i_{t+1} - i_t \ge k$（$0$-based 同样成立）。

**动态规划**：设 $dp[i][c]$ 表示在前缀 $0\sim i$ 中恰好选 $c$ 个充电站，且 **最后一个** 选在位置 $i$ 时的最大总和。

- 初始化：$dp[i][1] = \texttt{demands}[i]$；
- 转移（$c \ge 2$）：上一个站必须在 $i-k$ 及之前，
  $$dp[i][c] = \texttt{demands}[i] + \max_{0 \le j \le i-k} dp[j][c-1]$$
- 答案：$\max_i dp[i][m]$。

用数组 `best[c]` 维护「已滑出窗口」的 $\max dp[j][c]$：当扫描到 $i$ 时，先把 $dp[i-k][\cdot]$ 并入 `best`，再更新当前行，可将复杂度降为 **$O(n \cdot m)$**。

**常见假解**：

- **贪心按需求从大到小选**：忽略间距约束，样例 1 会错；
- **只取全局前 $m$ 大**：相邻高峰可能距离 $< k$，组 5、6 可 hack；
- **把 $k$ 当成「中间至少隔 $k-1$ 个未选」理解错**：与题面 $|i-j|\ge k$ 不一致。

## 复杂度分析

- 时间：$O(n \cdot m)$，$n \le 2000$，$m \le 200$，约 $4\times 10^5$ 次运算；
- 空间：$O(n \cdot m)$ 存 DP 表（可滚动优化到 $O(m)$，标程保留二维便于理解）。

```python
from typing import List


class Solution:
    def maxChargingDemand(self, n: int, m: int, k: int, demands: List[int]) -> int:
        neg = -(10**18)
        dp = [[neg] * (m + 1) for _ in range(n)]
        best = [neg] * (m + 1)
        ans = 0

        for i in range(n):
            # 将下标 i-k 的 DP 行并入窗口最大值
            if i >= k:
                for c in range(1, m + 1):
                    best[c] = max(best[c], dp[i - k][c])
            dp[i][1] = demands[i]
            for c in range(2, m + 1):
                if best[c - 1] != neg:
                    dp[i][c] = best[c - 1] + demands[i]
            ans = max(ans, dp[i][m])

        return ans
```

```c
#include <limits.h>
#include <stdlib.h>

int maxChargingDemand(int n, int m, int k, int* demands) {
    const long long NEG = LLONG_MIN / 4;
    long long** dp = (long long**)malloc(n * sizeof(long long*));
    long long* best = (long long*)malloc((m + 1) * sizeof(long long));
    for (int i = 0; i < n; i++) {
        dp[i] = (long long*)malloc((m + 1) * sizeof(long long));
        for (int c = 0; c <= m; c++) dp[i][c] = NEG;
    }
    for (int c = 0; c <= m; c++) best[c] = NEG;

    long long ans = 0;
    for (int i = 0; i < n; i++) {
        // 将下标 i-k 的 DP 行并入窗口最大值
        if (i >= k) {
            for (int c = 1; c <= m; c++) {
                if (dp[i - k][c] > best[c]) best[c] = dp[i - k][c];
            }
        }
        dp[i][1] = demands[i];
        for (int c = 2; c <= m; c++) {
            if (best[c - 1] != NEG) {
                dp[i][c] = best[c - 1] + demands[i];
            }
        }
        if (dp[i][m] > ans) ans = dp[i][m];
    }

    for (int i = 0; i < n; i++) free(dp[i]);
    free(dp);
    free(best);
    return (int)ans;
}
```
