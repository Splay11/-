## 解题思路

这道题的核心是按照题意直接生成数列，因此使用的算法就是模拟。

已知：

* 前 $M$ 项固定为 $1$ 到 $M$
* 从第 $M+1$ 项开始，每一项都只和前面连续的 $M$ 项有关

所以最直接的方法就是：

1. 先把前 $M$ 项加入数组
2. 若 $N \le M$，直接返回第 $N$ 项
3. 否则从第 $M+1$ 项开始逐项模拟：

   * 取出前面连续的 $M$ 个数
   * 判断这 $M$ 个数中是否有重复
   * 同时求出这 $M$ 个数的最大值和最小值
   * 如果有重复，当前项为最大值与最小值之和
   * 如果无重复，当前项为最大值与最小值之差
4. 一直生成到第 $N$ 项即可

## 复杂度分析

设一共需要生成到第 $N$ 项。

每生成一项，都需要检查前面的 $M$ 个数：

* 判断是否有重复，需要遍历这 $M$ 个数
* 求最大值和最小值，也需要遍历这 $M$ 个数

所以生成一项的时间复杂度是 $O(M)$。

总共最多生成 $N-M$ 项，因此总时间复杂度为：

$O(N \times M)$

空间上需要保存整个数列，共保存到第 $N$ 项，因此空间复杂度为：

$O(N)$

由于题目范围很小，$M \le 10$，$N \le 50$，这个复杂度完全足够。

```python
class Solution:
    def getNthValue(self, M: int, N: int) -> int:
        # 前 M 项固定为 1 到 M
        nums = list(range(1, M + 1))

        # 如果第 N 项在前 M 项中，直接返回
        if N <= M:
            return nums[N - 1]

        # 从第 M+1 项开始模拟生成
        while len(nums) < N:
            window = nums[-M:]  # 取前面的 M 项

            # 记录是否有重复，同时维护最大值和最小值
            seen = set()
            has_dup = False
            mx = window[0]
            mn = window[0]

            for x in window:
                # 判断是否重复
                if x in seen:
                    has_dup = True
                seen.add(x)

                # 更新最大值和最小值
                if x > mx:
                    mx = x
                if x < mn:
                    mn = x

            # 按题意生成当前项
            if has_dup:
                nums.append(mx + mn)
            else:
                nums.append(mx - mn)

        return nums[N - 1]
```

```java
    public int getNthValue(int M, int N) {
        // 前 M 项固定为 1 到 M
        java.util.List<Integer> nums = new java.util.ArrayList<>();
        for (int i = 1; i <= M; i++) {
            nums.add(i);
        }

        if (N <= M) {
            return nums.get(N - 1);
        }

        // 从第 M+1 项开始模拟生成
        while (nums.size() < N) {
            java.util.HashSet<Integer> seen = new java.util.HashSet<>();
            boolean hasDup = false;

            int mx = nums.get(nums.size() - M);
            int mn = nums.get(nums.size() - M);

            // 检查前面的 M 项
            for (int i = nums.size() - M; i < nums.size(); i++) {
                int x = nums.get(i);

                // 判断是否重复
                if (seen.contains(x)) {
                    hasDup = true;
```

```c
int getNthValue(int M, int N) {
    // 前 M 项固定为 1 到 M
    int nums[50];
    for (int i = 0; i < M; i++) {
        nums[i] = i + 1;
    }

    // 如果第 N 项在前 M 项中，直接返回
    if (N <= M) {
        return nums[N - 1];
    }

    // 从第 M+1 项开始模拟生成
    int size = M;
    while (size < N) {
        int start = size - M;
        int mx = nums[start];
        int mn = nums[start];
        int has_dup = 0;

        // 更新最大值和最小值
        for (int i = start; i < size; i++) {
            int x = nums[i];
            if (x > mx) mx = x;
            if (x < mn) mn = x;
        }

        // 检查是否有重复值（M <= 10，双重循环即可）
        for (int i = start; i < size && !has_dup; i++) {
            for (int j = i + 1; j < size && !has_dup; j++) {
                if (nums[i] == nums[j]) {
                    has_dup = 1;
                }
            }
        }

        // 按题意生成当前项
        if (has_dup) {
            nums[size++] = mx + mn;
        } else {
            nums[size++] = mx - mn;
        }
    }

    return nums[N - 1];
}
```
