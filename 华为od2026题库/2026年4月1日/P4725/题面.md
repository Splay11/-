## 题目描述

1、输入$M$、$N$两个数，则按照以下规则形成一个数列；

2、数列的前$M$个元素的值为$1$到$M$；

3、从$M+1$个元素开始，计算的逻辑为：

* 如果其前面的$M$个元素中，存在值相同的元素，则该位置上的数值等于前面$M$个数中最大的数值与最小的数值之和；
* 如果其前面的$M$个元素中，不存在值相同的元素，则该位置上的数值等于前面$M$个数中最大的数值与最小的数值之差；

请计算该数列第$N$个位置上的数值

## 补充说明

$M$取值范围：$3<=M<=10$

$N$取值范围：$1<=N<=50$

## 样例1

### 输入
```
5,1
```
### 输出
```
1
```
## 样例2

### 输入
```
5,5
```
### 输出
```
5
```
## 样例3

### 输入
```
5,6
```
### 输出
```
4
```
## 样例4

### 输入
```
5,7
```
### 输出
```
7
```
## 样例5

### 输入
```
5,8
```
### 输出
