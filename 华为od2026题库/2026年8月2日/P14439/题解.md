## 解题思路

本题的核心是对电池容量进行**分段线性修正**，再结合**场景修正系数**和**基础损耗系数**计算最终续航里程。

**算法**：分段计算 + 数学公式

**核心思路**：

1. **向下取整**：将输入的 `capacity` 向下取整得到整数容量 `c`。
2. **分段修正**：将 `c` 按 [160, ∞)、[80, 160)、[0, 80] 三个区间分段，各段分别乘以对应的修正系数（1.0 / 0.98 / 0.95），求和得到等效容量。
   - 零段容量 = max(0, c - 160) × 1.0
   - 一段容量 = max(0, min(c, 160) - 80) × 0.98
   - 二段容量 = min(c, 80) × 0.95
3. **理论续航**：等效容量 / 能耗效率 × 100，中间结果四舍五入保留 4 位小数。
4. **总体损耗系数**：基础损耗 0.956 × 场景修正系数 kc（城市=1，高速=0.92，山路=0.85），保留 4 位小数。
5. **最终结果**：理论续航 × 总体损耗系数，四舍五入为整数。

**时间复杂度**：O(1)，仅涉及常数次算术运算。
**空间复杂度**：O(1)，仅使用常数个变量。

## 复杂度分析

- **时间复杂度**：O(1)。算法仅执行常数次四则运算、取整和四舍五入操作，与输入规模无关。
- **空间复杂度**：O(1)。仅需要常数个变量存储中间计算结果。

```python
import math


class Solution:
    def calculateRange(self, capacity: float, efficiency: float, scene: int) -> int:
        # 电池容量向下取整
        c = int(math.floor(capacity))

        # 分段计算等效容量：零段(>=160)*1 + 一段(80~160)*0.98 + 二段(<=80)*0.95
        seg0 = max(0, c - 160) * 1.0
        seg1 = max(0, min(c, 160) - 80) * 0.98
        seg2 = min(c, 80) * 0.95
        equivalent_capacity = seg0 + seg1 + seg2

        # 理论续航里程 = 等效容量 / 能耗效率 * 100，保留4位小数
        theoretical_range = round(equivalent_capacity / efficiency * 100.0, 4)

        # 场景修正系数：城市=1，高速=0.92，山路=0.85
        kc = [1.0, 0.92, 0.85][scene]

        # 总体损耗系数 = 基础损耗 * 场景修正，保留4位小数
        kd = round(0.956 * kc, 4)

        # 有效续航里程 = 理论续航 * 总体损耗系数，四舍五入为整数
        return round(theoretical_range * kd)
```
