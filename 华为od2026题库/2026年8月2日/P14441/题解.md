## 解题思路

本题的核心是将「是否使用爆发」和「爆发窗口放在哪里」两个决策解耦。

**关键观察：**

1. **爆发窗口独立为一段**：爆发窗口覆盖连续的 $w$ 个技能，自身构成一段（消耗一次爆发机会）。窗口内的能量上限变为 $2k$，但技能数量限制 $m$ 依然生效（要求 $w \leq m$）。
2. **普通模式贪心**：在普通模式下（能量上限 $k$，段内技能数 $\leq m$），每一段应该尽可能多地放入技能——当加入下一个技能会超出能量上限或数量上限时，就开启新的一段。这种贪心策略对于固定序列是最优的。
3. **前后缀分解**：枚举爆发窗口的起始位置 $left$，则答案可以拆解为：
   - 窗口**左侧** $a[0:left]$ 用普通模式释放的最少分段数（`pre[left]`）
   - 爆发窗口自身占用 $1$ 段
   - 窗口**右侧** $a[left+w:n]$ 用普通模式释放的最少分段数（`suf[left+w]`）
   
   总段数 = `pre[left] + 1 + suf[left+w]`。

4. **边界处理**：
   - 若存在技能能耗 $> 2k$，无解。
   - 普通模式下，若技能能耗 $> k$，则该位置无法被普通段覆盖，前后缀 `pre`/`suf` 在此处停止扩展（值保持为 $\infty$）。
   - 爆发窗口要求 $w \leq m$，否则无法使用爆发。

**算法流程：**

1. 特判无解：$\exists\ a[i] > 2k \Rightarrow -1$。
2. 从左到右贪心预处理 `pre` 数组：`pre[i]` = 释放前 $i$ 个技能的最少段数。
3. 从右到左贪心预处理 `suf` 数组：`suf[i]` = 释放 $a[i:]$ 的最少段数。
4. 初始答案 = `pre[n]`（不使用爆发）。
5. 若 $w \leq m$，滑动窗口枚举爆发位置，用 `pre[left] + 1 + suf[right]` 更新答案。
6. 返回答案（若仍为 $\infty$ 则返回 $-1$）。

## 复杂度分析

- **时间复杂度**：$O(n)$。预处理 `pre` 和 `suf` 各需一次线性扫描，枚举爆发窗口也是线性滑动窗口，总复杂度 $O(n)$。
- **空间复杂度**：$O(n)$。需要两个长度为 $n+1$ 的辅助数组 `pre` 和 `suf`。

from typing import List


class Solution:
    def minSkillSegments(self, k: int, m: int, w: int, a: List[int]) -> int:
        n = len(a)
        INF = n + 1

        # 若存在技能能耗超过 2k，即使爆发也无法释放
        if any(x > 2 * k for x in a):
            return -1

        # pre[i]：普通模式下释放前 i 个技能的最少分段数
        pre = [INF] * (n + 1)
        pre[0] = 0
        segments = 0
        curSum = 0
        curCnt = 0
        for i, energy in enumerate(a):
            # 技能能耗超过 k 时，普通模式无法处理，停止扩展
            if energy > k:
                break
            # 新段开始：当前段为空、达到技能数上限、或加入后能量超限
            if curCnt == 0 or curCnt == m or curSum + energy > k:
                segments += 1
                curSum = energy
                curCnt = 1
            else:
                curSum += energy
                curCnt += 1
            pre[i + 1] = segments

        # suf[i]：普通模式下释放 a[i:] 的最少分段数（从后往前）
        suf = [INF] * (n + 1)
        suf[n] = 0
        segments = 0
        curSum = 0
        curCnt = 0
        for i in range(n - 1, -1, -1):
            energy = a[i]
            # 技能能耗超过 k 时，普通模式无法处理
            if energy > k:
                break
            if curCnt == 0 or curCnt == m or curSum + energy > k:
                segments += 1
                curSum = energy
                curCnt = 1
            else:
                curSum += energy
                curCnt += 1
            suf[i] = segments

        # 不使用爆发
        answer = pre[n]

        # 枚举爆发窗口位置（窗口长度固定为 w）
        if w <= m:
            windowSum = sum(a[:w])
            for left in range(n - w + 1):
                right = left + w
                # 窗口内总能耗不超过 2k，且前后缀均可行
                if (windowSum <= 2 * k
                        and pre[left] != INF
                        and suf[right] != INF):
                    answer = min(answer, pre[left] + 1 + suf[right])
                # 滑动窗口：移出左端，移入右端
                if right < n:
                    windowSum += a[right] - a[left]

        return -1 if answer == INF else answer
