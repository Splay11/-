## 解题思路

本题是一道**扁平化数组建模 + 区间累加**的模拟统计题，核心在于**下标映射**和**风控条件的整数化判断**，不涉及复杂算法。

**1. 数据布局与下标映射**

`warehouses` 把「仓库 × 天 × 3 个字段」压平成一维数组。由于所有仓库天数相同，可先算出每个仓库的天数：

```
days = len(warehouses) / 3 / numOfWarehouse
```

对仓库 `w`、第 `d` 天，其三元组（inCost, outRevenue, loss）的起始下标为：

```
base = (w * days + d) * 3
```

`warehouses[base]`、`warehouses[base+1]`、`warehouses[base+2]` 分别是入库成本、出库收入、当日损耗。这个映射是全题关键，写错就会把不同仓库/不同天的数据串位。

**2. 区间累加**

对每个查询 `[wid, startDay, endDay]`，在闭区间 `[startDay, endDay]` 上累加三项：`sumIn`、`sumOut`、`sumLoss`。于是：

- 累计净利润 `net = sumOut - sumIn`（注意可能为**负**）；
- 累计损耗 `totalLoss = sumLoss`。

**3. 风控条件的整数化判断（关键易错点）**

损耗率定义为 `totalLoss / (sumIn + sumOut) × 100`，风控触发条件是「损耗率 > 5%」。为避免浮点精度误差，把不等式整理为纯整数比较：

```
totalLoss / denom * 100 > 5   ⟺   totalLoss * 100 > 5 * denom   ⟺   totalLoss * 20 > denom
```

其中 `denom = sumIn + sumOut`。当 `denom == 0`（区间内成本与收入全为 0）时按 `totalLoss > 0` 判定，属边界保护。

每个查询产出一行 `[net, totalLoss, risk]`，收集所有查询结果即为答案。

## 复杂度分析

设查询数为 `q`，单次查询区间长度不超过天数 `D`（≤ 100）。

- **时间复杂度**：`O(q × D)`。每个查询遍历其区间一次；本题 `q ≤ 100`、`D ≤ 100`，规模很小。若需要更快可对每个仓库预处理前缀和，将单次查询降为 `O(1)`，但本数据范围下直接累加已足够。
- **空间复杂度**：`O(q)`（仅存放结果），不计输入本身。

```python
from typing import List


class Solution:
    def getWarehouseReport(self, warehouses: List[int], queries: List[List[int]], numOfWarehouse: int) -> List[List[int]]:
        # 每个仓库的天数 = 总记录条数 / 3 / 仓库数
        total = len(warehouses) // 3
        days = total // numOfWarehouse if numOfWarehouse > 0 else 0
        res = []
        for wid, s, e in queries:
            sum_in = sum_out = sum_loss = 0
            # 在闭区间 [s, e] 上累加该仓库每天的三项数据
            for d in range(s, e + 1):
                base = (wid * days + d) * 3  # 下标映射：定位到 (仓库 wid, 第 d 天)
                sum_in += warehouses[base]
                sum_out += warehouses[base + 1]
                sum_loss += warehouses[base + 2]
            net = sum_out - sum_in           # 净利润可能为负
            denom = sum_in + sum_out
            # 损耗率 > 5% 等价于 sum_loss*20 > denom（整数比较，规避浮点误差）
            if denom == 0:
                risk = 1 if sum_loss > 0 else 0
            else:
                risk = 1 if sum_loss * 20 > denom else 0
            res.append([net, sum_loss, risk])
        return res
```

class Solution {
    public int[][] getWarehouseReport(int[] warehouses, int[][] queries, int numOfWarehouse) {
        // 每个仓库的天数 = 总记录条数 / 3 / 仓库数
        int total = warehouses.length / 3;
        int days = numOfWarehouse > 0 ? total / numOfWarehouse : 0;
        int[][] res = new int[queries.length][3];
        for (int i = 0; i < queries.length; i++) {
            int wid = queries[i][0], s = queries[i][1], e = queries[i][2];
            long sumIn = 0, sumOut = 0, sumLoss = 0;
            // 在闭区间 [s, e] 上累加该仓库每天的三项数据
            for (int d = s; d <= e; d++) {
                int base = (wid * days + d) * 3; // 下标映射：定位到 (仓库 wid, 第 d 天)

                sumOut += warehouses[base + 1];
                sumLoss += warehouses[base + 2];

            res[i][1] = (int) sumLoss;
            res[i][2] = risk;
        }

    }

/**
