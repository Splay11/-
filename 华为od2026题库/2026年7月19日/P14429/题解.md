## 解题思路

本题可抽象为**加权区间调度（Weighted Interval Scheduling）**问题：

- 每位乘客对应一个区间 `[s, e)`，其权重（收益）为 `e − s`（乘车距离）。
- 两个区间兼容的条件是 `end_i ≤ start_j`（半开区间，端点相接不算重叠，如样例 1 中 `[0,3]` 与 `[3,8]` 可同时选）。
- 目标：在互不重叠的区间集合中，选出总权重最大的一组。

由于区间权重恰好等于其长度，一个常见的错误思路是「贪心选最早结束 / 选最长区间」。这两种贪心在带权场景下都会失败（见下方 hack 分析），因此必须使用动态规划。

**核心算法**：将所有区间按**结束时刻升序**排序，设排序后第 `i` 个区间为 `intervals[i] = [s, e)`，定义：

- `dp[i]`：只考虑前 `i` 个区间（按结束时刻排序）时能获得的最大收益。
- 对于第 `i` 个区间，有两种选择：
  - **不选它**：收益为 `dp[i]`（沿用前 `i−1` 个区间的最优解）。
  - **选它**：需找到在它之前、且与它兼容的区间集合的最优解。由于已按结束时刻排序，兼容的前缀就是「结束时刻 ≤ `s`」的那些区间，其数量为 `p`；这部分最优解为 `dp[p]`。于是选它的收益为 `w + dp[p]`，其中 `w = e − s`。
- 状态转移：`dp[i+1] = max(dp[i], w + dp[p])`。

`p` 可通过在已排序的结束时刻数组上二分查找（或线性扫描，因 `m ≤ 300` 规模很小）得到。

## 复杂度分析

- **时间复杂度**：`O(m log m)`。排序占 `O(m log m)`；之后每个区间二分查找兼容前缀占 `O(log m)`，共 `O(m log m)`。
- **空间复杂度**：`O(m)`。需要存储排序后的区间、结束时刻数组与 `dp` 数组。

> 由于乘客数量 `m ≤ 300`、终点 `n < 1000`，该复杂度非常宽裕；即便用 `O(m²)` 的线性扫描求 `p` 也完全够用。

```python
from typing import *

class Solution:
    def maxRideProfit(self, n: int, passengers: List[List[int]]) -> int:
        if not passengers:
            return 0
        # 按结束时刻升序排序，保证前缀性质：前面的区间结束得更早
        intervals = sorted(passengers, key=lambda x: x[1])
        m = len(intervals)
        ends = [intervals[i][1] for i in range(m)]  # 仅保留结束时刻，便于查找兼容前缀

        # dp[i] 表示前 i 个区间能获得的最大收益
        dp = [0] * (m + 1)
        for i in range(m):
            s, e = intervals[i][0], intervals[i][1]
            w = e - s  # 当前区间的权重（乘车距离）
            # p：在 i 之前、结束时刻 <= s 的区间个数，即与当前区间兼容的前缀长度
            p = 0
            while p < i and ends[p] <= s:
                p += 1
            take = w + dp[p]        # 选择当前区间
            dp[i + 1] = max(dp[i], take)  # 不选 / 选，取较大者
        return dp[m]
```

```java
class Solution {
    public int maxRideProfit(int n, List<List<Integer>> passengers) {
        if (passengers == null || passengers.isEmpty()) return 0;
        // 转为 int[] 并按结束时刻升序排序
        List<int[]> intervals = new ArrayList<>();
        for (List<Integer> p : passengers) {
            intervals.add(new int[]{p.get(0), p.get(1)});
        }
        intervals.sort((a, b) -> Integer.compare(a[1], b[1]));
        int m = intervals.size();
        int[] ends = new int[m];
        for (int i = 0; i < m; i++) ends[i] = intervals.get(i)[1];

        // dp[i] 表示前 i 个区间的最大收益
        int[] dp = new int[m + 1];
        for (int i = 0; i < m; i++) {
            int s = intervals.get(i)[0], e = intervals.get(i)[1];
            int w = e - s; // 当前区间权重
            // p：结束时刻 <= s 的兼容前缀长度
            int p = 0;
            while (p < i && ends[p] <= s) p++;
            int take = w + dp[p];       // 选择当前区间
            dp[i + 1] = Math.max(dp[i], take); // 不选 / 选
        }
        return dp[m];
    }
}
```

```c
// qsort 比较函数：按区间终点（第 2 列）升序
static int cmp(const void* a, const void* b) {
    int* x = *(int**)a;
    int* y = *(int**)b;
    return x[1] - y[1];
}

int maxRideProfit(int n, int** passengers, int passengersSize, int* passengersColSize) {
    if (passengersSize == 0) return 0;
    // 按结束时刻升序排序
    qsort(passengers, passengersSize, sizeof(int*), cmp);
    int* ends = (int*)malloc(passengersSize * sizeof(int));
    for (int i = 0; i < passengersSize; i++) ends[i] = passengers[i][1];

    // dp[i] 表示前 i 个区间的最大收益
    int* dp = (int*)calloc(passengersSize + 1, sizeof(int));
    for (int i = 0; i < passengersSize; i++) {
        int s = passengers[i][0], e = passengers[i][1];
        int w = e - s; // 当前区间权重
        // p：结束时刻 <= s 的兼容前缀长度
        int p = 0;
        while (p < i && ends[p] <= s) p++;
        int take = w + dp[p];                  // 选择当前区间
        dp[i + 1] = dp[i] > take ? dp[i] : take; // 不选 / 选
    }
    int ans = dp[passengersSize];
    free(ends);
    free(dp);
    return ans;
}
```
