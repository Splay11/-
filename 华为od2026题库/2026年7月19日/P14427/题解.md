## 解题思路

服务记录 `record` 仅包含小写字母 `a-z`，最多只有 `26` 种不同的服务类型。题目要求找出**出现次数大于 1** 的类型，并且结果必须按照这些类型在 `record` 中**首次出现**的顺序排列。

因此，核心思路分为两步：

1. **统计与定位**：遍历一次字符串，用长度为 `26` 的数组统计每个字符出现次数，并记录每个字符的**首次出现位置**。
2. **按首次出现顺序收集**：再次遍历字符串，当遍历到某个字符时，若当前位置恰好是该字符的首次出现位置，且该字符出现次数大于 `1`，则将其加入结果。

由于只涉及 `26` 个字母，计数和定位都可以用固定大小的数组完成，空间复杂度为 $O(1)$。

## 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 为字符串 `record` 的长度。算法对字符串进行两次线性遍历。
- **空间复杂度**：$O(1)$，仅使用长度为 `26` 的计数数组和首位置数组。

```python
from typing import List

class Solution:
    def findRepeatedServiceTypes(self, record: str) -> List[str]:
        # 统计每个字符出现次数，并记录首次出现位置
        cnt = [0] * 26
        first = [-1] * 26
        for i, ch in enumerate(record):
            idx = ord(ch) - ord('a')
            if cnt[idx] == 0:
                first[idx] = i
            cnt[idx] += 1
        # 按原串中首次出现顺序收集出现次数大于 1 的字符
        res = []
        for i, ch in enumerate(record):
            idx = ord(ch) - ord('a')
            if first[idx] == i and cnt[idx] > 1:
                res.append(ch)
        return res
```

```java
class Solution {
    public List<Character> findRepeatedServiceTypes(String record) {
        // 统计每个字符出现次数，并记录首次出现位置
        int[] cnt = new int[26];

        }
        return res;
    }
}
```

```c
#include <stdlib.h>

char** findRepeatedServiceTypes(char* record, int* returnSize) {
    // 统计每个字符出现次数，并记录首次出现位置
    int cnt[26] = {0};
    int first[26];
    for (int i = 0; i < 26; i++) first[i] = -1;
    for (int i = 0; record[i]; i++) {
        int idx = record[i] - 'a';
        if (cnt[idx] == 0) first[idx] = i;
        cnt[idx]++;
    }
    // 最多 26 个不同字母重复
    char** res = (char**)malloc(26 * sizeof(char*));
    int n = 0;
    // 按原串中首次出现顺序收集出现次数大于 1 的字符
    for (int i = 0; record[i]; i++) {
        int idx = record[i] - 'a';
        if (first[idx] == i && cnt[idx] > 1) {
            res[n] = (char*)malloc(2);
            res[n][0] = record[i];
            res[n][1] = '\0';
            n++;
        }
    }
    *returnSize = n;
    return res;
}
```
