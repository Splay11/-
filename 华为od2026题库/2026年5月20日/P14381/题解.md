## 解题思路

本题要求 **必须为恰好 `N` 次查询选择模型**，并且总延迟不能超过 `T`，目标是最大化总准确率。

同一个模型可以被多次选择，因此每一次查询都可以从所有模型中重新选择一个模型。

可以使用 **动态规划**。

定义状态：

```text
dp[i][t] 表示完成 i 次查询，恰好使用 t 时间时，可以获得的最大总准确率
```

初始化：

```text
dp[0][0] = 0
```

其余状态初始化为不可达。

状态转移：

对于第 `i` 次查询，可以选择任意一个模型 `j`：

```text
dp[i][t] = max(dp[i][t], dp[i - 1][t - latency[j]] + accuracy[j])
```

最后答案是：

```text
max(dp[N][0...T])
```

如果无法完成恰好 `N` 次查询，则返回 `0`。


## 复杂度分析

设模型数量为 `M`。

时间复杂度：

```text
O(N * T * M)
```

原因是需要枚举查询次数、时间预算以及每个模型。

空间复杂度：

```text
O(N * T)
```

使用二维动态规划数组保存状态。

在题目限制下，`N <= 10`，`T < 100`，`M <= 10`，该复杂度完全可以接受。

```python
from typing import List

class Solution:
    def maxTotalAccuracy(self, N: int, T: int, accuracy: List[int], latency: List[int]) -> int:
        # dp[i][t] 表示完成 i 次查询且恰好用时 t 时的最大准确率
        dp = [[-1] * (T + 1) for _ in range(N + 1)]
        dp[0][0] = 0

        for i in range(1, N + 1):
            for t in range(T + 1):
                for j in range(len(accuracy)):
                    cost = latency[j]

                    # 当前时间足够，且上一个状态可达
                    if t >= cost and dp[i - 1][t - cost] != -1:
                        dp[i][t] = max(
                            dp[i][t],
                            dp[i - 1][t - cost] + accuracy[j]
                        )

        ans = max(dp[N])

        # 如果无法查满 N 次，返回 0
        return ans if ans != -1 else 0

```


```java
class Solution {
    public int maxTotalAccuracy(int N, int T, int[] accuracy, int[] latency) {
        int m = accuracy.length;

        // dp[i][t] 表示完成 i 次查询，恰好花费 t 时间时的最大准确率
        int[][] dp = new int[N + 1][T + 1];

        // 初始化为不可达
        for (int i = 0; i <= N; i++) {
            for (int t = 0; t <= T; t++) {
                dp[i][t] = -1;
            }
        }

        dp[0][0] = 0;

        // 枚举查询次数
        for (int i = 1; i <= N; i++) {
            // 枚举当前总耗时
            for (int t = 0; t <= T; t++) {
                // 枚举选择的模型
                for (int j = 0; j < m; j++) {
                    int cost = latency[j];
                    int value = accuracy[j];

                    // 如果当前时间足够，并且上一个状态可达
                    if (t >= cost && dp[i - 1][t - cost] != -1) {
                        dp[i][t] = Math.max(dp[i][t], dp[i - 1][t - cost] + value);
                    }
                }
            }
        }

        // 总耗时不超过 T，取完成 N 次查询的最大值
        int ans = -1;
        for (int t = 0; t <= T; t++) {
            ans = Math.max(ans, dp[N][t]);
        }

        return ans == -1 ? 0 : ans;
    }
}
```

```javascript
/**
 * @param {number} N 查询次数
 * @param {number} T 总时间预算
 * @param {number[]} accuracy 各模型准确率数组
 * @param {number[]} latency 各模型延迟数组
 * @return {number} 最大总准确率
 */
var maxTotalAccuracy = function(N, T, accuracy, latency) {
    var M = accuracy.length;

    // dp[i][t] 表示完成 i 次查询且恰好用时 t 时的最大准确率，-1 表示不可达
    var dp = new Array(N + 1);
    for (var i = 0; i <= N; i++) {
        dp[i] = new Array(T + 1);
        for (var t = 0; t <= T; t++)
            dp[i][t] = -1;
    }
    dp[0][0] = 0;

    // 枚举查询次数
    for (var i = 1; i <= N; i++) {
        // 枚举当前总耗时
        for (var t = 0; t <= T; t++) {
            // 枚举选择的模型
            for (var j = 0; j < M; j++) {
                var cost = latency[j];
                var value = accuracy[j];
                // 当前时间足够，且上一个状态可达
                if (t >= cost && dp[i - 1][t - cost] !== -1) {
                    var candidate = dp[i - 1][t - cost] + value;
                    if (candidate > dp[i][t])
                        dp[i][t] = candidate;
                }
            }
        }
    }

    // 在总耗时不超过 T 的前提下，取完成 N 次查询的最大值
    var ans = -1;
    for (var t = 0; t <= T; t++)
        if (dp[N][t] > ans)
            ans = dp[N][t];

    // 无法查满 N 次则返回 0
    return ans === -1 ? 0 : ans;
};
```

```c
/**
 * @param N 查询次数
 * @param T 总时间预算
 * @param accuracy 模型准确率数组
 * @param accuracySize 模型数量
 * @param latency 模型延迟数组
 * @return 最大总准确率
 */
int maxTotalAccuracy(int N, int T, int* accuracy, int accuracySize, int* latency) {
    // dp[i][t] 表示完成 i 次查询且恰好用时 t 时的最大准确率，-1 表示不可达
    int dp[11][100];
    for (int i = 0; i <= N; i++)
        for (int t = 0; t <= T; t++)
            dp[i][t] = -1;
    dp[0][0] = 0;

    // 枚举查询次数
    for (int i = 1; i <= N; i++) {
        // 枚举当前总耗时
        for (int t = 0; t <= T; t++) {
            // 枚举选择的模型
            for (int j = 0; j < accuracySize; j++) {
                int cost = latency[j];
                int value = accuracy[j];
                // 当前时间足够，且上一个状态可达
                if (t >= cost && dp[i - 1][t - cost] != -1) {
                    int candidate = dp[i - 1][t - cost] + value;
                    if (candidate > dp[i][t])
                        dp[i][t] = candidate;
                }
            }
        }
    }

    // 在总耗时不超过 T 的前提下，取完成 N 次查询的最大值
    int ans = -1;
    for (int t = 0; t <= T; t++)
        if (dp[N][t] > ans)
            ans = dp[N][t];

    // 无法查满 N 次则返回 0
    return ans == -1 ? 0 : ans;
}
```
