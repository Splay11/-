## 解题思路

本题可以使用 **位运算 + 模拟**。

我们只需要关注二进制中每个 `1` 出现的位置。
如果相邻两个 `1` 的位置差为 `gap`，那么它们之间 `0` 的数量就是：

```text
gap - 1
```

例如：

```text
10101
1 的位置为 0, 2, 4
相邻位置差为 2
距离 = 2 - 1 = 1
```

实现时：

1. 从低位到高位遍历 `n` 的每一位。
2. 记录所有二进制位为 `1` 的位置。
3. 如果 `1` 的数量少于 `3`，返回 `-1`。
4. 计算前两个相邻 `1` 的距离，作为标准距离。
5. 检查后续所有相邻 `1` 的距离是否都相同。
6. 如果都相同，返回该距离，否则返回 `-1`。

这里自定义 LeetCode 风格接口为：

```text
int equalDistanceBinary(int n)
```

---

## 复杂度分析

设整数 `n` 的二进制长度为 `L`。

* 时间复杂度：`O(L)`
  需要遍历 `n` 的每一位。由于 `n < 2^31 - 1`，所以最多遍历 `31` 位。

* 空间复杂度：`O(L)`
  需要存储所有二进制中 `1` 的位置。最多存储 `31` 个位置。

```python
class Solution:
    def equalDistanceBinary(self, n: int) -> int:
        positions = []
        pos = 0

        # 从低位到高位遍历二进制位
        while n > 0:
            if n & 1:
                positions.append(pos)  # 记录当前 1 的位置
            n >>= 1
            pos += 1

        # 不少于 3 个 1
        if len(positions) < 3:
            return -1

        # 计算标准距离：相邻 1 的位置差 - 1
        distance = positions[1] - positions[0] - 1

        # 检查所有相邻 1 之间的距离是否相同
        for i in range(2, len(positions)):
            cur_distance = positions[i] - positions[i - 1] - 1
            if cur_distance != distance:
                return -1

        return distance
```

class Solution {
    public int equalDistanceBinary(int n) {
        int[] positions = new int[31];
        int count = 0;
        int pos = 0;

        // 从低位到高位遍历二进制位
        while (n > 0) {

                positions[count++] = pos; // 记录当前 1 的位置
            }
            n >>= 1;
            pos++;
        }

        // 不少于 3 个 1

            return -1;
        }

        // 计算标准距离：相邻 1 的位置差 - 1

        for (int i = 2; i < count; i++) {
            int curDistance = positions[i] - positions[i - 1] - 1;
            if (curDistance != distance) {
                return -1;
            }
        }

        return distance;
    }
}
