# 题目内容

张老师组织了一场线上模拟考试，并要求考生使用学号登录网站进行考试。考试完成后张老师发现试卷提交不全，他需要找到哪些同学没有交卷。

若班级内有 $N$ 个学生，则学号从 $1$ 开始到 $N$ 结束，每个学生一个学号。一个班级内学生个数不超过 $80$，即 $0 < N \leq 80$。

请你编写一个程序，帮助张老师快速找到哪些学号的学生没有交卷。

# 输入描述

- 班级内学生数量。
- 交卷学生的学号列表，由于是按照交卷时间排序的，学号是乱序的，同时本题确保学号是合法的，不存在小于 $1$ 或大于 $N$ 的学号。

# 输出描述

- 未交卷学生的学号列表，按照学号升序排列。

## 样例1

**输入**

```
10,[1,5,3,2,6,7,8,9,10]
```

**输出**

```
[4]
```

**说明**

班级内共有 10 人，学号 1-10，学号为 4 的学生没有交卷，因此返回 `[4]`。

## 样例2

**输入**

```
10,[9,2,3,5,6,7]
```

**输出**

```
[1,4,8,10]
```

**说明**

班级内共有 10 人，学号 1-10，学号为 1,4,8,10 的学生没有交卷，因此返回 `[1,4,8,10]`。

## 样例3

**输入**

```
10,[9,1,2,4,5,3,7,8,6,10]
```

**输出**

```
[]
```

**说明**

班级内共有 10 人，学号 1-10，所有学生均进行了交卷，因此返回 `[]`。
