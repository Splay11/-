# 谁没交卷

## 解题思路

核心任务是：在 $1 \dots N$ 的连续学号中，找出「未出现」在已交卷列表里的那些学号，并按升序返回。

由于学号是连续整数且范围很小（$N \le 80$），最直观也最稳妥的做法是**标记法（桶/集合）**：

1. 用一个布尔数组（或哈希集合）`seen` 标记哪些学号已经交卷——遍历一遍已交卷列表，把出现的学号置为「已交」。
2. 再从 $1$ 到 $N$ **顺序扫描**一遍，凡是 `seen` 为假的学号，就是没交卷的，直接收集进结果。

因为第二步本身就是按学号从小到大扫描的，收集出来的结果天然就是**升序**，无需额外排序。

涉及的算法/数据结构：
- **哈希集合 / 布尔数组**：用 $O(1)$ 的查询判断某个学号是否交卷；
- **一次线性扫描**：顺序遍历即可得到升序结果，避免排序开销。

这种写法对「已交卷列表乱序、含重复、甚至为空」等输入都天然鲁棒，且不会因边界（如全部交卷、无人交卷）而出错。

## 复杂度分析

设 $N$ 为学生总数，$m$ 为已交卷人数（$m \le N$）。

- **时间复杂度**：$O(N + m)$。标记阶段遍历已交卷列表一次 $O(m)$；扫描阶段遍历 $1 \dots N$ 一次 $O(N)$。两者相加为线性，远小于本题 $N \le 80$ 的限制，非常宽裕。
- **空间复杂度**：$O(N)$（布尔数组/集合最多标记 $N$ 个学号）。若用集合实现，空间为 $O(\min(N, m))$。同样在限制内绰绰有余。

之所以是上述复杂度：标记与扫描都只各走一遍，且每次操作都是常数时间；结果数组长度最坏为 $N$（无人交卷时），不构成额外渐近开销。

```python
from typing import List


class Solution:
    def findMissingStudents(self, n: int, submitted: List[int]) -> List[int]:
        # 用集合标记已交卷的学号，查询为 O(1)
        submitted_set = set(submitted)
        result = []
        # 从 1 到 n 升序扫描，天然就是升序结果
        for sid in range(1, n + 1):
            if sid not in submitted_set:   # 没交卷则收集
                result.append(sid)
        return result
```

```java
import java.util.*;

class Solution {
    public List<Integer> findMissingStudents(int n, List<Integer> submitted) {
        // seen[x] 表示学号 x 是否已交卷
        boolean[] seen = new boolean[n + 1];
        for (int x : submitted) {
            if (x >= 1 && x <= n) seen[x] = true;  // 标记已交卷学号
        }
        List<Integer> result = new ArrayList<>();
        // 从 1 到 n 升序扫描，结果天然升序
        for (int sid = 1; sid <= n; sid++) {
            if (!seen[sid]) result.add(sid);  // 未交卷则加入结果
        }
        return result;
    }
}
```

```c
#include <stdlib.h>

/**
 * @param n 班级学生总数（学号 1..n）
 * @param submitted 已交卷的学号数组
 * @param submittedSize 已交卷人数
 * @param returnSize 返回数组长度（由实现填写）
 * @return 未交卷学号数组（升序），长度由 returnSize 给出，调用方负责 free
 */
int* findMissingStudents(int n, int* submitted, int submittedSize, int* returnSize) {
    // seen[x] 标记学号 x 是否已交卷（用 calloc 初始化为 0）
    char* seen = (char*)calloc(n + 1, sizeof(char));
    for (int i = 0; i < submittedSize; i++) {
        int x = submitted[i];
        if (x >= 1 && x <= n) seen[x] = 1;  // 标记已交卷
    }
    // 未交卷最多 n 个，预留 n+1 空间
    int* ans = (int*)malloc((n + 1) * sizeof(int));
    int cnt = 0;
    // 从 1 到 n 升序扫描，结果天然升序
    for (int sid = 1; sid <= n; sid++) {
        if (!seen[sid]) ans[cnt++] = sid;  // 未交卷则收集
    }
    free(seen);
    *returnSize = cnt;  // 回填返回数组长度
    return ans;
}
```
