# 题目内容

在日常开发中，用户输入的日期格式五花八门。现需要你编写一个程序，能够识别多种日期格式，将其统一输出为 `yyyy-mm-dd` 格式，并按日期递增顺序排列。

# 输入描述

输入为字符串数组：

| 字符串格式类型 | 示例 | 说明 |
| --- | --- | --- |
| 斜杠分隔 | 2022/01/01、2022/1/1 | 月/日可能补零也可能不补零 |
| 横杠分隔 | 2022-01-01、2022-1-1 | 月/日可能补零也可能不补零 |

注意：

1. 合法年份范围：`1000` ~ `2100`
2. 输入可能包含非法格式（即非斜杠分隔或者非横杠分隔的或者横杠和斜杠混合的均为非法格式），非法格式忽略（不参与排序和输出）
3. 不同格式的输入可能解析为同一日期，相同日期只输出一次
4. 输入数组长度在 `1` ~ `200` 范围内，且单个字符串长度不超过 `50`，即单个字符串长度在 `0` ~ `50`
5. 注意日期的合法性，如月份超过 `12` 日，二月平年有 `28` 天，闰年有 `29` 天等
6. 年份能被 `4` 整除且不能被 `100` 整除，或者能被 `400` 整除都为闰年，否则都是平年

# 输出描述

按日期递增顺序输出字符串数组，每个日期字符串输出 `yyyy-mm-dd` 格式的日期。月份和日期不足两位补前导零。

若所有输入均非法，则输出仅包含一个元素且元素为 `"NULL"` 的字符串数组。

# 输入判定规则

判断格式的优先级顺序（从高到低）：

1. 斜杠分隔：包含 `/`，按 `yyyy/mm/dd` 解析
2. 横杠分隔：包含 `-`，按 `yyyy-mm-dd` 解析

## 样例1

**输入**

```
["2022/01/01","2022-1-1","20220101","1640995200","2022/1/1","2022-01-01","2022-12-31","1641081600"]
```

**输出**

```
["2022-01-01","2022-12-31"]
```

**说明**

- `2022/01/01` 为斜杠分隔，转成 `2022-01-01`
- `2022-1-1` 为横杠分隔，但月/日需要补零，转成 `2022-01-01`
- `20220101` 非法
- `1640995200` 非法
- `2022/1/1` 为斜杠分隔，月/日需要补零，转成 `2022-01-01`
- `2022-01-01` 满足条件
- `2022-12-31` 满足条件
- `1641081600` 非法
- 调整格式后满足条件的日期经过去重排序后，输出为 `2022-01-01`、`2022-12-31`

## 样例2

**输入**

```
["2021/02/29","2021/02-20"]
```

**输出**

```
["NULL"]
```

**说明**

- 输入 `2021/02/29` 日期非法，2021 年 2 月没有 29 日
- 输入 `2021/02-20` 日期非法，斜杠和横杠混用不支持

## 样例3

**输入**

```
["1970/1/1"]
```

**输出**

```
["1970-01-01"]
```

**说明**

- `1970/1/1` 转格式后为 `1970-01-01`
