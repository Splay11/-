## 解题思路

本题要求对每一分钟的端口流量速率，找到它后面第一次出现的更大流量速率，并返回相差的分钟数。

可以使用 **单调栈** 来解决。

核心思路如下：

* 使用一个栈保存还没有找到更大流量速率的下标。
* 遍历数组 `portRates`：
  * 如果当前流量速率 `portRates[i]` 大于栈顶下标对应的流量速率，说明当前分钟就是栈顶下标之后第一个更大的流量速率。
  * 弹出栈顶下标 `idx`，并令结果数组 `ans[idx] = i - idx`。
  * 重复上述过程，直到栈为空，或者当前流量速率不大于栈顶对应流量速率。
  * 将当前下标 `i` 入栈。
* 遍历结束后，栈中剩余下标表示后面没有更大的流量速率，结果保持为 `0`。

## 复杂度分析

时间复杂度：`O(n)`

其中 `n` 是数组 `portRates` 的长度。每个下标最多入栈一次、出栈一次，因此总时间复杂度为 `O(n)`。

空间复杂度：`O(n)`

需要使用一个栈保存下标。最坏情况下，数组单调递减，所有下标都会留在栈中，因此空间复杂度为 `O(n)`。

```python
from typing import List

class Solution:
    def StatPortRates(self, portRates: List[int]) -> List[int]:
        n = len(portRates)
        ans = [0] * n
        stack = []  # 单调栈，存放还没有找到更大流量速率的下标

        for i in range(n):
            # 当前流量速率更大，说明找到了栈顶下标对应的答案
            while stack and portRates[i] > portRates[stack[-1]]:
                idx = stack.pop()
                ans[idx] = i - idx

            # 当前下标入栈，等待后面更大的流量速率
            stack.append(i)

        return ans
```

```java
            stack.push(i);
        }

    }
```

```cpp
class Solution {
public:
    vector<int> StatPortRates(vector<int>& portRates) {
        int n = portRates.size();
        vector<int> ans(n, 0);
        stack<int> st; // 单调栈，存放还没有找到更大流量速率的下标

        for (int i = 0; i < n; i++) {
            // 当前流量速率更大，说明找到了栈顶下标对应的答案
            while (!st.empty() && portRates[i] > portRates[st.top()]) {
                int idx = st.top();
                st.pop();
                ans[idx] = i - idx;
            }

            // 当前下标入栈，等待后面更大的流量速率
            st.push(i);
        }

        return ans;
    }
};
```

```javascript
/**
 * @param {number[]} portRates - 端口每分钟流量速率数组
 * @return {number[]} - 对应分钟之后出现更大流量速率的等待分钟数
 */
var StatPortRates = function(portRates) {
    const n = portRates.length;
    const result = new Array(n).fill(0);
    const stack = []; // 单调栈，存放尚未找到更大值的下标

    for (let i = 0; i < n; i++) {
        // 当前流量速率更大，则更新之前下标的等待时间
        while (stack.length && portRates[stack[stack.length - 1]] < portRates[i]) {
            const j = stack.pop();
            result[j] = i - j;
        }
        // 当前下标入栈
        stack.push(i);
    }

    return result;
};
```

```c
#include <stdlib.h>
#include <string.h>

int* StatPortRates(int* portRates, int portRatesSize, int* returnSize) {
    *returnSize = portRatesSize;
    int* result = (int*)malloc(portRatesSize * sizeof(int));
    memset(result, 0, portRatesSize * sizeof(int));
    int* stack = (int*)malloc(portRatesSize * sizeof(int));
    int top = 0; // 栈顶指针

    for (int i = 0; i < portRatesSize; i++) {
        // 当前流量速率更大，说明找到了之前栈中下标的答案
        while (top > 0 && portRates[stack[top - 1]] < portRates[i]) {
            int j = stack[--top];
            result[j] = i - j;
        }
        // 当前下标入栈
        stack[top++] = i;
    }

    free(stack);
    return result;
}
```
