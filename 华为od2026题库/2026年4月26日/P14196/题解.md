## 解题思路

本题是经典的 **区间调度问题**，目标是在若干时间区间中选择最多数量的互不重叠区间。

由于题目允许两个试玩时间连续，例如 `[2,3]` 和 `[3,4]` 可以同时安排，所以判断是否冲突时使用：

```
当前试玩开始时间 >= 上一个已安排试玩结束时间
```

核心算法使用 **贪心**：

1. 将所有试玩申请按照 `end` 结束时间从小到大排序。
2. 每次优先选择结束时间最早的试玩。
3. 维护当前已经安排的最后结束时间 `lastEnd`。
4. 遍历排序后的试玩：
   * 如果 `start >= lastEnd`，说明可以安排；
   * 安排数量加一，并更新 `lastEnd = end`。

为什么这样是正确的？

因为结束越早，后面留给其他试玩的时间越多，因此每一步选择当前能选的、结束时间最早的试玩，可以保证最终安排数量最大。


## 复杂度分析

设试玩申请数量为 `n`。

**时间复杂度：**

```
O(n log n)
```

原因是需要对所有区间按照结束时间排序，排序复杂度为 `O(n log n)`，之后遍历一次为 `O(n)`。

**空间复杂度：**

```
O(1)
```

除排序所需空间外，只使用了常数个变量。若考虑排序内部额外空间，不同语言实现可能为 `O(log n)` 或 `O(n)`。

```python
from typing import List

class Solution:
    def MaxPlayers(self, playerCount: int, playerTimeRange: List[List[int]]) -> int:
        # 按照结束时间从小到大排序
        playerTimeRange.sort(key=lambda x: x[1])

        ans = 0
        lastEnd = -1  # 记录上一次安排的结束时间

        # 遍历每个试玩时间区间
        for start, end in playerTimeRange:
            # 允许连续，所以 start 等于 lastEnd 时也可以安排
            if start >= lastEnd:
                ans += 1
                lastEnd = end  # 更新最后安排结束时间

        return ans
```

```java
import java.util.*;

public class Solution {
    public int MaxPlayers(int playerCount, int[][] playerTimeRange) {
        // 按照结束时间从小到大排序
        Arrays.sort(playerTimeRange, new Comparator<int[]>() {
            public int compare(int[] a, int[] b) {
                return Integer.compare(a[1], b[1]);
            }
        });

        int ans = 0;
        int lastEnd = -1; // 记录上次结束时间

        // 依次尝试安排每一个试玩
        for (int i = 0; i < playerCount; i++) {
            int start = playerTimeRange[i][0];
            int end = playerTimeRange[i][1];

            // 若当前试玩开始时间不早于上次结束时间，则可以安排
            if (start >= lastEnd) {
                ans++;
                lastEnd = end;
            }
        }

        return ans;
    }
}
```

```javascript
/**
 * @param {number} playerCount 试玩申请数量
 * @param {number[][]} playerTimeRange 每个试玩的开始和结束时间数组
 * @return {number} 最多可安排的试玩数量
 */
var MaxPlayers = function(playerCount, playerTimeRange) {
    if (playerTimeRange.length === 0) return 0;

    // 按结束时间从小到大排序
    playerTimeRange.sort((a, b) => a[1] - b[1]);

    let count = 1; // 至少安排一个
    let lastEnd = playerTimeRange[0][1]; // 记录上一次安排结束时间

    // 遍历剩余区间
    for (let i = 1; i < playerTimeRange.length; i++) {
        // 若当前试玩开始时间不早于上次结束时间，则可以安排
        if (playerTimeRange[i][0] >= lastEnd) {
            count++;
            lastEnd = playerTimeRange[i][1];
        }
    }

    return count;
};
```

```c
// 比较函数，用于按结束时间排序
int _cmp(const void* a, const void* b) {
    int* ia = *(int**)a;
    int* ib = *(int**)b;
    if (ia[1] != ib[1]) return ia[1] - ib[1];
    return ia[0] - ib[0];
}

int MaxPlayers(int playerCount, int** playerTimeRange, int playerTimeRangeSize) {
    if (playerTimeRangeSize == 0) return 0;

    // 按结束时间排序
    qsort(playerTimeRange, playerTimeRangeSize, sizeof(int*), _cmp);

    int count = 1;
    int lastEnd = playerTimeRange[0][1]; // 记录上一次安排的结束时间

        // 若不冲突则安排当前试玩

            count++;
            lastEnd = playerTimeRange[i][1];
```
