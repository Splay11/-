## 解题思路

本题是对一个「嵌套在数组里的 TLV 流」做**顺序解析（线性扫描）**，并统计其中出现过的不同 `tag` 种类数。核心是一个**贪心式的一次性顺序解析**：

1. 从下标 `i = 0` 开始，每次尝试读取一个 TLV：
   - 至少需要 `tag` 与 `length` 两个元素；若剩余不足两个，说明数组尾部残缺 → 格式错误，返回 `0`。
   - `length` 必须严格大于 `0`；否则不符合规范 → 返回 `0`。
2. 一个 TLV 占用的元素个数为 `2 + length`（tag + length + value），并需**补齐到 4 的倍数**。若补齐后超出数组长度，说明数据不完整 → 返回 `0`。
3. 校验该 TLV 覆盖的每一个元素（tag、length、value、padding）是否都落在 `[0, 99]` 的合法取值范围内；越界即格式错误 → 返回 `0`。
4. 若校验通过，把 `tag` 加入去重集合，并将 `i` 跳到下一个 TLV 的起点，继续解析。
5. 直到 `i` 到达数组末尾，返回去重集合的大小。

这是一个**顺序状态机 / 贪心扫描**问题：因为 TLV 长度由 `length` 唯一确定，所以每读一个 TLV 就能确定下一个 TLV 的精确起点，无需回溯；任何一次校验失败都直接判格式错误。

## 复杂度分析

- **时间复杂度**：`O(n)`。每个数组元素最多被扫描两次（一次在顺序推进 `i` 时，一次在校验 `tag/length/value/padding` 时），且每个 TLV 仅处理一次，与 TLV 个数无关。
- **空间复杂度**：`O(1)` 或 `O(U)`。去重只需记录 tag（取值范围固定 `0~99`），可用布尔数组 / 哈希集合，额外空间为常数级 `O(100)`；不使用递归，无额外栈开销。

为何是线性：每次迭代消耗的数组长度是确定的（`2 + length` 的补齐值），指针单向前进，不回退、不重复展开，因此整体与输入规模成线性关系。

```python
class Solution:
    def countDistinctTags(self, arr):
        n = len(arr)
        i = 0
        tags = set()                     # 用集合去重，统计不同 tag
        while i < n:
            # 至少需要 tag 与 length 两个元素才能构成一个 TLV
            if i + 1 >= n:
                return 0
            length = arr[i + 1]
            # length 必须严格大于 0
            if length <= 0:
                return 0
            size = 2 + length              # tag + length + value 的真实长度
            padded = (size + 3) // 4 * 4  # 向上补齐到 4 的倍数（含 padding）
            # 剩余元素不足以容纳该 TLV（含补齐部分）→ 格式错误
            if i + padded > n:
                return 0
            # 校验 tag/length/value/padding 是否都落在 [0,99]
            for j in range(i, i + padded):
                if arr[j] < 0 or arr[j] > 99:
                    return 0
            tags.add(arr[i])                # 记录当前 TLV 的 tag
            i += padded                     # 跳到下一个 TLV 起点
        return len(tags)
```

```java
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public int countDistinctTags(List<Integer> arr) {
        int n = arr.size();
        int i = 0;
        Set<Integer> tags = new HashSet<>();   // 哈希集合去重
        while (i < n) {
            if (i + 1 >= n) return 0;          // 不足 tag+length 两个元素
            int length = arr.get(i + 1);
            if (length <= 0) return 0;          // length 必须严格大于 0
            int size = 2 + length;
            int padded = (size + 3) / 4 * 4;   // 补齐到 4 的倍数
            if (i + padded > n) return 0;        // 越界则格式错误
            // 校验该 TLV 覆盖的每个元素是否都在 [0,99]
            for (int j = i; j < i + padded; j++) {
                int v = arr.get(j);
                if (v < 0 || v > 99) return 0;
            }
            tags.add(arr.get(i));                // 记录当前 tag
            i += padded;                         // 跳到下一个 TLV
        }
        return tags.size();
    }
}
```

```c
int countDistinctTags(int* arr, int arrSize) {
    int i = 0;
    int seen[100] = {0};     // 布尔数组标记出现过的 tag（范围 0~99）
    int distinct = 0;
    while (i < arrSize) {
        if (i + 1 >= arrSize) return 0;   // 不足 tag+length
        int length = arr[i + 1];
        if (length <= 0) return 0;         // length 必须 > 0
        int size = 2 + length;
        int padded = (size + 3) / 4 * 4;   // 补齐到 4 的倍数
        if (i + padded > arrSize) return 0;  // 越界则格式错误
        // 校验覆盖区间内的每个元素是否都合法
        for (int j = i; j < i + padded; j++)
            if (arr[j] < 0 || arr[j] > 99) return 0;
        int tag = arr[i];
        if (tag >= 0 && tag < 100 && !seen[tag]) { // 新 tag 计数
            seen[tag] = 1;
            distinct++;
        }
        i += padded;                         // 跳到下一个 TLV
    }
    return distinct;
}
```
