## 解题思路

本题中每个时段对应数组中的一个元素，元素取值为 1~5 表示 5 种能源。我们要找一个**连续的子数组**，使得其**内部出现的不同能源种类数不超过 2**，并让子数组长度尽可能大。

这是一个典型的**滑动窗口（双指针）**问题：

1. 用两个指针 `left`、`right` 维护一个窗口 `[left, right]`，`right` 向右扩展，把 `nums[right]` 纳入窗口。
2. 用一个计数数组 `cnt[1..5]` 记录窗口内每种能源出现的次数，并用 `kinds` 维护「当前窗口内不同能源的种类数」。
3. 每纳入一个元素：若它是窗口内首次出现（`cnt[v]==0`），则 `kinds++`；计数器加一。
4. 当 `kinds > 2`（窗口内出现 3 种及以上能源）时，不断右移 `left` 缩小窗口，直到 `kinds <= 2`。
5. 每次窗口合法时，用 `right - left + 1` 更新答案最大值。

由于窗口只在「种类数 > 2」时才收缩，且 `left` 单调右移，**任何时刻窗口都保持合法**，整个过程只需一遍扫描。

## 复杂度分析

- **时间复杂度**：`O(n)`。`right` 与 `left` 都各自最多向右移动 `n` 次，每个元素被纳入、移出窗口各一次，均摊线性。
- **空间复杂度**：`O(1)`。仅用长度为 6 的计数数组（能源种类固定为 5 种），与输入规模无关；不使用递归，无额外栈开销。

为何是线性：当窗口非法（`kinds>2`）时才收缩左边界，且收缩后重新合法；`left` 只增不减，因此每个位置最多进出窗口一次，整体遍历一次即出结果。

```python
class Solution:
    def longestSubarray(self, nums):
        n = len(nums)
        if n == 0:
            return 0                      # 空数组特判
        cnt = [0] * 6                     # 能源类型 1~5，下标 0 不用
        kinds = 0                          # 当前窗口内不同能源种类数
        left = 0                           # 窗口左端点
        ans = 0
        for right in range(n):
            v = nums[right]
            if cnt[v] == 0:
                kinds += 1                 # 出现新的能源种类
            cnt[v] += 1
            while kinds > 2:               # 种类超过 2 时收缩左边界
                u = nums[left]
                cnt[u] -= 1
                if cnt[u] == 0:
                    kinds -= 1
                left += 1
            if right - left + 1 > ans:     # 更新最长合法窗口长度
                ans = right - left + 1
        return ans
```

```java
import java.util.List;

class Solution {
    public int longestSubarray(List<Integer> nums) {
        int n = nums.size();
        if (n == 0) return 0;                     // 空数组特判
        int[] cnt = new int[6];                    // 能源类型 1~5
        int kinds = 0;                             // 窗口内不同能源种类数
        int left = 0, ans = 0;
        for (int right = 0; right < n; right++) {
            int v = nums.get(right);
            if (cnt[v] == 0) kinds++;             // 新出现一种能源
            cnt[v]++;
            while (kinds > 2) {                   // 超过 2 种则收缩左边界
                int u = nums.get(left);
                cnt[u]--;
                if (cnt[u] == 0) kinds--;
                left++;
            }
            if (right - left + 1 > ans)           // 更新最长合法窗口
                ans = right - left + 1;
        }
        return ans;
    }
}
```
