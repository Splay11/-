# 最小代价完成论文评审

## 解题思路

本题可建模为**集合覆盖（Set Cover）**问题：每篇论文对应一个「可选教师集合」，我们要选出一个教师集合，使得每篇论文都至少被覆盖一次，并满足：

1. 选中的教师数量**最少**；
2. 在教师数量最少的前提下，总费用（所选教师 `cost` 之和）**最小**。

由于教师数量 $m \le 12$，最多可以组成 $2^m \le 4096$ 个教师子集，完全可以直接**枚举所有子集**：

- 对每个子集（用二进制 `mask` 表示，第 $t$ 位为 1 表示选中教师 $t$）；
- 检查它能否覆盖全部论文：对每篇论文 $i$，其可选教师列表 `files[i]` 中是否有人被选中；
- 合法子集记录其「教师数」与「总费用」，按（教师数升序，费用升序）维护全局最优解。

该思路是典型的「状态压缩枚举 + 可行性判定」，无需贪心或动态规划，正确性由穷举保证。

## 复杂度分析

- **时间复杂度**：$O(2^m \cdot n \cdot k)$，其中 $k$ 为单篇论文的可选教师数上界（$k \le m$）。本题中 $m \le 12$，最多约 $4096 \times 20 \times 12 \approx 10^6$ 次运算，远在时限内。
- **空间复杂度**：$O(n \cdot m)$，用于存储 `files` 与 `cost`，属于输入规模本身，额外开销为常数级。

from typing import List


class Solution:
    def minCost(self, n: int, m: int, files: List[List[int]], cost: List[int]) -> int:
        # best_cnt：当前最少教师数；best_cost：对应的最小总费用
        best_cnt = -1
        best_cost = 0
        # 枚举所有教师子集，mask 的第 t 位表示是否选中教师 t
        for mask in range(1 << m):
            # 检查该子集能否覆盖全部论文
            ok = True
            for row in files:
                covered = False
                for t in row:
                    if mask & (1 << t):  # 这篇论文有可选教师被选中
                        covered = True
                        break
                if not covered:  # 存在未被覆盖的论文，方案不合法
                    ok = False
                    break
            if not ok:
                continue
            # 统计该合法方案的教师数与总费用
            cnt = 0
            total = 0
            for t in range(m):
                if mask & (1 << t):
                    cnt += 1
                    total += cost[t]
            # 优先级：先最少教师，再最小费用
            if best_cnt == -1 or cnt < best_cnt or (cnt == best_cnt and total < best_cost):
                best_cnt = cnt
                best_cost = total
        return best_cost

/**
 * @param n 论文篇数
 * @param m 教师个数
 * @param files 每篇论文可评审的教师列表（files[i] 为教师编号数组）
 * @param filesSize 论文数量
 * @param filesColSize files[i] 的长度数组
 * @param cost 每位教师的评审费用
 * @param costSize 教师数量
 * @return 参与教师最少时的最小总费用
 */
int minCost(int n, int m, int** files, int filesSize, int* filesColSize, int* cost, int costSize) {
    // bestCnt：当前最少教师数；bestCost：对应的最小总费用
    int bestCnt = -1, bestCost = 0;

    for (int mask = 0; mask < (1 << m); mask++) {
        // 检查该子集能否覆盖全部论文

        for (int i = 0; i < n; i++) {
            int covered = 0;
            for (int j = 0; j < filesColSize[i]; j++) {
