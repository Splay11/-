## 解题思路

题目要求在灯笼尺寸序列中，找到最长的连续非递增区域。

非递增的含义是：对于连续区域中的相邻两个灯笼，后一个灯笼尺寸不能大于前一个灯笼尺寸，即满足：

$nums[i] \le nums[i - 1]$

我们从左到右扫描数组，维护当前连续非递增区域的起点和长度。

扫描到位置 $i$ 时：

- 如果 $nums[i] \le nums[i - 1]$，说明当前灯笼可以接在当前区域后面，当前区域长度加一；
- 否则，说明连续非递增关系断开，需要从位置 $i$ 重新开始计算；
- 每次更新当前区域后，若当前区域长度大于历史最长长度，就更新答案；
- 若长度相等，不更新答案，因为题目要求多个最长区域时选择最左边的起点。

这样可以保证最终得到最长连续非递增区域的长度和最左起点。

## 复杂度分析

设灯笼数量为 $n$。

时间复杂度：$O(n)$

只需要从左到右扫描一次数组。

空间复杂度：$O(1)$

除返回结果外，只使用了常数个变量。

class Solution:
    def longestBeautifulLanterns(self, nums):
        # 如果数组为空，返回长度 0，起点 0
        # 正常测试数据通常不会为空，这里用于增强鲁棒性
        if not nums:
            return [0, 0]

        # best_len 表示目前找到的最长连续非递增区域长度
        # best_start 表示该区域的起始位置
        best_len = 1
        best_start = 0

        # cur_len 表示当前连续非递增区域长度
        # cur_start 表示当前连续非递增区域起始位置
        cur_len = 1
        cur_start = 0

        # 从第二个灯笼开始，判断是否能接在前一个灯笼后面
        for i in range(1, len(nums)):
            if nums[i] <= nums[i - 1]:
                # 当前灯笼尺寸不超过前一个灯笼，满足非递增要求
                cur_len += 1
            else:
                # 当前灯笼尺寸大于前一个灯笼，连续区域断开
                cur_len = 1
                cur_start = i

            # 只有当前长度严格大于历史最长长度时才更新
            # 若相等则保留更靠左的历史答案
            if cur_len > best_len:
                best_len = cur_len
                best_start = cur_start

        return [best_len, best_start]
