## 解题思路

本题是**固定长度滑动窗口 + 无效点过滤**，可用双指针/滑动窗口在 $O(n)$ 时间内求最小合法窗口和。

1. **合法性**：长度为 $w$ 的窗口内任意 `scores[i]==0` 则该窗口非法，必须跳过。
2. **滑动维护**：对起点 `start` 从 $0$ 到 $n-w$，维护窗口和 `window_sum` 与窗口内 $0$ 的个数 `zero_count`；右移一步时减去离开元素、加入进入元素并同步更新 `zero_count`。
3. **最优与平局**：仅当 `zero_count==0` 时参与比较；若 `window_sum` **严格小于**当前最小和则更新答案。按 `start` 递增扫描，相等和时不更新，自然得到**最早起始下标**。
4. **无解**：扫描结束仍无合法窗口，返回 `[-1, 0]`。

**常见假解**：

- 把 $0$ 当作可忽略而非使整个窗口失效 → 样例 2 会错；
- 平局时用 `<=` 更新或取最后一个最小窗口 → 样例 1 会错；
- 每个窗口重新 $O(w)$ 求和 → $n=10^5,w=10^4$ 会超时；
- 忘记 `w=1` 时每个非零单点即合法窗口。

## 复杂度分析

设 $n$ 为小时数，$w$ 为窗口长度。

- 时间：$O(n)$，每个下标最多进出窗口各一次；
- 空间：$O(1)$ 额外变量（不计输入数组）。

```python
class Solution:
    def findMaintenanceWindow(self, n: int, w: int, scores: List[int]) -> List[int]:
        if n < w:
            return [-1, 0]

        window_sum = 0
        zero_count = 0
        for i in range(w):
            window_sum += scores[i]
            if scores[i] == 0:
                zero_count += 1

        best_start = -1
        min_sum = 10**18
        # 首个窗口合法则记录
        if zero_count == 0:
            min_sum = window_sum
            best_start = 0

        for start in range(1, n - w + 1):
            out_val = scores[start - 1]
            in_val = scores[start + w - 1]
            window_sum += in_val - out_val
            if out_val == 0:
                zero_count -= 1
            if in_val == 0:
                zero_count += 1
            # 严格更小才更新，保证平局取最早起点
            if zero_count == 0 and window_sum < min_sum:
                min_sum = window_sum
                best_start = start

        if best_start == -1:
            return [-1, 0]
        return [best_start, min_sum]
```

```java
public class Solution {
    public int[] findMaintenanceWindow(int n, int w, int[] scores) {
        if (n < w) return new int[] {-1, 0};

        long windowSum = 0;
        int zeroCount = 0;
        for (int i = 0; i < w; i++) {
            windowSum += scores[i];
            if (scores[i] == 0) zeroCount++;
        }

        int bestStart = -1;
        long minSum = Long.MAX_VALUE;
        if (zeroCount == 0) {
            minSum = windowSum;
            bestStart = 0;
        }

        for (int start = 1; start <= n - w; start++) {
            int outVal = scores[start - 1];
            int inVal = scores[start + w - 1];
            windowSum += inVal - outVal;
            if (outVal == 0) zeroCount--;
            if (inVal == 0) zeroCount++;
            if (zeroCount == 0 && windowSum < minSum) {
                minSum = windowSum;
                bestStart = start;
            }
        }

        if (bestStart == -1) return new int[] {-1, 0};
        return new int[] {bestStart, (int) minSum};
    }
}
```
