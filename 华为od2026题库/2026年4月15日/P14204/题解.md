## 解题思路

这题本质就是 **模拟 + 队列 + 栈/表结构维护桌面状态**。

### 核心规则抽象

我们把三部分状态维护出来：

* **甲、乙手牌**：都是“队首出牌，队尾收牌”，所以用 **队列** 最合适。
* **桌面牌堆**：按照“从底到顶”的顺序存放，用 **数组 / List** 即可。
* **同点数牌最近出现位置**：为了快速判断“当前牌是否和桌面之前某张牌点数相同”，可以为 `1~13` 每个点数维护一个 **位置栈**。


### 具体模拟过程

设当前轮到某个玩家出牌：

#### 1）回合开始先判断能否出牌

* 如果当前玩家已经没有牌：

  * 对方有牌：对方获胜，返回对方手牌队首；
  * 对方也没牌：平局，若桌面空返回 `0`，否则返回桌面顶牌。

#### 2）当前玩家打出一张牌

从自己的队首取一张牌，放到桌面顶端。

#### 3）判断是否触发收牌

有两种情况：

##### 情况 A：当前牌是 `J(11)`

* 若 **出牌前桌面非空**，则直接收走 **整桌牌**；
* 若出牌前桌面为空，则它只是普通牌。

##### 情况 B：当前牌不是触发 J 特效

* 若桌面上之前已经出现过同点数牌，则收走 **从那张同点数牌到当前牌之间的整段牌**。

#### 4）收牌后的处理

* 收到的一摞牌“整体翻面后放到自己牌堆底部”，结合样例可知，**加入手牌底部的顺序，正好就是桌面从下到上的顺序**。
* 收牌后，**仍然由当前玩家继续出牌**。
* 如果没有收牌，则轮到另一位玩家。

#### 5）死循环判定

* 记录总出牌次数；
* 若 **超过 10000 次** 仍未结束，则判平局：

  * 桌面空返回 `0`
  * 否则返回桌面顶牌

### 为什么这样做是对的

这题没有任何贪心、动态规划之类的优化空间，本质就是 **按题意严格模拟**。

为了避免每次都在线性扫描桌面找“最近相同点数牌”，我们额外维护：

* `pos[val]`：当前桌面上点数 `val` 出现位置的栈

这样：

* 出一张牌时，可以 **O(1)** 判断桌面上之前是否有同点数牌；
* 收牌时，由于收走的一定是桌面 **某个后缀**，所以同步把这些位置从对应栈里弹掉即可。

因此整个过程既清晰，又足够高效。


## 复杂度分析

设总出牌次数不超过上限 `10000`。

### 时间复杂度

* 每次出牌、判断是否匹配，都是 **O(1)**；
* 收牌时，需要把被收走的那一段从桌面移除，复杂度与收走牌数成正比。

因此整体复杂度可记为：

* **最坏时间复杂度：O(10000^2)** 的宽松上界；
* 但由于总出牌次数被限制在 `10000`，实际完全可接受。

更准确地说，这是一种 **受步数上限约束的模拟**，在本题数据范围内足够稳定。

### 空间复杂度

* 手牌、桌面、位置栈加起来存储的牌数受过程限制；
* 因此空间复杂度为 **O(10000)**。

```python
from collections import deque
from typing import List


class Solution:
    def catFishCardGame(self, cardA: List[int], cardB: List[int]) -> int:
        # 用队列维护双方手牌，队首出牌，队尾收牌
        a = deque(cardA)
        b = deque(cardB)

        # 桌面牌堆，按“从底到顶”存储
        table = []

        # pos[x] 维护点数 x 在桌面上的出现位置栈
        pos = [[] for _ in range(14)]

        # 0 表示甲回合，1 表示乙回合
        turn = 0
        moves = 0

        while True:
            cur = a if turn == 0 else b
            other = b if turn == 0 else a

            # 回合开始时无牌可出，游戏立即结束
            if not cur:
                if other:
                    # 对方获胜，返回对方手牌最上方
                    return other[0]
                # 双方都没牌，平局
                return 0 if not table else table[-1]

            # 出牌
            x = cur.popleft()
            moves += 1

            # 记录出牌前桌面是否为空，供 J 特效判断
            had_table = len(table) > 0

            # 放到桌面顶端
            old_same = pos[x][-1] if pos[x] else -1
            table.append(x)
            pos[x].append(len(table) - 1)

            captured = False

            # J 特效优先：若出的是 J 且出牌前桌面非空，则收走整桌
            if x == 11 and had_table:
                start = 0
                captured = True
            # 否则如果之前有相同点数牌，收走该区间
            elif old_same != -1:
                start = old_same
                captured = True

            if captured:
                # 收走 table[start:]，顺序保持为桌面从下到上
                gained = table[start:]

                # 同步弹出位置栈中对应的下标
                for i in range(len(table) - 1, start - 1, -1):
                    v = table[i]
                    pos[v].pop()

                # 删除桌面后缀
                table = table[:start]

                # 收到牌堆底部
                cur.extend(gained)
                # 收牌后当前玩家继续出牌，turn 不变
            else:
                # 没收牌则轮到对方
                turn ^= 1

            # 超过 10000 次仍未结束，判平局
            if moves > 10000:
                return 0 if not table else table[-1]
```

```java
import java.util.*;

public class Solution {
    /**
     * 代码中的类名、方法名、参数名已经指定，请勿修改，直接返回方法规定的值即可
     *
     * @param cardA int整型一维数组 甲的牌序列
     * @param cardB int整型一维数组 乙的牌序列
     * @return int整型
     */
    public int catFishCardGame(int[] cardA, int[] cardB) {
        // 双方手牌队列
        Deque<Integer> a = new ArrayDeque<>();
        Deque<Integer> b = new ArrayDeque<>();
        for (int x : cardA) a.offerLast(x);
        for (int x : cardB) b.offerLast(x);

        // 桌面牌堆，按“从底到顶”存储
        List<Integer> table = new ArrayList<>();

        // pos[x] 维护点数 x 在桌面上的出现位置栈
        List<Integer>[] pos = new ArrayList[14];
        for (int i = 0; i < 14; i++) pos[i] = new ArrayList<>();

        int turn = 0;   // 0 表示甲，1 表示乙
        int moves = 0;  // 总出牌次数

        while (true) {
            Deque<Integer> cur = (turn == 0) ? a : b;
            Deque<Integer> other = (turn == 0) ? b : a;

            // 回合开始时无牌可出，游戏结束
            if (cur.isEmpty()) {
                if (!other.isEmpty()) {
                    return other.peekFirst();
                }
                return table.isEmpty() ? 0 : table.get(table.size() - 1);
            }

            // 出牌
            int x = cur.pollFirst();
            moves++;

            // 记录出牌前桌面是否非空，供 J 特效使用
            boolean hadTable = !table.isEmpty();

            int oldSame = pos[x].isEmpty() ? -1 : pos[x].get(pos[x].size() - 1);

            // 当前牌放到桌面顶端
            table.add(x);
            pos[x].add(table.size() - 1);

            boolean captured = false;
            int start = -1;

            // J 特效优先
            if (x == 11 && hadTable) {
                start = 0;
                captured = true;
            } else if (oldSame != -1) {
                // 普通同点数匹配
                start = oldSame;
                captured = true;
            }

            if (captured) {
                // 先保存要收走的牌
                List<Integer> gained = new ArrayList<>();
                for (int i = start; i < table.size(); i++) {
                    gained.add(table.get(i));
                }

                // 从后往前弹出位置栈
                for (int i = table.size() - 1; i >= start; i--) {
                    int v = table.get(i);
                    pos[v].remove(pos[v].size() - 1);
                }

                // 删除桌面后缀
                while (table.size() > start) {
                    table.remove(table.size() - 1);
                }

                // 收到当前玩家牌堆底部
                for (int v : gained) {
                    cur.offerLast(v);
                }
                // 收牌后当前玩家继续出牌
            } else {
                // 没收牌则交换回合
                turn ^= 1;
            }

            // 超过 10000 次仍未结束，判平局
            if (moves > 10000) {
                return table.isEmpty() ? 0 : table.get(table.size() - 1);
            }
        }
    }
}
```

```cpp
class Solution {
public:
    /**
     * 代码中的类名、方法名、参数名已经指定，请勿修改，直接返回方法规定的值即可
     *
     * @param cardA int整型vector 甲的牌序列
     * @param cardB int整型vector 乙的牌序列
     * @return int整型
     */
    int catFishCardGame(vector<int>& cardA, vector<int>& cardB) {
        // 双方手牌队列
        deque<int> a(cardA.begin(), cardA.end());
        deque<int> b(cardB.begin(), cardB.end());

        // 桌面牌堆，按“从底到顶”存储
        vector<int> table;

        // pos[x] 维护点数 x 在桌面上的出现位置栈
        vector<int> pos[14];

        int turn = 0;   // 0 表示甲，1 表示乙
        int moves = 0;  // 总出牌次数

        while (true) {
            deque<int>& cur = (turn == 0) ? a : b;
            deque<int>& other = (turn == 0) ? b : a;

            // 回合开始时无牌可出，游戏结束
            if (cur.empty()) {
                if (!other.empty()) {
                    return other.front();
                }
                return table.empty() ? 0 : table.back();
            }

            // 出牌
            int x = cur.front();
            cur.pop_front();
            moves++;

            // 记录出牌前桌面是否非空，供 J 特效判断
            bool hadTable = !table.empty();

            int oldSame = pos[x].empty() ? -1 : pos[x].back();

            // 放到桌面顶端
            table.push_back(x);
            pos[x].push_back((int)table.size() - 1);

            bool captured = false;
            int start = -1;

            // J 特效优先
            if (x == 11 && hadTable) {
                start = 0;
                captured = true;
            } else if (oldSame != -1) {
                // 普通同点数匹配
                start = oldSame;
                captured = true;
            }

            if (captured) {
                // 保存收走的牌，顺序保持为桌面从下到上
                vector<int> gained(table.begin() + start, table.end());

                // 从后往前同步弹出位置栈
                for (int i = (int)table.size() - 1; i >= start; i--) {
                    int v = table[i];
                    pos[v].pop_back();
                }

                // 删除桌面后缀
                table.resize(start);

                // 收到当前玩家牌堆底部
                for (int v : gained) {
                    cur.push_back(v);
                }
                // 收牌后当前玩家继续出牌
            } else {
                // 没收牌则换对手
                turn ^= 1;
            }

            // 超过 10000 次仍未结束，判平局
            if (moves > 10000) {
                return table.empty() ? 0 : table.back();
            }
        }
    }
};
```

```javascript
var catFishCardGame = function(cardA, cardB) {
    // 双方手牌队列
    let qa = [...cardA];
    let qb = [...cardB];
    // 桌面牌堆，从底到顶
    let table = [];
    // 每个点数在桌面的位置栈
    let pos = Array.from({ length: 14 }, () => []);

    let turn = 0;   // 0=甲, 1=乙
    let moves = 0;

    while (true) {
        let cur = turn === 0 ? qa : qb;
        let other = turn === 0 ? qb : qa;

        // 回合开始无牌可出
        if (cur.length === 0) {
            if (other.length > 0) return other[0];
            return table.length === 0 ? 0 : table[table.length - 1];
        }

        // 出牌
        let x = cur.shift();
        moves++;

        let hadTable = table.length > 0;
        let oldSame = pos[x].length > 0 ? pos[x][pos[x].length - 1] : -1;

        table.push(x);
        pos[x].push(table.length - 1);

        let captured = false, start = -1;

        // J(11) 特效优先
        if (x === 11 && hadTable) {
            start = 0;
            captured = true;
        } else if (oldSame !== -1) {
            start = oldSame;
            captured = true;
        }

        if (captured) {
            // 同步弹出被收走牌的位置栈
            for (let i = table.length - 1; i >= start; i--) {
                let v = table[i];
                pos[v].pop();
            }
            // 收到的牌加入当前玩家队尾
            for (let i = start; i < table.length; i++) {
                cur.push(table[i]);
            }
            table.length = start;
        } else {
            turn ^= 1;  // 没收牌则切换回合
        }

        // 超过 10000 次判平局
        if (moves > 10000) {
            return table.length === 0 ? 0 : table[table.length - 1];
        }
    }
};
```

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stdbool.h>

#define MAXN 20010

int catFishCardGame(int* cardA, int cardASize, int* cardB, int cardBSize) {
    // 双方手牌队列（用数组模拟，ha/ta 为队首队尾）
    int* qa = (int*)malloc(MAXN * sizeof(int));
    int* qb = (int*)malloc(MAXN * sizeof(int));
    int ha = 0, ta = 0, hb = 0, tb = 0;

    for (int i = 0; i < cardASize; i++) qa[ta++] = cardA[i];
    for (int i = 0; i < cardBSize; i++) qb[tb++] = cardB[i];

    // 桌面牌堆，从底到顶
    int* table = (int*)malloc(MAXN * sizeof(int));
    int tsz = 0;

    // 每个点数在桌面的位置栈，用于 O(1) 查找
    int* pos[14];
    int posTop[14] = {0};
    for (int v = 0; v < 14; v++) pos[v] = (int*)malloc(MAXN * sizeof(int));

    int turn = 0;   // 0=甲, 1=乙
    int moves = 0;

    while (1) {
        int* curQ = (turn == 0) ? qa : qb;
        int* curH = (turn == 0) ? &ha : &hb;
        int* curT = (turn == 0) ? &ta : &tb;
        int* othQ = (turn == 0) ? qb : qa;
        int* othH = (turn == 0) ? &hb : &ha;

        // 回合开始无牌可出
        if (*curH >= *curT) {
            int result = (*othH < *(turn == 0 ? &tb : &ta)) ? othQ[*othH]
                                 : (tsz == 0 ? 0 : table[tsz - 1]);
            free(qa); free(qb); free(table);
            for (int v = 0; v < 14; v++) free(pos[v]);
            return result;
        }

        // 出牌
        int x = curQ[(*curH)++];
        moves++;

        bool hadTable = (tsz > 0);
        int oldSame = (posTop[x] > 0) ? pos[x][posTop[x] - 1] : -1;

        table[tsz] = x;
        pos[x][posTop[x]++] = tsz;
        tsz++;

        bool captured = false;
        int start = -1;

        // J(11) 特效优先
        if (x == 11 && hadTable) {
            start = 0;
            captured = true;
        } else if (oldSame != -1) {
            start = oldSame;
            captured = true;
        }

        if (captured) {
            // 同步弹出被收走牌的位置栈
            for (int i = tsz - 1; i >= start; i--) posTop[table[i]]--;
            // 收到的牌加入当前玩家队尾
            for (int i = start; i < tsz; i++) curQ[(*curT)++] = table[i];
            tsz = start;
        } else {
            turn ^= 1;  // 没收牌则切换回合
        }

        // 超过 10000 次判平局
        if (moves > 10000) {
            int result = (tsz == 0) ? 0 : table[tsz - 1];
            free(qa); free(qb); free(table);
            for (int v = 0; v < 14; v++) free(pos[v]);
            return result;
        }
    }
}
```
