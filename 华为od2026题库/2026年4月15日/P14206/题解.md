## 解题思路

题目要求我们对日志中的请求路径进行“按相邻段分组”的处理。

需要特别注意两点：

1. 只有“相邻且相同”的请求路径才能合并。
2. 即使后面再次出现相同路径，只要中间被其他路径隔开，就必须视为新的组。

因此，本题本质上是一个线性扫描问题。

我们从左到右遍历数组，用一个指针表示当前分组的起点：

- 记录当前组的起始下标 `start`
- 记录当前组的路径 `paths[start]`
- 向后不断扩展，直到遇到不同路径为止
- 在扩展过程中统计：
  - 当前组连续出现的次数 `count`
  - 当前组响应时间总和 `sum`
- 当前组结束后，计算平均值 `sum // count`
- 将结果 `[start, count, sum // count]` 加入答案
- 然后从下一组继续处理

因为每个元素只会被访问一次，所以时间复杂度是线性的，适合 `10^5` 的数据规模。

## 复杂度分析

设数组长度为 `n`。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`（不计返回结果空间）

```python
class Solution:
    def mergeLogs(self, paths, responseTimes):
        # 获取日志总数
        n = len(paths)

        # 用于存储最终答案
        ans = []

        # i 表示当前正在处理的分组起点
        i = 0

        # 线性扫描整个数组
        while i < n:
            # 当前组的起始下标
            start = i

            # 当前组的请求路径
            current_path = paths[i]

            # 当前组内元素个数
            count = 0

            # 当前组内响应时间总和
            total = 0

            # 向后扩展当前组，直到路径发生变化
            while i < n and paths[i] == current_path:
                count += 1
                total += responseTimes[i]
                i += 1

            # 计算当前组平均响应时间，题目要求向下取整
            avg = total // count

            # 将当前组统计结果加入答案
            ans.append([start, count, avg])

        # 返回所有分组结果
        return ans
````

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[][] mergeLogs(String[] paths, int[] responseTimes) {
        // 日志总数
        int n = paths.length;

        // 先用动态数组存储每一组结果，最后再转成二维数组返回
        List<int[]> list = new ArrayList<>();

        // i 表示当前处理到的位置
        int i = 0;

        // 线性扫描整个数组
        while (i < n) {
            // 当前组起始下标
            int start = i;

            // 当前组的请求路径
            String currentPath = paths[i];

            // 当前组连续出现次数
            int count = 0;

            // 当前组响应时间总和
            int total = 0;

            // 继续向后扫描，直到路径不同为止
            while (i < n && paths[i].equals(currentPath)) {
                count++;
                total += responseTimes[i];
                i++;
            }

            // 平均响应时间，向下取整
            int avg = total / count;

            // 保存当前组结果
            list.add(new int[] {start, count, avg});
        }

        // 将动态数组转换为题目要求的二维数组
        int[][] ans = new int[list.size()][3];
        for (int k = 0; k < list.size(); k++) {
            ans[k] = list.get(k);
        }

        return ans;
    }
}
```

```c
#include <stdlib.h>
#include <string.h>

int** mergeLogs(char** paths, int pathsSize, int* responseTimes, int responseTimesSize, int* returnSize) {
    if (pathsSize == 0) {
        *returnSize = 0;
        return NULL;
    }

    int** result = (int**)malloc(pathsSize * sizeof(int*));
    int groupCount = 0;
    int i = 0;

    while (i < pathsSize) {
        int start = i;
        char* currentPath = paths[i];
        int count = 0;
        int total = 0;

        while (i < pathsSize && strcmp(paths[i], currentPath) == 0) {
            count++;
            total += responseTimes[i];
            i++;
        }

        int avg = total / count;
        result[groupCount] = (int*)malloc(3 * sizeof(int));
        result[groupCount][0] = start;
        result[groupCount][1] = count;
        result[groupCount][2] = avg;
        groupCount++;
    }

    *returnSize = groupCount;
    return result;
}
```
