# 最小极差分组

## 解题思路

- 将 $n$ 个数分成两个非空集合，最小化两组极差之和。一组的极差只取决于该组内的最小值与最大值，中间元素不改变极差。
- 将数组**升序排序**后，最优解一定对应某个**前缀 / 后缀切分**：第 $1$ 组取 $nums[0..k]$，第 $2$ 组取 $nums[k+1..n-1]$（$0 \le k < n-1$）。若全局最小与最大分属两组，则一组的极差由「最小值到该组最大」、另一组由「该组最小到最大值」决定；中间元素可任意分配而不增大极差，因此只需枚举切分点。
- 对切分点 $k$，极差和为 $(nums[k]-nums[0])+(nums[n-1]-nums[k+1])$，遍历所有 $k$ 取最小即可。$n=2$ 时仅一种切分，答案为 $0$。
- 核心算法：**排序 + 线性枚举切分点**（贪心/结构观察，非 DP）。

## 复杂度分析

- 排序时间复杂度 $O(n \log n)$，枚举切分点 $O(n)$，总时间 $O(n \log n)$。
- 排序需 $O(n)$ 额外空间（或原地排序 $O(1)$），空间复杂度 $O(n)$ 或 $O(1)$。
- 极差和最大可达约 $4 \times 10^9$，需使用 64 位整数（`long long`）。

```python
from typing import List


class Solution:
    def minSplitRangeSum(self, nums: List[int]) -> int:
        # 排序后枚举前缀/后缀切分，极差只由两端点决定
        nums = sorted(nums)
        n = len(nums)
        best = 10**30
        for k in range(n - 1):
            # 左组 [0..k]，右组 [k+1..n-1] 的极差之和
            cur = nums[k] - nums[0] + nums[n - 1] - nums[k + 1]
            if cur < best:
                best = cur
        return best
```

import java.util.Arrays;

class Solution {
    public long minSplitRangeSum(int[] nums) {
        // 排序后只需考虑连续前缀与后缀的分组
        Arrays.sort(nums);
        int n = nums.length;
        long best = Long.MAX_VALUE;
        for (int k = 0; k < n - 1; k++) {
            // 左极差 nums[k]-nums[0]，右极差 nums[n-1]-nums[k+1]
            long cur = (long) nums[k] - nums[0] + (long) nums[n - 1] - nums[k + 1];
            if (cur < best) {
                best = cur;
            }
        }
        return best;
    }
}

    long long minSplitRangeSum(vector<int>& nums) {
        // 排序后枚举切分点 k：左组 [0..k]，右组 [k+1..n-1]
        sort(nums.begin(), nums.end());
        int n = static_cast<int>(nums.size());

        for (int k = 0; k < n - 1; ++k) {

                + static_cast<long long>(nums[n - 1]) - nums[k + 1];
            if (cur < best) {
                best = cur;
            }
        }
        return best;
    }
};

long long minSplitRangeSum(int* nums, int numsSize) {
    // 排序后枚举前缀 / 后缀切分
    qsort(nums, numsSize, sizeof(int), cmp);
    long long best = (long long)nums[numsSize - 1] - nums[0];
    for (int k = 0; k < numsSize - 1; k++) {
        // 左组极差 nums[k] - nums[0]，右组极差 nums[n-1] - nums[k+1]
        long long cur = (long long)(nums[k] - nums[0])
                      + (long long)(nums[numsSize - 1] - nums[k + 1]);
        if (cur < best) best = cur;
    }
    return best;
}
