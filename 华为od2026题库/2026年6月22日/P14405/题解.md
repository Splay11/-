## 解题思路

本题等价于：将数组划分为恰好 $k$ 个连续非空段，使**各段元素和的最大值**最小。这是经典的 **二分答案 + 贪心验证** 问题（与 LeetCode 410「分割数组的最大值」同型）。

1. **答案单调性**：若最大段和 $limit$ 可行，则任意更大的 $limit$ 也可行；反之不可行时，更小的 $limit$ 也不可行。因此在 $[\max(nums),\ \sum nums]$ 上二分。
2. **可行性检验 `can(limit)`**：从左到右贪心累加，当前段和超过 `limit` 则开新段；统计所需最少段数 `cnt`。若 `cnt <= k`，说明可在不超过 `limit` 的前提下拆成至多 $k$ 段；由于 $k \le n$ 且每段非空，还可继续细分至恰好 $k$ 段而不增大最大值。
3. 二分得到最小可行 `limit` 即为答案。

常见假解：用 DP 求最小段和（方向反了）、检验时用 `cnt == k` 而非 `cnt <= k`、忘记单元素下界 `max(nums)`。

## 复杂度分析

- 时间复杂度：$O(n \log S)$，其中 $S = \sum nums$；每次 `can` 为 $O(n)$，二分约 $\log S$ 轮。
- 空间复杂度：$O(1)$，仅常数额外变量。

```python
from typing import List


class Solution:
    def minimumLatency(self, nums: List[int], k: int) -> int:
        def can(limit: int) -> bool:
            cnt = 1
            s = 0
            for x in nums:
                # 当前段再加 x 会超限，则开启新通道
                if s + x > limit:
                    cnt += 1
                    s = 0
                s += x
            # 所需段数不超过 k 则 limit 可行
            return cnt <= k

        lo, hi = max(nums), sum(nums)
        while lo < hi:
            mid = (lo + hi) // 2
            if can(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

```java
public class Solution {
    public int minimumLatency(int[] nums, int k) {
        int lo = 0, hi = 0;
        for (int x : nums) {
            lo = Math.max(lo, x);
            hi += x;
        }

        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (canSplit(nums, k, mid))
                hi = mid;
            else
                lo = mid + 1;
        }
        return lo;
    }

    private boolean canSplit(int[] nums, int k, int limit) {
        int cnt = 1;
        long s = 0;
        for (int x : nums) {
            if (s + x > limit) {
                cnt++;
                s = 0;
            }
            s += x;
        }
        // 贪心段数不超过 k 即可通过二分
        return cnt <= k;
    }
}
```

```c
#include <stdlib.h>

// 贪心检验：limit下所需最少段数是否不超过k
static int canSplit(int* nums, int n, int k, long long limit) {
    int cnt = 1;
    long long s = 0;
    for (int i = 0; i < n; i++) {
        if (s + nums[i] > limit) {
            cnt++;
            s = 0;
        }
        s += nums[i];
    }
    return cnt <= k;
}

int minimumLatency(int* nums, int numsSize, int k) {
    long long lo = 0, hi = 0;
    for (int i = 0; i < numsSize; i++) {
        if (nums[i] > lo) lo = nums[i];
        hi += nums[i];
    }

    // 二分查找最小的可行limit
    while (lo < hi) {
        long long mid = (lo + hi) / 2;
        if (canSplit(nums, numsSize, k, mid))
            hi = mid;
        else
            lo = mid + 1;
    }
    return (int)lo;
}
```
