## 解题思路

本题是经典的**字符串压缩（游程编码 Run-Length Encoding）**，可用**双指针（滑动窗口）**在单次扫描内完成。

核心思路：字符串中相同字符总是连续成段。用两个指针刻画每一段：
- `i` 指向「当前连续段的起点」；
- `j` 从 `i` 开始向后扩张，直到遇到与 `s[i]` 不同的字符，此时 `[i, j)` 就是一段全相同的字符。

段长为 `cnt = j - i`，按规则输出：
- 若 `cnt > 1`：写 `字符 + cnt`（如 `aa` → `a2`，`ccccc` → `c5`）；
- 若 `cnt == 1`：只写该字符（如 `b` → `b`）。

把 `i` 跳到 `j` 继续下一段，直到扫完整个字符串。

**易错点（区分度设计）**：
- 大小写敏感：`A` 与 `a` 视为不同字符，不能合并（见样例 3 `AAbB` → `A2bB`）。
- 计数为 `1` 时**不写数字**，只写字符本身；写错（如输出 `b1`）即不符规则。
- 计数可能 ≥ 10（如 `zzzzzzzzzzzz` → `z12`），输出时要正确拼接多位数字，不能只输出个位。
- 相邻互异字符（如 `ababab`）没有长度 >1 的段，结果应等于原串，不能误压缩。

## 复杂度分析

- **时间复杂度**：`i`、`j` 各扫描字符串一次，每个字符最多被访问两次，故为 `O(n)`，`n` 为字符串长度（≤ 1000），非常高效。
- **空间复杂度**：结果字符串最坏情况下与原串等长（每个字符都单独成段，无压缩），故额外空间 `O(n)`；仅用常数个指针变量，辅助空间 `O(1)`。

```python
class Solution:
    def compress(self, s: str) -> str:
        n = len(s)
        if n == 0:
            return ""
        res = []
        i = 0
        # 双指针：i 为当前段起点，j 向后扩张直到字符改变
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            cnt = j - i
            # 计数 >1 才写数字，单个字符只写字母
            if cnt > 1:
                res.append(f"{s[i]}{cnt}")
            else:
                res.append(s[i])
            i = j  # 跳到下一段起点
        return "".join(res)
```

```java
class Solution {
    public String compress(String s) {
        int n = s.length();
        if (n == 0) return "";
        StringBuilder res = new StringBuilder();
        int i = 0;
        // 双指针：i 为当前段起点，j 向后扩张直到字符改变
        while (i < n) {
            int j = i;
            while (j < n && s.charAt(j) == s.charAt(i)) j++;
            int cnt = j - i;
            // 计数 >1 才写数字，单个字符只写字母
            if (cnt > 1) {
                res.append(s.charAt(i)).append(cnt);
            } else {
                res.append(s.charAt(i));
            }
            i = j; // 跳到下一段起点
        }
        return res.toString();
    }
}
```

```c
#include <stdlib.h>
#include <string.h>

/**
 * @param s 输入字符串（仅含大小写英文字母）
 * @return 压缩后的字符串（由 malloc 分配，以 '\0' 结尾，调用方负责 free）
 */
char* compress(const char* s) {
    int n = (int)strlen(s);
    // 最坏情况：每个字符都单独成段，输出长度不超过 2*n
    char* res = (char*)malloc((size_t)(2 * n + 1) * sizeof(char));
    int k = 0;
    int i = 0;
    // 双指针：i 为当前段起点，j 向后扩张直到字符改变
    while (i < n) {
        int j = i;
        while (j < n && s[j] == s[i]) j++;
        int cnt = j - i;
        // 计数 >1 才写数字，单个字符只写字母
        if (cnt > 1) {
            res[k++] = s[i];
            // 将计数逐位写入（支持任意长度，最多 4 位）
            char buf[8];
            int p = 0;
            if (cnt == 0) buf[p++] = '0';
            else {
                int t = cnt;
                while (t > 0) { buf[p++] = '0' + (t % 10); t /= 10; }
            }
            while (p > 0) res[k++] = buf[--p]; // 逆序写回，得到正序数字
        } else {
            res[k++] = s[i];
        }
        i = j; // 跳到下一段起点
    }
    res[k] = '\0';
    return res;
}
```
