# 字符串压缩编码

# 题目内容

给定一个只包含大小写英文字母的字符串，请实现字符串压缩编码功能。

压缩规则：

- 如果字符连续出现次数大于`1`，则用字符加上出现次数表示
- 如果字符连续出现次数等于`1`，则直接输出字符

# 输入描述

- 输入一行，包含一个字符串 $str$（长度 $1 \leq |str| \leq 1000$）
- 字符串只包含大小写英文字母

# 输出描述

输出压缩后的字符串

## 样例1

**输入**

```
aabcccccaaa
```

**输出**

```
a2bc5a3
```

**说明**

- `aa` → `a2`
- `b` → `b`（单个字符不写数字）
- `ccccc` → `c5`
- `aaa` → `a3`

## 样例2

**输入**

```
b
```

**输出**

```
b
```

**说明**

- 单个字符直接输出

## 样例3

**输入**

```
AAbB
```

**输出**

```
A2bB
```

**说明**

- `AA` → `A2`
- `b` → `b`
- `B` → `B`

## 样例4

**输入**

```
aaabbbcccaaa
```

**输出**

```
a3b3c3a3
```

**说明**

- `aaa` → `a3`
- `bbb` → `b3`
- `ccc` → `c3`
- `aaa` → `a3`
