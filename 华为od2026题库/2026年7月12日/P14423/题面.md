# 题目内容

在软件项目开发里涉及不同版本组件引用，组件依赖组件，形成一棵依赖树（从根节点深层展开）；
请编写一段代码，对当前项目的组件依赖关系进行分析，按项目组件依赖顺序输出最终有效的组件版本列表；

说明如下：
1. 从根节点开始按依赖顺序输出组件列表，项目上层组件依赖先输出，如果同层依赖则父组件先出现的优先输出，父组件相同的按依赖出现顺序输出，如：项目依赖组件【b,a】，a依赖【c,d】，b依赖【e】，输出顺序为 b,a,e,c,d；
2. 组件去重：依赖组件如多次出现，只保留第一次出现的顺序位置；
3. 同一组件如有不同版本，以首次依赖的组件版本作为输出；

# 输入描述

参数1：项目直属依赖 directDeps，格式：["组件名:版本号:排除组件列表"]，如："a:v1:"表示项目依赖a组件，版本为v1，无排除组件；
参数2：全局组件依赖 depRules，格式：["组件名:依赖组件名:依赖组件版本号:排除组件列表"]，如："a:b:v2:c"，表示a组件依赖b组件v2版本，须排除b组件依赖的c组件子树；
输入列表顺序为依赖声明顺序；组件名、版本号由字母数字组成，非空；输入保证同一组件不同版本依赖相同；排除组件列表以半角逗号分隔，格式如："a,b"，排除列表可为空，输入保证排除列表不会出现"a,b"或"a,"格式；

# 输出描述

符合依赖顺序要求的项目依赖组件列表，格式：["组件名:版本号"]

## 样例1

**输入**
```
["a:v1:"],[]
```

**输出**
```
["a:v1"]
```

**说明**
项目仅依赖一个无传递依赖的组件

## 样例2

**输入**
```
["a:v1:","b:v1:"],["a:c:v1:","b:d:v1:","d:c:v2:"]
```

**输出**
```
["a:v1","b:v1","c:v1","d:v1"]
```

**说明**
- 上层的依赖先输出，
- 同层依赖按依赖列表顺序输出

## 样例3

**输入**
```
["a:v1:b"],["a:c:v1:","a:b:v1:","b:d:v1:"]
```

**输出**
```
["a:v1","c:v1"]
```

**说明**
- 组件a依赖b和c，但项目依赖a时指定排除b，b及其子外依赖不出现

## 样例4

**输入**
```
["a:v1:b,e","d:v1:"],["a:c:v1:","c:e:v1:","b:c:v1:"]
```

**输出**
```
["a:v1","d:v1","c:v1"]
```

**说明**
- b被排除，b的c依赖也被排除，但a依赖c仍然有效，e在a依赖树中被排除

## 样例5

**输入**
```
["a:v1:","b:v1:"],["a:c:v1:","b:c:v1:","c:b:v1"]
```

**输出**
```
["a:v1","b:v1","c:v1"]
```

**说明**
- a和b共同依赖c的同一版本，c只应输出一次；
- b和c有循环依赖，b只输出一次
