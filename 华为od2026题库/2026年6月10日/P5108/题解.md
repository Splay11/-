## 解题思路

本题是**数组扫描 + 滑动窗口判定**，可按以下步骤处理：

1. **最高温度**：线性扫描 `temperatures`，维护当前最大值及其**首次出现**下标（仅在严格变大时更新下标）。
2. **危险时段枚举**：对每个起点 $i \in [0,\ n-k]$，检查长度 $k$ 的窗口是否**严格单调递增**：
   - 即对所有 $j \in [i,\ i+k-2]$，需满足 $\texttt{temperatures}[j] < \texttt{temperatures}[j+1]$；
   - 相邻相等（如 $2,2,3$）不满足「严格递增」，不能计入。
3. **阈值过滤**：窗口合法时，计算升幅 $\texttt{temperatures}[i+k-1]-\texttt{temperatures}[i]$，仅当 $\ge t$ 时计为一个危险时段。
4. **最优窗口**：在所有危险时段中，取升幅最大者；若升幅相同，取**起始下标最小**的窗口，输出其起止下标（含端点）；若无危险时段，后两项返回 $-1$。

**常见假解**：

- 只判断首尾差值、不检查中间是否严格递增 → $[1,2,2,5]$ 在 $k=4$ 时首尾差够大但中间有相等元素；
- 把「非递减」当成危险时段 → 相邻相等应排除；
- 最高温取下标最后一次出现 → 题目要求**首次**出现位置；
- 升幅相同时取结束下标最小或最后一个窗口 → 应取起始下标最小；
- 用 $>$ 而非 $\ge$ 判断阈值 → $t=10$ 时升幅恰好 $10$ 也应计入；
- 窗口长度弄错 → 危险时段固定为连续 $k$ 个点，不是任意更长上升段。

## 复杂度分析

设 $n = |\texttt{temperatures}| \le 10000$，$k \le n$。

- 时间：$O(nk)$。最多 $n-k+1$ 个起点，每个窗口检查 $k-1$ 对相邻元素；在题面约束下足够；
- 空间：$O(1)$ 额外空间（不计输入数组）。

from typing import List


class Solution:
    def analyzeTemperatureData(
        self, temperatures: List[int], k: int, t: int
    ) -> List[int]:
        n = len(temperatures)
        max_val = temperatures[0]
        max_idx = 0
        # 线性扫描：仅在严格变大时更新下标，保证是首次出现
        for i in range(1, n):
            if temperatures[i] > max_val:
                max_val = temperatures[i]
                max_idx = i

        count = 0
        best_start = -1
        best_end = -1
        best_rise = -1

        for i in range(0, n - k + 1):
            ok = True
            # 检查长度为 k 的窗口是否严格单调递增
            for j in range(i, i + k - 1):
                if temperatures[j] >= temperatures[j + 1]:
                    ok = False
                    break
            if not ok:
                continue
            rise = temperatures[i + k - 1] - temperatures[i]
            if rise >= t:
                count += 1
                # 升幅更大优先；升幅相同时取起始下标更小
                if rise > best_rise or (
                    rise == best_rise and (best_start == -1 or i < best_start)
                ):
                    best_rise = rise
                    best_start = i
                    best_end = i + k - 1

        return [max_val, max_idx, count, best_start, best_end]
