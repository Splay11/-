## 解题思路

本题考查**字符频次统计 + 枚举交换字符对 + 不同字符计数增量公式**，可按以下步骤处理：

1. **预处理**：统计 `resA`、`resB` 中 $26$ 个小写字母出现次数，并记 `dA`、`dB` 为两串当前的不同字符个数。
2. **枚举交换对**：只需枚举「从 `resA` 取出的字符 `ca`」与「从 `resB` 取出的字符 `cb`」（各 $26$ 种，且须在原串中出现）。一次交换只与这两个字符有关，无需遍历下标 $O(nm)$。
3. **交换后不同字符数**（`ca != cb` 时）：
   - `resA` 失去 `ca`、获得 `cb`：  
     $dA' = dA - [\text{countA}[ca]=1] + [\text{countA}[cb]=0]$
   - `resB` 失去 `cb`、获得 `ca`：  
     $dB' = dB - [\text{countB}[cb]=1] + [\text{countB}[ca]=0]$
4. **特判 `ca == cb`**：交换等价于不变，仅当 $dA = dB$ 时合法，候选值为 $dA$。
5. 在所有满足 $dA' = dB'$ 的交换中取**最小**的 $dA'$；若无合法交换返回 $-1$。

**常见假解**：

- 暴力枚举所有下标对 $O(nm)$，在 $10^5$ 规模下超时；
- 把「`cb` 是否已在 `resA` 中」误写成看 `countB[cb]`，导致计数错误；
- 发现初始 $dA = dB$ 就直接返回，未验证是否存在使交换后仍相等的方案；
- 忽略 `ca == cb` 时交换不改变字符串、需 $dA = dB$ 才合法；
- 找到第一个合法交换即返回，未取不同字符数的最小值。

## 复杂度分析

设 $n = |resA|$，$m = |resB|$。

- 统计频次：$O(n + m)$；
- 枚举字符对：至多 $26 \times 26 = 676$ 种，每种 $O(1)$ 更新；
- 总时间 $O(n + m)$，额外空间 $O(1)$（固定 $26$ 计数数组）。

```python
class Solution:
    def minDistinctAfterSwap(self, resA: str, resB: str) -> int:
        countA = [0] * 26
        countB = [0] * 26
        for c in resA:
            countA[ord(c) - ord("a")] += 1
        for c in resB:
            countB[ord(c) - ord("a")] += 1

        # 当前两串的不同字符个数
        dA = sum(1 for x in countA if x > 0)
        dB = sum(1 for x in countB if x > 0)

        ans = -1
        for a in range(26):
            if countA[a] == 0:
                continue
            for b in range(26):
                if countB[b] == 0:
                    continue
                if a == b:
                    # 交换相同字符，字符串不变；仅当原本已相等才合法
                    if dA != dB:
                        continue
                    cand = dA
                else:
                    # 按频次公式 O(1) 计算交换后的不同字符数
                    da = dA - (1 if countA[a] == 1 else 0) + (1 if countA[b] == 0 else 0)
                    db = dB - (1 if countB[b] == 1 else 0) + (1 if countB[a] == 0 else 0)
                    if da != db:
                        continue
                    cand = da
                # 多种合法交换时取不同字符数的最小值
                if ans == -1 or cand < ans:
                    ans = cand
        return ans
```

```java
public class Solution {
    public int minDistinctAfterSwap(String resA, String resB) {
        int[] countA = new int[26];
        int[] countB = new int[26];
        for (int i = 0; i < resA.length(); i++) {
            countA[resA.charAt(i) - 'a']++;
        }
        for (int i = 0; i < resB.length(); i++) {
            countB[resB.charAt(i) - 'a']++;
        }

        int dA = 0, dB = 0;
        for (int i = 0; i < 26; i++) {
            if (countA[i] > 0) dA++;
            if (countB[i] > 0) dB++;
        }

        int ans = -1;
        for (int a = 0; a < 26; a++) {
            if (countA[a] == 0) continue;
            for (int b = 0; b < 26; b++) {
                if (countB[b] == 0) continue;
                int cand;
                if (a == b) {
                    // 同字符交换不改变两串，必须原本不同字符数已相等
                    if (dA != dB) continue;
                    cand = dA;
                } else {
                    // 交换 ca=a 与 cb=b 后，用频次判断 distinct 的增减
                    int da = dA - (countA[a] == 1 ? 1 : 0) + (countA[b] == 0 ? 1 : 0);
                    int db = dB - (countB[b] == 1 ? 1 : 0) + (countB[a] == 0 ? 1 : 0);
                    if (da != db) continue;
                    cand = da;
                }
                if (ans == -1 || cand < ans) ans = cand;
            }
        }
        return ans;
    }
}
```

```javascript
var minDistinctAfterSwap = function(resA, resB) {
    var countA = new Array(26).fill(0);
    var countB = new Array(26).fill(0);

    // 统计频次
    for (var i = 0; i < resA.length; i++) {
        countA[resA.charCodeAt(i) - 97]++;
    }
    for (var i = 0; i < resB.length; i++) {
        countB[resB.charCodeAt(i) - 97]++;
    }

    // 当前不同字符个数
    var dA = 0, dB = 0;
    for (var i = 0; i < 26; i++) {
        if (countA[i] > 0) dA++;
        if (countB[i] > 0) dB++;
    }

    var ans = -1;
    for (var a = 0; a < 26; a++) {
        if (countA[a] === 0) continue;
        for (var b = 0; b < 26; b++) {
            if (countB[b] === 0) continue;
            var cand;
            if (a === b) {
                // 交换相同字符，字符串不变
                if (dA !== dB) continue;
                cand = dA;

                // 交换后不同字符数增量公式

                if (da !== db) continue;
                cand = da;
            }
            if (ans === -1 || cand < ans) ans = cand;
        }
    }
    return ans;
};
```
