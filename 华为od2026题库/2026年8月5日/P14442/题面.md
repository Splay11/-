# 题目内容

给定一个整数数组，请找出最长的子串，使得该子串中任意两个相邻元素的绝对差都严格大于 `1`。输出这个最长子串的长度。

例如，数组 `[1, 3, 4, 5, 6, 5, 4]` 中，子串 `[1, 3]` 满足条件 (`|1-3|=2>1`)，且是最长的，因此答案为 `2`。

数组长度为 $n$，$0 \le n \le 1000$

数组范围 $nums[]$ ，$0 \le \text{nums}[i] \le 10000$

# 输入描述

输入为一个整数数组

# 输出描述

输出满足条件的最长子串的长度

## 样例1

**输入**

```
[1, 3, 4, 5, 6, 5, 4]
```

**输出**

```
2
```

**说明**

最长子串是`[1,3]`,长度是`2`

## 样例2

**输入**

```
[1, 3, 5, 7]
```

**输出**

```
4
```

**说明**

最长子串是`[1, 3, 5, 7]`,长度是`4`
