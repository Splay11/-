## 解题思路

本题要求找出整数数组中满足「任意两个相邻元素的绝对差严格大于 $1$」的最长子串（连续子数组）长度。

**核心思路：一次遍历**

由于要求的是连续子串（不是子序列），我们只需要遍历数组，维护当前满足条件的子串长度即可：

- 从第一个元素开始，当前子串长度 `cur = 1`，答案 `ans = 1`。
- 对于每个后续元素 `nums[i]`（$i \ge 1$）：
  - 若 $|\text{nums}[i] - \text{nums}[i-1]| > 1$，则当前子串可以延长：`cur += 1`，并更新答案 `ans = max(ans, cur)`。
  - 否则，当前子串中断：`cur = 1`（以当前元素为新起点重新开始）。
- 特别地，若数组为空（$n = 0$），返回 $0$。

**正确性说明**

子串（连续子数组）的定义要求元素在数组中连续。当我们发现 `|nums[i] - nums[i-1]| ≤ 1` 时，`nums[i]` 不能和 `nums[i-1]` 在同一子串中，因此必须从这里断开。以 `nums[i]` 为起点重新计数是正确的，因为 `nums[i]` 和 `nums[i-1]` 已经无法同时出现在任何一个满足条件的子串中。

**时间复杂度**：$O(n)$，仅需一次遍历。

**空间复杂度**：$O(1)$，仅使用常数级额外空间。

## 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 为数组长度。算法仅需一次线性遍历，每次迭代执行常数次比较和赋值操作。
- **空间复杂度**：$O(1)$。除输入数组外，只使用了 `ans`、`cur` 等常数个变量。

```python
from typing import List


class Solution:
    def longestNonConsecutiveSubstring(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 0:
            return 0

        ans = 1  # 至少单个元素长度为 1
        cur = 1  # 当前连续满足条件的子串长度
        for i in range(1, n):
            # 相邻元素绝对差严格大于 1 则延长当前子串
            if abs(nums[i] - nums[i - 1]) > 1:
                cur += 1
                if cur > ans:
                    ans = cur
            else:
                cur = 1  # 差 ≤1，重置为当前元素单独成串

        return ans
```

```java
            }
        }
        return ans;
    }
```

```c
#include <stdlib.h>
#include <string.h>

/**
 * @param nums 整数数组
 * @param n 数组长度
 * @return 满足条件的最长子串长度
 */
int longestNonConsecutiveSubstring(int* nums, int n) {
    if (n == 0) return 0;

    int ans = 1;  // 至少单个元素长度为 1
    int cur = 1;  // 当前连续满足条件的子串长度
    for (int i = 1; i < n; i++) {
        int diff = nums[i] - nums[i - 1];
        if (diff < 0) diff = -diff;  // 手动求绝对值
        // 相邻元素绝对差严格大于 1 则延长当前子串
        if (diff > 1) {
            cur++;
            if (cur > ans) ans = cur;
        } else {
            cur = 1;  // 差 ≤1，重置为当前元素单独成串
        }
    }
    return ans;
}
```
