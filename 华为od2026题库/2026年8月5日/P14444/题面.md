# 题目内容

某企业新申请到一个完整的 IPv4 主网段，网络管理员需要根据各部门申报的最小主机需求数量，制定子网划分方案。

请你编写一个程序根据主网段信息、部门数量及各需求，自动计算满足所有部门需求的最小主机数网段，并按申请部门信息连续分配等长子网。

# 输入描述

参数1：合法的 IPv4 主网段（CIDR 格式，即 IP 地址/掩码位数），例如：`192.168.10.0/24`，$24$ 表示子网掩码中二进制 $1$ 的个数，等价于 `255.255.255.0`（前 $24$ 位为 $1$）；

参数2：正整数 $N$，表示部门数量（$1 \leq N \leq 20$）；

参数3：整型数组，代表 $N$ 个部门各自的最小主机需求数。

# 输出描述

若分配可行，输出一个包含 $N$ 个 CIDR 字符串的数组格式，按升序排列：`[CIDR1, CIDR2, CIDR3, ..., CIDRn]`；

若输入网段非法、主机位不足 $2$ 位，或计算发现无法同时满足所有部门的主机数需求和子网数量需求，输出 `[]`；

## 补充说明

1. 所有生成的子网掩码长度必须完全一致，子网必须从主网段起始地址开始连续分配，子网地址不能重叠；
2. 可用主机数计算公式：可用主机数 $=2^{h} - 2$（其中 $h=32-\text{掩码位数}$）；例如 `192.168.1.0/24` 表示支持 $254$ 个主机（$32-24=8$，$2^8=256$，减去 $2$ 为 $254$，表示 `192.168.1.1~192.168.1.254`）；
4. 输入必须是合法的 IPv4 CIDR 格式（如 `192.168.1.0/24`）；

## 样例1

**输入**

```
"192.168.1.0/24",3,[10,20,50]
```

**输出**

```
["192.168.1.0/26","192.168.1.64/26","192.168.1.128/26"]
```

**说明**

1. 解析主网段：`192.168.1.0/24`，前缀 $24$，主机位 $h=32-24=8$。
2. 确定最大需求：需求分别为 $10$, $20$, $50$。最大需求为 $50$。
3. 计算所需主机位：
   - 需满足主机数 $=2^h-2 \geq 50 \Rightarrow 2^h \geq 52$。
   - $2^6=64$（足够）。
   - 故所需主机位 $h=6$，子网掩码长度 $=32-6=26$。
4. 计算子网数量：
   - 原来有 $8$ 位主机位，现在保留 $6$ 位，剩下 $2$ 位拿来编号子网。
   - $2$ 个二进制位有 $2^2=4$ 种组合，因此能划分 $4$ 个等长子网。
   - 可划分子网数 $=4$ 个。
   - 需求部门数 $N=3$，$4 \geq 3$，数量充足。
5. 分配地址（连续分配）：
   - 子网 1：`192.168.1.0/26`（需求 $10$，可用 $62$）
   - 子网 2：`192.168.1.64/26`（需求 $20$，可用 $62$）
   - 子网 3：`192.168.1.128/26`（需求 $50$，可用 $62$）

## 样例2

**输入**

```
"192.168.1.0/24",20,[100, 100, 100, 100, 100, 100, 100, 100, 100, 100, 100, 100, 100, 100, 100, 100, 100, 100, 100, 100]
```

**输出**

```
[]
```

**说明**

1. 最大需求：$100$。
2. 所需主机位：$2^h-2 \geq 100 \Rightarrow h=7$。
3. 计算子网数量：
   - 原来有 $8$ 位主机位，现在保留 $7$ 位，剩下 $1$ 位拿来编号子网。
   - $1$ 个二进制位有 $2^1=2$ 种组合，因此能划分 $2$ 个等长子网。
4. 校验：
   - 需要分割 $20$ 个部门，但只有 $2$ 个可用子网。
   - $2 < 20$，无法满足。

## 样例3

**输入**

```
"192.168.1.0/24",2,[10,10]
```

**输出**

```
["192.168.1.0/28","192.168.1.16/28"]
```

**说明**

1. 解析主网段：`192.168.1.0/24`，前缀 $24$，主机位 $h=32-24=8$。
2. 确定最大需求：需求分别为 $10$, $10$。最大需求为 $10$。
3. 计算所需主机位：
   - 需满足主机数 $=2^h-2 \geq 10 \Rightarrow 2^h \geq 12$。
   - $2^4=16$（足够）。
   - 故所需主机位 $h=4$，子网掩码长度 $=32-4=28$。
4. 计算子网数量：
   - 原来有 $8$ 位主机位，现在保留 $4$ 位，剩下 $4$ 位拿来编号子网。
   - $4$ 个二进制位有 $2^4=16$ 种组合，因此能划分 $16$ 个等长子网。
   - 可划分子网数 $=16$ 个。
   - 需求部门数 $N=2$，$16 \geq 2$，数量充足。
5. 分配地址（连续分配）：
   - 子网 1：`192.168.1.0/28`（需求 $10$，可用 $14$）
   - 子网 2：`192.168.1.16/28`（需求 $10$，可用 $14$）
