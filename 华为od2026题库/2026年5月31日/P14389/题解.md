## 解题思路

本题给出的序列是二叉树的**层序遍历表示**，其中：

* 数字表示该位置存在部门节点；
* `#` 表示该位置没有部门节点；
* 每个存在的节点最多有两个子节点。

由于题目只要求最大深度，不需要真正构建二叉树，可以直接使用 **BFS（广度优先搜索）+ 队列** 处理层序序列。

其中 `nodes` 表示题目输入的字符串数组。

核心做法：

1. 如果数组为空，或根节点是 `#`，返回 `0`。
2. 使用队列保存当前存在节点的深度。
3. 从数组下标 `1` 开始，依次作为当前节点的左、右子节点。
4. 遇到非 `#` 节点，就把它的深度 `当前深度 + 1` 加入队列。
5. 遍历过程中维护最大深度即可。

## 复杂度分析

设序列长度为 `n`。

* 时间复杂度：`O(n)`

每个位置最多被访问一次，因此时间复杂度为 `O(n)`。

* 空间复杂度：`O(n)`

队列中最多可能存放一层中的所有节点，最坏情况下为 `O(n)`。

```python
from collections import deque

class Solution:
    def maxDepth(self, nodes):
        # 空树或根节点为空，深度为 0
        if not nodes or nodes[0] == "#":
            return 0

        # 队列中存储当前存在节点的深度
        queue = deque([1])
        index = 1
        ans = 1

        # 按层序数组模拟 BFS
        while queue:
            depth = queue.popleft()

            # 处理左子节点
            if index < len(nodes):
                if nodes[index] != "#":
                    queue.append(depth + 1)
                    ans = max(ans, depth + 1)
                index += 1

            # 处理右子节点
            if index < len(nodes):
                if nodes[index] != "#":
                    queue.append(depth + 1)
                    ans = max(ans, depth + 1)
                index += 1

        return ans
```

```java
import java.util.*;

class Solution {
    public int maxDepth(String[] nodes) {
        // 如果没有节点，或者根节点为空，深度为 0
        if (nodes == null || nodes.length == 0 || nodes[0].equals("#")) {
            return 0;
        }

        // 队列中存储每个存在节点对应的深度
        Queue<Integer> queue = new LinkedList<>();
        queue.offer(1);

        int index = 1;
        int ans = 1;

        // 按层序顺序处理每个存在的节点
        while (!queue.isEmpty()) {
            int depth = queue.poll();

            // 处理左子节点
            if (index < nodes.length) {
                if (!nodes[index].equals("#")) {
                    queue.offer(depth + 1);
                    ans = Math.max(ans, depth + 1);
                }
                index++;
            }

            // 处理右子节点
            if (index < nodes.length) {
                if (!nodes[index].equals("#")) {
                    queue.offer(depth + 1);
                    ans = Math.max(ans, depth + 1);
                }
                index++;
            }
        }

        return ans;
    }
}
```

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int maxDepth(char** nodes, int nodesSize) {
    // 空树或根节点为空
    if (nodesSize == 0 || strcmp(nodes[0], "#") == 0) {
        return 0;
    }

    // 队列存储深度（最多 1024 个节点）
    int queue[1100];
    int head = 0, tail = 0;

    // 根节点深度为 1
    queue[tail++] = 1;
    int ans = 1;
    int index = 1;

    while (head < tail) {
        int depth = queue[head++];

        // 处理左子节点
        if (index < nodesSize) {
            if (strcmp(nodes[index], "#") != 0) {
                queue[tail++] = depth + 1;
                if (depth + 1 > ans) ans = depth + 1;
            }
            index++;
        }

        // 处理右子节点
        if (index < nodesSize) {
            if (strcmp(nodes[index], "#") != 0) {
                queue[tail++] = depth + 1;
                if (depth + 1 > ans) ans = depth + 1;
            }
            index++;
        }
    }

    return ans;
}
```
