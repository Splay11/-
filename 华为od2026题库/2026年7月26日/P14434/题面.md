# 题目内容

在一个特殊的数学系统中，每个数字都有其独特的表示方式。给定两个不同的数字字符集和一个数字字符串，你需要将这个数字从一个字符系统转换到另一个字符系统。实现一个函数，将使用源字符集表示的数字转换为使用目标字符集表示的数字。

# 补充说明

- $1 \le \text{num.length} \le 100$
- $2 \le \text{sourceDigits.length} \le 36$
- $2 \le \text{targetDigits.length} \le 36$
- `sourceDigits` 和 `targetDigits` 由不同的字符组成，且不包含重复字符
- `num` 中的所有字符都存在于 `sourceDigits` 中
- 输入保证是有效的，不会出现非法字符
- 转换结果不应包含前导零，除非数字本身就是 $0$

## 样例1

**输入**

```
"101","01","0123456789"
```

**输出**

```
"5"
```

**说明**

解释: 二进制 `"101"` 转换为十进制是 `"5"`

## 样例2

**输入**

```
"ff","0123456789abcdef","0123456789"
```

**输出**

```
"255"
```

**说明**

解释: 十六进制 `"ff"` 转换为十进制是 `"255"`

## 样例3

**输入**

```
"100","01","0123456789abcdef"
```

**输出**

```
"4"
```

**说明**

解释: 二进制 `"100"` 转换为十六进制是 `"4"`

## 样例4

**输入**

```
"7","0123456789","01"
```

**输出**

```
"111"
```

**说明**

解释: 十进制 `"7"` 转换为二进制是 `"111"`

## 样例5

**输入**

```
"10012","01234","012"
```

**输出**

```
"212102"
```

**说明**

解释: 五进制 `"10012"` 转换为三进制是 `"212102"`
