# 题目内容

在一款游戏中设计炸弹人技能效果是预埋地雷，当敌人从地雷上走过时会触发地雷爆炸造成伤害。

当一个地雷被引爆时，在一定距离内的相邻的地雷也会引爆，这些能够同时引爆的枚收地雷雷形成一个雷区。一个雷区可以由一枚孤立的地雷组成，也可以有一片有连锁爆炸反应的多枚地雷组成。

现给出一组炸弹人地雷连锁爆炸关联数据，请计算有效雷区数量。

# 输入描述

地雷连锁爆炸关系数组 `isChainExplosion`：地雷连锁爆炸信息被记录在一个 $n \times n$ 的二维数组 `isChainExplosion` 中：
- `isChainExplosion[i][j] = 1` 表示第 $i$ 枚地雷和第 $j$ 枚地雷有互相引爆关系
- `isChainExplosion[i][j] = 0` 表示第 $i$ 枚地雷和第 $j$ 枚地雷不会被彼此还有引爆

输入用例保证：
- `isChainExplosion[i][i]` 和 `isChainExplosion[j][j]` 的值同时为 $0$ 或者同时为 $1$
- 地雷数量在 $[1, 20]$ 之间

# 输出描述

有效雷区数量。

## 样例1

**输入**

```
[[1,0],[0,1]]
```

**输出**

```
2
```

**说明**

两枚地雷互相独立，其中一枚被引爆时不会触发另一枚地雷，所以雷区数量是 $2$

## 样例2

**输入**

```
[[1,0,0],[0,1,1],[0,1,1]]
```

**输出**

```
2
```

**说明**

一枚三枚地雷，第一枚和第二、第三枚互相独立，第二枚和第三枚临近且引爆，因此雷区数量是 $2$

## 样例3

**输入**

```
[[1,1,1],[1,1,1],[1,1,1]]
```

**输出**

```
1
```

**说明**

全连通场景，三枚地雷两两直接互相引爆，形成一个雷区
