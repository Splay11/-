# 题目内容

给定一个非负整数数组 `nums`，满足以下两个前提条件：

1. 数组长度为偶数，且 $2 \le \text{nums.length} \le 20000$
2. 数组中恰好有一半元素是偶数，另一半元素是奇数

请你对该数组进行重构，满足以下两个核心要求：

1. 重构后的数组中，所有位于**偶数下标**（下标从 $0$ 开始）的元素必须是**偶数**，所有位于**奇数下标**的元素必须是**奇数**
2. 重构后，所有占据偶数下标的偶数元素，需按照**从小到大**的升序排列；所有占据奇数下标的奇数元素，也需按照**从小到大**的升序排列

返回满足上述所有条件的重构后数组。

**补充说明**

1. 数组长度 $n$ 满足 $2 \le n \le 20000$，且 $n \% 2 == 0$
2. 数组中的元素为非负整数，满足 $0 \le \text{nums}[i] \le 1000$
3. 数组中偶数和奇数的数量严格相等，各占 $n/2$ 个
4. 满足条件的输出数组是唯一的

## 样例1

**输入**

```
[4,2,5,7]
```

**输出**

```
[2,5,4,7]
```

## 样例2

**输入**

```
[1,3,2,6,8,5]
```

**输出**

```
[2,1,6,3,8,5]
```

**说明**

偶数元素为 `[2,6,8]`（升序后仍为 `[2,6,8]`），奇数元素为 `[1,3,5]`（升序后仍为 `[1,3,5]`）

## 样例3

**输入**

```
[9,0,3,4,7,2]
```

**输出**

```
[0,3,2,7,4,9]
```

**说明**

偶数元素为 `[0,4,2]`（升序后为 `[0,2,4]`），奇数元素为 `[9,3,7]`（升序后为 `[3,7,9]`）
