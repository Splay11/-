# 路口等待时间

## 解题思路

本题是一道**模拟**题，核心在于理解红绿灯信号的周期规律以及四个方向的独立排队机制。

### 1. 信号周期分析

设周期 $C = R + G$，时间从 $0$ 开始计时。

- **东西向（E/W）**：$t=0$ 时为红灯，红灯持续 $R$ 秒，绿灯持续 $G$ 秒。
  - 红灯条件：$t \bmod C < R$
  - 绿灯条件：$t \bmod C \geq R$

- **南北向（S/N）**：与东西向相反。
  - 绿灯条件：$t \bmod C < R$
  - 红灯条件：$t \bmod C \geq R$

### 2. 每辆车的处理

对于每辆车，需要计算其**能够开始通行的时间**，取以下两者的较大值：

1. **信号灯可用时间**：如果车到达时是绿灯，可以直接走；如果是红灯，需要等到下一次绿灯开始。通过取模运算 $t \bmod C$ 可以快速判断并计算下一绿灯开始时刻。
2. **同方向前车离开时间**：每个方向（E/W/S/N 各一条独立车道）有各自的排队队列，同方向后车必须等前车完全通过（通行需 $1$ 秒）后才能开始。

维护四个方向各自上辆车离开的时间 `last`，每处理一辆车就更新对应方向的时间。

### 3. 结果计算

第一辆车到达时间固定已知（数组首元素），最后一辆离开时间等于四个方向 `last` 值的最大值。总耗时 = 最后一辆离开时间 − 第一辆到达时间。返回 `[总耗时, 最后一辆离开时间]`。

## 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n$ 为车辆数量。只需要按顺序遍历所有车辆一次，每辆车的处理为 $O(1)$ 的常数操作。
- **空间复杂度**：$O(1)$，只需维护 4 个方向的 `last` 变量，与输入规模无关。

from typing import List

class Solution:
    def intersectionWaitingTime(self, R: int, G: int, directions: List[int], arrivalTimes: List[int]) -> List[int]:
        C = R + G
        # 记录每个方向上一辆车离开的时间
        last = {'E': 0, 'W': 0, 'S': 0, 'N': 0}

        for i in range(len(directions)):
            d = directions[i]
            t = arrivalTimes[i]

            # 判断当前方向的信号状态
            if d == 'E' or d == 'W':
                # 东西向：t % C < R 时为红灯
                if t % C < R:
                    next_green = t - (t % C) + R  # 等到本周期绿灯开始
                else:
                    next_green = t
            else:
                # 南北向：t % C >= R 时为红灯
                if t % C >= R:
                    next_green = t - (t % C) + C  # 等到下一周期开始
                else:
                    next_green = t

            # 取信号可用时间与同方向排队时间的较大值
            start = max(next_green, last[d])
            last[d] = start + 1  # 通行需要 1 秒

        first_arrival = arrivalTimes[0]
        last_leave = max(last.values())

        return [last_leave - first_arrival, last_leave]

#include <stdlib.h>

/**
 * @param R 东西向红灯时长
 * @param G 东西向绿灯时长
 * @param directions 方向字符数组
 * @param directionsSize 方向数组长度
 * @param arrivalTimes 到达时间数组
 * @param arrivalTimesSize 到达时间数组长度
 * @param returnSize 传出结果数组长度
 * @return 长度为 2 的数组 [总耗时, 最后一辆离开的时间]
 */
int* intersectionWaitingTime(int R, int G, char* directions, int directionsSize,
                             int* arrivalTimes, int arrivalTimesSize, int* returnSize) {
    int C = R + G;
    // 记录每个方向上一辆车离开的时间
    int lastE = 0, lastW = 0, lastS = 0, lastN = 0;

    for (int i = 0; i < directionsSize; i++) {
        char d = directions[i];
        int t = arrivalTimes[i];
        int mod = t % C;
        int nextGreen, start;

        // 判断当前方向的信号状态
        if (d == 'E' || d == 'W') {
            // 东西向：t % C < R 时为红灯
            if (mod < R) {
                nextGreen = t - mod + R;  // 等到本周期绿灯开始
            } else {
                nextGreen = t;
            }
        } else {
            // 南北向：t % C >= R 时为红灯
            if (mod >= R) {
                nextGreen = t - mod + C;  // 等到下一周期开始
            } else {
                nextGreen = t;
            }
        }

        // 取信号可用时间与同方向排队时间的较大值
        if (d == 'E') {
            start = nextGreen > lastE ? nextGreen : lastE;
            lastE = start + 1;  // 通行需要 1 秒
        } else if (d == 'W') {
            start = nextGreen > lastW ? nextGreen : lastW;
            lastW = start + 1;
        } else if (d == 'S') {
            start = nextGreen > lastS ? nextGreen : lastS;
            lastS = start + 1;
        } else { /* 'N' */
            start = nextGreen > lastN ? nextGreen : lastN;
            lastN = start + 1;
        }
    }

    int firstArrival = arrivalTimes[0];
    // 取四个方向中最大的离开时间
    int lastLeave = lastE;
    if (lastW > lastLeave) lastLeave = lastW;
    if (lastS > lastLeave) lastLeave = lastS;
    if (lastN > lastLeave) lastLeave = lastN;

    int* result = (int*)malloc(2 * sizeof(int));
    result[0] = lastLeave - firstArrival;
    result[1] = lastLeave;

    *returnSize = 2;
    return result;
}
