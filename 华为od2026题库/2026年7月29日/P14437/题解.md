## 解题思路

本题的**核心问题**是：数据流中的点按**到达顺序**依次处理，对于每个到达的数据点，需要在**已经到达的数据点**中，找到时间戳落在 `[current_timestamp - interval, current_timestamp]` 内的最大测量值。

**关键观察**：
- 数据是乱序到达的——到达顺序与时间戳顺序不一定一致。因此，对于当前处理的数据点 `(t_i, v_i)`，之前可能已经到达了时间戳大于 `t_i` 的点（属于"未来"），这些点不在追溯窗口内，需要排除。
- 窗口的上界是 `t_i`（只能回溯到当前时间戳及之前），下界是 `t_i - interval`。

**算法思路**：

由于数据量较小（`n <= 1000`），可以采用**直接遍历**的方法：

1. 对于第 `i` 个数据点 `(t_i, v_i)`（`i` 从 0 开始，表示到达序号），初始化当前窗口最大值 `max_val = v_i`。
2. 遍历之前所有已到达的数据点 `j < i`：
   - 如果数据点 `j` 的时间戳 `t_j` 满足 `t_i - interval <= t_j <= t_i`，则将其测量值 `v_j` 与 `max_val` 比较并更新最大值。
3. 将 `max_val` 作为第 `i` 个结果加入答案数组。

时间复杂度为 O(n²)，空间复杂度为 O(n)。对于 `n <= 1000` 的规模完全可行。

## 复杂度分析

- **时间复杂度**：O(n²)，其中 n 为数据流长度。对于每个数据点，需要扫描其之前的所有数据点。n 最大为 1000，运算量约为 5 × 10⁵，可以在 2 秒时限内轻松通过。
- **空间复杂度**：O(n)，存储结果数组。

```python
class Solution:
    def getMaxValues(self, data: list[list[int]], interval: int) -> list[int]:
        n = len(data)
        result = []
        for i in range(n):
            ti, vi = data[i]            # 当前数据点的时间戳和测量值
            lower = ti - interval        # 回溯窗口下界
            max_val = vi                # 初始化为当前点的值
            for j in range(i):
                tj, vj = data[j]
                # 检查是否在时间窗口 [ti-interval, ti] 内
                if lower <= tj <= ti:
                    if vj > max_val:
                        max_val = vj
            result.append(max_val)
        return result
```
