# 题目内容

在一个充满魔法能量的**消除游戏**中，一排排不同颜色的能量球（代表不同质量/能量值）静止在网格中。当玩家触发消除机制时，相邻的能量球会发生**相互碰撞**。

## 消除规则：

1. **碰撞机制**：当两个相邻的能量球相遇时，系统会根据它们的能量值（质量）进行判断。
2. **强弱判定**：如果两个能量球的能量值**不同**，能量值**较低**的那个球会被对手的能量波吞噬，从而消除。
3. **同归于尽**：如果两个能量球的能量值**完全相同**，它们会引发剧烈的能量湮灭反应，导致**两者同时被消除**。
4. **幸存条件**：只有能量值足够高且未发生碰撞（或碰撞后存活）的能量球，才能留在场上继续等待下一轮消除。

## 题目目标：

给定一排初始的能量球序列，请模拟上述消除过程，找出最终**留在场上**的所有能量球及其顺序。

## 约束：

能量球的个数不超过 $1000$ 个，能量球的能量值是非负整数，最大不超过 $10000$

# 输入描述

输入为一行字符串，格式为 `n,[a1,a2,a3,...,an]`，其中 $n$ 表示能量球的数量，方括号内为初始能量球序列的数值列表。

# 输出描述

输出最终留在场上的所有能量球序列，以数组形式表示，格式为 `[b1,b2,...,bm]`。

## 样例1

**输入**

```
5,[3,5,5,2,3]
```

**输出**

```
[3]
```

**说明**

1. 遇到 $3$：场上空，$3$ 上场。
   * 当前场上：`[3]`
2. 遇到 $5$：场上有 $3$。因为 $5 > 3$ ($5$比$3$大)，$3$ 被 $5$ 吃掉。$5$ 继续检查，场上空了，$5$ 上场。
   * 当前场上：`[5]`
3. 遇到 $5$：场上有 $5$。因为 $5 == 5$ (两个一样大)，$5$ 和 $5$ 同归于尽。
   * 当前场上：`[]` (空)
4. 遇到 $2$：场上空，$2$ 上场。
   * 当前场上：`[2]`
5. 遇到 $3$：场上有 $2$。因为 $3 > 2$ ($3$比$2$大)，$2$ 被 $3$ 吃掉。$3$ 继续检查，场上空了，$3$ 上场。
   * 当前场上：`[3]`

最终结果：场上只剩下一个 $3$。

## 样例2

**输入**

```
6,[1,2,2,1,3,4]
```

**输出**

```
[4]
```

**说明**

1. 遇到 $1$：上场。`[1]`
2. 遇到 $2$：场上有 $1$。$2 > 1$，$1$ 被 $2$ 吃掉。$2$ 上场。`[2]`
3. 遇到 $2$：场上有 $2$。$2 == 2$，$2$ 和 $2$ 同归于尽。`[]`
4. 遇到 $1$：场上空，$1$ 上场。`[1]`
5. 遇到 $3$：场上有 $1$。$3 > 1$，$1$ 被 $3$ 吃掉。$3$ 上场。`[3]`
6. 遇到 $4$：场上有 $3$。$4 > 3$，$3$ 被 $4$ 吃掉。$4$ 上场。`[4]`

最终结果：场上只剩下一个 $4$。
