## 解题思路

分析消除规则可以发现一个关键性质：**场上最多只有一个能量球**。

推理过程：初始场上为空。每来一个新球，它与场上的幸存者发生碰撞——大的留下、小的被消除、相等的同归于尽。碰撞后场上要么有一个幸存者（大的那个），要么为空（同归于尽），绝不可能出现两个球并存的情况。因此整个过程只需维护 **一个变量** 记录当前幸存者的能量值。

**算法步骤**：

1. 设 `survivor` 为空（表示场上无球）。
2. 遍历每个能量球 $e$：
   - 若 `survivor` 为空 → 当前球上场，`survivor = e`
   - 若 $e >$ `survivor` → 当前球更强，替换幸存者，`survivor = e`
   - 若 $e =$ `survivor` → 同归于尽，`survivor =` 空
   - 若 $e <$ `survivor` → 当前球被消除，幸存者不变
3. 遍历结束后，若 `survivor` 非空则返回 `[survivor]`，否则返回 `[]`。

**示例推演**（样例 1：`[3, 5, 5, 2, 3]`）：

| 当前球 | 操作 | 幸存者 |
|--------|------|--------|
| $3$ | 场上空，上场 | $3$ |
| $5$ | $5 > 3$，$3$ 被消除 | $5$ |
| $5$ | $5 = 5$，同归于尽 | 空 |
| $2$ | 场上空，上场 | $2$ |
| $3$ | $3 > 2$，$2$ 被消除 | $3$ |

最终返回 `[3]`。

## 复杂度分析

- **时间复杂度**：$O(n)$，只需遍历一次序列。
- **空间复杂度**：$O(1)$，仅维护一个变量，输出数组长度至多为 $1$。

```python
from typing import List

class Solution:
    def energyCollision(self, energies: List[int]) -> List[int]:
        # 维护场上唯一的幸存者（None 表示空）
        survivor = None
        for e in energies:
            if survivor is None:
                # 场上空，当前球直接上场
                survivor = e
            elif e > survivor:
                # 当前球更强，替换幸存者
                survivor = e
            elif e == survivor:
                # 能量相同，同归于尽
                survivor = None
            # e < survivor: 当前球被消除，幸存者不变
        return [survivor] if survivor is not None else []
```

```c
#include <stdlib.h>

/**
 * @param energies 能量球数组
 * @param energiesSize 数组长度
 * @param returnSize 返回数组长度
 * @return 最终留在场上的能量球数组（至多一个元素，需调用方释放）
 */
int* energyCollision(int* energies, int energiesSize, int* returnSize) {
    // 维护场上唯一的幸存者（-1 表示空）
    int survivor = -1;
    for (int i = 0; i < energiesSize; i++) {
        int e = energies[i];
        if (survivor == -1)
            // 场上空，当前球直接上场
            survivor = e;
        else if (e > survivor)
            // 当前球更强，替换幸存者
            survivor = e;
        else if (e == survivor)
            // 能量相同，同归于尽
            survivor = -1;
        // e < survivor: 当前球被消除
    }
    if (survivor == -1) {
        *returnSize = 0;
        return NULL;
    }
    *returnSize = 1;
    int* res = (int*)malloc(sizeof(int));
    res[0] = survivor;
    return res;
}
```
