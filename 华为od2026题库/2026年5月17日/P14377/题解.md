## 解题思路

题目要求统计 $14$ 张牌组成基本胡牌型的方案数量，即恰好拆成 $4$ 个面子和 $1$ 对将牌。

每张牌由花色和点数组成。由于只有三种花色，每种花色有 $1$ 到 $9$ 九种点数，因此一共只有 $27$ 种不同的牌。可以把每张牌映射成一个下标：

$index = (color - 1) \times 9 + (number - 1)$

然后统计每种牌出现的次数。

统计方案数时，可以枚举哪一种牌作为将牌：

1. 如果某种牌数量不少于 $2$，就先拿出两张作为将牌。
2. 剩下 $12$ 张牌需要全部拆成 $4$ 个面子。
3. 用递归搜索统计拆面子的方案数。

为了避免同一种拆法因为面子顺序不同而被重复计算，递归时每次都找到当前还剩牌中下标最小的一种牌，并且必须让这张牌参与当前要拆出的第一个面子。

对于这张最小的剩余牌，有两种可能：

1. 如果数量不少于 $3$，可以拆一个刻子。
2. 如果它的点数不超过 $7$，并且同花色的后两张连续牌都存在，可以拆一个顺子。

这样递归下去，如果所有牌都被拆完，说明得到了一种合法拆法。

为了提高效率，可以对当前牌数状态进行记忆化搜索。状态可以用 $27$ 个计数拼成的数组、字符串或元组表示。

## 复杂度分析

牌的种类固定为 $27$ 种，手牌数量固定为 $14$ 张。

枚举将牌最多 $27$ 种。每次递归都会拿走 $3$ 张牌，最多递归 $4$ 层。虽然递归中存在分支，但由于牌数和种类都是常数，并且使用了记忆化搜索，因此实际运行非常快。

时间复杂度可以看作 $O(S)$，其中 $S$ 是可达牌数状态数量。在本题固定 $14$ 张牌的限制下，$S$ 很小，可以视为常数级。

空间复杂度为 $O(S)$，主要来自记忆化搜索保存的状态。

from functools import lru_cache

class Solution:
    def countWinningHands(self, colors, numbers):
        # 统计 27 种牌的数量
        counts = [0] * 27
        for c, n in zip(colors, numbers):
            idx = (c - 1) * 9 + (n - 1)
            counts[idx] += 1

        @lru_cache(None)
        def dfs(state):
            # state 是不可变元组，方便作为记忆化搜索的键
            arr = list(state)

            # 找到当前还剩的最小下标牌
            first = -1
            for i in range(27):
                if arr[i] > 0:
                    first = i
                    break

            # 没有剩余牌，说明全部成功拆成面子
            if first == -1:
                return 1

            ans = 0

            # 尝试拆刻子：三张完全相同的牌
            if arr[first] >= 3:
                arr[first] -= 3
                ans += dfs(tuple(arr))
                arr[first] += 3

            # 尝试拆顺子：同花色连续三张
            suit = first // 9
            rank = first % 9

            # rank <= 6 表示点数不超过 7，才可能组成 x, x+1, x+2
            if rank <= 6:
                second = first + 1
                third = first + 2

                # second 和 third 一定还在同一花色内
                if arr[second] > 0 and arr[third] > 0:
                    arr[first] -= 1
                    arr[second] -= 1
                    arr[third] -= 1

                    ans += dfs(tuple(arr))

                    arr[first] += 1
                    arr[second] += 1
                    arr[third] += 1

            return ans

        total = 0

        # 枚举将牌
        for i in range(27):
            if counts[i] >= 2:
                counts[i] -= 2
                total += dfs(tuple(counts))
                counts[i] += 2

        return total

import java.util.*;

class Solution {
    private HashMap<String, Long> memo;

    public long countWinningHands(int[] colors, int[] numbers) {
        int[] counts = new int[27];

        // 统计 27 种牌的数量
        for (int i = 0; i < 14; i++) {
            int idx = (colors[i] - 1) * 9 + (numbers[i] - 1);
            counts[idx]++;
        }

        memo = new HashMap<>();
        long total = 0;

        // 枚举将牌
        for (int i = 0; i < 27; i++) {
            if (counts[i] >= 2) {
                counts[i] -= 2;
                total += dfs(counts);
                counts[i] += 2;
            }
        }

        return total;
    }

    private long dfs(int[] counts) {
        String key = encode(counts);
        if (memo.containsKey(key)) {
            return memo.get(key);
        }

        // 找到当前还剩的最小下标牌
        int first = -1;
        for (int i = 0; i < 27; i++) {
            if (counts[i] > 0) {
                first = i;
                break;
            }
        }

        // 没有剩余牌，说明全部成功拆成面子
        if (first == -1) {
            return 1;
        }

        long ans = 0;

        // 尝试拆刻子：三张完全相同的牌
        if (counts[first] >= 3) {
            counts[first] -= 3;
            ans += dfs(counts);
            counts[first] += 3;
        }

        // 尝试拆顺子：同花色连续三张
        int rank = first % 9;

        // rank <= 6 表示点数不超过 7，才可能组成 x, x+1, x+2
        if (rank <= 6) {
            int second = first + 1;
            int third = first + 2;

            if (counts[second] > 0 && counts[third] > 0) {
                counts[first]--;
                counts[second]--;
                counts[third]--;

                ans += dfs(counts);

                counts[first]++;
                counts[second]++;
                counts[third]++;
            }
        }

        memo.put(key, ans);
        return ans;
    }

    private String encode(int[] counts) {
        StringBuilder sb = new StringBuilder();

        // 每种牌数量不会很多，用分隔符拼接即可唯一表示状态
        for (int x : counts) {
            sb.append(x).append('#');
        }

        return sb.toString();
    }
}
