## 解题思路
题目的关键有两点：

1. 一个 AP 会覆盖自己所在位置周围的 3 × 3 区域。
2. 任意两个 AP 的覆盖区域不能重叠。

因此，一旦某个 AP 被选中，它对应的整块覆盖区域中的所有格子都不能再被其他 AP 使用。与此同时，所有空地 `.` 都必须被至少一个 AP 覆盖。

这可以转化为一个带约束的搜索问题：

- 每个可以放置 AP 的空地 `(i, j)` 都对应一个候选方案；
- 这个候选方案会覆盖一个固定的格子集合；
- 所有空地都必须被覆盖；
- 任意两个候选方案的覆盖格子集合不能有交集；
- 目标是让 AP 数量最少。

为了高效处理，我们可以使用下面的做法：

1. 先枚举所有合法的 AP 位置，也就是所有空地位置。
2. 预处理每个 AP 会覆盖哪些空地、会占用哪些实际格子。
3. 深度优先搜索：
   - 每次挑选一个当前还没有被覆盖的空地；
   - 枚举所有能够覆盖这个空地的 AP；
   - 如果该 AP 与已经选择的 AP 的覆盖区域没有冲突，则尝试选择它；
   - 不断更新当前最优答案。
4. 使用剪枝优化：
   - 如果当前已选 AP 数量已经不优于当前最优答案，直接返回；
   - 每次优先选择“可选 AP 数量最少”的空地，能显著减少分支。

这个方法本质上是一个精确覆盖搜索。虽然理论最坏情况较大，但在函数题、面试题和常见测试数据中表现通常较好。

### 复杂度分析

最坏情况下这是一个指数级搜索问题。

设：

- 空地数量为 `E`
- 候选 AP 数量为 `K`

则最坏时间复杂度可以写成：

- 时间复杂度：`O(指数级)`  
- 空间复杂度：`O(K + E)`

其中空间主要用于：

- 存储候选 AP 的覆盖信息；
- 递归搜索栈；
- 若干位集或布尔标记数组。

在实际实现中，由于每个 AP 最多只影响 9 个格子，且采用了“选择候选数最少的空地”这一剪枝策略，实际运行通常会快很多。

```python
class Solution:
    def networkPlanning(self, roomArrangement):
        # 获取行数
        m = len(roomArrangement)
        # 空网格直接返回 0
        if m == 0:
            return 0

        # 获取列数
        n = len(roomArrangement[0])

        # 给每个空地分配一个编号
        # 后续用二进制位来表示“这个空地是否已被覆盖”
        empty_id = {}
        empty_cells = []

        for i in range(m):
            for j in range(n):
                if roomArrangement[i][j] == '.':
                    empty_id[(i, j)] = len(empty_cells)
                    empty_cells.append((i, j))

        # 空地总数
        total_empty = len(empty_cells)

        # 没有空地，不需要放 AP
        if total_empty == 0:
            return 0

        # candidates 中每个元素表示一个候选 AP 放置方案
        # 每个候选保存三个信息：
        # 1. cover_full：该 AP 的 3×3 区域占用了哪些实际格子
        # 2. cover_empty：该 AP 覆盖了哪些空地
        # 3. covered_empty_list：该 AP 覆盖到的空地下标列表
        candidates = []

        # covers_of_empty[eid] 表示：
        # 能覆盖第 eid 个空地的所有候选 AP 编号
        covers_of_empty = [[] for _ in range(total_empty)]

        # 枚举所有可以放 AP 的位置
        # 题目规定只有 '.' 才能放 AP
        for i in range(m):
            for j in range(n):
                if roomArrangement[i][j] != '.':
                    continue

                # 用一个整数的二进制位表示该候选 AP 占用的实际格子
                cover_full = 0

                # 用一个整数的二进制位表示该候选 AP 覆盖到的空地
                cover_empty = 0

                # 记录它具体覆盖了哪些空地编号
                covered_empty_list = []

                # 枚举以 (i,j) 为中心的 3×3 覆盖区域
                for x in range(max(0, i - 1), min(m - 1, i + 1) + 1):
                    for y in range(max(0, j - 1), min(n - 1, j + 1) + 1):
                        # 把二维坐标压成一维编号，用于实际格子占用状态
                        full_index = x * n + y
                        cover_full |= 1 << full_index

                        # 如果这个格子本身是空地，则说明它会被这个 AP 覆盖
                        if roomArrangement[x][y] == '.':
                            eid = empty_id[(x, y)]
                            cover_empty |= 1 << eid
                            covered_empty_list.append(eid)

                # 当前候选 AP 的编号
                cid = len(candidates)
                candidates.append((cover_full, cover_empty, covered_empty_list))

                # 反向建立索引：
                # 对于每个被当前候选覆盖的空地，记录“它可以被这个候选覆盖”
                for eid in covered_empty_list:
                    covers_of_empty[eid].append(cid)

        # 如果存在某块空地，没有任何候选 AP 能覆盖到它
        # 那么显然无解
        for eid in range(total_empty):
            if not covers_of_empty[eid]:
                return -1

        # 所有空地都覆盖时的目标状态
        # 如果有 total_empty 个空地，那么低 total_empty 位全为 1
        all_covered = (1 << total_empty) - 1

        # best[0] 记录当前找到的最优解
        # 用列表包一层，方便在内部递归函数中修改
        best = [10 ** 9]

        def dfs(covered_empty_mask, occupied_full_mask, used_count):
            # 剪枝 1：
            # 当前已使用的 AP 数已经不可能优于最优解，直接返回
            if used_count >= best[0]:
                return

            # 如果所有空地都已覆盖，更新答案
            if covered_empty_mask == all_covered:
                best[0] = used_count
                return

            # target_list 用来保存“当前要处理的那个空地”的所有合法候选 AP
            target_list = None

            # 我们采用“最少剩余值”思想：
            # 每次优先选当前合法候选数最少的未覆盖空地
            # 这样更容易提前发现死路，减少搜索分支
            min_choices = 10 ** 9

            # 枚举每个空地，找一个尚未被覆盖的目标空地
            for eid in range(total_empty):
                # 如果该空地已经被覆盖，就跳过
                if (covered_empty_mask >> eid) & 1:
                    continue

                # valid 保存当前这个空地还能使用的候选 AP
                valid = []

                for cid in covers_of_empty[eid]:
                    cover_full, _, _ = candidates[cid]

                    # 如果当前候选 AP 的覆盖区域与已经选择的 AP 覆盖区域有交集
                    # 说明两个 AP 会相互干扰，不合法
                    if cover_full & occupied_full_mask:
                        continue

                    valid.append(cid)

                # 如果某个尚未覆盖的空地已经没有合法候选
                # 当前分支必然失败
                if not valid:
                    return

                # 选择合法候选数量最少的那个空地来扩展
                if len(valid) < min_choices:
                    min_choices = len(valid)
                    target_list = valid

                    # 如果只有一种选法，已经是很强的限制，可以直接停止继续找
                    if min_choices == 1:
                        break

            # 枚举当前目标空地的所有合法候选 AP
            for cid in target_list:
                cover_full, cover_empty, _ = candidates[cid]

                # 递归进入下一层：
                # 1. 已覆盖空地状态增加当前候选覆盖到的空地
                # 2. 已占用格子状态增加当前候选的 3×3 覆盖区域
                # 3. AP 数量加 1
                dfs(
                    covered_empty_mask | cover_empty,
                    occupied_full_mask | cover_full,
                    used_count + 1
                )

        # 从“还没有覆盖任何空地，也没有占用任何格子”的状态开始搜索
        dfs(0, 0, 0)

        # 如果 best 没有被更新，说明无解
        return -1 if best[0] == 10 ** 9 else best[0]
```

```java
import java.util.ArrayList;
import java.util.List;

public class Solution {
    // Candidate 表示一个候选 AP 放置方案
    static class Candidate {
        // fullMask：这个 AP 的 3×3 覆盖区域占用了哪些实际格子
        long[] fullMask;

        // emptyMask：这个 AP 覆盖了哪些空地
        long[] emptyMask;

        // coveredEmptyList：这个 AP 覆盖到的空地下标列表
        List<Integer> coveredEmptyList;

        Candidate(long[] fullMask, long[] emptyMask, List<Integer> coveredEmptyList) {
            this.fullMask = fullMask;
            this.emptyMask = emptyMask;
            this.coveredEmptyList = coveredEmptyList;
        }
    }

    // 网格大小
    private int m;
    private int n;

    // 空地总数
    private int totalEmpty;

    // 当前最优答案
    private int best;

    // 所有候选 AP
    private List<Candidate> candidates;

    // coversOfEmpty[eid]：能覆盖第 eid 个空地的所有候选 AP 编号
    private List<List<Integer>> coversOfEmpty;

    // 所有空地都被覆盖时的目标状态
    private long[] allCoveredMask;

    public int networkPlanning(char[][] roomArrangement) {
        // 获取行数
        m = roomArrangement.length;
        if (m == 0) {
            return 0;
        }

        // 获取列数
        n = roomArrangement[0].length;

        // emptyId[i][j] 表示空地 (i,j) 对应的编号
        // 若不是空地，则保持为 -1
        int[][] emptyId = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                emptyId[i][j] = -1;
            }
        }

        // 给所有空地编号
        totalEmpty = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (roomArrangement[i][j] == '.') {
                    emptyId[i][j] = totalEmpty++;
                }
            }
        }

        // 没有空地则不需要放 AP
        if (totalEmpty == 0) {
            return 0;
        }

        // Java 没有像 Python 那样的大整数位运算，这里用 long[] 模拟位集
        // 一个 long 存 64 位
        int fullWords = (m * n + 63) >> 6;
        int emptyWords = (totalEmpty + 63) >> 6;

        candidates = new ArrayList<>();
        coversOfEmpty = new ArrayList<>();
        for (int i = 0; i < totalEmpty; i++) {
            coversOfEmpty.add(new ArrayList<>());
        }

        // 枚举所有候选 AP
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 只有空地可以放 AP
                if (roomArrangement[i][j] != '.') {
                    continue;
                }

                long[] fullMask = new long[fullWords];
                long[] emptyMask = new long[emptyWords];
                List<Integer> coveredEmptyList = new ArrayList<>();

                // 枚举这个 AP 的 3×3 覆盖区域
                for (int x = Math.max(0, i - 1); x <= Math.min(m - 1, i + 1); x++) {
                    for (int y = Math.max(0, j - 1); y <= Math.min(n - 1, j + 1); y++) {
                        // 记录它占用的实际格子
                        int fullIndex = x * n + y;
                        fullMask[fullIndex >> 6] |= 1L << (fullIndex & 63);

                        // 若该格子本身是空地，则会被此 AP 覆盖
                        if (roomArrangement[x][y] == '.') {
                            int eid = emptyId[x][y];
                            emptyMask[eid >> 6] |= 1L << (eid & 63);
                            coveredEmptyList.add(eid);
                        }
                    }
                }

                // 当前候选 AP 编号
                int cid = candidates.size();
                candidates.add(new Candidate(fullMask, emptyMask, coveredEmptyList));

                // 建立反向索引：哪些候选能够覆盖某个空地
                for (int eid : coveredEmptyList) {
                    coversOfEmpty.get(eid).add(cid);
                }
            }
        }

        // 如果某个空地没有任何候选 AP 能覆盖，则无解
        for (int eid = 0; eid < totalEmpty; eid++) {
            if (coversOfEmpty.get(eid).isEmpty()) {
                return -1;
            }
        }

        // 构造“全部空地都被覆盖”的目标状态
        allCoveredMask = new long[emptyWords];
        for (int i = 0; i < totalEmpty; i++) {
            allCoveredMask[i >> 6] |= 1L << (i & 63);
        }

        // 初始化最优答案
        best = Integer.MAX_VALUE;

        // 从初始空状态开始搜索
        dfs(new long[emptyWords], new long[fullWords], 0);

        return best == Integer.MAX_VALUE ? -1 : best;
    }

    private void dfs(long[] coveredEmptyMask, long[] occupiedFullMask, int usedCount) {
        // 剪枝：当前已使用 AP 数已经不优于最优解
        if (usedCount >= best) {
            return;
        }

        // 若所有空地都已覆盖，则更新最优答案
        if (isEqualMask(coveredEmptyMask, allCoveredMask)) {
            best = usedCount;
            return;
        }

        // targetList 保存当前选中的目标空地对应的所有合法候选 AP
        List<Integer> targetList = null;
        int minChoices = Integer.MAX_VALUE;

        // 找一个尚未覆盖的空地，并优先选当前合法候选数最少的那个
        for (int eid = 0; eid < totalEmpty; eid++) {
            // 如果该空地已覆盖，则跳过
            if (((coveredEmptyMask[eid >> 6] >>> (eid & 63)) & 1L) != 0) {
                continue;
            }

            List<Integer> valid = new ArrayList<>();

            // 枚举所有可以覆盖该空地的候选 AP
            for (int cid : coversOfEmpty.get(eid)) {
                Candidate cand = candidates.get(cid);

                // 若与已选 AP 的覆盖区域有重叠，则不能选
                if (!hasIntersection(cand.fullMask, occupiedFullMask)) {
                    valid.add(cid);
                }
            }

            // 如果当前这个尚未覆盖的空地已经没有合法候选
            // 当前搜索分支直接失败
            if (valid.isEmpty()) {
                return;
            }

            // 选合法候选数最少的空地，减少分支数
            if (valid.size() < minChoices) {
                minChoices = valid.size();
                targetList = valid;
                if (minChoices == 1) {
                    break;
                }
            }
        }

        // 枚举当前目标空地的所有合法候选 AP
        for (int cid : targetList) {
            Candidate cand = candidates.get(cid);

            // Java 数组是引用类型，必须 clone，
            // 否则会污染其他递归分支的状态
            long[] nextCovered = coveredEmptyMask.clone();
            orMask(nextCovered, cand.emptyMask);

            long[] nextOccupied = occupiedFullMask.clone();
            orMask(nextOccupied, cand.fullMask);

            dfs(nextCovered, nextOccupied, usedCount + 1);
        }
    }

    // 判断两个位集是否有交集
    // 若有交集，说明两个 AP 的覆盖区域重叠，不能同时选
    private boolean hasIntersection(long[] a, long[] b) {
        for (int i = 0; i < a.length; i++) {
            if ((a[i] & b[i]) != 0) {
                return true;
            }
        }
        return false;
    }

    // a |= b
    // 表示把 b 中为 1 的状态并入 a
    private void orMask(long[] a, long[] b) {
        for (int i = 0; i < a.length; i++) {
            a[i] |= b[i];
        }
    }

    // 判断两个位集是否完全相等
    private boolean isEqualMask(long[] a, long[] b) {
        for (int i = 0; i < a.length; i++) {
            if (a[i] != b[i]) {
                return false;
            }
        }
        return true;
    }
}
```

```cpp
class Solution {
public:
    // Candidate 表示一个候选 AP 放置方案
    struct Candidate {
        // fullMask：该 AP 的 3×3 覆盖区域占用了哪些实际格子
        std::bitset<2500> fullMask;

        // emptyMask：该 AP 覆盖了哪些空地
        std::bitset<2500> emptyMask;

        // coveredEmptyList：该 AP 覆盖到的空地下标列表
        std::vector<int> coveredEmptyList;
    };

    int networkPlanning(std::vector<std::vector<char> >& roomArrangement) {
        // 获取行数
        int m = (int)roomArrangement.size();
        if (m == 0) {
            return 0;
        }

        // 获取列数
        int n = (int)roomArrangement[0].size();

        // 给每个空地分配编号，不是空地则为 -1
        std::vector<std::vector<int>> emptyId(m, std::vector<int>(n, -1));

        // 记录所有空地坐标，便于统计空地总数
        std::vector<std::pair<int, int>> emptyCells;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (roomArrangement[i][j] == '.') {
                    emptyId[i][j] = (int)emptyCells.size();
                    emptyCells.push_back({i, j});
                }
            }
        }

        // 空地总数
        int totalEmpty = (int)emptyCells.size();

        // 没有空地，不需要放 AP
        if (totalEmpty == 0) {
            return 0;
        }

        // 保存所有候选 AP
        std::vector<Candidate> candidates;

        // coversOfEmpty[eid]：所有能覆盖第 eid 个空地的候选 AP 编号
        std::vector<std::vector<int>> coversOfEmpty(totalEmpty);

        // 枚举每个可放 AP 的位置
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 只有空地可以放置 AP
                if (roomArrangement[i][j] != '.') {
                    continue;
                }

                Candidate cur;

                // 枚举这个 AP 的 3×3 覆盖区域
                for (int x = std::max(0, i - 1); x <= std::min(m - 1, i + 1); x++) {
                    for (int y = std::max(0, j - 1); y <= std::min(n - 1, j + 1); y++) {
                        // 标记它占用的实际格子
                        int fullIndex = x * n + y;
                        cur.fullMask.set(fullIndex);

                        // 如果该格子是空地，则它也会被覆盖
                        if (roomArrangement[x][y] == '.') {
                            int eid = emptyId[x][y];
                            cur.emptyMask.set(eid);
                            cur.coveredEmptyList.push_back(eid);
                        }
                    }
                }

                // 当前候选编号
                int cid = (int)candidates.size();
                candidates.push_back(cur);

                // 建立反向索引：这些空地可以被当前候选覆盖
                for (int eid : cur.coveredEmptyList) {
                    coversOfEmpty[eid].push_back(cid);
                }
            }
        }

        // 如果存在某块空地没有任何候选能覆盖，直接无解
        for (int eid = 0; eid < totalEmpty; eid++) {
            if (coversOfEmpty[eid].empty()) {
                return -1;
            }
        }

        // allCovered 表示“所有空地都被覆盖”的目标状态
        std::bitset<2500> allCovered;
        for (int i = 0; i < totalEmpty; i++) {
            allCovered.set(i);
        }

        // 当前最优答案
        int best = INT_MAX;

        // 深度优先搜索
        std::function<void(std::bitset<2500>, std::bitset<2500>, int)> dfs =
            [&](std::bitset<2500> coveredEmptyMask,
                std::bitset<2500> occupiedFullMask,
                int usedCount) {
                // 剪枝：已使用 AP 数不优于当前最优解
                if (usedCount >= best) {
                    return;
                }

                // 若全部空地都已覆盖，则更新最优答案
                if (coveredEmptyMask == allCovered) {
                    best = usedCount;
                    return;
                }

                // targetList 保存“当前被选中的目标空地”对应的所有合法候选 AP
                std::vector<int> targetList;
                int minChoices = INT_MAX;

                // 找一个尚未覆盖的空地，并优先选合法候选最少的那个
                for (int eid = 0; eid < totalEmpty; eid++) {
                    if (coveredEmptyMask.test(eid)) {
                        continue;
                    }

                    std::vector<int> valid;

                    // 枚举所有能覆盖这个空地的候选 AP
                    for (int cid : coversOfEmpty[eid]) {
                        // 如果当前候选的 3×3 区域和已选 AP 的覆盖区域有交集
                        // 就说明发生重叠，不能选
                        if ((candidates[cid].fullMask & occupiedFullMask).any()) {
                            continue;
                        }
                        valid.push_back(cid);
                    }

                    // 当前这个尚未覆盖的空地已经没有合法候选
                    // 当前搜索分支失败
                    if (valid.empty()) {
                        return;
                    }

                    // 采用“候选最少优先”的策略，减少分支
                    if ((int)valid.size() < minChoices) {
                        minChoices = (int)valid.size();
                        targetList = valid;
                        if (minChoices == 1) {
                            break;
                        }
                    }
                }

                // 枚举当前目标空地的所有合法候选 AP
                for (int cid : targetList) {
                    dfs(
                        // 新的已覆盖空地状态
                        coveredEmptyMask | candidates[cid].emptyMask,

                        // 新的已占用实际格子状态
                        occupiedFullMask | candidates[cid].fullMask,

                        // AP 数量 +1
                        usedCount + 1
                    );
                }
            };

        // 从空状态开始搜索
        dfs(std::bitset<2500>(), std::bitset<2500>(), 0);

        // 如果没有找到可行解，则返回 -1
        return best == INT_MAX ? -1 : best;
    }
};
```

```javascript
    // 给空地编号
    var emptyId = {};
    var emptyCells = [];
    for (var i = 0; i < m; i++) {
        for (var j = 0; j < n; j++) {
            if (roomArrangement[i][j] === '.') {
                emptyId[i * n + j] = emptyCells.length;
                emptyCells.push([i, j]);
            }
        }
    }

    var totalEmpty = emptyCells.length;
    if (totalEmpty === 0) return 0;

    // 生成所有候选 AP
    var candidates = [];
    var coversOfEmpty = [];
    for (var i = 0; i < totalEmpty; i++) coversOfEmpty.push([]);

    for (var r = 0; r < m; r++) {
        for (var c = 0; c < n; c++) {
            if (roomArrangement[r][c] !== '.') continue;

            var fullMask = 0n;
            var emptyMask = 0n;
            var emptyList = [];

            for (var dr = -1; dr <= 1; dr++) {
                var nr = r + dr;
                if (nr < 0 || nr >= m) continue;
                for (var dc = -1; dc <= 1; dc++) {
                    var nc = c + dc;
                    if (nc < 0 || nc >= n) continue;
                    var idx = nr * n + nc;
                    fullMask |= (1n << BigInt(idx));
                    if (roomArrangement[nr][nc] === '.') {
                        var eid = emptyId[idx];
                        emptyMask |= (1n << BigInt(eid));
                        emptyList.push(eid);
                    }
                }
            }

            var cid = candidates.length;
            candidates.push([fullMask, emptyMask, emptyList]);

            for (var k = 0; k < emptyList.length; k++) {
                coversOfEmpty[emptyList[k]].push(cid);
            }
        }
    }

    // 检查无覆盖的空地
    for (var eid = 0; eid < totalEmpty; eid++) {
        if (coversOfEmpty[eid].length === 0) return -1;
    }

    var allCovered = (1n << BigInt(totalEmpty)) - 1n;
    var best = totalEmpty + 1;

    function dfs(covered, occupied, used) {
        if (used >= best) return;
        if (covered === allCovered) {
            best = used;
            return;
        }

        var targetList = [];
        var minChoices = totalEmpty + 1;

        for (var eid = 0; eid < totalEmpty; eid++) {
            if (covered & (1n << BigInt(eid))) continue;

            var valid = [];
            var list = coversOfEmpty[eid];
            for (var k = 0; k < list.length; k++) {
                var cid = list[k];
                if (!(candidates[cid][0] & occupied)) {
                    valid.push(cid);
                }
            }

            if (valid.length === 0) return;
            if (valid.length < minChoices) {
                minChoices = valid.length;
                targetList = valid;
                if (minChoices === 1) break;
            }
        }

        for (var k = 0; k < targetList.length; k++) {
            var cid = targetList[k];
            var cand = candidates[cid];
            dfs(covered | cand[1], occupied | cand[0], used + 1);
            if (best === 1) return;
        }
    }

    dfs(0n, 0n, 0);
    return best > totalEmpty ? -1 : best;
};
```

```c
#include <stdlib.h>
#include <string.h>
#include <stdbool.h>
#include <limits.h>

#define MAX_CELLS 2500
#define BITSET_WORDS ((MAX_CELLS + 63) / 64)

typedef unsigned long long uint64;

static bool bitsetEq(const uint64* a, const uint64* b, int words) {
    for (int i = 0; i < words; i++)
        if (a[i] != b[i]) return false;
    return true;
}

static void bitsetOr(uint64* a, const uint64* b, int words) {
    for (int i = 0; i < words; i++) a[i] |= b[i];
}

static bool bitsetIntersects(const uint64* a, const uint64* b, int words) {
    for (int i = 0; i < words; i++)
        if (a[i] & b[i]) return true;
    return false;
}

static int bestAns;
static int totalEmpty;
static int candCount;
static uint64* candFull;
static uint64* candEmpty;
static int* candEmptyCnt;
static int** candEmptyList;
static int** coversOfEmpty;
static int* coversOfEmptyLen;
static uint64* allCovered;
static int fullWords, emptyWords;

static void dfsHelp(uint64* coveredEmpty, uint64* occupiedFull, int used, int rowCount, int colCount) {
    if (used >= bestAns) return;
    if (bitsetEq(coveredEmpty, allCovered, emptyWords)) {
        bestAns = used;
        return;
    }

    int targetEid = -1;
    int minChoices = INT_MAX;
    int savedCnt = 0;
    int savedCids[MAX_CELLS];

    for (int eid = 0; eid < totalEmpty; eid++) {
        if (coveredEmpty[eid >> 6] & (1ULL << (eid & 63))) continue;

        int cnt = 0;
        int validBuf[MAX_CELLS];
        for (int k = 0; k < coversOfEmptyLen[eid]; k++) {
            int cid = coversOfEmpty[eid][k];
            if (!bitsetIntersects(candFull + cid * fullWords, occupiedFull, fullWords)) {
                validBuf[cnt++] = cid;
            }
        }

        if (cnt == 0) return;
        if (cnt < minChoices) {
            minChoices = cnt;
            targetEid = eid;
            memcpy(savedCids, validBuf, cnt * sizeof(int));
            savedCnt = cnt;
            if (cnt == 1) break;
        }
    }

    if (targetEid == -1) return;

    int maxWords = (fullWords > emptyWords) ? fullWords : emptyWords;
    uint64 nextCovered[maxWords];
    uint64 nextOccupied[maxWords];

    for (int k = 0; k < savedCnt; k++) {
        int cid = savedCids[k];
        memcpy(nextCovered, coveredEmpty, emptyWords * sizeof(uint64));
        memcpy(nextOccupied, occupiedFull, fullWords * sizeof(uint64));
        bitsetOr(nextCovered, candEmpty + cid * emptyWords, emptyWords);
        bitsetOr(nextOccupied, candFull + cid * fullWords, fullWords);
        dfsHelp(nextCovered, nextOccupied, used + 1, rowCount, colCount);
        if (bestAns == 1) return;
    }
}

int networkPlanning(char** roomArrangement, int rows) {
    if (rows == 0) return 0;
    int cols = 0;
    while (roomArrangement[0][cols]) cols++;
    if (cols == 0) return 0;

    fullWords = (rows * cols + 63) / 64;
    int emptyId[rows * cols];
    memset(emptyId, -1, sizeof(emptyId));

    int* emptyRow = (int*)malloc(MAX_CELLS * sizeof(int));
    int* emptyCol = (int*)malloc(MAX_CELLS * sizeof(int));
    totalEmpty = 0;

    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            if (roomArrangement[i][j] == '.') {
                emptyId[i * cols + j] = totalEmpty;
                emptyRow[totalEmpty] = i;
                emptyCol[totalEmpty] = j;
                totalEmpty++;
            }
        }
    }

    if (totalEmpty == 0) {
        free(emptyRow); free(emptyCol);
        return 0;
    }

    emptyWords = (totalEmpty + 63) / 64;
    int maxCands = totalEmpty;
    candFull = (uint64*)calloc(maxCands * fullWords, sizeof(uint64));
    candEmpty = (uint64*)calloc(maxCands * emptyWords, sizeof(uint64));
    candEmptyCnt = (int*)calloc(maxCands, sizeof(int));
    candEmptyList = (int**)malloc(maxCands * sizeof(int*));
    candCount = 0;

    coversOfEmpty = (int**)malloc(totalEmpty * sizeof(int*));
    coversOfEmptyLen = (int*)calloc(totalEmpty, sizeof(int));
    for (int i = 0; i < totalEmpty; i++) {
        coversOfEmpty[i] = (int*)malloc(MAX_CELLS * sizeof(int));
    }

    for (int r = 0; r < rows; r++) {
        for (int c = 0; c < cols; c++) {
            if (roomArrangement[r][c] != '.') continue;
            int cid = candCount;
            uint64* cf = candFull + cid * fullWords;
            uint64* ce = candEmpty + cid * emptyWords;
            int eList[9];
            int ecnt = 0;

            for (int dr = -1; dr <= 1; dr++) {
                int nr = r + dr;
                if (nr < 0 || nr >= rows) continue;
                for (int dc = -1; dc <= 1; dc++) {
                    int nc = c + dc;
                    if (nc < 0 || nc >= cols) continue;
                    int idx = nr * cols + nc;
                    cf[idx >> 6] |= 1ULL << (idx & 63);
                    if (roomArrangement[nr][nc] == '.') {
                        int eid = emptyId[idx];
                        ce[eid >> 6] |= 1ULL << (eid & 63);
                        eList[ecnt++] = eid;
                    }
                }
            }

            candEmptyList[cid] = (int*)malloc(ecnt * sizeof(int));
            memcpy(candEmptyList[cid], eList, ecnt * sizeof(int));
            candEmptyCnt[cid] = ecnt;

            for (int k = 0; k < ecnt; k++) {
                int eid = eList[k];
                int idx = coversOfEmptyLen[eid]++;
                coversOfEmpty[eid][idx] = cid;
            }
            candCount++;
        }
    }

    for (int eid = 0; eid < totalEmpty; eid++) {
        if (coversOfEmptyLen[eid] == 0) return -1;
    }

    allCovered = (uint64*)calloc(emptyWords, sizeof(uint64));
    for (int i = 0; i < totalEmpty; i++)
        allCovered[i >> 6] |= 1ULL << (i & 63);

    bestAns = INT_MAX;
    uint64* initCovered = (uint64*)calloc(emptyWords, sizeof(uint64));
    uint64* initOccupied = (uint64*)calloc(fullWords, sizeof(uint64));
    dfsHelp(initCovered, initOccupied, 0, rows, cols);

    return (bestAns == INT_MAX) ? -1 : bestAns;
}
```
