## 解题思路

题目给定一个长度为 8 的 LED 状态，初始全部熄灭，即二进制为 `00000000`。  
每条指令都由两个字符组成：

- `Lx`：将第 `x` 个 LED 置为亮，也就是把第 `x` 位设为 `1`
- `Dx`：将第 `x` 个 LED 置为灭，也就是把第 `x` 位设为 `0`
- `Tx`：将第 `x` 个 LED 的状态取反

由于一共只有 8 个 LED，所以可以直接用一个整数来表示当前状态。  
整数的二进制第 `x` 位就表示第 `x` 个 LED 的状态。

遍历字符串时，每次取两个字符：

1. 第一个字符表示操作类型
2. 第二个字符表示 LED 编号

然后通过位运算更新状态：

- 点亮：`state |= (1 << x)`
- 熄灭：`state &= ~(1 << x)`
- 切换：`state ^= (1 << x)`

所有操作执行完成后，直接返回最终整数即可。

## 复杂度分析

时间复杂度：O(n)，其中 n 为字符串长度，每次处理 2 个字符。  
空间复杂度：O(1)，只需常数额外空间保存状态。

```python
class Solution:
    def processInstructions(self, instructions: str) -> int:
        # 用一个整数的二进制位表示 8 个 LED 的状态
        state = 0

        # 每两个字符是一条指令
        for i in range(0, len(instructions), 2):
            # 取出操作类型
            op = instructions[i]
            # 将字符数字转成对应的编号
            x = ord(instructions[i + 1]) - ord('0')

            # 生成第 x 位对应的掩码
            mask = 1 << x

            # 根据操作类型执行对应的位运算
            if op == 'L':
                # 点亮第 x 个 LED，把第 x 位置为 1
                state |= mask
            elif op == 'D':
                # 熄灭第 x 个 LED，把第 x 位置为 0
                state &= ~mask
            else:
                # 切换第 x 个 LED，把第 x 位取反
                state ^= mask

        # 返回最终的整数结果
        return state
```
