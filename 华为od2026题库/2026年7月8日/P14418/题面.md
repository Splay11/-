# 题目内容

玩家收集了 $N$ 个魔法咒语碎片，它们可以组合成强大的魔法阵。但并不是所有碎片都能使用——只含咒语中没有重复字母的碎片才是纯净的，可以激活。

请找出所有纯净碎片，输出由所有纯净碎片组成的所有魔法阵方案。

备注：
所有魔法咒语碎片互不重复

# 输入描述

1. 魔法咒语碎片为一个字符串，仅由小写字母构成，没有分隔符，字符串长度不超过 `26`。
2. 魔法咒语碎片数量 $N$ 小于等于 `6` 个。

# 输出描述

1. 魔法阵方案，由所有纯净碎片组成的长字符串，每个纯净碎片的字符串之间以空格隔开（`" "`）。
2. 所有魔法阵方案按字母序排列输出。

## 样例1

**输入**

```
["fire","water","earth"]
```

**输出**

```
["earth fire water","earth water fire","fire earth water","fire water earth","water earth fire","water fire earth"]
```

## 样例2

**输入**

```
["noon","sun","sky"]
```

**输出**

```
["sky sun","sun sky"]
```

**说明**

- "noon"：字母 'n' 重复，不纯净，舍弃
- "sun"：字母无重复，是纯净的
- "sky"：字母无重复，是纯净的
- 可以形成一个 $2! = 2$ 的全排列
