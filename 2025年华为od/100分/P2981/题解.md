## 解题思路

本题等价于经典的**容器盛水问题**（双指针），目标是最大化 $\min(h[i], h[j]) \times (j - i)$。

1. **暴力**：$O(n^2)$ 枚举所有支柱对，在 $n \le 10^4$ 时可能超时或偏紧。
2. **双指针**：左右指针从两端向中间收缩。当前面积由较短边与宽度决定；移动**较短**一侧的指针，才可能得到更大高度从而增大面积（移动较长侧只会减小宽度且高度上界不变）。
3. **正确性直觉**：对任意最优解 $(L,R)$，指针收缩过程中不会跳过该对而不计算到等价或更优面积。

**常见假解**：

- 只取最高两根支柱 → 距离可能很小，样例会错；
- 面积用 `int` 计算 → $10^9 \times 9999$ 溢出；
- 每次移动较高侧指针 → 漏掉最优解。

## 复杂度分析

设 $n$ 为支柱数。

- 时间：$O(n)$，左右指针各移动至多 $n$ 次；
- 空间：$O(1)$ 额外变量。

## 代码实现

### Python

```python
from typing import List


class Solution:
    def maxSolarPanelArea(self, heights: List[int]) -> int:
        left, right = 0, len(heights) - 1
        best = 0
        while left < right:
            # 面积由较短支柱与间距决定
            h = heights[left] if heights[left] < heights[right] else heights[right]
            area = h * (right - left)
            if area > best:
                best = area
            # 移动较短侧，才可能抬高木桶短板
            if heights[left] <= heights[right]:
                left += 1
            else:
                right -= 1
        return best
```

### Java

```java
public class Solution {
    public long maxSolarPanelArea(int[] heights) {
        int left = 0, right = heights.length - 1;
        long best = 0;
        while (left < right) {
            // 用 long 防止高度×宽度溢出 int
            long h = Math.min(heights[left], heights[right]);
            long area = h * (right - left);
            if (area > best) best = area;
            // 移动较短侧指针
            if (heights[left] <= heights[right]) {
                left++;
            } else {
                right--;
            }
        }
        return best;
    }
}
```

### C++

```cpp
#include <algorithm>
#include <vector>

using namespace std;

class Solution {
 public:
  long long maxSolarPanelArea(vector<int>& heights) {
    int left = 0, right = (int)heights.size() - 1;
    long long best = 0;
    while (left < right) {
      // 较短高度 × 间距；用 long long 防溢出
      long long h = min(heights[left], heights[right]);
      long long area = h * (right - left);
      if (area > best) best = area;
      // 移动较短侧
      if (heights[left] <= heights[right])
        left++;
      else
        right--;
    }
    return best;
  }
};
```
