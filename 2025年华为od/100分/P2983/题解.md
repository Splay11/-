## 解题思路

本题在**括号匹配（栈）**的同时维护**当前嵌套深度**，合法则返回过程中的最大深度，非法返回 $0$。

1. 遇左括号入栈，深度 $+1$，更新答案；
2. 遇右括号：栈空或栈顶类型不匹配 → 非法返回 $0$；否则出栈，深度 $-1$；
3. 扫描结束若栈非空（左括号有余）→ 非法返回 $0$；
4. 空串合法，深度为 $0$。

**常见假解**：

- 只数左右括号个数相等、不检查顺序 → 样例 `([)]`、`)(` 会错；
- 深度按「种类数」而非嵌套层数统计；
- 非法时仍返回非零深度。

## 复杂度分析

设 $n = |s|$（$n \le 10^5$）。

- 时间：$O(n)$，单次扫描；
- 空间：$O(n)$，最坏全为左括号时的栈。

## 代码实现

### Python

```python
class Solution:
    def maxBracketDepth(self, s: str) -> int:
        pair = {")": "(", "]": "[", "}": "{"}
        stack = []
        depth = 0
        best = 0
        for ch in s:
            if ch in "([{":
                stack.append(ch)
                depth += 1
                if depth > best:
                    best = depth
            elif ch in pair:
                # 栈空或类型不匹配则为无效
                if not stack or stack[-1] != pair[ch]:
                    return 0
                stack.pop()
                depth -= 1
            else:
                return 0
        # 仍有未闭合左括号则无效
        return best if not stack else 0
```

### Java

```java
import java.util.ArrayDeque;

public class Solution {
    public int maxBracketDepth(String s) {
        ArrayDeque<Character> stack = new ArrayDeque<>();
        int depth = 0, best = 0;
        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch == '(' || ch == '[' || ch == '{') {
                stack.push(ch);
                depth++;
                if (depth > best) best = depth;
            } else if (ch == ')' || ch == ']' || ch == '}') {
                char need = ch == ')' ? '(' : (ch == ']' ? '[' : '{');
                // 出栈前检查匹配
                if (stack.isEmpty() || stack.pop() != need) return 0;
                depth--;
            } else {
                return 0;
            }
        }
        return stack.isEmpty() ? best : 0;
    }
}
```

### C++

```cpp
#include <string>
#include <vector>

using namespace std;

class Solution {
 public:
  int maxBracketDepth(string s) {
    vector<char> stack;
    int depth = 0, best = 0;
    for (char ch : s) {
      if (ch == '(' || ch == '[' || ch == '{') {
        stack.push_back(ch);
        depth++;
        if (depth > best) best = depth;
      } else if (ch == ')' || ch == ']' || ch == '}') {
        char need = ch == ')' ? '(' : (ch == ']' ? '[' : '{');
        if (stack.empty() || stack.back() != need) return 0;
        stack.pop_back();
        depth--;
      } else {
        return 0;
      }
    }
    return stack.empty() ? best : 0;
  }
};
```
