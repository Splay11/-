# 题目内容

现有一字符串仅由 ‘(‘，’)’，'{‘，’}’，'[‘，’]’六种括号组成。

若字符串满足以下条件之一，则为无效字符串：

①任一类型的左右括号数量不相等；

②存在未按正确顺序（先左后右）闭合的括号。

输出括号的最大嵌套深度，若字符串无效则输出0。

0≤字符串长度≤100000

# 输入描述

- 只包含 `'('`、`')'`、`'{'`、`'}'`、`'['`、`']'` 的字符串。

字符串长度满足 $0 \le |s| \le 100000$。

# 输出描述

- 一个整数，表示最大括号嵌套深度；若字符串无效则输出 $0$。

## 样例1

**输入**
```
"[]"
```
**输出**
```
1
```
**说明**

有效字符串，最大嵌套深度为 $1$。

## 样例2

**输入**
```
"([]{()})"
```
**输出**
```
3
```
**说明**

有效字符串，最大嵌套深度为 $3$。

## 样例3

**输入**
```
"(]"
```
**输出**
```
0
```
**说明**

无效字符串，括号类型不匹配。

## 样例4

**输入**
```
"([)]"
```
**输出**
```
0
```
**说明**

无效字符串，存在未按正确顺序闭合的括号。

## 样例5

**输入**
```
")("
```
**输出**
```
0
```
**说明**

无效字符串，存在未按正确顺序闭合的括号。
