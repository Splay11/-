# 题目内容

所谓水仙花数，是指一个$n$位的正整数，其各位数字的$n$次方和等于该数本身。

例如$153$是水仙花数，$153$是一个$3$位数，并且$153 = 1^3 + 5^3 + 3^3$。



# 输入描述

第一行输入一个整数$n$，表示一个$n$位的正整数。$n$在$3$到$7$之间，包含$3$和$7$。

第二行输入一个整数$m$，表示需要返回第$m$个水仙花数。



# 输出描述

返回长度是$n$的第$m$个水仙花数。

个数从$0$开始编号。

若$m$大于水仙花数的个数，返回最后一个水仙花数和$m$的乘积。

若输入不合法，返回$-1$。



## 样例1 



**输入** 



```
3
0
```



**输出** 



```
153
```



**说明**

$153$是第一个水仙花数



## 样例2



**输入** 



```
9
1
```



**输出** 



```
-1
```



**说明**



$9$超出范围
