# 题目描述

给定一个二叉树，每个节点上站一个人，节点数字表示父节点到该节点传递悄悄话需要花费的时间。初始时，根节点所在位置的人有一个悄悄话想要传递给其他人，求二叉树所有节点上的人都接收到悄悄话花费的时间。

## 输入描述

给定二叉树

```
0 9 20 -1 -1 15 7 -1 -1 -1 -1 3 2
```

注：-1表示空节点

![image](file://ezVFySa6OgwcFfw5jGiKU.png) 


## 输出描述

返回所有节点都接收到悄悄话花费的时间

```
38
```



## 样例1

**输入**

```
0 9 20 -1 -1 15 7 -1 -1 -1 -1 3 2

```

**输出**

```
38
```
