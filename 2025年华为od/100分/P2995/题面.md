# 题目内容

部门组织绿岛骑行团建活动。租用公共双人自行车，每辆自行车最多坐两人，最大载重 $M$ 。

给出部门每个人的体重，请问最少需要租用多少双人自行车。





# 输入描述

第一行两个数字 $m、n$ ，分别代表自行车限重，部门总人数。

第二行， $n$ 个数字，代表每个人的体重，体重都小于等于自行车限重 $m$ 。

- $0<m<=200$

- $0<n<=1000000$



# 输出描述

最少需要的双人自行车数量。





## 样例1 



**输入** 



```
3 4
3 2 2 1
```



**输出** 



```
3
```
