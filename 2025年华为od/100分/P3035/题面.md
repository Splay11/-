# 题目描述

给定一个字符串 $s$，最多只能进行一次变换，返回变换后能得到的最小字符串(按照字典序进行比较)。

变换规则:交换字符串中任意两个不同位置的字符。

## 输入描述

一串小写字母组成的字符串 $s$。$s$是都是由小写字符组成， $1 \le s.length \le 1000$

## 输出描述

按照要求进行变换得到的最小字符串

## 样例1

**输入**

```
abcdef
```

**输出**

```
abcdef
```

**说明**：$abcdef$ 已经是最小字符串，不需要交换

## 样例2

**输入**

```
bcdefa
```

**输出**

```
acdefb
```

**说明**： $a$ 和 $b$ 进行位置交换，可以等到最小字符串
