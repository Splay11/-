## 解题思路

本题要求从 $A$ 中取出尽可能多组互不共享字符、且各自构成 $B$ 的**子序列**（相对顺序不变）。

因 $|A|<100$、$|B|<10$，可采用**反复贪心匹配**：

1. 从左到右扫描当前剩余字符，按 $B$ 的顺序尽量匹配一组完整子序列；
2. 匹配成功的字符从剩余串中删除，答案 $+1$；
3. 若无法再匹配一整组 $B$，结束。

每次匹配取最左可用字符，在本题数据与「$B$ 无重复字母」约束下可以得到正确组数。

**常见假解**：

- 只按字母频次取 $\min$ 而忽略顺序 → 样例 `badc` / `abc` 会错；
- 同一字符被多组重复使用；
- 匹配时改变相对顺序。

## 复杂度分析

设 $n=|A|$，$m=|B|$，答案至多 $\lfloor n/m \rfloor$。

- 时间：$O(n \cdot n/m) = O(n^2)$ 量级，在题面规模下足够；
- 空间：$O(n)$，存放剩余字符。

## 代码实现

### Python

```python
class Solution:
    def countFormableGroups(self, a: str, b: str) -> int:
        chars = list(a)
        ans = 0
        while True:
            j = 0
            nxt = []
            for ch in chars:
                # 按 B 的顺序贪心消耗一个字符
                if j < len(b) and ch == b[j]:
                    j += 1
                else:
                    nxt.append(ch)
            if j == len(b):
                # 成功凑出一组 B，继续用剩余字符
                ans += 1
                chars = nxt
            else:
                break
        return ans
```

### Java

```java
import java.util.ArrayList;

public class Solution {
    public int countFormableGroups(String a, String b) {
        ArrayList<Character> chars = new ArrayList<>();
        for (int i = 0; i < a.length(); i++) chars.add(a.charAt(i));
        int ans = 0;
        while (true) {
            int j = 0;
            ArrayList<Character> nxt = new ArrayList<>();
            for (char ch : chars) {
                if (j < b.length() && ch == b.charAt(j)) {
                    j++; // 匹配到 B 的下一位
                } else {
                    nxt.add(ch);
                }
            }
            if (j == b.length()) {
                ans++;
                chars = nxt;
            } else {
                break;
            }
        }
        return ans;
    }
}
```

### C++

```cpp
#include <string>
#include <vector>

using namespace std;

class Solution {
 public:
  int countFormableGroups(string a, string b) {
    vector<char> chars(a.begin(), a.end());
    int ans = 0;
    while (true) {
      int j = 0;
      vector<char> nxt;
      for (char ch : chars) {
        if (j < (int)b.size() && ch == b[j])
          j++;  // 贪心匹配 B[j]
        else
          nxt.push_back(ch);
      }
      if (j == (int)b.size()) {
        ans++;
        chars.swap(nxt);
      } else {
        break;
      }
    }
    return ans;
  }
};
```
