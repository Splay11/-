# 题目描述

小明和朋友玩跳格子游戏，有 $n$ 个连续格子组成的圆圈，每个格子有不同的分数，小朋友可以选择以任意格子起跳，但是不能跳连续的格子，不能回头跳，也不能超过一圈;

给定一个代表每个格子得分的非负整数数组，计算能够得到的最高分数。

# 输入描述

给定一个数例，第一个格子和最后一个格子首尾相连，如: $2$ $3$ $2$

# 输出描述

输出能够得到的最高分，如: $3$

# 备注

$1 ≤ nums.length ≤ 100$

$1 ≤ nums[i] ≤ 1000$

## 样例1

**输入**

```
2 3 2
```

**输出**

```
3
```

**说明**

只能跳 $3$ 这个格子，因为第一个格子和第三个格子首尾相连

## 样例2

**输入**

```
1 2 3 1
```

**输出**

```
4
```

**说明**

$1 + 3 = 4$
