# 华为 AI 岗选择题模拟卷

从 `华为模拟赛出题/选择题出题/object.json` **原样抽取真题**（不改写题干/选项），按当天日期落盘一场 20 题模拟卷。

## 交付物

在 `华为模拟赛出题/选择题出题/` 下：

```text
{M.D}/选择题/
  选择题题面.md
  题解.md
  config.yaml
```

日期目录名为当天（Asia/Shanghai）的 `月.日`，例如 9 月 8 日 → `9.8`。已存在同日 `选择题/` 则用 `9.8-2`、`9.8-3`。用户指定日期则以用户为准。

## 硬约束

1. **15 单选 + 5 多选**，共 20 道，全部来自 `object.json`。
2. **必须随机**：禁止人工点题。用脚本抽题；每次默认新 seed。
3. **tag1（大类）按题库频次比例分配席位**：高频多几道，低频 1～2 道（席位够时每个大类至少 1 道单选）。
4. **tag2（小类）在该 tag1 席位内同样按频次比例随机抽**。
5. **难度必须拉开**：简单 / 中等 / 困难都要有，且数量尽量均匀。难度档按真题 `difficulty`：`1–3` 简单、`4–5` 中等、`6–8` 困难。单选目标约 5/5/5，多选约 1/2/2（余数优先中等、困难）。
6. **题面 / 题解 / config 格式**分别对齐同目录 `选择题模板.md`、`选择题题解模板.md`、`config.yaml` 示例。
7. **不得改写真题**。脚本已按模板排版；Agent 不要再改选项或考点。

## 执行（必须跑脚本）

工作区根目录：

```powershell
python "华为模拟赛出题/选择题出题/scripts/make_mock.py"
```

常用参数：

| 参数 | 说明 |
|------|------|
| `--date 9.8` | 指定日期目录名 |
| `--seed 123` | 固定随机种子（复现）；默认每次随机并打印 seed |
| `--overwrite` | 覆盖已有同名日期目录 |
| `--stats` | 只打印题库 tag1/tag2/type 统计，不出卷 |
| `--json 路径` | 题库 JSON；默认根目录 `object.json` |

`object.json` 为空或不存在：**fatal stop**，请用户先保存该文件后再跑。

## 题面格式

对齐同目录 `选择题模板.md`。先 `## 一、单选题`，再 `## 二、多选题`；题号用 `**n、题干**`，不要用 `#####`。

```markdown
## 一、单选题
**1、题干原文**
{{ select(1) }}
- 选项A
- 选项B
- 选项C
- 选项D

## 二、多选题
**16、题干原文**
{{ multiselect(16) }}
- 选项A
- 选项B
- 选项C
- 选项D
```

多选（第 16～20 题）用 `{{ multiselect(n) }}`。题号与 `select` / `multiselect` 序号必须连续对应。

## 题解格式

对齐同目录 `选择题题解模板.md`。

```markdown
## T1
答案：C.14
解析：……

## T16
答案：
B.选项原文
D.选项原文
解析：……
```

- 单选：`答案：字母.该选项原文`（同一行）。
- 多选：`答案：` 后每个正确项一行 `字母.选项原文`。
- 解析用真题 `solution` 中的解析，不要另编。

## config.yaml

`type: objective`。单选分值 **6**，多选 **12**。多选答案为字母列表：

```yaml
  '16':
    - - B
      - D
    - 12
```

字母必须与题解一致。

## 完成后

向用户报告：日期目录、seed、本场 tag1/tag2 分布、**简单/中等/困难数量**、脚本打印的题库 tag1 频次对照。不要手改三份产出。
