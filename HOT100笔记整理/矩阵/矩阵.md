## LeetCode 73.矩阵置零

[在线刷题](https://codefun2000.com/p/P4013)

给定一个 $m × n$的矩阵，如果一个元素为 $0$ ，则将其所在行和列的所有元素都设为 $0$ 。请使用原地算法

![](/file/2/cE8YCI9Q5rGcyGSOy7oJa.png)


**输入** 

```
3 3
1 1 1
1 0 1
1 1 1
```

**输出** 

```
1 0 1
0 0 0
1 0 1
```

**思路：标记数组+模拟**

一个很自然的想法是：**先把所有需要清零的行和列记下来，再统一修改矩阵。**

比如我们可以开两个数组：

- `row_flag[i]`：表示第 `i` 行是否要清零
- `col_flag[j]`：表示第 `j` 列是否要清零

第一遍扫描整个矩阵，如果发现 `matrix[i][j] == 0`，就把对应的行和列标记下来。
第二遍再扫描一遍矩阵，只要当前位置所在的行或列被标记过，就把它变成 `0`。

这个做法很好理解，时间复杂度是 `O(mn)`，但空间复杂度是 `O(m+n)` (来源于标记数组)，**不满足题目要求的原地算法**。
对，应该把 **Python / C++ / Java / JavaScript / Go / C** 六份都给出来。下面全部都是 **核心代码模式**，不包含 ACM 输入输出。

```python
from typing import List

class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        m, n = len(matrix), len(matrix[0])

        # 标记数组：
        # row_flag[i] 表示第 i 行是否需要清零
        # col_flag[j] 表示第 j 列是否需要清零
        row_flag = [False] * m
        col_flag = [False] * n

        # 第一遍扫描矩阵，记录哪些行和列需要清零
        for i in range(m):
            for j in range(n):
                if matrix[i][j] == 0:
                    row_flag[i] = True
                    col_flag[j] = True

        # 第二遍扫描矩阵
        # 如果当前位置所在的行或列被标记过，就将其置为 0
        for i in range(m):
            for j in range(n):
                if row_flag[i] or col_flag[j]:
                    matrix[i][j] = 0
```

**如何优化到 `O(1)` 空间？**

受到[LeetCode 41. 缺失的第一个正数](https://codefun2000.com/p/P4039) 中**原地哈希**做法的启发，**我们想想本题是否可以也借用矩阵数组本身来代替掉那两个标记数组呢？**

具体来说：

- 用 `matrix[i][0]` 记录第 `i` 行是否需要清零
- 用 `matrix[0][j]` 记录第 `j` 列是否需要清零

也就是说，**第一列充当“行标记数组”，第一行充当“列标记数组”**。

**但是会有一个问题：第一行和第一列本身怎么办？**

因为第一行和第一列既要存原始数据，又要拿来当标记位，所以它们很容易被“污染”。

比如：

- 如果第一行本来就有 `0`，那最后第一行应该整行清零
- 如果第一列本来就有 `0`，那最后第一列应该整列清零

所以我们需要额外用两个变量：

- `row_zero`：记录第一行最终是否需要清零
- `col_zero`：记录第一列最终是否需要清零

这样就能把“第一行/第一列原本是否该清零”和“它们现在被拿来做标记”这两件事区分开。

总结来讲，我们相当于是把额外的标记数组“压缩”进了原矩阵中。唯一需要额外处理的，就是第一行和第一列自己既是数据又是标记数组，所以再额外用两个变量单独维护即可。

```python 
from typing import List

class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        m, n = len(matrix), len(matrix[0])

        # 记录第一行、第一列是否需要清零
        row_zero = any(matrix[0][j] == 0 for j in range(n))
        col_zero = any(matrix[i][0] == 0 for i in range(m))

        # 用第一行和第一列作为标记数组
        # 如果 matrix[i][j] 为 0，就标记第 i 行和第 j 列需要清零
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0
                    matrix[0][j] = 0

        # 根据标记，将非第一行、非第一列的位置清零
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0

        # 最后处理第一行
        if row_zero:
            for j in range(n):
                matrix[0][j] = 0

        # 最后处理第一列
        if col_zero:
            for i in range(m):
                matrix[i][0] = 0
```

### 面试问答

**1. 本题的核心思路是什么？**

这道题的核心思路是**用矩阵本身充当标记数组**：朴素做法是额外开两个数组，分别记录哪些行和哪些列需要清零；但为了满足原地算法要求，我们把第一行当作列标记，把第一列当作行标记。这样在扫描到某个位置是 `0` 时，就能把对应行列的信息记录到第一行和第一列里。由于第一行和第一列本身也可能原本就要被清零，所以再额外用两个变量单独记录它们的状态。最后根据这些标记统一清零即可。时间复杂度是 **`O(mn)`**，空间复杂度是 **`O(1)`**。

## LeetCode 54.螺旋矩阵

[在线刷题](https://codefun2000.com/p/P4014)

给你一个 $m$ 行 $n$ 列的矩阵 $matrix$，请按照 顺时针螺旋顺序 ，返回矩阵中的所有元素

![](/file/2/AU3KTMJzkan8Jrw4RO80i.png)


**输入** 

```
3 3
1 2 3
4 5 6
7 8 9
```

**输出** 

```
1 2 3 6 9 8 7 4 5
```

**思路：模拟**

我们可以把整个矩阵看成一层一层的“圈”，每次按顺时针顺序走当前这一圈：

1. 从左到右，走完**上边** ，下一个位置是右边界，转向。
2. 从上到下，走完**右边**，下一个位置是下边界，转向。
3. 从右到左，走完**下边** ， 下一个位置是左边界，转向。
4. 从下到上，走完**左边** 

走完一圈之后，说明最外层已经遍历完了，继续往内一层进行继续遍历。

在实现的过程，我们需要动态更改当前的边界值：

1.当遍历完上边时，上边界 `top += 1` 

2.当遍历完右边时，右边界 `right -= 1` 

3.当遍历完下边时，下边界 `bottom -= 1` 

4.当遍历完左边时，左边界 `left += 1` 

**注意**：当矩阵只剩一行或一列需要遍历时，不能重复访问元素，所以在遍历下边和左边之前要先判断当前边界是否仍然有效。

```python 
from typing import List

class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        # 如果矩阵为空，直接返回空数组
        if not matrix or not matrix[0]:
            return []

        m, n = len(matrix), len(matrix[0])
        result = []

        # 定义四个边界
        top, bottom = 0, m - 1
        left, right = 0, n - 1

        # 只要当前边界仍然合法，就继续按圈遍历
        while top <= bottom and left <= right:
            # 从左到右遍历上边
            for i in range(left, right + 1):
                result.append(matrix[top][i])
            top += 1  # 上边界下移

            # 从上到下遍历右边
            for i in range(top, bottom + 1):
                result.append(matrix[i][right])
            right -= 1  # 右边界左移
```

**1.这道题的整体思路是什么？**

这道题的核心思路是**模拟 + 按层遍历**。我们用 `top、bottom、left、right` 四个边界来表示当前这一圈还没有被遍历的范围，然后按照顺时针顺序，依次遍历上边、右边、下边、左边。每走完一条边，就把对应的边界向内收缩一格，表示这一层已经处理完了，接着继续遍历下一层。整个过程本质上就是按“圈”一层层向内模拟螺旋遍历。时间复杂度是 **O(mn)**，因为每个元素恰好访问一次；空间复杂度是 **O(1)**

你必须 **在原地旋转图像**，即直接修改输入的二维矩阵，**请不要使用额外的矩阵**。

```
3

7 8 9
```

**输出**

```
7 4 1
8 5 2
9 6 3
```

![](/file/2/MhZ8ZvQEzbpSX53kj-8F4.png)


**思路:转置 + 水平翻转**

考虑一个坐标`(i , j)` , 旋转90度之后变成`(j,n-1-i)`

因为旋转后：第一行会到最后一列，第二行会到倒数第二列，以此类推。

所以旋转后的列号是`n-1 - 原来的行号`

旋转后：第一列会到第一行，第二列会到第二行，以此类推。

所以旋转后的行号是`原先的列号`

现在我们需要通过一些原地操作，让`(i,j)` 变成 `(j , n - 1 -  i)`

分成两步：**转置**（行号和列号互换） :`(i,j) -> (j,i)`

接着，想让列号`i` 变成行号`n-1-i` ，本质上就是每个元素跑到它那一行对称的位置，而行号不变。

所以**水平翻转**(行号不变，列号对称翻转):`(j,n-1-i)`

## LeetCode 240.搜索二维矩阵Ⅱ

[在线刷题](https://codefun2000.com/p/P4041)

编写一个 **高效的算法** 来搜索 `m × n` 矩阵 `matrix` 中的目标值 `target`。该矩阵具有以下特性：

- 每行的元素 **从左到右升序排列**。
- 每列的元素 **从上到下升序排列**。

**输入**

```
5 5
1 4 7 11 15
2 5 8 12 19
3 6 9 16 22
10 13 14 17 24
18 21 23 26 30
5
```

**输出**

```
true
```

**思路:两数之和**

**刷过这个题的同学，可能从来都没想清楚过，为什么要从右上角或者左下角开始枚举。**

**核心：本题给的矩阵，就是两个有序数组两两相加所构成的二维矩阵**

先考虑这样一个问题：给定两个长度为$n$的升序数组$a,b$ 。考虑从两个数组中拿出任意两个元素进行相加，要求加出来的数恰好是$k$

例如:$a=[1,3,4,5] , b = [1,3,5,6] , k = 5$

![](/file/2/urqRPIVHmXpcrvEmT0ZoK.png =60%x)


一个显然的做法是双指针：定义$i = 1 , j = n$ ，分别指向数组$a$的第一个位置( 也是整个$a$数组最小的元素) 和 数组$b$的最后一个位置(也是整个$b$数组最大的元素)。 

若$a[i] + b[j] > k$ , 则我们需要总和变小,$j -= 1$。

若$a[i] + b[j] < k$ , 则我们需要总和变大,$i += 1$。

若$a[i] + b[j] = k$ , 则找到。

最后，当$i = n + 1$ 或者$j = 0$ 时都没找到两数相加等于$k$ , 则无解。

这里我们用一个实际的动画来演示👇
@[video](https://codefun2000.com/p/3967/file/%E6%90%9C%E7%B4%A2%E4%BA%8C%E7%BB%B4%E7%9F%A9%E9%98%B5%E5%8F%8C%E6%8C%87%E9%92%88.mp4)

> 没学双指针的同学先补一下双指针章节的知识。

 

现在我们把两数之和定义成：$D(i,j) = a[i] + b[j]$ ， 显然$D$ 是一个$n \times n$的矩阵。

![](/file/2/IpPRyPw1OV1DSjeA0JD5y.png =70%x)


不难发现，这个矩阵每行的元素 **从左到右升序排列** 。  因为固定$i$ , 让$j$递增 , 则$a[i] + b[j]$ 递增。

每列的元素 **从上到下升序排列**。因为固定$j$ , 让$i$递增 , 则$a[i] + b[j]$ 递增。


所以回顾我们刚刚的双指针策略 , 它就等价于从矩阵$D$的右上角$(1,n)$ 开始寻找，

若总和$D(i,j) > k$ ,则$j -= 1$ , 也就是在矩阵中往左走一格。

若总和$D(i,j) < k$ ,则$i += 1$ , 也就是在矩阵中往下走一格。

**从矩阵的角度描述这个做法的思路**：考虑从右上角$(1,n)$ 开始寻找，如果值小了则往下走，因为当前位置是本行的最大值，可以将该位置所在行的左侧的值都忽略。反之如果值大了则往左走，因为当前位置是本列的最小值，可以将该位置所在列的下方的值都忽略。

**这两个方法本质一样，但是从不同维度去看这个事情👇**

```python id="07vt5k"
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        # 如果矩阵为空，直接返回 False
        if not matrix or not matrix[0]:
            return False

        # 获取矩阵的行数和列数
        m, n = len(matrix), len(matrix[0])

        # 从右上角开始搜索
        i, j = 0, n - 1

        # 当当前位置没有越界时，继续搜索
        while i < m and j >= 0:
            # 如果当前元素等于目标值，说明找到了
            if matrix[i][j] == target:
                return True

            # 如果当前元素大于目标值，说明这一列下面的数更大，只能向左移动
            if matrix[i][j] > target:
                j -= 1
            else:
                # 如果当前元素小于目标值，说明这一行左边的数更小，只能向下移动
                i += 1

        # 搜索结束仍然没找到，返回 False
        return False
```

**面试问答**

**本题是什么思路？**

考虑从右上角$(1,n)$ 开始寻找，如果值小了则往下走一格，因为当前位置是本行的最大值，可以将该位置所在行的左侧的值都忽略。反之如果值大了则往左走一格，因为当前位置是本列的最小值，可以将该位置所在列的下方的值都忽略。直到找到目标元素或者超出边界时代表无解。

因为移动是朝着左下角移动的，最坏情况是一直找不到目标元素，移动$n+m$ 次到达左下角，复杂度为$O(n+m)$
