## Leetcode 283.移动零

[在线刷题](https://codefun2000.com/p/P4003)

化简题面:给定一个数组$nums$，将所有 $0$ **原地的** 移动到数组的末尾，同时保持非零元素的相对顺序。

$[0\ 1\ 0\ 3\ 12] \rightarrow [1\ 3\ 12\ 0\ 0]$

### 思路

使用双指针，左指针$i$指向当前已经处理好的序列的尾部，右指针$j$指向待处理序列的头部。

右指针$j$不断向右移动，每次右指针$j$指向非零数，则将左右指针对应的数交换，同时左指针右移。

这是官方思路，**总结的非常到位，但是理解起来非常抽象**。没有关系，我们先过一遍代码，针对代码思考这个解法的巧妙之处。

```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        # i 指向已经处理好的非零序列的下一个位置
        i = 0
        
        # 遍历数组
        for j in range(len(nums)):
            # 遇到非零元素时，将它交换到前面
            if nums[j] != 0:
                nums[i], nums[j] = nums[j], nums[i]
                
                # 交换后推进 i
                i += 1
```

粗读代码，我们大概能理解到这个算法的特征是：指针j每一轮都一定会往右移动，保证每个数都被考虑到。而只有当j发现了非零数时，才会和i进行交换，将i往后推进。

**理解关键**

接下来通过一个样例来解释算法的行为：[1,2,3,0,0,0,4,5,6] , 它被中间"零区" [0,0,0]分割成了两个部分👇

1.当遍历前缀[1,2,3]时，这个算法的行为是：每个数和自己交换(相当于啥也没干)，i,j一起往后推进👇

2.当遍历到中间零区时，**i会被留在原地指向零，而j会继续推进，负责往后找下一个要交换的数**。

3.接下来就是 **j 负责将 非零数 搬运到 i所指向的零，然后i往后走**。

总结：快慢指针i,j是一对绝佳搭档，各司其职。当没有遇到零的时候，俩人一起往后走，因为这些数已经处理好了。当遇到零，$i$停下来等，而$j$负责往后找非零数进行交换，然后$i$再推进指向下一个零。

整个过程结束，所有非零数都会被搬运到数组的前缀区域，这等价于所有0被搬运到后缀区域（即数组末尾）

**面试问答**

**1.这个算法的思想是什么？**

快慢指针。快指针负责遍历处理每个数，而慢指针负责维护 已经处理好的区间。每当快指针向右移动的时候，遇到非零数，则将它和慢指针所在位置进行交换，慢指针往后移动，它的移动代表增加已处理区间的长度。

一句话总结:一个指针负责枚举枚举，一个指针维护已处理区间

**2.这个算法的复杂度是多少？**

$O(n)$ ,  因为快指针和慢指针同时往一个方向移动，最多计算次数是$2n$次，则时间复杂度为$O(n)$

## 应用场景：快速排序的"partition" 操作

本算法的经典应用场景是快速排序里的"partition"操作。

快速排序中的"partition"操作是指:给定一个数组和一个分割值$x$, **原地**将这个数组分成左右两个区域，前面的数$\leq x$ , 后面的数$> x$ 

例如$[3,1,7,4,5],x=4$  , 输出$[3,1,4\ |\ 7,5]$


$[5,8,7,1,2],x=4$  , 输出$[1,2\ |\ 7,5,8]$

分析:考虑将所有 小于等于$x$的数视作 非零数 ， 大于$x$的数视作 零，问题转化为：

将所有$> x$ 的数搬运到数组末尾，即 移动零问题！

## 手撕快速排序

[在线刷题](https://codefun2000.com/p/P4683)

前面我们已经讲了 `partition` 操作。实际上，**快速排序的核心就是 partition**。

快速排序的思想就是`partition` + 分治递归：

要将一个数组排序，考虑将数组划分成两个区间，左边的区间都 <= 某个数 ， 右边的区间都 > 某个数。 

接着递归的去排序两个区间即可。

具体的步骤：

1. 先在数组里选定一个基准值 `x`
2. 用 `partition` 操作，把数组分成两部分：
   - 左边都 `<= x`
   - 右边都 `> x`
3. 然后递归地排序左边和右边

因为每一轮都能把问题规模缩小，所以最终整个数组会变得有序。

#code-switcher
```python
class Solution:
    def quickSort(self, nums: List[int], l: int, r: int) -> None:
        # 区间长度为 0 或 1，直接返回
        if l >= r:
            return
        
        # 选最后一个数作为基准值
        x = nums[r]
        
        # i 指向当前 <= x 区间的下一个位置
        i = l
        
        # 将小于等于基准值的元素放到左边
        for j in range(l, r):
            if nums[j] <= x:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
        
        # 最后把基准值放到正确位置
        nums[i], nums[r] = nums[r], nums[i]
        
        # 递归排序左半部分
        self.quickSort(nums, l, i - 1)
        
        # 递归排序右半部分
        self.quickSort(nums, i + 1, r)
```

### **面试问答**

#### 1.快速排序的思想是什么？

**分治**的思想：不断用基准值将数组划分成左右两个子区间，再递归地对它们排序。

而划分的过程，利用的是快慢指针的思想。

#### 2.这个算法的复杂度是多少？

平均复杂度:$O(nlogn)$  。 平均的含义是去计算所有可能的排列下，每个排列的排序复杂度的平均值。

> 如何理解复杂度里的 $log⁡n$？这是因为在数据随机情况下，每次选出的基准值通常不会太差，`partition` 之后数组大致会被分成两个规模接近的部分。于是递归过程就像一棵二叉树：每往下一层，子问题规模大约缩小一半，所以递归层数大约是 $log⁡n$。

最差复杂度:$O(n^2)$ , 这是因为如果每一轮选的基准值恰好都是整个数组的最值，则递归层数为$n$层，每层计算次数累加为$n+(n-1)+(n-2)+...+1$。则总的复杂度就是$O(n^2)$
