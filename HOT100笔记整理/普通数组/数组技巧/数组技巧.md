## LeetCode 189. 轮转数组

[在线刷题](https://codefun2000.com/p/P4037)

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

**输入样例**

```
7
1 2 3 4 5 6 7
3
```

### **输出样例**

```
5 6 7 1 2 3 4
```

**说明**

向右轮转 `1` 步: `[7,1,2,3,4,5,6]`

 向右轮转 `2` 步: `[6,7,1,2,3,4,5]`

 向右轮转 `3` 步: `[5,6,7,1,2,3,4]`

**思路：数组翻转法**

这道题本质就是要将前 n-k 个元素 和 后 k 个元素进行调转

那么我们可以先将整个数组进行翻转，然后再分别翻转前 k 个元素和后 n-k 个元素

```python
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        # 获取数组长度
        n = len(nums)
        
        # 如果数组为空，直接返回
        if n == 0:
            return
        
        # 避免 k 超过数组长度
        k %= n
        
        # 翻转整个数组
        nums.reverse()
        
        # 翻转前 k 个元素
        nums[:k] = reversed(nums[:k])
        
        # 翻转后 n - k 个元素
        nums[k:] = reversed(nums[k:])
```

**k为什么要取余？**

因为要考虑$k \geq n$ 的情况，例如：

$k = n$ 时，轮转完会回到原位置，等价于$k = 0$

$k = n + 1$ 的时候，等价于往后挪了一格,$k=1$。

所以对于$k \geq n$ 的情况，自然是需要取余的。

### 面试问答

**1.本题是什么思路？**

本题需要将前 n-k 个元素 和 后 k 个元素进行调转 ， 我们可以先将整个数组进行翻转，然后再分别翻转前 k 个元素和后 n-k 个元素。

三轮操作不会超过$2n$ 次计算，时间复杂度为$O(n)$ , 由于没有使用额外的空间辅助计算，空间复杂度为$O(1)$

## Leetcode 56.合并区间

[在线刷题](https://codefun2000.com/p/P4012)

以数组 $intervals$ 表示若干个区间的集合，其中单个区间为 $intervals[i] = [start_i, end_i]$ 。请你合并所有重叠的区间，并输出一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间 。

**输入** 

```
4
1 3
2 6
8 10
15 18
```

**输出** 

```
1 6
8 10
15 18
```

**说明**

区间 $[1,3] 和 [2,6] $重叠, 将它们合并为$ [1,6]$

![](/file/2/cEesXorlzWp3IP1ZY9j5M.png =70%x)

**思路**

重叠性质：考虑两个区间$[x_1,y_1]$ 和 $[x_2,y_2]$ 重叠，等价于$y_1 \geq x_2$

所以我们对所有区间的左端点$x_i$排序，从左到右遍历，判断对应的$y_i$  是否大于等于 下一个区间的左端点$x_{i+1}$ ，若重叠则合并区间$y_i = max(y_i,y_{i+1})$ , 如此往复合并所有可能的区间 ，直到$y_i < x_{i + 1}$  ，区间断开。

**为什么要对左端点排序？贪心**

对左端点排序后考虑任意一个相邻的区间$[x_i,y_i] , [x_{i+1},y_{i+1}]$ ，它满足，选中$[x_i,y_i]$的情况下，$x_i \leq x_{i+1}$且$x_i,x_{i+1}$他俩离的最近。这等价于$y_i$ 和$x_{i+1}$ 离的最近，那么重叠性质$y_i \geq x_{i+1}$ 最容易被满足。

换句话说，**对左端点排序之后，每一个区间$i+1$ 都是 最容易和 $i$ 发生重叠的区间。自然从左往右扫描能够考虑到所有重叠情况。**

所以可以这么说：排序保证了每次只需和前一个区间比较即可覆盖所有重叠情况

```python
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        # 如果区间数组为空，直接返回空数组
        if not intervals:
            return []
        # 按照区间左端点从小到大排序
        intervals.sort()
        # merged 用来保存合并后的区间
        merged = []

        # 依次遍历每一个区间
        for interval in intervals:
            # 如果 merged 为空，或者当前区间和上一个区间不重叠
            # 直接把当前区间加入答案
            if not merged or merged[-1][1] < interval[0]:
                merged.append(interval)
            else:
                # 否则说明两个区间有重叠
                # 更新上一个区间的右端点
                merged[-1][1] = max(merged[-1][1], interval[1])

        # 返回合并后的所有区间
        return merged
```

func merge(intervals [][]int) [][]int {
	// 如果区间数组为空，直接返回空数组
	if len(intervals) == 0 {
		return [][]int{}
	}

	// 按照区间左端点从小到大排序
	sort.Slice(intervals, func(i, j int) bool {
		return intervals[i][0] < intervals[j][0]
	})

	// merged 用来保存合并后的区间
	merged := make([][]int, 0)

	// 依次遍历每一个区间
	for _, interval := range intervals {
		// 如果 merged 为空，或者当前区间和上一个区间不重叠
		// 直接把当前区间加入答案
		if len(merged) == 0 || merged[len(merged)-1][1] < interval[0] {
			merged = append(merged, interval)
		} else {
			// 否则说明两个区间有重叠
			// 更新上一个区间的右端点
			if interval[1] > merged[len(merged)-1][1] {
				merged[len(merged)-1][1] = interval[1]
			}
		}
	}

	// 返回合并后的所有区间
	return merged
}

int cmp(const void* a, const void* b) {

    int* x = *(int**)a;

    // 按照区间左端点从小到大排序

    int** ans = (int**)malloc(sizeof(int*) * intervalsSize);

        }

    return ans;

### **面试问答**

**1.这道题的整体思路是什么？**

先按区间的左端点升序排序，然后从左到右进行贪心合并：依次遍历每个区间，如果当前区间与结果数组最后一个区间，也就是当前正在合并的区间不重叠（即前者右端点小于当前左端点），就直接加入到结果数组末尾；否则说明有重叠，就更新右端点为两者的最大值，从而实现区间合并。排序保证了每次只需和前一个区间比较即可覆盖所有重叠情况

时间复杂度为 **O(n log n)**（排序开销），遍历合并为 **O(n)**，总体为 **O(n log n)**；空间复杂度为 **O(n)**（用于存储结果）。

**解法二：原地哈希**

**step1:去掉无用的数**

首先，所有$i \notin [1,n]$ 的数，都可以忽视掉，它对我们的答案没有影响。比如样例里的0显然没用。大于$n$的数也不可能对答案有影响，这是因为最终答案不可能$>n$  。

例如:$[?,?,5,?]$  , 这里的$5 = 数组长度 + 1$ 。  **5若想要起作用，当且仅当 数组其他位置出现过$1,2,3,4$ 。 而这个数组总共还有三个位置可以填，答案最多是4（此时$[1,2,5,3]$），$5$ 无论如何都起不到桥接的作用，无法更新答案。**

**step2:像哈希那样，将数按下标进行归位**

现在的问题是，如何不借助哈希表的情况下，判断$[1,n]$ 这些数的存在性呢？

**我们可以将数组本身当作一个哈希数组**:把数组中所有元素$i \in [1,n]$  的数 ， 放到下标 $i$ 处，使得$a[i] = i$ 。   **如此以来，我们可以凭借$a[i]$ 是否等于$i$ 来判断$i$这个数在数组中的存在性** 

例如:$[2,4,7,1,6,5]$  ，需要把他变成 $[1,2,7,4,5,6]$   ，除了$7$  这个大于数组长度的数，其他位置都满足$a[i]=i$。

答案就是**从前往后第一个不满足$a[i]=i$的地方，即$i=3$的地方 ， 答案就是3** 

**step3:设计算法**

从左往右扫描数组，当：

1.遇到$a[i] \notin [1,n]$ 就跳过 ，

2.遇到$a[i] \in [1 , n]$ ，

​	2.1 如果$a[i] = i$ ， 那太好了，继续跳过 

​	2.2 如果$a[i] = x,x \neq i$ , 让$a[i],a[x]$  交换，让$a[x] = x$ , 代表$x$ 已经出现过。



但是随之而来有一个问题是：$a[x]$ 交换过来的值不一定满足$a[i] = i$ , 那么此时我们要继续上述过程，直到$a[i] \notin [1,n]$ 或者$a[i] = i$

class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        n = len(nums)

        for i in range(n):
            # 把每个数字放到它应该在的位置上
            # 代码里下标从 0 开始计数，所以数字 x 应该放在下标 x - 1 的位置
            # nums[nums[i] - 1] != nums[i] 是为了防止交换相同数字导致死循环
            while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
                nums[nums[i] - 1], nums[i] = nums[i], nums[nums[i] - 1]

        for i in range(n):
            # 第一个位置不对的下标，对应的答案就是 i + 1
            if nums[i] != i + 1:
                return i + 1

        return n + 1

**面试问答:**

**1.本题使用了什么思路？**

这道题的核心思路是**原地哈希**：因为我们要找的是第一个缺失的正数，所以真正有意义的只是在 `1` 到 `n` 这个范围内的数，其他小于等于 `0` 或大于 `n` 的数都可以忽略。接着目标是让每个值为 `x` 的数放到下标 `x` 的位置上。遍历数组时，如果当前数在有效范围内，并且还没有放到正确位置，就不断交换，直到当前位置放不动为止。这样整理完成后，再从左到右扫一遍，第一个不满足 `nums[i] == i+1` 的位置，对应缺失的数就是 `i+1`；如果全部都满足，答案就是 `n+1`。

时间复杂度是 **O(n)**，因为外层的`for`循环遍历$n$次，而内层`while` 循环每次会使得一个位置从$a[i] \neq i$变成$a[i] = i$，初始时$a[i] \neq i$ 的位置最多为$n$个，所以`while`最多执行$n$次；空间复杂度是 **O(1)**，因为整个过程都只是在原数组上操作，没有额外开哈希表。
