## 前缀和基础

给定一个数组$[a_1,a_2,...,a_n]$ , 前缀和的定义是:

$$prefix(i) = a_1+a_2+...+a_i$$

不难发现，

$$prefix(i) = prefix(i - 1) + a_i$$

我们可以用一个数组来存储前缀和的结果。
#code-switcher

```python
prefix[0] = a[0]
for i in range(1 , n):
    prefix[i] = prefix[i - 1] + a[i]
```

```cpp

}
```


#code-switcher

> 从定义来讲，前缀和是一种动态规划：用已经算过的内容来直接得到新的内容，从而减少重复计算，降低复杂度。

**它的一个经典作用就是快速得到一个数组的子数组的和:**

$a_i+a_{i+1}+a_{i+2}+...+a_{j} = prefix[j] - prefix[i - 1]$

如此以来，任意一个子数组的和都能够通过调用前缀和数组来$O(1)$  计算。

![](/file/2/tFj3nxDnruNOxXx7cxOxZ.png =70%x)


**前缀最值**

前缀可以维护和，同时也可以维护最值。

$max\_prefix(i) = max(max\_prefix(i - 1) , a_i)$

这样得到的就是$[a_1,a_2,...,a_i]$ 中的最大值。

**但是注意**：前缀最值数组无法用于快速得到一个数组的子数组的最值（自行思考为什么）

## LeetCode 53. 最大子数组和

[在线刷题](https://codefun2000.com/p/P4011)

给你一个整数数组 $nums $，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），输出其最大和。

子数组是数组中的一个连续部分。

**输入样例**

```
9
-2 1 -3 4 -1 2 1 -5 4	
```

### **输出样例**

```
6
```

**说明**

连续子数组 $[4,-1,2,1]$ 的和最大，为$ 6 $

**思路：前缀和 + 贪心**

先将问题拆解一下：

**定义函数$f(i)$代表以$i$ 为右端点时，它能够得到的最大子数组和**

最终答案就是以所有位置作为右端点时能够得到的最大子数组和的最大值：

$$ans = max(f(i), i \in [1,n])$$

例如:$[1,2,-1,-4,5,6]$

- `f(1) = 1`，对应子数组 `[1]`
- `f(2) = 3`，对应子数组 `[1,2]`
- `f(3) = 2`，对应子数组 `[1,2,-1]`
- `f(4) = -2`，对应子数组 `[1,2,-1,-4]`
- `f(5) = 5`，对应子数组 `[5]`
- `f(6) = 11`，对应子数组 `[5,6]`

> 其中比如 `f(6)=11`，表示以第 6 个位置结尾时，最大子数组和是 `11`，对应子数组 `[5,6]`。

所以这一组的 `f(i)` 值就是：

```text
[1, 3, 2, -2, 5, 11]
```

答案`ans = max(f) = max([1,3,2,-2,5,11]) = 11`

现在问题是:如何计算$f(i)$ , 由此本题可以通过不同的分析得到两种截然不同的做法：动态规划 / 前缀和+贪心，第一种做法我们会在动态规划章节讲解 ， 这里先讲解它的前缀和+贪心的做法。

根据文章开头所描述的前缀和的基础知识，我们知道前缀和的差 代表 一段子数组的和。

那么对于以$i$为右端点的子数组，它可以表示成:$prefix(i) - prefix(k)$ , 这里$k < i$

在$prefix(i)$不能更改的情况下，我们想让这个差尽量大，显然是在前面找一个最小的前缀和。两者一减就是最大值了。

我们举个更形象的例子：$[-1,-1,10,12,8,6,-5]$ , 考虑求$f(4)$ , 它对应的区间是$[-1,-1,10,12]$ 

肉眼可以看出$f(4) = 10 + 12 = 22$ , 我们可以先算整体前缀和$-1-1+10+12=20$ , 然后再去找前面的最小前缀和$-1-1=-2$ , 两者一减，得到$10+12 = 22$

```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        n = len(nums)

        # prefix[i] 表示 nums 前 i 个元素的和
        prefix = [0] * (n + 1)

        # 预处理前缀和数组
        for i in range(n):
            prefix[i + 1] = prefix[i] + nums[i]

        # min_prefix[i] 表示 prefix[0...i] 中的最小值
        min_prefix = [0] * (n + 1)
        for i in range(1, n + 1):
            min_prefix[i] = min(min_prefix[i - 1], prefix[i])

        # 枚举每个位置作为子数组右端点，维护最大子数组和
        maxSum = float("-inf")
        for i in range(1, n + 1):
            # 以 i 为右端点的最大子数组和 = 当前前缀和 - 前面最小的前缀和
            maxSum = max(maxSum, prefix[i] - min_prefix[i - 1])

        return maxSum
```

```go
func maxSubArray(nums []int) int {
    n := len(nums)

    // prefix[i] 表示 nums 前 i 个元素的和
    prefix := make([]int, n + 1)

    // 预处理前缀和数组
    for i := 0; i < n; i++ {
        prefix[i + 1] = prefix[i] + nums[i]
    }

    // minPrefix[i] 表示 prefix[0...i] 中的最小值
    minPrefix := make([]int, n + 1)
    for i := 1; i <= n; i++ {
        if minPrefix[i - 1] < prefix[i] {
            minPrefix[i] = minPrefix[i - 1]
        } else {
            minPrefix[i] = prefix[i]
        }
    }

    // 枚举每个位置作为子数组右端点，维护最大子数组和
    maxSum := -1 << 31
    for i := 1; i <= n; i++ {
        // 以 i 为右端点的最大子数组和 = 当前前缀和 - 前面最小的前缀和
        cur := prefix[i] - minPrefix[i - 1]
        if cur > maxSum {
            maxSum = cur
        }
    }

    return maxSum
}
```

```c
        prefix[i + 1] = prefix[i] + nums[i];

    min_prefix[0] = 0;

    // 预处理最小前缀和数组
    for (int i = 1; i <= numsSize; i++) {
        min_prefix[i] = min_prefix[i - 1] < prefix[i] ? min_prefix[i - 1] : prefix[i];

        if (cur > maxSum) {
            maxSum = cur;
        }
    }

    free(prefix);
    free(min_prefix);

    return maxSum;
```

**空间优化**

从左往右遍历的过程中，其实当前的前缀和 以及 前缀和中的最小值是可以被单一变量更新出来的：

```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        n = len(nums)

        # prefix 表示当前前缀和
        prefix = 0

        # min_prefix 表示当前遇到过的最小前缀和
        min_prefix = 0

        # 在求 f(i) 的过程中，边计算边维护前缀和与当前最小前缀和
        maxSum = float("-inf")

        for i in range(n):
            # 计算当前位置的前缀和
            prefix += nums[i]

            # 用当前前缀和减去前面最小的前缀和
            # 差分出来的子数组就是以当前位置为右端点时的最大子数组和
            maxSum = max(maxSum, prefix - min_prefix)

            # 维护当前最小前缀和
            min_prefix = min(min_prefix, prefix)

        return maxSum
```

### 面试问答

**1.本题是什么思路？**

这道题的核心思路是**前缀和 + 贪心**：我们从左到右遍历数组，一边累加得到当前的前缀和，一边记录之前出现过的最小前缀和。对于当前位置来说，想要得到以它结尾的最大子数组和，就是用当前总和减去之前最小的那个总和，这样差值最大。整个过程不断更新当前总和、历史最小值，并维护答案。由于只需要遍历一遍数组，时间复杂度是 **O(n)**，且只用到常数变量，空间复杂度是 **O(1)**。

## LeetCode 238. 除自身以外数组的乘积

[在线刷题](https://codefun2000.com/p/P4038)

给定一个整数数组 `nums`，返回一个数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。

**输入样例**

```
4
1 2 3 4
```

**输出样例**

```
24 12 8 6
```


> 输入 **保证** 数组 $answer[i]$在 **32 位** 整数范围内

**思路:前后缀积**

类似前缀和的思路，我们维护两个量：

- `prefix[i]`：表示 **i 左边所有元素的乘积（不包含自身）**
- `suffix[i]`：表示 **i 右边所有元素的乘积（不包含自身）**

那么最终答案就是：

- `answer[i] = prefix[i] * suffix[i]`

直接看代码吧~

#code-switcher

```python 
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        n = len(nums)

        # answer[i] 最终表示除 nums[i] 以外所有元素的乘积
        answer = [1] * n

        # prefix 表示当前位置左边所有元素的乘积
        prefix = 1
        for i in range(n):
            # 先把左边所有元素的乘积放到 answer[i]
            answer[i] = prefix

            # 更新前缀积，把当前元素乘进去
            prefix *= nums[i]

        # suffix 表示当前位置右边所有元素的乘积
        suffix = 1
        for i in range(n - 1, -1, -1):
            # answer[i] 原本是左边乘积，再乘上右边乘积就是最终答案
            answer[i] *= suffix

            # 更新后缀积，把当前元素乘进去
            suffix *= nums[i]

        return answer
```

```javascript 
    for (let i = n - 1; i >= 0; i--) {
        // answer[i] 原本是左边乘积，再乘上右边乘积就是最终答案
        answer[i] *= suffix;

        // 更新后缀积，把当前元素乘进去
        suffix *= nums[i];
    }

    return answer;
};
```

### **面试问答**

**1.这道题的整体思路是什么？**

前缀乘积和后缀乘积的思想，每个位置的答案等于左边所有数的乘积乘以右边所有数的乘积。时间复杂度为$O(n)$，因为只需遍历数组两次，空间复杂度：$O(n)$，开销来自前缀后缀积数组。
