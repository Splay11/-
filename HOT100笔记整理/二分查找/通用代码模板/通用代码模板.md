## 一种永远不会忘记的通用二分模板

**1.划分数组：根据目标值$T$所在位置，将数组切割成$Pre$和$Suf$两个部分**

![](/file/2/zuHC0CZJldLIakYOCUPZt.png =60%x)



**2.二分查找**

**这个步骤的核心目的是：将$L$推向`Suf`的第一个位置 ， 将$R$ 拉回到`Pre`的最后一个位置。**

为了实现这个目的，二分规则为👇

如果`mid` 在前缀区域`Pre`，则`L = mid + 1`

如果`mid` 在后缀区域`Suf`，则`R = mid -1`

一直循环直到`L > R`  。 最后检查`L`,`R`所指向的元素是否是目标值即可

![](/file/2/fGDDbIt8aiqAMvH7_n1Jo.png =80%x)

**这么讲很抽象，举两个例子你就明白👇**

## **实战:【二分1】查询是否存在某个数**

[在线刷题](https://codefun2000.com/p/P14085)

题意：给定一个长度为$n$的有序数组以及$Q$次询问。每次询问一个数$T$ 是否在数组内。存在则输出`YES` ,否则输出`NO`

**思路**

我们考虑将数组拆分成$\leq T$​ 和 $> T$​ 两个部分，此时$T$​如果存在，一定在前缀部分`Pre`的最后一个位置👇

![](/file/2/gSTNazZNm2psNGsMBTY8l.png)


此时我们的目标就是：二分结束后让$R$ 指向`Pre`的最后一个位置，让$L$指向`Suf`的第一个位置，然后检查$a[R] == T$ 即可。 

为了达成这个目标，二分过程中：

1.`a[mid] > T`($mid$在后缀区域) ，则`R = mid - 1`

2.`a[mid] <= T`($mid$在前缀区域) , 则`L = mid + 1`

直到`L > R`

```python
def binary_search(A, x):
    # 初始化查找范围的左右边界
    left = 0
    right = len(A) - 1
	# 将数组分为: <= x 和 > x的部分
    # 这里取 <= 而不是 <  ，因为我们的目的是让L,R错开，而不是让L == R
    while left <= right:
        mid = (left + right) // 2
        # 如果mid 坐落于 > x 的部分， 让right 往前移动
        if A[mid] > x:
            right = mid - 1
        # 如果mid 坐落于 <= x 的部分， 让left 往后移动
        else:
            left = mid + 1
    # 整个算法结束，right 一定会落在 <= x 区域的最后一个位置
    # 此时目标值要出现，也一定出现于right所在的位置。
    # 当然有一些边界情况:
    # 1.如果 x < a[0] , 此时right 会被推向 -1
    # 2.如果 x 不存在 ，则A[right] 不会是x
    return right != -1 and A[right] == x

def main():
    # 读取数组长度n和查询次数Q
    n, Q = map(int, input().split())
    
    # 读取升序数组A
    A = list(map(int, input().split()))
    
    # 对每个查询进行二分查找
    for _ in range(Q):
        x = int(input())  # 每次查询的目标值
        # 调用二分查找函数，输出查询结果
        if binary_search(A, x):
            print("YES")
        else:
            print("NO")
    
if __name__ == "__main__":
    main()
```

## **实战:【二分2】二分找下标问题**

[在线刷题](https://codefun2000.com/p/P14086)

题意：给定一个长度为$n$的有序数组以及$Q$次询问。每次询问一个数$T$ 第一次和最后一次出现的位置。

**输入**

```
7 3
1 2 2 3 4 4 5
2
4
6
```

**输出**

```
2 3
5 6
-1 -1
```

**说明：**

- 对于询问 $2$，元素 $2$ 在数组中第一次出现的位置是 $2$，最后一次出现的位置是 $3$。
- 对于询问 $4$，元素 $4$ 在数组中第一次出现的位置是 $5$，最后一次出现的位置是 $6$。
- 对于询问 $6$，元素 $6$ 不存在于数组中，因此输出 $-1 -1$。



**$T$第一次出现的位置：**

将数组划分成:$< T$ 和 $\geq T$ 两个部分，此时目标值$T$ 在`Suf` 的第一个位置

然后二分后查询$a[L]$即可。 

**$T$最后出现的位置：**

将数组划分成:$\leq T$ 和 $> T$ 两个部分，此时目标值$T$ 在`Pre` 的最后一个位置

然后二分后查询$a[R]$即可。

```python
def find_first_position(a , T):
    n = len(a)
    left , right = 0 , n - 1
    while left <= right:
        mid = (left + right) // 2
        if a[mid] < T:
            left = mid + 1
        else:
            right = mid - 1
    return left + 1 if left <= n - 1 and a[left] == T else -1
def find_last_position(a , T):
    n = len(a)
    left , right = 0 , n - 1
    while left <= right:
        mid = (left + right) // 2
        if a[mid] <= T:
            left = mid + 1
        else:
            right = mid - 1
    return right + 1 if right >= 0 and a[right] == T else -1   
def solve(a , T):
    first = find_first_position(a , T)
    last = find_last_position(a , T)
    return first , last

n , Q = map(int, input().split())
arr = list(map(int, input().split()))
for _ in range(Q):
    T = int(input())
    print(*solve(arr , T))
```

```cpp
#include <iostream>
#include <vector>
#include <utility>
using namespace std;

int find_first_position(vector<int>& a, int T) {
    int n = a.size();
    int left = 0, right = n - 1;
    while (left <= right) {
        int mid = (left + right) / 2;
        if (a[mid] < T) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    return left <= n - 1 && a[left] == T ? left + 1 : -1;
}

int find_last_position(vector<int>& a, int T) {
    int n = a.size();
    int left = 0, right = n - 1;
    while (left <= right) {
        int mid = (left + right) / 2;
        if (a[mid] <= T) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    return right >= 0 && a[right] == T ? right + 1 : -1;
}

pair<int, int> solve(vector<int>& a, int T) {
    int first = find_first_position(a, T);
    int last = find_last_position(a, T);
    return {first, last};
}

int main() {
    int n, Q;
    cin >> n >> Q;

    vector<int> arr(n);
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }

    for (int i = 0; i < Q; i++) {
        int T;
        cin >> T;
        pair<int, int> ans = solve(arr, T);
        cout << ans.first << " " << ans.second << endl;
    }

    return 0;
}
```

```java
import java.util.Scanner;

public class Main {
    static int find_first_position(int[] a, int T) {
        int n = a.length;
        int left = 0, right = n - 1;
        while (left <= right) {
            int mid = (left + right) / 2;
            if (a[mid] < T) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return left <= n - 1 && a[left] == T ? left + 1 : -1;
    }

    static int find_last_position(int[] a, int T) {
        int n = a.length;
        int left = 0, right = n - 1;
        while (left <= right) {
            int mid = (left + right) / 2;
            if (a[mid] <= T) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return right >= 0 && a[right] == T ? right + 1 : -1;
    }

    static int[] solve(int[] a, int T) {
        int first = find_first_position(a, T);
        int last = find_last_position(a, T);
        return new int[]{first, last};
    }

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int n = input.nextInt();
        int Q = input.nextInt();

        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = input.nextInt();
        }

        for (int i = 0; i < Q; i++) {
            int T = input.nextInt();
            int[] ans = solve(arr, T);
            System.out.println(ans[0] + " " + ans[1]);
        }

        input.close();
    }
}
```

## **总结**

**将数组一分为二，让目标点坐落于端点位置，接着二分让$L,R$ 逼近两个部分的端点，最后检查$L/R$ 即可。**
