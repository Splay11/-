## 二分查找基础

二分查找通常是在一个**有序**数组中查找特定元素。

例如：给定一个有序数组$[1,2,4,5,7,10,11,13]$ ， 查找$7$ 是否在其中。

查找数组中间位置的值$5$  ， $7 > 5$ , 而又由于数组有序，则$5$以及其左侧元素$[1,2,4]$都可以被抛弃。

接着查找$[7,10,11,13]$中间位置的值$10$ ， $7 < 10$ , 则$10$以及其右侧的元素$[11,13]$ 都可以被抛弃。

接着查找$[7]$ 中间位置的值$7$ ， $7 = 7$ , 找到。

**接下来我们用完整的三个例子动画带大家理解这个过程👇**

@[video](https://codefun2000.com/p/4176/file/%E6%9C%B4%E7%B4%A0%E4%BA%8C%E5%88%86.mp4)

动画的形式化表述就是：

   - 设定一个查找范围的左右边界，通常用两个变量表示，`L` 和 `R`。
   - 计算当前区间的中间元素下标：`mid = (L + R) / 2` （向下取整）
   - 将中间元素$a[mid]$与目标值$T$进行比较：
     - 如果$a[mid] == T$，查找成功，返回该元素的位置。
     - 如果$a[mid] > T$，说明目标值在左半部分，更新`R = mid - 1`。
     - 如果$a[mid] < T$，说明目标值在右半部分，更新`L = mid + 1`。
   - 重复上述过程，直到查找范围为空（`L > R`），即目标值不存在。

**时间复杂度**：二分查找的时间复杂度是$O(log n)$，因为每次查找都将查找范围缩小一半，最多对数次就能得到结果

实战:【二分1】查询是否存在某个数

题意：给定一个长度为$n$的有序数组以及$Q$次询问。每次询问一个数$T$ 是否在数组内。存在则输出`YES` ,否则输出`NO`

```python
from typing import List


class Solution:
    def search(self, nums: List[int], target: int) -> int:
        # 初始化查找范围的左右边界
        left = 0
        right = len(nums) - 1
        
        # 当查找范围有效时进行循环
        while left <= right:
            # 计算中间位置
            mid = (left + right) // 2
            
            # 如果中间元素等于目标值，返回下标
            if nums[mid] == target:
                return mid
            elif nums[mid] < target:
                # 目标值在右半部分，更新左边界
                left = mid + 1
            else:
                # 目标值在左半部分，更新右边界
                right = mid - 1
        
        # 没有找到目标值，返回 -1
        return -1


def main():
    # 读取数组长度 n 和查询次数 Q
    n, Q = map(int, input().split())
    
    # 读取升序数组
    nums = list(map(int, input().split()))
    
    # 创建 Solution 对象
    solution = Solution()
    
    # 对每个查询进行二分查找
    for _ in range(Q):
        # 读取每次查询的目标值
        target = int(input())
        
        # 调用函数并输出查询结果
        if solution.search(nums, target) != -1:
            print("YES")
        else:
            print("NO")


if __name__ == "__main__":
    main()
```

```cpp
#include <iostream>
#include <vector>
using namespace std;

class Solution {
public:
    int search(vector<int>& nums, int target) {
        // 初始化查找范围的左右边界
        int left = 0;
        int right = nums.size() - 1;
        
        // 当查找范围有效时进行循环
        while (left <= right) {
            // 计算中间位置
            int mid = left + (right - left) / 2;
            
            // 如果中间元素等于目标值，返回下标
            if (nums[mid] == target) {
                return mid;
            } else if (nums[mid] < target) {
                // 目标值在右半部分，更新左边界
                left = mid + 1;
            } else {
                // 目标值在左半部分，更新右边界
                right = mid - 1;
            }
        }
        
        // 没有找到目标值，返回 -1
        return -1;
    }
};

int main() {
    // 读取数组长度 n 和查询次数 Q
    int n, Q;
    cin >> n >> Q;
    
    // 读取升序数组
    vector<int> nums(n);
    for (int i = 0; i < n; i++) {
```

```java
import java.util.Scanner;

class Solution {
    public int search(int[] nums, int target) {
        // 初始化查找范围的左右边界
        int left = 0;
        int right = nums.length - 1;
        
        // 当查找范围有效时进行循环
        while (left <= right) {
            // 计算中间位置
            int mid = left + (right - left) / 2;
            
            // 如果中间元素等于目标值，返回下标
            if (nums[mid] == target) {
                return mid;
            } else if (nums[mid] < target) {
                // 目标值在右半部分，更新左边界
                left = mid + 1;
            } else {
                // 目标值在左半部分，更新右边界
                right = mid - 1;
            }
        }
        
        // 没有找到目标值，返回 -1
        return -1;
    }
}

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        
        // 读取数组长度 n 和查询次数 Q
        int n = input.nextInt();
        int Q = input.nextInt();
        
        // 读取升序数组
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = input.nextInt();
        }
        
        // 创建 Solution 对象
        Solution solution = new Solution();
        
        // 对每个查询进行二分查找
        for (int i = 0; i < Q; i++) {
            // 读取每次查询的目标值
            int target = input.nextInt();
            
            // 调用函数并输出查询结果
            if (solution.search(nums, target) != -1) {
                System.out.println("YES");
            } else {
                System.out.println("NO");
            }
        }
        
        input.close();
    }
}
```
