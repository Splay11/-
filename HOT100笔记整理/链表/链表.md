## LeetCode 21. 合并两个有序链表

[在线刷题](https://codefun2000.com/p/P4044)

给定两个升序链表 `L1` 和 `L2`，将它们合并为一个新的升序链表并返回。新链表由拼接 `L1` 和 `L2` 的所有节点组成。

**输入**

```
3
1 2 4
4
1 3 4
```

**输出**

```
1 1 2 3 4 4
```

**思路：**

这题第一眼看上去是链表题，但本质其实很简单。

因为给你的两个链表本身都已经是**升序**的，所以我们每次只需要看两个链表当前节点里，谁更小，就把谁接到答案链表后面即可。

**先想最核心的问题：新链表的下一个节点应该接谁？**

假设现在：

* `l1` 指向第一个链表当前节点
* `l2` 指向第二个链表当前节点

由于两个链表都已经有序，所以当前这两个节点里较小的那个，一定就是整个剩余部分里最小的节点。

也就是说：

* 如果 `l1.val <= l2.val`，那就先接 `l1`
* 否则先接 `l2`

然后把被接走的那个指针向后移动一位，继续比较。

这个过程其实就是两个指针同步向后扫。

**为什么只比较当前两个节点就够了？**

因为两个链表都已经升序。

比如当前：

* `l1.val = 1`
* `l2.val = 3`

那 `l1` 后面的节点再怎么说，也不可能影响“当前最小值一定是 1”这个事实。
所以此时答案链表的下一个节点只能接 `l1`。

这就是有序性给我们的保证。

一句话：

> **两个有序链表合并时，答案链表当前该接谁，只取决于两个链表当前节点谁更小。**

```python
class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        # 使用虚拟头节点，方便统一处理答案链表的拼接
        dummy = ListNode()
        cur = dummy

        # 两个链表都没有走完时，每次比较当前节点
        while list1 and list2:
            # 谁更小，就把谁接到答案链表后面
            if list1.val <= list2.val:
                cur.next = list1
                list1 = list1.next
            else:
                cur.next = list2
                list2 = list2.next

            # 答案链表指针向后移动
            cur = cur.next

        # 把还没走完的那一段直接接到答案链表后面
        if list1:
            cur.next = list1
        else:
            cur.next = list2

        return dummy.next
```

### 面试问答

**1. 本题的核心思路是什么？**

本题的核心思路是：利用两个链表都已经按升序排列这一性质，使用两个指针分别指向 `L1` 和 `L2` 当前节点，每次比较这两个节点的值，谁更小就把谁接到新链表尾部，然后将对应指针后移一位；这样不断推进，直到某一个链表为空，最后再把另一个链表剩余部分直接接到答案链表后面即可。本质上这就是**两个有序序列的归并过程**。由于两个指针都只会单调向后移动，每个节点最多被访问一次，所以时间复杂度是 $O(n+m)$，其中 $n,m$ 分别是两个链表的长度；额外空间复杂度是 $O(1)$，因为只使用了若干指针变量，没有开与输入规模相关的额外空间。
