## **邻居**

通过一条边就能到达点$u$的节点称为$u$的邻居节点👇

## **连通性和连通分量**

连通性：任意两个点之间是否能通过一些边到达。

连通块/连通分量：**对于一个无向图**，一个点集合，满足 任意两个点之间连通。

连通分量数：一张图中连通分量的个数

![](/file/2/yO9mmtXroB38sOFDJM-WI.png)



## **最短路径**

两个点之间，通过一些边联通，且边权之和最小的路径，$x$到$y$的最短路径定义为：$dist(x,y)$

ps:如果不定义边权，默认边权为1

![](/file/2/CFcTojznaxn4C7asEcKCN.png)

**如何在计算机中存储一张图?**

一般有两种方式👇

**1.邻接矩阵**：使用二维数组表示图，数组元素表示两个顶点之间是否存在边。

$edge[i][j] = 0 / 1$ 代表 $i$ 和 $j$ 之间是否存在边。

![](/file/2/ax01kQAxeHQOVkWe13qhM.png)



空间复杂度：$O(n^2)$ ,其中$n$是点的个数。 

以下是Python/C++/Java代码实现👇

```python
n , m = map(int, input().split())
# 开辟到n + 1 是因为 存储节点下标 1~n 需要开辟 (n + 1) 长度的数组
edges = [[0] * (n + 1) for _ in range(n + 1)]

for i in range(1 , n + 1):
    edges[i][i] = 1 # 自己到自己可以连通

for _ in range(m):
    u ,v  = map(int, input().split())

    edges[v][u] = 1 # 如果是无向图，需要反向建边

    for j in range(1 , n + 1):
        print(edges[i][j] , end = " ")
    print()
```

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;

    // 开辟到n + 1 是因为 存储节点下标 1~n 需要开辟 (n + 1) 长度的数组
    vector<vector<int>> edges(n + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= n; i++) {
        edges[i][i] = 1; // 自己到自己可以连通
    }

    for (int _ = 0; _ < m; _++) {
        int u, v;
        cin >> u >> v;
        edges[u][v] = 1;
        edges[v][u] = 1; // 如果是无向图，需要反向建边
    }

    // 打印邻接矩阵
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            cout << edges[i][j] << " ";
        }
        cout << endl;
    }

    return 0;
}

```

2. **2.邻接表**：顾名思义，构建一个点列表，第$i$行存储第$i$个点的所有邻居节点。
3. 
![](/file/2/fU9XgtUiCFqCiErwasSGA.png)

空间复杂度：$O(n + m)$，其中$n$是点的个数，$m$是边的个数。 

一般做题建议直接使用邻接表，以下是Python/C++/Java代码实现👇
#code-switcher
```python
n , m = map(int, input().split())
# 开辟到n + 1 是因为 存储节点下标 1~n 需要开辟 (n + 1) 长度的数组
edges = [[] for _ in range(n + 1)]

for _ in range(m):
    u , v = map(int, input().split())
    edges[u].append(v)
    edges[v].append(u) # 无向图需要反向建边

# 打印邻接表
for i in range(1 , n + 1):
    print(i , end = ":")
    for j in edges[i]:
        print(j , end = " ")
    print()
```

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;

    // 开辟到n + 1 是因为 存储节点下标 1~n 需要开辟 (n + 1) 长度的数组
    vector<vector<int>> edges(n + 1);

    for (int _ = 0; _ < m; _++) {
        int u, v;
        cin >> u >> v;
        edges[u].push_back(v);
        edges[v].push_back(u); // 无向图需要反向建边
    }

    // 打印邻接表
    for (int i = 1; i <= n; i++) {
        cout << i << ":";
        for (int j : edges[i]) {
            cout << j << " ";
        }
        cout << endl;
    }

    return 0;
}

```
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n, m;
        n = sc.nextInt();
        m = sc.nextInt();

        // 开辟到n + 1 是因为 存储节点下标 1~n 需要开辟 (n + 1) 长度的数组
        List<List<Integer>> edges = new ArrayList<>();
        for (int i = 0; i <= n; i++) {
            edges.add(new ArrayList<>());
        }

        for (int _ = 0; _ < m; _++) {
            int u, v;
            u = sc.nextInt();
            v = sc.nextInt();
            edges.get(u).add(v);
            edges.get(v).add(u); // 无向图需要反向建边
        }

        // 打印邻接表
        for (int i = 1; i <= n; i++) {
            System.out.print(i + ":");
            for (int j : edges.get(i)) {
                System.out.print(j + " ");
            }
            System.out.println();
        }

        sc.close();
    }
}
```
