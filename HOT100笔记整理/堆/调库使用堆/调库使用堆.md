堆是一种**特殊的[完全二叉树](https://codefun2000.com/codenote/hot100/P0039#%E5%AE%8C%E5%85%A8%E4%BA%8C%E5%8F%89%E6%A0%91)**，常用于快速获得集合元素中的最大值或最小值。

## **1.堆长什么样子？**

堆分为**大根堆**和**小根堆**，这里我们先介绍小根堆，理解了小根堆之后，大根堆就很简单了。

小根堆的性质很简单：

1.属于**完全二叉树**

2.**局部有序性**：每个节点的值**小于等于**左右儿子节点的值。

**举几个例子你就明白👇**

![](/file/2/KWeBx9mG620IbOX184jPH.png)


#warning-box

**重要性质**：堆顶是集合最小值

1.根据局部有序性，考虑从根节点开始往下走到任意一个节点，整个过程值是非递减的，也就是数值会越来越大。

2.又因为根节点能到达所有其他节点。

**根节点的值小于等于所有其他节点的值，即根节点的值是全局最小值。**

所以牢记一点，对堆的任何操作，我们一定要确保操作完后堆的性质不要被破坏。因为只要破环了，我们就无法再获得全局最小值了！

#warning-box


## **2.如何插入一个新元素？（底部冒泡法）**

直接将新元素插入在整颗树的末尾，然后从该位置开始不停跟父亲节点进行比较与交换：

$x$如果小于父亲节点，则破环了堆的规则，和父亲节点交换。

交换完之后，继续往上看父亲节点，如果小于等于，则继续交换。直到$x$ 大于等于父亲节点。

**整个过程，新元素$x$就如同一个气泡，如果更轻就往上浮**

**思考1:**：为什么要插入在整棵树的末尾，而不是插在其他地方？

这样能够保证插入之后依旧是一个完全二叉树。插入在其他位置不好保证这个性质

**思考2**：该操作的复杂度是多少？

$n$个节点的完全二叉树的高度是$logn$ 的 ， 也就是该操作最多执行$logn$次，复杂度为$O(logn)$

## **3.如何删除最小值？（下沉法）**

删除堆顶后，将整棵树的最后一个节点顶替堆顶，然后不断往下做调整。

1.如果新的堆顶同时大于左儿子与右儿子

堆顶与左右儿子中更小的那一个进行交换。和更大的那个进行交换会破坏堆的第二个性质👇

2.如果新的堆顶大于左儿子与右儿子的其中一个

直接和这一个进行交换即可。

如此往复，新的堆顶不断下沉，直到到达合适位置.

**思考1:为什么用完全二叉树存储,而不是别的数据结构?**

1.能直接用数组存储

2.访问父亲节点和儿子节点都极其方便

## **面试问答**

**1.堆是个怎样的数据结构**

堆本质上是一个**完全二叉树**，然后再加一个“父子之间有序”的性质。
比如小根堆就是：**每个节点都小于等于它的孩子**，所以堆顶就是全局最小值。

**2.如何存储堆？**

因为堆是完全二叉树，所以可以用数组直接表示
节点关系用：左孩子：`2*i+1`  ; 右孩子：`2*i+2`  ; 父亲节点：`(i - 1) // 2` )(向下取整) 来访问。

**3.如何维护堆？**

1.插入操作:

先将元素插到数组末尾（保证完全二叉树结构），然后再做一个“上浮”操作：如果当前节点比父节点小，就交换 。一直往上，直到满足堆性质。这个过程其实只会沿着一条路径往上走，完全二叉树的树高为logn，所以复杂度是 O(log n)

2.删除操作：

用最后一个元素补到堆顶（保证完全二叉树结构），然后再做一个“下沉”操作，和左右孩子里更小的那个交换。一直往下走，直到满足堆性质，完全二叉树的树高为logn，所以复杂度是 O(log n)

```python
class MinHeap:
    def __init__(self):
        self.heap = []
        self.size = 0

    # 加入一个元素
    def push(self, x):
        # 将元素插入到堆的末尾
        self.heap.append(x)
        # 维护堆的性质
        self.size += 1
        # 将元素上浮到合适的位置
        self.heapify_up(self.size - 1)

    # 删除最小元素
    def pop(self):
        if self.size == 0:
            return None
        self.heap[0], self.heap[-1] = self.heap[-1], self.heap[0]
        self.size -= 1
        self.heapify_down(0)
        return self.heap.pop()

    def heapify_up(self, index):
        # 如果当前元素小于父节点，则交换
        parent = (index - 1) // 2
        if parent >= 0 and self.heap[index] < self.heap[parent]:
            # 交换
            self.heap[index], self.heap[parent] = self.heap[parent], self.heap[index]
            # 继续上浮
            self.heapify_up(parent)

    def heapify_down(self, index):
        # 如果当前元素大于子节点，则交换
        left = 2 * index + 1
        right = 2 * index + 2

        # 找到当前元素的子节点中更小的那个
        smallest = index
        if left < self.size and self.heap[left] < self.heap[smallest]:
            smallest = left
        if right < self.size and self.heap[right] < self.heap[smallest]:
            smallest = right

        if smallest != index:
            # 交换
            self.heap[index], self.heap[smallest] = self.heap[smallest], self.heap[index]
            # 继续下沉
```

```cpp
class MinHeap {
public:
    vector<int> heap;
    int size;

    MinHeap() {
        heap = vector<int>();
        size = 0;
    }

    // 加入一个元素
    void push(int x) {
        // 将元素插入到堆的末尾
        heap.push_back(x);
        // 维护堆的性质
        size++;
        // 将元素上浮到合适的位置
        heapify_up(size - 1);
    }

    // 删除最小元素
    int pop() {
        if (size == 0) {
            return -1;
        }

        swap(heap[0], heap[size - 1]);
        size--;
        heapify_down(0);

        int ans = heap.back();
        heap.pop_back();

        return ans;
    }

    void heapify_up(int index) {
        // 如果当前元素小于父节点，则交换
        int parent = (index - 1) / 2;
        if (index > 0 && heap[index] < heap[parent]) {
            // 交换
            swap(heap[index], heap[parent]);
            // 继续上浮
            heapify_up(parent);
        }
    }

    void heapify_down(int index) {
        // 如果当前元素大于子节点，则交换
        int left = 2 * index + 1;
        int right = 2 * index + 2;

        // 找到当前元素的子节点中更小的那个
        int smallest = index;
        if (left < size && heap[left] < heap[smallest]) {
            smallest = left;
        }
        if (right < size && heap[right] < heap[smallest]) {
            smallest = right;
        }

        if (smallest != index) {
            // 交换
            swap(heap[index], heap[smallest]);
            // 继续下沉
            heapify_down(smallest);
        }
```

```python
class MinHeap:
    def __init__(self):
        # 初始化堆数组和当前堆大小
        self.heap = []
        self.size = 0

    def push(self, x: int) -> None:
        # 将元素插入到堆的末尾
        self.heap.append(x)
        self.size += 1

        # 将新插入的元素上浮到合适位置
        self.heapify_up(self.size - 1)

    def pop(self):
        if self.size == 0:
            return None

        # 记录堆顶最小值
        ans = self.heap[0]

        # 用最后一个元素覆盖堆顶
        self.heap[0] = self.heap[self.size - 1]
        self.heap.pop()
        self.size -= 1

        # 从堆顶开始下沉，维护小根堆
        if self.size > 0:
            self.heapify_down(0)

        return ans

    def heapify_up(self, index: int) -> None:
        # 不断和父节点比较，如果当前节点更小就向上交换
        while index > 0:
            parent = (index - 1) // 2

            if self.heap[parent] <= self.heap[index]:
                break

            self.heap[parent], self.heap[index] = self.heap[index], self.heap[parent]
            index = parent

    def heapify_down(self, index: int) -> None:
        # 不断和左右孩子中较小的节点比较，如果当前节点更大就向下交换
        while True:
            left = index * 2 + 1
            right = index * 2 + 2
            smallest = index

            if left < self.size and self.heap[left] < self.heap[smallest]:
                smallest = left

            if right < self.size and self.heap[right] < self.heap[smallest]:
                smallest = right

            if smallest == index:
                break

            self.heap[index], self.heap[smallest] = self.heap[smallest], self.heap[index]
            index = smallest


def heap_sort(arr: List[int]) -> List[int]:
    min_heap = MinHeap()

    # 所有元素依次入堆
    for x in arr:
        min_heap.push(x)

    ans = []

    # 每次取出当前堆顶最小值，得到升序结果
    while min_heap.size > 0:
        ans.append(min_heap.pop())

    return ans
```
