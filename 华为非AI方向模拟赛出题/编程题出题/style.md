# 华为非 AI 岗编程题题面文风（对照 `华为机考题汇总` 里非 AI 方向编程题）

只学语气和结构，**禁止**复述原题规则或搬原样例。本题是传统算法机考，不要写成大模型 / 训练集群 / MoE 叙事。

## 像真题的写法

- 开头用「某…系统 / 在…中 / 调度员要…」，一两句交代场景和要算什么，马上进规则。
- 规则条目化：编号或 `*` 列表；公式只写计算用得上的。
- 术语是工程对象：工单、货架、站点、报文、版本、区间、权限。不是故事人物。
- 约束单独成块；样例说明用手算走规则，不抒情。

## 不像真题、必须改掉

- 「随着…的快速发展」「为了更好地…」「值得注意的是」「换句话说」
- 「小明 / 小红 / Alice」叙事；真实公司名、产品型号堆砌
- 题面里点算法名（「请用 DP / 请用最短路」）
- 空泛形容词：智能、赋能、卓越、端到端闭环
- 把业务库 `hook` 整段粘贴进题面
- 把非 AI 题写成 Transformer / KV Cache / LoRA 包装

## 150 与 300

- 第一、二题（各 150）：中等档，一条主规则加 1～2 个思维难点，样例能手算完。两题算法核必须不同，第二题应略重于第一题（多一条规则或约束更紧）。
- 第三题（300）：困难档，3～4 个思维难点；多一步处理、多一个并列条件或多种输出，整体明显更重。不许写成前两题的换皮。
